# Issue #226774 — Show raw json sync file doesn't open the file

[https://github.com/microsoft/vscode/issues/226774](https://github.com/microsoft/vscode/issues/226774)

## Summary

The bug remains source-reproducible on current main: the context-menu action reads a nonexistent `resource` property from the selected sync-resource handle, so it cannot open the raw sync data.

## Change summary

Invoking “Show raw JSON sync data” on a Settings Sync activity entry does not open that entry's raw JSON document.

## Best solution

Make the Settings Sync activity action open the URI carried by the selected `syncResourceHandle`, while preserving the existing behavior of associated-resource and restore actions.
