# Issue #330496 — ChatApprovedAccountOrganizations causes toolset bootstrap deadlock

[https://github.com/microsoft/vscode/issues/330496](https://github.com/microsoft/vscode/issues/330496)

## Summary

The bootstrap race remains visible in current source: structural toolset resolution uses a permission-filtered lookup, so tools can be omitted while agent mode is transiently restricted. The report is actionable and should remain open as a bug.

## Change summary

Copilot-contributed read tools are permanently omitted from the read toolset when enterprise account-policy verification temporarily disables agent mode during startup.

## Best solution

Separate lookup of registered tool metadata from runtime permission filtering so toolsets are assembled completely during bootstrap while tool visibility and invocation remain governed by the resolved policy state.
