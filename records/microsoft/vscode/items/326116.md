# Issue #326116 — Cannot use MCP server with auth in Agent Host

[https://github.com/microsoft/vscode/issues/326116](https://github.com/microsoft/vscode/issues/326116)

## Summary

Keep open: Claude MCP OAuth remains an acknowledged SDK/integration limitation, and current source does not provide the native authentication bridge. The October comment supplies a concrete alternative worth evaluating, not evidence that the issue is fixed.

## Change summary

Allow an OAuth-protected MCP server to authenticate and become usable in a Claude Agent Host session.

## Best solution

Resolve the Claude SDK authentication boundary through an upstream API or a supported host-owned OAuth bridge. Evaluate the existing Codex token-injection approach against Claude's server configuration and reconnection capabilities, including plugin servers and expired credentials.
