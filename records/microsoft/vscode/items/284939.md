# Issue #284939 — Ctrl + PageDown and Ctrl + PageUp did not work as expected, Chrome shortcut was invoked.

[https://github.com/microsoft/vscode/issues/284939](https://github.com/microsoft/vscode/issues/284939)

## Summary

The report is consistent with Chrome reserving tab-navigation shortcuts rather than a failure of VS Code's editor-navigation commands. Keep it open as an upstream keyboard limitation; no specific fix or verified duplicate was found.

## Change summary

Ctrl+PageDown and Ctrl+PageUp switch Chrome tabs instead of navigating editors in VS Code for the Web on Windows.

## Best solution

Browser-reserved shortcuts need browser-level support before VS Code can reliably handle them in a normal tab. In the meantime, editor-group navigation remains available through workbench.action.focusNextGroup and workbench.action.focusPreviousGroup, which can be assigned non-conflicting shortcuts.

To switch editor groups, you can use “Focus Next Editor Group” and “Focus Previous Editor Group” from the Command Palette, or assign non-conflicting shortcuts to workbench.action.focusNextGroup and workbench.action.focusPreviousGroup.
