# Issue #334755 — Playwright cannot directly click session target picker items

[https://github.com/microsoft/vscode/issues/334755](https://github.com/microsoft/vscode/issues/334755)

## Summary

Real, source-confirmed bug with an open fixing PR already up — should stay open until that PR lands rather than being closed now.

## Change summary

Playwright can't click session target/harness picker items on the first attempt because an invisible pointer-block overlay intercepts the click.

## Best solution

Land https://github.com/microsoft/vscode/pull/334705, which removes the `.context-view-pointerBlock` overlay from ActionWidgetService and TabbedActionListWidget (the exact widget src/vs/sessions/contrib/chat/browser/sessionTypePicker.ts uses via IActionWidgetService) — merging it fixes this issue too.
