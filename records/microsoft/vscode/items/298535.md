## Change summary

PowerShell 5.1 lacks .NET member suggestions in terminal IntelliSense, while falling back to native completion can make Ctrl+Space insert a double quote.

## Best solution

Ensure native PowerShell MenuComplete remains usable when terminal suggestions are disabled, without requiring a keyboard-layout-specific profile remap.
