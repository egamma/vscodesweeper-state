# Issue #250630 — Setting to change image preview background

[https://github.com/microsoft/vscode/issues/250630](https://github.com/microsoft/vscode/issues/250630)

## Summary

Valid feature request with strong community support (32 upvotes, promoted to Backlog). The checkerboard background colors in the image preview are hardcoded in CSS with no user-facing settings — the requested capability does not exist on current main.

## Change summary

Allow users to customize the image preview checkerboard background colors via settings.

## Best solution

Add two settings (e.g. `imagePreview.background.primaryColor` and `imagePreview.background.secondaryColor`) to the media-preview extension (`extensions/media-preview/package.json`) and wire them into `extensions/media-preview/media/imagePreview.css` where the conic-gradient colors are currently hardcoded (lines 41 and 45). The predecessor issue https://github.com/microsoft/vscode/issues/52717 was closed as `*out-of-scope` years ago, but significant community demand (32 upvotes) and the Backlog promotion suggest reconsidering.
