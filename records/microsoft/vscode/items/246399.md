## Summary

The reported undefined-tree exception is fixed on current main: the AI-provider context-change handler now checks that the search tree exists before calling hasNode. The exact guard landed in a merged fix for an identical telemetry stack.

## Change summary

Registering an AI text-search provider could trigger a search-view refresh before its results tree was initialized, throwing an undefined hasNode error.
