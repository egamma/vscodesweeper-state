# Issue #235123 — `notebook.addFindMatchToSelection` needs one extra invocation

[https://github.com/microsoft/vscode/issues/235123](https://github.com/microsoft/vscode/issues/235123)

## Summary

Still reproduces on main: the Idle→Selecting transition in `findAndTrackNextSelection` selects the word but does not proceed to find the next match, requiring an extra Cmd+D. An open PR (#304968) addresses it but has not merged.

## Change summary

Pressing Cmd+D in a notebook cell with a word already selected requires two invocations instead of one to add the next find match to the selection.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/304968 (or an equivalent fix): after the Idle→Selecting transition, when the input selection was already non-empty, immediately proceed to the Selecting branch to find the next match — matching regular editor behavior from `MultiCursorSession.create()`.
