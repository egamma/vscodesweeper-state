# Issue #150152 — Cannot auth if vscode.dev is in iframe

[https://github.com/microsoft/vscode/issues/150152](https://github.com/microsoft/vscode/issues/150152)

## Summary

Keep this open as the public request for GitHub authentication in embedded vscode.dev. Maintainers explicitly retained it alongside the related embedded-auth investigation, and the inspected source does not establish that the requested scenario is now supported.

## Change summary

Allow GitHub sign-in to complete when vscode.dev runs inside an iframe on another site's page.

## Best solution

Define the supported embedding contract and provide an authentication callback flow that completes inside that environment without depending on shared storage between the embedded editor and a top-level callback page. Coordinate with the related embedded-auth investigation while retaining this public feedback thread.
