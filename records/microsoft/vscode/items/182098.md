# Issue #182098 — Support setting a badge-only color in file decorations

[https://github.com/microsoft/vscode/issues/182098](https://github.com/microsoft/vscode/issues/182098)

## Summary

Valid feature request with team agreement on the approach (extension-controlled badge-only coloring) but no implementation yet. The FileDecoration API still offers only a single `color` property with no badge-vs-text targeting. Stays open — team members endorsed the direction in the discussion.

## Change summary

Allow extensions to specify that a FileDecoration color applies only to the badge, not the filename text.

## Best solution

Add a property to the FileDecoration API (e.g. `colorTarget: 'all' | 'badge' | 'text'`) so extensions can control whether the decoration color applies to the badge, the text, or both. Team members alexr00 and lramos15 agreed this should be extension-controlled (comment 8). The implementation would touch `src/vscode-dts/vscode.d.ts` (the API surface), the decoration data model in `src/vs/workbench/services/decorations/`, and the tree renderers that apply decoration colors.
