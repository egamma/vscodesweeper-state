# Issue #174537 — Support HISTTIMEFORMAT in bash shell integration 

[https://github.com/microsoft/vscode/issues/174537](https://github.com/microsoft/vscode/issues/174537)

## Summary

Still unfixed on main: `fetchBashHistory` in history.ts does not skip `#<unix_epoch>` timestamp lines that bash writes to `~/.bash_history` when HISTTIMEFORMAT is set. An open PR (#307795) already addresses this — let the PR process proceed.

## Change summary

When HISTTIMEFORMAT is set in bash, the Run Recent Command quick pick shows `#<timestamp>` lines as commands instead of filtering them out.

## Best solution

Review and land the open PR https://github.com/microsoft/vscode/pull/307795, which adds a `#<timestamp>` skip in `fetchBashHistory` (src/vs/workbench/contrib/terminalContrib/history/common/history.ts). The fix is small and localized.
