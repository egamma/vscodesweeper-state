# Issue #337579 — Markdown preview does not scroll to an HTML anchor (<a id>) in a linked file

[https://github.com/microsoft/vscode/issues/337579](https://github.com/microsoft/vscode/issues/337579)

## Summary

The cross-file preview navigation defect remains present in current source: fragment lookup excludes inline HTML anchors without source-line metadata. The reporter confirmed that editor navigation is fixed in 1.139.0, so the remaining work is specifically the default inPreview path.

## Change summary

Make cross-file Markdown preview links scroll to inline HTML anchor targets instead of opening the destination at the top.

## Best solution

Support inline HTML anchor destinations in the built-in Markdown preview's fragment navigation while preserving heading navigation and source-line scrolling. Establish a preview DOM regression check for the supplied two-file example; the already-fixed editor path needs no additional change.
