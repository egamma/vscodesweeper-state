[https://github.com/microsoft/vscode/issues/349284](https://github.com/microsoft/vscode/issues/349284)

## Summary

The requested confirmation already exists through window.confirmBeforeClose set to "always", including mouse-initiated window closure with all files saved. The maintainer's reply identifies this setting, and current source confirms the behavior.

## Change summary

Ask for confirmation before closing VS Code, even when files are saved, to protect temporary work from accidental closure.
