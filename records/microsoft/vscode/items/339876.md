# Issue #339876 — `editorGroupHeader.tabsBackground` has no effect

[https://github.com/microsoft/vscode/issues/339876](https://github.com/microsoft/vscode/issues/339876)

## Summary

Modern UI connected tabs intentionally use editorGroupHeader.connectedTabsBackground rather than the standard header background. The existing dedicated color customization delivers the requested red tab-strip background.

## Change summary

Setting editorGroupHeader.tabsBackground to #ae0e0e does not visibly recolor the connected tab strip.

## Best solution

Keep the intentional separation between standard and connected header colors. Use editorGroupHeader.connectedTabsBackground for the connected strip and inactive tabs; use tab.activeBackground separately if the selected tab should also be red.

- **Proposed comment:**

  > Thanks for the report. Connected tabs in Modern UI use `editorGroupHeader.connectedTabsBackground`, independently of the standard `editorGroupHeader.tabsBackground` color. To make the connected tab strip red, use:
  > 
  > ```json
  > "workbench.colorCustomizations": {
  >     "editorGroupHeader.connectedTabsBackground": "#ae0e0e"
  > }
  > ```
  > 
  > The selected tab has a separate fill; add `"tab.activeBackground": "#ae0e0e"` if you want that red too. This separation is intentional.
