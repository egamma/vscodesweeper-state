# Issue #339876 — `editorGroupHeader.tabsBackground` has no effect

[https://github.com/microsoft/vscode/issues/339876](https://github.com/microsoft/vscode/issues/339876)

## Summary

Modern UI connected tabs intentionally use editorGroupHeader.connectedTabsBackground, independently of editorGroupHeader.tabsBackground. The requested red background is supported through that existing color customization; this is a token-selection question rather than broken theme application.

## Change summary

Make the editor tab-strip background red through workbench.colorCustomizations.

## Best solution

Use editorGroupHeader.connectedTabsBackground for the Modern UI connected tab strip, preserving its intentional independence from the classic header background. Individual active-tab fills remain separately customizable through tab.activeBackground.

- **Current color resolution:** src/vs/workbench/contrib/modernUI/browser/connectedEditorTabs.ts:21-36 first resolves editorGroupHeader.tabsBackground for shared connected tabs, then overrides --modern-ui-connected-tab-strip-background on Modern UI containers using editorGroupHeader.connectedTabsBackground.
- **Bundled themes explain the observed result:** extensions/theme-defaults/themes/dark_modern.json:37-38 explicitly sets tabsBackground to #181818 and connectedTabsBackground to #2B2B2B. Light Modern, classic light/dark, and the 2026 themes also explicitly provide connectedTabsBackground, so overriding only tabsBackground does not replace their connected-strip color.
- **Deliberate behavior contract:** src/vs/workbench/contrib/modernUI/test/browser/modernUI.contribution.test.ts contains 'uses separate connected strip and border colors without changing the editor group header' and 'keeps the shared connected strip on the standard header background outside Modern UI'.
