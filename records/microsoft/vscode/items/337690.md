# Issue #337690 — Always show a close button on each tab

[https://github.com/microsoft/vscode/issues/337690](https://github.com/microsoft/vscode/issues/337690)

## Summary

Genuine, unimplemented ask — the close button is deliberately hidden except for active/hover/dirty/sticky tabs — but it's only one day old with zero upvotes and a contributor already questioning the rationale, so it stays open for discussion rather than any close.

## Change summary

Add an option to always show the tab close (×) button instead of only on hover/active/dirty/sticky tabs.

## Best solution

If pursued, this would be a new boolean setting (alongside the existing `workbench.editor.tabActionCloseVisibility` on/off toggle) that forces the close action visible for all tabs regardless of hover/active state — but given the 'lean default UI' guardrail and lack of demonstrated demand, this should wait for more community traction or explicit maintainer interest before implementation.
