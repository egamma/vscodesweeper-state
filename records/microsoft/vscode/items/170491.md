# Issue #170491 — VSCode does not remember the size of the suggest widget when the size is reset with double click

[https://github.com/microsoft/vscode/issues/170491](https://github.com/microsoft/vscode/issues/170491)

## Summary

The double-click reset still bypasses size persistence in current source. Keep this open: the maintainer accepted that resetting should behave like manual resizing, and the older related issues concern the separate details pane.

## Change summary

Remember the suggest widget's size after double-clicking its resize sash, and preserve subsequent manual-resize persistence.

## Best solution

Make double-click reset participate in the suggest widget's size-persistence lifecycle, retaining existing drag thresholds, dimension-specific persistence, and layout limits. Cover reset followed by dismissal/reopening and reset followed by another drag.
