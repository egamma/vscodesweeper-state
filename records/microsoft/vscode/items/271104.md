# Issue #271104 — Chat: Support contributable chat context resources

[https://github.com/microsoft/vscode/issues/271104](https://github.com/microsoft/vscode/issues/271104)

## Summary

Keep open as the API finalization tracker: contributable context is implemented behind a proposed-API gate, not available as a stable extension API. Both the api-proposal label and the assigned 1.143.0 milestone independently require keeping this issue open.

## Change summary

Allow extensions to contribute attachable chat context with presentation metadata and asynchronously resolved prompt content.

## Best solution

Have the API owners finalize the supported context-provider contract and expose the approved surface in stable vscode.d.ts. Resolve the tab/resource versus explicit/workspace scope discussion without treating the existing proposed implementation as completion.
