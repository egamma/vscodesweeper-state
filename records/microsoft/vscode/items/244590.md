## Evidence

- **Verified older canonical:** https://github.com/microsoft/vscode/issues/127441 is open and was created on 2021-06-29, before this report. It describes false changed-line highlights in an unchanged working tree when .gitattributes working-tree-encoding matches the editor encoding—the same observable false-change symptom, not merely the same feature area.
- **Matching UTF-16 precedent:** https://github.com/microsoft/vscode/issues/242204 reports incorrect changed lines and content with working-tree-encoding=UTF-16LE-BOM. A maintainer explicitly classified it as a duplicate of the canonical issue: https://github.com/microsoft/vscode/issues/242204#issuecomment-2732926748. This connects the canonical's encoding-independent scope to this report's UTF-16 garbling.
- **Reporter trigger and repository attributes:** The reporter opens filesys/miniFilter/scanner/scanner.inf after cloning microsoft/Windows-driver-samples on Windows. https://github.com/microsoft/Windows-driver-samples/blob/main/.gitattributes declares *.inf text diff working-tree-encoding=UTF-16LE-BOM eol=crlf, so the checked-out UTF-16 file and Git's UTF-8 object content legitimately use different encodings.
- **Current source path:** extensions/git/src/fileSystemProvider.ts:readFile returns Repository.buffer for ordinary Git comparison resources. extensions/git/src/git.ts:Repository.buffer retrieves content using git show --textconv, without applying working-tree-encoding checkout conversion. This supports the shared encoding-mismatch diagnosis; no code was executed or modified.
- **Confirmed reproduction and related current report:** The reporter confirmed identical behavior on 1.99.0-insider after testing 1.98.2. https://github.com/microsoft/vscode/issues/334092 independently reports garbled original-side content and false whole-file changes under working-tree-encoding; a commenter reports resolving that symptom by changing the content retrieval primitive. It is newer and is not the proposed canonical; a maintainer links it to the older canonical at https://github.com/microsoft/vscode/issues/334092#issuecomment-5791157361.
