# Issue #326680 — feedback lost on update

[https://github.com/microsoft/vscode/issues/326680](https://github.com/microsoft/vscode/issues/326680)

## Summary

Keep open: a team member found this during the Markdown feedback test plan, and current source confirms that some session providers retain feedback only in memory, so restarting for an update can discard it.

## Change summary

Preserve unsubmitted Markdown-file feedback when VS Code restarts during an update, or warn before discarding it.

## Best solution

Persist pending feedback for every supported Agents window provider across restart, using the session-backed annotations path where possible; otherwise warn before an update restart can discard unsubmitted feedback.
