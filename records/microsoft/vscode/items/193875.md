# Issue #193875 — Nested for statements in JavaScript breaks in wrong indention

[https://github.com/microsoft/vscode/issues/193875](https://github.com/microsoft/vscode/issues/193875)

## Summary

Keep open: the current JavaScript/TypeScript Enter rules still misclassify the inner loop as a completed single-line statement and outdent instead of expanding its braces. An exact regression test exists but remains skipped.

## Change summary

Pressing Enter between the inner loop's braces after two nested for statements should indent the body and align the closing brace with the inner for statement.

## Best solution

Correct the JavaScript/TypeScript Enter behavior for this nested-loop case and make the existing issue-specific regression test pass, while preserving outdent after completed braceless statements.
