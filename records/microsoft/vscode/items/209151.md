# Issue #209151 — Outline view stuck with "Loading document symbols for " on large notebook

[https://github.com/microsoft/vscode/issues/209151](https://github.com/microsoft/vscode/issues/209151)

## Summary

Fixed on main and shipped in 1.89.0 — the outline view no longer blocks on code symbol loading for notebooks, which was the suspected cause of the stuck 'Loading document symbols' state.

## Change summary

Notebook outline view gets stuck showing 'Loading document symbols' on large notebooks because it awaits code symbol resolution before rendering.

## Best solution

Keep the shipped fix (commit 063d715c450, 1.89.0) which makes the outline pane not await code symbols. No further change needed.
