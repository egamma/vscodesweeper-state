# Issue #277949 — copilot keeps asking for permissions to github despite selecting "Never Ask Again"

[https://github.com/microsoft/vscode/issues/277949](https://github.com/microsoft/vscode/issues/277949)

## Summary

The bug is still reproducible on main: 'Never Ask Again' resets the in-memory guard (`hasRequestedPermissiveSessionUpgrade = false` at line 156 of authenticationUpgradeService.ts), and multiple independent callers (toolCallingLoop, chatParticipantRequestHandler, codeSearchChunkSearch) each invoke `shouldRequestPermissiveSessionUpgrade`, creating a race where the user is re-prompted within the same session.

## Change summary

Selecting 'Never Ask Again' for the GitHub permissions upgrade prompt does not reliably prevent re-prompting within the same session or across sessions.

## Best solution

The `handleConfirmationRequest` method should NOT reset `hasRequestedPermissiveSessionUpgrade` to `false` after the user selects 'Never Ask Again' — the config write to `AuthPermissionMode.Minimal` is the persistent gate, but the in-memory flag reset allows callers that race before the derived observable updates to re-prompt. Additionally, the multiple callers of `shouldRequestPermissiveSessionUpgrade` should share a single upgrade flow rather than independently triggering prompts.
