[https://github.com/microsoft/vscode/issues/235796](https://github.com/microsoft/vscode/issues/235796)

## Summary

Keep open: independent reporters confirm that reopening saved notebooks can leave widget outputs unreadable instead of showing their available fallback representation. Current source supports fallback but does not establish that these intermittent failures reach it; no concrete fix or qualifying open canonical was identified.

## Change summary

Reopening a notebook can leave saved tqdm or matplotlib widget outputs showing a renderer error instead of their plain-text or static fallback.

## Best solution

Ensure unavailable saved widgets reliably display an available alternative representation without requiring manual presentation changes. Diagnose the boundary between the Jupyter widget renderer and VS Code's notebook fallback handling before deciding which component needs a change.
