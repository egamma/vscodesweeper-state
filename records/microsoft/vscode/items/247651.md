# Issue #247651 — Cannot use tab as the trigger character for "format on type"

[https://github.com/microsoft/vscode/issues/247651](https://github.com/microsoft/vscode/issues/247651)

## Summary

Confirmed bug: Tab cannot work as a format-on-type trigger character because the Tab key is handled as a command (via `TypeOperations.tab()`) rather than flowing through `_type()`, so `onDidType` never fires for it and `FormatOnType` never sees it.

## Change summary

Extensions that register Tab as an on-type formatting trigger character never receive formatting requests when the user presses Tab.

## Best solution

The `FormatOnType` contribution in `src/vs/editor/contrib/format/browser/formatActions.ts` needs to also listen for the `tab` command execution (or the model content change it produces) and check whether Tab is among the registered trigger characters. The fix is localized to `FormatOnType._update()` — it currently only subscribes to `onDidType`, but it also needs to detect when Tab inserts content and treat it as a trigger.
