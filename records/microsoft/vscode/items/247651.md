# Issue #247651 — Cannot use tab as the trigger character for "format on type"

[https://github.com/microsoft/vscode/issues/247651](https://github.com/microsoft/vscode/issues/247651)

## Summary

The current source still bypasses on-type formatting when the Tab command inserts a tab. The supplied minimal extension isolates a core editor event-path defect, rather than an extension-owned failure.

## Change summary

Pressing Tab should invoke an enabled on-type formatting provider registered for the tab character when a literal tab is inserted.

## Best solution

Make literal-tab insertion through the editor's Tab command honor registered on-type formatting triggers while preserving indentation, focus navigation, completion acceptance, and existing formatting guards. Keep this core issue open; the linked YAML language-server work depends on this behavior.
