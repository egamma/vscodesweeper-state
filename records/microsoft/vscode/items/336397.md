# Issue #336397 — Request: (Copilot) Api to expose current model to chat session

[https://github.com/microsoft/vscode/issues/336397](https://github.com/microsoft/vscode/issues/336397)

## Summary

A real API gap remains for reliable model-side self-identification. Existing APIs expose the selected model to chat participants and, provisionally, extension tools, but do not provide the requested built-in introspection capability to the model itself.

## Change summary

Expose the actual model and provider used for a chat turn so the model can identify itself when signing comments or work-session output.

## Best solution

Provide a supported model-introspection mechanism for the active turn, either as a built-in model-visible tool or a finalized tool invocation contract, returning the actual selected model and provider rather than relying on the model's self-reported identity.
