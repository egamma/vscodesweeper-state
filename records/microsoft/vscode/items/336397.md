# Issue #336397 — Request: (Copilot) Api to expose current model to chat session

[https://github.com/microsoft/vscode/issues/336397](https://github.com/microsoft/vscode/issues/336397)

## Summary

Fresh, zero-comment request asking for a way for the model (or the extension driving the chat) to introspect which underlying model/provider is actually answering, so responses can be signed accurately rather than generically as 'GitHub Copilot'. Existing `ChatRequest.model` (vscode.d.ts) already exposes the selected `LanguageModelChat` to chat-participant extension authors, but that doesn't cover the reporter's actual ask — having the model itself surface its identity mid-conversation in the built-in Copilot chat experience.

## Change summary

Add an introspection/'who am I' capability so a chat session (or the model within it) can report which concrete model/provider is currently answering, instead of always saying 'GitHub Copilot'.

## Best solution

Belongs with the Copilot Chat team to decide: either document/expose that `ChatRequest.model` (name/vendor/family/id) already lets participant extensions report the active model, or add a built-in mechanism (e.g. a system-prompt fact or an agent tool) so responses in the stock Copilot chat can name the active model when asked.
