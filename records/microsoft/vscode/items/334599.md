# Issue #334599 — can't tab away from selected session

[https://github.com/microsoft/vscode/issues/334599](https://github.com/microsoft/vscode/issues/334599)

## Summary

Team-authored, same-day bug report from testing a recent change (#334481): Tab doesn't move focus in the Agents window sessions list once the mouse has moved off the hovered session, because the toolbar-focus keybinding's when-clause apparently depends on hover state rather than list focus. No fix has landed yet, so this stays open.

## Change summary

In the Agents window sessions list, pressing Tab does nothing (no matching when-clause) once the previously-hovered session row is no longer under the mouse, so focus can't move to the row's toolbar.

## Best solution

In the sessions list row/toolbar focus-on-Tab keybinding (src/vs/sessions/contrib/sessions/browser/views/sessionsList.ts or its toolbar helper), loosen the when-clause so it also fires when the row has keyboard focus, not only when it is mouse-hovered — likely tied to the recent work in #334481.
