# Issue #316851 — Find Bar's position overlaps and obscures Sticky Scroll current scope (function name etc) when UI is narrowed

## Summary

The overlap remains on current main and has an active fixing PR. Keep the issue open while that implementation is reviewed.

## Change summary

Prevent the editor Find widget from obscuring Sticky Scroll scope labels in narrow editor panes.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/326198, which dynamically positions the Find widget below Sticky Scroll as its height changes.
