# Issue #286742 — Terminal Font Ligatures stopped working in version 1.108

[https://github.com/microsoft/vscode/issues/286742](https://github.com/microsoft/vscode/issues/286742)

## Summary

The original 1.108 regression (ligatures not working at all) was addressed by PR #318992, which landed as merge commit 4ac5322601c6985aba4cd9349c23f4ef22dc3e65 — already refuted by a prior independent review and off the table as a close citation — and several commenters confirmed it fixed ligatures for them in 1.125. However, multiple later reports (1.125.0, 1.130.0) describe ligatures still rendering inconsistently for specific fonts (JetBrains Mono, FiraCode Nerd Font Mono), so a real residual defect likely remains and this should stay open.

## Change summary

Font ligatures in the integrated terminal broke in 1.108 and, per later reports, still render inconsistently for some fonts even after a partial fix shipped in 1.125.

## Best solution

Diagnose the residual partial-ligature-rendering reports (comments from KunalTanwar on 1.125.0 and mahy-ks-hussain on 1.130.0) separately from the already-fixed addon-config-tracking bug — determine whether this is a VS Code-side glyph/feature-matching issue in xtermTerminal.ts or an upstream limitation in @xterm/addon-ligatures, and whether it warrants a narrower follow-up issue.
