# Issue #235344 — `Add line comment` should await the tokenization to get the correct language at the position

[https://github.com/microsoft/vscode/issues/235344](https://github.com/microsoft/vscode/issues/235344)

## Summary

Still reproduces on main: async tokenization (default true) means the comment command may query `getLanguageIdAtPosition` before tokenization completes, returning the wrong language for embedded code (e.g. JS inside HTML). An open PR and tracking issue are actively addressing this.

## Change summary

The 'Add Line Comment' command uses the wrong language (HTML instead of JavaScript) inside `<script>` tags when async tokenization hasn't finished at startup.

## Best solution

The fix should either await tokenization before querying the language at position in `lineCommentCommand.ts`, or resolve via the async tokenization investigation tracked in https://github.com/microsoft/vscode/issues/244225. PR https://github.com/microsoft/vscode/pull/244217 is an open fix attempt (turns off async tokenization by default). A maintainer should land or iterate on that PR.
