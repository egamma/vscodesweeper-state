# Issue #235344 — `Add line comment` should await the tokenization to get the correct language at the position

[https://github.com/microsoft/vscode/issues/235344](https://github.com/microsoft/vscode/issues/235344)

## Summary

Keep open: the discussion confirms incorrect embedded-language commenting after reload, and current source still reads token-derived language information without awaiting readiness. An open PR explicitly targets this issue, so its implementation candidate should be reviewed before considering closure.

## Change summary

Line commenting inside an HTML script block can do nothing or use HTML comments after startup instead of commenting the JavaScript.

## Best solution

Ensure line-comment commands use the correct embedded-language configuration after startup or reload. Review https://github.com/microsoft/vscode/pull/244217 against both the immediate-after-reload and persistent-until-editing cases; disabling asynchronous tokenization is a candidate mitigation, not evidence that the command-readiness problem is fixed.
