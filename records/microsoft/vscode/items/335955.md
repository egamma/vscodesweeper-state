# Issue #335955 — Settings editor and other webview-based panels cannot be detached into a real, independent OS window

## Summary

The report's premise doesn't match current source: the Settings editor (`SettingsEditor2`) contains no iframe/webview at all, and its input class doesn't override `EditorInput.canMove()`, so nothing in code blocks it from being moved into a new OS window the same way other editors are. The related closed issue #195715 already shipped general iframe/webview/notebook/custom-editor reparenting into aux windows in March 2024. Given the mismatch, this needs a concrete repro before deciding.
