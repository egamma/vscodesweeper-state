# Issue #340380 — difficulty in restarting agent host tunnel

[https://github.com/microsoft/vscode/issues/340380](https://github.com/microsoft/vscode/issues/340380)

## Summary

Fresh, detailed, first-party report from a VS Code collaborator documenting multiple real defects in tunnel/Agent Host lifecycle cleanup (orphaned processes, stale registrations, HTTP 404 loops). No close rule applies — this is a brand-new, well-diagnosed bug report that should be routed to the remote-tunnel/agent-host owners.

## Change summary

Restarting/migrating a remote Agent Host tunnel leaves orphaned `tunnel service internal-run` and legacy `agent host --tunnel` processes alive even after `tunnel kill`/`service uninstall`, causing stale tunnel IDs, HTTP 404 loops, and a gateway-selection timeout.

## Best solution

Fix the CLI tunnel/Agent Host service lifecycle so `tunnel kill` and `tunnel service uninstall` reliably terminate all child/orphaned processes and reconcile local state (code_tunnel.json, lock/log files) with the server-side Dev Tunnel resource, rather than leaving reconnect loops and stale registry entries after an interactive client-side tunnel deletion.
