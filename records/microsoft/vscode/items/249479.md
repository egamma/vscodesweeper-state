# Issue #249479 — Support multiple LSP based completion provider

[https://github.com/microsoft/vscode/issues/249479](https://github.com/microsoft/vscode/issues/249479)

## Summary

The built-in LSP completion provider addon still only targets Python (shellTypes: [GeneralShellType.Python]). While groundwork has been done (removing hard-coded Python elements, finalizing the terminal completion provider API), multi-shell LSP support remains unimplemented. Team-authored, valid feature request — keeping open.

## Change summary

Extend the terminal LSP completion system to support multiple language servers (pwsh, node, julia) beyond the current Python-only implementation.

## Best solution

Generalize `LspCompletionProviderAddon` in `src/vs/workbench/contrib/terminalContrib/suggest/browser/lspCompletionProviderAddon.ts` to instantiate per shell type, leveraging the already-finalized terminal completion provider extension API for external providers while expanding the built-in LSP addon to detect and connect to active language servers for each shell.
