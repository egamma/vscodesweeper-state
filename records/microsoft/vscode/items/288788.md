# Issue #288788 — Chat took too long to get ready

[https://github.com/microsoft/vscode/issues/288788](https://github.com/microsoft/vscode/issues/288788)

## Summary

The logs show all network requests failing with `net::ERR_PROXY_CONNECTION_FAILED` against a local proxy at `127.0.0.1:7890`. The 210-second activation delay (`activationBlocker from 'conversationFeature' took for 210704ms`) is caused by the user's misconfigured or unavailable local proxy, not a VS Code or Copilot defect.

## Change summary

Copilot Chat activation was delayed ~3.5 minutes due to repeated proxy connection failures before eventually connecting.

## Best solution

This is a user environment issue — the local proxy at `127.0.0.1:7890` was unavailable during startup, causing all authentication and model-fetching requests to time out. The reporter should ensure their proxy is running before launching VS Code, or remove the proxy configuration if it is not needed.
