The reported misleading menu toggle has been replaced on current main by explicit whitespace modes. Keep the issue open while the linked open PR is reviewed; it proposes a separate change to the retained Toggle Render Whitespace command.

## Change summary

Make the Render Whitespace menu accurately communicate the active rendering mode instead of appearing enabled when only selected whitespace is rendered.
