# Issue #332798 — huge gap appeared between window right edge and the scrollbar

[https://github.com/microsoft/vscode/issues/332798](https://github.com/microsoft/vscode/issues/332798)

## Summary

Reproduces from source: the Modern UI Update experiment (an active A/B experiment, `workbench.experimental.modernUI`, default off but auto-enrolled per the settings' `experiment: { mode: 'auto' }`) insets pane rows and rounds/repositions scrollbars, which moves the scrollbar away from the window edge and breaks the classic edge-grab gesture; disabling the setting confirmed as a workaround.

## Change summary

With Modern UI enabled, a large gap opens between the window's right edge and the scrollbar, breaking the habit of grabbing the scrollbar at the window edge.

## Best solution

This is a known trade-off of the in-progress Modern UI redesign (rounded/inset scrollbars, gapped panes in src/vs/workbench/contrib/modernUI/browser/media/{padding,roundedCorners}.css); the modernUI team should decide whether to shrink the inset or keep a full-height edge hit-target for scrollbar dragging when the feature is enabled.

## Vision fit

- **Fit:** unclear
- **Reason:** Modern UI is an active workbench redesign; the vision doesn't prescribe how much edge padding versus edge-affordance is appropriate, so this is a design trade-off for the feature owners, not a vision violation.

- **CSS root cause:** src/vs/workbench/contrib/modernUI/browser/media/padding.css insets pane rows/scrollbars by --vscode-spacing-size40/80 and roundedCorners.css restyles/repositions scrollbar sliders under the `.modern-ui` class, consistent with a scrollbar shifted away from the window edge.
