Verified duplicate: this reports the exact same symptom as the older, open issue #326179 — a gap between the scrollbar and the window edge in the Modern UI that breaks quick-grab scrolling at the screen edge. A collaborator already flagged the same match in the thread.

Under the new 'Modern UI', a visible gap now separates the scrollbar from the window's right edge, so flinging the cursor to the screen edge no longer grabs the scrollbar handle.
