# Issue #332798 — huge gap appeared between window right edge and the scrollbar

[https://github.com/microsoft/vscode/issues/332798](https://github.com/microsoft/vscode/issues/332798)

## Summary

Real UX regression traced to the new experimental Modern UI feature: it shrinks the scrollbar to 8px (vs the default) and adds surface padding, making the scrollbar harder to grab near the window edge. A maintainer-suggested workaround (`workbench.experimental.modernUI: false`) confirms the cause; this belongs with the team already iterating on Modern UI feedback, not a generic close.

## Change summary

After enabling/receiving the Modern UI experiment, the vertical scrollbar sits with a noticeable gap from the window's right edge, making it harder to grab with a long-press at the edge as before.

## Best solution

File this as scrollbar-affordance feedback for the active Modern UI workstream (src/vs/workbench/contrib/modernUI/browser/modernUI.contribution.ts and media/padding.css, which reduce MODERN_UI_SCROLLBAR_SIZE to 8px and inset content) — the team already tracks broader Modern UI complaints in https://github.com/microsoft/vscode/issues/332193 (labeled `modernization`, assigned to maintainers) and should fold this specific scrollbar hit-target regression into that iteration rather than treat it as a one-off bug.
