# Issue #262823 — code.desktop on linux should not have execution permissions

[https://github.com/microsoft/vscode/issues/262823](https://github.com/microsoft/vscode/issues/262823)

## Summary

The executable desktop-entry permission remains in current main: code.desktop is tracked as 100755, and Debian packaging preserves its source permissions. Keep this open for a bounded packaging correction.

## Change summary

Install /usr/share/applications/code.desktop without executable permission bits on Debian Linux.

## Best solution

Ship the system application desktop entry as non-executable data, consistent with code-url-handler.desktop, while preserving launcher behavior and executable permissions on actual programs and package-maintenance scripts.
