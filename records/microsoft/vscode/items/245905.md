- **Trace:**

  > getUserMcpConfigPath in src/vs/workbench/contrib/mcp/browser/mcpWorkbenchService.ts provides no workspaceFolder, whereas workspace-folder configuration paths do. InstalledMcpServersDiscovery carries that value into variableReplacement.folder, and McpRegistry._replaceVariablesInLaunch forwards it to the configuration resolver. AbstractVariableResolverService.evaluateSingleVariable in variableResolver.ts requires an explicit folderUri or named folder for workspaceFolder and workspaceFolderBasename; it does not infer the sole open folder. relativeFile variables have an explicit absolute-path fallback, so their success does not demonstrate equivalent resolution semantics. selectedText instead reads the active editor through BaseConfigurationResolverService and is not explained by the absent folder. Preserve shared resolver behavior for other consumers unless a broader contract change is explicitly approved. The newer related report is https://github.com/microsoft/vscode/issues/297794; the original scope clarification is https://github.com/microsoft/vscode/issues/245905#issuecomment-2784621282.
- **Open decisions:**
