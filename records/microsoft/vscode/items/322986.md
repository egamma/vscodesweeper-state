# Issue #322986 — Cannot paste in empty markdown file

[https://github.com/microsoft/vscode/issues/322986](https://github.com/microsoft/vscode/issues/322986)

## Summary

The defect remains traceable on current main: the Markdown custom editor uses the native clipboard strategy even though VS Code webviews intercept native paste events. This team-authored issue should remain open until the integration selects the webview-compatible strategy.

## Change summary

Pasting text into a newly created empty file in the Markdown custom editor has no effect.

## Best solution

Configure `EditorController` in `extensions/markdown-language-features/markdown-editor-src/editor.ts` with `AsyncClipboardStrategy`, then cover pasting into both empty and populated Markdown documents in a webview-level test.
