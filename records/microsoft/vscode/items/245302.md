# Issue #245302 — [Sticky Scroll] If a function consist of multiline arguments, sticky the function also multiline

[https://github.com/microsoft/vscode/issues/245302](https://github.com/microsoft/vscode/issues/245302)

## Summary

Consolidate this request into the older, open multiline Sticky Scroll request. Its discussion explicitly reports the same symptom: multiline parameters leave only the last parameter visible instead of the function name.

## Change summary

Keep the function name and all parameter lines visible in Sticky Scroll for multiline function declarations.

## Best solution

Track multiline Sticky Scroll entries in https://github.com/microsoft/vscode/issues/238568, preserving this report's C example and the preference for keeping the function name visible even when a complete parameter list would be too tall.
