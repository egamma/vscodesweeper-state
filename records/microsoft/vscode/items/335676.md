# Issue #335676 — Accepting an automation template keeps it visible. Should it?

[https://github.com/microsoft/vscode/issues/335676](https://github.com/microsoft/vscode/issues/335676)

## Summary

Keep open for a post-creation UX decision: current main folds template sections when saved automations exist, but does not hide or mark the particular template used. This team-authored Backlog item has neither a verified same-symptom duplicate nor an issue-referencing fix supporting closure.

## Change summary

Make it clearer what happened to a built-in automation template after creating an automation from it.

## Best solution

Decide whether reusable templates should remain unchanged, gain a used indication, or disappear after creation, accounting for the existing automatic section folding. Keep the resulting interaction clear without conflating a reusable template with its independently editable saved automation.
