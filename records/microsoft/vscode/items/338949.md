# Issue #338949 — Custom agent model pin is overridden by the model selected in Copilot chat or the GitHub cloud window

[https://github.com/microsoft/vscode/issues/338949](https://github.com/microsoft/vscode/issues/338949)

## Summary

Thanks for the detailed report. A second user reproduced it on VS Code 1.141.0 in the Agents window and in regular chat. The picker model, and the reasoning effort too, override the custom agent's `model` pin. No existing duplicate was identified, so this stays open for triage.

## Change summary

A custom agent's frontmatter `model` (and `reasoning-effort`) pin is overridden by the model selected in the chat or Agents window picker.

## Best solution

When a custom agent with a `model` pin is selected in an agent host session, apply the pinned model (the first available entry of an array) and reasoning effort instead of the picker's model. Fall back to the picker only when no pin is set or none of the listed models is available.
