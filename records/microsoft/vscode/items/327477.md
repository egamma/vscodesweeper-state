# Issue #327477 — Agent mode needs BYOK/provider parity with Chat mode.

[https://github.com/microsoft/vscode/issues/327477](https://github.com/microsoft/vscode/issues/327477)

## Summary

BYOK models already work in agent mode when they declare tool-calling capability, but the specific asks — per-task model routing and budget/token-cost caps — are new feature requests not yet implemented. Keeping open as a valid feature request in the BYOK area.

## Change summary

Request for full BYOK/custom-provider parity in Agent mode, including per-task model routing and token/cost budget controls.

## Best solution

The core BYOK-in-agent-mode bridge already exists (AgentHostByokLmHandler, chatModelSelectionLogic filtering). The remaining gap is per-task model routing and budget/cost caps, which are genuine new features. This belongs in the model-byok area for the team to evaluate — the budget-controls ask in particular would be a new product surface. If the reporter's actual blocker is that their BYOK model doesn't appear in agent mode, that may be a configuration or capability-declaration issue worth clarifying via info-needed.
