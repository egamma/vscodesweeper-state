# Issue #324548 — [Error] unhandlederror-cannot add a decoration for a command {} with no marker

[https://github.com/microsoft/vscode/issues/324548](https://github.com/microsoft/vscode/issues/324548)

## Summary

Real regression in 1.127.0 affecting 1,436 users: `_flushPendingHandleCommandStartTask` fires `onCommandStartedEmitter` with a potentially undefined `commandStartMarker`, which reaches `registerCommandDecoration` and throws. An open PR already targets this fix.

## Change summary

Terminal throws an unhandled error when a command-start decoration is registered for a command whose start marker is undefined.

## Best solution

Land PR https://github.com/microsoft/vscode/pull/324557, which guards the `onCommandStarted` fire against an undefined `commandStartMarker`. The fix is small and localized to the command-detection capability layer.
