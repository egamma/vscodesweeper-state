## Summary

Valid bug: the BYOK Responses API path does not forward streamed tool-call argument deltas to the apply_patch pending-invocation UI, making patch generation appear buffered. An open community PR (https://github.com/microsoft/vscode/pull/321260) addresses this; the issue should stay open until the PR is reviewed and merged.

## Change summary

BYOK Responses API streams apply_patch argument deltas but the tool UI does not update incrementally — it only renders at the final output_item.done event.
