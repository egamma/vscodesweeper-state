## Summary

Multiple users confirmed truncated package downloads from packages.microsoft.com across Debian and Ubuntu-family systems. One commenter later reported spontaneous recovery, but there is no verified fix or matching canonical issue to justify closing this confirmed distribution failure.

## Change summary

APT upgrades fail because downloads of the VS Code Debian package terminate before the complete archive arrives.
