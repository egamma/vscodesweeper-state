# Issue #339700 — allowedDomains empty allows access to all pages

[https://github.com/microsoft/vscode/issues/339700](https://github.com/microsoft/vscode/issues/339700)

## Summary

This is a sandbox/network-escape concern (whether an empty allowedDomains list means 'deny all' or 'allow all' for the integrated browser), so per policy it stays open for a human rather than being closed on a code read alone, even though the current code/docs suggest the behavior is intentional.

## Change summary

Reporter observes that with `chat.agent.sandbox.network.allowedDomains` set to an empty array (and `allowNetwork: true`), the integrated browser can still reach arbitrary domains, and the semantics of an empty list are unclear (deny-all vs allow-all).

## Best solution

A maintainer should confirm whether the current semantics (empty allow list + sandboxEnabled + allowNetwork=true → no sandbox restriction added, i.e. effectively allow-all except deniedDomains) are the intended security posture, and if so, make the setting description/UI clearer that an empty list does not restrict network access; if the intent was 'deny all by default', src/vs/platform/networkFilter/common/networkFilterService.ts:126 needs to change.
