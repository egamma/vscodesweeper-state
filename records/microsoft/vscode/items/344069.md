# Issue #344069 — Claude agent (Agent SDK harness): thinking blocks always empty because `claudeSdkOptions.ts` never sets `thinking.display`

[https://github.com/microsoft/vscode/issues/344069](https://github.com/microsoft/vscode/issues/344069)

## Summary

The Claude Agent SDK startup path still omits thinking.display on current main, leaving supported models at the documented default that returns empty thinking text. Keep this open for a bounded harness fix; the separate Copilot Messages API implementation does not cover this path.

## Change summary

Restore summarized reasoning content for supported Claude models running through the Agent SDK harness.

## Best solution

Claude SDK sessions should receive summarized thinking on providers that support it, consistently across initial startup and rematerialization, without changing reasoning effort or forcing unsupported thinking modes on other models. A new user-facing setting is optional follow-up scope, not necessary to restore the reported behavior.
