# Issue #143435 — Line numbers in the Problems windows not easy to read when it comes to cells

[https://github.com/microsoft/vscode/issues/143435](https://github.com/microsoft/vscode/issues/143435)

## Summary

Still valid: the Problems panel shows notebook diagnostics with line/column numbers relative to individual cells but provides no cell identification (e.g. "Cell 3"), making it hard to locate which cell a problem belongs to. No fix or addressing commit found on main.

## Change summary

Notebook diagnostics in the Problems panel should identify which cell they belong to, not just show line/column numbers.

## Best solution

Add cell identification (e.g. "Cell N" or a cell content snippet) as a grouping or label in the Problems panel's markers tree when displaying notebook diagnostics. The rendering logic lives in `src/vs/workbench/contrib/markers/browser/markersTreeViewer.ts` (around line 180 for resource labels and line 411 for position display), and would need to detect `CellUri`-scheme resources and inject cell context.
