# Issue #339599 — Font

[https://github.com/microsoft/vscode/issues/339599](https://github.com/microsoft/vscode/issues/339599)

## Summary

Keep this in the existing Backlog Candidates community review: Windows still defaults to Consolas, and choosing Cascadia Mono manually does not satisfy the request to change the default. The related duplicate was already consolidated into this issue; no verified older open issue owns the same request.

## Change summary

Use Cascadia Mono as the default editor font to improve distinction between lowercase l and the digit 1.

## Best solution

Let the community review establish demand for reconsidering the Windows editor font default, with an explicit decision about font availability and fallback behavior before implementation. In the meantime, users with Cascadia Mono installed can select it through editor.fontFamily without changing the product default.
