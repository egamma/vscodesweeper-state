# Issue #200270 — Do not autoplay videos in release notes

[https://github.com/microsoft/vscode/issues/200270](https://github.com/microsoft/vscode/issues/200270)

## Summary

Valid feature request with 35 upvotes (well above the 20-vote backlog threshold), team acknowledgment, and an open community PR. The autoplay behavior remains unchanged on current main — the release notes renderer does not strip autoplay/loop attributes from fetched content. This stays open as an accepted backlog item.

## Change summary

Videos in VS Code's release notes auto-play and loop when the page opens, making it difficult to read the notes at one's own pace.

## Best solution

Either strip `autoplay` and `loop` attributes from `<video>` elements in `renderReleaseNotesMarkdown` (src/vs/workbench/contrib/update/browser/releaseNotesEditor.ts) via the sanitizer config, or coordinate with the vscode-docs repo to remove them from the source markdown. The reporter's open PR (https://github.com/microsoft/vscode-docs/pull/9931) addresses the docs side. Also consider respecting `prefers-reduced-motion` as connor4312 suggested.
