# Issue #179031 — Git - File status shows "Deleted" even after file is restored

[https://github.com/microsoft/vscode/issues/179031](https://github.com/microsoft/vscode/issues/179031)

## Summary

The deleted-file editor title is still constructed as a static label, and restoring the file does not update that editor. Keep this open while the existing fix PR is reviewed; its open status rules out a completed close or competing agent implementation.

## Change summary

An editor opened from a deleted Git resource retains the '(Deleted)' title after Discard Changes restores the file.

## Best solution

Review and resolve https://github.com/microsoft/vscode/pull/181815 so restoring a deleted file leaves no misleading deletion status on its open editor, while preserving accurate labels for historical Git content.
