# Issue #341296 — The chat diff tool now only shows uncommited git changes.

[https://github.com/microsoft/vscode/issues/341296](https://github.com/microsoft/vscode/issues/341296)

## Summary

Thanks for the report. On 1.141.0 the changes summary above the chat input reportedly lists all uncommitted Git changes instead of only the files the agent edited, so keep/discard no longer works per session. A second user confirmed it. I couldn't tell from the checkout whether this is an intentional change or a regression, so this is routed to the chat area owners.

## Change summary

The changes summary above the chat input shows all uncommitted Git changes instead of only the changes Copilot made in the session.

## Best solution

Confirm whether the summary's source changed on purpose. If it did not, restore per-session scoping of the changes list so keep/discard applies only to the agent's edits. If it did, add a setting or toggle to scope the list to the session's changes.
