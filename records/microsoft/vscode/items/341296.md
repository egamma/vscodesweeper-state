# Issue #341296 — The chat diff tool now only shows uncommited git changes.

[https://github.com/microsoft/vscode/issues/341296](https://github.com/microsoft/vscode/issues/341296)

## Summary

Thanks for the report. The new Copilot harness (agent host) session appears to show working-tree changes instead of only the session's edits. The report is complete, but I could not confirm it without running the code. A workaround is in the thread: set chat.defaultToCopilotHarness and chat.editor.preferCopilotHarness to false, then pick Local.

## Change summary

After a recent update, the changes list above the chat input shows all uncommitted git changes instead of only the files the Copilot session edited, so keep/discard of the session's edits is lost.

## Best solution

Scope the agent-host session changes view to the session's own edits, or restore the per-session keep/undo list for the Copilot harness. This is likely in the agent-host session diff/changes code. A maintainer should decide whether this is a regression or intended.
