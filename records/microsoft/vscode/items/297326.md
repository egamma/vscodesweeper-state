# Issue #297326 — Integrated terminal: flag emoji overlaps following space cell ("🇬🇧 to" looks like "🇬🇧to")

[https://github.com/microsoft/vscode/issues/297326](https://github.com/microsoft/vscode/issues/297326)

## Summary

Valid rendering bug — flag emoji (regional indicator pairs) overflow their allocated terminal cells and visually consume the following space. The issue lives in xterm.js's glyph rendering/clipping, surfaced through VS Code's terminal. No fix found on main.

## Change summary

Flag emoji in the integrated terminal render wider than their cell allocation, visually hiding the following ASCII space.

## Best solution

The fix likely needs to happen in xterm.js's renderer (glyph clipping or width measurement for RI-pair grapheme clusters). VS Code's role is setting the unicode version and passing it through to xterm.js — the core rendering logic is upstream. Keep open under `terminal-rendering` for the terminal team to coordinate with xterm.js upstream.
