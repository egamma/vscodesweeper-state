[https://github.com/microsoft/vscode/issues/240296](https://github.com/microsoft/vscode/issues/240296)

## Summary

Keep open: current source still redraws only the main terminal on OS resume, not the separate sticky-scroll renderer. Sticky scroll has since gained layout fixes and become enabled by default, but neither establishes a fix for this report; the suspend/resume and hover-recovery steps suffice for a focused retest.

## Change summary

Terminal sticky scroll can render incorrectly after OS suspend and recover only when hovered.
