# Issue #348554 — Show the Always on Top state in main windows like in detached windows

[https://github.com/microsoft/vscode/issues/348554](https://github.com/microsoft/vscode/issues/348554)

## Summary

The requested state indicator remains missing: main windows support Always on Top, but the existing pin controls explicitly exclude them. Keep this open for consistent window-state feedback, including in the Agents window.

## Change summary

Show an Always on Top pin indicator and disable control in main and Agents windows, at least while the state is enabled.

## Best solution

Reuse the existing pinned-window affordance across main and Agents title bars so enabled Always on Top is visible and can be turned off, without changing independent per-window state.

## Evidence

- **Existing capability and remaining gap:** src/vs/workbench/electron-browser/actions/windowActions.ts:492-568 registers workbench.action.toggleWindowAlwaysOnTop for the active window, but EnableWindowAlwaysOnTopAction and DisableWindowAlwaysOnTopAction restrict LayoutControlMenu contributions to IsAuxiliaryWindowContext and return early for main windows. The command provides toggling, not the requested visible state.
- **Agents window:** src/vs/sessions/browser/layoutActions.ts:409-423 contributes a pin with toggled IsWindowAlwaysOnTopContext, but its visibility requires IsAuxiliaryWindowContext and excludes windows with layout modes. It does not cover the main Agents window.
- **Existing state infrastructure:** src/vs/workbench/electron-browser/parts/titlebar/titlebarPart.ts:90-99 already initializes and updates the per-window IsWindowAlwaysOnTopContext. src/vs/platform/menubar/electron-main/menubar.ts:604-614 supplies a checkbox in the macOS Window menu, which is not a persistent title-bar indicator or a Windows/Linux equivalent.
- **Referenced test plan:** https://github.com/microsoft/vscode/issues/348421 tests main-window toggling, macOS menu checkmarks, independent window states, and restoration. It is a test-plan item, not a canonical request owning this missing indicator.
- **Related candidate checked:** https://github.com/microsoft/vscode/issues/341245 is open but requests a public extension API for creating floating editors with window options. It does not own visibility of Always on Top state in main windows.
