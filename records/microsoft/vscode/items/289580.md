# Issue #289580 — Allow and stop reviewing result should be preserved as choice in dropdown

[https://github.com/microsoft/vscode/issues/289580](https://github.com/microsoft/vscode/issues/289580)

## Summary

The requested dropdown-choice persistence is still missing: skipping result review affects only the current invocation, and subsequent confirmations reconstruct their primary action independently. Keep this UX improvement open; the related confirmation-wording issue does not own the same work.

## Change summary

Remember the choice to allow a fetch without reviewing its result, while retaining approval of each requested URL.

## Best solution

Let subsequent fetch confirmations reuse the explicitly selected skip-review action without automatically approving their URLs. The persistence scope should be explicit and remain separate from broader tool auto-approval permissions.
