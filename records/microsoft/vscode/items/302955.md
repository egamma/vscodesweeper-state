## Summary

Fixed on main: commit d786cb0bcb1 directly addresses Copilot CLI delegation failures, shipped in 1.116.0. The fix corrects the delegation routing logic so requests without a CLI-specific session resource are properly handled as delegation-from-another-chat, rather than falling through and being cancelled.

## Change summary

Delegating to Copilot CLI always results in 'Copilot CLI delegation cancelled' because the delegation path was not correctly entered when the session resource wasn't a CLI resource.
