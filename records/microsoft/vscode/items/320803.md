# Issue #320803 — View panel shows "Render Whitespace" selection as verbose entries

[https://github.com/microsoft/vscode/issues/320803](https://github.com/microsoft/vscode/issues/320803)

## Summary

Still present on main: the Render Whitespace submenu actions define both a verbose `title` ("Set Render Whitespace to None") and a concise `shortTitle` ("None"), but the menubar renders the full `title` because the submenu rendering path does not pass `renderShortTitle: true`. A small fix in either the menubar or the action registrations would resolve this.

## Change summary

The View > Appearance > Render Whitespace submenu entries show verbose labels like "Set Render Whitespace to None" instead of concise labels like "None".

## Best solution

The simplest fix is to swap the `title` and `shortTitle` values in `src/vs/workbench/contrib/codeEditor/browser/toggleRenderWhitespace.ts` so the concise label is the `title` (shown in menus) and the verbose label is the `shortTitle` (or dropped). Alternatively, pass `renderShortTitle: true` when resolving submenu actions in the menubar, but that has broader impact and would need careful review of all submenus.
