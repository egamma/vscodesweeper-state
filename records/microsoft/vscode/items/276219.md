# Issue #276219 — "No staged changes (stage all?)" (Suggest Smart Commit) modal does not conform to Microsoft interface guidelines.

[https://github.com/microsoft/vscode/issues/276219](https://github.com/microsoft/vscode/issues/276219)

## Summary

Keep open: the Smart Commit prompt still uses ambiguous Yes/Always/Never buttons, and its setting description remains unchanged. Existing settings can bypass the prompt but do not address its clarity; no verified canonical owns this dialog improvement.

## Change summary

Make the no-staged-changes prompt explain its commit actions and persistent preferences explicitly, with clearer Suggest Smart Commit setting text.

## Best solution

Improve the built-in Git prompt and configuration descriptions so users can distinguish a one-time stage-and-commit action from persistent Smart Commit preferences. Settle whether to retain direct action buttons or separate preference selection before implementing the UI.
