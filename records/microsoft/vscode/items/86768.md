# Issue #86768 — Make css auto completion items overtype on semicolon

[https://github.com/microsoft/vscode/issues/86768](https://github.com/microsoft/vscode/issues/86768)

## Summary

A real gap remains on current main: semicolons inserted by CSS completion are not tracked as auto-closed characters and therefore cannot be overtyped. Keep this older report as the canonical request and classify it as under discussion.

## Change summary

Allow typing a semicolon to advance over the semicolon inserted by CSS property completion instead of producing two semicolons.

## Best solution

Extend the editor completion or snippet path to identify completion-inserted closing characters as overtypable without treating every existing semicolon as auto-closed. The design should be generic enough to cover the same completion behavior in other languages while preserving ordinary semicolon insertion.
