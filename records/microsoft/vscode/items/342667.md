# Issue #342667 — Prevent accidental loss of AI chats when using “Start Over”

[https://github.com/microsoft/vscode/issues/342667](https://github.com/microsoft/vscode/issues/342667)

## Summary

Keep open: existing Start Over confirmations protect file edits, not every non-empty conversation. The related archive and delete-confirmation requests do not own this specific safeguard.

## Change summary

Protect non-empty AI conversations from accidental Start Over activation with confirmation or discoverable recovery.

## Best solution

Make Start Over safe for conversations without file edits as well as editing sessions, using a consistent confirmation or clearly discoverable recovery affordance. Assess the existing checkpoint Redo behavior before describing the operation as irreversible.
