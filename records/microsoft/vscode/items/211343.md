# Issue #211343 — Add Title Menu Entry for Extensions

## Summary

Keep open: the request earned 22 upvotes and was promoted to the Backlog, while an open PR remains an active implementation candidate. Current main still lacks a public contribution target for extension commands in the main menubar.

## Change summary

Allow extensions to expose commands through a dedicated top-level Extensions menu or another main-menubar contribution point.

## Best solution

Review https://github.com/microsoft/vscode/pull/212056 and either land it after aligning the design with menu contribution conventions or close it with clear direction. Prefer an explicit, opt-in contribution model that keeps extension commands grouped and avoids automatically exposing every contributed command.
