# Issue #297501 — In High contrast themes and in screen reader mode, we should set `accessibility.chat.showCheckmarks:true` by default

[https://github.com/microsoft/vscode/issues/297501](https://github.com/microsoft/vscode/issues/297501)

## Summary

Keep open: current source still defaults accessibility.chat.showCheckmarks to false without adapting to high-contrast themes or screen-reader mode. The existing manual toggle does not satisfy this team-authored follow-up, and no verified canonical or linked open implementation PR was found.

## Change summary

Enable chat checkmarks by default for high-contrast themes and screen-reader mode.

## Best solution

Make the effective chat-checkmark default accessibility-aware across response rows and collapsible content parts, while preserving explicit user preferences and the existing default outside those accessibility contexts.

- **Fit:** aligned
- **Reason:** An accessibility-aware default makes chat progress easier to perceive without requiring users to discover and configure an accessibility setting.
