# Issue #290891 — Claude Agent does not get instructions files

[https://github.com/microsoft/vscode/issues/290891](https://github.com/microsoft/vscode/issues/290891)

## Summary

Active team discussion about whether the Claude agent host should receive VS Code's copilot instruction files. The latest comment (Apr 2026) explicitly reopened the question, saying instructions should probably be brought in with an opt-out mechanism. No implementation has landed yet — the Claude agent host code does not reference the prompt service or copilot-instructions files. Stays open as a live design question.

## Change summary

The Claude agent in VS Code does not receive copilot instruction files (`.github/copilot-instructions.md` etc.), unlike the built-in Copilot agent.

## Best solution

The team needs to decide on the integration approach: bring VS Code instruction files into the Claude agent's context (as was done for skills/plugins in PR #312082), with an opt-out mechanism so users can disable them if context bloat hurts quality. Implementation would likely touch `src/vs/platform/agentHost/node/claude/customizations/claudeSessionCustomizationDiscovery.ts` and related files.
