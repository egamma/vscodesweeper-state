# Issue #213520 — Git - VS Code Cannot Push to Git via SSH

[https://github.com/microsoft/vscode/issues/213520](https://github.com/microsoft/vscode/issues/213520)

## Summary

Multiple reporters confirmed that Remote - SSH reconnects leave VS Code processes with a stale SSH_AUTH_SOCK, breaking forwarded-agent authentication. This is owned by the VS Code team's Remote - SSH extension and should be moved to its tracker rather than closed as caused by an extension.

## Change summary

Refresh SSH_AUTH_SOCK after a Remote - SSH reconnect so terminals and Git use the newly forwarded SSH agent socket.

## Best solution

Move the issue to https://github.com/microsoft/vscode-remote-release and validate it against the fix tracked by https://github.com/microsoft/vscode-remote-release/issues/10274; if current Remote - SSH still reproduces the exact reconnect failure, handle it there as a regression.
