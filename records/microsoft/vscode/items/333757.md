# Issue #333757 — Customization hard to find if I don't know where it is

[https://github.com/microsoft/vscode/issues/333757](https://github.com/microsoft/vscode/issues/333757)

## Summary

Team-authored (dbaeumer) UX gap report on the new AI Customization editor: there is no global/cross-card search and the search term isn't preserved when switching cards. No fix references this issue on main, so it stays open per the team-authored keep-open rule.

## Change summary

The AI Customization management view lacks a global search across all customization sections, and per-card search text isn't carried over when navigating between cards.

## Best solution

Add a global search entry point in aiCustomizationManagement.ts (which already persists a per-section search query under AI_CUSTOMIZATION_MANAGEMENT_SEARCH_KEY) that searches across all customization types, and/or carry the current search string forward when the user switches cards.
