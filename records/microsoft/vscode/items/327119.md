# Issue #327119 — Nested repository is detected only if its file is open at startup, not when opened later

[https://github.com/microsoft/vscode/issues/327119](https://github.com/microsoft/vscode/issues/327119)

## Summary

The timing-dependent nested-repository detection defect is present on current main, and an open PR explicitly fixes this issue. Keep it open while that implementation is reviewed.

## Change summary

Detect a nested Git repository when one of its files becomes visible after startup, even when an ancestor repository is already registered.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/327122, which updates the visible-editor detection in `extensions/git/src/model.ts` and adds smoke-test coverage.
