## Summary

The current source still skips nested-repository discovery when an already-open ancestor matches the newly visible file. Route this to Git and keep it open while the linked implementation candidate is reviewed.

## Change summary

Opening a nested repository's file after startup should discover that repository consistently with opening the same file before startup.
