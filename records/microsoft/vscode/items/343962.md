# Issue #343962 — Agents Window new-session: Previous environment's repo choice isn't remembered

[https://github.com/microsoft/vscode/issues/343962](https://github.com/microsoft/vscode/issues/343962)

## Summary

Keep open: the current source loses the selected local repository when switching to an incompatible environment, and returning to This Computer does not restore it. This team-authored report identifies a concrete remaining gap, not grounds for a cleanup close.

## Change summary

Remember the previously selected project when switching away from an environment and returning to it.

## Best solution

The new-session composer should restore the prior environment's valid project selection on a round trip, while continuing to exclude incompatible workspaces from the destination environment. This belongs in the Sessions-owned environment and workspace selection flow, not the WSL extension.
