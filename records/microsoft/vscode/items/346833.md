# Issue #346833 — Agents window: "Open Agents Window" from an editor on a local folder selects Cloud instead of This Computer

[https://github.com/microsoft/vscode/issues/346833](https://github.com/microsoft/vscode/issues/346833)

## Summary

Keep open: the editor handoff can still pin Cloud before the local provider registers, bypassing the intended local-folder default. This is a distinct remaining path after the first-launch fixes, not grounds to close this team-authored report.

## Change summary

Opening the Agents window from an editor with a local folder should select This Computer and retain that folder.

## Best solution

Make local-folder editor handoff honor the default local environment despite delayed provider registration, without overriding subsequent user choices or changing explicit remote, container, and draft destinations.
