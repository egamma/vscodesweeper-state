# Issue #199466 — Aux window terminals have messed up cursor blinking

[https://github.com/microsoft/vscode/issues/199466](https://github.com/microsoft/vscode/issues/199466)

## Summary

Intermittent cursor blink issue in aux windows — filed by the terminal maintainer, last seen sporadically in March 2024 with no consistent repro. No fixing commit found on main. Keeping open as a known intermittent issue the team is aware of.

## Change summary

Terminal cursor blinking is visually incorrect (possibly double-blinking or irregular) when a terminal is in an auxiliary window.

## Best solution

The terminal maintainer should investigate whether remaining `getActiveWindow` usage in terminal timer code can cause timer scheduling on the wrong window, leading to cursor blink irregularities. The fix in PR #199568 addressed some cases but this may still occur intermittently.
