## Evidence

- **Icon association path:** src/vs/editor/common/services/getIconClasses.ts derives extension classes from segments after the first dot, so ml.md receives md-ext-file-icon rather than ml-ext-file-icon. This is a strong diagnostic lead, but the ml.md report does not establish the same layout condition.
- **Relevant landed layout changes:** Merged https://github.com/microsoft/vscode/pull/340635 removes the earlier shortened-name width comparison and changes short fit-tab icon handling. Current src/vs/workbench/browser/parts/editor/multiEditorTabsControl.ts contains newer fit-width measurement logic. These changes could address the report, but no execution or exact ml.md reproduction established that they do.
