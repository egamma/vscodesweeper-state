[https://github.com/microsoft/vscode/issues/245078](https://github.com/microsoft/vscode/issues/245078)

## Summary

As-designed: the `closeFolder` command has a precondition requiring a workspace/folder to be open (`WorkbenchStateContext != 'empty'`). The reporter's reproduction steps explicitly open VS Code without any folder — so the command correctly does nothing because there is nothing to close.

## Change summary

The default `Ctrl+K F` keybinding for Close Workspace does not fire when no workspace or folder is open.

## Best solution

Close as as-designed. The `workbench.action.closeFolder` command intentionally requires an open workspace/folder via its precondition. Pressing `Ctrl+K F` in an empty window is expected to do nothing.
