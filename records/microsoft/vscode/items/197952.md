## Summary

Acknowledged bug with no fix on main — the Python kernel strips leading blank lines from cells, causing error tracebacks to show mismatched line numbers. A team member confirmed the root cause and noted the fix needs care.

## Change summary

Error messages in Jupyter notebook cells show incorrect line numbers when the cell starts with blank lines, because the Python kernel strips them before execution.

## Best solution

Add post-processing in the notebook output rendering (likely in `src/vs/workbench/contrib/notebook/browser/view/cellParts/cellOutput.ts` or the error output renderer) to adjust traceback line numbers by the count of stripped leading blank lines, with care not to over-correct for non-Python kernels or multi-cell tracebacks.
