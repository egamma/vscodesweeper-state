## Change summary

An already-open notebook output text editor switches from plain text to serialized output JSON after rerunning a cell that prints a large text blob.

## Best solution

Keep the existing text-editor view useful across reruns of the same cell, displaying the replacement stream as plain text rather than output metadata. Reproduce the large-output execution sequence first, then address output identity continuity in the notebook content-provider path without changing intentional raw-JSON views.
