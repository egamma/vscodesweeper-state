# Issue #273107 — PHP language scope in embedded PHP code is incorrectly exited after the first quotation mark

[https://github.com/microsoft/vscode/issues/273107](https://github.com/microsoft/vscode/issues/273107)

## Summary

Real grammar bug — still present on main. The PHP TextMate grammar (upstream: KapitanOczywisty/language-php) does not correctly scope PHP blocks inside HTML attribute strings when the PHP code contains the same quote character used by the HTML attribute delimiter. A team member (alexr00) already triaged this by closing a duplicate (#279756) against it. Keeping open as the canonical issue.

## Change summary

PHP syntax highlighting breaks when embedded PHP code inside an HTML attribute (e.g. `onclick="..."`) contains double quotes, because the grammar exits the PHP scope at the first inner double quote.

## Best solution

Fix the injection selector or the PHP-tag pattern in `extensions/php/syntaxes/html.tmLanguage.json` (upstream: KapitanOczywisty/language-php) so that `<?php ... ?>` blocks inside HTML attribute strings take precedence over the attribute string delimiter. Ideally file/coordinate with the upstream grammar repo at https://github.com/KapitanOczywisty/language-php and pull the fix back.
