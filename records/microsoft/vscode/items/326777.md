# Issue #326777 — Browser inspector

[https://github.com/microsoft/vscode/issues/326777](https://github.com/microsoft/vscode/issues/326777)

## Summary

Valid feature request to embed Chrome DevTools inside VS Code's sidebar rather than opening a separate window. The integrated browser already exists with DevTools support, but it currently delegates to Electron's native `toggleDevTools()` which opens a detached window. No duplicate found — letting the community process run its course.

## Change summary

Embed Chrome DevTools (browser inspector) within VS Code's primary or secondary sidebar instead of opening it as a separate window.

## Best solution

The integrated browser's DevTools feature (in `src/vs/workbench/contrib/browserView/electron-browser/features/browserDevToolsFeature.ts` and `src/vs/platform/browserView/electron-main/browserView.ts`) currently uses Electron's `webContents.toggleDevTools()`. Embedding DevTools inline would require significant Electron-level work (e.g. `openDevTools({ mode: 'detach' })` into a BrowserView rendered in a VS Code panel). This is a reasonable but non-trivial enhancement to the integrated browser — leave it for the backlog candidate community vote process.
