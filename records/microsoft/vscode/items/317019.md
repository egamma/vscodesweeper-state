Duplicate close gated off (the cited canonical #189858 is already closed — a duplicate close would strand the report; if the canonical's fix landed, an implemented-on-main close citing the fix commit is the right shape). Original assessment: This is a duplicate of #189858, which requested the same click-and-drag-anywhere behavior on the minimap. ## Change summary

Allow click-and-drag anywhere on the minimap to initiate slider dragging, matching scrollbar behavior.

## Best solution

This was already discussed and declined via the community process in #189858. The current code already supports click-to-drag outside the slider for non-proportional minimap sizes (lines 1250-1258 of minimap.ts), but proportional mode intentionally reveals the clicked line instead. If this gains traction again, it should be tracked on a fresh request with community upvotes.
