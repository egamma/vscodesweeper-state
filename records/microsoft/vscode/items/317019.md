# Issue #317019 — Minimap improvement - click & drag anywhere

[https://github.com/microsoft/vscode/issues/317019](https://github.com/microsoft/vscode/issues/317019)

## Summary

The different drag behavior is intentional for proportional minimaps: unlike a scrollbar, the minimap content itself can scroll, so the pointer location does not reliably represent the slider position. The same request was previously declined as designed with an explicit maintainer explanation.

## Change summary

Allow a minimap drag to begin from any point, rather than requiring the initial pointer-down to land on its viewport slider.

## Best solution

Keep proportional minimap clicks mapped to the represented source line and reserve direct dragging for its slider. Users who prefer scrollbar-like drag-anywhere behavior can use `editor.minimap.size` set to `fit` or `fill`, where the minimap does not scroll independently.

  > Thanks for the request. This interaction is intentional in proportional mode because the minimap content can scroll independently, so the clicked line and slider position do not share scrollbar geometry; the design and tradeoff are documented in https://github.com/microsoft/vscode/issues/21708. For scrollbar-like drag-anywhere behavior, `editor.minimap.size` can be set to `fit` or `fill`, where the minimap itself does not scroll.

## Evidence

- **current source:** src/vs/editor/browser/viewParts/minimap/minimap.ts:1240-1280 preserves this distinction: proportional-mode pointer-down reveals the represented line, while `_startSliderDragging` is entered directly from the slider's pointer-down listener.
- **existing alternative:** The same pointer-down handler starts slider dragging from anywhere when minimap size is not `proportional`; `editor.minimap.size` exposes the non-scrolling `fit` and `fill` modes in src/vs/editor/common/config/editorOptions.ts:3474-3520.
- **prior clarification:** https://github.com/microsoft/vscode/issues/21915 describes the same click-then-drag expectation and was closed after the maintainer linked the by-design geometry explanation.
