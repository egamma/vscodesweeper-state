# Issue #324049 — Allow Repository inheritence of MCP Servers like Skills

[https://github.com/microsoft/vscode/issues/324049](https://github.com/microsoft/vscode/issues/324049)

## Summary

Keep open: current discovery supports workspace-root .mcp.json files, but does not provide the requested repository-bounded ancestor discovery. Related multi-root work does not cover inheritance from folders outside the workspace roots.

## Change summary

Discover and combine MCP server configurations from workspace folders, the workspace-file directory, and their ancestors up to repository boundaries.

## Best solution

Define opt-in repository-bounded MCP inheritance in the existing discovery system, including configuration precedence and multi-root behavior. Preserve existing workspace configuration and trust semantics rather than treating workspace-root .mcp.json support as completion of this request.
