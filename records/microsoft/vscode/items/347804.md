# Issue #347804 — Agent Host: let extensions archive sessions and map host sessions to SDK sessions without a model turn

[https://github.com/microsoft/vscode/issues/347804](https://github.com/microsoft/vscode/issues/347804)

## Summary

Keep open as an extension-API feature request: existing host archive operations and internal SDK mappings do not establish a supported interface for Copilot CLI extensions. The related self-archive request does not cover this broader automation contract.

## Change summary

Expose reliable host/chat-to-SDK identity and deterministic archive/unarchive operations to Copilot CLI extensions without requiring a model turn.

## Best solution

Define a supported, scoped extension contract for session identity and archive mutations, preserving host lifecycle validation and explicit default-chat ownership. Document provisional/prewarmed backing lifetimes rather than treating private database records or logs as an API.
