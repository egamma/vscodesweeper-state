[https://github.com/microsoft/vscode/issues/299201](https://github.com/microsoft/vscode/issues/299201)

## Summary

The current source still permits recursive Copilot CLI launches when PATH contains a symlinked spelling of the shim directory. The newer matching report confirms substantial resource exhaustion, but cannot be the duplicate canonical for this older, previously reviewed issue.

## Change summary

Prevent the Copilot CLI bootstrapper from finding and recursively launching itself through a symlinked PATH entry.

## Best solution

Ensure CLI discovery excludes the bootstrapper regardless of directory spelling while preserving discovery of a real installed CLI and the missing-CLI installation prompt. Coordinate with the maintainer's planned native-shim replacement, but keep this report open until the affected path is actually fixed.
