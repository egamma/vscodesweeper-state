# Issue #299201 — `copilot` calls itself recursively due to bug in `$PATH` normalization

[https://github.com/microsoft/vscode/issues/299201](https://github.com/microsoft/vscode/issues/299201)

## Summary

Confirmed bug on current main: the Copilot CLI shim's PATH self-removal uses naive string replacement that fails when symlinks cause `__dirname` and PATH entries to differ, leading to infinite recursion.

## Change summary

The `copilotCLIShim.ts` PATH normalization doesn't resolve symlinks, so when `__dirname` and the PATH entry differ due to symlinks, the shim fails to remove itself from PATH and recurses infinitely.

## Best solution

Resolve `__dirname` through `fs.realpathSync` (and optionally resolve each PATH entry) before the `replaceAll` comparison in `copilotCLIShim.ts` line 34, so symlink-aliased paths are correctly matched and removed.
