## Plan brief

- **Likely files:** `src/vs/workbench/contrib/terminal/browser/terminalProcessManager.ts`, `src/vs/platform/terminal/node/terminalProcess.ts`
- **Validation:** On an affected macOS Zephyr setup, run the linked west build command twice consecutively in the same integrated terminal without restarting VS Code. Compare with an external terminal using the same working directory, toolchain, and environment, then repeat with shell integration disabled. The eventual regression check must demonstrate that both integrated-terminal builds finish successfully.
- **Behavior:**

  > Affected users report that a Zephyr build succeeds once after starting VS Code, while subsequent builds stop during CMake toolchain detection after the Found GnuLd output. The same command completes in an external terminal, and one commenter confirmed the failure without extensions. The intended outcome is reliable repeated builds without restarting VS Code. First establish this behavior on a current build and distinguish a blocked child process from stalled terminal output.
- **Trace:**

  > TerminalProcessManager._resolveEnvironment and _launchLocalProcess in src/vs/workbench/contrib/terminal/browser/terminalProcessManager.ts assemble the environment and shell-integration options passed to the terminal backend. TerminalProcess.start and setupPtyProcess in src/vs/platform/terminal/node/terminalProcess.ts apply shell integration and launch the shell through node-pty. Source inspection establishes those boundaries but does not identify a faulty branch explaining repeated CMake builds. https://github.com/zephyrproject-rtos/zephyr/issues/72963 contains the command, logs, environment details, independent confirmations, and suggested CMake tracing. A missing Python library affecting gdb-py is a reported workaround for one case, not an established common root cause. Preserve existing terminal and Python-environment behavior until matched-environment comparisons and the blocked process trace identify responsibility; no open fixing PR was supplied.
