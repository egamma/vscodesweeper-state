# Issue #334169 — Claude agent host harness ignores ANTHROPIC_BASE_URL / ANTHROPIC_AUTH_TOKEN (cc-switch and other Anthropic-compatible relays)

[https://github.com/microsoft/vscode/issues/334169](https://github.com/microsoft/vscode/issues/334169)

## Summary

Keep open to establish end-to-end compatibility for relay-only Claude configurations. Current source already preserves these environment variables in native mode, but that does not establish that settings-file discovery, account eligibility, and model selection work for the reported configuration.

## Change summary

Support Anthropic-compatible relays configured through ANTHROPIC_BASE_URL and ANTHROPIC_AUTH_TOKEN in the process environment or ~/.claude/settings.json, without requiring GitHub authentication.

## Best solution

Make a supported relay-only configuration discoverable and usable through the native Claude model path, while preserving intentional Copilot routing for Copilot-selected models. First establish whether the remaining failure occurs during SDK account discovery, model publication, or request startup; the existing environment forwarding alone is not sufficient evidence of resolution.
