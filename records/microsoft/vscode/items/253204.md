# Issue #253204 — VSCode instances started through "Relaunch VS Code" button are started with PR_SET_NO_NEW_PRIVS

[https://github.com/microsoft/vscode/issues/253204](https://github.com/microsoft/vscode/issues/253204)

## Summary

Valid Linux-specific bug where Electron's app.relaunch() inherits PR_SET_NO_NEW_PRIVS, breaking sudo in the terminal. An open PR (#296711) by a team member proposes a fix using spawn instead of Electron.relaunch; it hasn't merged yet.

## Change summary

VS Code instances relaunched via the 'Relaunch VS Code' button inherit PR_SET_NO_NEW_PRIVS, preventing sudo from working in the integrated terminal.

## Best solution

Land the open PR https://github.com/microsoft/vscode/pull/296711 which replaces Electron's app.relaunch() with a spawn-based approach to avoid inheriting the no-new-privs flag in the child process.
