# Issue #260556 — Configure tools... action should respect the tools I configured in my markdown file

[https://github.com/microsoft/vscode/issues/260556](https://github.com/microsoft/vscode/issues/260556)

## Summary

The bug remains necessary on current main: accepting Configure Tools without changing the selection can rewrite the frontmatter because the picker serializes its current tool ordering rather than preserving the document's configured order.

## Change summary

Configure Tools should leave prompt-file frontmatter unchanged when the user confirms without changing the configured tool selection.

## Best solution

Preserve the existing tools representation when the effective selection is unchanged, while continuing to update frontmatter when tools are actually added or removed.
