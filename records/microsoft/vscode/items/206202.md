# Issue #206202 — Fontconfig charset edit does not apply in vscode

[https://github.com/microsoft/vscode/issues/206202](https://github.com/microsoft/vscode/issues/206202)

## Summary

Correctly triaged as upstream — fontconfig charset edits are ignored by Chromium's font-matching stack, which Electron inherits. The reporter confirmed the same behavior in Chrome/Firefox, and a team member directed them to Chromium Issues.

## Change summary

Fontconfig charset manipulation (removing code points to delegate to a fallback font) is not honored in VS Code's integrated terminal because Chromium's font subsystem bypasses that fontconfig feature.

## Best solution

This lives in Chromium's font-matching layer (Skia/fontconfig integration). The fix would need to land upstream in Chromium, then flow through Electron to VS Code. The related issue https://github.com/microsoft/vscode/issues/319988 tracks broader Linux font-rendering concerns with newer Electron. Keep open as a known upstream limitation.
