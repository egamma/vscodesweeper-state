# Issue #252000 — Working progress in ask mode

[https://github.com/microsoft/vscode/issues/252000](https://github.com/microsoft/vscode/issues/252000)

## Summary

Still present on main: Ask mode shows a 'Working' label in the response header area that disappears on completion, causing content to jump. The code explicitly opts Ask mode out of the bottom-of-response working progress used in Agent mode. No fix commits reference this issue.

## Change summary

In Ask mode, the 'Working' progress message appears at the top of the response and disappears when streaming completes, causing a visible content jump.

## Best solution

Unify the working progress behavior so Ask mode uses the same bottom-of-response progress indicator as Agent mode (or reserves the header space to prevent the jump). The key decision point is the `progressMessageAtBottomOfResponse: mode => mode !== ChatModeKind.Ask` option in chatViewPane.ts and chatEditor.ts, and the fallback 'Working' text in chatListRenderer.ts line 1120–1121.
