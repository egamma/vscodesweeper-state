# Issue #349051 — Let administrators allow extensions' tools and MCP servers while general MCP access is disabled

[https://github.com/microsoft/vscode/issues/349051](https://github.com/microsoft/vscode/issues/349051)

## Summary

The requested administrator-controlled exception remains missing: current policy blocks extension tools categorically, and existing MCP allowlists do not override MCP disablement. Keep this open as a feature request; the introducing PR implements the restriction, not this exception.

## Change summary

## Best solution

Settle the policy contract and runtime/workbench enforcement boundary before implementation.
