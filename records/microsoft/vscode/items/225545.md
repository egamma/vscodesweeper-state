# Issue #225545 — [html] Relative links don't work with <base> element 

[https://github.com/microsoft/vscode/issues/225545](https://github.com/microsoft/vscode/issues/225545)

## Summary

The bug remains source-reproducible on current main: resolving a directory-valued `<base href>` removes its trailing slash, so subsequent relative links are resolved from the parent directory.

## Change summary

HTML document links should resolve relative paths against the directory specified by the document's `<base href>` element.

## Best solution

Preserve directory semantics while resolving an HTML `<base href>`, including parent-directory forms, so Ctrl+Click targets the same resource a browser loads.
