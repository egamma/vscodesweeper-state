# Issue #298050 — Copilot extension chat history is suddenly mixed up with Codex extension chat history

[https://github.com/microsoft/vscode/issues/298050](https://github.com/microsoft/vscode/issues/298050)

## Summary

The shared Chat Sessions history intentionally aggregates sessions contributed by multiple providers, including Codex. Separating that history by extension would change the intended cross-provider session experience, so this can be closed as designed.

## Change summary

Show only Copilot conversations in the Copilot chat history and keep Codex conversations exclusively in Codex UI.

## Best solution

Keep the unified Chat Sessions surface and its provider filters, while continuing to distinguish ordinary local Copilot history from contributed sessions and routing each selected session through its registered provider.

## Vision fit

- **Fit:** rejected
- **Reason:** A separate history surface for every chat provider conflicts with the project's preference for simple, uniform UI interactions and CLI/UI coexistence.
- **Evidence:** Values and guardrails: "Simple, uniform UI and UI interactions" and "Allow for CLI / UI co-existence and interplay whenever possible."
