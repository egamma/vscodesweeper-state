# Issue #125774 — Allow partial string replacement in package.json/package.nls.json, to ease translations of strings containing markdown

[https://github.com/microsoft/vscode/issues/125774](https://github.com/microsoft/vscode/issues/125774)

## Summary

Keep open: manifest localization still supports only whole-string replacement, and maintainers have explicitly supported improving placeholder handling. Related reports were consolidated into this issue; OneLoc locking is a partial workaround, not a portable solution.

## Change summary

Allow extension manifest translations to preserve Markdown syntax and nontranslated literals while keeping complete sentences and link labels localizable.

## Best solution

Provide a documented, translation-provider-independent manifest localization contract that preserves sentence context and supports brace placeholders, consistent with the maintainer's direction. Settle how authors supply literal arguments and localized link labels before implementing runtime and authoring support.
