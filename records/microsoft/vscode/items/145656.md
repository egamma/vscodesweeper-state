# Issue #145656 — File name seems to be lost when navigating directories

[https://github.com/microsoft/vscode/issues/145656](https://github.com/microsoft/vscode/issues/145656)

## Summary

Keep open: the simple save dialog remembers the filename internally, but selecting a child directory still replaces the displayed filename with the directory completion. The requested filename-visible navigation remains missing, and no verified canonical or issue-referencing fix supports closing this team-authored Backlog request.

## Change summary

Keep the proposed save filename visible while navigating directories, highlighting only the directory segment being selected.

## Best solution

Make directory navigation in SimpleFileDialog show the destination together with the remembered save filename, consistently for parent and child directories. Preserve the existing filename-retention behavior rather than treating this as a request to implement retention from scratch.
