# Issue #145656 — File name seems to be lost when navigating directories

[https://github.com/microsoft/vscode/issues/145656](https://github.com/microsoft/vscode/issues/145656)

## Summary

The requested behavior — preserving the filename when navigating into subdirectories in the simple file dialog — still appears unimplemented on main. The `onDidAccept` path for downward folder navigation (line 609 of simpleFileDialog.ts) calls `updateItems(item.uri, true)` without passing a trailing filename, while the `..` path does preserve it. Keeping open as a valid feature request.

## Change summary

When navigating into a subdirectory in the simple file dialog (save dialog), the entered filename is dropped; navigating upward with `..` preserves it.

## Best solution

Update the downward-navigation path in `SimpleFileDialog.onDidAccept()` (src/vs/workbench/services/dialogs/browser/simpleFileDialog.ts, around line 609) to pass `this.trailing` to `updateItems` — mirroring the behavior already in place for the trailing-preserving path at line 597 — so the filename is carried through when entering a subdirectory.
