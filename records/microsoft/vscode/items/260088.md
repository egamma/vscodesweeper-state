# Issue #260088 — [169] potential listener LEAK detected, having 183 listeners already. MOST frequent listener (8):

[https://github.com/microsoft/vscode/issues/260088](https://github.com/microsoft/vscode/issues/260088)

## Summary

The leak warning is a false positive caused by legitimate notebook usage (8+ cell outputs each subscribing to a menu's onDidChange). The code is architecturally sound (toolbarDisposables properly managed), but the listener count legitimately exceeds the global threshold. Still open — either raise the threshold for this emitter or restructure to share a single menu subscription.

## Change summary

Notebook cell outputs trigger a spurious listener leak warning when 8+ outputs each subscribe to their own menu's onDidChange event.

## Best solution

Either set a higher `leakWarningThreshold` on the DebounceEmitter in menuService.ts line ~443 for the menu's onDidChange, or restructure CellOutputElement to share a single menu subscription across outputs in the same cell container, reducing listener count below the threshold.
