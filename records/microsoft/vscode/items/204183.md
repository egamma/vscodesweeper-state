# Issue #204183 — Add cursor below and above don't work in readonly files

[https://github.com/microsoft/vscode/issues/204183](https://github.com/microsoft/vscode/issues/204183)

## Summary

The reported inconsistency remains in current main: both vertical cursor actions return immediately in read-only editors, while occurrence-based multiselection remains available. Keep this accepted editor-core bug open; the cause is bounded and supports an agent implementation session.

## Change summary

Allow Add Cursor Above and Add Cursor Below to create additional selections in read-only files without permitting text edits.

## Best solution

Make vertical cursor selection available in read-only editors consistently with occurrence-based multiselection, while retaining existing protections against editing and preserving writable-editor behavior.
