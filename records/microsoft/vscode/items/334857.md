# Issue #334857 — Feature request: Group custom agents by discovery source

[https://github.com/microsoft/vscode/issues/334857](https://github.com/microsoft/vscode/issues/334857)

## Summary

This is a valid AI-customizations UX request spanning both the Agent picker and Customizations editor. The picker portion overlaps an older open issue, but that picker-only issue does not fully own the additional management-view requirement, so this should remain open and be routed to the AI customizations area.

## Change summary

Group custom agents by discovery source and organization across the Agent picker and Customizations editor while preserving search, actions, and accessibility.

## Best solution

Use a consistent source hierarchy across both surfaces, building on the Customizations editor's existing collapsible source groups and extending the picker beyond its current Built-In/Custom split. Coordinate the picker work with https://github.com/microsoft/vscode/issues/334856 while retaining this issue for the management-view and cross-surface consistency requirements.
