# Issue #199998 — Entering Markdown Preview doesn't retain Alt key state for editor buttons

[https://github.com/microsoft/vscode/issues/199998](https://github.com/microsoft/vscode/issues/199998)

## Summary

Still open on main — an open PR (https://github.com/microsoft/vscode/pull/327497) directly addresses this with a fix to ModifierKeyEmitter's blur handling, but it hasn't merged yet. Keeping open pending PR review/landing.

## Change summary

Holding Alt and clicking the markdown preview toggle button loses the Alt modifier state because ModifierKeyEmitter resets on window blur when focus enters the webview iframe.

## Best solution

Land https://github.com/microsoft/vscode/pull/327497 after review — it defers the modifier reset on blur and checks `document.hasFocus()` so iframe focus transitions don't clear the state. The fix is small and localized to `src/vs/base/browser/dom.ts`.
