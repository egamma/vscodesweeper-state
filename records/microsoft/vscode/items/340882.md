# Issue #340882 — Extension API: conditional WorkspaceConfiguration.update (write only if the value still equals an expected value)

[https://github.com/microsoft/vscode/issues/340882](https://github.com/microsoft/vscode/issues/340882)

## Summary

Keep open: the current extension API has no conditional configuration update, and the write queue does not protect a value previously displayed by an extension. The issue is already correctly routed to api/config; no verified canonical issue or landed implementation was found.

## Change summary

Allow extensions to update a configuration target conditionally, preserving newer values and reporting a conflict when the precondition fails.

## Best solution

Have the configuration API owners evaluate an optional conditional-write contract that checks the selected target at write application time without changing existing unconditional updates. Define its concurrency guarantees across settings-file edits, windows, and Settings Sync before accepting an API shape.
