# Issue #329495 — Clicking on / hovering this issues pill in an agent session flickers the hovers states

[https://github.com/microsoft/vscode/issues/329495](https://github.com/microsoft/vscode/issues/329495)

## Summary

Fresh team-authored report of hover flicker/duplicate popups on the GitHub-issue pill in an agent session; the code shows a plausible mechanism (a managed hover plus a separately-triggered instant sticky hover on the same pill) but no fix exists yet, so this stays open for investigation.

## Change summary

Hovering/clicking the referenced-issues pill in an agent session header causes the hover state to flicker, and it appears two hover popups can compete.

## Best solution

Investigate OpenIssueActionViewItem in src/vs/sessions/contrib/github/browser/issueActions.ts: it exposes a standard managed hover (getHoverContents/getTooltip via the base action-view-item hover machinery) and, for the multi-issue case, also opens a separate sticky IHoverService.showInstantHover picker on click — the interaction between these two hover paths is the likely source of the flicker; reconcile so only one hover surface is active at a time.
