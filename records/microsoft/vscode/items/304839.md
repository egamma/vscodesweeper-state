# Issue #304839 — Agent file problems

[https://github.com/microsoft/vscode/issues/304839](https://github.com/microsoft/vscode/issues/304839)

## Summary

Already fixed: PR #304872 (merged 2026-03-26) restricted prompt-file diagnostics to only show for files open in an editor, and the Copilot Chat extension 0.41.2 removed the offending tool references. Shipped in 1.114.0.

## Change summary

Copilot agent prompt files (Ask/Explore/Plan.agent.md) surfaced 'unknown tool' warnings in the Problems panel for tools from optional extensions, polluting diagnostics for all users.

## Best solution

Keep the shipped fix — prompt-file diagnostics are now scoped to open editors (commit 6648ece), and Copilot Chat 0.41.2 cleaned up the tool references. No further change needed.
