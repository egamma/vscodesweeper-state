# Issue #337020 — Add setting to prevent sleep when using chat

[https://github.com/microsoft/vscode/issues/337020](https://github.com/microsoft/vscode/issues/337020)

## Summary

Thanks for the request — Copilot Chat already prevents the system from sleeping during chat requests via a built-in, enabled-by-default power save blocker, so the central problem described here is already covered on current main.

## Change summary

Add a setting so VS Code prevents the PC from sleeping during long chat/coding sessions.

## Best solution

Keep the existing automatic behavior: `ChatMLFetcher` already acquires a power save blocker (`prevent-app-suspension`) for the duration of chat requests, controlled by the internal config key `chat.advanced.chatRequestPowerSaveBlocker` which defaults to `true` — no additional public setting is needed for the reported scenario.

  > Thanks for filing this! Copilot Chat already prevents the machine from sleeping while a chat request is in flight — `ChatMLFetcher` acquires a power-save blocker (`prevent-app-suspension`) for the duration of the request, and this is enabled by default (`chat.advanced.chatRequestPowerSaveBlocker`).
