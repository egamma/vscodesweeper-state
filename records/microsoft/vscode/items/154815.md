# Issue #154815 — Git - VS Code does not respect the diff flag in .gitattributes

[https://github.com/microsoft/vscode/issues/154815](https://github.com/microsoft/vscode/issues/154815)

## Summary

The original defect remains in the current source: SCM opens a text comparison without consulting the unset diff attribute. Keep this accepted Git bug open; the verified related issues do not own the same reported behavior.

## Change summary

Respect `.gitattributes` diff classification when opening SCM comparisons, particularly suppressing text previews for files marked `-diff`.

## Best solution

SCM should honor Git's effective `-diff` classification and show a non-text preview instead of computing a plaintext diff, while retaining normal file editing. Plan the preview integration first; forced-text attributes and textconv symmetry reported later are related requirements, not proof that the original defect is resolved.
