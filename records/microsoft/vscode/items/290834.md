# Issue #290834 — Explore associating recognized shells with an icon that changes

[https://github.com/microsoft/vscode/issues/290834](https://github.com/microsoft/vscode/issues/290834)

## Summary

Valid feature request to dynamically update the terminal tab icon based on the detected shell type. No implementation exists on current main — the shell type property is tracked but never feeds into the tab icon. Keeping open as a real gap.

## Change summary

Automatically change the terminal tab icon to match the detected shell (e.g. copilot, bash, PowerShell) rather than always showing the default terminal icon.

## Best solution

Wire the existing `shellType` property (already tracked on `IProcessPropertyMap`) into the terminal instance icon logic in `src/vs/workbench/contrib/terminal/browser/terminalInstance.ts`, mapping recognized shell types to appropriate codicons. This would complement the shell-based title change from the sibling issue #290830.
