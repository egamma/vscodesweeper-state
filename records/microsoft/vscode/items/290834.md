# Issue #290834 — Explore associating recognized shells with an icon that changes

[https://github.com/microsoft/vscode/issues/290834](https://github.com/microsoft/vscode/issues/290834)

## Summary

Keep this exploration open: recognized agent CLIs can now affect terminal titles, but current source does not associate shell-type transitions with tab-icon changes. Existing profile icons and manual icon changes do not cover the request; the exploration title also triggers the explicit keep-open rule.

## Change summary

Automatically update a terminal tab's icon when its recognized shell or agent CLI changes.

## Best solution

Establish the intended shell-to-icon behavior in the terminal area, including precedence over explicitly chosen icons and restoration when an agent exits. Treat extension-controlled live icon/color updates as a related but separate API capability, not an already-delivered solution.
