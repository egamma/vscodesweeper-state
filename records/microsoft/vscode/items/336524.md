# Issue #336524 — Archived local agent sessions revert to unarchived after restart (archive state is stored in a per-launch workspace storage)

[https://github.com/microsoft/vscode/issues/336524](https://github.com/microsoft/vscode/issues/336524)

## Summary

Keep open: current source still stores local-session archive flags in workspace storage while folder-less session content survives independently of that workspace identifier. The report provides sufficient reproduction steps, and no verified canonical or linked open fix was found.

## Change summary

Preserve local chat sessions' archived state when a folder-less window is reopened with a different workspace storage identifier.

## Best solution

Make archive state durable for the same local session across folder-less window restarts without changing provider-owned archive behavior or broadening chat-history visibility. Cover archive and unarchive persistence with regression tests that recreate the model under a different workspace identity.
