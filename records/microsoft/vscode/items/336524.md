# Issue #336524 — Archived local agent sessions revert to unarchived after restart (archive state is stored in a per-launch workspace storage)

[https://github.com/microsoft/vscode/issues/336524](https://github.com/microsoft/vscode/issues/336524)

## Summary

Source-verified on current main: the local-session archive flag cache (`agentSessions.state.cache`) is stored at `StorageScope.WORKSPACE`, and folder-less windows get a new per-launch workspace storage id, so the archive flag never round-trips after restart for the exact scenario described.

## Change summary

Archiving a local Copilot chat session in a folder-less window doesn't survive a VS Code restart — the session reappears as active.

## Best solution

Persist local-session archive state (in AgentSessionsCache.saveSessionStates / STATE_STORAGE_KEY, agentSessionsModel.ts) at StorageScope.APPLICATION (or otherwise keyed by session id rather than the ephemeral workspace storage folder) for sessions whose provider doesn't own archiving via canSetChatSessionItemArchived, so the flag is stable across per-launch workspace-storage ids.
