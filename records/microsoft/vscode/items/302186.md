# Issue #302186 — Attachment visibility

[https://github.com/microsoft/vscode/issues/302186](https://github.com/microsoft/vscode/issues/302186)

## Summary

Verified duplicate: the older open issue https://github.com/microsoft/vscode/issues/250437 tracks the same user-visible problem where suggested current-file context looks attached even though its contents are not sent to the model.

## Change summary

Clarify that a file displayed as suggested chat context is not available to the model until the user explicitly attaches it.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/250437 and make suggested context visually distinct enough that users understand it must be added before the model can read it.
