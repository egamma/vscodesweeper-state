# Issue #332333 — Configure Custom Agent picker shows agents unavailable in Copilot harness

[https://github.com/microsoft/vscode/issues/332333](https://github.com/microsoft/vscode/issues/332333)

## Summary

Traced on current main: the `Configure Custom Agents...` picker (promptFilePickers.ts) lists every extension-registered custom agent provider without checking `userInvocable` or harness-specific availability, so Copilot's internal Ask/Plan/Explore providers leak into the picker even though `Explore` is explicitly marked `userInvocable: false`.

## Change summary

The Configure Custom Agent quick pick shows provider-backed agents (Ask, Plan, Explore) that aren't meant to be user-configurable in the active harness.

## Best solution

In `_createPromptPickItems`/`getExtensionPromptFiles` (src/vs/workbench/contrib/chat/browser/promptSyntax/pickers/promptFilePickers.ts and .../common/promptSyntax/service/extensionPromptFileService.ts), filter extension-provided agent resources by their `userInvocable`/availability metadata before adding them to the config picker, mirroring how `userInvocable` already gates the `/` slash-command list.
