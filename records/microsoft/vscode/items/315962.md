# Issue #315962 — Add ability to write custom commit message in VSCode Agents App

[https://github.com/microsoft/vscode/issues/315962](https://github.com/microsoft/vscode/issues/315962)

## Summary

Keep open: the current Agents Window commit action still generates and commits a message without offering a custom-message input. The related reports do not qualify as canonical duplicates under the re-review rules.

## Change summary

Allow users to supply their own commit message when committing changes in the Agents Window.

## Best solution

Provide a discoverable manual-message option in the Agents Window commit workflow and ensure the submitted text reaches Git unchanged, while retaining AI generation as an option. Coordinate with the broader Git-workflow discussion without replacing this focused request.
