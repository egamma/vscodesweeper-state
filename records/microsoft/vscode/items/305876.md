# Issue #305876 — chat.promptFilesLocations ordering ignored

[https://github.com/microsoft/vscode/issues/305876](https://github.com/microsoft/vscode/issues/305876)

## Summary

The precedence defect remains directly visible on current main, but an open PR already references and addresses this issue. Keep the issue open while that implementation is reviewed and either landed or closed.

## Change summary

Prompt slash-command discovery ignores the configured `chat.promptFilesLocations` order and gives user prompt files precedence over workspace prompt files with the same name.

## Best solution

Review and update https://github.com/microsoft/vscode/pull/308171 against the current prompt-discovery code, add coverage for both local-first and user-first configurations with duplicate prompt names, and land it once validated.
