# Issue #284659 — File Compare from different directory

[https://github.com/microsoft/vscode/issues/284659](https://github.com/microsoft/vscode/issues/284659)

## Summary

The cross-directory comparison workflow already exists through multi-selected editor tabs, but the separate request to reveal an out-of-workspace file in the Explorer remains a real product decision. Route the residual request to the Explorer and tabs owners rather than closing the combined report.

## Change summary

Make files from different directories directly comparable from editor tabs and allow Reveal in Explorer View to expose an external file's directory.

## Best solution

Keep the existing Ctrl+click-two-tabs then Compare Selected workflow for comparison. Decide whether revealing an out-of-workspace file should offer to add its parent as a workspace root or expose it through another Explorer surface, without silently changing the workspace.
