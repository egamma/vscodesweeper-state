# Issue #284659 — File Compare from different directory

[https://github.com/microsoft/vscode/issues/284659](https://github.com/microsoft/vscode/issues/284659)

## Summary

Duplicate close gated off (the cited canonical #260470 is already closed — a duplicate close would strand the report; if the canonical's fix landed, an implemented-on-main close citing the fix commit is the right shape). Original assessment: The core ask — comparing files from different directories — is already possible via the Command Palette command 'File: Compare Active File With…' and via Ctrl+click multi-selecting two tabs then using 'Compare Selected' from the tab context menu. The specific sub-request for individual 'Select for Compare' / 'Compare with Selected' entries on single-tab right-click was previously declined as *out-of-scope (#76248) and closed for insufficient upvotes (#260470). This is a duplicate of #260470.

## Change summary

Request to add 'Select for Compare' and 'Compare with Selected' to the editor tab context menu and improve 'Reveal in Explorer' for out-of-workspace files.

## Best solution

Close as duplicate of https://github.com/microsoft/vscode/issues/260470, which is the most recent identical request (tab context menu compare). The reporter can use the existing multi-select tab workflow (Ctrl+click two tabs → Compare Selected) or the 'File: Compare Active File With…' command from the Command Palette to compare files across directories today.

## Evidence

- **existing capability:** The 'File: Compare Active File With…' command (workbench.files.action.compareFileWith in src/vs/workbench/contrib/files/browser/fileActions.ts:497) lets users compare the active editor with any file via a quick-pick, regardless of directory.
