# Issue #320999 — Copying chat responses drops spaces between inline code spans and text

[https://github.com/microsoft/vscode/issues/320999](https://github.com/microsoft/vscode/issues/320999)

## Summary

Valid bug filed by a team member — native browser copy/paste of chat responses drops whitespace around inline `<code>` elements and links. Hard keep-open: author is MEMBER.

## Change summary

Copying rendered chat responses to the clipboard loses spaces between inline code spans (and links) and surrounding text.

## Best solution

Investigate whether the markdown rendering is producing DOM nodes without adequate whitespace text nodes between inline elements, or whether a CSS property (e.g. `display: inline-block` on a parent, or collapsed whitespace) causes the browser's clipboard serialization to drop spaces. Fix likely lives in the chat markdown rendering pipeline or in the copy action (chatCopyActions.ts) — may need to intercept the `copy` event and produce sanitized plaintext that preserves spacing.
