# Issue #320999 — Copying chat responses drops spaces between inline code spans and text

[https://github.com/microsoft/vscode/issues/320999](https://github.com/microsoft/vscode/issues/320999)

## Summary

The report includes direct evidence of copied chat text losing whitespace, and current main still delegates inline-code and ordinary-link selections to native rich-text copying. This team-authored, accepted bug should remain open; no issue-linked fix or canonical duplicate was found.

## Change summary

Copying rendered chat text into rich-text applications removes spaces around inline code spans and links.

## Best solution

Chat selection copying should preserve visible whitespace around inline code and links in both plain-text and HTML clipboard flavors, including when pasted into Slack, without changing rendered chat spacing.
