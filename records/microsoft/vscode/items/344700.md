# Issue #344700 — Agents window: nested `dependsOn` with `dependsOrder: "parallel"` is joined without grouping, so a sequence runs out of order

[https://github.com/microsoft/vscode/issues/344700](https://github.com/microsoft/vscode/issues/344700)

## Summary

The reported ordering defect remains in current main: a nested parallel dependency escapes its enclosing sequence because the generated shell expressions are composed without preserving grouping. Keep this open for a bounded task-command fix; the separate question about implicit dependency order should not block restoring explicit sequence semantics.

## Change summary

Preserve explicit dependency ordering when Agents window tasks combine sequential and parallel dependency groups.

## Best solution

Make task-command composition preserve dependency boundaries so every prerequisite finishes before the next sequential dependency starts, while retaining parallel execution inside parallel groups. Evaluate the implicit-order discrepancy separately because existing Sessions tests explicitly require the current sequential default.
