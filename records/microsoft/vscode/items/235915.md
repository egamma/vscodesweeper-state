# Issue #235915 — vscode settings.json improvement

[https://github.com/microsoft/vscode/issues/235915](https://github.com/microsoft/vscode/issues/235915)

## Summary

Keep open: automatic organization of settings.json into extension-specific groups remains distinct from the existing JSON sorting command. The issue already has appropriate area labels and an accepted Backlog milestone; neither its age nor the closed related requests establishes grounds to close it.

## Change summary

Organize settings.json into extension-specific sections that remain coherent when configuration entries are added or changed.

## Best solution

Define whether extension-based organization should use generated comment sections or actual nested configuration nodes, including how subsequent Settings UI edits preserve that organization. Existing JSON sorting can help with ordering but does not supply the requested grouping.
