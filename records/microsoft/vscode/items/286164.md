# Issue #286164 — Remote host extension repeatedly restarting

[https://github.com/microsoft/vscode/issues/286164](https://github.com/microsoft/vscode/issues/286164)

## Summary

The crash originates from the old Marketplace `github.copilot-chat` extension (v0.35.2/0.35.3) accessing `navigator` in Node.js, hitting VS Code's intentional `PendingMigrationError` trap. Copilot Chat now ships as a built-in extension (`extensions/copilot/`), so this specific failure path is very likely resolved — but we need confirmation from the reporter on the latest build.

## Change summary

The Marketplace Copilot Chat extension (v0.35.2+) accesses `navigator` during activation in the remote extension host, triggering VS Code's `PendingMigrationError` trap and causing the extension host to repeatedly restart.

## Best solution

Confirm whether this still reproduces on the latest VS Code Stable (which ships with the built-in Copilot extension instead of the old Marketplace `github.copilot-chat`). If the reporter is still using the Marketplace extension, the fix is to uninstall it and use the built-in one. If it reproduces with the built-in extension, the `navigator` access in `extensions/copilot/` needs to be traced and guarded.

## Evidence

- **navigator trap:** src/vs/workbench/api/node/extensionHostProcess.ts lines 140-149 intentionally traps `navigator` access in the Node.js extension host, firing a PendingMigrationError and returning undefined — this is by design to help extensions migrate (see https://github.com/microsoft/vscode/issues/250648).
- **old Marketplace extension:** The stack trace shows `github.copilot-chat-0.35.2/dist/extension.js` — the old Marketplace extension, not the built-in `extensions/copilot/` that now ships with VS Code.
- **version-specific:** Reporter confirms downgrading to v0.33.5 of the Marketplace extension fixed it, suggesting a regression in v0.34–0.35.x of that extension.
- **built-in replacement:** Copilot Chat is now built into VS Code at `extensions/copilot/`; the Marketplace extension is deprecated. The built-in extension has its own `PendingMigrationError` class (extensions/copilot/src/util/vs/base/common/errors.ts), suggesting awareness of this migration.
