# Issue #297393 — Modal customizations + non-modal editors doesn't feel smooth

[https://github.com/microsoft/vscode/issues/297393](https://github.com/microsoft/vscode/issues/297393)

## Summary

Team-authored UX feedback on the chat customizations editor: the modal flow is too many clicks to browse multiple customization files, and a sidebar tree view would be preferable. Stays open for the area owner to address.

## Change summary

Browsing customization files via the modal editor requires too many steps; a sidebar tree view would streamline access.

## Best solution

Add a sidebar tree view of customizations (instructions, prompts, etc.) so users can browse and open them as easily as files in the explorer, without repeatedly navigating through the modal editor. The sessions window already has a version of this (per joshspicer's comment) that could be brought to core.
