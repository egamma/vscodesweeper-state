# Issue #174483 — Git - Git checkout for remote branch does not work

[https://github.com/microsoft/vscode/issues/174483](https://github.com/microsoft/vscode/issues/174483)

## Summary

Keep open: current source still omits the blocking file names from this checkout error dialog. Git correctly protects the untracked file; the remaining work is the diagnostic improvement accepted by the maintainer.

## Change summary

Display the affected file paths when checkout is blocked because untracked files would be overwritten.

## Best solution

Make the built-in Git checkout error dialog identify the blocking paths without requiring the reporter to open command output. Preserve Git's refusal to overwrite untracked files and the existing diagnostic actions.
