# Issue #152869 — Support virtual desktops on windows

[https://github.com/microsoft/vscode/issues/152869](https://github.com/microsoft/vscode/issues/152869)

## Summary

Keep this canonical Backlog request open while Electron lacks window-restoration APIs for Windows virtual desktops. It has 51 community upvotes, and maintainers already consolidate duplicate reports here.

## Change summary

Restore each VS Code window to its previous Windows virtual desktop after restarting the application or computer.

## Best solution

Electron should implement application window restoration through https://github.com/electron/electron/issues/37494; VS Code can then persist and restore virtual-desktop state through its existing window-state handling in `src/vs/platform/windows/electron-main/windowsStateHandler.ts`.
