# Issue #166105 — 3-way merge: naming of accept actions

[https://github.com/microsoft/vscode/issues/166105](https://github.com/microsoft/vscode/issues/166105)

## Summary

Keep open for a merge-editor wording decision: current source still uses “Accept” for selecting either input and for combining changes. No verified canonical covers this distinction, and this team-authored Backlog item cannot be declined on a reviewer’s wording preference.

## Change summary

Clarify that single-side merge actions select that side’s outcome, while the combination action combines changes.

## Best solution

Choose wording that clearly distinguishes selecting one input’s result from combining both changes, including deletion conflicts. Apply the chosen terminology consistently across merge-editor code lenses, context menus, tooltips, and accessibility help without changing merge semantics.
