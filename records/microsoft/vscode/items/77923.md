# Issue #77923 — [html] auto close tags being inserted before its html content

[https://github.com/microsoft/vscode/issues/77923](https://github.com/microsoft/vscode/issues/77923)

## Summary

Keep open: the current auto-insertion implementation has cancellation and document-version checks, but those do not establish that the reported Remote-SSH timing race is resolved. The supplied fast-typing steps and incorrect HTML result suffice to retest without requesting more information.

## Change summary

Delayed HTML auto-closing over Remote-SSH inserts the closing tag before content typed while the request is pending.

## Best solution

Ensure asynchronous HTML tag insertion never moves newly typed content outside the intended element. First reproduce the remote timing sequence and determine whether the built-in HTML client's stale-response safeguards cover edits still traveling to the remote extension host.
