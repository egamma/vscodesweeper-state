# Issue #296596 — MCP gateway: UX for enabling/disabling tools per session

[https://github.com/microsoft/vscode/issues/296596](https://github.com/microsoft/vscode/issues/296596)

## Summary

Keep open: the gateway still lists tools without consulting session-specific selections, so the existing Local Configure Tools experience does not satisfy this request. This team-authored feature has no verified fixing commit or qualifying duplicate.

## Change summary

Allow users to enable or disable individual gateway MCP tools independently for each Claude session, using an experience consistent with Local Configure Tools.

## Best solution

Connect a session-scoped tool configuration experience to the gateway's advertised tool set, preserving independent selections across sessions. Reuse the Local picker conventions without changing global server enablement or unrelated sessions.
