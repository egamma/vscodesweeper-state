# Issue #100335 — Implement Google Chrome-like grouped tabs

[https://github.com/microsoft/vscode/issues/100335](https://github.com/microsoft/vscode/issues/100335)

## Summary

Keep open: native collapsible groups within the editor tab bar remain a real gap, with 853 upvotes and existing implementation efforts. Current tab-layout settings and sidebar extensions do not satisfy the request, and no verified older canonical owns the same behavior.

## Change summary

Support Chrome-style grouping of editor tabs, with collapsible groups in the tab bar and potential automatic grouping of related files.

## Best solution

Reach an editor-area product decision on native tab grouping, using the existing contributor implementations as design input rather than starting a competing implementation. Establish manual grouping semantics first and explicitly decide whether search, references, and folder-based automatic grouping belong in the initial scope.

## Evidence

- **Existing-capability check:** src/vs/workbench/browser/workbench.contribution.ts registers workbench.editor.wrapTabs to wrap tabs onto multiple lines and workbench.editor.pinnedTabsOnSeparateRow to separate pinned tabs. Neither provides named, independently collapsible tab groups. EditorTitleControl.createEditorTabsControl in src/vs/workbench/browser/parts/editor/editorTitleControl.ts selects ordinary single, multiple, or pinned/unpinned-row controls; the inspected EditorGroupModel interfaces and serialized state in src/vs/workbench/common/editor/editorGroupModel.ts contain no Chrome-style subgroup state.
- **Workarounds do not cover the requested surface:** The supplied discussion offers VirtualTabs, Tabstronaut, and better-tabsgroup. The April 30 and May 13 comments explicitly distinguish sidebar organization from the requested collapsible groups within the actual tab bar, so these extensions are not evidence that the central ask is satisfied.
- **Previous implementation was not merged:** https://github.com/microsoft/vscode/pull/315366 explicitly says Fixes #100335 and implements native grouping, but GitHub reports CLOSED with mergedAt null.
