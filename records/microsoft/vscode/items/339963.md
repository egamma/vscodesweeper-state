# Issue #339963 — Connected tabs: customized active background exposes shoulder join artifacts

[https://github.com/microsoft/vscode/issues/339963](https://github.com/microsoft/vscode/issues/339963)

## Summary

Freshly filed, well-documented visual bug in the experimental Modern UI connected-tabs feature; already correctly labeled (bug, workbench-tabs, modernization) and no maintainer discussion yet, so it just needs to stay open for triage/design.

## Change summary

Connected-tab shoulder/edge joins look broken when a tab's customized active background differs from the editor background, and the HC multi-selection outline closes off the connected look.

## Best solution

Design a shoulder/edge-mask approach that respects customized `modernEditorTab.activeBackground`/`inactiveBackground` colors and a non-color-only HC selection indicator; likely touches multiEditorTabsControl.ts and connectedTabClipping.ts alongside the related tab-geometry work in #339028/#338796.

## Plan brief

- **Likely files:** `src/vs/workbench/browser/parts/editor/multiEditorTabsControl.ts`, `src/vs/workbench/browser/parts/editor/connectedTabClipping.ts`
- **Validation:** A Component Explorer snapshot/manual check of `editor/tabs/Colors/TabAndActionCustomizations/SingleRow/Dark` (and `DarkHighContrast`) showing clean shoulder joins with customized active/inactive backgrounds and a non-color HC selection indicator.
- **Trace:**

  > Shoulder/edge-mask elements (`.tab-fill`, `.tab-connected-edge`) are created in multiEditorTabsControl.ts and their bounds computed in connectedTabClipping.ts; the mask currently paints using the active tab's background, which diverges visually from the editor body when `modernEditorTab.activeBackground` is customized, producing the reported shoulder artifacts. Where the uncertainty starts: whether the fix is a geometry/paint change to the mask itself, a new color token, or redesigning the HC selection outline — all three are live options per the issue's own 'Follow-up' section, and nothing in the thread has settled which.
- **Open decisions:**
  - Should the shoulder/edge mask paint use a blended or token-derived color instead of the raw active-tab background to avoid the seam, or should the connected geometry itself change?
  - How should the HC active-tab multi-selection outline be redesigned so it doesn't read as closing off the connected join, while remaining non-color-only per accessibility guidance?
