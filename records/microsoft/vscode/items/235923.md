# Issue #235923 — Emmet Balance for JSON and YAML

[https://github.com/microsoft/vscode/issues/235923](https://github.com/microsoft/vscode/issues/235923)

## Summary

The core functionality requested — progressively selecting enclosing structural elements in JSON — is already provided by the built-in "Expand Selection" command (Shift+Alt+Right), powered by the JSON language server's selectionRangeProvider. Emmet Balance is HTML-tag-specific by design; the generic equivalent already works for JSON.

## Change summary

Request to extend Emmet Balance (inward/outward) to work in JSON and YAML files for structural selection.

## Best solution

The existing "Expand Selection" command (editor.action.smartSelect.expand / Shift+Alt+Right) already delivers progressive structural selection in JSON, powered by the JSON language server's SelectionRangeProvider. For YAML, extensions like Red Hat's YAML extension provide the same. The reporter can use this today; Emmet Balance itself is architecturally tied to HTML tag parsing and isn't the right mechanism for structured data formats.
