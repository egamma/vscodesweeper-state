# Issue #235923 — Emmet Balance for JSON and YAML

[https://github.com/microsoft/vscode/issues/235923](https://github.com/microsoft/vscode/issues/235923)

## Summary

Expand Selection and Shrink Selection already provide a related workflow, including language-aware JSON selection, but they do not establish full coverage of Emmet-style inward/outward balancing for JSON and YAML. Keep this accepted Backlog request open under its existing classification; no canonical duplicate or concrete implementing commit was identified.

## Change summary

Provide structural inward/outward selection for JSON and YAML comparable to Emmet Balance.

## Best solution

Favor the existing language-neutral selection-range infrastructure for structural selection rather than adding JSON and YAML parsing to Emmet. Establish whether the remaining requirement is YAML structural ranges, inward navigation from an arbitrary selection, or both before expanding the command surface.

  > Thanks for the request. Expand Selection (`editor.action.smartSelect.expand`) and Shrink Selection (`editor.action.smartSelect.shrink`) provide a related workflow, with language-aware selection ranges for JSON. They are not identical to Emmet Balance: shrinking reverses earlier expansion steps rather than independently navigating inward through a selected structure. This leaves the requested JSON/YAML balancing behavior open for discussion.

## Evidence

- **Current Emmet boundary:** extensions/emmet/src/balance.ts implements balancing through HtmlFlatNode opening/closing tags and child nodes. extensions/emmet/src/parseDocument.ts:getRootNode selects an HTML or stylesheet parser, not a JSON or YAML parser.
- **Existing alternative:** src/vs/editor/contrib/smartSelect/browser/smartSelect.ts registers editor.action.smartSelect.expand and editor.action.smartSelect.shrink. SmartSelectController uses language selection-range providers and retains expansion history for shrinking. extensions/json-language-features/server/src/jsonServer.ts advertises selectionRangeProvider and delegates requests to languageService.getSelectionRanges.
- **Coverage limitation:** SmartSelectController filters candidate ranges to those containing the current selection, so Shrink Selection reverses its expansion history rather than independently traversing into a selected node as Emmet Balance can. The generic fallback in src/vs/editor/contrib/smartSelect/browser/bracketSelections.ts matches bracket pairs; it does not establish structural coverage for indentation-based YAML mappings and sequences.
