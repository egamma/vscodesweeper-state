# Issue #256050 — Add close button to terminal inline chat

[https://github.com/microsoft/vscode/issues/256050](https://github.com/microsoft/vscode/issues/256050)

## Summary

Keep open: terminal inline chat still lacks a close affordance when first opened. Its existing Close action is confined to a response-dependent status toolbar, so it only partially covers the requested editor parity.

## Change summary

Provide a discoverable close button in terminal inline chat, consistent with editor inline chat.

## Best solution

Terminal inline chat should expose a keyboard-accessible close control whenever the widget is visible, including before a response exists. Closing should retain the existing terminal chat dismissal, cancellation, and focus-restoration behavior.

- **Reason:** Making equivalent inline chat surfaces consistently dismissible advances uniform UI interactions without adding a new capability.
