# Issue #235155 — Number-of-files-found Badge is hard to see on a selected list item

[https://github.com/microsoft/vscode/issues/235155](https://github.com/microsoft/vscode/issues/235155)

## Summary

The contrast gap remains on current main: the explorer find badge combines a translucent match background with the generic badge foreground without accounting for selected-row colors. This team-authored Backlog polish item should remain open.

## Change summary

Make the explorer's number-of-files-found badge and its count legible when its folder row is selected in Light+.

## Best solution

Give the explorer find badge state-aware theme styling that preserves clear contrast in selected, focused, and unselected rows across light, dark, and high-contrast themes without changing when the badge appears.
