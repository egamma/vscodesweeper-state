# Issue #290996 — Natural language search for Agent Sessions

[https://github.com/microsoft/vscode/issues/290996](https://github.com/microsoft/vscode/issues/290996)

## Summary

Keep open: current main provides gated session-history search through `/chronicle:search`, but it returns lexical matches as session IDs rather than semantically locating and opening the selected Agent Session. The remaining Agents-window integration is a real gap, and this team-authored Backlog request has no explicitly linked completing change.

## Change summary

Let users ask the agent in natural language to locate and reopen a past Agent Session by topic, file, bug, or pull request.

## Best solution

Build on Chronicle's session index and search tool, exposing results as actionable Agent Sessions that can be opened directly from chat or the Sessions view; semantic ranking could enhance the existing keyword, file, and reference matching.
