Still relevant: the `!important` on the notebook inline value decoration color is still present on main (notebook.css line 491), and no commit references this issue. The investigation into why tokenization CSS leaks into the decoration hasn't been done yet.

## Change summary

Notebook inline value decorations receive tokenization colors, forcing `!important` to override them — investigate the root cause to remove the `!important`.

## Best solution

Investigate why the `nb-inline-value` `inlineClassName` decoration picks up tokenization CSS in notebook cell editors (but the equivalent `debug-inline-value` does not need `!important` in the debug editor). The fix likely involves either adjusting CSS specificity or changing how the injected text decoration interacts with token coloring in `src/vs/workbench/contrib/notebook/browser/media/notebook.css` and possibly the editor's inline decoration rendering.
