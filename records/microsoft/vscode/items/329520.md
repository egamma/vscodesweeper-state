## Change summary

Typing `/` in a Copilot Chat session opened in an auxiliary window failed to display slash-command suggestions.

Keep the shipped SuggestWidget fix that creates its measurement canvas in the main JavaScript realm while rendering the widget in the auxiliary document; the accompanying regression test covers this exact window configuration.
