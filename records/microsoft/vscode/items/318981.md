# Issue #318981 — Github Copilot auto-complete for commented code

[https://github.com/microsoft/vscode/issues/318981](https://github.com/microsoft/vscode/issues/318981)

## Summary

Keep open as a feature request for comment-specific Copilot completion control. Existing language-level controls do not cover the central ask, and no open canonical issue was verified.

## Change summary

Allow automatic Copilot completions to be disabled inside code comments while remaining enabled in ordinary code.

## Best solution

Provide selective suppression of automatic Copilot completions in comment contexts, consistent with the editor's existing token-specific suggestion controls. Preserve completions outside comments rather than requiring users to disable Copilot for an entire language.
