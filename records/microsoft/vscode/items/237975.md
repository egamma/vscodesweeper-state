# Issue #237975 — Find and Replace (regex) behavior changes when text is long (negated character class starts including newline)

[https://github.com/microsoft/vscode/issues/237975](https://github.com/microsoft/vscode/issues/237975)

## Summary

Confirmed on current main: Replace All changes implementation after 19,999 matches and incorrectly allows a nominally single-line regex to consume newlines. The issue is valid, already routed to editor find, and should remain open for a targeted fix.

## Change summary

Large regex replacements can cross line boundaries and corrupt text even though the same expression remains line-scoped in smaller files.

## Best solution

Make the large Replace All path preserve the same line-by-line matching semantics as normal editor find, then add a regression test exceeding MATCHES_LIMIT.
