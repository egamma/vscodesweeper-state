# Issue #313682 — SCM: Count Badge not working anymore

[https://github.com/microsoft/vscode/issues/313682](https://github.com/microsoft/vscode/issues/313682)

## Summary

The current source reproduces the reported undercount when only one repository is selected: the `all` setting sums selected repositories rather than all eligible providers. Keep this open to restore aggregation without reintroducing counts from explicitly hidden providers.

## Change summary

With `scm.countBadge` set to `all`, the Activity Bar badge should include changes from repositories outside the current selection.

## Best solution

Make the SCM Activity Bar count honor the documented distinction between `all` and `focused`, independently of repository selection. Preserve exclusion of explicitly hidden providers and the existing `focused` and `off` behavior.
