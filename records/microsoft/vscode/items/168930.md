# Issue #168930 — Git - clone locally is not user-friendly

[https://github.com/microsoft/vscode/issues/168930](https://github.com/microsoft/vscode/issues/168930)

## Summary

Current main partially addresses repeated cloning by offering known cached clones, but it still neither fetches the existing repository nor lets users edit a destination path prefilled from the remote owner and repository name. The remaining UX request is valid but unplanned, so it should stay open for discussion.

## Change summary

Improve Clone Repository Locally by recognizing an existing clone and pre-populating an editable destination path from the remote repository identity.

## Best solution

Extend the Git clone flow in `extensions/git/src/cloneManager.ts` to offer opening and updating a matching existing clone, while supporting an exact editable destination path derived from the remote owner and repository name rather than selecting only its parent directory.
