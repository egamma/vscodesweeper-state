# Issue #335156 — Copilot always prompts on temp files it just created

[https://github.com/microsoft/vscode/issues/335156](https://github.com/microsoft/vscode/issues/335156)

## Summary

Team-authored, one-day-old report about the agent-host permission model prompting for approval every time Copilot reads/writes a file it just created in the OS temp directory; no existing allowlist logic for self-created temp files was found on main, so this is a real, unimplemented gap and stays open.

## Change summary

Copilot triggers a tool-approval prompt to read/use a temp file it itself just downloaded or created, even though the user already granted the agent broader permissions.

## Best solution

In the agent-host permission/approval layer (src/vs/platform/agentHost/node/sessionPermissions.ts and the terminal/file auto-approve rule resolution it depends on), consider auto-approving read/inspect access to files the current session itself just wrote into the OS temp directory, so the second file-touch doesn't re-trigger a prompt; this is a permission-policy design call for the agent-host owners.
