# Issue #334283 — Support opening `file-uri:line:column`

[https://github.com/microsoft/vscode/issues/334283](https://github.com/microsoft/vscode/issues/334283)

## Summary

Legitimate feature request that just reached the 20-upvote threshold and was moved to Backlog per the community process — the policy explicitly says not to close these for being quiet, and no maintainer decision or duplicate exists yet.

## Change summary

Requests that VS Code's link detector recognize and make clickable a `file-uri:line:column` pattern (e.g. in the Debug Console) in addition to existing web-URI and filesystem-path-with-line/column patterns.

## Best solution

Best owned by src/vs/workbench/contrib/debug/browser/linkDetector.ts (WEB_LINK_REGEX / PATH_LINK_REGEX / LINE_COLUMN), which currently detects `scheme://` URIs and OS file paths with trailing `:line:column` but not a bare `file-uri:line:column` token — a maintainer would need to decide the exact pattern/scheme handling before implementation.
