# Issue #334283 — Support opening `file-uri:line:column`

[https://github.com/microsoft/vscode/issues/334283](https://github.com/microsoft/vscode/issues/334283)

## Summary

Real feature gap: the debug console link detector already strips a trailing `:line:col` into a location fragment for `scheme://…` links (see the #150702 fix in linkDetector.ts), but only matches URIs with a double-slash authority — single-colon schemes like `package:foo/bar.dart:12:5` or non-`//` file URIs never match `WEB_LINK_REGEX` at all, so clicking them does nothing. This has just reached the 20-upvote Backlog threshold, so it should not be closed for quietness.

## Change summary

Make file/package-style URIs followed by `:line:column` (not just `scheme://…:line:col`) clickable and openable in the Debug Console.

## Best solution

Extend the link-detection regexes in src/vs/workbench/contrib/debug/browser/linkDetector.ts (WEB_LINK_REGEX / PATH_LINK_REGEX) to also recognize single-colon URI schemes (e.g. `package:`, bare `file:` without `//`) followed by a `:line:col` suffix, reusing the existing LINE_COLUMN_REGEX fragment-stripping logic already used for `file://` links.
