# Issue #334283 — Fix opening file: links with a drive letter in the Debug Console

[https://github.com/microsoft/vscode/issues/334283](https://github.com/microsoft/vscode/issues/334283)

## Summary

Valid, already-triaged request (promoted to Backlog after 20+ upvotes) with a real gap confirmed in source: the Debug Console link detector doesn't recognize `file:` URIs with a Windows drive letter. The reporter has an open PR (#336167) proposing the fix, so this should stay open pending review/merge rather than being closed or auto-fixed.

## Change summary

Support clicking `file:...` links containing a Windows drive letter (e.g. `file:C:\path:line:column`) in the Debug Console.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/336167, which extends the link-detection regex in src/vs/workbench/contrib/debug/browser/linkDetector.ts to recognize `file:` URIs with a drive letter alongside the existing WIN_ABSOLUTE_PATH/PATH_LINK_REGEX patterns.
