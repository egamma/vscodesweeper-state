# Issue #318327 — Add app and extension install/update history log

[https://github.com/microsoft/vscode/issues/318327](https://github.com/microsoft/vscode/issues/318327)

## Summary

A real auditability gap remains: current extension metadata exposes only the latest installation/update timestamp, not a durable version history. Because the request concerns supply-chain compromise and credential exposure, the security-sensitive keep-open rule applies.

## Change summary

Maintain a persistent, inspectable history of VS Code and extension installations and updates, including version and timestamp.

## Best solution

Provide a durable local audit record for application and extension install/update events, retaining extension identifiers, versions, timestamps, and operation outcomes across subsequent updates. The design should account for profiles and local, remote, and web extension-management contexts before deciding whether the history also needs a dedicated UI.

## Evidence

- **partial existing surface:** src/vs/workbench/contrib/extensions/browser/extensionsViews.ts uses the same current timestamp for the Recently Updated view (around lines 650-660), which helps find recent updates but cannot determine whether an older compromised version was ever installed.
