# Issue #131689 — API Interactive renderer communication is not in stable

[https://github.com/microsoft/vscode/issues/131689](https://github.com/microsoft/vscode/issues/131689)

## Summary

The `rendererScripts` / `NotebookRendererScript` API on controllers remains in proposed state (`vscode.proposed.notebookMessaging.d.ts`) after 5 years. The separate `createRendererMessaging` was stabilized (commit 7422b951b4c, closing #123601), but the controller-level renderer scripts mechanism was never finalized. Team-authored issue on On Deck — keeping open.

## Change summary

The `rendererScripts` controller API documented for interactive notebooks is still proposed-only and should either be stabilized or the docs should stop referencing it.

## Best solution

Decide whether the controller-level `rendererScripts` proposed API is still needed given the stable `createRendererMessaging` path. If not needed, remove the proposed API file and update external docs. If still needed, finalize it. The proposed file lives at `src/vscode-dts/vscode.proposed.notebookMessaging.d.ts` and only the API tests extension uses it.
