# Issue #48754 — Allow programatically un-selecting an item in a contributed tree

[https://github.com/microsoft/vscode/issues/48754](https://github.com/microsoft/vscode/issues/48754)

## Summary

Valid, unimplemented feature request with 21 upvotes and a proposed API (`treeViewReveal`) that allows `reveal(undefined)` to clear selection, but it has not been finalized into the stable API. The stable `TreeView.reveal` still requires a non-undefined element. Should stay open until the proposed API is finalized.

## Change summary

Allow extension authors to programmatically clear the selection in a contributed TreeView, e.g. by calling `reveal(undefined)`.

## Best solution

Finalize the `treeViewReveal` proposed API (in `src/vscode-dts/vscode.proposed.treeViewReveal.d.ts`) which already widens the `reveal` signature to accept `T | undefined`, enabling `reveal(undefined)` to clear the selection. The stable API in `vscode.d.ts` line 12214 currently requires `element: T`. Issue https://github.com/microsoft/vscode/issues/180394 was already closed as a duplicate of this one.
