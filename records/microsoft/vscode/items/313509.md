# Issue #313509 — Chat Debug: Add ability to filter by call type (tool calls vs internal agent calls)

[https://github.com/microsoft/vscode/issues/313509](https://github.com/microsoft/vscode/issues/313509)

## Summary

Valid feature request — the Chat Debug filter system currently has a single 'Tool Calls' toggle that lumps MCP tool calls and internal Copilot agent calls together; there is no way to filter them independently. The capability does not exist on current main.

## Change summary

Add independent show/hide toggles in the Chat Debug view to separate MCP tool calls from internal Copilot agent/wrapper calls.

## Best solution

Extend ChatDebugFilterState with a sub-kind distinction within the 'toolCall' kind (e.g. based on tool name patterns or a source/category field on IChatDebugEvent), add a new toggle command and context key, and wire it into the existing filter menu infrastructure in chatDebugFilters.ts.
