# Issue #308311 — Display reason for why 'Add Models...' button in GitHub Copilot Chat is disabled ("greyed out")

[https://github.com/microsoft/vscode/issues/308311](https://github.com/microsoft/vscode/issues/308311)

## Summary

The underlying policy state already has a hover explanation on current main, but the modal still lacks a visible and screen-reader-associated reason for the disabled control. The older related issue concerns model availability rather than this observable presentation gap, so the stronger re-review duplicate bar is not met.

## Change summary

Show the enterprise-policy reason directly in the Language Models modal when Add Models is disabled.

## Best solution

Present the managed-organization restriction in the Language Models modal without requiring users to discover a hover, and associate the explanation with the disabled Add Models control for assistive technology.

  > When Add Models is unavailable because a Business or Enterprise organization does not enable client BYOK, the Language Models modal explains that adding models is managed by the organization without requiring hover discovery. The disabled button and its reason are understandable to keyboard and screen-reader users. Accounts allowed to add models, and signed-out users offered Copilot setup, retain their existing behavior.
- **Trace:**

  > ChatModelsWidget.updateAddModelsButton in src/vs/workbench/contrib/chat/browser/chatManagement/chatModelsWidget.ts derives supportsAddingModels from entitlement and clientByokEnabled, disables the button when no dropdown actions remain, and supplies the organization reason only through Button.setTitle. Button.setTitle in src/vs/base/browser/ui/button/button.ts creates a managed hover but does not associate that text with the control through aria-describedby. https://github.com/microsoft/vscode/pull/289981 established the hover behavior intentionally, so this work is incremental presentation and accessibility polish rather than repairing the entitlement gate. Preserve the existing action construction and entitlement logic, including the signed-out Copilot action.
