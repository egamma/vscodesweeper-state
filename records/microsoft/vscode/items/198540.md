# Issue #198540 — "View: Show GitHub" keyboard shortcut focuses wrong activity view

[https://github.com/microsoft/vscode/issues/198540](https://github.com/microsoft/vscode/issues/198540)

## Summary

Confirmed UX issue where 'View: Show' commands for view containers break silently when views are moved to custom containers. Team members reproduced it and discussed it but no fix or warning was implemented; the issue remains under discussion.

## Change summary

The 'View: Show GitHub' keyboard shortcut focuses the wrong activity view (Explorer) instead of the GitHub view container after views have been rearranged.

## Best solution

Either show a warning/notification when the user invokes a 'View: Show' command for a view container whose views have been moved away, or automatically redirect the command to wherever the views ended up. The discussion in comment 12 (alexr00's suggestion of a warning) and comment 14 (sbatten's suggestion to use the `view` quick access) are the two candidate paths.
