# Issue #305717 — Simple Browser: Add command to focus browser content instead of URL bar

[https://github.com/microsoft/vscode/issues/305717](https://github.com/microsoft/vscode/issues/305717)

## Summary

Keep open: the dedicated content-focus command remains missing, and an open PR explicitly targets this request. That PR changes the iframe-based Simple Browser, so review should establish whether it also addresses the integrated-browser experience discussed by the maintainers.

## Change summary

Provide a command that focuses browser page content directly without tabbing through the URL bar and navigation controls.

## Best solution

Review https://github.com/microsoft/vscode/pull/307889 against the intended desktop integrated-browser scope before landing it. The finished command should restore focus to the page's last focused element, or its body by default, without changing initial URL-bar focus when opening a browser.
