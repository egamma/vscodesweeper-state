## Summary

Keep open: the reporter repeatedly confirmed the large-diff regression and bisected it, and an explicitly linked revert PR remains open. Current source still contains a quick-diff computation path without a practical time limit.

## Change summary

Opening a sufficiently large SCM diff prevents subsequent diffs from loading until VS Code is restarted.

## Best solution

Review the proposed revert at https://github.com/microsoft/vscode/pull/318314 against the reported large-diff sequence, ensuring subsequent SCM and non-SCM diffs remain usable after a timeout. Preserve the intended extension-facing diff information while preventing background quick-diff work from monopolizing diff computation.
