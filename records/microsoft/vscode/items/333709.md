# Issue #333709 — Automatically allow `read_file` access to Copilot terminal-output artifacts

[https://github.com/microsoft/vscode/issues/333709](https://github.com/microsoft/vscode/issues/333709)

## Summary

Keep open: current main still has the double-spill flow, and the existing settings do not provide automatic access without user configuration. The maintainer has already selected consolidation on trusted chat-session resources rather than another file-access exception.

## Change summary

Allow agents to recover complete large terminal results through file-reading tools without an additional external-file confirmation.

## Best solution

Consolidate local-harness terminal results on the existing generic session-resource paging mechanism, following the maintainer's stated direction. Preserve independent terminal-output compaction and ordinary external-file approval protections; do not extend this cleanup to Agent Host.
