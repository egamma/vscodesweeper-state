# Issue #209234 — Terminal in Floating Window Does Not Echo Characters in Real Time When Remotely Connected

[https://github.com/microsoft/vscode/issues/209234](https://github.com/microsoft/vscode/issues/209234)

## Summary

Keep open: the reporter confirmed the failure on 1.88, another commenter reported it again in May 2026, and a newer report independently describes the same minimized-main-window symptom. No verified fixing commit or older canonical was found.

## Change summary

Remote terminals in floating windows stop displaying typed characters after the main window has been minimized for a while, then display them when it is restored.

## Best solution

Ensure an active floating remote terminal continues processing input and displaying output independently of the main window's minimized state. Diagnose the Windows window-lifecycle and remote-terminal delivery paths before choosing a fix; this older report should retain the matching evidence from the newer report.
