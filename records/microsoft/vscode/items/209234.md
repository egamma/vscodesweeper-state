# Issue #209234 — Terminal in Floating Window Does Not Echo Characters in Real Time When Remotely Connected

[https://github.com/microsoft/vscode/issues/209234](https://github.com/microsoft/vscode/issues/209234)

Still-open bug confirmed by multiple users (most recently May 2026). No fixing commit found on main; the issue is assigned and in the Backlog. The `confirmation-pending` label appears stale since two users have confirmed it reproduces on later versions.

## Change summary

Terminal in a floating (auxiliary) window does not echo typed characters in real time when remotely connected and the main window is minimized; characters appear only when the main window is restored.

## Best solution

The root cause is likely that when the main window is minimized during a remote session, the remote connection or xterm rendering pipeline suspends output to the auxiliary window's terminal. The fix belongs in the terminal process or auxiliary-window integration layer (under `workbench-auxwindow` / `terminal-process`). The `confirmation-pending` label can be removed since users confirmed the issue persists through at least May 2026.
