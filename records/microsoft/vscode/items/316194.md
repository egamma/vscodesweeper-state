# Issue #316194 — Agents app changes broken

[https://github.com/microsoft/vscode/issues/316194](https://github.com/microsoft/vscode/issues/316194)

## Summary

Still present on main: the `_extractChanges` fallback creates a synthetic `summary://changes` URI with no registered content provider, so clicking a summary-only change entry throws 'Unable to resolve resource'. The Agents window Changes view is under heavy active development; routing to the sessions area.

## Change summary

In the Agents window, the Changes view shows entries without file names and errors on click when a session reports only a summary object (insertions/deletions counts) instead of individual file changes.

## Best solution

Guard the summary-only code path in `_extractChanges` (src/vs/sessions/contrib/providers/copilotChatSessions/browser/copilotChatSessionsProvider.ts) so it either registers a content provider for the `summary://changes` scheme, renders summary entries as non-clickable display-only items, or avoids emitting `ISessionFileChange` entries with unresolvable URIs.
