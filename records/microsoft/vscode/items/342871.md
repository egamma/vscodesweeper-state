## Change summary

Opening an agent-modified file from Session Changes targets the local user's home path instead of the actual remote file path.

## Best solution

Ensure Session Changes opens the edited file with its original remote authority and absolute path. First reproduce with different local and SSH home directories, then identify where the working-file URI diverges from the successfully edited resource.
