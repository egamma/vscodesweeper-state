# Issue #337014 — No special indication for WSL Dev Container session

[https://github.com/microsoft/vscode/issues/337014](https://github.com/microsoft/vscode/issues/337014)

## Summary

Current main still loses the Dev Container execution context when presenting a WSL-backed session. The issue is team-authored and remains a valid, source-confirmed Agents Window bug with the existing area labels.

## Change summary

Show that an Agents Window session is running in a Dev Container reached through WSL, rather than presenting only the underlying folder or host context.

## Best solution

Preserve the source host and Dev Container execution context separately from the workspace grouping label, then expose that context consistently in the session row or hover and its accessible text without splitting identical repositories into separate workspace groups.
