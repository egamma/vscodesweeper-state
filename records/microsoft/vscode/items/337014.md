# Issue #337014 — No special indication for WSL Dev Container session

[https://github.com/microsoft/vscode/issues/337014](https://github.com/microsoft/vscode/issues/337014)

## Summary

Fresh (same-day) UX suggestion from a contributor testing the Agents Window: there's currently no visible cue that a session is running inside a WSL-hosted Dev Container. Already correctly labeled (containers, agents-window, agent-host); nothing here warrants a close yet — it needs a design decision on where/how to surface the indicator.

## Change summary

When a session runs in a Dev Container inside WSL, the Agents Window gives no visual indication of that context (e.g. in the session hover or folder name).

## Best solution

Decide where the WSL+Dev Container context should surface in the Agents Window (session hover text, folder/name suffix, or an icon badge) and add it in remoteAgentHostSessionsProvider.ts / wslAgentHost.contribution.ts / devContainerSource.ts, consistent with how remote location is already indicated elsewhere in the picker.
