# Issue #143736 — Refactor preview: not all checkboxes should be tabstops

[https://github.com/microsoft/vscode/issues/143736](https://github.com/microsoft/vscode/issues/143736)

## Summary

The accessibility gap remains on current main: every native checkbox in Refactor Preview is still a Tab stop, unlike the established Breakpoints tree pattern. This should remain open in the existing accessibility/workspace-edit backlog.

## Change summary

Use one tree tab stop in Refactor Preview instead of tabbing through every edit checkbox, while exposing checkbox semantics on tree rows.

## Best solution

Remove the nested file and text-edit checkboxes from the Tab order in `bulkEditTree.ts`, following the Breakpoints view pattern, and expose each row's checked state through `BulkEditAccessibilityProvider.isChecked` so arrow navigation and checkbox semantics remain accessible.
