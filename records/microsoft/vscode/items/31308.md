# Issue #31308 — Support workspace projects / folders under different colors in sidebar and tabs

[https://github.com/microsoft/vscode/issues/31308](https://github.com/microsoft/vscode/issues/31308)

## Summary

Keep open as the canonical Backlog request: 159 community upvotes demonstrate sustained demand, while current file decorations provide only partial foreground-color coverage and no built-in per-workspace color mapping or background styling.

## Change summary

Allow workspace folders and their files to use distinct colors in the Explorer and editor tabs.

## Best solution

Make an explicit UX decision between a narrow built-in workspace-folder foreground-color mapping and documenting the existing FileDecorationProvider path for extensions. Background-colored tree rows or tabs should remain excluded unless the workbench design direction changes.

## Vision fit

- **Fit:** rejected
- **Reason:** Per-folder background customization conflicts with the uniform workbench UI guardrail and is largely implementable through the extension decoration API.
- **Evidence:** Public values: “Simple, uniform UI and UI interactions” and “The power lives in extensions.”
