# Issue #156457 — Allow to hide breadcrumbs via right-click

[https://github.com/microsoft/vscode/issues/156457](https://github.com/microsoft/vscode/issues/156457)

## Summary

The in-place right-click hide action remains missing; existing breadcrumb toggles do not cover that interaction. Related context-menu requests do not qualify as duplicates under the re-review rules, so retain this request for a coordinated breadcrumb menu design.

## Change summary

Allow users to hide breadcrumbs directly from their right-click context menu.

## Best solution

Provide an in-place breadcrumb visibility action consistent with other hideable workbench surfaces, retaining the existing setting and toggle command. Coordinate its menu placement with the ongoing breadcrumb context-menu discussion without expanding this request into file-management actions.

## Plan brief

- **Likely files:** `src/vs/workbench/browser/parts/editor/breadcrumbsControl.ts`, `src/vs/base/browser/ui/breadcrumbs/breadcrumbsWidget.ts`
- **Validation:** In a running workbench, enable breadcrumbs and right-click a breadcrumb with multiple editor tabs; the agreed visibility action must hide breadcrumbs and update breadcrumbs.enabled. Repeat with tabs hidden, verify the agreed editor-menu behavior, and confirm breadcrumbs.toggle restores breadcrumbs and existing breadcrumb navigation still works.
- **Behavior:**

  > Users can hide the breadcrumb surface directly through a right-click action on breadcrumbs, rather than finding a separate menu or setting. The action must use the existing breadcrumb visibility state, and existing ways to restore breadcrumbs must continue to work. Acceptance includes multiple-tab and no-tab layouts, plus unchanged normal breadcrumb navigation.
- **Trace:**

  > ToggleBreadcrumb in src/vs/workbench/browser/parts/editor/breadcrumbsControl.ts already exposes breadcrumbs.toggle and updates BreadcrumbsConfig.IsEnabled, but its menu registrations do not include a breadcrumb context menu. BreadcrumbsControl constructs BreadcrumbsWidget and subscribes to focus and selection without supplying a breadcrumb context-menu handler. The existing _showEditorTypePicker context menu is unrelated to this request. https://github.com/microsoft/vscode/issues/157757#issuecomment-1216326514 supports in-place toggles, while https://github.com/microsoft/vscode/issues/286073 records unresolved differences between breadcrumb menus with tabs and the editor title menu without tabs. Preserve current visibility semantics and navigation; file creation and other entity actions from https://github.com/microsoft/vscode/issues/56494 are outside this request. Source inspection established the missing interaction, but no runtime checks were performed in the read-only checkout.
- **Open decisions:**
  - With editor tabs hidden, should right-clicking inline breadcrumbs retain the editor title context menu with an added visibility action, or show a dedicated breadcrumb menu?
