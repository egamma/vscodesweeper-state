# Issue #156457 — Allow to hide breadcrumbs via right-click

[https://github.com/microsoft/vscode/issues/156457](https://github.com/microsoft/vscode/issues/156457)

## Summary

The requested in-place toggle remains absent on current main. A matching context menu was briefly implemented and then removed over single-tab UX issues, so the request should stay open for design discussion alongside the newer breadcrumbs-menu proposal.

## Change summary

Add a right-click action on breadcrumbs that disables the breadcrumbs bar.

## Best solution

Define a consistent breadcrumbs context-menu model for both tabbed and single-tab layouts, then expose the existing `breadcrumbs.toggle` action there. Coordinate that design with https://github.com/microsoft/vscode/issues/286073 without treating it as a duplicate, since that issue primarily concerns breadcrumb-item actions and copying paths.
