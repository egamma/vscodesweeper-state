# Issue #157816 — three space block does not indent with tab

[https://github.com/microsoft/vscode/issues/157816](https://github.com/microsoft/vscode/issues/157816)

## Summary

The Python example exposes the same loss of relative indentation already tracked by the older, open canonical issue. Consolidate there, preserving this example of the behavior changing Python block structure.

## Change summary

Indenting a selected Python block rounds three leading spaces up to four instead of adding four, collapsing its nesting.

## Best solution

Track preservation of relative indentation under https://github.com/microsoft/vscode/issues/63388, including this Python example. The existing editor.useTabStops setting provides a workaround for selected-block indentation.
