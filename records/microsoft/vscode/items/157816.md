# Issue #157816 — three space block does not indent with tab

[https://github.com/microsoft/vscode/issues/157816](https://github.com/microsoft/vscode/issues/157816)

## Summary

The reported indentation follows intentional per-line tab-stop snapping. The existing editor.useTabStops setting provides the requested fixed-width block indentation, and a maintainer explicitly confirmed this behavior in an earlier report of the same symptom.

## Change summary

Preserve relative indentation when pressing Tab on a multiline selection containing a three-space-indented line.

## Best solution

Keep the documented tab-stop behavior and use "editor.useTabStops": false for fixed-width block indentation. Explain that this setting also changes Backspace behavior rather than implying it affects only multiline selections.

- **Proposed comment:**

  > Thanks for the report. By default, Tab moves each selected line to its next tab stop independently, so a line indented three spaces moves to four rather than seven. This behavior is intentional, as explained in https://github.com/microsoft/vscode/issues/104371#issuecomment-687142125.
  > 
  > Set "editor.useTabStops": false to add one indentation level to every selected nonempty line while preserving their relative indentation. With four-space indentation, the three-space line then becomes seven spaces. This setting also makes Backspace remove individual spaces rather than snapping to tab stops.
