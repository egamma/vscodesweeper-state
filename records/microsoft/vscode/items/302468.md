# Issue #302468 — Staging agent-changed files before pressing Keep on them results in new unstaged files

[https://github.com/microsoft/vscode/issues/302468](https://github.com/microsoft/vscode/issues/302468)

## Summary

The staging/acceptance ordering on current main can still produce unstaged changes: Git stages the files before implicitly accepting chat edits, which can then run formatting and other save participants. Keep this report open; no qualifying fix or older open duplicate was established.

## Change summary

Staging agent-edited files before clicking Keep should not leave those files partially staged because implicit acceptance subsequently changes their contents.

## Best solution

Coordinate whole-file staging with chat acceptance so acceptance-triggered saves do not leave the index behind the resulting working-tree contents. Preserve configured save participants and existing partial-staging semantics.
