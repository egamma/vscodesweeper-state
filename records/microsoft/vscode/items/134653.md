# Issue #134653 — Deleting large files with the UI takes very long

[https://github.com/microsoft/vscode/issues/134653](https://github.com/microsoft/vscode/issues/134653)

## Summary

The root cause identified by a contributor — VS Code reading file content for undo backup on delete — is addressed by two shipped mechanisms: a 5MB `maxSize` cap that skips backup for large files, and the `explorer.enableUndo` setting (1.64) that lets users disable explorer undo entirely. This can be closed as completed.

## Change summary

Deleting large files via the explorer UI is slow compared to CLI `rm`, especially over remote SSH, because VS Code reads file content for undo backup.

## Best solution

Keep the shipped `explorer.enableUndo` setting (set to `false` to skip undo backup entirely) and the existing 5MB `maxSize` cap in `bulkFileEdits.ts` that already skips reading file content for files over 5MB. No further change needed.
