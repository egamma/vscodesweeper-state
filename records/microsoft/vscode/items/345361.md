# Issue #345361 — VS Code pet (Blobby): evolve and show live chat state (context usage, model cost, open chats, terminals, windows)

[https://github.com/microsoft/vscode/issues/345361](https://github.com/microsoft/vscode/issues/345361)

## Summary

Keep open as a feature request: existing chat indicators and Blobby reactions do not provide the proposed live status overlays. The breadth of signals and visual density need a product decision before implementation.

## Change summary

Add opt-in Blobby overlays and expressions reflecting context usage, model cost, session activity, terminals, and windows.

## Best solution

Evaluate a minimal, opt-in session-status enhancement in the chat pet area, reusing authoritative chat data and preserving existing reactions, reduced-motion behavior, and accessible feedback. Decide which signals genuinely improve glanceability before expanding into a multi-surface dashboard.
