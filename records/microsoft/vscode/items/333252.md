# Issue #333252 — Stop-hook continuation disables Anthropic thinking and invalidates prompt cache

[https://github.com/microsoft/vscode/issues/333252](https://github.com/microsoft/vscode/issues/333252)

## Summary

The defect remains conclusively traceable on current main: Stop-hook follow-ups are marked as continuations, causing Anthropic thinking and effort configuration to be omitted when no prior thinking block exists. This is a bounded correctness and cache-stability bug with no canonical duplicate or fixing change identified.

## Change summary

Preserve Anthropic thinking and reasoning-effort configuration on continuation requests generated by a blocking Stop hook.

## Best solution

Treat Stop-hook-generated follow-ups differently from ordinary automatic continuations when determining Anthropic model capabilities, while preserving the existing safeguard for ordinary continuations without a thinking block. Keep foreground requests and background-summarization capability calculation consistent.
