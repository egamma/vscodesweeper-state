# Issue #333252 — Stop-hook continuation disables Anthropic thinking and invalidates prompt cache

[https://github.com/microsoft/vscode/issues/333252](https://github.com/microsoft/vscode/issues/333252)

## Summary

Traced conclusively in current main: Stop-hook continuations set `hasStopHookQuery` but that flag is not consulted when deciding to disable Anthropic thinking, so the hook-generated follow-up drops `thinking`/`output_config.effort` and invalidates the prompt cache even though nothing about the conversation content changed.

## Change summary

A Stop-hook-generated continuation request to an Anthropic model disables thinking/effort, invalidating prompt cache instead of preserving the prior configuration.

## Best solution

In extensions/copilot/src/extension/intents/node/toolCallingLoop.ts (the `shouldDisableThinking` check around line 1893) and the matching parity logic in extensions/copilot/src/extension/intents/node/agentIntent.ts (around line 1023), add `&& !context.hasStopHookQuery` / `&& !promptContext.hasStopHookQuery` to the condition so hook-driven continuations keep the same thinking/effort configuration as the preceding request.
