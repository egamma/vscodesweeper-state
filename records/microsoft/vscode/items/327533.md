# Issue #327533 — Agents window Markdown editor: Support standard bold and italic shortcuts

[https://github.com/microsoft/vscode/issues/327533](https://github.com/microsoft/vscode/issues/327533)

## Summary

Keep open: this team-authored request identifies a current capability gap in the experimental Markdown editor, whose command and keyboard-dispatch paths do not provide bold or italic actions.

## Change summary

Add standard Cmd/Ctrl+B and Cmd/Ctrl+I shortcuts that toggle Markdown strong-emphasis and emphasis markers around the selection.

## Best solution

Implement marker-aware toggle commands and platform keybindings in the @vscode/markdown-editor package, with selection-preserving tests, then consume the updated package in the built-in Markdown extension.
