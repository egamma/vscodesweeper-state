# Issue #209671 — diffs are barely visible in HC light theme

[https://github.com/microsoft/vscode/issues/209671](https://github.com/microsoft/vscode/issues/209671)

## Summary

Still reproduces on main — the HC Light gutter diff colors lack sufficient contrast against the white editor background. An open PR (#326224) is actively attempting a fix, so this should stay open.

## Change summary

Diff gutter decorations (added/modified/deleted indicators) are barely visible in the High Contrast Light theme.

## Best solution

Land or iterate on the open PR https://github.com/microsoft/vscode/pull/326224, which adjusts the HC Light defaults for `editorGutter.addedBackground`, `editorGutter.modifiedBackground`, and `editorGutter.deletedBackground` to provide adequate contrast against the white editor background.
