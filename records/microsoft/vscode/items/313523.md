# Issue #313523 — MCP Authentication Dialog overflows and hides action buttons when URL is very long (Linux)

[https://github.com/microsoft/vscode/issues/313523](https://github.com/microsoft/vscode/issues/313523)

## Summary

The remaining defect is confirmed on current main: a long unbroken authentication URL drives the dialog toward its 90vw maximum because the wrapping rule does not reduce the content's intrinsic minimum width. A maintainer independently confirmed the excessively wide modal, so this should remain open for a bounded dialog-layout fix.

## Change summary

Keep MCP authentication dialogs compact and their action buttons accessible when the authorization URL is an extremely long unbroken string.

## Best solution

Make unbroken dialog detail text participate in intrinsic-size wrapping so the modal remains near its normal width while preserving the full selectable URL and keeping all action buttons visible.
