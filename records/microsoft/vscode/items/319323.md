# Issue #319323 — BidirectionalMap.set() and delete() cannot handle undefined as a stored value

[https://github.com/microsoft/vscode/issues/319323](https://github.com/microsoft/vscode/issues/319323)

## Summary

The undefined-value failures remain directly reproducible from current source. A merged neighboring fix handles ordinary BidirectionalMap updates but retained the undefined sentinel, while delete() and getOrSet() have the same unresolved ambiguity.

## Change summary

Allow BidirectionalMap and getOrSet to distinguish missing keys from keys whose stored value is undefined.
