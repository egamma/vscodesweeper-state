# Issue #267716 — feature request: more flexibility with send to remote agent

[https://github.com/microsoft/vscode/issues/267716](https://github.com/microsoft/vscode/issues/267716)

## Summary

Keep open: current continuation actions carry conversation context, but the cloud handoff action is disabled while a request is running, leaving the central mid-run request unmet. The discussion supports pursuing this workflow; neither the closed delegation cleanup nor the older handoff issue establishes completion or a qualifying duplicate.

## Change summary

Allow an ongoing local agent run to hand off its remaining work and accumulated context to the cloud agent without waiting for completion.

## Best solution

Provide a safe mid-run handoff through the existing chat continuation surface, preserving conversation context and already completed work. Establish how partial local edits reach the cloud and how declining or failing the handoff returns the user to local work before implementation.
