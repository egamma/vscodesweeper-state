# Issue #267716 — feature request: more flexibility with send to remote agent

[https://github.com/microsoft/vscode/issues/267716](https://github.com/microsoft/vscode/issues/267716)

## Summary

The 'Continue in...' delegation action exists but is gated by `requestInProgress.negate()`, so it's only available when no request is running — the core ask (delegate mid-run) is still unimplemented. Keeping open as a valid feature request from a team member.

## Change summary

Allow users to hand off a running local agent session to a remote/cloud agent mid-execution, rather than waiting for the local session to finish.

## Best solution

Remove or relax the `requestInProgress.negate()` precondition on `ContinueChatInSessionAction` and implement a pause-and-handoff flow: pause the local session, prompt for confirmation, transfer the session history to the cloud agent, and let the user resume or discard the local session. The work likely lives in `src/vs/workbench/contrib/chat/browser/actions/chatContinueInAction.ts` and the agent sessions infrastructure.
