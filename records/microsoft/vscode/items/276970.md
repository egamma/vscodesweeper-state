# Issue #276970 — Copilot code review is not discoverable

[https://github.com/microsoft/vscode/issues/276970](https://github.com/microsoft/vscode/issues/276970)

## Summary

This should stay open. A team member filed this UX request, and the main gap still exists: the built-in `/review` chat command is hidden behind an advanced setting, and no commit references this issue. The related issues are newer and cover narrower parts of the request, so none of them is a valid duplicate target.

## Change summary

Make Copilot code review easier to find, for example with a visible `/code-review` command, a better entry point than `Generate Code > Review`, or a suggested action after an agent finishes.

## Best solution

Show the existing review intent (`/review`, currently gated on `github.copilot.advanced.review.intent`) to users by default, and add a clear review action in the chat and SCM flows. Track the narrower slash-command and button work in https://github.com/microsoft/vscode/issues/276976 and https://github.com/microsoft/vscode/issues/277901 under this umbrella.
