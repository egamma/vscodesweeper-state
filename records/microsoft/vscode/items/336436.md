# Issue #336436 — Horizontal scrollbar is not scrolling all diff editors

[https://github.com/microsoft/vscode/issues/336436](https://github.com/microsoft/vscode/issues/336436)

## Summary

Keep open: the shared horizontal scrollbar still sends offsets that individual diff editors clamp to different local limits, so editors with shorter content stop scrolling before their neighbours. The source confirms the reported inconsistency; no verified fix or same-symptom canonical was found.

## Change summary

Make horizontal scrolling move all expanded editors in a multi-diff consistently despite differences in their content widths.

## Best solution

Give the multi-diff editor a consistent horizontal scrolling extent across its embedded editors, so a shared scrollbar position produces the same displacement throughout the widget. Preserve standalone diff-editor scrolling and the existing vertical virtualization behaviour.
