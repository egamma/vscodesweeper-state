# Issue #264195 — makefile / Markdown syntax highlighting quirks

[https://github.com/microsoft/vscode/issues/264195](https://github.com/microsoft/vscode/issues/264195)

## Summary

Two upstream grammar issues: (1) the markdown fenced-code-block grammar (from textmate/markdown.tmbundle) does not recognize `make` as a language alias for makefile highlighting — only `Makefile`, `makefile`, `GNUmakefile`, `OCamlMakefile` are matched; (2) the makefile TextMate grammar (from fadeevab/make.tmbundle, abandoned) may have comment-scoping limitations in target lines. Already correctly labeled `upstream` and `help wanted`.

## Change summary

Makefile syntax highlighting in markdown fenced code blocks fails when using `make` as the language identifier, and inline comments on target lines may not highlight correctly.

## Best solution

Add `make` as an alias in the markdown fenced code block pattern in `extensions/markdown-basics/syntaxes/markdown.tmLanguage.json` (the regex at line 234 needs `make` added to the alternation). For the makefile grammar comment-scoping issues, either upstream a fix to `fadeevab/make.tmbundle` or fork/patch the grammar locally since the upstream is abandoned. A community `help wanted` contribution could address both.
