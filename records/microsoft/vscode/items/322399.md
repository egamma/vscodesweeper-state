# Issue #322399 — [Error] unhandlederror-ModelService: Cannot add model because it already exists!

[https://github.com/microsoft/vscode/issues/322399](https://github.com/microsoft/vscode/issues/322399)

## Summary

Real regression in 1.125: `loadModel()` in `AbstractFileOutputChannelModel` lacks an idempotency guard, so concurrent calls via `provideTextContent` create a duplicate model and throw. An open PR (#322407) addresses it but has not merged.

## Change summary

Opening an output channel can throw 'Cannot add model because it already exists!' when `loadModel()` is called concurrently.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/322407 (or an equivalent idempotency guard in `loadModel()` at `src/vs/workbench/contrib/output/common/outputChannelModel.ts:492`). The fix should return the existing `loadModelPromise` when a load is already in progress and check for an existing model before calling `createModel`.
