# Issue #148193 — Settings editor funnel button: What does `@lang` do?

[https://github.com/microsoft/vscode/issues/148193](https://github.com/microsoft/vscode/issues/148193)

## Summary

Team-authored UX discussion about the @lang filter's discoverability remains valid — the current implementation still shows all LANGUAGE_OVERRIDABLE settings regardless of language relevance, which is confusing. No resolution or fix has landed.

## Change summary

The @lang filter in the settings editor shows settings that don't appear language-specific (e.g. generic Files settings for Java), making the feature's purpose unclear.

## Best solution

Improve UX clarity of the @lang filter — either add inline explanation text, improve the filtering to show truly language-relevant settings, or add better documentation/tooltips about what LANGUAGE_OVERRIDABLE scope means to users.
