# Issue #148193 — Settings editor funnel button: What does `@lang` do?

[https://github.com/microsoft/vscode/issues/148193](https://github.com/microsoft/vscode/issues/148193)

## Summary

Keep open as Settings editor clarity feedback: @lang selects settings that can be overridden for a language, not settings exclusive to that language. Existing scope indicators partially explain this, but no issue-referencing fix or qualifying canonical was established; the team-authored Backlog item is protected from a judgment close.

## Change summary

Make the Settings editor language filter's scope and inclusion of general settings easier to understand.

## Best solution

Make the filter affordance explain that it lists language-overridable settings and that edits apply only to the selected language. Preserve the existing filtering semantics rather than restricting results to language-exclusive or already-modified settings.

  > Thanks for the context. `@lang:java` shows settings that can be overridden for Java, including general settings that also support other languages; it does not mean those settings are Java-exclusive.
