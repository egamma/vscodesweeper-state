# Issue #225736 — Allow multi-select for REPL / interactive window

[https://github.com/microsoft/vscode/issues/225736](https://github.com/microsoft/vscode/issues/225736)

## Summary

Keep open: the existing Interactive Window still omits the editor contribution needed for occurrence-based multi-selection in its editable input. The newer notebook-backed REPL includes that contribution, but it does not replace the existing Interactive Window path.

## Change summary

Support standard multi-selection editing in the current editable REPL or Interactive Window input cell.

## Best solution

Provide standard occurrence-selection commands in the existing Interactive Window input, matching notebook cells and the newer REPL, while preserving read-only execution history. Coordinate with the notebook-backed interactive-window work without treating its broader API proposal as a duplicate.

- **Existing Interactive Window still lacks the contribution:** src/vs/workbench/contrib/interactive/browser/interactiveEditor.ts:397-418 constructs the input CodeEditorWidget with an explicit contribution allowlist that excludes MultiCursorSelectionController. - **Exact command path:** src/vs/editor/contrib/multicursor/browser/multicursor.ts:700-720 returns immediately from MultiCursorSelectionControllerAction.run when MultiCursorSelectionController.get(editor) is absent.
