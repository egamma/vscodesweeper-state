# Issue #200875 — Clicking into notebook activates links when VS Code is unfocused

[https://github.com/microsoft/vscode/issues/200875](https://github.com/microsoft/vscode/issues/200875)

## Summary

Still reproduces on main: the notebook webview link handler in backLayerWebView.ts processes `clicked-link` messages from the webview without checking whether the window was previously focused, so a refocus click also opens the link. No fix has landed for this specific behavior.

## Change summary

Clicking a link in a notebook markdown cell or output to refocus VS Code from another app also opens the link, instead of requiring a second click.

## Best solution

Guard the `clicked-link` message handler in backLayerWebView.ts (or the webview-side click handler in the notebook preload) to suppress link activation when the click is the window-activation event. The webview could track `document.hasFocus()` state and suppress the first click event after focus is gained, or the host side could track window focus transitions.
