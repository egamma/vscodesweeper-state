# Issue #336136 — Allow configuring the default click action for Chat Sessions

[https://github.com/microsoft/vscode/issues/336136](https://github.com/microsoft/vscode/issues/336136)

## Summary

Team-authored feature request (author defines intent, protected from judgment closes); confirmed on main that clicking a chat session always opens it in the Chat view pane (sidebar) unless the modifier click is held (openSessionDefault in agentSessionsOpener.ts), with no setting to invert the default — a real gap remains.

## Change summary

Add a setting so the default (non-modifier) click on a Chat Session opens it as an editor instead of the Chat sidebar, with modifier-click doing the opposite.

## Best solution

Add a `chat.sessions.defaultOpenLocation` (or similarly named) setting consulted in `openSessionDefault` (src/vs/workbench/contrib/chat/browser/agentSessions/agentSessionsOpener.ts) alongside the existing `openOptions?.sideBySide` modifier-click check, so users can flip which action (plain click vs. modifier click) opens in the editor vs. the panel.
