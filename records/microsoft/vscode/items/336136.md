# Issue #336136 — Allow configuring the default click action for Chat Sessions

[https://github.com/microsoft/vscode/issues/336136](https://github.com/microsoft/vscode/issues/336136)

## Summary

Keep open: the current session opener still defaults to the Chat view, and existing settings and commands do not provide the requested configurable click behavior. This team-authored request has no verified fix or canonical duplicate.

## Change summary

Allow ordinary clicks on Chat Sessions to open in the editor or Chat sidebar according to a setting, with modifier-click selecting the alternative.

## Best solution

Provide a configurable opening preference for the regular workbench Chat Sessions list, retaining the current default and reversing the modifier-click destination when editor opening is preferred. Preserve existing-session reveal behavior and provider-specific opening constraints.
