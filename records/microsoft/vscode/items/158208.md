# Issue #158208 — WebAssembly is not defined

[https://github.com/microsoft/vscode/issues/158208](https://github.com/microsoft/vscode/issues/158208)

## Summary

Still reproducible on main: the vscode-oniguruma loadWASM path in textMateTokenizationFeatureImpl.ts has no guard for environments where the WebAssembly global is unavailable (e.g. Edge with restrictive enterprise policies). alexdima explicitly requested this stay open.

## Change summary

Syntax highlighting fails on vscode.dev in Edge environments where WebAssembly is disabled, because vscode-oniguruma's loadWASM call crashes with 'WebAssembly is not defined'.

## Best solution

Add a typeof-WebAssembly guard in _getVSCodeOniguruma (src/vs/workbench/services/textMate/browser/textMateTokenizationFeatureImpl.ts) that gracefully degrades tokenization when WebAssembly is unavailable, rather than throwing an unhandled ReferenceError.
