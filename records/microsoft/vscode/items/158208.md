# Issue #158208 — WebAssembly is not defined

[https://github.com/microsoft/vscode/issues/158208](https://github.com/microsoft/vscode/issues/158208)

## Summary

Keep open: the current tokenization path still reports unavailable WebAssembly through `onUnexpectedError`, and the owning maintainer explicitly reopened this team-authored telemetry issue after rejecting the proposed duplicate.

## Change summary

Handle the expected absence of WebAssembly without generating repeated unexpected-error telemetry when TextMate tokenization cannot initialize.

## Best solution

Treat an unavailable WebAssembly runtime as a recognized tokenization-environment limitation: tokenization may remain unavailable, but VS Code should fail cleanly without reporting it as an unexpected product error, while preserving normal WebAssembly-backed tokenization.
