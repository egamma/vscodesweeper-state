# Issue #345611 — Agent Host: let archive_chat mark the calling session Done after the turn ends

[https://github.com/microsoft/vscode/issues/345611](https://github.com/microsoft/vscode/issues/345611)

## Summary

The requested deferred self-archive capability remains missing: current source explicitly rejects both the calling chat and its owning session. Keep this distinct from the existing conversation-header button request.

## Change summary

Allow archive_chat to schedule marking its calling chat or session Done after successful turn completion, dropping the request on cancellation, failure, or queued follow-up work.

## Best solution

Support deferred self-archive through the Agent Host turn-lifecycle contribution model, retaining the existing archive validation, persistence, and worktree-cleanup semantics. Preserve immediate archival of other conversations and avoid discarding pending work.
