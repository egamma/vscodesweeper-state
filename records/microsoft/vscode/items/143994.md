# Issue #143994 — Remote SSH: Copy + Paste automatically open file in new tab 

[https://github.com/microsoft/vscode/issues/143994](https://github.com/microsoft/vscode/issues/143994)

## Summary

The requested setting remains absent, and current main still automatically opens a single pasted file through the core Explorer path. The accepted Backlog item should remain open; the older matching report is closed and therefore cannot serve as a duplicate canonical.

## Change summary

Add a way to prevent Explorer paste operations from automatically opening a single pasted file, particularly when copying large files into remote workspaces.

## Best solution

Provide an Explorer-level option that suppresses opening a pasted file while preserving the current default for users who depend on it; the behavior should apply consistently to local and remote file-system resources.
