# Issue #332672 — PowerShell terminal discovery ignores custom Scoop installation root

[https://github.com/microsoft/vscode/issues/332672](https://github.com/microsoft/vscode/issues/332672)

## Summary

The custom Scoop root is still ignored in current source, so this should remain open and be routed to terminal discovery. The defect is bounded and ready for implementation.

## Change summary

PowerShell discovery should recognize Scoop installations under the SCOOP environment variable instead of only the default home-directory location.

## Best solution

Honor a nonempty SCOOP environment variable when locating Scoop's PowerShell executable, retaining the default home-directory root when it is unset or empty. Preserve existing PowerShell discovery order and terminal profile naming.

It never reads SCOOP. With SCOOP=D:\TOOL\scoop and the executable present only there, the candidate points at the wrong root.
