# Issue #332672 — PowerShell terminal discovery ignores custom Scoop installation root

[https://github.com/microsoft/vscode/issues/332672](https://github.com/microsoft/vscode/issues/332672)

## Summary

Confirmed on current main: `findPSCoreScoopInstallation` in src/vs/base/node/powershell.ts always derives the Scoop apps directory from `os.homedir()` and never consults the `SCOOP` environment variable that Scoop itself sets when installed to a custom root, so PowerShell installed via a custom Scoop directory is never discovered.

## Change summary

PowerShell profile discovery does not detect a Scoop-installed pwsh.exe when Scoop was installed to a non-default directory (i.e. `SCOOP` env var points elsewhere).

## Best solution

In `findPSCoreScoopInstallation` (src/vs/base/node/powershell.ts:229), prefer `process.env.SCOOP` as the Scoop root when set, falling back to `path.join(os.homedir(), 'scoop')` as today, matching Scoop's own environment-variable convention.
