# Issue #149912 — applyTo: closedDocuments and a custom owner caused errors to leak/persist

[https://github.com/microsoft/vscode/issues/149912](https://github.com/microsoft/vscode/issues/149912)

## Summary

Keep open: current source still permits custom-owner diagnostics to survive a successful watch pass after their file is opened. The detailed 2025 follow-up establishes an extension-independent reproduction, and no verified canonical owns this stale-marker behavior.

## Change summary

Task diagnostics using closedDocuments and a custom owner persist after the reported error is fixed while the file is open.

## Best solution

Make custom-owner task diagnostics accurately reflect the latest completed watch pass across document opening and closing, without retaining resolved errors. Preserve the existing diagnostic handoff for owners shared with language extensions.
