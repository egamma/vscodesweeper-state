# Issue #196372 — Double click in empty bottom notebook area should create a new empty cell

[https://github.com/microsoft/vscode/issues/196372](https://github.com/microsoft/vscode/issues/196372)

## Summary

This remains a valid Backlog feature request: current main provides explicit cell-insertion commands and toolbars but does not handle double-clicking the empty notebook area.

## Change summary

Create and focus a blank notebook cell when the user double-clicks the empty area below the final cell.

## Best solution

Add a read-only-aware empty-area double-click interaction around NotebookEditorWidget/NotebookCellList that reuses the existing code-cell insertion path and does not affect double-clicks within rendered cells.
