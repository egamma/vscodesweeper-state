# Issue #196372 — Double click in empty bottom notebook area should create a new empty cell

[https://github.com/microsoft/vscode/issues/196372](https://github.com/microsoft/vscode/issues/196372)

## Summary

Keep this accepted Backlog request open: existing insertion commands and toolbars do not provide the requested bottom-area double-click gesture. An older identical request was declined, but that decision predates this item's acceptance and cannot justify declining it now.

## Change summary

Allow double-clicking the empty area below the last notebook cell to append a new blank cell.

## Best solution

Have the notebook workflow owner revisit the earlier gesture decision in light of this accepted request. If adopted, bottom-area double-click should append and focus one blank cell while preserving existing insertion commands, keyboard access, and read-only behavior.
