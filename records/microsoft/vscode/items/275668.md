# Issue #275668 — Model selector does not respect preferences set in github.com/settings/copilot/features

[https://github.com/microsoft/vscode/issues/275668](https://github.com/microsoft/vscode/issues/275668)

## Summary

Confirmed upstream bug: the Copilot API returns models that the user has disabled in github.com/settings/copilot/features, and VS Code displays them because the server doesn't filter them out. The tracking epic in github/copilot is still open, so the fix has not landed yet.

## Change summary

Models disabled in GitHub Copilot settings (github.com/settings/copilot/features) still appear in VS Code's model picker.

## Best solution

The upstream Copilot API needs to exclude user-disabled models from the model list response. The VS Code side displays what the API returns; once the API respects the disabled-model policy, VS Code will show the correct filtered list. Keep tracking until the upstream epic lands.
