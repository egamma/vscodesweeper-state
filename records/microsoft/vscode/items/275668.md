# Issue #275668 — Model selector does not respect preferences set in github.com/settings/copilot/features

[https://github.com/microsoft/vscode/issues/275668](https://github.com/microsoft/vscode/issues/275668)

## Summary

Keep open as an upstream server bug. A maintainer reproduced the behavior with a test account, agreed that disabled models should be absent, and referred the defect to the server team.

## Change summary

Models disabled through the GitHub Copilot feature settings remain visible in VS Code's model selector across installations.

## Best solution

The Copilot model-metadata service should apply the account's GitHub feature preferences and omit disabled models from the response consumed by VS Code; keep this issue tracking that upstream correction until it is verified.
