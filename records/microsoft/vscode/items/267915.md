# Issue #267915 — Enable `window.autoDetectColorScheme` by default

[https://github.com/microsoft/vscode/issues/267915](https://github.com/microsoft/vscode/issues/267915)

## Summary

The request remains unresolved on current main: automatic color-scheme detection still defaults to false for the standard workbench, and the discussion has not settled the migration policy.

## Change summary

Enable automatic OS color-scheme detection by default while preserving intentional theme choices during migration.

## Best solution

Decide whether adoption should cover all default-theme users or only users whose OS is configured for automatic appearance changes, then implement that guarded migration in the theme configuration service with settings-sync protection.
