# Issue #349283 — Mermaid: fall back to source instead of showing parse errors in chat

[https://github.com/microsoft/vscode/issues/349283](https://github.com/microsoft/vscode/issues/349283)

## Summary

Keep open as a presentation-policy feature request: current chat rendering deliberately displays diagnostics, and no existing setting provides the requested automatic source fallback.

## Change summary

Display original Mermaid source when chat diagrams contain invalid syntax, while retaining diagnostics in the explicit diagram editor.

## Best solution

Provide a chat-specific invalid-source presentation in the built-in Mermaid renderer, preserving selectable source, copy/open actions, and existing diagnostics in explicit editing and other Markdown surfaces. Keep unexpected runtime failures distinguishable from syntax failures.
