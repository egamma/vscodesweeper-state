# Issue #54272 — Allow diagnostics messages to have markdown (or formatted text) content

[https://github.com/microsoft/vscode/issues/54272](https://github.com/microsoft/vscode/issues/54272)

## Summary

This remains a valid, highly supported API request, and current main still restricts diagnostic messages to plain strings. Keep it open while the directly linked implementation PR is reviewed and either landed or closed.

## Change summary

Allow extension and language-server diagnostics to provide opt-in Markdown or other formatted message content while retaining a plain-text representation.

## Best solution

Review and complete https://github.com/microsoft/vscode/pull/214051, preserving plain-text behavior for the Problems view, accessibility, filtering, copying, and extensions that do not opt into Markdown while rendering trusted formatted content in diagnostic hovers.
