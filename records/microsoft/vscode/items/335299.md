# Issue #335299 — Agent Host stops forwarding turn events after screenshot tool returns an image

[https://github.com/microsoft/vscode/issues/335299](https://github.com/microsoft/vscode/issues/335299)

## Summary

The captured timeline confirms that an image-bearing client tool completes while subsequent SDK work continues, but Agent Host stops publishing that turn's events and completion. Current source handles image results, yet no referenced fix or test covers the reported post-image forwarding failure, so this team-authored bug should remain open.

## Change summary

Keep Agent Host forwarding progress, response, and turn-completion events after a browser screenshot returns an image, without rebinding buffered events during steering.

## Best solution

Preserve the original turn and request association across an image-bearing client-tool completion so all later SDK actions and `chat/turnComplete` reach the subscribed AHP chat; cancellation or steering must not attribute buffered actions to a replacement request.
