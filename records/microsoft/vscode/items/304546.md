## Summary

Keep open: CPU profiles and independent reports confirm that Copilot Chat can monopolize the shared extension host in large workspaces, blocking other extensions. A later exclusion-filtering fix addresses a similar regression but was introduced after this report and was explicitly not established as the same root cause.

## Change summary

Copilot Chat spends several seconds continuously evaluating content exclusions after loading a large workspace, making the shared extension host and unrelated extensions unresponsive.

## Best solution

Profile the original reload-and-large-workspace scenario on current main, identify which caller drives the sustained `isCopilotIgnored` work, and ensure content-exclusion and repository discovery work cannot monopolize the shared extension host. Preserve enforcement of local and remote exclusion rules while bounding startup work and filesystem activity.
