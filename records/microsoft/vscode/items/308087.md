# Issue #308087 — Unable to Find Skill in user level ~/.copilot/skills

[https://github.com/microsoft/vscode/issues/308087](https://github.com/microsoft/vscode/issues/308087)

## Summary

Confirmed via source: `getSourceFolders()` explicitly excludes user-level skill folders (line 412 of promptsServiceImpl.ts), causing the AI Customization Editor's "Create" picker to show no user skill folders — while the command palette path (`getResolvedSourceFolders`) correctly includes them via `DEFAULT_SKILL_SOURCE_FOLDERS`. The inconsistency is a real bug.

## Change summary

The AI Customization Management Editor's "Create skill" picker does not list user-level skill source folders (~/.copilot/skills, ~/.agents/skills, ~/.claude/skills) because `getSourceFolders()` intentionally skips them for skills.

## Best solution

Remove the skill exclusion in `getSourceFolders()` (line 412 of promptsServiceImpl.ts) so that user-level skill folders from `DEFAULT_SKILL_SOURCE_FOLDERS` are returned consistently across both the management editor and command palette creation flows. The user-home path for skills should mirror the pattern already used for instructions/prompts/agents.
