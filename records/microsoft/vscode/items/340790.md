# Issue #340790 — Option to turn off suggestion

[https://github.com/microsoft/vscode/issues/340790](https://github.com/microsoft/vscode/issues/340790)

## Summary

The requested option already exists for both inline suggestions and automatic IntelliSense popups. The discussion links the documented inline-suggestion controls, and the report does not describe those controls failing.

## Change summary

Allow suggestions to be disabled so the reporter can learn coding without automatic completion prompts.

## Best solution

Use the existing suggestion settings rather than add another toggle: disable editor.inlineSuggest.enabled for automatic inline suggestions, and disable editor.quickSuggestions and editor.suggestOnTriggerCharacters for automatic IntelliSense popups.
