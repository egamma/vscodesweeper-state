# Issue #340790 — Option to turn off suggestion

[https://github.com/microsoft/vscode/issues/340790](https://github.com/microsoft/vscode/issues/340790)

## Summary

The request is terse, but it almost certainly refers to AI inline suggestions. VS Code already has settings that turn these off, and a contributor linked the docs, so the option exists.

## Change summary

Provide a way to disable suggestions (almost certainly AI inline suggestions) while learning to code.

## Best solution

Keep the shipped behavior. The reporter can use the existing settings: `editor.inlineSuggest.enabled` for inline suggestions, or `chat.disableAIFeatures` to hide all built-in AI features.

  > Thanks for the report. You can turn suggestions off with existing settings. Set `editor.inlineSuggest.enabled` to false to disable inline (AI) suggestions, or set `chat.disableAIFeatures` to true to hide all built-in AI features. If you mean the regular IntelliSense popup, set `editor.quickSuggestions` to off. See https://code.visualstudio.com/docs/editing/ai-powered-suggestions#_enable-or-disable-inline-suggestions. Please open a new issue with details if none of these cover what you want.
