# Issue #331039 — Agent Host "Allow remote session access" hangs and triggers Unexpected end of JSON input on VS Code 1.133.0

[https://github.com/microsoft/vscode/issues/331039](https://github.com/microsoft/vscode/issues/331039)

## Summary

Fresh, single report against a very new feature (Agent Host remote/tunnel session access); the stack trace maps to a real deserialization path in the IPC protocol, so this looks like a genuine framing/corruption bug rather than user error, but the underlying cause (why the buffer read stops short) isn't pinned down yet.

## Change summary

Enabling 'Allow remote session access' on an Agent Host/Copilot session throws 'Unexpected end of JSON input' and the tunnel never finishes establishing.

## Best solution

Have the Agent Host/remote-tunnel owners trace why the MessagePort-based protocol frame being read at src/vs/base/parts/ipc/common/ipc.ts (onRawMessage/onBuffer -> deserialize) is truncated during the gateway inventory/selection handshake in src/vs/platform/agentHost/common/tunnelAgentHost.ts, and add resilience (or a clearer error) instead of a raw JSON.parse crash — ideally after getting an insiders repro trace from the reporter.
