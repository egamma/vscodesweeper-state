# Issue #331039 — Agent Host "Allow remote session access" hangs and triggers Unexpected end of JSON input on VS Code 1.133.0

[https://github.com/microsoft/vscode/issues/331039](https://github.com/microsoft/vscode/issues/331039)

## Summary

Verified duplicate of the open regression-tracking issue #330263, which already diagnoses this exact crash — an unguarded JSON.parse in ipc.ts's deserialize() throwing on a truncated MessagePort frame to the agent host process — introduced in the 1.133.0 Agent Host Protocol-over-MessagePort rework.

## Change summary

Clicking 'Allow remote session access' to start tunnel hosting for a Copilot Agent Host session hangs at 'Establishing tunnel connection...' while Main logs an uncaught 'Unexpected end of JSON input' from AgentHost:stderr.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/330263, which already traces the crash to src/vs/base/parts/ipc/common/ipc.ts's deserialize() (DataType.Object case, JSON.parse on a truncated buffer) reached via ChannelServer.onRawMessage over a MessagePort transport; a prior fix attempt (https://github.com/microsoft/vscode/issues/330276, closed not-planned) only enriched the error message rather than addressing the truncation, so real work remains there — a bounds-check in deserialize/BufferReader.read plus finding why the agent host's local MessagePort transport is delivering truncated frames during tunnel-hosting establishment.
