# Issue #164029 — Inline completions and snippets collide

[https://github.com/microsoft/vscode/issues/164029](https://github.com/microsoft/vscode/issues/164029)

## Summary

The reported snippet-navigation collision is addressed on current main: inline suggestions are suppressed during snippet mode by default. A concrete merged change enables that behavior, so this can be closed as completed.

## Change summary

Prevent Tab from accepting an inline completion when the user intends to advance between snippet placeholders.

## Best solution

Keep the default snippet-mode suppression introduced by dd57d238873d180e1484a1568abf8126752a3193, while retaining editor.inlineSuggest.suppressInSnippetMode as an explicit opt-out.
