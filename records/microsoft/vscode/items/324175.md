# Issue #324175 — Should Browser become visible when Agent opens it?

[https://github.com/microsoft/vscode/issues/324175](https://github.com/microsoft/vscode/issues/324175)

## Summary

Valid feature request from a team member: the integrated browser should stay hidden by default when an agent opens it, with a status indicator and an explicit 'show me the browser' path. No implementation exists on main yet.

## Change summary

When an agent uses the integrated browser, it auto-opens in the workbench, which can be distracting; the request is to keep it hidden by default with a status indicator and an opt-in reveal.

## Best solution

Add a background/hidden mode to the browser tool invocation path (likely in `src/vs/workbench/contrib/browserView/electron-browser/tools/openBrowserTool.ts` and the browser view service) so agent-initiated browser opens don't auto-reveal. Surface a status indicator (e.g. in the session view or status bar) and a tool parameter like `showBrowser: true` that the agent can use when the user explicitly asks to see the browser.
