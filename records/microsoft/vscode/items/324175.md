# Issue #324175 — Should Browser become visible when Agent opens it?

[https://github.com/microsoft/vscode/issues/324175](https://github.com/microsoft/vscode/issues/324175)

## Summary

A genuine, unresolved UX design question about the integrated browser's auto-reveal behavior during agent sessions — current code confirms the browser editor is opened (and revealed) automatically today, with no hidden-by-default/status-indicator toggle yet, so this stays open pending a maintainer design decision.

## Change summary

Proposes keeping the integrated browser hidden by default when an agent opens it, showing a status indicator with a button to reveal the live view instead of auto-opening it.

## Best solution

Belongs with the Agents window / integrated-browser design work in src/vs/workbench/contrib/browserView (e.g. openBrowserToolNonAgentic.ts and browserViewWorkbenchService.ts, which currently call editorService.openEditor directly to reveal the page) — a maintainer needs to decide whether to add a non-intrusive 'agent is browsing' indicator instead of auto-reveal; no implementation exists yet.
