# Issue #200479 — macOS path bar "Open in Terminal" opens VSCode instead of Terminal

[https://github.com/microsoft/vscode/issues/200479](https://github.com/microsoft/vscode/issues/200479)

## Summary

Keep open for macOS association diagnosis: multiple users confirm the Finder-specific symptom, but neither a VS Code defect nor an upstream cause has been established. Resetting the default terminal reportedly helps; that is a workaround, not evidence of a landed fix.

## Change summary

Finder’s path-bar “Open in Terminal” action launches VS Code instead of Terminal.app on some macOS installations.

## Best solution

Identify which Launch Services association Finder consults on an affected account and whether VS Code’s bundle registration contributes to the unexpected selection. Preserve shell-script editing and folder-opening support; establish ownership before changing registration or treating this as an Apple-side defect.
