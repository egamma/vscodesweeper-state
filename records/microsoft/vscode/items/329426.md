# Issue #329426 — Cannot Enable GitHub authentication Extention

[https://github.com/microsoft/vscode/issues/329426](https://github.com/microsoft/vscode/issues/329426)

## Summary

Traced on main: the guard meant to stop Settings Sync's auth-provider extension (vscode.github-authentication) from being disabled instead blocks changing enablement in either direction, so once the extension ends up disabled (e.g. via an old synced extensions.json) the user can never re-enable it while sync is on.

## Change summary

User cannot re-enable the GitHub Authentication built-in extension once it was synced as disabled, because Settings Sync is active for the GitHub account.

## Best solution

In extensionEnablementService.ts, scope the isDefaultOrSettingsSyncAuthProviderExtension guard in throwErrorIfCannotChangeEnablement to only fire when the extension is currently enabled and the caller is trying to disable it, not when it is disabled and the caller wants to enable it.
