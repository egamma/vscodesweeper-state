# Issue #329426 — Cannot Enable GitHub authentication Extention

[https://github.com/microsoft/vscode/issues/329426](https://github.com/microsoft/vscode/issues/329426)

## Summary

The defect remains on current main: VS Code deliberately prevents changing the enablement of the authentication provider used by Settings Sync, but the same guard incorrectly blocks re-enabling an already-disabled provider. The existing settings-sync routing is appropriate, and this should remain open for a bounded fix.

## Change summary

Allow a Settings Sync authentication provider that was previously synced as disabled to be enabled again without allowing users to disable the active provider.

## Best solution

Distinguish enabling from disabling in the extension-enablement checks: enabling the authentication provider required by Settings Sync must remain available, while disabling that active provider must stay prohibited.
