# Issue #81352 — [html] Jump to after next opening HTML tag

[https://github.com/microsoft/vscode/issues/81352](https://github.com/microsoft/vscode/issues/81352)

## Summary

The requested navigation is already available through Emmet's assignable “Go to Next Edit Point” command, which moves through empty tag content, empty attributes, and indented blank lines. A custom keyboard shortcut can invoke that command after the cursor has moved away from the original Emmet expansion.

## Change summary

Provide a keyboard command that moves the cursor into the next HTML element after its opening tag while filling an Emmet-generated structure.

## Best solution

Use the existing `editor.emmet.action.nextEditPoint` command and assign it a preferred keybinding through Keyboard Shortcuts; the corresponding previous-edit-point command supports reverse navigation.
