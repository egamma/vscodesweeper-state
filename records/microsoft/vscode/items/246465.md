# Issue #246465 — Cannot resize or move window with Custom Title bar on Linux via MobaXterm

[https://github.com/microsoft/vscode/issues/246465](https://github.com/microsoft/vscode/issues/246465)

## Summary

This is a documented Electron/X11 window-management limitation with a reporter-confirmed native-title-bar workaround. Although a maintainer explicitly recommended an out-of-scope close, the review policy requires dependency-owned issues to remain open.

## Change summary

Allow dragging and resizing Linux custom-title-bar windows displayed through MobaXterm X forwarding.

## Best solution

Retain the documented window.titleBarStyle="native" workaround; supporting the custom title bar in this environment requires resolving Electron's frameless-window interaction with the receiving X server, rather than changing command-center layout.
