# Issue #246465 — Cannot resize or move window with Custom Title bar on Linux via MobaXterm

[https://github.com/microsoft/vscode/issues/246465](https://github.com/microsoft/vscode/issues/246465)

## Summary

The report matches a documented Electron/X11 limitation affecting frameless windows over X forwarding. Classify it as upstream and keep it open under the dependency rule rather than treating it as a VS Code implementation defect.

## Change summary

Custom-title-bar windows cannot be moved or resized when Linux VS Code is displayed through MobaXterm X forwarding.

## Best solution

Electron or the receiving X server must support the frameless-window drag and resize operations; until then, retain the documented `window.titleBarStyle: "native"` workaround.
