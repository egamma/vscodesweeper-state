# Issue #320422 — Remote-SSH 0.107.1 breaks on macOS due to Unix socket path exceeding 104-char limit

[https://github.com/microsoft/vscode/issues/320422](https://github.com/microsoft/vscode/issues/320422)

## Summary

This is a confirmed Remote-SSH regression, and Remote-SSH is maintained by the VS Code team in microsoft/vscode-remote-release. Keep it open and transfer it to that tracker rather than closing it as extension-caused.

## Change summary

Remote-SSH generates an askpass Unix socket path longer than macOS's 104-character limit, preventing remote connections.

## Best solution

Shorten or relocate the generated askpass socket path in Remote-SSH and cover macOS temporary-directory lengths with a regression test that keeps the Unix socket path below the platform limit.
