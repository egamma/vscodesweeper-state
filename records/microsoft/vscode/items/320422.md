# Issue #320422 — Remote-SSH 0.107.1 breaks on macOS due to Unix socket path exceeding 104-char limit

[https://github.com/microsoft/vscode/issues/320422](https://github.com/microsoft/vscode/issues/320422)

## Summary

This is a Remote-SSH extension issue (socket path generation in the askpass helper), not a VS Code core bug. Remote-SSH has its own active tracker at microsoft/vscode-remote-release — the issue should be moved there so the extension team can address it.

## Change summary

Remote-SSH 0.107.1 generates IPC socket paths exceeding macOS's 104-char UNIX_PATH_MAX limit, breaking SSH connections.

## Best solution

Move this issue to https://github.com/microsoft/vscode-remote-release so the Remote-SSH team can shorten the socket filename (e.g. truncate the hash or use a shorter prefix) to stay under UNIX_PATH_MAX on macOS.
