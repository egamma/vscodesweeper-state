# Issue #327424 — MCP tools silently dropped from agent requests on BYOK when signed out of GitHub Copilot

[https://github.com/microsoft/vscode/issues/327424](https://github.com/microsoft/vscode/issues/327424)

## Summary

Confirmed in source: when embeddings are unavailable (no Copilot token on BYOK), `computeToolGroupings` returns empty arrays for MCP tool groups, silently dropping all MCP/extension tools from agent requests when the total tool count exceeds 64. No fix on current main.

## Change summary

MCP tools are silently excluded from agent requests in BYOK mode without Copilot sign-in because virtual-tools grouping depends on Copilot-hosted embeddings that are unavailable without a token.

## Best solution

Add a fallback path in `_generateEmbeddingBasedGroups` (or `_processToolset`) so that when `computeToolGroupings` returns zero groups due to missing embeddings, the MCP tools are still included — either ungrouped, or grouped into a single virtual tool with an LLM-generated summary (the `allocatedSlots === 1` path already works without embeddings). The fix lives in `extensions/copilot/src/extension/tools/common/virtualTools/virtualToolGrouper.ts`.
