# Issue #298145 — Customizations window should offer "Generate workspace instructions" when missing

[https://github.com/microsoft/vscode/issues/298145](https://github.com/microsoft/vscode/issues/298145)

## Summary

Keep open: the Instructions section offers AI generation, but it starts the on-demand instruction flow rather than workspace initialization. The overview now provides an /init launcher, which partially addresses discoverability without establishing that the requested missing-workspace-instructions experience is complete.

## Change summary

Offer workspace-instruction generation directly from the Customizations view when workspace instructions are missing.

## Best solution

Make workspace initialization discoverable from the Instructions section when workspace instructions are absent, while preserving separate manual and on-demand instruction creation. Reuse the existing workspace-generation capability rather than introducing another generation workflow.
