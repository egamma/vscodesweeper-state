# Issue #73780 — Add more flexible Decorations or editor overlays for extensions

[https://github.com/microsoft/vscode/issues/73780](https://github.com/microsoft/vscode/issues/73780)

## Summary

A substantial extension API gap remains on current main: decorations cannot provide arbitrary, position-anchored overlays without affecting editor layout. With 521 upvotes and a Backlog milestone, this established request should remain open.

## Change summary

Provide extensions with flexible, non-layout-affecting editor decorations or overlays anchored to document positions and ranges.

## Best solution

Design a constrained editor overlay or expanded decoration API in the editor rendering and extension API layers, supporting blank lines, multi-line geometry, stable range tracking, and non-layout-affecting primitives while preserving virtualization and rendering performance.
