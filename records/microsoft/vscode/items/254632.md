# Issue #254632 — Filter comments only accepts filenames and not repo relative paths

[https://github.com/microsoft/vscode/issues/254632](https://github.com/microsoft/vscode/issues/254632)

## Summary

Still reproduces on main: the Comments view filter only matches against basename, not the full path. An open PR (#281939) exists to address this but has not been merged.

## Change summary

The Comments view filter box only matches against filenames (basename), ignoring repo-relative paths like `src/sentinel.c`, making it impossible to disambiguate files with the same name in different directories.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/281939 (or a human-authored equivalent) which adds a fallback to full-path matching in `commentsTreeViewer.ts` when the basename filter doesn't match. The fix is small and localized to `filterResourceMarkers`.
