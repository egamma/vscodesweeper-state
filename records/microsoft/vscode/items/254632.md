# Issue #254632 — Filter comments only accepts filenames and not repo relative paths

[https://github.com/microsoft/vscode/issues/254632](https://github.com/microsoft/vscode/issues/254632)

## Summary

The Comments view still matches resource filters against filenames only, so repository-relative queries cannot select the intended file. Keep this open while the existing path-filtering PR is reviewed; it has not merged.

## Change summary

Allow Comments view filtering by repository-relative paths to distinguish identically named files.
