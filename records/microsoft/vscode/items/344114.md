# Issue #344114 — Local BYOK agents spin through repeated tool turns

[https://github.com/microsoft/vscode/issues/344114](https://github.com/microsoft/vscode/issues/344114)

## Summary

Keep open for diagnosis of the local BYOK regression: the reporter documents repeated successful tool calls and confirms that reverting to 1.139.1 restores task completion. Current source distinguishes empty replies to user messages from empty tool continuations, so its existing empty-response handling does not establish that this incident is fixed.

## Change summary

Local llama.cpp/Qwen agent sessions repeatedly execute equivalent tool requests without completing the task and can finish silently after an empty model response.

## Best solution

Identify the regression in the Copilot BYOK request/history and SDK execution path, preserving legitimate long-running tool workflows while preventing the demonstrated no-progress cycle. Establish an explicit incomplete outcome for the reported empty terminal response without treating every valid empty tool continuation as an error.
