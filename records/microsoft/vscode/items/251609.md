# Issue #251609 — Add option for disabling middle mouse button scroll-lock

[https://github.com/microsoft/vscode/issues/251609](https://github.com/microsoft/vscode/issues/251609)

## Summary

The requested hold-only scrolling mode remains unavailable; keep the existing under-discussion classification while the editor owner decides whether to offer it. Four upvotes and an expired Backlog Candidates window do not independently justify a cleanup close.

## Change summary

Allow middle-button scrolling without entering a persistent scrolling session when the button is released.

## Best solution

Offer an editor scrolling mode in which releasing the middle button always ends the session, while preserving existing behavior for users who prefer click-lock. The editor owner still needs to settle the thread's setting-versus-default question.
