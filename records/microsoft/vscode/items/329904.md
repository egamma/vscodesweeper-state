## Change summary

The 'imports a prepared model directory and creates scanner metadata' unit test intermittently fails on Windows CI, apparently due to transient filesystem locks when replacing an existing model directory during cleanup.

## Best solution

Land https://github.com/microsoft/vscode/pull/329972, which retries removal of the previous model backup directory in `installPreparedModel`/`replaceDirectory` (src/vs/platform/localTranscription/node/foundryLocalModelImport.ts) to tolerate transient Windows file locks during backup cleanup.
