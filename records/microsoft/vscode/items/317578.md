# Issue #317578 — Delayed Python environment auto-activation can corrupt active terminal input

[https://github.com/microsoft/vscode/issues/317578](https://github.com/microsoft/vscode/issues/317578)

## Summary

Multiple reporters confirm delayed Python activation interfering with terminal input and running programs. Keep the report alive by transferring it to the VS Code-owned Python tracker; neither a completed fix nor a same-scope canonical has been established.

## Change summary

Delayed Python environment auto-activation can overwrite interactive input, interrupt running commands, or inject activation text into another program.

## Best solution

Automatic Python activation should finish before user interaction or refrain from sending commands once the terminal is occupied. The Python extension owners should investigate both legacy activation and delegation to Python Environments, preserving intentional terminal command execution rather than globally restricting the sendText API.
