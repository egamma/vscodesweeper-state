## Summary

Verified duplicate: the older open canonical issue explicitly tracks unsent Agents window input not remaining with its originating new or existing session when users switch chats.

## Change summary

Preserve unsent chat text when switching to another Agents window chat and returning.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/281434 and implement session-owned drafts so each new or existing session restores its own unsent text and attachments after navigation or reopening.
