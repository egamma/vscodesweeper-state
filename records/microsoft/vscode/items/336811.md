# Issue #336811 — Add model switched to for internal Auto survey

[https://github.com/microsoft/vscode/issues/336811](https://github.com/microsoft/vscode/issues/336811)

## Summary

Team-authored internal telemetry enhancement to the Copilot chat model feedback survey; the wire contract exists on main but doesn't yet capture which model the user switched to after leaving Auto, so this is a real, open gap — not evidence for any close.

## Change summary

Extend the internal Auto-model feedback survey telemetry to also record which model/model-family the user switched to, not just that they switched away from Auto.

## Best solution

Add a field (e.g. `switchedToModelId`) to `IChatModelFeedbackSurveyTelemetryEvent` alongside the existing `trigger: 'modelSwitchedAway'` case, populated where the switch-away trigger fires, and forwarded through the matching contract in the Copilot extension's `chatModelFeedbackSurveyForwardingContrib.ts`.
