# Issue #336811 — Add model switched to for internal Auto survey

[https://github.com/microsoft/vscode/issues/336811](https://github.com/microsoft/vscode/issues/336811)

## Summary

Fresh, team-authored telemetry request (also protected by the team-authored keep-open rule) asking to capture which model a user switched to when the Auto feedback survey's `modelSwitchedAway` trigger fires; confirmed on main that `toModelId` is currently received but discarded, only used for an eligibility check.

## Change summary

Record which model the user switched to when the internal Auto feedback survey is triggered by 'switched away from Auto', not just that a switch happened.

## Best solution

Thread `toModelId` from `ChatModelFeedbackSurveyPromptContribution` through `notifyModelSwitchedAway` / `beginPrompt` into the survey state and add a `switchedToModelId` (escaped) field to `IChatModelFeedbackSurveyTelemetryEvent`, populated only for the `modelSwitchedAway` trigger.
