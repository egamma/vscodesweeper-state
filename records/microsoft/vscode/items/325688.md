# Issue #325688 — Multiple extension recommendation modals stack and overlap when workbench.editor.useModal is enabled

[https://github.com/microsoft/vscode/issues/325688](https://github.com/microsoft/vscode/issues/325688)

## Summary

Fixed on current main: concurrent modal-editor creation now reuses one in-flight singleton, preventing extension recommendation editors from producing stacked modal parts.

## Change summary

Opening a workspace with multiple recommended extensions could create overlapping modal editors when workbench.editor.useModal was enabled.
