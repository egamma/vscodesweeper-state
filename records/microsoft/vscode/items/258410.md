[https://github.com/microsoft/vscode/issues/258410](https://github.com/microsoft/vscode/issues/258410)

## Summary

The reported cross-resource authentication reuse is fixed on current main: provider selection now checks the full protected-resource URI as well as the authorization server. Propose closing as completed with the concrete fixing commit.

## Change summary

Authenticate two MCP resources sharing a host and authorization server independently, sending each resource's own identifier rather than reusing the first resource's session.

## Best solution

Keep the resource-specific provider selection implemented in commit 3fe7649e8a92bf62ab62aa6ed97d6684b5c99004; it prevents Product2 from selecting Product1's provider and retained resource metadata.
