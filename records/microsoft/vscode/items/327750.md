# Issue #327750 — Proposal: add an extension events for symbol rename (onDidRenameSymbol / onWillRenameSymbol)

[https://github.com/microsoft/vscode/issues/327750](https://github.com/microsoft/vscode/issues/327750)

## Summary

A real extension API gap remains: stable document-change events expose raw edits but cannot identify a symbol rename. Route this API proposal for design rather than closing it.

## Change summary

Expose extension events before and after a successful Rename Symbol operation.

## Best solution

Have the API and editor owners decide whether to finalize a typed rename reason on `TextDocumentChangeEvent` or introduce operation-level rename events. The API should reliably expose the old and new names and multi-document completion semantics without treating unrelated workspace edits as renames.

## Evidence
