# Issue #186022 — EditorContextKeys.inDiffEditor should be EditorContextKeys.isInDiffEditor

[https://github.com/microsoft/vscode/issues/186022](https://github.com/microsoft/vscode/issues/186022)

## Summary

Still open on main: two separate context keys ('inDiffEditor' via EditorContextKeys and 'isInDiffEditor' set directly) coexist with inconsistent naming. The duplication and naming mismatch have not been resolved. Team-authored debt item — keeping open.

## Change summary

Two diff-editor context keys ('inDiffEditor' and 'isInDiffEditor') coexist with inconsistent naming; one should be consolidated into the other.

## Best solution

Consolidate onto a single context key — likely rename `EditorContextKeys.inDiffEditor` to use the string `'isInDiffEditor'` (matching the value set by `diffEditorWidget.ts`) and update the two files that reference `EditorContextKeys.inDiffEditor` (`codeEditorWidget.ts`, `diffEditorCommands.ts`). Alternatively, remove the raw `'isInDiffEditor'` key and route all usages through `EditorContextKeys.inDiffEditor`. Either way, ensure all ~16 `ContextKeyExpr.has('isInDiffEditor')` call sites in `commands.ts` and `diffEditor.contribution.ts` go through the shared constant.
