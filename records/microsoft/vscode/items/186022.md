# Issue #186022 — EditorContextKeys.inDiffEditor should be EditorContextKeys.isInDiffEditor

[https://github.com/microsoft/vscode/issues/186022](https://github.com/microsoft/vscode/issues/186022)

## Summary

The naming and ownership ambiguity remains on current main: the diff widget sets `isInDiffEditor`, while its child code editors set `inDiffEditor`, and both keys have active consumers. This team-authored debt has no issue-referencing fix, so it should remain open pending a compatibility decision.

## Change summary

Resolve the overlapping `isInDiffEditor` and `inDiffEditor` context keys and give the surviving semantics a consistent typed declaration.

## Best solution

Define whether the canonical key represents the outer diff-widget context or an individual code editor embedded in a diff, then consolidate or clearly document the keys while preserving extension keybinding compatibility.
