# Issue #228528 — [json] builtin json formatter doesn't support format-on-paste

[https://github.com/microsoft/vscode/issues/228528](https://github.com/microsoft/vscode/issues/228528)

## Summary

The bug remains on current main: format-on-paste forwards only the exact inserted range, which does not provide the built-in JSON formatter enough surrounding context to indent the pasted line. A maintainer confirmed that the fix belongs in the paste path, and the only attempted fix was closed unmerged.

## Change summary

Make editor format-on-paste correctly indent pasted JSON content using its surrounding document context.

## Best solution

Adjust the editor's format-on-paste range handling so range formatters receive enough context to format an insertion correctly, while leaving explicit Format Selection semantics unchanged.
