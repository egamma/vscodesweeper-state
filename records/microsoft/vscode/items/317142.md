# Issue #317142 — I'd expect a single attachment when I use `add element to chat`

[https://github.com/microsoft/vscode/issues/317142](https://github.com/microsoft/vscode/issues/317142)

## Summary

Valid polish request: "Add Element to Chat" currently creates two separate attachments (element data + screenshot) when `attachImages` is enabled; the reporter expects a single combined attachment. Still present on main.

## Change summary

"Add Element to Chat" in the integrated browser produces two separate chat attachments (element context and element screenshot) instead of one unified attachment.

## Best solution

Combine the element context and screenshot into a single chat attachment entry in `_attachElementDataToChat` (in `src/vs/workbench/contrib/browserView/electron-browser/features/browserEditorChatFeatures.ts`), so the user sees one cohesive attachment rather than two.
