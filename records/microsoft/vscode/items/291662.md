# Issue #291662 — Export/Save Full Copilot Chat History

[https://github.com/microsoft/vscode/issues/291662](https://github.com/microsoft/vscode/issues/291662)

## Summary

A real bulk-export gap remains: current VS Code exports only the focused chat session, not the complete history across sessions. This older, re-reviewed request should remain open and route to the chat area rather than being folded into the younger bulk-export report.

## Change summary

Add a built-in command to export current and previous Copilot Chat sessions together, preserving readable formatting and rich content where possible.

## Best solution

Treat this as the canonical product decision for bulk chat-history export and consolidate the newer https://github.com/microsoft/vscode/issues/312058 request here. If accepted, the chat area should define the session scope, output format, and treatment of attachments and rendered content before implementation.
