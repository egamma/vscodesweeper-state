# Issue #172072 — Source control buttons should not shift after calculating errors/problems

[https://github.com/microsoft/vscode/issues/172072](https://github.com/microsoft/vscode/issues/172072)

## Summary

The older, verified-open report tracks the same observable problem: asynchronously arriving SCM decorations move inline actions and cause unintended clicks. Consolidate this report there, preserving its diagnostics-triggered example and the maintainers' design suggestions.

## Change summary

Keep Source Control inline actions stationary when asynchronous file decorations appear or change.

## Best solution

Consolidate the stable-action-layout work in https://github.com/microsoft/vscode/issues/167333, carrying forward this report's problems-count trigger and the discussion of reserving decoration space versus hiding decorations while actions are visible.
