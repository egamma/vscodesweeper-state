# Issue #172072 — Source control buttons should not shift after calculating errors/problems

[https://github.com/microsoft/vscode/issues/172072](https://github.com/microsoft/vscode/issues/172072)

## Summary

Consolidate with the older, verified open report of asynchronous SCM decorations shifting inline actions and causing misclicks. It meets the stronger re-review duplicate bar: the same observable symptom in the same view, not merely related design work.

## Change summary

Keep Source Control stage and discard buttons stationary when asynchronously calculated file decorations appear.

## Best solution

Resolve the stable-action layout in https://github.com/microsoft/vscode/issues/167333, carrying over this report's problems-count trigger and the existing design discussion about reserving space or hiding decorations while actions are visible.
