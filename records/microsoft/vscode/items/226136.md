# Issue #226136 — Git - wrong handling of .gitignore that contains the folder name

The directory-scoping defect remains in current main. Keep this open while the directly linked fix candidate, PR 313021, is reviewed and completed.

## Change summary

A pattern matching the containing directory's name in a nested .gitignore incorrectly hides that directory rather than only matching descendants.

## Best solution

Review https://github.com/microsoft/vscode/pull/313021 and land a fix that confines each ignore file's patterns to descendants of its normalized directory. Include regression coverage for the containing directory, its same-named child, and content updates.
