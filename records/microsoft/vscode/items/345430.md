The reported unrequested model-selection change warrants investigation, but the report does not distinguish a changed input picker from Fusion displaying its chosen execution model. Request the affected chat surface and a before/after capture rather than closing this as billing feedback or intentional routing.

## Change summary

Copilot Fusion reportedly changes the active chat selection to Claude Opus 5 after completing a prompt, affecting subsequent requests.
