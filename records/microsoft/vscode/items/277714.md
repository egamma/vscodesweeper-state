# Issue #277714 — Global search doesn't always look in open editors anymore

[https://github.com/microsoft/vscode/issues/277714](https://github.com/microsoft/vscode/issues/277714)

## Summary

Keep open: the supplied steps suffice to retest missing results from inactive, out-of-workspace editors. Current source still intends to include those editors, but inspection did not establish the reported failure or a fixing commit since version 1.106.0.

## Change summary

Global search omits matches in an inactive editor outside the workspace when no workspace file contains the search term.

## Best solution

Ensure out-of-workspace editor matches appear independently of editor focus and workspace matches. Reproduce the three reported cases, then identify whether results disappear during collection, asynchronous delivery, or search-tree presentation.
