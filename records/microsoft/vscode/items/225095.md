# Issue #225095 — Inline diff not indenting wrapped lines correctly

[https://github.com/microsoft/vscode/issues/225095](https://github.com/microsoft/vscode/issues/225095)

## Summary

The inline deleted-line renderer still discards continuation indentation calculated by the wrapping engine. Keep this correctly routed bug open; the source identifies a bounded rendering defect.

## Change summary

Wrapped removed lines in a narrow inline diff should retain the configured continuation indentation.

## Best solution

Make inline deleted-line rendering honor the same wrapping projection semantics as normal editor lines, preserving highlighting, width calculations, and model-position mapping.
