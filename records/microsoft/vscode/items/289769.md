# Issue #289769 — Cloud agent does not create PR in correct repository

[https://github.com/microsoft/vscode/issues/289769](https://github.com/microsoft/vscode/issues/289769)

## Summary

Keep open to resolve prompt-directed repository selection. Current source supports explicitly choosing another repository, but does not use the repository named in the prompt to select the task destination; the maintainer's suggested picker fix does not establish that this request was completed.

## Change summary

Recognize when a Cloud agent prompt targets a repository other than the open workspace and resolve the intended destination before creating the task.

## Best solution

Make a prompt naming a different repository lead to a clearly resolved destination before Cloud agent execution. First decide whether that should select the named repository or ask for confirmation when it conflicts with the current repository selection.
