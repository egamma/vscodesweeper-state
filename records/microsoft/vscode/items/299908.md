# Issue #299908 — Extensions list takes long time to open.

[https://github.com/microsoft/vscode/issues/299908](https://github.com/microsoft/vscode/issues/299908)

## Summary

The report provides useful evidence of a network-dependent Extensions delay, but the emergency-alert timeout is not demonstrably its cause. Request confirmation on a current build and diagnostics identifying which request delays the list.

## Change summary

Opening the Extensions view takes approximately 20 seconds with automatic IPv6 configuration on macOS, even with installed extensions disabled.

## Best solution

Keep installed-extension browsing responsive when network requests stall, without weakening extension safety checks. First identify the blocking request in the Extensions query path and distinguish it from the independently running emergency-alert fetch.
