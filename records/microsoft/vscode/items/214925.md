# Issue #214925 — feat: Add sidebar event listener or get detail apis

[https://github.com/microsoft/vscode/issues/214925](https://github.com/microsoft/vscode/issues/214925)

## Summary

Keep this accepted Backlog request open: it has 22 community upvotes, remains an extension API gap on current main, and is the older canonical issue for later reports requesting the same layout-visibility state.

## Change summary

Expose extension APIs for observing sidebar visibility and determining whether a particular sidebar view or container is currently displayed.

## Best solution

Define the intended public contract for workbench-part versus individual view-container visibility, then bridge the accepted state and events from the workbench layout/view services to the extension host. Consolidate https://github.com/microsoft/vscode/issues/321409 and its open implementation attempt https://github.com/microsoft/vscode/pull/321414 onto this older canonical before proceeding.
