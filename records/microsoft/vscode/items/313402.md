# Issue #313402 — Include active branch directory in Copilot context.

[https://github.com/microsoft/vscode/issues/313402](https://github.com/microsoft/vscode/issues/313402)

## Summary

Keep open as a feature request: existing workspace-path context and Git tools do not establish that Copilot receives an explicit association between the active repository and its directory. No verified older canonical or concrete implementing commit was found.

## Change summary

Include the active Git repository's directory alongside its repository and branch metadata in Copilot context.

## Best solution

Expose the active repository's directory explicitly in Copilot's repository context, including when it differs from a workspace root. Define how SCM selection and session working-directory selection interact so the supplied path identifies the intended repository consistently.
