# Issue #289048 — commit & push button renders source control unusable when no remotes

[https://github.com/microsoft/vscode/issues/289048](https://github.com/microsoft/vscode/issues/289048)

## Summary

The busy state matches the existing flow: Commit & Push waits for the no-remotes warning to be dismissed or acted on. A maintainer reviewed the same symptom previously and retained this behavior; propose closing as designed.

## Change summary

Commit & Push leaves Source Control showing a busy state in a repository without remotes.

## Best solution

Keep the existing no-remotes warning and Add Remote flow. Dismissing the warning releases the pending operation; use the Commit dropdown option for local-only commits.

  > Thanks for the report.
