# Issue #308616 — Running benchmark results in a lot of checking terminal output

[https://github.com/microsoft/vscode/issues/308616](https://github.com/microsoft/vscode/issues/308616)

## Summary

Keep open: current terminal tools already advertise completion notifications and discourage polling, but timeout and idle-silence results still explicitly encourage repeated output checks. This team-authored request has no verified issue-linked fix or eligible canonical duplicate.

## Change summary

Tell the agent that a benchmark command remains running and will announce completion, avoiding unnecessary terminal-output polling unless blocking is necessary.

## Best solution

Make terminal-tool guidance consistently distinguish waiting for ordinary command completion from handling actual input prompts, preserving necessary blocking workflows. Confirm that a long-running benchmark no longer produces repeated 'Checking terminal output' calls.
