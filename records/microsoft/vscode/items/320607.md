# Issue #320607 — VS Code does not respond when I save a file

[https://github.com/microsoft/vscode/issues/320607](https://github.com/microsoft/vscode/issues/320607)

## Summary

This is a configuration/support question: explicit saves intentionally await the configured code-action providers, and the displayed progress message links directly to the relevant setting.

## Change summary

Avoid waiting for several extension-provided code actions whenever a file is saved.

## Best solution

Keep the save-participant behavior and configure `editor.codeActionsOnSave` to disable unnecessary actions, or disable the slow providers; investigate separately only if the UI still freezes with save actions disabled.
