# Issue #318553 — Run and debug view feels kind of broken on small views

[https://github.com/microsoft/vscode/issues/318553](https://github.com/microsoft/vscode/issues/318553)

Keep this as the canonical narrow-layout debug-header bug: independent reports confirm the configuration selector becomes obscured, and maintainers have consolidated those reports here. Current source still allows the launcher to shrink while preserving secondary actions; no qualifying fixing commit was established.

## Change summary

Keep launch configurations discoverable and usable when the Run and Debug sidebar is narrow.

## Best solution

Make the Run and Debug header prioritize selecting and starting a launch configuration over secondary chrome at narrow widths. Retain access to configuration editing through the existing toolbar customization or overflow mechanisms.
