# Issue #350744 — P2 Git: every changed file costs ~3 workspace.getConfiguration('git') calls per refresh (Resource.command, Repository.onFileChange) – up to ~850 ms extension host CPU for 2k changes

[https://github.com/microsoft/vscode/issues/350744](https://github.com/microsoft/vscode/issues/350744)

## Summary

The repeated configuration reads remain directly traceable on main. Keep this focused Git performance issue open; the existing git area label is correct.

## Change summary

Eliminate per-resource and per-file-event configuration construction during Git refreshes without changing configuration behavior.

## Best solution

Git command resolution and automatic refresh should reuse effective configuration values across bulk work while promptly respecting configuration changes. Keep the optimization within the built-in Git extension rather than changing the shared configuration API.
