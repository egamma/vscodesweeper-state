Already fixed on main: the 4px bottom margin on spans in markdown hovers was entirely removed in commit 200701b2f39, which shipped in 1.107.0. The root cause CSS rule no longer exists.

## Change summary

All <span> tags in markdown hovers received a 4px bottom margin causing stacking margins in nested spans and unwanted gaps between vertically stacked spans.
