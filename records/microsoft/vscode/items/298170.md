# Issue #298170 — Change Menu Terminology from 'Worktree' to 'Session' for Background (CopilotCLI) Sessions

[https://github.com/microsoft/vscode/issues/298170](https://github.com/microsoft/vscode/issues/298170)

## Summary

The user-facing menu labels for the three main actions (Open in New Window, Open in Terminal, Resume in Terminal) appear to already use 'Session' in the NLS strings on current main, but the related PR in vscode-copilot-chat is still open and some secondary strings (e.g. 'Commit File to Worktree', the provider description) still reference 'worktree'. Keeping open as the work may not be fully complete.

## Change summary

Rename menu items from 'Worktree' to 'Session' for background Copilot CLI sessions to reflect that sessions can use either worktree or workspace isolation.

## Best solution

Verify with the related PR (https://github.com/microsoft/vscode-copilot-chat/pull/4060) whether remaining 'Worktree' references in secondary strings and the provider description should also be updated. Close once the full rename is landed and confirmed.
