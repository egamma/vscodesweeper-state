# Issue #312107 — Copilot Autopilot (Preview) mode answers its own questions without waiting for user input

[https://github.com/microsoft/vscode/issues/312107](https://github.com/microsoft/vscode/issues/312107)

## Summary

Autopilot answering blocking questions is now explicitly documented and presented in-product as intentional autonomous behavior. The requested combination of model-reviewed tool calls and interactive questions is provided by Agent mode with Assisted permissions rather than Autopilot.

## Change summary

Make Autopilot pause for explicit user answers instead of answering clarification questions autonomously.

## Best solution

Keep Autopilot autonomous and direct users who want model-reviewed tool approvals with interactive participation to Agent mode with Assisted permissions.
