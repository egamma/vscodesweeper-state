# Issue #312107 — Copilot Autopilot (Preview) mode answers its own questions without waiting for user input

[https://github.com/microsoft/vscode/issues/312107](https://github.com/microsoft/vscode/issues/312107)

## Summary

Autopilot intentionally treats the user as unavailable and answers blocking questions so work can continue autonomously. The desired combination is already available through Interactive mode with Assisted permissions, which uses an LLM judge for tool approvals while still surfacing questions to the user.

## Change summary

Make Autopilot pause on `askQuestion` calls instead of automatically telling the agent to use its best judgment.

## Best solution

Keep Autopilot's documented autonomous semantics. Users who want model-reviewed tool calls but interactive questions should select Interactive mode with Assisted permissions, using the separate Mode and Permissions controls.
