[https://github.com/microsoft/vscode/issues/77492](https://github.com/microsoft/vscode/issues/77492)

## Summary

Team-authored feature request about TextEditorDecorations persisting when pasting over decorated text. No fixing commit references this issue, and the decoration stickiness behavior during paste/replace operations remains unchanged on current main — the issue is still valid.

## Change summary

When pasting over text that has TextEditorDecorations (e.g. semantic tokens), the decorations carry over to the newly pasted text instead of being cleared.

## Best solution

Adjust decoration range handling in the editor model (likely `src/vs/editor/common/model/textModel.ts` or `src/vs/editor/common/model/intervalTree.ts`) so that when text is fully replaced by a paste operation, decorations applied to the replaced range are cleared or truncated rather than growing to cover the new text. The stickiness mode used by semantic token decorations may need to be reconsidered for replace-style edits.
