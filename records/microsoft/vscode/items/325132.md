# Issue #325132 — Agents window should show and continue local Copilot Chat Agent sessions

[https://github.com/microsoft/vscode/issues/325132](https://github.com/microsoft/vscode/issues/325132)

## Summary

Current `main` already ships a `LocalChatSessionsProvider` (id `local-chat`) registered by default in the Agents Window, which surfaces, restores, and lazily continues local in-process Chat view/sidebar Copilot Agent sessions — this is exactly what the issue asks for, so it can be closed as implemented.

## Change summary

Local (non-CLI) Copilot Agent sessions started in the Chat view aren't visible/continuable in the Agents window, splitting the two surfaces into separate products.

## Best solution

Treat as implemented on main: the local chat sessions provider (`src/vs/sessions/contrib/providers/localChatSessions/browser/localChatSessionsProvider.ts`) already does the migration/visibility/continuation work described in the issue, enabled by default via `sessions.chat.localAgent.enabled`. Ask the reporter to confirm on an up-to-date build.
