# Issue #173019 — SCM - add support for horizontal scrolling

[https://github.com/microsoft/vscode/issues/173019](https://github.com/microsoft/vscode/issues/173019)

## Summary

Horizontal scrolling remains unavailable in the SCM resource tree despite the global setting. Keep this accepted Backlog request open: the current source confirms the gap, and the related issues do not qualify as duplicate canonicals.

## Change summary

Support horizontal scrolling in the SCM file list when workbench.list.horizontalScrolling is enabled.

## Best solution

Allow SCM resource rows to expose overflowing filenames and paths through opt-in horizontal scrolling, while preserving usable commit-input and action controls. The SCM owner should assess the mixed-row layout and performance implications before implementation.
