# Issue #338691 — Clicking enter on chat opens a remote picker

[https://github.com/microsoft/vscode/issues/338691](https://github.com/microsoft/vscode/issues/338691)

## Summary

Team-authored UX feedback (also independently protected from judgment closes) about the chat delegation/session-target picker's default Enter behavior — the reporter wants Local to always be the Enter-accepted default with remote targets surfaced via hover/secondary interaction instead of being reachable via a plain Enter. No fix commit exists yet and the design direction isn't settled, so this stays open for design discussion.

## Change summary

Pressing Enter in the chat session/delegation picker can select a remote (Background/Cloud) target instead of always defaulting to the local chat, which feels surprising given the '+' new-chat action only offers local chats.

## Best solution

A maintainer should decide the intended default-accept semantics for `DelegationSessionPickerActionItem`/`SessionTypePickerActionItem` (src/vs/workbench/contrib/chat/browser/widget/input/delegationSessionPickerActionItem.ts and sessionTargetPickerActionItem.ts) — e.g. always default Enter to `_getDefaultSessionType()` (Local) and require an explicit action (hover/right-arrow/click) to pick a remote target — then adjust the action-widget dropdown accordingly.
