# Issue #196373 — Notebook cell: shift + enter scroll my cell out of view

[https://github.com/microsoft/vscode/issues/196373](https://github.com/microsoft/vscode/issues/196373)

## Summary

Keep open: the request is for stable scrolling by default, not merely an available setting. Current main still defaults to revealing the next cell, so the reporter's clarification remains relevant and needs a notebook UX decision.

## Change summary

Avoid scrolling the executed notebook cell and its output out of view by default when Shift+Enter selects the following cell.

## Best solution

Agree on default Shift+Enter scrolling that preserves the user's execution context while retaining next-cell selection. The existing no-scroll option provides a workaround, but does not settle the requested default behavior.
