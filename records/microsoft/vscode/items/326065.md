# Issue #326065 — Improve inaccessible plugin marketplace errors and private GitHub authentication

[https://github.com/microsoft/vscode/issues/326065](https://github.com/microsoft/vscode/issues/326065)

## Summary

Valid, well-specified UX request: confirmed in source that plugin marketplace clone/pull failures still surface the raw git error string (including command/stderr) with no classification of missing-repo vs. authentication/access failures, and no sign-in action is offered.

## Change summary

Improve the error notification shown when a private/inaccessible GitHub-hosted plugin marketplace fails to clone/pull, distinguishing auth/access failures and offering a GitHub sign-in/retry action instead of the raw git error.

## Best solution

In agentPluginRepositoryService.ts (_cloneRepository/pullRepository) and localGitService.ts's clone/pull exec error handling, classify git clone/pull failures (e.g. exit code 128 + 'Repository not found' vs. network vs. invalid ref) into typed errors, move the raw command/stderr behind the existing 'Show Git Output' action, and add a GitHub-authentication retry action for GitHub HTTPS sources.
