# Issue #323547 — groups don't follow sorting preference

[https://github.com/microsoft/vscode/issues/323547](https://github.com/microsoft/vscode/issues/323547)

## Summary

Keep open for the Agents Window design discussion. Current main intentionally keeps custom groups in user-managed order while applying the sorting preference to sessions, and a maintainer confirmed that this was deliberate but remains under consideration.

## Change summary

Make custom groups follow the selected created-time or updated-time sorting preference instead of retaining an independent manual order.

## Best solution

Settle whether the sorting control governs session rows only or also custom-group sections. Preserve manual group ordering if that remains the intended model, but clarify the control's scope in the UI; otherwise define a stable group sort key before changing the behavior.
