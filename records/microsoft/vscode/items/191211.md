# Issue #191211 — Suggest Widget: Don't replace next word when accepting with trigger character

[https://github.com/microsoft/vscode/issues/191211](https://github.com/microsoft/vscode/issues/191211)

## Summary

Keep open: current completion settings still cannot preserve replacement on explicit acceptance while avoiding replacement on commit-character acceptance. The older related issues cover different observable problems, and this team-authored request should not receive a judgment close.

## Change summary

Allow commit-character acceptance to preserve the following word while explicit suggestion acceptance retains replace-mode behavior.

## Best solution

Support an opt-in acceptance-sensitive insert/replace policy in the editor suggest configuration and controller, preserving existing insert and replace modes. Settle the public setting contract before implementation.
