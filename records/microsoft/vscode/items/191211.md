# Issue #191211 — Suggest Widget: Don't replace next word when accepting with trigger character

[https://github.com/microsoft/vscode/issues/191211](https://github.com/microsoft/vscode/issues/191211)

## Summary

A real capability gap remains: commit-character acceptance still uses the configured replace range. This team-authored feature request must remain open absent an explicitly linked implementation or verified duplicate.

## Change summary

Allow suggestions accepted with commit characters such as `.` to preserve text after the cursor while explicit acceptance continues replacing it.

## Best solution

Decide whether commit-character acceptance should always use the insertion range or whether `editor.suggest.insertMode` should gain a third mode, then implement the distinction in the suggest controller with focused acceptance tests.
