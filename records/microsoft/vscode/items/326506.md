# Issue #326506 — Add "Scroll By Page" choice for terminal pane

[https://github.com/microsoft/vscode/issues/326506](https://github.com/microsoft/vscode/issues/326506)

## Summary

The requested scrollbar-click setting is not exposed on current main; existing terminal page-scroll commands provide only a keyboard alternative. Keep this request under discussion: no open canonical was verified, and the related closed report does not clearly establish a decision against adding an optional setting.

## Change summary

Add an option for terminal scrollbar-track clicks to scroll one page instead of jumping to the clicked position.

## Best solution

Have the terminal owner decide whether to expose optional page-by-page scrollbar-track scrolling, consistent with the editor and workbench lists while preserving the existing default. The existing page-scroll commands remain an alternative, not fulfillment of the mouse interaction request.
