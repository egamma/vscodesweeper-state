# Issue #326506 — Add "Scroll By Page" choice for terminal pane

[https://github.com/microsoft/vscode/issues/326506](https://github.com/microsoft/vscode/issues/326506)

## Summary

Valid feature request: the terminal's scrollbar (rendered by xterm.js) lacks a 'scroll by page on track click' option, unlike the editor and workbench list scrollbars which expose this setting.

## Change summary

Request a 'Scroll By Page' setting for the terminal scrollbar track click behavior, matching the existing editor and workbench list settings.

## Best solution

Add a terminal-specific scrollByPage configuration that passes through to the xterm.js scrollbar, or investigate whether xterm.js supports this behavior natively. The setting would live alongside the existing `terminal.integrated.*` scroll settings in terminal configuration contributions.
