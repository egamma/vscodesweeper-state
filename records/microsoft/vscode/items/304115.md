# Issue #304115 — Searching for files in "Explorer" using CTRL + F

[https://github.com/microsoft/vscode/issues/304115](https://github.com/microsoft/vscode/issues/304115)

## Summary

The clarification establishes a valid Explorer discoverability request: VS Code already provides the requested file-and-folder overlay, but only through Ctrl+Alt+F/F3 and without the proposed magnifying-glass affordance or separate search scopes. Route this to the File Explorer area as a feature request rather than leaving it in info-needed.

## Change summary

Expose Explorer file-and-folder filtering through a visible search affordance and consider clearer separation from file-content search.

## Best solution

Make the existing Explorer find widget discoverable from the Explorer UI, while clearly distinguishing filename/folder filtering from Search view content queries. The File Explorer owner should decide whether that is a toolbar action, a persistent field, or a broader unified-search design.
