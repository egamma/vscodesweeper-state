# Issue #337555 — Support disabling Inline Chat

[https://github.com/microsoft/vscode/issues/337555](https://github.com/microsoft/vscode/issues/337555)

## Summary

Keep open as a feature request: existing settings hide individual affordances, but do not provide an independent Inline Chat disable switch while preserving other AI features. No verified older canonical owns the same request.

## Change summary

Provide a setting to disable Inline Chat and its entry points without disabling other AI features.

## Best solution

Decide on a coherent Inline Chat control covering its editor entry points while preserving other Chat functionality. Distinguish the Settings AI-search toggle from Inline Chat rather than coupling unrelated features solely because they share a sparkle icon.

  > Thanks for the request. Some parts already have separate controls: `inlineChat.affordance: "off"` hides the selection icon, and `inlineChat.fixDiagnostics: false` hides the diagnostic Fix action. `workbench.editor.empty.hint: "hidden"` hides the entire empty-editor hint.

## Evidence

- **Existing controls provide partial coverage:** src/vs/workbench/contrib/inlineChat/common/inlineChat.ts registers inlineChat.affordance with an 'off' value and inlineChat.fixDiagnostics with a false option. These hide the selection affordance and diagnostic Fix action respectively, but neither disables Inline Chat as a feature.
- **Remaining editor entry point:** StartSessionAction in src/vs/workbench/contrib/inlineChat/browser/inlineChatActions.ts registers inlineChat.start in the editor context menu and on Ctrl/Cmd+I. InlineChatEnabler in src/vs/workbench/contrib/inlineChat/browser/inlineChatSessionServiceImpl.ts derives availability from registered agents; the inspected path has no independent Inline Chat disable setting.
- **Empty editor workaround is broader than requested:** src/vs/workbench/contrib/codeEditor/browser/emptyTextEditorHint/emptyTextEditorHint.ts invokes inlineChat.start from its AI hint. Setting workbench.editor.empty.hint to 'hidden' suppresses the entire empty-editor hint, not selectively Inline Chat.
- **Settings sparkle is a separate feature:** src/vs/workbench/contrib/preferences/browser/settingsEditor2.ts implements updateAiSearchToggleVisibility using workbench.settings.showAISearchToggle and workbench.settings.enableNaturalLanguageSearch. This AI-search control is separate from Inline Chat and already has independent visibility controls.
