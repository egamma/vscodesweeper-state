# Issue #337555 — Support disabling Inline Chat

[https://github.com/microsoft/vscode/issues/337555](https://github.com/microsoft/vscode/issues/337555)

## Summary

A real configuration gap remains: current main offers controls for several individual inline-chat affordances, but no setting disables Inline Chat and all of its entry points while leaving other AI features enabled. No older open issue reports this same observable request closely enough to satisfy the stronger duplicate bar for this re-review.

## Change summary

Add a granular setting that disables Inline Chat and removes its editor affordances, commands, context-menu actions, diagnostic actions, and empty-editor entry point without using the global AI kill switch.

## Best solution

Provide one coherent Inline Chat enablement setting that hides and disables all Inline Chat entry points while preserving unrelated chat and completion features. Keep unrelated surfaces independently configurable, including the Settings AI-search toggle.

## Evidence

- **current configuration gap:** src/vs/workbench/contrib/inlineChat/common/inlineChat.ts registers `inlineChat.notebookAgent`, `inlineChat.defaultModel`, `inlineChat.affordance`, `inlineChat.fixDiagnostics`, and `inlineChat.askInChat`, but no overall Inline Chat enablement setting.
- **ungated entry point:** src/vs/workbench/contrib/inlineChat/browser/inlineChatActions.ts registers `inlineChat.start` in the command palette, editor context menu, and chat title menu using editor/provider context keys; there is no granular configuration condition that disables the command and menus.
- **partial existing controls:** `inlineChat.affordance: "off"` hides the selection sparkle, `inlineChat.fixDiagnostics: false` hides diagnostic Fix actions, `workbench.editor.empty.hint: "hidden"` hides the entire empty-editor hint, and `workbench.settings.showAISearchToggle: false` hides the separate Settings AI-search toggle. These controls do not disable Inline Chat as a capability or remove every entry point.
- **related issue distinction:** https://github.com/microsoft/vscode/issues/237819 is older and open but concerns removing or globally hiding Copilot integration, not selectively disabling Inline Chat while retaining other AI features. https://github.com/microsoft/vscode/issues/331704 concerns disabling Copilot as an Agent Host provider and explicitly excludes Inline Chat.
- **prior precedent is incomplete:** https://github.com/microsoft/vscode/issues/278944 was closed after pointing to `chat.disableAIFeatures`, but this report explicitly requires retaining other AI features, and the discussion there confirms the global switch also disables desired suggestions.
