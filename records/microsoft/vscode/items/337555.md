# Issue #337555 — Support disabling Inline Chat

[https://github.com/microsoft/vscode/issues/337555](https://github.com/microsoft/vscode/issues/337555)

## Summary

Reasonable, well-scoped request: today only the global `chat.disableAIFeatures` kill switch exists, with no dedicated setting to disable inline chat's sparkle/affordance icon, its context-menu entries, or the "Generate Code" new-file prompt on their own — confirmed by checking chatSettings.ts and the inline chat contribution files.

## Change summary

Add a setting to disable inline chat specifically (the sparkle affordance icon, context-menu entry, and new-file "Generate Code" prompt) without using the all-or-nothing global AI kill switch.

## Best solution

Add a scoped `chat.inlineChat.enabled`-style setting (or extend the existing chat settings surface) that gates the affordance widget (inlineChatAffordanceWidget.ts), the context-menu "Open Inline Chat"/"Fix" actions (inlineChatActions.ts), and the new-file "Generate Code" entry point, independent of the global disableAIFeatures switch.

## Vision fit

- **Fit:** aligned
- **Reason:** Giving users granular control to opt out of a specific always-on AI affordance while keeping other chat features fits the workbench/core-UX theme of settings fidelity and a lean, non-intrusive default experience.
- **Evidence:** Values: 'Out of the box, VS Code is a text editor: lightweight and fast' and durable theme 'Workbench & core UX — layout flexibility, profiles, settings fidelity'.

- **Trace:**
