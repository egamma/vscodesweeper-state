# Issue #124095 — Invalid syntax in web worker

[https://github.com/microsoft/vscode/issues/124095](https://github.com/microsoft/vscode/issues/124095)

## Summary

The Monaco editor worker architecture has been completely rewritten since this 2021 report — the AMD build system was replaced with native ESM (ESM merge in 2024–2025, commit 6b924c51528 and follow-ups), the worker entry points were split and redesigned (commit 46035d02960), and further Monaco webworker fixes landed in 2025 (commit a4495aaf9aa). The original problem — an inadvertent top-level export in a bundled AMD worker script — no longer applies to the current architecture.

## Change summary

Monaco's editor.worker.js contained a top-level export that was invalid in a web worker context when bundled with esbuild targeting ESM.

## Best solution

Close as not reproducible against the current Monaco editor architecture. The entire worker loading system has been redesigned around ESM; consumers should use the current Monaco editor npm package and its updated worker setup APIs.
