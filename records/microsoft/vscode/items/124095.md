# Issue #124095 — Invalid syntax in web worker

[https://github.com/microsoft/vscode/issues/124095](https://github.com/microsoft/vscode/issues/124095)

## Summary

The original file `src/vs/editor/editor.worker.ts` with the invalid top-level `export` was deleted and the entire worker infrastructure was refactored in commit 46035d02960. The issue is resolved on current main.

## Change summary

The editor web worker script (`editor.worker.ts`) had an `export` keyword on its `initialize` function, which is invalid syntax in a web worker context and caused errors when bundling with ESBuild for Monaco.

## Best solution

Keep the shipped refactor from commit 46035d02960 — the old `editor.worker.ts` no longer exists, replaced by a clean `editor.worker.start.ts` with proper worker architecture. No further change needed.
