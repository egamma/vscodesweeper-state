[https://github.com/microsoft/vscode/issues/304931](https://github.com/microsoft/vscode/issues/304931)

## Summary

The recurring Problems-panel diagnostics were fixed after this report by limiting prompt validation to files currently open in an editor. The same cross-platform symptom was tracked and verified resolved in https://github.com/microsoft/vscode/issues/304778.

## Change summary

Built-in Copilot agent files generated recurring unknown-tool diagnostics for `github/issue_read` in the Problems panel.

## Best solution
