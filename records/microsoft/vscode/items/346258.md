## Summary

Keep open: current source includes silent authentication and routed server activation, but neither establishes that the reported first-turn token delay is resolved. The supplied steps and timestamps suffice to retest without requesting more basic information.

## Change summary

The first Agent chat after successful MCP sign-in misses the server's tools because the agent host receives its OAuth token too late.

## Best solution

Ensure the requested OAuth server remains discoverable during first-turn authentication and becomes usable within that turn, with an actionable chat prompt when interaction is required. Diagnose the token hand-off and routing sequence before choosing between turn-level waiting and selected-server activation.
