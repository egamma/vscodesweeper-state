# Issue #302547 — When referencing memories in "Plan" mode it sometimes provides a relative path to the file instead of absolute path when working in Codespaces

[https://github.com/microsoft/vscode/issues/302547](https://github.com/microsoft/vscode/issues/302547)

## Summary

Verified duplicate of the older open issue https://github.com/microsoft/vscode/issues/297354: both report that Plan mode exposes `/memories/session/plan.md` as a filesystem-looking path that is not reliably clickable or openable.

## Change summary

Plan mode sometimes presents its virtual session-memory plan path as a local or absolute filesystem path instead of an openable link.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/297354 and make user-facing plan references openable through the memory URI resolver or an artifact affordance, without exposing the storage abstraction as a physical path.
