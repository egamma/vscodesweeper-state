# Issue #302547 — When referencing memories in "Plan" mode it sometimes provides a relative path to the file instead of absolute path when working in Codespaces

[https://github.com/microsoft/vscode/issues/302547](https://github.com/microsoft/vscode/issues/302547)

## Summary

Still reproducible on main: the plan agent's system prompt instructs the LLM to reference `/memories/session/plan.md` (a virtual memory-tool path), and the LLM sometimes echoes this to the user as though it were a real filesystem path. The prompt hasn't been updated to prevent this. A related fix (973986af9bd) addressed invocation-message leaking of raw `/memories/` paths, but the plan agent prompt itself still exposes the virtual path.

## Change summary

When using Plan mode in Codespaces, Copilot sometimes shows the virtual `/memories/session/plan.md` path instead of a clickable link to the actual file location.

## Best solution

Update the plan agent system prompt in `planAgentProvider.ts` to instruct the LLM to never expose the raw `/memories/…` virtual path to the user, and instead always present plan file references as clickable links or simply say 'the session plan' without a path. The memory tool's invocation response could also be improved to return a user-friendly reference.
