# Issue #330271 — Clicking on a filename should unfold the diff for that file

[https://github.com/microsoft/vscode/issues/330271](https://github.com/microsoft/vscode/issues/330271)

## Summary

Real, traceable bug: `MultiDiffEditorWidgetImpl.reveal()` scrolls to a file but never clears its `collapsed` state, unlike the sibling `_goToFile`/`_navigateToChange` methods which explicitly un-collapse before navigating — so clicking a folded file elsewhere (breadcrumbs, view-state restore, etc.) lands you on a still-collapsed, effectively invisible item.

## Change summary

Clicking a collapsed/folded file entry in the multi-diff editor scrolls to it but leaves it folded, making it easy to mistake for the wrong file.

## Best solution

In src/vs/editor/browser/widget/multiDiffEditor/multiDiffEditorWidgetImpl.ts, have `reveal()` also set `viewItem.viewModel.collapsed.set(false, ...)` before scrolling, mirroring the existing un-collapse logic already present in `_goToFile` (lines ~540-541) and `_navigateToChange` (lines ~517-518).
