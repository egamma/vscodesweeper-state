# Issue #329223 — MCP authentication required for every new session

[https://github.com/microsoft/vscode/issues/329223](https://github.com/microsoft/vscode/issues/329223)

## Summary

Team-authored report describing a real UX gap in the Agent Host: MCP OAuth tokens aren't reused across new Agents Window sessions with the Copilot CLI harness, forcing re-authentication each time. No fix is present on main and the author is a maintainer, so this should be routed to the agent-host/MCP area rather than closed.

## Change summary

Agent Host should persist and reuse MCP server authentication tokens across newly created sessions instead of requiring re-auth every time.

## Best solution

Have the agent-host layer persist MCP OAuth/session tokens keyed by server (not per-session-process) and rehydrate them when a new session starts a given harness (Copilot CLI first, per the report) — likely touching the MCP customization/session-launch plumbing in src/vs/platform/agentHost/node/shared/mcpCustomizationController.ts and the Copilot CLI session launcher/harness startup path.
