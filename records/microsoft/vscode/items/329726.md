# Issue #329726 — Commit Message Editor Fails when moved to different window

[https://github.com/microsoft/vscode/issues/329726](https://github.com/microsoft/vscode/issues/329726)

## Summary

The current source still treats moving the commit-message tab as finishing the Git editor session, allowing Git to read the empty message before the user writes it. Keep this open as a built-in Git bug.

## Change summary

Moving the commit-message editor to another window prematurely ends the pending commit and causes an empty-message cancellation.

## Best solution

Keep the pending Git editor session alive when its document moves between editor groups or windows, and complete it only when the user finishes editing. Preserve ordinary commit acceptance and discard behavior.
