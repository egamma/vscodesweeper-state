# Issue #337799 — Copilot 

[https://github.com/microsoft/vscode/issues/337799](https://github.com/microsoft/vscode/issues/337799)

## Summary

This is the same deterministic `vision_attachment_not_accessible` recovery failure already tracked by the older, open https://github.com/microsoft/vscode/issues/331428 (resuming/restoring a chat whose historical image is no longer accessible permanently breaks later turns, including after forking, since the stale image stays in the replayed turn history). A fix is already an open PR against that issue, so consolidating there rather than tracking it twice.

## Change summary

Resuming (or forking) a conversation that once had an image attachment permanently fails every subsequent request with HTTP 400 vision_attachment_not_accessible.

## Best solution

Land https://github.com/microsoft/vscode/pull/331430 (fixes #331428), which stops the unconditional retry on this deterministic error and retries once with the stale historical image set omitted so later turns — including forked ones — become usable again.
