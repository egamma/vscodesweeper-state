# Issue #317005 — [Bug] Incomplete Sanitization in snippetString.ts (Core): Unescaped Backslash Corrupts VS Code Snippet Grammar

[https://github.com/microsoft/vscode/issues/317005](https://github.com/microsoft/vscode/issues/317005)

## Summary

Real bug, confirmed in current source: `appendVariable()` escapes `$` and `}` but not `\` in default values, while `_escape()` (used by `appendText`/`appendPlaceholder`) correctly escapes all three. The inline CodeQL suppression marks this as intentional, but the inconsistency can produce malformed snippet grammar when default values contain backslashes.

## Change summary

SnippetString.appendVariable() does not escape backslashes in default values, leading to malformed snippet grammar when backslashes are present.

## Best solution

Replace the inline regex in `appendVariable` with a call to the existing `SnippetString._escape()` method (which already escapes `$`, `}`, and `\`), matching the behavior of `appendText` and `appendPlaceholder`. Remove the CodeQL suppression comment. Verify that existing snippet variable consumers are not relying on the current pass-through behavior.
