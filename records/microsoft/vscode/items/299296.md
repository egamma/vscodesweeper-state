# Issue #299296 — Failed to render content: ModelService: Cannot add model because it already exists!

[https://github.com/microsoft/vscode/issues/299296](https://github.com/microsoft/vscode/issues/299296)

## Summary

Team-authored bug that remains open. The ref-counted model fix (122e527a810, March 2026) addressed tool-confirmation re-rendering, and a355c0792ae addressed output channels, but the reported scenario — large inline code blocks triggering duplicate-model errors during chat re-rendering — may involve a different rendering path (codeBlockPart.ts or the markdown content part). Keeping open per team-author policy.

## Change summary

Chat renders a red error banner ('Cannot add model because it already exists!') when re-rendering messages containing large inline code blocks (20KB+), breaking all subsequent message rendering in the conversation.

## Best solution

Audit the remaining chat content-part rendering paths — particularly codeBlockPart.ts and any markdown-rendering code path that calls modelService.createModel — for the same duplicate-model-on-rerender pattern that was fixed for tool confirmations in commit 122e527a810. The InlineTextModelCollection (ref-counted model) pattern should be applied wherever models are created during chat content re-rendering.
