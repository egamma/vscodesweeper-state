## Summary

The reported Insiders build predates a targeted fix by roughly three hours. Current main no longer creates tool-confirmation models directly under a stable URI, so the reported re-render collision is resolved.

## Change summary

Large tool approval content or inline code caused chat re-renders to create a second Monaco model with the same URI, breaking subsequent message rendering.

## Best solution

Keep the ref-counted/pool-managed model lifecycle introduced by https://github.com/microsoft/vscode/commit/122e527a810b752011b6b900831d4aaedafbe482; no additional change is indicated for this chat-renderer path.
