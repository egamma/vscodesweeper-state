# Issue #235670 — Run Recent Command does not cover multi-line Python REPL commands

[https://github.com/microsoft/vscode/issues/235670](https://github.com/microsoft/vscode/issues/235670)

## Summary

Still open on main: multi-line Python REPL commands are not captured as a single entry in 'Run Recent Command' because the Python shell integration does not emit a full multi-line command line via the `633;E` sequence (or equivalent continuation handling). No fix has been committed. Team member authored, keeping open.

## Change summary

'Run Recent Command' only shows the last line of a multi-line Python REPL command instead of the full command.

## Best solution

The Python shell integration (likely the Python extension side emitting OSC 633 sequences, coordinated with core's `commandDetectionCapability.ts`) needs to emit the complete multi-line command text via the `633;E` CommandLine sequence before `633;C` CommandExecuted, so that `setCommandLine` receives the joined multi-line input. The core continuation handling (`handleContinuationStart`/`handleContinuationEnd`) may also need to be wired for the Python REPL's prompt pattern.
