## Change summary

Opening a workspace via a symlinked path causes extensions (e.g. Java Test Runner) to fail because VS Code / Electron resolves the symlink to the real path, breaking URI comparisons.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/74104 — the root cause is Electron's symlink-to-realpath resolution on certain platforms, which was triaged as upstream/out-of-scope. If the team reconsiders, that is the canonical issue to reopen. The Java test runner extension issues (576, 630, 797, 1463) document the downstream impact but the fix belongs in the platform layer.
