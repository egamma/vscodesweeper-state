# Issue #335524 — Clarify which agent the Tools customization page applies to

[https://github.com/microsoft/vscode/issues/335524](https://github.com/microsoft/vscode/issues/335524)

## Summary

Reasonable UX clarity request — traced in the code that the Tools customization page shows a static description with no indication of the active harness, unlike the harness label surfaced elsewhere (editor tab title, welcome page, migration cards). Worth keeping open for a maintainer/design decision on how to surface this on the Tools page specifically.

## Change summary

The Agent Customizations > Tools page doesn't indicate which harness/agent (e.g. Copilot CLI, Claude Code) its listed tools apply to, unlike the Harness page which reflects the active selection.

## Best solution

Extend ToolsListWidget's header (currently a static localized string in toolsListWidget.ts) to include the active harness label, similar to how AiCustomizationManagementEditor already threads `getActiveHarnessLabel()` into welcome-page cards and migration descriptions — so the Tools page reads consistently with the rest of the customization editor.
