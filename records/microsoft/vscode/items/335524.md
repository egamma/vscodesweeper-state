# Issue #335524 — Clarify which agent the Tools customization page applies to

[https://github.com/microsoft/vscode/issues/335524](https://github.com/microsoft/vscode/issues/335524)

## Summary

Valid UI-clarity gap: the Tools customization page's enablement is genuinely scoped per agent-host session type under the hood, but its header never surfaces which agent/harness that scope applies to, unlike the editor tab description which does show the active harness.

## Change summary

The Agent Customizations > Tools page doesn't indicate which agent (default vs. selected partner agent) its tool enablement configuration applies to.

## Best solution

Add the active agent/harness name to the Tools section header (in toolsListWidget.ts, alongside the existing static 'Tools' title/description), mirroring how aiCustomizationManagementEditorInput already surfaces the harness label in the editor tab description — and make it update reactively when the harness changes, matching the pattern used elsewhere in aiCustomizationManagementEditor.ts (harnessService.activeHarness observable).
