# Issue #345315 — hasByokModels ignores models from third-party LanguageModelChatProvider extensions unless a provider group exists (signed-out users still see Sign In)

[https://github.com/microsoft/vscode/issues/345315](https://github.com/microsoft/vscode/issues/345315)

## Summary

Current source confirms that usable extension-provided BYOK models stop counting after extension registration unless a configured provider group exists. Keep this open: the related SCM PR does not repair model detection or the title-bar symptom.

## Change summary

Recognize usable extension-provided BYOK models when computing github.copilot.hasByokModels, without requiring a chatLanguageModels.json group.

## Best solution

Make BYOK availability reflect usable extension-provided models as well as configured providers, while preserving startup persistence, disabled-AI behavior, and protection against stale models after group removal.
