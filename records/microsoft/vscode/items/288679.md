# Issue #288679 — After F2+Ctrl+C in Explorer, need to click editor twice before Ctrl+V works

[https://github.com/microsoft/vscode/issues/288679](https://github.com/microsoft/vscode/issues/288679)

## Summary

The focus loss is still present on current main: ending Explorer rename mode after the first editor click unconditionally returns DOM focus to the Explorer tree. The issue should remain open as a bounded file-explorer focus bug.

## Change summary

After copying a filename from Explorer rename mode, the first click in an editor is overridden by Explorer focus restoration, so pasting requires a second click.

## Best solution

Preserve focus on the newly focused editor when rename mode ends because of input blur, while retaining Explorer focus restoration for keyboard-driven completion such as Enter or Escape.
