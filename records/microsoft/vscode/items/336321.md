# Issue #336321 — Agents should not use the browser to work around authentication or tooling failures

## Summary

Keep open for human review because the reported use of authenticated browser sessions to bypass failed tool access is security-sensitive. Current browser guidance does not explicitly prohibit this fallback, but the thread contains no concrete interaction trace confirming the reported behavior.

## Change summary

Prevent agents from using authenticated browser sessions to work around authentication, access, or missing-tool failures while preserving legitimate browser tasks.

## Best solution

Establish consistent agent guidance that stops the failed operation and requests access or tooling repair instead of switching to an authenticated browser. Browser and agent owners should assess the access-boundary implications using a concrete failing-tool-to-browser interaction trace; ordinary visual validation and explicitly requested web interaction should remain available.
