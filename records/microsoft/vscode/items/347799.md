# Issue #347799 — Chat UI: Display model generation speed (tok/s) and response duration per turn

[https://github.com/microsoft/vscode/issues/347799](https://github.com/microsoft/vscode/issues/347799)

## Summary

Existing response footers already provide model details, elapsed-time access, and provider-reported token counts, but not inline generation speed. Keep this request open for the remaining presentation and throughput capability; the related metrics issue does not clearly own that UI.

## Change summary

Display compact per-turn model, elapsed duration, and generation-speed statistics in the Chat response footer.

## Best solution

Extend the existing response-details surface rather than adding a parallel footer, subject to a product decision about inline visibility and a consistent throughput definition for multi-call agent turns. Reuse existing timing and token details where available, without presenting total task duration as pure model-generation time.
