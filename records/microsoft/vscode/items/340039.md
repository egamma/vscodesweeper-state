## Summary

Keep open — an open PR (#340100) already identifies the root cause (uncoordinated core utility model requests, e.g. one thinking-title request per block with no shared rate limiting/caching) and implements the fix; close only once it merges.

## Change summary

Dense bursts of thousands of HTTP 429s from gpt-4o-mini-2024-07-18 requests logged via copilotLanguageModelWrapper, with no backoff between retries.

## Best solution
