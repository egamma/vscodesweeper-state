# Issue #199864 — No Feedback when Issue Reporter's GitHub API Call Fails

[https://github.com/microsoft/vscode/issues/199864](https://github.com/microsoft/vscode/issues/199864)

## Summary

Keep open: the reporter has gained a browser-preview wizard, but the retained legacy Create on GitHub path still handles unsuccessful API responses without visible feedback. The report identifies the trigger and failing branch sufficiently to retest; runtime behavior was not exercised.

## Change summary

Failed GitHub issue-creation requests leave the reporter without visible error feedback or an automatic browser fallback.
