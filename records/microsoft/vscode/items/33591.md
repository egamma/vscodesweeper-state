# Issue #33591 — Option to allow quickSuggestions inside words

[https://github.com/microsoft/vscode/issues/33591](https://github.com/microsoft/vscode/issues/33591)

## Summary

A real configuration gap remains on main: quick suggestions cannot be enabled arbitrarily inside words. This team-authored Backlog request is already correctly routed and should remain open.

## Change summary

Allow users or language configurations to enable automatic quick suggestions while typing inside an existing word.

## Best solution

Extend `editor.quickSuggestions` with a trigger-location policy and apply it consistently to suggest-widget and inline quick suggestions in the editor suggest implementation.

## Evidence

- **current source:** `src/vs/editor/contrib/suggest/browser/suggestModel.ts` (`LineContext.shouldAutoTrigger`) rejects positions that are neither the word end nor immediately after one newly typed character before a word, so arbitrary in-word quick suggestions remain unavailable.
- **configuration gap:** `src/vs/editor/common/config/editorOptions.ts` configures `editor.quickSuggestions` by token type and presentation mode but exposes no option controlling whether suggestions trigger inside words.
- **inline parity:** `src/vs/editor/contrib/suggest/browser/suggestInlineCompletions.ts` explicitly returns when the cursor is not at the end of a word, noting that quick suggestions inside words are intentionally suppressed.
