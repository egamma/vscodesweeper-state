# Issue #248110 — SCM - scm.workingSets.enabled steals focus from integrated terminal

[https://github.com/microsoft/vscode/issues/248110](https://github.com/microsoft/vscode/issues/248110)

## Summary

Still reproduces on current main: the previous fix (commit bbb3b1c06b4) only suppresses the final explicit `activeGroup.focus()` call via `preserveFocus`, but intermediate editor state operations during `applyWorkingSet` (closing/opening editors in auxiliary and main parts) can still steal focus from the terminal panel. The bug is real and the fix was incomplete.

## Change summary

Switching git branches while the integrated terminal has focus causes the SCM working sets feature to steal focus away from the terminal.

## Best solution

The `preserveFocus` flag needs to be threaded through the entire `applyWorkingSet` → `applyState` → editor close/open pipeline in `src/vs/workbench/browser/parts/editor/editorParts.ts`, not just the final focus call. Alternatively, capture and restore the focused element around the entire working set application in `src/vs/workbench/contrib/scm/browser/workingSet.ts`. The fix should also extend the `hasFocus` check beyond `Parts.PANEL_PART` to cover auxiliary bar and editor-area terminals.
