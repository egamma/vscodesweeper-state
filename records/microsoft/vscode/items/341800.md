## Change summary

VS Code's MCP allowlist matcher (name fallback, command/URL precedence, env expansion, URL case rules) differs from the Copilot runtime's contract.

## Best solution

Agree one matching contract with the runtime owner. Then align isMcpServerMatched and matchesMatcher in src/vs/platform/mcp/common/allowedMcpServers.ts with it, adding the allow/deny test cases listed in the issue. Do not add a second permission interpreter.
