# Issue #223308 — Wrong auto-indentation in typescript when pasting

[https://github.com/microsoft/vscode/issues/223308](https://github.com/microsoft/vscode/issues/223308)

## Summary

Keep open: the current auto-indent-on-paste path still shifts an Allman-style TypeScript block one level too far after an if statement. The earlier typing fix does not cover this paste-specific behavior, and the inspected older reports do not establish a same-symptom canonical.

## Change summary

Preserve the correct indentation of an Allman-style TypeScript block when it is cut and pasted back.

## Best solution

Make paste indentation recognize an opening brace following a control-flow header without adding an extra level to the entire block, while preserving indentation for genuinely braceless statements and the existing typing behavior.
