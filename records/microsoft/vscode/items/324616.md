[https://github.com/microsoft/vscode/issues/324616](https://github.com/microsoft/vscode/issues/324616)

## Summary

Keep open: current source still does not deliver ordinary session-reference context from the Agents Window composer. The existing #session completion is troubleshooting-specific, not complete coverage of the requested picker, drag-and-drop, and inline attachment behavior.

## Change summary

Make session attachments usable as context in the Agents Window through the attachment picker, drag and drop, and inline session references.
