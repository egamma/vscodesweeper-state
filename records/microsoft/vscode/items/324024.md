# Issue #324024 — Suggestions

[https://github.com/microsoft/vscode/issues/324024](https://github.com/microsoft/vscode/issues/324024)

## Summary

The reporter wants to disable suggestions, which existing editor settings support. Answer the configuration question; the report does not establish a separate performance defect.

## Change summary

Disable word suggestions that interrupt the reporter's coding workflow.

## Best solution

Use editor.wordBasedSuggestions set to "off" to disable document-word completions. If the reporter means automatic completion popups generally, disable editor.quickSuggestions and editor.suggestOnTriggerCharacters as well.
