# Issue #328844 — No Context widget/Usage shown for multi repo claude agent sessions in Editor Window.

[https://github.com/microsoft/vscode/issues/328844](https://github.com/microsoft/vscode/issues/328844)

## Summary

Real, well-diagnosed bug still present on main and carries an assigned release milestone (1.135.0), which blocks any close under the hard keep-open rules regardless of how strong the diagnosis is.

## Change summary

The context widget and usage footer disappear for restored/cross-window Claude Opus 5 (1M-context) sessions because the SDK's bracketed usage model key (`claude-opus-5[1m]`) never resolves back to the registered `claude-opus-5` model identity once the live turn's `message.model` fallback is gone.

## Best solution

In src/vs/platform/agentHost/node/claude/claudeMapSessionEvents.ts (mapResult), normalize/strip the SDK's context-variant suffix from `modelUsage` keys (or resolve them against the registered Claude model IDs) before attaching `usage.model`, so replayed/cross-window turns resolve the same model metadata a live session does.
