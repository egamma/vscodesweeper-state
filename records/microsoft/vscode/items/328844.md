# Issue #328844 — No Context widget/Usage shown for multi repo claude agent sessions in Editor Window.

[https://github.com/microsoft/vscode/issues/328844](https://github.com/microsoft/vscode/issues/328844)

## Summary

Real, well-diagnosed bug (a maintainer traced the exact model-identity mismatch in a follow-up comment), but it carries a real version milestone (1.137.0), which is a scheduling decision — the hard keep-open milestone rule applies and no implemented-on-main fix commit exists yet on main to override it.

## Change summary

The context widget and usage/response footer disappear for restored/replayed Claude sessions (e.g. reopened in a different window) when the turn used a bracketed usage-variant model key like `claude-opus-5[1m]` instead of the canonical registered model id.

## Best solution

Fix the restored-session model-identity fallback so replayed turns resolve the bracketed SDK usage key (e.g. `claude-opus-5[1m]`) back to the canonical registered model id (`claude-opus-5`) before the context widget/response footer try to look up model metadata — likely in `src/vs/platform/agentHost/node/claude/claudeMapSessionEvents.ts` (the `modelKey`/`usage.model` mapping around line 460-480) and wherever the transcript-replay path reconstructs `message.model` for completed turns.
