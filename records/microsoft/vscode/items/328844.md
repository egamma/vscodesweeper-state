# Issue #328844 — No Context widget/Usage shown for claude agent sessions in Editor Window.

[https://github.com/microsoft/vscode/issues/328844](https://github.com/microsoft/vscode/issues/328844)

## Summary

Confirmed, reproducible bug: the context/usage widget disappears for Claude agent-host sessions after VS Code is restarted and the session reopened (confirmed by a maintainer's own repro steps in a single-folder window, not just multi-root). Carries a real version milestone (1.137.0), so this must stay open regardless of any other evidence.

## Change summary

The context-window usage widget/hover is missing for Claude agent sessions once a VS Code window is restarted and the prior session reopened.

## Best solution

Trace why usage data isn't rehydrated on session restore for agent-host (Claude) sessions specifically — regular chat sessions restore `usage` via `ChatModel._deserializeRequest`/`ChatResponseModel.setUsage` in src/vs/workbench/contrib/chat/common/model/chatModel.ts, but agent-host session restore appears to follow a different path that doesn't feed the same data into `ChatContextUsageWidget` (src/vs/workbench/contrib/chat/browser/widgetHosts/viewPane/chatContextUsageWidget.ts), which also depends on resolving `usage.actualModelId`/`contextWindow` that may not be available immediately after restore.
