# Issue #328844 — No Context widget/Usage shown for multi repo claude agent sessions in Editor Window.

[https://github.com/microsoft/vscode/issues/328844](https://github.com/microsoft/vscode/issues/328844)

## Summary

Team-authored bug carrying an assigned real milestone (1.136.0) — a hard keep-open case regardless of the (very good) diagnosis in the comments. A maintainer already root-caused it precisely, but no fix has landed on main yet.

## Change summary

The context widget and usage/response footer disappear for restored/replayed Claude Agent sessions (e.g. reopened across windows) because the model identity from SDK usage data (`claude-opus-5[1m]`) doesn't match the registered canonical model id (`claude-opus-5`), so context-window metadata can't be resolved.

## Best solution

Normalize/strip the SDK's bracketed usage-variant suffix (e.g. `[1m]`) when mapping `modelUsage` keys to a model identity in `claudeMapSessionEvents.ts` `mapResult`, or otherwise resolve replayed-turn model ids against the registered canonical model list before falling back, so restored sessions can still resolve context-window dimensions.
