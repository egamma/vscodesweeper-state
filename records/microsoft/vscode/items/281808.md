# Issue #281808 — Image attachment disappears when sending to new chat

[https://github.com/microsoft/vscode/issues/281808](https://github.com/microsoft/vscode/issues/281808)

## Summary

Still reproducible from current source: Send to New Chat preserves only the prompt text, while clearing the session replaces the composer state and drops its image attachments before submission.

## Change summary

Sending a prompt with a pasted image to a new chat via Ctrl+Shift+Enter submits the text without the image.

## Best solution

Preserve the prompt's sendable attachments across the new-session transition and submit them with the text, without changing ordinary session clearing or normal chat submission behavior.
