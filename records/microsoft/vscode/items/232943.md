[https://github.com/microsoft/vscode/issues/232943](https://github.com/microsoft/vscode/issues/232943)

## Summary

The reported toolbar mismatch is addressed by a merged change that checks keybinding conditions before displaying a shortcut. Current main retains that behavior, so this can be closed as completed.

## Change summary

The inline suggestion toolbar advertised Cmd+Enter even when the visible suggest widget made that acceptance shortcut inactive.

## Best solution

Keep the context-aware toolbar lookup implemented in commit 5655a12f6af53c80ac9a3ad085677d6724761cab: advertise only an applicable acceptance shortcut without changing suggest-widget keyboard behavior.
