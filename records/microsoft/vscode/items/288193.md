# Issue #288193 — Open PR as default artifact for WIP cloud agents

[https://github.com/microsoft/vscode/issues/288193](https://github.com/microsoft/vscode/issues/288193)

## Summary

Keep open: explicit cloud-session PR opening exists, but it does not establish the requested automatic artifact presentation when selecting a WIP session. This team-authored request has no verified fixing commit or qualifying canonical duplicate.

## Change summary

Automatically show a WIP cloud session's associated pull request in the main artifact editor when the session is selected in agent/artifact-first mode.

## Best solution

Define the current equivalent of artifact-first session selection and make an existing associated PR its default review surface, without requiring a separate Open Pull Request action. Settle how this interacts with restored editors, delayed PR availability, and an unavailable PR editor before implementation.
