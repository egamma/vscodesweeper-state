# Issue #296565 — Add separator in Copilot Model Picker Search

[https://github.com/microsoft/vscode/issues/296565](https://github.com/microsoft/vscode/issues/296565)

## Summary

The accepted visual-hierarchy bug remains source-reproducible in the default grouped model picker: filtering removes the unlabeled boundary and skips the “Other Models” section toggle, leaving promoted and other matching models visually contiguous.

## Change summary

Preserve a visible section boundary between promoted models and matching “Other Models” entries while searching the Copilot model picker.

## Best solution

When the grouped picker is filtered, retain the “Other Models” section identity as a labeled separator whenever that section has matching results, without changing sorting or the experimental tabbed picker's intentionally flat search results.
