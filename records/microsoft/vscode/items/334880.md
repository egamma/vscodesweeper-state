# Issue #334880 — Can't hide "changes" pill

[https://github.com/microsoft/vscode/issues/334880](https://github.com/microsoft/vscode/issues/334880)

## Summary

Keep open for an explicit product decision: current main deliberately makes the Changes pill non-hideable, while this team-authored test feedback requests otherwise. The team-authored-item rule bars a judgment close such as *as-designed.

## Change summary

Allow users to hide the Changes status pill above an Agent Host chat input.

## Best solution

Decide whether persistent visibility of agent-made file changes is a required safety affordance or whether the Changes pill should participate in the existing per-kind visibility controls. If customization wins, it should behave consistently with the other status pills and remain recoverable through the toolbar context menu.
