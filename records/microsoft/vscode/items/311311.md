# Issue #311311 — Spinner appears when pasting text

[https://github.com/microsoft/vscode/issues/311311](https://github.com/microsoft/vscode/issues/311311)

## Summary

Thanks for the detailed report. Two other users confirm that disabling the Copilot extension fixes it. I could not confirm the cause from source. The report has what's needed to retest on a current build, so it stays open.

## Change summary

On macOS, after the screen sleeps, pasting text shows a spinner that blocks the paste until it is clicked. Disabling Copilot makes it go away.

## Best solution

Find which paste or extension-host path is stalling after wake from sleep. The reporters implicate Copilot, but it registers no document paste provider. Check for extension-host unresponsiveness or the paste-progress widget waiting on a pending provider, then fix it in core or in the Copilot code in this repo.
