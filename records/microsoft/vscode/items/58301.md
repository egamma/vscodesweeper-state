# Issue #58301 — Allow text-shadow to be used in themes

Keep open in the Backlog: 67 community upvotes exceed the promotion threshold, current theme APIs still lack text-shadow support, and no open canonical issue owns this specific request.

## Change summary

Allow color themes to specify text shadows for editor tokens, enabling glow effects without modifying VS Code's generated CSS.

## Best solution

Evaluate a bounded theme API property rather than arbitrary CSS access, accounting for both DOM and GPU editor renderers and avoiding measurable text-rendering regressions. The editor-theming owners should retain this accepted request until that feasibility decision is made.
