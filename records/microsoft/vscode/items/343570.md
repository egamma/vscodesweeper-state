# Issue #343570 — Copilot remote codebase index fails for Azure DevOps orgs in a non-home tenant (ADO token requested without tenant)

[https://github.com/microsoft/vscode/issues/343570](https://github.com/microsoft/vscode/issues/343570)

## Summary

Keep open: current source still requests ADO credentials without organization-specific tenant information. Authentication identity handling has evolved, but the supplied cross-tenant steps suffice to retest; the external token rejection was not verified in this read-only review.

## Change summary

Copilot remote indexing fails for Azure DevOps organizations outside the signed-in account’s home tenant and surfaces an HTML response as a JSON parsing error.

## Best solution

Make ADO remote indexing authenticate against the organization’s tenant while preserving same-tenant behavior and local-search fallback. Return an actionable authentication diagnostic for unexpected HTML responses rather than a JSON SyntaxError.
