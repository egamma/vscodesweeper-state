# Issue #286086 — Original tree shows all worktrees top-level in Repositories but a worktree doesn't

[https://github.com/microsoft/vscode/issues/286086](https://github.com/microsoft/vscode/issues/286086)

## Summary

Keep open for feedback on worktree discovery and presentation: current source still implements the intentional asymmetry described by the maintainer. This team-authored discussion has neither a verified fixing commit nor an older canonical covering the same full request.

## Change summary

Consider making top-level worktree visibility consistent between main-repository and linked-worktree windows, potentially avoiding duplicate Worktrees subnodes.

## Best solution

Resolve whether Repositories should represent only repositories opened in the window or consistently expose the whole worktree family, accounting for multi-repository clutter. Coordinate that decision with existing discovery work rather than treating the current intentional behavior as a confirmed bug.
