# Issue #105603 — Copy/paste from custom titlebar doesn't work in markdown previews

[https://github.com/microsoft/vscode/issues/105603](https://github.com/microsoft/vscode/issues/105603)

## Summary

This issue has been addressed by multiple webview focus/clipboard fixes since 2021, most notably commit 066f28822af (2021-07-07) which added the custom-menu fallback to dispatch copy to the active webview editor when focus is stolen by the menubar, and commit d4b4c327798 (2024-03-12) which keeps webview focus state correct when a context menu is visible.

## Change summary

Copy from the context menu or Edit menu in markdown preview does not work on Windows with the custom titlebar because the menu steals focus from the webview.

## Best solution

The fix is already on main via the action-menu-item fallback in webview.contribution.ts and the vscode-context-menu-visible focus tracking in the webview host page. No further change needed; confirm on latest build and close as completed.
