# Issue #152252 — Go To Source Definition UX improvements

[https://github.com/microsoft/vscode/issues/152252](https://github.com/microsoft/vscode/issues/152252)

## Summary

Both requested UX improvements remain unimplemented on current main: the 'no source definitions found' error still uses a notification instead of an inline message, and the `unverified` property from the protocol response is never surfaced to the user.

## Change summary

Improve Go To Source Definition UX by replacing the error notification with an inline message and surfacing the `unverified` flag on results.

## Best solution

In `extensions/typescript-language-features/src/languageFeatures/sourceDefinition.ts`, switch from `showErrorMessage` to using `editor.action.goToLocations` with a `noResultsMessage` parameter (the mechanism already exists in the goToCommands infrastructure). For the `unverified` indicator, the editor-side reference peek widget would need a new concept — potentially via the location-kind proposal referenced in https://github.com/microsoft/vscode/issues/74237.
