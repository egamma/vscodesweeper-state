# Issue #342775 — Opening an agent host session eagerly subscribes to every subagent chat (tens of MB of snapshots)

[https://github.com/microsoft/vscode/issues/342775](https://github.com/microsoft/vscode/issues/342775)

## Summary

Keep open: current source can eagerly load all child chats advertised as in progress, even when their parent task calls have completed. Settled catalog entries already receive lazy loading, but that does not cover the reported stale-status case or bound the active-child subscription burst.

## Change summary

Avoid transferring full transcripts for dozens of subagent chats merely because their parent session is opened.

## Best solution

Make parent-session loading avoid unnecessary child transcript transfers while preserving intentional live subagent activity and on-demand transcript access. Establish how conflicting parent completion and child catalog activity should affect that behavior before extending the existing lazy-loading path.
