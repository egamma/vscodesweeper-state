# Issue #322483 — Inline chat error: 'MISSING inline chat exit tool'.

[https://github.com/microsoft/vscode/issues/322483](https://github.com/microsoft/vscode/issues/322483)

## Summary

Inline chat still requires editing tools that current main filters out when agent mode is disabled. The earlier fix permits the internal exit tool, not the editing tools named in this report; route this unresolved report to inline-chat.

## Change summary

Inline chat fails with “MISSING inline chat edit tools” when enterprise policy disables agent mode while leaving chat editing available.

## Best solution

Make inline editing function under the supported agent-disabled configuration without enabling general agent capabilities or weakening enterprise restrictions. Address tool availability across the workbench-to-extension boundary rather than treating the earlier exit-tool fix as completion.
