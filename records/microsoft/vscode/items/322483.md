# Issue #322483 — Inline chat error: 'MISSING inline chat exit tool'.

[https://github.com/microsoft/vscode/issues/322483](https://github.com/microsoft/vscode/issues/322483)

## Summary

Current main still contains the reported failure path: disabling agent mode filters every inline-chat edit tool before the Copilot extension can obtain it. This is a distinct remainder from the earlier exit-tool fix and should be routed to inline chat.

## Change summary

Inline chat fails with “MISSING inline chat edit tools” when enterprise policy disables agent mode while inline editing remains enabled.

## Best solution

Allow inline chat to obtain its required edit tools without exposing them to ordinary agent-mode requests, preserving the enterprise restriction while keeping inline editing functional. The boundary spans core tool permission filtering and the Copilot inline-chat tool-selection path.
