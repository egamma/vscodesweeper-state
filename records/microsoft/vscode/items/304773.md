# Issue #304773 — `+` in chat empty state create a ghost in progress chat session

[https://github.com/microsoft/vscode/issues/304773](https://github.com/microsoft/vscode/issues/304773)

## Summary

The ghost-session defect remains source-reproducible on current main: New Chat unconditionally creates another untitled contributed session even when the current contributed session is already empty. The only directly linked fix PR was closed without merging, so this team-authored bug should remain open.

## Change summary

Clicking New Chat from an already-empty contributed chat creates an inaccessible ghost session marked in progress.

## Best solution

Keep the existing empty contributed draft active when New Chat is invoked without an explicit session-type override, while preserving creation of a new session for chats containing requests and for explicit session-type selections.
