# Issue #190831 — `editor.action.clipboardPasteAction` doesn't work with `runCommands`

[https://github.com/microsoft/vscode/issues/190831](https://github.com/microsoft/vscode/issues/190831)

## Summary

Still reproduces on main: clipboard cut/paste actions in `runCommands` don't properly await completion. The paste action was partially fixed (commit a28e68ad) to return a promise via `triggerPaste`, but the cut action still returns a synchronous `true`, and there's a recent report (Oct 2025) that paste has regressed again in 1.104.

## Change summary

`editor.action.clipboardPasteAction` and `editor.action.clipboardCutAction` don't complete before the next command runs in `runCommands` sequences.

## Best solution

Ensure all clipboard MultiCommand implementations (`cut`, `copy`, `paste`) return proper promises that resolve only after the clipboard operation and any resulting editor edits have fully completed — similar to the paste fix in a28e68ad but extended to cut and made robust against regressions. The fix belongs in `src/vs/editor/contrib/clipboard/browser/clipboard.ts`.
