# Issue #336844 — Agent Host: permission mode can race managed-settings resolution

[https://github.com/microsoft/vscode/issues/336844](https://github.com/microsoft/vscode/issues/336844)

## Summary

This narrower race-condition report is fully covered by the open, broader-scoped https://github.com/microsoft/vscode/issues/335928, which explicitly requires reflecting resolved managed-permission policy in SDK mode selection before calling `permissions.setMode` and blocking elevated bypass while policy is unresolved/fail-closed — proposing consolidation there.

## Change summary

Agent Host can send `allow-all` to the SDK via `syncPermissionMode`/`permissions.setMode` before managed-settings resolution completes, causing the SDK to reject the mode.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/335928, which already tracks building a shared effective-permission state that gates SDK mode selection (and the picker) on managed-settings resolution readiness — implementing that issue's 'Required behavior' delivers this fix.
