# Issue #327815 — Error when launching the VSCode via Code.exe

[https://github.com/microsoft/vscode/issues/327815](https://github.com/microsoft/vscode/issues/327815)

## Summary

Real crash signature (`TypeError: Invalid value for env` from Electron's `ForkUtilityProcess`) that prevents the local extension host from starting when Code.exe is launched from Explorer/shortcuts but not from the CLI wrapper — but we don't know which specific environment variable Electron is rejecting, so this needs more diagnostic info from the reporter before it can be traced to a fix.

## Change summary

Launching Code.exe directly (vs. the code.cmd/CLI wrapper) fails to start the extension host with `TypeError: Invalid value for env`, breaking all built-in extensions.

## Best solution

Have the reporter capture and share the full environment Code.exe inherits when launched from Explorer (e.g. via `Help: Report Issue` or `set` output) so the team can identify the specific env var/key that Electron's `ForkUtilityProcess` rejects; the likely fix would extend `removeDangerousEnvVariables` in src/vs/base/common/processes.ts or `createEnv` in src/vs/platform/utilityProcess/electron-main/utilityProcess.ts to sanitize whatever value/key type it is (e.g. Windows' hidden `=C:` drive-tracking variables, which start with `=` and may not survive Electron's env validation).
