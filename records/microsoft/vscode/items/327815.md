# Issue #327815 — Error when launching the VSCode via Code.exe

[https://github.com/microsoft/vscode/issues/327815](https://github.com/microsoft/vscode/issues/327815)

## Summary

This is a credible extension-host startup defect triggered by the desktop process environment. It remains open without a canonical issue or fix and should be routed to the Electron and extension-host owners.

## Change summary

Launching Code.exe directly passes an environment that Electron rejects when VS Code forks the local extension host, while launching through code.cmd succeeds.

## Best solution

Make utility-process environment construction tolerate or clearly diagnose malformed inherited Windows environment entries in src/vs/platform/utilityProcess/electron-main/utilityProcess.ts, preserving valid variables and consistent Code.exe/code.cmd behavior.
