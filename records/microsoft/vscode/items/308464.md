# Issue #308464 — Copilot extension breaks auto complete

[https://github.com/microsoft/vscode/issues/308464](https://github.com/microsoft/vscode/issues/308464)

## Summary

Keep open: multiple reporters confirm that enabling Copilot inline suggestions prevents normal completion, and the reporter explicitly says both Ctrl+Space and the suggested configuration workaround fail. The related report is newer and still reports problems, so neither a duplicate close nor a completed close is justified.

## Change summary

Copilot ghost-text suggestions prevent native symbol and snippet completion from appearing, including manual invocation in the reporter's case.
