# Issue #133955 — URI provided by didOpen does not conform to RFC3986

[https://github.com/microsoft/vscode/issues/133955](https://github.com/microsoft/vscode/issues/133955)

## Summary

The reported authority encoding remains present in current source: default URI serialization converts the '+' in 'ssh-remote+…' to '%2B'. Keep this open in the URI area; the thread already establishes the interoperability concern, and no verified fix or qualifying canonical duplicate was found.

## Change summary

Serialize remote untitled-document URI hosts without unnecessarily percent-encoding ASCII '+' while retaining required UTF-8 encoding.

## Best solution

Provide interoperable host serialization for the reported language-server flow while preserving required encoding elsewhere and existing URI identity guarantees. Assess compatibility before changing the shared serializer, since earlier maintainer discussion documents extensions and persisted data depending on its current behavior.
