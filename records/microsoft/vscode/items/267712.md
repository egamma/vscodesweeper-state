# Issue #267712 — Code actions of kind 'quickfix' requested but returned code action is of kind 'refactor.rewrite.review.copilot'. Code action will be dropped

[https://github.com/microsoft/vscode/issues/267712](https://github.com/microsoft/vscode/issues/267712)

## Summary

Still reproduces on main: the Copilot Chat QuickFixesProvider in inlineChatCodeActions.ts returns a 'refactor.rewrite.review.copilot' code action even when only 'quickfix' kind is requested, because it never checks context.only before adding the review action.

## Change summary

The Copilot Chat code action provider returns code actions of mismatched kinds, causing repeated warnings in extension host logs.

## Best solution

Add a context.only filter check in QuickFixesProvider.provideCodeActions (extensions/copilot/src/extension/inlineChat/vscode-node/inlineChatCodeActions.ts) so the review action is only returned when the requested kind includes refactor.rewrite.
