# Issue #339726 — Make output of `/plugin marketplace browse` easier to read

[https://github.com/microsoft/vscode/issues/339726](https://github.com/microsoft/vscode/issues/339726)

## Summary

Confirmed from source: the `/plugin marketplace browse` case renders a flat `name:description` list with no markdown formatting, while `/plugin marketplace list` right next to it already uses headers, bullets, and escaped inline code via `appendMarketplaceGroup`. This is a real, bounded readability gap worth keeping open.

## Change summary

Make `/plugin marketplace browse <name>` render its plugin list with the same markdown formatting (headers, bullets, distinct name/description styling) that `/plugin marketplace list` already uses.

## Best solution

Rework the 'browse' case in copilotCustomizationCommandDisplay.ts to build markdown output (header + bulleted entries with escaped inline-code plugin names and separately styled descriptions) mirroring the existing `appendMarketplaceGroup` helper used by 'list', and set `markdown: true` on the result.
