# Issue #340315 — Copilot CLI shim recurses infinitely (fork bomb) when `/home` is a symlink

[https://github.com/microsoft/vscode/issues/340315](https://github.com/microsoft/vscode/issues/340315)

## Summary

Thanks for the detailed report. The defect is still on main: the shim strips its directory from PATH by string match on `__dirname`, which fails when the PATH entry contains a symlink. A maintainer says a native replacement is in progress on a branch, so this stays open until that ships.

## Change summary

The Copilot CLI shim fails to remove itself from PATH when the global storage path contains a symlink such as /home -> var/home. It then recurses without bound and exhausts memory.

## Best solution

Ship the native `copilot` command from the `packaging/vscode-with-copilot` branch, which skips itself by device and inode. If that slips, backport a fix to the script shim: compare PATH entries by realpath and add an environment-variable recursion guard.
