# Issue #340315 — Copilot CLI shim recurses infinitely (fork bomb) when `/home` is a symlink

[https://github.com/microsoft/vscode/issues/340315](https://github.com/microsoft/vscode/issues/340315)

## Summary

Thanks for the detailed report. The defect is still in current main: the shim strips its own directory from PATH by plain string match on __dirname, which fails when the path contains a symlink such as /home -> var/home. A maintainer says a native replacement is in progress on a branch but has not shipped, so this stays open.

## Change summary

The Copilot CLI shim fails to remove itself from PATH when the global storage path contains a symlink, so it recurses without bound.

## Best solution

Keep the issue open until the native copilot-shim ships. If the script shim is still shipped in the meantime, filter PATH by realpath (or inode) and add a recursion guard env var.
