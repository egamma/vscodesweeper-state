# Issue #320556 — Batch delete the copilot chat of the current project

[https://github.com/microsoft/vscode/issues/320556](https://github.com/microsoft/vscode/issues/320556)

## Summary

The central request is already covered by the built-in Delete All Local Workspace Chat Sessions command, which deletes the current project's local chat history in one confirmed operation. This capability was present before the report; no additional clear-all button is necessary to avoid deleting conversations individually.

## Change summary

Provide a single action to batch-delete Copilot chat history for the current project.

## Best solution

Use the existing Command Palette action Chat Agent Sessions: Delete All Local Workspace Chat Sessions (workbench.action.chat.clearHistory), retaining its confirmation dialog and workspace-local scope.

## Vision fit

- **Fit:** aligned
- **Reason:** Efficient management of workspace chat history fits the workbench UX and AI-assisted development themes, and the existing command provides it without adding another UI control.

This permanently deletes the local workspace conversations rather than archiving them.
