# Issue #320556 — Batch delete the copilot chat of the current project

[https://github.com/microsoft/vscode/issues/320556](https://github.com/microsoft/vscode/issues/320556)

## Summary

The requested batch-delete capability already exists: the command 'Delete All Local Workspace Chat Sessions' (workbench.action.chat.clearHistory) clears all local workspace chat sessions in one action. Multi-select delete is also supported in the sessions panel. Proposing close as *as-designed.

## Change summary

Request for a button to batch-delete all Copilot chat history for the current project instead of deleting sessions one by one.

## Best solution

The existing command `workbench.action.chat.clearHistory` ('Delete All Local Workspace Chat Sessions') already covers this. Multi-select delete in the Chat Sessions panel also works (though issue https://github.com/microsoft/vscode/issues/327073 tracks a bug where it only removes one). No new feature is needed.
