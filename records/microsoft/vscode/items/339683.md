# Issue #339683 — Agent sessions retain prompt-derived titles instead of generated titles

## Change summary

New Agent Host sessions keep their provisional prompt-derived title instead of being renamed to a generated title after the first turn, because deferred/background title refinement isn't reliably replacing it.

## Best solution

Current main's title-generation code (src/vs/platform/agentHost/common/titleGenerationConfiguration.ts and src/vs/platform/agentHost/node/agentHostSessionTitleController.ts) already reverts the default strategy to `activeAgent` for non-stable builds and eagerly loads `rename_chat` for `activeAgent` sessions, which matches the merged PRs referenced on this issue (#339908, #340425) and should resolve the reported symptom — the maintainer should verify against a fresh Insiders build and close with an explicit commit citation once confirmed, rather than relying on this review's source trace alone.
