# Issue #286759 — Clarify if `FinishedCallback` is awaited or not

[https://github.com/microsoft/vscode/issues/286759](https://github.com/microsoft/vscode/issues/286759)

## Summary

The callback contract still needs clarification: current main retains the promise-only signature while consumers differ in whether they await it and honor its result. The related runtime bug is closed, but that does not resolve this separate contract-cleanup request.

## Change summary

Clarify FinishedCallback's asynchronous completion and return-value semantics, and align its type and documentation with the supported contract.

## Best solution

Establish an explicit callback contract across Copilot response processors so callers know whether asynchronous work delays completion and whether a numeric result stops streaming. Make the declaration and consumers consistent with that decision without assuming that the related runtime fix completed this cleanup.

- **Open decisions:**
