# Issue #286759 — Clarify if `FinishedCallback` is awaited or not

[https://github.com/microsoft/vscode/issues/286759](https://github.com/microsoft/vscode/issues/286759)

## Summary

The contract ambiguity remains on current main: FinishedCallback requires a Promise, but some processors await it while others discard it. Keep this open to establish and document the intended callback semantics.

## Change summary

Clarify FinishedCallback's type and documentation so callers know whether asynchronous work and stop-reading results are honored.

## Best solution

Make the callback contract accurately describe completion ordering and return-value handling across Copilot response processors. Settle whether these guarantees should be uniform or explicitly processor-specific before changing types or runtime behavior.
