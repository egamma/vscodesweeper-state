# Issue #145307 — Add a way to read all enabled extensions across all extension hosts

[https://github.com/microsoft/vscode/issues/145307](https://github.com/microsoft/vscode/issues/145307)

## Summary

The proposed API (`extensions.allAcrossExtensionHosts`, `getExtension` overload, `isFromDifferentExtensionHost`) exists in the codebase but remains in `vscode.proposed.extensionsAny.d.ts` — it has not been finalized into the stable `vscode.d.ts`. This is a team-authored issue with `api-finalization` label, actively awaiting finalization; it should stay open.

## Change summary

Add a stable API to enumerate all enabled extensions across all extension hosts, not just the current one.

## Best solution

Finalize the `extensionsAny` proposal: move `allAcrossExtensionHosts`, the `getExtension` overload with `includeDifferentExtensionHosts`, and `isFromDifferentExtensionHost` from `src/vscode-dts/vscode.proposed.extensionsAny.d.ts` into the stable `vscode.d.ts`. Multiple extension authors and the community (5 upvotes, repeated requests in comments) are waiting on this. The API shape appears settled — the main decision is whether to also update the semantics of `extensions.all` for a future major version.
