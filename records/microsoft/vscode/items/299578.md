# Issue #299578 — Model Picker dissappears in CLI if you are mid session

[https://github.com/microsoft/vscode/issues/299578](https://github.com/microsoft/vscode/issues/299578)

## Summary

Team-authored bug report — the model picker disappears mid-session when switching to Copilot CLI because `lockedToCodingAgent` is set to true and the `when` clause on `OpenModelPickerAction` hides it unless `chatSessionHasTargetedModels` is also set. No fix commit references this issue; keeping open.

## Change summary

Model picker vanishes from the chat input toolbar when switching to Copilot CLI mid-session.

## Best solution

The `OpenModelPickerAction` menu `when` clause (in `src/vs/workbench/contrib/chat/browser/actions/chatExecuteActions.ts`, line ~436) gates visibility on `lockedToCodingAgent.negate()` OR `chatSessionHasTargetedModels`. For agent-host (CLI) sessions the `lockedToCodingAgent` key is `true` (set in `chatWidget.ts` `lockToCodingAgent`), so the picker only appears if `chatSessionHasTargetedModels` is also set. The fix likely needs to add `ChatContextKeyExprs.isAgentHostSession` as an additional OR branch in the model picker's `when` clause, mirroring the pattern already used by other actions (e.g. `chatEditingActions.ts`, `chatForkActions.ts`, `chatNewActions.ts`).
