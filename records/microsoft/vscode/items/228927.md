- **Existing capability remains partial:** src/vs/workbench/contrib/notebook/browser/notebook.contribution.ts:1122-1127 defines notebook.output.textLineLimit specifically for text. In extensions/notebook-renderers/src/index.ts, renderHTML and renderImage do not apply the scrollable class used by the text paths; the associated overflow-y and max-height rules target .scrollable. The notebook.cell.toggleOutputScrolling command sets output metadata, but these built-in rich-output renderers do not consume that metadata to constrain their height.
