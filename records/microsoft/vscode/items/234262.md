# Issue #234262 — Presentation of experimental settings in settings.json

[https://github.com/microsoft/vscode/issues/234262](https://github.com/microsoft/vscode/issues/234262)

## Summary

Keep open for a presentation decision: current source still uses hint markers spanning the setting, with a possible “No quick fixes available” footer. Explicit experimental/preview hover descriptions address the related issue, but not this report’s request for a clearer, less confusing presentation.

## Change summary

Improve how experimental settings are identified in settings.json, including their visual prominence and irrelevant quick-fix messaging.

## Best solution

Agree on a consistent experimental-setting affordance that communicates instability without overwhelming settings.json, then address the non-actionable hover footer. The thread leaves warning-level, key-only decoration versus inlay-style presentation unresolved.
