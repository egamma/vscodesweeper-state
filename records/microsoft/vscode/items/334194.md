## Evidence

- **regex captures full URL:** Ran src/vs/workbench/contrib/debug/browser/linkDetector.ts's WEB_LINK_REGEX against the exact reported vite output ('http://localhost:5173/', 'http://192.168.0.123:5173/') in Node — both matches include the full host:port/path, not just the scheme+host.
- **single anchor per link:** createWebLink() (linkDetector.ts, ~line 226) sets link.textContent to the full matched value and returns one <a class="link"> node for the whole URL — there is no split between host and port/path.
- **hover underline CSS applies to the whole anchor:** The only underline rule for these links, `.monaco-list-row .expression .value a.link:hover { text-decoration: underline; }` in debug.contribution.css:121, targets the whole `<a>` element. Debug console output is rendered as `.output.expression > span.value` inside a `.monaco-list-row` (repl-tree, see replViewer.ts lines 141-142), so the selector matches and underlines the complete anchor on hover, not a partial substring.
