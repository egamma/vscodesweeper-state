# Issue #334194 — Debug Console: The Hyperlink annotation is missing a port.

[https://github.com/microsoft/vscode/issues/334194](https://github.com/microsoft/vscode/issues/334194)

## Summary

Confirmed in source: the Debug Console's ANSI handler splits text into separate stylized spans at every SGR escape boundary and runs link detection independently on each span, so a URL whose port is styled differently than the rest (as Vite's dev-server banner does, bolding the port number) gets truncated before the colon — matching the reporter's exact symptom.

## Change summary

In the Debug Console, a hyperlink for a URL like http://localhost:5173/ is only underlined up to "http://localhost" when the port number carries different ANSI styling (e.g. bold) than the rest of the line.

## Best solution

In src/vs/workbench/contrib/debug/browser/debugANSIHandling.ts, link detection needs to run over the full logical line (or at least across adjoining style spans) before splitting for per-span styling, rather than calling linkDetector.linkify() separately on each buffer flushed between SGR codes in handleANSIOutput — this is a structural fix to the ANSI-to-DOM pipeline, not a one-line patch.

## Evidence

- **regex works standalone:** WEB_LINK_REGEX in src/vs/workbench/contrib/debug/browser/linkDetector.ts (line 30) correctly matches the full 'http://localhost:5173/' when given the whole string intact.
- **root cause traced:** handleANSIOutput() in src/vs/workbench/contrib/debug/browser/debugANSIHandling.ts flushes the text buffer and calls appendStylizedStringToContainer()->linkDetector.linkify() every time an SGR escape sequence is hit (lines 61-67), so a URL split by a style change (e.g. bold on the port digits) is linkified in separate pieces.
- **reproduced the truncation:** Simulating the per-span calls with parts 'http://localhost:', '5173', '/' (as would occur if the port were bolded), WEB_LINK_REGEX matches only 'http://localhost' on the first chunk and nothing on the remaining chunks — exactly the reported behavior.
