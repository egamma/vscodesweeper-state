# Issue #330718 — (UX) Automations progress spinner should replace the watch icon

[https://github.com/microsoft/vscode/issues/330718](https://github.com/microsoft/vscode/issues/330718)

## Summary

Confirmed in source: the Automations section header always renders a static watch codicon in the leading icon slot, while the animated status indicator (spinner) is a separate element placed after the label — exactly the misalignment described. Routing to the Agents window area for a fix.

## Change summary

In the Agents window's Automations section header, the in-progress spinner appears to the right of the label instead of replacing the leading watch icon.

## Best solution

In SessionSectionRenderer.renderElement (src/vs/sessions/contrib/sessions/browser/views/sessionsList.ts), host the SessionStatusIcon in the leading `template.icon` slot for the Automations section (falling back to Codicon.watch when idle) instead of the separate `template.statusIndicator` element on the right, so hover actions/toolbar aren't obscured.
