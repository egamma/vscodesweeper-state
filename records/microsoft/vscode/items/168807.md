- **Behavior:**

  > Selected notebook cell inputs and outputs sometimes return to expanded after fully closing and reopening VS Code, although tab reopening and window reload preserve them. The existing VS Code-local collapse state should survive full restart for the same workspace and notebook. Acceptance covers mixed input/output collapse, repeated restarts, and subsequent expansion being remembered. Portable collapse metadata in notebook files and Markdown heading-section folding are outside this bug's scope.
