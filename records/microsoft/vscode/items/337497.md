# Issue #337497 — Uneven/ugly padding for modern UI sidebar

[https://github.com/microsoft/vscode/issues/337497](https://github.com/microsoft/vscode/issues/337497)

## Summary

Real visual defect in the opt-in Modern UI feature (workbench.experimental.modernUI) — the reporter's screenshots show uneven top/bottom padding in the sidebar that current main's padding.css doesn't obviously fix, so this stays open pending a maintainer/agent pass to pin down the exact rule.

## Change summary

With Modern UI enabled, the sidebar's vertical padding below the last list item is noticeably larger than its horizontal padding, looking asymmetric compared to the classic UI.

## Best solution
