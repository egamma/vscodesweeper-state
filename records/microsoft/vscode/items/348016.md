# Issue #348016 — Agents Window: agent host respawns the harness mid-session; two processes resume the same session ('agentHostManagement' timed out after 1000ms)

[https://github.com/microsoft/vscode/issues/348016](https://github.com/microsoft/vscode/issues/348016)

## Summary

Keep open: independent Windows and macOS reports confirm overlapping Claude processes resuming one conversation, lost replies, and missing conversational context. Current source still warrants lifecycle investigation; neither a complete fix nor a qualifying canonical duplicate was established.

## Change summary

Prevent overlapping Claude session rebuilds from splitting message delivery, response streaming, and conversation history across different processes.

## Best solution

Ensure each Claude conversation has one authoritative runtime throughout restart and recovery, preserving turn delivery and transcript continuity. Diagnose the double-rebuild ordering in the core Claude agent-host pipeline before choosing a bounded fix.
