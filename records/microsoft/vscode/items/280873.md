# Issue #280873 — bad api doc continuations for rust

[https://github.com/microsoft/vscode/issues/280873](https://github.com/microsoft/vscode/issues/280873)

## Summary

The reported end-of-line continuation behavior is owned by the installed Rust extension, not VS Code's built-in Rust language support, so it should be handled in that extension's tracker.

## Change summary

Preserve Rust documentation-comment prefixes such as `///` when continuing a comment onto the next line.

## Best solution

The installed Rust extension should preserve Rust documentation-comment prefixes when handling Enter; VS Code core's basic Rust support should retain its deliberately limited generic `//` continuation behavior.
