# Issue #306490 — bg terminal fails to start in other directory

[https://github.com/microsoft/vscode/issues/306490](https://github.com/microsoft/vscode/issues/306490)

## Summary

The current source still permits a background command's cd prefix to be removed using a foreground terminal's working directory, even though execution creates a fresh terminal. Keep this issue open in chat-terminal; the reporter's unsuccessful simplified reproductions do not rule out this traced path.

## Change summary

Background terminal commands can lose a necessary cd prefix and execute from the wrong directory; the report also questions misleading output summaries.

## Best solution

Ensure command simplification preserves the requested working directory in the terminal that actually executes the command, while retaining safe foreground simplification. Investigate the reported error-summary and literal undefined output separately without treating the cwd correction as proof that those symptoms are resolved.
