# Issue #349644 — replies to background-task notifications are never shown in the chat

[https://github.com/microsoft/vscode/issues/349644](https://github.com/microsoft/vscode/issues/349644)

## Summary

Keep open: current source silently drops Claude notification-driven responses when no host-submitted turn remains in the prompt queue. The report provides a deliberate reproduction and matching logs; related subagent-completion work does not cover these assistant replies.

## Change summary

Show Claude's responses to background-task notifications instead of silently omitting them from chat.

## Best solution

Represent SDK-initiated notification activity in the owning chat so users can see the resulting assistant response and distinguish completed background work from work still running. Establish its visible turn and history semantics before implementation.
