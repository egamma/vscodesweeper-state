## Summary

Keep open: Inspect Context Keys still requires mouse selection, so inspecting the previously focused element remains a genuine keyboard-accessibility gap. ## Change summary

Provide keyboard-only context-key inspection for the element focused before opening the Command Palette.

## Best solution

- **Behavior:**

  > Keyboard users need to discover context keys for a workbench element without clicking it. Invoking inspection through the Command Palette must target the element focused before the palette opened, not the palette itself. The timing of focus-dependent values and the result presentation remain product decisions.
