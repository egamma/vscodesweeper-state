# Issue #156160 — Option to save panel layouts globally instead of per-workspace.

[https://github.com/microsoft/vscode/issues/156160](https://github.com/microsoft/vscode/issues/156160)

## Summary

A meaningful gap remains: current main stores some layout properties globally but still keeps view sizes and collapsed state per workspace. The accepted Backlog request remains active and has recent community interest.

## Change summary

Allow users to reuse a preferred panel and view layout across new workspaces instead of rearranging it for every folder.

## Best solution

Add an explicit global/default layout scope for view sizes, collapsed state, visibility, and placement while preserving per-workspace layouts for users who need them. The implementation belongs in the workbench layout and view-state storage services.
