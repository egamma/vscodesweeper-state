# Issue #183761 — can't define keybinding for "prtsc"

[https://github.com/microsoft/vscode/issues/183761](https://github.com/microsoft/vscode/issues/183761)

## Summary

Still reproduces on main: PrintScreen (ScanCode.PrintScreen) is explicitly mapped to KeyCode.Unknown in keyCodes.ts, making it unbindable. The underlying cause (PrintScreen only fires keyup, not keydown) is an OS/browser-level quirk that VS Code has not worked around.

## Change summary

The PrintScreen key cannot be used in VS Code keybindings because it is mapped to KeyCode.Unknown and only fires a keyup event.

## Best solution

Add PrintScreen support by mapping ScanCode.PrintScreen to a real KeyCode and handling the keyup-only behavior in the keybinding resolver (src/vs/base/common/keyCodes.ts and the keybinding dispatch layer). This is a small but non-trivial change since the key dispatch assumes keydown events.
