## Summary

Keep open as a feature request for sharing marketplace-installed plugins with standalone Copilot CLI. Current source supports discovering CLI-installed plugins in VS Code, but that does not establish the reverse capability requested here.

## Change summary

Allow choosing a marketplace plugin installation location so plugins installed through VS Code are also available to Copilot CLI.

## Best solution

Provide a supported way for VS Code and standalone Copilot CLI to share installed plugins and their installation state, rather than assuming a shared directory alone is sufficient. Coordinate with the provider-owned plugin-management discussion while preserving this report's standalone CLI requirement.
