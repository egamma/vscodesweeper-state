# Issue #38149 — [folding] Hover can show region description on `#endregion`

[https://github.com/microsoft/vscode/issues/38149](https://github.com/microsoft/vscode/issues/38149)

## Summary

A real gap remains: current folding tracks paired region lines but does not expose the opening region's description when hovering over its closing marker. No older open issue reports the same observable request, so the stronger duplicate bar for this re-reviewed item is not met.

## Change summary

Show the opening `#region` description when the user hovers over the corresponding `#endregion` marker.

## Best solution

If prioritized, add a folding-aware hover for closing region markers that resolves the paired opening marker and presents its description without requiring users to duplicate the text on `#endregion`. The design should preserve ordinary language hovers and define behavior for syntax-provider ranges that do not carry a region name.

## Evidence

- **current source gap:** On current main, src/vs/editor/contrib/folding/browser/folding.ts handles folding mouse interactions but registers no hover behavior for closing markers.
- **available range data:** src/vs/editor/contrib/folding/browser/foldingModel.ts retains each folding region's start and end line, so paired lines are known, but src/vs/editor/common/languages.ts defines FoldingRange with only start, end, and kind—there is no description or display-name field.
- **marker implementation:** src/vs/editor/contrib/folding/browser/indentRangeProvider.ts pairs configured start and end markers into line ranges but discards the matched marker text, confirming that the requested description is not currently surfaced.
- **partial workaround:** https://github.com/microsoft/vscode/issues/38149#issuecomment-387668297 documents manually repeating the description on `#endregion`; this does not provide the requested automatic lookup and is less useful in languages such as HTML.
