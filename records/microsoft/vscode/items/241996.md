## Summary

Quoted-path support remains a real gap in terminal suggestions: current resource completion and filtering retain the opening quote as part of the matching text. Keep this accepted Backlog request open; no verified canonical or fixing commit was found.

## Change summary

Show usable terminal path suggestions when the cursor is inside a quoted PowerShell argument such as cd '|'.

## Best solution

Make PowerShell quoted path arguments work through resource lookup, suggestion filtering, and acceptance without corrupting the surrounding command. Preserve existing unquoted completion behavior and establish the supported quoting semantics before implementation.
