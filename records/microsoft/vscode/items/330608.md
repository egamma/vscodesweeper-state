# Issue #330608 — Chat History not syncing to other devices

[https://github.com/microsoft/vscode/issues/330608](https://github.com/microsoft/vscode/issues/330608)

## Summary

A VS Code contributor confirmed session sync is currently one-way (device → cloud only), with pull-down only available via manual chronicle commands, not automatic hydration into Chat History or the Agents window — this is a real, acknowledged gap rather than something to close.

## Change summary

Cloud-synced Copilot chat sessions do not automatically hydrate into Chat History / the Agents window on other devices, despite `chat.sessionSync.enabled` being on.

## Best solution

Either make session pull-down automatic in Chat History/Agents window (true two-way sync) or, short of that, clarify the setting's description and surface the manual chronicle commands more discoverably; belongs in src/vs/workbench/contrib/chat/browser/agentSessions and the sessionSync setting description in chat.shared.contribution.ts.
