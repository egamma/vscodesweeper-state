# Issue #330608 — Chat History not syncing to other devices

[https://github.com/microsoft/vscode/issues/330608](https://github.com/microsoft/vscode/issues/330608)

## Summary

Thanks for the report — this isn't a bug so much as a documented gap: `chat.sessionSync.enabled` currently only pushes local sessions to the cloud (see extensions/copilot/src/extension/chronicle/vscode-node/remoteSessionExporter.ts, a one-way "exporter"), it doesn't pull/hydrate remote sessions back into Chat History or the Agents window. A contributor confirmed this in the thread, and the workaround is chronicle SQL commands, not the UI. This is a real, still-open product gap and should be routed to the area owners rather than closed.

## Change summary

Chat sessions synced to the cloud from other devices don't appear in local Chat History / the Agents window — only push-to-cloud sync works, not pull-from-cloud hydration.

## Best solution

Either extend sessionSync (extensions/copilot/src/extension/chronicle/vscode-node/sessionSync.contribution.ts / remoteSessionExporter.ts) to hydrate remote cloud sessions into the local Agents window/Chat History list, or explicitly document that sync is currently push-only and cross-device access is via chronicle commands so users aren't misled by the setting name.
