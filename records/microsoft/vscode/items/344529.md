# Issue #344529 — Agent host (Copilot CLI): steering messages never handed to the running agent after it starts a background sub-agent

[https://github.com/microsoft/vscode/issues/344529](https://github.com/microsoft/vscode/issues/344529)

## Summary

Keep open: the reported sequence and logs suffice to retest steering stranded while the parent agent continues working. Current main includes deferred-handoff retries, but inspection does not establish that they resolve this background-subagent scenario.

## Change summary

Steering submitted to a running Copilot CLI parent chat remains pending indefinitely after background-subagent activity.

## Best solution

Establish where the addressed parent-chat message stops between renderer submission, host admission, and Copilot delivery, then restore reliable delivery without interrupting background agents or redirecting messages to child chats.
