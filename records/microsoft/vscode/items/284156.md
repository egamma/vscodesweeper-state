# Issue #284156 — Wildcard ("*": true) in github.copilot.enable does not apply to Markdown

[https://github.com/microsoft/vscode/issues/284156](https://github.com/microsoft/vscode/issues/284156)

## Summary

Still reproduces on main: the default setting has `"markdown": false` which persists through VS Code's object-settings merge, so the user's `"*": true` never overrides it. Valid UX issue from a team member — the wildcard semantics don't match user expectations.

## Change summary

Setting `"*": true` in `github.copilot.enable` does not enable Copilot for markdown because the default explicitly sets `"markdown": false`, and VS Code's settings merge preserves per-language defaults over the wildcard fallback.

## Best solution

Either change the wildcard semantics in `documentFilter.ts` so that an explicit user-set `"*": true` overrides default-only per-language `false` entries, or remove `"markdown": false` from the setting's default value in `package.json` (the `agentsWindow` variant already defaults markdown to `true`). The fix likely involves distinguishing user-provided values from defaults in `_isGhostTextEnabled`.
