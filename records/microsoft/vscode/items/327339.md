# Issue #327339 — Copilot harness doesn't work with remote repositories

[https://github.com/microsoft/vscode/issues/327339](https://github.com/microsoft/vscode/issues/327339)

## Summary

Consolidate this report into the verified open Remote Repositories support issue. The canonical predates this report and covers the same observable limitation: Copilot Agent Host cannot operate on files in a Remote Repositories virtual workspace.

## Change summary

Allow the Copilot harness to locate and edit files opened through Remote Repositories.

## Best solution
