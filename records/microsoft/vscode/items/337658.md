# Issue #337658 — Git: Allow merging the current branch's upstream from the merge picker

[https://github.com/microsoft/vscode/issues/337658](https://github.com/microsoft/vscode/issues/337658)

## Summary

The merge picker still excludes the upstream ref, and Pull does not preserve the requested fetch-free merge semantics. Route this reconsideration request to the Git owner; the earlier discussion established intentional behavior, not an explicit rejection of this feature request.

## Change summary

Allow selecting the current branch's upstream remote-tracking ref in Git: Merge... without fetching again or rebasing.

## Best solution

Have the Git owner decide whether the existing merge picker should support explicitly merging the locally available upstream ref while continuing to exclude the current local branch. Pull should remain a separate operation, not be treated as equivalent to this workflow.
