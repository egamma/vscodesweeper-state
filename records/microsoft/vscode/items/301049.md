# Issue #301049 — Trailing comma breaks fonts in editor.fontFamily, terminal.integrated.fontFamily

[https://github.com/microsoft/vscode/issues/301049](https://github.com/microsoft/vscode/issues/301049)

## Summary

The reported input still reaches font rendering without normalization: both editor and terminal font handling preserve a trailing comma and append another separator, producing an invalid font-family list. Keep this open for a bounded fix that preserves valid font lists and existing fallbacks.

## Change summary

Ignore a trailing separator in editor.fontFamily and terminal.integrated.fontFamily so the configured fonts continue to render.

## Best solution

Make the effective editor and terminal font lists tolerate a trailing separator without changing valid quoted font names, font ordering, or platform-specific fallbacks. Removing the comma is an immediate workaround, but does not satisfy the requested input tolerance.
