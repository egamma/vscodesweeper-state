# Issue #329436 — Custom OpenAI-compatible model streaming response usage metadata shows as "undefined" in Copilot chat log

[https://github.com/microsoft/vscode/issues/329436](https://github.com/microsoft/vscode/issues/329436)

## Summary

Well-diagnosed BYOK streaming bug with an open fixing PR already referencing this issue; keep open until that PR merges rather than closing early.

## Change summary

For custom OpenAI-compatible (BYOK) models with streaming enabled, the final SSE usage event is dropped when the provider closes the stream without a trailing newline or `[DONE]`, so token usage logs as `undefined` and the context-window indicator disappears.

## Best solution

Land and verify PR https://github.com/microsoft/vscode/pull/330547, which fixes the SSE reader to tolerate a stream ending immediately after the final usage event without a terminating line break; close this issue once that merges.
