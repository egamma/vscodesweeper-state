# Issue #201999 — The extensions list should have the ARIA listbox role; not the list role

[https://github.com/microsoft/vscode/issues/201999](https://github.com/microsoft/vscode/issues/201999)

## Summary

The Extensions list still receives role="list" while publishing aria-activedescendant; the requested semantic correction remains necessary. The merged active-descendant ordering fix explicitly excludes this role change, and the maintainers' question about changing shared list defaults remains unsettled.

## Change summary

Expose the selectable Extensions list with appropriate listbox semantics rather than a noninteractive list role.

## Best solution

Give the Extensions list consistent listbox, option, and selection semantics while preserving keyboard navigation and valid active-descendant ordering. Resolve the maintainers' broader scope question before changing the default accessibility semantics of unrelated list consumers.
