# Issue #168411 — local language specific setting priority is lower than user level language  specific setting

[https://github.com/microsoft/vscode/issues/168411](https://github.com/microsoft/vscode/issues/168411)

## Summary

Confirmed bug with an open fix PR (#285034) awaiting review — keeping open as the fix lane is active and team-acknowledged.

## Change summary

Multi-language workspace language-specific settings (e.g. `[javascript][typescript]`) have lower priority than single-language user-level language-specific settings, breaking the expected workspace-overrides-user precedence.

## Best solution

Land the open fix PR https://github.com/microsoft/vscode/pull/285034 after review by @sandy081, who acknowledged the bug and committed to reviewing. The fix should ensure multi-language workspace overrides take precedence over single-language user overrides, consistent with the general workspace > user settings rule.
