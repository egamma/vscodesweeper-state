# Issue #331511 — Keep/Undo covers up the new text

[https://github.com/microsoft/vscode/issues/331511](https://github.com/microsoft/vscode/issues/331511)

## Summary

Freshly reported UI overlap issue in the chat-editing diff-hunk toolbar (Keep/Undo), and the positioning code confirms the toolbar is placed as an absolute overlay at the top-right corner of the modified line block without any check against the actual line content width, so it can visually cover the new text it is meant to let you review.

## Change summary

The Keep/Undo hunk toolbar for AI-edited code renders directly on top of the new text it's reviewing, instead of beside or above it without overlap.

## Best solution

In DiffHunkWidget.layout() (chatEditingCodeEditorIntegration.ts), reposition or shrink/offset the overlay when it would intersect the actual rendered content of the affected line(s), similar to how other content widgets (suggest/hover) avoid covering their anchor context; likely needs a design decision (e.g., placing it in the line's trailing gutter only when there's room, or moving it to a dedicated view-zone row) rather than a pure bug-fix.
