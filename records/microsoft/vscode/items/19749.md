# Issue #19749 — Add action to show inline all diagnostics in file.

[https://github.com/microsoft/vscode/issues/19749](https://github.com/microsoft/vscode/issues/19749)

## Summary

This remains the canonical, community-backed request for showing all file diagnostics inline. Current main still only presents one marker-navigation widget at a time, and the issue has qualified for the Backlog with 61 upvotes.

## Change summary

Add an opt-in editor action that displays every diagnostic in the current file inline.

## Best solution

Implement a native editor action using view zones or another non-scrolling inline presentation, preserving existing diagnostic navigation while avoiding the rendered-target-line limitation identified by maintainers.
