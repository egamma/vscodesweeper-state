# Issue #14836 — Add "find all occurences" in the current file feature

[https://github.com/microsoft/vscode/issues/14836](https://github.com/microsoft/vscode/issues/14836)

## Summary

Keep open: selecting or highlighting matches does not provide the requested navigable results list scoped to the current file. Two linked implementation PRs remain open, and the existing search labels already route this appropriately.

## Change summary

Provide a convenient action from the editor Find widget to list all matching lines in the current file.

## Best solution

Provide a discoverable current-file results action that carries over the Find query and options into a navigable results surface. Review the existing implementation candidates, especially https://github.com/microsoft/vscode/pull/128915, rather than starting a competing implementation.
