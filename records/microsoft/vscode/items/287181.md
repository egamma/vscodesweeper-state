# Issue #287181 — Activate.ps1 messes up shell integration exit code

[https://github.com/microsoft/vscode/issues/287181](https://github.com/microsoft/vscode/issues/287181)

## Summary

Team-authored bug, still present on main. The Python activation via command in shellIntegration.ps1 corrupts the exit code because the Invoke-Expression on line 83 alters $?/$LASTEXITCODE, and the OriginalPrompt capture on line 84 happens after activation without preserving/restoring exit code state. No fix commit references this issue.

## Change summary

Running Python's Activate.ps1 via command in PowerShell terminal corrupts the shell integration exit code reporting.

## Best solution

In `src/vs/workbench/contrib/terminal/common/scripts/shellIntegration.ps1`, the activation block (lines 82–89) should save `$?`/`$LASTEXITCODE` before `Invoke-Expression $activateScript` and restore them afterward, and the OriginalPrompt capture on line 84 needs to account for the prompt function being replaced by activation. The author's comment 3 confirms the prompt function needs updating post-activation.
