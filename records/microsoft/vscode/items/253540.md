# Issue #253540 — Improve chat input editing experience with expandable editor or prompt file

[https://github.com/microsoft/vscode/issues/253540](https://github.com/microsoft/vscode/issues/253540)

## Summary

Keep open: current prompt-file commands provide a spacious editor but do not expand an existing chat draft into it, and the linked prototype was closed without merging. The maintainer's objection concerns adding input buttons, leaving the authoring workflow open for a product decision.

## Change summary

Allow long or multiline chat drafts to be edited in an expanded surface or an untitled prompt file.

## Best solution

Provide a discoverable, keyboard-accessible way to continue editing an existing chat draft in a spacious surface without losing its content. Decide whether this should remain an inline composer or become a prompt-file workflow, accounting for the maintainer's objection to additional input buttons.
