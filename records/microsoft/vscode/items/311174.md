# Issue #311174 — Icon theme missing after update to 1.116.0

[https://github.com/microsoft/vscode/issues/311174](https://github.com/microsoft/vscode/issues/311174)

## Summary

Confirmed Windows update bug: the versioned (commit-hash-named) resource folder changes on every update, breaking icon paths both for manually-configured shortcuts and for Windows Start Menu tile caching. A team member is actively investigating. Related issue #322323 describes the same root cause from the tile perspective.

## Change summary

VS Code's desktop/Start Menu icon disappears after auto-update because the hash-named resource subfolder changes, invalidating cached icon paths.

## Best solution

The installer (build/win32/code.iss) should either invalidate the Windows icon cache after update (SHChangeNotify / ie4uinit) or ensure stable icon paths that survive the versioned-folder rename. The VisualElementsManifest tile PNG path issue (related #322323) shares the same root cause and should be addressed together.
