# Issue #150793 — Does not fit well in side panel

[https://github.com/microsoft/vscode/issues/150793](https://github.com/microsoft/vscode/issues/150793)

## Summary

Keep open: the Problems table still lacks a compact presentation for narrow sidebars, and existing resizing and tree mode do not fully cover the request. Horizontal scrolling is related work, but its open issue does not own the distinct requirement to show useful diagnostic content without scrolling.

## Change summary

Make the Problems view useful at narrow widths by shortening file labels and reducing the space consumed by secondary diagnostic metadata.

Define a compact Problems presentation that prioritizes the diagnostic message and recognizable filename while keeping secondary metadata discoverable. Settle how this interacts with horizontal scrolling and user-controlled column visibility before implementation.
