# Issue #150793 — Does not fit well in side panel

[https://github.com/microsoft/vscode/issues/150793](https://github.com/microsoft/vscode/issues/150793)

## Summary

The narrow-layout gap remains on main: the Problems table preserves fixed minimum widths and does not adapt or hide secondary columns. This team-authored Backlog item should remain open under its existing error-list routing.

## Change summary

Make the Problems table useful in narrow side-panel layouts by prioritizing message and filename content over secondary columns.

## Best solution

Add responsive column behavior in `markersTable.ts`: compact the file presentation and collapse Code and Source as space decreases, while retaining full content at wider sizes. Horizontal scrolling from https://github.com/microsoft/vscode/issues/150186 can complement this but does not replace a useful at-a-glance narrow layout.
