# Issue #349224 — Agents window is really unfriendly for long time users of sessions in editor windows

[https://github.com/microsoft/vscode/issues/349224](https://github.com/microsoft/vscode/issues/349224)

## Summary

Keep open: existing automatic cleanup and group-wide completion actions help, but do not provide the requested discoverable, one-time cleanup of merged-PR sessions across workspaces. This team-authored request has neither a verified canonical duplicate nor an explicitly referencing fix.

## Change summary

Offer bulk completion of historical sessions with merged pull requests when adopting the Agents Window.

## Best solution

Provide an explicit bulk cleanup action for eligible merged-PR sessions without requiring users to enable ongoing automatic cleanup. Reuse existing session archival semantics and consider onboarding discovery separately.
