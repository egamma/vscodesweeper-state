[https://github.com/microsoft/vscode/issues/349224](https://github.com/microsoft/vscode/issues/349224)

## Summary

Keep open: existing automatic cleanup and section-wide actions do not provide the requested one-shot, merged-PR-selective cleanup for accumulated history. This team-authored request has no verified fixing commit or canonical duplicate.

## Change summary

Offer bulk marking of sessions with merged pull requests as Done to reduce historical clutter when adopting the Agents Window.

## Best solution

Provide a discoverable, explicit bulk cleanup action that identifies eligible merged-PR sessions and follows the existing restorable Done lifecycle. Reuse existing cleanup eligibility and archive safeguards rather than requiring users to enable an ongoing cleanup policy.
