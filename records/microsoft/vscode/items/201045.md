# Issue #201045 — Replace in files global command should move focus

[https://github.com/microsoft/vscode/issues/201045](https://github.com/microsoft/vscode/issues/201045)

## Summary

Keep open: the current command still chooses its focus target from whether search text was seeded, rather than the currently focused input. With focus already in the Search view, Replace in Files reveals the replacement input but focuses Search instead.

## Change summary

Make repeated Replace in Files invocations move focus between the Search and Replace inputs, consistently with the editor find widget.

## Best solution

Make the Search view's Replace in Files command honor the existing input focus when invoked repeatedly, while preserving editor-selection seeding and the ordinary Find in Files behavior.
