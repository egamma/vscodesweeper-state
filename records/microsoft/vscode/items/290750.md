# Issue #290750 — Drop target too small when using integrated browser

[https://github.com/microsoft/vscode/issues/290750](https://github.com/microsoft/vscode/issues/290750)

## Summary

Team-filed bug about the integrated browser's drop target being too small — no fix has landed on main, and the browserView component has no drag-and-drop handling code at all, confirming the gap remains.

## Change summary

When dragging a file from the explorer into the integrated browser area, the drop target is only available at the top of the screen instead of covering the full browser pane.

## Best solution

Expand the drop target area in the integrated browser editor pane (likely in `src/vs/workbench/contrib/browserView/`) to cover the full browser surface, similar to how the chat widget's dndContainer was expanded in commit 8f95a9c3229. The browserView component currently has no drop-handling code, so a drop overlay or dndContainer needs to be wired up.
