# Issue #339764 — Signing in was awkward experience

[https://github.com/microsoft/vscode/issues/339764](https://github.com/microsoft/vscode/issues/339764)

## Summary

Fresh dogfooding report (same day, no comments yet) of a brief UI flicker when signing in with a Microsoft account: the native OS account picker is followed by a flash of VS Code's generic sign-in UI instead of a clear 'Microsoft sign-in in progress' state. Plausible and specific (video attached), but too new for any maintainer triage or code trace to confirm root cause yet.

## Change summary

After picking an account in the native Microsoft account picker, VS Code briefly flashes its own sign-in UI without an MS-specific 'in progress' indicator before completing.

## Best solution

Investigate how the authentication progress/quick-pick UI in core (src/vs/workbench/services/authentication) hands off from the native MSAL/broker account picker to VS Code's own sign-in dialog, and smooth the transition (e.g. keep provider branding/progress state visible) so there's no unbranded flicker.
