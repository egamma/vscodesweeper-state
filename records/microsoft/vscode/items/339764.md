# Issue #339764 — Signing in was awkward experience

[https://github.com/microsoft/vscode/issues/339764](https://github.com/microsoft/vscode/issues/339764)

## Summary

Keep open: current onboarding source still leaves the provider choices visible while Microsoft sign-in is pending, without identifying the ongoing operation. This team-authored UX report has no verified fixing commit or canonical duplicate.

## Change summary

Make the welcome screen clearly communicate pending Microsoft sign-in instead of returning to apparently idle provider choices with a flickering Microsoft icon.

## Best solution

The welcome onboarding sign-in step should remain clear and stable throughout Microsoft authentication, including after the native account picker returns. The onboarding owner should settle whether that means provider-specific progress feedback or retaining the selected provider visibly, while preserving account-link eligibility and cancellation behavior.
