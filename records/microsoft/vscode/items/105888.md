# Issue #105888 — Line height setting consistency

[https://github.com/microsoft/vscode/issues/105888](https://github.com/microsoft/vscode/issues/105888)

## Summary

The original editor request and Output-panel customization are now covered, but a meaningful consistency gap remains: `editor.suggestLineHeight` and `debug.console.lineHeight` still lack the relative sizing semantics supported by `editor.lineHeight`. The related issue is newer than this re-reviewed item, so it cannot serve as its duplicate canonical.

## Change summary

Make line-height settings use consistent, font-relative semantics across the editor, suggestions, Debug Console, Markdown preview, terminal, and Output panel.

## Best solution

Preserve compatibility while extending `editor.suggestLineHeight` and `debug.console.lineHeight` with the same relative-value convention already supported by `editor.lineHeight`; keep Output customization based on the existing `[Log]` language override rather than coupling it to terminal settings.
