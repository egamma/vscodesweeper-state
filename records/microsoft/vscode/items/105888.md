# Issue #105888 — Line height setting consistency

[https://github.com/microsoft/vscode/issues/105888](https://github.com/microsoft/vscode/issues/105888)

## Summary

Partially addressed — editor.lineHeight now supports relative units (PR #125601), but the remaining asks (relative units for editor.suggestLineHeight and debug.console.lineHeight, Output panel line height) are still unimplemented on main. Team members were assigned sub-parts in late 2022 but no follow-up landed.

## Change summary

Make editor.suggestLineHeight and debug.console.lineHeight accept relative/em-based values (like editor.lineHeight), and give the Output panel its own line height or sync it with the terminal.

## Best solution

Apply the same relative-unit approach from editor.lineHeight (PR #125601) to editor.suggestLineHeight and debug.console.lineHeight. The Output panel concern has a workaround via language overrides ("[Log]": {"editor.lineHeight": N}) noted by a team member, so that part may be lower priority.
