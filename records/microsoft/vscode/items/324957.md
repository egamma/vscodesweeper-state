[https://github.com/microsoft/vscode/issues/324957](https://github.com/microsoft/vscode/issues/324957)

## Summary

Real, actively-affecting regression with a clear root cause: the passive chat-sessions refresh path throws when the user isn't signed in to GitHub, and this surfaces as an unhandled telemetry error rather than a silent empty list. An open PR already targets the fix, so this should stay open until it lands rather than being closed now.

## Change summary

Chat Sessions view background refresh throws 'Sign in to GitHub to use the Cloud Agent' as an unhandled error when the user has no permissive GitHub session, instead of failing quietly.

## Best solution

Land https://github.com/microsoft/vscode/pull/324964, which adds a guard in `provideChatSessionItems` (copilotCloudSessionsProvider.ts) checking `this._authenticationService.permissiveGitHubSession` before calling `fetchSessionList`, returning `[]` instead of letting the auth-header throw from `taskApiBackend.ts` propagate as an unhandled error.
