# Issue #238908 — Setting change does not re-render notebook markdown

[https://github.com/microsoft/vscode/issues/238908](https://github.com/microsoft/vscode/issues/238908)

## Summary

Still present on main: the `MarkupCell` option-change handler (line 165–169 of markupCell.ts) only reacts to `showFoldingControls`, not `markupFontFamily`. The Copilot-authored PR #251025 was closed without merging, so the gap remains. Team-authored debt item — keeping open.

## Change summary

Changing the `notebook.markupFontFamily` setting does not re-render notebook markdown cells until the editor is closed and reopened.

## Best solution

Extend the `onDidChangeOptions` handler in `src/vs/workbench/contrib/notebook/browser/view/cellParts/markupCell.ts` to check `e.markupFontFamily` and re-render preview-mode cells via `createMarkupPreview()`. The fix is small — roughly the approach PR #251025 attempted.
