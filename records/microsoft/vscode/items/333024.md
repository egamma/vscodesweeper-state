# Issue #333024 — Pet Z index should be higher than sticky scroll

[https://github.com/microsoft/vscode/issues/333024](https://github.com/microsoft/vscode/issues/333024)

## Summary

Confirmed in source: the chat pet button/respawn effect uses `z-index: 1` (src/vs/workbench/contrib/chat/browser/widget/media/chatPet.css:41-44) while the tree's sticky-scroll container uses `z-index: 13` (src/vs/base/browser/ui/tree/media/tree.css:130), so when the pet is thrown up over the conversation it renders underneath the sticky header, matching the reported 'bounces off an invisible boundary' behavior. A second reporter corroborated this with a screenshot.

## Change summary

The chat pet renders behind (under) the sticky-scroll header instead of on top of it when thrown to the top of the chat view.

## Best solution

Bump the stacking of `.chat-pet-button`/`.chat-pet-respawn-effect` above the tree's sticky-scroll z-index (13) in chatPet.css, or otherwise ensure the pet overlay's stacking context sits above `.monaco-tree-sticky-container`; belongs with the chat pet feature owner.
