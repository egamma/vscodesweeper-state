# Issue #333024 — Pet Z index should be higher than sticky scroll

[https://github.com/microsoft/vscode/issues/333024](https://github.com/microsoft/vscode/issues/333024)

## Summary

Team-authored, open bug that still reproduces on main by source trace — dragging was fixed to sit above sticky scroll (z-index 14) but the throw/bounce animation still uses the base z-index 1, so it renders under the tree sticky-scroll header (z-index 13). Keeping open; this is a small, well-scoped CSS fix.

## Change summary

The chat pet's throw/bounce animation renders behind sticky scroll, even though dragging was already fixed to render above it.

## Best solution

Extend the elevated z-index rule currently scoped to `.chat-pet-button.dragging` (chatPet.css) to also cover the `throwing`/bounce animation state so the pet stays above the tree sticky-scroll header (z-index 13) during all animations, not just drag.
