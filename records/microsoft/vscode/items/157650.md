# Issue #157650 — Limit the amount of shown inlay hints

[https://github.com/microsoft/vscode/issues/157650](https://github.com/microsoft/vscode/issues/157650)

## Summary

The requested per-line character budget already exists as editor.inlayHints.maximumLength, but it truncates the first overflowing hint rather than suppressing it completely. Keep this team-authored issue open for the owner's assessment: the covering implementation does not explicitly reference this issue, so it does not meet the protected-item completion bar.

## Change summary

Limit aggregate inlay-hint characters per line so parameter-heavy calls remain readable without disabling hints in ordinary code.

## Best solution

Use the existing editor.inlayHints.maximumLength mechanism rather than introduce another character-budget setting. The owner should determine whether truncating the boundary hint satisfies the request or whether whole-hint suppression remains necessary.
