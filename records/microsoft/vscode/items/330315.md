# Issue #330315 — Corner radius of promotions widget is not aligned with the chat input widget

[https://github.com/microsoft/vscode/issues/330315](https://github.com/microsoft/vscode/issues/330315)

## Summary

Confirmed on main: the chat input notification (promo) widget's top corners use `--vscode-cornerRadius-small` while the chat input container and every other stacked widget above it (todo list, artifacts, editing session) use `--vscode-cornerRadius-large` — the mismatched token is exactly the misalignment shown in the screenshot.

## Change summary

The promotions/notification banner shown above the chat input has a smaller corner radius than the chat input box it sits on top of, so the two don't visually align.

## Best solution

Update the top-left/top-right border-radius rules in chatInputNotificationWidget.css (currently `var(--vscode-cornerRadius-small, 4px)`) to `var(--vscode-cornerRadius-large)` to match chat-input-container and the other stacked widgets (chat-todo-list-widget, chat-artifacts-widget, chat-editing-session-container all use cornerRadius-large for their top corners).
