# Issue #189960 — [Accessibility] Add a setting for users to choose whether to hear partial or the complete token in inline suggestion alert

[https://github.com/microsoft/vscode/issues/189960](https://github.com/microsoft/vscode/issues/189960)

## Summary

The requested announcement choice remains missing: current inline suggestion alerts omit the already-typed prefix, and existing accessibility settings do not change that. Keep this accepted Backlog request open under its existing area labels.

## Change summary

Allow screen reader users to choose between announcing the remaining inline suggestion text and the complete token, including the typed prefix.

## Best solution
