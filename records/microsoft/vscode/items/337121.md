# Issue #337121 — Show type of suggested member

[https://github.com/microsoft/vscode/issues/337121](https://github.com/microsoft/vscode/issues/337121)

## Summary

The core suggest widget already supports showing type/detail text for completion items (the `detail`/`label.detail`/`label.description` right-hand text), so this is about what the C# language extension populates in its completion items, not a core gap — the C# extension isn't owned by the VS Code team, so this belongs in its own repo.

## Change summary

C# IntelliSense member suggestions don't show the member's type alongside its name, unlike Visual Studio.

## Best solution

Ask the reporter to file this against the C# extension (dotnet/vscode-csharp or the C# Dev Kit feedback channel) so its completion provider populates `CompletionItem.detail`/label detail with the member's type — the core suggest widget already renders that field.
