# Issue #336919 — Closing and reopening vscode with an undocked chat window will reopen a completely blank window instead of the chat

[https://github.com/microsoft/vscode/issues/336919](https://github.com/microsoft/vscode/issues/336919)

## Summary

The merged fix for chat-session handoffs covers this exact failure mode: moved sessions remain persisted and reopenable after their source window closes. The implementation and regression tests landed after this report, so this can close as completed.

## Change summary

Reopening a chat previously moved to an auxiliary window could produce a blank, unusable window instead of restoring the session.

## Best solution

Keep the session model retained until the destination window acquires it and distinguish model unloading from explicit history deletion, as implemented in https://github.com/microsoft/vscode/commit/14200868c7fb67eb932fbdf69abbe0f87b5da837.
