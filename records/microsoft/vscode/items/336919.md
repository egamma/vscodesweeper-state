# Issue #336919 — Closing and reopening vscode with an undocked chat window will reopen a completely blank window instead of the chat

[https://github.com/microsoft/vscode/issues/336919](https://github.com/microsoft/vscode/issues/336919)

## Summary

Same root cause as the older, closed issue https://github.com/microsoft/vscode/issues/336748 (moving a chat into a new window, then reopening after restart leaves the session unusable/blank) — fixed on main by commit 14200868c, which the PR itself ties to that issue.

## Change summary

After using 'Open in New Window' on a chat session, closing and reopening VS Code and clicking that session opens a completely blank auxiliary window.

## Best solution

Keep the shipped fix in commit 14200868c7fb67eb932fbdf69abbe0f87b5da837 (merged PR https://github.com/microsoft/vscode/pull/337232), which keeps the chat model's reference alive across the window move so the autosaved session's initial transcript entry isn't deleted before the destination window acquires it — the exact blank/unreopenable-session symptom reported here.
