# Issue #303061 — /COMPACT caused the plan chat session to get deleted

[https://github.com/microsoft/vscode/issues/303061](https://github.com/microsoft/vscode/issues/303061)

## Summary

This was the same history-deletion defect diagnosed in the older report https://github.com/microsoft/vscode/issues/299477 and fixed by merged PR https://github.com/microsoft/vscode/pull/307721. The fix shipped in 1.116.0 and remains present on current main, so this can be closed as completed.

## Change summary

Using the context widget's Compact action after a plan/checkpoint state removed the visible conversation history and then reported that there was nothing to compact.

## Best solution

Keep the shipped checkpoint-cleanup fix from commit b3afb80fdb069644a078706c20da2d7b14d60401; it ensures submission removes only blocked requests and the checkpoint request rather than treating every request as blocked.
