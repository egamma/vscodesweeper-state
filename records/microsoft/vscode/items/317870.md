# Issue #317870 — Mermaid diagrams fail to render after 1.121 upgrade when bierner.markdown-mermaid is still installed

[https://github.com/microsoft/vscode/issues/317870](https://github.com/microsoft/vscode/issues/317870)

## Summary

Keep open for the Mermaid upgrade compatibility gap: independent reports confirm that retaining the superseded extension can break Markdown diagrams, and uninstalling it restores rendering. No verified fixing commit or canonical issue fully covers this report; its existing steps suffice for a current-build retest.

## Change summary

Prevent Mermaid Markdown previews from silently failing after an upgrade when bierner.markdown-mermaid remains installed.

## Best solution

Provide a reliable transition from the superseded Mermaid extension to built-in rendering, without silently breaking existing previews. The Mermaid and extension-management owners should settle whether conflict handling is advisory or automatic, while preserving users' ability to choose another renderer.
