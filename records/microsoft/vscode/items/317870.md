# Issue #317870 — Mermaid diagrams fail to render after 1.121 upgrade when bierner.markdown-mermaid is still installed

[https://github.com/microsoft/vscode/issues/317870](https://github.com/microsoft/vscode/issues/317870)

## Summary

The rendering failure is caused by the third-party extension `bierner.markdown-mermaid` conflicting with the new built-in `mermaid-markdown-features` extension — the reporter confirmed that uninstalling the third-party extension resolves it. VS Code already has deprecation infrastructure to mark superseded marketplace extensions; the remaining suggestion (deprecation marker on the old extension) is a marketplace/ops action, not a core code change.

## Change summary

Mermaid diagrams silently fail to render in VS Code 1.121 when the superseded third-party extension `bierner.markdown-mermaid` is still installed alongside the new built-in `mermaid-markdown-features`.

## Best solution

Close as caused-by-extension. The fix is to uninstall `bierner.markdown-mermaid`. If not already done, the VS Code team should mark `bierner.markdown-mermaid` as deprecated in the extensions control manifest (the infrastructure already exists in `src/vs/platform/extensionManagement/common/extensionGalleryService.ts`) so that users see a deprecation notice and migration prompt automatically.
