# Issue #198399 — Mutilple cursor also includes wrapped lines

[https://github.com/microsoft/vscode/issues/198399](https://github.com/microsoft/vscode/issues/198399)

## Summary

This remains a valid multi-cursor bug: the issue includes a concrete mouse reproduction and video, and an independent user confirms the same behavior. The existing keyboard fix does not cover mouse-based column selection across wrapped visual lines.

## Change summary

Mouse-based multi-cursor or column selection creates an extra cursor on a wrapped visual line instead of one cursor per logical line.

## Best solution

Make mouse-driven column selection use the same wrapped-line exclusion semantics already established for keyboard column selection, while preserving ordinary Alt/Option-click cursor placement and rectangular selection on unwrapped lines.

Typing after selection must keep each cursor associated with its intended logical line as wrapping changes. Existing Alt/Option-click multi-cursor placement and box selection across unwrapped lines must remain unchanged.
