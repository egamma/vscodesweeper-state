# Issue #198399 — Mutilple cursor also includes wrapped lines

[https://github.com/microsoft/vscode/issues/198399](https://github.com/microsoft/vscode/issues/198399)

## Summary

The mouse-based multi-cursor path still treats wrapped visual lines as separate cursor targets, while the equivalent keyboard path was fixed to operate on model lines. A second independent report confirms the behavior, so this should remain open in the multi-cursor editor area.

## Change summary

Alt+Shift mouse gestures add an unintended cursor at a soft-wrapped visual-line boundary.

## Best solution

Make mouse multi-cursor and column-selection gestures follow the keyboard behavior established by commit c0d32634fb0cbf18ec82d6167ab2accc0c9f17f5: one cursor per model line rather than per wrapped view line, with regression coverage for both mouse gestures.
