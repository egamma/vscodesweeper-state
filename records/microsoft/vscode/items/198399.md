# Issue #198399 — Mutilple cursor also includes wrapped lines

[https://github.com/microsoft/vscode/issues/198399](https://github.com/microsoft/vscode/issues/198399)

## Summary

Still reproduces on main: Alt+Shift+Click column selection operates on view line numbers, which include wrapped lines, creating unwanted cursors at wrap points. The keyboard shortcut was fixed in 2021 but the mouse path was not.

## Change summary

Alt+Shift+Click to create multi-cursors across lines also places cursors on wrapped (virtual) lines, not just real document lines.

## Best solution

Apply the same wrapped-line-collapsing logic from the keyboard InsertCursorAbove/Below fix (commit c0d32634fb) to the mouse column-select path. The fix likely belongs in `src/vs/editor/browser/view/viewController.ts` (the `_columnSelect` dispatch) or in `src/vs/editor/common/cursor/cursorColumnSelection.ts` (the `columnSelect` loop), mapping view line numbers back to model lines before creating cursors.

- **mouse dispatch path:** src/vs/editor/browser/view/viewController.ts line 285: Alt+Shift+Click dispatches to `_columnSelect(data.position, data.mouseColumn, true)` using view positions that include wrap points.
- **keyboard fix not applied to mouse:** Commit c0d32634fb (Oct 2021, PR #135805) fixed InsertCursorAbove/Below for wrapped lines but did not touch the column-select mouse path, as confirmed by commenter misterpyrrhuloxia.
- **no fix on main:** git log on cursorColumnSelection.ts since Nov 2023 shows no relevant changes; the view-line iteration is still unguarded.
