# Issue #331947 — The VS Code PowerShell Extension "Play" button fails to load Microsoft.Graph.Authentication v2.36.0–2.39.0 (works with v2.35.0)

[https://github.com/microsoft/vscode/issues/331947](https://github.com/microsoft/vscode/issues/331947)

## Summary

The reported failure is in the PowerShell extension's runtime (PowerShell Editor Services assembly loading), not in VS Code core — the `ms-vscode.powershell` extension is developed and maintained in the separate PowerShell/vscode-powershell (and PowerShellEditorServices) repositories, so this should be filed there.

## Change summary

The 'Play' button in the PowerShell extension fails to load newer Microsoft.Graph.Authentication versions (2.36.0–2.39.0) due to an assembly conflict in the extension's PowerShell Editor Services host.

## Best solution

Reporter should file this against PowerShell/vscode-powershell (or PowerShellEditorServices), which owns the runtime hosting and assembly-loading behavior described; nothing in microsoft/vscode needs to change.
