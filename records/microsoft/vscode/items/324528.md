# Issue #324528 — Model used by Auto does not show when /compact is run

[https://github.com/microsoft/vscode/issues/324528](https://github.com/microsoft/vscode/issues/324528)

## Summary

The defect remains source-reproducible on main: manual `/compact` receives the compaction model but publishes post-compaction usage with an undefined top-level model, so the AHP response cannot identify the model Auto used. This team-authored, accepted bug should remain open.

## Change summary

Show the concrete model selected by Auto in the response details for an AHP `/compact` turn.

## Best solution

Preserve the compaction call's reported model in the completed `/compact` turn usage so AHP renders the same concrete model attribution as ordinary Auto turns and local chat.
