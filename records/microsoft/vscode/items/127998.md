# Issue #127998 — Interactive Window at the bottom of the screen

[https://github.com/microsoft/vscode/issues/127998](https://github.com/microsoft/vscode/issues/127998)

## Summary

The Interactive Window is still implemented as an editor pane with no option to place it in the bottom panel; the feature remains unimplemented on current main. With 24 upvotes and steady community interest, this stays open in Backlog.

## Change summary

Allow the Interactive Window to appear as a tab in the bottom panel alongside Terminal, Problems, Output, and Debug Console.

## Best solution

Implement an option to open the Interactive Window in the bottom panel (ViewContainerLocation.Panel). This likely requires changes in `src/vs/workbench/contrib/interactive/browser/interactive.contribution.ts` to register a panel-compatible view or add a setting controlling editor group location. The 'split down' workaround doesn't satisfy the request — users want it at the same level as Terminal/Debug Console.
