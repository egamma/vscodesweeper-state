# Issue #332493 — Feature Request: Expose settings.json configuration for integrated browser proxy

[https://github.com/microsoft/vscode/issues/332493](https://github.com/microsoft/vscode/issues/332493)

## Summary

Fresh, credible feature request confirmed by code inspection: local integrated-browser sessions never get a proxy set (only the remote tunnel path does), so there's a real gap and no existing setting covers it — it's in the Backlog Candidates holding bin with 0 upvotes and only 2 days old, so the community upvote/age process should run its course.

## Change summary

Add settings.json options to configure a dedicated proxy (and bypass list) for the integrated browser, independent of the OS-level system proxy and unrelated to `http.proxy`.

## Best solution

Design and land a `workbench.browser.proxy`/`proxyBypassList` (or similar) setting that calls `session.setProxy()` on the local browser-view Electron session in src/vs/platform/browserView/electron-main/browserSessionRemote.ts (currently only wired for the remote tunnel case) — a contributor has already offered to implement it and raised a reasonable design question (dedicated setting vs. following `http.proxy` with an opt-in toggle) that a maintainer should weigh in on.
