## Summary

Legitimate, newly-filed feature request: the integrated browser currently has no dedicated network-proxy setting, so `http.proxy`/`http.noProxy` don't reach it. Too fresh (0 days old, no upvotes, no maintainer input) to judge scope or priority — keep open for the area owners.

## Change summary

Add settings.json options (e.g. `workbench.browser.proxy`, `workbench.browser.proxyBypassList`) so the integrated browser can use a dedicated proxy independent of the OS-wide system proxy.
