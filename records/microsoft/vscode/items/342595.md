# Issue #342595 — Copilot harness (Agent Host): "Instructions" missing from attach picker; unclear how attached/applyTo instructions are loaded and persisted

[https://github.com/microsoft/vscode/issues/342595](https://github.com/microsoft/vscode/issues/342595)

## Summary

Keep open: current source still hides the Instructions picker for Agent Host sessions, and automatic instruction discovery does not establish the requested explicit session-pinning contract. The missing capability and its persistence semantics need a product decision, not a support-question close.

## Change summary

Provide explicit session instruction attachment in the Copilot harness, or a documented equivalent with clear loading and compaction semantics.

## Best solution

Define a supported way to select instructions explicitly for a Copilot session and explain how that selection differs from ordinary file attachments and automatic applyTo discovery. Agree on the lifetime and compaction contract before exposing a picker that could imply unsupported guarantees.
