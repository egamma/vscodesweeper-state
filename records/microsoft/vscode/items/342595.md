## Summary

Keep open as an instruction-attachment parity and persistence-contract request. Current source explains the missing picker entry, but neither automatic discovery nor ordinary file attachments establishes the session-long instruction behavior requested here.

## Change summary

Provide explicit session-scoped instruction attachments in the Copilot harness, with documented loading and compaction semantics.

## Best solution

Define and expose a supported way to select instructions for a Copilot session, documenting how explicit instructions differ from ordinary files and automatically discovered applyTo rules, including behavior after compaction and restoration. Resolve the contract across the chat attachment surface and Copilot runtime before enabling a picker that might imply unsupported persistence guarantees.
