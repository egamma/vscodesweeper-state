# Issue #225514 — History graph diff always shows horizontal scroll bar

[https://github.com/microsoft/vscode/issues/225514](https://github.com/microsoft/vscode/issues/225514)

## Summary

The inline multi-diff layout still counts the original editor's non-visible text as horizontal overflow, producing a scrollbar even when the displayed content fits. Keep this open in the existing multi-diff-editor area; the source identifies a bounded defect with an available browser-test harness.

## Change summary

Inline commit multi-diffs show an unnecessary horizontal scrollbar whose movement does not reveal additional content.

## Best solution

Make horizontal overflow in inline multi-diffs reflect the displayed inline content, while retaining working scrolling for genuinely overflowing lines and preserving side-by-side behavior.
