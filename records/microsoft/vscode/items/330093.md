# Issue #330093 — Regression: Shell integration is disabled on Windows 10 build 17763 (1809) even though ConPTY is supported

[https://github.com/microsoft/vscode/issues/330093](https://github.com/microsoft/vscode/issues/330093)

## Summary

Keep open for a terminal compatibility decision: current main still excludes build 17763, and enabling the bundled ConPTY DLL does not bypass either build gate. Historical maintainer discussion establishes that the exclusion was intentional, so this is a request to extend supported behavior rather than a verified regression.

## Change summary

Enable automatic shell integration on Windows 10 build 17763 when its terminal backend can reliably deliver OSC 633 command detection.

## Best solution

Establish whether native or bundled ConPTY can reliably support shell integration on build 17763, then make terminal backend eligibility and injection eligibility consistent across integrated and agent-host terminals. Do not lower the injection threshold alone or treat successful script initialization as proof that command-detection sequences reach VS Code.
