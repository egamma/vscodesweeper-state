# Issue #173577 — NotebookCellExecution.replaceOutput(...) appends output instead of replacing

[https://github.com/microsoft/vscode/issues/173577](https://github.com/microsoft/vscode/issues/173577)

## Summary

Keep open: the report documents a replacement regression, an integration-test failure, and persistence in 1.84.0. Current source preserves replacement semantics at the model layer, but does not establish that the reported rendered duplication is resolved; the supplied consecutive-run scenario suffices to retest.

## Change summary

NotebookCellExecution.replaceOutput should replace existing cell output without retaining or duplicating the previous output.

## Best solution

Verify consecutive replacements through both the notebook document model and rendered output, then resolve any remaining discrepancy in the notebook output update pipeline. Preserve the documented distinction between replacement and append without requiring clearOutput as a workaround.
