# Issue #173577 — NotebookCellExecution.replaceOutput(...) appends output instead of replacing

[https://github.com/microsoft/vscode/issues/173577](https://github.com/microsoft/vscode/issues/173577)

## Summary

The replacement regression was confirmed through an integration test and again in VS Code 1.84, while no fixing commit or canonical issue was found. Keep it open under notebook output until the extension-host-to-renderer replacement flow has a regression test and verified fix.

## Change summary

NotebookCellExecution.replaceOutput can leave previous rendered output alongside the replacement instead of presenting only the new output.

## Best solution

Add an end-to-end notebook API regression test that repeatedly calls replaceOutput and asserts that only the latest output remains, then fix the responsible model or renderer update path without requiring clearOutput first.
