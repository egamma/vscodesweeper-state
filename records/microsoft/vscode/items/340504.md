# Issue #340504 — When using "Move into New Window", there should be an option for the new window to be maximized automatically.

[https://github.com/microsoft/vscode/issues/340504](https://github.com/microsoft/vscode/issues/340504)

## Summary

Keep open for the community review that began on October 29. Current source supports explicitly opening maximized auxiliary windows internally, but does not expose that preference for Move into New Window.

## Change summary

Provide an option to automatically maximize auxiliary editor windows created by Move into New Window.

## Best solution

If accepted through community review, provide an opt-in maximized opening preference for auxiliary editor windows while preserving existing window restoration behavior. Decide whether this should share window.newWindowDimensions or have a distinct auxiliary-window preference.
