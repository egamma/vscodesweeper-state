# Issue #340504 — When using "Move into New Window", there should be an option for the new window to be maximized automatically.

[https://github.com/microsoft/vscode/issues/340504](https://github.com/microsoft/vscode/issues/340504)

## Summary

Legitimate gap: the existing `window.newWindowDimensions` setting (including its 'maximized' option) only applies to brand-new top-level windows, not to auxiliary editor windows created via 'Move/Copy Editor into New Window' — those always open at the default size with no way to auto-maximize.

## Change summary

Add an option so the new window created by 'Move Editor into New Window' opens maximized automatically instead of at default size.

## Best solution

Extend the auxiliary editor window creation path (BaseMoveCopyEditorToNewWindowAction in editorActions.ts / createAuxiliaryEditorPart) to honor a maximize preference, deciding whether to reuse `window.newWindowDimensions` or add a dedicated setting for auxiliary/move-into-new-window behavior.
