# Issue #291311 — Agent mode does not reference instruction files after reading a file outside its initial context.

[https://github.com/microsoft/vscode/issues/291311](https://github.com/microsoft/vscode/issues/291311)

## Summary

Current main intentionally performs deterministic `applyTo` matching only against files attached to the request; files encountered later are covered by a model-readable instruction index. A maintainer explicitly confirmed that model-mediated lazy loading is the intended design, so automatic post-read injection is a feature change rather than a defect.

## Change summary

Automatically load matching `applyTo` instruction files when the agent reads or starts modifying a file that was not attached to the initial request.

## Best solution

Retain the current lazy-loading contract: expose each instruction's path, description, and `applyTo` pattern, and direct the model to read matching instructions before modifying or creating files. A deterministic hook that recomputes instructions after tool reads would require a separate product and lifecycle design decision.

  > Thanks for the report and detailed follow-up.
