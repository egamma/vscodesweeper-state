# Issue #322586 — Open file in external application

[https://github.com/microsoft/vscode/issues/322586](https://github.com/microsoft/vscode/issues/322586)

## Summary

Legitimate feature request: VS Code has the infrastructure to open files with the OS default application (via Electron's shell.openExternal) but does not expose a context-menu command for it in the file explorer. No canonical duplicate found in the checkout or linked items, so keeping open for triage.

## Change summary

Add an explorer context-menu option to open a file in the OS-associated external application.

## Best solution

Route to the file explorer area owner. Implementation would register a new command that calls `nativeHostService.openExternal(fileUri)` for the selected file(s), with a context-menu contribution in the explorer. The infrastructure already exists in `src/vs/platform/native/electron-main/nativeHostMainService.ts`.
