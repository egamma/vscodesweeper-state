# Issue #272761 — typescript.tsdk not resolved correctly when it starts with the same name as the parent directory

[https://github.com/microsoft/vscode/issues/272761](https://github.com/microsoft/vscode/issues/272761)

## Summary

Confirmed bug in current main: `RelativeWorkspacePathResolver` incorrectly strips a workspace-folder-name prefix from paths that genuinely start with the same name, producing a wrong absolute path. Two community PRs are open but neither has merged.

## Change summary

When `typescript.tsdk` starts with the workspace folder name (e.g. `x/.yarn/…` inside a folder named `x`), the path resolver strips the leading segment, producing an incorrect resolved path.

## Best solution

Land one of the two open fix PRs (https://github.com/microsoft/vscode/pull/295060 or https://github.com/microsoft/vscode/pull/305215) after review. The fix should make the prefix-stripping logic more robust — e.g. only strip when the path is genuinely relative to the workspace root, not when it coincidentally shares the folder name.
