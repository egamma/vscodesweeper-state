# Issue #187944 — `editor.detectIndentation` produces incorrect values for empty files when `editor.insertSpaces` is `true`

[https://github.com/microsoft/vscode/issues/187944](https://github.com/microsoft/vscode/issues/187944)

## Summary

The empty-file fallback still discards the configured indent size on current main. Keep this report open: the source confirms the defect, and the related indentation-refactoring request is newer, so it cannot absorb this re-reviewed issue.

## Change summary

Preserve the configured indent size independently of tab size when indentation detection has no evidence in an empty file.

## Best solution

Empty-file initialization and subsequent indentation detection should retain the configured indentation defaults without conflating indent size with tab display width. Address this bounded fallback defect without requiring the broader indentation-detection redesign.
