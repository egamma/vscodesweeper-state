# Issue #335397 — Copilot should ignore `.env` files by default

[https://github.com/microsoft/vscode/issues/335397](https://github.com/microsoft/vscode/issues/335397)

## Summary

Reasonable, narrow ask: the default `github.copilot.enable` map already disables completions for `plaintext`, `markdown`, and `scminput`, but has no entry for `.env` files (language id `dotenv`, contributed by the built-in `dotenv` extension) — adding one is a small, sensible default-safety change, but it needs a maintainer/product call on defaults, not an automated close.

## Change summary

Requests that Copilot inline completions be disabled by default for `.env` files, to avoid suggesting or exposing secret-like values.

## Best solution

Add a `dotenv: false` entry to the default value of `github.copilot.enable` in extensions/copilot/package.json (mirroring the existing `plaintext`/`markdown`/`scminput` entries), pending a decision from the Copilot completions owners on whether this should be opt-out by default.
