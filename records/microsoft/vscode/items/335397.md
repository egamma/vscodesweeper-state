# Issue #335397 — Copilot should ignore `.env` files by default

[https://github.com/microsoft/vscode/issues/335397](https://github.com/microsoft/vscode/issues/335397)

## Summary

Keep open for a maintainer decision on safer Copilot defaults: the current configuration does not disable dotenv suggestions by default. The concern involves potentially sensitive file contents, so the security-sensitive keep-open rule applies.

## Change summary

Disable Copilot inline suggestions for dotenv files by default and clarify whether that also prevents their contents from being accessed.

## Best solution

Have the Copilot owners decide the default for dotenv completions and clearly distinguish completion disablement from file-content exclusion. Coordinate with the existing sensitive-file exclusion request without treating a language-level toggle as a comprehensive access restriction.
