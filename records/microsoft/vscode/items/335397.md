# Issue #335397 — Copilot should ignore `.env` files by default

[https://github.com/microsoft/vscode/issues/335397](https://github.com/microsoft/vscode/issues/335397)

## Summary

Reasonable, security-motivated ask: Copilot's `github.copilot.enable` setting already disables auto-suggestions by default for `plaintext`, `markdown`, and `scminput`, but not for `.env`/dotenv files — extending that precedent to `dotenv` is a small, concrete product decision a maintainer can make, not something already covered by the shipped default.

## Change summary

Add `"dotenv": false` to the default value of `github.copilot.enable` so Copilot completions don't auto-trigger in `.env` files (which commonly hold secrets/credentials).

## Best solution

Add `"dotenv": false` to the default object of `github.copilot.enable` in extensions/copilot/package.json (alongside the existing `plaintext`/`markdown`/`scminput` entries) — the `dotenv` language id is already registered by the bundled `extensions/dotenv` extension, so no new plumbing is needed, just a default-value change and a decision from the Copilot completions owners.
