# Issue #335017 — Support opening a PR directly in a browser instead of PR view in agents window

[https://github.com/microsoft/vscode/issues/335017](https://github.com/microsoft/vscode/issues/335017)

## Summary

Brand-new, unreviewed feature request (0 days old, no upvotes) asking for a way to open a PR directly in the external browser from the agents window's PR/changes view, rather than only the in-app PR view.

## Change summary

Add a button/option in the agents window's PR view UI to open the pull request in an external browser instead of (or in addition to) the in-app PR view.

## Best solution

There's already an 'Open Pull Request' action (OPEN_PULL_REQUEST_ACTION_ID in src/vs/sessions/contrib/github/browser/pullRequestActions.ts) that opens externally via IOpenerService with openExternal: true, but it's only wired into the session item context menu, not into the changes/PR view toolbar shown in the screenshot — wiring it there (or an equivalent toolbar action) in src/vs/sessions/contrib/changes/browser/changesView.ts or sessionChangesEditor.ts would satisfy this request.
