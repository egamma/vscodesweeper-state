# Issue #335017 — Support opening a PR directly in a browser instead of PR view in agents window

[https://github.com/microsoft/vscode/issues/335017](https://github.com/microsoft/vscode/issues/335017)

## Summary

Keep open: current Agents Window PR actions still allow contributed openers rather than offering an explicit browser-only action. Existing opener configuration provides a workaround, but does not fully satisfy the requested UI choice; no qualifying fix or canonical duplicate was established.

## Change summary
