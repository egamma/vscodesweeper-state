# Issue #153233 — Round window corners on linux

[https://github.com/microsoft/vscode/issues/153233](https://github.com/microsoft/vscode/issues/153233)

## Summary

The original request is implemented through Electron 43: Linux custom-titlebar windows receive rounded corners on desktops supporting client-side decorations, with rounding removed when maximized. The later request to disable rounding is distinct and already has an open report.

## Change summary

Round Linux window corners when using the custom title bar, except when maximized.

## Best solution

Close the original request as completed by the adopted Electron implementation. Keep the separate request for controlling or disabling rounding tracked in https://github.com/microsoft/vscode/issues/337665.
