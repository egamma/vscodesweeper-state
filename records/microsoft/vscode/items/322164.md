# Issue #322164 — special paste hotkey conflict within chat input

[https://github.com/microsoft/vscode/issues/322164](https://github.com/microsoft/vscode/issues/322164)

## Summary

The conflict remains on current main: both paste options and the chat agent picker register Ctrl+. at the same keybinding weight, allowing the agent picker to win while the paste widget is visible. This is a confirmed, bounded bug and should stay open for a keybinding-context fix.

## Change summary

Pressing Ctrl+. after a special paste in the chat input opens the agent picker instead of the paste-options dropdown.

## Best solution

When the paste widget is visible in a chat input, Ctrl+. should open its paste-options selector; otherwise the existing chat agent-picker shortcut should remain unchanged.
