# Issue #322164 — special paste hotkey conflict within chat input

[https://github.com/microsoft/vscode/issues/322164](https://github.com/microsoft/vscode/issues/322164)

## Summary

The conflict remains in current source: Ctrl+. resolves to the agent picker even while the chat input's paste-options widget is visible. Keep this open for a bounded keybinding fix that preserves the agent-picker shortcut outside that context.

## Change summary

Make Ctrl+. open the available special-paste options after pasting into chat instead of opening the agent picker.

## Best solution

Give the visible paste-options interaction precedence in chat while preserving Ctrl+. for the agent picker when no paste widget is showing, and preserve ordinary editor paste behavior.
