# Issue #342922 — Agents Window: support Compare Agents in Dev Containers

[https://github.com/microsoft/vscode/issues/342922](https://github.com/microsoft/vscode/issues/342922)

## Summary

Keep open: current main deliberately disables container comparisons; the merged Environment picker implements the interim safeguard, not the requested integration. This team-authored follow-up still owns a concrete lifecycle and persistence gap.

## Change summary

Support isolated Dev Container execution throughout Compare Agents attempts, judging, retries, and synthesis.

## Best solution

Extend the provider-neutral comparison lifecycle to retain explicit container execution intent and participant identity through container handoffs and restoration. Enable supported combinations only after isolation, Judge evidence access, failure handling, and cleanup are established; preserve the interim restrictions elsewhere.
