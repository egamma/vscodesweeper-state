# Issue #237201 — Allow for styling the bracket colorized guides

[https://github.com/microsoft/vscode/issues/237201](https://github.com/microsoft/vscode/issues/237201)

## Summary

Keep this accepted backlog request open: current bracket-guide settings support colors and visibility, but not thicker strokes. The older open styling request concerns primarily dashed indentation guides and does not clearly meet the same-observable-symptom bar for consolidating this re-reviewed report.

## Change summary

Allow users to increase the thickness and customize the appearance of colorized bracket-pair guides.

## Best solution

Provide a supported, bounded way to make bracket-pair guides more visible without requiring stylesheet-patching extensions, while preserving existing defaults. Decide the width and styling contract alongside the related indentation-guide request without assuming the two surfaces have identical requirements.

## Plan brief

- **Likely files:** `src/vs/editor/common/config/editorOptions.ts`, `src/vs/editor/browser/viewParts/indentGuides/indentGuides.ts`, `src/vs/editor/browser/viewParts/indentGuides/indentGuides.css`
- **Validation:** The plan should end with a runnable rendering check using nested brackets and editor.guides.bracketPairs enabled: changing the supported thickness must visibly increase bracket-guide stroke width, including horizontal segments where enabled; default rendering, guide colors, and ordinary indentation guides must remain unchanged unless explicitly included in the approved scope.
- **Behavior:**

  > Colorized bracket-pair guides are too thin for the reporter to see comfortably, and current settings cannot increase their thickness. Users should have a supported way to make these guides more visible without patching application stylesheets. Acceptance should demonstrate a visibly thicker guide at the chosen setting while preserving current default appearance, bracket colors, and guide visibility behavior.
- **Trace:**

  > IGuidesOptions and GuideOptions in src/vs/editor/common/config/editorOptions.ts expose visibility and highlighting controls but no width or stroke-style contract. The theming participant in src/vs/editor/browser/viewParts/indentGuides/indentGuides.ts renders active and inactive bracket guides with fixed 1px shadows or borders. editorBracketPairGuide.background1–6 and activeBackground1–6 in src/vs/editor/common/core/editorColorRegistry.ts already provide color customization, which does not address thickness. Ordinary indentation guides use separate .core-guide-indent rules and should not change implicitly. The older open request https://github.com/microsoft/vscode/issues/197066 provides related dashed-line and indentation-width demand, while https://github.com/microsoft/vscode/issues/160976 documents the same bracket-width need but was closed for insufficient votes. The remaining uncertainty is the supported user-facing styling scope, not whether a width control exists today.
- **Open decisions:**
  - Should the supported customization cover bracket-guide thickness only, or also line styles such as dashed guides?
  - Should thickness apply uniformly to active and inactive bracket guides, or allow the active guide to have a separate thickness?
