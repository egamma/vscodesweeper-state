# Issue #291035 — SCM view collapse button not expanding

[https://github.com/microsoft/vscode/issues/291035](https://github.com/microsoft/vscode/issues/291035)

## Summary

The resource-group action still only collapses folders; the requested expand/toggle behavior remains missing. Keep this accepted, team-authored request open for the SCM owner's behavior decision; no verified canonical covers the same request.

## Change summary

Allow the SCM resource-group Collapse All control to expand folders again, similar to the repository-level control.

## Best solution

Provide an owner-approved, group-scoped expansion counterpart to collapse in the SCM tree, with consistent action labeling and no effect on other groups or repositories. Settle whether expansion opens every descendant or restores the previous expansion state before implementation.

The repository-level CollapseAllRepositoriesAction and ExpandAllRepositoriesAction switch through repository-collapse context keys, but their methods act only on repository headers and do not cover this request. Preserve repository-header behavior and unrelated restoration/auto-reveal semantics; uncertainty starts at the desired group expansion contract.
- **Open decisions:**
