# Issue #174547 — Explorer hover text can become sticky when primary side bar is positioned on the right

[https://github.com/microsoft/vscode/issues/174547](https://github.com/microsoft/vscode/issues/174547)

## Summary

Keep open: the reporter and maintainer confirmed displaced and clipped Explorer hovers, and no verified fix or canonical duplicate was found. The hover implementation has since changed substantially; the supplied right-sidebar and long-filename scenario is sufficient to retest without requesting more information.

## Change summary

Long Explorer hovers shifted left from a right-positioned primary sidebar can remain visible unexpectedly and become obscured by the editor.

## Best solution

Ensure long Explorer hovers remain readable across sidebar boundaries and dismiss normally when the pointer leaves their tracked targets. Retest the recorded scenario against the current shared hover implementation before deciding whether any code change remains necessary.
