## Summary

The missing Git gutter indicators for files opened through mismatched symlink and physical paths are already tracked by an older, open issue with the same observable symptom. Consolidate there while preserving this report's recent trace logs.

## Change summary

Git change indicators disappear when an editor file and its registered repository use different paths through a symlink.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/90611 and make Git quick-diff resolution recognize the same repository through its symlink and physical paths without requiring users to reopen files through Source Control.

The canonical therefore covers this specific gutter failure, rather than merely general symlink support.
- **report-specific evidence:** https://github.com/microsoft/vscode/issues/267247#issuecomment-3642138576 records opening songs.js from the palette, editing and saving it without gutter indicators. Its trace uses /media/struct1/code/slide/src/songs.js for the editor but reuses the repository registered at /home/yo/code/slide. The later complete output at https://github.com/microsoft/vscode/issues/267247#issuecomment-3642792891 contains no provideOriginalResource entries; these logs should remain linked from the canonical.
- **current source confirms the failing path:** extensions/git/src/model.ts: getRepositoryExact resolves real paths and openRepository reuses the existing symlink-rooted repository. extensions/git/src/repository.ts registers its SourceControl with Uri.file(repository.root); src/vs/workbench/api/browser/mainThreadSCM.ts passes that rootUri to the quick-diff provider. src/vs/workbench/contrib/scm/common/quickDiffService.ts: getQuickDiffs filters providers by URI ancestry before invoking getOriginalResource. With the paths in this report, the physical editor URI is outside the symlink root and the provider is excluded, explaining both missing gutters and absent provider trace entries. Model.getOpenRepository also checks only repository.root ancestry. This was traced read-only, not executed.
