# Issue #118115 — API: Allow extensions to render a table in a view

[https://github.com/microsoft/vscode/issues/118115](https://github.com/microsoft/vscode/issues/118115)

## Summary

Keep this canonical API request open. The public extension API still offers tree views and webview views but no native table view, while the 35 community upvotes qualify it for the Backlog.

## Change summary

Expose a native table view API so extensions can render accessible, themed multi-column data without implementing a webview.

## Best solution

Design and stabilize an extension-facing table API backed by the existing WorkbenchTable infrastructure, covering columns, row actions, sorting, accessibility, theming, and extension-controlled ordering.
