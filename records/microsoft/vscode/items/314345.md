# Issue #314345 — Settings search doesn't rank exact match at the top

[https://github.com/microsoft/vscode/issues/314345](https://github.com/microsoft/vscode/issues/314345)

## Summary

Keep open: current settings-search code does not distinguish an exact displayed-name match from longer names containing the same words. The source supports the reported ranking problem, although the precise sixteenth-place position was not verified.

## Change summary

Rank workbench.editor.tabSizing first when the Settings editor search exactly matches its displayed name, Tab Sizing.
