# Issue #314345 — Settings search doesn't rank exact match at the top

[https://github.com/microsoft/vscode/issues/314345](https://github.com/microsoft/vscode/issues/314345)

## Summary

Still reproduces on main: the exact-match detection in settings search only fires when the query matches the full setting ID (e.g. 'workbench.editor.tabSizing'), not the display label ('Tab Sizing'). No fix has landed.

## Change summary

Settings search should rank an exact display-name match (like 'tab sizing' → 'Tab Sizing') at the top of results.

## Best solution

Extend the exact-match check in `preferencesSearch.ts` (line ~102) to also compare the query against the setting's display label (case-insensitive), so that a query matching the label exactly gets `SettingMatchType.ExactMatch` and sorts first.
