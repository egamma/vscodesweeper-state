# Issue #296786 — Custom Foundry Local models do not appear in VS Code Copilot Chat model picker

[https://github.com/microsoft/vscode/issues/296786](https://github.com/microsoft/vscode/issues/296786)

## Summary

The picker defect was fixed and shipped in VS Code 1.121.0. Current model-selection logic treats an omitted `isUserSelectable` as selectable, restoring third-party and Foundry-backed models.

## Change summary

Custom models registered through Foundry Local or third-party language-model providers were absent from the Copilot Chat model picker.

## Best solution

Keep the shipped fix from commit 74465a46fcb30880eefac6108f061ce07ef602b8; users should update to VS Code 1.121.0 or later and ensure agent-mode models advertise tool-calling support.
