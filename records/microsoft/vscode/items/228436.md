# Issue #228436 — Editor scrolls horizontally with wrapping enabled

[https://github.com/microsoft/vscode/issues/228436](https://github.com/microsoft/vscode/issues/228436)

## Summary

Verified duplicate: the horizontal scrollbar appearing with viewport wrapping enabled is caused by inline text adornments from extensions making lines wider than the wrapping column accounts for — the exact defect tracked by the open canonical issue #32856. A previous identical report (#119875) was already closed as a duplicate of the same issue.

## Change summary

Editor shows a horizontal scrollbar even when word wrapping is enabled, especially noticeable with the minimap on the right side.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/32856 — fixing inline text adornments to participate in word wrapping calculations would eliminate this horizontal overflow. The code path in `src/vs/editor/common/viewLayout/viewLayout.ts` (`_computeContentWidth`, lines 319–328) explicitly adds scrollbar width when `maxLineWidth` exceeds `contentWidth` during viewport wrapping with a right-side minimap, which is triggered by inline decorations from extensions widening lines beyond what the wrapping column anticipated.
