# Issue #329800 — Regression: Focus on <View> View commands are not searchable by English view name in localized UI

[https://github.com/microsoft/vscode/issues/329800](https://github.com/microsoft/vscode/issues/329800)

## Summary

Verified regression on current main: the Focus on <View> command title is built with localize2() using the already-localized view name for both the `value` and `original` fields, so the English/original title also contains the localized view name and cannot be found by searching the English name.

## Change summary

In localized UI, Command Palette entries for 'Focus on <View> View' can no longer be found by searching the view's original English name because the generated `original` title also uses the localized name.

## Best solution

In registerFocusViewAction (src/vs/workbench/services/views/browser/viewsService.ts, line ~560), stop relying on localize2()'s single-argument templating for both value and original; build `value` via localize2(...) with `viewDescriptor.name.value` and separately set `original` using `viewDescriptor.name.original`, restoring the pre-#204180 behavior described in the issue.
