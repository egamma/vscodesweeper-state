# Issue #329800 — Regression: Focus on <View> View commands are not searchable by English view name in localized UI

[https://github.com/microsoft/vscode/issues/329800](https://github.com/microsoft/vscode/issues/329800)

## Summary

The regression remains in current source: focus-view commands interpolate the translated view name into both their localized title and English search alias. Keep this open to restore English-name discovery without changing localized labels.

## Change summary

Preserve the original English view name in generated focus-view command aliases so both English and localized names are searchable.

## Best solution

Restore distinct localized and original titles for generated focus-view actions in ViewsService, preserving existing command IDs, categories, keybindings, visibility conditions, and focus behavior.
