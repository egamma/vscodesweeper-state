# Issue #327114 — Error with trying to configure launch settings when a setting with `@hasPolicy` exists

[https://github.com/microsoft/vscode/issues/327114](https://github.com/microsoft/vscode/issues/327114)

## Summary

Verified duplicate of the older open issue tracking the same standalone launch-configuration failure when any policy setting exists.

## Change summary

Adding a dynamically provided debug configuration to launch.json fails when an unrelated setting is managed by policy.

## Best solution

Consolidate the fix in https://github.com/microsoft/vscode/issues/282418 by excluding standalone configuration writes from policy validation when their internal operation key is undefined.
