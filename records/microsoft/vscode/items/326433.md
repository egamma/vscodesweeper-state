# Issue #326433 — Add an option to display Copilot-edited files in either List View or Tree View

[https://github.com/microsoft/vscode/issues/326433](https://github.com/microsoft/vscode/issues/326433)

## Summary

A real gap remains in the chat response's changed-files summary: current main still renders one flat row per edited file with no list/tree selector. Route this to the chat area as a feature request rather than closing it.

## Change summary

Allow Copilot's changed-files summary to switch between its existing flat list and a workspace-relative tree.

## Best solution

Add a list/tree view mode to the chat changed-files summary, grouping tree-mode entries by workspace-relative folders while preserving file activation and change counts. The existing Agents Changes view provides a nearby model for the selector and persisted view mode.

- **Fit:** aligned

- **Evidence:** Durable themes: AI-assisted development and Workbench & core UX; the proposed selector also follows an established VS Code interaction already used by SCM and the Agents Changes view.
