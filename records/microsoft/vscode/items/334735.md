# Issue #334735 — [Bug] CoPilot Chat is unable to invoke commands when `pwsh` is the default shell, because its mandatory wrapper prepends POSIX `$Env:PATH` assignments to every invoked command.

[https://github.com/microsoft/vscode/issues/334735](https://github.com/microsoft/vscode/issues/334735)

## Summary

The shell/wrapper mismatch remains in current main: sandboxed commands receive POSIX environment assignments even when the terminal shell is PowerShell. Keep this report open; no verified open canonical or landed fix was identified.

## Change summary

Copilot terminal commands fail before execution when a POSIX sandbox wrapper is evaluated by pwsh on Linux.

## Best solution

Make sandboxed terminal execution compatible with the selected PowerShell shell, including environment injection, argument quoting and working-directory handling, without disabling sandbox protections or requiring a different default terminal profile.

- **Behavior:**

Sandboxed execution should reach the requested payload without requiring the user to change their default terminal profile. - **Trace:**

  > TerminalSandboxEngine.wrapCommand in src/vs/platform/sandbox/common/terminalSandboxEngine.ts receives shell but ignores it in the sandboxed branch, emitting POSIX environment assignments and quoting. CommandLineSandboxRewriter forwards the selected shell and recognizes PowerShell for command parsing, so the mismatch is not prevented there. Linux working-directory preservation adds both an outer cd to the temporary directory and an inner cd prefix, which are part of the compatibility boundary. The exact outer parsing failure is source-confirmed; uncertainty begins at the sandbox-runtime CLI's interpretation of -c and selection of the payload shell, whose implementation is absent from this checkout. Establish that contract before treating this as an environment-prefix-only change. Do not weaken sandbox policy, bypass approval, or alter the user's default terminal profile. - **Current-source defect:** At checkout commit 8571e6fd2f04a40dc0341c05897b93ff132b06f8, src/vs/platform/sandbox/common/terminalSandboxEngine.ts:198-289 accepts a shell argument but does not use it in the sandboxed branch. Line 271 unconditionally emits POSIX PATH, TMPDIR and CLAUDE_TMPDIR assignments; lines 274-278 optionally prepend ELECTRON_RUN_AS_NODE=1. PowerShell cannot parse the reported $PATH: expression.
- **Shell propagation and execution:** src/vs/workbench/contrib/terminalContrib/chatAgentTools/browser/tools/commandLineRewriter/commandLineSandboxRewriter.ts passes options.shell to wrapCommand without excluding PowerShell; it explicitly selects the PowerShell grammar when parsing the original command. RunInTerminalTool forwards the selected shell through its rewriter pipeline, and basicExecuteStrategy.ts:223 and noneExecuteStrategy.ts:96 send commandLine to the terminal.

Changing only the PATH interpolation would leave other shell-syntax incompatibilities.
