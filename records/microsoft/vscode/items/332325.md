# Issue #332325 — Modern UI: side-by-side editor groups should render as separate islands

[https://github.com/microsoft/vscode/issues/332325](https://github.com/microsoft/vscode/issues/332325)

## Summary

The requested per-group islands remain distinct from current Modern UI styling, which frames the editor area as a whole. Keep this specific design request open: existing density and tab settings do not provide it, and no verified canonical owns the same request.

## Change summary

Render split editor groups as individually rounded, bordered surfaces with consistent inter-group gaps while preserving the editor area's outer spacing.

## Best solution

Have the modernization owner decide whether independent editor groups should become separate surfaces, balancing consistent boundaries against density and visual noise. Settle compact-layout behavior and whether the two panes within a single diff editor are intentionally excluded before implementation.
