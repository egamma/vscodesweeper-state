# Issue #332325 — Modern UI: side-by-side editor groups should render as separate islands

[https://github.com/microsoft/vscode/issues/332325](https://github.com/microsoft/vscode/issues/332325)

## Summary

Well-specified, source-confirmed gap in the experimental Modern UI: the editor-border CSS only frames the whole editor part, not per-group. This is a legitimate polish request for an opt-in experimental feature, filed today with maintainer attention already on this module — keep open and route to the modernUI area.

## Change summary

Under `workbench.experimental.modernUI`, split editor groups should each render as a separate rounded/bordered island (like the Side Bar/Panel) instead of sharing one continuous surface divided by a thin sash.

## Best solution

Extend the modernUI editor styling (src/vs/workbench/contrib/modernUI/browser/media/editorBorder.css and the grid/sash rendering it targets) to apply per-group borders/radius/gaps on `.editor-group-container` splits, not just the outer `.part.editor` — a design/implementation task for the Modern UI experiment owners.
