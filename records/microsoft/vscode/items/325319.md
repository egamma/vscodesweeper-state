# Issue #325319 — Discarding changes doesn't work in Agents Window

[https://github.com/microsoft/vscode/issues/325319](https://github.com/microsoft/vscode/issues/325319)

## Summary

Valid bug report from a team member: the Discard action in the Agents Window Changes view appears to be a no-op. The discard ref and action runner plumbing exist, but the discard operation itself depends on changeset operations provided by the session provider — and no fix has landed. Routing to the appropriate area.

## Change summary

Discard changes in the Agents Window Changes view does nothing when clicked, and is only available under the non-default 'Uncommitted Changes' changeset view.

## Best solution

Fix the discard operation wiring in the Agents Window changes view. The `ChangesViewActionRunner` passes `sessionResource`, `discardRef`, and file URIs to the action, but the underlying changeset operation handler (in the agent host or Copilot Chat session provider) may not be processing the discard correctly. Also consider making the discard action available across all changeset views, not just Uncommitted Changes.
