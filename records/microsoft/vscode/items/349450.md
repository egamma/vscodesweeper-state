# Issue #349450 — UI freezes (window unresponsive) when an extension registers ~200+ language model tools — getFullReferenceName → isPermitted recomputed per tool on every tool/tool-set change (regression in 1.147.0)

[https://github.com/microsoft/vscode/issues/349450](https://github.com/microsoft/vscode/issues/349450)

## Summary

The reported policy-inspection and reference-name recomputation bottlenecks are addressed by two concrete fixes present on current main. Propose closing as completed, rather than attributing the freezes to the contributing extension.

## Change summary

Registering or disposing many language model tools freezes the renderer through repeated policy inspections and full reference-name enumeration.

## Best solution

Retain the cached policy checks and per-update reference-name resolver delivered by commits d2b5719d73f7ca4735d6ef8b3ac7ddefed4371b2 and d8c6755b060358ed8a10f1c25bf6852f3a77b81c; these directly address the reported startup and shutdown hot paths.
