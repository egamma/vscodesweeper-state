## Summary

The reported hot path is addressed on main by two landed changes: cached policy checks and reference-name computation shared across each tool update. Propose closing as completed; the shipping release is unknown.

## Change summary

Prevent multi-second renderer freezes when registering or disposing large collections of chat tools.

## Best solution

Retain the policy caching in d2b5719d73f7ca4735d6ef8b3ac7ddefed4371b2 and the per-update reference resolver in d8c6755b060358ed8a10f1c25bf6852f3a77b81c, which address the reported configuration-inspection storm and repeated reference computation.
