Keep open for a design decision about quieter default bracket colors while preserving accessibility. Existing color overrides offer a workaround, but do not resolve the requested default-palette improvement; this team-authored request is also protected from a judgment close.

## Change summary

Reduce the visual prominence of bracket-pair colors in dark themes without compromising accessible contrast.

## Best solution

Agree on an accessible dark-theme bracket palette that supports reading code rather than competing with it, using the existing theme color tokens. Evaluate candidate colors against editor backgrounds and nesting distinguishability before changing defaults, preserving high-contrast themes and user overrides.
