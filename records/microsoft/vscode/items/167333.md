## Summary

Keep this accepted SCM polish item open: current source still allows asynchronously loaded status badges to change the space beside inline actions. No verified canonical or concrete fixing commit establishes that the reported pointer-target shift is resolved.

## Change summary

Keep Source Control file actions stationary while Git status indicators load or refresh after staging and unstaging.
