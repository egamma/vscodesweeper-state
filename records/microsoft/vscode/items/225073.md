# Issue #225073 — [GNOME Linux] No window decoration (shadow) if a window title bar style is custom

[https://github.com/microsoft/vscode/issues/225073](https://github.com/microsoft/vscode/issues/225073)

## Summary

Keep open as an Electron/Chromium upstream issue: many users have confirmed the missing shadow with custom title bars across GNOME and KDE, including recent VS Code releases. The issue was reopened specifically to verify upstream custom-frame behavior, and the latest reports show the problem persists.

## Change summary

Custom-title-bar VS Code windows on Linux lack compositor-provided borders and shadows, especially under Wayland.

## Best solution

Track and validate the Electron custom-frame fix, including https://github.com/electron/electron/pull/49295, then adopt the Electron release containing it and confirm shadows on GNOME and KDE under Wayland.
