# Issue #337532 — Branch Changes status pill assumes the base remote is origin

[https://github.com/microsoft/vscode/issues/337532](https://github.com/microsoft/vscode/issues/337532)

## Summary

The origin-only comparison path remains in current source and can include unrelated upstream changes when origin is a stale fork. Keep this team-authored report open: the inspected related issues do not establish an older canonical covering the same non-origin-remote symptom.

## Change summary

Branch Changes should compare against the actual base ref without assuming its remote is named origin.

## Best solution
