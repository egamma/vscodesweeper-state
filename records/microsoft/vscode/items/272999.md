# Issue #272999 — run_in_terminal missing OS/ distribution context

[https://github.com/microsoft/vscode/issues/272999](https://github.com/microsoft/vscode/issues/272999)

## Summary

Keep open: current agent context identifies Linux and the terminal shell, but does not automatically distinguish Fedora from Ubuntu for package-manager selection. Existing terminal-profile settings do not cover that request, and no verified canonical issue or fixing commit was found.

## Change summary

Provide execution-environment context to Copilot terminal commands, including Linux distribution and efficient discovery of available commands and packages.

## Best solution

Establish a bounded, execution-target-aware environment-context capability so terminal guidance distinguishes the local host from remote or container environments and selects appropriate package managers. Evaluate the broader hardware, package-discovery, installation, and devcontainer-editing tools separately rather than treating basic distribution context as requiring that entire suite.
