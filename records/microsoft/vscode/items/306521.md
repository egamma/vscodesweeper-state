# Issue #306521 — Sessions: Some unexpected views and phrasing when + new session

[https://github.com/microsoft/vscode/issues/306521](https://github.com/microsoft/vscode/issues/306521)

## Summary

Keep open for Agents Window follow-through: the team-authored report documents previous-session content appearing in a new session and inconsistent target naming. Neither an explicitly linked fix nor an eligible canonical duplicate was verified.

## Change summary

Starting a new session retains the previous session’s Artifacts view and changes the target label from “Copilot CLI” to “copilotcli”.

## Best solution

A new-session composer should not display the previous session’s changes as its own, and its target should retain a human-readable name. Verify both transitions against the current session-layout and session-type-picker implementations while preserving access to changes when returning to the completed session.
