# Issue #135713 — Combine workspace trust with enablePromptUseWorkspaceTsdk

[https://github.com/microsoft/vscode/issues/135713](https://github.com/microsoft/vscode/issues/135713)

## Summary

Still valid and unimplemented: current main still requires users to explicitly opt in to the workspace TypeScript SDK via a prompt or manual selection, even in trusted workspaces. An open PR (#190057) exists but has not merged.

## Change summary

Automatically use the workspace TypeScript SDK when workspace trust is granted, eliminating the redundant enablePromptUseWorkspaceTsdk prompt.

## Best solution

Land or iterate on https://github.com/microsoft/vscode/pull/190057 (or a fresh PR) to make the TypeScript version manager honor workspace trust directly — when `typescript.tsdk` is set in workspace settings and the workspace is trusted, use it without requiring the separate prompt/approval. The fix lives in `extensions/typescript-language-features/src/tsServer/versionManager.ts`.
