# Issue #135713 — Combine workspace trust with enablePromptUseWorkspaceTsdk

[https://github.com/microsoft/vscode/issues/135713](https://github.com/microsoft/vscode/issues/135713)

## Summary

The requested behavior is still missing: trusting a workspace does not automatically select its configured TypeScript SDK. Keep this accepted, well-supported request open while the existing linked implementation PR is reviewed.

## Change summary

Automatically honor a workspace-configured TypeScript SDK in trusted workspaces without requiring separate per-workspace approval.

## Best solution

Make workspace trust sufficient to select the explicitly configured workspace TypeScript SDK while preserving restricted-workspace protections and intentional user version choices. Review https://github.com/microsoft/vscode/pull/190057 against that behavior rather than starting a competing implementation.
