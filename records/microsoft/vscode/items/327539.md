# Issue #327539 — Agents window Markdown editor: Most of a thematic break maps clicks to the next paragraph

[https://github.com/microsoft/vscode/issues/327539](https://github.com/microsoft/vscode/issues/327539)

## Summary

The defect is traceable in the currently pinned Markdown editor package: rightward clicks on the source-less thematic-break run resolve to its source end, including trailing glue. This team-authored issue should remain open for a package fix and dependency update.

## Change summary

Clicking most of a rendered Markdown thematic break activates the following paragraph instead of revealing and selecting the rule.

## Best solution

Change thematic-break point mapping in `microsoft/vscode-packages` so the entire rendered rule resolves within the break, add a focused Playwright regression test, then publish and consume the corrected `@vscode/markdown-editor` version.
