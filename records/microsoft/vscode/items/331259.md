## Summary

Team-authored bug report (firsthand, with screenshot) describing inconsistent/delayed sync of an external agent session between the GitHub app and VS Code — messages sent in one client don't appear promptly (or at all without reload) in the other, and one message showed stray system-prompt text. This is a fresh, real defect that needs area-owner investigation, not a close.

## Change summary
