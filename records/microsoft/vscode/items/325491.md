## Change summary

NES inline completions fail with noSuggestions when the file's relative workspace path contains a space in any folder name.

## Best solution

The NES/xtab team should trace whether the space in the relative path is mishandled during prompt construction (in `toUniquePath` → the model prompt), in the relatedFiles fetching, or in the backend model's response parsing. The `toUniquePath` function itself returns decoded paths (with literal spaces), so the issue may be in how the backend API endpoint receives or processes the path. Fix should ensure paths with spaces work end-to-end in the NES pipeline.
