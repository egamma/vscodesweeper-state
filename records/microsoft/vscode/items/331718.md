# Issue #331718 — Support auto model selection in .agent.md based on task complexity

[https://github.com/microsoft/vscode/issues/331718](https://github.com/microsoft/vscode/issues/331718)

## Summary

Keep open through the remaining community-review window: existing Copilot Auto selection does not provide a custom-agent policy for capability- and task-aware routing across BYOK models. The older routing requests inspected cover related but distinct capabilities, not this request's full scope.

## Change summary

Allow custom agents to declare dynamic model-selection policies based on task complexity, context size, capabilities, and cost instead of static model preferences.

## Best solution

If accepted, define a provider-aware custom-agent routing contract with explicit capability constraints, fallback behavior, and cost-selection semantics. Decide whether routing occurs only at invocation or can change during execution, accounting for the contributor's per-round scheduling proposal.
