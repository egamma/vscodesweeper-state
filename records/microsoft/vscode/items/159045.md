# Issue #159045 — Use edit sessions for hot exit

[https://github.com/microsoft/vscode/issues/159045](https://github.com/microsoft/vscode/issues/159045)

## Summary

The cross-device hot-exit request remains valid. Current main can upload changes when a signed-in desktop window closes, but that experimental setting defaults off and explicitly has no effect on web, leaving the reported web-to-desktop flow uncovered.

## Change summary

Automatically carry unsaved working changes between VS Code instances through Cloud Changes, without requiring an explicit Continue Working On action.

## Best solution

Extend Cloud Changes into an opt-in cross-device hot-exit mechanism, likely by incrementally storing working-copy changes rather than relying on asynchronous web shutdown, while preserving explicit sign-in and online-service consent.
