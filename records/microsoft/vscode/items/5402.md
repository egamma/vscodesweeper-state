# Issue #5402 — Improved column selection (Alt+select)

[https://github.com/microsoft/vscode/issues/5402](https://github.com/microsoft/vscode/issues/5402)

## Summary

The central request was implemented and shipped in VS Code 1.32.0: with `editor.multiCursorModifier` set to `ctrlCmd`, Alt-drag starts column selection at the initial click. The remaining virtual-space and arbitrary mouse-binding requests have dedicated open issues.

## Change summary

Make mouse-driven column selection start at the drag origin, preferably using Alt-drag, and support rectangular selection through virtual whitespace.
