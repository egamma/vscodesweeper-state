# Issue #5402 — Improved column selection (Alt+select)

## Summary

Long-standing, heavily-upvoted (407) feature request in the Backlog milestone; a prior review's implemented-on-main close citing commit be7af0e8c89b79ce06cd42f8d8d254c66d5a0535 was refuted by an independent re-review, and I found no other fix commit on main referencing this issue, so it stays open.

## Change summary

Make Alt+drag column/block selection start from the click point (like Sublime/VS/Eclipse/Notepad++) instead of today's awkward multi-cursor-based approximation, including virtual-space support for ragged line lengths.

## Best solution

This should be resolved together with virtual-space support (tracked in the related, newer https://github.com/microsoft/vscode/issues/13960, which per a 2024 comment has active work in a fork) — once virtual space lands, rebind/implement true rectangular Alt+drag selection in the editor mouse/selection controller rather than the current multi-cursor emulation.
