# Issue #201312 — Explorer: Expanding unmatched folders while filtering loses focus

[https://github.com/microsoft/vscode/issues/201312](https://github.com/microsoft/vscode/issues/201312)

## Summary

The keyboard-focus defect remains source-reproducible on current main: filtering can remove the focused row without transferring usable tree focus to the visually adjacent row, so the next Right Arrow has no focused element to expand.

## Change summary

Keep keyboard focus usable when expanding an unresolved Explorer folder causes that folder to disappear from filtered results.

## Best solution

When filtering removes the focused tree row, move both visual and logical tree focus to the appropriate remaining row so repeated keyboard expansion continues to work. Keep this tree-specific and avoid restoring automatic focus preservation for every list.
