# Issue #201312 — Explorer: Expanding unmatched folders while filtering loses focus

[https://github.com/microsoft/vscode/issues/201312](https://github.com/microsoft/vscode/issues/201312)

## Summary

The reported focus-loss path no longer exists on current main: Explorer filtering now resolves matching paths through the search service instead of retaining unmatched unresolved folders for manual expansion. The redesign in commit 6ee792e0e9a7a456a0535be4efcb06b0c4fb034e therefore resolves the central problem.

## Change summary

Preserve usable keyboard focus when expanding an unmatched unresolved Explorer folder causes that folder to disappear from a filtered tree.

## Best solution

Keep the search-backed Explorer filtering introduced by commit 6ee792e0e9a7a456a0535be4efcb06b0c4fb034e, which discovers matches and their parent paths up front and removes the manual unresolved-folder expansion workflow.
