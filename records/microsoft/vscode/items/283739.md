# Issue #283739 — VScode AI chat function doesn't work when opening code files from a remote SSH server

[https://github.com/microsoft/vscode/issues/283739](https://github.com/microsoft/vscode/issues/283739)

## Summary

This is a network-configuration support question, not a VS Code bug. The diagnostic logs clearly show the remote SSH server cannot reach Copilot API endpoints (ECONNRESET on api.individual.githubcopilot.com and proxy.individual.githubcopilot.com), while the same endpoints are reachable from the local machine — a textbook remote-server firewall/proxy issue. The reporter did not address the maintainer's follow-up about firewall allowlisting, and the issue has been stale for over 7 months with `info-needed`.

## Change summary

Copilot Chat models are unavailable when connected to a remote SSH server due to the remote server's network blocking connections to Copilot API endpoints.

## Best solution

The remote server's network needs to allowlist the Copilot API hosts (api.individual.githubcopilot.com, proxy.individual.githubcopilot.com, telemetry.individual.githubcopilot.com). This is a server-side network configuration issue, not a VS Code defect. The GitHub docs on firewall settings for Copilot cover the required hosts.
