# Issue #277632 — VSCode 1.106 / repository new icon problem

[https://github.com/microsoft/vscode/issues/277632](https://github.com/microsoft/vscode/issues/277632)

## Summary

Keep open for SCM UX discussion: current source still deliberately distinguishes visible repositories with a filled selection icon in multi-repository workspaces. That explains the tick, but does not resolve the request for quieter, more consistent repository icons.

## Change summary

Use outline repository icons consistently, or make the meaning of the filled selection icon clearer.

## Best solution

Have the SCM UX owner decide whether repository visibility can be communicated more quietly without losing the selected-versus-hidden distinction. The decision belongs in the shared repository renderer rather than a one-off Windows adjustment or another customization setting.
