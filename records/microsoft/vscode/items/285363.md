## Change summary

Committing all local changes while the delegation confirmation is pending leaves the background agent stuck after selecting Copy Changes.

## Best solution

Background-agent delegation should finish when the source becomes clean while confirmation is pending, without waiting indefinitely or migrating unrelated changes. Reproduce the reported timing against the current Copilot migration path and establish which awaited operation stalls before making a bounded correction.
