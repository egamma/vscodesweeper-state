# Issue #190478 — Document symbols: details are not rendered

[https://github.com/microsoft/vscode/issues/190478](https://github.com/microsoft/vscode/issues/190478)

## Summary

A real gap remains on current main: Go to Symbol in Editor ignores the LSP `DocumentSymbol.detail` field. The promoted Backlog request has 27 upvotes and no canonical issue owns the work, so it should remain open.

## Change summary

Show and search document-symbol details, such as overloaded function signatures, in Go to Symbol in Editor.

## Best solution

Extend `AbstractGotoSymbolQuickAccessProvider.doGetSymbolPicks` to render `DocumentSymbol.detail` and include it in matching, while preserving the existing container-name presentation. Workspace-symbol details should remain a separate API request as the maintainer requested.
