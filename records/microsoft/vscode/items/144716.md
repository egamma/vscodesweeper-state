# Issue #144716 — [Linux] Show hamburger menu when "Show Menu Bar" option is unchecked.

[https://github.com/microsoft/vscode/issues/144716](https://github.com/microsoft/vscode/issues/144716)

## Summary

Implemented and shipped in VS Code 1.101.0: Linux users can combine a native title bar with the custom compact hamburger menu.

## Change summary

Allow Linux's compact hamburger menu while retaining the native window title bar.

## Best solution

Use `window.titleBarStyle: "native"`, `window.menuStyle: "custom"`, and `window.menuBarVisibility: "compact"`; commit 4e68b628ea4444bca3ed1b7d4080bf1e880ca8d7 added this supported combination.
