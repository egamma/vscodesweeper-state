# Issue #144716 — [Linux] Show hamburger menu when "Show Menu Bar" option is unchecked.

[https://github.com/microsoft/vscode/issues/144716](https://github.com/microsoft/vscode/issues/144716)

## Summary

The requested hamburger menu with a native Linux title bar is now supported by setting window.menuStyle to custom. A concrete implementation commit enables both compact menu visibility and the Show Menu Bar toggle independently of title bar style.

## Change summary

Allow Linux users to access a compact hamburger menu while retaining the native title bar.
