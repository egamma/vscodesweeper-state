## Summary

The mismatch remains source-reproducible on current main: Chat renders Markdown as formatted DOM, while its Accessible View uses plaintext conversion options that preserve some Markdown syntax and discard raw HTML content. This team-authored accessibility bug should remain open for a bounded rendering-parity fix and verification.

## Change summary

Make the Chat Accessible View expose the same meaningful text shown in the visual Chat response, without leaked Markdown syntax, substituted entities, or lost HTML content.

## Best solution

Define and test a shared visible-text contract for Chat responses so the Accessible View preserves the text users see while removing presentation-only Markdown and HTML markup.
