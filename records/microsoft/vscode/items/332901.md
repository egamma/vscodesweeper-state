# Issue #332901 — Pinning mechanism for symbol detail hover panel

[https://github.com/microsoft/vscode/issues/332901](https://github.com/microsoft/vscode/issues/332901)

## Summary

The core ask — keeping the hover panel open long enough to select and copy its contents — is already built into `editor.hover.sticky` (on by default) plus `editor.hover.hidingDelay`, and the hover controller has dedicated logic to keep the widget open while text inside it is being selected, so this looks like existing, intentional behavior rather than a gap.

## Change summary

Add a way to pin the symbol hover panel open (e.g. Ctrl-hover or a pin icon) so it doesn't disappear while dragging to select/copy its text.

## Best solution

Point the reporter at `editor.hover.sticky` (default true) and `editor.hover.hidingDelay` (configurable up to 600000ms) — the hover's own doc comment says it exists 'such that it can be clicked and its contents selected', and `ContentHoverController._shouldKeepCurrentHover` has an explicit `isTextSelectedWithinContentHoverWidget` check that keeps the widget open during in-progress text selection.

  > Thanks for the report! This is already handled by two existing settings: `editor.hover.sticky` (on by default) keeps the hover open so its contents can be selected, and `editor.hover.hidingDelay` (default 300ms, can be raised) controls how long it stays open once your cursor drifts outside it while dragging. The hover controller also has logic that keeps the panel open specifically while a text selection inside it is in progress. If you're still seeing it vanish mid-drag with sticky enabled and a higher hidingDelay, a fresh reproduction (steps + a short clip) would help pin down whether there's a remaining gap versus timing/settings.
