# Issue #324001 — Pressing new terminal in new terminal window leads to terminal in wrong location

[https://github.com/microsoft/vscode/issues/324001](https://github.com/microsoft/vscode/issues/324001)

## Summary

Confirmed on main: the dropdown's 'New Terminal' action bypasses the auxiliary-window location detection that the plus button (command) uses, so the terminal is created in the main panel instead of the current auxiliary window.

## Change summary

In a new terminal window (auxiliary window), the dropdown 'New Terminal' action creates the terminal in the main panel instead of the current auxiliary window.

## Best solution

In `getTerminalActionBarArgs` (terminalMenus.ts, line 801), the dropdown's 'New Terminal' action should pass the `location` parameter (already available in scope) to `createAndFocusTerminal()` — or replicate the auxiliary-window detection from the `TerminalCommandId.New` command handler. The plus button already works because it fires the command, which has auxiliary-window logic at terminalActions.ts:1237–1239.
