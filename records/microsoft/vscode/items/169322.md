# Issue #169322 — Search editor context lines is ambiguous and doesn't appear to be accessible to screen readers

[https://github.com/microsoft/vscode/issues/169322](https://github.com/microsoft/vscode/issues/169322)

## Summary

The context-lines number input still has neither an accessible name nor an explanatory hover in current source. Keep this issue open; the related hover report was explicitly closed in favor of this one.

## Change summary

Give the Search Editor context-lines number input an explanatory hover and an accessible name.

## Best solution

Make the number input identify itself as the number of surrounding context lines, both on hover and to screen readers, while preserving the existing toggle and search behavior.
