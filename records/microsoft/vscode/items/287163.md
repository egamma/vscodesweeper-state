# Issue #287163 — GitHub Copilot output stops scrolling during generation

[https://github.com/microsoft/vscode/issues/287163](https://github.com/microsoft/vscode/issues/287163)

## Summary

The intermittent loss of auto-scroll remains plausible, but there is no deterministic trigger, current-version confirmation, or independent reproduction. More information is needed to distinguish it from intentional suspension after user scrolling and from other chat layout defects.

## Change summary

Keep a streaming Copilot response automatically scrolled to its latest content unless the user deliberately scrolls away.

## Best solution

Preserve the chat's auto-follow intent across dynamic response-height and viewport changes, while continuing to suspend it after an explicit user scroll. Add a regression test once the specific resize or rendering sequence that drops the bottom state is identified.
