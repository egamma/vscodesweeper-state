# Issue #333113 — Session artifact pills - When ask-question box, or permission box is shown, don't show the artifacts pills.

[https://github.com/microsoft/vscode/issues/333113](https://github.com/microsoft/vscode/issues/333113)

## Summary

Keep open: current pill visibility does not account for blocking questions or permission prompts. The related artifacts tracker lists this specific improvement rather than replacing it, and no verified fix or same-symptom canonical was found.

## Change summary

Temporarily hide session artifact pills while a blocking question or permission prompt is displayed, restoring them afterward.

## Best solution

Give blocking question and permission surfaces visual precedence over session artifact pills in the Agents Window, without removing artifacts or changing the user's persisted pill visibility preferences.
