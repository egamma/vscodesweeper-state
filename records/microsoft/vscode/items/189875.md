# Issue #189875 — Workspace files dropped and pasted into CSS file should be automatically formatted

[https://github.com/microsoft/vscode/issues/189875](https://github.com/microsoft/vscode/issues/189875)

## Summary

Keep open: current main provides CSS drop-and-paste URL insertion, but it does not produce the quoted form requested and does not safely format paths containing whitespace. The older related issue covers only drag-and-drop, so it cannot absorb this broader paste request under the re-review duplicate rules.

## Change summary

Format workspace files dropped or pasted into CSS as quoted url() references using paths relative to the CSS document.

## Best solution

Complete the CSS drop-or-paste provider so generated relative paths are valid for all filenames, including paths requiring CSS quoting or escaping, with focused coverage for both paste and drop. Once that remaining behavior lands, close this and reconcile the narrower drag-only request at https://github.com/microsoft/vscode/issues/147483.
