# Issue #340931 — SDK Marketplace plugin install completes but card reports stale inventory

[https://github.com/microsoft/vscode/issues/340931](https://github.com/microsoft/vscode/issues/340931)

## Summary

Thanks for the detailed report. The error comes from waitForPluginInventory in the Agent Host marketplace install provider. It times out waiting for agentPluginService.plugins to contain a plugin whose copilotCliInstallation matches the expected identity. Plugin inventory publication and matching were not traced end to end, so the defect is not confirmed from source. The report is complete and the steps suffice to retest.

## Change summary

Installing a plugin from Discover with the Copilot session target succeeds, but the card shows a failure because the workbench never sees the installed plugin in its inventory.

## Best solution

Find why agentPluginService.plugins does not surface a plugin with a matching copilotCliInstallation (name, marketplace, directSourceId) after the install. The cause is either an identity mismatch between the install request and the published inventory, or inventory publication happening outside the wait window. Fix the synchronization so the card moves to Uninstall.
