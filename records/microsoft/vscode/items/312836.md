# Issue #312836 — Agents scope selector should always show `select folder`

[https://github.com/microsoft/vscode/issues/312836](https://github.com/microsoft/vscode/issues/312836)

## Summary

Keep open: the current workspace picker still filters away the folder-browse action when an unfamiliar folder name matches no rows. The picker has been redesigned since the report, but the underlying discoverability gap remains directly traceable in source.

## Change summary

Keep the folder-browse option available while searching the Agents workspace picker, including when no recent workspace matches.

## Best solution

The Agents workspace picker should retain an actionable way to browse for a folder regardless of the search query, while continuing to filter recent workspaces normally. Preserve existing folder-selection behavior and scope this work to browse-action visibility.
