# Issue #312836 — Agents scope selector should always show `select folder`

[https://github.com/microsoft/vscode/issues/312836](https://github.com/microsoft/vscode/issues/312836)

## Summary

Valid bug: the Agents window workspace picker filters out the 'Select Folder...' entry when the user types text that doesn't match any recent workspace, leaving no way to browse for a new folder. Still present on main.

## Change summary

The Agents scope selector hides the 'Select Folder...' option when typed text filters out all recent workspaces, leaving no actionable items.

## Best solution

Ensure the 'Select Folder...' entry in `WebWorkspacePicker._buildItems()` (and the underlying action widget filtering) is always visible regardless of filter text — likely by marking it as a pinned/unfiltered item in the action widget, or by always including a 'no matching workspaces' placeholder plus the browse action.
