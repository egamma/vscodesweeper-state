# Issue #264472 — Selecting option `Preview on GitHub` could change permanently option `Create on GitHub` to it

[https://github.com/microsoft/vscode/issues/264472](https://github.com/microsoft/vscode/issues/264472)

## Summary

Keep open for the split-button UX decision: the legacy issue reporter still makes Create on GitHub primary regardless of a previous Preview selection. The team-authored request has explicit maintainer support, but the consistency and persistence semantics remain unsettled.

## Change summary

Make selecting Preview on GitHub promote it to the primary issue-reporter action, moving Create on GitHub into the dropdown.

## Best solution

Agree on whether the issue reporter should remember the selected primary action and for how long, taking the newer wizard and existing split-button conventions into account. If adopted, retain access to both actions and preserve authentication-dependent availability.
