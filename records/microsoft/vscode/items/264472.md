# Issue #264472 — Selecting option `Preview on GitHub` could change permanently option `Create on GitHub` to it

[https://github.com/microsoft/vscode/issues/264472](https://github.com/microsoft/vscode/issues/264472)

## Summary

Active team UX discussion about whether the issue reporter's dropdown button should persist the last-selected action (e.g. swapping 'Create on GitHub' ↔ 'Preview on GitHub'). Both participants are team members; the discussion is unresolved and correctly labeled `under-discussion`.

## Change summary

Selecting 'Preview on GitHub' from the dropdown should permanently swap it to be the default button action, moving 'Create on GitHub' into the dropdown.

## Best solution

The team should decide on a consistent dropdown-button persistence pattern across the workbench (issue reporter, SCM view, PR extension) and implement it in `src/vs/workbench/contrib/issue/browser/baseIssueReporterService.ts` where the `publicGithubButton` actions are configured. The broader pattern question raised by Yoyokrazy may warrant a cross-component decision before implementation.
