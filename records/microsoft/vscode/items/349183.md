# Issue #349183 — Support a configurable home directory for VS Code Chat harness

[https://github.com/microsoft/vscode/issues/349183](https://github.com/microsoft/vscode/issues/349183)

## Summary

COPILOT_HOME already redirects the runtime home without changing HOME or USERPROFILE, but does not establish the requested profile/workspace-scoped isolation across Chat configuration and instruction discovery. Keep open to clarify that remaining scope rather than introduce a redundant override.

## Change summary

Allow VS Code Chat to use an isolated harness configuration home independently of standalone Copilot CLI configuration.

## Best solution

Build on the existing COPILOT_HOME support and define whether isolation includes Chat instruction discovery and concurrent profiles/workspaces. Any additional control should consistently select the runtime configuration home and related discovery paths while preserving the existing default.
