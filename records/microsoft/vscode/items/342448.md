# Issue #342448 — Reconnect only the newest tool call for each shell ID when restoring detached shells in Agent Host chats

[https://github.com/microsoft/vscode/issues/342448](https://github.com/microsoft/vscode/issues/342448)

## Summary

Keep open: current main streams detached shell output after live tool completion but does not reconnect that reader when restoring history. Selecting only the newest tool call for a reused shell ID remains a meaningful requirement for restore support.

## Change summary

Restore detached shell output streaming only into the newest tool call associated with each running shell ID, leaving older calls settled.

## Best solution

Extend Copilot's detached-shell restoration so each running shell has exactly one live terminal owner: its newest matching historical tool call. Preserve the existing shell-ID reuse behavior for live commands and cover two calls using shell ID 0 across a restart.
