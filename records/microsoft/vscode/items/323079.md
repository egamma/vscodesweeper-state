# Issue #323079 — Bring back the GitHub Copilot icon instead of the generic Chat icon

[https://github.com/microsoft/vscode/issues/323079](https://github.com/microsoft/vscode/issues/323079)

## Summary

Keep open as design feedback: current Chat surfaces still use generic chat glyphs, and the available Copilot icon variants do not fulfill the request for consistent mascot branding throughout VS Code. No verified older canonical or maintainer decision supports closing it.

## Change summary

Restore the Copilot mascot on the title-bar Chat entry point and consistently use it across Copilot-related views, buttons, and menus.

## Best solution

Have the Chat design owners establish which surfaces represent GitHub Copilot specifically versus provider-neutral chat, then apply a consistent icon convention across those surfaces. The choice of mascot branding versus generic chat iconography remains a product decision, not a confirmed defect.
