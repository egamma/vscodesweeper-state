# Issue #346087 — Agent Host: prevent disabling the essential Search Tools routing tool

[https://github.com/microsoft/vscode/issues/346087](https://github.com/microsoft/vscode/issues/346087)

## Summary

The requested protection is absent: saved group and individual selections can exclude Search Tools. Keep this open as a feature request; current source also disables runtime tool-search deferral when the discovery tool is absent, so tool unavailability is not established by that selection alone.

## Change summary

Make Agent Host Search Tools non-optional while preserving disabled optional tools and MCP servers, including existing saved selections.

## Best solution

Distinguish required discovery infrastructure from optional tools in Agent Host tool selection and publication, preserving optional-tool and MCP exclusions. Retain the separate model-capability and explicit tool-search configuration gates.
