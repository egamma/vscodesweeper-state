# Issue #227120 — Editor GPU: Support ligatures (editor.fontLigatures)

[https://github.com/microsoft/vscode/issues/227120](https://github.com/microsoft/vscode/issues/227120)

## Summary

Keep this accepted GPU-renderer feature request open: current source still renders ASCII characters separately, without ligature shaping. A later same-symptom report was explicitly consolidated here, and the open GPU-rendering PR leaves this capability outstanding.

## Change summary

Honor editor.fontLigatures when rendering editor text with experimental GPU acceleration.

## Best solution

Provide font-aware ligature shaping in the editor GPU rendering pipeline while respecting editor.fontLigatures and preserving editing geometry and rendering performance. Retain this issue as the specific capability tracker rather than folding it into the broader renderer exploration.
