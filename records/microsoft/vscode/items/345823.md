# Issue #345823 — Allow custom hats for Blobby

[https://github.com/microsoft/vscode/issues/345823](https://github.com/microsoft/vscode/issues/345823)

## Summary

Custom hats remain a genuine capability gap: current customization selects bundled achievement accessories, not user-provided artwork. Keep this request open for a product decision; no verified duplicate or established decline was found.

## Change summary

Support creating, importing, selecting, and retaining custom Blobby hats that follow existing animations.

## Best solution

Decide whether Blobby should expose a supported accessory format and loading mechanism, potentially through extension contributions. If accepted, reuse the existing animation rig and store custom assets outside the application installation so updates do not replace them.
