# Issue #280562 — Generating test functions in an existing file overwrites last code-containing line of the existing content

[https://github.com/microsoft/vscode/issues/280562](https://github.com/microsoft/vscode/issues/280562)

## Summary

Still reproduces on main: when generating tests into an existing test file, the insertion range includes the last line of the last test function (a replacement range rather than a zero-width insertion point), causing it to be overwritten and the new code to be indented at the wrong level.

## Change summary

The 'Generate Tests' action overwrites the last code line of an existing test file instead of appending after it.

## Best solution

Fix the range construction in `testFromSrcInvocation.tsx` (lines ~117 and ~200) to use a zero-width insertion range at `lineAfterLastLine` instead of a replacement range spanning the last line of the last test. The range should be `new Range(lineAfterLastLine, 0, lineAfterLastLine, 0)` instead of `new Range(lastLineOfTest.line, lastLineOfTest.character, lineAfterLastLine, 0)`.
