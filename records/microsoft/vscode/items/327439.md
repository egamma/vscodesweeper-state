# Issue #327439 — MCP App webviews duplicate identical multi-MB HTML bundles (35MB in one renderer snapshot)

[https://github.com/microsoft/vscode/issues/327439](https://github.com/microsoft/vscode/issues/327439)

## Summary

Current main confirms the reported memory amplification: every MCP App model independently rebuilds and retains the same multi-megabyte HTML. This should remain open as a performance bug.

## Change summary

Repeated MCP App invocations retain separate copies of identical multi-megabyte HTML bundles, consuming tens of megabytes per renderer.

## Best solution

Introduce a shared, lifetime-bounded cache for identical post-preamble MCP App HTML, with keys and invalidation that cannot return stale resource content. Also clear retained webview HTML during disposal and separately verify whether disposed models remain reachable.
