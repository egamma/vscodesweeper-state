## Summary

Fresh, team-authored report of a stale model shown in the Agents Window picker when a session started in the editor window is later opened there; no fix has landed yet and I couldn't conclusively trace the sync bug in the short window since filing, so this should be routed to the Agents Window / sessions area rather than closed.

## Change summary

When a chat session is created in the editor window and then opened in the Agents Window while still running, the model picker in the Agents Window shows a stale/incorrect model instead of the session's actual model.

## Best solution
