# Issue #291640 — Debug disassembly view sometimes assumes a single contiguous memory space despite instructionReference changes

[https://github.com/microsoft/vscode/issues/291640](https://github.com/microsoft/vscode/issues/291640)

## Summary

Keep open: current source still merges disassembly from different instruction references by numeric address, retaining instructions from unrelated contexts. An open PR explicitly targets this issue and should be reviewed before considering completion.

## Change summary

Prevent stale disassembly and scrolling gaps when switching frames whose instruction references identify unrelated memory regions.

## Best solution

Ensure the disassembly view shows a coherent memory context after frame switches without mixing unrelated instructions or leaving unfillable internal gaps. Review https://github.com/microsoft/vscode/pull/310782 against both multi-process switching and ordinary same-process frame navigation before landing it.
