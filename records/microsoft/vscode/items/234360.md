# Issue #234360 — Ability to Set Different Zoom Levels for Each Editor Group

[https://github.com/microsoft/vscode/issues/234360](https://github.com/microsoft/vscode/issues/234360)

## Summary

This remains a valid backlog feature request: current zoom controls operate per window or globally across editors, not per editor group. It has 39 community upvotes and was explicitly promoted to the Backlog.

## Change summary

Allow each editor group to use and optionally persist an independent zoom or font-scaling level.

## Best solution

Introduce editor-group-scoped font zoom state and commands, independent of Electron window zoom, with restoration through editor-group state. Preserve the existing global Editor Font Zoom behavior as the default.

- **Fit:** aligned
- **Reason:** Independent group scaling supports accessibility and flexible workbench layouts without adding always-visible UI.
