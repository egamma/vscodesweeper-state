# Issue #209503 — Add a boolean property to `TextDocument` if the encoding was guessed

[https://github.com/microsoft/vscode/issues/209503](https://github.com/microsoft/vscode/issues/209503)

## Summary

The original encoding-access request is covered, but the requested boolean distinguishing guessed encoding remains absent. Keep this team-authored, reopened request open for an API-owner decision; the reporter's appreciation of TextDocument.encoding does not explicitly withdraw the additive request.

## Change summary

Expose whether a TextDocument's encoding was selected through files.autoGuessEncoding rather than BOM detection, UTF-16 detection, configuration, or explicit user choice.

## Best solution

Resolve whether C/C++ still needs encoding provenance now that it consumes TextDocument.encoding. If the API owner accepts that need, define a per-document provenance contract that distinguishes actual heuristic selection from merely having autoGuessEncoding enabled, including what happens after explicit encoding changes.
