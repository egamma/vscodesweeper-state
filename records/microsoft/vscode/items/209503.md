# Issue #209503 — Add a boolean property to `TextDocument` if the encoding was guessed

[https://github.com/microsoft/vscode/issues/209503](https://github.com/microsoft/vscode/issues/209503)

## Summary

Keep open under discussion: the finalized API exposes `TextDocument.encoding`, but not whether that encoding was guessed. This team-authored request remains a distinct API gap.

## Change summary

Expose whether a text document's encoding resulted from automatic guessing so extensions can reconcile their decoding behavior with VS Code.

## Best solution

Decide whether encoding provenance should become stable extension API, then preserve the detection source through the text-file model and extension-host document data if accepted. The existing `encoding` property should remain unchanged.
