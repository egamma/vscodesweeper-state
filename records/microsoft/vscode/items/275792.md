# Issue #275792 — Resetting various settings can delete comments from settings.json file

[https://github.com/microsoft/vscode/issues/275792](https://github.com/microsoft/vscode/issues/275792)

## Summary

Confirmed bug: the `removeProperty` function in `jsonEdit.ts` computes a removal range from the previous property's end to the deleted property's end, which swallows any comments in between. Two open PRs (#308319, #309171) attempt to fix this but neither has merged.

## Change summary

Resetting a setting to its default (removing it from settings.json) also deletes comment lines directly above that setting.

## Best solution

Land PR https://github.com/microsoft/vscode/pull/309171 (or #308319) which preserves comments above a deleted JSON property by adjusting the removal range in `src/vs/base/common/jsonEdit.ts` to stop before preceding comment lines.
