# Issue #340656 — Local dictation returns empty transcript for non-English languages since 1.141.0 (foundry-local-sdk 2.0.1 drops language)

[https://github.com/microsoft/vscode/issues/340656](https://github.com/microsoft/vscode/issues/340656)

## Summary

Thanks for the detailed report. Current main still pins foundry-local-sdk 2.0.1, which the reporter says drops the language setting for local dictation. The fix is reported to be in SDK 2.1.0, so a version bump looks like the remedy.

## Change summary

Local dictation returns an empty transcript for non-English languages because foundry-local-sdk 2.0.1 does not forward the language to the native request.

## Best solution

Bump foundry-local-sdk to 2.1.0 or later in package.json, the lockfile and the allow-list entry. Then verify that Japanese dictation with agents.voice.language set to ja produces text.
