# Issue #340656 — Local dictation returns empty transcript for non-English languages since 1.141.0 (foundry-local-sdk 2.0.1 drops language)

[https://github.com/microsoft/vscode/issues/340656](https://github.com/microsoft/vscode/issues/340656)

## Summary

Keep open: the discussion identifies a Foundry Local streaming-language regression, and current main still pins foundry-local-sdk 2.0.1. VS Code already supplies the language to the SDK; the reported upstream correction still needs verification and adoption.

## Change summary

Restore local dictation for Japanese, Spanish, and other affected non-English languages.

## Best solution

Adopt a verified Foundry Local release that forwards the language through live transcription, keeping the packaged native runtime aligned with the SDK. Confirm Japanese and Spanish transcription works without regressing English; cloud dictation is only a workaround.

- **Independent confirmation:** The 2026-10-19 comment on https://github.com/microsoft/vscode/issues/340656 confirms empty Spanish transcripts on VS Code 1.142.0 / Ubuntu 22.04 while English works, and reproduces the behavior outside VS Code using the bundled SDK with 16 kHz mono 16-bit audio and several Spanish language settings.
