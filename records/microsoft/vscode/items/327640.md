# Issue #327640 — MCP auth in Agent Sessions: "Authenticate" notification link is a no-op (targets sessions.html), and the whole auth flow completes silently

[https://github.com/microsoft/vscode/issues/327640](https://github.com/microsoft/vscode/issues/327640)

## Summary

Keep open as an Agents window bug. Current main intercepts the Authenticate link and displays progress, but failed or rejected authentication still completes silently because the result is discarded and errors are converted to an unreported false result.

## Change summary

Agent Sessions MCP authentication provides no actionable success or failure feedback, making an unsuccessful Authenticate action appear inert.

## Best solution

Make the Agents window authentication card retain and display explicit failure/cancellation state while successful authentication visibly resolves the card, and align the MCP command route with the same outcome reporting.
