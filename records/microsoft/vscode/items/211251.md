# Issue #211251 — Expanded SCM tree view is not scrolled into view

[https://github.com/microsoft/vscode/issues/211251](https://github.com/microsoft/vscode/issues/211251)

## Summary

The confirmed defect remains in the shared pane-view path on current main: expanding an overflowed pane changes its size and the scrollable content dimensions, but nothing reveals the expanded pane. This should remain open in the workbench views backlog.

## Change summary

Expanding the last SCM section while the pane container is vertically overflowed does not scroll the newly expanded content into view.

## Best solution

When a user expands a pane section in an overflowed vertical PaneView, bring enough of that section into the viewport to expose its expanded content while preserving normal collapse, resize, and user-scroll behavior.
