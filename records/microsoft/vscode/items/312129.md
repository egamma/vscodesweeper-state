# Issue #312129 — UI: Slash command dropdown truncates namespaced skills, hiding the command's purpose

[https://github.com/microsoft/vscode/issues/312129](https://github.com/microsoft/vscode/issues/312129)

## Summary

Fixed on current main by commit 0ab4910b94e14bea6555fc6c11c1a9fca389952a, which expands chat suggestion widgets to fit their content and prevents command labels from shrinking behind descriptions.

## Change summary

Namespaced skill commands in the chat slash-command dropdown were truncated before their distinguishing action suffix.

## Best solution

Keep the merged detail-aware sizing behavior from https://github.com/microsoft/vscode/pull/327913, which preserves the complete command label and lets secondary detail content yield when space is constrained.
