# Issue #326096 — [Terminal] Manually restart action

[https://github.com/microsoft/vscode/issues/326096](https://github.com/microsoft/vscode/issues/326096)

## Summary

Valid feature request: the 'Relaunch Active Terminal' command exists but is not exposed in the terminal tab context menu or terminal instance context menu, making it hard to discover and requiring a hover interaction. Keeping open for area owner review.

## Change summary

Add a 'Relaunch' (restart) action to the terminal tab context menu so users can restart terminals without hovering over status indicators.

## Best solution

Register `TerminalCommandId.Relaunch` in `MenuId.TerminalTabContext` (and possibly `MenuId.TerminalInstanceContext`) in `src/vs/workbench/contrib/terminal/browser/terminalMenus.ts`, grouped near the existing Kill action. Multi-select restart would follow naturally since the tab context menu already supports multi-selection for Kill.
