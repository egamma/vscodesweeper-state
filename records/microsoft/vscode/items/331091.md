# Issue #331091 — Support keyboard Layout on Linux

[https://github.com/microsoft/vscode/issues/331091](https://github.com/microsoft/vscode/issues/331091)

## Summary

Genuine, verified gap: the desktop keyboard layout service (electron-browser) always returns an empty layout list and has no manual override, unlike the web build's `keyboard.layout` setting — routing to the keyboard-layout area for a product decision.

## Change summary

Add the Web build's manual 'Configure Keyboard Layout' override (keyboard.layout setting) to the desktop Linux (and other platforms) build.

## Best solution

Extend `src/vs/workbench/services/keybinding/electron-browser/nativeKeyboardLayout.ts`'s `KeyboardLayoutService` to support a manual layout override analogous to the browser `BrowserKeyboardLayoutService`'s `keyboard.layout` config, since `getAllKeyboardLayouts()` is currently hardcoded to return `[]` on desktop.
