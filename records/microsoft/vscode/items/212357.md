- **Behavior:**

  > With Windows physical-keyboard text suggestions enabled, typing into the Command Palette can display an OS popup over command results. - **Trace:**

  > QuickInputController constructs QuickInputBox, which wraps FindInput and HistoryInputBox; the default flexibleHeight=false path in InputBox creates an HTML input. The uncertainty starts at why Windows suppresses suggestions for editor-backed controls but not these inputs; source inspection alone cannot identify that native interaction or prove a replacement fixes it. Do not indiscriminately alter shared InputBox behavior or weaken accessibility attributes to suppress suggestions. https://github.com/microsoft/vscode/issues/268091 is a newer related search-input report, not an eligible duplicate target for this issue.
