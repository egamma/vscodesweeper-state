# Issue #55440 — Disable undo menu item when there is no more history available

[https://github.com/microsoft/vscode/issues/55440](https://github.com/microsoft/vscode/issues/55440)

## Summary

The context keys `canUndo`/`canRedo` exist in `EditorContextKeys` and are maintained by the code editor widget, but the `UndoCommand` and `RedoCommand` still register with `precondition: undefined` — the menu items are never conditionally disabled. The feature remains unimplemented.

## Change summary

Disable the Undo/Redo menu items when there is no undo/redo history available.

## Best solution

Wire `EditorContextKeys.canUndo` / `canRedo` as the precondition on `UndoCommand` / `RedoCommand` in `src/vs/editor/browser/editorExtensions.ts`. The tricky part (noted in discussion) is that `canUndo`/`canRedo` are scoped to the focused editor — when focus is outside an editor (e.g. in an input or webview), a global context key is needed too, which may require additional plumbing.
