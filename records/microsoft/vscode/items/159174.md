# Issue #159174 — Find Dialogue

[https://github.com/microsoft/vscode/issues/159174](https://github.com/microsoft/vscode/issues/159174)

## Summary

Keep open: existing width resizing and tree filter defaults cover parts of the request, but editor find positioning and persistent tree-find visibility remain meaningful accessibility gaps. Maintainers supported those improvements in the discussion; no verified canonical issue was found.

## Change summary

Make editor Find easier to position for low-vision users and allow tree Find to remain visible, with its filter preference retained.

## Best solution

Provide an accessible positioning option for editor Find and an opt-in persistent tree-find presentation. Preserve existing width resizing and filter-default behavior, and follow the thread's preference against introducing independent zoom for individual widgets.
