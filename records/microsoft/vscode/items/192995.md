[https://github.com/microsoft/vscode/issues/192995](https://github.com/microsoft/vscode/issues/192995)

## Summary

The mixed-pattern traversal defect remains in current source: adding a relative folder include introduces a blanket exclusion that prevents traversal to files matching the other glob. Keep this confirmed search bug open; no verified older canonical owns the same symptom.

## Change summary

Combining a wildcard include with a relative folder include makes Find in Files lose matching files.

## Best solution

Ensure mixed global-glob and relative-folder includes preserve results from both patterns without admitting unrelated files. Cover actual search results as well as argument construction so directory-pruning errors cannot hide behind passing argument snapshots.
