## Summary

Team-authored performance bug about slow matplotlib output rendering when switching notebook editor tabs. No fix commit references this issue, and the report remains valid. Keeping open for the notebook team.

## Change summary

Matplotlib plot outputs render slowly when switching between notebook editor tabs, making it appear as if they don't render.

## Best solution

Investigate the notebook output webview restore path when switching editor tabs — the backlayer webview may be doing a full re-render instead of preserving cached output. The fix likely lives in the notebook output rendering pipeline (cellRenderer.ts / backLayerWebView.ts).
