# Issue #260295 — Move the AI usage pill into the Copilot dashboard

[https://github.com/microsoft/vscode/issues/260295](https://github.com/microsoft/vscode/issues/260295)

## Summary

The AI usage gauge still occupies a separate status bar entry; the Copilot dashboard does not expose its statistics. Keep this accepted request open while maintainers reconcile relocation with the newer proposal to remove the widget entirely.

## Change summary

Move the AI usage indicator into the Copilot dashboard instead of displaying a separate status bar pill.

## Best solution

Resolve whether AI attribution statistics remain useful in light of https://github.com/microsoft/vscode/issues/340001. If retained, expose them on demand in the Copilot dashboard without a separate status bar gauge; do not confuse edit-attribution statistics with subscription quota usage.
