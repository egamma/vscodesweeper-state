# Issue #260295 — Move the AI usage pill into the Copilot dashboard

[https://github.com/microsoft/vscode/issues/260295](https://github.com/microsoft/vscode/issues/260295)

## Summary

The AI usage gauge still occupies a separate status bar entry; the Copilot dashboard's quota display does not satisfy this relocation request. Keep this accepted design work open, but reconcile it with the newer proposal to remove the statistics widget before implementing a move.

## Change summary

Move the AI-versus-typing usage indicator from its separate status bar entry into the Copilot dashboard.

## Best solution

Resolve whether AI-versus-typing statistics remain useful in light of https://github.com/microsoft/vscode/issues/340001. If retained, consolidate them into the Copilot dashboard without a separate gauge; if removal is approved and lands, retire this relocation request against that concrete change.
