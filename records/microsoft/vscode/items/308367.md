# Issue #308367 — prompts-diagnostics-provider: false "File not found" errors for existing .md links in multi-root workspace

[https://github.com/microsoft/vscode/issues/308367](https://github.com/microsoft/vscode/issues/308367)

## Summary

The original multi-root path-resolution theory is not supported, but the refined stale-diagnostic bug remains present on current main: restoring a referenced file does not trigger validation of an open prompt document.

## Change summary

Clear a prompt's stale "File not found" diagnostic after its referenced Markdown file is restored.

## Best solution

Revalidate affected open prompt documents when referenced files are restored or changed, so markers reflect the current filesystem without requiring an edit to the prompt itself.
