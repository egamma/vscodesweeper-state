# Issue #322004 — Global, local-device search across Copilot Chat conversations

[https://github.com/microsoft/vscode/issues/322004](https://github.com/microsoft/vscode/issues/322004)

## Summary

Reasonable ask for a local, cross-window full-text search over saved Copilot chats; VS Code already has a 'Find Agent Session' filter in the Agent Sessions viewer (agentSessionsViewer.find in agentSessionsActions.ts) but that appears to filter the visible session list by title/metadata, not index message content across all local conversations, so a real gap likely remains. No upvotes or comments and the prior review also kept it open, so this stays under-discussion rather than promoted.

## Change summary

Request for a local, indexed, cross-window/workspace full-text search over saved Copilot Chat conversation history, with optional tags/favorites/filters.

## Best solution
