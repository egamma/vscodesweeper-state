# Issue #346220 — Window close shows "Remove Terminal Auto Replies" dialog because a pty host is spawned during shutdown

[https://github.com/microsoft/vscode/issues/346220](https://github.com/microsoft/vscode/issues/346220)

## Summary

The shutdown defect remains in current source: terminal cleanup can start an otherwise unused pty host, and the auto-reply shutdown joiner waits for it. Keep this open for a bounded fix that preserves cleanup for existing hosts.

## Change summary

Closing a window without using its terminal starts a pty host unnecessarily and can display the “Remove Terminal Auto Replies” shutdown dialog.

## Best solution

Terminal cleanup should finish without starting a previously unused pty host, while existing hosts still receive layout updates and owner-scoped auto-reply removal before disconnection.
