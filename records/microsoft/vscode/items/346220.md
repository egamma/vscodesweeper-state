# Issue #346220 — Window close shows "Remove Terminal Auto Replies" dialog because a pty host is spawned during shutdown

[https://github.com/microsoft/vscode/issues/346220](https://github.com/microsoft/vscode/issues/346220)

## Summary

The shutdown path still starts an otherwise unused pty host and joins its auto-reply cleanup on current main. Keep this open for the terminal area; the reported delay and dialog follow directly from that path.

## Change summary

Closing a window without using its terminal unnecessarily starts a pty host and can display the slow-shutdown dialog.

## Best solution

Terminal cleanup should not start a previously unused pty host, while cleanup of existing hosts, owner-scoped auto replies, and terminal persistence continue to work.
