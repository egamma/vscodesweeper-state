# Issue #344561 — Agent host: every server tool call keeps a connection-wide `onDidAction` listener until its turn ends

[https://github.com/microsoft/vscode/issues/344561](https://github.com/microsoft/vscode/issues/344561)

## Summary

Keep open: current source registers a connection-wide action listener for every observed server tool call and retains it after tool completion. This is a distinct, bounded listener-lifetime defect, not covered by the customization-listener PR or the broader remote-chat performance report.

## Change summary

Prevent server tool calls from accumulating connection-wide action listeners throughout long-running turns.

## Best solution

Keep tool-output dispatch bounded independently of completed tool-call count, while preserving live output delivery and isolation between chats, turns, and tools. Address this specific lifecycle defect separately from authentication listeners and broader transcript-rendering costs.
