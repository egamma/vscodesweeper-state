# Issue #264652 — Want `Preview Internally` setting or dropdown option in issue reporter

[https://github.com/microsoft/vscode/issues/264652](https://github.com/microsoft/vscode/issues/264652)

## Summary

Valid feature request from a team member — the internal "Create Internally" button is still a plain Button with no preview dropdown on current main, while the public button already supports a ButtonWithDropdown with a preview action. The requested capability is not yet implemented.

## Change summary

Add a "Preview Internally" option (dropdown or setting) to the issue reporter's "Create Internally" button, mirroring the existing preview dropdown on the public "Create on GitHub" button.

## Best solution

Add a preview action to the internal button in `baseIssueReporterService.ts` by converting the internal button from a plain `Button` to a `ButtonWithDropdown` (similar to the public button at line 311), with a preview action that opens the internal repo's new-issue form pre-filled. Alternatively, a setting could default the internal button to preview mode.
