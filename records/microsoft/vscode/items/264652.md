# Issue #264652 — Want `Preview Internally` setting or dropdown option in issue reporter

[https://github.com/microsoft/vscode/issues/264652](https://github.com/microsoft/vscode/issues/264652)

## Summary

Keep open: the classic issue reporter still offers preview for public submissions but immediately creates internal issues. The optional wizard provides a browser-preview submission path, but does not establish completion of this team-authored request.

## Change summary

Allow internal issue submissions to open a GitHub draft instead of immediately creating the issue, through a dropdown or configurable default.

## Best solution

Provide an explicit internal-preview workflow that retains the private destination and populated report without submitting it. Settle whether this is a per-submission choice or a persisted preference, accounting for both the classic reporter and optional wizard.
