# Issue #286323 — Chat input shadows are confusing

[https://github.com/microsoft/vscode/issues/286323](https://github.com/microsoft/vscode/issues/286323)

## Summary

The misleading bottom shadow was fixed, but the remaining top shadow is still scoped to the narrower Monaco editor rather than the full chat-input surface. The issue remains necessary for that visual gap.

## Change summary

Make overflowing chat-input shadows span the input surface and indicate only the directions in which more content can be scrolled.

## Best solution

Keep the native top scroll indication only while content exists above, but render it across the full chat-input surface rather than only the embedded editor; do not restore the removed toolbar shadow.
