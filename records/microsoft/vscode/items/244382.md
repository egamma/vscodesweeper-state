# Issue #244382 — Hide unhide of dot files and hidden folders not working on vscode macos using Shift+Cmd+. keybinding

[https://github.com/microsoft/vscode/issues/244382](https://github.com/microsoft/vscode/issues/244382)

## Summary

Shift+Cmd+. is a macOS Finder shortcut to toggle hidden files — it has never been a VS Code feature. VS Code uses `files.exclude` patterns to control explorer visibility; there is no built-in toggle command or keybinding for dot-file visibility.

## Change summary

Reporter expects macOS Finder's Shift+Cmd+. hidden-file toggle to work in VS Code's file explorer.

## Best solution

Close as designed — VS Code controls file visibility via the `files.exclude` setting, not a Finder-style toggle. Users can manually add/remove `**/.*` patterns from `files.exclude` or use an extension that provides a toggle command.

  > Thanks for reporting this. The Shift+Cmd+. shortcut is a macOS Finder feature for toggling hidden file visibility — it isn't (and hasn't been) a VS Code built-in keybinding.
  > 
  > In VS Code, file visibility in the explorer is controlled by the `files.exclude` setting. You can add `"**/.*": true` to hide dot-files, or remove that pattern to show them. There are also extensions on the Marketplace that provide a one-click toggle for this.
  > 
  > Closing this as the current behavior is by design. If you'd like to request a built-in toggle command for dot-file visibility, feel free to open a new feature request.
