# Issue #338890 — NativeEditContext: tapping a keyboard suggestion on Android corrupts the line

[https://github.com/microsoft/vscode/issues/338890](https://github.com/microsoft/vscode/issues/338890)

## Summary

The reported defects remain in current main: NativeEditContext can retain phantom text, misplace the caret, and copy the wrong surrounding characters when accepting keyboard suggestions. Keep this report open; the newer Android Enter report concerns a separate failure and does not replace it.

## Change summary

Prevent Android keyboard suggestions from corrupting document text after a caret move.

## Best solution

Make NativeEditContext's surrounding text and event-to-editor offset translation remain consistent through keyboard replacements and selection-only updates. Preserve unaffected text and the keyboard-requested caret position without expanding this fix into composing-keyboard Enter handling or Chromium composition behavior.
