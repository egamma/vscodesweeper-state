# Issue #280654 — Long chat context titles should be truncated

[https://github.com/microsoft/vscode/issues/280654](https://github.com/microsoft/vscode/issues/280654)

## Summary

Still reproduces on main: attachment containers use `width: fit-content` which defeats ellipsis truncation for long context titles. An open draft PR (https://github.com/microsoft/vscode/pull/292863) is in progress but unmerged.

## Change summary

Long chat context attachment titles (e.g. PR titles) overflow instead of being truncated with ellipsis.

## Best solution

Land https://github.com/microsoft/vscode/pull/292863 (or its successor) to apply proper `max-width` / `text-overflow: ellipsis` on the attachment label container so long context names are truncated. The fix lives in `src/vs/workbench/contrib/chat/browser/widget/media/chat.css` around the `.chat-attached-context-attachment` rules.
