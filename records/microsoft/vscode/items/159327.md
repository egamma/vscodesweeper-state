# Issue #159327 — Auto open Diff Editor when Refactor Preview is opened

[https://github.com/microsoft/vscode/issues/159327](https://github.com/microsoft/vscode/issues/159327)

## Summary

A real UX gap remains in the current multi-diff implementation, and this Backlog request has 25 community upvotes. The obsolete PR should not close the issue; the interaction should be reconsidered for the newer architecture.

## Change summary

Automatically open and restore the Refactor Preview diff editor when the Refactor Preview panel opens.

## Best solution

Revisit the interaction using the current multi-diff editor in `src/vs/workbench/contrib/bulkEdit/browser/preview/bulkEditPane.ts`, balancing discoverability against the maintainers' concern that simultaneously opening a panel and editor is distracting.
