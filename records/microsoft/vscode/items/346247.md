# Issue #346247 — Agents window: canvases from a remote agent host session can't be listed or opened from the UI

[https://github.com/microsoft/vscode/issues/346247](https://github.com/microsoft/vscode/issues/346247)

## Summary

The remote canvas discovery and opening gap remains in current main: the sessions provider requires connection methods that AgentHostProtocolClient does not implement. The related close-canvas report describes a different observable failure and does not justify consolidating this re-reviewed issue.

## Change summary

Registered remote-session canvases are missing from the Available picker and Customizations, preventing users from opening them directly.

## Best solution

Provide remote canvas discovery and user-initiated opening through a negotiated host contract, preserving local behavior and compatibility with hosts that lack the capability. Coordinate with the related close-canvas work without losing this issue's distinct discovery requirement.
