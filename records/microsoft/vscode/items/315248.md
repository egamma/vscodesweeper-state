# Issue #315248 — Changing from PLAN mode to Agent Mode (Start Implementation) should compact the conversation

[https://github.com/microsoft/vscode/issues/315248](https://github.com/microsoft/vscode/issues/315248)

## Summary

Genuine feature request for auto-compacting conversation context when transitioning from Plan mode to Agent mode. No existing implementation found on main; the capability gap is real.

## Change summary

When switching from Plan mode to Agent mode via 'Start Implementation', the full planning conversation remains in context rather than being compacted/summarized.

## Best solution

Implement context compaction (or summarization) when the mode transitions from Plan to Agent, gated behind a setting. The implementation would likely touch the chat service's mode-switching logic and the model's turn history management in `src/vs/workbench/contrib/chat/common/chatService/chatServiceImpl.ts` and `src/vs/workbench/contrib/chat/common/model/chatModel.ts`.
