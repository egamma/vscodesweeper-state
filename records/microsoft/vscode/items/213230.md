# Issue #213230 — alt + f5 doesnt work for Goto Next Change, but Shift+Alt+F5 does, maybe PowerToys conflict

[https://github.com/microsoft/vscode/issues/213230](https://github.com/microsoft/vscode/issues/213230)

## Summary

The keyboard troubleshooting logs conclusively show that VS Code's keybinding service never receives the F5 keydown event when Alt is held — something external (PowerToys, Windows 11, or another app) is intercepting the keystroke before it reaches the Electron window. This is not a VS Code keybinding bug, but the reporters haven't confirmed the external cause or whether it persists on current builds.

## Change summary

Alt+F5 (Goto Next Change) does not fire because an external application intercepts the keystroke before it reaches VS Code on Windows 11.

## Best solution

This is almost certainly caused by external software (PowerToys, Windows 11 hotkeys, or keyboard firmware) intercepting Alt+F5. The reporter and commenters should identify and disable the conflicting shortcut in their system. If the issue persists with all external key-remapping tools disabled, a fresh report with updated troubleshooting logs on the latest VS Code build would be needed.
