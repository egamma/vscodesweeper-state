# Issue #331754 — [Terminal][IME][Korean] Ghost duplicate preview of the in-progress (composing) Korean character appears diagonally below the cursor while typing

[https://github.com/microsoft/vscode/issues/331754](https://github.com/microsoft/vscode/issues/331754)

## Summary

IME composition rendering in the integrated terminal is implemented entirely inside the `@xterm/xterm` dependency's CompositionHelper, not VS Code's own terminal code, so this is best classified as an upstream rendering defect rather than a VS Code bug to fix directly — though it should stay open pending upstream investigation or a version pin/revert.

## Change summary

A ghost/duplicate preview of the in-progress (composing) CJK character is rendered offset below the real cursor position while IME composition is active in the Integrated Terminal.

## Best solution

Confirm whether this is a regression from the recent xterm.js beta bump (package.json currently pins `@xterm/xterm` ^6.1.0-beta.302 and `@xterm/headless` ^6.1.0-beta.301) and either file/track the defect against xterm.js upstream or pin back to a known-good pre-regression beta until fixed there; not something VS Code's own terminal contribution code controls.
