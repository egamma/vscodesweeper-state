# Issue #331754 — [Terminal][IME][Korean] Ghost duplicate preview of the in-progress (composing) Korean character appears diagonally below the cursor while typing

[https://github.com/microsoft/vscode/issues/331754](https://github.com/microsoft/vscode/issues/331754)

## Summary

Real, well-corroborated display-only glitch (three independent CJK IME confirmations with screenshots), but the composition preview element and its positioning are owned by the bundled @xterm/xterm dependency, not VS Code's own terminal source — routing to the terminal area as an upstream issue rather than closing.

## Change summary

While composing a CJK character in the integrated terminal, a duplicate 'ghost' preview of the in-progress composition renders offset from the real cursor until the character is finalized.

## Best solution

Terminal team should reproduce against the current @xterm/xterm beta and, if confirmed as a regression in that library's CompositionHelper/composition-view positioning, file or track the fix upstream in xtermjs/xterm.js (this repo's src/vs/workbench/contrib/terminal/browser/media/xterm.css only mirrors xterm.js's own composition-view styling, it doesn't compute the position).
