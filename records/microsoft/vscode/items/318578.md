# Issue #318578 — Use Agents Window without signing in

[https://github.com/microsoft/vscode/issues/318578](https://github.com/microsoft/vscode/issues/318578)

## Summary

This is the canonical, team-authored backlog request and remains unimplemented on main. It has substantial community support and directly enables BYOK use in environments where GitHub sign-in is unavailable or prohibited.

## Change summary

Allow users with BYOK models to enter and use the Agents Window without signing in to GitHub Copilot.

## Best solution

Make the Agents Window setup dialog dismissible or provide a “Continue without Signing In” action that completes setup without a GitHub account, while retaining passive Copilot sign-in affordances. The flow belongs in `src/vs/sessions/browser/sessionsSetUpService.ts` and should preserve the existing AI-feature consent gate.
