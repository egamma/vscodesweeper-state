# Issue #46654 — [folding] Fold block comments scrolls editor

[https://github.com/microsoft/vscode/issues/46654](https://github.com/microsoft/vscode/issues/46654)

## Summary

The reported scroll jump remains present on current main: every folding action unconditionally reveals the cursor after running, even when the action neither hides nor moves it. This is a bounded editor-folding bug with no verified duplicate or active fixing PR.

## Change summary

Running Fold All Block Comments scrolls an off-screen cursor back into view even when folding does not affect that cursor.

## Best solution

Preserve the editor viewport when a folding action leaves the cursor unaffected, while retaining the existing behavior that reveals the cursor when folding moves it out of a newly hidden range.
