# Issue #340185 — Terminal created from a contributed terminal profile is not focused when the extension host is remote (creation is not awaited before focusing the "last" instance)

[https://github.com/microsoft/vscode/issues/340185](https://github.com/microsoft/vscode/issues/340185)

## Summary

The current source still permits contributed-profile creation to finish after VS Code selects and focuses the previous terminal. Route this unlabeled report to the terminal area; the linked extension PR is a workaround, not a completed core fix.

## Change summary

Creating a contributed terminal profile through the terminal dropdown can leave the new terminal unfocused when the extension host is remote.

## Best solution

Contributed-profile creation should complete only when its terminal instance is available, and focus should target that specific instance rather than whichever terminal happens to be last. Preserve the synchronous public terminal-creation API and existing location semantics.
