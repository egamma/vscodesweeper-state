# Issue #336374 — Placeholder text used as the only visible label for Search input field: A11y_VisualStudioCode_Labels or Instructions

[https://github.com/microsoft/vscode/issues/336374](https://github.com/microsoft/vscode/issues/336374)

## Summary

Legitimate accessibility observation (WCAG 3.3.2) that the search/quick-access input relies on placeholder text as its only visible label, with no persistent on-screen label; this is a design-wide pattern rather than a simple code bug, so it needs the accessibility team's judgment rather than an automated close.

## Change summary

The Quick Access/search input shows only placeholder text (no persistent visible label), which disappears once text is typed, hurting low-vision and cognitive-disability users.

## Best solution

Have the accessibility team decide whether a persistent visible label should be added around the quick-access/search input (e.g. in src/vs/platform/quickinput/browser/quickInputBox.ts and its widget wrapper) or whether the existing aria-label + compact placeholder design is an intentional, accepted UI tradeoff for this dense control.
