# Issue #336374 — Placeholder text used as the only visible label for Search input field: A11y_VisualStudioCode_Labels or Instructions

[https://github.com/microsoft/vscode/issues/336374](https://github.com/microsoft/vscode/issues/336374)

## Summary

Genuine, freshly-filed accessibility report from an internal a11y scan: the Quick Open/search input relies on placeholder text (and an aria-label mirrored from it) as its only visible label, with no persistent visible label element — this is a real WCAG 3.3.2 gap worth routing to the accessibility area for a design decision rather than closing.

## Change summary

The Quick Open / search input field shows only placeholder text as its visual label, which disappears once the user starts typing, leaving no persistent visible label.

## Best solution

An accessibility/design call is needed on whether to add a persistent visible label (or an equivalent affordance) to the quick input widget in src/vs/platform/quickinput/browser/quickInputBox.ts and quickInput.ts; this is a UX/design tradeoff for a very widely used core surface, not a one-line fix.
