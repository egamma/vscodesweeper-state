# Issue #320225 — Unsaved image preview tab can't be closed (and is buggy)

[https://github.com/microsoft/vscode/issues/320225](https://github.com/microsoft/vscode/issues/320225)

## Summary

The close failure is still present in current source: an untitled readonly image preview becomes dirty, but neither Save nor Don't Save clears that state, so closing is vetoed. Two newer reports document the related lifecycle and content-ownership problems; neither can replace this older, re-reviewed report under the duplicate rules.

## Change summary

Reopening an unsaved text document as Image Preview creates a tab that cannot be closed through the save/discard dialog and can acquire another untitled document's title and icon.

## Best solution

Make untitled custom-editor transitions preserve authoritative text and ensure explicit discard can close an already-stranded readonly preview without weakening the editor group's dirty-state protection. Coordinate with the two newer lifecycle reports and investigate the title/icon aliasing before treating this original report as fully resolved.
