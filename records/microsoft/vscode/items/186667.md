- **Current watcher path:** extensions/git/src/repository.ts:930 creates a recursive '**' file-system watcher rooted at repository.root, which can be the home directory rather than the opened subfolder. src/vs/platform/files/node/watcher/parcel/parcelWatcher.ts:364–386 passes the root and configured exclusions to parcelWatcher.subscribe and logs 'Started watching' after subscription completes. This matches the historical trace boundary but does not establish the current duration or an upstream defect.
- **Current Git status path:** extensions/git/src/git.ts:2794–2850 invokes 'git status -z -uall' unless git.untrackedChanges is hidden; the status limit terminates the child only after parsed output exceeds the limit. This supplies a separate plausible enumeration path for the newer 10,000-change report, not proof that it caused the original fileWatcher CPU usage.
