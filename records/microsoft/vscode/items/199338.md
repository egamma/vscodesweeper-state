# Issue #199338 — Don't honor padding config in multi-diff editors

[https://github.com/microsoft/vscode/issues/199338](https://github.com/microsoft/vscode/issues/199338)

## Summary

Keep open: multi-diff editors still inherit ordinary editor padding, and the existing layout variants do not provide independent control. This team-authored Backlog request needs a decision on padding inheritance, not a staleness or as-designed close.

## Change summary

Allow multi-diff editors to omit vertical editor padding while regular editors retain configured top and bottom gaps.

## Best solution

Establish multi-diff-specific padding semantics that let users retain padding in regular editors without adding it to every embedded diff. Decide whether multi-diff editors should always ignore ordinary editor padding or offer an independent override.

- **Trace:**

  > MultiDiffEditorInput builds each document item's options from resource configuration through computeOptions in src/vs/workbench/contrib/multiDiffEditor/browser/multiDiffEditorInput.ts.
