## Change summary

Avoid accessing the OS keyring during startup when Settings Sync, Cloud Changes, and other authentication-dependent features have not been enabled.

## Best solution

Audit the existing Cloud Changes startup gates and identify any remaining consumer before changing code or declaring this completed.
