# Issue #306967 — Agent doesn't ask while deleting files

[https://github.com/microsoft/vscode/issues/306967](https://github.com/microsoft/vscode/issues/306967)

## Summary

Current source groups patch-based deletion with ordinary edit approvals rather than providing a deletion-specific permission switch. Keep this destructive-operation authorization concern open for human review; existing path-based approval controls only partially cover the request.

## Change summary

Provide independent permission control for agent file deletion so users can allow creation and editing while requiring confirmation before removal.

## Best solution

Define deletion-specific authorization across patch tools and terminal-based deletion without unnecessarily restricting ordinary edits. Review the overlapping safeguard request at https://github.com/microsoft/vscode/issues/298393 before deciding whether to consolidate the reports.
