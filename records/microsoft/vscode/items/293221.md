# Issue #293221 — Integrated browser: find widget pushed web page content down

[https://github.com/microsoft/vscode/issues/293221](https://github.com/microsoft/vscode/issues/293221)

## Summary

Still present on main: the browser find widget is deliberately laid out in-flow (position: relative, flex-shrink: 0) rather than overlaid, so opening it pushes the web page content down. No fix commit references this issue and the CSS is unchanged.

## Change summary

Opening the find widget in the integrated browser pushes the rendered web page content downward instead of overlaying the widget on top of the content.

## Best solution

Change the find widget wrapper's CSS from in-flow positioning to an overlay approach (e.g. position: absolute with a z-index above the browser container), similar to how the editor's built-in find widget floats over content. The layout callback in `layoutBrowserContainer` should not need to resize the browser view when the find widget toggles — the WebContentsView bounds should remain stable. Likely files: `browser.css` (.browser-find-widget-wrapper rules) and possibly `browserEditorFindFeature.ts` (the `onDidChangeHeight` → `layoutBrowserContainer` call may become unnecessary or need adjustment).
