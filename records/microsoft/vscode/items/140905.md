# Issue #140905 — Multiple line commenting does not work for languages like XML/HTML

[https://github.com/microsoft/vscode/issues/140905](https://github.com/microsoft/vscode/issues/140905)

## Summary

Keep open as the canonical backlog request. Current main still converts an ordinary multi-line selection into one block comment, while the multi-cursor workaround does not provide the requested single-selection workflow.

## Change summary

Apply separate block-comment pairs to each selected line when a language lacks native line comments.

## Best solution

Add a core command or language-configuration capability for per-line block commenting without changing the established default block-comment behavior. The editor comment implementation and its command tests are the likely implementation area.
