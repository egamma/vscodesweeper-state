# Issue #335226 — Agent harness always receives current file context

[https://github.com/microsoft/vscode/issues/335226](https://github.com/microsoft/vscode/issues/335226)

## Summary

This is intentional: agent-host sessions forward the active editor as ambient context by default via `chat.implicitContext.includeActiveEditor`, independent of whether the user explicitly attached it with the '+' button — there's a dedicated setting to turn this off.

## Change summary

Reporter expected that not clicking '+' on the active file means it's excluded from the Codex agent harness request, but the current file is still sent.

## Best solution

Point the reporter at `chat.implicitContext.includeActiveEditor` (default `true`), which they can disable to stop the active editor from being auto-forwarded to agent-host sessions.
