# Issue #335226 — Agent harness always receives current file context

[https://github.com/microsoft/vscode/issues/335226](https://github.com/microsoft/vscode/issues/335226)

## Summary

This is intentional: agent-host (Copilot/Codex agent harness) sessions always forward the active editor as ambient context unless the `chat.implicitContext.includeActiveEditor` setting is turned off — the per-message +/- toggle only controls the 'suggested context' UI, not this ambient forwarding, and that split is explicitly documented in the setting description and in code.

## Change summary

In an agent harness session, toggling off the current-file 'suggested context' chip doesn't stop the active file from being sent — it's forwarded anyway.

## Best solution

Point the reporter at `chat.implicitContext.includeActiveEditor` (default on) to fully stop automatic active-editor forwarding in Agent Host sessions; if the toggle-vs-setting split is felt to be confusing UX, that's a separate polish/UI-clarity follow-up, not this bug.
