# Issue #335226 — Agent harness always receives current file context

[https://github.com/microsoft/vscode/issues/335226](https://github.com/microsoft/vscode/issues/335226)

## Summary

The active file is intentionally forwarded as ambient context in Agent Host sessions when `chat.implicitContext.includeActiveEditor` is enabled; the explicit attachment control does not disable that setting.

## Change summary

Prevent Codex from receiving the active file unless the user explicitly adds it to the prompt context.

## Best solution

Keep the existing behavior and use `chat.implicitContext.includeActiveEditor: false` when active-editor context should require explicit attachment.
