# Issue #333879 — the disabled cloud pill has low contrast and is hard to read

[https://github.com/microsoft/vscode/issues/333879](https://github.com/microsoft/vscode/issues/333879)

## Summary

Fresh, team-authored accessibility polish report confirmed by a collaborator as a valid tracked contrast issue; no fix has landed yet, so this stays open pending a contrast adjustment to the disabled session-type/cloud pill styling.

## Change summary

The disabled state of the cloud session-type pill in the chat input renders with low-contrast styling in themes like Quiet Light and Abyss, making it hard to read.

## Best solution

Adjust the disabled-state color/opacity rules for the session type picker trigger (e.g. `.sessions-chat-picker-slot.disabled .action-label` in src/vs/sessions/contrib/chat/browser/media/chatWidget.css, and the related `.disabled` toggle in sessionTypePicker.ts) so the disabled pill still meets contrast guidance across themes, rather than relying on generic dimmed-disabled styling.
