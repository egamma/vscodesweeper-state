# Issue #336379 — Built-in Git extension writes branch.*.vscode-merge-base via git config --add and can wipe remotes from .git/config

[https://github.com/microsoft/vscode/issues/336379](https://github.com/microsoft/vscode/issues/336379)

## Summary

The merge-base config write still exists, but the supplied logs do not establish that it deletes unrelated configuration. Request a reproduction in current official VS Code and evidence identifying the write that truncates the file before attributing this to the built-in Git extension.

## Change summary

Branch switching reportedly deletes repository-local remotes, tracking settings, and identity configuration in two sibling repositories.

## Best solution

Establish which process destroys .git/config, then address the responsible write path so unrelated repository configuration survives branch changes. Changing append semantics alone is not a demonstrated fix for file truncation.
