# Issue #214389 — Integrated Terminal Distorts Text Upon Restart After Being Terminated

[https://github.com/microsoft/vscode/issues/214389](https://github.com/microsoft/vscode/issues/214389)

## Summary

Confirmed terminal layout bug: when Problems, Debug Console, and Terminal panels are all visible and the terminal is killed and restarted, the terminal renders at a restricted/distorted size. No fix commit references this issue, and no related layout fix on main appears to address this specific scenario. Keeping open.

## Change summary

Restarting a killed terminal while Problems and Debug Console panels are visible causes the terminal to render at a distorted/restricted size.

## Best solution

The terminal layout code in `src/vs/workbench/contrib/terminal/browser/terminalGroup.ts` (and possibly the panel layout in `terminalView.ts`) needs to correctly recalculate dimensions when a new terminal instance is created while sibling panel sections are open. The fix likely involves ensuring `layout()` is called with correct dimensions after the new terminal instance attaches to the split view.
