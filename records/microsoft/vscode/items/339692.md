# Issue #339692 — Agents - number of runs is a weird flow

[https://github.com/microsoft/vscode/issues/339692](https://github.com/microsoft/vscode/issues/339692)

## Summary

Thanks for the feedback. The inline Number of Runs control still appears on the model-selection step only while exactly one model is selected, so the reported flow is unchanged on main. The proposed wizard flow is a UX decision for the owners, so this stays open.

## Change summary

Replace the Number of Runs control that appears and disappears with the model count by a separate step shown only when one model is selected.

## Best solution

Make the attempts step model-selection only. On Next, show a separate Number of Runs step only when exactly one model is selected. Skip it otherwise and go to the judge step.
