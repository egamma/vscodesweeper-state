# Issue #339692 — Agents - number of runs is a weird flow

[https://github.com/microsoft/vscode/issues/339692](https://github.com/microsoft/vscode/issues/339692)

## Summary

Confirmed from source: the run-count control is rendered inline on the same 'attempts' page and only appears when exactly one model is selected, so it visibly pops in/out as the selection changes, exactly as the reporter (a team member) describes — this is real, actionable UX work on a brand-new Agents feature and should stay open for implementation.

## Change summary

The 'Number of Runs' control in the Agents comparison model picker appears and disappears awkwardly on the same page as you add/remove selected models; the reporter suggests splitting it into its own page shown only when one model is selected.

## Best solution

Split the run-count control into its own step in SessionComparisonModelSelection's state machine (a 'count' step reached only when exactly one model was selected on 'attempts'), rather than conditionally rendering it inline on the same page.
