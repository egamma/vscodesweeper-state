# Issue #251084 — [LEAKED DISPOSABLE] in extensions view

[https://github.com/microsoft/vscode/issues/251084](https://github.com/microsoft/vscode/issues/251084)

## Summary

The disposable leak remains possible on current main: a cancelled local-extension query can finish late, install its result into the view, and then be overwritten without its query-scoped DisposableStore being disposed.

## Change summary

Ensure resources created by an in-flight extensions-view query are disposed when the query is cancelled, superseded, or completes after the view is disposed.

## Best solution

Make query-result ownership cancellation-safe so only the active request can publish its model and every superseded or post-disposal result disposes its query-scoped resources.

- **Behavior:**

  > Cancelling or superseding an extensions-view query must release every listener and disposable created for that query, including when its asynchronous work finishes after cancellation. A late result must not replace the current query model or survive disposal of the view. Normal completed @installed queries must continue updating when installed or running extensions change.
- **Trace:**

  > ExtensionsListView.show in src/vs/workbench/contrib/extensions/browser/extensionsViews.ts cancels the current CancelablePromise before starting another query, but the callback awaiting query() can continue and assign this.queryResult after cancellation. queryLocal creates a DisposableStore only after awaiting the workbench service and filtering, then places its emitter and change listener in that store. The callback returns an IPagedModel rather than the owning IQueryResult, so createCancelablePromise in src/vs/base/common/async.ts cannot automatically dispose the nested store when cancellation wins. A later completion can overwrite this.queryResult, or repopulate it after dispose(), leaving the old store unreachable. Keep gallery-query behavior and live updates for the active local query unchanged; the boundary is ownership and publication of cancelled query results.
