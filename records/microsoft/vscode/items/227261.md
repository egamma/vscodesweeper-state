# Issue #227261 — Support mouse wheelScrollSensitivity in notebooks

[https://github.com/microsoft/vscode/issues/227261](https://github.com/microsoft/vscode/issues/227261)

## Summary

A real configuration gap remains on current main: notebooks inherit the global workbench list sensitivity, so they cannot be tuned independently. Keep this canonical request open for a notebook-area decision.

## Change summary

Allow notebook mouse-wheel sensitivity to be configured independently from Explorer and other workbench lists.

## Best solution

Either normalize notebook scrolling so the global sensitivity behaves consistently across workbench surfaces, or add a notebook-specific sensitivity override in the notebook editor configuration without changing other lists.
