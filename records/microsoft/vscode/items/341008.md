# Issue #341008 — Clicking an Outline item navigates the wrong editor when its source is in an auxiliary window

[https://github.com/microsoft/vscode/issues/341008](https://github.com/microsoft/vscode/issues/341008)

## Summary

Thanks for the detailed report. The code path explains the behavior: the Outline reveals symbols through ICodeEditorService.openCodeEditor, which opens into ACTIVE_GROUP rather than the group that owns the outlined editor. After clicking in the main window's Outline view, the active group is the main window's, so the navigation lands in the wrong editor.

## Change summary

Clicking an Outline symbol navigates the last-active editor instead of the auxiliary-window editor whose outline is shown.

## Best solution

Make the Outline reveal target the group of the outlined editor: resolve the source editor's group via the editor service and open there, or reveal directly in the source editor when the resource matches. Do this in the document-symbols adapter or in CodeEditorService.doOpenCodeEditor.
