# Issue #250678 — when trying to add an invalid resource, show the error in the quick input

[https://github.com/microsoft/vscode/issues/250678](https://github.com/microsoft/vscode/issues/250678)

## Summary

Keep open: current source still disposes the MCP resource input before checking whether the resource exists, then reports failure through a notification. The requested inline correction flow remains missing, and no verified canonical or linked implementation was found.

## Change summary

Keep the MCP resource quick input open with an inline error when an entered resource does not exist, allowing correction without repeating earlier inputs.

## Best solution

Make unsuccessful resource-template validation recoverable within the existing quick-input flow, retaining entered values so the user can correct the invalid resource and retry. Preserve successful attachment and resource-opening behavior.
