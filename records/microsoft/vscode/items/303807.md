# Issue #303807 — In a multi-root workspace, all user tasks are injected into request context multiple times (for each workspace folder)

[https://github.com/microsoft/vscode/issues/303807](https://github.com/microsoft/vscode/issues/303807)

## Summary

The reported duplication remains source-reproducible: task collection reads inherited configuration for every workspace folder, and the agent prompt renders each resulting list independently. Keep this open to eliminate repeated user-task metadata without conflating genuinely folder-specific tasks.

## Change summary

User tasks are repeated under every workspace folder in the agent's workspace context, unnecessarily consuming its token budget.

## Best solution

Make agent task context distinguish shared user-task definitions from folder-owned definitions, presenting shared metadata once while retaining the information needed to select and execute tasks in the correct folder. Preserve existing task execution and configuration behavior.
