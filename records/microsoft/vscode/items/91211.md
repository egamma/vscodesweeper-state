# Issue #91211 — Find/replace icons are not intuitive

[https://github.com/microsoft/vscode/issues/91211](https://github.com/microsoft/vscode/issues/91211)

## Summary

This accepted Backlog request remains necessary: current main still presents find/replace actions as compact icon-only controls, and no setting provides persistent visual labels. Its 29 community upvotes also exceed the Backlog promotion threshold.

## Change summary

Make editor find/replace controls easier to understand through persistent labels, clearer icons, and better grouping.

## Best solution

Design an adaptive or otherwise space-conscious labeled presentation for the editor find widget, covering its inputs, search options, selection scope, and replacement actions. The implementation likely belongs in the editor find widget and shared find-input controls without removing the existing accessible names or keyboard behavior.
