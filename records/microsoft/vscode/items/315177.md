# Issue #315177 — Add API for computing the diff between two documents

[https://github.com/microsoft/vscode/issues/315177](https://github.com/microsoft/vscode/issues/315177)

## Summary

The document diff API is implemented behind the documentDiff proposal gate, but it is not available in the stable API. Keep this api-proposal tracking issue open for the API owners to evaluate and finalize; the merged implementation does not complete that lifecycle.

## Change summary

Expose VS Code's document diff algorithm to extensions so custom diff renderers do not need to reimplement it.

## Best solution

Evaluate the existing workspace.getTextDiff proposal with extension consumers and settle its public contract before finalization into vscode.d.ts. Reuse the existing editor-worker implementation rather than introducing another diff engine.
