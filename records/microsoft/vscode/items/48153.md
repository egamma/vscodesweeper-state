# Issue #48153 — Option to configure editor scrollbar to be opaque

[https://github.com/microsoft/vscode/issues/48153](https://github.com/microsoft/vscode/issues/48153)

## Summary

The requested opacity control is implemented: scrollbar.background configures the scrollbar track, not merely its slider, without requiring a minimap. Propose closing as completed while retaining the default transparent appearance.

## Change summary

Allow an opaque editor scrollbar track so line highlights and text underneath do not obscure the scroll position.

## Best solution

Use workbench.colorCustomizations with an opaque scrollbar.background color, implemented in commit 908f34c37dd98bf1e6d88e695cc8b5a4cf0addc0. No additional option is needed for the ordinary editor scenario described here.
