# Issue #48153 — Option to configure editor scrollbar to be opaque

[https://github.com/microsoft/vscode/issues/48153](https://github.com/microsoft/vscode/issues/48153)

## Summary

Implemented and shipped: `editorOverviewRuler.background` can make the editor's overview-ruler/scrollbar area opaque even without the minimap.

## Change summary

Allow users to prevent editor content and line highlighting from showing through the transparent scrollbar area.

## Best solution

Use `workbench.colorCustomizations` to assign an opaque color such as `"editorOverviewRuler.background": "#ff0000ff"`; commit 84c141253338b5497ebc41ad2d2a2f03fac9d0b6 implemented this behavior.
