# Issue #325554 — Log Panel: Flow Chart hard to navigate

[https://github.com/microsoft/vscode/issues/325554](https://github.com/microsoft/vscode/issues/325554)

## Summary

Valid polish request from a team member: the Agent Debug Log flow chart uses mouse-wheel-to-zoom with CSS-transform panning and no scrollbars, making navigation awkward compared to a normal scroll-based view. No fix has landed on main since filing. Keeping open as a team-authored item in the Backlog.

## Change summary

The flow chart in the Agent Debug Log panel lacks scrollbars and maps the mouse wheel exclusively to zoom instead of scrolling, making navigation unintuitive.

## Best solution

Refactor `ChatDebugFlowChartView` (in `src/vs/workbench/contrib/chat/browser/chatDebug/chatDebugFlowChartView.ts`) to use native scrollbars for panning, change the default mouse-wheel behavior to vertical scrolling, and auto-fit the zoom scale to the editor font size. Zoom can remain accessible via Ctrl+wheel or the existing +/– keyboard shortcuts.
