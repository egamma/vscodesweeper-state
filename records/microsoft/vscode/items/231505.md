# Issue #231505 — Chinese not fully supported.

[https://github.com/microsoft/vscode/issues/231505](https://github.com/microsoft/vscode/issues/231505)

## Summary

The `<U+XXXX>` output is produced by the R kernel (IRkernel), a third-party extension, not by VS Code's notebook rendering. VS Code faithfully displays whatever text the kernel sends; the encoding issue lives in the R runtime/kernel's locale handling.

## Change summary

Chinese characters in R notebook output are displayed as `<U+XXXX>` escape sequences instead of rendered Unicode glyphs.

## Best solution

Report to the R kernel extension (IRkernel / vscode-R) maintainers, or configure the R environment to use a UTF-8 locale (e.g. `Sys.setlocale('LC_ALL', 'en_US.UTF-8')`) so R emits actual Unicode instead of escape sequences.
