## Summary

Valid bug in markdown link validation for SKILL.md files ("skill" language mode). The maintainer (mjbvz) has engaged and asked for a reproduction project. The reporter clarified the issue is specific to the skill language mode. Awaiting the example project to proceed with investigation.

## Change summary

Markdown validation flags root-relative links as not found in SKILL.md files (skill language mode), while preview/navigation resolves them correctly.

## Best solution

Investigate why the markdown language service's workspace-root-relative path resolution (`getWorkspaceFolder` in `vscode-markdown-languageservice/out/util/mdLinks.js`) fails for documents in the "skill" language mode. The `prompt-basics` extension registers the skill language, and `markdown-language-features` activates for it — the validation path resolution should behave identically to regular markdown files. Likely a workspace-folder lookup issue specific to this language mode on Windows.
