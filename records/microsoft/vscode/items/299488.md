# Issue #299488 — SKILL.md language mode for markdown files flags project-root-relative links (e.g. /docs/...) as not found, while preview/navigation resolve them. Regular Markdown files don't have this problem

[https://github.com/microsoft/vscode/issues/299488](https://github.com/microsoft/vscode/issues/299488)

## Summary

The root-relative link inconsistency remains visible in current source: Skill diagnostics resolve /docs/... against the filesystem root, while Markdown preview resolves it against the containing workspace folder. Keep this open; it is an in-scope VS Code defect, not grounds for an extension redirect.

## Change summary

Make Skill document validation recognize existing workspace-root-relative Markdown links consistently with Markdown preview and navigation.

## Best solution

Skill Markdown links should use the same workspace-root interpretation as ordinary Markdown, retaining useful missing-file warnings. Preserve filesystem-absolute semantics for explicit #file references and URI links.
