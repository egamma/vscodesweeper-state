# Issue #233425 — Issue reporter fails without telling the user why if content is too large

[https://github.com/microsoft/vscode/issues/233425](https://github.com/microsoft/vscode/issues/233425)

## Summary

Still reproduces on main: the electron-sandbox issue reporter silently fails (console.error + return false) when the issue body exceeds MAX_GITHUB_API_LENGTH and there's no extension data to strip. The newer wizard path handles large content via clipboard, but the old submitToGitHub path in IssueReporter does not notify the user.

## Change summary

Issue reporter silently fails without user notification when content is too large to submit via GitHub API.

## Best solution

Add a user-visible notification (dialog or inline error message) in the `submitToGitHub` method of `IssueReporter` (electron-browser path) when the body exceeds the GitHub API limit and cannot be trimmed — instead of silently logging to console and returning false.
