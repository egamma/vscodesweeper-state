# Issue #182573 — Workspace edit createFile with overwrite deletes file completely on undo

[https://github.com/microsoft/vscode/issues/182573](https://github.com/microsoft/vscode/issues/182573)

## Summary

Still reproduces on main: `CreateOperation.perform()` in `bulkFileEdits.ts` always pushes a `DeleteEdit` as its undo, even when overwriting an existing file — so undo deletes the file entirely instead of restoring its previous content.

## Change summary

Workspace edit `createFile` with `overwrite: true` on an existing file causes undo to delete the file instead of restoring the previous version.

## Best solution

In `CreateOperation.perform()`, when `overwrite` is true and the target file already exists, read and save the existing file content before overwriting. The undo should then be a `CreateEdit` with the saved content (restoring the old file) rather than a `DeleteEdit`.
