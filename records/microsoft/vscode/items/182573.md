# Issue #182573 — Workspace edit createFile with overwrite deletes file completely on undo

[https://github.com/microsoft/vscode/issues/182573](https://github.com/microsoft/vscode/issues/182573)

## Summary

The overwrite-undo defect remains in current source: creating over an existing file records deletion as its inverse without preserving the original contents. Keep this report open as the canonical issue for that data-loss path.

## Change summary

Undoing a workspace edit that overwrites an existing file deletes the file instead of restoring its previous contents.

## Best solution

Make workspace file-edit undo restore the overwritten file's original bytes, with redo reapplying the replacement. Preserve the existing behavior where undo removes a genuinely new file.
