# Issue #126932 — Support for "related code" in tests

[https://github.com/microsoft/vscode/issues/126932](https://github.com/microsoft/vscode/issues/126932)

## Summary

Team-authored feature request with active proposed API (`testRelatedCode`) already implemented and in use by the selfhost test provider. The API still needs finalization — keeping open as the tracking issue for that work.

## Change summary

Allow test extensions to associate tests with implementation code locations (and vice versa) so users can navigate between tests and source, and run related tests from implementation code.

## Best solution

Finalize the `testRelatedCode` proposed API (currently in `src/vscode-dts/vscode.proposed.testRelatedCode.d.ts`) based on extension author feedback from Go, Java, Ruby LSP, and Python communities. The selfhost test provider in `.vscode/extensions/vscode-selfhost-test-provider` already exercises it. Once confident in the shape, move the declarations into the stable `vscode.d.ts`.
