# Issue #126932 — Support for "related code" in tests

[https://github.com/microsoft/vscode/issues/126932](https://github.com/microsoft/vscode/issues/126932)

## Summary

Keep open as an API-proposal tracking issue: related-test navigation and execution are implemented, but the API remains proposed. The maintainer also deferred finalization while considering a more general related-code navigation contract.

## Change summary

Let extensions associate tests with implementation code so users can navigate, run related tests, and potentially discover or automatically run them while editing.

## Best solution

Have the API owners resolve whether to finalize the testing-specific provider or incorporate it into a broader related-code navigation API, preserving the existing related-test execution and navigation behavior. Treat passive gutter actions and automatic reruns as additional capabilities, not as already delivered by the on-demand provider.
