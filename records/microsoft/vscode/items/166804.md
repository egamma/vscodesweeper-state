# Issue #166804 — allow filename#L<line_number> syntax to open file at specific line

[https://github.com/microsoft/vscode/issues/166804](https://github.com/microsoft/vscode/issues/166804)

## Summary

The requested syntax remains unsupported on current main, and this Backlog feature request earned the required 20 community upvotes. No open canonical issue was found, so it should remain open.

## Change summary

Allow `code --goto` to interpret a trailing GitHub-style `#L<line>` fragment as a line number.

## Best solution

Extend `parseLineAndColumnAware` to recognize the trailing GitHub line fragment while preserving existing colon syntax and filenames containing hashes, then cover both local and remote CLI paths with parser tests.
