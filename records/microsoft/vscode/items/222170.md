# Issue #222170 — Deprecated settings do not show in settings UI even when configured by the user

[https://github.com/microsoft/vscode/issues/222170](https://github.com/microsoft/vscode/issues/222170)

## Summary

Fixed on main in commit 2f30ffde1e7 (March 2025, shipped in 1.99.0): the missing `inspectSelf()` call before checking `isConfigured` meant deprecated-but-configured settings were always hidden. Current code properly inspects before filtering.

## Change summary

Deprecated settings that are configured by the user do not appear in the Settings UI because `isConfigured` was checked before calling `inspectSelf()`.

## Best solution

Keep the shipped fix; no further change needed. The current code at settingsTreeModels.ts lines 669-678 correctly calls `inspectSelf()` before checking `isConfigured` for deprecated settings.
