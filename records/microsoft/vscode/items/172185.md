# Issue #172185 — Inline suggest hover inconsistent keybinding style to other editor hovers

[https://github.com/microsoft/vscode/issues/172185](https://github.com/microsoft/vscode/issues/172185)

## Summary

The keybinding presentation still differs between the inline suggestion toolbar, suggest status bar, and other editor hovers. Keep this accepted backlog item open for a shared presentation decision; the discussion supports consistency but does not settle which style should be standard.

## Change summary

Make keybinding hints visually consistent across inline suggestion hovers and comparable editor surfaces.

## Best solution

Agree on a shared editor-action keybinding presentation, then apply it consistently to inline suggestions, the suggest status bar, and comparable hover actions. Preserve shortcut resolution and action behavior, and avoid introducing a per-surface styling setting.
