# Issue #172185 — Inline suggest hover inconsistent keybinding style to other editor hovers

[https://github.com/microsoft/vscode/issues/172185](https://github.com/microsoft/vscode/issues/172185)

## Summary

Keep open: current source still gives inline-suggestion shortcuts a different presentation from other editor hover actions. The discussion supports consistency, but the intended common presentation and scope need agreement before implementation.

## Change summary

Make shortcut presentation consistent between inline-suggestion hovers and comparable editor hover actions.

## Best solution

Agree on a shared shortcut presentation for inline-suggestion toolbars, editor hover actions, and the suggest status bar, using the existing keybinding theme styles where keycaps are intended. Preserve readable shortcut labels and existing command behavior rather than introducing per-surface styling settings.
