[https://github.com/microsoft/vscode/issues/338620](https://github.com/microsoft/vscode/issues/338620)

## Summary

Confirmed on main: the "Reveal in Explorer" label is still hardcoded in three places in requestLogTree.ts instead of using the platform-adapted REVEAL_IN_OS_LABEL pattern used elsewhere. An open PR from the reporter (#338829) already implements the fix, so this stays open pending that review rather than being closed now.

## Change summary

The Chat Debug view's log-export success notification always shows "Reveal in Explorer" instead of adapting the label per OS (Finder/File Explorer/Open Containing Folder) like the rest of the workbench.

## Best solution

Land PR https://github.com/microsoft/vscode/pull/338829 (or an equivalent fix) that mirrors REVEAL_IN_OS_LABEL's per-platform logic in requestLogTree.ts for all three hardcoded occurrences.
