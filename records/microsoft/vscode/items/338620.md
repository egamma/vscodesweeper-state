# Issue #338620 — Chat debug log export: "Reveal in Explorer" notification action is not platform-adapted

[https://github.com/microsoft/vscode/issues/338620](https://github.com/microsoft/vscode/issues/338620)

## Summary

Confirmed on main: three occurrences of a hardcoded 'Reveal in Explorer' label in extensions/copilot/src/extension/log/vscode-node/requestLogTree.ts (lines ~359, 409, 496), while the workbench already has the platform-adapted REVEAL_IN_OS_LABEL pattern for the same 'reveal in OS file manager' action. Reporter has a patch ready — this is a clean, bounded polish fix.

## Change summary

The Chat Debug view's export success notification always shows 'Reveal in Explorer' instead of adapting the label per OS (Finder on macOS, File Explorer on Windows, Open Containing Folder on Linux).

## Best solution

Mirror the REVEAL_IN_OS_LABEL platform-branching used in src/vs/workbench/contrib/files/electron-browser/fileActions.contribution.ts, using os.platform() (already imported in requestLogTree.ts) to pick the correct label string at all three call sites.
