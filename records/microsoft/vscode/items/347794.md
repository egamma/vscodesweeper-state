# Issue #347794 — Create custom instructions is not supported in the virtual file system when Copilot harness is selected.

[https://github.com/microsoft/vscode/issues/347794](https://github.com/microsoft/vscode/issues/347794)

## Summary

Keep open: current Copilot code explicitly excludes virtual workspaces from instruction discovery, so the requested capability remains missing. Supporting creation alone would not make those instructions effective; the area owner should settle the end-to-end support boundary.

## Change summary

Allow project instructions to be created and used with the Copilot harness in virtual workspaces.

## Best solution

Provide virtual-workspace instruction creation, discovery, and consumption through the editor-backed filesystem. Until that is supported, the Customizations editor should explain the limitation rather than offer a creation flow that ends with an empty-source dialog.
