# Issue #347794 — Create custom instructions is not supported in the virtual file system when Copilot harness is selected.

[https://github.com/microsoft/vscode/issues/347794](https://github.com/microsoft/vscode/issues/347794)

## Summary

Keep open: the Copilot harness explicitly omits workspace customization discovery in virtual workspaces, so this is a remaining support gap rather than an established instruction-creation capability that broke. The enabled creation action currently exposes that limitation through a generic missing-folders message.

## Change summary

Support creating and using project instructions with the Copilot harness in virtual workspaces.

## Best solution

Provide an end-to-end virtual-workspace instruction workflow covering creation, discovery, and consumption by Copilot. Until that capability is supported, the Customizations editor should explain the limitation rather than offer a creation action that leads to an unexplained dead end.
