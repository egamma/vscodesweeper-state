# Issue #150948 — False dialog text when formatters aren't registered

[https://github.com/microsoft/vscode/issues/150948](https://github.com/microsoft/vscode/issues/150948)

## Summary

The misleading formatter message remains on current main, and an open PR explicitly targets this issue. Keep it open while that implementation is reviewed; the request already has sufficient community support and belongs to the formatting backlog.

## Change summary

Make the formatting-unavailable message distinguish an unsupported unsaved document from a language with no formatter installed.

## Best solution

Review and land an accurate, actionable distinction through https://github.com/microsoft/vscode/pull/319326, preserving the install-formatter flow when no applicable formatter is installed. The message should describe document support without implying that installing the already-present formatter will help.
