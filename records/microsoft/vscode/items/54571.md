# Issue #54571 — Enhancement: finer control of word separators

[https://github.com/microsoft/vscode/issues/54571](https://github.com/microsoft/vscode/issues/54571)

## Summary

Directional word boundaries remain unsupported: current settings cannot select one adjacent LaTeX command together with its leading backslash. The older related requests describe different observable behavior, so this remains a distinct editor enhancement needing a product decision.

## Change summary

Allow word boundaries before or after a separator so double-clicking adjacent LaTeX commands selects one complete command, including its leading backslash.

## Best solution

Provide an opt-in directional-boundary capability in the editor while preserving existing word-separator defaults. Decide which word operations share those boundaries before implementing the configuration contract.
