# Issue #311404 — pwsh changes to cmd in tab title when copilot CLI launched

[https://github.com/microsoft/vscode/issues/311404](https://github.com/microsoft/vscode/issues/311404)

## Summary

Team-authored bug report about the terminal tab title incorrectly changing to 'cmd' when Copilot CLI is launched in pwsh with `allowAgentCliTitle` enabled. The feature (introduced in commit b81fc85ac33) delegates the title to OSC escape sequences from the CLI; the Copilot CLI appears to emit misleading sequences on certain setups. Not yet fixed on main.

## Change summary

Terminal tab title changes from 'pwsh' to 'cmd' (and other intermediate names) when launching the Copilot CLI with allowAgentCliTitle enabled.

## Best solution

Investigate the escape sequences emitted by the Copilot CLI on pwsh 7.6 and either filter/sanitize unexpected shell-type titles in the terminal label logic, or coordinate with the Copilot CLI to emit proper OSC 2 sequences. The fix likely lives in `src/vs/workbench/contrib/terminal/browser/terminalInstance.ts` in the `_updateTitleProperties` or label-computation path.
