# Issue #311404 — pwsh changes to cmd in tab title when copilot CLI launched

[https://github.com/microsoft/vscode/issues/311404](https://github.com/microsoft/vscode/issues/311404)

Keep open: the reporter confirmed an incorrect Windows terminal title with agent titles enabled and no custom title setting. No verified fixing commit or canonical duplicate was found, and this team-authored, accepted bug should not receive a judgment close.

## Change summary

Launching Copilot CLI from PowerShell 7.6 temporarily changes the integrated terminal tab title to cmd rather than a useful Copilot identity or session title.

## Best solution

Ensure the terminal retains a useful Copilot title while the CLI is active and restores the underlying PowerShell identity after exit. First capture the Windows process-tree and OSC-title event sequence to distinguish shell-detection changes from titles emitted by the CLI.
