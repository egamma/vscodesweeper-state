# Issue #312925 — VS Code crashes (code 5) with Remote SSH + Copilot Chat codebase indexing on M1

[https://github.com/microsoft/vscode/issues/312925](https://github.com/microsoft/vscode/issues/312925)

## Summary

A real crash (SIGSEGV / exit code 5) on macOS Apple Silicon triggered by Copilot Chat's codebase semantic indexing (WorkspaceChunkSearchService) during Remote SSH sessions, confirmed by multiple users across M1/M3. The crash path involves node:sqlite and the embeddings subsystem. No specific fix commit addressing this SIGSEGV on Apple Silicon has been found on main. Closely related to the now-closed #304692 (same trigger, closed as *not-reproducible) but this report adds the Remote SSH + Apple Silicon dimension and has 9 upvotes with ongoing confirmations through June 2026.

## Change summary

VS Code window crashes with SIGSEGV (code 5) ~40 seconds after connecting via Remote SSH when Copilot Chat's codebase semantic indexing starts, specifically on macOS Apple Silicon.

## Best solution

Investigate the SIGSEGV in the WorkspaceChunkSearchService / node:sqlite embeddings path on macOS ARM64 during Remote SSH sessions. The crash likely originates in the native SQLite bindings or the embeddings computation (metis-1024-I16-Binary) under the extension host. The area owner (chat-codebase / copilot) should capture a native crash report to identify the exact fault address, and consider whether the node:sqlite experimental feature is stable enough on Apple Silicon in the remote extension host context, or whether a fallback/guard is needed.

- **workaround confirmed:** Disabling Copilot Chat entirely (--disable-extension GitHub.copilot-chat) prevents the crash; commenter ayspunde confirmed stability with Copilot Chat 0.35.3 (crash starts with 0.40+).
