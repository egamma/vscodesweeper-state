# Issue #341724 — Chats created before upgrading from 1.141.2 to 1.142.0 close immediately

[https://github.com/microsoft/vscode/issues/341724](https://github.com/microsoft/vscode/issues/341724)

## Summary

Keep open as a confirmed release regression: another user reports the same failure, and the reporter can open the same conversation in 1.141.2. The supplied upgrade comparison is sufficient to investigate; source inspection does not establish a current fix or prove that the related disappearance reports have the same cause.

## Change summary

Previously created chats close immediately and disappear from the sessions list after upgrading to 1.142.0.

## Best solution

Preserve and successfully reopen existing local conversations across upgrades, with an actionable error rather than silent disappearance if restoration fails. Investigate session acquisition and local session-list updates together, distinguishing actual archival from filtering or removal.
