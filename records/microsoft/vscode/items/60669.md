# Issue #60669 — `extensions/extension-editing/src/extensionLinter.ts` does not respect `repository` shorthand in package.json

[https://github.com/microsoft/vscode/issues/60669](https://github.com/microsoft/vscode/issues/60669)

## Summary

Still reproduces on main: the linter only checks `['repository', 'url']` (object form) and ignores string shorthand like `"github:user/repo"`. An open PR (#318073) is attempting to fix this.

## Change summary

The extension linter warns about relative image URLs even when package.json uses a valid npm repository shorthand string (e.g. `"repository": "github:user/repo"`).

## Best solution

Land https://github.com/microsoft/vscode/pull/318073 (or equivalent) which adds parsing for npm repository shorthand strings in extensionLinter.ts. The fix is small and localized to `readPackageJsonInfo`.
