# Issue #164329 — Jump to first error when clicking on error number in tab

[https://github.com/microsoft/vscode/issues/164329](https://github.com/microsoft/vscode/issues/164329)

## Summary

The requested mouse interaction remains absent on current main, and this accepted Backlog request has 22 community upvotes. It should remain open for implementation.

## Change summary

Make an editor tab's diagnostic-count badge navigate to the file's first problem when clicked.

## Best solution

Give the diagnostic badge a distinct, accessible click action that opens the affected editor and invokes marker navigation, without disrupting normal tab selection, multi-selection, or dragging.
