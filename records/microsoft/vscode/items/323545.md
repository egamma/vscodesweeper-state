# Issue #323545 — no idea how to get a session back after marking it done

[https://github.com/microsoft/vscode/issues/323545](https://github.com/microsoft/vscode/issues/323545)

## Summary

Keep open for session-recovery discoverability: current main has Show Done and Restore, but title search still excludes sessions hidden by the archive filter. This team-authored report cannot be closed as designed, and neither an issue-referencing fix nor a verified duplicate was established.

## Change summary

Make it clear where a session goes after Mark as Done and how to find and restore it.
