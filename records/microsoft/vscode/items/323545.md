# Issue #323545 — no idea how to get a session back after marking it done

[https://github.com/microsoft/vscode/issues/323545](https://github.com/microsoft/vscode/issues/323545)

## Summary

Valid UX discoverability issue: marking a session as "Done" (archiving) hides it from the list, and the mechanism to show it again (the "Done" filter toggle in the sessions view filter toolbar) is hard to discover. Search also doesn't surface archived sessions when the filter excludes them. Keeping open as a polish item for the Agents window.

## Change summary

After marking a session as done in the Agents window, users cannot find it again because the "Done" filter is off by default and search respects the filter exclusion.

## Best solution

Improve discoverability of archived/done sessions: either make search always include archived sessions regardless of filter state, show a hint or banner after archiving ("Session marked done — show done sessions"), or surface the "Done" filter toggle more prominently. The relevant filtering logic is in `src/vs/sessions/contrib/sessions/browser/views/sessionsList.ts` (the `_excludeArchived` path) and the filter registration is in `src/vs/sessions/contrib/sessions/browser/views/sessionsView.ts`.
