# Issue #220071 — Multi Diff Editor: Add folding behaviour options

[https://github.com/microsoft/vscode/issues/220071](https://github.com/microsoft/vscode/issues/220071)

## Summary

Keep open: current multi-diff controls provide manual folding, but neither automatic collapse for multi-file commits nor accordion-style expansion. The existing area label and Backlog milestone remain appropriate; no verified canonical owns both requested behaviors.

## Change summary

Offer automatic initial collapse when a multi-diff contains multiple files and optional accordion folding that collapses other files when one expands.

## Best solution

Support opt-in folding policies in the shared multi-diff editor, including the SCM graph commit-review flow, while preserving current behavior by default. Before implementation, settle how those policies interact with restored folding state and explicit Expand All.
