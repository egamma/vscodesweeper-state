# Issue #284880 — explorer file nesting broken with icon themes using `hidesExplorerArrows`

[https://github.com/microsoft/vscode/issues/284880](https://github.com/microsoft/vscode/issues/284880)

## Summary

The defect remains in current main: nested-file twisties are still modified through a late DOM query, so icon themes that hide Explorer arrows can lose the expand/collapse indicator until another render. The linked fix PR was closed without merging.

## Change summary

File-nesting chevrons disappear or become misaligned after expanding or collapsing a nest when the active file icon theme sets `hidesExplorerArrows`.

## Best solution

Make the Explorer tree assign the nested-file twistie class as part of normal tree rendering, preserving visible expand/collapse controls under themes that hide ordinary Explorer arrows.
