# Issue #350431 — Timeline : entries from before a file rename are listed but cannot be opened ("Unable to resolve nonexistent file")

[https://github.com/microsoft/vscode/issues/350431](https://github.com/microsoft/vscode/issues/350431)

## Summary

This is a verified duplicate of the open Git Timeline rename-history bug. The supplied reproduction and historical-path diagnosis add useful evidence to that existing report.

## Change summary

Git Timeline lists pre-rename commits but cannot open their diffs because it resolves the current filename at historical revisions.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/205244 and make Timeline comparisons resolve each revision's historical path, including comparisons across the rename itself.
