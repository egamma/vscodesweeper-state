# Issue #280623 — Github MCP server: Changing settings does not directly update tools

[https://github.com/microsoft/vscode/issues/280623](https://github.com/microsoft/vscode/issues/280623)

## Summary

Keep open: current source still alphabetically mixes “Update Tools” into cached tool entries, matching the maintainer-confirmed picker bug. Automatic refresh is intentionally deferred for performance; that distinction does not resolve the remaining presentation issue or justify closing this team-authored report.

## Change summary

Make the Configure Tools picker clearly represent outdated GitHub MCP tools after configuration changes, without burying the refresh action among cached tools.

## Best solution

Present the refresh action distinctly from tool entries while preserving the maintainer-established lazy server-start behavior. Settle whether outdated tools remain visible with a clear stale state or are withheld until refreshed.
