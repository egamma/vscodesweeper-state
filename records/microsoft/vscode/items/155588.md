# Issue #155588 — Add a setting to let CJK font width == 2 * ASCII font width

[https://github.com/microsoft/vscode/issues/155588](https://github.com/microsoft/vscode/issues/155588)

## Summary

Keep this accepted Backlog request open: it exceeded the community threshold with 41 upvotes, and current VS Code still lacks the requested grid-based CJK width mode.

## Change summary

Add an optional editor rendering mode that gives CJK characters exactly twice the width of ASCII characters.

## Best solution

Retain this as the canonical backlog request while the editor team evaluates whether a grid-width mode can coexist safely with Chromium text shaping, bidirectional text, and complex scripts. Compatible fonts such as Sarasa Fixed SC remain a workaround, not complete coverage.
