Deleting an isolated session now records durable worktree cleanup and schedules its removal, so the reported missing deletion path is covered on current main. Propose closing as completed.

## Change summary

Deleting a session should clean up its managed Git worktree rather than leave it orphaned on disk.

## Best solution

Keep the implemented background cleanup lifecycle: session deletion durably requests worktree removal, failures are retried, branches are preserved, and worktrees still used by another live session are retained.
