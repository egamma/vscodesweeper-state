# Issue #186961 — Locale independent keybindings (character instead of physical key)

[https://github.com/microsoft/vscode/issues/186961](https://github.com/microsoft/vscode/issues/186961)

## Summary

Valid feature request promoted to Backlog with 24 upvotes. No implementation exists on main — VS Code's keybinding system still dispatches on physical scan codes with no opt-in character-based mode. Stays open as an accepted backlog item.

## Change summary

Allow keybindings to bind to characters (locale-independent) rather than physical keys, so extensions like Vim emulators can define bindings that work correctly across keyboard layouts.

## Best solution

Add an opt-in character-based keybinding dispatch mode (likely in the keybinding resolver and schema) so extensions can declare bindings that map to produced characters rather than scan codes. This would live in the keybinding platform layer (`src/vs/platform/keybinding/`) and the workbench keybinding service.
