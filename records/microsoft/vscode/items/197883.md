## Evidence

- **reported trigger:** https://github.com/microsoft/vscode/issues/197883 reports that setting scm.diffDecorationsGutterWidth to 5 and clicking a decoration's rightmost or topmost visible edge does not open the gutter popup; the report includes a GIF and says it occurs with extensions disabled.
- **current source:** src/vs/workbench/contrib/scm/browser/quickDiffWidget.ts:680-713, QuickDiffEditorController.onEditorMouseDown, rejects gutterOffsetX outside [-3, 3] before recording mouseDownInfo. This fixed boundary does not consult scm.diffDecorationsGutterWidth. The same file's hover styling renders a 6px-wide pseudo-element at left: -6px. This source inspection supports the horizontal hit-area mismatch; no interactive reproduction was run, and the top-edge behavior was not independently established.
- **confirmed related report:** https://github.com/microsoft/vscode/issues/214541 reports the same difficulty clicking the inline diff decoration on Windows in VS Code 1.90.0. A maintainer confirmed the behavior in older builds and said it should be fixed: https://github.com/microsoft/vscode/issues/214541#issuecomment-2180035144.
- **canonical ownership:** The related issue is closed as a duplicate of this report, explicitly stated at https://github.com/microsoft/vscode/issues/214541#issuecomment-2531438953. It is newer than this re-reviewed issue and cannot be used as a duplicate target. A search for open gutter-click/diff reports did not establish an older canonical owning this same symptom.
- **open implementation candidate:** https://github.com/microsoft/vscode/pull/214554 is currently OPEN and its body explicitly includes Fix #197883 and Fix #214541. Its diff changes line-decoration rendering and folding interaction, and removes the fixed coordinate rejection in QuickDiffEditorController.onEditorMouseDown. These changes are not present in the inspected checkout, so this is pending implementation rather than a completed fix.
- **maintainer direction:** The project has accepted the direction of improving this interaction: https://github.com/microsoft/vscode/pull/214554#issuecomment-2199612889 approves the proposed changes, and https://github.com/microsoft/vscode/pull/214554#issuecomment-3448588990 requests review and merge if appropriate.
