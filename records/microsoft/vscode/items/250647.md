# Issue #250647 — SCM - "Show Opened Editors" not change position

[https://github.com/microsoft/vscode/issues/250647](https://github.com/microsoft/vscode/issues/250647)

## Summary

Still reproduces on main. The git extension registers Stage/Unstage in group `2_git` on `MenuId.EditorTitle`, which sorts above the core "Show Opened Editors" in group `3_open`, causing the menu to shift when git items appear. This is a polish issue — the menu ordering is working as coded, but the inconsistent top item is a UX friction worth addressing.

## Change summary

The editor title ellipsis menu shifts "Show Opened Editors" down when git Stage/Unstage items appear, because the git group (`2_git`) sorts above the core group (`3_open`).

## Best solution

Renumber the git extension's `editor/title` menu group from `2_git` to `4_git` (or similar) in `extensions/git/package.json` so that the always-present core items (`3_open`, `1_diff`) stay above context-dependent SCM actions. Alternatively, move "Show Opened Editors" to a lower-numbered group. The fix is in `extensions/git/package.json` lines ~2788–2821.
