# Issue #50140 — Support syntax highlighting with tree-sitter

[https://github.com/microsoft/vscode/issues/50140](https://github.com/microsoft/vscode/issues/50140)

## Summary

Tree-sitter support is actively being implemented in VS Code behind experimental settings (`editor.experimental.preferTreeSitter.*`) for CSS, TypeScript, INI, and regex — but it is not yet general-purpose or stable. This high-signal feature request (738 upvotes) remains the canonical tracker and should stay open until the feature graduates from experimental.

## Change summary

Support tree-sitter grammars for syntax highlighting as an alternative to TextMate grammars.

## Best solution

Continue the ongoing tree-sitter integration work in `src/vs/editor/common/model/tokens/treeSitter/` and `src/vs/workbench/services/treeSitter/browser/`. The feature is behind experimental flags and covers only a few languages; the issue should remain open as the canonical tracker until tree-sitter tokenization is stable and broadly available.
