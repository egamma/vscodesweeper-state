# Issue #341195 — Chat workspace-change confirmation drops Windows path separators before dot-prefixed folders

[https://github.com/microsoft/vscode/issues/341195](https://github.com/microsoft/vscode/issues/341195)

## Summary

Thanks for the detailed report. The path is interpolated raw into the confirmation message in sessionServerTools.ts. A likely cause is that the message is rendered as markdown, where `\.` is an escape and drops the backslash. I could not run it to confirm.

## Change summary

The Change Workspace confirmation drops the backslash before dot-prefixed folders in Windows paths, although the actual destination is correct.

## Best solution

Render the workspace path in the confirmation as a code span, or escape markdown syntax in it, so the exact path is displayed. Do this in the SetWorkspace display metadata in sessionServerTools.ts.
