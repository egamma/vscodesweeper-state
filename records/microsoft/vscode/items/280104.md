Still reproduces on main: line 91 of baseTerminalBackend.ts hardcodes `Schemas.file` when resolving the workspace root for variable substitution, which fails for remote workspaces where the URI scheme is `vscode-remote`. An open PR (#280106) from the author addresses this but has not merged.
