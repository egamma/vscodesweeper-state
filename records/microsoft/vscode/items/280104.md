[https://github.com/microsoft/vscode/issues/280104](https://github.com/microsoft/vscode/issues/280104)

## Summary

Confirmed bug: `Schemas.file` is hardcoded in `baseTerminalBackend.ts` line 91, so `${workspaceFolder}` resolution fails for remote workspaces. An open PR (#280106) from the author addresses this — keeping open until it lands.

## Change summary

Terminal profiles using `${workspaceFolder}` fail to resolve in remote workspaces (dev containers, VS Code Server) because the variable resolver is hardcoded to `Schemas.file` URIs.

## Best solution

Land the author's open PR https://github.com/microsoft/vscode/pull/280106, which should fix the `Schemas.file` filter in `baseTerminalBackend.ts` to also accept remote workspace URIs. The fix is small and localized to the variable resolution listener.
