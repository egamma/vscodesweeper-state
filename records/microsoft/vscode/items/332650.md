# Issue #332650 — Extend notification service to support promos and chat tips

[https://github.com/microsoft/vscode/issues/332650](https://github.com/microsoft/vscode/issues/332650)

## Summary

Keep open and classify as a feature request. Current main confirms that chat promos, quota notices, and tips bypass the workbench notification filters, and this team-authored proposal has no referenced implementation or verified duplicate.

## Change summary

Unify workbench and chat notification controls so global Do Not Disturb and source/type muting apply to promos, usage banners, and tips without changing their in-chat presentation or dismissal behavior.

## Best solution

Establish a shared notification-source contract for non-toast surfaces, then have chat promos, usage notices, and tips participate in global and per-source filtering while retaining their current placement, session scope, and persisted dismissal semantics. Settle source granularity, quota severity behavior, and preference migration before implementation; treat the unspecified visual modernization as a separately bounded decision.
