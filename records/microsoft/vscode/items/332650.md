# Issue #332650 — Extend notification service to support promos and chat tips

[https://github.com/microsoft/vscode/issues/332650](https://github.com/microsoft/vscode/issues/332650)

## Summary

Team-authored architectural proposal to unify chat promo/quota/tip notifications with the workbench notification service's DND and per-source mute controls; verified the described separate mechanisms (ChatPromoNotificationContribution, ChatQuotaNotificationContribution, IChatTipService, IChatInputNotificationService) exist as distinct code paths on main with no unification yet, so this is a real, unimplemented gap that should stay open for design/maintainer scoping.

## Change summary

Unify chat promo, quota/usage, and tip notification surfaces into the same INotificationService control plane (DND, per-source mute) that extension toasts already use.

## Best solution

Design a shared notification-source abstraction so chatPromoNotification.ts, chatQuotaNotification.ts, and chatTipService.ts register as INotificationService sources while retaining in-chat placement and session-scoped dismiss semantics; this is a multi-surface architecture change that needs maintainer design input before implementation, likely spanning src/vs/workbench/contrib/chat/browser/chatPromoNotification.ts, chatQuotaNotification.ts, chatTipService.ts, and src/vs/workbench/services/notification.
