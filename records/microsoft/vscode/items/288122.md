# Issue #288122 — Session Initializing… message won't dissappear from VSC UI for abandoned job

[https://github.com/microsoft/vscode/issues/288122](https://github.com/microsoft/vscode/issues/288122)

## Summary

Still present on main: when a cloud agent session's PR is closed but the backend still reports state as `in_progress` or `queued`, the UI shows a permanent 'Session is initializing...' placeholder with no way to dismiss it. No fix commit references this issue.

## Change summary

The 'Session Initializing…' message persists in the Copilot Chat Sessions UI for cloud agent sessions whose associated PR was closed/abandoned.

## Best solution

The session content builder in `copilotCloudSessionContentBuilder.ts` should handle the case where a session is abandoned (PR closed) — either by polling for updated state from the backend that reflects the PR closure, or by providing a dismiss/remove action in the UI for stuck sessions.
