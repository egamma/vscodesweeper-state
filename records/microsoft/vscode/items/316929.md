# Issue #316929 — Copilot Chat: chat session deletion is intermittent

[https://github.com/microsoft/vscode/issues/316929](https://github.com/microsoft/vscode/issues/316929)

## Summary

The intermittent deletion failure needs an identifiable failing case: the report does not distinguish session providers, the deletion control used, or conditions separating successful and unsuccessful attempts. The Claude comment describes unavailable permanent deletion rather than confirming the reported intermittent failure.

## Change summary

Deleting a Copilot Chat session sometimes leaves it visible in the session list.

## Best solution

Identify a failing session provider and deletion path, then ensure successful deletion consistently removes the session from history and the list. Distinguish an actual Delete failure from Archive behavior or a provider that does not expose deletion.
