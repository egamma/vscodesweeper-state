[https://github.com/microsoft/vscode/issues/154102](https://github.com/microsoft/vscode/issues/154102)

## Summary

Keep open: the discussion confirms that touching the editor fails to reclaim input after typing in another iPad multitasking app. No verified fix or older canonical covering that same symptom was found; current-device diagnosis is still needed.

## Change summary

Restore editor input focus when returning by touch from another app in iPadOS Split View or Slide Over.

## Best solution

Make tapping the existing editor reliably reclaim keyboard input without reopening the document or dismissing the other app. Diagnose the editor touch-to-textarea focus path on current iPadOS before deciding whether the failure is in VS Code focus bookkeeping or browser/OS focus delivery.
