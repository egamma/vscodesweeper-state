# Issue #138323 — Move telemetry cleansing into shared process

[https://github.com/microsoft/vscode/issues/138323](https://github.com/microsoft/vscode/issues/138323)

## Summary

The architectural debt remains on current main: renderer telemetry is still cleansed before IPC, while the shared-process channel only forwards already-formed data to its appenders. The On Deck milestone and existing debt classification also represent accepted work, so this should remain open.

## Change summary

Move telemetry PII cleansing from producer processes into the shared process to reduce renderer startup cost and centralize sanitization.

## Best solution

Centralize cleansing at the shared-process telemetry boundary while preserving process-specific common properties, PII paths, trusted-value semantics, telemetry levels, and cleansing for telemetry produced outside the renderer.
