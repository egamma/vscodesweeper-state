# Issue #138323 — Move telemetry cleansing into shared process

[https://github.com/microsoft/vscode/issues/138323](https://github.com/microsoft/vscode/issues/138323)

## Summary

Team-authored tech-debt issue requesting that telemetry PII cleansing be moved from the renderer to the shared process. The core request remains unimplemented — cleanData still runs in-process in the renderer — though PR #164815 mitigated the worst perf impact with a fast-path optimization. Keeping open per team-authored policy.

## Change summary

Move regex-based telemetry PII cleansing from the renderer process to the shared process to eliminate its impact on renderer startup performance.

## Best solution

Refactor so that `cleanData` (src/vs/platform/telemetry/common/telemetryService.ts:216) and `removePropertiesWithPossibleUserInfo` (src/vs/platform/telemetry/common/telemetryUtils.ts:400) run in the shared process rather than the renderer. The `TelemetryService` in the renderer would send uncleansed data over IPC to the shared process, which would apply the regex scrubbing before forwarding to App Insights. This requires extracting the cleanup-pattern configuration (piiPaths, etc.) so it can be transmitted or reconstructed in the shared process.
