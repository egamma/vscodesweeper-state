# Issue #138323 — Move telemetry cleansing into shared process

[https://github.com/microsoft/vscode/issues/138323](https://github.com/microsoft/vscode/issues/138323)

## Summary

The telemetry cleansing (`cleanData` with regex anonymization) still runs in the renderer process before IPC to the shared process. The architectural move requested here has not been done — only a mitigation (PR #164815, quick-check optimization) landed. The debt remains valid.

## Change summary

Move telemetry data cleansing (PII regex scrubbing) from the renderer process into the shared process to avoid impacting startup performance.

## Best solution

Refactor the `TelemetryService` so that `cleanData` and its regex-based anonymization run in the shared process (after the IPC boundary) rather than in the renderer. The `piiPaths` and cleanup patterns would need to be transmitted alongside telemetry events. This is a meaningful perf-debt item that still has value, though PR #164815's quick-check optimization reduced urgency.
