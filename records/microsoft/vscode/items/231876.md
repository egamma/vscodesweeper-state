# Issue #231876 — Multiline cursor using ALT-Up and Down on number pad causes character to display after releasing keys

## Summary

Verified duplicate of issue #22364 — Alt + numpad keybindings inserting characters is a long-standing known issue tracked there since 2017. This report describes the same root cause (Windows Alt-code input triggered by numpad keys) in the specific multicursor scenario.

## Change summary

Using Alt+Up/Down on the numpad to create multiline cursors inserts spurious characters when the keys are released, due to Windows Alt-code input interception.
