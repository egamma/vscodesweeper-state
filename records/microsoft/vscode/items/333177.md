# Issue #333177 — Stop on an agent host turn can immediately restart the same turn

[https://github.com/microsoft/vscode/issues/333177](https://github.com/microsoft/vscode/issues/333177)

## Summary

Team-authored bug report with a clear, source-traced race condition and no fix landed yet; hard keep-open rule for team-authored items applies regardless of staleness or judgment.

## Change summary

Pressing Stop on a stuck agent-host turn can immediately re-adopt the same turn as a server-initiated request because the client-dispatched turn id is deleted before the cancellation round-trip completes.

## Best solution

Fix in src/vs/workbench/contrib/chat/browser/agentSessions/agentHost/agentHostSessionHandler.ts: either set `lastSeenTurnId` at dispatch time in `_handleTurn` (as suggested in the author's own follow-up comment), or defer removal from `_clientDispatchedTurnIds` until the host reports a terminal state instead of on cancel.
