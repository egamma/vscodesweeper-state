# Issue #334895 — Agent merge - icon in the disablement message is not vertically centered

[https://github.com/microsoft/vscode/issues/334895](https://github.com/microsoft/vscode/issues/334895)

## Summary

Fresh, credible visual bug from a team member testing the new Agent Merge disablement flow (PR #334491) — the screenshot clearly shows the disablement icon sitting higher than the message text instead of vertically centered on it; the code path is traceable but the exact fix needs verification against a rendered build.

## Change summary

In the chat 'Agent Merge was disabled for this session' notification, the leading icon is not vertically centered against the single-line message text.

## Best solution

Adjust the vertical alignment rule for `.interactive-item-container .progress-container` (src/vs/workbench/contrib/chat/browser/widget/media/chat.css) and/or the icon element built in `ChatProgressSubPart` (src/vs/workbench/contrib/chat/browser/widget/chatContentParts/chatProgressContentPart.ts) so a short single-line notice centers the icon on the text while still keeping the icon pinned to the first line for messages that wrap — then validate visually via the existing `chatAgentMergeFlow` component fixture (src/vs/workbench/test/browser/componentFixtures/chat/chatAgentMergeFlow.fixture.ts).
