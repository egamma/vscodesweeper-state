# Issue #312289 — chat/subagent: Provide API to control default expanded state of subagent content parts

[https://github.com/microsoft/vscode/issues/312289](https://github.com/microsoft/vscode/issues/312289)

## Summary

The requested API remains absent on current main: extension-provided subagent data cannot specify initial expansion, and the inline renderer explicitly starts every subagent collapsed. This is a valid proposed-API request that should be routed to the chat subagent and API owners for contract design.

## Change summary

Add an extension API option that lets a subagent content part start expanded so its live activity is immediately visible.

## Best solution

Add an opt-in initial-expansion hint to the proposed chat API, preserving collapsed-by-default behavior and yielding to subsequent user toggles and confirmation-driven expansion. The API owners should define how that hint applies to restored responses and the rich presentation that opens subagents in separate editors.
