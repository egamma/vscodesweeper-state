# Issue #168885 — ability to open vscode from `code` command line that focuses integrated terminal

[https://github.com/microsoft/vscode/issues/168885](https://github.com/microsoft/vscode/issues/168885)

## Summary

A real capability gap remains: the CLI opens and focuses the requested editor without an option to preserve integrated-terminal focus. With 34 upvotes and promotion to the Backlog, this should remain open.

## Change summary

Add an opt-in way for `code <file>` to reveal a file while retaining focus in the integrated terminal.

## Best solution

Add a CLI preserve-focus option and propagate it through the native open-file request into the editor options, leaving existing CLI focus behavior unchanged by default.
