# Issue #289879 — Chat took too long to get ready

[https://github.com/microsoft/vscode/issues/289879](https://github.com/microsoft/vscode/issues/289879)

## Summary

The logs show a network connectivity failure — `ConnectTimeoutError` to `api.githubcopilot.com:443` from the remote GCP VM over SSH. This is a transient environment/network issue, not a VS Code defect.

## Change summary

Copilot Chat was slow to initialize because the remote SSH host could not reach the Copilot API endpoint within the 10-second timeout.

## Best solution

No product change needed. The reporter's remote GCP VM had a network path issue reaching `api.githubcopilot.com:443`. The reporter should verify outbound HTTPS connectivity from the remote host (firewall rules, proxy settings, DNS resolution) and retry.
