# Issue #341057 — Discover page should only show matches from the sources

[https://github.com/microsoft/vscode/issues/341057](https://github.com/microsoft/vscode/issues/341057)

## Summary

Thanks for the testing feedback. The Discover page's text search merges every locally installed customization, including ones that did not come from a marketplace source, with the catalog results. Your own instructions therefore show up when searching 'test'. This is a clear, still-valid refinement of a new feature.

## Change summary

Discover search shows the user's own local instructions and other customizations that are not from any enabled marketplace source; it should show only source matches, tagging installed ones.

## Best solution

Limit the installed entries merged into Discover results to items whose catalogResource matches an enabled source, and show them with an Installed tag and the Uninstall button. Locally authored items stay on their own management pages.
