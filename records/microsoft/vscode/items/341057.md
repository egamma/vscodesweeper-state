# Issue #341057 — Discover page should only show matches from the sources

[https://github.com/microsoft/vscode/issues/341057](https://github.com/microsoft/vscode/issues/341057)

## Summary

Keep open to settle whether Discover searches only published sources or also acts as a unified entry point for installed customizations. Current source filters installed items when a particular source is selected, but All Sources still includes unrelated local items, so the original request is only partially addressed.

## Change summary

Restrict Discover results to enabled catalog sources while retaining installation indicators and uninstall controls for matching installed entries.

## Best solution

Resolve the intended scope of All Sources with the participants in https://github.com/microsoft/vscode/pull/342584, including the proposed removal of search fields from other pages. Make Discover's filtering and installed-item presentation consistently follow that decision without losing a way to find local instructions.
