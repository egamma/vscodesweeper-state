# Issue #341057 — Discover page should only show matches from the sources

[https://github.com/microsoft/vscode/issues/341057](https://github.com/microsoft/vscode/issues/341057)

## Summary

Source-specific filtering has landed, but All Sources still includes personal customizations. Keep this team-authored request open for the unresolved Discover-versus-management search decision.

## Change summary

Restrict Discover search to enabled catalog sources, retaining installed catalog matches with installation status and uninstall actions.

## Best solution

Resolve whether Discover should exclusively search published catalog items or remain a combined discovery-and-management search. Source-specific filtering already exists; the remaining decision concerns personal items under All Sources and their search home.
