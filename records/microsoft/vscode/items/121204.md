# Issue #121204 — Add a `modifier` flag to the `onDidAccept` event of quick picks

[https://github.com/microsoft/vscode/issues/121204](https://github.com/microsoft/vscode/issues/121204)

## Summary

Keep open: extension quick picks still cannot expose acceptance modifiers, although core pickers have that information. No verified canonical issue or shipped implementation covers the request.

## Change summary

Expose the modifier keys held when an extension quick pick is accepted so consumers can choose alternate actions.

## Best solution

Have the quick-pick API owners evaluate a backward-compatible acceptance-modifier contract, including cross-platform Ctrl/Cmd semantics. If accepted, extension consumers should receive the modifier state associated with acceptance rather than infer it from unrelated keyboard commands.
