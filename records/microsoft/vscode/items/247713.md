## Summary

The action widget separator still carries `margin: 4px 6px` with `width: calc(100% - 12px)` (line 86–87 of actionWidget.css), and the hover color uses `--vscode-list-hoverBackground` which may still differ from the context menu's selection color. ## Change summary

Align the action widget, NES control, and custom context menu so separators stretch full-width, hover/active background colors match, and keybinding rendering is consistent — ideally sharing a single underlying widget.

## Best solution

Continue the incremental CSS alignment already underway: make the action widget separator full-width (remove the 6px horizontal margin), unify the hover/focus background color with the context menu's selection color, and verify keybinding rendering consistency. The longer-term goal of a single shared menu widget (discussed in comments 14–15, 21–22) would prevent future drift but is a larger effort.
