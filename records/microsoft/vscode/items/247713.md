- **Validation:** Compare a custom editor context menu, a grouped action widget, and an NES gutter menu in the running application. Verify matching separator spans, equivalent hover/selection colors, and lightweight platform-appropriate shortcut labels in light, dark, and high-contrast themes; check keyboard navigation and action invocation remain unchanged. Establish repeatable screenshot or browser checks for these comparisons before implementation.
- **Behavior:**

  > Equivalent rows and separators in custom context menus, action widgets, and NES menus should follow the same visual conventions. Separators should span the menu surface consistently, hover/selection treatments should not diverge accidentally, and shortcut labels should retain macOS symbols and appropriate Windows formatting. Native OS menus are not the reference surface. Acceptance must compare all three surfaces and preserve keyboard navigation, action invocation, section headings, and footer actions.
- **Trace:**

  > Current actionWidget.css still insets separators through outer padding and separator-specific horizontal margins, while custom-menu separator rules in menu.ts span the full width. NES hoverContent() in gutterIndicatorMenu.ts wraps its separator nodes in a margin: 4 container; NES active rows in view.css use editorActionList focus tokens that default to active-selection colors, whereas defaultMenuStyles and action widgets use list-hover colors. ActionList already uses getLabel() for supplied shortcuts, while NES retains a separately styled KeybindingLabel, so do not assume shortcut work is wholly absent. https://github.com/microsoft/vscode/pull/265813 predates the reopen, and https://github.com/microsoft/vscode/pull/283047 addresses only action-widget styling. The maintainer-supported boundary in https://github.com/microsoft/vscode/issues/247713#issuecomment-3355532980 permits style alignment without a shared-widget rewrite. The remaining uncertainty is how to verify the complete visual result across themes and input modalities; source inspection alone does not supply that acceptance check.
