# Issue #247713 — Custom actions control, NES control and context menu alignment

[https://github.com/microsoft/vscode/issues/247713](https://github.com/microsoft/vscode/issues/247713)

## Summary

A real alignment gap remains on current main: hover colors and keybinding labels have largely converged, but action-widget separators are again inset rather than full width. The accepted On Deck debt should remain open until the original checklist is verified across the custom context menu, action widget, and NES surfaces.

## Change summary

Align keybinding presentation, focused-item styling, and separators across custom context menus, action widgets, and the NES menu.

## Best solution

Make the three surfaces consume the same menu presentation contract for keybinding labels, hover/focus colors, and separator geometry, while preserving their distinct interaction semantics. Cover the contract with a focused browser test or component fixture so later widget styling cannot reintroduce the drift.
