# Issue #330586 — [Windows] `network.meteredConnection: auto` ignores `NetworkCostType.Fixed`

[https://github.com/microsoft/vscode/issues/330586](https://github.com/microsoft/vscode/issues/330586)

## Summary

Well-diagnosed gap: VS Code's `auto` metered-detection relies entirely on Chromium's Network Information API (`getIsBrowserConnectionMetered` in meteredConnection.ts), which doesn't surface Windows' native `NetworkCostType.Fixed` state — confirmed by reading current main, with no fix present and no open canonical issue tracking it.

## Change summary

On Windows, `network.meteredConnection: auto` fails to detect a connection Windows itself reports as metered (`NetworkCostType.Fixed`), so the metered indicator doesn't show and background updates download anyway.

## Best solution

Add a native Windows detection path (e.g. via the electron-main metered connection service in src/vs/platform/meteredConnection/electron-main/meteredConnectionMainService.ts) that queries the WinRT `NetworkInformation.GetConnectionCost()` API and feeds the result into `isConnectionMetered`, since Chromium's `navigator.connection` alone cannot expose `NetworkCostType.Fixed` on this system.
