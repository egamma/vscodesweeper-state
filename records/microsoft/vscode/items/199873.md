# Issue #199873 — "Reveal in File Explorer" not working after opening file with incomplete path via Ctrl+P

[https://github.com/microsoft/vscode/issues/199873](https://github.com/microsoft/vscode/issues/199873)

## Summary

The Windows-specific defect remains source-reproducible on current main: Quick Open accepts a root-relative path as absolute but preserves a drive-less file URI, which later gives Electron's reveal API a non-fully-qualified path.

## Change summary

Opening a Windows file through Ctrl+P with a root-relative path such as `\bug\file` creates an editor resource that cannot be revealed in File Explorer.

## Best solution

Preserve support for the successfully resolved root-relative Quick Open result, but ensure its editor resource is canonical and drive-qualified so subsequent file operations, including Reveal in File Explorer, address the same file.
