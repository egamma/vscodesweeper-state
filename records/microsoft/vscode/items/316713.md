# Issue #316713 — Shell integration cannot be enabled for executable "/app/bin/host-spawn" and args undefined

[https://github.com/microsoft/vscode/issues/316713](https://github.com/microsoft/vscode/issues/316713)

## Summary

Valid request: shell integration injection determines the shell type from `path.basename(executable)`, which doesn't recognize wrapper executables like `host-spawn` or `flatpak-spawn`. An open PR (#316714) already proposes a fix by adding `shellType` to terminal profiles and auto-detecting these wrappers — keeping open for that PR to land.

## Change summary

Shell integration cannot inject when the terminal profile executable is a wrapper like `host-spawn` or `flatpak-spawn` rather than a recognized shell binary.

## Best solution

Land PR https://github.com/microsoft/vscode/pull/316714 (or an equivalent approach) that lets `getShellIntegrationInjection` in `src/vs/platform/terminal/node/terminalEnvironment.ts` resolve the actual shell type through the wrapper's args or via an explicit `shellType` profile property. The fix belongs in the terminal platform layer.
