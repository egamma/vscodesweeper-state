# Issue #312728 — Integrated Browser: DevTools dock position is not persisted

[https://github.com/microsoft/vscode/issues/312728](https://github.com/microsoft/vscode/issues/312728)

## Summary

Confirmed in source: `toggleDevTools()` in `browserView.ts` delegates to Electron's bare `webContents.toggleDevTools()` with no mode argument and no persistence logic — the dock position is lost every time. A commenter reports this as a regression. The issue is real, properly labeled, and needs a fix.

## Change summary

Integrated Browser DevTools always reopen as a floating window because the dock position chosen by the user is never persisted or restored.

## Best solution

Replace the bare `webContents.toggleDevTools()` call with `openDevTools({mode})` using a persisted dock mode. Store the last-used dock position (e.g. via `IStorageService` or a `workbench.browser.devTools.defaultDockSide` setting) and restore it on re-open. The main files are `src/vs/platform/browserView/electron-main/browserView.ts` (the `toggleDevTools` method) and `src/vs/workbench/contrib/browserView/electron-browser/features/browserDevToolsFeature.ts`.
