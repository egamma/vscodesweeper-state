# Issue #199050 — Unexpected indentation added on new line if a string contains a '{'

[https://github.com/microsoft/vscode/issues/199050](https://github.com/microsoft/vscode/issues/199050)

## Summary

The faulty PHP indentation rule was removed on main, so braces inside strings no longer trigger this unexpected indentation.

## Change summary

Prevent an unmatched `{` inside a PHP string from indenting the following line.

## Best solution

Keep the fix from commit 8d2287f6f7d61d8311497ff09887717fed5e6f2a, which delegates ordinary bracket indentation to the existing bracket configuration.
