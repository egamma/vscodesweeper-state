# Issue #257547 — Suggest picks weird suggestions when there's an exact match

[https://github.com/microsoft/vscode/issues/257547](https://github.com/microsoft/vscode/issues/257547)

## Summary

Valid polish issue — still reproduces on main. Since TS 5.0 (commit ed43d97e47a), VS Code defers entirely to TypeScript's sortText for auto-import ranking, and TypeScript sometimes ranks auto-import suggestions (like `it` from `node:test`) above local exact matches (like `iterator`). The issue is already correctly labeled.

## Change summary

Auto-import suggestions from packages rank above local variable exact matches in JavaScript/TypeScript completions.

## Best solution

Improve completion ranking in the TypeScript language features extension (extensions/typescript-language-features/src/languageFeatures/completions.ts) or in the editor suggest model (src/vs/editor/contrib/suggest/browser/completionModel.ts) to boost local/in-scope exact matches above auto-import suggestions. This may also warrant an upstream TypeScript issue if the sortText from TS itself doesn't distinguish local vs. auto-import priority sufficiently.
