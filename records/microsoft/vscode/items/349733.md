# Issue #349733 — Copilot harness ignores the Local harness auto-compaction threshold setting, with no VS Code replacement

[https://github.com/microsoft/vscode/issues/349733](https://github.com/microsoft/vscode/issues/349733)

## Summary

Keep open as a feature request: current main still lacks editor-level control over the Copilot harness's background compaction ratio. The existing Local setting and the related context-limit reports do not cover this capability.

## Change summary

Provide configurable automatic compaction timing for Copilot harness sessions without reducing the model's prompt budget.

## Best solution

Provide a supported, runtime-owned compaction preference accessible from VS Code, preserving the default threshold and prompt budget when unset. Clarify the Local-only setting's scope and settle the supported configuration contract before implementation.
