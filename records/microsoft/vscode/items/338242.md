# Issue #338242 — Thinking Effort selector caps at "High", missing `xhigh`/`max` supported by underlying models

[https://github.com/microsoft/vscode/issues/338242](https://github.com/microsoft/vscode/issues/338242)

## Summary

Already fixed on main: the reasoning-effort dropdown is now fully schema-driven per model/host (including xhigh/max/ultra), not the hardcoded Low/Medium/High list the reporter saw — a contributor also confirms this landed via #335276 for 1.140.0.

## Change summary

The Thinking Effort selector in the model/effort config UI only shows Low/Medium/High, never the xhigh/max tiers some models (GPT-6 Luna Pro, Claude Opus 5.5) support.

## Best solution

Keep the shipped fix: src/vs/workbench/contrib/chat/browser/agentSessions/agentHost/agentHostLanguageModelProvider.ts now derives the picker's enum straight from each host's ConfigSchema (via _toLanguageModelConfigurationSchema/_reasoningEffortDisplay) instead of a fixed 3-option list, and src/vs/platform/agentHost/common/reasoningEffort.ts defines the full ['none','minimal','low','medium','high','xhigh','max','ultra'] level set with labels for each.
