# Issue #330239 — github.copilot.git.repository not populated for self-hosted GitHub Enterprise Server remotes with custom domains

[https://github.com/microsoft/vscode/issues/330239](https://github.com/microsoft/vscode/issues/330239)

## Summary

Real bug in the bundled Copilot Chat extension's OTel repo-attribute logic, and it's already being actively fixed in an open PR that the reporter and contributor are iterating on directly — keep open until that PR merges rather than closing now.

## Change summary

For self-hosted GitHub Enterprise Server remotes with custom domains, the Copilot Chat OTel span is missing github.copilot.git.repository (and copilot_chat.repo.remote_url) because the repo-URL extraction hard-codes an allowlist of github.com/*.ghe.com/Azure DevOps hosts.

## Best solution

Land https://github.com/microsoft/vscode/pull/330284, which normalizes any parseable git remote URL (not just github.com/ghe.com/Azure DevOps) so github.copilot.git.repository is populated for custom-domain GHES, GitLab, Bitbucket Server, etc.; the contributor has already added a test for the reporter's exact custom-domain case.
