# Issue #247628 — can't scroll down for long outputs (without output scrolling enabled)

[https://github.com/microsoft/vscode/issues/247628](https://github.com/microsoft/vscode/issues/247628)

## Summary

Still reproduces on main: the Notebook Output Preview editor's scroll-related methods (`layout`, `setScrollTop`, `triggerScroll`) are empty stubs in `notebookOutputEditor.ts`, so long outputs overflow the viewport without any scrollbar.

## Change summary

Opening notebook output preview with scrolling disabled renders long outputs beyond the viewport with no way to scroll.

## Best solution

Implement the `layout()` and scroll methods in `NotebookOutputEditor` so the BackLayerWebView container gets proper dimensions and scroll behavior when its content exceeds the editor pane's viewport. The fix belongs in `src/vs/workbench/contrib/notebook/browser/outputEditor/notebookOutputEditor.ts`.
