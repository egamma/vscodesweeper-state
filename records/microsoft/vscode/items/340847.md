# Issue #340847 — With an integrated browser view open, the menu bar does not respond to mouse clicks (keyboard still works)

[https://github.com/microsoft/vscode/issues/340847](https://github.com/microsoft/vscode/issues/340847)

## Summary

Thanks for the detailed report. The reporter confirms the repro on 1.141.0 (menu bar ignores clicks while an integrated browser editor is open, and recovers when it is closed). It was filed today and has no maintainer or third-party confirmation. I could not trace it in source, so I'm keeping it open for the integrated-browser owners.

## Change summary

Menu bar mouse clicks stop working while an integrated browser editor is open, possibly because the native browser view has stale bounds that cover the menu bar.

## Best solution

Have the integrated browser owners check the native view's bounds and overlay layout when a restored tab points at an unreachable URL. The view should never intercept input outside the editor area, and the menu bar should respond to clicks.
