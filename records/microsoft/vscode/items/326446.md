# Issue #326446 — get_errors tool returns "No errors found" when filePaths targets a Kotlin file with diagnostics, but global query works

[https://github.com/microsoft/vscode/issues/326446](https://github.com/microsoft/vscode/issues/326446)

## Summary

The current filtering path is case-sensitive even for Windows file URIs, so diagnostics can be dropped when the resolved path and diagnostic URI differ only in drive-letter or path casing.

## Change summary

Make targeted get_errors queries return diagnostics for Windows files whose diagnostic URI uses different path casing.

## Best solution

Use the existing platform-aware URI comparator consistently for parent and exact matches in GetErrorsTool, with a regression test covering differently-cased Windows-style file URIs.
