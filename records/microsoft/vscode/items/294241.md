# Issue #294241 — Copilot Chat can't handle huge files to commit, even with small changes

[https://github.com/microsoft/vscode/issues/294241](https://github.com/microsoft/vscode/issues/294241)

## Summary

The reported context overflow was fixed by bounding Git diff content before it reaches Copilot Chat, so this can be closed as completed.

## Change summary

Copilot Chat requests failed with a 200,000-token overflow when committing changes involving a very large file.

## Best solution

Keep the shipped GitDiffService limits from commit 4a3ea92149deb42b6cf62035642318a1807fc0f7: truncate individual diffs, omit oversized untracked-file content, and bound the number of changed files processed.
