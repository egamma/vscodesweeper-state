# Issue #294241 — Copilot Chat can't handle huge files to commit, even with small changes

[https://github.com/microsoft/vscode/issues/294241](https://github.com/microsoft/vscode/issues/294241)

## Summary

The reporter confirmed repeatable context-limit failures and explicitly retracted the apparent resolution after updating. Keep this open: current source includes budgeting safeguards, but neither a verified fix for this trigger nor a canonical duplicate was established.

## Change summary

Copilot Chat rejects requests to commit small changes when a large uncommitted lockfile is present, reporting prompts above the model's 200,000-token limit.

## Best solution

Copilot's agent request pipeline should handle large changed files within the selected model's context budget while retaining enough information to describe and commit the actual changes. First reproduce this specific lockfile scenario on current builds and identify which context or tool-result path causes the overflow.
