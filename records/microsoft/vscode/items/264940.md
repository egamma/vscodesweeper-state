# Issue #264940 — No way to read full text in coding agent card

[https://github.com/microsoft/vscode/issues/264940](https://github.com/microsoft/vscode/issues/264940)

## Summary

Keep open for a decision on access to delegated-agent details. The current PR card no longer displays the description, but that does not establish that users can read the original text elsewhere; the thread already records maintainer interest in replacing the card.

## Change summary

Make the full delegated coding-agent card text accessible instead of directing users to a potentially different PR description.

## Best solution

Provide a clearly identified way to inspect the delegated task's full details, distinct from opening its PR. Decide whether the relevant content is the original handoff snapshot or the delegated session's current state, alongside the related inline-session work.
