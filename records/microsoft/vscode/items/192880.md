# Issue #192880 — Support two variants of `LanguageStatusItem#text`

[https://github.com/microsoft/vscode/issues/192880](https://github.com/microsoft/vscode/issues/192880)

## Summary

The short/long text capability exists on main, but remains gated behind the languageStatusText proposed API. Keep this api-proposal tracking issue open for the API owners' finalization or abandonment decision; the merged implementation does not complete that lifecycle.

## Change summary

Allow language status items to provide compact pinned text independently of their full flyout text.

## Best solution

Have the API owners assess the positive extension-author feedback and settle the stable LanguageStatusItem contract, preserving compact pinned text and full flyout text. Keep the broader layout, tooltip, and busy-indicator requests separate from this focused proposal.
