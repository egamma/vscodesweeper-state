# Issue #192880 — Support two variants of `LanguageStatusItem#text`

[https://github.com/microsoft/vscode/issues/192880](https://github.com/microsoft/vscode/issues/192880)

## Summary

The proposed API implements and validates the requested behavior, but the public API still accepts only a string. Keep this focused API-proposal issue open until the proposal is finalized or explicitly abandoned.

## Change summary

Allow language status items to provide separate long and short text for the flyout and pinned status bar.

## Best solution

Finalize the `languageStatusText` proposal by exposing the validated `{ value, shortValue }` shape through `LanguageStatusItem.text`, with compatibility for existing string values. Track the separate request to limit `busy` rendering independently.
