# Issue #347820 — Chat export should list reasons for approving command runs

[https://github.com/microsoft/vscode/issues/347820](https://github.com/microsoft/vscode/issues/347820)

## Summary

Keep open: exports already retain some approval metadata, but that does not establish which earlier approval authorized the reported command. The permission-safety concern warrants human review rather than a speculative close.

## Change summary

Include enough command-approval provenance in chat exports to explain why each command was allowed to run.

## Best solution

Make exported approval records explain the authorization source and, where applicable, the earlier user action that granted it. Preserve existing approval enforcement; distinguish unavailable historical provenance from a known approval reason.
