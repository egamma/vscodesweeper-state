# Issue #347820 — Chat export should list reasons for approving command runs

[https://github.com/microsoft/vscode/issues/347820](https://github.com/microsoft/vscode/issues/347820)

## Summary

Keep open: exports already retain some approval metadata, but that does not establish which earlier approval enabled a later command. The request for approval provenance remains distinct from the linked approval-behavior report.

## Change summary

Make chat exports explain why each command was approved, including the earlier permission grant when applicable.

## Best solution

Provide understandable per-command approval provenance in exported sessions, distinguishing immediate approval reasons from the earlier action that granted reusable permission. Preserve runtime ownership of authorization decisions rather than reconstructing them from current settings.
