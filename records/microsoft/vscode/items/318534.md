- **Proposed comment:**

  > Thanks for the report. You can turn off automatic completion without removing the feature: in your User Settings JSON, set `"editor.quickSuggestions": false`, `"editor.suggestOnTriggerCharacters": false`, and `"editor.inlineSuggest.enabled": false`. Keep `"editor.tabCompletion": "off"` to disable Tab completion as well.
  > 
  > The documentation linked above explains these controls: https://code.visualstudio.com/docs/editing/intellisense#_customizing-intellisense. These settings let you write without automatic suggestions while keeping manually requested IntelliSense available through Ctrl+Space.
