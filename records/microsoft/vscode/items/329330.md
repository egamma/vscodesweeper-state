# Issue #329330 — Custom menus and submenus close immediately on Windows, but temporarily recover after an RDP connection

[https://github.com/microsoft/vscode/issues/329330](https://github.com/microsoft/vscode/issues/329330)

## Summary

A member (dmitrivMS) already linked the likely fix, and it has merged into main: the context-view close-animation change in PR #329327 (commit b966285) makes closing menus `inert` so they can no longer reclaim focus and immediately blur a newly opened menu/quick pick — exactly the 'appears briefly then closes' symptom described here, including for custom title-bar menus and the Account/Manage menus.

## Change summary

Custom (non-native) title bar menus and submenus on Windows close immediately after opening, recovering temporarily after an RDP session.

## Best solution

Treat as fixed by the animated-context-view disposal fix in commit b966285933b27aaa9be0904c1c6f2bbe666aefa9 (PR #329327, merged 2026-08-06) — that PR fixed the same 'menu/quick pick closes immediately' regression for several other reports (e.g. toolbar '...' menus, Show Open Editors) via the same shared ContextView component that custom title-bar menus use. Ask the reporter to confirm on the next Insiders build once it ships main-only.
