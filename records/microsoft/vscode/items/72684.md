# Issue #72684 — [folding] Option to show both fold/unfold controls on mouseover only

[https://github.com/microsoft/vscode/issues/72684](https://github.com/microsoft/vscode/issues/72684)

## Summary

The requested distinction remains absent on current main: `mouseover` hides expanded controls until hover but leaves collapsed controls visible. No older open issue found in the canonical-search pass reports this same observable behavior, so the re-reviewed item should remain open in its existing editor-folding backlog lane.

## Change summary

Add a folding-control mode that hides both collapsed and expanded gutter controls until the mouse is over the gutter.

## Best solution

If maintainers accept the additional configuration complexity, extend `editor.showFoldingControls` with a mode that auto-hides both collapsed and expanded glyphs while preserving existing modes and keyboard-accessible folding commands.
