# Issue #348933 — Copilot agent host: skills created during a turn remain undiscoverable until the next user message

## Summary

Keep open: the supplied steps suffice to retest same-turn skill discovery, but current-main behavior is not independently confirmed. Current source includes runtime reload notifications; those do not establish that creating a user skill refreshes the model-facing catalog during an active turn.

## Change summary

Make newly created user skills discoverable by the parent and subsequently spawned skill-capable subagents without another user message.

## Best solution

Establish where the active Copilot session retains its skill catalog, then ensure completed skill creation becomes discoverable before subsequent model requests and subagent launches, preserving trust, enablement, and policy restrictions.
