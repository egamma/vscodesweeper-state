## Change summary

A skill created during an active Copilot agent-host turn remains absent from parent and newly spawned subagent catalogs until another user message.

## Best solution

Make completed skill creation discoverable on subsequent model requests and newly spawned skill-capable subagents within the same turn. First distinguish host inventory freshness from SDK session catalog freshness, preserving trust, enablement, policy, and intentional agent-tool restrictions.
