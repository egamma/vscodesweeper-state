# Issue #157734 — API: Edit session identifier provider

[https://github.com/microsoft/vscode/issues/157734](https://github.com/microsoft/vscode/issues/157734)

## Summary

Keep open as the active API-proposal tracker. The proposed API is implemented and used, but remains unfinalized and still has the documented single-provider design limitation.

## Change summary

Provide an extension API for deriving stable workspace identities so edit sessions can follow repositories across machines and environments.

## Best solution

Resolve the naming, multi-provider, and onboarding questions before either finalizing the API or deliberately retiring it. In particular, replace the current one-provider-per-scheme model if multiple workspace identity sources must coexist.
