# Issue #324615 — I should be able to drag and drop sessions into the chat editor

[https://github.com/microsoft/vscode/issues/324615](https://github.com/microsoft/vscode/issues/324615)

## Summary

Valid feature request from a team member: the chat drag-and-drop system on current main handles files, folders, images, symbols, HTML, markers, notebook outputs, and SCM history items, but has no session type — the gap is confirmed in the code.

## Change summary

Allow dragging and dropping chat sessions into the chat input to attach them as context.

## Best solution

Add a new `SESSION` entry to `ChatDragAndDropType` in `src/vs/workbench/contrib/chat/browser/widget/chatDragAndDrop.ts` and wire up the detection, overlay text, and attachment resolution to create a session variable entry, mirroring how SCM history items or symbols are handled. The session picker (`#session:`) already supports attaching sessions — this would be the drag-and-drop equivalent.
