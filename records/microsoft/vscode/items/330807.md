# Issue #330807 — Copilot chat overview shows number of lines added/removed when there is none

[https://github.com/microsoft/vscode/issues/330807](https://github.com/microsoft/vscode/issues/330807)

## Summary

Thanks for the report and the screenshots. The sessions list appears to keep showing a diff summary for pending changes after they were kept. A second user confirmed this on 1.133.0. I could not confirm the defect from source, so the issue stays open.

## Change summary

After clicking Keep, the chat session list still shows pending added/removed line counts that the open session no longer shows.

## Best solution

Make the sessions list drop or refresh its changes summary once a session's changes are kept or cleared, instead of carrying over the previous value. The code in agentSessionsModel.ts is the likely place, but that is unconfirmed.
