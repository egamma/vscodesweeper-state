# Issue #349613 — Agent session terminal cards highlight PowerShell commands with the shell (bash) grammar

[https://github.com/microsoft/vscode/issues/349613](https://github.com/microsoft/vscode/issues/349613)

## Summary

The adapter still chooses shellscript for terminal tools not named exactly powershell, ignoring the existing shell-language presentation metadata. This is a concrete rendering defect; the linked issues cover different behavior.

## Change summary

Executed agent terminal cards should highlight PowerShell commands as PowerShell rather than Bash.

## Best solution

Preserve the executing shell's supplied display language throughout terminal invocation creation, updates, completion, and history replay. Keep highlighting independent of shell execution and approval behavior.
