# Issue #144235 — Support web workers for a remotely installed web extension loaded in the web extension host

[https://github.com/microsoft/vscode/issues/144235](https://github.com/microsoft/vscode/issues/144235)

## Summary

Keep open: current main still explicitly rejects workers created from remote extension URIs, and child-worker resource rewriting does not support those URIs. The related embedding-API proposal is an enabling design issue, not a verified duplicate of this team-authored Backlog request.

## Change summary

Allow remotely installed web extensions running in the web extension host to create workers and load their remote resources.

## Best solution

Support remote worker entry points and subsequent resource loads without requiring extensions to be served from a different installation source. Coordinate the embedding resource-resolution contract with https://github.com/microsoft/vscode/issues/143962 while retaining this issue's end-to-end capability requirement.
