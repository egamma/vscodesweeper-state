# Issue #144235 — Support web workers for a remotely installed web extension loaded in the web extension host

[https://github.com/microsoft/vscode/issues/144235](https://github.com/microsoft/vscode/issues/144235)

## Summary

The capability remains explicitly unsupported on current main. This team-authored Backlog request should remain open while its resource-URI prerequisite is unresolved.

## Change summary

Allow remotely installed web extensions running in the web extension host to create web workers that load remote resources.

## Best solution

Replace the synchronous resource URI callback with a serializable template or equivalent mapping that can run inside child workers, then remove the explicit vscode-remote worker rejection in the web extension host.
