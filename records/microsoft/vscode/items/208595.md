## Summary

Keep open: current inline-chat review already prioritizes a change containing the cursor, but still automatically reveals another change when none contains it. This team-authored request has maintainer agreement, and no issue-referencing fix or verified older duplicate establishes that it is complete.

## Change summary

Keep inline-chat review at the user's current editing location when presenting multiple changes, with explicit navigation to changes elsewhere.
