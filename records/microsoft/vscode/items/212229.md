# Issue #212229 — Uncaught TypeError: Cannot read properties of undefined (reading 'element')

[https://github.com/microsoft/vscode/issues/212229](https://github.com/microsoft/vscode/issues/212229)

## Summary

Still occurring on current insider builds (1.118.0) per telemetry. The race condition in listView.ts where `items[index]` can be undefined during DnD/splice operations hasn't been fully resolved. Team-authored error-telemetry issue; keep open.

## Change summary

Uncaught TypeError when accessing `items[index].element` in listView.ts during notebook cell drag-and-drop when the items array is in a transient empty/stale state.

## Best solution

Add a bounds/undefined guard in `ListView.element()` (src/vs/base/browser/ui/list/listView.ts:844) or make `notebookCellList.elementAt` guard against the case where `items` is empty despite `view.length` reporting non-zero (race during splice). The recent telemetry hit from the Agents product suggests the same path is also reachable from aiCustomizationListWidget.
