# Issue #173935 — Outline's "Follow Cursor" option is missing from Settings

[https://github.com/microsoft/vscode/issues/173935](https://github.com/microsoft/vscode/issues/173935)

## Summary

The cross-workspace preference gap remains: Follow Cursor still defaults to off and is persisted per workspace, not exposed as a setting. Keep this discussion open; the maintainer expressed willingness to change the default, and a later duplicate confirms this issue owns that request.

## Change summary

Allow Outline to follow the cursor in new workspaces without requiring users to enable it separately in each workspace.

## Best solution

Resolve the new-workspace default in the Outline contribution while preserving explicit workspace choices. Changing the default to enabled is the maintainer-supported direction; decide whether that suffices or whether a user-configurable initial default is warranted.

## Evidence

This explains why enabling the option in one workspace does not enable it in newly opened workspaces.
