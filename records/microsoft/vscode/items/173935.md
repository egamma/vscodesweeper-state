# Issue #173935 — Outline's "Follow Cursor" option is missing from Settings

[https://github.com/microsoft/vscode/issues/173935](https://github.com/microsoft/vscode/issues/173935)

## Summary

A real configuration gap remains: Follow Cursor is machine-local workspace state with a false default, not a user-configurable default. This is already the canonical, correctly routed under-discussion request.

## Change summary

Allow users to enable Outline's Follow Cursor behavior globally or change its default.

## Best solution

Decide whether Follow Cursor should default to enabled globally, as the maintainer suggested, or support a user-scoped default while retaining workspace UI state. The former avoids duplicating persisted state with another setting.

## Vision fit

- **Fit:** rejected
- **Reason:** Adding another component-specific setting contributes configuration sprawl; changing the uniform default better fits the project's UI guardrails.
- **Evidence:** Value: "Simple, uniform UI and UI interactions." The lean-default guardrail also discourages configuration sprawl.
