# Issue #326095 — Code Execution Permission Error in latest vscode

[https://github.com/microsoft/vscode/issues/326095](https://github.com/microsoft/vscode/issues/326095)

## Summary

Keep open: current CLI source still accepts an incomplete cached server installation and reports a missing executable as a permission failure without repairing it. The discussion confirms the missing bin directory and successful recovery after redeployment; the newer related report cannot be this re-reviewed issue's duplicate canonical.

## Change summary

Remote-SSH connections fail persistently when a cached Linux server installation lacks server/bin/code-server.

## Best solution

Make the core CLI recover from a missing server entrypoint without treating genuine permission failures as corruption or repeatedly downloading. Investigate the cache-eviction mechanism documented in https://github.com/microsoft/vscode/issues/338114 separately; this report does not establish that mechanism as its original cause.
