# Issue #312054 — Multi-file Editor for arbitrary files  (continuous scroll editing)

[https://github.com/microsoft/vscode/issues/312054](https://github.com/microsoft/vscode/issues/312054)

## Summary

The existing multi-diff and Search Editor surfaces do not cover continuous editing of arbitrary selected files with view-wide find and replace. Keep this as a feature request; no qualifying older canonical issue or maintainer decision to decline it was found.

## Change summary

Provide a continuously scrolling editor for several selected files, with editing and find/replace across that selected collection.

## Best solution

Evaluate an opt-in multi-file editing surface that preserves each file's identity, language services, and save behavior while supporting collection-wide find and replace. Decide whether to extend existing editor infrastructure or support an extension implementation before committing to a new core surface.
