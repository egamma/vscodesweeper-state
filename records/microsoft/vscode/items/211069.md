# Issue #211069 — Problem rendering in notebooks should use default VS Code workbench font

[https://github.com/microsoft/vscode/issues/211069](https://github.com/microsoft/vscode/issues/211069)

## Summary

Still appears unfixed on main: the notebook error rendering in the output webview inherits the output/editor font-family rather than the workbench UI font, making error messages look out of place. No commit references this issue.

## Change summary

Notebook problem/error rendering uses the editor monospace font instead of the default VS Code workbench (sans-serif) font.

## Best solution

The error rendering elements in the notebook output webview (e.g. `.no-renderer-error` and the minimal error renderer output) should explicitly use `var(--vscode-font-family)` to match the workbench UI font. The fix likely lives in `src/vs/workbench/contrib/notebook/browser/view/renderers/backLayerWebView.ts` (the CSS template) and possibly in the error renderer's own styles.
