# Issue #211069 — Problem rendering in notebooks should use default VS Code workbench font

[https://github.com/microsoft/vscode/issues/211069](https://github.com/microsoft/vscode/issues/211069)

## Summary

The minimal notebook error renderer still inherits the notebook output font for its summary and actions rather than the workbench font. The source confirms the mismatch, and no verified canonical issue or open implementation PR was found.

## Change summary

Use the default workbench font for the minimal notebook error presentation instead of inheriting the code-output font.

## Best solution

Make the minimal error summary and its actions use workbench typography in the built-in notebook renderer, while preserving output-font settings for stack traces and ordinary text outputs.
