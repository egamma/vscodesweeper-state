# Issue #293007 — Configurable location for MCP configuration files

[https://github.com/microsoft/vscode/issues/293007](https://github.com/microsoft/vscode/issues/293007)

## Summary

Current main supports sharing the Copilot CLI MCP configuration, including a configurable COPILOT_HOME, but does not expose arbitrary MCP configuration-file locations. Keep this team-authored request open: the likely-covering commits reference a different issue, and the owner should establish whether broader location configuration remains required.

## Change summary

Allow MCP configuration locations to be configured so VS Code and Copilot CLI can share user-level server definitions.

Retain the existing Copilot CLI discovery and have the owner assess whether it completes the original request. If arbitrary additional files remain required, define their discovery and precedence contract before expanding the MCP configuration surface.
