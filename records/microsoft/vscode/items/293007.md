# Issue #293007 — Configurable location for MCP configuration files

[https://github.com/microsoft/vscode/issues/293007](https://github.com/microsoft/vscode/issues/293007)

## Summary

A real configuration gap remains on current main: MCP discovery supports several fixed paths but no user-configurable file locations. This member-authored feature request should remain open for design and implementation.

## Change summary

Allow users to configure additional locations from which VS Code discovers MCP configuration files.

## Best solution

Add configurable user/profile and workspace MCP file locations, reusing the existing file-watching, parsing, remote-authority, and trust behavior in the MCP discovery layer.
