# Issue #317971 — VSCode should allow opening a devcontainer by cloning instead of mounting a local clone

[https://github.com/microsoft/vscode/issues/317971](https://github.com/microsoft/vscode/issues/317971)

## Summary

This is a valid Dev Containers feature request owned by the VS Code Remote Development team, so it should remain open and be moved to the Remote Development tracker.

## Change summary

Allow a locally defined dev-container configuration to clone a remote repository into the container rather than mounting an existing local checkout.

## Best solution

Extend the Dev Containers workflow to accept both a local configuration and a repository URL, cloning the repository into an isolated container volume while applying the user's local settings. Design and implementation belong in the Dev Containers extension tracked at https://github.com/microsoft/vscode-remote-release.
