# Issue #309538 — Try to move agent flow diagram on resize

## Summary

Team-authored polish request: the agent debug flow chart view has no resize handling, so window resizing can hide parts of the diagram. The view currently only centers content on first load and has pan/zoom but no responsive re-layout on container resize. Keeping open as a valid improvement.

## Change summary

The agent debug log flow chart diagram does not reposition or re-layout when the window is resized, potentially hiding content.

## Best solution

Add a resize observer or container size-change listener in `ChatDebugFlowChartView` (src/vs/workbench/contrib/chat/browser/chatDebug/chatDebugFlowChartView.ts) that triggers `centerContent()` or adjusts the pan/zoom transform when the container dimensions change, so the diagram remains visible after resize.
