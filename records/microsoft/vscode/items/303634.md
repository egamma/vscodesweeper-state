# Issue #303634 — Sessions: Want to be able to create new branch from branch picker

[https://github.com/microsoft/vscode/issues/303634](https://github.com/microsoft/vscode/issues/303634)

## Summary

Keep open: the new-session branch picker still selects existing branches rather than offering branch creation. A newer report confirms the same gap with UX-study feedback, but cannot replace this older, previously reviewed team-authored request.

## Change summary

Allow users to create a new Git branch directly from the branch picker when starting a session in an existing project.

## Best solution

Provide an explicit branch-creation flow within the new-session picker, with clear base-branch and checkout semantics that respect the selected isolation mode. Retain this issue as the older record and coordinate the matching feedback in https://github.com/microsoft/vscode/issues/340720.

- **Fit:** aligned
- **Reason:** Making branch creation available where users choose a session's working branch improves the integrated developer workflow and reduces unnecessary context switching.
