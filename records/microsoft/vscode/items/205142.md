# Issue #205142 — usability: callstack UI should not scroll

[https://github.com/microsoft/vscode/issues/205142](https://github.com/microsoft/vscode/issues/205142)

## Summary

The issue remains valid: with very long stack-frame labels, horizontal scrolling moves filename/line metadata and the load-more row outside the visible viewport, while disabling scrolling makes long labels and metadata unreachable. The debug maintainer acknowledged the poor experience, and no canonical issue or fixing change is identified.

## Change summary

Keep stack-frame source metadata and the Load More Stack Frames control anchored to the Call Stack viewport while long frame labels scroll underneath them.

## Best solution

Preserve horizontal scrolling for long frame names, but render source metadata and the load-more action as viewport-anchored overlays in the debug Call Stack view without changing general list scrolling behavior.
