# Issue #244972 — workspace/symbol only sends the part of the query before the first space the the provider

[https://github.com/microsoft/vscode/issues/244972](https://github.com/microsoft/vscode/issues/244972)

## Summary

Keep open: current source confirms the intentional query splitting, while the provider API consequently loses information. This team-authored request earned 38 upvotes and was promoted to the Backlog.

## Change summary

Pass the complete multi-word workspace-symbol query to providers instead of only its first segment.

## Best solution

Pass `query.original` to workspace symbol providers while retaining the segmented symbol/container query for local quick-access scoring, with tests covering multi-word symbol and container searches.
