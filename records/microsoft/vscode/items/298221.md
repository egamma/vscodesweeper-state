# Issue #298221 — Cannot reconnect in WSL window after hibernation

[https://github.com/microsoft/vscode/issues/298221](https://github.com/microsoft/vscode/issues/298221)

## Summary

This is a well-confirmed Remote-WSL reconnection bug: after long sleep or hibernation, the WSL window exceeds the three-hour reconnection grace period and requires a reload, sometimes orphaning running tasks. Remote-WSL is VS Code-team-owned, so the thread should remain open and be moved to microsoft/vscode-remote-release rather than closed as extension-caused.

## Change summary

Allow VS Code windows connected through Remote-WSL to reconnect reliably after a machine has slept or hibernated for more than three hours without losing task/session tracking.

## Best solution

Move the issue to https://github.com/microsoft/vscode-remote-release and adjust Remote-WSL's server launch or reconnection lifecycle so host suspension does not exhaust the connection's grace period; reconnecting should preserve the remote window and its running-task state.
