# Issue #345262 — MCP Gallery: support installing servers with additional inputs

[https://github.com/microsoft/vscode/issues/345262](https://github.com/microsoft/vscode/issues/345262)

## Summary

Keep open: current source deliberately excludes configurable Gallery installations, and the related Argus report requests filtering rather than this broader capability. Credential persistence and separate remote/local SDK limitations require owner review.

## Change summary

Support transport selection and declared configuration inputs when installing MCP Gallery servers through the owning Agent Host.

## Best solution

Provide runtime-compatible input collection followed by explicit non-secret configuration review, preserving policy enforcement, cancellation, secure secret storage, and installation inventory. Stage configured remote and local-package support separately according to verified SDK capabilities.
