# Issue #345262 — MCP Gallery: support installing servers with additional inputs

[https://github.com/microsoft/vscode/issues/345262](https://github.com/microsoft/vscode/issues/345262)

## Summary

Keep this as the configuration-input installation tracker: current source still deliberately rejects these configurations. The related Argus filtering report does not own the full requested capability.

## Change summary

Support transport selection and declared configuration inputs when installing MCP Gallery servers through Chat and the Agents window.

## Best solution

Provide capability-aware configuration collection followed by host-resolved, non-secret installation review, with secure secret storage and cancellation that writes nothing. Treat configured remote installation and confirmed local-package installation as separate runtime capabilities; optional or defaulted fields must not automatically block installation.
