# Issue #110245 — Allow `createWebviewPanel` to open tab in preview mode

[https://github.com/microsoft/vscode/issues/110245](https://github.com/microsoft/vscode/issues/110245)

## Summary

Still unimplemented: the `createWebviewPanel` API has no preview-mode option, and no proposed API exists for it. Team-authored feature request in the Backlog — stays open.

## Change summary

Allow extensions to open webview panels in preview mode via `createWebviewPanel`, matching the behavior of editor preview tabs.

## Best solution

Add an optional `preview` boolean to `WebviewPanelOptions` (or the `showOptions` parameter) in the extension API, wiring it through to the editor group's preview slot. The Tab API already exposes `isPreview` read-only; this would complete the write side for webviews.
