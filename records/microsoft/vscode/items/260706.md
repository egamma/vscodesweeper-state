# Issue #260706 — Git - Make it easier to tell that the current window is a work tree

[https://github.com/microsoft/vscode/issues/260706](https://github.com/microsoft/vscode/issues/260706)

## Summary

Valid feature request from a team member. The existing window title variables (`activeRepositoryName`, `activeRepositoryBranchName`) show the worktree's own name/branch, not the parent repository, so there's no built-in way to quickly identify which repo a worktree window belongs to. The gap remains on current main.

## Change summary

When a worktree is open, the window title and SCM view don't make it easy to identify which parent repository the worktree belongs to.

## Best solution

Add a new window title variable like `${activeRepositoryParentName}` that resolves to the parent repository name for worktrees, and surface the parent repo relationship more prominently in the SCM view header. The git extension already tracks `repositoryKind` ('worktree') and has access to the common git dir — the parent repo name can be derived from the worktree's `.git/commondir` path. Likely touches: `extensions/git/src/repository.ts` (expose parent repo name), `src/vs/workbench/contrib/scm/browser/activity.ts` (title bar label), and `src/vs/workbench/browser/workbench.contribution.ts` (new title variable).
