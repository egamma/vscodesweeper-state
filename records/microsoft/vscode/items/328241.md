# Issue #328241 — ChatAllowedMcpServers enterprise policy is not enforced for agent-host (delegated) chat sessions

[https://github.com/microsoft/vscode/issues/328241](https://github.com/microsoft/vscode/issues/328241)

## Summary

Keep open for security-owner investigation: the reporter confirmed that delegated agent-host sessions bypass an applied enterprise MCP allowlist on both stdio and HTTP servers. Security-sensitive issues require human handling.

## Change summary

Enforce ChatAllowedMcpServers and ChatDeniedMcpServers consistently for MCP servers used by delegated agent-host sessions.

## Best solution

Propagate and enforce MCP governance inside the agent-host launch path, covering synced configurations, MCP-only plugins, and host-discovered workspace configurations; filtering only the workbench sync list would leave alternate discovery paths open.
