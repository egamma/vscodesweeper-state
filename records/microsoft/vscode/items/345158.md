# Issue #345158 — Subagent tools missaligned when its model's tool set differs from the parent's

[https://github.com/microsoft/vscode/issues/345158](https://github.com/microsoft/vscode/issues/345158)

## Summary

Keep open: the reporter's model-switch comparison and an independent matching report support a real mixed-model editing failure. The parent-model alias-resolution explanation remains a hypothesis, not a confirmed source diagnosis.

## Change summary

Custom subagents lose editing tools when their model uses a different editing-tool family from the parent.

## Best solution

Ensure each subagent receives the editing capabilities allowed by its definition and supported by its selected model, without inheriting an incompatible parent tool profile. First isolate the affected harness and capture the actual child tool catalog.
