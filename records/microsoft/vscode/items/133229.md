# Issue #133229 — Webview editors are not registered editors?

[https://github.com/microsoft/vscode/issues/133229](https://github.com/microsoft/vscode/issues/133229)

## Summary

The debt remains: webview editors are still not registered via IEditorResolverService on current main. The AUTO_LOCK_EXTRA_EDITORS hack in editorConfiguration.ts is unchanged and even grew (browserPreview was added). The underlying architectural gap persists.

## Change summary

Webview editors (markdown preview, simple browser, etc.) do not register with IEditorResolverService, requiring a hardcoded workaround list for features like auto-lock configuration.

## Best solution

Register webview editor types with IEditorResolverService (possibly as lightweight, non-pickable entries) so that features like auto-lock can discover them programmatically instead of maintaining a hardcoded list. Coordinate between webview infrastructure and editor resolver ownership.
