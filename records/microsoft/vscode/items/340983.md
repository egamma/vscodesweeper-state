# Issue #340983 — Agent-host sessions with BYOK models: responses are buffered until completion — no incremental streaming, cancel does not reach the provider

[https://github.com/microsoft/vscode/issues/340983](https://github.com/microsoft/vscode/issues/340983)

## Summary

Keep open: current source conclusively buffers BYOK responses until completion and drops cancellation before reaching the renderer's model request. The report supplies concrete reproduction steps and a same-window Local-mode control; this is an actionable core bridge defect.

## Change summary

Agent-host BYOK sessions should deliver incremental reasoning and response text and propagate Stop to the in-flight model request.

## Best solution

Provide incremental delivery and end-to-end cancellation across the agent-host BYOK bridge while preserving response ordering, tool results, usage, and continuation state. Coordinate the overlapping streaming report without discarding this issue's separately demonstrated cancellation failure.
