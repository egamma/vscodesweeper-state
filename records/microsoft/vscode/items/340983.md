# Issue #340983 — Agent-host sessions with BYOK models: responses are buffered until completion — no incremental streaming, cancel does not reach the provider

[https://github.com/microsoft/vscode/issues/340983](https://github.com/microsoft/vscode/issues/340983)

## Summary

Thanks for the detailed report. Current main still shows the described design: the BYOK bridge returns a buffered result, and the channel passes CancellationToken.None, so Stop cannot reach the provider. Keeping open.

## Change summary

Agent-host sessions with BYOK models show no incremental streaming and Stop does not cancel the upstream provider request.

## Best solution

Make the BYOK LM reverse-RPC bridge streaming (progress events forwarded to SSE frames) and propagate cancellation from the proxy request abort to the renderer's LM API call.
