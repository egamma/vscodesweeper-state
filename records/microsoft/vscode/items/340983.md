# Issue #340983 — Agent-host sessions with BYOK models: responses are buffered until completion — no incremental streaming, cancel does not reach the provider

[https://github.com/microsoft/vscode/issues/340983](https://github.com/microsoft/vscode/issues/340983)

## Summary

Keep open: current main still buffers BYOK responses until completion and drops cancellation before the renderer's provider request. The supplied reproduction and independent macOS confirmation support a real bridge defect, not a provider streaming limitation.

## Change summary

Stream reasoning and response content incrementally in Copilot agent-host BYOK sessions, and propagate Stop to the in-flight provider request.

## Best solution

Provide end-to-end incremental delivery and request cancellation across the renderer LM handler, reverse IPC bridge, and Responses proxy while preserving tool-call ordering, continuation state, usage, and existing non-streaming consumers. Investigate delayed tool execution updates separately unless the same bridge changes demonstrably resolve them.
