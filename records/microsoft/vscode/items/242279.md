# Issue #242279 — Support multi-file diff editor rich markdown view zone

[https://github.com/microsoft/vscode/issues/242279](https://github.com/microsoft/vscode/issues/242279)

## Summary

The requested editor-level rich-content zone remains missing: opening a commit shows its subject in the title, but not its full details above the file diffs. Keep this accepted Backlog request open; no verified canonical or concrete fixing commit was found.

## Change summary

Support rich Markdown view zones in the multi-file diff editor, including a commit-details zone above the diffs when opening a commit from Git blame.

## Best solution

Provide an optional rich-content region within the multi-diff editor and let commit-opening flows supply the description, author, date, and issue links. Decide the reusable view-zone contract and presentation before implementation, while preserving the lightweight default for other diff sources.
