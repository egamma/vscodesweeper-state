[https://github.com/microsoft/vscode/issues/308263](https://github.com/microsoft/vscode/issues/308263)

## Summary

Keep open: current source exposes Apply Changes in the regular Copilot CLI chat toolbar, but its discard action is restricted to file changes in the Agents Window. This team-authored Backlog request has no verified issue-referencing fix or older canonical reporting the same missing action.

## Change summary

Provide a discoverable option to discard Copilot CLI session changes alongside the existing apply option.

Provide a supported discard workflow in the regular Copilot CLI change-review surface, with an explicit scope and confirmation that protects unrelated edits. The existing Agents Window file-discard capability is relevant prior art, but does not resolve the missing action in the reported surface.
