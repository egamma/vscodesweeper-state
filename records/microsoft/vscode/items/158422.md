# Issue #158422 — Continue Working On from a multi-root workspace 

[https://github.com/microsoft/vscode/issues/158422](https://github.com/microsoft/vscode/issues/158422)

## Summary

A real gap remains: Continue Working On recognizes a multi-root workspace but the built-in Git destination selects and clones only one repository. Keep this open for a product decision on transferring the complete workspace.

## Change summary

Support continuing an entire multi-root workspace, rather than selecting only one repository from it.

## Best solution

Teach the Continue Working On destination flow and built-in Git integration to recreate all relevant workspace roots, then restore each folder's edit-session changes into the resulting multi-root workspace.
