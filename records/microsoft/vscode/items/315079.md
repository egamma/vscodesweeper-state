# Issue #315079 — Improve communication for continuation options based on past usage

[https://github.com/microsoft/vscode/issues/315079](https://github.com/microsoft/vscode/issues/315079)

## Summary

Team-authored feature request for smarter context-aware continuation recommendations in the UBB flow, still under discussion with no evidence of implementation on main.

## Change summary

Recommend primary next steps (upgrade vs. add budget) based on the user's usage pattern and remaining cycle time, rather than showing a static upgrade prompt.

## Best solution

Design and implement context-aware recommendation logic that factors in days remaining in the billing cycle and consumption rate to surface the most relevant continuation option (upgrade, add budget, switch model, wait for reset) as the primary action.
