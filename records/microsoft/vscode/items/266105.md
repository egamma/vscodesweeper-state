# Issue #266105 — MCP server configurations should be an options map

[https://github.com/microsoft/vscode/issues/266105](https://github.com/microsoft/vscode/issues/266105)

## Summary

Team-authored feature request (hard keep-open). The config options-map approach for MCP servers has not been implemented on current main — IMcpStdioServerConfiguration still uses command/args with no config property.

## Change summary

Replace command-line variable substitution in MCP server configs with a named options map derived from the registry schema, enabling safe server updates across versions.

## Best solution

Add a `config` options map to IMcpServerConfiguration in src/vs/platform/mcp/common/mcpPlatformTypes.ts that mirrors the registry's named-input schema, and update the MCP management/discovery code to resolve configs through this map instead of baking parameters into args. This allows graceful version upgrades and cleaner user-facing configuration.
