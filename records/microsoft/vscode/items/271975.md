# Issue #271975 — Terminal is still showing `node` is process title, despite being finished

[https://github.com/microsoft/vscode/issues/271975](https://github.com/microsoft/vscode/issues/271975)

## Summary

Still present on main: the terminal's `_processName` is set when a child process runs but never cleared when it exits, so the tab title shows the last child process name (e.g. "node") after it finishes. No fix commit references this issue.

## Change summary

Terminal tab continues to display the child process name (e.g. "node") after the process has exited, instead of reverting to the shell name.

## Best solution

In `_onProcessExit` in `src/vs/workbench/contrib/terminal/browser/terminalInstance.ts`, reset `_processName` back to the shell's base name (or clear the stale title) and trigger a label refresh so the tab reverts to showing the shell process rather than the finished child process.
