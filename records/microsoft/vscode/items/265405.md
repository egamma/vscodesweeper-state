# Issue #265405 — git.openFile opens in wrong split

[https://github.com/microsoft/vscode/issues/265405](https://github.com/microsoft/vscode/issues/265405)

## Summary

Still reproducible on main: `git.openFile` hardcodes `ViewColumn.Active` (line 1338 of extensions/git/src/commands.ts), so clicking the toolbar button on a non-focused diff editor opens the file in the wrong split. An open PR (#307595) already proposes a fix.

## Change summary

The `git.openFile` command opens the file in the active editor group instead of the group containing the source diff editor.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/307595 (or an equivalent fix) that resolves the source diff editor's tab group and uses its `viewColumn` instead of `ViewColumn.Active` when the command is invoked from the editor toolbar.
