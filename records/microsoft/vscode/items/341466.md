# Issue #341466 — The release notes linked from the VS Code update section in the title bar correspond to a previous update rather than the update that was installed.

## Summary

The tooltip code looks correct on paper, so this needs the reporter's exact scenario. The Release Notes button in updateTooltip.ts opens `update.productVersion`, falling back to the running product version only when there is no update info. Without knowing which update state was shown, the cause can't be confirmed.

## Change summary

The Release Notes button in the title bar update tooltip opens notes for the already-installed version instead of the pending update's version.

## Best solution
