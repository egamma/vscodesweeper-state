# Issue #350708 — P1 Markdown preview: one keystroke in a large Markdown file pins the preview webview at 100% CPU for ~40 s (DOMParser is quadratic under the `<div dir="auto">` wrapper)

[https://github.com/microsoft/vscode/issues/350708](https://github.com/microsoft/vscode/issues/350708)

## Summary

Keep open while the linked fixing PR is reviewed: current main still parses the complete preview HTML under the costly dir="auto" wrapper. The PR reports an additional reproduction and substantial improvement, but it has not merged.

## Change summary

Prevent large Markdown preview updates from spending tens of seconds parsing HTML after each keystroke.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/350769 while preserving right-to-left rendering on initial load, updates, and document switches. Keep the distinct copy-button DOM churn tracked by https://github.com/microsoft/vscode/issues/350778 and its separate PR.
