# Issue #236160 — Merge editor: add setting to auto navigate to next conflict

[https://github.com/microsoft/vscode/issues/236160](https://github.com/microsoft/vscode/issues/236160)

## Summary

The merge editor still lacks configurable automatic navigation after resolving a conflict; its existing navigation command is manual. Keep this accepted Backlog request open: no verified open canonical or landed implementation covers it.

## Change summary

Add opt-in automatic navigation to the next conflict after resolving a conflict in the merge editor.

## Best solution

Provide a merge-editor equivalent of the inline conflict editor's opt-in automatic navigation, preserving the current stay-in-place behavior when disabled and allowing users to review or edit the accepted result.
