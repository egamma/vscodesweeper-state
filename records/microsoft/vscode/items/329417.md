# Issue #329417 — Weird white space in agents window editor tabs

[https://github.com/microsoft/vscode/issues/329417](https://github.com/microsoft/vscode/issues/329417)

## Summary

Traced a real, localized CSS gap in the Agents window: the sessions-specific tab strip stylesheet only overrides `.tab.sizing-fit`, so setting `workbench.editor.tabSizing: "shrink"` falls through to the default workbench tab CSS (`flex-grow: 1; min-width: 80px`), which stretches/pads tabs in the narrower agents-window strip — matching the screenshot's odd whitespace.

## Change summary

With `workbench.editor.tabSizing: "shrink"`, editor tabs in the Agents window show unexpected extra whitespace/padding.

## Best solution

Extend src/vs/sessions/contrib/editor/browser/media/editorTabs.css to also override `.tab.sizing-shrink` (and likely `.tab.sizing-fixed`) the same way `.tab.sizing-fit` is handled today — disabling the default `flex-grow`/min-width growth so shrink-sized tabs keep the compact, content-width look the agents window already achieves for the default 'fit' sizing.
