# Issue #338128 — Windows emojis aren't registering in VS Code following the latest update.

[https://github.com/microsoft/vscode/issues/338128](https://github.com/microsoft/vscode/issues/338128)

## Summary

Thanks for the report. A maintainer reproduced this and traced it to an upstream Chromium bug, triggered by `autocorrect:off` on the editor element. The Electron backport is still pending, and users on 1.141.2 and 1.142.0 still see the problem, so the issue stays open until a build with the fix ships.

## Change summary

On Windows, emoji insertion through the Win+. picker is silently dropped or only intermittently registers in the editor since 1.139.

## Best solution

Land the Chromium fix in Electron and pick up the updated Electron build. Then ask reporters to confirm. If a release is needed before that, VS Code could consider not setting `autocorrect=off` on the editor input.
