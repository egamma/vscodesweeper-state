# Issue #338128 — Windows emojis aren't registering in VS Code following the latest update.

## Summary

Thanks for the report. Many users confirm it on 1.139–1.141 insiders, and a maintainer (aiday-mar) reproduced it on desktop only, not web, which points to a Chromium/Electron input regression.
