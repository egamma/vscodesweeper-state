# Issue #338128 — Windows emojis aren't registering in VS Code following the latest update.

[https://github.com/microsoft/vscode/issues/338128](https://github.com/microsoft/vscode/issues/338128)

## Summary

Thanks for the report. A VS Code contributor reproduced this on desktop and traced it to a Chromium bug that is triggered when `autocorrect:off` is set on the editor element. A fix is to be backported into Electron next week, so this stays open until the backport ships and can be verified.

## Change summary

The Windows emoji picker (Win + .) intermittently fails to insert emojis into the editor on VS Code 1.139 and later.

## Best solution

Land the Chromium fix in Electron (backport planned) and pick it up in VS Code. Then confirm emoji insertion works reliably on Windows and close the issue. If the backport is delayed, consider removing or working around `autocorrect:off` on the editor element.
