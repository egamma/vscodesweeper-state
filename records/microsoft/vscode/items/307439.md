# Issue #307439 — Copilot Chat: Unresponsive, stale "pending edits" persist when files are edited outside the session

[https://github.com/microsoft/vscode/issues/307439](https://github.com/microsoft/vscode/issues/307439)

## Summary

Keep open to investigate stale chat-editing state after external file changes. Another user confirms the stale-diff symptom after stashing; source inspection identifies relevant restoration and acceptance paths but does not establish a current fix or a qualifying duplicate.

## Change summary

Reopening a chat session after manual or Git-driven file changes leaves stale pending-edit overlays that Keep and Undo cannot clear.

## Best solution

Make restored chat-editing state reconcile safely with current workspace contents so pending-edit controls remain functional without abandoning the conversation. Diagnose the existing Keep path first; a new baseline-reset command or automatic checkpoint rebasing would require a separate decision about retained history.
