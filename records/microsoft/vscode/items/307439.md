[https://github.com/microsoft/vscode/issues/307439](https://github.com/microsoft/vscode/issues/307439)

## Summary

Keep open: the reported reopen-after-manual-edit workflow supplies enough detail to retest, but the unresponsive Keep/Undo behavior is not confirmed on current main. Current source has manual-edit reconciliation and snapshot restoration paths, neither of which establishes that this report is resolved.

## Change summary

Restoring an older chat session leaves stale pending-edit decorations that Keep/Undo cannot clear after files have changed outside that session.

## Best solution

Make restored chat edit tracking reconcile with the current workspace so users can clear pending edits without discarding their conversation or disabling checkpoints. Diagnose the existing restoration and acceptance paths before deciding whether a separate baseline-reset capability is necessary.
