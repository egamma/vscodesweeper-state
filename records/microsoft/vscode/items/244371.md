# Issue #244371 — Cannot read properties of null (reading 'domNode')

[https://github.com/microsoft/vscode/issues/244371](https://github.com/microsoft/vscode/issues/244371)

## Summary

Keep open while the explicitly linked fix PR remains unmerged. Current source still permits notebook height updates during list insertion to reach an unguarded null-row dereference; stable telemetry confirms substantial user impact.

## Change summary

Notebook cell layout can throw a null domNode error when a height update reenters list rendering before all visible rows are allocated.

## Best solution

Review https://github.com/microsoft/vscode/pull/332587 against the reentrant notebook insertion path and land a fix that prevents the exception without leaving cell geometry stale. Keep this issue available for tracking the outcome until the implementation merges.
