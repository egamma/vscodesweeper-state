# Issue #285902 — Copilot Chat fails in Jupyter Notebook with “Unsupported kind 'markdown'” when Notebook Alternative Format is set to markdown

[https://github.com/microsoft/vscode/issues/285902](https://github.com/microsoft/vscode/issues/285902)

## Summary

Still reproducible on main: package.json offers 'markdown' as a valid enum value for the notebook alternativeFormat setting, but the runtime code only supports xml/text/json and throws 'Unsupported kind' — the stale enum entry in package.json needs to be removed or a markdown provider needs to be implemented.

## Change summary

Copilot Chat throws 'Unsupported kind markdown' when the notebook alternative format setting is set to markdown, because the setting UI offers it but the runtime has no handler for it.

## Best solution

Remove 'markdown' from the enum in `extensions/copilot/package.json` (line ~4656) and replace it with 'text' and 'json' to match the supported values in `AlternativeNotebookFormat`. A team member already acknowledged this fix direction.
