# Issue #322124 — Add BYOK settings to Group Policies

[https://github.com/microsoft/vscode/issues/322124](https://github.com/microsoft/vscode/issues/322124)

## Summary

Keep open: the existing BYOK gate follows the signed-in account, whereas this request needs device-specific enforcement that leaves the same account usable on personal machines. The inspected policy catalog does not expose that control, and no verified older canonical owns this requirement.

## Change summary

Allow administrators to restrict BYOK models on company-managed devices without disabling them for the same GitHub account on personal devices.

## Best solution

Provide an administrator-managed, device-scoped BYOK restriction while preserving ordinary Copilot model access and personal-device behavior. Define its enforcement scope and interaction with account policy through the supported managed-settings contract rather than adding another account entitlement.
