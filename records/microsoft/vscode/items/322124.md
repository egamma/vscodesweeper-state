# Issue #322124 — Add BYOK settings to Group Policies

[https://github.com/microsoft/vscode/issues/322124](https://github.com/microsoft/vscode/issues/322124)

## Summary

Valid feature request to add enterprise Group Policy controls for BYOK model settings — currently BYOK settings like `chat.byokUtilityModelDefault` lack a `policy:` field, while other chat settings (e.g. `chat.defaultModel`, `chat.agentAutoApproval`) already support policy-driven management.

## Change summary

Allow enterprise admins to restrict or configure BYOK model usage via Group Policy / managed preferences, preventing BYOK on company-managed machines.

## Best solution

Add `policy:` blocks to the BYOK-related configuration settings in `src/vs/workbench/contrib/chat/browser/chat.shared.contribution.ts` (e.g. `chat.byokUtilityModelDefault` and related BYOK settings), following the existing pattern used by `chat.defaultModel` and `chat.agentAutoApproval`. This would let enterprise admins control BYOK availability through Windows Group Policy, macOS managed preferences, or Linux policy.json.
