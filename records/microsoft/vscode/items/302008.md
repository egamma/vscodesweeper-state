# Issue #302008 — Image Carousel Does Not Automatically Refresh When New Screenshots Are Added

[https://github.com/microsoft/vscode/issues/302008](https://github.com/microsoft/vscode/issues/302008)

## Summary

Keep open: the carousel still snapshots chat images at opening, so screenshots produced afterward do not appear until it is reopened. A maintainer accepted the reproduction, and an open fixing PR already owns the implementation.

## Change summary

Refresh an open chat image carousel automatically when the agent produces additional screenshots.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/321304 so newly produced screenshots appear without reopening the carousel, while preserving the currently viewed image and its viewing state.
