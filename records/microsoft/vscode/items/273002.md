## Change summary

Clicking a file link in a chat response navigates to the wrong file when multiple files share the same name across different directories.

## Best solution

The inline reference resolution path (chatModel.ts `resolveInlineReference`, chatMarkdownContentPart.ts, chatInlineAnchorWidget.ts) needs disambiguation logic when the LLM's response references a file name that appears in multiple directories — the resolution should prefer the file contextually relevant to the conversation (e.g., the file the user was editing, the directory being discussed, or the file mentioned in tool call context).
