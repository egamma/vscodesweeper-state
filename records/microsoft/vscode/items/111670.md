# Issue #111670 — Consider adding a clear condition option

[https://github.com/microsoft/vscode/issues/111670](https://github.com/microsoft/vscode/issues/111670)

## Summary

Team-authored feature request for a 'Clear Condition' context menu action on breakpoints — not yet implemented on main. The existing workaround (Edit Condition → backspace → Enter) works but is clunky. Keeping open as a valid, unimplemented enhancement.

## Change summary

Add a dedicated 'Clear Condition' action to the breakpoint context menu so users don't have to manually edit and delete the condition text.

## Best solution

Add a 'Clear Condition' context menu action to `MenuId.DebugBreakpointsContext` in `src/vs/workbench/contrib/debug/browser/breakpointsView.ts`, alongside the existing 'Edit Condition...' action. The action should clear the breakpoint's condition/hitCondition via `IDebugService.updateBreakpoints()`. A similar action could be added to the editor gutter context menu in `breakpointEditorContribution.ts`.
