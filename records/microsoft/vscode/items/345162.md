# Issue #345162 — Keep Auto Update Disabled

[https://github.com/microsoft/vscode/issues/345162](https://github.com/microsoft/vscode/issues/345162)

## Summary

Keep open as a request to change the default update behavior. The reporter explicitly confirmed that they already disabled updates; pointing to that setting does not address their request.

## Change summary

Make updates manual by default, with separate user consent to check for and download or install an available update.

## Best solution

Have the update owners decide whether the default should become manual and whether checking should remain separate from downloading and installing. Preserve existing update-mode choices unless a broader product decision replaces them.
