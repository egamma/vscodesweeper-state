# Issue #337570 — Linux (Xfce/xfwm4): grey border on left, right and bottom of the window since 1.139 (Electron 43 regression)

[https://github.com/microsoft/vscode/issues/337570](https://github.com/microsoft/vscode/issues/337570)

## Summary

Root cause is a Chromium/Electron regression (Electron 43), not a VS Code defect: Chromium's X11Window::CanSetDecorationInsets() special-cases the Xfwm4 window-manager name and disables decoration insets, causing Electron's Linux frame view to paint a solid border instead of a transparent shadow. Already correctly labeled bug/upstream/electron/regression; nothing to fix in VS Code core until upstream lands a fix.

## Change summary

On Xfce/xfwm4 with the custom title bar, VS Code 1.139.0 (first release on Electron 43) shows a 4px grey border on the left/right/bottom window edges that wasn't present in 1.138.0 (Electron 42).

## Best solution

Track electron/electron#52024 for the upstream fix; alternatively, VS Code could investigate the app-side workaround the reporter mentions (frame:false + hasShadow:false, no titleBarOverlay) for Linux frameless windows, but that needs a maintainer decision since it could affect shadow/rounded-corner rendering on other window managers.
