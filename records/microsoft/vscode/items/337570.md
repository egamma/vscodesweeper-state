# Issue #337570 — Linux (Xfce/xfwm4): grey border on left, right and bottom of the window since 1.139 (Electron 43 regression)

[https://github.com/microsoft/vscode/issues/337570](https://github.com/microsoft/vscode/issues/337570)

## Summary

Confirmed, well-diagnosed upstream Electron/Chromium regression affecting xfwm4 users on Electron 43; current main still pins Electron 43.7.3, which predates both upstream fixes, so the issue genuinely remains open pending a dependency bump.

## Change summary

Since the Electron 43 bump in 1.139.0, custom-title-bar windows show an opaque grey border on Xfce/xfwm4 because Chromium disables client-side shadows for any window manager reporting itself as 'Xfwm4'.

## Best solution

Bump the bundled Electron past 43.7.6 (which backports electron/electron#54390) to remove the grey band; full shadow restoration on xfwm4 additionally needs the Chromium 156 fix, which only ships with Electron 45 — track both via the normal Electron version-bump process.
