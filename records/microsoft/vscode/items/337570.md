# Issue #337570 — Linux (Xfce/xfwm4): grey border on left, right and bottom of the window since 1.139 (Electron 43 regression)

[https://github.com/microsoft/vscode/issues/337570](https://github.com/microsoft/vscode/issues/337570)

## Summary

Root cause is confirmed upstream in Electron/Chromium (Electron 43's frame view paints a solid border when Chromium's X11Window::CanSetDecorationInsets() returns false for xfwm4); the reporter has already tracked both fixing PRs, so this should stay open until VS Code bundles an Electron build containing the backport.

## Change summary

Since VS Code 1.139.0 (Electron 43), windows on Xfce/xfwm4 with the custom title bar show an opaque 4px grey border on the left/right/bottom edges instead of the transparent shadow.

## Best solution

Keep tracking until VS Code updates its bundled Electron to a 43.x patch release containing electron/electron#54390 (the backport of #54376); verify the border disappears once that Electron version ships, then close as implemented via the dependency bump.
