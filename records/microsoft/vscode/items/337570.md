# Issue #337570 — Linux (Xfce/xfwm4): grey border on left, right and bottom of the window since 1.139 (Electron 43 regression)

[https://github.com/microsoft/vscode/issues/337570](https://github.com/microsoft/vscode/issues/337570)

## Summary

Confirmed still-open Electron/Chromium regression affecting xfwm4 window decorations; the reporter has done excellent upstream diagnosis and current main (.npmrc target="43.7.3") has not yet picked up the partial Electron fix, let alone the full Chromium 156/Electron 45 fix, so this stays open as upstream.

## Change summary

Grey 4px border appears on left/right/bottom window edges under Xfce/xfwm4 with custom title bar since VS Code 1.139 (Electron 43), caused by a Chromium/Electron workaround targeting old xfwm4 versions.

## Best solution

Bump the pinned Electron version in .npmrc to 43.7.6+ once VS Code adopts it (removes the grey band), and track the remaining shadow-restoration fix which requires Electron 45 (Chromium 156) for a full resolution — likely a separate later Electron major bump.
