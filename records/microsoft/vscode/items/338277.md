# Issue #338277 — [agent_stop] Prevent potential negative duration calculation due to clock skew

[https://github.com/microsoft/vscode/issues/338277](https://github.com/microsoft/vscode/issues/338277)

## Summary

Confirmed defect in cli/src/commands/agent_stop.rs — the duration subtraction is unguarded and could go negative on clock skew — but an open PR (#338278) already targets this exact fix, so the issue should stay open pending review/merge of that PR rather than be worked on independently.

## Change summary
