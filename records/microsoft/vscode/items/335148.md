# Issue #335148 — Modern UI Tabs: no theme color id for inactive editor tab foreground

[https://github.com/microsoft/vscode/issues/335148](https://github.com/microsoft/vscode/issues/335148)

## Summary

Confirmed gap on main: `modernEditorTab.activeForeground` and `modernEditorTab.hoverForeground` are registered colors in src/vs/workbench/common/theme.ts, but there is no `modernEditorTab.inactiveForeground` at all — inactive is hardcoded. A partial workaround (falling back to the generic `tab.inactiveForeground`) exists only for the default 'Connected' tab style, not for 'Pill' style (which is the Agents window default), so the reporter's core ask is still unmet.

## Change summary

Modern UI editor tabs have registered theme colors for active/hover foreground but none for inactive foreground, so themes can't restyle it (and Pill-style tabs ignore even the generic `tab.inactiveForeground`).

## Best solution

Register a `modernEditorTab.inactiveForeground` color (mirroring the active/hover pattern in src/vs/workbench/common/theme.ts) and wire it into tabs.css so both Connected and Pill tab styles honor it, replacing the ad-hoc hardcoded color-mix and the connected-only `tab.inactiveForeground` fallback.
