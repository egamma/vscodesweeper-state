# Issue #335148 — Modern UI Tabs: no theme color id for inactive editor tab foreground

[https://github.com/microsoft/vscode/issues/335148](https://github.com/microsoft/vscode/issues/335148)

## Summary

Confirmed on current main: `modernEditorTab.activeForeground` and `modernEditorTab.hoverForeground` are registered theme colors, but there is no `modernEditorTab.inactiveForeground` equivalent — the inactive label is hardcoded to a 50%-transparent mix of the base `foreground` color with no theme-settable id in the chain.

## Change summary

Modern UI (`workbench.experimental.modernUI`) tabs expose theme colors for active/hover editor-tab foreground but not for the inactive state.

## Best solution

Register a `modernEditorTab.inactiveForeground` color (mirroring `modernEditorTab.activeForeground`/`hoverForeground`) in src/vs/workbench/common/theme.ts, default it to the existing color-mix behavior, and reference it from the inactive-foreground CSS variable in tabs.css — the same pattern the 'connected' tab variant already uses via `tab.inactiveForeground` (connectedEditorTabs.css / tabs.css line 53-54).
