# Issue #335148 — Modern UI Tabs: no theme color id for inactive editor tab foreground

[https://github.com/microsoft/vscode/issues/335148](https://github.com/microsoft/vscode/issues/335148)

## Summary

Traced in the current source: the Modern UI editor tab CSS defines registered, theme-settable colors for the active and hover foreground states but hardcodes the inactive foreground to a transparency mix of the generic foreground color with no color id anywhere in the chain — a real, verifiable gap in an actively developed experimental feature.

## Change summary

Modern UI tabs (workbench.experimental.modernUI) have no theme color id for the inactive editor tab's foreground text, so themes setting tab.inactiveForeground are silently ignored for inactive tabs.

## Best solution

Register a `modernEditorTab.inactiveForeground` color in src/vs/workbench/common/theme.ts (mirroring MODERN_EDITOR_TAB_ACTIVE_FOREGROUND/MODERN_EDITOR_TAB_HOVER_FOREGROUND, likely defaulting through `oneOf(tabInactiveForeground, foreground)` or similar), then reference it via `--vscode-modernEditorTab-inactiveForeground` in tabs.css instead of the hardcoded color-mix.
