# Issue #285926 — Agent unable to read terminal

[https://github.com/microsoft/vscode/issues/285926](https://github.com/microsoft/vscode/issues/285926)

## Summary

Real bug where custom bash prompts (like bash-git-prompt) break shell integration sequences (A/B missing), causing the agent's terminal tool to fail with 'invalid terminal ID'. Maintainer confirmed and provided a workaround. Extensive terminal tool fixes have landed since (missing terminal ID fix in 8eaab1c0893, empty output fix in 6532ec0a097), but none reference this issue and the root cause — custom prompts overriding shell integration — may still apply.

## Change summary

Custom bash prompts that override PS1 (like bash-git-prompt) break shell integration sequences, causing the chat agent's run_in_terminal tool to lose track of terminal IDs and fail to read command output.

## Best solution

The terminal tool has received significant hardening since this was filed (missing terminal ID fix, empty output fix, idle silence improvements). Verify whether the original reporter's scenario still reproduces on current main with bash-git-prompt active. If the root issue persists, the terminal tool's execute strategies need to be more resilient when shell integration sequences A/B are missing due to custom prompts. Comment 3's report of commands >2-3s returning 'no output' may be a separate timing issue worth checking independently.
