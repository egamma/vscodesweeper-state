# Issue #326895 — vscode_listCodeusages tool should implement some form of caching

[https://github.com/microsoft/vscode/issues/326895](https://github.com/microsoft/vscode/issues/326895)

## Summary

The current usages tool recomputes and returns the complete reference set on every invocation, so the reported token-efficiency gap remains. This team-authored request should stay open and be classified for the chat-tools area.

## Change summary

Avoid repeatedly sending the complete code-usage result when an agent queries the same symbol multiple times.

## Best solution

Design a reusable, invalidation-aware result mechanism for `vscode_listCodeUsages`, likely combining cached reference data with pagination or a stable result handle. A computation-only cache would not reduce model input tokens if every invocation still returns the full text.
