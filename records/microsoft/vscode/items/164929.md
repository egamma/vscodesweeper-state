# Issue #164929 — Search & Replace exclude deleted files by default

[https://github.com/microsoft/vscode/issues/164929](https://github.com/microsoft/vscode/issues/164929)

## Summary

Keep open: current source still searches retained editors whose backing files were deleted, and replacement saves those models. The search area is already correctly assigned; no verified older canonical or concrete fixing commit was found.

## Change summary

Exclude deleted files retained in open editors from workspace Search & Replace by default so bulk replacement does not recreate them.

## Best solution

Workspace Search & Replace should omit deleted file-backed editors while preserving their unsaved contents and explicit recovery options. Address the open-editor search path without changing normal searches of existing files or untitled documents.
