## Summary

A real gap remains: current main implements `lineDecorationsWidth`, but omits its configuration schema, so VS Code still reports `editor.lineDecorationsWidth` as unknown. This accepted Backlog request has 138 upvotes and should remain open.

Expose the existing `editor.lineDecorationsWidth` editor option as an officially supported and documented setting.
