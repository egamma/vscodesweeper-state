# Issue #288787 — Chat took too long to get ready

[https://github.com/microsoft/vscode/issues/288787](https://github.com/microsoft/vscode/issues/288787)

## Summary

The slow Chat readiness is caused by the reporter's local proxy at 127.0.0.1:7890 failing all connections (`net::ERR_PROXY_CONNECTION_FAILED`), not a VS Code defect. The activation blocker waited ~210 seconds for network requests that could never succeed through the broken proxy.

## Change summary

Copilot Chat took over 3 minutes to become ready due to repeated proxy connection failures during activation.

## Best solution

This is a local environment issue — the reporter's proxy at 127.0.0.1:7890 was refusing connections, causing every network request (token fetch, model fetch, embedding fetch) to fail and time out. Fixing or disabling the proxy resolves the delay. No product change needed.
