# Issue #164267 — Add support for language-aware word wrap

[https://github.com/microsoft/vscode/issues/164267](https://github.com/microsoft/vscode/issues/164267)

## Summary

A real editor capability gap remains: wrapping indentation is still uniform rather than language- or line-aware. This accepted Backlog request has 65 community upvotes and already carries the correct area labels.

## Change summary

Make wrapped Markdown list continuations align beneath list content without applying the same extra indentation to ordinary paragraphs.

## Best solution

Extend the core editor wrapping pipeline to determine continuation indentation per line, with language-aware input capable of recognizing constructs such as Markdown list markers. Preserve the existing global `editor.wrappingIndent` behavior as the default.

## Evidence

- **current source:** On current main, `computeWrappedTextIndentLength` in `src/vs/editor/common/viewModel/monospaceLineBreaksComputer.ts` derives continuation indentation only from leading whitespace plus the global `WrappingIndent` mode; it receives no language or token information.
- **advanced wrapping:** `src/vs/editor/browser/view/domLineBreaksComputer.ts` likewise applies one `wrappingIndent` value to every requested line, so the advanced strategy does not provide Markdown-list-specific indentation.
- **existing settings:** `src/vs/editor/common/config/editorOptions.ts` exposes only `none`, `same`, `indent`, and `deepIndent` for `editor.wrappingIndent`; none conditionally distinguishes list items from paragraphs.

- **referenced PR:** https://github.com/microsoft/vscode/pull/134171 only fixed honoring existing indentation settings in advanced wrapping; it did not add per-line or language-aware indentation.
