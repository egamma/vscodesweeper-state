# Issue #93006 — [rename on type] strange behavior with auto indent in closing tag

[https://github.com/microsoft/vscode/issues/93006](https://github.com/microsoft/vscode/issues/93006)

## Summary

Confirmed rename-on-type bug in HTML synced regions where full auto-indent interferes with mirrored tag edits, causing the first typed character to be lost in the opening tag and moving the closing tag unexpectedly.

## Change summary

Typing a replacement HTML tag name after clearing a closing tag produces divergent opening and closing tags when full auto-indent is enabled.

## Best solution

Coordinate synced-region mirror edits with auto-indent so indentation edits do not invalidate or overwrite the opening-tag mirror edit, while preserving normal full auto-indent behavior outside synced tag regions.
