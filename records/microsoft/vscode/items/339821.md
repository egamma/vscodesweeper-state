## Summary

Thanks for the request. Copilot chat has no built-in tools that read the live debug session (call stack, variables, debug console, breakpoints). No existing setting or command covers this, so it stays open as a feature request.

## Change summary

Expose live debugger state (call stack, debug console output, breakpoints and control) to Copilot agent tools.

## Best solution

Add built-in language model tools in the debug contrib that expose session state (call stack, variables, breakpoints, debug console output, and optionally continue/pause/step), gated behind tool approval. Decide how they overlap with the DebugMCP extension.
