# Issue #292072 — Disambiguate file reads when there are multiple with same name

[https://github.com/microsoft/vscode/issues/292072](https://github.com/microsoft/vscode/issues/292072)

## Summary

The gap remains on current main: file links in chat tool progress use only the basename, so reads of different same-named files are visually indistinguishable. Route this accepted polish item to the chat tools area.

## Change summary

Show the minimum distinguishing path context when chat displays reads of multiple files with the same basename.

## Best solution

Within each displayed tool-activity group, keep unique file labels compact while adding the shortest distinguishing parent-path context to duplicate basenames, consistent with editor-tab labeling.
