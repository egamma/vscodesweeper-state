# Issue #320869 — Korean IME input is dropped or corrupted in Markdown preview Cmd+F find box

[https://github.com/microsoft/vscode/issues/320869](https://github.com/microsoft/vscode/issues/320869)

## Summary

Confirmed bug on current main: Korean IME input is corrupted in SimpleFindWidget because focusFindBox() disrupts composition at syllable boundaries. An open PR (#320898) addresses it — keeping open pending review and merge.

## Change summary

Korean IME keystrokes are dropped or corrupted in the Markdown preview (and terminal/browserView) Cmd+F find box because focusFindBox() blur/refocus cycle aborts active IME composition.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/320898, which guards focusFindBox() during IME composition in SimpleFindWidget. The fix covers all three consumers (WebviewFindWidget, TerminalFindWidget, BrowserFindWidget).
