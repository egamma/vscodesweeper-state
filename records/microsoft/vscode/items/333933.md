# Issue #333933 — Terminal: empty rename does not restore dynamic tab title — stale staticTitle is never cleared

[https://github.com/microsoft/vscode/issues/333933](https://github.com/microsoft/vscode/issues/333933)

## Summary

Traced conclusively in current main: `_updateTitleProperties` in terminalInstance.ts returns early for an `undefined` title before reaching the `TitleEventSource.Api` branch that would clear `_staticTitle`, so an empty rename never clears the stale static title and the tab reverts to the old custom name on the next title update.

## Change summary

Renaming a terminal tab to an empty string is supposed to clear the static title and restore the dynamic title, but the stale `_staticTitle` is never cleared, so the custom name reappears on the next title event.

## Best solution

In `terminalInstance.ts`, have `_updateTitleProperties` (or `rename`) clear `_staticTitle` (and reset `_titleSource` to `Process`) when an empty/undefined title comes from `TitleEventSource.Api`, so later `refreshLabel` calls fall through to the dynamic template instead of the stale static title guard in `computeLabel`.
