## Summary

The original report (empty rename leaving a stale `_staticTitle` on the regular integrated terminal) was fixed and merged in commit 5ddf120 (PR https://github.com/microsoft/vscode/pull/336599, which explicitly says 'Fixes #333933'), but the issue was reopened because a VS Code collaborator confirmed the same symptom persists specifically for the default agent-host terminal created in the Agents window — a different code path this fix doesn't reach, so the issue must stay open.
