# Issue #336797 — Agent Host loses BYOK Custom Endpoint context limits: context usage hidden and 1M model compacted at 128K

[https://github.com/microsoft/vscode/issues/336797](https://github.com/microsoft/vscode/issues/336797)

## Summary

Already fixed on main: PR #336798 (merged as ff61d319) plumbs the BYOK model's independent maxPromptTokens/maxOutputTokens through the Agent Host bridge, replacing the previous maxContextWindowTokens-only path that produced the 0/0 metadata and 128K fallback described here.

## Change summary

For BYOK/Custom Endpoint models, the Agent Host loses the configured context window (maxInputTokens/maxOutputTokens become 0), hides the context-usage indicator, and silently compacts at a generic 128K budget instead of the configured window.

## Best solution

Keep the fix landed in commit ff61d31952aa3ca982afe61db10f530d5db0b38e (PR #336798): maxPromptTokens/maxOutputTokens now propagate from IByokLmModelInfo through ByokLmBridgeRegistry into CopilotAgent's model registration and resolveByokSessionConfig, so the Agent Host budgets on the configured window instead of falling back to 128K.
