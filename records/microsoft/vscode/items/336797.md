# Issue #336797 — Agent Host loses BYOK Custom Endpoint context limits: context usage hidden and 1M model compacted at 128K

[https://github.com/microsoft/vscode/issues/336797](https://github.com/microsoft/vscode/issues/336797)

## Summary

Already fixed: PR #336798 ("Fix context window display", merged the same day this issue was filed) adds `maxPromptTokens`/`maxOutputTokens` propagation through the BYOK bridge into the Agent Host, exactly the metadata path this report says was lost (Agent Host model entries getting `maxInputTokens: 0`/`maxOutputTokens: 0` and falling back to a 128K budget). The fix is present on current main.

## Change summary

BYOK / Custom Endpoint models with large context windows had their input/output token limits dropped when relayed to the Agent Host, causing a hardcoded 128K fallback and a hidden context-usage indicator.

## Best solution

Keep the shipped fix — commit ff61d31952aa3ca982afe61db10f530d5db0b38e (PR #336798) — which threads `maxPromptTokens`/`maxOutputTokens` (in addition to `maxContextWindowTokens`) from `byokLmBridgeRegistry.ts` through `copilotAgent.ts` and `copilotSessionLauncher.ts` to the Agent Host model registration.
