# Issue #336797 — Agent Host loses BYOK Custom Endpoint context limits: context usage hidden and 1M model compacted at 128K

[https://github.com/microsoft/vscode/issues/336797](https://github.com/microsoft/vscode/issues/336797)

## Summary

This is the same root cause as microsoft/vscode#332995, fixed by PR #336798 (merged as commit ff61d31952aa3ca982afe61db10f530d5db0b38e, shipped in milestone 1.139.0) — the Agent Host BYOK bridge previously sent only a computed `maxContextWindowTokens` and dropped the model's independent `maxInputTokens`/`maxOutputTokens`, which is exactly the reported 0/0 metadata loss and 128K compaction fallback.

## Change summary

Configured BYOK/Custom Endpoint context limits (e.g. a 1M-token window) are lost on the Agent Host side, which falls back to a 128K budget, hides the context-usage indicator, and silently compacts far too early.

## Best solution

Keep the shipped fix — `agentHostByokLmHandler.ts` now sends `maxPromptTokens` and `maxOutputTokens` alongside `maxContextWindowTokens` (via `getModelContextWindowTotal`) to the Agent Host BYOK model registry, so configured limits propagate correctly. Ask reporters to confirm on a build containing 1.139.0 / commit ff61d31952aa3ca982afe61db10f530d5db0b38e.
