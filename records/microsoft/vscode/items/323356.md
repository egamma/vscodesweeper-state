# Issue #323356 — Unused variables,functions,imports are not highlighted

[https://github.com/microsoft/vscode/issues/323356](https://github.com/microsoft/vscode/issues/323356)

## Summary

Confirmed JavaScript highlighting regression beginning in 1.126.0 and reportedly persisting in 1.129.0. Keep this canonical issue open and route it to the JavaScript area for investigation.

## Change summary

Unused JavaScript variables, functions, and imports no longer receive the expected faded decoration.

## Best solution

Identify whether the regression is in TypeScript diagnostic tagging or the editor's unnecessary-code decoration pipeline, then restore unused-code fading without changing diagnostic behavior.
