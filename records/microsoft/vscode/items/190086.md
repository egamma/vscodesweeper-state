# Issue #190086 — notebook.output.wordWrap does not seem to affect outputs from all Magics

[https://github.com/microsoft/vscode/issues/190086](https://github.com/microsoft/vscode/issues/190086)

## Summary

Still present on main: the built-in notebook-renderers extension only applies the `word-wrap` CSS class for stream, plaintext, and error outputs — JSON outputs (like those from `%lsmagic`) never get the class toggled, so `notebook.output.wordWrap` has no effect on them.

## Change summary

The `notebook.output.wordWrap` setting does not apply word-wrapping to JSON/non-text notebook outputs (e.g. from Jupyter magics like `%lsmagic`).

## Best solution

In `extensions/notebook-renderers/src/index.ts`, either add a dedicated `application/json` case that renders as text with the `word-wrap` class, or apply the `word-wrap` class toggle more broadly (e.g. in the default/fallback path or on the output element itself for all mime types that produce text-like content).
