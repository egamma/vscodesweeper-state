# Issue #135114 — Add `editor.contentLeftPadding` to add padding between the `editorGutter` and `editor`.

[https://github.com/microsoft/vscode/issues/135114](https://github.com/microsoft/vscode/issues/135114)

## Summary

This remains a valid, highly supported Backlog feature request. Current main exposes only vertical editor padding, while the available gutter-width workaround does not provide the requested clickable content padding.

## Change summary

Add configurable left padding between the editor gutter and text, with clicks in that padding placing the cursor at the beginning of the line.

## Best solution

Extend the editor padding option and layout calculations with left padding, then make the mouse-target logic treat that region as content column 1. Preserve existing layout by defaulting it to zero.
