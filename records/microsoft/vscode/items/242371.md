# Issue #242371 — Support local hyperlink ansi escapes in the integrated terminal

[https://github.com/microsoft/vscode/issues/242371](https://github.com/microsoft/vscode/issues/242371)

## Summary

Fixed on main and shipped in 1.105.0: OSC 8 hyperlinks with `file://` scheme now properly open in VS Code via the TerminalUrlLinkOpener, which delegates file:// URIs to the local file/folder openers.

## Change summary

Ctrl+Click on OSC 8 hyperlinks with `file:///` URLs in the integrated terminal did nothing — only http/https links worked.

## Best solution

Keep the shipped fix from commit ceb07bd32d4 (1.105.0). The TerminalUrlLinkOpener now handles `file://` scheme OSC 8 hyperlinks by delegating to the local file/folder opener. No further change needed.
