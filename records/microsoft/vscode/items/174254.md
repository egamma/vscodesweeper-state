# Issue #174254 — Diff Editor: indicate whether there are more diffs above or below the current diff

[https://github.com/microsoft/vscode/issues/174254](https://github.com/microsoft/vscode/issues/174254)

## Summary

The ordinary diff editor still lacks an explicit first/last-change indication near the changed lines. Keep this accepted Backlog request open for a compact design that addresses the maintainer's concern about added spacing and clutter.

## Change summary

Clearly indicate when no further changes exist above or below the current change in the diff editor.

## Best solution

Provide a compact, accessible first/last-change cue in the ordinary diff editor without inserting extra space between lines. Preserve existing wraparound navigation and avoid adding markers around every change.
