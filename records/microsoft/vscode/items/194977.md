# Issue #194977 — Cursor moving left when typing brackets

[https://github.com/microsoft/vscode/issues/194977](https://github.com/microsoft/vscode/issues/194977)

## Summary

Verified duplicate: the diagnostic log identifies the longstanding AltGr/X11 defect already tracked by the open canonical issue. Consolidating there preserves this report's concrete keyboard-event evidence.

## Change summary

Typing an opening bracket with AltGr on Linux incorrectly invokes cursor-left before inserting the bracket.

## Best solution

Fix the AltGr event translation under X11 in https://github.com/microsoft/vscode/issues/24783 so it no longer emits ArrowLeft; retain `keyboard.dispatch: keyCode` only as a workaround.
