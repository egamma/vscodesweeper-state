# Issue #194977 — Cursor moving left when typing brackets

[https://github.com/microsoft/vscode/issues/194977](https://github.com/microsoft/vscode/issues/194977)

## Summary

The reporter's keyboard trace identifies the same AltGr-triggered cursor-left movement already tracked by an older, verified open issue. Consolidate there, preserving the Linux version details and confirmation that the default dispatch mode still fails.

## Change summary

Typing opening brackets on Linux moves the cursor left before inserting the character.

## Best solution

Resolve AltGr being dispatched as cursorLeft under https://github.com/microsoft/vscode/issues/24783, which owns the same observable defect. Keep keyboard.dispatch = keyCode documented as a workaround, not a completed fix.
