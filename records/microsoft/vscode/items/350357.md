# Issue #350357 — Agent feedback: every comment change disposes and recreates every comment widget in the editor

[https://github.com/microsoft/vscode/issues/350357](https://github.com/microsoft/vscode/issues/350357)

## Summary

The full widget teardown remains directly reproducible from current source: one feedback change recreates every group, adding rendering work and discarding expansion state. The related batching work reduces event frequency but does not fix this per-event defect.

## Change summary

Preserve unchanged editor comment widgets when another feedback group changes, avoiding unnecessary recreation and loss of interaction state.

## Best solution

Unchanged comment groups should retain their widget instances, expansion and composer focus across feedback updates; only changed or removed groups should require replacement or disposal. Keep existing grouping, navigation and draft-restoration behavior intact.
