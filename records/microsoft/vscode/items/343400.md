# Issue #343400 — Multi Diff Editor: Add option to show unchanged regions

[https://github.com/microsoft/vscode/issues/343400](https://github.com/microsoft/vscode/issues/343400)

## Summary

The requested per-view override remains missing: the multi-diff implementation forces unchanged-region hiding, and its opening options expose no override. Route this extension-authoring request to the editor area; existing expansion commands do not cover the requested persistent behavior across commit navigation.

## Change summary

Allow an extension's multi-diff viewer to display unchanged regions and unchanged files without changing the user's global diff settings.

## Best solution

Define an editor-scoped option that lets callers retain unchanged content throughout commit navigation while preserving current defaults for other multi-diff viewers. Specify unchanged-file visibility alongside region expansion, since both are necessary for the reporter's workflow.
