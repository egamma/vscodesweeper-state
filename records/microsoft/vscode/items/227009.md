# Issue #227009 — Support reverse search in tree find

[https://github.com/microsoft/vscode/issues/227009](https://github.com/microsoft/vscode/issues/227009)

## Summary

Keep open: tree find still lacks the exclusion matching supported by the Debug Console filter. The source indicates that “reverse search” means inverted matching rather than backward navigation; this team-authored request remains actionable, with its user-facing semantics to settle.

## Change summary

Support exclusion or inverted matching in tree find so the Debug Console can eventually consolidate its separate filter and find controls.

## Best solution

Provide exclusion matching through the shared tree-find surface while preserving ordinary matching and the Debug Console's existing filtering behavior. Treat removal of the separate Debug Console filter as a follow-up requiring demonstrated feature parity.
