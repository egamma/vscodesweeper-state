# Issue #292389 — Allow users to close out of walkthrough widget on welcome page

[https://github.com/microsoft/vscode/issues/292389](https://github.com/microsoft/vscode/issues/292389)

## Summary

The welcome-page walkthrough card still has no dismissal control; existing walkthrough-hiding controls belong to a different welcome surface. Keep this team-authored request open: no verified canonical or completed implementation covers it.

## Change summary

Allow users to dismiss the walkthrough card without closing the Agent Sessions Welcome page.
