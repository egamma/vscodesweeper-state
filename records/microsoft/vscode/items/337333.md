# Issue #337333 — Dictation first-run experience does not clearly indicate model download

[https://github.com/microsoft/vscode/issues/337333](https://github.com/microsoft/vscode/issues/337333)

## Summary

Keep open: current source still separates model-download feedback from the first-run waveform, leaving the reported discoverability gap. Existing microphone progress and accessibility notifications do not cover the requested in-context indication.

## Change summary

Make model downloading apparent within the first-run Dictation waveform section so users know transcription is not ready.

## Best solution

The Dictation introduction should clearly distinguish model preparation from readiness to transcribe where the user's attention is focused, while preserving existing microphone progress and accessible notifications. The likely owning surface is DictationOnboardingBanner in the chat speech-to-text contribution.
