# Issue #250622 — Model of a custom editor URI is never cleared

[https://github.com/microsoft/vscode/issues/250622](https://github.com/microsoft/vscode/issues/250622)

## Summary

Confirmed still present on main: when a custom editor model creation promise rejects, the entry remains in `CustomEditorModelManager._references` permanently, causing all subsequent open attempts for that URI to replay the rejection.

## Change summary

Custom editor model entries are never removed from the model cache when the model creation promise rejects, permanently locking out the URI.

## Best solution

In `CustomEditorModelManager.add()` or in `getOrCreateCustomEditorModel`, attach a `.catch` to the model promise that removes the entry from `_references` if creation fails, so subsequent attempts get a fresh creation cycle.
