# Issue #73111 — Add a button to open Find All References from Peek References

[https://github.com/microsoft/vscode/issues/73111](https://github.com/microsoft/vscode/issues/73111)

## Summary

Keep open: the references peek still lacks an action to open its results in the References view. Existing commands and the preferred-location setting provide alternative entry points, but do not cover the requested peek-first workflow.

## Change summary

Add a button to open the current Peek References results in the full References view without changing the default CodeLens presentation.

## Best solution

Provide a discoverable action in the references peek header that opens references for the original symbol in the References view, while preserving the user's peek default. Establish the editor-to-built-in-extension handoff and whether promotion retains or closes the peek before implementation.

- **Behavior:**
