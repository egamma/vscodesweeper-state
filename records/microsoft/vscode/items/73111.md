# Issue #73111 — Add a button to open Find All References from Peek References

[https://github.com/microsoft/vscode/issues/73111](https://github.com/microsoft/vscode/issues/73111)

## Summary

A real gap remains: current main supports choosing Peek or View globally, but provides no action for promoting an already-open references peek into the References view. This is already correctly routed and accepted into the Backlog.

## Change summary

Add a Peek References toolbar action that opens the same search in the full References view.

## Best solution

Add a header action to the references peek that transfers its current query or resolved locations to the built-in References view, avoiding a second manual search. The bridge likely spans the editor references controller and the built-in references-view extension.

- **Fit:** aligned
- **Reason:** A consistent transition between two built-in representations of the same reference search advances core workbench UX without adding broad default surface.
