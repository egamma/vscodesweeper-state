# Issue #169871 — Git - Message Box on git commit errors is too short

[https://github.com/microsoft/vscode/issues/169871](https://github.com/microsoft/vscode/issues/169871)

## Summary

The Git error dialog still reduces multiline hook output to a single line, which can hide the actual commit failure. Keep this open while the existing linked fix PR is reviewed; it has not merged.

## Change summary

Show meaningful multiline diagnostics directly in the Git commit failure dialog instead of an isolated, potentially misleading output line.

## Best solution

Review https://github.com/microsoft/vscode/pull/244052 against the current Git error-handling code and settle an appropriately bounded multiline presentation. Preserve access to the complete command output and Git log.
