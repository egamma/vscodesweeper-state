# Issue #311029 — Agents: Session scoping

[https://github.com/microsoft/vscode/issues/311029](https://github.com/microsoft/vscode/issues/311029)

## Summary

Keep this team-authored session-scoping request open: current workspace synchronization does not establish that reusing a local session for a cloud repository updates its scope or changes its commit workflow. The maintainer's request for the exact transition steps remains unanswered, and no qualifying fix or canonical duplicate was verified.

## Change summary

Keep the Files view and repository workflow consistent with the repository an agent actually works on when a user reuses a session across local and cloud contexts.

## Best solution

Establish the supported local-to-cloud transition in the Agents Window, then ensure the displayed workspace and repository actions match that context. A maintainer should first clarify how the participant changed repositories and whether this should retarget the existing session or start a separate cloud session.
