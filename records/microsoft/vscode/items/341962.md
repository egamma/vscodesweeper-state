# Issue #341962 — Copilot harness tool-control regression: missing Local-style Configure Tools picker and per-tool MCP toggles

[https://github.com/microsoft/vscode/issues/341962](https://github.com/microsoft/vscode/issues/341962)

## Summary

Thanks for the detailed report. The Customizations tools list on main still shows toggles only for server rows, and the connected MCP child-tool rows are not expandable and have no toggle. A Copilot-harness Configure Tools picker and per-tool MCP filtering are real gaps, so this stays open as a feature request.

## Change summary

Add a Local-style Configure Tools picker to the Copilot harness chat input, and allow individual MCP tools to be enabled or disabled.

## Best solution

Give the Copilot harness a searchable tools picker next to the chat input with group and per-tool toggles. Support per-tool MCP filtering in the Customizations tools list, and make sure disabled tools are excluded from the session's tool catalog. Coordinate with the broader Local/Copilot tool-parity issue (#340041).
