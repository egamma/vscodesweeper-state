# Issue #341962 — Copilot harness tool-control regression: missing Local-style Configure Tools picker and per-tool MCP toggles

[https://github.com/microsoft/vscode/issues/341962](https://github.com/microsoft/vscode/issues/341962)

## Summary

Keep open: current source still exposes only server-level toggles for connected MCP tools, and the documented Copilot workflow does not provide the requested conversation-specific picker. This is a tool-selection parity request, rather than a demonstrated failure of an existing Copilot per-tool control.

## Change summary

Provide an input-adjacent Copilot tool picker with individual MCP tool filtering and clearly defined selection scope and persistence.

## Best solution

Provide task-specific tool selection that supports individual connected MCP tools and excludes deselected tools from the model-facing catalog and tool search. Define how these selections interact with profile defaults and when changes take effect before implementing the UI and runtime integration.
