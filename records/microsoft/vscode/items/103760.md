# Issue #103760 — Snap: Wrong icons in file picker

[https://github.com/microsoft/vscode/issues/103760](https://github.com/microsoft/vscode/issues/103760)

## Summary

Still present on main: the snap packaging explicitly strips /usr/share/icons from the prime step and has no icon theme passthrough — GTK file picker icons remain broken for snap users. The `help wanted` label is appropriate.

## Change summary

GTK file picker shows wrong/missing icons when VS Code is installed via snap because the snap environment lacks access to system icon themes.

## Best solution

Add icon theme support to the snap packaging: either include a minimal icon theme (e.g. hicolor/Adwaita subset) in the snap, or configure the electron-launch script to expose the host's icon theme via XDG_DATA_DIRS pointing to the host's /usr/share/icons (similar to how fonts are handled). The fix belongs in `resources/linux/snap/`.
