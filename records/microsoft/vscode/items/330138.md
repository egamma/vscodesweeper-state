# Issue #330138 — Agent stops early after creating a session

[https://github.com/microsoft/vscode/issues/330138](https://github.com/microsoft/vscode/issues/330138)

## Summary

Team-authored bug with a real assigned milestone (1.134.0) — the hard keep-open rule applies regardless of evidence strength, so no close is proposed here.

## Change summary

After the create_session tool runs, the model's canned confirmation reply ('Reply with one short sentence...') causes some models (e.g. gpt-5.6 Sol) to treat the turn as finished and stop doing further requested work.

## Best solution

Revisit the create_session tool-result prompt in formatCreateSessionResult (src/vs/platform/agentHost/node/shared/sessionServerTools.ts:623) so the instruction to give a short confirmation doesn't read as 'end of turn' to more literal-following models — likely needs prompt wording iteration and cross-model evaluation rather than a mechanical code fix.
