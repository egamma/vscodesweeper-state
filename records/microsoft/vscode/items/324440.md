# Issue #324440 — Got a big search bar.

[https://github.com/microsoft/vscode/issues/324440](https://github.com/microsoft/vscode/issues/324440)

## Summary

The terminal icon picker appears to render incorrectly (as an oversized search bar) when the terminal is in a separate window. No duplicate found, and the report has clear reproduction steps and a screenshot. Routing to the terminal area for investigation.

## Change summary

Right-clicking a terminal tab and selecting 'Choose Icon' in a separate window shows an oversized search bar instead of the compact icon picker.

## Best solution

Investigate the `TerminalIconPicker` hover-widget positioning in auxiliary windows — the layout in `terminalIconPicker.ts` uses `getActiveDocument().body` and `_layoutService.activeContainerOffset`, which may not behave correctly when the terminal is in a separate/auxiliary window, causing the icon grid to not render or the hover to stretch.
