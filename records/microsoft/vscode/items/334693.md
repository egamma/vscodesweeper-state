# Issue #334693 — Turn changes believes upstream changes were done by the agent

[https://github.com/microsoft/vscode/issues/334693](https://github.com/microsoft/vscode/issues/334693)

## Summary

The older, open report tracks the same observable problem: updating a stale branch during an agent turn makes upstream changes appear as Turn Changes. Consolidate this report there, preserving the existing-folder details.

## Change summary

Turn Changes attributes upstream changes brought into a stale checkout to the agent's turn.

## Best solution

Consolidate the upstream-update attribution problem in https://github.com/microsoft/vscode/issues/327999. Turn Changes should distinguish imported upstream changes from the agent's own edits without losing genuine edits made through terminal tools.
