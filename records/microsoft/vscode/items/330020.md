# Issue #330020 — Chat sticky scroll: Expect mention of attachment rather than `(empty prompt)`

[https://github.com/microsoft/vscode/issues/330020](https://github.com/microsoft/vscode/issues/330020)

## Summary

Confirmed in source: the new prompt-timeline sticky header's preview text only reads `messageText` and falls back to a generic '(empty prompt)' string, whereas sibling surfaces (chat outline, accessibility label, list renderer) already fall back to `getExplicitFileOrImageAttachmentSummary` for attachment-only prompts — this is a small, easily-fixed gap in a brand-new feature.

## Change summary

Sticky scroll header shows '(empty prompt)' for a prompt that has only an image/file attachment and no text, instead of describing the attachment.

## Best solution

In src/vs/workbench/contrib/chat/browser/promptTimeline/promptTimelineModel.ts, have `getPromptPreview`/`_recompute` fall back to `getExplicitFileOrImageAttachmentSummary(item.variables)` (from common/attachments/chatVariableEntries.ts) before falling back to the generic empty-prompt string, mirroring chatOutline.ts and chatAccessibilityProvider.ts.
