# Issue #349766 — Folder Location restores the previously selected canvas as a background tab

[https://github.com/microsoft/vscode/issues/349766](https://github.com/microsoft/vscode/issues/349766)

## Summary

Keep open: the editor-window working-set suspension retains the canvas but does not capture its active-tab state, so restoration explicitly opens it inactive. This is a source-confirmed restoration defect, not lost canvas content.

## Change summary

Returning to a folder location should restore its previously selected canvas as the active tab rather than select a text file.

## Best solution

Preserve canvas selection across editor-window folder-location round trips in CanvasService, while retaining focus-preservation behavior and keeping previously inactive or background canvases inactive.
