# Issue #119047 — [themes] use both English and UI language to search color theme names

[https://github.com/microsoft/vscode/issues/119047](https://github.com/microsoft/vscode/issues/119047)

## Summary

The localization gap remains relevant: users cannot reliably filter localized theme names using familiar English terms, and a later comment confirms the broader problem in localized Quick Open results. The request should remain open for a product decision rather than being retired for age.

## Change summary

Match color themes by both their localized display names and English names in Quick Open.

## Best solution

Define a consistent Quick Pick search policy that retains localized labels while adding English aliases for built-in theme names, then consider whether the same alias mechanism should cover other localized Quick Open providers such as `workbench.action.openView`.
