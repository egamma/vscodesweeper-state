# Issue #336918 — Chat: bare URLs are linkified together with the text that directly follows them

[https://github.com/microsoft/vscode/issues/336918](https://github.com/microsoft/vscode/issues/336918)

## Summary

Traced to a real defect in the vendored GFM autolink tokenizer in src/vs/base/common/marked/marked.js: the `url` rule's `[^\s<]*` tail and the `_backpedal` cleanup only strip trailing ASCII punctuation, so a bare URL immediately followed by non-whitespace text (letters, CJK characters, etc., with no separating space) gets swallowed into the link. Kept open, not closed, since the fix requires a maintainer call on how to patch a vendored third-party library.

## Change summary

When Copilot chat renders a bare URL that is directly followed by text with no whitespace in between, the trailing text gets included in the generated hyperlink instead of being left as plain text.

## Best solution

Tighten the GFM `url` autolink boundary (or the `_backpedal` trim) in src/vs/base/common/marked/marked.js so a URL match stops at a word/script boundary rather than consuming any adjacent non-whitespace run; alternatively pull in an upstream marked.js release that already fixes this extended-autolink edge case, since this file is a vendored copy used by hovers, notebooks, and chat, not just this one surface.

## Evidence

- **source trace:** src/vs/base/common/marked/marked.js:1215 defines `url: /^((?:ftp|https?):\/\/|www\.)(?:[a-zA-Z0-9\-]+\.?)+[^\s<]*|^email/i`; the trailing `[^\s<]*` matches any non-whitespace run after the domain.
- **backpedal is insufficient:** marked.js:1218 `_backpedal` only strips trailing ASCII punctuation (`?!.,:;*_'"~()&`); it does not stop at a word boundary or non-ASCII text, so adjacent letters/CJK characters stay part of the match.
- **reproduced the regex path:** Ran the exact regex/backpedal pair from marked.js against the string 'https://example.com这是中文文字' outside the app (no repo modification) — the match after backpedal is the full string including the trailing CJK text, confirming the URL and following text get linkified together.
- **vendored, unmodified upstream code:** git log shows no recent targeted commits to src/vs/base/common/marked/marked.js; this is the same extended-autolink boundary logic shipped upstream in the marked library.
