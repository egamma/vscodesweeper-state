## Summary

Still open on main: PolicyValue is typed as `string | number | boolean` with no object support, and FilePolicyService does not handle JSON object values from policy.json. The debt remains unaddressed.

## Change summary

Support native JSON objects (not just stringified JSON) in Linux policy.json for object-type configuration settings.

## Best solution
