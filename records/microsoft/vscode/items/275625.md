## Summary

Team-authored bug that remains unresolved — the first character dropped when copilot sends commands to Git Bash is still reported (May 2026) even after ConptyDll 1.25 was enabled as default. No fix commit references this issue. Keeping open for continued investigation.

## Change summary

The run_in_terminal tool drops the first character of commands sent to a Git Bash terminal on Windows.

## Best solution

Investigate the interaction between terminal input delivery and Git Bash's readiness after terminal creation or resize. The conpty dll upgrade (cfebe6aeafb) didn't resolve it. The logging added in e955f18c756 ("Add logs around early terminal input") may help diagnose the timing — consider whether a brief delay or readiness check is needed before writing data to a newly created Git Bash instance. The resize/focus variant reported by garretwilson may share the same root cause.
