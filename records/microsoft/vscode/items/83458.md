# Issue #83458 — [folding] Improve #region support: make it look like Visual Studio IDE

[https://github.com/microsoft/vscode/issues/83458](https://github.com/microsoft/vscode/issues/83458)

## Summary

The requested region-specific collapsed title and hover preview remain absent on current main. The issue is an accepted Backlog feature request, and no older issue owns the same complete user-visible behavior.

## Change summary

Render collapsed named regions as compact titled boxes and show the region's hidden code in a hover preview.

## Best solution

Design a consistent folded-region presentation that can display the region name without its marker and offer an accessible preview of hidden content, while preserving ordinary folding behavior and avoiding a language-specific implementation.

## Plan brief

- **Likely files:** `src/vs/editor/contrib/folding/browser/folding.ts`, `src/vs/editor/contrib/folding/browser/foldingDecorations.ts`, `src/vs/editor/contrib/folding/browser/folding.css`, `src/vs/editor/contrib/folding/test/browser/foldingModel.test.ts`
- **Validation:** Collapse named regions in JavaScript and C#, verify the marker is replaced by a compact accessible title presentation, hover it to preview the hidden range, and confirm ordinary folds retain their existing rendering and interaction; add focused editor tests for the selected folded-display model.
- **Behavior:**

  > When a named region is collapsed, the editor presents its name as a compact, recognizable folded-region title rather than leaving the raw region marker followed by an ellipsis. Hovering that collapsed presentation exposes a readable preview of the hidden code without expanding or moving the editor viewport. Keyboard and screen-reader users must be able to identify and expand the region, and non-region folds must preserve their current appearance and behavior.
- **Trace:**

  > Current collapsed rendering is uniform: FoldingDecorationProvider in src/vs/editor/contrib/folding/browser/foldingDecorations.ts attaches the `inline-folded` class and a generic gutter tooltip to every collapsed range, while src/vs/editor/contrib/folding/browser/folding.css supplies a fixed ellipsis. FoldingController in src/vs/editor/contrib/folding/browser/folding.ts tracks range kinds and hidden ranges but does not expose region names to a specialized collapsed renderer or hover participant. The older https://github.com/microsoft/vscode/issues/70794 tracks generalized provider-defined folded text and is a likely prerequisite, while https://github.com/microsoft/vscode/issues/146952 was closed by a maintainer as a duplicate of this issue. The design boundary is the collapsed presentation and preview: ordinary folding ranges, folding commands, and language-specific region detection should not change.
- **Open decisions:**
  - Should the titled presentation apply only to recognized region ranges, or should it be the first consumer of generalized provider-defined folded text from https://github.com/microsoft/vscode/issues/70794?
  - What portion of hidden content should the hover preview show, and how should large regions be bounded?
  - Should this presentation replace the raw region-marker line entirely or retain part of that line alongside the title?
  - What keyboard and screen-reader interaction should expose the same preview information available on pointer hover?

## Evidence

- **current source:** src/vs/editor/contrib/folding/browser/foldingDecorations.ts assigns every collapsed range the same `inline-folded` after-content decoration and only provides the gutter tooltip “Click to expand the range.”
- **current rendering:** src/vs/editor/contrib/folding/browser/folding.css hardcodes the collapsed placeholder to an ellipsis; there is no region-title box or hidden-code preview.
- **configuration gap:** src/vs/editor/common/config/editorOptions.ts exposes folding strategy, highlights, controls, limits, and click behavior, but no folded-region display or preview option.
- **related prerequisite:** https://github.com/microsoft/vscode/issues/70794 is an older open request for provider-defined folded text and discusses Visual Studio region rendering, but it is an API/general-folding request and does not own this issue's complete region-specific presentation and hover-preview behavior.
- **canonical status:** A maintainer closed https://github.com/microsoft/vscode/issues/146952 as a duplicate of this issue and explicitly described https://github.com/microsoft/vscode/issues/70794 as a dependency, supporting this issue's role as the canonical visual-region request.
- **related issues differ:** https://github.com/microsoft/vscode/issues/3352 concerns placing closing braces on the collapsed line, while https://github.com/microsoft/vscode/issues/40048 concerns minimap previews; neither owns the same observable behavior.
