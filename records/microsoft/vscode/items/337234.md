# Issue #337234 — New Session pane is not rendered - TypeError: Cannot read properties of undefined (reading 'removeToolFromConfirmationCarousel')

[https://github.com/microsoft/vscode/issues/337234](https://github.com/microsoft/vscode/issues/337234)

## Summary

Confirmed on current main: the new-session pane still fails to render because ChatListItemRenderer.addModelToolConfirmation's disposer resolves `widget.inputPart` (a non-null-asserted getter over `inputPartDisposable.value`) after the input part has already been torn down during session switch, throwing the exact reported TypeError. No fix has landed on main despite sandy081's diagnosis comment — no commit references this issue or touches the relevant getters.

## Change summary

Creating a new session in the Agents Window after being idle throws an unhandled TypeError during the outgoing chat widget's disposal, leaving the new session pane unrendered.

## Best solution

Capture the owning ChatInputPart when the confirmation carousel entry is added in ChatListItemRenderer.addModelToolConfirmation, and use that captured reference (not the widget.inputPart getter) in the cleanup disposable, so removal doesn't depend on the widget still holding a live input part during disposal.
