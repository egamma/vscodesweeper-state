# Issue #337234 — New Session pane is not rendered - TypeError: Cannot read properties of undefined (reading 'removeToolFromConfirmationCarousel')

[https://github.com/microsoft/vscode/issues/337234](https://github.com/microsoft/vscode/issues/337234)

## Summary

Confirmed on current main: `addModelToolConfirmation` in `chatListRenderer.ts` captures `widget` and later dereferences `widget.inputPart` in its disposal callback, but during an Agents Window session switch the widget's input-part is torn down before the renderer, so the getter yields `undefined` and throws mid-disposal, leaving the new session pane unrendered. Milestone 1.140.0 is assigned and a maintainer (sandy081) already diagnosed the exact fix and wrote a regression test, so this stays open pending that change landing.

## Change summary

Creating a new Agents Window session after being idle throws during disposal cleanup and the new session pane fails to render (workaround: switch to another session first).

## Best solution

Land the fix sandy081 already scoped: capture the `ChatInputPart` instance alongside the carousel entry in `addModelToolConfirmation` and use that captured reference for `removeToolFromConfirmationCarousel` instead of re-resolving `widget.inputPart` during disposal, plus the regression test simulating the disposal ordering.
