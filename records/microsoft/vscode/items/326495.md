# Issue #326495 — Regression: Panel tabs use wrong capitalization

[https://github.com/microsoft/vscode/issues/326495](https://github.com/microsoft/vscode/issues/326495)

## Summary

Confirmed on current main: fontRamp.css still forces `text-transform: capitalize` on panel/composite-bar titles, corrupting locale casing like French "Console de débogage" into "Console De Débogage" — but an open PR already targets exactly this fix, so the issue stays open pending that merge.

## Change summary

Enabling the experimental modern UI forces title-case on panel tab labels, breaking correctly-cased localized strings (e.g. French sentence case).

## Best solution

Land https://github.com/microsoft/vscode/pull/326851 ("Preserve localized casing in panel tabs"), which removes/adjusts the forced `text-transform: capitalize` rule while keeping the modern UI font-size override; once merged this issue can close as completed.
