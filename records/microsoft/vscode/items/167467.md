# Issue #167467 — Diff Editor: Support Go To Line In Original Text Editor

[https://github.com/microsoft/vscode/issues/167467](https://github.com/microsoft/vscode/issues/167467)

## Summary

Original-side line navigation remains unsupported by the current Go to Line command. Keep this accepted accessibility request open; the remaining product decision is how to identify the target side without unexpectedly changing the established modified-side behavior.

## Change summary

Allow keyboard and screen-reader users to navigate directly to a numbered line in the original side of a diff editor.

## Best solution

Provide discoverable, keyboard-accessible original-side line navigation with an unambiguous target and matching screen-reader feedback. Agree on whether Ctrl+G follows the previously focused side or original-side navigation is explicitly selected, while preserving ordinary editor navigation.
