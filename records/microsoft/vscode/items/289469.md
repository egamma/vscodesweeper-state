# Issue #289469 — Allow me to redirect a URI to another URI in the Content Provider

[https://github.com/microsoft/vscode/issues/289469](https://github.com/microsoft/vscode/issues/289469)

## Summary

Valid feature request from a team member: the ChatSessionContentProvider API lacks a mechanism to redirect/remap a URI during session resolution. No implementation exists on main; the ChatSession interface and ChatSessionContentProvider have no redirect or resolvedUri support.

## Change summary

Allow a ChatSessionContentProvider to redirect an incoming URI (e.g. `claude-code://untitled-<guid>`) to a different canonical URI (e.g. `claude-code://<session-id>`) during session resolution.

## Best solution

Add a `uri` or `resolvedUri` property to the `ChatSession` return type (or a separate resolve step in `ChatSessionContentProvider`) so providers can remap an untitled URI to a meaningful session URI. The proposed API lives in `src/vscode-dts/vscode.proposed.chatSessionsProvider.d.ts`; plumbing goes through `src/vs/workbench/api/common/extHostChatSessions.ts` and `src/vs/workbench/api/browser/mainThreadChatSessions.ts`.
