# Issue #289469 — Allow me to redirect a URI to another URI in the Content Provider

[https://github.com/microsoft/vscode/issues/289469](https://github.com/microsoft/vscode/issues/289469)

## Summary

Keep open: the content-provider return contract still cannot replace the URI being resolved. Existing session-creation and commit mechanisms provide related capabilities, but do not establish that resolution-time redirection is covered; this team-authored request needs an API lifecycle decision.

## Change summary

Allow a chat session content provider to replace an untitled URI with the backend session URI obtained while resolving its content.

## Best solution

Define how a content provider establishes the authoritative session URI when backend creation occurs during content resolution, preserving editor state and session identity. Reconcile that contract with the existing controller creation and commit mechanisms rather than introducing competing identity lifecycles.
