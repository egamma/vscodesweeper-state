# Issue #295284 — MCP servers should be able to be securely updated.

[https://github.com/microsoft/vscode/issues/295284](https://github.com/microsoft/vscode/issues/295284)

## Summary

Verified duplicate: the older open maintainer-authored https://github.com/microsoft/vscode/issues/271137 tracks MCP metadata version updates, including the registry-backed update behavior requested here.

## Change summary

Notify users when a registry-installed MCP server has a newer version or endpoint and let them apply that update under explicit user control.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/271137 and implement registry-backed update detection and an explicit update action there, preserving pinned versions until the user approves the replacement configuration.
