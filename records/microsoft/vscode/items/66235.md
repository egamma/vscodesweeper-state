# Issue #66235 — Allow more powerful onEnterRules for cursor alignment

[https://github.com/microsoft/vscode/issues/66235](https://github.com/microsoft/vscode/issues/66235)

## Summary

Still an open gap — onEnterRules lack capture-group transforms or any dynamic appendText mechanism. The feature is team-authored, has 48 upvotes, and sits in Backlog with no implementation on main. Two related open issues (#17281 for capture groups, #208985 for treesitter-based rules) are complementary but neither subsumes this request's full scope.

## Change summary

Allow onEnterRules to produce variable-length indentation via capture-group transforms or dynamic appendText, enabling proper PEP8-style alignment in Python and similar languages.

## Best solution

Implement capture-group support in onEnterRules (#17281) with snippet-style transforms (e.g. `${1/./ /g}`) as alexdima sketched — this would cover the core use case declaratively without making Enter async. Alternatively, a declarative indentation provider or treesitter-based rules (#208985) could subsume this. The work belongs in `src/vs/editor/common/languages/languageConfiguration.ts` and the onEnterRules evaluation path.
