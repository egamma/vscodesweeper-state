# Issue #331853 — Unbounded concurrent reads in prompt discovery exhaust file handles (EMFILE) and hang the window

[https://github.com/microsoft/vscode/issues/331853](https://github.com/microsoft/vscode/issues/331853)

## Summary

Verified on main: three discovery paths in promptsServiceImpl.ts fan out over every discovered file with unbounded Promise.all, matching the reported EMFILE/hang mechanism. The reporter has already opened a fix PR (#331855), so this stays open pending that PR's review/merge rather than being closed or auto-fixed.

## Change summary

Prompt/agent/skill/hook discovery reads all customization files concurrently with no concurrency bound, exhausting OS file handles (EMFILE) and hanging the window on profiles with many customization files.

## Best solution

Land the linked PR https://github.com/microsoft/vscode/pull/331855, which bounds the three unbounded Promise.all sites (computeSlashCommandDiscoveryInfo, computeAgentDiscoveryInfo, computeHooks) with a Limiter, consistent with existing usage elsewhere (e.g. agentService.ts's Limiter<boolean>(4)). The separate CachedPromise non-cancelling-invalidation issue is explicitly deferred by the reporter as follow-up work.
