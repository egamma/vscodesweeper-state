# Issue #206007 — Kernel picker spinner never stops

[https://github.com/microsoft/vscode/issues/206007](https://github.com/microsoft/vscode/issues/206007)

## Summary

The kernel picker spinner bug is still present on main — the detection task disposal in notebookKernelDetection.ts relies on `activationEventIsDone` returning true after `onDidChangeExtensionsStatus` fires, but if extension activation stalls or the status event doesn't fire, the spinner never stops. No fix commit found.

## Change summary

The notebook kernel picker spinner never stops even when kernels are available and cells can be executed.

## Best solution

Add a timeout or fallback in `NotebookKernelDetection` (src/vs/workbench/contrib/notebook/browser/contrib/kernelDetection/notebookKernelDetection.ts) so detection tasks are disposed after a reasonable deadline, even if `activationEventIsDone` never returns true. Also investigate whether `onDidChangeExtensionsStatus` reliably fires after all relevant extensions activate.
