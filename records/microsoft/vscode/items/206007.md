# Issue #206007 — Kernel picker spinner never stops

[https://github.com/microsoft/vscode/issues/206007](https://github.com/microsoft/vscode/issues/206007)

## Summary

Keep open as the established canonical report for kernel discovery indicators that continue spinning despite usable kernels. Related reports confirm the symptom, and current source inspection does not establish a fix or identify which discovery task fails to finish.

## Change summary

The notebook kernel picker continues showing discovery activity after a kernel is available and cells can execute.

## Best solution

Diagnose the outstanding discovery or source-action operation during notebook creation and kernel installation, then ensure the indicator returns to its idle state when that operation finishes. Preserve genuine discovery feedback and the ability to select and execute available kernels while discovery continues.
