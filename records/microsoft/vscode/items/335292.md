# Issue #335292 — Background subagent is not visible in the chat that spawned it

[https://github.com/microsoft/vscode/issues/335292](https://github.com/microsoft/vscode/issues/335292)

## Summary

Team-authored (MEMBER) bug report with a corroborating community comment; an open draft PR (#337620) explicitly references this issue and is actively working on related subagent-visibility/lifecycle fixes, but per its own description it targets only 'the restored/reused cases' and not the full missing-UI-surface ask, so this should stay open pending that PR landing and further UI work.

## Change summary

The chat that spawns a background subagent (via the `task` tool) shows no persistent status or link to the delegated work in its own transcript — only the Sessions sidebar and a hidden-by-default Subagents pill surface it.

## Best solution

Land https://github.com/microsoft/vscode/pull/337620 (currently draft) for the reuse/reconnect fixes, then extend the Subagents pill / inline session-result link so it also covers live background `task` subagents (not just `ChatOriginKind.Tool` children with a matching `parentChat`), per the author's own notes in the issue body.
