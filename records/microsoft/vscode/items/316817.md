# Issue #316817 — Long-running "Run Playwright Code" doesn't respect cancellation

[https://github.com/microsoft/vscode/issues/316817](https://github.com/microsoft/vscode/issues/316817)

## Summary

Keep open: the current tool explicitly ignores its cancellation token, and the execution service has no cancellation parameter. Long-running code is deferred rather than stopped, so the reported cancellation gap remains.

## Change summary

Canceling a chat turn should stop its long-running Run Playwright Code operation.

## Best solution

Provide cancellation through the browser tool's shared-process execution lifecycle, including deferred work, without closing the user's browser tab or disrupting unrelated operations. Establish how execution can actually be interrupted rather than merely abandoning its result.
