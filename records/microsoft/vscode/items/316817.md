# Issue #316817 — Long-running "Run Playwright Code" doesn't respect cancellation

[https://github.com/microsoft/vscode/issues/316817](https://github.com/microsoft/vscode/issues/316817)

## Summary

Confirmed in source: the RunPlaywrightCodeTool.invoke() method ignores the CancellationToken (parameter prefixed with `_`), and the IPlaywrightService.invokeFunction/waitForDeferredResult APIs don't accept a CancellationToken at all. The bug is real and unfixed on main.

## Change summary

Cancelling a chat turn does not stop a running "Run Playwright Code" tool invocation — the Playwright code continues executing.

## Best solution

Thread the CancellationToken through: (1) add a CancellationToken parameter to IPlaywrightService.invokeFunction and waitForDeferredResult, (2) in the node-side implementation, listen for cancellation and abort/kill the running Playwright execution, (3) in RunPlaywrightCodeTool.invoke(), pass the token to the service calls and handle cancellation errors.
