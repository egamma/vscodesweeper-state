# Issue #326804 — Copilot agent switches to Plan mode and can't switch back

[https://github.com/microsoft/vscode/issues/326804](https://github.com/microsoft/vscode/issues/326804)

## Summary

Verified duplicate: the older open canonical issue tracks the same failure where a conversation remains governed by Plan-only restrictions after implementation is approved, blocking edits and requiring a new chat or workaround.

## Change summary

Prevent an agent-initiated switch to Plan mode from leaving the conversation unable to return to an implementation-capable agent.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/311802 and ensure the Plan-to-Agent handoff changes the active mode before dispatching the implementation request, including when Plan was selected automatically by the agent.
