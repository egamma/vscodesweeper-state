# Issue #178686 — Reserved keybinding prefixes

[https://github.com/microsoft/vscode/issues/178686](https://github.com/microsoft/vscode/issues/178686)

## Summary

Keep open: user keybinding overrides do not provide the requested convention reserving a conflict-free namespace across core and extensions. The request is already correctly routed and accepted into Backlog; no verified older canonical or implementation was found.

## Change summary

Define and promote keybinding prefixes reserved for users, with conventions separating extension bindings from core bindings.

## Best solution

Have the keybindings owners assess whether a documented user-reserved namespace can coexist with existing shortcuts and variant keymaps, including whether the convention would be advisory or enforced. Existing override precedence should not be presented as equivalent to that ecosystem-wide guarantee.
