# Issue #337602 — Copilot Chat (1.139.0 / 0.67.0): Prompt prefix cache busted on turns 2+ for third-party prefix-caching models (Grok, DeepSeek)

[https://github.com/microsoft/vscode/issues/337602](https://github.com/microsoft/vscode/issues/337602)

## Summary

Already fixed on main: commit a20001ead23eb08d0c62e90bc54ef9fed394931e explicitly references this issue and gates explicit Responses-API prompt-cache breakpoints behind an opt-in setting for BYOK endpoints, restoring implicit caching (as in 1.138) unless the user explicitly enables github.copilot.chat.responsesApi.promptCacheBreakpoint.enabled.

## Change summary

Multi-turn chat with third-party BYOK prefix-caching models (Grok, DeepSeek via LiteLLM) got 0% cache hits on turns 2+ in 1.139.0/0.67.0, because explicit Responses API prompt caching (prompt_cache_breakpoint markers) was enabled by default and BYOK gateways silently drop those markers.

## Best solution

Keep the fix in commit a20001ead23 — BYOK OpenAIEndpoint subclasses now declare promptCacheBreakpointsRequireOptIn so explicit caching only activates when the user opts in via the setting; CAPI endpoints are unaffected.
