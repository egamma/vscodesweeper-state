# Issue #331317 — Initially-hidden file list is confusing

[https://github.com/microsoft/vscode/issues/331317](https://github.com/microsoft/vscode/issues/331317)

## Summary

Team-authored (connor4312, MEMBER) UX feedback from testing the sessions window: the way to reveal the Files view (a small icon in the top-right of the aux bar) isn't discoverable, so onboarding instructions to 'use the Files view' don't map to any obvious affordance.

## Change summary

First-run/onboarding guidance tells users to use the 'Files view' in the Agents Window, but the only way to open it is a small, unlabeled icon that isn't discoverable.

## Best solution

Improve discoverability of the Files view entry point in the sessions/Agents Window aux bar — e.g. a more prominent affordance, a label/tooltip, or contextual pointer the first time a session opens — likely touching src/vs/sessions/contrib/files/browser/files.contribution.ts and the session header/layout controller in src/vs/sessions/contrib/layout and src/vs/sessions/browser/parts/sessionHeader.ts.
