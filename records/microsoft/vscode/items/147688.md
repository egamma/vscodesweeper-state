# Issue #147688 — Adopt `LSItemContentTypes` over `CFBundleTypeOSTypes`

[https://github.com/microsoft/vscode/issues/147688](https://github.com/microsoft/vscode/issues/147688)

## Summary

Keep open: current macOS packaging still supplies legacy OSTypes for document associations, so the migration remains incomplete. Two linked implementation PRs are open and should be evaluated before starting competing work.

## Change summary

Migrate macOS document associations from deprecated CFBundleTypeOSTypes to LSItemContentTypes with appropriate Uniform Type Identifiers.

## Best solution

Complete the migration through the existing PRs, coordinating the document-type configuration in build/lib/electron.ts with @vscode/gulp-electron's plist generation while preserving file associations and icons. Adding UTIs while retaining legacy OSTypes does not fully satisfy the requested replacement.
