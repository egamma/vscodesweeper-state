[https://github.com/microsoft/vscode/issues/327559](https://github.com/microsoft/vscode/issues/327559)

## Summary

The report isolates the runaway memory use to the third-party Claude Code extension: disabling it immediately restores stable memory consumption. This should be handled in the extension's tracker rather than VS Code core.

## Change summary

Claude Code for VS Code continuously consumes memory while idle until Linux kills the renderer after system memory is exhausted.
