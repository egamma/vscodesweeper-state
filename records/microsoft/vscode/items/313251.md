# Issue #313251 — Collapse folders in Incoming Changes in tree view for many files

[https://github.com/microsoft/vscode/issues/313251](https://github.com/microsoft/vscode/issues/313251)

## Summary

Keep open: the graph still expands change folders by default and lacks a folder-level bulk-collapse affordance for Incoming Changes. The older Collapse All request concerns collapsing commit rows, not retaining an expanded Incoming Changes row with a compact folder overview.

## Change summary

Make large Incoming Changes trees easier to navigate without individually collapsing every folder.

## Best solution

Provide a discoverable way to collapse change folders while keeping Incoming Changes expanded in the SCM Graph. Prefer a consistent tree interaction over a new file-count-dependent default unless the area owner chooses otherwise.
