# Issue #301580 — Copilot help menu covers line numbers immediately upon selection

[https://github.com/microsoft/vscode/issues/301580](https://github.com/microsoft/vscode/issues/301580)

## Summary

The selection affordance is intentional and already has an explicit opt-out, so the reporter's central need is covered by setting `inlineChat.affordance` to `off`.

## Change summary

Prevent the inline Copilot affordance from covering line numbers or appearing beside selected text.

## Best solution

Keep the configurable affordance behavior and direct users who do not want it to set `inlineChat.affordance` to `off`; current main documents this mode as showing no selection affordance.

## Vision fit

- **Fit:** aligned
- **Reason:** Providing an opt-out for an optional editor overlay supports a simple, unobstructed editing UI without removing the capability for users who value it.
- **Evidence:** Value and guardrail: simple, uniform UI and UI interactions, with a lean default experience.

## Evidence
