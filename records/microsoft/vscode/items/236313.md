# Issue #236313 — In Terminal view, the 'Next/Previous Match' search function conflicts with the redirection triggered by Ctrl+Left Click.

[https://github.com/microsoft/vscode/issues/236313](https://github.com/microsoft/vscode/issues/236313)

## Summary

Keep open: the reporter supplies a concrete compilation-log workflow where opening a terminal link loses the current search position. Current source exposes a plausible selection-dependent path, but neither a fixing commit nor an older canonical covering this symptom was verified.

## Change summary

Preserve terminal find navigation position when Ctrl+Click opens a link, so Next/Previous Match continues from the previously selected match.

## Best solution

Terminal find should retain its navigation position across link activation without changing normal link opening or text-selection behavior. Reproduce the interaction on a current Windows build, then establish whether the correction belongs in VS Code's terminal integration or the xterm search addon.
