# Issue #342655 — Commands that don't take immediate action should have `...` in the name

[https://github.com/microsoft/vscode/issues/342655](https://github.com/microsoft/vscode/issues/342655)

## Summary

Keep open: the migration dashboard and item menu still omit the requested ellipses, although their migration flows require confirmation. This is a bounded consistency improvement requested by a team member, not a reason to close the issue.

## Change summary

Make the customization migration actions indicate that another interaction is required by displaying “Migrate...” and “Migrate This Item...”.

## Best solution

The dashboard, item menu, and corresponding detail action should consistently signal the confirmation step, while the final confirmation buttons retain their immediate-action labels. Keep this scoped to customization migration rather than treating the title as a repository-wide command audit.
