# Issue #339398 — Local harness: parent agent PreToolUse deny propagates to child subagents

[https://github.com/microsoft/vscode/issues/339398](https://github.com/microsoft/vscode/issues/339398)

## Summary

Traced the exact delegation path in RunSubagentTool on current main and the described propagation does not occur: when a tool call resolves a named target subagent, the parent/coordinator's own agent-scoped hooks are explicitly dropped rather than inherited, and only the target subagent's own hooks (merged with global hook-file hooks) govern its tool calls.

## Change summary

A parent custom agent's agent-scoped PreToolUse deny hook was reported to also run on (and block) a delegated child subagent's own allowed tool calls.

## Best solution

Keep the current behavior: RunSubagentTool.invoke in src/vs/workbench/contrib/chat/common/tools/builtinTools/runSubagentTool.ts already scopes hooks so a named child subagent's own frontmatter hooks (not the caller's) govern its tool calls; ask the reporter to confirm on the latest Insiders/Stable build.
