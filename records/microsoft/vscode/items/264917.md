# Issue #264917 — Chat - different modes use different working rendering

[https://github.com/microsoft/vscode/issues/264917](https://github.com/microsoft/vscode/issues/264917)

## Summary

The visual inconsistency remains in Stable's default rendering, and this team-authored polish issue has no referenced fixing commit or verified duplicate, so it should stay open for a shared progress-treatment decision.

## Change summary

Use a consistent visual treatment for the chat working indicator in Ask and Agent/Edit modes while preserving their intentionally different positions and scrolling behavior.

## Best solution

Choose one shared visual language for active chat progress and apply it to both modes without changing Ask's top placement or Agent/Edit's bottom placement. The existing shared `ChatWorkingProgressContentPart` and experimental persistent-progress path are the natural design boundary, but Stable's legacy default still needs an explicit decision.
