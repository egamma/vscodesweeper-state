# Issue #159186 — Feature request: change editor's commenting behavior in makefiles

[https://github.com/microsoft/vscode/issues/159186](https://github.com/microsoft/vscode/issues/159186)

## Summary

Fixed on main: commit d9145a291dc added a `noIndent` option to the line comment system and enabled it for makefiles, so comments now always go to column 0 — addressing both the indentation and consistency concerns raised here.

## Change summary

Makefile commenting via Ctrl+/ should place `#` at column 0 instead of indenting, and should be consistent regardless of whether the line is a make directive or a shell command.

## Best solution

Keep the shipped fix (d9145a291dc, 1.102.0). No further change needed — the `noIndent: true` in the makefile language configuration resolves both points.
