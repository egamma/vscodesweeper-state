# Issue #314028 — Selecting a large file consumes a lot of memory.

[https://github.com/microsoft/vscode/issues/314028](https://github.com/microsoft/vscode/issues/314028)

## Summary

Legitimate performance concern — selecting a multi-GB video file in the explorer with preview enabled causes excessive memory consumption, especially problematic over Remote SSH causing OOM. The streaming fix (43b8edc68b0) is already in the reporter's version (1.118.1), suggesting the issue persists despite streaming; more details needed on the exact scenario and whether range requests are being used properly.

## Change summary

Previewing a multi-GB video file consumes proportional memory, causing OOM on Remote SSH servers.

## Best solution

Investigate whether the webview video preview should enforce a file-size cap (refusing to preview files above a threshold) or whether the browser's video element is failing to use range requests through the webview resource loading path. A size guard in the media-preview extension's video provider (extensions/media-preview/src/videoPreview.ts) would be the simplest mitigation.
