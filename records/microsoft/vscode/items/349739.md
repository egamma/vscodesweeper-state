- **Trace:**

  > The reported management timeout can arise from delayed registration: ChannelServer in src/vs/base/parts/ipc/common/ipc.ts queues unknown channels and fails requests after 1000ms. ChatSetupController.signIn displays the reported dialog after requests.signIn returns no default account; its text does not establish an agent-host policy root cause. The uncertainty starts at which startup exception actually blocks panel creation and authentication on this Windows installation. Reproduce before selecting a fix boundary, retain existing authentication and policy semantics, and do not assume the related OOM report at https://github.com/microsoft/vscode/issues/348812 has the same cause.
