# Issue #292012 — Cannot add xAi Language model

[https://github.com/microsoft/vscode/issues/292012](https://github.com/microsoft/vscode/issues/292012)

## Summary

Legitimate bug: after entering an invalid API key for an xAI BYOK provider group, the key is persisted and the prompt never reappears, leaving the user unable to add xAI models without resetting their configuration. No fix found on current main.

## Change summary

Entering an invalid API key when adding an xAI BYOK provider causes the API key prompt to never reappear on subsequent add attempts.

## Best solution

The BYOK provider group creation flow should either validate the API key before persisting the group (e.g. a test request to the xAI models endpoint), or provide a clear path to re-enter/update the key when the stored one is invalid. The 'Update API Key' action exists in the group context menu (chatModelsWidget.ts line ~905), but the initial creation flow in languageModels.ts stores the group with the invalid key and never re-prompts. The fix likely belongs in the `configureLanguageModelsProviderGroup` / `addLanguageModelsProviderGroup` flow in `src/vs/workbench/contrib/chat/common/languageModels.ts` and the migration path in `extensions/copilot/src/extension/byok/vscode-node/abstractLanguageModelChatProvider.ts`.
