# Issue #248339 — `Create on GitHub` in `Issue Reporter` after extension bisect doesn't do anything

[https://github.com/microsoft/vscode/issues/248339](https://github.com/microsoft/vscode/issues/248339)

## Summary

Confirmed bug: after extension bisect completes, the main window reloads and orphans the Issue Reporter's service references, making the 'Create on GitHub' button and 'show' buttons silently fail. An open PR (#314616) addresses this but has not yet merged — keeping open.

## Change summary

The 'Create on GitHub' button in the Issue Reporter does nothing after extension bisect because the main window reload orphans the auxiliary window's service references.

## Best solution

Land https://github.com/microsoft/vscode/pull/314616, which skips the trailing `hostService.reload()` on the report-issue path in `src/vs/workbench/services/extensionManagement/browser/extensionBisect.ts`, so the Issue Reporter's service references remain valid.
