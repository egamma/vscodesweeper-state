## Change summary

When an extension sends updated semantic tokens via the refresh notification, the editor does not visually repaint until the user scrolls or types.

## Best solution

Investigate whether the ViewTokensChangedEvent from setSemanticTokens properly triggers a synchronous repaint in the editor view layer, specifically when no content change accompanies the token update. The fix likely lives in the rendering invalidation path in src/vs/editor/browser/view/viewLayer.ts or the view model event dispatch in src/vs/editor/common/viewModel/viewModelImpl.ts.
