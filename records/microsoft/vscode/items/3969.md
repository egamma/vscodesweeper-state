## Change summary

Show context-valid command and keybinding continuations while VS Code waits for the next key in a chord.

## Best solution

Expose matching chord continuations from the keybinding resolver and present them after a short delay in an accessible, keyboard-navigable workbench popup, while retaining the existing timeout and direct chord execution behavior.
