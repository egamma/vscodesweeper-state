# Issue #326765 — High CPU usage (infinite loop) When Incorrect Proxy URL is Set

[https://github.com/microsoft/vscode/issues/326765](https://github.com/microsoft/vscode/issues/326765)

## Summary

This is a confirmed Undici defect with an upstream fix, but current VS Code main still resolves Undici 7.29.0 rather than the fixed 8.6.0 release. Keep the issue open to track adoption or backport of the upstream fix.

## Change summary

An incorrectly configured HTTP proxy can make Undici retry a failed CONNECT tunnel indefinitely, consuming an entire CPU core.

## Best solution

Consume an Undici release containing nodejs/undici@445522ba1bc22bcef2971bfdc30c883531e84e84, or an upstream-supported backport, then verify that a proxy dropping the CONNECT tunnel causes one failed request rather than an unbounded retry loop.

- **upstream fix:** https://github.com/nodejs/undici/commit/445522ba1bc22bcef2971bfdc30c883531e84e84 fixes the loop by converting tunnel-establishment UND_ERR_SOCKET failures into a non-recoverable ProxyConnectionError, with a regression test asserting exactly one connection attempt.
