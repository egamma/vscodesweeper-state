# Issue #339720 — Copilot Connectors: no Disconnecting label while disconnecting

[https://github.com/microsoft/vscode/issues/339720](https://github.com/microsoft/vscode/issues/339720)

## Summary

Confirmed in source: this is a real, bounded gap in the newly-added Copilot Connectors detail panel — the Disconnect button only disables itself during the request, it never swaps its label to an in-progress state, unlike the sibling marketplace detail view which already handles this for its own flow.

## Change summary

The connector detail panel's Disconnect button (opened via MCP Servers > Built-In) stays labeled 'Disconnect' while the disconnect request is in flight, instead of showing a 'Disconnecting...' label.

## Best solution

In EmbeddedConnectorDetail.renderItem's onDidClick handler (embeddedConnectorDetail.ts), swap the button label to an in-progress label (e.g. 'Disconnecting...'/'Connecting...' per action) before calling runAction and restore it afterward, mirroring the pattern already used in embeddedMarketplaceDetail.ts's renderConnectorAction (state.kind === 'uninstalling' -> 'Disconnecting...').
