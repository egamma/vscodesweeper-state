# Issue #239110 — Activating display pointer trails makes text editing pointer disappear

[https://github.com/microsoft/vscode/issues/239110](https://github.com/microsoft/vscode/issues/239110)

## Summary

This is a known Windows 11 24H2 / Chromium bug affecting cursor rendering in all Chromium-based applications, not a VS Code defect. Multiple duplicate issues have been filed and closed with the same root cause. The pointer-trails variant described here is the same underlying issue.

## Change summary

Enabling Windows 'Display pointer trails' causes the text-select (I-beam) cursor to disappear in the VS Code editor on Windows 11 24H2.

## Best solution

Close as upstream — the root cause is a Windows 11 24H2 cursor-rendering bug affecting Chromium (and therefore Electron/VS Code). The workaround is changing the Windows cursor scheme or increasing pointer size. The fix belongs in Windows or Chromium, not in VS Code.

  > **Workarounds:**
  > - Change the Windows cursor scheme (Settings → Accessibility → Mouse pointer and touch → change the pointer style)
  > - Increase pointer size to 2 or above
  > - Disable pointer trails
