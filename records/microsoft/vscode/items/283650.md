# Issue #283650 — Improve agent behavior when certain tools are disabled

[https://github.com/microsoft/vscode/issues/283650](https://github.com/microsoft/vscode/issues/283650)

## Summary

Keep open: this team-authored Backlog request tracks a deliberate improvement to agent behavior and evaluation coverage when required tools are disabled. The related report describes one consequence, but no verified older canonical with the same observable symptom is present.

## Change summary

Make agents stop and clearly report that a task cannot be completed when the necessary tool is disabled, rather than attempting unrelated tool actions.

## Best solution

Define the expected unavailable-tool response in the agent prompt/context and add focused evaluations covering disabled-tool tasks, including retry and subagent behavior.
