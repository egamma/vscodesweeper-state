# Issue #344183 — [Feature]: The three buttons in the upper-right corner allow you to configure the traffic-light effect

[https://github.com/microsoft/vscode/issues/344183](https://github.com/microsoft/vscode/issues/344183)

## Summary

Keep open for feature triage: existing settings select native or custom window controls, but do not provide a traffic-light styling option. Native decorations may offer an alternative, but their appearance with WhiteSur on the reported Wayland/labwc setup is not established.

## Change summary

Allow Linux window controls to use a macOS-like traffic-light appearance, as illustrated with the WhiteSur desktop theme.

## Best solution

Prefer desktop-managed decorations through the existing native-title-bar setting where they deliver the requested appearance. Any remaining request for traffic-light controls within VS Code's custom title bar needs a maintainer scope decision; the supplied evidence does not justify declining it.
