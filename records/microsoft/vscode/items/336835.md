# Issue #336835 — cannot open HTML files in integrated browser when using WSL

[https://github.com/microsoft/vscode/issues/336835](https://github.com/microsoft/vscode/issues/336835)

## Summary

Confirmed in source: the Integrated Browser editor-resolver registration for .html/.htm/.mhtml/.mht only matches `Schemas.file`, so WSL/remote-hosted HTML files (scheme `vscode-remote`) never get the 'Open With → Integrated Browser' option, even though the browser view already has explicit remote-authority support elsewhere.

## Change summary

Right-clicking an HTML file in a WSL (remote) workspace offers no 'Open with Integrated Browser' option.

## Best solution

Extend the editor-resolver registration in browserView.contribution.ts to also match `Schemas.vscodeRemote` (or otherwise scheme-agnostic within a remote context) so the Integrated Browser option appears for remote/WSL-hosted HTML files, consistent with the remote-proxy support already built into BrowserViewWorkbenchService.
