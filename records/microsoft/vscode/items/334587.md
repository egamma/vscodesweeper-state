# Issue #334587 — Find+Replace within selection doesn't work

[https://github.com/microsoft/vscode/issues/334587](https://github.com/microsoft/vscode/issues/334587)

## Summary

Selecting text and opening Find/Replace does not automatically scope the search to the selection — that requires enabling the 'Find in Selection' toggle (or the `editor.find.autoFindInSelection` setting, default `never`). This is shipped, intentional behavior, not a defect.

## Change summary

Reporter expects Find/Replace to automatically restrict matches and Replace All to the current selection whenever text is selected before opening the widget.

## Best solution

Point the reporter to the 'Find in Selection' toggle button in the find widget (also bound to a command/keybinding) and the `editor.find.autoFindInSelection` setting (values: never/always/multiline) which auto-enables this behavior when desired.

- **Proposed comment:**

  > Thanks for the report. This matches the intended behavior: opening Find/Replace doesn't automatically scope to your selection — you need to click the 'Find in Selection' toggle icon in the widget (or its keybinding), or set `editor.find.autoFindInSelection` to `always` or `multiline` if you'd like this to happen automatically for multi-line selections. Since the default is `never`, Replace All without enabling that toggle intentionally affects the whole file.
