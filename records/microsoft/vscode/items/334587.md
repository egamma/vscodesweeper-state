# Issue #334587 — Find+Replace within selection doesn't work

[https://github.com/microsoft/vscode/issues/334587](https://github.com/microsoft/vscode/issues/334587)

## Summary

This is expected behavior: selecting text and opening Find/Replace does not automatically scope search to the selection unless the 'Find in Selection' toggle is enabled, either manually via the widget's icon or via the `editor.find.autoFindInSelection` setting (default `never`).

## Change summary

User expects Find+Replace to automatically restrict matches/replace-all to a text selection, but it searches the whole file instead.

## Best solution

Point the reporter to the 'Find in Selection' toggle in the find widget (the selection icon, `findSelectionIcon`/`toggleSelectionFind` in src/vs/editor/contrib/find/browser/findWidget.ts) and the `editor.find.autoFindInSelection` setting (values 'never'/'always'/'multiline', default 'never') in src/vs/editor/common/config/editorOptions.ts, which controls exactly this behavior.

- **Proposed comment:**

  > Thanks for the report! This is expected behavior, not a bug: selecting text and opening Find/Replace doesn't automatically restrict matches to the selection. You need to either click the 'Find in Selection' icon (the selection icon on the right side of the Find widget) to turn it on for that search, or set `editor.find.autoFindInSelection` to `"multiline"` (turns it on automatically when multiple lines are selected) or `"always"` in your settings. The current default is `"never"`. Closing as as-designed, but let us know if you think the default should change — that'd be a separate feature discussion.
