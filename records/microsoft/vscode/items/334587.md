# Issue #334587 — Find+Replace within selection doesn't work

[https://github.com/microsoft/vscode/issues/334587](https://github.com/microsoft/vscode/issues/334587)

## Summary

Selecting text and opening Find doesn't automatically restrict the search to that selection unless the 'Find in Selection' toggle is enabled — this is controlled by the `editor.find.autoFindInSelection` setting, which defaults to `never` by design.

## Change summary

User expects Find+Replace to be automatically scoped to their current selection, but Replace All affects matches outside the selection too.

## Best solution

No code change needed: point the reporter to the 'Find in Selection' toggle button in the Find widget (or the `editor.find.autoFindInSelection` setting, set to `multiline` or `always`) to get the behavior they expect.

  > Thanks for the report! This is expected behavior, not a bug: by default, selecting text and opening Find doesn't automatically scope the search to that selection (`editor.find.autoFindInSelection` defaults to `never`). To restrict Find/Replace to your selection, click the "Find in Selection" toggle button in the Find widget (or set `editor.find.autoFindInSelection` to `multiline` or `always` if you'd like this to happen automatically for multi-line or all selections).
