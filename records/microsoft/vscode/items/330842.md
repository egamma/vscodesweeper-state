# Issue #330842 — Microsoft account sign in isn't properly dark themed so it flashes black to white repeatedly -- giving me a headache

[https://github.com/microsoft/vscode/issues/330842](https://github.com/microsoft/vscode/issues/330842)

## Summary

The flashing is happening on Microsoft's hosted identity platform sign-in pages (login.microsoftonline.com), opened in the user's default system browser during auth — not in any VS Code-rendered UI, so there's no VS Code code path to theme here.

## Change summary

During Microsoft account sign-in (used for the Azure DevOps MCP server), the screen repeatedly flashes black/white, which is jarring in dark mode.

## Best solution

Nothing to fix in this repo: the sign-in flow (extensions/microsoft-authentication/src/node/flows.ts) calls `env.openExternal(...)` to hand the auth URL to the system default browser, so the flashing pages are Microsoft's external identity-platform site rendering in that browser, outside VS Code's control. VS Code's own local success/error template (extensions/microsoft-authentication/src/node/loopbackTemplate.ts) is already dark-styled (`background-color: #2C2C32`, white text), so there's no local theming gap to close. Feedback on the identity site's own dark-mode support belongs with the team that owns login.microsoftonline.com, not microsoft/vscode.
