# Issue #330842 — Microsoft account sign in isn't properly dark themed so it flashes black to white repeatedly -- giving me a headache

[https://github.com/microsoft/vscode/issues/330842](https://github.com/microsoft/vscode/issues/330842)

## Summary

Keep this open as an upstream Microsoft sign-in appearance issue: the built-in authentication provider delegates the reported window to MSAL's native broker rather than rendering it. The reporter's no-broker workaround reduces repeated prompts but does not establish that the white flashes are fixed.

## Change summary

Prevent bright white transitions in Microsoft account sign-in when using a dark theme, including the broker and hosted authorization pages.

## Best solution

Have the Windows WAM and Microsoft identity UI owners address the loading surfaces and authorization-page appearance, retaining this issue to track the VS Code impact. Keep repeated authentication tracked separately from the visual defect; changing the default authentication implementation is not an established solution.
