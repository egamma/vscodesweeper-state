# Issue #330842 — Microsoft account sign in isn't properly dark themed so it flashes black to white repeatedly -- giving me a headache

[https://github.com/microsoft/vscode/issues/330842](https://github.com/microsoft/vscode/issues/330842)

## Summary

The reporter's own code trace holds up: the flashing black/white window is the native Windows Web Account Manager (WAM) broker rendered by @azure/msal-node-runtime, not a VS Code-owned webview or dialog, so there is no VS Code color/theme option to pass in — this is an upstream MSAL/WAM limitation, not a core bug to fix directly.

## Change summary

The Microsoft account sign-in window is not dark themed and visibly flashes between black and white during interactive auth on Windows.

## Best solution

Track this against the upstream MSAL/WAM broker (no theming API exists yet — see the linked AzureAD/microsoft-authentication-library-for-dotnet report) and, in the meantime, consider documenting or defaulting away from the native broker (the existing `microsoft-authentication.implementation: msal-no-broker` setting avoids the WAM window) for affected users; the authentication extension team should decide whether that tradeoff is worth making by default.
