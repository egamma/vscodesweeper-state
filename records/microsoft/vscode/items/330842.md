## Summary

The flashing black/white sign-in UI most likely comes from the native Windows Broker (WAM) dialog that the built-in microsoft-authentication extension launches by default on Windows — that dialog is rendered by the OS/native broker plugin, not by VS Code, so VS Code has no theming control over it. Routing to the authentication-microsoft area for a maintainer to confirm which surface (native broker vs. external browser) is flashing and whether a mitigation (e.g. defaulting away from the broker, or filing upstream against msal-node-extensions/Windows) is possible.
