# Issue #255995 — Profiles editor: it's possible to uncheck `Use for New Windows`

[https://github.com/microsoft/vscode/issues/255995](https://github.com/microsoft/vscode/issues/255995)

## Summary

The ambiguity remains on current main: unchecking the option stores the Active Window fallback, but neither the visible description nor the checkbox's accessible title explains that outcome. The accepted `bug` in the Backlog milestone should remain open for the clarification proposed by the area maintainer.

## Change summary

Clarify which profile new windows use when no profile is selected through the Profiles editor's `Use for New Windows` checkbox.

## Best solution

Keep the checkbox behavior, but make its visible description and accessible label explain that an unchecked option inherits the active window's profile, falling back to Default when there is no active window.
