# Issue #275005 — Zoom in shortcut not working when Thai keyboard layout is active (macOS)

[https://github.com/microsoft/vscode/issues/275005](https://github.com/microsoft/vscode/issues/275005)

## Summary

Legitimate keyboard-layout bug: the Thai Kedmanee layout on macOS maps the physical `=` key to a different character, so Cmd+= (zoom in) never fires, while Cmd+- (zoom out) still works because `-` stays in place. No fix found on main; already correctly labeled.

## Change summary

Zoom in shortcut (Cmd+=) does not trigger when the Thai Kedmanee keyboard layout is active on macOS, because the physical key produces a Thai character instead of `=`.

## Best solution

The keybinding resolver (macLinuxKeyboardMapper.ts) needs to resolve Cmd+= via the underlying physical key (keycode) rather than the produced character when a non-Latin layout is active — similar to how other keyboard-layout issues are addressed. This is a long-standing class of problems tracked under the `keyboard-layout` label with no single systemic fix yet.
