# Issue #299191 — Ask questions hover should render to the side

[https://github.com/microsoft/vscode/issues/299191](https://github.com/microsoft/vscode/issues/299191)

## Summary

Keep open: the question carousel has evolved, but both option renderers still request vertical hovers rather than side placement. The reported surface and hover interaction suffice to retest the overlap; no qualifying fix or canonical duplicate was established.

## Change summary

Question-option hovers obscure neighboring options instead of appearing beside the list.

## Best solution

Question-option hovers should prefer available space beside the row in both single- and multi-select carousels, while preserving viewport fallback when neither side has room. Keep the option content, selection behavior, and keyboard accessibility unchanged.
