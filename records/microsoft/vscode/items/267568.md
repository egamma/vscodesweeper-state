# Issue #267568 — VSCode Integrated Terminal IME Issue

[https://github.com/microsoft/vscode/issues/267568](https://github.com/microsoft/vscode/issues/267568)

## Summary

Already properly triaged as an upstream xterm.js issue — the terminal bypasses IME composition results for certain remapped keys in macOS one-hand Hangul mode. Linked to the canonical xterm.js tracker and labeled accordingly; nothing further needed from VS Code core.

## Change summary

VS Code's integrated terminal shows raw Latin keys instead of IME-composed Hangul characters for remapped keys in macOS one-hand Hangul mode.

## Best solution

The fix belongs in xterm.js (https://github.com/xtermjs/xterm.js/issues/3836 or a related issue there). Once xterm.js handles the IME composition result for these remapped keys, VS Code picks it up via its xterm.js dependency bump. The `help wanted` label invites community contribution on the xterm.js side.
