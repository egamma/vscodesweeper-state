# Issue #7772 — Long Text longer than 10000 letters wrapped with [...]

[https://github.com/microsoft/vscode/issues/7772](https://github.com/microsoft/vscode/issues/7772)

## Summary

Keep this accepted, well-supported request open: current main provides a “Show more” affordance, but still truncates rendering at 10,000 characters by default. Existing workarounds do not deliver responsive, unwrapped editing of very long lines, and maintainers explicitly consolidated related usability reports here.

## Change summary

Improve navigation, visibility, and editing of long unwrapped lines without requiring users to discover a hidden rendering override or accept substantial lag.

## Best solution

Provide understandable, responsive access to text beyond the rendering cutoff while preserving editor performance and the complete underlying document. A maintainer-led plan should distinguish the remaining rendering capability from narrower discoverability improvements already partially implemented.
