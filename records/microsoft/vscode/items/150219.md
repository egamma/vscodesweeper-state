# Issue #150219 — Debug Cell option disappears 

[https://github.com/microsoft/vscode/issues/150219](https://github.com/microsoft/vscode/issues/150219)

## Summary

Still an open bug with 98 upvotes. The Debug Cell dropdown disappears because notebook cell context keys (likely `notebookCellExecuting` or Jupyter-extension-side debug-support keys) get stuck in a bad state after a debug session crash. No fix commit references this issue, and the related vscode-jupyter#16189 (context key issues for debug actions) remains open. The Backlog milestone does not block a close, but there is no evidence of a fix to justify one.

## Change summary

The Debug Cell dropdown and keyboard shortcut stop working after a notebook debug session crashes or is force-stopped, requiring a window reload to restore.

## Best solution

Investigate whether the cell execution state context keys in `src/vs/workbench/contrib/notebook/browser/view/cellParts/cellContextKeys.ts` (particularly the `cellExecuting` and `cellRunState` reset paths in `updateForExecutionState`) fail to reset when a debug session terminates abnormally, and coordinate with the Jupyter extension team on the debug-action context key conditions (tracked in vscode-jupyter#16189). The fix likely needs both a core-side guard ensuring context keys reset on abnormal debug termination and an extension-side review of the `when` clauses on the debug cell menu contribution.
