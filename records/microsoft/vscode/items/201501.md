# Issue #201501 — Collapsed diff should also collapse the diff when there are no changes at all (happens in clean rename and other events)

[https://github.com/microsoft/vscode/issues/201501](https://github.com/microsoft/vscode/issues/201501)

## Summary

Keep open: current source explicitly excludes whole-file unchanged regions from collapsing, so the requested empty state remains missing. A maintainer supported the idea, and the reporter clarified that revealing the file should be temporary; distinguishing external refreshes from active editing still needs investigation.

## Change summary

Show a temporary, revealable empty state for identical-file diffs when unchanged-region collapsing is enabled, without interrupting active editing.

## Best solution

Extend the diff editor's unchanged-region experience to cover identical files on initial opening and external refresh, with an editor-local reveal action. Preserve visibility when typing removes the final difference, and preserve existing behavior when collapsing is disabled.

- **Behavior:**

  > With unchanged-region collapsing enabled, opening a content-identical diff or externally refreshing a diff to have no changes should show a clear centered empty state instead of the full file. A 'View entire file' action temporarily reveals contents in the current editor instance without changing the persistent setting; a new instance starts collapsed. Typing that removes the final difference must not suddenly hide the active editor. With collapsing disabled, identical diffs continue to show the whole file. Acceptance covers clean staged renames and commit, stage, and unstage transitions.
- **Trace:**

  > HideUnchangedRegionsFeature in src/vs/editor/browser/widget/diffEditor/features/hideUnchangedRegionsFeature.ts filters out a sole unchanged region spanning the entire modified file before creating view zones or applying hidden areas. UnchangedRegion.fromDiffs in src/vs/editor/browser/widget/diffEditor/diffEditorViewModel.ts can produce that whole-file region, but the feature deliberately ignores it. DiffEditorViewModel updates unchanged-region state through original and modified content-change listeners and preserves visibility through decorations. The uncertainty starts at reliably identifying external refreshes versus active user edits and carrying the editor-local reveal state across those transitions. Preserve ordinary partial-diff folding, cursor visibility, and the persistent collapse setting. The temporary reveal semantics are already specified in https://github.com/microsoft/vscode/issues/201501; https://github.com/microsoft/vscode/issues/339566 concerns a separate visibility-restoration problem, not a canonical for this request.
