# Issue #191269 — Terminal Toggle Size to Content Width can stretch the canvas beyond the max texture size

[https://github.com/microsoft/vscode/issues/191269](https://github.com/microsoft/vscode/issues/191269)

## Summary

Upstream xterm.js issue (xtermjs/xterm.js#4186) was closed as out-of-scope without a fix. The bug remains reproducible for users with very long wrapped lines, but since the root cause is in xterm.js's canvas handling and VS Code already provides a workaround (Terminal: Set Fixed Dimensions), this stays as a tracked upstream limitation.

## Change summary

Terminal canvas stretches beyond max GPU texture size when toggling word wrap off with very long lines, causing distorted rendering.

## Best solution

Either implement a VS Code-side safeguard that caps terminal canvas dimensions before they exceed the GPU max texture size (in the terminal rendering layer), or wait for xterm.js to revisit the issue. The existing workaround (Terminal: Set Fixed Dimensions) mitigates the problem for affected users.
