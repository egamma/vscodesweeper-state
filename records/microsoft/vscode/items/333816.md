# Issue #333816 — Native MDM ignores documented object-form plugin marketplaces

[https://github.com/microsoft/vscode/issues/333816](https://github.com/microsoft/vscode/issues/333816)

## Summary

Confirmed in source: `readConfiguredMarketplaces()` in marketplaceReference.ts drops every non-string entry from the parsed `extraKnownMarketplaces` object even though `parseMarketplaceObjectEntry()` two stages later fully supports object-form entries — matching the reporter's root-cause analysis exactly. An open PR already targets this fix.

## Change summary

Native-MDM-delivered `extraKnownMarketplaces` object-form entries are silently dropped instead of being parsed, so managed plugin marketplaces never load.

## Best solution

Land (after review) the linked fix in https://github.com/microsoft/vscode/pull/333822, which should stop discarding non-string values in readConfiguredMarketplaces() and route them through parseExtraMarketplaceConfigValue/parseMarketplaceObjectEntry the same way string-encoded JSON entries are.
