## Summary

The 'Run Python File' command and the terminal-launch/execution flow it describes are implemented entirely by the ms-python.python (and debugpy) extensions, not by VS Code core, so this is best triaged as extension-owned rather than a core defect.

## Change summary

Reporter says clicking 'Run Python File' takes 2–3 minutes to open the integrated terminal and start the script, after a recent VS Code update.

## Best solution

Move this to microsoft/vscode-python (the Python extension's own tracker, which owns 'Run Python File', environment activation, and debugpy startup) so the Python team can investigate the reported regression with their own diagnostics.
