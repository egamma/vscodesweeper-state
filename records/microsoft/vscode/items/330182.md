# Issue #330182 — Python scripts take 2–3 minutes to open the terminal after VS Code update

[https://github.com/microsoft/vscode/issues/330182](https://github.com/microsoft/vscode/issues/330182)

## Summary

A commenter root-caused this to the third-party (Microsoft-owned) 'GitHub Copilot modernization' extension (vscjava.migrate-java-to-azure) unexpectedly activating and slowing down Python terminal/file operations; uninstalling it resolved the delay, so this isn't a core VS Code defect.

## Change summary

Running a Python file takes 2–3 minutes to open the integrated terminal and start execution after a recent VS Code update.
