# Issue #284229 — Unexpected sort in completions

[https://github.com/microsoft/vscode/issues/284229](https://github.com/microsoft/vscode/issues/284229)

## Summary

Team-authored bug about fuzzy scoring penalizing exact substring matches that start late in long setting names. An open community PR (https://github.com/microsoft/vscode/pull/285449) attempts a fix but has not been merged. The issue remains valid on current main.

## Change summary

Typing 'joint' in settings.json completions ranks weak early fuzzy matches above an exact substring match that appears deep in a long setting key.

## Best solution

Review and land (or close with an alternative approach to) the open PR https://github.com/microsoft/vscode/pull/285449, which modifies `fuzzyScore` in `src/vs/base/common/filters.ts` to skip the late-start penalty when the pattern is a contiguous substring of the target. The fix should be validated against the broader suggest/filter test suite to avoid regressions in other completion contexts.
