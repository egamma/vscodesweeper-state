# Issue #313533 — Support explicit `[\`symbolName\`](path/to/file.py)` symbol links and deprecate optimistic backtick matching

[https://github.com/microsoft/vscode/issues/313533](https://github.com/microsoft/vscode/issues/313533)

## Summary

Explicit symbol links already have a working source path, but optimistic bare-backtick matching remains registered and active. Keep this team-authored request open for the remaining deprecation work; the merged related PR addresses late anchor updates, not that migration.

## Change summary

Prefer explicit symbol-and-file Markdown links over inferred links from bare inline-code symbol names.

## Best solution

Complete the transition to explicit symbol links in the Copilot response-linkification pipeline while preserving existing symbol-pill rendering and late symbol resolution. Bare inline-code symbol names should no longer acquire speculative symbol targets; ordinary file links and notebook references should retain their intended behavior.
