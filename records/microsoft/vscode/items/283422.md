# Issue #283422 — Allow specifying MCP server for `Chat › Tools: Eligible For Auto Approval` configuration

[https://github.com/microsoft/vscode/issues/283422](https://github.com/microsoft/vscode/issues/283422)

## Summary

The requested server-specific eligibility remains missing: current code matches MCP tools by their unqualified reference name, so identically named tools cannot receive different eligibility values. Keep this accepted Backlog request open; the related namespace issues do not establish a canonical duplicate with the same observable problem.

## Change summary

Allow chat.tools.eligibleForAutoApproval to distinguish identically named tools supplied by different MCP servers.

## Best solution

Provide server-qualified MCP tool eligibility with corresponding settings completion and documented precedence over existing unqualified entries. Preserve existing eligibility semantics: true permits auto-approval options rather than automatically approving execution.
