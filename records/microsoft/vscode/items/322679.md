# Issue #322679 — Middle-click paste Primary Selection doesn't work after copying a file

[https://github.com/microsoft/vscode/issues/322679](https://github.com/microsoft/vscode/issues/322679)

## Summary

Verified duplicate of #202594: the root cause is that VS Code's middle-click paste reads from the system clipboard instead of the X11 primary selection buffer, so any operation that writes to the system clipboard (like copying a file in Explorer) overwrites what middle-click pastes.

## Change summary

After copying a file in Explorer on Linux, middle-click paste in the editor pastes the file path instead of the X11 primary selection text.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/202594 — fixing the editor's selection clipboard implementation to read from the X11 primary selection buffer rather than the system clipboard resolves both this report and the broader problem.
