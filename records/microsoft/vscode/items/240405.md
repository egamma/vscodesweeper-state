# Issue #240405 — Persist execution time within notebook cells' metadata

[https://github.com/microsoft/vscode/issues/240405](https://github.com/microsoft/vscode/issues/240405)

## Summary

Valid feature request with 31 upvotes, already promoted to Backlog. Execution timing lives in transient `NotebookCellInternalMetadata` (runStartTime/runEndTime) which is explicitly not persisted to disk — the gap is real and no implementation exists on main.

## Change summary

Persist notebook cell execution timing (start/end time) into the cell's metadata in the .ipynb file so it survives restarts and can be used in exported reports.

## Best solution

Add an opt-in setting that serializes execution timing from `NotebookCellInternalMetadata` into the cell's persisted metadata during notebook save. This likely spans VS Code's notebook serialization layer and the Jupyter extension's `.ipynb` serializer — the Jupyter extension already owns the `.ipynb` format and would need to write/read the `execution` metadata block. Coordinate with the vscode-jupyter team on the serialization format (matching the Jupyter nbextension convention shown in the issue).
