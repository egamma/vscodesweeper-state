# Issue #240405 — Persist execution time within notebook cells' metadata

[https://github.com/microsoft/vscode/issues/240405](https://github.com/microsoft/vscode/issues/240405)

## Summary

Keep this accepted, community-supported request open. The existing execution-time verbosity setting changes presentation, but does not provide the requested metadata persistence and restoration after restarting VS Code.

## Change summary

Offer opt-in persistence of notebook cell execution timestamps in .ipynb metadata for reopening notebooks and generating reports.

## Best solution

Provide an opt-in, interoperable execution-metadata contract spanning notebook execution, .ipynb serialization, and timing restoration. Preserve the default behavior without adding timing metadata, and retain timestamps in a format usable by notebook export tools.
