# Issue #343797 — Copilot harness needs ability to disable execute permissions

[https://github.com/microsoft/vscode/issues/343797](https://github.com/microsoft/vscode/issues/343797)

## Summary

Keep open for human assessment of the execution-permission and containment requirements. Current main already exposes tool-exclusion configuration, but its existence does not establish an enforceable no-execution security boundary; the sandbox concern also triggers the security-sensitive keep-open rule.

## Change summary

Allow users to disable shell and command execution in the Copilot harness while retaining other tools.

## Best solution

Establish whether the existing tool filters satisfy personal tool-selection needs, and distinguish that from an enforceable execution prohibition. Any organizational no-execution guarantee should use runtime-enforced managed permissions, with its coverage and containment limitations clearly documented.
