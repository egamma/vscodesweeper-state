# Issue #245152 — VSCode Webversion (github.dev) - Text selection opens file from file-tree

[https://github.com/microsoft/vscode/issues/245152](https://github.com/microsoft/vscode/issues/245152)

## Summary

The erroneous activation path remains on current main: a click delivered to an Explorer row is treated as a complete pointer gesture without checking whether the mouse interaction began in that list. The report should remain open as a bounded web/Firefox interaction bug.

## Change summary

Dragging an editor text selection into the Explorer and releasing over a file unexpectedly opens that file on github.dev in Firefox.

## Best solution

Ensure tree and list items activate only from a valid click gesture originating in the relevant list, while preserving normal single-click, double-click, middle-click, touch, and modifier behavior.
