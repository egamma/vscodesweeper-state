# Issue #280025 — Task terminal sticky scroll bug after being cleared

[https://github.com/microsoft/vscode/issues/280025](https://github.com/microsoft/vscode/issues/280025)

## Summary

Confirmed bug still present on main — `getCommandForLine()` doesn't guard against disposed markers (line === -1) after `clearBuffer()`, causing stale commands to appear in sticky scroll. An open PR (#282888) already targets this issue.

## Change summary

Terminal sticky scroll shows stale/disposed command entries after a task terminal is cleared and rerun with `presentation.clear: true`.

## Best solution

Land or refine the open PR at https://github.com/microsoft/vscode/pull/282888, which adds disposed-marker filtering in `getCommandForLine()` in `commandDetectionCapability.ts`. The fix is small and localized — filter commands whose marker has `line === -1` before comparing against the requested line.
