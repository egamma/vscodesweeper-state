# Issue #329735 — Extension 'ms-vscode-remote.remote-ssh' CANNOT use API proposal: terminalRemoteResolver

[https://github.com/microsoft/vscode/issues/329735](https://github.com/microsoft/vscode/issues/329735)

## Summary

Extension-side version skew: VS Code core now requires the `terminalRemoteResolver` API proposal for terminal remote resolvers, but the currently-installed Remote-SSH build doesn't declare it yet, so remote connections fail. This belongs with the Remote-SSH extension tracker rather than core; per practice it should be moved there, not closed-and-refiled.

## Change summary

Opening any SSH remote fails with 'Extension ms-vscode-remote.remote-ssh CANNOT use API proposal: terminalRemoteResolver' because the extension's enabledApiProposals list is missing that entry.

## Best solution

Move this issue to microsoft/vscode-remote-release (the Remote-SSH extension's own tracker) so the extension team can ship a build that declares `terminalRemoteResolver` in package.json#enabledApiProposals; core already exposes the proposal (src/vs/platform/extensions/common/extensionsApiProposals.ts:468-470) and enforces it via checkProposedApiEnabled in src/vs/workbench/api/common/extHost.api.impl.ts:141.
