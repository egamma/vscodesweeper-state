# Issue #329735 — Extension 'ms-vscode-remote.remote-ssh' CANNOT use API proposal: terminalRemoteResolver

[https://github.com/microsoft/vscode/issues/329735](https://github.com/microsoft/vscode/issues/329735)

## Summary

Real regression on Insiders: remote-ssh throws 'CANNOT use API proposal: terminalRemoteResolver' and can't load SSH remotes, confirmed by a second reporter within hours — but the root cause (the build's product.json#extensionEnabledApiProposals allowlist not granting remote-ssh this newly-added proposal) lives outside this OSS checkout, so I can't cite a fixing commit.

## Change summary

Since a recent Insiders build, ms-vscode-remote.remote-ssh can no longer use the (apparently new) terminalRemoteResolver proposed API and fails to open any SSH remote.

## Best solution

A maintainer needs to add/restore 'ms-vscode-remote.remote-ssh' to the internal product.json's extensionEnabledApiProposals for the 'terminalRemoteResolver' proposal (see src/vs/workbench/services/extensions/common/extensionsProposedApi.ts, which reads that allowlist) — this looks like a rollout sequencing gap between adding the new proposal and granting the built-in-trusted extension access to it.
