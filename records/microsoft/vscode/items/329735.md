# Issue #329735 — Extension 'ms-vscode-remote.remote-ssh' CANNOT use API proposal: terminalRemoteResolver

[https://github.com/microsoft/vscode/issues/329735](https://github.com/microsoft/vscode/issues/329735)

## Summary

The error is a package.json/API-proposal declaration mismatch inside the ms-vscode-remote.remote-ssh extension itself (it calls into the newly added `terminalRemoteResolver` proposal without declaring it in enabledApiProposals) — this is an extension-side versioning bug, not a VS Code core defect, so it should move to the extension's own tracker rather than close-and-refile here.

## Change summary

All SSH remote connections fail on Insiders with 'CANNOT use API proposal: terminalRemoteResolver' because the installed remote-ssh extension build doesn't declare that proposal.

## Best solution

Move this to microsoft/vscode-remote-release (the Remote-SSH extension's own tracker) so the extension team can ship a build whose package.json#enabledApiProposals includes `terminalRemoteResolver`, matching the core proposal added for https://github.com/microsoft/vscode/issues/328475 (declared in src/vscode-dts/vscode.proposed.terminalRemoteResolver.d.ts and checked via checkProposedApiEnabled in src/vs/workbench/api/common/extHost.api.impl.ts:141).
