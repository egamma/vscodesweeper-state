[https://github.com/microsoft/vscode/issues/329584](https://github.com/microsoft/vscode/issues/329584)

## Summary

The screenshot and independently reported matching symptom establish a real approval-layout defect: long terminal commands cannot be fully inspected before execution. No verified fix or eligible older canonical was found, so this should remain open and route to the terminal-confirmation and Agent Host owners.

## Change summary

Ensure the terminal approval UI lets users scroll through and inspect the complete proposed command when a risk-assessment footer is present.

## Best solution

Keep the complete command reachable within the approval card at constrained heights: the command viewport must account for the risk-assessment footer and action row so its final line can scroll fully into view. Confirm the behavior in the current chat confirmation carousel and add regression coverage for a long wrapped command.
