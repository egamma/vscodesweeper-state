## Summary

Plausible but unconfirmed layout issue in the newly-added terminal tool risk-assessment footer; traced the confirmation widget code and found nothing conclusively proving an overlap (the footer banner is inserted as a normal-flow sibling after the scrollable message, not absolutely positioned), so this needs a repro/screenshot from the reporter rather than a source-only close.

## Change summary
