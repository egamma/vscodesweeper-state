  > 
  > - **Firewall / antivirus**: make sure `*.gallery.vsassets.io` and `*.visualstudio.com` are allowed.
  > - **Proxy**: if you're behind a corporate or school proxy, configure `http.proxy` in VS Code settings (File → Preferences → Settings → search "proxy"). You may also need to set `http.proxyStrictSSL` to `false` if TLS inspection is in play.
  > - **VPN / ISP**: some ISPs or VPN providers block certain CDN domains — try with/without a VPN.
  > - **DNS**: try switching to a public DNS like `8.8.8.8` or `1.1.1.1`.
  > 
  > See the [network troubleshooting docs](https://code.visualstudio.com/docs/setup/network) for more detail.
