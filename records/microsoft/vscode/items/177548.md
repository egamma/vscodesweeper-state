# Issue #177548 — Removed Keybinding can't be found in the keybinding list

[https://github.com/microsoft/vscode/issues/177548](https://github.com/microsoft/vscode/issues/177548)

## Summary

Still reproducible on main: when a default keybinding is removed, `KeybindingResolver.handleRemovals` strips both the original default entry and the negated user entry from `getKeybindings()`, so the keybindings editor model never receives the removed binding and cannot display it under `@source:user`.

## Change summary

After removing a default keybinding, the removed entry disappears entirely from the Keyboard Shortcuts editor instead of appearing as a User-sourced removal.

## Best solution

The keybindings editor model (`src/vs/workbench/services/preferences/browser/keybindingsEditorModel.ts`) should also consume negated/removed user keybinding entries (from `keybindings.json`) and present them in the list as User-sourced items with no active key, allowing the user to find and reset them.
