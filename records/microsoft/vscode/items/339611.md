# Issue #339611 — Renderer OOM during Copilot external ingest: unbounded file search returns millions of files

[https://github.com/microsoft/vscode/issues/339611](https://github.com/microsoft/vscode/issues/339611)

## Summary

Keep open: current main retains the effectively unlimited external-ingest search, and an independent reporter confirms repeated renderer OOMs with crash stacks in the matching search-result path. Disabling external ingest is a confirmed mitigation, not a resolution.

## Change summary

Prevent background Copilot external-ingest reconciliation from exhausting renderer memory when enumerating very large remote workspaces.

## Best solution

Make external-ingest discovery resource-bounded and cancellable without treating incomplete enumeration as evidence that existing indexed files were deleted. Establish the behavior for workspaces exceeding the discovery budget, then validate both reconciliation correctness and renderer memory behavior.
