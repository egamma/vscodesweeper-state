# Issue #339611 — Renderer OOM during Copilot external ingest: unbounded file search returns millions of files

[https://github.com/microsoft/vscode/issues/339611](https://github.com/microsoft/vscode/issues/339611)

## Summary

Keep open: current main still performs effectively unlimited external-ingest enumeration and retains search results in the renderer. The report supplies sufficient conditions and diagnostics to retest; the exact renderer-OOM causality remains unconfirmed, and subsequent search filtering does not bound the initial query.

## Change summary

Prevent Copilot external-ingest initialization from exhausting renderer memory while enumerating very large remote workspaces.

## Best solution

Make external-ingest reconciliation resource-bounded and cancellable without treating an incomplete scan as proof that existing indexed files were deleted. Confirm the reported crash path with a controlled large-workspace reproduction and define graceful behavior when enumeration exceeds the supported budget.
