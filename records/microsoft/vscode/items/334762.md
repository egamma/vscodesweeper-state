# Issue #334762 — Accessibility blocker: no one-click way to select or copy the entire Copilot response

[https://github.com/microsoft/vscode/issues/334762](https://github.com/microsoft/vscode/issues/334762)

## Summary

Current main already ships exactly what's being asked for: every Copilot chat response has a persistent, keyboard-accessible 'Copy' button in its footer toolbar that copies the entire response (as Markdown) with no mouse selection needed, so this is already-implemented behavior.

## Change summary

Requests a one-click/keyboard-accessible way to copy an entire Copilot chat response without manual mouse-drag text selection.

## Best solution

Point the reporter to the existing per-response 'Copy' button in the chat message footer toolbar (command `workbench.action.chat.copyItem`, registered on `MenuId.ChatMessageFooter`) — it's reachable via Tab/keyboard and copies the full response via `stringifyItem`/`toPortableMarkdown`, without requiring a text selection.

## Evidence

- **footer copy action:** src/vs/workbench/contrib/chat/browser/actions/chatCopyActions.ts registers `CopyItemAction` (id `workbench.action.chat.copyItem`, Codicon.copy) on `MenuId.ChatMessageFooter` with `when: ChatContextKeys.isResponse`, copying `stringifyItem(item, false)` as portable Markdown to the clipboard.
- **rendered per response:** src/vs/workbench/contrib/chat/browser/widget/chatListRenderer.ts (around line 1146-1160) always creates a `footerToolbarContainer`/`MenuWorkbenchToolBar` bound to `MenuId.ChatMessageFooter` for each list item unless `rendererOptions.noFooter` is set — so the Copy button is visible on every response by default.
- **keyboard reachable:** The footer toolbar is a standard MenuWorkbenchToolBar item, reachable via Tab/arrow-key navigation without requiring a mouse drag/selection, satisfying the 'keyboard access to copy the complete response' ask.
- **context-menu alternative:** A `CopyFinalResponseAction` (`workbench.action.chat.copyFinalResponse`) also exists on `MenuId.ChatContext` for copying just the final response text.
