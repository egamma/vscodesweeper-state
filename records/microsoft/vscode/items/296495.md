[https://github.com/microsoft/vscode/issues/296495](https://github.com/microsoft/vscode/issues/296495)

## Summary

Keep open and route to terminal: the reported Arabic shaping, directionality, and cursor limitations match the unresolved xterm.js RTL work. The matching older VS Code terminal reports are closed, so they are not valid duplicate targets.

## Change summary

Support connected Arabic glyphs, bidirectional text layout, and correct cursor positioning in the integrated terminal.

## Best solution

Resolve shaping and bidirectional terminal layout in xterm.js, then adopt that behavior in VS Code while preserving terminal grid, selection, and cursor semantics. Renderer configuration may improve individual examples but does not satisfy the complete request.
