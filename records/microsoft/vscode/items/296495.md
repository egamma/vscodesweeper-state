# Issue #296495 — Arabic (RTL) Rendering Issues in Integrated Terminal on macOS

[https://github.com/microsoft/vscode/issues/296495](https://github.com/microsoft/vscode/issues/296495)

## Summary

Verified duplicate: Arabic/RTL rendering in the integrated terminal is a known xterm.js limitation tracked upstream at xtermjs/xterm.js#701. Multiple prior VS Code issues (#271615, #210391, #72581, #28571) have been closed as duplicates of this same upstream gap. The most recent equivalent, #271615, was closed with `upstream` + `*duplicate`.

## Change summary

Arabic text renders with disconnected glyphs and broken RTL direction in the VS Code integrated terminal on macOS.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/271615 (or the upstream https://github.com/xtermjs/xterm.js/issues/701). The fix requires BiDi and Arabic shaping support in xterm.js itself; no VS Code-side change can address it.
