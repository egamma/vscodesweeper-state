# Issue #296495 — Arabic (RTL) Rendering Issues in Integrated Terminal on macOS

[https://github.com/microsoft/vscode/issues/296495](https://github.com/microsoft/vscode/issues/296495)

## Summary

This is a known xterm.js limitation (xtermjs/xterm.js#701) that has been reported and closed as duplicate multiple times in VS Code. The canonical VS Code issue for RTL support is #11770; prior identical Arabic terminal reports (#271615, #210391) were closed by a maintainer as duplicates of that upstream tracking issue.

## Change summary

Arabic/RTL text renders incorrectly in the integrated terminal — characters appear disconnected, direction is wrong, and cursor movement is broken.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/11770 which tracks RTL language support broadly, and the upstream xterm.js issue https://github.com/xtermjs/xterm.js/issues/701 which owns the terminal-specific BiDi/shaping work. No action needed in VS Code core until xterm.js ships BiDi support.
