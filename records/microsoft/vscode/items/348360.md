# Issue #348360 — Stop button throws away all context from the turn

[https://github.com/microsoft/vscode/issues/348360](https://github.com/microsoft/vscode/issues/348360)

## Summary

Keep open: the reported Stop → follow-up sequence is sufficient to retest, and current source exposes a plausible cancellation-time history gap without conclusively reproducing it. Current code already preserves some cancelled tool-call loops, so the exact failing boundary needs isolation rather than assuming every stopped turn is discarded.

## Change summary

Stopping an agent turn should retain its completed work in subsequent model context and indicate that the turn was interrupted.

## Best solution

Preserve completed tool calls, results, and supported conversation content when a turn is cancelled, while stopping execution promptly. Diagnose cancellation separately from crash recovery; neither should be judged solely from the model's claims about its memory.
