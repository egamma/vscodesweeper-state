# Issue #184404 — Different Font Setting for Light/Dark modes.

[https://github.com/microsoft/vscode/issues/184404](https://github.com/microsoft/vscode/issues/184404)

## Summary

A real accessibility-oriented configuration gap remains: VS Code can automatically select light and dark color themes, but cannot select corresponding editor typography. The Backlog milestone and recent confirmations support keeping the request open.

## Change summary

Allow editor font family, weight, size, and line height to vary automatically between light and dark appearance modes.

## Best solution

Extend appearance-aware configuration so light and dark modes can select editor typography alongside their preferred color themes, likely through the workbench theme configuration and editor configuration layers.

## Evidence

- **current source:** src/vs/workbench/services/themes/common/themeConfiguration.ts defines window.autoDetectColorScheme and preferred light/dark color themes, but no corresponding appearance-aware typography settings.
- **existing capability gap:** Editor font family, weight, size, and line height remain ordinary editor configuration in src/vs/editor/common/config/editorOptions.ts; automatic theme selection does not override them.
- **prior related request:** https://github.com/microsoft/vscode/issues/103422 requested the same theme-specific font capability but was closed only by the historical community upvote process, not because it was implemented or superseded.
- **continued demand:** Two later commenters independently describe needing heavier fonts in light mode, including for projector presentations, while preferring lighter fonts in dark mode.
