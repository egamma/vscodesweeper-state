# Issue #184404 — Different Font Setting for Light/Dark modes.

[https://github.com/microsoft/vscode/issues/184404](https://github.com/microsoft/vscode/issues/184404)

## Summary

Keep this accepted Backlog request open: automatic color-theme switching does not provide corresponding editor font preferences, and existing token styling only partially covers the request. A newer related request reinforces demand but cannot serve as the canonical for this re-reviewed item.

## Change summary

Automatically select different font families, weights, sizes, and line heights when switching between light and dark appearance.

## Best solution

Provide opt-in appearance-dependent editor typography while preserving ordinary font settings when no overrides are configured. Settle whether overrides follow the active theme's light/dark classification or individual named themes, and coordinate the overlapping font-weight work with https://github.com/microsoft/vscode/issues/185538.

- **Behavior:**

  > Users currently adjust typography manually after light/dark transitions to maintain reading comfort. The desired outcome is automatic selection of configured font family, numeric weight, size, and line height for the applicable appearance or theme. Acceptance must cover both existing and newly opened editors, automatic and manual theme transitions under the chosen semantics, and unchanged behavior for users without overrides.
- **Trace:**

  > src/vs/workbench/services/themes/common/themeConfiguration.ts registers automatic light/dark color-theme selection and theme-scoped token customizations, but not appearance-scoped editor typography. src/vs/workbench/services/themes/common/colorThemeSchema.ts already permits token font family and size/line-height multipliers, so the design must distinguish token styling from editor-wide font settings. Editor options are defined in src/vs/editor/common/config/editorOptions.ts and font information is computed from validated options in src/vs/editor/browser/config/editorConfiguration.ts; theme restoration and configuration listeners live in src/vs/workbench/services/themes/browser/workbenchThemeService.ts. - **Open decisions:**

## Evidence

- **Existing automatic switching:** src/vs/workbench/services/themes/common/themeConfiguration.ts registers window.autoDetectColorScheme and workbench.preferredLightColorTheme/workbench.preferredDarkColorTheme for choosing color themes, not editor font preferences.
- **Existing capability is partial:** themeConfiguration.ts supports theme-scoped editor.tokenColorCustomizations. src/vs/workbench/services/themes/common/colorThemeSchema.ts permits token fontStyle, fontFamily, fontSize, and lineHeight, but fontStyle only offers bold/italic/underline/strikethrough combinations, not independent numeric font weights.
