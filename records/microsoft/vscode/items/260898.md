# Issue #260898 — `Keybinding` for `Git: Open Containing Folder` doesn't work

[https://github.com/microsoft/vscode/issues/260898](https://github.com/microsoft/vscode/issues/260898)

## Summary

Still reproduces on main: the `git.revealInExplorer` and `git.revealFileInOS.*` commands silently bail when invoked via keybinding because no `resourceState` is passed. An open PR (#297211) already addresses this.

## Change summary

Keybinding invocation of Git reveal/open-containing-folder commands does nothing because the commands require a `SourceControlResourceState` argument that is only supplied by context-menu invocation.

## Best solution

Land the open fix PR (https://github.com/microsoft/vscode/pull/297211), which adds fallback logic to resolve the selected SCM resource when the command is invoked without a `resourceState` argument (i.e. via keybinding).
