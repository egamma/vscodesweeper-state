# Issue #334397 — Agents window: sessions from different folders with the same basename collapse into one workspace section

[https://github.com/microsoft/vscode/issues/334397](https://github.com/microsoft/vscode/issues/334397)

## Summary

The same-basename collision remains directly reproducible from current source: distinct workspace URIs still produce one section. Keep this open for a bounded sessions-list correction covering section identity, disambiguation, and workspace-scoped actions.

## Change summary

Keep sessions from distinct, same-named workspaces in separate, distinguishable sections with independent presentation state and drag-and-drop scope.

## Best solution

Workspace sections should represent workspace identity rather than display-name equality, with enough visible and accessible context to distinguish identical names. Grouping, collapse and ordering state, drag-and-drop acceptance, and section actions should consistently address the same workspace without changing provider or repository/worktree semantics.
