# Issue #334397 — Agents window: sessions from different folders with the same basename collapse into one workspace section

[https://github.com/microsoft/vscode/issues/334397](https://github.com/microsoft/vscode/issues/334397)

## Summary

Confirmed on current main: `groupByWorkspace()` in sessionsList.ts keys its Map purely on `session.workspace.get()?.label`, so distinct folders sharing a basename (e.g. multiple `<ws>/src` layouts) collapse into one section even though `ISessionWorkspace.uri` and `description` already carry the disambiguating info.

## Change summary

Agents window groups sessions by workspace display label only, so different folders with the same basename merge into a single section (and share collapse/expand state and DnD scope).

## Best solution

Key `groupByWorkspace()` (and the related section-id, expanded-state, and DnD 'same workspace' checks in src/vs/sessions/contrib/sessions/browser/views/sessionsList.ts) on the workspace URI instead of the label, falling back to label only when no URI is present, and surface `description` (parent path) on the section header so same-named sections stay distinguishable.
