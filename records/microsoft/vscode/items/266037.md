# Issue #266037 — Extension pre-release and recommended modifiers are applied inconsistently

[https://github.com/microsoft/vscode/issues/266037](https://github.com/microsoft/vscode/issues/266037)

## Summary

Keep open: current source still uses icon bookmarks in extension lists and a text pre-release tag on the details page, so the proposed consistent tag treatment remains missing. The team-supported design needs to resolve narrow-width layouts and coexistence with ratings and install counts before implementation.

## Change summary

Replace inconsistent extension pre-release and recommendation indicators with a coherent, readable treatment across list and details views.

## Best solution

Finish the proposed tag design for extension lists and details, including compact layouts, simultaneous indicators, and metadata coexistence, then implement it in the extension widgets and renderer. Preserve the distinction between an available pre-release version and the installed pre-release state; do not conflate MCP workspace indicators with extension recommendations.
