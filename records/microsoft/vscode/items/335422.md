# Issue #335422 — Format AI credit amounts with locale-aware digit grouping

[https://github.com/microsoft/vscode/issues/335422](https://github.com/microsoft/vscode/issues/335422)

## Summary

Verified against current main: `formatCopilotCredits` in chatService.ts does `parseFloat(credits.toFixed(1)).toString()` with no digit grouping, so a session cost of 12268 renders as a plain "12268 credits" everywhere this shared helper is used — the request is real and unaddressed.

## Change summary

Format displayed AI/Copilot credit amounts (session cost, subagent credits, etc.) with locale-aware thousands separators instead of raw digit strings.

## Best solution

Update `formatCopilotCredits` in src/vs/workbench/contrib/chat/common/chatService/chatService.ts to run its formatted number through `safeIntl.NumberFormat` (already used elsewhere in this area, e.g. chatStatusDashboard.ts) so every caller (chatSubagentContentPart.ts, chatSubagentOpenChat.ts, chatContextUsageDetails.ts, stateToProgressAdapter.ts) picks up locale-aware grouping for free; the secondary "122.68" currency-style suggestion in the body is a separate, more speculative ask and can be left to maintainer discretion.
