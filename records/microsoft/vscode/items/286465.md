# Issue #286465 — New task is created when one already exists from folder

[https://github.com/microsoft/vscode/issues/286465](https://github.com/microsoft/vscode/issues/286465)

## Summary

Keep open: the npm-provider and recently-used paths can still give the same task different execution identities, bypassing the running-instance check. The related restart issue was explicitly closed with this remaining defect split out for follow-up.

## Change summary

Running an already-active npm task from recent history should recognize the instance started through the npm picker instead of launching another instance.

## Best solution

Make running-instance recognition consistent across provider-discovered and history-restored representations of the same npm task. Preserve termination confirmation, explicit task customizations, workspace boundaries, and configured instance limits.
