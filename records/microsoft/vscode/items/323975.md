- **Current signing and packaging path:** build/azure-pipelines/win32/codesign.ts invokes spawnCodesignProcess with '*.ps1,*.psm1,*.psd1,*.ps1xml', awaits the signing process, then creates the client ZIP. build/azure-pipelines/win32/steps/product-build-win32-sign.yml supplies the client and server folders. Signing is intended, but source inspection cannot verify the signed bytes in the affected release artifact.
- **Terminal failure path:** src/vs/platform/terminal/node/terminalEnvironment.ts:328-330 wraps Windows PowerShell's dot-sourcing of shellIntegration.ps1 in try/catch and explicitly notes that execution-policy errors are swallowed for archive distributions. This explains how a rejected script can leave shell integration inactive; it does not identify the cause of HashMismatch.
