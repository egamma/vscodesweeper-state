# Issue #258837 — Snippets not showing up in terminal

[https://github.com/microsoft/vscode/issues/258837](https://github.com/microsoft/vscode/issues/258837)

## Summary

Valid feature request from a team member: terminal suggest does not surface user/language snippets. No snippet integration exists in the terminal suggest contribution on current main, and no work toward it has landed. Keeping open.

## Change summary

User-defined and language snippets should appear in the terminal REPL's suggest/completion list, as they do in the editor.

## Best solution

Integrate the snippet completion provider into the terminal suggest pipeline so that snippets registered for the terminal's active language scope appear alongside other completions. The work likely lives in `src/vs/workbench/contrib/terminalContrib/suggest/` and would need to pull from the snippet service (`ISnippetsService`).
