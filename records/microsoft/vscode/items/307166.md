# Issue #307166 — Copilot cannot read the output of `node -v`

[https://github.com/microsoft/vscode/issues/307166](https://github.com/microsoft/vscode/issues/307166)

## Summary

Keep open: the current source incorrectly treats the leading 'v' in Node's version output as a partial command echo and removes the entire output line. This explains the reporter's command matrix and provides a bounded diagnosis.

## Change summary

Copilot's terminal tool discards legitimate Node.js version output for commands ending in '-v'.

## Best solution

Preserve legitimate stdout when it coincides with a command suffix, while retaining correct removal of actual wrapped command echoes and shell prompts in the terminal execution strategies.
