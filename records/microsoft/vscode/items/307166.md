# Issue #307166 — Copilot cannot read the output of `node -v`

[https://github.com/microsoft/vscode/issues/307166](https://github.com/microsoft/vscode/issues/307166)

## Summary

Still reproduces on main: the suffix-matching logic in `findCommandEcho` incorrectly treats the output `v24.14.1` as a wrapped command-echo continuation of `node -v` because the single character `v` is a suffix of the command that also starts the output, causing the entire output to be stripped.

## Change summary

Copilot's `run_in_terminal` tool returns empty output for `node -v` because the output-stripping heuristic falsely matches the output as a command echo suffix.

## Best solution

Add a minimum suffix length threshold (e.g. ≥3 characters) in the suffix-matching branch of `findCommandEcho` in `src/vs/workbench/contrib/terminalContrib/chatAgentTools/browser/executeStrategy/strategyHelpers.ts` to prevent very short (1–2 char) suffixes from being treated as wrapped command echoes. This prevents false positives like `v` matching `v24.14.1`.
