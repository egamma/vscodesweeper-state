# Issue #249690 — [html] Rename Symbol doesn't work on attribute names

[https://github.com/microsoft/vscode/issues/249690](https://github.com/microsoft/vscode/issues/249690)

## Summary

This is a valid but underspecified feature request: HTML rename currently supports tag names, while the requested semantics for attribute names and especially attribute values are not defined. The Backlog milestone permits review, but there is no verified duplicate, shipped implementation, or maintainer decision supporting closure.

## Change summary

Extend HTML Rename Symbol so F2 can rename attribute names or attribute values instead of returning “No result.”

## Best solution

The HTML language feature owners should first define safe rename semantics: attribute-name rename could update matching attributes in an appropriate scope, while arbitrary attribute values should remain unsupported unless the language service can identify a semantic relationship such as IDs and references. Then implement the agreed behavior in the HTML language service and expose it through the built-in HTML extension.
