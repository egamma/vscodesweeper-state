# Issue #241855 — Bash env doesn't update on first `unset`

[https://github.com/microsoft/vscode/issues/241855](https://github.com/microsoft/vscode/issues/241855)

## Summary

Keep open: current Bash environment reporting still retains cached variables after they are unset. The original arbitrary-variable example no longer matches the reporting allowlist, but the underlying deletion defect remains for supported variables.

## Change summary

Remove an unset Bash variable from the shell-integration environment snapshot at the next prompt.

## Best solution

Make removal of currently reported variables visible immediately through terminal.shellIntegration.env and its change event, preserving the existing reporting allowlist and nonce semantics. Do not expand arbitrary-variable reporting as part of this bug fix.
