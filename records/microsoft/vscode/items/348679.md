Keep open: the current source permits Explain to reach a capability rejection that tells users to update the agent host without explaining how. This collaborator-authored report has no verified fix or canonical duplicate.

## Change summary

Make Explain usable or meaningfully unavailable on assisted permission requests, and distinguish approval warnings from execution errors.

## Best solution

Align Explain availability with support for context-free explanations and provide actionable guidance when the connected host cannot support them, without silently inheriting conversation history. Review the approval-reason icon separately so a pending permission decision does not imply execution has failed.
