# Issue #169581 — Show inlay hints on current line, or selection

[https://github.com/microsoft/vscode/issues/169581](https://github.com/microsoft/vscode/issues/169581)

## Summary

Keep open: current inlay-hint settings control visibility across the editor, not a command-scoped current line or selection. The older related requests cover configurable shortcuts and hint-length limits, neither of which owns this request.

## Change summary

Provide a command to toggle inlay hints for the current line or selected range.

## Best solution

Support localized, on-demand hint visibility in the editor's inlay-hint contribution while preserving existing editor-wide modes. Settle whether the command targets a captured range or follows the cursor and selection before implementing.
