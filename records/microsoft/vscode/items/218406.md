# Issue #218406 — Right clicking an item selects a different item

[https://github.com/microsoft/vscode/issues/218406](https://github.com/microsoft/vscode/issues/218406)

## Summary

Still present on main — the webview context menu handler in `webviewElement.ts` does not ensure the hosting editor pane is focused/active before showing the context menu, so right-clicking can show a context menu while another editor tab remains selected. Already triaged with `help wanted` and `On Deck` milestone; no fix has landed.

## Change summary

Right-clicking an image in image preview selects a different editor tab instead of keeping focus on the right-clicked tab.

## Best solution

The `did-context-menu` handler in `src/vs/workbench/contrib/webview/browser/webviewElement.ts` should ensure the webview's containing editor pane is focused/activated before invoking `showContextMenu`, so the selection state matches the right-clicked tab. A `help wanted` contribution can address this.
