# Issue #325827 — Support registration of external agents via Extension API in the agents view

[https://github.com/microsoft/vscode/issues/325827](https://github.com/microsoft/vscode/issues/325827)

## Summary

Genuine feature request for a deep Extension API surface to register full agent host providers alongside the built-in Copilot/Claude/Codex agents. No existing API or proposed API covers this; the architecture is currently hardcoded. The request is well-articulated but represents a significant architectural decision that needs team input.

## Change summary

Allow extensions to register full IAgent implementations (with their own SDKs) into the agent host, so third-party agents appear in the agents view alongside built-in ones.

## Best solution

This needs a product decision from the agent host team. The current architecture runs agent providers in a separate utility process (`agentHostMain.ts`) with deep IPC contracts — exposing `IAgent` via the Extension API would require a significant new API surface, process-boundary bridging, and security/sandboxing design. If pursued, a proposed API (`vscode.proposed.agentHostProvider.d.ts`) would be the starting point. The team should evaluate whether the existing `ChatCustomAgentProvider` (prompt-based agents) can be extended to cover more use cases first, or whether full agent-host-level extensibility is the right abstraction.
