# Issue #286277 — Large pasted content in Copilot Chat silently dropped - message appears empty to AI

[https://github.com/microsoft/vscode/issues/286277](https://github.com/microsoft/vscode/issues/286277)

## Summary

Current main prevents the reported silent loss by converting sufficiently large plain-text pastes into named chat attachments while preserving their full contents. This behavior was added after the report and is covered by a focused test, so the issue can be closed as completed.

## Change summary

Large console-log pastes could be submitted as empty prompts without warning that their contents had been discarded.

## Best solution

Keep the large-paste attachment behavior introduced by commit 0d5a81a060b1b89879bf10c5415ea94b5a0b175a: the prompt contains an attachment reference and the complete pasted text remains available to the request.
