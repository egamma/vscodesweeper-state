# Issue #347103 — View focus previous part gets stuck in chat input or editor

[https://github.com/microsoft/vscode/issues/347103](https://github.com/microsoft/vscode/issues/347103)

## Summary

Keep open: the auxiliary-window focus cycle cannot distinguish the chat and editor parts, and the Agents layout redirects editor focus back to the active group. This corroborates the collaborator's reported keyboard-navigation failure.

## Change summary

Focus Next Part and Focus Previous Part should move between the visible editor and chat parts instead of retaining focus.

## Best solution

Make part traversal recognize the separate visible content parts in chat windows while preserving existing navigation in the main workbench and ordinary auxiliary editor windows.
