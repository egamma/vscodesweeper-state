# Issue #311324 — Terminal title changes in unexpected ways

[https://github.com/microsoft/vscode/issues/311324](https://github.com/microsoft/vscode/issues/311324)

## Summary

Valid bug: when `allowAgentCliTitle` is false, the terminal title still changes from the shell name to the agent CLI's version string. No fix found on current main.

## Change summary

Terminal title changes from 'zsh' to '2.1.114' (Claude's version) even when `allowAgentCliTitle` is disabled.

## Best solution

The `_onTitleChange` handler (line ~1922 in terminalInstance.ts) unconditionally calls `_setTitle` with the OSC sequence value, and on macOS the pty may also report it as `ProcessPropertyType.Title`. When `allowAgentCliTitle` is false and the shell type is a known agent CLI, the sequence/process-title update should be suppressed (or `_processName` should not be overwritten) so the template `${process}` continues to resolve to the original shell name.
