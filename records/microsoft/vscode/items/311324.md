## Summary

Keep open: the report gives sufficient macOS steps to retest the unexpected version-number title with agent titles disabled. Current source still permits process-name changes independently of that setting; subsequent title-handling changes do not establish that this particular behavior is fixed.

## Change summary

Launching Claude Code on macOS changes the terminal title from zsh to 2.1.114 despite terminal.integrated.tabs.allowAgentCliTitle being disabled.

## Best solution

Ensure the configured terminal title remains a useful process or shell identity when agent-provided titles are disabled. First reproduce the reported Claude launch and distinguish the foreground process name from its OSC title before deciding whether VS Code needs a correction.
