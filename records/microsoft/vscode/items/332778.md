# Issue #332778 — Copilot Chat composer

[https://github.com/microsoft/vscode/issues/332778](https://github.com/microsoft/vscode/issues/332778)

## Summary

Confirmed on main: the chat input editor's font family and size are hard-coded (13px, DEFAULT_FONT_FAMILY) with no configuration path, distinct from the existing `chat.fontFamily`/`chat.fontSize` (rendered messages) and `chat.editor.fontFamily`/`chat.editor.fontSize` (codeblocks) settings — a real, unrouted feature gap worth flagging to the chat area owners.

## Change summary

Expose user settings to control the Copilot Chat composer's (input editor) font family and size, independent of chat message and codeblock font settings.

## Best solution

Add `chat.input.fontFamily`/`chat.input.fontSize` settings alongside the existing `chat.fontFamily`/`chat.editor.fontFamily`, and read them in `updateInputEditorFontFamily()`/the initial editor construction options in chatInputPart.ts instead of the hard-coded `DEFAULT_FONT_FAMILY`/`13`.
