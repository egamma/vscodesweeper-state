# Issue #282687 — Maintain /Plan mode todo list after adding a new message to the chat

[https://github.com/microsoft/vscode/issues/282687](https://github.com/microsoft/vscode/issues/282687)

## Summary

Legitimate feature request for plan persistence/versioning in Copilot plan mode. Recent work on the background todo agent (cross-turn scoping, dropping completed todos) touches adjacent code but does not address the core ask of preserving the original plan when follow-up messages are sent. Already labeled under-discussion; stays open.

## Change summary

When a new message is added in Copilot plan mode, the original todo list/plan is replaced by a new one, with no way to recover it.

## Best solution

Implement plan persistence so that follow-up messages either append to or version the existing plan rather than replacing it. The relevant code lives in `extensions/copilot/src/extension/prompt/node/todoListContextProvider.ts` and the manageTodoListTool. A plan-stacking or pinning mechanism would address this without disrupting the current single-plan flow.
