# Issue #282687 — Maintain /Plan mode todo list after adding a new message to the chat

[https://github.com/microsoft/vscode/issues/282687](https://github.com/microsoft/vscode/issues/282687)

## Summary

Keep open under discussion: current todo storage still permits replacement of the active plan, and existing plan persistence does not provide todo versioning or pinning. The related reports examined do not establish an older canonical covering the same symptom.

## Change summary

Preserve or recover the original planning todo list when follow-up messages or interrupted execution generate another list.

## Best solution

Provide a recoverable original todo plan across follow-up requests and interruptions in the chat todo lifecycle. Maintainers should first choose whether that means selectable history, preservation of the active list, or explicit pinning; these have different user-visible semantics.
