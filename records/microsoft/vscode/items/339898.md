# Issue #339898 — scrolling up on chat collapses the expanded box

[https://github.com/microsoft/vscode/issues/339898](https://github.com/microsoft/vscode/issues/339898)

## Summary

Fresh team-authored bug report (filed while testing another chat change) with a clear, deterministic description and an attached video showing an expanded thinking/tool step collapsing only when scrolling up, not down — keeping open for investigation; the exact root cause in the virtualized chat list still needs to be pinned down.

## Change summary

An expanded chat 'thinking'/progress step collapses unexpectedly when the user scrolls up past it, but not when scrolling down, forcing the user to re-expand it repeatedly.

## Best solution

Diagnose why scrolling up (but not down) in the chat list causes ChatThinkingContentPart.collapseContentWhenUnfocused's FOCUS_OUT listener (src/vs/workbench/contrib/chat/browser/widget/chatContentParts/chatThinkingContentPart.ts) to fire — likely related to virtualized-list row recycling moving focus during upward scroll — and make the auto-collapse-on-unfocus logic scroll-direction agnostic.
