# Issue #314319 — Better unusual unicode char highlight

[https://github.com/microsoft/vscode/issues/314319](https://github.com/microsoft/vscode/issues/314319)

## Summary

The requested language-specific control already exists: Unicode highlighting settings support language overrides, so prose files can disable highlighting while code retains its existing settings.

## Change summary

Allow unusual Unicode highlighting to be disabled for plain text, Markdown, and LaTeX without disabling it in source code.

## Best solution

Use language-specific user settings for plaintext, markdown, and latex rather than adding another control. Disable the three Unicode highlighting categories in those language modes and leave other languages unchanged.

- **Proposed comment:**

  > Thanks for the request. Unicode highlighting already supports language-specific settings. Add this block inside your user settings.json to disable it for plain text, Markdown, and LaTeX while leaving your code settings unchanged:
  > 
  > ```json
  > "[plaintext][markdown][latex]": {
  >   "editor.unicodeHighlight.nonBasicASCII": false,
  >   "editor.unicodeHighlight.ambiguousCharacters": false,
  >   "editor.unicodeHighlight.invisibleCharacters": false
  > }
  > ```
  > 
  > If you still want invisible characters highlighted in prose, leave `editor.unicodeHighlight.invisibleCharacters` enabled. See https://code.visualstudio.com/docs/configure/settings#_language-specific-editor-settings.
