# Issue #161991 — Allow me to continue in an existing location?

[https://github.com/microsoft/vscode/issues/161991](https://github.com/microsoft/vscode/issues/161991)

## Summary

A real gap remains for continuing in an existing Codespace. Core now supports existing local folders and extension-contributed destinations, but the Codespaces provider still owns selecting and reconciling an existing Codespace.

## Change summary

Allow Continue Working On to target a previously created environment, particularly an existing Codespace.

## Best solution

Move this issue to https://github.com/microsoft/vscode-remote-release so the Codespaces extension can contribute a “Continue in Existing Codespace” destination, including safeguards for divergent branches and unpublished changes. Preserve this thread because it is the canonical request and contains the relevant state-transfer concerns.
