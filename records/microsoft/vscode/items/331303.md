# Issue #331303 — No history on search

[https://github.com/microsoft/vscode/issues/331303](https://github.com/microsoft/vscode/issues/331303)

## Summary

Team-authored bug report from testing the chat transcript Find widget (TPI https://github.com/microsoft/vscode/issues/330953): Up-arrow doesn't recall search history. Tracing the source confirms ChatFindWidget never wires a history source into its find input, unlike the editor's own Find widget which supplies a persisted history set — this stays open pending a fix (team-authored items are not judgment-closed anyway).

## Change summary

In the chat transcript Find widget, pressing the Up arrow in the find input does not recall previously searched terms.

## Best solution

Give ChatFindWidget a history source for its ContextScopedFindInput, mirroring how the editor's FindWidget passes a `history` set (backed by `FindWidgetSearchHistory.getOrCreate(storageService)` in src/vs/editor/contrib/find/browser/findController.ts) into IFindInputOptions — SimpleFindWidget's IFindOptions currently has no `history` field at all, so every SimpleFindWidget-based find (chat, terminal, webview, browser view) starts with an empty, non-persisted history.
