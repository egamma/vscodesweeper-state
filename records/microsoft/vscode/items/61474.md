# Issue #61474 — Expanding emmet abbreviations inside JSX inline functions not working

[https://github.com/microsoft/vscode/issues/61474](https://github.com/microsoft/vscode/issues/61474)

## Summary

Still reproduces on main: Emmet's `isValidLocationForEmmetAbbreviation` rejects positions inside JSX tag attribute values (like inline render functions), confirmed by contributors and traceable in current source.

## Change summary

Emmet abbreviation expansion fails inside JSX inline functions passed as tag props because the location validator rejects positions inside attribute values.

## Best solution

The fix belongs in `extensions/emmet/src/abbreviationActions.ts` in the `isValidLocationForEmmetAbbreviation` function — for JSX/TSX syntax, positions inside attribute values that contain JSX expressions (arrow functions returning JSX) should be treated as valid expansion locations. The reporter's suggestion of a `emmet.validateAbbreviationLocation` setting is also a reasonable escape hatch.
