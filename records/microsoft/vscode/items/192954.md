# Issue #192954 — Setting `workbench.editorAssociations` to change the default open mode of markdown to preview doesn't work

[https://github.com/microsoft/vscode/issues/192954](https://github.com/microsoft/vscode/issues/192954)

## Summary

Fixed on main and shipped: on cold start, user-configured `workbench.editorAssociations` was ignored because the editor resolver didn't wait for extension registration when its cache was empty. Commit 22aaa657153 added a fallback check against user associations, fixing this exact scenario.

## Change summary

Setting `workbench.editorAssociations` to open markdown files in preview mode did not work on cold start (first launch), though it worked when VS Code was already running.

## Best solution

Keep the shipped fix in commit 22aaa657153 (1.116.0+). No further change needed — the cold-start editor association resolution now correctly waits for extension registration when the user has configured a custom editor association.
