## Summary

Legitimate, well-diagnosed request for a shared `.agents/` directory convention and manifest-based discovery to replace the growing pile of tool-specific top-level dotfolders; it's still within the 60-day/20-upvote backlog-candidate window (14 upvotes, 14 days old), so it should stay open as under-discussion rather than being judged now.

## Change summary

Add support for discovering agent configuration/skills/instructions under a shared `.agents/<tool>/` directory, and prefer manifest-declared resource paths over fixed directory conventions.

## Best solution

Let the community process run its course (20 upvotes / 60 days); if it gains traction, this belongs in the chat customization discovery layer (`src/vs/workbench/contrib/chat/common/promptSyntax/config/promptFileLocations.ts` and `extensions/copilot/src/platform/promptFiles/vscode-node/agentInstructionsLocator.ts`), which already enumerates AGENTS.md/.claude/.github conventions and would be the natural place to add `.agents/<tool>/` as another discovery root.
