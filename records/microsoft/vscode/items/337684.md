# Issue #337684 — Agent Host chat stays Working after final answer while an attached background server runs

[https://github.com/microsoft/vscode/issues/337684](https://github.com/microsoft/vscode/issues/337684)

## Summary

Confirmed lifecycle bug on current main: VS Code completes Copilot Agent Host turns only on `session.idle`, which an attached background shell can withhold after the final answer. Keep this team-authored issue open while the linked background-work implementation is reviewed and landed.

## Change summary

Allow an attached background server to remain session-owned without leaving completed Agent Host answers shown as Working indefinitely.

## Best solution

Represent attached background work independently from foreground conversational progress, complete the foreground turn once its model and foreground tools are done, and keep the server visible and session-owned for later notification and cleanup. Review and land the protocol work in https://github.com/microsoft/agent-host-protocol/pull/482 and its VS Code consumer in https://github.com/microsoft/vscode/pull/338723, then retain this issue for the remaining turn-completion behavior because that PR explicitly leaves completion unchanged.
