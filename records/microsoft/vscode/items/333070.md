# Issue #333070 — Session artifact pills - Convert comments, pipeline failures into alert pills (leverage sub-agent alert state UI for this)

[https://github.com/microsoft/vscode/issues/333070](https://github.com/microsoft/vscode/issues/333070)

## Summary

Keep open: current main consolidates comments and failing checks into a banner carousel, but does not deliver the requested alert-pill presentation. This team-authored design request still needs a decision on how actionable alerts coexist with artifact pills.

## Change summary

Present PR comments and pipeline failures as alert pills using a consistent attention-state treatment instead of separate banners.

## Best solution

Agree on a unified alert-pill interaction for session items requiring attention, preserving existing review and CI actions, dismissal behavior, and accessibility. Coordinate it with the session-artifacts tracker without treating that broader, newer tracker as a duplicate canonical.
