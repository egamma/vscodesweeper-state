# Issue #330954 — Mermaid Preview: Add support for image link's in Markdown

[https://github.com/microsoft/vscode/issues/330954](https://github.com/microsoft/vscode/issues/330954)

## Summary

The requested external-file embedding remains missing: built-in Mermaid rendering consumes inline diagram source, while Markdown image links remain ordinary images. Keep this open as a feature request; no verified canonical or completed implementation covers it.

## Change summary

Render a separate Mermaid source file referenced by Markdown image syntax, such as ![A graph](diagram.mmd), in the Markdown preview.

## Best solution

Consider external Mermaid source references within the bundled Markdown/Mermaid preview integration, preserving existing inline diagrams and ordinary image behavior. The product decision should establish supported reference types and refresh behavior before implementation.
