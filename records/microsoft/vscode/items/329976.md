# Issue #329976 — No sign-in prompt when you try to open a remote GitHub repo in agents window

[https://github.com/microsoft/vscode/issues/329976](https://github.com/microsoft/vscode/issues/329976)

## Summary

Team-authored bug report filed same-day while dogfooding a very recent conditional-GitHub-auth feature for the Agents window (referencing microsoft/vscode#329737); no fix exists on main yet, so this should stay open and be routed to the sessions/agent-host area for follow-up.

## Change summary

When creating a new session and choosing a GitHub repository via the repo picker's Browse flow, the user is not prompted to sign in to GitHub if they are signed out.

## Best solution

The repo picker's browse-for-repo flow (src/vs/sessions/contrib/chat/browser/repoPicker.ts, which invokes github.copilot.chat.cloudSessions.openRepository) or the underlying GitHub repository browse command in extensions/copilot needs to trigger a sign-in prompt for signed-out users before letting them pick a repo, consistent with the per-type sign-in gate described in src/vs/sessions/browser/sessionsAuthGate.ts; the author (a maintainer working on the related conditional-auth feature) is best positioned to pin down the exact code path.
