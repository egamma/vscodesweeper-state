# Issue #337277 — Automations: support script-first actions with optional AI continuation

[https://github.com/microsoft/vscode/issues/337277](https://github.com/microsoft/vscode/issues/337277)

## Summary

Keep open: current Automations still create an agent session before executing work, so script-only runs and independent AI-continuation decisions remain missing. This team-authored Backlog request warrants design work on the signaling and run-status contracts.

## Change summary

Allow automations to execute scripts before optionally creating an AI session, preserving script results independently of continuation.

## Best solution

Support a host-owned script-first action with an explicit continuation contract and durable script results for all four exit-status/continuation combinations. Agree on the control-output protocol and overall status after AI recovery before implementation.
