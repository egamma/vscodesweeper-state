# Issue #299924 — "Gemini 3 Flash (Preview)" is actually "Gemini 2.0 Flash (Preview)"

[https://github.com/microsoft/vscode/issues/299924](https://github.com/microsoft/vscode/issues/299924)

## Summary

This is a support question based on a misunderstanding: asking an LLM "What model are you?" is not a reliable way to verify the model version — LLMs routinely hallucinate their own identity. The model picker label comes from the Copilot service and is authoritative; the model's self-report is not.

## Change summary

Reporter believes the model picker is mislabeled because the model self-identified as a different version when asked.

## Best solution

Close as a question — the model picker label is service-provided and authoritative; LLMs do not reliably self-identify their version. No code change is needed.
