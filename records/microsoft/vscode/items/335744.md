# Issue #335744 — Issues with VS Code Icons

[https://github.com/microsoft/vscode/issues/335744](https://github.com/microsoft/vscode/issues/335744)

## Summary

Same root cause as the widely-tracked Remote-SSH icon-loading regression (#334144): a referrer check on vscode-managed-remote-resource requests rejected legitimate icon/font/asset loads over Remote-SSH, and GitLens/extension icons rendered blank as a result. That was fixed on main in commit 365b48f9bc374b5eaadb5a38bd605f940081ae3a (merged 2026-09-09) and shipped in Insiders, with stable landing in 1.138 — the same fix that maintainers have used to close the entire cluster of nearly-identical follow-up reports.

## Change summary

GitLens (and other extension) icons render blank/missing while connected over Remote-SSH.

## Best solution

Treat as resolved by the same fix as #334144 (commit 365b48f9bc374b5eaadb5a38bd605f940081ae3a, 'remote: fix managed resource loading from workbench'), which removed the unreliable referrer check that was rejecting managed-remote-resource requests for icons/fonts over vscode-file scheme; confirm on 1.138 stable.
