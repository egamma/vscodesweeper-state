# Issue #325523 — Copilot chat shows ignored-files troubleshooting text in grep search tool completion UI

[https://github.com/microsoft/vscode/issues/325523](https://github.com/microsoft/vscode/issues/325523)

## Summary

The defect remains on current main: the grep-format no-results path assigns agent-oriented ignore-file troubleshooting text to the user-facing tool completion message. This is a bounded chat-tools bug that should remain open and be routed for correction.

## Change summary

Keep grep search troubleshooting guidance available to the model without displaying the full internal guidance in the completed tool UI.

## Best solution

Separate the grep tool's model-facing no-match guidance from its user-facing completion message, matching the existing tag-format behavior while retaining a concise localized no-results status for users.
