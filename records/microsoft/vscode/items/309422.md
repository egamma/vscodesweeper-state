# Issue #309422 — Artifacts widget does not dissapear when I set artifact rules to {}

[https://github.com/microsoft/vscode/issues/309422](https://github.com/microsoft/vscode/issues/309422)

## Summary

Keep open: current source retains default artifact rules when these object-valued settings are set to {}, contradicting the linked test plan. A second tester independently confirmed the same failure; the rule-versus-tool distinction does not explain away this configuration defect.

## Change summary

Explicitly empty artifact-rule settings should stop extracting matching screenshots and plans from existing conversations.

## Best solution

Make explicitly empty rule settings disable their corresponding automatic extraction while preserving defaults when settings are absent. Hide the widget when no artifacts remain, without clearing independently contributed artifacts or changing configuration merging globally.
