# Issue #340967 — Avoid restarting Agent Host when OTel settings change

[https://github.com/microsoft/vscode/issues/340967](https://github.com/microsoft/vscode/issues/340967)

## Summary

Keep open: current source still binds Agent Host OTel configuration at startup, requires application restart for personal setting changes, and restarts the shared host for settled enterprise-policy changes. Avoiding those restarts remains unfinished lifecycle work.

## Change summary

Allow Agent Host OTel configuration changes to take effect without restarting the Agent Host.

## Best solution

Support OTel reconfiguration without replacing the shared Agent Host or disrupting unrelated conversations, covering host-owned exporters and provider-native telemetry. Establish when changes affect already-running provider sessions while preserving enterprise-policy precedence.
