# Issue #340967 — Avoid restarting Agent Host when OTel settings change

[https://github.com/microsoft/vscode/issues/340967](https://github.com/microsoft/vscode/issues/340967)

## Summary

Thanks for the follow-up. This is team-authored, milestone-scheduled work and it is still needed: current main still restarts the Agent Host when the enterprise OTel policy changes.

## Change summary

Stop restarting the Agent Host when OTel settings or policy change, and apply the change at runtime.

## Best solution

Push OTel setting and policy updates to the running Agent Host, for example over an IPC or protocol call that reconfigures the OTel service, instead of relaunching the utility process. Keep the start-time env as the initial state.
