# Issue #288603 — "Transform to Snake Case" does nothing on kebab case text

[https://github.com/microsoft/vscode/issues/288603](https://github.com/microsoft/vscode/issues/288603)

## Summary

Confirmed on main: SnakeCaseAction only splits on camelCase boundaries (Ll→Lu transitions) and never replaces hyphens, so kebab-case input passes through unchanged. An open PR (#288817) exists but has not merged.

## Change summary

Transform to Snake Case command does nothing when the input is kebab-case because its regex only matches camelCase boundaries, not hyphens.

## Best solution

The fix should add hyphen handling to SnakeCaseAction._modifyText (replace `-` with `_` before or after the existing camelCase boundary logic) in src/vs/editor/contrib/linesOperations/browser/linesOperations.ts. An open PR already targets this — review and land it, or implement a similar fix.
