# Issue #261140 — Chat re-shows when hidden in side bar.

[https://github.com/microsoft/vscode/issues/261140](https://github.com/microsoft/vscode/issues/261140)

## Summary

Confirmed layout-state bug that remains open while draft PR https://github.com/microsoft/vscode/pull/266219 addresses the underlying view-container visibility handling.

## Change summary

A hidden Chat view becomes visible again after Explorer is moved to the secondary side bar and back, while the visibility menu still reports Chat as disabled.

## Best solution

Review and validate https://github.com/microsoft/vscode/pull/266219 against this reproduction, then land or revise it so hiding the last visible composite hides its part and restoring a visible composite reopens the correct container without resurrecting hidden views.
