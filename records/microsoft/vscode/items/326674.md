# Issue #326674 — different UI and options for different views

[https://github.com/microsoft/vscode/issues/326674](https://github.com/microsoft/vscode/issues/326674)

## Summary

The UI disparity remains on current main: Markdown comment cards support deletion but not the text editor's Edit and Add to Comment actions. This team-authored polish issue should stay open while the intended cross-view interaction is finalized from the linked design.

## Change summary

Make agent-feedback comment presentation and available actions consistent between the text editor and Markdown editor.

## Best solution

Give Markdown comment cards the intended editing and follow-up-comment capabilities while preserving synchronization with the shared session feedback store and limiting comment authoring to the Markdown editor's Locked mode.
