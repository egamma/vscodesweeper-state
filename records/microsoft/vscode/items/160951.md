# Issue #160951 — Accepting completion with multiline edits makes editor scroll jump higher

[https://github.com/microsoft/vscode/issues/160951](https://github.com/microsoft/vscode/issues/160951)

## Summary

Still reproducible on main: when a completion's insertText is multiline and additionalTextEdits delete/replace overlapping lines above the cursor, the main snippet insertion (which lacks StableEditorScrollState protection) causes a scroll jump. The maintainer flagged this as undefined behavior due to overlapping edits, but it remains a real UX issue for extensions using this pattern.

## Change summary

Accepting a completion item with multiline insertText and additionalTextEdits that overlap the main edit causes an unexpected scroll jump upward.

## Best solution

Either wrap the main snippet insertion (suggestController.ts ~line 444) in StableEditorScrollState capture/restore similar to the additionalTextEdits path, or document that overlapping additional edits are officially unsupported and consider an API warning. The former is more user-friendly; the fix would be localized to suggestController.ts.
