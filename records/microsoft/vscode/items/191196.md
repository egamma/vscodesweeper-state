# Issue #191196 — Unicode Highlighting Message Messes Up Alignment

[https://github.com/microsoft/vscode/issues/191196](https://github.com/microsoft/vscode/issues/191196)

## Summary

Keep open: current source still allows a Unicode warning banner on one diff pane to shift its text independently of the other pane. This team-authored Backlog bug has no verified fixing commit or canonical duplicate.

## Change summary

Showing the Unicode highlighting warning should not disturb alignment between corresponding lines in the diff editor.

## Best solution

Make diff-pane layout account for unequal Unicode banner heights so corresponding lines remain aligned when a warning appears or is dismissed, while retaining the warning and its actions.
