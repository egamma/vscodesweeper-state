# Issue #316242 — Copilot CLI agent panel: cannot attach screenshots or images when a multiple-choice ask_user prompt is active

[https://github.com/microsoft/vscode/issues/316242](https://github.com/microsoft/vscode/issues/316242)

## Summary

Current main still limits multiple-choice prompts to option selections and freeform text, so attaching visual context remains a real unsupported capability. Keep this open as a feature request; the answer and transport contracts need design work before implementation.

## Change summary

Allow screenshots or image attachments while answering a Copilot CLI ask_user multiple-choice prompt.

## Best solution

Let users submit image context with a structured answer without cancelling the active prompt, while preserving existing selection, freeform-text, keyboard, and accessibility behavior. Define how that attachment reaches the blocked agent operation consistently across the core question tool and Agent Host paths.

- **Validation:** Add question-carousel tests that paste and drop an image while a single- or multi-select question is active, submit it with an option or freeform response, and assert that the agent-facing result retains both the structured answer and image; existing text-only, keyboard-navigation, and cancellation tests must remain passing.
- **Behavior:**

  > While a structured ask_user question is active, the user can paste or drag an image into the prompt and submit it with a selected option or a freeform answer without cancelling the question. The agent receives the image as context for that answer. Existing text-only answers, option selection, skip/cancel behavior, keyboard navigation, and screen-reader behavior remain unchanged.
- **Trace:**

  > The current carousel in src/vs/workbench/contrib/chat/browser/widget/chatContentParts/chatQuestionCarouselPart.ts renders freeform input as a plain textarea and serializes only textual IChatQuestionAnswerValue variants from src/vs/workbench/contrib/chat/common/chatService/chatService.ts. The Copilot CLI bridge in extensions/copilot/src/extension/chatSessions/copilotcli/vscode-node/askUserQuestionHandler.ts receives only selected/freeText answers. The newer Agent Host path converts the same carousel through stateToProgressAdapter.ts and agentHostSessionHandler.ts, but its ChatInputAnswer protocol also has no attachment field. Normal chat messages already have attachment infrastructure, but this blocked input-request response is a separate contract. Preserve current answer semantics and avoid changing ordinary chat attachment handling outside this prompt flow.
- **Open decisions:**
  - Should an image be part of the structured input-request response itself, keeping the agent operation blocked until one combined answer is submitted, or should submitting it create a separate chat message that resumes or steers the conversation?
  - May an image accompany any selected option, or only the freeform alternative?
