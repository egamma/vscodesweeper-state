# Issue #328110 — tree-sitter PowerShell grammar cannot parse ~8% of realistic agent commands, blocking auto-approve suggestions

[https://github.com/microsoft/vscode/issues/328110](https://github.com/microsoft/vscode/issues/328110)

## Summary

Keep open as an upstream grammar limitation with a concrete impact on terminal auto-approval. The issue is distinct from the partial-parse safety defect because it tracks restoring useful approval suggestions for valid, commonly emitted commands.

## Change summary

Improve PowerShell parsing or suggestion fallback so valid commands containing bare `--` or leading `./path` can produce terminal auto-approve suggestions.

## Best solution

Fix the constructs in the upstream PowerShell grammar and update `@vscode/tree-sitter-wasm`; until then, consider a narrowly scoped masking or suggestion-only fallback that cannot weaken enforcement.
