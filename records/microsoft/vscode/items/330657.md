# Issue #330657 — CopilotCLIModels queries github.com instead of configured GitHub Enterprise host, causing repeated 401 Bad credentials

[https://github.com/microsoft/vscode/issues/330657](https://github.com/microsoft/vscode/issues/330657)

## Summary

Traced conclusively: CopilotCLIModels.getAuthInfo() (extensions/copilot/src/extension/chatSessions/copilotcli/node/copilotCli.ts, lines 662-700) calls the SDK's resolveAuthInfoFromToken(token) with only one argument and hardcodes host: 'https://github.com' in its fallback, never consulting the configured github-enterprise.uri/authProvider — a real, localized bug in this repo's own code.

## Change summary

The Copilot CLI model list repeatedly fails with 401 Bad credentials when VS Code is authenticated against a GitHub Enterprise host, because the user-info lookup queries github.com instead of the configured enterprise host.

## Best solution

In CopilotCLISDK.getAuthInfo(), derive the host the same way DomainService does (extensions/copilot/src/platform/endpoint/node/domainServiceImpl.ts, line 54: check ConfigKey.Shared.AuthProvider === AuthProviderId.GitHubEnterprise and read the 'github-enterprise.uri' non-extension config) and pass it as the second argument to resolveAuthInfoFromToken(token, host, options), and use the same resolved host (not a hardcoded 'https://github.com') in the fallback return at line 696.
