# Issue #345842 — Agents window: hidden Agent/Ask selector doesn't switch modes, and cross-session context appears incomplete

[https://github.com/microsoft/vscode/issues/345842](https://github.com/microsoft/vscode/issues/345842)

## Summary

Keep open to investigate the reported mode-switch failure. Current main explicitly synchronizes agent selection with chat input state, but the failure reported on 1.142.0 remains unconfirmed; the supplied interaction sequence is sufficient to retest.

## Change summary

Selecting Agent through Add Context appears ineffective, and the same menu creates confusion about referencing previous sessions.

## Best solution

Ensure agent selection, visible input state, and effective request behavior agree in the Agents window, with clear distinctions between selecting an agent and attaching conversation context. Track the broader session-context UX alongside the existing attachment request without treating it as a duplicate of the mode-switch defect.
