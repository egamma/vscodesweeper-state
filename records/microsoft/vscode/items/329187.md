# Issue #329187 — Allow Windows native title bar colors to follow VS Code theme colors

[https://github.com/microsoft/vscode/issues/329187](https://github.com/microsoft/vscode/issues/329187)

## Summary

Current main already syncs titleBar.* theme colors to the native Windows title bar overlay by default (via Windows Controls Overlay), so the core capability requested here already exists — proposing an as-designed close rather than a new feature.

## Change summary

Requests that VS Code's titleBar.* theme colors also drive the native Windows title bar overlay (color/symbolColor), not just the HTML/CSS workbench titlebar.

## Best solution

No new capability needed: on Windows with the default titlebar style (custom + Window Controls Overlay), NativeTitlebarPart.updateStyles() already forwards titleBar.activeBackground/activeForeground to Electron's setTitleBarOverlay via nativeHostService.updateWindowControls(). If the reporter is on 'window.titleBarStyle': 'native' or 'window.controlsStyle': 'custom'/'hidden', WCO is intentionally disabled and the native chrome is fully OS-controlled instead — that's a deliberate tradeoff, not a gap; recommend the reporter confirm their titleBarStyle/controlsStyle settings and VS Code version.

## Evidence

- **theme-to-overlay sync:** src/vs/workbench/electron-browser/parts/titlebar/titlebarPart.ts lines 252-271 (updateStyles): when useWindowControlsOverlay() is true, it calls nativeHostService.updateWindowControls({ backgroundColor: this.element.style.backgroundColor, foregroundColor: this.element.style.color }) whenever the DOM titlebar colors (driven by TITLE_BAR_ACTIVE_BACKGROUND/TITLE_BAR_ACTIVE_FOREGROUND theme tokens) change.
- **native overlay update:** src/vs/platform/windows/electron-main/windowImpl.ts lines 412-446 (updateWindowControls): forwards those exact colors to Electron's win.setTitleBarOverlay({ color, symbolColor, height }) — the same API the reporter manually patched main.js to call with hardcoded colors as proof of concept.
- **default WCO on Windows:** src/vs/platform/window/common/window.ts lines 307-349: titlebar style defaults to CUSTOM on all OS, and useWindowControlsOverlay() returns true by default unless window.controlsStyle is explicitly set to custom/hidden — so this sync path is active out of the box on Windows.
