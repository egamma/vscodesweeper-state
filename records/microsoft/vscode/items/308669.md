# Issue #308669 — <memoryInstructions> cannot be overridden by copilot-instructions.md — causes knowledge drift in structured repos

[https://github.com/microsoft/vscode/issues/308669](https://github.com/microsoft/vscode/issues/308669)

## Summary

Keep open as a request for repository-controlled memory persistence. Current source still encourages automatic memory writes; existing prompt-placement, tool-availability, and memory-management controls do not establish the requested repository policy.

## Change summary

Allow repositories to suppress internal memory writes and keep canonical knowledge in repository documentation.

## Best solution

Provide a supported repository-scoped memory policy that respects projects opting out of automatic persistence without disabling unrelated agent instructions. Decide its enforcement and read/write semantics explicitly rather than making repository instructions override all system instructions.
