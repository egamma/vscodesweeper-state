# Issue #308669 — <memoryInstructions> cannot be overridden by copilot-instructions.md — causes knowledge drift in structured repos

[https://github.com/microsoft/vscode/issues/308669](https://github.com/microsoft/vscode/issues/308669)

## Summary

Keep open as a request for repository-controlled memory policy. Current source supports omitting memory instructions when the tool is unavailable, but does not establish a repository-specific policy for suppressing automatic writes while retaining memory access.

## Change summary

Allow repositories to suppress or constrain automatic internal-memory writes so canonical repository documentation remains authoritative.

## Best solution

Define a memory-specific repository policy that governs automatic persistence without weakening unrelated system instructions. Preserve the existing all-off behavior, and settle whether repositories can retain memory reads while prohibiting automatic writes.
