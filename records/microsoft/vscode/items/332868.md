# Issue #332868 — Prompt user to open folder in "Current Window" or "New Window" (like IntelliJ)

[https://github.com/microsoft/vscode/issues/332868](https://github.com/microsoft/vscode/issues/332868)

## Summary

Keep this accepted feature request open: the existing folder-window setting cannot ask on each opening, and the related implementation PR was closed without merging. The request has exceeded the community upvote threshold and has maintainer interest.

## Change summary

Offer an optional Current Window, New Window, or Cancel choice when opening a folder.

Provide an opt-in folder-opening prompt while preserving existing defaults and explicit window-target overrides. Use the closed PR as design context, with native and simplified folder-opening flows covered consistently.
