# Issue #336223 — Feature Request: Provide Cursor-like Code Edit Review UI and Extension API

[https://github.com/microsoft/vscode/issues/336223](https://github.com/microsoft/vscode/issues/336223)

## Summary

Reasonable, on-theme AI-assisted-development request; VS Code already ships a native chat-editing review UI (accept/reject hunks, next/previous navigation, undo/redo integration) but it isn't exposed as a general-purpose public API for arbitrary extensions to submit reviewable edits, so a real gap remains. Too fresh (same-day, 0 upvotes) to judge community traction yet.

## Change summary

Add a built-in Cursor-style code-edit review UI (keep/undo per change, next/previous navigation, accept/reject all) plus a public Extension API so any extension can submit programmatic edits as reviewable changes.

## Best solution

If pursued, generalize the existing chat-editing review machinery (src/vs/workbench/contrib/chat/browser/chatEditing/*) behind a proper public API rather than building a parallel UI, and settle the multi-producer attribution question raised in the comments (per-edit ownership rather than anonymous hunks) before finalizing any API shape.
