# Issue #171074 — Feature request: prettify symbols mode

[https://github.com/microsoft/vscode/issues/171074](https://github.com/microsoft/vscode/issues/171074)

## Summary

Keep this canonical feature request open: it earned 60 community upvotes and was promoted to the Backlog, while current editor capabilities still do not provide reliable, context-sensitive symbol substitution.

## Change summary

Add language-aware visual replacement of source sequences with configurable symbols while preserving the underlying document text.

## Best solution

Implement range substitution in the editor view model, or expose a supported rendering API that extensions can use without CSS injection. It should preserve model text while handling cursor movement, accessibility, hover-to-reveal, previews, and refreshes correctly.
