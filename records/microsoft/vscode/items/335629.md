# Issue #335629 — Hover is confusing

[https://github.com/microsoft/vscode/issues/335629](https://github.com/microsoft/vscode/issues/335629)

## Summary

The confusing hover remains on current main: the combined trigger reuses a comma-separated accessibility label, while mode rows still receive the generic keybinding tooltip instead of explanatory hover content. This team-authored UX-polish issue should remain open for a bounded consistency fix.

## Change summary

Make the combined mode-and-permissions trigger and option hovers clearly distinguish their purpose, current selections, and option descriptions.

## Best solution

Give the combined trigger hover a clear information hierarchy for the control and selected values, and make mode-option hovers match permission-option hovers by explaining each choice without the generic “Enter to Apply” tooltip.
