# Issue #150660 — Loading 256kb file takes 15 seconds on a powerful machine

[https://github.com/microsoft/vscode/issues/150660](https://github.com/microsoft/vscode/issues/150660)

## Summary

Keep open as an upstream Chromium/LayoutNG performance issue: the discussion contains a confirmed extension-free reproduction and identifies DOM character-position queries on very long lines as the bottleneck. The On Deck milestone is a holding bin and does not itself block closure, but there is no verified fix or open canonical issue supporting one.

## Change summary

Opening and scrolling a 256 KB JSON file containing very long lines can stall the editor for roughly 5–15 seconds.

## Best solution

Track the Chromium/LayoutNG regression while evaluating a bounded editor-rendering mitigation for very long lines, such as safely selecting the fast line-rendering path or reducing decoration-position work without sacrificing cursor and decoration accuracy.
