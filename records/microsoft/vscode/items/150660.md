# Issue #150660 — Loading 256kb file takes 15 seconds on a powerful machine

[https://github.com/microsoft/vscode/issues/150660](https://github.com/microsoft/vscode/issues/150660)

## Summary

Hard keep-open: the issue carries the `important` label and was filed by a team contributor. The underlying performance problem — long lines triggering slow DOM character-positioning queries due to Chromium's LayoutNG — remains unresolved on main. No fixing commit was found.

## Change summary

Opening a 256KB JSON file with long lines causes a multi-second freeze due to decoration rendering and DOM-based character positioning.

## Best solution

Expand the use of `FastRenderedViewLine` (multiplication-based positioning) for long lines to avoid expensive DOM `getBoundingClientRect` queries triggered by LayoutNG. The fix would likely live in `src/vs/editor/browser/viewParts/viewLines/viewLine.ts` where the fast/slow rendering path is chosen. Alternatively, disable or batch decoration positioning for lines above a length threshold.
