# Issue #150660 — Loading 256kb file takes 15 seconds on a powerful machine

[https://github.com/microsoft/vscode/issues/150660](https://github.com/microsoft/vscode/issues/150660)

## Summary

Protected by the `important` label. The root cause — LayoutNG making Chromium slower for character positioning queries on long lines, amplified by decoration rendering — remains unresolved on main. Related issue #106699 was closed as upstream but this issue's decoration-specific angle is distinct. No commit references #150660.

## Change summary

Loading a 256KB JSON file with long lines takes 15 seconds due to slow decoration rendering triggered by Chromium LayoutNG character positioning queries.

## Best solution

Investigate whether `FastRenderedViewLine` (simple multiplication for char offsets) can be used for long lines to avoid expensive DOM-based character positioning queries, counteracting rounding errors. The fix likely lives in `src/vs/editor/browser/viewParts/viewLines/viewLine.ts` where the `RenderedViewLine` vs `FastRenderedViewLine` decision is made. Alternatively, disable or batch decoration queries for lines exceeding a length threshold.
