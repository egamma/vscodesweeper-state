# Issue #339759 — managed sandbox settings: what does 'allowDevToolAccess' mean?

[https://github.com/microsoft/vscode/issues/339759](https://github.com/microsoft/vscode/issues/339759)

## Summary

A VS Code contributor raised a genuine clarity question while verifying the in-progress managed sandbox settings test plan (#339645) — the managed-settings JSON schema for `allowDevToolAccess` only carries a bare title ('Allow Dev Tool Access') with no description, unlike the equivalent user-facing setting. This needs a maintainer/team answer or a doc addition, not a close.

## Change summary

Reporter can't tell from the managed sandbox policy schema what 'allowDevToolAccess' actually grants or which tools count as 'dev tools'.

## Best solution

Add a markdownDescription to the AllowDevToolAccess entry in sandboxConfigSchema.ts (mirroring the existing chat.agent.sandbox.fileSystem.allowDevToolAccess description in terminalChatAgentToolsConfiguration.ts, which explains it grants read access to PATH/toolchain tool directories and dev-tool config/caches, plus read-write to shared build caches) so admins reading the managed-settings reference get the same clarity end users do.
