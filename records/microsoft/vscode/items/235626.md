# Issue #235626 — VSCode does not open file paths while in a workspace

[https://github.com/microsoft/vscode/issues/235626](https://github.com/microsoft/vscode/issues/235626)

## Summary

The older, open issue https://github.com/microsoft/vscode/issues/208840 tracks the same observable failure: Go to File cannot find a file when the pasted path includes its workspace root directory. Consolidate there while preserving this report's custom workspace-folder-name example.

## Change summary

Go to File should find files from root-prefixed paths such as code/main.py, including when the workspace displays that directory as Source.

## Best solution

Resolve root-prefixed file lookup under https://github.com/microsoft/vscode/issues/208840, retaining this report's requirement that physical directory names work even when workspace display names differ. Preserve existing workspace-relative and absolute-path lookup.
