# Issue #340538 — Selecting Autopilot in VS Code Chat does not unlock the Party Mode pet achievement

[https://github.com/microsoft/vscode/issues/340538](https://github.com/microsoft/vscode/issues/340538)

## Summary

Thanks for the report. Only the Agent Host mode picker and the mobile phone input presenter unlock the Party Mode achievement. The Chat permission picker in the workbench never does. Whether it should is a product call, because the achievement text only mentions an Interactive to Autopilot switch in an agent session.

## Change summary

Unlock the Party Mode pet achievement when Autopilot is selected from the Chat permission picker.

## Best solution

A maintainer decides whether the workbench permission picker should also unlock AutopilotEnabled. If it should, add the call there with a test and adjust the description wording if needed. Otherwise close as as-designed.
