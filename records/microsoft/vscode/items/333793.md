# Issue #333793 — [Feature Request] Auto Closing Brackets with True Context-Aware Logic (Skip Whitespace/Newlines When Detecting Existing Closing Brackets)

[https://github.com/microsoft/vscode/issues/333793](https://github.com/microsoft/vscode/issues/333793)

## Summary

Keep open as a feature request, but narrow the remaining ask: current main already detects unmatched closing brackets across newlines outside the 'always' mode. Changing 'always' or reusing a closing bracket that already belongs to an enclosing pair would change intentional, tested behavior.

## Change summary

Make bracket auto-closing recognize existing closing brackets across whitespace and newlines, including when editor.autoClosingBrackets is set to 'always'.

## Best solution

Preserve existing balance-aware behavior and clarify whether the requested enhancement is an additional strategy or a change to 'always'. Distinguish globally unmatched closers from the already-matched outer brace in the example before deciding whether additional editor behavior is warranted.
