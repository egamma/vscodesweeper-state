[https://github.com/microsoft/vscode/issues/214857](https://github.com/microsoft/vscode/issues/214857)

## Summary

Keep this open while the existing human-authored fix is reviewed. Current main still applies the configured border only to the active wrapped view line, and the linked PR directly addresses the requested model-line framing but has unresolved design feedback and requested changes.

## Change summary

Draw the current-line highlight border around the complete model line when it spans multiple wrapped view lines.
