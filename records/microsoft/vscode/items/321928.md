# Issue #321928 — Newly added report issue feature doesn't add the attach screenshot when they redirect to the github

[https://github.com/microsoft/vscode/issues/321928](https://github.com/microsoft/vscode/issues/321928)

## Summary

Valid bug: the new issue reporter wizard collects screenshot attachments from the user but silently drops them when submitting via the GitHub URL-redirect flow (no GitHub access token present), so the filed issue never contains the screenshots the user attached.

## Change summary

Screenshots attached in the new issue reporter wizard are not included in the GitHub issue body when the reporter redirects to github.com to file the issue.

## Best solution

When `githubAccessToken` is absent and attachments exist, `submitIssue` in `src/vs/workbench/contrib/issue/browser/issueFormService.ts` should either (a) prompt the user to sign in with GitHub so uploads can proceed, or (b) embed the screenshot data URLs inline in the body markdown, or (c) clearly warn the user that attachments require GitHub sign-in and won't be included. The current silent drop is the core defect.

## Evidence

- **no user feedback:** There is no warning, error, or fallback when attachments exist but the upload path is skipped due to a missing GitHub token — the user sees their screenshots in the wizard UI but they silently vanish from the submitted issue.
- **new wizard feature:** The issue reporter wizard was recently added (commit 4e538f26ea3) and this is a gap in its submission flow.
