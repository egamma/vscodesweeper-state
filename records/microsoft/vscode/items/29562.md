# Issue #29562 — Selection of problem matcher is not very intuitive when running a task

[https://github.com/microsoft/vscode/issues/29562](https://github.com/microsoft/vscode/issues/29562)

## Summary

Keep open: current VS Code provides a Problems count badge and automatic panel-reveal options, but the matcher picker still does not explain the different output formats, and zero matches do not produce matcher-specific guidance. The remaining UX request is distinct from the related issues inspected.

## Change summary

Make problem matcher selection easier to understand and provide useful feedback when the selected matcher finds no problems.

## Best solution

Improve the task matcher picker’s explanation of supported output formats and agree on restrained feedback for unsuccessful matching. Preserve clean-build behavior: zero matches alone must not be presented as proof that the matcher is wrong.
