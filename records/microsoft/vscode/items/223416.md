[https://github.com/microsoft/vscode/issues/223416](https://github.com/microsoft/vscode/issues/223416)

## Change summary

Inserting a newline with Ctrl+Enter in a horizontally scrolled Find or Replace field leaves the caret outside the visible input area.

## Best solution

Make keyboard newline insertion keep the caret visible in both editor Find and Replace inputs, preserving native paste behavior and existing keybinding dispatch. First reproduce the horizontal scrolling failure on current macOS VS Code to establish the browser behavior involved.
