# Issue #337501 — Revamp the Agent Bake Off comparison UI

[https://github.com/microsoft/vscode/issues/337501](https://github.com/microsoft/vscode/issues/337501)

## Summary

Keep open for an approved end-to-end UX proposal. Current main has simplified Judge results and replaced the custom synthesis matrix with additional instructions, but those changes do not establish completion of the broader setup, progress, responsive-layout, and accessibility design request.

## Change summary

Make the Agent Bake Off comparison workflow cohesive, scannable, responsive, and accessible across setup, running attempts, Judge results, and synthesis.

## Best solution

Agree on a cohesive design for the current comparison workflow, explicitly reconciling the requested decision matrix with today's instruction-based synthesis. Specify consistent attempt identity and stage-leading actions across desktop, narrow-window, and phone layouts, then implement against focused behavioral and visual acceptance checks.
