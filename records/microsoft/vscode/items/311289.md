# Issue #311289 — API: Allow access to the notebook editor scroll state

[https://github.com/microsoft/vscode/issues/311289](https://github.com/microsoft/vscode/issues/311289)

## Summary

Well-articulated API proposal for pixel-level notebook scroll state, promoted to Backlog with 26 upvotes. No implementation exists on main; the requested API surface is a genuine gap.

## Change summary

Expose pixel-level scroll position (scrollTop, scrollHeight, viewportHeight) and programmatic setScrollTop on the NotebookEditor extension API.

## Best solution

Implement a proposed API (`vscode.proposed.notebookEditorScroll.d.ts`) exposing scrollTop/scrollHeight/viewportHeight properties, a setScrollTop method, and an onDidChangeNotebookEditorScroll event on the NotebookEditor. The internal data already exists on NotebookCellList/NotebookEditorWidget — the work is wiring it through the extension host RPC.
