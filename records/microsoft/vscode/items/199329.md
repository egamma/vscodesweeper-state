# Issue #199329 — The sash gets away from the mouse when using scroll wheel

[https://github.com/microsoft/vscode/issues/199329](https://github.com/microsoft/vscode/issues/199329)

## Summary

Still reproduces on main: the sash component (`src/vs/base/browser/ui/sash/sash.ts`) has no wheel-event handling during drag, so scrolling while dragging desynchronizes the sash from the cursor. No fix has been committed — the issue remains valid.

## Change summary

While dragging the diff-editor sash, using the mouse scroll wheel causes the sash to drift away from the cursor because the drag doesn't account for scroll-position changes.

## Best solution

During an active sash drag, listen for wheel events on the container and adjust the sash's tracked position by the scroll delta so it stays aligned with the cursor. The fix likely touches `src/vs/base/browser/ui/sash/sash.ts` (the drag lifecycle in `onPointerStart`/move handlers) and possibly the diff-editor sash wrapper at `src/vs/editor/browser/widget/diffEditor/components/diffEditorSash.ts`.
