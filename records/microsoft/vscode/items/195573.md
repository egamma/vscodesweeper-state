# Issue #195573 — Allow commands to have optional descriptions to be used for similar commands feature

[https://github.com/microsoft/vscode/issues/195573](https://github.com/microsoft/vscode/issues/195573)

## Summary

Keep open: core commands already support searchable descriptions, but extension-contributed commands still cannot supply them. This remains the canonical extension contribution request; the related core-description issue does not replace it.

## Change summary

Allow extensions to contribute optional command descriptions so searches such as “venv” or “conda” can discover “Python: Create Environment.”

## Best solution

Provide optional extension-contributed search metadata that reaches Command Palette similarity matching without requiring command-title changes. Settle the public description-versus-keywords contract in coordination with the existing core metadata discussion.
