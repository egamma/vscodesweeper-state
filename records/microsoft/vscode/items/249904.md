# Issue #249904 — Send VS Code notifications via Codex CLI

[https://github.com/microsoft/vscode/issues/249904](https://github.com/microsoft/vscode/issues/249904)

## Summary

The central request now has a built-in solution: terminal commands can emit OSC 99 sequences to display VS Code notifications, enabled by default. The implementation is merged and present on current main, so this can be closed as completed.

## Change summary

Allow a command running in a Dev Container, such as a Codex completion hook, to notify the user inside VS Code.

## Best solution

Use the built-in OSC 99 notification support from the command or completion hook, with terminal.integrated.enableNotifications enabled. This satisfies notification delivery from the terminal without requiring a dedicated code --notify flag or the third-party extension.
