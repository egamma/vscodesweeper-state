# Issue #148316 — Are there plans to expose the Resolvers interface?

[https://github.com/microsoft/vscode/issues/148316](https://github.com/microsoft/vscode/issues/148316)

## Summary

Keep open: remote authority resolver registration remains a proposed API, so current main does not satisfy the request for official, stable exposure. The accepted Backlog request has 31 upvotes and recent reports of blocked extension publication; it needs an API-owner decision on finalization.

## Change summary

Expose the remote authority resolvers API as a stable extension API so remote-development extensions can distribute without relying on proposed APIs.

## Best solution

Have the remote/API owners define and finalize a supported remote authority resolver contract, preserving existing remote connection behavior. Decide which parts of the current proposal belong in the stable contract rather than treating its existing implementation as completion.
