# Issue #148316 — Are there plans to expose the Resolvers interface?

[https://github.com/microsoft/vscode/issues/148316](https://github.com/microsoft/vscode/issues/148316)

## Summary

Keep open: this accepted Backlog request has 31 community upvotes, and current main still restricts the resolver API to proposed-API consumers. Recent extension authors confirm that this prevents Marketplace publication.

## Change summary

Graduate the remote authority resolver API so third-party remote-development extensions can use and publish against it.

## Best solution

Finalize the resolver contract in `src/vscode-dts/vscode.proposed.resolvers.d.ts`, move the supported surface into the stable API, and remove the `resolvers` proposed-API gate in `src/vs/workbench/api/common/extHost.api.impl.ts` while preserving the existing extension-host implementation.
