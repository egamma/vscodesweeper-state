# Issue #149667 — [scss] don't autocomplete in comments

[https://github.com/microsoft/vscode/issues/149667](https://github.com/microsoft/vscode/issues/149667)

## Summary

The built-in SCSS language support was confirmed by a maintainer to offer completions inside comments, and extension bisect found no responsible extension. The issue should remain open until current behavior is rechecked and the SCSS completion path suppresses inappropriate suggestions in comments.

## Change summary

SCSS completion suggestions appear while typing comment prose, causing Enter to accept an unwanted suggestion instead of inserting a newline.

## Best solution

Ensure the built-in CSS language service does not return ordinary SCSS completions when the cursor is inside a comment, while preserving explicitly requested word-based suggestions according to editor settings.
