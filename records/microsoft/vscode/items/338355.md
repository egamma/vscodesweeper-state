# Issue #338355 — Side-by-side chats should have a close button

[https://github.com/microsoft/vscode/issues/338355](https://github.com/microsoft/vscode/issues/338355)

## Summary

Confirmed on main: the 'Close' action for a side-by-side chat group header is only registered in the SessionBarToolbar's overflow group (`secondary/4_pin`), not in a visible `navigation` slot, matching the reporter's screencast. A maintainer (sandy081) is actively soliciting design input from a teammate in the thread, so this stays open pending that decision rather than being auto-closed or auto-implemented.

## Change summary

Side-by-side (non-tab) chat group headers only expose 'Close' via the overflow/kebab menu, unlike the tab strip's inline close affordance; reporter wants a direct close button.

## Best solution

Once sandy081/romalpani settle on placement, move the CloseChatAction menu contribution for the SessionHeaderShowsChat case into the toolbar's `navigation` group (or add a dedicated hover-visible close button) in src/vs/sessions/contrib/sessions/browser/sessionsActions.ts, mirroring how SessionChatTab already surfaces it inline.
