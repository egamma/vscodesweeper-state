# Issue #280628 — Bogous legacy name for usages-tool

[https://github.com/microsoft/vscode/issues/280628](https://github.com/microsoft/vscode/issues/280628)

## Summary

The schema removal (PR #281462) addressed the surface visibility concern, but the underlying API design issue — that the legacy-name mapping is inverted (defined on the tool instead of the toolset) — remains open and proposal-gated. The property still exists in code awaiting a proper redesign before finalization.

## Change summary

The `legacyToolReferenceFullNames` property on tools has an inverted mapping design that should be revisited before the API is finalized for third-party extensions.

## Best solution

Revisit the `legacyToolReferenceFullNames` mapping direction before finalizing the API: move the association from the tool level to the toolset level (or define it at the tool level with an explicit toolset reference), as discussed in comments 4–5.
