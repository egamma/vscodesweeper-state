# Issue #196705 — Support Monaco editor in webviews

[https://github.com/microsoft/vscode/issues/196705](https://github.com/microsoft/vscode/issues/196705)

## Summary

Valid, unimplemented feature request from a team member, assigned to mjbvz in Backlog with 13 upvotes. No work toward embedding a VS Code editor in webviews exists on main — the request remains a real gap.

## Change summary

Provide a way to embed a full VS Code (Monaco) editor inside webviews so extension authors get completions, hovers, keybindings, and link detection without reimplementing them.

## Best solution

Design and ship a webview-embeddable editor component (e.g. a web-component or dedicated API) that proxies back to VS Code's real editor services, giving webview-hosted inputs the same completions, hovers, and shortcuts as native editors. The webview contrib and the extension host API layers would both need changes. This is a significant API/architecture effort that the assigned owner (mjbvz) should scope.
