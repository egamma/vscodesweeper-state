[https://github.com/microsoft/vscode/issues/303677](https://github.com/microsoft/vscode/issues/303677)

## Summary

The cloud handoff still has a path that selects the repository's default branch instead of the checked-out branch. This is the same observable failure already tracked by the verified, older open issue https://github.com/microsoft/vscode/issues/296899, so consolidate there.

## Change summary

Delegating a plan to the cloud agent ignores the checked-out non-default branch and loses its implementation context.

## Best solution

Resolve branch preservation for plan-to-cloud delegation under https://github.com/microsoft/vscode/issues/296899, retaining this report's confirmation that the problem also occurs when the default branch is dev and the intended branch is main.
