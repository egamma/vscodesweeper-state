# Issue #303677 — "Delegate to cloud agent" uses wrong branch

[https://github.com/microsoft/vscode/issues/303677](https://github.com/microsoft/vscode/issues/303677)

## Summary

Still reproduces on main: when delegating to the cloud agent from a non-default branch that isn't yet pushed to the remote, the fallback logic in `copilotCloudSessionsProvider.ts` silently replaces the user's current branch with the repo's default branch, causing the cloud agent to work on the wrong code.

## Change summary

Delegating to the Copilot cloud agent from a non-default branch causes the cloud agent to operate on the repo's default branch instead of the user's current branch.

## Best solution

Fix the branch resolution in `copilotCloudSessionsProvider.ts` so that when the user's current branch is missing on the remote and the user chooses to push it, the pushed branch name is preserved as `base_ref` rather than falling back to the default branch. The fallback at line 2152 (`checkBaseBranchPresentOnRemote` result handling) and the condition at line 1962 in `delegate()` both need review to ensure the user's intended branch is carried through to `invokeRemoteAgent`.
