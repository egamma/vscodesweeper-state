# Issue #341603 — Add Colourful Product Icons Like Visual Studio

[https://github.com/microsoft/vscode/issues/341603](https://github.com/microsoft/vscode/issues/341603)

## Summary

Thanks for the suggestion. VS Code already supports product icon themes (`workbench.productIconTheme`), but they are font-glyph based and so effectively monochrome, so the central ask of coloured icons is not covered today. No maintainer has weighed in and there is no demand yet, so this stays open for community feedback.

## Change summary

Provide optional colourful product icons (Activity Bar, panels, etc.), similar to Visual Studio, instead of monochrome ones.

## Best solution

Keep open as a feature request for community upvotes. A maintainer should decide whether multi-colour glyphs are worth the cost: product icon themes would need to support non-font (e.g. SVG) icons, and this adds UI inconsistency. Until then, the existing product icon theme extension point is the nearest route.
