# Issue #332854 — Adopt SDK-managed AHP subscriptions and retire duplicate reconnect lifecycle

[https://github.com/microsoft/vscode/issues/332854](https://github.com/microsoft/vscode/issues/332854)

## Summary

This is valid architectural debt that remains present on current main, but the coordinated migration is blocked on unfinished SDK work. Keep it open until the managed-subscription and transport-generation lifecycle are available from the official AHP SDK.

## Change summary

Move protocol-generic subscription ownership and reconnect restoration from VS Code into SDK-managed AHP leases while retaining VS Code-specific state projection and optimistic reconciliation.

## Best solution

First review and land https://github.com/microsoft/agent-host-protocol/pull/423 plus an official SDK host-generation restoration slice. Then migrate VS Code consumers to those managed leases, preserve the existing application reducers and pending-action reconciliation, and remove only the superseded generic lifecycle code.
