# Issue #324050 — When using the Report Bug (issue reporter) it ignores the Github selected account

[https://github.com/microsoft/vscode/issues/324050](https://github.com/microsoft/vscode/issues/324050)

## Summary

The issue reporter bypasses the authentication account preference system and picks the first GitHub session with a `repo` scope, ignoring any user-configured preferred account. This is a real defect, confirmed by source inspection — the code uses `potentialSessions[0]` or `.find()` with no preference lookup.

## Change summary

The issue reporter uses the first available GitHub session rather than the user's preferred GitHub account when filing bugs.

## Best solution

The issue reporter's session selection (in `issueService.ts` for both browser and electron-browser, and in `baseIssueReporterService.ts`) should either let the user pick which GitHub account to use for filing, or integrate with the authentication preference system. Since the issue reporter is a core component (not an extension), the per-extension `getAccountPreference` API doesn't directly apply — a lightweight account picker in the reporter UI or a new preference key for core components would be the cleanest fix.
