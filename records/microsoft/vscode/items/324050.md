# Issue #324050 — When using the Report Bug (issue reporter) it ignores the Github selected account

[https://github.com/microsoft/vscode/issues/324050](https://github.com/microsoft/vscode/issues/324050)

## Summary

Keep open: the legacy reporter still selects the first eligible GitHub session without consulting an account preference. Reporting now also has a wizard/browser-preview path, so the supplied multi-account scenario is sufficient to retest, but its current end-to-end behavior remains unverified.

## Change summary

The issue reporter submits bugs using the first GitHub account rather than the reporter's selected account.

## Best solution

Make the submitting identity explicit and respect the applicable account preference throughout issue reporting. Establish which preference the reporter selected before extending its semantics to unrelated Git operations or workspace-wide defaults.
