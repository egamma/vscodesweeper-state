# Issue #214776 — [2eg] potential listener LEAK detected, having 203 listeners already. MOST frequent listener (29):

[https://github.com/microsoft/vscode/issues/214776](https://github.com/microsoft/vscode/issues/214776)

## Summary

Team-authored debt issue; the listener leak in the merge editor's FixedZoneWidget is still present on current main. Each autorun cycle creates new ActionsContentWidget instances that register onDidLayoutChange listeners, and while individual widgets are disposed via DisposableStore, the accumulation pattern can exceed the 200-listener threshold before cleanup occurs.

## Change summary

The merge editor's conflict-action view zones accumulate onDidLayoutChange listeners on the editor, triggering a 203-listener leak warning.

## Best solution

Guard the listener accumulation in FixedZoneWidget — either batch the view-zone creation to limit concurrent widget instances, or restructure so a single shared listener dispatches layout changes to all active widgets instead of each widget subscribing independently. The fix is localized to `src/vs/workbench/contrib/mergeEditor/browser/view/fixedZoneWidget.ts` and the view-zone lifecycle in `viewZones.ts`/`mergeEditor.ts`.
