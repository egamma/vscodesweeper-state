# Issue #239025 — Delay to scroll to bottom when auto-scroll is enabled

[https://github.com/microsoft/vscode/issues/239025](https://github.com/microsoft/vscode/issues/239025)

## Summary

The delayed jump remains explainable on current main: changing category filters updates hidden editor areas immediately, while auto-scroll only reveals the last line after a subsequent model-content event. This accepted, team-authored Backlog bug should remain open.

## Change summary

When category filtering reveals Output content with auto-scroll enabled, the view initially stays at the top and scrolls to the bottom only after a delay.

## Best solution

Make Output filter changes preserve the auto-scroll contract by settling at the last visible line immediately when scroll lock is off, while leaving locked and smart-scroll behavior unchanged.
