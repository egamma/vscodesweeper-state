# Issue #290962 — Terminal tool command is very horizontally cramped

[https://github.com/microsoft/vscode/issues/290962](https://github.com/microsoft/vscode/issues/290962)

## Summary

Current main still reserves substantial horizontal space for the terminal status decoration, header gap, padding, and an always-present action bar, so the reported narrow-sidebar UX gap remains. This team-authored, already-routed design issue should stay open for a responsive-layout decision.

## Change summary

Give terminal commands more readable horizontal space when rendered in a narrow sidebar chat.

## Best solution

Use a responsive terminal header where the command remains the leading content at narrow widths and secondary actions do not permanently consume its available width. Evaluate changes to the shared thinking gutter separately so other tool rows retain a consistent hierarchy.
