# Issue #296940 — AI Customizations Editor: List gets cropped

[https://github.com/microsoft/vscode/issues/296940](https://github.com/microsoft/vscode/issues/296940)

## Summary

Visual regression in the still-young AI Customizations Editor (collapsing the Extensions section crops the list) with a reporter-supplied screenshot as evidence, but I couldn't pin a specific defect in the layout/height code reading it statically, and a prior review's proposed fix commit was refuted on re-check — so this stays open pending a confirmed root cause.

## Change summary

In the AI Customizations Editor, collapsing the 'Extensions' group causes the remaining list content to render cropped instead of filling the available space.

## Best solution

Reproduce interactively and trace how `aiCustomizationListWidget.ts`'s `layout()`/`getCustomizationTreeContentHeight()` (src/vs/workbench/contrib/chat/browser/aiCustomization/customizationTree.ts) and the WorkbenchObjectTree's internal scroll-height recompute interact when a top-level group's collapse state changes — the list viewport height is fixed at widget-layout time and isn't recalculated on tree collapse/expand events, which is a plausible source of a stale/cropped render.
