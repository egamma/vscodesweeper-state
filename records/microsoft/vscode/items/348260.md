# Issue #348260 — Chat: persistentProgressVerbosity "Compact" is less compact than "Conversation"

[https://github.com/microsoft/vscode/issues/348260](https://github.com/microsoft/vscode/issues/348260)

## Summary

Keep open as settings-language polish: current main still calls the intermediate grouping mode Compact without clearly identifying Conversation as the most collapsed option. The rendering matches the documented modes; the remaining issue is discoverability, not broken collapsing.

## Change summary

Clarify the relative compactness of the Compact and Conversation chat progress modes.

## Best solution

Make the relative disclosure levels explicit in the Settings descriptions, preserving existing stored values and rendering behavior. Keep any display-name changes consistent with the Chat View Mode actions.

These source assertions support treating this as terminology polish; tests were not executed.
