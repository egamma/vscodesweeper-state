# Issue #263558 — Support developing VS Code extensions in TypeScript

[https://github.com/microsoft/vscode/issues/263558](https://github.com/microsoft/vscode/issues/263558)

## Summary

Native TypeScript workspace extensions already satisfy the central request, as both the maintainer and reporter confirmed. The subsequently reported integration-test blocker also has a landed fix and downstream confirmation, so this can be closed as completed.

## Change summary

Allow local workspace extensions to execute TypeScript directly without a JavaScript compilation step.

## Best solution

Use the existing Node extension-host loading path with package.json declaring "type": "module" and "main": "./index.ts". Close as completed with the integration-test loader fix in a5bfd2dc34012635c27d457c4227540bce503fba; automatic extension reloading is a separate request.
