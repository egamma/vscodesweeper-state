# Issue #313116 — Codespace integration for session creation: auto-create or connect & host agent server

[https://github.com/microsoft/vscode/issues/313116](https://github.com/microsoft/vscode/issues/313116)

## Summary

Keep open: existing environment connections cover already-hosted environments, but not creating a Codespace or starting an agent server in an existing one during session creation. This team-authored Backlog request still describes a meaningful provisioning gap; no verified canonical or issue-referencing fix was found.

## Change summary

Let session creation provision a new Codespace or select an existing Codespace, start its agent server, and connect automatically.

## Best solution

Provide a Codespace setup flow integrated with session creation and the existing remote agent-host connection surface. Design the provisioning and host-bootstrap contract first, preserving the distinction between discovering an already-running host and creating or starting remote compute.
