# Issue #344544 — Markdown editor: pan and zoom for Mermaid diagrams

[https://github.com/microsoft/vscode/issues/344544](https://github.com/microsoft/vscode/issues/344544)

## Summary

Keep open: the experimental Markdown editor renders Mermaid diagrams but does not connect them to the preview's pan/zoom implementation or expose the requested host-toolbar actions. This team-authored request identifies a real capability gap that needs coordination with the embedded-editor protocol and host.

## Change summary

Add keyboard-accessible host-toolbar zoom, reset, and pan-toggle actions for Mermaid blocks in the experimental Markdown editor, inline and in full view.

## Best solution

Provide Mermaid navigation through the Markdown editor's existing block toolbar, reusing the preview's navigation behavior rather than adding a second toolbar inside the diagram. Establish the guest-to-host action contract and define or document how the existing Mermaid navigation settings apply.

## Evidence

- **Current editor capability gap:** extensions/mermaid-markdown-features/preview-src/markdownEditor/index.ts connects WebEditorClient, renders the Mermaid SVG, reports natural height, and handles content/theme changes. It neither instantiates DiagramManager nor registers pan/zoom controls or contributed toolbar actions.
- **Existing preview implementation:** extensions/mermaid-markdown-features/preview-src/markdown/index.ts creates DiagramManager and calls setup for successfully rendered diagrams. preview-src/shared/diagramManager.ts implements pan/zoom, state retention, and diagram-local controls; this functionality is not wired into the Markdown editor guest.
- **Existing settings and commands do not cover the ask:** extensions/mermaid-markdown-features/package.json registers markdown-mermaid.mouseNavigation.enabled, markdown-mermaid.controls.show, and _mermaid-markdown.resetPanZoom. Their existence does not supply editor-host toolbar integration: the editor guest loads the configuration but does not install DiagramManager, and the reset command's context-menu contribution targets other Mermaid surfaces.
- **Host and protocol boundary:** extensions/mermaid-markdown-features/src/markdownEditor/mermaidCodeBlockEditorProvider.ts supplies resizable/fullWidth/fullView presentation preferences. extensions/markdown-language-features/src/preview/lazyCodeBlockEditorFactory.ts delegates embedded-editor creation to @vscode/markdown-editor/web-editors, so the complete host-toolbar implementation is not contained in the Mermaid guest. The issue identifies https://github.com/microsoft/vscode-packages/pull/396 as a protocol-design reference, not as a verified implementation of this request.
