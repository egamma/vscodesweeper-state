# Issue #139331 — Emmet: update tag

[https://github.com/microsoft/vscode/issues/139331](https://github.com/microsoft/vscode/issues/139331)

## Summary

The 'Update Tag' command replaces the tag name only — it does not expand Emmet abbreviations. This was explicitly confirmed as designed in #89668, which was closed *as-designed.

## Change summary

User expects Emmet abbreviations (like `#test`) to expand when using the Update Tag command, but the command only does literal tag-name replacement.

## Best solution

Keep the current behavior: Update Tag replaces the tag name with the literal input. Abbreviation expansion in that input box was already declined in #89668. Users wanting abbreviation expansion should use Emmet's wrap/expand commands instead.
