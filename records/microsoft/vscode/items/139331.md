## Summary

Emmet's Update Tag command still replaces tag names literally; interpreting #test as an attribute update remains unsupported. Keep this accepted Backlog feature request open: the earlier as-designed decision is relevant precedent, but does not override this issue's subsequent triage.

## Change summary

Allow Emmet: Update Tag to interpret abbreviations such as #test and update attributes while preserving the existing tag name.
