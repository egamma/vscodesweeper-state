# Issue #307149 — Skill triggers external file allow dialog

[https://github.com/microsoft/vscode/issues/307149](https://github.com/microsoft/vscode/issues/307149)

## Summary

Team-authored bug still present on main: when a skill references multiple external files, each triggers a separate allow dialog instead of batching or inheriting approval from the skill's declared paths. No fix commit references this issue.

## Change summary

Invoking a skill that reads multiple external files triggers a confirmation dialog for every file individually, instead of allowing them in a batch from the skill context.

## Best solution

The `ChatExternalPathConfirmationContribution` in `src/vs/workbench/contrib/chat/common/tools/builtinTools/chatExternalPathConfirmation.ts` should recognize when file reads originate from a skill invocation and either auto-allow paths referenced within that skill's definition, or batch the confirmations so the user approves once for the skill's working scope rather than per-file. The `chat-tools` area owns this.
