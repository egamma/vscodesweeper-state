# Issue #329600 — Modern UI - Misaligned extensions cards

[https://github.com/microsoft/vscode/issues/329600](https://github.com/microsoft/vscode/issues/329600)

## Summary

Screenshots show real alignment/scrollbar-overlap defects in the extensions list under the experimental Modern UI Update (workbench.experimental.modernUI); the extensions viewlet CSS has no style-override module of its own in this catalog, so it wasn't adapted alongside the other Modern UI modules — routing to the extensions-view area for a proper look, since verifying the exact rendering glitch requires running the build rather than reading CSS.

## Change summary

Under the experimental Modern UI setting, extension cards in the Extensions view are misaligned and the vertical scrollbar overlaps the cards.

## Best solution

Have the extensions-view owners either add a style-override module for the extensions list/grid (mirroring tabs.css, padding.css, etc. in src/vs/workbench/contrib/styleOverrides/browser/media/) or adjust extensionsViewlet.css so the list layout tolerates the Modern UI's padding/scrollbar changes and doesn't overlap the scrollbar with card content.
