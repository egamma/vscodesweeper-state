# Issue #164484 — Investigate removing cursor hit testing

[https://github.com/microsoft/vscode/issues/164484](https://github.com/microsoft/vscode/issues/164484)

## Summary

Team-authored debt item that remains valid: the hardcoded underline cursor height of 2px is still present on main (line 238 of viewCursor.ts), and cursor hit testing has not been removed. Keeping open per maintainer-authored policy.

## Change summary

Remove cursor hit testing from the editor's cursor rendering layer and fix the hardcoded underline height.

## Best solution

Investigate whether `pointer-events: none` on the cursor layer (or individual cursors) can eliminate the need for precise cursor sizing for click purposes, then clean up the hardcoded `height = 2` in `viewCursor.ts`. The referenced PR #159325 addressed misplaced cursor positioning but did not tackle the underlying hit-testing debt.
