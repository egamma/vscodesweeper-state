# Issue #316345 — Session records that cannot be deleted come from codex and claude code plug-ins.

[https://github.com/microsoft/vscode/issues/316345](https://github.com/microsoft/vscode/issues/316345)

## Summary

Keep open: sessions remaining after deletion in their originating tools is a distinct synchronization concern, not merely a request for a Delete menu item. Current main has separate agent-host and extension-provider deletion paths; the reported external-delete-then-inspect sequence suffices to retest, but neither a current reproduction nor a covering fix was established.

## Change summary

Codex and Claude Code sessions remain in VS Code's session list and cannot be removed even after deletion in their originating tools.

## Best solution

The Sessions list should reconcile with its owning providers so genuinely deleted sessions disappear after refresh without affecting unrelated conversations. First establish which provider supplies the retained entries and whether deletion actually removes them from that provider's inventory.
