# Issue #319291 — Changes are not immediately visible in the changes view

[https://github.com/microsoft/vscode/issues/319291](https://github.com/microsoft/vscode/issues/319291)

## Summary

Keep open for a decision on the Changes view default: current source explicitly prefers Branch Changes, but that does not settle the reporter's expectation of immediately reviewing generated edits. This team-authored item cannot receive an as-designed close, and the related reports do not establish a duplicate covering its full concern.

## Change summary

Opening Changes after an agent refactor should expose the generated edits without requiring a switch from Branch Changes to Uncommitted Changes.

## Best solution

Define the appropriate initial review scope for agent edits on an existing custom branch, then make the Changes view honor that contract while preserving explicit user selections. Separately establish whether this report also involves the empty Branch Changes refresh defect tracked in https://github.com/microsoft/vscode/issues/318883.
