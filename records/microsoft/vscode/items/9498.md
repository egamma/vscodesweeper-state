## Summary

Keep open: this Backlog request has 183 community upvotes, and current VS Code only restores working sets automatically per source-control branch; it does not expose user-managed named editor sets.

## Change summary

Allow users to save, name, and restore sets of open editors and their group layout.

## Best solution

Expose commands and UI for saving, listing, applying, and deleting named editor working sets, building on the existing IEditorGroupsService working-set implementation in src/vs/workbench/browser/parts/editor/editorParts.ts.
