# Issue #334562 — Banner shows up pretty quickly

[https://github.com/microsoft/vscode/issues/334562](https://github.com/microsoft/vscode/issues/334562)

## Summary

Current behavior matches the explicit five-second reconnect-banner threshold, so this is optional timing polish rather than a defect. Because this is a team-authored issue, the owning maintainers should decide whether to adjust the threshold; an as-designed close is not proposed.

## Change summary

Consider delaying the remote Agent Host reconnection banner so restarting a tunnel does not surface a short-lived interruption.

## Best solution

Keep the five-second delay unless transport measurements support a longer threshold; if adjusted, update the connection presentation tests to define precisely which interruptions remain silent.
