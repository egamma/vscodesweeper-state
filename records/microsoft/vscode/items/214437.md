# Issue #214437 — feature request: open file url without --file-uri flag

[https://github.com/microsoft/vscode/issues/214437](https://github.com/microsoft/vscode/issues/214437)

## Summary

Keep open in the Backlog: the request exceeded the community threshold with 37 upvotes, and current main still treats positional CLI arguments as filesystem paths rather than file URIs.

## Change summary

Allow `code file:///path` to open the referenced file without requiring the `--file-uri` flag.

## Best solution

Teach the desktop CLI opening path to recognize positional `file://` arguments and route them through the existing file-URI resolution path while preserving ordinary positional path behavior.
