# Issue #327371 — Cloud Session in Agents Window to Editor Window is broken

[https://github.com/microsoft/vscode/issues/327371](https://github.com/microsoft/vscode/issues/327371)

## Summary

The cloud-session handoff is broken on current source: a virtual GitHub repository URI is passed to the native window API as a workspace folder. Keep this team-authored issue open and route it to the Agents Window and cloud-agent owners.

## Change summary

Opening a completed cloud session from the Agents Window creates a broken editor workspace.

## Best solution

Handle virtual cloud workspaces explicitly in `OpenSessionInVSCodeAction`, opening a valid editor target while preserving `chatSessionToOpen`, with focused coverage for cloud sessions.
