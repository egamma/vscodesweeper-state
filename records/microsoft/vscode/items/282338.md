## Change summary

Reloading a window with background Copilot CLI sessions containing edits repeatedly attempts to read those external sessions from local chat-session storage.

## Best solution

Ensure startup restoration preserves external session identity and never treats a copilotcli URI as a local session filename. Retest the reported reload scenario against the current session-restoration path before deciding whether further code changes are necessary.
