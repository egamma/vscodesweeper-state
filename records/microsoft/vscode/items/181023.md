# Issue #181023 — some snippet show suggestion preview, but some not

[https://github.com/microsoft/vscode/issues/181023](https://github.com/microsoft/vscode/issues/181023)

## Summary

The reported difference follows the current insertion-only preview behavior: `imp` is a prefix of its expansion, whereas expanding `imb` requires removing the typed `b`. Keep this accepted Backlog item open for an owner decision about replacement-aware snippet previews; its existing bug classification and milestone bar a decline close.

## Change summary

Show suggestion previews for snippets whose trigger text is not contained in their expanded body.

## Best solution

Have the suggest/inline-completions owner settle how a preview should represent typed characters that accepting the snippet would remove, without misleading users about their actual buffer contents. The remaining capability is replacement-aware previewing, not snippet registration or extension ownership.

After placeholder expansion, the second body contains no `b`, so preserving all typed characters while only inserting ghost text cannot display that completion.
- **Current preview path:** src/vs/editor/contrib/inlineCompletions/browser/model/suggestWidgetAdapter.ts: SuggestItemInfo.fromSuggestion parses snippet bodies and uses snippet.toString() as the preview text. inlineCompletionsModel.ts passes the selected suggestion edit to computeGhostText; computeGhostText.ts returns undefined whenever a diff change has originalLength > 0. This explains the reported imp/imb distinction directly from current source.
