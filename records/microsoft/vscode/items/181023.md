## Evidence

- **Verified older canonical:** https://github.com/microsoft/vscode/issues/130297 is currently open, was created on 2021-08-06, and tracks the same observable symptom: a selected suggestion has no preview when displaying it would require changing existing typed characters. Its scope explicitly includes previews that do more than insert text.
- **Exact reported snippets:** https://github.com/tjx666/snippets/blob/HEAD/package.json identifies the extension as YuTengjing.ytj-snippets. In https://github.com/tjx666/snippets/blob/HEAD/snippets/javascript.code-snippets, lines 13–21 define `imp` as `import ${2:module} from '${1:package}';$0` and `imb` as `import ${2:module} from 'node:${1:package}';$0`. The parsed `imp` expansion preserves the typed prefix; the parsed `imb` expansion contains no `b`, so previewing it requires replacing that character.
- **Current source boundary:** src/vs/editor/contrib/inlineCompletions/browser/model/suggestWidgetAdapter.ts, SuggestItemInfo.fromSuggestion, parses snippet text into its expanded preview text. inlineCompletionsModel.ts passes the selected suggestion to computeGhostText. In browser/model/computeGhostText.ts, computeGhostText returns undefined whenever a diff change has originalLength > 0, rejecting the replacement required by `imb`. This is a core preview limitation, not evidence of an extension defect.
- **Maintainer-confirmed same symptom:** In https://github.com/microsoft/vscode/issues/144421#issuecomment-1060489039, a maintainer directed an earlier report from the same author about some snippets previewing and others not to https://github.com/microsoft/vscode/issues/130297, explaining that snippets can only preview when they extend the abbreviation. https://github.com/microsoft/vscode/issues/130297#issuecomment-899340588 explicitly describes the insertion-only behavior as intentional.
