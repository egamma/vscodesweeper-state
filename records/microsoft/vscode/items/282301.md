# Issue #282301 — Todo list appears to be cleared when resuming after stopping agent

[https://github.com/microsoft/vscode/issues/282301](https://github.com/microsoft/vscode/issues/282301)

## Summary

Valid tension between two behaviors — clearing todos on stop (fix for #274729) vs. preserving them for resumption. A team member acknowledged this and suggested a 'pause' compromise; the issue should remain open for that design decision.

## Change summary

Stopping an agent clears the todo list, losing progress state the user relies on when resuming.

## Best solution

Implement the 'pause' compromise suggested by bhavyaus: when stopping, change in-progress todo items to a paused/stopped visual state rather than clearing the entire list, preserving the state for resumption while avoiding the 'stuck' appearance from #274729.
