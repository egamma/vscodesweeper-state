# Issue #157124 — Transform file:// URIs to remote URI inside comments and hover result markdown in remote mode 

[https://github.com/microsoft/vscode/issues/157124](https://github.com/microsoft/vscode/issues/157124)

## Summary

Still unfixed on main: file:// URIs in JSDoc/hover markdown are not transformed to the remote authority when connected via remote SSH. The related PR #157448 was closed without merging, and no URI transformation logic exists in the hover markdown rendering path.

## Change summary

file:// URIs in JSDoc comments and hover results don't navigate correctly in remote mode because they aren't rewritten to use the remote authority.

## Best solution

The hover markdown rendering path (markdownHoverParticipant.ts → IMarkdownRendererService.render) needs to supply a `transformUri` option that rewrites file:// URIs to the workspace's remote authority. The `MarkdownRenderOptions.transformUri` hook already exists in the base markdownRenderer — it just needs to be wired up in the hover and comments rendering contexts with the workspace's remote URI scheme.
