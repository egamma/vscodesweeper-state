# Issue #187155 — Ctrl+# not being detected

[https://github.com/microsoft/vscode/issues/187155](https://github.com/microsoft/vscode/issues/187155)

## Summary

Still valid on main: Ctrl+# on UK Windows keyboards never delivers the # keydown event to VS Code, likely an Electron/Chromium issue where the key event is consumed before reaching the renderer. No fix has been committed. Author is a team member.

## Change summary

Ctrl+# keybinding cannot be detected or used on UK keyboard layouts on Windows because the keydown event for # with Ctrl held never reaches VS Code's keybinding service.

## Best solution

Investigate whether Electron/Chromium is consuming the Ctrl+[code:Backslash, vkey:VK_OEM_7] combination on UK layouts. If upstream, file an Electron/Chromium bug. If VS Code's native keyboard hook can work around it (like other scancode-based dispatch improvements), fix in the Windows keyboard mapper or the native keyboard module.
