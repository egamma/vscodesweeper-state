# Issue #247359 — ViewColumn.Below API

[https://github.com/microsoft/vscode/issues/247359](https://github.com/microsoft/vscode/issues/247359)

## Summary

Keep open in the Backlog: current main still lacks per-call downward editor placement, and the request earned 27 community upvotes.

## Change summary

Allow extensions to open an editor in a new group below the active group regardless of the user's global side-by-side direction.

## Best solution

Extend the editor-opening API with explicit directional placement, whether through `ViewColumn.Below` or a richer group-location option, while preserving `ViewColumn.Beside` and the global setting's existing behavior.
