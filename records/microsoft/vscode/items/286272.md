## Change summary

Deleting a worktree in another window leaves stale repository entries and causes subsequent worktree selection to fail.

## Best solution

Keep the Git extension's repository and worktree views consistent with worktree removal across windows, so deleted paths cannot remain actionable. First establish which stale state survives on current VS Code, distinguishing a legitimate retained branch from a deleted worktree path.
