# Issue #330062 — Agents window -- Files tab disappearance

[https://github.com/microsoft/vscode/issues/330062](https://github.com/microsoft/vscode/issues/330062)

## Summary

Fresh, team-authored report (opened by a COLLABORATOR today, following up on the just-closed #324564) describing a real UX rough edge in the Agents window's managed Files tab, not a code defect with a clear right answer — needs a maintainer design decision on the intended tab-replacement behavior, so it stays open.

## Change summary

In the Agents window single-pane layout, opening a file from the Files tab replaces the Files tab itself (as a 'temporary'/preview editor) instead of keeping the Files tab present alongside it, and there's no easy way back to the Files view short of toggling Hide Editor.

## Best solution

A maintainer on the Agents window layout team should decide whether the Files placeholder tab should persist as a pinned tab alongside the opened file (or be easily re-addable) in src/vs/sessions/contrib/layout/browser/singlePane/singlePaneManagedTabsStrategy.ts, which currently governs when the Files/Changes managed tabs are ensured or replaced.
