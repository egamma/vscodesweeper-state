# Issue #285287 — Separate Taskbar Icons (Groups) for Multiple vscode Instances

[https://github.com/microsoft/vscode/issues/285287](https://github.com/microsoft/vscode/issues/285287)

## Summary

Keep open in the Backlog: the request passed the community threshold with 25 upvotes, and current main still assigns one product-wide application identity rather than supporting logical taskbar groups.

## Change summary

Allow multiple VS Code windows to be divided into distinct OS taskbar groups for faster keyboard switching.

## Best solution

Define a cross-platform grouping model, likely based on profiles, and map it to each operating system's application identity mechanism. The work should remain consolidated here, while the narrower Windows proposal at https://github.com/microsoft/vscode/issues/307266 can contribute its AppUserModelID requirements.
