# Issue #302658 — Copilot CLI: can’t easily open a file in a worktree that was not modified by the agent.

[https://github.com/microsoft/vscode/issues/302658](https://github.com/microsoft/vscode/issues/302658)

## Summary

Team-authored feature request for improving file navigation (Cmd+P / Quick Open) in agent worktrees for unmodified files. No implementation found on main referencing this issue; the design tension between worktree file discoverability and MRU pollution is still unresolved.

## Change summary

Allow users to open files in an agent worktree via Quick Open (Cmd+P) even when those files were not modified by the agent.

## Best solution

Decide on a UX approach that makes worktree files discoverable via Quick Open without polluting the MRU — possibly a scoped file picker mode or a separate Quick Open provider for the active worktree. The design trade-off noted in the issue body (worktree files in MRU causing confusion) needs a product decision before implementation.
