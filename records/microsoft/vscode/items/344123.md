# Issue #344123 — Agent host session blocked by 128K prompt budget while context widget shows 1M window

[https://github.com/microsoft/vscode/issues/344123](https://github.com/microsoft/vscode/issues/344123)

## Summary

Keep open for investigation of the persistent prompt-budget rejection and misleading available-context indication. Current source distinguishes catalog limits from session runtime configuration, but inspection does not establish why this session enforced 128K; the supplied steps and logs suffice to start retesting without an info-needed timeout.

## Change summary

A Copilot CLI agent-host conversation becomes unusable after repeated 128K prompt-budget failures while its context widget advertises a 1M window.

## Best solution

Make the context indicator accurately explain the effective session input budget, total window, and output reservation, and preserve the intended limits across model selection and session restoration. When noncompactable input exceeds the effective budget, recovery guidance should identify an action that can actually reduce that input rather than repeatedly recommending compaction.
