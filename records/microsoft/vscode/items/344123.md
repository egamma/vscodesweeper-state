## Summary

Keep open: repeated prompt-budget failures leave the session unusable despite the widget reporting substantial remaining capacity. Current main has explicit context-tier forwarding, but source inspection does not establish what caused this session's conflicting limits; the supplied environment, steps, and logs suffice to begin retesting without an info-needed timeout.

## Change summary

Ensure a Copilot agent-host session's displayed context capacity, enforced prompt budget, and compaction behavior agree and do not leave subsequent turns permanently blocked.

## Best solution

Establish the effective model and prompt limits at the failing request, then make context reporting and admission/compaction honor the same runtime configuration. Recovery must account for fixed prompt and tool overhead rather than relying on conversation compaction when that overhead already exceeds the enforced budget.
