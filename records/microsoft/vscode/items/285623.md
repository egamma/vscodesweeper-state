## Summary

VS Code already has significant MCP resource/file handling infrastructure (ui/download-file, resource and resource_link processing, save-to-workspace via SaveResourcesAction), but parts of this request — especially automatic ZIP extraction, preview cards for binary artifacts, and auto-save settings — go beyond what's currently implemented. Keeping open as a feature request that partially overlaps with existing capabilities but asks for more.

## Change summary

Add richer handling of MCP tool responses containing file artifacts, including ZIP extraction, preview cards, and auto-save preferences.

## Best solution

Evaluate which specific sub-features (ZIP extraction, artifact preview cards, auto-save settings) are worth adding on top of the existing MCP download/save infrastructure in `chatMcpAppModel.ts` and `chatResourceGroupWidget.ts`. The core save-to-workspace flow already works; this is about polish and completeness for binary/archive artifact types. Consider whether ZIP extraction belongs in core or an extension.
