# Issue #339842 — automations: sandboxing for terminal value is not respected

[https://github.com/microsoft/vscode/issues/339842](https://github.com/microsoft/vscode/issues/339842)

## Summary

Confirmed bug with an open fixing PR already in flight — keeping this open until that PR lands rather than closing it or treating it as agent-ready.

## Change summary

When editing the 'sandboxing for terminal' setting inside an Automation and saving, the Automation dialog doesn't reflect the changed value and always shows it as on.

## Best solution

Land https://github.com/microsoft/vscode/pull/339948, which removes `SessionConfigKey.SandboxEnabled` from `automationDefinitionOwnedConfigKeys` in src/vs/platform/agentHost/common/sessionConfigKeys.ts so sandbox preferences are no longer stripped from the Automation session template and round-trip correctly.
