# Issue #296643 — Model picker renders in top left corner when clicking "Other models"

[https://github.com/microsoft/vscode/issues/296643](https://github.com/microsoft/vscode/issues/296643)

## Summary

Team-authored bug report about the model picker rendering unanchored in the top-left corner. No fix commit found on main; the related issue #299589 was closed as a duplicate of this one, confirming this is the canonical tracker. Keeping open per team-member policy.

## Change summary

The model picker popup sometimes renders in the top-left corner of the window instead of anchored to the triggering button when clicking 'Other models'.

## Best solution

Investigate the anchor-element resolution in `chatModelPicker.ts` — the `show()` method falls back to `this._domNode` when no anchor is provided, but the intermittent nature suggests the DOM node may not yet be laid out or may have been detached when the picker is triggered during streaming. The fix likely belongs in `src/vs/workbench/contrib/chat/browser/widget/input/chatModelPicker.ts` around the anchor logic.
