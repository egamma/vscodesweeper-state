# Issue #296643 — Model picker renders in top left corner when clicking "Other models"

[https://github.com/microsoft/vscode/issues/296643](https://github.com/microsoft/vscode/issues/296643)

## Summary

Keep open as the canonical report for an accepted model-picker anchoring bug. Multiple team-authored reports confirm the same top-left rendering symptom, while no fixing commit referencing this team-authored issue was found.

## Change summary

Expanding "Other Models" can render the model picker at the window's top-left instead of keeping it anchored to the chat input.

## Best solution

Reproduce both known timing variants on current main—during initial window layout and while a chat response finishes—then stabilize the model picker's anchored layout without changing positioning behavior for other action widgets.
