# Issue #252066 — Environment Variables are not inherited when running with Ozone platform (for Wayland)

[https://github.com/microsoft/vscode/issues/252066](https://github.com/microsoft/vscode/issues/252066)

## Summary

Keep open: the reporter confirmed that desktop-launched Wayland sessions still could not use SSH keys in 1.103.1, despite improvements to locale handling and terminal launches. The related macOS fix does not establish that this remaining Linux behavior is resolved.

## Change summary

Wayland-launched VS Code fails to expose expected environment variables to debugging and Git operations, although the integrated terminal can access them.

## Best solution

Establish where the desktop-launch environment diverges from the terminal-launch environment, then restore the variables needed by Git and debugging without changing intentional shell-resolution rules. Separate the remaining Linux launcher failure from the already-resolved locale symptom and macOS environment-truncation regression.
