# Issue #242568 — Support outline for multi-file diff editors

[https://github.com/microsoft/vscode/issues/242568](https://github.com/microsoft/vscode/issues/242568)

## Summary

Keep open: current outline integration does not provide the requested list of files in a multi-file diff editor. The related search-editor bugs concern a different navigation path, and the newer mobile-navigation request is not a valid canonical for this re-reviewed issue.

## Change summary

Show the files belonging to a multi-file diff editor in an outline for navigation.

## Best solution

Provide a file-level outline for the active multi-diff input, with entries that reveal the corresponding diff without opening a separate editor. Preserve ordinary document-symbol outlines and handle search-editor navigation as separate work.
