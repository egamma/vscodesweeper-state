Delegating an untitled prompt to a background session should offer the same copy/move choices for uncommitted changes as submitting a new-session prompt.

Ensure untitled-prompt delegation presents the existing Copy Changes, Move Changes, and Skip Changes confirmation when creating an isolated worktree with eligible local changes.
