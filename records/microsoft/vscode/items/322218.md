# Issue #322218 — SCM: Show changed files as child nodes under each stash

[https://github.com/microsoft/vscode/issues/322218](https://github.com/microsoft/vscode/issues/322218)

## Summary

Keep open as a distinct enhancement: native stash entries remain leaf nodes, so incremental file inspection is not available in the Repositories tree. The proposed change to stash-click behavior needs a maintainer UX decision.

## Change summary

Expand native stash entries into decorated changed-file nodes with individual diffs, retaining stash-level actions.

## Best solution

Provide incremental stash inspection within the existing SCM Repositories tree while retaining the explicit multi-file View Stash action and Apply, Pop, and Drop actions. Decide whether clicking the stash label should expand its children or retain the current editor-opening behavior before accepting the prototype.
