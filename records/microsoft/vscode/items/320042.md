# Issue #320042 — In the server version of VSCode, the menu item is missing in the upper-right corner of the new terminal window

[https://github.com/microsoft/vscode/issues/320042](https://github.com/microsoft/vscode/issues/320042)

## Summary

Keep open as a request for terminal-action parity in browser-based compact windows. Current source explicitly limits auxiliary custom title bars to desktop, leaving the reported web surface without the toolbar; this is not established as a code-server-specific defect.

## Change summary

Expose the terminal action menu in compact terminal windows when VS Code runs in a browser.

## Best solution

Provide an accessible terminal-action surface in browser-based compact auxiliary windows without requiring users to leave compact mode. The work belongs in VS Code's auxiliary editor/title-bar integration, with a maintainer decision on the supported web presentation.
