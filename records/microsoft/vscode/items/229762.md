# Issue #229762 — Move cursor when adding secondary cursors

[https://github.com/microsoft/vscode/issues/229762](https://github.com/microsoft/vscode/issues/229762)

## Summary

VS Code already provides separate anchored extend/shrink commands, while retaining the primary cursor and allowing ordinary arrows to move every cursor are intentional multicursor semantics. The requested workflow can use the existing column-selection commands, but the proposed alternate exit behavior conflicts with established design.

## Change summary

Provide keyboard commands that grow and shrink contiguous multicursors around an anchor, plus an option for ordinary arrow keys to exit multicursor mode at the active edge.

## Best solution

Use custom keybindings for `cursorColumnSelectUp` and `cursorColumnSelectDown` to obtain anchored vertical extension and contraction. Keep the established behavior where multicursors persist through navigation and Escape removes secondary cursors while retaining the primary cursor.

## Evidence

- **existing commands:** `cursorColumnSelectUp` and `cursorColumnSelectDown` are registered in src/vs/editor/browser/coreCommands.ts; they preserve an anchor and move the opposite endpoint one line at a time.
- **verified shrink behavior:** ColumnSelection.columnSelectUp/columnSelectDown in src/vs/editor/common/cursor/cursorColumnSelection.ts recompute the range from the stored anchor to the moving endpoint. The `issue #20087: column select with keyboard` test in src/vs/editor/test/browser/controller/cursor.test.ts verifies that reversing direction removes cursors.
- **primary cursor behavior:** The `issue #8817: Cursor position changes when you cancel multicursor` test in src/vs/editor/contrib/multicursor/test/browser/multicursor.test.ts verifies that `removeSecondaryCursors` retains the original primary selection; the command implements this explicitly in src/vs/editor/browser/coreCommands.ts.
- **maintainer precedent:** A maintainer explained at https://github.com/microsoft/vscode/issues/115413#issuecomment-769919042 that ordinary arrow commands intentionally continue moving all cursors and that Escape is the supported way to remove secondary cursors.
