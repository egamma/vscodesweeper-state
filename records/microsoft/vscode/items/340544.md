# Issue #340544 — Test tab spinner icon broken

[https://github.com/microsoft/vscode/issues/340544](https://github.com/microsoft/vscode/issues/340544)

## Summary

Thanks for the report. The pane-composite (top/bottom activity bar) badge CSS has no icon-badge centering rule. The spinning Testing badge there is a likely cause, and I found no fix on main.

## Change summary

The running-tests spinner badge on the Testing tab renders misstyled when the activity bar is at the top or bottom.

## Best solution

Add a pane-composite CSS rule for icon badges, mirroring the existing progress-badge centering rule. It should set the flex centering, size and padding of `.badge .codicon.badge-content`. Then verify visually in top and bottom positions with and without compact mode.

Acceptance is a visual check in top and bottom positions, in compact and non-compact modes. Number and progress badges must be unchanged.
- **Trace:**

  > The Testing view publishes an IconBadge, which compositeBarActions.ts renders as `.badge.icon-badge > .badge-content.codicon-loading`. The side activity bar has dedicated codicon badge-content rules in activityaction.css. The pane-composite top/bottom bar in paneCompositePart.css only has generic number-badge sizing (10px font, 10px line-height, 16px min-width, padding) and a progress-badge centering rule, and nothing equivalent for icon badges. This is inferred from the CSS and not observed in a render. Do not change the number or progress badge styling.

## Evidence

- **badge source:** The Testing view sets an IconBadge with `spinningLoading` in src/vs/workbench/contrib/testing/browser/testingExplorerView.ts (~line 647). compositeBarActions.ts adds the `icon-badge` class and the codicon classes to `.badge-content`.
- **left-position CSS:** src/vs/workbench/browser/parts/activitybar/media/activityaction.css (~lines 212-222) has `.badge .codicon.badge-content` rules (13px, no padding, centered). These apply only to the side activity bar, which matches the report that the left position works.
