# Issue #22583 — Add padding when pressing space between a pair of curly braces

[https://github.com/microsoft/vscode/issues/22583](https://github.com/microsoft/vscode/issues/22583)

## Summary

Keep open: current typing and formatting capabilities do not provide symmetric padding when Space is pressed inside an empty bracket pair. The accepted Backlog request has 123 upvotes, and no older canonical owning this behavior was verified.

## Change summary

Allow pressing Space inside an empty bracket pair to insert two padding spaces with the cursor between them.

## Best solution

Provide a maintainer-approved bracket-padding behavior in the editor typing experience, with ordinary typing and reliable undo preserved. Decide its activation and language/pair scope before implementation; the existing extension demonstrates a workaround but does not settle core product policy.

- **Behavior:**

  > The requested interaction starts with the caret inside an empty bracket pair: pressing Space inserts a space on each side of the caret instead of inserting only one character. Curly braces are the primary example; the reporter also requests parentheses and square brackets. Acceptance checks should assert both text and caret position, preserve ordinary Space typing outside eligible pairs, and verify that undo/redo never loops. Whether this behavior is enabled by default and which language/pair contexts qualify remain product decisions.
- **Trace:**

  > TypeOperations.typeWithInterceptors in src/vs/editor/common/cursor/cursorTypeOperations.ts is the central typing dispatch. AutoClosingOpenCharTypeOperation in src/vs/editor/common/cursor/cursorTypeEditOperations.ts handles typed openings, while SimpleCharacterTypeOperation inserts the provided character unchanged; neither inspected operation provides the requested empty-pair padding. EnterOperation in the same file implements the newline analogy cited by the reporter through its IndentOutdent path. The JavaScript/TypeScript formatter is not a substitute: extensions/typescript-language-features/src/languageFeatures/formatting.ts does not register Space as an on-type trigger. The extension and its reported undo fix in https://github.com/microsoft/vscode/issues/22583 are useful behavioral context, not a settled decision about default core behavior.
- **Open decisions:**

  - Should padding apply uniformly to empty curly braces, parentheses and square brackets, or follow language-specific eligibility and spacing conventions?
