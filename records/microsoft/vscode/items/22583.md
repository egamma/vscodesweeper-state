# Issue #22583 — Add padding when pressing space between a pair of curly braces

[https://github.com/microsoft/vscode/issues/22583](https://github.com/microsoft/vscode/issues/22583)

## Summary

A real editor feature gap remains, and the Backlog request has 123 community upvotes, well above the promotion threshold. Keep it open for a product decision and classify it as under discussion.

## Change summary

Insert balanced padding when Space is typed between an empty pair of braces, brackets, or parentheses.

## Best solution

Decide whether to add a configurable, language-aware smart-space operation to the editor's character-pair typing pipeline. It should preserve normal single-character insertion unless enabled and handle undo and multiple cursors correctly.
