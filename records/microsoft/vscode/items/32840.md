# Issue #32840 — Cannot display emoji ✔️, 🙋‍♂️

[https://github.com/microsoft/vscode/issues/32840](https://github.com/microsoft/vscode/issues/32840)

## Summary

Still relevant: VS Code's default editor font families (in `src/vs/editor/common/config/fontInfo.ts`) do not include color emoji fonts, so emoji rendering depends on Chromium/Electron's fallback behavior, which varies by platform and version. The workaround is documented in the issue body, but no default-font-family change has landed. Keeping open as an upstream/font-rendering issue with a viable fix path.

## Change summary

Emoji characters render as monochrome glyphs or broken symbols in the editor because color emoji fonts are not included in the default font family stack.

## Best solution

Append platform-appropriate color emoji fonts to `EDITOR_FONT_DEFAULTS` in `src/vs/editor/common/config/fontInfo.ts` — `'Segoe UI Emoji'` on Windows, `'Apple Color Emoji'` on macOS, `'Noto Color Emoji'` on Linux — as the workaround already demonstrates. Alternatively, wait for Chromium/Electron to handle emoji fallback natively, though this has been the stance since 2017 with limited upstream progress. Issue https://github.com/microsoft/vscode/issues/118905 (macOS-specific) and https://github.com/microsoft/vscode/issues/223483 are related and could be consolidated once a default-font-family fix lands.
