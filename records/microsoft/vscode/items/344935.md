# Issue #344935 — Copilot harness: in-Chat terminals are more difficult to follow and cancel by default

[https://github.com/microsoft/vscode/issues/344935](https://github.com/microsoft/vscode/issues/344935)

## Summary

Keep open: current source confirms that Copilot's output-only shell presentation lacks the interactive terminal path used by Local. Existing streaming, background-stop controls, and an experimental terminal override provide partial coverage, but do not establish equivalent default behavior for the full request.

## Change summary

Make Copilot-run commands as easy to monitor, interrupt, and locate in VS Code as Local agent terminals, including interactive tools such as Nx.

## Best solution

Define and deliver a consistent default command-monitoring experience across harnesses, with timely output and discoverable per-command interruption. Decide whether this requires interactive terminal parity or explicit controls for runtime-owned shells, and verify Nx behavior before choosing the execution model.
