# Issue #306165 — Skipping terminal tool call results in model trying to run the terminal tool once again

[https://github.com/microsoft/vscode/issues/306165](https://github.com/microsoft/vscode/issues/306165)

## Summary

Keep open: a maintainer independently reproduced Local chat attempting alternative installation methods after Skip. Current source still returns Skip as a normal model-facing tool result; no verified fixing commit or older canonical covering this symptom was found.

## Change summary

Skipping a Local chat terminal installation request should not cause the model to request the same installation again through another command.

## Best solution

Make Local chat respect the user's decision to skip the requested installation while allowing unrelated work to continue. First retest the confirmed scenario on current builds and establish whether the remaining failure lies in tool-result interpretation or the agent loop.
