# Issue #275979 — Prompt file type detection should be case-insensitive

[https://github.com/microsoft/vscode/issues/275979](https://github.com/microsoft/vscode/issues/275979)

## Summary

Keep open pending demand and an explicit filename-contract decision. Current main remains case-sensitive, but the area maintainer stated that lowercase suffixes may intentionally be required and asked to wait for additional user requests.

## Change summary

Recognize prompt, instruction, agent, and Copilot instruction filenames regardless of extension or filename casing, and strip those suffixes consistently when deriving display names.

## Best solution

The chat-customizations owners should first decide whether these filenames have a strict lowercase contract. If case-insensitive tolerance is accepted, apply it consistently in both type detection and clean-name derivation, with mixed-case tests for every supported prompt-file suffix and special filename.
