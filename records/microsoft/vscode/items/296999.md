# Issue #296999 — VS Code displaying unexpected context window size for Gemini models

[https://github.com/microsoft/vscode/issues/296999](https://github.com/microsoft/vscode/issues/296999)

## Summary

The incorrect value remains source-reproducible on current main: Manage Models still adds the input and output limits even when the provider declares an independent total context window. The accepted, team-authored On Deck bug should remain open for the bounded display correction.

## Change summary

Manage Models displays an inflated context size for Gemini and other models whose input/output limits do not add up to their declared context window.

## Best solution

Make every Manage Models representation—table cell, hover, and accessible label—show the model's declared total context window while retaining the input-plus-output fallback for legacy providers.
