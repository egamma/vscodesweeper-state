# Issue #296999 — VS Code displaying unexpected context window size for Gemini models

[https://github.com/microsoft/vscode/issues/296999](https://github.com/microsoft/vscode/issues/296999)

## Summary

Team-authored bug about incorrect context window size displayed for Gemini models in the model picker. The display logic in chatModelsWidget.ts sums maxInputTokens + maxOutputTokens as 'Context Size', which may produce unexpected values depending on the metadata the backend provides. Keeping open per team-member policy.

## Change summary

The model picker shows an unexpected context window size of 173k for Gemini models.

## Best solution

Verify that the Gemini model metadata (maxInputTokens/maxOutputTokens) from the backend is correct, and consider whether 'Context Size' should show only maxInputTokens (the actual context window) rather than the sum of input + output tokens. The display logic is in `src/vs/workbench/contrib/chat/browser/chatManagement/chatModelsWidget.ts` around lines 141–146.
