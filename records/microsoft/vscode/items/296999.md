# Issue #296999 — VS Code displaying unexpected context window size for Gemini models

[https://github.com/microsoft/vscode/issues/296999](https://github.com/microsoft/vscode/issues/296999)

## Summary

Keep open: model metadata now distinguishes the context window from input/output budgets, but Manage Models still displays their sum. The supplied steps suffice to retest; the historical Gemini value of 173k was not independently confirmed against current provider metadata.

## Change summary

Manage Models displays an unexpectedly small context-window size for Gemini and potentially other models.

## Best solution

Make Manage Models report the provider-supported context window consistently across its column, hover, and accessible label, without confusing reserved prompt budgets with model capacity. Confirm the Gemini provider metadata before deciding the correct displayed value; do not assume the provider exposes the model vendor's full advertised maximum.
