# Issue #234708 — VSCode will silently never auto-update if it is not explicitly moved from the "Downloads" directory to "Application"

[https://github.com/microsoft/vscode/issues/234708](https://github.com/microsoft/vscode/issues/234708)

## Summary

The underlying problem — macOS quarantine/translocation silently blocking auto-updates when VS Code is run from Downloads — has been addressed by switching to DMG as the primary macOS install mechanism (issue #265849, shipped). The canonical tracking issue #213909 was closed as resolved by this same DMG work. This issue describes the same root problem.

## Change summary

VS Code silently fails to auto-update on macOS when run from the Downloads directory due to app translocation/quarantine, with no proactive notification to the user.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/213909 — the DMG install path (#265849) is now the primary macOS distribution and sidesteps the quarantine/translocation issue. Users who installed via the old zip method and are stuck should re-download the DMG.
