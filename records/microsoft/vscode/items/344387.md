# Issue #344387 — Clarify how "This Computer" relates to remote tunnels and sharing controls

[https://github.com/microsoft/vscode/issues/344387](https://github.com/microsoft/vscode/issues/344387)

## Summary

Keep open for UX exploration: current source exposes the tunnel name in the sharing menu but does not connect that identity to This Computer across the picker and Remote Environments. Existing management controls cover only part of the request, and the final presentation is explicitly undecided.

## Change summary

Make the local computer's tunnel identity recognizable across sharing and environment surfaces while distinguishing hosting state from client connection state.

## Best solution

Establish a consistent identity and state presentation across the Agents Window environment picker, Remote Environments, and sharing menu. Preserve the distinction between sharing this machine and connecting to a host; choose the labels and control placement through maintainer design review.
