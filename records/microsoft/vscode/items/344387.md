[https://github.com/microsoft/vscode/issues/344387](https://github.com/microsoft/vscode/issues/344387)

## Summary

Keep open: this work is scheduled for 1.148.0, with substantial changes landed but an open implementation proposal and related testing still underway. Partial implementation does not establish that the cross-surface identity and sharing questions are settled.

## Change summary

Make this computer's local identity, remote sharing name, sharing state, and client connection state understandable across the picker, antenna menu, and Remote Environments.

## Best solution

Review https://github.com/microsoft/vscode/pull/345253 for the remaining behavior, preserving the distinction between sharing this computer, connecting this window, and choosing a session destination.
