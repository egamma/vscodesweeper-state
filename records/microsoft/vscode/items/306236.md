[https://github.com/microsoft/vscode/issues/306236](https://github.com/microsoft/vscode/issues/306236)

## Summary

Verified duplicate of #130332 — both report the same minimap 'fit' sizing bug where switching tabs causes the minimap to render at an incorrect size (between 'fit' and 'fill'). The root cause is the same layout stability logic in editorOptions.ts, and the bug is still present on current main.

## Change summary

Minimap set to 'fit' renders at an incorrect intermediate size when switching file tabs.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/130332 and fix the minimap layout stability heuristics in `EditorLayoutInfoComputer.computeMinimapLayout` (src/vs/editor/common/config/editorOptions.ts) so the `stableFitRemainingWidth` / `stableFitMaxMinimapScale` memory does not carry stale state across tab switches.
