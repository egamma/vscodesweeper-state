# Issue #308595 — Administrator mode doesn't show up in search bar like earlier

[https://github.com/microsoft/vscode/issues/308595](https://github.com/microsoft/vscode/issues/308595)

## Summary

Valid bug: the Administrator label is missing from the command center because the AgentTitleBarStatusWidget creates its own WindowTitle that never receives isAdmin property updates. An open PR (#309255) is already addressing this.

## Change summary

The [Administrator] label no longer appears in the command center search bar when VS Code is running elevated on Windows.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/309255, which syncs title properties (including isAdmin) into the AgentTitleBarStatusWidget's WindowTitle so getTitleDecorations() returns the correct [Administrator] suffix.
