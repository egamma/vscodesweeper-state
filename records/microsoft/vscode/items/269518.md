# Issue #269518 — Hitting undo after code completion should signal that completion was not wanted

[https://github.com/microsoft/vscode/issues/269518](https://github.com/microsoft/vscode/issues/269518)

## Summary

Keep open: current suggestion settings provide workarounds, but do not interpret immediately undoing an accepted completion as negative feedback. The thread supports exploring undo-aware assistance, while leaving the observable response—suppression or a settings recommendation—undecided.

## Change summary

Use immediate undo of a commit-character completion to avoid repeatedly accepting the same unwanted suggestion.

## Best solution

Define undo-aware feedback for ordinary IntelliSense completions in the suggest contribution. Resolve whether that feedback changes future suggestion selection or recommends the existing commit-character setting, preserving explicit completion acceptance and ordinary undo/redo behavior.

- **Open decisions:**
