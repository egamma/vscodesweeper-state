# Issue #205604 — Cannot read properties of null (reading 'modelInfo')

[https://github.com/microsoft/vscode/issues/205604](https://github.com/microsoft/vscode/issues/205604)

## Summary

Still reproduces on current main: `WordHighlighter.query` can be nulled by a re-entrant `_run` call (triggered via `_stopAll` → decoration removal → event emission → cursor change → `_run`), then the outer `_run` at line 676 crashes accessing `.modelInfo` on null.

## Change summary

Clicking in the editor can trigger a TypeError in the word highlighter when a re-entrant `_run` nullifies `WordHighlighter.query` during decoration removal.

## Best solution

Add a null guard on `WordHighlighter.query` at line 676 (`WordHighlighter.query?.modelInfo?.modelURI` instead of `WordHighlighter.query.modelInfo?.modelURI`), and similarly at any other access after `_stopAll` calls that can re-enter. The re-entrancy through `_stopAll` → `removeDecorations` → event fire → `_run` is the root cause pattern.
