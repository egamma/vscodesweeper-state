[https://github.com/microsoft/vscode/issues/274550](https://github.com/microsoft/vscode/issues/274550)

## Summary

Active plan-item tracking multiple UX improvements for background terminals in the agent/chat terminal tool. Significant incremental work has landed since filing (visual indicators for background terminals, terminal reuse improvements, telemetry for hidden terminal interaction), but the umbrella of problems described — excessive terminal creation, missing await semantics, cwd confusion — remains an ongoing workstream with strong community demand (18 upvotes, many satellite issues).

## Change summary

Revisit the UX for how the terminal tool manages background terminals: reduce proliferation, allow awaiting background commands, fix cwd confusion, and reconsider foreground vs. background defaults.

## Best solution

Continue iterating on the terminal tool's background terminal UX in the `chat-terminal` area. Key remaining work includes smarter terminal reuse to prevent proliferation, proper await/completion semantics for background commands, and cwd alignment. The community comments also surface a need for named/targeted terminal support so agents can interact with specific running services without killing them.
