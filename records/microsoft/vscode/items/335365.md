[https://github.com/microsoft/vscode/issues/335365](https://github.com/microsoft/vscode/issues/335365)

## Summary

Current main already persists and restores collapse/scroll state per session in the Changes multi-diff editor when switching sessions — the exact scenario described here appears already handled, so this can likely be closed as already fixed, though the shallow checkout can't confirm a specific fixing commit predating the report.

## Change summary

The Changes multi-diff editor loses collapsed/expanded file state when switching away from and back to an agent session.

## Best solution

Keep the current view-state persistence design in src/vs/sessions/contrib/changes/browser/sessionChangesEditor.ts (setEditorVisible saves state keyed by the per-session multiDiffSource resource, tracksDisposedEditorViewState() keeps it around across tab disposal, and setInput restores it via loadEditorViewState) — verify on the latest build that collapse state now survives session switches.
