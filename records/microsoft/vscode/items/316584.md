[https://github.com/microsoft/vscode/issues/316584](https://github.com/microsoft/vscode/issues/316584)

## Summary

The requested VSIX download capability is already shipped: an extension's context menu in the Extensions view provides Download VSIX, including installed extensions and specific versions.

## Change summary

Provide a way to download an extension's installable VSIX file for offline installation and sideloading.

## Best solution

Use the shipped Download VSIX actions in the Extensions view; commit 19cafbc77dd63c580805305852b312cce71b9a66 introduced the core workflow, and the later follow-up expanded it to installed extensions and version selection.
