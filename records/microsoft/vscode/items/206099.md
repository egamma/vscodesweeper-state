# Issue #206099 — Git - Open File should be in core, not the git extension

[https://github.com/microsoft/vscode/issues/206099](https://github.com/microsoft/vscode/issues/206099)

## Summary

Keep open: the text diff editor's Open File toolbar action still belongs to the Git extension and depends on Git availability. A core command already opens a diff side, but it does not replace that toolbar action or its view-state handling.

## Change summary

Move generic diff-editor Open File functionality into core rather than relying on the built-in Git extension.

## Best solution

Make opening the modified file from an ordinary text diff a core editor capability, available without Git and preserving the relevant selection and viewport. Retain Git-specific resource resolution and SCM behavior in the Git extension.

- **Fit:** aligned
- **Reason:** An extension-independent action for ordinary file comparisons supports consistent core editor interactions.
- **Evidence:** Public values: "Simple, uniform UI and UI interactions." Durable themes: Workbench & core UX and Developer inner loop.
