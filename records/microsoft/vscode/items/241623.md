# Issue #241623 — SCM - Terminal on sidebar loses focus when switching SCM working sets

## Summary

The sidebar-specific focus loss remains identifiable in current source: SCM working-set restoration preserves panel focus but not sidebar focus. Keep this issue open in SCM for a bounded correction.

## Change summary

Switching Git branches from a terminal moved to either sidebar lets restored SCM working-set editors steal keyboard focus.

## Best solution

SCM working-set restoration should retain focus in the sidebar terminal while restoring the branch's editors, preserving existing panel-terminal behavior and normal editor-focused restoration.
