# Issue #296249 — [regression] Coloured brackets very laggy

[https://github.com/microsoft/vscode/issues/296249](https://github.com/microsoft/vscode/issues/296249)

## Summary

Keep open: the reported whitespace-rendering path still collects bracket decorations separately for every visible line. Later whitespace optimizations do not remove that work, and no verified canonical issue or fixing commit supports closing this reopened regression.

## Change summary

Scrolling and typing in bracket-heavy files became substantially slower in 1.102 when bracket colorization and overlay whitespace rendering are enabled together.

## Best solution

Make whitespace overlay rendering avoid redundant per-line bracket-decoration collection while preserving whitespace placement, variable-font support, and bracket colors. Pin the query-cost regression with an editor rendering test.
