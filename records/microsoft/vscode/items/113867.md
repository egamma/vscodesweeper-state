# Issue #113867 — Breadcrumb supports expand all level by default

[https://github.com/microsoft/vscode/issues/113867](https://github.com/microsoft/vscode/issues/113867)

## Summary

The breadcrumb symbol picker still starts with nested levels collapsed, and no verified canonical issue owns this request. Go to Symbol provides an alternative for searching the whole file, but does not deliver the requested expanded breadcrumb dropdown.

## Change summary

Allow the breadcrumb symbol dropdown to start with every nesting level expanded so symbols can be found without manually expanding their parents.

## Best solution

Retain this request for a breadcrumbs-owner decision on initial expansion and searching nested symbols. Preserve Go to Symbol as the existing whole-file search alternative without treating it as equivalent to an expanded breadcrumb tree.
