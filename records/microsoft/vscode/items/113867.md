# Issue #113867 — Breadcrumb supports expand all level by default

[https://github.com/microsoft/vscode/issues/113867](https://github.com/microsoft/vscode/issues/113867)

## Summary

A real gap remains on main: the breadcrumbs symbol picker still collapses nested symbols by default, preventing direct discovery of descendants. The searchable Quick Pick mode is a partial alternative, but it does not provide the requested hierarchical experience.

## Change summary

Allow the breadcrumbs symbol picker to expose nested symbols by default so users can quickly search the entire current-file outline.

## Best solution

Make breadcrumbs filtering reveal matching descendant paths regardless of their prior collapsed state, or provide a breadcrumbs-specific setting controlling initial expansion. Preserve the current collapsed default for users and large outlines unless maintainers explicitly choose otherwise.
