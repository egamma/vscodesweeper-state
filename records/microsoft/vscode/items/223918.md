# Issue #223918 — code moved feature for the inline view

[https://github.com/microsoft/vscode/issues/223918](https://github.com/microsoft/vscode/issues/223918)

## Summary

The inline diff still exposes an enabled moved-code toggle while deliberately suppressing move detection. Keep this accepted diff-editor issue open; the remaining decision is whether to communicate that limitation or support moved-code indicators inline.

## Change summary

Make the moved-code control and its visible results consistent when the diff editor uses inline view.

## Best solution

Give the moved-code control an accurate availability state for the active diff layout, preserving the user's preference when switching layouts. Decide whether this issue should deliver inline move visualization or make the existing side-by-side-only limitation explicit.
