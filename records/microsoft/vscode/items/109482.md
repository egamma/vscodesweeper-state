# Issue #109482 — Details pane flips to the left instead of the top

[https://github.com/microsoft/vscode/issues/109482](https://github.com/microsoft/vscode/issues/109482)

## Summary

Keep open for a placement-policy decision: current code supports displaying suggestion details above the list, but still prefers either side whenever it fits. This team-authored report asks for a different preference, and no verified fix or older canonical establishes grounds for closing it.

## Change summary

Prefer moving suggestion details above the suggestion list rather than to its left when the list itself moves above the cursor.

## Best solution

Resolve whether an above-cursor suggestion list should prefer details above the list over lateral placement, while preserving signature-help visibility. Apply the agreed placement policy in the suggestion-details overlay.
