# Issue #319680 — check for updates button is missing

[https://github.com/microsoft/vscode/issues/319680](https://github.com/microsoft/vscode/issues/319680)

## Summary

This is a support question from a user on a very old build (1.92.2). The 'Check for Updates...' command is available via the Command Palette; on Windows, VS Code auto-updates without a dedicated Help menu entry. The claim that this prevents installing extensions is a misunderstanding — extensions install independently of VS Code version updates.

## Change summary

Reporter on VS Code 1.92.2 cannot find a 'Check for Updates' option in the Help menu on Windows.

## Best solution

Direct the reporter to use the Command Palette (Ctrl+Shift+P → 'Check for Updates') or simply download the latest installer from https://code.visualstudio.com. The missing Help menu entry is by design on Windows where auto-update handles this.
