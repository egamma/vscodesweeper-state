# Issue #86467 — Trailing comma-aware move line up/down

[https://github.com/microsoft/vscode/issues/86467](https://github.com/microsoft/vscode/issues/86467)

## Summary

The built-in move-line commands still move punctuation unchanged; automatic comma adjustment remains a real gap. This accepted Backlog request has 28 upvotes, and the older related requests do not cover the same move-line behavior.

## Change summary

Make moving lines across the last item in JSON and similar comma-separated structures adjust separators so the result remains valid.

## Best solution

Provide language-aware movement that preserves required separators and a single undo operation without changing ordinary text movement unexpectedly. Decide whether this extends the existing move-line commands or is a separate structural operation before implementation.
