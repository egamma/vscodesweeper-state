# Issue #194113 — Use Code Actions For "Edit" In settings.json

[https://github.com/microsoft/vscode/issues/194113](https://github.com/microsoft/vscode/issues/194113)

## Summary

The settings JSON Edit menu still uses a separate context-menu path rather than Code Actions. Keep this accepted, team-authored request open: current providers do not expose its value choices, and no qualifying canonical or concrete fixing commit was established.

## Change summary

Expose the settings.json Edit menu through Code Actions so its setting-value choices can be invoked with the keyboard.

## Best solution

Make the existing setting-value choices available through the standard keyboard-invoked Code Actions surface, preserving configuration eligibility and update semantics. Decide whether this supplements or replaces the existing gutter Edit affordance.
