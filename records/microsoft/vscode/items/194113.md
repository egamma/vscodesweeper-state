# Issue #194113 — Use Code Actions For "Edit" In settings.json

[https://github.com/microsoft/vscode/issues/194113](https://github.com/microsoft/vscode/issues/194113)

## Summary

Still valid: the settings.json "Edit" gutter widget (EditSettingRenderer) is mouse-only and not exposed as a code action. The request to make it keyboard-accessible via code actions remains unimplemented on current main.

## Change summary

Expose the settings.json edit/pencil gutter menu as a code action so it can be triggered via keyboard.

## Best solution

Register a CodeActionProvider in `preferencesRenderers.ts` alongside the existing `EditSettingRenderer` that surfaces the same edit actions (true/false toggle, enum values, etc.) as quick-fix code actions on settings lines, enabling keyboard-driven access.
