# Issue #278169 — Copilot Telemetry - Add a metric to capture when the chat response finishes rendering to the user

[https://github.com/microsoft/vscode/issues/278169](https://github.com/microsoft/vscode/issues/278169)

## Summary

This is a valid, unimplemented feature request from a team member. No rendering-finish telemetry metric exists on current main — the existing `chatIncrementalRenderingSettings` event logs only settings, not timing. No commits reference this issue.

## Change summary

Add a telemetry metric capturing when the chat response finishes rendering to the user, to detect cases where the response data is complete but UI rendering lags.

## Best solution

Instrument the progressive rendering pipeline in `chatListRenderer.ts` to emit a timing metric when the last progressive render tick completes (around the `doNextProgressiveRender` path that clears `renderData` at line ~1811). The metric should capture the delta between response completion and render completion, ideally in the existing Copilot chat response measures bag.
