# Issue #327473 — Why does the built-in AI agent tool, edit_notebook_file, often fail to edit, meaning it executes but doesn't make any changes? However, it never has any problems when editing a brand new notebook.

[https://github.com/microsoft/vscode/issues/327473](https://github.com/microsoft/vscode/issues/327473)

## Summary

Real, source-confirmed bug in the chat notebook-editing flow, and an open PR (#329524) already targets it with `Fixes #327473` — keep this open for that PR to land rather than closing or auto-fixing.

## Change summary

The `edit_notebook_file` tool silently makes no changes to existing notebooks (works fine on brand-new ones), with a repeating 'file already exists' error in the logs.

## Best solution

Land (or otherwise resolve) https://github.com/microsoft/vscode/pull/329524, which adds an `exists()` check before the create-fallback in `ChatEditingSession._createModifiedFileEntry` so failures on an existing notebook re-throw instead of misfiring a non-overwriting create.
