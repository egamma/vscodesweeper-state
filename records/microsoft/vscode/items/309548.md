# Issue #309548 — [Unhandled Error] Cannot resolve canonical URI

[https://github.com/microsoft/vscode/issues/309548](https://github.com/microsoft/vscode/issues/309548)

## Summary

The defect remains on current main: canonical URI resolution rejects whenever one queried local extension host has no proxy, despite the manager contract allowing a null result. Repeated telemetry through stable 1.132.0 confirms substantial ongoing impact across Windows, macOS, and Linux.

## Change summary

Canonical URI resolution emits an unhandled error when a local extension host failed to start, was disposed, or was never lazily created.

## Best solution

Treat an unavailable extension host as having no canonical-URI resolver so other local hosts can still answer, while preserving the final error when no resolver exists and allowing genuine resolver failures to propagate.
