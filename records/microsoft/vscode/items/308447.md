# Issue #308447 — After installing the new version, the message "If you are running a Visual Studio Code user-wide installation as an administrator, updates will be disabled" appears and cannot be resolved.

[https://github.com/microsoft/vscode/issues/308447](https://github.com/microsoft/vscode/issues/308447)

## Summary

Duplicate of #203207 — the reporter's environment triggers the admin-detection logic in the user setup even after attempting to run as non-admin, which is the same incorrect/overly-broad detection tracked there.

## Change summary

VS Code user-wide installation shows 'updates will be disabled' when running as administrator, and the message persists even after the user claims to have switched to non-admin.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/203207 which tracks the broader problem of user setup detecting admin privileges incorrectly (e.g. disabled UAC, domain-joined admin accounts). The fix belongs in `src/vs/platform/update/electron-main/updateService.win32.ts` where `isAdmin` is checked.
