- **Confirmed reproduction and workaround:** https://github.com/microsoft/vscode/issues/156031#issuecomment-1843867051 confirms reproduction with editor.autoClosingComments set to languageDefined and states that turning off comment auto-closing avoids the problem. This workaround does not resolve the underlying defect.
- **Current source path:** extensions/javascript/javascript-language-configuration.json registers '/**' with closing text ' */' and excludes strings but not comments. In src/vs/editor/common/cursor/cursorTypeEditOperations.ts, AutoClosingOpenCharTypeOperation.getAutoClosingPair selects that pair when '*' completes '/*', permits the following whitespace, and enables balance checking only for brackets, not comments. The contained-pair logic does not consume the existing block-comment terminator, so this path inserts another ' */'.
- **Existing unmerged fix candidate:** https://github.com/microsoft/vscode/pull/319405 is OPEN with mergedAt null and explicitly fixes https://github.com/microsoft/vscode/issues/156031. Its documented trigger and erroneous '/** */ */' result match this report; it is not evidence of a landed fix.
