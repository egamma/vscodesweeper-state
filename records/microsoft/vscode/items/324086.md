# Issue #324086 — Python notebook cell editor context menu is rendered behind the bottom panel on Windows

[https://github.com/microsoft/vscode/issues/324086](https://github.com/microsoft/vscode/issues/324086)

## Summary

Valid bug report with clear reproduction steps and screenshots showing the notebook cell editor context menu clipped by the bottom panel on Windows. The prior issue #184455 was closed after macOS-only verification; this appears to still reproduce on Windows. Routing to the notebook area for investigation.

## Change summary

Right-clicking inside a notebook cell's code editor area renders the context menu behind the bottom panel on Windows, making lower options inaccessible.

## Best solution

Investigate whether the editor context menu inside notebook cells uses the correct DOM container/position strategy on Windows — the cell-level context menu works fine, suggesting the editor's context menu is anchored differently (likely using absolute positioning within a clipped container rather than fixed/shadow-root positioning). The fix likely lives in the notebook editor's context view container setup or in how the editor's context menu service obtains its container.
