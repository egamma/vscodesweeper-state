# Issue #331813 — Pet context menu needs reset size

[https://github.com/microsoft/vscode/issues/331813](https://github.com/microsoft/vscode/issues/331813)

## Summary

Confirmed on main: the pet's context menu only offers Grow/Shrink in fixed steps with no way to reset to the default size, so a user who grows the pet a lot has to shrink it repeatedly to get back to normal — a legitimate small UX gap, filed by a team member.

## Change summary

Add a 'Reset Size' option to the VS Code pet's right-click context menu so users don't have to repeatedly click Shrink to return to the default scale.

## Best solution

Add a 'Reset Size' action to the actions list built in `_showContextMenu` in src/vs/workbench/contrib/chat/browser/widget/chatPetWidget.ts, calling `this.chatPetService.setScale(1)` (the default scale used at `_scale = 1`), enabled only when the current scale differs from 1.
