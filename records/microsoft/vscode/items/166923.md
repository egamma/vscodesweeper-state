# Issue #166923 — Outline view for workspace but not only current file

[https://github.com/microsoft/vscode/issues/166923](https://github.com/microsoft/vscode/issues/166923)

## Summary

The requested persistent workspace-wide symbol view remains absent on main. This accepted Backlog request has 29 community upvotes and should remain open.

## Change summary

Add a persistent, filterable Outline-style view containing symbols from the entire workspace rather than only the active file.

## Best solution

Extend the Outline area with a workspace-symbol mode backed by workspace symbol providers, retaining a visible filter and allowing symbol definitions to be inspected without dismissing the view.
