# Issue #250189 — Bug in global search field

[https://github.com/microsoft/vscode/issues/250189](https://github.com/microsoft/vscode/issues/250189)

## Summary

Keep open: current source still replaces the Search input programmatically when seeding from an editor selection, with no explicit undo preservation. The report supplies sufficient steps to retest; native Ctrl+Z behavior on current VS Code remains unverified, and the acknowledged UpArrow workaround does not resolve that behavior.

## Change summary

Seeding global Search from selected editor text prevents Ctrl+Z from restoring previously entered search text.

## Best solution

Preserve undo continuity when editor selections seed the Search field, without changing selection seeding or the separate search-history navigation. First confirm the reported sequence on current Windows VS Code and establish a native-input regression check.
