# Issue #233106 — API for native window handle

[https://github.com/microsoft/vscode/issues/233106](https://github.com/microsoft/vscode/issues/233106)

## Summary

Keep open to track API finalization. The native handle capability is implemented and used by Microsoft Authentication, but it remains a proposed API; the api-proposal label and explicit maintainer direction prohibit a completed close.

## Change summary

Expose the active native window handle to extensions so brokered Microsoft Authentication can parent its OS dialogs correctly.

## Best solution

API owners should settle and finalize the window.nativeHandle contract, including active auxiliary-window semantics and availability across extension hosts. Preserve this issue as the lifecycle tracker until finalization or explicit abandonment.
