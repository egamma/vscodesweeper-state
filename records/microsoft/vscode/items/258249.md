# Issue #258249 — sticky apply button

[https://github.com/microsoft/vscode/issues/258249](https://github.com/microsoft/vscode/issues/258249)

## Summary

This team-authored UX-polish request remains necessary: current main still anchors the code-block action toolbar at the block's top, so it scrolls out of view on long code blocks. No older open issue with the same observable symptom was verified, and the team-author protection bars a judgment close.

## Change summary

Keep the Apply and related code-block actions reachable while the user scrolls through a long chat code block.

## Best solution

Keep the code-block toolbar within its block while pinning it below other sticky chat surfaces whenever the block is visible, without obscuring code or weakening keyboard and screen-reader access. Preserve the quiet-at-rest interaction unless maintainers explicitly choose persistent visibility.
