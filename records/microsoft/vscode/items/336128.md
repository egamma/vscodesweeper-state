# Issue #336128 — Automations: Workdays

[https://github.com/microsoft/vscode/issues/336128](https://github.com/microsoft/vscode/issues/336128)

## Summary

Genuine gap confirmed on main: the Automations recurrence options are only 'manual', 'hourly', 'daily', and 'weekly' — there's no weekdays-only cadence, so this is a real, unimplemented feature request worth keeping open and routing to the Agents Window automations area.

## Change summary

Add a 'Workdays' (Mon–Fri) recurrence option to Automations scheduling so automations can skip weekends.

## Best solution

Extend the AutomationInterval type and schedule model (src/vs/sessions/contrib/automations/browser/automationTools.ts, automationDialog.ts, automationDialogService.ts, providers/agentHost/browser/agentHostAutomationStore.ts, automationsView.ts) with a 'workdays' interval that runs on weekday scheduleDay values only, plus corresponding UI, accessibility text, and store scheduling logic.
