# Issue #330736 — Suggest widget: "Not allowed to create elements in child window" when typing / in a floating (auxiliary) chat window

[https://github.com/microsoft/vscode/issues/330736](https://github.com/microsoft/vscode/issues/330736)

## Summary

Confirmed in source: SuggestWidget._measureContentWidth creates its offscreen canvas via `this.element.domNode.ownerDocument.createElement('canvas')`, which resolves to the auxiliary window's poisoned document when the chat view is undocked — matching the reported error. A PR is already open to fix it, so this should stay open pending that merge, not be closed or auto-fixed.

## Change summary

The suggest widget's measurement canvas is created from the auxiliary window's document, which throws when the chat view is floated into a separate window, so completions never render there.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/330777, which should make SuggestWidget's measurement path use the main window document (or the editor's owning main-window document) instead of the aux-window `ownerDocument`.
