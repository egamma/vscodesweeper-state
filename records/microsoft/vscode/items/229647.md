# Issue #229647 — Undo stacks are not granular enough for Korean

[https://github.com/microsoft/vscode/issues/229647](https://github.com/microsoft/vscode/issues/229647)

## Summary

Keep open: current composition edits still lack Korean-specific undo boundaries, and maintainers explicitly supported improving this behavior. The issue is already correctly routed; no verified canonical or landed fix was found.

## Change summary

Make Korean typing undo in smaller units, ideally consonant/vowel input steps or at least individual completed syllables instead of whole words or lines.

## Best solution

Define Korean-aware undo semantics in the editor input and cursor history pipeline, then provide predictable small-step undo and matching redo across macOS and Windows. Preserve ordinary typing and other IME behavior rather than changing composition grouping globally without validation.
