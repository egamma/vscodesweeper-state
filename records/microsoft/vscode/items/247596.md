# Issue #247596 — http/sse server should not should use stdio/process language

[https://github.com/microsoft/vscode/issues/247596](https://github.com/microsoft/vscode/issues/247596)

## Summary

The terminology gap remains in current source: HTTP/SSE server code lenses still show Running, Stop, and Restart without distinguishing the transport. Keep this open for a bounded presentation-only improvement.

## Change summary

Use connection terminology rather than process-lifecycle terminology in HTTP/SSE MCP server code lenses.

## Best solution

HTTP/SSE code lenses should describe connecting, disconnecting, and reconnecting to a server, while stdio servers retain process-oriented wording. Preserve the existing commands and connection lifecycle.
