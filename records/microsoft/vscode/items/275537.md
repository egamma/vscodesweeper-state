# Issue #275537 — Extensions view is logging 404s often

[https://github.com/microsoft/vscode/issues/275537](https://github.com/microsoft/vscode/issues/275537)

## Summary

Team-authored issue, keeping open. The 404 is caused by the gallery service attempting to fetch marketplace metadata for `ms-vscode.visualization-runner`, a local-only dev extension (lives in `extensions/copilot/.vscode/extensions/`) that has no marketplace listing. The `getLatestRawGalleryExtension` path in `extensionGalleryService.ts` returns `null` on 404 but the network error is still visible in DevTools.

## Change summary

The Extensions view fires marketplace 404 requests for locally-sideloaded dev extensions that have no marketplace presence.

## Best solution

The gallery service in `src/vs/platform/extensionManagement/common/extensionGalleryService.ts` should either skip the marketplace-latest fetch for extensions known to be sideloaded/development-only, or suppress the 404 network noise (e.g. by not logging or not requesting for extensions without a gallery identifier). The `visualization-runner` extension at `extensions/copilot/.vscode/extensions/` is the immediate trigger, but any sideloaded extension with a non-existent marketplace ID would hit this.
