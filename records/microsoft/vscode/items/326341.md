[https://github.com/microsoft/vscode/issues/326341](https://github.com/microsoft/vscode/issues/326341)

## Summary

Confirmed: the 'Search Feature Requests' menu item opens a go.microsoft.com redirect (LinkID=533482) that chains through aka.ms/popular-feature-requests and ultimately lands on Bing instead of the GitHub issues page. The fix is in the Microsoft link-service configuration or in the proprietary product.json, not in the OSS repo's code.

## Change summary

The Help > Search Feature Requests menu item opens a broken Microsoft redirect that lands on Bing instead of the VS Code GitHub feature-request issues list.

## Best solution

Fix the go.microsoft.com/fwlink redirect (LinkID=533482) or the aka.ms/popular-feature-requests shortlink to point to `https://github.com/microsoft/vscode/issues?q=is%3Aissue+state%3Aopen+label%3Afeature-request`. Alternatively, update `requestFeatureUrl` in the proprietary product.json to use the direct GitHub URL. The OSS code in `src/vs/workbench/browser/actions/helpActions.ts` correctly opens whatever URL is configured — no source change needed there.
