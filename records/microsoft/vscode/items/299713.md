# Issue #299713 — CLI session isolation: show name of worktree

[https://github.com/microsoft/vscode/issues/299713](https://github.com/microsoft/vscode/issues/299713)

## Summary

Keep open: existing CLI sessions still receive a locked, generically named Worktree option rather than the worktree's identity. Navigation commands partially address the request, but neither they nor the newer end-to-end tracking issue eliminate the requested inline orientation cue.

## Change summary

Show the active CLI session's worktree name where the disabled isolation picker appears, optionally making it an entry point to open that worktree.

## Best solution

Provide persistent, recognizable worktree identity beside the existing CLI chat input without allowing an established session's isolation mode to change. Decide whether that identity also offers navigation, reusing the existing worktree-opening capability and coordinating terminology with the broader Git/worktree UX effort.
