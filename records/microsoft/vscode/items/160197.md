# Issue #160197 — Comments: Go to Next Comment Thread *in Files*

[https://github.com/microsoft/vscode/issues/160197](https://github.com/microsoft/vscode/issues/160197)

## Summary

The cross-file comment navigation feature has not been implemented. Current main only has single-file comment navigation commands (Go to Next/Previous Commented Range). The request remains valid and has positive community support with a team member (alexr00) actively engaging on the design.

## Change summary

Add a "Go to Next Comment Thread in Files" command that navigates across files, similar to how "Go to Next Problem in Files" works for diagnostics.

## Best solution

Implement cross-file comment thread navigation commands in `src/vs/workbench/contrib/comments/`, modeled on the existing cross-file problem navigation pattern. The team member's suggestion of "Go to Next Expanded Comment Thread in Files" could serve as the scoped variant. This belongs in core alongside the existing single-file comment navigation commands.
