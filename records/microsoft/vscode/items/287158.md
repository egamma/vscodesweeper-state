# Issue #287158 — Git - surface additional actions for worktrees

[https://github.com/microsoft/vscode/issues/287158](https://github.com/microsoft/vscode/issues/287158)

## Summary

Team-authored feature request (hard keep-open). The four requested worktree subcommands (lock, unlock, prune, repair) are not yet implemented on current main — the git extension only exposes worktree add, remove, and a few copy-info commands.

## Change summary

Expose git worktree lock, unlock, prune, and repair as VS Code commands in the built-in git extension.

## Best solution

Implement the four subcommands in `extensions/git/src/git.ts` (Git class) and surface them via `extensions/git/src/commands.ts`, following the existing patterns for `worktree add` and `worktree remove`. Lock/unlock are per-worktree actions and fit the existing worktree context menu; prune and repair are repository-level and could live in the source-control view's overflow menu.
