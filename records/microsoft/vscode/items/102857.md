# Issue #102857 — Git - Bulk merge conflict resolving issue on large files

[https://github.com/microsoft/vscode/issues/102857](https://github.com/microsoft/vscode/issues/102857)

## Summary

The original pain point — bulk merge conflict resolution within a single large file — is partially addressed by the 3-way merge editor's "Accept All Incoming/Current" commands (introduced in ~1.69). However, performance on very large files remains unverified, and the request also encompasses folder-level bulk conflict resolution from the SCM tree view (accept all incoming for all files in a folder), which is not yet implemented. Keeping open as the canonical issue for bulk merge conflict resolution improvements.

## Change summary

Provide reliable bulk merge conflict resolution for large files and across multiple files/folders in the SCM view.

## Best solution

Verify whether the merge editor's `acceptAll` handles very large files gracefully; if so, the single-file part is covered and the issue can be narrowed to the remaining gap: folder-level "accept all incoming/current" in the SCM tree view (right-click a folder → resolve all conflicts within it). That would live in `extensions/git/src/commands.ts` and the SCM view menus. If large-file performance is still a problem in the merge editor, that's a separate perf investigation in `src/vs/workbench/contrib/mergeEditor/`.
