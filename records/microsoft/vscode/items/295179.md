# Issue #295179 — Custom line heights should only affect the view line

[https://github.com/microsoft/vscode/issues/295179](https://github.com/microsoft/vscode/issues/295179)

## Summary

The current source still applies a custom line height across every wrapped view line of the affected model line. Keep this open while the explicitly linked fixing PR remains open; it is an implementation candidate, not a completed fix.

## Change summary

Restrict custom line heights to wrapped view lines containing the decorated range, unless the decoration explicitly applies to the whole line.

## Best solution

Review and resolve https://github.com/microsoft/vscode/pull/258454, preserving whole-line decoration behavior while limiting range decorations to their affected view lines. Coordinate its acceptance with the overlapping older report at https://github.com/microsoft/vscode/issues/249967.
