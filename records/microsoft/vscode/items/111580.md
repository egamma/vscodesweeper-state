# Issue #111580 — Align upload & download progress between desktop and web

[https://github.com/microsoft/vscode/issues/111580](https://github.com/microsoft/vscode/issues/111580)

## Summary

The gap remains on current main: native (desktop) download/upload progress still only reports the file name with no byte-level or percentage progress, while the web/browser path has detailed progress tracking. With 24+ upvotes and active community interest, this should stay open.

## Change summary

Align desktop upload/download progress with the detailed byte-level progress already shown in the web version.

## Best solution

Add byte-level progress reporting to the file service layer (likely in `doCopyFile`/`doPipeStream` in `src/vs/platform/files/common/fileService.ts`) and surface it through `IProgressStep` in `doDownloadNative` and the native upload path in `src/vs/workbench/contrib/files/browser/fileImportExport.ts`. The web browser path already demonstrates the UX pattern to match. This is a good `help-wanted` candidate requiring file-service infrastructure work.
