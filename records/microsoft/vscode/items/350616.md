# Issue #350616 — Regression: GitHub Copilot changes no longer trigger SFTP uploadOnSave after the latest VS Code update

[https://github.com/microsoft/vscode/issues/350616](https://github.com/microsoft/vscode/issues/350616)

## Summary

Keep open to investigate the reported save-event regression. Current main already forces a save when accepting clean documents, so the supplied steps suffice to retest, but source inspection alone cannot establish why uploads stop.

## Change summary

Copilot-edited files no longer consistently trigger SFTP uploadOnSave after acceptance, requiring individual manual saves.

## Best solution

Preserve standard document-save notifications for Copilot changes without requiring users to reopen and save every file. First isolate whether the failure occurs before extension notification delivery or inside SFTP's upload handling; additional Copilot buttons or settings are not yet justified.
