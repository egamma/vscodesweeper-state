# Issue #325647 — Agents window: SSH fails with "no matching host key format" on hosts using OpenSSH host certificates

[https://github.com/microsoft/vscode/issues/325647](https://github.com/microsoft/vscode/issues/325647)

## Summary

Keep open: the Agents window still establishes SSH connections through ssh2, whose supported host-key algorithms exclude OpenSSH certificates. Current host-verification handling explicitly acknowledges this limitation; it does not resolve the reporter's certificate-only handshake failure.

## Change summary

Allow Agents window SSH connections to hosts that offer only OpenSSH host certificates and are trusted through @cert-authority entries.

## Best solution

Provide a certificate-capable SSH connection path that preserves OpenSSH CA trust and host identity verification. This requires upstream ssh2 certificate support or a maintainer-approved alternative transport; recognizing CA entries alone cannot repair algorithm negotiation.
