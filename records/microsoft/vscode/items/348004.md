# Issue #348004 — Changing one chat's workspace restores all sibling SDK sessions and can time out

[https://github.com/microsoft/vscode/issues/348004](https://github.com/microsoft/vscode/issues/348004)

## Summary

The reported dependency on unrelated sibling restores remains in current main: one chat's workspace conversion fails when their combined restore exceeds 30 seconds. Keep this team-authored issue open; preserving legacy sibling directories remains necessary, but does not justify loading their conversations.

## Change summary

Decouple a chat's workspace change from unrelated sibling history loading and SDK restoration while preserving sibling directories across restarts.

## Best solution

Workspace conversion should prepare only the directory metadata whose inheritance could be affected, without hydrating unrelated chats or resuming their SDK sessions. Preserve unopened legacy siblings' original directories, existing explicit directory choices, and peer-only move isolation.
