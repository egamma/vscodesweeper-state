# Issue #100222 — Support reverse tunnel

[https://github.com/microsoft/vscode/issues/100222](https://github.com/microsoft/vscode/issues/100222)

## Summary

Reverse tunnel support (remote-to-local port forwarding) is not implemented in the current extension API or tunneling infrastructure. The request has strong community support (144 upvotes) and is correctly in the Backlog — it should stay open.

## Change summary

Support reverse tunnels (remote-to-local port forwarding) in the VS Code tunnel API and remote explorer, analogous to `ssh -R`.

## Best solution

Extend the tunnel API (`vscode.workspace.openTunnel`) and the ports view to support reverse/remote-to-local tunnels. The work spans `src/vs/platform/tunnel/common/tunnel.ts`, the tunnel model in `src/vs/workbench/services/remote/common/tunnelModel.ts`, and the extension host tunnel service. The use cases (adb forwarding, HTTP proxy, MCP servers) are well-documented in the thread and provide clear acceptance criteria.
