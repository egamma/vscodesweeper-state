# Issue #329076 — Text to Text conversion

[https://github.com/microsoft/vscode/issues/329076](https://github.com/microsoft/vscode/issues/329076)

## Summary

This matches a well-documented, previously-reported class of bug: the integrated terminal (xterm.js) mis-renders complex Indic scripts with conjunct/combining characters — Telugu here, Malayalam and Devanagari in prior reports — because xterm.js's fixed-width grid rendering doesn't handle complex script shaping; root cause lives upstream, so I'm routing to the terminal area rather than closing.

## Change summary

Printing Telugu text from a Python script to the VS Code integrated terminal renders the glyphs overlapping/garbled instead of correctly shaped.

## Best solution

Track as an upstream xterm.js limitation (same family as https://github.com/microsoft/vscode/issues/248894 for Malayalam/Devanagari, itself tied to xtermjs/xterm.js#4867 and xtermjs/xterm.js#2668) — no VS Code-side code change is expected until xterm.js improves complex-script/combining-character shaping; route to the terminal area for awareness and consolidation with the existing upstream tracking.
