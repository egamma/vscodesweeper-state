# Issue #144389 — A white line at the top of the window on macOS Monterey

[https://github.com/microsoft/vscode/issues/144389](https://github.com/microsoft/vscode/issues/144389)

## Summary

Keep open as an upstream macOS/Electron window-decoration issue. Independent reproductions and recent reports support the remaining problem; an upstream report of improvement on macOS 27 beta does not establish a fix for affected macOS versions.

## Change summary

Prevent the bright top window border when VS Code uses a dark theme while macOS uses light appearance.

## Best solution

Resolve the native window-decoration behavior in Electron/macOS, then verify VS Code with its custom title bar on affected OS and display configurations. Evaluate the existing window.systemColorTheme setting as a supported mitigation without assuming it removes the border.
