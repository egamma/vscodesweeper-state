# Issue #329611 — [Regression] [Error] unhandlederror-Cannot read properties of undefined (reading 'isVisible')

[https://github.com/microsoft/vscode/issues/329611](https://github.com/microsoft/vscode/issues/329611)

## Summary

Recurring sticky-scroll crash traced to a real race: `_updateState` in stickyScrollController.ts is async and awaits the folding model before recomputing/rendering state, so `modelLineProjections` can be spliced (via onModelLinesDeleted) between the await and the stale-index read in `modelPositionIsVisible` — this matches the engineering bot's own root-cause analysis and remains unresolved on main across three stable releases with growing user counts (216 → 8,358).

## Change summary

Sticky scroll throws 'Cannot read properties of undefined (reading isVisible)' during async state updates, apparently a regression of a previously 'fixed' issue.

## Best solution

A real fix needs to make the sticky scroll async render path (_updateState in stickyScrollController.ts) resilient to concurrent model-line splicing — e.g. re-validate/clamp line numbers against the current modelLineProjections length right before use in viewModelLines.ts's modelPositionIsVisible, or cancel/re-run the pending render when the model version changes mid-await. This needs a maintainer/editor-team owner to design the concurrency fix rather than a guessed guard.
