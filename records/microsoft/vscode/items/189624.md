# Issue #189624 — Indent guide transparency affects Active indent guide

[https://github.com/microsoft/vscode/issues/189624](https://github.com/microsoft/vscode/issues/189624)

## Summary

Keep open: current source still discards an opaque active indent-guide color when its inactive counterpart is fully transparent. The discussion confirms the exact symptom and provides a near-transparent workaround, not a complete solution.

## Change summary

Honor the active indent-guide color independently when inactive indent guides are configured to be fully transparent.

## Best solution

Allow fully transparent inactive indentation guides alongside a visible active guide in the editor's existing theming path. Preserve default color-level cycling and bracket-guide behavior; an additional active-only setting is not necessary to resolve this report.
