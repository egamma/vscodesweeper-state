# Issue #329155 — Agents window: group delegated sessions across connected AHP hosts

[https://github.com/microsoft/vscode/issues/329155](https://github.com/microsoft/vscode/issues/329155)

## Summary

Team-authored (MEMBER) feature request filed a day ago with a detailed design proposal; no traction data yet and no hard keep-open rule is even needed here since author-defined intent should not be second-guessed — this is a clear route-to-area case for the Agents window/agent-host owners.

## Change summary

Represent cross-host delegation relationships between AHP sessions (e.g. an orchestrator delegating to Windows/Linux runner hosts) as a navigable parent/child hierarchy in the Agents window, rather than as independent flat session lists per host.

## Best solution

Design a lightweight, implementation-neutral relationship-metadata API (originating host/session, downstream host/session, tool-call/task id, optional label) that MCP orchestrators or other tools can publish, and have the Agents window project it into the session tree while still delegating live state/transcript rendering to each session's authoritative AHP host — likely touching src/vs/sessions and the AHP client/session-list code.
