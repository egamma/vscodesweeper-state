Well-specified feature request for the Agents window with no existing capability, no maintainer response yet, and only 30 days old with zero upvotes — too early to close under the staleness process, and no duplicate covers this cross-host delegation grouping.

## Change summary

Add cross-host delegation grouping to the Agents window so sessions created by an orchestrator on other connected AHP hosts appear nested under the originating session instead of as independent top-level entries.

## Best solution

Design a lightweight, provider-agnostic relationship metadata schema (originating host/session, downstream host/session, tool-call/task id) that AHP-connected session providers can publish, and have the sessions tree (src/vs/sessions/contrib/sessions/browser/views/sessionsList.ts, src/vs/sessions/services/sessions/common/sessionsProvider.ts) project it into a nested hierarchy while each child still opens its authoritative live session.
