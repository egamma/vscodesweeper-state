# Issue #348406 — Add option to hide first-line preview of collapsed notebook cell input

[https://github.com/microsoft/vscode/issues/348406](https://github.com/microsoft/vscode/issues/348406)

## Summary

Keep open: current source always renders the collapsed input preview, and the maintainer explicitly retained this request after confirming no setting disables it. No verified open canonical or completed implementation was found.

## Change summary

Allow collapsed notebook cell inputs to hide all source text while keeping interactive outputs visible.

## Best solution

Provide an opt-in output-focused collapse presentation while preserving today's first-line preview by default and accessible ways to expand input. Decide whether provider-controlled per-cell behavior belongs in the initial scope.
