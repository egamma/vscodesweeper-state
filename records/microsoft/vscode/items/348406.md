# Issue #348406 — Add option to hide first-line preview of collapsed notebook cell input

[https://github.com/microsoft/vscode/issues/348406](https://github.com/microsoft/vscode/issues/348406)

## Summary

Keep open: current source always renders the collapsed input preview, and the discussion independently confirms that no setting disables it. The existing collapse command does not cover the requested output-only presentation.

## Change summary

Allow collapsed notebook inputs to hide their source preview while keeping cell outputs visible.

## Best solution

Provide an opt-in notebook presentation option that hides collapsed input previews while preserving the current default and an accessible way to expand inputs. Consider provider-controlled per-cell behavior separately as an API design question.
