# Issue #348406 — Add option to hide first-line preview of collapsed notebook cell input

[https://github.com/microsoft/vscode/issues/348406](https://github.com/microsoft/vscode/issues/348406)

## Summary

The requested output-focused presentation remains missing: collapsing notebook input still renders its first line. Keep this new request open for notebook-owner consideration; no verified canonical issue covers hiding that preview.

## Change summary

Allow collapsed notebook inputs to hide their source preview while keeping interactive outputs visible.

## Best solution

Have notebook owners assess an optional output-focused collapsed-input presentation that preserves the current default and an accessible way to restore input. Treat provider-controlled per-cell behavior as a separate API scope decision.
