# Issue #321157 — Notebook: "Run Cells In Section" (notebook.section.runCells) does nothing when invoked via keybinding

[https://github.com/microsoft/vscode/issues/321157](https://github.com/microsoft/vscode/issues/321157)

## Summary

Confirmed on current main: `NotebookRunCellsInSection` only accepts context from menus (outline entry or cell toolbar) and has no fallback to resolve the active cell from the notebook editor when invoked via keybinding or Command Palette.

## Change summary

The `notebook.section.runCells` command silently does nothing when triggered via a keybinding because it lacks a fallback to resolve the active cell without menu context.

## Best solution

Add a fallback branch in `NotebookRunCellsInSection.run()` (sectionActions.ts) that, when no menu context is provided, resolves the active notebook editor and its focused/selected cell — similar to how other notebook execute commands handle the no-context case.
