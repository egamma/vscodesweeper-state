# Issue #345655 — Move Priority/Recent/Filter toolbar closer to the inbox list when an item is open

[https://github.com/microsoft/vscode/issues/345655](https://github.com/microsoft/vscode/issues/345655)

## Summary

Keep open: the current Inbox places list sorting and filtering controls in the full-width header rather than beside the list they control. This is actionable, team-authored layout feedback, with no verified fix or duplicate.
