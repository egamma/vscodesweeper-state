# Issue #234353 — Terminal suggest: Support resolving environment variables in directories

[https://github.com/microsoft/vscode/issues/234353](https://github.com/microsoft/vscode/issues/234353)

## Summary

Keep open: current directory completion supports tilde expansion but still treats variable-prefixed paths literally. Neither the existing settings nor the related open issues cover the requested shell-aware directory resolution.

## Change summary

Resolve shell variables in directory suggestions so variable-valued paths show their actual location and offer completions beneath it.

## Best solution

Terminal suggestions should resolve supported variable expressions against the active shell's values for directory lookup and display, with shell-appropriate syntax and without evaluating arbitrary shell expressions. Cover both the resolved-path detail and child-directory completions, not only the special case of HOME.
