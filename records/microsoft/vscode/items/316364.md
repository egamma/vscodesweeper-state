[https://github.com/microsoft/vscode/issues/316364](https://github.com/microsoft/vscode/issues/316364)

## Summary

Keep open: the supplied logs substantiate excessive window creation, but neither the suspected agents-restoration cause nor a fixing commit is established. Startup handling has changed since the report; the launch-after-update steps, affected versions, and attached logs suffice to begin retesting without an info-needed timeout.

## Change summary

Launching VS Code after updating to 1.120.0 repeatedly opens additional windows and consumes substantial memory, even with extensions disabled.

## Best solution

Identify what repeatedly requests new windows during Windows startup and eliminate that feedback loop while preserving normal session restoration. Investigate the supplied logs before treating agents restoration or PowerShell-related relaunching as the cause.
