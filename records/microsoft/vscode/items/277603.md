Keep open: the reporter reproduced the Insiders Snap regression on two Kubuntu versions and confirmed that the official .deb avoids it. Neither a fixing commit nor an open canonical covering both the text-rendering failures and dialog-triggered exits was established.

## Change summary

The Insiders Snap displays excessively spaced UI text and exits when opening several dialogs on Kubuntu, while stable and the official .deb behave correctly.

## Evidence

- **Reporter reproduction and package isolation:** In https://github.com/microsoft/vscode/issues/277603, the reporter reproduced the rendering failure on Kubuntu 25.10 and a second computer running 25.04 with extensions disabled. The November 17 comments report exits when deleting files, committing without staged files, and opening About; Snap version 7ba6cc66 remained affected, whereas the official .deb did not reproduce the issue.
- **Current Snap-specific runtime boundary:** resources/linux/snap/snapcraft.yaml uses core20, stages GTK/Pango libraries, excludes bundled fonts and icons, and launches through electron-launch. resources/linux/snap/electron-launch configures host fontconfig, Snap-specific schema and pixbuf caches, sets GDK_BACKEND=wayland when its socket detection succeeds, and ultimately appends --ozone-platform=x11. These are concrete package-specific investigation points, not proof of the reported root cause or a fix.

That confirmation does not establish a fix for this reporter's Snap-specific rendering and dialog failures.
