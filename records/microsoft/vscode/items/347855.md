# Issue #347855 — Agents App: Sub branches don't work, PR and changes shows diff between current worktree branch and master, not current branch and parent

[https://github.com/microsoft/vscode/issues/347855](https://github.com/microsoft/vscode/issues/347855)

## Summary

The current source can create a worktree from the selected feature branch while recording the repository default as its comparison and PR base. Keep this open: related reports cover incorrect diffs, but do not clearly own this report's complete Create PR behavior.

## Change summary

Use the selected parent branch for an agent-created worktree's Changes comparison and Create PR target instead of master.

## Best solution

Preserve the selected parent as the effective base consistently across worktree creation, Changes, and PR creation. Establish how existing sessions with a previously recorded default base should behave before extending the correction to them.
