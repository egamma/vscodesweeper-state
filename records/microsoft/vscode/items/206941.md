# Issue #206941 — Git - The staged file disappears from the git view

[https://github.com/microsoft/vscode/issues/206941](https://github.com/microsoft/vscode/issues/206941)

## Summary

The staged symlink-to-file replacement still disappears on current main: the Git resource mapping handles working-tree type changes but omits staged type changes. Keep this open for a bounded fix in the built-in Git extension.

## Change summary

Keep a tracked symlink replaced by a regular file visible in Staged Changes after staging.

## Best solution

Represent staged Git type changes in the index resource group, with staged diff and unstage behavior consistent with other staged changes. Preserve existing working-tree type-change handling and public status compatibility.
