# Issue #206941 — Git - The staged file disappears from the git view

[https://github.com/microsoft/vscode/issues/206941](https://github.com/microsoft/vscode/issues/206941)

## Summary

Confirmed bug on current main: staged type changes (e.g. symlink → regular file) are silently dropped because the index status parser does not handle the 'T' status code. The file vanishes from the Staged Changes group.

## Change summary

When a symlink is replaced with a regular file and staged, the staged file disappears from the Source Control view because git's 'T' (type changed) status code is not handled for the index/staged position.

## Best solution

Add `case 'T'` to the `switch (raw.x)` block in `extensions/git/src/repository.ts` (around line 3071) to push a `TYPE_CHANGED` resource into `indexGroup`, mirroring how `raw.y === 'T'` is already handled for the working tree. A new `INDEX_TYPE_CHANGED` enum value may be needed in the `Status` enum, or the existing `TYPE_CHANGED` can be reused if a separate index variant is not required for icon/label differentiation.
