# Issue #227528 — Content Lacks Proper Heading Markup

[https://github.com/microsoft/vscode/issues/227528](https://github.com/microsoft/vscode/issues/227528)

## Summary

Still reproduces on main: the settings editor group titles (e.g. 'Extensions', 'HTML') are rendered as plain <div> elements with no heading role or aria-level, making screen reader heading navigation impossible in that view.

## Change summary

Settings editor group/category titles lack proper heading markup (role="heading" + aria-level), hindering screen reader navigation.

## Best solution

Add `role="heading"` and appropriate `aria-level` (computed from `element.element.level`) to the label element in `SettingGroupRenderer.renderElement` in `src/vs/workbench/contrib/preferences/browser/settingsTree.ts`.
