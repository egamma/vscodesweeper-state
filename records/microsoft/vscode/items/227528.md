# Issue #227528 — Content Lacks Proper Heading Markup

[https://github.com/microsoft/vscode/issues/227528](https://github.com/microsoft/vscode/issues/227528)

## Summary

The Settings editor still renders group titles and individual setting titles without heading semantics, matching the reported markup defect. Keep this accepted Backlog bug open; existing accessible labels and tree levels do not provide the requested heading hierarchy.

## Change summary

Expose the Settings editor's visual group and setting-title hierarchy as headings that screen readers can navigate.

## Best solution

Make the rendered Settings content expose meaningful heading names and levels matching its visual hierarchy, including the reported Extensions → HTML → HTML: Auto Closing Tags example. Preserve existing setting-control labels, keyboard navigation, and appearance; changing the overall tree interaction model is separate work.
