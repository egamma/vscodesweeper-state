# Issue #346499 — Agent host: selected custom agent is dropped on send (picker still shows it)

[https://github.com/microsoft/vscode/issues/346499](https://github.com/microsoft/vscode/issues/346499)

## Summary

Keep open: the report provides sufficient steps and wire evidence to retest, but source inspection does not conclusively establish the failure mechanism or a fix. Current code derives draft and submitted agent selections through different state paths; the reported cross-chat draft contamination also remains distinct from the related agent-selection reports.

## Change summary

The Agents window can display a selected custom agent while submitting or executing the turn with the default agent, and can restore another chat's draft.

## Best solution

Make the displayed custom-agent selection agree with the submitted and executed agent on initial and follow-up turns, while keeping drafts isolated per chat. Diagnose client-side selection loss separately from the reported slow-start case where the wire message already contains the agent.
