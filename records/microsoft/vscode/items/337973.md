# Issue #337973 — Agent sessions: built-in GitHub MCP server is locked to a read-only 19-tool subset and its toolset cannot be configured

[https://github.com/microsoft/vscode/issues/337973](https://github.com/microsoft/vscode/issues/337973)

## Summary

Well-researched and source-confirmed: the built-in GitHub MCP server's tool allowlist is hardcoded in `src/vs/platform/agentHost/node/shared/githubMcpServer.ts` (no `X-MCP-Toolsets` header, no configurable toolset setting), so write-capable tools like `projects_write`/`issue_write` are unreachable from agent sessions even with the right OAuth scopes. This is a real, unaddressed gap worth a maintainer decision on the fix shape.

## Change summary

Add a way to configure which GitHub MCP toolsets the built-in agent-host server exposes (or honor a user-supplied server definition), instead of the current hardcoded 19-tool read-only allowlist.

## Best solution

Add a setting (e.g. `chat.agentHost.githubMcpServer.toolsets`, mirroring `github.copilot.chat.githubMcpServer.toolsets`) that `createGitHubMcpServerConfiguration` translates into an `X-MCP-Toolsets` header, or make the dedupe/identity check in the built-in-server matcher respect a user-supplied server's headers instead of collapsing it into the built-in identity.
