# Issue #286296 — Support decorations that hide characters

[https://github.com/microsoft/vscode/issues/286296](https://github.com/microsoft/vscode/issues/286296)

## Summary

Genuine feature gap — the editor decoration API supports injecting and styling text but has no mechanism to hide/collapse existing characters in the view. Team-authored and milestoned to Backlog; keeping open.

## Change summary

Add a decoration option that hides (visually collapses) characters in the editor view without removing them from the underlying document.

## Best solution

Extend `IModelDecorationOptions` (in `src/vs/editor/common/model.ts`) with a property that tells the view model to collapse the decorated range visually, analogous to how `InjectedTextOptions` injects text. The view-line projection logic in `modelLineProjectionData.ts` and the inline-decoration pipeline would need to support zero-width rendering for hidden ranges. This unlocks WYSIWYG markdown editing and similar rich-text overlay scenarios via extensions.
