# Issue #296608 — Error when searching after opening file by clicking link in terminal with line number

[https://github.com/microsoft/vscode/issues/296608](https://github.com/microsoft/vscode/issues/296608)

## Summary

The current source still preserves #L65 in terminal file-link resources without interpreting it as a selection, exposing the reported search failure. Keep this open: the older related report covers query-bearing links but does not establish coverage of the additional line-fragment navigation defect.

## Change summary

Opening a terminal file link ending in #L65 fails to navigate to that line and subsequently breaks workspace search.

## Best solution

Terminal line-fragment links should open the underlying file at the requested line without retaining navigation metadata in its editor resource identity. Workspace search must continue working while that editor remains open, without changing global URI comparison semantics.
