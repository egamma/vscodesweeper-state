# Issue #328285 — Agents window: make GitHub issue filing reliable across MCP, browser, and CLI

[https://github.com/microsoft/vscode/issues/328285](https://github.com/microsoft/vscode/issues/328285)

## Summary

Keep open: current Agent Host startup resolves the login-shell environment, but that alone does not establish reliable GitHub write-path selection across MCP, browser, and CLI authentication. The related issues cover different observable failures, and no verified fix or eligible duplicate canonical was found.

## Change summary

Make agent-driven GitHub issue filing reliably discover a usable write capability, distinguish independent authentication stores, and honor an explicitly named repository.

## Best solution

Establish a capability-aware GitHub issue-filing contract for Agent Host sessions that honors the requested owner/repo and reports authentication failures for the specific client involved. Determine with the maintainer whether this should remain agent tool-selection guidance or become a first-class issue-creation operation; login-shell PATH resolution addresses only one part of the request.
