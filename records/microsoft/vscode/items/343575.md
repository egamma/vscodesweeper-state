# Issue #343575 — Copilot harness (now default) silently lacks run_in_terminal; agents fall back to a separate shell and fail where Local works

[https://github.com/microsoft/vscode/issues/343575](https://github.com/microsoft/vscode/issues/343575)

## Summary

Keep open for a decision on integrated-terminal compatibility and clear harness limitations. Current terminal overrides offer partial support, but do not cover prepared Local-terminal state or the additional migration and customization concerns.

## Change summary

Provide integrated-terminal compatibility in Copilot-harness chats, or clearly disclose its absence, and clarify migration status and Local-default selection.

## Best solution

Make harness capabilities understandable before existing workflows fail, and decide whether Copilot sessions should access prepared integrated terminals. Distinguish MCP configuration migration from live server availability; retain the related terminal and picker issues as focused dependencies rather than closing this broader report into one of them.
