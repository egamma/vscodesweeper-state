# Issue #170960 — A setting to change the minimum scrollbar height

[https://github.com/microsoft/vscode/issues/170960](https://github.com/microsoft/vscode/issues/170960)

## Summary

A niche but valid feature request — the minimum scrollbar slider size is hardcoded to 20px in `scrollbarState.ts` with no user-facing configuration. No existing setting covers this, and no canonical issue absorbs it. Stays open under the community process with 0 upvotes and no maintainer signal.

## Change summary

Allow users to configure the minimum height of the scrollbar slider (currently hardcoded to 20px), so it can be reduced when users prefer scrolling via the minimap.

## Best solution

Expose a setting (e.g. `editor.scrollbar.minimumSliderSize`) that feeds into `ScrollbarState` in `src/vs/base/browser/ui/scrollbar/scrollbarState.ts`, replacing the hardcoded `MINIMUM_SLIDER_SIZE = 20`. The setting would need a sensible floor (e.g. 5px) to prevent a zero-size slider. Given 0 upvotes and niche appeal, this is low priority — keep open for community traction.
