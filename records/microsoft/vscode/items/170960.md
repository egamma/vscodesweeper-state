# Issue #170960 — A setting to change the minimum scrollbar height

[https://github.com/microsoft/vscode/issues/170960](https://github.com/microsoft/vscode/issues/170960)

## Summary

Verified duplicate: the open scrollbar-customization backlog issue owns both scrollbar dimensions and the minimum thumb-height requirement, so this request should be consolidated there.

## Change summary

Add an editor setting that controls the scrollbar thumb's minimum height, allowing it to match the minimap indicator for large files.

## Best solution

Consolidate the design in https://github.com/microsoft/vscode/issues/30191 and decide there on a uniform scrollbar customization model covering width, height, visibility, and minimum thumb size rather than adding an isolated editor-only setting.
