# Issue #170960 — A setting to change the minimum scrollbar height

[https://github.com/microsoft/vscode/issues/170960](https://github.com/microsoft/vscode/issues/170960)

## Summary

A real configuration gap remains: current main hard-codes a 20px minimum scrollbar thumb size, and the existing scrollbar settings only control visibility and thickness. The Backlog item should remain under discussion because there is no implemented capability, canonical duplicate, or maintainer scope decision supporting closure.

## Change summary

Allow users to configure the editor scrollbar thumb's minimum length so it can remain proportional to the minimap for very large files.

## Best solution

Prefer a coherent scrollbar-sizing design that preserves the accessible 20px default while determining whether advanced users should be allowed to reduce the editor thumb minimum; avoid adding an isolated visual toggle without an explicit product decision.
