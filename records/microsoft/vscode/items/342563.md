## Summary

Keep open: the current fork flow still lacks an explicit success message or link back to the original conversation. The existing title change and session navigation do not fully address the reported orientation problem.

## Change summary

Make successful conversation forking clearly apparent, ideally with an in-chat confirmation linking to the original conversation.
