# Issue #302518 — terminal command was linkified

[https://github.com/microsoft/vscode/issues/302518](https://github.com/microsoft/vscode/issues/302518)

## Summary

Team-filed bug about false-positive terminal link detection on a command argument path; no fix found on current main. Routing to the terminal area for triage.

## Change summary

Terminal link detector incorrectly linkifies path-like substrings within command arguments (e.g. `--extensionDevelopmentPath=d:\src\...`), resolving them to unrelated workspace files.

## Best solution

The local link detector in `terminalLocalLinkDetector.ts` should exclude or deprioritize path-like substrings that appear as values of CLI flags (after `=` or following `--flag`). The resolver validates existence but not contextual plausibility.
