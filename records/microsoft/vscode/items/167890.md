# Issue #167890 — Allow extensions to change { ... } completion to { ... };

[https://github.com/microsoft/vscode/issues/167890](https://github.com/microsoft/vscode/issues/167890)

## Summary

Keep this accepted Backlog request open while the editor API design is resolved. Format-on-type is only a partial workaround because it requires `editor.formatOnType`, which defaults to false, and does not customize the autoclosing operation itself.

## Change summary

Allow language extensions to contextually replace an automatically inserted `}` with `};` for C-like type definitions.

## Best solution

Provide a language-aware extension hook for customizing generated closing text, or deliberately extend the existing on-type formatting path so extensions can implement this behavior without requiring users to enable global format-on-type.
