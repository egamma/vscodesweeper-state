# Issue #267445 — Accessibility/A11y: quickInputBox aria role is textbox when it should be combobox

[https://github.com/microsoft/vscode/issues/267445](https://github.com/microsoft/vscode/issues/267445)

## Summary

The quick-pick input still lacks combobox semantics in current source, while plain text-entry dialogs must retain textbox semantics. Keep this open for the existing PR to address that distinction.

## Change summary

Give list-filtering quick inputs appropriate combobox semantics without changing plain text-entry inputs into comboboxes.

## Best solution

Review and complete https://github.com/microsoft/vscode/pull/267447 with scenario-appropriate input roles and associated ARIA state. Preserve textbox behavior for standalone input dialogs such as creating a Git branch.

This establishes the semantic mismatch from source; screen-reader speech was not executed.
