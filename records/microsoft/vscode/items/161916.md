# Issue #161916 — Git - "Stage selected range" doesn't change diff view instantly

[https://github.com/microsoft/vscode/issues/161916](https://github.com/microsoft/vscode/issues/161916)

## Summary

Keep this open for Git refresh diagnosis. A landed change adds immediate diff invalidation, but subsequent reports describe the same stale display, and the current notification ordering does not establish that the original problem is fully resolved.

## Change summary

Refresh the open unstaged diff after staging selected lines without requiring a tab switch, reopening the editor, or a delayed background refresh.

## Best solution

Ensure the Git diff's original document reflects the updated index after partial staging, including the first staged range in a previously unstaged file. Establish a regression check for notification and repository-state ordering before treating the existing invalidation change as sufficient.
