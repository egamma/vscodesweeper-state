# Issue #335435 — Agent chat title is automatically replaced by a temporary subtask

[https://github.com/microsoft/vscode/issues/335435](https://github.com/microsoft/vscode/issues/335435)

## Summary

The overwrite remains possible on current main: an automatic `rename_chat` call is applied without checking whether the existing title is already meaningful. This member-authored issue must remain open absent an explicitly linked fixing commit or verified duplicate.

## Change summary

Prevent an agent's automatic title update for a narrow follow-up task from replacing an established conversation-wide title.

## Best solution

Add a host-enforced policy for automatic rename requests that preserves established titles while retaining explicit user-requested renames; maintainers should first settle whether automatic renaming after initial title generation is ever allowed when the conversation topic materially changes.
