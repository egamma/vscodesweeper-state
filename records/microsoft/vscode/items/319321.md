# Issue #319321 — Feature Request: Presaved MCP Toolsets / Named Presets for Context-Aware Tool Activation

[https://github.com/microsoft/vscode/issues/319321](https://github.com/microsoft/vscode/issues/319321)

## Summary

Current VS Code already provides named reusable tool sets, including sets containing individual MCP tools, through `.toolsets.jsonc`, the Configure Tool Sets command, and the chat tool picker. The narrower workspace-storage request remains separately tracked, so this broader request can close as covered by the designed tool-set workflow.

## Change summary

Provide named presets that switch the MCP servers or individual tools exposed to chat for different tasks.

## Best solution

Use user-defined `.toolsets.jsonc` sets and select them through the Configure Tools picker; use prompt or agent tool declarations for task-specific configurations. Continue workspace-local tool-set storage work in https://github.com/microsoft/vscode/issues/251515 rather than adding a parallel `mcp.toolsets` settings model.

## Evidence

- **named tool sets:** `src/vs/workbench/contrib/chat/browser/tools/toolSetsContribution.ts` defines the `.toolsets.jsonc` schema with named sets, descriptions, icons, and arrays containing individual tools or nested tool sets; full reference-name resolution allows MCP tools to be members.
- **configuration command:** `ConfigureToolSets` registers the `chat.configureToolSets` Command Palette action and supports creating a tool set from the active chat selection, creating a new tool-set file, and editing existing named sets.
- **activation UI:** `src/vs/workbench/contrib/chat/browser/actions/chatToolPicker.ts` renders user-defined tool sets and MCP servers as selectable checkbox groups, including per-tool children, while `chatSelectedTools.ts` applies and persists the resulting global or session selection.
- **extension contribution:** `src/vs/workbench/contrib/chat/common/tools/languageModelToolsContribution.ts` registers the existing `languageModelToolSets` extension contribution point, covering extension-contributed sets without a new switching API.
- **maintainer precedent:** In https://github.com/microsoft/vscode/issues/243714, a maintainer preferred tool sets in prompt files and modes over MCP-configuration enablement and later closed the request after that support became available.
- **remaining subset:** Workspace-local `.toolsets.jsonc` storage is an independently tracked open request at https://github.com/microsoft/vscode/issues/251515; it does not require retaining this broader duplicate configuration proposal.
