## Summary

The Ruby indentation rules still miss method declarations containing a default hash and brace-delimited blocks, allowing move-line operations to remove required indentation. Keep this open; the reporter supplied the requested clarification and recording, and the current source exposes the remaining defect.

## Change summary

Moving Ruby lines incorrectly reduces indentation around brace blocks and methods with hash-valued default arguments.

## Best solution

Make Ruby automatic indentation recognize method bodies despite hash-valued defaults and correctly handle brace-delimited blocks, with move-up and move-down regression cases using the reported examples. Preserve the existing do/end behavior and indentation behavior for other languages.
