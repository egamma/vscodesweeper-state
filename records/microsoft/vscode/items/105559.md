# Issue #105559 — Windows Magnifier not following active menuitem

[https://github.com/microsoft/vscode/issues/105559](https://github.com/microsoft/vscode/issues/105559)

## Summary

Windows Magnifier not following focused menu items in custom menus remains unresolved on main — no fix commit found, and the root cause appears to be an Electron/Chromium interaction with Windows Magnifier. The issue is real but blocked on upstream investigation.

## Change summary

Windows Magnifier does not follow the active menu item when navigating VS Code's custom dropdown menus with keyboard arrows.

## Best solution

This likely requires Electron/Chromium-level investigation into how Windows Magnifier tracks focus in BrowserWindow overlays. The menu code correctly focuses items and sets ARIA roles; the issue may be that Magnifier doesn't detect focus changes in certain Electron rendering contexts. A workaround exists via native title bar menus. Further upstream engagement or testing against newer Electron versions may resolve it.
