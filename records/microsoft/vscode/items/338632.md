# Issue #338632 — Organizing the custom agents in agent picker

[https://github.com/microsoft/vscode/issues/338632](https://github.com/microsoft/vscode/issues/338632)

## Summary

Keep open for community review: individual agent visibility controls exist, but user-defined role groups and group-level visibility remain distinct missing capabilities. The reporter-linked request covers discovery-source grouping, not the full role-based workflow requested here.

## Change summary

Organize custom agents into role-based groups and let users show selected groups while hiding others.

## Best solution
