# Issue #342141 — Copilot Chat: built-in link rules block user-requested links to .proto definitions

[https://github.com/microsoft/vscode/issues/342141](https://github.com/microsoft/vscode/issues/342141)

## Summary

Keep open: current linkification supports explicit source-line destinations but deliberately replaces descriptive labels with file-location chips, leaving the requested combination unsupported. This is a link-presentation capability request, not grounds to remove URI restrictions wholesale.

## Change summary

Allow a Copilot response link to retain a qualified symbol name while opening an explicitly specified source file and definition line.

## Best solution

Provide a supported named-location link that preserves the requested symbol label and explicit source destination, with consistent prompt guidance across models. Keep existing file-reference navigation and remote-workspace handling intact rather than requiring users to bypass prompt rules with URI formats.
