# Issue #350043 — "Open Customizations" should be in a different group of right click menu

[https://github.com/microsoft/vscode/issues/350043](https://github.com/microsoft/vscode/issues/350043)

## Summary

The grouping concern remains on current main: Open Customizations shares the navigation section with session-opening actions, while host and session settings occupy a separate management section. Keep this open as bounded menu-discoverability polish.

## Change summary

Separate Open Customizations from actions that choose where a session opens.

## Best solution

Present session customization alongside configuration actions rather than session-opening destinations, consistently across the editor window's legacy and shared session lists.
