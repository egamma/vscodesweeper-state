# Issue #237861 — Fix `CompletionItem.command` deprecation for built-in js/ts

[https://github.com/microsoft/vscode/issues/237861](https://github.com/microsoft/vscode/issues/237861)

## Summary

Still valid: the built-in TypeScript extension sets CompletionItem.command during resolve (via the ApplyCompletionCommand pattern), triggering the deprecation warning at extHostLanguageFeatures.ts:1248. The code hasn't been refactored yet.

## Change summary

The built-in JS/TS completion provider changes CompletionItem.command during resolveCompletionItem, which is deprecated.

## Best solution

Refactor extensions/typescript-language-features/src/languageFeatures/completions.ts so the completion item's command is fully determined at provide-time rather than being assembled during resolve. The commands array built in resolveCompletionItem (line 207–232) needs to move earlier or use a different mechanism (e.g., additionalTextEdits + a pre-set command).
