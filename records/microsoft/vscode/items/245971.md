# Issue #245971 — Can't Use "Publish Branch" Feature When Using SOCKS5 Proxy

[https://github.com/microsoft/vscode/issues/245971](https://github.com/microsoft/vscode/issues/245971)

## Summary

The upstream networking limitation has been fixed and the supporting Undici version is now integrated into VS Code, so Publish Branch requests can use a configured SOCKS5 proxy.

## Change summary

Publishing a GitHub branch failed when `http.proxy` used a SOCKS5 URL.

## Best solution

Keep the upstream SOCKS5 support from nodejs/undici commit b12081c340b69716c75a9f73687748b46858fbda and VS Code's integration of Undici 7.24.0 or newer; no additional GitHub extension change is needed.
