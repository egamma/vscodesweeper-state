# Issue #259540 — Support rollback and review code change suggestion in github copilot of vscode

[https://github.com/microsoft/vscode/issues/259540](https://github.com/microsoft/vscode/issues/259540)

## Summary

Verified duplicate of the older open issue https://github.com/microsoft/vscode/issues/245108: both request that undoing an accepted Copilot edit restore its pending review decorations and per-change Keep/Undo controls.

## Change summary

After accepting all Copilot changes in a file, undo or checkpoint restore should return those changes to a reviewable state with per-line acceptance and rejection controls.

## Best solution

Consolidate the review-state semantics in https://github.com/microsoft/vscode/issues/245108, including this report's whole-file Accept case: undoing that decision should restore the file's undecided suggestions and per-change review controls.
