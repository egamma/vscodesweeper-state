# Issue #227467 — API to expose the shell's actual environment to extensions

[https://github.com/microsoft/vscode/issues/227467](https://github.com/microsoft/vscode/issues/227467)

## Summary

The `terminalShellEnv` API is actively being developed — shell environment collection is implemented for pwsh, bash, zsh, fish, and Windows, but the API remains in proposed state and hasn't been finalized yet. This tracking issue should stay open until the API is promoted to stable.

## Change summary

Expose the shell process's actual environment variables to extensions via a new proposed API on TerminalShellIntegration.

## Best solution

Finalize the `terminalShellEnv` proposed API (resolve the TODO about sharing `onDidChangeTerminalShellIntegration` and promote from `vscode.proposed.terminalShellEnv.d.ts` to stable). The implementation groundwork is largely done; this issue tracks the remaining API finalization.
