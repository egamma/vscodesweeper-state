# Issue #198805 — Explore using code mapping for pasted code

[https://github.com/microsoft/vscode/issues/198805](https://github.com/microsoft/vscode/issues/198805)

## Summary

Keep this exploration open: existing paste transformations do not establish that mapped-edit providers can participate in ordinary code paste. No verified canonical or concrete implementing fix was found, and the exploration-title protection independently rules out closing it.

## Change summary

Explore invoking mapped-edit providers when users paste code into an existing file to reduce manual integration work.

## Best solution

Determine whether code mapping should be offered through the existing Paste As provider framework, preserving ordinary paste behavior. Keep this API exploration distinct from language-specific import updates and chat code-block application.
