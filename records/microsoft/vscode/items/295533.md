# Issue #295533 — `"chat.editing.explainChanges.enabled": true,` the tooltips still visible after i click on keep button.

[https://github.com/microsoft/vscode/issues/295533](https://github.com/microsoft/vscode/issues/295533)

## Summary

The defect remains on current main: accepting chat edits does not clear the active explanation state, and hidden explanation widgets can be reused with stale diff data during a later generation.

## Change summary

Keeping explained chat edits should dismiss their explanation tooltips and prevent those explanations from reappearing for later edits or unrelated files.

## Best solution

Tie explanation state to the lifetime of the edits it describes: successful Keep operations should remove explanations for the accepted changes, and a later explanation generation should create widgets exclusively from its current diff state.
