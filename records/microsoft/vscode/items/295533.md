# Issue #295533 — `"chat.editing.explainChanges.enabled": true,` the tooltips still visible after i click on keep button.

[https://github.com/microsoft/vscode/issues/295533](https://github.com/microsoft/vscode/issues/295533)

## Summary

Still reproduces on main: the `accept()` and `reject()` methods in `ChatEditingSession` do not call `clearExplanations()`, so explanation tooltips persist after changes are kept or undone. Only `dispose()` clears them.

## Change summary

Explanation tooltips from `chat.editing.explainChanges.enabled` persist after clicking Keep/Undo, and stale tooltips can appear in unrelated files on subsequent edits.

## Best solution

Add a `this.clearExplanations()` call inside the `accept()` and `reject()` methods in `src/vs/workbench/contrib/chat/browser/chatEditing/chatEditingSession.ts`, after the entries are operated on. This ensures tooltips are cleaned up whenever changes are accepted or rejected, not only when the session is disposed.
