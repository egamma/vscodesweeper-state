# Issue #330786 — Modern UI: extension-contributed Panel icons are visually oversized and misaligned

[https://github.com/microsoft/vscode/issues/330786](https://github.com/microsoft/vscode/issues/330786)

## Summary

Fresh, well-documented report of a genuine Modern UI polish gap: extension-contributed SVG icons in the Panel composite bar render visually larger than built-in codicons even though both are scaled to the same 16px box, because raw extension SVG artwork typically fills its 24×24 viewBox edge-to-edge while codicon glyphs bake in internal optical padding.

## Change summary

Under `workbench.experimental.modernUI` with Panel labels hidden, extension-contributed view-container icons (e.g. Codex, Claude Code) look oversized and optically off-center compared to built-in Terminal icon in the horizontal Panel composite bar.

## Best solution

Same team/area that fixed the related Chat panel icon centering issue (https://github.com/microsoft/vscode/issues/324632, https://github.com/microsoft/vscode/pull/324942) should look at `src/vs/workbench/browser/parts/paneCompositeBar.ts` (uri-icon `mask-size` uses the same `iconSize` as codicons, so third-party SVG artwork that fills its full viewBox reads bigger) and `src/vs/workbench/contrib/styleOverrides/browser/media/activityBar.css`; likely fix is applying uniform optical inset/padding to `uri-icon` masks rather than raw `mask-size` equal to the codicon font-size.

## Evidence

- **iconSize for Panel composite bar:** src/vs/workbench/browser/parts/panel/panelPart.ts sets `iconSize: 16` for the Panel composite bar options (getCompositeBarOptions).
- **shared mask-size for uri-icon:** src/vs/workbench/browser/parts/paneCompositeBar.ts `toCompositeBarActionItem` creates a CSS rule `mask-size: var(--activity-bar-icon-size, ${this.options.iconSize}px)` for extension URI icons — the same 16px box used for the codicon `font-size: 16px` rule in src/vs/workbench/contrib/styleOverrides/browser/media/activityBar.css. Both icon kinds are scaled to an identical box, so the reported size mismatch stems from how much of that box each icon's own artwork fills, not from a differing box size.
- **precedent fix:** A closely related issue for the Chat panel icon (https://github.com/microsoft/vscode/issues/324632) was fixed via targeted CSS in activityBar.css/padding.css in PR https://github.com/microsoft/vscode/pull/324942 — confirming this class of Modern UI icon-centering/sizing issue is actively triaged and fixed piecemeal by the same area owners.
- **--activity-bar-icon-size scope:** The `--activity-bar-icon-size` CSS custom property is only set on the dedicated `.activitybar` element in src/vs/workbench/browser/parts/activitybar/activitybarPart.ts, so it does not affect the Panel's composite bar; the Panel falls back to the 16px iconSize default for both codicon and uri-icon rules, ruling out a stray CSS-variable mismatch as the cause.
