# Issue #223339 — No Pre-selection on Manual IntelliSense Trigger

[https://github.com/microsoft/vscode/issues/223339](https://github.com/microsoft/vscode/issues/223339)

## Summary

Keep open: current main supports selection control only for triggers marked automatic, while this requests equivalent control for a manual programmatic trigger. This team-authored Backlog item has no issue-referencing implementation or verified duplicate permitting a factual close.

## Change summary

Allow programmatic manual IntelliSense invocation to show suggestions without initially selecting an item.

## Best solution

Decide whether to restore a `noSelection` argument on `editor.action.triggerSuggest` or formally document `{ auto: true }` with `editor.suggest.selectionMode` as the supported API for this scenario.
