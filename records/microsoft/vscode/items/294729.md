# Issue #294729 — Mermaid Diagram graph edge text cut off

[https://github.com/microsoft/vscode/issues/294729](https://github.com/microsoft/vscode/issues/294729)

## Summary

The mermaid diagram container uses `overflow: hidden` which clips long edge labels; no fix has landed on main for this. Team-authored, valid visual bug — keeping open.

## Change summary

Mermaid graph edge labels are clipped when they exceed the rendered edge width, and hovering does not reveal the full text.

## Best solution

Either allow the SVG viewBox to expand to fit edge labels, or add a hover/tooltip mechanism in `extensions/mermaid-markdown-features/preview-src/` that shows full label text on hover. The container's `overflow: hidden` (in `diagramStyles.css` and `diagramManager.ts`) contributes to clipping but is needed for pan/zoom — a tooltip on truncated `edgeLabel` SVG elements would be the least-invasive fix.
