# Issue #348118 — Bring the Local harness’s per-session tool picker to the Copilot harness

[https://github.com/microsoft/vscode/issues/348118](https://github.com/microsoft/vscode/issues/348118)

## Summary

The open tool-selection parity issue already covers this request, including independent selections for different sessions and reducing irrelevant tool context. Consolidate there while preserving the explicit requirement to change tools in an existing session.

## Change summary

Add a Copilot chat-input tool picker that changes tool availability only for the active session, including individual MCP tools.

## Best solution

Deliver session-scoped Copilot tool-selection parity through https://github.com/microsoft/vscode/issues/340041, keeping workspace defaults and other sessions unchanged.
