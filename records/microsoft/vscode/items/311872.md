# Issue #311872 — Modal overlay windows do not apply `contrastBorder` or `contrastActiveBorder`

[https://github.com/microsoft/vscode/issues/311872](https://github.com/microsoft/vscode/issues/311872)

## Summary

The contrast customization gap remains in current source: the modal border prefers editorWidget.border, preventing the configured contrastBorder from taking effect in Dark 2026. The reported workaround improves visibility but does not resolve support for the contrast tokens.

## Change summary

Settings and keyboard-shortcut modal overlays do not honor the configured contrast border colors.

## Best solution

Make modal editor boundaries honor the existing contrast-color semantics while preserving the ordinary editorWidget.border appearance when contrast colors are unset. Keep the change confined to modal editor presentation rather than changing shared theme defaults.
