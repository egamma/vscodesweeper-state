# Issue #311872 — Modal overlay windows do not apply `contrastBorder` or `contrastActiveBorder`

[https://github.com/microsoft/vscode/issues/311872](https://github.com/microsoft/vscode/issues/311872)

## Summary

The modal overlay border uses `var(--vscode-editorWidget-border, var(--vscode-contrastBorder))`, so `contrastBorder` is only a fallback — Dark 2026 explicitly sets `editorWidget.border`, which wins. The reporter's expectation that `contrastBorder` would add a separate contrast outline (as it does for other workbench parts) is reasonable as a polish request.

## Change summary

Setting `contrastBorder` or `contrastActiveBorder` does not affect the modal overlay window border when `editorWidget.border` is already set by the theme.

## Best solution

The modal editor part (`src/vs/workbench/browser/parts/editor/media/modalEditorPart.css`) should apply `contrastBorder` as a separate outline (like other workbench parts do in HC themes) rather than only as a fallback for `editorWidget.border`. The workaround is to customize `editorWidget.border` directly.
