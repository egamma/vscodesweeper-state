# Issue #326445 — workbench.colorCustomizations stop working after update to V1.130

[https://github.com/microsoft/vscode/issues/326445](https://github.com/microsoft/vscode/issues/326445)

## Summary

This should stay open: the report has a credible root-cause analysis and maintainer follow-up around Modern UI overriding explicit workbench colors, and the linked later issue appears closed as a duplicate/reference rather than proof that this one is fixed. The current workaround is disabling `workbench.experimental.modernUI`, which confirms the affected area but does not remove the underlying bug.

## Change summary

Explicit `workbench.colorCustomizations` and theme colors for the activity bar, status bar, and title bar are ignored when `workbench.experimental.modernUI` is enabled.

## Best solution

Modern UI should preserve explicit theme/custom color values for affected workbench parts, likely in the workbench Modern UI styling path, while retaining transparency only as the default when no explicit color is provided.
