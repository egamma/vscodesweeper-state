# Issue #339236 — VS Code very slow to install on Windows arm64 due to x86 emulation on the installer

[https://github.com/microsoft/vscode/issues/339236](https://github.com/microsoft/vscode/issues/339236)

## Summary

Valid, well-diagnosed report — the Windows installer (build/win32/code.iss) has no SetupArchitecture directive, so it defaults to the slow x86-under-emulation path on arm64. An open PR already proposes the exact fix, so this should stay open and the PR reviewed rather than closed.

## Change summary

The Windows installer runs as an x86 executable on arm64 (and x64), which is slow under emulation; Inno Setup 7's SetupArchitecture=x64 opt-in would fix this.

## Best solution

Land https://github.com/microsoft/vscode/pull/339238 (which bumps to Inno Setup 7 and sets a 64-bit setup architecture) — that directly implements the reporter's request.
