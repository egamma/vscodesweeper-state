# Issue #339236 — VS Code very slow to install on Windows arm64 due to x86 emulation on the installer

[https://github.com/microsoft/vscode/issues/339236](https://github.com/microsoft/vscode/issues/339236)

## Summary

Valid, well-diagnosed request (Inno Setup's SetupArchitecture=x86 default forces slow x86 emulation on arm64 installs) that already has an open fixing PR from the same reporter — keep open until that PR lands rather than closing or treating as done.

## Change summary

Switch the Windows installer (Inno Setup) to build a native 64-bit (x64/arm64) setup executable instead of defaulting to x86, which runs slowly under emulation on Windows arm64.

## Best solution

Land https://github.com/microsoft/vscode/pull/339238 (which sets SetupArchitecture=x64 in build/win32/code.iss, pending the Inno Setup 7.1.0 compiler update in joaomoreno/node-innosetup-compiler#1) — that directly resolves the reported install slowness.
