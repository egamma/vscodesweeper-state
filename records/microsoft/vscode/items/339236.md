# Issue #339236 — VS Code very slow to install on Windows arm64 due to x86 emulation on the installer

[https://github.com/microsoft/vscode/issues/339236](https://github.com/microsoft/vscode/issues/339236)

## Summary

Keep open: current main does not select a 64-bit setup executable, and an open PR already proposes the requested change. Review that implementation together with its compiler upgrade prerequisite; neither has merged.

## Change summary

Build Windows x64 and arm64 installers as x64 executables to avoid slower x86 emulation on Windows on Arm.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/339238 together with adoption of Inno Setup 7, then verify fresh installation and updates from existing installations on Windows arm64 and x64. The version-guarded script change alone will not activate the requested behavior with the currently bundled compiler.
