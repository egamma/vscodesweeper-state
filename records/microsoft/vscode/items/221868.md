The failure path remains present on main: unbounded output appends can grow the piece-tree line-start array until `Array.concat` rejects its length. This team-authored telemetry issue has no issue-linked fix, so it should remain open.

## Change summary

Appending a sufficiently large, newline-heavy output stream can throw `RangeError: Invalid array length` while updating the output text model.

## Best solution

Bound or compact the output model before its line-start storage reaches JavaScript array limits, while preserving recent output and clearly handling truncated content. The change likely spans the output model and piece-tree boundary and needs a controlled large-output regression test.
