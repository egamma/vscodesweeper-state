# Issue #344344 — Automations + DevContainers: inactionable, non-dismissable warning message

[https://github.com/microsoft/vscode/issues/344344](https://github.com/microsoft/vscode/issues/344344)

## Summary

Keep open: the current Automations UI still displays the reported disconnected-host message without explanation, recovery actions, or dismissal. This team-authored usability request belongs with the existing Automations owners; the collaborator's suggestion to associate warnings with affected automations remains an unresolved presentation decision.

## Change summary

Make disconnected Dev Container warnings in Automations understandable and actionable rather than persistent unexplained messages.

## Best solution

Explain which automation capabilities are affected and provide a relevant next step without obscuring usable automations on other hosts. The owner should decide whether this belongs on affected automation cards, in a provider-level notice, or both; do not assume that a disconnected host necessarily has known saved automations.
