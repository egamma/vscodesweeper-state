# Issue #346307 — `git.defaultCloneDirectory` setting does not expand `${userHome}` or `${env:HOME}` in Remote WSL settings

[https://github.com/microsoft/vscode/issues/346307](https://github.com/microsoft/vscode/issues/346307)

## Summary

Keep open for review of the linked implementation candidate. Current source supports leading-tilde expansion but not predefined variables in this setting; adding that capability belongs to the built-in Git extension, not Remote WSL.

## Change summary

Support ${userHome} and ${env:HOME} in git.defaultCloneDirectory, resolving them in the remote environment when using Remote WSL.

## Best solution

Review and land, revise, or close https://github.com/microsoft/vscode/pull/346334 before pursuing another implementation. The resulting behavior should resolve supported variables on the machine performing the clone while preserving existing tilde and literal-path handling.
