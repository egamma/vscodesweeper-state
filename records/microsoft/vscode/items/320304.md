# Issue #320304 — Whitespace colors should be more customizable.

[https://github.com/microsoft/vscode/issues/320304](https://github.com/microsoft/vscode/issues/320304)

## Summary

The existing foreground override does not provide theme-relative colors or a whitespace background, so a meaningful capability gap remains. The older theme-reference request covers part of this proposal, but not enough to justify closing this re-reviewed item as a duplicate.

## Change summary

Allow whitespace markers to use customizable backgrounds and theme-derived foreground colors that remain readable when switching themes.

## Best solution

Consider whitespace-background support in the editor rendering and color-token surfaces, while keeping references and relative color expressions consistent with the shared theming work in https://github.com/microsoft/vscode/issues/56855. Establish which additional control characters are desired separately rather than treating that unspecified addition as an implementation requirement.
