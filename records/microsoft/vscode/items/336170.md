## Change summary

An active Agent Host is omitted from Agents web discovery when five stale tunnel records precede it in the account inventory.

## Best solution

Ensure Agents web discovery returns every eligible tunnel and presents the active host regardless of stale account records. Trace the six-tunnel reproduction through the deployed embedder or SDK enumeration path and subsequent cache reconciliation; do not require users to delete unrelated tunnels.
