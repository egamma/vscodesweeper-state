## Summary

This upstream Chromium/Logitech driver interaction bug was partially fixed by Chromium updates (the original Chrome 76 issue is long resolved), but later comments reveal a separate Logitech Options DLL-injection component that may still affect some users. The issue is correctly labeled upstream and should remain open as a tracking point, though it likely doesn't reproduce on modern Electron 42/Chromium 134+.

## Change summary

Horizontal mouse wheel scrolling (especially Logitech mice on Windows) doesn't work in VS Code due to an interaction between older Chromium versions and Logitech Options driver software.

## Best solution

The Chromium-side fix shipped years ago (Chrome 78+). What remains is likely the Logitech Options process-injection issue described in later comments. If this still reproduces on current VS Code (Electron 42, Chromium ~134), it would need a fresh investigation — possibly an Electron-level workaround or documentation. A maintainer should check whether any recent reports exist; if not, this could be closed as resolved by Chromium updates.
