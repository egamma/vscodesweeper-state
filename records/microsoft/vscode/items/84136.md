# Issue #84136 — The horizontal wheel of mouse is invalid

[https://github.com/microsoft/vscode/issues/84136](https://github.com/microsoft/vscode/issues/84136)

## Summary

Keep open as the existing horizontal-wheel interoperability report: later confirmations show that the original Chromium improvement and Logitech profile workarounds did not resolve the full issue. No verified open canonical or concrete adopted fix supports closing it.

## Change summary

Dedicated horizontal mouse wheels intermittently fail to scroll VS Code on Windows, sometimes depending on window focus or mouse-driver application profiles.

## Best solution

Reliable native horizontal-wheel delivery through the Windows driver and Chromium/Electron input boundary, without elevation, executable renaming, or focus-switching workarounds. Establish which remaining failures originate in driver event delivery versus runtime handling before choosing the owning fix.
