# Issue #317439 — Browser: Browser tab is very long when the title matches another tab's

[https://github.com/microsoft/vscode/issues/317439](https://github.com/microsoft/vscode/issues/317439)

## Summary

Still reproduces on main: when two browser tabs share the same page title, VS Code's tab disambiguation escalates to LONG verbosity, which includes the full URL with query strings — producing an extremely wide tab. Team-authored polish issue, no fix found.

## Change summary

Integrated browser editor tabs become excessively wide when two tabs share the same page title, because disambiguation shows the full URL including query parameters.

## Best solution

Cap the description length at each verbosity level in `BrowserEditorInput.getDescription()` (or its `getURLTitles` helper), or provide a smarter disambiguation that highlights only the differing URL segments rather than dumping the entire raw URL. The fix belongs in `src/vs/workbench/contrib/browserView/common/browserEditorInput.ts`.
