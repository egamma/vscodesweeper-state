# Issue #334922 — Claude: `/reload-skill` offered but doesn't seem to be working

[https://github.com/microsoft/vscode/issues/334922](https://github.com/microsoft/vscode/issues/334922)

## Summary

Thanks for the report — this looks like a real gap, not user error. Tracing the Claude agent-host code, `Query.reloadPlugins()` is fully wired (`claudeSdkPipeline.ts`), but `reloadSkills()` is never called anywhere outside test stubs (which explicitly throw 'not modeled'), and the pipeline's own roadmap notes list the skills/commands reload mapping and file-watching behavior as still-open design questions.

## Change summary

Selecting the Claude `/reload-skills` slash command in chat doesn't appear to actually refresh the SDK's skill set — a newly added `.claude/skills/...` skill isn't picked up.

## Best solution

Wire the `/reload-skills` built-in command selection to actually invoke the SDK's `Query.reloadSkills()` (mirroring how `ClaudeSdkPipeline.reloadPlugins()` is already implemented and called), and resolve the open 'skills vs commands mapping' / file-watching questions noted in `src/vs/platform/agentHost/node/claude/roadmap.md`.
