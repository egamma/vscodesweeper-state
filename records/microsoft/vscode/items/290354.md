# Issue #290354 — Git - single line diff in the inline git blame box

[https://github.com/microsoft/vscode/issues/290354](https://github.com/microsoft/vscode/issues/290354)

## Summary

The built-in blame hover still lacks the requested line-level diff preview. Opening the commit already targets the current file, but that partial navigation improvement does not satisfy the central request; keep this open as a feature request.

## Change summary

Show the blamed line's committed change inside the inline Git blame hover, with a direct link to the corresponding single-file diff.

## Best solution

Consider a compact, on-demand committed-change preview in the built-in Git blame hover, with access to the file diff while preserving existing commit navigation. Decide the preview's scope before implementation; revealing the current file in a multi-file diff is useful but not equivalent.
