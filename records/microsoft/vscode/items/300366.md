## Change summary

Add selectable worktree and workspace isolation modes to VS Code Copilot, comparable to the isolation choices available in Copilot CLI.

## Best solution

Define a unified Copilot isolation model that lets users choose whether an agent operates in a dedicated Git worktree or within an explicit workspace boundary, then apply that model consistently across local and background agent sessions without changing ordinary editor workspace semantics.
