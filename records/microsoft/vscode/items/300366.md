# Issue #300366 — Add Worktree and Workspace Isolation Modes to GitHub Copilot (Similar to GitHub Copilot CLI)

[https://github.com/microsoft/vscode/issues/300366](https://github.com/microsoft/vscode/issues/300366)

## Summary

The requested worktree and workspace isolation modes already exist in the Copilot extension, exposed via the `github.copilot.chat.cli.isolationOption.enabled` setting. The `IsolationMode` enum (`Workspace` / `Worktree`) is implemented in the chat sessions system and was being actively developed even before this issue was filed.

## Change summary

Add worktree and workspace isolation modes to GitHub Copilot in VS Code, allowing scoping of AI context to a Git worktree or workspace boundary.

## Best solution

The capability is already shipped. The `github.copilot.chat.cli.isolationOption.enabled` setting enables the isolation-mode picker in Copilot CLI / Agents sessions, letting users choose between Worktree (isolated Git worktree) and Workspace modes. Close as already available and point the reporter at the setting.
