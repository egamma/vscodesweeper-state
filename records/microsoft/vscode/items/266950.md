# Issue #266950 — Restore local model selection (ability to disable models) in VS Code Copilot Chat

[https://github.com/microsoft/vscode/issues/266950](https://github.com/microsoft/vscode/issues/266950)

## Summary

The original ask (restore the model-hide UI) was partially addressed in v1.109, but the remaining and now central request — that hidden models should also be excluded from Auto mode and subagent selection — is still unimplemented on current main. Valid open feature request.

## Change summary

Hidden models should be excluded from Auto mode selection and subagent model choices, not just removed from the model picker UI.

## Best solution

Extend the Auto model selection logic in `chatModelSelectionLogic.ts` and any subagent model resolution paths to respect `isModelHidden()`, so that hiding a model via the management UI effectively removes it from all automated selection — not just the picker dropdown. The BYOK model selection concern (comment 10) may also warrant a dedicated follow-up.
