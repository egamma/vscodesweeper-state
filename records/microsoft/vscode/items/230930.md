# Issue #230930 — Modified image attachments don't update the thumbnail/hover

[https://github.com/microsoft/vscode/issues/230930](https://github.com/microsoft/vscode/issues/230930)

## Summary

The bug remains on current main: file-backed image attachments cache their bytes when attached, and subsequent file-change events neither refresh the attachment nor rerender its thumbnail and hover.

## Change summary

Refresh an attached image's thumbnail and hover after its source file is edited and saved.

## Best solution

Refresh the image attachment data when its watched file changes and emit an attachment update so the chat input rerenders the thumbnail and hover, while preserving the existing deletion behavior.

- **current source:** In src/vs/workbench/contrib/chat/browser/attachments/chatAttachmentModel.ts, ChatAttachmentModel._watchAttachment handles only FileChangeType.DELETED; modification events do not re-resolve the image or emit an updated attachment.
- **stale rendering path:** In src/vs/workbench/contrib/chat/browser/attachments/chatAttachmentWidgets.ts, ImageAttachmentWidget captures attachment.value as imageData during construction and passes that fixed buffer to createImageElements, so both the thumbnail and hover retain the original bytes until the attachment is rerendered.
