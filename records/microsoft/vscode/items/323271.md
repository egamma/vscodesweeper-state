[https://github.com/microsoft/vscode/issues/323271](https://github.com/microsoft/vscode/issues/323271)

## Summary

Keep open as a feature request: the inspected built-in Git authentication settings do not provide an alternate credential-helper configuration file. The workflow that writes the helper still needs identification before deciding which component should support this.

## Change summary

Allow credential-helper configuration to be written to an untracked local Git configuration file instead of a version-controlled ~/.gitconfig.

## Best solution

Identify the component that writes the helper and assess alternate-file support there, preserving authentication and ensuring Git actually loads the selected file. The built-in Askpass integration should not acquire a new configuration-writing responsibility merely to accommodate an unidentified writer.
