## Summary

The missing status-icon symptom (CVS extension status glyphs disappearing) matches the root cause tracked and fixed in the related issue: a 1.136 regression that blocked `vscode-managed-remote-resource` icon loads over Remote-SSH. That was fixed and merged before this report closed, and the reporter's own last comment agrees it's the same issue, so this can be closed as completed.

## Change summary

After updating to VS Code 1.136, status icons (pending/not-checked-in/etc.) from the Schwartzkers CVS extension stopped rendering when connected over Remote-SSH; downgrading to 1.135 restored them.

No further core change needed; ask the reporter to confirm on a build containing that fix.
