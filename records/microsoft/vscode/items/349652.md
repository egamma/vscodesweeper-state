# Issue #349652 — Text inserted by dictation app (Wispr Flow) does not reach the editor while JAWS is running

Keep open for accessibility investigation: the report supplies sufficient steps and useful controls to retest the JAWS–Wispr interaction. Current source exposes two editor input implementations, but neither source inspection nor the available history establishes where automatic insertion fails.

## Change summary

Wispr Flow fails to insert dictated text into the editor with JAWS running, although manual paste succeeds.

## Best solution
