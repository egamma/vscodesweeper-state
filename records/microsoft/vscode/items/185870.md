# Issue #185870 — Editor rulers disappear randomly in large files

[https://github.com/microsoft/vscode/issues/185870](https://github.com/microsoft/vscode/issues/185870)

## Summary

Keep open: the discussion confirms disappearing ruler segments, and the default renderer still uses document-height ruler elements. Experimental GPU rendering addresses this scenario through a separate path, but does not establish a fix for the default renderer.

## Change summary

Configured editor rulers develop missing segments while scrolling larger files.

## Best solution

Make rulers remain continuously visible in the default DOM renderer without requiring experimental GPU acceleration. First reproduce the artifact on a current build and distinguish oversized-element painting from other browser or scaling effects.
