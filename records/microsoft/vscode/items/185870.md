# Issue #185870 — Editor rulers disappear randomly in large files

[https://github.com/microsoft/vscode/issues/185870](https://github.com/microsoft/vscode/issues/185870)

## Summary

Still reproduces on main: the ruler DOM elements use a static height capped at 1,000,000px (line 95 of rulers.ts), but Chromium's GPU compositor can fail to render tall thin elements well before that limit, causing rulers to vanish or show gaps in large files. No fix has landed.

## Change summary

Editor rulers visually disappear at certain scroll positions in large files due to Chromium GPU texture limits on very tall DOM elements.

## Best solution

Virtualize ruler rendering: instead of a single element spanning the full scroll height, reposition the ruler element to a viewport-relative window on each scroll event (similar to how the editor virtualizes line rendering). This avoids Chromium's GPU texture size limits entirely and may also improve rendering performance. The fix lives in `src/vs/editor/browser/viewParts/rulers/rulers.ts`.
