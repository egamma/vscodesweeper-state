# Issue #154156 — use "current working directory detection" in the implementation of "runInTerminal"

[https://github.com/microsoft/vscode/issues/154156](https://github.com/microsoft/vscode/issues/154156)

## Summary

This remains a valid debug/terminal integration cleanup: avoid emitting a redundant `cd` before `runInTerminal` when the integrated terminal's detected current directory already matches the requested working directory. The issue is in the Backlog, has no verified duplicate or fixing reference, and the discussion clarified rather than rejected the intended optimization.

## Change summary

Use integrated-terminal current-working-directory detection to skip a redundant directory-change command when launching a debug target through `runInTerminal`.

## Best solution

Keep the requested debug launch directory authoritative, but have the integrated-terminal `runInTerminal` path compare it with the terminal's reliably detected current directory and omit only a provably redundant `cd`; preserve the existing fallback whenever detection is absent, stale, or differs.
