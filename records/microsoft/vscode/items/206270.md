# Issue #206270 — Suggest keyboard shortcuts based on user behavior

[https://github.com/microsoft/vscode/issues/206270](https://github.com/microsoft/vscode/issues/206270)

## Summary

Valid feature request for behavior-based keyboard shortcut suggestions. No existing implementation in core, and the discussion raises legitimate points about extension API limitations for detecting composite actions. Stays open for community traction.

## Change summary

VS Code should observe user interaction patterns and suggest relevant keyboard shortcuts when it detects repetitive multi-step actions that could be done more efficiently.

## Best solution

This could reasonably live as an extension if the extension API exposed sufficient action-sequence observability, or as a core feature in the keybindings/editor layer. The strongest path is probably an extension-candidate with API gaps filed separately — but no maintainer has weighed in yet, so it stays open for the community process.
