# Issue #314896 — Browser: Agentic network request inspection

[https://github.com/microsoft/vscode/issues/314896](https://github.com/microsoft/vscode/issues/314896)

## Summary

Valid feature request for agentic network request inspection in the integrated browser. No implementation exists on main — the CDP infrastructure is present but Network domain events are not surfaced for agent inspection. Team-authored and in Backlog; stays open.

## Change summary

Allow the agent to inspect network requests made in the integrated browser, beyond what the Playwright Page API currently provides.

## Best solution

Expose CDP Network domain events (request/response logging from initial page load onward) through the integrated browser's existing CDP infrastructure so agents can inspect network traffic without an external CDP MCP server. The plumbing lives in `src/vs/platform/browserView/electron-main/browserViewDebugger.ts` and the CDP proxy layer; the feature would add a network event stream accessible to agent tools.
