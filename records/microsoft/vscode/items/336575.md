# Issue #336575 — Open Markdown preview in a browser or save as HTML

[https://github.com/microsoft/vscode/issues/336575](https://github.com/microsoft/vscode/issues/336575)

## Summary

Propose closing as an extension candidate: established triage decisions cover both exporting the built-in Markdown preview as HTML and opening that preview in an external browser. This is a scope decision, not a duplicate close or a claim that the requested UI already exists.

## Change summary

Add a way to export rendered Markdown as HTML or open it in an external browser for text-to-speech and sharing.

## Best solution

Provide browser-ready Markdown export through an extension, consistent with the existing decisions for this capability. Any concrete missing API needed to preserve preview fidelity should be evaluated separately as an extension-API request.

## Evidence

A subsequent reporter objection about extension feasibility was not a maintainer acceptance of the feature.
- **Recent HTML-export precedent:** https://github.com/microsoft/vscode/issues/239837 requests an export button alongside the built-in Markdown preview, explicitly including HTML and preserving rendered formatting. It was closed with *extension-candidate on 2025-02-07: https://github.com/microsoft/vscode/issues/239837#issuecomment-2641433014.
- **Reporter-cited decision:** The report acknowledges https://github.com/microsoft/vscode/issues/69413. That issue requested Chrome/Mozilla preview and was closed with *extension-candidate: https://github.com/microsoft/vscode/issues/69413#issuecomment-467196681. The broader export precedents above also address this report's HTML-saving alternative.
- **Existing capability and boundary:** extensions/markdown-language-features/src/commands/index.ts registers preview commands and markdown.api.render, but no HTML-export or external-preview command. RenderDocument.execute in src/commands/renderDocument.ts returns rendered HTML to command callers, not a user-facing portable document. MdDocumentRenderer.renderDocument in src/preview/documentRenderer.ts:72-128 constructs webview-specific HTML with rewritten resource URLs, scripts, styles and a webview base URI; saving that wrapper unchanged is not established browser-ready export.
