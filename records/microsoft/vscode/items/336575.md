## Summary

Reasonable, currently uncovered request: no built-in command exports the Markdown preview's HTML or opens it in an external browser. Too new (1 day old, 0 upvotes) to judge community traction, so it should stay open for discussion rather than be closed either way.

## Change summary

Add a way to export/save the rendered Markdown preview as an HTML file, or open it in the system's default browser.
