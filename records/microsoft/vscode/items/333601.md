# Issue #333601 — `chat.pasteAsAttachmentThreshold` is confusing with requiring some arbitrary number of lines

[https://github.com/microsoft/vscode/issues/333601](https://github.com/microsoft/vscode/issues/333601)

## Summary

Team-authored polish proposal from the setting's own area — the author (a VS Code team member) confirms the hidden 10-line minimum in code and proposes removing it to simplify the feature; kept open per the team-authored protection and because it needs a maintainer design decision, not a mechanical close.

## Change summary

The chat.pasteAsAttachmentThreshold setting only kicks in once a paste spans more than 10 lines, a hardcoded minimum not clearly documented in the setting description; the author suggests dropping the line-count gate entirely so the character threshold alone decides.

## Best solution

Decide whether to drop the `pastedTextArtifactMinLines = 10` gate in chatPasteProviders.ts (letting `minLength`/character count alone govern attachment conversion) or instead clarify the setting description to state the 10-line minimum explicitly; either is a small, self-contained change once the design call is made.
