# Issue #115136 — Tab wrap - implement different presentation so that tabs don't jump around (editor actions, decorations, dirty state)

[https://github.com/microsoft/vscode/issues/115136](https://github.com/microsoft/vscode/issues/115136)

## Summary

Keep open: existing settings mitigate wrapped-tab jumping, but do not deliver stable content-sized tabs across editor-action, decoration, and dirty-state changes. This older issue remains the broader tracking point; a pending PR addresses part of the remaining work.

## Change summary

Keep wrapped tabs and the editor's vertical position stable when editor actions, file decorations, or dirty indicators change.

## Best solution

Provide a stable wrapped-tab presentation without requiring users to truncate labels with fixed sizing or hide useful indicators. Review https://github.com/microsoft/vscode/pull/332012 for dirty-indicator stability, then assess the remaining decoration and editor-toolbar cases under this issue.
