# Issue #115136 — Tab wrap - implement different presentation so that tabs don't jump around (editor actions, decorations, dirty state)

[https://github.com/microsoft/vscode/issues/115136](https://github.com/microsoft/vscode/issues/115136)

## Summary

Keep this canonical wrapped-tab stability request open under discussion. Existing settings mitigate individual causes, but no single behavior prevents tabs from moving as actions, decorations, and dirty indicators change.

## Change summary

Keep wrapped tabs and the editor content position stable when editor actions, decorations, or dirty state change.

## Best solution

Design the wrapped-tab layout in the workbench tab controls to reserve or isolate dynamic UI space so routine state changes do not reflow tabs. Preserve the existing action-location and fixed-sizing settings as opt-in mitigations rather than treating them as complete coverage.
