# Issue #291721 — Goto symbol shows worktrees

[https://github.com/microsoft/vscode/issues/291721](https://github.com/microsoft/vscode/issues/291721)

## Summary

Keep open: a maintainer confirmed that background-session worktrees contaminate workspace-symbol results and endorsed read-only protection. Current source still exposes the relevant gaps; no concrete fix or verified duplicate was found.

## Change summary

Background-session worktree symbols appear in workspace navigation, allowing users to accidentally open and edit the wrong copy of a file.

## Best solution

Keep background-session worktrees from misleading normal workspace navigation and provide the read-only working-folder protection endorsed in the discussion. Preserve intentional navigation across user-opened projects and explicit worktree workflows.
