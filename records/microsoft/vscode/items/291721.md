# Issue #291721 — Goto symbol shows worktrees

[https://github.com/microsoft/vscode/issues/291721](https://github.com/microsoft/vscode/issues/291721)

## Summary

Still a valid open issue: background session worktrees leak into the main window's workspace symbol picker, causing confusion. No fixing commit references this issue, and the existing fix (f97c287567a) only covers remote agent-host sessions, not local worktrees.

## Change summary

Open Workspace Symbol picker includes symbols from local worktrees created by background sessions, tricking users into editing worktree files.

## Best solution

Either exclude worktree directories from the main window's file indexer/symbol search, or mark worktree folders as readonly via IFilesConfigurationService (as discussed in comments). The glob-based readonly session override bpasero suggested would prevent accidental edits even if symbols still appear.
