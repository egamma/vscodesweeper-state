# Issue #292598 — Code snippets in chat should have go to location

[https://github.com/microsoft/vscode/issues/292598](https://github.com/microsoft/vscode/issues/292598)

## Summary

Valid feature request from a team member: code blocks in chat responses lack a 'go to location' action to navigate to the corresponding source line. No implementation found on current main.

## Change summary

Code snippets shown in chat responses should offer a 'go to location' action to navigate to the referenced line in the source file.

## Best solution

Add a 'Go to Location' action to the `MenuId.ChatCodeBlock` menu (in `src/vs/workbench/contrib/chat/browser/actions/chatCodeblockActions.ts`) that resolves the code block's source location and opens the editor at that line. This requires the code block to carry provenance metadata (source file URI + line range) so the action knows where to navigate — likely needs plumbing through the chat response model in `codeBlockPart.ts`.
