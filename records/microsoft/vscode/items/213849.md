# Issue #213849 — Allow Developer to get command description from API

## Summary

Keep open in the Backlog: the request passed the community threshold with 22 upvotes, and current main still exposes only command identifiers through the public API.

## Change summary

Expose command descriptions programmatically to extension developers.

## Best solution
