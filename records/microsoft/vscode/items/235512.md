# Issue #235512 — Characters go into each other with fontLigatures and RTL characters.

[https://github.com/microsoft/vscode/issues/235512](https://github.com/microsoft/vscode/issues/235512)

## Summary

The overlapping glyphs were confirmed in late 2024, but current-main behavior remains uncertain after subsequent RTL-rendering changes. A current Insiders confirmation with font and environment details is needed before diagnosing this as an editor, browser, or Fira Code shaping defect.

## Change summary

Enabling editor ligatures with Fira Code causes the `===` ligature to overlap adjacent Arabic text in a mixed RTL/LTR line.

## Best solution

Ensure programming ligatures remain within their LTR text run and do not overlap an adjacent RTL run, while preserving normal Arabic shaping. First confirm the problem on current Insiders and compare another ligature font or browser rendering to establish whether the correction belongs in the editor renderer or an upstream dependency.
