# Issue #335657 — Copilot errors out when it is unable to access the web even with local model

[https://github.com/microsoft/vscode/issues/335657](https://github.com/microsoft/vscode/issues/335657)

## Summary

The external requests are intentional utility-model traffic, not telemetry: background flows default to GitHub Copilot even when the selected chat model is local. Existing settings, available before this report, support fully local utility routing.

## Change summary

Avoid contacting GitHub model endpoints when agent mode uses a locally hosted custom model and many MCP tools.

## Best solution

Keep the explicit utility-model policy and configure `chat.byokUtilityModelDefault` to `mainAgent`, or select local models in `chat.utilityModel` and `chat.utilitySmallModel`, for restricted-network operation.
