# Issue #288596 — Please have option to batch delete merge conflict

[https://github.com/microsoft/vscode/issues/288596](https://github.com/microsoft/vscode/issues/288596)

## Summary

The batch-resolution gap remains on current main: staging multiple deletion conflicts still opens one modal per file. The request is accepted in the Backlog and already routed to Git, so it should remain open.

## Change summary

Allow one keep-or-delete decision to be applied to all selected files with deletion conflicts.

## Best solution

Update the Git staging flow in `extensions/git/src/commands.ts` to offer an explicit apply-to-all choice for selected deletion conflicts while preserving per-file decisions when desired.
