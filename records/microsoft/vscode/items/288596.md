# Issue #288596 — Please have option to batch delete merge conflict

[https://github.com/microsoft/vscode/issues/288596](https://github.com/microsoft/vscode/issues/288596)

## Summary

The batch-choice capability remains missing: both selected-file staging and Stage All Merge Changes prompt separately for each deletion conflict. Keep this accepted Backlog request open; the verified related issues do not meet the canonical duplicate bar.

## Change summary

Allow a keep-or-delete choice in a deletion-conflict dialog to apply to the remaining files in the current operation.

## Best solution

Provide an explicit operation-scoped apply-to-all choice in the built-in Git deletion-conflict workflow, retaining per-file resolution by default. Define how that choice applies when the operation contains both deletion directions, without persisting it into later operations.
