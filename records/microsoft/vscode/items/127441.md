# Issue #127441 — Git - incorrectly highlight changed lines

[https://github.com/microsoft/vscode/issues/127441](https://github.com/microsoft/vscode/issues/127441)

## Summary

Keep this as the canonical report for false Git change highlights with working-tree-encoding. Current source still compares differently encoded content, and maintainers have directed newer reports back here.

## Change summary

Git gutter decorations incorrectly mark unchanged lines when Git stores UTF-8 blobs but checks files out using a different working-tree encoding.

## Best solution

Make Git-backed original content and the working-tree editor agree on decoded text, so clean files have no change decorations and actual edits produce accurate diffs. Preserve existing textconv behavior and ordinary non-UTF-8 repositories without working-tree-encoding.
