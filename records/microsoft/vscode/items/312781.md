# Issue #312781 — Model used doesn't show on hover in auto mode as it does for VS Code agent

[https://github.com/microsoft/vscode/issues/312781](https://github.com/microsoft/vscode/issues/312781)

## Summary

The gap persists on main: the VS Code agent surfaces 'Routed to X' via `ChatResponseAutoModeResolutionPart` (extension API), but the Copilot CLI agent host path (`stateToProgressAdapter`) does not emit the equivalent `autoModeResolution` progress part — it only shows the model name in the response footer. Team-authored issue stays open.

## Change summary

When using auto mode with Copilot CLI, the user has no way to see which model was routed to on hover, unlike the VS Code agent which shows a 'Routed to X' collapsible widget.

## Best solution

Extend the agent host's `stateToProgressAdapter` to emit an `autoModeResolution` progress part when the model router resolves for Copilot CLI sessions, mirroring the behavior the Copilot extension already provides for the VS Code agent. Recent work in `211b37346fa` (turn details) and `04b756ba9f0` (explainability UI) brought the pieces close — wiring them together in the agent-host path would close this gap.
