# Issue #294558 — Treat "Working Tree" as a selectable node for comparisons in Git Graph

[https://github.com/microsoft/vscode/issues/294558](https://github.com/microsoft/vscode/issues/294558)

## Summary

Keep open: the built-in graph still lacks a selectable working-tree comparison endpoint. The older revision-comparison request is related, but does not establish the same graph-specific interaction required for a duplicate close on this re-reviewed item.

## Change summary

Expose uncommitted working-tree changes as a selectable graph node for comparisons with historical commits or branches.

## Best solution

Support working-tree comparisons from the built-in Source Control Graph while preserving existing commit-to-commit comparisons. Coordinate the comparison semantics with https://github.com/microsoft/vscode/issues/200011, without losing this request's selectable-node workflow.
