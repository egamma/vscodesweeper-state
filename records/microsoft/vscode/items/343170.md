# Issue #343170 — Server for Docker Containers on Updates

[https://github.com/microsoft/vscode/issues/343170](https://github.com/microsoft/vscode/issues/343170)

## Summary

This requests smoother server provisioning after updates when using Dev Containers. Propose transferring the issue to microsoft/vscode-remote-release, the VS Code team's owning tracker, while keeping it open.

## Change summary

Avoid repeated manual server-component installation when reconnecting to Docker containers after VS Code updates.

## Best solution

Make Dev Containers reconnection handle any required server provisioning automatically, retaining reusable installation data where compatible. The owning team should distinguish normal installation of a matching server build from the reported need for manual reinstallation.
