# Issue #319584 — Incorrect indent line highlighted when selected line has children

[https://github.com/microsoft/vscode/issues/319584](https://github.com/microsoft/vscode/issues/319584)

## Summary

The different highlights follow an explicit, tested design: a line opening a child scope activates that child's indent guide rather than its own parent guide. Propose closing this report as designed, not as a fixed bug or duplicate.

## Change summary

Highlight the same parent indent guide for equally indented sibling lines, regardless of whether either line opens a child scope.

## Best solution

Retain the existing scope-based highlighting semantics. Explain that the active guide identifies a scope, not necessarily the selected line's indentation level.

- **Proposed comment:**

  > Thanks for the report. The active indent guide highlights a scope rather than always matching the selected line's indentation. When a line opens a child scope, that child's guide is intentionally highlighted; a sibling without children can therefore highlight a different guide. This design is also explained in https://github.com/microsoft/vscode/issues/108848#issuecomment-712683607.
  > 
  > You can disable active highlighting with `"editor.guides.highlightActiveIndentation": false` while retaining ordinary indent guides. That does not change scope selection, but removes the differing highlights. Closing this report as designed.
