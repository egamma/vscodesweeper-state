# Issue #342643 — Allow sandboxed Agent Host processes to communicate with an extension-owned process over restricted IPC

[https://github.com/microsoft/vscode/issues/342643](https://github.com/microsoft/vscode/issues/342643)

## Summary

Keep open for human design review: the inspected MCP configuration and extension API do not expose the requested endpoint-scoped IPC capability. This changes a sandbox trust boundary, so it should not be closed or treated as an agent-ready implementation.

## Change summary

Allow a sandboxed execution MCP server to exchange requests with an explicitly authorized extension-owned process without granting general network or process access.

## Best solution

Define a security-reviewed capability contract for accessing a specific extension-owned endpoint while preserving sandbox restrictions. Establish endpoint identity, authorization, lifecycle, and the supported process topology before selecting a transport.
