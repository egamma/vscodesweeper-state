## Summary

Keep open: the initial Ctrl+wheel font-size jump remains supported by current source and the reporter's post-fix reproduction. The merged bounds-checking PR limits font sizes but does not correct first-event classification or zoom increments.

## Change summary

The first Ctrl+mouse-wheel operation after opening the terminal changes font size by a large amount instead of one step.

## Best solution

Make physical-wheel terminal zoom consistently change font size by one step from the first event, without depending on previous scrolling. Preserve the existing font-size bounds, trackpad gestures, and ordinary terminal scrolling.
