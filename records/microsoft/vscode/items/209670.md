# Issue #209670 — Terminal is zoomed in and out to be very large or small with the mouse wheel while holding Ctrl

[https://github.com/microsoft/vscode/issues/209670](https://github.com/microsoft/vscode/issues/209670)

## Summary

Still reproduces on main: the first Ctrl+scroll zoom in the terminal produces a large font size jump because MouseWheelClassifier returns false (no data) on the first wheel events, sending physical mouse wheel events through the gesture/trackpad code path where large deltaY values cause disproportionate font changes.

## Change summary

Terminal font size jumps dramatically on the first Ctrl+mouse wheel zoom after opening VS Code, then works normally on subsequent zoom steps.

## Best solution

Guard the initial classification state in TerminalMouseWheelZoomContribution — when the MouseWheelClassifier has no data, either default to the physical-mouse-wheel path (delta ±1) or feed the classifier before branching. The fix is localized to `src/vs/workbench/contrib/terminalContrib/zoom/browser/terminal.zoom.contribution.ts`. Note that the related bounds-checking fix (PR #253010) only clamped min/max — the initial-jump root cause (misclassification) remains.
