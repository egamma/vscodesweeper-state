# Issue #332542 — Copilot chat text input - paste as markdown from m365 copilot includes css style

[https://github.com/microsoft/vscode/issues/332542](https://github.com/microsoft/vscode/issues/332542)

## Summary

Traced conclusively on main: the DOM-based HTML→Markdown converter used by chat's "paste as markdown" has no case for `<style>` (or `<script>`), so its `default` branch falls through to `convertChildren(el)` and renders the raw CSS/JS text as if it were normal document content — exactly matching the reported stray CSS block.

## Change summary

Pasting rich text (e.g. from M365 Copilot) into Copilot Chat as markdown prepends the source page's CSS `<style>` block content as plain text.

## Best solution

Add `style`/`script`/`head`/`noscript` cases to the switch in src/vs/base/browser/htmlToMarkdown.ts's `convertNode` that return `''` instead of falling through to the default `convertChildren` handling.
