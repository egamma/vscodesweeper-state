# Issue #99121 — Custom menus should absorb keystrokes and dismiss if not mnemonic (letter)

[https://github.com/microsoft/vscode/issues/99121](https://github.com/microsoft/vscode/issues/99121)

## Summary

The accepted menu bug remains source-reproducible on current main: F10 is unhandled by the custom menu and reaches the global keybinding service without dismissing the menu. This team-authored, On Deck issue should remain open.

## Change summary

Custom context menus should consume mnemonic letter keys and dismiss when another key, such as F10, invokes a global command.

## Best solution

Make custom context-menu keyboard behavior match the native-menu behavior agreed in the thread: retain mnemonic handling for letter keys, but dismiss the menu when an otherwise unhandled key such as F10 reaches the global keybinding path.
