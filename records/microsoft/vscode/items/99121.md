# Issue #99121 — Custom menus should absorb keystrokes and dismiss if not mnemonic (letter)

[https://github.com/microsoft/vscode/issues/99121](https://github.com/microsoft/vscode/issues/99121)

## Summary

Still reproduces on main: the context menu handler's block div only intercepts MOUSE_DOWN events, not keyboard events — global keybindings still fire while custom menus are open, and non-mnemonic keys don't dismiss the menu.

## Change summary

Custom context menus don't absorb non-mnemonic keystrokes and don't dismiss on unrecognized key presses, unlike native menus.

## Best solution

Add a keydown listener on the block element (or the context view container) in `src/vs/platform/contextview/browser/contextMenuHandler.ts` that absorbs non-mnemonic keystrokes and dismisses the menu on function keys / unrecognized keys, matching native menu behavior.
