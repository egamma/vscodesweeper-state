# Issue #336428 — Agent host: review confirmation cannot load comments in editor windows

[https://github.com/microsoft/vscode/issues/336428](https://github.com/microsoft/vscode/issues/336428)

## Summary

Traced on main: the `_agentFeedbackReview.*` commands (chatService.ts) are only registered by src/vs/sessions/contrib/agentFeedback/browser/agentFeedback.contribution.ts, which loads for the dedicated Agents window but not regular editor windows, so the renderer's missing-command error is swallowed as an empty-comments state. An open PR (#336430) already targets this exact fix, so this should stay open pending that PR's review/merge rather than being auto-fixed or closed.

## Change summary

In a regular editor-window agent-host chat, the review-confirmation UI silently shows 'no unreviewed comments' instead of loading them, because the required `_agentFeedbackReview.*` commands aren't registered outside the Agents window.

## Best solution

Review and land PR https://github.com/microsoft/vscode/pull/336430, which registers editor-window-safe command handlers for `_agentFeedbackReview.getComments`/reveal/delete/accept without pulling `vs/sessions` into the workbench, and distinguishes load failures from a genuine empty state.
