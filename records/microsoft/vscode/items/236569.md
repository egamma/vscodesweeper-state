# Issue #236569 — Remove the extra steps when installing updates to VS Code

[https://github.com/microsoft/vscode/issues/236569](https://github.com/microsoft/vscode/issues/236569)

## Summary

The extra update step for system installs is by design (UAC elevation required), but recent work has been improving the Windows update UX. This is a valid polish request to streamline the system-installer update flow — keeping open as it aligns with ongoing update improvements.

## Change summary

Windows system installer update flow requires an extra click cycle (cog → Update Now) after the initial Install Update + UAC prompt.

## Best solution

Extend the background-update logic in `updateService.win32.ts` so that system installs automatically transition from Downloaded → Updating → Ready without requiring the user to re-click, leveraging the already-elevated session or the RunAsInvoker trick. The `d32a089dfb7` commit (UAC-disabled path) is a partial step; the general case still parks at `State.Ready` after download.
