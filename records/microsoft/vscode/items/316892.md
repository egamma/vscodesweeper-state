# Issue #316892 — Allow extensions to use any theme background in the Status Bar

[https://github.com/microsoft/vscode/issues/316892](https://github.com/microsoft/vscode/issues/316892)

## Summary

This reopens the same status bar background-color API request that was previously closed as not planned/out-of-scope; the added opt-in setting does not change the underlying product boundary enough to keep a fresh issue open.

## Change summary

Allow extensions to set arbitrary or theme-derived StatusBarItem background colors, optionally gated by a user setting.

## Best solution

Keep the current restricted API: extension status bar item backgrounds remain limited to the warning/error affordances, and broader visual emphasis/custom coloring should not be added as a core extension API setting.

## Vision fit

- **Fit:** rejected
- **Reason:** The request adds a one-off customization path for a core UI surface where the project values simple, uniform UI and avoids configuration sprawl in the default product.
- **Evidence:** Values & guardrails: "Simple, uniform UI and UI interactions" and the lean default experience guardrail against niche UI/configuration expansion.

- **Proposed comment:**

  > Thanks for reopening the discussion. This is still covered by the previous product decision in https://github.com/microsoft/vscode/issues/140437: extension-provided status bar item backgrounds are intentionally limited to the warning/error affordances to preserve a consistent status bar surface. An opt-in setting would still add a new customization policy for this core UI area, so I think this should be closed with the same out-of-scope resolution.
