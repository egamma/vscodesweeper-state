# Issue #319411 — Browser suggestions panel: don't show it if empty on New Tab

[https://github.com/microsoft/vscode/issues/319411](https://github.com/microsoft/vscode/issues/319411)

## Summary

Valid polish item: the URL bar picker opens and shows an empty suggestion list on New Tab because _buildSuggestionItems returns nothing for an empty input and no providers have async results yet. No fix on main. Team-authored, keeping open.

## Change summary

The integrated browser's URL bar shows an empty suggestions panel when focused on a New Tab page, unlike native browsers which suppress it.

## Best solution

In _openPicker (browserUrlBarWidget.ts), either defer picker.show() until items are non-empty, or hide/suppress the picker when both _buildSuggestionItems and all provider results are empty. The render() function around line 565 is the natural place to add an emptiness check that hides the picker when items.length === 0.
