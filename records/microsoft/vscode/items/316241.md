# Issue #316241 — Copilot CLI agent panel: "Files" tab should show full workspace file tree, not only git-changed files

[https://github.com/microsoft/vscode/issues/316241](https://github.com/microsoft/vscode/issues/316241)

## Summary

Current main already has a full Explorer-backed Files view, but that does not establish coverage of the requested multi-root worktree workflow. Keep this open while separating file-tree discoverability from the remaining workspace-root selection and mounting limitations.

## Change summary

Provide a full, git-decorated workspace file browser in the Copilot CLI agent surface, including clean files across workspace roots.

## Best solution

Use the existing Explorer-backed Files surface rather than introduce another git-status tree. Establish that every intended workspace root is available for human browsing, including an explicitly included main checkout alongside a session worktree, while keeping Changes focused on diffs.
