# Issue #18666 — Multiple decorations on end of line

[https://github.com/microsoft/vscode/issues/18666](https://github.com/microsoft/vscode/issues/18666)

## Summary

The central request is implemented: multiple independently styled end-of-line decorations now render separately rather than sharing one CSS pseudo-element. A concrete 2021 fix and the current renderer support closing this as completed.

## Change summary

Support multiple end-of-line decorations so inline names and values can have different styling.

## Best solution

Use separate decoration types with independently styled `after.contentText` attachments at the same end-of-line position. Preserve the implementation in commit 2d80cb75c4b14e85e17e25b1b2355305f08e9074; general overlapping-highlight behavior is a separate concern.
