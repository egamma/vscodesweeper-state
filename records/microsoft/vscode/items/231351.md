# Issue #231351 — Configurable fast scroll to keys other than Alt

[https://github.com/microsoft/vscode/issues/231351](https://github.com/microsoft/vscode/issues/231351)

## Summary

Valid feature request — the fast scroll modifier is still hardcoded to Alt on current main. No existing setting covers configuring the modifier key. With 7 upvotes and milestoned to Backlog, this should stay open for the community process.

## Change summary

Allow configuring the fast scroll modifier key (currently hardcoded to Alt) to other keys like Ctrl or Shift.

## Best solution

Add an `editor.fastScrollModifier` setting (similar to `editor.multiCursorModifier`) accepting values like `alt`, `ctrl`, `shift`, or `none`, and use it in `scrollableElement.ts` line 473 instead of the hardcoded `altKey` check. The change is localized to the scrollbar element options and the editor configuration.
