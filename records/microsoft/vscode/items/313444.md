# Issue #313444 — Improve Quick Access Search Bar UI/UX

[https://github.com/microsoft/vscode/issues/313444](https://github.com/microsoft/vscode/issues/313444)

## Summary

The experimental unified Quick Access still opens Sessions first; file-search commands provide alternatives but do not satisfy the requested click behavior or Files → Sessions → Commands ordering. Keep this open for a default-mode design decision; the related configurable-default request is newer and cannot absorb this re-reviewed item.

## Change summary

Make Files the initial search context in unified Quick Access, with Sessions and Commands following in that order.

## Best solution

Decide whether the experimental unified search should adopt a file-first default or expose a preferred starting mode, considering the related request at https://github.com/microsoft/vscode/issues/321081. Preserve explicit session and command entry points and ordinary Go to File behavior.
