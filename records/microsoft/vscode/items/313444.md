# Issue #313444 — Improve Quick Access Search Bar UI/UX

[https://github.com/microsoft/vscode/issues/313444](https://github.com/microsoft/vscode/issues/313444)

## Summary

The reporter asks for the experimental Unified Quick Access widget (gated behind `chat.unifiedAgentsBar.enabled`) to default to the Files tab instead of Sessions. The tab order is a deliberate design choice for the agent-focused experience; the feature is still experimental. Worth keeping open for UX feedback but needs team input on the intended default.

## Change summary

Change the default tab in the Unified Quick Access widget from Sessions to Files.

## Best solution

Route to the Agents window / chat team for a design decision on the default tab order in `DEFAULT_UNIFIED_QUICK_ACCESS_TABS` (defined in `src/vs/workbench/contrib/chat/browser/agentSessions/experiments/unifiedQuickAccess.ts`). Since this is an experimental feature actively being shaped, the team should decide whether Files-first or Sessions-first better serves the target workflow.
