# Issue #275761 — [Features]: Increase size of error indicator into vertical scrollbar

[https://github.com/microsoft/vscode/issues/275761](https://github.com/microsoft/vscode/issues/275761)

## Summary

Keep this accepted feature request open: current source still restricts diagnostic indicators to one overview-ruler lane, and the existing scrollbar-width setting does not satisfy the request. It reached 20 upvotes and was promoted to Backlog; no verified canonical owns the same work.

## Change summary

Allow wider error indicators in the editor overview ruler without increasing the vertical scrollbar width.

## Best solution

Provide a supported way to make diagnostic indicators more visible with a narrow scrollbar while preserving navigation and other decorations. The editor-core owner should decide whether this controls diagnostic width specifically or exposes a shared overview-ruler lane mode.
