# Issue #336767 — Copilot Chat agent mode: no identical-tool-call repetition detection; "Continue to iterate?" auto-extends budget so loops run 12-18+ rounds unattended

[https://github.com/microsoft/vscode/issues/336767](https://github.com/microsoft/vscode/issues/336767)

## Summary

Well-documented gap: the agent tool-calling loop in extensions/copilot has no consecutive-identical-tool-call detection, and in autopilot mode the round budget is silently raised (up to 200) rather than surfacing a warning — this is a real missing safeguard, not a bug in existing logic, and needs a design decision on thresholds/UX before implementation.

## Change summary

Add harness-level detection of repeated identical tool calls (refuse + warn) and stop silently auto-extending the agent round budget when the spent budget was a repetition loop.

## Best solution

Add a bounded consecutive-identical-tool-call guard to ToolCallingLoop (extensions/copilot/src/extension/intents/node/toolCallingLoop.ts) that surfaces a visible warning/blocks re-execution after N repeats, and gate the autopilot silent budget increase (line ~1450) so it doesn't fire when recent rounds are pure repetition.
