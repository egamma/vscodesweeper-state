# Issue #205915 — [SUGGESTION] Test Explorer is able to be grouped

[https://github.com/microsoft/vscode/issues/205915](https://github.com/microsoft/vscode/issues/205915)

## Summary

Keep this accepted, community-supported request open: current Test Explorer supports tag filtering, but still lacks tag/category grouping. The existing testing label is appropriate, and no verified canonical issue was found.

## Change summary

Allow Test Explorer to display tests beneath tag/category groups, including MSTest TestCategory values exposed by a test provider.

## Best solution

Provide an optional tag-grouped Test Explorer presentation using provider-supplied test tags, without changing the existing tree/list defaults. Settle how multi-tagged and untagged tests appear before implementation.

- **Trace:**

  > The request and maintainer response are recorded at https://github.com/microsoft/vscode/issues/205915. TestingExplorerViewModel.updatePreferredProjection in src/vs/workbench/contrib/testing/browser/testingExplorerView.ts selects only ListProjection or TreeProjection, while TestsFilter.testTags uses existing tag metadata only for filtering. View-mode and sorting contracts live in common/constants.ts, and the corresponding user actions are in browser/testExplorerActions.ts. ITestTreeProjection and TestItemTreeElement in browser/explorerProjections/index.ts assume parent-linked elements and a single lookup result per test ID, so multi-group membership needs an explicit observable contract. Preserve provider-owned discovery hierarchy, test identity, execution semantics, and current view defaults; the uncertainty starts with how a grouped presentation represents multiple memberships and tests without tags.
- **Open decisions:**
  - Should a test with multiple tags appear under every matching category, or in one combined grouping, and what should reveal/select do when it has multiple visible occurrences?
  - Should tests without tags appear in a dedicated untagged group or retain their existing hierarchy within the grouped presentation?
