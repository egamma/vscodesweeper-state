# Issue #252001 — Allow tasks to be run via terminal suggest

[https://github.com/microsoft/vscode/issues/252001](https://github.com/microsoft/vscode/issues/252001)

## Summary

Keep open: terminal suggest still accepts shell text rather than running VS Code tasks, and the linked implementation PR was closed without merging. The existing task command does not cover discovery and execution directly from terminal suggestions.

## Change summary

Expose existing VS Code tasks in terminal suggestions and allow selecting a suggestion to execute the corresponding task.

## Best solution

Integrate task discovery and task execution into terminal suggest while preserving normal shell completions and task-service execution semantics. Settle task matching and ranking before implementation, using the closed PR as prior work rather than evidence of a shipped feature.
