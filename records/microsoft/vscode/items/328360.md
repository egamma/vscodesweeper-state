# Issue #328360 — Agent: act on feedback processes all comments

[https://github.com/microsoft/vscode/issues/328360](https://github.com/microsoft/vscode/issues/328360)

## Summary

Current main can reprocess resolved feedback: the tool returns resolved comments and the skill instructs the agent to act on every listed comment when no comments are attached. Route this confirmed bug to the Agents window area.

## Change summary

Running `/act-on-feedback` manually processes resolved feedback comments instead of only unresolved comments.

## Best solution

Make the act-on-feedback workflow select only unresolved comments when no explicit comment IDs are attached, while preserving the ability to inspect or reopen resolved comments through the underlying tools.
