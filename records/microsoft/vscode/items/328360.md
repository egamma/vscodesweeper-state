# Issue #328360 — Agent: act on feedback processes all comments

[https://github.com/microsoft/vscode/issues/328360](https://github.com/microsoft/vscode/issues/328360)

## Summary

Traced on current main: `listComments` (used by the `/act-on-feedback` skill) includes already-resolved comments, not just open ones, so the agent can reprocess feedback that was already handled — a real, still-present issue. A maintainer has already acknowledged it and is investigating, so it should stay open for that fix.

## Change summary

The `/act-on-feedback` skill's `listComments` server tool returns resolved comments alongside open ones, causing the agent to reprocess already-resolved feedback and waste tokens.

## Best solution

In `src/vs/platform/agentHost/node/shared/agentFeedbackServerTools.ts`, `listableAnnotations()` treats an annotation as listable whenever `effectiveState !== 'created'`, which admits `resolved` annotations too; the fix likely needs `listComments` (or the `act-on-feedback` skill's consumption of it) to exclude already-resolved comments so the agent only acts on open feedback. Left to benibenj, who is already looking into the right approach.
