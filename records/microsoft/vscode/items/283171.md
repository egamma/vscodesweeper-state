# Issue #283171 — Agent mode with existing files

[https://github.com/microsoft/vscode/issues/283171](https://github.com/microsoft/vscode/issues/283171)

## Summary

Keep open: the project-creation tool still rejects folders containing existing project files, matching the limitation shown in the screenshot. Existing settings do not provide reference-aware scaffolding in a populated workspace, and no qualifying older canonical was verified.

## Change summary

Allow Agent project creation to use an existing project's files and instructions without requiring an empty workspace.

## Best solution

Support reference-aware project scaffolding in the Copilot new-workspace flow while preserving existing files and instructions. The product contract should distinguish reference content from generation destinations and make replacement of existing content explicit.
