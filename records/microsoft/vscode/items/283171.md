# Issue #283171 — Agent mode with existing files

[https://github.com/microsoft/vscode/issues/283171](https://github.com/microsoft/vscode/issues/283171)

## Summary

Keep this accepted Backlog request open: the dedicated agent workspace-creation tool still rejects folders containing an existing project. Current support for dotfile-only folders does not cover the requested workflow.

## Change summary

Allow agent-mode project creation to use instructions and an existing project without requiring an empty workspace.

## Best solution

Extend the Copilot project-creation workflow to support existing-project reference material while preserving existing files. The product design should distinguish the source project from the generation destination and define how conflicting files are handled.
