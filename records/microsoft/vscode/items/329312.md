# Issue #329312 — Copilot config/chat view crashes when multiple VS Code windows are open (TypeError: e is not iterable)

[https://github.com/microsoft/vscode/issues/329312](https://github.com/microsoft/vscode/issues/329312)

## Summary

The reporter's own root-cause trace (comment 1/2) matches a real defect that has since been fixed on main: PR #329697 (commit 78a7b6c291b, merged the day after this issue was filed) removed the entire extension-host Claude implementation — including the exact `ClaudeSessionUri` scheme and the unconditional `createChatParticipant` call the reporter identified — making Agent Host the sole Claude sessions implementation, so the crash path no longer exists.

## Change summary

Copilot's built-in Claude Code chat participant crashed/hung the extension host (TypeError: e is not iterable) once Agent Host defaults (chat.agentHost.enabled / preferAgentHost) made the extension-host chatSessions `when` clause evaluate false while the code still unconditionally registered the participant.

## Best solution

Treat as fixed by commit 78a7b6c291b ("agentHost: remove extension-host Claude implementation", PR #329697): the obsolete extension-host Claude runtime, its `ClaudeSessionUri`-based participant registration, and the conflicting provider-preference settings are gone from main, closing the exact crash chain the reporter traced.
