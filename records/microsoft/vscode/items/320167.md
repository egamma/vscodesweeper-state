## Summary

Still reproduces on main: `claudeConfigToServerDefinition` evaluates `cwd?.fsPath` on the Windows client side, producing backslash paths sent to Linux remotes. Open PR #322874 addresses it but has not merged.

## Change summary

MCP servers defined in `.mcp.json` fail with ENOENT on Windows-to-Linux Remote-SSH because the cwd path is converted with Windows separators before being sent to the remote.

## Best solution

Land the open PR https://github.com/microsoft/vscode/pull/322874 (or an equivalent fix) that defers the `fsPath` evaluation to the remote extension host side, matching how `.vscode/mcp.json` already handles it correctly.
