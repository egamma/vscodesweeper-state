# Issue #342919 — Outline view for Markdown Preview

[https://github.com/microsoft/vscode/issues/342919](https://github.com/microsoft/vscode/issues/342919)

## Summary

Keep open as a feature request: current source supports Outline navigation for the Markdown Editor but does not provide equivalent integration for Markdown Preview. The closed related requests do not establish an open canonical or a fix for the preview surface.

## Change summary

Display a navigable heading outline while Markdown Preview is the active editor, without requiring a switch to the source or Markdown Editor.
