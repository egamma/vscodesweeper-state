# Issue #157030 — Update codicon names to use aliases

[https://github.com/microsoft/vscode/issues/157030](https://github.com/microsoft/vscode/issues/157030)

## Summary

Keep open as icon-system debt: current main has partially moved derived/component aliases out of the generated library, but the generated codicon library still registers duplicate codepoints directly, including the reporter's `person-*` examples.

## Change summary

Make duplicate codicon names consistently reference a source icon definition/alias instead of repeating the same font character.

## Best solution

Finish the alias cleanup at the codicon generation/mapping boundary so generated library entries or derived mappings express aliases consistently without breaking existing icon IDs.
