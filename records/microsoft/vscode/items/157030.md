# Issue #157030 — Update codicon names to use aliases

[https://github.com/microsoft/vscode/issues/157030](https://github.com/microsoft/vscode/issues/157030)

## Summary

The accepted cleanup remains relevant: current generated codicon registrations still repeat character values rather than referencing a source icon. Keep this open; a durable change needs coordination with the upstream generator rather than a hand-edit of generated output.

## Change summary

Represent codicon names sharing a glyph consistently as aliases while preserving existing public names and rendering.

## Best solution

Make alias representation consistent in the authoritative codicon generation pipeline and regenerate VS Code's library without changing existing icon identifiers or glyph mappings. Treat removal of component-specific aliases as separate compatibility work, not a prerequisite for this cleanup.
