# Issue #189162 — When a document contains many invisible characters, it is unclear what to do to fix that

[https://github.com/microsoft/vscode/issues/189162](https://github.com/microsoft/vscode/issues/189162)

## Summary

Thanks for the suggestion. Current main still shows only the 'many invisible characters' banner with a disable action, so the proposed highlight-all button is not implemented. The issue is team-authored and sits in Backlog, so it stays open.

## Change summary

Add a button to the 'many invisible unicode characters' banner that highlights all occurrences.

## Best solution

Add a second banner action in the unicode highlighter that forces highlighting of all matches, bypassing the 'hasMore' cutoff for the current document. Alternatively, make that cutoff configurable.
