# Issue #189162 — When a document contains many invisible characters, it is unclear what to do to fix that

[https://github.com/microsoft/vscode/issues/189162](https://github.com/microsoft/vscode/issues/189162)

## Summary

Valid unimplemented feature request from a team member. The banner for documents with many invisible characters currently only offers a disable action; a 'highlight all' button has not been added. Keeping open in the Backlog.

## Change summary

Add a button in the unicode-highlighting banner to highlight all invisible character occurrences, even when the count exceeds the threshold that suppresses decorations.

## Best solution

Add a second action to the banner in `src/vs/editor/contrib/unicodeHighlighter/browser/unicodeHighlighter.ts` (around line 120) that re-runs highlighting without the `hasMore` cap, applying decorations to all invisible characters. This would require the highlighter to support an 'uncapped' mode or a second compute pass that returns all ranges.
