# Issue #185112 — Column Select / Multiple Cursors: Ability to not have cursor inserted in wrapped part of wrapped text, without need to disable line wrap

[https://github.com/microsoft/vscode/issues/185112](https://github.com/microsoft/vscode/issues/185112)

## Summary

The bug remains on current main: mouse-driven column selection traverses visual view lines, so wrapped continuations receive cursors even though the equivalent keyboard commands default to logical lines. The older report should remain open as the canonical issue for this behavior.

## Change summary

Make mouse-based column selection and multi-cursor gestures avoid inserting cursors into wrapped continuations without requiring word wrap to be disabled.

## Best solution

Mouse column selection should traverse logical model lines by default, matching Add Cursor Above/Below, while preserving word wrap and existing behavior for unwrapped lines.

## Evidence

- **current source path:** In src/vs/editor/browser/view/viewController.ts, ViewController._columnSelect forwards mouse view positions to CoreNavigationCommands.ColumnSelect. In src/vs/editor/browser/coreCommands.ts, that command passes the view-line endpoints to ColumnSelection.columnSelect.
- **root cause:** src/vs/editor/common/cursor/cursorColumnSelection.ts loops from fromLineNumber through toLineNumber on the supplied ICursorSimpleModel; because the command supplies the view model, every wrapped continuation is treated as another selectable line and produces a cursor.
- **keyboard precedent:** https://github.com/microsoft/vscode/commit/c0d32634fb0cbf18ec82d6167ab2accc0c9f17f5 fixed https://github.com/microsoft/vscode/issues/26393 by making Add Cursor Above/Below use logical lines by default, but it did not change the mouse column-selection path.
- **corroborating report:** https://github.com/microsoft/vscode/issues/198399 is a newer open report with explicit steps showing the same mouse/view-line behavior. It is not a better canonical than this older issue and identifies this issue as similar.
- **no current fix:** Current main still routes mouse column selection through view-line coordinates, and history searches for issues 185112 and 198399 found no fixing commit.
