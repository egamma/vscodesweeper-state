# Issue #185112 — Column Select / Multiple Cursors: Ability to not have cursor inserted in wrapped part of wrapped text, without need to disable line wrap

[https://github.com/microsoft/vscode/issues/185112](https://github.com/microsoft/vscode/issues/185112)

## Summary

The requested model-line mouse selection mode remains absent by design. Maintainer guidance confirms that mouse multicursor placement uses exact visual positions, while the equivalent model-based box-selection request was previously declined as out of scope.

## Change summary

Provide a mouse-based column-selection or multicursor mode that skips wrapped segments without disabling word wrap.

## Best solution

Retain visual-line semantics for mouse placement and box selection; users needing logical-line cursor insertion should use Add Cursor Above/Below, whose default was changed to logical lines by commit c0d32634fb0cbf18ec82d6167ab2accc0c9f17f5.

## Vision fit

- **Fit:** rejected
- **Reason:** Adding a specialized alternative mouse-selection mode would complicate otherwise uniform selection interactions for a niche workflow.
- **Evidence:** Value and guardrail: "Simple, uniform UI and UI interactions" and avoiding configuration sprawl in the default product.
