# Issue #185112 — Column Select / Multiple Cursors: Ability to not have cursor inserted in wrapped part of wrapped text, without need to disable line wrap

[https://github.com/microsoft/vscode/issues/185112](https://github.com/microsoft/vscode/issues/185112)

## Summary

Still reproduces on main: mouse-based column selection and Alt+Click multi-cursor place cursors on wrapped (virtual) lines. The 2021 keyboard fix (PR #135805 for InsertCursorAbove/Below) was never extended to the mouse interaction paths in viewController.ts.

## Change summary

Column select and multi-cursor modifier via mouse insert cursors on wrapped virtual lines, unlike the keyboard shortcuts which correctly skip them.

## Best solution

Extend the logic from the keyboard-based InsertCursorAbove/Below fix (PR #135805, which maps view lines to model lines) to the mouse-driven column selection path in `src/vs/editor/browser/view/viewController.ts` (`_columnSelect` and the mouse click handler that creates cursors via Alt+Click). Issue https://github.com/microsoft/vscode/issues/198399 is a duplicate and should be consolidated here.
