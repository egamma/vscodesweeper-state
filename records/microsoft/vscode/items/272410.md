# Issue #272410 — Exception Breakpoints don't honor BreakpointMode

[https://github.com/microsoft/vscode/issues/272410](https://github.com/microsoft/vscode/issues/272410)

## Summary

The exception-breakpoint mode selected in the UI is still discarded when constructing the debug-adapter request on current main. Keep this open: the source confirms a bounded VS Code defect, and the related reports concern different behavior.

## Change summary

Honor the selected exception-breakpoint mode in outgoing setExceptionBreakpoints requests.

## Best solution

Ensure DebugSession.sendExceptionBreakpoints transmits the selected exception mode through the existing DAP contract, preserving conditions and compatibility with adapters that do not support exception filter options.
