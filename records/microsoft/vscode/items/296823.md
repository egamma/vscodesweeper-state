# Issue #296823 — Copilot chat window not accessible any more because of `Unknown event type: "session.mode_changed"`

[https://github.com/microsoft/vscode/issues/296823](https://github.com/microsoft/vscode/issues/296823)

## Summary

Fixed on main: commit 6b8d0f84c17 added graceful handling for unknown event types in session files, falling back to partial session history instead of failing. Shipped in 1.116.0; the reporter was on 1.109.5.

## Change summary

Opening a chat session with a `session.mode_changed` event in its history file fails with a corrupted-session error, making the Copilot chat window unusable.

## Best solution

Keep the shipped fix in commit 6b8d0f84c17 (1.116.0). The `isUnknownEventTypeError` guard in `getSessionHistory` now catches unknown event types and falls back to `tryGetPartialSessionHistory`, so sessions with unrecognized events load partially rather than failing. No further change needed.
