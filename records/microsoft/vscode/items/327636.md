# Issue #327636 — Keyboard shortcut for GitHub Copilot thinking effort in Configure Model

[https://github.com/microsoft/vscode/issues/327636](https://github.com/microsoft/vscode/issues/327636)

## Summary

Thanks for the request. The model picker already has a keyboard command, but current main exposes no direct commands for changing Thinking Effort, so the central accessibility and keyboard-efficiency gap remains.

## Change summary

Add bindable commands that increase or decrease the active Copilot chat model's Thinking Effort.

## Best solution

Add commands that traverse the active model's supported reasoning-effort values and update the active editor's model configuration, preserving its per-editor scope. The separate keyboard-navigation problems in Configure Model should remain eligible for their own accessibility fix.
