# Issue #251364 — Chinese path encoding issue

[https://github.com/microsoft/vscode/issues/251364](https://github.com/microsoft/vscode/issues/251364)

## Summary

This is a version-specific Remote - SSH regression involving Windows paths with Chinese characters. Remote - SSH is maintained by the VS Code team but tracked in microsoft/vscode-remote-release, so the issue should be transferred rather than closed.

## Change summary

Remote - SSH 0.120.0 cannot read its configuration or other paths containing Chinese characters on Windows, while rolling back restores the behavior.

## Best solution

Remote - SSH should consistently decode and access Unicode configuration paths on Windows; investigate the regression between 0.120.0 and the reporter's previously working version in the Remote Development tracker.
