# Issue #297622 — Allow agent/chat to access images in the terminal

[https://github.com/microsoft/vscode/issues/297622](https://github.com/microsoft/vscode/issues/297622)

## Summary

Team-authored feature request that remains unimplemented. Current main only extracts images from terminal output by scanning for file paths; inline terminal images rendered via xterm.js protocols (sixel, iTerm) are not yet accessible to the chat/agent.

## Change summary

Allow the chat/agent to access inline images rendered in the terminal via xterm.js image protocols, not just image file paths found in text output.

## Best solution

Extend the run-in-terminal tool's output extraction (in `src/vs/workbench/contrib/terminalContrib/chatAgentTools/browser/tools/runInTerminalTool.ts`) to also pull inline images from the xterm.js ImageAddon buffer — likely via a new API on `XtermTerminal` or the ImageAddon — and include them as data content parts alongside the existing file-path-based image extraction.
