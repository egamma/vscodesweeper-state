# Issue #49925 — Add commands to outline elements

[https://github.com/microsoft/vscode/issues/49925](https://github.com/microsoft/vscode/issues/49925)

## Summary

This remains the canonical, well-supported request for commands and extension-contributed actions on Outline elements. Current source still lacks an element context menu, and the Backlog item has 94 community upvotes.

## Change summary

Add Outline-element commands such as rename and find references, plus a contribution point for language-specific actions.

## Best solution

Add an Outline element context menu in `OutlinePane`, with built-in symbol commands and a public menu contribution point that supplies the selected document symbol's resource and position to contributed commands.

- **Reason:** Exposing Outline actions improves the developer inner loop while enabling language extensions to provide specialized behavior without expanding core for every language.
