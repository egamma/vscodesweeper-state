# Issue #75615 — Menu widget rendered in greyscale

[https://github.com/microsoft/vscode/issues/75615](https://github.com/microsoft/vscode/issues/75615)

## Summary

This Chromium subpixel-rendering inconsistency is no longer reproducible on current VS Code: since Chrome 98 (early 2022), Chromium on Windows defaults to grayscale antialiasing everywhere, eliminating the grey-vs-RGB inconsistency caused by layer compositing. VS Code now ships Electron 42 (Chromium 132+), so the specific rendering discrepancy reported here cannot occur.

## Change summary

Menu widgets and other UI elements rendered with inconsistent subpixel antialiasing (greyscale vs RGB) depending on layer compositing state.

## Best solution

Close as not reproducible — the underlying Chromium behavior that caused the inconsistency (subpixel AA enabled on some layers, disabled on others) no longer exists since Chrome disabled subpixel text rendering by default on Windows in Chrome 98.
