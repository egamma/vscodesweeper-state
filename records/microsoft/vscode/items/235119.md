# Issue #235119 — Selection Highlighting in notebooks doesn't work after a few scroll passes

[https://github.com/microsoft/vscode/issues/235119](https://github.com/microsoft/vscode/issues/235119)

## Summary

Still reproduces on main: the NotebookSelectionHighlighter applies decorations only at cursor-change time and never re-applies them when new cells scroll into view after virtualization/recycling, so highlights disappear on scroll.

## Change summary

Selection highlighting in notebooks stops appearing on newly-scrolled-into-view cells because decorations are not reapplied after cell editor recycling.

## Best solution

Add a visible-range-change listener in NotebookSelectionHighlighter that reapplies the current highlight decorations to cells that enter the viewport, similar to how other cell parts handle scroll-driven updates.
