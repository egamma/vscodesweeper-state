# Issue #2766 — Automatically Activate Markdown Preview

[https://github.com/microsoft/vscode/issues/2766](https://github.com/microsoft/vscode/issues/2766)

## Summary

Keep open for automatic side-by-side preview: editor associations cover opening the preview instead of the source, but not the remaining behavior a maintainer explicitly acknowledged. The request has 90 upvotes, and the canonical search found no older issue owning that same work.

## Change summary

Allow Markdown source files to open with their preview automatically, without invoking Open Preview to the Side.

## Best solution

Provide an opt-in automatic side-by-side preview workflow in the built-in Markdown extension, preserving source editing and reusing an existing unlocked preview. Settle focus and preview-lifecycle behavior before implementation; preview-only associations are useful but do not satisfy this remaining request.
