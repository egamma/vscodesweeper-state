# Issue #2766 — Automatically Activate Markdown Preview

[https://github.com/microsoft/vscode/issues/2766](https://github.com/microsoft/vscode/issues/2766)

## Summary

The core ask — a first-class setting to auto-open markdown files in preview mode — is partially addressable today via `workbench.editorAssociations`, but no dedicated discoverable toggle exists. With 90 upvotes and Backlog milestone, this stays open as a valid feature request.

## Change summary

Automatically open markdown files in preview mode instead of source, without requiring manual editor-association configuration.

## Best solution

Add a dedicated, discoverable markdown setting (e.g. `markdown.editor.openMode: preview | source | sideBySide`) that configures the default open behavior for `.md` files, rather than requiring users to discover and manually set `workbench.editorAssociations`. The custom editor infrastructure (`vscode.markdown.preview.editor`) is already in place — this is primarily a UX/discoverability improvement.
