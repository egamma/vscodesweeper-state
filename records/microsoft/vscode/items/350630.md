# Issue #350630 — Claude agent host: a client tool hangs forever outside Bypass mode when the workbench's confirmation arrives before the CLI asks for permission

[https://github.com/microsoft/vscode/issues/350630](https://github.com/microsoft/vscode/issues/350630)

## Summary

Keep open: current source drops an early Claude client-tool approval, then leaves the later permission request unresolved because the completed tool's confirmation is discarded as stale. The report supplies a deterministic trigger and debugger evidence; this is distinct from the related completion-routing and session-rebuild hangs.

## Change summary

Claude client-tool calls hang when their workbench confirmation precedes the SDK permission request outside Bypass mode.

## Best solution

Make the Claude provider's client-tool permission round-trip tolerate an already-delivered decision without weakening authorization or reviving completed UI state. Coordinate with the separate early-result delivery defect so the reported parallel-tool turn finishes end to end.
