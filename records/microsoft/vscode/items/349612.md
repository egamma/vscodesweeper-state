# Issue #349612 — Linux (Fedora/RHEL): .rpm download doesn't set up the update repository, so installs silently stop updating

[https://github.com/microsoft/vscode/issues/349612](https://github.com/microsoft/vscode/issues/349612)

## Summary

Keep open as an installation/update discoverability request. Manual RPM installation currently requires separate repository setup, but the download page and in-product update action do not make that updating installation path discoverable.

## Change summary

Make repository-backed updates discoverable or optionally configured when installing VS Code on Fedora/RHEL.

## Best solution

Expose the documented repository installation path alongside Linux downloads and update guidance. A maintainer should decide separately whether RPM installation should offer repository registration rather than changing system repository configuration automatically.
