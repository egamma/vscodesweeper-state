# Issue #331000 — Unable to return multiple window titles for windows across multiple screens / desktops

[https://github.com/microsoft/vscode/issues/331000](https://github.com/microsoft/vscode/issues/331000)

## Summary

This isn't a VS Code code defect — it's a Windows/.NET limitation where `Process.MainWindowHandle` (used by PowerShell's `Get-Process`) exposes only one top-level window per OS process, and VS Code runs all its windows under a single main Electron process on Windows. The reporter's own investigation confirms this is a Windows-side quirk, not something traceable to VS Code's source.

## Change summary

PowerShell's `Get-Process`/`MainWindowHandle` only shows the most recently active VS Code window title, not all open windows across screens/virtual desktops.

## Best solution

No core code change is warranted: VS Code (like other single-process multi-window apps) shares one PID across windows, so Win32's one-handle-per-process model can't surface every window via `Get-Process`. Point the reporter to window-enumeration approaches (e.g. `EnumWindows`/`Get-Process | ... | Select -ExpandProperty MainWindowTitle` won't work, but tools that enumerate all top-level HWNDs regardless of owning process, like `user32.dll EnumWindows`, will) rather than treating this as a VS Code defect.
