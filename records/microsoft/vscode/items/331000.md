# Issue #331000 — Unable to return multiple window titles for windows across multiple screens / desktops

[https://github.com/microsoft/vscode/issues/331000](https://github.com/microsoft/vscode/issues/331000)

## Summary

This is a Windows/.NET process-introspection question rather than a VS Code defect: `Process.MainWindowHandle` exposes one main window for a process, while VS Code internally creates and tracks every open native window.

## Change summary

Retrieve the titles and native handles of every VS Code window across Windows virtual desktops from PowerShell.

## Best solution

Use `code --status` when the window titles are sufficient; when native handles and virtual-desktop placement are required, enumerate Windows top-level windows rather than relying on the singular `Process.MainWindowHandle` property.
