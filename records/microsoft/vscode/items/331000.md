# Issue #331000 — Unable to return multiple window titles for windows across multiple screens / desktops

[https://github.com/microsoft/vscode/issues/331000](https://github.com/microsoft/vscode/issues/331000)

## Summary

This describes a limitation of Windows' Process/MainWindowHandle API (and by extension PowerShell's Get-Process) returning only one window handle per process, not a defined behavior VS Code's own code controls or has broken — the reporter themselves suspects it's 'a deeper Windows/dotnet issue.' There's no concrete, actionable VS Code change being requested.

## Change summary

Reporter wants a PowerShell script using Get-Process/MainWindowHandle to enumerate all open VS Code windows across screens/virtual desktops, but it only surfaces one window per process.

## Best solution

This is really a question about Windows process/window enumeration limitations (MainWindowHandle is a single-value property per OS process) rather than a VS Code defect; if the reporter wants a supported way to enumerate all open VS Code windows/folders, that would need a concrete feature ask (e.g., a CLI/API to list open windows) filed separately with a specific proposal.
