# Issue #333770 — Indented code blocks are not supported in Java Markdown documentation comments

[https://github.com/microsoft/vscode/issues/333770](https://github.com/microsoft/vscode/issues/333770)

## Summary

This is about how the Java language server (Language Support for Java(TM) by Red Hat, `redhat.java`) converts `///` JEP 467 Markdown doc comments into hover content — not something VS Code core touches, since core ships no Java language server (only a syntax-highlighting grammar in `extensions/java`).

## Change summary

Indented (4-space) code blocks inside Java `///` Markdown documentation comments are not rendered as code blocks in the hover.

## Best solution

File this against the extension that actually produces the hover markdown for Java doc comments — redhat-developer/vscode-java (and/or the Eclipse JDT Language Server it embeds) — since that's where the doc-comment-to-Markdown conversion (and any leading-whitespace stripping) happens.
