# Issue #333770 — Indented code blocks are not supported in Java Markdown documentation comments

[https://github.com/microsoft/vscode/issues/333770](https://github.com/microsoft/vscode/issues/333770)

## Summary

Plausible report about JEP 467 `///` Markdown Javadoc comments, but it's unclear which component is actually responsible for stripping the indentation — the hover/doc rendering for Java in VS Code comes from the Red Hat Java Language Support extension, not this core repo, and there's no confirmed repro or comment narrowing it down yet.

## Change summary

Indented (4-space) code blocks inside Java's new `///` Markdown-style Javadoc comments are not rendered as code blocks; the leading whitespace appears to be stripped and the text is shown as plain paragraph text instead.

## Best solution

Get the reporter (or a maintainer) to confirm whether this reproduces with only VS Code's built-in Java syntax (extensions/java, TextMate-only, no hover/doc rendering) or requires the Red Hat Java Language Support extension for hover content — if it's the latter, this is the extension's Javadoc-to-Markdown conversion stripping indentation and belongs in that extension's tracker (redhat.java/vscode-java), not here; if it can be traced to VS Code's generic markdown renderer or the Java `onEnterRules` in extensions/java/language-configuration.json mishandling `///` continuation, then it's a real core fix in that area.
