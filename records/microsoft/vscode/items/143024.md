# Issue #143024 — Tabs that group editor grid layouts (Vim-style tabs)

[https://github.com/microsoft/vscode/issues/143024](https://github.com/microsoft/vscode/issues/143024)

## Summary

Keep open in the Backlog: this remains a distinct, strongly supported request for switchable editor-grid states, and current layout commands do not provide the higher-order tab experience.

## Change summary

Add Vim-style higher-order tabs that each preserve a named arrangement of editor groups, editors, and splits.

## Best solution

Design first-class switchable editor-layout states in the workbench editor grid, including reliable restoration of editor and non-editor state; alternatively, expose sufficient stable APIs for an extension to implement the complete experience.
