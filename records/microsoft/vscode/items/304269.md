# Issue #304269 — Support discovering and installing agent skills from `.well-known` skill indices

[https://github.com/microsoft/vscode/issues/304269](https://github.com/microsoft/vscode/issues/304269)

## Summary

Valid team-authored feature request for `.well-known` URI-based agent skill discovery. No implementation found on current main — the existing `agentPluginRepositoryService.ts` references a local well-known file path for plugins, not the RFC 8615 `.well-known` HTTP discovery spec proposed here. Stays open.

## Change summary

Allow VS Code to discover and install agent skills from standardized `.well-known/agent-skills/index.json` endpoints hosted by skill publishers.

## Best solution

Implement a discovery flow in the agent-plugins/customization layer that fetches and parses `.well-known/agent-skills/index.json` from user-provided URLs, presents available skills in the UI, and installs them with SHA-256 integrity verification. The `agentPluginRepositoryService.ts` and AI customization UI are the natural integration points.
