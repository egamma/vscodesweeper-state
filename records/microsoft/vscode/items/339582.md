## Summary

The issue's own assignee for the canonical bug (vritant24) commented 'related to #332085' on this report. #332085 (older, open, same bug+model-byok labels, assigned) tracks custom BYOK/custom-endpoint models disappearing from the chat model picker (only 'Auto' available) in remote workspaces; a later comment there confirms the same symptom hits the regular Chat UI (not just the Agents window) specifically under Remote-WSL. This report is the same symptom under Remote-SSH, which very likely shares the same remote-vs-local Agent Host BYOK gap (src/vs/platform/agentHost/node/byokLmBridgeRegistry.ts, agentHostByokLm.ts) since both WSL and SSH route through VS Code's generic remote extension host transport.
