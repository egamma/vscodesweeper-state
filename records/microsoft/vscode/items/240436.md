# Issue #240436 — DocumentDropEditProvider does not work with notebooks

[https://github.com/microsoft/vscode/issues/240436](https://github.com/microsoft/vscode/issues/240436)

## Summary

Valid open bug — the DocumentDropEditProvider API does not fire for editors embedded in notebook cells. The issue is already triaged with `help wanted` and belongs in the Backlog; no fix has landed on main.

## Change summary

DocumentDropEditProvider is not invoked when dropping content into notebook cell editors, even though it works for regular editors.

## Best solution

The notebook cell DnD infrastructure likely needs to allow external drops (non-cell drags) to propagate to the embedded CodeEditor's DragAndDropObserver so that DropIntoEditorController fires the registered DocumentDropEditProviders. The fix likely lives in `src/vs/workbench/contrib/notebook/browser/view/cellParts/cellDnd.ts` or how the cell container handles external drag events relative to the code editor within it.
