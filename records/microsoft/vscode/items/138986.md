# Issue #138986 — Support opacity in ThemableDecorationAttachmentRenderOptions

[https://github.com/microsoft/vscode/issues/138986](https://github.com/microsoft/vscode/issues/138986)

## Summary

The accepted Backlog request remains necessary: current main still lacks attachment opacity control, and 44 community upvotes protect it from a quiet-backlog close.

## Change summary

Allow before/after editor decoration graphics to remain fully opaque when the decorated text is dimmed as unnecessary.

## Best solution

Keep unnecessary-code opacity on the decorated text while preventing that style from affecting before/after attachment spans, likely in the editor inline-decoration rendering path. This may solve the underlying problem more correctly than adding an opacity property that cannot override an already-transparent parent.
