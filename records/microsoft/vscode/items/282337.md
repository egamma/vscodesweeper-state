# Issue #282337 — Apparent text escaping bug when using code search tool

[https://github.com/microsoft/vscode/issues/282337](https://github.com/microsoft/vscode/issues/282337)

## Summary

This reports incorrect escaping of parentheses in the search tool query, causing no results. The tool defaults to regex mode (isRegexp ?? true) and has a fallback to try the opposite mode on empty results, but the issue likely arose when the model sent the escaped query with isRegexp: false (literal mode), where `\(` literally doesn't exist in the file. No definitive fix has landed for this behavior; the Nov 2025 commit c19aeea3256 only clarified display messages.

## Change summary

The code search tool returns no results when the LLM escapes parentheses in the query, likely due to a mismatch between regex escaping and the search mode.

## Best solution

The tool should either strip unnecessary regex escaping when in literal mode, or the model prompting should be improved to instruct models not to escape special characters when passing literal text queries. The fallback logic (try opposite regex mode on 0 results) partially addresses this but may not cover all cases. Investigate whether the model is sending isRegexp explicitly as false while escaping characters, bypassing the fallback.
