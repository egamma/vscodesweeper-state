## Summary

The report describes an actionable Copilot lifecycle bug, but it predates the current Agent Host terminal architecture and has no confirmation on current builds. Current source does not expose the reported terminal-close-to-chat-resume path, so reporter confirmation and logs are needed rather than assuming it is fixed.

## Change summary

Stopping or closing a background terminal after an agent turn completes causes Copilot to resume the completed chat and perform more work.

## Best solution

First confirm the behavior on the latest Insiders build and collect Copilot/Agent Host logs showing which terminal event resumes the completed turn. If it persists, terminal lifecycle observation should be scoped to the active tool call and disposed once its owning turn completes.
