# Issue #302900 — Copilot Chat silently stopped persisting conversation state; full session lost after VS Code crash

[https://github.com/microsoft/vscode/issues/302900](https://github.com/microsoft/vscode/issues/302900)

## Summary

The reporter's later diagnostics identified oversized chat serialization as the persistence failure behind the lost history. Current main guards that path with a truncating serialization fallback, so this can close as completed.

## Change summary

Prevent Copilot Chat from silently losing an extended conversation when session persistence fails before a VS Code crash.

## Best solution

Keep the bounded serialization fallback from commit eb308be4f9d2ce27a4117d84b7a789d90dd6cd62 so oversized tool results cannot prevent the rest of a chat session from being persisted, while retaining the existing explicit save-error dialog for other failures.
