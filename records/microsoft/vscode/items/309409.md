# Issue #309409 — Add "Don't Save All" button

[https://github.com/microsoft/vscode/issues/309409](https://github.com/microsoft/vscode/issues/309409)

## Summary

Valid feature request: when using Close All Editors (or similar bulk-close actions), dirty editors are confirmed one-by-one with no "Don't Save All" shortcut. During window close/shutdown a combined dialog already exists, but not for in-editor bulk close.

## Change summary

Add a "Don't Save All" option when closing multiple dirty editors so users can dismiss all remaining save dialogs at once.

## Best solution

Extend the `handleCloseConfirmation` flow in `editorGroupView.ts` to batch dirty editors into a single combined dialog (similar to `showSaveConfirm` during shutdown) when more than one dirty editor is being closed, offering "Save All", "Don't Save All", and "Cancel" buttons.
