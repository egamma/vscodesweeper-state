# Issue #105795 — Go to next error/warning/info

[https://github.com/microsoft/vscode/issues/105795](https://github.com/microsoft/vscode/issues/105795)

## Summary

A real capability gap remains on main: marker-navigation commands still traverse errors, warnings, and information together. This well-supported Backlog request is the canonical issue and should remain open.

## Change summary

Allow separate keyboard navigation through diagnostics by severity, within the current file or across files.

## Best solution

Extend the existing marker-navigation commands to accept a severity filter, then apply it when constructing the MarkerList. Preserve the current combined-severity behavior when no argument is supplied.
