# Issue #265510 — Submodule auto selected every time

[https://github.com/microsoft/vscode/issues/265510](https://github.com/microsoft/vscode/issues/265510)

## Summary

Request current-build confirmation and discovery logs before deciding whether this is persistent selection loss or temporary selection during startup. Current source contains plausible restoration failure paths, but the report does not establish which one occurs.

## Change summary

Previously deselected submodules become selected again after restarting VS Code, accompanied by slow repository discovery and a shrinking SCM view.

## Best solution

Preserve the user's saved repository selection after submodule discovery finishes in SCMViewService. Establish the discovery timing and final selection first, and investigate the reported view resizing separately if it persists after discovery.
