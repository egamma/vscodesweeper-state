# Issue #289465 — Introduce model pick action item hide feature

[https://github.com/microsoft/vscode/issues/289465](https://github.com/microsoft/vscode/issues/289465)

## Summary

Keep open: model visibility is supported, but the current picker still lacks an action to hide a model directly. This team-authored request has no verified fixing commit or older canonical covering the same picker interaction.

## Change summary

Expose a discoverable action within the model picker to hide individual models without opening the models editor.

## Best solution

Provide an accessible, clearly labeled in-picker hiding interaction backed by the existing model-visibility behavior, with hidden models remaining recoverable through Manage Models. Choose its presentation in the context of the current tabbed picker rather than changing visibility semantics.
