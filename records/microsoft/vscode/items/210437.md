# Issue #210437 — option for `editor.autoClosingBrackets` to not auto-close if there's a syntax error in the file

[https://github.com/microsoft/vscode/issues/210437](https://github.com/microsoft/vscode/issues/210437)

## Summary

Current main addresses the motivating unmatched-closing-bracket example, but does not provide the requested option to suppress auto-closing whenever the file has syntax errors. Keep the accepted Backlog request open for a scope decision rather than treating the narrower balancing improvement as full implementation.

## Change summary

Add an auto-closing mode that avoids inserting closing brackets while the file contains syntax errors.

## Best solution

Determine whether syntax-error-wide suppression remains desirable alongside the existing bracket-balancing behavior. If retained, define which syntax errors control suppression and preserve normal auto-closing when those errors are absent.
