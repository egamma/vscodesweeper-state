# Issue #177550 — npm scripts do not run in integrated terminal when it has init script for cmd and powershell

[https://github.com/microsoft/vscode/issues/177550](https://github.com/microsoft/vscode/issues/177550)

## Summary

Keep open: current task launch construction still combines profile startup arguments with task execution flags without sequencing initialization and the npm command. The task-launching code has evolved since 1.76.2, but the supplied Windows and WSL configurations suffice to retest; runtime behavior was not verified in this read-only review.

## Change summary

Running an npm script from the explorer should initialize the configured Node environment before executing the selected script, rather than skipping initialization or never executing the task.

## Best solution

Establish a supported task-shell initialization contract that preserves environment changes through execution of the npm command and allows normal task completion. Diagnose the supplied cmd, PowerShell, and WSL cases in the task launch path before deciding whether all interactive-profile startup arguments can be supported.
