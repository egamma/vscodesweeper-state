# Issue #202188 — Notebook Code Action inconsistency

[https://github.com/microsoft/vscode/issues/202188](https://github.com/microsoft/vscode/issues/202188)

## Summary

Both inconsistencies remain on current main: `always` is explicitly commented out in the notebook codeActionsOnSave schema and save participant, and notebook-prefixed code actions in `editor.codeActionsOnSave` are not read by the notebook save participant. This is a valid open feature request.

## Change summary

Notebook code actions on save lack `always` trigger support and don't honor notebook-prefixed actions placed in `editor.codeActionsOnSave`.

## Best solution

Add `always` support to `notebook.codeActionsOnSave` (the TODO already exists at line 368 of saveParticipants.ts) and consider whether notebook-prefixed actions in `editor.codeActionsOnSave` should be forwarded to the notebook save participant for consistency with the editor-level behavior.
