# Issue #319331 — Please provide a way to override the system prompt, so we can reduce credit waste

[https://github.com/microsoft/vscode/issues/319331](https://github.com/microsoft/vscode/issues/319331)

## Summary

Legitimate feature request for user-editable system prompt to reduce token/credit costs. Existing custom instructions (`.github/copilot-instructions.md`, instruction files) append to but cannot replace the system prompt. Related issues exist but none fully owns this exact ask — keeping open for the community process.

## Change summary

Allow users to override or edit the Copilot system prompt to reduce credit consumption and customize agent behavior.

## Best solution

The existing instructions mechanism (`chat.instructionsFilesLocations`, `.github/copilot-instructions.md`) already lets users append custom instructions, but the core ask — replacing or trimming the built-in system prompt to reduce token cost — remains unaddressed. A dedicated mechanism to suppress or replace portions of the system prompt (with appropriate warnings) would serve cost-conscious users. Related work on system prompt efficiency is tracked in https://github.com/microsoft/vscode/issues/321299 (tokenomics optimization) and https://github.com/microsoft/vscode/issues/291992 (custom prompts for BYOK), but neither fully absorbs this broader user-facing request.
