# Issue #338662 — Python environment auto-activation unreliable in multi-root workspace

[https://github.com/microsoft/vscode/issues/338662](https://github.com/microsoft/vscode/issues/338662)

## Summary

This is about the Python extension's Conda environment activation in integrated terminals for multi-root workspaces — behavior owned by the Python/Python Environments extensions, not VS Code core. Proposing this be moved to the owning tracker rather than closed.

## Change summary

Newly created integrated terminals don't auto-run `conda activate <env>` for the per-folder selected interpreter in a multi-root workspace, and interpreter selection sometimes appears to leak across folders.

## Best solution

Move this to microsoft/vscode-python (and/or microsoft/vscode-python-envs, given the Python Environments extension is installed), where terminal activation and per-folder interpreter state are implemented.
