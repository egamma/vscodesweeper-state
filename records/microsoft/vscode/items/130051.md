# Issue #130051 — Label activity bar icons so we can tell what they are

[https://github.com/microsoft/vscode/issues/130051](https://github.com/microsoft/vscode/issues/130051)

## Summary

The requested Activity Bar labels remain absent on current main, and related explorations deliberately leave this specific design decision open. Keep the request open under discussion.

## Change summary

Show persistent text labels alongside Activity Bar icons, with an option to hide them for a denser layout.

## Best solution

Add a configurable labeled mode to the vertical Activity Bar, exposed through its context menu, while leaving the default behavior to a UX decision. The implementation belongs around ActivitybarPart and ActivityBarCompositeBar.

## Vision fit

- **Fit:** aligned
- **Reason:** Persistent labels improve discoverability and cognitive accessibility in a core workbench surface without requiring always-on behavior.
- **Evidence:** Durable themes: Accessibility and Workbench & core UX; public value: "Simple, uniform UI and UI interactions."
