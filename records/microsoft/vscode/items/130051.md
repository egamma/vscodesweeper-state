# Issue #130051 — Label activity bar icons so we can tell what they are

[https://github.com/microsoft/vscode/issues/130051](https://github.com/microsoft/vscode/issues/130051)

## Summary

Persistent Activity Bar labels remain missing on current main, and the maintainer supported exploring them through a comfortable density mode rather than changing everyone's default. Keep this focused request open; the related design explorations do not establish a canonical duplicate under the re-review rules.

## Change summary

Show readable text labels alongside Activity Bar icons without requiring hover, while retaining an icon-only option.

## Best solution

Provide an opt-in labeled Activity Bar consistent with the maintainer's comfortable-density direction, preserving the existing compact experience. Resolve the label layout and long-name behavior before implementation.
