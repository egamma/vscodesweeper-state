# Issue #332318 — [Auto v2] Pasted text attachment placeholder is scored instead of its content

[https://github.com/microsoft/vscode/issues/332318](https://github.com/microsoft/vscode/issues/332318)

## Summary

The defect remains visible in current source: Auto v2 sends only `ChatRequest.prompt` to `/auto`, while pasted-text content remains in `ChatRequest.references`. Keep this team-authored issue open while maintainers settle the cross-product routing contract for textual attachments.

## Change summary

Auto v2 routes long pasted prompts using their attachment placeholder instead of the attached text, producing capability scores unrelated to the task.

## Best solution

Define an attachment-aware routing contract for Auto that consistently incorporates the user-authored text maintainers consider relevant, including pasted text and mixed inline-plus-attachment prompts, without changing the attachment representation used by the eventual model request.
