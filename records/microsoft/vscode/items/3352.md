# Issue #3352 — [folding] Collapse ending brace to the same line

[https://github.com/microsoft/vscode/issues/3352](https://github.com/microsoft/vscode/issues/3352)

## Summary

This remains a valid, highly supported folding request: current native folding still leaves the closing delimiter on its own line, while extensions provide only partial workarounds. The open implementation PR means the issue should stay open while that proposal is reviewed.

## Change summary

Include a folding range's closing brace or tag in the collapsed presentation so the folded construct occupies one line.

## Best solution

Review and either land or close https://github.com/microsoft/vscode/pull/334371, then establish a consistent folding-range contract for built-in language providers so JavaScript/TypeScript and other brace- or tag-based languages can include closing delimiters without relying on third-party folding extensions.
