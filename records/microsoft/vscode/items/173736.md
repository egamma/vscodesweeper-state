# Issue #173736 — Code action not working even though command is invoked

[https://github.com/microsoft/vscode/issues/173736](https://github.com/microsoft/vscode/issues/173736)

## Summary

Still reproduces on current main: the retrigger in `applyCodeAction`'s `finally` block cancels any in-flight code action request that the applied code action's command triggered. This is a confirmed VS Code bug filed by a team member with milestone On Deck — keeping open.

## Change summary

A code action whose command triggers another code action (e.g. `editor.action.organizeImports`) silently fails when invoked from the lightbulb, because the retrigger in the `finally` block cancels the in-flight request.

## Best solution

In `CodeActionController.applyCodeAction` (`src/vs/editor/contrib/codeAction/browser/codeActionController.ts`), the retrigger at line 195 should not cancel code action requests that were initiated by the command itself. One approach: defer the retrigger until any command-initiated code action request has settled, or use a separate cancellation scope so the retrigger doesn't interfere with the command's own code action flow.
