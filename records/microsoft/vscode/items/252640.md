# Issue #252640 — Dragging the View Container title in a singleton View Contain should move the View Container, not the View

[https://github.com/microsoft/vscode/issues/252640](https://github.com/microsoft/vscode/issues/252640)

## Summary

This remains a valid workbench interaction-design question: the same visible title acts as a container drag handle when multiple views exist but effectively moves the lone view when the container is singleton. The issue is already routed to workbench views and no older canonical with the same observable symptom is established.

## Change summary

Make dragging the title shown for a singleton view container move the whole container rather than only its lone view.

## Best solution

Define a consistent drag contract for the visually shared singleton title in the workbench views area, preserving the container's location when additional views later appear; a maintainer should first decide whether that title always represents the container or whether the UI must distinguish view and container drag targets.
