# Issue #332235 — terminal dictation icon out of sync

[https://github.com/microsoft/vscode/issues/332235](https://github.com/microsoft/vscode/issues/332235)

## Summary

Keep open: current source still lacks cursor/prompt synchronization for terminal dictation decorations and does not end dictation when the shell advances to another prompt. The related reports overlap only partially, and no verified fix or same-symptom canonical supports closing this team-authored issue.

## Change summary

Keep the terminal dictation microphone aligned with terminal input and prevent an in-progress dictation from persisting across prompt transitions.

## Best solution

Make terminal dictation decorations track the active input position reliably, including cursor movement and line wrapping. Establish whether advancing to another prompt should stop dictation or begin a fresh dictation segment, then enforce that lifecycle consistently.
