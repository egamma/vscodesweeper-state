# Issue #330904 — BYOK support for embedding-based AI features

[https://github.com/microsoft/vscode/issues/330904](https://github.com/microsoft/vscode/issues/330904)

## Summary

Legitimate, unaddressed gap: embedding-based features (semantic search, workspace chunk search) are wired only to GitHub-hosted embedding types, with no BYOK path — this is only 3 days old and still in its Backlog Candidates upvote window, so it should stay open for the community process rather than be closed.

## Change summary

Requests that embedding-dependent features (semantic/workspace search, etc.) support BYOK model providers (e.g. local Ollama embedding models) instead of requiring a GitHub/Copilot account.

## Best solution

Belongs with the model-byok workstream: extend the embeddings computation path (extensions/copilot/src/platform/embeddings and workspaceChunkSearch) to accept a BYOK-configured embedding provider instead of hard-requiring IGithubAvailableEmbeddingTypesService; needs a maintainer/product decision on scope and priority relative to other BYOK work, not a mechanical fix.
