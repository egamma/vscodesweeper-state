# Issue #316618 — WSL path handling in Copilot Chat does not appear to support automatic path translation

[https://github.com/microsoft/vscode/issues/316618](https://github.com/microsoft/vscode/issues/316618)

## Summary

Verified duplicate of the open, better-diagnosed remote-extension placement issue. Both reports show Copilot file tools interpreting remote Linux paths as Windows paths when `remote.extensionKind` forces Copilot to the UI host.

## Change summary

Prevent Copilot file tools in WSL from failing or writing into unintended Windows locations when remote paths are interpreted locally.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/280816 and add a guard or clear diagnostic when Copilot is forced onto the UI host during a remote session, including protection against successful writes to unintended local paths.
