# Issue #344616 — Add opt-in setting to keep Primary Side Bar visible when maximizing Secondary Side Bar

[https://github.com/microsoft/vscode/issues/344616](https://github.com/microsoft/vscode/issues/344616)

## Summary

The requested opt-in layout is not available in current main. Keep this newly admitted Backlog Candidate open for community feedback: the verified related issues do not own its full scope.

## Change summary

Allow Secondary Side Bar maximization to preserve the Primary Side Bar and its width, with unchanged defaults and reversible layout restoration.

## Best solution

Evaluate an optional layout mode in the workbench layout service that preserves primary-sidebar navigation while maximizing the secondary sidebar, including consistent toggling and restoration. Coordinate with the related sidebar-toggling request without treating that narrower request as coverage of this entire proposal.
