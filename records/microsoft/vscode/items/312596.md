# Issue #312596 — Performance degradation in Diff Editor due to forced reflows during scrolling

[https://github.com/microsoft/vscode/issues/312596](https://github.com/microsoft/vscode/issues/312596)

## Summary

Confirmed on current main: the DiffToolBar.layout() method synchronously reads clientHeight twice during scroll-triggered layout calls, causing forced reflows. An open PR exists but has not merged.

## Change summary

Diff Editor gutter toolbar causes forced reflows during scrolling by synchronously reading clientHeight in the layout path.

## Best solution

Review and land the open PR https://github.com/microsoft/vscode/pull/312599, which replaces synchronous clientHeight reads with a ResizeObserver-based approach. The fix is localized to `src/vs/editor/browser/widget/diffEditor/features/gutterFeature.ts`.
