# Issue #343940 — Unclear how matching worktreesis calculated

[https://github.com/microsoft/vscode/issues/343940](https://github.com/microsoft/vscode/issues/343940)

## Summary

Keep open: the matching count includes worktrees still being measured, then excludes some as measurement completes, so its decrease does not establish that running sessions were excluded. Current main provides an unavailable-for-cleanup section, but the distinction between discovered, measurable, and cleanup-eligible worktrees still needs clarification.

## Change summary

Clarify the changing matching-worktree count and provide an understandable overview of worktrees across session states.

## Best solution

Make the cleanup editor distinguish discovery and measurement progress from the final matching and cleanup-eligible totals, explaining omissions. Preserve cleanup protections while the owner decides whether this surface should also expose worktrees whose storage cannot be measured.
