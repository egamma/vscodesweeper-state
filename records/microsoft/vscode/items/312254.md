Team-authored bug report about the Plan mode not appearing in the custom agent type picker in the Agents window when using Copilot CLI. No fix commit references this issue, and the filtering logic in `ModePickerModel.getAvailableModes()` still gates custom modes on target matching, which may exclude Plan. Keeping open.

## Change summary

The Plan mode does not appear as a selectable custom agent type in the Agents window agent picker when using Copilot CLI sessions.

Either the Plan mode's target needs to align with the CLI session type, or the filtering logic needs adjustment to include it.
