# Issue #312254 — Agents: Plan doesn't show up as a custom agent type

[https://github.com/microsoft/vscode/issues/312254](https://github.com/microsoft/vscode/issues/312254)

## Summary

The underlying Plan capability exists for Copilot CLI sessions, but current main still separates session planning from the custom-agent picker, leaving a real discoverability and consistency gap. This team-authored Backlog issue should remain open for Agents Window UX iteration.

## Change summary

Make Copilot CLI's built-in Plan mode discoverable when selecting an agent or mode for an Agents Window session.

## Best solution

Present the host's Plan session mode clearly alongside custom-agent selection, or provide an adjacent affordance that explains and activates `/plan`, while preserving the distinction between session modes and custom agent definitions.
