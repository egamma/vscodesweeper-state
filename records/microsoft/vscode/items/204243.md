# Issue #204243 — slow start up

[https://github.com/microsoft/vscode/issues/204243](https://github.com/microsoft/vscode/issues/204243)

## Summary

Keep open as an upstream GPU-startup issue: multiple commenters confirmed the slowdown without extensions, and the issue was reopened because a workaround did not resolve the underlying problem. One driver-update success does not establish resolution across the affected configurations.

## Change summary

Avoid prolonged startup delays and intermittent stalls when GPU initialization encounters a disabled Nvidia discrete GPU or an affected graphics-driver configuration.

## Best solution

Resolve the Chromium/Electron GPU-initialization delay so affected systems start normally without disabling rendering features. Retain this report until current-build evidence establishes resolution, particularly for integrated-only graphics configurations and Wayland.
