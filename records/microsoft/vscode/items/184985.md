# Issue #184985 — Manual linked editing doesn't seem to work

[https://github.com/microsoft/vscode/issues/184985](https://github.com/microsoft/vscode/issues/184985)

## Summary

The defect remains on current main: manually starting linked editing can create the linked ranges while the content-change listeners needed to synchronize them remain unregistered. This is a bounded editor bug and should stay open for a code fix.

## Change summary

Starting linked editing manually while the automatic linked-editing setting is disabled displays linked ranges but does not synchronize edits.

## Best solution

Make a manually started linked-editing session register and retain the same synchronization lifecycle used by automatically enabled linked editing, while preserving the disabled setting for subsequent automatic activation.
