# Issue #211387 — Terminal animations break link detection in integrated terminal

[https://github.com/microsoft/vscode/issues/211387](https://github.com/microsoft/vscode/issues/211387)

## Summary

Still reproduces on current main — no fix has landed. The bug is well-investigated: xterm.js's Linkifier invalidates links across a start/end row range on viewport re-render, so any animation that triggers re-rendering breaks link detection on nearby lines. A caching approach was discussed but never implemented.

## Change summary

Terminal animations that update lines cause link detection to break on the animated lines and adjacent lines, making links intermittently unclickable.

## Best solution

Implement link-content caching in xterm.js's Linkifier (or in VS Code's TerminalLinkDetectorAdapter) so that if the cell content under a detected link hasn't actually changed, the link is preserved rather than invalidated on re-render. The fix likely spans both xterm.js (Linkifier/RenderService) and VS Code's link adapter layer. Tyriar's suggested approach — tracking cell chars at linkify time and only invalidating when the link's cells actually change — is the right direction.
