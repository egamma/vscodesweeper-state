# Issue #211387 — Terminal animations break link detection in integrated terminal

[https://github.com/microsoft/vscode/issues/211387](https://github.com/microsoft/vscode/issues/211387)

## Summary

Keep open: the bundled xterm.js still invalidates hovered links across rendered row ranges without checking whether their contents changed. The maintainer acknowledged this problem and supported investigating caching; no qualifying fix or older same-symptom canonical issue was established.

## Change summary

Keep unchanged terminal hyperlinks clickable while nearby spinners or progress indicators update.

## Best solution

Resolve render-driven link invalidation in xterm.js so unchanged links remain usable during nearby animation, while changed links are correctly refreshed. Verify both OSC 8 hyperlinks and VS Code-detected URLs through the integrated terminal after adopting the upstream change.
