# Issue #236980 — suggestion widget focus ,but can't use page down or ↓,it can't work nomally

[https://github.com/microsoft/vscode/issues/236980](https://github.com/microsoft/vscode/issues/236980)

## Summary

Still reproduces on main: the precondition for selectNextPageSuggestion/selectNextSuggestion blocks PageDown/Down when there's a single focused suggestion, even though the widget code handles the Details-scrolling case correctly.

## Change summary

When the suggest widget shows a single suggestion with focus, PageDown and Down arrow keys don't work to scroll the details pane text.

## Best solution

Adjust the precondition for navigation commands (selectNextSuggestion, selectNextPageSuggestion, selectPrevSuggestion, selectPrevPageSuggestion) in suggestController.ts to also allow activation when in the Details state with a single focused suggestion, so the existing `pageDown()`/scrolling logic in suggestWidget.ts can be reached.
