# Issue #251118 — Chat: Inline context doesn't work inside parens

[https://github.com/microsoft/vscode/issues/251118](https://github.com/microsoft/vscode/issues/251118)

## Summary

The defect remains source-reproducible on current main: inline attachment completion can create a reference after an opening parenthesis, but the request parser only recognizes dynamic references at the start of the message or after whitespace.

## Change summary

Allow inline chat context references such as `(#file:example.ts)` to work without whitespace between the reference and surrounding punctuation.

## Best solution

Recognize registered dynamic-variable ranges independently of the whitespace boundary used for textual chat variables, while preserving the existing boundary rules for agents, slash commands, and unregistered `#` tokens.
