# Issue #251118 — Chat: Inline context doesn't work inside parens

[https://github.com/microsoft/vscode/issues/251118](https://github.com/microsoft/vscode/issues/251118)

## Summary

The defect remains on current main: parenthesis punctuation interferes with both file-context completion and recognition of an accepted dynamic reference. This team-authored, accepted bug should stay open for a bounded parser/completion fix.

## Change summary

Inline chat file context cannot be selected or recognized when the `#` reference is directly enclosed in parentheses.

## Best solution

Treat parentheses as valid boundaries around inline context references, without allowing references embedded within ordinary identifiers or changing whitespace-delimited behavior.
