# Issue #315841 — Deadlock in extension host activation blocks tunnels auth

[https://github.com/microsoft/vscode/issues/315841](https://github.com/microsoft/vscode/issues/315841)

## Summary

Keep open: a maintainer confirmed the tunnel connection hang after the attempted fix, prompting the reopen. The existing steps and activation trace suffice for investigation; no verified post-reopen fix or qualifying canonical was found.

## Change summary

Connecting to a remote tunnel can stall because authentication activation waits on extension-host initialization that itself requires the remote connection.

## Best solution

Resolve the remaining tunnel-startup activation dependency in the core extension-host/authentication services, preserving immediate authentication before remote initialization completes. Investigate the post-fix failure separately from the already-covered case where a local provider registers while another host remains blocked.
