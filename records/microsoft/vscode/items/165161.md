# Issue #165161 — [Accessibility] Open Folder dialog controls do not have accelerator keys

[https://github.com/microsoft/vscode/issues/165161](https://github.com/microsoft/vscode/issues/165161)

## Summary

Partially addressed on main: PR #272554 added an accelerator key for the 'Select Folder' button on Windows, but the remaining two controls (folder name text field, folder location treeview) are upstream Electron/Windows issues that VS Code cannot fix. Keeping open as an upstream tracker.

## Change summary

The native Open Folder dialog on Windows lacks accelerator keys on the folder name field, folder location treeview, and Select Folder button, unlike the Open File dialog.

## Best solution

The VS Code-side fix (Select Folder button mnemonic) has shipped. The remaining two controls (folder name, folder treeview) need a fix in Electron or the underlying Windows common dialog. The upstream Electron issue (electron/electron#48631) was closed as a Windows-side problem. This issue should stay open to track the upstream gap, and be revisited if a future Electron or Windows update exposes a path to fix the remaining controls.
