# Issue #244047 — Mac VSCode update is disabled and cannot be executed

[https://github.com/microsoft/vscode/issues/244047](https://github.com/microsoft/vscode/issues/244047)

## Summary

The 'command is disabled' error is the generic message shown when a command's precondition isn't met. On managed machines, an MDM policy likely sets update.mode to 'none', which puts the update service into a Disabled state — making the Check for Updates command's precondition (state = Idle) fail. Without seeing the effective update.mode value or policy inspection output, we can't distinguish a real bug from working-as-designed policy enforcement.
