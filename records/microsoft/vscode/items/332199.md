# Issue #332199 — Chat input history leaks across sessions

[https://github.com/microsoft/vscode/issues/332199](https://github.com/microsoft/vscode/issues/332199)

## Summary

Confirmed session-isolation bug with an open PR that directly fixes the reported behavior. Keep the issue open until https://github.com/microsoft/vscode/pull/332200 is reviewed and merged or otherwise resolved.

## Change summary

Scope Chat input-history navigation to each chat session so prompts from one session cannot be recalled in another.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/332200, which keys input history by session resource, migrates history when an untitled session materializes, and adds regression coverage.
