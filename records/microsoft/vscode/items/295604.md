# Issue #295604 — Show skipped questions

[https://github.com/microsoft/vscode/issues/295604](https://github.com/microsoft/vscode/issues/295604)

## Summary

The gap remains on current main: skipped standard question carousels retain their question data but render only “Skipped question,” so users cannot review what was asked. Agent Host carousels already have the requested richer summary, providing a clear pattern to extend.

## Change summary

Show the original question text, and available choices where applicable, after a Copilot Chat question is skipped or restored following a reload.

## Best solution

Render retained questions in the terminal summary for every skipped carousel, using the existing conversational skipped-question presentation rather than replacing the whole carousel with a generic status message.
