# Issue #324223 — Performance loss in the VS Code `fs` abstraction that potentionally hits all extensions

[https://github.com/microsoft/vscode/issues/324223](https://github.com/microsoft/vscode/issues/324223)

## Summary

Confirmed performance issue: the `workspace.fs` shortcut path in `ExtHostConsumerFileSystem` still makes an RPC call to the renderer via `$ensureActivation` on every operation, negating the fast-path benefit. An open PR (#324070) from the reporter addresses this. Keeping open for the PR to land.

## Change summary

The `workspace.fs` API's extension-host shortcut path unnecessarily round-trips to the renderer process via `$ensureActivation` on every file operation, causing 2–65x slowdowns compared to direct provider calls.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/324070 which removes the unnecessary `$ensureActivation` RPC from the shortcut path in `src/vs/workbench/api/common/extHostFileSystemConsumer.ts`. The activation check should be resolvable locally in the extension host.
