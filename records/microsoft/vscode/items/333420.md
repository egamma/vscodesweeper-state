## Summary

The mapped-drive workspace mismatch is covered by the merged canonical-path fix: file tools now resolve both the requested file and its containing workspace root before checking containment.

## Change summary

Copilot's read tool incorrectly treats files in a mapped network-drive workspace as external when path resolution changes drive-letter casing or produces a canonical UNC path.

## Best solution

Keep the canonical workspace-root containment logic from commit dd10470a17e5cd04fa43a68f4fec339651b5b176 and close this as completed; it preserves prompts for genuinely external symlink targets while accepting files whose canonical path remains under the canonical workspace root.
