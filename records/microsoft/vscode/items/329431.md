# Issue #329431 — Agent Host: create_chat hangs when target session was evicted

[https://github.com/microsoft/vscode/issues/329431](https://github.com/microsoft/vscode/issues/329431)

## Summary

The original silent hang is now partly contained by fail-fast cleanup, but current main still cannot create a chat for an evicted target session because `AgentService.createChat()` never restores the parent. This team-authored Backlog bug should remain open; no linked fixing PR or issue-referencing fix commit exists.

## Change summary

Creating a peer chat in a durable but evicted Agent Host session fails instead of restoring the parent and starting the requested turn.

## Best solution

Make chat creation materialize an absent parent session before provider provisioning, preserve the catalog-before-turn invariant, and retain rollback if registration cannot complete. Cover the evicted-parent server-tool flow in the Agent Service unit suite, including delivery of permission-related protocol actions.
