# Issue #34093 — Feature request - undo after moving cursor should optionally just put the cursor back, without undoing

[https://github.com/microsoft/vscode/issues/34093](https://github.com/microsoft/vscode/issues/34093)

## Summary

A real gap remains: Cursor Undo is separate from text undo and current main does not provide the requested optional two-step undo behavior. This is the canonical Backlog request for that behavior and should remain open.

## Change summary

Optionally make the first undo after cursor movement return to the last edit location without reverting text.

## Best solution

Add an opt-in editor behavior that makes undo restore the cursor to the pending edit location before a subsequent undo reverts text, while preserving the existing Cursor Undo command and default undo semantics.
