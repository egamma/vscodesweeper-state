# Issue #229115 — Cannot move multi-cell selection within Jupyter notebook using alt+up/down arrows

[https://github.com/microsoft/vscode/issues/229115](https://github.com/microsoft/vscode/issues/229115)

## Summary

Still reproduces on main: when Alt+Arrow triggers the move command via keyboard, `getContextFromActiveEditor` always sets `context.cell` to the active cell, so `moveCellRange` takes the single-cell path and ignores the multi-cell selection.

## Change summary

Alt+Up/Down in a notebook with multiple cells selected via Shift+Arrow moves only the active cell instead of the entire selection.

## Best solution

In `moveCellRange` (src/vs/workbench/contrib/notebook/browser/controller/cellOperations.ts), when `context.cell` is set but the editor has a multi-cell selection that includes that cell, prefer the selection range over the single-cell range. Alternatively, have the move commands not pass `context.cell` when invoked via keybinding so the selection path is used.
