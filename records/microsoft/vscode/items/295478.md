# Issue #295478 — Extensions editor uses a mix of native and custom scrollbar

[https://github.com/microsoft/vscode/issues/295478](https://github.com/microsoft/vscode/issues/295478)

## Summary

The mismatch remains on current main: extension README content uses Chromium's CSS-styled native scrollbar while adjacent extension details use VS Code's custom DomScrollableElement. This should stay open and be routed to the extensions editor and webview owners.

## Change summary

Make the scrollbars shown together in the Extensions editor visually and behaviorally consistent.

## Best solution

Align the extension README/CHANGELOG webview scrollbar with the workbench scrollbar presentation without regressing scrollbar behavior in other webview consumers. The extensions editor and shared webview styling owners should determine whether that means a closer native style or a surface-specific treatment.
