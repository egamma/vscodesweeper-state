# Issue #310853 — Agents: Changes rendering defaults and flexibility

[https://github.com/microsoft/vscode/issues/310853](https://github.com/microsoft/vscode/issues/310853)

## Summary

Keep this open for a focused decision on review presentation and discoverability. Current source covers single-file opening, selected-file navigation, and editor maximization, but those capabilities do not fully settle the requested modal-versus-docked experience.

## Change summary

Make Changes and plan review presentation discoverable and adaptable to available space, while opening the file the user selected.

## Best solution

Agree on a coherent desktop review policy for individual files, View All Changes, and plan artifacts, with discoverable controls for the supported presentation choices. Retain the existing selected-file navigation and single-file option rather than treating those already-covered parts as new work.
