# Issue #247685 — How do I get from the inline merge conflicts view to the merge editor?

[https://github.com/microsoft/vscode/issues/247685](https://github.com/microsoft/vscode/issues/247685)

## Summary

The accessibility gap remains in current source: the inline action is mouse-only and its Git command is hidden from the Command Palette. Keep this report open because the older palette request covers only part of the maintainer-endorsed work.

## Change summary

Make opening the merge editor from an inline conflict discoverable and operable with the keyboard and a screen reader.

## Best solution

Expose the existing Git merge-editor action through the Command Palette and provide accessible keyboard navigation to the in-editor control, following the thread's preference for a first tab stop in Tab Moves Focus mode. Preserve normal editor Tab behavior and existing merge/rebase semantics.
