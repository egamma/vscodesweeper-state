# Issue #247685 — How do I get from the inline merge conflicts view to the merge editor?

[https://github.com/microsoft/vscode/issues/247685](https://github.com/microsoft/vscode/issues/247685)

## Summary

Team-authored accessibility bug, still open on main: the inline merge conflict 'Resolve in Merge Editor' button has no keyboard path — no keybinding for `git.openMergeEditor`, no tab stop on the button, and the command isn't surfaced in the Command Palette during a merge conflict. Active team discussion on the best fix approach (command palette entry vs. tab stop vs. both).

## Change summary

The inline merge conflict 'Resolve in Merge Editor' button cannot be reached or activated via the keyboard.

## Best solution

At minimum, expose `git.openMergeEditor` in the Command Palette when a file has merge conflicts (the command exists but isn't discoverable). Additionally, make the inline button a tab stop in the editor so keyboard/screen-reader users can reach it — as the team discussion leans toward both approaches. The fix likely touches `extensions/git/package.json` (command palette `when` clause, possible keybinding) and the merge-conflict decoration code in `extensions/merge-conflict/`.
