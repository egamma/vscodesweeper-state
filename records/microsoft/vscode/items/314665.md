# Issue #314665 — Very large text spotted in sessions list

[https://github.com/microsoft/vscode/issues/314665](https://github.com/microsoft/vscode/issues/314665)

## Summary

Still reproducible from current source: a Markdown heading in an active session description is rendered as an `<h1>` inside the fixed-height metadata row, producing the oversized text shown in the screenshot.

## Change summary

Session status descriptions containing Markdown headings can render at heading size in the Agents Window sessions list.

## Best solution

Keep session status descriptions constrained to the list's single-line label typography regardless of Markdown block syntax, while preserving supported inline formatting, and add a focused regression test using the reported heading input.
