# Issue #290063 — MCP: structuredContent in tool result overrides content[].text sent to model

[https://github.com/microsoft/vscode/issues/290063](https://github.com/microsoft/vscode/issues/290063)

## Summary

Keep open: current main still drops model-facing text whenever structuredContent is present, matching the independently confirmed Fabric failures. The Agent Host mitigation and separate MCP Apps fix do not resolve this local tool-result conversion path.

## Change summary

Preserve MCP tool text answers in model input when the same result also contains structuredContent.

## Best solution

Ensure local MCP tool results deliver assistant-visible content[].text without substitution by structuredContent. Follow the maintainer's stated direction that structuredContent is for programmatic consumption, while preserving the original structured payload for MCP Apps.
