# Issue #243755 — Scroll state should not be shared between walkthrough steps

[https://github.com/microsoft/vscode/issues/243755](https://github.com/microsoft/vscode/issues/243755)

## Summary

Still reproduces on main: the walkthrough details panel never resets its scroll position when switching between steps, because `selectStep` only calls `scanDomNode()` (recalculates dimensions) but never resets scroll offset.

## Change summary

Switching walkthrough steps preserves the previous step's scroll position instead of resetting to the top.

## Best solution

In `selectStep` (gettingStarted.ts ~line 861), after expanding the new step and calling `scanDomNode()`, call `setScrollPosition({ scrollTop: 0 })` on both `detailsPageScrollbar` and `detailsScrollbar.value` to reset scroll to top when the selected step changes.
