[https://github.com/microsoft/vscode/issues/343638](https://github.com/microsoft/vscode/issues/343638)

## Summary

The classification loss remains directly visible on main: deterministic provider failures still become retryable 502 responses before streaming output begins. Keep this open while the linked contributor PR is reviewed; its narrower DeepSeek fix does not establish completion of the general error-preservation request.

## Change summary

Preserve deterministic BYOK provider error classifications across the Agent Host bridge so invalid requests are not retried unchanged.

## Best solution

Known deterministic provider/client errors should retain a serializable classification and reach the Responses client as non-retryable 4xx responses, while unknown, transport, and upstream 5xx failures retain existing transient recovery. Review https://github.com/microsoft/vscode/pull/345850 against that broader contract before treating this issue as resolved.
