# Issue #297485 — Yolo but scoped to workspace or chat session

[https://github.com/microsoft/vscode/issues/297485](https://github.com/microsoft/vscode/issues/297485)

## Summary

Both requested scopes are now supported: `/yolo` changes the current session's permission level, while a workspace-scoped default can start new sessions with approvals bypassed. This can be closed as completed.

## Change summary

Allow YOLO/auto-approve behavior to be enabled for one workspace or one chat session instead of globally.

## Best solution

Keep the shipped session permission picker and `/yolo` behavior, with `chat.defaultConfiguration.approvals` available in workspace settings for workspace-specific defaults.
