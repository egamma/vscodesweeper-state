# Issue #337946 — Copilot Chat agent mode: rename tool reports success but does not modify the file

[https://github.com/microsoft/vscode/issues/337946](https://github.com/microsoft/vscode/issues/337946)

## Summary

Confirmed from source: the built-in rename tool's chat-session code path reports success unconditionally after streaming edits, without verifying the workspace edit actually landed — unlike the sibling editFileTool, which guards on an active editing session and waits for confirmed application before returning success.

## Change summary

In agent mode, the built-in rename tool reports a specific success message with edit/file counts even when the workspace files were not actually modified.

## Best solution

Fix RenameTool.invoke in renameTool.ts to mirror editFileTool's pattern: require/verify an active editing session and wait for the streamed edits to be confirmed applied (via the editing session's entry state) before returning a success result; return an error otherwise.
