# Issue #20266 — Offline spell checker for VSCode

[https://github.com/microsoft/vscode/issues/20266](https://github.com/microsoft/vscode/issues/20266)

## Summary

Keep this canonical feature request open. It has 101 community upvotes and remains a real platform gap: current main has no built-in offline spell-check service and explicitly disables browser spell checking in editor inputs.

## Change summary

Provide reliable offline spell checking through a bundled platform service or a stable API that extensions can use without maintaining Electron-specific native binaries.

## Best solution

Define a stable, asynchronous platform spell-check service backed by operating-system dictionaries where available, while leaving language-aware text extraction and presentation to extensions. This issue should remain the canonical discussion for that platform capability.

## Vision fit

- **Fit:** unclear
- **Reason:** A bundled checker adds core weight, but a stable platform API would strengthen extensions and address a capability they cannot reliably implement alone.
- **Evidence:** The public guardrails favor a lightweight default and state that “the power lives in extensions,” while recognizing missing extension-API capabilities as valid core work.
