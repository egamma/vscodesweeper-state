## Evidence

- **Current client request:** extensions/markdown-language-features/src/languageFeatures/updateLinksOnPaste.ts calls MdLanguageClient.getUpdatePastedLinksEdit when the clipboard contains Markdown link-update metadata. In src/client/client.ts, toLspRange constructs an object-shaped LSP range with start and end, and getUpdatePastedLinksEdit sends those ranges to the server.
- **Upstream defect:** https://github.com/microsoft/vscode-markdown-languageserver/blob/main/src/server.ts still reconstructs request edits using edit.range[0].line and edit.range[1].line. Those array entries are undefined for the object-shaped ranges sent by the current client, directly explaining the reported exception.
- **Existing open report and confirmed reproduction:** https://github.com/microsoft/vscode/issues/323131 is open and reports the identical request failure during Markdown paste. https://github.com/microsoft/vscode/issues/323131#issuecomment-5237287979 identifies the server range-shape mismatch; https://github.com/microsoft/vscode/issues/323131#issuecomment-5312513545 documents repeated macOS reproduction and the setting workaround. This report adds vscode.dev, a local-folder workspace, and Chrome 154.0.8037.98.
- **Fix candidate remains open:** https://github.com/microsoft/vscode-markdown-languageserver/pull/25 is open and targets this exact range-shape mismatch. It is an implementation candidate, not evidence of a landed fix; no competing agent implementation is appropriate.
- **Previously closed report:** https://github.com/microsoft/vscode/issues/298733 is closed as completed and therefore cannot be a duplicate target. The later open report and upstream PR explicitly describe the same failure persisting after that closure.
- **Workaround and inspection limits:** UpdatePastedLinksEditProvider.#isEnabled reads markdown.editor.updateLinksOnPaste.enabled; setting it to false bypasses this provider but also disables its link rewriting. Inspection was read-only, no runtime reproduction was performed, and git status remained clean.
