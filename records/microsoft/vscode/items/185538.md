# Issue #185538 — Offer different `editor.fontWeight` and `terminal.integrated.fontWeight` for both dark and light mode 

[https://github.com/microsoft/vscode/issues/185538](https://github.com/microsoft/vscode/issues/185538)

## Summary

Keep open: this is a backlog feature request with 35 community upvotes, and the current settings surface does not appear to offer light/dark-specific values for `editor.fontWeight` or `terminal.integrated.fontWeight`. The request remains a real theming/settings gap rather than something already covered by existing theme color overrides.

## Change summary

Allow separate editor and integrated terminal font-weight settings for light and dark color modes.

## Best solution

If accepted, add a settings-level mechanism for color-scheme-specific font-related overrides, or a narrower theme-aware override path for `editor.fontWeight` and `terminal.integrated.fontWeight`, owned by editor theming/settings and terminal configuration maintainers.
