# Issue #241918 — Warning when attaching image from localhost or private sites

[https://github.com/microsoft/vscode/issues/241918](https://github.com/microsoft/vscode/issues/241918)

## Summary

The misleading URL-only image attachment path was replaced after this report: current main fetches dropped HTTP(S) images locally and attaches their binary data, while failed fetches no longer create an unusable image attachment.

## Change summary

Dragging an image from localhost or an inaccessible private URL into Chat created a URL attachment that the model could not read.

## Best solution

Keep the implementation from commit c588828980a0a8abad76f87a73a2819a27be1b8c: download accessible dropped images and attach their bytes, and avoid creating an image attachment when the fetch fails.
