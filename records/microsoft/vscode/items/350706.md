# Issue #350706 — Remote agent host (Remote - SSH) uses the client's loopback http.proxy on the remote machine; Copilot sessions fail with ECONNREFUSED

[https://github.com/microsoft/vscode/issues/350706](https://github.com/microsoft/vscode/issues/350706)

## Summary

The current source still forwards the client's configured proxy to the Remote-SSH agent host without honoring proxy-configuration separation. Keep this open for the agent-host owner; the related reports describe different failures.

## Change summary

Prevent a Remote-SSH agent host from using the client's loopback proxy when local proxy configuration is disabled.

## Best solution

Make agent-host proxy configuration respect the existing local-versus-remote setting boundary, including connection, reconnection, and configuration changes. Preserve local agent-host proxy behavior and the remote machine's own proxy settings.
