# Issue #115137 — workbench.externalUriOpeners protocol glob patterns don't work

[https://github.com/microsoft/vscode/issues/115137](https://github.com/microsoft/vscode/issues/115137)

## Summary

The remaining ask — supporting shorter protocol-only globs like `https:*` in addition to the existing `https://*` syntax — is still unimplemented on current main. The initial confusion was resolved (correct syntax is documented in hover intellisense), but the feature request to accept the shorter form remains valid.

## Change summary

Support protocol-only glob patterns like `https:*` (without `://`) in the `workbench.externalUriOpeners` setting.

## Best solution

Extend `testUrlMatchesGlob` in `src/vs/platform/url/common/urlGlob.ts` to recognize scheme-only patterns like `https:*` (where the glob has a scheme followed by a wildcard but no `://`), treating them as matching any URL with that scheme. Alternatively, close as low-priority since `https://*` already works and is documented.
