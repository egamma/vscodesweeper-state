# Issue #236450 — Expose native support for USB, HID and Serial device access in VS Code (Desktop)

[https://github.com/microsoft/vscode/issues/236450](https://github.com/microsoft/vscode/issues/236450)

## Summary

Keep open: this accepted Backlog request has 45 community upvotes and an active implementation PR. Desktop extension device selection remains a real gap on main.

## Change summary

Expose WebUSB, WebHID, and WebSerial device authorization to web extensions running in desktop VS Code.

## Best solution

Review and either land or supersede https://github.com/microsoft/vscode/pull/198047, using a secure Electron-to-workbench device-selection broker consistent with the existing web and integrated-browser permission models.
