# Issue #111596 — SCM - go to next/previous change (Alt-F5) should cycle between files

[https://github.com/microsoft/vscode/issues/111596](https://github.com/microsoft/vscode/issues/111596)

## Summary

Keep open while the linked implementation candidate is reviewed. Multi-Diff already supports cross-file change navigation, but ordinary editor navigation still wraps within the current file, leaving the requested workflow incomplete.

## Change summary

Make next/previous SCM change navigation continue into another changed file instead of wrapping within the current file.

## Best solution

Provide continuous keyboard navigation through SCM changes across files in the ordinary editor workflow. Review https://github.com/microsoft/vscode/pull/225601 against that requirement: its separate changed-file commands do not themselves make Alt-F5 advance across file boundaries.
