# Issue #25021 — full width tab glyph for editor.renderWhitespace

[https://github.com/microsoft/vscode/issues/25021](https://github.com/microsoft/vscode/issues/25021)

## Summary

The full-width tab marker remains missing: current SVG, font, and legacy rendering use a single-cell arrow rather than extending to the next tab stop. Keep this accepted Backlog request open; no verified older canonical or landed implementation was found.

## Change summary

Render visible tabs as a line or arrow spanning their actual width to the next tab stop.

## Best solution

Agree on a consistent full-width tab-marker treatment in the editor whitespace renderer, including whether it replaces the existing marker or is optional. Preserve whitespace visibility modes and avoid expanding this into arbitrary per-glyph styling.

- **Reason:** Making tab extent legible within the existing whitespace surface fits core editor usability without requiring additional always-on UI.
