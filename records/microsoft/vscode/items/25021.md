# Issue #25021 — full width tab glyph for editor.renderWhitespace

[https://github.com/microsoft/vscode/issues/25021](https://github.com/microsoft/vscode/issues/25021)

## Summary

A real gap remains: current main still renders each tab marker only one space wide. The request is already correctly routed and should remain open for product discussion.

## Change summary

Render visible tab markers across the tab's full width instead of using a single-character-width arrow.

## Best solution

Decide on a consistent full-width tab marker in the editor's whitespace overlay, calculating the marker width through the next tab stop without adding per-glyph configuration.
