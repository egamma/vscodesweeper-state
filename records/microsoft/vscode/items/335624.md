# Issue #335624 — Word wrapping breaks when line contains right arrow characters (→) with Iosevka SS11 font

[https://github.com/microsoft/vscode/issues/335624](https://github.com/microsoft/vscode/issues/335624)

## Summary

The default wrapping strategy intentionally assumes equal-width glyphs for performance; Iosevka SS11 renders `→` with metrics that violate that assumption. The existing `editor.wrappingStrategy: "advanced"` setting delegates measurement to the browser and covers this case.

## Change summary

Repeated right-arrow characters rendered with Iosevka SS11 overflow instead of wrapping under the default wrapping strategy.

## Best solution

Keep the fast equal-width algorithm as the default and use `editor.wrappingStrategy: "advanced"` when a font contains glyphs with non-uniform widths.
