# Issue #331330 — Unchecking all items in a section does not disable the section's check box

[https://github.com/microsoft/vscode/issues/331330](https://github.com/microsoft/vscode/issues/331330)

## Summary

Team-authored bug report with an already-open, well-described fixing PR that explicitly closes this issue on merge — should stay open until that PR lands, not be closed now.

## Change summary

Unchecking every individual item in an Agent Customizations migration group leaves the group's own checkbox checked instead of unchecking it.

## Best solution

Review and land PR https://github.com/microsoft/vscode/pull/331419, which adds an onSelectionChange callback so renderGroup recomputes the group checkbox state as items are toggled (with a regression test in aiCustomizationManagementEditor.test.ts); the issue closes automatically via its 'Fixes #331330' syntax once merged.
