# Issue #312380 — [Error] unhandlederror-Cannot access a disposed editing session

[https://github.com/microsoft/vscode/issues/312380](https://github.com/microsoft/vscode/issues/312380)

## Summary

Still reproduces on main: the race condition in `rejectSession()` is unguarded — after awaiting `cancelCurrentRequestForSession`, no disposed check protects the subsequent `session.editingSession.reject()` call. Recurring across 1.117–1.130 with thousands of affected users per release.

## Change summary

Rejecting an inline chat session throws 'Cannot access a disposed editing session' when the editing session is disposed during the async cancel await.

## Best solution

Guard `rejectSession()` in `inlineChatController.ts` (line ~626) with a disposed check after the `cancelCurrentRequestForSession` await, either returning early or swallowing the error when the editing session was already disposed during cancellation — this is a benign race, not a logic error.
