[https://github.com/microsoft/vscode/issues/312380](https://github.com/microsoft/vscode/issues/312380)

## Summary

Keep open: current main retains the inline-chat rejection race described in the telemetry. A captured editing session can be disposed while cancellation is awaited, after which rejection throws the reported error.

## Change summary

Prevent inline-chat rejection from accessing an editing session disposed during asynchronous request cancellation.

## Best solution

Make inline-chat rejection complete safely when its original session is concurrently torn down, while preserving normal edit rejection and leaving any replacement session untouched.
