# Issue #309410 — Agents app not showing current git state complicates life

[https://github.com/microsoft/vscode/issues/309410](https://github.com/microsoft/vscode/issues/309410)

## Summary

Keep open for the remaining Git-context discoverability work: ahead/behind counts now have a built-in surface, but the author's follow-up asks for branch identity within Changes. The newer cross-surface tracking issue explicitly preserves this narrower report.

## Change summary

Make the active branch and its remote divergence understandable when starting agents and reviewing their changes.

## Best solution

Make the active branch identifiable at the point where users inspect Changes, while preserving the existing ahead/behind indicator. Coordinate that presentation with the broader Git/worktree experience without treating aggregate change counts as evidence that a particular diff contains changes.
