# Issue #307720 — Find/Replace (`Ctrl` + `F`/`Ctrl` + `H`) won't add multiline selection

[https://github.com/microsoft/vscode/issues/307720](https://github.com/microsoft/vscode/issues/307720)

## Summary

Confirmed in current source: Ctrl+F and Ctrl+H deliberately restrict selection seeding to one line, despite the find controller already supporting multiline search terms. The issue is correctly routed and should remain open.

## Change summary

Seed the editor Find and Replace widgets from a multiline selection when invoked with Ctrl+F or Ctrl+H.

## Best solution

Pass multiline selection content through the existing find-controller path for both StartFindAction and StartFindReplaceAction, preserving the current focus and setting behavior.
