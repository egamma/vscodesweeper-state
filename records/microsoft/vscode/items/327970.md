# Issue #327970 — MCP servers are stopped immediately after tool discovery (and mid-initialize) in 1.131 — kills stateful servers

[https://github.com/microsoft/vscode/issues/327970](https://github.com/microsoft/vscode/issues/327970)

## Summary

Keep open and route to MCP maintainers: this team-authored report documents a credible 1.131 regression that repeatedly terminates active and initializing servers.

## Change summary

MCP discovery repeatedly stops and restarts configured servers, destroying stateful sessions.

## Best solution

Identify the discovery or configuration refresh that replaces server definitions, then preserve active connections when definitions are unchanged. The likely investigation points are MCP collection synchronization and `McpService.updateCollectedServers()`.
