## Summary

Team-filed flaky smoke test issue — the afterEach hook times out waiting for the quick input widget when running KillAll. Author is a MEMBER, so this stays open for maintainer judgment.

## Change summary

Terminal smoke test afterEach hook intermittently times out waiting for the quick input widget when running the KillAll command.

## Best solution

Make the afterEach cleanup in `test/smoke/src/areas/terminal/terminal.test.ts` more resilient — either retry the KillAll command on timeout, use a direct terminal API instead of going through quick input, or add a fallback cleanup path. The root issue is that `runCommand` routes through the quick input widget, which can fail to focus within 20 seconds under CI load.
