## Summary

Keep open and route to file-watcher: two users confirmed that file events can stop until focus changes, and no issue-linked fix or canonical duplicate was found.

## Change summary

On macOS, external file changes sometimes stop updating open buffers and the Explorer until VS Code regains focus or restarts.

## Best solution

Determine whether the current `@vscode/watcher` backend can silently stop delivering macOS events under heavy directory churn, then add health detection or recovery in the file-watcher process.
