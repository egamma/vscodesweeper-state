- **Behavior:**

  > Typing in a roughly 1200–1550-line Markdown file reportedly consumes substantially more CPU after the file is committed to Git; disabling Git reduces the load. The original crashes and extreme memory growth were reported resolved and are not the currently confirmed defect. Establish whether the excess persists on current main and quantify it using identical contents and typing rates. Any improvement must preserve correct live SCM change indicators and normal tracked-file editing.
- **Trace:**

  > QuickDiffModel in src/vs/workbench/contrib/scm/browser/quickDiffModel.ts schedules work on text content changes through a 200ms ThrottledDelayer and computes advanced diffs against provider baselines. GitQuickDiffProvider.provideOriginalResource in extensions/git/src/quickDiffProvider.ts excludes untracked files, giving a concrete explanation for additional work after tracking. QuickDiffWorkbenchController in src/vs/workbench/contrib/scm/browser/quickDiffDecorator.ts disables decoration-driven references for scm.diffDecorations=none, providing a narrower diagnostic control than disabling Git entirely. EditorWorkerService.computeDiff in src/vs/editor/browser/services/editorWorkerService.ts delegates computation to the editor worker. These paths are leads, not proof of the performance defect's root cause; profiling must distinguish worker diff cost, rendering, provider calls, and other consumers before defining the fix boundary. The reporter's controlled comparisons are at https://github.com/microsoft/vscode/issues/257939#issuecomment-3658418936 and https://github.com/microsoft/vscode/issues/257939#issuecomment-3667438341.
