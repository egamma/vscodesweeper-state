# Issue #316594 — Allow to view mermaid diagram in fullscreen

[https://github.com/microsoft/vscode/issues/316594](https://github.com/microsoft/vscode/issues/316594)

## Summary

Keep open: Markdown diagrams have pan, zoom, resizing, and an Open Diagram in Editor context-menu action, but no direct fullscreen button. The existing editor view partially addresses large-diagram viewing; no verified duplicate or issue-referencing fix establishes completion of this team-authored request.

## Change summary

Provide a discoverable fullscreen viewing action for large Mermaid diagrams embedded in Markdown previews.

## Best solution

Make diagram-focused, screen-sized viewing directly accessible from a Markdown diagram without requiring manual layout changes. Decide whether the existing diagram editor should provide that experience or whether an in-preview fullscreen mode is needed.

- **Behavior:**

  > Large Mermaid diagrams in Markdown previews should offer a discoverable action for focused, screen-sized viewing rather than requiring users to rearrange the workbench manually. - **Trace:**

  > Markdown preview rendering in extensions/mermaid-markdown-features/preview-src/markdown/index.ts delegates diagram interaction to DiagramManager. The remaining uncertainty is whether the requested fullscreen experience should reuse the diagram editor or stay inside the Markdown preview; preserve existing inline navigation and avoid broadening this into node selection or export. Related https://github.com/microsoft/vscode/issues/298869 concerns those separate capabilities and is not a duplicate.
- **Open decisions:**
