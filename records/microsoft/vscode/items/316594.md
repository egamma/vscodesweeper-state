# Issue #316594 — Allow to view mermaid diagram in fullscreen

[https://github.com/microsoft/vscode/issues/316594](https://github.com/microsoft/vscode/issues/316594)

## Summary

Valid feature request from a team member: the mermaid markdown preview lacks a fullscreen/open-in-editor button that already exists in the chat output renderer. No implementation found on main for the markdown preview context.

## Change summary

Add a fullscreen or 'open in editor' button to mermaid diagrams rendered in the markdown preview, so large diagrams can be viewed at full size.

## Best solution

Extend the mermaid markdown preview (extensions/mermaid-markdown-features/preview-src/markdown/) to include an 'open in editor' or fullscreen button similar to the one in chatOutputRenderer.ts, leveraging the existing MermaidEditorManager panel infrastructure.
