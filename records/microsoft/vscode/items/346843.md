## Evidence

- **Current restart blocker:** src/vs/workbench/contrib/browserView/electron-browser/browserViewWorkbenchService.ts registers an unattended-restart participant that returns browser.livePage whenever _remoteEvents.size > 0. _createModel populates that map before _openEditorForCreatedView consults handlers, so a hidden agent page blocks even when opening its editor is suppressed.

The tracked map is renderer-local and reconstructed after reload.
