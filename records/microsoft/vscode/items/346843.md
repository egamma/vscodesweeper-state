# Issue #346843 — Hidden browser pages from idle agent sessions block unattended restarts for updates

[https://github.com/microsoft/vscode/issues/346843](https://github.com/microsoft/vscode/issues/346843)

## Summary

Keep open for the assigned 1.148.0 milestone. Current source still lets hidden agent pages block unattended updates and ties session cleanup to editor-opening history rather than authoritative page ownership.

## Change summary

Prevent unused hidden agent pages from blocking unattended updates, and close agent-owned pages when their session is archived or removed.

## Best solution

Honor actual session ownership for browser-page cleanup, including background-created and re-adopted pages. Restart eligibility should preserve user-used page state without treating untouched hidden pages from idle agents as blockers.
