# Issue #346843 — Hidden browser pages from idle agent sessions block unattended restarts for updates

[https://github.com/microsoft/vscode/issues/346843](https://github.com/microsoft/vscode/issues/346843)

## Summary

Keep open: current source still lets hidden agent pages veto unattended updates and ties session cleanup to editor opening rather than agent ownership. The assigned 1.147.0 release milestone also requires keeping this scheduled work open.

## Change summary

Prevent unused hidden agent pages from blocking unattended updates and close agent-owned pages when their session is archived or removed.

## Best solution

Make browser cleanup follow the actual owning session, including background-created and re-adopted pages. Restart eligibility should distinguish unused hidden agent pages from pages whose user state needs protection, while preserving running-agent blockers.
