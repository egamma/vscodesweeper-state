# Issue #231304 — Folders in explorer disappear when clicked

[https://github.com/microsoft/vscode/issues/231304](https://github.com/microsoft/vscode/issues/231304)

## Summary

Verified duplicate: the older open issue reports the same observable symptom—folders governed by nested `.gitignore` files remain visible until expansion and then disappear—and owns the same Explorer filtering defect.

## Change summary

With `explorer.excludeGitIgnore` enabled, opening a folder can cause that folder itself to disappear because a pattern in its nested `.gitignore` is applied to the containing directory.

## Best solution

Consolidate the fix under https://github.com/microsoft/vscode/issues/210341 and correct the Explorer ignore evaluation so a nested `.gitignore` applies only to paths beneath its containing directory, while retaining lazy folder resolution.
