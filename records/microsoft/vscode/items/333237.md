# Issue #333237 — "suggestWidget" reappearing after closing with the Esc "Escape" key

[https://github.com/microsoft/vscode/issues/333237](https://github.com/microsoft/vscode/issues/333237)

## Summary

Freshly filed, detailed repro with clear steps, and already assigned to hediet (owner of inline-completions/NES work) — a strong signal the team recognizes this as real. I could not confirm on current main via static tracing alone (the interaction is timing/async-dependent), so this needs a live repro rather than a close.

## Change summary

The suggest widget reopens by itself immediately after being dismissed with Escape, specifically when the typed character matches a word already known from earlier typing on the same line, and repeated Escape presses cannot close it.

## Best solution

Trace the interaction between SuggestModel's quick-suggest scheduling/cancellation (src/vs/editor/contrib/suggest/browser/suggestModel.ts, especially `_doTriggerQuickSuggest`/`_waitForInlineCompletionsAndTrigger`) and `cancelSuggestWidget()` in suggestController.ts — a pending async path there looks like the most plausible source of a suggest re-trigger that survives `model.cancel()`. Since hediet is already assigned, this is best left for them to reproduce live and pinpoint rather than guessed at from source alone.
