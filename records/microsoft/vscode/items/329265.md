# Issue #329265 — Support session-scoped model configuration in the Sessions model picker

[https://github.com/microsoft/vscode/issues/329265](https://github.com/microsoft/vscode/issues/329265)

## Summary

Team-authored (benvillalobos, MEMBER) investigation note filed a day ago describing a real gap in the Sessions model picker; no fix commit references this issue, so it stays open per the team-authored protection rule.

## Change summary

The Sessions/automation-dialog model picker doesn't provide a session/provider-scoped `modelConfiguration` delegate, so reasoning-effort/context-size changes leak into the global New Chat widget instead of being scoped to the automation session being edited.

## Best solution

Resume the investigation from the linked spike branch (benvillalobos/vscode bv/automation-model-configuration-spike, commit 47b1788942b) to implement a session-scoped `IModelConfigurationAccess` that `ModelPickerWidget` can read from instead of always falling back to `ILanguageModelsService`.
