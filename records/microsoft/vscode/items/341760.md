# Issue #341760 — Agent Host: remote prompts with command-… source missing from VS Code chat

[https://github.com/microsoft/vscode/issues/341760](https://github.com/microsoft/vscode/issues/341760)

## Summary

Thanks for the detailed report. The source confirms that the Agent Host's user.message handler returns early for any non-'user' source, so remote prompts with source 'command-<id>' never start a turn. The assistant output then hits 'Markdown delta emitted with no active turn; dropping'.

## Change summary

Prompts sent from GitHub.com via /remote on (source 'command-<id>') are not shown in VS Code's Agent Host chat history.

## Best solution

Treat remote command-sourced user.message events as root user prompts: begin a provider-initiated turn showing the prompt text, while still skipping SDK-injected skill and harness messages.
