# Issue #341760 — Agent Host: remote prompts with command-… source missing from VS Code chat

[https://github.com/microsoft/vscode/issues/341760](https://github.com/microsoft/vscode/issues/341760)

## Summary

Keep open: current main still filters out command-sourced remote prompts before creating their chat turns, and history replay excludes them too. The independent confirmation establishes that this also affects local Agent Host sessions, not only Remote-SSH.

## Change summary

Show GitHub.com and GitHub Mobile prompts and their responses in Copilot Agent Host chat, both live and after history restoration.

## Best solution

Recognize remotely submitted human prompts consistently across Copilot live-event handling and history replay while preserving filtering of internal injections and existing subagent routing. A distinct remote-origin badge is an optional follow-up, not a prerequisite for restoring the missing conversation.
