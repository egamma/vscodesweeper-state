## Change summary

The first mouse-wheel notch after finding text in a notebook causes an oversized, sometimes opposite-direction scroll jump.

## Best solution

Make notebook scrolling continue from the displayed search result without an initial discontinuity, preserving normal find navigation and subsequent wheel scrolling. Coordinate the matching newer report at https://github.com/microsoft/vscode/issues/240391 with this older issue.
