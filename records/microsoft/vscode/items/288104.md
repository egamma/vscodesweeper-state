# Issue #288104 — @terminal with #terminalLastCommand did not work 

[https://github.com/microsoft/vscode/issues/288104](https://github.com/microsoft/vscode/issues/288104)

## Summary

The terminal participant remains exposed in the chat view, where combining it with terminal context can fail. Current source preserves this path because terminal `/explain` still depends on it.

## Change summary

Using `@terminal` with `#terminalLastCommand` and `#terminalSelection` produced an unknown-variable reference and no useful answer.

## Best solution

Clarify the terminal participant's supported locations, hide it from ordinary chat completions where possible, and preserve terminal `/explain` through a dedicated invocation path that correctly resolves terminal references.
