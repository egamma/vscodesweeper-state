# Issue #285212 — Add support for webview.hide() and webview.collapse() in the API

[https://github.com/microsoft/vscode/issues/285212](https://github.com/microsoft/vscode/issues/285212)

## Summary

Legitimate API gap: `WebviewView` exposes `show()` and `visible`/`onDidChangeVisibility` but has no programmatic `hide()` or `collapse()`. No duplicate found. The request is in the backlog-candidates community process with 0 upvotes and 30 days remaining.

## Change summary

Add `hide()` and/or `collapse()` methods to the `WebviewView` extension API so extensions can programmatically dismiss or collapse their webview views.

## Best solution

Add a `hide()` method (or a combined visibility setter) to the `WebviewView` interface in `src/vscode-dts/vscode.d.ts`, backed by the existing `_setVisible` plumbing in `src/vs/workbench/api/common/extHostWebviewView.ts`. This mirrors the show/hide symmetry already present on `OutputChannel`, `Terminal`, and `StatusBarItem`. The community process will determine if there is enough demand.
