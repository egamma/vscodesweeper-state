# Issue #270514 — `Install Specific Extension` behaves different in extension view vs extension page

[https://github.com/microsoft/vscode/issues/270514](https://github.com/microsoft/vscode/issues/270514)

## Summary

The bug remains source-reproducible on current main: the Extensions view command discards the selected extension instance's location and resolves the first matching local entry, so a locally installed copy can be targeted instead of the Dev Container copy. This team-authored Backlog bug should remain open for a bounded fix.

## Change summary

Installing a specific extension version from the Extensions view can update the local copy instead of the selected Dev Container copy.

## Best solution

Make the Extensions view's specific-version action preserve the selected extension-management server, matching the extension details page, and cover the local-plus-remote case with a focused regression test.
