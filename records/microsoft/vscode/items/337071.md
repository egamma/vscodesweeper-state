# Issue #337071 — Use a single virtualized tree for the Chat Customizations page

[https://github.com/microsoft/vscode/issues/337071](https://github.com/microsoft/vscode/issues/337071)

## Summary

Legitimate, unimplemented architectural improvement: the Chat Customizations page currently renders each source as a separate WorkbenchList inside a manually-toggled collapsible section (confirmed in aiCustomizationListWidget.ts and customizationCardList.ts), matching the described nested-scroll/scroll-trapping problem exactly, with no unified-tree rework found on main.

## Change summary

Replace the per-source separate virtualized lists on the Chat Customizations page with a single virtualized tree to fix nested-scroll trapping and wasted horizontal space.

## Best solution

Rework aiCustomizationListWidget.ts / customizationCardList.ts to use a single WorkbenchObjectTree (or WorkbenchCompressibleObjectTree) with source headers as top-level collapsible nodes and per-item renderers, following the Explorer/Breakpoints pattern, while preserving expand/collapse persistence, accessibility, keyboard nav, and filtering.
