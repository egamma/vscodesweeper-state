# Issue #324910 — Terminal title overlaps with action buttons when panel is moved to the side and tabs are collapsed

[https://github.com/microsoft/vscode/issues/324910](https://github.com/microsoft/vscode/issues/324910)

## Summary

Confirmed visual bug on current main: the `.single-terminal-tab` flex container lacks overflow constraints, so long terminal titles overflow into action buttons when tabs are collapsed in side-panel mode. An open community PR already targets this.

## Change summary

Terminal title text overlaps action buttons when the panel is docked to the side and tabs are collapsed to single-tab mode with a long title.

## Best solution

Review and land the open community PR https://github.com/microsoft/vscode/pull/325078, which wraps the title text in a constrained span with `overflow: hidden; text-overflow: ellipsis` — the standard pattern already used by `.monaco-icon-label` elsewhere in the terminal.
