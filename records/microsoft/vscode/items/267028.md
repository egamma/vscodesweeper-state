# Issue #267028 — Shell integration leaks variables

[https://github.com/microsoft/vscode/issues/267028](https://github.com/microsoft/vscode/issues/267028)

## Summary

The reported Bash namespace pollution remains in current main: all five named variables are assigned globally. Keep this accepted shell-integration debt open; the related PowerShell cleanup does not resolve the Bash implementation.

## Change summary

Prevent Bash shell integration from introducing unnamespaced internal variables that collide with user scripts.

## Best solution

Keep persistent Bash integration state consistently namespaced and initialization-only state out of the user's ordinary variable namespace, while preserving existing user variables and environment-reporting behavior.
