# Issue #189265 — VsCode does not recognise the "U" key ("unknown" key in shortcut)

[https://github.com/microsoft/vscode/issues/189265](https://github.com/microsoft/vscode/issues/189265)

## Summary

This is a duplicate of #72947 — on Linux, Ctrl+Shift+U is intercepted by the ibus input method for Unicode character entry, causing VS Code to receive an unidentifiable keypress. This is an upstream platform/input-method issue, not a VS Code bug.

## Change summary

Ctrl+Shift+U is reported as 'unknown' in the keybinding recorder on Linux because ibus intercepts the key combination for Unicode input.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/72947 which already documented this as an upstream ibus/input-method issue. The workaround is to disable the Unicode input shortcut in ibus-setup or use a different keybinding.
