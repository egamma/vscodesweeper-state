## Summary

The redundant checkpoint writes remain on current main: eligible unchanged turns still create two commits and update a ref per repository. Keep this open in agent-host; the source confirms the report without requiring another reproduction from the reporter.

## Change summary

Avoid redundant checkpoint commits and ref writes for unchanged agent turns while preserving accurate per-turn diffs across repositories.

## Best solution

Unchanged turns should avoid redundant Git writes without changing checkpoint lookup, comparison, or cleanup behavior. Preserve first-turn and partially changed multi-repository checkpoints; assess reusable temporary indexes separately from the bounded commit-elision fix.
