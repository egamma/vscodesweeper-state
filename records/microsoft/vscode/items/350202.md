# Issue #350202 — Agent host: every turn writes a "turn start" commit and a turn commit even when neither tree changed

[https://github.com/microsoft/vscode/issues/350202](https://github.com/microsoft/vscode/issues/350202)

## Summary

The redundant commit creation remains directly traceable on current main. Keep this open to eliminate unchanged-tree checkpoint commits while preserving turn diffs and restore behavior.

## Change summary

Avoid creating two checkpoint commits for an agent-host turn whose start and end trees are unchanged.

## Best solution

Unchanged turns should retain valid checkpoint lookup, diff and restore results without creating redundant commits. Keep temporary-index reuse as a separate optimization unless its correctness and lifecycle can be established within the same bounded change.
