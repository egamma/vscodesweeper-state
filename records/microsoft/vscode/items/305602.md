# Issue #305602 — Bring back the 'Used references' indication for instructions

[https://github.com/microsoft/vscode/issues/305602](https://github.com/microsoft/vscode/issues/305602)

## Summary

Current main still deliberately suppresses the “Used references” UI for the default agent, so the requested instruction visibility remains missing. This team-authored feature request should stay open for a product decision on restoring all references or introducing an instruction-specific indication.

## Change summary

Restore a visible indication of which instruction files were used by an agent response.

## Best solution

Give users a discoverable, per-response indication of the instruction files supplied to the agent while preserving the intended reduction of unrelated reference noise in default agent mode.

  > After an agent response uses instruction files, the user can discover which instruction files were supplied without asking the model or inspecting request logs. Responses without applied instructions do not show a misleading instruction indication. Existing reference behavior in non-default modes remains unchanged unless the maintainer explicitly chooses a broader restoration.
- **Trace:**

  > The removal was intentional in https://github.com/microsoft/vscode/pull/296144. On current main, the `references` branch in src/vs/workbench/contrib/chat/browser/widget/chatListRenderer.ts returns `renderNoContent` for the default agent, even though `ChatUsedReferencesListContentPart` in src/vs/workbench/contrib/chat/browser/widget/chatContentParts/chatReferencesContentPart.ts can still render the reference list. The instruction collection and attachment path is outside this request: the boundary is visibility of already-reported references, and instruction application semantics must not change. The uncertainty starts at the desired presentation and scope—whether default agent mode should restore the complete generic reference list or expose only applied instructions.
- **Open decisions:**
  - Should default agent responses restore the complete “Used references” list, or show a separate instruction-only indication while continuing to hide other references?
  - Should the instruction indication appear on every response that receives instructions, or only when expanded or explicitly requested by the user?
