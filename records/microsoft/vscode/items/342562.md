# Issue #342562 — Compare agent messes up model filtering in model picker tabs

[https://github.com/microsoft/vscode/issues/342562](https://github.com/microsoft/vscode/issues/342562)

## Summary

Comparison mode overwrites model-provider grouping with execution-harness identity, which makes OpenRouter models from the Copilot harness qualify for the Copilot tab. Keep this team-authored report open; the source confirms the classification problem, but the intended relationship between harness tabs and provider tabs needs clarification.

## Change summary

Prevent comparison mode from incorrectly presenting OpenRouter models as Copilot-provided models.

## Best solution

Preserve an accurate distinction between a model's provider and its execution harness throughout comparison selection, while retaining cross-harness comparisons. Settle how those two identities should appear in the picker before changing the existing harness-tab behavior.
