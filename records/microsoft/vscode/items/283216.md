# Issue #283216 — Chat: Copy/Insert Buttons should always be visible

[https://github.com/microsoft/vscode/issues/283216](https://github.com/microsoft/vscode/issues/283216)

## Summary

A real usability gap remains: code-block actions are positioned at the block header and leave the viewport when scrolling through long code. The request should remain open for UX discussion.

## Change summary

Keep Chat code-block Copy, Insert, and Run actions accessible while scrolling through a long response.

## Best solution

Keep the active code block's toolbar pinned within that block while it intersects the Chat viewport, retaining existing hover, focus, and screen-reader behavior without adding an always-on global toolbar.
