# Issue #23757 — Allow project specific keybindings

[https://github.com/microsoft/vscode/issues/23757](https://github.com/microsoft/vscode/issues/23757)

## Summary

Keep this canonical feature request open in the Backlog. The capability remains absent on main, has 117 community upvotes, and continues to absorb newer duplicate reports.

## Change summary

Allow a workspace or project to define keybindings that override user-level bindings, with appropriate conflict and trust handling.

## Best solution

Add a workspace-scoped keybinding source to the workbench keybinding service, with explicit precedence, Workspace Trust enforcement, platform handling, and disclosure before project-provided bindings become active.
