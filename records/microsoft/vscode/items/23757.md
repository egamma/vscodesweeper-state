# Issue #23757 — Allow project specific keybindings

[https://github.com/microsoft/vscode/issues/23757](https://github.com/microsoft/vscode/issues/23757)

## Summary

Keep open: current keybinding loading remains profile-scoped, so repository-local overrides are still missing. This accepted Backlog request has 118 upvotes; the matching newer report cannot replace it under the re-review rules.

## Change summary

Allow project-local keybindings to override user and default shortcuts, with user control over accepting those overrides.

## Best solution

Resolve the product contract for repository-local shortcut overrides, including consent, precedence, and platform handling, before extending the keybinding surface. Profiles and conditional user shortcuts should remain available, but neither replaces portable project-owned bindings.
