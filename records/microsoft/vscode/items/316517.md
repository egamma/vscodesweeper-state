# Issue #316517 — Allow configuring which editor group Ctrl+Click "Go to Definition" opens in

[https://github.com/microsoft/vscode/issues/316517](https://github.com/microsoft/vscode/issues/316517)

## Summary

Genuine feature request with no existing setting or open duplicate covering it. The Backlog Candidates community process is running — let it play out.

## Change summary

Add a setting to control which editor group Ctrl+Click Go to Definition opens in, so split-editor workflows can default to opening definitions beside the current editor.

## Best solution

If the community process promotes it: add a setting (e.g. `editor.gotoDefinition.targetGroup`) and thread it through `GotoDefinitionAtPositionEditorContribution.gotoDefinition()` in `src/vs/editor/contrib/gotoSymbol/browser/link/goToDefinitionAtPosition.ts`, overriding the hardwired `hasSideBySideModifier` boolean with a configurable default. The `DefinitionAction` and `_openReference` in `goToCommands.ts` already support `openToSide`; the plumbing is minimal.
