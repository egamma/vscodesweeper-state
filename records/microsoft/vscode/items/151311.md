# Issue #151311 — editor.actions.findWithArgs behaves inconsistently when searchString is empty

[https://github.com/microsoft/vscode/issues/151311](https://github.com/microsoft/vscode/issues/151311)

## Summary

The bug remains on current main: an explicitly empty `searchString` is treated as absent and can be overwritten by selection or clipboard seeding. The variable-substitution request is separately covered by an open canonical issue.

## Change summary

`editor.actions.findWithArgs` inconsistently replaces an explicitly empty search string with seeded editor text.

## Best solution

Preserve any explicitly supplied `searchString`, including `""`, in `CommonFindController._start`; only seed from the selection or find clipboard when the argument is undefined. Continue tracking general keybinding variable substitution in https://github.com/microsoft/vscode/issues/140136.
