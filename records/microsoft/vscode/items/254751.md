# Issue #254751 — Visual Studio Code reopens after closing

[https://github.com/microsoft/vscode/issues/254751](https://github.com/microsoft/vscode/issues/254751)

## Summary

Unexpected restart after closing with a pending update is a recognized bug, but related reporters now report resolution. Ask whether this still occurs on the latest stable build before proposing a close or further implementation.

## Change summary

VS Code reopens after all Windows windows are closed with the X button, briefly showing an update window despite no explicit restart request.

## Best solution

Closing the last window should leave VS Code closed even when an update is pending. Confirm whether the current Windows updater still violates that expectation; if it does, use updater and lifecycle logs to distinguish normal-close behavior from an explicit restart.
