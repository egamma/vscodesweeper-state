# Issue #339860 — Send button gets cut off in the grid

[https://github.com/microsoft/vscode/issues/339860](https://github.com/microsoft/vscode/issues/339860)

## Summary

Credible, screenshot-backed layout bug in the new Agents Window sessions grid: at the grid's minimum cell width the chat input doesn't truncate correctly, clipping the send button. Already correctly labeled bug/chat-input; keeping open for a maintainer to pick the fix direction.

## Change summary

When a session chat view is sized down to the sessions grid's minimum width, the composer's send button gets cut off instead of the input truncating to keep it visible.

## Best solution

Either raise AbstractChatView.minimumWidth (src/vs/sessions/browser/parts/chatView.ts, currently 200) so the grid never squeezes a cell below what the input toolbar needs, or make the chat input/execute-toolbar (src/vs/workbench/contrib/chat/browser/widget/media/chat.css, .chat-input-toolbars / .chat-execute-toolbar) shrink the text area before the send button is affected — a maintainer should pick one, since they trade off differently against how many sessions fit on screen.
