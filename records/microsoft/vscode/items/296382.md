# Issue #296382 — New model picker is not kb/screen reader friendly

[https://github.com/microsoft/vscode/issues/296382](https://github.com/microsoft/vscode/issues/296382)

## Summary

The keyboard accessibility defect remains present on current main, but an open PR directly fixes it. Keep the issue open while that human-owned implementation candidate is reviewed.

## Change summary

Pressing Enter on the model picker's "Other model" section does not expand it, although Space does.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/296512, which makes the Enter action toggle a focused section before falling back to accepting a normal item.
