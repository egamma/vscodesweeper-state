# Issue #196483 — Relaunch terminal hides terminal after reloading window

[https://github.com/microsoft/vscode/issues/196483](https://github.com/microsoft/vscode/issues/196483)

## Summary

Still reproduces: after window reload, clicking 'Relaunch Terminal' from the env variable contribution status hides the terminal panel. No fix commit references this issue, and a Nov 2025 comment confirms it persists.

## Change summary

Relaunching a terminal after window reload hides the terminal panel instead of keeping it visible.

## Best solution

The relaunch flow in `terminalInstance.ts` needs to ensure the terminal panel remains visible. The likely fix is in the interaction between `relaunch()` → `reuseTerminal()` → `_processManager.relaunch()` and the `onDidChangeActiveInstance` listener in `terminalService.ts` (line ~210) that calls `hidePanel()` when the active instance becomes undefined. Either the relaunch should suppress the hide-on-last-closed behavior, or the panel visibility should be explicitly restored after relaunch completes.
