# Issue #196483 — Relaunch terminal hides terminal after reloading window

[https://github.com/microsoft/vscode/issues/196483](https://github.com/microsoft/vscode/issues/196483)

## Summary

This bug was fixed by commit b625e085b74 (PR #276420), which resolved the identical issue #228359. The root cause was that `attachPersistentProcess` remained set during relaunch after window reload, causing the terminal to attempt reattaching to the old (dead) process instead of creating a new one, hiding the panel.

## Change summary

Relaunching a terminal after reloading the window hides the terminal panel instead of creating a new process.

## Best solution

Already fixed in 1.107.0 — the fix clears `attachPersistentProcess` before relaunch. Close as duplicate of the resolved #228359.
