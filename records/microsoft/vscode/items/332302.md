# Issue #332302 — Agents Window: Files tab should show the file tree when no file is open

[https://github.com/microsoft/vscode/issues/332302](https://github.com/microsoft/vscode/issues/332302)

## Summary

Keep open: current layout handling covers revealing the Files tree when its tab is activated, but does not establish the requested fallback across last-file closure and session restoration. This team-authored request is not fully covered by the related reports or by a verified fixing commit.

## Change summary

Make the workspace file tree the Files tab's default content whenever no file editor remains, including across session changes and restoration.

## Best solution

Make the desktop Files lifecycle consistently return to usable workspace browsing after the last file closes, while preserving explicit user dismissal of the Files tab or whole side pane. Coordinate the draft, existing-session, and managed-tab behavior rather than treating activation alone as completion.
