# Issue #330379 — A minor cosmetic issue regarding Modern UI.

[https://github.com/microsoft/vscode/issues/330379](https://github.com/microsoft/vscode/issues/330379)

## Summary

Traced in source: with `workbench.experimental.modernUI` enabled, the tab close/action button is deliberately overlaid on top of the label via `position: absolute` (src/vs/workbench/contrib/styleOverrides/browser/media/tabs.css, rules gated by `.modern-ui-tabs`), rather than reserving trailing space as the classic tab style does — so it can visually sit over the filename/Git-status glyph, matching the report exactly. This is by design per the code comment, but the rough edge (overlap while hovering, and uneven left/right spacing once the label re-flows) is legitimate feedback on an actively-developed experimental feature, so I'd route it to the area owners rather than declare it as-designed or close it.

## Change summary

In the experimental Modern UI tab style, the close button visually overlaps the filename/Git-status icon on hover, and leaves uneven spacing afterward.

## Best solution

Route to the workbench-tabs/styleOverrides owners to decide whether the overlay approach in src/vs/workbench/contrib/styleOverrides/browser/media/tabs.css (`.tab-actions { position: absolute; ... }`, ~lines 260-297) needs a label-width reservation or fade tweak so the button doesn't visually collide with the filename; this is an active experimental feature (`workbench.experimental.modernUI`) still being iterated on, not a settled contract.

- **experimental gating:** The `.modern-ui-tabs` class is toggled by `workbench.experimental.modernUI` (src/vs/workbench/services/layout/browser/layoutService.ts:54, src/vs/workbench/contrib/styleOverrides/browser/styleOverrides.contribution.ts), confirming this is opt-in/experimental, not the default stable experience.
- **hover-only background:** The action button only gets a covering background/gradient on `:hover`/`:focus-within` (tabs.css lines 287-297), so in the non-hovered state the icon floats transparently over label text with no background — plausible source of the overlap the reporter describes.
