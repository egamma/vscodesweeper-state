# Issue #330379 — A minor cosmetic issue regarding Modern UI.

[https://github.com/microsoft/vscode/issues/330379](https://github.com/microsoft/vscode/issues/330379)

## Summary

Traced this in the current styleOverrides tabs.css: Modern UI tabs deliberately overlay the close/pin action absolutely on top of the tab label (comment: "Overlay tab actions on the label instead of reserving a trailing/leading column") rather than reserving flex space for it, and the label's padding-right is explicitly zeroed for shrink/fixed sizing. That's an intentional layout choice, but it plausibly produces the exact overlap/uneven-whitespace the reporter describes, and the file was actively touched the day before/after this report (PR #330669), so it's still being iterated on rather than settled.

## Change summary

In the experimental Modern UI tabs, the close (X) button on file tabs overlaps the filename/Git-status icon on hover instead of sitting beside it as in 1.131 and earlier, and the reporter asks whether this is intentional or a bug, requesting a revert setting either way.

## Best solution

Belongs with the Modern UI tabs work in src/vs/workbench/contrib/styleOverrides/browser/media/tabs.css (the `.tab-actions` overlay rules around the 'Overlay tab actions on the label' comment, and the `padding-right: 0` rule for `.sizing-shrink/.sizing-fixed` `.tab-label`). A maintainer familiar with the Modern UI design intent should confirm whether the overlay-on-hover behavior is final, or whether the label truncation/gradient needs tightening so text doesn't visually collide with the action icon.
