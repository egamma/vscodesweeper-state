# Issue #330379 — A minor cosmetic issue regarding Modern UI.

[https://github.com/microsoft/vscode/issues/330379](https://github.com/microsoft/vscode/issues/330379)

## Summary

This is the same defect already reported, fixed, and closed as completed in the canonical https://github.com/microsoft/vscode/issues/329605 — the Modern UI close-button overlay was reserved as real padding instead of overlapping the label, and current main confirms the fix is present.

## Change summary

In Modern UI (workbench.experimental.modernUI), the tab close button overlaps the filename/git-status icon instead of sitting in its own reserved space, causing accidental tab closes and uneven padding on hover.

## Best solution

Keep the shipped fix from commit 9de2f4de3a7ba83d9a5cc96003ff49d81b26f651 (merged via PR #330754 on 2026-08-14) — it reserves a 28px right-hand column (24px on the left for tabActionsLocation: left) for the close/pin/dirty overlay via the `tab-actions-reserve-space` CSS class and the `workbench.editor.tabActionReserveSpace` setting (default true), so the control no longer overlaps the label's hit target.
