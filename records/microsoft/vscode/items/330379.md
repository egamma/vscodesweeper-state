# Issue #330379 — A minor cosmetic issue regarding Modern UI.

[https://github.com/microsoft/vscode/issues/330379](https://github.com/microsoft/vscode/issues/330379)

## Summary

The reported filename overlap and accidental-close target were addressed by a merged fix that reserves a separate column for tab actions. Current main retains this behavior by default and exposes workbench.editor.tabActionReserveSpace to keep that space reserved.

## Change summary

Prevent Modern UI tab close buttons from covering filenames and Git badges or intercepting clicks intended to activate a tab.

## Best solution

Close as completed by commit 851a360639cd70543a2ef6e19b921ac1d226118d and retain workbench.editor.tabActionReserveSpace: true for predictable separation between filenames and close controls. The newer opt-out truncation report at https://github.com/microsoft/vscode/issues/340848 tracks a distinct remaining case.
