# Issue #293085 — For the extended LanguageModelChatProvider, the context indicator is always 0.

[https://github.com/microsoft/vscode/issues/293085](https://github.com/microsoft/vscode/issues/293085)

## Summary

The defect remains on current main: extension-contributed models that do not emit Copilot's private usage data part are assigned synthetic zero-token usage, causing the context indicator to show 0% rather than being hidden. A maintainer explicitly confirmed that the indicator should be hidden for these providers.

## Change summary

The chat context-window indicator shows zero or stale usage for models contributed through LanguageModelChatProvider even when provideTokenCount works.

## Best solution

Treat absent response usage as unavailable rather than zero, and clear or hide the context indicator after a completed request without usage data. Providers that emit supported usage data should continue to receive live context-window updates.
