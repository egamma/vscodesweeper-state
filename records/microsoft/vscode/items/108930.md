# Issue #108930 — Add color customization for editor action icons

[https://github.com/microsoft/vscode/issues/108930](https://github.com/microsoft/vscode/issues/108930)

## Summary

The existing icon.foreground setting covers product/font-based editor actions, but not arbitrary extension-supplied image icons discussed in this thread. Keep the accepted Backlog discussion open: automatic SVG recoloring was subsequently reverted for compatibility, so that implementation does not establish completion.

## Change summary

Allow theme color customization of editor toolbar icons, including extension-contributed icons that currently retain their image colors.

## Best solution

Retain the existing icon.foreground support and determine whether extension-supplied image icons need an additional opt-in theming contract without destroying their intentional colors or state indicators. Any additional capability belongs in shared command/menu icon rendering, not editor-specific CSS.
