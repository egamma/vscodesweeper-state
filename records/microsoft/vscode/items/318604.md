# Issue #318604 — AgentHost: Remote session stops updating after connection change

[https://github.com/microsoft/vscode/issues/318604](https://github.com/microsoft/vscode/issues/318604)

## Summary

Team-filed bug (MEMBER author) about remote agent host sessions going stale after network reconnection — must stay open for maintainer judgment.

## Change summary

Remote agent host sessions stop rendering updates after a network-triggered reconnection, because a stale ChatModel kept alive by requestInProgressKeepAlive is reused instead of going through provideChatSessionContent.

## Best solution

Fix the reconnection path so that when a remote AH session is re-subscribed after a connection change, the stale ChatModel is either invalidated or the full content from the agent host is properly rendered through provideChatSessionContent rather than silently consumed by the kept-alive model.
