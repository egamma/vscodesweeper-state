# Issue #318604 — AgentHost: Remote session stops updating after connection change

[https://github.com/microsoft/vscode/issues/318604](https://github.com/microsoft/vscode/issues/318604)

## Summary

Keep open while the directly linked fix in https://github.com/microsoft/vscode/pull/329876 is under review. The issue has a concrete lifecycle diagnosis, and the open PR adds targeted reconnect and stale-model coverage rather than providing grounds to close before merge.

## Change summary

After a remote Agent Host connection is replaced, a completed session can remain displayed as in progress because VS Code reuses a stale ChatModel kept alive by the interrupted request.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/329876, ensuring obsolete handler-owned turns settle and the replacement connection cannot reuse the retired ChatModel generation while preserving existing transcript and input state.
