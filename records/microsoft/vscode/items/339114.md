# Issue #339114 — Provide an option to install a specific version of VS Code within the app

[https://github.com/microsoft/vscode/issues/339114](https://github.com/microsoft/vscode/issues/339114)

## Summary

Keep this accepted Backlog request open: existing update controls can defer updates, but do not let users select and install a particular VS Code release within the app. No verified canonical issue was found.

## Change summary

Allow users to choose and install a specific VS Code release within the application instead of downloading and replacing it manually.

## Best solution

The install-update area should assess an on-demand release-selection workflow, including supported platforms and subsequent automatic-update behavior. Existing update timing controls and local-installer commands do not cover the requested experience.

## Evidence

- **Existing settings do not select releases:** src/vs/platform/update/common/update.config.contribution.ts registers update.mode with none, manual, start, and default options. These control update checks, not the target release; update.channel is deprecated in favor of update.mode.
- **Existing commands provide only partial coverage:** src/vs/workbench/contrib/update/browser/update.ts registers check, download, install, and restart actions without a release selector. In src/vs/workbench/contrib/update/browser/update.contribution.ts, _update.applyupdate exposes Developer: Apply Update from File only on Windows and requires an already-downloaded .exe. It does not provide in-app release discovery or download.
- **Update service boundary:** src/vs/platform/update/common/update.ts exposes checkForUpdates(explicit), downloadUpdate(explicit), applyUpdate(), and quitAndInstall() without a target-release parameter. Its _applySpecificUpdate(packagePath) accepts a local package path rather than a version; the abstract implementation in src/vs/platform/update/electron-main/abstractUpdateService.ts is a no-op.
- **Related issue is not a canonical:** https://github.com/microsoft/vscode/issues/263827 is open and older, but concerns disabling automatic updates after installing a specific extension version, as indicated by its extensions label. It does not own selecting a VS Code application release.
