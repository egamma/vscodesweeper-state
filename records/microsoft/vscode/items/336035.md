# Issue #336035 — Comment thread reply area does not collapse on blur: expand class toggled on different elements

[https://github.com/microsoft/vscode/issues/336035](https://github.com/microsoft/vscode/issues/336035)

## Summary

Confirmed in source: the expand/collapse toggle and the blur-check use different DOM elements, so the reply area never auto-collapses on blur. This is a small, well-localized fix in commentReply.ts.

## Change summary

The comment thread reply editor stays expanded after losing focus with empty content, instead of collapsing back to the single 'Reply...' row.

## Best solution

In src/vs/workbench/contrib/comments/browser/commentReply.ts, make createReplyButton's blur handler (and the text-model listener at line 275) toggle 'expand' on this._container instead of the commentForm/this._form element, matching expandReplyArea/hideReplyArea and the review.css selector '.comment-form-container.expand'.
