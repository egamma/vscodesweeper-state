# Issue #279375 — Use hover service not `title` for hovers in models and agent dropdown

[https://github.com/microsoft/vscode/issues/279375](https://github.com/microsoft/vscode/issues/279375)

## Summary

The inconsistency remains on current main: action-list rows in the model and agent pickers still use native `title` tooltips while the dropdown button uses the managed hover service. This is a bounded workbench-hover polish item with enough source evidence to remove `info-needed` and route it to the hover/action-widget owners.

## Change summary

Use VS Code managed hovers instead of browser-native `title` tooltips for model and agent dropdown rows.

## Best solution

Make action-widget row tooltips and keybinding hints use the existing hover service with mouse-aware placement, while preserving rich expandable hovers, disabled-item labeling, and rows that intentionally suppress tooltips.
