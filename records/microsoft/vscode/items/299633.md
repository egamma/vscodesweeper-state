# Issue #299633 — Clarify meaning of "Workspace" and "Worktree" in UI

[https://github.com/microsoft/vscode/issues/299633](https://github.com/microsoft/vscode/issues/299633)

## Summary

Keep open: the Copilot CLI isolation picker still offers Workspace and Worktree without explaining either choice. This team-authored request has a concrete remaining gap; the related newer Agents Window work does not qualify as a duplicate canonical.

## Change summary

Explain the difference between running a Copilot CLI session in the workspace and in an isolated Git worktree at the point of selection.

## Best solution

Make the isolation choice self-explanatory with concise, accessible text describing where each mode edits files. Agree on inline descriptions versus hover-only help without changing isolation behavior or expanding this into a cross-surface redesign.
