# Issue #322201 — Context window dial assumes 1M tokens when 200K tokens are selected

[https://github.com/microsoft/vscode/issues/322201](https://github.com/microsoft/vscode/issues/322201)

## Summary

The Agent Host context-size mismatch was fixed after this report. Current main uses the selected numeric context tier when calculating the usage dial denominator, so a selected 200K window no longer displays usage against 1M.

## Change summary

Make the context-window usage dial calculate its percentage against the selected 200K tier rather than the model's 1M maximum.

## Best solution

Keep the context-size handling shipped by commit 54f316d4c09162e589080df3054a6f876dff1ba7, which exposes Agent Host tiers as numeric context sizes and uses the selected tier for the dial denominator.
