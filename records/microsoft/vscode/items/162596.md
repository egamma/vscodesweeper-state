# Issue #162596 — Settings UI shows no warning (and possibly an incorrect value) when an invalid enum is in settings.json

[https://github.com/microsoft/vscode/issues/162596](https://github.com/microsoft/vscode/issues/162596)

## Summary

The defect remains in current source: an invalid enum value silently selects the first dropdown option without displaying a validation warning. The linked validation PR was closed without merging, so it does not establish a fix.

## Change summary

Show a validation warning in the Settings UI when a configured enum value is invalid, rather than silently presenting a valid option as its value.

## Best solution

Make enum settings communicate invalid configured values clearly and accessibly in the Settings UI, without changing the stored value or the value extensions receive. Preserve normal selection and editing for valid enum values.
