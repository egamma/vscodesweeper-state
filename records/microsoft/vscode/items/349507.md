# Issue #349507 — Unable to paste screenshots into the 'Answer' area when the agent is asking follow-up questions

[https://github.com/microsoft/vscode/issues/349507](https://github.com/microsoft/vscode/issues/349507)

## Summary

Screenshot answers remain unsupported in the structured follow-up form. Keep this open as a capability request: the current answer editor and provider response contract carry text, not image attachments.

## Change summary

Allow pasted screenshots to accompany answers to agent follow-up questions.

## Best solution

Support image-bearing follow-up answers end to end, including preview and delivery to the requesting agent, while preserving ordinary text answers and compatibility with text-only elicitation schemas.

## Evidence

- **Reported trigger:** https://github.com/microsoft/vscode/issues/349507 supplies Windows Insiders build details, paste steps, and an ask_user requestedSchema containing two string fields. Pasting the requested screenshot into Answer produces image.png rather than an image attachment.
- **Existing capability boundary:** src/vs/workbench/contrib/chat/browser/widget/chatContentParts/chatQuestionAnswerEditor.ts implements a free-text Monaco editor with a string value and no attachment model or paste-target registration. chatQuestionCarouselPart.ts creates this editor and reads its string value for text answers.
- **Image paste pipeline:** src/vs/workbench/contrib/chat/browser/widget/input/editor/chatPasteProviders.ts:117-120 requires a registered IChatPasteTarget to attach pasted image bytes. The answer editor does not register one. Existing chat.inlineAttachments.enabled controls attachment presentation in the chat composer, not attachment support in answer forms.
- **Provider contract:** src/vs/platform/agentHost/node/copilot/copilotAgentSession.ts maps string schema fields to ChatInputQuestionKind.Text in elicitationFieldToQuestion and maps text answers back to scalar strings in askUserAnswerToFieldValue. Image delivery would require more than displaying a preview.
- **Related report, not a verified canonical:** https://github.com/microsoft/vscode/issues/316242 was verified open and requests screenshot input during choices-array multiple-choice ask_user prompts, including their Other field. It is closely related, but does not explicitly own the multi-field requestedSchema elicitation flow reported here; consolidating the broader structured-form requirement into that narrower report is not established.
