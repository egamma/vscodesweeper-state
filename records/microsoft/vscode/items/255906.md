# Issue #255906 — Variable substitution in enum properties of `launch.json` causes un-suppressable warnings

[https://github.com/microsoft/vscode/issues/255906](https://github.com/microsoft/vscode/issues/255906)

## Summary

Keep open: launch configuration schemas still validate literal enum values without accommodating substitution in otherwise supported properties. The existing debug label is appropriate; the example involving `type` needs separate treatment because debugger selection precedes substitution.

## Change summary

Avoid misleading enum-validation warnings for supported variable substitutions in launch.json without disabling unrelated validation.

## Best solution

Provide targeted handling for substitution-bearing enum properties while retaining diagnostics for invalid literal values. Establish which launch properties actually support substitution before choosing between launch-specific schema handling and a general diagnostic-suppression feature.
