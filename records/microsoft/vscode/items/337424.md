# Issue #337424 — Renaming a chat session in the Chat sidebar fails silently

[https://github.com/microsoft/vscode/issues/337424](https://github.com/microsoft/vscode/issues/337424)

## Summary

Confirmed from source: ChatSessionStore.setSessionTitle updates the in-memory index cache but never calls flushIndex(), so a rename of a session whose ChatModel isn't loaded in memory (i.e. never opened as an editor tab) is never persisted to storage and silently reverts — this matches the reporter's exact workaround.

## Change summary

Renaming a chat session from the sidebar Sessions list (without ever opening it as an editor tab) doesn't stick — no error, no persistence.

## Best solution

Add the missing `await this.flushIndex()` call inside `ChatSessionStore.setSessionTitle` (src/vs/workbench/contrib/chat/common/model/chatSessionStore.ts, ~line 510-517), matching every other index mutator in that class (deleteSession, clearAllSessions, etc.), so the renamed title is actually written to storage regardless of whether the session model is loaded.
