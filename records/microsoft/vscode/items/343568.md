# Issue #343568 — DevContainer Remote Agent: remove remote doesn't work

[https://github.com/microsoft/vscode/issues/343568](https://github.com/microsoft/vscode/issues/343568)

## Summary

Keep open: the Environment picker's Remove Remote action can leave a registered Dev Container visible because it falls back to disconnecting instead of unregistering the workspace. This is an Agents Window core issue, already carrying the appropriate area label.

## Change summary

Removing a Dev Container remote through the Environment picker's Manage menu should remove its registered picker entry.

## Best solution

Make the Dev Container provider's removal contract forget the registered workspace and remove its provider, consistently with the existing Remotes management flow. Preserve ordinary disconnect behavior and do not delete the underlying container.
