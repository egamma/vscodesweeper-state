# Issue #313403 — agents-app (inders) - already open project in devcontainer (in vscode) does open in local folder (in agents-app)

[https://github.com/microsoft/vscode/issues/313403](https://github.com/microsoft/vscode/issues/313403)

## Summary

Dev Container handoff from “Open in Agents” is now implemented on main. The originating container workspace is mapped back to its host folder and Dev Container execution is preselected when the supported setting is enabled.

## Change summary

Opening the Agents Window from a VS Code window attached to a Dev Container should preserve that container execution context instead of selecting the local host folder.

## Best solution

Keep the shipped handoff implemented by https://github.com/microsoft/vscode/commit/c772f67cd2f65a6998276becb4e1f2059e24116f; users can enable `chat.agentHost.devContainer.enabled` to run the resulting Agent Host session in the project’s Dev Container.
