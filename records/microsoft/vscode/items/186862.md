# Issue #186862 — Terminal tabs are re-rendered several times on start up

[https://github.com/microsoft/vscode/issues/186862](https://github.com/microsoft/vscode/issues/186862)

## Summary

Creating additional terminal tabs still triggers consecutive full-list renders in current source, including two structural notifications for the same populated group. Keep this performance bug open; the related single-tab issue is newer and concerns a different rendering surface.

## Change summary

Avoid redundant terminal-tab rendering when creating the second and third terminal tabs.

## Best solution

Remove redundant rendering work in the terminal tabs refresh path while retaining timely updates for actual membership, title, icon, status, selection, and layout changes.
