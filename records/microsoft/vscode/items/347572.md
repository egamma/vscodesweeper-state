# Issue #347572 — Prompt-to-skill migration does not preserve relative Markdown links

[https://github.com/microsoft/vscode/issues/347572](https://github.com/microsoft/vscode/issues/347572)

## Summary

Confirmed in current source: prompt-to-skill migration preserves the body verbatim while changing its directory, breaking relative Markdown links. Keep open for a bounded migration fix.

## Change summary

Preserve relative Markdown link targets when converting prompt files into skills.

## Best solution

The generated SKILL.md should resolve relative Markdown links to their original repository targets regardless of the selected destination, while leaving absolute links unchanged.
