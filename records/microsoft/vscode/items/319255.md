# Issue #319255 — Custom Endpoint vision attachments stop working when using BYOK without GitHub sign-in

[https://github.com/microsoft/vscode/issues/319255](https://github.com/microsoft/vscode/issues/319255)

## Summary

Fixed on main: PR #323965 ('GA vision in vs code') removed the preview-feature gate that blocked image attachments for BYOK models without GitHub sign-in. The original fix PR #322199 was closed as superseded by this broader change.

## Change summary

Image attachments are silently dropped when using a BYOK custom endpoint model without being signed into GitHub, because the vision path was gated behind a Copilot preview-features check.

## Best solution

Keep the shipped fix from commit f170fd1f23d — no further change needed. The preview-feature gate has been removed entirely, so vision works regardless of GitHub sign-in state.
