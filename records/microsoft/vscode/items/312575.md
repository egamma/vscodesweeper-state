## Summary

The reported focus transfer is potentially serious, but the report combines several possible triggers and does not identify which control receives focus. Current main contains guards for known cross-chat focus paths, so confirmation on the latest build with precise reproduction details is needed.

## Change summary

Prevent background VS Code or chat-window updates from moving keyboard focus and accidentally accepting or rejecting prompts.

## Best solution

Determine which background event and UI component moves focus, then preserve the active window and focused control unless the user explicitly activates the notification or prompt. First confirm whether the remaining behavior comes from core Chat, the Claude Code extension, or another installed extension.
