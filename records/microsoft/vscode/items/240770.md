# Issue #240770 — Git diff does not show files with long paths in Source Control View (Windows)

[https://github.com/microsoft/vscode/issues/240770](https://github.com/microsoft/vscode/issues/240770)

## Summary

Real bug on Windows — the git extension doesn't pass `-c core.longpaths=true` to git invocations, so files with paths exceeding MAX_PATH (260 chars) are silently dropped from the Source Control view. An open community PR (https://github.com/microsoft/vscode/pull/310058) addresses it; keep open pending review/merge of that PR.

## Change summary

Git diff in the Source Control view silently omits files whose absolute path exceeds Windows MAX_PATH (260 characters), even though terminal `git diff` shows them.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/310058, which injects `-c core.longpaths=true` into every git spawn on Windows. The approach is non-invasive (process-scoped, Windows-only, idempotent). The fix lives in `extensions/git/src/git.ts`.
