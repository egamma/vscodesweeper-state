Keep this accepted browser playback request open: it has 21 upvotes, and related reports document continuing media limitations. The older AAC request covers part of the problem, but does not establish that this broader video-playback request is a duplicate.

Support video playback in the integrated browser so developers can test media functionality without leaving VS Code.
