# Issue #289795 — Enable Video Playback in Simple Browser's Integrated Browser for Web Testing

[https://github.com/microsoft/vscode/issues/289795](https://github.com/microsoft/vscode/issues/289795)

## Summary

Valid feature request — the Simple Browser's iframe sandbox (`allow-scripts allow-forms allow-same-origin allow-downloads`) does not include media permissions, so video playback is blocked. The newer integrated browser (browserView) uses Electron's WebContentsView which supports video natively, but the Simple Browser extension remains unchanged. Keeping open in the Backlog.

## Change summary

Enable video playback in the Simple Browser extension's embedded iframe by adding appropriate sandbox permissions for media.

## Best solution

Either add `allow-autoplay` (and potentially other media-related sandbox attributes) to the iframe in `extensions/simple-browser/src/simpleBrowserView.ts`, or guide users toward the newer integrated browser (browserView) which supports video natively via Electron's WebContentsView. If the Simple Browser remains the entry point for lightweight web previews, the sandbox attribute update is the right fix.
