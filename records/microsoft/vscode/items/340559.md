[https://github.com/microsoft/vscode/issues/340559](https://github.com/microsoft/vscode/issues/340559)

## Summary

Keep open for investigation of enterprise sign-in after migrating to the plural setting. The authentication implementation changed recently, and the supplied migration steps suffice to retest; neither a subsequent fix nor an equivalent open duplicate was established.

## Change summary

Replacing github-enterprise.uri with github-enterprise.uris reportedly removes the enterprise sign-in option and prevents authentication.

## Best solution

A correctly configured single enterprise instance should retain usable authentication when moved to github-enterprise.uris. Investigate configuration resolution, credential migration, and Accounts menu visibility in the built-in GitHub Authentication extension before attributing the failure to a consumer extension.
