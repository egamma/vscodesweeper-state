# Issue #317930 — Error serializing chat session for storage.

[https://github.com/microsoft/vscode/issues/317930](https://github.com/microsoft/vscode/issues/317930)

## Summary

This is a duplicate of the canonical issue #308843, which tracked the 'RangeError: Invalid string length' crash during chat session serialization. The root cause — unbounded tool-result storage making JSON.stringify exceed V8's string-length limit — was fixed in commit eb308be4f9d and shipped in 1.123.0. The reporter was on 1.121.0, which predates the fix.

## Change summary

Chat session serialization fails with 'RangeError: Invalid string length' when a session contains very large tool results, causing loss of chat context on reload.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/308843 — the fix shipped in 1.123.0 (commit eb308be4f9d) with additional hardening in e266aa425b9. The reporter should update to the latest stable build.
