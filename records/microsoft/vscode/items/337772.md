# Issue #337772 — Setting to output file extension in tabs as part of file name

[https://github.com/microsoft/vscode/issues/337772](https://github.com/microsoft/vscode/issues/337772)

## Summary

The requested control is still missing: connected tabs preserve the extension separately while truncating the filename. Existing tab settings do not provide ordinary whole-filename truncation, and the older readability report does not establish a verified duplicate under the re-review rules.

## Change summary

Allow file extensions to remain part of the truncatable tab filename instead of reserving an always-visible suffix.

## Best solution

Have the workbench-tabs owner decide whether connected tabs should offer ordinary whole-filename truncation as an option or revise the shared default. Preserve filename identification and accessibility without requiring users to widen tabs or rewrite their displayed filenames.
