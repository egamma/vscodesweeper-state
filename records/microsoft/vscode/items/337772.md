# Issue #337772 — Setting to output file extension in tabs as part of file name

[https://github.com/microsoft/vscode/issues/337772](https://github.com/microsoft/vscode/issues/337772)

## Summary

Verified duplicate: the older open issue tracks the same connected-tab behavior that preserves the extension while aggressively abbreviating the more useful filename. Its broader request to restore normal shrinking and wrapping fully covers this report.

## Change summary

Allow file extensions to truncate with the rest of an editor tab label instead of reserving space for them at all times.

## Best solution

Resolve https://github.com/microsoft/vscode/issues/337476 by making connected editor tabs honor normal shrink and wrap behavior, including allowing the filename suffix to truncate; this avoids adding another narrowly scoped setting.
