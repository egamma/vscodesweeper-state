# Issue #281810 — Don't expand to show the same thing

[https://github.com/microsoft/vscode/issues/281810](https://github.com/microsoft/vscode/issues/281810)

## Summary

Implemented on current main: a completed Thinking group containing exactly one tool and no reasoning now removes the redundant wrapper and restores the tool directly to the chat transcript.

## Change summary

Avoid requiring users to expand a Thinking block when its only child is the same single fetch or tool call they want to inspect.

## Best solution

Keep the single-tool promotion implemented by commit 5b9be8ab46c34ce0e0818901ae6f8ec1e9ca5023; it presents the fetch directly while retaining grouped Thinking UI for responses with reasoning or multiple items.
