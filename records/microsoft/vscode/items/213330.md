# Issue #213330 — VSCode does not honor LSP-advertised capabilities when displaying inlay hints menu

[https://github.com/microsoft/vscode/issues/213330](https://github.com/microsoft/vscode/issues/213330)

## Summary

The reported mismatch remains in current source: the inlay-hint menu includes registered navigation actions without checking their provider-dependent visibility conditions. Keep this open; the existing inlay-hints routing is appropriate.

## Change summary

Make location-bearing inlay hints omit navigation menu entries unsupported by the referenced document's language providers.

## Best solution

The inlay-hint navigation menu should reflect the capabilities available for its referenced location, consistently with ordinary symbol navigation, while retaining supported actions and any explicit label-part command.
