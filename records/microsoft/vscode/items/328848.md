# Issue #328848 — Align subagent rendering between tool and chat pill

[https://github.com/microsoft/vscode/issues/328848](https://github.com/microsoft/vscode/issues/328848)

## Summary

Keep open for a design decision: later changes improved the subagent pill substantially, but current main still uses distinct aggregate and per-invocation presentations, and the discussion never settled how model information, progress, and width constraints should align. The issue is team-authored, and none of the likely-covering commits or PRs explicitly references this issue, so an implemented-on-main close is unavailable.

## Change summary

Align the visual hierarchy, progress treatment, and container styling of subagent tool rendering with the Agents Window subagent status pill.

## Best solution

Define one consistent subagent visual language while preserving the different roles: the input pill summarizes multiple background activities, whereas the in-response pill represents one invocation and can expose its model, duration, progress, and active tool. Confirm the intended information hierarchy with design, then cover the agreed states in component fixtures.
