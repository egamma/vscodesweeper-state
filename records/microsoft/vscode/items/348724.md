# Issue #348724 — Restore Checkpoint leaves an empty file instead of undoing its creation

[https://github.com/microsoft/vscode/issues/348724](https://github.com/microsoft/vscode/issues/348724)

## Summary

Keep open: current source contains a live-versus-persisted file-creation mismatch consistent with this report. Current checkpoint restoration also refreshes authoritative turn changesets, so the supplied steps suffice to retest whether that path overrides the incorrect live metadata.

## Change summary

Restoring a checkpoint before an agent-created file should remove the file rather than leave it empty.

## Best solution

Make live and restored file-edit metadata preserve the same distinction between nonexistent files and existing empty files, so checkpoint undo and redo behave consistently without restarting.
