# Issue #306268 — Show all approved command with arguments even though the command tool is approved completely

[https://github.com/microsoft/vscode/issues/306268](https://github.com/microsoft/vscode/issues/306268)

## Summary

Keep open: current approval management displays stored argument-specific approvals, but disabling whole-tool approval explicitly deletes them. The central request to return to granular approvals without losing the earlier choices remains unmet.

## Change summary

Allow users to inspect and retain argument-specific command approvals when enabling and subsequently disabling whole-tool approval.

## Best solution

Make whole-tool approval independently reversible while preserving previously granted argument-specific approvals in the tool approval manager. Keep an explicit way to revoke those granular approvals without conflating that action with disabling blanket approval.
