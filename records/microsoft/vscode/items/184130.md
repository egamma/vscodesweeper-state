Verified duplicate: this reports the same bug as #234504 (web worker extension host incorrectly started on restart), which was fixed by PR #234505 (commit 81e10ad4f26) and is now closed. Proposing duplicate close.

## Change summary

Restarting the extension host incorrectly starts the web worker extension host even when no pure web extensions are installed.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/234504, which received the fix in PR #234505 — the LazyCreateExtensionHostManager was refactored to properly handle lazy auto-start and avoid spurious web worker extension host launches on restart.
