# Issue #328385 — Clicking on a comment should open the Changes editor with the comment

[https://github.com/microsoft/vscode/issues/328385](https://github.com/microsoft/vscode/issues/328385)

## Summary

This is a valid Agents window interaction gap: comments are previewed in a hover, while activation does not open the Changes editor with the full comment. The existing agents-window and polish labels already route it correctly.

## Change summary

Make clicking a feedback comment open the session Changes editor and reveal the complete comment.

## Best solution

Keep the hover as a preview, but route comment activation through the session Changes editor and set its navigation anchor so the relevant file, range, and full comment are revealed.
