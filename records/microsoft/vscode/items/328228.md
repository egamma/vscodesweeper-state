# Issue #328228 — Running Azure Foundry BYOK causes Github pro+ account limit enforcement

[https://github.com/microsoft/vscode/issues/328228](https://github.com/microsoft/vscode/issues/328228)

## Summary

The reporter reconfirmed this on current stable, and the source shows GitHub quota state is maintained globally without regard to the selected BYOK provider. Keep open as a Copilot core bug requiring model-aware quota handling.

## Change summary

Selecting an Azure Foundry BYOK model still triggers GitHub Copilot quota enforcement and Auto-mode behavior after the account quota is exhausted.

## Best solution

Ensure quota gating and Auto fallback apply only to Copilot-backed requests, preserving the explicitly selected non-Copilot model through endpoint selection and response handling in the Copilot extension.
