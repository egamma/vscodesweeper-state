[https://github.com/microsoft/vscode/issues/291526](https://github.com/microsoft/vscode/issues/291526)

## Summary

The linked merged PR addressed the default agent icon and description, not the full picker-alignment request. Current source still shows filename descriptions and lacks the cloud picker's configuration action and grouping, so this team-authored issue should remain open.

## Change summary
