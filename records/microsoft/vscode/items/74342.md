# Issue #74342 — [themes] Allow to set a background color for settings / webview editors

[https://github.com/microsoft/vscode/issues/74342](https://github.com/microsoft/vscode/issues/74342)

## Summary

Valid feature request for a dedicated background color for the settings editor and webview editor panes, distinct from `editor.background`. The settings color registry has tokens for individual controls (dropdowns, checkboxes, rows) but no overall page-level background. Still unimplemented on main.

## Change summary

Allow theme authors to set a separate background color for non-code editor panes like the settings editor and webview editors.

## Best solution

Register a new theme color (e.g. `settings.background`) in `settingsEditorColorRegistry.ts` that defaults to `editor.background` but can be overridden by themes. Similarly consider a webview-editor-level background token. This is a small, self-contained theming addition that fits the `help wanted` label well.
