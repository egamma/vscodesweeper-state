# Issue #211684 — Accessibility: "Show All Symbols" command doesn't speak file names and paths

[https://github.com/microsoft/vscode/issues/211684](https://github.com/microsoft/vscode/issues/211684)

## Summary

The omission remains reproducible from current source: workspace symbol results explicitly set their accessible label to the symbol name, excluding the visually displayed file path. Keep this open; the cause is bounded and ready for implementation.

## Change summary

Make workspace symbol results announce their symbol name and identifying file information when navigating with a screen reader.

## Best solution

Expose the displayed file name and workspace-relative path in each workspace symbol result's accessible name so identically named symbols can be distinguished without opening them. Preserve existing search, sorting, visual descriptions, and navigation behavior.
