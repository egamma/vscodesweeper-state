# Issue #260493 — "settingsSync.ignoredSettings" entries display as invalid if they're settings from disabled extensions

[https://github.com/microsoft/vscode/issues/260493](https://github.com/microsoft/vscode/issues/260493)

## Summary

Keep open as a settings-validation improvement: the current schema restricts ignored-setting entries to registered settings, while the sync implementation accepts additional setting names. No verified older canonical issue or fixing commit was found.

## Change summary

Avoid invalid-value warnings for settingsSync.ignoredSettings entries belonging to extensions disabled outside their enabled workspace.

## Best solution

Make ignored-settings validation accommodate legitimate extension setting names when the extension is temporarily disabled, while preserving useful completions and existing sync exclusions. The settings owner should decide how to distinguish unavailable settings from misspelled names.
