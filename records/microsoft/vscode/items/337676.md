# Issue #337676 — Setting or memory for the default agent harness in the main window (Welcome page / chat panel always start on Copilot)

[https://github.com/microsoft/vscode/issues/337676](https://github.com/microsoft/vscode/issues/337676)

## Summary

Keep open: main-window chat already has persisted harness selection for the panel and editor, but the Welcome page still initializes its own Local session without consulting that preference. The existing capability therefore does not cover the full request.

## Change summary

Allow new chats across the main window to consistently start with the user's preferred agent harness, including after restart.

## Best solution

Make the Welcome page, chat panel, and chat editor consistently honor the existing remembered harness preference, subject to availability and enterprise policy. Investigate the reported panel reset during startup before introducing a second preference setting.
