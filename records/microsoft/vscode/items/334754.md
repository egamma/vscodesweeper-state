# Issue #334754 — Resizable content hover doesn't work

[https://github.com/microsoft/vscode/issues/334754](https://github.com/microsoft/vscode/issues/334754)

## Summary

Well-documented, recent report (with video) that the resizable content hover disappears as soon as a resize is attempted; I traced the relevant guard logic on main (resizableContentWidget.ts, contentHoverController.ts, contentHoverWidgetWrapper.ts) and it appears structurally correct, so the root cause isn't conclusively pinned down — this needs a live debugging session rather than a source-only read, so it stays open rather than being closed or auto-fixed.

## Change summary

Attempting to resize the content hover via its sash causes the hover to disappear instead of resizing.

## Best solution

A maintainer familiar with src/vs/editor/contrib/hover/browser/{resizableContentWidget.ts,contentHoverController.ts,contentHoverWidgetWrapper.ts} should live-debug the resize interaction (mousedown-on-sash vs. editor mouse-down/leave handlers, `isResizing` timing) to find why the hide guard isn't preventing dismissal, then add a regression test for hover-resize interaction.
