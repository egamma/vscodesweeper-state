# Issue #334754 — Resizable content hover doesn't work

[https://github.com/microsoft/vscode/issues/334754](https://github.com/microsoft/vscode/issues/334754)

## Summary

Fresh, detailed report (with video) that starting a drag on the resizable content hover's sash causes the hover to disappear instead of resizing; the hover controller already has an `isResizing` guard meant to prevent exactly this, so either that guard is racing with the mouse-move hide path or something in the very recent Electron/Chromium bump (42.10.0 / 148.0.7778.280) is interfering with sash mousedown capture. Needs area routing and a maintainer/engineer to confirm on a stable build.

## Change summary

Attempting to drag-resize the resizable content hover (introduced in 1.80) makes the hover close instead of resizing.

## Best solution

Route to the editor/hover area for investigation; check whether ContentHoverController._shouldKeepHoverWidgetVisible's `isResizing` flag (set in resizableContentWidget.ts via onDidWillResize) is actually true at the moment the mousemove-hide check runs, and whether the very new Electron/Chromium build changes sash mousedown/pointer-capture timing.
