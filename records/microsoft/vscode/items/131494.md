# Issue #131494 — [scss] Hover hint doesn't support SCSS Interpolation syntax

[https://github.com/microsoft/vscode/issues/131494](https://github.com/microsoft/vscode/issues/131494)

## Summary

A real capability gap remains in the CSS language service's SCSS selector printer: it handles direct parent selectors such as `&__bar`, but does not evaluate the equivalent `#{&}__paragraph` interpolation. The issue should remain open and be tracked as upstream work rather than closed.

## Change summary

Resolve SCSS parent-selector interpolation when rendering selector previews in hover hints.

## Best solution

Add interpolation-aware parent-selector rendering and regression coverage in `microsoft/vscode-css-languageservice`, then consume the updated language-service dependency in VS Code.

- **upstream source gap:** Current selector printing at https://github.com/microsoft/vscode-css-languageservice/blob/1c00d690ee38c7dfb137df8de1a6ddf571ea9b36/src/services/selectorPrinting.ts expands `&` only when a simple-selector child is `NodeType.SelectorCombinator`; there is no branch that evaluates an SCSS `Interpolation` node containing the parent selector.
- **upstream test coverage:** https://github.com/microsoft/vscode-css-languageservice/blob/1c00d690ee38c7dfb137df8de1a6ddf571ea9b36/src/test/scss/selectorPrinting.test.ts covers `&__bar` and related direct parent selectors, but has no `#{&}` interpolation case.
