# Issue #277300 — Google Authentication stopped working in 1.106

[https://github.com/microsoft/vscode/issues/277300](https://github.com/microsoft/vscode/issues/277300)

## Summary

Fixed in 1.106.2 — the `http.systemCertificatesNode` setting was enabled by default in 1.106.0 (commit 30878bf7c96), which broke SSL certificate verification for extensions making outbound HTTPS requests (including the Colab extension hitting Google OAuth). Commit 16cd8a75cc7 disabled it by default again, shipping in 1.106.2.

## Change summary

Google authentication via the Colab extension broke in VS Code 1.106 due to an SSL certificate verification failure ('unable to get issuer certificate') caused by a change in how system certificates were loaded.

## Best solution

Keep the shipped fix — `http.systemCertificatesNode` defaults to `false` on current main. No further change is needed. Users who still need Node.js system certificate loading can opt in via the setting.
