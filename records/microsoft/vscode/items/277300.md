# Issue #277300 — Google Authentication stopped working in 1.106

[https://github.com/microsoft/vscode/issues/277300](https://github.com/microsoft/vscode/issues/277300)

## Summary

This is a duplicate of the certificate-handling regression on macOS in 1.106 that was tracked and fixed via #284800. The root cause — expired/conflicting certificates in the macOS Keychain causing 'unable to get issuer certificate' errors — was addressed by @vscode/proxy-agent 0.37.0, shipped in 1.109.

## Change summary

Extensions making HTTPS requests (here Google Colab auth) fail with 'unable to get issuer certificate' on macOS after upgrading to VS Code 1.106.

Consolidate on https://github.com/microsoft/vscode/issues/284800, which tracked the same macOS certificate regression, collected multiple duplicates, and was fixed by the proxy-agent 0.37.0 update in 1.109. No further action needed beyond closing as duplicate.
