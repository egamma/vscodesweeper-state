# Issue #277300 — Google Authentication stopped working in 1.106

[https://github.com/microsoft/vscode/issues/277300](https://github.com/microsoft/vscode/issues/277300)

## Summary

This is a confirmed instance of the system-certificate behavior tracked by the broader open networking issue; enabling Node system certificates restores Colab authentication on affected macOS environments.

## Change summary

Google Colab OAuth token refresh fails after upgrading to VS Code 1.106 because the issuer certificate cannot be validated.

## Best solution

Consolidate the certificate-loading work on https://github.com/microsoft/vscode/issues/287739, including this report's macOS, Google corporate environment, and Colab OAuth evidence.
