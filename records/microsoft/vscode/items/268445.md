# Issue #268445 — Issue Reporter window orphaned after running `Developer: Reload Window` command

[https://github.com/microsoft/vscode/issues/268445](https://github.com/microsoft/vscode/issues/268445)

## Summary

Still valid on main: the default (legacy) issue reporter opens in a separate auxiliary window that becomes orphaned after reload. The new EditorPane-based wizard (behind `issueReporter.wizard.enabled`, default false) would fix this, but it is experimental and not yet the default path.

## Change summary

The Issue Reporter window becomes non-functional after running Developer: Reload Window because the auxiliary window is orphaned from the reloaded main window.

## Best solution

Either promote the new wizard as the default issue reporter (removing the legacy auxiliary-window path), or fix the legacy reporter's lifecycle to handle reloads. The wizard approach (PR #317577, commit 4e538f26ea3) is the team's stated direction per the MEMBER comment.
