# Issue #256324 — We should show test progress inline inside chat

[https://github.com/microsoft/vscode/issues/256324](https://github.com/microsoft/vscode/issues/256324)

## Summary

PR #257350 moved the tests tool to core with incremental progress updates, partially addressing the request. The author reopened the issue for the remaining ask: a collapsible tree view rendered inline inside chat showing test results. That capability does not exist on current main — the tool reports progress via ToolProgress but does not render an inline tree widget. Keeping open as a valid, unfinished feature request.

## Change summary

Show test results as a collapsible tree view rendered inline inside chat responses, rather than opening the testing view.

## Best solution

Extend the testing chat agent tool (src/vs/workbench/contrib/testing/common/testingChatAgentTool.ts) to emit a rich inline tree widget in chat showing test pass/fail results with collapsible hierarchy, rather than only text-based progress. This likely involves a new chat content part or tool result renderer in the chat contribution area that can display a WorkbenchObjectTree of test results inline.
