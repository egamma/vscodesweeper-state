## Summary

Keep open for a product-curation decision: the existing recommendation engine supports the requested matching, and the Svelte precedent supports considering it. The public checkout contains no recommendation for this extension, but it does not establish the recommendation configuration shipped in Microsoft's distribution.

Recommend deltaxml.xslt-xpath when users open .xsl or .xslt files or select the built-in xsl language.
