# Issue #290708 — If multiple instances of VSCode are opened for different git worktrees, the git editor is opened in the main worktree VSCode instance

[https://github.com/microsoft/vscode/issues/290708](https://github.com/microsoft/vscode/issues/290708)

## Summary

Keep open: current source still routes linked-worktree Git metadata files to the main worktree's window. An open PR explicitly targets this issue and should be reviewed before considering completion.

## Change summary

Open commit-message and interactive-rebase editors in the window belonging to the initiating linked worktree rather than the main worktree.

## Best solution

Review and, if correct, land https://github.com/microsoft/vscode/pull/335634 so window selection recognizes linked-worktree metadata ownership while preserving ordinary file-routing behavior. Keep this issue open until that implementation is merged and verified.
