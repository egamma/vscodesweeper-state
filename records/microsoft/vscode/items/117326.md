# Issue #117326 — Allow moving the floating debug.toolbar everywhere

[https://github.com/microsoft/vscode/issues/117326](https://github.com/microsoft/vscode/issues/117326)

## Summary

Keep open as an accepted Backlog feature request: the docked toolbar and “Start Additional Session” command provide a workaround, but they do not satisfy the requested combination of a visible configuration selector, multi-session launching, and a non-obstructing toolbar location. The related reports are newer and closed, so none qualifies as a canonical duplicate under the re-review rule.

## Change summary

Allow the floating debug toolbar to be placed in a fixed, non-obstructing location while retaining configuration selection and support for starting multiple debug sessions.

## Best solution

Provide a supported debug-toolbar placement in a predictable workbench location that does not cover editor tabs, while preserving the configuration selector and multi-session controls; the debug and workbench layout owners should decide the exact host surface.
