# Issue #132208 — Git - git warnings show an error popup with cancel button

[https://github.com/microsoft/vscode/issues/132208](https://github.com/microsoft/vscode/issues/132208)

## Summary

Keep open: Git's generic command-error presentation still uses an error modal with a Cancel dismissal and a single-line summary. Related open reports and a proposed warning-classification fix cover parts of the request, but none owns its full presentation scope.

## Change summary

Distinguish Git warnings from errors, use an acknowledgment rather than a misleading Cancel button, and retain useful diagnostic context.

## Best solution

Review the warning-classification work in https://github.com/microsoft/vscode/pull/327894, then settle the remaining Git-specific acknowledgment and modality behavior here. Preserve actionable failures as errors and retain access to complete command output rather than treating every warning-looking first line as a successful operation.
