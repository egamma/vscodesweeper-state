# Issue #292807 — Constant popup of "Diff Algorithm has stopped after 5000 ms" when running a agent session

[https://github.com/microsoft/vscode/issues/292807](https://github.com/microsoft/vscode/issues/292807)

## Summary

Keep open to decide how diff timeouts should be presented during background agent edits. The current warning path remains unconditional for non-embedded diff editors, and changing the computation limit does not deliver the requested contextual tolerance.

## Change summary

Avoid repeated intrusive diff-timeout warnings during background agent edits without requiring users to change the default computation limit.

## Best solution

Provide a less disruptive presentation of incomplete diffs during background agent activity while retaining useful feedback when users inspect changes. Decide the notification policy separately from improving the diff algorithm's performance.
