# Issue #292807 — Constant popup of "Diff Algorithm has stopped after 5000 ms" when running a agent session

[https://github.com/microsoft/vscode/issues/292807](https://github.com/microsoft/vscode/issues/292807)

## Summary

Keep open: current source still requests a warning whenever a non-embedded diff reports a timeout, without distinguishing background agent activity. The existing timeout setting does not satisfy the request to reduce interruptions while preserving the default computation limit.

## Change summary

Make diff-timeout notifications less intrusive during background agent editing without requiring users to increase or disable the computation timeout.

## Best solution

Establish a less intrusive notification policy for background agent diffs, then apply it in DiffEditorHelperContribution while preserving computation limits and useful feedback for explicitly opened comparisons.
