# Issue #306273 — Lots of powershell command approvals needed for troubleshooting

[https://github.com/microsoft/vscode/issues/306273](https://github.com/microsoft/vscode/issues/306273)

## Summary

Valid UX friction report from a team member: the troubleshooting feature generates many sequential command approvals, especially painful on Windows where native sandboxing isn't yet available. Stays open as a team-authored item with no fix landed.

## Change summary

Agent troubleshooting runs many shell commands in sequence, each requiring a separate user approval, creating excessive friction.

## Best solution

Batch related diagnostic commands into a single approval prompt, or allow the troubleshooting tool to auto-approve its own read-only diagnostic commands within the sandbox. The Windows sandbox gap (noted in comments) is a prerequisite for the sandbox-based workaround.
