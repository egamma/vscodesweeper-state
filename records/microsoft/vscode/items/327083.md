## Summary

The "Change Completions Model" command exists in the codebase but is gated behind the context key `github.copilot.completions.hasMultipleModels`, which is only true when the user's account/subscription provides access to multiple completion models. The documentation describes a feature that is conditionally available, and the reporter's account may not currently have multiple models enabled. Additionally, documentation issues belong in microsoft/vscode-docs, not here.

## Change summary

User cannot find the "Change Completions Model" option in the UI despite it being described in VS Code documentation.

## Best solution

If the concern is that the documentation is misleading for users without multi-model access, the reporter should file a docs issue at https://github.com/microsoft/vscode-docs. The feature itself works as intended — it's gated on `github.copilot.completions.hasMultipleModels` (set in `extensions/copilot/src/extension/completions-core/vscode-node/extension/src/modelPicker.ts`) and only surfaces when the backend provides multiple completion models for the user's account.
