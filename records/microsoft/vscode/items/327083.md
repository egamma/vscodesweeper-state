# Issue #327083 — documentation is lying again on BYOK

[https://github.com/microsoft/vscode/issues/327083](https://github.com/microsoft/vscode/issues/327083)

## Summary

The missing picker is explained by intentional availability gating: it appears only when multiple eligible Copilot completion models are available. The current documentation explicitly describes this restriction and distinguishes completion models from BYOK chat models.

## Change summary

Explain why the documented Change Completions Model option is absent and whether inline suggestions have a model-selection setting.

## Best solution

Answer the availability question with the existing command and setting, without treating BYOK chat models as eligible completion models. Keep the separate request for BYOK inline completions tracked in https://github.com/microsoft/vscode/issues/318545.

## Evidence

- **Documented availability restriction:** https://code.visualstudio.com/docs/agent-customization/language-models#_change-the-model-for-inline-suggestions currently states: 'When no alternative models are available, the option to change the model is not available.' Its BYOK section and FAQ explicitly exclude inline suggestions from BYOK support. This establishes the current explanation, not when the documentation changed.
- **Intentional command and menu gating:** extensions/copilot/package.json:3053-3057 registers github.copilot.chat.openModelPicker with enablement requiring extension activation, desktop, and github.copilot.completions.hasMultipleModels. ModelPickerManager.hasMultipleModels() in extensions/copilot/src/extension/completions-core/vscode-node/extension/src/modelPicker.ts requires more than one eligible model; statusBarPicker.ts:66-84 independently applies the same restriction to the menu item.
- **Existing setting:** extensions/copilot/package.json:3408-3411 registers github.copilot.selectedCompletionModel as a string setting with an empty default. The report's assertion that no settings key exists is therefore not true of current main.
- **Completion models are separate from chat models:** AvailableModelsManager in extensions/copilot/src/extension/completions-core/vscode-node/lib/src/openai/model.ts obtains completion models through IEndpointProvider.getAllCompletionModels(), filters for capabilities.type === 'completion', and rejects selected IDs outside that list. Configuring a BYOK chat or utility model does not populate this picker.
- **Related issue verified, not a duplicate of this question:** https://github.com/microsoft/vscode/issues/318545 is open and requests custom endpoints and BYOK support for inline completions. That is an additional capability, whereas this report asks why an existing documented command and setting cannot be found. No open canonical for the missing-command question was verified.

The explanation at https://github.com/microsoft/vscode/issues/336431#issuecomment-5791545935 distinguishes completion models from general-purpose models; the reporter acknowledges that distinction in https://github.com/microsoft/vscode/issues/336431#issuecomment-5791655788.
