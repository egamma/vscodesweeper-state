# Issue #128527 — editor.scrollbar.scrollByPage doesn't work correctly when Option-clicking (Mac)

[https://github.com/microsoft/vscode/issues/128527](https://github.com/microsoft/vscode/issues/128527)

## Summary

Still unimplemented on main: the scrollbar click handler in abstractScrollbar.ts checks `_scrollByPage` but never inspects `altKey` to invert the behavior, so the macOS convention of Option-clicking to toggle between page-scroll and jump-to-position is not honored. Valid enhancement for Mac platform parity.

## Change summary

Option-clicking in the scrollbar track on macOS should invert the `scrollByPage` behavior (jump to position vs. scroll by page), matching native macOS scrollbar conventions.

## Best solution

Add an `altKey` check in `AbstractScrollbar._onPointerDown` (src/vs/base/browser/ui/scrollbar/abstractScrollbar.ts, around line 226) to invert the `_scrollByPage` logic on macOS when Option is held, matching native AppKit scrollbar behavior. This is a small, localized change.
