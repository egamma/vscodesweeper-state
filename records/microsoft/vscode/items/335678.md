# Issue #335678 — Opening an automations file should show an action to import/add the automation

[https://github.com/microsoft/vscode/issues/335678](https://github.com/microsoft/vscode/issues/335678)

## Summary

Confirmed gap: there's an `Import Automation` command inside the Agents window automations view (via file-picker), but no action surfaces when a user directly opens an `.automation.md` file in the text editor. This is active, in-development work in the new automations feature area, so it stays open.

## Change summary

When a user opens an automation blueprint (`.automation.md`) file, show an editor action to import/add it, working from both the Agents window and the plain editor (falling back to opening the Agents window and revealing it).

## Best solution

Add an editor contribution (title-bar action or similar) for `.automation.md` files that calls the existing import/blueprint-parsing logic already used by `sessions.automations.import` (src/vs/sessions/contrib/sessions/browser/views/automationsView.ts), and have the editor-window path open/focus the Agents window and reveal the imported automation.
