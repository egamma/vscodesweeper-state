# Issue #307819 — Render snippet description as markdown

[https://github.com/microsoft/vscode/issues/307819](https://github.com/microsoft/vscode/issues/307819)

## Summary

A real capability gap remains on current main, and the request earned the 20 community upvotes required for promotion to the Backlog. It should remain open under the existing snippets and suggest routing.

## Change summary

Allow user-snippet descriptions to contain links and Markdown formatting in completion details.

## Best solution

Add a backward-compatible rich-description property such as `markdownDescription` to the snippet schema and model, then render it through the completion item's Markdown-capable documentation path while preserving plain `description` behavior.
