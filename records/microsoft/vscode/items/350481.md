## Summary

The current source confirms an initial-attachment event-ordering defect that leaves the empty-notebook toolbar permanently visible after inserting cells. Keep this open in the notebook area; no verified duplicate or landed fix was found.

## Change summary

Empty-notebook insertion controls remain permanently visible after the first Code or Markdown cell is added.

## Best solution

Keep the top insertion toolbar's empty-state styling synchronized with cell-count changes from the first model attachment onward, while preserving normal hover and keyboard-focus visibility.
