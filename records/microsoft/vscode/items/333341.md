# Issue #333341 — Toggle block comment edittor focus problem

[https://github.com/microsoft/vscode/issues/333341](https://github.com/microsoft/vscode/issues/333341)

## Summary

Verified duplicate of an open canonical issue from the same reporter describing the identical Ctrl+Shift+A conflict between Toggle Block Comment and Open Agents Window; consolidating there.

## Change summary

On Linux, Ctrl+Shift+A while editor has focus opens the Agents Window instead of toggling block comment, because both commands bind the same key.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/321321 (already labeled bug + agents-window, assigned to a maintainer) — the fix is scoping OpenAgentsWindowAction's keybinding in src/vs/workbench/contrib/chat/electron-browser/agentSessions/agentSessionsActions.ts (line ~140-144) to not fire when the editor has text focus, or otherwise resolving the shortcut clash with editor.action.blockComment's Linux binding in src/vs/editor/contrib/comment/browser/comment.ts (line 145).
