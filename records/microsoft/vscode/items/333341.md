# Issue #333341 — Toggle block comment edittor focus problem

[https://github.com/microsoft/vscode/issues/333341](https://github.com/microsoft/vscode/issues/333341)

## Summary

Verified duplicate of the still-open, maintainer-acknowledged issue #321321 filed by the same reporter — the Agents Window's Ctrl+Shift+A keybinding doesn't check editor focus and beats the editor's block-comment shortcut on the same keys.

## Change summary

On Linux, Ctrl+Shift+A (Toggle Block Comment) opens the Agents Window instead of toggling the comment when the editor has focus.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/321321, where a maintainer already agreed (comment from sandy081) to add an editor-focus check to OpenAgentsWindowAction's keybinding `when` clause in src/vs/workbench/contrib/chat/electron-browser/agentSessions/agentSessionsActions.ts; that fix has not landed on main yet.
