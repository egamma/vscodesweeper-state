# Issue #350325 — Reopen Closed Editor should be per folder location

[https://github.com/microsoft/vscode/issues/350325](https://github.com/microsoft/vscode/issues/350325)

## Summary

Keep open: recently closed editors still share one history across folder locations. This team-authored improvement is scheduled for 1.149.0, and the linked open PR explicitly excludes it.

## Change summary

Save and restore a separate Reopen Closed Editor history for each folder location.

## Best solution

Reopen Closed Editor should restore only editors closed at the current location, preserving each location's history alongside its working set. Coordinate this with the recently opened history work without changing ordinary reopening or batch semantics.
