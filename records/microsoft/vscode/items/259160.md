# Issue #259160 — Cannot use access token for gemini

[https://github.com/microsoft/vscode/issues/259160](https://github.com/microsoft/vscode/issues/259160)

## Summary

This is a request for a new authentication mode rather than a defect: Gemini BYOK intentionally accepts only an API key today. The request remains unimplemented, but the maintainer discussion indicates that the Gemini extension should preferably contribute and manage its authenticated models.

## Change summary

Allow Gemini models in Copilot Chat to authenticate with the OAuth credentials managed by the Gemini extension instead of requiring a Google AI API key.

## Best solution

The Gemini extension should register and manage models authenticated through its own account flow rather than Copilot reading another extension's private credentials file. If the language-model extension API cannot support that integration, the remaining core work should be narrowed to the specific API gap.
