# Issue #310933 — GPT-5.2 in Copilot CLI session target missing xHigh option

[https://github.com/microsoft/vscode/issues/310933](https://github.com/microsoft/vscode/issues/310933)

## Summary

The xHigh reasoning option availability is determined by the Copilot CLI SDK backend (`getAvailableModels()` → `model.supportedReasoningEfforts`), not by VS Code's code. VS Code faithfully displays whatever effort levels the service reports per model. This is an upstream limitation in the Copilot CLI service/SDK, likely tier-gated as a commenter confirmed.

## Change summary

GPT-5.2 xHigh reasoning effort is missing from the model picker when using Copilot CLI session target, but present for Local target.

## Best solution

The fix belongs in the Copilot CLI SDK/service backend — it controls which reasoning effort levels are returned per model per tier. VS Code's code in `extensions/copilot/src/extension/chatSessions/copilotcli/node/copilotCli.ts` correctly passes through `model.supportedReasoningEfforts` from the SDK. Track parity with the linked upstream issue (github/copilot-cli/issues/2725).
