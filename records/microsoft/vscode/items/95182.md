# Issue #95182 — Support "perspectives" like approach in VSCode 

[https://github.com/microsoft/vscode/issues/95182](https://github.com/microsoft/vscode/issues/95182)

## Summary

Keep this canonical backlog request open. Profiles and current layout commands provide partial workarounds, but they do not provide named, independently saved workbench layouts with save, reset, and switch behavior.

## Change summary

Add Eclipse-like perspectives for switching between saved workspace scopes and workbench view layouts.

## Best solution

Implement named layout presets independently of settings profiles, capturing view visibility, locations, dimensions, and editor-group layout with save, reset, rename, delete, and switch commands. Folder scoping can remain with https://github.com/microsoft/vscode/issues/41860 rather than expanding the layout implementation.
