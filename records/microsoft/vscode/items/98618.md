# Issue #98618 — Bulb menu should open immediately after clicking on the info icon in the problems view

[https://github.com/microsoft/vscode/issues/98618](https://github.com/microsoft/vscode/issues/98618)

## Summary

The requested interaction remains absent on current main, and this feature request has reached 20 community upvotes and been promoted to the Backlog. It should remain open for Problems view UX work.

## Change summary

Allow clicking a problem's severity icon to request and immediately present available quick fixes without waiting for the lightbulb.

## Best solution

Let the Problems view icon initiate `getCodeActions` on click and present the resulting actions with suitable loading and no-actions states, while retaining the existing asynchronously discovered lightbulb.
