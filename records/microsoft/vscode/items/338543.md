# Issue #338543 — Progressively disclose advanced new-session options in the Agents window

[https://github.com/microsoft/vscode/issues/338543](https://github.com/microsoft/vscode/issues/338543)

## Summary

The experimental composer already provides a collapsible options tray, but it does not summarize meaningful non-default choices when collapsed. Keep this team-authored request open: the linked implementation merged, but current source does not establish completion of the requested experience.

## Change summary

Group advanced new-session options behind an accessible disclosure with a provider-neutral summary of consequential non-default choices.

## Best solution

Build on the existing experimental tray to expose consequential effective choices without requiring users to expand every picker, preserving the legacy layout and provider boundaries. Resolve the difference between the requested single-focus disclosure and the current screen-reader behavior before completing the experience.
