# Issue #181050 — editor.selectionClipboard option has no effect on vscode.dev

[https://github.com/microsoft/vscode/issues/181050](https://github.com/microsoft/vscode/issues/181050)

## Summary

The bug remains on current main: the listener that suppresses native middle-click paste when `editor.selectionClipboard` is false is still registered only through the desktop workbench contribution, so vscode.dev never installs it.

## Change summary

Make `editor.selectionClipboard: false` suppress middle-click paste in vscode.dev as it does in the desktop application.

## Best solution

Expose the Linux middle-click paste prevention through an editor feature loaded by both standalone/web and workbench editors, while preserving the existing desktop selection-clipboard behavior.
