# Issue #181050 — editor.selectionClipboard option has no effect on vscode.dev

[https://github.com/microsoft/vscode/issues/181050](https://github.com/microsoft/vscode/issues/181050)

## Summary

Still reproduces on main: the SelectionClipboard editor contribution and the LinuxSelectionClipboardPastePreventer workbench contribution both live exclusively in `electron-browser/`, so they are never loaded in the web (vscode.dev). The IEditorFeature approach alexdima suggested has not been applied.

## Change summary

The `editor.selectionClipboard` setting has no effect on vscode.dev because the selection clipboard logic is only registered in the Electron (desktop) layer.

## Best solution

Move the SelectionClipboard contribution from `electron-browser/selectionClipboard.ts` to a browser-compatible registration (e.g. an `IEditorFeature` as alexdima suggested), and port the LinuxSelectionClipboardPastePreventer workbench contribution to the browser layer so that the middle-click paste prevention also works on vscode.dev.
