# Issue #325363 — "Send to a new session" should trigger the create_session tool

[https://github.com/microsoft/vscode/issues/325363](https://github.com/microsoft/vscode/issues/325363)

## Summary

Keep open: the reported tool-selection failure has a concrete screenshot, and current `main` still describes `create_session` generically without covering explicit requests to send or start work in a new session. This is a team-authored issue, and no issue-linked fixing commit or older canonical establishes a factual close.

## Change summary

Explicit requests such as “Send to a new session” produce a textual handoff instead of invoking `create_session` and starting the new session with that context.

## Best solution

Make explicit new-session intent reliably select `create_session`, preserving the requested work as the initial prompt, and cover the natural-language trigger in the Agent Host provider E2E suite. First settle whether a related task described as a “new session” should create a `currentSession` peer chat or an `independent` top-level session under the current relationship model.
