# Issue #306459 — Sessions: Allow merging the PR for a cloud session

[https://github.com/microsoft/vscode/issues/306459](https://github.com/microsoft/vscode/issues/306459)

## Summary

Keep open: the inspected cloud-session commands support checkout and closing a PR, but do not establish the requested merge action. This team-authored request has no verified canonical duplicate or issue-referencing fix.

## Change summary

Add Merge Pull Request to a cloud session's split-button dropdown while retaining Checkout as the primary action.

## Best solution
