Neither wrapper provides an AAC decoder, so a preview setting does not supply the requested codec support.

It is closed as a duplicate, not as a landed fix, and is not used as the canonical. https://github.com/microsoft/vscode/issues/329811#issuecomment-5247405894 confirms that VS Code deliberately ships only a subset of FFmpeg codecs.
