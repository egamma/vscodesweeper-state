# Issue #339573 — Video Preview and Simple Browser: no audio, volume button disabled on Ubuntu (.deb install)

[https://github.com/microsoft/vscode/issues/339573](https://github.com/microsoft/vscode/issues/339573)

## Summary

This is a specific instance (Ubuntu .deb, Video Preview + Simple Browser) of the well-known, already-tracked gap: Chromium/Electron webviews on Linux don't decode AAC audio in MP4, so the volume control stays disabled. The open canonical issue fully covers this root cause and has substantial traction, so proposing a duplicate close to consolidate.

## Change summary

MP4 files with AAC-LC audio play video but no audio in Video Preview and Simple Browser on Ubuntu; the volume button is disabled.
