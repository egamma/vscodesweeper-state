# Issue #139845 — VS Code fails to open files from relative paths

[https://github.com/microsoft/vscode/issues/139845](https://github.com/microsoft/vscode/issues/139845)

## Summary

Relative-path matching still has a concrete gap on main: Quick Open can discover a normalized file but discard it when scoring against the unnormalized input. Keep this accepted bug open; the related issues do not establish a same-symptom duplicate under the re-review rules.

## Change summary

Make file opening tolerate dot and parent-directory segments in Quick Open queries and compiler-output links.

## Best solution

Ensure equivalent file paths remain discoverable through Quick Open without manual normalization, preserving line/column navigation and terminal working-directory resolution. Establish how leading parent segments interact with real workspace-relative paths before extending fallback matching.
