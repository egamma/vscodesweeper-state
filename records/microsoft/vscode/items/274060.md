# Issue #274060 — Support content exclusions/ignore service in core

[https://github.com/microsoft/vscode/issues/274060](https://github.com/microsoft/vscode/issues/274060)

## Summary

A real gap remains on current main: core exposes an ignored-files service and the terminal tool detects some destination files, but the terminal write-analysis path does not consult content exclusions. The accepted Backlog request should remain open while maintainers decide how excluded terminal writes are enforced.

## Change summary

Make core terminal-tool file operations honor Copilot content-exclusion rules when their destination files can be identified.

## Best solution

Ensure terminal commands that can be proven to write an excluded file cannot bypass the applicable content-exclusion policy, while leaving non-excluded commands unchanged and defining conservative behavior for destinations that cannot be resolved statically.

## Plan brief

- **Likely files:** `src/vs/workbench/contrib/chat/common/ignoredFiles.ts`, `src/vs/workbench/contrib/terminalContrib/chatAgentTools/browser/tools/commandLineAnalyzer/commandLineFileWriteAnalyzer.ts`, `src/vs/workbench/contrib/terminalContrib/chatAgentTools/browser/tools/runInTerminalTool.ts`, `src/vs/workbench/contrib/terminalContrib/chatAgentTools/test/electron-browser/commandLineAnalyzer/commandLineFileWriteAnalyzer.test.ts`
- **Validation:** Extend the CommandLineFileWriteAnalyzer/run-in-terminal tests with a stub ILanguageModelIgnoredFilesService: a command targeting an excluded resolved URI must follow the chosen enforcement policy, the same command targeting a non-excluded URI must retain existing behavior, and unresolved or complex destinations must follow the explicitly selected fallback.
- **Behavior:**

  > Terminal-tool commands with statically identifiable file-write destinations must honor registered content-exclusion rules rather than bypassing them. Commands targeting non-excluded files must retain their existing execution and approval behavior. Acceptance should cover ordinary redirection and an in-place edit, plus document the behavior for destinations that cannot be resolved reliably.
- **Trace:**

  > Core already owns ILanguageModelIgnoredFilesService in src/vs/workbench/contrib/chat/common/ignoredFiles.ts, and Copilot registers its exclusion provider through extensions/copilot/src/extension/ignore/vscode-node/ignoreProvider.ts. RunInTerminalTool constructs CommandLineFileWriteAnalyzer, whose path resolution in src/vs/workbench/contrib/terminalContrib/chatAgentTools/browser/tools/commandLineAnalyzer/commandLineFileWriteAnalyzer.ts detects redirections and selected in-place edits but only evaluates auto-approval and workspace boundaries. The existing analyzer suite provides the closest validation surface. Preserve behavior for non-excluded writes and do not broaden the command parser beyond its currently supported write forms as part of this issue; uncertainty starts at the user-visible enforcement response and fallback for unresolved targets.
- **Open decisions:**
  - When a detected destination is content-excluded, should the terminal tool reject the command outright as an organizational policy violation, or permit it only through an explicit user confirmation path?

## Evidence

- **core capability:** src/vs/workbench/contrib/chat/common/ignoredFiles.ts defines ILanguageModelIgnoredFilesService and LanguageModelIgnoredFilesService, which dispatch fileIsIgnored checks to a registered provider.
- **provider integration:** extensions/copilot/src/extension/ignore/vscode-node/ignoreProvider.ts registers Copilot's ignored-file provider with vscode.lm.registerIgnoredFileProvider, so exclusion decisions are already exposed to core.
- **remaining terminal gap:** src/vs/workbench/contrib/terminalContrib/chatAgentTools/browser/tools/commandLineAnalyzer/commandLineFileWriteAnalyzer.ts resolves detectable write destinations and checks workspace boundaries, but it neither injects ILanguageModelIgnoredFilesService nor calls fileIsIgnored before allowing the command.
- **validation surface:** src/vs/workbench/contrib/terminalContrib/chatAgentTools/test/electron-browser/commandLineAnalyzer/commandLineFileWriteAnalyzer.test.ts already exercises detected writes, workspace boundaries, redirections, and in-place edits, but contains no content-exclusion cases.
