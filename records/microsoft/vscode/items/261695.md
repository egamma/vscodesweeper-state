# Issue #261695 — SCM - Interactive Timeline Scrubber for File History

[https://github.com/microsoft/vscode/issues/261695](https://github.com/microsoft/vscode/issues/261695)

## Summary

Existing Timeline commands support browsing and comparing revisions without checking out commits, but do not cover continuous, editor-integrated history scrubbing. Keep this accepted Backlog request open; no verified canonical duplicate or concrete implementation was found.

## Change summary

Add an editor-integrated Git history scrubber with live revision previews, comparison anchors, change indicators, and animated transitions.

## Best solution

Evaluate an opt-in history exploration surface that previews revisions without modifying working files and preserves responsive editing. The Git/Timeline owners should decide whether continuous scrubbing merits a core surface or is better delivered through an extension; existing revision comparisons remain useful but incomplete coverage.
