# Issue #186359 — reverted custom editor for untitled files will stay open after shutdown

[https://github.com/microsoft/vscode/issues/186359](https://github.com/microsoft/vscode/issues/186359)

## Summary

Still unfixed on main: reverted untitled custom editors are serialized and restored on window reopen because the custom editor shutdown/serialization path doesn't account for reverted untitled files the way text editors do.

## Change summary

A reverted untitled custom editor incorrectly persists across window close/reopen, appearing as a blank editor.

## Best solution

During shutdown, when an untitled custom editor has been reverted (not dirty), it should be excluded from serialization — likely by checking `this.resource.scheme === Schemas.untitled && !this.isDirty()` in the serialization/restore path in `customEditorInput.ts` or the editor serializer, mirroring how untitled text editors are dropped.
