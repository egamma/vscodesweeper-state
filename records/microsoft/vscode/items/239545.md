# Issue #239545 — Editor GPU causes code overlap with line # toggle in notebook cells

[https://github.com/microsoft/vscode/issues/239545](https://github.com/microsoft/vscode/issues/239545)

Keep open: current GPU rendering still has a layout-update mismatch that explains notebook line-number overlap and stale positioning. The broader renderer tracking issue does not establish a same-symptom duplicate, and no issue-referencing fix was identified.

## Change summary

Toggling notebook cell line numbers with experimental GPU acceleration enabled can overlap code with the gutter and misalign symbol highlights.

## Best solution

Keep GPU text, clipping, and decoration coordinates synchronized with the cell editor's current layout when line numbers change, without requiring a canvas resize or unrelated settings change. Preserve notebook line-number semantics and DOM-rendered alignment.
