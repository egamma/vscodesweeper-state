# Issue #316388 — Agents App: `Error: there is no registered task type 'cppbuild'.`

[https://github.com/microsoft/vscode/issues/316388](https://github.com/microsoft/vscode/issues/316388)

## Summary

The Agents Window doesn't register extension-contributed task types (like 'cppbuild'), producing the error in the Output panel. The related issue #318004 was closed for a different symptom (agent looping from empty tool results), but the underlying task-type registration gap likely persists. Already labeled `confirmation-pending` — leave open for maintainer follow-up.

## Change summary

Extension-contributed task types (e.g. 'cppbuild') are not registered in the Agents Window, so tasks.json entries referencing them produce an error.

## Best solution

Ensure the sessions/agents window properly loads extension-contributed task type definitions via `TaskDefinitionRegistry`, or suppress the error when running in agent-host mode where extension task providers are unavailable by design. The `confirmation-pending` label is appropriate to verify whether the incremental fixes (PR #317186, #320707) have addressed the user-facing impact.
