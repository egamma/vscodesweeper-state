# Issue #337299 — Agent window overwrite workbench.editor.useModal

[https://github.com/microsoft/vscode/issues/337299](https://github.com/microsoft/vscode/issues/337299)

## Summary

Confirmed in source: the Agents Window 'Open in Modal Editor' action calls `configurationService.updateValue('workbench.editor.useModal', 'all')` with no target, which VS Code's configuration service resolves to the global USER_LOCAL settings file — so toggling modal mode in one Agents session silently flips the setting for every other window on the machine, exactly as the reporter describes.

## Change summary

Clicking 'Open in Modal Editor' in the Agents window permanently sets the global workbench.editor.useModal setting to 'all', affecting all other VS Code windows/projects.

## Best solution

Write this transient toggle with ConfigurationTarget.MEMORY (in-memory, per-window) instead of the default/persisted target in src/vs/sessions/contrib/editor/browser/editor.contribution.ts, so opening/closing the modal editor in the Agents window never touches the user's persisted settings.json.
