# Issue #154866 — Expand object in debug panel messes up with scroll top

[https://github.com/microsoft/vscode/issues/154866](https://github.com/microsoft/vscode/issues/154866)

## Summary

The debug REPL expansion bug was confirmed in the discussion, and the maintainer identified autoscroll ownership as the likely cause. No verified duplicate or completed fix is present, so the Backlog issue should remain open.

## Change summary

Expanding a large object in the Debug Console scrolls to the end of the expanded object instead of preserving the user's viewport.

## Best solution

Make Debug Console autoscroll conditional on the view already being pinned to the bottom, while preserving the viewport when an existing object is expanded; the list/tree layer likely needs to expose or own that distinction.
