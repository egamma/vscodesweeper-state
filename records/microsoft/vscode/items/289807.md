# Issue #289807 — Really long thinking descriptions for cloud agents

[https://github.com/microsoft/vscode/issues/289807](https://github.com/microsoft/vscode/issues/289807)

## Summary

The defect remains possible on current main: generated thinking titles are requested to stay under ten words, but the model response is accepted verbatim without validating its length. This team-authored bug has no issue-referencing fix or verified duplicate, so it should remain open.

## Change summary

Cloud and regular agents can display excessively long generated descriptions for completed thinking sections.

## Best solution

Ensure generated thinking titles satisfy the existing fewer-than-ten-words contract before they are displayed and cached, while preserving compliant titles and the underlying reasoning content.
