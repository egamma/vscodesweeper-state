# Issue #84486 — [themes] provide command to change theme

[https://github.com/microsoft/vscode/issues/84486](https://github.com/microsoft/vscode/issues/84486)

## Summary

The exact arbitrary-theme command was declined for core by the themes maintainer as better suited to an extension. VS Code has since added a built-in command covering the stated light/dark switching workflow, while named-theme shortcuts remain extension territory.

## Change summary

Allow a keybinding to select a color theme directly by passing its name as a command argument.

## Best solution

Use `workbench.action.toggleLightDarkThemes` with the preferred light and dark theme settings for the reported workflow. More general shortcuts that select arbitrary named themes should be provided by an extension rather than additional core configuration and commands.

## Vision fit

- **Fit:** rejected
- **Reason:** Arbitrary named-theme shortcuts are a specialized customization that can be implemented through the extension ecosystem without expanding the core command surface.
- **Evidence:** Values and guardrails: “The power lives in extensions,” and capabilities that can be built well with the extension API generally belong in an extension rather than core.
