# Issue #84486 — [themes] provide command to change theme

[https://github.com/microsoft/vscode/issues/84486](https://github.com/microsoft/vscode/issues/84486)

## Summary

The motivating light/dark workflow is now built in, while a maintainer explicitly declined arbitrary favorite-theme switching for core and identified it as extension territory.

## Change summary

Allow a keybinding to switch directly to a named color theme without opening the theme picker.

## Best solution

Use `workbench.action.toggleLightDarkThemes` with the preferred-theme settings for light/dark switching; provide arbitrary named-theme shortcuts through an extension.

## Vision fit

- **Fit:** rejected
- **Reason:** Arbitrary user-defined theme switching is a specialized customization that can be implemented through the extension ecosystem.
- **Evidence:** Public value: “The power lives in extensions,” while the lean default experience discourages niche configuration surface in core.
