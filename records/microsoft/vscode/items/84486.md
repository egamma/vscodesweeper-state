# Issue #84486 — [themes] provide command to change theme

[https://github.com/microsoft/vscode/issues/84486](https://github.com/microsoft/vscode/issues/84486)

## Summary

Decline close (out-of-scope) gated off: the issue sits in the Backlog milestone — the owner already triaged it as accepted work. Original assessment: The common light/dark switching scenario now has a built-in command, while the broader request for argument-driven arbitrary theme selection was explicitly identified by the theme maintainer as extension territory after the issue entered Backlog.

## Change summary

Allow a keybinding to invoke a command with a theme name and immediately activate that color theme.

## Best solution

Use `workbench.action.toggleLightDarkThemes` with the preferred light/dark theme settings for the reported day/night workflow. More general argument-driven theme switching should remain an extension capability rather than adding another core command and configuration surface.

## Vision fit

- **Evidence:** Values and guardrails: “The power lives in extensions” and capabilities that can be built well with the extension API generally belong in an extension.
