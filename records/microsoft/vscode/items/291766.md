# Issue #291766 — Double-clicking on an in-item toggle selects the item instead of toggling twice

[https://github.com/microsoft/vscode/issues/291766](https://github.com/microsoft/vscode/issues/291766)

## Summary

The double-click event still escapes the inline toggle and reaches the quick-pick list's selection handler. Keep this open for a bounded interaction fix; ordinary action buttons already prevent that propagation.

## Change summary

Double-clicking an inline quick-pick toggle should toggle twice without selecting or accepting the containing item.

## Best solution

Make inline toggles preserve the same mouse-event isolation as ordinary quick-pick action buttons, while retaining normal row selection and keyboard toggle behavior.
