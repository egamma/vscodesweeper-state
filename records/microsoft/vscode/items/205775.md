# Issue #205775 — Notebook editor options not respected when editor options set

[https://github.com/microsoft/vscode/issues/205775](https://github.com/microsoft/vscode/issues/205775)

## Summary

Still reproduces on main: the notebook editorOptionsCustomizations for insertSpaces may be overridden by the editor widget's own option resolution, because the text model options and editor options interact in a way that can revert the model-level insertSpaces setting. The code path is unchanged since the issue was filed.

## Change summary

Setting `notebook.editorOptionsCustomizations` with `editor.insertSpaces: false` is not respected when `editor.insertSpaces: true` is also set in user settings.

## Best solution

The fix likely needs to ensure that `model.updateOptions()` with the notebook-specific insertSpaces value is authoritative and not overridden by the editor widget re-applying its own resolved options. The interaction between `CellEditorOptions`, `BaseCellEditorOptions`, and the editor widget's model option resolution in `codeCell.ts` needs to be debugged to find where the model's insertSpaces gets reset.
