# Issue #317633 — Agents: Add search/filter bar to workspace picker

[https://github.com/microsoft/vscode/issues/317633](https://github.com/microsoft/vscode/issues/317633)

## Summary

Keep open: current main displays a search field in the unified workspace picker, but it filters only the ten entries retained by the picker, so it cannot find the omitted workspaces that motivated this request. This member-authored Backlog item still tracks a real capability gap.

## Change summary

Make the Agents workspace picker searchable so users can locate workspaces omitted from its short default list.

## Best solution

Keep the unfiltered picker concise, but search the complete known workspace history so filtering can reveal entries outside the ten-item presentation cap. The area owner should also decide whether search covers only known recent/session workspaces or queries provider-backed browse sources.

Typing in its search field must reveal and allow selection of a matching known workspace even when that workspace falls outside the default ten-item list. Search must remain keyboard-operable and expose an appropriate accessible label, while clearing the query restores the normal capped presentation.
- **Trace:**

  > WorkspacePicker._buildItems in src/vs/sessions/contrib/chat/browser/sessionWorkspacePicker.ts constructs recent-workspace entries and slices them to MAX_NEW_PICKER_RECENT_WORKSPACES before _showFlatPicker supplies them to IActionWidgetService. WorkspacePicker._buildListOptions enables the filter UI, but ActionList in src/vs/platform/actionWidget/browser/actionList.ts filters only its supplied _allMenuItems, so the search cannot recover entries removed by the cap. Commit https://github.com/microsoft/vscode/commit/1bb677d477f3a76b1ab80335ed9fecaf0162c3fa and the existing cap test establish the current boundary. Preserve the concise unfiltered list, provider grouping, selection semantics, and browse actions; the uncertainty begins at whether a query searches only the complete locally known recent/session corpus or also invokes provider-backed discovery.
