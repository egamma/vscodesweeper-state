# Issue #260375 — Review built-in tool enablement

[https://github.com/microsoft/vscode/issues/260375](https://github.com/microsoft/vscode/issues/260375)

## Summary

Keep open: this is a team-authored tracking and exploration issue with several unresolved checklist items and product tradeoffs. Partial tool-specific improvements do not complete the broader built-in tool enablement review.

## Change summary

Audit built-in Copilot tools and avoid exposing tools that are irrelevant to the current workspace or task without harming tool discovery or prompt-cache affinity.

## Best solution

Continue the per-tool audit under this tracker, settling a stable enablement or virtual-group mechanism that balances context size, prompt caching, and discoverability. Concrete tool changes can land separately while this umbrella remains open until its owners resolve or deliberately remove the remaining checklist items.
