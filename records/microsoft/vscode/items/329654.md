# Issue #329654 — macOS: update restart hangs indefinitely in uv__threadpool_cleanup

[https://github.com/microsoft/vscode/issues/329654](https://github.com/microsoft/vscode/issues/329654)

## Summary

Well-diagnosed hang during macOS update restart, but the reporter's own native stack traces point squarely at Electron/libuv's process-exit thread-pool teardown (uv__threadpool_cleanup), not VS Code application code — keep open and classify as upstream.

## Change summary

After VS Code Insiders triggers an update restart on macOS, all windows/extension hosts exit cleanly but the main process hangs forever waiting to join a stuck libuv worker thread, blocking the staged update install.

## Best solution

Keep open as an upstream Electron/libuv teardown issue; VS Code's own code only invokes electron.autoUpdater.quitAndInstall() (src/vs/platform/update/electron-main/updateService.darwin.ts:206-209) and does not control the native exit path where uv__threadpool_cleanup hangs — the fix, if any, lives in Electron or libuv, or may need an Electron version bump once upstream addresses it.
