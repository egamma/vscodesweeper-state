# Issue #329654 — macOS: update restart hangs indefinitely in uv__threadpool_cleanup

[https://github.com/microsoft/vscode/issues/329654](https://github.com/microsoft/vscode/issues/329654)

## Summary

Root cause is confirmed upstream in Electron/libuv (`uv__threadpool_cleanup` hanging on the last worker thread during teardown), already fixed in Electron per a collaborator's comment, but the fix hasn't shipped in VS Code yet — the Electron bump PR is still open and the issue carries a real version milestone, so this stays open until the bump lands.

## Change summary

On macOS, triggering an update restart leaves the main Code process alive indefinitely (hung in libuv thread-pool teardown) instead of exiting so the staged update can install.

## Best solution

Land https://github.com/microsoft/vscode/pull/332863 (bump to electron@42.10.0, which includes the libuv teardown fix https://github.com/electron/electron/commit/c36d14cf035b029af891bb88c7a9c34e7f508fb8) and close this once that Electron version ships in a VS Code build.
