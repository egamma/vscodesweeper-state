# Issue #349984 — Allow filtering to remote machine in worktree cleanup page

[https://github.com/microsoft/vscode/issues/349984](https://github.com/microsoft/vscode/issues/349984)

## Summary

Keep open: the cleanup editor supports individual-workspace filtering, but not filtering all workspaces by machine or displaying a dedicated machine column. This team-authored request describes a distinct capability not covered by the related reports.

## Change summary

Allow filtering Worktree Cleanup by remote machine and show machine identity in its own column.

## Best solution

Make machine identity independently visible and filterable in the shared Worktree Cleanup editor, while retaining workspace and inactivity filtering and existing cleanup safeguards.
