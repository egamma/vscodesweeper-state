# Issue #285121 — Ollama Customized Endpoint not working with Ollama Cloud

[https://github.com/microsoft/vscode/issues/285121](https://github.com/microsoft/vscode/issues/285121)

## Summary

Direct Ollama Cloud support is not implemented by the built-in Ollama provider, which is now deprecated in favor of Ollama's official extension. A later maintainer decision confirms that Ollama integration has moved to that extension, so this can close as an extension candidate.

## Change summary

Support discovering and using Ollama Cloud models when the customized Ollama endpoint points to ollama.com.

## Best solution

Keep the built-in Ollama provider deprecated and let the official Ollama extension own authenticated Ollama Cloud integration and endpoint compatibility.

## Vision fit

- **Fit:** rejected
- **Reason:** Provider-specific cloud integration is a specialized capability that can be delivered through the extension ecosystem rather than maintained in VS Code core.
- **Evidence:** Values and guardrails: "The power lives in extensions" and capabilities that can be built with the extension API generally belong in an extension.

- **maintainer precedent:** A maintainer closed the later Ollama Cloud API-key report https://github.com/microsoft/vscode/issues/312992 with the explicit decision that built-in Ollama support has been replaced by the third-party official Ollama extension: https://github.com/microsoft/vscode/issues/312992#issuecomment-5024869045.
- **related but distinct report:** https://github.com/microsoft/vscode/issues/279832 concerned cloud-model metadata returned by a local Ollama server, not direct authenticated access to ollama.com, and is closed; it is therefore not a valid duplicate canonical.
