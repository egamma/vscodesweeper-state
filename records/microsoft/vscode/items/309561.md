# Issue #309561 — Feature Request: Remove/reduce "noisy" devcontainer warnings when updating Docker Desktop

[https://github.com/microsoft/vscode/issues/309561](https://github.com/microsoft/vscode/issues/309561)

## Summary

This requests improved reconnection behavior for Dev Containers during Docker Desktop updates. Dev Containers is maintained in microsoft/vscode-remote-release, so the issue should remain open and be transferred there.

## Change summary

Reduce disruptive reload notifications by waiting for Docker Desktop and affected development containers to become available again after an update.

## Best solution

Handle temporary Docker daemon outages in the Dev Containers connection lifecycle, distinguishing an expected restart from a persistent connection failure and reconnecting without prompting when safe.
