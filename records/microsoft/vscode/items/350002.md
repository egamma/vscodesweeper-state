# Issue #350002 — sandbox profile: changes would not apply as expected with an offline host that reconnects

[https://github.com/microsoft/vscode/issues/350002](https://github.com/microsoft/vscode/issues/350002)

## Summary

Offline profile edits still leave the remote host using its previous copy after reconnect; current source and an existing test explicitly establish this gap. Keep this team-authored, sandbox-sensitive report open for maintainer review.

## Change summary

Apply sandbox profile edits made while a remote host is disconnected when that host reconnects, including to existing chats.

## Best solution

Reconcile offline edits with the remote host's assigned profile on reconnect without requiring manual reassignment. Preserve managed restrictions and avoid overwriting a different assignment made by another client.
