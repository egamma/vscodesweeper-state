# Issue #342645 — Hover shows on button when navigating customizations view

[https://github.com/microsoft/vscode/issues/342645](https://github.com/microsoft/vscode/issues/342645)

## Summary

Keep open: current customization-detail navigation automatically focuses a back button whose managed hover schedules a tooltip on focus. This matches the reported unwanted popup, and the team-authored report should remain open for a focused correction.

## Change summary

Opening a customization detail view automatically displays the back button's tooltip without deliberate interaction with that button.

## Best solution

Customization-detail navigation should establish accessible keyboard focus without displaying an unsolicited back-button tooltip. Preserve the button's accessible label, back navigation, and deliberately requested hover behavior; avoid changing focus-triggered hovers globally.
