# Issue #179015 — 'Define keybinding' widget doesn't accept `shift shift` keybinding

[https://github.com/microsoft/vscode/issues/179015](https://github.com/microsoft/vscode/issues/179015)

## Summary

Still open on main — the code explicitly acknowledges this limitation with a TODO comment in keybindingWidgets.ts. No fix has been applied.

## Change summary

The 'Define Keybinding' widget cannot accept `shift shift` as input because the first shift keydown is treated as an incomplete chord modifier, even though the keybinding is valid when written manually in keybindings.json.

## Best solution

Implement special handling in the keybinding recording widget (src/vs/workbench/contrib/preferences/browser/keybindingWidgets.ts) to detect repeated-modifier-only keybindings — likely by using a timeout or keyup detection to distinguish 'shift as chord start' from 'shift shift as complete binding'.
