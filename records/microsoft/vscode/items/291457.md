# Issue #291457 — Welcome view closes my MRU picker

[https://github.com/microsoft/vscode/issues/291457](https://github.com/microsoft/vscode/issues/291457)

## Summary

Still reproduces on main: the startup page opens an editor after LifecyclePhase.Restored, which can dismiss an active quick input picker even with preserveFocus logic. No fix commit references this issue.

## Change summary

Opening the Welcome view on startup dismisses the MRU picker if the user opened the command palette quickly after launching a new window.

## Best solution

The startup page runner in startupPage.ts should check whether a quick input is currently visible before opening the Welcome editor, or defer opening until the quick input is dismissed. The fix belongs in `src/vs/workbench/contrib/welcomeGettingStarted/browser/startupPage.ts` around the `run()` method.
