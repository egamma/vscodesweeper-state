# Issue #162099 — Could we avoid this prompt on the Desktop side?

[https://github.com/microsoft/vscode/issues/162099](https://github.com/microsoft/vscode/issues/162099)

## Summary

Verified duplicate: the open, earlier, better-diagnosed issue tracks the same
wrong-auth-provider problem and fully absorbs this proposed desktop-flow improvement.

## Change summary

Carry the web Edit Sessions account and authentication provider into the
desktop Continue Working On flow to avoid another account prompt.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/162025 and design the
Continue Working On handoff there so the destination identifies or recommends the source account
without exposing sensitive account data.

- **Fit:** aligned
- **Reason:** Making cross-environment continuation preserve the user's identity context
supports seamless remote development and a consistent workbench experience.
