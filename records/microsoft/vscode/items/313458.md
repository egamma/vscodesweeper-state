# Issue #313458 — Copilot Chat local models do not populate Context Window usage even when backend usage and model limits are available

[https://github.com/microsoft/vscode/issues/313458](https://github.com/microsoft/vscode/issues/313458)

## Summary

Confirmed in source: the AgentHostByokLmHandler drops usage data from the BYOK chat response, so the Context Window widget never receives token counts for local models. An open PR (#313667) exists to address this.

## Change summary

Context Window usage widget stays empty for local BYOK models (ollama, customoai) because token usage from the language model response is never forwarded to the chat response model.

## Best solution

Land the fix in `AgentHostByokLmHandler.chat()` (src/vs/workbench/contrib/chat/browser/agentSessions/agentHost/agentHostByokLmHandler.ts, line 97) so that `response.result` usage data is included in the returned `IByokLmChatResult`. The open PR https://github.com/microsoft/vscode/pull/313667 targets exactly this gap — review and merge it.
