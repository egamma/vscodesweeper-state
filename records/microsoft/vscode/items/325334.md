# Issue #325334 — Mermaid built-in extension point to register further icons .

[https://github.com/microsoft/vscode/issues/325334](https://github.com/microsoft/vscode/issues/325334)

## Summary

Keep open as a feature request: the built-in Mermaid renderer still registers only its bundled icon packs and exposes no extension-facing registration API. Existing settings do not cover the request, and no canonical issue owning the same capability was verified.

## Change summary

Allow extensions to contribute additional icon packs to Mermaid diagrams in the built-in Markdown preview without replacing its renderer.

## Best solution

Provide a supported icon-pack contribution contract in the built-in Mermaid extension so external extensions can supply specialized packs while retaining the standard Markdown preview. Keep specialized icon assets in contributing extensions rather than bundling additional packs by default.
