# Issue #296494 — Regression: Custom hotkeys stopped working after updating VS Code (1.108 OK, 1.109 broken)

[https://github.com/microsoft/vscode/issues/296494](https://github.com/microsoft/vscode/issues/296494)

## Summary

Confirmed regression on current main: commit cce0642bfb8 changed the language selection path to use `pick.id`, but when `languageMode` is passed as a string arg via keybinding, the pick object is constructed as `{ label: languageMode }` with no `id` property, so `languageService.createById(undefined)` falls back to plain text. An open fix PR (#327086) exists.

## Change summary

Custom keybindings passing a language name as `args` to `workbench.action.editor.changeLanguageMode` now switch to Plain Text instead of the specified language.

## Best solution

Review and land the open PR https://github.com/microsoft/vscode/pull/327086 which restores the `getLanguageIdByLanguageName` lookup when the pick comes from a string arg (no `id` property). The fix is in `src/vs/workbench/browser/parts/editor/editorStatus.ts` around line 1270.
