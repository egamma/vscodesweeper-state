# Issue #334243 — Support symlinks to be shown in multi-diff editor

[https://github.com/microsoft/vscode/issues/334243](https://github.com/microsoft/vscode/issues/334243)

## Summary

Keep open: the current multi-diff pipeline has no explicit representation for symlink changes, and no verified fix or matching canonical issue was found. This team-authored request needs a decision on how links should appear, followed by confirmation of the Agents SCM path.

## Change summary

Show changed symlinks in the multi-diff editor so Agents SCM does not report changes that users cannot inspect.

## Best solution

Make symlink changes visible and identifiable in the Agents changes editor without presenting target-file contents as though they were the link change. Settle the representation, then verify it across the session changes resolver and multi-diff model-loading path.
