# Issue #332464 — Truncated tool result shows up in autopilot mode

[https://github.com/microsoft/vscode/issues/332464](https://github.com/microsoft/vscode/issues/332464)

## Summary

Real, already-diagnosed bug: in Autopilot mode, `getTaskCompleteSummary` in copilotToolDisplay.ts prefers the raw tool output over the input `summary` argument, so a truncated "Output too large to read at once..." message is shown instead of the actual completion summary. An open PR (#332485) fixes exactly this and has matching regression tests, but it hasn't merged yet, so the issue stays open until it lands.

## Change summary

In Autopilot/Advanced mode, the task_complete summary shown to the user is the truncated tool-output placeholder instead of the model's actual summary text.

## Best solution

Land PR https://github.com/microsoft/vscode/pull/332485, which swaps the precedence in `getTaskCompleteSummary` (src/vs/platform/agentHost/node/copilot/copilotToolDisplay.ts) to prefer the `summary` parameter and only fall back to tool output when no summary is present; then close this issue referencing that merge.
