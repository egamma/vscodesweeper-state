# Issue #348370 — Language Models editor: Context Size column ignores maxContextWindowTokens, the chat input uses it

[https://github.com/microsoft/vscode/issues/348370](https://github.com/microsoft/vscode/issues/348370)

## Summary

The Context Size column still ignores the declared context window in current source. Keep this open while the linked fix PR is reviewed and merged.

## Change summary

Make the Language Models editor honor maxContextWindowTokens instead of always adding input and output budgets.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/348999 so the column and its hover use the shared context-window semantics, preserving the fallback for providers without a declared window.
