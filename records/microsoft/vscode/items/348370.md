# Issue #348370 — Language Models editor: Context Size column ignores maxContextWindowTokens, the chat input uses it

[https://github.com/microsoft/vscode/issues/348370](https://github.com/microsoft/vscode/issues/348370)

## Summary

Confirmed in current source: the Language Models editor ignores the declared context window and displays 85K instead of 66K for the reported metadata. The same incorrect calculation affects its hover text and screen-reader announcement.

## Change summary

Make the Language Models editor honor maxContextWindowTokens when presenting a model's context size.

## Best solution

Present the declared model context window consistently in the management column, related hovers, and accessibility label, retaining the input-plus-output fallback for legacy providers. Leave prompt budgeting and configured chat context limits unchanged.
