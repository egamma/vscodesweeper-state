# Issue #257118 — Markdown Code Fences in Notebook Markdown Cells Lack Proper Background Highlighting

[https://github.com/microsoft/vscode/issues/257118](https://github.com/microsoft/vscode/issues/257118)

## Summary

Still reproduces on main: notebook markdown cell CSS lacks background styling for fenced code blocks. The `theme-code-background` variable exists in the webview theme mapping but is never applied to `pre`/`code` elements in the markdown cell stylesheet.

## Change summary

Fenced code blocks in notebook markdown cells have no background highlight, unlike regular markdown preview.

## Best solution

Add a `pre { background: var(--theme-code-background); }` rule (or equivalent using `--vscode-textPreformat-background`) to the inline styles in `extensions/markdown-language-features/notebook/index.ts` to match the standard markdown preview behavior.
