## Summary

This requests an assistant-facing tab-management capability, rather than reporting broken existing behavior. Current source provides manual tab-closing controls and general Playwright execution, but no dedicated assistant control for closing selected browser tabs while preserving the current tab.

## Change summary

Allow the assistant to close selected integrated-browser tabs without closing the current tab.

## Best solution

Have the browser-tools owner assess whether selective tab closing warrants a dedicated tool or clearer support through existing Playwright execution, with explicit preservation of the current tab and existing sharing boundaries.
