## Summary

This requests a new assistant-facing browser tab-management control, rather than reporting broken existing behavior. Keep it open as a feature request: current tools provide general Playwright execution, but no dedicated control for closing selected tabs while preserving the current one.

## Change summary

Allow the assistant to close selected integrated-browser tabs without closing the current tab.

## Best solution

Evaluate a focused browser-tool capability that targets explicitly selected pages and preserves the current page, using the existing browser lifecycle and sharing boundaries. General Playwright execution is a possible workaround, not an equivalent dedicated control.
