# Issue #333153 — Agent Debug Logs resolves Agent Host ID instead of Copilot SDK conversation ID

[https://github.com/microsoft/vscode/issues/333153](https://github.com/microsoft/vscode/issues/333153)

## Summary

Confirmed on current main: Agent Debug Logs still derives `events.jsonl` from the Agent Host session URI, although Copilot's provider-owned API resolves the distinct SDK conversation ID. This remains a bounded Chat diagnostics bug and should be routed to the `chat` area.

## Change summary

Agent Debug Logs fails to display Copilot SDK model and tool events when the Agent Host session ID differs from the backing SDK conversation ID.

## Best solution

Resolve the active session's journal through the Agent Host connection's provider-owned `getSessionStateFile` API, including remote and chat-specific mappings, while preserving direct URI resolution as the historical-session fallback.
