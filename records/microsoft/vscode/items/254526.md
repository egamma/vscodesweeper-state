# Issue #254526 — Policy parser does not support `markdownDescription`

[https://github.com/microsoft/vscode/issues/254526](https://github.com/microsoft/vscode/issues/254526)

## Summary

The policy-generation migration removed the parser requirement that caused this failure and explicitly removed this issue's duplicated-description workaround. Settings can now use markdownDescription without a setting-level description, while supplying separate plain-text policy metadata.

## Change summary

Prevent policy generation from rejecting settings that use markdownDescription instead of description.

## Best solution

Close as completed by d72d6a24245db6cc9d80988f7cda1305a385037c. Retain the separate policy.localization.description contract so administrative policy text does not depend on the setting's Markdown description.
