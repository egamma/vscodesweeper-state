# Issue #254526 — Policy parser does not support `markdownDescription`

[https://github.com/microsoft/vscode/issues/254526](https://github.com/microsoft/vscode/issues/254526)

## Summary

Still reproduces on main: the policy export system requires settings to have an explicit `description` and does not fall back to `markdownDescription`. The workaround PR added a plain description to the affected setting, but the infrastructure-level fix to support `markdownDescription` fallback was never implemented.

## Change summary

The policy export pipeline errors when a setting uses only `markdownDescription` without a plain `description`, even though `markdownDescription` is a valid alternative in VS Code's configuration schema.

## Best solution

Modify the policy export infrastructure (likely in `src/vs/workbench/contrib/policyExport/electron-browser/policyExport.contribution.ts` or the `IPolicy.localization` resolution logic) to strip markdown and fall back to `markdownDescription` when `description` is absent, since consumers like the Windows Group Policy Editor cannot render markdown anyway.
