# Issue #298680 — Action to expand all collapsed lines in the multi-diff editor

[https://github.com/microsoft/vscode/issues/298680](https://github.com/microsoft/vscode/issues/298680)

## Summary

Keep open: expanding file cards and revealing unchanged lines are separate operations, and current main has no action to reveal unchanged regions across every file in a multi-diff editor. The linked request establishes that this is about hidden lines, not the existing Expand All Diffs action.

## Change summary

Add an action to reveal all collapsed unchanged regions across all files in the multi-diff editor.

## Best solution

Provide an explicit multi-diff-wide action that reveals unchanged lines across its documents, including documents outside the viewport, without changing the default collapse setting or the existing file-card expansion command. Settle whether the action also opens collapsed file cards before implementation.
