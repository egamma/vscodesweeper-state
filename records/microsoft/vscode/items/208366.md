# Issue #208366 — Show more git diff info in the code compare window

[https://github.com/microsoft/vscode/issues/208366](https://github.com/microsoft/vscode/issues/208366)

## Summary

Keep this accepted Backlog request open: the current comparison surface does not explain both file-mode and encoding-only changes. Older related issues cover individual parts, but neither owns the full request.

## Change summary

Show file-mode and encoding differences in Git comparisons when the decoded file contents appear identical.

## Best solution

Provide an explicit comparison of original and modified file metadata in the Git diff experience, so users can understand non-text changes without running git diff. Coordinate the mode and encoding portions with the existing related issues while preserving their distinct requirements.
