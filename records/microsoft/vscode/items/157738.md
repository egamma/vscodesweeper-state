# Issue #157738 — Emmet snippets autocomplete stops midway

[https://github.com/microsoft/vscode/issues/157738](https://github.com/microsoft/vscode/issues/157738)

## Summary

Still reproduces on main: the `isAbbreviationValid` function in `@vscode/emmet-helper` rejects any abbreviation starting with `!` that contains non-`!` characters, which prevents custom snippets like `!!!4s` from appearing in completions.

## Change summary

Custom Emmet snippets starting with `!` (e.g. `!!!4s`) lose their autocomplete suggestion once any non-`!` character is typed.

## Best solution

Update the `isAbbreviationValid` logic in `@vscode/emmet-helper` to account for custom user snippets that start with `!` but contain additional characters — the guard should check against known custom snippet prefixes before rejecting. The fix belongs in https://github.com/nicolo-ribaudo/emmet-helper or the `@vscode/emmet-helper` package, then bumped in `extensions/emmet/package.json`.
