# Issue #327586 — Agent Mode / Copilot CLI delivered identical user prompt twice in one session

[https://github.com/microsoft/vscode/issues/327586](https://github.com/microsoft/vscode/issues/327586)

## Summary

The duplicate-delivery path is visible in the Agent Host queue synchronization code and a maintainer confirmed that this can happen. Keep the correctly routed bug open for a focused race fix and regression test.

## Change summary

A queued prompt can be delivered to Copilot CLI again after the Agent Host has already consumed and executed it.

## Best solution

Seed server-turn queue tracking from the existing protocol state so consumption of a message present before watcher installation still removes the corresponding pending UI request, then cover restored-session consumption with a regression test.
