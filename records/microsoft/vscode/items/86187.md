# Issue #86187 — [scss] provide hover information for at-rules

[https://github.com/microsoft/vscode/issues/86187](https://github.com/microsoft/vscode/issues/86187)

## Summary

The requested SCSS at-rule hover information is still missing on current main. The behavior is owned by the bundled vscode-css-languageservice, so this should remain open and be classified as upstream rather than closed or consolidated.

## Change summary

Show the documentation already provided by SCSS at-rule completions when hovering those at-rules.

## Best solution

Add hover support for the specialized Sass at-rule nodes in microsoft/vscode-css-languageservice, sharing the directive documentation currently held by SCSSCompletion, cover it with SCSS hover tests, and then consume the updated language-service version in VS Code.

## Evidence

- **missing upstream behavior:** https://github.com/microsoft/vscode-css-languageservice/blob/main/src/services/cssHover.ts supplies at-directive documentation only for UnknownAtRule nodes, while the SCSS parser represents @mixin, @include, @function, control statements, @use, and @forward as specialized nodes; those paths receive no directive hover.
- **documentation already exists:** https://github.com/microsoft/vscode-css-languageservice/blob/main/src/services/scssCompletion.ts contains documentation for Sass directives such as @extend, @mixin, @include, @function, @if, @for, @each, @while, @use, and @forward, but that private completion data is not consumed by hover.
- **test coverage confirms gap:** https://github.com/microsoft/vscode-css-languageservice/blob/main/src/test/css/hover.test.ts has no documentation assertions for Sass at-rules; its only SCSS at-rule hover case is @at-root with empty contents.
- **related issue is not canonical:** https://github.com/microsoft/vscode/issues/86488 is open but was created after this re-reviewed issue and asks for comprehensive Sass references in completion data, not the same reporter-observable hover behavior; it does not satisfy the stronger duplicate bar.
