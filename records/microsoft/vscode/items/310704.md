# Issue #310704 — Change colour of status bar while attached to running process when broken on exception/breakpoint

[https://github.com/microsoft/vscode/issues/310704](https://github.com/microsoft/vscode/issues/310704)

## Summary

This is an unimplemented debugger-state UX request, not a bug: current main deliberately applies the same debugging status-bar style while running and stopped. Route it to the debug area for a product and accessibility decision rather than closing it.

## Change summary

Give the status bar a distinct appearance when an attached debug session stops on a breakpoint or exception.

## Best solution

Provide a clear stopped-state cue that remains themeable and is not communicated by color alone, while avoiding an overly prominent whole-window signal. The debug area should decide whether that belongs in the status bar or should strengthen the existing toolbar and title indicators.
