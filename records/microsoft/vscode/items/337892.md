# Issue #337892 — Extend the Git integration as to allow for project specific trailer messages

[https://github.com/microsoft/vscode/issues/337892](https://github.com/microsoft/vscode/issues/337892)

## Summary

Project-configurable trailer selection is a genuine missing capability, but the project previously classified configurable trailer-entry UI as extension territory. Propose the same *extension-candidate disposition, based on that explicit precedent rather than age or lack of upvotes.

## Change summary

Add user- and project-configurable commit-trailer checkboxes, icons, and optional labels beside the Git commit input.

## Best solution

Provide configurable trailer selection through an extension that updates the Git commit message, preserving the existing built-in commit UI. The exact inline checkbox placement would require separate consideration of SCM UI extensibility; it is not an existing capability.
