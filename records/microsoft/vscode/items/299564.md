[https://github.com/microsoft/vscode/issues/299564](https://github.com/microsoft/vscode/issues/299564)

## Summary

Keep open: current main still bundles contributed session pickers into one toolbar action, leaving individual pickers inaccessible from overflow. The linked open PR directly addresses this remaining defect; the earlier merged fix corrected anchoring, not independent picker actions.

## Change summary

Give each contributed Claude session picker its own toolbar action, overflow entry, and appropriate label instead of grouping all pickers under one primary-picker action.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/304565 after confirming that each contributed picker sizes and overflows independently, remains individually accessible, and uses the same presentation conventions as built-in pickers.
