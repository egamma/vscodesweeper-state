# Issue #282242 — Chat codeblocks don't fill container

[https://github.com/microsoft/vscode/issues/282242](https://github.com/microsoft/vscode/issues/282242)

## Summary

The visual defect remains on current main: request code-block editors are deliberately laid out at only 90% of their available container width. This is a bounded chat rendering bug with no verified duplicate or landed fix.

## Change summary

Chat code blocks leave unused horizontal space instead of filling their containing request surface.

## Best solution

Make embedded request code-block editors occupy their full available container width while preserving existing borders, reserved width, wrapping, scrolling, and response-code-block behavior.
