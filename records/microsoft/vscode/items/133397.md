# Issue #133397 — Embedded languages use outer language auto-closing characters

[https://github.com/microsoft/vscode/issues/133397](https://github.com/microsoft/vscode/issues/133397)

## Summary

Still reproduces on main: CursorConfiguration builds autoClosingPairs from the outer language only, ignoring embedded language config. An open community PR (#309365) is attempting a fix — keeping open for that PR to land or be reviewed.

## Change summary

Typing auto-closing characters inside embedded language regions uses the outer language's pairs instead of the embedded language's pairs.

## Best solution

Review and land (or iterate on) the open PR https://github.com/microsoft/vscode/pull/309365, which adds an embedded-language check in the auto-closing path of cursorTypeEditOperations.ts, mirroring the existing pattern used for electric characters.
