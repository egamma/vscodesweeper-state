# Issue #133397 — Embedded languages use outer language auto-closing characters

[https://github.com/microsoft/vscode/issues/133397](https://github.com/microsoft/vscode/issues/133397)

## Summary

The defect remains conclusively present on current main: typing operations select auto-closing candidates from the outer document language even after tokenization identifies an embedded language. Keep the canonical issue open while the linked human-owned fix PR is reviewed.

## Change summary

Auto-closing while typing inside an embedded language incorrectly uses the outer language's configured character pairs.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/309365 after ensuring the behavior consistently follows the language at each cursor, including outer-only pairs, embedded-only pairs, and mixed-language multi-cursor cases, with focused editor cursor tests.
