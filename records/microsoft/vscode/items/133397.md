# Issue #133397 — Embedded languages use outer language auto-closing characters

[https://github.com/microsoft/vscode/issues/133397](https://github.com/microsoft/vscode/issues/133397)

## Summary

The typing path still selects auto-closing pairs from the outer language, so this remains a valid core editor bug. An open PR references this issue and addresses part of the behavior; keep the report open while that implementation is reviewed.

## Change summary

Use the embedded language's auto-closing configuration rather than the outer document's configuration when typing inside embedded regions.

## Best solution

Review https://github.com/microsoft/vscode/pull/309365 against this report's full scope: suppress outer-only pairs and honor embedded-language pairs and conditions. Preserve this issue as the broader tracking report until the remaining behavior, including mixed-language multi-cursor typing, is resolved.
