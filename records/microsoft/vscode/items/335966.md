# Issue #335966 — Multi-diff editor disposal hangs as rendering replenishes the template pool

[https://github.com/microsoft/vscode/issues/335966](https://github.com/microsoft/vscode/issues/335966)

## Summary

Keep open: current source still permits rendering consumers to acquire replacement templates while the pool drains its live Set during disposal. The related scrolling and double-unbinding reports do not cover this direct-disposal hang.

## Change summary

Directly disposing a rebound multi-diff editor with a live input can hang because synchronous binding notifications replenish the template pool during teardown.

## Best solution

Make multi-diff teardown terminate without rendering or acquiring replacements, while releasing all active and cached templates and preserving the externally owned input. Cover the reported clear/rebind/direct-dispose sequence with a bounded regression.
