# Issue #276326 — Search: line number should be wider for coherent preview

[https://github.com/microsoft/vscode/issues/276326](https://github.com/microsoft/vscode/issues/276326)

## Summary

The Search Editor serializer still produces inconsistent content alignment when context lines cross a line-number digit boundary. Keep this open: the current source contains a concrete failing path, and the older redesign discussion does not track this same symptom.

## Change summary

Keep Search Editor preview text aligned when line numbers grow from one digit to two or more.

## Best solution

Give every displayed line within a file result a consistent line-number prefix width, including trailing context, while preserving source indentation and accurate match highlighting.
