# Issue #293631 — Add agent identifier to Copilot Chat hook parameters

[https://github.com/microsoft/vscode/issues/293631](https://github.com/microsoft/vscode/issues/293631)

## Summary

The request remains necessary: agent-scoped hooks partially cover custom-agent policies, but global hooks still cannot consistently identify the active agent. Current Agent Host development delegates hook inputs to the Copilot SDK, so the missing contract is now primarily upstream.

## Change summary

Expose the active custom or default agent identity in hook inputs so hook policies and logging can vary by agent.

## Best solution

Define stable agent identity fields in the Copilot SDK hook-input contract for relevant lifecycle and tool events, including a documented value for the default agent, then preserve those fields through VS Code's Agent Host hook adapter. The legacy extension-host path should remain compatible while it is supported.
