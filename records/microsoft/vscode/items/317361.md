# Issue #317361 — Cmd.default prototype in cmd.pyi should be changed.

[https://github.com/microsoft/vscode/issues/317361](https://github.com/microsoft/vscode/issues/317361)

## Summary

This is a type-stub issue in Pylance (the `cmd.pyi` stub for Python's `cmd.Cmd.default`), which is a third-party extension maintained outside microsoft/vscode. Closing as caused-by-extension and directing the reporter to the correct tracker.

## Change summary

The `cmd.Cmd.default` method's type stub in Pylance should return `Optional[bool]` instead of `None` to allow overrides that control CLI exit behavior.

## Best solution

File this against Pylance's type stubs. The `cmd.pyi` stubs ultimately come from typeshed (https://github.com/python/typeshed), so the most effective fix would be a PR to typeshed's `stdlib/cmd.pyi`. Pylance bundles typeshed stubs, so the fix would flow downstream.
