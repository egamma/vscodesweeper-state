Fresh, well-diagnosed report of MCP OAuth breaking for remote HTTP servers via the Copilot agent host; I could not locate the client-registration/authorization-handoff code in this repo (neither agentHost's shared MCP discovery code nor the bundled copilot-chat extension source contain OAuth client_id logic), so the fix likely lives in the closed Copilot CLI runtime rather than something traceable here — keeping open for a Copilot/agent-host maintainer to route or trace further.
