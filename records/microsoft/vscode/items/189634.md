# Issue #189634 — Open file as file read-only through command flag

## Summary

This remains a valid backlog request with 42 community upvotes. Current main supports read-only files after opening but still lacks a CLI option to open a file read-only atomically.

## Change summary

Add a `code` command-line flag that opens specified local or remote files as read-only.

## Best solution

Extend CLI argument handling and editor-open options with a read-only flag that works for new and reused windows, including remote file URIs, while preserving existing session-level read-only controls.
