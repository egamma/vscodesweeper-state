# Issue #334982 — Chat Window's `LLM Request Failed` message is too big, and unnecessary.

[https://github.com/microsoft/vscode/issues/334982](https://github.com/microsoft/vscode/issues/334982)

## Summary

Reasonable UX complaint: when a chat request fails, the shown error message can include a raw stack trace as the 'reason' text (as seen in getChatErrorDetailsInner's ChatFetchResponseType.Failed branch in src/vs/workbench/contrib/chat/common/chatErrorMessages.ts), which is unnecessarily technical for end users. The report also bundles separate asks (retry-count limits, auto-approve/quota interaction) that aren't fully substantiated here.

## Change summary

The 'Sorry, your request failed' chat error message can surface a full JS stack trace as the reason text instead of a concise, user-facing explanation.

## Best solution

In src/vs/workbench/contrib/chat/common/chatErrorMessages.ts (getChatErrorDetailsInner, ChatFetchResponseType.Failed/BadRequest cases) and/or the Copilot extension's error construction path (extensions/copilot/src/platform/chat/common/commonTypes.ts, languageModelAccess.ts), consider truncating or summarizing the 'reason' string before it's shown, rather than passing raw exception text/stack traces through verbatim; the retry-count and auto-approve/quota concerns are separate asks better tracked independently if a maintainer wants to pursue them.
