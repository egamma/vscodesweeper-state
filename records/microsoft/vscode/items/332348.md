# Issue #332348 — [Error] [GitHub.copilot-chat] unhandlederror-Cannot read properties of null (reading 'value')

[https://github.com/microsoft/vscode/issues/332348](https://github.com/microsoft/vscode/issues/332348)

## Summary

Confirmed source defect: `getDiagnosticsForUri` in diagnosticsChanged.ts dereferences `d.code.value` for any diagnostic code that is an object-typed value, including `null` (since `typeof null === 'object'`). An open PR already targets this exact fix, so the issue should stay open pending that PR merging rather than being closed or auto-fixed now.

## Change summary

Copilot CLI's diagnostics-changed notification crashes with `Cannot read properties of null (reading 'value')` when a diagnostic's `code` field is `null`.

## Best solution

Land the already-open fix in https://github.com/microsoft/vscode/pull/332355, which guards against a null diagnostic code in `getDiagnosticsForUri`; once merged this issue can be closed as implemented.
