# Issue #208763 — Request json/sort failed with message: Range#create

[https://github.com/microsoft/vscode/issues/208763](https://github.com/microsoft/vscode/issues/208763)

## Summary

Keep open: the discussion confirms failures and malformed output when sorting nested JSONC objects with trailing commas. Current VS Code delegates sorting to the JSON language service, and neither the earlier upstream fix nor the closed error-notification PR establishes that this reopened report is resolved.

## Change summary

JSON sorting should handle nested objects with trailing commas without throwing or corrupting the document.

## Best solution

Correct the nested-container bookkeeping in vscode-json-languageservice's sorting implementation and adopt the correction in VS Code. Verify both Sort Document and sort-on-save with the supplied examples, preserving the document's structure and values.
