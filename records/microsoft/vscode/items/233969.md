# Issue #233969 — Emmet class expansions retain period in .erb files

[https://github.com/microsoft/vscode/issues/233969](https://github.com/microsoft/vscode/issues/233969)

## Summary

Still open on main — the emmet extension has no built-in erb/html.erb language mapping, so abbreviation extraction doesn't recognize the syntax and retains the trigger text. Two open PRs (#309172, #309181) are attempting to fix this; keeping open pending their review.

## Change summary

Emmet class expansions (e.g. `.something`) leave the leading period in the output when the file language is `erb` because the emmet extension has no built-in mapping for erb to html syntax.

## Best solution

Land the open PRs that add erb/html.erb language mappings and pass the correct syntax hint to extractAbbreviation. The workaround (`"emmet.includeLanguages": {"erb": "html"}`) resolves it for individual users in the meantime.
