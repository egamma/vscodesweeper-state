- **execution path:** In `src/vs/platform/agentHost/node/copilot/copilotAgentSession.ts` (line ~1204-1207), skill-kind slash commands fall through the runtime command invocation and are passed as plain prompt text to `session.send()` — prompt file content injection must happen in the Copilot CLI runtime, not the VS Code side.
