# Issue #249244 — Preserve Scroll Position When Zoom Level Changes

[https://github.com/microsoft/vscode/issues/249244](https://github.com/microsoft/vscode/issues/249244)

## Summary

Keep open: current editor zoom preserves the viewport's first line rather than anchoring content beneath the mouse pointer. The requested interaction remains missing, and no verified canonical issue owns it.

## Change summary

Anchor mouse-wheel and touchpad editor zoom around the current mouse position.

## Best solution

Provide pointer-centered editor zoom while preserving existing keyboard zoom, modifier handling, and ordinary scrolling behavior. The editor-core owner should decide whether this replaces the existing wheel-zoom anchoring behavior.
