# Issue #207120 — Web issue reporter does not respect the `options.issueBody` setting

[https://github.com/microsoft/vscode/issues/207120](https://github.com/microsoft/vscode/issues/207120)

## Summary

The bug remains on current main for stable vscode.dev: the legacy web-reporter path constructs a static issue body without consulting the command's `issueBody` option. The newer experimental reporter preserves the option, but it is still disabled by default for stable web builds.

## Change summary

Make `workbench.action.openIssueReporter` honor its `issueBody` option on vscode.dev as it does on desktop.

## Best solution

Preserve the supplied `issueBody` when the stable web reporter creates its GitHub URL, while retaining the generated version and environment details and existing extension-target routing.
