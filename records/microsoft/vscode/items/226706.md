# Issue #226706 — SCM - show repositories view by default with multiple repositories

[https://github.com/microsoft/vscode/issues/226706](https://github.com/microsoft/vscode/issues/226706)

## Summary

Keep open: current source still hides the Repositories view by default and initially selects all repositories. The maintainer accepted changing this experience, and the existing single-selection setting does not deliver the requested automatic defaults.

## Change summary

Show the SCM Repositories view automatically in multi-repository workspaces and initially select only the first repository.

## Best solution

Provide a calmer fresh-workspace SCM experience with the repository picker visible and one repository's changes initially displayed. Settle how automatic visibility interacts with saved user choices and later repository discovery before changing the defaults.

Manually showing the Repositories view can approximate the requested layout, but neither action changes the out-of-box experience. scm.alwaysShowRepositories controls repository headers in the Changes view, not automatic visibility of the separate Repositories view.
