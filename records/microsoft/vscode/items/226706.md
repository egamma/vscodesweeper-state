# Issue #226706 — SCM - show repositories view by default with multiple repositories

[https://github.com/microsoft/vscode/issues/226706](https://github.com/microsoft/vscode/issues/226706)

## Summary

Valid, team-acknowledged feature request to show the SCM Repositories view by default when multiple repos are present. The view is still registered with `hideByDefault: true` on current main, and a team member confirmed this is planned work — keeping open.

## Change summary

Show the SCM Repositories view by default when a workspace contains multiple repositories, selecting only the first, for a calmer multi-repo experience.

## Best solution

Change the Repositories view registration in `src/vs/workbench/contrib/scm/browser/scm.contribution.ts` to not hide by default when multiple providers are present — likely by removing `hideByDefault: true` and restoring the commented-out `when` clause that gates on `scm.providerCount > 1`. The team (lszomoru) has already confirmed intent to tackle this.
