## Summary

Keep open: current source still selects the entire input before applying a requested range, and the original fix was reverted because it broke quick-input focus. An open PR explicitly addresses this issue; it needs review and Linux/X11 verification rather than a completed close or a competing implementation.

## Change summary

Preserve the Linux/X11 primary selection when opening Command Palette, file-picker, and other inputs that programmatically select text.
