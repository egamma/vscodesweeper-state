## Summary

Keep open: the existing setting disables CodeLens but does not provide the requested in-context discovery or provider identification. An open implementation candidate addresses part of this request and should be reviewed before considering closure.

## Change summary

Make it discoverable what a CodeLens is, which provider contributed it, and how to disable it.
