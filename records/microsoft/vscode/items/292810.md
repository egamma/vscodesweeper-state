## Summary

The reported failure involves CMake Tools extension commands (right-click compile). While the reporter blames PR #283065 (removal of pty input throttling), the reproduction depends entirely on the CMake Tools extension's workflow and it's unclear whether the root cause is in VS Code's terminal or in how the extension sends commands. ## Change summary

Right-click compile via CMake Tools extension fails with 'g++: no input files' after PR #283065 removed pty input throttling.

## Best solution

Determine whether the CMake Tools extension is sending a malformed or overly-long command to the terminal. If the command is correct but the terminal layer is truncating it, the fix belongs in VS Code's terminal (possibly restoring chunking for Linux). If the extension is constructing the command incorrectly, file against microsoft/vscode-cmake-tools. The reporter should provide the exact command string being sent to the terminal and confirm whether it reproduces with a manually typed long command.
