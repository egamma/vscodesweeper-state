# Issue #292810 — Vs code terminal process incorrect behaviour

[https://github.com/microsoft/vscode/issues/292810](https://github.com/microsoft/vscode/issues/292810)

## Summary

The supplied project has an independently confirmed reproduction. CMake Tools subsequently changed its compilation path to bypass terminal input truncation, but that does not establish that the reported VS Code terminal regression is fixed.

## Change summary

Long compiler commands sent through the integrated terminal lose their trailing arguments, causing single-file compilation to fail while a full CMake build succeeds.

## Best solution

Use the merged CMake Tools direct-process execution fix for single-file compilation, and have the terminal owner determine whether the underlying Terminal.sendText truncation remains independently reproducible. Preserve this report until that core-versus-extension boundary is established.
