# Issue #328954 — Markdown preview opened from Source Control lacks diff overview ruler

[https://github.com/microsoft/vscode/issues/328954](https://github.com/microsoft/vscode/issues/328954)

## Summary

Reasonable feature request: Markdown Preview (unlike the source-code diff editor) has no overview-ruler diff markers when opened from Source Control, and I found no such rendering in the markdown preview extension's source, so this is a real gap worth routing to the markdown/SCM area rather than closing.

## Change summary

When a changed Markdown file is opened in Preview mode from Source Control, the preview shows no diff overview ruler markers and scroll-to-change behavior is unreliable, unlike the source-code diff view.

## Best solution

This belongs with the markdown-language-features preview (extensions/markdown-language-features/src/preview) and/or the SCM-to-preview scroll sync path; no diff-decoration rendering exists there today (no matches for overview ruler/diff decoration markers), so a maintainer would need to design how diff markers could be surfaced in a webview-based preview — not a trivial port of the editor's overview ruler.
