# Issue #209465 — Add option to create reference links when pasting links into markdown

[https://github.com/microsoft/vscode/issues/209465](https://github.com/microsoft/vscode/issues/209465)

## Summary

Valid feature request for reference-link paste support in markdown; not yet implemented on main — the paste provider only generates inline links today. Stays open in Backlog for future consideration.

## Change summary

Add an option to paste URLs as markdown reference links (e.g. `[text][ref]` with a `[ref]: url` definition) instead of only inline links.

## Best solution

Extend the paste/drop URL provider in the markdown extension to offer a reference-link variant, leveraging the existing `extractLinkDef` logic in vscode-markdown-languageservice for reuse of existing references. The work lives in `extensions/markdown-language-features/src/languageFeatures/copyFiles/`.
