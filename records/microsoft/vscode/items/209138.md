# Issue #209138 — Include more notebook toolbar actions in accessibility help dialog

[https://github.com/microsoft/vscode/issues/209138](https://github.com/microsoft/vscode/issues/209138)

## Summary

The notebook accessibility help still omits dynamically available toolbar actions, including navigation to the most recently failed cell. Keep this team-authored Backlog request open; the discussion calls for a design decision about which actions and kernel information the help should include.

## Change summary

Make dynamically available notebook toolbar actions discoverable through the notebook accessibility help dialog.

## Best solution

Extend the existing notebook accessibility help to explain relevant conditional toolbar actions and how keyboard users can invoke them. Settle whether this is general guidance or notebook-state-dependent help, and whether kernel variables belong in the same scope.
