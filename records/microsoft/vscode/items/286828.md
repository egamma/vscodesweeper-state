# Issue #286828 — Shortcut for Terminal in Linux no longer works correctly for non-default US keyboards

[https://github.com/microsoft/vscode/issues/286828](https://github.com/microsoft/vscode/issues/286828)

## Summary

Verified duplicate of #282752, which tracks the same regression: dead-key keyboard layouts on Linux broke after the Electron 39 update in VS Code 1.107. The canonical issue is labeled upstream/regression and has active discussion including a bisect pointing to the Electron update.

## Change summary

Ctrl+` no longer toggles the terminal on Linux with international keyboard layouts that use dead keys (e.g. US alt-intl), because the Electron 39 / Wayland backend change altered how dead-key events are dispatched.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/282752, which already owns the upstream Electron/Wayland dead-key regression with bisect data and workaround discussion. The fix likely needs to land in Electron or in VS Code's keybinding dispatch layer to handle dead-key keydown events correctly under native Wayland.
