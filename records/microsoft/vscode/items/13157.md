# Issue #13157 — Trim trailing whitespace only on changed lines

[https://github.com/microsoft/vscode/issues/13157](https://github.com/microsoft/vscode/issues/13157)

## Summary

A real capability gap remains on current main, and this Backlog feature request has 200 community upvotes. It should remain open under the established feature-request process.

## Change summary

Allow trailing whitespace to be trimmed on save only for lines changed by the user, avoiding unrelated diff churn.

## Best solution

Add a modified-lines mode for trailing-whitespace save cleanup, preserving compatibility with the existing `files.trimTrailingWhitespace` boolean behavior. Reuse the SCM modified-range machinery already used by `editor.formatOnSaveMode` rather than introducing separate change tracking.
