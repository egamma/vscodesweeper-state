# Issue #13157 — Trim trailing whitespace only on changed lines

[https://github.com/microsoft/vscode/issues/13157](https://github.com/microsoft/vscode/issues/13157)

## Summary

Keep open: built-in trailing-whitespace trimming still processes the whole file, and modified-lines formatting does not constrain it. This accepted Backlog request has 201 upvotes, maintainer support, and a verified duplicate pointing here.

## Change summary

Provide built-in trailing-whitespace trimming limited to changed lines so saving legacy files does not create unrelated whitespace diffs.

## Best solution

Offer an opt-in modified-lines trimming mode in the file-save pipeline while preserving existing whole-file and disabled behavior. Settle what counts as a changed line and how the mode behaves without a comparison baseline before implementation.
