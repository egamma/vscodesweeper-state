# Issue #202450 — Inside of multiline math expressions in markdown files is not recognized as math/latex context.

[https://github.com/microsoft/vscode/issues/202450](https://github.com/microsoft/vscode/issues/202450)

## Summary

Still reproduces on main: the inline math grammar in `extensions/markdown-math/syntaxes/md-math-inline.tmLanguage.json` uses single-line `match` patterns for single-dollar math, so multiline `$...$` expressions are never tokenized. An open PR (https://github.com/microsoft/vscode/pull/255248) is attempting a fix.

## Change summary

Multiline single-dollar math expressions in markdown are not recognized as math/LaTeX context because the TextMate grammar uses a single-line `match` regex instead of `begin`/`end` patterns.

## Best solution

Review and land (or close) the open PR https://github.com/microsoft/vscode/pull/255248, which targets this issue. The fix belongs in `extensions/markdown-math/syntaxes/md-math-inline.tmLanguage.json` — the `math_inline_single` rule needs to be converted from a `match` pattern to a `begin`/`end` pattern (similar to how `math_inline_block` already handles multiline `$$`). Colorize fixture tests in `extensions/vscode-colorize-tests/` should cover the multiline case.

## Evidence

- **grammar source:** In `extensions/markdown-math/syntaxes/md-math-inline.tmLanguage.json`, the `math_inline_single` rule uses `"match": "(?<=\\s|\\W|^)(?<!\\$)(\\$)(.+?)(\\$)(?!\\$)(?=\\s|\\W|$)"` — a single-line match that cannot span lines. The `math_inline_block` rule for `$$` already uses `begin`/`end` and works multiline, but there is no equivalent for single `$`.
