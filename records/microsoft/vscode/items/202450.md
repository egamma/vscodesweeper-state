# Issue #202450 — Inside of multiline math expressions in markdown files is not recognized as math/latex context.

[https://github.com/microsoft/vscode/issues/202450](https://github.com/microsoft/vscode/issues/202450)

## Summary

The reported gap remains in current main: single-dollar math beginning after prose cannot retain LaTeX context across lines. Both linked fix attempts closed without merging, and no verified canonical owns this specific defect.

## Change summary

Recognize multiline inline Markdown math as LaTeX context when its opening dollar sign follows prose, so language-scoped snippets work inside it.

## Best solution

Make the built-in Markdown math grammar recognize the reported multiline expression while preserving existing delimiter boundaries, currency exclusions, and code/comment isolation. Keep this issue as the focused work item rather than moving it upstream or folding it into the general tokenization overhaul.
