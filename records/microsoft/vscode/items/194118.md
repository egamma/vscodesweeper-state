# Issue #194118 — Notebook goto symbol: improve styling for highlighting symbol

[https://github.com/microsoft/vscode/issues/194118](https://github.com/microsoft/vscode/issues/194118)

## Summary

Keep open for the notebook highlight design improvement acknowledged in the discussion. Current source still separates the surrounding cell highlight from the editor interior; symbol discovery settings do not resolve that styling concern.

## Change summary

Make notebook symbol-preview highlighting visually coherent inside the cell rather than emphasizing its surrounding margins.

## Best solution

Agree on a focused, editor-consistent preview treatment in the notebook outline area, including how cell-level emphasis should coexist with symbol-range emphasis. Preserve useful highlighting when no language provider supplies a symbol range.
