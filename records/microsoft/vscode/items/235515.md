# Issue #235515 — Brackets Snippet deleting chars

[https://github.com/microsoft/vscode/issues/235515](https://github.com/microsoft/vscode/issues/235515)

## Summary

The replacement-range defect remains in current main: accepting the bracket snippet can consume a character beyond the closing bracket. Keep this issue open while the existing fix proposals are reviewed; neither has merged.

## Change summary

Accepting a bracket-pair snippet in replace mode incorrectly deletes the character immediately following an already-matched closing bracket.

## Best solution

Review and land one of the existing fixes at https://github.com/microsoft/vscode/pull/317164 or https://github.com/microsoft/vscode/pull/240604, preserving the intended replacement of auto-closed brackets while preventing replacement beyond the matched prefix.
