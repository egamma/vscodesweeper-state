# Issue #311690 — Chat copy button prioritizes selected text instead of the message

[https://github.com/microsoft/vscode/issues/311690](https://github.com/microsoft/vscode/issues/311690)

## Summary

The defect remains source-reproducible on current main: the footer copy action returns the active selection from anywhere in the focused chat widget instead of copying its bound message. Keep it open and route it to the chat response area while the existing fix PR is reviewed.

## Change summary

Make a chat message's copy button copy that message rather than unrelated selected text elsewhere in the chat widget.
