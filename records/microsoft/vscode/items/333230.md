# Issue #333230 — [Error] unhandlederror-Invalid array length

[https://github.com/microsoft/vscode/issues/333230](https://github.com/microsoft/vscode/issues/333230)

## Summary

Confirmed regression in the 1.135 stable line: `probeDynamicHeights` in ListView constructs `new Array(range.end - range.start)`, which throws `RangeError: Invalid array length` when the visible range is inverted (end < start) during a scroll-triggered rerender — this crashes chat/inline-chat list rendering. An open PR (#333236, titled 'fix: clamp inverted visible range in ListView to prevent RangeError (fixes #333230)') already targets this exact defect, so the fix lane should not compete with it.

## Change summary

RangeError: Invalid array length thrown from ListView.probeDynamicHeights during onScroll rerender, new in 1.135 stable (absent in 1.134).

## Best solution

Review and land https://github.com/microsoft/vscode/pull/333236, which clamps the inverted visible range passed into probeDynamicHeights in src/vs/base/browser/ui/list/listView.ts (around line 1765) before allocating the diffs array.
