# Issue #307697 — Allow customizing the media sound for user confirmation prompts

[https://github.com/microsoft/vscode/issues/307697](https://github.com/microsoft/vscode/issues/307697)

## Summary

The confirmation sound still cannot be replaced, but the older, open sound-customization request already owns this capability. Consolidate this report there, preserving the confirmation-specific distinguishability goal and the maintainer's concern about confusion.

## Change summary

Allow users to replace the confirmation-prompt sound with one they can distinguish more easily from other sounds.

## Best solution

Resolve customization of built-in accessibility sounds in https://github.com/microsoft/vscode/issues/145204, including the user-action-required cue. Evaluate distinguishability and consistent signal meanings together rather than introducing an independent confirmation-only setting.
