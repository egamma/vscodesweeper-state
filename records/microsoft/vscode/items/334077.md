# Issue #334077 — Claude now not loading models

[https://github.com/microsoft/vscode/issues/334077](https://github.com/microsoft/vscode/issues/334077)

## Summary

Multiple independent users (the reporter plus two commenters) confirm the same failure — the Claude agent SDK isn't getting auto-downloaded/cached correctly after the latest update, leaving 'no models available' and 'Provider claude could not describe claude:/' errors — and all needed the same manual workaround (extracting the SDK tarball by hand and touching a missing `.complete` sentinel file). This is a real, currently-reproducing defect in the agent-host Claude SDK provisioning path, not something I can confirm fixed on main.

## Change summary

After updating VS Code, the Claude agent fails to load any models ('no models available') and imported Claude sessions error with 'Provider claude could not describe claude:/', apparently because the bundled agent-sdk isn't being downloaded/cached automatically.

## Best solution

Root-cause why the agent-sdk cache for Claude isn't being populated (or its `.complete` sentinel isn't being written) automatically for these users in `src/vs/platform/agentHost/node/agentSdkDownloader.ts`/`claudeAgent.ts`'s SDK-resolution path, and consider surfacing a clearer in-product retry/error instead of silently deferring chat metadata forever.
