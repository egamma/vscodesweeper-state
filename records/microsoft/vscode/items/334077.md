# Issue #334077 — Claude now not loading models

[https://github.com/microsoft/vscode/issues/334077](https://github.com/microsoft/vscode/issues/334077)

## Summary

The root cause — the Claude agent SDK never auto-downloading (gated behind sign-in/entitlement checks, so a session could never trigger the download and the model picker stayed empty) — was fixed by PR #334316, and the reporter's own later comment confirms it now works on 1.140.0-insider, which matches the current main state.

## Change summary

After updating VS Code, the Claude agent SDK never downloads, so no models are listed and imported Claude sessions fail with "Provider claude could not describe claude:/…".

## Best solution

Keep the shipped download-consent/auto-download-on-use flow (agentSdkDownloader.ts + agentSdkSetupChannel.ts); no further change needed beyond confirming on the latest build, and any residual issue with the stale sdk-cache folder left behind after an SDK version bump (noted in the final comment) is a minor follow-up, not this defect.
