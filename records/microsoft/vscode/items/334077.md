# Issue #334077 — Claude now not loading models

[https://github.com/microsoft/vscode/issues/334077](https://github.com/microsoft/vscode/issues/334077)

## Summary

Real, multiply-confirmed bug in the Claude agent SDK auto-download path: two other commenters hit the exact same 'Provider claude could not describe claude:/' failure and both had to manually download/extract the SDK and hand-create the `.complete` sentinel to restore model loading, which points at the in-app download/extraction flow in agentSdkDownloader.ts silently failing or never completing for these installs.

## Change summary

After updating VS Code, the Claude agent shows no available models and imported sessions fail with 'Provider claude could not describe claude:/...', because the agent SDK never finishes downloading/extracting into the local sdk-cache.

## Best solution

Investigate why `AgentSdkDownloader._download` (src/vs/platform/agentHost/node/agentSdkDownloader.ts) isn't reaching a successful `.complete` sentinel write for these users — likely a swallowed fetch/extract error or a CDN/version mismatch — and surface a visible error/retry instead of leaving the agent silently stuck on 'SDK not downloaded yet'.
