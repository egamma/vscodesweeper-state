# Issue #327600 — Memory tool: user memory is never auto-loaded when the memories directory is a junction/symlink (strict FileType check)

[https://github.com/microsoft/vscode/issues/327600](https://github.com/microsoft/vscode/issues/327600)

## Summary

Confirmed in current main: all three memory-context directory checks reject the valid `Directory | SymbolicLink` bitmask, preventing linked memory directories from being loaded. This team-authored issue should remain open for a localized fix.

## Change summary

Allow automatic user, session, and repository memory loading when their directories are junctions or symbolic links.

## Best solution

Change the three directory checks in `memoryContextPrompt.tsx` to test the `FileType.Directory` bit and add coverage for directory-plus-symbolic-link stats.
