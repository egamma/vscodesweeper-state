# Issue #340112 — Git: kill() of a failed git spawn sends SIGTERM to the whole VS Code process group (macOS, deleted worktree)

[https://github.com/microsoft/vscode/issues/340112](https://github.com/microsoft/vscode/issues/340112)

## Summary

Keep open: the report isolates process-group termination to Electron utility-process child handling, and current Git source still calls kill() without checking for a successful spawn. No verified fix or same-symptom canonical was found.

## Change summary

Prevent a failed Git spawn in a deleted worktree from causing SIGTERM termination of every VS Code process in the process group.

## Best solution

Correct failed-spawn kill semantics in Electron and assess a defensive mitigation in the built-in Git extension. Failed commands should surface their errors without terminating unrelated windows or terminals, while cancellation of successfully spawned Git processes remains functional.
