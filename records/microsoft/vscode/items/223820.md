# Issue #223820 — Visual issue when running apache_beam interactive_runner

[https://github.com/microsoft/vscode/issues/223820](https://github.com/microsoft/vscode/issues/223820)

## Summary

Keep open: the maintainer-diagnosed stylesheet leak remains possible in current source. HTML outputs share the notebook document, and its body background remains overridable by the Bootstrap stylesheet imported by Apache Beam.

## Change summary

Prevent Apache Beam interactive output from turning the entire notebook output webview white instead of respecting the active theme.

## Best solution

Preserve the notebook's themed background when an individual output imports document-wide CSS, while retaining intentional styling inside that output. Keep the protection notebook-specific so ordinary extension webviews retain their existing styling contract.
