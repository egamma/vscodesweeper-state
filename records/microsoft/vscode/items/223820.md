Still reproducible on main: notebook output stylesheets (e.g. Bootstrap) can override the webview body background. ## Change summary

Notebook outputs that import external CSS (e.g. Bootstrap) override the webview body background color, breaking dark theme appearance.

## Best solution

Guard the body background-color in the webview (or in the notebook-specific output rendering) so that external stylesheets from cell outputs cannot override it — either via !important on the body background, or by isolating output-injected styles from the top-level body element. The fix belongs in src/vs/workbench/contrib/webview/browser/pre/index.html or notebook-specific preloads.
