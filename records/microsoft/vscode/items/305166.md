# Issue #305166 — Support for native, context-aware File and Folder Icons (JetBrains-style)

[https://github.com/microsoft/vscode/issues/305166](https://github.com/microsoft/vscode/issues/305166)

## Summary

A maintainer explicitly confirmed that there are no plans for additional built-in themes, while VS Code already exposes file icon themes through its extension contribution API. This is best pursued as a Marketplace icon theme rather than bundled core functionality.

## Change summary

Add a built-in, visually restrained file icon theme with semantic folder icons, language icons, and context-sensitive state overlays.

## Best solution

Implement the visual theme as an extension using the existing `iconThemes` contribution point. If generated-file or symbol-kind overlays require runtime context unavailable to declarative themes, track that narrowly as a separate extension API request rather than bundling another theme into core.

## Vision fit

- **Fit:** rejected
- **Reason:** A replaceable visual theme is well suited to the extension ecosystem and bundling another opinionated theme would expand the default product for a preference that extensions can largely serve.
- **Evidence:** Values and guardrails: “The power lives in extensions” and “Out of the box, VS Code is a text editor: lightweight and fast.”
