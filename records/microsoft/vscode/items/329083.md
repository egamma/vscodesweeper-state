# Issue #329083 — Automations: Claude is being shown the Copilot permission picker

[https://github.com/microsoft/vscode/issues/329083](https://github.com/microsoft/vscode/issues/329083)

## Summary

Traced conclusively in source: the unified permission picker's hover text is hardcoded to say "Copilot" even though the same delegate/action item is shared across all agent-host providers (Claude, Codex) whose autoApprove schema matches the well-known shape — so a Claude session shows Copilot-branded wording, matching the screenshot in the report.

## Change summary

The chat input permission picker shows Copilot-specific wording ("Copilot asks before running tools...", "Copilot runs all tools...") even when the active agent-host session is Claude, not Copilot.

## Best solution

Make the hover/detail strings in AgentHostPermissionPickerDelegate.getPermissionLevelHover (src/vs/sessions/contrib/providers/agentHost/browser/agentHostPermissionPickerDelegate.ts) provider-agnostic — either generic wording or interpolate the active provider's display name — since the delegate is shared across Copilot, Claude, and Codex agent-host sessions.
