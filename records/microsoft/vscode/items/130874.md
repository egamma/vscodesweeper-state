# Issue #130874 — Test UI: Ability to `preserveFocus` when running tests

[https://github.com/microsoft/vscode/issues/130874](https://github.com/microsoft/vscode/issues/130874)

## Summary

The API now exposes TestRunRequest.preserveFocus, but it does not suppress following running tests in the Test Explorer. Keep this accepted backlog request open for a decision on that remaining behavior; the changed default reduces its impact without covering the extension-controlled opt-out.

## Change summary

Allow extensions to suppress Test Explorer scrolling and selection changes for individual test runs without changing the user's global follow-running-test setting.

## Best solution

Define whether per-run focus preservation should also suppress automatic Test Explorer following, including dynamically discovered subtests. Preserve the user's global setting for ordinary runs and document the resulting API contract.
