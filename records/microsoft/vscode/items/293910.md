# Issue #293910 — Environment variables leak into launced program

[https://github.com/microsoft/vscode/issues/293910](https://github.com/microsoft/vscode/issues/293910)

## Summary

Real bug: the snap environment cleanup (unsetSnapExportedVariables) is only applied for the terminal pty host and external URL launches — not for the extension host or debug adapters. Programs launched via debug/tasks/extensions inherit the snap-polluted XDG_DATA_DIRS.

## Change summary

When VS Code is installed as a snap, environment variables like XDG_DATA_DIRS leak snap-specific paths into programs launched via debug adapters or tasks, causing runtime failures in libraries like glib.

## Best solution

Call unsetSnapExportedVariables() early in the main process startup (in app.ts before extension hosts are spawned), so all child processes — including extension hosts and debug adapters — inherit the cleaned environment. The terminal-only fix from PR #185834 is insufficient.
