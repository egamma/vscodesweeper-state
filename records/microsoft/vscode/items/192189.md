# Issue #192189 — Ability to disable diagnostics etc. from certain sources

## Change summary

Allow users to disable or reorder diagnostics from specific sources (extensions, built-in TS server) to reduce duplication in the Problems panel.

## Best solution

Keep open for the community process. The related issue https://github.com/microsoft/vscode/issues/174355 explores diagnostics feedback/filtering UX but doesn't fully own this specific request (per-source disable/priority). If implemented, a per-source filter in the Problems panel or a diagnostics priority setting would address the reporter's need without wasting extension CPU cycles (the concern jrieken raised could be mitigated by letting extensions opt into a 'disable my diagnostics' API).
