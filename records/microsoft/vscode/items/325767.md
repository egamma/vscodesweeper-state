Current source preserves resource paths and revalidates cached responses, so a targeted diagnosis is needed before choosing an invalidation fix.

## Change summary

An extension webview becomes persistently blank after an in-place update and recovers only after clearing several VS Code caches.

## Best solution

Establish which requested URL, cached response, or resource-loading failure persists across the update, then correct the responsible lifecycle behavior. Distinguish stale extension-generated URLs from corrupted cached responses and resource exhaustion before changing cache invalidation.

- **Trace:**

WebviewElement's load-resource handler reconstructs the URI, and loadLocalResource in browser/resourceLoading.ts checks roots and reads that resource.
