# Issue #57939 — Allow to set a file association for files with no extension

[https://github.com/microsoft/vscode/issues/57939](https://github.com/microsoft/vscode/issues/57939)

## Summary

Keep open: current main still lacks a file-association pattern specifically for extensionless files, and this accepted Backlog request has 35 community upvotes.

## Change summary

Allow `files.associations` to target extensionless filenames while excluding dotfiles and filenames with extensions.

## Best solution

Add an explicit extensionless-file association syntax or setting, preserving existing association precedence and excluding dotfiles such as `.gitignore`. Cover the behavior in the language-association tests.
