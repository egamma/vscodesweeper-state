# Issue #335232 — vscode.dev/agents: opening a large Agent Host conversation repeatedly disconnects tunnel after >1 MB chat snapshot

[https://github.com/microsoft/vscode/issues/335232](https://github.com/microsoft/vscode/issues/335232)

## Summary

Well-documented protocol bug (AHP chat snapshot exceeding a ~1MB tunnel frame limit causes repeated disconnect/reconnect loops) with an open fixing PR already in flight, so this should stay open pending that PR landing rather than being closed now.

## Change summary

Opening a large Agent Host conversation over a VS Code tunnel repeatedly disconnects the transport because the chat snapshot subscription response exceeds the tunnel's frame size limit.

## Best solution

Land https://github.com/microsoft/vscode/pull/336004 (or an equivalent fix that chunks/paginates large AHP chat snapshot responses so they don't exceed the tunnel relay's frame limit) rather than tearing down the whole session; keep this issue open until that PR merges and the fix is verified.
