# Issue #324316 — Listener leak: AgentHostSessionAdapter subscribes to shared rootState.onDidChange per session

[https://github.com/microsoft/vscode/issues/324316](https://github.com/microsoft/vscode/issues/324316)

## Summary

Confirmed on current main: every AgentHostSessionAdapter still creates its own observableFromEvent on the shared rootState.onDidChange emitter (line 724), producing O(N) listeners on a single emitter. No fix has landed. Team-authored issue, keeping open.

## Change summary

Each agent-host session adapter subscribes independently to the shared rootState emitter, triggering a listener-leak warning at ~175 sessions.

## Best solution

Hoist a single shared root-state observable to the provider or connection level (the existing `observableFromSubscription` helper in `src/vs/platform/agentHost/common/state/agentSubscription.ts` is a drop-in), scoped to the current connection lifetime, so the emitter gets exactly one listener instead of N. The per-adapter `capabilities` derived can read from this shared observable.
