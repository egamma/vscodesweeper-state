# Issue #56356 — [api] Allow extensions to use the syntax highlighter 

[https://github.com/microsoft/vscode/issues/56356](https://github.com/microsoft/vscode/issues/56356)

## Summary

The requested capability now exists on main as a proposed API, but it is not yet available as a stable public extension API. Keep this issue open to track stabilization.

## Change summary

Expose VS Code's installed TextMate grammars and active theme colors so extensions can render consistently highlighted code.

## Best solution

Finalize `documentSyntaxHighlighting`, moving `languages.computeFullSyntaxHighlighting` and `languages.onDidChangeSyntaxHighlighting` into the stable extension API after completing API review and tests.
