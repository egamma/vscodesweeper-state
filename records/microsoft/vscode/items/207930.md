# Issue #207930 — Notebook cell fails to run command notebook.cell.executeAndSelectBelow when markdown cell is immediately below

[https://github.com/microsoft/vscode/issues/207930](https://github.com/microsoft/vscode/issues/207930)

## Summary

The execution stall matches a maintainer-confirmed regression fixed by commit cac2dcf41eb9ceccb4ec5515d5ba278c8d6b828e. Current source retains the fix, so propose closing as completed.

## Change summary

Executing a code cell with notebook.cell.executeAndSelectBelow selects the following markdown cell without running the original code cell.

## Best solution

Keep the landed fix that prevents revealing a preview markdown cell from waiting indefinitely for an editor attachment, allowing the original code cell to execute after focus moves.
