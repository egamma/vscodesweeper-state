# Issue #334580 — Customizations migration: Expect some UI indication that hiding hint took effect

[https://github.com/microsoft/vscode/issues/334580](https://github.com/microsoft/vscode/issues/334580)

## Summary

Current main confirms the dismissal is persisted without any immediate visible or accessible acknowledgement, leaving the action's success unclear. This fresh, team-authored UX-polish issue should remain open while the desired confirmation behavior is chosen.

## Change summary

Provide immediate feedback when a user selects “Hide for this workspace” on a customization migration hint.

## Best solution

Immediately confirm that migration hints were hidden for the current workspace and harness, preferably by updating the hint in place and providing an equivalent polite screen-reader announcement. The interaction should remain quiet and should not affect other harnesses.
