- **Proposed comment:**

  > Thanks for the suggestion! These commands already exist in VS Code:
  > 
  > - **Open Model Picker** (`workbench.action.chat.openModelPicker`) — opens the model quick pick. Default keybinding: `Ctrl+Alt+.` (when the chat input is focused). You can rebind this to any shortcut you prefer.
  > - **Switch to Next Model** (`workbench.action.chat.switchToNextModel`) — cycles to the next available model.
  > - **Switch to Next Pinned Model** (`workbench.action.chat.switchToNextPinnedModel`) — cycles through your pinned models.
  > - **Change Model** (`workbench.action.chat.changeModel`) — switches to a specific model by identifier.
  > 
  > You can find these in the Command Palette (search for "model") and bind any of them to your preferred keybindings via **Preferences: Open Keyboard Shortcuts**.
  > 
  > Since these are already available, I'm closing this as already covered. Please open a new issue if you find the existing commands don't meet your needs!
