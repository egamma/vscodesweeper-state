# Issue #319049 — MCP: add displayName to mcp.json (or fall back to JSON key when serverInfo.name collides)

[https://github.com/microsoft/vscode/issues/319049](https://github.com/microsoft/vscode/issues/319049)

## Summary

Valid, well-evidenced feature request with 12 upvotes and Microsoft team member confirmation. An open PR (#325003) already attempts a minimal fix. The regression was introduced by commit 0245c88390a which preferred serverInfo.name over JSON keys, breaking disambiguation for multi-instance server configurations.

## Change summary

MCP servers configured multiple times with different args/env show identical labels in the Configure Tools UI because they all report the same serverInfo.name, with no way to distinguish them.

## Best solution

Land a fix that disambiguates multi-instance MCP servers in the Configure Tools picker — either by adding a user-configurable `displayName` field to mcp.json entries, or by showing the JSON key as secondary text/tooltip when serverInfo.name collides. PR https://github.com/microsoft/vscode/pull/325003 is an open attempt at the latter approach and should be reviewed/iterated on.
