# Issue #190575 — notebook find replace instance does not increment to next match correctly

[https://github.com/microsoft/vscode/issues/190575](https://github.com/microsoft/vscode/issues/190575)

## Summary

The notebook find/replace bug is still present on main — after replacing a match, the current-match index advancement logic in findModel.ts doesn't reliably move to the next sequential match; no fixing commit references this issue.

## Change summary

Notebook find-replace jumps to wrong match index after replacing (e.g. from match 26 to match 6 instead of 27).

## Best solution

Fix the match index recalculation in `src/vs/workbench/contrib/notebook/browser/contrib/find/findModel.ts` and the `replaceOne` method in `notebookFindWidget.ts` so that after a successful replace, the model advances to the next sequential match rather than recalculating from stale position data.
