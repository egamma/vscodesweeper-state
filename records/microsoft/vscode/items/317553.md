# Issue #317553 — MCP Registry "Registry only" enforcement blocks all servers even when they exist in the registry

[https://github.com/microsoft/vscode/issues/317553](https://github.com/microsoft/vscode/issues/317553)

## Summary

Confirmed bug on current main: registry-only enforcement checks `mcpServer.gallery` but never populates it for servers added via mcp.json (only gallery-installed ones get synced). An open PR (#325380) already targets this fix.

## Change summary

MCP servers manually configured in mcp.json are disabled under registry-only policy because their gallery metadata is never fetched for the allowlist check.

## Best solution

Land the open fix PR https://github.com/microsoft/vscode/pull/325380 which addresses the gallery-sync gap for non-gallery-sourced servers under registry-only enforcement.
