# Issue #146401 — Profile 2 things at once

[https://github.com/microsoft/vscode/issues/146401](https://github.com/microsoft/vscode/issues/146401)

## Summary

Keep open: the bundled JavaScript debugger still requires stopping an existing profile before starting another on the same debug session. Profiling separate sessions concurrently does not satisfy the request to collect CPU and heap profiles of the same app together.

## Change summary

Allow overlapping CPU and heap profile collection for the same JavaScript application.

## Best solution

Support concurrent CPU and heap collection in the built-in JavaScript debugger, with clear controls for stopping each collection and retaining both outputs. The existing debug area is appropriate; the request needs product consideration before implementation.
