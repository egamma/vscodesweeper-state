# Issue #333948 — Terminal from another window's workspace appears in a newly opened window (regression of #133542)

[https://github.com/microsoft/vscode/issues/333948](https://github.com/microsoft/vscode/issues/333948)

## Summary

Real, well-researched report combining two related terminal-persistence bugs: the cross-window shell-kill half is confirmed on main by source (the `_onWillShutdown` guard only skips disposal for `ShutdownReason.RELOAD`, not for closing one of several open windows) and already has an open, unmerged fix PR; the cross-window session-sharing half is an intermittent reattach race that I could not confirm from source alone.

## Change summary

Two windows on different folders can end up sharing one terminal session (intermittent), and closing one window kills a terminal that belongs to another still-open window (consistent).

## Best solution

Land https://github.com/microsoft/vscode/pull/307472 (or an equivalent fix) so `_onWillShutdown` in src/vs/workbench/contrib/terminal/browser/terminalService.ts detaches rather than disposes terminals when other windows remain open; the separate cross-window session-sharing symptom needs someone with a reliable local repro to trace the workspace-scoped reattach path in src/vs/platform/terminal/node/ptyService.ts for the race the reporter describes.

This matches the unfixed half the reporter cites.
