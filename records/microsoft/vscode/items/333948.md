# Issue #333948 — Terminal from another window's workspace appears in a newly opened window (regression of #133542)

[https://github.com/microsoft/vscode/issues/333948](https://github.com/microsoft/vscode/issues/333948)

## Summary

The reported cross-workspace terminal sharing warrants investigation, but the intermittent trigger is not established on current main. Request current-build confirmation and correlated terminal logs; neither the historical fix nor the related shutdown report justifies closing this regression.

## Change summary

Opening a different workspace sometimes attaches both windows to one terminal process, causing cross-window resizing and termination.

## Best solution

Maintain workspace-isolated terminal restoration and ownership so opening or closing another window cannot resize or terminate an existing window's terminal. First capture the intermittent failure in the local terminal restoration path and distinguish it from the related shutdown-only report.
