# Issue #333948 — Terminal from another window's workspace appears in a newly opened window (regression of #133542)

## Summary

Real, still-open regression composed of two linked sub-problems: the 'closing one window kills another window's terminal' half is confirmed unfixed on current main and already has an open PR, so this stays open and unrouted for now rather than closed or auto-fixed.

## Change summary

Two windows on different folders end up sharing/killing each other's integrated terminal sessions instead of each having its own scoped terminal.
