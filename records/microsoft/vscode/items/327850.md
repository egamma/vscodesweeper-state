## Summary

Keep open: the related discussion independently confirms that renaming the right-hand reference loses document highlights while renaming the declaration or assignment target restores them. Current source still clears highlights on content changes without guaranteeing a post-rename refresh; no fixing commit or verified canonical duplicate was found.
