# Issue #327850 — Document highlights sometimes disappear when renaming

[https://github.com/microsoft/vscode/issues/327850](https://github.com/microsoft/vscode/issues/327850)

## Summary

Current main contains the reported race: rename triggers a cursor-based highlight request before applying edits, then the content-change handler clears highlights without reliably requesting them again. Route this confirmed editor defect to document highlighting.

## Change summary

Document highlights should refresh consistently after a symbol rename, regardless of which occurrence initiated it.

## Best solution

After rename edits finish, explicitly refresh document highlights for the final cursor position, without refreshing on every ordinary content change. Add coverage for renaming from occurrences before and after the cursor.
