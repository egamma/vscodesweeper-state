# Issue #248561 — `terminal.shellIntegration.env.value.PATH` uses wrong separators for `git bash`

[https://github.com/microsoft/vscode/issues/248561](https://github.com/microsoft/vscode/issues/248561)

## Summary

Team-authored bug tracking that `shellIntegration.env.value.PATH` reports forward-slash paths for git bash on Windows instead of backslash paths. The suggestion layer worked around this in PR #248556 by falling back to `process.env`, but the underlying shell-integration env data issue remains unfixed. No commit references this issue. Keeping open.

## Change summary

The shell integration environment detection reports PATH entries with `/` separators instead of `\` for git bash on Windows.

## Best solution

Fix the shell env detection layer (likely in `src/vs/platform/terminal/common/capabilities/shellEnvDetectionCapability.ts` or the shell integration addon that feeds it) to normalize PATH separators for git bash on Windows, so downstream consumers don't need per-shell workarounds.
