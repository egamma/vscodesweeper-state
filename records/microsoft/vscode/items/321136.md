# Issue #321136 — Apply minimum release age delay to extension installs (not just auto-updates)

[https://github.com/microsoft/vscode/issues/321136](https://github.com/microsoft/vscode/issues/321136)

## Summary

A real security gap remains on current main: the release-age delay gates automatic updates but not Marketplace, CLI, or recommendation-driven installs. This member-authored, security-sensitive Backlog request has 27 upvotes and must remain open.

## Change summary

Apply the configurable minimum extension release age to every gallery install path, with clear eligibility UX, controlled override behavior, enterprise policy support, and an optional allowlist.

## Best solution

Enforce release-age eligibility consistently at the shared extension-management boundary used by workbench, CLI, and recommendation-driven installs, while defining explicit policy-lock, override, trusted-publisher, and allowlist semantics. Preserve clear UI and CLI diagnostics that identify the publish time and when installation becomes eligible.
