# Issue #331695 — Cannot navigate to folders after opening WSL root directory

[https://github.com/microsoft/vscode/issues/331695](https://github.com/microsoft/vscode/issues/331695)

## Summary

Assigned to milestone 1.136.0, so this is a scheduled fix and stays open regardless of other evidence; the reporter's steps (navigate to WSL root '/', then try to open '/home' or any other folder) are specific enough to act on, and a second commenter reports a related-but-not-identical WSL connect failure on the same release.

## Change summary

After opening a WSL folder at the filesystem root '/', the Open Folder dialog can no longer navigate into subfolders like /home.

## Best solution

Trace the simple-file-dialog navigation state machine (src/vs/workbench/services/dialogs/browser/simpleFileDialog.ts, particularly tryUpdateItems' newFolderIsParent/newFolderIsSubFolder logic and the root()/pathFromUri() handling of a root URI with an empty path segment) to find why selecting a child of '/' fails to update currentFolder, then add a regression test in simpleFileDialog.test.ts for navigating from an authority-scoped root.
