# Issue #192994 — Popovers getting hidden behind code cells in VSCode notebook renderers

[https://github.com/microsoft/vscode/issues/192994](https://github.com/microsoft/vscode/issues/192994)

## Summary

Keep open as a discussion about supporting custom popovers beyond notebook output boundaries. Current source retains the separate output-webview architecture, and the maintainer rejected the proposed event-forwarding workaround without settling whether a different supported overlay mechanism should exist.

## Change summary

Allow custom notebook-renderer popovers to appear above neighboring code cells without blocking editor interaction.

## Best solution

Notebook owners should decide whether to provide a supported floating-output contract that preserves editor interaction and output isolation. Until such a design is accepted, retain output containment rather than raising the entire webview and forwarding mouse events.
