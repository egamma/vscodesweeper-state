# Issue #192994 — Popovers getting hidden behind code cells in VSCode notebook renderers

[https://github.com/microsoft/vscode/issues/192994](https://github.com/microsoft/vscode/issues/192994)

## Summary

Known architectural limitation — notebook outputs render in isolated viewports (iframes), so popovers cannot escape their container boundaries. The team has acknowledged the issue but declined proposed solutions (z-index bumping + event propagation) as adding instability. No feasible fix path has emerged; leaving open as under-discussion.

## Change summary

Popovers from notebook output renderers get hidden behind adjacent code cells due to iframe viewport boundaries.

## Best solution

This remains an open design problem for notebook outputs. The most viable path discussed (comment 7) would be mounting modal nodes higher in the DOM tree with position tracking, but this requires an API that exposes a notebook-level container to renderer extensions. The issue should stay open as a design discussion until a workable approach is identified by the notebook team.
