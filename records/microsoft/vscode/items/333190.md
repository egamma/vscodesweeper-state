# Issue #333190 — Flex Consumption function deployment in Azure no longer works

[https://github.com/microsoft/vscode/issues/333190](https://github.com/microsoft/vscode/issues/333190)

## Summary

The failure occurs in the separately maintained Azure Functions extension while it provisions Azure resources, not in VS Code core. This should be reported to the extension's tracker.

## Change summary

Fix Azure Functions Flex Consumption app creation with managed identity when storage-account key authentication is disabled.

## Best solution

The Azure Functions extension should create the Function App using the selected managed-identity authentication flow without attempting storage-account key authentication; track that work in https://github.com/microsoft/vscode-azurefunctions/issues.
