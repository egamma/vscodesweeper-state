# Issue #69233 — Workspace-level environment variable *definitions*

[https://github.com/microsoft/vscode/issues/69233](https://github.com/microsoft/vscode/issues/69233)

## Summary

Keep this canonical feature request open: it exceeded the community threshold with 60 upvotes, is accepted into the Backlog, and current VS Code still lacks one workspace-defined environment shared across terminals, tasks, debugging, and extensions.

## Change summary

Allow workspace-level environment variables, including values loaded from an ignored `.env` file, to apply consistently across workspace processes.

## Best solution

Provide a trusted workspace/folder environment source with an optional untracked override file, then consume it consistently when creating terminals, tasks, debug sessions, and relevant extension processes. Preserve existing surface-specific environment settings for overrides.
