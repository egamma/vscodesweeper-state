# Issue #320900 — Git meesage opens in agent window

[https://github.com/microsoft/vscode/issues/320900](https://github.com/microsoft/vscode/issues/320900)

## Summary

Keep open: current file-routing code can still select the Agents window for a Git message. Existing protections against replacing that window do not cover opening files in an already-selected workspace.

## Change summary

Git messages opened through VS Code's external-editor invocation should appear in an editor window, not the Agents window.

## Best solution

Make external Git-editor requests select an appropriate editor window, creating one when necessary, while preserving --wait behavior and intentional file opening inside the Agents window.
