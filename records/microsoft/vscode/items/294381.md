# Issue #294381 — "Selection changed" log spam

[https://github.com/microsoft/vscode/issues/294381](https://github.com/microsoft/vscode/issues/294381)

## Summary

Still reproduces on main: the selection-changed push notification handler in selectionChanged.ts doesn't filter out output channel documents, causing a feedback loop when the output channel is focused — each trace log updates the output channel content, triggering another selection change event.

## Change summary

Focusing the Copilot CLI output channel causes infinite "selection_changed" log spam because the trace logging itself triggers new selection change events in the output channel.

## Best solution

Filter out non-file documents (e.g. `output` scheme URIs) in `registerSelectionChangedNotification` before broadcasting, since selection changes in output channels, debug consoles, etc. are not meaningful to the agent. The fix belongs in `extensions/copilot/src/extension/chatSessions/copilotcli/vscode-node/tools/push/selectionChanged.ts`.
