# Issue #336353 — Agents Window stays at “Worktree · Creating...” while session runs with unknown branch

[https://github.com/microsoft/vscode/issues/336353](https://github.com/microsoft/vscode/issues/336353)

## Summary

Fresh, detailed, team-authored bug report about the Agents Window worktree status UI getting stuck at 'Creating...' while the session is already active; no fix exists yet and it needs to stay open for engineering follow-up.

## Change summary

When a session requests worktree isolation, the session list can keep showing 'Worktree · Creating...' indefinitely while the agent is already actively running, with no visible effective path/branch or failure/fallback state.

## Best solution

In the sessions worktree-creation flow (src/vs/sessions/services/sessions/common/session.ts's worktreePending observable and the sessionsList.ts rendering of the pending state), ensure the session doesn't start executing tools until worktree resolution reaches a terminal state, and surface the resolved path/branch or an explicit failure/fallback message once it does.
