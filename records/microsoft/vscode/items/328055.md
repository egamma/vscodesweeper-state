# Issue #328055 — Agent host can't list model in different custom endpoints but model have same id

[https://github.com/microsoft/vscode/issues/328055](https://github.com/microsoft/vscode/issues/328055)

## Summary

The defect is present on current main: the Agent Host bridge identifies custom models only by vendor and model ID, so endpoints sharing both values collide. Route this confirmed bug to Agent Host and language-model management.

## Change summary

Preserve distinct custom endpoints in the Copilot Agent Host model picker when their models share the same ID.

## Best solution

Carry a unique custom-endpoint identity through the BYOK bridge, synthesized Agent Host provider configuration, proxy routing, and request resolution while retaining the endpoint display name.
