## Summary

The error is entirely within the ms-python.debugpy extension's bundled pydevd libraries (PySide6/Qt event loop integration). This is not a VS Code core issue.

## Change summary

Qt GUI event loop integration fails in debugpy's vendored pydevd when using PySide6, raising an AttributeError.

## Best solution

Report this to the debugpy extension's issue tracker (https://github.com/microsoft/debugpy) where the Qt/PySide6 inputhook compatibility can be addressed by the extension maintainers.
