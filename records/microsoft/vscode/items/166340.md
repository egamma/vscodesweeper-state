# Issue #166340 — A code definition window like visual studio 

[https://github.com/microsoft/vscode/issues/166340](https://github.com/microsoft/vscode/issues/166340)

## Summary

A real capability gap remains: VS Code supports manually triggered definition navigation and peek, but not a persistent definition view that follows the cursor. With 29 upvotes and explicit promotion to the Backlog, this should remain open.

## Change summary

Add an independent, scrollable definition view that automatically follows the symbol under the cursor and supports navigating or opening definitions.

## Best solution

Implement a dockable definition view in the editor-symbols area, reusing definition providers and ReferencesModel while supporting multiple definitions, cursor-follow updates, nested symbol navigation, and opening a selected location to the side.
