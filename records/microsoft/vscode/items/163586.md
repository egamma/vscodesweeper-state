# Issue #163586 — Add individual folder select on compressed folders for search tree

[https://github.com/microsoft/vscode/issues/163586](https://github.com/microsoft/vscode/issues/163586)

## Summary

Still unimplemented on main. The search tree uses WorkbenchCompressibleAsyncDataTree but lacks the individual-folder-select behavior that the explorer provides on compressed folder nodes. Team-authored polish request in Backlog — keeping open.

## Change summary

Allow clicking individual folders within a compressed folder node in the search results tree to scope folder-based actions (like restrict-to-folder search).

## Best solution

Extend the FolderMatchRenderer in src/vs/workbench/contrib/search/browser/searchResultsView.ts to support individual compressed-node folder selection, mirroring how the file explorer handles this. This would let folder-based actions (#162628, #161864) target a specific segment of a compressed path.
