# Issue #342195 — Prevent copilot from starting subagents

[https://github.com/microsoft/vscode/issues/342195](https://github.com/microsoft/vscode/issues/342195)

## Summary

Keep open as a request for a discoverable subagent opt-out in the Copilot harness. Current source confirms that its built-in tool list is read-only; advanced tool filters provide a scoped workaround, but not a unified control preventing all subagent execution.

## Change summary

Allow users to prevent Copilot from delegating to subagents, including subagents using a different model.

## Best solution

Provide an understandable, runtime-enforced way to opt out of subagent delegation while retaining ordinary agent tools. Account for the existing tool-exclusion mechanism and separate search/execution subagent controls rather than introducing another overlapping setting without a clear contract.

- **Existing capability and its limits:** src/vs/workbench/contrib/chat/browser/chat.shared.contribution.ts registers chat.agentHost.copilot.modelCapabilityOverrides with wildcard model matching and excludedTools. The source explicitly says these filters are not reapplied on a mid-session model change; this is a scoped configuration workaround, not a unified subagent-disable switch.
