# Issue #342195 — Prevent copilot from starting subagents

[https://github.com/microsoft/vscode/issues/342195](https://github.com/microsoft/vscode/issues/342195)

## Summary

Keep open as a request for a discoverable way to disable subagents in the Copilot harness. Current source deliberately presents its built-in task tool as read-only, so the thread's suggestion to uncheck runSubagent does not address the reporter's harness.

## Change summary

Allow users to prevent Copilot from delegating work to subagents, including subagents using a different model.

## Best solution

Provide a supported, discoverable subagent opt-out for Copilot-harness sessions, enforced by the runtime and reflected accurately in tool configuration. Existing advanced tool filters offer a narrower workaround, but should not be mistaken for a unified subagent control.
