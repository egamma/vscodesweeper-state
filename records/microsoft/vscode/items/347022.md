# Issue #347022 — Associated untitled Save replaces binary destinations without confirmation

[https://github.com/microsoft/vscode/issues/347022](https://github.com/microsoft/vscode/issues/347022)

## Summary

Current source confirms that saving an associated untitled draft can delete an existing binary destination before asking permission. Keep this open while the linked replacement-confirmation PR is reviewed and merged.

## Change summary

Require overwrite confirmation before an associated untitled Save can delete a binary or too-large destination, preserving the destination and dirty source on Cancel.

## Best solution

Review https://github.com/microsoft/vscode/pull/347023 against the requirement that confirmation precede destructive target handling and Cancel preserve both destination bytes and the dirty draft. Keep ordinary Save, missing-target saves, and existing text-target confirmation behavior unchanged.
