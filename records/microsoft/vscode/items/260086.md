# Issue #260086 — AbstractContextKeyService has been disposed

[https://github.com/microsoft/vscode/issues/260086](https://github.com/microsoft/vscode/issues/260086)

## Summary

This is a duplicate of #310777 which tracks the same "AbstractContextKeyService has been disposed" error through the same toolbar update → menu service → context key service call path, with richer analysis and active tracking.

## Change summary

Toolbar update fires after the scoped ContextKeyService is disposed, causing an unhandled error when evaluating menu action visibility rules.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/310777 which has detailed regression analysis and tracks the same toolbar-path disposal race; the fix is a disposal guard in the toolbar update path or ensuring event listeners are torn down before the context key service is disposed.
