# Issue #294050 — Copilot Chat extension memory usage/leak causing frequent resets of extension host process

[https://github.com/microsoft/vscode/issues/294050](https://github.com/microsoft/vscode/issues/294050)

## Summary

Memory leak causing extension host OOM crashes remains actively reported (most recently July 2026 on v1.127.0). Multiple partial fixes have landed (NES telemetry batching, tool invocation disposable leaks, chat widget leaks) but the issue persists — keeping open as the problem is not fully resolved.

## Change summary

Copilot Chat extension causes unbounded memory growth (4GB+) leading to extension host OOM crashes, traced to NES enhanced telemetry buffering and chat tool invocation UI event listener leaks.

## Best solution

Continue investigating remaining memory growth paths — the NES telemetry batching was reworked (periodic windows in 67ac0eef57d) and several chat UI disposable leaks were fixed (#300339, #316767, #319176), but reporters still hit OOM on v1.127.0. The next step is a fresh ETW/heap profile on current main to identify which leak paths remain after the landed fixes.
