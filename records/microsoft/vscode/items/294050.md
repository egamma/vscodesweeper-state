# Issue #294050 — Copilot Chat extension memory usage/leak causing frequent resets of extension host process

[https://github.com/microsoft/vscode/issues/294050](https://github.com/microsoft/vscode/issues/294050)

## Summary

Keep open: maintainer ETW analysis confirmed rapid-typing NES telemetry retention exhausting the extension host's 4 GB heap, and current main still retains full document snapshots in the deferred telemetry path. A commit explicitly claiming to fix this issue exists, but it is not an ancestor of current main, while the later terminal-renderer fixes describe themselves as partial and non-closing.

## Change summary

Copilot's next-edit telemetry retains large document and request data during repeated edits until the extension host reaches its heap limit and restarts.

## Best solution

Restore a bounded lifetime and size for document/request data retained by the NES telemetry and cache paths, then validate the original rapid-edit scenario against current main with extension-host heap tracing. Keep later renderer-side terminal listener leaks in their narrower reports rather than treating them as proof that this extension-host defect is resolved.
