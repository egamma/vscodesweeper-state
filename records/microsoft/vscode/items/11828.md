# Issue #11828 — [json] validation doesn't work offline

[https://github.com/microsoft/vscode/issues/11828](https://github.com/microsoft/vscode/issues/11828)

## Summary

The request remains partially unmet: current VS Code caches eligible schemas, but an expired cache is not used when the refresh request fails offline. Keep the canonical request open for deciding the desired stale-cache fallback.

## Change summary

Allow JSON validation to use previously downloaded schemas while VS Code is offline.

## Best solution

Have the JSON schema request service return the last valid cached schema when a network refresh fails, while retaining conditional refreshes and the existing Clear Schema Cache command.

## Evidence

- **remaining source gap:** extensions/json-language-features/client/src/node/jsonClientMain.ts returns cached SchemaStore content only while it is less than 48 hours old; after expiration, request failures are thrown without falling back to the cached content.
- **cache limitations:** The same request path stores a downloaded schema only when the response supplies an ETag, so schemas without an ETag cannot satisfy the requested offline behavior.
