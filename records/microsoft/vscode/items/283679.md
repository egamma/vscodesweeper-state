# Issue #283679 — Cannot read properties of null (reading 'getFoldingState')

[https://github.com/microsoft/vscode/issues/283679](https://github.com/microsoft/vscode/issues/283679)

## Summary

Still reproduces on current main: the `foldingDelegate` is nulled out in `dispose()` but the `foldingState` getter has no guard, so accessing it on a disposed `MarkupCellViewModel` throws. An open PR (#308025) proposes the fix but has not merged yet.

## Change summary

Accessing `foldingState` on a disposed `MarkupCellViewModel` throws a null-dereference error because `foldingDelegate` is set to null in `dispose()` without a corresponding guard in the getter.

## Best solution

Land the open PR (https://github.com/microsoft/vscode/pull/308025) which adds an `isDisposed` guard in the `foldingState` getter to return `CellFoldingState.None` for disposed cells, or apply an equivalent null-guard at line 76 of `markupCellViewModel.ts`.
