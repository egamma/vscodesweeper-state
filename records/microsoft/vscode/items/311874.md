# Issue #311874 — Inline Skill Picker with Fuzzy Search while typing in Chat

[https://github.com/microsoft/vscode/issues/311874](https://github.com/microsoft/vscode/issues/311874)

## Summary

Keep open for product discussion: current main provides an explicit skill picker through slash-command completions, but it does not satisfy the central request to suggest skills from ordinary prompt text using fuzzy matches across names and descriptions. No older open issue with the same reporter-observable request was verified.

## Change summary

Suggest relevant Agent Skills while the user types natural-language chat input and let the user explicitly attach a suggested skill.

## Best solution

Build on the existing skill slash-completion infrastructure to provide predictable explicit skill selection with fuzzy matching over skill names and descriptions, while avoiding an intrusive unsolicited dropdown during ordinary typing. The interaction and matching scope need product validation before implementation.

## Evidence

- **existing partial capability:** Commit https://github.com/microsoft/vscode/commit/107a383f65f5590c218f7a049ab7cae0ca3c6748, merged through https://github.com/microsoft/vscode/pull/293173 before this report, added skill frontmatter and slash-command support. Current src/vs/workbench/contrib/chat/browser/widget/input/editor/chatInputCompletions.ts obtains prompt and skill slash commands, displays their descriptions, and inserts `/<skill-name>` selections.
- **remaining gap:** The classic completion provider in src/vs/workbench/contrib/chat/browser/widget/input/editor/chatInputCompletions.ts requires the slash token to be at the start of otherwise-empty input, while src/vs/platform/agentHost/node/copilot/copilotSlashCommandCompletionProvider.ts only activates for slash-delimited tokens. Neither path observes ordinary text such as the reported `Selektor` example or searches skill descriptions to proactively suggest a skill.
- **fuzzy matching scope:** Commit https://github.com/microsoft/vscode/commit/79e090a07ea898521af09d92388615f309ff25d2 restored Monaco fuzzy ranking for slash-command and skill names, but it did not add description-based or cross-language matching for natural-language prompt text.
