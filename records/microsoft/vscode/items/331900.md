# Issue #331900 — Preview of a Markdown file shows a cached copy, not the current version

[https://github.com/microsoft/vscode/issues/331900](https://github.com/microsoft/vscode/issues/331900)

## Summary

Confirmed on current main: the markdown preview's TokenCache keys its cache by document URI + version, and document versions restart from 1 when a document is reopened, so a reopened file can spuriously hit a stale cache entry from before the edit. An open PR (#332081) already fixes exactly this by keying the cache on document identity instead of URI; it just hasn't merged yet, so the issue should stay open until it lands.

## Change summary

Reopening a saved-and-edited Markdown file and opening its preview shows the pre-edit content instead of the current content.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/332081, which changes extensions/markdown-language-features/src/markdownEngine.ts's TokenCache to compare document object identity (not just uri+version) before reusing cached tokens, fixing the stale-cache case caused by document version numbers restarting on reopen.
