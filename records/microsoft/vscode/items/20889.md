# Issue #20889 — [Feature Request] Undo branches

[https://github.com/microsoft/vscode/issues/20889](https://github.com/microsoft/vscode/issues/20889)

## Summary

Keep this canonical Backlog request open: current main still discards alternate redo futures, and 329 community upvotes substantially exceed the feature-request promotion threshold.

## Change summary

Preserve alternate edit histories as undo branches and provide a safe UI for navigating them.

## Best solution

Evolve `ResourceEditStack` to retain redo branches, then expose them through an unobtrusive, accessible editor or Timeline UI while preserving normal undo/redo behavior. Local History remains a useful fallback but does not provide granular branching.
