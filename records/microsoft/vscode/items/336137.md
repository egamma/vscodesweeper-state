# Issue #336137 — Create PR title bar action overlaps navigation controls when zoomed

[https://github.com/microsoft/vscode/issues/336137](https://github.com/microsoft/vscode/issues/336137)

## Summary

The responsive gap remains on current main: Create PR is always rendered with its text label, while the title-bar overflow path can only hide entire toolbar groups. The closed fix attempt contains no implementation, so this should remain open as a bounded title-bar bug.

## Change summary

Make the Agents window Create PR title-bar action adapt to constrained space at higher zoom instead of overlapping or displacing navigation controls.

## Best solution

Compact Create PR to an icon-only presentation before navigation controls are hidden or overlapped, restoring its label when space returns while preserving the full accessible name and hover text.
