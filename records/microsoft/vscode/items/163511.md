# Issue #163511 — Add static preloads notebook contribution 

[https://github.com/microsoft/vscode/issues/163511](https://github.com/microsoft/vscode/issues/163511)

## Summary

Keep open as an API proposal: static notebook preloads exist on current main but remain explicitly proposal-gated. The thread deliberately defers finalization until use cases beyond Jupyter emerge, and api-proposal tracking issues must remain open for the API owners.

## Change summary

Allow extensions to contribute notebook-type-specific static preload scripts that run before notebook renderers load.

## Best solution

Retain the proposed notebookPreload contribution while collecting concrete non-Jupyter consumers; API owners can then decide whether to finalize the contract and how it relates to the older notebookMessaging proposal.
