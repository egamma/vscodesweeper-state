[https://github.com/microsoft/vscode/issues/330706](https://github.com/microsoft/vscode/issues/330706)

## Summary

The requested quick editor-area toggle already exists: VS Code can maximize either the panel or the secondary side bar, hiding the editor area and restoring it when toggled again.

## Change summary

Provide a quick way to hide and restore the editor area for agent-first workflows.

## Best solution

Keep the existing layout behavior and use the keybindable `workbench.action.toggleEditorVisibility` or `workbench.action.toggleMaximizedAuxiliaryBar` command, depending on where the agent view is located.
