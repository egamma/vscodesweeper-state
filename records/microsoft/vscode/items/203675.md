# Issue #203675 — Quick open: Questionable focus related code with a `setTimeout`

[https://github.com/microsoft/vscode/issues/203675](https://github.com/microsoft/vscode/issues/203675)

## Summary

The deferred focus code remains on current main, with explicit TODOs referencing this issue in both list and tree handlers. The original window-switching bug received a workaround, but that does not complete the underlying cleanup.

## Change summary

Investigate Quick Input's timeout-based focus restoration and eliminate fragile event-ordering dependencies while preserving keyboard behavior.

## Best solution

Establish a lifecycle-safe focus handoff for Quick Input lists and trees that preserves the existing protection against the triggering key reaching the input. First pin down the event ordering and regression checks; removing the timeout alone is not a demonstrated solution.
