# Issue #287929 — I hope to add the ability to directly drag and drop files or folders into the chat box.

[https://github.com/microsoft/vscode/issues/287929](https://github.com/microsoft/vscode/issues/287929)

## Summary

The current drag-and-drop path attaches files as context but does not insert positional inline references, and persistent context remains a separate open gap. No single canonical issue covers both requests, so this accepted Backlog item should remain open.

## Change summary

Insert dropped files or folders as inline chat references and allow selected context to persist across chat interactions.

## Best solution

Implement cursor-position file references in the chat drag-and-drop path, coordinating with https://github.com/microsoft/vscode/issues/297190, while tracking persistent or pinned attachments with https://github.com/microsoft/vscode/issues/283137. The two capabilities should remain independently specified even if this issue continues as their umbrella.
