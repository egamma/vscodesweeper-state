[https://github.com/microsoft/vscode/issues/269560](https://github.com/microsoft/vscode/issues/269560)

## Summary

Keep open: current source still allows cached whitespace-only suggestions to bypass the setting that suppresses newly generated suggestions. The originating discussion confirms the caching diagnosis, and no verified canonical or issue-referencing fix was found.

## Change summary

Previously cached whitespace-only Next Edit Suggestions can remain eligible after github.copilot.nextEditSuggestions.allowWhitespaceOnlyChanges changes from true to false.

## Best solution

Make cached NES respect the current whitespace-only setting without requiring a reload or manual cache clear, while preserving suggestions that change non-whitespace content.
