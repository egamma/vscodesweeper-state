# Issue #297714 — GitHub Copilot hangs when creating new chat after long conversation

[https://github.com/microsoft/vscode/issues/297714](https://github.com/microsoft/vscode/issues/297714)

## Summary

This remains a credible chat performance bug: creating a new chat from an exceptionally long active conversation freezes the window, and a newer independent report describes the same New Chat hang. No fixing commit, open fixing PR, or verified canonical issue was found, so it should be routed to the chat performance area.

## Change summary

Starting a new Copilot chat while a very large conversation is active can indefinitely freeze the VS Code window and remain broken after restart.

## Best solution

Profile the transition out of a large active chat and ensure New Chat can detach from that model and display an empty session without synchronously processing the full conversation. Add a large persisted-session regression scenario covering both Ctrl+N and restoration after restart.
