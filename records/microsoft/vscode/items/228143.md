# Issue #228143 — High resource usage and file watcher creation on github.dev

[https://github.com/microsoft/vscode/issues/228143](https://github.com/microsoft/vscode/issues/228143)

## Summary

Likely fixed by commit 4679606b304 ("Don't try watching non writable file systems", #232433), which guards against creating file watchers on non-writable schemes like `review://`. However, the fix commit references #232433, not this issue, so it stays open for a maintainer to confirm and close.

## Change summary

Opening a PR review on github.dev causes the TypeScript language service to create excessive file watchers for `review://` URIs, leading to high resource usage and unresponsive hovers.

## Best solution

Confirm that commit 4679606b304 (merged Oct 2024) resolves the excessive file-watcher creation on github.dev PR reviews, then close this issue as completed. The fix adds an `isWritableFileSystem` guard in `extensions/typescript-language-features/src/tsServer/fileWatchingManager.ts` that skips watcher creation for read-only schemes like `review://`.
