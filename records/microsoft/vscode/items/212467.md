# Issue #212467 — Redundant `Open Workspace` button appears after `Preferences: Open Workspace Settings (JSON)`

[https://github.com/microsoft/vscode/issues/212467](https://github.com/microsoft/vscode/issues/212467)

## Summary

The redundant button remains source-reproducible: its visibility condition does not exclude the workspace configuration already open in the window. The existing notification prevents reopening that workspace but does not address the reported UI defect.

## Change summary

Hide the editor's Open Workspace button when the displayed .code-workspace file is already the current workspace.

## Best solution

Make the workspace editor action reflect whether its own document represents the current workspace, while preserving the button for other workspace files and retaining the command's existing defensive check.
