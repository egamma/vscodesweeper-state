# Issue #212467 — Redundant `Open Workspace` button appears after `Preferences: Open Workspace Settings (JSON)`

[https://github.com/microsoft/vscode/issues/212467](https://github.com/microsoft/vscode/issues/212467)

## Summary

Still reproduces on main: the 'Open Workspace' button's when-clause doesn't exclude the case where the edited .code-workspace file is the currently active workspace configuration.

## Change summary

A redundant 'Open Workspace' button appears in the editor when editing the already-open workspace's .code-workspace JSON file.

## Best solution

Add a context key (e.g. a WorkspaceConfigurationFileContext or similar) that tracks whether the active editor's resource matches the current workspace configuration URI, then add it negated to the when-clause in workspaces.contribution.ts. The original filer noted that comparing two context key values isn't supported, so a dedicated boolean context key set by the editor input resolver or a workbench contribution is the viable approach.
