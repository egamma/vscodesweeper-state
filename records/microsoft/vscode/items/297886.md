# Issue #297886 — Git prompts via askpass in Dev Container despite valid cached credentials

[https://github.com/microsoft/vscode/issues/297886](https://github.com/microsoft/vscode/issues/297886)

Keep open in Git/authentication: the reporter explicitly reconfirmed redundant system askpass prompts in 1.111.0, and neither a fixing commit nor a matching canonical was established. The remaining investigation is which credential helper or forwarded process invokes the system prompt.

## Change summary

Git fetch, pull, and sync in a Dev Container display system credential prompts even though dismissing them allows authentication to succeed.

## Best solution

Identify the process requesting credentials and prevent redundant prompts when usable credentials are already available, while preserving prompts for genuinely missing credentials. Investigate the built-in Git authentication path alongside Dev Containers credential forwarding before deciding ownership.
