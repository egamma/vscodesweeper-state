# Issue #339675 — Copilot: Autopilot permissions auto-approve plans in Plan mode

[https://github.com/microsoft/vscode/issues/339675](https://github.com/microsoft/vscode/issues/339675)

## Summary

This is the documented behavior of Autopilot, not a bug: Autopilot is defined as auto-approving every tool-call decision (including the exit-plan-mode choice) until the task is done, and the code and UI copy both say so explicitly.

## Change summary

Requests that Plan mode always pause for an explicit plan-approval step, even when Autopilot permissions are enabled, so permission level and plan approval are separate decisions.

## Best solution

Keep current behavior — Autopilot intentionally auto-approves the exit-plan-mode decision along with every other tool call. If a separate 'always confirm plans even under Autopilot' mode is wanted, that would need to be a new opt-in setting, not a change to Autopilot's existing contract.
