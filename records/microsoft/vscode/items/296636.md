# Issue #296636 — Deprecate and remove github.copilot.chat.reviewSelection.enabled setting

[https://github.com/microsoft/vscode/issues/296636](https://github.com/microsoft/vscode/issues/296636)

## Summary

This is a team-authored debt item, and the setting is still wired up everywhere on current main, so the item stays open. Two of its premises don't hold on main. The command-palette enablement gate is still there, and `github.copilot.chat.review` still reviews the selection directly, with no scope picker. A maintainer should confirm the scope picker has landed or is planned before the setting is removed.

## Change summary

Remove the `github.copilot.chat.reviewSelection.enabled` setting and every `when` clause, enablement check and context key that depends on it.

## Best solution

Once the Code Review command offers a scope picker (selection, file, unstaged changes, branch diff), remove the setting completely. That means the `enablement` and menu `when` clauses in extensions/copilot/package.json, the `isCodeFeedbackEnabled()` gate in inlineChatCodeActions.ts, `ConfigKey.CodeFeedback`, the context-key sync in reviewServiceImpl.ts, and the NLS string. If the picker isn't coming, decide whether the setting still earns its place before removing it.
