# Issue #248760 — NES: InlineInsertion renders over the current line with editor.scrollBeyondLastLine

[https://github.com/microsoft/vscode/issues/248760](https://github.com/microsoft/vscode/issues/248760)

## Summary

The reported insertion overlap is an accepted inline-completions bug, but its presence on current main is unconfirmed. Request a current-build reproduction and exact suggestion input; the inspected fixes do not establish that this report is resolved.

## Change summary

Multiline next-edit insertion previews overlap the cursor line and drift during scrolling when editor.scrollBeyondLastLine is enabled.

## Best solution

Insertion previews should occupy the additional lines at their insertion point and remain attached while scrolling, without covering existing text. Establish a deterministic current-build reproduction, then address any remaining mismatch between the ghost-text view zone and insertion overlay in the inline-completions renderer.
