# Issue #300203 — Prompt rendering overflows

[https://github.com/microsoft/vscode/issues/300203](https://github.com/microsoft/vscode/issues/300203)

## Summary

Still reproducible from current source: separate `${NAME}` placeholders can be paired as one inline KaTeX expression, and inline math lacks the overflow handling applied to display math. This is a bounded chat-markdown rendering bug rather than an outdated-version report.

## Change summary

Chat misinterprets prose containing multiple `${NAME}` environment-variable placeholders as LaTeX, producing content that overflows a narrow chat pane.

## Best solution

Render `${NAME}` placeholders as ordinary text rather than combining separate placeholders into an inline-math expression, while preserving genuine `$…$` math rendering and existing display-math scrolling.
