# Issue #277665 — Require manual accepting of Copilot Edits

[https://github.com/microsoft/vscode/issues/277665](https://github.com/microsoft/vscode/issues/277665)

## Summary

Keep open for the remaining edit-approval UX: current settings support requiring approval before edits, but the permission picker switches approval for all tools rather than edits alone. No verified older canonical owns this same request, and the Backlog milestone rules out a judgment-based decline.

## Change summary

Provide an easy way to switch Copilot edits between explicit acceptance before application and automatic application.

## Best solution

Expose a discoverable edit-specific approval control that lets users protect a running or debugging workspace without changing unrelated tool permissions. Build on chat.tools.edits.autoApprove and coordinate with the existing approval-UX work rather than adding a parallel approval mechanism.
