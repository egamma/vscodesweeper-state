# Issue #324200 — Integrated terminal enters inconsistent state after restart: "Restart Terminal" warnings, xterm.js Cannot read properties of undefined (reading 'dimensions'), terminal shortcuts intermittently stop working

[https://github.com/microsoft/vscode/issues/324200](https://github.com/microsoft/vscode/issues/324200)

## Summary

The core technical signal — the xterm.js `Cannot read properties of undefined (reading 'dimensions')` error — shares the same root cause as the open canonical issue #316419: xterm's internal renderer enters a bad state during disposal/restore, causing the `dimensions` getter to throw. The reporter's stack trace shows a `scrollToBottom` → `scrollLines` → `dimensions` path, while #316419 tracks the `_resize` → `_updatePtyDimensions` path, but both stem from the same unguarded access to xterm internals when the renderer is in a bad state. The broader symptoms (keyboard issues, environment warnings) are plausibly downstream of the same terminal-state corruption. Proposing duplicate close against #316419.
