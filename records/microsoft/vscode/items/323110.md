# Issue #323110 — BYOK Azure OpenAI: hardcoded temperature=0.1 breaks all GPT-5 reasoning models (not a transient failure, see #260506)

[https://github.com/microsoft/vscode/issues/323110](https://github.com/microsoft/vscode/issues/323110)

## Summary

The core blocker (400 error from hardcoded temperature) has a working solution: setting `"thinking": true` in the model config causes the BYOK code to strip temperature. Commit 4034ee46add also added `modelOptions` support for explicit `temperature: null`. The remaining ask — auto-detection of reasoning models or better documentation of these fields — is a valid polish/feature-request that should stay open.

## Change summary

BYOK Azure OpenAI GPT-5 reasoning models fail with 400 because Copilot hardcodes temperature=0.1, which these models reject.

## Best solution

Either auto-detect reasoning-model families (GPT-5.x) so `thinking: true` is implied and temperature is stripped automatically, or document the available BYOK capability fields (`thinking`, `reasoning`, `toolCalling`, `vision`, `modelOptions`) in user-facing docs so users can self-serve. The related issue https://github.com/microsoft/vscode/issues/317503 covers the same root cause and should be closed as a duplicate of this one.
