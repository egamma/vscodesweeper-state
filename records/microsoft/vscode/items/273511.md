# Issue #273511 — Markdown - better handle command links that are not enabled

[https://github.com/microsoft/vscode/issues/273511](https://github.com/microsoft/vscode/issues/273511)

## Summary

The presentation gap remains in current source: command links excluded from enabledCommands still look actionable even though the opener ignores them. Keep this maintainer-authored Backlog item open; choose between plain text and an explicitly disabled link presentation before implementation.

## Change summary

Make Markdown command links visibly non-actionable when their commands are excluded from enabledCommands.

## Best solution

Have the shared Markdown renderer distinguish excluded command links from executable links while preserving existing command authorization. Settle the requested plain-text-versus-disabled-link presentation, then cover it in the Markdown renderer tests.
