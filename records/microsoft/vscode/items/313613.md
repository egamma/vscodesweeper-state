## Change summary

Allow Copy Path to abbreviate the local home-directory prefix as `~` instead of copying the full absolute path.

## Best solution

If accepted after the community process, provide an opt-in Explorer setting or separate command that abbreviates the local home directory for absolute Copy Path output while preserving the existing default, relative-path behavior, and remote or multi-root formatting.
