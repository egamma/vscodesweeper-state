# Issue #149153 — Support to detect file links in output

[https://github.com/microsoft/vscode/issues/149153](https://github.com/microsoft/vscode/issues/149153)

## Summary

The gap remains on current main: Output only creates file-link patterns from workspace roots, so absolute remote paths outside the workspace are not converted into usable remote resources. This is the oldest, best-diagnosed report for that specific behavior and should remain the canonical issue.

## Change summary

Detect and correctly open absolute file links outside the workspace from Output channels, including in remote environments.

## Best solution

Extend OutputLinkComputer to recognize absolute paths independently of workspace membership and resolve them through the applicable local or remote URI scheme, while preserving link-detection performance. Consolidate the newer https://github.com/microsoft/vscode/issues/163778 into this issue.
