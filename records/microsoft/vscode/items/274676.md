# Issue #274676 — Grey out unused functions/symbols in outline view

[https://github.com/microsoft/vscode/issues/274676](https://github.com/microsoft/vscode/issues/274676)

## Summary

The Outline still lacks unused-symbol fading; existing editor fading and Outline problem colors do not cover this request. Keep the accepted Backlog item open; targeted searches found no verified older canonical.

## Change summary

Reflect unused-code fading for functions and other symbols in the Outline view.

## Best solution

Let Outline reflect unused status supplied by language diagnostics, consistently with editor fading, without treating every unreferenced or exported symbol as unused. The Outline diagnostic-to-symbol mapping needs a product decision before implementation.
