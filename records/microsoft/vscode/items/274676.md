# Issue #274676 — Grey out unused functions/symbols in outline view

[https://github.com/microsoft/vscode/issues/274676](https://github.com/microsoft/vscode/issues/274676)

## Summary

A real outline gap remains on current main: unused code can be faded in the editor, but outline symbols only support deprecated styling. The accepted Backlog request already has the correct area label and should remain open.

## Change summary

Fade unused functions and symbols consistently in the editor and Outline view.

## Best solution

Extend the outline symbol model or its diagnostic integration to recognize unnecessary-code diagnostics and render the corresponding symbol as faded, while preserving the existing `editor.showUnused` behavior.
