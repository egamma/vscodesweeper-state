# Issue #142439 — VSCode automatically scrolls to top of cell output when scrolling up

[https://github.com/microsoft/vscode/issues/142439](https://github.com/microsoft/vscode/issues/142439)

## Summary

The notebook anchoring logic now stops fighting upward user scrolling while output grows, addressing the reported viewport jump. The fix shipped in VS Code 1.84.0.

## Change summary

Prevent notebook output resizing from pulling the viewport back toward the focused cell while the user scrolls upward.

## Best solution

Keep the shipped anchoring behavior from commit 24c7e890da55dfce97e63335b5e88b9d42e83db1, which gives upward scrolling precedence over automatic cell anchoring.
