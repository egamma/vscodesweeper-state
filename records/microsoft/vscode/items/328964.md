## Summary

Single, 2-day-old report with no confirmed second reproduction; the code shows VS Code trusts Electron's `nativeTheme.shouldUseHighContrastColors`/`shouldUseInvertedColorScheme` on Windows (gated by `window.autoDetectHighContrast`, default true) to auto-switch themes, so something during the WSL-connect flow likely flipped that OS-level signal — but we need logs/confirmation before concluding root cause.

## Change summary
