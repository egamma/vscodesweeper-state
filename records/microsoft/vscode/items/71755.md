# Issue #71755 — Default formatter selection should write to project specific settings rather than global.

[https://github.com/microsoft/vscode/issues/71755](https://github.com/microsoft/vscode/issues/71755)

## Summary

The formatter picker still does not offer a user/workspace storage choice. Keep this accepted request open while the directly linked implementation candidate, https://github.com/microsoft/vscode/pull/317959, is reviewed.

## Change summary

Allow default formatter selection to save a language-specific preference at project or workspace scope instead of implicitly updating user settings.
