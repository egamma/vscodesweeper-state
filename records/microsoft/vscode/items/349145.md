# Issue #349145 — SCM Graph - keep the remote color for pushed commits when the branch is in sync with its upstream

[https://github.com/microsoft/vscode/issues/349145](https://github.com/microsoft/vscode/issues/349145)

## Summary

The requested color precedence is not available on current main. Keep this as a feature request for SCM design review: existing colors identify references, while the proposal would make lane colors communicate pushed status more consistently.

## Change summary

Prefer the upstream reference color when the current local branch and its upstream point to the same commit.

## Best solution

Have the SCM owner decide whether synchronized history should retain the upstream color rather than local-reference precedence. Settle that semantic change before implementation, treating the behind-upstream case as an explicit related design question rather than silently changing all branch colors.
