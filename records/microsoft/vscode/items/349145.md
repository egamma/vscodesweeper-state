# Issue #349145 — SCM Graph - keep the remote color for pushed commits when the branch is in sync with its upstream

[https://github.com/microsoft/vscode/issues/349145](https://github.com/microsoft/vscode/issues/349145)

## Summary

Keep open as the maintainer-confirmed feature request: current source still gives the local reference precedence when local and upstream share a commit. Existing graph settings do not provide the requested behavior, and the maintainer explicitly chose to retain this request.

## Change summary

Keep pushed history in the remote lane color when the current branch and its upstream point to the same commit.

## Best solution

Establish consistent local-versus-remote lane semantics in the SCM graph, then cover the synchronized state and push transition. Decide whether remote precedence becomes the default or an option, and explicitly settle the behind-upstream case.
