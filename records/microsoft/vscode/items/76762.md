# Issue #76762 — The `cursorWordPart`* commands are limited to editor text, unlike the other `cursorWord`* commands

[https://github.com/microsoft/vscode/issues/76762](https://github.com/microsoft/vscode/issues/76762)

## Summary

Subword navigation still lacks a native-input implementation, and this accepted Backlog request has 46 upvotes. A broader predecessor was declined on implementation-cost grounds, but the open rename issue covers only one surface; neither supports closing this broader accepted request.

## Change summary

Extend word-part cursor movement and selection commands to non-editor text inputs, including Quick Open, Find, and Rename.

## Best solution

Provide consistent subword navigation in workbench text inputs without changing editor navigation or imposing full-editor overhead everywhere. Before implementation, the area owner should reconcile this accepted request with the earlier decision against whole-UI support.
