# Issue #76762 — The `cursorWordPart`* commands are limited to editor text, unlike the other `cursorWord`* commands

[https://github.com/microsoft/vscode/issues/76762](https://github.com/microsoft/vscode/issues/76762)

## Summary

A real gap remains on current main: word-part commands still target code editors rather than focused workbench input boxes. This accepted Backlog request has 46 upvotes and remains the broad canonical issue.

## Change summary

Make cursor and deletion word-part commands work consistently in find, quick-open, rename, and other workbench text inputs.

## Best solution

Extend common workbench input handling so word-part movement, selection, and deletion operate on the focused InputBox while retaining existing editor behavior.
