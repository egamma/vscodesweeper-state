# Issue #123615 — [api][commands] Open new window and a file

[https://github.com/microsoft/vscode/issues/123615](https://github.com/microsoft/vscode/issues/123615)

## Summary

Team-authored feature request; the `vscode.newWindow` API still only accepts `reuseWindow` and `remoteAuthority` on current main — no support for passing files to open or extra resolver arguments. Keeping open per policy (MEMBER author) and because the gap remains real.

## Change summary

Extend the `vscode.newWindow` command API to accept files to open (and/or custom resolver arguments) when opening a new window on a remote authority.

## Best solution

Extend `INewWindowAPICommandOptions` in `src/vs/workbench/browser/actions/workspaceCommands.ts` to accept a `filesToOpen` array (and possibly custom resolver data), then thread those through to `_files.newWindow` / the window-open flow. This would let extensions like Azure ML open a remote window with a file without encoding extra data in the `remoteAuthority` string, avoiding spurious recently-opened entries and repeated workspace-trust prompts.
