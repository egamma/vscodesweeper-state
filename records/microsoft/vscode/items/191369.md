# Issue #191369 — Terminal title on Windows may not change when switched shortly after creating

[https://github.com/microsoft/vscode/issues/191369](https://github.com/microsoft/vscode/issues/191369)

## Summary

Keep open: current source suppresses the title update when git.exe is detected before the initial shell type has been established. The existing terminal-tabs routing is appropriate, and the startup case has a bounded regression-testable diagnosis.

## Change summary

Ensure a Windows terminal title changes to git when git log is launched immediately after terminal creation.

## Best solution

Windows process-name changes should reach the terminal title even when the detected shell type remains undefined, while preserving shell-type notification semantics, custom titles, and existing monitoring cadence.
