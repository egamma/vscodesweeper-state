# Issue #343907 — With Ordering: Updated, Move Up/Down on a nested session changes a hidden order instead of the visible one

[https://github.com/microsoft/vscode/issues/343907](https://github.com/microsoft/vscode/issues/343907)

## Summary

The reported mismatch remains in current source: Move Up/Down selects a visible neighbor but changes provider order, which Updated sorting ignores. Keep this open to decide whether manual reordering should affect the visible order or be unavailable in that mode.

## Change summary

Prevent nested-session reorder actions from silently changing hidden provider order while Updated sorting leaves the displayed rows unchanged.

## Best solution

Make nested-session reorder controls consistent with the active ordering mode across context menus, keyboard shortcuts, and drag feedback. A maintainer should choose between honoring an explicit visible reorder under Updated and disabling same-session manual reordering there, while preserving supported moves between sessions.
