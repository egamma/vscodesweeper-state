# Issue #343907 — With Ordering: Updated, Move Up/Down on a nested session changes a hidden order instead of the visible one

[https://github.com/microsoft/vscode/issues/343907](https://github.com/microsoft/vscode/issues/343907)

## Summary

The current source still mixes displayed update-time order with provider-stored chat order, allowing Move Down to change a hidden order without moving the visible row. Keep this scheduled issue open while the linked implementation candidate is reviewed.

## Change summary

Ensure nested-chat reordering actions do not silently modify provider order while Ordering: Updated displays a different order.

## Best solution

Review https://github.com/microsoft/vscode/pull/344293, which proposes offering chat reordering only under Ordering: Created. The completed behavior should prevent invisible same-session reorders under Updated while preserving legitimate moves between sessions.
