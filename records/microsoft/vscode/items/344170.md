# Issue #344170 — Terminal sticky scroll stays a white bar after its WebGL context is lost

[https://github.com/microsoft/vscode/issues/344170](https://github.com/microsoft/vscode/issues/344170)

## Summary

Keep open: current main still lacks WebGL context-loss handling for the terminal sticky-scroll overlay, unlike the terminal itself. The report provides a deterministic trigger, and the missing fallback is confirmed in source.

## Change summary

Recover terminal sticky-scroll rendering when its WebGL context is lost and does not recover.

## Best solution

Make the sticky-scroll overlay fall back to readable DOM rendering after unrecovered WebGL context loss and remain usable through subsequent commands, resizes, and option synchronization. Keep this scoped to overlay renderer recovery rather than diagnosing or preventing GPU process failures.
