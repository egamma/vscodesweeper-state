# Issue #141546 — Outline is empty when using Split JSON mode for settings editor

[https://github.com/microsoft/vscode/issues/141546](https://github.com/microsoft/vscode/issues/141546)

## Summary

Still reproduces on main: the outline pane calls `EditorResourceAccessor.getOriginalUri(pane?.input)` without `supportSideBySide`, which returns `undefined` for a SideBySideEditorInput with non-identical sides, causing the outline to bail out with 'no editor' message.

## Change summary

Outline view is empty when using the Split JSON settings editor because SideBySideEditorInput.resource returns undefined for non-identical sides.

## Best solution

In `src/vs/workbench/contrib/outline/browser/outlinePane.ts` line 217, pass `{ supportSideBySide: SideBySideEditor.PRIMARY }` to `EditorResourceAccessor.getOriginalUri` so the outline picks up the primary side's resource URI for side-by-side editors.
