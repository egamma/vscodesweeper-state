# Issue #141546 — Outline is empty when using Split JSON mode for settings editor

[https://github.com/microsoft/vscode/issues/141546](https://github.com/microsoft/vscode/issues/141546)

## Summary

The defect remains in current main: split settings provide a usable text editor, but Outline rejects the composite input because its resource lookup does not support side-by-side editors. Keep this open under the existing settings-editor classification.

## Change summary

Show the JSON document outline when settings are opened with workbench.settings.useSplitJSON enabled.

## Best solution

Allow Outline to display symbols for the active text document inside split JSON settings, with document identity and navigation consistent with the selected side. Preserve ordinary JSON Outline behavior and existing focus-change handling.
