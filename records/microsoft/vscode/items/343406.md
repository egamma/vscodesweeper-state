# Issue #343406 — Agent Host: switching to an untitled multi-root workspace sends disposeSession for existing Copilot CLI sessions, permanently deleting them

[https://github.com/microsoft/vscode/issues/343406](https://github.com/microsoft/vscode/issues/343406)

## Summary

The destructive workspace-change and teardown paths are fixed on current main by an explicit backend-ownership change. The suggested related issue is already closed as completed, so this should be closed as fixed rather than as a duplicate.

## Change summary

Preserve existing Copilot CLI sessions and their history when adding workspace folders or reloading into an untitled multi-root workspace.

## Best solution

Retain the ownership fix in commit 43c3a69a40c390e34b724f779feffde8796f969d: graduated sessions must survive workspace reconciliation and UI teardown without backend deletion or replacement.
