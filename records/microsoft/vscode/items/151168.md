# Issue #151168 — Search Marketplace button for missing notebook renderer doesn't work as expected

[https://github.com/microsoft/vscode/issues/151168](https://github.com/microsoft/vscode/issues/151168)

## Summary

Keep open: the missing-renderer button still searches a MIME type as ordinary Marketplace text rather than matching renderer capabilities. The older discovery issues do not establish a duplicate of this specific empty-results symptom, and On Deck records accepted work rather than grounds for declining it.

## Change summary

Make Search Marketplace find compatible notebook renderer extensions even when their descriptions do not mention the output MIME type.

## Best solution

Provide capability-aware discovery for missing notebook renderers across the notebook output and Marketplace search surfaces. A compatible extension should be discoverable from its contributed MIME types, not depend on incidental description text.
