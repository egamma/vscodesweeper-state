# Issue #316998 — [Bug] Incomplete Sanitization in htmlContent.ts (Copilot): Unescaped '<' Passes Raw HTML to MarkdownString

[https://github.com/microsoft/vscode/issues/316998](https://github.com/microsoft/vscode/issues/316998)

## Summary

Security-sensitive report: `appendText()` in both core and Copilot's `htmlContent.ts` does not escape `<`, relying solely on downstream DOM sanitization. The team acknowledges this via CodeQL suppressions, and the downstream renderer does sanitize, but the defense-in-depth concern is valid. Keeping open for a human to evaluate the hardening request.

## Change summary

The `appendText()` method escapes `>` but not `<`, allowing raw HTML open tags to pass through to the MarkdownString value before downstream sanitization.

## Best solution

Evaluate whether escaping `<` in `appendText()` (adding `.replace(/</gm, '\<')` alongside the existing `>` escape) is a worthwhile defense-in-depth hardening, or explicitly document/confirm the current design as intentional. The fix would be small and localized in both `src/vs/base/common/htmlContent.ts` and `extensions/copilot/src/util/vs/base/common/htmlContent.ts`.
