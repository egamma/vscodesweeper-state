# Issue #308887 — Chat/Configure Tools/Update Tools disables OK button, unless fold tool

[https://github.com/microsoft/vscode/issues/308887](https://github.com/microsoft/vscode/issues/308887)

## Summary

The defect remains present on current main: updating an MCP server rebuilds the tool tree while the non-pickable Update Tools callback can remain active, causing OK to invoke that callback again instead of accepting the selection. The reported collapse workaround is consistent with changing tree focus and clearing that stale activation.

## Change summary

After Update Tools refreshes an expanded MCP entry, the Configure Tools dialog's OK button does not close or save until that entry is collapsed.

## Best solution

Ensure that rebuilding the Configure Tools tree after an MCP update reconciles or clears activation of the removed callback item, so OK immediately accepts the refreshed selection while preserving tool check states.
