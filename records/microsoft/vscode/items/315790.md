## Summary

Team-authored feature request to add pricing-based sorting to the model picker or Manage Models menu. No existing sort-by-pricing capability found on main; the model picker currently sorts by label only. Keeping open per team-authored item rules.

## Change summary

Allow sorting models by pricing (input cost, output cost, or relative 'dot' pricing) in the model picker or Manage Models menu.

## Best solution
