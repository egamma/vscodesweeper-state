# Issue #317035 — Integrated Browser: Page is blocked while paused

[https://github.com/microsoft/vscode/issues/317035](https://github.com/microsoft/vscode/issues/317035)

## Summary

Team-authored upstream bug with a Chromium issue already filed (issuetracker.google.com/issues/514195872). The root cause is in Chromium's inspect overlay not rendering when paused in a requestAnimationFrame callback. Stays open to track upstream resolution.

## Change summary

The integrated browser's inspect overlay stops rendering when the debugger is paused (typically via the pause button hitting a RAF callback), blocking page interaction feedback.

## Best solution

Track the upstream Chromium fix at https://issuetracker.google.com/issues/514195872. Once Chromium ships the fix and the Electron dependency is updated, this resolves automatically. No VS Code-side workaround is practical since the behavior is in the browser engine's DevTools protocol overlay rendering.
