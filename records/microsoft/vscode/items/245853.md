# Issue #245853 — Discard Changes dialog buttons inconsistent with meaning

[https://github.com/microsoft/vscode/issues/245853](https://github.com/microsoft/vscode/issues/245853)

## Summary

Still present on main: the confirm button reads "Discard File" when the action only discards changes to a tracked file. The dialog message itself says "discard changes" — the button label is inconsistent. The issue is milestoned On Deck and has a satellite duplicate (#285361). Keeping open as a valid polish item.

## Change summary

The "Discard Changes" confirmation dialog button is labeled "Discard File" for tracked files, which is misleading since only changes are discarded, not the file itself.

## Best solution

Change the button label at `extensions/git/src/commands.ts` line 2306 from `l10n.t('Discard File')` to `l10n.t('Discard Changes')` for the non-deleted single-file case. The multi-file variant at line 2307 should similarly be reviewed. The satellite issue https://github.com/microsoft/vscode/issues/285361 should be closed as a duplicate of this one.
