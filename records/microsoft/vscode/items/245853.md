# Issue #245853 — Discard Changes dialog buttons inconsistent with meaning

[https://github.com/microsoft/vscode/issues/245853](https://github.com/microsoft/vscode/issues/245853)

## Summary

The tracked-file confirmation still says “Discard File” although it discards changes, not the file. Keep this older report as the tracking issue; the matching open report was filed later and cannot serve as its canonical.

## Change summary

Label the confirmation for discarding changes to an existing tracked file “Discard Changes” rather than “Discard File”.

## Best solution

Make the tracked-file confirmation describe the operation accurately, while preserving distinct wording for restoring deleted files and deleting untracked files. Keep the underlying Git operations unchanged.
