## Change summary

The 'Discard File' button label in the discard-changes confirmation dialog is misleading for tracked files — it should say 'Discard Changes' since only changes are discarded, not the file itself.

## Best solution

In `extensions/git/src/commands.ts` line ~2306, change the button label from `l10n.t('Discard File')` to `l10n.t('Discard Changes')` for the single-tracked-file non-deleted case, keeping `Discard File` (or `Delete File`) only for untracked files. The related issue https://github.com/microsoft/vscode/issues/285361 should be closed as a duplicate of this one.
