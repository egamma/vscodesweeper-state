# Issue #334842 — SCM view keeps only one repository visible after a new repository is discovered before a previously-visible one

[https://github.com/microsoft/vscode/issues/334842](https://github.com/microsoft/vscode/issues/334842)

## Summary

Excellent, source-verified bug report: the exact logic flaw the reporter traced is present on current main, and an open PR already targets the fix, so this stays open pending that PR landing rather than being closed or auto-fixed.

## Change summary

In multi-root workspaces, discovering a new repository before a previously-visible one causes the SCM view to collapse to showing only one repository, and the bad state persists across restarts.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/334845 ("Keep all repositories visible when a new one is discovered first"), which appears to implement the reporter's suggested fix of not consulting `previousState` further once branch (A) in `onDidAddRepository` has decided to select all repositories.
