# Issue #347113 — A group of sessions disappears from inbox if a child is running something?

[https://github.com/microsoft/vscode/issues/347113](https://github.com/microsoft/vscode/issues/347113)

## Summary

Keep open: the reported steps suffice to retest parent visibility when a nested session starts working. Current source classifies the entire session by aggregate status, which could explain the disappearance from Inbox, but the exact screenshot scenario has not been reproduced.

## Change summary

Starting work in a child session removes its independently usable parent from the primary Inbox.

## Best solution

Preserve discoverability of independently actionable parent conversations while nested conversations are working. Establish the intended Inbox classification for mixed-state session groups before changing the Sessions list.
