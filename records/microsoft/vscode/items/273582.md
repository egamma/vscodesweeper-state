# Issue #273582 — Terminal suggest: Support path completions without the ./

[https://github.com/microsoft/vscode/issues/273582](https://github.com/microsoft/vscode/issues/273582)

## Summary

The requested capability is still missing: current resource completions add ./ or .\ even when the user types an unprefixed path. Keep this accepted terminal-suggest request open; the related PowerShell report was consolidated into this issue, and no verified open canonical or fixing PR was found.

## Change summary

Support terminal file and folder completions that preserve an unprefixed relative path instead of always adding ./ or .\.

## Best solution

Make relative-path suggestions follow the user's typed format while retaining explicitly prefixed paths and shell-required executable prefixes. Resolve the default behavior for empty input and command-position completions with the terminal maintainer before implementation.
