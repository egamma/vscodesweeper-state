## Change summary

The GitHub repo picker in the Agents window loads slowly, is hard to discover, lacks caching, and does not accept a pasted URL when search fails.

## Best solution

Improve the repo picker with a cached repo list, a clearer entry point for 'Work in GitHub', an indication of private-only results, and a paste-a-URL fallback. The code is in the Agents window workspace picker, src/vs/sessions/contrib/chat/browser.
