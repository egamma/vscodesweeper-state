# Issue #287498 — PHP autoindent behavior is broken (since 1.108)

[https://github.com/microsoft/vscode/issues/287498](https://github.com/microsoft/vscode/issues/287498)

## Summary

Keep open: current PHP indentation rules still omit brace handling, and the editor's rule-based paths can consequently discard block indentation. The discussion confirms the regression; the advanced-autoIndent workaround does not resolve the default behavior.

## Change summary

Preserve PHP block indentation when inserting a newline before existing code and correctly infer indentation when pressing Tab on an empty nested line.

## Best solution

Restore correct indentation for PHP brace-delimited blocks under editor.autoIndent=full while preserving alternative-syntax indentation and the array behavior addressed by the earlier change. Cover the reported Enter and Tab cases using the actual shipped PHP configuration.
