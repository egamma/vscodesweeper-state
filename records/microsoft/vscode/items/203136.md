# Issue #203136 — Testing #203097: Unecessary screen jumping on chevron clicking

[https://github.com/microsoft/vscode/issues/203136](https://github.com/microsoft/vscode/issues/203136)

## Summary

Keep open: folding through a notebook sticky-scroll chevron still unconditionally repositions the viewport, even when the header is already visible. The closely related folding-position report is newer, so it cannot replace this team-authored, previously reviewed issue under the duplicate rules.

## Change summary

Avoid unnecessary viewport jumps when folding a notebook section through its sticky-scroll chevron while the original header is already visible.

## Best solution

Preserve the user's viewport when the section header is already visible, while retaining necessary reveal behavior when folding would otherwise leave the user disoriented. Keep explicit header-click navigation distinct from chevron folding.
