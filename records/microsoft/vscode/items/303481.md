# Issue #303481 — Crash when VS Code runs out of RAM on Linux but not on Windows

[https://github.com/microsoft/vscode/issues/303481](https://github.com/microsoft/vscode/issues/303481)

## Summary

Keep open: the reporter supplied an extension-disabled reproduction and another Ubuntu user confirmed it. The simultaneous process terminations need investigation to distinguish Linux memory-pressure killing from a VS Code recovery defect; neither a fix nor a canonical duplicate is established.

## Change summary

Keep VS Code running when a Python process launched in its integrated terminal exhausts system RAM on Ubuntu.

## Best solution

Establish which process or OS memory-pressure mechanism terminates the VS Code processes, using current-build logs and the system journal. If VS Code mishandles a surviving host's child-process failure, correct that recovery path; externally terminated processes cannot catch the termination as a Python exception.
