- **setting semantics:** src/vs/workbench/electron-browser/desktop.contribution.ts registers `window.restoreWindows` as controlling restoration when opening VS Code; `all` and `preserve` restore prior windows under different startup conditions.
- **macOS lifecycle distinction:** src/vs/platform/windows/electron-main/windowsStateHandler.ts documents separate macOS flows: Quit invokes `onBeforeShutdown` and persists the full windows state, while closing one window invokes only `onBeforeCloseWindow`. src/vs/platform/windows/electron-main/windowsMainService.ts restores folders and workspaces from that persisted state during initial startup.
