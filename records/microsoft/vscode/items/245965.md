# Issue #245965 — Option to Disable Bidirectional Text Rendering in Visual Studio Code

[https://github.com/microsoft/vscode/issues/245965](https://github.com/microsoft/vscode/issues/245965)

## Summary

Legitimate feature request under active discussion with alexdima. The reporter built a workaround extension (Free Bidi Editor) but asks for a core setting to disable/override bidi rendering. The maintainer engaged with a tokenization-based approach; the conversation is ongoing. Keep open.

## Change summary

Request for a built-in editor setting to disable or override bidirectional text rendering, forcing consistent LTR display for mixed-script code (e.g. COBOL with Hebrew).

## Best solution

The maintainer and reporter are actively exploring whether the existing token-level bidi isolation (unicode-bidi:isolate per syntactical token in viewLineRenderer.ts) can be extended or complemented by a setting like `editor.bidiTextRendering` to force LTR within tokens. A decision on whether this belongs in core or stays as an extension-level workaround (via TM grammar / semantic tokens) is still needed from the area owner.
