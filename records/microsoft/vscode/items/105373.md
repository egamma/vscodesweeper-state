# Issue #105373 — Allow snippets to target standard token types

[https://github.com/microsoft/vscode/issues/105373](https://github.com/microsoft/vscode/issues/105373)

## Summary

A real capability gap remains on current main: snippets can target languages and files, but not standard token types. Keep the Backlog request open for a product decision and classify it as under discussion.

## Change summary

Allow individual snippets to opt into or out of comments, strings, regex tokens, and ordinary code.

## Best solution

Add optional standard-token-type metadata to the snippet schema and model, then filter candidates in SnippetCompletionProvider while preserving existing snippets' behavior by default.
