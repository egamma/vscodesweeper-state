## Change summary

Suggestion documentation in the Python REPL lacks syntax highlighting for auto-import strings, unlike the same suggestions in a normal editor.

## Best solution

The markdown renderer in `simpleSuggestWidgetDetails.ts` needs a language hint when rendering code blocks in the REPL context. The fix likely involves passing the correct language ID (from the REPL's kernel or notebook cell language) through to the markdown rendering call so code blocks get proper tokenization. The terminal suggest addon (`terminalSuggestAddon.ts`) or the completion provider should propagate the language context.
