# Issue #258688 — Some suggestion syntax highlighting missing in repl suggestions

[https://github.com/microsoft/vscode/issues/258688](https://github.com/microsoft/vscode/issues/258688)

## Summary

Keep open: terminal suggestion documentation lacks the language-context fallback used by editor suggestions, leaving unlabelled code blocks without Python highlighting. No verified canonical or completed fix was found.

## Change summary

Python REPL suggestion documentation should highlight auto-import snippets consistently with suggestions in a Python editor.

## Best solution

Preserve the Python completion's language context through terminal suggestion documentation rendering so unlabelled code blocks receive Python tokenization. Explicitly labelled code blocks and ordinary shell suggestions should retain their existing behavior.
