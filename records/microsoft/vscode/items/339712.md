# Issue #339712 — Same, built-in, message used every time when using append mode in `sessions.chat.experimental.welcomeName`

[https://github.com/microsoft/vscode/issues/339712](https://github.com/microsoft/vscode/issues/339712)

## Summary

The repeated first phrase is explained by current source: each window reload resets the welcome-phrase counter to zero, selecting the first built-in phrase again. Keep this team-authored report open; append mode includes custom phrases correctly, but its selection state does not survive reloads.

## Change summary

Allow the new-session welcome heading to vary across window reloads instead of repeatedly selecting the first built-in phrase in append mode.

## Best solution

Make welcome-phrase selection across reloads give both built-in and appended phrases an opportunity to appear, while retaining stable text within an existing composer and preserving replace-mode behavior.
