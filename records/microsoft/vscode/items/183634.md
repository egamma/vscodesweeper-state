# Issue #183634 — Show the extension details (instead of just the title) in extension's settings

[https://github.com/microsoft/vscode/issues/183634](https://github.com/microsoft/vscode/issues/183634)

## Summary

The requested extension identity details remain absent from the Settings editor's navigation and section headings. Keep this accepted Backlog request open; extension-ID filtering offers a workaround but does not address browsing similarly named extensions.

## Change summary

Show publisher information and extension icons in Settings navigation and headings so users can distinguish similarly named extensions.

## Best solution

Provide consistent extension identity cues in the Settings editor's extension navigation and headings, using publisher information to disambiguate names and considering icons within the existing compact layout.
