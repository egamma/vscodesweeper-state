# Issue #339689 — Unclear how many of my sessions the checkbox options will automatically delete / mark done

[https://github.com/microsoft/vscode/issues/339689](https://github.com/microsoft/vscode/issues/339689)

## Summary

Keep open: the automatic cleanup controls still do not show how many current sessions each threshold affects. This team-authored request remains distinct from the older report about when enabling cleanup takes effect.

## Change summary

Show affected-session counts beside the automatic mark-as-done and permanent-deletion controls for their respective day thresholds.

## Best solution

Provide an accessible, current impact preview for each automatic cleanup option in the Worktree Cleanup editor, using the corresponding lifecycle eligibility rules rather than the manual worktree-cleanup count. Preserve existing cleanup timing and settings behavior.
