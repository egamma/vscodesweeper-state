# Issue #316794 — Support custom headers or stable chat session identifiers for BYOK/OpenAI-compatible model providers

[https://github.com/microsoft/vscode/issues/316794](https://github.com/microsoft/vscode/issues/316794)

## Summary

Static requestHeaders already cover part of this request, but conversation-stable metadata remains missing on current main. Keep this issue open while the linked middleware PR and its session-ID follow-up are reviewed; neither has merged.

## Change summary

Allow BYOK requests to carry configurable headers whose session identifier stays stable across one conversation and differs between conversations.

## Best solution

Review https://github.com/microsoft/vscode/pull/337130 together with https://github.com/microsoft/vscode/pull/337203 as implementation candidates for conversation-aware gateway headers. Resolve whether extension middleware sufficiently serves the requested configuration-only workflow before treating the remaining request as completed.
