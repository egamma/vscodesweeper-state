# Issue #316794 — Support custom headers or stable chat session identifiers for BYOK/OpenAI-compatible model providers

[https://github.com/microsoft/vscode/issues/316794](https://github.com/microsoft/vscode/issues/316794)

## Summary

Keep open as a BYOK feature request: current main already supports static `requestHeaders` for custom endpoint/OpenAI-compatible BYOK models, but the remaining request for a stable per-chat `${sessionId}`-style value is not covered by the current configuration surface.

## Change summary

Allow BYOK/OpenAI-compatible providers to receive custom static headers and/or a stable chat-session identifier for routing, caching, auth, and observability.

## Best solution

Keep the issue scoped to the remaining dynamic session identifier variable/header decision in the BYOK model configuration path. Static custom headers appear implemented already; maintainers should decide whether exposing a stable chat session id to provider headers is acceptable from privacy, cache isolation, and API-design perspectives.
