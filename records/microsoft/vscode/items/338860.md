## Summary

Legitimate, well-scoped request to let users lock Copilot to local/BYOK models only and never silently fall back to a cloud provider; it's parked in Backlog Candidates with only 4 upvotes (below the 20-vote bar), so per policy it stays open under the community process rather than being closed for being quiet, and a second reviewer (prior review) already left it open with no new closing evidence since.

## Change summary

Add a setting/control so Copilot never automatically switches from an unavailable local (BYOK/Ollama) model to a default external LLM provider without explicit user consent.

## Best solution

Add an explicit opt-out (e.g. a BYOK/model-selection setting) that blocks silent fallback to non-local providers when the selected local model is unavailable, surfacing an error/prompt instead of silently routing the request elsewhere — likely in the BYOK provider selection or chat model-routing logic (extensions/copilot/src/extension/byok/ and the chat endpoint/model-selection path such as chatMLFetcher.ts / modelSelection.ts).
