# Issue #338860 — Option to disable fallback to external LLM models

[https://github.com/microsoft/vscode/issues/338860](https://github.com/microsoft/vscode/issues/338860)

## Summary

Reasonable, freshly-filed request for a setting to stop Copilot Chat from silently falling back to external LLM providers when a configured local/BYOK model (e.g. Ollama) becomes unavailable; no existing setting covers this and it's too new (same day, 1 upvote, no maintainer input) to have a settled design, so it stays open for triage/design.

## Change summary

Add a config option so Copilot Chat never silently falls back to an external LLM provider when the user's chosen local model (e.g. via Ollama BYOK) is offline.

## Best solution

Needs a maintainer decision on the right mechanism — likely a chat model-selection setting/policy in the BYOK or model-picker layer (extensions/copilot/src/extension/byok, src/vs/workbench/contrib/chat/common/modelSelection.ts) that keeps the request pending/blocked instead of auto-selecting a fallback model when the desired provider is unreachable.
