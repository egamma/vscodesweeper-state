# Issue #326520 — Copilot Chat (Agents): folder picker defaults to alphabetically first repository in multi-repo workspace, no way to prefer workspace root

[https://github.com/microsoft/vscode/issues/326520](https://github.com/microsoft/vscode/issues/326520)

## Summary

The extension-backed Copilot CLI picker still defaults to the alphabetically first repository when no selection is supplied. Keep this request open: newer agent-host folder defaults partially address the goal on a different path, but do not establish that the reported submodule workflow is resolved.

## Change summary

Prefer the workspace root or remember the chosen repository for new Copilot CLI sessions without disabling Git submodule detection.

## Best solution

Give new extension-backed Copilot CLI sessions a predictable workspace-aware folder default while preserving explicit submodule selection. Decide whether workspace-root preference or a remembered choice should govern fresh sessions, and keep that behavior consistent with the newer agent-host experience.
