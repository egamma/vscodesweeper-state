# Issue #339861 — Auto resizing behavior in the grid is confusing

[https://github.com/microsoft/vscode/issues/339861](https://github.com/microsoft/vscode/issues/339861)

## Summary

Keep open: current source still conditionally expands panes on activation, but the reported middle-row insertion sequence has not been conclusively reproduced. The grid now has topology-preservation tests; the supplied steps suffice to retest the remaining sizing behavior.

## Change summary

Adding a chat to an evenly divided middle row can unexpectedly change pane widths and row height, with additional inconsistent resizing on focus.

## Best solution

Make ordinary insertion and activation predictable without disturbing unrelated user-sized branches. Evaluate row-local redistribution and focus-driven expansion separately; existing explicit maximize/restore controls already cover part of the suggested alternative.
