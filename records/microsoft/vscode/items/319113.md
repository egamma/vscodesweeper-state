## Summary

This security-sensitive safety report must remain open for human review. It identifies a real gap between prompt-based instructions and enforceable authorization boundaries, but combines several distinct product and policy decisions rather than defining one bounded implementation.

## Change summary

Add enforceable, persistent guardrails for agent-driven file changes and destructive infrastructure operations, including hard gates, dry runs, scoped authorization, blast-radius limits, and session-reset handling.

## Best solution

Agent and tool owners should define a platform-level authorization model for consequential operations, with durable policy state, explicit operation-scoped approval, preview-before-execution, and reauthorization after session boundaries. The broad proposal should first be decomposed into independently testable requirements across the agent host, tool permission system, and enterprise policy surfaces.
