# Issue #336438 — Report Issue wizard resets when its editor tab is moved to another group

[https://github.com/microsoft/vscode/issues/336438](https://github.com/microsoft/vscode/issues/336438)

## Summary

The defect remains present on current main: moving the singleton editor rebuilds its pane-local wizard, while the shared input preserves only attachments. The report includes a confirmed automated reproduction and a complete source trace, so it should remain open for a bounded state-preservation fix.

## Change summary

Moving the Report Issue editor to another editor group resets its wizard, draft, preview, diagnostics, and unsaved screenshot-annotation state.

## Best solution

Make the Report Issue editor's restorable state follow its singleton editor input so pane recreation preserves the active wizard step, draft selections, diagnostic options, preview state, attachments, and any in-progress annotation session.
