# Issue #336438 — Report Issue wizard resets when its editor tab is moved to another group

## Summary

Team-authored, well-documented bug with a confirmed root cause traced in current source; no fix has landed yet, so this stays open for implementation.

## Change summary

Moving the Report Issue editor tab to another group recreates the wizard and drops in-progress wizard/annotation state that isn't mirrored onto the shared editor input.

## Best solution

Extend IssueReporterEditorInput to be the source of truth for full wizard state (step, draft fields, diagnostics toggles, active annotation state), as outlined in the issue's own proposed fix, in src/vs/workbench/contrib/issue/browser/issueReporterOverlay.ts and issueReporterEditorInput.ts, then add the editor integration test the reporter suggests.
