# Issue #336541 — Selected item outline has inconsistent padding across suggestion and code action menus

[https://github.com/microsoft/vscode/issues/336541](https://github.com/microsoft/vscode/issues/336541)

## Summary

Fresh, plausible visual-consistency nit: the suggest widget (src/vs/editor/contrib/suggest/browser/media/suggest.css) and the Code Actions widget (src/vs/platform/actionWidget/browser/actionWidget.css) each define their own focused-row padding/outline treatment rather than sharing one, so a visible difference is real, but it's a design call, not a mechanical bug fix.

## Change summary

Requests that the focused/selected-item outline use the same padding and border radius in the suggest (autocomplete) widget and the Code Actions menu.
