# Issue #336541 — Selected item outline has inconsistent padding across suggestion and code action menus

[https://github.com/microsoft/vscode/issues/336541](https://github.com/microsoft/vscode/issues/336541)

## Summary

Current main still gives equivalent selected rows visibly different spacing, radius, and outline geometry. The older related issue covers only clipping in the suggestion widget, so it is too narrow to absorb this cross-widget consistency request.

## Change summary

Make selected-item spacing, outline placement, and corner treatment consistent between completion suggestions and Code Actions.

## Best solution

Choose a common selected-row treatment for editor suggestion and action overlays, then express both widgets using the same spacing and elevation roles while preserving their content-density requirements.
