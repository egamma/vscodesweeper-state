# Issue #332665 — macOS: missing folder remains in File > Open Recent after failed open

[https://github.com/microsoft/vscode/issues/332665](https://github.com/microsoft/vscode/issues/332665)

## Summary

Confirmed in source: the main-process Menubar caches its menu and only rebuilds via renderer-driven `updateMenu`, so when a recent-item open fails with zero windows open, `removeRecentlyOpened` updates history but the cached menu is never refreshed. A contributor has already opened a fix PR, so this should stay open for that PR to land rather than be closed now.

## Change summary

On macOS, choosing a deleted folder from File > Open Recent shows the expected error, but the stale entry isn't pruned from the menu afterward.

## Best solution

Land https://github.com/microsoft/vscode/pull/333032, which wires `onDidChangeRecentlyOpened` into the electron-main Menubar so it rebuilds/prunes stale recent items even with zero windows open (matching the removal already done in `createOpenRecentMenuItem` in src/vs/platform/menubar/electron-main/menubar.ts).
