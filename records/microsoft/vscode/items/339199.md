# Issue #339199 — macOS: Remote status bar corner is clipped with Modern UI enabled

[https://github.com/microsoft/vscode/issues/339199](https://github.com/microsoft/vscode/issues/339199)

## Summary

Confirmed from source: the Modern UI status bar module rounds the leftmost/rightmost status bar pill with a fixed controls-tier radius that never accounts for macOS Tahoe's larger native window corner, unlike the equivalent base-statusbar focus rule and the editor/panel 'floating panels' module, which both already special-case `.mac.macos-tahoe`. Real, bounded visual bug, but niche (experimental setting + newer macOS + Remote SSH) and the exact fix approach is an open design call, so this stays open rather than being handed straight to an agent to implement.

## Change summary

With `workbench.experimental.modernUI` enabled on macOS 26/27, the rounded pill behind the Remote SSH status bar indicator uses a small, fixed corner radius that is visually clipped by the OS's larger native window corner.

## Best solution

Extend the Modern UI corner-radius handling for the edge status-bar item pills (`.first-visible-item` / `.last-visible-item` in roundedCorners.css/statusBar.css) to account for macOS Tahoe's larger window-chrome radius — either reusing the dynamic macOS-corner-matching approach already used for the editor/sidebar/panel in editorBorder.css/floatingPanels.css, or adding a `.mac.macos-tahoe` override mirroring the one already present for the base statusbar's focus-corner rule in statusbarpart.css (lines 25-28).

## Evidence
