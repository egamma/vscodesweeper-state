# Issue #191889 — ILanguageService events only fire once

[https://github.com/microsoft/vscode/issues/191889](https://github.com/microsoft/vscode/issues/191889)

## Summary

The late-listener limitation remains in current main: both events expose ordinary emitters, while requests are permanently deduplicated per language. Keep this team-authored debt item open; no verified fix or older canonical issue supports a factual close.

## Change summary

Address language-feature request notifications that leave listeners registered after the first request unaware of previously requested languages.

## Best solution

Provide a supported way for late consumers to learn which languages have already requested basic or rich features, while preserving once-per-language activation and tokenizer initialization. The language-service owner should establish the notification contract before changing subscription behavior.
