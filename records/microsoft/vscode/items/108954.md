# Issue #108954 — Matching bracket decoration and :after decoration clash

[https://github.com/microsoft/vscode/issues/108954](https://github.com/microsoft/vscode/issues/108954)

## Summary

Still reproducible on main: the `.bracket-match` CSS class applies background-color and border without scoping, so it visually leaks into `::after` pseudo-element decorations created by extensions. No fix has landed.

## Change summary

Matching bracket highlight decoration visually bleeds into extension-created `::after` pseudo-element decorations placed near brackets.

## Best solution

Scope the `.bracket-match` CSS rules to exclude `::after`/`::before` pseudo-elements (e.g. `.monaco-editor .bracket-match:not(::after)` or resetting styles on `.bracket-match::after`), so bracket highlighting does not leak into extension decoration pseudo-elements. The fix lives in `src/vs/editor/contrib/bracketMatching/browser/bracketMatching.css`.
