# Issue #328359 — Agent: submit / act on feedback buttons broken in 1.131.0

[https://github.com/microsoft/vscode/issues/328359](https://github.com/microsoft/vscode/issues/328359)

## Summary

Real, intermittent bug in the Agents Window feedback/act-on-feedback flow: the widget lookup used by `submitFeedback` sometimes fails to find the chat widget for a live session, silently dropping the submit. A contributor (benibenj) is already actively engaging and gathering logs, and root cause isn't pinned down yet, so this should stay open rather than being force-classified.

## Change summary

Clicking submit / act-on-feedback intermittently does nothing because the session's chat widget can't be resolved, and once broken the session stops responding to further feedback comments.

## Best solution

Investigate why `whenWidgetForSession`/`IChatWidgetService.getWidgetBySessionResource` in src/vs/sessions/contrib/agentFeedback/browser/agentFeedbackService.ts loses track of a live agent-host session's widget, especially after using the 'Run Code Review' action from the Changes panel (per the reporter's latest comment) — likely a widget-registration/lifecycle race rather than a simple missing-timeout bug.
