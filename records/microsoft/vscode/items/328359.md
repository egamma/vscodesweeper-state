# Issue #328359 — Agent: submit / act on feedback buttons broken in 1.131.0

[https://github.com/microsoft/vscode/issues/328359](https://github.com/microsoft/vscode/issues/328359)

## Summary

Real, reproduced bug (console error + video) where submitting agent feedback silently fails after a session gets a second chat part (e.g. via 'Run Code Review'); a contributor is actively diagnosing and just asked the reporter a specific follow-up question that hasn't been answered yet, so this stays in info-needed pending that reply.

## Change summary

Clicking 'Submit'/act-on-feedback in the agent feedback UI does nothing for some sessions, logging 'no chat widget found for session' in the console.

## Best solution

In src/vs/workbench/contrib/chat/browser/widget/chatWidgetService.ts, getWidgetBySessionResource() does `this._widgets.find(w => isEqual(w.viewModel?.sessionResource, sessionResource))`, returning only the first matching widget; once the reporter confirms whether a second chat part (from 'Run Code Review') is the trigger, the fix likely needs to make agentFeedbackService.ts's whenWidgetForSession/submitFeedback resolve the correct/active widget when multiple widgets share a sessionResource, rather than an arbitrary first match.
