# Issue #296234 — The background color of the “Remote Indicator” on the status bar is wrong in new Experiment 2026 theme.

[https://github.com/microsoft/vscode/issues/296234](https://github.com/microsoft/vscode/issues/296234)

## Summary

The report is actionable and still appears valid from the current theme sources: the Experiment 2026 themes define `statusBarItem.remoteBackground` as `#4BBCCB` while the main prominent/status accent is a darker blue/cyan, producing the mismatch the reporter describes. This should stay open with the existing 2026 theme routing rather than be closed or sent for more information.

## Change summary

The Remote Indicator active background in the new Experiment 2026 theme does not match the blue/cyan accent used by the rest of the status bar treatment.

## Best solution

Have the 2026 theme owners decide and adjust the `statusBarItem.remoteBackground` token in the Experiment 2026 Dark and Light theme definitions if the remote indicator is intended to share the same accent family as the other prominent status bar items.
