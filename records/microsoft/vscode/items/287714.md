# Issue #287714 — Reverse search in zsh not working when EDITOR env variable is set to vim

[https://github.com/microsoft/vscode/issues/287714](https://github.com/microsoft/vscode/issues/287714)

## Summary

This is zsh's native vi-mode behavior, not a VS Code bug. When EDITOR=vim is set, zsh switches to vi keybindings where Ctrl+R is unbound; this happens identically in every terminal emulator. VS Code neither intercepts bare Ctrl+R in the terminal nor modifies zsh keymaps via shell integration.

## Change summary

Ctrl+R reverse-incremental-search stops working in the integrated terminal's zsh when EDITOR=vim is exported.

## Best solution

Close as designed — the behavior is zsh's vi-mode keymap, not VS Code's. The user can restore Ctrl+R in vi mode by adding `bindkey '^R' history-incremental-search-backward` to their .zshrc after setting EDITOR.
