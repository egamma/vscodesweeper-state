# Issue #340166 — Chat does not have an option to require permission prompts for all terminal commands.

[https://github.com/microsoft/vscode/issues/340166](https://github.com/microsoft/vscode/issues/340166)

## Summary

Keep open as a permission-picker feature request. Terminal auto-approval controls already exist in Settings, but the picker does not provide the requested direct, frequently changeable option to require approval for every terminal command.

## Change summary

Expose a require-approval-for-all-terminal-commands option directly in the Chat permissions popup.

## Best solution

Provide a discoverable terminal approval control in the permissions picker, with clearly defined scope and precedence relative to Allow all, session approvals, and sandboxing. Reuse the existing permission mechanisms rather than introduce a competing approval policy.
