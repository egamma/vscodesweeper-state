# Issue #345596 — Ability to control which models Copilot Fusion uses

[https://github.com/microsoft/vscode/issues/345596](https://github.com/microsoft/vscode/issues/345596)

## Summary

Keep open as a distinct Fusion model-selection request. Existing controls change routing preferences or enablement, not the constituent models allowed for each pass; the related configuration proposal does not explicitly cover that capability.

## Change summary

Allow users to constrain the models Copilot Fusion uses, optionally by orchestration pass.

## Best solution

Evaluate a runtime-supported model allowlist for Fusion, with per-pass assignments considered as a separate product decision. Any resulting VS Code controls should reflect runtime capabilities and respect managed model restrictions.
