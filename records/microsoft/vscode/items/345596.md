# Issue #345596 — Ability to control which models Copilot Fusion uses

[https://github.com/microsoft/vscode/issues/345596](https://github.com/microsoft/vscode/issues/345596)

## Summary

Keep open: Fusion effort levels bias routing but do not provide the requested constituent-model controls. The related configuration proposal and newer Fusion opt-out request do not establish a canonical covering this request's full scope.

## Change summary

Allow users to restrict Copilot Fusion's model choices, potentially separately for each workflow pass.

## Best solution

Define a runtime-enforced model-selection contract for Fusion, exposed through the existing model configuration experience. Decide whether restrictions apply to the entire workflow or individual passes, including what happens when no eligible model remains.
