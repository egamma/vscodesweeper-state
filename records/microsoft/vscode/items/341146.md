# Issue #341146 — permissions.defaultMode not set to assisted

[https://github.com/microsoft/vscode/issues/341146](https://github.com/microsoft/vscode/issues/341146)

## Summary

Thanks for the test report. The managed setting `permissions.defaultMode` is declared and delivered, but I found no non-test code that applies it to a new chat's initial permission level, which matches what you saw. It is a plausible gap in the feature tracked by #340781.

## Change summary

A managed `permissions.defaultMode = "assisted"` is loaded but new chats still start in Allow all instead of Assisted permissions.

## Best solution

Make the initial permission level for new chats honor the managed `permissions.defaultMode`. It should still be clamped by `permissions.disableAssistedPermissionsMode` and `permissions.disableBypassPermissionsMode`, and apply where `chat.permissions.default` is resolved.
