# Issue #330607 — vscode.dev not switching to new branch for repo in private emu org

[https://github.com/microsoft/vscode/issues/330607](https://github.com/microsoft/vscode/issues/330607)

## Summary

This is about the built-in GitHub Repositories extension that powers vscode.dev's '.' shortcut for browsing/editing GitHub repos — its source and issue tracking live in the separate microsoft/vscode-remote-repositories-github repo, not in this one, so per team practice it should be moved there rather than triaged here.

## Change summary

Switching to a newly created branch in vscode.dev (for a repo in a private GitHub EMU org) briefly loads the branch then bounces back to main, because the extension's request to GitHub's extract-ref API is sent unauthenticated and gets rate-limited/404s.

## Best solution

Move this issue to https://github.com/microsoft/vscode-remote-repositories-github, where the GitHub Repositories extension's ref-resolution/auth code (the extract-ref call flow) actually lives, so the extension owners can add the missing auth header to that request.
