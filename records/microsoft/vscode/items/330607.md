# Issue #330607 — vscode.dev not switching to new branch for repo in private emu org

[https://github.com/microsoft/vscode/issues/330607](https://github.com/microsoft/vscode/issues/330607)

## Summary

The report provides a credible current-version reproduction and network trace showing that an unauthenticated extract-ref request receives a rate-limit 403, after which vscode.dev returns to the original branch. This is a real web/GitHub integration defect that should remain open and be routed to the responsible owners.

## Change summary

Switching to a newly created branch in a private EMU organization intermittently returns vscode.dev to the default branch when an unauthenticated GitHub extract-ref request is rate-limited.

## Best solution

Ensure the vscode.dev repository URL resolver authenticates extract-ref requests for private repositories, or treats rate-limit responses as inconclusive without reverting the requested branch. The change likely belongs at the vscode.dev workbench-embedder and GitHub authentication boundary.
