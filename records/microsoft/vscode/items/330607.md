# Issue #330607 — vscode.dev not switching to new branch for repo in private emu org

[https://github.com/microsoft/vscode/issues/330607](https://github.com/microsoft/vscode/issues/330607)

## Summary

Well-diagnosed report: on vscode.dev with a GitHub EMU/private-org account, some GitHub API calls (e.g. extract-ref for branch switching) go out unauthenticated and get rate-limited (403) or 404'd, causing branch switches to intermittently fail and bounce back to the default branch. The reporter traced this across three comments with concrete network evidence, isolating it to auth/token exchange behavior involving multiple signed-in accounts.

## Change summary

In vscode.dev, switching to a newly created branch in a private/EMU-org repo fails intermittently because some GitHub API requests are sent without auth, hitting rate limits or 404s.

## Best solution

Route to the GitHub/Microsoft authentication extension owners to trace why `extract-ref`/HEAD lookups sometimes bypass the Entra-to-GitHub token exchange (see extensions/github-authentication/src/entraTokenExchange.ts and githubServer.ts's auth.vscode.dev proxy path) and fall back to an unauthenticated request instead of failing or retrying with a valid session token.
