## Change summary

Switching branches in a private EMU repository on vscode.dev intermittently returns to main when unauthenticated ref-resolution requests receive rate-limit errors.

## Best solution

Make vscode.dev branch resolution reliably open the selected private-repository branch without depending on anonymous API quota. First establish whether the failing request originates in the web embedder or Remote Repositories, rather than assuming the reporter's speculative Entra-renewal diagnosis.
