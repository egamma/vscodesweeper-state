# Issue #235072 — Wrong file type icon for attached code

[https://github.com/microsoft/vscode/issues/235072](https://github.com/microsoft/vscode/issues/235072)

## Summary

Team-authored visual bug in chat paste attachment icon rendering — no fix commit found on main, and the code path that constructs the icon classes is unchanged since filing. Keeping open.

## Change summary

Pasting code from a TypeScript file into the chat input shows the plaintext file icon instead of the TypeScript icon on the attachment pill.

## Best solution

Investigate why `PasteAttachmentWidget` (in `src/vs/workbench/contrib/chat/browser/attachments/chatAttachmentWidgets.ts`, line ~738) constructs correct-looking icon classes (`['file-icon', '${language}-lang-file-icon']`) but the theme's icon CSS doesn't match. The language value and the CSS selector ancestry (`.show-file-icons .${lang}-lang-file-icon.file-icon::before`) should be verified at runtime — the `language` property on the paste entry or a CSS specificity issue may be the root cause. Consider using `getIconClassesForLanguageId()` from `getIconClasses.ts` instead of manually constructing the class list.
