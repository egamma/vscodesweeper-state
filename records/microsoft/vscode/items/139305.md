# Issue #139305 — Swedish keyboard layout is identified as German and this breaks Cmd+Z to undo

[https://github.com/microsoft/vscode/issues/139305](https://github.com/microsoft/vscode/issues/139305)

## Summary

The keyboard layout autodetection scoring logic in the web version still exists and can misidentify Swedish as German — no fix has been committed for this issue. Keeping open as a valid, unfixed bug.

## Change summary

On vscode.dev with a Swedish keyboard on macOS, the autodetect algorithm scores Swedish as German, swapping Z/Y and breaking Cmd+Z for undo.

## Best solution

Improve the keyboard layout scoring algorithm in `src/vs/workbench/services/keybinding/browser/keyboardLayoutService.ts` (the `getMatchedKeymapInfo` / `getScore` path) to better discriminate Swedish from German layouts — possibly by weighting distinguishing keys (like the different digit-row shifted characters) or by using the `navigator.keyboard.getLayoutMap()` API result more aggressively when available.
