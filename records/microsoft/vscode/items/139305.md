# Issue #139305 — Swedish keyboard layout is identified as German and this breaks Cmd+Z to undo

[https://github.com/microsoft/vscode/issues/139305](https://github.com/microsoft/vscode/issues/139305)

## Summary

Team-authored issue (alexdima, MEMBER) — hard keep-open. The bug is still present on main: the web keyboard layout guesser misidentifies Swedish as German because the two layouts share many key mappings (ö, ä, same digits/punctuation), but German swaps Y/Z, which breaks Cmd+Z undo.

## Change summary

On vscode.dev with a Swedish keyboard on macOS, the layout guesser picks German (which swaps Y/Z), causing Cmd+Z (undo) to fail.

## Best solution

Improve the keyboard layout matching heuristic in `src/vs/workbench/services/keybinding/browser/keyboardLayoutService.ts` to better distinguish Swedish from German — the critical differentiator is that Swedish maps KeyY→'y' and KeyZ→'z' (same as US), while German maps KeyY→'z' and KeyZ→'y'. The matching score needs to weight these discriminating keys more heavily, or the algorithm needs a secondary disambiguation pass when the top candidates share a high score.
