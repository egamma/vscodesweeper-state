# Issue #139305 — Swedish keyboard layout is identified as German and this breaks Cmd+Z to undo

[https://github.com/microsoft/vscode/issues/139305](https://github.com/microsoft/vscode/issues/139305)

## Summary

This remains a valid web keyboard-layout bug: multiple users confirmed that Swedish is inferred as German on macOS Chrome, causing physical-key dispatch to break undo and other shortcuts. The issue is team-authored and no referenced fix or verified canonical duplicate supports closing it.

## Change summary

Correct Swedish keyboard-layout detection in vscode.dev so Cmd+Z and other shortcuts resolve against the user's actual layout.

## Best solution

Update the browser keyboard-layout mapper and its layout-identification data so Swedish input is not classified as German, while preserving physical-key shortcut behavior for genuinely German layouts.
