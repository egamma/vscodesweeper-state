# Issue #119984 — EnvironmentVariableCollection in remote vs local terminals

[https://github.com/microsoft/vscode/issues/119984](https://github.com/microsoft/vscode/issues/119984)

## Summary

Still a valid gap: `EnvironmentVariableScope` currently supports only `workspaceFolder` scoping — there is no remote-vs-local dimension, so extensions cannot restrict their env-var mutations to remote or local terminals.

## Change summary

Allow extensions to scope EnvironmentVariableCollection entries to remote-only or local-only terminals.

## Best solution

Extend `EnvironmentVariableScope` (in `src/vs/platform/terminal/common/environmentVariable.ts` and mirrored in `src/vscode-dts/vscode.d.ts`) with a property indicating whether the collection applies to remote terminals, local terminals, or both. The filtering would need to be wired through `environmentVariableService.ts` and the terminal process manager. This is a small, self-contained API addition in the terminal-env-collection area.
