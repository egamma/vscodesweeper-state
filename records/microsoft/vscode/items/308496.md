# Issue #308496 — Property "key" in keybindings contributed by extensions must be optional

[https://github.com/microsoft/vscode/issues/308496](https://github.com/microsoft/vscode/issues/308496)

## Summary

The schema/runtime mismatch remains in current main: extension keybindings may omit `key` at runtime, but the manifest schema still requires it. Keep this open for a bounded schema correction.

## Change summary

Stop reporting a missing `key` property for extension-contributed keybindings that use platform-specific bindings.

## Best solution

Make manifest validation agree with the established runtime contract: `command` remains mandatory, while `key` is optional for both single-object and array contributions. Preserve existing platform selection and property-type validation.
