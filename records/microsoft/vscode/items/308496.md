# Issue #308496 — Property "key" in keybindings contributed by extensions must be optional

[https://github.com/microsoft/vscode/issues/308496](https://github.com/microsoft/vscode/issues/308496)

## Summary

Confirmed on current main: the keybindings extension-point JSON schema (line 96 of keybindingService.ts) marks `key` as required, but the runtime validation (line 70) explicitly treats it as optional. The schema should be updated to match the runtime's intent.

## Change summary

The JSON schema for extension-contributed keybindings incorrectly requires the `key` property, producing a spurious warning when only platform-specific keys (win/mac/linux) are provided.

## Best solution

Remove `'key'` from the `required` array on line 96 of `src/vs/workbench/services/keybinding/browser/keybindingService.ts` so the schema matches the runtime validation that already accepts omitting `key`.
