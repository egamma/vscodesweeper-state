# Issue #245421 — Git - timeline updates every second if "Autofetch period" is set to 1

[https://github.com/microsoft/vscode/issues/245421](https://github.com/microsoft/vscode/issues/245421)

## Summary

Still reproduces on main: the Git timeline provider refreshes on every autofetch because `onRepositoryOperationRun` does not exclude Fetch operations from triggering `fireChanged()`. With `git.autofetchPeriod` set to 1, this causes the timeline to refresh every second, losing hover focus.

## Change summary

Git timeline refreshes every second when autofetch period is 1, because fetch operations are not excluded from the timeline change trigger.

## Best solution

In `extensions/git/src/timelineProvider.ts`, add `_result.operation.kind !== OperationKind.Fetch` to the guard in `onRepositoryOperationRun`. A fetch only updates remote-tracking refs and never alters the local commit history of a file, so it should not trigger a timeline refresh. The related issue https://github.com/microsoft/vscode/issues/219877 fixed the source control icon flashing from frequent fetches (PR https://github.com/microsoft/vscode/pull/219940) but did not address the timeline refresh path.
