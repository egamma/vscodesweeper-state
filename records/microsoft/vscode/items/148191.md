# Issue #148191 — Notebook lightbulb action should stay around after clicking

[https://github.com/microsoft/vscode/issues/148191](https://github.com/microsoft/vscode/issues/148191)

## Summary

The requested interaction is still missing: accepting the detected language removes the lightbulb, with no alternative-detection cycling. Keep this accepted Backlog request open for a decision on the post-acceptance interaction; manual language selection is available but does not fully cover it.

## Change summary

Keep notebook language-detection choices accessible after accepting a suggestion so users can reconsider an incorrect detection.

## Best solution

Provide a deliberate post-acceptance interaction in the notebook cell status bar for reconsidering the detected language, while preserving manual language selection. Decide whether this means returning to the previous language, choosing alternative detections, or both, and when the interaction expires.
