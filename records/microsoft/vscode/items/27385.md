# Issue #27385 — Add option to use windows keymap on MacOS

[https://github.com/microsoft/vscode/issues/27385](https://github.com/microsoft/vscode/issues/27385)

## Summary

A real gap remains: current main cannot select another operating system's default keymap. This is the canonical Backlog request with 97 community upvotes, so it should remain open.

## Change summary

Allow users to select Windows, macOS, or Linux default keybindings independently of their host operating system.

## Best solution

Add a supported base-keymap selector in the keybinding service, keeping it separate from physical keyboard-layout selection and preserving user overrides. Alternatively, ship maintained first-party keymap extensions generated from the same per-platform defaults.

## Vision fit

- **Fit:** aligned
- **Reason:** A selectable cross-platform keymap supports consistent workbench interactions and settings fidelity across users' machines.
- **Evidence:** Public values emphasize “Simple, uniform UI and UI interactions,” while the durable Workbench & core UX theme includes settings fidelity.
