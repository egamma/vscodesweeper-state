# Issue #335938 — Model says it's thinking, but it's really downloading the model

[https://github.com/microsoft/vscode/issues/335938](https://github.com/microsoft/vscode/issues/335938)

## Summary

Keep open for clearer first-use agent download feedback. Current source still presents SDK download progress separately from chat working indicators; no verified fix or older same-symptom canonical was found, and this team-authored report is protected from judgment closes.

## Change summary

Distinguish agent SDK downloading from model thinking and reduce competing loading indicators during first use.

## Best solution

Make the pending chat explain that the agent SDK is downloading, without suggesting model reasoning has started. Agree whether download progress should remain in a notification or become the primary inline chat indicator, including how a download shared by multiple sessions is presented.
