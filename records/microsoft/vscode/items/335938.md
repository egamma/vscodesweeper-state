## Summary

Fresh, unconfirmed UX polish suggestion about overlapping/confusing loading indicators when a local chat model is being downloaded vs. actually thinking; no maintainer or community signal yet, so this should stay open for triage rather than be closed or routed with low confidence.

## Change summary

When a local/BYOK chat model is downloading, the UI still shows the generic 'Considering/Thinking' spinner alongside a separate toast progress bar, which the reporter finds confusing and visually noisy; they suggest either suppressing the thinking indicator during download or surfacing download progress inline in the chat view.

## Best solution

A chat maintainer should look at how the 'thinking' status text (chatThinkingContentPart.ts) is set during a model-download phase and decide whether to suppress/replace it with a download-specific indicator inline in the chat response, consolidating it with the existing toast progress notification.
