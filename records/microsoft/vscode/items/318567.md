# Issue #318567 — Console errors when rendering cross file suggestions

[https://github.com/microsoft/vscode/issues/318567](https://github.com/microsoft/vscode/issues/318567)

## Summary

Real bug with a race condition in the cross-file NES preview editor; an open PR (#318568) proposes a fix that has not yet merged. Keeping open for the PR to land.

## Change summary

Cross-file inline edit suggestions cause console errors due to a race between model switching and hidden-area updates in the preview editor.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/318568, which adds a synchronization guard in the preview editor effect, bounds hidden-area calculations to the current model, and validates cursor positions against the active model. The fix touches `longDistancePreviewEditor.ts` in the inline-edits view layer.
