# Issue #318567 — Console errors when rendering cross file suggestions

[https://github.com/microsoft/vscode/issues/318567](https://github.com/microsoft/vscode/issues/318567)

## Summary

Still unfixed on current main — the long-distance preview editor computes hidden areas from the scratch preview model even when the cross-file target model is attached — and an open PR from the reporter already proposes a fix, so this stays open pending that review.

## Change summary

Cross-file (NES) inline suggestions log a `TypeError` from Monaco's `viewModelLines` (out-of-bounds line projection) in the dev console while the suggestion renders.

## Best solution

Review and land (or redirect) https://github.com/microsoft/vscode/pull/318568: bound the hidden-area ranges in `longDistancePreviewEditor.ts` by the model actually attached to the preview editor instead of `_previewTextModel`, and guard the effect against evaluating before `setModel` has swapped in the cross-file target.
