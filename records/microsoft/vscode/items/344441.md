# Issue #344441 — ctrl+down arrow is given as a hint to open the terminal but does not do that

[https://github.com/microsoft/vscode/issues/344441](https://github.com/microsoft/vscode/issues/344441)

## Summary

The current source explains the misleading hint: the Terminal action advertises a shortcut restricted to terminal accessibility navigation even when that context is inactive. Keep this open; normal editor scrolling should remain unchanged.

## Change summary

The Terminal hover advertises Ctrl+Down even though that shortcut invokes scrollLineDown from the editor.

## Best solution

Make the Terminal entry's shortcut hint reflect an applicable binding, or omit it when none applies, without repurposing Ctrl+Down or weakening its accessibility-specific conditions.
