# Issue #309274 — Git commit message generation - allow path exclusion

[https://github.com/microsoft/vscode/issues/309274](https://github.com/microsoft/vscode/issues/309274)

## Summary

Keep open as a feature request: current commit-message generation lacks deterministic, generation-only path exclusions. Natural-language instructions and shared Copilot content exclusions do not fully cover the requested scope, and no matching canonical issue was verified.

## Change summary

Allow file and folder patterns to exclude changes from generated commit-message context without excluding those files from the commit.

## Best solution

Provide deterministic path exclusions scoped to Copilot commit-message generation, leaving Git staging and other Copilot workflows unchanged. Product review should establish the configuration contract and the behavior when every changed file is excluded.
