# Issue #330549 — VS Code v1.133 .deb Won't Install on Ubuntu Noble / Mint Zena

[https://github.com/microsoft/vscode/issues/330549](https://github.com/microsoft/vscode/issues/330549)

## Summary

This is the same libglib2.0-0 / libglib2.0-0t64 versioned-dependency mismatch already declined by a maintainer in a directly-precedential closed issue: installing via `apt install ./code.deb` (the documented method) resolves the virtual package fine, and the failure only shows up with tools like `dpkg`/GDebi that don't resolve versioned virtual `Provides`.

## Change summary

Requests the .deb declare `libglib2.0-0 | libglib2.0-0t64` as an alternative dependency so the package installs cleanly on Ubuntu 24.04+/Noble-based systems regardless of the installer tool used.

## Best solution

No core change planned — same precedent as https://github.com/microsoft/vscode/issues/237378, where @deepak1556 (COLLABORATOR) confirmed the documented install route (apt) works fine on Ubuntu and the gap is in the installation tool, not the .deb's declared dependency; point reporters at https://code.visualstudio.com/docs/setup/linux#_install-vs-code-on-linux.
