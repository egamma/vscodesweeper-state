# Issue #221614 — Provide a "withoutFormatting" option for `document.save` and `workspace.save`

[https://github.com/microsoft/vscode/issues/221614](https://github.com/microsoft/vscode/issues/221614)

## Summary

The API gap remains on current main, and this accepted Backlog request has 25 community upvotes. It is also the older, better-supported canonical candidate for the same request later reported in issue 245405.

## Change summary

Allow extensions to save a document or workspace editor while bypassing formatting and other save participants.

## Best solution

Design a public save option that deliberately controls save participants, then pass it through both TextDocument.save and workspace.save without changing default save behavior. Consolidate the newer https://github.com/microsoft/vscode/issues/245405 into this issue.
