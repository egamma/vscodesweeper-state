# Issue #323080 — Markdown preview that includes Mermaid diagrams renders the latter in an unreadable fashion when using dark theme

[https://github.com/microsoft/vscode/issues/323080](https://github.com/microsoft/vscode/issues/323080)

## Summary

Keep open to investigate the diagram’s foreground/background mismatch, with an independent confirmation in the discussion. The attached sample explicitly supplies a light Mermaid palette, so this is not yet established as a failure of automatic dark-theme selection.

## Change summary

Mermaid sequence-diagram text becomes unreadable against the dark Markdown preview background.

## Best solution

Establish how the built-in Mermaid preview should render an explicitly light-themed diagram inside a dark preview, then ensure its canvas and foreground colors remain readable together. Preserve intentional diagram color overrides rather than treating every diagram as using the default VS Code-derived theme.
