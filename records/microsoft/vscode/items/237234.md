# Issue #237234 — No hint shown when hovering over type in debugger variables view

[https://github.com/microsoft/vscode/issues/237234](https://github.com/microsoft/vscode/issues/237234)

## Summary

The missing type hover remains identifiable in current source: inline types are rendered without a tooltip, while names and values have separate hover handling. Keep this open; the report provides sufficient detail, and no verified canonical or open fixing PR was found.

## Change summary

Make debugger variable details accessible by hovering over an inline type when a narrow Variables pane clips the row.

## Best solution

Provide a hover on the inline type that exposes the full variable name, type, and value without requiring the pane to be widened. Preserve existing name/value hovers and the debug.showVariableTypes setting; a broader whole-row hover redesign is not necessary to resolve the reported defect.

## Evidence

With inline types enabled, data.label.set receives variable.name as its tooltip, so the name hover does not expose the clipped type either.
- **No template-level fallback:** src/vs/workbench/contrib/debug/browser/baseDebugView.ts, AbstractExpressionsRenderer.renderTemplate, creates span.type without a title or managed hover. This matches the reporter's trigger: the visible type cannot provide the hidden details when the value is clipped away.
