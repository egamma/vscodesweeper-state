# Issue #342240 — Notebook Markdown: code blocks in cells rendered in the same millisecond lose syntax highlighting (ID collision in requestHighlightCodeBlock)

[https://github.com/microsoft/vscode/issues/342240](https://github.com/microsoft/vscode/issues/342240)

## Summary

The reported collision remains in current main: separate render calls can register the same request ID, leaving one block unhighlighted and applying both responses to another. Keep this open as a core notebook bug.

## Change summary

Prevent same-millisecond rendering of notebook Markdown code blocks from losing highlighting or displaying another block's tokenized content.

## Best solution

Give every highlighting request a distinct identity within the notebook webview, preserving correct response-to-element association across Markdown cells and rendered outputs. Cover concurrent requests with a deterministic regression check.
