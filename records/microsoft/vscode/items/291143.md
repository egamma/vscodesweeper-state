# Issue #291143 — Cannot edit file in WSL UI using Agent mode

[https://github.com/microsoft/vscode/issues/291143](https://github.com/microsoft/vscode/issues/291143)

## Summary

Verified duplicate in the remote Agent file-tools cluster: the older open issue tracks the same Windows-host/Linux-workspace path conversion failure, where terminal commands work but workspace file tools reject remote paths.

## Change summary

Agent mode cannot edit files in a WSL workspace because file tools resolve the workspace using Windows-style paths.

## Best solution

Consolidate the remote extension-placement diagnosis and any warning or error-message improvement in https://github.com/microsoft/vscode/issues/280816. Affected users should remove Copilot entries from `remote.extensionKind` so the extensions use their default workspace-side placement.
