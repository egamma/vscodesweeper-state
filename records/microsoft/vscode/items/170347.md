# Issue #170347 — iPad: Cmd-C Cmd-X shortcuts for copying the current line don't work

[https://github.com/microsoft/vscode/issues/170347](https://github.com/microsoft/vscode/issues/170347)

## Summary

Keep open as an upstream iPadOS Safari defect. The reporter isolated the missing clipboard event outside VS Code, and current main still relies on that browser event for web copy and cut shortcuts.

## Change summary

Cmd-C and Cmd-X fail to copy or cut the current editor line on iPadOS when no text is selected.

## Best solution

WebKit should emit the standard copy and cut events for hardware-keyboard shortcuts with an empty textarea selection. Keep this report as the concrete VS Code impact and verify it on current iPadOS after the upstream behavior changes; a VS Code workaround would need to preserve browser clipboard security behavior.

## Evidence

- **current source path:** src/vs/editor/contrib/clipboard/browser/clipboard.ts deliberately does not register Cmd-C/Cmd-X keybindings on web and relies on the browser clipboard event; executeClipboardCopyWithWorkaround only falls back to IClipboardService when platform.isNative.
- **event dependency:** src/vs/editor/browser/controller/editContext/textArea/textAreaEditContextInput.ts handles copying and cutting through TextAreaInput.onCopy/onCut, so the missing WebKit event still prevents current main from generating the whole-line clipboard payload.
