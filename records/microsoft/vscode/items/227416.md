# Issue #227416 — Markdown language detection is overly aggressive and cannot be disabled

[https://github.com/microsoft/vscode/issues/227416](https://github.com/microsoft/vscode/issues/227416)

## Summary

Keep open: existing controls can prevent automatic switching altogether, but cannot exclude Markdown as a detection result while retaining detection of other languages. The older exclusion request is related, but does not meet the same-observable-symptom duplicate bar for this re-reviewed item.

## Change summary

Avoid automatically selecting Markdown for ordinary prose or URLs, or allow users to exclude Markdown from automatic language detection.

## Best solution

Agree on how automatic detection should distinguish ordinary plain text from Markdown, with selective output-language exclusion as an alternative. Coordinate the exclusion contract with https://github.com/microsoft/vscode/issues/143817 without treating its CoffeeScript/Perl examples as proof that this Markdown-specific report is redundant.

## Evidence

- **Existing setting controls the source language:** src/vs/workbench/browser/workbench.contribution.ts:173–177 documents workbench.editor.languageDetection as controlling which languages users do not want switched away from. BaseTextEditorModel.doAutoDetectLanguage in src/vs/workbench/common/editor/textEditorModel.ts:140–152 checks enablement against the current language, not the detected result. A Markdown-scoped false override therefore does not prevent Plain Text from becoming Markdown.
- **Workarounds do not cover selective exclusion:** A global workbench.editor.languageDetection=false prevents automatic switching through the model's enablement guard. files.defaultLanguage="plaintext" supplies an explicit language for new untitled files through src/vs/workbench/services/untitled/common/untitledTextEditorService.ts:247–253 and UntitledTextEditorModel's constructor. Both can preserve plain text, but sacrifice automatic detection of other languages rather than excluding only Markdown.
- **Current detection path:** LanguageDetectionService.detectLanguage in src/vs/workbench/services/languageDetection/browser/languageDetectionWorkerServiceImpl.ts uses history settings to control biases and resolver preference. BaseTextEditorModel calls it without the optional supportedLangs restriction. LanguageDetectionWorker.adjustLanguageConfidence in src/vs/workbench/services/languageDetection/browser/languageDetectionWebWorker.ts penalizes several problematic languages but not Markdown; the exact model output for the reporter's prose and URL was not executed or confirmed.
