# Issue #309223 — Weekly updates are too frequent

[https://github.com/microsoft/vscode/issues/309223](https://github.com/microsoft/vscode/issues/309223)

## Summary

Keep open under discussion: the request for less disruptive stable releases has substantial community support, and existing update controls do not provide a slower supported release cadence. Related requests cover configurable reminders or are newer duplicates, rather than fully absorbing this issue.

## Change summary

Reduce stable release frequency so updates disrupt ongoing development less often.

## Best solution

Make an explicit release-policy decision addressing the requested monthly cadence, informed by the reported interruption costs and servicing constraints. Coordinate reminder-frequency work with https://github.com/microsoft/vscode/issues/308615 without treating deferred reminders as equivalent to a slower supported release stream.
