# Issue #309223 — Weekly updates are too frequent

[https://github.com/microsoft/vscode/issues/309223](https://github.com/microsoft/vscode/issues/309223)

## Summary

Keep this open as the canonical discussion about reducing the Stable release cadence. It has substantial community demand, remains actively assigned and under discussion, and neither the existing manual-update mode nor the narrower configurable-frequency request fully resolves the central ask.

## Change summary

Reduce Stable releases from a weekly cadence to a less disruptive schedule, while avoiding client/server version mismatches and workflow interruptions.

## Best solution

The release and update owners should decide whether Stable should return to a slower default cadence; configurable reminder delays remain separately tracked by https://github.com/microsoft/vscode/issues/308615. The reported premature WSL server update and resulting crashes should be diagnosed as a separate version-integrity bug rather than folded into the cadence decision.
