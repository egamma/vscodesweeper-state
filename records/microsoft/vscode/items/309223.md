# Issue #309223 — Weekly updates are too frequent

[https://github.com/microsoft/vscode/issues/309223](https://github.com/microsoft/vscode/issues/309223)

## Summary

High-traction feature request (102 upvotes) asking for user control over update cadence — e.g. release channels (weekly/monthly/quarterly). Already labeled under-discussion with a team member response; the existing `update.mode` setting offers only on/off control, not frequency control. This is the canonical issue; #325073 is a satellite.

## Change summary

Users want configurable update frequency or release channels so they can receive stable updates less often than the current weekly cadence.

## Best solution

Introduce an update cadence or release-channel mechanism (e.g. weekly/monthly/quarterly options within `update.mode` or a new `update.cadence` setting) so users can control how frequently they receive stable releases. The update infrastructure lives in `src/vs/platform/update/`. Issue https://github.com/microsoft/vscode/issues/325073 is a duplicate satellite of this canonical issue.
