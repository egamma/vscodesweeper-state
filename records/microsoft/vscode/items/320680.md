## Change summary

VS Code doesn't offer 'Use Workspace Version' for TypeScript when a project with TypeScript is nested inside a workspace folder rather than being a direct workspace folder root.

## Best solution

If the reporter was using a single-folder workspace pointing to the parent directory, the behavior is as-designed — `typescript.tsdk` is the correct solution and already documented. If they had a true multi-root workspace with the Next.js project as a separate folder entry, the code in `DiskTypeScriptVersionProvider.localNodeModulesVersions` should have found it, and a reproduction with the exact workspace file would be needed to identify a bug.
