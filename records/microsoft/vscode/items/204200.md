# Issue #204200 — [folding] Add Code Folding Actions to the Undo Stack

[https://github.com/microsoft/vscode/issues/204200](https://github.com/microsoft/vscode/issues/204200)

## Summary

A real capability gap remains on current main: folding changes only editor view state, while the standard Undo command operates on the text model. The request is correctly routed and should remain open for a product decision about mixing folding and edit history.

## Change summary

Optionally make fold and unfold actions reversible through the editor's standard Undo and Redo commands.

## Best solution

Define consistent ordering and persistence semantics for folding state alongside text edits, then expose the behavior through an opt-in editor setting if maintainers accept the added undo complexity.
