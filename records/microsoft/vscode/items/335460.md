# Issue #335460 — Updating external plugins broken for manual and AutoUpdates

[https://github.com/microsoft/vscode/issues/335460](https://github.com/microsoft/vscode/issues/335460)

## Summary

Keep open: current main addresses the manual-update source gate and changed-install-URI handling, but scheduled detection still checks only marketplace repositories. An external plugin repository can advance without triggering an automatic update, so a substantive part of this report remains.

## Change summary

Make manual and automatic updates reliably refresh externally hosted agent plugins, preserve their current installation location, and report update outcomes.

## Best solution

Complete external-source detection in the periodic plugin update pipeline so eligible plugins update even when their marketplace repository is unchanged, while preserving revision pins, managed eligibility, and metered-connection behavior. Retain the existing manual-update and URI-replacement behavior, and make scheduled outcomes and failure output discoverable.
