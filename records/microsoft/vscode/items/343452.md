# Issue #343452 — Codex: remember Full Access permission preference across New Chat

[https://github.com/microsoft/vscode/issues/343452](https://github.com/microsoft/vscode/issues/343452)

## Summary

Keep open as a feature request: the regular workbench's new-session defaults do not expose Codex's Full Access preset. Existing permission settings and Agents-window preference storage do not establish that the reported New Chat workflow is covered.

## Change summary

Allow an explicitly chosen Codex permission preset, including Full Access, to become the default for new chats within a clearly identified scope.

## Best solution

Provide consistent, explicitly opted-in Codex permission defaults across new-chat entry points, with a clear persistence scope and runtime policy remaining authoritative. Account for the existing Agents-window preference mechanism rather than introducing a separate, conflicting default.
