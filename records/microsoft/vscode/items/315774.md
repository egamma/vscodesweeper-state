# Issue #315774 — No feedback when you press cmd+n in new agents window session

[https://github.com/microsoft/vscode/issues/315774](https://github.com/microsoft/vscode/issues/315774)

## Summary

Keep open as a UX polish request: current source intentionally reuses the empty new-session view, but provides no explicit acknowledgment when Cmd+N is repeated there. No verified duplicate or fixing commit was found.

## Change summary

Provide feedback when New Session is invoked while the Agents window already shows an empty new-session composer.

## Best solution

Provide a restrained, accessible acknowledgment that the user is already composing a new session, with a clear path to choosing another workspace. Preserve the existing empty-composer reuse rather than creating redundant sessions.
