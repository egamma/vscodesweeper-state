# Issue #282750 — Remember workspace specific tool disablement

[https://github.com/microsoft/vscode/issues/282750](https://github.com/microsoft/vscode/issues/282750)

## Summary

The bug remains source-reproducible on current main: saving tool selections replaces the global state with entries visible in the current workspace, dropping disabled entries for workspace-specific tools that are temporarily absent.

## Change summary

Preserve disablement choices for workspace-specific MCP tools when tool selections are configured from another workspace.

## Best solution

When updating the default agent's global tool selection, retain stored decisions for tools unavailable in the current workspace while applying the user's choices for currently visible tools.
