# Issue #281484 — Slow unit-tests

[https://github.com/microsoft/vscode/issues/281484](https://github.com/microsoft/vscode/issues/281484)

## Summary

Still valid: the vitest configuration for copilot chat unit tests has not been changed since the issue was filed, and no performance fix has landed. Issue #289078 was closed as a duplicate of this one, making this the canonical tracker for the problem.

## Change summary

Copilot chat unit tests (vitest) run disproportionately slowly relative to the main VS Code mocha test suite — ~37s wall-clock for ~3.8k tests vs ~55s for ~13.8k tests.

## Best solution

Investigate vitest pooling, transform, and collect overhead in `extensions/copilot/chat-lib/vitest.config.ts` — the reported `collect` phase alone takes ~75s of CPU time. Profiling the vitest run (as hediet suggested) should identify whether the bottleneck is transform/esbuild config, module collection, or fork overhead. A concrete perf profile is the next step.
