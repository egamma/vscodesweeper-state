# Issue #242420 — ssh config wrong when adding reverse proxy ssh

[https://github.com/microsoft/vscode/issues/242420](https://github.com/microsoft/vscode/issues/242420)

## Summary

This is a confirmed Remote-SSH command-to-config parsing defect owned by the VS Code Remote Development team. It should be moved to the Remote Development tracker, where the exact bug is already tracked.

## Change summary

Remote-SSH converts an `ssh -R port:host:hostport` argument into an invalid `RemoteForward port:host:hostport` configuration directive instead of separating the listening port from the destination with whitespace.

## Best solution

Consolidate this report with https://github.com/microsoft/vscode-remote-release/issues/8012 and fix Remote-SSH's Add New SSH Host parser to emit `RemoteForward 12346 127.0.0.1:7890` while preserving valid reverse-forward command syntax.
