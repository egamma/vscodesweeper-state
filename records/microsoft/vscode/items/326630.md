# Issue #326630 — Copilot Chat Sessions list missing Claude Agent SDK sessions after updating to latest release.

[https://github.com/microsoft/vscode/issues/326630](https://github.com/microsoft/vscode/issues/326630)

## Summary

Real, well-diagnosed bug with an open PR that already fixes it — keep open until that PR merges rather than closing now.

## Change summary

After moving Claude Agent SDK sessions to Agent Host, sessions created under Remote-SSH disappear from the sessions list on reload because their working-directory URIs (wrapped for Remote SSH) get filtered out incorrectly.

## Best solution

Land https://github.com/microsoft/vscode/pull/327425, which normalizes Agent Host working-directory URIs against the local workspace before filtering under Remote-SSH and adds a regression test — this directly restores the missing sessions.
