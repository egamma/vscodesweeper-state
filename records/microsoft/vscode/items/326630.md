## Change summary

After updating VS Code, previously-created Claude Agent SDK sessions vanish from the sessions list under Remote-SSH, while new sessions still appear.

## Best solution

Land PR https://github.com/microsoft/vscode/pull/327425, which unwraps Agent Host working-directory URIs (via `fromAgentHostUri`/`toLocalResource`) before comparing them against the `vscode-remote` workspace folder in `agentHostSessionListStore.ts`, restoring the missing SSH sessions; close #326630 once merged.
