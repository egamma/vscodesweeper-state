# Issue #333927 — Automatically generated Chat title randomly mixes CJK characters into an English title

[https://github.com/microsoft/vscode/issues/333927](https://github.com/microsoft/vscode/issues/333927)

## Summary

Real but hard-to-pin-down defect: the auto-title model (gpt-4o-mini-2024-07-18) occasionally appends a CJK word to an otherwise English title. The title prompt (TitlePrompt) has no explicit instruction to keep the title in the same language as the request, but this is a single, unconfirmed occurrence and the near-identical prior report (https://github.com/microsoft/vscode/issues/321853) was closed as info-needed without a fix landing, so this needs more corroboration before it can be actioned.

## Change summary

Automatically generated chat titles sometimes mix in a CJK word/suffix even when the whole conversation is in English.

## Best solution

If this recurs with more evidence (ideally a captured Language Model Request/response from Show Chat Debug View), consider tightening extensions/copilot/src/extension/prompts/node/panel/title.tsx to explicitly instruct the model to keep the title in the same language as the user's request; also check whether IRequestLogger's 100-entry cap should be raised or made configurable so title requests aren't evicted before they can be inspected.
