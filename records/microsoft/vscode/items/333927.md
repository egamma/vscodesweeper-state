# Issue #333927 — Automatically generated Chat title randomly mixes CJK characters into an English title

[https://github.com/microsoft/vscode/issues/333927](https://github.com/microsoft/vscode/issues/333927)

## Summary

Keep open: two independent reports received the exact same unexpected `原因` suffix, and current main accepts a successful title-model response without checking its language. The team-authored-item rule also bars a judgment close without a referenced fix or verified open canonical.

## Change summary

Prevent automatically generated English chat titles from unexpectedly mixing in CJK words.

## Best solution

Define whether title language follows the configured response locale or the first request, then make title generation enforce that policy and use a safe fallback when the model returns a mixed-language result.
