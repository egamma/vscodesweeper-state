# Issue #88638 — Moving lines of code up and down breaks indentation

[https://github.com/microsoft/vscode/issues/88638](https://github.com/microsoft/vscode/issues/88638)

## Summary

Keep open: the supplied JavaScript sample and recording suffice to retest the unwanted indentation after a method chain. Move-lines handling has changed since the report, but the historical fix addresses a different case and does not establish that this report is resolved.

## Change summary

Moving statements around a multiline JavaScript method chain incorrectly gives subsequent statements the chain's continuation indentation.

## Best solution

Make move-line indentation distinguish a completed method chain from its continuation, keeping subsequent statements at the enclosing block's indentation while preserving legitimate reindentation when moving between scopes. First pin the reported movement sequence in a regression test using the actual JavaScript indentation configuration.
