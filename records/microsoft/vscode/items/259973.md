# Issue #259973 — Allow MCP Servers in non-agent mode

[https://github.com/microsoft/vscode/issues/259973](https://github.com/microsoft/vscode/issues/259973)

## Summary

Valid feature request — MCP tools are currently gated to Agent mode only (confirmed via the `ConfigureToolsAction` precondition in `chatToolActions.ts`). A team member (connor4312) commented with concrete implementation ideas, and the issue sits on the On Deck milestone. No duplicate found; keeping open for the team to act on.

## Change summary

Allow MCP server tools (especially those with `readOnlyHint: true`) to be available in Ask and Edit modes, not only Agent mode.

## Best solution

Extend the tool picker and tool-availability logic to include MCP tools with `readOnlyHint: true` (and no confirmation required) in Ask mode, as connor4312 outlined. The main gating is in `src/vs/workbench/contrib/chat/browser/actions/chatToolActions.ts` (the `ConfigureToolsAction` precondition restricts to `ChatModeKind.Agent`) and likely in how tools are filtered for the request in the chat service. A scoped-down tool picker for non-agent modes would also be needed.
