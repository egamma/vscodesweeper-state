# Issue #259611 — Edit source applyEdit - include source extension

[https://github.com/microsoft/vscode/issues/259611](https://github.com/microsoft/vscode/issues/259611)

## Summary

Extension attribution remains missing from both editor and workspace edit paths. Keep this accepted, team-authored request open; the original implementation was not merged, and a newer related proposal does not qualify as its duplicate canonical.

## Change summary

Preserve the originating extension identity in edit-source metadata for extension-applied editor and workspace edits.

## Best solution

Carry the originating VersionedExtensionId through both extension API edit paths into edit-source metadata, without inventing provider IDs. Evaluate the existing editor-attribution demonstration before starting competing implementation work, while retaining workspace-edit attribution in this issue's scope.
