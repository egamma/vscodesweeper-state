# Issue #277735 — Agent: Prompts should not persist tool/model selection after chat response

[https://github.com/microsoft/vscode/issues/277735](https://github.com/microsoft/vscode/issues/277735)

## Summary

Team-authored issue, kept open. The behavior is still present on current main: `_applyPromptMetadata` in chatWidget.ts persistently sets tools and model on the input widget with no restore-after-response logic. The gap between prompts (one-shot) and custom agents (multi-turn) remains unaddressed.

## Change summary

Prompt files that specify tools or model selections persist those selections into subsequent chat turns instead of reverting after the prompt's response completes.

## Best solution

In `_applyPromptMetadata` (src/vs/workbench/contrib/chat/browser/widget/chatWidget.ts ~L3140), snapshot the current tool/model selection before applying the prompt header, then restore it after the response completes. This enforces the one-shot semantics of prompts vs. multi-turn agents. The related closed issues (https://github.com/microsoft/vscode/issues/290363, https://github.com/microsoft/vscode/issues/307602) confirm user demand for this behavior.
