# Issue #349834 — Closing the troubleshoot dialogs also close the Remote Env dialog

[https://github.com/microsoft/vscode/issues/349834](https://github.com/microsoft/vscode/issues/349834)

## Summary

The close button still dismisses the entire Remote Environments modal, whereas Back and Escape return to its overview. Keep this open in the already-assigned agents-window area.

## Change summary

Closing the troubleshooting page should return to Remote Environments instead of dismissing the management modal.

## Best solution

Preserve the Remote Environments overview when closing its troubleshooting page, without changing ordinary modal dismissal or actions that deliberately leave the modal to open diagnostics.
