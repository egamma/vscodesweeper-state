# Issue #325670 — Skills don't always show as completions in agents window

[https://github.com/microsoft/vscode/issues/325670](https://github.com/microsoft/vscode/issues/325670)

## Summary

Still reproduces on main: the deduplication between runtime slash commands and known skills uses mismatched name formats (`monitor-pr` vs `monitor-pr:monitor-pr`), causing skills to either duplicate or fail to appear depending on session state. DonJayamanne acknowledged the issue and has a fix in progress but not yet landed.

## Change summary

Plugin skills from the Copilot SDK don't reliably appear as slash-command completions in the agents window, and when they do appear they can show up twice.

## Best solution

Fix the name-matching logic in `CopilotSlashCommandCompletionProvider._getRuntimeSlashCommandCompletionInfo` so that deduplication between runtime commands and known skills handles the `pluginName:skillName` vs bare `skillName` format consistently. The `_toSlashCommandCandidate` method (line 126) already knows when to produce the compound name — the dedup check at line 152 needs to account for both forms. Also address the `VS Code Synced Data` plugin name leaking into completions (related issue https://github.com/microsoft/vscode/issues/325671).
