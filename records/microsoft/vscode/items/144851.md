# Issue #144851 — Align editor find widget with the notebook find widget

[https://github.com/microsoft/vscode/issues/144851](https://github.com/microsoft/vscode/issues/144851)

## Summary

The UX gap remains on current main: editor Find in Selection is still a standalone action, while notebook find embeds a scalable filters control in its input. This is already correctly routed and remains the canonical polish item.

## Change summary

Move editor Find in Selection into an input-embedded filters menu aligned with notebook find and extensible to future search scopes.

## Best solution

Adapt the editor find input to use a notebook-style filters control, initially containing Find in Selection while preserving its command, keyboard, selection, and accessibility behavior.
