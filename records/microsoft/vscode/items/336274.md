# Issue #336274 — Markdown Editor: Video elements are not rendered

[https://github.com/microsoft/vscode/issues/336274](https://github.com/microsoft/vscode/issues/336274)

## Summary

Legitimate, freshly filed bug in the new (preview) Markdown Editor: HTML `<video>` elements render as an empty area instead of a playable video. The reporter includes clear repro steps, a demo video, and a concrete real-world test file (vscode-docs v1.138 release notes). It should stay open for a fix.

## Change summary

In the new rich Markdown Editor, HTML `<video>` tags in markdown source render as an empty gap instead of an embedded, playable video.

## Best solution

Fix belongs in the rich-editing node schema that decides which raw HTML tags get rendered inline (image works, video doesn't) — but that schema lives in the external `@vscode/markdown-editor` npm package consumed by extensions/markdown-language-features/markdown-editor-src/editor.ts, not in this checkout, so it can't be traced or patched from this repo alone; needs the markdown-editor package maintainers to add/fix video-node support.
