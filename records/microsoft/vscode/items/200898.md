# Issue #200898 — Copy&Paste picture cell failure

[https://github.com/microsoft/vscode/issues/200898](https://github.com/microsoft/vscode/issues/200898)

## Summary

Keep open: Copy Cell Down still copies the Markdown attachment reference while discarding its image metadata. This issue already serves as the canonical report for confirmed attachment-loss duplicates.

## Change summary

Preserve embedded image attachments when duplicating a notebook Markdown cell.

## Best solution

Notebook cell duplication should retain the attachment data needed to render copied Markdown, without sharing mutable attachment state or changing cell identity and execution-state semantics. Cover the reported Copy Cell Down path and the shared clipboard cloning path with regression tests.
