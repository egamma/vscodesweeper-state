# Issue #200898 — Copy&Paste picture cell failure

[https://github.com/microsoft/vscode/issues/200898](https://github.com/microsoft/vscode/issues/200898)

## Summary

Still reproduces on main: `cloneNotebookCellTextModel` in `notebookCellTextModel.ts` hard-codes `metadata: {}`, which drops cell metadata including image attachments when copying a cell up/down or via clipboard paste.

## Change summary

Copying a markdown cell with a pasted image attachment loses the image because cell metadata is discarded during the clone operation.

## Best solution

Modify `cloneNotebookCellTextModel` to selectively preserve the `attachments` field from cell metadata (while still clearing execution-related metadata per the original fix in #103881). This preserves images without reintroducing stale execution state on copy.
