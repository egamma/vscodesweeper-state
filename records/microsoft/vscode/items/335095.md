# Issue #335095 — Tool ordering seems mixed between agent window and editor window

[https://github.com/microsoft/vscode/issues/335095](https://github.com/microsoft/vscode/issues/335095)

## Summary

Current main conclusively explains the ordering mismatch: reconnect snapshots append an active ask-question input request after all previously accumulated response parts instead of preserving its stream position. This team-authored bug should remain open for a focused Agent Host transcript fix.

## Change summary

Preserve identical tool and ask-question ordering when an active Agent Host conversation is displayed in the Agents Window and editor window.

## Best solution

Make active-turn reconnection preserve the authoritative `responseParts` order, including unresolved input requests, while retaining the existing behavior for live streaming and completed-history restoration.
