# Issue #334608 — Agents: prompted about uncommitted changes on cloud session start, but Changes panel is empty

[https://github.com/microsoft/vscode/issues/334608](https://github.com/microsoft/vscode/issues/334608)

## Summary

Keep open: current source allows the cloud-start prompt to detect local repository changes that the cloud session's Changes panel cannot display. No verified canonical or issue-linked fixing commit establishes completion, and this maintainer-authored report is protected from judgment closes.

## Change summary

Cloud session startup asks users to decide about uncommitted changes without showing which repository or files the decision concerns.

## Best solution

Make the cloud-start confirmation identify the repository and affected files, with an inspection path available before any decision. Dirty-state detection must correspond to the selected cloud target or explicitly explain any local changes being offered for inclusion, rather than silently using an unrelated active repository.
