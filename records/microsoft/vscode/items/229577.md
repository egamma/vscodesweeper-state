## Summary

Keep open as an upstream EditContext positioning issue: a maintainer reproduced the off-screen-caret trigger on desktop, web, and a standalone browser demo. Current VS Code updates bounds on scrolling, but that alone does not establish that Chromium's IME positioning problem is resolved.

## Change summary

Keep the IME composition window anchored to the caret when typing reveals a line that was scrolled outside the viewport.

## Best solution
