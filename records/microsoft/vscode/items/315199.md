# Issue #315199 — Suggestion: check .gitattributes for linguist-language before giving up on syntax highlighting

[https://github.com/microsoft/vscode/issues/315199](https://github.com/microsoft/vscode/issues/315199)

## Summary

Keep open for a decision on reading repository language overrides. Existing file associations require duplicating the configuration, and the older related issue does not clearly own the full GitHub/GitLab override request under the stricter re-review duplicate rules.

## Change summary

Use linguist-language and gitlab-language attributes from .gitattributes when selecting a file's language.

## Best solution

Decide whether repository language attributes should participate in VS Code language selection, including precedence against explicit files.associations and conflicting attributes. If accepted, honor repository-relative attribute rules without requiring a second configuration in .vscode/settings.json.
