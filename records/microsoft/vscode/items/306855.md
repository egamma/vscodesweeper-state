# Issue #306855 — Copilot floods context with tools output, leading to stupidly early "summarizing", which in turn loses *real* context rather than out of date tool output

[https://github.com/microsoft/vscode/issues/306855](https://github.com/microsoft/vscode/issues/306855)

## Summary

Current main compacts conversation history but does not semantically invalidate superseded tool results. Retaining only useful outcomes requires a product decision about when earlier output is safe to discard, so this should remain open under discussion.

## Change summary

Prune or condense superseded test-command output before it consumes enough context to trigger conversation compaction.

## Best solution

Introduce lifecycle-aware tool-result retention in the Copilot prompt pipeline: repeated test runs should preserve the latest result and a concise history of meaningful state changes rather than every complete output. The policy must retain distinct failures and diagnostic evidence rather than treating every older invocation as invalid.
