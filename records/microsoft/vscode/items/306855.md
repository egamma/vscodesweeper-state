# Issue #306855 — Copilot floods context with tools output, leading to stupidly early "summarizing", which in turn loses *real* context rather than out of date tool output

[https://github.com/microsoft/vscode/issues/306855](https://github.com/microsoft/vscode/issues/306855)

## Summary

Keep open for selective tool-output retention: current safeguards limit large results but do not identify earlier test runs as superseded. No fixing commit or older canonical covering this specific symptom was established.

## Change summary

Reduce superseded test-run output in agent context before conversation summarization discards useful task details.

## Best solution

Evaluate selective retention in Copilot's conversation-history pipeline, preserving current test results, relevant failure history, and user decisions while reducing redundant logs. Re-running a command should not automatically erase every earlier result, since those results can explain regressions or progress.
