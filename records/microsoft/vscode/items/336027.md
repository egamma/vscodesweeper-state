# Issue #336027 — Support `chat.editor.wordSeparators` setting for GitHub Copilot Chat input boxes

[https://github.com/microsoft/vscode/issues/336027](https://github.com/microsoft/vscode/issues/336027)

## Summary

Legitimate, specific request: the chat input editor doesn't expose any word-separator customization (traced via getSimpleEditorOptions/chatInputPart.ts), so CJK users can't tune Ctrl+←/→ word jumps in chat the way they can in the code editor. It's very fresh (8 days, 0 upvotes) with an open design question — a dedicated `chat.editor.wordSeparators` vs. simply honoring `editor.wordSeparators` — so it stays open for maintainer input rather than a plan/implement push.

## Change summary

Add a way to customize word separators (e.g. for CJK punctuation) in the Copilot Chat input box, independent of the code editor's `editor.wordSeparators`.

## Best solution

A maintainer should decide whether chat input should simply inherit `editor.wordSeparators` (simpler, more consistent) or get its own `chat.editor.wordSeparators` setting as proposed, then wire the chosen value into `getSimpleEditorOptions`/the input editor's `IEditorOptions` in chatInputPart.ts.
