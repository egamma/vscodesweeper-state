# Issue #336027 — Support `chat.editor.wordSeparators` setting for GitHub Copilot Chat input boxes

[https://github.com/microsoft/vscode/issues/336027](https://github.com/microsoft/vscode/issues/336027)

## Summary

Keep open as a feature request: current chat input supports locale-based word segmentation, but not independently configurable punctuation separators. No verified older duplicate or completed implementation was found.

## Change summary

Allow Copilot Chat input word navigation to use customizable separators independently of editor.wordSeparators.

## Best solution

Provide input-specific word-boundary customization in the shared chat input, preserving code-editor settings and existing locale-based segmentation. Choose the setting namespace carefully: existing chat.editor settings describe response code blocks, not the input.
