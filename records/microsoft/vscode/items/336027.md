# Issue #336027 — Support `chat.editor.wordSeparators` setting for GitHub Copilot Chat input boxes

[https://github.com/microsoft/vscode/issues/336027](https://github.com/microsoft/vscode/issues/336027)

## Summary

Reasonable, technically grounded request: the chat input editor is a 'simple widget' CodeEditorWidget built with a static options object (getSimpleEditorOptions) that never sets or observes `editor.wordSeparators`, so CJK punctuation-aware word navigation genuinely doesn't work there today — but this is a fresh, uncommented, 0-upvote report that needs area-owner triage rather than an immediate close.

## Change summary

Add a dedicated `chat.editor.wordSeparators` setting (or otherwise honor word-separator configuration) for the Copilot Chat input box, since Ctrl+Left/Right currently jumps over entire CJK sentences there.

## Best solution

Have the chat/workbench owners decide whether to simply thread `editor.wordSeparators` (and wordSegmenterLocales-style live config) into the chat input's CodeEditorWidget construction in src/vs/workbench/contrib/chat/browser/widget/input/chatInputPart.ts / src/vs/workbench/contrib/codeEditor/browser/simpleEditorOptions.ts, or add the proposed chat-specific override — either closes the gap for CJK users.
