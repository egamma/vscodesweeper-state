# Issue #333648 — Show host name in Agent Host Terminal tab titles

[https://github.com/microsoft/vscode/issues/333648](https://github.com/microsoft/vscode/issues/333648)

## Summary

Fresh, well-scoped feature request (0 days old, no traction yet) that already carries the right area labels; no existing setting or naming path covers it on current main, so it stays open pending a maintainer decision on the naming scheme.

## Change summary

Agent Host Terminal tabs all show the generic title 'Agent Host Terminal' with no indication of which remote host/tunnel they belong to, making multiple sessions indistinguishable.

## Best solution

In agentHostTerminalService.ts, thread the connection's host/address (already available via IAgentHostTerminalEntry.address, used elsewhere for the 'Agent Host ({0})' profile name) into the default terminal `name` passed to createTerminal/reviveTerminal so each tab's title includes the host or tunnel name.
