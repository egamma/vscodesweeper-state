# Issue #309219 — Chat artifacts settings don't support workspace settings

[https://github.com/microsoft/vscode/issues/309219](https://github.com/microsoft/vscode/issues/309219)

## Summary

Team-authored feature request still under active discussion between members about how artifact path configuration should work per-workspace, particularly for the CLI. The artifact rule settings exist but may not cover the full workspace-scoping need for CLI plan paths.

## Change summary

Allow chat artifact settings (file path grouping rules) to be configured per workspace rather than globally.

## Best solution

Ensure the artifact rule settings (`chat.artifacts.rules.byFilePath`, etc.) properly support workspace-level configuration and that the Copilot CLI respects workspace-scoped overrides for plan file locations. The team discussion (comments 1-4) suggests an API for defining where plan files are stored may be needed.
