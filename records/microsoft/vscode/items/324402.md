# Issue #324402 — Copilot Chat loses custom agents and MCP servers after first prompt (workspace becomes `unknown:/`)

[https://github.com/microsoft/vscode/issues/324402](https://github.com/microsoft/vscode/issues/324402)

## Summary

The issue remains necessary: current main can still replace a session workspace with the synthetic `unknown:///` URI, and the customization workspace service accepts that URI as a project root, causing workspace agents and MCP configuration to be rediscovered against a scheme with no file-system provider.

## Change summary

Preserve the selected workspace custom agent and workspace MCP servers after the first prompt instead of switching customization discovery to `unknown:///`.

## Best solution

Keep a valid workspace root associated with the session when provider metadata is refreshed after the first turn, or treat the synthetic unknown workspace as unavailable for customization discovery. Add coverage for the transition from a valid draft workspace to provider session metadata without repository information.
