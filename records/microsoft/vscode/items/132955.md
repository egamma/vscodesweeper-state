# Issue #132955 — Support `highContrast` attribute on `DecorationRenderOptions`

[https://github.com/microsoft/vscode/issues/132955](https://github.com/microsoft/vscode/issues/132955)

## Summary

A real API gap remains on current main: decoration overrides still distinguish only light and dark themes, with high-contrast themes inheriting those respective overrides. Keep this accepted Backlog request open for API design.

## Change summary

Allow extensions to provide high-contrast-specific rendering options for editor decorations.

## Best solution

Design explicit high-contrast decoration overrides, accounting for both high-contrast light and dark themes, then carry them through the public API, extension-host conversion, editor decoration model, CSS generation, and overview ruler handling.

## Evidence

- **public API gap:** Current main exposes only `light` and `dark` overrides on `DecorationRenderOptions` in `src/vscode-dts/vscode.d.ts`; no high-contrast override exists.
- **runtime behavior:** `src/vs/editor/browser/services/abstractCodeEditorService.ts` applies light overrides to `.vs` and `.hc-light`, and dark overrides to `.vs-dark` and `.hc-black`, preventing independent high-contrast styling.
- **conversion boundary:** `src/vs/workbench/api/common/extHostTypeConverters.ts` and `src/vs/editor/common/editorCommon.ts` likewise carry only light and dark decoration overrides.
- **related issue:** https://github.com/microsoft/vscode/issues/141652 delivered a high-contrast light theme but did not add high-contrast-specific `DecorationRenderOptions`; it is related, not a canonical duplicate.
