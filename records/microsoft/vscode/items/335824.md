# Issue #335824 — Tab order after the picker closes in a new session goes back to the beginning

[https://github.com/microsoft/vscode/issues/335824](https://github.com/microsoft/vscode/issues/335824)

## Summary

This remains an actionable keyboard-focus bug: dismissing a Sessions picker by tabbing can restart focus at the beginning of the window instead of continuing through the local control sequence. The member-authored report provides a concrete reproduction, and current main retains the asynchronous blur-close and unconditional focus-restoration paths implicated in the behavior.

## Change summary

Preserve logical tab order when mode or permission pickers close in new and existing Sessions views.

## Best solution

Make action-widget dismissal distinguish Tab-driven focus traversal from cancellation or selection: Tab should continue to the next eligible control near the picker, while Escape and ordinary dismissal retain appropriate trigger-focus restoration.
