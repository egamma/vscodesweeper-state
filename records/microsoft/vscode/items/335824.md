# Issue #335824 — Tab order after the picker closes in a new session goes back to the beginning

## Summary

Fresh, first-hand bug report from a maintainer testing the new sessions view (linked to #335602): after a hover picker (Interactive / permission) closes via quick double-tab, focus jumps to Toggle Side Bar instead of continuing tab order from where the hover was triggered.
