# Issue #349807 — Sandbox Profile: Previously selected profile not shown while disconnected

[https://github.com/microsoft/vscode/issues/349807](https://github.com/microsoft/vscode/issues/349807)

## Summary

The disconnected picker still replaces the selected profile with Default, and an existing test explicitly requires that behavior. Keep this team-authored UX request open to reconcile the reporter's expectation with the current live-assignment-only design.

## Change summary

Keep the previously selected sandbox profile visible while its remote host is disconnected.

## Best solution

Show the last-known profile while disconnected without implying that it is freshly verified or allowing offline assignment. Reconnection should refresh the display from the host's authoritative state.
