# Issue #335441 — Terminal and Help menu hidden under ... in VS Code for Windows

[https://github.com/microsoft/vscode/issues/335441](https://github.com/microsoft/vscode/issues/335441)

## Summary

This is the intentional overflow behavior of the custom (non-native) menu bar: when the title bar doesn't have enough horizontal space for all menu titles, VS Code collapses the trailing menus into a '...' (More) button — visible in `updateOverflowAction()` in menubar.ts. It's a deliberate space-management feature, not a defect.

## Change summary

Reporter asks whether the Terminal and Help menus, which appear collapsed under a '...' overflow button on Windows, can be forced to always show inline.

## Best solution

As-designed: the custom menu bar computes available width and moves menus into the overflow '...' button when they don't fit (src/vs/base/browser/ui/menu/menubar.ts, `updateOverflowAction`). Widening the window, using compact/native title bar settings, or reducing menu bar zoom will show more menus inline; there is no separate defect to fix here.
