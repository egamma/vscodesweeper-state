This is expected, responsive behavior of the custom menu bar, not a bug — when the title bar/menu bar doesn't have enough horizontal width, VS Code collapses trailing menu items into an overflow '...' button by design; this reads as a support question about how to avoid that collapsing, not a defect.

  > Thanks for the report. This is expected behavior of VS Code's custom menu bar: when the window (or its available title-bar width) is too narrow to fit every top-level menu, the trailing items collapse into the '...' overflow menu, similar to how many apps handle a crowded title bar. Two ways to avoid it: widen the window a bit, or switch to `window.titleBarStyle: "native"` in settings, which uses the OS's native menu bar instead of VS Code's custom one and doesn't collapse items the same way.
