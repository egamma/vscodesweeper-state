# Issue #349618 — How should a user discover the built-in Copilot agents and skills?

[https://github.com/microsoft/vscode/issues/349618](https://github.com/microsoft/vscode/issues/349618)

## Summary

Keep open as a discoverability feature request: the existing Customizations editor supports built-in items, but current discovery explicitly excludes SDK built-in agents and skills. A complete inventory remains distinct from the related grouping and migration work.

## Change summary

List every available invokable customization with its name, kind, and source, including bundled and fileless SDK items.

## Best solution

Use the existing Customizations editor to expose the active harness's invokable inventory, including read-only SDK entries. Distinguish readable definitions from discovery-only entries without implying that unavailable source content can be opened.

- **current discovery exclusions:** src/vs/platform/agentHost/node/copilot/sessionCustomizationDiscovery.ts:643-678 skips agents with source === 'builtin'; discoverSkills at lines 757-781 omits skills without paths and skills with source === 'builtin'. These exclusions substantiate incomplete SDK inventory, although they do not prove every named item is available in every harness.
- **existing capability is partial:** src/vs/workbench/contrib/chat/browser/aiCustomization/aiCustomizationManagement.contribution.ts registers Open Customizations, and aiCustomizationListWidget.ts already renders a Built-in group for read-only customizations. This presents supplied items, not an exhaustive runtime catalog. extensions/copilot/src/extension/chatSessions/copilotcli/node/copilotCli.ts:425-455 enumerates prompt-service custom agents; CopilotCLICustomizationProvider.getSkillItems likewise reads prompt-service skills.
- **fileless content boundary:** src/vs/sessions/AI_CUSTOMIZATIONS.md documents host-provided troubleshoot as a discovery-only customization with no openable source. Thus displaying an item and exposing its definition are separate capabilities; the existing read-only presentation does not fully satisfy the requested inventory.
