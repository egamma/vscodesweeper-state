# Issue #330036 — Error: (sendFailed) Error: Copilot SDK rejected permission mode 'on'

[https://github.com/microsoft/vscode/issues/330036](https://github.com/microsoft/vscode/issues/330036)

## Summary

Team-authored, reopened bug with an assigned real release milestone (1.136.0) — the hard keep-open rule for assigned milestones applies regardless of other evidence, so no close is proposed. A second reporter confirmed the same failure on a later Insiders build (1.134.0), so it's still live.

## Change summary

When AH tries to set the Copilot SDK's allow-all permission mode ('on') for a session with autoApprove enabled, the SDK rejects it because enterprise managed settings could not be determined and bypass-permissions mode fails closed, causing sendMessage to fail outright.

## Best solution

Trace how `_getSdkPermissionMode()`/`syncPermissionMode` (src/vs/platform/agentHost/node/copilot/copilotAgentSession.ts, around lines 3457-3541) reacts when the SDK's `onManagedSettingsEnforced` event reports `action=bypass_permissions_blocked`: today the mismatch just throws and fails the send. The actual fail-closed enforcement logic lives inside the Copilot SDK dependency, not in this repo, so the AH-side fix is likely to detect this rejection and gracefully fall back to a non-bypass mode (or surface a clear user-facing error) instead of hard-failing the turn.
