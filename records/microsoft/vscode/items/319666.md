# Issue #319666 — Feature Request: Add a confirmation dialog to the "Archive/Clear" button in Copilot Chat

[https://github.com/microsoft/vscode/issues/319666](https://github.com/microsoft/vscode/issues/319666)

## Summary

Archiving is intentionally reversible and does not erase the conversation or its context. The existing Archived filter and Unarchive action provide a persistent recovery path, so a confirmation dialog would add friction to a non-destructive operation.

## Change summary

Add confirmation or short-lived undo UI before a Copilot Chat session is archived.

## Best solution

Keep Archive as a reversible, immediate organization action: accidentally archived sessions remain available under the Archived filter and can be restored with Unarchive. Reserve destructive safeguards for the separate permanent Delete action.

## Vision fit

- **Fit:** rejected
- **Reason:** Adding confirmation friction to a reversible action conflicts with the preference for simple, uniform UI interactions.

  > Thanks for the feedback. Archive is intentionally non-destructive: the session and its conversation remain available under the **Archived** filter and can be restored with **Unarchive**, as documented at https://code.visualstudio.com/docs/agents/run/sessions/manage-sessions#_archive-sessions. Because this action is already reversible, we don't plan to add a confirmation dialog; permanent deletion remains a separate action.
