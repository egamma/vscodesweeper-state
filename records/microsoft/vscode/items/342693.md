# Issue #342693 — Allow repeated Bakeoff runs with the same model and different thinking levels

[https://github.com/microsoft/vscode/issues/342693](https://github.com/microsoft/vscode/issues/342693)

## Summary

Keep open: current main supports comparing different reasoning configurations of one model, but explicitly deduplicates identical configurations, leaving the requested run-to-run comparisons and independently editable repeated attempts incomplete. This team-authored Backlog request is already correctly routed.

## Change summary

Allow independently managed Bakeoff attempts using the same model and identical or different reasoning configurations, with distinguishable labels and existing limits and accessibility preserved.

## Best solution

Complete the comparison setup experience so multiple attempts can retain identical model configurations and remain independently editable and removable. Build on the existing reasoning-variant support while preserving the two-to-ten attempt bounds, configuration isolation, and accessible navigation.
