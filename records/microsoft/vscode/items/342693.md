# Issue #342693 — Allow repeated Bakeoff runs with the same model and different thinking levels

[https://github.com/microsoft/vscode/issues/342693](https://github.com/microsoft/vscode/issues/342693)

## Summary

Keep open as scheduled work for 1.144.0. Current comparison setup supports different-effort variants, but explicitly deduplicates identical configurations, leaving the requested independently editable repeated attempts incomplete.

## Change summary

Allow multiple independently managed Bakeoff attempts using the same model and identical or different reasoning configurations, with distinguishable labels and existing limits and accessibility preserved.

## Best solution

Complete the attempt-level workflow in the Sessions comparison picker so identical model/configuration pairs can coexist and each attempt can be edited, removed, and identified independently. Preserve the existing different-effort support and two-to-ten-attempt limit.
