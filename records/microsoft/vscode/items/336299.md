# Issue #336299 — agentFilesLocations, skillFilesLocations disappears

[https://github.com/microsoft/vscode/issues/336299](https://github.com/microsoft/vscode/issues/336299)

## Summary

A maintainer already explained the direction (deprecating `chat.agentFilesLocations`/`chat.agentSkillsLocations` in favor of harness-native configuration as VS Code migrates off the Local agent harness), but several users are actively pushing back and no resolution has been reached — this stays open as an ongoing product discussion rather than a decline close.

## Change summary

Users want `chat.agentFilesLocations`/`chat.agentSkillsLocations` (and configurable skill/agent folder locations generally) kept rather than deprecated as VS Code migrates from the Local agent harness to the Copilot harness.

## Best solution

Either the Copilot CLI/SDK gains configurable workspace-level skill/agent directories (mirroring `~/.copilot/settings.json`'s `skillDirectories`) so users get back the flexibility, or the team formally reaffirms the deprecation with a documented migration path (the Agent Customizations editor migrations tab) — either way this needs an explicit maintainer decision recorded in the thread, since a settings deprecation is being contested by multiple users citing real workflows (shared skills across `.claude`, `.github`, `.agents`).
