# Issue #336299 — agentFilesLocations, skillFilesLocations disappears

[https://github.com/microsoft/vscode/issues/336299](https://github.com/microsoft/vscode/issues/336299)

## Summary

Confirmed on main: `chat.agentFilesLocations`/`chat.agentSkillsLocations` (and the sibling instructions/mode location settings) are deliberately deprecated as part of migrating from the VS Code 'Local agent harness' to letting each harness (Copilot, Claude, Codex) control its own customization discovery. A maintainer explained the rationale and pointed to existing alternatives (Copilot's `skillDirectories` in `~/.copilot/settings.json`, `.claude/skills`, symlinks), so this is an intentional design direction rather than a bug or oversight.

## Change summary

Restore configurability of agent/skill file locations (`agentFilesLocations`, `skillFilesLocations`) instead of deprecating them in favor of fixed Copilot-controlled locations.

## Best solution

Keep the shipped direction: the Local agent harness and its location settings are being retired in favor of harness-native discovery (`.github/agents`, `.github/skills`, `~/.copilot/settings.json` `skillDirectories`, or `.claude/skills` via symlink). If workspace-level custom skill folder configuration is wanted, that's a feature request against the Copilot CLI/SDK, not this VS Code setting.
