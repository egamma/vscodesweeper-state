# Issue #336299 — agentFilesLocations, skillFilesLocations disappears

[https://github.com/microsoft/vscode/issues/336299](https://github.com/microsoft/vscode/issues/336299)

## Summary

The settings still exist but are intentionally deprecated with the Local agent harness. A durable project-scoped custom-directory mechanism must be defined by the Copilot SDK so it works consistently across VS Code, CLI, and cloud, making this an upstream request rather than a VS Code bug.

## Change summary

Preserve configurable workspace and user search paths for custom agents and skills, including neutral locations such as `.agents/agents` and `.agents/skills`.

## Best solution

Add an SDK-supported workspace configuration for additional skill and custom-agent directories, then have VS Code consume that shared contract instead of retaining a VS Code-specific discovery layer.
