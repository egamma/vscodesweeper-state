# Issue #337521 — Terminal title and inline actions dont show if hidden terminals are detected

[https://github.com/microsoft/vscode/issues/337521](https://github.com/microsoft/vscode/issues/337521)

## Summary

The disappearance is directly traceable on current main: hidden chat terminals unconditionally suppress both the active-terminal title and inline actions, overriding their configured visibility. Keep this open in the terminal area.

## Change summary

Preserve the configured active-terminal title and inline split/kill actions when Copilot creates a hidden terminal.

## Best solution

Terminal view-title visibility should continue to honor the active-terminal and action settings when hidden chat terminals exist, while retaining access to those hidden terminals through the tabs view.
