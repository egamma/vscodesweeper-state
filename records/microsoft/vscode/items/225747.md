# Issue #225747 — Invalid line width

[https://github.com/microsoft/vscode/issues/225747](https://github.com/microsoft/vscode/issues/225747)

## Summary

The maintainer explained this is expected behavior: VS Code's rendering is Chromium-based and respects font kerning rules. Unicode suit symbols (♣♠♥♦) may not be monospaced in all fonts. The suggested fix is using a strict monospace font.

## Change summary

Lines with special Unicode characters (card suits) render at different widths than plain ASCII lines despite having the same character count.

## Best solution

Close as designed — Chromium respects per-font kerning/glyph-width rules; Unicode characters outside the ASCII range may not be strictly monospaced depending on the font. Users should choose a strict monospace font (e.g. Consolas, Inconsolata) for consistent widths.
