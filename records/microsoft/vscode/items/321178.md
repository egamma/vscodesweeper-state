# Issue #321178 — @restartrequired tag "Show" link doesn't refresh when new extensions are updated

[https://github.com/microsoft/vscode/issues/321178](https://github.com/microsoft/vscode/issues/321178)

## Summary

The bug remains source-reproducible on current main: clicking Show again with `@restartrequired` already selected performs no search, leaving the extension list stale until the filter is cleared.

## Change summary

Refresh the restart-required extension results when Show is clicked after additional extensions begin requiring a restart.

## Best solution

Make repeated activation of the restart-required notification query refresh its local extension results while preserving normal search and filtering behavior.
