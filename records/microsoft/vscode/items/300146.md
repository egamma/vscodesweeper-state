# Issue #300146 — Copilot CLI: Store attachments in session metadata store

[https://github.com/microsoft/vscode/issues/300146](https://github.com/microsoft/vscode/issues/300146)

## Summary

Keep this accepted cleanup open: current Copilot CLI history reconstruction still parses prompt text, and the VS Code session metadata contract does not store attachments. No issue-referencing fix or qualifying canonical duplicate was established.

## Change summary

Persist Copilot CLI request attachments in session metadata instead of reconstructing them from prompt text.

## Best solution

Preserve structured, per-request attachment references so restored Copilot CLI history faithfully represents the original request, while retaining compatibility with older sessions. Establish the supported attachment types and persistence contract before implementing this across request recording and history restoration.
