## Summary

Valid internal debt item: the Copilot CLI session metadata store does not persist attachments, requiring parsing to reconstruct them. The work has not been implemented on main — no commits reference this issue, and the metadata store implementation has no attachment handling.

## Change summary

Store chat attachments directly in the Copilot CLI session metadata store instead of requiring fragile parsing to reconstruct them.

## Best solution

Extend `ChatSessionMetadataStore` in `extensions/copilot/src/extension/chatSessions/copilotcli/vscode-node/chatSessionMetadataStoreImpl.ts` to persist attachment metadata alongside sessions, so session restore can retrieve attachments directly rather than parsing conversation history.
