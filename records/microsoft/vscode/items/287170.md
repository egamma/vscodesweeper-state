# Issue #287170 — Option for Copilot handoff buttons to force a new chat session to avoid context rot

[https://github.com/microsoft/vscode/issues/287170](https://github.com/microsoft/vscode/issues/287170)

## Summary

Valid feature request for handoff buttons to optionally start a new chat session. Not yet implemented — the IHandOff interface has no newSession property. 19 upvotes approaching Backlog threshold, and a team member recently engaged (cc'd another). Keeping open for triage.

## Change summary

Add an option for Copilot handoff buttons to start a new chat session with only curated context, avoiding context rot from accumulated history.

## Best solution

Add a `newSession` (or similar) property to the handoff configuration in `src/vs/workbench/contrib/chat/common/promptSyntax/promptFileParser.ts` (the `IHandOff` interface) and wire it through `chatSuggestNextWidget.ts` so clicking the button opens a fresh session with only the handoff prompt/summary as context. This aligns with the agents-window multi-session architecture.
