# Issue #336698 — Copilot agent chat should not show feedback (chat transcript upload) buttons when telemetry off or using BYOK

[https://github.com/microsoft/vscode/issues/336698](https://github.com/microsoft/vscode/issues/336698)

## Summary

The buttons are intentionally controlled by the separate `telemetry.feedback.enabled` setting, and the vote path sends rating metadata rather than chat transcripts or attached code. BYOK and the general telemetry level do not currently redefine that feedback preference, so the existing setting covers the requested opt-out.

## Change summary

Hide Helpful and Unhelpful chat controls when product telemetry is off or the selected model uses BYOK.

## Best solution

Keep feedback visibility governed by `telemetry.feedback.enabled`; users and administrators who do not want feedback mechanisms can set it to `false`, independently of model provider and diagnostic telemetry level.
