# Issue #190879 — [folding] Folding is clickable on the whole foldable region in the gutter

[https://github.com/microsoft/vscode/issues/190879](https://github.com/microsoft/vscode/issues/190879)

## Summary

A real folding interaction gap remains on current main: gutter clicks only toggle a range from its starting line. This member-authored Backlog request is protected from judgment closes, and no older canonical issue owns the same observable behavior.

## Change summary

Allow clicking the folding gutter anywhere within a foldable region to collapse that region.

## Best solution

Define which containing range wins when nested fold regions overlap, then extend the editor folding mouse interaction so clicks within an expanded region collapse the intended range without interfering with source-control gutter decorations.
