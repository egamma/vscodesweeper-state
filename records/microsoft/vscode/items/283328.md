# Issue #283328 — No stop button to interrupt agent

[https://github.com/microsoft/vscode/issues/283328](https://github.com/microsoft/vscode/issues/283328)

## Summary

The persisted post-reopen case is fixed on current main by a later issue-linked commit: the stop action now remains available whenever the response has not reached a terminal state, including while an elicitation needs input.

## Change summary

An active agent request could lose its stop button, or expose a stop button that did not interrupt it, after an elicitation such as “Focus Terminal” remained pending.

## Best solution

Keep the active-request state introduced by https://github.com/microsoft/vscode/commit/07f2e22302307538d346bb3a0be7959cea5b20f6 as the source for stop-button visibility; it preserves cancellation throughout pending confirmations and elicitations.
