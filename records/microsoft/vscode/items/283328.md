# Issue #283328 — No stop button to interrupt agent

[https://github.com/microsoft/vscode/issues/283328](https://github.com/microsoft/vscode/issues/283328)

## Summary

Team-authored issue with `important` label — must stay open. Three merged PRs have addressed specific manifestations, but the underlying elicitation state-management bug persists; the most recent fix (PR #307938, April 2026) is explicitly a workaround, not a root-cause fix.

## Change summary

The stop button disappears or becomes non-functional during agent sessions, leaving users unable to interrupt the AI without reloading the window.

## Best solution

The workaround in PR #307938 (using `chatSessionHasActiveRequest` context key) ensures the stop button is visible during elicitation states, but the root cause — elicitations not properly transitioning state when dismissed — still needs fixing in the chat model's elicitation lifecycle (`src/vs/workbench/contrib/chat/common/model/chatModel.ts`). A proper fix should ensure elicitations transition out of pending state when the user clicks 'focus terminal' or otherwise dismisses them.
