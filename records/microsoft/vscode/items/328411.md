# Issue #328411 — Windows: After clicking to open the search bar at the top of the window and then clicking elsewhere to close it, the search bar still shows up but you can't interact with it.

[https://github.com/microsoft/vscode/issues/328411](https://github.com/microsoft/vscode/issues/328411)

## Summary

A trusted community contributor confirmed this is intentional: the find/search widget stays visible after clicking elsewhere so users can still reference it, and closes via Esc rather than an outside click — matches *as-designed.

## Change summary

The editor's find/search widget doesn't dismiss when clicking elsewhere in the window; it stays visible and (per the reporter) unresponsive.

## Best solution

Close as as-designed: the widget intentionally persists on outside-click so the current search context stays visible; Esc is the documented dismiss action. If the reporter still finds the widget truly unresponsive (not just visually present) after pressing Esc, that would be a distinct, narrower repro worth a fresh report.
