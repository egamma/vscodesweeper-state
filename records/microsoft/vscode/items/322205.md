[https://github.com/microsoft/vscode/issues/322205](https://github.com/microsoft/vscode/issues/322205)

## Summary

The Marketplace already exposes an AI category, but the requested free-plan, trial, quota, and student-benefit metadata is a real additional capability. With no canonical issue, maintainer decision, or community demand establishing its direction, this should remain open under discussion rather than receive a judgment close.

## Change summary

Add a Marketplace directory for free AI coding assistants, including student offers, trials, quotas, and alternatives when credits expire.

## Best solution

If pursued, define generic, publisher-maintained Marketplace metadata for pricing tiers, trials, and eligibility, then expose filters within the existing AI category rather than adding a hardcoded or manually curated VS Code directory. This keeps changing commercial terms authoritative and avoids endorsing a fixed set of assistants.
