# Issue #346028 — Support administrator-approved redirects for custom MCP registries

[https://github.com/microsoft/vscode/issues/346028](https://github.com/microsoft/vscode/issues/346028)

## Summary

Administrator-approved cross-origin registry redirects remain unsupported; the trailing-slash fix does not deliver this capability. Keep open for human review because the request changes an enterprise trust boundary and falls under the security-sensitive keep-open rule.

## Change summary

Allow custom MCP registry redirects to explicitly administrator-approved origins while retaining restrictions on unapproved destinations.

## Best solution

Have MCP and enterprise-policy owners decide whether and how administrator-approved redirect origins can participate in registry membership validation, preserving restrictive defaults and consistent enforcement after reload.
