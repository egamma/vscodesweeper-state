# Issue #346790 — Explorer jumping around whenever a file window is closed

[https://github.com/microsoft/vscode/issues/346790](https://github.com/microsoft/vscode/issues/346790)

## Summary

The Explorer movement follows the configured auto-reveal behavior, rather than a demonstrated implementation defect. Keep the request to reconsider the default open for an Explorer product decision; existing settings mitigate the workflow but do not change the default.

## Change summary

Use a less disruptive Explorer auto-reveal default so closing an editor does not pull navigation away from nearby files.

## Best solution

Have the Explorer owner evaluate the requested default change separately from existing behavior. For the reported workflow today, explorer.autoReveal=false prevents automatic expansion and selection; focusNoScroll suppresses automatic reveal scrolling but still expands the active file's ancestors.
