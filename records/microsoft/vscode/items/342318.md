## Summary

The Markdown editor still omits both math settings from its configuration and rendering paths. Keep this open: current source confirms the integration gap, despite the editor package advancing since the report.

## Change summary

Make the rich Markdown editor honor markdown.math.macros and markdown.math.enabled, including changes while a document is open.
