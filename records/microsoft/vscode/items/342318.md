# Issue #342318 — New Markdown editor ignores markdown.math.macros (and markdown.math.enabled)

[https://github.com/microsoft/vscode/issues/342318](https://github.com/microsoft/vscode/issues/342318)

## Summary

The settings gap remains in current main: the new Markdown editor neither receives the math configuration nor responds to its changes. Keep this open; the supplied reproduction is sufficient, and the integration omission is directly visible in source.

## Change summary

Make the new Markdown editor honor markdown.math.macros and markdown.math.enabled, including changes while a document is open.

## Best solution

Bring the new editor's math rendering into parity with the existing Markdown math settings, covering initial rendering and live configuration changes. Establish the supported rendering contract in @vscode/markdown-editor and wire it through the built-in Markdown editor integration without changing preview behavior.
