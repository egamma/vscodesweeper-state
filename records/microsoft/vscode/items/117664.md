# Issue #117664 — Diff editor scrolls horizontally when dragging selection vertically

[https://github.com/microsoft/vscode/issues/117664](https://github.com/microsoft/vscode/issues/117664)

## Summary

Still reproduces on main: when the mouse drags over a view zone (e.g. in the diff editor), the resolved position snaps to end-of-line above the zone, causing unwanted horizontal scroll. The root cause is unchanged in the current code.

## Change summary

Dragging a selection vertically over a diff editor view zone causes horizontal scroll because the cursor position snaps to the end of the line above instead of using the mouse's horizontal offset.

## Best solution

In `src/vs/editor/browser/controller/mouseTarget.ts`, when resolving `positionBefore` for a view zone hit (around line 286), use the mouse's horizontal coordinate to compute the column on the line above rather than defaulting to `getLineMaxColumn`. alexdima's comment confirms this approach is correct except for rare cases where the line above isn't visible.
