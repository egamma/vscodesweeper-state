# Issue #117664 — Diff editor scrolls horizontally when dragging selection vertically

[https://github.com/microsoft/vscode/issues/117664](https://github.com/microsoft/vscode/issues/117664)

## Summary

The defect remains in current main: dragging upward across a diff view zone selects the end of the preceding line, which can reveal that distant column and scroll horizontally. The issue is already routed to editor rendering and should remain open.

## Change summary

Dragging a text selection vertically across a diff editor view zone unexpectedly moves the selection endpoint to the preceding line's end and scrolls the editor horizontally.

## Best solution

Selection crossing a view zone should retain the mouse's horizontal position whenever an adjacent visible line permits coordinate-to-column conversion, while preserving safe fallback behavior for large zones and bidi or RTL text.
