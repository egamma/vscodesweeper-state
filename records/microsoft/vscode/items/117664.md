# Issue #117664 — Diff editor scrolls horizontally when dragging selection vertically

[https://github.com/microsoft/vscode/issues/117664](https://github.com/microsoft/vscode/issues/117664)

## Summary

Still reproduces on main: when dragging a selection upward over a view zone in the diff editor, `positionBefore` resolves to end-of-line (via `getLineMaxColumn`), causing unwanted horizontal scroll. The fix alexdima suggested (use horizontal mouse offset for column) has never been implemented.

## Change summary

Dragging a selection vertically over a diff view zone snaps cursor to end-of-line, causing unwanted horizontal scroll.

## Best solution

In `mouseTarget.ts` (line ~286), when computing `positionBefore` for a view zone, use the mouse's horizontal coordinate to derive the column (similar to how normal line hit-testing works) instead of unconditionally using `getLineMaxColumn`. Guard for the edge case alexdima noted (line above not visible) by falling back to max column only then.
