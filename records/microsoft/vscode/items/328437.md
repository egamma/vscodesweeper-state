# Issue #328437 — Feature Request: Add spawnSession agent tool to run subagents in their own chat session

[https://github.com/microsoft/vscode/issues/328437](https://github.com/microsoft/vscode/issues/328437)

## Summary

A real capability gap remains: current subagents are read-only child chats within the parent session, while this request needs independently resumable sessions with isolated changes. Route to the Agents window and subagent owners for product and permission design.

## Change summary

Add an agent tool that delegates work into a new top-level chat session and returns a link and result to the parent.

## Best solution

Add a session-spawning tool backed by the existing background session-creation path, preserving parent/tool provenance while giving the child an independent transcript, changeset, and follow-up capability. The design should define permissions, lifecycle, concurrency, and foreground/background behavior before implementation.
