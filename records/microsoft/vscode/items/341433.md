## Change summary

The local Copilot agent works from stale file contents after the files were edited on disk or manually, and overwrites the user's edits.

## Best solution

Establish whether the agent's file reads and edit tools use stale cached or in-memory content instead of the current text model or disk state. If so, fix the invalidation in the chat tools. If the cause is stale conversation context, handle it as a separate prompt-context issue.
