# Issue #334126 — Old pasted image permanently breaks later text-only requests with vision_attachment_not_accessible

[https://github.com/microsoft/vscode/issues/334126](https://github.com/microsoft/vscode/issues/334126)

## Summary

Real, still-open bug: when a historical vision attachment expires, Copilot keeps resending it and the auto-retry loop has no special handling for `vision_attachment_not_accessible` (only `context_length_exceeded`-style overflow is special-cased), so the conversation becomes permanently stuck. An open PR already proposes a fix, so this should stay open pending review/merge rather than being closed now.

## Change summary

An expired/inaccessible pasted image attachment in an old Copilot Chat turn gets resent on every subsequent text-only request, causing repeated `vision_attachment_not_accessible` failures and an infinite auto-retry loop that makes the conversation unusable.

## Best solution

Land (or iterate on) the linked PR https://github.com/microsoft/vscode/pull/334129, which proposes skipping auto-retry for `vision_attachment_not_accessible` and surfacing an actionable error, mirroring the existing `isContextOverflowBadRequest` special-case in extensions/copilot/src/extension/prompt/node/searchSubagentToolCallingLoop.ts.
