# Issue #263293 — Change between models with hotkeys

[https://github.com/microsoft/vscode/issues/263293](https://github.com/microsoft/vscode/issues/263293)

## Summary

Valid feature request for direct model-switching keybindings or a cycle-models shortcut. Not implemented on main — the existing `OpenModelPickerAction` (Cmd+Alt+.) opens the picker but doesn't support cycling or direct model switching via keybinding. A newer, more detailed duplicate exists at #317991 that could be consolidated into this one.

## Change summary

Allow switching between chat models via dedicated hotkeys — either binding a shortcut to a specific model or cycling through models with a single keystroke.

## Best solution

Expose `workbench.action.chat.changeModel` (already exists at `chatExecuteActions.ts:770` but is `f1: false` with no keybinding) as a user-facing command accepting a model identifier argument, so users can bind it to keys. Additionally, consider a cycle-previous-model command. Issue https://github.com/microsoft/vscode/issues/317991 is a later, more detailed duplicate that should be consolidated here.
