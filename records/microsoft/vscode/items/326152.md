# Issue #326152 — "languageModelTools" are duplicated in the tool picker

[https://github.com/microsoft/vscode/issues/326152](https://github.com/microsoft/vscode/issues/326152)

## Summary

Confirmed on current main: the tool picker's `computeItems()` in chatToolPicker.ts adds extension-contributed tools twice — once as children of the synthetic per-extension tool set, and again as direct children of the extension bucket — because the second loop has no deduplication against tools already placed under a tool set.

## Change summary

Extension-contributed languageModelTools appear duplicated in the Chat tool picker — once under the extension's tool set and once standalone under the extension bucket.

## Best solution

In `computeItems()` in `chatToolPicker.ts`, the second loop (line ~473) that adds individual tools to buckets should skip tools that were already added as children of a tool set in the same bucket. A `Set<string>` of tool IDs placed via the tool-set loop would serve as the dedup guard.
