## Summary

A real customization gap remains on current main: both context-usage surfaces still use fixed 75% and 90% thresholds, while the only related setting controls indicator visibility. With no canonical issue or maintainer scope decision, this should remain open as under discussion.

## Change summary

Allow users to configure the warning and error color thresholds for the chat context-window usage indicator.
