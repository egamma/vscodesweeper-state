# Issue #199126 — [Accessibility] Preserve last position in the Copilot Chat response list view

[https://github.com/microsoft/vscode/issues/199126](https://github.com/microsoft/vscode/issues/199126)

## Summary

The central request is implemented through a dedicated command that restores the last focused chat item, matching the separate-command approach suggested in the discussion. Propose closing as completed; ordinary Ctrl+Up retains its latest-response behavior.

## Change summary

Allow keyboard users to return to their previously focused chat response after leaving the response list.

## Best solution

Keep the implemented workbench.chat.action.focusLastFocused command and its Ctrl+Shift+Up shortcut on Windows/Linux. Use that command instead of chat.action.focus in the reporter's command sequence to return to the previous response before opening Accessible View.

  > Thanks for the request. Returning to the previously focused response is now supported by `workbench.chat.action.focusLastFocused` (Focus Last Focused Chat List Item), added in https://github.com/microsoft/vscode/commit/5cb209f624eed24c1e4ff5e4d58a761fd47eec33. On Windows, use Ctrl+Shift+Up, or replace `chat.action.focus` with this command in your `runCommands` sequence before `editor.action.accessibleView`. Ordinary Ctrl+Up still focuses the latest response; the separate command provides the position-preserving behavior discussed here. The fix shipped in 1.105.0.
