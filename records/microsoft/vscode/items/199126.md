# Issue #199126 — [Accessibility] Preserve last position in the Copilot Chat response list view

[https://github.com/microsoft/vscode/issues/199126](https://github.com/microsoft/vscode/issues/199126)

## Summary

This feature request has been implemented: a dedicated 'Focus Last Focused Chat List Item' command (`workbench.chat.action.focusLastFocused`) was added, bound to Ctrl+Shift+Up, which preserves and returns to the last focused position in the chat response list. Shipped in 1.105.0.

## Change summary

Request to preserve and restore the last focused position in the Copilot Chat response list view when navigating back from the input area.

## Best solution

Keep the shipped implementation: `workbench.chat.action.focusLastFocused` (Ctrl+Shift+UpArrow) returns focus to the last focused chat response item, while the default `chat.action.focus` (Ctrl+UpArrow) continues to focus the last response. The accessibility help dialog also documents this keybinding. No further change needed.
