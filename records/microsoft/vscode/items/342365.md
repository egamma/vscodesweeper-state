## Summary

Keep open: current main still assembles the Universal application from unsigned architecture archives, then skips the signing-time insertion of NSAppleEventsUsageDescription. The supplied Swift reproduction and TCC log identify a concrete packaging defect; the automated upgrade request does not establish that it was fixed.

## Change summary

Ensure the Universal macOS application includes the Apple Events usage description so terminal-launched tools can request Automation consent.
