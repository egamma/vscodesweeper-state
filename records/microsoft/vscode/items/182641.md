# Issue #182641 — Multicursor on duplicated lines disappears

[https://github.com/microsoft/vscode/issues/182641](https://github.com/microsoft/vscode/issues/182641)

## Summary

Still reproduces on main: when multiple cursors sit on the same line and the line is duplicated via Copy Line Down, the deduplication logic in AbstractCopyLinesAction marks all but one selection as noop. Each noop CopyLinesCommand still emits an edit and tracks only one selection, so the extra cursors are lost instead of being replicated onto the new line.

## Change summary

Duplicating a line (Ctrl+Shift+D) when multiple cursors exist on that line drops all but a few cursors instead of preserving them on the copied line.

## Best solution

Fix `AbstractCopyLinesAction.run()` in `src/vs/editor/contrib/linesOperations/browser/linesOperations.ts` so that when multiple selections on the same line are deduplicated, the resulting cursor state after the copy includes all original cursor positions translated to the new (duplicated) line. The noop `CopyLinesCommand` path needs to compute cursor positions that reflect the copied content rather than emitting destructive edit operations.
