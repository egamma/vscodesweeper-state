# Issue #182641 — Multicursor on duplicated lines disappears

[https://github.com/microsoft/vscode/issues/182641](https://github.com/microsoft/vscode/issues/182641)

## Summary

The defect remains on current main: copying a line containing several selections deliberately deduplicates the line edit, but overlapping placeholder edits are then discarded together with four of the six cursor states. The command duplicates the line once but leaves only two selections.

## Change summary

Duplicating a line with several selections on that line preserves only two of the selections instead of all of them.

## Best solution

Copy each source line only once while preserving every distinct selection on the duplicated line, with a regression test covering multiple selected occurrences on one line.
