# Issue #339610 — Bulk file moves repeatedly refresh expanded Explorer folders

[https://github.com/microsoft/vscode/issues/339610](https://github.com/microsoft/vscode/issues/339610)

## Summary

Team-authored, reproducible perf bug with an open draft PR (#339614) from the same author already implementing and validating a fix — keep open until that PR merges rather than closing or treating as implemented.

## Change summary

Bulk file/folder moves in Explorer trigger a per-item parent refresh and tree render, causing visible slowdown (≈1.9s vs 0.2s) when the moved files' parent folders are expanded.

## Best solution

Review and land draft PR https://github.com/microsoft/vscode/pull/339614, which coalesces parent refreshes during bulk moves in ExplorerService.onDidRunOperation.
