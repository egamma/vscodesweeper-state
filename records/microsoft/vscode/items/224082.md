# Issue #224082 — Mac: Text replacement not working.

[https://github.com/microsoft/vscode/issues/224082](https://github.com/microsoft/vscode/issues/224082)

## Summary

macOS system text replacement is a known Chromium/Electron limitation — the NSTextInputClient text substitution protocol is not fully implemented upstream. This is still unresolved on current main and is the sole remaining open report after related issues were closed.

## Change summary

macOS system-level text replacements (configured in System Settings → Keyboard → Text) do not trigger in VS Code's editor.

## Best solution

Track as an upstream Chromium/Electron text-input limitation. The root cause is that Chromium does not fully implement macOS's NSTextInputClient substitution protocol — VS Code cannot fix this without upstream changes. The area label `editor-input` should be added for proper routing, and the type should reflect its upstream nature.
