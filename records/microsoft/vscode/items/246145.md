# Issue #246145 — Cannot unbind positionPanelLeft and positionPanelRight

[https://github.com/microsoft/vscode/issues/246145](https://github.com/microsoft/vscode/issues/246145)

## Summary

The issue reports an inability to unbind positionPanelLeft/positionPanelRight keybindings (ctrl+alt+left/right on macOS). The commands have no default keybinding in the source, making the origin of the binding unclear, but the reported behavior (inability to unbind and have the event bubble to OS) is a plausible keybinding system issue that remains unresolved on main.

## Change summary

User cannot unbind ctrl+opt+left/right from positionPanelLeft/positionPanelRight, and setting a negative binding or noop prevents the shortcut from reaching the OS.

## Best solution

Investigate the source of the ctrl+alt+arrow → positionPanel bindings (they aren't registered in current source — may be a leftover user keybinding or something platform-specific). If legitimate, the keybinding resolver's handleRemovals at `src/vs/platform/keybinding/common/keybindingResolver.ts` should handle removal of non-default bindings, and the abstractKeybindingService dispatch should ensure events for null-command resolutions bubble to the OS.
