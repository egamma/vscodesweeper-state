## Change summary

Editor cursor is misaligned at certain column positions when a line contains Swedish characters (å, ä, ö) in VS Code Insiders.

## Best solution

Ask the reporter for the output of 'Developer: Font Info' command and their exact font family. The bug likely lives in the font measurement / monospace assumption code in `src/vs/editor/browser/config/fontMeasurements.ts` — the monospace test chars don't include accented Latin characters, and if the font renders å/ä/ö at a slightly different width, the cursor position calculation drifts. The Insiders-only aspect may relate to an Electron/Chromium version difference in text shaping.
