[https://github.com/microsoft/vscode/issues/312623](https://github.com/microsoft/vscode/issues/312623)

## Summary

The RTL/BiDi rendering gap remains on current main, but an open PR explicitly fixes this issue and adds focused coverage. Keep the issue open while that human-owned implementation is reviewed rather than closing it as a duplicate or completed work.

## Change summary

Mixed Persian, Arabic, or Hebrew prose containing English technical terms is displayed in the wrong visual order in Copilot Chat.
