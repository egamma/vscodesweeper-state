# Issue #26729 — VS Code keyboard shortcuts suggestion to learn

[https://github.com/microsoft/vscode/issues/26729](https://github.com/microsoft/vscode/issues/26729)

## Summary

Keep open: personalized shortcut suggestions remain distinct from the existing Command Palette suggestions, and two open PRs already attempt this work. The request has substantial community support and a maintainer explicitly welcomed core contributions for a keybinding tutor.

## Change summary

Suggest useful keyboard shortcuts based on commands the user repeatedly invokes with the mouse.

## Best solution

Review the existing tutor PRs and select an implementation that teaches shortcuts from repeated mouse usage without treating keyboard invocations as missed shortcuts or interrupting normal work. Resolve the competing proposals before starting another implementation.
