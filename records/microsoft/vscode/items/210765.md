# Issue #210765 — ChatResponseCommandButtonPart's should have a way to signal they've been 'used'

[https://github.com/microsoft/vscode/issues/210765](https://github.com/microsoft/vscode/issues/210765)

## Summary

Keep open: current main still provides no supported way to update or disable a command button after use, and the API design concern about per-response context-key leakage remains unresolved.

## Change summary

Allow chat response command buttons to become disabled or change their presentation after execution.

## Best solution

Design a lifecycle-safe chat API for updating command-button state without requiring extensions to create per-response context keys. The change would span the public API declaration, extension-host conversion, chat DTO, and command-button renderer.
