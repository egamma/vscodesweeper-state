# Issue #215390 — Cursor appears before decoration on empty lines

[https://github.com/microsoft/vscode/issues/215390](https://github.com/microsoft/vscode/issues/215390)

## Summary

The defect remains source-reproducible on current main: empty decorated lines receive a non-empty character mapping, bypassing the existing pixel-offset logic that places the caret after a before-decoration.

## Change summary

Place the caret after a before-content decoration when the decorated editor line has no text.

## Best solution

Restore correct caret positioning for empty lines while preserving support for multiple before and after decorations introduced for https://github.com/microsoft/vscode/issues/118759.
