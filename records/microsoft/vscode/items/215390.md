# Issue #215390 — Cursor appears before decoration on empty lines

[https://github.com/microsoft/vscode/issues/215390](https://github.com/microsoft/vscode/issues/215390)

## Summary

Still reproduces on current main: the cursor is positioned before `before` decorations on empty lines because `CharacterMapping` is created with length 1 (line 403 of viewLineRenderer.ts), causing the length-0 guard in `_readPixelOffset` (viewLine.ts:588) to be skipped.

## Change summary

Cursor appears before `before` decorations on empty lines instead of after them.

## Best solution

Fix the interaction between `renderViewLine` (src/vs/editor/common/viewLayout/viewLineRenderer.ts, line 403) and `_readPixelOffset` (src/vs/editor/browser/viewParts/viewLines/viewLine.ts, line 588): either create the `CharacterMapping` with length 0 for the empty-line-with-decorations case (as the reporter suggests), or adjust the `_readPixelOffset` guard to handle a CharacterMapping of length 1 that represents only foreign elements. Add a test in viewLineRenderer.test.ts covering before-decoration on empty lines.
