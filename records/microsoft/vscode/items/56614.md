# Issue #56614 — Allow extensions to be installed for all users

[https://github.com/microsoft/vscode/issues/56614](https://github.com/microsoft/vscode/issues/56614)

## Summary

A real gap remains for centrally managed extensions alongside per-user extensions. With 73 community upvotes and a Backlog milestone, this established request should remain open.

## Change summary

Allow administrators to install and maintain extensions once for every OS user while preserving each user's own extension directory and settings.

## Best solution

Add a managed, read-only extension location that is scanned alongside the writable per-user location, with supported administrator CLI operations for installation and updates. The design belongs in environment argument handling and extension scanning/management, and must define precedence, updates, profiles, and permissions.
