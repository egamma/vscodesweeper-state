# Issue #131182 — [api] memento onDidChange api

[https://github.com/microsoft/vscode/issues/131182](https://github.com/microsoft/vscode/issues/131182)

## Summary

A real API gap remains: global memento values synchronize across windows internally, but extensions cannot subscribe to those changes. The issue is already correctly classified and routed in the Backlog.

## Change summary

Expose a Memento change event so extensions can react when global or workspace state changes, particularly from another window.

## Best solution

Add a proposed key-scoped change event to `Memento`, backed by the existing extension-host storage notification path, then clarify whether it fires for local writes as well as external-window changes before API finalization.

## Evidence

- **public API gap:** `src/vscode-dts/vscode.d.ts` exposes only `Memento.keys`, `get`, and `update`; there is no change event.
- **existing infrastructure:** `src/vs/workbench/api/common/extHostStorage.ts` already emits `onDidChangeStorage`, and `src/vs/workbench/api/common/extHostMemento.ts` consumes it only to replace the cached value without notifying extensions.
- **cross-window support:** Commit 2ce9665b30fc76409899268ce0471c213359a898 fixed https://github.com/microsoft/vscode/issues/55834 by synchronizing global state between windows, providing the underlying mechanism but not the requested public event.
- **prior API discussion:** The discussion on https://github.com/microsoft/vscode/issues/95209 explicitly considered `Memento.onDidChange`; maintainers said the event was planned for later, but it was not included in the finalized API.
- **canonical search:** Searches for open VS Code issues covering Memento change events and cross-window globalState notifications found only https://github.com/microsoft/vscode/issues/131182.
- **continued use case:** Comments describe extensions abusing `SecretStorage.onDidChange` or implementing external pub/sub, and https://github.com/Vizards/localias/pull/2 references this gap while implementing cross-window synchronization.
