# Issue #129505 — Git - Images should not be `textconv`ed when pulled from Git for display in diff viewer

[https://github.com/microsoft/vscode/issues/129505](https://github.com/microsoft/vscode/issues/129505)

## Summary

The reported failure remains source-reproducible: Git-backed image previews receive textconv output rather than image bytes. Keep this correctly routed Git bug open; the related quick-diff issue does not cover the same observable symptom.

## Change summary

Images configured with a Git textconv driver fail to display on Git-backed sides of staged and unstaged image comparisons.

## Best solution

Image comparisons should receive the original image bytes for the requested HEAD and index revisions, while preserving textconv behavior for textual comparisons. Address the Git resource-reading path and retain the existing image preview and Git LFS behavior.
