# Issue #130082 — Add option to always open files at their canonical path

## Summary

The requested capability remains missing, but the older, open issue https://github.com/microsoft/vscode/issues/34627 already requests configurable opening at the original path and documents the same duplicate-editor and missing Git annotation symptoms. ## Change summary

Add an opt-in setting that resolves symbolic links when opening files so alternate paths reuse the original file's editor and integrations.
