# Issue #325455 — vscode.lm — Add model visibility (hide/show) APIs

[https://github.com/microsoft/vscode/issues/325455](https://github.com/microsoft/vscode/issues/325455)

## Summary

Legitimate API gap: the internal ILanguageModelsService already implements model visibility (hide/show), but no vscode.lm API exposes it to extensions. Milestone is the Backlog Candidates holding bin and the bot just posted the standard 60-day upvote notice, so this should stay open for the normal community process rather than be closed for having 0 upvotes at 26 days.

## Change summary

Expose the existing model-visibility state (isModelHidden/setModelHidden/setGroupHidden/getHiddenModelIds/onDidChangeModelVisibility) from ILanguageModelsService as a public/proposed vscode.lm API so extensions (BYOK providers, model-management UIs) can read and control the model picker's hide/show state.

## Best solution

Add a proposed API file (e.g. vscode.proposed.lmModelVisibility.d.ts) that thinly bridges the existing ILanguageModelsService visibility methods to the extension host; no new storage or behavior is needed since src/vs/workbench/contrib/chat/common/languageModels.ts:658-690 already implements the full internal surface. This issue is also the verified canonical for the now-closed duplicate #314971 (BYOK 'hidden by default' use case), so consolidate that discussion here.
