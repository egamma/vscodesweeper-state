## Summary

Valid feature request for a new extension API to expose model visibility (hide/show) state from the internal ILanguageModelsService. The internal service already supports these methods, but no extension API or proposal exists yet. No duplicates found. Keeping open for the team to evaluate whether this internal surface should be exposed to extensions.

## Change summary

Expose model visibility (hide/show) APIs in the vscode.lm namespace so extensions can programmatically read and write which models appear in the chat model picker.

## Best solution

The team should evaluate whether the internal ILanguageModelsService visibility methods (isModelHidden, setModelHidden, isGroupHidden, setGroupHidden, getHiddenModelIds, onDidChangeModelVisibility) warrant a proposed extension API in `src/vscode-dts/`. The use cases (BYOK providers, workspace onboarding, custom model management UIs) are reasonable but niche. If approved, this would be a thin bridge from the extension host to the existing main-thread service — no new storage or behavior needed. Route to the `api-proposal` and `chat-lm-management` area owners for a design decision.
