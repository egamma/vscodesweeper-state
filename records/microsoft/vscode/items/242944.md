# Issue #242944 — Command-Enter for "Replace all" does not work for "Replace in selection"

[https://github.com/microsoft/vscode/issues/242944](https://github.com/microsoft/vscode/issues/242944)

## Summary

Keep open: the discussion confirms a focus-dependent shortcut failure, and current main still restricts Command-Enter to the replacement input. The existing editor-find routing is appropriate; selecting text is not itself shown to be the cause.

## Change summary

Command-Enter fails to invoke Replace All outside the replacement input, although clicking Replace All succeeds.

## Best solution

Make the editor find widget's advertised Replace All shortcut consistent with the contexts where it works. Resolve the focus-dependent behavior without changing the selected replacement scope or inserting unintended newlines into multiline search inputs.
