# Issue #242944 — Command-Enter for "Replace all" does not work for "Replace in selection"

[https://github.com/microsoft/vscode/issues/242944](https://github.com/microsoft/vscode/issues/242944)

## Summary

The Cmd+Enter shortcut for Replace All on Mac is intentionally scoped to fire only when the replace input field is focused (CONTEXT_REPLACE_INPUT_FOCUSED), to avoid conflicts with other Cmd+Enter bindings. The universal Replace All shortcut Cmd+Alt+Enter works regardless of focus within the find widget. This is as-designed.

## Change summary

On macOS, pressing Cmd+Enter to Replace All does nothing unless the replace input field is focused.

## Best solution

Close as designed — the Mac-specific Cmd+Enter shortcut deliberately requires replace-input focus to avoid keybinding conflicts. Users can use Cmd+Alt+Enter (the cross-platform Replace All shortcut) from any focus position, or focus the replace input first.

  > Thanks for the report. The `Cmd+Enter` shortcut for Replace All on Mac is intentionally scoped to work only when the **replace input field** is focused — this avoids conflicts with other `Cmd+Enter` bindings elsewhere in the editor.
  > 
  > Two alternatives:
  > 1. **Use `Cmd+Alt+Enter`** — this is the cross-platform Replace All shortcut and works regardless of which field is focused.
  > 2. **Focus the replace input first** — pressing `Cmd+Alt+F` (or your find/replace shortcut) when the find widget is already open moves focus to the replace input, after which `Cmd+Enter` works.
  > 
  > Closing this as the current behavior is by design.
