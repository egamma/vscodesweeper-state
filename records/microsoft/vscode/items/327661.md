# Issue #327661 — Option to not open the git repo.

[https://github.com/microsoft/vscode/issues/327661](https://github.com/microsoft/vscode/issues/327661)

## Summary

Keep open for the Backlog Candidates process. Dismissing the notification already declines once, but an explicit transient “No” action remains a valid UX improvement distinct from the persistent “Never” setting.

## Change summary

Add a “No” button that declines opening parent Git repositories for the current prompt without changing the persistent setting.

## Best solution

Add a localized “No” action to `Model.showParentRepositoryNotification` in `extensions/git/src/model.ts`; selecting it should dismiss the current notification without opening repositories or updating `git.openRepositoryInParentFolders`.
