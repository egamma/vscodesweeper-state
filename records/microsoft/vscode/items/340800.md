# Issue #340800 — Clickable links for extension-contributed/built-in MCP servers don't work in Agents Window

[https://github.com/microsoft/vscode/issues/340800](https://github.com/microsoft/vscode/issues/340800)

## Summary

Thanks for the report. The MCP list builds an 'Extension: …' / 'Built-in: …' source link that calls extensionsWorkbenchService.open(...), and that has no usable target in the Agents Window. This needs a decision on what the link should do there.

## Change summary

In the Agents Window, the source link on extension-contributed or built-in MCP list items tries to open an extension details view that isn't available there.

## Best solution

Make the source link in the MCP list widget non-interactive (plain label) when the Extensions view can't be opened, or point it at something the Agents Window can show. Separately, decide whether the derived github-mcp-server row should be its own list item.
