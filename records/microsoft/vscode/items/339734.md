# Issue #339734 — Updating with `/plugin update` when no newer version is available doesn't say so

[https://github.com/microsoft/vscode/issues/339734](https://github.com/microsoft/vscode/issues/339734)

## Summary

Confirmed in source: the `/plugin update` handler always prints 'Updated plugin X' regardless of whether a newer version actually existed, even though the SDK's `update` result already carries `previousVersion`/`newVersion` to detect that. A small, well-bounded messaging fix remains open.

## Change summary

Running `/plugin update <plugin>` when the plugin is already at the latest version reports it was updated instead of saying no update was needed.

## Best solution

In the `update` case of copilotCustomizationCommandDisplay.ts, compare `result.previousVersion` and `result.newVersion`; when they match, return a message like 'Plugin {0} is already up to date (version {1}).' instead of the unconditional 'Updated plugin' text.
