# Issue #339734 — Updating with `/plugin update` when no newer version is available doesn't say so

[https://github.com/microsoft/vscode/issues/339734](https://github.com/microsoft/vscode/issues/339734)

## Summary

Confirmed in source: the `/plugin update <plugin>` handler always reports 'Updated plugin X' and never checks whether the SDK's update result actually changed the version, so a no-op update is reported the same as a real one. This is a small, bounded fix.

## Change summary

`/plugin update <plugin>` always says the plugin was updated, even when it was already at the latest version.

## Best solution

In copilotCustomizationCommandDisplay.ts's 'update' case, compare `result.previousVersion` to `result.newVersion` (or check for an absent `newVersion`) and emit a distinct 'already up to date' message when no version change occurred, leaving the existing 'Updated plugin {0}. Updated version: {1}.' message for real updates.
