## Summary

This is a team-authored API design tracking issue. The proposed API exists and is in use, but has not been finalized — open design questions remain (extending beyond notebooks, per issue #204031 and community feedback). Keeping open as the API is still marked proposed.

## Change summary

Provide a finalized extension API for notebook kernels to report variable values to a built-in variable viewer.

## Best solution

Finalize the `notebookVariableProvider` proposed API after resolving whether variable providers should extend beyond notebook controllers (tracked in https://github.com/microsoft/vscode/issues/204031). The API shape in `src/vscode-dts/vscode.proposed.notebookVariableProvider.d.ts` is stable and in production use by the Jupyter extension.
