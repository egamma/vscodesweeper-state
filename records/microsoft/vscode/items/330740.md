# Issue #330740 — xtensionsAutoProfiler teardown silently destroys V8 block coverage in the extension host (V8ProfilerAgentImpl::disable() calls stopPreciseCoverage() unconditionally)

[https://github.com/microsoft/vscode/issues/330740](https://github.com/microsoft/vscode/issues/330740)

## Summary

Well-documented, reproduced bug: ExtensionsAutoProfiler attaches an inspector session to the extension host on unresponsiveness, and its teardown calls V8's stopPreciseCoverage(), silently discarding block-granularity coverage from any other active inspector session (e.g. a test run's coverage collector). A fix is already proposed in an open PR that references this issue, so it should be reviewed/landed rather than treated as unaddressed.

## Change summary

ExtensionsAutoProfiler's teardown unconditionally disables precise V8 coverage isolate-wide, corrupting block coverage collected by extension test runs.

## Best solution

Land (or iterate on) the open PR https://github.com/microsoft/vscode/pull/330752, which skips registering ExtensionsAutoProfiler when `extensionTestsLocationURI` is present (in src/vs/workbench/contrib/extensions/electron-browser/extensionsAutoProfiler.ts), preserving coverage sessions started by the test harness's own inspector connection.
