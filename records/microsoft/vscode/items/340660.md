# Issue #340660 — Start Debugging (▶) button gives no feedback at the point of interaction while a session is starting/running

[https://github.com/microsoft/vscode/issues/340660](https://github.com/microsoft/vscode/issues/340660)

## Summary

Thanks for the detailed report. This is a UX request for the Run and Debug view's start button to reflect session state. The source was not traced and no existing setting or canonical issue was verified, so it stays open for maintainer triage and community upvotes.

## Change summary

Make the Start Debugging (▶) button in the Run and Debug view show starting, active or stop state while a session launches or runs.

## Best solution

Have the debug view's start action reflect session state, for example a spinner while the session launches and a Stop or Restart affordance while one is active. A maintainer should confirm the design, and the debug area owners should decide whether the existing docked toolbar setting is enough.
