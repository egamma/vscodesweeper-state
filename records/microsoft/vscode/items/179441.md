# Issue #179441 — SCM - Tab refresh on every keypress on editor

[https://github.com/microsoft/vscode/issues/179441](https://github.com/microsoft/vscode/issues/179441)

## Summary

Keep open: current source still re-queries quick diff providers after editor changes, and the original caching fix was explicitly reverted. The maintainer-proposed direction is provider-driven invalidation, which needs API design rather than another unconditional cache.

## Change summary

Avoid repeated quick diff original-resource queries while typing without leaving diff bases stale after repository changes.

## Best solution

Develop the maintainer-proposed provider invalidation contract across the SCM API and quick diff model, retaining compatible behavior for existing providers. Reduce redundant remote queries while preserving correct gutter diffs after commits, branch changes, and other base changes.
