# Issue #236999 — Inconsistency between “window.zoomLevel” and Minimap size

[https://github.com/microsoft/vscode/issues/236999](https://github.com/microsoft/vscode/issues/236999)

## Summary

Still open and valid: alexdima confirmed the root cause (a pixelRatio >= 2 threshold at line 2749 of editorOptions.ts causing a discontinuous jump in minimap scale) and suggested allowing scale values >3 (currently clamped at 3 on line 3564). No PR has been submitted yet. Keeping open.

## Change summary

Minimap size changes drastically with tiny zoom level adjustments due to a hard pixelRatio >= 2 threshold in the minimap scale calculation.

## Best solution

Allow `editor.minimap.scale` values above 3 (currently clamped to [1,3] at editorOptions.ts:3564) so that on HiDPI monitors the doubled scale at pixelRatio >= 2 (line 2749) doesn't cap out, giving users finer control. alexdima invited a community PR for this.
