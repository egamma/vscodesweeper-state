# Issue #236999 — Inconsistency between “window.zoomLevel” and Minimap size

[https://github.com/microsoft/vscode/issues/236999](https://github.com/microsoft/vscode/issues/236999)

## Summary

The discontinuous minimap resize is confirmed in the current source: automatic minimap scaling switches abruptly between scale 1 and the configured scale when the effective pixel ratio crosses 2. A maintainer has identified the same cause and suggested allowing explicit scale values above 3, so the issue should remain open for a bounded editor-minimap fix.

## Change summary

Avoid a drastic minimap size change when a tiny negative window zoom adjustment moves the effective pixel ratio below the HiDPI threshold.

## Best solution

Preserve proportional control of minimap size across display and window zoom levels, following the maintainer's suggested direction of permitting larger explicit `editor.minimap.scale` values while retaining the automatic HiDPI behavior.
