# Issue #269587 — Terminal menu would benefit from separators

[https://github.com/microsoft/vscode/issues/269587](https://github.com/microsoft/vscode/issues/269587)

## Summary

The terminal overflow menu still places execution and dictation actions in the same group. Current toolbar infrastructure supports separate groups without losing visibility toggles, so the requested polish remains actionable.

## Change summary

Separate unrelated terminal menu actions into meaningful groups while preserving the ability to show dictation actions in the toolbar.

## Best solution

Give the terminal view's overflow menu meaningful separators between execution and dictation actions, preserving hidden-by-default behavior and right-click visibility controls. Use the existing grouped-primary-action support rather than changing toolbar behavior globally.
