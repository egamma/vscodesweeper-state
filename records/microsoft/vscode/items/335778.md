# Issue #335778 — Agents Window PRs: Unclear when PR opens in-product vs in-browser

[https://github.com/microsoft/vscode/issues/335778](https://github.com/microsoft/vscode/issues/335778)

## Summary

The session hover still bypasses contributed PR openers, unlike the existing Open Pull Request action. Keep this scheduled, team-authored issue open: the maintainer confirmed that hover links should also open in-product, and milestone 1.143.0 independently bars a close proposal.

## Change summary

Make PR links in the Agents Window session hover honor in-product PR opening consistently with other PR entry points.

## Best solution

Session-hover PR links should participate in the existing contributed-opener behavior, allowing GHPR to open supported PRs in-product while retaining browser fallback. Preserve existing opener preferences rather than introducing a separate hover-specific destination prompt.
