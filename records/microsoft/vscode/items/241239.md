# Issue #241239 — GitHub - "Open on GitHub" does not show for github private repo remote with auth params

[https://github.com/microsoft/vscode/issues/241239](https://github.com/microsoft/vscode/issues/241239)

## Summary

Still reproduces on main: the `getRepositoryFromUrl` regex in the GitHub extension does not account for credentials in the remote URL, so URLs like `https://USERNAME:PAT@github.com/owner/repo.git` fail to match and the "Open on GitHub" action disappears.

## Change summary

The "Open on GitHub" action in the Source Control Graph disappears after restart when the git remote URL contains embedded auth credentials (USERNAME:PAT@).

## Best solution

Update the HTTPS regex in `getRepositoryFromUrl` (extensions/github/src/util.ts) to optionally match a userinfo segment before `github.com` — e.g. `^https:\/\/(?:[^@]+@)?github\.com\/…`. The same fix should propagate to `repositoryHasGitHubRemote` and `getRepositoryDefaultRemoteUrl` which both call `getRepositoryFromUrl`.
