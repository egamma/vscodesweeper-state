# Issue #241239 — GitHub - "Open on GitHub" does not show for github private repo remote with auth params

[https://github.com/microsoft/vscode/issues/241239](https://github.com/microsoft/vscode/issues/241239)

## Summary

The credential-bearing HTTPS remote is still rejected by the built-in GitHub URL parser on current main, suppressing the graph hover action. Keep this accepted bug open; no verified canonical or open fixing PR was found.

## Change summary

Keep the Source Control Graph's Open on GitHub action available after reloading a repository whose HTTPS origin URL includes username and PAT userinfo.

## Best solution

The built-in GitHub integration should recognize credential-bearing github.com HTTPS remotes and open the corresponding credential-free commit page, while preserving existing remote selection and supported URL behavior.
