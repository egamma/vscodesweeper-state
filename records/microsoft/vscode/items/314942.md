# Issue #314942 — Saving of jupyter notebook with large outputs fails

[https://github.com/microsoft/vscode/issues/314942](https://github.com/microsoft/vscode/issues/314942)

## Summary

The failure remains traceable on current main, and an open PR explicitly fixes this issue. Keep it open while that implementation is reviewed.

## Change summary

Saving notebooks with sufficiently large outputs fails because ipynb serialization constructs one notebook-sized JavaScript string.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/319880, which changes the ipynb save paths to encode independently serialized chunks without first constructing a full notebook-sized string.
