# Issue #272827 — Chat response: fold multiple changes in a file into one pill

[https://github.com/microsoft/vscode/issues/272827](https://github.com/microsoft/vscode/issues/272827)

## Summary

Keep open: current source still creates individual edit pills, while existing collapsed groups and turn summaries do not consolidate repeated edits into one pill per file. A maintainer supported aggregation in the discussion; its presentation and grouping boundary need a design decision.

## Change summary

Consolidate repeated changes to the same file in a chat response into a single file pill.

## Best solution

Provide a compact per-file representation of repeated edits without losing access to individual changes or their ordering. Agree how that representation interacts with intervening response text and undo stops before implementing it in the chat response renderer.
