# Issue #159664 — Treat any `en-*` dialect as default

[https://github.com/microsoft/vscode/issues/159664](https://github.com/microsoft/vscode/issues/159664)

## Summary

Already implemented: current main treats any `en-*` locale as the default fast path, exactly as requested, via a commit distinct from the one a prior review cited and had refuted.

## Change summary

Requested that any `en-GB`/`en-*` dialect skip the language-pack lookup and take the fast default-locale path like plain `en`, to avoid a ~15-20ms startup waterfall.

## Best solution

Keep the current `userLocale.startsWith('en')` fast path in src/vs/base/node/nls.ts — it already covers the requested behavior for every `en-*` dialect.
