Keep open: the repeated crashes and allocation profile warrant investigating the Agents window's background file search. Current source has bounded Sessions telemetry searches but still permits unbounded search-result accumulation elsewhere; the supplied steps suffice to retest, although the initiating caller remains unidentified.
