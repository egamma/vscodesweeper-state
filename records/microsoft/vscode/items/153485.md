# Issue #153485 — Show both selection and semantic occurrences in the scrollbar

[https://github.com/microsoft/vscode/issues/153485](https://github.com/microsoft/vscode/issues/153485)

## Summary

The requested capability remains absent on current main: selection markers are deliberately suppressed whenever semantic highlights exist. Keep this Backlog request open for an editor UX decision and classify it as under discussion.

## Change summary

Show textual selection occurrences and semantic symbol occurrences simultaneously in the editor overview ruler, using distinguishable colors.

## Best solution

Decide whether both marker sets can coexist without excessive overview-ruler noise, then update the word-highlighter decoration policy in `src/vs/editor/contrib/wordHighlighter/browser/highlightDecorations.ts`; the existing separate selection and semantic color tokens already provide differentiation.
