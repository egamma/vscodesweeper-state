# Issue #283331 — Add API to detect if primary sidebar, secondary sidebar and panel regions are visible

[https://github.com/microsoft/vscode/issues/283331](https://github.com/microsoft/vscode/issues/283331)

## Summary

The public API still lacks visibility state for all three workbench regions, and this accepted request has 25 community upvotes. A newer report covers the same gap and has an open API proposal, but it cannot replace this older, previously reviewed issue as the duplicate canonical.

## Change summary

Expose primary sidebar, secondary sidebar, and panel visibility so extensions can restore the user's layout after temporarily maximizing their interface.

## Best solution

Provide a supported, window-scoped API for reading region visibility and observing changes, without requiring extensions to inspect internal storage. Review https://github.com/microsoft/vscode/pull/321414 as the existing proposal and consolidate the newer report's design discussion with this older request.
