# Issue #325219 — Agents window: make out-of-workspace agent changes clearer in the Changes panel (2 prototypes + user study)

[https://github.com/microsoft/vscode/issues/325219](https://github.com/microsoft/vscode/issues/325219)

## Summary

Keep open: current Changes list/tree modes do not provide the dedicated outside-workspace section recommended by the study. This team-authored request has a concrete product recommendation, and no verified canonical issue or issue-referencing fix was found.

## Change summary

Show out-of-workspace agent edits separately from committable workspace changes, grouped by containing folder by default, while retaining the enriched-list alternative.

Deliver the study-backed outside-workspace section in the Sessions Changes surface, using grouped locations by default and preserving an alternative list presentation. Keep purpose hints and additional action affordances as non-blocking follow-ups.
