# Issue #336235 — Copilot Chat: “InstantiationService has been disposed” thrown from PromptRenderer.render during long sessions

[https://github.com/microsoft/vscode/issues/336235](https://github.com/microsoft/vscode/issues/336235)

## Summary

Confirmed on main: PromptRenderer.render calls `this._instantiationService.dispose()` after `await super.render(...)` but not in a `finally`, so a throw or race during the async tree walk can leave the hydrated child disposed mid-render or skip disposal — matching the reported `_throwIfDisposed → async .render` crash signature. An open PR already targets this exact fix, so it should be reviewed/landed rather than treated as a fresh work item.

## Change summary

Extension host crashes with "InstantiationService has been disposed" from PromptRenderer.render during long, heavy Copilot Chat sessions.

## Best solution

Land (or iterate on) https://github.com/microsoft/vscode/pull/336236, which wraps the hydrated InstantiationService dispose in a finally/guard in extensions/copilot/src/extension/prompts/node/base/promptRenderer.ts so an exception or cancellation during `super.render` can't skip disposal or leave a disposed child touched by a later call.
