# Issue #344222 — Custom agents: open tool hover retains diagnostic for the pre-completion namespace prefix

[https://github.com/microsoft/vscode/issues/344222](https://github.com/microsoft/vscode/issues/344222)

## Summary

The current editor hover retains a snapshot of diagnostic content without observing subsequent marker changes, matching the reported stale-prefix display. Keep this open to refresh an already-visible hover when validation removes the obsolete diagnostic.

## Change summary

An open custom-agent tool hover should drop the incomplete-prefix diagnostic after completion and validation, without requiring dismissal and reopening.

## Best solution

Make visible editor hover diagnostics reflect current markers while retaining valid tool documentation and keyboard focus. Address the hover presentation lifecycle rather than weakening tool validation or changing canonical tool identifiers.
