## Summary

The request for a modifier+click gesture to step into a specific debug target is still unimplemented on main. The existing StepIntoTargetsAction uses cursor position or a context menu picker, but no mouse-click+modifier binding exists. Keeping open as a valid debug UX improvement from a team member.
