# Issue #293310 — Terminal command edits are silently ignored when using Claude Agent SDK (works correctly with regular Copilot)

[https://github.com/microsoft/vscode/issues/293310](https://github.com/microsoft/vscode/issues/293310)

## Summary

Still reproduces on main: the agent host confirmation dispatch never populates `editedToolInput` — the protocol field exists but VS Code doesn't wire the user's edits into it, so agent-host-backed sessions silently ignore terminal command edits.

## Change summary

Terminal command edits by the user are silently discarded when running through the agent host path (Claude Agent SDK and other AHP harnesses), while the regular Copilot tool-execution path correctly reads `userEdited`.

## Best solution

In `agentHostSessionHandler.ts` around line 1712, when dispatching `ChatToolCallConfirmed` for terminal tool calls, read `toolSpecificData.commandLine.userEdited` from the invocation and forward it as `editedToolInput` on the `ChatToolCallApprovedAction`. The protocol already defines this field (`ChatToolCallApprovedAction.editedToolInput` in `channels-chat/actions.ts:219`); it just needs to be populated by the client.
