# Issue #293310 — Terminal command edits are silently ignored when using Claude Agent SDK (works correctly with regular Copilot)

[https://github.com/microsoft/vscode/issues/293310](https://github.com/microsoft/vscode/issues/293310)

## Summary

Keep open: the earlier fix preceded the reopen, and current Claude approval handling still cannot apply command edits. Current Agent Host confirmation UI prevents edits rather than restoring the requested steering behavior, so the original symptom is mitigated but the central capability remains missing.

## Change summary

Honor user-edited terminal commands in Claude Agent SDK sessions and make the executed command and its output available to the agent.

## Best solution

Restore end-to-end command-edit handling for Claude confirmations, with the approved command matching what executes and what the agent observes. Preserve read-only confirmation behavior on paths that cannot apply edits until that contract is supported.
