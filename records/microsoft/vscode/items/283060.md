# Issue #283060 — Cant output markdown correctly

[https://github.com/microsoft/vscode/issues/283060](https://github.com/microsoft/vscode/issues/283060)

## Summary

The screenshot shows a reproducible nested-fence failure: an inner triple-backtick code block terminates the outer block intended to display literal Markdown, causing the remainder to render as formatted Markdown. The issue is already correctly routed to chat/chat-response and carries an accepted bug classification, so it should remain open.

## Change summary

Chat cannot reliably present a generated Markdown document as literal text when that document contains fenced code blocks.

## Best solution

Make the chat response path reliably preserve literal Markdown containing nested code fences, either by producing a sufficiently long outer fence or by providing an explicit raw-Markdown presentation/copy path that does not depend on model-selected delimiters.
