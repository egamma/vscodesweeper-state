# Issue #335798 — session counter changes to a dot, and doesn't seem to come back

[https://github.com/microsoft/vscode/issues/335798](https://github.com/microsoft/vscode/issues/335798)

## Summary

Team-authored bug report (author is a COLLABORATOR) filed 3 days ago with a screenshot from direct testing of the new session-count indicator; no fix has landed that references this issue, so per the hard keep-open rule for team-authored items this stays open pending investigation.

## Change summary

The Agents Window session-attention counter/badge collapses to a generic dot when a session completes, and sometimes fails to come back to showing the correct count after the window regains and loses focus.

## Best solution

Investigate the interaction between the numeric badge computed in src/vs/sessions/contrib/sessions/electron-browser/sessionsApplicationBadge.ts (derived `_count` over sessions needing attention) and the transient attention-dot mechanism in src/vs/platform/windows/electron-main/windowImpl.ts's DockBadgeManager (acquireBadge/setCount/update), which is supposed to let a numeric count always win over the generic dot from FocusMode.Notify (see src/vs/sessions/contrib/sessions/browser/sessionsWindowNotifier.ts). A race where the dot's attention set updates before the session badge's derived count recomputes (or fails to clear/recompute on focus) looks like the likely cause of the count getting stuck as a dot.
