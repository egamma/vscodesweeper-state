# Issue #283683 — Find widget doesn't reveal its zone

[https://github.com/microsoft/vscode/issues/283683](https://github.com/microsoft/vscode/issues/283683)

## Summary

Still open on main — the find widget's view zone reveal logic in `_showViewZone` doesn't account for the inline chat zone widget already occupying space at the top of the editor, so the find zone is inserted but not scrolled into view.

## Change summary

When triggering the find widget while inline chat is active at line 1, the find widget's view zone is inserted but not revealed/scrolled into view.

## Best solution

The find widget's `_showViewZone` / `_reveal` logic in `src/vs/editor/contrib/find/browser/findWidget.ts` needs to account for existing view zones (like inline chat's zone widget) when computing scroll adjustment. The scroll adjustment currently only considers the find widget's own height and editor padding, not other active view zones that may be above the viewport.
