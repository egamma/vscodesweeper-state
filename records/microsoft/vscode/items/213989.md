# Issue #213989 — Bad multi cursor paste behaviour

[https://github.com/microsoft/vscode/issues/213989](https://github.com/microsoft/vscode/issues/213989)

## Summary

Keep open for the default-behavior discussion: the reporter clarified that they want full-text paste by default, not an explanation of the existing setting. Current source still defaults to spread, and no verified older open canonical owns this request.

## Change summary

Make multicursor paste repeat the full clipboard text by default instead of distributing lines when their count matches the selection count.

## Best solution

Have the editor owner decide whether full-text paste should become the default while preserving an explicit way to distribute lines. The existing editor.multiCursorPaste setting already provides the reporter's preferred behavior per user, but does not settle the requested default change.
