# Issue #340854 — Modern UI: Hovered tab width is not stable with `tabSizing` is `"fixed"` or `"shrink"` and `tabActionReserveSpace` is `false`

[https://github.com/microsoft/vscode/issues/340854](https://github.com/microsoft/vscode/issues/340854)

## Summary

Thanks for the report. This is a fresh, specific regression report from a recent Modern UI change; the setting exists on main, and a related report (#340848) was filed with it. It stays open and should be handled by the tabs owners.

## Change summary

Hovering a clean, unpinned tab changes its width when tabSizing is fixed/shrink and tabActionReserveSpace is false.

## Best solution

Make the hover-revealed close action not change tab width when tabSizing is fixed/shrink (e.g. overlay it instead of reflowing), in the tab CSS controlled by the tab-actions-reserve-space class; consider handling together with https://github.com/microsoft/vscode/issues/340848.
