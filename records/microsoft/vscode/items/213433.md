# Issue #213433 — Add enum to let users tune find in cell selection behavior

[https://github.com/microsoft/vscode/issues/213433](https://github.com/microsoft/vscode/issues/213433)

## Summary

Team-authored feature request for a notebook-level `autoFindInCellSelection` enum setting (mirroring `editor.find.autoFindInSelection`). The underlying find-in-cell-selection feature shipped via PR #213409, but the user-configurable enum to tune when it activates automatically has not been implemented on main.

## Change summary

Add a configuration enum to let users control when notebook find-in-cell-selection activates automatically (never/always/multiline), mirroring the editor's `autoFindInSelection` setting.

## Best solution

Register a `notebook.find.autoFindInCellSelection` enum setting (never/always/multiline) in the notebook contribution, and wire it into the find widget's auto-activation logic in `src/vs/workbench/contrib/notebook/browser/contrib/find/notebookFindReplaceWidget.ts` where cell selection is currently checked unconditionally.
