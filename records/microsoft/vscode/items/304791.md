# Issue #304791 — Unwanted new default themes without consent

[https://github.com/microsoft/vscode/issues/304791](https://github.com/microsoft/vscode/issues/304791)

## Summary

This should stay open as community feedback on a broadly visible default-theme migration: the old Dark Modern theme remains available, but the central request is about not changing existing users' theme choice on update, and it has substantial community traction.

## Change summary

Avoid automatically switching existing users to newly introduced default themes, or provide an opt-out/legacy default path.

## Best solution

Workbench/theme owners should decide whether future default-theme migrations need an explicit migration guard, prompt, release-note guidance, or a stable legacy-default option while preserving the existing ability to choose `Dark Modern`.
