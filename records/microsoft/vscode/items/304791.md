# Issue #304791 — Unwanted new default themes without consent

[https://github.com/microsoft/vscode/issues/304791](https://github.com/microsoft/vscode/issues/304791)

## Summary

Keep open: Dark Modern remains available, and current main offers a one-time rollback notification, but it still applies the new default before asking. The request for consent before changing an established theme remains distinct and has substantial community support.

## Change summary

Preserve an existing user's familiar default theme across updates unless they agree to adopt a replacement.

## Best solution

Settle the upgrade policy for users following the default theme: preserve their previous appearance until they explicitly accept a replacement, while allowing new installations to use the new default. Retain the existing Dark Modern selection and avoid changing unrelated syntax-color or rendering behavior.
