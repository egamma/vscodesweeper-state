# Issue #283762 — VSCode loses connection with remote after "Developer: Restart Extension Host"

[https://github.com/microsoft/vscode/issues/283762](https://github.com/microsoft/vscode/issues/283762)

## Summary

Confirmed and acknowledged by a team member: 'Restart Extension Host' stops all extension hosts including the one managing the remote connection, immediately breaking the session. The issue remains unfixed on main — the action still calls stopExtensionHosts/startExtensionHosts without any remote-aware guard. A maintainer suggested redirecting to 'Reload Window' in remote mode, which is a reasonable fix direction.

## Change summary

Running 'Developer: Restart Extension Host' while connected to a remote kills the remote connection because the local extension host managing it is stopped.

## Best solution

Guard the RestartExtensionHostAction (in src/vs/workbench/services/extensions/electron-browser/nativeExtensionService.ts) to detect a remote session and either redirect to 'Reload Window' or skip stopping the extension host that owns the remote connection. The area label `remote-connection` is already correct.
