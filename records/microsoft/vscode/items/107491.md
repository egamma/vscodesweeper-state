# Issue #107491 — Selecting 2 color values and changing them both with color picker

[https://github.com/microsoft/vscode/issues/107491](https://github.com/microsoft/vscode/issues/107491)

## Summary

Keep open: the hover color picker still edits only the hovered occurrence, although the standalone picker now supports multiple selections. The earlier duplicate decision was explicitly withdrawn, and the proposed implementation was closed without merging.

## Change summary
