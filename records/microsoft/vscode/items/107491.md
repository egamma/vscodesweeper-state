# Issue #107491 — Selecting 2 color values and changing them both with color picker

[https://github.com/microsoft/vscode/issues/107491](https://github.com/microsoft/vscode/issues/107491)

## Summary

Still a valid, unimplemented feature request. The hover color picker only updates a single color range — the multi-cursor support recently added for the standalone color picker (issue #180918) was not extended to the hover color picker. The issue carries `help wanted` and `On Deck`, and remains actionable.

## Change summary

When multiple identical color values are selected, the hover color picker should update all of them simultaneously, not just the one being hovered.

## Best solution

Extend `HoverColorPickerParticipant.renderHoverParts` to detect other selections matching the hovered color value and pass their ranges as `insertionRanges` to `updateEditorModel`, similar to how the standalone color picker handles multi-cursor insertion. The infrastructure (`insertionRanges` parameter in `updateEditorModel`) already exists.
