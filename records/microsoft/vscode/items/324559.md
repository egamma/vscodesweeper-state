# Issue #324559 — terminal tool rendering bug - wrapped text pushes status code out of view

[https://github.com/microsoft/vscode/issues/324559](https://github.com/microsoft/vscode/issues/324559)

## Summary

Team-filed rendering bug in the chat terminal tool progress part: when command text wraps or overflows, the exit-status decoration is pushed out of view and the container cannot scroll to reveal it. The collapsed-row CSS enforces `white-space: nowrap` and `overflow: hidden` with `text-overflow: ellipsis`, but there appears to be no mechanism to keep the status decoration visible when the command label is long. No fix commit references this issue.

## Change summary

In the chat terminal tool card, long or wrapped command text pushes the exit-status code decoration out of the visible area, with no way to scroll to it.

## Best solution

Fix the flex layout in `chatTerminalToolProgressPart.css` / `.chat-terminal-command-block` so the decoration element (`.chat-terminal-command-decoration` / `.terminal-command-decoration`) is always visible — likely by ensuring `flex-shrink: 0` on the decoration and letting the command text truncate rather than pushing the decoration offscreen. The fix lives in `src/vs/workbench/contrib/chat/browser/widget/chatContentParts/media/chatTerminalToolProgressPart.css` and possibly the TS file that builds the DOM.
