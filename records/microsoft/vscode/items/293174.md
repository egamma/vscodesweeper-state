# Issue #293174 — Add a currently typing state to sessions view

[https://github.com/microsoft/vscode/issues/293174](https://github.com/microsoft/vscode/issues/293174)

## Summary

Keep open: the sessions list still lacks an indicator for unsent text in an existing conversation. This team-authored Backlog request remains distinct from draft-preservation bugs and agent attention indicators.

## Change summary

Identify sessions containing unsent chat text so users can resume composing after switching conversations.

## Best solution

Expose an accessible, session-specific draft indicator in the sessions list that persists while the user switches conversations and disappears when the text is sent or cleared. Decide how it coexists with existing working, attention, and unread indicators before implementation.
