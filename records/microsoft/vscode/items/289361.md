# Issue #289361 — A little lighter color tone for comparision files

[https://github.com/microsoft/vscode/issues/289361](https://github.com/microsoft/vscode/issues/289361)

## Summary

Softer comparison highlighting is already supported through theme color customization. Propose closing with the exact settings needed to reduce the intensity without changing colors for every theme and user.

## Change summary

Use less intense red and green highlighting when comparing files.

## Best solution

Use workbench.colorCustomizations to soften both changed-line and changed-text backgrounds while retaining recognizable insertion and deletion colors. The existing theme-level mechanism covers this preference without adding another setting or imposing a universal palette.

- **Proposed comment:**

  > Thanks for the request. Comparison highlight colors follow your theme and can already be softened with `workbench.colorCustomizations`. For example, add this to your user settings JSON to reduce the intensity of both line and text highlights:
  > 
  > ```json
  > "workbench.colorCustomizations": {
  >   "diffEditor.insertedLineBackground": "#9BB95514",
  >   "diffEditor.removedLineBackground": "#FF000014",
  >   "diffEditor.insertedTextBackground": "#9BB95526",
  >   "diffEditor.removedTextBackground": "#FF000026"
  > }
  > ```
  > 
  > The final two hex digits control opacity; smaller values make the highlights subtler. This lets you choose comfortable colors for your theme without changing the palette for everyone.
