# Issue #314769 — PowerShell in Integrated  Terminal: Ctrl+Spacebar not working when shell integration is disabled

[https://github.com/microsoft/vscode/issues/314769](https://github.com/microsoft/vscode/issues/314769)

## Summary

The reported no-op has a concrete path in current source: terminal IntelliSense captures Ctrl+Space even without the shell-integration capability it requires, then returns without doing anything. Keep this open; the keyboard-layout misencoding described in the workaround is related but does not establish a duplicate of the primary symptom.

## Change summary

Disabling shell integration prevents Ctrl+Space from reaching PowerShell's native MenuComplete handler while terminal suggestions remain enabled.

## Best solution

Terminal IntelliSense should not consume Ctrl+Space when it cannot service the request, leaving the keystroke available to the shell. Preserve working IntelliSense and investigate native PowerShell key encoding separately if completion still fails after interception is removed.
