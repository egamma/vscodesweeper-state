# Issue #314769 — PowerShell in Integrated  Terminal: Ctrl+Spacebar not working when shell integration is disabled

[https://github.com/microsoft/vscode/issues/314769](https://github.com/microsoft/vscode/issues/314769)

## Summary

Still reproduces on main: the terminal suggest TriggerSuggest keybinding (Ctrl+Space) is registered with a `when` clause that only checks `config.terminal.integrated.suggest.enabled` (default `true`) but does NOT check whether shell integration is enabled. When shell integration is off, the keybinding still fires, consumes the keystroke, but cannot produce completions — so Ctrl+Space never reaches PowerShell's PSReadLine MenuComplete.

## Change summary

Ctrl+Space does nothing in the integrated terminal with PowerShell when shell integration is disabled, because the terminal suggest keybinding intercepts it even though suggest cannot function without shell integration.

## Best solution

Add `TerminalContextKeys.terminalShellIntegrationEnabled` (or an equivalent 'suggest can actually work' guard) to the `when` clause of the `TriggerSuggest` keybinding in `terminal.suggest.contribution.ts` (line ~438), so that when shell integration is off, Ctrl+Space falls through to the shell. The sendSequence keybindings already gate on shell integration correctly; this is the suggest keybinding that's missing the guard.
