# Issue #295100 — Feature Request: Visual indicator for language-specific setting overrides

[https://github.com/microsoft/vscode/issues/295100](https://github.com/microsoft/vscode/issues/295100)

## Summary

Confirmed on main: the scope-overrides indicator uses an if/else-if chain, so when a setting shows 'Applies to all profiles' it eclipses the language-override indicator. An open PR (#295102) already addresses this.

## Change summary

Settings GUI fails to show language-specific override indicator when the 'Applies to all profiles' indicator is displayed for the same setting.

## Best solution

Land the fix in PR https://github.com/microsoft/vscode/pull/295102, which separates the 'Applies to all profiles' indicator from the scope-overrides indicator so both can coexist.
