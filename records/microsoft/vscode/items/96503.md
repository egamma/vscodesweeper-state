# Issue #96503 — Custom editor autosave menubar state not updated properly

## Summary

Several partial fixes landed in 2020 (6cc7c45, 03cbe60, 9721b4a) addressing autosave data loss and revert-disabled issues for custom editors, but the auto save menu checkmark state bug was last confirmed still reproducing by a team member in Oct 2021. No subsequent fix commit addresses the remaining menu-state issue. The `help wanted` label signals it's accepted work awaiting a contributor.

## Change summary

The File → Auto Save menu checkmark doesn't update visually when toggling auto save while a custom editor is focused.

## Best solution

The remaining defect is likely in how the menu's `toggled` state (`config.files.autoSave` context key) is evaluated or refreshed when a custom editor has focus. A fix would ensure the configuration-based context key update triggers a menu re-render regardless of active editor type. The `help wanted` label is appropriate — a contributor could investigate the menu refresh path in `src/vs/workbench/contrib/files/browser/fileActions.contribution.ts` and the menu bar rendering logic.
