# Issue #341595 — Agents window: mode/permissions picker can't be clicked with the mouse due to sensitiveEditLocations config ping-pong between clients

[https://github.com/microsoft/vscode/issues/341595](https://github.com/microsoft/vscode/issues/341595)

## Summary

Keep open: current main filters unrelated-session updates in the three picker listeners, but still contains the configuration feedback loop that breaks the affected session's mouse interaction. This team-authored report is not fully resolved by the narrower UI mitigation.

## Change summary

Conflicting client settings continuously overwrite a shared session's sensitiveEditLocations, causing configuration churn and lost mouse clicks on composer controls.

## Best solution

Make remote configuration updates converge without clients repeatedly reasserting conflicting local settings, while preserving initial settings propagation and deliberate local updates. Keep composer controls stable when configuration updates do not change their displayed state.
