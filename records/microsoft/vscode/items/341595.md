# Issue #341595 — Agents window: mode/permissions picker can't be clicked with the mouse due to sensitiveEditLocations config ping-pong between clients

[https://github.com/microsoft/vscode/issues/341595](https://github.com/microsoft/vscode/issues/341595)

## Summary

Thanks for the detailed diagnosis. The code on main still matches it: `_seedRunningConfigFromState` calls `_syncSensitiveEditLocations` after every host state update, so two clients with different settings would overwrite each other's value indefinitely.

## Change summary

Two clients with different agent/hook file location settings cause a sensitiveEditLocations config ping-pong, which keeps re-rendering the mode picker so mouse clicks are lost.

## Best solution

Sync sensitiveEditLocations only on the first seed, on a local settings change, and before sending a request. Also skip the DOM rebuild in the mode picker trigger when nothing has changed.
