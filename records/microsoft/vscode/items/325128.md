# Issue #325128 — AutoPilot mode for agent with handoffs results in infinite loop

[https://github.com/microsoft/vscode/issues/325128](https://github.com/microsoft/vscode/issues/325128)

## Summary

The infinite loop remains source-reproducible on current main: Autopilot automatically executes the first `send` handoff after every completed response, including a handoff back to the same custom agent, with no cycle guard.

## Change summary

Prevent Autopilot from repeatedly executing a custom agent's self-targeting auto-send handoff.

## Best solution

Stop self-targeting or cyclic auto-send handoffs from recursively submitting new requests while preserving automatic handoffs between distinct agents.
