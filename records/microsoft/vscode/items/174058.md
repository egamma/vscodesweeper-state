# Issue #174058 — Rendered whitespace characters non-uniform

[https://github.com/microsoft/vscode/issues/174058](https://github.com/microsoft/vscode/issues/174058)

## Summary

This was a well-confirmed Windows regression at negative zoom levels, but current behavior cannot be established from source alone because SVG antialiasing depends on Chromium, display scaling, and zoom. A recent renderer refactor preserved the same fractional marker geometry rather than explicitly fixing this issue, so current-build confirmation is needed.

## Change summary

SVG-rendered whitespace dots have visibly inconsistent brightness on Windows at negative window zoom levels.

## Best solution

Confirm the original settings on a current Windows build at 100% and 125% display scaling. If the dots remain uneven, investigate pixel alignment or another antialiasing-stable representation in the editor whitespace overlay while preserving the SVG renderer's performance characteristics.
