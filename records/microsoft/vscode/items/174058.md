# Issue #174058 — Rendered whitespace characters non-uniform

[https://github.com/microsoft/vscode/issues/174058](https://github.com/microsoft/vscode/issues/174058)

## Summary

Still reproduces on main: the SVG-based whitespace rendering (`editor.experimentalWhitespaceRendering: 'svg'`, the default) draws circles at fractional pixel coordinates that produce non-uniform anti-aliasing/dithering at negative zoom levels on Windows. No fix has landed.

## Change summary

Rendered whitespace dots appear with varying brightness (dithered) at negative zoom levels due to sub-pixel positioning in the SVG rendering path.

## Best solution

Either round the SVG circle coordinates to align with the device pixel grid at the current zoom level, or apply `shape-rendering: crispEdges` / `shape-rendering: geometricPrecision` to the SVG to avoid sub-pixel anti-aliasing artifacts. The fix belongs in `src/vs/editor/browser/viewParts/whitespace/whitespace.ts` around line 219 where the `<circle>` elements are generated. Alternatively, snap the radius to whole device pixels using `window.devicePixelRatio`.
