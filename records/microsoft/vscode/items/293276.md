# Issue #293276 — Skills: Scoped tool permissions (auto-approve tools declared by a skill)

[https://github.com/microsoft/vscode/issues/293276](https://github.com/microsoft/vscode/issues/293276)

## Summary

Keep open: the inspected skill-loading and confirmation paths do not provide skill-lifetime tool approval. This team-authored request also raises an explicit trust-boundary concern, so permission semantics need human review rather than a cleanup close.

## Change summary

Allow trusted skills to request narrowly scoped tool auto-approval that expires when the skill finishes and respects user and administrator restrictions.

## Best solution

Define a user-authorized, runtime-enforced permission contract for skills, including activation and expiry, revocation, and precedence of trust and administrator restrictions. Treat extension-owned auxiliary-file reads as a related use case, not a substitute for the broader skill-scoped capability.
