# Issue #293276 — Skills: Scoped tool permissions (auto-approve tools declared by a skill)

[https://github.com/microsoft/vscode/issues/293276](https://github.com/microsoft/vscode/issues/293276)

## Summary

Valid feature request from a team member. Skill-scoped tool auto-approval is not implemented on main — the `allowed-tools` field exists only as passthrough metadata (inside `metadata:` maps) with no wired auto-approval behavior. The `skillAttributes` schema does not include an `allowed-tools` attribute, and the tool confirmation pipeline has no skill-scoped bypass logic. Stays open.

## Change summary

Allow skills to declare tools that are auto-approved for the duration of that skill's execution, reducing confirmation friction for trusted workflows.

## Best solution

Add an `allowed-tools` (or similar) frontmatter field to the skill attributes schema in `promptFileAttributes.ts`, then wire it into the tool confirmation pipeline in `languageModelToolsService.ts` so that tools listed in a skill's frontmatter are auto-approved only while that skill is active. The scoping, workspace-trust gating, and user-override design considerations in the issue are sound starting points.
