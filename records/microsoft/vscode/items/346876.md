# Issue #346876 — explorer.excludeGitIgnore: workspace root folder is hidden when its name matches an unanchored pattern in its own .gitignore

## Summary

The reported root-disappearance path remains present in current main: loading the root's .gitignore allows its own basename to exclude it. Keep this actionable report open; the supplied reproduction is sufficient.

## Change summary

With explorer.excludeGitIgnore enabled, expanding a workspace root hides it when its own .gitignore contains an unanchored pattern matching its name.

## Best solution

Keep workspace roots visible when loading their own ignore rules, while preserving exclusion of matching descendants and existing files.exclude exception behavior. Cover the asynchronous ignore-file loading and subsequent root refilter in the Explorer filter tests.
