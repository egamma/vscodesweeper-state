# Issue #125093 — Trust: dialogs should listen to changes

[https://github.com/microsoft/vscode/issues/125093](https://github.com/microsoft/vscode/issues/125093)

## Summary

Still reproduces on main: the trust dialogs in WorkspaceTrustRequestHandler show via dialogService.prompt() but never subscribe to onDidChangeTrust to auto-dismiss when trust state changes externally (e.g., from another window trusting the same parent folder).

## Change summary

When a workspace trust dialog is open and trust is granted from another window, the dialog should auto-dismiss rather than remaining open and potentially reverting the trust decision.

## Best solution

In WorkspaceTrustRequestHandler.registerListeners(), each dialog (workspace trust request, open files trust request, resources trust request) should subscribe to workspaceTrustManagementService.onDidChangeTrust and programmatically dismiss the dialog when trust becomes granted. The dialogService would need to expose a dismiss/close handle, or a racing pattern (e.g., Promise.race with an event-to-promise on onDidChangeTrust) could be used.
