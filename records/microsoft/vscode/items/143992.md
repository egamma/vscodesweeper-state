## Summary

Keep open: the report describes a concrete Zscaler login-redirect flow that blocks extension images, and those steps suffice to retest in the affected network. Networking and browser surfaces have evolved since 2022, but current source does not establish that this cookie-based authentication flow is resolved.

## Change summary

Extension images fail to load when a corporate Zscaler proxy requires interactive web login and a session cookie.

## Best solution

Establish how the Zscaler redirect and authentication cookie interact with the workbench image-loading session, then determine a supported authentication flow for that session. Preserve the distinction between browser-based portal authentication and ordinary HTTP proxy credential challenges.
