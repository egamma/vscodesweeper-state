# Issue #316160 — [Agents App] Sub-session (plus button) creates confusion — expected new session, got nested conversation

[https://github.com/microsoft/vscode/issues/316160](https://github.com/microsoft/vscode/issues/316160)

## Summary

Valid UX feedback from a usability study: the plus button in the Agents window creates a sub-session within the current session, but users expected a new independent session. The request to visually differentiate these actions and show sub-session hierarchy is actionable and relates to active Agents window development. Not a duplicate of #312259, which tracks sub-session implementation for Claude rather than the UX confusion itself.

## Change summary

The plus button in the Agents window title bar creates a sub-session inside the current session, confusing users who expect it to create a new independent session.

## Best solution

Visually differentiate the 'new sub-session' action from 'new independent session' in the Agents window titlebar, and surface sub-session hierarchy in the sessions list so users can navigate between parent and child sessions. The UX for `NewChatInSessionWidget` (src/vs/sessions/contrib/chat/browser/newChatInSessionWidget.ts) and the sessions list (src/vs/sessions/contrib/sessions/browser/views/sessionsList.ts) are the likely areas to update.
