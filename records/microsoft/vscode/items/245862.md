# Issue #245862 — When using the command to cycle through completions, indicate if there are no alternatives

[https://github.com/microsoft/vscode/issues/245862](https://github.com/microsoft/vscode/issues/245862)

## Summary

Keep open: keyboard cycling still lacks explicit feedback when there are no alternative inline completions. The existing toolbar exposes the suggestion count, but its default hover-only presentation does not cover the keyboard-only request.

## Change summary

Indicate when Show Next or Show Previous Inline Suggestion cannot offer an alternative.

## Best solution

Provide lightweight, accessible feedback after an explicit cycling request finds no alternatives, within the editor inline-completions command flow. Preserve normal cycling and avoid notifications during automatically triggered suggestions.
