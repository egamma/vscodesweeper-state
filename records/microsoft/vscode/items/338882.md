## Summary

Team-authored bug filed hours ago by dbaeumer describing PATH not being forwarded correctly into the Agent Host / Copilot harness when using fnm to manage Node versions; the shell-env resolution code exists but no diagnosis of why it diverges from the terminal/local-harness path has been done yet, so this stays open pending investigation.

## Change summary

Commands run via the Copilot harness in the Agent Host sometimes fail because PATH (managed by fnm) isn't correctly forwarded/available, unlike in a same-window terminal or the local harness.

## Best solution
