# Issue #133843 — Toggle Line Comment can produce invalid block comment in JSX and CSS (should use single-line comments instead)

[https://github.com/microsoft/vscode/issues/133843](https://github.com/microsoft/vscode/issues/133843)

## Summary

Valid feature request for smarter block comment toggling in languages without line comments (JSX, CSS, HTML). No fix has landed on main; the comment contrib has no nested/escaped comment handling. Stays open in the Backlog.

## Change summary

Toggle Line Comment produces invalid nested block comments in JSX/CSS/HTML because these languages lack single-line comment tokens and the command doesn't handle nesting.

## Best solution

Implement escape-aware or per-line block comment wrapping in `src/vs/editor/contrib/comment/browser/blockCommentCommand.ts` so that toggling comments in languages without line-comment tokens handles pre-existing block comments gracefully (escaping or per-line wrapping).
