# Issue #315844 — `New file` save dialog in agents window doesn't update path for

[https://github.com/microsoft/vscode/issues/315844](https://github.com/microsoft/vscode/issues/315844)

## Summary

The bug remains source-reproducible on current main: switching sessions replaces the active workspace folders, but save-path resolution still prefers the most recent file from global editor history, which can belong to the previous session.

## Change summary

Default a new file's save dialog to the active Agents Window session instead of the previously visited session.

## Best solution

Make save-path selection in the Agents Window reject history entries outside the active session workspace and fall back to that workspace's current root, while preserving the normal workbench behavior for files opened outside a workspace.
