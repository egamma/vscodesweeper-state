# Issue #301582 — create_file tool corrupts file content for Go files

[https://github.com/microsoft/vscode/issues/301582](https://github.com/microsoft/vscode/issues/301582)

## Summary

The reported corruption path has been removed from current main: `create_file` now submits the complete file as one text edit instead of emitting separate edits for every line. The concrete fix landed after this report, so the issue can be closed as completed.

## Change summary

Creating larger Go files could produce duplicated, reordered, or otherwise corrupted content even though the tool input was correct.
