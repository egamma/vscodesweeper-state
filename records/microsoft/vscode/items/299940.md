# Issue #299940 — Integrated terminal never reflects updated PATH/env; previous issues closed as not planned / not reproducible

[https://github.com/microsoft/vscode/issues/299940](https://github.com/microsoft/vscode/issues/299940)

## Summary

Keep open for consideration of an explicit environment-refresh capability. The linked implementation PR remains open, and existing terminal relaunch behavior does not provide the requested in-place refresh across sessions.

## Change summary

Provide an explicit action to refresh PATH and environment variables in existing integrated terminal sessions without restarting terminals or the window.

## Best solution

Review https://github.com/microsoft/vscode/pull/299941 against a defined cross-platform refresh contract before deciding whether to land it. Any accepted behavior should preserve session-specific environment customizations and avoid injecting commands into running applications.
