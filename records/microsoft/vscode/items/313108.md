# Issue #313108 — Agents: Provide a way to group completed sessions by workspace

[https://github.com/microsoft/vscode/issues/313108](https://github.com/microsoft/vscode/issues/313108)

## Summary

Completed sessions still bypass workspace grouping and appear in one final Done/Archived section. Keep this team-authored Backlog request open: the existing grouping command does not cover it, and related discovery reports do not establish a duplicate canonical for this specific request.

## Change summary

Provide workspace-based organization for completed sessions so users can find them without remembering session titles.

## Best solution

Extend the Agents Window sessions list presentation so completed sessions can be browsed by workspace while respecting archive visibility. Decide whether this belongs inside the Done section or alongside ongoing sessions in workspace sections before implementation.
