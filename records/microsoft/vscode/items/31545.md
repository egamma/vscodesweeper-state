# Issue #31545 — Change all occurrences in a single 100MB line leads to a crash when autosave on

[https://github.com/microsoft/vscode/issues/31545](https://github.com/microsoft/vscode/issues/31545)

## Summary

The autosave memory-pressure cause was addressed by streaming large-file snapshots instead of materializing the entire document as one string. The fix shipped in 1.20.0, so disabling autosave for large files is no longer necessary.

## Change summary

Avoid crashing when autosave follows multi-cursor edits in a 100 MB single-line file, potentially by suppressing autosave for large files.

## Best solution

Keep the shipped streaming save path from commit 59e50838af197ba7c3a38f7a9386255d079f336f; it addresses the underlying large-file save allocation without selectively disabling autosave.
