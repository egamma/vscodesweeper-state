# Issue #333695 — All models say "Contact your admin"

[https://github.com/microsoft/vscode/issues/333695](https://github.com/microsoft/vscode/issues/333695)

## Summary

Keep open as an upstream-backed model-availability gap: a maintainer confirmed that an empty server model list is currently interpreted as organization policy disablement, producing the misleading “Contact your admin” state.

## Change summary

A transient empty model-list response caused every organizational Copilot model to appear administrator-disabled until the model-management flow refreshed the state.

## Best solution

Obtain an upstream response that distinguishes policy-disabled models from transient empty or failed model-list requests, then consume that distinction in VS Code so transient failures show an accurate retryable state rather than administrator guidance.
