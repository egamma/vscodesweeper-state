# Issue #45368 — Emmet completions disappear when using bem in the presence of other snippets

[https://github.com/microsoft/vscode/issues/45368](https://github.com/microsoft/vscode/issues/45368)

## Summary

Kept open. This is a Backlog-milestone bug confirmed by a maintainer, and I have no new fix commit to cite. The earlier fix citation was refuted and I did not re-check the code, so the case stays open. The cause is the completion-provider caching behavior (#13735), and the Emmet helper may need to return a 'bem' item earlier.

## Change summary

Emmet completions such as 'bem' vanish while typing when another extension's snippets match the earlier characters, because VS Code does not re-query a provider that already returned 0 results for the current word.

## Best solution

Fix it in the completion stack so a provider that returned zero results is re-queried as the word grows (https://github.com/microsoft/vscode/issues/13735). Alternatively, have vscode-emmet-helper return the full abbreviation as a completion item earlier. Ctrl+Space remains the workaround.
