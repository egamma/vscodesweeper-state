# Issue #45368 — Emmet completions disappear when using bem in the presence of other snippets

[https://github.com/microsoft/vscode/issues/45368](https://github.com/microsoft/vscode/issues/45368)

## Summary

Fixed on main: the emmet completion provider marks its CompletionList as incomplete, ensuring the suggest model re-queries emmet on every keystroke even when it previously returned 0 results — directly addressing the reported BEM scenario.

## Change summary

Emmet completions disappear when typing BEM syntax (e.g. `abc|bem`) because VS Code stops re-querying providers that returned 0 results.

## Best solution

Keep the shipped fix (isIncomplete: true in emmet's CompletionList); no further change needed. The suggest model re-queries emmet on every keystroke, so BEM abbreviations are now offered even after intermediate empty-result states.
