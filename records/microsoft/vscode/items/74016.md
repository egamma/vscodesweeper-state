# Issue #74016 — Expose vscode remote reconnecting UI.

[https://github.com/microsoft/vscode/issues/74016](https://github.com/microsoft/vscode/issues/74016)

## Summary

A 5-year-old feature request with zero upvotes and a negative signal from a team contributor on the core ask (letting extensions block the UI). No reconnecting-UI extension API exists on current main. Stays open for the community process, but unlikely to gain traction given the pushback.

## Change summary

Expose the VS Code remote reconnecting UI as an extension API so extensions like LiveShare can block the UI during network reconnection.

## Best solution

If this ever advances, the API should NOT allow arbitrary UI blocking (per jrieken's feedback). A more viable path would be a narrower API that signals a degraded-connection state to the workbench without fully blocking user interaction. However, with zero community demand and explicit team pushback, this is a natural candidate for the community-driven stale-close process.
