# Issue #324996 — `list.find` doesn't match by file's directory path in reference view

[https://github.com/microsoft/vscode/issues/324996](https://github.com/microsoft/vscode/issues/324996)

## Summary

The directory displayed for each file is not included in the References tree's list.find representation on current main. Keep this open while the linked human-authored PR is reviewed and narrowed to avoid changing matching behavior across unrelated tree views.

## Change summary

Allow list.find in the References view to distinguish same-named files by matching their displayed directory paths.

## Best solution

Revise and review https://github.com/microsoft/vscode/pull/325016 so path matching is scoped to the References tree, unless maintainers explicitly choose broader tree-widget semantics.
