# Issue #334236 — Persist hidden chat state when reopening a session in an editor window

[https://github.com/microsoft/vscode/issues/334236](https://github.com/microsoft/vscode/issues/334236)

## Summary

The defect remains on current main: every session handoff unconditionally reopens Chat, overriding the hidden state. Keep the issue open while the directly linked fix in https://github.com/microsoft/vscode/pull/337442 is reviewed.

## Change summary

Reopening an Agents session in an existing editor window should preserve the user's choice to hide the Chat view.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/337442, which preserves window-local hidden Chat state while retaining first-open, visible-widget, missing-widget, and retry behavior.
