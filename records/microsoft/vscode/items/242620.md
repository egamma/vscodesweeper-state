# Issue #242620 — Git - keyboard shortcut of `git.stage` can't add unstaged image files to staged area

[https://github.com/microsoft/vscode/issues/242620](https://github.com/microsoft/vscode/issues/242620)

## Summary

Still reproduces on main: `getSCMResource()` falls back to `window.activeTextEditor` which is null for image/binary files, and also omits `untrackedGroup` from its search — both bugs are present in current code.

## Change summary

The `git.stage` command invoked via keyboard shortcut silently fails for image (binary) files because the fallback path cannot resolve non-text-editor resources.

## Best solution

Fix `getSCMResource()` in `extensions/git/src/commands.ts` to (1) also search `repository.untrackedGroup.resourceStates` alongside the other three groups (line ~5728), and (2) when no `activeTextEditor` is available, fall back to the SCM view's current selection/focus to obtain the resource URI. Related but distinct from https://github.com/microsoft/vscode/issues/207066 (focus loss after staging via shortcut).
