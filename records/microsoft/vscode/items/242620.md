# Issue #242620 — Git - keyboard shortcut of `git.stage` can't add unstaged image files to staged area

[https://github.com/microsoft/vscode/issues/242620](https://github.com/microsoft/vscode/issues/242620)

## Summary

The image-staging failure remains explainable directly from current source: argumentless git.stage cannot resolve the resource displayed in an image preview. Keep this separate from the SCM focus regression, whose maintainer explicitly requested a separate image-staging report.

## Change summary

A custom git.stage shortcut should stage a newly added image opened from the SCM view, as it does a text file.

## Best solution

Make argumentless Git staging resolve the active image resource without depending on a text editor, preserving existing explicit-resource, text-editor, and notebook behavior. Keep general SCM selection shortcuts and post-staging focus changes outside this fix.
