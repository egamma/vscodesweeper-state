# Issue #330016 — Chat sticky scroll: Want a way to get to list of all prompts

[https://github.com/microsoft/vscode/issues/330016](https://github.com/microsoft/vscode/issues/330016)

## Summary

Fresh, team-authored feature request filed while dogfooding the new chat sticky-scroll banner (a testing task itself just landed); it's a reasonable UX gap and the hard keep-open rule for team-authored issues applies regardless.

## Change summary

Add a way (e.g. a context menu or click action) to open a list of all prompts from the chat sticky-scroll banner, instead of only stepping one-at-a-time via the arrow buttons.

## Best solution

The Agents window's `sessions.chatTimeline.display: gutter` rail (src/vs/workbench/contrib/chat/browser/promptTimeline/) already offers a hoverable list of every prompt, but it's gated to `environmentService.isSessionsWindow` in PromptTimelineWidgetContrib._update(); extending an equivalent lightweight prompt-list affordance to the sticky header in the regular Chat window (where only the sticky banner is mounted) would close this gap without duplicating the rail UI.
