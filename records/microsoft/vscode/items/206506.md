# Issue #206506 — Add applied changes in diff editor to undo stack

[https://github.com/microsoft/vscode/issues/206506](https://github.com/microsoft/vscode/issues/206506)

## Summary

Individual diff-editor changes now have separate undo boundaries, addressing the reported all-at-once undo behavior. The concrete fix is retained on current main, so this can be closed as completed.

## Change summary

Make each change applied from the original file to the modified file in the diff editor individually undoable.

## Best solution

Keep the undo boundaries introduced by commit 02ebbd647de6ec4acebaf49d03e648127e45068e; they isolate individual revert operations from other reversions and manual edits.
