# Issue #187142 — Deprecate IRelaxedExtensionDescription.id

[https://github.com/microsoft/vscode/issues/187142](https://github.com/microsoft/vscode/issues/187142)

## Summary

This maintainer-authored cleanup remains incomplete on current main: `IRelaxedExtensionDescription.id` is still declared and populated alongside the case-insensitive `identifier`. Keep it open until maintainers decide whether to deprecate the field first or remove it directly.

## Change summary

Deprecate and eventually remove the redundant string `id` from `IRelaxedExtensionDescription`, and document the case-insensitive identity semantics of `identifier`.

## Best solution

Define the compatibility sequence for the optional `id` field, remove its remaining producers when safe, and document that `identifier` is the canonical extension identity used for case-insensitive comparison and indexing.
