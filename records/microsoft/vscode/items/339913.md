# Issue #339913 — Sticky function actions

[https://github.com/microsoft/vscode/issues/339913](https://github.com/microsoft/vscode/issues/339913)

## Summary

Fresh feature request (no upvotes/comments yet) asking for CodeLens-style actions (e.g. Rust's Run/Debug) to remain visible alongside sticky scroll lines. I confirmed the sticky scroll widget only renders raw view-model lines today and has no CodeLens/decoration integration, so this is a real, unimplemented gap rather than something already covered.

## Change summary

Let code actions/CodeLens (like a Rust function's Run/Debug buttons) stay visible in the sticky-scroll header instead of scrolling out of view, ideally behind a setting.

## Best solution

Design how CodeLens content could be surfaced in StickyScrollWidget (src/vs/editor/contrib/stickyScroll/browser/stickyScrollWidget.ts), likely gated by a new setting; this needs a maintainer decision on scope (all CodeLens vs. just the ones on the sticky line) before implementation.
