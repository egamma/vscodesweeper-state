# Issue #339913 — Sticky function actions

[https://github.com/microsoft/vscode/issues/339913](https://github.com/microsoft/vscode/issues/339913)

## Summary

Keep open as a feature request: Sticky Scroll currently preserves source lines, not the CodeLens actions above them. Existing settings and navigation commands do not cover the requested persistent Run/Debug controls, and no matching canonical was verified.

## Change summary

Optionally display a function's CodeLens actions above its sticky header so they remain clickable while scrolling through the function.

## Best solution

Consider editor-level support for CodeLens actions associated with sticky function headers, reusing extension-provided commands rather than adding Rust-specific behavior. Decide the opt-in behavior and layout before implementation.
