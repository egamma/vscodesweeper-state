# Issue #317379 — Agents: Act on feedback is broken (with data loss) when used in a CCA session

[https://github.com/microsoft/vscode/issues/317379](https://github.com/microsoft/vscode/issues/317379)

## Summary

The defect remains traceable on current main: Copilot Cloud follow-ups discard attached feedback references, while the feedback service hides the submitted comments after the request is accepted. The newer related issue reports feedback reaching the wrong fork and is not an eligible duplicate for this re-reviewed, older report.

## Change summary

Submitting inline feedback from a Copilot Coding Agent session sends `/act-on-feedback` without the comments and removes those comments from the editor.

## Best solution

Ensure Copilot Cloud follow-ups deliver the attached agent-feedback content to the remote task and retain recoverable feedback until that submission is accepted, without changing the established Agent Host feedback flow.
