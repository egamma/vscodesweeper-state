# Issue #74585 — Make `editor.gotoLocation.multiple: "goto"` state UX more discoverable 

[https://github.com/microsoft/vscode/issues/74585](https://github.com/microsoft/vscode/issues/74585)

## Summary

The symbol navigation state is still communicated only via `INotificationService.status()` (a transient status bar message) — the discoverability concern remains valid and unaddressed on current main.

## Change summary

When using the 'goto' mode for multiple definitions/references, the navigation state indicator in the status bar is not sufficiently discoverable.

## Best solution

Add an inline editor hint (e.g. a fading content widget or decoration near the cursor) that briefly shows the 'Symbol N of M, press F12 for next' message, complementing the status bar entry. The change would live in `src/vs/editor/contrib/gotoSymbol/browser/symbolNavigation.ts` around `_showMessage()`.
