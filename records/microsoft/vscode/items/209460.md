# Issue #209460 — Enable paste to create markdown link in scm input

[https://github.com/microsoft/vscode/issues/209460](https://github.com/microsoft/vscode/issues/209460)

## Summary

The requested capability remains missing: SCM input uses a language that the Markdown URL-paste provider does not target. The merged PR enabled paste infrastructure, not Markdown-link conversion; keep this accepted backlog request open alongside its unresolved language-configuration dependency.

## Change summary

Support creating Markdown links when URLs are pasted into the SCM commit-message input.

## Best solution

Make Markdown-link pasting available in SCM input with the existing Markdown paste preferences and plain-text alternative. First settle whether this requires an explicitly Markdown-configured input, coordinating with https://github.com/microsoft/vscode/issues/209475.
