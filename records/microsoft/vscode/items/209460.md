# Issue #209460 — Enable paste to create markdown link in scm input

[https://github.com/microsoft/vscode/issues/209460](https://github.com/microsoft/vscode/issues/209460)

## Summary

Still unimplemented on main. PR #209466 enabled the copy-paste API in the SCM input, but the markdown paste-URL-as-link behavior is only registered for markdown-family language IDs — the SCM input doesn't get it. The feature request remains valid.

## Change summary

Pasting a URL into the SCM commit input should automatically create a markdown-formatted link, like it does in markdown files.

## Best solution

Extend the markdown extension's paste-URL-as-link provider to also activate for the SCM input (e.g., by registering it for the SCM input's document selector or by having the git extension provide its own paste edit provider that creates markdown links). Depends on #209475 per the author's comment.
