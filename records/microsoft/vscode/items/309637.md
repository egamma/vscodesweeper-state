# Issue #309637 — Agents: Parallel back-ground tasks are executed sequential

[https://github.com/microsoft/vscode/issues/309637](https://github.com/microsoft/vscode/issues/309637)

## Summary

Keep open: another reporter independently confirmed sequential execution despite promised parallelism, and neither a verified duplicate nor a fixing commit covers this Agents-window report. The current SDK integration does not establish whether execution is serialized or the activity display only makes it appear so.

## Change summary

Independent subagents launched for parallel work in the Agents window appear to execute one after another, unlike the standalone CLI.

## Best solution

Establish overlapping execution from timestamped subagent events for the same prompt and model in the Agents window and standalone CLI. Correct any unintended serialization in the Copilot integration, or correct the activity presentation if execution already overlaps, while preserving permissions and legitimate concurrency limits.
