# Issue #169798 — When in debug REPL, tab key changes focus instead of indents

[https://github.com/microsoft/vscode/issues/169798](https://github.com/microsoft/vscode/issues/169798)

## Summary

Keep open for an accessibility and interaction decision: maintainers agreed the current Debug Console tab behavior could be improved consistently across SimpleEditorWidget inputs, but the desired keyboard contract remains unsettled.

## Change summary

Make Tab indent multiline Debug Console REPL input while retaining an accessible way to move focus out, and improve cursor/history navigation consistency with Chrome DevTools.

## Best solution

Define a shared SimpleEditorWidget keyboard contract that inserts indentation while editing multiline content, preserves keyboard focus escape, and lets arrow keys navigate within multiline input before recalling history; then adopt it in the Debug Console without changing full-editor Tab behavior.
