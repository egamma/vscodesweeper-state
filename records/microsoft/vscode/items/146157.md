# Issue #146157 — VSCode line sorting does not use custom sort order set in System Preferences

[https://github.com/microsoft/vscode/issues/146157](https://github.com/microsoft/vscode/issues/146157)

## Summary

Keep open in the Backlog: current main still provides no way for line sorting to honor a custom locale or macOS collation preference, and the request earned 23 community upvotes.

## Change summary

Make Sort Lines honor the operating system's custom collation order or a configurable VS Code sort locale.

## Best solution

Allow the line-sorting collator in `sortLinesCommand.ts` to use an explicitly resolved locale or collation preference, with a setting if the host runtime cannot expose the macOS choice.
