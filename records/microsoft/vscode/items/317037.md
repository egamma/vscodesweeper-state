# Issue #317037 — "Files changed" working set accumulates unrelated files and cannot be dismissed — persists across sessions

[https://github.com/microsoft/vscode/issues/317037](https://github.com/microsoft/vscode/issues/317037)

## Summary

Keep open: the report provides sufficient steps to retest incorrect changed-file attribution across fresh conversations. Current chat rendering supports multiple session backends and session-keyed persistence, but inspection did not establish that the reported accumulation is fixed or identify a canonical covering its full scope.

## Change summary

Agent-mode changed-file lists include unrelated files and retain them across restarts and new conversations without an apparent dismissal control.

## Best solution

Ensure the local Agent changed-file list belongs to the selected conversation and does not inherit unrelated entries in a fresh conversation. Preserve pending-review state when reopening the same conversation; investigate attribution separately from optional dismissal UX and differences from Git's working-tree count.
