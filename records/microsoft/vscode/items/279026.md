# Issue #279026 — Add drag-and-drop support for multiple files in the terminal

[https://github.com/microsoft/vscode/issues/279026](https://github.com/microsoft/vscode/issues/279026)

## Summary

Valid feature request with 20 upvotes, promoted to Backlog. The terminal drop handler on current main still only inserts a single path (`JSON.parse(rawResources)[0]`). An open community PR (#235672) exists but hasn't merged. Keeping open.

## Change summary

Dragging multiple files from the Explorer onto the terminal should insert all paths, not just the first one.

## Best solution

Review and land PR #235672 (or an equivalent fix) that iterates over all resources/files in the drop event and fires `_onDropFile` for each. The fix is localized to `TerminalInstanceDragAndDropController.onDrop` in `src/vs/workbench/contrib/terminal/browser/terminalInstance.ts`.
