# Issue #306680 — Built-in Source Control does not properly work with a worktree in WSL

[https://github.com/microsoft/vscode/issues/306680](https://github.com/microsoft/vscode/issues/306680)

## Summary

Repository detection may be failing because Windows Git cannot resolve the worktree's WSL-native gitdir path. Ask for the execution environment and Git output before deciding whether this is a built-in Git defect; neither a fix nor a matching duplicate is established.

## Change summary

Source Control fails to recognize a WSL-created worktree whose .git file points to repository metadata through /mnt/c.

## Best solution

Establish whether repository detection fails in a WSL-connected window using Linux Git or only in a local Windows window using Windows Git. Preserve support for valid worktrees and investigate the built-in Git discovery path if Git itself successfully resolves the repository in the same environment.
