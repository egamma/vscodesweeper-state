# Issue #203344 — New System commands to toggle collapse state

[https://github.com/microsoft/vscode/issues/203344](https://github.com/microsoft/vscode/issues/203344)

## Summary

A real capability gap remains on current main, and the request has been accepted into the Backlog with 27 community upvotes. Existing APIs can expand or hide a view, but cannot collapse it while preserving the webview.

## Change summary

Add commands or an API for programmatically collapsing and expanding a specific contributed view without hiding or disposing it.

## Best solution

Expose explicit collapse/expand operations through the views service and extension-facing commands or API, preserving the webview lifecycle and keeping visibility distinct from collapsed state.
