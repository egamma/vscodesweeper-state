# Issue #346871 — Opening a named pipe (FIFO) in the editor fails with “Unavailable (FileSystemError)” since 1.139

[https://github.com/microsoft/vscode/issues/346871](https://github.com/microsoft/vscode/issues/346871)

## Summary

Current source confirms that every FIFO is rejected before reading, including one with a writer and available content. Keep this open: the regression is actionable, but restoring reads must preserve the protection against stalled pipe operations.

## Change summary

Opening a writer-backed FIFO fails instead of displaying its contents.

## Best solution

Restore bounded reads of available FIFO content without reintroducing hangs for pipes without writers, while preserving regular-file behavior and rejection of other unsupported file types.
