# Issue #333204 — `Repository.setConfig()` in the built-in Git extension always uses `git config --add`, causing unbounded duplicate branch config entries

[https://github.com/microsoft/vscode/issues/333204](https://github.com/microsoft/vscode/issues/333204)

## Summary

Repeated setConfig calls still append duplicate and stale values on current main. Keep this shared built-in Git API defect open; neither the newer config-loss report nor the previously fixed merge-base issue resolves it.

## Change summary

Repeatedly setting branch metadata accumulates duplicate config entries instead of maintaining one current value.

## Best solution

Make the built-in Git Repository.setConfig operation maintain a single current value for the requested key, including replacing previously accumulated duplicates, without altering unrelated config entries. Cover the public API with regression checks for repeated writes and changed values.
