# Issue #178852 — [Extension Development] parsing exception in "when" clause should default to not showing corresponding entry

[https://github.com/microsoft/vscode/issues/178852](https://github.com/microsoft/vscode/issues/178852)

## Summary

The requested failure behavior is still missing: menu registration treats an unparsable when clause like an omitted clause, allowing the contribution to appear outside its intended context. Keep this team-authored, under-discussion request open; no fixing commit or qualifying duplicate was established.

## Change summary

Hide an extension-contributed menu entry when its explicit when clause cannot be parsed instead of making it unconditional.

## Best solution

Make invalid explicit menu conditions fail closed while preserving unconditional contributions that omit when and the behavior of valid expressions. Keep useful author-facing parsing diagnostics; correcting an extension's expression is a workaround, not coverage of the requested fallback.
