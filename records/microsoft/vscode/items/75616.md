# Issue #75616 — Make proxy settings machine scoped

[https://github.com/microsoft/vscode/issues/75616](https://github.com/microsoft/vscode/issues/75616)

## Summary

Keep open: current main supports separate local and remote proxy settings only when local proxy inheritance is disabled, while proxy settings remain application-scoped by default. This team-authored, under-discussion item therefore has neither been implemented exactly as requested nor superseded by a qualifying referenced fix.

## Change summary

Make HTTP proxy configuration machine-scoped so local and remote machines can use network-specific settings.

## Best solution

The proxy owners should decide whether separate machine-specific proxy configuration should become the default or whether the current application-scoped default with `http.useLocalProxyConfiguration` is the intended final behavior. Any resolution should preserve explicit local-versus-remote configuration for machines on different networks.
