# Issue #273696 — Enhance RTL Support for Arabic Language in VS Code Chat Interface

[https://github.com/microsoft/vscode/issues/273696](https://github.com/microsoft/vscode/issues/273696)

## Summary

Keep this open as the canonical chat-specific RTL request. Current main still lacks direction-aware chat input and Markdown rendering, and two open PRs are actively attempting the implementation.

## Change summary

Make chat prompts and rendered responses direction-aware for Arabic and other RTL languages while keeping code and technical literals left-to-right.

## Best solution

Review and land one coherent RTL implementation for chat input and rendered Markdown, preserving isolated LTR rendering for code. Resolve overlap between the focused chat change in https://github.com/microsoft/vscode/pull/312507 and the broader editor/chat design in https://github.com/microsoft/vscode/pull/314365 before closing this issue.
