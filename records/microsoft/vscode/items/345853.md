# Issue #345853 — Cannot select Anthropic BYOK models when Claude harness is selected

[https://github.com/microsoft/vscode/issues/345853](https://github.com/microsoft/vscode/issues/345853)

## Summary

Keep open as the maintainer-classified feature request: Claude-native credentials provide a workaround, but do not deliver reuse of keys configured through Model Providers. The request remains within its Backlog Candidates community-review period.

## Change summary

Make Anthropic models configured through Model Providers usable with the Claude harness, with clear guidance when its separate credential requirements are unmet.

## Best solution

Provide a coherent Anthropic credential-configuration experience across harnesses. Until shared configuration is supported, Claude's model picker and documentation should clearly explain its separate setup rather than imply that adding a Model Provider configures Claude.
