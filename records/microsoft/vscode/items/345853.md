# Issue #345853 — Cannot select Anthropic BYOK models when Claude harness is selected

[https://github.com/microsoft/vscode/issues/345853](https://github.com/microsoft/vscode/issues/345853)

## Summary

Claude supports BYOK, but its native SDK reads a separate credential configuration rather than the key added through VS Code's Model Provider window. Keep this open as a request to bridge that setup gap; the current native-key setup does not satisfy the specific request to reuse already-configured Anthropic models.

## Change summary

Make Anthropic models configured through VS Code's Model Provider window usable with the Claude harness without a Copilot subscription.

## Best solution

Decide whether the Claude harness should reuse VS Code-configured Anthropic credentials. At minimum, its setup experience should clearly distinguish native Claude authentication from Model Provider configuration instead of leaving users with an unexplained empty picker.
