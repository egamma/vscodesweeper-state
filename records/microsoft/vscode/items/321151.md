# Issue #321151 — Make extensions trusted publishers configurable, to optionally include Microsoft, GitHub and Open AI in delayed auto-update

[https://github.com/microsoft/vscode/issues/321151](https://github.com/microsoft/vscode/issues/321151)

## Summary

Keep this accepted feature request open: current source still exempts product-trusted publishers from delayed auto-updates without consulting a user-configurable exemption list. It has 32 upvotes, and the related issues do not own this specific remaining capability.

## Change summary

Allow users to configure which publishers bypass extension auto-update delays, including choosing no exempt publishers.

## Best solution

Provide an owner-reviewed configuration contract for auto-update publisher exemptions that permits an empty list while preserving current defaults. Keep delay exemptions distinct from installation publisher trust, and explicitly consider enterprise-policy enforcement.
