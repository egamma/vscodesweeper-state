## Summary

Keep open: current source still compiles MCP tool schemas with the default draft-07 AJV validator, and compilation failures return unvalidated arguments. The independent reproduction confirms this correctness defect, but does not substantiate the reported IDE crash or tool omission.

## Best solution

Track the alleged crash separately within this investigation until its exact schema and failing runtime path are established.
