# Issue #275529 — Enable option to set sort order of projects in "Window" menu

[https://github.com/microsoft/vscode/issues/275529](https://github.com/microsoft/vscode/issues/275529)

## Summary

This remains the canonical, accepted Backlog request for stable or configurable project ordering in the macOS Window menu. Current main exposes no independent ordering control, and the existing window-title customization is only a partial workaround.

## Change summary

Allow project windows in the Window menu to be sorted by project name or opening order instead of the active-file-dependent title.

## Best solution

Provide a stable project-oriented ordering in the macOS Window menu, ideally with a small choice of ordering modes, while preserving the current behavior as the compatibility default.

## Evidence

- **current implementation:** src/vs/platform/menubar/electron-main/menubar.ts creates the macOS Window menu with Electron's `window` role and appends only fixed actions; it contains no project-name or opening-order sorting option.
- **partial workaround:** The existing `window.title` setting in src/vs/workbench/browser/workbench.contribution.ts can place `${rootName}` before the active editor, but this changes the title globally and does not independently control menu order or support opening order.
