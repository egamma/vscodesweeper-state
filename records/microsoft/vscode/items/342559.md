# Issue #342559 — Copilot chat does not work on older Linux remotes any more

[https://github.com/microsoft/vscode/issues/342559](https://github.com/microsoft/vscode/issues/342559)

## Summary

Keep open for investigation of Copilot runtime startup with the older-Linux sysroot workaround. Current main still launches a separate native runtime without applying the server's custom-glibc handling; the supplied steps and loader error suffice to retest, although this explicitly unsupported environment was not executed.

## Change summary

Copilot chat fails on an Ubuntu 18.04 SSH remote because the bundled copilot-runtime requires GLIBC_2.28 despite the server running with a custom sysroot.

## Best solution

Determine whether Copilot's bundled runtime can honor the existing custom-sysroot workaround without broadening the supported Linux baseline. If that workaround is intentionally unavailable for Copilot, make that limitation explicit and provide an actionable startup diagnostic rather than leaving chat to fail unexpectedly.
