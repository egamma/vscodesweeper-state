# Issue #342559 — Copilot chat does not work on older Linux remotes any more

[https://github.com/microsoft/vscode/issues/342559](https://github.com/microsoft/vscode/issues/342559)

## Summary

Keep open to investigate Copilot runtime compatibility with older Linux remotes using a custom glibc sysroot. Current main still launches a separate native runtime outside the server Node patching path; the supplied steps and loader error suffice to retest, but the affected environment was not executed.

## Change summary

Copilot chat stopped starting on an Ubuntu 18.04 SSH remote because its bundled native runtime requires GLIBC_2.28.

## Best solution

Determine whether Copilot's native runtime can use the remote server's custom glibc environment, and restore startup for that configuration where supported. Resolve the compatibility boundary between server bootstrap and Copilot runtime packaging without treating this as a third-party extension issue.
