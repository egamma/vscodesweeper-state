# Issue #342559 — Copilot chat does not work on older Linux remotes any more

[https://github.com/microsoft/vscode/issues/342559](https://github.com/microsoft/vscode/issues/342559)

## Summary

Keep open for investigation of Copilot runtime compatibility with the documented older-Linux sysroot workaround. Current main still launches a separate native Copilot executable while the server workaround patches only Node; the supplied steps and loader error suffice to retest, but this environment-dependent failure was not executed.

## Change summary

Copilot chat stopped starting on an Ubuntu 18.04 SSH remote because its native runtime cannot load GLIBC_2.28 despite the server's custom-sysroot setup.

## Best solution

Establish whether Copilot's bundled runtime can honor the existing custom-sysroot arrangement, and make the compatibility boundary explicit. The investigation belongs in core Copilot runtime startup and server compatibility handling, not a Remote-SSH transfer or an extension-caused close.
