# Issue #227697 — LSP DocumentColor Refresh Request

[https://github.com/microsoft/vscode/issues/227697](https://github.com/microsoft/vscode/issues/227697)

## Summary

Still unimplemented on main: the DocumentColorProvider API has no refresh/onDidChange mechanism, and no workspace/documentColor/refresh support exists. Team-authored feature request that remains valid.

## Change summary

Add a workspace/documentColor/refresh request so LSP servers can trigger VS Code to re-request document colors without a text change.

## Best solution

Add an onDidChangeDocumentColors event to the DocumentColorProvider API (mirroring the pattern used by other LSP refresh requests like foldingRange refresh), wire it through the ext-host protocol, and support the workspace/documentColor/refresh LSP method. The color picker contribution (src/vs/editor/contrib/colorPicker/) and the ext-host language features (src/vs/workbench/api/common/extHostLanguageFeatures.ts, mainThreadLanguageFeatures.ts) are the likely implementation sites.
