Verified duplicate of the older, open Fedora 45 extension-installation failure report. Both discussions identify missing OpenSSL 3 compatibility libraries and the same successful workaround; this report adds useful verifier crash logs and ARM64 confirmation.

## Change summary

Extension installation fails on Fedora 45 because the bundled signature verifier aborts without the required OpenSSL 3 runtime.

Consolidate investigation in https://github.com/microsoft/vscode/issues/338194 and ensure Linux installations supply the signature verifier's required runtime without disabling verification. Preserve this report's x64 and ARM64 crash evidence in that investigation.
