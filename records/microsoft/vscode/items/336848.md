# Issue #336848 — Clarify which files can be imported as automations

[https://github.com/microsoft/vscode/issues/336848](https://github.com/microsoft/vscode/issues/336848)

## Summary

The file picker already filters to .automation.md, but the path-based picker still does not explain that requirement before selection. Keep open for the remaining discoverability fix; the existing filter is not evidence of a later resolution.

## Change summary

Make the supported *.automation.md file pattern clear when importing an automation.

## Best solution

Retain the existing filtered file picker and make the supported pattern visible before selection in both native and path-based dialogs, with the change scoped to the automation import presentation.
