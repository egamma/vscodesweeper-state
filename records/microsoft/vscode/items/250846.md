[https://github.com/microsoft/vscode/issues/250846](https://github.com/microsoft/vscode/issues/250846)

## Summary

This remains the canonical request for improving how NES presents complex multi-line edits. Current main still restricts the clearer word-replacement view to single-line changes, and no commit explicitly fixing this team-authored issue was found, so it should remain open.

## Change summary

Choose a clearer, more localized diff presentation for multi-line next edit suggestions instead of showing an opaque large replacement.

## Best solution

Define when a multi-line NES change should be decomposed into localized word replacements, then extend the inline-edit view-selection logic while retaining line-replacement or side-by-side rendering for changes where decomposition would be misleading.
