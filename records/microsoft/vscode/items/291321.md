# Issue #291321 — Test 3.2. fails -- both files are found

[https://github.com/microsoft/vscode/issues/291321](https://github.com/microsoft/vscode/issues/291321)

## Summary

Still reproduces on main: the sibling-clause (`when`) in glob exclude patterns does a case-sensitive lookup against an in-memory Set/map of directory entries, so on macOS/Windows (case-insensitive filesystems) the `$(basename).TS` pattern fails to match the actual `file.ts` sibling.

## Change summary

Search exclude sibling clause (`when`) ignores platform case-insensitivity, causing files not to be excluded when sibling exists with different casing.

## Best solution

Make the `hasSibling` lookup case-insensitive on case-insensitive platforms: lowercase both the stored sibling names and the query in `localFileSearch.ts` (the `sibilings` Set) and in `hasSiblingPromiseFn`/`hasSiblingFn` in `search.ts` (the property map). Gate this on the platform or a `caseSensitive` parameter propagated from the query options.
