# Issue #301941 — Cause `url.parse` deprecation warning on Node 24

[https://github.com/microsoft/vscode/issues/301941](https://github.com/microsoft/vscode/issues/301941)

## Summary

Still reproduces on main: all three cited files still use the deprecated `url.parse()` from the legacy Node `url` module. An open PR (#302334) exists but has not been merged. Keeping open — the fix PR needs review and landing.

## Change summary

Replace deprecated `url.parse()` calls with the WHATWG `URL` API to eliminate Node 24 deprecation warnings.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/302334, which substitutes `url.parse` with the WHATWG `URL` API in `src/vs/platform/request/node/requestService.ts`, `src/vs/platform/request/node/proxy.ts`, and `src/vs/server/node/server.cli.ts`. This is a forward-compat debt item for Node 24 readiness.
