## Change summary

Updating the remote tunnel service and local client can leave the host tunnel running while subsequent client connections fail with WebSocket 1006 or a version-mismatch error.

## Best solution

Investigate the remote-tunnel update lifecycle so client and service versions remain compatible during an update, or the client completes the required remote update before reconnecting. Preserve the exact-version handshake for genuinely incompatible installations while making this supported update sequence recover automatically.
