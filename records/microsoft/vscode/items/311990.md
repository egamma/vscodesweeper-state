# Issue #311990 — SCM inline toolbar actions leak between providers on template reuse

[https://github.com/microsoft/vscode/issues/311990](https://github.com/microsoft/vscode/issues/311990)

## Summary

The reported defect remains in current main: connecting an initially empty menu skips the callback, leaving the recycled resource toolbar populated with another provider's actions. Keep this open and classify it as a bug; the diagnosis is bounded and ready for implementation.

## Change summary

Recycled SCM resource rows retain another provider's inline actions when their own menu has no actions.

## Best solution

Ensure every new SCM menu connection synchronizes its consumer's actions initially, including empty menus, while preserving suppression of subsequent unchanged updates.
