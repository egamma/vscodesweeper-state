# Issue #344706 — Copilot LM API: Responses HTTP request ID is lost when the stream ends after reasoning

[https://github.com/microsoft/vscode/issues/344706](https://github.com/microsoft/vscode/issues/344706)

## Summary

The diagnostic correlation gap remains in current main: a reasoning event followed by graceful EOF produces no completion, leaving the final failure without the supplied HTTP request ID. Keep this open; the deterministic reproduction is sufficient to establish the defect independently of what interrupted the historical live request.

## Change summary

Preserve an available Responses HTTP request ID in the classified failure when streaming ends without a terminal completion.

## Best solution

Carry actual HTTP correlation through response processing independently of emitted completions, so incomplete-stream failures and their debug records retain it. Preserve the existing failure classification, terminal-event requirements, and transport-error behavior.
