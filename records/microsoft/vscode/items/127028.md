# Issue #127028 — Git - Adding a folder to `.gitignore` should not add every single file

[https://github.com/microsoft/vscode/issues/127028](https://github.com/microsoft/vscode/issues/127028)

## Summary

Still unfixed on main: the `git.ignore` command in the SCM view receives individual file URIs from the resource tree, and `repository.ignore()` writes each one verbatim to `.gitignore` with no folder-collapsing logic. An open community PR (#138111) exists but has not been reviewed or merged.

## Change summary

Right-clicking a folder in the SCM view and choosing 'Add to .gitignore' appends every individual file to `.gitignore` instead of a single folder path entry.

## Best solution

The `ignore()` method in `extensions/git/src/repository.ts` (or the command handler in `commands.ts`) needs logic to detect when all passed URIs share a common folder prefix and collapse them into a single folder entry (e.g. `node_modules/`). The open PR https://github.com/microsoft/vscode/pull/138111 attempts this — review it, request updates if needed, or use it as a starting point for a fresh implementation.
