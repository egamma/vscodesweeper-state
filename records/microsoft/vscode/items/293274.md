# Issue #293274 — Multi-select on worktrees in SCM -> delete only deletes one at a time, despite multi select

[https://github.com/microsoft/vscode/issues/293274](https://github.com/microsoft/vscode/issues/293274)

## Summary

Keep open: the current SCM repository context menu forwards selected worktrees, but the Git deletion command processes only the first. This team-authored report describes a remaining selection-handling defect, not a completed fix or verified duplicate.

## Change summary

Deleting multiple selected worktrees from SCM deletes only one instead of honoring the selection.

## Best solution

Make the built-in Git worktree deletion action honor the selected worktree repositories while retaining existing dirty-worktree confirmation and active-worktree safeguards. Keep palette deletion and unrelated repository commands unchanged.
