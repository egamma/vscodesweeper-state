# Issue #226068 — Git - VS Code doesn't show "Merge branch" commits in "Timeline" and shows incorrect diffs for subsequent commits

[https://github.com/microsoft/vscode/issues/226068](https://github.com/microsoft/vscode/issues/226068)

## Summary

Keep this as the canonical Git Timeline bug: current source retains the problematic history and comparison paths. The linked PR was closed without merging after its author reproduced the issue and found that topological ordering alone did not fix it.

## Change summary

Git Timeline omits a conflict-resolution merge commit and incorrectly attributes merged changes to the subsequent commit.

## Best solution

Make Timeline preserve relevant merge-resolution history and compare subsequent commits against the correct file revision while retaining history across renames. Establish the comparison semantics for merge entries before implementing; adding --topo-order alone is insufficient.
