# Issue #211288 — notebook progress accessibility signal refinement suggestions

[https://github.com/microsoft/vscode/issues/211288](https://github.com/microsoft/vscode/issues/211288)

## Summary

Team-authored feature request with multiple valid accessibility enhancement suggestions for notebook progress signals. None of the requested refinements (determinant vs. indeterminant differentiation, smart repeat frequency, focus-aware cues, progress source identification) appear implemented on current main.

## Change summary

Refine notebook progress accessibility signals to distinguish determinant/indeterminant progress, support smart repeat frequency, and allow disabling when unfocused.

## Best solution

Implement the suggested refinements in the accessibility signal scheduler: differentiate determinant vs. indeterminant progress with distinct audio cues, add configurable repeat frequency based on estimated duration, and consider focus-awareness. The work lives in src/vs/platform/accessibilitySignal/browser/progressAccessibilitySignalScheduler.ts and the notebook execution contribution.
