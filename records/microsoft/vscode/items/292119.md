# Issue #292119 — Add Option to Prevent Automatic Collapsing of Thinking Process in GitHub Copilot Chat Agent

[https://github.com/microsoft/vscode/issues/292119](https://github.com/microsoft/vscode/issues/292119)

## Summary

The requested option is now implemented on main: disabling `chat.agent.collapseCompletedResponses` prevents completed responses from folding intermediate reasoning and tool work into the “Completed N steps” disclosure.

## Change summary

Add a setting that keeps Copilot Chat's intermediate thinking and work visible after an agent response completes.

## Best solution

Use the shipped `chat.agent.collapseCompletedResponses` setting with value `false`; the completed-response renderer then leaves intermediate work visible instead of creating the automatic disclosure.
