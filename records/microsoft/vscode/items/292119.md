# Issue #292119 — Add Option to Prevent Automatic Collapsing of Thinking Process in GitHub Copilot Chat Agent

[https://github.com/microsoft/vscode/issues/292119](https://github.com/microsoft/vscode/issues/292119)

## Summary

Existing settings address completed-response folding and tool-chain expansion, but do not keep reasoning sections expanded. Keep this accepted request open to resolve that remaining gap; the reporter's thanks does not establish that it was fully satisfied.

## Change summary

Provide an option to keep agent reasoning expanded instead of automatically collapsing it.

## Best solution

Provide a supported presentation preference that preserves expanded reasoning after streaming finishes, alongside the existing completed-response and tool-detail controls. Preserve current compact defaults for users who do not opt in.
