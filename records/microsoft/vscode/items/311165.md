# Issue #311165 — Subject: Codex session handling in VS Code is broken and unacceptable

[https://github.com/microsoft/vscode/issues/311165](https://github.com/microsoft/vscode/issues/311165)

## Summary

Per-session deletion for Codex and other agent-host sessions is implemented on current main, including provider-backed disposal and removal from the session list. The reported all-or-nothing cleanup limitation can therefore be closed as completed.

## Change summary

Allow users to delete individual Codex sessions without removing unrelated chat history, while retaining separate archive and delete lifecycle controls.

## Best solution

Keep the provider-capability-based session lifecycle now implemented in commit 5bcfb040f4e28b4612fde0a77ec4dbc4f0dbd481: Codex sessions advertise deletion support, and the shared Sessions UI delegates deletion to the owning provider.
