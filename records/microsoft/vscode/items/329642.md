# Issue #329642 — Modern UI uses inconsistent theme colors

## Summary

Genuine, source-verified theming bug in the experimental Modern UI: at least one of the listed inconsistencies (panel section headers resolving `sideBarSectionHeader.border` before `panelSectionHeader.border`) still reproduces on main, and maintainers are actively chipping away at the rest (one item already fixed by a merged PR, another already tracked separately) — this should stay open and routed to the theming/workbench area rather than closed.

## Change summary

Several Modern UI surfaces (activity bar icons, top activity bar, side bar vs. panel backgrounds, panel section headers) apply theme color tokens inconsistently or use the wrong token for the surface they affect.

Have the workbench/theming owners work through the remaining bullet list against `src/vs/workbench/contrib/styleOverrides/browser/media/paneHeaders.css` (line 47, which prefers `--vscode-sideBarSectionHeader-border` even for panel headers) and the related activity-bar/side-bar CSS, fixing or reassigning each token to match its intended color-id semantics; fold in the already-tracked background item from https://github.com/microsoft/vscode/issues/327267 rather than duplicating it.
