# Issue #193521 — Keyboard shortcuts "get stuck" with invalid "when expressions"

[https://github.com/microsoft/vscode/issues/193521](https://github.com/microsoft/vscode/issues/193521)

## Summary

Still reproducible on main: invalid when expressions in keybindings.json cannot be matched by the keybindings editor because `ContextKeyExpr.deserialize()` returns undefined for unparseable expressions, causing `findUserKeybindingEntryIndex` to always return -1 — making the entry uneditable and unremovable from the UI.

## Change summary

Keybindings with invalid when expressions become permanently stuck in the keybindings editor UI — they cannot be edited, reset, or removed.

## Best solution

In `findUserKeybindingEntryIndex` (src/vs/workbench/services/keybinding/common/keybindingEditing.ts), fall back to a raw string comparison of the `when` field when `ContextKeyExpr.deserialize()` returns undefined for either side, so that entries with invalid expressions can still be matched and removed/edited.

Root cause: in src/vs/workbench/services/keybinding/common/keybindingEditing.ts, the method `findUserKeybindingEntryIndex` (line ~175) matches entries by calling `ContextKeyExpr.deserialize(keybinding.when)` and comparing its serialized form to `keybindingItem.when.serialize()`. When the stored when string is syntactically invalid, `deserialize` returns `undefined`, and the guard `if (contextKeyExpr && ...)` skips the entry, so the method returns -1 (not found). All operations (edit, remove, reset) that depend on finding the entry index then silently no-op. Fix: when `ContextKeyExpr.deserialize()` returns undefined for the stored entry's `when`, fall back to comparing the raw `keybinding.when` string against `keybindingItem.when?.serialize()` (and also handle the case where `keybindingItem.when` is undefined but the raw string is non-empty — meaning the resolved item also failed to parse the when). The simplest approach: if `contextKeyExpr` is falsy but `keybinding.when` is truthy, compare `keybinding.when` directly to the raw source when string of the keybindingItem (which may need to be threaded through or stored). Do NOT change the happy path for valid expressions.
