# Issue #193521 — Keyboard shortcuts "get stuck" with invalid "when expressions"

[https://github.com/microsoft/vscode/issues/193521](https://github.com/microsoft/vscode/issues/193521)

## Summary

The stuck-binding defect remains traceable in current main: parsing discards the invalid when expression, but editing and removal require it to match the original JSON entry. Keep this issue open in the already-correct keybindings-editor area.

## Change summary

Invalid when expressions make keyboard shortcuts appear unconditional and prevent editing, resetting, or removing them through the Keyboard Shortcuts editor.

## Best solution

Keep malformed user bindings recoverable through the Keyboard Shortcuts editor: editing must update the selected entry, and removal or reset must remove it without creating duplicates or changing another binding. Preserve valid-expression behavior and the existing when-expression grammar.
