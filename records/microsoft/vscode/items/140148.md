# Issue #140148 — Page down and page up do not work in Jupyter notebooks

[https://github.com/microsoft/vscode/issues/140148](https://github.com/microsoft/vscode/issues/140148)

## Summary

The keyboard-navigation gap remains on current main: Page Up/Down moves the cursor or cell focus rather than consistently scrolling the notebook viewport. The existing notebook-layout routing and On Deck holding milestone are appropriate.

## Change summary

Make Page Up/Down and document-boundary shortcuts scroll notebooks consistently regardless of whether a cell editor has focus.

## Best solution

Unify notebook page navigation so it scrolls the viewport across cell editors, outputs, and command mode while preserving valid text-selection behavior. The implementation likely spans notebook navigation keybindings and dynamic-height list scrolling.
