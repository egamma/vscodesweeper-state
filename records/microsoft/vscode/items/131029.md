# Issue #131029 — [Feature Request] Bracket Pair Colorization: Force unique opening color

[https://github.com/microsoft/vscode/issues/131029](https://github.com/microsoft/vscode/issues/131029)

## Summary

Keep this accepted feature request open: current colorization still assigns colors by nesting depth, so adjacent sibling pairs remain indistinguishable. With 38 upvotes and maintainer interest, the remaining work merits a design session to settle color-cycle and ancestor-collision semantics.

## Change summary

Allow successive bracket pairs at the same nesting depth to receive different colors, rather than changing colors only when nesting changes.

## Best solution

Provide one opt-in adjacent-pair distinction mode in native bracket colorization, following the maintainer's preference rather than copying both legacy settings. Settle its color-cycle and ancestor-exclusion behavior, keep bracket guides consistent, and preserve existing default coloring and performance.
