# Issue #336539 — Unable to scroll horizontally in VScode when secondary panel is open

[https://github.com/microsoft/vscode/issues/336539](https://github.com/microsoft/vscode/issues/336539)

## Summary

Real, reproducible regression — the diff/editor view can't be scrolled horizontally when the browser's own 'desperate reveal' scroll fires with an inconsistent flag — and a contributor already has an open fix PR that explicitly targets and tests this issue number, so this should stay open pending that PR landing.

## Change summary

Horizontal scrolling in the diff/editor view is blocked when the secondary side bar is open, because a browser-triggered scroll-reveal on the scrollbar DOM node isn't absorbed into the editor's own scroll state.

## Best solution

Land https://github.com/microsoft/vscode/pull/338030, which flips the `lookAtScrollLeft` flag for the `scrollbarDomNode` 'scroll' listener in src/vs/editor/browser/viewParts/editorScrollbar/editorScrollbar.ts so the native scrollLeft is absorbed back into the editor's scroll position instead of fighting the user's scroll.
