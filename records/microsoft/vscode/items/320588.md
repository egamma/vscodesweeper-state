# Issue #320588 — Undefined variable not detected in local problems

[https://github.com/microsoft/vscode/issues/320588](https://github.com/microsoft/vscode/issues/320588)

## Summary

VS Code core is a text editor and does not perform Python-specific static analysis like control-flow-aware undefined-variable detection. This is the responsibility of a Python language extension such as Pylance (which, powered by Pyright, does exactly this). The request should be directed to the Python extension ecosystem.

## Change summary

Request for VS Code to detect potentially undefined Python variables across if/else branches.

## Best solution

The reporter should install the Pylance extension (ms-python.vscode-pylance), which uses Pyright's control-flow analysis to detect exactly this class of issue — variables that may be unbound depending on the branch taken. This is not a VS Code core capability.
