# Issue #203554 — Check for updates

[https://github.com/microsoft/vscode/issues/203554](https://github.com/microsoft/vscode/issues/203554)

## Summary

Valid feature request: on Windows with the Inno Setup updater, 'Check for Updates' immediately downloads and installs without a confirmation prompt. The request for an intermediate 'update available — proceed?' dialog is still unaddressed on current main.

## Change summary

Request a confirmation dialog between checking for an update and downloading/installing it when using Help > Check for Updates.

## Best solution

In the Windows update service (`updateService.win32.ts`), when `explicit` is true and an update is found, transition to `AvailableForDownload` state instead of directly to `Downloading` — this would show the user the available update and let them choose to proceed. The existing `update.enableWindowsBackgroundUpdates` setting already gates auto-apply after download, but the gap is the missing pre-download confirmation on explicit checks.
