# Issue #318452 — Screenshots should be manageable while in step 2

[https://github.com/microsoft/vscode/issues/318452](https://github.com/microsoft/vscode/issues/318452)

## Summary

A real UX gap remains: current main keeps attachment management and description authoring on separate wizard pages, so screenshots cannot be referenced while writing the description. This team-authored request should remain open for an issue-reporter UX decision.

## Change summary

Make captured screenshots visible and manageable while the reporter selects the target and writes the issue description.

## Best solution

Let reporters view and manage existing attachments from the description stage without losing the capture workflow, using a layout that remains usable on smaller displays.
