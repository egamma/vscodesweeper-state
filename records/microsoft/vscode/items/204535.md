# Issue #204535 — Option to show intellisense only after certain number of characters typed

[https://github.com/microsoft/vscode/issues/204535](https://github.com/microsoft/vscode/issues/204535)

## Summary

A real configuration gap remains, and the request has been accepted into the Backlog with 65 community upvotes. Existing settings address delay or snippet-specific suppression, but not a minimum prefix length.

## Change summary

Allow automatic IntelliSense suggestions to appear only after a configurable number of characters, while preserving manual invocation.

## Best solution

Add a minimum-prefix-length editor option for automatic quick suggestions in the editor suggestion model, while leaving Ctrl+Space and trigger-character suggestions unaffected. The design should define how prefix length is measured across language tokens.
