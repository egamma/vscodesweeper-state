# Issue #337398 — Align customization migration hint styling with MCP authentication hint

[https://github.com/microsoft/vscode/issues/337398](https://github.com/microsoft/vscode/issues/337398)

## Summary

Real, source-confirmed visual inconsistency: the customization migration hint (rendered via the generic `systemNotification` chat content part) and the MCP authentication hint (its own dedicated `.chat-mcp-servers-interaction` widget) use different CSS for icon/text color, opacity, and font styling. A maintainer (aeschli) already posted a comparison screenshot, so this is a legitimate polish item, not a stale/vague report.

## Change summary

Make the customization migration hint's icon/text color and spacing match the MCP authentication hint's visual treatment in chat.

## Best solution

Have a maintainer decide which treatment is canonical (the compact icon+italic MCP style, or the systemNotification workflow style) and then align the other component's CSS/markup to match; this is a design-consistency call, not a mechanical fix.
