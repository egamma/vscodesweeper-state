# Issue #750 — Live preview cannot open pages if the containing folder has a "#" in the name

[https://github.com/microsoft/vscode-livepreview/issues/750](https://github.com/microsoft/vscode-livepreview/issues/750)

## Summary

Keep open: current source still leaves literal '#' characters unescaped in path segments, matching the reported truncated URLs and directory listings. An open PR explicitly targets this issue, so it should remain open while that implementation is reviewed.

## Change summary

Files with '#' in their filename or a containing folder name fail to preview because the character is interpreted as a URL fragment delimiter.

## Best solution

Review https://github.com/microsoft/vscode-livepreview/pull/857 against both folder-name and filename reproductions, including a leading '#', and verify URL construction and decoding together. Resolve this issue only after the complete fix lands; changing the embedded browser default does not establish that these extension-side encoding paths are fixed.
