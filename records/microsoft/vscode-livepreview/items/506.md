# Issue #506 — Create a launch.json configuration for live preview

[https://github.com/microsoft/vscode-livepreview/issues/506](https://github.com/microsoft/vscode-livepreview/issues/506)

## Summary

The current extension can launch an external debug preview from a command, but it does not contribute a launch configuration or debug-configuration provider that makes the same flow available through F5. The requested integration remains a valid, currently unimplemented feature.

## Change summary

Provide a launch.json-compatible Live Preview debug configuration that starts the server, opens the selected or generated HTML output, and attaches the JavaScript debugger through the standard F5 workflow.

## Best solution

Add a Live Preview debug-configuration provider and launch.json snippet that starts or reuses the appropriate workspace server, resolves its actual URL after port allocation, and delegates browser attachment to js-debug. It should support normal preLaunchTask composition so a project can compile before previewing, while preserving the existing command-based debug flow.

## Vision fit

- **Fit:** aligned
- **Reason:** This improves the supported external-browser debugging workflow and makes the default development flow more approachable without expanding Live Preview into an application server.
- **Evidence:** The durable preview-target theme explicitly includes external-browser preview with the js-debug attach, while the values emphasize approachability for beginners.

## Evidence

- **no launch configuration integration:** Current package.json contributes Live Preview commands, settings, and a `Live Preview` task definition, but no `debuggers`, launch configuration snippets, or debug-configuration provider; no `registerDebugConfigurationProvider` implementation exists under src/.
- **command-only debug path:** src/extension.ts registers `livePreview.start.externalDebugPreview.atFile`, and src/editorPreview/previewManager.ts launches debugging by executing `extension.js-debug.debugLink` with the dynamically selected server URL. This path is available through a Live Preview command rather than F5 or launch.json.
- **existing setting is partial:** `livePreview.debugOnExternalPreview` only controls whether external preview launches attach the debugger; it does not provide a launch.json configuration, compose with a project preLaunchTask, or expose the server's dynamically allocated URL to a launch configuration.
- **related precedent is not a canonical:** https://github.com/microsoft/vscode-livepreview/issues/258 was closed with the command-palette workaround `Live Preview: Show Debug Preview (External)`. That answers how to launch debugging manually but does not provide the F5/launch.json and build-task integration requested here.
- **canonical search:** Searches for launch.json, F5, preLaunchTask, and debug-preview requests found no other open issue that owns this same integration work.
