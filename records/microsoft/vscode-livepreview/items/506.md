# Issue #506 — Create a launch.json configuration for live preview

[https://github.com/microsoft/vscode-livepreview/issues/506](https://github.com/microsoft/vscode-livepreview/issues/506)

## Summary

The requested F5/launch.json workflow remains a distinct feature gap: current main can start a JavaScript debug preview through commands and settings, but it contributes no debug configuration or launch snippet. The existing feature-request label and Backlog milestone remain appropriate.

## Change summary

Allow a workspace launch.json configuration to start Live Preview, optionally run a build task, open a chosen generated HTML file, and attach the JavaScript debugger when the user presses F5.

## Best solution

Add a launch configuration contribution or debug-configuration provider that starts the Live Preview server for a configured HTML path and launches the existing external debug-preview flow, while supporting normal launch.json composition such as `preLaunchTask`. Reuse the current server and debugger-launch code rather than introducing a separate server lifecycle.

## Evidence

- **missing launch contribution:** Current `package.json` contributes Live Preview commands, menus, settings, and a task provider, but no `debuggers`, `configurationSnippets`, or launch-configuration contribution.
- **existing debug foundation:** `src/extension.ts` registers `livePreview.start.debugPreview.atFile` and `livePreview.start.externalDebugPreview.atFile`; both route through `ServerManager.openPreviewAtFileUri` using `PreviewType.externalDebugPreview`, so the underlying server-plus-debug-preview operation already exists.
- **partial existing capabilities:** `livePreview.defaultPreviewPath`, `livePreview.autoRefreshPreview`, and `livePreview.debugOnExternalPreview` cover selecting an initial page, refreshing changed output, and debugging external previews, but they do not make Live Preview an F5 launch target or support launch.json orchestration with a build task.
- **canonical search:** Open-issue searches for `launch.json`, `F5`, `debug preview`, and `build output` found no broader open issue owning this workflow; https://github.com/microsoft/vscode-livepreview/issues/422 concerns custom-browser selection and https://github.com/microsoft/vscode-livepreview/issues/448 concerns query parameters, not launch integration.
- **additional use case:** The comment at https://github.com/microsoft/vscode-livepreview/issues/506#issuecomment-1858765163 adds a concrete launch.json composition need: run a compile task and then preview or refresh its generated HTML output.
