# Issue #431 — Show progress while external browser is starting

[https://github.com/microsoft/vscode-livepreview/issues/431](https://github.com/microsoft/vscode-livepreview/issues/431)

## Summary

This team-authored Backlog feature request remains unimplemented on current main: external-browser launch provides no progress UI, although the server already exposes the request event needed to detect when the page arrives. No open canonical issue owns the same work, so it should remain open.

## Change summary

Show progress after an external-preview command is invoked and dismiss it when the launched browser requests the preview page.

## Best solution

Add cancellable or bounded progress around the external-preview launch flow, completing it when the server observes the expected page request and ensuring unrelated requests or a browser that never connects cannot leave progress visible indefinitely. The likely integration points are `src/server/serverGrouping.ts`, which exposes `onNewReqProcessed`, and the launch wiring in `src/manager.ts` and `src/editorPreview/previewManager.ts`.
