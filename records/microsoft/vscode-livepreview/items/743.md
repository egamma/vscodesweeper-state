# Issue #743 — Automatically switch between tabs.

[https://github.com/microsoft/vscode-livepreview/issues/743](https://github.com/microsoft/vscode-livepreview/issues/743)

## Summary

The reported focus stealing was independently observed with the former bundled preview, but the issue lacks versions, page details, and a current-version retest. Live Preview now uses VS Code's Integrated Browser by default, so confirmation is needed to determine whether the symptom persists there or only affects the legacy bundled-browser path.

## Change summary

Refreshing the embedded preview after an edit or save activates its tab and removes keyboard focus from the source editor.

## Best solution

Retest with a current Live Preview and VS Code release using the default `livePreview.useIntegratedBrowser: true`; if focus is still stolen, determine whether VS Code's Integrated Browser or page-authored focus behavior owns it. If it occurs only with the setting disabled, preserve editor focus when the bundled preview reloads and add a focused regression test around that legacy path.
