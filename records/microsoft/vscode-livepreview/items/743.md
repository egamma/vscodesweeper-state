# Issue #743 — Automatically switch between tabs.

[https://github.com/microsoft/vscode-livepreview/issues/743](https://github.com/microsoft/vscode-livepreview/issues/743)

## Summary

Current releases use VS Code's Integrated Browser by default, avoiding the bundled-preview focus-stealing path described here. A maintainer closed the older canonical report after this change specifically because it should resolve the same behavior.

## Change summary

Refreshing Live Preview after an edit or save should not switch focus from the source editor to the preview tab.

## Best solution

Keep `livePreview.useIntegratedBrowser` enabled so automatic refresh reloads the existing browser page without revealing the bundled preview tab. Treat a recurrence on a current release with that setting enabled as a separate Integrated Browser investigation.
