# Issue #148 — Feature request: Add option to provide a wrapper html page (with additional css or js files included)

[https://github.com/microsoft/vscode-livepreview/issues/148](https://github.com/microsoft/vscode-livepreview/issues/148)

## Summary

The requested wrapper-and-placeholder preview capability remains absent from current main. The reporter's working fetch-based workaround requires manually selecting the snippet, so it does not satisfy the request; no canonical issue was found.

## Change summary

Allow an HTML snippet to select a wrapper page that supplies surrounding markup, CSS, and JavaScript and inserts the snippet at a designated placeholder.

## Best solution

Retain this as a scoped product decision about preview-time composition in the extension's serving layer, not the Integrated Browser. If accepted, define wrapper selection, relative-resource resolution, and script execution semantics while preserving ordinary static-file previews.
