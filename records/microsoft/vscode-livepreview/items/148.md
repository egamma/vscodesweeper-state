# Issue #148 — Feature request: Add option to provide a wrapper html page (with additional css or js files included)

[https://github.com/microsoft/vscode-livepreview/issues/148](https://github.com/microsoft/vscode-livepreview/issues/148)

## Summary

This remains a valid, unscheduled feature request: Live Preview can serve a hand-written wrapper as a workaround, but it has no setting or command that automatically composes an HTML fragment into a configurable wrapper template. The Backlog milestone and age do not justify closing it.

## Change summary

Allow an HTML snippet to select a wrapper page that supplies surrounding markup, CSS, and JavaScript and inserts the snippet at a placeholder.

## Best solution

Keep the request open for a product decision and, if accepted, implement fragment-to-wrapper composition in the extension's serving path with an explicit workspace setting rather than requiring authors to modify the wrapper for each snippet. The design should define placeholder syntax, relative-URL bases, reload behavior, and safe handling of both wrapper and snippet content before considering the proposed magic-comment shorthand.
