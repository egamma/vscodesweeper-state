# Issue #660 — fragment/anchor in Uri is ignored when preview loose file

[https://github.com/microsoft/vscode-livepreview/issues/660](https://github.com/microsoft/vscode-livepreview/issues/660)

## Summary

The defect is present on current main: the command preserves the supplied URI until PreviewManager converts it into a server path using only `file.fsPath`, which discards a valid URI fragment for both workspace and loose files. No canonical issue or fixing change was found, so this should remain open as a localized correctness bug.

## Change summary

Preserve a `vscode.Uri` fragment when `livePreview.start.preview.atFile` opens a workspace or loose HTML file so the preview navigates to the requested anchor.

## Best solution

Update `src/editorPreview/previewManager.ts` to carry `file.fragment` through the filesystem-path-to-preview-URL conversion for bundled, Integrated Browser, external, and debug previews. Construct the Integrated Browser URL so its `vscode-livepreview` query parameter precedes the fragment, and add focused coverage in `src/test/suite/preview.test.ts` for valid fragmented URIs.

## Evidence

- **command preserves URI:** `src/extension.ts` registers `livePreview.start.preview.atFile` and passes the supplied `vscode.Uri` to `Manager.openPreviewAtFileUri`; `src/manager.ts` then forwards that URI through `_handleOpenFile` without removing its fragment.
- **fragment dropped on current main:** `PreviewManager._fileUriToPath` in `src/editorPreview/previewManager.ts` derives both loose-file endpoints and workspace-relative paths exclusively from `file.fsPath` and never reads `file.fragment`. Consequently, a URI created with `.with({ fragment: 'duration-prop' })` loses the anchor before any preview target constructs its URL.
- **all preview targets affected:** `launchFileInEmbeddedPreview` and `launchFileInExternalBrowser` both consume the fragment-free result of `_fileUriToPath`. The Integrated Browser path also appends `?vscode-livepreview=true`, so a preserved fragment must be placed after that query rather than before it.
