# Issue #660 — fragment/anchor in Uri is ignored when preview loose file

[https://github.com/microsoft/vscode-livepreview/issues/660](https://github.com/microsoft/vscode-livepreview/issues/660)

## Summary

Current source conclusively drops the URI fragment while converting the requested file into a preview URL, so this remains a valid extension bug. The fix should preserve the fragment for loose and workspace files across integrated, bundled, external, and debug previews.

## Change summary

Opening `livePreview.start.preview.atFile` with a valid file URI containing a fragment should navigate the preview to that document anchor.

## Best solution

Update `PreviewManager` to retain `vscode.Uri.fragment` when it constructs the served preview URL, placing it after Live Preview's query parameters where applicable. Cover workspace and loose-file URIs in `src/test/suite/preview.test.ts`, including the Integrated Browser and external-preview paths.
