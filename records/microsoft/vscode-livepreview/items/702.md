# Issue #702 — Javascript injected in non-html/javascript files

[https://github.com/microsoft/vscode-livepreview/issues/702](https://github.com/microsoft/vscode-livepreview/issues/702)

## Summary

Current source confirms that every extensionless filesystem file is treated as injectable HTML, so an extensionless JSON response is prefixed with the live-reload script. This is a real server correctness defect and must remain open for human handling because it concerns script injection into served content.

## Change summary

Serve extensionless non-HTML files without inserting the Live Preview reload script or altering their contents.

## Best solution

Change the server-side classification in `src/server/serverUtils/contentLoader.ts` and `src/utils/utils.ts` so injection occurs only after the response has been identified as HTML, while preserving support for genuinely extensionless HTML pages. Add coverage for both extensionless JSON and extensionless HTML to prevent either behavior from regressing.

- **current main still affected:** The current filesystem-serving path in `ContentLoader.getFileStream` retains this behavior, and the repository contains no test covering extensionless non-HTML content.
