# Issue #467 — Persistent status bar item to show when server is off also

[https://github.com/microsoft/vscode-livepreview/issues/467](https://github.com/microsoft/vscode-livepreview/issues/467)

## Summary

This remains a valid, maintainer-acknowledged feature request: current main hides the Live Preview status item whenever all servers are off, and no user-facing setting enables a persistent indicator. The existing server-logging command provides visibility while running but does not satisfy the request.

## Change summary

Provide an optional persistent status-bar item that indicates when Live Preview is stopped and offers a clearer way to start or manage the server.

## Best solution

Add an opt-in setting, disabled by default, that keeps the Live Preview status item visible in an inactive state when no server is running. The inactive item should invoke the existing start flow, while the active state can retain the current port display and command-palette access, preserving the team's minimal default status bar.

## Vision fit

- **Fit:** aligned
- **Reason:** An optional server-state indicator supports the durable server-lifecycle theme and makes the default workflow more understandable for beginners without adding status-bar clutter by default.
- **Evidence:** The vision identifies server lifecycle and configuration as a durable theme and says that approachability of the open-and-preview flow is valuable, while the issue's opt-in design preserves the intentionally small default surface.
