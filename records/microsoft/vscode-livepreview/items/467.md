# Issue #467 — Persistent status bar item to show when server is off also

[https://github.com/microsoft/vscode-livepreview/issues/467](https://github.com/microsoft/vscode-livepreview/issues/467)

## Summary

The requested persistent off-state indicator remains unimplemented, and the maintainer explicitly accepted an optional, disabled-by-default status-bar item as a feature request. The issue is already correctly classified in Backlog, and no open canonical issue owns the request.

## Change summary

Add an optional persistent Live Preview status-bar item that indicates when no server is running and provides an understandable way to start or stop it.

## Best solution

Add a disabled-by-default `livePreview.showStatusBarItem` setting and update `src/server/serverUtils/statusBarNotifier.ts` so the item can remain visible with distinct running and stopped states, while preserving the current minimal status bar by default. Its command should expose the appropriate start or stop action without changing the editor-title preview button's meaning.
