# Issue #795 — The folder link is incorrect in Windows 11

[https://github.com/microsoft/vscode-livepreview/issues/795](https://github.com/microsoft/vscode-livepreview/issues/795)

## Summary

Current main still generates directory-index URLs with the host-native path separator, which produces encoded backslashes and broken nested-folder links on Windows. The issue must remain open because an open PR explicitly identifies #795 as affected by the same root cause and provides a targeted fix.

## Change summary

Directory-index links for nested folders use Windows backslashes, producing `%5C` URLs that return 404 instead of navigating to the folder.

## Best solution

Review and land https://github.com/microsoft/vscode-livepreview/pull/856, which changes only the URL-path join in `ContentLoader.createIndexPage` to `path.posix.join` while retaining native `path.join` for the filesystem path, and adds a directory-link regression test. After that PR merges, verify the generated links on Windows and close this issue as implemented using the merge commit.

## Evidence

- **source-traced defect:** `src/server/serverUtils/contentLoader.ts` currently computes `relativeFileWithChild` with `path.join(relativePath, childFile)` and then passes it to `encodeURI`. On Windows, the native join introduces backslashes into this URL path, which are encoded as `%5C`; the resulting href does not identify the intended nested directory.
- **matching reports:** https://github.com/microsoft/vscode-livepreview/issues/855 documents the same Windows directory-index output (`%5Capps%5Cfolder`) with concrete reproduction steps, and https://github.com/microsoft/vscode-livepreview/issues/762 reports the same `%5C` path corruption.
- **open implementation:** https://github.com/microsoft/vscode-livepreview/pull/856 explicitly names #795 as having the same root cause, changes the URL join to `path.posix.join`, leaves the filesystem join native, and adds `src/test/suite/contentLoader.test.ts` to check that generated links contain forward slashes and no `%5C`. The PR is still open, so the issue must not be closed yet.
