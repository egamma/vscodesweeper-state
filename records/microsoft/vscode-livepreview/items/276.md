# Issue #276 — Live preview reloads when adding a new workspace root

[https://github.com/microsoft/vscode-livepreview/issues/276](https://github.com/microsoft/vscode-livepreview/issues/276)

## Summary

Keep open: the reporter reproduced the unwanted reload with only Live Preview enabled, and a maintainer also observed it. The supplied multi-root steps are sufficient to retest; current source exposes plausible refresh paths but does not establish that adding an unrelated root is fixed.

## Change summary

Adding an unrelated workspace folder unexpectedly reloads an existing preview whose server root and port have not changed.

## Best solution

Preserve the existing page and its state when an unrelated workspace root is added without changing its served content or connection. Retest the supplied scenario and distinguish extension-wide refresh notifications in src/updateListener.ts and src/manager.ts from bundled-browser reconnection before selecting the fix.
