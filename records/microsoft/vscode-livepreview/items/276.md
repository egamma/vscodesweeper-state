# Issue #276 — Live preview reloads when adding a new workspace root

[https://github.com/microsoft/vscode-livepreview/issues/276](https://github.com/microsoft/vscode-livepreview/issues/276)

## Summary

The reload is a confirmed Live Preview defect: adding an unrelated workspace root causes the active page to reload even though its root, URL, and served files are unchanged. The later `.git` report is related to overly broad refresh triggers but does not replace this issue's distinct workspace-folder-change trigger.

## Change summary

Prevent an active Live Preview page from reloading when an unrelated root is added to a multi-root workspace.

## Best solution

Keep the preview's server and reload connection stable when `workspace.onDidChangeWorkspaceFolders` adds or removes a root that does not affect the previewed file. The fix likely belongs in the workspace-folder/server lifecycle wiring around `src/manager.ts` and should be validated separately from any future ignore-path mechanism.
