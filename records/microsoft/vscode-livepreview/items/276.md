# Issue #276 — Live preview reloads when adding a new workspace root

[https://github.com/microsoft/vscode-livepreview/issues/276](https://github.com/microsoft/vscode-livepreview/issues/276)

## Summary

The reload is caused by the same unfiltered workspace-wide watcher tracked by the open ignore-path request in https://github.com/microsoft/vscode-livepreview/issues/548. That issue is the maintainer-designated solution and fully owns the remaining work, so this report can be consolidated into it.

## Change summary

Adding an unrelated folder to a multi-root workspace visibly reloads an active preview even though its served root and port have not changed.

## Best solution

Implement the configurable refresh exclusions tracked by https://github.com/microsoft/vscode-livepreview/issues/548 in `src/updateListener.ts`, allowing unrelated workspace roots and generated directories to be excluded from reload triggers while retaining the conservative default that potentially referenced files may require a refresh.
