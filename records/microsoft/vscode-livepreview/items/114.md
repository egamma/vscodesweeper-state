# Issue #114 — Address suggestions on using address bar.

[https://github.com/microsoft/vscode-livepreview/issues/114](https://github.com/microsoft/vscode-livepreview/issues/114)

## Summary

The bundled preview's address field still accepts only complete typed URLs and has no suggestion mechanism. This team-authored Backlog request is protected from a product-judgment close, although it now concerns the legacy browser used when `livePreview.useIntegratedBrowser` is disabled.

## Change summary

Add predictive path or URL suggestions to the address bar in Live Preview's bundled embedded browser.

## Best solution

Decide whether the bundled browser remains supported for feature development. If it does, add workspace/server-path completion to its address input; otherwise retain this issue until maintainers explicitly settle the legacy browser's scope rather than treating the Integrated Browser default as implementing the request.
