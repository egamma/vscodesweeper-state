# Issue #114 — Address suggestions on using address bar.

[https://github.com/microsoft/vscode-livepreview/issues/114](https://github.com/microsoft/vscode-livepreview/issues/114)

## Summary

The bundled preview still lacks address suggestions, while the default Integrated Browser has its own suggestions interface. Keep this team-authored request open: switching browsers did not implement the requested functionality in the original surface, and no qualifying older canonical was found.

## Change summary

Offer predictive address suggestions while typing in the embedded preview's URL bar.

## Best solution

Have the maintainer decide whether the Integrated Browser's existing suggestions satisfy the intended product experience or whether the bundled fallback still needs completion. Prefer core's browser UI for the default experience rather than duplicating it; retain this issue until that scope decision is explicit.
