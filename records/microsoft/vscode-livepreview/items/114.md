# Issue #114 — Address suggestions on using address bar.

[https://github.com/microsoft/vscode-livepreview/issues/114](https://github.com/microsoft/vscode-livepreview/issues/114)

## Summary

The bundled preview still lacks predictive address entry, but it is now the fallback behind `livePreview.useIntegratedBrowser: false`. This team-authored Backlog request is protected from a product-judgment close and no open canonical was found, so it should remain open pending a maintainer decision about the legacy browser.

## Change summary

Add predictive typing or completion suggestions to the embedded browser's address bar.

## Best solution

Decide whether address completion remains worth implementing in the bundled browser or whether the desired experience should be owned by VS Code's Integrated Browser. If the fallback remains supported at this level, suggestions could draw from its existing page-history data; otherwise maintainers should explicitly retire the request rather than treating the Integrated Browser default as its implementation.
