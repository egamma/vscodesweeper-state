# Issue #213 — Project breaks on unplanned "update-path" messages

[https://github.com/microsoft/vscode-livepreview/issues/213](https://github.com/microsoft/vscode-livepreview/issues/213)

## Summary

Keep open: disabling live refresh still does not suppress the bundled preview's update-path messaging, and the maintainer explicitly accepted this as a feature request. The current Integrated Browser default changes the usual preview path but does not implement message suppression in the bundled browser that still ships.

## Change summary

Allow projects to avoid Live Preview's update-path messages interfering with their own message handling, independently of automatic reloads.

## Best solution

Decide whether the supported bundled-preview experience should offer message suppression or another compatibility mechanism without breaking navigation and history. Retest the affected project with the Integrated Browser to establish whether that provides a practical alternative, while retaining this issue for the distinct messaging behavior rather than treating the default switch as a fix.
