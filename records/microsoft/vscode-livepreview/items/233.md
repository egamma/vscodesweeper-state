# Issue #233 — watch files settings

[https://github.com/microsoft/vscode-livepreview/issues/233](https://github.com/microsoft/vscode-livepreview/issues/233)

## Summary

This remains a valid feature request: current main watches all workspace files and provides no include or exclude setting, so unrelated file updates can still refresh the preview. The older, broader request should remain open rather than being closed in favor of the narrower ignore-setting request.

## Change summary

Add configurable file patterns controlling which workspace changes trigger Live Preview refreshes.

## Best solution

Add an include/exclude glob setting for auto-refresh and apply it when constructing or filtering the watcher in `src/updateListener.ts`, while preserving external watch-script support. Coordinate the design with https://github.com/microsoft/vscode-livepreview/issues/548, whose ignore-pattern request is a narrower part of this work.
