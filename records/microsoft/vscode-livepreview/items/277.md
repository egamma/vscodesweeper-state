# Issue #277 — Live preview task should use the radio tower icon

[https://github.com/microsoft/vscode-livepreview/issues/277](https://github.com/microsoft/vscode-livepreview/issues/277)

## Summary

The requested radio-tower icon remains unimplemented and blocked on VS Code exposing icon metadata for extension-contributed tasks. The attempted manifest declaration was removed because it had no effect, while the upstream API request was closed for lack of votes rather than delivered.

## Change summary

Display the radio-tower icon on terminals created for Live Preview's contributed server task.

## Best solution

VS Code core should provide a supported icon field for extension-contributed task definitions; Live Preview can then assign the radio-tower icon to its task contribution in `package.json`. Until that platform capability exists, there is no effective extension-side implementation.
