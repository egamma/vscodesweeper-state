# Issue #277 — Live preview task should use the radio tower icon

[https://github.com/microsoft/vscode-livepreview/issues/277](https://github.com/microsoft/vscode-livepreview/issues/277)

## Summary

The requested radio-tower icon depends on VS Code exposing icon support for extension-contributed tasks. An attempted manifest change was removed because the platform did not honor it, and the maintainer explicitly marked this issue blocked upstream, so it should remain open rather than be treated as implemented or obsolete.

## Change summary

Use the radio-tower icon for Live Preview's contributed task terminal instead of the generic task icon.

## Best solution

VS Code must first expose supported icon metadata for extension-contributed tasks; Live Preview can then declare the radio-tower icon in its `taskDefinitions` contribution. The previously linked core request was closed without implementing that capability, so the extension-side work remains blocked pending a platform decision.
