# Issue #277 — Live preview task should use the radio tower icon

[https://github.com/microsoft/vscode-livepreview/issues/277](https://github.com/microsoft/vscode-livepreview/issues/277)

## Summary

The requested default radio-tower icon remains unimplemented in Live Preview's task provider. The linked removal PR explicitly removed a nonworking attempt, and the upstream issues' closed states do not establish that the necessary API shipped.

## Change summary

Give the Live Preview server-logging task terminal a radio-tower icon by default.

## Best solution

Establish whether VS Code now exposes supported icon configuration for extension-contributed tasks, then adopt it in src/task/serverTaskProvider.ts so automatically generated Live Preview tasks show the radio-tower icon without user-authored tasks.json configuration. Retain this issue because upstream API support alone would not complete the extension-side adoption.
