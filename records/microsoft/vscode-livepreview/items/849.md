[https://github.com/microsoft/vscode-livepreview/issues/849](https://github.com/microsoft/vscode-livepreview/issues/849)

## Summary

The report does not establish that the Live Preview extension is serving the app: it describes a React/npm development server and Codespaces forwarded-port redirects, either of which could independently cause the failed refresh and 404. The exact server, port, preview surface, and logs are needed before this can be attributed to this extension.

## Change summary

After a Codespace sits idle for about 30 minutes, hot refresh stops and reopening the preview returns a persistent 404.

## Best solution

Determine whether port 3000/3001 is owned by Live Preview or whether the page comes from the React npm development server, then distinguish an extension URL-resolution failure in `src/connectionInfo/` from a Codespaces forwarding or Integrated Browser problem. A minimal reproduction plus the Ports view and Live Preview logs should reveal which component loses its endpoint after resume.
