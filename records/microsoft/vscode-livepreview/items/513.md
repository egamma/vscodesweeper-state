# Issue #513 — "Open Devtools Pane" does not work in browser-based Codespaces

[https://github.com/microsoft/vscode-livepreview/issues/513](https://github.com/microsoft/vscode-livepreview/issues/513)

## Summary

Keep open: a maintainer confirmed that the bundled preview's DevTools action does nothing in browser-based Codespaces, and the extension still exposes that action unconditionally. The Integrated Browser changes the current preview path, but does not establish a fix for this bundled-browser behavior.

## Change summary

The bundled preview's Open Devtools Pane action silently does nothing in browser-based Codespaces, leaving users without either DevTools or an explanation.

## Best solution

Make the bundled preview accurately communicate whether webview DevTools are available in browser-based Codespaces rather than offering a silent no-op. Actual browser-hosted DevTools capability belongs to microsoft/vscode, but this extension owns the menu affordance and feedback; determine current platform support before choosing the supported behavior.
