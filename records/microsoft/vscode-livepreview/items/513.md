# Issue #513 — "Open Devtools Pane" does not work in browser-based Codespaces

[https://github.com/microsoft/vscode-livepreview/issues/513](https://github.com/microsoft/vscode-livepreview/issues/513)

## Summary

A maintainer confirmed the bundled preview's DevTools action failed in browser-based Codespaces in 2023, and the current fallback implementation still exposes the action and invokes the same VS Code command without checking or reporting failure. Current versions default to the Integrated Browser and bypass this UI, however, so a current-version retest with the bundled preview is needed before deciding whether work remains.

## Change summary

Make the bundled preview's Open Devtools Pane action work in browser-based Codespaces, or disable it with a clear unsupported message.

## Best solution

Retest in current browser-based Codespaces with `livePreview.useIntegratedBrowser` set to `false`. If the VS Code web host still cannot execute `workbench.action.webview.openDeveloperTools`, update `src/editorPreview/` to hide or disable the action in that environment and explain the limitation instead of silently doing nothing.
