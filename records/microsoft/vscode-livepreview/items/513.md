# Issue #513 — "Open Devtools Pane" does not work in browser-based Codespaces

[https://github.com/microsoft/vscode-livepreview/issues/513](https://github.com/microsoft/vscode-livepreview/issues/513)

## Summary

The dropdown action was confirmed broken in browser-based Codespaces, but the 2023 report predates the current Integrated Browser default and does not establish whether the problem still occurs on current VS Code and Live Preview versions or which preview implementation now owns the action. A current retest is needed before deciding between an extension-side fallback and VS Code core behavior.

## Change summary

Selecting "Open Devtools Pane" from Live Preview in browser-based Codespaces produces no visible result, leaving mobile browser users without an in-preview debugging surface or an unsupported-action message.

## Best solution

Retest in a current browser-based Codespace with `livePreview.useIntegratedBrowser` at its default and then set to `false`. If the action belongs to the legacy bundled preview, either make `src/editorPreview/` report that DevTools cannot be opened in web-hosted VS Code or provide a supported fallback; if it is now an Integrated Browser action, keep this issue available for maintainer routing to `microsoft/vscode` under `browser-integration`.
