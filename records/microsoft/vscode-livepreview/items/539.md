# Issue #539 — Embedded vs Internal Preview documentation inconsistency

[https://github.com/microsoft/vscode-livepreview/issues/539](https://github.com/microsoft/vscode-livepreview/issues/539)

## Summary

The terminology inconsistency remains on current main: the command says “Internal Browser,” while the README and preview-target setting say “Embedded Preview.” This team-authored polish item should remain open, and the related issue covers a distinct documentation gap rather than owning this cleanup.

## Change summary

Unify the names used for the in-editor preview across commands, settings, and documentation.

## Best solution

Adopt a consistent vocabulary across README.md, package.nls.json, and package.json, distinguishing the generic embedded preview from VS Code’s Integrated Browser and the extension’s bundled webview where necessary. This should avoid treating “Internal Browser,” “Embedded Preview,” and “Integrated Browser” as interchangeable now that the Integrated Browser is the default rendering path.
