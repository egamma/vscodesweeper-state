# Issue #111 — Improve experience when using Codespaces

[https://github.com/microsoft/vscode-livepreview/issues/111](https://github.com/microsoft/vscode-livepreview/issues/111)

## Summary

This team-authored issue remains the canonical request for eliminating Codespaces' manual port-authorization flow. Current documentation still requires users to open both forwarded ports before embedded preview works, and no commit explicitly referencing this issue implements the requested experience.

## Change summary

Make the first embedded preview in Codespaces work without manually opening and authorizing the forwarded HTTP and WebSocket ports.

## Best solution

Provide a seamless first-run path across `src/connectionInfo/` and the current Integrated Browser flow, ideally through VS Code/Codespaces port-forwarding support; if authorization cannot be initiated programmatically, show a targeted action that opens the required forwarded addresses and explains the one-time step. Preserve this issue as the canonical cross-layer request while validating both HTTP and WebSocket authorization.
