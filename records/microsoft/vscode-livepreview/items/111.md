# Issue #111 — Improve experience when using Codespaces

[https://github.com/microsoft/vscode-livepreview/issues/111](https://github.com/microsoft/vscode-livepreview/issues/111)

## Summary

Keep this team-authored Codespaces improvement tracker open: the README still documents the manual redirect workaround, and no verified implementation or eligible duplicate establishes that the requested first-launch experience is delivered. The newer Integrated Browser path warrants a fresh comparison, but its availability does not prove that Codespaces authentication onboarding is fixed.

## Change summary

Make embedded preview startup in Codespaces understandable and usable without discovering the external-browser authentication workaround manually.

## Best solution

Establish the first-launch behavior separately for browser-based Codespaces and the Integrated Browser path, then provide actionable extension-side guidance wherever manual authorization remains necessary. Authentication and framing restrictions belong to GitHub/VS Code infrastructure; any extension mitigation should preserve those boundaries rather than attempt to bypass them.
