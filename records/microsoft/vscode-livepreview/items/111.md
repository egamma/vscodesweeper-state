# Issue #111 — Improve experience when using Codespaces

[https://github.com/microsoft/vscode-livepreview/issues/111](https://github.com/microsoft/vscode-livepreview/issues/111)

## Summary

Keep this team-authored canonical Codespaces experience request open. Current documentation still requires users to authorize both forwarded ports manually, and current connection code resolves external URIs without detecting or initiating the required browser authentication flow.

## Change summary

Make the first embedded Live Preview session in Codespaces work without manually opening and authorizing the HTTP and WebSocket forwarded-port URLs.

## Best solution

Prefer a VS Code or Codespaces platform mechanism that lets the Integrated Browser reach newly forwarded ports without an unframeable authentication redirect. If that is unavailable, add a focused extension-side onboarding action that opens the required HTTP and WebSocket forwarded URLs externally and explains the one-time authorization requirement, while retaining the README fallback.
