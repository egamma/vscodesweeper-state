# Issue #817 — When used with DevContainers the Forwarded Address should be used

[https://github.com/microsoft/vscode-livepreview/issues/817](https://github.com/microsoft/vscode-livepreview/issues/817)

## Summary

The Integrated Browser preview uses the container-local address instead of VS Code's forwarded address in a Dev Container. The open implementation PR https://github.com/microsoft/vscode-livepreview/pull/861 directly references this issue, so it must remain open while that fix is reviewed.

## Change summary

Use the VS Code-forwarded external address when opening an Integrated Browser preview from a Dev Container, forwarding the server port first if necessary.

## Best solution

Review and land https://github.com/microsoft/vscode-livepreview/pull/861 if it correctly resolves the server URI through VS Code's forwarding API before opening the Integrated Browser. Verify both Dev Container behavior and ordinary local previews so the forwarding change does not regress desktop use.
