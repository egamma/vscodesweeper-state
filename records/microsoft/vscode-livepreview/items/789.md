# Issue #789 — Support vscode files.associations setting

[https://github.com/microsoft/vscode-livepreview/issues/789](https://github.com/microsoft/vscode-livepreview/issues/789)

## Summary

Live Preview already uses VS Code's resolved language ID rather than requiring an `.html` filename in its editor and Explorer command enablement, so a `files.associations` entry mapping `*.phtml` to `html` provides the requested behavior.

## Change summary

Allow files associated with the VS Code `html` language through `files.associations` to use Live Preview.

## Best solution

Keep the existing language-ID-based command enablement and HTML handling; users can associate additional filename patterns with `html` through VS Code's `files.associations` setting.

## Vision fit

- **Fit:** aligned
- **Reason:** Supporting HTML-associated templates fits the extension's durable serving-correctness theme without adding a separate extension-specific association setting.
- **Evidence:** The vision identifies serving correctness and path handling for plain HTML/CSS/JS projects as a durable theme, while favoring reuse of VS Code platform surfaces.
