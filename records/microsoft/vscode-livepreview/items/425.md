# Issue #425 — Consider respecting server root even if the directory doesn't exist

[https://github.com/microsoft/vscode-livepreview/issues/425](https://github.com/microsoft/vscode-livepreview/issues/425)

## Summary

Current main still deliberately replaces a nonexistent `livePreview.serverRoot` with the workspace root, which can conceal a configuration mistake. The requested diagnostic improvement remains valid, is already classified appropriately as polish, and has no open canonical issue.

## Change summary

Honor the configured server root even when its directory does not exist instead of silently serving from the workspace root.

## Best solution

Preserve the configured `livePreview.serverRoot` throughout workspace selection and server setup, then surface the resulting missing-root or 404 state rather than serving unrelated workspace-root content. Update the path utility tests and the setting description so the behavior and documentation remain consistent.
