# Issue #762 — File not found.

[https://github.com/microsoft/vscode-livepreview/issues/762](https://github.com/microsoft/vscode-livepreview/issues/762)

## Summary

The broken `%5C` directory links are reproducible from the current source on Windows: directory-index URL paths are built with the platform-dependent `path.join`. Keep the issue open because PR https://github.com/microsoft/vscode-livepreview/pull/856 explicitly addresses #762 and has not merged.

## Change summary

Directory-index links generated on Windows contain encoded backslashes, causing nested folders to return File Not Found.

## Best solution

Review and land https://github.com/microsoft/vscode-livepreview/pull/856, which changes the URL-path operation in `ContentLoader.createIndexPage` to `path.posix.join` while retaining native `path.join` for filesystem paths, and adds a directory-index regression test. Issue https://github.com/microsoft/vscode-livepreview/issues/855 documents the same root cause in greater detail, but the open fixing PR already references this report directly.
