# Issue #762 — File not found.

[https://github.com/microsoft/vscode-livepreview/issues/762](https://github.com/microsoft/vscode-livepreview/issues/762)

## Summary

Current main still generates directory-index URLs with the host-native path separator, which becomes `%5C` on Windows and produces the reported broken links. Keep this open because PR https://github.com/microsoft/vscode-livepreview/pull/856 explicitly identifies this report as the same root cause and provides an unmerged fix.

## Change summary

Generated directory-index links use encoded Windows backslashes and lead to file-not-found responses.

## Best solution

Review and land https://github.com/microsoft/vscode-livepreview/pull/856, which changes the URL-path join in `ContentLoader.createIndexPage` to `path.posix.join` while retaining native joining for the filesystem path and adds a regression test. Close this issue only after that fix merges.
