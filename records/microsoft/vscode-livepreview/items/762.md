## Evidence

- **Current source still generates encoded backslashes:** src/server/serverUtils/contentLoader.ts:208–230 constructs directory-index URLs with native path.join(relativePath, childFile), then applies encodeURI. On Windows, the native join produces backslash separators, which encodeURI turns into %5C; both file and directory links use this value.
- **URL-to-index call path:** src/server/httpServer.ts:212–213 decodes the request pathname and resolves the filesystem location; at lines 276–285, a directory without index.html is passed to ContentLoader.createIndexPage with URLPathName as relativePath. The subsequent native join therefore treats a URL path as a filesystem path.
- **Open implementation candidate:** https://github.com/microsoft/vscode-livepreview/pull/856 is OPEN and explicitly identifies this issue as sharing the root cause. Despite its reversed title, its inspected diff changes the URL join from path.join to path.posix.join, leaves the filesystem join unchanged, and proposes a directory-link regression test. An open referencing PR requires keeping the issue open.
