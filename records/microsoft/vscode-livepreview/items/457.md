# Issue #457 — Injected script should be aware of whether it's inside webview or not

[https://github.com/microsoft/vscode-livepreview/issues/457](https://github.com/microsoft/vscode-livepreview/issues/457)

## Summary

Keep open: console overrides now exclude top-level browser windows, but the injected script still initializes webview-specific listeners without establishing that it is connected to an editor panel. This team-authored debt item is only partially addressed, and the linked visibility report does not own its broader initialization work.

## Change summary

Make the injected reload script distinguish an editor-panel connection from ordinary browser use so it can avoid unnecessary embedded-preview initialization and support visibility-aware refresh.

## Best solution

Separate browser-independent live reload from panel-specific initialization in media/injectScript.js and its bundled-webview messaging counterpart in media/main.js, preserving reload in external browsers and the Integrated Browser. Coordinate visibility behavior with https://github.com/microsoft/vscode-livepreview/issues/454 without treating that narrower report as a duplicate canonical.

## Evidence

- **Partial console coverage:** media/injectScript.js guards console overrides with window.parent !== window, so top-level external-browser pages already avoid them. This detects framing, not an association with a Live Preview editor panel.
- **Remaining initialization gap:** media/injectScript.js installs message and error listeners unconditionally. onLoad() also installs link-click, link-hover, keydown, and keyup handlers regardless of browser context; postParentMessage() guards message delivery but does not prevent this setup. The setup-parent-listener handler replies with update-path without recording panel association.
- **Existing parent communication:** media/main.js sends setup-parent-listener to the hostedContent iframe. src/server/serverUtils/HTMLInjector.ts initializes the shared injected script by substituting HTTP and WebSocket addresses, without supplying browser or panel identity.
