# Issue #457 — Injected script should be aware of whether it's inside webview or not

[https://github.com/microsoft/vscode-livepreview/issues/457](https://github.com/microsoft/vscode-livepreview/issues/457)

## Summary

Keep this team-authored debt item open. A later commit avoided console overrides in top-level browser windows, but the injected client still performs embedded-preview initialization for every served page and reloads every connected client without knowing whether its associated preview panel is visible.

## Change summary

Make the injected live-reload client identify whether it belongs to an embedded preview and use that association to skip embedded-only setup and avoid refreshing hidden preview tabs.

## Best solution

Introduce an explicit initialization or handshake between `media/injectScript.js`, the WebSocket server, and the bundled `BrowserPreview` so each client can be classified and associated with panel visibility. External-browser clients should retain live refresh without embedded-only listeners, while hidden bundled previews should defer reloads as tracked by https://github.com/microsoft/vscode-livepreview/issues/454.

## Vision fit

- **Fit:** aligned
