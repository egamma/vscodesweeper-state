# Issue #116 — Responsive Layouts - Like Devices (sm, md, lg, xl) & Viewport dimensions

[https://github.com/microsoft/vscode-livepreview/issues/116](https://github.com/microsoft/vscode-livepreview/issues/116)

## Summary

The requested responsive presets and viewport-dimension display remain unimplemented, but the default embedded-preview surface is now VS Code's Integrated Browser, so this browser-toolbar capability belongs primarily in microsoft/vscode rather than the Live Preview server. This issue should remain open as the oldest canonical request while maintainers determine how to coordinate it with the Integrated Browser.

## Change summary

Add responsive viewport presets and a visible current-width/current-height indicator to the embedded preview.

## Best solution

Provide responsive viewport sizing, device presets, and dimension feedback in VS Code's Integrated Browser so Live Preview and other browser users share the capability; Live Preview should continue handing it the served URL without implementing separate browser chrome. Retain this issue as the canonical Live Preview request and consolidate the narrower https://github.com/microsoft/vscode-livepreview/issues/494 into it.

## Vision fit

- **Evidence:** The vision states that "the server is the product; the browser is increasingly VS Code's" and specifically treats requests that grow the bundled webview browser as contrary to the current direction.
