# Issue #688 — Incorrect Content-Type header for XHTML files

[https://github.com/microsoft/vscode-livepreview/issues/688](https://github.com/microsoft/vscode-livepreview/issues/688)

## Summary

The XHTML Content-Type defect remains directly traceable on current main: serving an open document in HTML language mode overwrites its inferred MIME type. The linked fix attempt was closed without merging, so this accepted Backlog bug still needs a fix.

## Change summary

Serve XHTML documents as application/xhtml+xml while preserving live-reload injection so XML namespace-dependent styling works.

## Best solution

Correct MIME-type selection in src/server/serverUtils/contentLoader.ts so HTML language mode does not erase an XHTML file's inferred type, while preserving ordinary HTML behavior and XHTML live refresh. Review the unmerged approach in https://github.com/microsoft/vscode-livepreview/pull/689 and verify that the injected content remains valid XHTML.
