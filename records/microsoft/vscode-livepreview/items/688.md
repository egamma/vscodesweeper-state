# Issue #688 — Incorrect Content-Type header for XHTML files

[https://github.com/microsoft/vscode-livepreview/issues/688](https://github.com/microsoft/vscode-livepreview/issues/688)

## Summary

The XHTML Content-Type defect remains present on current `main`: an open document with language ID `html` is injected and then unconditionally served as `text/html`, discarding the MIME type inferred from its `.xhtml` extension. The related fix PR was closed without merging, and no other open issue owns this XHTML-specific work.

## Change summary

Preserve `application/xhtml+xml` when injecting the live-reload script into an open XHTML document.

## Best solution

Update `src/server/serverUtils/contentLoader.ts` so HTML-language script injection preserves an inferred XHTML media type while retaining `text/html` for ordinary HTML, and add a server/content-loader regression test asserting both the response Content-Type and injection behavior for an `.xhtml` document.
