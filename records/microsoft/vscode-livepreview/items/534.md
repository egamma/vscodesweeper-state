# Issue #534 — Live preview extension doesn't display window at full height in codespaces

[https://github.com/microsoft/vscode-livepreview/issues/534](https://github.com/microsoft/vscode-livepreview/issues/534)

## Summary

The bundled preview iframe can fail to fill its container because its percentage height depends on a `.content` element with no defined height. Keep the issue open because the directly linked fix PR remains open and explicitly references this issue.

## Change summary

Make the bundled embedded preview fill the available editor height in browser-hosted environments such as Codespaces, Gitpod, and code-server.

## Best solution

Review and land the localized container-layout correction from https://github.com/microsoft/vscode-livepreview/pull/751 after separating or carefully reviewing its unrelated CSP wildcard changes. The fix belongs in `media/vscode.css`; the legacy bundled-browser path still ships even though current default configurations use VS Code's Integrated Browser.
