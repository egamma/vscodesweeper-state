# Issue #534 — Live preview extension doesn't display window at full height in codespaces

[https://github.com/microsoft/vscode-livepreview/issues/534](https://github.com/microsoft/vscode-livepreview/issues/534)

## Summary

The bundled preview iframe can fail to fill its container because its percentage height depends on a `.content` table row with no definite height. The open PR https://github.com/microsoft/vscode-livepreview/pull/751 directly references this issue and proposes a CSS fix, so the issue must remain open while that implementation is reviewed.

## Change summary

Make the bundled embedded preview fill the available editor height in browser-hosted VS Code environments such as Codespaces, Gitpod, and code-server.

Review and validate the localized iframe-layout change in https://github.com/microsoft/vscode-livepreview/pull/751 against the supplied Codespaces reproduction and Firefox/code-server case, while separating or reconsidering its unrelated CSP changes. Close the issue only after an appropriate fix merges.
