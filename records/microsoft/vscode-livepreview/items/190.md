# Issue #190 — Make Live Preview work on the web

[https://github.com/microsoft/vscode-livepreview/issues/190](https://github.com/microsoft/vscode-livepreview/issues/190)

## Summary

This is a team-authored, explicitly backlogged product proposal for supporting static HTML/CSS/JS preview in vscode.dev and github.dev. The discussion records team interest and a concrete prototype direction, while the related items do not establish an open canonical or a completed implementation, so it should remain open.

## Change summary

Enable Live Preview in browser-hosted VS Code by prototyping a Service Worker bridge from VS Code's virtual file system for static HTML, CSS, and JavaScript.

## Best solution

Keep this as the canonical product and feasibility issue, then prototype a web extension architecture that serves virtual-workspace files through a Service Worker and supports refresh without relying on a Node extension host or localhost server. The prototype should explicitly validate virtual file-system access, relative-resource resolution, reload behavior, and browser security constraints before committing to the full implementation.
