# Issue #741 — live preview not working

[https://github.com/microsoft/vscode-livepreview/issues/741](https://github.com/microsoft/vscode-livepreview/issues/741)

## Summary

This is a configuration and UI-visibility problem rather than an extension defect: the configured LAN address is unavailable on the machine, and Live Preview intentionally falls back to 127.0.0.1. Maintainer guidance for the same warning is to reset `livePreview.hostIP`, while the missing editor button can be restored or bypassed through the existing Show Preview command.

## Change summary

Live Preview reports that a configured 192.168.x.x host address cannot be used, and its editor preview button is no longer visible.

## Best solution

Keep `livePreview.hostIP` at its default `127.0.0.1` unless the machine actually owns the requested address, and use the existing Live Preview Show Preview command with an HTML editor active. If its editor-title action was hidden, re-enable Show Preview from that area's context menu.
