# Issue #877 — [Bug] `:root {font-size: 1rem;}` does not equivalate `settings.json#/editor.fontSize`.

[https://github.com/microsoft/vscode-livepreview/issues/877](https://github.com/microsoft/vscode-livepreview/issues/877)

## Summary

The requested relationship between page font size and editor.fontSize concerns browser rendering, likely VS Code's Integrated Browser on the reported versions, rather than Live Preview's server. Keep this open for browser identification and a core-side product decision; the related color-scheme issue does not own this request.

## Change summary

Make a preview page's root font size of 1rem resolve to the configured VS Code editor font size, reported as 13px.

## Best solution

Confirm that livePreview.useIntegratedBrowser is enabled, then assess editor-font-size inheritance in microsoft/vscode's Integrated Browser (browser-integration), including whether it should be configurable independently of page zoom. Preserve the distinction between editor preferences and website CSS; no extension-side server change is established as necessary.
