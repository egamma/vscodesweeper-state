# Issue #697 — customizable date format

[https://github.com/microsoft/vscode-livepreview/issues/697](https://github.com/microsoft/vscode-livepreview/issues/697)

## Summary

The generated directory index still uses a hard-coded date format despite localizing its headings. Date-format customization remains an uncovered capability, and the canonical search found no open issue owning the same request.

## Change summary

Allow directory-index modification dates to use a localized or user-configurable format, including Korean year-month-day formatting.

## Best solution

Decide whether directory-index dates should automatically follow the VS Code display language, expose an explicit formatting preference, or support both. The behavior belongs in this extension's date-formatting helper and server-generated index, not VS Code's Integrated Browser.

Switching preview browsers does not change this server-side formatting.
