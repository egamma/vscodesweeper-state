# Issue #697 — customizable date format

[https://github.com/microsoft/vscode-livepreview/issues/697](https://github.com/microsoft/vscode-livepreview/issues/697)

## Summary

Current main still formats directory-index timestamps with a fixed US-style `M/DD/YY, H:mm:ss` pattern even though the surrounding index text is localized. No existing setting or open canonical issue covers date formatting, so this remains a valid, currently unlabeled feature request.

## Change summary

Make modification dates on generated directory-index pages follow the user's locale or a configurable date format.

## Best solution

Format directory-index dates according to the active VS Code locale by default, with a narrowly scoped `livePreview.*` setting only if explicit customization is needed. Keep this separate from task and preview-console timestamps, which currently share `FormatDateTime`, and add directory-index coverage under `src/test/suite/`.

## Vision fit

- **Fit:** aligned
- **Reason:** Localized directory-index metadata improves serving correctness and the approachable default experience for users outside US date conventions.
- **Evidence:** The durable serving-correctness theme explicitly includes generated directory indexes, while the values identify beginners and the simple open-and-preview flow as important.
