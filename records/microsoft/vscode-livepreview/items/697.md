# Issue #697 — customizable date format

[https://github.com/microsoft/vscode-livepreview/issues/697](https://github.com/microsoft/vscode-livepreview/issues/697)

## Summary

The requested customization remains absent on current main: generated directory indexes localize their labels but render modification timestamps with a fixed US-style format. This is a valid, unclassified feature request that should remain open.

## Change summary

Allow directory-index modification dates to follow the user's locale or a configurable date format instead of always using M/DD/YY.

## Best solution

Format directory-index timestamps according to the VS Code display locale by default, then add a `livePreview.*` format setting only if maintainers want explicit overrides. Keep the directory-index behavior in `src/server/serverUtils/contentLoader.ts` separate from task and preview log timestamps, which currently share the same formatting helper.

- **Evidence:** The public durable themes explicitly include directory indexes under “Serving correctness,” while the README defines the extension as a local server for previewing web projects.
