# Issue #325 — Add option to hide the address bar

[https://github.com/microsoft/vscode-livepreview/issues/325](https://github.com/microsoft/vscode-livepreview/issues/325)

## Summary

The bundled webview still always renders its navigation header and no `livePreview.*` setting hides it, so the requested capability remains unimplemented. It should stay open for a maintainer scope decision because the bundled browser is now a fallback behind `livePreview.useIntegratedBrowser: false`, while the default Integrated Browser's chrome belongs to VS Code core.

## Change summary

Add an option that hides the embedded preview's address bar to give the page more vertical space.

## Best solution

Decide whether customization of the legacy bundled browser remains supported; if so, add a scoped setting and conditionally omit or collapse the header generated in `src/editorPreview/webviewComm.ts`. If the request instead applies to the default Integrated Browser, its address-bar visibility belongs in `microsoft/vscode`, not this extension.
