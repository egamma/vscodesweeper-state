# Issue #325 — Add option to hide the address bar

[https://github.com/microsoft/vscode-livepreview/issues/325](https://github.com/microsoft/vscode-livepreview/issues/325)

## Summary

The requested address-bar visibility option is not exposed by Live Preview, and the bundled preview still renders the bar unconditionally. Keep this accepted Backlog request open; the equivalent capability for today's default Integrated Browser belongs in VS Code core.

## Change summary

Allow hiding the embedded preview's address bar to reclaim space when the page URL does not change.

## Best solution

Pursue toolbar visibility in microsoft/vscode's Integrated Browser through https://github.com/microsoft/vscode/issues/341244, while leaving support for the bundled preview as an explicit maintainer scope decision. That newer core request is related, not a valid duplicate target for this re-reviewed 2022 issue, and does not change the bundled browser.
