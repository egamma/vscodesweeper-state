# Issue #576 — Support for SPA

[https://github.com/microsoft/vscode-livepreview/issues/576](https://github.com/microsoft/vscode-livepreview/issues/576)

## Summary

A real gap remains: Live Preview still returns its generated 404 page for unknown routes and has no configurable fallback document. The maintainer and reporter agreed that serving a configured file for missing paths would satisfy the request, so the existing feature request should remain open.

## Change summary

Add a setting that serves a designated HTML fallback when a requested path does not exist, enabling history-based SPA routing.

## Best solution

Keep the scope narrower than full SPA or application-server support: add a setting such as `livePreview.fileNotFoundFilepath`, validate that it resolves within the configured server root, and have `src/server/httpServer.ts` serve that document for otherwise-missing paths while preserving the requested URL. The maintainer should decide the fallback response status and behavior for missing or invalid configured files.
