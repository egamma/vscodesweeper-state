# Issue #862 — Embedded Live Preview Console Does Not Work

[https://github.com/microsoft/vscode-livepreview/issues/862](https://github.com/microsoft/vscode-livepreview/issues/862)

## Summary

The inactive Output channel is a leftover from the bundled preview and is misleading when the default Integrated Browser is used. Keep the issue open because the directly linked PR is still open and explicitly implements the requested cleanup.

## Change summary

Only expose the Embedded Live Preview Console Output channel when the legacy bundled preview that supplies its messages is actually used.

## Best solution

Review and land https://github.com/microsoft/vscode-livepreview/pull/867, which lazily creates the channel for the legacy preview while directing Integrated Browser users to Developer Tools; close this issue after that implementation merges.
