# Issue #733 — images doesn't load when i use live preview in a vite project

[https://github.com/microsoft/vscode-livepreview/issues/733](https://github.com/microsoft/vscode-livepreview/issues/733)

## Summary

This is a Vite server/path-resolution setup question rather than a Live Preview defect. The image works when Vite runs because Vite processes the project and applies its public-asset semantics, whereas Live Preview only serves workspace files and does not replace Vite's development server.

## Change summary

A background image referenced by a Tailwind arbitrary-value class is missing when a Vite project is served through Live Preview, although it appears through Vite's development and build workflows.

## Best solution

Run the project's Vite development server and open its URL in VS Code's Integrated Browser. If previewing built static output instead, build first and serve the output directory by configuring `livePreview.serverRoot`; asset URLs must resolve within that served root.
