# Issue #733 — images doesn't load when i use live preview in a vite project

[https://github.com/microsoft/vscode-livepreview/issues/733](https://github.com/microsoft/vscode-livepreview/issues/733)

## Summary

This is a Vite/Tailwind setup question: the reporter confirms that Vite's development server and build display the images correctly. Live Preview serves files without running Vite's processing pipeline, so the supported answer is to preview the Vite-served URL rather than replace that server.

## Change summary

A Tailwind background-image utility fails when a Vite project's source files are served through Live Preview, although an ordinary image element and Vite's own workflow work.

## Best solution

Use npm run dev and open the URL Vite prints in an external browser or VS Code's Integrated Browser. No extension change is established here; determining whether the specific background fails because of CSS generation or asset-root resolution would require the project's stylesheet setup and directory layout.
