# Issue #402 — Warn users if external browser opens invalid URL

[https://github.com/microsoft/vscode-livepreview/issues/402](https://github.com/microsoft/vscode-livepreview/issues/402)

## Summary

The bundled browser still forwards a scheme-less address to the external opener without reporting failure. The Integrated Browser default bypasses this path rather than fixing it; this team-authored, accepted bug should remain open.

## Change summary

Provide actionable feedback when opening an invalid address from the bundled preview's URL bar fails.

## Best solution

Ensure the bundled preview reports an invalid address or failed external launch instead of silently returning to the previous page. This belongs in src/editorPreview/browserPreview.ts and src/utils/externalBrowserUtils.ts, not VS Code's Integrated Browser.
