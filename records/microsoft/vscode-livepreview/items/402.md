# Issue #402 — Warn users if external browser opens invalid URL

[https://github.com/microsoft/vscode-livepreview/issues/402](https://github.com/microsoft/vscode-livepreview/issues/402)

## Summary

The invalid-URL failure remains visible in the current bundled-preview source: a bare hostname is passed unchanged to the external-browser API, whose success result is discarded, leaving the user without feedback. This team-authored Backlog issue has no verified duplicate, linked PR, or explicitly referencing fix commit, so it should remain open.

## Change summary

Provide useful feedback when a hostname entered in the bundled preview's address bar cannot be opened in an external browser.

## Best solution

In the bundled preview path, normalize a hostname such as `google.ca` to a valid HTTP URL before launching it, or await the external-open result and display a clear warning when it fails. Keep the behavior localized to `src/editorPreview/browserPreview.ts` and `src/utils/externalBrowserUtils.ts`; the legacy path still ships behind `livePreview.useIntegratedBrowser: false` even though it is no longer the default.
