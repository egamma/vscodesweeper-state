# Issue #673 — Allow previewing from codeblocks in chat

[https://github.com/microsoft/vscode-livepreview/issues/673](https://github.com/microsoft/vscode-livepreview/issues/673)

## Summary

Keep this team-authored feature request open: the current server path does not support VS Code chat-code-block URIs, and the explicitly linked implementation PR remains open. The PR needs review and current-platform validation rather than the issue being closed before it lands.

## Change summary

Allow an HTML code block generated in VS Code chat to be opened directly in Live Preview.

## Best solution

Update and validate https://github.com/microsoft/vscode-livepreview/pull/670 against current VS Code, especially its handling of `vscode-chat-code-block` URIs and Windows paths, then land or replace it with a tested implementation. The supporting VS Code context-key change has already merged, so the remaining work is in this extension's endpoint and content-loading paths.

## Vision fit

- **Fit:** aligned
- **Reason:** Previewing generated HTML through the existing server extends the core server-plus-preview workflow to a VS Code editing surface without turning the extension into an application server or expanding the legacy browser.
- **Evidence:** The README positions Live Preview as "An extension that hosts a local server for you to preview your web projects on!"; this request reuses that server and preview flow for an HTML virtual document.
