# Issue #537 — Explain possible Internal (Embedded) vs External Browser version (capabilities) mismatch.

[https://github.com/microsoft/vscode-livepreview/issues/537](https://github.com/microsoft/vscode-livepreview/issues/537)

## Summary

The documentation gap remains on current main: the README presents embedded and external previews without explaining that their browser engines and supported web-platform features may differ. The later Integrated Browser integration changes the explanation needed but does not satisfy the request.

## Change summary

Document that embedded and external previews can use different browser-engine versions and therefore support different web-platform capabilities.

## Best solution

Update the embedded and external preview sections of README.md to distinguish VS Code's Integrated Browser, the bundled fallback selected with `livePreview.useIntegratedBrowser: false`, and the user's external browser, explaining that engine versions and capabilities can differ without promising fixed Chromium or V8 versions. Keep the terminology cleanup in https://github.com/microsoft/vscode-livepreview/issues/539 as a separate, related polish task.
