# Issue #537 — Explain possible Internal (Embedded) vs External Browser version (capabilities) mismatch.

[https://github.com/microsoft/vscode-livepreview/issues/537](https://github.com/microsoft/vscode-livepreview/issues/537)

## Summary

The documentation gap remains: the current FAQ attributes embedded-versus-external differences only to browser cache or client state and does not explain that the rendering environments can have different web-platform capabilities. The newer Integrated Browser default changes the wording needed, but does not eliminate the need for this clarification.

## Change summary

Document that embedded and external previews can use different browser runtimes and therefore support different web-platform features.

## Best solution

Update the README's existing embedded-versus-external FAQ to distinguish VS Code's Integrated Browser, the legacy bundled webview selected with `livePreview.useIntegratedBrowser: false`, and an external desktop browser. Explain conceptually that their engine versions and client state can differ, without hard-coding Chromium or V8 versions that change with VS Code and browser updates.
