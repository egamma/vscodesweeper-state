# Issue #537 — Explain possible Internal (Embedded) vs External Browser version (capabilities) mismatch.

[https://github.com/microsoft/vscode-livepreview/issues/537](https://github.com/microsoft/vscode-livepreview/issues/537)

## Summary

The documentation gap remains: the README explains embedded/external differences through cache and client-side state, but not browser-engine versions or feature support. The reporter explicitly clarified that color-mix() was an example, so newer Chromium support does not complete this request.

## Change summary

Explain why embedded and external previews can support different web-platform features despite displaying the same served page.

## Best solution

Extend the README's existing rendering-differences FAQ to explain browser-engine and version differences, distinguishing the default Integrated Browser from the bundled webview fallback. Describe the dependency on the installed VS Code/browser environment rather than publishing a fixed Chromium or V8 version that will become outdated.
