# Issue #476 — [Feature request] Allow setting multiple preferred Server Roots as one string

[https://github.com/microsoft/vscode-livepreview/issues/476](https://github.com/microsoft/vscode-livepreview/issues/476)

## Summary

The current extension accepts only one server root, so the requested ordered fallback list remains a real gap. Keep the issue open because https://github.com/microsoft/vscode-livepreview/pull/581 directly implements it and remains open under maintainer review.

## Change summary

Allow `livePreview.serverRoot` to specify multiple preferred roots in priority order, including `.` for the open file's directory, with workspace-root fallback.

## Best solution

Review and resolve https://github.com/microsoft/vscode-livepreview/pull/581, settling the string-or-array setting format and the expected behavior when the selected root changes between files. Before landing it, address the reported connection-level root caching so `.` and file-dependent root selection do not keep serving the previous root.
