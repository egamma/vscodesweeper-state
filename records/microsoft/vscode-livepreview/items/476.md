# Issue #476 — [Feature request] Allow setting multiple preferred Server Roots as one string

[https://github.com/microsoft/vscode-livepreview/issues/476](https://github.com/microsoft/vscode-livepreview/issues/476)

## Summary

The requested capability is still absent from current main, and open PR https://github.com/microsoft/vscode-livepreview/pull/581 is an implementation candidate that explicitly references this issue. The issue must remain open while that PR is under review.

## Change summary

Allow `livePreview.serverRoot` to specify an ordered set of preferred roots, including `.` for the active file's directory, selecting the first available root and otherwise falling back to the workspace root.

## Best solution

Review and either land or close https://github.com/microsoft/vscode-livepreview/pull/581, ensuring the chosen configuration syntax is documented and covered by path utility tests for root ordering, `.`, invalid roots, files outside the workspace, and workspace-root fallback.

## Vision fit

- **Fit:** aligned
- **Reason:** Selecting among multiple server roots directly improves serving correctness for workspace layouts with several possible build-output directories.
- **Evidence:** The durable themes explicitly identify serving correctness and `livePreview.serverRoot` behavior as a long-standing area of investment.

- **open implementation PR:** Open PR https://github.com/microsoft/vscode-livepreview/pull/581 explicitly says it resolves this issue and changes the configuration to accept an array, selects the first existing root, and handles `.` as the active file's directory.
- **existing capability check:** No existing `livePreview.*` setting or command on current main provides an ordered set of fallback server roots; `livePreview.serverRoot` supports only one root.
