# Issue #489 — Support Remote Repositories

[https://github.com/microsoft/vscode-livepreview/issues/489](https://github.com/microsoft/vscode-livepreview/issues/489)

## Summary

Remote Repositories remains unsupported on current main: the manifest explicitly disables virtual workspaces and workspace content is still accessed through Node's filesystem APIs. This team-authored, On Deck feature request remains the canonical and best-diagnosed item for that work.

## Change summary

Allow Live Preview to serve and live-refresh HTML projects opened through Remote Repositories without requiring a local clone.

## Best solution

Add virtual-workspace support by carrying workspace resource URIs through the serving pipeline and using `vscode.workspace.fs` for user-workspace stat, read, and directory operations, while retaining native filesystem access for extension-owned resources such as the injected script. Validate the design with a non-`file` filesystem provider before changing `capabilities.virtualWorkspaces` to true.
