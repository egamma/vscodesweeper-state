# Issue #454 — Live preview reloads on editor changes even when not visible

[https://github.com/microsoft/vscode-livepreview/issues/454](https://github.com/microsoft/vscode-livepreview/issues/454)

## Summary

Keep open: the bundled preview's reload path still has no visibility check, so editor changes can reload an obscured preview. The Integrated Browser is now the default, but that does not fix the retained bundled-browser path; no verified canonical owns this specific defect.

## Change summary

Defer automatic reloads of a hidden embedded preview until it becomes visible again.

## Best solution

Make automatic refresh visibility-aware for the bundled preview while preserving ordinary refresh behavior for visible previews and external browsers, and bring the page up to date when revealed. Coordinate with https://github.com/microsoft/vscode-livepreview/issues/457, which discusses identifying embedded clients but does not replace this report's concrete hidden-tab defect.
