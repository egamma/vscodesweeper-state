# Issue #514 — Add custom field for browser path

[https://github.com/microsoft/vscode-livepreview/issues/514](https://github.com/microsoft/vscode-livepreview/issues/514)

## Summary

The requested executable-path capability remains absent on current main: external previews can select only Edge, Chrome, Firefox, or the system default. This team-authored On Deck issue is also the established canonical for several narrower browser-variant requests, so it should remain open.

## Change summary

Allow desktop users to configure an arbitrary browser executable path for normal external previews, including development or nightly browser variants.

## Best solution

Extend `livePreview.customExternalBrowser` or add a companion path setting in `package.json` and `src/utils/settingsUtil.ts`, then update `src/utils/externalBrowserUtils.ts` to launch that executable for normal desktop external previews while preserving the existing named-browser and system-default behavior.
