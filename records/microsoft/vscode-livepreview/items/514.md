# Issue #514 — Add custom field for browser path

[https://github.com/microsoft/vscode-livepreview/issues/514](https://github.com/microsoft/vscode-livepreview/issues/514)

## Summary

Keep this canonical, member-authored feature request open. Current main still limits external-browser selection to four predefined values, while related requests were explicitly consolidated into this issue.

## Change summary

Allow users to supply a browser executable path so external previews can open in browser variants such as Edge Dev, Chrome Canary, or Firefox Developer Edition.

## Best solution

Add a desktop-only custom executable-path setting alongside `livePreview.customExternalBrowser`, then update `src/utils/externalBrowserUtils.ts` to launch that executable for normal external previews while preserving the existing default-browser and named-browser behavior. The implementation should define cross-platform path handling and clarify whether custom executables participate in debug previews.

- **Reason:** Selecting a custom external browser extends an established preview destination without growing the bundled webview browser or turning the extension into an application server.
