# Issue #265 — Switching between single and multi-root will not properly handle panel

[https://github.com/microsoft/vscode-livepreview/issues/265](https://github.com/microsoft/vscode-livepreview/issues/265)

## Summary

Duplicate close gated off (the cited canonical #158839 is already closed — a duplicate close would strand the report; if the canonical's fix landed, an implemented-on-main close citing the fix commit is the right shape). Original assessment: This is the Live Preview manifestation of the open VS Code webview-lifecycle defect tracked by https://github.com/microsoft/vscode/issues/98603. Live Preview already disposes its bundled preview panel during deactivation, so the remaining work is entirely in VS Code core and this protected team-authored item can be closed as a verified factual duplicate.

## Change summary

Close or correctly restore the embedded preview panel when changing a single-folder workspace into a multi-root workspace restarts the extension host.

## Best solution

Resolve https://github.com/microsoft/vscode/issues/98603 so webview panels are not left detached when the extension host restarts during a single-root to multi-root transition. Live Preview already requests panel disposal during deactivation and has a serializer for restoration, so no additional extension-side change is identified.
