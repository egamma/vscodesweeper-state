# Issue #716 — Not running in Virtual Workspace?

[https://github.com/microsoft/vscode-livepreview/issues/716](https://github.com/microsoft/vscode-livepreview/issues/716)

## Summary

This is a support question about the virtual-workspace restriction, which Live Preview explicitly declares in its manifest. Explain what the warning means and how to open a local project on the Mac for previewing and debugging.

## Change summary

The reporter wants to understand the virtual-workspace warning and how to debug their web project on macOS.

## Best solution

Keep the declared virtual-workspace restriction and answer with a local-folder workflow: clone or download the project onto the Mac, open its folder in desktop VS Code, and use Live Preview's documented debug-preview command for a plain HTML/CSS/JavaScript project.

- **Proposed comment:**

  > Thanks for the question! A virtual workspace means VS Code is accessing files through a virtual filesystem, for example a GitHub repository opened without cloning it onto your Mac. Live Preview does not support that setup; the warning is not a macOS limitation.
  > 
  > Clone or download the project onto your Mac, then open the local project folder using **File > Open Folder…** in the desktop VS Code app. For a plain HTML/CSS/JavaScript project, open your HTML file and run **Live Preview: Show Debug Preview** from the Command Palette to preview it with browser debugging. This is documented at https://github.com/microsoft/vscode-livepreview/blob/main/README.md#external-browser-debugging.
