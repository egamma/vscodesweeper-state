## Summary

Extensionless HTML resolution remains missing from the current server, and an open PR explicitly targets this request. Keep the issue open while that implementation candidate is reviewed.

## Change summary

Add an option to resolve extensionless page URLs to corresponding HTML files instead of returning a file-not-found response.

## Best solution

Review https://github.com/microsoft/vscode-livepreview/pull/671, which proposes configurable extension fallback in the HTTP server. Resolve the requested URL semantics, including the report's trailing-slash example, while preserving existing exact-file and directory-index behavior.
