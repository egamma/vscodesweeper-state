# Issue #611 — Live Preview does not resolve file when html extension is not provided.

[https://github.com/microsoft/vscode-livepreview/issues/611](https://github.com/microsoft/vscode-livepreview/issues/611)

## Summary

Extensionless HTML resolution remains absent from current main, and open PR https://github.com/microsoft/vscode-livepreview/pull/671 explicitly implements the request and references this issue. The issue must remain open while that implementation candidate is under review.

## Change summary

Resolve an extensionless request such as `/page` to an existing `/page.html` file, preferably through a configurable extension allowlist.

## Best solution

Review and complete https://github.com/microsoft/vscode-livepreview/pull/671, including tests for successful extensionless resolution, unchanged 404 behavior, and precedence when the exact path exists. If configurability is retained, declare and document the proposed setting in `package.json` and `package.nls.json` before landing it.
