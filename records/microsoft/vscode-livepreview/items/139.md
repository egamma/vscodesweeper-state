# Issue #139 — Firefox support

[https://github.com/microsoft/vscode-livepreview/issues/139](https://github.com/microsoft/vscode-livepreview/issues/139)

## Summary

Firefox can now be selected for ordinary external previews, but current main still sends every debug preview through VS Code's js-debug command without honoring that browser selection. The central request for Firefox DevTools/debugging remains open and has no verified canonical issue.

## Change summary

Support launching and debugging Live Preview pages with Firefox and its developer tools.

## Best solution

Decide whether Firefox debugging belongs in Live Preview's external-preview integration or should be provided through a compatible VS Code debug adapter, then add an explicit debugger/browser selection rather than routing every debug launch through `extension.js-debug.debugLink`. Keep normal Firefox launching and Firefox debugging clearly distinguished in settings and documentation.
