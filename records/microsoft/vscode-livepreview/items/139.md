# Issue #139 — Firefox support

[https://github.com/microsoft/vscode-livepreview/issues/139](https://github.com/microsoft/vscode-livepreview/issues/139)

## Summary

Firefox is already selectable for ordinary external previews; the remaining request—using that browser for DevTools/debug previews—is fully tracked by the broader open issue https://github.com/microsoft/vscode-livepreview/issues/422, making this a duplicate.

## Change summary

Allow Live Preview to launch Firefox with browser DevTools and JavaScript debugging attached.

## Best solution

Consolidate the remaining work into https://github.com/microsoft/vscode-livepreview/issues/422 and make the debug-preview path honor `livePreview.customExternalBrowser`, including its Firefox option, rather than always invoking the generic js-debug debug-link command.

- **Fit:** aligned
- **Reason:** Selecting an external browser and attaching the JavaScript debugger are established Live Preview capabilities, so making them work together fits the extension's supported preview-opening surface.
- **Evidence:** The durable theme “Where the preview opens” explicitly includes the custom external browser and debug preview with the js-debug attach.

## Evidence

- **ordinary Firefox support exists:** `package.json` exposes Firefox under `livePreview.customExternalBrowser`, and `src/utils/externalBrowserUtils.ts` passes the selected browser to `js-debug-companion.launch`. - **debug path remains separate:** `src/editorPreview/previewManager.ts` lines 111-125 uses `extension.js-debug.debugLink` whenever `debug` is true and consults `livePreview.customExternalBrowser` only for a non-debug launch; `package.nls.json` likewise says the browser setting works only for normal, non-debug previews.
- **canonical open request:** Open feature request https://github.com/microsoft/vscode-livepreview/issues/422 explicitly asks for the debug preview to use `livePreview.customExternalBrowser`. Because Firefox is one of that setting's enumerated values, completing that issue would fully satisfy the remaining work here.
