# Issue #139 — Firefox support

[https://github.com/microsoft/vscode-livepreview/issues/139](https://github.com/microsoft/vscode-livepreview/issues/139)

## Summary

Firefox can now be selected for ordinary external previews, but that setting explicitly excludes debugging and does not fulfill the request for Firefox DevTools and debugger integration. Keep this accepted Backlog request open; no older open canonical owning that integration was found.

## Change summary

Support Firefox DevTools and debugging when previewing a project.

## Best solution

Decide whether Live Preview should integrate with a Firefox-capable debugger and developer-tools workflow, distinct from its existing Firefox preview launcher. Any adopted integration needs extension-side launch wiring in src/editorPreview/previewManager.ts; the existing js-debug command alone does not establish Firefox support.

- **Evidence:** The durable theme 'Where the preview opens' includes the custom external browser and external preview debugging; README.md documents external-browser debugging as an existing product capability.

## Evidence

It is labeled feature-request and assigned to Backlog, with no maintainer decline or linked implementation in the supplied discussion.
- **Existing setting provides partial coverage:** package.json contributes livePreview.customExternalBrowser with Firefox as an option. package.nls.json explicitly describes this setting as working only for normal, non-debug preview on desktop; livePreview.debugOnExternalPreview enables JavaScript debugging but provides no Firefox debugger selection.
- **Current launch-path boundary:** src/editorPreview/previewManager.ts:120-125 routes debug launches to extension.js-debug.debugLink with only the URL. Only the non-debug branch calls ExternalBrowserUtils.openInBrowser with customExternalBrowser; src/utils/externalBrowserUtils.ts:16-18 forwards that selection to js-debug-companion.launch. The Firefox browser selection therefore does not control the debug launch.
- **Documented debugging integration:** README.md, 'External Browser Debugging', documents the built-in js-debug extension and the Edge Devtools Extension, but does not document Firefox debugger or DevTools integration.
