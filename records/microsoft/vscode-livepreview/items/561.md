[https://github.com/microsoft/vscode-livepreview/issues/561](https://github.com/microsoft/vscode-livepreview/issues/561)

## Summary

The thread confirms a historical bundled-browser failure where the server ran and its URL worked externally but no embedded tab opened. However, the latest confirmation predates Live Preview 0.4.17 and the current default Integrated Browser path, so a current-version retest is needed before the remaining failure can be located.

## Change summary

Starting an internal preview can leave the server running without opening any preview tab or reporting an actionable error.

## Best solution

Retest with current VS Code and Live Preview 0.4.20 using `livePreview.useIntegratedBrowser` both at its default `true` and explicitly `false`. If only the bundled browser fails, investigate panel creation in `src/editorPreview/previewManager.ts`; if only the Integrated Browser fails, the remaining defect likely belongs to `microsoft/vscode`'s browser integration.
