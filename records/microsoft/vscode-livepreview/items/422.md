# Issue #422 — `Live Preview: Show Debug Preview (External Browser)` doesn't respect `livePreview.customExternalBrowser`

[https://github.com/microsoft/vscode-livepreview/issues/422](https://github.com/microsoft/vscode-livepreview/issues/422)

## Summary

The requested integration remains absent on current main: normal external previews use `livePreview.customExternalBrowser`, while debug previews bypass it and invoke js-debug with only the URL. This team-authored Backlog feature should remain open until the debug-launch path can honor the configured browser or the supported behavior is explicitly reconsidered.

## Change summary

Make `Live Preview: Show Debug Preview (External Browser)` launch and debug using the browser selected by `livePreview.customExternalBrowser`.

## Best solution

Update the external debug-launch integration in `src/editorPreview/previewManager.ts` to translate the configured browser into a js-debug-supported launch request, with explicit handling for `Default` when the operating-system default is not directly debuggable. Extend `src/test/suite/preview.test.ts` to verify that the selected browser reaches the debug command without changing normal external-preview behavior.
