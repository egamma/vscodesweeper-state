# Issue #422 — `Live Preview: Show Debug Preview (External Browser)` doesn't respect `livePreview.customExternalBrowser`

[https://github.com/microsoft/vscode-livepreview/issues/422](https://github.com/microsoft/vscode-livepreview/issues/422)

## Summary

Current `main` still sends debug previews directly to js-debug without passing `livePreview.customExternalBrowser`, while normal external previews honor the setting. This is a confirmed, team-authored feature gap with no canonical issue or implementing change, so it should remain open.

## Change summary

Make external debug previews honor the browser selected by `livePreview.customExternalBrowser`, including the system-default selection.

## Best solution

Extend the debug launch path in `src/editorPreview/previewManager.ts` to translate the configured browser into a js-debug launch that supports the selected or default executable, while retaining debugger attachment and useful launch errors. Update the external-preview tests to verify each supported browser selection; https://github.com/microsoft/vscode-livepreview/issues/506 concerns `launch.json` and F5 integration and does not own this setting-specific work.
