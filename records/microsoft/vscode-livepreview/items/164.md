## Summary

VS Code core implemented this request by adding Live Preview to the `workbench.editor.autoLockGroups` configuration and enabling auto-lock for its editor type by default. The implementation remains present on current VS Code main, so the request can be closed as completed.

## Change summary

Allow Live Preview editor groups to be selected for automatic locking through `workbench.editor.autoLockGroups`.

## Best solution

Retain the shipped VS Code core registration for `mainThreadWebview-browserPreview`; no change is needed in this extension because editor-group locking and the setting's editor list are owned by the VS Code workbench.
