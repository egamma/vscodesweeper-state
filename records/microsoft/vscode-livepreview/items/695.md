# Issue #695 — Enable Auto-Preview on File Switch

[https://github.com/microsoft/vscode-livepreview/issues/695](https://github.com/microsoft/vscode-livepreview/issues/695)

## Summary

This request is fully owned by the older open feature request https://github.com/microsoft/vscode-livepreview/issues/530, which asks Live Preview to follow the active HTML editor automatically; close this issue as a duplicate so the discussion remains consolidated.

## Change summary

Add an option that automatically opens or updates Live Preview to show the HTML file in the currently active editor.

## Best solution

Track the behavior in https://github.com/microsoft/vscode-livepreview/issues/530 and implement an opt-in active-editor-follow mode that updates a reusable preview when focus moves to another HTML file while retaining the most recent HTML preview during CSS or JavaScript editing.
