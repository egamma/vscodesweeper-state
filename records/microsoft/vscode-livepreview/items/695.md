## Summary

This request is already tracked by the older open issue https://github.com/microsoft/vscode-livepreview/issues/530, which asks Live Preview to follow the active HTML editor automatically. The additional suggestion to retain the most recently viewed HTML page while editing CSS or JavaScript is compatible detail for that canonical request.

## Change summary

Add an option for the preview to follow the active HTML file automatically when the user switches editor tabs.

Consolidate the use cases in https://github.com/microsoft/vscode-livepreview/issues/530 and define the behavior for both HTML tab switches and temporary focus on related CSS or JavaScript files; implementation would likely belong in the preview/editor event handling rather than the server.
