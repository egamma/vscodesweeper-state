# Issue #256 — Consider changing default time for server to turn off to be instant

[https://github.com/microsoft/vscode-livepreview/issues/256](https://github.com/microsoft/vscode-livepreview/issues/256)

## Summary

The requested immediate-shutdown behavior remains unavailable on current main: the default delay is still three minutes, while zero explicitly means keeping the server alive indefinitely. This team-authored Backlog feature request is still necessary and is protected from a judgment close.

## Change summary

Make the server stop immediately by default when the embedded preview closes, and provide a clear way to select immediate shutdown.

## Best solution

Define an unambiguous immediate-shutdown value for `livePreview.serverKeepAliveAfterEmbeddedPreviewClose` in `package.json` and implement it in `src/editorPreview/previewManager.ts`, while preserving or deliberately migrating the existing zero-means-indefinite behavior. The default and compatibility implications need a maintainer product decision.
