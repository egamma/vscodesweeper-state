# Issue #256 — Consider changing default time for server to turn off to be instant

[https://github.com/microsoft/vscode-livepreview/issues/256](https://github.com/microsoft/vscode-livepreview/issues/256)

## Summary

The requested immediate-shutdown default remains unimplemented: the setting still defaults to three minutes, while zero intentionally means keeping the server alive indefinitely. This team-authored Backlog feature request requires a product decision and is protected from a judgment close.

## Change summary

Make the server shut down immediately by default when the bundled embedded preview closes, with a way to select immediate shutdown explicitly.

## Best solution

Define an explicit immediate-shutdown value or mode without repurposing the documented `0 = indefinitely` behavior, then decide whether it should become the default for the bundled preview path. The implementation belongs in the `livePreview.serverKeepAliveAfterEmbeddedPreviewClose` configuration and `src/editorPreview/previewManager.ts`, with lifecycle tests covering immediate, delayed, and indefinite shutdown.
