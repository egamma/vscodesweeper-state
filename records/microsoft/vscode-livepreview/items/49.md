# Issue #49 — [ Question ] What about PHP files preview?

## Summary

Keep this as the canonical PHP-support request: the capability remains absent, and maintainers explicitly consolidated two later reports here. Its Backlog milestone and continuing demand support retaining it pending a scope decision, not declining it for age.

## Change summary

Support previewing the rendered output of PHP projects rather than serving PHP files without server-side execution.

## Best solution

Decide whether PHP support should integrate with a separately running PHP server or introduce runtime management into Live Preview, while preserving the existing static-server workflow. Keep this issue as the discussion point; opening a PHP server's URL in the Integrated Browser is an alternative workflow, not implementation of this extension-side request.
