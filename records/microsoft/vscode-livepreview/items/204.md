# Issue #204 — Add ignore file for injected script

[https://github.com/microsoft/vscode-livepreview/issues/204](https://github.com/microsoft/vscode-livepreview/issues/204)

## Summary

Keep open: current source still injects scripts into unopened extensionless files, and no shipped setting provides the requested path-based exclusion and MIME override. The related reload-ignore request addresses a different behavior; the newer matching injection report cannot supersede this older, re-reviewed item.

## Change summary

Allow project-level path rules to serve extensionless data files without script injection and optionally specify their response MIME type.

## Best solution

Define a project-scoped injection-exclusion and MIME-override contract in the settings and server content-loading path, preserving extensionless HTML previewing outside explicitly configured rules. Keep this issue as the older request and relate the matching report at https://github.com/microsoft/vscode-livepreview/issues/702; reload-watcher exclusions remain separate work.

- **Current injection behavior:** src/utils/utils.ts:isFileInjectable explicitly treats files without extensions as injectable. In src/server/serverUtils/contentLoader.ts:getFileStream, the disk-file branch at lines 327–337 calls that helper and injects the script; a file containing only 1.653 therefore receives a script prefix. The open-document branch instead injects only when languageId is html, explaining the reporter's temporary plaintext workaround.
- **Existing capabilities do not cover the request:** package.json contributes.configuration and contributes.commands, with descriptions in package.nls.json, expose no path-based injection exclusion or MIME mapping. livePreview.autoRefreshPreview controls refresh frequency, and media/injectScript.js:reloadPage checks data-server-no-reload only after injection. livePreview.httpHeaders supplies extra response headers, not a per-path rule that prevents response-body injection.
- **Related request is not a canonical:** https://github.com/microsoft/vscode-livepreview/issues/548 is open and was created on 2023-09-08, after this issue. Its body requests exclusion of changed files from reload triggering through the workspace watcher; implementing it would not prevent scripts being inserted into fetched data. The maintainer's link at https://github.com/microsoft/vscode-livepreview/issues/548#issuecomment-1846216022 marks the relationship, not duplicate ownership.
