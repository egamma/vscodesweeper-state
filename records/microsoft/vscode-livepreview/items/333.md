# Issue #333 — Allow setting host IP to 0.0.0.0

[https://github.com/microsoft/vscode-livepreview/issues/333](https://github.com/microsoft/vscode-livepreview/issues/333)

## Summary

Keep open: the recent 0.4.20 reproduction and current source confirm that wildcard binding does not provide working access through interface addresses. Non-loopback exposure and Host/Origin authorization make this security-sensitive, requiring human review rather than closure or agent implementation.

## Change summary

Make livePreview.hostIP set to 0.0.0.0 support previewing and live refresh through the machine's available network interfaces.

## Best solution

A maintainer should define safe wildcard-host support across HTTP authorization, browser-facing URL construction, and WebSocket origins in src/server/ and src/connectionInfo/. The end state should support LAN preview and live refresh without weakening existing request protections; accepting HTTP requests alone does not complete the request.
