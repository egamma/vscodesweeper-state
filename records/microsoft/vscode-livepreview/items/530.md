# Issue #530 — [Feature request] Auto preview active opened file

[https://github.com/microsoft/vscode-livepreview/issues/530](https://github.com/microsoft/vscode-livepreview/issues/530)

## Summary

Keep this accepted Backlog feature request open for editor/preview synchronization. A maintainer explicitly accepted preview-following-editor and potentially editor-following-preview while excluding non-HTML preview, and current main still lacks the accepted synchronization behavior.

## Change summary

Optionally keep the preview synchronized with the active HTML editor and provide a way to reveal the previewed document in the editor; the original report also requested configurable non-HTML preview support.

## Best solution

Add an opt-in editor/preview synchronization mode that navigates the active Live Preview tab when the user switches between previewable HTML editors, without creating focus or navigation loops. Evaluate reverse synchronization separately for VS Code's default Integrated Browser; non-HTML preview should remain outside this issue's implementation scope per the maintainer decision.
