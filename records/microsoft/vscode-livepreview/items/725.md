# Issue #725 — Add https server config

[https://github.com/microsoft/vscode-livepreview/issues/725](https://github.com/microsoft/vscode-livepreview/issues/725)

## Summary

Live Preview does not currently expose HTTPS certificate and key configuration, so the requested capability remains unimplemented. HTTPS pushes beyond the extension's current static HTTP-server scope, but there is no established maintainer decision declining it, so it should remain open for a product and security design decision.

## Change summary

Allow the Live Preview server to serve over HTTPS using configurable certificate and private-key files or another HTTPS-enablement mechanism.

## Best solution

Decide whether HTTPS belongs in the server surface, then design it in `src/server/` and the `livePreview.*` configuration with explicit certificate/key validation, clear startup errors, and compatibility with external URLs, WebSockets, remote port forwarding, and both preview implementations. The design should avoid copying the unrelated `liveServer.settings.*` schema and should receive security review before implementation.
