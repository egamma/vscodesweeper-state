[https://github.com/microsoft/vscode-livepreview/issues/725](https://github.com/microsoft/vscode-livepreview/issues/725)

## Summary

Configurable local HTTPS remains missing on current main, and no verified canonical owns this request. Keep it open for a maintainer scope decision; the Live Server configuration is an example of the desired capability, not evidence of a misfile.

## Change summary

Allow Live Preview's local server to serve HTTPS using user-provided certificates and private keys or another configurable TLS mechanism.

## Best solution

Decide whether optional local TLS belongs in Live Preview's server scope. If accepted, certificate configuration, server startup, preview URL construction and live-reload connections must work together; switching to the Integrated Browser alone does not provide local HTTPS.
