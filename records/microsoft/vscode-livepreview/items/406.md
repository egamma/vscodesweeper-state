# Issue #406 — Server Logging for Non-workspace files

[https://github.com/microsoft/vscode-livepreview/issues/406](https://github.com/microsoft/vscode-livepreview/issues/406)

## Summary

Current main still silently returns when Start Server Logging is invoked for a file outside every workspace, exactly matching this team-authored feature request. No broader open canonical or implementing commit was found, so the accepted On Deck item should remain open.

## Change summary

Make Start Server Logging support files outside the workspace, or display an explicit error explaining that logging is unavailable.

## Best solution

Update the logging command path in `src/manager.ts` to either launch the existing global server task for the loose-file server grouping or show a clear VS Code error message when that cannot be done. Add coverage for invoking `runTaskForFile` with an out-of-workspace URI.

- **Fit:** aligned
- **Reason:** Making server logging reliable for loose files strengthens the extension's server lifecycle and configuration experience without expanding it into an application server.
- **Evidence:** The durable themes explicitly include the `Live Preview` server-logging task under server lifecycle and configuration, while serving correctness includes files outside the workspace.
