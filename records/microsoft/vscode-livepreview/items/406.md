# Issue #406 — Server Logging for Non-workspace files

[https://github.com/microsoft/vscode-livepreview/issues/406](https://github.com/microsoft/vscode-livepreview/issues/406)

## Summary

The logging command still returns silently for an out-of-workspace file, so the requested logging support or explanatory message remains missing. This maintainer-authored On Deck request should stay open; no verified canonical or open implementation PR was found.

## Change summary

Make Start Server Logging either provide logging for non-workspace files or explain why logging cannot start.

## Best solution

Ensure livePreview.runServerLoggingTask gives a meaningful outcome for loose files rather than silently returning. Decide whether that outcome is supported loose-file logging or an explicit limitation message, then cover it in the manager tests while preserving workspace logging.
