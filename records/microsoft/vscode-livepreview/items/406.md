## Summary

The requested feedback or logging for files outside a workspace remains absent on current main. This team-authored feature request should remain open, and no separate canonical issue or implementation PR was found.

## Change summary

Make the Start Server Logging command support non-workspace files, or display an explicit error instead of silently doing nothing.

## Best solution
