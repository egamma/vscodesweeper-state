# Issue #112 — Allow to view multiple items the history in embedded browser

[https://github.com/microsoft/vscode-livepreview/issues/112](https://github.com/microsoft/vscode-livepreview/issues/112)

## Summary

The bundled browser still records multiple history entries but only supports one-step back and forward clicks, so the requested history menu remains unimplemented. This team-authored Backlog item has no verified duplicate or issue-linked implementing commit and must remain open pending a product decision about the legacy bundled browser.

## Change summary

Allow users to long-press the bundled embedded browser's back or forward button and select from multiple navigation-history entries.

## Best solution

Decide whether this browser-style history menu remains appropriate now that the Integrated Browser is the default. If the bundled fallback remains supported at this level, expose its stored PageHistory entries and add an accessible selection menu to the navigation controls; otherwise the maintainers should explicitly resolve the feature's scope.
