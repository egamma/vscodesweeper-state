# Issue #112 — Allow to view multiple items the history in embedded browser

[https://github.com/microsoft/vscode-livepreview/issues/112](https://github.com/microsoft/vscode-livepreview/issues/112)

## Summary

The requested history menu remains absent from the bundled browser on current main, and no open canonical issue owns the same work. This team-authored Backlog item must remain open while maintainers decide whether the off-by-default bundled browser should gain the feature or defer entirely to VS Code's Integrated Browser.

## Change summary

Show the embedded browser's navigation history in a menu when the Back or Forward button is held.

## Best solution

First verify whether VS Code's Integrated Browser provides or should provide this navigation-history UI, since it is now the default embedded preview. Only add a history menu around `PageHistory` in `src/editorPreview/` and `media/main.js` if maintainers intend to keep expanding the legacy bundled browser.
