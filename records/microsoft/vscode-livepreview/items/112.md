# Issue #112 — Allow to view multiple items the history in embedded browser

[https://github.com/microsoft/vscode-livepreview/issues/112](https://github.com/microsoft/vscode-livepreview/issues/112)

## Summary

The bundled browser still lacks the requested long-press history menu; switching the default to the Integrated Browser does not implement it. Keep this team-authored Backlog request open pending a maintainer decision about the legacy browser surface; no qualifying canonical was found.

## Change summary

Allow holding the embedded browser's back or forward button to display navigation history and select an entry directly.

## Best solution

Determine whether this interaction should be supported in the retained bundled browser or pursued in microsoft/vscode's Integrated Browser under browser-integration. The default preview's navigation UI belongs to core, but that migration is not evidence that the original bundled-browser request is complete.

## Vision fit

- **Fit:** rejected
- **Reason:** Adding navigation UI to the bundled browser runs against the direction of delegating embedded browsing to VS Code's Integrated Browser.
- **Evidence:** Layer 1: "The server is the product; the browser is increasingly VS Code's." The vision explicitly places bundled-browser expansion against that direction.
