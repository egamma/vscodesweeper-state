## Summary

Current source still reproduces the reported malformed external-preview URL when the resolved server root retains a trailing separator. This is a clear, localized Live Preview defect that should remain open and be classified as a bug.

## Change summary

Ensure an external-browser preview path retains its leading slash when `livePreview.serverRoot` ends with a slash.

## Best solution

Normalize the result of `Connection.getFileRelativeToWorkspace` so every served workspace-relative path begins with `/`, then add a trailing-server-root regression case to `src/test/suite/connectionInfo.test.ts`. Keep this older, concrete report as the canonical issue for the missing-slash defect; the separate absolute-URL problem bundled into https://github.com/microsoft/vscode-livepreview/issues/840 should be tracked independently.
