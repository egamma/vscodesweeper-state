# Issue #149 — New feature request: select element 

[https://github.com/microsoft/vscode-livepreview/issues/149](https://github.com/microsoft/vscode-livepreview/issues/149)

## Summary

Keep this accepted feature request open: selecting a rendered element and selecting its HTML in the editor is deeper integration than the existing DevTools commands provide. Maintainer comments identify this issue as the tracking home, and the verified related open requests are newer rather than eligible canonicals for this re-review.

## Change summary

Allow selecting an element in the preview to reveal and select its corresponding HTML source in the VS Code editor.

## Best solution

Retain this issue as the source-selection request and assess an Integrated Browser integration in microsoft/vscode rather than adding another inspector to the bundled browser. Distinguish core-owned element picking from any extension-side mapping between served URLs, workspace files, and source locations; a browser inspector alone does not satisfy the request.
