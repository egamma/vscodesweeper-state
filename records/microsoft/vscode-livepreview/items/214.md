# Issue #214 — Follow along scroll?

[https://github.com/microsoft/vscode-livepreview/issues/214](https://github.com/microsoft/vscode-livepreview/issues/214)

## Summary

This remains the canonical feature request for synchronizing the HTML editor and preview; current settings and code provide live reload and find-in-page, but no editor-to-preview scrolling or bidirectional selection mapping. The Backlog milestone and existing feature-request label are appropriate.

## Change summary

Synchronize scrolling and text or element selection between the HTML editor and its live preview.

## Best solution

Define the desired behavior across the default Integrated Browser, the legacy bundled preview, and external browsers, then add source-position mapping and editor synchronization in the extension where feasible. Any Integrated Browser API needed to reveal or identify page elements would require coordination with microsoft/vscode, but no matching open core issue currently owns the complete request.
