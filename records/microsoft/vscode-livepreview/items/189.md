# Issue #189 — Video not loading in Safari due to missing byte-range support

[https://github.com/microsoft/vscode-livepreview/issues/189](https://github.com/microsoft/vscode-livepreview/issues/189)

## Summary

Keep open: current source still ignores HTTP Range requests and streams the complete video with status 200. The server-side protocol gap is directly traceable; the Safari playback symptom was not executed.

## Change summary

Videos served by Live Preview fail to load in Safari because the server does not support byte-range responses.

## Best solution

Support byte-range requests for video resources in src/server/httpServer.ts and src/server/serverUtils/contentLoader.ts, preserving existing file-access restrictions and ordinary full-file responses. Verify partial-response status, headers, and exact response bytes, followed by Safari playback and seeking.
