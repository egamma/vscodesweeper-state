# Issue #855 — Live Preview generates incorrect directory index URLs using encoded backslashes (%5Cfolder%5Cpath)

[https://github.com/microsoft/vscode-livepreview/issues/855](https://github.com/microsoft/vscode-livepreview/issues/855)

## Summary

The Windows directory-index URL defect remains in current source. Keep this issue open while the explicitly linked implementation candidate is reviewed; PR https://github.com/microsoft/vscode-livepreview/pull/856 is still open and has not delivered a fix.

## Change summary

Directory-index links on Windows encode native backslashes as %5C, producing broken URLs with repeated directory segments.

## Best solution

Review https://github.com/microsoft/vscode-livepreview/pull/856 to ensure directory-index hrefs use URL separators while filesystem paths retain native separators, with regression validation that actually exercises Windows behavior. Keep this issue as the linked reproduction until the implementation lands.

For the reported /apps and folder inputs, Windows produces %5Capps%5Cfolder rather than /apps/folder, matching the reported failure. This is server-generated HTML, not an Integrated Browser rendering defect.

Current main still contains the original URL-path join. The proposed test uses the host platform's path module, so running it only on a non-Windows host would not demonstrate the original failure.
