# Issue #855 — Live Preview generates incorrect directory index URLs using encoded backslashes (%5Cfolder%5Cpath)

[https://github.com/microsoft/vscode-livepreview/issues/855](https://github.com/microsoft/vscode-livepreview/issues/855)

## Summary

The Windows directory-index failure is directly traceable in current source: a URL path is joined with the platform-native `path.join`, producing backslashes that `encodeURI` converts to `%5C`. Keep the issue open because the linked fix in https://github.com/microsoft/vscode-livepreview/pull/856 is still under review.

## Change summary

Generate directory-index links with URL-compatible forward slashes so nested folders remain navigable on Windows.

## Best solution

Review and land https://github.com/microsoft/vscode-livepreview/pull/856, which changes only the URL-path join in `ContentLoader.createIndexPage` to `path.posix.join` while preserving native joining for filesystem paths, and adds a regression test. Once merged and verified, the issue can be closed as completed with that merge commit.

## Evidence

- **source-traced defect:** `src/server/serverUtils/contentLoader.ts` in `ContentLoader.createIndexPage` builds `relativeFileWithChild` with `path.join(relativePath, childFile)` and then applies `encodeURI`; on Windows the native join introduces backslashes, which become `%5C` in generated directory and file hrefs.
- **filesystem and URL paths conflated:** The adjacent `absolutePath = path.join(readPath, childFile)` correctly represents a filesystem path, but `relativeFileWithChild` represents a URL path and therefore must use POSIX separators independently of the host OS.
- **open implementation PR:** https://github.com/microsoft/vscode-livepreview/pull/856 explicitly fixes #855 by switching the URL-path expression to `path.posix.join` and adds `src/test/suite/contentLoader.test.ts`; the PR is currently open, so the issue must remain open.
- **same observed cluster:** The report's `%5C` symptom is also documented in the still-open https://github.com/microsoft/vscode-livepreview/issues/762 and https://github.com/microsoft/vscode-livepreview/issues/795, and the linked PR identifies all three as the same root cause.
