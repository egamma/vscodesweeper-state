# Issue #494 — [Feature Request] Add "Toggle Device Toolbar" to the options

[https://github.com/microsoft/vscode-livepreview/issues/494](https://github.com/microsoft/vscode-livepreview/issues/494)

## Summary

The older, open responsive-layout request already owns device-size controls and a responsive-mode toggle for the embedded preview, so this narrower request should be consolidated there. Current default previews also use VS Code's Integrated Browser, which now provides its own device-emulation toolbar.

## Change summary

Add a device toolbar to the embedded preview so users can test pages at different viewport and device sizes without opening an external browser.

## Best solution

Track any remaining extension-side responsive-preview work in https://github.com/microsoft/vscode-livepreview/issues/116 rather than maintaining a second request. For the default Integrated Browser path, retain VS Code core's existing emulation toolbar instead of duplicating browser tooling in this extension.

## Vision fit

- **Fit:** rejected
- **Reason:** Expanding the bundled preview's DevTools conflicts with the direction of relying on VS Code's Integrated Browser for browser UI and emulation capabilities.
- **Evidence:** The vision states that "the server is the product; the browser is increasingly VS Code's" and identifies the bundled webview as a fallback rather than the future embedded-preview surface.
