# Issue #494 — [Feature Request] Add "Toggle Device Toolbar" to the options

[https://github.com/microsoft/vscode-livepreview/issues/494](https://github.com/microsoft/vscode-livepreview/issues/494)

## Summary

Device-size previewing is now implemented in VS Code's Integrated Browser, which current Live Preview uses by default. The actual browser-emulation implementation delivers the requested responsive-testing workflow without opening an external browser; this conclusion does not rely on the browser-default switch alone.

## Change summary

Provide an embedded device toolbar so users can preview their pages at different device sizes without switching to an external browser.

## Best solution

Use the Integrated Browser's Show Emulation Toolbar action for device presets and adjustable viewport dimensions, keeping livePreview.useIntegratedBrowser enabled. Treat the central request as implemented by https://github.com/microsoft/vscode/commit/46050be407ed64db2763d0c47d028a4f83b31390 rather than adding a second device toolbar to the legacy bundled browser.
