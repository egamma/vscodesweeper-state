# Issue #494 — [Feature Request] Add "Toggle Device Toolbar" to the options

[https://github.com/microsoft/vscode-livepreview/issues/494](https://github.com/microsoft/vscode-livepreview/issues/494)

## Summary

The open feature request https://github.com/microsoft/vscode-livepreview/issues/116 already owns responsive device-size controls for the embedded preview, including a proposed toggle and presets; this report requests the same user outcome through the DevTools device toolbar and can be consolidated there.

## Change summary

Add device emulation controls to the embedded preview so developers can inspect pages at mobile and tablet viewport sizes without opening an external browser.

## Best solution

Track the bundled-preview responsive-controls request in https://github.com/microsoft/vscode-livepreview/issues/116, carrying over this report's preference for integration with the DevTools device toolbar. For the default Integrated Browser path, retain VS Code core's existing `Emulate Device...` capability rather than adding another browser-emulation implementation to this extension.

## Vision fit

- **Fit:** rejected
- **Reason:** Adding browser-device tooling to the extension's legacy bundled webview conflicts with the direction of relying on VS Code's Integrated Browser for browser UI and capabilities.
- **Evidence:** The vision states that "the server is the product; the browser is increasingly VS Code's" and that requests to grow the bundled webview browser run against the direction.
