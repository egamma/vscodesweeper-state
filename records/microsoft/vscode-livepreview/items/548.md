# Issue #548 — Create `ignore` setting for livepreview auto-reloading

[https://github.com/microsoft/vscode-livepreview/issues/548](https://github.com/microsoft/vscode-livepreview/issues/548)

## Summary

The configurable ignore capability remains absent from current main, while the file-system watcher still observes every workspace path. This team-authored Backlog item is the canonical request maintainers have used for unwanted reloads caused by paths such as `.git`, so it should remain open.

## Change summary

Add a configurable set of file or directory patterns that do not trigger Live Preview auto-reloads, with `.git` considered as a default exclusion.

## Best solution

Add a documented `livePreview.*` exclusion setting and apply it in `src/updateListener.ts` to suppress matching watcher events, including a deliberate decision about safe defaults such as `.git`. Preserve reloads for potentially relevant files outside the configured server root because the extension cannot infer all page dependencies.
