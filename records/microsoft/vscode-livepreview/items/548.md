# Issue #548 — Create `ignore` setting for livepreview auto-reloading

[https://github.com/microsoft/vscode-livepreview/issues/548](https://github.com/microsoft/vscode-livepreview/issues/548)

## Summary

This team-authored Backlog item remains the broad canonical request for configurable auto-refresh exclusions. The related reports cover narrower symptoms such as `.git` changes or edits outside the server root, while this issue owns the general ignore-setting behavior and has not been superseded by an existing capability.

## Change summary

Add configurable file or folder exclusions so workspace changes matching ignored patterns do not trigger Live Preview auto-reloads.

## Best solution

Keep this issue as the canonical feature request and add a `livePreview.*` exclusion setting whose glob patterns are applied by the update-listener watcher, with sensible treatment of generated or metadata directories such as `.git`. The implementation should preserve the existing `livePreview.autoRefreshPreview` modes and add watcher-focused tests for ignored versus relevant file changes.
