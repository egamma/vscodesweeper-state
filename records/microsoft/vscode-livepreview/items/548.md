# Issue #548 — Create `ignore` setting for livepreview auto-reloading

[https://github.com/microsoft/vscode-livepreview/issues/548](https://github.com/microsoft/vscode-livepreview/issues/548)

## Summary

Keep this accepted feature request open: current main still lacks configurable reload exclusions, and maintainers explicitly consolidated the outside-root and .git reports here. Existing refresh controls do not provide selective path filtering.

## Change summary

Allow configurable file and directory exclusions from automatic preview reloads, including ignoring .git by default.

## Best solution

Provide a documented reload-ignore setting in the extension's update-listener and configuration surfaces, with a configurable default excluding .git as already endorsed by the maintainer. Define pattern matching and workspace scope while preserving live refresh for non-excluded files; this concerns extension-generated refresh events, not Integrated Browser rendering.

## Vision fit

- **Fit:** aligned
- **Reason:** Selective reload exclusions improve the extension's core live-refresh behavior without expanding it into an application server or browser implementation.
- **Evidence:** The vision's durable Live refresh theme explicitly includes which edits should trigger refresh, and its product promise includes refreshing served pages as files change.
