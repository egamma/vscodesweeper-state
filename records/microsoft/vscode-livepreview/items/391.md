# Issue #391 — Place cursor from preview in editor

[https://github.com/microsoft/vscode-livepreview/issues/391](https://github.com/microsoft/vscode-livepreview/issues/391)

## Summary

This remains a valid feature request, but the requested preview-to-source interaction is primarily browser UI behavior rather than a local-server capability. The Backlog milestone does not justify closing it, and the related issue mentioned in the discussion does not establish a canonical duplicate.

## Change summary

Add a preview interaction, such as a context-menu action, that reveals the corresponding HTML element or text and places the editor cursor at its source location.

## Best solution

Define the source-mapping contract needed to associate rendered DOM nodes with workspace source locations, then pursue the user-facing inspect/reveal action in VS Code's Integrated Browser while retaining only the minimal extension-side metadata or URL integration needed to support it. Issue https://github.com/microsoft/vscode-livepreview/issues/149 may be complementary, but should absorb this request only if it is confirmed to own the complete preview-to-editor workflow.
