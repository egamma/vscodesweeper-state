# Issue #9265 — Now that VSCode ask projects to work within devcontainer, we need VSCode workspace to support opening many projects using devcontainer.

[https://github.com/microsoft/vscode-remote-release/issues/9265](https://github.com/microsoft/vscode-remote-release/issues/9265)

## Summary

Verified duplicate: the open canonical issue already tracks using multiple Dev Containers concurrently for folders in one multi-root VS Code window.

## Change summary

Allow each folder in a multi-root workspace to use its own Dev Container, terminal, and extension environment within one VS Code window.

## Best solution

Consolidate this request under https://github.com/microsoft/vscode-remote-release/issues/1460. The Containers component should design concurrent per-folder container contexts there, including this report's request to follow the active editor when selecting terminals and extension environments.
