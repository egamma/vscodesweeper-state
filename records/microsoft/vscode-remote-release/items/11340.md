# Issue #11340 — Disable executables installed over SSH

[https://github.com/microsoft/vscode-remote-release/issues/11340](https://github.com/microsoft/vscode-remote-release/issues/11340)

## Summary

Remote - SSH intentionally installs and runs VS Code Server; it cannot provide its integrated filesystem and terminal experience without that backend. A server-free mode conflicts with the documented architecture.

## Change summary

Provide an SSH mode that exposes remote files and terminals without installing or running VS Code Server.

## Best solution

Keep the current Remote - SSH architecture; users requiring plain SSH without remote executables should use an SSH client rather than Remote - SSH.

## Vision fit

- **Fit:** rejected
- **Reason:** The requested server-free mode conflicts with the established client-server architecture used to deliver the remote VS Code experience.
- **Evidence:** The vision identifies the client-server architecture as settled, while the Remote - SSH documentation states that the extension installs VS Code Server on the remote OS.
