# Issue #7799 — Environment variable is not set in container only when Developing inside a Container

[https://github.com/microsoft/vscode-remote-release/issues/7799](https://github.com/microsoft/vscode-remote-release/issues/7799)

## Summary

The reported loss of explicitly empty variables in container terminals is covered by a public VS Code fix shipped in 1.77.0. The changed environment-merging helper runs on the remote server's terminal-creation path, matching the maintainer's diagnosis.

## Change summary

Preserve Docker Compose environment variables with empty values when opening an integrated terminal in a dev container.

## Best solution

Treat this terminal-environment defect as resolved by the shipped VS Code core fix; no Dev Containers configuration change is required.
