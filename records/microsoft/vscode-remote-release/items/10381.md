# Issue #10381 — Devcontainer: USERPROFILE Path Issues When Cloning into Volumes

[https://github.com/microsoft/vscode-remote-release/issues/10381](https://github.com/microsoft/vscode-remote-release/issues/10381)

## Summary

Keep open as a Rancher Desktop integration issue: the reporter supplied configuration, logs, and a working Linux-path workaround. The linked upstream discussion does not establish that this volume-cloning failure is resolved or fully owned by its PowerShell quoting problem.

## Change summary

Windows USERPROFILE paths fail as AWS configuration bind mounts when cloning a Dev Container repository into a volume with Rancher Desktop.

## Best solution

The Dev Containers and Rancher Desktop owners should establish where Windows-to-Linux bind-path translation belongs for the bootstrap-container workflow, then make the portable configuration work without a hard-coded /mnt/c path. Keep this report available until that integration behavior is resolved.
