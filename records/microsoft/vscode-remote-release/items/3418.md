# Issue #3418 — ${execPath} has wrong value in a Container Remote

[https://github.com/microsoft/vscode-remote-release/issues/3418](https://github.com/microsoft/vscode-remote-release/issues/3418)

## Summary

Keep open for the maintainer-supported remote executable variable: documented environment settings offer a workaround, but do not supply the requested path independently of a login shell's PATH. Neither related open issue meets the re-review bar for the same observable symptom; the expired Backlog Candidates window is not grounds for a decline close.

## Change summary

Provide a task variable for the active container's VS Code CLI executable without changing the local meaning of ${execPath}.

## Best solution

Provide a remote CLI path variable usable in tasks and launch configurations, coordinated between Dev Containers and VS Code's variable resolver. Preserve ${execPath} for local extension-host debugging and support tasks whose login profiles overwrite PATH.
