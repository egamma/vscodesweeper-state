# Issue #8827 — devcontainer.json shows Warning/Problem for extension entry using a filepath

[https://github.com/microsoft/vscode-remote-release/issues/8827](https://github.com/microsoft/vscode-remote-release/issues/8827)

## Summary

The Dev Containers validator still rejects supported VSIX file paths, producing a false Problem diagnostic despite successful installation. Multiple recent confirmations show the gap remains, and the issue is already routed correctly.

## Change summary

Accept supported local VSIX file paths in the validation schema for `customizations.vscode.extensions`.

## Best solution

The Dev Containers component should align its VS Code-specific devcontainer schema with the installer by accepting in-container VSIX paths without weakening validation for marketplace extension identifiers.
