# Issue #9143 — Readme badges for monorepo 

[https://github.com/microsoft/vscode-remote-release/issues/9143](https://github.com/microsoft/vscode-remote-release/issues/9143)

## Summary

Keep open: the remaining request is a badge that directly selects a monorepo subproject's dev container, not interactive configuration selection. A maintainer proposed a folder URI parameter; current documentation and the related issue do not establish that this capability has shipped.

## Change summary

Allow each monorepo README badge to clone the repository and open its specific subproject dev container without a configuration-selection prompt.

## Best solution

The Dev Containers extension should support and document a repository-relative folder or configuration selector in cloneInVolume links. Preserve this product-side request separately from interactive discovery of multiple configurations.
