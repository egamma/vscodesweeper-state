# Issue #9143 — Readme badges for monorepo 

[https://github.com/microsoft/vscode-remote-release/issues/9143](https://github.com/microsoft/vscode-remote-release/issues/9143)

## Summary

Keep open as an already-routed Dev Containers feature request. Current badge documentation still exposes only the repository URL, so monorepos cannot select a configuration without an interactive prompt.

## Change summary

Allow an Open in Dev Containers badge to select a specific monorepo subfolder or dev container configuration.

## Best solution

The Dev Containers extension should support a `folder` parameter on the `cloneInVolume` URI so each monorepo badge can directly open its intended subproject and configuration.
