# Issue #10063 — Reconnection issues with ExecServer

[https://github.com/microsoft/vscode-remote-release/issues/10063](https://github.com/microsoft/vscode-remote-release/issues/10063)

## Summary

Keep this team-authored issue open as the maintainer-selected tracker for ExecServer reconnection cleanup. Dev Containers gained a workaround after the original investigation, but the linked sleep/reconnect steps suffice to retest the underlying behavior; no current confirmation or qualifying fix establishes resolution.

## Change summary

Reconnection should discard stale underlying connections and settle command exit and stream-end promises when an ExecServer connection is lost or replaced.

## Best solution

The Remote-SSH/ExecServer and Remote Core owners should retest the chained SSH-to-container sleep scenario and ensure stale connections are discarded and all command lifecycle promises settle on connection loss. Retain this tracker until both behaviors are verified, rather than treating the Dev Containers workaround as the underlying fix.
