# Issue #9117 — Connection unaware of reboots/graceful disconnect

[https://github.com/microsoft/vscode-remote-release/issues/9117](https://github.com/microsoft/vscode-remote-release/issues/9117)

## Summary

The clarified report describes Remote - SSH hanging on a dead transport after the host reboots, but it lacks logs or confirmation on a current release. A current retest and Remote - SSH log are needed to distinguish a remaining reconnect defect from behavior that has since changed.

## Change summary

Remote - SSH should abandon a dead connection and establish a new socket promptly after a remote Linux host reboots.

## Best solution

The SSH reconnect path should detect the dead transport, discard it, and open a new connection once the host is reachable without requiring a window reload. A current failure log should identify whether stale-connection detection or reconnect timeout handling still blocks that outcome.
