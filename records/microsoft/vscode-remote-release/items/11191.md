# Issue #11191 — UI doesn't show Windows username domain

[https://github.com/microsoft/vscode-remote-release/issues/11191](https://github.com/microsoft/vscode-remote-release/issues/11191)

## Summary

Keep open for Remote - SSH: the password prompt reportedly omits the Windows domain from the actual SSH username. The supplied steps suffice to retest; the report concerns older releases, with no subsequent confirmation or evidence of a fix.

## Change summary

Remote - SSH displays an unqualified username in its password prompt when Windows OpenSSH defaults to a domain-qualified account.

## Best solution

Remote - SSH should display the full account requested by SSH, including its domain, without changing SSH's default username selection. Retest the supplied scenario and distinguish the misleading prompt from authentication failure caused by selecting an unintended remote account.
