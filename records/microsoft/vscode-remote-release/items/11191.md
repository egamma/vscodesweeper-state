# Issue #11191 — UI doesn't show Windows username domain

[https://github.com/microsoft/vscode-remote-release/issues/11191](https://github.com/microsoft/vscode-remote-release/issues/11191)

## Summary

The reported mismatch between plain SSH and Remote - SSH could be an authentication bug, but this remains a single unconfirmed report without a Remote-SSH log. A current-version reproduction and comparison log are needed.

## Change summary

Remote - SSH omits the Windows account domain from its password prompt and fails authentication when OpenSSH implicitly selects a domain-qualified username.

## Best solution

The SSH component should verify that its password-prompt handling preserves the complete username selected by Windows OpenSSH. If the failure remains, matching verbose logs from plain SSH and Remote - SSH should show whether this is only incorrect prompt text or an authentication-path defect.
