# Issue #6319 — RemoteCommand is executed with `powershell` on linux machine (incorrect platform detection)

[https://github.com/microsoft/vscode-remote-release/issues/6319](https://github.com/microsoft/vscode-remote-release/issues/6319)

## Summary

Keep open: a maintainer reproduced Linux being detected as Windows with a minimal interactive RemoteCommand, and another user confirmed the failure in May 2025. Current-release resolution is unconfirmed, but the existing reproduction is sufficient to retest.

## Change summary

Remote - SSH selects PowerShell for a Linux host when RemoteCommand launches an interactive Bash shell.

## Best solution

Remote - SSH should correctly determine the platform when an interactive RemoteCommand is enabled, including delayed initialization, and respect an explicit remotePlatform override. Retest the minimal example against current connection modes before deciding whether platform-probe timing or output handling needs correction.
