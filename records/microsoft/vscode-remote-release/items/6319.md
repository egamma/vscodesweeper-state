# Issue #6319 — RemoteCommand is executed with `powershell` on linux machine (incorrect platform detection)

[https://github.com/microsoft/vscode-remote-release/issues/6319](https://github.com/microsoft/vscode-remote-release/issues/6319)

## Summary

Keep open: a maintainer reproduced the Linux remote being misclassified as Windows in December 2024, and another user confirmed the interactive-shell variant in May 2025. The issue is already routed to Remote - SSH and remains actionable.

## Change summary

Remote - SSH should correctly detect a Linux host when an interactive bash RemoteCommand delays or changes the platform-probe response.

## Best solution

Remote - SSH should make platform probing robust to interactive RemoteCommand output and timing, then use the detected or explicitly configured Linux platform rather than launching PowerShell.
