[https://github.com/microsoft/vscode-remote-release/issues/2881](https://github.com/microsoft/vscode-remote-release/issues/2881)

## Summary

Keep open: the January 2026 success report tests locally applied templates, not the sample command's clone-in-volume bootstrap path. Podman compatibility has improved since the original report, but the supplied steps and logs already suffice for a targeted maintainer retest.

## Change summary

Starting a sample with Podman fails in the temporary container used to clone and build the repository in a container volume.

## Best solution

The Dev Containers owner should retest the Python sample through Clone Repository in Container Volume with current Podman, including Linux socket access and non-root permissions. Confirm that this bootstrap path works before treating local-template successes as resolution.
