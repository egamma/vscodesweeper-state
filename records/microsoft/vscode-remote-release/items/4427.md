# Issue #4427 — Auth prompts during scp with useLocalServer not handled properly

[https://github.com/microsoft/vscode-remote-release/issues/4427](https://github.com/microsoft/vscode-remote-release/issues/4427)

## Summary

Keep open as the established Remote - SSH report for unanswerable authentication prompts during SCP fallback. Connection bootstrapping has evolved since the report, but its steps and logs suffice to retest; no confirmed fix establishes resolution.

## Change summary

With useLocalServer enabled, SCP fallback after a failed remote server download presents a second Duo authentication prompt only in read-only output, preventing installation.

## Best solution

Remote - SSH should make SCP authentication interactive in local-server mode, preferably by transferring the server over the already authenticated connection. Retest the documented fallback scenario on current releases without relying on the wget proxy workaround.
