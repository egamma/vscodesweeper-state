# Issue #4427 — Auth prompts during scp with useLocalServer not handled properly

[https://github.com/microsoft/vscode-remote-release/issues/4427](https://github.com/microsoft/vscode-remote-release/issues/4427)

## Summary

The detailed 2021 log shows that fallback SCP opened a second Duo authentication prompt without an interactive input surface, but there is no current-release confirmation. A retest is needed before deciding whether the SSH transfer path still has this defect.

## Change summary

Allow users to complete—or avoid—the second two-factor authentication challenge created when Remote - SSH falls back to copying the server with SCP.

## Best solution

Remote - SSH should reuse the established SSH connection for server transfer or route fallback SCP authentication through the same interactive prompt handling. First confirm the behavior and capture a current Remote - SSH log.
