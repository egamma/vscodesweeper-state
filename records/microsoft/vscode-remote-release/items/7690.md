# Issue #7690 — "Avoiding VS Code extension reinstalls" recipe for dev containers doesn't work

[https://github.com/microsoft/vscode-remote-release/issues/7690](https://github.com/microsoft/vscode-remote-release/issues/7690)

## Summary

Keep open: multiple users confirmed that persisting the extensions directory is unreliable, and a maintainer confirmed in 2025 that a general solution remains difficult. This team-authored issue is correctly routed to Containers and has no verified factual close.

## Change summary

Persisting Dev Container extensions across rebuilds can leave extensions missing, inactive, or blocked by volume-ownership errors.

## Best solution

The Dev Containers component should provide a built-in or maintained Feature that persists Stable and Insiders extensions separately while handling the remote user's UID/GID correctly, then publish tested guidance for it.
