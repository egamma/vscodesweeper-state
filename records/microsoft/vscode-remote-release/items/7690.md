## Change summary

Extensions persisted in an extensions-directory volume are not reliably activated after rebuilding a dev container.

## Best solution

The Dev Containers owner should establish a supported extension-persistence solution that handles non-root ownership and UID changes without retaining stale machine settings, and replace the missing recipe with tested guidance. Retest the original activation failure separately from the later permission failures.
