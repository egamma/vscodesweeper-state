# Issue #2468 — Containers: make opening a container from Dockerfile a nice experience

[https://github.com/microsoft/vscode-remote-release/issues/2468](https://github.com/microsoft/vscode-remote-release/issues/2468)

## Summary

The current Dev Containers workflow now covers the central request: Open Folder in Container can select an existing Dockerfile, build and start the container, mount the folder, and connect VS Code.

## Change summary

Provide a streamlined command that opens a local folder using an existing Dockerfile without requiring manual image and container management.

## Best solution

Keep the documented Dev Containers: Open Folder in Container workflow as the supported path; it abstracts the Docker lifecycle while preserving configuration through devcontainer.json.
