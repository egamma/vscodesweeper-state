## Summary

Keep open: the full report provides sufficient steps to retest prolonged ripgrep CPU saturation when opening a very large remote directory. Versions have advanced since VS Code 1.104.2 / Remote - SSH 0.120.0, but neither resolution nor a qualifying canonical is established.

## Change summary

Opening a large remote directory over SSH saturates the server CPU with ripgrep scans for 10–15 minutes.

## Best solution
