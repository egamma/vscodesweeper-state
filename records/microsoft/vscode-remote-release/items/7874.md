# Issue #7874 — devcontainer.json: Extensions installed by VSIX are not installed automatically in devcontainer

[https://github.com/microsoft/vscode-remote-release/issues/7874](https://github.com/microsoft/vscode-remote-release/issues/7874)

## Summary

Keep open in the accepted Containers backlog. Explicit VSIX paths do not satisfy the requested automatic fallback from an extension identifier to a locally installed VSIX, and no broader canonical issue was found.

## Change summary

Allow devcontainer.json to install a locally available VSIX automatically when its extension identifier is unavailable from the Marketplace.

## Best solution

The Dev Containers extension should support a reliable, documented way to provision non-Marketplace extensions, ideally resolving an identifier to the locally installed VSIX or clearly supporting an explicit VSIX path available during container creation.
