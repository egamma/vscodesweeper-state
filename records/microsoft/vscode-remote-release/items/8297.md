# Issue #8297 — Remote containers does not work with custom docker psFormat

[https://github.com/microsoft/vscode-remote-release/issues/8297](https://github.com/microsoft/vscode-remote-release/issues/8297)

## Summary

Keep open as an upstream Docker CLI regression, consistent with the maintainer's diagnosis. An upstream fix merged, but this thread contains no confirmation that it resolved the reporter's Dev Containers workflow.

## Change summary

Custom psFormat configuration breaks Dev Containers container discovery; the reporter requests an explicit docker ps format override.

## Best solution

Docker CLI should honor --quiet regardless of configured psFormat, allowing Dev Containers to discover container IDs without requiring users to remove their customization. Verify the supplied scenario with a Docker CLI containing the upstream fix before deciding whether extension-side defensive formatting remains necessary.
