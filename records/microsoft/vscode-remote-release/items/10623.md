# Issue #10623 — [Dev Containers] try a example button at left dev container pannel open the example in local instead of remote when in remote window

[https://github.com/microsoft/vscode-remote-release/issues/10623](https://github.com/microsoft/vscode-remote-release/issues/10623)

## Summary

The proxy-related clone failure is resolved, but a distinct Dev Containers polish gap remains: after sample creation fails on a Remote-SSH host, the status bar omits the host suffix and misleadingly resembles a local container context.

## Change summary

Preserve the originating remote-host identity in the Dev Container status indicator when opening a sample fails.

## Best solution

The Dev Containers extension should retain or restore the Remote-SSH host indicator while sample creation is pending or after it fails, so the status bar continues to identify where the operation ran.
