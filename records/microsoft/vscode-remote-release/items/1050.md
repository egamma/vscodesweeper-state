# Issue #1050 — Command substitution in devcontainer.json

[https://github.com/microsoft/vscode-remote-release/issues/1050](https://github.com/microsoft/vscode-remote-release/issues/1050)

## Summary

Keep open as the existing command-substitution tracking issue. Documented UID/GID matching and lifecycle scripts cover some use cases, but do not deliver computed values directly in runArgs, build arguments, or remoteEnv.

## Change summary

Allow command output to supply devcontainer.json values without manually exporting host environment variables.

## Best solution

The Dev Containers owner should evaluate a spec-aligned mechanism for computing configuration values before build and container creation. Keep this product-side request open while determining the supported syntax and evaluation timing.

- **Reason:** Computing host-dependent configuration supports deeper dev container capabilities and reduces manual environment setup.
