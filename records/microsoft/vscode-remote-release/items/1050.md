# Issue #1050 — Command substitution in devcontainer.json

[https://github.com/microsoft/vscode-remote-release/issues/1050](https://github.com/microsoft/vscode-remote-release/issues/1050)

## Summary

Keep this open as the canonical request for host-side command substitution in devcontainer.json. Current variable substitution and initializeCommand workflows provide partial workarounds, but do not directly cover dynamic values in runArgs and other properties.

## Change summary

Allow devcontainer.json values such as runArgs and build arguments to derive values from host commands like `id -u`.

## Best solution

The Dev Containers and devcontainers spec owners should design a safe, portable host-evaluated substitution mechanism rather than implicitly shell-evaluating JSON values. It should cover dynamic runArgs and build values without requiring generated Compose environment files.
