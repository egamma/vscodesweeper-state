# Issue #2677 — Shared Docker host: Distinguish between running containers by more than just local path

[https://github.com/microsoft/vscode-remote-release/issues/2677](https://github.com/microsoft/vscode-remote-release/issues/2677)

## Summary

The shared-Docker-host identity collision was independently reproduced and acknowledged, but the available evidence is several years old and does not establish whether current Dev Containers releases still select containers using the same insufficient identity.

## Change summary

Prevent Dev Containers users sharing a Docker host from reconnecting to another user's container when their local repository paths match.

## Best solution

Confirm the current container-selection labels and behavior on a shared Docker daemon; if the collision remains, the Dev Containers extension should include a stable user or client-specific identity while preserving intentional reconnection.
