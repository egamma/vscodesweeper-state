# Issue #2677 — Shared Docker host: Distinguish between running containers by more than just local path

[https://github.com/microsoft/vscode-remote-release/issues/2677](https://github.com/microsoft/vscode-remote-release/issues/2677)

## Summary

Keep open as the maintainer-selected tracker for shared-Docker container identity collisions. The supplied steps suffice to retest despite their age; current resolution is unverified, and unintended access to a colleague's workspace warrants human review rather than closure.

## Change summary

Reopening a dev container can select another user's container when their local configuration paths match on a shared Docker host.

## Best solution

The Dev Containers owner should retest the shared-daemon scenario and make container reuse distinguish users or explicitly resolve ambiguous matches. Preserve this issue as the canonical tracker; unique local paths are a workaround, not a complete solution.
