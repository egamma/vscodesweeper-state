# Issue #689 — Use existing Node to connect

[https://github.com/microsoft/vscode-remote-release/issues/689](https://github.com/microsoft/vscode-remote-release/issues/689)

## Summary

Keep this request open and route it to the SSH/server owners: using a host-provided Node runtime remains a distinct capability not covered by the documented download controls. The maintainer acknowledged potential benefits, and no qualifying canonical or confirmed implementation was found.

## Change summary

Allow Remote - SSH to use a compatible host-provided Node runtime instead of requiring the bundled executable, reducing installation overhead on constrained hosts.

## Best solution

The SSH and VS Code Server owners should evaluate an opt-in host-provided Node runtime with explicit version and native-module compatibility checks and a bundled-runtime fallback. Preserve the managed server lifecycle while determining whether runtime reuse can actually reduce the downloaded and installed footprint.
