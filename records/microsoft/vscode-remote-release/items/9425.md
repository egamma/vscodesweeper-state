# Issue #9425 — Find `.devcontainer` in parent folders

[https://github.com/microsoft/vscode-remote-release/issues/9425](https://github.com/microsoft/vscode-remote-release/issues/9425)

## Summary

Keep open: the available workflows support sharing a container across projects, but do not establish automatic nearest-parent configuration discovery when reopening a locally opened subfolder. No verified canonical owns this exact request.

## Change summary

Discover the nearest ancestor .devcontainer configuration when reopening a monorepo subproject in a container.

## Best solution

The Dev Containers extension should support nearest-parent configuration discovery while retaining the selected subproject as the opened folder, without merging ancestor configurations. The remaining product decision is how ancestor discovery interacts with workspace mounting and existing configuration selection.
