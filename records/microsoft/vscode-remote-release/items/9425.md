# Issue #9425 — Find `.devcontainer` in parent folders

[https://github.com/microsoft/vscode-remote-release/issues/9425](https://github.com/microsoft/vscode-remote-release/issues/9425)

## Summary

This remains a valid Dev Containers feature request. The documented alternatives support monorepos but do not let a user open a subproject directly and discover a shared configuration in an ancestor directory.

## Change summary

When a subfolder is opened, search its parent directories for a shared `.devcontainer` configuration.

## Best solution

The Dev Containers extension should support deliberate ancestor configuration discovery, bounded by a repository or workspace root and with selection when multiple configurations qualify. The existing multi-root and `workspaceFolder` workflows should remain available.

## Evidence

- **documented behavior:** https://code.visualstudio.com/docs/devcontainers/containers documents configurations at `.devcontainer/devcontainer.json` or `.devcontainer.json` in the project root and documents multi-root workspaces, but not ancestor lookup from an independently opened subfolder.
