# Issue #9870 — Failing to (re)build dev container, failing locally

[https://github.com/microsoft/vscode-remote-release/issues/9870](https://github.com/microsoft/vscode-remote-release/issues/9870)

## Summary

Keep open: a maintainer reproduced the Dev Containers failure, and later users confirmed the same Copilot-dependent path. The newly documented requirement to create devcontainer.json provides a workaround but does not fix the undefined-value exception.

## Change summary

Opening an SSH-hosted folder in a dev container fails with an undefined-value TypeError when no devcontainer.json exists and Copilot Chat is installed remotely.

## Best solution

The Dev Containers extension should reliably show the configuration picker or create devcontainer.json in this Remote-SSH flow, regardless of Copilot Chat installation, and avoid calling toString on missing configuration data.
