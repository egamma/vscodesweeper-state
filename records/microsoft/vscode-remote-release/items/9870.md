# Issue #9870 — Failing to (re)build dev container, failing locally

[https://github.com/microsoft/vscode-remote-release/issues/9870](https://github.com/microsoft/vscode-remote-release/issues/9870)

## Summary

Keep open as the established tracking issue: configuration creation over Remote-SSH still fails on Dev Containers 0.475.0 with Copilot Chat installed. The maintainer's reproduction and recent matching report distinguish an unresolved extension defect from the configuration-file workarounds.

## Change summary

Creating a dev container configuration over Remote-SSH throws an undefined toString error when Copilot Chat is installed, preventing the container-opening workflow.

## Best solution

Dev Containers should handle unavailable remote-host URI conversion in its Copilot template-suggestion integration without aborting configuration creation. Retain this issue as the canonical tracker and preserve manual template selection when suggestions cannot run.
