[https://github.com/microsoft/vscode-remote-release/issues/11698](https://github.com/microsoft/vscode-remote-release/issues/11698)

## Summary

The reported ARM32 rejection matches the explicitly documented support retirement: VS Code 1.122 was the last release supporting prebuilt servers on 32-bit ARM Linux. Propose closing as designed, while acknowledging the request to reconsider embedded-device support.

## Change summary

Remote - SSH rejects a previously usable Raspberry Pi running armv7l Raspbian 11 with UnsupportedPlatform("LinuxARM32").

Explain the precise support cutoff and supported host architectures rather than investigate this as an installation regression. Correct the older Linux requirements documentation that still lists ARMv7l support; restoring ARM32 support would require an explicit product decision.

The request to restore support for constrained devices is understood, but it would require reconsidering that support policy.
