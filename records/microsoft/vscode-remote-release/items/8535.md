# Issue #8535 — code command not available in postcreatecommand when using devcontainers

[https://github.com/microsoft/vscode-remote-release/issues/8535](https://github.com/microsoft/vscode-remote-release/issues/8535)

## Summary

Keep open: the maintainer proposed exposing the server CLI during container setup, but the thread contains only partial workarounds, not a shipped resolution. Existing extension configuration does not cover conditional installation and the later client-command use cases; no qualifying canonical was found.

## Change summary

Provide supported access to VS Code CLI capabilities from Dev Containers lifecycle scripts, including conditional VSIX installation during postCreateCommand.

## Best solution

The Dev Containers component should provide a stable, supported server CLI entry point for lifecycle-time extension installation without searching versioned installation directories. Separately define which client-dependent operations, such as opening workspaces or reloading the window, can be supported after attachment.
