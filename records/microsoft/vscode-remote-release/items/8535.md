# Issue #8535 — code command not available in postcreatecommand when using devcontainers

[https://github.com/microsoft/vscode-remote-release/issues/8535](https://github.com/microsoft/vscode-remote-release/issues/8535)

## Summary

This remains a valid Dev Containers feature gap: lifecycle commands lack a stable `code` CLI entry point. The documented extension customization covers basic extension installation but not conditional installation, workspace opening, or extension-host reloads.

## Change summary

Make an appropriate `code` CLI available to Dev Container lifecycle commands such as `postCreateCommand`.

## Best solution

Dev Containers should expose a documented, stable server CLI path during lifecycle commands for server-side operations such as extension installation. Client-bound operations should either become available at a defined post-connection stage or have their lifecycle limitation documented clearly.
