# Issue #11014 — CANNOT Disable Credential Forwarding Git GnuPG SSH

[https://github.com/microsoft/vscode-remote-release/issues/11014](https://github.com/microsoft/vscode-remote-release/issues/11014)

## Summary

Keep open for human security review: the requested host-side credential-forwarding opt-out remains unconfirmed as implemented. The older overlapping request is verified, but the security-sensitive keep-open rule bars a duplicate close.

## Change summary

Provide a reliable way to disable Dev Containers forwarding of Git credentials, SSH agents, and GPG agents.

## Best solution

Dev Containers should provide a host-controlled opt-out that prevents credential access rather than merely removing container-side configuration, including after reconnects. Coordinate this work with the older request at https://github.com/microsoft/vscode-remote-release/issues/9466 and have a maintainer assess the reported IPC exposure.
