# Issue #11014 — CANNOT Disable Credential Forwarding Git GnuPG SSH

[https://github.com/microsoft/vscode-remote-release/issues/11014](https://github.com/microsoft/vscode-remote-release/issues/11014)

## Summary

Keep open for human security review: Dev Containers automatically exposes Git, SSH-agent, and GPG credentials without a comprehensive opt-out, and a maintainer agreed that a setting can be added. The older issue https://github.com/microsoft/vscode-remote-release/issues/9466 owns the broader request, but the security-sensitive keep-open rule bars an automated duplicate close.

## Change summary

Add a trusted user-level option that prevents Git credential, SSH-agent, and GPG-agent forwarding into Dev Containers.

## Best solution

The Dev Containers extension should provide a user-controlled, workspace-unmodifiable setting that disables all credential forwarding before a container starts. Maintainers should coordinate the implementation and eventual consolidation with the broader tracking issue https://github.com/microsoft/vscode-remote-release/issues/9466.
