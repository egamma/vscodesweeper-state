# Issue #9605 — Remote-containers fails to build the container when using TARGETARCH substitution for stages

[https://github.com/microsoft/vscode-remote-release/issues/9605](https://github.com/microsoft/vscode-remote-release/issues/9605)

## Summary

Keep open while the referenced Dev Containers CLI implementation PR remains open. The detailed reproduction, maintainer diagnosis, and independent confirmations establish the missing TARGETARCH support.

## Change summary

Dev Containers resolves `${TARGETARCH}` to an empty value while inspecting multi-stage Dockerfiles, preventing multi-architecture container builds.

## Best solution

The Dev Containers CLI should resolve BuildKit automatic platform arguments during base-image analysis, including the Docker Compose path used here. Review and complete https://github.com/devcontainers/cli/pull/1064, ensuring it covers this Compose scenario before resolving this report and the older canonical issue.
