# Issue #4538 — Be able to set containerEnv's in VSCode settings.json

[https://github.com/microsoft/vscode-remote-release/issues/4538](https://github.com/microsoft/vscode-remote-release/issues/4538)

## Summary

Keep open: current documentation supports environment variables through project-level devcontainer configuration, but not a user-level setting applied across projects. This accepted Backlog request remains the best canonical issue for that gap.

## Change summary

Allow users to define build-time and runtime Dev Container environment variables in VS Code settings so they apply across projects.

## Best solution

The Dev Containers extension should provide a user-scoped environment mechanism that applies without modifying each project's devcontainer.json, with clear build-time, runtime, and secret-handling semantics.
