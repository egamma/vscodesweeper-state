# Issue #4538 — Be able to set containerEnv's in VSCode settings.json

[https://github.com/microsoft/vscode-remote-release/issues/4538](https://github.com/microsoft/vscode-remote-release/issues/4538)

## Summary

Keep this accepted feature request open: documented environment configuration and dotfiles support do not cover user-wide build-time and container-wide runtime variables independent of project configuration. The verified related requests do not establish a canonical owning its full scope.

## Change summary

Allow personal build-time and container-wide runtime environment variables to be configured in VS Code user settings across projects.

## Best solution

The Dev Containers component should provide user-level environment defaults with explicit precedence against project configuration, distinguishing build arguments, container-wide variables, and the extension-host environment. Retain this issue for that broader capability and coordinate with the related user-environment request.
