# Issue #10967 — can't start remote SSH when remote Linux server uses fish shell

[https://github.com/microsoft/vscode-remote-release/issues/10967](https://github.com/microsoft/vscode-remote-release/issues/10967)

## Summary

Verified duplicate of the open fish-shell connection-timeout issue. The successful authentication followed by a bootstrap timeout, bash workaround, and local-server setting workaround match the canonical report.

## Change summary

Remote - SSH should connect to Linux accounts using fish as their default shell without requiring a switch to bash.

Consolidate the remaining Remote - SSH bootstrap compatibility work in https://github.com/microsoft/vscode-remote-release/issues/2509, preserving this report's 0.120.0 connection log and confirmed RemoteCommand workaround.
