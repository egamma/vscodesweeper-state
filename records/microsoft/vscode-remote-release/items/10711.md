# Issue #10711 — Could not establish connection to [id]: Failed to  download VS Code Server(Failed to fetch)

[https://github.com/microsoft/vscode-remote-release/issues/10711](https://github.com/microsoft/vscode-remote-release/issues/10711)

## Summary

The server archive downloads and transfers successfully; connection then fails because the CentOS host lacks the documented minimum glibc and libstdc++ versions. This is an unsupported remote-environment dependency rather than evidence of a Remote - SSH download defect.

## Change summary

Remote - SSH reports a server-download failure while connecting to an older CentOS host.

## Best solution

The remote host should be upgraded to meet the VS Code Server requirements or configured using the documented older-Linux workaround. If the failure remains afterward, the SSH owner needs a fresh current-version log.
