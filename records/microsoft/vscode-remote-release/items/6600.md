# Issue #6600 — Enable SSH agent forwarding for scp

[https://github.com/microsoft/vscode-remote-release/issues/6600](https://github.com/microsoft/vscode-remote-release/issues/6600)

## Summary

Keep open: the existing agent-forwarding setting does not cover server uploads through scp, and a maintainer identified a security-conscious conditional implementation.

## Change summary

Allow Remote - SSH server uploads through scp to forward the SSH agent when the selected host explicitly enables ForwardAgent.

## Best solution

Remote - SSH should detect `ForwardAgent yes` in the resolved host configuration and add `-A` only to the corresponding scp server-upload command, avoiding unconditional agent exposure.
