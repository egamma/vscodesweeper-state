# Issue #1460 — Multiple container support for multi root workspaces

[https://github.com/microsoft/vscode-remote-release/issues/1460](https://github.com/microsoft/vscode-remote-release/issues/1460)

## Summary

This remains the canonical, highly supported request for concurrently connecting one multi-root workspace to multiple dev containers. Current functionality can start multiple containers and switch between them, but it still cannot keep folders attached to different containers simultaneously in one VS Code window.

## Change summary

Allow each folder in a multi-root workspace to use its own devcontainer configuration and remain connected concurrently in one VS Code window.

## Best solution

The Dev Containers and remote-workspace architecture should support multiple concurrent container-backed folders in one window, preserving each folder's extensions, tools, debugging context, and container configuration. If that architectural investment is not feasible, the containers team should make an explicit scope decision on this canonical request.
