# Issue #3045 — One installation of vs code server on remote machine

[https://github.com/microsoft/vscode-remote-release/issues/3045](https://github.com/microsoft/vscode-remote-release/issues/3045)

## Summary

Remote - SSH now supports installing outside the home directory through remote.SSH.serverInstallPath, covering the reporter's alternative request. Ask whether that resolves the space constraint before closing; a single installation shared by all users is not established by this setting.

## Change summary

Allow a shared VS Code Server installation for all remote users, or alternatively install outside their home directories.

## Best solution

Use Remote - SSH's host-specific serverInstallPath setting to place each user's installation on a writable filesystem outside /home. If shared binaries remain necessary, retain that distinct server-installation request rather than treating path relocation as shared-install support.
