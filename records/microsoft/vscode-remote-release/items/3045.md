# Issue #3045 — One installation of vs code server on remote machine

[https://github.com/microsoft/vscode-remote-release/issues/3045](https://github.com/microsoft/vscode-remote-release/issues/3045)

## Summary

The requested alternative is now supported: Remote - SSH can install the VS Code Server outside the remote user's home directory using `remote.SSH.serverInstallPath`.

## Change summary

Allow administrators to share one VS Code Server installation among users or relocate each installation outside users' home directories.

## Best solution

Use `remote.SSH.serverInstallPath` to map the SSH host to an absolute path with sufficient space. A single installation shared across users remains outside the documented model, but relocation resolves the reported storage constraint.

  > Thanks for the request. The reported storage constraint is now covered by `remote.SSH.serverInstallPath`, introduced in Remote - SSH 0.67.x. It maps each SSH host to an absolute server installation path outside the user's home directory; configuration and an example are documented at https://github.com/microsoft/vscode-docs/blob/main/remote-release-notes/v1_63.md#customize-server-installation-path. A single installation shared by multiple users is not the supported model, but the custom path provides the requested alternative.
