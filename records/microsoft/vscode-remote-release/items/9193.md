# Issue #9193 — Docker-in-docker does not clear docker data on rebuild

[https://github.com/microsoft/vscode-remote-release/issues/9193](https://github.com/microsoft/vscode-remote-release/issues/9193)

## Summary

The requested ephemeral Docker data mode remains unavailable: the current Docker-in-Docker Feature unconditionally mounts named volumes keyed to the dev container, preserving data across rebuilds. The issue should remain open pending transfer or consolidation in the Dev Container Features tracker.

## Change summary

Add an option for Docker-in-Docker data to be deleted with each dev-container rebuild instead of persisted in named volumes.

## Best solution

Track the capability in https://github.com/devcontainers/features, where the Docker-in-Docker Feature is maintained, and add an opt-in ephemeral mode while retaining persistence by default for compatibility. Any required conditional-mount support should be coordinated through the Dev Container specification.
