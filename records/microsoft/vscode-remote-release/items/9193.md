# Issue #9193 — Docker-in-docker does not clear docker data on rebuild

[https://github.com/microsoft/vscode-remote-release/issues/9193](https://github.com/microsoft/vscode-remote-release/issues/9193)

## Summary

Keep open: an opt-in Docker-in-Docker mode that discards nested Docker state on rebuild remains missing. A maintainer supported optional persistence while retaining the existing default for compatibility.

## Change summary

Allow Docker-in-Docker containers and data to be discarded when their parent dev container is rebuilt.

## Best solution

Provide an opt-in ephemeral Docker-in-Docker mode, retaining persistence by default. Coordinate the Feature change in https://github.com/devcontainers/features with any conditional-mount support needed in the spec and Dev Containers extension; retain this issue for the user-facing rebuild behavior.
