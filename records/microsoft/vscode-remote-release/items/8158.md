# Issue #8158 — Disable `docker compose ... build`

[https://github.com/microsoft/vscode-remote-release/issues/8158](https://github.com/microsoft/vscode-remote-release/issues/8158)

## Summary

Verified cross-repository duplicate: the open Dev Container specification proposal covers the requested pull-first, build-on-miss behavior for Docker Compose.

## Change summary

Allow Compose-based dev containers to use a published image without rebuilding it, while retaining build fallback when the image is unavailable.

## Best solution

Consolidate this requirement on https://github.com/devcontainers/spec/issues/74, which owns the build-and-reuse semantics; the Dev Containers CLI and extension should implement the resulting specification.
