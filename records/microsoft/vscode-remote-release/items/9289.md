# Issue #9289 — Opening Remote from the Welcome Screen "Recent" is not case sensitive

[https://github.com/microsoft/vscode-remote-release/issues/9289](https://github.com/microsoft/vscode-remote-release/issues/9289)

## Summary

Keep open: the reporter supplied concrete steps and contrasting SSH commands, and confirmed that regenerating the Recent entry did not help. The supplied steps suffice to retest on current versions; the last confirmation predates subsequent releases, and no verified fix or canonical was found.

## Change summary

Opening a mixed-case SSH host alias from Welcome > Recent lowercases it and fails, while Remote Explorer preserves its casing and connects.

## Best solution

Preserve SSH host aliases when storing and reopening recent remote entries. The SSH owner should compare both entry points on Windows and coordinate with the workbench owner if recent-entry URI handling causes the transformation; a maintainer can transfer this to microsoft/vscode if core ownership is established.
