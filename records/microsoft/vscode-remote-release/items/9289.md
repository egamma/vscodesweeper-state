# Issue #9289 — Opening Remote from the Welcome Screen "Recent" is not case sensitive

[https://github.com/microsoft/vscode-remote-release/issues/9289](https://github.com/microsoft/vscode-remote-release/issues/9289)

## Summary

The logs demonstrate that Open Recent lowercased a mixed-case SSH alias, but the latest confirmation used Remote - SSH 0.107.1 in 2023. A current-version retest is needed before determining whether the SSH extension or VS Code's recent-workspace storage still corrupts the alias.

## Change summary

Opening a mixed-case SSH host alias from Welcome or Open Recent lowercases the alias and prevents connection.

## Best solution

Preserve the SSH host alias casing when creating and reopening recent remote entries. If current logs show VS Code core lowercasing the remote URI rather than Remote - SSH constructing it incorrectly, a maintainer can transfer this to microsoft/vscode.
