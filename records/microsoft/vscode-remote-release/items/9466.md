# Issue #9466 — Disable credential sharing

[https://github.com/microsoft/vscode-remote-release/issues/9466](https://github.com/microsoft/vscode-remote-release/issues/9466)

## Summary

Keep open as the canonical security-sensitive request for an IDE-controlled way to disable all Dev Container credential forwarding. The documented behavior remains automatic, and a maintainer agreed that a single user setting makes sense.

## Change summary

Add a trusted user-level control that prevents Dev Containers from receiving Git credentials or SSH and GPG agent access.

## Best solution

The Dev Containers extension should provide a user-scoped setting, not overridable from the container or workspace, that disables Git credential sharing and SSH/GPG agent forwarding together; an optional per-request consent mode could follow separately. Consolidate the narrower requests in https://github.com/microsoft/vscode-remote-release/issues/11014 and https://github.com/microsoft/vscode-remote-release/issues/11413 into this broader canonical issue.
