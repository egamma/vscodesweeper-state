# Issue #9466 — Disable credential sharing

[https://github.com/microsoft/vscode-remote-release/issues/9466](https://github.com/microsoft/vscode-remote-release/issues/9466)

## Summary

Keep open for human security review: the requested host-enforced credential-sharing opt-out remains unsupported by the cited settings and documentation. A maintainer accepted the single-setting direction, and the credential-exposure concerns independently prohibit a cleanup close.

## Change summary

Provide a global, host-enforced switch disabling all credential and agent forwarding into dev containers that container or workspace settings cannot override.

## Best solution

The Dev Containers owner should implement a host-side credential-forwarding policy covering Git credentials, authentication tokens, SSH/GPG agents, and Docker registry credentials, including attach and Remote-SSH workflows. Enforce denial at the credential-serving boundary rather than merely removing environment variables or helper configuration; consider per-container controls and consent separately.
