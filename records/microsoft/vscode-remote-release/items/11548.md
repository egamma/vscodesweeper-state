# Issue #11548 — Support `--goto` with dev containers

[https://github.com/microsoft/vscode-remote-release/issues/11548](https://github.com/microsoft/vscode-remote-release/issues/11548)

## Summary

Keep open as a Dev Containers command-line parity request. Existing remote CLI support does not establish that the reporter's host-side attached-container workflow supports line-and-column navigation, and no verified canonical owns that specific ask.

## Change summary

Open a file inside a dev container at a specified line and column from an external command line.

## Best solution

The containers owner should verify whether `code --remote attached-container+<container-hex> --goto /path-to-project/file.ext:5:10` delivers this workflow. Document the supported invocation if it does; otherwise preserve this issue for the missing container-side integration.
