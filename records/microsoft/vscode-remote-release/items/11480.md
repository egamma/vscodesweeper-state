# Issue #11480 — "unexpected end of parent stream" on empty or missing "known_hosts"

[https://github.com/microsoft/vscode-remote-release/issues/11480](https://github.com/microsoft/vscode-remote-release/issues/11480)

## Summary

Keep open as a confirmed Dev Containers bug: an empty or missing WSL known_hosts file deterministically terminates the shell server, and two independent users confirmed the behavior through Dev Containers 0.467.0.

## Change summary

Dev Containers should tolerate an empty or missing known_hosts file instead of terminating its shell and keep-alive processes during container startup.

## Best solution

The Dev Containers extension should skip or safely copy a zero-byte known_hosts file without closing the parent stream; the containers owner should reproduce using the supplied steps and remove the need for a dummy entry.
