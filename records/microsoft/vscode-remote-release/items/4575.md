# Issue #4575 — Is the requirement specifications for Docker Desktop on Windows 10 Home correct?

[https://github.com/microsoft/vscode-remote-release/issues/4575](https://github.com/microsoft/vscode-remote-release/issues/4575)

## Summary

Decline close (as-designed) gated off: the issue carries `under-discussion` — the owner has not decided yet. Original assessment: The maintainer explained that the Windows 10 Home minimum was deliberately raised to 2004 because of problems with 1903. Docker's historical installation minimum does not establish the extension's supported minimum, so the requested correction is not warranted on that evidence.

## Change summary

Change the documented Windows 10 Home minimum for Dev Containers from 2004 to 1903 to match Docker's historical requirements.

## Best solution

Retain the distinction between Docker installation requirements and the Dev Containers support baseline rather than advertise 1903 support. Any modernization of the requirements should follow current supported configurations, not restore the historical Docker minimum.

- **Published extension requirements:** https://marketplace.visualstudio.com/items?itemName=ms-vscode-remote.remote-containers and https://code.visualstudio.com/docs/devcontainers/containers#_system-requirements still specify Windows 10 Home 2004+ with the WSL2 backend. The requested reduction has not been published; the thread explains why the higher baseline was intentional.
- **Historical Docker minimum is not current guidance:** https://docs.docker.com/desktop/setup/install/windows-install/#system-requirements now lists substantially newer Windows and WSL requirements and limits Docker Desktop support to Windows versions within Microsoft's servicing timeline. The 2021 Docker installation statement cannot establish current 1903 support.
