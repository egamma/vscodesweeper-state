# Issue #4575 — Is the requirement specifications for Docker Desktop on Windows 10 Home correct?

[https://github.com/microsoft/vscode-remote-release/issues/4575](https://github.com/microsoft/vscode-remote-release/issues/4575)

## Summary

The proposed 1903 minimum is obsolete, but the underlying documentation mismatch remains: the Dev Containers page still advertises Windows 10 Home 2004+, while Docker now documents newer supported Windows versions. Keep this open as documentation polish.

## Change summary

Align the Dev Containers system requirements for Docker Desktop on Windows with Docker's supported Windows versions.

The containers documentation owner should replace the historical Windows 10 Home 2004+ requirement with current Docker Desktop requirements and link directly to Docker's maintained support matrix.
