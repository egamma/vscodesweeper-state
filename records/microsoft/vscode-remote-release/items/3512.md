# Issue #3512 — Stop and remove container

[https://github.com/microsoft/vscode-remote-release/issues/3512](https://github.com/microsoft/vscode-remote-release/issues/3512)

## Summary

Keep this maintainer-supported, team-authored cleanup request open. Existing configuration provides only partial coverage, and the newer Agents-window cleanup does not deliver the requested ordinary Dev Containers workflow.

## Change summary

Provide an explicit way to disconnect, stop, and remove a development container, with optional cleanup of its associated volumes.

## Best solution

The Dev Containers component should provide an opt-in stop-and-remove action, defining Compose behavior and requiring explicit confirmation before deleting workspace volumes. Coordinate any shutdownAction extension with the Dev Container specification while retaining the product implementation request here.
