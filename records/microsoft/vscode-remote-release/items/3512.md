# Issue #3512 — Stop and remove container

[https://github.com/microsoft/vscode-remote-release/issues/3512](https://github.com/microsoft/vscode-remote-release/issues/3512)

## Summary

A real lifecycle gap remains: current cleanup commands remove stopped resources, but there is no documented one-step action or shutdown policy that disconnects, stops, and removes the active container. This team-authored feature request cannot receive a judgment close.

## Change summary

Provide an action or shutdown policy that disconnects from an active Dev Container, stops it, and removes its container and optionally its volumes.

## Best solution

The Dev Containers extension should offer a clearly scoped “Close, Stop, and Remove” action, with explicit confirmation before deleting volumes. If automatic removal is desired through `shutdownAction`, the corresponding enum addition should first be coordinated with https://github.com/devcontainers/spec.
