# Issue #104 — In tasks.json/launch.json, how do I know if vscode is running on remote or not?

[https://github.com/microsoft/vscode-remote-release/issues/104](https://github.com/microsoft/vscode-remote-release/issues/104)

## Summary

Keep open: extension APIs now expose remote-workspace detection, but the documented tasks.json/launch.json variables do not provide it directly. The verified related issues address different capabilities, not this incremental extension-copy workflow.

## Change summary

Expose local-versus-remote context in tasks.json and launch.json so extension-development scripts can select the appropriate installation directory.

## Best solution

The remote owners should coordinate with VS Code's configuration-variable owner on a supported remote-context or extension-location variable. A custom command using vscode.env.remoteName is a workaround, but requiring additional extension code does not provide the requested built-in configuration surface.
