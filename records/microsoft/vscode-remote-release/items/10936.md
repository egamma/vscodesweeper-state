# Issue #10936 — git includeIf config wont get applied

[https://github.com/microsoft/vscode-remote-release/issues/10936](https://github.com/microsoft/vscode-remote-release/issues/10936)

## Summary

Keep open because the report identifies potential identity exposure from ignored conditional Git configuration. The WSL case is now resolved, but Dev Containers 0.427.0 still exhibits the gap and should be routed conceptually with the older container tracking issue.

## Change summary

Preserve applicable Git include/includeIf configuration, including identity and signing settings, when entering remote environments.

## Best solution

The Dev Containers component should safely resolve or transfer applicable included Git configuration while excluding host-specific entries such as credential helpers. Coordinate the implementation with https://github.com/microsoft/vscode-remote-release/issues/2084 and verify that user identity, signing, and hooks remain consistent without exposing host-only paths or credentials.
