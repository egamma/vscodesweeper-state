[https://github.com/microsoft/vscode-remote-release/issues/3364](https://github.com/microsoft/vscode-remote-release/issues/3364)

## Summary

The older, open Docker-image preinstallation request tracks the same inability to install server-side extensions before attaching VS Code. Consolidate there while preserving this report's fully offline, internal-VSIX and no-devcontainer.json requirements.

## Change summary

Provide a way to preinstall internally supplied VSIX extensions into a container image without devcontainer.json or an attached VS Code session.

## Best solution

Track a supported build-time server-side extension installation mechanism in https://github.com/microsoft/vscode-remote-release/issues/1718, including local VSIX inputs for fully offline images. Its solution should work before attachment and without requiring devcontainer.json.
