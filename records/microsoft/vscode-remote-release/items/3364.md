# Issue #3364 — Offline --install-extension on host

[https://github.com/microsoft/vscode-remote-release/issues/3364](https://github.com/microsoft/vscode-remote-release/issues/3364)

## Summary

A real capability gap remains for baking offline VSIX extensions into an attachable container without devcontainer.json. The team-authored request is already correctly routed and has no verified canonical or documented equivalent.

## Change summary

Provide a supported host-side mechanism to preinstall offline VSIX extensions into a container image without devcontainer.json or an already-running VS Code Server.

## Best solution

The Dev Containers component should provide or document a supported CLI workflow that installs local VSIX files into an image or container before first attachment, without requiring devcontainer.json or Marketplace access.
