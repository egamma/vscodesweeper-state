# Issue #10675 — Cannot install Code Tunnel as a service on MacOS

[https://github.com/microsoft/vscode-remote-release/issues/10675](https://github.com/microsoft/vscode-remote-release/issues/10675)

## Summary

Keep open: the supplied command, macOS version, and launchctl error suffice to retest this service-installation failure. Later service reports describe different failures; neither current documentation nor the thread establishes that this macOS defect was fixed.

## Change summary

Installing the tunnel service on macOS reports successful registration but fails to start it with launchctl exit code 3.

## Best solution

The tunnel CLI owner should retest installation on macOS and investigate the generated launch-agent location and registration domain. If the reported failure persists, installation should register and start the service reliably without requiring manual plist relocation or loading.
