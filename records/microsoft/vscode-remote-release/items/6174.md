## Summary

Keep open: the documented manual log command and lifecycle-command output do not provide the requested automatic full-log visibility. No verified canonical owns the same request, and the thread supports adding a persistent preference.

## Change summary

Allow users to automatically display the complete Dev Containers startup log without clicking Show Log on every connection.

## Best solution

The Dev Containers extension should offer a persistent preference to reveal its startup log automatically, while preserving the existing hidden-by-default behavior for other users.
