# Issue #2705 — Show attached container name instead of image

[https://github.com/microsoft/vscode-remote-release/issues/2705](https://github.com/microsoft/vscode-remote-release/issues/2705)

## Summary

Keep open for Dev Containers: distinguishing attached windows by their Docker container names remains a meaningful usability request. The verified related issues do not own the same window-title and remote-indicator behavior.

## Change summary

Prefer the attached Docker container's name over its shared image name in the window title and remote status indicator.

## Best solution

Dev Containers should prioritize the actual Docker container name in attached-window titles and remote indicators, retaining image information as secondary context so same-image containers remain distinguishable.

- **Existing capability check:** https://code.visualstudio.com/docs/devcontainers/attach-container documents image-level and container-name-level attached configurations. The named-configuration command changes configuration association, not the documented title/indicator display preference. https://github.com/devcontainers/spec/blob/main/docs/specs/devcontainerjson-reference.md defines name as a UI display name, but does not establish automatic use of the actual Docker name when attaching to existing containers.
- **Newer related request:** https://github.com/microsoft/vscode-remote-release/issues/11885 is open and requests prioritizing container names over images in Remote Explorer to avoid truncation, on Dev Containers 0.469.0. It concerns a different UI surface and is newer; its Backlog Candidates milestone does not make it canonical for this title/status-indicator request.
- **Older candidates have different scope:** https://github.com/microsoft/vscode-remote-release/issues/1557 concerns Explorer grouping and configuration/extension synchronization between same-image containers. https://github.com/microsoft/vscode-remote-release/issues/2485 requests choosing names when creating containers. Neither owns the same observable symptom.
