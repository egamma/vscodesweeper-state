# Issue #2705 — Show attached container name instead of image

[https://github.com/microsoft/vscode-remote-release/issues/2705](https://github.com/microsoft/vscode-remote-release/issues/2705)

## Summary

The current attached-container configuration cannot set a display name, so users attaching multiple Compose containers from the same image still lack a documented way to distinguish their windows. The issue is correctly routed and remains a useful under-discussion container UX request.

## Change summary

Display an attached container's Docker name instead of its image name in the VS Code window title and remote status indicator.

## Best solution

Dev Containers should use the Docker container name as the default display label for attached containers, while preserving an explicit configured display name when available.
