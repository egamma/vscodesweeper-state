# Issue #10856 — support autossh

[https://github.com/microsoft/vscode-remote-release/issues/10856](https://github.com/microsoft/vscode-remote-release/issues/10856)

## Summary

A real Remote - SSH compatibility gap remains: autossh works through a version-output wrapper, but the extension rejects it directly. The separate request to delay the reconnect popup is already covered by the broader timeout issue.

## Change summary

Allow command-line-compatible SSH wrappers such as autossh, or make the reconnect-failure timeout configurable.

## Best solution

The SSH component should decide whether client validation can safely accept compatible wrappers without assuming OpenSSH-specific behavior. Consolidate the reconnect-timeout portion on https://github.com/microsoft/vscode-remote-release/issues/440.
