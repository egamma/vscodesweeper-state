# Issue #10856 — support autossh

[https://github.com/microsoft/vscode-remote-release/issues/10856](https://github.com/microsoft/vscode-remote-release/issues/10856)

## Summary

Keep open as an SSH compatibility request: the documented custom-client setting does not establish autossh support. The reporter's wrapper connected but did not prevent the reload dialog, so client compatibility and reconnection policy need separate consideration.

## Change summary

Allow autossh or other command-line-compatible SSH clients whose version output does not contain OpenSSH, with less aggressive reconnect failure prompting as a follow-up request.

## Best solution

The Remote - SSH owner should decide whether to support compatible wrappers through capability-aware client validation. Evaluate reconnect timing separately: bypassing version validation did not deliver the reporter's desired session recovery.
