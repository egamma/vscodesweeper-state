# Issue #7497 — Remote SSH stuck in a reconnect loop

[https://github.com/microsoft/vscode-remote-release/issues/7497](https://github.com/microsoft/vscode-remote-release/issues/7497)

## Summary

Verified duplicate: the older open canonical tracks the same Remote - SSH reconnect loop caused when a busy remote extension host stops acknowledging traffic. Consolidating there preserves the multiple confirmations and diagnostics.

## Change summary

Remote - SSH repeatedly reconnects when extension-host work or a slow connection exceeds the fixed responsiveness timeout.

## Best solution

Consolidate on https://github.com/microsoft/vscode-remote-release/issues/1257 and improve the remote connection watchdog so temporary extension-host stalls or constrained links do not trigger an endless reconnect loop or leave redundant SSH processes.
