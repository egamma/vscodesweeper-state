# Issue #7497 — Remote SSH stuck in a reconnect loop

[https://github.com/microsoft/vscode-remote-release/issues/7497](https://github.com/microsoft/vscode-remote-release/issues/7497)

## Summary

Keep open: the supplied workload triggers and communication traces suffice for a maintainer retest, but current-release reproduction remains unverified. Later reports describe continued failures despite extension removal and connection-setting workarounds; neither a fixing release nor a canonical owning the full persistent-loop behavior is established.

## Change summary

Remote sessions repeatedly reconnect after extension-host communication times out, leaving editing unusable until the window is reloaded.

## Best solution

The Remote - SSH and remote extension-host owners should investigate why successful transport reconnection does not restore extension-host responsiveness, using the supplied CodeLens and git-blame traces. Separate confirmed third-party extension stalls from the reporter's extension-disabled case before deciding whether shared VS Code core reconnection work warrants transfer.
