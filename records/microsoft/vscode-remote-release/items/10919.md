# Issue #10919 — Add support for docker buildx bake files

[https://github.com/microsoft/vscode-remote-release/issues/10919](https://github.com/microsoft/vscode-remote-release/issues/10919)

## Summary

This remains a valid, accepted feature request: it exceeded the community threshold and was moved to Backlog, while the current Dev Container specification does not provide Bake-file support.

## Change summary

Allow devcontainer.json to invoke docker buildx bake with a referenced Bake definition instead of requiring a Dockerfile or Docker Compose build.

## Best solution

Define portable Bake support through https://github.com/devcontainers/spec and implement it in the reference CLI before the Dev Containers extension consumes it; this issue can remain as the extension-side tracking request.
