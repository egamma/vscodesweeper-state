# Issue #10540 — Cannot connect to projects in WSL after upgrading to Windows 11 24H2 if BBR2 is enabled

[https://github.com/microsoft/vscode-remote-release/issues/10540](https://github.com/microsoft/vscode-remote-release/issues/10540)

## Summary

Keep open as an upstream Windows/WSL networking issue. Changing congestion control restored the reporter's connection, but this is a workaround rather than a confirmed shipped fix, and another user needed a different networking workaround.

## Change summary

WSL projects fail to connect after upgrading to Windows 11 24H2 with BBR2 enabled, despite successful server startup.

## Best solution

Windows/WSL networking owners should resolve the transport failure; the WSL extension owner should retain this report's connection logs and distinguish the BBR2 case from mirrored-networking failures. No verified canonical or shipped fix currently establishes that this report is resolved.
