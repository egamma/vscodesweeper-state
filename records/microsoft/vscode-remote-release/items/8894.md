# Issue #8894 — ssh-askpass.bat not found on Linux remote machine

[https://github.com/microsoft/vscode-remote-release/issues/8894](https://github.com/microsoft/vscode-remote-release/issues/8894)

## Summary

Keep open for Dev Containers investigation: Linux-side Docker SSH connections attempt to execute a Windows askpass script. The supplied steps and logs suffice to retest newer releases; the historical confirmations do not establish current reproduction or resolution.

## Change summary

Reopening a workspace in a remote Docker container fails when Docker runs through Remote-SSH or WSL and receives a Windows ssh-askpass.bat path.

## Best solution

Dev Containers should use authentication helpers and agent configuration appropriate to the host executing Docker and SSH. Retest both the Remote-SSH intermediate-host and WSL Docker-context paths; connecting directly to the Docker server is a workaround, not a resolution of these workflows.
