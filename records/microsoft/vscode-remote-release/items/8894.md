# Issue #8894 — ssh-askpass.bat not found on Linux remote machine

[https://github.com/microsoft/vscode-remote-release/issues/8894](https://github.com/microsoft/vscode-remote-release/issues/8894)

## Summary

The nested Remote-SSH/WSL-to-remote-Docker failure was acknowledged and independently confirmed, but the latest evidence is from March 2024. Current status needs a retest before further investigation.

## Change summary

Dev Containers passes a Windows ssh-askpass.bat path into a Linux host when Docker is reached over SSH from another remote environment.

## Best solution

Dev Containers should select an askpass helper valid for the environment where the Docker SSH command executes, supporting remote Docker from Remote-SSH and WSL hosts. First confirm whether current Dev Containers still exhibits the path mismatch.
