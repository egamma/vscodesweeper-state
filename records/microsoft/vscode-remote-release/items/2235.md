# Issue #2235 — Prompt for "rebuild + reopen in container"

[https://github.com/microsoft/vscode-remote-release/issues/2235](https://github.com/microsoft/vscode-remote-release/issues/2235)

## Summary

Keep open: the existing combined command does not establish that the local-folder notification offers it. The related resolved issue explicitly distinguishes this two-prompt improvement from its own implemented rebuild notification.

## Change summary

Offer Rebuild and Reopen in Container directly in the local-folder prompt instead of prompting separately to reopen and then rebuild.

## Best solution

The Dev Containers extension should offer the existing Rebuild and Reopen in Container action in the local notification when configuration changes require a rebuild, avoiding an unnecessary connection before rebuilding.
