# Issue #2235 — Prompt for "rebuild + reopen in container"

[https://github.com/microsoft/vscode-remote-release/issues/2235](https://github.com/microsoft/vscode-remote-release/issues/2235)

## Summary

A real Dev Containers UX gap remains: the rebuild-and-reopen operation exists, but the local-folder prompt does not expose it directly. No open canonical issue was found that owns this specific prompt improvement.

## Change summary

Offer “Rebuild and Reopen in Container” directly from the local-folder notification instead of requiring an initial reopen followed by a rebuild prompt.

## Best solution

The Dev Containers extension should add its existing rebuild-and-reopen action to the local-folder notification when the selected container configuration requires rebuilding.

- **Reason:** Reducing unnecessary connection steps improves the depth and reliability of the standard Dev Containers workflow.
