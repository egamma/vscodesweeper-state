# Issue #9641 — wrong user permission in devcontainer when using docker-compose and remoteUser

[https://github.com/microsoft/vscode-remote-release/issues/9641](https://github.com/microsoft/vscode-remote-release/issues/9641)

## Summary

Keep open as an under-discussion Dev Containers capability gap. The maintainer confirmed that UID/GID rewriting only considers the primary dev container, while multiple users confirmed permission failures in the documented multi-container Compose workflow.

## Change summary

Apply the host UID/GID update to every development service in a multi-container Docker Compose project, regardless of which container is opened first.

## Best solution

The Containers component should coordinate UID/GID updates across services represented by sibling devcontainer.json files, or provide a supported Compose-safe mechanism that works independently of container opening order.
