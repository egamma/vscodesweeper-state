# Issue #9641 — wrong user permission in devcontainer when using docker-compose and remoteUser

[https://github.com/microsoft/vscode-remote-release/issues/9641](https://github.com/microsoft/vscode-remote-release/issues/9641)

## Summary

Keep open as a Dev Containers enhancement: maintainers explain that UID/GID synchronization considers only the selected devcontainer.json, leaving other Compose services unchanged. Documented settings and manual workarounds do not deliver automatic synchronization across both development containers.

## Change summary

Automatically synchronize remote-user UID/GID in every configured Compose development container, regardless of which container is opened first.

## Best solution

Coordinate multi-container configuration support with the Dev Container specification, then implement UID/GID synchronization for participating services in Dev Containers. Retain this product-side request separately from related feature-installation reports.
