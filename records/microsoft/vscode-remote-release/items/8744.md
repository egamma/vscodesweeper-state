# Issue #8744 — Docker-Compose Dev Container Setup Cannot use multi window dev-containers and use .devcontainer.json features 

[https://github.com/microsoft/vscode-remote-release/issues/8744](https://github.com/microsoft/vscode-remote-release/issues/8744)

## Summary

Verified cross-repository duplicate: the Dev Containers spec issue tracks this exact limitation, and a maintainer confirmed this request depends on it.

## Change summary

Apply each devcontainer.json's Features and container configuration when multiple Docker Compose services are opened in separate VS Code windows.

## Best solution

Consolidate the specification work on https://github.com/devcontainers/spec/issues/546. Once the spec supports applying dev-container treatment to multiple Compose services, the Dev Containers extension can adopt that behavior.
