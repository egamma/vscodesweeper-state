Keep open: the supplied versions, rebuild steps, and log sequence suffice for a Dev Containers retest. No subsequent fix or independent reproduction is established; bootstrap removal interrupting extension installation remains distinct from the related retry requests.

## Change summary

Rebuilding a repository cloned into a container volume interrupts configured extension installation when the bootstrap container is removed.

## Best solution

The Dev Containers owner should investigate installation and bootstrap teardown ordering so configured extensions finish installing in the intended container. Interrupted installation should remain recoverable rather than leaving a marker that suppresses necessary work.
