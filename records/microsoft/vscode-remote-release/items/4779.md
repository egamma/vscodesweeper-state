# Issue #4779 — Allow to open vscode:// urls in remote

[https://github.com/microsoft/vscode-remote-release/issues/4779](https://github.com/microsoft/vscode-remote-release/issues/4779)

## Summary

This is a more specific SSH instance of the older open issue tracking remote-file handling for `vscode:` URLs. Explicit `vscode://vscode-remote/...` file URLs now work, but authority discovery, documentation, and contextual handling of ordinary file URLs remain gaps that belong in the canonical issue.

## Change summary

Allow browser-launched VS Code URLs to open files in the appropriate Remote - SSH window instead of resolving their paths on the local machine.

## Best solution

Consolidate the remaining work on https://github.com/microsoft/vscode-remote-release/issues/2578. The remote URI surface should make authorities discoverable and documented, while reliably opening remote files in the matching existing window.
