## Summary

Consolidate this request into the verified, older open issue tracking browser links opening remote files rather than local paths. Explicit remote URLs are now documented, but implicit remote-file resolution and window selection remain covered by that canonical.

## Change summary

Allow browser-launched vscode:// file links to open files in the appropriate remote workspace instead of resolving them on local disk.
