# Issue #2856 — Remote Containers: Design Bug or missdocumented feature: lack of affinity.

[https://github.com/microsoft/vscode-remote-release/issues/2856](https://github.com/microsoft/vscode-remote-release/issues/2856)

## Summary

Keep open for human review: the request combines container lifecycle management with owner-only access, making it security-sensitive under the hard keep-open rule. Existing attachment features cover part of the workflow, but do not establish the requested ownership guarantee.

## Change summary

Persist a client-to-container association for lifecycle management, monitor container state, and reject access by clients other than the creator.

## Best solution

The containers owner should separate lifecycle tracking from authorization and determine which remaining extension behavior needs improvement. Any owner-only access guarantee must account for Docker daemon permissions rather than treating a container identifier as proof of ownership.
