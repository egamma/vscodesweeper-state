## Summary

Keep open for human review because the request explicitly concerns container isolation and unauthorized attachment. It remains a containers feature request, and the thread contains neither a maintainer decision nor a canonical issue.

## Change summary

Track VS Code-created containers through a persistent identifier, monitor their state, restore stopped containers, and restrict management or attachment to the creating client.

## Best solution

The Dev Containers owner should separate lifecycle affinity from access control, then decide whether stable identity and liveness handling should improve inspect, reconnect, and restart behavior. The security boundary should also be documented because retaining a container ID and authorizing access are distinct concerns.
