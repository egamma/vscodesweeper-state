# Issue #4442 — Investigate umask behavior

[https://github.com/microsoft/vscode-remote-release/issues/4442](https://github.com/microsoft/vscode-remote-release/issues/4442)

## Summary

Keep this team-authored investigation open as the canonical issue for Remote - SSH umask behavior. Recent reports still identify the server startup shell as producing permissions inconsistent with the user's interactive SSH environment.

## Change summary

Determine how Remote - SSH should establish the VS Code Server's umask without unexpectedly changing permissions in integrated terminals or other child processes.

## Best solution

The SSH component should define and implement predictable server-startup umask behavior that respects the user's intended SSH environment while avoiding unintended inheritance by terminals. The diagnosis and workaround from issue 11666 should inform that investigation.
