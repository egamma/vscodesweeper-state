# Issue #7300 — Using an `image` fails when it is available for a different platform

[https://github.com/microsoft/vscode-remote-release/issues/7300](https://github.com/microsoft/vscode-remote-release/issues/7300)

## Summary

Keep open for the containers owner: the supplied steps and failing build command suffice to retest the image-only cross-platform case. Later reports concern platform selection during image inspection or pulling, but do not establish that this generated-build failure is fixed or fully tracked elsewhere.

## Change summary

Using a locally available amd64 image on an ARM Mac fails because the generated Dev Containers build does not select the image's platform.

## Best solution

The containers owner should retest the image-only configuration with a locally available foreign-architecture image and ensure the generated build uses the intended platform. Preserve this case separately from inspection/pull failures unless a shared fix is established.
