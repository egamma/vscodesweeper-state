# Issue #4852 — Add possibility to use a custom predefined container definitions repository for quick setup

[https://github.com/microsoft/vscode-remote-release/issues/4852](https://github.com/microsoft/vscode-remote-release/issues/4852)

## Summary

Keep open as the canonical Backlog request for searchable private Dev Container Template sources. OCI publishing and manual template references now exist, but they do not provide the requested configurable private collection in VS Code's selection UX.

## Change summary

Allow organizations to configure private Dev Container Template collections and browse their contents during quick setup.

## Best solution

The Dev Containers extension should accept configurable private OCI Template collection sources, authenticate through supported registry credentials, and include their templates in the existing searchable selection UI. This is tool-specific discovery over the established Dev Container Template specification.
