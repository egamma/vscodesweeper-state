# Issue #7879 — Clone in Volume: Support multiple devcontainer.json files

[https://github.com/microsoft/vscode-remote-release/issues/7879](https://github.com/microsoft/vscode-remote-release/issues/7879)

## Summary

Keep open as the established Dev Containers tracking issue for configuration selection when cloning into a volume. Local-folder support does not cover this workflow, and a downstream report documents the remaining gap in 2026.

## Change summary

Allow Clone Repository in Container Volume to discover and select configurations at .devcontainer/<folder>/devcontainer.json.

## Best solution

The Dev Containers extension should offer the repository's existing configurations during Clone Repository in Container Volume, matching local-folder selection without requiring users to copy files or choose a generic template.
