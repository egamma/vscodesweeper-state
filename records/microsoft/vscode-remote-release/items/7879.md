# Issue #7879 — Clone in Volume: Support multiple devcontainer.json files

[https://github.com/microsoft/vscode-remote-release/issues/7879](https://github.com/microsoft/vscode-remote-release/issues/7879)

## Summary

Keep open: this team-authored Backlog item is the canonical request for selecting among multiple devcontainer configurations during Clone in Volume, and the thread contains no evidence that capability has shipped.

## Change summary

Allow Clone Repository in Container Volume to detect multiple standard-location devcontainer.json files and let the user select or browse for one.

## Best solution

The Dev Containers extension should add configuration discovery and selection to the Clone in Volume flow, matching its existing local-folder behavior and the Dev Container specification's multiple-configuration guidance.
