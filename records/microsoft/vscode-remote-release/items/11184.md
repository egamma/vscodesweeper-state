# Issue #11184 — Allow unsetting `dotfiles.repository` in `devcontainer.json`

[https://github.com/microsoft/vscode-remote-release/issues/11184](https://github.com/microsoft/vscode-remote-release/issues/11184)

## Summary

Keep open with the existing containers routing: documented dotfiles settings do not establish a per-container opt-out from a configured user repository. Related requests do not meet the re-review bar for the same observable behavior.

## Change summary

Allow devcontainer.json to disable inherited dotfiles installation for an individual container without changing global user settings.

## Best solution

The Dev Containers component should define explicit per-container dotfiles opt-out semantics and document their precedence over user settings, allowing manual installation-script debugging without automatic setup.
