# Issue #11184 — Allow unsetting `dotfiles.repository` in `devcontainer.json`

[https://github.com/microsoft/vscode-remote-release/issues/11184](https://github.com/microsoft/vscode-remote-release/issues/11184)

## Summary

A real Dev Containers configuration gap remains: the documented dotfiles settings allow selecting a repository but provide no documented per-container opt-out. The issue is already correctly classified and routed.

## Change summary

Allow a devcontainer.json configuration to suppress a user's global dotfiles repository for one container.

## Best solution

The Dev Containers component should define and document an explicit per-container opt-out while preserving the intended precedence between personal settings and team-shared devcontainer.json configuration.
