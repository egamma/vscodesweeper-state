# Issue #423 — Remote-SSH fails on non-glibc Linux instances.

[https://github.com/microsoft/vscode-remote-release/issues/423](https://github.com/microsoft/vscode-remote-release/issues/423)

## Summary

Keep open: native musl support over Remote - SSH remains outside the documented supported surface. Existing container/WSL support and compatibility workarounds do not fulfill this request, and no verified canonical owns its full scope.

## Change summary

Detect musl-based SSH hosts and install compatible server binaries instead of glibc-dependent binaries.

## Best solution

The SSH and server owners should decide whether to support native musl hosts, including compatible runtime and native-module artifacts with reliable platform detection. Retain this issue as the broader product request rather than folding it into a narrower compatibility-layer failure.
