# Issue #423 — Remote-SSH fails on non-glibc Linux instances.

[https://github.com/microsoft/vscode-remote-release/issues/423](https://github.com/microsoft/vscode-remote-release/issues/423)

## Summary

A current capability gap remains: official documentation explicitly says Remote - SSH does not yet support Alpine's musl environment. This broad request should remain the canonical feature request rather than be folded into the narrower ARMv7 report.

## Change summary

Provide Remote - SSH server binaries or installation logic compatible with musl-based Linux hosts instead of requiring glibc.

## Best solution

The SSH and VS Code Server owners should decide and document the supported musl architectures, then provide a musl-compatible server artifact selected during installation. The existing issue is broad enough to track that work across Alpine and other non-glibc hosts.
