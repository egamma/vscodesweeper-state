# Issue #5755 — SSH disconnects when the laptop goes to sleep even for a short time while the native terminal is running

[https://github.com/microsoft/vscode-remote-release/issues/5755](https://github.com/microsoft/vscode-remote-release/issues/5755)

## Summary

Keep open: maintainers confirmed that Remote - SSH should reconnect more cleanly after wake, and recent reports demonstrate the same unresolved timeout behavior. This older, well-supported On Deck issue remains the best canonical tracker.

## Change summary

Allow Remote - SSH sessions to survive brief laptop sleep and reconnect without reauthentication or a window reload when the underlying tunnel remains viable.

## Best solution

Remote - SSH should make post-wake recovery sleep-aware, briefly allowing the existing tunnel and network stack to recover before declaring the cached connection stale, while falling back to a fresh connection when necessary.
