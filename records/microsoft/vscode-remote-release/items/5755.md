# Issue #5755 — SSH disconnects when the laptop goes to sleep even for a short time while the native terminal is running

[https://github.com/microsoft/vscode-remote-release/issues/5755](https://github.com/microsoft/vscode-remote-release/issues/5755)

## Summary

Keep open for the accepted Remote - SSH sleep/wake resilience improvement. Existing authentication workarounds do not preserve a healthy tunnel, and the newer same-symptom report does not qualify as a canonical for this re-reviewed issue.

## Change summary

Preserve or recover a usable Remote - SSH session after brief laptop sleep without unnecessary reauthentication or window reload.

## Best solution

Remote - SSH should allow connection recovery after wake, checking whether the previous tunnel remains usable before replacing it and falling back promptly when it is genuinely broken. Evaluate the newer timeout observations alongside this issue's accepted resolver-reuse direction.
