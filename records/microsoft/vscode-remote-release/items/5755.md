# Issue #5755 — SSH disconnects when the laptop goes to sleep even for a short time while the native terminal is running

[https://github.com/microsoft/vscode-remote-release/issues/5755](https://github.com/microsoft/vscode-remote-release/issues/5755)

## Summary

Keep this accepted SSH reconnection improvement open: maintainers explicitly proposed reusing healthy connections after sleep, and existing authentication and retry options only partially address the request. This issue already serves as the consolidation target for related sleep/reload reports.

## Change summary

Preserve or cleanly resume a healthy Remote - SSH connection after brief laptop sleep without unnecessary reauthentication or window reload.

## Best solution

The SSH component should implement sleep-aware connection health checks and reuse a surviving tunnel, with bounded recovery when it is genuinely broken. Use the newer timeout reports as diagnostic evidence while retaining this established tracking issue.
