# Issue #8000 — [Remote-SSH Bug]: Connection hangs at "checking for a running server"

[https://github.com/microsoft/vscode-remote-release/issues/8000](https://github.com/microsoft/vscode-remote-release/issues/8000)

## Summary

Keep open: the maintainer could not reproduce the environment-dependent hang, but subsequently accepted the unquoted process-list expansion as a valid Remote - SSH bug for the Backlog. There is no evidence that it was fixed or superseded.

## Change summary

Prevent Remote - SSH server detection from hanging when unquoted process-list contents contain glob arguments that access a stalled filesystem.

## Best solution

Remote - SSH should avoid shell expansion when inspecting the process list, ensuring that unrelated process arguments cannot block server detection. The SSH owner should confirm whether current releases still contain the vulnerable command construction and implement safe quoting or filtering if so.
