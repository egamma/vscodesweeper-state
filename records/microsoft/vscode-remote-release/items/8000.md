## Change summary

Remote-SSH server detection expands wildcard arguments from unrelated processes, potentially hanging on an inaccessible NFS mount.

## Best solution

Remote-SSH should treat captured process output as literal text when checking for an existing server, without expanding embedded filename patterns. Retest the supplied wildcard scenario on the legacy connection path and confirm whether the exec-server path also needs protection.
