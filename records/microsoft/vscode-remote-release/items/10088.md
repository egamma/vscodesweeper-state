# Issue #10088 — Allow user to add a local volume mount for all Dev Containers

[https://github.com/microsoft/vscode-remote-release/issues/10088](https://github.com/microsoft/vscode-remote-release/issues/10088)

## Summary

A real Dev Containers capability gap remains: additional mounts can be declared per project, but there is no documented user-level setting that applies them across containers. Keep the accepted Backlog request open and route it to the volume area.

## Change summary

Add a Dev Containers user setting for bind or volume mounts that should be applied to every development container.

## Best solution

The Dev Containers extension should merge user-configured default mounts with each project's configuration, supporting local variables and clearly defining precedence. Dotfiles remain useful for portable configuration files, but do not replace local bind mounts or workspace-relative mounts.
