# Issue #10669 — Notification to download git locally shows up when no git in Dev Container

[https://github.com/microsoft/vscode-remote-release/issues/10669](https://github.com/microsoft/vscode-remote-release/issues/10669)

## Summary

Keep open: a team member reproduced that the SCM notification offers a local Git download when Git is missing in a Dev Container. The team-authored report has no verified duplicate or public fixing commit referencing it.

## Change summary

Make the missing-Git notification and action remote-aware when a Dev Container does not contain Git.

## Best solution

The SCM/Git welcome flow should avoid offering a local installation for a remote environment and instead provide accurate remote-oriented guidance. Because the behavior is implemented by VS Code's built-in SCM/Git UI, a maintainer can transfer this to microsoft/vscode if the remaining fix is entirely in core.
