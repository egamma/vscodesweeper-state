# Issue #4885 — Docker-Compose: Support --env-file option

[https://github.com/microsoft/vscode-remote-release/issues/4885](https://github.com/microsoft/vscode-remote-release/issues/4885)

## Summary

The requested Compose `--env-file` capability remains absent, but the open Dev Container specification issue now owns the exact `dockerComposeArgs` proposal. Consolidating there avoids tracking spec evolution in the extension aggregate tracker.

## Change summary

Allow devcontainer configurations using Docker Compose to specify an alternate environment file and other compatible Compose arguments.

## Best solution

Define `dockerComposeArgs` in https://github.com/devcontainers/spec/issues/726, then implement it in the Dev Container CLI and extension so every spec consumer passes supported arguments consistently.
