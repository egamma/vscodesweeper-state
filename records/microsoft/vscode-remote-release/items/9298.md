# Issue #9298 — `code` executed in Git Bash terminal does not refer to the local VSCode

[https://github.com/microsoft/vscode-remote-release/issues/9298](https://github.com/microsoft/vscode-remote-release/issues/9298)

## Summary

The report identifies a plausible Windows Git Bash launcher-resolution defect, but the last reproduction used VS Code 1.85 and Remote - SSH 0.107.1. A current-version retest is needed before the remaining code-server packaging gap can be confirmed.

## Change summary

Provide a Git Bash-compatible remote `code` launcher so `code path/to/file` targets the connected local VS Code instance instead of launching the remote installation.

## Best solution

If this still reproduces, the VS Code Server packaging should provide a shell-compatible launcher alongside `code.cmd` on Windows remote hosts. The SSH/code-server owners should confirm ownership or have a maintainer transfer it to microsoft/vscode if the launcher is supplied by VS Code core.
