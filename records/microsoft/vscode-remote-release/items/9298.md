# Issue #9298 — `code` executed in Git Bash terminal does not refer to the local VSCode

[https://github.com/microsoft/vscode-remote-release/issues/9298](https://github.com/microsoft/vscode-remote-release/issues/9298)

## Summary

Keep open: the reporter demonstrated a missing Git Bash launcher despite the correct remote-cli PATH, distinct from the proposed duplicate's PATH-loss problem. The supplied steps suffice to retest on current releases; no subsequent fix or current-release confirmation is documented.

## Change summary

Running code in Git Bash on a Windows SSH host launches the host's desktop VS Code instead of opening the remote file in the connected client.

## Best solution

The Windows VS Code Server remote-cli distribution should provide a Git Bash-compatible code launcher alongside code.cmd, preserving remote file opening and argument handling. The SSH/server owners should retest the supplied Windows scenario and coordinate with core server packaging ownership if needed.
