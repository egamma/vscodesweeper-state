# Issue #3203 — Allow opening container configuration file before attaching to container

[https://github.com/microsoft/vscode-remote-release/issues/3203](https://github.com/microsoft/vscode-remote-release/issues/3203)

## Summary

Keep open for the maintainer-endorsed container context-menu action. Editing configuration before attachment is already supported through the Command Palette, but that does not establish that the requested Remote Explorer/Docker integration has shipped.

## Change summary

Expose an action on a container to create or edit its attached-container configuration before connecting.

## Best solution

Dev Containers should expose the existing configuration-editing capability from container entries in Remote Explorer and the Docker view, without requiring attachment. Preserve the Command Palette recovery path for invalid configurations.
