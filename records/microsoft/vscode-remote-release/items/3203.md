# Issue #3203 — Allow opening container configuration file before attaching to container

[https://github.com/microsoft/vscode-remote-release/issues/3203](https://github.com/microsoft/vscode-remote-release/issues/3203)

## Summary

The pre-attach Command Palette action remains documented, but the requested inline container-view action is still a valid discoverability gap that a maintainer explicitly endorsed. The existing component and type labels are correct, and no verified canonical owns the same UI request.

## Change summary

Add an action on container entries that opens or creates their attached-container configuration before VS Code attempts to attach.

## Best solution

The Dev Containers owner should expose the existing pre-attach configuration command as an inline or context action in the Remote Explorer Containers view, allowing invalid configurations to be repaired without locating their files manually.
