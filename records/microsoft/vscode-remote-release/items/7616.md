# Issue #7616 — Error: ENOTDIR when adding .devcontainer configuration files when a workspace is opened from file.

[https://github.com/microsoft/vscode-remote-release/issues/7616](https://github.com/microsoft/vscode-remote-release/issues/7616)

## Summary

This was reproducible by two users in 2022, but there is no current-release confirmation. A matching later report was completed and verified in January 2023, so the reporter should retest before further work is scheduled.

## Change summary

Adding Dev Container configuration files from a saved workspace incorrectly treats the workspace file as a directory and fails with ENOTDIR.

## Best solution

Confirm whether the current Dev Containers extension still appends `.devcontainer` to the workspace-file path. If reproduced, the containers component should resolve the target from a workspace folder rather than the `.code-workspace` file URI.
