# Issue #6413 — Override kubectl exec command

[https://github.com/microsoft/vscode-remote-release/issues/6413](https://github.com/microsoft/vscode-remote-release/issues/6413)

## Summary

Keep open: per-container user selection for Kubernetes attachment remains undocumented, and an open CLI implementation candidate references this issue. That PR does not establish that the Dev Containers attachment path supports the requested behavior.

## Change summary

Allow Kubernetes attachment to run VS Code processes as a selected container user, for example by wrapping execution with runuser.

## Best solution

Dev Containers should support per-container user selection while preserving its shell-based environment and working-directory handling. Review https://github.com/devcontainers/cli/pull/1234 and determine what integration the extension's Kubernetes attachment path still requires.
