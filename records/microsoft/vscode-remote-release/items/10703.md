# Issue #10703 — Emit warning when AFS filesystem detected

[https://github.com/microsoft/vscode-remote-release/issues/10703](https://github.com/microsoft/vscode-remote-release/issues/10703)

## Summary

Route this warning request to Remote - SSH. Moving the server off AFS mitigates the reported connection failure, but does not deliver automatic detection and guidance; no verified canonical owns that warning.

## Change summary

Emit an actionable warning when Remote - SSH detects an AFS filesystem for its server installation.

## Best solution

Remote - SSH should detect an AFS-backed server installation directory and explain the known compatibility risks, pointing users to remote.SSH.serverInstallPath for relocation to a suitable non-AFS directory.
