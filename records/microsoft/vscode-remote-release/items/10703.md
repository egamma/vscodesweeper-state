# Issue #10703 — Emit warning when AFS filesystem detected

[https://github.com/microsoft/vscode-remote-release/issues/10703](https://github.com/microsoft/vscode-remote-release/issues/10703)

## Summary

Keep this team-authored diagnostic improvement open and route it to Remote - SSH. The existing serverInstallPath workaround mitigates AFS failures but does not provide the requested proactive warning.

## Change summary

Warn Remote - SSH users when the VS Code Server installation path resides on an AFS filesystem.

## Best solution

Remote - SSH should detect an AFS-backed server installation path and recommend configuring remote.SSH.serverInstallPath to use a local filesystem. The warning should link users to the relevant troubleshooting guidance without replacing the underlying AFS compatibility work.
