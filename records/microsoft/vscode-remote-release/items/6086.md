# Issue #6086 — Investigate using local server on remoteListenOnSocket

[https://github.com/microsoft/vscode-remote-release/issues/6086](https://github.com/microsoft/vscode-remote-release/issues/6086)

## Summary

Keep the scoped Remote - SSH investigation open: socket listening still has a documented multiplexing limitation, and no verified fix covers its combination with useLocalServer and RemoteCommand. The broader HPC workflow issue does not establish the same settings-specific symptom required for a re-reviewed duplicate close.

## Change summary

Investigate supporting RemoteCommand with useLocalServer while the remote server listens on a Unix socket.

## Best solution

The SSH owner should determine whether socket forwarding can coexist with the local-server RemoteCommand path and document the supported combination. Keep scheduler allocation and login-to-compute-node forwarding design in https://github.com/microsoft/vscode-remote-release/issues/1722.
