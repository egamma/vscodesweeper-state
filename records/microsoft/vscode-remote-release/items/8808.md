# Issue #8808 — dev container issue: Is it possible to set "fetch control manifest" as optional ?

[https://github.com/microsoft/vscode-remote-release/issues/8808](https://github.com/microsoft/vscode-remote-release/issues/8808)

## Summary

A supported way to avoid the control-manifest timeout in air-gapped environments remains missing. This older, focused Backlog request is the best-diagnosed place to track that gap.

## Change summary

Allow air-gapped Dev Containers users to disable or otherwise avoid the network fetch for the control manifest.

## Best solution

The Dev Containers extension and public CLI should provide a supported offline configuration, such as a configurable manifest source or explicit opt-out, while clearly preserving or documenting the manifest's security-advisory role. Coordinate the broader air-gap work with https://github.com/microsoft/vscode-remote-release/issues/9727.
