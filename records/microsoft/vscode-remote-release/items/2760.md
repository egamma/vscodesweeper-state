# Issue #2760 — Include the `docker-compose log` as a task in the output tab

[https://github.com/microsoft/vscode-remote-release/issues/2760](https://github.com/microsoft/vscode-remote-release/issues/2760)

## Summary

Keep open: the documented container log covers build/setup diagnostics, not aggregated application logs from every Compose service in the Output tab. No verified canonical found owns that remaining request.

## Change summary

Expose logs from all services in the dev container's Docker Compose stack together in the Output tab.

## Best solution

The Dev Containers component should offer a stack-wide application-log stream associated with the active Compose project, preserving service identification in a dedicated Output channel. Existing build/setup logs should remain separate.
