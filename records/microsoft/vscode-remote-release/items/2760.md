# Issue #2760 — Include the `docker-compose log` as a task in the output tab

[https://github.com/microsoft/vscode-remote-release/issues/2760](https://github.com/microsoft/vscode-remote-release/issues/2760)

## Summary

A real Dev Containers capability gap remains: existing commands expose extension startup logs, not aggregated runtime output from every Docker Compose service. No open canonical issue was found, and the request has 13 upvotes.

## Change summary

Provide an Output view task or command that follows logs from all services in the Docker Compose project used by a dev container.

## Best solution

The Dev Containers extension should offer a command that follows the active Compose project's combined service logs in VS Code, while keeping this output distinct from the extension's container-creation log.

- **Reason:** Aggregated service logs improve diagnosability and deepen support for mainstream multi-container development.
