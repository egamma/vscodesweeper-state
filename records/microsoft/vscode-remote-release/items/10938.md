# Issue #10938 — Remote SSH connection failed

[https://github.com/microsoft/vscode-remote-release/issues/10938](https://github.com/microsoft/vscode-remote-release/issues/10938)

## Summary

The connection is intentionally rejected because the host provides GLIBCXX 3.4.24, below the documented VS Code Server requirement of 3.4.25. Supporting CentOS 7-era libraries would be a request to expand the supported environment matrix.

## Change summary

Allow Remote - SSH and VS Code Server to run on Kylin or CentOS 7-era systems whose libstdc++ lacks GLIBCXX 3.4.25.

## Best solution

Retain the documented VS Code Server prerequisites; affected users should upgrade the host or use the documented unsupported sysroot workaround for older Linux distributions.

## Vision fit

- **Fit:** rejected
- **Reason:** Supporting a host below the documented library requirements conflicts with the project's guardrail of broad environment support within pragmatic compatibility limits.
- **Evidence:** The Remote Development Linux documentation lists kernel 4.18, glibc 2.28, and libstdc++ 3.4.25 as requirements and explicitly marks CentOS 7 unsupported: https://code.visualstudio.com/docs/remote/linux
