# Issue #10938 — Remote SSH connection failed

[https://github.com/microsoft/vscode-remote-release/issues/10938](https://github.com/microsoft/vscode-remote-release/issues/10938)

## Summary

The connection is intentionally rejected because the remote host provides GLIBCXX 3.4.24, below the documented 3.4.25 minimum. Supporting this older environment is a compatibility request rather than a Remote - SSH defect.

## Change summary

Allow current VS Code Server releases to run on a Kylin host whose libstdc++ provides only GLIBCXX 3.4.24.

## Best solution

Retain the documented VS Code Server requirements; the host should upgrade its libraries or distribution, or use the documented custom-sysroot workaround for older Linux environments.
