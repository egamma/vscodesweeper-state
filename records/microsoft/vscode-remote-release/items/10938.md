# Issue #10938 — Remote SSH connection failed

[https://github.com/microsoft/vscode-remote-release/issues/10938](https://github.com/microsoft/vscode-remote-release/issues/10938)

## Summary

Keep open as an environment-dependency issue: the Kylin host provides GLIBCXX 3.4.24, below the documented 3.4.25 minimum. The logs establish a prerequisite failure, not an SSH transport defect; upstream issues are not proposed for closure.

## Change summary

Remote - SSH cannot start VS Code Server 1.100.0 on a Kylin host with libstdc++ 7.3.0.

## Best solution

The remote host administrator should provide a compatible libstdc++ runtime or migrate to a supported environment; the documented custom-sysroot workaround is an unsupported alternative. Remote - SSH owners should investigate prerequisite detection only if a compatible library is present but overlooked.
