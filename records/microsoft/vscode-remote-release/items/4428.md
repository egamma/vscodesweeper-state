## Change summary

Remote - SSH loses a dialog-specified custom SSH port when invoking scp for a locally downloaded server archive.

## Best solution

Remote - SSH should preserve the selected port by translating SSH's `-p` argument to scp's `-P` argument during local server upload. The SSH owner should verify the path on the current release before deciding whether work remains.
