# Issue #7856 — Can't use devcontainer cli on macos

[https://github.com/microsoft/vscode-remote-release/issues/7856](https://github.com/microsoft/vscode-remote-release/issues/7856)

## Summary

Keep open for the Dev Containers owner to retest the macOS CLI launcher. Related executable-path handling changed after the last confirmation, but this report already provides sufficient steps and an exact failing path; resolution on macOS remains unverified.

## Change summary

The VS Code-installed devcontainer launcher fails because it references a missing Code Helper executable under a macOS AppTranslocation directory.

## Best solution

The Dev Containers CLI launcher should resolve a valid VS Code executable rather than retain an expired translocation path. Retest the documented installation sequence on macOS against the later path-refresh changes; npm installation remains a workaround, not confirmation that the extension installer is fixed.
