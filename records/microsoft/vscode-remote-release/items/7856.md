# Issue #7856 — Can't use devcontainer cli on macos

[https://github.com/microsoft/vscode-remote-release/issues/7856](https://github.com/microsoft/vscode-remote-release/issues/7856)

## Summary

The documented VS Code installation command generated a wrapper tied to a temporary macOS AppTranslocation path, and an independent user later reproduced the same failure. The npm workaround does not fix the extension's broken installation path.

## Change summary

Installing the devcontainer CLI through VS Code on macOS can create a command wrapper referencing a temporary Code Helper location.

## Best solution

The Dev Containers extension should generate the wrapper from a stable VS Code application path, or stop with an actionable message when VS Code is running from an AppTranslocation location.
