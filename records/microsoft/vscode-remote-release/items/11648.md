# Issue #11648 — Provide a way to reset Remote-SSH connection state without reloading the window

[https://github.com/microsoft/vscode-remote-release/issues/11648](https://github.com/microsoft/vscode-remote-release/issues/11648)

## Summary

Keep this recovery-command request open and route it to the remote connection owners. Existing detection and server-liveness fixes do not establish an extension-callable reset that preserves the window after server replacement.

## Change summary

Expose a command that establishes fresh remote connections after permanent reconnection failure without reloading the window, preserving recoverable state.

## Best solution

Define fresh-session recovery in the core remote connection layer, coordinated with Remote-SSH authority resolution; a maintainer can transfer this to microsoft/vscode. Preserve local editor state and recoverable remote state, explicitly distinguishing these from terminal or debug processes lost when the server or container terminates.
