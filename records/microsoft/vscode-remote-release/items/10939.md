# Issue #10939 — Can't connect to Remote SSH server using Exec server

[https://github.com/microsoft/vscode-remote-release/issues/10939](https://github.com/microsoft/vscode-remote-release/issues/10939)

## Summary

Keep this older, well-supported report open as the canonical OpenSUSE/OpenSSL compatibility issue. Multiple users reproduced the exec-server startup failure, and later investigation isolated it to OpenSUSE's OpenSSL JITTER configuration rather than an ordinary SSH connection failure.

## Change summary

Remote - SSH's exec-server path fails to start the VS Code CLI on affected OpenSUSE systems, leaving the server log empty and producing `listeningOn====`.

## Best solution

The SSH/code-server owners should determine whether the bundled exec-server CLI can support OpenSUSE's `seed=JITTER` OpenSSL configuration or document the compatibility boundary and `remote.SSH.useExecServer: false` workaround. Newer matching reports should consolidate here rather than replace this older, broader canonical report.
