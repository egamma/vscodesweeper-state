# Issue #4802 — Unsupported architecture: riscv64

[https://github.com/microsoft/vscode-remote-release/issues/4802](https://github.com/microsoft/vscode-remote-release/issues/4802)

## Summary

RISC-V remains outside the documented Remote - SSH architecture matrix, and no existing capability satisfies the request. Keep this well-supported Backlog item open and route it to the SSH and server owners.

## Change summary

Build and distribute the VS Code Server and its native components for Linux riscv64 so Remote - SSH can connect to RISC-V hosts.

## Best solution

Produce, test, and distribute riscv64 VS Code Server artifacts, then add RISC-V to the documented Remote - SSH support matrix. This older, detailed issue should remain the canonical request, with the overlapping https://github.com/microsoft/vscode-remote-release/issues/6687 consolidated into it.

## Vision fit

- **Fit:** aligned
- **Reason:** Supporting RISC-V would extend remote-development parity and the VS Code Server lifecycle to another Linux architecture.
- **Evidence:** The public product promise is to "Open any folder in a container, on a remote machine, or in WSL and take advantage of VS Code's full feature set," while server lifecycle and broad environment support are durable themes.
