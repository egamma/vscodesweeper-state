# Issue #11604 — Dev Containers: reconnecting to existing subfolder config container fails with "devcontainer.json not found"

[https://github.com/microsoft/vscode-remote-release/issues/11604](https://github.com/microsoft/vscode-remote-release/issues/11604)

## Summary

Keep open with the containers owner: an independent user confirmed the missing-config failure through Dev Containers 0.466.0 and identified an additional Remote Explorer symptom. No confirmed fix or canonical covering the full reconnect behavior was found.

## Change summary

Reconnecting to an existing container loses its nested devcontainer configuration path and incorrectly searches for a root-level devcontainer.json.

## Best solution

Dev Containers should preserve the selected configuration across reconnect commands and Remote Explorer URIs, passing it consistently to the CLI. Equivalent running-container and recent entries should retain the same configuration identity and be deduplicated without hiding distinct workspaces.
