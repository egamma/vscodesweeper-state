# Issue #3216 — [wsl] open \\wsl$\.. directly in Remote WSL

[https://github.com/microsoft/vscode-remote-release/issues/3216](https://github.com/microsoft/vscode-remote-release/issues/3216)

## Summary

Consolidate this request into the older, currently open default-WSL launch request, whose discussion explicitly covers Open with Code opening WSL UNC paths locally. The documented commands are workarounds, not automatic Explorer integration.

## Change summary

Automatically open WSL UNC folders selected through Windows Explorer's Open with Code action in the corresponding WSL remote environment.

## Best solution

Track automatic WSL launch behavior in https://github.com/microsoft/vscode-remote-release/issues/2365, preserving this report's requirement to infer the distribution from the UNC path. The WSL owner and VS Code launch integration need to account for extension availability and user preference.
