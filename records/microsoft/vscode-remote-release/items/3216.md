# Issue #3216 — [wsl] open \\wsl$\.. directly in Remote WSL

[https://github.com/microsoft/vscode-remote-release/issues/3216](https://github.com/microsoft/vscode-remote-release/issues/3216)

## Summary

Keep open: documented WSL commands do not establish automatic routing of Explorer's existing Open with Code action. The maintainer endorsed this improvement; the related context-menu request does not clearly own the automatic-detection requirement.

## Change summary

Automatically open WSL UNC folders selected through Windows Explorer's Open with Code action in a WSL-connected window instead of as Windows network shares.

## Best solution

The WSL component should coordinate with VS Code's Windows launch handling to recognize WSL UNC folders, honoring extension availability and the user's connection preference. Retain this issue's automatic-routing requirement separately from proposals for an additional explicit context-menu action.
