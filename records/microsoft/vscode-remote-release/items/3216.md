# Issue #3216 — [wsl] open \\wsl$\.. directly in Remote WSL

[https://github.com/microsoft/vscode-remote-release/issues/3216](https://github.com/microsoft/vscode-remote-release/issues/3216)

## Summary

A real WSL workflow gap remains: current documentation supports explicit WSL commands but not opening a WSL UNC path directly in Remote WSL from Explorer. This older Backlog item should remain the canonical request.

## Change summary

Detect WSL UNC folders opened through Windows Explorer and launch them directly in a Remote WSL window.

## Best solution

The WSL extension and VS Code launcher should coordinate so an Explorer-opened `\\wsl$` or `\\wsl.localhost` path can be translated to its distro and Linux path, with an explicit user choice where automatic routing would be ambiguous. Consolidate the matching request at https://github.com/microsoft/vscode-remote-release/issues/6416 into this older canonical issue.
