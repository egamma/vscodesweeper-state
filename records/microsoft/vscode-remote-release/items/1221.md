# Issue #1221 — Visual Studio Code Remote - Serial

[https://github.com/microsoft/vscode-remote-release/issues/1221](https://github.com/microsoft/vscode-remote-release/issues/1221)

## Summary

This remains an unsupported feature request with meaningful community interest and no canonical issue or existing capability covering serial transport. Keep it open for an explicit product-scope decision.

## Change summary

Add a serial-console transport for using VS Code Remote with devices that have no network connection.

## Best solution

The remote/code-server owners should decide whether the existing client-server protocol can reasonably support serial links without compromising the full remote-development experience. If accepted, connection setup, server installation, and reconnection over constrained serial links all need a defined design.
