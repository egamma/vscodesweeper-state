# Issue #7704 — Reveal in Explorer shortcut not working with WSL Remote Development

[https://github.com/microsoft/vscode-remote-release/issues/7704](https://github.com/microsoft/vscode-remote-release/issues/7704)

## Summary

Keep open: the reporter isolated a WSL-specific difference in shortcut focus conditions, and the supplied steps suffice to retest. Later fixes to Reveal in Explorer do not establish that this shortcut discrepancy was resolved.

## Change summary

Shift+Alt+R fails with Explorer focus in a WSL window even though the Reveal in Explorer context-menu action works.

## Best solution

The WSL component owner should compare the default reveal keybindings with Explorer and editor focus and make the WSL shortcut work consistently with local windows. Investigate the focus conditions before changing the working native-Explorer launch path.
