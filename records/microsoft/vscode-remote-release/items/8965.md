# Issue #8965 — Can't specify platform for Docker image in DevContainers

[https://github.com/microsoft/vscode-remote-release/issues/8965](https://github.com/microsoft/vscode-remote-release/issues/8965)

## Summary

Propose consolidating into the verified older open report: both describe Dev Containers attempting an ARM64 image pull despite FROM --platform=linux/amd64, preventing container creation. The Python image and alternative configuration attempts here provide additional evidence of the same failure.

## Change summary

Dev Containers fails to inspect or pull an AMD64-only base image on Apple Silicon despite an explicit Dockerfile platform.

## Best solution

Track the platform-aware image inspection and pull fix in https://github.com/microsoft/vscode-remote-release/issues/8737, preserving this report's Python buster example and maintainer-confirmed manual-pull workaround.
