# Issue #11431 — Ordering Projects

[https://github.com/microsoft/vscode-remote-release/issues/11431](https://github.com/microsoft/vscode-remote-release/issues/11431)

## Summary

Alphabetical project ordering is already supported through remote.SSH.foldersSortOrder. This setting covers the central request without requiring a new ordering control.

## Change summary

Allow alphabetical ordering of projects under an SSH server to make large project lists easier to navigate.

## Best solution

Use the existing Remote - SSH folder-sorting setting to order projects alphabetically in Remote Explorer; no additional product capability is needed for the stated goal.
