# Issue #5307 — When using remote container, we're forced to download docker desktop, it is possible to use remote docker container via ssh only?

[https://github.com/microsoft/vscode-remote-release/issues/5307](https://github.com/microsoft/vscode-remote-release/issues/5307)

## Summary

Implemented and shipped in VS Code 1.63: Dev Containers can run through a Remote - SSH session without Docker or Docker Desktop installed locally. The current documentation describes this exact supported workflow.

## Change summary

Allow using a Docker-backed dev container on a remote SSH host without installing Docker Desktop locally.

## Best solution

Keep the shipped Remote - SSH plus Dev Containers workflow documented at https://code.visualstudio.com/remote/advancedcontainers/develop-remote-host; no additional implementation is needed for the central request.

## Vision fit

- **Fit:** aligned
- **Reason:** Running Dev Containers on an SSH host without a local Docker installation advances remote-development parity through the established client-server architecture.
- **Evidence:** The vision promises users can "Open any folder in a container, on a remote machine, or in WSL and take advantage of VS Code's full feature set."
