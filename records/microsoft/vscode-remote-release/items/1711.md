## Summary

Verified duplicate: the open, broader dynamic-runArgs issue tracks shell-generated Docker arguments and has ongoing discussion through 2026. The UID/GID example is now partly addressed by automatic UID/GID synchronization, but the generic command-substitution gap belongs with that canonical request.

## Change summary

Allow command-backed input variables in devcontainer.json runArgs so host-derived values can be passed to Docker.
