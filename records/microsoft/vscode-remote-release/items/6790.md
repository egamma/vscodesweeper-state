# Issue #6790 — `Rebuild Container` fails for broken multi root Workspace Container

[https://github.com/microsoft/vscode-remote-release/issues/6790](https://github.com/microsoft/vscode-remote-release/issues/6790)

## Summary

Keep open: a maintainer confirmed that failed multi-root container resolution prevents the rebuild handler from running. The report targets 2022 releases, so current behavior remains unverified, but the supplied steps and failing Dockerfile suffice to retest.

## Change summary

Rebuild Container does nothing after a multi-root workspace's initial container build fails and the error popup is dismissed.

## Best solution

Dev Containers should allow rebuilding a multi-root workspace after an initial build failure, matching single-folder recovery. Retest the supplied trigger and coordinate with VS Code core on command activation after resolver failure; a maintainer can transfer this to microsoft/vscode if core ownership is established.
