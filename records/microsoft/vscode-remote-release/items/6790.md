# Issue #6790 — `Rebuild Container` fails for broken multi root Workspace Container

[https://github.com/microsoft/vscode-remote-release/issues/6790](https://github.com/microsoft/vscode-remote-release/issues/6790)

## Summary

A maintainer reproduced that Rebuild Container never reaches its command handler after a failed resolver attempt in a multi-root workspace. No fix, resolution confirmation, or verified canonical issue is documented, so this should remain open.

## Change summary

Allow Rebuild Container to run after an initial multi-root workspace container build fails.

## Best solution

The Dev Containers and workbench owners should ensure the rebuild command remains invokable after authority resolution fails for a multi-root workspace, transferring the relevant work to microsoft/vscode if the command-dispatch failure is entirely in core.
