# Issue #6464 — Env Vars (proxy) specified in devcontainer.json don't propagate to containers used to build/add advanced features

[https://github.com/microsoft/vscode-remote-release/issues/6464](https://github.com/microsoft/vscode-remote-release/issues/6464)

## Summary

Keep this accepted Dev Containers feature request open: Dockerfile build arguments cover some scenarios, but the thread still identifies a gap for configuring feature-installation proxies with registry images without changing host-wide defaults. No verified canonical owns the full remaining request.

## Change summary

Allow per-dev-container proxy configuration to reach feature-installation builds, including configurations based directly on registry images.

## Best solution

The Dev Containers component should provide a supported, scoped way to supply proxy settings during feature installation without affecting unrelated containers or requiring a wrapper Dockerfile. Preserve the distinction between runtime containerEnv and build-time configuration, coordinating any format changes with the Dev Container specification.
