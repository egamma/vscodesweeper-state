# Issue #6464 — Env Vars (proxy) specified in devcontainer.json don't propagate to containers used to build/add advanced features

[https://github.com/microsoft/vscode-remote-release/issues/6464](https://github.com/microsoft/vscode-remote-release/issues/6464)

## Summary

A real capability gap remains: build arguments now cover some Dockerfile-based feature builds, but image-based and other configurations still cannot provide per-devcontainer proxy variables to the generated feature build. The existing Docker client proxy workaround affects every container and does not satisfy the requested isolation.

## Change summary

Allow proxy environment variables or build arguments from devcontainer.json to propagate into the generated build stage that installs Features.

## Best solution

The Dev Containers implementation and devcontainers CLI should provide a documented, per-devcontainer mechanism for passing proxy configuration into generated Feature builds, including image-based and Compose configurations, without changing Docker's host-wide proxy configuration. Coordinate the implementation with https://github.com/devcontainers/cli/issues/927 while retaining this older, broader tracker issue.
