[https://github.com/microsoft/vscode-remote-release/issues/4123](https://github.com/microsoft/vscode-remote-release/issues/4123)

## Summary

Fixed and verified in VS Code 1.52: VS Code 1.51 mishandled the null working directory sent when C# debugging launched an integrated terminal in a remote environment.

## Change summary

Launching a .NET Core application with the C# debugger's integratedTerminal console hangs under Remote-WSL.
