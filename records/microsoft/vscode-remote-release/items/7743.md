# Issue #7743 — Linter is marking "consistency" as invalid option for "mounts" entry of devcontainer.json file

[https://github.com/microsoft/vscode-remote-release/issues/7743](https://github.com/microsoft/vscode-remote-release/issues/7743)

## Summary

Keep open: an independent user confirmed the diagnostic on Dev Containers 0.469.0 in September 2026. String-form mounts support consistency, but that workaround does not resolve the reported object-form validation gap.

## Change summary

Object-form mounts in devcontainer.json reject the consistency property despite documentation referring users to Docker's mount options.

## Best solution

The Dev Containers owner should reconcile object-form validation with the documented mount syntax, coordinating any shared schema change with devcontainers/spec and checking runtime support before accepting additional properties. Document the string-form workaround without treating it as resolution of this accepted bug.
