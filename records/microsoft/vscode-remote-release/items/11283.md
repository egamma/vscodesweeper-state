# Issue #11283 — Extremely High CPU Usage with rg process spawns

[https://github.com/microsoft/vscode-remote-release/issues/11283](https://github.com/microsoft/vscode-remote-release/issues/11283)

## Summary

Keep open: the attach steps and full process tree provide a concrete retest starting point, with a later user reporting matching package.json enumeration. The earlier Dev Containers discovery fix predates this report and does not establish resolution of these different searches.

## Change summary

Attaching VS Code to a running container starts ripgrep file-enumeration processes that consume many CPU cores.

## Best solution

The containers owner should identify which remote extension-host consumers launch the general file and package.json searches, then address excessive traversal or cancellation in the owning component. A maintainer can transfer this to microsoft/vscode if investigation establishes that core search or a built-in consumer owns the whole defect.
