# Issue #11805 — Remote-SSH Bug: reconnect forfeits its 3-hour grace on the first attempt when a managed socket closes mid-connect

[https://github.com/microsoft/vscode-remote-release/issues/11805](https://github.com/microsoft/vscode-remote-release/issues/11805)

## Summary

Route to SSH reconnection owners: a fresh independent confirmation shows the same managed-socket error prematurely ending reconnection on VS Code 1.147 and Remote-SSH 0.128.0. The issue remains actionable; neither a confirmed fix nor a qualifying canonical was established.

## Change summary

A managed socket closing during reconnection immediately exhausts recovery despite the announced three-hour grace period, sometimes silently abandoning the remote extension host.

## Best solution

The SSH owners should coordinate managed-socket error classification with the VS Code core reconnection owners so transient transport closures remain retryable within the grace period without masking genuine permanent failures. Investigate the newly reported stale-authority race and ensure extension-host recovery failures are visible.
