# Issue #11482 — Please Provide Clear Warning When Delete WSL OS under WSL Targets

[https://github.com/microsoft/vscode-remote-release/issues/11482](https://github.com/microsoft/vscode-remote-release/issues/11482)

## Summary

Keep open as a WSL safety polish item: the destructive action needs to state clearly that it permanently deletes the distribution and its data. Existing documentation warns about this consequence, but that does not protect users acting through the VS Code UI.

## Change summary

Make the WSL Targets deletion confirmation explicitly warn that the selected distribution and all its data will be permanently lost.

## Best solution

The WSL extension should name the selected distribution and require an unambiguous destructive confirmation before invoking unregister, clearly distinguishing permanent deletion from disconnecting or removing a target reference.
