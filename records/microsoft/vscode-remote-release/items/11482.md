# Issue #11482 — Please Provide Clear Warning When Delete WSL OS under WSL Targets

[https://github.com/microsoft/vscode-remote-release/issues/11482](https://github.com/microsoft/vscode-remote-release/issues/11482)

## Summary

The requested explicit warning already exists: a maintainer documented a confirmation naming permanent distribution deletion and loss of all its data before this report. The thread does not identify a path that bypasses that confirmation.

## Change summary

Clearly warn that deleting a WSL target permanently removes the entire distribution and its data, rather than disconnecting it from VS Code.

## Best solution

Retain the existing explicit deletion confirmation. If a particular WSL Targets action omits it, investigate that specific path as a separate WSL extension defect; removing distribution management entirely is a different request.
