# Issue #2509 — "Connecting with SSH timed out" when Fish/tcsh/csh shell is used

[https://github.com/microsoft/vscode-remote-release/issues/2509](https://github.com/microsoft/vscode-remote-release/issues/2509)

## Summary

This remains the canonical Remote - SSH issue for connection failures caused by Fish/tcsh/csh login shells. A merged workaround did not fully resolve the behavior, and current-version reports continue to reproduce it.

## Change summary

Remote - SSH should connect successfully when the remote account uses Fish, tcsh, or csh as its default shell.

## Best solution

Keep this as the canonical SSH tracker and make platform detection and server bootstrap invoke a compatible shell independently of the account's default shell, without requiring remotePlatform or useLocalServer workarounds. The narrower https://github.com/microsoft/vscode-remote-release/issues/10967 should consolidate here.
