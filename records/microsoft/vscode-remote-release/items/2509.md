# Issue #2509 — "Connecting with SSH timed out" when Fish/tcsh/csh shell is used

[https://github.com/microsoft/vscode-remote-release/issues/2509](https://github.com/microsoft/vscode-remote-release/issues/2509)

## Summary

Keep open: recent confirmations establish useful workarounds, not resolution of the default-shell timeout. Connection modes have evolved since the original regression, but the supplied bash-versus-fish steps and log suffice for a maintainer to retest.

## Change summary

Remote - SSH authenticates successfully but times out during initialization when the remote login shell is Fish/tcsh/csh rather than bash.

## Best solution

The SSH component should make platform detection and server bootstrapping work with these login shells without requiring per-host platform overrides or changing the user's shell. Retest the existing shell-switch reproduction across connection modes and retain this established report as the consolidation point for matching failures.
