# Issue #9027 — Git - Copied path of staged file includes backslashes

[https://github.com/microsoft/vscode-remote-release/issues/9027](https://github.com/microsoft/vscode-remote-release/issues/9027)

## Summary

Keep open: the supplied steps and follow-up recordings suffice to retest the staged-file path mismatch, but resolution on current releases is unverified. VS Code and Remote - SSH have advanced since the reported versions; that alone does not establish a fix for this reopened issue.

## Change summary

Staged Git files opened over SSH from Windows display and copy Linux paths with backslashes when the repository is outside the remote home directory.

## Best solution

Ensure staged Git resources use the remote Linux path conventions consistently with working-tree files, including repositories outside the home directory. A maintainer can transfer this to microsoft/vscode for investigation of the built-in Git resource and editor path-label handling; confirm that ownership while retesting the supplied steps.
