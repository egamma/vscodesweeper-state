# Issue #11896 — Buildx v0.37.2 breaks compose builds

[https://github.com/microsoft/vscode-remote-release/issues/11896](https://github.com/microsoft/vscode-remote-release/issues/11896)

## Summary

Keep open as an upstream Docker Compose compatibility issue affecting Dev Containers. The matching upstream fix has merged, but this thread confirms only workarounds, not resolution with an updated Compose release.

## Change summary

Compose-based Dev Container builds fail when Buildx enforces filesystem permissions for the generated temporary Dockerfile.

## Best solution

Docker Compose should grant read access to the generated Dockerfile while preserving Buildx entitlement enforcement. The containers owner should track the upstream fix's availability and verify the original build works without disabling those checks.

## Evidence

- **Verified upstream cause:** https://github.com/docker/compose/issues/14285 describes the identical Dockerfile-with-features failure: Compose invokes Bake with rawjson progress but omits read grants for Dockerfiles outside the build context. https://github.com/docker/compose/issues/14285#issuecomment-6120262146 confirms Compose must supply those grants.
- **Merged upstream fix:** https://github.com/docker/compose/pull/14325 merged on 2026-10-12 and grants permissions for configured build inputs, including external Dockerfiles, without disabling entitlement enforcement. It supersedes https://github.com/docker/compose/pull/14286, which closed without merging.

It cannot serve as an open duplicate canonical, and this issue's reporter has not confirmed resolution.
