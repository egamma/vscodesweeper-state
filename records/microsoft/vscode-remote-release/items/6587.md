# Issue #6587 — Automatic build of devcontainers based on repository code

[https://github.com/microsoft/vscode-remote-release/issues/6587](https://github.com/microsoft/vscode-remote-release/issues/6587)

## Summary

Keep open: existing template selection and dependency-installation hooks cover parts of the workflow, but do not establish the requested post-clone prompt and automatic, repository-specific configuration generation. The issue is already routed to containers, and no verified canonical owns its full scope.

## Change summary

After cloning a repository, offer to infer its language and dependencies, generate a template-based dev container configuration, and reopen in the container.

## Best solution

The Dev Containers extension should offer an opt-in post-clone configuration flow that recommends a template and dependency-installation commands from repository contents, lets the user review the generated files, and offers to reopen in the container.
