# Issue #6587 — Automatic build of devcontainers based on repository code

[https://github.com/microsoft/vscode-remote-release/issues/6587](https://github.com/microsoft/vscode-remote-release/issues/6587)

## Summary

A meaningful automation gap remains: current tooling recommends templates based on folder contents, but does not fully infer project dependencies and proactively generate a configuration after a normal repository clone.

## Change summary

Offer to generate and open a Dev Container automatically after cloning, using detected languages and dependency manifests.

## Best solution

The Dev Containers extension should offer an opt-in post-clone flow that selects a suitable template, incorporates detected dependency manifests, writes the configuration, and offers to reopen the repository in the container.
