# Issue #11649 — Support ssh keys without the trailing newline

[https://github.com/microsoft/vscode-remote-release/issues/11649](https://github.com/microsoft/vscode-remote-release/issues/11649)

## Summary

The Windows OpenSSH client rejects the newline-less private key, but Remote - SSH could make the resulting authentication failure substantially easier to diagnose. Route this to SSH authentication as a diagnostic improvement rather than treating it as an extension connection bug.

## Change summary

Recognize private-key format failures caused by a missing final newline and provide actionable guidance instead of only falling back to password authentication.

## Best solution

Remote - SSH should continue delegating key parsing to the configured OpenSSH client, while recognizing its `Load key ...: invalid format` output and surfacing targeted key-format guidance before or alongside the password fallback.
