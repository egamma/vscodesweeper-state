Keep open during the active 60-day Backlog Candidates window and route to Remote - SSH. Public documentation provides no profile-specific alternative for configuring always-installed SSH extensions.

## Change summary

Allow `remote.SSH.defaultExtensions` to contain different extension lists for individual VS Code profiles.

## Best solution

Remote - SSH should make `remote.SSH.defaultExtensions` profile-specific, or provide an equivalent profile-aware setting, so switching profiles also changes which extensions are automatically installed on SSH hosts.
