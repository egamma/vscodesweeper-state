# Issue #3143 — VMware Fusion Nautilus Support

[https://github.com/microsoft/vscode-remote-release/issues/3143](https://github.com/microsoft/vscode-remote-release/issues/3143)

## Summary

VMware Nautilus support remains unimplemented, but the upstream vctl project and documentation are archived and vctl never supplied the Docker CLI compatibility Dev Containers requires. Keep this open for an explicit maintainer scope decision rather than inferring an out-of-scope close.

## Change summary

Allow Dev Containers to use VMware Fusion's Nautilus/vctl runtime instead of Docker Desktop on macOS.

## Best solution

The containers owner should determine whether any supported successor to Nautilus offers the Docker-compatible inspect, events, and related operations required by Dev Containers. Without such an active runtime, a Nautilus-specific integration should not be implemented.
