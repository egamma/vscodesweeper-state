# Issue #11485 — upgrading vscode with multiple instances opened to the same linux remote will cause corrupt installation

[https://github.com/microsoft/vscode-remote-release/issues/11485](https://github.com/microsoft/vscode-remote-release/issues/11485)

## Summary

Keep open: the supplied multi-window restart steps and paired installation logs suffice to retest the SSH installation race. A subsequent WSL installer fix addresses a different path; no verified SSH fix or qualifying canonical was found.

## Change summary

Concurrent Remote - SSH windows install the same server version simultaneously after an upgrade, leaving missing modules and an unusable installation.

## Best solution

The SSH owner should ensure installation coordination covers download, extraction, and publication of the complete server, with waiting windows reusing the finished installation rather than installing concurrently. Retest the supplied multi-window scenario and distinguish shared-trigger handling from server-side staging-directory races.
