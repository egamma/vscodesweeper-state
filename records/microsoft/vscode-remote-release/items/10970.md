# Issue #10970 — Can't use vscode git commit when inside a devcontainer

[https://github.com/microsoft/vscode-remote-release/issues/10970](https://github.com/microsoft/vscode-remote-release/issues/10970)

## Summary

Keep open: the supplied log demonstrates that host-specific SSH signing configuration is copied into the Dev Container but its required signer file is not, and a maintainer confirmed both failures. The issue is already correctly routed to Dev Containers.

## Change summary

Git commits fail inside a Dev Container when copied host Git configuration references an unavailable SSH signing key or allowed-signers file.

## Best solution

Dev Containers should omit an unusable host `user.signingKey` and reliably transfer or rewrite `gpg.ssh.allowedSignersFile`; its Git-config sanitization should also account for other host-only executable paths where feasible.
