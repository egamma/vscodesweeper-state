# Issue #10970 — Can't use vscode git commit when inside a devcontainer

[https://github.com/microsoft/vscode-remote-release/issues/10970](https://github.com/microsoft/vscode-remote-release/issues/10970)

## Summary

Keep open: a maintainer confirmed that Dev Containers incorrectly preserves a host-only SSH signing key and fails to copy the configured allowed-signers file.

## Change summary

Git commits fail inside a Dev Container when copied Windows Git configuration references SSH-signing files and tools unavailable in the container.

## Best solution

Dev Containers should remove or translate host-only `user.signingkey` values while copying Git configuration and reliably copy or remap `gpg.ssh.allowedSignersFile` into the target container.
