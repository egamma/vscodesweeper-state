# Issue #6494 — Disconcerting delay after clicking `Open in Container`

[https://github.com/microsoft/vscode-remote-release/issues/6494](https://github.com/microsoft/vscode-remote-release/issues/6494)

## Summary

This remains a valid Dev Containers feedback gap in a common workflow. Current releases have a progress panel, but newer reports show that users can still receive no immediate acknowledgement in related container-opening flows.

## Change summary

Show immediate progress feedback after the user accepts the Open in Container prompt.

## Best solution

The Dev Containers extension should display its progress notification as soon as an open or create command is accepted, before potentially slow preparation and window reload work begins.

- **Reason:** Prompt progress feedback improves diagnosability and makes remote workflows behave more predictably like local ones.
