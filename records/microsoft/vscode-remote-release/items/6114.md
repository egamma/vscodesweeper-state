# Issue #6114 — Current Docker context not used when connected to SSH server

[https://github.com/microsoft/vscode-remote-release/issues/6114](https://github.com/microsoft/vscode-remote-release/issues/6114)

## Summary

This was well-confirmed through 2023, but needs a current retest because the documentation now says Dev Containers honors the active Docker context or `containers.environment`. No recent confirmation establishes whether the SSH-specific failure remains.

## Change summary

Dev Containers uses the default Docker socket instead of the active Docker context when invoked after connecting through Remote - SSH.

## Best solution

Dev Containers should honor the active Docker context on an SSH host, including rootless Docker endpoints, without requiring shell-profile workarounds. A current creation log should confirm whether that documented behavior now works or identify where context detection still falls back to `default`.
