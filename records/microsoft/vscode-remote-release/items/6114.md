# Issue #6114 — Current Docker context not used when connected to SSH server

[https://github.com/microsoft/vscode-remote-release/issues/6114](https://github.com/microsoft/vscode-remote-release/issues/6114)

## Summary

Keep open: the thread establishes a Dev Containers context-selection defect over Remote-SSH, but contains no confirmed fix or current-release reproduction. The supplied steps and diagnostic logs suffice to retest; documentation and setting names have since changed, which does not establish resolution.

## Change summary

Dev Containers uses the default Docker endpoint instead of the SSH host's selected Docker context when reopening a folder in a container.

## Best solution

The Dev Containers owner should retest the documented SSH workflow with an active non-default context and ensure Docker invocations use the SSH host's context unless explicitly overridden. Retain this issue as the tracking report; shell exports and client-side SSH contexts are workarounds, not equivalent context-selection behavior.
