Request a reproducible save scenario and performance diagnostics before deciding ownership or resolution. The intermittent load spikes lack a sample, remote-extension isolation, and a profile; related reports do not establish the same root cause.

## Change summary

Saving files in remote Angular, Node.js, or Rust projects intermittently produces excessive server-process load in WSL2 and Docker.

## Best solution

The WSL and Dev Containers owners should isolate the save-triggered workload using a small reproducer and remote extension-host diagnostics, then address the responsible process without sacrificing remote language features.
