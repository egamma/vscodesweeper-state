## Change summary

Allow remote extensions to download version- and platform-specific VS Code Server artifacts from a configurable internal source while preserving the public source as the default.

- **Existing capability is partial:** https://code.visualstudio.com/docs/remote/faq documents remote.SSH.localServerDownload and local download followed by transfer for Dev Containers. These avoid remote-host internet access but still require local access to Microsoft's download hosts; they do not configure an internal artifact source.
