# Issue #11546 — Extension host crash on restart/reload

[https://github.com/microsoft/vscode-remote-release/issues/11546](https://github.com/microsoft/vscode-remote-release/issues/11546)

## Summary

The Dev Containers reload race was independently reproduced through 1.118.1, but a closely matching `dev-container` report was subsequently confirmed resolved on VS Code 1.123.0 with Dev Containers 0.459.1. The original Docker-based reproduction needs retesting before this can be closed.

## Change summary

Reloading a dev-container window while remote extensions are being reconciled can terminate the extension host and leave authority reconnection without its previous result.

## Best solution

Confirm that the Dev Containers extension preserves or recreates the `dev-container` authority result when extension reconciliation restarts the host; first retest the minimal Docker reproduction on current releases to determine whether that path is already fixed.
