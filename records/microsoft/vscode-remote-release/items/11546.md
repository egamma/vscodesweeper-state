# Issue #11546 — Extension host crash on restart/reload

[https://github.com/microsoft/vscode-remote-release/issues/11546](https://github.com/microsoft/vscode-remote-release/issues/11546)

## Summary

Keep open: the minimal container sample and independent confirmation establish a reload/reconnect failure, not a proven defect in a particular installed extension. No verified canonical or fix covers this report's dev-container behavior.

## Change summary

Reloading a dev container with extensions configured terminates the extension host and leaves reconnect failing with 'Reconnect attempt without old result'.

## Best solution

The Dev Containers owner should investigate the reported extension-reconciliation timing and ensure authority resolution recovers after extension-host restart. Coordinate with VS Code core if renderer-driven extension reconciliation is responsible, while retaining this product-side recovery report.

- **Independent confirmation and diagnosis:** https://github.com/microsoft/vscode-remote-release/issues/11546#issuecomment-4467670703 confirms the failure on VS Code 1.118.1 / Dev Containers 0.459.0 with Python or YAML alone.
