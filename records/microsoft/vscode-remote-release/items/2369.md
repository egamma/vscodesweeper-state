# Issue #2369 — Git through SSH with passphrase-protected key when in WSL remote

[https://github.com/microsoft/vscode-remote-release/issues/2369](https://github.com/microsoft/vscode-remote-release/issues/2369)

## Summary

Keep open: multiple users reproduced WSL Source Control operations hanging or failing because VS Code cannot use the SSH agent or present the key passphrase. Current troubleshooting documentation still identifies this as a known limitation.

## Change summary

Git operations initiated from VS Code in a WSL window should use the available SSH agent or prompt for a passphrase instead of hanging or failing.

## Best solution

The WSL integration should provide Source Control Git processes with the correct SSH agent environment and a functioning askpass prompt, while allowing blocked operations to be cancelled without restarting VS Code.
