# Issue #2369 — Git through SSH with passphrase-protected key when in WSL remote

[https://github.com/microsoft/vscode-remote-release/issues/2369](https://github.com/microsoft/vscode-remote-release/issues/2369)

## Summary

Keep open: WSL Source Control authentication remains a documented limitation, with no verified fix covering both missing passphrase prompts and agent visibility. The supplied steps suffice to retest; the latest report concerns VS Code 1.98.0, not the current release.

## Change summary

Git operations from WSL Source Control fail or hang without a passphrase prompt despite working from the terminal.

## Best solution

The WSL component owner should investigate agent-environment propagation and remote Git passphrase prompting together, coordinating with the built-in Git owner where needed. Source Control should use the available agent or request the passphrase, and authentication failures should remain cancellable.
