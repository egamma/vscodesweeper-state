## Summary

Keep open as the IBM i platform-support request. Current documentation does not establish IBM i support, and the related issues do not provide a valid canonical or evidence of resolution.

## Change summary

Support Remote - SSH development on IBM i, including running Git on the remote host.

The SSH and VS Code Server owners should assess an IBM i-compatible server distribution and installation path, including native dependencies and platform utilities. Retain this issue for that platform decision rather than folding it into Linux architecture support or connection-error wording.
