# Issue #520 — Support ssh to IBM i

[https://github.com/microsoft/vscode-remote-release/issues/520](https://github.com/microsoft/vscode-remote-release/issues/520)

## Summary

IBM i remains outside the documented Remote - SSH host matrix, and no existing setting or command provides the requested support. This is the oldest, best-diagnosed IBM i request and should remain the canonical feature request.

## Change summary

Add Remote - SSH and VS Code Server support for IBM i hosts.

## Best solution

The SSH and VS Code Server owners should assess an IBM i port covering OS400 detection, server packaging, Node.js, native modules, shell utilities, and filesystem watching, then document IBM i prerequisites if support is feasible.

## Vision fit

- **Fit:** aligned
- **Reason:** Supporting IBM i would extend remote-development parity to another SSH environment, although its native-runtime requirements make this a deliberate support-matrix decision.
- **Evidence:** The public vision identifies remote parity and SSH breadth as durable themes while treating environments outside the documented requirements as scope decisions rather than defects.

## Evidence

- **current requirements:** The current Remote - SSH system requirements at https://code.visualstudio.com/docs/remote/ssh list supported Linux, Windows, and macOS hosts but do not include IBM i.

- **canonical search:** The newer https://github.com/microsoft/vscode-remote-release/issues/11693 concerns the same AS400 platform, while https://github.com/microsoft/vscode-remote-release/issues/703 and https://github.com/microsoft/vscode-remote-release/issues/401 concern distinct Linux architectures.
