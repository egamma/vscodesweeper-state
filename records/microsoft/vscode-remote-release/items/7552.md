# Issue #7552 — Why is the SSH Max Reconnection attempts option limited to a max value of 8?

[https://github.com/microsoft/vscode-remote-release/issues/7552](https://github.com/microsoft/vscode-remote-release/issues/7552)

## Summary

Keep open: unlimited retries do not satisfy the request for a finite limit above eight, and the team explicitly accepted improving the setting. A November 2026 report indicates that the numeric cap and misleading description remain.

## Change summary

Allow Remote - SSH reconnection limits above eight and accurately describe the null/default behavior.
