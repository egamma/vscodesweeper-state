# Issue #7552 — Why is the SSH Max Reconnection attempts option limited to a max value of 8?

[https://github.com/microsoft/vscode-remote-release/issues/7552](https://github.com/microsoft/vscode-remote-release/issues/7552)

## Summary

Keep open as SSH settings polish: a maintainer confirmed that the limit lacks a current rationale and that the description is inaccurate. Infinite retries are available, but that does not cover finite values above eight.

## Change summary

Allow Remote - SSH users to configure more than eight reconnection attempts and accurately document the setting's null behavior.

## Best solution

The SSH component should either lift the numeric ceiling and document that null means unlimited retries, or replace the attempts limit with clearer timeout-based behavior after resolving the maintainer's usage question.
