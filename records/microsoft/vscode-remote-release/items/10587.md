# Issue #10587 — Option to remove git credential config options from global git config in devcontainer

[https://github.com/microsoft/vscode-remote-release/issues/10587](https://github.com/microsoft/vscode-remote-release/issues/10587)

## Summary

Keep open: the available workarounds do not provide selective removal of host-only, URL-specific credential configuration while retaining credential forwarding. The related reports do not establish a verified fix or a canonical with the same observable symptom.

## Change summary

Allow Dev Containers to exclude host-specific credential configuration whose helper executables are unavailable inside the container.

## Best solution

The Dev Containers extension should support filtering host-only credential helper entries during Git configuration sharing while preserving forwarding and unrelated configuration. Determine how URL-specific helper settings should be handled without requiring a post-start cleanup script.
