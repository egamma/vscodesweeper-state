# Issue #10587 — Option to remove git credential config options from global git config in devcontainer

[https://github.com/microsoft/vscode-remote-release/issues/10587](https://github.com/microsoft/vscode-remote-release/issues/10587)

## Summary

Consolidate with the older, open credential-helper report: both describe URL-specific host helpers surviving configuration copying and producing executable-not-found errors during Git operations inside containers.

## Change summary

Allow removal of host-specific credential configuration from the container's copied Git configuration while retaining credential forwarding.

## Best solution

Resolve URL-specific credential-helper handling in https://github.com/microsoft/vscode-remote-release/issues/9252 so host-only executables do not run inside containers. Carry over this report's Nix-store paths and helper-specific settings; keep the separate lifecycle-hook failure tracked independently.
