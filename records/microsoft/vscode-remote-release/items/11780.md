# Issue #11780 — [Remote-SSH Bug]: Add New SSH Host corrupts KnownHostsCommand by quoting the entire command

[https://github.com/microsoft/vscode-remote-release/issues/11780](https://github.com/microsoft/vscode-remote-release/issues/11780)

## Summary

Confirmed Remote - SSH config-serialization bug with a precise standalone reproduction and an upstream fix already released. Keep it open for the SSH owner to update the bundled dependency and obtain reporter verification.

## Change summary

Adding an SSH host rewrites a valid KnownHostsCommand so its executable and arguments become one quoted path.

## Best solution

Remote - SSH should update its lockfile to ssh-config 5.2.1 or newer, publish a pre-release containing that dependency, and ask the reporter to verify that Add New SSH Host preserves the directive.
