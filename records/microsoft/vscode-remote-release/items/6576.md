# Issue #6576 — howto configure docker context within workspace

[https://github.com/microsoft/vscode-remote-release/issues/6576](https://github.com/microsoft/vscode-remote-release/issues/6576)

## Summary

Keep open: this is a still-valid Dev Containers feature request for workspace-scoped Docker context selection, and the thread has maintainer confirmation that the relevant implementation is closed-source and more complicated than expected. The issue is already correctly routed to `containers`, and no verified open canonical or existing documented first-class setting fully covers the ask.

## Change summary

Allow a workspace or devcontainer configuration to select the Docker context used by Dev Containers instead of requiring `docker context use` to change the global Docker client context.

## Best solution

The Dev Containers owner should decide on a first-class way to pass a Docker context into the extension's Docker CLI calls, such as honoring a workspace-scoped setting or using `DOCKER_CONTEXT`/`--context` during container creation. Existing documentation covers checking or switching the current Docker context, but that does not satisfy the request for non-global per-workspace selection.
