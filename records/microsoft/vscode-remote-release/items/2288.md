[https://github.com/microsoft/vscode-remote-release/issues/2288](https://github.com/microsoft/vscode-remote-release/issues/2288)

## Summary

Keep this team-authored diagnostic request open. Modern Docker backends reduce the relevance of legacy drive-sharing credentials, but neither documented workarounds nor the verified related issue establish that the requested detection has shipped.

## Change summary

Detect Windows Docker drive-sharing credential failures and provide actionable guidance instead of a generic bind-mount permission error.

## Best solution

The Dev Containers owner should determine whether supported Windows Docker backends still expose this failure and, where applicable, provide targeted credential-reset guidance without treating every mount permission error as a credential failure.
