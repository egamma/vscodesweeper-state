# Issue #286 — wsl: allow to run with a non-default user

[https://github.com/microsoft/vscode-remote-release/issues/286](https://github.com/microsoft/vscode-remote-release/issues/286)

## Summary

Keep this accepted WSL feature request open: changing the distro's default user does not support simultaneous windows connected as different users. The maintainer proposed implementation approaches, and this issue already serves as the canonical user-selection request.

## Change summary

Allow WSL connections to select a non-default user, including simultaneous connections to one distribution under different users.

## Best solution

The WSL extension should retain the selected user in each workspace's remote connection identity, enabling independent windows for different users without changing the distro default or restarting WSL. A per-distro user setting could address simpler cases but would not satisfy the parallel-user workflow.
