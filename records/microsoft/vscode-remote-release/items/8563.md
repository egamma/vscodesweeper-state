# Issue #8563 — Dev Containers - "Attach to Running Container..." Error: ENAMETOOLONG: name too long

[https://github.com/microsoft/vscode-remote-release/issues/8563](https://github.com/microsoft/vscode-remote-release/issues/8563)

## Summary

Keep open for the Dev Containers owner: the supplied attach steps and ENAMETOOLONG log suffice to retest the image-configuration filename failure. The report targets older releases, but no confirmed fix or canonical duplicate was found.

## Change summary

Attaching to a running container fails when its long registry-qualified image reference becomes an oversized imageConfigs filename.

## Best solution

Dev Containers should use bounded, stable filenames for image-level configuration while preserving access to existing configurations. Retest the supplied long-image-reference scenario on the current extension before deciding whether that change remains necessary.
