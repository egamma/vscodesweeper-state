## Summary

The report provides strong attribution and measurements, but no maintainer or independent current-version reproduction confirms that the polling remains present. Requesting a current Dev Containers retest and diagnostic logs.

## Change summary

Dev Containers repeatedly invokes the Docker CLI while no container or dev-container workspace is active, causing unnecessary CPU and endpoint-security activity.

## Best solution

The Dev Containers extension should avoid high-frequency Docker discovery while idle, or substantially reduce its polling frequency. A current reproduction with the Dev Containers log and Docker command arguments should identify which background discovery path owns the calls.
