# Issue #11161 — No environment GITHUB_TOKEN available.

[https://github.com/microsoft/vscode-remote-release/issues/11161](https://github.com/microsoft/vscode-remote-release/issues/11161)

## Summary

This is a configuration support question rather than a Dev Containers defect: `runArgs` only configures the created container, while authenticated feature retrieval reads `GITHUB_TOKEN` from the environment that starts VS Code.

## Change summary

Use a GitHub token to download a private Dev Container Feature referenced directly as a tarball.

## Best solution

Set `GITHUB_TOKEN` in the environment before starting VS Code; no GitHub extension is required. Further setup assistance belongs in the support channel referenced by the question close.
