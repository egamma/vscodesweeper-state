# Issue #4053 — Support property name for attached container config

[https://github.com/microsoft/vscode-remote-release/issues/4053](https://github.com/microsoft/vscode-remote-release/issues/4053)

## Summary

Keep this accepted, team-authored request open: current documentation does not establish support for a custom display name in attached-container configuration, and the verified related issues do not own that capability.

## Change summary

Support the name property in attached-container configuration to customize the container's display name in VS Code.

## Best solution

Dev Containers should honor an attached configuration's name as the display label without requiring the underlying container to be renamed. Retain this issue for that extension-side capability, distinct from configuration-file access and displaying Docker's existing container name.
