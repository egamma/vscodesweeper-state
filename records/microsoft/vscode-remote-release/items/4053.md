# Issue #4053 — Support property name for attached container config

[https://github.com/microsoft/vscode-remote-release/issues/4053](https://github.com/microsoft/vscode-remote-release/issues/4053)

## Summary

A documented capability gap remains: general dev-container configurations support `name`, while attached-container configurations still do not. This team-authored Backlog request should remain open.

## Change summary

Allow an attached-container configuration to set a custom display name through the `name` property.

## Best solution

The Dev Containers extension should honor `name` in attached-container configuration files and use it for the container's VS Code UI display name. This is distinct from automatically displaying the runtime container name tracked by https://github.com/microsoft/vscode-remote-release/issues/2705.
