[https://github.com/microsoft/vscode-remote-release/issues/11727](https://github.com/microsoft/vscode-remote-release/issues/11727)

## Summary

Keep open: existing feature-update code lenses do not cover the requested lockfile-first upgrades that preserve version specifiers, and a maintainer welcomed an update-all command. The older related request covers only preserving the latest tag, not this issue's full scope.

## Change summary

Provide a documented Dev Containers UI workflow to upgrade locked feature versions while preserving devcontainer.json version-specifier granularity.

## Best solution

The Dev Containers extension should offer lockfile-aware individual and bulk feature upgrades, preserving existing specifiers for compatible updates and changing both files consistently when crossing their bounds. Document the workflow and coordinate the overlapping latest-tag behavior with https://github.com/microsoft/vscode-remote-release/issues/11617.
