# Issue #11727 — Support devcontainer-lock.json upgrade flow

[https://github.com/microsoft/vscode-remote-release/issues/11727](https://github.com/microsoft/vscode-remote-release/issues/11727)

## Summary

A real Dev Containers UI gap remains: the existing feature code lens edits devcontainer.json rather than performing the stable lockfile-aware upgrade flow. The issue is already correctly classified and routed in the Backlog.

## Change summary

Make feature updates regenerate devcontainer-lock.json while preserving compatible version selectors in devcontainer.json, with an option to update all features.

## Best solution

The Dev Containers extension should expose the CLI's lockfile upgrade behavior through its feature code lenses and an update-all command, preserving the existing version selector unless the selected release requires changing it.
