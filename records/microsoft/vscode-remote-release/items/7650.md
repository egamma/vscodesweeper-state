# Issue #7650 — Separate extensions in devcontainer.json into mandatory and personal

[https://github.com/microsoft/vscode-remote-release/issues/7650](https://github.com/microsoft/vscode-remote-release/issues/7650)

## Summary

Consolidate this request into the verified, older open issue tracking repository-specific personal extension files. The global default-extensions setting does not satisfy the requested per-repository behavior.

## Change summary

Allow an optional, gitignored personal extension list to supplement the shared devcontainer.json extension list for each repository.

## Best solution

Implement repository-specific personal extension configuration in Dev Containers through https://github.com/microsoft/vscode-remote-release/issues/5422. Preserve this report's requirements for additive merging, an optional missing file, and no changes to the shared configuration.
