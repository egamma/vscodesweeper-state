# Issue #1814 — Feature request: Right-click on docker-compose.yml -> Compose Up and Attach

[https://github.com/microsoft/vscode-remote-release/issues/1814](https://github.com/microsoft/vscode-remote-release/issues/1814)

## Summary

The documented Dev Containers workflow can start a Compose project and attach VS Code, but only after configuring devcontainer.json; it does not fully cover the requested one-step action on an arbitrary Compose file. Keep this open for a Containers UX decision.

## Change summary

Add a docker-compose.yml context-menu action that starts the Compose services and attaches VS Code to a selected container.

## Best solution

The Dev Containers component should decide whether to provide a guided Compose-file action that selects a service, starts the project, and attaches VS Code, potentially generating or reusing devcontainer.json for repeatable configuration.

## Vision fit

- **Fit:** aligned
- **Reason:** Reducing a common Compose workflow to a direct open-and-attach action advances the remote-development promise of opening a folder in a container with VS Code's full feature set.
- **Evidence:** The public product promise is: "Open any folder in a container, on a remote machine, or in WSL and take advantage of VS Code's full feature set."
