[https://github.com/microsoft/vscode-remote-release/issues/1814](https://github.com/microsoft/vscode-remote-release/issues/1814)

## Summary

Keep open: documented workflows can start Compose services and connect through devcontainer.json, but do not establish the requested combined context-menu action on an unconfigured docker-compose.yml. No verified canonical owns that same workflow improvement.

## Change summary

Add a docker-compose.yml context-menu action that starts the Compose project and attaches VS Code to a selected container.

## Best solution

Provide a combined Compose Up and Attach action through integration between Container Tools and Dev Containers, selecting the target service when necessary. Preserve the ability to use an existing Compose file without first creating devcontainer.json.
