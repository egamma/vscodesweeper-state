## Summary

Verified duplicate: the open canonical issue tracks the same attached-container recovery failure in which the second resolveAuthority call cannot recover after the connection or extension host restarts.

## Change summary

Attaching to a container through an SSH-backed remote Docker host loses its WebSocket connection and then waits indefinitely while attempting to resolve the authority again.

## Best solution

Consolidate the recovery-path work on https://github.com/microsoft/vscode-remote-release/issues/11690. The component should make attached-container reconnection recover with a fresh attach or terminate with an actionable error instead of waiting indefinitely.
