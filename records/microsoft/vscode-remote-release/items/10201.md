# Issue #10201 — When installing VSCode Server on a `ssh` remote, verify the `scp` transfer status and display appropriate error if transfer failed

[https://github.com/microsoft/vscode-remote-release/issues/10201](https://github.com/microsoft/vscode-remote-release/issues/10201)

## Summary

Route this accepted error-handling debt to Remote - SSH. Enhanced session diagnostics were announced, but there is no confirmation that failed SCP transfers now stop installation with an appropriate error.

## Change summary

Check SCP transfer success before extracting the VS Code Server archive and report the transfer failure instead of a downstream gzip error.

## Best solution

Remote - SSH should stop installation when SCP fails and surface the transfer's actionable error, including disk-space exhaustion. Verify this specific path against the enhanced diagnostics work before considering it completed.
