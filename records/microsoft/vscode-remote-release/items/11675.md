# Issue #11675 — Dev Containers: declared extensions not installed on rebuild — remote-containers extension host crashes with "PendingMigrationError: navigator is now a global in nodejs"

[https://github.com/microsoft/vscode-remote-release/issues/11675](https://github.com/microsoft/vscode-remote-release/issues/11675)

## Summary

The extension-install failure remains reproducible across Dev Containers over SSH and Codespaces, including on VS Code 1.129.1. The navigator warning is a red herring; route the confirmed bug to the container/server extension-install path.

## Change summary

Declared dev-container extensions intermittently fail to install during rebuild or creation, leaving the remote environment with zero extensions.

## Best solution

The Dev Containers and VS Code Server owners should investigate the extension-install orchestration, using the extension-host termination and `remote.downloadExtensionsLocally` workaround as leads. The flow should complete or report a meaningful failure instead of silently leaving all declared extensions uninstalled.
