## Summary

Route to Dev Containers: later independent reports confirm declared extensions remain missing after rebuild, despite the original reporter's successful retries. Maintainers identify the navigator warning as diagnostic logging, not proof of a crash; no verified fix or open canonical covers the remaining failure.

## Change summary

Extensions declared in customizations.vscode.extensions sometimes fail to install automatically after a container rebuild, while manual installation succeeds.

## Best solution

The Dev Containers owner should diagnose the automatic installation failure using a failing container log and server startup arguments, then ensure declared extensions install reliably after rebuild. Investigate server-side installation readiness without assuming the navigator warning or Copilot causes the failure.
