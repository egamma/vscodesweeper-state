# Issue #4841 — Add "build.secrets" field to `devcontainer.json`

[https://github.com/microsoft/vscode-remote-release/issues/4841](https://github.com/microsoft/vscode-remote-release/issues/4841)

## Summary

The central request is already supported through the more general `build.options` field, which can pass BuildKit's `--secret` option during image builds.

## Change summary

Allow Dev Container Dockerfile builds to receive BuildKit secrets without requiring an external build workflow.

## Best solution

Keep the general `build.options` mechanism rather than adding a dedicated `build.secrets` field; users can supply `--secret=id=...,src=...` there while retaining Docker CLI flexibility.

- **Proposed comment:**

  > Thanks for the request and the detailed use cases. Dev Containers now supports this through the more general `build.options` field verified in https://github.com/microsoft/vscode-remote-release/issues/9415. For example, `"build": { "options": ["--secret=id=credentials,src=/home/user/.config/credentials.json"] }` passes the BuildKit secret to Dockerfile `RUN --mount=type=secret` instructions, as confirmed in https://github.com/microsoft/vscode-remote-release/issues/4841#issuecomment-2118505706. A dedicated `build.secrets` field is therefore no longer needed.
