# Issue #11218 — Remote SSH connection hangs forever on `Waiting for port forwarding to be ready`

[https://github.com/microsoft/vscode-remote-release/issues/11218](https://github.com/microsoft/vscode-remote-release/issues/11218)

## Summary

Keep open as an accepted SSH documentation enhancement. The reported hang was traced to Windows 11 BBR2 behavior rather than Remote - SSH, but the current troubleshooting guide does not document this confirmed failure mode.

## Change summary

Document that Windows BBR2 can stall Remote - SSH dynamic forwarding through localhost and describe the CUBIC workaround.

## Best solution

Add a Windows BBR2 troubleshooting entry to the Remote - SSH wiki, covering the port-forwarding symptom, the external SSH-command check, and the confirmed CUBIC workaround with the Microsoft support reference.
