# Issue #11293 — Remote-SSH incorrectly detects Yocto/glibc system as Alpine/musl

[https://github.com/microsoft/vscode-remote-release/issues/11293](https://github.com/microsoft/vscode-remote-release/issues/11293)

## Summary

Keep open as the canonical Remote-SSH platform-detection bug: detailed logs and independent current-version reports show glibc hosts receiving the Alpine/musl CLI build.

## Change summary

Remote-SSH selects `cli-alpine-*` for glibc-based Yocto, Ubuntu, and RHEL hosts, preventing the VS Code Server from starting.

## Best solution

Remote-SSH should detect the remote libc independently of BusyBox and select the matching CLI package, with an explicit override if reliable automatic detection is impossible. Related reports should consolidate here.
