## Summary

Keep open for investigation of the prerequisite rejection on Yocto/glibc; the supplied configuration and complete log suffice to retest. Later reports extend through September 2026, but do not establish a current-version reproduction or resolution, and the Alpine CLI filename alone does not prove libc misdetection.

## Change summary

Remote-SSH fails to start its server on a Yocto/glibc host with exit code 207 and a missing-musl-loader prerequisite error.

## Best solution

The SSH owner should isolate why the bootstrap rejects this glibc host and ensure supported libc and library layouts are recognized, coordinating with the VS Code Server prerequisite-check owner as needed. Establish the actual failing check before adopting the proposed binary-selection override or attributing the failure to BusyBox.
