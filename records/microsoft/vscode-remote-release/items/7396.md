# Issue #7396 — Devcontainer cloning fails with invalid characters for a local volume name error

[https://github.com/microsoft/vscode-remote-release/issues/7396](https://github.com/microsoft/vscode-remote-release/issues/7396)

## Summary

This remains the best canonical report for Dev Containers generating invalid Docker volume names from repository URLs. Multiple configurations reproduce the same failure, including a matching 2025 report, and no shipped fix is documented.

## Change summary

Cloning a repository into a container volume fails when the generated Docker volume name begins with punctuation or contains encoded or otherwise invalid characters.

## Best solution

Dev Containers should sanitize every generated volume-name segment while retaining a deterministic suffix, covering leading dots or underscores, URL-encoded spaces, and characters such as `@`. The narrower https://github.com/microsoft/vscode-remote-release/issues/10794 should consolidate into this broader report.
