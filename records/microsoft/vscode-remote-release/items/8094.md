# Issue #8094 — Use latest images when using docker-compose in devcontainer

[https://github.com/microsoft/vscode-remote-release/issues/8094](https://github.com/microsoft/vscode-remote-release/issues/8094)

## Summary

The original limitation was confirmed by a maintainer, but Docker Compose and the Dev Containers CLI later adopted additional build contexts, so a current-version retest is needed before deciding whether the pull behavior remains broken.

## Change summary

Rebuilding a Docker Compose-based dev container with features should pull updated base images without duplicating compose-file configuration in an initializeCommand.

## Best solution

Confirm the behavior with current Dev Containers and Docker Compose 2.17 or later; if it persists, the Dev Containers CLI should safely request fresh images when its feature-injection path uses additional build contexts.
