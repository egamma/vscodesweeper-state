# Issue #8094 — Use latest images when using docker-compose in devcontainer

[https://github.com/microsoft/vscode-remote-release/issues/8094](https://github.com/microsoft/vscode-remote-release/issues/8094)

## Summary

Keep open for the Dev Containers owner: the report and maintainer diagnosis provide sufficient steps to retest image refresh during Compose rebuilds. Additional-context support arrived after this report, but that does not establish that its stale-image behavior is resolved.

## Change summary

Docker Compose dev-container rebuilds should retrieve updated images without requiring a separate pull command that duplicates the Compose-file configuration.

## Best solution

Verify that current Dev Containers rebuilds with Compose and Features pull updated base images using additional contexts, particularly for Rebuild Without Cache. If stale images remain, correct the extension's Compose rebuild path without requiring duplicated initializeCommand configuration.
