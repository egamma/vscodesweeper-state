# Issue #7898 — Add option to `settings.json` for `dev.containers.defaultSettings`

[https://github.com/microsoft/vscode-remote-release/issues/7898](https://github.com/microsoft/vscode-remote-release/issues/7898)

## Summary

Keep open: existing settings inheritance covers ordinary personal preferences, but the documented configuration does not provide a user-level set of defaults applied only across dev containers. The Backlog request is already correctly routed, and no matching open canonical was found.

## Change summary

Add dev.containers.defaultSettings in local settings.json to apply personal setting defaults automatically to newly created dev containers.

## Best solution

The Dev Containers component should decide whether to offer container-only personal defaults analogous to dev.containers.defaultExtensions, with explicit precedence relative to devcontainer.json and remote settings. Local settings inheritance already handles preferences that should also apply outside containers.
