# Issue #7898 — Add option to `settings.json` for `dev.containers.defaultSettings`

[https://github.com/microsoft/vscode-remote-release/issues/7898](https://github.com/microsoft/vscode-remote-release/issues/7898)

## Summary

This remains a valid, accepted Backlog feature request. Existing user-setting reuse and project-level devcontainer customizations do not provide a container-specific personal settings layer applied to every Dev Container.

## Change summary

Add a user-level `dev.containers.defaultSettings` option that applies selected VS Code settings to every Dev Container.

## Best solution

The Dev Containers extension should provide an application-scoped default-settings object, analogous to `dev.containers.defaultExtensions`, with documented precedence below container, remote, and workspace-specific settings.
