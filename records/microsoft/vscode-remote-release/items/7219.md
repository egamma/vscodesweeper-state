# Issue #7219 — Prompt user to select devcontainer config when more than one available.

[https://github.com/microsoft/vscode-remote-release/issues/7219](https://github.com/microsoft/vscode-remote-release/issues/7219)

## Summary

The requested selection flow shipped in Dev Containers 0.275.x: repositories can place configurations in `.devcontainer` subfolders and choose one when reopening in a container.

## Change summary

Prompt users to choose among multiple dev container configurations in one repository.

## Best solution

Use one `.devcontainer/<name>/devcontainer.json` per configuration and select the desired configuration when reopening the repository in a container. The narrower Clone Repository in Container Volume gap remains tracked separately.

  > Thanks for the request. This is now supported in Dev Containers 0.275.x and later: place each configuration at `.devcontainer/<name>/devcontainer.json`, then **Dev Containers: Reopen in Container** lets you choose which configuration to use. The shipped behavior is documented in https://github.com/microsoft/vscode-docs/blob/main/remote-release-notes/v1_75.md. The separate Clone Repository in Container Volume limitation remains tracked at https://github.com/microsoft/vscode-remote-release/issues/7879.
