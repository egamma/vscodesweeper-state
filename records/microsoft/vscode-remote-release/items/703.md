# Issue #703 — Support ssh to IBM LinuxOne (Red Hat Enterprise) 

[https://github.com/microsoft/vscode-remote-release/issues/703](https://github.com/microsoft/vscode-remote-release/issues/703)

## Summary

A real capability gap remains: current Remote - SSH documentation supports x86_64 and ARM Linux hosts but not s390x, while sustained demand and a working VSCodium port support retaining this as the canonical request.

## Change summary

Provide official s390x Linux builds of VS Code Server so Remote - SSH can connect to IBM Z and LinuxONE hosts.

## Best solution

The VS Code Server and Remote - SSH owners should evaluate a supported s390x build-and-test pipeline covering the server and its native dependencies. Keep this older, better-supported report as the canonical request and consolidate the newer https://github.com/microsoft/vscode-remote-release/issues/6994 into it.

- **Fit:** aligned
- **Reason:** Supporting VS Code Server on s390x would extend local-quality remote-development parity and the server lifecycle to another Linux architecture.
- **Evidence:** The public product promise is to "Open any folder in a container, on a remote machine, or in WSL and take advantage of VS Code's full feature set," while VS Code Server lifecycle and broad environment support are durable themes.
