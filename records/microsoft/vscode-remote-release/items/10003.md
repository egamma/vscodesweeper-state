# Issue #10003 — Extend support for variables in `mount` syntax to include containerEnv, among others in devcontainer spec

[https://github.com/microsoft/vscode-remote-release/issues/10003](https://github.com/microsoft/vscode-remote-release/issues/10003)

## Summary

Verified cross-repository duplicate: the open Dev Container specification issue already tracks this exact limitation in `mounts`, including unresolved `${containerEnv:HOME}` values.

## Change summary

Allow mount definitions to reference image or container environment values, particularly the container user's home directory.

## Best solution

Define unambiguous pre-creation environment substitution, such as `${imageEnv:...}`, in https://github.com/devcontainers/spec/issues/282; the Dev Containers extension can then implement the agreed specification.
