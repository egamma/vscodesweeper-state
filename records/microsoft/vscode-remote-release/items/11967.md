# Issue #11967 — Rebuild Container (Docker Compose) still races the old container's removal: "container is marked for removal and cannot be started"

## Summary

Keep open while the linked implementation candidates are reviewed. The supplied steps, versions, and timed Docker events suffice to retest this remaining Compose race; the earlier removal-conflict fix does not establish resolution.

## Change summary

Docker Compose devcontainer rebuilds can start the old container before its removal finishes, failing until Retry succeeds.

## Best solution

The Dev Containers component should wait for removal to complete before starting Compose services. Review and land the linked CLI and extension changes, then verify the shipped extension handles slow removal before closing this report.
