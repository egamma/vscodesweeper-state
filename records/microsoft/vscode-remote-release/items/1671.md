# Issue #1671 — remote-ssh: Add possibility to invoke a login shell

[https://github.com/microsoft/vscode-remote-release/issues/1671](https://github.com/microsoft/vscode-remote-release/issues/1671)

## Summary

Login terminal profiles already support the original opt-in request, but the discussion also establishes unresolved server-environment inheritance and default-behavior concerns. Keep open for the SSH team's decision; terminal-only configuration does not settle the full discussion.

## Change summary

Allow Remote - SSH sessions to use login-shell initialization so remote development tools receive the expected profile environment.

## Best solution

The SSH team should distinguish the supported login-terminal configuration from server and extension-host environment initialization, then resolve the remaining inheritance and refresh behavior. Document the terminal profile option and decide whether remote login-shell defaults should change.
