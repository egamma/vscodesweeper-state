# Issue #1671 — remote-ssh: Add possibility to invoke a login shell

[https://github.com/microsoft/vscode-remote-release/issues/1671](https://github.com/microsoft/vscode-remote-release/issues/1671)

## Summary

The requested ability now exists through Linux terminal profiles: users can configure Bash with `--login` and select it as the default remote terminal profile. The remaining preference for login shells by default is a separate behavior change, while the original configurability request is satisfied.

## Change summary

Allow Remote-SSH users to launch integrated terminals as login shells so profile initialization files are sourced.

## Best solution

Keep login-shell startup configurable through `terminal.integrated.profiles.linux` rather than changing every Linux remote terminal by default, and make the Remote-SSH documentation point clearly to that configuration.

- **Reason:** Giving remote terminals the same configurable shell initialization available locally supports remote-development parity and SSH fidelity.

- **Proposed comment:**

  > Thanks for the discussion and examples. The original request—to make a Remote-SSH integrated terminal invoke a login shell—is now supported through terminal profiles. For example, configure `terminal.integrated.profiles.linux` with a Bash profile whose `args` are `["--login"]`, then select it with `terminal.integrated.defaultProfile.linux`. This is documented at https://code.visualstudio.com/docs/terminal/profiles, and users above have confirmed it works remotely. The broader request to make every Linux remote terminal a login shell by default is a separate behavior change, so the configurable behavior here is working as designed.
