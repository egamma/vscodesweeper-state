[https://github.com/microsoft/vscode-remote-release/issues/2649](https://github.com/microsoft/vscode-remote-release/issues/2649)

## Summary

Keep open: this team-authored Backlog request remains a distinct Dev Containers usability gap, and no verified duplicate or documented persistent log-visibility option was found.

## Change summary

Preserve whether the Dev Containers log was visible when the window reloads.
