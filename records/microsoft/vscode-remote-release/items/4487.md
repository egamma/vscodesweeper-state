# Issue #4487 — Windows Remote-SSH install script has a character limit

[https://github.com/microsoft/vscode-remote-release/issues/4487](https://github.com/microsoft/vscode-remote-release/issues/4487)

## Summary

Keep this team-authored SSH debt item open: local-server mode is a documented workaround, not evidence that terminal-mode script delivery no longer encounters the limit. No verified open canonical or qualifying fix was found.

## Change summary

Investigate Windows Remote-SSH install-script delivery that avoids command-length limits without requiring local-server mode.

## Best solution

The SSH component should establish whether current terminal-mode bootstrapping still hits the documented limits and, if so, deliver the script without embedding its full contents in a length-limited command. Preserve support for users who cannot use local-server mode.
