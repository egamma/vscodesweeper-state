# Issue #7789 — How to open a file in a remote development container by link? 

[https://github.com/microsoft/vscode-remote-release/issues/7789](https://github.com/microsoft/vscode-remote-release/issues/7789)

## Summary

Keep open as the accepted backlog request for deep links to files inside Dev Containers. Current documentation covers opening a repository in a container but not targeting a file, and no broader canonical issue owns this request.

## Change summary

Allow browser links to open a specific workspace file in its Dev Container, analogous to local vscode:// file links.

## Best solution

The Dev Containers extension should extend its link handler to accept a workspace-relative file, optionally with line and column, while opening or reusing the corresponding container.

## Vision fit

- **Fit:** aligned
- **Reason:** Providing the same file-link navigation locally and in a Dev Container advances remote-development parity.
- **Evidence:** The stated product promise is to open folders remotely while retaining VS Code's full feature set; URL-based file opening is documented for local VS Code.
