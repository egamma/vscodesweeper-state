# Issue #8559 — Declarative secret support in Dev Containers

[https://github.com/microsoft/vscode-remote-release/issues/8559](https://github.com/microsoft/vscode-remote-release/issues/8559)

## Summary

Keep this team-authored implementation request open: completed specification work does not establish that local Dev Containers supports declarative secrets. Existing environment-variable mechanisms do not cover the requested secret-setup experience, and no qualifying canonical was verified.

## Change summary

Support declared secret names, descriptions, and documentation links during local Dev Container creation.

## Best solution

The Dev Containers extension should consume the spec's secrets declarations and offer a local setup experience for supplying their values, without making recommended secrets mandatory. Retain this issue as the product implementation tracker rather than folding it into completed specification work.
