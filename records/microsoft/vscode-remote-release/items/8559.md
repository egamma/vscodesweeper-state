# Issue #8559 — Declarative secret support in Dev Containers

[https://github.com/microsoft/vscode-remote-release/issues/8559](https://github.com/microsoft/vscode-remote-release/issues/8559)

## Summary

The declarative-secrets schema is finalized, but no public documentation or release note confirms that the Dev Containers extension implements the local provisioning experience. This team-authored Backlog request should remain open for the extension work.

## Change summary

Add Dev Containers extension support for secrets declared by a repository's `devcontainer.json` when creating containers locally.

## Best solution

The Dev Containers extension should consume the finalized `secrets` property, provide a secure local secret-provisioning experience, and inject supplied values without requiring projects to store credentials in `devcontainer.json`.
