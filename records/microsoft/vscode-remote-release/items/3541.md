# Issue #3541 — Support using config variables in devcontainer.json

[https://github.com/microsoft/vscode-remote-release/issues/3541](https://github.com/microsoft/vscode-remote-release/issues/3541)

## Summary

Verified duplicate: the older open issue https://github.com/microsoft/vscode-remote-release/issues/2697 explicitly tracks adding config-variable substitution to devcontainer.json. Current specification documentation confirms that `${config:...}` remains unsupported.

## Change summary

Allow devcontainer.json values such as mounts, build arguments, and run arguments to reference user settings through `${localConfig:settingName}`.
