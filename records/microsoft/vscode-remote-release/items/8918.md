# Issue #8918 — Rebuild container on start if devcontainer.json was changed

[https://github.com/microsoft/vscode-remote-release/issues/8918](https://github.com/microsoft/vscode-remote-release/issues/8918)

## Summary

Keep this accepted Dev Containers request open: documented rebuild commands do not provide automatic configuration-change detection and rebuilding on startup. Related requests cover prompts or scripted rebuilds, not the same end-to-end behavior.

## Change summary

Provide an opt-in automatic rebuild at startup when devcontainer.json differs from the configuration used to create the existing container.

## Best solution

Dev Containers should offer an opt-in startup check that rebuilds a stale container before attempting to connect, including after a previously dismissed rebuild notification. Preserve the default manual workflow because rebuilding can discard container-local changes.
