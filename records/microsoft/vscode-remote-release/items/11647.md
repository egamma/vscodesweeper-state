# Issue #11647 — No offline download option?

[https://github.com/microsoft/vscode-remote-release/issues/11647](https://github.com/microsoft/vscode-remote-release/issues/11647)

## Summary

This is a support question with an existing documented path: Remote - SSH can be transferred as a VSIX and installed without Marketplace access.

## Change summary

Install the Remote - SSH extension on multiple air-gapped client systems.

## Best solution

Download the Remote - SSH VSIX from its Marketplace page on a connected system, transfer it into the air-gapped environment, and install it with Extensions: Install from VSIX or `code --install-extension <extension-vsix-path>`.

  > Thanks for the question. You can download the Remote - SSH VSIX from https://marketplace.visualstudio.com/items?itemName=ms-vscode-remote.remote-ssh on a connected system, transfer it to each air-gapped machine, and install it with **Extensions: Install from VSIX** or `code --install-extension <path-to-vsix>`. The documented steps are at https://code.visualstudio.com/docs/configure/extensions/extension-marketplace#_install-from-a-vsix. The broader case where both the client and SSH host need preinstalled server components is tracked at https://github.com/microsoft/vscode-remote-release/issues/9454.
