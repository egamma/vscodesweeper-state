# Issue #11647 — No offline download option?

[https://github.com/microsoft/vscode-remote-release/issues/11647](https://github.com/microsoft/vscode-remote-release/issues/11647)

## Summary

This is an installation support question: downloading a VSIX on a connected machine and installing it offline is documented. That installs the extension, but does not by itself provision the VS Code Server for fully air-gapped SSH use.

## Change summary

Install the Remote - SSH extension on several air-gapped systems.

## Best solution

Explain the documented Download VSIX and Install from VSIX workflow. Keep the separate, unresolved end-to-end offline server-provisioning work tracked in https://github.com/microsoft/vscode-remote-release/issues/1399.

- **Proposed comment:**

  > Thanks for the question. You can install the Remote - SSH extension offline: on an internet-connected machine, find it in VS Code's Extensions view, right-click and select **Download VSIX**, then transfer the file and run **Extensions: Install from VSIX** on each air-gapped machine. See https://code.visualstudio.com/docs/configure/extensions/extension-marketplace.
  > 
  > Installing the extension is separate from provisioning the VS Code Server needed for SSH connections. If both the client and SSH host are offline, the remaining offline-provisioning work is tracked at https://github.com/microsoft/vscode-remote-release/issues/1399; `remote.SSH.localServerDownload` still requires a connected client to download the server.
  > 
  > For further installation support, please use StackOverflow: https://aka.ms/vscodestackoverflow.
