# Issue #508 — Can't cancel VS Code Server update

[https://github.com/microsoft/vscode-remote-release/issues/508](https://github.com/microsoft/vscode-remote-release/issues/508)

## Summary

Keep open: safe cancellation of a WSL server update remains an accepted request, with no verified fix or matching open canonical found. The existing steps provide a concrete scenario for the WSL owner to retest.

## Change summary

Allow Ctrl+C to cancel a VS Code Server download launched from WSL without leaving orphaned download processes or an unusable installation.

## Best solution

The WSL component should support cancellation of terminal-initiated server updates, stop associated download processes, and ensure the next launch can recover from an interrupted installation.
