# Issue #508 — Can't cancel VS Code Server update

[https://github.com/microsoft/vscode-remote-release/issues/508](https://github.com/microsoft/vscode-remote-release/issues/508)

## Summary

Keep open: current documentation and related issue history do not establish an in-progress WSL server-update cancellation mechanism, and no open canonical issue was found. The request remains useful because forced termination can orphan the downloader and leave a damaged installation.

## Change summary

Allow Ctrl+C to cancel an in-progress VS Code Server download from WSL without leaving downloader processes or a partial installation behind.

## Best solution

The WSL extension's server-update launcher should propagate cancellation to its downloader, remove incomplete artifacts, and leave the next connection able to retry cleanly.
