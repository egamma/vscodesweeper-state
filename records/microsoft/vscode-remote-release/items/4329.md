# Issue #4329 — Extensions specified in devcontainer.json doesn't get installed to "offline" host, even if remote.downloadExtensionsLocally=true

[https://github.com/microsoft/vscode-remote-release/issues/4329](https://github.com/microsoft/vscode-remote-release/issues/4329)

## Summary

VS Code gained a client-side fallback in 2025 for extensions that fail to install during remote server startup, but the thread does not confirm whether it covers devcontainer-declared extensions. A current-version retest is needed before deciding whether a gap remains.

## Change summary

Install extensions declared in devcontainer.json through the connected client when the remote Docker host cannot access the Marketplace.

## Best solution

Confirm that the current server-install fallback handles devcontainer-declared extensions on an offline Docker host. If it does not, the Dev Containers component should pass failed startup installations to the client; any remaining timeout or forced-local behavior may belong with https://github.com/microsoft/vscode-remote-release/issues/9994.
