# Issue #4329 — Extensions specified in devcontainer.json doesn't get installed to "offline" host, even if remote.downloadExtensionsLocally=true

[https://github.com/microsoft/vscode-remote-release/issues/4329](https://github.com/microsoft/vscode-remote-release/issues/4329)

## Summary

Consolidate this request into the verified open issue tracking client-side installation of startup extensions for Dev Containers and SSH. Its scope includes installing configured extensions when the remote cannot reach the Marketplace.

## Change summary

Download extensions listed in devcontainer.json locally and install them into an offline remote container when remote.downloadExtensionsLocally is enabled.

## Best solution

Track the client-side startup installation behavior in https://github.com/microsoft/vscode-remote-release/issues/9994, preserving this report's offline Docker-over-SSH configuration. The final behavior should install configured container extensions without requiring Marketplace connectivity from the container.
