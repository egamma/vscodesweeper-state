# Issue #11119 — Remote SSH Exec Server ignores Local Server Download setting of always

[https://github.com/microsoft/vscode-remote-release/issues/11119](https://github.com/microsoft/vscode-remote-release/issues/11119)

## Summary

Keep open as a confirmed Remote-SSH regression: with Exec Server enabled, multiple users found that `remote.SSH.localServerDownload: always` was ignored, preventing connections to hosts without internet access. No open canonical or confirmed fix was found.

## Change summary

Make the Remote-SSH Exec Server installation path honor `remote.SSH.localServerDownload: always` by downloading locally and transferring the server to the remote host.

## Best solution

The Remote-SSH installer should apply `remote.SSH.localServerDownload` consistently in Exec Server mode, restoring local download and transfer for offline hosts without requiring users to disable `remote.SSH.useExecServer`.
