# Issue #11119 — Remote SSH Exec Server ignores Local Server Download setting of always

[https://github.com/microsoft/vscode-remote-release/issues/11119](https://github.com/microsoft/vscode-remote-release/issues/11119)

## Summary

Keep open for Remote - SSH: the report supplies concrete steps to retest a regression against documented local-download behavior. Confirmations cover later 2025 releases, but current-release resolution remains unverified; no verified canonical or product fix was found.

## Change summary

With Exec Server enabled, Remote - SSH attempts a remote server download despite localServerDownload being set to always, preventing installation on offline hosts.

## Best solution

Remote - SSH should honor localServerDownload=always throughout Exec Server installation, downloading required server artifacts locally and transferring them to the host. Retest the supplied scenario on current versions; disabling Exec Server remains a workaround, not equivalent functionality.
