# Issue #7080 — Docker not being executed in windows when a \\wsl$\ folder is opened

[https://github.com/microsoft/vscode-remote-release/issues/7080](https://github.com/microsoft/vscode-remote-release/issues/7080)

## Summary

Keep open: the documented setting intentionally runs CLI commands in WSL for WSL-hosted workspaces even when disabled, so it does not cover this Windows-Docker workflow. A maintainer explicitly proposed extending the setting with a “Never” mode.

## Change summary

Allow Dev Containers to execute Docker through Windows for a workspace stored on the WSL filesystem.

## Best solution

The Dev Containers extension should replace or extend `dev.containers.executeInWSL` with an explicit three-state policy such as “Never”, “For WSL paths”, and “Always”, preserving the current default while enabling Windows Docker for WSL-hosted source.
