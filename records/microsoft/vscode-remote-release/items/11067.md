# Issue #11067 — HostName expansion in ssh_config with Host * pattern breaks remote ssh for matching hosts

[https://github.com/microsoft/vscode-remote-release/issues/11067](https://github.com/microsoft/vscode-remote-release/issues/11067)

## Summary

The logs and an independent confirmation show Remote - SSH incorrectly serializing `user@host` targets as `user@host:undefined`, breaking OpenSSH `%h` expansion. This remains a valid SSH configuration-parsing bug and should be routed to `ssh-config`.

## Change summary

Preserve explicit usernames and optional ports when connecting through wildcard SSH config entries that expand `HostName` with `%h`.

## Best solution

Remote - SSH should pass `user@host` unchanged when no port is specified and serialize an explicit port separately, allowing OpenSSH to apply wildcard `Host` rules and `%h` expansion correctly.
