# Issue #2795 — [docker-compose] Only rebuild target "service" on container rebuild

[https://github.com/microsoft/vscode-remote-release/issues/2795](https://github.com/microsoft/vscode-remote-release/issues/2795)

## Summary

Keep open: documented service-selection settings do not establish independent rebuild control, and the thread explicitly reports that Rebuild Without Cache rebuilt all four services. Related reports suggest container removal may already be selective, but do not prove the complete request is resolved.

## Change summary

Allow rebuilding only the targeted Docker Compose service without rebuilding or disrupting sibling services.

## Best solution

Dev Containers should support target-service-only image rebuilding and container recreation while preserving sibling containers and their connected windows. The owner should distinguish image-build scope from container-removal scope when checking current behavior.
