# Issue #11566 — Feature Request: Support for Global Environment Variables / Secrets

[https://github.com/microsoft/vscode-remote-release/issues/11566](https://github.com/microsoft/vscode-remote-release/issues/11566)

## Summary

This is a valid Dev Containers feature gap: current configuration can import local variables per project, but it cannot automatically and securely inject user-scoped variables into every local Dev Container. The existing candidate issues cover different, narrower build-time concerns.

## Change summary

Provide user-level environment variables or secrets that are securely injected into every local Dev Container without repository configuration.

## Best solution

The Dev Containers extension should provide a user-scoped secret or environment-variable mechanism that applies across local container sessions without storing values or variable mappings in project repositories.
