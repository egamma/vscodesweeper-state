# Issue #10168 — VSCode freezing when adding folder to workspace while working on remote Linux machine

[https://github.com/microsoft/vscode-remote-release/issues/10168](https://github.com/microsoft/vscode-remote-release/issues/10168)

## Summary

This remains a well-confirmed Remote - SSH freeze affecting the first multi-root workspace transition. Route it to the SSH connection owner; no verified fix or broader open canonical supersedes it.

## Change summary

Adding the first additional folder to a Remote - SSH workspace freezes the window and often requires forcibly terminating VS Code.

## Best solution

The SSH component should coordinate with the VS Code workbench lifecycle so the local extension host remains able to resolve the remote authority while the first multi-root workspace reload completes, without hanging or disconnecting.
