# Issue #9715 — defaultForwardedPorts differs from User forwarded Ports

[https://github.com/microsoft/vscode-remote-release/issues/9715](https://github.com/microsoft/vscode-remote-release/issues/9715)

## Summary

Keep this maintainer-acknowledged forwarding mismatch open. The supplied configuration and manual-versus-default comparison suffice to retest, and a newer report on Remote - SSH 0.128.0 describes the same limitation rather than demonstrating resolution.

## Change summary

Default port forwards to named remote hosts fail although equivalent host:port forwards entered through the Ports view work.

## Best solution

Remote - SSH should preserve the destination hostname when configuring default forwards and expose a supported configuration matching the Ports view. Retain this older, maintainer-diagnosed report as the tracking issue and consolidate the matching evidence from https://github.com/microsoft/vscode-remote-release/issues/11929 here.
