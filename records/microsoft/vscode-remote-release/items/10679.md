# Issue #10679 — .vscode-remote-containers folder create in Remote-SSH without interaction

[https://github.com/microsoft/vscode-remote-release/issues/10679](https://github.com/microsoft/vscode-remote-release/issues/10679)

## Summary

Keep open: this team-authored bug has controlled reproduction evidence and an independent confirmation. No verified fix or broader canonical issue supports a factual close.

## Change summary

Dev Containers unnecessarily downloads a server into `.vscode-remote-containers` when connecting through Remote - SSH with `remote.SSH.serverInstallPath` configured, even without a workspace or devcontainer.json.

## Best solution

The Dev Containers extension should check for container configuration without installing its server when no workspace is open, while preserving custom Remote - SSH server installation paths. Configurable relocation of `.vscode-remote-containers` remains separately tracked by https://github.com/microsoft/vscode-remote-release/issues/9529.
