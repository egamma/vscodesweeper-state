# Issue #10679 — .vscode-remote-containers folder create in Remote-SSH without interaction

[https://github.com/microsoft/vscode-remote-release/issues/10679](https://github.com/microsoft/vscode-remote-release/issues/10679)

## Summary

Keep this Dev Containers bug open: the supplied configuration and paired logs suffice to retest unwanted installation during an SSH connection without a workspace. The confirmations concern older releases, and no current resolution is established; this team-authored issue has no verified factual closing basis.

## Change summary

Dev Containers creates and populates ~/.vscode-remote-containers during an ordinary SSH connection with remote.SSH.serverInstallPath configured, despite no workspace or devcontainer.json being opened.

## Best solution

Dev Containers should avoid installing its remote support package merely to detect container configuration when no workspace is open. Retest the supplied serverInstallPath comparison on current releases and address unnecessary initialization without requiring users to abandon their custom SSH installation path.
