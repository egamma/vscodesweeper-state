# Issue #8404 — Backslash in username causes chown to fail during image build

[https://github.com/microsoft/vscode-remote-release/issues/8404](https://github.com/microsoft/vscode-remote-release/issues/8404)

## Summary

Verified duplicate: the failure is caused by applying a high host UID/GID during an image build under user-namespace remapping, which the open canonical issue tracks. The backslash in the login name is incidental to the matching chown failure.

## Change summary

Allow Dev Containers to build under rootless Podman when the remote account has a domain-qualified name and high UID/GID.

## Best solution

Consolidate on https://github.com/microsoft/vscode-remote-release/issues/9007 and make UID/GID synchronization compatible with user-namespace remapping, including rootless Podman; retain this report's domain-qualified username and Podman details there.
