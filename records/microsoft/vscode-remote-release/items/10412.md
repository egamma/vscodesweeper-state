Keep open: the reporter supplied concrete steps showing that setting remote.SSH.remotePlatform breaks an otherwise working RemoteCommand connection. Those steps suffice to retest beyond Remote - SSH 0.115.0, and the referenced implementation PR remains open rather than proving a shipped fix.
