# Issue #10412 — Cannot execute command-line and remote command

[https://github.com/microsoft/vscode-remote-release/issues/10412](https://github.com/microsoft/vscode-remote-release/issues/10412)

## Summary

Keep open: the reporter provided a repeatable Remote - SSH failure, a maintainer acknowledged it as a bug, and an open draft PR directly references this issue.

## Change summary

Remote - SSH passes an additional command that conflicts with SSH RemoteCommand when the host is recorded in remote.SSH.remotePlatform.

## Best solution

The SSH component should resolve the RemoteCommand condition through https://github.com/microsoft/vscode-remote-ssh/pull/525, then verify connections both with and without a preconfigured remote.SSH.remotePlatform entry.
