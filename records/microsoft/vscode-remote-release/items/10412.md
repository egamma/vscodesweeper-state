# Issue #10412 — Cannot execute command-line and remote command

[https://github.com/microsoft/vscode-remote-release/issues/10412](https://github.com/microsoft/vscode-remote-release/issues/10412)

## Summary

Keep open: the reporter provided a repeatable two-system reproduction, and a maintainer accepted this as a bug. There is no public evidence of a shipped fix.

## Change summary

Remote - SSH fails when an enabled SSH RemoteCommand is combined with an explicit remote.SSH.remotePlatform entry.

## Best solution

Remote - SSH should honor the configured RemoteCommand consistently whether or not the host appears in remote.SSH.remotePlatform, avoiding the conflicting trailing shell command shown in the connection log.
