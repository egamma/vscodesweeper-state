# Issue #8460 — Dev Containers: Custom Image & Features URL

[https://github.com/microsoft/vscode-remote-release/issues/8460](https://github.com/microsoft/vscode-remote-release/issues/8460)

## Summary

A real capability gap remains: private images and Features work in hand-authored configurations, but the Dev Containers configuration UI still documents discovery through the public index only. The related issues do not provide an open canonical or an existing setting that covers the request.

## Change summary

Allow organizations to add private image, Template, and Feature sources to the Dev Containers configuration picker.

## Best solution

The Dev Containers extension should provide a configurable catalog source for organization-hosted Templates and Features, including authenticated private OCI registries, and expose those entries in its configuration picker.

- **Reason:** Custom private catalogs deepen Dev Container capability while retaining the open specification and its standard OCI distribution model.
- **Evidence:** The vision identifies Dev Container capability depth and convergence with the open specification as durable themes; https://containers.dev/implementors/templates-distribution/ explicitly supports privately self-published Templates.
