Keep open: this team-authored bug tracks native Windows ARM64 server support and correct architecture/VSIX selection. Related fixes addressed the later ia32 download failure, but no evidence establishes that the broader ARM64 problem was resolved.

Remote - SSH should install a native Windows ARM64 server and ARM64 extensions instead of running x64 binaries under emulation and reporting the process as x64.
