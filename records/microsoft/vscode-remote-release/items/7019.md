# Issue #7019 — VS Code 1.69.0 installs x64 node server onto Windows 11 ARM64 remote PC and identifies platform incorrectly as x64

[https://github.com/microsoft/vscode-remote-release/issues/7019](https://github.com/microsoft/vscode-remote-release/issues/7019)

## Summary

Keep open: the supplied Windows ARM64 connection and extension-installation scenario is sufficient to retest, but current resolution is unverified. Related fixes address unavailable ia32 downloads, not the full architecture-mismatch problem; this reopened, team-authored report has no qualifying fix or open canonical.

## Change summary

Remote - SSH installs an emulated server on Windows ARM64, causing extensions to observe x64 and Marketplace installation to select x64 VSIX packages.

## Best solution

The Remote - SSH and VS Code Server owners should verify native Windows ARM64 server selection and matching platform-specific extension installation on current releases. An x64 fallback that restores connectivity alone does not resolve the reported architecture mismatch and performance impact.
