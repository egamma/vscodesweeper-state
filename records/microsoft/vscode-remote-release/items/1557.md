# Issue #1557 — Confusing attach behaviors when multiple containers have the same image name

[https://github.com/microsoft/vscode-remote-release/issues/1557](https://github.com/microsoft/vscode-remote-release/issues/1557)

## Summary

Keep open: current documentation supports per-container-name configuration, but the latest report shows container identity can still become inconsistent, even launching a terminal in the wrong container. The team-authored issue cannot receive a judgment close, and no open canonical issue owns the remaining behavior.

## Change summary

Make attached-container configuration and Explorer state consistently target either the selected container or its image when multiple containers share an image.

## Best solution

The Dev Containers extension should consistently key configuration, Explorer state, and terminal sessions by the selected container identity; image-level sharing should remain explicit, while named configurations must isolate containers.
