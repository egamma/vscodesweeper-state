# Issue #8577 — `initializeCommand` implementation and documentation don't align

[https://github.com/microsoft/vscode-remote-release/issues/8577](https://github.com/microsoft/vscode-remote-release/issues/8577)

## Summary

The documentation mismatch has been fixed in the public Dev Container specification. The current reference now explicitly documents that `initializeCommand` runs during creation and subsequent starts and may run multiple times per session.

## Change summary

Align the documented `initializeCommand` lifecycle with its behavior when reopening an existing dev container.

## Best solution

Keep the existing lifecycle behavior and its corrected specification. The separate request for a creation-only command remains tracked at https://github.com/microsoft/vscode-remote-release/issues/8179.
