# Issue #1790 — Support for Eternal Terminal

[https://github.com/microsoft/vscode-remote-release/issues/1790](https://github.com/microsoft/vscode-remote-release/issues/1790)

## Summary

Keep open: native Eternal Terminal support remains distinct from SSH session persistence, and the documented SSH settings do not establish coverage of this request. The forwarding workaround has reported limitations and is not evidence that the accepted Backlog request is resolved.

## Change summary

Support Eternal Terminal as the transport for the full remote development session, surviving network disconnects and IP changes.

## Best solution

The SSH component should evaluate an optional ET-backed connection path within the existing VS Code Server architecture, including installation, forwarding, and recovery after network changes or sleep. Coordinate with the related session-persistence request without replacing this transport-specific item.
