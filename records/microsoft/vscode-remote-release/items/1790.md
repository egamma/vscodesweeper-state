# Issue #1790 — Support for Eternal Terminal

[https://github.com/microsoft/vscode-remote-release/issues/1790](https://github.com/microsoft/vscode-remote-release/issues/1790)

## Summary

This remains a well-supported Remote - SSH feature gap: the documented OpenSSH transport does not provide ET-style persistence across network changes, and the forwarding workaround still loses the VS Code session after sleep.

## Change summary

Allow Remote - SSH to use Eternal Terminal so remote development sessions survive network outages and IP changes.

## Best solution

The SSH component should evaluate ET or a transport abstraction that preserves the VS Code connection across network changes. Coordinate the broader persistent-workspace behavior with https://github.com/microsoft/vscode-remote-release/issues/3096 without merging the distinct transport request into it.
