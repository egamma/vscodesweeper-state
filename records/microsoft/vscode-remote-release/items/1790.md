# Issue #1790 — Support for Eternal Terminal

[https://github.com/microsoft/vscode-remote-release/issues/1790](https://github.com/microsoft/vscode-remote-release/issues/1790)

## Summary

This accepted Backlog request remains necessary: Remote - SSH documents an OpenSSH transport but no native Eternal Terminal integration, while the forwarding workaround does not preserve the VS Code connection through sleep. Route it to SSH connection and reconnection ownership.

## Change summary

Allow remote development sessions to use Eternal Terminal so they survive network interruptions and IP changes.

## Best solution

Remote - SSH should support Eternal Terminal as a connection transport, or provide an equivalent integration that preserves its forwarding and reconnection benefits through network changes and client sleep.
