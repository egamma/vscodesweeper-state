# Issue #8550 — DevContainer + Remote SSH: Host server: X11 connection rejected because of wrong authentication

[https://github.com/microsoft/vscode-remote-release/issues/8550](https://github.com/microsoft/vscode-remote-release/issues/8550)

## Summary

The Dev Containers X11 forwarding path mishandles the TCP display and authentication created by Remote - SSH. A maintainer acknowledged the defect, and multiple users confirmed the same SSH-only failure with working manual workarounds.

## Change summary

X11 applications cannot connect from a dev container opened through Remote - SSH when SSH X11 forwarding is enabled.

## Best solution

Dev Containers should recognize a TCP-forwarded SSH DISPLAY and propagate the corresponding Xauthority credentials into the container instead of treating it as a local Unix-socket display.
