# Issue #11151 — Remote processes remain running indefinitely after remote session hard disconnect

[https://github.com/microsoft/vscode-remote-release/issues/11151](https://github.com/microsoft/vscode-remote-release/issues/11151)

## Summary

Keep open for Remote - SSH lifecycle investigation: the network-disable/window-close sequence is concrete enough to retest despite missing logs. Later related reports suggest cleanup problems remain, but neither a fix nor a canonical covering this exact hard-disconnect behavior is established.

## Change summary

Remote server processes remain alive indefinitely when the client window closes during a network outage, unlike a normal connected shutdown.

## Best solution

The SSH component owner should reproduce the supplied sequence and determine whether disconnect detection or server shutdown fails, distinguishing intentional reconnection grace periods from indefinite retention. Ensure abandoned sessions eventually clean up without terminating other active sessions.
