# Issue #8741 — Unable to start devcontainer when code resides on google drive

[https://github.com/microsoft/vscode-remote-release/issues/8741](https://github.com/microsoft/vscode-remote-release/issues/8741)

## Summary

The issue is already correctly classified as upstream: Docker fails to bind-mount a Google Drive-backed Windows path, while the same project works from the local C: drive. Keep it open as upstream rather than treating it as a Dev Containers defect.

## Change summary
