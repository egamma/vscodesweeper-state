# Issue #10178 — Podman Compose: Failing to build when any "features" are added? Error in devContainersSpecCLI.js

[https://github.com/microsoft/vscode-remote-release/issues/10178](https://github.com/microsoft/vscode-remote-release/issues/10178)

## Summary

Keep open: the linked implementation PR remains open, so closure would be premature. The supplied trigger and logs suffice to retest; later reports demonstrate persistence through Dev Containers 0.413.0, but do not establish the current-release outcome.

## Change summary

Adding Features to a Podman Compose dev container causes generation of unsupported additional build contexts and prevents the image from building.

## Best solution

The containers owner should review https://github.com/devcontainers/cli/pull/944, which avoids additional build contexts for Podman Compose, and ensure the corrected CLI behavior ships in Dev Containers. Retain this issue until the extension-side workflow is confirmed working.
