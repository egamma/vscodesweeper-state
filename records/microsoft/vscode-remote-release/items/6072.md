# Issue #6072 — Upgrading to 1.63 breaks attaching to Remote Containers over SSH if you have a custom docker executable path configured

[https://github.com/microsoft/vscode-remote-release/issues/6072](https://github.com/microsoft/vscode-remote-release/issues/6072)

## Summary

Keep open: this team-authored Backlog issue documents a confirmed settings-scope gap in Dev Containers over SSH, with no public fix commit, verified duplicate, or current retest supporting a factual close.

## Change summary

Attaching to containers over SSH fails when the locally configured custom Docker executable path does not exist on the SSH host.

## Best solution

Dev Containers should resolve the Docker executable setting for the SSH host rather than inheriting the local application-scoped path; the component owners should reconcile this with the broader per-remote setting request at https://github.com/microsoft/vscode-remote-release/issues/8728.
