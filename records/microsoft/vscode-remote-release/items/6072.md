# Issue #6072 — Upgrading to 1.63 breaks attaching to Remote Containers over SSH if you have a custom docker executable path configured

[https://github.com/microsoft/vscode-remote-release/issues/6072](https://github.com/microsoft/vscode-remote-release/issues/6072)

## Summary

Keep this Dev Containers regression open: the complete steps and logs suffice to retest, but no current-release fix is confirmed. Later reports concern the renamed Docker-path setting and related scoping limitations, not a verified canonical for this exact attachment failure.

## Change summary

Attaching to a container through Remote-SSH incorrectly executes the local Windows Docker path on Linux and reports that Docker needs upgrading.

## Best solution

Dev Containers should resolve the Docker executable for the intermediate SSH host independently of the local machine and container, following the machine-settings approach discussed by maintainers. Retest the supplied attachment scenario with current versions and distinguish executable-not-found errors from unsupported Docker versions.
