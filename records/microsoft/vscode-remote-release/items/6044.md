# Issue #6044 — Recent Item Link for Remote Containers

[https://github.com/microsoft/vscode-remote-release/issues/6044](https://github.com/microsoft/vscode-remote-release/issues/6044)

## Summary

Keep open for compact, informative remote-container labels in Welcome Recent and Windows jump lists. The closest matching report is newer and does not meet the re-review canonical-ownership bar; no verified fix covers this request.

## Change summary

Display the project, container identity, and remote hostname instead of a trailing user@address] fragment in recent-item labels.

## Best solution

The Dev Containers component should supply a concise recent-workspace label that preserves the folder and remote host while retaining full details in the tooltip. Coordinate with the matching report at https://github.com/microsoft/vscode-remote-release/issues/7876, retaining this older issue unless maintainers establish a canonical.
