# Issue #6044 — Recent Item Link for Remote Containers

[https://github.com/microsoft/vscode-remote-release/issues/6044](https://github.com/microsoft/vscode-remote-release/issues/6044)

## Summary

A real presentation gap remains for Dev Containers on remote Docker hosts: the compact Recent and Windows jump-list label loses the folder and container identity. No setting or canonical issue was found that fully covers the requested label format.

## Change summary

Show a concise folder, container, and remote-host identity for remote-Docker projects in Recent lists and Windows jump lists.

## Best solution

The Dev Containers integration should provide a compact Recent-item label that preserves the folder and meaningful container/host identity, coordinating with the VS Code workbench if its truncation behavior is responsible.

- **Reason:** Making remote-container entries as understandable as Remote-SSH entries advances the stated goal that remote development should feel like local development.
