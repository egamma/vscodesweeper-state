# Issue #9776 — Ability to open remote file in a different local program

[https://github.com/microsoft/vscode-remote-release/issues/9776](https://github.com/microsoft/vscode-remote-release/issues/9776)

## Summary

Keep this accepted SSH feature request open: documented browser forwarding and filesystem workarounds do not provide integrated opening of arbitrary remote files in local applications. No verified canonical owns the full request.

## Change summary

Allow files accessed through Remote - SSH to open in locally installed external applications, including browsers.

## Best solution

The Remote - SSH owner should define an integrated remote-file handoff to local applications, including how local copies and subsequent edits are handled. Preserve the broader arbitrary-file request rather than reducing it to HTTP preview.
