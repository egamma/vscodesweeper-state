# Issue #8978 — Open project on different drive: mount path must be absolute.

[https://github.com/microsoft/vscode-remote-release/issues/8978](https://github.com/microsoft/vscode-remote-release/issues/8978)

## Summary

The log suggests a Windows path is being passed directly to a Linux Docker daemon, but the Docker installation, context, versions, and WSL execution settings are missing. A current retest and complete environment details are needed to distinguish an extension path-conversion defect from Docker/WSL configuration.

## Change summary

Opening a Windows folder from another drive in a Dev Container fails because Docker receives the bind source as a Windows drive path rather than its WSL mount path.

## Best solution

Confirm whether Dev Containers still passes a Windows path when configured to execute Docker in the appropriate WSL distro. If so, the containers component should translate the workspace path consistently; otherwise the documented WSL execution configuration should resolve the report.
