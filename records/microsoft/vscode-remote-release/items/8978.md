# Issue #8978 — Open project on different drive: mount path must be absolute.

[https://github.com/microsoft/vscode-remote-release/issues/8978](https://github.com/microsoft/vscode-remote-release/issues/8978)

## Summary

Keep open: the folder-opening steps and generated Docker command provide a concrete retest case, but neither report establishes resolution. Related WSL execution settings may address some configurations; they do not prove this later report is fixed.

## Change summary

Opening a Windows project on another drive in a dev container fails because Docker rejects the generated bind-mount path.

## Best solution

The Dev Containers owner should retest the supplied secondary-drive case and determine which Docker backend receives the Windows path. Ensure workspace mounts use paths valid for that backend; distinguish a path-conversion defect from a Docker configuration mismatch before choosing a fix or configuration guidance.
