# Issue #4646 — Rootless docker mounts have the wrong permissions

[https://github.com/microsoft/vscode-remote-release/issues/4646](https://github.com/microsoft/vscode-remote-release/issues/4646)

## Summary

Keep open as an upstream Docker UID-mapping limitation with remaining Dev Containers integration work. Running as container root or using a repository volume does not satisfy the requested non-root access to host bind mounts.

## Change summary

Allow non-root users inside rootless Docker dev containers to modify host-owned bind-mounted files without changing host ownership.

## Best solution

Docker/RootlessKit needs configurable non-root UID mapping; the Dev Containers owners should track that dependency and coordinate any CLI integration, while documenting the limitations of root and volume workarounds.
