# Issue #2763 — code command not working in an external terminal or tmux

[https://github.com/microsoft/vscode-remote-release/issues/2763](https://github.com/microsoft/vscode-remote-release/issues/2763)

## Summary

This remains the canonical request for making the remote `code` CLI usable from persistent tmux sessions and external terminals. Recent reports confirm that users still need fragile workarounds to refresh `VSCODE_IPC_HOOK_CLI`.

## Change summary

Provide a supported way for the remote `code` command to reconnect to the current VS Code window from external terminals and persistent tmux sessions.

## Best solution

The remote/code-server CLI should discover or securely refresh the active IPC endpoint without relying on environment variables inherited when a shell was created, including when tmux outlives a Remote - SSH, WSL, or Dev Containers connection.
