# Issue #2763 — code command not working in an external terminal or tmux

[https://github.com/microsoft/vscode-remote-release/issues/2763](https://github.com/microsoft/vscode-remote-release/issues/2763)

## Summary

Keep this accepted feature request open as the established canonical for using the remote code command from external terminals and persistent tmux sessions. Documented commands and community environment-refresh workarounds do not fully deliver that workflow.

## Change summary

Make the remote code command usable from external terminals and reattached tmux panes without manually repairing session-specific environment variables.

## Best solution

The remote CLI and Remote - SSH owners should provide a supported way to associate external shells and persistent tmux sessions with the intended VS Code window after reconnecting, with documented handling of multiple windows. Retain this issue as the shared tracker for the corresponding containers and WSL workflows.
