# Issue #10603 — `tar -xf --no-same-owner` Option Not Supported on OpenWrt Remote Host for Extracting VS Code Server

[https://github.com/microsoft/vscode-remote-release/issues/10603](https://github.com/microsoft/vscode-remote-release/issues/10603)

## Summary

The original log identifies a concrete BusyBox tar incompatibility, but it is from Remote - SSH 0.116.1 and no current-release reproduction is available. A retest is needed before changing the installer.

## Change summary

Remote - SSH fails to install the VS Code Server on OpenWrt because BusyBox tar does not support `--no-same-owner`.

## Best solution

If this still reproduces, the Remote - SSH installer should detect BusyBox tar or probe `--no-same-owner` support and omit the unsupported option; installing a full tar implementation remains the available environment workaround.
