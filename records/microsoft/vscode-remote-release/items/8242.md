Keep the accepted Dev Containers improvement open: browsing containers on an already-connected SSH host still lacks verified coverage without another refresh and password prompt. Avoid requiring an explicit refresh and additional SSH authentication to list remote Docker containers after connecting with Remote - SSH.

Coordinate with the existing connection-sharing proposal, while handling the commenter's separate failure after entering a password through the container-log investigation requested by the maintainer.
