## Summary

Keep open: the request is specifically for Dev Containers to reuse an established Remote-SSH connection when refreshing remote containers, and the thread does not establish that current releases provide this behavior.

## Change summary

Avoid requiring another SSH password when refreshing the remote Docker containers list from an active Remote-SSH window.

## Best solution

Dev Containers should reuse the active Remote-SSH connection or its credential-capable connection path when enumerating containers. The containers owner should first retest with current Remote-SSH and Dev Containers releases and collect the Dev Containers log if the extra authentication remains.
