# Issue #3326 — Make timeout for resolvers configurable

[https://github.com/microsoft/vscode-remote-release/issues/3326](https://github.com/microsoft/vscode-remote-release/issues/3326)

## Summary

The configurable-timeout gap remains documented, with no current setting or open canonical issue found. Route this from the generic remote area to Dev Containers connection handling.

## Change summary

Allow users with unusually slow Docker endpoints to configure the timeout used while attaching to a container.

## Best solution

The Dev Containers owner should either expose a bounded resolver timeout or avoid the slow `docker info` dependency through a lightweight Docker health check, while retaining clear diagnostics when the endpoint is unresponsive.
