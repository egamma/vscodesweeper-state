# Issue #10504 — Multiple postAttachCommands scripts requiring input will not allow user to input response to second prompt.

[https://github.com/microsoft/vscode-remote-release/issues/10504](https://github.com/microsoft/vscode-remote-release/issues/10504)

## Summary

Keep open: a maintainer confirmed the second interactive postAttachCommand fails on Windows with Docker Desktop but works on macOS. The supplied reproduction remains actionable; there is no verified fix or canonical issue covering this exact symptom.

## Change summary

The second postAttachCommand inherited or configured for a dev container stops accepting input after the first interactive command finishes.

## Best solution

The Dev Containers owner should retest the supplied example on current Windows releases and preserve interactive input across inherited and local postAttachCommand executions. Both prompts should accept responses without the terminal prematurely entering its completed state.
