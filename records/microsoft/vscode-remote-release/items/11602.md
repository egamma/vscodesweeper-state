# Issue #11602 — Cannot build container with features on rootless podman

[https://github.com/microsoft/vscode-remote-release/issues/11602](https://github.com/microsoft/vscode-remote-release/issues/11602)

## Summary

The logs show a current rootless-Podman feature build failure, but the failure changed between attempts and both use the community Flatpak sandbox. A retest with current versions outside Flatpak is needed to separate a Dev Containers regression from packaging or runtime permissions.

## Change summary

Dev Containers cannot build an image containing Features with rootless Podman on Fedora Silverblue through the community VS Code Flatpak.

## Best solution

The containers owner should determine whether generated Feature builds work with rootless Podman outside the Flatpak sandbox; if they do not, the build path should avoid BuildKit assumptions and bind-mount permissions incompatible with rootless Podman.
