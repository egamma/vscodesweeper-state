# Issue #10024 — Support server install path to have wildcard keys or global install path for all hosts

[https://github.com/microsoft/vscode-remote-release/issues/10024](https://github.com/microsoft/vscode-remote-release/issues/10024)

## Summary

A real Remote - SSH capability gap remains: the setting supports exact host aliases but not wildcard or default entries. No open canonical owns the request, and its 17 upvotes show meaningful demand.

## Change summary

Allow one remote.SSH.serverInstallPath entry to apply to multiple SSH hosts through wildcard matching or a global default.

## Best solution

Remote - SSH should support OpenSSH-style host patterns or an explicit default entry for serverInstallPath, with exact aliases taking precedence. This would serve dynamic host fleets without requiring duplicated settings.
