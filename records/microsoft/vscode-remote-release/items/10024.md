# Issue #10024 — Support server install path to have wildcard keys or global install path for all hosts

[https://github.com/microsoft/vscode-remote-release/issues/10024](https://github.com/microsoft/vscode-remote-release/issues/10024)

## Summary

Keep open: per-host install-path configuration does not cover the requested wildcard or global default, and no open canonical was verified. Related requests were closed for insufficient votes, not because this capability shipped or was explicitly ruled out.

## Change summary

Allow remote.SSH.serverInstallPath to apply one installation directory to matching host patterns or all hosts.

## Best solution

Remote - SSH should support a shared install-path rule for host groups or a global default, preserving explicit per-host overrides and documenting matching precedence.
