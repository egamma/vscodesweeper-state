# Issue #9366 — IPv6 support issue

[https://github.com/microsoft/vscode-remote-release/issues/9366](https://github.com/microsoft/vscode-remote-release/issues/9366)

## Summary

Several users confirmed that Add New SSH Host misparsed IPv6 literals in 2024, but the thread has no current-version reproduction. Requesting a retest and log before the SSH parser bug remains actionable.

## Change summary

Remote - SSH should preserve a literal IPv6 address when converting an SSH command into an SSH config entry.

## Best solution

The SSH component should parse bracketed and unbracketed IPv6 literals without treating their colons as port separators, then generate a valid HostName entry. First confirm the behavior on the current Remote - SSH release because manual SSH config entries already provide a workaround.
