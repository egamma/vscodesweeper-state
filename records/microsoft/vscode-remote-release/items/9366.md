# Issue #9366 — IPv6 support issue

[https://github.com/microsoft/vscode-remote-release/issues/9366](https://github.com/microsoft/vscode-remote-release/issues/9366)

## Summary

Keep open for the Remote - SSH host-entry parsing defect, not general IPv6 connectivity. The supplied command and malformed-config symptom suffice to retest; the confirmations are historical, and no current fix or canonical covering this workflow was established.

## Change summary

Adding an SSH host using an IPv6 literal truncates the address and generates invalid SSH configuration.

## Best solution

Remote - SSH should preserve IPv6 literals when generating HostName entries and distinguish address colons from port syntax. Retest the supplied Add New SSH Host workflow on the current extension; manual configuration remains a workaround, not resolution.
