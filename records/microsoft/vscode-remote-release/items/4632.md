# Issue #4632 — Improve configuration of dev container .gitconfig

[https://github.com/microsoft/vscode-remote-release/issues/4632](https://github.com/microsoft/vscode-remote-release/issues/4632)

## Summary

Keep open: this team-authored Backlog request remains only partially covered by existing settings, and no verified canonical issue or implementation resolves its broader Git-configuration ask.

## Change summary

Make Dev Containers apply container-appropriate Git configuration, particularly VS Code editor, diff, merge, and credential-helper settings, without unexpectedly overwriting user configuration.

## Best solution

The Dev Containers component should define a predictable Git configuration policy: preserve user-owned settings, apply container-compatible VS Code defaults where appropriate, provide finer credential-helper placement controls, and document the copy timing and available settings.
