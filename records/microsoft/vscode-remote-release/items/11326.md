# Issue #11326 — Remote SSH to Windows Server fails on reading log file with Cannot find path

[https://github.com/microsoft/vscode-remote-release/issues/11326](https://github.com/microsoft/vscode-remote-release/issues/11326)

## Summary

The logs and reporter's sleep workaround strongly suggest a Windows bootstrap race, but the only reproduction used Remote - SSH 0.120.0 and has not been reconfirmed on a current release. A current retest is needed before deciding whether the defect remains.

## Change summary

Remote - SSH prematurely reports that its Windows server failed to start when the temporary log and port information are not created within the bootstrap polling window.

## Best solution

The SSH component should tolerate slow Windows process and filesystem startup by waiting or retrying for the temporary log and port output instead of failing after the fixed polling window. A current log is needed to determine whether that race remains and whether it shares the later bootstrap timeout tracked at https://github.com/microsoft/vscode-remote-release/issues/11657.
