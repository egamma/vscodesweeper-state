## Summary

Keep this maintainer-acknowledged image-refresh bug open as the existing tracking issue. The supplied steps and build log suffice to retest; later reports show persistence, but none establishes reproduction on current releases or a confirmed fix.

## Change summary

Rebuild Container Without Cache recreates an image-based dev container without refreshing its base image, including the Linux UID-adjustment build path.

## Best solution

The Dev Containers owner should ensure the no-cache rebuild refreshes the configured base image before applying Linux UID adjustments. Retest the supplied image-based scenario and assess the later Dockerfile variant without treating manual pulls or migration to Compose as resolution.
