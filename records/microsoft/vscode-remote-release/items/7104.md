# Issue #7104 — Linux: 'Rebuild Container Without Cache' doesn't re-pull image when using 'image' in devcontainer.json

[https://github.com/microsoft/vscode-remote-release/issues/7104](https://github.com/microsoft/vscode-remote-release/issues/7104)

## Summary

This remains a confirmed Dev Containers bug: rebuilding without cache can recreate the container without pulling the current image. The available initializeCommand workaround does not fulfill the command's expected behavior.

## Change summary

Make Rebuild Container Without Cache pull the current image for image-based dev containers, including Linux configurations using updateUID.Dockerfile.

## Best solution

The Dev Containers extension should preserve image pulling through the Linux updateUID.Dockerfile path so Rebuild Container Without Cache consistently refreshes base images without requiring a duplicated docker pull command.
