# Issue #4052 — Sjow WSL version in Open Remote Window name

[https://github.com/microsoft/vscode-remote-release/issues/4052](https://github.com/microsoft/vscode-remote-release/issues/4052)

## Summary

This remains an accepted, unscheduled WSL UI request: current documentation still shows a generic WSL indicator, with no documented setting that adds the WSL generation. No canonical issue was found that owns the request.

## Change summary

Display whether a remote WSL window uses WSL 1 or WSL 2 alongside its distribution name.

## Best solution

The WSL extension should include the distribution's WSL generation in the remote window label or indicator, while retaining the distribution name so mixed WSL 1/2 environments are distinguishable at a glance.
