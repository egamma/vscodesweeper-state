# Issue #4052 — Sjow WSL version in Open Remote Window name

[https://github.com/microsoft/vscode-remote-release/issues/4052](https://github.com/microsoft/vscode-remote-release/issues/4052)

## Summary

Keep this accepted WSL enhancement open: the documented version lookup does not provide the requested in-window identification, and no verified canonical or shipped implementation was found.

## Change summary

Include the distribution's WSL generation in the remote window indicator, for example “WSL2: CentOS7”.

## Best solution

The WSL extension should expose the connected distribution's WSL 1/2 generation alongside its name in the remote indicator, allowing users to distinguish environments without a separate lookup.
