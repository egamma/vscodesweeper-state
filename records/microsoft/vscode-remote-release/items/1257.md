# Issue #1257 — Repeated SSH disconnects/reconnects that eventually stabilizes (large folder)

[https://github.com/microsoft/vscode-remote-release/issues/1257](https://github.com/microsoft/vscode-remote-release/issues/1257)

## Summary

Keep open as the established Remote - SSH resilience issue for load-induced server stalls and crashes. Numerous users supplied matching evidence, and a current 2026 report shows remote search exhausting memory, triggering OOM termination and a connection loss that did not recover.

## Change summary

Large remote workspaces can overload file watching, search, or extension-host processes, causing repeated Remote - SSH disconnects and sometimes crashing the remote server.

## Best solution

The SSH and VS Code Server owners should keep connection management responsive during remote file-watching, search, and extension-host resource spikes, and recover cleanly when those child processes fail. Narrower causes such as the long-disconnection timer in https://github.com/microsoft/vscode-remote-release/issues/11734 should remain separately tracked without replacing this broader load-induced failure.
