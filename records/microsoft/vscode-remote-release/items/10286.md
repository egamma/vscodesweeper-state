# Issue #10286 — Is there a command to open a file?

[https://github.com/microsoft/vscode-remote-release/issues/10286](https://github.com/microsoft/vscode-remote-release/issues/10286)

## Summary

Keep open: the maintainer accepted a folder-level attachment action in the container files view. Documented container attachment and default-folder configuration provide workarounds, but do not establish that this direct-opening workflow has shipped.

## Change summary

Provide a direct way to open a selected container path in VS Code, through a folder attachment action or a usable CLI URI.

## Best solution

Dev Containers should expose the maintainer-proposed Attach Visual Studio Code action on folders in the container files view, opening the selected folder in the selected container. Preserve this product-side request rather than consolidating it into broader URI handling or unrelated CLI installation work.

## Vision fit

- **Fit:** aligned
- **Reason:** Directly opening a selected container folder improves access to remote development without changing the established architecture.
- **Evidence:** The public product promise is to "Open any folder in a container, on a remote machine, or in WSL and take advantage of VS Code's full feature set."
