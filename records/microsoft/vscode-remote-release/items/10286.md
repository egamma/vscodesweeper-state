# Issue #10286 — Is there a command to open a file?

[https://github.com/microsoft/vscode-remote-release/issues/10286](https://github.com/microsoft/vscode-remote-release/issues/10286)

## Summary

Keep open in the Backlog: a maintainer confirmed that the CLI cannot currently open a selected container folder and endorsed adding an Attach Visual Studio Code action to the container files view.

## Change summary

Add a command or container-files context action that opens a selected folder from a running container in VS Code.

## Best solution

The Dev Containers extension should offer an Attach Visual Studio Code action on folders in the container files view, opening the selected path directly. Existing attached-container configuration can remember a default workspace folder but does not cover this one-off selection workflow.

## Vision fit

- **Fit:** aligned
- **Reason:** Directly opening an arbitrary folder in a running container advances the remote-development goal of making container folders accessible with the full VS Code experience.
- **Evidence:** The public product promise is to "Open any folder in a container, on a remote machine, or in WSL and take advantage of VS Code's full feature set."
