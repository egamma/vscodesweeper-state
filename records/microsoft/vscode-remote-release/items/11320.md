# Issue #11320 — DevContainer populate system file /etc/environment and broke sudo and su.

[https://github.com/microsoft/vscode-remote-release/issues/11320](https://github.com/microsoft/vscode-remote-release/issues/11320)

## Summary

Keep open: the report provides concrete steps to retest HOME contamination after attaching to a multi-user container. A later startup log corroborates /etc/environment patching, but neither confirms this exact sudo/su failure nor establishes a fix.

## Change summary

Attaching to a running container writes a user-specific HOME into /etc/environment, causing subsequent sudo/su sessions to inherit the wrong home directory.

## Best solution

The Dev Containers owner should reproduce the supplied attach workflow and ensure environment propagation preserves each target user's HOME during sudo/su sessions. Review the later escaping report as a potentially separate defect in the same environment-file patching operation.
