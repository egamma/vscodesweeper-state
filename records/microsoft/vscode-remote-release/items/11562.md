## Summary

Keep open: the reporter supplied sufficient steps to retest Remote Explorer recent-folder actions ignoring the explicit current-window choice. No current-release fix is established, and the related report does not meet the stronger duplicate bar for this re-reviewed issue.

## Change summary

Remote Explorer opens a recent SSH folder in a new window despite selecting Connect in Current Window when window.openFoldersInNewWindow is on.

## Best solution

Remote - SSH should make recent-folder actions honor the explicit current/new-window choice regardless of the global folder-opening default, while preserving working host-level commands.
