# Issue #5541 — Non-WSL paths should be linkified in WSL terminals

[https://github.com/microsoft/vscode-remote-release/issues/5541](https://github.com/microsoft/vscode-remote-release/issues/5541)

## Summary

Keep open for WSL-aware terminal link handling. Maintainers accepted both path-conversion directions, and neither the documentation nor canonical searches established that the full request is already delivered or tracked elsewhere.

## Change summary

Recognize mounted Windows paths in local WSL terminals and Windows-style paths in Remote-WSL terminals, opening the corresponding files.

## Best solution

The WSL component should provide terminal link handling that resolves paths across Windows and WSL while preserving line and column suffixes. Retest both window modes and coordinate any local-terminal integration needed with VS Code core.
