# Issue #2900 — Automatically open in container

[https://github.com/microsoft/vscode-remote-release/issues/2900](https://github.com/microsoft/vscode-remote-release/issues/2900)

## Summary

Keep this as the Dev Containers issue for opt-in automatic container opening: a maintainer explicitly directed an identical request here in September 2026. Documented commands and saved-project workarounds do not provide the requested global setting.

## Change summary

Add a setting that automatically opens a project in its dev container when a .devcontainer configuration is detected.

## Best solution

The Dev Containers extension should provide an opt-in automatic-opening preference for ordinary folder opens, retaining manual opening when disabled. Keep this issue as the owner of that setting rather than folding it into CLI-only requests.

- **Fit:** aligned
- **Reason:** Reducing repeated manual reopening supports containers as full-time development environments and a local-quality development experience.
- **Evidence:** The public vision emphasizes remote/local parity and durable investment in dev container capability depth.
