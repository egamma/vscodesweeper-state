# Issue #2900 — Automatically open in container

[https://github.com/microsoft/vscode-remote-release/issues/2900](https://github.com/microsoft/vscode-remote-release/issues/2900)

## Summary

Keep open as the canonical request for automatically reopening folders with a devcontainer configuration. Current commands and CLI workflows require explicit user action and do not provide the requested global setting.

## Change summary

Add an option that automatically reopens any locally opened project containing a devcontainer configuration inside its container.

## Best solution

The Dev Containers extension should offer an opt-in user setting or notification action that automatically reopens detected devcontainer projects, while retaining the existing prompt-based default.

## Vision fit

- **Fit:** aligned
- **Reason:** Removing the manual reopen step advances the goal of making container-based development feel as seamless as local development.
- **Evidence:** The public product promise is to let users “Open any folder in a container” and use VS Code's full feature set; dev-container capability depth is also a durable theme.
