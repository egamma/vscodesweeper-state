# Issue #11345 — Distinguish hosts with the same Host but different Ports in Explorer

[https://github.com/microsoft/vscode-remote-release/issues/11345](https://github.com/microsoft/vscode-remote-release/issues/11345)

## Summary

Remote Explorer already supports distinct entries for one address by using unique SSH `Host` aliases with a shared `HostName` and different `Port` values. The duplicate `Host` entries shown are ambiguous under standard OpenSSH configuration semantics.

## Change summary

Display two SSH targets separately when they use the same network address but different ports.

## Best solution

Keep the existing SSH alias behavior and configure distinct names such as `windows-host` and `wsl-host`, each pointing to the same `HostName` with its respective port.

- **Reason:** Clearly identifying SSH targets supports the vision's durable theme of SSH fidelity, and the established SSH configuration model already provides it.

- **Proposed comment:**

  > Thanks for the report. Remote Explorer identifies targets by their SSH `Host` aliases. Please give the two entries unique aliases while keeping the actual address in `HostName`, for example:
  > 
  > ```ssh-config
  > Host windows-host
  >     HostName <address>
  >     Port <windows-port>
  > 
  > Host wsl-host
  >     HostName <address>
  >     Port <wsl-port>
  > ```
  > 
  > Both aliases will then appear separately in Remote Explorer. This configuration is covered by https://code.visualstudio.com/docs/remote/ssh#_remember-hosts-and-advanced-settings.

- **SSH configuration semantics:** https://man7.org/linux/man-pages/man5/ssh_config.5.html documents that `Host` selects a configuration section and the first obtained value for each parameter is used. Distinct aliases can therefore share a `HostName` while specifying different `Port` values.
