# Issue #9491 — Dev Container Docker build failes if "from" keyword is used in a string in Dockerfile

[https://github.com/microsoft/vscode-remote-release/issues/9491](https://github.com/microsoft/vscode-remote-release/issues/9491)

## Summary

The current public Dev Containers CLI parser still uses line-anchored `FROM` matching that could misread this continuation line, but the report has no current-version confirmation or creation log. A retest is needed before routing the likely parser defect to devcontainers/cli.

## Change summary

A Dockerfile build fails because `from` at the beginning of a continued RUN string is interpreted as a new image stage.

## Best solution

If confirmed on the current Dev Containers extension, the devcontainers CLI parser should recognize logical Dockerfile instructions rather than treating every physical line beginning with `FROM` as a stage; the extension owner can route the parser fix to https://github.com/devcontainers/cli.
