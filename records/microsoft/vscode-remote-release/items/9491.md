# Issue #9491 — Dev Container Docker build failes if "from" keyword is used in a string in Dockerfile

[https://github.com/microsoft/vscode-remote-release/issues/9491](https://github.com/microsoft/vscode-remote-release/issues/9491)

## Summary

Keep open: the supplied two-file example and exact error suffice for a maintainer retest, but there is no confirmation of resolution. The report dates to VS Code 1.86.0; neighboring Dockerfile-parser fixes do not establish that current Dev Containers handles this case.

## Change summary

Dev Containers reportedly interprets a continued RUN string beginning with 'from Simon' as an image declaration and fails looking up simon:latest.

## Best solution

The containers owner should compare the exact sample in current Dev Containers with a direct Docker build, preserving its continuation whitespace. If Dev Containers alone interprets the string as a base image, correct its Dockerfile handling so continued RUN arguments are not treated as FROM instructions.
