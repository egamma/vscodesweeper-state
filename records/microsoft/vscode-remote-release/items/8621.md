# Issue #8621 — feat: add port forwarding to wsl

[https://github.com/microsoft/vscode-remote-release/issues/8621](https://github.com/microsoft/vscode-remote-release/issues/8621)

## Summary

Keep this accepted WSL feature request open: displaying ports and providing localhost access do not deliver the requested LAN forwarding. Existing networking workarounds do not establish that extension-managed forwarding has shipped, and no eligible canonical was verified.

## Change summary

Add WSL port forwarding that exposes selected services through the Windows host's network interfaces, including support for remote.localPortHost=allInterfaces.

## Best solution

The WSL component should provide functional Ports-view forwarding with selectable Windows-side bindings, rather than relying solely on WSL's localhost forwarding. Preserve this public request until that capability ships or a verified canonical owns the full remaining work.

- **Existing-capability check:** https://learn.microsoft.com/en-us/windows/wsl/networking documents localhost access, manual netsh interface portproxy for NAT-mode LAN access, and networkingMode=mirrored for direct LAN access on Windows 11 22H2 or newer.
