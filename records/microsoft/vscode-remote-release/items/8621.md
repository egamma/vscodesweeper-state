# Issue #8621 — feat: add port forwarding to wsl

[https://github.com/microsoft/vscode-remote-release/issues/8621](https://github.com/microsoft/vscode-remote-release/issues/8621)

## Summary

Keep open: this accepted Backlog request has 104 upvotes, and later reports confirm that the Ports view still does not expose WSL services through all host interfaces. Existing WSL localhost integration only partially covers the requested capability.

## Change summary

Make WSL port forwarding functional through the Ports view, including exposing forwarded services to other network devices when all-interface binding is requested.

## Best solution

The WSL extension should provide functional tunnel handling for the Ports view and honor `remote.localPortHost: "allInterfaces"`, including when WSL automatic localhost forwarding is disabled. The implementation should make the selected binding and its network exposure explicit.
