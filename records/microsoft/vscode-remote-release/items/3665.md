# Issue #3665 — Allow a default ".code-workspace" file to open to be specified in devcontainer.json #1124

[https://github.com/microsoft/vscode-remote-release/issues/3665](https://github.com/microsoft/vscode-remote-release/issues/3665)

## Summary

Keep this accepted, team-authored request open: documented folder-selection settings and reload-based workarounds do not deliver automatic workspace-file opening. An open PR explicitly references this issue, so implementation review—not closure—is the next step.

## Change summary

Allow devcontainer.json to select a .code-workspace file automatically when opening or reopening a project in a container.

## Best solution

The Dev Containers owner should review https://github.com/microsoft/vscode/pull/297244 and coordinate the remaining configuration-consumption and connection-path work so the selected workspace opens directly while lifecycle commands retain a directory working path. Keep this issue tracking the product capability until that integration ships.
