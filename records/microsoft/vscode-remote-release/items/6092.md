# Issue #6092 — Self signed SSL Certificate support for DevContainers

[https://github.com/microsoft/vscode-remote-release/issues/6092](https://github.com/microsoft/vscode-remote-release/issues/6092)

## Summary

Keep this as the canonical request for consistent custom-CA handling across the Dev Containers lifecycle. Shipped changes cover several certificate paths, but recent reports and the open CLI work show that feature installation, build helpers, and child processes can still lose trust configuration.

## Change summary

Allow Dev Containers to use corporate or self-signed trusted CAs consistently during bootstrap, image builds, feature retrieval, extension installation, and container runtime.

## Best solution

The containers component should consistently propagate host trust and explicit CA configuration through the extension, Dev Container CLI, bootstrap helpers, and feature installation, while clearly identifying Docker-owned trust boundaries. Coordinate the remaining OS-certificate-store work with https://github.com/devcontainers/cli/issues/412.
