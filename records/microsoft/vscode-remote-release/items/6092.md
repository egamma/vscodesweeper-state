# Issue #6092 — Self signed SSL Certificate support for DevContainers

[https://github.com/microsoft/vscode-remote-release/issues/6092](https://github.com/microsoft/vscode-remote-release/issues/6092)

## Summary

Keep open for the remaining host-CA propagation capability: confirmed fixes cover the local CLI and bootstrap container, but the thread still requests a supported way to consume those certificates in user containers without per-developer setup. The existing Dockerfile workaround and narrower related reports do not establish full resolution.

## Change summary

Allow corporate trusted CA certificates to be supplied consistently across Dev Containers setup, feature installation, and the development container.

## Best solution

The Dev Containers component should define a supported way to expose or install its collected host CA bundle in user containers early enough for feature installation, without requiring certificates in each repository. Preserve the existing CLI/bootstrap improvements and distinguish Docker builder trust configuration from extension-owned certificate propagation.
