# Issue #3296 — Allow picking folder names under volumes

[https://github.com/microsoft/vscode-remote-release/issues/3296](https://github.com/microsoft/vscode-remote-release/issues/3296)

## Summary

Keep open: this team-authored feature request identifies a remaining usability gap in the named-volume workflow, and no verified canonical issue or documented existing folder picker covers it.

## Change summary

When reusing a named container volume, offer its existing folders for selection instead of requiring the folder name to be entered again.

## Best solution

The Dev Containers extension should enumerate suitable folders inside the selected named volume and offer them in the Clone Repository in Container Volume workflow, while retaining manual entry for new folders.
