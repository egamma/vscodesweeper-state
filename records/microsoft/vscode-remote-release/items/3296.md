# Issue #3296 — Allow picking folder names under volumes

[https://github.com/microsoft/vscode-remote-release/issues/3296](https://github.com/microsoft/vscode-remote-release/issues/3296)

## Summary

Keep this team-authored request open: selecting existing folders within a volume is distinct from naming a folder or inspecting the volume. No verified fix or same-symptom canonical establishes that the requested picker is delivered.

## Change summary

Offer existing folder names when selecting a previously used volume in the clone-in-volume workflow.

## Best solution

The Dev Containers extension should offer existing directories alongside new-folder entry after a volume is selected. Check the current named-volume flow against the supplied steps before deciding whether implementation remains necessary.
