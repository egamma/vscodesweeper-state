# Issue #9251 — using vs code CLI from within tunnel connection

[https://github.com/microsoft/vscode-remote-release/issues/9251](https://github.com/microsoft/vscode-remote-release/issues/9251)

## Summary

Keep open as the maintainer-designated tracker for tunnel subcommands in the remote terminal's injected code command. The documented standalone CLI is a workaround, not evidence that this integration has shipped.

## Change summary

Support code tunnel status and service-management subcommands from the terminal inside a Remote Tunnels connection.

## Best solution

The CLI and remote-server owners should expose tunnel-management subcommands through the injected code command while preserving its ability to open files in the connected editor. Keep this issue tracking that integration; invoking the standalone CLI explicitly remains a workaround.
