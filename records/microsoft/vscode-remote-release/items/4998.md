# Issue #4998 — "Attach Visual Studio Code" doesn't use kubeconfig.yaml in current project

[https://github.com/microsoft/vscode-remote-release/issues/4998](https://github.com/microsoft/vscode-remote-release/issues/4998)

## Summary

Keep this as the canonical issue: maintainers explicitly consolidated the same request here, and recent reports confirm Dev Containers still ignores the Kubernetes extension's selected kubeconfig.

## Change summary

Attaching VS Code to a Kubernetes container should use the project or Kubernetes extension's active kubeconfig instead of assuming the default configuration.

## Best solution

Dev Containers should retrieve the Kubernetes extension's active kubeconfig or carry its resolved path into the Kubernetes remote authority and pass it to kubectl. Consolidate https://github.com/microsoft/vscode-remote-release/issues/6553 into this older, maintainer-designated canonical issue.
