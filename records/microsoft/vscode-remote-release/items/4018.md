# Issue #4018 — Can't connect to WSL with VPN/disabled ipv6

[https://github.com/microsoft/vscode-remote-release/issues/4018](https://github.com/microsoft/vscode-remote-release/issues/4018)

## Summary

The available evidence points to VPN or Windows networking blocking WSL loopback access rather than a confirmed WSL-extension defect. Keep this open as an upstream/environment issue and route it accordingly.

## Change summary

Connecting to WSL fails when IPv6 is disabled or a VPN blocks access to the local WSL endpoint.

## Best solution

The VPN or Windows networking configuration should preserve local-network access to WSL; the WSL extension could additionally diagnose this condition and explain which endpoint is unreachable.
