## Summary

Keep open for the WSL owner to retest the documented VPN/disabled-IPv6 connection failure. WSL networking and the extension's connection path have changed since this report, but neither the workarounds nor related fixes establish resolution; the supplied steps and log suffice for a retest.

## Change summary

Opening a WSL2 remote window fails when the IPv4 probe receives no response and the resolver falls back to ::1 despite IPv6 being disabled.

## Best solution

The WSL owner should verify fallback selection with IPv6 disabled and a VPN active, distinguishing an unusable resolver endpoint from VPN restrictions that block all reachable endpoints. Correct endpoint selection if necessary, or document the demonstrated network prerequisite if the failure is entirely environmental.
