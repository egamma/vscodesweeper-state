[https://github.com/microsoft/vscode-remote-release/issues/8526](https://github.com/microsoft/vscode-remote-release/issues/8526)

## Summary

Linux-host Dev Containers support over tunnels shipped after this report, but this thread has no confirmation that attaching to an existing container now works. Ask for a targeted retest rather than closing an accepted, planned request on release documentation alone.

## Change summary

Allow attaching VS Code to an existing Docker container on an Ubuntu host reached through Remote - Tunnels.

## Best solution

Dev Containers should discover and attach to running containers on the tunnel host. Confirm the original attachment workflow with current releases; if the empty-container list persists, investigate that remaining behavior rather than treating folder reopening as equivalent.
