# Issue #2985 — Add `preDeleteCommand` to devcontainer.json

[https://github.com/microsoft/vscode-remote-release/issues/2985](https://github.com/microsoft/vscode-remote-release/issues/2985)

## Summary

The teardown capability remains absent from the current Dev Container specification, and no public canonical issue owns it. This team-authored design discussion should remain open until its cross-tool semantics are decided.

## Change summary

Add a best-effort devcontainer.json lifecycle command that runs before a development container is deleted.

## Best solution

Define deletion semantics and portability in https://github.com/devcontainers/spec before implementing the hook in Dev Containers and other supporting tools. This issue can track the extension-specific behavior until a public specification proposal becomes canonical.
