# Issue #8757 — `Remote-ssh connect to remote` should connect to remote, even if I add a new host

[https://github.com/microsoft/vscode-remote-release/issues/8757](https://github.com/microsoft/vscode-remote-release/issues/8757)

## Summary

Keep this Remote - SSH workflow improvement open: adding a host during Connect interrupts keyboard navigation and loses the requested current-window behavior. This team-authored Backlog item has neither a verified canonical covering both concerns nor evidence of a fix.

## Change summary

Continue connecting after adding a new SSH host, preserving keyboard flow and the original current-window choice.

## Best solution

Remote - SSH should retain the originating connection command through host creation and connect in the selected window, without requiring a separate notification action. Preserve the standalone Add New SSH Host command's configuration-editing workflow.
