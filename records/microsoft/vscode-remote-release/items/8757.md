# Issue #8757 — `Remote-ssh connect to remote` should connect to remote, even if I add a new host

[https://github.com/microsoft/vscode-remote-release/issues/8757](https://github.com/microsoft/vscode-remote-release/issues/8757)

## Summary

Keep open as a team-authored SSH workflow polish item. The available Connect action does not preserve the requested current-window behavior or provide an effective keyboard path, and no open canonical issue was found.

## Change summary

After adding a host from a Remote-SSH connect command, automatically connect using the selected window mode without interrupting keyboard flow.

## Best solution

Remote - SSH should carry the originating Connect Current Window or Connect New Window intent through the add-host flow and make the resulting Connect action keyboard-accessible.
