# Issue #5945 — Allow mounting workspace in multiple containers (docker compose)

[https://github.com/microsoft/vscode-remote-release/issues/5945](https://github.com/microsoft/vscode-remote-release/issues/5945)

## Summary

Verified duplicate: the open canonical issue tracks exposing a clone-in-volume workspace to additional Docker Compose services with one configuration.

## Change summary

Allow multiple Docker Compose services to mount the workspace volume created by Clone Repository in Named Container Volume.

## Best solution

Consolidate on https://github.com/microsoft/vscode-remote-release/issues/6561 and add a supported way for Compose services to reference the automatically created workspace volume and its repository subpath.
