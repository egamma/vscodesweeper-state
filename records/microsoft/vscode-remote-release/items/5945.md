# Issue #5945 — Allow mounting workspace in multiple containers (docker compose)

[https://github.com/microsoft/vscode-remote-release/issues/5945](https://github.com/microsoft/vscode-remote-release/issues/5945)

## Summary

Keep open: the supplied Compose configuration and generated override provide concrete steps to retest the conflicting workspace mount. Later discussion acknowledges the multi-service limitation, but neither a confirmed fix nor a canonical covering this report's custom mount failure was established.

## Change summary

Cloning into a named container volume generates a workspace mount that conflicts with sharing the repository at /var/www/html across backend and webserver services.

## Best solution

The containers component should support sharing the cloned workspace volume across Compose services without the generated repository override breaking the configured mount location. Retest the supplied configuration and coordinate with the related multi-service volume work while preserving this report's custom-target and ./ cloning cases.
