# Issue #11641 — Open New Window With Project.

[https://github.com/microsoft/vscode-remote-release/issues/11641](https://github.com/microsoft/vscode-remote-release/issues/11641)

## Summary

VS Code already supports opening a recent project directly in a new window through the normal Open Recent picker using a modifier key. This is core workbench behavior rather than a Remote Development feature.

## Change summary

Provide a single action that opens a selected project in a new VS Code window.

## Best solution

Keep the existing Open Recent modifier behavior; users can hold Ctrl/Cmd while selecting a project, or run `code --new-window <project>`. Any discoverability improvement belongs in microsoft/vscode, where the equivalent request was already considered.

## Vision fit

- **Fit:** rejected
- **Reason:** General project and window management belongs to the VS Code workbench, not the remote extensions.
- **Evidence:** The Remote Development vision concerns opening folders in containers, remote machines, or WSL; this request does not describe remote-specific behavior.
