# Issue #3047 — Unable to pass paratmers to file in dotfile install command

[https://github.com/microsoft/vscode-remote-release/issues/3047](https://github.com/microsoft/vscode-remote-release/issues/3047)

## Summary

This team-authored feature request remains necessary: current documentation still presents the dotfiles install command as a script path, while a December 2025 report confirms that arguments remain unsupported. The wrapper-script workaround does not provide workspace-specific arguments.

## Change summary

Allow the Dev Containers dotfiles install command to invoke an entry script or command with workspace-specific arguments.

## Best solution

The Dev Containers extension should support an unambiguous executable-and-arguments form for dotfiles installation while retaining compatibility with existing script-path settings.
