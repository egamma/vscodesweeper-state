# Issue #3047 — Unable to pass paratmers to file in dotfile install command

[https://github.com/microsoft/vscode-remote-release/issues/3047](https://github.com/microsoft/vscode-remote-release/issues/3047)

## Summary

Keep this team-authored request open: configurable arguments to the dotfiles installer remain an unconfirmed capability gap, and wrapper scripts do not satisfy the stated requirement. No verified open canonical or product fix was found.

## Change summary

Allow the Dev Containers dotfiles installation setting to pass arguments to a reusable installer instead of requiring separate wrapper scripts.

## Best solution

The Dev Containers component should support configurable installer arguments while preserving existing script-only configurations and defining quoting semantics. Keep this issue as the owner of that capability rather than treating user-maintained wrapper scripts as a product fix.
