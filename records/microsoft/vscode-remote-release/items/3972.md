# Issue #3972 — Feature request: Allow dynamic "runArgs" for docker

[https://github.com/microsoft/vscode-remote-release/issues/3972](https://github.com/microsoft/vscode-remote-release/issues/3972)

## Summary

Keep open: documented settings cover variable substitution and optional GPUs, but not arbitrary host-computed Docker arguments or conditional device inclusion. Related open requests cover only portions of this accepted Backlog feature.

## Change summary

Allow host-side scripts to generate container creation arguments while preserving Dev Containers' automatic lifecycle management.

## Best solution

The containers owner should agree on a spec-compatible way to consume dynamically generated creation arguments without requiring users to replace container lifecycle management. Coordinate with the related spec proposal while retaining this product-side request.
