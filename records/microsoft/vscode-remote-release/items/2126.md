# Issue #2126 — Support WSL mount options with vscode remote

[https://github.com/microsoft/vscode-remote-release/issues/2126](https://github.com/microsoft/vscode-remote-release/issues/2126)

## Summary

Keep this accepted WSL compatibility request open: restrictive mount permissions require repeated manual repairs after extension updates, and no verified fix or eligible canonical covers it.

## Change summary

Support WSL connections with metadata and restrictive fmask settings without manually restoring script execute permissions after every extension update.

## Best solution

The WSL extension should launch its bootstrap and download scripts without depending on default executable permissions on Windows-mounted files, while preserving the user's mount configuration. Coordinate with the related core request without retiring this extension-side tracking item.
