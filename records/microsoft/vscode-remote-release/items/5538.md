# Issue #5538 — [Remote - Containers] Be more restrictive when installing Docker Desktop on MacOS to set up a container

[https://github.com/microsoft/vscode-remote-release/issues/5538](https://github.com/microsoft/vscode-remote-release/issues/5538)

## Summary

Keep open: current documentation covers Colima, Podman, Rancher Desktop, and remote Docker hosts, but it does not establish that the macOS installation prompt explains Docker Desktop licensing or presents those alternatives. The request remains a valid, highly upvoted Backlog item.

## Change summary

Make Dev Containers onboarding on macOS disclose Docker Desktop's licensing considerations and present suitable alternative container setups before offering installation.

## Best solution

The Dev Containers onboarding prompt should retain Docker Desktop as the supported default while clearly linking to licensing information and the documented alternative Docker options. This preserves the simple setup path without implying Docker Desktop is the only available choice.
