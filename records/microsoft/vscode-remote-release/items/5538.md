# Issue #5538 — [Remote - Containers] Be more restrictive when installing Docker Desktop on MacOS to set up a container

[https://github.com/microsoft/vscode-remote-release/issues/5538](https://github.com/microsoft/vscode-remote-release/issues/5538)

## Summary

Keep open for the Dev Containers installation experience: documented alternatives now avoid Docker Desktop, but do not establish that the extension explains subscription requirements before offering installation. No verified canonical owns that remaining request, and the accepted Backlog item should not receive a decline close.

## Change summary

Make the macOS Docker Desktop installation offer explain subscription requirements and provide a clear path to alternative setups.

## Best solution

The Dev Containers owner should review the current macOS installation prompt and ensure it links Docker Desktop licensing requirements and documented alternatives before users choose to install. Runtime compatibility work remains separate from this onboarding decision.
