# Issue #6844 — Export `LOCAL_WORKSPACE_FOLDER` env var to docker compose

[https://github.com/microsoft/vscode-remote-release/issues/6844](https://github.com/microsoft/vscode-remote-release/issues/6844)

## Summary

Keep open: documented configuration does not establish automatic workspace-path export to Compose, and the maintainer proposed a local-environment configuration surface. No verified canonical owns the same request.

## Change summary

Expose the host workspace path to Docker Compose, or support an equivalent declarative workspace mount, without generating a .env file.

## Best solution

The containers component should provide a declarative way to pass workspace-derived values to its Compose invocations, coordinating any new devcontainer.json property with the specification. Preserve the reporter's same-path mounting use case and the later request for development-only Compose interpolation.
