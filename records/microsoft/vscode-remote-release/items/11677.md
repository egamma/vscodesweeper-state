# Issue #11677 — Remote SSH: askpass socket path exceeds macOS 104-char Unix socket limit (regression in 0.123.0)

[https://github.com/microsoft/vscode-remote-release/issues/11677](https://github.com/microsoft/vscode-remote-release/issues/11677)

## Summary

Verified duplicate: the older open issue tracks the same macOS askpass socket path overflow, `EINVAL` errors, and infinite Remote-SSH reconnect loop.

## Change summary

Prevent Remote-SSH's askpass Unix socket path from exceeding macOS's `sun_path` limit when the local server is enabled.

## Best solution

Consolidate on https://github.com/microsoft/vscode-remote-release/issues/11672 and fix askpass socket generation there so it remains within macOS's path limit without requiring `TMPDIR` or `useLocalServer` workarounds.
