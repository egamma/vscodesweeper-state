# Issue #7093 — Tagging DevContainer image

[https://github.com/microsoft/vscode-remote-release/issues/7093](https://github.com/microsoft/vscode-remote-release/issues/7093)

## Summary

Keep this accepted Dev Containers request open: documented tagging options do not establish control over the image name generated when opening a Docker Compose dev container. The older tagging request is related, but does not establish ownership of this Compose-specific behavior.

## Change summary

Allow users to control the final dev-container image name and tag, rather than replacing the Docker Compose service's configured image reference with a generated name.

## Best solution

Dev Containers should provide a supported way to select the final image name and tag in its Docker Compose workflow, with clear handling of extension-generated image variants. Coordinate with the older tagging request without closing this report unless its Compose-specific requirement is explicitly covered.
