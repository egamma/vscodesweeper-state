# Issue #7093 — Tagging DevContainer image

[https://github.com/microsoft/vscode-remote-release/issues/7093](https://github.com/microsoft/vscode-remote-release/issues/7093)

## Summary

Consolidate this request into the older, open image-tagging request, whose discussion explicitly reports the same Docker Compose image-name override. The existing pre-build command offers a workaround, not control over the extension's generated image tag.

## Change summary

Allow a Docker Compose dev container to retain a user-specified image name and tag instead of receiving a generated name.

## Best solution

Track configurable image tagging in https://github.com/microsoft/vscode-remote-release/issues/3650, including honoring the selected Compose service's image name when building the development image.
