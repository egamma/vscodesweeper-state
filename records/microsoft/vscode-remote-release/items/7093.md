# Issue #7093 — Tagging DevContainer image

[https://github.com/microsoft/vscode-remote-release/issues/7093](https://github.com/microsoft/vscode-remote-release/issues/7093)

## Summary

This remains an accepted Containers backlog request with sufficient community support, and the current Dev Containers tooling still generates hash-based derived image names without exposing naming control.

## Change summary

Allow Docker Compose-based dev containers to use a user-controlled name and tag for the derived development image.

## Best solution

The Containers owner should add a collision-safe way to configure the derived image tag, likely in coordination with the public devcontainers CLI, while continuing to honor Compose's `image` value for the original service build.

- **Fit:** aligned
- **Reason:** Predictable derived-image naming improves reproducibility and operational control for Docker Compose dev-container workflows.
- **Evidence:** The durable vision includes deeper Docker Compose support and describes dev-container environments as easy to create and recreate.
