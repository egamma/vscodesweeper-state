# Issue #6149 — Zsh of VSCode terminal hangs if command "code --wait <filename>" is used and file is closed without been saved.

[https://github.com/microsoft/vscode-remote-release/issues/6149](https://github.com/microsoft/vscode-remote-release/issues/6149)

## Summary

Keep open: the concrete new-file/discard steps suffice to retest, and historical confirmations show this is not Zsh-specific. Later CLI fixes do not establish resolution of this remote-only report; its accepted bug/Backlog classification also bars applying an older decline decision.

## Change summary

Closing a newly opened, unsaved file should release remote `code --wait` without requiring Ctrl+C.

## Best solution

The remote CLI owners should retest discarding a nonexistent file over SSH and SSH-backed Dev Containers, ensuring the waiting command exits. If the failure is the shared workbench untitled-editor handling identified in the related core report, a maintainer can transfer this to microsoft/vscode.
