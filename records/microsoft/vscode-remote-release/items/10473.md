# Issue #10473 — pylance extension does not install to devcontainer (most of the time)

[https://github.com/microsoft/vscode-remote-release/issues/10473](https://github.com/microsoft/vscode-remote-release/issues/10473)

## Summary

Fixed by the merged Dev Containers change that increased the extension-cache pruning limit from 50 to 500 entries. The commit explicitly references this issue and addresses the diagnosed cause.

## Change summary

Dev-container rebuilds intermittently fail to install Pylance and other extensions because required files disappear from the VS Code Server extension cache.

## Best solution

Keep the increased cache limit shipped by the Dev Containers component; usage-based cache cleanup can be tracked separately if the higher limit remains insufficient.
