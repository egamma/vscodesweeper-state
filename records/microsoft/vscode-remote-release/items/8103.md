# Issue #8103 — Cannot build a devcontainer image with Podman - Dockerfile-with-features: no such file or directory

[https://github.com/microsoft/vscode-remote-release/issues/8103](https://github.com/microsoft/vscode-remote-release/issues/8103)

## Summary

This is correctly classified as an upstream Podman path-forwarding defect, not a Dev Containers bug. Podman identified the missing transfer of additional build contexts and later received confirmations of a Windows fix, while macOS may still require separate upstream investigation.

## Change summary

Building a feature-enabled dev container with Podman on Windows or macOS fails because temporary Dockerfile and build-context paths are not available inside the Podman VM.

## Best solution

Podman should reliably copy and remap `-f` and `--build-context` paths into its VM. Confirm the original macOS scenario with a current Podman release; if it persists, track that remaining platform-specific defect with Podman as requested in the upstream thread.
