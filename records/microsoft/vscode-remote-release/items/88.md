# Issue #88 — Support for working with Azure Container Instances

[https://github.com/microsoft/vscode-remote-release/issues/88](https://github.com/microsoft/vscode-remote-release/issues/88)

## Summary

This remains the canonical feature request for developing directly in Azure Container Instances. Current remote-container support requires a Docker Engine host, while Docker has retired its ACI integration, so the requested capability remains unimplemented and needs a fresh product decision.

## Change summary

Allow Dev Containers to create or attach to Azure Container Instances and use remotely mounted workspace storage without requiring local files or Docker.

## Best solution

The Dev Containers owner should decide whether to provide native ACI provisioning and connection through Azure tooling, independent of the retired Docker ACI context. If pursued, it must accommodate ACI's restricted execution and connectivity model while supporting remotely stored workspaces.
