# Issue #88 — Support for working with Azure Container Instances

[https://github.com/microsoft/vscode-remote-release/issues/88](https://github.com/microsoft/vscode-remote-release/issues/88)

## Summary

Keep open as the maintainer-designated tracking issue for ACI development support. Documented remote Docker workflows cover remote-only files, but do not establish ACI compatibility; the previously suggested Docker cloud integration is now deprecated.

## Change summary

Support development inside Azure Container Instances with source files persisted on a mounted Azure Files share.

## Best solution

The Dev Containers owner should assess an ACI-compatible provisioning and connection path using supported Azure tooling, with Azure Files-backed workspaces. Retain this issue as the umbrella for that product work, including the related request to avoid a local Docker CLI.
