# Issue #11390 — Distinguish Icons for Folders and Workspaces in Remote Explorer WSL Targets

[https://github.com/microsoft/vscode-remote-release/issues/11390](https://github.com/microsoft/vscode-remote-release/issues/11390)

## Summary

Keep this request open and route it to WSL and Remote Explorer owners. No documented capability or verified open canonical covers distinguishing saved workspaces from folders by their icons.

## Change summary

Use distinct icons for saved workspaces and previously opened folders in Remote Explorer's WSL targets.

## Best solution

The WSL Remote Explorer tree should identify saved workspace entries with a workspace icon distinct from folder entries, making their type recognizable without hovering or opening them.
