# Issue #4504 — Remote server disconnected when delete some files

[https://github.com/microsoft/vscode-remote-release/issues/4504](https://github.com/microsoft/vscode-remote-release/issues/4504)

## Summary

Keep open: the reporter supplied a concrete large-file deletion trigger, VPN comparison, recording, and full SSH log sufficient to retest. The report predates current releases, but neither a verified fix nor an open canonical owning this deletion-specific failure was established.

## Change summary

Deleting a large remote file over a campus VPN disconnects Remote - SSH and leaves repeated password prompts until VS Code restarts.

## Best solution

The SSH/file-IO owners should retest large-file Explorer deletion over a constrained connection and investigate the suggested undo-content transfer alongside failed reconnection. If Explorer undo is confirmed as the cause, a maintainer can transfer this to microsoft/vscode for the core change.
