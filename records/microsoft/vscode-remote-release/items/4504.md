# Issue #4504 — Remote server disconnected when delete some files

[https://github.com/microsoft/vscode-remote-release/issues/4504](https://github.com/microsoft/vscode-remote-release/issues/4504)

## Summary

The reported disconnect has a plausible Explorer-undo explanation, but no current-version reproduction or recent logs confirm it remains present. A targeted retest is needed before further investigation.

## Change summary

Deleting a large file through Explorer over a VPN-backed Remote-SSH connection disconnects the remote session and leaves reconnection unusable until VS Code restarts.

## Best solution

Confirm whether current VS Code and Remote - SSH releases still transfer large deleted files for Explorer undo; if so, the owning component should limit or avoid that transfer on remote file systems.
