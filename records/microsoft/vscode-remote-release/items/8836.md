# Issue #8836 — Environment variables are empty when processing devcontainer.json

[https://github.com/microsoft/vscode-remote-release/issues/8836](https://github.com/microsoft/vscode-remote-release/issues/8836)

## Summary

Keep open for Dev Containers: the supplied configuration and logs suffice to retest the csh host-environment probe failure. Later tcsh reports corroborate the diagnosis, but neither they nor the 2026 Bash workaround establish resolution on current releases.

## Change summary

Dev Containers passes empty Docker build arguments after its SSH-host environment probe invokes csh with incompatible login-shell options.

## Best solution

The Dev Containers owner should retest the supplied configuration and make host-environment probing compatible with csh/tcsh before resolving localEnv build arguments. Investigate the reported ineffective userEnvProbe override separately from container-side probing.
