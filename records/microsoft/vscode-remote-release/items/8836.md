# Issue #8836 — Environment variables are empty when processing devcontainer.json

[https://github.com/microsoft/vscode-remote-release/issues/8836](https://github.com/microsoft/vscode-remote-release/issues/8836)

## Summary

Keep open: multiple reporters reproduced environment probing failures with csh/tcsh, where the generated `-lic` invocation is invalid and leaves `${localEnv:...}` build arguments empty.

## Change summary

Dev Containers fails to import host environment variables when the remote user's login shell is csh or tcsh.

## Best solution

The Dev Containers component should generate shell-compatible environment-probe arguments for csh/tcsh, or provide a reliable fallback that preserves the configured `userEnvProbe` behavior.
