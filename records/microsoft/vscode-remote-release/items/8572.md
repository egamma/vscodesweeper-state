[https://github.com/microsoft/vscode-remote-release/issues/8572](https://github.com/microsoft/vscode-remote-release/issues/8572)

## Summary

Keep open for the misleading Dev Containers prerequisite diagnostic, not the missing Podman dependency itself. Current documentation now describes Podman 5+, but the supplied steps and log suffice to retest; neither resolution nor an open canonical covering this failure was established.

## Change summary

Dev Containers reports an insufficient Docker version when Podman's version command actually fails because newuidmap is missing.

## Best solution

Dev Containers should distinguish a failed container-runtime command from an unsupported API version and surface the underlying error with the configured runtime's name. Installing uidmap addresses this reporter's environment, but does not correct the misleading diagnostic.
