# Issue #7685 — Containers: Clicking on "Starting Dev Container (show log)" doesn't show logs

[https://github.com/microsoft/vscode-remote-release/issues/7685](https://github.com/microsoft/vscode-remote-release/issues/7685)

## Summary

Keep open: a maintainer reproduced the missing build-log display with terminal editors, and a later user confirmed it remains reproducible on VS Code 1.101.1 and Dev Containers 0.417.0. The closed vscode issue addressed a narrower shell-integration case and does not establish resolution here.

## Change summary

The Dev Containers progress notification fails to reveal build logs until connection or container startup finishes.

## Best solution

The Dev Containers component should ensure startup output opens immediately, using a panel terminal while workbench startup blocks terminal editors if necessary; any underlying VS Code terminal-startup dependency can be coordinated with microsoft/vscode.
