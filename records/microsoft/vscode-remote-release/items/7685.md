# Issue #7685 — Containers: Clicking on "Starting Dev Container (show log)" doesn't show logs

[https://github.com/microsoft/vscode-remote-release/issues/7685](https://github.com/microsoft/vscode-remote-release/issues/7685)

## Summary

Keep open: a maintainer reproduced the failure with terminal editors, and a user reconfirmed it on VS Code 1.101.1 and Dev Containers 0.417.0. The issue is already correctly routed to Containers.

## Change summary

The Dev Containers startup notification's “show log” action fails to display build output until connection completes, particularly when terminals default to the editor.

## Best solution

Dev Containers should make its startup log immediately accessible regardless of `terminal.integrated.defaultLocation`, potentially by explicitly opening this output in the terminal panel as suggested in the thread.
