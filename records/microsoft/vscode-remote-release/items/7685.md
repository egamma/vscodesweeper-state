## Summary

Keep open: maintainers reproduced delayed build-log visibility with terminal.integrated.defaultLocation set to editor, and users confirmed persistence through VS Code 1.101.1. Releases have advanced since that confirmation, but the existing steps suffice to retest; neither a confirmed fix nor a qualifying canonical was found.

## Change summary

Clicking the Dev Containers startup notification should reveal build logs immediately rather than waiting until the connection finishes.

## Best solution

The Dev Containers owner should ensure startup logs can open before remote resolution completes, evaluating the thread's proposed panel-targeted log terminal. Preserve this issue for that product-side work and distinguish the separate lifecycle hangs reported later.
