# Issue #6416 — add option to open in wsl vscode (not windows vscode) in windows explorer context menu

[https://github.com/microsoft/vscode-remote-release/issues/6416](https://github.com/microsoft/vscode-remote-release/issues/6416)

## Summary

Keep this accepted Backlog request open: it exceeded the community threshold with 85 upvotes, and current documentation still offers command-line and in-editor WSL entry points but no Windows Explorer integration.

## Change summary

Add a Windows Explorer context-menu action that opens the selected folder directly in a VS Code WSL window.

## Best solution

The WSL extension and VS Code Windows installer owners should coordinate an optional Explorer shell action that invokes the documented WSL remote-opening flow. The registry workaround proves feasibility but is not a supported installation experience.
