# Issue #6416 — add option to open in wsl vscode (not windows vscode) in windows explorer context menu

[https://github.com/microsoft/vscode-remote-release/issues/6416](https://github.com/microsoft/vscode-remote-release/issues/6416)

## Summary

Keep this accepted feature request open: documented WSL launch commands and the registry workaround do not provide a shipped Windows Explorer context-menu option. Older related requests cover automatic WSL selection, not this explicit additional menu action.

## Change summary

Add a Windows Explorer context-menu option that opens selected files or folders directly in WSL without first opening locally and reopening.

## Best solution

Provide an opt-in Explorer action that launches the selected path in WSL while preserving the existing local action. Coordinate WSL integration with VS Code's Windows installer ownership; a maintainer can transfer this to microsoft/vscode if installer-side implementation should own the work.
