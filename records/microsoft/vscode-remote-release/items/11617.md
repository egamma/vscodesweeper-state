# Issue #11617 — Preserve latest tag in feature version update

[https://github.com/microsoft/vscode-remote-release/issues/11617](https://github.com/microsoft/vscode-remote-release/issues/11617)

## Summary

Keep this team-authored improvement open: existing tag and lockfile support does not establish that feature updates preserve `latest`. No verified canonical or qualifying fix was found.

## Change summary

Preserve a feature's `latest` tag during version updates and update only its lockfile entry.

## Best solution

The Dev Containers feature updater should retain explicit `:latest` references in devcontainer.json while refreshing the corresponding lockfile version, resolved digest, and integrity. This remains extension-side work, not merely a specification change.
