# Issue #937 — Remote-SSH: Fails to discover WSL SSH

[https://github.com/microsoft/vscode-remote-release/issues/937](https://github.com/microsoft/vscode-remote-release/issues/937)

## Summary

Keep open for native WSL SSH support in Windows Remote - SSH. Even the July 2026 success requires a custom batch wrapper and reports remaining errors; it does not establish that discovery and WSL configuration integration have shipped.

## Change summary

Allow Windows Remote - SSH to discover and invoke WSL's SSH client while using its configuration and keys without custom wrappers or duplicated Windows configuration.

## Best solution

The SSH component should provide supported WSL client selection and invocation, with consistent host discovery, configuration-path handling, interactive input, and forwarding. Keep this issue as the existing tracker for that product-side capability.
