# Issue #937 — Remote-SSH: Fails to discover WSL SSH

[https://github.com/microsoft/vscode-remote-release/issues/937](https://github.com/microsoft/vscode-remote-release/issues/937)

## Summary

Keep open as the canonical feature request for native WSL SSH-client support. Current settings permit wrapper-based workarounds, but the thread shows they remain brittle and do not provide official discovery, configuration, authentication, and connection handling.

## Change summary

Allow Remote - SSH on Windows to discover and directly use an SSH client and configuration from a selected WSL distribution.

## Best solution

Remote - SSH should natively select a WSL distribution's SSH client and correctly handle its config paths, authentication prompts, agents, and forwarded ports without requiring a batch-file shim. The SSH component owns this integration.
