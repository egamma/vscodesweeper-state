# Issue #11380 — Remote SSH requires scp -O; need configurable extra flags and option to skip server transfer

[https://github.com/microsoft/vscode-remote-release/issues/11380](https://github.com/microsoft/vscode-remote-release/issues/11380)

## Summary

This remains a valid Remote-SSH capability gap: SSH config supports SSH options, but there is no equivalent way to pass `-O` to the separate SCP invocation. Existing download controls also do not fully support a manually preinstalled server on an air-gapped host.

## Change summary

Allow legacy SCP arguments or a custom SCP executable, and avoid transferring the server when a compatible installation is already present.

## Best solution

The SSH component should add a safe SCP executable/arguments configuration so this issue can remain the canonical request for `scp -O`. The preinstalled-server portion should be coordinated with https://github.com/microsoft/vscode-remote-release/issues/9454; `remote.SSH.localServerDownload: never` avoids local SCP only when the remote can download the server, so it does not cover this air-gapped scenario.
