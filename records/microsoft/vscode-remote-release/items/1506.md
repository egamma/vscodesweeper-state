# Issue #1506 — Support for cloning private https git repositories

[https://github.com/microsoft/vscode-remote-release/issues/1506](https://github.com/microsoft/vscode-remote-release/issues/1506)

## Summary

Keep open: documented container credential sharing does not establish that the missing HTTPS authentication prompt is covered across remote environments. Neither inspected related issue is a verified canonical for this report.

## Change summary

Allow authentication prompts for private HTTPS Git repositories when cloning or pulling in a remote development window.

## Best solution

Identify the remote transport and whether Git runs through Source Control or the integrated terminal, then ensure that workflow can surface HTTPS authentication locally. Ownership depends on whether the missing prompt originates in the remote extension or the built-in Git integration; a maintainer can transfer this to microsoft/vscode if the latter owns the defect.
