# Issue #11012 — Support for the Containerization Framework on macOS

[https://github.com/microsoft/vscode-remote-release/issues/11012](https://github.com/microsoft/vscode-remote-release/issues/11012)

## Summary

Keep open: experimental attachment to an already-running Apple container is available, but full Dev Containers lifecycle support remains missing. The Backlog request has substantial demand and is already correctly routed.

## Change summary

Add Apple Containerization Framework as a complete Dev Containers backend on macOS.

## Best solution

The Dev Containers extension should support creating and reopening Apple containers from devcontainer.json, including lifecycle commands, workspace selection, extensions, settings, and automatic port discovery. Coordinate the shared CLI work with https://github.com/devcontainers/cli/issues/1263.
