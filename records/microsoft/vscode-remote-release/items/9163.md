# Issue #9163 — Using a key-pair with a passphrase, unable to clone private repo to dev container

[https://github.com/microsoft/vscode-remote-release/issues/9163](https://github.com/microsoft/vscode-remote-release/issues/9163)

## Summary

This remains a confirmed Dev Containers bug: cloning a private repository into a container volume can hang when Git needs an interactive credential or SSH-key passphrase prompt. The merged terminal-input change was insufficient, and the latest maintainer diagnosis identifies missing `GIT_ASKPASS` setup.

## Change summary

Surface and accept Git credential and SSH passphrase prompts while cloning private repositories into container volumes.

## Best solution

Dev Containers should configure `GIT_ASKPASS` when no credential manager is available and reliably connect SSH passphrase prompts to VS Code input, so the clone command works without external agent or manual-clone workarounds.
