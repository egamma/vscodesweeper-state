# Issue #9163 — Using a key-pair with a passphrase, unable to clone private repo to dev container

[https://github.com/microsoft/vscode-remote-release/issues/9163](https://github.com/microsoft/vscode-remote-release/issues/9163)

## Summary

Keep open: a maintainer confirmed the SSH passphrase hang after the attempted fix, and later discussion still identifies missing credential prompting. The existing steps suffice for a current-release retest; neither workarounds nor a verified canonical establish resolution.

## Change summary

Cloning a private repository into a container volume hangs or fails when authentication requires an SSH passphrase or unavailable HTTPS credentials.

## Best solution

Dev Containers should provide usable authentication prompts during both host-side git ls-remote and container-volume git clone, distinguishing SSH passphrases from HTTPS credentials. Retest both paths and finish the maintainer-proposed prompt integration rather than relying on preloaded credentials.
