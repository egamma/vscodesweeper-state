# Issue #3251 — An wrapper for xdg-open

[https://github.com/microsoft/vscode-remote-release/issues/3251](https://github.com/microsoft/vscode-remote-release/issues/3251)

## Summary

Verified duplicate: the older open issue tracks the same remote-to-local browser bridge, including a remote command and `$BROWSER` integration. Consolidating there preserves this report's additional `xdg-open` compatibility requirement.

## Change summary

Allow commands running in remote environments to open URLs in the local browser through a `code` command, `$BROWSER`, or an `xdg-open` shim.

## Best solution

Consolidate the cross-remote browser-opening capability on https://github.com/microsoft/vscode-remote-release/issues/1919, retaining this report's requirement that tools which invoke `xdg-open` directly also work. The existing `$BROWSER` bridge covers compliant tools, while automatic `xdg-open` availability remains separately tracked for Dev Container images at https://github.com/devcontainers/images/issues/885.
