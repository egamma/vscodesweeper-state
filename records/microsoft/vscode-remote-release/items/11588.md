# Issue #11588 — Background agent worktrees do not work in Dev Containers

[https://github.com/microsoft/vscode-remote-release/issues/11588](https://github.com/microsoft/vscode-remote-release/issues/11588)

## Summary

Keep open: this team-authored, On Deck feature request identifies an unresolved Dev Containers integration gap. The documented workarounds require manual privileged setup or project-specific mounts and do not provide durable built-in support.

## Change summary

Make background-agent Git worktrees usable inside Dev Containers when the container user cannot create sibling directories under `/workspaces`.

## Best solution

Dev Containers should provide a writable, persistent worktree location for background agents automatically, or coordinate a supported location with the worktree service without requiring users to pre-create privileged directories or customize every devcontainer configuration.
