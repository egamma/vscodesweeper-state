# Issue #11588 — Background agent worktrees do not work in Dev Containers

[https://github.com/microsoft/vscode-remote-release/issues/11588](https://github.com/microsoft/vscode-remote-release/issues/11588)

## Summary

Keep this team-authored capability request open: the documented mounting options provide manual workarounds, not automatic background-agent worktree support. No verified fix or same-symptom canonical was found.

## Change summary

Support background-agent worktrees in Dev Containers without permission failures or loss of their files when the container is rebuilt.

## Best solution

The Dev Containers owner should coordinate with the agent-worktree owner on a writable, persistent worktree location that works with container mounts and survives rebuilds without per-project setup.
