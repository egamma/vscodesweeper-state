# Issue #6811 — Add support for custom building script

[https://github.com/microsoft/vscode-remote-release/issues/6811](https://github.com/microsoft/vscode-remote-release/issues/6811)

## Summary

Keep open: the request passed the repository's community threshold and was explicitly moved to Backlog. Current documentation supports images, Dockerfiles, Docker Compose, or attaching to an existing container, but not invoking an arbitrary image-building command.

## Change summary

Allow a project to supply a custom command, such as Earthly, for building the image used by its dev container.

## Best solution

Define a portable custom-build integration through the Dev Container specification, then implement it consistently in the Dev Containers extension and reference CLI; the hook should produce an image that the existing dev-container lifecycle can consume.

- **Fit:** aligned
- **Reason:** Supporting additional container build workflows advances dev-container capability depth, provided the behavior is standardized rather than implemented as an extension-specific spec fork.
