# Issue #11021 — Dev Containers fails safe.directory detection when folder path contains square brackets on Windows

[https://github.com/microsoft/vscode-remote-release/issues/11021](https://github.com/microsoft/vscode-remote-release/issues/11021)

## Summary

Keep open: the paired logs isolate a bracket-dependent failure in Dev Containers' Windows ownership check, and the supplied steps suffice to retest. Later downstream work provides a workaround, not evidence that the extension defect was fixed.

## Change summary

Dev Containers skips Git safe.directory setup when a Windows workspace path contains square brackets and the host ownership lookup returns the wrong owner.

## Best solution

The containers component should retest the bracketed-path case and make its Windows ownership lookup handle literal paths correctly while preserving the ownership check before trusting a repository.
