# Issue #11021 — Dev Containers fails safe.directory detection when folder path contains square brackets on Windows

[https://github.com/microsoft/vscode-remote-release/issues/11021](https://github.com/microsoft/vscode-remote-release/issues/11021)

## Summary

The original A/B logs strongly indicate incorrect Windows ownership detection for paths containing square brackets, but there is no current-release retest or independent confirmation. Requesting updated evidence before the containers team investigates further.

## Change summary

Dev Containers should configure Git safe.directory correctly when a Windows workspace path contains square brackets.

## Best solution

Confirm the failure on the current Dev Containers release, then make its Windows ownership lookup treat workspace paths literally so valid special characters cannot change the ACL result.
