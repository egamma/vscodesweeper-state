# Issue #10203 — Dev Containers extension misinterprets SSH URLs with custom ports as repository paths

[https://github.com/microsoft/vscode-remote-release/issues/10203](https://github.com/microsoft/vscode-remote-release/issues/10203)

## Summary

Keep open for the Dev Containers owner: the supplied URL, directory layout, versions, and command suffice to retest configuration discovery. The report predates current releases, but neither a confirmed fix nor an open canonical covering custom-port parsing was found.

## Change summary

External repository configuration discovery incorrectly treats an explicit SSH URL port as a repository path segment.

## Best solution

The Dev Containers extension should distinguish the port in an ssh:// URL from its repository path when resolving external configurations. Retest the supplied case on the current release and preserve support for scp-style Git remotes.
