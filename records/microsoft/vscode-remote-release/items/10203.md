# Issue #10203 — Dev Containers extension misinterprets SSH URLs with custom ports as repository paths

[https://github.com/microsoft/vscode-remote-release/issues/10203](https://github.com/microsoft/vscode-remote-release/issues/10203)

## Summary

The detailed report suggests incorrect repository-path derivation, but it has no independent or current-release reproduction. A retest is needed because the only evidence is from Dev Containers 0.380.0 in 2024.

## Change summary

External dev-container configuration lookup treats an SSH URL's custom port as a repository-path segment.

## Best solution

The Dev Containers owner should verify URI parsing on the current release and, if reproduced, derive the external configuration key from the SSH hostname and repository path without confusing the authority port with a path segment. If retaining the port is intentional for collision avoidance, the documented directory convention should make that explicit.
