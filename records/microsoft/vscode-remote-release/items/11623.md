# Issue #11623 — Remote SSH git integration stopped working

[https://github.com/microsoft/vscode-remote-release/issues/11623](https://github.com/microsoft/vscode-remote-release/issues/11623)

## Summary

Keep open: the reporter's apparent resolution in 1.119 is followed by an independent report of broken remote Git integration in 1.122.1. The remote-workspace scenario, disabled-extension message, and downgrade comparison provide enough detail to retest, although current-release behavior remains unverified.

## Change summary

Git branch and change tracking disappear over Remote - SSH after upgrading VS Code, with a later report showing the built-in Git extension disabled and no remote installation action.

## Best solution

The SSH and remote-extension-host owners should determine why the built-in Git extension becomes unavailable after upgrading and restore remote source-control activation. If investigation establishes that core extension management owns the defect, a maintainer can transfer this to microsoft/vscode.
