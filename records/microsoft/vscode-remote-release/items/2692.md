- **Historical reproduction evidence:** Independent users reported whole-host lockups, including a clean server installation without additional extensions at https://github.com/microsoft/vscode-remote-release/issues/2692#issuecomment-691548733. A contributor supplied repeatable file-opening steps and remote-agent watcher errors at https://github.com/microsoft/vscode-remote-release/issues/2692#issuecomment-778618413, but that resource-related case does not establish the original delayed failure's cause or current-release status.
- **Failed reproduction is not resolution:** A maintainer could not reproduce on their Ubuntu cloud VM in September 2020: https://github.com/microsoft/vscode-remote-release/issues/2692#issuecomment-690587902. Subsequent independent reports and the reporter's later scope clarifications prevent treating that historical attempt as proof that this issue is resolved.
- **Workarounds cover only some reports:** Disabling search.followSymlinks resolved one contributor's high-CPU rg case at https://github.com/microsoft/vscode-remote-release/issues/2692#issuecomment-1172983510, but another user reported continued whole-instance failures with that setting at https://github.com/microsoft/vscode-remote-release/issues/2692#issuecomment-2457958965. Adding swap resolved another user's case in January 2026 at https://github.com/microsoft/vscode-remote-release/issues/2692#issuecomment-3707103000; this is not a fixing-release confirmation for the original report.
