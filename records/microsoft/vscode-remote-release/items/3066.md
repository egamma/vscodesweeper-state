# Issue #3066 — Remote container with Singularity

[https://github.com/microsoft/vscode-remote-release/issues/3066](https://github.com/microsoft/vscode-remote-release/issues/3066)

## Summary

Keep open as the existing Dev Containers request for Singularity/Apptainer support. Current public documentation explicitly links this issue as an outstanding alternate-engine request; SSH and server workarounds do not provide native Dev Containers integration.

## Change summary

Support remote development through Dev Containers on hosts that provide Singularity/Apptainer instead of Docker.

## Best solution

The containers component should retain ownership of the extension-side integration, coordinating runtime interoperability work with the devcontainers CLI/spec. Deliver a supported Singularity/Apptainer workflow rather than requiring users to assemble SSH wrappers or launch the server manually.
