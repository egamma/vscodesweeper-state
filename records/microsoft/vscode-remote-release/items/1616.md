## Change summary

VS Code connected to WSL2 can fail to reconnect after the Windows host resumes from hibernation.

## Best solution

The WSL owner should retest hibernate recovery on current Windows, WSL, and VS Code versions and compare client and server logs when reconnection fails. The implementation should tolerate delayed WSL networking after resume without requiring a window reload or `wsl --shutdown`.
