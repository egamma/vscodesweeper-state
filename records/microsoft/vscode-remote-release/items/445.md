# Issue #445 — Support Windows Containers

[https://github.com/microsoft/vscode-remote-release/issues/445](https://github.com/microsoft/vscode-remote-release/issues/445)

## Summary

Keep open as the team-authored canonical tracker for Windows container support. Current documentation still explicitly excludes Windows container images, and the substantial community interest indicates a meaningful unresolved gap.

## Change summary

Add first-class Dev Containers support for developing inside Windows container images.

## Best solution

Develop the Windows-specific behavior first through https://github.com/devcontainers/spec, implement it in https://github.com/devcontainers/cli, add compatible Features, Templates, and samples, then adopt the resulting capability in the Dev Containers extension. This issue should remain the extension-side canonical tracker.
