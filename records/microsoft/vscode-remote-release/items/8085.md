# Issue #8085 — Non-Buildkit: Builds stages past the one specified in `build.target`

[https://github.com/microsoft/vscode-remote-release/issues/8085](https://github.com/microsoft/vscode-remote-release/issues/8085)

## Summary

The extra stages result from the legacy Docker builder processing the generated Dockerfile sequentially; the maintainer confirms BuildKit skips unused stages. Keep this classified as an upstream builder limitation rather than a Dev Containers bug.

## Change summary

Using build.target with the legacy Docker builder builds later unrelated stages after Dev Containers appends its generated feature stage.

## Best solution

Use BuildKit/buildx with Rancher Desktop so unused stages are skipped, and clarify the BuildKit requirement where Dev Containers documents build.target behavior.
