# Issue #10674 — Support shared home folder

[https://github.com/microsoft/vscode-remote-release/issues/10674](https://github.com/microsoft/vscode-remote-release/issues/10674)

## Summary

Keep this accepted feature request open: simultaneous attachments to containers sharing a home directory remain a distinct capability gap. Verified related issues cover narrower failures, not the full request.

## Change summary

Support attaching separate VS Code windows to multiple running Distrobox containers that share the same home directory.

## Best solution

Dev Containers should isolate container-specific server state and handle differing filesystem ownership while preserving the shared home. Coordinate with the related server-state collision report without reducing this request to its port-forwarding symptom.

These provide file access and configuration controls, but do not establish isolation of server state for simultaneous attachments sharing the actual home directory.
