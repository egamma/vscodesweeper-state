# Issue #10674 — Support shared home folder

[https://github.com/microsoft/vscode-remote-release/issues/10674](https://github.com/microsoft/vscode-remote-release/issues/10674)

## Summary

A maintainer confirmed that shared home folders across containers are unsupported, and the documented attach configuration does not provide per-container VS Code Server storage. The request remains a distinct Dev Containers capability gap.

## Change summary

Allow simultaneous attachment to multiple containers that share a home directory without collisions in `.vscode-server` state.

## Best solution

Dev Containers should isolate VS Code Server state by container when the home directory is shared, or expose a documented per-container server storage location for attached containers.
