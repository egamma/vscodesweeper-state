# Issue #9279 — Build log (as displayed on terminal and logged to file) is useless for debugging Dockerfiles.

[https://github.com/microsoft/vscode-remote-release/issues/9279](https://github.com/microsoft/vscode-remote-release/issues/9279)

## Summary

This remains a valid Dev Containers logging gap: Docker Compose build output should be preserved as a lossless, scrollable stream rather than TTY snapshots. No documented extension setting or open canonical issue currently covers the complete request.

## Change summary

Preserve detailed Docker Compose and Dockerfile build output in both the interactive Dev Containers log and the persisted log file.

## Best solution

The containers component should request plain progress from Docker Compose or otherwise record the raw subprocess stream in the persisted log, while presenting the same output in a scrollback-friendly terminal view.
