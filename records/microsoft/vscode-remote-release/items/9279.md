[https://github.com/microsoft/vscode-remote-release/issues/9279](https://github.com/microsoft/vscode-remote-release/issues/9279)

## Summary

Keep this Dev Containers logging request open: neither complete Compose build-output capture nor a canonical owning the same symptom was verified. Existing Docker progress controls are relevant, but do not establish that the extension preserves detailed output in both its display and saved log.

## Change summary

Preserve detailed Docker Compose build output in scrollback and saved logs instead of recording transient progress-screen snapshots.

## Best solution

Dev Containers should provide an append-only, detailed Compose build transcript in both Show Container Log and the saved log. The containers owner should assess plain-progress integration and verify that intermediate build output survives successful and failed steps.
