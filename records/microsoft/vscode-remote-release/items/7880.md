# Issue #7880 — Attach to Kubernetes: Support container metadata

[https://github.com/microsoft/vscode-remote-release/issues/7880](https://github.com/microsoft/vscode-remote-release/issues/7880)

## Summary

Keep open: this team-authored backlog item tracks a remaining Kubernetes parity gap. Docker attachment gained container-metadata support, while current documentation still describes metadata-aware attached configuration only for Docker containers.

## Change summary

Apply container image metadata when the Dev Containers extension attaches to a Kubernetes container.

## Best solution

The Dev Containers extension should consume applicable `devcontainer.metadata` from Kubernetes container images during attachment, providing the same supported configuration behavior available when attaching to Docker containers.
