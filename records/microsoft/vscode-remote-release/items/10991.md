# Issue #10991 — ECONNREFUSED with `networkingMode=VirtioProxy` and `localhostForwarding=true`

[https://github.com/microsoft/vscode-remote-release/issues/10991](https://github.com/microsoft/vscode-remote-release/issues/10991)

## Summary

Keep open as an upstream WSL networking issue. Maintainers identified VirtioProxy as the cause, the WSL team’s canonical issue remains open, and affected users still require this mode in some corporate environments.

## Change summary

Remote - WSL cannot connect to its dynamically allocated localhost server port when VirtioProxy and localhost forwarding are active.

## Best solution

The WSL networking implementation should restore reliable localhost forwarding under VirtioProxy in https://github.com/microsoft/WSL/issues/13256. The WSL extension should retain its fixed-port workaround until that upstream fix is available.
