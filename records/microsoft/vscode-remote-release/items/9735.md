# Issue #9735 — Give the ability to trigger devcontainer rebuild from scripts (git hooks, etc.)

[https://github.com/microsoft/vscode-remote-release/issues/9735](https://github.com/microsoft/vscode-remote-release/issues/9735)

## Summary

Keep open: documented CLI image building and interactive rebuild commands do not establish a scriptable rebuild/reopen operation for the active VS Code environment. The verified related requests cover different workflows, not this request's full scope.

## Change summary

Allow scripts or Git hooks to trigger a Dev Containers rebuild/reopen so the development environment matches the checked-out branch.

## Best solution

The Dev Containers extension should expose a supported scriptable rebuild/reopen entry point that applies the checked-out configuration to the active workspace. Reuse the existing container lifecycle rather than requiring hooks to manage image building and editor reconnection separately.
