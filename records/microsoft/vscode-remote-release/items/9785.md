# Issue #9785 — Only one window can be connected to a container

[https://github.com/microsoft/vscode-remote-release/issues/9785](https://github.com/microsoft/vscode-remote-release/issues/9785)

## Summary

Keep open as an accepted Dev Containers enhancement: repeated attachment cannot create multiple folderless windows on the same container. The maintainer's different-folder workaround does not cover that workflow, and no canonical owning this request was verified.

## Change summary

Allow attaching additional VS Code windows to the same running container without first opening distinct folders.

## Best solution

Dev Containers should provide an explicit way to attach another window without reusing the existing folderless container window. Preserve the existing different-folder workflow while addressing the direct repeated-attachment request.
