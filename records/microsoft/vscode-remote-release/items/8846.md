[https://github.com/microsoft/vscode-remote-release/issues/8846](https://github.com/microsoft/vscode-remote-release/issues/8846)

## Summary

Keep open: the reported accumulation across Dev Container updates provides enough detail to retest, and moving installations to .vscode-server/cli/servers does not establish a fix. No verified open canonical or confirmed resolution was found.

## Change summary

Old VS Code Server installations accumulate across container updates, consuming gigabytes without effective automatic cleanup.

## Best solution

The Dev Containers owner should verify retention across successive server updates and ensure obsolete installations are pruned without removing versions still in use. Treat the later SSH reinstall report separately unless evidence establishes the same cleanup defect.
