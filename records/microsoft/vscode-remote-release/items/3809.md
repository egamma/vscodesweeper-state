# Issue #3809 — Use local Docker config when building volumeBootstrap image

[https://github.com/microsoft/vscode-remote-release/issues/3809](https://github.com/microsoft/vscode-remote-release/issues/3809)

## Summary

Keep open: later credential forwarding and bootstrap customization address parts of this request, but do not establish that the bootstrap Docker client inherits the host's proxy configuration. The related open reports do not own this issue's full clarified scope.

## Change summary

Make Clone Repository in Container Volume use the host Docker client's proxy configuration and registry authentication when building the development container.

## Best solution

The Dev Containers component should ensure host Docker proxy configuration reaches builds invoked inside the bootstrap container, while preserving credential-helper integration. Verify the remaining proxy-config gap against current releases rather than requiring users to edit extension-managed Dockerfiles.
