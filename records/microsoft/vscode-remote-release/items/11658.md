# Issue #11658 — Excessive container exec calls while probing X11 display socket during Dev Container attach

[https://github.com/microsoft/vscode-remote-release/issues/11658](https://github.com/microsoft/vscode-remote-release/issues/11658)

## Summary

The logs show a plausible Dev Containers performance defect, but only one environment demonstrates it and the exact extension versions and complete attach log are missing. Requesting current-version confirmation before the containers owner investigates.

## Change summary

Attaching to a Dev Container through Remote SSH incurs roughly 10 seconds of latency because X11 socket candidates are probed through hundreds of sequential container exec calls.

## Best solution

The Dev Containers component should avoid separate round trips for each X11 socket candidate, preferably probing them in one container operation. First confirm the behavior on current Dev Containers and Remote - SSH versions with the complete creation log.
