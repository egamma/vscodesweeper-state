# Issue #1722 — Cluster workflow feature to allow shell commands or script to run before remote server setup (e.g. slurm) (wrap install script)

[https://github.com/microsoft/vscode-remote-release/issues/1722](https://github.com/microsoft/vscode-remote-release/issues/1722)

## Summary

Keep the accepted SSH cluster-workflow request open: tunnels and community wrappers help, but do not establish built-in support for allocating a job and running server setup inside it. The reporter explicitly qualified their earlier resolution statement, and the verified related issues do not own the full remaining ask.

## Change summary

Allow Remote - SSH to wrap server installation and startup in a scheduler command so development runs on an allocated compute node rather than the login node.

## Best solution

The SSH component should define a supported, opt-in way to allocate or reuse a scheduler job and run server bootstrap and subsequent connections within that allocation. Use the community Slurm integration as implementation input, preserving job environment and resource restrictions without requiring Azure tunnels.
