# Issue #1996 — [New feature] Abilities to set the remoteUser globally.

[https://github.com/microsoft/vscode-remote-release/issues/1996](https://github.com/microsoft/vscode-remote-release/issues/1996)

## Summary

A real capability gap remains: attached-container configurations support `remoteUser` per image or container name, but not as a user-wide default. This issue remains the clearest canonical request and has recent community interest.

## Change summary

Allow users to configure a default `remoteUser` for every attached container instead of repeating it in image- or name-specific files.

## Best solution

Dev Containers should provide a user-level fallback for attached-container `remoteUser`, overridden by image- and name-specific configurations, with a clear error when that user does not exist in the selected container.
