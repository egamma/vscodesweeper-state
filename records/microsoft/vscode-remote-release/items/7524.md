# Issue #7524 — Use default SSH_AUTH_SOCK on Windows

[https://github.com/microsoft/vscode-remote-release/issues/7524](https://github.com/microsoft/vscode-remote-release/issues/7524)

## Summary

Keep open: this team-authored Backlog request remains the canonical proposal for Remote - SSH to recognize the standard Windows OpenSSH agent when SSH_AUTH_SOCK is unset. No existing documented setting or open canonical issue covers the same behavior.

## Change summary

Default SSH_AUTH_SOCK to the Windows OpenSSH agent named pipe when Remote - SSH runs on Windows and the variable is unset.

## Best solution

Remote - SSH should detect the standard Windows OpenSSH agent pipe when SSH_AUTH_SOCK is absent, matching the established Dev Containers behavior while preserving explicit overrides.
