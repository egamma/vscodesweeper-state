# Issue #11509 — Attach to running container fails due to missing ldconfig cache

[https://github.com/microsoft/vscode-remote-release/issues/11509](https://github.com/microsoft/vscode-remote-release/issues/11509)

## Summary

Keep open: the reporter supplied the requested log, image, versions, and attach steps, which suffice to retest. Releases have advanced since March, but neither a current-release resolution nor a matching open canonical is established.

## Change summary

Attaching to a running Debian hardened container fails when /etc/ld.so.cache is absent, although running ldconfig makes attachment succeed.

## Best solution

The containers owner should retest the supplied image and determine whether attachment should prepare the cache or the VS Code Server prerequisite check should tolerate its absence while still validating dependencies. If the fix belongs entirely to the core-owned server helper, a maintainer can transfer this to microsoft/vscode.
