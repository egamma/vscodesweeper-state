[https://github.com/microsoft/vscode-remote-release/issues/2424](https://github.com/microsoft/vscode-remote-release/issues/2424)

## Summary

Keep the accepted WSL feature request open: no documented capability or verified canonical establishes that switching between Windows and WSL preserves the current open editors.

## Change summary

Preserve open files and editor layout when reopening the same folder between Windows and WSL.

## Best solution

The WSL extension should carry the current editor session across Reopen Folder in WSL and Reopen in Windows, mapping equivalent file paths. Treat cross-PC session restoration from the later comment as a separate capability rather than a prerequisite for this change.
