# Issue #2424 — [wsl] reopen should restore open editors

[https://github.com/microsoft/vscode-remote-release/issues/2424](https://github.com/microsoft/vscode-remote-release/issues/2424)

## Summary

A genuine WSL parity gap remains: switching the same folder between Windows and WSL does not preserve its open editors and layout. The issue is already correctly classified and routed.

## Change summary

Preserve open editors and editor-group layout when reopening a folder between Windows and WSL, potentially including reconnection from another PC.

## Best solution

The WSL reopen commands should map and restore the current editor groups, open files, and view state across the local/WSL authority transition. Cross-machine restoration should be assessed separately because Settings Sync does not currently include open editor state.

## Vision fit

- **Fit:** aligned
- **Reason:** Preserving editor state across Windows and WSL directly advances the goal that remote development should feel like local development.
- **Evidence:** The product promise is to provide a "local-quality development experience" in WSL, and WSL integration fidelity is identified as a durable theme.
