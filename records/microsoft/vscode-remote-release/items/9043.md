# Issue #9043 — Cannot use a basic dockerfile with Docker or Podman on Windows

[https://github.com/microsoft/vscode-remote-release/issues/9043](https://github.com/microsoft/vscode-remote-release/issues/9043)

## Summary

Keep open as an upstream Podman/runtime compatibility issue. The author resolved the original Podman build failure by updating Podman, while the remaining Windows failure was identified by a maintainer as a Podman limitation with a documented workaround.

## Change summary

A minimal Dockerfile-based dev container fails on Windows with runtime errors under Docker/Podman and an unsupported UNC path when the Wayland socket is mounted.

## Best solution

The containers owner should track whether current Podman for Windows can accept the automatic Wayland mount or whether Dev Containers should avoid offering that mount for unsupported runtimes; the older Docker/cgroup failure needs a current retest before being treated as a separate extension defect.
