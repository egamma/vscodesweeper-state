# Issue #9043 — Cannot use a basic dockerfile with Docker or Podman on Windows

[https://github.com/microsoft/vscode-remote-release/issues/9043](https://github.com/microsoft/vscode-remote-release/issues/9043)

## Summary

Keep open: the thread identifies a Podman limitation and confirms only a partial workaround, not resolution of every reported failure. This team-authored report has neither a verified full-scope duplicate nor qualifying fix evidence.

## Change summary

Building and opening a basic Dockerfile-based dev container on Windows fails through container-engine build errors and an automatically mounted WSLg Wayland socket.

## Best solution

The containers owner should distinguish the original build failures from Podman's unsupported UNC socket mount and decide whether automatic mounting should avoid incompatible engines. Podman owns the UNC-path limitation; disabling the socket remains a workaround, not evidence that the whole report is fixed.
