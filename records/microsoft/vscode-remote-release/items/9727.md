# Issue #9727 — Support for Airgap Envrionments

[https://github.com/microsoft/vscode-remote-release/issues/9727](https://github.com/microsoft/vscode-remote-release/issues/9727)

## Summary

Keep open: private image and Feature registries provide partial coverage, but do not establish a supported air-gapped workflow. The maintainer explicitly identified remaining Dev Containers extension work; the linked issues address narrower download problems.

## Change summary

Support using mirrored or customized dev container images and Features in internet-denied environments.

## Best solution

The Dev Containers owner should define a supported air-gapped workflow using internal image and Feature registries, including how remaining external metadata requests are handled. Coordinate shared functionality with devcontainers/cli while retaining extension-side integration work here.
