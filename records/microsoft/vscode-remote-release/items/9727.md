# Issue #9727 — Support for Airgap Envrionments

[https://github.com/microsoft/vscode-remote-release/issues/9727](https://github.com/microsoft/vscode-remote-release/issues/9727)

## Summary

A real air-gap capability gap remains: explicit internal Feature references are supported, but there is no documented global source-rewrite setting for images, Features, and the control manifest. The containers classification and Backlog placement remain appropriate.

## Change summary

Allow Dev Containers users to redirect image and Feature downloads to internal mirrors in air-gapped environments.

## Best solution

The Dev Containers extension and devcontainers CLI should provide a coordinated source-remapping configuration for images, Features, and required metadata, without requiring every devcontainer.json to be rewritten.
