## Change summary

Recreate a deleted development container directly from an existing repository volume using the .devcontainer configuration stored inside it.

## Best solution

Dev Containers should expose a direct way to select a repository folder in an existing volume and build/open its configuration without re-entering the repository or copying configuration elsewhere. Coordinate with the related volume-inspection workflow proposed in https://github.com/microsoft/vscode-remote-release/issues/5344.
