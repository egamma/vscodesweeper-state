# Issue #11725 — Open repository in volume using WSLC fails

[https://github.com/microsoft/vscode-remote-release/issues/11725](https://github.com/microsoft/vscode-remote-release/issues/11725)

## Summary

Keep open as a confirmed Dev Containers WSLC integration bug. A second user reproduced the failed repository-in-volume workflow on newer WSL and VS Code Insiders versions with detailed logs.

## Change summary

Opening a repository in a container volume fails when Dev Containers is configured to use WSLC.

## Best solution

The Dev Containers component should make the repository-in-volume workflow consistently use WSLC-compatible volume commands instead of invoking Docker-only commands or flags when `wslc` is selected.
