# Issue #11725 — Open repository in volume using WSLC fails

[https://github.com/microsoft/vscode-remote-release/issues/11725](https://github.com/microsoft/vscode-remote-release/issues/11725)

## Summary

Keep open: the repository-in-volume workflow has actionable steps and logs showing Docker volume enumeration during a WSLC session. WSLC has since reached GA according to the September follow-up, but no confirmed fix is documented; the supplied steps suffice for a current-version retest.

## Change summary

Opening a repository in a volume with WSLC fails during volume enumeration and subsequently removes the bootstrap container.

## Best solution

The Dev Containers owner should make repository-in-volume setup work with WSLC without requiring an in-container Docker daemon, investigating the logged volume-enumeration failure and subsequent cleanup. Keep this separate from WSL-filesystem bind-mount support.
