# Issue #2393 — Extension installation failing from CLI but not GUI

[https://github.com/microsoft/vscode-remote-release/issues/2393](https://github.com/microsoft/vscode-remote-release/issues/2393)

## Summary

Keep this tracking item open and route it to the CLI/server owners: scripted extension installation needs certificate-trust parity with the GUI. Related certificate-loading improvements do not establish that this installation path is resolved.

## Change summary

Make scripted extension installation honor trusted corporate CA certificates consistently with GUI installation.

## Best solution

The CLI and VS Code Server extension-installation paths should consume the appropriate trusted CA certificates, including installation before a client connects. Coordinate shared implementation with microsoft/vscode while preserving this tracker’s explicitly consolidated remote-installation scope.
