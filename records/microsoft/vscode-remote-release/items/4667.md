# Issue #4667 — SSH authenticity popup vanishing again

[https://github.com/microsoft/vscode-remote-release/issues/4667](https://github.com/microsoft/vscode-remote-release/issues/4667)

## Summary

Keep open: the maintainer confirmed that Remote - SSH does not recognize this specific OpenSSH host-key mismatch prompt and should. The login-terminal setting is only a workaround, and no open canonical issue owns the gap.

## Change summary

Recognize the OpenSSH warning shown when a hostname's key differs from its IP-address key and present an interactive authenticity confirmation.

## Best solution

Remote - SSH should detect this specific OpenSSH confirmation message and surface a durable trust prompt instead of leaving the connection apparently hung; `remote.SSH.showLoginTerminal` can remain the fallback for unrecognized prompts.
