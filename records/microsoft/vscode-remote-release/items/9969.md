# Issue #9969 — net::ERR_CONTENT_LENGTH_MISMATCH returning large content when port-forwarding from devcontainer

[https://github.com/microsoft/vscode-remote-release/issues/9969](https://github.com/microsoft/vscode-remote-release/issues/9969)

## Summary

This remains reproducible on current releases: the VS Code forwarder truncates slow responses from Docker-on-WSL2 dev containers after roughly 12 seconds. Route it to the Dev Containers connection path for investigation.

## Change summary

Port-forwarded HTTP responses from a dev container are prematurely truncated when the client consumes large responses slowly.

## Best solution

The Dev Containers/remote forwarding owner should ensure an active transfer is not closed by a fixed-duration timeout, using the browser-free slow-reader reproduction to verify complete Content-Length and chunked responses.
