# Issue #10734 — VSCode Remote SSH still listens on a loopback `localhost` address even with `"remote.localPortHost": "allInterfaces"`

[https://github.com/microsoft/vscode-remote-release/issues/10734](https://github.com/microsoft/vscode-remote-release/issues/10734)

## Summary

Fixed and shipped in VS Code 1.104: the managed tunnel implementation now honors `remote.localPortHost` and binds to `0.0.0.0` for `allInterfaces`.

## Change summary

Remote-SSH forwarded ports remain bound to loopback even when `remote.localPortHost` requests all local interfaces.

## Best solution

Keep the shipped VS Code core fix from https://github.com/microsoft/vscode/pull/262522; no additional Remote-SSH change is needed unless the behavior still reproduces on VS Code 1.104 or newer.
