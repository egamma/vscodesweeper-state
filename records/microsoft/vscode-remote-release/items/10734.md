[https://github.com/microsoft/vscode-remote-release/issues/10734](https://github.com/microsoft/vscode-remote-release/issues/10734)

## Summary

Keep open: the report provides sufficient steps to retest the incorrect local listener binding. A subsequent core fix may cover this behavior, but its applicability to this Remote - SSH connection path and resolution here remain unconfirmed.

## Change summary

Forwarded application ports bind only to loopback despite remote.localPortHost being set to allInterfaces, preventing access through the client's LAN address.
