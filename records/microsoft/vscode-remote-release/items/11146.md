# Issue #11146 — Remote SSH does not handle "Match all" configuration correctly

[https://github.com/microsoft/vscode-remote-release/issues/11146](https://github.com/microsoft/vscode-remote-release/issues/11146)

## Summary

The minimal configuration shows a plausible SSH-config parsing gap, but it was reported against Remote - SSH 0.120.0 and has no independent current-release confirmation. A retest is needed before determining whether the bug remains.

## Change summary

Remote Explorer omits hosts included after a `Match all` directive even though OpenSSH resolves and connects to them correctly.

## Best solution

Remote - SSH should enumerate included hosts according to OpenSSH's `Match all` semantics. First confirm the minimal reproduction on the current extension; if it persists, the SSH config parser owner should compare this path with the earlier Include handling implemented for wildcard `Host` sections.
