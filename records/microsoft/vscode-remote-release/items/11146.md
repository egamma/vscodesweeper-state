# Issue #11146 — Remote SSH does not handle "Match all" configuration correctly

[https://github.com/microsoft/vscode-remote-release/issues/11146](https://github.com/microsoft/vscode-remote-release/issues/11146)

## Summary

The detailed reproduction indicates a valid SSH-config parsing gap in Remote - SSH 0.120.0, but there is no confirmation on a current release. A current-version retest is needed before routing this for implementation.

## Change summary

Remote Explorer omits hosts from an included SSH configuration file when the Include directive follows `Match all`, although OpenSSH resolves them correctly.

## Best solution

The SSH configuration parser should resolve Include directives within `Match all` consistently with OpenSSH while excluding the Match stanza itself from the host list. If the minimal reproduction still fails on the current release, the SSH config parsing owner should investigate it as distinct from the earlier wildcard-Include regression.
