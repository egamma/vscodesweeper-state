# Issue #4260 — [remote] suppport --open-url in remote cli

[https://github.com/microsoft/vscode-remote-release/issues/4260](https://github.com/microsoft/vscode-remote-release/issues/4260)

## Summary

The central CLI-parity request remains valid: remote URI activation now works through the internal `openExternal` path, but the remote `code` stub still does not expose the requested `--open-url` option. Route this accepted Backlog request to the server/CLI owners.

## Change summary

Add `--open-url` support to the remote `code` CLI so remote processes can invoke VS Code URI handlers consistently with the local CLI.

## Best solution

The VS Code Server CLI should expose the local CLI's public `--open-url` interface and forward its URI through the existing remote `openExternal` path. This preserves the current workaround while providing documented CLI parity.
