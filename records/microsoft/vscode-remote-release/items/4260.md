# Issue #4260 — [remote] suppport --open-url in remote cli

[https://github.com/microsoft/vscode-remote-release/issues/4260](https://github.com/microsoft/vscode-remote-release/issues/4260)

## Summary

Keep open: protocol handling through --openExternal has improved, but the remote CLI still excludes --open-url. The accepted Backlog request retains a concrete CLI-parity gap, and no verified canonical owns that remaining work.

## Change summary

Support code --open-url in remote terminals so external tools can invoke extension URI handlers, including debugger launchers.

## Best solution

Implement --open-url parity in the VS Code Server's remote CLI while preserving extension URI dispatch to the connected session. A maintainer can transfer this to microsoft/vscode, where the shared server CLI implementation lives.
