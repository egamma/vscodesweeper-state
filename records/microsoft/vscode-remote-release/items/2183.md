# Issue #2183 — Add support for `mount --ssh` at container build time

[https://github.com/microsoft/vscode-remote-release/issues/2183](https://github.com/microsoft/vscode-remote-release/issues/2183)

## Summary

Implemented and shipped: Dev Containers now passes arbitrary Docker build options through `build.options`, enabling BuildKit SSH forwarding with `--ssh=default`.

## Change summary

Allow dev-container image builds to forward the host SSH agent for Dockerfile instructions using `RUN --mount=type=ssh`.

## Best solution

Use the shipped `build.options` support with `"options": ["--ssh=default"]`; the Dockerfile can then consume the forwarded agent through `RUN --mount=type=ssh`.
