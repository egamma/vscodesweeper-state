Build-time SSH forwarding is now supported through build.options, with maintainer guidance and user confirmations on Dev Containers 0.338.x. Ask whether this satisfies the original workflow before proposing a completed close; this thread has no confirmation or citable public fix commit.

## Change summary

Allow Dockerfile build steps to access the host SSH agent when installing dependencies from private Git repositories.
