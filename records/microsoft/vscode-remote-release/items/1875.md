# Issue #1875 — Remote SSH: Support SunOS

[https://github.com/microsoft/vscode-remote-release/issues/1875](https://github.com/microsoft/vscode-remote-release/issues/1875)

## Summary

SunOS and illumos remain unsupported, and no setting or documented workaround satisfies the request. Keep the well-supported feature request open for an explicit platform-support decision.

## Change summary

Add Remote - SSH and VS Code Server support for Solaris, SunOS, and illumos hosts, including SPARC and x86_64 systems.

## Best solution

The Remote - SSH and VS Code Server owners should assess sustainable automated builds and native-module testing, potentially treating x86_64 illumos and legacy SPARC Solaris as separate targets.

- **Reason:** Broader remote-host support advances remote/local parity, but Solaris and illumos fall outside the documented support matrix and require an ongoing platform-maintenance commitment.
- **Evidence:** The Remote Development promise is to "Open any folder in a container, on a remote machine, or in WSL," while https://code.visualstudio.com/docs/remote/ssh documents supported Linux, Windows, and macOS hosts rather than SunOS.
