# Issue #8636 — Pre-open and post-close hooks for remote tunnel connections

[https://github.com/microsoft/vscode-remote-release/issues/8636](https://github.com/microsoft/vscode-remote-release/issues/8636)

## Summary

Keep open: existing extension-based startup workarounds do not establish support for both pre-connect and post-disconnect hooks. This accepted Backlog request remains correctly routed to tunnels, with no verified open canonical owning its full scope.

## Change summary

Provide configurable tunnel connection lifecycle hooks to start remote compute before connecting and stop it after disconnecting.

## Best solution

The tunnels component should define supported pre-connect and post-disconnect integration points for on-demand compute, including authentication and failure handling. Preserve this issue's two-sided lifecycle scope rather than treating a custom startup command as full coverage.
