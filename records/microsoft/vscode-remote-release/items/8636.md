# Issue #8636 — Pre-open and post-close hooks for remote tunnel connections

[https://github.com/microsoft/vscode-remote-release/issues/8636](https://github.com/microsoft/vscode-remote-release/issues/8636)

## Summary

This remains a valid Backlog feature request: the documented and maintainer-suggested custom connection command can cover part of the pre-open scenario, but no existing capability provides general authenticated pre-open and post-close hooks.

## Change summary

Add lifecycle hooks around Remote Tunnel client connections so external automation can start and stop on-demand compute.

## Best solution

The Tunnels component should provide a supported lifecycle integration for provisioning on-demand hosts before connecting and notifying automation after disconnect. Any API should support authentication and avoid requiring the host tunnel to remain available continuously.
