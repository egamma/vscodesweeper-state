# Issue #10785 — enter dev container in new window

[https://github.com/microsoft/vscode-remote-release/issues/10785](https://github.com/microsoft/vscode-remote-release/issues/10785)

## Summary

Keep this accepted Dev Containers request open as the maintainer-designated tracking issue. The documented separate-window workflow requires opening another window manually; it does not provide the requested option when entering a container.

## Change summary

Add an option to enter a dev container in a new window while preserving the current window.

## Best solution

The Dev Containers extension should offer a new-window alternative to reopening the current project in a container, preserving current-window behavior as an available choice. Continue tracking that product capability here.
