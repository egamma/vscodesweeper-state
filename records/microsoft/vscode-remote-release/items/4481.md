# Issue #4481 — Include global .gitignore (core::excludesfile) with .gitconfig

[https://github.com/microsoft/vscode-remote-release/issues/4481](https://github.com/microsoft/vscode-remote-release/issues/4481)

## Summary

Keep open in the Containers backlog: Dev Containers still copies `.gitconfig` without automatically making its referenced global ignore file available, and the documented dotfiles or bind-mount approaches are manual workarounds rather than coverage of the request.

## Change summary

Copy a valid host-side `core.excludesFile` into a Dev Container alongside the automatically copied `.gitconfig`.

## Best solution

Dev Containers should resolve `core.excludesFile` from the host Git configuration and safely make that file available at the corresponding container path. Dotfiles and user-configured mounts can remain alternatives, but should not be required for this standard Git configuration.
