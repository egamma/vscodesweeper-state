# Issue #4481 — Include global .gitignore (core::excludesfile) with .gitconfig

[https://github.com/microsoft/vscode-remote-release/issues/4481](https://github.com/microsoft/vscode-remote-release/issues/4481)

## Summary

Keep open: automatic copying of the global ignore file referenced by core.excludesFile remains an unconfirmed capability gap. Documented dotfiles and explicit mounts provide workarounds, but neither delivers the requested automatic discovery and copying.

## Change summary

Copy a valid host-side core.excludesFile into the container alongside the automatically copied .gitconfig.

## Best solution

The Dev Containers extension should resolve the host's core.excludesFile and make its contents available at the corresponding container-side location when sharing .gitconfig. Retain this issue as the specific automatic-copy request; configurable default mounts are related but distinct work.
