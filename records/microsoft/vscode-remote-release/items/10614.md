# Issue #10614 — ENV cannot take effect

[https://github.com/microsoft/vscode-remote-release/issues/10614](https://github.com/microsoft/vscode-remote-release/issues/10614)

## Summary

The supplied log confirms that the SSH server environment contains `DISPLAY=:0`, but it does not establish whether VS Code ignores the terminal setting or the shell subsequently overwrites it. A current-version retest that compares local and remote fresh terminals is needed.

## Change summary

A Linux integrated terminal opened through Remote - SSH does not use the `DISPLAY` value configured in `terminal.integrated.env.linux`, although other configured variables work.

## Best solution

Determine where `DISPLAY` is overwritten using a fresh terminal and a shell without startup files. If the same behavior occurs in a local Linux window, a maintainer can transfer this to microsoft/vscode; if it is remote-only, the SSH component should correct its environment precedence.
