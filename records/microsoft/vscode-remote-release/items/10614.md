# Issue #10614 — ENV cannot take effect

[https://github.com/microsoft/vscode-remote-release/issues/10614](https://github.com/microsoft/vscode-remote-release/issues/10614)

## Summary

Keep open: the supplied setting, Bash check, and subsequent logs provide a concrete retest case for DISPLAY being ignored while another variable applies. The report predates current releases, but neither resolution nor a canonical owning this exact failure is established.

## Change summary

A configured terminal.integrated.env.linux DISPLAY value is not reflected in the remote Bash terminal, although another configured variable takes effect.

## Best solution

The SSH component owner should isolate whether DISPLAY is overwritten by remote environment contributions or shell startup, and ensure explicit terminal overrides work as intended. If the same failure reproduces without a remote connection, a maintainer can transfer this to microsoft/vscode for terminal ownership.
