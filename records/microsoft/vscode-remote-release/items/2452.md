# Issue #2452 — Allow external contributions to the core (code) of the remote development extensions.

[https://github.com/microsoft/vscode-remote-release/issues/2452](https://github.com/microsoft/vscode-remote-release/issues/2452)

## Summary

The remote extensions remain intentionally closed source, and a maintainer declined a later issue requesting the same external-contribution model. This is a valid request but outside the extension team's established contribution model.

## Change summary

Allow external developers to access, modify, test, and contribute to the core source of the Remote Development extensions.

## Best solution

Keep core extension development within the current closed-source model while accepting public contributions through the open Dev Container specification, CLI, images, features, and documentation repositories.

## Vision fit

- **Fit:** rejected
- **Reason:** The request conflicts with the established boundary between the closed-source Remote Development extensions and the deliberately open Dev Container ecosystem.
- **Evidence:** The public vision identifies the devcontainer.json specification, reference CLI, images, features, and templates—not the extension implementation—as the open contribution surfaces.
