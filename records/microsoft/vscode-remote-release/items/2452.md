# Issue #2452 — Allow external contributions to the core (code) of the remote development extensions.

[https://github.com/microsoft/vscode-remote-release/issues/2452](https://github.com/microsoft/vscode-remote-release/issues/2452)

## Summary

The team has already declined the same request to accept community contributions to the remote extensions' implementation, and the current FAQ retains that closed-source boundary. Propose an out-of-scope close based on that precedent, not inactivity.

## Change summary

Allow external developers to develop, test, and submit changes to the remote extensions' implementation.

## Best solution

Apply the established contribution boundary consistently: keep extension defects and feature requests in this tracker, with external code contributions available in the open Dev Container ecosystem rather than the closed-source extensions.
