# Issue #11707 — DevContainer Port Forwarding terminates prematurely

[https://github.com/microsoft/vscode-remote-release/issues/11707](https://github.com/microsoft/vscode-remote-release/issues/11707)

## Summary

Verified duplicate: the open canonical issue tracks the same Dev Containers port-forwarder truncation, including both chunked and Content-Length responses. This report adds a useful macOS/Podman/Lima reproduction and a specific stream-drain diagnosis.

## Change summary

Dev Containers port forwarding intermittently closes large chunked HTTP responses before their complete contents reach the host.

## Best solution

Consolidate investigation in https://github.com/microsoft/vscode-remote-release/issues/9969 and preserve this report's finding that the forwarding subprocess exits before stdout drains. Fixing the Dev Containers forwarding teardown there should cover both reported HTTP error variants.
