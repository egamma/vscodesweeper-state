# Issue #8328 — Dev container: `Attach Visual Studio Code` fails with `Workspace does not exist`

[https://github.com/microsoft/vscode-remote-release/issues/8328](https://github.com/microsoft/vscode-remote-release/issues/8328)

## Summary

Keep open: this team-authored bug has a reproducible stale-workspace failure and remains the canonical issue for the behavior. Later reports provide workarounds but no evidence that the underlying remembered-folder handling was fixed.

## Change summary

Attaching to a container fails when Dev Containers reopens a workspace remembered for the image but that workspace path does not exist in the new container.

## Best solution

Dev Containers should verify that the remembered workspace exists before reopening it and fall back to the container folder-selection flow when it does not.
