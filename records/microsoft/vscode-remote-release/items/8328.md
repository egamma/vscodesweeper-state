# Issue #8328 — Dev container: `Attach Visual Studio Code` fails with `Workspace does not exist`

[https://github.com/microsoft/vscode-remote-release/issues/8328](https://github.com/microsoft/vscode-remote-release/issues/8328)

## Summary

Keep open: this team-authored issue has a detailed smoke-test reproduction and the Dev Containers maintainer identified the stale remembered-workspace behavior. No verified duplicate or public fixing commit permits a factual close.

## Change summary

Attaching to a replacement container reopens a remembered workspace path that no longer exists, causing the connection to fail.

## Best solution

Dev Containers should verify that the remembered workspace exists in the target container before reopening it; when absent, attach without the stale path and let the user choose a valid folder.
