[https://github.com/microsoft/vscode-remote-release/issues/3567](https://github.com/microsoft/vscode-remote-release/issues/3567)

## Summary

The open Dev Container spec proposal now owns this exact cross-platform home-directory variable request, with an active CLI implementation PR. Consolidating there preserves this report's Git Bash case while keeping the specification work in its owning tracker.

## Change summary

Provide a platform-independent devcontainer.json variable that resolves to the local user's home directory.

## Best solution

Follow https://github.com/devcontainers/spec/issues/335 and review the proposed `${localHomeFolder}` implementation in https://github.com/devcontainers/cli/pull/1111. The Git Bash case and this issue's community support should be carried into that specification discussion.
