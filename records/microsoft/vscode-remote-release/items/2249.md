# Issue #2249 — Using forwardPorts gives no indication that a different port was used

[https://github.com/microsoft/vscode-remote-release/issues/2249](https://github.com/microsoft/vscode-remote-release/issues/2249)

## Summary

Opt-in collision notifications now exist through requireLocalPort, but this team-authored request cannot be closed from capability evidence alone. Keep it open for the author to assess whether opt-in notification satisfies the intended behavior for forwardPorts.

## Change summary

Notify users when an explicitly forwarded container port maps to a different local port because the requested port is occupied.

## Best solution

Use portsAttributes with requireLocalPort enabled for ports whose local number matters. The Dev Containers owner should confirm whether this opt-in behavior completes the request or whether explicitly listed forwardPorts need additional default collision feedback.
