# Issue #620 — Add Option to ignore certain folder

[https://github.com/microsoft/vscode-remote-release/issues/620](https://github.com/microsoft/vscode-remote-release/issues/620)

## Summary

The documented `mounts` property already provides the requested folder isolation by overlaying selected workspace directories with named volumes. A commenter confirmed this solution works, so a specialized ignore property is unnecessary.

## Change summary

Add a devcontainer.json property that prevents selected workspace folders such as node_modules from being bind-mounted into the container.

## Best solution

Keep the general-purpose `mounts` mechanism and configure a named volume for each container-only directory. This covers node_modules and analogous package or build directories without introducing a second mount-exclusion syntax.

- **Proposed comment:**

  > Thanks for the request. The supported way to keep a workspace subfolder container-only is now the `mounts` property, as documented at https://code.visualstudio.com/remote/advancedcontainers/improve-performance. For example, `"mounts": ["source=${localWorkspaceFolderBasename}-node_modules,target=${containerWorkspaceFolder}/node_modules,type=volume"]` overlays the host's node_modules with a container volume. The confirmation above shows this addresses the reported scenario, so a separate `workspaceFolderIgnore` property is not needed.
