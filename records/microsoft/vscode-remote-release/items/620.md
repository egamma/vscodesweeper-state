# Issue #620 — Add Option to ignore certain folder

[https://github.com/microsoft/vscode-remote-release/issues/620](https://github.com/microsoft/vscode-remote-release/issues/620)

## Summary

Keep open as a Dev Containers usability request: documented volume mounts address dependency isolation, but do not provide the requested folder-exclusion option. No verified open canonical owns that remaining capability.

## Change summary

Provide a simple workspace-mount exclusion list so host dependency folders do not override container-built dependencies.

## Best solution

The Dev Containers owner should evaluate a straightforward exclusion configuration with explicit image-content and rebuild semantics, coordinating any new shared devcontainer.json property with devcontainers/spec. Retain the documented mounts approach as the existing workaround, not as proof that the requested interface has shipped.
