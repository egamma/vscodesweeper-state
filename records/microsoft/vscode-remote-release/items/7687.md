# Issue #7687 — nss_wrapper support

[https://github.com/microsoft/vscode-remote-release/issues/7687](https://github.com/microsoft/vscode-remote-release/issues/7687)

## Summary

Dev Containers 0.300.0 changed user lookup to the NSS-aware `getent passwd`, which should cover nss_wrapper, but the tracker has no confirmation for this specific configuration. A current-release retest is needed before treating the request as resolved.

## Change summary

Support container users and groups supplied through nss_wrapper instead of requiring entries in `/etc/passwd`.

## Best solution

Dev Containers should resolve container identities through NSS rather than reading `/etc/passwd` directly. Confirm that the shipped `getent` lookup works when nss_wrapper's preload and passwd/group variables are present; otherwise the Containers owner should investigate where those variables are lost.
