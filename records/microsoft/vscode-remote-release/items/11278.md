# Issue #11278 — Extend the preconnect functionality

[https://github.com/microsoft/vscode-remote-release/issues/11278](https://github.com/microsoft/vscode-remote-release/issues/11278)

## Summary

This is a valid Remote - SSH feature request. The documented preconnect setting supports one global script or per-host script paths, but not arguments or host/user substitution, so the central scalability gap remains.

## Change summary

Allow remote.SSH.preconnect to pass configured arguments or resolved SSH host and user values to a reusable script.

## Best solution

The SSH component should extend remote.SSH.preconnect with backward-compatible argument and host/user substitution support, allowing one reusable script across many connection profiles.
