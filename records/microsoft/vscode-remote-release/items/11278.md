# Issue #11278 — Extend the preconnect functionality

[https://github.com/microsoft/vscode-remote-release/issues/11278](https://github.com/microsoft/vscode-remote-release/issues/11278)

## Summary

Keep open: documented preconnect support covers global and per-host scripts, but does not establish support for arguments or connection-user/host substitution. No verified open canonical was found for this extension request.

## Change summary

Allow one Remote - SSH preconnect script to receive configurable arguments and the selected connection's user and host.

## Best solution

The Remote - SSH component should support explicit preconnect arguments and documented connection-context substitution, allowing a reusable preparation script instead of hundreds of per-host/user wrappers while preserving script approval.
