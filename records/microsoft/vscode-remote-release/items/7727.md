[https://github.com/microsoft/vscode-remote-release/issues/7727](https://github.com/microsoft/vscode-remote-release/issues/7727)

## Summary

A real capability gap remains: current documentation exposes no integrated command for converting a dev container into a WSL distribution. Route this team-authored Backlog request to both Containers and WSL ownership.

## Change summary

Add an action that exports an existing dev container as a WSL distribution while preserving relevant container and dev-container metadata.

## Best solution

The Containers and WSL components should jointly provide an export/import workflow, potentially surfaced in the WSL Remote Explorer, that applies image environment, user, working-directory, and dev-container metadata without requiring Docker for registry-sourced images.
