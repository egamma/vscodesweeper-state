# Issue #11372 — "Show Login Terminal" Not Working on MacOS

[https://github.com/microsoft/vscode-remote-release/issues/11372](https://github.com/microsoft/vscode-remote-release/issues/11372)

## Summary

Keep open: the supplied device-authorization workflow and versions suffice to retest the non-copyable prompt despite Show Login Terminal being enabled. The reported prerelease builds are now old, but neither the thread nor the reviewed documentation establishes resolution.

## Change summary

Remote - SSH on macOS displays a device-authorization code in non-copyable prompt text instead of the requested login terminal.

## Best solution

The SSH component should test this authentication flow with remote.SSH.showLoginTerminal enabled and remote.SSH.useLocalServer disabled, then determine whether the documented terminal mode resolves it. If it persists, ensure the authorization instructions and code are accessible and copyable during login.
