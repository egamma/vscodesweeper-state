# Issue #6193 — Publish Remote - WSL extension to open-vsx

[https://github.com/microsoft/vscode-remote-release/issues/6193](https://github.com/microsoft/vscode-remote-release/issues/6193)

## Summary

Keep open as the existing WSL publishing and licensing request. The extension remains unavailable from Open VSX, and the team previously said this issue should track the required product and pipeline decision.

## Change summary

Publish the WSL extension to Open VSX and permit its use with VSCodium and other compatible VS Code distributions.

## Best solution

The WSL extension owners should decide whether to support non-Microsoft VS Code distributions; if supported, align the license and compatibility restrictions before adding Open VSX publishing to the release pipeline.

## Vision fit

- **Fit:** rejected
- **Reason:** Supporting VSCodium conflicts with the currently documented product boundary that Remote Development and the VS Code Server are intended for a licensed VS Code client.
- **Evidence:** The Remote Development FAQ states that the VS Code Server is managed by a VS Code client and is not intended or licensed for use by other clients: https://code.visualstudio.com/docs/remote/faq#_can-vs-code-server-be-installed-or-used-on-its-own
