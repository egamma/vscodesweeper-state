# Issue #4238 — If a devcontainer has a directory mapping VsCode uses the container's internal mapped directory as the identifier for the dev container instead of the project directory.

[https://github.com/microsoft/vscode-remote-release/issues/4238](https://github.com/microsoft/vscode-remote-release/issues/4238)

## Summary

This remains a valid Dev Containers bug: a maintainer reproduced the incorrect recent-history label, and a later user confirmed it still occurred in VS Code 1.68.0. The issue is already routed correctly and has no verified canonical replacement.

## Change summary

Dev containers opened from WSL-backed projects are identified in recent history by the mapped container workspace name rather than the host project directory name.

## Best solution

Dev Containers should preserve the host project directory as the recent-history identifier when `workspaceFolder` maps it to a common container path such as `/app`, including projects stored in WSL.
