Keep open: the maintainer reproduced the naming defect, and subsequent reports contradict the tentative fix. The supplied configuration and WSL-specific steps suffice for a current-version retest; no confirmed resolution exists.

## Change summary

Dev containers sharing an internal workspace directory such as /app appear indistinguishable in Open Recent instead of using their host project names.

## Best solution

Dev Containers should preserve distinguishable host-project labels in Open Recent when projects share a container workspace path. Retest the documented WSL and Open Folder in Container paths, coordinating with the related taskbar-label issue without assuming both surfaces have the same fix.
