# Issue #5818 — Remote ssh hangs indefinitely when trying to open a folder if the terminal is not wide enough

[https://github.com/microsoft/vscode-remote-release/issues/5818](https://github.com/microsoft/vscode-remote-release/issues/5818)

## Summary

Keep open: the reporter supplied a repeatable terminal-width-dependent hang and logs, and a maintainer identified newline handling in the SSH tunnel interactor as the defect. The issue is already correctly routed to SSH and remains the best canonical report.

## Change summary

Remote - SSH can hang while setting up a tunnel when terminal line wrapping inserts newlines into the success message.

## Best solution

The Remote - SSH tunnel interactor should recognize its success message regardless of terminal wrapping or inserted newlines, so connection progress does not depend on terminal width or visibility.
