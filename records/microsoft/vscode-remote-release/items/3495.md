# Issue #3495 — [Dev Containers] An option reopen the folder locally while container is being built

[https://github.com/microsoft/vscode-remote-release/issues/3495](https://github.com/microsoft/vscode-remote-release/issues/3495)

## Summary

Keep open: this team-authored Backlog request identifies a concrete Dev Containers workflow gap, and no canonical issue or documented mid-build escape action was found.

## Change summary

Allow users to cancel an in-progress dev-container build and immediately reopen the workspace locally.

## Best solution

Dev Containers should expose a cancellable build action that reopens the folder locally without waiting for resolution to finish. The component owner should coordinate with VS Code core on making resolver-extension commands available while the resolver runs, as identified in the thread.

- **Fit:** aligned
- **Reason:** A faster recovery path while iterating on container configuration advances the durable theme of deep, reliable Dev Container workflows.
