# Issue #3495 — [Dev Containers] An option reopen the folder locally while container is being built

[https://github.com/microsoft/vscode-remote-release/issues/3495](https://github.com/microsoft/vscode-remote-release/issues/3495)

## Summary

Keep open: the requested action is cancellation and local reopening during an active build, not reopening after connection or failure. Maintainers acknowledged the command-availability limitation; this team-authored request has neither a verified canonical nor qualifying fix evidence.

## Change summary

Allow cancelling an in-progress dev-container build and reopening the same folder locally to edit its Dockerfile.

## Best solution

The Dev Containers owner should verify whether local reopening is available during resolution and, if still missing, expose a cancel-and-reopen action throughout the build. Coordinate with VS Code core on resolver contribution timing if that remains the blocker.
