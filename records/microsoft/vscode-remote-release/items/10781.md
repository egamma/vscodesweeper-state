# Issue #10781 — [Feature Request] Support for SSH3

[https://github.com/microsoft/vscode-remote-release/issues/10781](https://github.com/microsoft/vscode-remote-release/issues/10781)

## Summary

Keep open as an SSH feature request: documented client selection and Remote Tunnels do not deliver SSH3 compatibility, and searches found no canonical issue. Supporting this experimental transport needs an explicit component-owner decision.

## Change summary

Add Remote - SSH support for SSH3's HTTP/3 transport, including URL-path endpoints and UDP forwarding.

## Best solution

The Remote - SSH owners should assess whether SSH3 compatibility belongs in the extension or a separate transport integration, accounting for server startup, forwarding, and protocol maturity. Keep this request as the product-side tracking item until that decision is made.
