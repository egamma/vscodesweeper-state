# Issue #10497 — [Remote-SSH Bug]: Race condition when parsing ssh.exe -V output on Windows

[https://github.com/microsoft/vscode-remote-release/issues/10497](https://github.com/microsoft/vscode-remote-release/issues/10497)

## Summary

Keep open: the log, timing-sensitive workarounds, and maintainer analysis identify an unresolved race that can leave Remote - SSH connections waiting indefinitely on Windows.

## Change summary

Remote - SSH can hang when the ssh.exe exit event is processed before its version output is delivered from stderr.

## Best solution

The SSH component should wait for child-process stdio to close before parsing the version output and must resolve the detection operation even when both output buffers are empty.
