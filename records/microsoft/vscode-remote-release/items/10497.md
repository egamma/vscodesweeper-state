# Issue #10497 — [Remote-SSH Bug]: Race condition when parsing ssh.exe -V output on Windows

[https://github.com/microsoft/vscode-remote-release/issues/10497](https://github.com/microsoft/vscode-remote-release/issues/10497)

## Summary

Keep open: the thread supplies a concrete version-probe hang, diagnostic logs, and a timing workaround sufficient for targeted retesting. The reporter says it resurfaced in October 2025 after script-path support changed; neither a confirmed fix nor a qualifying canonical was found.

## Change summary

Remote - SSH can hang indefinitely when ssh.exe exits before its version-output streams have finished delivering data.

## Best solution

The SSH component should finish collecting version output before classifying the executable and ensure every probe settles, including empty-output cases, while retaining a bounded timeout. Retest the reported event ordering rather than relying on a fixed sleep.
