# Issue #10697 — Support SSH IdentityAgent config for DevContainers

[https://github.com/microsoft/vscode-remote-release/issues/10697](https://github.com/microsoft/vscode-remote-release/issues/10697)

## Summary

This accepted Backlog feature request remains necessary: current Dev Containers documentation and the thread provide SSH_AUTH_SOCK-based workarounds, but no native support for resolving IdentityAgent from SSH configuration.

## Change summary

Forward the SSH agent configured through IdentityAgent into Dev Containers without requiring SSH_AUTH_SOCK to be exported for the VS Code process.

## Best solution

The Dev Containers component should resolve an applicable IdentityAgent socket from the host SSH configuration and forward it when SSH_AUTH_SOCK is unavailable, with defined behavior for host-specific entries.
