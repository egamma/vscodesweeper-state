# Issue #10697 — Support SSH IdentityAgent config for DevContainers

[https://github.com/microsoft/vscode-remote-release/issues/10697](https://github.com/microsoft/vscode-remote-release/issues/10697)

## Summary

Keep this accepted Dev Containers request open: exporting SSH_AUTH_SOCK enables forwarding, but does not deliver automatic discovery from IdentityAgent. The verified related reports do not own the same requested behavior.

## Change summary

Discover the SSH agent configured through a global IdentityAgent entry so Dev Containers can forward it without separate host environment configuration.

## Best solution

The Dev Containers owner should evaluate global IdentityAgent discovery, the narrower scope the reporter explicitly accepted. Define precedence relative to SSH_AUTH_SOCK and handling of host-specific entries without silently changing which agent is forwarded.
