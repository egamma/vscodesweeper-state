# Issue #11651 — Remote SSH keeps disconnecting

[https://github.com/microsoft/vscode-remote-release/issues/11651](https://github.com/microsoft/vscode-remote-release/issues/11651)

## Summary

Keep this team-authored report open: repeated disconnects leave reconnection stuck until the server is killed, but missing logs prevent identifying the cause. The linked resource-consumption report is relevant context, not a verified duplicate or confirmed fix.

## Change summary

Remote - SSH repeatedly disconnects and cannot reconnect until the remote VS Code Server process is manually killed.

## Best solution

The SSH owner should obtain disconnect/reconnect logs, the remote OS, and server-process resource and exit information to distinguish connection recovery failure from host termination or extension-host overload. Restore reliable reconnection without requiring manual server termination.
