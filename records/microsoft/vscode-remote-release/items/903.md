# Issue #903 — Git for Windows functionality breaks when repository is open in Remote WSL

[https://github.com/microsoft/vscode-remote-release/issues/903](https://github.com/microsoft/vscode-remote-release/issues/903)

## Summary

This was well confirmed historically, but the last relevant reproduction used obsolete VS Code, WSL, and Windows versions. A current retest is needed before the WSL component can determine whether the NTFS lock conflict remains.

## Change summary

Opening an NTFS-hosted repository through Remote - WSL prevents Windows Git clients from replacing Git lock and index files.

## Best solution

The WSL component should verify that its file watcher and Git integration do not retain handles that block Windows Git operations on repositories under `/mnt/*`; if the conflict is inherent to cross-platform repository access, document that limitation and the supported workflow.
