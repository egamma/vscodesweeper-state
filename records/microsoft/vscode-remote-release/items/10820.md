# Issue #10820 — Dev containers: option to run git locally

[https://github.com/microsoft/vscode-remote-release/issues/10820](https://github.com/microsoft/vscode-remote-release/issues/10820)

## Summary

Keep open: documented Git configuration copying and credential forwarding do not provide the requested host-side Git integration. The maintainer-linked conditional-config issue is related, but does not own the full local-execution request.

## Change summary

Allow VS Code's Git integration to execute locally while developing in a container, preserving host-specific conditional configuration and SSH setup.

## Best solution

The Dev Containers owner should assess an opt-in host-side Git integration for locally accessible workspaces, including host/container path mapping. Coordinate conditional-configuration handling with the related issue without treating configuration copying as equivalent to local Git execution.
