# Issue #11551 — Dev Containers: Automatically writing `portsAttributes` to `devcontainer.json` for temporary forwarded ports causes unintended repo changes

[https://github.com/microsoft/vscode-remote-release/issues/11551](https://github.com/microsoft/vscode-remote-release/issues/11551)

## Summary

Keep open for the containers owner: writing shared configuration when temporarily forwarding a port conflicts with the documented session-only workflow. The supplied steps and versions suffice to retest on newer builds; no confirmed fix or matching canonical was found.

## Change summary

Manually forwarding a temporary port can silently add portsAttributes entries to devcontainer.json, creating unintended repository changes.

## Best solution

The Dev Containers extension should keep temporary forwarding separate from shared configuration and require explicit persistence intent before editing devcontainer.json. Retest the supplied workflow and identify which action causes the attribute write before deciding whether a fix or clearer persistence UI is needed.
