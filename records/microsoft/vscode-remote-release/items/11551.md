# Issue #11551 — Dev Containers: Automatically writing `portsAttributes` to `devcontainer.json` for temporary forwarded ports causes unintended repo changes

[https://github.com/microsoft/vscode-remote-release/issues/11551](https://github.com/microsoft/vscode-remote-release/issues/11551)

## Summary

The reported implicit repository edit conflicts with the established explicit “Set Label and Update devcontainer.json” workflow, but the thread has no independent reproduction and does not identify the precise action that triggers the edit. A current-version retest with that interaction detail is needed.

## Change summary

Prevent an ordinary manual port forward from silently persisting user-specific port attributes into the shared devcontainer configuration.

## Best solution

The Dev Containers integration should keep ordinary manual forwards ephemeral and write `portsAttributes` only after an explicit configuration action. The containers owner should first confirm whether the reporter used the dedicated update action or whether forwarding alone modifies the file.
