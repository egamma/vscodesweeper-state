# Issue #7540 — `Rebuild Container` (without reopening) from outside of DevContainer

[https://github.com/microsoft/vscode-remote-release/issues/7540](https://github.com/microsoft/vscode-remote-release/issues/7540)

## Summary

This accepted Backlog request remains a real Dev Containers workflow gap: the CLI can build without opening a container, but the documented VS Code command still rebuilds the active container rather than exposing a build-only operation.

## Change summary

Add a VS Code command that builds a dev-container image without reopening or replacing the current development environment.

## Best solution

The Dev Containers extension should expose a build-only command backed by the existing `devcontainer build` path, usable from both local and remote windows without reloading the window or switching containers.

- **Reason:** A non-disruptive build workflow deepens Dev Containers integration and helps remote development feel as fluid as local development.
