# Issue #7540 — `Rebuild Container` (without reopening) from outside of DevContainer

[https://github.com/microsoft/vscode-remote-release/issues/7540](https://github.com/microsoft/vscode-remote-release/issues/7540)

## Summary

Keep this accepted Dev Containers request open: the documented CLI supports build-only iteration, but that workaround does not deliver the requested VS Code command without reopening. No verified canonical owns the same workflow.

## Change summary

Expose a build-only Dev Containers command that leaves the current window and container session intact until the user explicitly reopens.

## Best solution

The Dev Containers extension should expose build-only iteration from local, SSH, and existing container windows, leaving the active environment untouched on build failure. Reopening or replacing the container should remain a separate, explicit action after a successful build.
