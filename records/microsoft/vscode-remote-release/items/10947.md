[https://github.com/microsoft/vscode-remote-release/issues/10947](https://github.com/microsoft/vscode-remote-release/issues/10947)

## Summary

Verified duplicate: container attachment fails because Remote - SSH misidentifies the openSUSE glibc host as Alpine and downloads the wrong CLI binary. The older open issue tracks this exact exec-server failure and already includes the remote-container consequence.

## Change summary

Attaching Dev Containers over Remote - SSH fails on an openSUSE MicroOS Podman host because the exec server selects cli-alpine instead of cli-linux.

## Best solution

Consolidate on https://github.com/microsoft/vscode-remote-release/issues/10939 and correct Remote - SSH's glibc/musl platform detection so it selects cli-linux on this host; preserve this report's Podman container-attachment symptom as supporting evidence.
