# Issue #11483 — Search box for "Remote Explorer" entries

[https://github.com/microsoft/vscode-remote-release/issues/11483](https://github.com/microsoft/vscode-remote-release/issues/11483)

## Summary

The requested live filtering is already provided by VS Code's built-in tree Find control, which applies to the Remote Explorer SSH tree. Propose closing with instructions for opening it and enabling filtering.

## Change summary

Provide a search box that filters Remote Explorer SSH entries while typing, making hundreds of configured hosts easier to navigate.

## Best solution

Use the existing tree Find control in Remote Explorer with Filter enabled; no separate Remote - SSH search implementation is needed for the requested behavior.
