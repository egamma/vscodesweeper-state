# Issue #11483 — Search box for "Remote Explorer" entries

[https://github.com/microsoft/vscode-remote-release/issues/11483](https://github.com/microsoft/vscode-remote-release/issues/11483)

## Summary

The requested filtering capability already exists through VS Code's built-in list find command, which works in the focused Remote Explorer view.

## Change summary

Add a search box that filters a large list of Remote Explorer SSH targets while typing.

## Best solution

Use the existing list find command in the SSH Targets view. Any follow-up to make that command more discoverable belongs to the VS Code workbench's Remote Explorer surface in microsoft/vscode.

- **Proposed comment:**

  > Thanks for the request. This filtering capability is already available through VS Code's built-in list find: focus the SSH Targets list in Remote Explorer and press Ctrl+Alt+F on Windows/Linux or Cmd+Alt+F on macOS, then type to filter the entries. The same workflow was confirmed in https://github.com/microsoft/vscode/issues/317258, so closing this as designed.
