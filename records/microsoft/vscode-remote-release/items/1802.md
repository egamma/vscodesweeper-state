# Issue #1802 — Support VSCode Remote Server offline  package.

[https://github.com/microsoft/vscode-remote-release/issues/1802](https://github.com/microsoft/vscode-remote-release/issues/1802)

## Summary

Verified duplicate: the older open issue tracks complete offline installation, including downloadable server packages and air-gapped clients and hosts. The newer reports here reinforce that same remaining gap.

## Change summary

Provide a supported package and installation flow for using Remote SSH, containers, and WSL when both the client and remote environment are offline.

## Best solution

Consolidate the request on https://github.com/microsoft/vscode-remote-release/issues/1399 and provide a documented way to pre-stage the matching VS Code Server artifacts without either endpoint contacting the updater service.
