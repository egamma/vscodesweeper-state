[https://github.com/microsoft/vscode-remote-release/issues/10460](https://github.com/microsoft/vscode-remote-release/issues/10460)

## Summary

Verified cross-repository duplicate: the open devcontainers CLI issue tracks the same failure to honor a Dockerfile-specific dockerignore file and is the correct home for the generated-Dockerfile behavior.

## Change summary

Dev container builds should apply `<Dockerfile name>.dockerignore` when using a named Dockerfile.

## Best solution

Consolidate the defect in https://github.com/devcontainers/cli/issues/969 and update the Dev Containers CLI to copy the named Dockerfile's dockerignore file alongside its generated temporary Dockerfile.
