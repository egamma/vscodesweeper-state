# Issue #10460 — "name.Dockerfile.dockerignore" no longer applies to dev container build

[https://github.com/microsoft/vscode-remote-release/issues/10460](https://github.com/microsoft/vscode-remote-release/issues/10460)

## Summary

Keep open: the maintainer identified why Dockerfile-specific ignore rules are lost and accepted copying them alongside the generated Dockerfile. The supplied sample suffices to retest; later related reports indicate continued impact, but do not establish resolution or a current-version reproduction of this exact sample.

## Change summary

Dev Containers builds ignore dc.Dockerfile.dockerignore, allowing an excluded testfile into the image and causing the sample build to fail.

## Best solution

Preserve the original Dockerfile-specific ignore file when the Dev Containers CLI generates its temporary Dockerfile, including Docker's precedence over the context-root .dockerignore. Coordinate implementation with https://github.com/devcontainers/cli/issues/969 and retain this issue until the fix reaches the VS Code Dev Containers build path.
