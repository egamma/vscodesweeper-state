# Issue #9935 — Opening the host's browser automatically after Dev Container startup

[https://github.com/microsoft/vscode-remote-release/issues/9935](https://github.com/microsoft/vscode-remote-release/issues/9935)

## Summary

Keep open: automatic folder-open tasks work, but the thread establishes a remaining need for container-only startup actions with browser access and visible progress. Existing documentation and the verified related issues do not establish complete coverage or a matching canonical.

## Change summary

Allow container-only startup or post-attach commands to open the host browser without imposing automatic tasks on developers opening the repository locally.

## Best solution

The Dev Containers component should provide a connection-ready, container-scoped way to run startup actions with host-browser forwarding and appropriate progress visibility. Clarify whether postAttachCommand can supply that connection context or whether a container-specific task mechanism is needed.
