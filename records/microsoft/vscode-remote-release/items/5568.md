## Summary

Keep open as the team-authored canonical request for WSL server cleanup and restart controls. Current documentation exposes server removal for Remote-SSH but not WSL, and the narrower kill-server request remains open.

## Change summary

Add WSL commands to stop and uninstall the VS Code Server from a selected distribution.

## Best solution

The WSL extension should provide supported commands to stop the server for environment refreshes and remove its installation for cleanup, without requiring users to terminate the entire distribution or manually delete server files.
