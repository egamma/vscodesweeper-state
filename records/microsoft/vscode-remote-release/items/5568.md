## Summary

Keep this accepted, team-authored WSL lifecycle request open. Maintainers already consolidated the kill-server request here; current documentation does not establish an equivalent WSL uninstall command.

## Change summary

Add WSL commands to uninstall the VS Code Server and stop it so subsequent connections can refresh the environment.
