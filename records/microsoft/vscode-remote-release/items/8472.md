# Issue #8472 — [Remote-SSH Bug]: Containers no longer detected on Remote-SSH

[https://github.com/microsoft/vscode-remote-release/issues/8472](https://github.com/microsoft/vscode-remote-release/issues/8472)

## Summary

Keep open pending maintainer retesting: the thread identifies a RemoteCommand conflict, and the supplied steps and configuration suffice to reproduce the historical failure. Dev Containers subsequently changed to reuse Remote-SSH's connection, but that architectural change does not establish resolution of this report.

## Change summary

Attaching VS Code to a running container over an established SSH connection silently fails when the host's SSH configuration includes a tmux RemoteCommand.

## Best solution

The containers owner should retest attachment with the supplied tmux RemoteCommand and confirm whether connection reuse eliminates the conflicting SSH invocation. If it persists, preserve Remote-SSH's handling of RemoteCommand and surface attachment errors rather than silently returning.
