# Issue #6056 — Container reopened from Remote-SSH not stopping after closing the window

[https://github.com/microsoft/vscode-remote-release/issues/6056](https://github.com/microsoft/vscode-remote-release/issues/6056)

## Summary

This remains the oldest broad report for Dev Containers failing to honor shutdownAction over Remote-SSH. Recent matching reports confirm the defect persists, so this should remain open as the canonical issue.

## Change summary

Dev containers opened through Remote-SSH remain running after the VS Code window closes despite stopContainer or stopCompose shutdownAction settings.

## Best solution

The Dev Containers shutdown monitor should execute the configured Docker or Compose stop operation on the SSH host after the final nested session closes. The narrower reports https://github.com/microsoft/vscode-remote-release/issues/8818 and https://github.com/microsoft/vscode-remote-release/issues/8991 should be consolidated here, retaining their current logs.
