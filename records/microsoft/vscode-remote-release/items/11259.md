# Issue #11259 — ssh -T causes git to stuck - How do I prevent Remote VSCode from using ssh -T?

[https://github.com/microsoft/vscode-remote-release/issues/11259](https://github.com/microsoft/vscode-remote-release/issues/11259)

## Summary

This is a configuration/support question: the log shows PTY allocation explicitly disabled, which makes Remote - SSH add `-T`. The supported control already exists, while the linked equivalent hang was reproduced outside VS Code and closed as environment-specific.

## Change summary

Use Remote - SSH without the `ssh -T` behavior that causes Git operations to hang on a Windows SSH host.

## Best solution

Set `remote.SSH.permitPtyAllocation` to `true` in local User settings. If Git still hangs, investigate the Windows OpenSSH server and PowerShell profile because the equivalent behavior is reproducible independently of VS Code.
