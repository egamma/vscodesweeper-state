# Issue #3387 — Detect Input/Output error and give more information.

[https://github.com/microsoft/vscode-remote-release/issues/3387](https://github.com/microsoft/vscode-remote-release/issues/3387)

## Summary

Keep open: the underlying failure is upstream in WSL, but detecting its distinctive error and presenting the known recovery action remains a valid WSL-extension diagnostics improvement.

## Change summary

Detect WSL mount input/output failures during server startup and explain that restarting WSL may restore access.

## Best solution

The WSL extension should recognize this startup failure, verify whether the Windows-mounted extension path is inaccessible, and show targeted guidance to run `wsl --shutdown` rather than only reporting that the server closed unexpectedly.
