# Issue #5795 — Support docker-compose 3.9 profiles 

[https://github.com/microsoft/vscode-remote-release/issues/5795](https://github.com/microsoft/vscode-remote-release/issues/5795)

## Summary

Keep this accepted feature request open: documented service selection and Compose overrides do not fully deliver profile selection in Dev Containers. The newer build-failure report covers only part of this request, not a replacement canonical.

## Change summary

Support selecting Docker Compose profiles in devcontainer.json and correctly building and starting the selected profiled services.

## Best solution

The Dev Containers component should support consistent profile selection across configuration discovery, builds, and startup, coordinating any new devcontainer.json property with the Dev Container specification. Retain this broader request and link the narrower profiled-service build failure as related implementation work.
