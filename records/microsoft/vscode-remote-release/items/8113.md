# Issue #8113 — Missing visual info for docker context in Remote Explorer

[https://github.com/microsoft/vscode-remote-release/issues/8113](https://github.com/microsoft/vscode-remote-release/issues/8113)

## Summary

Keep open for Dev Containers to retest the supplied local → remote → local context-switching sequence. The report concerns a 2023 Insiders build, but neither current documentation nor the reviewed related issues establishes that the wrong-context behavior is resolved.

## Change summary

Opening the same container setup across local and remote Docker contexts appears to reuse the remote context after switching back locally, without sufficient context identification in Remote Explorer.

## Best solution

Dev Containers should distinguish Remote Explorer entries by their Docker host/context and reopen the intended container without confusing otherwise identical setups. Retest the supplied sequence before deciding whether context association, presentation, or both require correction.
