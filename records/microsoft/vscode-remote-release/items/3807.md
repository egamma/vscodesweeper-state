# Issue #3807 — Make Podman work without setting the executable name/path

[https://github.com/microsoft/vscode-remote-release/issues/3807](https://github.com/microsoft/vscode-remote-release/issues/3807)

## Summary

Keep open: current documentation still requires explicitly setting the Podman executable, which does not satisfy the request for automatic selection. The related Podman issues inspected do not own this same capability.

## Change summary

Automatically discover and use Podman without requiring a Docker symlink, compatibility package, or manually configured executable path.

## Best solution

The Dev Containers extension should discover Podman when Docker is unavailable while preserving explicit executable overrides. Define predictable selection behavior when both CLIs are installed, addressing the maintainer's stated concern.
