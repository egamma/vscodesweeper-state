# Issue #5207 — Automate the copy of ~/.ssh/config and ~/.ssh/*.pub from the host to the container

[https://github.com/microsoft/vscode-remote-release/issues/5207](https://github.com/microsoft/vscode-remote-release/issues/5207)

## Summary

A real Dev Containers capability gap remains for users with multiple SSH identities: current agent forwarding does not bring the host's alias and public-key metadata into the container. Existing mount, dotfiles, and default-feature workarounds do not provide the requested selective, automatic, per-user behavior.

## Change summary

Optionally copy the host's SSH config and public keys into each dev container so forwarded SSH agents select the correct identity without exposing private keys.

## Best solution

The Dev Containers extension should offer an opt-in user-scoped mechanism that synchronizes `~/.ssh/config` and matching public keys while leaving private keys on the host. It should account for per-container customization without requiring shared project configuration to contain developer-specific paths.
