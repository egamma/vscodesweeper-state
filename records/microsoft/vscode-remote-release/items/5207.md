# Issue #5207 — Automate the copy of ~/.ssh/config and ~/.ssh/*.pub from the host to the container

[https://github.com/microsoft/vscode-remote-release/issues/5207](https://github.com/microsoft/vscode-remote-release/issues/5207)

## Summary

Keep open: documented agent forwarding and configurable mounts do not deliver the requested optional copying of SSH configuration and public keys. Related issues cover different capabilities, and the private-key exposure concerns warrant a human-owned design decision.

## Change summary

Add optional host-to-container copying of ~/.ssh/config and public keys so SSH host aliases and multiple identities work without exposing private-key files.

## Best solution

The Dev Containers owner should design an opt-in configuration/public-key transfer mechanism with user-controlled precedence and preservation of container-owned configuration. Keep private-key files excluded and retain host-agent forwarding.
