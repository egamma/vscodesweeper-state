# Issue #9615 — Remote Extension requires Microsoft account

[https://github.com/microsoft/vscode-remote-release/issues/9615](https://github.com/microsoft/vscode-remote-release/issues/9615)

## Summary

Keep open for the Tunnels owner: maintainers explicitly said background account probing should not produce this sign-in notification. The supplied steps and versioned confirmations suffice to retest newer releases, but no current-release resolution is established.

## Change summary

Remote - Tunnels displays a persistent Microsoft sign-in badge for SSH-only users and users accessing tunnels exclusively through GitHub.

## Best solution

Make Remote - Tunnels probe authentication providers without creating unsolicited sign-in requests, preserving explicit authentication when connecting. Retest both SSH-only and GitHub-only workflows; disabling the extension does not solve the latter.
