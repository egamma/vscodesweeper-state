# Issue #9615 — Remote Extension requires Microsoft account

[https://github.com/microsoft/vscode-remote-release/issues/9615](https://github.com/microsoft/vscode-remote-release/issues/9615)

## Summary

Keep open: maintainers confirmed that account probing should not display this notification, and multiple users reproduced it across later releases. The existing tunnels routing is correct.

## Change summary

Remote - Tunnels displays a persistent Microsoft sign-in badge while probing accounts, including for users who do not use tunnels or use only GitHub authentication.

## Best solution

Remote - Tunnels should probe both authentication providers silently, using the authentication API's `silent: true` option, and show sign-in UI only after an explicit user action.
