# Issue #10173 — can't use dev container offline

[https://github.com/microsoft/vscode-remote-release/issues/10173](https://github.com/microsoft/vscode-remote-release/issues/10173)

## Summary

Keep open: this Backlog feature request has substantial support and remains the canonical Dev Containers issue for offline reuse of existing containers and images. Current public CLI behavior still includes registry inspection and pull fallbacks that can block disconnected workflows.

## Change summary

Allow Dev Containers to reconnect to existing containers and use locally available images and server artifacts without internet access.

## Best solution

The Containers owner should cache the required server/bootstrap artifacts and avoid registry access when an existing container or exact local image is usable. Any required change in the reference CLI should be coordinated in https://github.com/devcontainers/cli while retaining this issue for the extension's end-to-end offline experience.
