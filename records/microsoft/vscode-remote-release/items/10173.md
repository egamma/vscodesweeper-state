# Issue #10173 — can't use dev container offline

[https://github.com/microsoft/vscode-remote-release/issues/10173](https://github.com/microsoft/vscode-remote-release/issues/10173)

## Summary

Keep this accepted Dev Containers request open: offline reuse of local images and existing containers remains unsupported by the evidence reviewed. The older related issues cover server installation or control-manifest delays, not all the registry-dependent failures documented here.

## Change summary

Allow opening and reconnecting to prepared dev containers offline without mandatory registry lookups or repeated downloads.

## Best solution

Dev Containers should reuse available local images and compatible cached bootstrap/server assets when offline, reporting precisely which prerequisite is missing when reuse is impossible. Retain this issue for the product-side workflow and coordinate any CLI image-resolution changes with devcontainers/cli.
