# Issue #9149 — Can't start container on Raspberry Pi 5 - debian install steps

[https://github.com/microsoft/vscode-remote-release/issues/9149](https://github.com/microsoft/vscode-remote-release/issues/9149)

## Summary

The failure is caused by the universal image lacking an ARM64 manifest, not by the Dev Containers extension. The image remains x86-64-only and is owned by the public devcontainers/images project.

## Change summary

Provide an ARM64-compatible universal Dev Container image so the referenced configuration can run on Raspberry Pi 5.

## Best solution

Track ARM64 support or an ARM-compatible alternative in https://github.com/devcontainers/images; meanwhile, the container configuration can use a supported ARM64 base image or build a custom image as documented.
