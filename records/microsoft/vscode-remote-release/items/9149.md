# Issue #9149 — Can't start container on Raspberry Pi 5 - debian install steps

[https://github.com/microsoft/vscode-remote-release/issues/9149](https://github.com/microsoft/vscode-remote-release/issues/9149)

## Summary

Keep open as an upstream image-architecture limitation, not a Dev Containers extension bug. The log and maintainer responses establish that the selected universal image lacks ARM64 support; current image documentation still lists only x86-64.

## Change summary

Allow the CircuitPython dev container using the universal image to start on a Raspberry Pi 5 ARM64 host.

## Best solution

The image-support work belongs in https://github.com/devcontainers/images, where ARM64 availability must be addressed. An ARM64 Ubuntu base image with the required CircuitPython tooling is a practical alternative, but is not a drop-in replacement for universal.
