# Issue #11413 — Add setting to disable automatic SSH agent forwarding in Dev Containers

[https://github.com/microsoft/vscode-remote-release/issues/11413](https://github.com/microsoft/vscode-remote-release/issues/11413)

## Summary

Keep open for human review: this requests a security-sensitive control over host SSH-agent exposure, so the hard keep-open rule blocks a duplicate close. Existing documentation and related discussions do not establish a shipped setting that prevents forwarding.

## Change summary

Provide a configurable opt-out that prevents Dev Containers from exposing the host SSH-agent socket, rather than only clearing SSH_AUTH_SOCK.

## Best solution

The Dev Containers owner should provide a host-enforced forwarding opt-out, with an explicit decision on per-project configuration and host-policy precedence. Coordinate with the broader credential-sharing work in https://github.com/microsoft/vscode-remote-release/issues/9466 while preserving this report's socket-creation detail.
