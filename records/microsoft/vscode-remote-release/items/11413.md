# Issue #11413 — Add setting to disable automatic SSH agent forwarding in Dev Containers

[https://github.com/microsoft/vscode-remote-release/issues/11413](https://github.com/microsoft/vscode-remote-release/issues/11413)

## Summary

This security-sensitive request is substantially covered by the broader open credential-sharing issue, but it must remain open for human review rather than receive an automated duplicate close.

## Change summary

Add a Dev Containers setting that prevents the host SSH agent socket from being mounted or exposed inside a container.

## Best solution

The Dev Containers owner should implement an IDE-controlled opt-out for SSH-agent forwarding, preferably as part of the broader credential-isolation design tracked at https://github.com/microsoft/vscode-remote-release/issues/9466. The control must prevent socket exposure rather than merely clear SSH_AUTH_SOCK.
