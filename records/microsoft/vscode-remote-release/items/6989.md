# Issue #6989 — Enabling GPU

[https://github.com/microsoft/vscode-remote-release/issues/6989](https://github.com/microsoft/vscode-remote-release/issues/6989)

## Summary

The central request is now covered: Dev Containers supports optional GPU requirements and the `dev.containers.gpuAvailability` setting provides explicit control when detection is unreliable. The remaining Codespaces prebuild concern is Codespaces-specific and already has a GitHub Community discussion.

## Change summary

Allow a dev container to enable GPU access explicitly or opportunistically without maintaining separate GPU and CPU configurations.

## Best solution

Keep `hostRequirements.gpu` and `dev.containers.gpuAvailability` as the supported Dev Containers controls. GPU-aware Codespaces prebuild behavior belongs in https://github.com/orgs/community/discussions/41549 rather than this tracker.
