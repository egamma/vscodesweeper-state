# Issue #6989 — Enabling GPU

[https://github.com/microsoft/vscode-remote-release/issues/6989](https://github.com/microsoft/vscode-remote-release/issues/6989)

## Summary

A real GPU-control gap remains: the implemented optional GPU requirement relies on automatic detection, while the thread documents environments where that detection is unreliable. The issue is already correctly classified and routed to Dev Containers.

## Change summary

Allow users to explicitly control GPU enablement for a dev container instead of relying exclusively on host GPU detection or static Docker run arguments.

## Best solution

Dev Containers should provide a portable configuration-level GPU availability override, aligned with the Dev Container specification, and pass it through to the existing CLI GPU-selection behavior. Codespaces prebuild limitations should remain with GitHub's Codespaces feedback channel.
