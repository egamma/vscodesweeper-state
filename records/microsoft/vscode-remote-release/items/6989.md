# Issue #6989 — Enabling GPU

[https://github.com/microsoft/vscode-remote-release/issues/6989](https://github.com/microsoft/vscode-remote-release/issues/6989)

## Summary

Keep open for the maintainer-defined GPU override capability. Correctly formatted runArgs address the original failure, but neither that workaround nor detection-based hostRequirements.gpu establishes completion of the remaining request.

## Change summary

Allow explicit GPU enablement in Dev Containers without depending on automatic GPU detection.

## Best solution

The containers owner should deliver or document an explicit GPU availability override for the extension's launch path. Treat Codespaces GPU-machine and prebuild handling as related integration concerns, not evidence that the extension request is resolved.
