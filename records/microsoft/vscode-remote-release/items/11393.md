# Issue #11393 — simplify old linux remote fix

[https://github.com/microsoft/vscode-remote-release/issues/11393](https://github.com/microsoft/vscode-remote-release/issues/11393)

## Summary

The current older-Linux FAQ still requires users to assemble a sysroot, install patchelf, and configure three environment variables, so the documentation-simplification gap remains. Keep this as SSH documentation polish rather than closing it as an unsupported-environment request.

## Change summary

Provide a clearer, preferably one-step procedure for configuring the unsupported sysroot workaround on older Linux SSH hosts.

## Best solution

The Remote - SSH documentation owners should evaluate a maintained helper in https://github.com/microsoft/vscode-linux-build-agent and update the FAQ with an end-to-end procedure; an external gist should not become the documented path without review.
