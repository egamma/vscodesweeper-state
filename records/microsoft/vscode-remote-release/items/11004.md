# Issue #11004 — Debug console shows incorrect slashes in paths when using Windows but SSH to Ubuntu

[https://github.com/microsoft/vscode-remote-release/issues/11004](https://github.com/microsoft/vscode-remote-release/issues/11004)

## Summary

Keep open: the launch configuration and concrete path-conversion example provide a useful retest case, but no confirmation establishes resolution. An older, similar console-link issue was resolved before this report; that does not prove the Firefox scenario is fixed.

## Change summary

Debug Console converts Ubuntu source paths to Windows separators during Firefox debugging over SSH, causing source links to fail.

## Best solution

Retest the supplied Windows-to-Ubuntu Firefox configuration and determine whether path conversion occurs in the debug adapter or VS Code's console-link handling. If core link handling owns the defect, a maintainer can transfer this to microsoft/vscode; retain SSH ownership until that boundary is established.
