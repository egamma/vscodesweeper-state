# Issue #10432 — Reveal in file explorer (host) for a DevContainer solution

[https://github.com/microsoft/vscode-remote-release/issues/10432](https://github.com/microsoft/vscode-remote-release/issues/10432)

## Summary

Keep open: the request passed the community threshold with 41 upvotes and was accepted into the Backlog. A community extension provides a workaround, but the documented Dev Containers surface still lacks built-in host-folder reveal.

## Change summary

Add a Dev Containers command that maps a mounted container file to its host path and reveals it in the host operating system's file explorer.

## Best solution

The Dev Containers extension should expose Open Containing Folder for host-backed workspace files, translating bind-mount paths before invoking the local OS explorer and clearly handling files without a host equivalent.

- **Evidence:** The public product promise is to "Open any folder in a container, on a remote machine, or in WSL and take advantage of VS Code's full feature set."
