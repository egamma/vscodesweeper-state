# Issue #10432 — Reveal in file explorer (host) for a DevContainer solution

[https://github.com/microsoft/vscode-remote-release/issues/10432](https://github.com/microsoft/vscode-remote-release/issues/10432)

## Summary

Keep this accepted Dev Containers request open: the thread offers a third-party workaround, not evidence of built-in host-file reveal. No verified open canonical owns the same capability.

## Change summary

Provide a file context-menu action that reveals a container file's corresponding host location in the native file explorer.

## Best solution

The Dev Containers component should resolve host-accessible bind mounts and reveal the selected file in the host's native explorer, including Windows-accessible WSL paths. Define availability for files without a host-accessible counterpart; use the reported extension as implementation inspiration rather than grounds to retire the request.
