# Issue #11502 — Dotfiles broken with podman

[https://github.com/microsoft/vscode-remote-release/issues/11502](https://github.com/microsoft/vscode-remote-release/issues/11502)

## Summary

The log and `userEnvProbe` workaround suggest a Dev Containers environment-probing defect under Podman, but there is no independent reproduction or complete creation log. Current-version diagnostics are needed before the containers owner can isolate it.

## Change summary

Dotfiles installation fails in Podman-based dev containers unless `userEnvProbe` is changed from its default to `loginShell`.

## Best solution

The Dev Containers component should reproduce this with Podman and ensure output from the default `loginInteractiveShell` environment probe cannot corrupt the generated dotfiles installation command. A complete current creation log and minimal container configuration are needed to identify the offending probe output.
