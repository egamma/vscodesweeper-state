# Issue #11502 — Dotfiles broken with podman

## Summary

Keep open with the existing containers and podman routing: the steps and shell errors suffice for a retest, and changing userEnvProbe is a workaround rather than a confirmed fix. The report predates current releases, but no confirmation or verified canonical establishes resolution.

## Change summary

Dotfiles installation fails with shell command-not-found errors when Dev Containers uses Podman, unless userEnvProbe is changed to loginShell.

## Best solution

The Dev Containers owner should retest the documented Podman workflow and determine why the default environment probe causes dotfiles installation to fail. Preserve working installation without requiring users to disable interactive-shell probing; the workaround narrows the investigation but does not establish the root cause.
