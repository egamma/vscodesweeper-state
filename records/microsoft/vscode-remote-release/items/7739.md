# Issue #7739 — Conditional Docker files / docker compose files

[https://github.com/microsoft/vscode-remote-release/issues/7739](https://github.com/microsoft/vscode-remote-release/issues/7739)

## Summary

Keep this accepted Backlog request open. Multiple configurations now provide a manual alternative, but the documented surface still does not automatically select Docker Compose files according to whether the environment is local or Codespaces.

## Change summary

Allow one repository to select different Dockerfiles or Docker Compose configurations for local Dev Containers and GitHub Codespaces.

## Best solution

The containers component should support environment-aware selection among dev-container configurations or Compose overlays. If that requires new conditional devcontainer.json syntax, the format change should be coordinated through https://github.com/devcontainers/spec rather than implemented as an extension-only fork.
