# Issue #7739 — Conditional Docker files / docker compose files

[https://github.com/microsoft/vscode-remote-release/issues/7739](https://github.com/microsoft/vscode-remote-release/issues/7739)

## Summary

Keep open: multiple dev-container configurations now support manually choosing different Compose setups, but do not cover automatic environment-dependent selection. The verified related issues do not own this re-reviewed item's full request.

## Change summary

Select different Dockerfiles or Docker Compose files automatically depending on whether development runs locally or in GitHub Codespaces.

## Best solution

The Dev Containers component should address environment-dependent configuration selection, coordinating any format change with the Dev Container specification. Separate local and Codespaces configurations are an available workaround, not a replacement for conditional selection.
