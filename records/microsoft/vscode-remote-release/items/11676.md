# Issue #11676 — [Remote-SSH Bug]: askpass/local server socket path too long on macOS causes listen EINVAL and publickey failure

[https://github.com/microsoft/vscode-remote-release/issues/11676](https://github.com/microsoft/vscode-remote-release/issues/11676)

## Summary

Verified duplicate: the older open canonical tracks the same macOS askpass socket path overflow and EINVAL regression, including the broader local-server failure without passphrase authentication.

## Change summary

Remote - SSH cannot authenticate with passphrase-protected keys when its askpass Unix socket path exceeds macOS limits.

## Best solution

Consolidate the socket-path regression in https://github.com/microsoft/vscode-remote-release/issues/11672; its fix should ensure all Remote - SSH local IPC paths stay within macOS Unix-socket limits.
