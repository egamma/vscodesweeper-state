# Issue #4584 — Allow Loading Attached Container Configs from the Current Project Repository

[https://github.com/microsoft/vscode-remote-release/issues/4584](https://github.com/microsoft/vscode-remote-release/issues/4584)

## Summary

A real capability gap remains: attached-container configurations are still stored locally by image or container name and cannot be loaded from a team repository. The request is already correctly routed to the containers backlog.

## Change summary

Allow repository-owned attached-container configuration to be shared by a team and reapplied when attaching to an externally managed running container.

## Best solution

The Dev Containers extension should support an explicit repository-scoped attached-container configuration, with defined precedence over local image/name configurations and a policy for reapplying updates on attach.

- **Reason:** Shareable configuration for externally managed containers advances dev-container capability depth and makes remote environments behave consistently across a team.
