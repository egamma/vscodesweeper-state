# Issue #4584 — Allow Loading Attached Container Configs from the Current Project Repository

[https://github.com/microsoft/vscode-remote-release/issues/4584](https://github.com/microsoft/vscode-remote-release/issues/4584)

## Summary

Keep open: documented attached-container configurations remain local rather than automatically loaded from the project repository. The maintainer explicitly requested this separate feature request; the related configuration-editing issue does not own the same work.

## Change summary

Allow repository-local attached-container configurations to be shared across a team, with an option to reapply updated settings on each attachment.

## Best solution

The Dev Containers extension should support discovering repository-local configurations when attaching to externally managed containers, with defined precedence over user-local configurations and explicit control over reapplying settings.
