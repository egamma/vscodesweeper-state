[https://github.com/microsoft/vscode-remote-release/issues/4584](https://github.com/microsoft/vscode-remote-release/issues/4584)

Verified duplicate: the older open issue https://github.com/microsoft/vscode-remote-release/issues/1785 already tracks project-versioned configuration for attaching to externally managed containers.

## Change summary

## Best solution

Consolidate on https://github.com/microsoft/vscode-remote-release/issues/1785 and add support in Dev Containers for a repository-managed attach configuration associated with an existing container.
