# Issue #11984 — Dev Containers: postStartCommand never runs when several windows reconnect to a stopped compose container at once

[https://github.com/microsoft/vscode-remote-release/issues/11984](https://github.com/microsoft/vscode-remote-release/issues/11984)

## Summary

Keep open for the Dev Containers owner: the report provides sufficient versions, reproduction steps, and contrasting logs to investigate concurrent reconnects skipping postStartCommand. This is a fresh report with no subsequent fix or independent reproduction established.

## Change summary

Simultaneous window reconnects to a stopped Compose container reportedly skip postStartCommand, while reconnecting a single window runs it.

## Best solution

The Dev Containers extension should reliably complete the post-start lifecycle when multiple windows reconnect concurrently, without leaving configuration pending. Investigate the reported omission of run-user-commands during simultaneous server startup; treat rebuild behavior as unconfirmed rather than part of the established reproduction.
