# Issue #11544 — Please allow to disable tab completion in devkit/copilot

[https://github.com/microsoft/vscode-remote-release/issues/11544](https://github.com/microsoft/vscode-remote-release/issues/11544)

## Summary

Copilot inline suggestions are editor-wide behavior, not part of the Remote Development extensions. The requested ability to disable them already exists through the Copilot menu or the `github.copilot.enable` setting.

## Change summary

Allow users to disable Copilot suggestions accepted with Tab or bind acceptance to another key.

## Best solution

Use the existing Copilot inline-suggestion controls documented at https://code.visualstudio.com/docs/editing/ai-powered-suggestions; any remaining editor or Copilot keybinding request belongs in https://github.com/microsoft/vscode/issues.
