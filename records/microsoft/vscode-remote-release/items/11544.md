- **Proposed comment:**

  > Thanks for the report. You can disable Copilot inline suggestions from the Copilot menu in the Status Bar, or set `"github.copilot.enable": { "*": false }`. Next edit suggestions have a separate setting: `"github.copilot.nextEditSuggestions.enabled": false`.
  > 
  > If you prefer to keep suggestions, open Keyboard Shortcuts and remove the Tab bindings for suggestion acceptance, then assign another shortcut. These controls are documented at https://code.visualstudio.com/docs/editing/ai-powered-suggestions and https://code.visualstudio.com/docs/configure/keybindings.
