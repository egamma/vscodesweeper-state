# Issue #61 — PuTTY Pageant

[https://github.com/microsoft/vscode-remote-release/issues/61](https://github.com/microsoft/vscode-remote-release/issues/61)

## Summary

Pageant is now supported through its native Windows OpenSSH integration, while Remote - SSH intentionally delegates authentication to the configured SSH client. Multiple users confirmed this works with current Pageant versions, so no Pageant-specific extension integration is needed.

## Change summary

Allow Remote - SSH on Windows to authenticate using private keys loaded in PuTTY Pageant.

## Best solution

Keep Remote - SSH client-agnostic and use Pageant's supported Windows OpenSSH bridge; documenting the Pageant setup in the Remote - SSH troubleshooting guide would improve discoverability.
