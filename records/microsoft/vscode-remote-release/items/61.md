# Issue #61 — PuTTY Pageant

[https://github.com/microsoft/vscode-remote-release/issues/61](https://github.com/microsoft/vscode-remote-release/issues/61)

## Summary

Configured Pageant authentication already works through Windows OpenSSH, but the thread explicitly requests extension-level discovery without manual bridging configuration. Keep this SSH feature request open for that remaining integration decision; no verified canonical owns it.

## Change summary

Provide convenient Remote - SSH integration with keys held in PuTTY Pageant instead of requiring separate private-key files or manual agent configuration.

## Best solution

The Remote - SSH owner should evaluate an opt-in Pageant integration that handles agent discovery within the extension's existing OpenSSH connection path. Document the supported Pageant configuration meanwhile, without treating it as delivery of the requested out-of-the-box integration.

A maintainer explains at https://github.com/microsoft/vscode-remote-release/issues/4702#issuecomment-802978527 that the extension runs ssh and inherits its configured authentication; that related issue's KeeAgent configuration resolution does not implement automatic PuTTY Pageant integration.
