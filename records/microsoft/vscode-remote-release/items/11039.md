# Issue #11039 — Problems with the vscode plugin remotessh connecting to a remote server

[https://github.com/microsoft/vscode-remote-release/issues/11039](https://github.com/microsoft/vscode-remote-release/issues/11039)

## Summary

Maintainers have already declined maintaining legacy server builds for pre-glibc 2.28 systems, while the documentation provides an unsupported sysroot workaround. This request is therefore out of scope rather than an unresolved Remote-SSH defect.

## Change summary

Provide an officially maintained VS Code Server compatible with remote hosts using glibc 2.17.

## Best solution

Keep the documented glibc 2.28 server baseline; users who cannot upgrade can provide a compatible sysroot using the documented workaround.
