# Issue #8012 — [Remote-SSH Bug]: vscode does not parse the argument correctly in converting the 'ssh -R' command to 'RemoteForward' specification in ssh_config

[https://github.com/microsoft/vscode-remote-release/issues/8012](https://github.com/microsoft/vscode-remote-release/issues/8012)

## Summary

Keep open: a maintainer confirmed the Remote - SSH host-command parser emits invalid `RemoteForward` syntax and identified the required correction. No canonical issue, shipped fix, or current capability supersedes this accepted Backlog bug.

## Change summary

Convert an SSH `-R` forwarding argument into the two-argument `RemoteForward` form required by `ssh_config`.

## Best solution

The Remote - SSH component should serialize `ssh -R 123:localhost:456` as `RemoteForward 123 localhost:456` when adding a host, while preserving the supported bind-address and socket forms.
