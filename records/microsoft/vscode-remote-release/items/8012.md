# Issue #8012 — [Remote-SSH Bug]: vscode does not parse the argument correctly in converting the 'ssh -R' command to 'RemoteForward' specification in ssh_config

[https://github.com/microsoft/vscode-remote-release/issues/8012](https://github.com/microsoft/vscode-remote-release/issues/8012)

## Summary

Keep open: the report provides sufficient steps to retest incorrect RemoteForward generation, and the thread explicitly accepts the parsing fix. No current-release reproduction, confirmed resolution, or matching canonical was found.

## Change summary

Remote-SSH's Add New SSH Host command converts a valid -R argument into invalid ssh_config syntax.

## Best solution

The Remote-SSH owner should retest the supplied command and ensure host creation writes RemoteForward 123 localhost:456 rather than preserving the command-line colon separators. Manually correcting the configuration unblocks connections but does not fix host generation.
