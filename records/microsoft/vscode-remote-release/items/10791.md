# Issue #10791 — X applications can not start in devcontainer under Xwayland because of missing X authentication

[https://github.com/microsoft/vscode-remote-release/issues/10791](https://github.com/microsoft/vscode-remote-release/issues/10791)

## Summary

A real Dev Containers capability gap remains: built-in X11 forwarding passes DISPLAY but does not securely provide Xwayland authentication. The available per-project workarounds do not satisfy the request for automatic handling.

## Change summary

Securely forward the host's changing Xauthority credentials so X applications work in dev containers under Wayland/Xwayland.

## Best solution

The Dev Containers extension should securely propagate the active Xwayland authorization data alongside its existing DISPLAY forwarding, without requiring an insecure xhost rule or project-specific scripts.
