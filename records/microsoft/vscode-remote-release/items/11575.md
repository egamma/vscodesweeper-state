[https://github.com/microsoft/vscode-remote-release/issues/11575](https://github.com/microsoft/vscode-remote-release/issues/11575)

## Summary

The intended Podman configuration already works, but the failure message and documentation do not explain that `dockerComposePath` accepts only an executable. Keep this as a focused Dev Containers diagnosability polish item.

## Change summary

Improve the error and documentation when `dev.containers.dockerComposePath` contains a command plus arguments such as `podman compose`.

## Best solution

Dev Containers should detect a multi-token `dockerComposePath`, explain that it expects one executable, and recommend `dev.containers.dockerPath: "podman"` for Podman's Compose subcommand.
