# Issue #11575 — VSCode Devcontainers broke unexpectedly (probably because of unexpected extension update)

[https://github.com/microsoft/vscode-remote-release/issues/11575](https://github.com/microsoft/vscode-remote-release/issues/11575)

## Summary

Keep open for clearer Compose configuration guidance: the maintainer explains the intended executable-path restriction, but that does not satisfy the reporter's explicit request for an actionable error message. The suspected regression remains unconfirmed.

## Change summary

Explain which Compose setting to correct when a command containing a subcommand is rejected, or restore support for that configuration.

## Best solution

Dev Containers should identify dev.containers.dockerComposePath in the failure message and explain that it expects an executable without arguments. For Podman, point users toward dev.containers.dockerPath = "podman" with the Compose override unset, preserving the intended command-selection behavior.
