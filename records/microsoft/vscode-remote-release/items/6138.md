# Issue #6138 — Add inline action to delete 'Attached Container' config files

[https://github.com/microsoft/vscode-remote-release/issues/6138](https://github.com/microsoft/vscode-remote-release/issues/6138)

## Summary

The Dev Containers UI still lacks the requested deletion action. Current documentation only offers opening or editing attached-container configuration files, so manual file deletion does not satisfy the central cleanup request.

## Change summary

Add an inline action for deleting obsolete image-level or named attached-container configuration files.

## Best solution

Dev Containers should provide a delete action in the attached-container configuration picker that removes the selected local configuration file. The existing manual path-copying workaround can remain available but should not be the only cleanup mechanism.
