# Issue #6138 — Add inline action to delete 'Attached Container' config files

[https://github.com/microsoft/vscode-remote-release/issues/6138](https://github.com/microsoft/vscode-remote-release/issues/6138)

## Summary

Keep open: the thread narrowed the request to deleting saved attached-container configurations from the picker, an improvement a maintainer explicitly supported. Current documentation covers opening and editing configurations, but does not establish that inline deletion has shipped.

## Change summary

Add a delete action beside each saved configuration in the attached-container configuration picker.

## Best solution

The Dev Containers extension should let users remove obsolete image-level and named-container configurations directly from the picker, without locating and deleting their files manually.
