# Issue #141 — Enable custom shell initialization script on the remote

[https://github.com/microsoft/vscode-remote-release/issues/141](https://github.com/microsoft/vscode-remote-release/issues/141)

## Summary

Remote - SSH now supports this workflow through SSH RemoteCommand, including sourcing an environment script before server startup. The shipped opt-in mechanism covers the central request without executing workspace-controlled scripts automatically.

## Change summary

Allow a remote initialization script to configure project-specific tools and environment variables before installing or launching the VS Code Server.

## Best solution

Use `remote.SSH.enableRemoteCommand` with `remote.SSH.useLocalServer` and a non-terminating SSH `RemoteCommand` that sources the desired script before starting a shell. Separate SSH host aliases can select different environments for concurrent projects.
