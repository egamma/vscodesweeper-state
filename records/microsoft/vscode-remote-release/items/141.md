# Issue #141 — Enable custom shell initialization script on the remote

[https://github.com/microsoft/vscode-remote-release/issues/141](https://github.com/microsoft/vscode-remote-release/issues/141)

## Summary

Keep this accepted SSH feature request open: existing workarounds do not establish complete coverage of remote-only initialization before installation and server startup. The closest open requests are narrower, so this remains a useful tracking issue.

## Change summary

Allow a remote-only shell initialization script to prepare tooling and environment variables before Remote - SSH installs and starts the server, without modifying ordinary shell initialization.

## Best solution

Remote - SSH should provide an explicitly opted-in initialization hook before installation and server startup, with its environment inherited by remote tooling. Define how different project environments coexist on one host and how the hook applies to exec-server bootstrapping.
