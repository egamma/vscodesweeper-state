## Summary

Keep open as upstream: the thread reports Windows executable-launch failures beyond VS Code, and a maintainer confirms the WSL extension cannot work around them. Disabling administrator mode helps some users but does not establish a general fix.

## Change summary

Launching VS Code with `code .` from WSL fails with `Code.exe: Invalid argument`, while opening VS Code directly and connecting to WSL works.
