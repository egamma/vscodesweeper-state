# Issue #7050 — `Code.exe: Invalid argument` after upgrading to Windows 11

[https://github.com/microsoft/vscode-remote-release/issues/7050](https://github.com/microsoft/vscode-remote-release/issues/7050)

## Summary

This is a recurring WSL Windows-binary interop failure rather than a Remote - WSL defect. The existing `wsl` and `upstream` labels correctly identify its ownership, and upstream issues must remain open.

## Change summary

Launching `Code.exe` from WSL intermittently fails with `Invalid argument`, while other Windows executables fail similarly until WSL is restarted.

## Best solution

The WSL platform should fix the underlying Windows-binary interop failure; Remote - WSL should not special-case `Code.exe`. Keep this report as the aggregate tracker's pointer to the upstream problem and its workarounds.
