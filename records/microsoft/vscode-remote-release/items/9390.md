# Issue #9390 — Avoid `echo -n` on macOS

[https://github.com/microsoft/vscode-remote-release/issues/9390](https://github.com/microsoft/vscode-remote-release/issues/9390)

## Summary

Fixed and shipped: Dev Containers now reads the home folder through a separate non-PTY shell on macOS, avoiding the stray `-n` output that corrupted the path.

## Change summary

Dev Containers misreads the remote macOS home directory because its shell invocation appends `-n` to `echo ~`.

## Best solution

Keep the shipped macOS-specific home-folder lookup from Dev Containers 0.338.1; it directly prevents the malformed path shown in this report.
