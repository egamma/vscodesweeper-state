# Issue #5437 — bug: devcontainerCLI doesn't respect docker.host setting for remote ssh docker daemon

[https://github.com/microsoft/vscode-remote-release/issues/5437](https://github.com/microsoft/vscode-remote-release/issues/5437)

## Summary

Keep open: the supplied steps and paired logs suffice to retest the CLI-versus-command-palette Docker host mismatch. Docker configuration settings have evolved since 2021, but there is no verified fix or qualifying canonical for this report.

## Change summary

The extension-provided devcontainer open command selects a different Docker daemon than Reopen in Container when docker.host specifies an SSH endpoint.

## Best solution

The containers component should retest the extension-provided open command against Reopen in Container with the same configured remote Docker endpoint and make endpoint selection consistent. Keep this product-integration issue here rather than assuming the standalone reference CLI owns VS Code settings propagation.
