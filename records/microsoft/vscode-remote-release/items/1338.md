# Issue #1338 — Support Termux on Android/aarch64

[https://github.com/microsoft/vscode-remote-release/issues/1338](https://github.com/microsoft/vscode-remote-release/issues/1338)

## Summary

Termux remains outside the documented Remote - SSH host matrix, and a 2026 confirmation shows that direct support is still missing. A community glibc workaround does not satisfy the request for supported Android/Termux operation.

## Change summary

Provide official Remote - SSH and VS Code Server support for Android/aarch64 hosts running Termux.

## Best solution

The SSH and VS Code Server owners should decide whether to support Android's Termux environment and, if accepted, provide a compatible server runtime and documented prerequisites rather than requiring manual linker, shebang, and LD_PRELOAD workarounds.

## Evidence

- **documented requirements:** https://code.visualstudio.com/docs/remote/linux documents supported glibc-based Linux distributions and server prerequisites; it does not list Android or Termux, which uses Android's runtime rather than the expected glibc environment.
- **canonical ownership:** A maintainer closed https://github.com/microsoft/vscode-remote-release/issues/3769 in favor of this issue, explicitly identifying https://github.com/microsoft/vscode-remote-release/issues/1338 as the outstanding Termux support request.
- **current gap:** https://github.com/microsoft/vscode-remote-release/issues/1338#issuecomment-3788527191 reports in January 2026 that SSH itself works but VS Code still cannot run on the Termux host.
- **community workaround:** https://github.com/microsoft/vscode-remote-release/issues/1338#issuecomment-3913137285 confirms operation on several Android versions only after installing glibc, configuring three custom-glibc environment variables, and handling additional shebang and LD_PRELOAD caveats.
