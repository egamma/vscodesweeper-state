# Issue #11005 — dev.containers.executeInWSL causes containers to run dev containers even on local windows

[https://github.com/microsoft/vscode-remote-release/issues/11005](https://github.com/microsoft/vscode-remote-release/issues/11005)

## Summary

Keep open: a maintainer acknowledged that initialization is triggered prematurely, and the reporter reproduced it again two months later. The issue is already routed to Dev Containers, and no canonical issue owns this specific behavior.

## Change summary

Enabling dev.containers.executeInWSL triggers Dev Containers initialization for ordinary local Windows workspaces without user action.

## Best solution

The Dev Containers extension should avoid early initialization in local Windows windows unless a container operation requires it, while preserving execute-in-WSL behavior when explicitly used.
