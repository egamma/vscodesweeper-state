# Issue #10307 — GPU detection: Not only check for runtime, but also number of GPUs

[https://github.com/microsoft/vscode-remote-release/issues/10307](https://github.com/microsoft/vscode-remote-release/issues/10307)

## Summary

Keep this accepted, team-authored Dev Containers bug open: automatic detection can mistake an installed NVIDIA runtime for an attached GPU. GPU Availability overrides shipped, but this report explicitly identifies the remaining detection defect; its GPU-removal steps suffice for a current-release retest.

## Change summary

Optional GPU detection adds --gpus all when the NVIDIA runtime remains installed but no GPU is attached, preventing container startup.

## Best solution

Dev Containers should distinguish NVIDIA runtime availability from usable GPUs on the Docker host and omit GPU flags when optional GPU support is unavailable. Retest the supplied GPU-removal scenario; a manual availability override does not resolve the automatic-detection gap.
