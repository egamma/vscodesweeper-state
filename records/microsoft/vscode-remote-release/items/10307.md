# Issue #10307 — GPU detection: Not only check for runtime, but also number of GPUs

[https://github.com/microsoft/vscode-remote-release/issues/10307](https://github.com/microsoft/vscode-remote-release/issues/10307)

## Summary

Keep open: this team-authored issue records a confirmed false-positive in automatic GPU detection when the NVIDIA runtime remains installed but no GPU is attached. The existing GPU Availability override is a workaround, not a fix for automatic detection.

## Change summary

Dev Containers should not add `--gpus all` for an optional GPU requirement unless the host has an available GPU, rather than checking only for the NVIDIA runtime.

## Best solution

The containers component should verify that at least one usable GPU is present before adding Docker GPU arguments, while retaining the machine-scoped GPU Availability override for environments where detection is unreliable.
