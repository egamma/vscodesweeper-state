# Issue #6160 — Support ${localWorkspaceFolder} when cloning in volume

[https://github.com/microsoft/vscode-remote-release/issues/6160](https://github.com/microsoft/vscode-remote-release/issues/6160)

## Summary

Keep open as a Dev Containers capability request: one configuration should support workspace-relative mounts with both local checkouts and clone-in-volume workspaces. The documented alternatives do not provide that parity, and the maintainer discussion leaves extension-side design unresolved.

## Change summary

Support workspace-relative mounts without separate configurations for local-folder and clone-in-volume development.

## Best solution

The Dev Containers component should define a volume-aware workspace reference or equivalent mount abstraction that works across both storage modes, including CI cache mounts. Docker volume-subpath support is a prerequisite, not proof that the extension implements this behavior.
