# Issue #7473 — Bootstrap Code Server Directly from Internet in Dev Containers over SSH

[https://github.com/microsoft/vscode-remote-release/issues/7473](https://github.com/microsoft/vscode-remote-release/issues/7473)

## Summary

The documented Dev Containers behavior still always downloads the VS Code Server locally and transfers it into the container, so the requested remote-host download path remains a real gap. This Backlog item is correctly routed and has become the broader canonical for slow-link reports.

## Change summary

Allow Dev Containers over SSH to download or preinstall the matching VS Code Server from the remote host instead of transferring it over the client connection.

## Best solution

Dev Containers should support a remote-host server download mode or fallback while retaining commit compatibility and local transfer when remote download is unavailable. The narrower failure fallback tracked by https://github.com/microsoft/vscode-remote-release/issues/9414 can be addressed as part of this broader capability.
