# Issue #95 — Remote - Containers Add support for Docker Toolbox

[https://github.com/microsoft/vscode-remote-release/issues/95](https://github.com/microsoft/vscode-remote-release/issues/95)

## Summary

Docker Toolbox remains explicitly unsupported and has since been deprecated by Docker, making support for it no longer a viable Dev Containers investment.

## Change summary

Add Docker Toolbox support by translating Windows bind-mount paths for its VirtualBox-hosted Docker daemon.

## Best solution

Keep Dev Containers focused on supported container environments. Windows users should use Docker Desktop with its WSL 2 backend, Docker installed in WSL, or a documented remote Docker host.

## Vision fit

- **Fit:** rejected
- **Reason:** Supporting an abandoned runtime outside the documented environment matrix conflicts with the project's pragmatic support guardrail.
- **Evidence:** The vision identifies environments outside documented requirements as scope decisions rather than defects, while the current Dev Containers requirements explicitly exclude Docker Toolbox.

Supported Windows alternatives now include Docker Desktop with the WSL 2 backend or Docker installed in WSL, as documented at https://code.visualstudio.com/docs/devcontainers/containers#_system-requirements and https://code.visualstudio.com/remote/advancedcontainers/docker-options.
