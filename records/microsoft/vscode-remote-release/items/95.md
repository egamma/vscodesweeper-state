# Issue #95 — Remote - Containers Add support for Docker Toolbox

[https://github.com/microsoft/vscode-remote-release/issues/95](https://github.com/microsoft/vscode-remote-release/issues/95)

## Summary

Docker Toolbox remains explicitly unsupported by Dev Containers and has since been retired by Docker. Supported Windows Home and remote-host workflows now cover the original constraints without adding compatibility for the obsolete runtime.

## Change summary

Add Docker Toolbox path and mount handling so Dev Containers can run Linux containers through its VirtualBox VM on Windows.

## Best solution

Keep Dev Containers focused on maintained container runtimes. Windows Home users should use Docker Desktop with its WSL 2 backend, while users operating a separate Docker host can use the documented remote-host workflow.

- **Fit:** rejected
- **Reason:** Supporting an unmaintained runtime outside the documented environment matrix conflicts with the project's guardrail of broad support with pragmatic limits.
- **Evidence:** The Dev Containers system requirements explicitly state that Docker Toolbox is unsupported, while the vision identifies documented runtime requirements as the boundary for environment support.
