# Issue #95 — Remote - Containers Add support for Docker Toolbox

[https://github.com/microsoft/vscode-remote-release/issues/95](https://github.com/microsoft/vscode-remote-release/issues/95)

## Summary

Keep open as the established Docker Toolbox support request. Current documentation still excludes Toolbox, and maintainers explicitly retained this issue for the broader feature request and consolidated another report here.

## Change summary

Support opening local Windows folders in Dev Containers through Docker Toolbox, including correct VirtualBox-hosted bind-mount paths.

## Best solution

The Dev Containers owner should decide whether to add and test Toolbox-compatible workspace and auxiliary mount handling. Until that decision, retain this canonical request; manual Compose or workspaceMount configuration and alternative Docker hosts do not provide automatic Toolbox support.
