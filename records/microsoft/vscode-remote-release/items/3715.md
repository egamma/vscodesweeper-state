# Issue #3715 — Add possibility to specify dotfiles configuration at the repository/project level

[https://github.com/microsoft/vscode-remote-release/issues/3715](https://github.com/microsoft/vscode-remote-release/issues/3715)

## Summary

Keep open for project-specific dotfiles selection without editing the shared devcontainer.json. Existing settings cover global personalization and some project configuration, but do not establish coverage of the separate personal configuration requested here.

## Change summary

Allow users to select different dotfiles repositories per project through configuration separate from the shared devcontainer.json.

## Best solution

The Dev Containers component should provide a persistent per-project dotfiles override outside shared container configuration, with documented precedence over user defaults. Decide whether workspace settings or a separate local configuration file should supply it.
