# Issue #3715 — Add possibility to specify dotfiles configuration at the repository/project level

[https://github.com/microsoft/vscode-remote-release/issues/3715](https://github.com/microsoft/vscode-remote-release/issues/3715)

## Summary

A real gap remains: devcontainer.json can now select project-specific dotfiles, but there is no documented local, per-project configuration that stays outside source control. The existing containers routing is correct.

## Change summary

Allow each repository or workspace to select its own dotfiles profile without requiring that personal configuration to be committed in devcontainer.json.

## Best solution

The Dev Containers extension should provide a local per-project override for the dotfiles repository, target path, and install command while retaining devcontainer.json customization for intentionally shared profiles.
