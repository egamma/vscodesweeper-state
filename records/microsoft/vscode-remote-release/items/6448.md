# Issue #6448 — Transfer environment from ssh session to new EH

[https://github.com/microsoft/vscode-remote-release/issues/6448](https://github.com/microsoft/vscode-remote-release/issues/6448)

## Summary

The older, open environment-isolation request tracks the same observable problem: a second SSH window inherits the first connection's environment. Consolidate this shared-account case there, preserving the key-specific environment configuration.

## Change summary

Preserve each developer's SSH-session environment when creating a new remote extension host and terminal under a shared system account.

## Best solution

Resolve concurrent SSH-window environment isolation through https://github.com/microsoft/vscode-remote-release/issues/6186, including environments supplied through PermitUserEnvironment rather than RemoteCommand. The solution must preserve each connection's values without requiring a shared-server restart.
