# Issue #7029 — Port forwarding should support IPv6

[https://github.com/microsoft/vscode-remote-release/issues/7029](https://github.com/microsoft/vscode-remote-release/issues/7029)

## Summary

Keep open: multiple independent reports show that forwarded ports fail when either endpoint resolves or binds to the IPv6 loopback, while IPv4 works. This remains the accepted canonical backlog issue for the shared remote port-forwarding behavior.

## Change summary

Make remote port forwarding work with IPv6 loopback addresses and display the actual bound local address in the Ports view.

## Best solution

The shared remote-explorer tunnel path should forward IPv4 and IPv6 loopback listeners consistently across Dev Containers, SSH, and Tunnels, while showing the actual local bind address rather than an ambiguous localhost endpoint.
