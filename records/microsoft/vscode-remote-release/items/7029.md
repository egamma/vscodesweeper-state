# Issue #7029 — Port forwarding should support IPv6

[https://github.com/microsoft/vscode-remote-release/issues/7029](https://github.com/microsoft/vscode-remote-release/issues/7029)

## Summary

Keep this as the IPv6 port-forwarding report: the supplied sample and Python comparison suffice to retest, and later users still rely on IPv4 workarounds. Reports extend into 2026, but no current-release resolution or qualifying canonical was verified.

## Change summary

Forwarded ports should work with IPv6 loopback on both ends, and the Ports view should accurately describe the reachable local address.

## Best solution

The remote port-forwarding owners should retest both local IPv6 access and remote IPv6-only listeners, then make localhost forwarding work without disabling IPv6 or rewriting hosts files. Preserve this broader report rather than folding it into the newer Angular-specific issue.
