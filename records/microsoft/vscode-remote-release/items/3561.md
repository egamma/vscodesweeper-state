# Issue #3561 — SSH & port forwarding: connections aren't closed in the server

[https://github.com/microsoft/vscode-remote-release/issues/3561](https://github.com/microsoft/vscode-remote-release/issues/3561)

## Summary

A maintainer reproduced and diagnosed the forwarded connection remaining half-closed after the local client aborts. No fix or canonical issue is documented, so this should remain open and route to Remote - SSH connection handling.

## Change summary

Aborting a local client connected through an SSH-forwarded port does not close the remote connection, leaving the server-side writer blocked.

## Best solution

Remote - SSH port forwarding should fully destroy the tunnel when the local socket closes or errors, ensuring the remote server can finish rather than block under backpressure. The SSH owner should retest the supplied Go reproduction on the current release and reconcile why the core forwarding path behaved differently over SSH.
