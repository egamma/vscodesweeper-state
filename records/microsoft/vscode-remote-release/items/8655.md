# Issue #8655 — Docker error after installing Dev Containers

[https://github.com/microsoft/vscode-remote-release/issues/8655](https://github.com/microsoft/vscode-remote-release/issues/8655)

## Summary

Keep open: installing Dev Containers should not unexpectedly initiate a Docker-dependent reopen workflow, and the reporter also requested a new-container choice. The verified Docker-startup issue covers only part of this team-authored onboarding request.

## Change summary

Separate extension installation from container opening and offer an explicit choice to create a new container or reopen an existing configuration.

## Best solution

The Dev Containers owner should provide an explicit post-install getting-started chooser, deferring Docker-dependent operations until the user selects a container action. Coordinate the Remote Indicator entry point with VS Code core while retaining this issue for the extension-side experience.
