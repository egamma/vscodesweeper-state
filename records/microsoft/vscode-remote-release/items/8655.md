# Issue #8655 — Docker error after installing Dev Containers

[https://github.com/microsoft/vscode-remote-release/issues/8655](https://github.com/microsoft/vscode-remote-release/issues/8655)

## Summary

Keep open: the documented manual command and the Docker auto-start request in issue 8089 do not fully address this post-install flow, which probes existing configurations before the user chooses what to open. This team-authored Backlog request retains a distinct Dev Containers onboarding gap.

## Change summary

After installing Dev Containers from the Remote Indicator, avoid immediately failing against a stopped Docker daemon and offer the normal choice for opening a new container.

## Best solution

The Containers owner should make the post-install flow wait for an explicit action and offer the same new-container choices available from the Remote Indicator. Docker startup can be handled through https://github.com/microsoft/vscode-remote-release/issues/8089, while this issue continues to track the distinct selection and onboarding experience.
