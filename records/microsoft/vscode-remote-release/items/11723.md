# Issue #11723 — WSL containers fails with hostRequirements because `wslc info` isn't a command

[https://github.com/microsoft/vscode-remote-release/issues/11723](https://github.com/microsoft/vscode-remote-release/issues/11723)

## Summary

The WSLC host-requirements failure is confirmed by multiple members, and an open PR explicitly fixes this issue. Keep it open until that implementation is reviewed and merged.

## Change summary

Dev Containers invokes the unsupported `wslc info` command when a WSLC dev container declares `hostRequirements`, preventing the container from opening.

## Best solution

Review and land https://github.com/microsoft/vscode-remote-containers/pull/1212 so the containers extension avoids Docker-specific capability checks under WSLC and handles unsupported host requirements explicitly.
