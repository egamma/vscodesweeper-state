# Issue #9730 — [Remote-SSH Bug]: Space in user folder breaks SSH_ASKPASS

[https://github.com/microsoft/vscode-remote-release/issues/9730](https://github.com/microsoft/vscode-remote-release/issues/9730)

## Summary

Keep open for Remote - SSH to retest the documented Windows askpass failure. The supplied steps and complete log suffice; historical fixes predate this report, and no current resolution or matching open canonical was verified.

## Change summary

Remote - SSH fails to prompt for a key passphrase when local-server mode uses an askpass path under a Windows user folder containing spaces.

## Best solution

The SSH component should ensure its Windows askpass launcher handles spaced user-profile paths when using Git's SSH client. Retest the supplied scenario on current versions and distinguish launcher quoting from SSH-client-specific behavior before choosing the fix.
