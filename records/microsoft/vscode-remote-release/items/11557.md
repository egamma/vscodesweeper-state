# Issue #11557 — Orphaned `node -e` proxy processes accumulate inside Dev Container when `docker exec` dies during reconnection

[https://github.com/microsoft/vscode-remote-release/issues/11557](https://github.com/microsoft/vscode-remote-release/issues/11557)

## Summary

Keep open for the Dev Containers owner: the two-window host-networking steps suffice to retest orphaned proxy accumulation. Later reports show related leaks on newer releases, but neither a shipped fix nor a canonical owning this exact lifecycle failure is established.

## Change summary

Dev Containers should terminate stale exec-backed Node proxies after their client disappears instead of accumulating CPU-consuming orphan processes.

## Best solution

The containers component should establish reliable proxy-session teardown even when runtime-held pipes never signal EOF, preserving healthy idle connections. Evaluate the proposed initial-data watchdog against proxies orphaned after a successful handshake before adopting it.
