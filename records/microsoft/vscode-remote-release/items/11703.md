# Issue #11703 — Dev Containers: auto-forwarded extension-host agent port storms `docker exec` relays (~15/s), leaking thousands of procs until swap is exhausted

[https://github.com/microsoft/vscode-remote-release/issues/11703](https://github.com/microsoft/vscode-remote-release/issues/11703)

## Summary

Keep this actionable relay-lifecycle report open and route it to Dev Containers. The supplied two-window load trigger, versions, socket inspection, and logs suffice for retesting; no current-release confirmation, verified canonical, or fixing release is established.

## Change summary

Repeated reconnections to the container's server-agent port reportedly leave docker exec relays alive, accumulating thousands of processes and exhausting swap.

## Best solution

The Dev Containers owner should reproduce the two-window load scenario and ensure disconnected agent-port relays terminate without accumulating across reconnects. Investigate the reconnect trigger separately; forwarding the agent's control channel is not itself proof of erroneous application-port auto-forwarding.
