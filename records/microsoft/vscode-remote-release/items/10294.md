# Issue #10294 — [Remote-SSH Bug]: Proxy not configured when Adding container definition

[https://github.com/microsoft/vscode-remote-release/issues/10294](https://github.com/microsoft/vscode-remote-release/issues/10294)

## Summary

The proxy gap remains credible and independently confirmed: template retrieval runs locally without honoring the configured VS Code proxy, while host-level proxy environment variables provide a workaround. The issue is already correctly routed to Dev Containers and proxy handling.

## Change summary

Dev Containers should honor the configured local proxy when downloading a template for a workspace reached through SSH or WSL.

## Best solution

The Dev Containers extension should pass the applicable VS Code or system proxy configuration to its locally executed template CLI, allowing template retrieval without machine-wide proxy environment variables.
