# Issue #10294 — [Remote-SSH Bug]: Proxy not configured when Adding container definition

[https://github.com/microsoft/vscode-remote-release/issues/10294](https://github.com/microsoft/vscode-remote-release/issues/10294)

## Summary

Keep open for Dev Containers: the supplied steps and logs suffice to retest template downloads that bypass the configured proxy. Later users confirmed a local environment-variable workaround, not a shipped fix; current-release behavior remains unverified.

## Change summary

Adding Dev Container Configuration Files fails behind a corporate proxy because the locally launched template CLI does not use the proxy configuration that works elsewhere in VS Code.

## Best solution

The Dev Containers owner should verify that the locally launched templates CLI honors VS Code's configured HTTP proxy across SSH and WSL windows, and correct the integration if it does not. Preserve this report separately from certificate-trust and BuildKit failures unless matching proxy-selection behavior is established.
