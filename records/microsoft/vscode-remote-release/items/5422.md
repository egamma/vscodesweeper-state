# Issue #5422 — Allow extensions to be decoupled from devcontainer.json

[https://github.com/microsoft/vscode-remote-release/issues/5422](https://github.com/microsoft/vscode-remote-release/issues/5422)

## Summary

Keep open: the documented global default-extensions setting does not provide repository-specific personal extension lists, so the accepted Backlog request remains unsatisfied.

## Change summary

Allow each developer to maintain a gitignored, repository-specific extension list separately from the shared devcontainer.json.

## Best solution

The Dev Containers extension should merge an optional local, gitignored extension configuration with the repository's shared configuration. The overlapping newer discussion at https://github.com/microsoft/vscode-remote-release/issues/7650 should be consolidated into this older accepted Backlog item.
