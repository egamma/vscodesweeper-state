# Issue #1879 — Reconnecting with open files

[https://github.com/microsoft/vscode-remote-release/issues/1879](https://github.com/microsoft/vscode-remote-release/issues/1879)

## Summary

The existing `Developer: Reload Window` command provides the requested on-demand recovery after dismissing the reconnect prompt, without closing the current window. A maintainer documented this exact path and another reporter confirmed that it preserves their open-file workflow.

## Change summary

Provide an on-demand way to reconnect an SSH window after the automatic reconnect prompt is canceled.

## Best solution

Keep `Developer: Reload Window` as the recovery path after a canceled reconnect prompt. The distinct request for seamless reconnection without reloading and persistence of remote runtime state remains tracked at https://github.com/microsoft/vscode-remote-release/issues/3096.
