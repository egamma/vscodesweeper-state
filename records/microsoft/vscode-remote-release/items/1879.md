# Issue #1879 — Reconnecting with open files

[https://github.com/microsoft/vscode-remote-release/issues/1879](https://github.com/microsoft/vscode-remote-release/issues/1879)

## Summary

Retain the request and route it to SSH reconnection owners: canceling the reconnect prompt should not leave an open window without a discoverable retry action. Neither the documentation nor the related reports establishes that this specific recovery path is already covered.

## Change summary

Provide an on-demand SSH reconnect action after dismissing the automatic reconnect prompt, retaining open files and unsaved edits.

## Best solution

Remote - SSH should expose a retry action in the disconnected window even after Cancel, preserving its open editors and unsaved buffers. Determine whether the existing reload action safely delivers that recovery and needs better discoverability, or whether a dedicated reconnect action is required.
