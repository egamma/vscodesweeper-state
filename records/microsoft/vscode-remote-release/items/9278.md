# Issue #9278 — Devcontainer `initializeCommand` erroneously runs on container reopen

[https://github.com/microsoft/vscode-remote-release/issues/9278](https://github.com/microsoft/vscode-remote-release/issues/9278)

## Summary

Consolidate with the verified older, open request for host initialization that runs only during container creation/build rather than every window launch. The current specification explicitly permits initializeCommand to run on subsequent starts, but the creation-only capability remains a valid request.

## Change summary

Allow host-side initialization to run only when creating or rebuilding a container, without rerunning when reopening it.

## Best solution

Track creation/build-only host initialization in https://github.com/microsoft/vscode-remote-release/issues/8179 while preserving compatibility for existing initializeCommand configurations. Carry this report's reopen sequence and cleanup use case into that discussion.
