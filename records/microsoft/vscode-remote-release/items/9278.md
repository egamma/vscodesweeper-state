# Issue #9278 — Devcontainer `initializeCommand` erroneously runs on container reopen

[https://github.com/microsoft/vscode-remote-release/issues/9278](https://github.com/microsoft/vscode-remote-release/issues/9278)

## Summary

Verified duplicate: the older open issue tracks the same mismatch between `initializeCommand` behavior and its former documentation. The current specification now explicitly documents execution on subsequent starts.

## Change summary

Run `initializeCommand` only when creating a dev container, rather than whenever an existing container is reopened.

## Best solution

Consolidate the original behavior/documentation mismatch on https://github.com/microsoft/vscode-remote-release/issues/8577. Retain the now-documented behavior, while tracking a distinct once-per-build command capability on https://github.com/microsoft/vscode-remote-release/issues/8179.
