# Issue #11329 — `dev.containers.githubCLILoginWithToken` does not respect host account switching.

[https://github.com/microsoft/vscode-remote-release/issues/11329](https://github.com/microsoft/vscode-remote-release/issues/11329)

## Summary

Keep open: this team-authored Containers bug reports stale GitHub CLI credentials after switching the active host account. The report is already routed correctly, and the team-author protection overrides the usual info-needed action for an unconfirmed reproduction.

## Change summary

A restarted dev container continues using the GitHub CLI account active when it was built instead of the host's newly selected account.

## Best solution

The Dev Containers extension should refresh the token supplied by `dev.containers.githubCLILoginWithToken` when a container starts or reconnects, so `gh auth switch` on the host takes effect without rebuilding.
