# Issue #7603 — Initial Docker command is executed on local instead of remote machine

[https://github.com/microsoft/vscode-remote-release/issues/7603](https://github.com/microsoft/vscode-remote-release/issues/7603)

## Summary

The 2022 report lacks a current reproduction, while current documentation explicitly supports configuring a remote Docker host through `containers.environment`. A current-version retest is needed before deciding whether a Dev Containers defect remains.

## Change summary

Dev Containers should direct its initial Docker commands to the configured remote Docker daemon instead of the local Windows socket.

## Best solution

Confirm that current Dev Containers honors the Container Tools `containers.environment` setting for `DOCKER_HOST`; if it still selects the local daemon, the containers owner needs a current Dev Containers log showing the setting and first Docker invocation.
