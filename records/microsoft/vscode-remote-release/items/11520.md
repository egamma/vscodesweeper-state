# Issue #11520 — **Feature Request: Default remote directory for SSH connections**

[https://github.com/microsoft/vscode-remote-release/issues/11520](https://github.com/microsoft/vscode-remote-release/issues/11520)

## Summary

Keep open as a Remote - SSH feature request: documented shortcuts can reopen a chosen folder, but do not configure a default directory per host for ordinary connections. The matching historical requests are closed, and no open canonical was verified.

## Change summary

Allow each SSH host to specify a remote directory that opens automatically when connecting.

## Best solution

Remote - SSH should offer an optional per-host default folder for Connect to Host, preserving empty-window connections when unset. Existing Remote Explorer history and direct-folder launch commands remain useful alternatives, not equivalent coverage.
