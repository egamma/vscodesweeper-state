# Issue #11520 — **Feature Request: Default remote directory for SSH connections**

[https://github.com/microsoft/vscode-remote-release/issues/11520](https://github.com/microsoft/vscode-remote-release/issues/11520)

## Summary

A real Remote-SSH usability gap remains: previously opened folders and URI/CLI shortcuts reduce navigation, but no supported per-host default automatically opens when using Connect to Host. The exact prior request is closed and therefore cannot serve as a duplicate canonical.

## Change summary

Allow each SSH host to specify a remote folder or workspace that opens automatically upon connection.

## Best solution

Remote-SSH should provide a host-specific default folder or workspace setting used by Connect to Host, while preserving the existing empty-window behavior when none is configured.
