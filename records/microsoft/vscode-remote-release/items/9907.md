# Issue #9907 — GLIBC version dependency on legacy server

[https://github.com/microsoft/vscode-remote-release/issues/9907](https://github.com/microsoft/vscode-remote-release/issues/9907)

## Summary

Debian Stretch ARMv7 falls outside the documented Linux support matrix because its glibc is too old. This is an unsupported-platform compatibility request rather than evidence of a current Dev Containers defect, so it should remain open for an explicit scope decision.

## Change summary

Provide a VS Code legacy server build capable of running in Debian Stretch ARMv7 containers with glibc 2.24.

## Best solution

The supported end state is upgrading the container to Debian 10 or newer; alternatively, the VS Code Server owner must explicitly decide whether to provide compatibility for this legacy ARMv7 environment.
