# Issue #3432 — Remote-SSH using PKI card on Windows: vscode-server download fails

[https://github.com/microsoft/vscode-remote-release/issues/3432](https://github.com/microsoft/vscode-remote-release/issues/3432)

## Summary

The detailed logs established that the server-transfer scp process could hang while its PKCS#11 PIN prompt was inaccessible, but there is no current-version reproduction. A retest is needed before retaining this 2020 Remote - SSH bug.

## Change summary

Remote - SSH should recognize and display PKCS#11 PIN prompts when scp transfers the VS Code Server from a Windows client.

## Best solution

Confirm whether current Remote - SSH still fails to surface the PKCS#11 PIN prompt during client-side server transfer; if reproduced, the SSH component should handle that OpenSSH prompt through its authentication UI rather than leaving scp blocked.
