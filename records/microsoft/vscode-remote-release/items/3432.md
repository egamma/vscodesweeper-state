# Issue #3432 — Remote-SSH using PKI card on Windows: vscode-server download fails

[https://github.com/microsoft/vscode-remote-release/issues/3432](https://github.com/microsoft/vscode-remote-release/issues/3432)

## Summary

Keep open for Remote - SSH PIN-prompt handling during server installation. The supplied configuration and full log suffice to retest on current versions; the confirmed workaround is not a shipped fix, and the last maintainer comment identifies remaining SCP authentication-prompt work.

## Change summary

Server installation stalls during the local-download SCP fallback because the Windows PKCS#11 card PIN prompt is not presented for input.

## Best solution

Remote - SSH should recognize and expose the card PIN prompt during SCP transfers so installation on an offline remote host completes without changing authentication or enabling a login-terminal workaround. Retest the documented configuration on current releases before deciding whether this accepted fix remains necessary.
