# Issue #6146 — Configurable download location for vscode-server

[https://github.com/microsoft/vscode-remote-release/issues/6146](https://github.com/microsoft/vscode-remote-release/issues/6146)

## Summary

Keep open: the accepted Backlog request remains a distinct capability gap for organizations that must serve VS Code Server artifacts from an internal mirror. Existing download and installation-path settings do not provide a configurable download URL.

## Change summary

Allow the VS Code Server download base URL to be configured so remote extensions can use an internal artifact mirror.

## Best solution

Provide a shared remote-server download setting that supports an internal mirror, including the required commit and platform substitutions, while retaining the official update service as the default. The code-server lifecycle should own this across Remote - SSH and the other remote extensions.
