# Issue #6146 — Configurable download location for vscode-server

[https://github.com/microsoft/vscode-remote-release/issues/6146](https://github.com/microsoft/vscode-remote-release/issues/6146)

## Summary

Keep this accepted request open: documented download controls do not provide an internal server-download mirror. This issue already owns the cross-extension request; broader offline-installation work and a newer matching report do not supersede it.

## Change summary

Allow configuring the VS Code Server download source so restricted networks can supply version- and platform-specific artifacts from an internal mirror.

## Best solution

The remote extensions should share a supported configurable server-download source, retaining the public endpoint as the default and supporting commit- and platform-specific artifacts. Keep this issue as the established tracker for that capability, distinct from complete offline installation and container-image caching.
