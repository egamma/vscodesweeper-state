# Issue #6146 — Configurable download location for vscode-server

[https://github.com/microsoft/vscode-remote-release/issues/6146](https://github.com/microsoft/vscode-remote-release/issues/6146)

## Summary

Keep open as the accepted canonical request for configuring a private VS Code Server download mirror. The existing settings do not cover this requirement, and maintainers deliberately consolidated the equivalent Dev Containers request here.

## Change summary

Allow administrators to replace the VS Code Server download base URL with an internal mirror for restricted or disconnected environments.

## Best solution

Provide a shared remote-extension setting for an administrator-controlled VS Code Server download URL, preserving the official update service as the default. It should support Remote - SSH and other remote extensions consistently.
