# Issue #10592 — Dev Containers doubles the size of gitconfig when using shared HOME folder

[https://github.com/microsoft/vscode-remote-release/issues/10592](https://github.com/microsoft/vscode-remote-release/issues/10592)

## Summary

The shared-HOME configuration plausibly causes destructive self-copying, but the report lacks the Dev Containers version, logs, and a current-release confirmation. A retest is needed because related gitconfig growth handling changed around the time this was filed.

## Change summary

Dev Containers repeatedly appends a host gitconfig to itself when the container HOME resolves to the same shared location, eventually producing a very large file and slow Git operations.

## Best solution

Dev Containers should resolve the source and destination gitconfig paths before copying and skip the operation when they identify the same file. The containers owner first needs a current reproduction with before/after config contents and the creation log.
