# Issue #11750 — Dev container with the wslc runtime hangs when the repo is on the WSL filesystem (works from Windows)

[https://github.com/microsoft/vscode-remote-release/issues/11750](https://github.com/microsoft/vscode-remote-release/issues/11750)

## Summary

The WSL team confirmed that running wslc.exe inside a WSL distro is currently unsupported because bind mounts cross separate VMs. Keep this team-authored issue open as an upstream limitation linked to the dedicated WSL feature request.

## Change summary

Enable Dev Containers with the wslc runtime for repositories stored in a WSL filesystem, without hanging or passing unsupported arguments.

## Best solution

Track the underlying capability in https://github.com/microsoft/WSL/issues/41105. The Dev Containers extension should also detect this unsupported configuration and report a clear error instead of leaving container setup hanging.
