# Issue #2240 — Port forwarding: Forwarded ports are not visible in multiple windows

[https://github.com/microsoft/vscode-remote-release/issues/2240](https://github.com/microsoft/vscode-remote-release/issues/2240)

## Summary

Keep open: this team-authored backlog item remains the canonical request for sharing forwarded-port state across windows connected to the same remote host. Current documentation covers restoring ports between sessions, but not synchronizing active tunnels across windows.

## Change summary

Show and manage the same forwarded ports consistently in every VS Code window connected to one remote SSH host.

## Best solution

Remote - SSH should share tunnel state with the Remote Explorer service across windows connected to the same host, so each window displays existing forwards and handles additional forwarding without conflicts.
