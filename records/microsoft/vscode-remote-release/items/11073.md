# Issue #11073 — RemoteSSH: allow to detect or set remote PATH (user set PATH ignored)

[https://github.com/microsoft/vscode-remote-release/issues/11073](https://github.com/microsoft/vscode-remote-release/issues/11073)

## Summary

This is a valid Remote-SSH feature gap: no documented setting discussed in the thread configures the VS Code Server and remote extension-host PATH when sshd disallows user environment variables. Existing terminal settings and extension-specific executable overrides do not cover the central request.

## Change summary

Allow users or administrators to augment the environment, particularly PATH, inherited by the remote VS Code Server and its extensions.

## Best solution

Remote-SSH should provide a host-scoped server-environment setting or startup hook that augments the inherited SSH environment before starting the VS Code Server, subject to a maintainer security and behavior review.
