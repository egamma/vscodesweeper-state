# Issue #11073 — RemoteSSH: allow to detect or set remote PATH (user set PATH ignored)

[https://github.com/microsoft/vscode-remote-release/issues/11073](https://github.com/microsoft/vscode-remote-release/issues/11073)

## Summary

Keep open as an SSH environment-configuration request: terminal settings do not address the remote server and extensions' PATH. Existing workarounds and related requests do not establish that this specific gap is resolved or meets the re-review duplicate bar.

## Change summary

Allow Remote - SSH to discover or configure the remote user PATH for VS Code Server and remote extensions, independently of terminal settings.

## Best solution

The SSH component should establish whether shell-environment discovery covers this configuration and provide a documented, user-controlled way to initialize PATH for remote extensions without administrator changes or per-extension overrides.
