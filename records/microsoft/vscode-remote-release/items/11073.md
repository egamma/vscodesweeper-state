# Issue #11073 — RemoteSSH: allow to detect or set remote PATH (user set PATH ignored)

[https://github.com/microsoft/vscode-remote-release/issues/11073](https://github.com/microsoft/vscode-remote-release/issues/11073)

## Summary

This is a duplicate of the open issue tracking login-shell or equivalent environment initialization for Remote - SSH. That canonical covers making user PATH and other profile-defined variables available to the VS Code Server and remote extension host.

## Change summary

Allow users to configure or detect the PATH inherited by the remote VS Code Server and its extensions when sshd does not permit user environment overrides.

## Best solution

Consolidate on https://github.com/microsoft/vscode-remote-release/issues/1671 and design an SSH-owned mechanism to initialize the server environment from a login shell or equivalent configuration without requiring per-extension executable settings.
