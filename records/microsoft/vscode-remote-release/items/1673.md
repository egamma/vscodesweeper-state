# Issue #1673 — Open new WSL window and close local one.

[https://github.com/microsoft/vscode-remote-release/issues/1673](https://github.com/microsoft/vscode-remote-release/issues/1673)

## Summary

The original request is now covered by commands that connect the current window to WSL or reopen its folder in WSL. Preserving every open tab is a distinct, more complex request that the maintainer explicitly asked to track separately.

## Change summary

Allow switching the current local VS Code window into WSL instead of opening a second window, optionally preserving all open editors.

## Best solution

Keep the existing `WSL: Connect to WSL` and `WSL: Reopen Folder in WSL` workflows for the original request, and track cross-environment restoration of all open files and tabs as a separate WSL feature request.

  > Thanks for the request. The original current-window workflow is now available through `WSL: Connect to WSL`; when a folder or workspace is already open, use `WSL: Reopen Folder in WSL`.
