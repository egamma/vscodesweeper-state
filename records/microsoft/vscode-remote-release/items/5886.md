# Issue #5886 — downloading multiple files/folders from ssh remote: remember download location and show all dialogues at once

[https://github.com/microsoft/vscode-remote-release/issues/5886](https://github.com/microsoft/vscode-remote-release/issues/5886)

## Summary

The older, open Batch Download issue tracks the same repeated destination prompts and forgotten download location. Consolidating there preserves this report's additional requirement that downloads proceed without waiting for further user input.

## Change summary

Remember the local download destination and collect destination choices before transferring multiple remote files or folders.

## Best solution

Implement a single destination choice for the entire Explorer download selection, with destination reuse, under https://github.com/microsoft/vscode-remote-release/issues/4685. Carry over this report's requirement to complete all destination selection before transfers begin.
