# Issue #5886 — downloading multiple files/folders from ssh remote: remember download location and show all dialogues at once

[https://github.com/microsoft/vscode-remote-release/issues/5886](https://github.com/microsoft/vscode-remote-release/issues/5886)

## Summary

This remains a well-supported Remote - SSH workflow gap: bulk downloads still require repeated, sequential destination prompts. Keep it open and route it to the SSH file-transfer owners.

## Change summary

Remember the previous local download destination and allow destinations for multiple remote files or folders to be selected without waiting for each transfer.

## Best solution

Remote - SSH should treat a multi-selection as one download batch, prompting once for a destination or defaulting to the last-used location, then queueing all transfers without serial dialogs.
