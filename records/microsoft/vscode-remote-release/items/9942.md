# Issue #9942 — Auto install local extensions (not on the marketplace) when connecting to a remote

[https://github.com/microsoft/vscode-remote-release/issues/9942](https://github.com/microsoft/vscode-remote-release/issues/9942)

## Summary

Keep this accepted SSH feature request open. A user confirms automatic installation of non-Marketplace extensions through remote.defaultExtensionsIfInstalledLocally, but only after recreating the server; coverage on existing servers remains unestablished.

## Change summary

Automatically install designated private extensions from the local VS Code installation onto SSH remotes instead of requiring Marketplace availability.

## Best solution

The SSH connection workflow should install designated locally available private extensions without manual installation or server recreation. Verify the existing setting on both fresh and existing servers, then document sufficient coverage or retain the remaining installation gap.
