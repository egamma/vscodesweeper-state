# Issue #6065 — Containers Remote Explorer doesn't reopen a dev container built with a different Docker context

[https://github.com/microsoft/vscode-remote-release/issues/6065](https://github.com/microsoft/vscode-remote-release/issues/6065)

## Summary

Keep open for the Dev Containers owner to retest context preservation when reopening through Remote Explorer. The supplied steps suffice; Docker integration settings have evolved since the report, but no confirmation establishes that this specific workflow is fixed.

## Change summary

Remote Explorer reopens a remotely created dev container on the local Docker context instead of reconnecting to the existing remote container.

## Best solution

Dev Containers should reopen the selected container on its associated Docker host without creating a local replacement. Compare the Remote Explorer reopen path with the working Clone Repository in Container Volume path using the supplied reproduction.
