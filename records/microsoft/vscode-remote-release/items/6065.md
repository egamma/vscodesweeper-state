# Issue #6065 — Containers Remote Explorer doesn't reopen a dev container built with a different Docker context

[https://github.com/microsoft/vscode-remote-release/issues/6065](https://github.com/microsoft/vscode-remote-release/issues/6065)

## Summary

The detailed 2021 report describes Dev Containers reconnecting through the wrong Docker context, but it has no current-version confirmation or logs. A retest is needed because current documentation says Dev Containers honors `DOCKER_CONTEXT` or the active Docker context.

## Change summary

Remote Explorer should reopen an existing dev container using the Docker context on which that container was created rather than creating another container locally.

## Best solution

Dev Containers should retain the originating Docker context in Remote Explorer container identity and use it when reconnecting. First confirm the behavior on current releases and collect the Dev Containers log showing which context is selected.
