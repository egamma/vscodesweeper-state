[https://github.com/microsoft/vscode-remote-release/issues/11682](https://github.com/microsoft/vscode-remote-release/issues/11682)

## Summary

This was a Container Tools extension compatibility bug, not a Dev Containers defect. Container Tools 2.4.5 fixed it, and an affected user confirmed that updating the extension resolves the error.

## Change summary

The Containers and Images views fail with an isNullOrUndefined error after upgrading VS Code to a Node 24-based release.

## Best solution

Use Container Tools 2.4.5 or newer, which contains the owning extension's fix; further reports belong at https://github.com/microsoft/vscode-containers.
