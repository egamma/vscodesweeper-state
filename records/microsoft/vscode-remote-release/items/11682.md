[https://github.com/microsoft/vscode-remote-release/issues/11682](https://github.com/microsoft/vscode-remote-release/issues/11682)

## Summary

The failing Containers and Images views belong to Container Tools, not Dev Containers. Its maintainer identified this error and announced a fix in 2.4.5; an affected commenter here confirms updating Container Tools resolves it.

## Change summary

Opening the Containers explorer or its settings displays an isNullOrUndefined error instead of container and image information.

## Best solution

Use Container Tools 2.4.5 or later and close this tracker entry as caused by another extension. Any remaining Container Explorer failure belongs to https://github.com/microsoft/vscode-containers.
