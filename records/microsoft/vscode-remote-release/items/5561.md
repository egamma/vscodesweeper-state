Keep open for a targeted Dev Containers retest: current documentation promises support for the reported .env placement, but the thread contains no confirmed resolution. The supplied directory layout, sample repository, and command log suffice to retest against today's Compose behavior.

## Change summary

Dev Containers overrides COMPOSE_PROJECT_NAME from a .env beside a nested Compose file, producing incorrectly named projects and potentially conflicting with existing containers.

## Best solution
