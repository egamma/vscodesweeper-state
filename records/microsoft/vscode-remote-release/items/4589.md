# Issue #4589 — Support local privileged ports for port forwarding with SSH and Containers

[https://github.com/microsoft/vscode-remote-release/issues/4589](https://github.com/microsoft/vscode-remote-release/issues/4589)

## Summary

Keep this team-authored request open: the maintainer explicitly identified it as the outstanding SSH elevation feature, and neither the existing settings nor the linked PR establishes completion for SSH and Containers. No verified open canonical supersedes it.

## Change summary

Allow SSH and Dev Containers forwarding to bind privileged local ports through the built-in forwarding mechanism.

## Best solution

Provide consent-based local elevation in the shared forwarding path used by SSH and Containers, preserving localhost binding without requiring system-wide permission changes. Retain this issue as the product implementation tracker; existing provider APIs and spec attributes are integration surfaces, not proof of delivery.
