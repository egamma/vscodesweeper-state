# Issue #4589 — Support local privileged ports for port forwarding with SSH and Containers

[https://github.com/microsoft/vscode-remote-release/issues/4589](https://github.com/microsoft/vscode-remote-release/issues/4589)

## Summary

Keep open: this team-authored Backlog request remains unimplemented for Remote - SSH and Dev Containers, with 47 upvotes and later maintainer confirmation that elevation was supported only by Codespaces.

## Change summary

Allow Remote - SSH and Dev Containers users to bind forwarded connections to privileged local ports through an elevation flow.

## Best solution

Add elevation support to VS Code's built-in forwarding mechanism when a remote extension does not supply its own tunnel factory, covering both SSH and Containers without requiring unsafe system-wide configuration changes.
