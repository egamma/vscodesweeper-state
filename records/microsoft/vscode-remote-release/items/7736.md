# Issue #7736 — Extension commands are not proxied between remote and workstation extension hosts

[https://github.com/microsoft/vscode-remote-release/issues/7736](https://github.com/microsoft/vscode-remote-release/issues/7736)

## Summary

Keep open: the linked samples and installation steps suffice for a maintainer retest, and current documentation still promises cross-host command routing. The report targets VS Code 1.74/1.75; no current reproduction, confirmed fix, or matching open canonical was established.

## Change summary

A remote workspace extension cannot invoke a command supplied by an extension installed on the local workstation, although the same samples work locally.

## Best solution

Retest the samples with the provider explicitly running as a UI extension, distinguishing execution-location or activation problems from command-routing failure. If routing fails with both extensions correctly activated, a maintainer can transfer this to microsoft/vscode for the shared extension-host command infrastructure.
