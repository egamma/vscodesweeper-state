# Issue #11428 — Allow VSCode-wide security configuration.

[https://github.com/microsoft/vscode-remote-release/issues/11428](https://github.com/microsoft/vscode-remote-release/issues/11428)

## Summary

Keep open for security-sensitive maintainer assessment. Documented Workspace Trust does not establish the requested user-enforced, per-action controls, and no qualifying canonical was verified.

## Change summary

Add user-wide allow, deny, or prompt policies for privileged containers, host mounts outside the workspace, and initializeCommand execution.

## Best solution

The Dev Containers owner should assess enforceable user-level controls across supported container configurations, with clear documentation of their limits. Such controls should not imply that arbitrary repository code becomes a secure sandbox.
