# Issue #11428 — Allow VSCode-wide security configuration.

[https://github.com/microsoft/vscode-remote-release/issues/11428](https://github.com/microsoft/vscode-remote-release/issues/11428)

## Summary

This security-sensitive feature request identifies a real gap: Workspace Trust is repository-wide, while Dev Containers provides no documented user policy to allow, deny, or prompt for individual host-impacting capabilities. It must remain open for human security review.

## Change summary

Add user-level policies that allow, deny, or prompt before a dev container uses privileged mode, host mounts, or host-side initialization commands.

## Best solution

The Dev Containers extension should evaluate user security policies before container creation and block or obtain explicit approval for `initializeCommand`, privileged mode, and mounts outside permitted paths. These controls should supplement rather than replace Workspace Trust.
