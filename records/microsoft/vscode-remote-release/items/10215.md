# Issue #10215 — Podman is incompatible with `dockerComposeFile`

[https://github.com/microsoft/vscode-remote-release/issues/10215](https://github.com/microsoft/vscode-remote-release/issues/10215)

## Summary

Keep open with the existing containers/podman routing. The supplied configuration and logs suffice to retest; a related report describes the same failure on CLI 0.90.0, but resolution or current reproduction in the Dev Containers extension remains unverified.

## Change summary

Podman-backed Docker Compose builds fail during UID adjustment because the generated BASE_IMAGE uses localhost/ instead of the image's actual docker.io/library prefix.

## Best solution

The Dev Containers owner should coordinate image-resolution work with https://github.com/devcontainers/cli/issues/863 so UID adjustment uses an existing image reference or ID rather than an unconditional registry-prefix heuristic. Retain this product report until the extension receives and verifies the shared fix.
