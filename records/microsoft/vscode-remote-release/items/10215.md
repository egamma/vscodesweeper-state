# Issue #10215 — Podman is incompatible with `dockerComposeFile`

[https://github.com/microsoft/vscode-remote-release/issues/10215](https://github.com/microsoft/vscode-remote-release/issues/10215)

## Summary

The original logs demonstrate an image-name mismatch, but there has been no confirmation since Dev Containers CLI 0.69.0 and Podman 5.2.2; a current-version retest is needed before further action.

## Change summary

Dev Containers fails during UID adjustment because Podman Compose creates a docker.io/library-prefixed image while the subsequent build expects a localhost-prefixed image.

## Best solution

The Dev Containers CLI should reliably identify or inspect the image produced by the Compose build instead of assuming Podman always uses the localhost prefix. First confirm that the mismatch remains with current CLI, Podman, and Compose-provider versions.
