# Issue #986 — Remote extension installation ignores proxy settings 

[https://github.com/microsoft/vscode-remote-release/issues/986](https://github.com/microsoft/vscode-remote-release/issues/986)

## Summary

Retain the accepted request and route it to Dev Containers: automatic extension installation needs proxy and certificate handling equivalent to the UI. Later improvements and individual workarounds do not establish that the full request is resolved.

## Change summary

Make automatic remote extension installation honor configured proxies and trusted certificates consistently with interactive installation.

## Best solution

The Dev Containers owner should verify bootstrap installation with configured proxy settings and corporate CA trust, then address any remaining discrepancy with UI installation. Preserve this broader tracking issue rather than folding it into a narrower certificate report.
