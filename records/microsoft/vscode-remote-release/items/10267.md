## Change summary

The VS Code-installed devcontainer CLI wrapper does not accept interactive input during up and exec, unlike the npm-distributed CLI.

## Best solution

The Dev Containers owner should ensure the VS Code-installed wrapper preserves interactive input and shell lifetime for up and exec across macOS and Windows.
