# Issue #488 — Show error when workspaceMount is malformed in devcontainer.json

[https://github.com/microsoft/vscode-remote-release/issues/488](https://github.com/microsoft/vscode-remote-release/issues/488)

## Summary

A validation gap remains for malformed `workspaceMount` strings in supported image and Dockerfile configurations. Current schema validation catches the example's unsupported use with Docker Compose, but otherwise validates only that the value is a string.

## Change summary

Surface a clear configuration error before container creation when `workspaceMount` is unsupported or has invalid Docker `--mount` syntax.

## Best solution

The Dev Containers component should validate `workspaceMount` against Docker `--mount` syntax before invoking Docker and present an actionable configuration error. Validation shared with the public devcontainers CLI would keep editor and CLI behavior consistent.

- **documented syntax:** The reference documentation says `workspaceMount` accepts Docker CLI `--mount` values and is for image/Dockerfile scenarios: https://github.com/devcontainers/spec/blob/main/docs/specs/devcontainerjson-reference.md
