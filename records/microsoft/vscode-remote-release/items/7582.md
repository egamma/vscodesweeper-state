# Issue #7582 — Automatic platform ARGs are not recognized in a FROM stage for extension version >= 0.255.2 (exclude pre-release version)

[https://github.com/microsoft/vscode-remote-release/issues/7582](https://github.com/microsoft/vscode-remote-release/issues/7582)

## Summary

This remains an acknowledged Dev Containers defect with an open CLI pull request implementing and testing automatic platform-argument substitution. The issue must remain open while that implementation candidate is pending.

## Change summary

Dev Containers should resolve Docker's automatic platform arguments such as `TARGETARCH` when identifying base stages in multi-stage Dockerfiles.

## Best solution

Review and land https://github.com/devcontainers/cli/pull/1064, verify the original Dockerfile through the Dev Containers extension, and then consolidate the matching report at https://github.com/microsoft/vscode-remote-release/issues/9605.
