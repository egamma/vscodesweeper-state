# Issue #7796 — SSH commit signing: handle local filepath in gitconfig

[https://github.com/microsoft/vscode-remote-release/issues/7796](https://github.com/microsoft/vscode-remote-release/issues/7796)

## Summary

Keep open: this team-authored Backlog feature tracks automatically translating a host-local SSH signing-key path when Git configuration is copied into a dev container. The confirmed workarounds do not provide that automation.

## Change summary

Make SSH commit signing work in dev containers when `user.signingkey` references a public-key file on the local host.

## Best solution

The Dev Containers extension should detect a file-backed `user.signingkey` while copying Git configuration and safely inline the public key or otherwise provide an equivalent container-valid value.
