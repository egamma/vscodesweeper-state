# Issue #7796 — SSH commit signing: handle local filepath in gitconfig

[https://github.com/microsoft/vscode-remote-release/issues/7796](https://github.com/microsoft/vscode-remote-release/issues/7796)

## Summary

Keep open to track automatic handling of host-local SSH signing-key paths in Dev Containers. The maintainer explicitly retained this team-authored request; the confirmed workaround does not establish that the requested automation shipped.

## Change summary

Automatically make a public key referenced by the host's user.signingkey usable for SSH commit signing inside a dev container.

## Best solution

Dev Containers should inline the selected public key into the container's copied Git configuration while leaving the host configuration unchanged and private-key operations with the forwarded SSH agent.
