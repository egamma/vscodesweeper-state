# Issue #7796 — SSH commit signing: handle local filepath in gitconfig

[https://github.com/microsoft/vscode-remote-release/issues/7796](https://github.com/microsoft/vscode-remote-release/issues/7796)

## Summary

Keep open: the Dev Containers maintainer explicitly retained this team-authored feature request to track automatic handling of local `user.signingkey` file paths. The confirmed configuration workaround does not provide the requested transparent behavior.

## Change summary

Translate a host-local SSH signing-key filepath in copied Git configuration into a signing key that remains usable inside the dev container.

## Best solution

Dev Containers should detect when `user.signingkey` references a local public-key file and make that key usable in the container, such as by inlining its public-key value while preserving the host configuration.
