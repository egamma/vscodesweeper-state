# Issue #10571 — Cannot install extension on remote server

[https://github.com/microsoft/vscode-remote-release/issues/10571](https://github.com/microsoft/vscode-remote-release/issues/10571)

## Summary

The investigation traced the failure to broken IPv6 traffic between the remote network and Microsoft’s CDN, not Remote - SSH itself. Keep this open as an upstream networking case with potential SSH download-diagnostics work.

## Change summary

Remote extension discovery, installation, and VS Code Server updates hang when an established IPv6 CDN connection stops transferring data.

## Best solution

Remote - SSH should detect and clearly report stalled server or extension downloads, including the selected address family and endpoint, so users can distinguish CDN or network-path failures from extension failures.
