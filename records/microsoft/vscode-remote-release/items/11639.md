# Issue #11639 — Lifecycle marker files in home directory break persistent home volume across rebuilds

[https://github.com/microsoft/vscode-remote-release/issues/11639](https://github.com/microsoft/vscode-remote-release/issues/11639)

## Summary

Keep open: documented named-volume support covers persistence, but does not establish that lifecycle markers remain container-scoped when the entire home directory persists. The related issues do not own this report's full scope.

## Change summary

Separate lifecycle and dotfiles markers from persistent home data and provide an opt-in per-devcontainer home volume.

## Best solution

The Dev Containers owner should investigate marker handling across rebuilds with a persistent home volume and ensure container-specific initialization is not suppressed by retained home state. Evaluate automatic home-volume provisioning separately, coordinating with devcontainers/spec if a new format property is needed while retaining the extension-side work here.
