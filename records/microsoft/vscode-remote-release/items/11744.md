# Issue #11744 — I can't login with my github account to sync settings

[https://github.com/microsoft/vscode-remote-release/issues/11744](https://github.com/microsoft/vscode-remote-release/issues/11744)

## Summary

This is a VS Code Settings Sync usage question rather than a Remote Development defect. GitHub authentication is already supported, including switching an existing sync setup to another account.

## Change summary

Use a GitHub account instead of a Microsoft account to access synchronized VS Code settings.

## Best solution

Turn off Settings Sync, turn it on again, and select GitHub when prompted for the account provider, as documented at https://code.visualstudio.com/docs/configure/settings-sync.
