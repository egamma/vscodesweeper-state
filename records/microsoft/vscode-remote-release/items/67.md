# Issue #67 — Support Linux 32bit

[https://github.com/microsoft/vscode-remote-release/issues/67](https://github.com/microsoft/vscode-remote-release/issues/67)

## Summary

Keep this as the existing tracker for native 32-bit x86 Linux support, including containers. Current documentation does not provide that capability, and a maintainer explicitly consolidated a newer i686 report here in 2025.

## Change summary

Support running the VS Code Server inside native i386 Linux containers and on 32-bit x86 Linux hosts.

## Best solution

The remote/server owners should make an explicit support decision for native i386 server builds and their Dev Containers integration. Keep ARM support and running 64-bit binaries on mixed-architecture systems distinct from this request.
