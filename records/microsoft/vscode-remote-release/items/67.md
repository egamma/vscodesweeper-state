# Issue #67 — Support Linux 32bit

[https://github.com/microsoft/vscode-remote-release/issues/67](https://github.com/microsoft/vscode-remote-release/issues/67)

## Summary

Linux x86 32-bit remains unsupported, and no documented setting or workaround provides the requested server binaries. This issue is the canonical request and should remain open for a component-owner scope decision.

## Change summary

Provide VS Code Server and native-module support for 32-bit x86 Linux hosts and containers.

## Best solution

The VS Code Server and Dev Containers owners should decide whether producing and testing an i386 Node runtime and native modules is sustainable; if not, document the scope decision explicitly.
