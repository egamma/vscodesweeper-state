# Issue #10921 — segmentation fault in code-server

[https://github.com/microsoft/vscode-remote-release/issues/10921](https://github.com/microsoft/vscode-remote-release/issues/10921)

## Summary

The failure was isolated to Docker Desktop 4.41 on Intel Macs and resolved upstream in Docker Desktop 4.42. An affected user confirmed that 4.42.1 no longer reproduces it; upstream issues remain open under this repository's policy.

## Change summary

Starting code-server inside a Dev Container segfaulted on Intel Macs after upgrading to Docker Desktop 4.41.

## Best solution

Treat Docker Desktop 4.42 or newer as the resolution for this compatibility issue; no Dev Containers or VS Code Server change is indicated unless the crash returns on current Docker Desktop releases.

- **upstream fix:** Docker Desktop 4.42 disabled memory protection keys in its Linux VM because they prevented VS Code Dev Containers from working, as recorded at https://docs.docker.com/desktop/release-notes/#4420 and https://github.com/docker/for-mac/issues/7667#issuecomment-2943167155.
