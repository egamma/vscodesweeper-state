# Issue #10921 — segmentation fault in code-server

[https://github.com/microsoft/vscode-remote-release/issues/10921](https://github.com/microsoft/vscode-remote-release/issues/10921)

## Summary

The thread identifies this as an upstream Docker Desktop virtualization issue affecting Intel Macs, not a Dev Containers defect. Docker Desktop 4.42.0 disabled the triggering memory-protection mechanism, and a user confirmed the failure no longer occurs on 4.42.1.

## Change summary

VS Code Server exits with segmentation fault 139 when opening Debian-based dev containers through Docker Desktop 4.41 on Intel Macs.

## Best solution

Retain Docker Desktop 4.42.0 or newer as the upstream resolution; no change to the Dev Containers extension is indicated by the available evidence.
