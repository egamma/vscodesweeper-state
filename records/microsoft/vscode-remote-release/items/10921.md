# Issue #10921 — segmentation fault in code-server

[https://github.com/microsoft/vscode-remote-release/issues/10921](https://github.com/microsoft/vscode-remote-release/issues/10921)

## Summary

Docker Desktop's Intel-Mac memory-protection regression was fixed in 4.42.0, with an affected user confirming recovery on 4.42.1. Keep this upstream tracking issue open under the policy against upstream closes; no remaining Dev Containers defect is established.

## Change summary

Starting the VS Code Server in a dev container on an Intel Mac fails with a segmentation fault and exit code 139.

## Best solution

Use a supported Docker Desktop release containing the 4.42.0 fix. The containers owner should retain the upstream resolution context; the evidence does not establish a need for an extension-side change.
