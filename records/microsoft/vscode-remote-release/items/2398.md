Keep open: Windows-to-Linux agent forwarding failed inside Remote - SSH while the same SSH client worked outside VS Code. Connection modes have evolved since these reports, but the supplied setup and comparisons suffice to retest; neither a current fix nor a full-scope canonical is verified.
