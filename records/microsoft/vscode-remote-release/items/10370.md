# Issue #10370 — Port Forwarding Fails Due to 'PortsPerTunnel' Limit Despite No Active Forwards

[https://github.com/microsoft/vscode-remote-release/issues/10370](https://github.com/microsoft/vscode-remote-release/issues/10370)

## Summary

Keep open: multiple users reproduced port-forwarding failure after stale tunnel ports accumulated, and a maintainer identified the cleanup behavior as a probable bug. Restart workarounds temporarily clear the state but do not resolve the lifecycle defect.

## Change summary

Remote Tunnels leaves stale port registrations that eventually exhaust the 10-port limit despite showing no active forwards.

## Best solution

The tunnels component should reconcile relay-side port registrations when sessions start and reliably remove them after disconnects, preventing invisible stale ports from consuming the per-tunnel limit.
