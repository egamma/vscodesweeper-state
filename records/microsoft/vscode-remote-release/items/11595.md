# Issue #11595 — Feature Request: Allow `devcontainer.json` to pass server-side startup args (e.g. `--enable-proposed-api`) to VS Code Server

[https://github.com/microsoft/vscode-remote-release/issues/11595](https://github.com/microsoft/vscode-remote-release/issues/11595)

## Summary

Keep open as a Dev Containers feature request. The documented VS Code customization surface has no server-argument capability, and current-version testing confirms that neither local argv.json nor directly injecting the server flag enables proposed APIs in the remote extension host.

## Change summary

Allow a shared devcontainer configuration to enable selected VS Code Server or remote-extension-host startup capabilities such as proposed APIs.

## Best solution

The Dev Containers and VS Code platform owners should define a supported, trust-gated customization that propagates approved extension API enablement through both the client and remote extension host; forwarding arbitrary server arguments alone is insufficient. Coordinate this with the related API-stabilization work in https://github.com/microsoft/vscode/issues/310930 without treating that narrower issue as a duplicate.
