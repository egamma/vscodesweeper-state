# Issue #11595 — Feature Request: Allow `devcontainer.json` to pass server-side startup args (e.g. `--enable-proposed-api`) to VS Code Server

[https://github.com/microsoft/vscode-remote-release/issues/11595](https://github.com/microsoft/vscode-remote-release/issues/11595)

## Summary

Keep open: the documented configuration does not provide shareable VS Code Server startup arguments, and no matching canonical was found. The complete discussion also indicates that forwarding server arguments alone may not enable proposed APIs in the remote extension host.

## Change summary

Allow devcontainer definitions or image metadata to declare VS Code Server startup options, including per-extension proposed-API enablement.

## Best solution

The Dev Containers owner should evaluate a supported, appropriately gated configuration surface and coordinate with VS Code core on end-to-end proposed-API enablement. Establish whether server arguments actually deliver the requested behavior before adopting serverArgs; tunnel API stabilization is related but does not resolve the general configuration request.
