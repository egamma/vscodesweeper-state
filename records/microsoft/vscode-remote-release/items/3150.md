# Issue #3150 — .env file in project root is not used

[https://github.com/microsoft/vscode-remote-release/issues/3150](https://github.com/microsoft/vscode-remote-release/issues/3150)

## Summary

The documentation ambiguity has been corrected: automatic `.env` loading applies only to Docker Compose, while Dockerfile/image configurations must use `runArgs` with `--env-file`.

## Change summary

Clarify that a workspace-root `.env` file is not automatically injected into Dockerfile-based dev containers.

## Best solution

Keep the shipped documentation distinction between Docker Compose's automatic `.env` handling and explicit `--env-file` configuration for Dockerfile/image scenarios; no extension change is required for this report.
