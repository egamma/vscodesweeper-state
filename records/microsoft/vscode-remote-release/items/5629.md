# Issue #5629 — Snap: Built-in devcontainer CLI path uses old version

[https://github.com/microsoft/vscode-remote-release/issues/5629](https://github.com/microsoft/vscode-remote-release/issues/5629)

## Summary

A later matching report received a Dev Containers fix, but this thread has no post-fix confirmation. Ask for a targeted retest rather than closing against an already-closed issue.

## Change summary

The bundled devcontainer CLI retains revision-specific VS Code Snap paths that become invalid after updates.

## Best solution

Dev Containers should refresh its saved VS Code paths independently of extension updates. Confirm that the announced fix preserves CLI operation after a Snap refresh, including both saved executable and application-root paths.
