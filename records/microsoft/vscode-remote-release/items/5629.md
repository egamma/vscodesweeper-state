# Issue #5629 — Snap: Built-in devcontainer CLI path uses old version

[https://github.com/microsoft/vscode-remote-release/issues/5629](https://github.com/microsoft/vscode-remote-release/issues/5629)

## Summary

The failure was independently confirmed through June 2024, but there is no current-version reproduction. A retest is needed to determine whether the Dev Containers launcher still retains obsolete versioned Snap paths.

## Change summary

The built-in devcontainer CLI records a version-specific Snap executable path that disappears after VS Code updates.

## Best solution

If still reproducible, Dev Containers should use the stable `/snap/code/current/...` paths or regenerate its CLI launcher metadata after Snap updates.
