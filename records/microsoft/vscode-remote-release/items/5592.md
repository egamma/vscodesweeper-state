# Issue #5592 — Detect if host doesn't have enough space

[https://github.com/microsoft/vscode-remote-release/issues/5592](https://github.com/microsoft/vscode-remote-release/issues/5592)

## Summary

Keep open: this team-authored Backlog request identifies a remaining Remote - SSH diagnosability gap for hosts that cannot support the VS Code Server.

## Change summary

Detect insufficient remote-host RAM, disk space, or quota before server setup and present an actionable error.

## Best solution

Remote - SSH should perform a best-effort resource preflight before installing or starting the VS Code Server and distinguish insufficient RAM, free storage, and quota failures in its diagnostics.

## Vision fit

- **Fit:** aligned
- **Reason:** Resource preflight errors directly improve VS Code Server lifecycle reliability and connection-failure diagnosability.
- **Evidence:** The durable themes explicitly include VS Code Server installation on constrained hosts and clearer diagnostics when connections cannot be established.
