## Summary

Keep open: the paired URI examples and reproduction script suffice to retest the context-dependent attach failure on the reported current versions. Route to Dev Containers; selecting the default context remains an inference, not a confirmed root cause.

## Change summary

An attached-container URI without settings.context reports an existing container as missing, while an explicit-context URI and the Command Palette attach successfully.
