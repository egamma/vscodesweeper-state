# Issue #10513 — [Remote-SSH Bug]: First connection failing 50% of the time, and then retry works

[https://github.com/microsoft/vscode-remote-release/issues/10513](https://github.com/microsoft/vscode-remote-release/issues/10513)

## Summary

Keep open for Remote - SSH bootstrap investigation: paired logs and the server-reboot trigger provide enough to retest. Matching failures persisted from Remote - SSH 0.115.1 to 0.120.0, but current-release resolution and a qualifying canonical remain unverified.

## Change summary

The first SSH connection fails to obtain the remote listening port, while an immediate retry succeeds.

## Best solution

Remote - SSH should reliably obtain the exec server's listening address during cold startup rather than fail before it becomes available. Investigate startup readiness and log polling using the reboot trigger and paired logs; distinguish this from AFS-specific file visibility failures.
