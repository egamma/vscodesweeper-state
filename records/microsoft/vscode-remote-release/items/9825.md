# Issue #9825 — [Remote-SSH Bug]: Directives in config files that are included are erroneously case-sensitive

[https://github.com/microsoft/vscode-remote-release/issues/9825](https://github.com/microsoft/vscode-remote-release/issues/9825)

## Summary

Keep open: the two-file example is sufficient to retest the included-config host-discovery defect. The thread identifies likely extension-side handling but provides neither a current reproduction nor a confirmed fix.

## Change summary

Remote Explorer omits hosts declared with uppercase or lowercase Host keywords in included SSH configuration files.

## Best solution

Remote - SSH should discover hosts from included configuration files regardless of keyword casing, while preserving argument casing. Retest the supplied example and inspect how the extension consumes parsed directives; changing keywords to title case is a workaround, not a fix.

## Evidence

- **Expected SSH semantics:** https://man7.org/linux/man-pages/man5/ssh_config.5.html explicitly states that configuration keywords are case-insensitive and arguments are case-sensitive. The reporter also observes that alternate keyword casing works in the main configuration file.
