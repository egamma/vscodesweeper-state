# Issue #9825 — [Remote-SSH Bug]: Directives in config files that are included are erroneously case-sensitive

[https://github.com/microsoft/vscode-remote-release/issues/9825](https://github.com/microsoft/vscode-remote-release/issues/9825)

## Summary

The report remains a valid Remote - SSH config-handling bug. A maintainer confirmed that the parser accepts the directives and localized the defect to how the extension consumes parsed output; no open canonical or confirmed fix was found.

## Change summary

Remote Explorer omits hosts from included SSH config files when directives such as Host and User use non-title casing permitted by OpenSSH.

## Best solution

The SSH component should consume parsed directive names case-insensitively when building Remote Explorer targets from included config files, preserving OpenSSH ssh_config semantics.
