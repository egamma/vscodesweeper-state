# Issue #10065 — Devcontainers lose connection after a few seconds

[https://github.com/microsoft/vscode-remote-release/issues/10065](https://github.com/microsoft/vscode-remote-release/issues/10065)

## Summary

A team member reproduced the indefinite reconnection failure after the announced pre-release fix, so the issue remains actionable. Route it as a Dev Containers-over-WSL reconnection bug.

## Change summary

Dev Containers opened from WSL can lose their host connection and remain stuck reconnecting indefinitely, leaving the terminal unusable.

## Best solution

Dev Containers should restore its WSL host and container connections after the underlying transport drops, without leaving the window in an endless reconnect state. The containers/WSL owners should revalidate the documented forced-disconnection scenario on the current release and separately investigate what caused the reporter's spontaneous WSL connection loss.
