# Issue #3279 — Overlay .devcontainer

[https://github.com/microsoft/vscode-remote-release/issues/3279](https://github.com/microsoft/vscode-remote-release/issues/3279)

## Summary

The requested Git-ignored overlay is now tracked directly by the open Dev Container specification proposal at https://github.com/devcontainers/spec/issues/305. Consolidating there keeps the configuration format and merge semantics with the specification that all consumers implement.

## Change summary

Allow a user-specific configuration file to overlay a repository's maintained devcontainer configuration without modifying the shared file.

## Best solution

Define the override-file behavior and merge semantics through https://github.com/devcontainers/spec/issues/305, with the Dev Containers extension adopting the resulting specification. The related inheritance proposal at https://github.com/devcontainers/spec/issues/22 can cover reusable parent configurations.
