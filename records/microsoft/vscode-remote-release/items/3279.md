# Issue #3279 — Overlay .devcontainer

[https://github.com/microsoft/vscode-remote-release/issues/3279](https://github.com/microsoft/vscode-remote-release/issues/3279)

## Summary

Keep open: personal, per-project overlays remain distinct from the documented global settings and image-metadata workaround. The component is already correctly routed, and the related spec proposals do not deliver extension support.

## Change summary

Allow gitignored personal configuration to overlay a shared devcontainer definition while retaining upstream configuration updates.

## Best solution

The Dev Containers component should support a spec-aligned local overlay with explicit merge, replacement, and removal semantics. Coordinate with the spec proposals while retaining this issue for the extension-side behavior.
