# Issue #11538 — Remote-SSH fails to recover from stale server metadata after system crash

[https://github.com/microsoft/vscode-remote-release/issues/11538](https://github.com/microsoft/vscode-remote-release/issues/11538)

## Summary

The merged VS Code keepalive fix detects the dead connection but does not fully address Remote-SSH's stale metadata: the extension can still repeatedly reuse dead IPC and SOCKS endpoints. Keep this open for extension-side cleanup.

## Change summary

Remote-SSH should discard stale local-server metadata and establish a fresh connection after an unclean client shutdown.

## Best solution

Remote-SSH should treat ENOENT or ECONNREFUSED from the cached local server as fatal, remove the stale data, and re-resolve the host instead of continuing to short-circuit connection setup.
