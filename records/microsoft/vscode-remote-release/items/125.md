# Issue #125 — Share dotfiles with the host machine

[https://github.com/microsoft/vscode-remote-release/issues/125](https://github.com/microsoft/vscode-remote-release/issues/125)

## Summary

The reporter's dotfiles-repository use case is already supported, while the remaining request for private host-backed configuration is covered by the broader open issue proposing user-level container mounts.

## Change summary

Allow personal dotfiles and other host configuration to be shared into every Dev Container without baking them into the image or repository configuration.

## Best solution

Consolidate the remaining host-sharing requirement on https://github.com/microsoft/vscode-remote-release/issues/3185, whose proposed user-level mounts would support both host bind mounts and persistent named volumes without changing each project's devcontainer.json.
