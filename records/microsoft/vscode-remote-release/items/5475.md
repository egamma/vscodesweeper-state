# Issue #5475 — Read build args from env file i.e. private npm registry

[https://github.com/microsoft/vscode-remote-release/issues/5475](https://github.com/microsoft/vscode-remote-release/issues/5475)

## Summary

Verified duplicate: the older open issue tracks secure file-backed credentials during Dev Container builds, including private package registries. Consolidating there preserves this report's request for project-specific credentials without host-global environment variables.

## Change summary

Allow Dockerfile builds to consume project-specific build credentials from a gitignored environment file.

## Best solution

Follow https://github.com/microsoft/vscode-remote-release/issues/4841 for a declarative build-secrets experience. Meanwhile, the current specification's `build.options` can pass Docker BuildKit `--secret` options without committing credentials or exposing them as build arguments.
