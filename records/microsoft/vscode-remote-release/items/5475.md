# Issue #5475 — Read build args from env file i.e. private npm registry

[https://github.com/microsoft/vscode-remote-release/issues/5475](https://github.com/microsoft/vscode-remote-release/issues/5475)

## Summary

Keep this accepted Dev Containers request open: documented environment-file support does not populate Dockerfile build arguments, and the verified related issues track different behavior. Existing build-secret options address private-registry credentials, but not general project-local env-file interpolation.

## Change summary

Load Dockerfile build arguments from a project-local, uncommitted environment file without requiring inherited host environment variables.

## Best solution

The Dev Containers owner should evaluate project-scoped env-file loading for build arguments, coordinating any format addition with the Dev Container spec while retaining extension-side tracking here. For private-registry credentials, recommend file-backed BuildKit secret mounts rather than copying secrets into image layers or passing them as build arguments.
