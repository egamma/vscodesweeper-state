# Issue #1688 — Save as admin option.

[https://github.com/microsoft/vscode-remote-release/issues/1688](https://github.com/microsoft/vscode-remote-release/issues/1688)

## Summary

Keep this remote save-elevation request open: documented user-selection options and the terminal-based sudoedit workaround do not provide native per-file elevated saving. A maintainer explicitly consolidated the corresponding core product request here.

## Change summary

Allow non-root remote sessions to create and save privileged files through an explicit save-as-admin action.

## Best solution

The remote file-service owners should coordinate with the core FileSystemProvider permissions work to provide scoped, explicitly authorized elevated saves across SSH, containers, and WSL without running the entire session as root or changing file permissions.
