# Issue #7865 — Support "Allow Tunnel access" for the remote when connected to a SSH/WSL remote window

[https://github.com/microsoft/vscode-remote-release/issues/7865](https://github.com/microsoft/vscode-remote-release/issues/7865)

## Summary

Keep this team-authored request open: documented tunnel commands do not establish that an SSH/WSL-connected window can enable tunnel access on its remote endpoint. No verified canonical or public fix was found.

## Change summary

Allow an SSH/WSL-connected window to enable tunnel access on the remote environment rather than the local client machine.

## Best solution

The tunnels/CLI owners should provide remote-targeted tunnel activation from an existing SSH/WSL window, coordinating with the connection extensions so the selected remote environment is published.
