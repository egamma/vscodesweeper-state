# Issue #6817 — Auto-detect docker in WSL when not available in Windows

[https://github.com/microsoft/vscode-remote-release/issues/6817](https://github.com/microsoft/vscode-remote-release/issues/6817)

## Summary

The existing Execute in WSL setting resolves the workflow, but it requires manual configuration and does not provide the requested automatic Windows-to-WSL fallback. No open canonical issue was found that owns this enhancement.

## Change summary

Automatically use Docker from WSL when no usable Docker installation is available on Windows.

## Best solution

Dev Containers should offer an automatic execution mode that prefers Windows Docker when available and otherwise runs Docker commands in the configured WSL distribution, while retaining explicit Windows and WSL choices.

## Vision fit

- **Fit:** aligned
- **Reason:** Automatic selection would improve Dev Containers support for an explicitly documented alternative Docker installation and reduce connection setup friction.
- **Evidence:** The public alternative Docker options documentation supports using Docker installed in WSL through the WSL extension: https://code.visualstudio.com/remote/advancedcontainers/docker-options#_windows-windows-subsystem-for-linux-wsl
