# Issue #11522 — "Reopen in Container" triggers template wizard instead of opening existing devcontainer.json

[https://github.com/microsoft/vscode-remote-release/issues/11522](https://github.com/microsoft/vscode-remote-release/issues/11522)

## Summary

This remains a well-supported Dev Containers regression: multiple users confirm that the standard reopen command invokes configuration creation instead of using the existing devcontainer.json. The issue is already correctly routed to containers and should remain open.

## Change summary

Restore "Reopen in Container" so it detects and opens an existing .devcontainer/devcontainer.json rather than launching the template wizard.

## Best solution

The Dev Containers extension should correct its command dispatch or configuration discovery so an existing devcontainer.json proceeds through the normal container-opening path, while the configuration wizard remains limited to workspaces without a configuration.
