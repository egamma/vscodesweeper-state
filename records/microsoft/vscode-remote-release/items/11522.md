# Issue #11522 — "Reopen in Container" triggers template wizard instead of opening existing devcontainer.json

[https://github.com/microsoft/vscode-remote-release/issues/11522](https://github.com/microsoft/vscode-remote-release/issues/11522)

## Summary

Keep open with the existing containers routing: multiple users confirm that reopening an existing configuration enters the template wizard, including a September report on VS Code 1.139.1. No confirmed fix or same-symptom canonical was found.

## Change summary

Dev Containers: Reopen in Container launches the configuration wizard instead of using an existing .devcontainer/devcontainer.json.

## Best solution

The Dev Containers owner should investigate configuration discovery and command dispatch so Reopen in Container uses the existing configuration without offering to overwrite it. Compare the failing window with a fresh code . window and the reported working VS Code 1.109.5 baseline.

These are independent confirmations, not proof of the exact internal cause.
