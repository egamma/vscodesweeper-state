# Issue #4237 — Improve moving from image to name based configuration

[https://github.com/microsoft/vscode-remote-release/issues/4237](https://github.com/microsoft/vscode-remote-release/issues/4237)

## Summary

Keep open for the configuration-migration UX: named configurations already provide isolation, but the reporter explicitly requests an easier way to discover existing image configurations and bind them to containers. The related issues do not own that same remaining request, and its accepted Backlog status bars an as-designed decline.

## Change summary

Make it easier to discover and migrate image-level attached-container configurations to container-name-specific configurations.

## Best solution

Dev Containers should provide a discoverable way to select an existing image configuration and bind or copy it to a named container, preserving the desired folder, settings, and extensions without manipulating globalStorage files.
