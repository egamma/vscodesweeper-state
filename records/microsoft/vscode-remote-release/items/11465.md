# Issue #11465 — User impersonation with kubectl "--as argument"

[https://github.com/microsoft/vscode-remote-release/issues/11465](https://github.com/microsoft/vscode-remote-release/issues/11465)

## Summary

This is a valid, already-routed Dev Containers feature request in the Backlog. Kubernetes contexts can associate namespaces with impersonating identities, but that workaround does not provide the requested per-namespace Dev Containers setting.

## Change summary

Allow Kubernetes pod attachments to pass a namespace-specific user through kubectl's `--as` impersonation option.

## Best solution

Dev Containers should support namespace-specific kubectl impersonation when listing and attaching to Kubernetes pods, ensuring the configured identity is applied consistently to every kubectl invocation.
