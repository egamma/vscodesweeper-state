# Issue #11193 — downloaded wsl server cache in windows side never be clean

[https://github.com/microsoft/vscode-remote-release/issues/11193](https://github.com/microsoft/vscode-remote-release/issues/11193)

## Summary

Keep this as the existing WSL cache-cleanup tracking item: later reports document substantial Windows-side accumulation, and no documented capability covers automatic retention. The matching newer issue does not meet the re-review canonical ownership bar.

## Change summary

Automatically prune obsolete Windows-side WSL server download packages and abandoned partial downloads instead of accumulating them across updates.

## Best solution

The WSL extension should implement bounded cache retention for Stable and Insiders, preserving packages needed by active builds and downloads while removing obsolete and abandoned entries. Use this older Backlog item to track the work, incorporating the Insiders evidence from https://github.com/microsoft/vscode-remote-release/issues/11708; consider cache relocation separately.
