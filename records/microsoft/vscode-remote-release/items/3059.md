[https://github.com/microsoft/vscode-remote-release/issues/3059](https://github.com/microsoft/vscode-remote-release/issues/3059)

## Summary

This remains the canonical feature request for Remote - SSH support on AIX. Current documentation excludes AIX, no existing setting provides equivalent support, and sustained community interest supports retaining the request for an explicit product decision.

## Change summary

Add an AIX-compatible VS Code Server and Remote - SSH installation path so developers can work directly on AIX hosts.

## Best solution

The SSH and VS Code Server owners should assess an AIX server build and installation path, including its architecture, runtime, and Unix-tool compatibility requirements. This issue should remain the canonical place for that scope decision.
