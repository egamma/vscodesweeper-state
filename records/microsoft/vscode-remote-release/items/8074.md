# Issue #8074 — getExtension('vscode.git') returns undefined for extensions on different extension hosts

[https://github.com/microsoft/vscode-remote-release/issues/8074](https://github.com/microsoft/vscode-remote-release/issues/8074)

## Summary

Keep this reopened, team-authored bug open: the discussion identifies the cross-host Git-context failure sufficiently to retest, but contains no current-release resolution. The linked disablement predates reopening, and the related tunnels issue does not own the full Containers-side work.

## Change summary

Continue On targets cannot obtain active Git repository context when their extension and vscode.git run in different extension hosts.

## Best solution

The Dev Containers owner should replace the cross-host Git API dependency with an asynchronous, JSON-serializable repository-context command, coordinating any Git-side support with VS Code core. Retest container-to-Codespaces continuation and retain this product-side issue until that workflow works.
