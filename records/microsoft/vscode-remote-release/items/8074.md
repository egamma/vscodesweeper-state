# Issue #8074 — getExtension('vscode.git') returns undefined for extensions on different extension hosts

[https://github.com/microsoft/vscode-remote-release/issues/8074](https://github.com/microsoft/vscode-remote-release/issues/8074)

## Summary

Keep open: this team-authored Backlog bug identifies a cross-extension-host limitation that breaks Continue On workflows, and no verified fix is present. The underlying API gap likely belongs in microsoft/vscode.

## Change summary

Allow a UI-side remote resolver to obtain active Git repository context from the workspace-side Git extension.

## Best solution

A maintainer can transfer or consolidate the underlying API work in microsoft/vscode, where the Git extension and extension-host APIs are owned. The likely solution is a JSON-serializable Git command or another supported cross-host API; the Containers integration should then consume it.
