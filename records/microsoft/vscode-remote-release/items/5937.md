# Issue #5937 — Azure CLI credentials not passed through to container

[https://github.com/microsoft/vscode-remote-release/issues/5937](https://github.com/microsoft/vscode-remote-release/issues/5937)

## Summary

This remains a valid, correctly routed Dev Containers feature request. The current Azure CLI Feature installs the CLI but does not forward authentication, while a manual bind mount is an incomplete security- and platform-sensitive workaround.

## Change summary

Allow Azure CLI authentication from the local host to be reused securely inside a Dev Container.

## Best solution

The Dev Containers component should define an explicit, secure, opt-in mechanism for reusing host Azure CLI authentication without requiring every project to bind-mount the host credential cache. The design should account for container users, cache permissions, and host/container platform differences.
