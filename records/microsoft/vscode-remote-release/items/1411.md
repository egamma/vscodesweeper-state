# Issue #1411 — Remote SSH: provide File dialog boxes similar to when running locally

[https://github.com/microsoft/vscode-remote-release/issues/1411](https://github.com/microsoft/vscode-remote-release/issues/1411)

## Summary

Keep this dialog-parity request open and route it to SSH. Existing remote browsing and SSHFS workarounds do not establish that the requested dialog experience is available, and no verified canonical covers the full ask.

## Change summary

Provide a conventional file/folder dialog for remote SSH files while preserving local/remote selection, including bulk folder selection for workspaces.

## Best solution

Improve the remote file picker with conventional browsing and multi-selection while preserving the local/remote distinction. SSH owners should coordinate with the VS Code workbench dialog owners; a maintainer can transfer this to microsoft/vscode if the shared picker owns the entire change.
