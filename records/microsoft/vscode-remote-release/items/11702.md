# Issue #11702 — Can't cannot via SSH: `Cannot reconnect. Please reload the window.`

[https://github.com/microsoft/vscode-remote-release/issues/11702](https://github.com/microsoft/vscode-remote-release/issues/11702)

## Summary

Keep open as a confirmed Remote - SSH reconnection regression. The reporter reproduced it across multiple hosts, devices, and networks, and another user confirmed that current versions fail while VS Code 1.122.1 works.

## Change summary

Remote - SSH connects successfully but loses the server within about a minute and cannot reconnect without reloading the window.

## Best solution

The SSH component should investigate the server and exec-server lifecycle regression after VS Code 1.122.1; the logs show the server being killed, a successful replacement SSH connection, and subsequent timeout rather than recovery.
