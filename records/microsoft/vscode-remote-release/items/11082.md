# Issue #11082 — SSE connections wont close ( golang )

[https://github.com/microsoft/vscode-remote-release/issues/11082](https://github.com/microsoft/vscode-remote-release/issues/11082)

## Summary

Keep open: the sample and browser-tab closure steps suffice to retest the reported forwarding defect, although the July 2025 builds are not identified and no current reproduction is confirmed. The sample also has a cancellation-handling flaw that must be separated from any forwarding failure.

## Change summary

Closing a browser tab accessing an SSE endpoint through Remote - SSH port forwarding reportedly leaves the remote connection active.

## Best solution

The SSH component owner should compare cancellation through VS Code forwarding with direct access or ordinary SSH forwarding, using a handler that returns when its request context is canceled. If only VS Code forwarding retains the connection, fix disconnect propagation in the responsible forwarding path.
