# Issue #4866 — SingleSignOn Federation

[https://github.com/microsoft/vscode-remote-release/issues/4866](https://github.com/microsoft/vscode-remote-release/issues/4866)

## Summary

Keep open: seamless enterprise identity federation into Remote - SSH remains unproven as a shipped capability. The thread explicitly raises token-exposure risks requiring human review, and the maintainer proposed exploring an authentication-provider integration rather than declining the request.

## Change summary

Automate enterprise Windows SSO and federated cloud authentication for Remote - SSH without manual token files or unsupported scripts.

## Best solution

The SSH and authentication owners should define a secure, supported identity-provider integration for cloud connection helpers, coordinating AWS-specific behavior with AWS Toolkit. Establish token suitability, consent, lifetime, and handoff boundaries before selecting an implementation.
