# Issue #9397 — Allow the user to specify inputs for .devcontainer.json

[https://github.com/microsoft/vscode-remote-release/issues/9397](https://github.com/microsoft/vscode-remote-release/issues/9397)

## Summary

Keep open: documented build-argument substitution does not provide the requested interactive prompts. The older input-variable request covers shell-derived run arguments, not this report's promptString-based build configuration.

## Change summary

Allow devcontainer.json to declare interactive inputs and substitute their values into configuration properties such as build.args.

## Best solution

The Dev Containers component should support declarative prompts before resolving build arguments, coordinated with the Dev Container specification. Retain this product-side request because environment substitution and the related runArgs proposal do not deliver its interactive build workflow.
