# Issue #462 — FR: configurable Max wait time for initial connect

[https://github.com/microsoft/vscode-remote-release/issues/462](https://github.com/microsoft/vscode-remote-release/issues/462)

## Summary

The requested configuration now exists: `remote.SSH.connectTimeout` controls the initial SSH connection timeout in seconds. A commenter confirmed that increasing it helped in the same kind of environment.

## Change summary

Allow users with slow proxy and hardware-key authentication flows to increase the initial Remote - SSH connection timeout.

## Best solution

Keep the existing `remote.SSH.connectTimeout` setting as the supported way to accommodate slow initial SSH connections; users can raise its default value of 15 seconds as needed.
