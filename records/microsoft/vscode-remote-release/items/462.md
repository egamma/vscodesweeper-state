# Issue #462 — FR: configurable Max wait time for initial connect

[https://github.com/microsoft/vscode-remote-release/issues/462](https://github.com/microsoft/vscode-remote-release/issues/462)

## Summary

The requested initial-connection timeout is now configurable through remote.SSH.connectTimeout. Public release notes document the setting, and an affected commenter confirms that increasing it helped in a comparable environment.

## Change summary

Allow a longer initial SSH connection timeout for connections involving multiple proxies and hardware-key interaction.

## Best solution

Use the existing remote.SSH.connectTimeout setting rather than adding another timeout control. Account for a host's SSH ConnectTimeout option, which takes precedence according to the documented behavior.
