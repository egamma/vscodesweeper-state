# Issue #9958 — remotePlatform notification is sometimes shown unnecessarily

[https://github.com/microsoft/vscode-remote-release/issues/9958](https://github.com/microsoft/vscode-remote-release/issues/9958)

## Summary

Keep open for Remote - SSH to investigate redundant platform notifications and per-host settings writes despite wildcard configuration. The Windows connection-mode default is now documented, but no fix is confirmed; the described configuration and connection flow suffice to retest.

## Change summary

Windows SSH connections show a platform-selection confirmation and add explicit host settings even when a wildcard already specifies the platform.

## Best solution

Remote - SSH should reuse the matching wildcard platform without implying a new selection or adding redundant host entries. Verify both connection modes and the Dev Containers-over-SSH variant; enabling local-server mode is a workaround, not proof that the default-mode behavior is resolved.
