# Issue #9958 — remotePlatform notification is sometimes shown unnecessarily

[https://github.com/microsoft/vscode-remote-release/issues/9958](https://github.com/microsoft/vscode-remote-release/issues/9958)

## Summary

Keep open as a confirmed Windows-specific Remote - SSH settings bug: the effective `useLocalServer` default differs from the value shown in Settings, causing redundant platform notification and explicit host entries despite a matching wildcard.

## Change summary

Remote - SSH should honor wildcard `remotePlatform` entries without notifying users or adding redundant host entries, and Settings should display the effective Windows default for `useLocalServer`.

## Best solution

Remote - SSH should consistently resolve and display the effective `remote.SSH.useLocalServer` value on Windows, then avoid persisting an explicit `remotePlatform` entry when an existing wildcard already supplies the platform.
