# Issue #5322 — Conditional mounting

[https://github.com/microsoft/vscode-remote-release/issues/5322](https://github.com/microsoft/vscode-remote-release/issues/5322)

## Summary

The open Dev Containers specification proposal owns this exact request for optional bind mounts. Consolidating there keeps the cross-tool behavior and design discussion in the canonical tracker.

## Change summary

Allow dev containers to skip bind mounts whose host source does not exist.

## Best solution

Define and implement optional-bind behavior through https://github.com/devcontainers/spec/issues/132 so all Dev Container implementations can consistently support it.
