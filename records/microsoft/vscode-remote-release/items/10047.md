## Summary

Verified duplicate: the open, broader issue tracks repositoryConfigurationPaths failing when Dev Containers runs through WSL because host paths are not translated for the WSL-side command.

## Change summary

Dev Containers passes a Windows repository configuration path unchanged to its WSL-side CLI, preventing the external devcontainer.json from being read.

## Best solution

Consolidate the path-translation defect on https://github.com/microsoft/vscode-remote-release/issues/3708; its fix should ensure repositoryConfigurationPaths are resolved in the environment where the Dev Containers CLI runs.
