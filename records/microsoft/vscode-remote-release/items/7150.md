[https://github.com/microsoft/vscode-remote-release/issues/7150](https://github.com/microsoft/vscode-remote-release/issues/7150)

## Summary

Consolidate this report into the older, open custom-certificate issue: its discussion explicitly covers the same host-side Feature download failures, not merely related container certificate configuration.

## Change summary

Dev Containers 0.251.0 fails to download Features behind a corporate certificate authority despite certificates being installed by the project's Dockerfile.

## Best solution

Track the remaining certificate-handling work in https://github.com/microsoft/vscode-remote-release/issues/6092. Preserve this report's 0.245.2-to-0.251.0 regression and WSL-specific host-download details there, distinguishing registry downloads from commands executed inside the image.
