[https://github.com/microsoft/vscode-remote-release/issues/8489](https://github.com/microsoft/vscode-remote-release/issues/8489)

## Summary

This remains a valid, correctly routed feature request. Current Dev Containers support for Docker-compatible CLIs does not cover udocker's more limited runtime model, and no broader canonical issue owns this CLI-specific work.

## Change summary

Add Dev Containers compatibility with udocker so users without permission to install Docker can develop inside its userspace containers.

## Best solution

The Containers owner should assess a udocker-specific integration, likely involving the open https://github.com/devcontainers/cli project, while accounting for udocker's lack of image-building and full Docker CLI compatibility.
