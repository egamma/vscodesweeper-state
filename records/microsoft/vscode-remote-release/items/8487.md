# Issue #8487 — Can't attach to devcontainer "ln: failed to access ‘/tmp/user/1000/vscode-wayland-xxxxxx.sock’: Permission denied"

[https://github.com/microsoft/vscode-remote-release/issues/8487](https://github.com/microsoft/vscode-remote-release/issues/8487)

## Summary

The attach failure remains reproducible on a recent Dev Containers release, and disabling Wayland socket mounting does not prevent the related X11 setup from failing on inaccessible paths. The issue is already correctly routed to the containers component.

## Change summary

Dev Containers cannot attach when its Wayland or X11 socket setup encounters container paths that the active user cannot access or create.

## Best solution

The Dev Containers attach helper should avoid treating unavailable graphical socket setup as fatal when no display is available, while honoring `dev.containers.mountWaylandSocket` consistently. It should report unsafe `/tmp` permissions clearly rather than attempting a potentially unsafe automatic permission change.
