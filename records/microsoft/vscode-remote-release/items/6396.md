# Issue #6396 — Podman: systemd not working

[https://github.com/microsoft/vscode-remote-release/issues/6396](https://github.com/microsoft/vscode-remote-release/issues/6396)

## Summary

This is a container configuration question rather than a Dev Containers defect: `containerUser: "vscode"` starts the container as a non-root user, while systemd system mode must start as root.

## Change summary

Run a Podman-based CentOS dev container with systemd as PID 1 while using an unprivileged user for the editor and terminal.

## Best solution

Start the container as root with `containerUser: "root"`, retain `remoteUser: "vscode"` for the editor session, disable command overriding, and use `sudo systemctl` inside the container.
