# Issue #4024 — Automatically add SSH keys to ssh-agent

[https://github.com/microsoft/vscode-remote-release/issues/4024](https://github.com/microsoft/vscode-remote-release/issues/4024)

## Summary

Keep open as an accepted Dev Containers feature request. Current documentation still requires users to load keys manually, while the thread identifies security reasons not to load them automatically without explicit opt-in.

## Change summary

Provide an opt-in way to load macOS SSH keys before forwarding the host agent into a Dev Container, or notify users when the forwarded agent has no identities.

## Best solution

The Dev Containers extension should offer an explicit user setting or actionable notification when the forwarded SSH agent is empty, preserving users' control over when private-key identities become available.

## Evidence

- **current capability:** The current documentation at https://code.visualstudio.com/remote/advancedcontainers/sharing-git-credentials says the extension forwards a running local SSH agent but instructs users to run `ssh-add`; it does not provide automatic or opt-in identity loading.
