# Issue #6558 — Pre-built image not used as-is

[https://github.com/microsoft/vscode-remote-release/issues/6558](https://github.com/microsoft/vscode-remote-release/issues/6558)

## Summary

Keep open: the controlled reproduction shows that adding a Dev Container Feature causes the extension to request another build after `devcontainer build`, and a maintainer identified the missing shared checksum as the cause. The team-authored issue has no verified fix or canonical duplicate.

## Change summary

Make a container produced by `devcontainer build` retain enough configuration identity for the Dev Containers extension to use it without prompting for a redundant rebuild.

## Best solution

The Dev Containers extension and CLI should share or persist the configuration checksum, potentially on the image or container, so opening a freshly built configuration recognizes it as current.
