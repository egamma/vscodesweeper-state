# Issue #5620 — Extension are not installed when configured in devcontainer.json

[https://github.com/microsoft/vscode-remote-release/issues/5620](https://github.com/microsoft/vscode-remote-release/issues/5620)

## Summary

Verified duplicate: the open canonical issue tracks Dev Container extension installation failing because the VS Code Server does not trust corporate or self-signed certificates.

## Change summary

Use the container's configured CA certificates when installing extensions declared in devcontainer.json, and surface certificate failures in the Dev Containers log.

## Best solution

Consolidate on https://github.com/microsoft/vscode-remote-release/issues/2987, retaining this report's evidence that the failure is hidden from the container-build log and that NODE_EXTRA_CA_CERTS restores installation.
