# Issue #11654 — Remote SSH Extension Host repeatedly exits with code 7 when extensions activate

[https://github.com/microsoft/vscode-remote-release/issues/11654](https://github.com/microsoft/vscode-remote-release/issues/11654)

## Summary

Keep open as likely environment-caused: the reporter and another user report recovery after DNS/hosts corrections, not a shipped extension fix. The navigator errors alone do not establish the cause of the code-7 restart loop or a verified duplicate.

## Change summary

The shared remote extension host repeatedly exits with code 7 after extension activation on an Ubuntu SSH host.

## Best solution

Separate the reported DNS/hosts configuration failure from the earlier extension activation errors. If crashes remain with corrected networking, the SSH/server owner should identify the fatal exception before deciding whether a maintainer can transfer the remaining extension-host defect to microsoft/vscode.
