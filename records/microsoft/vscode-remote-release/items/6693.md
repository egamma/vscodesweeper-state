# Issue #6693 — Support ssh to IBM z/OS (USS)

[https://github.com/microsoft/vscode-remote-release/issues/6693](https://github.com/microsoft/vscode-remote-release/issues/6693)

## Summary

Keep the accepted z/OS USS support request open. Later logs show that resolving the original grep incompatibility did not deliver support, and the related s390x request tracks a different operating-system requirement.

## Change summary

Enable full Remote - SSH development sessions on IBM z/OS UNIX System Services.

## Best solution

The SSH and VS Code Server owners should assess a supported z/OS USS runtime and installation path, including platform detection and encoding compatibility. Retain this issue for the z/OS-specific work rather than consolidating it into Linux-on-Z architecture support.
