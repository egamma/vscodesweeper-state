# Issue #10041 — [devcontainer] Move docker (compose) path to Remote section / Allow override of settings by Remote section

[https://github.com/microsoft/vscode-remote-release/issues/10041](https://github.com/microsoft/vscode-remote-release/issues/10041)

## Summary

Keep open in the Backlog: a maintainer confirmed that Dev Containers cannot currently access the active WSL, SSH, or Tunnel settings while connecting, so the requested per-remote container-engine configuration remains a real gap.

## Change summary

Allow Docker, Compose, and WSL execution settings to vary with the active outer remote environment instead of requiring global changes.

## Best solution

Dev Containers should resolve these host-side settings from the active WSL, SSH, or Tunnel authority before starting a nested container. If the extension API cannot expose remote-scoped values during connection, the containers and VS Code core owners should establish an accessible per-authority configuration mechanism.
