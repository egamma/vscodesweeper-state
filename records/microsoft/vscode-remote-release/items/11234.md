# Issue #11234 — Remote tunnel disconnects after opening link from integrated terminal in new window

[https://github.com/microsoft/vscode-remote-release/issues/11234](https://github.com/microsoft/vscode-remote-release/issues/11234)

## Summary

The bug has a video reproduction and an independent confirmation on a later VS Code release. It is currently mislabeled as SSH and should be routed to the tunnels connection owners.

## Change summary

Opening a terminal-linked remote directory in a new window disrupts the original tunnel connection and can cause repeated disconnects.

## Best solution

Opening the linked directory should preserve the current remote authority without destabilizing the original tunnel. The tunnels owner should determine whether the fix belongs in the tunnel lifecycle or whether a maintainer should transfer it to microsoft/vscode for the integrated-terminal link provider.
