# Issue #11269 — Vscode-server component insists to being downloaded - problem with slow internet users.

[https://github.com/microsoft/vscode-remote-release/issues/11269](https://github.com/microsoft/vscode-remote-release/issues/11269)

## Summary

A real server-lifecycle gap remains: interrupted or failed Remote-SSH installations discard a completed or partial server package and restart the full download. Keep this open as a feature request routed to the server installation path.

## Change summary

Cache and resume VS Code Server downloads, preserve verified packages after installation failures, and expose download progress in the Remote-SSH UI.

## Best solution

The Remote-SSH/VS Code Server installer should retain downloads by commit hash, resume interrupted transfers when supported, and reuse a verified archive after post-download installation failures rather than fetching it again.
