# Issue #11269 — Vscode-server component insists to being downloaded - problem with slow internet users.

[https://github.com/microsoft/vscode-remote-release/issues/11269](https://github.com/microsoft/vscode-remote-release/issues/11269)

## Summary

Keep open for resumable downloads and reuse of matching server packages after installation failures. Existing download-location controls do not establish this capability, and the verified related issues do not own the full request.

## Change summary

Preserve and resume VS Code Server downloads, reuse completed matching packages after failed installation, and make download progress clearer over slow connections.

## Best solution

The SSH/server installation owners should retain packages keyed by commit, platform, and architecture across retries, support resumption where possible, and expose useful progress. Investigate the recorded rename failure separately; reusing an older server after a client update is not equivalent to reusing the matching package.
