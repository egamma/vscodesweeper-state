# Issue #2511 — Download via terminal

[https://github.com/microsoft/vscode-remote-release/issues/2511](https://github.com/microsoft/vscode-remote-release/issues/2511)

## Summary

The requested terminal-based remote-file download remains a genuine capability gap, with no current CLI option or verified canonical issue covering it. Keep it open for a code-server design decision.

## Change summary

Add a remote-terminal command such as `code --download <path>` for downloading files outside the open workspace to the local machine.

## Best solution

The code-server/remote owner should provide a transport-independent CLI command that transfers a remote path through the connected client, including local destination selection and clear handling when no client is attached.
