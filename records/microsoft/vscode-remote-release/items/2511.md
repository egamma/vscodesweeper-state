# Issue #2511 — Download via terminal

[https://github.com/microsoft/vscode-remote-release/issues/2511](https://github.com/microsoft/vscode-remote-release/issues/2511)

## Summary

Keep open: the documented remote terminal CLI does not establish a way to invoke Download for an arbitrary remote path. Related download requests cover Explorer workflows, not this terminal entry point.

## Change summary

Allow downloading remote files outside the current workspace through a terminal command such as code --download file.

## Best solution

Expose the existing remote-to-local Download operation through the remote CLI, accepting paths outside the workspace and prompting for a local destination. The remote file-I/O and CLI owners should determine the shared implementation boundary.

- **Fit:** aligned
- **Reason:** Making remote files accessible through the integrated terminal extends the existing remote-development workflow without changing its architecture.
