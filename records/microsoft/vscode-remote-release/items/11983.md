# Issue #11983 — vsce-sign isn't forward compatible with OpenSSL 4 which is the system default in Fedora 45 and probably other distros

[https://github.com/microsoft/vscode-remote-release/issues/11983](https://github.com/microsoft/vscode-remote-release/issues/11983)

## Summary

The OpenSSL 4 compatibility failure is already tracked in an open VS Code core issue, including a Fedora 45 VS Code Server reproduction and the same OpenSSL 3 workaround. This is the shared extension-signature verifier failing after SSH has connected, not an SSH connection defect.

## Change summary

Allow remote extension installation on OpenSSL 4 systems without manually installing OpenSSL 3 compatibility libraries.

## Best solution

Consolidate the bundled verifier compatibility work in https://github.com/microsoft/vscode/issues/338194, preserving this minimal Fedora 45 Remote-SSH reproduction. Track the misleading error separately in https://github.com/microsoft/vscode/issues/349294.
