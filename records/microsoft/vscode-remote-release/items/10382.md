# Issue #10382 — Case-sensitivity when opting out of VSCode extensions

[https://github.com/microsoft/vscode-remote-release/issues/10382](https://github.com/microsoft/vscode-remote-release/issues/10382)

## Summary

Keep open for Dev Containers to retest case-insensitive extension exclusions. The supplied configuration and casing-only comparison suffice to reproduce the reported behavior; releases have advanced since VS Code 1.94.1, but no fix or current reproduction is established.

## Change summary

A lowercase extension exclusion fails to suppress a Feature-provided extension whose publisher ID uses uppercase letters.

## Best solution

Dev Containers should compare extension exclusion IDs case-insensitively while preserving the existing minus-prefixed opt-out syntax. Retest the supplied AWS CLI Feature example on the current extension before deciding whether a change remains necessary.
