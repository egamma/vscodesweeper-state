## Summary

Verified duplicate of the open Compose-profile support issue: its discussion already covers selecting a profiled service whose image is never built. Consolidate this report's minimal Features-based reproduction there.

## Change summary

Dev Containers skips building the selected Compose service when it belongs to an inactive profile, then fails to find the generated image.

## Best solution

Resolve profile-aware building in https://github.com/microsoft/vscode-remote-release/issues/5795, preserving this report's proposal to explicitly target the selected service during the build step. Include its Features-generated image case in the canonical issue's scope.
