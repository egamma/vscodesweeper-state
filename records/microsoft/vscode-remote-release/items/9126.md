# Issue #9126 — Basic node js container template fails

[https://github.com/microsoft/vscode-remote-release/issues/9126](https://github.com/microsoft/vscode-remote-release/issues/9126)

## Summary

Keep open for the maintainer-accepted improvement to prevent selecting incompatible template/Feature combinations. The linked spec proposal remains open and does not itself deliver the extension's selection behavior; this team-authored item has no verified factual closing basis.

## Change summary

Prevent offering the Node.js-via-nvm Feature with an incompatible Alpine base image.

## Best solution

The containers component should detect incompatible template/Feature combinations and disable or clearly flag them before building, coordinated with compatibility metadata work in https://github.com/devcontainers/spec/issues/58. Retain this issue for the extension-side behavior rather than closing it against the spec proposal.
