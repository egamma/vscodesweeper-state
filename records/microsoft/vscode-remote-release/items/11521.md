# Issue #11521 — Angular port forwarding hangs

[https://github.com/microsoft/vscode-remote-release/issues/11521](https://github.com/microsoft/vscode-remote-release/issues/11521)

## Summary

Keep open: multiple users confirmed the Angular forwarding failure and the IPv4-binding workaround, not a shipped fix. The existing demo steps and address-family comparison support retesting without asking the reporter to reconstruct the report.

## Change summary

An Angular development server inside a container is unreachable through automatically or explicitly forwarded port 4200 unless its host is set to 127.0.0.1.

## Best solution

The containers owner should compare forwarding to Angular listeners on IPv4 and IPv6 loopback and identify where address-family handling fails. Forwarding should reach the application's actual listener without requiring changes to /etc/hosts; investigate shared server forwarding ownership before prescribing an IPv4-only default.
