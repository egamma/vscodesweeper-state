# Issue #11521 — Angular port forwarding hangs

[https://github.com/microsoft/vscode-remote-release/issues/11521](https://github.com/microsoft/vscode-remote-release/issues/11521)

## Summary

Verified duplicate of the older, open IPv6 port-forwarding issue: its discussion describes the same dev-container server receiving no browser response until IPv4 binding is forced. The confirmed Angular workaround does not establish a shipped fix.

## Change summary

An Angular development server in a container is inaccessible through forwarded port 4200 when localhost resolves to IPv6.

## Best solution

Consolidate this report into https://github.com/microsoft/vscode-remote-release/issues/7029 and address IPv6 loopback forwarding for container development servers. Preserve the Fedora/Debian Angular reproduction and confirmed IPv4-binding workaround.
