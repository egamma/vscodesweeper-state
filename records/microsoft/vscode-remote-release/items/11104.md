# Issue #11104 — Remote SSH Support IPV6 scp

[https://github.com/microsoft/vscode-remote-release/issues/11104](https://github.com/microsoft/vscode-remote-release/issues/11104)

## Summary

The log shows a plausible IPv6 formatting defect in the SCP fallback, but this remains a single report on Remote - SSH 0.120.0 without the requested external-command test or a current-version confirmation.

## Change summary

When connecting directly to an IPv6 host, Remote - SSH's local-download fallback passes an unbracketed IPv6 destination to SCP, preventing server installation.

## Best solution

Remote - SSH should preserve bracketed IPv6 literals when constructing the SCP destination, or consistently resolve the connection through an SSH config alias. A current log and external-command result are needed to establish whether the defect remains.
