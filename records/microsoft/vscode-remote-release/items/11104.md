# Issue #11104 — Remote SSH Support IPV6 scp

[https://github.com/microsoft/vscode-remote-release/issues/11104](https://github.com/microsoft/vscode-remote-release/issues/11104)

## Summary

Keep open for Remote - SSH: the complete log shows successful IPv6 authentication followed by an SCP destination missing IPv6 brackets. The supplied URI and transfer logs suffice to retest on current releases; no confirmed fix or open canonical covering this transfer failure was found.

## Change summary

Remote - SSH drops IPv6 brackets when constructing the SCP destination for locally downloaded server files, causing installation to fail.

## Best solution

Remote - SSH should preserve the username and correctly bracket literal IPv6 addresses in SCP destinations when connecting through a remote URI. Retest the supplied URI with local server download on a current release; successful SSH authentication must lead to transfer to the same IPv6 host.
