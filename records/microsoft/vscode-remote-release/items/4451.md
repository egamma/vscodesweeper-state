# Issue #4451 — Remote code command precedence on PATH

[https://github.com/microsoft/vscode-remote-release/issues/4451](https://github.com/microsoft/vscode-remote-release/issues/4451)

## Summary

This remains the canonical issue for remote terminals resolving the host-installed `code` command before the remote CLI. A maintainer reproduced the macOS behavior, and reports through 2025 show that users still require shell-specific PATH workarounds.

## Change summary

Ensure the remote `code` CLI takes precedence over a host-installed VS Code CLI in Remote-SSH integrated terminals.

## Best solution

Remote-SSH and the integrated terminal should establish the remote CLI PATH entry after shell initialization, without changing terminals outside the remote VS Code session. The SSH owner should coordinate with VS Code core if post-initialization terminal integration is required.
