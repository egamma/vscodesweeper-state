# Issue #4451 — Remote code command precedence on PATH

[https://github.com/microsoft/vscode-remote-release/issues/4451](https://github.com/microsoft/vscode-remote-release/issues/4451)

## Summary

Keep this as the existing tracking issue for remote CLI PATH precedence. The remote CLI layout and terminal integration have changed since the maintainer's historical reproduction, but the supplied macOS setup suffices to retest and no verified fix establishes resolution.

## Change summary

On a macOS SSH host with desktop VS Code installed, shell initialization places the desktop code command ahead of the remote session's CLI.

## Best solution

The SSH/server owners should coordinate with the core terminal team to preserve remote CLI precedence after macOS login-shell initialization, without changing ordinary local terminals or unrelated SSH sessions. Retest the documented setup with current shell integration before choosing the implementation.
