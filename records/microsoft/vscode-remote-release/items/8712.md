# Issue #8712 — Allow for default container mounts in user settings

[https://github.com/microsoft/vscode-remote-release/issues/8712](https://github.com/microsoft/vscode-remote-release/issues/8712)

## Summary

A real capability gap remains: Dev Containers supports project-defined mounts but no direct user setting for mounts applied to every container. The correctly routed Backlog request should remain open.

## Change summary

Allow users to configure personal host-directory mounts that are automatically applied to every Dev Container without changing shared devcontainer.json files.

## Best solution

The Dev Containers extension should provide a user-scoped default-mounts setting and merge those entries with project-defined mounts, preserving personal configuration outside shared repositories.
