# Issue #11447 — SendEnv does not work

[https://github.com/microsoft/vscode-remote-release/issues/11447](https://github.com/microsoft/vscode-remote-release/issues/11447)

## Summary

The log shows Remote - SSH reusing an already-running server, whose environment intentionally remains fixed from its initial SSH session. Restarting that server is the established way to apply newly sent environment variables.

## Change summary

Make environment variables forwarded through SSH SendEnv available in Remote - SSH terminals.

## Best solution

Keep the existing SSH-server environment lifecycle and restart the remote VS Code Server after changing SendEnv variables. A failure after a confirmed fresh server start is separately tracked by https://github.com/microsoft/vscode-remote-release/issues/11706.
