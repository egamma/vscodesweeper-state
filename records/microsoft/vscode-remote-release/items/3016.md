# Issue #3016 — CL arg "--disable-extensions" should not disable remote extensions in remote setup

[https://github.com/microsoft/vscode-remote-release/issues/3016](https://github.com/microsoft/vscode-remote-release/issues/3016)

## Summary

Keep open: preserving indispensable remote resolvers while disabling other extensions remains an unverified capability gap. The existing bug classification and the author's explicit proposal rule out a decline close; no open canonical or confirmed fix was found.

## Change summary

Allow --disable-extensions to isolate extension tests without disabling the remote resolver needed to open their remote workspace.

## Best solution

Remote-development owners should coordinate with VS Code core on retaining the active remote resolver during extension-isolated test launches. A maintainer can transfer this to microsoft/vscode if CLI extension-enablement policy owns the entire change.

## Evidence

- **Concrete trigger and workaround:** https://github.com/microsoft/vscode/issues/97844 describes launching Python extension tests over SSH on VS Code 1.45.0 and Ubuntu 16.04, producing a disconnected development host and a required Remote - SSH extension message. https://github.com/microsoft/vscode/issues/97844#issuecomment-629118001 confirms that removing --disable-extensions lets the tests run, but that workaround sacrifices extension isolation.
- **Explicit improvement proposal:** After the original support report closed, https://github.com/microsoft/vscode/issues/97844#issuecomment-630074112 explicitly identifies this issue as the follow-up improvement. Its existing bug label also bars a decline close without a later overriding maintainer decision.
- **Existing capability check:** https://code.visualstudio.com/docs/configure/command-line documents --disable-extensions as disabling all installed extensions. Profiles and isolated extension directories offer alternative setups, but the documentation does not establish an automatic exemption for the remote resolver under this flag.
- **Closed broader request:** https://github.com/microsoft/vscode-remote-release/issues/249 includes launching with all extensions disabled except remote resolvers, but was closed as out-of-scope in https://github.com/microsoft/vscode-remote-release/issues/249#issuecomment-1893095170. It is not an eligible duplicate target or evidence of implementation; that decline does not override this issue's accepted bug classification.
