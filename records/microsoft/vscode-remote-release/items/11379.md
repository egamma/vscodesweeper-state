# Issue #11379 — Unable to commit and sign because of GPG signing error in devcontainer

[https://github.com/microsoft/vscode-remote-release/issues/11379](https://github.com/microsoft/vscode-remote-release/issues/11379)

## Summary

The reporter confirmed signing works after disabling Dev Containers: Execute In WSL and restarting the container. The enabled setting selected WSL, where GPG was not configured, rather than Windows, where the signing key was installed.

## Change summary

Enable signed commits in a dev container using Windows Gpg4win with Docker Desktop's WSL2 engine.

## Best solution

Keep Execute In WSL disabled for this Windows-hosted workflow so the extension uses the configured Windows GPG installation; no extension change is established as necessary.
