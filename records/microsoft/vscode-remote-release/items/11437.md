# Issue #11437 — Command WSL: Connect to WSL in New Window not found when connected via Remote - SSH

[https://github.com/microsoft/vscode-remote-release/issues/11437](https://github.com/microsoft/vscode-remote-release/issues/11437)

## Summary

Keep open for the WSL owner: the supplied steps and versions suffice to retest command availability from an SSH-connected window. Current documentation describes additional WSL-over-SSH functionality, but neither it nor the related threads establishes that this missing-command defect was fixed.

## Change summary

WSL connection commands fail with command-not-found errors when invoked from an SSH-connected VS Code window.

## Best solution

The WSL extension should make its new-window connection command usable from an SSH-connected Windows client, or gracefully explain any unsupported context. Retest the supplied Linux SSH-target scenario and distinguish opening local WSL from connecting to WSL on a remote Windows host.
