# Issue #9627 — excessive docker context ls calls

[https://github.com/microsoft/vscode-remote-release/issues/9627](https://github.com/microsoft/vscode-remote-release/issues/9627)

## Summary

Keep open: the excessive polling remains relevant, with a matching report on VS Code 1.108.1 in January 2026. The issue is already correctly classified and routed to the Dev Containers backlog.

## Change summary

Dev Containers repeatedly invokes `docker context ls`, causing unnecessary process churn, log spam, battery drain, and potentially high CPU usage.

## Best solution

Dev Containers should restore the intended once-per-minute and event-driven context refresh behavior, avoiding independent one-second polling in every VS Code window; sharing or caching the result would further reduce process churn.
