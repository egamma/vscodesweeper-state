# Issue #9627 — excessive docker context ls calls

[https://github.com/microsoft/vscode-remote-release/issues/9627](https://github.com/microsoft/vscode-remote-release/issues/9627)

## Summary

Keep this accepted Dev Containers performance debt open: the October 2026 report confirms two-second polling still occurs without a dev-container workspace or Docker Desktop running. The newer related report does not supersede this older Backlog item.

## Change summary

Reduce or make configurable the repeated per-window Docker context discovery that consumes CPU, battery, and logging resources even when Dev Containers is idle.

## Best solution

Dev Containers should avoid continuous per-window Docker context discovery while idle, using demand-driven refresh, caching, or a configurable interval while preserving context switching. Retain this older accepted item as the consolidation point for matching polling reports.
