# Issue #9923 — Support self-signed certs / custom CAs for devtunnels

[https://github.com/microsoft/vscode-remote-release/issues/9923](https://github.com/microsoft/vscode-remote-release/issues/9923)

## Summary

Keep this accepted Tunnels feature request open as the project's existing consolidation point for custom-CA support. Two users confirmed a Windows workaround, but that does not establish consistent system-trust integration or a shipped resolution of the full request.

## Change summary

Allow desktop Remote - Tunnels connections to trust enterprise and custom certificate authorities consistently with other VS Code networking.

## Best solution

The Tunnels component should provide and document reliable custom-CA trust configuration while preserving certificate validation. Use this issue to track the remaining system-store and cross-platform support beyond the reported NODE_EXTRA_CA_CERTS workaround.
