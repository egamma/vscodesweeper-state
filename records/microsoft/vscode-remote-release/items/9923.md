# Issue #9923 — Support self-signed certs / custom CAs for devtunnels

[https://github.com/microsoft/vscode-remote-release/issues/9923](https://github.com/microsoft/vscode-remote-release/issues/9923)

## Summary

Keep this accepted Backlog feature request open as the canonical tracker for custom-CA support in Remote Tunnels. NODE_EXTRA_CA_CERTS is a confirmed workaround, but its platform-specific path handling does not fully address consistent system-CA and proxy-interception support.

## Change summary

Allow Remote Tunnels connections to trust self-signed or organization-managed certificate authorities consistently.

## Best solution

The tunnels component should provide a documented, supported custom-CA mechanism and consistently honor the applicable system trust store or VS Code certificate configuration. Preserve NODE_EXTRA_CA_CERTS as a workaround while removing its Windows path-format pitfalls.
