# Issue #11449 — Devcontainer VSCode freezes while activating extensions

[https://github.com/microsoft/vscode-remote-release/issues/11449](https://github.com/microsoft/vscode-remote-release/issues/11449)

## Summary

The report strongly suggests restored port-forwarding state freezes the Dev Container window, matching the workaround documented in an older issue. There is no independent current-version reproduction or diagnostic log showing where restoration stalls, so a current retest and focused logs are needed.

## Change summary

Opening a compose-based Dev Container freezes VS Code while restoring ports declared both in devcontainer.json and Docker Compose.

## Best solution

Dev Containers should restore forwarded ports without blocking the window when the same ports are also published by Docker Compose, and should discard or recover from invalid persisted tunnel state. A minimal current-version reproduction plus the Dev Containers and renderer logs should identify whether the remaining defect is in container port restoration or VS Code core.
