# Issue #10415 — Port forwarding stalls (after macOS sleep?)

[https://github.com/microsoft/vscode-remote-release/issues/10415](https://github.com/microsoft/vscode-remote-release/issues/10415)

## Summary

Keep open as the canonical Remote - SSH port-forwarding reliability bug: numerous users confirm that forwarded ports remain listed but stop passing data after sleep or reconnection, including reports across macOS, Windows, and ChromeOS through March 2026.

## Change summary

Remote - SSH port forwards can accept connections but stop transferring data after the client sleeps or reconnects, requiring users to delete and recreate the forward.

## Best solution

Remote - SSH should detect and replace stale forwarding transports after sleep or reconnection while preserving the configured port entries. The newer overlapping report https://github.com/microsoft/vscode-remote-release/issues/10568 should be consolidated into this older, broader, and better-supported canonical issue.
