# Issue #10415 — Port forwarding stalls (after macOS sleep?)

[https://github.com/microsoft/vscode-remote-release/issues/10415](https://github.com/microsoft/vscode-remote-release/issues/10415)

## Summary

Keep open: multiple users confirm forwarded ports accepting connections but failing to carry data after sleep, with reports continuing into March 2026. The socat example provides actionable reproduction steps; neither a confirmed fix nor a qualifying canonical was established.

## Change summary

SSH port forwards stop transmitting data after prolonged laptop sleep despite remaining active, requiring removal and recreation.

## Best solution

The SSH component should ensure forwarded ports resume carrying traffic after sleep or reconnection without manual recreation. Compare failure-time logs with the related reconnect and shared-forward reports before deciding whether the defect belongs in the extension or VS Code core.
