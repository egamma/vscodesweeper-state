# Issue #11035 — Cannot clone repository in container volume with ssh on podman

[https://github.com/microsoft/vscode-remote-release/issues/11035](https://github.com/microsoft/vscode-remote-release/issues/11035)

## Summary

The attached log identifies a host SSH-agent configuration issue rather than a Dev Containers defect: no SSH agent socket was available to forward into the bootstrap container.

## Change summary

Cloning an SSH repository into a container volume fails with public-key authentication when using Podman Desktop on Windows.

## Best solution

Configure and start the host SSH agent, load the private key with `ssh-add`, and retry the documented clone-in-volume flow; no Dev Containers change is indicated by the current evidence.
