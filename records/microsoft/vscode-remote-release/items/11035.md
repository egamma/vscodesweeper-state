# Issue #11035 — Cannot clone repository in container volume with ssh on podman

[https://github.com/microsoft/vscode-remote-release/issues/11035](https://github.com/microsoft/vscode-remote-release/issues/11035)

## Summary

Keep open for Dev Containers investigation: the concrete reproduction and attached log suffice to retest the Podman SSH-clone failure. Newer reports show Windows-agent forwarding working in other configurations, but neither resolution of this report nor a matching canonical is established.

## Change summary

Cloning an SSH repository into a container volume fails with publickey authentication errors using Podman Desktop on Windows.

## Best solution

The Dev Containers owner should retest the supplied Windows/WSL Podman setup and distinguish missing agent configuration from an agent-discovery or forwarding defect. Ensure an available, loaded host agent reaches the bootstrap clone without requiring private keys to be copied into containers.
