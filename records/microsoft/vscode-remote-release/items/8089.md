# Issue #8089 — Start Docker daemon for me if it's not already started

[https://github.com/microsoft/vscode-remote-release/issues/8089](https://github.com/microsoft/vscode-remote-release/issues/8089)

## Summary

Docker Desktop auto-start shipped for Windows and Mac, but that does not establish completion of this broader daemon-start request, whose discussion also includes Linux. Keep this canonical feature request open to clarify the remaining platform coverage; newer startup regressions do not own its full scope.

## Change summary

Start an installed but stopped Docker daemon when creating a local dev container, without requiring manual startup or startup at boot.

## Best solution

The Dev Containers owner should establish whether supported local Linux daemon startup remains outstanding and complete that coverage with startup progress, readiness polling, and explicit failure reporting. Preserve the shipped Windows/Mac behavior and address its regressions in their existing reports.
