# Issue #9218 — Dev containers: Attach to running container... hangs forever

[https://github.com/microsoft/vscode-remote-release/issues/9218](https://github.com/microsoft/vscode-remote-release/issues/9218)

## Summary

Keep the accepted containers request open: attaching to a healthy container should not depend on inspecting an unrelated broken container. Existing attachment documentation and related CLI work do not establish that this SSH-host scenario is covered.

## Change summary

Allow attaching directly to a container by name or ID without first inspecting every running container.

## Best solution

The Dev Containers extension should offer direct target selection that inspects only the requested container, preserving the SSH host context. This would avoid requiring users to repair or stop containers they do not own.
