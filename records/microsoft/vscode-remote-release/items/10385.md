# Issue #10385 — "Rebuild container" fails if swapping from `.devcontainer/devcontainer.json` to `.devcontainer.json` or vice versa

[https://github.com/microsoft/vscode-remote-release/issues/10385](https://github.com/microsoft/vscode-remote-release/issues/10385)

## Summary

The report provides a clear historical reproduction, but there are no current-version confirmations or follow-up logs showing that the cached configuration-path failure still occurs. A retest is needed before the Containers team can act.

## Change summary

Rebuild Container continues using a cached devcontainer configuration path after the file moves between `.devcontainer/devcontainer.json` and `.devcontainer.json`.

## Best solution

The Dev Containers extension should rediscover the supported configuration location when its cached path no longer exists, allowing Rebuild Container to proceed without requiring the workspace to be reopened locally.
