# Issue #10385 — "Rebuild container" fails if swapping from `.devcontainer/devcontainer.json` to `.devcontainer.json` or vice versa

[https://github.com/microsoft/vscode-remote-release/issues/10385](https://github.com/microsoft/vscode-remote-release/issues/10385)

## Summary

Keep open for the Dev Containers owner: the supplied steps and logs suffice to retest rebuild after relocating the configuration. The report concerns older releases, but no confirmed fix or canonical duplicate was found.

## Change summary

Rebuild Container retains a nonexistent configuration path after moving between .devcontainer/devcontainer.json and .devcontainer.json.

## Best solution

Dev Containers should rediscover the supported configuration location when the previously selected file disappears during a rebuild, preserving explicit selection when it remains valid. Retest the supplied relocation steps on the current extension; reopening locally is a workaround, not equivalent rebuild behavior.
