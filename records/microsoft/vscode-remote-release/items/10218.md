# Issue #10218 — code tunnel only from certain IPs

[https://github.com/microsoft/vscode-remote-release/issues/10218](https://github.com/microsoft/vscode-remote-release/issues/10218)

## Summary

Keep open as a security-sensitive upstream capability gap: Dev Tunnels does not support source-IP restrictions, so `code tunnel` cannot currently limit clients to approved networks or devices.

## Change summary

Allow `code tunnel` operators to restrict connections to specified client IP addresses or ranges.

## Best solution

The Dev Tunnels service must first support source-IP access-control entries; the VS Code CLI can then expose an argument and apply that ACL when creating its tunnel.

- **Fit:** aligned
- **Reason:** Stronger access controls make tunnels more viable as a mainstream remote-development path in managed environments.
