# Issue #10218 — code tunnel only from certain IPs

[https://github.com/microsoft/vscode-remote-release/issues/10218](https://github.com/microsoft/vscode-remote-release/issues/10218)

## Summary

Keep open: the thread identifies Dev Tunnels service support as the prerequisite for restricting connections by IP. This security-sensitive access-control request needs human follow-up; current documentation does not establish that the requested restriction is available.

## Change summary

Restrict access to code tunnels running inside SLURM jobs to approved client IPs or work devices, even when other devices use the same authenticated account.

## Best solution

The tunnels/CLI owners should confirm whether Dev Tunnels now supports service-enforced client IP restrictions. If supported, expose them through code tunnel; otherwise retain this upstream dependency rather than treating account authentication or client-side policies as equivalent protection.
