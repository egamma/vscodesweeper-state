# Issue #9529 — Add ability to change location of .vscode-remote-containers

[https://github.com/microsoft/vscode-remote-release/issues/9529](https://github.com/microsoft/vscode-remote-release/issues/9529)

## Summary

Keep this as the canonical Dev Containers installation-location request: a maintainer recently consolidated the matching request here. No documented setting covering the requested relocation was identified, and the symlink workaround does not remove the home-directory entry.

## Change summary

Allow configuring the location of .vscode-remote-containers instead of placing it in the user's home directory.

## Best solution

Dev Containers should provide a supported host-specific installation-directory override, including for remote hosts with slow or space-constrained home directories. Retain this issue as the owner of that capability, distinct from preventing unnecessary initialization.
