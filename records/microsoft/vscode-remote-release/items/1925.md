# Issue #1925 — Remote Containers and VSCodium

[https://github.com/microsoft/vscode-remote-release/issues/1925](https://github.com/microsoft/vscode-remote-release/issues/1925)

## Summary

The incompatibility with VSCodium is intentional licensing and product behavior, not a Dev Containers defect. Current documentation and prior maintainer guidance explicitly restrict the VS Code Server to official VS Code clients.

## Change summary

Allow the proprietary Remote Development extensions and VS Code Server to run with VSCodium and other Code OSS distributions.

## Best solution

Keep the documented official-client restriction unless Microsoft makes a deliberate licensing and product-policy change; users requiring an open-source client need a separately licensed remote-development implementation.

## Vision fit

- **Fit:** unclear
- **Reason:** The vision promises remote-development parity within VS Code but does not establish support for third-party Code OSS distributions.
- **Evidence:** The public product promise is to open remote folders while taking advantage of VS Code's full feature set; it does not extend that promise to independently distributed clients.
