# Issue #10926 — devcontainer over ssh: "Over 20 ports have been automatically forwarded", sets remote.autoForwardPortsSource to hybrid

[https://github.com/microsoft/vscode-remote-release/issues/10926](https://github.com/microsoft/vscode-remote-release/issues/10926)

## Summary

The switch to hybrid after more than 20 automatically forwarded ports is intentional VS Code core behavior, but the original report does not identify what opened the unexpected ports. The only follow-up traced newly opened ports to Pylance and Gemini Code Assist, so a current clean reproduction is needed before assigning a root cause.

## Change summary

A remote Dev Container session unexpectedly forwards 21 high-numbered ports and consequently changes remote.autoForwardPortsSource from process to hybrid.

## Best solution

Identify the processes that create the ports on a current release and determine whether VS Code core is incorrectly forwarding internal extension ports. If the behavior reproduces independently of installed extensions, a maintainer can transfer this to microsoft/vscode, which owns automatic port discovery and the fallback setting.
