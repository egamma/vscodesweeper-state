# Issue #10926 — devcontainer over ssh: "Over 20 ports have been automatically forwarded", sets remote.autoForwardPortsSource to hybrid

[https://github.com/microsoft/vscode-remote-release/issues/10926](https://github.com/microsoft/vscode-remote-release/issues/10926)

## Summary

The report identifies a regression that spuriously forwarded 21 unexplained ports in a nested Dev Container-over-SSH setup, but there is no current reproduction or diagnostic log identifying which remote layer supplied them. A current retest and logs are needed before routing this to Dev Containers, Remote - SSH, or VS Code core.

## Change summary

Opening a Dev Container through Remote - SSH automatically forwards more than 20 unexplained ports and changes remote.autoForwardPortsSource to hybrid.

## Best solution

Determine which layer reports the stale or unowned listeners, then prevent those ports from entering automatic forwarding; if the remote extensions supply correct data and the defect is in the shared forwarding implementation, a maintainer can transfer this to microsoft/vscode.
