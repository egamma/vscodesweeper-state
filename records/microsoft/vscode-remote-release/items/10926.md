# Issue #10926 — devcontainer over ssh: "Over 20 ports have been automatically forwarded", sets remote.autoForwardPortsSource to hybrid

[https://github.com/microsoft/vscode-remote-release/issues/10926](https://github.com/microsoft/vscode-remote-release/issues/10926)

## Summary

Keep open to investigate the unexpected accumulation of automatically forwarded ports, not the fallback notification alone. The supplied connection workflow and 1.99.3 comparison suffice to retest; neither the later WSL report nor the related history establishes resolution on current releases.

## Change summary

Connecting to a dev container over SSH unexpectedly forwards 21 unidentified ports and changes remote.autoForwardPortsSource from process to hybrid.

## Best solution

The Dev Containers and SSH owners should determine why this workflow accumulates unidentified ports and distinguish newly detected ports from restored entries. The fallback itself is implemented in VS Code core; a maintainer can transfer this to microsoft/vscode if the unwanted forwarding is confirmed to originate in its shared port-discovery logic.
