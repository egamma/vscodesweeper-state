# Issue #3547 — Attach to Kubernetes Pod does not use kubectl provided by Kubernetes Extension

[https://github.com/microsoft/vscode-remote-release/issues/3547](https://github.com/microsoft/vscode-remote-release/issues/3547)

## Summary

Keep open: discovering the Kubernetes extension's managed kubectl remains a distinct integration request. Current documentation requires kubectl separately, and the verified related issues do not establish a fix or an open canonical for this exact failure.

## Change summary

Allow Kubernetes attachment to use the Kubernetes extension's installed kubectl or an explicitly configured executable without changing the system PATH.

## Best solution

The Dev Containers extension should resolve the Kubernetes extension's managed kubectl when available, with an explicit executable-path override for other installations. Keep kubeconfig selection as related but separate work.
