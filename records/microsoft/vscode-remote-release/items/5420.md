# Issue #5420 — devcontainer cli ignores docker context

[https://github.com/microsoft/vscode-remote-release/issues/5420](https://github.com/microsoft/vscode-remote-release/issues/5420)

## Summary

The Dev Container CLI still ignores the active Docker context while the extension honors it, with independent confirmations on CLI 0.80.1 and 0.80.2. This remains an open CLI defect rather than a support or stale-report close.

## Change summary

Make `devcontainer open` honor the Docker context selected through `docker context use`, consistent with Docker commands and the Dev Containers extension.

## Best solution

The Dev Container CLI should resolve and use Docker's active context instead of falling back to the default socket. Since this behavior belongs to the public CLI, a maintainer can transfer or consolidate the report in https://github.com/devcontainers/cli while preserving the confirmations here.
