# Issue #11690 — Dev Containers 0.459.1 / VS Code 1.123.0: attached-container reconnect still intermittently fails with "Reconnect attempt without old result"

[https://github.com/microsoft/vscode-remote-release/issues/11690](https://github.com/microsoft/vscode-remote-release/issues/11690)

## Summary

Keep the attached-container recovery failure open for Dev Containers investigation. Later reports concern related connection failures, but none verifies resolution or canonical ownership of this exact path; the supplied reload steps and logs suffice to retest.

## Change summary

Reloading an attached-container window can lose the previous resolver result after a normal extension-host restart and fail to reconnect to the running container.

## Best solution

The Dev Containers owner should investigate recovery after local extension-host restart on the attached-container path, restoring the connection without requiring the previous in-memory result. Compare the extension-reconciliation sequence in the older report before deciding whether both authority paths need one shared fix.
