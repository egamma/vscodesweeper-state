# Issue #11690 — Dev Containers 0.459.1 / VS Code 1.123.0: attached-container reconnect still intermittently fails with "Reconnect attempt without old result"

[https://github.com/microsoft/vscode-remote-release/issues/11690](https://github.com/microsoft/vscode-remote-release/issues/11690)

## Summary

The detailed logs show a reproducible attached-container reconnect failure after the local extension host restarts. A newer related report confirms that the attached-container recovery path remains unreliable, so this should remain open and be routed to Dev Containers.

## Change summary

Reloading a window attached to a running container intermittently fails because the second attached-container authority resolution has no reusable connection result.

## Best solution

The Dev Containers owner should make the attached-container resolver preserve or recreate its connection state across local extension-host restarts, with bounded retry or an actionable failure when recovery is impossible.
