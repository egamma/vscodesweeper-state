# Issue #7814 — Gpg agent not forwarded when using devcontainer through remote-ssh

[https://github.com/microsoft/vscode-remote-release/issues/7814](https://github.com/microsoft/vscode-remote-release/issues/7814)

## Summary

Keep open: the remaining request is control over which GPG agent Dev Containers forwards through Remote - SSH. The documented sharing capability and successful manual workarounds do not establish that this selection gap is resolved.

## Change summary

Allow selecting the local GPG agent when an SSH host has GPG installed but lacks the user's signing keys.

## Best solution

Dev Containers should provide an explicit local-versus-remote GPG agent preference, as the maintainer suggested, without requiring removal of GPG from the SSH host. Preserve the existing default unless the team deliberately decides to change it.
