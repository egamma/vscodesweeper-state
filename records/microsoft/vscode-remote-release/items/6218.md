[https://github.com/microsoft/vscode-remote-release/issues/6218](https://github.com/microsoft/vscode-remote-release/issues/6218)

## Summary

Keep this team-authored exploration open: the discussion establishes a connection-sharing direction, but neither implementation nor supersession is confirmed. Its existing SSH and containers routing is correct.

## Change summary

Let Dev Containers reuse Remote-SSH's existing local-server connection to avoid repeated authentication and share SSH connection handling.

## Best solution

The Dev Containers and Remote-SSH owners should assess optional API-based connection reuse while preserving Dev Containers operation without Remote-SSH installed. Establish whether that integration has shipped before treating the investigation as completed.
