# Issue #9454 — Preinstalled server+extensions environment for SSH hosts (similar to "offline"/airgapped host)

[https://github.com/microsoft/vscode-remote-release/issues/9454](https://github.com/microsoft/vscode-remote-release/issues/9454)

## Summary

Keep open in Backlog: shipped fallbacks improve offline installation but do not provide the requested pre-provisioned SSH host containing a reusable server and extensions. A maintainer explicitly identified the fully isolated local-and-remote case as remaining work.

## Change summary

Allow administrators to bake the VS Code Server and remote extensions into SSH hosts so connections require neither internet access nor repeated installation.

## Best solution

Remote - SSH should support a documented pre-provisioning contract for a compatible server and extension set, allowing immutable SSH hosts to connect without downloads or installation. Version incompatibility should produce an explicit error rather than silently using an arbitrary outdated server.
