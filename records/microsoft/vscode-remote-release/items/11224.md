# Issue #11224 — WSL: Connection fails on Arch Linux when networkingMode is set to `mirrored`

[https://github.com/microsoft/vscode-remote-release/issues/11224](https://github.com/microsoft/vscode-remote-release/issues/11224)

## Summary

Keep open as upstream: the maintainer explicitly requests WSL-team help, and the linked networking discussion remains unresolved. Switching networking modes is a workaround, not confirmation that mirrored-mode connections are fixed.

## Change summary

Opening an Arch Linux folder through WSL times out when networkingMode=mirrored, while removing that setting restores connectivity.

## Best solution

The WSL team should investigate mirrored-mode connectivity using this report's Arch Linux reproduction alongside https://github.com/microsoft/WSL/issues/11184. Retain the WSL tracking here until the platform cause or any remaining extension-side work is established.
