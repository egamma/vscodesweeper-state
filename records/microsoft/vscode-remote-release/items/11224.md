# Issue #11224 — WSL: Connection fails on Arch Linux when networkingMode is set to `mirrored`

[https://github.com/microsoft/vscode-remote-release/issues/11224](https://github.com/microsoft/vscode-remote-release/issues/11224)

## Summary

Keep open as upstream: the WSL server starts successfully, but mirrored networking prevents the client connection, and a maintainer explicitly identified this as requiring the WSL team's help.

## Change summary

Allow the VS Code WSL extension to connect to an Arch Linux distro when WSL mirrored networking is enabled.

## Best solution

The WSL platform should correct the mirrored-networking loopback or forwarding behavior tracked in https://github.com/microsoft/WSL/issues/11184; once addressed upstream, the WSL extension connection should be retested with the reported Arch configuration.
