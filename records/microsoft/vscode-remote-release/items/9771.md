# Issue #9771 — Remote devcontainers on Azure ML compute instances

[https://github.com/microsoft/vscode-remote-release/issues/9771](https://github.com/microsoft/vscode-remote-release/issues/9771)

## Summary

Keep open: this is a valid Dev Containers integration request, and current documentation still does not describe support for reopening Azure ML compute-instance sessions in a dev container. The required Azure ML extension support remains the principal dependency.

## Change summary

Allow an Azure ML compute-instance session opened in VS Code to be reopened inside a dev container.

## Best solution

The Azure ML Remote extension should first expose the required remote-container integration, after which the Dev Containers component can support reopening that remote workspace in a container. Coordination should continue with https://github.com/microsoft/vscode-tools-for-ai/issues/2062 rather than treating its automated archival as implementation.
