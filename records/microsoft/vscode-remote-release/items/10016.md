# Issue #10016 — [Remote-Container Bug] Massive UI performance issues without x11 socket when using Containers in WSL2

[https://github.com/microsoft/vscode-remote-release/issues/10016](https://github.com/microsoft/vscode-remote-release/issues/10016)

## Summary

Keep open: the manual DISPLAY and socket mount remain a workaround rather than coverage of the requested automatic X11 forwarding, and the reporter confirmed the performance gap remains in February 2026.

## Change summary

Automatically mount the WSL2 X11 socket into Dev Containers to avoid severe GUI application CPU and rendering-performance degradation.

## Best solution

The Dev Containers extension should detect a locally running Docker daemon under WSL2 and forward the appropriate X11 socket alongside Wayland, preserving native GUI performance without project-specific runArgs.
