# Issue #12 — Kubernetes container

[https://github.com/microsoft/vscode-remote-release/issues/12](https://github.com/microsoft/vscode-remote-release/issues/12)

## Summary

Keep open for Kubernetes deployment and lifecycle support beyond attaching to existing containers. A maintainer explicitly designated this issue to track those additional commands; the shipped attach capability does not complete that work.

## Change summary

Support creating, deploying, rebuilding, and stopping Kubernetes development containers alongside the existing attach workflow.

## Best solution

The Dev Containers component should define spec-compatible Kubernetes lifecycle integration, building on the discussed user-configurable deployment and connection commands. Coordinate with the orchestrator interoperability proposal while retaining this issue for the extension-side implementation.

- **Existing hooks do not replace orchestration:** https://github.com/devcontainers/spec/blob/main/docs/specs/devcontainerjson-reference.md documents initializeCommand and postStartCommand, but its scenario-specific creation properties cover images, Dockerfiles, and Docker Compose. Running setup scripts does not provide the requested Kubernetes deployment, attachment, rebuild, and stop integration.
