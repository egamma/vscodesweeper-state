# Issue #10799 — Unsaved files on a disconnected connection cannot be saved and prevent successful reconnection

[https://github.com/microsoft/vscode-remote-release/issues/10799](https://github.com/microsoft/vscode-remote-release/issues/10799)

## Summary

Keep open: concrete WSL shutdown steps and two SSH confirmations establish an unsaved-edit recovery failure, but no current-release resolution is documented. The existing steps suffice for retesting; the related open requests do not own the complete defect.

## Change summary

Unsaved remote files cannot be saved locally and obstruct reconnection after the remote environment disconnects or restarts.

## Best solution

The WSL and SSH owners should ensure reconnection preserves dirty buffers and permits local recovery, including notebooks. Coordinate with the VS Code workbench owners if save or reload handling requires a core change, without assuming the notebook error explains the entire report.
