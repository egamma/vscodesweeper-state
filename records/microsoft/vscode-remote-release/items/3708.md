# Issue #3708 — remote.containers.repositoryConfigurationPaths doesn't work with WSL / SSH / Clone in Volume

[https://github.com/microsoft/vscode-remote-release/issues/3708](https://github.com/microsoft/vscode-remote-release/issues/3708)

## Summary

This remains the canonical report for remote path handling with repository configuration folders, but there is no current-release confirmation. A retest is needed before deciding whether the path-conversion defect remains.

## Change summary

Dev Containers passes a Windows or UNC repository-configuration path into a Linux remote context, causing Docker Compose configuration lookup to fail under WSL, SSH, or Clone in Volume.

## Best solution

Dev Containers should resolve `dev.containers.repositoryConfigurationPaths` into paths valid in the active WSL, SSH, or remote-Docker execution context. First confirm the affected scenarios and collect current Dev Containers logs because the available reproductions are outdated.
