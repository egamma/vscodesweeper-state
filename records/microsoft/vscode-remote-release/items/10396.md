# Issue #10396 — ptyHost was unable to resolve shell environment (arm64 container running on amd64 host)

[https://github.com/microsoft/vscode-remote-release/issues/10396](https://github.com/microsoft/vscode-remote-release/issues/10396)

## Summary

Keep open for configurable Dev Containers environment-probe timeouts. The reporter resolved the ptyHost error, but the subsequent comments establish a separate remaining request: let slow shell initialization finish before lifecycle commands run without its environment.

## Change summary

Allow Dev Containers userEnvProbe to wait longer than 10 seconds so lifecycle commands retain shell-defined environment variables under cross-architecture emulation.

## Best solution

The containers owner should provide a configurable environment-probe timeout, or explicitly coordinate it with application.shellEnvironmentResolutionTimeout, while retaining a bounded default. Retest the supplied setup against current releases; the existing setting and interactive-shell workaround do not establish that the lifecycle-probe request is satisfied.
