# Issue #10396 — ptyHost was unable to resolve shell environment (arm64 container running on amd64 host)

[https://github.com/microsoft/vscode-remote-release/issues/10396](https://github.com/microsoft/vscode-remote-release/issues/10396)

## Summary

A real gap remains: the VS Code shell-resolution timeout is configurable, but Dev Containers' separate user environment probe still has a fixed 10-second timeout. The existing containers and feature-request labels correctly classify this Backlog item.

## Change summary

Allow Dev Containers' user environment probe to wait longer on slow environments such as ARM64 containers emulated on AMD64 hosts.

## Best solution

The Dev Containers component should expose a configurable userEnvProbe timeout in the public devcontainers CLI and have the extension pass it through, preferably reusing `application.shellEnvironmentResolutionTimeout` where appropriate.
