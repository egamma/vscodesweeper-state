# Issue #2440 — Warn when mistyping devcontainer `build` properties

The current public Dev Container schema appears to implement the requested validation, but this team-authored issue must remain open because the implementing commit does not reference it.

## Change summary

Warn when an unrecognized property such as `dockerFile` is used inside the devcontainer `build` object.
