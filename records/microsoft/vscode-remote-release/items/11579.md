## Summary

The logs strongly associate the connection failure with an unavailable default extension, but this remains a single report on Remote - SSH 0.122.0 with no current-release confirmation. A retest is needed before further investigation.

## Change summary

Remote - SSH should skip an unavailable extension in `remote.SSH.defaultExtensions` rather than aborting the remote connection.

## Best solution

Remote - SSH and the VS Code Server should treat failure to install an optional default extension as non-fatal, report the failed extension clearly, and continue opening the remote window. First confirm the behavior on the current release with the supplied deterministic reproduction.
