## Summary

Keep open for the Dev Containers owner: detailed logs show cleanup killing an in-flight lifecycle command, and a September report corroborates unsafe process-group termination on Dev Containers 0.470.0. The related open issue covers zero process groups, not the original misclassification of transient CLI processes.

## Change summary

Dev Containers agent cleanup kills unrelated lifecycle commands or its own shell server when attaching or reconnecting.

## Best solution

Dev Containers should distinguish long-running agents from transient CLI invocations and terminate only verified agent processes without harming lifecycle commands or its shell server. Coordinate the zero-process-group case with https://github.com/microsoft/vscode-remote-release/issues/10843 while retaining this report's separate CLI-misclassification reproduction.
