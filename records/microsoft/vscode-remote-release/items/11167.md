Keep open for the Remote Explorer owner: the reporter supplied a concrete Windows junction-and-permissions reproduction, sufficient to retest on releases newer than VS Code 1.103.2 and Remote Explorer 0.5.0. No confirmed fix or verified canonical covers this failure.

## Change summary

Remote Explorer's refresh command is unavailable when the user's .vscode directory is junction-linked to an accessible directory beneath an inaccessible parent.
