The detailed junction and permission scenario plausibly prevents Remote Explorer activation, but the thread lacks an extension-host stack trace or an independent reproduction under the same conditions. Current-version logs are needed to verify the suspected realpath failure.

## Change summary

Remote Explorer fails to register its refresh command when the Windows user’s `.vscode` directory is a junction beneath an inaccessible parent directory.

## Best solution
