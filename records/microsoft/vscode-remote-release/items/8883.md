# Issue #8883 — Dev Containers: set GIT_ASKPASS to use GitHub auth token

[https://github.com/microsoft/vscode-remote-release/issues/8883](https://github.com/microsoft/vscode-remote-release/issues/8883)

## Summary

Keep open: reusing VS Code's GitHub authentication for container-volume cloning remains a maintainer-supported improvement. Documented credential-helper sharing offers a workaround, not coverage of the requested authentication integration.

## Change summary

Use GIT_ASKPASS to reuse VS Code's GitHub authentication when cloning a private repository into a container volume.

## Best solution

Dev Containers should connect its clone workflow's Git authentication to VS Code's existing GitHub session, including the preliminary git ls-remote call. A configured local credential helper is the documented workaround while that integration remains outstanding.
