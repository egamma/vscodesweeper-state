# Issue #8883 — Dev Containers: set GIT_ASKPASS to use GitHub auth token

[https://github.com/microsoft/vscode-remote-release/issues/8883](https://github.com/microsoft/vscode-remote-release/issues/8883)

## Summary

A real Dev Containers authentication gap remains: cloning a private repository into a container volume cannot reuse VS Code's GitHub authentication when the host lacks a credential helper. The documented credential-helper alternative does not satisfy that central request.

## Change summary

Allow the container-volume clone workflow to authenticate Git operations through VS Code's existing GitHub credentials using GIT_ASKPASS.

## Best solution

The Dev Containers clone bootstrap should provide a host-mediated GIT_ASKPASS implementation equivalent to the built-in Git extension, allowing private HTTPS repositories to clone without requiring a separately configured credential helper.
