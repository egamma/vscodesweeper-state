## Change summary

Make the Extensions view's "Add to devcontainer.json" action update the project's configuration when invoked from an active dev-container window.

## Best solution

The Dev Containers extension should resolve and edit the workspace's devcontainer.json from an active container, adding the selected extension under customizations.vscode.extensions as the equivalent local action does.
