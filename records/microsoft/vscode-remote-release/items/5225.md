# Issue #5225 — Feature Request: Lifecycle scripts (initalize/postCreateCommand) support user input

[https://github.com/microsoft/vscode-remote-release/issues/5225](https://github.com/microsoft/vscode-remote-release/issues/5225)

## Summary

Keep this accepted Dev Containers request open: documented lifecycle hooks do not establish support for interactive host-side setup before container startup. Related reports cover narrower workflows, and a maintainer explicitly identified this issue as the existing feature request.

## Change summary

Allow host-side lifecycle scripts to accept user input before starting a development container.

## Best solution

The Dev Containers owner should define an opt-in interactive host-initialization workflow that completes before container startup, including cancellation and sensitive-input handling. Retain this issue as the product-side tracker even if implementing that workflow requires a coordinated specification change.
