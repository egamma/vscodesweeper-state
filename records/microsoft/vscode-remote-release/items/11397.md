# Issue #11397 — Include remote host/prompt context in the SSH password input box

[https://github.com/microsoft/vscode-remote-release/issues/11397](https://github.com/microsoft/vscode-remote-release/issues/11397)

## Summary

Keep open as an SSH feature request: the documented login-terminal workaround does not add host or authentication-stage context to the password input box. No verified canonical owns this same improvement.

## Change summary

Show the requesting host and original SSH authentication prompt in password input boxes so users can distinguish jump-host passwords, target passwords, and OTP challenges.

## Best solution

Remote - SSH should preserve meaningful authentication-prompt context in its input boxes, identifying the requesting host when available rather than attributing every challenge to the final target. The SSH owner should assess prompt handling across ProxyJump and MFA flows.
