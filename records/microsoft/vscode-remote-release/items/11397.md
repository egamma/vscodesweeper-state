# Issue #11397 — Include remote host/prompt context in the SSH password input box

[https://github.com/microsoft/vscode-remote-release/issues/11397](https://github.com/microsoft/vscode-remote-release/issues/11397)

## Summary

A real SSH authentication UX gap remains: the existing login-terminal workaround exposes the native prompt, but the standard input box can lose context needed to distinguish target, jump-host, password, and MFA requests.

## Change summary

Show the originating SSH prompt and remote-host context in authentication input boxes.

## Best solution

Remote - SSH should preserve safe context from each SSH askpass request and identify the relevant connection stage or host in its input box. Route this to SSH authentication and proxy handling; the linked GPG-signing request is separate work.
