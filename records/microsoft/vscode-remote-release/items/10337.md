# Issue #10337 — Feature request: SSH Connection error message pop up: Display stderr content

[https://github.com/microsoft/vscode-remote-release/issues/10337](https://github.com/microsoft/vscode-remote-release/issues/10337)

## Summary

Keep open in the accepted Backlog: Remote - SSH captures the actionable PAM stderr but hides it from the connection-failure popup. The documented login-terminal and Output views are workarounds, not coverage of the requested error presentation.

## Change summary

Display relevant SSH stderr content in the connection-error popup so authentication guidance from PAM is visible without inspecting Remote - SSH logs.

## Best solution

Remote - SSH should surface concise, actionable authentication stderr in its connection-failure UI while filtering verbose diagnostic noise; the existing output log can retain the complete stream.
