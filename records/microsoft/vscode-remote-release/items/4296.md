# Issue #4296 — Clone repository with specific branch

[https://github.com/microsoft/vscode-remote-release/issues/4296](https://github.com/microsoft/vscode-remote-release/issues/4296)

## Summary

Keep open: current Dev Containers support branch selection for GitHub, but the provider-agnostic branch-selection gap remains and this issue is the maintainer-designated canonical request.

## Change summary

Allow Clone Repository in Container Volume to select a specific branch for repositories hosted outside GitHub.

## Best solution

Dev Containers should honor branch information supplied by any RemoteSourceProvider or provide a generic branch prompt before cloning, so the selected branch's devcontainer configuration is used. Keep this issue as the canonical request; the existing checkout-and-rebuild workaround does not cover the central ask.
