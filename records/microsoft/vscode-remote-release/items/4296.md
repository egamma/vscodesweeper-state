# Issue #4296 — Clone repository with specific branch

[https://github.com/microsoft/vscode-remote-release/issues/4296](https://github.com/microsoft/vscode-remote-release/issues/4296)

## Summary

Keep this accepted request open: documented GitHub branch support does not cover selecting a branch from an arbitrary Git host before discovering its devcontainer configuration. A maintainer explicitly identified this issue as the tracker for that remaining capability.

## Change summary

Allow Clone Repository in Container Volume to select a non-default branch on any Git host before loading the branch's devcontainer configuration.

## Best solution

Dev Containers should accept a repository URL and an explicit branch independently of GitHub URL conventions, checking out that branch before discovering devcontainer configuration. Keep this issue as the general branch-selection tracker; existing-volume isolation is separate work.
