# Issue #9115 — Dev Container fails to inspect target image on a different architecture

[https://github.com/microsoft/vscode-remote-release/issues/9115](https://github.com/microsoft/vscode-remote-release/issues/9115)

## Summary

Verified duplicate: the older open issue tracks the same cross-architecture image inspection and pull failure, including the identical manual platform-specific pull workaround.

## Change summary

Dev Containers ignores the Dockerfile platform while inspecting or pulling an image, causing amd64-only images to fail on arm64 hosts.

## Best solution

Consolidate the Dev Containers platform-selection defect on https://github.com/microsoft/vscode-remote-release/issues/8965, where the team has confirmed that runArgs cannot affect image inspection or pulling.
