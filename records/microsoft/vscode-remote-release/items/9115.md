# Issue #9115 — Dev Container fails to inspect target image on a different architecture

[https://github.com/microsoft/vscode-remote-release/issues/9115](https://github.com/microsoft/vscode-remote-release/issues/9115)

## Summary

Verified duplicate: the open Backlog issue tracks the same cross-architecture image inspection and pull failure, including the identical manual-pull workaround.

## Change summary

Dev Containers ignores a Dockerfile's target platform while inspecting or pulling its base image, causing amd64 containers to fail on arm64 hosts.

## Best solution

Consolidate on https://github.com/microsoft/vscode-remote-release/issues/8965; the Dev Containers image inspection and pull path should honor the requested platform before container startup.
