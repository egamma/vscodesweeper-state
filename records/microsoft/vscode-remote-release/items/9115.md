# Issue #9115 — Dev Container fails to inspect target image on a different architecture

[https://github.com/microsoft/vscode-remote-release/issues/9115](https://github.com/microsoft/vscode-remote-release/issues/9115)

## Summary

Verified duplicate of the older, open platform-selection issue: both fail during image inspection and fallback pulling on ARM64 despite an explicit AMD64 Dockerfile platform. Consolidate the report without treating the workaround as a fix.

## Change summary

Dev Containers pulls a Dockerfile base image for the host architecture instead of honoring FROM --platform=linux/amd64.

## Best solution

Track platform-aware base-image inspection and pulling in https://github.com/microsoft/vscode-remote-release/issues/8965, already accepted into Backlog. Preserve this report's Ubuntu Focal image example and successful explicit-platform pre-pull workaround there.
