# Issue #3096 — Persistent SSH session

[https://github.com/microsoft/vscode-remote-release/issues/3096](https://github.com/microsoft/vscode-remote-release/issues/3096)

## Summary

VS Code 1.107 added configurable SSH reconnection grace time, substantially covering long-lived sessions, but an open vscode PR explicitly addressing this issue triggers the hard keep-open rule.

## Change summary

Keep Remote-SSH server, terminal, and extension state alive so users can disconnect for days and later resume the same session.

## Best solution

The SSH and code-server owners should determine whether `remote.SSH.reconnectionGraceTime` fully covers the requested persistent-session behavior, then review or close https://github.com/microsoft/vscode/pull/273060 before resolving this issue.
