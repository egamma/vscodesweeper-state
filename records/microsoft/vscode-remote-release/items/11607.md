# Issue #11607 — Can't open VSCode in WSL while offline when there is an update

[https://github.com/microsoft/vscode-remote-release/issues/11607](https://github.com/microsoft/vscode-remote-release/issues/11607)

## Summary

Verified duplicate of an older open report documenting the same WSL startup failure: the updater removes the previous server installation, then fails to download its replacement while offline.

## Change summary

Launching VS Code from WSL while offline becomes impossible when the installed server does not match the updated client.

## Best solution

Consolidate this report into https://github.com/microsoft/vscode-remote-release/issues/11385 so the WSL owner can address offline startup across Stable and Insiders, including failures of the existing server-prefetch mechanism.
