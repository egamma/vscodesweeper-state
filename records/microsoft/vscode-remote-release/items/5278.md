# Issue #5278 — Attach to running docker container by name in CLI and document code remote CLI options

[https://github.com/microsoft/vscode-remote-release/issues/5278](https://github.com/microsoft/vscode-remote-release/issues/5278)

## Summary

Keep this accepted Dev Containers request open: the confirmed URI workaround enables scripted attachment, but does not deliver the requested documented, readable interface and configuration options. Related project-launch requests do not own the full externally managed-container workflow.

## Change summary

Provide and document a CLI interface that opens VS Code attached to an existing Docker container by name or ID, with optional attached-container settings and extensions.

## Best solution

The Dev Containers component should provide a supported, documented attach-by-name/ID interface without taking over the container lifecycle, and define how scripts supply attached-container configuration. Retain this issue as the existing-container tracker; coordinate any reference-CLI work without dropping the VS Code attachment remainder.
