# Issue #7018 — all passing machine name as a cli argument

[https://github.com/microsoft/vscode-remote-release/issues/7018](https://github.com/microsoft/vscode-remote-release/issues/7018)

## Summary

Implemented and shipped: the tunnel CLI accepts `--name <machine-name>`, eliminating the interactive machine-name prompt for automated deployments.

## Change summary

Allow automation to specify the VS Code tunnel machine name through a CLI argument or environment variable.

## Best solution

Use `code tunnel --name <machine-name> --accept-server-license-terms` for non-interactive container or VM provisioning; the CLI argument fully covers the central request.
