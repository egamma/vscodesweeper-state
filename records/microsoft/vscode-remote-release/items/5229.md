# Issue #5229 — Always install extensions to support mounting the home folder

[https://github.com/microsoft/vscode-remote-release/issues/5229](https://github.com/microsoft/vscode-remote-release/issues/5229)

## Summary

Keep open: reconciling newly declared extensions while preserving a mounted home and existing extensions remains distinct from the documented workarounds. The expired Backlog Candidates window and eight upvotes do not justify a cleanup close.

## Change summary

Install newly declared devcontainer.json extensions despite a persisted installation marker, without discarding previously installed extensions.

## Best solution

The Dev Containers extension should reconcile declared extensions with those already installed when reconnecting or rebuilding with a persistent home, installing missing entries without uninstalling others. Retain this issue as the owner of that automatic behavior; extension-cache configuration and an explicit retry command are related but different work.
