# Issue #5229 — Always install extensions to support mounting the home folder

[https://github.com/microsoft/vscode-remote-release/issues/5229](https://github.com/microsoft/vscode-remote-release/issues/5229)

## Summary

A real capability gap remains: persisted home directories prevent newly requested extensions from being installed, and the documented marker-deletion workaround does not satisfy the request. Keep this older report open as the likely canonical and classify it as under discussion.

## Change summary

Install newly listed Dev Container extensions when the remote home and existing extension installation persist across container rebuilds.

## Best solution

Dev Containers should compare the requested extension list with the persisted installation and install only missing extensions, without requiring users to delete `.installExtensionsMarker`. The newer matching report https://github.com/microsoft/vscode-remote-release/issues/9703 should consolidate here rather than replace this older issue.
