# Issue #8031 — Allow for disabling automatic forwarding of sockets from the host when attaching to a container

[https://github.com/microsoft/vscode-remote-release/issues/8031](https://github.com/microsoft/vscode-remote-release/issues/8031)

## Summary

Keep open: this accepted Backlog request remains necessary because Dev Containers still lacks a first-class way to disable automatic host-socket forwarding when attaching to an already configured container.

## Change summary

Allow attached containers to opt out of automatic SSH-agent, X11, Wayland, and similar host-socket forwarding.

## Best solution

Dev Containers should provide a per-container or per-workspace opt-out for automatic socket forwarding while preserving the current default. The setting should apply when attaching to existing containers and avoid replacing their socket-related environment configuration.
