# Issue #8031 — Allow for disabling automatic forwarding of sockets from the host when attaching to a container

[https://github.com/microsoft/vscode-remote-release/issues/8031](https://github.com/microsoft/vscode-remote-release/issues/8031)

## Summary

Keep the accepted Dev Containers request open: preserving an existing DISPLAY value addressed the related regression, but does not establish an opt-out from automatic host-socket forwarding. The verified related requests do not satisfy this re-reviewed item's same-observable-symptom duplicate bar.

## Change summary

Allow attaching to an existing container without injecting host SSH, X11, or other forwarded sockets or overriding its independently configured environment.

## Best solution

Dev Containers should offer an explicit socket-forwarding opt-out for attached containers, preserving their existing sockets and environment. Coordinate with the broader integration and credential-forwarding requests without treating the DISPLAY regression fix as delivery of this capability.
