# Issue #669 — Unsupported architecture: armv6l

[https://github.com/microsoft/vscode-remote-release/issues/669](https://github.com/microsoft/vscode-remote-release/issues/669)

## Summary

Keep this as the canonical ARMv6 support request. Current Remote - SSH documentation still requires ARMv7 or newer, while the maintainer left this open pending confidence that the server can operate reliably within ARMv6 Raspberry Pi memory constraints.

## Change summary

Add Remote - SSH and VS Code Server support for ARMv6 devices such as the original Raspberry Pi Zero and Raspberry Pi 1.

## Best solution

The SSH and VS Code Server owners should retain this canonical request until they either provide a server build that works reliably on typical ARMv6 hardware or make an explicit scope decision based on the documented memory and architecture requirements.
