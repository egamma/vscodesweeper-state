# Issue #9603 — Docker Credential Helper list subcommand disconnects vscode from devcontainer

[https://github.com/microsoft/vscode-remote-release/issues/9603](https://github.com/microsoft/vscode-remote-release/issues/9603)

## Summary

Keep open for the Dev Containers owner: the minimal configuration and credential-helper command suffice to retest, and the logs show the container server terminating. Confirmations concern older releases; no verified fix or canonical duplicate establishes resolution today.

## Change summary

Running the forwarded Docker credential helper's list subcommand terminates the Dev Containers connection while the container keeps running.

## Best solution

The Dev Containers credential-forwarding bridge should return list results without terminating the server or shared connection. Retest the supplied configuration on current releases, including a WSL-hosted workspace, and investigate the list-specific failure if it persists.
