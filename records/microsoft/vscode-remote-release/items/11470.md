# Issue #11470 — Remote-SSH is not waiting long enough for the checking ssh command.

[https://github.com/microsoft/vscode-remote-release/issues/11470](https://github.com/microsoft/vscode-remote-release/issues/11470)

## Summary

This matches the older open issue tracking intermittent rejection of a valid Windows SSH binary when its version process produces output but does not exit before Remote-SSH's timeout.

## Change summary

Remote-SSH rejects an explicitly configured SSH executable when `ssh -V` takes longer than the fixed validation timeout, particularly on a resource-constrained VDI.

## Best solution

Consolidate on https://github.com/microsoft/vscode-remote-release/issues/11332. The SSH component should avoid rejecting a valid configured binary solely because its version process exits slowly; a configurable validation timeout is one possible remedy.
