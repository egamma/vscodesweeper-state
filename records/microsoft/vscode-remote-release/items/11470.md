# Issue #11470 — Remote-SSH is not waiting long enough for the checking ssh command.

[https://github.com/microsoft/vscode-remote-release/issues/11470](https://github.com/microsoft/vscode-remote-release/issues/11470)

## Summary

Keep open for the SSH owner to consider configurable local executable-validation timing on resource-constrained machines. The documented executable-path setting does not provide that control, and neither a covering implementation nor a canonical owning this configuration request was verified.

## Change summary

Allow configuring how long Remote - SSH waits for the local ssh -V validation process, particularly when remote.SSH.path is explicitly set.

## Best solution

Remote - SSH should offer bounded, configurable validation timing, or another reliable way to accept a valid SSH executable under heavy local CPU contention. Preserve bounded handling of genuinely stuck processes and distinguish validation timeouts from invalid binaries.
