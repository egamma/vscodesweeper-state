# Issue #2067 — OS specific dev containers

[https://github.com/microsoft/vscode-remote-release/issues/2067](https://github.com/microsoft/vscode-remote-release/issues/2067)

## Summary

Keep open: existing environment substitution and platform-specific script handling do not cover host-OS declarations, conditional properties, or compatibility warnings. This team-authored request has no verified canonical owning its full scope.

## Change summary

Allow dev containers to declare supported host operating systems and apply host-specific configuration, with appropriate filtering or warnings.

## Best solution

Coordinate host-platform semantics with the Dev Container specification, then implement conditional configuration and compatibility guidance in the Dev Containers extension. Define which host is evaluated for WSL and remote Docker workflows rather than assuming the UI client's OS.

- **Fit:** aligned
- **Reason:** Host-aware configuration would reduce mixed-platform setup failures while preserving consistent development environments.
