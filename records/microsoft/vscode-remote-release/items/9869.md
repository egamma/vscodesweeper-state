# Issue #9869 — Remote targets order is not determined by my ssh config

[https://github.com/microsoft/vscode-remote-release/issues/9869](https://github.com/microsoft/vscode-remote-release/issues/9869)

## Summary

The thread identifies a concrete ordering defect: integer-like SSH host aliases are reordered by JavaScript object-key enumeration instead of retaining ssh-config order. Keep this open and route it to SSH configuration and Remote Explorer.

## Change summary

Preserve ssh-config insertion order in Remote Explorer when Host aliases contain only digits.

## Best solution

Remote - SSH should retain an explicitly ordered host list rather than deriving it through Object.keys, so numeric and non-numeric aliases appear in ssh-config order.
