# Issue #9869 — Remote targets order is not determined by my ssh config

[https://github.com/microsoft/vscode-remote-release/issues/9869](https://github.com/microsoft/vscode-remote-release/issues/9869)

## Summary

Keep open: the detailed numeric-host ordering examples suffice to retest, and a maintainer identified an enumeration-order cause. The versions reported are from 2024; no later fix or resolution confirmation establishes that current releases preserve config order.

## Change summary

Numeric SSH Host aliases appear before other aliases and sort numerically instead of following their positions in the SSH config.

## Best solution

Remote - SSH should preserve SSH config order for numeric and nonnumeric aliases alike. Retest the supplied alias examples on current releases and, if still affected, correct the target-list ordering without requiring users to rename hosts.
