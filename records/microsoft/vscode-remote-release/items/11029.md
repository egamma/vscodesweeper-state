# Issue #11029 — Fail to read C:/Users/<username>/.ssh/config if the local username profile contains an accented character

[https://github.com/microsoft/vscode-remote-release/issues/11029](https://github.com/microsoft/vscode-remote-release/issues/11029)

## Summary

Keep open: the accented-profile path failure has a concrete 1.100.3 versus 1.101 regression comparison and an independent confirmation. Those steps suffice to retest newer releases; neither a current resolution nor a matching open canonical was established.

## Change summary

Accented Windows profile paths become corrupted, preventing automatic SSH config discovery and terminal startup after upgrading to VS Code 1.101.

## Best solution

Preserve Unicode Windows profile paths through Remote - SSH config discovery and connection startup. Investigate the integrated-terminal environment corruption alongside the SSH failure; if the defect is in core environment handling, a maintainer can transfer this to microsoft/vscode.
