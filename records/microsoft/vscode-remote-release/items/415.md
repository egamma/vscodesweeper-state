# Issue #415 — Allow a dev container to disable an extension 

[https://github.com/microsoft/vscode-remote-release/issues/415](https://github.com/microsoft/vscode-remote-release/issues/415)

## Summary

Keep open: the shipped minus-prefix syntax omits extension installation but does not cover disabling built-in extensions. The maintainer explicitly retained this reopened request after the related opt-out feature shipped.

## Change summary

Allow devcontainer.json to disable selected extensions, including built-in JavaScript/TypeScript or PHP language support.

## Best solution

Dev Containers should support declarative, container-specific extension disablement, including built-in extensions, without requiring each user to disable them manually. Retain this issue for that product-side work rather than folding it into the completed installation opt-out request.
