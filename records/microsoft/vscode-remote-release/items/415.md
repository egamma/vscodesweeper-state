# Issue #415 — Allow a dev container to disable an extension 

[https://github.com/microsoft/vscode-remote-release/issues/415](https://github.com/microsoft/vscode-remote-release/issues/415)

## Summary

A real capability gap remains: the shipped `-` prefix can omit extensions requested by container metadata, but it cannot disable built-in extensions. The request has maintainer confirmation, 46 upvotes, and is already correctly routed in the Backlog.

## Change summary

Allow a dev container configuration to disable selected extensions, including built-in VS Code language extensions.

## Best solution

Dev Containers should support a declarative per-container disabled-extension list, extending or complementing the existing `-` syntax so built-in extensions can also be disabled; this may require a corresponding VS Code core extension-management capability.
