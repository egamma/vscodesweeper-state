## Summary

Keep open: a maintainer explicitly retained this Backlog issue to improve Dev Containers support for Docker userns-remap setups, and the documented configuration options only provide partial workarounds.

## Change summary

Support building and using Dev Containers with Docker userns-remap without UID/GID update failures or unusable workspace and home-directory permissions.

## Best solution

Dev Containers should handle or clearly diagnose userns-remap when updating container UID/GID, while preserving writable bind mounts and home directories. The containers component owns this extension-side compatibility work.
