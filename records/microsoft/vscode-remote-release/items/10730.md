# Issue #10730 — Zombie Process (<defunct>) and Lingering Processes in VS Code Servers

[https://github.com/microsoft/vscode-remote-release/issues/10730](https://github.com/microsoft/vscode-remote-release/issues/10730)

## Summary

Keep open for Remote - SSH process-lifecycle investigation: independent users confirm accumulation, and the thread supplies a Reload Window trigger. Related fixes and reports do not establish resolution of the unreaped child and lingering server processes described here.

## Change summary

Remote SSH sessions leave defunct Node children and accumulating remote processes after disconnects or window reloads.

## Best solution

The SSH owner should investigate the reported bootstrap-shell lifetime and server cleanup after connection loss, distinguishing unreaped children from intentionally retained server processes. Verify ssh-agent ownership separately rather than assuming those processes share the same cause.
