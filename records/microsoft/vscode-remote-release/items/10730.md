# Issue #10730 — Zombie Process (<defunct>) and Lingering Processes in VS Code Servers

[https://github.com/microsoft/vscode-remote-release/issues/10730](https://github.com/microsoft/vscode-remote-release/issues/10730)

## Summary

Keep open as a confirmed Remote - SSH process-lifecycle bug. Multiple users reproduce accumulating server processes, and the newest report identifies a plausible keepalive-loop failure after disconnect.

## Change summary

Remote - SSH should terminate its bootstrap shell and server processes, and reap child processes, after the client disconnects.

## Best solution

The Remote - SSH owner should make the generated keepalive loop exit when writing to the disconnected client fails, then verify cleanup after Reload Window, Close Remote Connection, and hard disconnect. Any remaining defunct node or ssh-agent accumulation should be investigated separately from the identified server-lifetime cause.
