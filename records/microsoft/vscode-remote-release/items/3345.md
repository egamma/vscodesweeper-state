# Issue #3345 — Support Toolbox (a.k.a. Fedora Toolbox)

[https://github.com/microsoft/vscode-remote-release/issues/3345](https://github.com/microsoft/vscode-remote-release/issues/3345)

## Summary

A real Toolbox integration gap remains despite generic Podman attachment and community workarounds. Route this established feature request to the Podman refinement for a component-owner decision.

## Change summary

Provide first-class Dev Containers support for attaching to Fedora Toolbox containers with the correct user, environment, and VS Code Server location.

## Best solution

Dev Containers should either support Toolbox through generic attach configuration hooks or document a supported integration coordinated with https://github.com/containers/toolbox/issues/628, without requiring manual permission changes and server-directory symlinks.
