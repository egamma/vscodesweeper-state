# Issue #3345 — Support Toolbox (a.k.a. Fedora Toolbox)

[https://github.com/microsoft/vscode-remote-release/issues/3345](https://github.com/microsoft/vscode-remote-release/issues/3345)

## Summary

Keep open: documented Podman attachment covers parts of this workflow, but does not establish seamless Toolbox support. The reporter's early willingness to close was followed by reports that the third-party integration stopped working; no verified canonical owns the whole request.

## Change summary

Support attaching Dev Containers directly to existing Fedora Toolbox environments without fragile manual integration.

## Best solution

The Dev Containers owner should define a reliable attachment workflow for Toolbox-created containers, including non-root server installation and host-shared configuration handling. Coordinate Toolbox-side configuration generation with containers/toolbox while retaining any extension-side work here.
