[https://github.com/microsoft/vscode-remote-release/issues/10843](https://github.com/microsoft/vscode-remote-release/issues/10843)

## Summary

Keep open for reliable agent-tree cleanup when Podman reports zero process-group IDs. The related symlink-reuse defect was fixed, but that does not establish that cleanup is fixed; the supplied container recipe and process tables suffice to retest.

## Change summary

Dev Containers fails to terminate an obsolete server process tree when crun-backed Podman processes report PGID zero.

## Best solution
