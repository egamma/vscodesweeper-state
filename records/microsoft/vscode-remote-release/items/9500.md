## Summary

The thread identifies this as an upstream Docker Desktop for Mac filesystem issue, and the existing `upstream` classification is appropriate. The reporter's successful workaround and maintainer assessment both isolate the failure to the VirtioFS/Virtualization framework configuration.

## Change summary

Using Docker Desktop's VirtioFS and Virtualization framework causes the remote extension host's workspace lock handling to fail repeatedly inside a Dev Container.

## Best solution

Docker Desktop should correct the VirtioFS lock-file behavior under its Virtualization framework; Dev Containers should retain compatibility once that upstream filesystem behavior is fixed.
