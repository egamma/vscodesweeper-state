# Issue #463 — Update default extensions on every connection

[https://github.com/microsoft/vscode-remote-release/issues/463](https://github.com/microsoft/vscode-remote-release/issues/463)

## Summary

Keep open to verify that newly added default extensions are installed when reconnecting to an existing SSH server. Newer connection paths may already cover this, but the thread has no confirmed resolution and maintainers accepted the improvement.

## Change summary

Reconcile remote.SSH.defaultExtensions on every connection, rather than only during initial server installation.

## Best solution

Remote - SSH should install missing configured defaults on reconnect without reinstalling existing extensions or materially delaying connection. Retest the existing-server scenario on current connection paths and resolve any remaining gap before closing.
