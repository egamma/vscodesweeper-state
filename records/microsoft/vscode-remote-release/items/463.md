# Issue #463 — Update default extensions on every connection

[https://github.com/microsoft/vscode-remote-release/issues/463](https://github.com/microsoft/vscode-remote-release/issues/463)

## Summary

Keep open as the canonical request for reconciling SSH default extensions on every connection. The documented setting exists, but the thread shows it only applies during initial server setup, leaving changed settings and shared or ephemeral hosts uncovered.

## Change summary

Ensure extensions added to `remote.SSH.defaultExtensions` are installed when reconnecting to an existing SSH host, not only during its initial server installation.

## Best solution

Remote - SSH should list installed remote extensions on connection and install only missing entries from `remote.SSH.defaultExtensions`, avoiding the performance cost of reinstalling or checking every extension individually.
