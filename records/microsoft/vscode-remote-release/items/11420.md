[https://github.com/microsoft/vscode-remote-release/issues/11420](https://github.com/microsoft/vscode-remote-release/issues/11420)

## Summary

Verified duplicate: the open canonical issue already tracks exposing an option to disable BuildKit in the Dev Containers extension. This report adds a useful Podman disk-growth motivation but requests the same capability.

## Change summary

Allow Dev Containers users to disable BuildKit so its Podman build cache does not rapidly consume WSL disk space.

## Best solution
