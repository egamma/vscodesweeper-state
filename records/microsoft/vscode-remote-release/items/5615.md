# Issue #5615 — Hide popup when deleting permanently or support moving to trash

[https://github.com/microsoft/vscode-remote-release/issues/5615](https://github.com/microsoft/vscode-remote-release/issues/5615)

## Summary

The remaining WSL trash request is already tracked by the broader open VS Code issue, while the alternative request to suppress deletion confirmation is covered by `explorer.confirmDelete`.

## Change summary

Allow WSL files to be moved to trash, or permit permanent deletion without repeated confirmation.

## Best solution

Follow https://github.com/microsoft/vscode/issues/108731 for remote trash support. Users who intentionally want confirmation-free permanent deletion can set `explorer.confirmDelete` to `false`.
