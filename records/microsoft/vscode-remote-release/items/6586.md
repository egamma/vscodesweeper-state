# Issue #6586 — devcontainer.json does not pick up parameters from the env file and does not pass them to docker-compose

[https://github.com/microsoft/vscode-remote-release/issues/6586](https://github.com/microsoft/vscode-remote-release/issues/6586)

## Summary

The central gap remains: current documentation provides separate environment-variable mechanisms for Dev Containers and Docker Compose, but no declarative way for devcontainer.json to consume Compose's .env values. The issue is already correctly classified and accepted into the Backlog.

## Change summary

Provide one declarative source for values such as the workspace path that must be shared by devcontainer.json and docker-compose.yml.

## Best solution

Define a spec-level variable source in the devcontainers/spec tracker that lets devcontainer.json consume an environment file, then implement it in the Dev Containers extension. This should avoid requiring an OS-specific initializeCommand to generate Compose configuration.
