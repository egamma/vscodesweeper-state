# Issue #2648 — Can't connect to non-admin Windows account (Get-CimInstance PermissionDenied)

[https://github.com/microsoft/vscode-remote-release/issues/2648](https://github.com/microsoft/vscode-remote-release/issues/2648)

## Summary

Keep open: maintainers reproduced the failure with Windows Local Standard accounts, and it was still reported on VS Code 1.100.3. The administrative WMI-permission workaround does not address users who cannot alter the remote host.

## Change summary

Remote - SSH cannot start its Windows bootstrap under a non-administrator account because its Get-CimInstance calls are denied for SSH network logons.

## Best solution

Remote - SSH should detect the Windows version and SSH parent process without requiring WMI permissions unavailable to standard-account network logons, then verify that the server starts without elevation.
