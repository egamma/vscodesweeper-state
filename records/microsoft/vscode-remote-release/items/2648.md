# Issue #2648 — Can't connect to non-admin Windows account (Get-CimInstance PermissionDenied)

[https://github.com/microsoft/vscode-remote-release/issues/2648](https://github.com/microsoft/vscode-remote-release/issues/2648)

## Summary

Keep open as the established Remote - SSH tracking issue for non-admin Windows connections failing on CIM permissions. The October 2026 workaround confirmation supports continued relevance, not a shipped fix; the thread already supplies sufficient reproduction details.

## Change summary

Remote - SSH cannot initialize its Windows server under a standard account because bootstrap CIM queries fail with PermissionDenied despite ordinary SSH login working.

## Best solution

The SSH component should investigate replacing permission-sensitive CIM queries with non-WMI alternatives while preserving standard-user privileges. If those queries remain necessary, provide explicit diagnostics and official least-privilege setup guidance rather than relying on administrator accounts or broad permission grants.
