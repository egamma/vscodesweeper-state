# Issue #11672 — [Remote-SSH Bug]: Infinite reconnect loop on macOS — delay-shutdown IPC socket path exceeds macOS 103-char limit (EINVAL), regression in da03e4ef

[https://github.com/microsoft/vscode-remote-release/issues/11672](https://github.com/microsoft/vscode-remote-release/issues/11672)

## Summary

Keep this SSH regression open: reports of resolution in Remote - SSH 0.124.0 are contradicted by later matching failures. The supplied steps and logs suffice to retest current releases; this older, more-upvoted report remains the strongest canonical candidate.

## Change summary

Remote - SSH repeatedly reconnects after local IPC socket creation fails with EINVAL under macOS's default temporary directory.

## Best solution

The SSH component should ensure its local IPC paths fit macOS socket limits and handle socket initialization failure without an endless reconnect loop. Verify default-mode connections without TMPDIR overrides, distinguishing extension versions from VS Code versions when reconciling the mixed fix reports.
