# Issue #11672 — [Remote-SSH Bug]: Infinite reconnect loop on macOS — delay-shutdown IPC socket path exceeds macOS 103-char limit (EINVAL), regression in da03e4ef

[https://github.com/microsoft/vscode-remote-release/issues/11672](https://github.com/microsoft/vscode-remote-release/issues/11672)

## Summary

Keep open as the canonical report: multiple users reproduced this macOS regression, including a team member, and a later exact reproduction on VS Code 1.126.0 shows that the apparent 0.124.0 resolution was not conclusive.

## Change summary

Remote - SSH must avoid macOS Unix-socket path limits that make its local askpass server fail and reconnect indefinitely.

## Best solution

Remote - SSH should generate its local IPC socket under a bounded-length path on macOS and stop retrying indefinitely when socket creation fails. Consolidate the narrower reports at https://github.com/microsoft/vscode-remote-release/issues/11676, https://github.com/microsoft/vscode-remote-release/issues/11677, and https://github.com/microsoft/vscode-remote-release/issues/11778 into this older, well-diagnosed report.
