# Issue #401 — Support Linux ppc64le

[https://github.com/microsoft/vscode-remote-release/issues/401](https://github.com/microsoft/vscode-remote-release/issues/401)

## Summary

Keep open as the established request for official Linux ppc64le support. Current documentation excludes this architecture, and the thread's third-party successes do not establish support in Microsoft's Remote - SSH.

## Change summary

Support connecting with Remote - SSH to Linux ppc64le hosts, including IBM POWER9 servers running Red Hat.

## Best solution

The Remote - SSH and VS Code Server owners should decide whether to build, distribute, and maintain ppc64le server binaries and native dependencies, using the offered test systems. Retain this issue as the canonical product request rather than treating alternative clients as completion.

- **Evidence:** The public vision identifies SSH breadth and fidelity and the VS Code Server lifecycle as durable themes, with broad environment support subject to pragmatic limits.
