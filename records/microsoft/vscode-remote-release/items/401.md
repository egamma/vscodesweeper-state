# Issue #401 — Support Linux ppc64le

[https://github.com/microsoft/vscode-remote-release/issues/401](https://github.com/microsoft/vscode-remote-release/issues/401)

## Summary

This remains a valid, well-supported feature request. Current documentation still excludes ppc64le, and the existing s390x request concerns a distinct architecture rather than superseding this issue.

## Change summary

Build and support the Remote - SSH server and its native dependencies for Linux ppc64le hosts.

## Best solution

The Remote - SSH and VS Code Server owners should decide whether to add ppc64le builds, dependency testing, and a documented support tier. The existing SSH and code-server architecture should remain unchanged.

## Vision fit

- **Fit:** aligned
- **Reason:** Supporting ppc64le would extend remote-development parity to another Linux architecture through the established client-server model.
- **Evidence:** The public product promise is to "Open any folder in a container, on a remote machine, or in WSL and take advantage of VS Code's full feature set," while the documented support-matrix guardrail makes additional architectures a team scope decision.
