Keep open: the report provides concrete steps and timing evidence for slow Dev Containers agent discovery with host PID sharing. There is no independent retest since the August report, verified covering fix, or matching canonical; the supplied steps suffice to retest.

## Change summary

Reattaching to a container using --pid=host incurs approximately 30 seconds of per-process scanning before reusing its existing extension host agent.
