# Issue #9756 — Fail to attach docker container  /lib64/libc.so.6: version `GLIBC_2.28' not found

[https://github.com/microsoft/vscode-remote-release/issues/9756](https://github.com/microsoft/vscode-remote-release/issues/9756)

## Summary

The 2024 regression affected a narrow legacy-Linux, nested Remote-SSH/Dev Containers reconnection path. Dev Containers 0.360.0-pre-release included a mitigation, but nobody confirmed that release resolved the issue and the maintainer described the full compatibility fix as outstanding, so a current-version retest is needed.

## Change summary

Attaching to a container through Remote-SSH can select an incompatible fallback Node installation and fail with a GLIBC_2.28 error.

## Best solution

Dev Containers should use Remote-SSH's compatible Node installation when available and run the compatibility check to obtain the legacy server when necessary. First confirm whether the remaining legacy-URI path still fails on current releases and collect the full Dev Containers log if it does.
