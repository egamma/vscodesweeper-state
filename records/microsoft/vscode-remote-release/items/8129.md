# Issue #8129 — Feature request: devcontainer: add options to avoid applying the feature's `customizations`

[https://github.com/microsoft/vscode-remote-release/issues/8129](https://github.com/microsoft/vscode-remote-release/issues/8129)

## Summary

Keep open: the documented customization controls do not establish a settings opt-out, and no verified canonical owns this request. The existing containers routing is appropriate.

## Change summary

Allow installing Dev Container Features without applying their VS Code customizations, preserving the user's preferred terminal settings.

## Best solution

The Dev Containers extension should provide an explicit way to suppress Feature-provided settings while retaining the Feature's installed tooling. Coordinate any shared metadata changes with the Dev Container spec, but retain the extension-side implementation request here.
