# Issue #11643 — Dev Containers: add command to reinstall/sync extensions from devcontainer.json in the current container

[https://github.com/microsoft/vscode-remote-release/issues/11643](https://github.com/microsoft/vscode-remote-release/issues/11643)

## Summary

Keep this accepted Dev Containers request open: documented extension-installation options do not provide configuration-driven retry in the connected container. The marker-removal suggestion is an unconfirmed workaround, not a shipped recovery command.

## Change summary

Add a command that retries missing extensions declared in devcontainer.json in the current container, with visible progress and errors, without rebuilding.

## Best solution

Dev Containers should offer an explicit retry command using the active configuration's extension declarations, preserving already-installed extensions and reporting failures. Investigate the suggested marker-reset workaround as supporting context, without requiring users to manipulate internal server files.
