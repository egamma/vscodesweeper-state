# Issue #11643 — Dev Containers: add command to reinstall/sync extensions from devcontainer.json in the current container

[https://github.com/microsoft/vscode-remote-release/issues/11643](https://github.com/microsoft/vscode-remote-release/issues/11643)

## Summary

A real Dev Containers recovery gap remains: declared extensions can be installed during container setup, but there is no documented command to retry missing installations in the current container. The issue is already correctly classified and routed.

## Change summary

Add a command that synchronizes the current container with extensions declared in customizations.vscode.extensions without rebuilding it.

## Best solution

The Dev Containers extension should provide an in-place synchronization command that identifies missing declared extensions, retries their installation, and reports failures clearly.

- **Fit:** aligned
