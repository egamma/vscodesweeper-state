# Issue #11469 — Preserve / bring Copilot session data across remote targets

[https://github.com/microsoft/vscode-remote-release/issues/11469](https://github.com/microsoft/vscode-remote-release/issues/11469)

## Summary

Keep open: manual volume mounts and experimental history sync do not establish automatic session resumption across remote targets and container rebuilds. This team-authored Backlog request has no verified full-scope canonical or citable fix.

## Change summary

Automatically preserve and carry Copilot session data when rebuilding dev containers or switching between local, WSL, container, and SSH environments.

## Best solution

The Dev Containers owners should coordinate with WSL, SSH, and Copilot session owners on supported session persistence and migration, including repositories not hosted on GitHub. Preserve this issue's cross-target scope rather than replacing it with container-only storage workarounds.
