## Summary

Keep open for the Dev Containers owner to reconcile the naming proposal with the shipped CLI forwarding. The replacement addresses much of the original confusion, but this team-authored item has neither a verified open canonical nor an issue-referencing public fix that permits closure.

## Change summary

Differentiate the VS Code-installed devcontainer CLI from the reference CLI through clearer naming.

## Best solution

The Dev Containers owner should reconcile the proposed rename with the extension's forwarding to the reference CLI, explicitly deciding whether any wrapper or legacy-package naming work remains. Preserve a clear installation path and document the VS Code-only open command without implying that the two installations are interchangeable.
