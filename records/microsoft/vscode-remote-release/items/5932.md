# Issue #5932 — Sync the "haven't used remote-wsl" extension notification

[https://github.com/microsoft/vscode-remote-release/issues/5932](https://github.com/microsoft/vscode-remote-release/issues/5932)

## Summary

Keep this accepted WSL feature request open: the thread establishes that notification state was not synchronized, and no shipped implementation or qualifying canonical was found. Existing Settings Sync capabilities do not establish that this particular flag now syncs.

## Change summary

Synchronize WSL's already-used notification flag so experienced users do not receive the unused-extension reminder on each new PC.

## Best solution

The WSL extension should synchronize the user-level already-used or already-seen flag through globalState.setKeysForSync while keeping installation timing machine-local. Separately assess the later report that the reminder appears immediately after installation and repeats across windows.
