# Issue #5932 — Sync the "haven't used remote-wsl" extension notification

[https://github.com/microsoft/vscode-remote-release/issues/5932](https://github.com/microsoft/vscode-remote-release/issues/5932)

## Summary

This remains a concrete WSL extension feature request: notification state is not synchronized, so users can receive the onboarding prompt again on a new machine. The issue is already correctly routed and no canonical or evidence of implementation was found.

## Change summary

Synchronize the Remote-WSL used-or-dismissed state so its onboarding notification does not recur after setting up another machine.

## Best solution

The WSL extension should register the relevant global-state key with `Memento.setKeysForSync` and ensure the notification is not repeatedly shown across windows once acknowledged or after Remote-WSL has been used.
