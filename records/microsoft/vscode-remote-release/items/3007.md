# Issue #3007 — Add envFile to devcontainer.json and handle missing env file gracefully

[https://github.com/microsoft/vscode-remote-release/issues/3007](https://github.com/microsoft/vscode-remote-release/issues/3007)

## Summary

A real capability gap remains: the current Dev Container specification has no `envFile` property or graceful missing-file semantics, while documented alternatives either fail when the file is absent or require platform-specific setup. This issue is also the canonical request referenced by newer devcontainers issues.

## Change summary

Allow devcontainer configurations to load an optional environment file without failing container creation when that file is absent.

## Best solution

Define optional environment-file metadata and missing-file behavior in https://github.com/devcontainers/spec, then implement that specification in the Dev Containers extension and CLI. Keep this canonical request open and cross-link the eventual spec proposal.
