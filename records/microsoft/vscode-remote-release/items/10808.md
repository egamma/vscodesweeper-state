# Issue #10808 — `.gitconfig` not copied to development container when a symlink on host system

[https://github.com/microsoft/vscode-remote-release/issues/10808](https://github.com/microsoft/vscode-remote-release/issues/10808)

## Summary

The documented automatic `.gitconfig` copy does not work when the macOS host file is a symlink, but the available reports use year-old versions and do not establish whether this still reproduces on the current Dev Containers release.

## Change summary

Resolve a host `.gitconfig` symlink and copy its target contents into the development container during startup.

## Best solution

Confirm the behavior on the current Dev Containers release; if it persists, the containers component should resolve a valid host symlink before performing the documented `.gitconfig` copy.
