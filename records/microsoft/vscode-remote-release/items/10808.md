# Issue #10808 — `.gitconfig` not copied to development container when a symlink on host system

[https://github.com/microsoft/vscode-remote-release/issues/10808](https://github.com/microsoft/vscode-remote-release/issues/10808)

## Summary

Keep open for the Dev Containers owner to retest automatic Git configuration copying from a symlinked host file. The supplied steps, configuration and logs suffice; the reported versions are older than current releases, but neither a current reproduction nor a confirmed fix is established.

## Change summary

A host ~/.gitconfig symlink is reportedly not copied into a newly created development container.

## Best solution

Dev Containers should copy the readable contents of a symlinked host ~/.gitconfig when the container has no existing configuration. Retest the supplied setup, distinguishing symlink handling from an unavailable iCloud-backed target or an already-created container configuration.
