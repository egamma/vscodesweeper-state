# Issue #10808 — `.gitconfig` not copied to development container when a symlink on host system

[https://github.com/microsoft/vscode-remote-release/issues/10808](https://github.com/microsoft/vscode-remote-release/issues/10808)

## Summary

Keep open as a Dev Containers bug: the documented automatic `.gitconfig` copy fails for a reproducible host-side symlink configuration, and a second user independently confirmed the behavior.

## Change summary

Resolve a host `.gitconfig` symlink and copy its target into the development container.

## Best solution

The Dev Containers extension should follow a valid host-side `.gitconfig` symlink when performing its automatic copy, while preserving the existing behavior for regular files.
