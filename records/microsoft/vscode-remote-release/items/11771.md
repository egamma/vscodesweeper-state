# Issue #11771 — Dev Containers hangs indefinitely at "Installing VS Code Server" during `dd | tar` step (affects both x64 and ARM64)

[https://github.com/microsoft/vscode-remote-release/issues/11771](https://github.com/microsoft/vscode-remote-release/issues/11771)

## Summary

A detailed current-version reproduction across two architectures, plus an independent recent confirmation, indicates a Dev Containers server-install hang. Keep it open and route it to the containers installation path.

## Change summary

Dev Containers indefinitely stalls while streaming and extracting the VS Code Server through the `dd | tar` installation command.

## Best solution

The Dev Containers owner should diagnose why the client-to-container server archive stream does not reach EOF and ensure the installation either completes or fails with an actionable timeout and diagnostic output.
