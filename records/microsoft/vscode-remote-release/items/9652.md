# Issue #9652 — [devcontainers] Warn users using Docker Desktop on Linux

[https://github.com/microsoft/vscode-remote-release/issues/9652](https://github.com/microsoft/vscode-remote-release/issues/9652)

## Summary

Keep the Dev Containers warning request open: documented user and volume workarounds do not deliver automatic detection and guidance for Docker Desktop on Linux. The related rootless-Docker issue does not establish ownership of this Desktop-specific UX request.

## Change summary

Detect Docker Desktop on Linux configurations with bind-mount ownership problems and warn users with actionable guidance.

## Best solution

The Dev Containers extension should assess whether the affected Docker Desktop configuration is still identifiable and offer targeted guidance when workspace permissions prevent non-root editing, rather than warning every Linux Desktop user. Coordinate with the related rootless-permissions discussion without losing this product-side diagnostic request.

- **Existing-capability check:** https://code.visualstudio.com/remote/advancedcontainers/add-nonroot-user documents remoteUser, containerUser, and updateRemoteUserUID for user selection and Linux UID/GID matching. https://code.visualstudio.com/docs/devcontainers/containers documents Dev Containers: Clone Repository in Container Volume... to avoid workspace bind mounts. These are configuration or workflow alternatives, not automatic Docker Desktop-on-Linux detection and warnings.
