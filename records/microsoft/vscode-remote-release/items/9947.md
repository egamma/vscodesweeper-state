# Issue #9947 — [Remote-SSH Bug]: Wrong user name used if it has spaces

[https://github.com/microsoft/vscode-remote-release/issues/9947](https://github.com/microsoft/vscode-remote-release/issues/9947)

## Summary

Keep open: the quoted SSH configuration, connection steps, and full log suffice to retest the username-display defect on current releases. The report concerns Remote - SSH 0.110.1; no subsequent fix or resolution is confirmed, and the logged disconnect occurs after successful authentication.

## Change summary

Remote - SSH displays an incorrect username when the configured account name contains spaces, and the reported connection subsequently fails.

## Best solution

The SSH component should preserve the complete account name in password prompts and separately investigate the post-authentication disconnect. Retest the supplied configuration on current releases, comparing the displayed username with OpenSSH's prompt rather than assuming authentication used the truncated name.
