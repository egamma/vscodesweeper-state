# Issue #6955 — `--diff` on workspace files opens the workspace instead of diff-ing them

[https://github.com/microsoft/vscode-remote-release/issues/6955](https://github.com/microsoft/vscode-remote-release/issues/6955)

## Summary

The original report clearly distinguished a remote-only CLI defect from the locally fixed VS Code bug, but there is no current-release confirmation after four years. A retest is needed before the remaining remote behavior can be assessed.

## Change summary

Running `code --diff` on two `.code-workspace` files inside WSL, SSH, or a dev container opens a workspace instead of showing the requested diff.

## Best solution

The shared remote CLI/server path should preserve `--diff` semantics for two workspace-file arguments rather than interpreting the first argument as a workspace to open. First confirm the behavior on current WSL, Remote - SSH, and Dev Containers releases and identify which transports remain affected.
