# Issue #9977 — Add the ability to use local container configuration templates

[https://github.com/microsoft/vscode-remote-release/issues/9977](https://github.com/microsoft/vscode-remote-release/issues/9977)

## Summary

Keep open: documented container-creation workflows do not establish support for discovering disk-backed templates in the picker. The older custom-repository request is related, but does not explicitly own this local-filesystem capability.

## Change summary

Allow locally stored, spec-compliant Dev Container templates to appear in the New Dev Container picker, potentially through configurable search paths.

## Best solution

The Dev Containers extension should support discovering and applying local template directories using existing template metadata and option handling, without requiring registry publication. Coordinate with the custom-repository discovery request while preserving the disk-backed requirement.
