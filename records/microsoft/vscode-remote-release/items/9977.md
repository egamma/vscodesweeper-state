# Issue #9977 — Add the ability to use local container configuration templates

[https://github.com/microsoft/vscode-remote-release/issues/9977](https://github.com/microsoft/vscode-remote-release/issues/9977)

## Summary

A real Dev Containers capability gap remains: current documentation only exposes indexed templates, not configurable local template search paths. The related repository/private-template request does not clearly own this narrower local-disk workflow.

## Change summary

Allow spec-compliant templates stored in configurable local directories to appear in the Dev Containers configuration picker.

## Best solution

The Dev Containers extension should support configurable local template directories in its template picker while preserving compatibility with the Dev Container Template specification.
