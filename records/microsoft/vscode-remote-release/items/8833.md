# Issue #8833 — Failed to build container with "cannot create directory '/home/vscode': Permission denied"

[https://github.com/microsoft/vscode-remote-release/issues/8833](https://github.com/microsoft/vscode-remote-release/issues/8833)

## Summary

The reported failure is tied to Docker builder/cache behavior rather than a confirmed Dev Containers defect. The reporter resolved it by upgrading Docker, while later reports show the same message can also result from stale Docker state, so this should remain classified as upstream.

## Change summary

Dev-container startup fails because the generated UID-adjusted image leaves `/home/vscode` owned by root, preventing creation of the VS Code server directory.

## Best solution

Docker should preserve the configured user's home ownership during the UID-adjustment build. The Containers component can retain this issue as upstream compatibility evidence and improve diagnostics when the generated image has incorrect home ownership.
