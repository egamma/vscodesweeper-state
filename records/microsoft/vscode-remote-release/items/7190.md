## Summary

Keep this accepted Dev Containers request open: documented offline installation is manual and does not cover automatic startup installation through an internet-connected client. No verified fix or canonical with the same observable symptom supersedes this report.

## Change summary

## Best solution

Dev Containers should provide a supported client-download-and-transfer fallback for configured extensions during container startup, without requiring a terminal session or timing-dependent lifecycle script. Retest that startup path specifically; SSH installation improvements alone do not establish that this request is delivered.
