# Issue #7190 — Air gaped remote host: Extensions do not auto install

[https://github.com/microsoft/vscode-remote-release/issues/7190](https://github.com/microsoft/vscode-remote-release/issues/7190)

## Summary

A real Dev Containers air-gap gap remains: extensions declared in devcontainer.json cannot be installed automatically when the remote container lacks Marketplace access. This focused report is the established canonical issue for offline extension installation.

## Change summary

Allow a connected local VS Code client to supply and automatically install devcontainer.json extensions on an air-gapped remote container.

## Best solution

Dev Containers should stage extension packages through the connected desktop or a configurable offline source before server startup, allowing customizations.vscode.extensions to work without Marketplace access from the container.
