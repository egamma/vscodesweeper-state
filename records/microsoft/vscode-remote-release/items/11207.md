# Issue #11207 — VSCode Tunnel expires after 24 hours and have an error on refreshing the token.

[https://github.com/microsoft/vscode-remote-release/issues/11207](https://github.com/microsoft/vscode-remote-release/issues/11207)

## Summary

The GitHub-authenticated tunnel still loses authorization during long-running or concurrent use, with multiple confirmations and a recent recurrence. Keep it open and route it to the tunnel CLI connection lifecycle.

## Change summary

Long-running GitHub-authenticated tunnels fail with a 401 after their access token becomes invalid and cannot refresh without interactive authentication.

## Best solution

The tunnels CLI should preserve unattended GitHub authentication across reconnects and concurrent tunnels, ideally through a refresh-capable GitHub app flow; otherwise it should clearly diagnose token eviction and document the supported durable authentication option.
