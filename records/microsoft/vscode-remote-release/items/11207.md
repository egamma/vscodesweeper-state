# Issue #11207 — VSCode Tunnel expires after 24 hours and have an error on refreshing the token.

[https://github.com/microsoft/vscode-remote-release/issues/11207](https://github.com/microsoft/vscode-remote-release/issues/11207)

## Summary

Keep open: September 2026 reports, including a maintainer's logged reproduction, confirm tunnel authentication recovery failures remain actionable. The GitHub token-expiry explanation does not establish resolution of the later Microsoft-authenticated failure.

## Change summary

Long-running tunnels lose authentication or remain offline after restart, requiring manual logout and re-enablement instead of recovering access.

## Best solution

The tunnels/CLI owners should distinguish GitHub access-token invalidation from tunnel-service host-token renewal failures, then ensure recoverable sessions reconnect and unrecoverable authentication is clearly surfaced rather than displaying remote access as enabled.
