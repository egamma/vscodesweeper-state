# Issue #727 — Please add support for FreeBSD

[https://github.com/microsoft/vscode-remote-release/issues/727](https://github.com/microsoft/vscode-remote-release/issues/727)

## Summary

Native FreeBSD remote development remains an unmet platform-support request, not a resolved connection bug. Retain this older, heavily supported report and route it to Remote - SSH and VS Code Server owners.

## Change summary

Support connecting from desktop VS Code to FreeBSD hosts with a native remote server and remote development features.

## Best solution

The Remote - SSH and VS Code Server owners should assess native FreeBSD server distribution, installation, and compatibility with remote extensions, terminals, and file watching. Keep this report as the established request rather than replacing it with newer, less-supported reports.
