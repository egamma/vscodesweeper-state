# Issue #727 — Please add support for FreeBSD

[https://github.com/microsoft/vscode-remote-release/issues/727](https://github.com/microsoft/vscode-remote-release/issues/727)

## Summary

FreeBSD remains officially unsupported, while community Linux-compatibility workarounds do not provide native or complete support. This is the oldest, broadest, and most-supported canonical request, so it should remain open and be routed to the SSH and VS Code Server owners.

## Change summary

Add native FreeBSD remote-host support to Remote - SSH and distribute a compatible VS Code Server build.

## Best solution

The SSH and code-server components should either ship and recognize a supported FreeBSD server target or make an explicit scope decision. Newer FreeBSD connection and server requests should consolidate here.
