# Issue #11382 — Allow configuring SCP similar to `Remote.SSH: Path` setting

[https://github.com/microsoft/vscode-remote-release/issues/11382](https://github.com/microsoft/vscode-remote-release/issues/11382)

## Summary

Keep open as a Remote - SSH feature request: the documented SSH executable and download settings do not provide the requested SCP executable override, and no verified canonical owns that capability.

## Change summary

Allow configuring the SCP executable or wrapper independently so Windows-hosted Remote - SSH can perform server transfers through WSL.

## Best solution

Remote - SSH should provide an SCP executable override alongside remote.SSH.path, allowing connection and server-transfer commands to use compatible WSL wrappers without requiring remote downloads.

- **Existing-capability check:** https://code.visualstudio.com/docs/remote/troubleshooting#_installing-a-supported-ssh-client documents remote.SSH.path for choosing the SSH client. https://code.visualstudio.com/docs/remote/ssh#_connectivity-requirements documents remote.SSH.localServerDownload for choosing local versus remote downloads. Neither documented capability selects the SCP executable; disabling local downloads bypasses rather than fulfills the requested transfer behavior.
