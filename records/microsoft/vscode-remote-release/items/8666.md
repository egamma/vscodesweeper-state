# Issue #8666 — SSH Agent - Public Key Denied

[https://github.com/microsoft/vscode-remote-release/issues/8666](https://github.com/microsoft/vscode-remote-release/issues/8666)

## Summary

Keep open for the runtime compatibility check explicitly requested by the maintainer. Documentation now explains the OpenSSH incompatibility, but the Dev Containers diagnostic gap remains.

## Change summary

Detect incompatible Windows and container OpenSSH versions and explain the resulting forwarded-key authentication failure in the Dev Containers log.

## Best solution

Dev Containers should detect the Windows OpenSSH agent <=8.8 and container OpenSSH >=8.9 combination at startup and log an actionable upgrade message.
