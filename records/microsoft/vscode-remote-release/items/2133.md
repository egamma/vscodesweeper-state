# Issue #2133 — Ability to launch .devcontainer project from command line

[https://github.com/microsoft/vscode-remote-release/issues/2133](https://github.com/microsoft/vscode-remote-release/issues/2133)

## Summary

The remaining request for a direct `code` CLI command is now owned by an open VS Code core backlog issue. The extension-installed `devcontainer open [path]` command already provides the one-shot workflow, but not the requested integrated `code` syntax.

## Change summary

Allow a folder containing `.devcontainer` configuration to be opened directly in its development container from the command line.

## Best solution

Follow https://github.com/microsoft/vscode/issues/236565 for an integrated `code devcontainer` command; meanwhile, retain the documented `devcontainer open [path]` command supplied through the Dev Containers extension.

## Vision fit

- **Fit:** aligned
- **Reason:** A direct launch path improves the accessibility and depth of the standard Dev Containers workflow.
- **Evidence:** The product promise is to “Open any folder in a container” while retaining VS Code's full feature set, and Dev Container capability depth is a durable theme.
