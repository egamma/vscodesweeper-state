# Issue #10339 — Remote-SSH: Forward Git Credential Helper

[https://github.com/microsoft/vscode-remote-release/issues/10339](https://github.com/microsoft/vscode-remote-release/issues/10339)

## Summary

This remains a valid, accepted SSH feature request: local Git credential forwarding is documented for Dev Containers but not Remote - SSH, and the issue earned 16 upvotes before moving to the Backlog.

## Change summary

Allow Git operations on a Remote - SSH host to use the client's local Git Credential Manager identity and stored access tokens.

## Best solution

Remote - SSH should securely proxy Git credential-helper requests to the local client, preferably falling back to it when the remote helper cannot authenticate, while preserving any remote helper that succeeds.

## Vision fit

- **Fit:** aligned
- **Reason:** Forwarding the client's credential helper would improve SSH fidelity and make remote Git authentication behave more like local development.
