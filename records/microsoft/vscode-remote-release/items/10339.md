# Issue #10339 — Remote-SSH: Forward Git Credential Helper

[https://github.com/microsoft/vscode-remote-release/issues/10339](https://github.com/microsoft/vscode-remote-release/issues/10339)

## Summary

Keep this accepted SSH feature request open: documented credential-helper forwarding covers Dev Containers, not the requested plain Remote-SSH workflow. The earlier identical request is closed, and no verified open canonical owns this work.

## Change summary

Allow Git on a Remote-SSH host to reuse Azure identities and access tokens through the client's Git Credential Manager.

## Best solution

The SSH component should provide supported forwarding of local Git credential-helper requests for plain remote folders, with explicit control over credential sharing. Container forwarding and configuring a separate remote helper do not deliver the requested reuse of the client's existing identity.

## Vision fit

- **Fit:** aligned
- **Reason:** Extending credential-helper reuse from containers to SSH addresses a remote-development parity gap within the existing architecture.
- **Evidence:** Layer 1 promises access to VS Code's full feature set across remote environments and identifies parity gaps as central product work.
