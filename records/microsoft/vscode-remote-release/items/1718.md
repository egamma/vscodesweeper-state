# Issue #1718 — Allow pre-installing VS code server and extensions in development Docker image

[https://github.com/microsoft/vscode-remote-release/issues/1718](https://github.com/microsoft/vscode-remote-release/issues/1718)

## Summary

Keep open: documented image prebuilding and extension configuration do not establish supported build-time installation of both the VS Code Server and remote extensions. The thread offers useful scripts, but not a confirmed product implementation.

## Change summary

Allow reusable development Docker images to contain the VS Code Server and remote extensions before the first connection.

## Best solution

The Dev Containers component should provide a supported image-build installation workflow, with explicit client/server version compatibility and extension-placement guidance, so new containers can reuse those installations.
