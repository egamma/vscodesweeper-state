# Issue #2084 — .gitconfig includeif not available inside container

[https://github.com/microsoft/vscode-remote-release/issues/2084](https://github.com/microsoft/vscode-remote-release/issues/2084)

## Summary

This remains the canonical feature request for preserving conditional Git configuration in Dev Containers. Current documentation confirms that only the primary local `.gitconfig` is copied automatically, while mounts, dotfiles, and lifecycle scripts are incomplete per-project workarounds.

## Change summary

Make host Git configuration using `includeIf` available inside Dev Containers without requiring repository-specific mounts or scripts.

## Best solution

The Dev Containers component should resolve applicable includes when constructing the container Git configuration, copying or flattening safe entries while excluding host-specific settings such as credential helpers. Any design should preserve Git's normal repository-local resolution and avoid copying secrets unintentionally.
