# Issue #2084 — .gitconfig includeif not available inside container

[https://github.com/microsoft/vscode-remote-release/issues/2084](https://github.com/microsoft/vscode-remote-release/issues/2084)

## Summary

Keep open: documented mounts and dotfiles support require manual configuration rather than automatically carrying host conditional Git configuration into containers. Maintainer history identifies this issue as the tracking home; no shipped resolution is established.

## Change summary

Preserve the host repository's conditional Git configuration inside dev containers without developer-specific per-repository setup.

## Best solution

The Dev Containers component should support transferring the applicable host Git configuration, accounting for included files and changed workspace paths. Coordinate with https://github.com/microsoft/vscode-remote-release/issues/3331 while retaining this maintainer-designated tracking issue.
