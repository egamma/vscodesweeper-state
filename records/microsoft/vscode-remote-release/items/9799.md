## Summary

Keep this containers bug open: the supplied Dockerfile, configuration, and logs suffice to retest the erroneous scratch image lookup. The report predates current releases, but later workaround reports and the still-open CLI issue provide no evidence of resolution.

## Change summary

Dev Containers fails to build a Dockerfile whose final stage uses FROM scratch and copies a complete filesystem from an earlier stage.

## Best solution

Dev Containers should build this valid multistage Dockerfile without attempting to inspect or pull scratch as a registry image. Coordinate with https://github.com/devcontainers/cli/issues/239 and verify the corrected behavior in the extension's bundled build path; retain this product report until that path is resolved.
