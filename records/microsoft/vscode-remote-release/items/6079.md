# Issue #6079 — Custom remote installation directory for Containers

[https://github.com/microsoft/vscode-remote-release/issues/6079](https://github.com/microsoft/vscode-remote-release/issues/6079)

## Summary

Keep open as the established Containers installation-directory request. Documented volume mounts offer a workaround, but do not provide a configurable server location for existing-container attachment or installation outside the user's home.

## Change summary

Allow configuring the VS Code Server installation directory inside containers independently of the Remote - SSH installation path.

## Best solution

The Dev Containers extension should support a configurable server installation location for both dev-container creation and attachment to existing containers, without requiring a different home directory. Keep this issue as the canonical product request and document volume mounting as a partial workaround.
