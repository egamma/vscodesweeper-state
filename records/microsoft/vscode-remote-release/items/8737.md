# Issue #8737 — Dockerfile 'platform' argument in 'from' command seems to get ignored.

[https://github.com/microsoft/vscode-remote-release/issues/8737](https://github.com/microsoft/vscode-remote-release/issues/8737)

## Summary

The logs support a Dev Containers image-inspection bug, and newer reports describe the same failure, but there is no confirmation on a current release. Ask for a current-version retest before retaining this as the canonical report.

## Change summary

Dev Containers pulls an ARM64 image before building even when the Dockerfile's FROM instruction explicitly selects linux/amd64.

## Best solution

The Containers implementation should honor the Dockerfile platform while inspecting or pulling the base image before the build. If reproduced currently, keep this oldest report as the canonical issue and consolidate the newer matching reports into it.
