# Issue #168 — Local tasks

[https://github.com/microsoft/vscode-remote-release/issues/168](https://github.com/microsoft/vscode-remote-release/issues/168)

## Summary

Keep open as the established tracker for local task execution from remote workspaces. Local terminals cover the manual-command portion, but not the requested remote-build/local-flash task chain.

## Change summary

Allow tasks in a remote workspace to execute selected commands on the local machine and participate in build/debug task chains.

## Best solution

Provide explicit local execution targeting for tasks while preserving remote execution by default, coordinated between the tasks owner and remote components. Retain this issue as the canonical request spanning SSH, containers, WSL, and tunnels.
