# Issue #7738 — DevContainers for the same project kill each other on shared remote host

[https://github.com/microsoft/vscode-remote-release/issues/7738](https://github.com/microsoft/vscode-remote-release/issues/7738)

## Summary

Verified duplicate: the open canonical issue tracks this exact container-identity collision when multiple users share a Docker host and have matching local project paths.

## Change summary

Dev Containers removes another developer's running container because both projects have the same local path on a shared remote Docker host.

## Best solution

Consolidate on https://github.com/microsoft/vscode-remote-release/issues/2677 and make Dev Containers distinguish containers using more than the local project path when a Docker daemon is shared.
