# Issue #10536 — [devcontainers] Extension does not accept .devcontainer.json as a symlink

[https://github.com/microsoft/vscode-remote-release/issues/10536](https://github.com/microsoft/vscode-remote-release/issues/10536)

## Summary

Keep open: the report supplies a concrete symlink command and comparison cases sufficient to retest configuration discovery. Releases have advanced since the March 2025 corroboration, but no current confirmation, applicable fix, or verified canonical establishes resolution.

## Change summary

A root-level .devcontainer.json symlink does not trigger the Dev Container configuration notification, while the same configuration linked under .devcontainer/devcontainer.json does.

## Best solution

The Dev Containers extension should recognize a valid root-level .devcontainer.json symlink consistently with the nested configuration location. Retest the supplied comparison cases on current releases and address the discovery discrepancy if it persists.
