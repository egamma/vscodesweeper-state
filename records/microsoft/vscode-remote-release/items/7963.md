# Issue #7963 — Housekeep the remote installation location

[https://github.com/microsoft/vscode-remote-release/issues/7963](https://github.com/microsoft/vscode-remote-release/issues/7963)

## Summary

Keep open: automatic retention already exists, but a configurable limit below five remains an unmet need for quota-limited SSH hosts. Maintainers accepted this direction, and the matching configurable-retention request was consolidated here.

## Change summary

Allow users to configure how many Remote - SSH server versions are retained automatically.

## Best solution

Expose a Remote - SSH retention setting and pass it to the CLI-managed server cache, allowing quota-limited hosts to retain fewer versions. Keep this issue as the tracking home for configurable SSH retention.
