# Issue #7963 — Housekeep the remote installation location

[https://github.com/microsoft/vscode-remote-release/issues/7963](https://github.com/microsoft/vscode-remote-release/issues/7963)

## Summary

This accepted Backlog request remains necessary: the public VS Code CLI still hardcodes retention at five server downloads, with no documented configuration for space-constrained remote homes.

## Change summary

Allow Remote - SSH users to configure how many previous VS Code Server installations are retained.

## Best solution

Remote - SSH should expose a retention setting and pass it to the VS Code CLI download cache, while preserving five as the default. This would support quota-constrained SSH hosts without requiring complete server removal or manual cleanup.
