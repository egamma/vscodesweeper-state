Keep open for Dev Containers investigation: the supplied configuration and image-only comparison suffice to retest the missing dotfiles installation. No confirmed fix or canonical covering this image-dependent failure was found.

## Change summary

Dotfiles are not cloned or installed in a dev container over SSH with base:ubuntu, while base:noble works with unchanged settings.
