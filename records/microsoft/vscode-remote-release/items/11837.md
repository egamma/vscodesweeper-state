# Issue #11837 — OOM when creating devcontainer with shared network

[https://github.com/microsoft/vscode-remote-release/issues/11837](https://github.com/microsoft/vscode-remote-release/issues/11837)

## Summary

This matches the verified open issue tracking host-network port-forwarding self-loops and runaway process creation. Consolidate the new minimal reproduction there rather than reopening the previously closed report.

## Change summary

Connecting to an unbound forwarded port in a host-network dev container creates a recursive forwarding loop that exhausts memory.

## Best solution

Track the fix in https://github.com/microsoft/vscode-remote-release/issues/9993: Dev Containers should prevent forwarding connections back into their own listeners when host networking shares the network namespace. Preserve this report's explicit forwardPorts reproduction and server-tunnel logs there.
