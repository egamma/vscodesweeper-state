# Issue #10945 — devcontainer.json: add support for multi-platform "localEnv" in "mounts"

[https://github.com/microsoft/vscode-remote-release/issues/10945](https://github.com/microsoft/vscode-remote-release/issues/10945)

## Summary

Verified cross-repository duplicate: the open Dev Container spec proposal tracks the same need for a reliable platform-independent local home variable.

## Change summary

Provide conditional or platform-independent local path substitution for cross-platform bind mounts in devcontainer.json.

## Best solution

Define a portable home-directory variable through https://github.com/devcontainers/spec/issues/335, then have supporting tools including Dev Containers consume that standardized variable.
