# Issue #10945 — devcontainer.json: add support for multi-platform "localEnv" in "mounts"

[https://github.com/microsoft/vscode-remote-release/issues/10945](https://github.com/microsoft/vscode-remote-release/issues/10945)

## Summary

This is covered by the open Dev Container specification proposal for a reliable cross-platform local home variable. Consolidating there preserves the demand and avoids defining extension-specific conditional syntax.

## Change summary

Provide a portable way for devcontainer.json mounts to reference the host user's directory across Windows, Linux, and macOS.

## Best solution

Follow https://github.com/devcontainers/spec/issues/335 and review the linked CLI implementation at https://github.com/devcontainers/cli/pull/1111; a standardized local-home variable would let this mount append `/Desktop/nwtimetracking` without OS-specific environment variables.
