# Issue #8496 — Compose: Use default `workspaceFolder` and mount point

[https://github.com/microsoft/vscode-remote-release/issues/8496](https://github.com/microsoft/vscode-remote-release/issues/8496)

## Summary

This is a duplicate of the older open request for Docker Compose configurations to receive the same automatic workspace path behavior as image- and Dockerfile-based configurations.

## Change summary

Infer a default workspace mount and workspaceFolder for Docker Compose configurations instead of requiring duplicate explicit configuration.

## Best solution

Consolidate on https://github.com/microsoft/vscode-remote-release/issues/6472. The Dev Containers component should provide Compose workspace defaults equivalent to single-container configurations while keeping Compose working_dir semantically separate.
