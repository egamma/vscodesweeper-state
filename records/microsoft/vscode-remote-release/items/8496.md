# Issue #8496 — Compose: Use default `workspaceFolder` and mount point

[https://github.com/microsoft/vscode-remote-release/issues/8496](https://github.com/microsoft/vscode-remote-release/issues/8496)

## Summary

Keep open: Docker Compose still lacks the documented automatic workspace selection and source mount provided for single containers. A maintainer proposed investigating that improvement; the existing explicit configuration does not satisfy it.

## Change summary

Provide sensible default workspaceFolder selection and a default workspace mount for Docker Compose dev containers.

## Best solution

The Dev Containers component should implement Compose workspace and mount defaults while preserving explicitly configured paths and the separate meaning of working_dir. Coordinate any specification changes without losing the extension-side implementation request.
