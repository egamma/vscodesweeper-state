# Issue #4289 — Jumping into and out of WSL needs polish

[https://github.com/microsoft/vscode-remote-release/issues/4289](https://github.com/microsoft/vscode-remote-release/issues/4289)

## Summary

The requested same-window WSL commands now exist, but preserving the Explorer and sidebar state across the transition remains an unresolved UX gap. Keep the issue open for that narrower WSL polish work.

## Change summary

Make transitions between local and WSL windows reuse the current window and preserve its Explorer and sidebar visibility state.

## Best solution

The WSL extension should preserve relevant workbench layout state when connecting, reopening in WSL, or returning to Windows. The issue can be narrowed to that remaining behavior because current commands already cover same-window connection and folder selection.
