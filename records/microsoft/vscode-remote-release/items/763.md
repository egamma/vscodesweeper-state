## Summary

The current Dev Containers workflow provides a progress notification with status updates during container creation, directly addressing the reported uncertainty about whether setup has stalled.

## Change summary

Keep the shipped Dev Containers progress notification as the standard setup feedback; distinct cases where progress does not appear should be tracked as bugs.
