# Issue #763 — Progress bar when installing Remote server

[https://github.com/microsoft/vscode-remote-release/issues/763](https://github.com/microsoft/vscode-remote-release/issues/763)

## Summary

Keep open: Dev Containers now documents setup status notifications, but the available evidence does not establish measurable progress during server installation. No verified open canonical owns this specific request.

## Change summary

Show installation progress when opening a dev container so users can distinguish a slow server setup from a stalled operation.

## Best solution

The containers component should provide meaningful server-download and installation progress within its setup notification. Assess whether the current notification covers that stage; general build status alone does not establish that the requested feedback exists.
