# Issue #9414 — Fall back to downloading server from the remote VM when local download has failed

[https://github.com/microsoft/vscode-remote-release/issues/9414](https://github.com/microsoft/vscode-remote-release/issues/9414)

## Summary

Keep open as the maintainer-designated Dev Containers fallback request. Manual server installation worked around the connection failure, but did not deliver automatic remote downloading; the older related request reports slow transfers rather than this item's failed local download.

## Change summary

Fall back to downloading VS Code Server on the remote VM when Dev Containers cannot download it locally.

## Best solution

Dev Containers should support remote-VM server downloading after a local download failure, subject to the team's policy considerations. Preserve this issue as the fallback-specific tracker and coordinate with the related remote-first download request.
