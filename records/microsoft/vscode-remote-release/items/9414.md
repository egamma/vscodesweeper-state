# Issue #9414 — Fall back to downloading server from the remote VM when local download has failed

[https://github.com/microsoft/vscode-remote-release/issues/9414](https://github.com/microsoft/vscode-remote-release/issues/9414)

## Summary

This remains a valid Dev Containers feature request: a maintainer explicitly reopened it to track downloading through the remote VM when the local download fails. The documented manual installation workaround restores service but does not provide the requested automatic fallback.

## Change summary

Fall back to downloading the VS Code Server through the remote VM when the Dev Containers extension cannot download it locally.

## Best solution

Dev Containers should retry server acquisition from the remote VM when the local download fails, then install it into the container through the existing server-installation flow. Preserve the manual `/vscode/vscode-server/bin/<commit>` workaround for environments where neither route is automatically available.
