# Issue #2704 — Install default extensions on WSL (as for SSH and containers)

[https://github.com/microsoft/vscode-remote-release/issues/2704](https://github.com/microsoft/vscode-remote-release/issues/2704)

## Summary

Keep this accepted WSL feature request open: CLI installation now addresses the fallback question, but the verified capabilities do not provide automatic installation from a configured default-extension list.

## Change summary

Provide a WSL equivalent of the SSH and Dev Containers default-extension settings for automated extension provisioning.

## Best solution

The WSL extension should support a configurable default-extension list installed automatically when connecting to a distribution. Preserve this issue as the tracking item; CLI installation is a useful workaround, not equivalent declarative provisioning.
