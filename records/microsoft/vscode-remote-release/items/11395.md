# Issue #11395 — ssh needs to input password twice

[https://github.com/microsoft/vscode-remote-release/issues/11395](https://github.com/microsoft/vscode-remote-release/issues/11395)

## Summary

The two prompts match documented socket-mode behavior: separate SSH connections authenticate for server startup and socket forwarding. Repeated authentication in new windows also matches the configured Terminal Mode rather than shared Local Server Mode.

## Change summary

The reporter wants one password prompt when connecting and no additional prompts when opening another remote window.

## Best solution

Retain the documented SSH connection behavior and explain the configuration tradeoff. Use public-key authentication for socket mode; if socket mode is not required, disable it and enable Local Server Mode to reuse connections across windows.

  > Thanks for the detailed log. Both password prompts authenticate successfully: the first starts the server, and the second establishes socket forwarding. Your `remote.SSH.remoteServerListenOnSocket: true` setting disables connection multiplexing; the documentation recommends public-key authentication for this mode: https://code.visualstudio.com/docs/remote/troubleshooting#_improving-security-on-multi-user-servers.
  > 
  > Your `remote.SSH.useLocalServer: false` setting also gives each window its own connection, so additional windows require authentication. If socket mode is not required, disable `remote.SSH.remoteServerListenOnSocket` and enable `remote.SSH.useLocalServer` to use shared connections across windows. These settings explain the prompts shown here, so this is expected behavior for the current configuration.
