# Issue #11395 — ssh needs to input password twice

[https://github.com/microsoft/vscode-remote-release/issues/11395](https://github.com/microsoft/vscode-remote-release/issues/11395)

## Summary

The two prompts are the documented consequence of Unix-socket mode disabling SSH connection multiplexing. The log shows separate installation and socket-forwarding SSH connections, each requiring password authentication.

## Change summary

Avoid requesting the SSH password separately for server startup and socket forwarding, including when opening another window.

## Best solution

Use key-based authentication while retaining `remote.SSH.remoteServerListenOnSocket` on a multi-user host. Where socket isolation is unnecessary, disabling that setting restores connection multiplexing and avoids the second password-authenticated connection.
