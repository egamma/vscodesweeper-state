# Issue #9034 — Requires internet connection to connect to local container

[https://github.com/microsoft/vscode-remote-release/issues/9034](https://github.com/microsoft/vscode-remote-release/issues/9034)

## Summary

The current server-download settings provide an offline prefetch workaround, but they do not fully address the requested automatic cache fallback for previously used local containers. This remains a well-supported Backlog feature request.

## Change summary

Cache matching VS Code Server artifacts locally so an existing local container can be opened without internet access or manual pre-seeding.

## Best solution

Dev Containers should retain downloaded server artifacts outside temporary storage and reuse the matching client-version artifact before attempting a network download. The existing configurable download folder should remain available for explicitly managed offline installations.
