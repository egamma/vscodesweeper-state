# Issue #3568 — Import common baseline definitions (Containers)

[https://github.com/microsoft/vscode-remote-release/issues/3568](https://github.com/microsoft/vscode-remote-release/issues/3568)

## Summary

Keep open: Git-hosted baseline imports with project overrides remain distinct from documented image-metadata inheritance and template application. The related overlay issue does not establish a canonical for this cross-repository distribution request.

## Change summary

Allow devcontainer.json to inherit shared definitions from Git repositories and override their properties without duplicating baseline configuration.

## Best solution

The containers component should retain the product-side request while coordinating import and merge semantics with the Dev Container specification proposals. Define how shared baselines are fetched, cached for offline use, and overridden independently of the project's chosen image.
