# Issue #3568 — Import common baseline definitions (Containers)

[https://github.com/microsoft/vscode-remote-release/issues/3568](https://github.com/microsoft/vscode-remote-release/issues/3568)

## Summary

This is now owned by the open Dev Container spec proposal for versioned, reusable configurations across repositories. Existing Features and image metadata cover portions of the request but not general configuration inheritance.

## Change summary

Allow projects to import centrally maintained dev-container definitions and override selected properties locally.

## Best solution

Consolidate the requirements on https://github.com/devcontainers/spec/issues/716, where configuration packaging, versioning, inheritance, and overrides can be defined consistently for all dev-container implementations.

## Vision fit

- **Fit:** rejected
- **Reason:** The capability fits the Dev Container ecosystem, but configuration inheritance changes the shared specification rather than the VS Code Dev Containers extension alone.
- **Evidence:** The vision guardrail says that requests extending devcontainer.json belong in the open devcontainers specification tracker and that the extension should follow the shared specification rather than fork it.
