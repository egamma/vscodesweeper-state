# Issue #9993 — Host networking causes an explosion of Docker processes

[https://github.com/microsoft/vscode-remote-release/issues/9993](https://github.com/microsoft/vscode-remote-release/issues/9993)

## Summary

The minimal reproduction and maintainer analysis identify recursive port forwarding with host networking, but the report has no current-version retest or independent confirmation. Updated information is needed before deciding whether the defect remains.

## Change summary

Using Dev Containers with host networking and a forwarded port recursively spawns Docker processes until memory is exhausted.

## Best solution

The Dev Containers extension should detect host networking and prevent VS Code from forwarding ports back into the same host endpoint, using an appropriate tunnel or port-attributes provider. First confirm the behavior on current Dev Containers and VS Code releases.
