# Issue #7975 — Cannot create dev containers

[https://github.com/microsoft/vscode-remote-release/issues/7975](https://github.com/microsoft/vscode-remote-release/issues/7975)

## Summary

The evidence identifies this as an upstream Docker 23.0.0 BuildKit failure rather than a Dev Containers defect. Upstream issues must remain open under the review policy, despite Docker 23.0.1 subsequently resolving the underlying failure.

## Change summary

Creating any Dev Container fails on Linux after upgrading the Docker engine to version 23.0.0.

## Best solution

Users should update Docker to 23.0.1 or newer, where the upstream fix shipped. The Dev Containers CLI issue at https://github.com/devcontainers/cli/issues/398 should remain the technical tracking location if any affected configuration still fails.
