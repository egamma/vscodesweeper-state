# Issue #11457 — Remote-SSH Does Not Detect ConnectTimeout from SSH Config

[https://github.com/microsoft/vscode-remote-release/issues/11457](https://github.com/microsoft/vscode-remote-release/issues/11457)

## Summary

Keep open: the supplied configuration, steps, and contrasting logs suffice to retest SSH-config timeout handling. This report postdates the previously confirmed fix and shows the extension still overriding ConnectTimeout; that earlier resolution does not establish that this report is fixed.

## Change summary

Remote - SSH overrides a host's ConnectTimeout 60 with ConnectTimeout=15, preventing a DevPod connection unless the timeout is also configured in VS Code.

## Best solution

The SSH component should investigate why the previously shipped SSH-config timeout support does not apply to this host and restore effective per-host timeout handling. Retest the supplied DevPod configuration with the extension setting unset; setting remote.SSH.connectTimeout to 60 is a workaround, not fulfillment of the configuration-inheritance expectation.
