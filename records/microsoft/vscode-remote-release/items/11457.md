# Issue #11457 — Remote-SSH Does Not Detect ConnectTimeout from SSH Config

[https://github.com/microsoft/vscode-remote-release/issues/11457](https://github.com/microsoft/vscode-remote-release/issues/11457)

## Summary

The logs suggest a regression: Remote - SSH 0.122.0 overrides the host's effective `ConnectTimeout 60` with 15 seconds, although this precedence behavior was previously fixed and verified. A current-release retest is needed before routing it as an active regression.

## Change summary

Remote - SSH should honor the per-host `ConnectTimeout` from SSH configuration instead of replacing it with its default timeout.

## Best solution

The SSH component should restore the configuration precedence verified in the earlier fix, retaining `remote.SSH.connectTimeout` as a fallback while honoring effective per-host SSH configuration. First confirm the behavior on the current release and capture `ssh -G` output alongside the Remote - SSH log.
