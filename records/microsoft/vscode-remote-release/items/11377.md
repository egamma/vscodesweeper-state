# Issue #11377 — Memory leaks after lost connection

[https://github.com/microsoft/vscode-remote-release/issues/11377](https://github.com/microsoft/vscode-remote-release/issues/11377)

## Summary

Keep open with the existing SSH routing: a November confirmation on VS Code 1.143.1 and Remote - SSH 0.128.0 reports substantial local memory growth during offline reconnection. The thread provides reproducible steps and measured error rates; no verified canonical or confirmed fix was found.

## Change summary

Remote - SSH reconnection after network loss causes excessive local memory consumption and repeated offline-error output.

## Best solution

The Remote - SSH owner should investigate retained extension state and high-volume offline-error handling, then ensure prolonged reconnection keeps local memory bounded. Use local extension-host profiles to distinguish the retaining mechanism from the separate remote-process cleanup report.
