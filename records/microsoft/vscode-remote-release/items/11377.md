# Issue #11377 — Memory leaks after lost connection

[https://github.com/microsoft/vscode-remote-release/issues/11377](https://github.com/microsoft/vscode-remote-release/issues/11377)

## Summary

The increasing Remote - SSH global-state warnings provide credible evidence of unbounded growth after disconnection, but the report lacks the requested Remote - SSH log and process diagnostics needed to connect that growth to the renderer memory exhaustion.

## Change summary

Remote - SSH appears to accumulate extension state and consume increasing client memory while reconnecting after an SSH connection is lost.

## Best solution

The SSH owner should determine what repeatedly appends roughly 50 KB to global extension state during reconnection and ensure it is bounded or moved to disk. A current reproduction with the Remote - SSH log and a sample of the affected macOS process is needed to localize the leak.
