# Issue #9540 — Devcontainer Additional Config Path doesnt work with remote

[https://github.com/microsoft/vscode-remote-release/issues/9540](https://github.com/microsoft/vscode-remote-release/issues/9540)

## Summary

Keep open for Dev Containers: discovery and opening of additional configurations appear to use different filesystem contexts over SSH. The reports predate current releases, but the described differing-path setup suffices to retest; there is no confirmed fix or verified canonical owning the SSH case.

## Change summary

Additional dev-container configurations discovered locally cannot be used over SSH when their absolute paths differ on the remote host.

## Best solution

Dev Containers should resolve configuration discovery and consumption consistently across the local and SSH filesystems without requiring identical absolute paths. Investigate alongside the related WSL report, preserving this older SSH report until shared ownership of the full fix is established.
