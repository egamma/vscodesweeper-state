# Issue #9540 — Devcontainer Additional Config Path doesnt work with remote

[https://github.com/microsoft/vscode-remote-release/issues/9540](https://github.com/microsoft/vscode-remote-release/issues/9540)

## Summary

The path-resolution failure was independently confirmed, but the latest evidence is from 2024 and lacks logs or current version details. A current retest is needed before the Dev Containers owner can investigate further.

## Change summary

Additional Dev Container configuration paths resolve against the local filesystem and are then opened at the same absolute path on a different Remote-SSH filesystem.

## Best solution

Dev Containers should resolve additional configuration paths within the correct local or Remote-SSH file authority rather than assuming identical absolute paths. A current Dev Containers log and concrete local/remote path example are needed to confirm the remaining behavior.
