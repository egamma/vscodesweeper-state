# Issue #2321 — Explorer should list multiple remote docker hosts

[https://github.com/microsoft/vscode-remote-release/issues/2321](https://github.com/microsoft/vscode-remote-release/issues/2321)

## Summary

A real capability gap remains: current Docker-context support switches the active host but does not present multiple hosts simultaneously in Remote Explorer. The issue is already correctly classified and remains the canonical request.

## Change summary

Add multiple Docker hosts as parent entries in Remote Explorer so users can browse and attach to containers across hosts without changing a global setting.

## Best solution

The Dev Containers Remote Explorer should enumerate configured Docker contexts or hosts and retain the selected host when attaching or reopening a container. Context switching remains a workaround, but it does not satisfy simultaneous multi-host navigation.
