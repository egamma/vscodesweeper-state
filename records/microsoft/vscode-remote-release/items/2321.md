# Issue #2321 — Explorer should list multiple remote docker hosts

[https://github.com/microsoft/vscode-remote-release/issues/2321](https://github.com/microsoft/vscode-remote-release/issues/2321)

## Summary

Keep this Dev Containers request open: documented Docker-context switching does not deliver the requested multi-host Remote Explorer hierarchy. A maintainer explicitly consolidated a related report here, and no verified replacement canonical was found.

## Change summary

Show containers grouped under multiple configured Docker hosts or contexts in Remote Explorer, allowing attachment without changing the active global host.

## Best solution

The Dev Containers component should let Remote Explorer browse and attach to containers across configured Docker contexts, preserving each container's host identity. Reuse Docker contexts rather than introducing a separate host configuration mechanism.
