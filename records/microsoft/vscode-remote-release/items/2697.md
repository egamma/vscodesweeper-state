# Issue #2697 — Support ALL doc'd variables.

[https://github.com/microsoft/vscode-remote-release/issues/2697](https://github.com/microsoft/vscode-remote-release/issues/2697)

## Summary

A real capability gap remains, but supporting every VS Code variable indiscriminately is incompatible with the dev-container lifecycle. Keep this open for a narrower decision on the unresolved config and executable-path substitutions.

## Change summary

Expand variable interpolation across string-valued devcontainer.json properties, including configuration and executable-path variables.

## Best solution

The Dev Containers owner should define the remaining substitutions with the dev container specification, separating host-time and container-time values rather than enabling every editor variable globally. Existing workspace and environment substitutions should remain the supported foundation.
