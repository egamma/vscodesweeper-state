# Issue #11282 — Attached to wrong container

[https://github.com/microsoft/vscode-remote-release/issues/11282](https://github.com/microsoft/vscode-remote-release/issues/11282)

## Summary

Verified duplicate: the incorrect attachment occurs because multiple containers share the same home and `.vscode-server` state, a scenario already tracked by the open shared-home support request.

## Change summary

Support attaching simultaneously to multiple containers that share a home directory without connecting a window to the wrong container.

## Best solution

Consolidate on https://github.com/microsoft/vscode-remote-release/issues/10674; Dev Containers would need to isolate VS Code Server state per container before shared-home configurations can work reliably.
