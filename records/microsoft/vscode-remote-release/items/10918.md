# Issue #10918 — Remote-SSH fails to determine the listeningOn address - panic in src/bin/code/main.rs (FIPS 140-2 security mode)

[https://github.com/microsoft/vscode-remote-release/issues/10918](https://github.com/microsoft/vscode-remote-release/issues/10918)

## Summary

Keep open: the report supplies a repeatable FIPS-enabled trigger and logs showing the remote CLI crashing before publishing its listening address. The reported versions are old, but the supplied steps suffice to retest; no confirmed fix or open canonical was found.

## Change summary

Remote-SSH cannot connect to a FIPS-configured ARM64 Linux host because its remote CLI panics during TLS client initialization.

## Best solution

The SSH and CLI owners should establish whether the remote CLI can initialize TLS under the reported FIPS configuration and replace the startup panic with actionable error handling. If the defect belongs entirely to the public VS Code CLI, a maintainer can transfer this to microsoft/vscode; disabling FIPS is not an acceptable resolution for compliance-constrained hosts.
