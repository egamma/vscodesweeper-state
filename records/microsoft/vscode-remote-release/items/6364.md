# Issue #6364 — Auto-install recommended extensions

[https://github.com/microsoft/vscode-remote-release/issues/6364](https://github.com/microsoft/vscode-remote-release/issues/6364)

## Summary

Keep open in the containers backlog: current documentation still requires explicit extension IDs in `customizations.vscode.extensions`, leaving the requested reuse and recommendation-versus-required distinction unresolved.

## Change summary

Allow dev containers to auto-install selected workspace recommendations without duplicating extension IDs from `.vscode/extensions.json`.

## Best solution

The Dev Containers integration should provide an opt-in way to merge workspace recommendations into container-installed extensions, with exclusions so personal recommendations are not forced on every user. Codespaces should share the behavior where it consumes the same VS Code customization.
