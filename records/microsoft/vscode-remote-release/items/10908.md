# Issue #10908 — hostRequirements fails with podman (can't evaluate field Runtimes)

[https://github.com/microsoft/vscode-remote-release/issues/10908](https://github.com/microsoft/vscode-remote-release/issues/10908)

## Summary

This remains a concrete Podman compatibility bug: optional GPU host requirements invoke a Docker-specific template field that Podman does not expose, preventing the dev container from opening. A second user supplied a workaround for the same failure, and the current public Dev Containers CLI implementation retains the incompatible probe.

## Change summary

Make optional GPU host-requirement detection work with Podman instead of failing while evaluating Docker's Runtimes field.

## Best solution

Update the GPU capability probe in devcontainers/cli to handle Podman with a runtime-appropriate check and treat unavailable optional GPU support as non-fatal, then ship that implementation through Dev Containers.
