# Issue #10908 — hostRequirements fails with podman (can't evaluate field Runtimes)

[https://github.com/microsoft/vscode-remote-release/issues/10908](https://github.com/microsoft/vscode-remote-release/issues/10908)

## Summary

Keep open with the existing containers/podman routing: the configuration and failing command suffice to retest on current releases. The April 2026 wrapper workaround is not a shipped fix, and no verified canonical owns this Podman template failure.

## Change summary

Dev Containers fails when optional GPU host requirements invoke a Docker-specific Runtimes.nvidia query against Podman.

## Best solution

The Dev Containers owner should make optional GPU detection compatible with Podman's information format, allowing startup without a GPU when appropriate. Retest the supplied configuration on current versions without the wrapper and preserve this product-side issue until resolution is demonstrated.
