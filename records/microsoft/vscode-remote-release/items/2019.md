# Issue #2019 — Unable to connect to container with ssh unless SSH key is in a running SSH agent

[https://github.com/microsoft/vscode-remote-release/issues/2019](https://github.com/microsoft/vscode-remote-release/issues/2019)

## Summary

Keep open as upstream tracking, as the maintainers explicitly intended. The documentation update clarified the SSH-agent requirement; it did not remove the underlying authentication limitation.

## Change summary

Connecting to a remote Docker host over ssh:// requires a running SSH agent with the key loaded, although command-line Docker connects without it.

## Best solution

Retain containers/upstream tracking until the Dev Containers connection path supports the reporter's agent-free authentication workflow. Coordinate with https://github.com/apocas/docker-modem/issues/113, while preserving the documented agent workaround.
