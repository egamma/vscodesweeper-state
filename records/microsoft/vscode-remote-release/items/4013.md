# Issue #4013 — Allow `Open Named Configuration File...` prior to attaching

[https://github.com/microsoft/vscode-remote-release/issues/4013](https://github.com/microsoft/vscode-remote-release/issues/4013)

## Summary

Keep open: documented commands allow editing existing attached-container configurations offline, but do not establish support for creating a named configuration before the first attachment. This team-authored Backlog request has neither a verified fix nor a canonical owning that remaining capability.

## Change summary

Allow creating or opening a container-name-based attach configuration from the Command Palette before attaching.

## Best solution

Dev Containers should provide a pre-attachment command that can create a named configuration even when none exists, so the first connection uses the intended settings. Preserve offline editing of existing configurations.

- **Fit:** aligned
- **Reason:** Preparing configuration before connecting improves dev-container workflow depth and avoids unnecessary initial attachments.
