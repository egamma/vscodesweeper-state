# Issue #11433 — Problems starting a VS Code server in OpenSUSE Leap 16.0

[https://github.com/microsoft/vscode-remote-release/issues/11433](https://github.com/microsoft/vscode-remote-release/issues/11433)

## Summary

Verified duplicate of the older open SUSE Exec Server failure report: SSH authenticates, but the remote CLI produces no listening port. Consolidate the OpenSSL trigger and newer-release confirmations there.

## Change summary

Remote-SSH cannot start its CLI control server on recent SUSE systems whose OpenSSL configuration enables JITTER.

## Best solution

Track the CLI startup compatibility fix in https://github.com/microsoft/vscode-remote-release/issues/10939, preserving this report's JITTER/TLS trigger and nested Dev Containers requirement. Restore Exec Server startup without requiring changes to the host's crypto policy.
