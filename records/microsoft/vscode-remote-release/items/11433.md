# Issue #11433 — Problems starting a VS Code server in OpenSUSE Leap 16.0

[https://github.com/microsoft/vscode-remote-release/issues/11433](https://github.com/microsoft/vscode-remote-release/issues/11433)

## Summary

Consolidate with the older, open exec-server report: both describe successful SSH authentication followed by an empty CLI log, missing listening port, and failed connection on SUSE hosts. The crypto-configuration diagnosis here should accompany the consolidation; the workarounds do not establish a shipped fix.

## Change summary

Remote-SSH cannot start its downloaded CLI on newer SUSE systems when the host OpenSSL configuration triggers an initialization deadlock.

## Best solution

Resolve the downloaded CLI's compatibility with SUSE OpenSSL configuration under https://github.com/microsoft/vscode-remote-release/issues/10939, preserving exec-server functionality and Dev Containers over SSH without requiring host crypto-policy changes.
