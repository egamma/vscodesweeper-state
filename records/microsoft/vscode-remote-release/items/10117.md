# Issue #10117 — when connecting to remote host trim whitespace for the ssh url

[https://github.com/microsoft/vscode-remote-release/issues/10117](https://github.com/microsoft/vscode-remote-release/issues/10117)

## Summary

Keep open: adding leading or trailing spaces provides a concrete trigger sufficient to retest. Subsequent discussion of SSH hostname restrictions does not establish that Remote - SSH now trims this input, and no same-symptom canonical was found.

## Change summary

Remote - SSH connection input should ignore accidental whitespace surrounding an otherwise valid host.

## Best solution

The SSH component should compare connection attempts with a valid host and the same host surrounded by spaces, then normalize surrounding whitespace in the host-entry field if the failure persists without changing meaningful SSH command arguments.
