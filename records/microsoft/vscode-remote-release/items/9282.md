# Issue #9282 — devcontainer support for docker compose watch (new in v2.22 of docker compose)

[https://github.com/microsoft/vscode-remote-release/issues/9282](https://github.com/microsoft/vscode-remote-release/issues/9282)

## Summary

Keep open: documented Compose support does not cover extension-managed Watch activation. The discussion establishes a multi-service use case beyond the original workspace-sync request, and no verified canonical or shipped implementation was found.

## Change summary

Allow Dev Containers to enable Docker Compose Watch for file synchronization and selective updates of Compose services.

## Best solution

The Dev Containers component should define opt-in Watch lifecycle support, including companion-service updates, without unnecessarily rebuilding the attached development container. Resolve which filesystem Watch observes when edits originate inside the dev container; host-to-container sync alone does not provide reverse synchronization.
