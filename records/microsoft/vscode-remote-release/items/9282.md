# Issue #9282 — devcontainer support for docker compose watch (new in v2.22 of docker compose)

[https://github.com/microsoft/vscode-remote-release/issues/9282](https://github.com/microsoft/vscode-remote-release/issues/9282)

## Summary

A current capability gap remains: Dev Containers cannot start its Compose project in watch mode, and no other open issue owns this request. It is appropriately classified in the Containers backlog and has sustained demand.

## Change summary

Allow Docker Compose-based dev containers to start with Compose Watch so configured services can synchronize, restart, or rebuild when host files change.

## Best solution

The Dev Containers component should integrate `docker compose up --watch` while preserving attachment to the primary development service and allowing other configured services to sync, restart, or rebuild. If this requires a portable `devcontainer.json` property rather than extension-specific behavior, the corresponding schema proposal should be coordinated with https://github.com/devcontainers/spec.
