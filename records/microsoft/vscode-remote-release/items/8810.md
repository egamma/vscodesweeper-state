# Issue #8810 — ssh-agent forward through Remote Tunnels

[https://github.com/microsoft/vscode-remote-release/issues/8810](https://github.com/microsoft/vscode-remote-release/issues/8810)

## Summary

Keep this accepted Remote Tunnels feature request open: it already owns the agent-forwarding work, and the documented container capability and separate SSH-session workaround do not cover authentication throughout the tunnel-connected workspace.

## Change summary

Forward the local SSH agent into a Remote Tunnels workspace without storing private keys on the remote host.

## Best solution

The tunnels component should provide session-scoped local SSH-agent forwarding for remote terminals and extension processes, with explicit consent and appropriate access controls. Retain this issue as the canonical product request.
