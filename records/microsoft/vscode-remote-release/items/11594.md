# Issue #11594 — VS code terminal loses env vars from docker compose that have dots

[https://github.com/microsoft/vscode-remote-release/issues/11594](https://github.com/microsoft/vscode-remote-release/issues/11594)

## Summary

A team member provided a current, minimal reproduction showing that Dev Containers drops dotted environment variables only from VS Code terminals. The issue is correctly routed and should remain open for investigation.

## Change summary

Preserve Docker Compose environment variables containing dots when launching an integrated terminal in a dev container.

## Best solution

The Dev Containers component should preserve the container process environment when constructing integrated-terminal environments, including names that are valid container environment entries but invalid shell assignment identifiers.
