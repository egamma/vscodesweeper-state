# Issue #11261 — vscode leaks `node` processes over time

[https://github.com/microsoft/vscode-remote-release/issues/11261](https://github.com/microsoft/vscode-remote-release/issues/11261)

## Summary

Keep open and route to Dev Containers: the original process snapshots and a fresh independent confirmation show obsolete container helpers surviving reloads and accumulating memory. No verified canonical owns the full reported behavior.

## Change summary

Reloading after a connection interruption leaves previous Dev Containers helper and remote processes running inside the container.

## Best solution

The Dev Containers owner should investigate helper retirement after reconnect and IPC socket replacement, ensuring superseded processes exit without terminating active sessions. Use the VPN/reload steps and the recent local-container confirmation to distinguish helper leaks from intentional server reconnection retention.
