# Issue #11261 — vscode leaks `node` processes over time

[https://github.com/microsoft/vscode-remote-release/issues/11261](https://github.com/microsoft/vscode-remote-release/issues/11261)

## Summary

Keep open for Dev Containers reconnection cleanup: the VPN-disconnect/reload steps and successive process snapshots suffice to retest. The report targets VS Code 1.105.1 rather than current releases, but neither a confirmed resolution nor a qualifying canonical establishes that this is obsolete.

## Change summary

Repeated VPN interruptions and window reloads accumulate remote Node helpers and extension-host processes inside a dev container.

## Best solution

The Dev Containers owner should reproduce the supplied interruption sequence and ensure superseded connection helpers and extension hosts are reclaimed without disrupting active sessions. Retain SSH routing for the remote transport, but distinguish this container-side accumulation from local SSH memory leaks and port-forwarding relay storms.
