# Issue #11261 — vscode leaks `node` processes over time

[https://github.com/microsoft/vscode-remote-release/issues/11261](https://github.com/microsoft/vscode-remote-release/issues/11261)

## Summary

The report is a reproducible Dev Containers reconnection cleanup bug, not primarily an SSH issue. Route it to Containers with the related current reports showing the same accumulation of stale Node relay and server processes.

## Change summary

Dev Containers leaves additional Node relay and server processes running after a VPN interruption and window reload, causing process and resource usage to grow with each reconnection.

## Best solution

The Dev Containers connection owner should ensure superseded proxy and server processes terminate when transport connections fail, reconnect, or the window reloads. The diagnosis in https://github.com/microsoft/vscode-remote-release/issues/11557 and current-release evidence in https://github.com/microsoft/vscode-remote-release/issues/11703 should be consolidated with this older report.
