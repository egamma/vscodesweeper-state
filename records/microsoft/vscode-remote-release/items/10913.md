# Issue #10913 — Connect in Window forgets current VSCode profile (when not default) unless a recent directory/workspace is chosen

[https://github.com/microsoft/vscode-remote-release/issues/10913](https://github.com/microsoft/vscode-remote-release/issues/10913)

## Summary

Keep open: the workaround changes the global new-window profile preference, but does not resolve why connecting in the current window overrides its active profile. The July 2026 follow-up still describes a workaround rather than a fix; the supplied steps and identified setting suffice to retest.

## Change summary

Connecting to an SSH host without selecting a remote folder replaces the active profile with the configured new-window profile, including when reusing the current window.

## Best solution

The Remote - SSH owner should verify that current-window connection preserves the active profile while new-window connection respects the configured new-window preference. Coordinate with VS Code's profile/window owner if the shared window-opening behavior causes the reset.
