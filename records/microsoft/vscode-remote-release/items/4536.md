# Issue #4536 — Constantly losing WSL connection 

[https://github.com/microsoft/vscode-remote-release/issues/4536](https://github.com/microsoft/vscode-remote-release/issues/4536)

## Summary

Keep open: recent users confirm that WSL reconnection can remain stuck even after Reload Window. The October confirmation concerns a locally modified extension, not a shipped fix, and no verified canonical owns the full remaining work.

## Change summary

WSL connection drops can leave VS Code unable to reconnect without terminating all VS Code processes.

## Best solution

The WSL extension owner should reproduce recovery after a distro/server restart and investigate the reported stale resolver and daemon caches, then ship reliable reconnection without a full VS Code restart. Separate platform-wide WSL failures from cases where WSL remains usable but the extension cannot recover.
