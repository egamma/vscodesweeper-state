## Summary

The extension-host initialization failure has a concrete reload reproduction and an independent confirmation using the same server-deletion workaround. No verified canonical or resolution supports closing it.

## Change summary

Remote - SSH enters a reconnect loop after window reload when reusing an installed VS Code Server, while deleting its bin directory restores operation.

## Best solution

Remote - SSH and the VS Code Server lifecycle owner should determine why reusing the running installation after reload prevents the remote extension host from becoming ready, while a fresh installation succeeds.
