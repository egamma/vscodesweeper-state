# Issue #10488 — Remote SSH Extension - Disable File(s) Download from server option

[https://github.com/microsoft/vscode-remote-release/issues/10488](https://github.com/microsoft/vscode-remote-release/issues/10488)

## Summary

Keep open: this accepted Backlog request addresses data-exfiltration controls and no existing Remote - SSH policy covers it. The issue exceeded the community threshold, is correctly routed, and requires a deliberate security and enforcement design.

## Change summary

Add an administrator-enforced Remote - SSH policy that prevents users from downloading remote files through the desktop client.

## Best solution

The Remote - SSH component should define the threat model and implement a server- or organization-controlled policy that users cannot override, rather than merely hiding the Download action. The design should clearly state which VS Code transfer paths it governs and that unrestricted SSH access can provide other exfiltration paths.
