# Issue #1399 — Complete offline installation of VSCode Remote

[https://github.com/microsoft/vscode-remote-release/issues/1399](https://github.com/microsoft/vscode-remote-release/issues/1399)

## Summary

A supported fully offline installation workflow remains missing when neither the workstation nor remote host can access the updater. This well-supported cross-component request should remain open and be routed to the shared server installation lifecycle.

## Change summary

Provide a documented way to stage and install matching VS Code Server packages for completely air-gapped remote development.

## Best solution

Provide a stable download or packaging surface and a supported local cache or package path that Remote SSH and Dev Containers can consume without internet access or undocumented marker files. Keep this older, broader issue as the canonical request for complete offline installation.
