# Issue #10124 — hostRequirements: gpu: missing driver option

[https://github.com/microsoft/vscode-remote-release/issues/10124](https://github.com/microsoft/vscode-remote-release/issues/10124)

## Summary

This remains an actionable Dev Containers bug: multiple users observed that the generated Docker Compose override requests GPU capability without the NVIDIA driver, and the current public CLI implementation still generates that shape.

## Change summary

Make optional GPU host requirements work with Docker Compose by including the appropriate GPU driver when NVIDIA support is detected.

## Best solution

Update the Dev Containers implementation shared with devcontainers/cli so its generated Compose device reservation selects the detected NVIDIA driver while still omitting GPU reservations on hosts without usable GPUs.
