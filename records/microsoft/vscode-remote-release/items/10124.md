[https://github.com/microsoft/vscode-remote-release/issues/10124](https://github.com/microsoft/vscode-remote-release/issues/10124)

## Summary

Keep open for the Dev Containers owner: the thread identifies a concrete missing-driver problem in generated Docker Compose GPU reservations. GPU detection overrides shipped after this report, but do not establish resolution of this Compose-specific defect; the supplied configuration and workaround suffice for a targeted retest.

## Change summary

Optional GPU support generates a Docker Compose device reservation without driver: nvidia, leaving GPU access broken despite an available NVIDIA runtime.

## Best solution

The containers owner should retest optional GPU reservation generation with an NVIDIA runtime and ensure the generated Compose configuration enables GPU access while remaining usable on hosts without GPUs. Diagnose driver selection separately from GPU availability detection.
