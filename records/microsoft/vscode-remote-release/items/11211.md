# Issue #11211 — Remote-ssh on windows can't connect to a default zsh shell linux server

[https://github.com/microsoft/vscode-remote-release/issues/11211](https://github.com/microsoft/vscode-remote-release/issues/11211)

## Summary

Verified duplicate: the open canonical issue tracks Remote - SSH failures with non-bash default shells, including zsh. This report adds a useful Windows exec-server log identifying incorrect zsh expansion of LISTEN_ARGS.

## Change summary

Remote - SSH from Windows cannot connect when the Linux account uses zsh because the generated server command passes combined listen arguments incorrectly.

## Best solution

Consolidate non-bash remote-shell compatibility work in https://github.com/microsoft/vscode-remote-release/issues/2509, carrying over this report's LISTEN_ARGS and host-parsing diagnosis.
