# Issue #8554 — Add Folder to Workspace inside container displays error

[https://github.com/microsoft/vscode-remote-release/issues/8554](https://github.com/microsoft/vscode-remote-release/issues/8554)

## Summary

The thread identifies a VS Code workbench reload race: a reconnect dialog opened by the old remote session survives the automatic workspace reload. Keep this open for transfer to microsoft/vscode rather than treating the broader extension-host reload request as an exact duplicate.

## Change summary

Adding a folder to a workspace inside a Dev Container triggers a misleading reconnect error dialog even though cancelling it leaves the workspace working.

## Best solution

A maintainer can transfer this to microsoft/vscode, where the workspace reload and reconnect-dialog lifecycle are owned. The fix should either avoid the remote window reload or ensure dialogs from the old session are dismissed during it.
