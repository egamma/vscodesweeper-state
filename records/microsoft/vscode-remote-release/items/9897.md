# Issue #9897 — SSH still available in container even I disable `forwardWSLServices`

[https://github.com/microsoft/vscode-remote-release/issues/9897](https://github.com/microsoft/vscode-remote-release/issues/9897)

## Summary

Keep open because this is security-sensitive container-isolation work. The older open issue https://github.com/microsoft/vscode-remote-release/issues/9466 owns the credential-forwarding portion, while this report additionally requests controls for display and service forwarding.

## Change summary

Add user-controlled options to prevent Dev Containers from forwarding SSH/GPG agents, displays, and other host services into containers.

## Best solution

The Dev Containers component should provide trusted user-level controls that containers and workspace configuration cannot override, ideally including a global credential-forwarding switch coordinated with https://github.com/microsoft/vscode-remote-release/issues/9466 and granular controls for other host services.
