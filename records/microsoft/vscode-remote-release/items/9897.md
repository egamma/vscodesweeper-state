## Change summary

Allow disabling SSH/GPG agent and display forwarding into dev containers without disabling those services for other local tools.

## Best solution

Dev Containers should provide host-controlled forwarding opt-outs and clearly document their limits without promising container security. Coordinate credential controls with https://github.com/microsoft/vscode-remote-release/issues/9466 while retaining this report's display-forwarding and setting-clarity requirements.
