# Issue #5699 — Cannot connect to SSH daemon not named "sshd"

[https://github.com/microsoft/vscode-remote-release/issues/5699](https://github.com/microsoft/vscode-remote-release/issues/5699)

## Summary

Keep open as the accepted Remote - SSH request for Windows servers whose session ancestry lacks an sshd-named process. No documented capability or confirmed release resolves the Bitvise case, and the related reconnect-leak issue has a different observable symptom.

## Change summary

Allow Remote - SSH connections to Windows SSH servers without requiring an ancestor process named sshd.

## Best solution

Remote - SSH should provide the maintainer-suggested process-name configuration or a more general session-lifetime mechanism, allowing Bitvise connections while preserving cleanup when the SSH session ends.
