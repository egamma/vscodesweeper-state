# Issue #5699 — Cannot connect to SSH daemon not named "sshd"

[https://github.com/microsoft/vscode-remote-release/issues/5699](https://github.com/microsoft/vscode-remote-release/issues/5699)

## Summary

Keep open in the SSH backlog: Remote - SSH still assumes a Windows session has an `sshd.exe` ancestor, excluding Bitvise and other valid process topologies. No existing setting or broader canonical issue covers the requested configurability.

## Change summary

Allow Remote - SSH to manage Windows sessions whose SSH daemon or relevant parent process is not named `sshd`.

## Best solution

Remote - SSH should replace the hard-coded `sshd.exe` lifecycle check with a daemon-independent mechanism, or expose the configurable process-name setting proposed by the maintainer. Issue 5699 should remain the canonical request for nonstandard Windows SSH daemon ancestry.
