# Issue #9939 — Dev container dies when launched from Mac Shortcuts app

[https://github.com/microsoft/vscode-remote-release/issues/9939](https://github.com/microsoft/vscode-remote-release/issues/9939)

## Summary

Keep open: the minimal Compose configuration, exact Shortcuts trigger, and termination logs suffice to retest. The report concerns 2024 versions; no subsequent fix or current-release confirmation is established.

## Change summary

A dev container opened through macOS Shortcuts terminates roughly sixty seconds after another shortcut runs, even when that shortcut does nothing.

## Best solution

The Dev Containers owner should retest the supplied two-shortcut reproduction and investigate shutdown-monitor lifetime and socket placement under the Shortcuts helper's temporary directory. Opening another shortcut should not stop an active container; separately starting and attaching remains a workaround, not resolution.
