# Issue #4443 — Podman: .vscode-server directory creation in wrong place when remoteUser is defined

[https://github.com/microsoft/vscode-remote-release/issues/4443](https://github.com/microsoft/vscode-remote-release/issues/4443)

## Summary

Keep open as an upstream Podman compatibility issue: configuration workarounds helped some users but did not resolve attaching as a non-root remoteUser to existing containers. The thread contains no verified fix covering that remaining case.

## Change summary

Resolve the remote user's home directory correctly instead of installing VS Code Server under /root when using Podman.

## Best solution

The Dev Containers owner should revisit Podman's HOME and user-namespace interaction, including attaching to existing toolbox containers, and determine whether Podman or extension-side home detection needs adjustment. Preserve remoteUser-only workflows rather than requiring users to change the whole container's user.
