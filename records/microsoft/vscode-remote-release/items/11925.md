# Issue #11925 — Remote Explorer leaks docker events processes on window reload/quit

[https://github.com/microsoft/vscode-remote-release/issues/11925](https://github.com/microsoft/vscode-remote-release/issues/11925)

## Summary

Keep open for Dev Containers: the fresh-profile steps, watcher logs, and process-count observations suffice to retest the shutdown leak. There is no confirmed fix or verified open canonical; the reported pre-release comparison does not establish resolution.

## Change summary

Remote Explorer leaves two Docker event watcher processes running after each window reload or quit, even without a container connection.

## Best solution

Dev Containers should reliably terminate both Remote Explorer views' Docker event watchers when the extension host shuts down. The component owner should verify the reported disposal gap and ensure repeated reloads and quitting leave no watchers behind on a quiet Docker host.
