# Issue #10875 — Allow sysadmin to block launching/installation

[https://github.com/microsoft/vscode-remote-release/issues/10875](https://github.com/microsoft/vscode-remote-release/issues/10875)

## Summary

Keep this accepted request open and route it to SSH/server lifecycle owners. The reporter's PAM workaround does not deliver the requested built-in, host-specific opt-out, and no verified canonical owns that capability.

## Change summary

Allow administrators to place a host-level configuration file that Remote - SSH checks before installing or starting VS Code Server.

## Best solution

SSH/server lifecycle owners should evaluate a documented administrator-controlled opt-out checked before server installation or launch, preserving access on permitted compute nodes sharing the same NFS home. Define its enforcement limits rather than treating a cooperative configuration check as a security boundary.
