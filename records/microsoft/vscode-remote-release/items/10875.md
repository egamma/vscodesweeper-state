# Issue #10875 — Allow sysadmin to block launching/installation

[https://github.com/microsoft/vscode-remote-release/issues/10875](https://github.com/microsoft/vscode-remote-release/issues/10875)

## Summary

This accepted backlog request still represents a product gap: administrators lack a documented host-level policy that prevents Remote - SSH from installing or starting the VS Code Server. Route it to the SSH and server-lifecycle owners.

## Change summary

Allow administrators to place a system-wide policy file on selected hosts that blocks Remote - SSH server installation and startup.

## Best solution

Remote - SSH should check an administrator-owned host policy before downloading or starting the VS Code Server and return a clear policy-denied message. The reporter's PAM bind-mount is a useful workaround but does not replace a supported control.
