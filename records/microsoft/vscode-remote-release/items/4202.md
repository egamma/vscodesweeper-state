# Issue #4202 — Containers: Git credentials helper for external shells

[https://github.com/microsoft/vscode-remote-release/issues/4202](https://github.com/microsoft/vscode-remote-release/issues/4202)

## Summary

Keep open: automatically enabling forwarded Git credentials in external docker exec shells remains an accepted Dev Containers request. Documented environment settings and manual socket workarounds do not establish that this capability has shipped.

## Change summary

Make the Dev Containers Git credential helper usable automatically in externally started container shells while VS Code is running.

## Best solution

Dev Containers should provide a supported way for external shells to discover the active credential-helper connection without copying environment variables or guessing among stale sockets. Preserve the documented limitation that forwarding depends on a running VS Code session.
