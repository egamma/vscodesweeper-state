# Issue #4202 — Containers: Git credentials helper for external shells

[https://github.com/microsoft/vscode-remote-release/issues/4202](https://github.com/microsoft/vscode-remote-release/issues/4202)

## Summary

Keep open: Dev Containers still lacks a supported way for external `docker exec` shells to inherit the temporary credential-helper IPC environment automatically. The issue is correctly classified and routed, with multiple affected users and no canonical issue covering the full request.

## Change summary

Automatically expose the active Dev Containers credential-helper IPC socket to shells started externally with `docker exec`.

## Best solution

Dev Containers should provide a stable, supported mechanism for external container shells to discover the active credential and SSH-agent forwarding endpoints while VS Code is connected, without selecting temporary socket files manually.
