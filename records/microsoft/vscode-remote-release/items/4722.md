# Issue #4722 — Copy .gitconfig before running dotfiles installation

[https://github.com/microsoft/vscode-remote-release/issues/4722](https://github.com/microsoft/vscode-remote-release/issues/4722)

## Summary

Keep open: no verified existing capability makes the host's Git identity available before dotfiles installation. The maintainer acknowledged the team workflow but identified a compatibility risk for installers that preserve existing files.

## Change summary

Make the host's .gitconfig available before dotfiles installation so shared, noninteractive installers can inherit each user's Git name and email.

## Best solution

Dev Containers should provide an opt-in way to expose host Git identity before dotfiles installation while preserving existing installer behavior and honoring the Git-config copying opt-out. The maintainer should resolve that compatibility choice before changing the default ordering.
