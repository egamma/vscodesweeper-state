# Issue #8626 — dev-containers: include output from Annotations as an extension of Labels for running containers

[https://github.com/microsoft/vscode-remote-release/issues/8626](https://github.com/microsoft/vscode-remote-release/issues/8626)

## Summary

Keep open in the Backlog: Podman annotations still are not documented as an automatic metadata source when attaching to running containers, and the existing attached-container configuration only provides a manual workaround. The issue is already correctly routed to Containers and Podman.

## Change summary

Read Podman's Config.Annotations alongside Config.Labels so attached Distrobox containers can supply Dev Container metadata such as remoteUser.

## Best solution

The Dev Containers component should support a defined precedence-preserving merge of Podman container annotations and labels when attaching to an existing container, allowing Distrobox to expose the correct remote user automatically.
