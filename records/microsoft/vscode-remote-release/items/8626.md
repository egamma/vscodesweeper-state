# Issue #8626 — dev-containers: include output from Annotations as an extension of Labels for running containers

[https://github.com/microsoft/vscode-remote-release/issues/8626](https://github.com/microsoft/vscode-remote-release/issues/8626)

## Summary

Keep open: documented attached-container configuration can set remoteUser manually, but does not cover automatically consuming Podman annotations. No verified canonical or shipped implementation was found for this accepted Backlog request.

## Change summary

Read Podman Config.Annotations as an additional metadata source when attaching to an already running container.

## Best solution

The Dev Containers owner should define annotation metadata encoding and precedence against labels and attached-container configuration, then support container-provided metadata during attachment. Clarify the example's dotted devcontainer.metadata.remoteUser key, which differs from the documented JSON-valued devcontainer.metadata label.

- **Existing capability is a workaround:** https://code.visualstudio.com/docs/devcontainers/attach-container documents image-level and named attached-container configuration files with remoteUser, including editing configuration before attachment.
