# Issue #690 — Changing User on Remote Machine

[https://github.com/microsoft/vscode-remote-release/issues/690](https://github.com/microsoft/vscode-remote-release/issues/690)

## Summary

Keep open: RemoteCommand supports switching users in some configurations, but the thread documents unresolved password-prompt and connection-mode limitations. The September 2026 workaround addresses Windows settings, not the full request to operate the remote workspace as a different user.

## Change summary

Allow SSH authentication as a personal account while running the remote workspace as a project account that cannot log in directly over SSH.

## Best solution

Remote - SSH should provide a supported user-switching workflow that runs the server, file operations, extensions, and terminals as the selected project user, including required interactive authentication. Retain this issue for that capability and distinguish narrower RemoteCommand failures from the overall request.
