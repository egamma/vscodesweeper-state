# Issue #690 — Changing User on Remote Machine

[https://github.com/microsoft/vscode-remote-release/issues/690](https://github.com/microsoft/vscode-remote-release/issues/690)

## Summary

Keep this canonical feature request open. RemoteCommand supports switching users in some configurations, but password prompts, remotePlatform interaction, and changing identity after connection remain unresolved.

## Change summary

Allow Remote - SSH users to authenticate as one account and run the remote workspace and VS Code Server as another account.

## Best solution

Remote - SSH should provide a supported way to start or reconnect the VS Code Server under a selected post-authentication identity, including interactive sudo or su authentication, without conflicting with remotePlatform detection.
