# Issue #9059 — Devcontainer for vscode.dev?

[https://github.com/microsoft/vscode-remote-release/issues/9059](https://github.com/microsoft/vscode-remote-release/issues/9059)

## Summary

Keep open as the maintainer-designated tracker for Dev Containers support in vscode.dev. Documented desktop-over-tunnel support and unofficial workarounds do not deliver the requested browser-only workflow.

## Change summary

Enable vscode.dev users to create, reopen, and work in dev containers on a tunnel-connected host without installing desktop VS Code.

## Best solution

The Dev Containers component should support browser-compatible container orchestration over Remote Tunnels, preserving devcontainer.json configuration and port forwarding. Retain this issue as the product-side tracker rather than replacing it with the narrower direct-container-tunnel request.
