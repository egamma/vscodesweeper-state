[https://github.com/microsoft/vscode-remote-release/issues/11867](https://github.com/microsoft/vscode-remote-release/issues/11867)

## Summary

Route this startup-environment request to Remote - SSH. WSL documents the requested hook, but the reviewed evidence does not establish equivalent coverage in SSH's exec-server bootstrap or a canonical issue owning that specific capability.

## Change summary

Allow a user-controlled environment setup file to configure Linux Remote - SSH server startup without changing ordinary SSH sessions.

## Best solution

Remote - SSH should provide a supported, documented way to configure its exec-server startup environment independently of ordinary SSH sessions. Assess whether existing RemoteCommand support covers that bootstrap path; otherwise add an environment setup hook with clear inheritance and failure behavior.
