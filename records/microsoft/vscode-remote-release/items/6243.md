# Issue #6243 — Feature Request: allow opening remote workspaces through extensions

[https://github.com/microsoft/vscode-remote-release/issues/6243](https://github.com/microsoft/vscode-remote-release/issues/6243)

## Summary

Keep open for a supported, documented way for extensions to reopen remote workspaces. Existing Codespaces URI handling and Dev Containers commands cover individual cases, but do not establish that the broader API request is fulfilled.

## Change summary

Allow workspace-management extensions to programmatically open local and remote workspaces, including dev containers, Codespaces, and remote machines.

## Best solution

The Dev Containers owner should clarify and document a supported programmatic opening contract, coordinating with the other remote providers for workspace-switching parity. Preserve this broader request rather than folding it into a container-only fix or tunnel-only request.
