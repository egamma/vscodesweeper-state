# Issue #6856 — Can't disable BuildKit

[https://github.com/microsoft/vscode-remote-release/issues/6856](https://github.com/microsoft/vscode-remote-release/issues/6856)

## Summary

Keep open for an extension-level BuildKit opt-out: the maintainer confirmed that the CLI supports disabling BuildKit but the Dev Containers extension does not expose it. No verified shipped capability or eligible canonical resolves this broader request.

## Change summary

Allow disabling BuildKit for Dev Containers builds without disabling buildx globally.

## Best solution

The Dev Containers extension should expose the CLI's BuildKit selection, with clear limitations for features requiring BuildKit. Keep proxy configuration, WSLC compatibility, and Compose entitlement regressions distinct from this general opt-out request.
