# Issue #6856 — Can't disable BuildKit

[https://github.com/microsoft/vscode-remote-release/issues/6856](https://github.com/microsoft/vscode-remote-release/issues/6856)

## Summary

Keep open: the Dev Containers CLI can disable BuildKit, but the extension still does not expose that option. Recent WSLC evidence confirms the gap remains relevant beyond the original proxy scenario.

## Change summary

Expose a Dev Containers extension option that disables BuildKit for container builds without disabling buildx system-wide.

## Best solution

The Dev Containers extension should surface the CLI's `--buildkit=never` option and pass it to container build and rebuild operations, while clearly reporting operations that genuinely require BuildKit.
