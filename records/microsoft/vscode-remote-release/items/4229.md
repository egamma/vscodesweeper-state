# Issue #4229 — Docker: No obvious way to use an existing image

[https://github.com/microsoft/vscode-remote-release/issues/4229](https://github.com/microsoft/vscode-remote-release/issues/4229)

## Summary

Keep open for Dev Containers setup discoverability: using an existing image is supported, but maintainers explicitly accepted the remaining UX improvement. No verified canonical or shipped fix covers selecting an arbitrary image from the setup flow.

## Change summary

Make it obvious how to create a new development container from an existing local image tag or registry image without defining a Dockerfile.

## Best solution

The Dev Containers configuration wizard should offer a discoverable existing-image option accepting a local tag or registry reference and generating an image-based devcontainer.json. Preserve the distinction from attaching to an already running container.
