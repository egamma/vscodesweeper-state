# Issue #4229 — Docker: No obvious way to use an existing image

[https://github.com/microsoft/vscode-remote-release/issues/4229](https://github.com/microsoft/vscode-remote-release/issues/4229)

## Summary

Keep open as a Dev Containers discoverability request. Using an existing image is supported, but the configuration flow still does not clearly offer entry of an arbitrary image reference.

## Change summary

Add an obvious way to create a dev container configuration from an existing local or registry image.

## Best solution

The Dev Containers configuration command should offer an existing-image option that accepts an image reference and generates a devcontainer.json containing the `image` property.
