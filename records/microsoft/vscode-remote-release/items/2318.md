[https://github.com/microsoft/vscode-remote-release/issues/2318](https://github.com/microsoft/vscode-remote-release/issues/2318)

## Summary

Keep this accepted feature request open and add SSH routing. Reverse forwarding already works through SSH configuration, but that does not deliver the requested Forwarded Ports view integration; maintainers explicitly directed the earlier request here.

## Change summary

Display RemoteForward (ssh -R) mappings in Remote - SSH's Forwarded Ports view alongside LocalForward mappings.
