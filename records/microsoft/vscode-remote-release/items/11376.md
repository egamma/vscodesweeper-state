# Issue #11376 — Unable to open files on the remote WSL connection

[https://github.com/microsoft/vscode-remote-release/issues/11376](https://github.com/microsoft/vscode-remote-release/issues/11376)

## Summary

Keep open: the supplied steps and matching logs suffice to retest the WSL-over-SSH folder-opening failure. Versions have advanced since the historical confirmations, but neither a current resolution nor a canonical covering this exact symptom is established.

## Change summary

Opening a folder in WSL reached through an SSH connection to Windows fails because the WSL remote authority cannot be resolved.

## Best solution

The WSL and SSH owners should investigate resolver availability when opening a folder in an established nested WSL session, preserving the SSH parent connection. Retest the supplied sequence on current releases and determine whether it shares the command-activation defect in the related report.
