# Issue #11543 — Extensions defined in devcontainer.json are not auto-installing

[https://github.com/microsoft/vscode-remote-release/issues/11543](https://github.com/microsoft/vscode-remote-release/issues/11543)

## Summary

The extensions mechanism works once the container can reach the Marketplace through the configured proxy; the remaining gap is that installation stalls without surfacing the network failure. Keep this as a Dev Containers diagnosability improvement and route it to proxy handling.

## Change summary

Surface an actionable error when extensions requested by devcontainer.json cannot be downloaded because Marketplace endpoints are unreachable.

## Best solution

Dev Containers should stop the indefinite installation state and surface the failed Marketplace request with proxy guidance, while preserving the existing customizations.vscode.extensions behavior.

## Evidence

- **documented network requirement:** https://code.visualstudio.com/docs/setup/network documents that querying and installing extensions requires network access and lists marketplace.visualstudio.com and the *.gallery.vsassets.io CDN endpoints.
