# Issue #11543 — Extensions defined in devcontainer.json are not auto-installing

[https://github.com/microsoft/vscode-remote-release/issues/11543](https://github.com/microsoft/vscode-remote-release/issues/11543)

## Summary

Keep open for the remaining diagnosability improvement: the reporter resolved automatic installation by configuring the container's proxy, but requested visible feedback instead of indefinite installation progress when downloads are blocked.

## Change summary

Show an actionable warning when extensions declared in devcontainer.json cannot be downloaded, rather than leaving installation apparently pending indefinitely.

## Best solution

The Dev Containers owner should assess how automatic extension installation reports blocked Marketplace requests and surface the failure with actionable network guidance. If the missing feedback belongs wholly to core extension management, a maintainer can transfer this to microsoft/vscode.
