# Issue #10455 — Always forward docker credential helper to support ORAS.

[https://github.com/microsoft/vscode-remote-release/issues/10455](https://github.com/microsoft/vscode-remote-release/issues/10455)

## Summary

The shipped ORAS and Skopeo executable checks only partially address the request; OCI client libraries without those executables still cannot use the forwarded credential helper. No open canonical issue owns this specific remaining capability.

## Change summary

Allow Docker credential-helper forwarding in dev containers even when no Docker, ORAS, or Skopeo executable is installed.

## Best solution

Dev Containers should provide a documented way to force credential-helper registration independently of executable detection, potentially by making the enabled `dev.containers.dockerCredentialHelper` setting authoritative while preserving a lightweight default.
