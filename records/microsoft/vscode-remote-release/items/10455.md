# Issue #10455 — Always forward docker credential helper to support ORAS.

[https://github.com/microsoft/vscode-remote-release/issues/10455](https://github.com/microsoft/vscode-remote-release/issues/10455)

## Summary

Keep open for credential forwarding to OCI client libraries without a detected executable. The announced ORAS/Skopeo change covers command-line tools, not the reporter's library-only workflow; the maintainer proposed a configurable solution.

## Change summary

Allow Docker credential-helper forwarding when a container uses OCI client libraries without docker, oras, or skopeo executables.

## Best solution

Dev Containers should offer an explicit way to enable credential-helper forwarding independently of executable detection, preserving lightweight defaults and the existing disable control.
