Verified duplicate: the older open issue tracks the same Dev Containers failure to pass the Kubernetes extension's selected kubeconfig when attaching to a pod.

## Change summary

Dev Containers should use the Kubernetes extension's active non-default kubeconfig when attaching VS Code to a pod.
