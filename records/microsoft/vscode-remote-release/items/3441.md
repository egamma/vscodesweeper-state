# Issue #3441 — Provide an option to link to a devcontainer definition in a repo

[https://github.com/microsoft/vscode-remote-release/issues/3441](https://github.com/microsoft/vscode-remote-release/issues/3441)

## Summary

Keep open: published Templates generate local configuration files rather than maintaining a live reference to a shared definition. Features cover reusable installation and lifecycle hooks, but do not establish that the full configuration-linking request is satisfied.

## Change summary

Allow devcontainer.json to reference a centrally maintained container definition, inherit its updates, and supply template-specific options.

## Best solution

The Dev Containers component should coordinate a spec-compatible mechanism for resolving reusable configuration references with local options. Retain this issue for the extension-side behavior; template discovery and spec proposals do not independently deliver it.
