# Issue #3441 — Provide an option to link to a devcontainer definition in a repo

[https://github.com/microsoft/vscode-remote-release/issues/3441](https://github.com/microsoft/vscode-remote-release/issues/3441)

## Summary

This is a duplicate of the broader, open inheritance and overlay request, which explicitly covers externally hosted parent definitions, merged overrides, and centrally distributed updates.

## Change summary

Allow repositories to reference a centrally maintained, parameterized dev-container definition and automatically receive its updates.

## Best solution

Consolidate the Julia template and parameterization use case on https://github.com/microsoft/vscode-remote-release/issues/3279. Any resulting inheritance property should be standardized through the Dev Container specification before the extension implements it.
