# Issue #7625 — Configure Container Features should not be available in a local window

[https://github.com/microsoft/vscode-remote-release/issues/7625](https://github.com/microsoft/vscode-remote-release/issues/7625)

## Summary

Keep open for the maintainer-proposed improvement: opening devcontainer.json after configuring Features would make the result visible. Local command availability is intentional, but the documented capability does not establish that this feedback gap has been addressed.

## Change summary

Make Configure Container Features visibly show the configuration changes after selections in a local window.

## Best solution

The Dev Containers extension should retain local configuration editing and open the updated devcontainer.json when the command finishes, as proposed in the thread. Check whether that completion behavior already ships before implementing the polish.
