# Issue #10949 — Cannot choose branch of dotfiles repository

[https://github.com/microsoft/vscode-remote-release/issues/10949](https://github.com/microsoft/vscode-remote-release/issues/10949)

## Summary

Keep open: selecting a dotfiles branch remains a distinct Dev Containers capability request. The maintainer suggested a command-based workaround, not a shipped branch-selection setting or a decision to decline the accepted Backlog item.

## Change summary

Allow choosing the dotfiles repository branch used when personalizing a dev container.

## Best solution

Dev Containers should provide explicit dotfiles branch selection before installation, retaining the repository default when no branch is specified. Keep the command-based checkout approach as an interim workaround.
