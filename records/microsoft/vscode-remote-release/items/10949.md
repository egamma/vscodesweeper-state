# Issue #10949 — Cannot choose branch of dotfiles repository

[https://github.com/microsoft/vscode-remote-release/issues/10949](https://github.com/microsoft/vscode-remote-release/issues/10949)

## Summary

This remains a valid Dev Containers feature gap: current dotfiles settings cannot select a branch, and the maintainer-provided command workaround does not cover the central configuration request.

## Change summary

Allow users to select which branch of a configured dotfiles repository is installed in a dev container.

## Best solution

The Dev Containers component should add a branch or Git-ref selector alongside the existing dotfiles repository settings while retaining the install-command workaround for custom flows.
