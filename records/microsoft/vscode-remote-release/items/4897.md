# Issue #4897 — Clone Repo in Container Volume: Generic clone command

[https://github.com/microsoft/vscode-remote-release/issues/4897](https://github.com/microsoft/vscode-remote-release/issues/4897)

## Summary

A real Dev Containers capability gap remains: the volume-clone workflow still documents only repository identifiers and URLs, not customizable Git arguments. No open canonical issue owns the broader request.

## Change summary

Allow users to customize the Git clone command used by Clone Repository in Container Volume, including options such as --recursive and --single-branch.

## Best solution

The Dev Containers extension should provide a safe advanced clone-options surface for repository-container volumes, covering recursive submodules and branch-limited clones without requiring a post-clone workaround.
