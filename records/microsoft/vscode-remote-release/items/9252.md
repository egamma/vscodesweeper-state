## Change summary

Git pushes from a Dev Container intermittently fail because copied host-specific GitHub CLI credential helpers and generated VS Code credential-forwarding files are unavailable inside the container.

## Best solution

Dev Containers should prevent copied URL-specific credential helpers from invoking host-only binaries and ensure its generated credential helper remains available for the container session. A current reproduction should establish whether both failures remain or only the broader configuration behavior tracked in https://github.com/microsoft/vscode-remote-release/issues/10587 persists.
