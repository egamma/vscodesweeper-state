[https://github.com/microsoft/vscode-remote-release/issues/9252](https://github.com/microsoft/vscode-remote-release/issues/9252)

Keep open for Dev Containers credential-forwarding investigation. Releases have advanced since the supplied 0.327.0 log, but the steps, container log, and gitconfig suffice to retest; neither a confirmed fix nor a canonical covering the full failure was established.

## Change summary

Git push inside a WSL-hosted dev container fails with host-specific gh credential helpers and missing container helper resources.

## Best solution

Dev Containers should forward HTTPS credentials correctly when gh auth setup-git creates URL-specific helpers. Retest the supplied configuration and distinguish helper-precedence failures from the missing temporary helper script and Git askpass socket before choosing the fix.
