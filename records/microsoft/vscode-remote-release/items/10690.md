# Issue #10690 — remote ssh troubleshooting shows in terminal pane instead of default terminal on every start

[https://github.com/microsoft/vscode-remote-release/issues/10690](https://github.com/microsoft/vscode-remote-release/issues/10690)

## Summary

Keep open as SSH polish: stale enhanced-session metadata repeatedly replaces the normal terminal with obsolete troubleshooting output. The documented cleanup command is only a workaround, and no canonical issue owns this behavior.

## Change summary

Prevent a past Remote-SSH offline error from reopening the troubleshooting terminal after subsequent successful sessions.

## Best solution

Remote - SSH should clear or disregard stale `enhancedSessionLogs` offline metadata after a successful connection and avoid displacing the user's normal terminal with obsolete diagnostics.
