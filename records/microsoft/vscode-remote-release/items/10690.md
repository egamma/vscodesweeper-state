# Issue #10690 — remote ssh troubleshooting shows in terminal pane instead of default terminal on every start

[https://github.com/microsoft/vscode-remote-release/issues/10690](https://github.com/microsoft/vscode-remote-release/issues/10690)

## Summary

Keep open as SSH polish: an old offline diagnostic repeatedly displaces the usable terminal after successful connections. Clearing session metadata is a workaround, not a confirmed shipped fix, and the thread accepts improving this experience.

## Change summary

Prevent a previous Remote - SSH offline diagnostic from reopening in the terminal pane on every subsequent successful connection.

## Best solution

Remote - SSH should retire stale enhanced-session diagnostics after successful sessions without requiring manual metadata cleanup. Investigate whether toggling the experimental logging or chat settings leaves the previous error active, as raised in the thread.
