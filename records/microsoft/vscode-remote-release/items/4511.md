## Change summary

Allow code to open remote files in an existing local VS Code window from arbitrary external SSH terminal sessions.

- **Unique proposal to preserve:** https://github.com/microsoft/vscode-remote-release/issues/4511 links https://github.com/chvolkmann/code-connect, which discovers an existing IPC socket for arbitrary terminal connections. The issue's 2021-02-22 maintainer comment accepts that the remote console IPC channel could be used while noting that selecting the correct channel is nontrivial; this is useful design evidence for the canonical.
