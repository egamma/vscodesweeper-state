# Issue #5000 — Files on /mnt/ do not refresh when is modified from external source

[https://github.com/microsoft/vscode-remote-release/issues/5000](https://github.com/microsoft/vscode-remote-release/issues/5000)

## Summary

Keep open as an upstream WSL limitation. A maintainer identified missing WSL2 file events on `/mnt` as the root cause, and the upstream WSL issue remains open.

## Change summary

Files open from Windows-mounted paths in WSL do not refresh when an external process modifies them.

## Best solution

WSL must provide reliable file-change notifications across the Windows/Linux filesystem boundary. Until then, retain this issue for WSL-extension visibility and recommend storing projects in the Linux filesystem.
