# Issue #7927 — Forwarding ssh agent from Windows to WSL

[https://github.com/microsoft/vscode-remote-release/issues/7927](https://github.com/microsoft/vscode-remote-release/issues/7927)

## Summary

Keep this accepted WSL feature request open: documented credential sharing excludes SSH keys, and third-party bridges do not provide the requested integrated forwarding option. The verified related issues concern different authentication paths, not the same observable gap.

## Change summary

Add an option to forward the Windows SSH agent into WSL, with actionable errors when the agent cannot be used.

## Best solution

The WSL extension should provide opt-in Windows-agent forwarding usable by WSL tools and remote extensions, with appropriate lifecycle handling and compatibility diagnostics. Existing external bridges can inform the design but do not replace the product integration.
