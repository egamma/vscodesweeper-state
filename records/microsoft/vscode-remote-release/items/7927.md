# Issue #7927 — Forwarding ssh agent from Windows to WSL

[https://github.com/microsoft/vscode-remote-release/issues/7927](https://github.com/microsoft/vscode-remote-release/issues/7927)

## Summary

Keep open in the Backlog: the community process accepted this request after it reached 10 upvotes, and current WSL documentation still provides no native way to forward the Windows SSH agent into WSL.

## Change summary

Add an option for Remote - WSL to expose the Windows SSH agent inside WSL, including useful handling of known Win32 OpenSSH incompatibilities.

## Best solution

The WSL extension should securely bridge the Windows OpenSSH agent into WSL and configure SSH_AUTH_SOCK, with a clear diagnostic when the installed Win32 OpenSSH version is incompatible. This should avoid requiring users to maintain an external socat/npiperelay bridge.
