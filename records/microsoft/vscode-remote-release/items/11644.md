# Issue #11644 — `~/.copilot/skills` not found inside devcontainers

[https://github.com/microsoft/vscode-remote-release/issues/11644](https://github.com/microsoft/vscode-remote-release/issues/11644)

## Summary

Keep open: documented personal skill locations and explicit bind mounts do not establish automatic discovery of host-owned skills inside dev containers. The request is already routed to containers and accepted into Backlog; no verified canonical or confirmed implementation was found.

## Change summary

Make host-level ~/.copilot/skills available automatically when using VS Code inside a dev container, without per-project mounts or copies.

## Best solution

The Dev Containers owner should coordinate with VS Code's agent-customization owner on making personal skills available across the host/container boundary, including their supporting resources and an explicit access policy. Manual mounts should remain a workaround rather than be treated as satisfying automatic discovery.
