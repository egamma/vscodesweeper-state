# Issue #4645 — Allow forwarded ports from all containers in Dev Container composition

[https://github.com/microsoft/vscode-remote-release/issues/4645](https://github.com/microsoft/vscode-remote-release/issues/4645)

## Summary

Keep open for maintainer disposition because this is a team-authored Backlog request. The Dev Container specification now defines the requested declarative `"host:port"` syntax, but the thread does not confirm that Codespaces implements it.

## Change summary

Allow `devcontainer.json` to declaratively forward ports from supporting Docker Compose service containers in Codespaces.

## Best solution

Codespaces should honor entries such as `"forwardPorts": ["db:5432"]`, matching the Dev Container specification; the Codespaces owner should confirm current support and either document it or retain this as the implementation gap.
