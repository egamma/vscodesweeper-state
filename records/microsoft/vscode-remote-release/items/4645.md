[https://github.com/microsoft/vscode-remote-release/issues/4645](https://github.com/microsoft/vscode-remote-release/issues/4645)

## Summary

Current documentation describes declarative forwarding of secondary Compose services through forwardPorts host:port entries. Keep this team-authored, security-sensitive item open for maintainer confirmation: neither a qualifying public fix nor reporter-confirmed resolution establishes a factual close.

## Change summary

Allow declarative forwarding of ports from secondary Docker Compose containers without attaching additional editor windows or sharing network namespaces.

## Best solution

Use the existing forwardPorts array, such as [3000, "db:5432"], rather than introducing a service-map format. The containers owner should confirm that this delivers local database access in Codespaces while preserving separate network namespaces and database authentication.
