# Issue #11749 — Leaking `agent host` processes when your home directory is on NFS

[https://github.com/microsoft/vscode-remote-release/issues/11749](https://github.com/microsoft/vscode-remote-release/issues/11749)

## Summary

The detailed report identifies a plausible host-agnostic lock-file collision that leaks agent-host processes across machines sharing an NFS home, but there is not yet an independent confirmation. Requesting a current-version retest with process and lock-state snapshots.

## Change summary

Remote - SSH repeatedly leaves inaccessible agent-host processes running when multiple remote machines share the user's NFS-mounted home directory.

## Best solution

The VS Code Server/CLI lifecycle should make agent-host discovery machine-specific, such as by namespacing its lock state by host or storing it in a machine-local runtime directory, and should eventually terminate unreachable idle agents.
