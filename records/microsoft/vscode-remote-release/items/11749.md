# Issue #11749 — Leaking `agent host` processes when your home directory is on NFS

[https://github.com/microsoft/vscode-remote-release/issues/11749](https://github.com/microsoft/vscode-remote-release/issues/11749)

## Summary

Keep open: the report provides sufficient steps to retest agent-host accumulation when alternating between machines sharing an NFS home directory. No confirmed resolution or open canonical was found; newer versions alone would not establish a fix.

## Change summary

Alternating SSH connections between hosts sharing an NFS home directory reportedly loses agent-host discovery information and accumulates orphaned processes.

## Best solution

The remote CLI's agent-host discovery should distinguish machines sharing a home directory and reuse the appropriate existing process without accumulating inaccessible instances. The SSH/server owners should reproduce the A–B–A sequence and determine whether idle agent hosts also need bounded shutdown.
