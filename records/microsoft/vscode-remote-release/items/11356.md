# Issue #11356 — Inconsistent behaviour of dev container local features depending on configuration location

[https://github.com/microsoft/vscode-remote-release/issues/11356](https://github.com/microsoft/vscode-remote-release/issues/11356)

## Summary

Keep open: the directory layouts, setting, and error provide sufficient steps to retest this accepted Dev Containers configuration inconsistency. Current documentation still exposes the conflicting workspace restriction; the later spec discussion and third-party workaround do not establish a product fix.

## Change summary

Local Features stop building when an otherwise working dev container configuration is moved outside the repository to a supported configuration location.

## Best solution

The Dev Containers owner should coordinate external-configuration support with the spec and reference CLI so local Features work when opening the original repository. Document the current restriction and improve the diagnostic while that compatibility gap remains.
