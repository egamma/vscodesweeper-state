# Issue #11356 — Inconsistent behaviour of dev container local features depending on configuration location

[https://github.com/microsoft/vscode-remote-release/issues/11356](https://github.com/microsoft/vscode-remote-release/issues/11356)

## Summary

The behavior follows the current Dev Container specification, and the broader request to support reusable local Features is already tracked in the open devcontainers/spec issue that explicitly covers alternative repository configuration paths.

## Change summary

Allow locally referenced Dev Container Features to work when the selected devcontainer configuration is stored outside the opened workspace.

## Best solution

Consolidate the capability decision in https://github.com/devcontainers/spec/issues/671 so the specification and CLI define consistent path semantics; the Dev Containers documentation should then clearly describe the supported behavior.
