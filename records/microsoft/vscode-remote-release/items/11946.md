# Issue #11946 — [Remote-SSH Bug]: Install script waits forever holding the lock after a failed local server download

[https://github.com/microsoft/vscode-remote-release/issues/11946](https://github.com/microsoft/vscode-remote-release/issues/11946)

## Summary

Keep open for Remote - SSH: the report supplies sufficient steps and process evidence to retest an installer that retains its lock after download failure. There is no independent confirmation, verified fix, or established canonical for this cleanup failure.

## Change summary

A failed client-side fallback download leaves the legacy remote installer waiting indefinitely and holding a lock that blocks subsequent connections.

## Best solution

Remote - SSH should terminate or explicitly fail the pending host-side transfer wait when the client abandons the download, releasing the installation lock. Verify that a subsequent connection succeeds without manually killing the installer, including when the server has been installed separately.
