# Issue #8409 — EACCESS error when changing devcontainer-lock.json file

[https://github.com/microsoft/vscode-remote-release/issues/8409](https://github.com/microsoft/vscode-remote-release/issues/8409)

## Summary

Keep open: this team-authored bug has two concrete reports of permission failures, including a regression identified in Dev Containers 0.292.0. No factual duplicate or public fixing commit supports closing it.

## Change summary

Files created or opened in a newly generated dev container can become unwritable because the container user lacks the required permissions.

## Best solution

The Dev Containers owner should retest the current “New Dev Container” flow and ensure generated workspace files, including devcontainer-lock.json, remain writable by the container user after rebuilds.
