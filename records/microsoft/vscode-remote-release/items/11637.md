# Issue #11637 — user should be shown the local backup version of the  file, if remote SSH is disconnected during an unsaved edit.

[https://github.com/microsoft/vscode-remote-release/issues/11637](https://github.com/microsoft/vscode-remote-release/issues/11637)

## Summary

Keep this recovery-UX request open and route it to SSH. Documented backups provide a manual recovery path, but do not establish that users can discover the affected file's backup directly after disconnection.

## Change summary

Expose the local backup of an unsaved remote file when an SSH disconnection prevents saving it.

## Best solution

The SSH disconnection experience should offer an accessible way to view or recover available unsaved content locally without requiring reconnection or manual backup-directory searches. Coordinate with the core editor backup owners; if the recovery interface belongs entirely in core, a maintainer can transfer this to microsoft/vscode.
