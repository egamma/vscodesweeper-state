# Issue #3650 — Build image with user defined tag

[https://github.com/microsoft/vscode-remote-release/issues/3650](https://github.com/microsoft/vscode-remote-release/issues/3650)

## Summary

Keep open: CLI prebuilding supports explicit image tags, but it does not establish coverage for naming images produced by the extension's normal build workflow, including the Compose case raised here.

## Change summary

Allow users to configure the image name and tag produced when the Dev Containers extension builds their development environment.

## Best solution

The containers component should support predictable, user-defined tags for extension-managed builds, with clear behavior for Compose and derived images. Coordinate the overlapping Compose request without replacing this broader report with that narrower issue.
