# Issue #9226 — Empty ENTRYPOINT causes Dev Container to fail

[https://github.com/microsoft/vscode-remote-release/issues/9226](https://github.com/microsoft/vscode-remote-release/issues/9226)

## Summary

The attached log demonstrates the original failure, but there is no current-release confirmation. A retest is needed because Dev Containers and Docker Compose have changed substantially since 2023.

## Change summary

Dev Containers fails to start a Docker Compose container when its image declares an empty exec-form ENTRYPOINT.

## Best solution

If this still reproduces, the containers component should normalize an empty image ENTRYPOINT when constructing its keep-alive wrapper rather than passing an empty argument to `exec "$@"`.
