## Summary

Keep open for human review because the request concerns potential credential exposure. The cited CLI implementation does not establish equivalent secure, dynamic secret handling in the Dev Containers extension.

## Change summary

Add first-class secret injection to Dev Containers, including secure credential-store integration and updates without rebuilding containers.

The Dev Containers owner should define and implement secure runtime secret injection and refresh behavior, coordinating with the existing declarative-secrets and credential-store requests. Distinguish the implementation proposal from a finalized specification requirement and assess the reported leakage risk.
