# Issue #11580 — Bug: Missing First Class Secrets Support

[https://github.com/microsoft/vscode-remote-release/issues/11580](https://github.com/microsoft/vscode-remote-release/issues/11580)

## Summary

Keep open: this security-sensitive Dev Containers feature gap requires human review rather than an automated close. The specification and reference CLI establish first-class secret injection, while the extension does not document an equivalent secure mechanism.

## Change summary

Add secure, dynamically updateable secret injection to the Dev Containers extension without requiring container rebuilds or exposing values through remoteEnv.

## Best solution

The Dev Containers component should integrate a secure host-side secret provider with the CLI secrets interface, ensuring values are neither persisted nor exposed in logs and can change without rebuilding the container.
