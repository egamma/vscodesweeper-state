# Issue #6848 — Custom BuildKit frontends don't work in Remote-Container 0.238 and later

[https://github.com/microsoft/vscode-remote-release/issues/6848](https://github.com/microsoft/vscode-remote-release/issues/6848)

## Summary

Keep open because an open implementation PR explicitly targets this issue. The failure was well established, but no current-release retest establishes whether it still reproduces in 2026.

## Change summary

Dev Containers should support custom BuildKit frontends that do not use standard Dockerfile syntax or contain a leading FROM instruction.

## Best solution

The Dev Containers owners should decide whether to revise and land or close https://github.com/devcontainers/cli/pull/316, accounting for the documented multi-platform, caching, and build-complexity concerns. The issue should remain open while that implementation candidate is unresolved.
