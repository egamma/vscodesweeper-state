# Issue #6205 — Borken dotfiles config

[https://github.com/microsoft/vscode-remote-release/issues/6205](https://github.com/microsoft/vscode-remote-release/issues/6205)

## Summary

Verified duplicate of the older, open dotfiles-settings report: both describe settings unavailable in the User UI, rejected in local settings.json, and lost on container rebuild when configured remotely.

## Change summary

Dotfiles configuration should remain editable in persistent User settings while connected to a dev container.

## Best solution

Consolidate the settings-scope and persistence work in https://github.com/microsoft/vscode-remote-release/issues/4766, preserving this report's executeInWSL detail and confirmation that unprefixed dotfiles settings can still execute despite UI warnings.
