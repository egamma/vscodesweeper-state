[https://github.com/microsoft/vscode-remote-release/issues/8257](https://github.com/microsoft/vscode-remote-release/issues/8257)

## Summary

The reporter isolated different signal behavior between a Dev Container and ordinary `docker exec`, but the sole reproduction is from 2023 and the maintainer's earlier test did not exercise a Node signal handler. Current-version confirmation and diagnostics are needed.

## Change summary

Node processes launched from a Dev Container terminal or task exit without receiving their registered SIGINT or SIGTERM handlers.

## Best solution

Retest a minimal Node signal-handler program with current VS Code and Dev Containers versions, separately from the integrated terminal and a task. If the difference from ordinary `docker exec` remains, the Containers owner should determine whether signal forwarding belongs to Dev Containers or the VS Code terminal/task process path.
