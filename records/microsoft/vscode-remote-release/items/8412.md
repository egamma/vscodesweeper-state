# Issue #8412 — Multiple Dev Containers not recognized when cloning repository

[https://github.com/microsoft/vscode-remote-release/issues/8412](https://github.com/microsoft/vscode-remote-release/issues/8412)

## Summary

Keep open as the canonical feature request. Dev Containers now supports switching configurations after cloning through a default container, but it still cannot select among multiple definitions during the initial clone workflow.

## Change summary

Allow Clone Repository in Container Volume and clone redirect links to detect multiple dev-container definitions and let the user choose one.

## Best solution

The Dev Containers extension should defer final container creation until after cloning, then present the discovered configurations for selection; alternatively, clone redirect URIs should accept an explicit configuration path. The existing Switch Container workflow remains a workaround rather than coverage of the initial-selection request.
