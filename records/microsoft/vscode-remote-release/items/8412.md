# Issue #8412 — Multiple Dev Containers not recognized when cloning repository

[https://github.com/microsoft/vscode-remote-release/issues/8412](https://github.com/microsoft/vscode-remote-release/issues/8412)

## Summary

Consolidate this request into the verified older canonical, which tracks the same missing configuration picker when cloning into a container volume. Switch Container provides a workaround, not initial configuration discovery.

## Change summary

Discover and offer nested devcontainer.json configurations when cloning a repository into a container volume, including through cloneInVolume links.

## Best solution

Implement configuration discovery and selection before container creation under https://github.com/microsoft/vscode-remote-release/issues/7879. Preserve this report's redirect-link scenario and default-configuration workaround in the consolidation.
