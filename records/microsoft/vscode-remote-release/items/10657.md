# Issue #10657 — X11 Forwarding with Remote-ssh

[https://github.com/microsoft/vscode-remote-release/issues/10657](https://github.com/microsoft/vscode-remote-release/issues/10657)

## Summary

X11 forwarding is expected to work, but the current evidence is configuration-dependent and outdated: one user still reproduced it while another confirmed it working in Remote - SSH 0.120.0. A current retest is needed before distinguishing an extension regression from local DISPLAY, X server, or bastion configuration.

## Change summary

Remote - SSH does not reliably propagate a usable DISPLAY value for X11 forwarding, particularly from Windows through a bastion host.

## Best solution

Remote - SSH should preserve OpenSSH X11 forwarding and propagate its DISPLAY value through ProxyCommand or bastion connections. First reproduce with a current release and compare the generated SSH command outside VS Code to isolate the extension from local X server configuration.
