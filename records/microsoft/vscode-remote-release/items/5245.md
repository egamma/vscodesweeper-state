# Issue #5245 — [Remote-SSH] can specify folder when connect to remote host using special connection string

[https://github.com/microsoft/vscode-remote-release/issues/5245](https://github.com/microsoft/vscode-remote-release/issues/5245)

## Summary

Keep open: this accepted Backlog feature request still identifies a gap in the Remote-SSH connection picker. Existing CLI and Remote Explorer paths reduce the friction but do not let users enter an arbitrary remote folder in the Connect to Host dialog.

## Change summary

Allow Remote-SSH users to specify a remote folder while selecting or entering an SSH host so the connection opens directly in that folder.

## Best solution

The Remote-SSH connection picker should support an unambiguous host-and-folder input or offer previously opened folders alongside each host, while preserving standard SSH host parsing.

## Vision fit

- **Fit:** aligned
- **Reason:** Reducing the host-then-folder flow makes remote workspace startup feel more like opening a local folder and improves SSH workflow fidelity.
- **Evidence:** The public vision emphasizes local-development parity and SSH fidelity; this request removes an extra remote-only navigation step without changing the established client-server architecture.
