# Issue #5245 — [Remote-SSH] can specify folder when connect to remote host using special connection string

[https://github.com/microsoft/vscode-remote-release/issues/5245](https://github.com/microsoft/vscode-remote-release/issues/5245)

## Summary

Keep this accepted SSH feature request open: command-line folder URIs and Remote Explorer shortcuts do not cover entering a destination folder directly in the Connect to Host dialog. No verified open canonical was found.

## Change summary

Allow Remote-SSH: Connect to Host to accept a connection string containing the remote folder and open it immediately.

## Best solution

The Remote - SSH extension should provide a supported way to specify both the SSH destination and remote folder in its keyboard-driven connection dialog, without requiring a separate folder-selection step.
