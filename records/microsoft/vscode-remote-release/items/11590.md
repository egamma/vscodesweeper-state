# Issue #11590 — Remote‑SSH: Preserve or surface SSH bootstrap terminal output on connection failure

[https://github.com/microsoft/vscode-remote-release/issues/11590](https://github.com/microsoft/vscode-remote-release/issues/11590)

## Summary

A real Remote-SSH diagnostics gap remains: existing logs and the login-terminal setting expose connection output, but neither preserves nor automatically surfaces the failure output as requested. Route this connection UX improvement to the SSH owner.

## Change summary

Preserve the SSH bootstrap terminal or automatically surface its captured output when a Remote-SSH connection fails.

## Best solution

Remote-SSH should retain the failed bootstrap terminal or reveal the Remote-SSH output panel automatically, while continuing to dispose successful bootstrap terminals. The existing `remote.SSH.showLoginTerminal` setting is a partial workaround, not coverage of post-failure persistence.
