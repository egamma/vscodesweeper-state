# Issue #1982 — Open workspace in container when workspace file is not at the root

[https://github.com/microsoft/vscode-remote-release/issues/1982](https://github.com/microsoft/vscode-remote-release/issues/1982)

## Summary

A documented Dev Containers limitation still excludes workspaces whose file references a parent directory. No open canonical issue clearly owns this specific capability, so the existing feature request should remain open.

## Change summary

Allow Open Workspace in Container when a nested .code-workspace file references its parent directory.

## Best solution

Dev Containers should determine and mount an appropriate common root for these workspaces, or provide an explicit configuration that safely makes parent folders available while preserving the workspace file's relative paths.
