# Issue #1982 — Open workspace in container when workspace file is not at the root

[https://github.com/microsoft/vscode-remote-release/issues/1982](https://github.com/microsoft/vscode-remote-release/issues/1982)

## Summary

Keep open: current documentation still excludes parent-relative folders from Open Workspace in Container, matching this request's ide/*.code-workspace layout. The verified related issues do not own the same observable limitation.

## Change summary

Support opening a container workspace whose .code-workspace file sits in an ide subfolder and references the repository root through "..".

## Best solution

Dev Containers should support resolving and mounting parent-relative workspace folders while preserving the workspace file's location. Opening the repository folder in a container before opening the nested workspace is an alternative workflow, not equivalent support in Open Workspace in Container.
