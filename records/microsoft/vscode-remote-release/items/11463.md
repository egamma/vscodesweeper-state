# Issue #11463 — remote-ssh closes the SSH session after laptop wakes up from sleep even though the session could stay up

[https://github.com/microsoft/vscode-remote-release/issues/11463](https://github.com/microsoft/vscode-remote-release/issues/11463)

## Summary

Consolidate this report into the older, open sleep/wake resilience request at https://github.com/microsoft/vscode-remote-release/issues/5755. It tracks the same observable failure: Remote - SSH abandons a session after laptop sleep while terminal SSH remains usable.

## Change summary

Allow recoverable SSH sessions to survive laptop sleep and network recovery without premature exec-server or local-server timeout shutdown.

## Best solution

Track sleep-aware connection preservation in https://github.com/microsoft/vscode-remote-release/issues/5755, carrying over this report's evidence that both timeout paths need attention. The SSH owner should address cached-connection recovery and local-server shutdown together rather than requiring extension monkey patches.
