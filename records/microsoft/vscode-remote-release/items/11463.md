# Issue #11463 — remote-ssh closes the SSH session after laptop wakes up from sleep even though the session could stay up

[https://github.com/microsoft/vscode-remote-release/issues/11463](https://github.com/microsoft/vscode-remote-release/issues/11463)

## Summary

Verified duplicate: the open canonical issue already tracks Remote - SSH discarding a viable connection after laptop sleep. This report contributes a current, controlled diagnosis of the ping and delay-shutdown timeouts.

## Change summary

Remote - SSH abandons a surviving SSH connection after laptop sleep because its cached-server and shutdown timeouts expire before networking recovers.

## Best solution

Consolidate on https://github.com/microsoft/vscode-remote-release/issues/5755. Remote - SSH should use sleep-aware timeout handling and revalidate or reuse a healthy tunnel after wake rather than immediately replacing it.
