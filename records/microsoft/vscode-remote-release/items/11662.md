# Issue #11662 — Host aliases show up as distinct severs

[https://github.com/microsoft/vscode-remote-release/issues/11662](https://github.com/microsoft/vscode-remote-release/issues/11662)

## Summary

This is an actionable Remote Explorer polish gap: every pattern in a multi-name SSH Host directive is displayed separately, with no documented way to collapse or hide compatibility aliases. Route it to Remote - SSH configuration and explorer ownership.

## Change summary

Represent aliases from one SSH Host directive as a single server rather than separate Remote Explorer targets.

## Best solution

Remote - SSH should preserve every alias for connection compatibility while letting Remote Explorer group aliases from one Host directive under one logical target, or selectively hide compatibility aliases.
