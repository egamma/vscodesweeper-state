Keep open for SSH-owner investigation: the supplied steps and logs suffice to retest the connection timeout. Later releases have mixed reports of similar failures and recovery, but neither resolution of this report nor a shared root cause is established.

## Change summary

Remote-SSH times out opening an SSH connection on macOS Tahoe while terminal SSH to the same host succeeds.

## Best solution
