# Issue #7525 — Unable to use keys forwarded by Windows ssh-agent <=8.8 with ssh client >=8.9

[https://github.com/microsoft/vscode-remote-release/issues/7525](https://github.com/microsoft/vscode-remote-release/issues/7525)

## Summary

Keep open as an upstream Windows OpenSSH agent incompatibility. This reopened issue owns the general container-authentication failure; neither the narrower cloning workaround nor the reporter's intention to upgrade establishes resolution.

## Change summary

Forwarded keys appear in ssh-add but cannot authenticate from containers running OpenSSH 8.9 or later against an older Windows ssh-agent.

## Best solution

The compatibility fix belongs to OpenSSH for Windows; retain this issue as the general Dev Containers tracking point until an upgraded Windows agent is confirmed to resolve authentication inside the affected container. The extension's cloning-client downgrade does not fix arbitrary SSH commands inside user containers.
