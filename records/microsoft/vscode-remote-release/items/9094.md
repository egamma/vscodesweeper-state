[https://github.com/microsoft/vscode-remote-release/issues/9094](https://github.com/microsoft/vscode-remote-release/issues/9094)

## Summary

Keep open: the supplied steps and logs suffice to retest incorrect local-versus-remote Git configuration precedence. The report predates current releases, but neither the thread nor related issues establishes a fix; containers routing is already correct.

## Change summary

Dev Containers copies the local ~/.gitconfig alongside the SSH host's XDG Git configuration, causing local values to override remote values.

## Best solution

Dev Containers should consider both remote global Git configuration locations before falling back to local configuration, preserving remote-host precedence. Retest the supplied mixed-location scenario and use this older report to track the precedence defect, with the related WSL report as supporting evidence.
