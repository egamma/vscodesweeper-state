# Issue #9094 — Dev container prioritizes copying local host's ~/.gitconfig over remote host's $XDG_CONFIG_HOME/git/config

[https://github.com/microsoft/vscode-remote-release/issues/9094](https://github.com/microsoft/vscode-remote-release/issues/9094)

## Summary

The logs support a plausible precedence bug, but the report has no current-release reproduction or independent confirmation. A retest with current Dev Containers and VS Code versions is needed.

## Change summary

When creating a dev container on an SSH host, the extension copies both the local ~/.gitconfig and the remote XDG Git config, causing Git to prefer the local configuration.

## Best solution

The Dev Containers extension should recognize the remote host's $XDG_CONFIG_HOME/git/config as an existing remote configuration and avoid copying a higher-precedence local ~/.gitconfig. First confirm the behavior and capture a current dev-container creation log.
