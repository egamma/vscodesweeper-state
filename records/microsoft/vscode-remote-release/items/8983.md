# Issue #8983 — [remote] close remote connection should connect to hosting remote

[https://github.com/microsoft/vscode-remote-release/issues/8983](https://github.com/microsoft/vscode-remote-release/issues/8983)

## Summary

Keep open: the documented disconnect command returns to the local machine, not the enclosing SSH host, and maintainers proposed a command for exiting only the innermost connection. This team-authored Backlog request has no verified fix or qualifying canonical duplicate.

## Change summary

Allow leaving a dev container nested inside an SSH connection without also leaving the enclosing remote host.

## Best solution

The remote connection command surface should offer an explicit exit-one-level action, coordinated with Dev Containers and Remote - SSH. Follow the thread's proposal to remove the innermost remote authority and reconnect an empty window to the enclosing host, while retaining a full-disconnect option.
