# Issue #5033 — Ability to remove all integration "helpers"

[https://github.com/microsoft/vscode-remote-release/issues/5033](https://github.com/microsoft/vscode-remote-release/issues/5033)

## Summary

The broad opt-out remains unimplemented. Individual Git controls exist, but SSH-agent and other integration forwarding still lack one global “manage everything myself” setting, and newer narrower requests confirm the continuing gap.

## Change summary

Add a global mode that disables Dev Containers' automatic Git, credential-agent, dotfiles, socket, and environment integrations.

## Best solution

The Dev Containers extension should provide one local user setting that disables all automatic host integration, with granular settings available as overrides. This issue should remain the umbrella while credential forwarding and socket-specific evidence from newer reports informs the design.

## Vision fit

- **Fit:** aligned
- **Reason:** Explicit control over host integration deepens Dev Container capability and supports isolated environments without changing the established client-server architecture.
- **Evidence:** The durable vision theme includes Dev Container capability depth, while the current direction treats containers as sandboxes for agent workflows.
