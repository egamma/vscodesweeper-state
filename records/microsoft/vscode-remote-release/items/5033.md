# Issue #5033 — Ability to remove all integration "helpers"

[https://github.com/microsoft/vscode-remote-release/issues/5033](https://github.com/microsoft/vscode-remote-release/issues/5033)

## Summary

Keep open: individual controls cover parts of this request, but no verified capability provides the requested global opt-out from container personalization and integration helpers. Related forwarding requests overlap without clearly owning the full customization scope.

## Change summary

Provide one global switch to disable optional Dev Containers integration helpers so users can manage their container home directory and environment themselves.

## Best solution

The containers component should define and document a single opt-out for optional Git configuration, credential/agent forwarding, dotfiles installation, and environment personalization while preserving the connection machinery required by VS Code. Coordinate forwarding controls with the related requests without losing this issue's broader customization goal.
