## Change summary

Inspecting a volume incorrectly reuses its recovery container, whose /workspaces mount does not match the inspection flow's expected /volume path.

## Best solution

Dev Containers should distinguish recovery containers from volume-inspection containers when selecting a reusable container, ensuring inspection opens the correct mounted path. Retest the supplied scenario on the current extension before deciding whether implementation work remains.
