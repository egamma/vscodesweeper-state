# Issue #5138 — Recovery container used as Inspect container

[https://github.com/microsoft/vscode-remote-release/issues/5138](https://github.com/microsoft/vscode-remote-release/issues/5138)

## Summary

Keep open: this team-authored issue identifies a concrete container-selection defect, and there is no verified duplicate or public fix referencing it.

## Change summary

Volume inspection incorrectly selects a recovery container whose volume is mounted at `/workspaces`, then expects it at `/volume`.

## Best solution

Dev Containers should distinguish recovery and inspection containers, then select only a container with the expected inspection mount.
