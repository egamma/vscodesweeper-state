# Issue #6014 — [Containers] Support using nerdctl to connect to a containerd backend

[https://github.com/microsoft/vscode-remote-release/issues/6014](https://github.com/microsoft/vscode-remote-release/issues/6014)

## Summary

The central request remains open: Finch can now run some dev containers through nerdctl, but direct nerdctl and Compose compatibility still have documented gaps, and Docker-compatible alternatives are not officially supported.

## Change summary

Support nerdctl as the container CLI used by Dev Containers to create, inspect, and attach to containers on containerd.

## Best solution

The Dev Containers component and public devcontainers CLI should handle nerdctl's remaining version and Compose differences, then document a supported nerdctl configuration. Reusable container-engine abstractions should remain aligned with https://github.com/devcontainers/spec/issues/11.
