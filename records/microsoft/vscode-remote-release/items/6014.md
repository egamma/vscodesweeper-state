## Summary

Keep open as the nerdctl interoperability tracker. Finch success demonstrates progress, but does not establish that direct nerdctl discovery, attachment, and Compose workflows are covered; current VS Code documentation still links this request as outstanding.

## Change summary

Support using nerdctl with a containerd backend for Dev Containers workflows instead of requiring the Docker CLI.

## Best solution

The Dev Containers owner should establish which direct nerdctl workflows remain unsupported, including container discovery/attachment and Compose builds, and coordinate CLI compatibility changes with devcontainers/cli. Retain this product tracker until those workflows are covered, documenting Finch as an available alternative rather than full resolution.
