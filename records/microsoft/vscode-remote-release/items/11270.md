# Issue #11270 — Support trash in dev containers

[https://github.com/microsoft/vscode-remote-release/issues/11270](https://github.com/microsoft/vscode-remote-release/issues/11270)

## Summary

Keep the accepted containers request open: installing trash-cli and using the reporter's extension do not provide fully integrated Explorer trash support. Related remote-trash requests exist, but none is verified to own delivery of the complete Dev Containers capability.

## Change summary

Support moving files deleted through Explorer to trash inside dev containers instead of permanently deleting them.

## Best solution

The containers owner should coordinate native remote-filesystem trash support with VS Code core so Explorer deletion works with the container's trash and normal file-operation integration. Retain this product request until the shared implementation explicitly covers Dev Containers.
