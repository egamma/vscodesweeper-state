# Issue #9890 — Dev Containers: Possible bug with "appPort" property

[https://github.com/microsoft/vscode-remote-release/issues/9890](https://github.com/microsoft/vscode-remote-release/issues/9890)

## Summary

Keep open for the maintainer-accepted documentation clarification: numeric appPort entries bind to loopback, while strings pass through to Docker. The current public documentation still does not explain that distinction.

## Change summary

Clarify the different host-interface binding behavior of numeric and string appPort entries in the hover and public documentation.

## Best solution

The Dev Containers owner should clarify the appPort hover and coordinate matching updates to the VS Code documentation and Dev Container reference, explicitly distinguishing host-side loopback binding from the application's container-side listening address.
