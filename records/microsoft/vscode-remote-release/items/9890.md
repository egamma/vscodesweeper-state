# Issue #9890 — Dev Containers: Possible bug with "appPort" property

[https://github.com/microsoft/vscode-remote-release/issues/9890](https://github.com/microsoft/vscode-remote-release/issues/9890)

## Summary

The runtime behavior is intentional, but the acknowledged documentation gap remains: current public documentation does not explain that numeric appPort entries bind only to the loopback interface.

## Change summary

Clarify the different host-binding behavior of numeric and string appPort values.

## Best solution

Update the Dev Containers documentation and the devcontainer.json schema description to state that a numeric appPort binds on loopback, while a string is passed unchanged to Docker and can publish on other interfaces.
