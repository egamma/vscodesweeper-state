# Issue #443 — Increase priority of the vscode server

[https://github.com/microsoft/vscode-remote-release/issues/443](https://github.com/microsoft/vscode-remote-release/issues/443)

## Summary

This remains an uncovered SSH server-lifecycle request: no documented Remote - SSH setting controls server process priority, and no verified canonical issue owns the same behavior.

## Change summary

Keep the remote VS Code Server connection responsive during CPU-intensive workloads by raising the priority of its critical process.

## Best solution

The SSH component should decide whether connection-critical server work can receive configurable or automatic CPU scheduling priority without unnecessarily competing with the user's remote workload.
