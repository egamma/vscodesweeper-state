# Issue #6829 — Reconnect to remote server without reloading the whole screen and share a single ssh connection when working on multiple projects in the same machine

[https://github.com/microsoft/vscode-remote-release/issues/6829](https://github.com/microsoft/vscode-remote-release/issues/6829)

## Summary

Keep open: this accepted Backlog request remains relevant, and current related work does not cover its full multi-window reconnection scope. The issue is already correctly routed to Remote - SSH.

## Change summary

Reconnect all VS Code windows targeting one SSH host without reloading each workbench, ideally through a shared host connection.

## Best solution

Remote - SSH and VS Code core should provide state-preserving reconnection after extended outages, then coordinate reconnection across windows targeting the same host. The multi-window behavior should remain represented here even if core reconnect work is tracked separately.
