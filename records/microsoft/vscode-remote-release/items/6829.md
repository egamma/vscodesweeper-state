# Issue #6829 — Reconnect to remote server without reloading the whole screen and share a single ssh connection when working on multiple projects in the same machine

[https://github.com/microsoft/vscode-remote-release/issues/6829](https://github.com/microsoft/vscode-remote-release/issues/6829)

## Summary

Keep this accepted feature request open: shared SSH connections are documented, but coordinated reconnection across windows without reloading remains unconfirmed. The reporter's tentative improvement report does not establish resolution of the full request.

## Change summary

Reconnect all project windows on the same SSH host together without reloading each window or unnecessarily discarding session state.

## Best solution

The SSH owner should coordinate with VS Code core on host-wide reconnection that preserves existing windows and recoverable session state. Retain this issue for the multi-window workflow; persistent server sessions and a connection-reset command are related but do not independently deliver the whole request.
