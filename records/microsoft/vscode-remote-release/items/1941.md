# Issue #1941 — Open repository into container: support that the user can enter the credentials

[https://github.com/microsoft/vscode-remote-release/issues/1941](https://github.com/microsoft/vscode-remote-release/issues/1941)

## Summary

Keep this team-authored feature request open as the canonical request for complete interactive credential handling during repository-container cloning. Keyboard input forwarding was partially added, but later maintainer investigation confirms that passphrase and HTTPS credential prompts remain incomplete.

## Change summary

Allow users to enter Git HTTPS credentials or SSH key passphrases interactively while opening a repository in a container volume.

## Best solution

Dev Containers should support interactive Git authentication throughout repository bootstrap, including an appropriate GIT_ASKPASS path and SSH passphrase prompts. The narrower reports in https://github.com/microsoft/vscode-remote-release/issues/9163 can remain consolidated under this broader canonical request.

- **Evidence:** The public Dev Containers documentation supports credentials already available through a host credential helper or SSH agent, but does not cover the requested interactive fallback: https://code.visualstudio.com/remote/advancedcontainers/sharing-git-credentials.
