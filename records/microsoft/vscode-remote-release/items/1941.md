# Issue #1941 — Open repository into container: support that the user can enter the credentials

[https://github.com/microsoft/vscode-remote-release/issues/1941](https://github.com/microsoft/vscode-remote-release/issues/1941)

## Summary

Keep this as the Dev Containers tracking issue for interactive Git/SSH credential entry during repository cloning. Documented credential forwarding does not establish coverage of that request, and this team-authored item has no verified factual basis for closing.

## Change summary

Allow users to enter credentials interactively when cloning a repository into a container without credentials already available through a helper or SSH agent.

## Best solution

Dev Containers should surface Git/SSH authentication prompts during Clone Repository in Container Volume rather than require preconfigured credentials. Retain this broader tracking issue; the known_hosts improvement and WSL-specific authentication reports do not establish completion or a replacement canonical.
