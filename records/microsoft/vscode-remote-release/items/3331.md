# Issue #3331 — include.path inside gitconfig Not Working

[https://github.com/microsoft/vscode-remote-release/issues/3331](https://github.com/microsoft/vscode-remote-release/issues/3331)

## Summary

This remains the canonical request for preserving included Git configuration in Dev Containers. Current documentation covers copying the primary config, while recent reports confirm referenced files are still omitted.

## Change summary

Copy or safely flatten files referenced through Git include and includeIf directives when transferring host Git configuration into a Dev Container.

## Best solution

The Dev Containers extension should preserve applicable include and conditional-include configuration while filtering host-specific entries that cannot work inside the container.
