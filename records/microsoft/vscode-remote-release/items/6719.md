# Issue #6719 — remote - containers with Docker Desktop not forwarding ssh-agent from Git for Windows

[https://github.com/microsoft/vscode-remote-release/issues/6719](https://github.com/microsoft/vscode-remote-release/issues/6719)

## Summary

Git Bash SSH-agent forwarding was implemented and shipped in the November 2022 remote release. The initial implementation's matching communication failure received a public follow-up fix and maintainer verification.

## Change summary

Forward Git for Windows' SSH agent into dev containers without requiring the Windows ssh-agent service.

## Best solution

Treat this as completed by the shipped MINGW/Cygwin socket support and its handshake-stream correction; retain forwarding through SSH_AUTH_SOCK for Git Bash agents.
