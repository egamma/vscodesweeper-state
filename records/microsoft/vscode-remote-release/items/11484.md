# Issue #11484 — Setting the authentication provider when the tunnel is started

[https://github.com/microsoft/vscode-remote-release/issues/11484](https://github.com/microsoft/vscode-remote-release/issues/11484)

## Summary

Route this request to the tunnel CLI owners. Provider selection exists for a separate login command, but does not cover the requested single-command tunnel startup; no verified canonical owns that remaining improvement.

## Change summary

Allow the tunnel startup command to accept an authentication provider so scripts can bypass the provider-selection prompt.

## Best solution

Support provider selection directly when starting a tunnel, reusing the existing login provider choices and retaining the prompt when unspecified. The tunnel CLI owners should decide this interface improvement; a maintainer can transfer this to microsoft/vscode for the public CLI implementation.
