# Issue #10814 — Dev Containers does not work with podman

[https://github.com/microsoft/vscode-remote-release/issues/10814](https://github.com/microsoft/vscode-remote-release/issues/10814)

## Summary

Keep open as upstream: the thread identifies Flatpak isolation as preventing Podman execution, and the reporter confirms the official RPM works. That workaround does not establish that the original Flatpak failure was fixed.

## Change summary

Dev Containers cannot execute host Podman from the Flathub VS Code package on Fedora Silverblue 41.

## Best solution

The remaining Flatpak host-command integration belongs with https://github.com/flathub/com.visualstudio.code, rather than a general Dev Containers Podman change. Retain the reporter-confirmed official RPM workaround and the existing upstream classification.
