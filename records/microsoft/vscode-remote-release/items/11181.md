# Issue #11181 — Killing install terminal closes connection 

[https://github.com/microsoft/vscode-remote-release/issues/11181](https://github.com/microsoft/vscode-remote-release/issues/11181)

## Summary

The install terminal owns the active SSH process, so terminating it intentionally disconnects the remote session. It can instead be hidden without termination using VS Code's panel toggle; the separate authentication-prompt improvement remains tracked by issue 11182.

## Change summary

Allow the visible Remote-SSH login terminal used for two-factor authentication to be removed without disconnecting the session.

## Best solution

Keep the SSH process alive while allowing users to hide its terminal through View: Toggle Panel (Ctrl+J). Track presenting the second-factor challenge outside that terminal in https://github.com/microsoft/vscode-remote-release/issues/11182.
