# Issue #9389 — Development Containers don't work with Compose V2

[https://github.com/microsoft/vscode-remote-release/issues/9389](https://github.com/microsoft/vscode-remote-release/issues/9389)

## Summary

Dev Containers now defaults to `docker compose`, but this reporter has not confirmed that the change resolves their WSL2 setup. Request confirmation with the executable-path override removed rather than closing an accepted Backlog request.

## Change summary

Allow Dev Containers to use Compose V2 without requiring the obsolete standalone Compose V1 executable.

## Best solution

Use native Compose V2 detection without setting `dev.containers.dockerComposePath` to a command containing arguments. Confirm that this resolves the reported setup; if explicit argument-bearing overrides remain necessary, retain that extension-side requirement separately.
