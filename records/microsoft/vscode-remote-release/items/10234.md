# Issue #10234 — [Remote-SSH Bug]: Include port in data folder cache name

[https://github.com/microsoft/vscode-remote-release/issues/10234](https://github.com/microsoft/vscode-remote-release/issues/10234)

## Summary

The cache key demonstrably omitted the SSH port when reviewed, potentially reusing metadata across distinct port-addressed targets. Current behavior remains unconfirmed, so a retest on the latest Remote - SSH release is needed.

## Change summary

Include the SSH port in Remote - SSH's host metadata cache identity so connections to different containers behind one hostname do not share stale target data.

## Best solution

Remote - SSH should distinguish endpoints by hostname and port when caching host metadata, while preserving stable behavior for SSH aliases. First confirm whether current releases still reuse the wrong data and collect the Remote - SSH log from a failing attempt.
