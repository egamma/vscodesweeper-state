# Issue #10234 — [Remote-SSH Bug]: Include port in data folder cache name

[https://github.com/microsoft/vscode-remote-release/issues/10234](https://github.com/microsoft/vscode-remote-release/issues/10234)

## Summary

Keep open for Remote - SSH to retest port-specific cache isolation. The report predates current releases, but its same-host/different-port setup and wrong-container terminal outcome provide sufficient steps to retest; no fix or current reproduction is confirmed.

## Change summary

Remote - SSH reuses cached connection data across distinct container SSH endpoints sharing a hostname but using different ports.

## Best solution

Remote - SSH should isolate cached connection metadata by endpoint, including the SSH port, so connecting or reloading never selects another container's server. Retest the described two-port setup and implement the cache-key change acknowledged in the thread if the collision persists.
