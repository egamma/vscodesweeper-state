# Issue #11890 — workspaceMount Property Errors When Using Variables

[https://github.com/microsoft/vscode-remote-release/issues/11890](https://github.com/microsoft/vscode-remote-release/issues/11890)

## Summary

Keep open: the reported literal ${devcontainerId} reaching Docker contradicts documented workspaceMount support. The pinned configuration, command, and error suffice to retest; no subsequent fix or resolution is established.

## Change summary

Using ${devcontainerId} in a workspaceMount volume name prevents container creation because the variable reaches Docker unexpanded.

## Best solution

The Dev Containers owner should retest the supplied image-based configuration and ensure workspaceMount substitutes ${devcontainerId} before invoking Docker, preserving a stable volume identifier across rebuilds.
