# Issue #11890 — workspaceMount Property Errors When Using Variables

[https://github.com/microsoft/vscode-remote-release/issues/11890](https://github.com/microsoft/vscode-remote-release/issues/11890)

## Summary

Route to Dev Containers: a fresh independent confirmation narrows the failure to `${devcontainerId}` in `workspaceMount`, where substitution is explicitly documented. The supplied configuration and Docker error make this actionable; no verified fix or same-symptom canonical was found.

## Change summary

Dev Containers passes an unresolved `${devcontainerId}` in the workspace volume name to Docker, preventing container creation.

## Best solution

The Dev Containers owner should ensure `${devcontainerId}` is resolved in the workspace mount passed to Docker, coordinating with devcontainers/cli if the reported substitution-order diagnosis is confirmed. Preserve this product report until the extension delivers the correction; moving the volume to `mounts` is a workaround, not resolution.
