# Issue #11415 — Need "remote.SSH.noProxy" from setting

[https://github.com/microsoft/vscode-remote-release/issues/11415](https://github.com/microsoft/vscode-remote-release/issues/11415)

## Summary

Keep open as a Remote - SSH feature request: documented remote proxy configuration does not establish a setting that generates no_proxy in the remote environment. The related environment issues do not own this specific settings-based capability.

## Change summary

Add a Remote - SSH setting that supplies no_proxy to the remote SSH environment.

## Best solution

The SSH component should decide whether to expose settings-based proxy exclusions and define which remote processes inherit them. Host-side environment configuration is an alternative, but does not provide the requested settings-driven setup.
