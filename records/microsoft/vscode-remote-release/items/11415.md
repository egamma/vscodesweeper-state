[https://github.com/microsoft/vscode-remote-release/issues/11415](https://github.com/microsoft/vscode-remote-release/issues/11415)

## Summary

This is a valid Remote - SSH proxy-configuration gap. The documented host-side environment workaround does not provide the requested settings-driven exclusion list, so the request should remain open and route to the proxy and remote-environment areas.

## Change summary

Add a Remote - SSH setting that exports a proxy-bypass list through `no_proxy` on the remote host.

## Best solution

The SSH component should provide a host-scoped proxy-bypass setting alongside its proxy configuration and propagate it consistently as `NO_PROXY` and `no_proxy` to the remote bootstrap, server, and child processes, with documented precedence.
