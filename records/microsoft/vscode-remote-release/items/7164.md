# Issue #7164 — Misleading error message when project folder is moved and vscode tries to open it

[https://github.com/microsoft/vscode-remote-release/issues/7164](https://github.com/microsoft/vscode-remote-release/issues/7164)

## Summary

The original diagnosis is credible, but this 2022 report has no current-release confirmation. A retest is needed before deciding whether Dev Containers still misattributes a missing working directory to the Docker executable.

## Change summary

Show an accurate missing-project-folder error when reopening a Dev Container workspace whose local folder was moved or renamed.

## Best solution

Dev Containers should distinguish process-spawn ENOENT caused by a missing working directory from a missing Docker executable and identify the unavailable project path in the error.
