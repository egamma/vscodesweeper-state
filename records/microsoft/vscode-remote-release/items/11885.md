# Issue #11885 — The name of the container is more important that the image

[https://github.com/microsoft/vscode-remote-release/issues/11885](https://github.com/microsoft/vscode-remote-release/issues/11885)

## Summary

Route this display-priority request to Dev Containers and Remote Explorer. It remains within the 60-day Backlog Candidates window, and the documented naming features do not establish that container names stay visible ahead of image names.

## Change summary

Show container names as the primary Remote Explorer label so multiple containers sharing an image remain distinguishable in narrow views.

## Best solution

The Dev Containers Remote Explorer should prioritize the container name and show the image as secondary information, preserving container identity when space is limited.
