# Issue #8179 — Version of initializeCommand for devcontainer that happens only on container (re)build?

[https://github.com/microsoft/vscode-remote-release/issues/8179](https://github.com/microsoft/vscode-remote-release/issues/8179)

## Summary

This accepted backlog request remains necessary: the current specification explicitly allows initializeCommand on subsequent starts, with no host-side lifecycle command limited to container creation or rebuild.

## Change summary

Add a host-side command or execution condition that runs only when creating or rebuilding a dev container.

## Best solution

Define the new lifecycle semantics in https://github.com/devcontainers/spec first, then have Dev Containers implement the standardized hook or run condition. Keep this issue as the extension-adoption request; the related reports address documentation or the existing command's frequency rather than providing the missing capability.
