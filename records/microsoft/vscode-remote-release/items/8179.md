# Issue #8179 — Version of initializeCommand for devcontainer that happens only on container (re)build?

[https://github.com/microsoft/vscode-remote-release/issues/8179](https://github.com/microsoft/vscode-remote-release/issues/8179)

## Summary

Keep open: build-only host initialization remains a distinct capability gap. A recent maintainer comment explicitly identifies this issue as its tracker; the documentation correction does not implement the requested behavior.

## Change summary

Allow host-side initialization to run only before container builds or rebuilds, rather than on every window launch.

## Best solution

Dev Containers should provide a spec-aligned build-only host hook or reliable build-context signal while preserving existing initializeCommand behavior. Keep this issue as the product-side tracker rather than folding it into documentation or variable-substitution requests.
