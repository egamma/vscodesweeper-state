# Issue #11507 — Open a new vscode window when chooseing Volume/Inspect popup menu item

[https://github.com/microsoft/vscode-remote-release/issues/11507](https://github.com/microsoft/vscode-remote-release/issues/11507)

## Summary

Keep the volume-inspection request open with Dev Containers: no verified shipped option preserves the project window while opening the volume separately. The older general new-window request is related, but does not explicitly establish ownership of this volume-menu behavior.

## Change summary

Add an option to explore a Docker volume in a dev container in a new VS Code window.

## Best solution

Dev Containers should offer a new-window action for volume exploration so users can inspect a volume alongside their existing project. Coordinate with the general container new-window request without dropping this specific entry point.
