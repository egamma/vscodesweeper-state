# Issue #2578 — open remote file using vscode: URI handler

[https://github.com/microsoft/vscode-remote-release/issues/2578](https://github.com/microsoft/vscode-remote-release/issues/2578)

## Summary

Explicit remote-resource URLs now provide part of the requested capability, but they do not cover ordinary editor links generated by remote applications or the container OSC8 scenario. Neither verified related issue owns this report's full scope.

## Change summary

Allow clickable file-and-line links to open the intended remote resource rather than a same-path local file, including workflows with multiple remote windows.

## Best solution

Document explicit remote-resource URLs for integrations that can identify the destination, and retain the remaining remote-context link-resolution request. A maintainer can transfer the terminal OSC8 portion to microsoft/vscode if investigation establishes core ownership, without losing the broader SSH and container workflows.
