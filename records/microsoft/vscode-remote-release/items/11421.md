# Issue #11421 — Provide Base Devcontainer.json Inheritance

[https://github.com/microsoft/vscode-remote-release/issues/11421](https://github.com/microsoft/vscode-remote-release/issues/11421)

## Summary

Keep open: reusable base-file inheritance and excluding base files from runnable configuration choices remain unfulfilled product requirements. Existing image-metadata reuse and pending specification work do not establish that this team-authored request has shipped.

## Change summary

Allow multiple devcontainer.json configurations to inherit a shared base file that tools recognize as non-runnable.

## Best solution

The containers component should coordinate inheritance semantics with the open specification and CLI proposals, then deliver extension support and define how base-only files are excluded from configuration selection. Keep the product-side discovery requirement tracked here.
