# Issue #11421 — Provide Base Devcontainer.json Inheritance

[https://github.com/microsoft/vscode-remote-release/issues/11421](https://github.com/microsoft/vscode-remote-release/issues/11421)

## Summary

Verified cross-repository duplicate: the open Dev Container specification issue already proposes the same top-level `extends` capability for inheriting and merging a base configuration.

## Change summary

Allow multiple devcontainer configurations to inherit shared settings from a non-executable base JSON file.

## Best solution

Consolidate the proposal on https://github.com/devcontainers/spec/issues/22, where configuration inheritance and merge semantics are owned; the Dev Containers extension should implement the resulting specification.

## Evidence

- **partial existing capability:** The specification supports merging `devcontainer.metadata` from prebuilt images, but that requires an image-building workflow and does not provide the requested inheritance between repository configuration files.
