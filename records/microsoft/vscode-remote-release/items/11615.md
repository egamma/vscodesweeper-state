# Issue #11615 — VS Code remote server is not compatible with Alpine armv7's Musl compat layer

[https://github.com/microsoft/vscode-remote-release/issues/11615](https://github.com/microsoft/vscode-remote-release/issues/11615)

## Summary

Keep open and route to SSH/CLI owners: the supplied logs identify an ARMv7 glibc-compatibility failure before the server starts. General Alpine support announcements do not establish that this architecture-specific CLI failure is resolved.

## Change summary

Remote-SSH cannot install its CLI bootstrap on Alpine 3.23 ARMv7 despite the installed glibc compatibility packages.

## Best solution

SSH/CLI owners should use the supplied QEMU steps to determine whether Alpine's ARMv7 compatibility layer needs upstream changes or a native musl CLI artifact is required. Retain this report until that bootstrap-specific support gap is resolved or explicitly scoped.
