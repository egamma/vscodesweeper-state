# Issue #11615 — VS Code remote server is not compatible with Alpine armv7's Musl compat layer

[https://github.com/microsoft/vscode-remote-release/issues/11615](https://github.com/microsoft/vscode-remote-release/issues/11615)

## Summary

This is a concrete request to support the currently undocumented Alpine ARMv7 and Remote-SSH combination. The supplied logs localize the gap to the downloaded armhf server binary, so it should be routed to the SSH and server owners rather than treated as an unverified bug.

## Change summary

Provide a VS Code Server build or supported compatibility path that runs on ARMv7 Alpine Linux using musl.

## Best solution

The SSH and VS Code Server owners should decide whether to produce a musl-compatible ARMv7 server artifact or explicitly document this architecture combination as unsupported.
