## Summary

The evidence points to Docker Desktop's Windows bind-mount filesystem adapter rather than Dev Containers. Keep this team-authored upstream issue open as the canonical Remote-side reference to the active Docker report.

## Change summary

Windows bind-mounted files intermittently return EIO inside Dev Containers until the host or Docker Desktop is restarted.

## Best solution
