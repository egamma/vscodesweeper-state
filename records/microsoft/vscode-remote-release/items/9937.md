# Issue #9937 — WSL Devcontainer inconsistence between ~/.gitconfig and ~/.config/git/config

[https://github.com/microsoft/vscode-remote-release/issues/9937](https://github.com/microsoft/vscode-remote-release/issues/9937)

## Summary

Verified duplicate of the older, open issue tracking local Windows Git configuration overriding a remote host's XDG configuration. This report adds the WSL2 case of the same copying and precedence defect.

## Change summary

Dev Containers copies Windows Git configuration alongside WSL XDG configuration, giving Windows settings precedence unlike the WSL ~/.gitconfig case.

## Best solution

Consolidate on https://github.com/microsoft/vscode-remote-release/issues/9094 so Dev Containers consistently selects remote Git configuration before falling back to Windows configuration, regardless of its supported file location.
