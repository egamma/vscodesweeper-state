# Issue #9937 — WSL Devcontainer inconsistence between ~/.gitconfig and ~/.config/git/config

[https://github.com/microsoft/vscode-remote-release/issues/9937](https://github.com/microsoft/vscode-remote-release/issues/9937)

## Summary

Verified duplicate: the open canonical issue tracks the same Dev Containers bug where a remote host's XDG Git config is copied alongside, but loses precedence to, the local Windows `.gitconfig`.

## Change summary

Dev Containers should prefer the WSL host's `~/.config/git/config` over the Windows user's `.gitconfig`, as it already does for WSL `~/.gitconfig`.

## Best solution

Consolidate on https://github.com/microsoft/vscode-remote-release/issues/9094 and make Dev Containers treat a remote host's XDG Git config as sufficient to suppress copying the local host config. Carry over this report's confirmation that the defect also occurs when WSL is the remote host.
