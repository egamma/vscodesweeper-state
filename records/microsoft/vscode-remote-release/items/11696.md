# Issue #11696 — Volume mount does not resolve path correctly

[https://github.com/microsoft/vscode-remote-release/issues/11696](https://github.com/microsoft/vscode-remote-release/issues/11696)

## Summary

This matches Docker bind-mount semantics rather than a Dev Containers path-resolution defect: Compose resolves sources on the Docker daemon host, where a workspace cloned into a volume is not available at `/workspace`. Route it as a container-volume environment issue.

## Change summary

Allow Compose services started inside a volume-backed Dev Container to mount individual workspace files into sibling containers.

## Best solution

Use Compose `configs`, bake the files into the images, or share the workspace through a named volume instead of bind-mounting container-only paths. The Containers owner should document this limitation for repositories cloned into volumes.

  > Thanks for the detailed example. If the repository was cloned into a Docker volume, `/workspace` exists inside the Dev Container but not as that path on the Docker daemon host. Compose bind mounts are resolved by the daemon, and Docker's short volume syntax creates a missing source path as a directory, which accounts for the reported result: https://docs.docker.com/engine/storage/bind-mounts/
  > 
  > For these scripts, the available alternatives are baking them into the images, sharing them through a named volume, or using Compose `configs`: https://docs.docker.com/reference/compose-file/configs/

## Evidence

- **Docker bind semantics:** Docker documents that bind-mount sources are resolved on the Docker daemon host, not in the client container: https://docs.docker.com/engine/storage/bind-mounts/
- **Observed directory creation:** Docker also documents that short `--volume` syntax creates a missing source path as a directory, directly explaining why both nonexistent host-side file paths appear as directories.
- **Supported alternative:** Compose configs mount configuration data as files and support a file source: https://docs.docker.com/reference/compose-file/configs/
