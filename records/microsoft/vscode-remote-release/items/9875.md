## Summary

The report has detailed original steps and was later accepted into the Backlog as a probable bug, but the thread has no current-version reproduction or confirmation. A retest is needed before deciding whether the path-conversion defect remains.

## Change summary

Opening an attached-container URI from WSL converts its POSIX directory path to backslashes and opens it as a new file.

## Best solution

The Dev Containers and WSL integration should preserve the URI's POSIX path when forwarding an attached-container request from WSL to the Windows client, so `/server/ui` opens as a directory inside the container.
