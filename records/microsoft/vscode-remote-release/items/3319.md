# Issue #3319 — High CPU usage by vscode-server/typescript

[https://github.com/microsoft/vscode-remote-release/issues/3319](https://github.com/microsoft/vscode-remote-release/issues/3319)

## Summary

The central request remains valid: workspace-scoped extension disabling is available, but it does not provide the requested CPU isolation. Keep this open and route it to the VS Code Server performance owners rather than treating it as container-specific.

## Change summary

Add configurable CPU limits for VS Code Server extension processes so resource-intensive language servers cannot starve a remote host.

## Best solution

The VS Code Server should provide cross-transport resource controls for remote extension processes, such as configurable cgroup v2 CPU limits. Workspace-scoped disabling can remain the workaround when individual language features are unnecessary.
