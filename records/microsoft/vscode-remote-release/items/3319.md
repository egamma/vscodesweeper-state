# Issue #3319 — High CPU usage by vscode-server/typescript

[https://github.com/microsoft/vscode-remote-release/issues/3319](https://github.com/microsoft/vscode-remote-release/issues/3319)

## Summary

Keep the request for configurable remote-process CPU limits open and route it to SSH/server ownership rather than containers. Disabling individual language services is a documented mitigation, but does not deliver the requested CPU budget.

## Change summary

Allow CPU limits for VS Code Server extension processes so they do not monopolize constrained remote hosts.

## Best solution

The SSH/server owners should evaluate an opt-in CPU budget covering extension processes and their children while preserving resources for development commands. Investigate individual language-server and filesystem performance defects separately rather than treating this mixed thread as one confirmed root cause.
