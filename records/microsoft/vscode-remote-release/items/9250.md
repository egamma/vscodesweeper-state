# Issue #9250 — remote tunnel to linux aarch64 with /usr/lib fails

[https://github.com/microsoft/vscode-remote-release/issues/9250](https://github.com/microsoft/vscode-remote-release/issues/9250)

## Summary

The tunnel CLI still hard-codes `/usr/lib64/libstdc++.so.6` for aarch64 and only falls back to `/sbin/ldconfig`, excluding the reported valid `/usr/lib` layout. The failure remains relevant and should be routed to the CLI owner.

## Change summary

Allow the Linux arm64 tunnel CLI prerequisite check to find libstdc++ under `/usr/lib` when `ldconfig` is unavailable.

## Best solution

Update the public VS Code CLI prerequisite discovery to recognize conventional aarch64 library locations including `/usr/lib` and multiarch directories, rather than requiring `/usr/lib64` or `/sbin/ldconfig`.
