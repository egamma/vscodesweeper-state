## Summary

Keep open as the active tracker: multiple users report that the Dev Containers volume-bootstrap path omits proxy configuration, and a maintainer redirected the older matching issue here for follow-up.

## Change summary

Propagate proxy configuration when building and running the temporary bootstrap container used by Clone Repository in Container Volume.

## Best solution

Dev Containers should pass applicable proxy settings into the volume-bootstrap build and container without exposing unrelated Docker credentials. The component owner should use the requested current Dev Containers log to confirm which bootstrap stage still drops the configuration.
