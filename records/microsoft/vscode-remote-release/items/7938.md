# Issue #7938 — 'Clone Repository in Container Volume' should use partial clones

[https://github.com/microsoft/vscode-remote-release/issues/7938](https://github.com/microsoft/vscode-remote-release/issues/7938)

## Summary

This remains a valid, accepted Dev Containers performance request. Current documentation exposes the clone-in-volume workflow but no partial-clone option, and no broader canonical issue was found.

## Change summary

Use Git partial cloning when cloning large repositories into container volumes to reduce initial transfer and storage costs.

## Best solution

The Dev Containers extension should use or offer `git clone --filter=blob:none` for the clone-in-volume workflow, with compatibility handling for servers that do not support partial clones.
