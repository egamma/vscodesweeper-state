# Issue #7938 — 'Clone Repository in Container Volume' should use partial clones

[https://github.com/microsoft/vscode-remote-release/issues/7938](https://github.com/microsoft/vscode-remote-release/issues/7938)

## Summary

Keep open: documented volume-cloning workflows do not establish support for blobless partial clones, and the canonical search found no verified open issue owning this request.

## Change summary

Use git clone --filter=blob:none when cloning large repositories into a container volume to reduce initial download time.

## Best solution

The Dev Containers owner should evaluate blobless partial cloning for the built-in volume-clone command, including Git-server compatibility and subsequent on-demand blob downloads. Manual cloning into a named volume is a workaround, not coverage of the requested command behavior.
