[https://github.com/microsoft/vscode-remote-release/issues/4271](https://github.com/microsoft/vscode-remote-release/issues/4271)

## Summary

Keep open: documented environment-variable forwarding supports the reporter's workaround, but does not automatically expose the Windows host's IANA timezone. No verified canonical or shipped implementation was found.

## Change summary

Expose the Windows host's IANA timezone automatically for use in development-container configuration.

The Dev Containers component should provide an opt-in way to reference the host's IANA timezone without requiring a manually maintained Windows environment variable. Coordinate any standardized substitution variable with devcontainers/spec while retaining this issue for extension implementation.
