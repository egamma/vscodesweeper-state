# Issue #10221 — Rename "Add New SSH Host..."

[https://github.com/microsoft/vscode-remote-release/issues/10221](https://github.com/microsoft/vscode-remote-release/issues/10221)

## Summary

A genuine Remote - SSH usability gap remains: the picker supports direct hostname entry, but its presentation leads users toward a command that modifies their SSH config. The issue is already classified as polish and should be routed to the SSH/config owners.

## Change summary

Clarify the Connect to Host picker so direct hostname entry is discoverable and adding a host explicitly communicates that it writes to an SSH config file.

## Best solution

Remote - SSH should distinguish direct connection from config mutation in the picker, such as an explicit connect-by-hostname affordance and wording like “Add New Host to SSH Config File.”
