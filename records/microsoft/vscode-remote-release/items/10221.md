# Issue #10221 — Rename "Add New SSH Host..."

[https://github.com/microsoft/vscode-remote-release/issues/10221](https://github.com/microsoft/vscode-remote-release/issues/10221)

## Summary

Retain this SSH usability improvement and route it to the SSH owner. Direct hostname entry already works, but that does not address the reported confusion between connecting and adding an SSH config entry; a maintainer acknowledged the scenario and discussed improvements.

## Change summary

Clearly distinguish connecting to a typed hostname from adding a persistent SSH config entry in the Remote-SSH host picker.

## Best solution

The Remote - SSH picker should explicitly advertise direct hostname entry and identify the add-host action as modifying an SSH config file. Preserve the existing connection functionality while making the distinction discoverable for users relying on wildcard host configuration.
