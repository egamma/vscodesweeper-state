# Issue #5782 — Add a delete button for folder history in SSH explorer

[https://github.com/microsoft/vscode-remote-release/issues/5782](https://github.com/microsoft/vscode-remote-release/issues/5782)

## Summary

The requested folder cleanup is already available through “Remove from Recent List,” while deleting SSH hosts is intentionally unsupported because the explorer mirrors SSH configuration files.

## Change summary

Add controls to remove remembered folders and SSH hosts from the SSH Remote Explorer.

## Best solution

Keep the existing folder context-menu command and continue managing hosts through the SSH configuration file, avoiding partial or confusing edits from Remote Explorer.
