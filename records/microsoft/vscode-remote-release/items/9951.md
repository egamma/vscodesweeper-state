# Issue #9951 — Add tasks support to devcontainer.json

[https://github.com/microsoft/vscode-remote-release/issues/9951](https://github.com/microsoft/vscode-remote-release/issues/9951)

## Summary

Keep open as an accepted Containers backlog request. The current settings-based behavior is explicitly described by maintainers as an unofficial implementation detail and does not provide complete task support.

## Change summary

Add an officially supported devcontainer.json section for container-specific VS Code tasks that can be shared across workspaces and customized separately from repository defaults.

## Best solution

The Dev Containers extension should support a dedicated tasks section, validate it in the VS Code customization schema, and materialize a remote tasks file as maintainers proposed. This should preserve task-provider types such as npm and define how container tasks combine with workspace tasks.

## Vision fit

- **Fit:** aligned
- **Reason:** Official container-scoped tasks improve Dev Container capability depth and bring a standard VS Code workflow into remote environments without relying on an unsupported settings detail.
- **Evidence:** The Remote Development promise is to let users open a folder in a container and use VS Code's full feature set; first-class task configuration advances that parity.
