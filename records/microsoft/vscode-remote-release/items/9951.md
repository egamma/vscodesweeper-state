# Issue #9951 — Add tasks support to devcontainer.json

[https://github.com/microsoft/vscode-remote-release/issues/9951](https://github.com/microsoft/vscode-remote-release/issues/9951)

## Summary

Keep open: tasks inside settings remain an explicitly unofficial workaround, not supported dev-container task configuration. A maintainer accepted the shared-across-workspaces use case and recommended a dedicated tasks section/file, so a decline close would contradict that direction.

## Change summary

Support repository-tracked dev-container task defaults shared across workspaces while allowing private workspace customizations.

## Best solution

The Dev Containers owner should define and document supported container-level task configuration, following the recommended separate section/file and specifying how it combines with workspace tasks. Preserve or provide migration for the unofficial settings-based configuration that existing users rely on.
