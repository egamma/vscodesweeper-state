# Issue #7258 — Dev container CLI error messages aren't very helpful

[https://github.com/microsoft/vscode-remote-release/issues/7258](https://github.com/microsoft/vscode-remote-release/issues/7258)

## Summary

Keep open: this team-authored bug was reproduced by two maintainers, and no verified duplicate or public fixing commit supports a factual close. The reproduction is old, but team-authored items are protected from an information-based close.

## Change summary

Preserve Docker's actionable error details when a Dev Container CLI command fails instead of returning only a generic container-build error.

## Best solution

The Dev Container CLI should include Docker stderr, such as daemon connectivity or permission errors, in its structured failure output. Because this behavior belongs to the public reference CLI, the implementation should be tracked with https://github.com/devcontainers/cli.
