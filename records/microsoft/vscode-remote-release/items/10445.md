# Issue #10445 — [Remote-SSH Bug]: AFS - 2nd connection always fails - Failed to parse remote port from server output

[https://github.com/microsoft/vscode-remote-release/issues/10445](https://github.com/microsoft/vscode-remote-release/issues/10445)

## Summary

Keep open for AFS-compatible port discovery in Remote - SSH. A later report corroborates the failure on 0.116.1, but current-release behavior remains unverified; the supplied reconnect steps and diagnostic logs suffice to retest.

## Change summary

Remote - SSH fails on subsequent connections when port discovery reads a still-open CLI log on an AFS home filesystem.

## Best solution

The SSH owner should retest the exec-server bootstrap on AFS and make port discovery independent of a continuously open log, for example through a separate closed status file. Retain this established diagnostic thread; relocating the installation or disabling exec-server mode mitigates rather than fixes the reported path.
