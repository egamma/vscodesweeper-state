## Summary

The requested standalone `devcontainer open` capability remains absent, but the open devcontainers/cli issue tracks the same feature and its editor-association design. Consolidating there avoids maintaining duplicate requests across the old and current CLI trackers.

## Change summary

Add an `open` command to the independently installed dev container CLI so scripts can launch a project directly in its VS Code dev container.
