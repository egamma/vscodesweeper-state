# Issue #2099 — Information about non-compatibility with OSS versions

[https://github.com/microsoft/vscode-remote-release/issues/2099](https://github.com/microsoft/vscode-remote-release/issues/2099)

## Summary

The documentation-discoverability gap remains: the README and Marketplace description link to licensing information but do not prominently state that Code - OSS distributions are unsupported. Route this shared documentation improvement to the remote component.

## Change summary

Add an explicit Code - OSS compatibility notice and a direct FAQ link to the README and Marketplace descriptions.

## Best solution

The remote component owners should add a concise supported-client notice to the README and Marketplace descriptions, linking directly to the Remote Development FAQ. This clarifies the existing restriction without requesting support for additional clients.
