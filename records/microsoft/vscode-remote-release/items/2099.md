# Issue #2099 — Information about non-compatibility with OSS versions

[https://github.com/microsoft/vscode-remote-release/issues/2099](https://github.com/microsoft/vscode-remote-release/issues/2099)

## Summary

The compatibility limitation remains insufficiently disclosed: current documentation explains that Remote Development is proprietary but does not plainly warn that unofficial OSS builds are unsupported. Keep this documentation request open and route it to the shared Remote surface.

## Change summary

Add a prominent README, Marketplace, and FAQ notice that Remote Development requires Microsoft's VS Code or VS Code Insiders distribution.

## Best solution

The Remote Development README and Marketplace description should explicitly state the supported client distributions and link to the FAQ, Code - OSS differences, and applicable license information.
