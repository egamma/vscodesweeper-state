# Issue #11299 — ssh-agent forwarding from WSL to devcontainer does not work after sleep

[https://github.com/microsoft/vscode-remote-release/issues/11299](https://github.com/microsoft/vscode-remote-release/issues/11299)

## Summary

Keep open as a confirmed Dev Containers bug. The requested log was supplied, and two additional affected users confirmed that Windows sleep or hibernation breaks the forwarded SSH agent until the window is reloaded.

## Change summary

Restore SSH-agent forwarding from WSL into a dev container automatically after Windows resumes from sleep or hibernation.

## Best solution

The Dev Containers connection owner should ensure the WSL-to-container SSH bridge is recreated after resume without requiring Developer: Reload Window. This may be a WSL-specific regression of the reconnect recovery previously delivered for the related failure in https://github.com/microsoft/vscode-remote-release/issues/6904.
