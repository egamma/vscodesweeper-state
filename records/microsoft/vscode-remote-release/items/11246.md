# Issue #11246 — Various SSH timeout usability issues

[https://github.com/microsoft/vscode-remote-release/issues/11246](https://github.com/microsoft/vscode-remote-release/issues/11246)

## Summary

Keep open for SSH timeout recovery usability: a configurable timeout already exists, but it does not address the reported inability to edit settings from the failed-connection screen. The older timeout-action decision covers only part of this report.

## Change summary

Make it easier to increase the SSH connection timeout and retry without closing the remote window first.

## Best solution

The SSH component should provide a usable recovery path from a timeout, including access to local timeout settings while disconnected. Reassess a temporary higher-timeout retry action separately from repairing the existing Open Settings action.

This covers timeout configuration, not access to that configuration from the failed-connection screen.
