# Issue #8620 — DevContainers: cannot rebuild and reopen container ; devcontainer.json not found when file is located deeper than 1 subfolder (.devcontainer/myfolder1/myfolder2/devcontainer.json)

[https://github.com/microsoft/vscode-remote-release/issues/8620](https://github.com/microsoft/vscode-remote-release/issues/8620)

## Summary

Keep open: the current Dev Container specification intentionally limits configuration discovery to one subfolder level, so deeper project/environment hierarchies remain an accepted Backlog capability gap.

## Change summary

Allow Dev Containers to discover, select, rebuild, and reopen configurations located more than one directory below `.devcontainer`.

## Best solution

Coordinate an expanded configuration-location rule through https://github.com/devcontainers/spec, then have the Dev Containers extension adopt it while preserving deterministic selection among multiple configurations.

- **Reason:** Supporting structured monorepos advances dev-container capability depth and scalability, provided the discovery behavior is standardized rather than implemented as an extension-specific spec fork.
