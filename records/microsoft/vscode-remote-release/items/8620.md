# Issue #8620 — DevContainers: cannot rebuild and reopen container ; devcontainer.json not found when file is located deeper than 1 subfolder (.devcontainer/myfolder1/myfolder2/devcontainer.json)

[https://github.com/microsoft/vscode-remote-release/issues/8620](https://github.com/microsoft/vscode-remote-release/issues/8620)

## Summary

Keep this accepted feature request open: documented configuration discovery supports only one subfolder level, not the requested project/environment hierarchy. The related open reports concern different workflows and do not own this remaining capability.

## Change summary

Discover and reopen dev containers configured at paths such as .devcontainer/project_a/dev/devcontainer.json.

## Best solution

The Dev Containers component should support selecting deeper configuration paths and preserve that selection through reopen and rebuild. Coordinate discovery conventions with the Dev Container specification while retaining this issue for extension-side implementation.
