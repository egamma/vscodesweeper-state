# Issue #2857 — Listing SSH targets is slow with big config/many hosts

[https://github.com/microsoft/vscode-remote-release/issues/2857](https://github.com/microsoft/vscode-remote-release/issues/2857)

## Summary

Keep this SSH performance report open: the supplied large-config reproduction is sufficient to retest, but current-release behavior is unverified. The 2025 report adds a Remote - Tunnels interaction, not evidence of a shipped fix.

## Change summary

Listing thousands of SSH targets consumes excessive CPU and makes the extension host unresponsive.

## Best solution

Remote - SSH should enumerate large configurations, including included files, without blocking extension commands. Investigate repeated parsing and compare Remote Explorer performance with Remote - Tunnels enabled and disabled before attributing all reports to one cause.
