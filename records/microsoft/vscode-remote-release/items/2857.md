# Issue #2857 — Listing SSH targets is slow with big config/many hosts

[https://github.com/microsoft/vscode-remote-release/issues/2857](https://github.com/microsoft/vscode-remote-release/issues/2857)

## Summary

This remains the canonical report for severe Remote - SSH target-list performance with very large configurations. Multiple independent users reproduced high CPU or an unresponsive extension, including a 2024 confirmation, and no shipped fix is established.

## Change summary

Opening Remote Explorer repeatedly parses large SSH configurations, causing multi-second delays, high CPU usage, or an unresponsive extension host.

## Best solution

Remote - SSH should avoid redundant parsing and rebuilding of the target list, retaining usable performance for large configurations and Include files. The owner should also investigate the reported additional overhead when Remote - Tunnels is installed.
