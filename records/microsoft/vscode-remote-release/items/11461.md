# Issue #11461 — Remote-SSH: Connectivity issues with WALLIX Bastion requiring MFA (Browser OTP) + Interactive Password on Windows

[https://github.com/microsoft/vscode-remote-release/issues/11461](https://github.com/microsoft/vscode-remote-release/issues/11461)

## Summary

The documented interactive-authentication settings do not handle this WALLIX browser-MFA sequence as expected, but the report lacks a current Remote-SSH log and uses outdated versions. A current retest and command-level comparison are needed to distinguish an extension defect from a bastion constraint.

## Change summary

Remote-SSH cannot complete its server bootstrap through a WALLIX bastion requiring browser OTP, an Enter keypress, and an interactive password on Windows.

## Best solution

The SSH owner should determine from a current Remote-SSH log whether the WALLIX flow consumes or rejects the stdin needed for the install script. If reproducible, Remote-SSH should preserve interactive authentication while delivering the bootstrap command, or report that the bastion flow is unsupported instead of hanging.
