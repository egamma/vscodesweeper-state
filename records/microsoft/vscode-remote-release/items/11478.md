# Issue #11478 — Experimental worktree support doesn't work when workspaceMount is customized

[https://github.com/microsoft/vscode-remote-release/issues/11478](https://github.com/microsoft/vscode-remote-release/issues/11478)

## Summary

Keep open as a Dev Containers bug: the supplied worktree layout and configuration suffice to retest the missing automatic Git mount. Subsequent discussion establishes a CLI counterpart and manual workaround, but no confirmed extension fix or qualifying canonical.

## Change summary

Experimental worktree support fails to mount the main repository's Git directory when workspaceMount is customized.

## Best solution

Dev Containers should preserve custom workspace mounts while automatically mounting the Git common directory at the location required by the worktree's relative pointer. Coordinate with https://github.com/devcontainers/cli/issues/1243 and retain this issue until the extension delivers that behavior.
