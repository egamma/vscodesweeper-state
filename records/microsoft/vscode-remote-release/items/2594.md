# Issue #2594 — Support for working with Amazon ECS clusters (especially Fargate)

[https://github.com/microsoft/vscode-remote-release/issues/2594](https://github.com/microsoft/vscode-remote-release/issues/2594)

## Summary

A real Dev Containers capability gap remains: current remote-host support requires an accessible Docker Engine and does not provision or attach to ECS Fargate tasks. No broader open canonical was found, so this should remain open for a product-scope decision.

## Change summary

Allow Dev Containers to provision and use remote development containers on Amazon ECS, particularly serverless Fargate tasks.

## Best solution

The containers owner should decide on a supported ECS/Fargate provisioning and attachment model, potentially coordinating with the AWS Toolkit while preserving the normal Dev Containers workspace and server lifecycle. The retired Docker ECS context integration is no longer a viable implementation path.

## Evidence
