# Issue #7245 — Add repositoryConfigurationPath variable

[https://github.com/microsoft/vscode-remote-release/issues/7245](https://github.com/microsoft/vscode-remote-release/issues/7245)

## Summary

Keep open: the documented variables do not expose the selected external configuration directory for initializeCommand or mounts, and no verified canonical owns this request. The existing containers routing is correct.

## Change summary

Expose the selected repository configuration directory as a substitution variable so devcontainer.json can reference adjacent scripts and mount sources.

## Best solution

The Dev Containers component should provide a configuration-directory substitution usable in initializeCommand and mounts, including configurations selected through repositoryConfigurationPaths. Coordinate the variable semantics with the Dev Container specification while retaining the extension implementation request here.
