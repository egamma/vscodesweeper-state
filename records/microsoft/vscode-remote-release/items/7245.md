# Issue #7245 — Add repositoryConfigurationPath variable

[https://github.com/microsoft/vscode-remote-release/issues/7245](https://github.com/microsoft/vscode-remote-release/issues/7245)

## Summary

A real capability gap remains for externally stored repository configurations: current predefined variables identify the workspace, not the selected configuration directory. The issue is already correctly classified and routed to Dev Containers.

## Change summary

Expose the selected external repository-configuration directory as a variable usable in devcontainer.json properties such as initializeCommand and mounts.

## Best solution

The Dev Containers component should expose the external configuration's host directory through a predefined variable, coordinating with the dev container specification if this is intended to be portable across supporting tools.

## Evidence

- **current variable surface:** The current specification at https://containers.dev/implementors/json_reference/#variables lists localWorkspaceFolder, containerWorkspaceFolder, their basenames, environment variables, and devcontainerId, but no variable identifying the devcontainer.json configuration directory.
- **existing capability does not cover request:** The specification documents initializeCommand as running wherever the source workspace is located, while mounts can reference only predefined variables; therefore localWorkspaceFolder cannot locate an external configuration selected through remote.containers.repositoryConfigurationPaths.
