# Issue #3937 — Indistinguishable folder name in Windows "Recent Workspaces"

[https://github.com/microsoft/vscode-remote-release/issues/3937](https://github.com/microsoft/vscode-remote-release/issues/3937)

## Summary

Keep open as the canonical containers issue: multiple users, most recently in July 2025, report that WSL-originated Dev Containers still receive inconsistent or indistinguishable Recent Workspaces names.

## Change summary

Give Dev Container entries in Windows Recent Workspaces stable, descriptive names that distinguish projects opened through WSL.

## Best solution

The Dev Containers component should consistently supply Windows recent-item metadata using the originating project, devcontainer name, or another stable descriptive identifier rather than the common workspace path or remote-authority hash.
