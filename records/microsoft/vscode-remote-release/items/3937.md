# Issue #3937 — Indistinguishable folder name in Windows "Recent Workspaces"

[https://github.com/microsoft/vscode-remote-release/issues/3937](https://github.com/microsoft/vscode-remote-release/issues/3937)

## Summary

This remains the canonical report for ambiguous Dev Container entries opened through WSL. Multiple later confirmations, including one from July 2025, show that recent-item names are still inconsistent.

## Change summary

Windows Recent Workspaces cannot distinguish multiple WSL-hosted Dev Containers when they share the same configured workspace-folder basename.

## Best solution

The Containers component should derive a stable, distinguishing recent-item label from the originating WSL project or Dev Container name instead of showing only the shared workspace-folder basename or encoded authority.
