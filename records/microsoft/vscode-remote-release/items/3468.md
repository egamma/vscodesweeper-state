# Issue #3468 — Improve architecture unsupported message to have link to docs with information on device examples

[https://github.com/microsoft/vscode-remote-release/issues/3468](https://github.com/microsoft/vscode-remote-release/issues/3468)

## Summary

A meaningful diagnosability gap remains: current documentation identifies supported ARM systems, but the public evidence does not show that the SSH error reports the detected architecture, links to those requirements, or identifies common unsupported devices such as the Raspberry Pi Zero.

## Change summary

Make Remote - SSH's unsupported-architecture error report the detected architecture and link to documentation containing recognizable device examples.

## Best solution

The SSH connection diagnostic should name the detected architecture and link to the Linux prerequisites page; that page should explicitly distinguish unsupported ARMv6 devices such as Raspberry Pi 1/Zero from supported ARMv7 systems.
