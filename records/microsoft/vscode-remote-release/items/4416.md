# Issue #4416 — vscode install hangs at wget step if target filesystem cannot flock ~/.wget-hsts

[https://github.com/microsoft/vscode-remote-release/issues/4416](https://github.com/microsoft/vscode-remote-release/issues/4416)

## Summary

The original workaround caused a separate wget 1.14 regression that was resolved in Remote - SSH 0.65.3, but the underlying HSTS-file lock hang was reproduced again on 0.114.2. The issue remains a valid, correctly routed SSH installer bug.

## Change summary

Prevent Remote - SSH server installation from hanging when wget attempts to lock its HSTS state file on an NFS-backed home directory.

## Best solution

Remote - SSH should download the server without accessing persistent wget HSTS state while remaining compatible with wget versions that lack `--no-hsts`; capability detection or an isolated HSTS-file location should avoid both known failure modes.
