[https://github.com/microsoft/vscode-remote-release/issues/11032](https://github.com/microsoft/vscode-remote-release/issues/11032)

## Summary

Keep open as an upstream proxy-inheritance problem affecting Dev Containers' Podman bootstrap workflow. Explicitly configuring the BuildKit builder works, but no supported integration or shipped resolution is established, and the reporter still reported blockage in September 2026.

## Change summary

Feature-enabled dev containers fail when the containerized BuildKit builder cannot reach Docker Hub through the required proxy.

## Best solution

Track the Podman/BuildKit proxy behavior upstream while the containers owner establishes a supported way to configure the bootstrap workflow's builder environment. Carry forward the demonstrated proxy-enabled builder workaround without requiring users to patch the extension's bootstrap Dockerfile.
