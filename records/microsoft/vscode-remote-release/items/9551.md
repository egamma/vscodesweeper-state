# Issue #9551 — Remote-SSH: bind [::ffff:127.0.0.1]:58206: Can't assign requested address [ipv6]

[https://github.com/microsoft/vscode-remote-release/issues/9551](https://github.com/microsoft/vscode-remote-release/issues/9551)

## Summary

The logs and a second report identify an IPv6-specific Remote-SSH forwarding failure, but the latest confirmation is from January 2025 and does not identify the Remote-SSH version. A current-version retest is needed before deciding whether the defect remains.

## Change summary

Remote-SSH fails to establish local forwarding on macOS when the host's SSH configuration specifies `AddressFamily inet6`, because it requests an IPv4 loopback bind.

## Best solution

Remote-SSH should select a local forwarding address compatible with `AddressFamily inet6` rather than generating an incompatible `-L 127.0.0.1:...` command; first confirm the behavior and capture a current Remote-SSH log.
