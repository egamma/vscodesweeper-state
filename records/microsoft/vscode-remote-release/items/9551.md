# Issue #9551 — Remote-SSH: bind [::ffff:127.0.0.1]:58206: Can't assign requested address [ipv6]

[https://github.com/microsoft/vscode-remote-release/issues/9551](https://github.com/microsoft/vscode-remote-release/issues/9551)

## Summary

Keep open: an independent user confirmed the same AddressFamily inet6 forwarding failure, and enabling useExecServer did not help. The confirmations are historical, but no current fix or open canonical was established.

## Change summary

Remote - SSH fails to establish local forwarding when AddressFamily inet6 conflicts with its IPv4 loopback binding and connection addresses.

## Best solution

The SSH component should retest the supplied configuration and make local forwarding bindings and client connections compatible with IPv6-only address-family selection, including socket-listening and exec-server paths. Removing AddressFamily is a workaround, not a fix for users who require IPv6.
