# Issue #10946 — Devcontainer not pulling branch from github URL

[https://github.com/microsoft/vscode-remote-release/issues/10946](https://github.com/microsoft/vscode-remote-release/issues/10946)

## Summary

Keep open as an accepted Backlog feature request: the existing repository-level volume reuse prevents isolated branch or PR environments, and the request exceeded the community-upvote threshold.

## Change summary

Allow branch and PR URLs for the same repository to use separate container volumes instead of reopening the repository's existing volume.

## Best solution

Dev Containers should offer a setting that keys repository-container volumes by branch or PR while preserving repository-level reuse as the default for users who prefer it.
