# Issue #10946 — Devcontainer not pulling branch from github URL

[https://github.com/microsoft/vscode-remote-release/issues/10946](https://github.com/microsoft/vscode-remote-release/issues/10946)

## Summary

Keep open for optional, independent branch/PR environments when a repository volume already exists. Maintainers accepted this direction; the older branch-selection request does not own the same observable volume-reuse behavior.

## Change summary

Allow cloning another branch or PR into an independent dev container without reopening or modifying the repository's existing environment.

## Best solution

The Dev Containers extension should offer the maintainer-suggested opt-in setting for separate branch/PR volumes and containers, preserving existing environments and ensuring displayed configuration matches the checked-out files.
