# Issue #10028 — Cannot connect multiple VS code windows to single docker container, despite menu options available

[https://github.com/microsoft/vscode-remote-release/issues/10028](https://github.com/microsoft/vscode-remote-release/issues/10028)

## Summary

Keep open: attaching another window still restores the remembered folder and focuses its existing window rather than enabling a different-folder workflow. A maintainer proposed an empty-window setting; the documented configuration and reported workarounds do not fully cover that request.

## Change summary

Allow attaching a second VS Code window to an existing container without reopening the folder already active in another window.

## Best solution

Dev Containers should offer an option to attach into an empty window without restoring the remembered folder, making another folder accessible without pre-populating Remote Explorer history. Preserve remembered-folder behavior for users who prefer it.
