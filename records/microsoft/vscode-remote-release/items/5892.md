# Issue #5892 — devcontainer CLI support for opening workspace files

[https://github.com/microsoft/vscode-remote-release/issues/5892](https://github.com/microsoft/vscode-remote-release/issues/5892)

## Summary

Keep open: this team-authored Backlog request remains distinct from the broader default-workspace request, and no public evidence proves it was implemented. It is already routed correctly to Dev Containers.

## Change summary

Make `devcontainer open <file.code-workspace>` open that workspace inside the container instead of reducing the target to its containing directory.

## Best solution

The Dev Containers extension's `devcontainer open` command should preserve a `.code-workspace` target through container resolution and open that workspace remotely, matching the corresponding `code` CLI behavior.
