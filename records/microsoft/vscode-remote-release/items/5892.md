# Issue #5892 — devcontainer CLI support for opening workspace files

[https://github.com/microsoft/vscode-remote-release/issues/5892](https://github.com/microsoft/vscode-remote-release/issues/5892)

## Summary

Keep open: no verified shipped capability honors the workspace-file argument to devcontainer open. The related default-workspace request does not establish ownership of this explicit CLI behavior, and this team-authored request should remain tracked.

## Change summary

Make devcontainer open myworkspace.code-workspace open the specified workspace inside the container instead of its containing directory.

## Best solution

The Dev Containers extension's CLI integration should preserve the explicitly requested workspace file when opening the container, including its tasks and launch configuration. Coordinate with the default-workspace work without treating a configuration-based default as a substitute for the CLI argument.
