# Issue #11135 — Using enableRemoteCommand and showLoginTerminal and useLocalServer=false does not work

[https://github.com/microsoft/vscode-remote-release/issues/11135](https://github.com/microsoft/vscode-remote-release/issues/11135)

## Summary

This is a specific instance of the open RemoteCommand compatibility work in issue 690: RemoteCommand requires the local-server path, while this smartcard flow requires an interactive login terminal.

## Change summary

Allow Remote - SSH to accept an interactive smartcard PIN while also honoring the host's configured RemoteCommand.

## Best solution

Consolidate this smartcard authentication case into https://github.com/microsoft/vscode-remote-release/issues/690 and make RemoteCommand compatible with authentication flows requiring interactive terminal input.
