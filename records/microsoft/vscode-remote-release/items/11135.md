# Issue #11135 — Using enableRemoteCommand and showLoginTerminal and useLocalServer=false does not work

[https://github.com/microsoft/vscode-remote-release/issues/11135](https://github.com/microsoft/vscode-remote-release/issues/11135)

## Summary

Keep open as a Remote - SSH capability gap: the reporter needs interactive smartcard PIN entry and RemoteCommand together, while the published RemoteCommand implementation requires local-server mode. Neither a shipped solution nor a canonical covering this combined requirement was verified.

## Change summary

Allow interactive smartcard authentication and the configured SSH RemoteCommand to work in the same Remote - SSH connection.

## Best solution

The SSH component should support RemoteCommand alongside terminal-mode authentication, or provide working interactive smartcard PIN entry in local-server mode. Address the remotePlatform interaction separately rather than assuming that removing its entry solves the authentication requirement.
