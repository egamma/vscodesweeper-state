# Issue #4537 — Should the post-create terminal close automatically if it exited cleanly

[https://github.com/microsoft/vscode-remote-release/issues/4537](https://github.com/microsoft/vscode-remote-release/issues/4537)

## Summary

Keep open: this team-authored Backlog request remains the canonical issue for optionally closing or suppressing successful Dev Container lifecycle terminals, with continued community demand and no documented setting that covers it.

## Change summary

Automatically close, or optionally suppress, the lifecycle-command terminal when commands finish successfully while preserving failure output.

## Best solution

The Dev Containers extension should provide an opt-in presentation setting that closes or hides lifecycle-command terminals after a zero exit while keeping failed-command output visible.
