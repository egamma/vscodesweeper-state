# Issue #11751 — Remote-SSH 0.124.0 remote child processes do not reliably inherit lowercase proxy variables

[https://github.com/microsoft/vscode-remote-release/issues/11751](https://github.com/microsoft/vscode-remote-release/issues/11751)

## Summary

This is a detailed but currently single-user report of a possible Remote-SSH 0.124.0 environment regression. The workaround is compelling, but the thread does not yet establish whether lowercase variables are dropped or individual network clients require uppercase names, so a current-version retest is needed.

## Change summary

Remote server and extension processes become slow or lose outbound connectivity when the remote environment defines only lowercase proxy variables.

## Best solution

The Remote-SSH owner should compare the environments inherited by the server, Exec Server, extension host, and tasks when only lowercase proxy variables are exported. If inheritance is intact, the supported proxy-variable casing should be documented clearly; otherwise the 0.124.0 regression should be corrected across launch paths.
