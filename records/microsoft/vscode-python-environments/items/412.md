[https://github.com/microsoft/vscode-python-environments/issues/412](https://github.com/microsoft/vscode-python-environments/issues/412)

## Summary

This accepted feature request remains necessary: the current venv creation flow asks users to choose from every available Python interpreter before inspecting workspace package metadata. Its team-authored and `needs PR` status requires keeping it open.

## Change summary

Use a project's `pyproject.toml` `requires-python` constraint to guide Python selection during environment creation.

## Best solution

Read the selected project's `requires-python` metadata before interpreter selection, then filter or clearly annotate incompatible Python versions while handling unsupported constraints safely in the venv creation flow.
