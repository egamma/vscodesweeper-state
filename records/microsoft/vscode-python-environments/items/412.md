# Issue #412 — feature request: supports `requires-python` in "create environment.." flow

[https://github.com/microsoft/vscode-python-environments/issues/412](https://github.com/microsoft/vscode-python-environments/issues/412)

## Summary

Keep this accepted, team-authored request open: the current venv creation wizard still selects Python before examining pyproject.toml dependencies and does not use the project's requires-python constraint. The related PEP 723 request concerns inline script metadata, not the same observable workflow.

## Change summary

Use pyproject.toml's requires-python constraint to guide Python-version selection during environment creation.

## Best solution

Make the built-in creation flow aware of the chosen project's Python requirement before interpreter selection. The maintainer should settle whether incompatible interpreters are excluded or explained, and what users see when no compatible interpreter is installed.
