# Issue #187 — Auto create environments for `.py` files and have inline metadata create custom transient environments.

[https://github.com/microsoft/vscode-python-environments/issues/187](https://github.com/microsoft/vscode-python-environments/issues/187)

## Summary

Keep open: this team-authored feature request is accepted for a spike, and the central automatic workflow remains incomplete. Current main can build cached PEP 723 environments behind an internal flag, but opening a matching `.py` file only records telemetry and does not create or select an environment.

## Change summary

Automatically create environments for Python files and materialize custom transient environments from PEP 723 inline metadata.

## Best solution

Complete the accepted spike by settling consent, cache lifetime, and environment-selection semantics, then connect PEP 723 detection to the inline-script environment manager so an eligible script can acquire and use its metadata-derived environment. Coordinate with microsoft/vscode-python where Run/F5 must honor that per-script environment.
