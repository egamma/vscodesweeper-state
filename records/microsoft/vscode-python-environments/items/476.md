# Issue #476 — Environment Manager viewlet - no visual  indicatior on the currently selected environment.

[https://github.com/microsoft/vscode-python-environments/issues/476](https://github.com/microsoft/vscode-python-environments/issues/476)

## Summary

Keep this team-authored UX request open: current main provides temporary selection feedback and selection tooltips, but not a persistent visual indication of the selected environment. The maintainer discussion calls for a UX decision, and no qualifying duplicate or explicitly linked fix was established.

## Change summary

Clearly distinguish currently selected environments from the action for selecting an environment in the Environment Managers view.

## Best solution

Agree on a persistent, scope-aware selection indicator in the Environment Managers view that distinguishes global selection from project assignments. Preserve temporary action feedback without presenting it as the environment's lasting selection state.

- **Fit:** aligned
- **Reason:** Making environment selection visible supports the extension's Python Projects and environment-switching workflows.
