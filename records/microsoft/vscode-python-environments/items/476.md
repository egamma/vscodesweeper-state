# Issue #476 — Environment Manager viewlet - no visual  indicatior on the currently selected environment.

[https://github.com/microsoft/vscode-python-environments/issues/476](https://github.com/microsoft/vscode-python-environments/issues/476)

## Summary

The durable selection indicator remains a real UX gap on current main. Route this team-authored request to the environment area for the proposed UX discussion.

## Change summary

Show a persistent visual distinction between the currently selected environment and other environments in the Environment Managers view.

## Best solution

Choose a persistent selection treatment in UX review, then represent active selection directly on `PythonEnvTreeItem` rather than through temporary command feedback. It should distinguish global and project selection and remain correct after reload or selection changes.
