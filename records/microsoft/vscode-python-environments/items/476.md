# Issue #476 — Environment Manager viewlet - no visual  indicatior on the currently selected environment.

[https://github.com/microsoft/vscode-python-environments/issues/476](https://github.com/microsoft/vscode-python-environments/issues/476)

## Summary

A persistent visual indicator for the active environment remains missing on current main. The later selection-feedback implementation only shows a temporary icon after an environment is selected, so this team-authored UX request should remain open and be routed to the environment area.

## Change summary

Show a persistent visual indication beside the currently selected environment in the Environment Managers view, including when it was already selected before the view opened.

## Best solution

Define the selection UX with the design team, then have `EnvManagerView` render a persistent selected-state indicator derived from the current global or workspace environment rather than the temporary post-action state. The indicator should update when selection changes and be initialized correctly when the view opens.
