# Issue #1739 — Quick Create, error: %ProgramFiles%\Microsoft VS Code Insiders does not appear to be a Python project

[https://github.com/microsoft/vscode-python-environments/issues/1739](https://github.com/microsoft/vscode-python-environments/issues/1739)

## Summary

Still present on main: Quick Create passes Numba's requirements files to uv without a working directory, so the `-e .` entry in its root requirements.txt resolves against the VS Code Insiders installation directory. This is a confirmed package-install path bug and should remain open for the package and environment areas.

## Change summary

Quick Create creates the venv but fails to install dependencies when a requirements file contains a relative editable reference such as `-e .`.

## Best solution

Resolve relative local references in each discovered requirements file against that file's directory, or execute each requirements group with the appropriate working directory, rather than inheriting the extension host's installation directory. The solution must account for Quick Create collecting requirements files from multiple directories.
