# Issue #1739 — Quick Create, error: %ProgramFiles%\Microsoft VS Code Insiders does not appear to be a Python project

[https://github.com/microsoft/vscode-python-environments/issues/1739](https://github.com/microsoft/vscode-python-environments/issues/1739)

## Summary

Quick Create still loses the project working directory before dependency installation, so requirements containing `-e .` can resolve against VS Code's installation directory. Keep this accepted work open; the maintainer diagnosis is supported by source, and the public API contract remains undecided.

## Change summary

Quick Create creates the environment but fails to install relative editable dependencies because installation runs outside the owning project.

## Best solution

Ensure Quick Create's dependency installation uses the owning project directory with both pip and uv, independently of the environment's location. Settle the package-management API contract for supplying that context while preserving existing callers and shared-environment support.
