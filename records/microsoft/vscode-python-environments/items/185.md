- **Existing capability check:** package.json contributes ordinary environment creation and project commands but no inline-script setup command or declared inline-script setting. src/managers/builtin/inlineScript/main.ts registers the experimental manager only when the undeclared python-envs.inlineScripts.enabled flag is true; src/helpers.ts defaults that flag to false.
- **Partial implementation on main:** src/managers/builtin/inlineScript/envManager.ts:109–193 implements create() by parsing script metadata, selecting a compatible interpreter, and creating or reusing a dependency-keyed environment. - **Detection is not setup:** src/features/inlineScript/lazyDetector.ts explicitly describes its open/save detection as a silent telemetry observer that neither registers projects nor surfaces UI.
