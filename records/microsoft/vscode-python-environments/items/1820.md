[https://github.com/microsoft/vscode-python-environments/issues/1820](https://github.com/microsoft/vscode-python-environments/issues/1820)

## Summary

Keep open: the reporter confirmed the no-workspace trigger, and current core Python source rejects terminal creation when no Python project exists despite having a valid environment. The failing guard belongs to microsoft/vscode-python; related reports do not establish a canonical duplicate for this specific failure.

## Change summary

Shift+Enter fails to start a Python terminal for a standalone file opened without a workspace folder.

## Best solution

Allow the core Python terminal handoff to create a terminal for a valid selected environment without requiring a Python project, preserving existing workspace behavior. A maintainer can transfer this to microsoft/vscode-python and coordinate with the related loose-file selection work.
