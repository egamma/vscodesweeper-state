# Issue #1690 — Breaks python stack, delays venv activation, forgots settings, installs automatically even after being uninstalled.

[https://github.com/microsoft/vscode-python-environments/issues/1690](https://github.com/microsoft/vscode-python-environments/issues/1690)

## Summary

Keep open for human handling: current main contains a terminal-activation path that can wait several seconds and then submit an activation command through the terminal while the user is typing. Because this can combine with text already at the prompt, the report is security-shaped and must not be closed automatically; the selection, tooling, and automatic-install symptoms need separate investigation across the Python-extension rollout boundary.

## Change summary

Enabling the Python Environments extension allegedly loses project environment selections, disrupts environment-provided tools, delays Poetry/venv activation, and injects an activation command into a terminal after the user has started typing.

## Best solution

Prevent command-mode activation from calling `Terminal.sendText` after a delay unless the prompt is known to be idle, and cancel or safely defer activation when user input may already be present. A maintainer should separately trace environment-selection propagation to the core Python and tool extensions, and investigate why the core rollout reinstalls or enables the extension after removal.

## Evidence

- **source-reproducible activation path:** `src/features/terminal/terminalManager.ts` waits in `waitForShellIntegration(terminal)` before invoking `activate`; if integration is still unavailable, `src/features/terminal/terminalActivationState.ts` falls back to `terminal.sendText(activationCommands)`. This directly permits delayed submission of the activation command.
- **delay matches source:** `src/features/terminal/utils.ts` defaults the shell-integration timeout to 5000 ms when integration is enabled. Its prompt detector does not observe user keystrokes, so typing during that wait does not cancel the later `sendText`, matching the reported 5–10 second behavior.
- **security-sensitive impact:** The reporter states that the delayed `source ...` text is appended to the current prompt and submitted. Combining an extension-generated shell command with text already entered by the user can execute unintended shell input, so this requires human security review rather than a cleanup close.
- **distinct related work:** https://github.com/microsoft/vscode-python-environments/issues/664 is open and tracks automatic activation selecting or activating the wrong conda environment, but it does not establish ownership of this report's delayed zsh command injection, Poetry selection loss, tooling integration, or reinstall behavior, so it is related rather than a verified canonical duplicate.
