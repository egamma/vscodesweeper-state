## Summary

The delayed terminal injection remains possible on main: command activation can wait five seconds for shell integration and then send the activation text into a terminal where the user may already be typing. The environment-selection and tool-resolution symptoms need trace logs and likely involve the integration boundary with the core Python and tool extensions.

## Change summary

Installing the extension disrupts Poetry environment selection and tool resolution, while delayed terminal activation can interfere with typed commands.

## Best solution

Prevent command-mode activation from sending text after interactive input has begun, and investigate the Poetry project-selection state using trace logs. The core Python extension should also ensure its rollout does not repeatedly reinstall or enable an explicitly disabled experience.
