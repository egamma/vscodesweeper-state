# Issue #1690 — Breaks python stack, delays venv activation, forgots settings, installs automatically even after being uninstalled.

[https://github.com/microsoft/vscode-python-environments/issues/1690](https://github.com/microsoft/vscode-python-environments/issues/1690)

## Summary

Keep open: current main can wait up to five seconds before falling back to sendText, allowing an activation command to collide with text already entered at the prompt. The tool-resolution and forgotten-selection symptoms still require trace logs.

## Change summary

Installing the extension disrupts environment-dependent tools and saved selections, while delayed terminal activation can append and execute activation text after the user starts typing.

## Best solution

Prevent delayed command-mode activation from writing into a terminal with pending user input, preferably by using shell integration or cancelling the fallback once input begins. Diagnose the selection and tool-extension integration failures separately from trace logs; the core Python extension should own any rollout or automatic-installation behavior.
