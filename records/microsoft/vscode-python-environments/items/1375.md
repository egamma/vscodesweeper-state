# Issue #1375 — Automated terminal activation kills all running tasks in terminals

[https://github.com/microsoft/vscode-python-environments/issues/1375](https://github.com/microsoft/vscode-python-environments/issues/1375)

## Summary

Verified duplicate: command-based activation can interrupt running terminal processes, while the open canonical issue tracks making non-disruptive shell-startup activation the default.

## Change summary

Automatic environment detection activates newly created uv environments in existing terminals and interrupts their running tasks.

## Best solution

Consolidate the default-activation change on https://github.com/microsoft/vscode-python-environments/issues/962. Until that lands, users can select `shellStartup` or disable automatic activation with `python-envs.terminal.autoActivationType`.
