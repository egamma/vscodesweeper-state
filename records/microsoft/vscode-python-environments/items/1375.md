# Issue #1375 — Automated terminal activation kills all running tasks in terminals

[https://github.com/microsoft/vscode-python-environments/issues/1375](https://github.com/microsoft/vscode-python-environments/issues/1375)

## Summary

Verified duplicate: the reporter confirmed that shell-startup activation prevents the interruption and refined the request to making that mode the default, which is exactly the work owned by the older open issue https://github.com/microsoft/vscode-python-environments/issues/962.

## Change summary

Make shell-startup activation the default so delayed environment discovery cannot interrupt programs already running in terminals.

## Best solution

Consolidate the default-mode change on https://github.com/microsoft/vscode-python-environments/issues/962 and carry over this report's concrete uv workflow: discovery can occur after `uv run` starts a program, causing command-based activation to interrupt that program.
