# Issue #1640 — Please make `python-envs.terminal.autoActivationType` syncable to all remotes

[https://github.com/microsoft/vscode-python-environments/issues/1640](https://github.com/microsoft/vscode-python-environments/issues/1640)

## Summary

The accepted account-wide activation preference is still missing: current main exposes only the machine-scoped setting, not a Settings Sync–enabled default for new remotes. Route this to the terminal area and retain the accepted work.

## Change summary

Allow a terminal auto-activation preference to follow users to new remotes and dev containers while preserving host-specific overrides.

## Best solution

Deliver the maintainer-endorsed synced default for command, shellStartup, and off, with explicit machine-specific settings remaining authoritative. Preserve existing behavior for users who have not chosen the new default and establish its precedence relative to legacy activation preferences.
