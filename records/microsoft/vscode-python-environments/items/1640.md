# Issue #1640 — Please make `python-envs.terminal.autoActivationType` syncable to all remotes

[https://github.com/microsoft/vscode-python-environments/issues/1640](https://github.com/microsoft/vscode-python-environments/issues/1640)

## Summary

A real capability gap remains: the existing machine-scoped setting is stored per remote, with no synchronized fallback. The team has welcomed a contribution, so this should remain open and be routed to terminal activation.

## Change summary

Allow users to synchronize a preferred terminal auto-activation mode across remote hosts and development containers.

## Best solution

Add an application-scoped synchronized default setting in package.json while retaining the existing machine-scoped setting as a higher-precedence per-remote override; update getAutoActivationType() in src/features/terminal/utils.ts to apply that precedence.
