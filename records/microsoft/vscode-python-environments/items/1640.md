# Issue #1640 — Please make `python-envs.terminal.autoActivationType` syncable to all remotes

[https://github.com/microsoft/vscode-python-environments/issues/1640](https://github.com/microsoft/vscode-python-environments/issues/1640)

## Summary

A real settings gap remains: `python-envs.terminal.autoActivationType` is machine-scoped and therefore does not provide a synced default across remotes. A maintainer has approved implementation, so this should remain open and be routed to terminal activation.

## Change summary

Allow users to synchronize their preferred terminal auto-activation behavior across remote machines and containers.

## Best solution

Make the existing activation setting syncable while preserving remote-specific overrides, preferably by revisiting its `machine` scope rather than adding a parallel setting. Ensure remote, local, and synced values retain a documented precedence.
