[https://github.com/microsoft/vscode-python-environments/issues/664](https://github.com/microsoft/vscode-python-environments/issues/664)

## Summary

Keep open: the reporter confirmed that Windows PowerShell shell-startup activation still fails after shell detection was corrected, with VSCODE_PYTHON_PWSH_ACTIVATE empty. The assigned Feb Bug Bash milestone independently bars a close; the existing area-activation label is appropriate.

## Change summary

New Windows PowerShell terminals fail to activate the selected conda environment with shellStartup enabled and without permanent conda initialization.

## Best solution

Ensure shell-startup activation delivers and executes the selected environment's per-session conda hook and activation commands in the actual PowerShell terminal. Investigate activation-variable injection and the decision to skip command fallback, preserving operation without permanent conda init changes.
