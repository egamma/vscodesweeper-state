# Issue #664 — The automatic activation mechanism has been damaged

[https://github.com/microsoft/vscode-python-environments/issues/664](https://github.com/microsoft/vscode-python-environments/issues/664)

## Summary

The reporter confirmed that conda shell-startup activation still failed in PowerShell 7 while cmd worked. The assigned Feb Bug Bash milestone and `needs spike` label require this accepted, scheduled investigation to remain open.

## Change summary

Conda shell-startup activation targets the wrong PowerShell installation or profile, leaving new pwsh terminals on the base environment.

## Best solution

Make shell-startup setup resolve the active VS Code terminal's PowerShell executable and corresponding profile rather than relying only on `pwsh` discovery through PATH. The generated activation should load `conda-hook.ps1` before invoking `conda activate`, preserving operation without `conda init`.
