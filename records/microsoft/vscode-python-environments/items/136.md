# Issue #136 — User Approval Flow for Package Installation

[https://github.com/microsoft/vscode-python-environments/issues/136](https://github.com/microsoft/vscode-python-environments/issues/136)

## Summary

Keep open: this team-authored, security-sensitive design issue defines the user-consent boundary for package operations and is accepted for investigation under `needs spike`. Two implementation attempts were closed without merging, and the latest maintainer direction says the approach must be revisited.

## Change summary

Define and implement user-controlled approval policies for package changes requested through the extension API.

## Best solution

Complete the spike with a threat model and consent design that distinguishes user-initiated operations from external-extension requests, stores durable decisions securely, and provides a way to review or revoke permissions. Then implement the approved barrier around API-originated package installation and removal while preserving direct user-initiated package workflows.
