# Issue #136 — User Approval Flow for Package Installation

[https://github.com/microsoft/vscode-python-environments/issues/136](https://github.com/microsoft/vscode-python-environments/issues/136)

## Summary

Keep open: this accepted security-sensitive spike defines the user-consent boundary for package installations initiated through the extension API. Two implementation PRs were closed without merging, and current main still delegates API package operations without an approval layer.

## Change summary

Add user-controlled, per-extension approval and notification flows for package installation and removal through the extension API.

## Best solution

Complete the spike and implement permission mediation for external API callers, including secure per-extension allow/ask decisions and a management UI, while preserving direct user-initiated package operations. The policy should clearly distinguish user-initiated actions from background requests.
