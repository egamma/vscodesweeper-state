[https://github.com/microsoft/vscode-python-environments/issues/136](https://github.com/microsoft/vscode-python-environments/issues/136)

## Summary

Keep open: the per-extension package-installation consent and permission-management flow remains missing from the current API surface, and both implementation attempts were closed without merging. This accepted, team-authored trust-boundary work is protected from cleanup closes.

## Change summary

Introduce user consent and manageable per-extension permissions for package installation through the Python Environments API.

## Best solution

Complete a maintainer-led trust-boundary design for external package-management API calls, using the latest proposal's secret-storage-backed, per-extension approval choices and an interface for reviewing and changing permissions. Preserve the distinction between explicitly user-initiated internal operations and external requests, and settle the remaining removal and permission-scope semantics.
