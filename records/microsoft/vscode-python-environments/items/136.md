# Issue #136 — User Approval Flow for Package Installation

[https://github.com/microsoft/vscode-python-environments/issues/136](https://github.com/microsoft/vscode-python-environments/issues/136)

## Summary

Keep open: this team-authored, security-sensitive design issue defines the user-consent boundary for package operations and is marked as accepted work with `needs spike`. Current main still exposes package installation through the extension API without the proposed per-calling-extension approval flow.

## Change summary

Add a user-controlled permission flow for package operations requested through the extension API, including per-extension approval preferences and management UI.

## Best solution

Design and land an API-level permission barrier that distinguishes internal or user-initiated operations from external extension requests, stores per-extension choices securely, prompts before unapproved installs or removals, and lets users review or revoke those choices. The area owner should build on the UX and implementation work from the closed, unmerged prototypes while retaining explicit human security review.
