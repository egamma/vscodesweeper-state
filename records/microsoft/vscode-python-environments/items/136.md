# Issue #136 — User Approval Flow for Package Installation

[https://github.com/microsoft/vscode-python-environments/issues/136](https://github.com/microsoft/vscode-python-environments/issues/136)

## Summary

Keep open: this team-authored, security-sensitive design issue is accepted for investigation under `needs spike`. Two implementation attempts closed without merging, and current main still lacks an approval barrier for package-management API calls.

## Change summary

Require user-controlled permissions before external extensions can install or remove packages through the extension API.

## Best solution

Revisit the design requested after https://github.com/microsoft/vscode-python-environments/pull/218, then enforce caller-aware approval before `PythonEnvironmentApi.managePackages` delegates package mutations. The end state should securely persist per-extension choices and provide a user-facing way to review or revoke them.
