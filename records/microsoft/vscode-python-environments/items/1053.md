# Issue #1053 — Feature Request: activate default project python/conda environment when launching a task

[https://github.com/microsoft/vscode-python-environments/issues/1053](https://github.com/microsoft/vscode-python-environments/issues/1053)

## Summary

This remains a real capability gap: current main explicitly skips command-based activation for task terminals, while shell-startup activation only partially covers the request. The issue already has the correct terminal and activation routing labels.

## Change summary

Activate a project's selected Python or conda environment before executing tasks from its tasks.json.

## Best solution

Provide the selected project environment to task terminals before their first command for supported activation modes, while respecting the `off` setting and avoiding activation commands that interrupt running tasks.

- **Reason:** Reliable project-scoped task activation directly supports the extension's terminal-activation and environment-selection responsibilities.
