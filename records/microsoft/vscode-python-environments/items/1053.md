# Issue #1053 — Feature Request: activate default project python/conda environment when launching a task

[https://github.com/microsoft/vscode-python-environments/issues/1053](https://github.com/microsoft/vscode-python-environments/issues/1053)

## Summary

A real gap remains: shell-startup activation can affect tasks, but command activation deliberately skips task terminals. The existing area labels already route this valid feature request correctly.

## Change summary

Automatically activate a project's selected Python or conda environment before running tasks from its tasks.json, regardless of terminal activation mode.

## Best solution

Add task-aware activation that resolves the selected environment for the task's workspace or project and makes it effective before the task command starts, including when command activation is selected. Preserve an opt-out so non-Python tasks and tasks expecting untouched input are not disrupted.

- **Evidence:** The vision identifies terminal activation across shells and the per-project environment model as durable themes, while current priorities emphasize activation correctness during rollout.
