# Issue #1053 — Feature Request: activate default project python/conda environment when launching a task

[https://github.com/microsoft/vscode-python-environments/issues/1053](https://github.com/microsoft/vscode-python-environments/issues/1053)

## Summary

A real capability gap remains on current main: command-based activation explicitly refuses to activate task terminals, while shell-startup activation only partially covers the request. The issue already has the appropriate feature and area labels, and no open canonical or implementing PR was found.

## Change summary

Automatically activate each project's selected Python or conda environment before its VS Code tasks execute, regardless of the configured terminal activation mode.

## Best solution

Provide a task-safe activation path that contributes the selected project's environment before the task's first command, without sending activation text into an already-running task terminal. Preserve shell-startup behavior while extending equivalent task support to command activation and multi-project workspace scoping.
