# Issue #960 — Expose helper for resolving python-env search paths (getAllExtraSearchPaths)

[https://github.com/microsoft/vscode-python-environments/issues/960](https://github.com/microsoft/vscode-python-environments/issues/960)

## Summary

A real public-API gap remains on current main, and the accepted-work label `needs PR` requires keeping this open. External manager extensions still must duplicate the extension's search-path resolution logic.

## Change summary

Expose the canonical resolution of legacy, global, and workspace environment search paths to third-party environment managers.

## Best solution

Add a documented method to `PythonEnvironmentApi` that delegates to the existing `getAllExtraSearchPaths()` implementation, preserving multi-root scoping, validation, relative-path resolution, glob support, and legacy-setting compatibility.
