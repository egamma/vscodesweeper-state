# Issue #188 — Raise errors when the required type of python is not available.

[https://github.com/microsoft/vscode-python-environments/issues/188](https://github.com/microsoft/vscode-python-environments/issues/188)

## Summary

This accepted, team-authored PEP 723 work item remains necessary: current main detects that no installed interpreter satisfies `requires-python`, but only logs a warning and returns without presenting an actionable error. The existing `needs PR` label explicitly stages it for implementation.

## Change summary

Surface an error when no installed Python interpreter satisfies a script's required Python constraint.

## Best solution

In the inline-script environment creation flow, present a localized, actionable error when interpreter selection cannot satisfy `requires-python`, while retaining the diagnostic log and avoiding environment creation with an incompatible interpreter.
