# Issue #1868 — Concurrent runs duplicate terminals and invalidate live terminal cache

[https://github.com/microsoft/vscode-python-environments/issues/1868](https://github.com/microsoft/vscode-python-environments/issues/1868)

## Summary

The supplied main checkout still permits duplicate same-key terminal creation and eviction of a newer live terminal when an older terminal closes. Route this well-documented, team-authored report to the terminal area; no verified fix or canonical duplicate was found.

## Change summary

Concurrent execution requests should share terminal initialization, and closing an older terminal should not invalidate another terminal's cache entry.

## Best solution

Make project and dedicated terminal reuse concurrency-safe in TerminalManagerImpl while preserving explicit new-terminal requests and existing activation behavior. Validate shared initialization, cache ownership on close, sequential reuse, separate keys, and replacement after the cached terminal closes.
