# Issue #1689 — Disruptive "No python found in the selected conda environment: base" dialog on startup

[https://github.com/microsoft/vscode-python-environments/issues/1689](https://github.com/microsoft/vscode-python-environments/issues/1689)

## Summary

The report traces to a current-main bug: automatic startup selection passes the no-Python base environment through the same modal flow intended for explicit user selection. Route this to Conda environment handling; the report is complete and should remain open.

## Change summary

Opening a workspace displays a blocking, incorrect no-Python dialog for Conda base before the previously selected environment is restored.

## Best solution

Separate automatic restoration from explicit environment selection in the Conda manager. Startup should not display the install-Python modal or clear selection when a transient no-Python base environment is encountered; the prompt should remain available for an explicit user selection.
