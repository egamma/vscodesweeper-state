# Issue #1689 — Disruptive "No python found in the selected conda environment: base" dialog on startup

[https://github.com/microsoft/vscode-python-environments/issues/1689](https://github.com/microsoft/vscode-python-environments/issues/1689)

## Summary

The supplied trace confirms startup briefly selects a false `base (no-python)` environment and opens the modal before discovery has already found the valid base environment. This remains present on main and should be routed to conda environment discovery.

## Change summary

Startup displays a blocking, incorrect no-Python dialog while conda environment discovery is still settling.

## Best solution

Do not run the interactive no-Python prompt for automatic initial selection, or re-resolve transient no-Python results before prompting. Preserve the modal and installation action for an explicit user selection of a genuinely Python-free conda environment.
