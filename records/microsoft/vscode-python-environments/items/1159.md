# Issue #1159 — Improve testability of environment managers by creating a mock/fake NativePythonFinder

[https://github.com/microsoft/vscode-python-environments/issues/1159](https://github.com/microsoft/vscode-python-environments/issues/1159)

## Summary

The testability debt remains on current main: some manager tests now use local stubs, but the proposed reusable NativePythonFinder mock, Python API mock, and fixture infrastructure do not exist. The related wrapper-consolidation issue addressed a separate prerequisite rather than this focused work.

## Change summary

Introduce reusable mocks and fixture data so built-in environment-manager classes can be unit tested without PET, real filesystems, or installed Python environments.

## Best solution

Add shared NativePythonFinder and PythonEnvironmentApi test doubles under `src/test/mocks/`, cross-platform fixture builders, and manager tests that consume them instead of repeating incomplete casts or local stubs. Keep the fixtures platform-neutral by constructing paths with the repository's cross-platform path utilities.
