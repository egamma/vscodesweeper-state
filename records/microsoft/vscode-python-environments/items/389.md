# Issue #389 — Show warning that python isnt installed in select interpreter and/or create environment quick pick

[https://github.com/microsoft/vscode-python-environments/issues/389](https://github.com/microsoft/vscode-python-environments/issues/389)

## Summary

The missing-Python state remains unrepresented in the interpreter picker on current main: it always offers Create Virtual Environment without checking for an available base interpreter. The issue is team-authored, and the only linked fix attempt was closed without merging, so it should remain open.

## Change summary

Warn users when no Python installation is detected and avoid offering environment-creation paths that cannot provide their own Python.

## Best solution

Update the picker in `src/common/pickers/environments.ts` to represent the no-Python state explicitly and offer creation only when an eligible manager can use or install a base interpreter. Preserve the newer uv-backed installation path in the built-in venv manager rather than hiding every creation option whenever Python is absent.
