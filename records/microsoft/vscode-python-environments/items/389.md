# Issue #389 — Show warning that python isnt installed in select interpreter and/or create environment quick pick

[https://github.com/microsoft/vscode-python-environments/issues/389](https://github.com/microsoft/vscode-python-environments/issues/389)

## Summary

Current main still always shows Create Virtual Environment without indicating that Python is absent. The related fixing PR was closed unmerged, and this team-authored issue must remain open.

## Change summary

Warn users when no Python installation is detected and avoid offering an unusable environment-creation path.

## Best solution

Make the interpreter picker communicate the no-Python state and offer Create Virtual Environment only when a manager can supply or install a base interpreter. Account for the current venv flow, which can bootstrap Python through uv.
