# Issue #389 — Show warning that python isnt installed in select interpreter and/or create environment quick pick

[https://github.com/microsoft/vscode-python-environments/issues/389](https://github.com/microsoft/vscode-python-environments/issues/389)

## Summary

The gap remains on current main: the interpreter picker always offers environment creation without checking whether Python is available. This team-authored issue should remain open; its proposed implementation PR was closed without merging.

## Change summary

Warn when Python is unavailable and avoid offering environment creation unless a manager can provide a Python installation.

## Best solution

Make the picker capability-aware: offer creation when an available manager can supply Python, otherwise show a localized no-Python warning while retaining manual interpreter browsing. The implementation belongs in the environment picker and manager capability flow.
