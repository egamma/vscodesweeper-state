[https://github.com/microsoft/vscode-python-environments/issues/1467](https://github.com/microsoft/vscode-python-environments/issues/1467)

## Summary

Multiple users confirm that new terminals activate an environment from another project. The current terminal-selection path still relies on the project-scoped environment before considering terminal cwd, so this remains actionable activation work.

## Change summary

New terminals automatically activate a virtual environment belonging to a different project despite project-specific environment settings.

## Best solution

Ensure terminal creation resolves the selected environment for the current project or terminal cwd and never reuses stale state from another project. The investigation should trace project selection through `src/features/interpreterSelection.ts` into `getEnvironmentForTerminal` and terminal activation.
