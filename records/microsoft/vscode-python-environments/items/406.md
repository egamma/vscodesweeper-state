# Issue #406 — Use the Prefix path for the environment when autofinding projects

[https://github.com/microsoft/vscode-python-environments/issues/406](https://github.com/microsoft/vscode-python-environments/issues/406)

## Summary

The gap remains on current main: project auto-discovery excludes only `.venv`, so metadata inside another selected environment prefix can be offered as a project. This accepted `needs PR` work should remain open.

## Change summary

Exclude `pyproject.toml` and `setup.py` files beneath the workspace environment's `sysPrefix` when auto-finding projects.

## Best solution

Update `src/features/creators/autoFindProjects.ts` to resolve each workspace's selected environment prefix and filter discovered project files contained within it, with cross-platform path-containment tests.
