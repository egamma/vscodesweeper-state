The gap remains on current main: auto-find excludes only `.venv`, not the selected workspace environment's `sysPrefix`. This team-authored issue is accepted with `needs PR`, so it should remain open.

## Change summary

Auto-find should ignore project metadata located anywhere under the workspace environment's actual prefix path.
