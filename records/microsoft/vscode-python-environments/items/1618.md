# Issue #1618 — Missing signature for darwin-arm64 pet binary

[https://github.com/microsoft/vscode-python-environments/issues/1618](https://github.com/microsoft/vscode-python-environments/issues/1618)

## Summary

The released darwin-arm64 extension contains an ad-hoc-signed PET binary, preventing reliable allowlisting in managed macOS environments. The current packaging pipeline downloads PET and packages it without an explicit signing step, so this remains actionable here.

## Change summary

Ship the darwin-arm64 PET binary with a Microsoft code signature rather than an ad-hoc linker signature.

## Best solution

Update the macOS extension packaging pipeline to sign the downloaded PET binary with the Microsoft identity before packaging, and validate that both Darwin architectures have a non-ad-hoc signature and TeamIdentifier.
