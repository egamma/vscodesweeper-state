# Issue #1618 — Missing signature for darwin-arm64 pet binary

[https://github.com/microsoft/vscode-python-environments/issues/1618](https://github.com/microsoft/vscode-python-environments/issues/1618)

## Summary

The released darwin-arm64 extension contains a PET executable with only an ad-hoc signature, and current packaging consumes the binary produced by the PET pipeline without signing it locally. This remains actionable, but the signing fix likely belongs in microsoft/python-environment-tools or its shared Rust-package pipeline.

## Change summary

Ship the darwin-arm64 PET binary with a Microsoft-identifiable code signature so enterprise application-control tools can allowlist it reliably.

## Best solution

Update the microsoft/python-environment-tools signing pipeline or its shared engineering template so Darwin PET artifacts receive the intended Microsoft signature before this extension packages them, then verify the signature in a published darwin-arm64 VSIX. A maintainer can transfer this report to microsoft/python-environment-tools or link a concrete counterpart there.
