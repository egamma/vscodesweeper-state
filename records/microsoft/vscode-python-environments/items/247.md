# Issue #247 — Avoid creating new folders outside our existing ones

[https://github.com/microsoft/vscode-python-environments/issues/247](https://github.com/microsoft/vscode-python-environments/issues/247)

## Summary

The user-directory clutter remains source-reproducible on current main. The accepted `needs proposal` work should stay open and be routed to CMD terminal activation.

## Change summary

CMD shell-startup activation creates a `.cmdrc` directory in the user's home instead of using VS Code's instance-specific user-data storage.

## Best solution

Store the CMD startup scripts under the current VS Code instance's user-data storage and update the AutoRun command accordingly, while preserving CMD activation for shells launched from VS Code.
