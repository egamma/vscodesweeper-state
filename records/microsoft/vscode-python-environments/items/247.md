# Issue #247 — Avoid creating new folders outside our existing ones

[https://github.com/microsoft/vscode-python-environments/issues/247](https://github.com/microsoft/vscode-python-environments/issues/247)

## Summary

The clutter remains on current main: CMD shell-startup setup still creates `%USERPROFILE%\.cmdrc`. The accepted `needs proposal` work should remain open while the CMD invocation strategy and instance-specific storage location are designed.

## Change summary

Store generated CMD startup scripts in VS Code's existing user-data storage instead of creating a `.cmdrc` directory in the user's home folder.

## Best solution

Design the CMD AutoRun integration so every CMD launched by the relevant VS Code instance invokes generated scripts stored under that instance's user-data storage, without adding a top-level home directory or affecting external terminals.
