# Issue #247 — Avoid creating new folders outside our existing ones

[https://github.com/microsoft/vscode-python-environments/issues/247](https://github.com/microsoft/vscode-python-environments/issues/247)

## Summary

Still present on current main: cmd shell-startup setup unconditionally creates `%USERPROFILE%\.cmdrc`. The accepted `needs proposal` label protects this work from cleanup closure, and the unresolved multi-instance AutoRun design requires maintainer direction.

## Change summary

Store cmd shell-startup scripts in VS Code's existing per-instance user-data storage instead of creating a new folder in the user's home directory.

## Best solution

Design cmd activation so its generated batch files live under the extension's `globalStorageUri` while the process-wide cmd AutoRun entry reliably dispatches to the appropriate VS Code instance's script. The proposal must account for multiple VS Code instances or user-data directories sharing the same HKCU Command Processor AutoRun value.
