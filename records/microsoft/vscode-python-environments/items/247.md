# Issue #247 — Avoid creating new folders outside our existing ones

[https://github.com/microsoft/vscode-python-environments/issues/247](https://github.com/microsoft/vscode-python-environments/issues/247)

## Summary

The issue remains present on current main: enabling shell-startup activation for Windows cmd creates `%USERPROFILE%\.cmdrc`. The accepted `needs proposal` work should remain open and be routed to the cmd terminal and activation areas.

## Change summary

Store cmd shell-startup scripts in VS Code's existing per-instance user-data storage instead of creating a new folder in the user's home directory.

## Best solution

Design a stable per-VS Code-instance storage location for the cmd startup scripts while preserving registry AutoRun behavior for every cmd terminal opened by that instance. The proposal must also account for multiple VS Code variants or profiles and migration or cleanup of the existing `%USERPROFILE%\.cmdrc` files.
