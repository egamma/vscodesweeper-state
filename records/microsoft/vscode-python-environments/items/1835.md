# Issue #1835 — Turn off the Python Environments experiment

[https://github.com/microsoft/vscode-python-environments/issues/1835](https://github.com/microsoft/vscode-python-environments/issues/1835)

## Summary

Keep this team-authored meta issue open as the coordination tracker for retiring the experiment. Current source still supports opting out and conditionally hides UI, while the API, documentation, and Jupyter prerequisites remain open.

## Change summary

Make Python Environments the unconditional default and retire experiment assignment, the opt-out setting, legacy environment paths, and transitional documentation and tests.

## Best solution

Retain this umbrella until stable API delivery and first-party adoption are complete, then coordinate removal of transitional paths across Python Environments and the core Python extension. A default-setting change alone does not satisfy the completion criteria because it preserves the legacy opt-out.
