[https://github.com/microsoft/vscode-python-environments/issues/1091](https://github.com/microsoft/vscode-python-environments/issues/1091)

## Summary

The debt remains on current main: terminal setup still treats the enabled setting as evidence that shell integration is available, despite the adjacent TODO noting that this does not prove successful injection. This team-authored debt item should remain open.

## Change summary

Replace the shell-integration setting check with a more accurate indication that integration was successfully injected.

## Best solution

Determine shell-integration availability from the terminal API or a cached observation of successful integration, while retaining profile activation for WSL and unsupported shells. Avoid treating an enabled setting alone as proof that startup injection succeeded.
