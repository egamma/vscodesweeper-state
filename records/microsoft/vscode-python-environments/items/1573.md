# Issue #1573 — [Python Environments] default value of python-envs.workspaceSearchPaths is not respected

[https://github.com/microsoft/vscode-python-environments/issues/1573](https://github.com/microsoft/vscode-python-environments/issues/1573)

## Summary

Keep this accepted proposal open and route it to environment discovery: configuring workspace-relative discovery once at user level remains unsupported. The latest clarification establishes that explicit recursive discovery works; repeating the configuration in every workspace is the remaining blocker.

## Change summary

Allow a reusable user-level workspace-relative environment search configuration and accurately document the bounded discovery defaults.

## Best solution

Design an opt-in user-level discovery configuration resolved against each workspace folder, with workspace and folder overrides and safeguards for expensive recursive scans. Keep the safe defaults unless explicitly reconsidered, and make the documentation accurately describe them.
