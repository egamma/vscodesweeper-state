# Issue #1573 — [Python Environments] default value of python-envs.workspaceSearchPaths is not respected

[https://github.com/microsoft/vscode-python-environments/issues/1573](https://github.com/microsoft/vscode-python-environments/issues/1573)

## Summary

Keep the accepted proposal open and route it to environment discovery: current defaults intentionally cover only the workspace root and immediate child folders, while deeper discovery and reusable user-level configuration remain unresolved. The documentation mismatch also needs correction; existing settings only partially cover the request.

## Change summary

Provide reliable discovery of nested monorepo environments without repetitive workspace configuration, and document the actual search defaults.

## Best solution

Agree on a performance-safe discovery policy for deeper monorepos and whether workspace-relative search patterns can be configured once at user level. Make the documentation accurately describe the shipped defaults and supported configuration scopes without restoring unbounded scans by accident.
