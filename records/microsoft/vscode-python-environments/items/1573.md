# Issue #1573 — [Python Environments] default value of python-envs.workspaceSearchPaths is not respected

[https://github.com/microsoft/vscode-python-environments/issues/1573](https://github.com/microsoft/vscode-python-environments/issues/1573)

## Summary

The configured default is being respected, but the documentation is stale: the recursive default was intentionally replaced with root and first-level searches for performance. Keep this open to correct the documentation and clarify the available global setting.

## Change summary

Documentation claims recursive `.venv` discovery by default, while the extension intentionally searches only the workspace root and its immediate children.

## Best solution

Update the Python environments documentation to describe the actual `.venv` and `*/.venv` defaults and explain that deeper recursive patterns belong in workspace settings. Also document `python-envs.globalSearchPaths` for absolute user-level locations without implying that workspace-relative patterns can be configured globally.

## Evidence

- **current source:** `package.json` defines `python-envs.workspaceSearchPaths` as `[".venv", "*/.venv"]`; `src/managers/common/nativePythonFinder.ts` reads `inspection.defaultValue` and resolves each path against the scoped workspace folder.
- **documentation mismatch:** The current https://code.visualstudio.com/docs/python/environments#_configure-search-paths still claims the default is `./**/.venv`, which does not match the shipped setting.
- **global alternative:** `package.json` exposes machine-scoped `python-envs.globalSearchPaths`; its description and implementation restrict it to absolute paths shared across workspaces.
