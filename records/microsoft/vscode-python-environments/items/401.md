# Issue #401 — Bug: Children Projects in Settings

[https://github.com/microsoft/vscode-python-environments/issues/401](https://github.com/microsoft/vscode-python-environments/issues/401)

## Summary

The redundant-settings behavior remains on current main: every non-root project is persisted without checking whether it inherits identical manager settings from an ancestor. This team-authored issue should remain open.

## Change summary

Avoid persisting a nested Python project when its environment and package managers match the effective configuration inherited from its parent project.

## Best solution

Update project addition and settings persistence to find the nearest configured ancestor, compare effective manager IDs, and omit or remove redundant child overrides. Preserve explicit child entries when they differ and include the workspace identifier where needed in multi-root workspaces.
