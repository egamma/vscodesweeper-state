# Issue #401 — Bug: Children Projects in Settings

[https://github.com/microsoft/vscode-python-environments/issues/401](https://github.com/microsoft/vscode-python-environments/issues/401)

## Summary

Still present on current main: adding any non-root project writes a `pythonProjects` entry without checking whether it inherits identical manager settings from a parent. Route this team-authored issue to the environment area.

## Change summary

Avoid persisting redundant settings for nested projects that use the same environment and package managers as their parent project.

## Best solution

Update project addition to resolve the nearest parent project's effective managers, including implicit workspace-root defaults and multi-root workspace identity, and persist the child only when its configuration differs. Add coverage for inherited, overridden, and multi-root nested projects.
