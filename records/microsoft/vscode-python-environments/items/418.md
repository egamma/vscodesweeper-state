# Issue #418 — Explore a Python Run Command Tool

[https://github.com/microsoft/vscode-python-environments/issues/418](https://github.com/microsoft/vscode-python-environments/issues/418)

## Summary

Keep open: this team-authored exploration is accepted into the proposal lane with `needs proposal`, and current main provides background Python execution through the API but does not expose the requested language-model tool.

## Change summary

Add a Copilot tool that runs Python directly without constructing commands for or waiting on a terminal.

## Best solution

Develop the requested proposal around a language-model tool backed by `PythonExecutionApi.runInBackground`, including environment selection, working-directory and argument semantics, output collection, cancellation, and workspace-trust safeguards. The implementation should reuse the existing execution API rather than duplicate process-launching logic.
