# Issue #630 — Button to refresh select environment

[https://github.com/microsoft/vscode-python-environments/issues/630](https://github.com/microsoft/vscode-python-environments/issues/630)

## Summary

The requested picker-level refresh remains absent on current main, while the existing refresh command is exposed only from the Environment Managers view. This team-authored issue is accepted work with `needs PR`, so it should remain open.

## Change summary

Restore a refresh button in the Select Environment picker so users can rescan environments without leaving the picker.

## Best solution

Add a refresh button to the picker in `src/common/pickers/environments.ts`; triggering it should refresh the environment managers and rebuild the picker items while preserving the selection workflow. The existing `python-envs.refreshAllManagers` implementation provides the manager-refresh operation, though the picker helper may need to support refreshing without closing the quick pick.
