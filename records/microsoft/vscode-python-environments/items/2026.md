[https://github.com/microsoft/vscode-python-environments/issues/2026](https://github.com/microsoft/vscode-python-environments/issues/2026)

## Summary

The double-quoting defect is fixed on the core Python extension's main branch. The linked sibling report was closed by the behavioral fix; this issue can be closed as completed, not as a duplicate of that closed report.

## Change summary

Run Python File passes literal quotation marks as part of script paths, causing Python to report that the file does not exist.

## Best solution

Retain the core Python fix that passes raw script paths to the Python Environments terminal API, leaving shell quoting to this extension. Release availability is not established, so communicate this as a main-only fix.
