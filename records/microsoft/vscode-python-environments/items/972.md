# Issue #972 — shellStartup notification should describe the changes to be made

[https://github.com/microsoft/vscode-python-environments/issues/972](https://github.com/microsoft/vscode-python-environments/issues/972)

## Summary

Keep open: the shell-profile consent dialog still offers neither a change preview nor a documentation link, and its success notification does not describe the edits. This team-authored, reopened item has no verified subsequent fix or open canonical duplicate.

## Change summary

Make shellStartup notifications explain the proposed and completed shell-profile changes so users can make an informed decision.

## Best solution

Make the shell-profile setup flow disclose affected files and the changes before consent, with either a reviewable preview or directly accessible documentation, and explain what was changed afterward. Preserve existing activation behavior and the explicit revert command.
