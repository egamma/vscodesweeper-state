# Issue #972 — shellStartup notification should describe the changes to be made

[https://github.com/microsoft/vscode-python-environments/issues/972](https://github.com/microsoft/vscode-python-environments/issues/972)

## Summary

The requested transparency is still missing on current main: the modal identifies affected shells but does not preview or document the profile edits, and accepting it writes the changes immediately. This team-authored issue was reopened after the related cleanup change failed to address the concern, so it should remain open.

## Change summary

Show users the proposed shell-profile modifications, ideally as a diff requiring confirmation, before applying shell-startup activation changes.

## Best solution

Refactor shell-startup setup so providers can prepare proposed profile contents without writing them, then show the affected files and diff before the user confirms the edits. At minimum, the prompt should describe the inserted startup block and link to documentation explaining the change and how to revert it.
