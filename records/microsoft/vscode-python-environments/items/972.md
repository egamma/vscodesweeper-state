# Issue #972 — shellStartup notification should describe the changes to be made

[https://github.com/microsoft/vscode-python-environments/issues/972](https://github.com/microsoft/vscode-python-environments/issues/972)

## Summary

The UX gap remains on current main: the modal describes profile updates only generally, and accepting it immediately writes startup scripts without showing the affected files or proposed diff. This team-authored debt item should remain open.

## Change summary

Explain and preview shell-profile modifications before asking users to approve them.

## Best solution

Separate previewing from applying shell-profile edits in the terminal startup providers, then present the proposed file changes in a diff editor before final confirmation. At minimum, the prompt should identify the affected profiles and link to documentation describing the inserted startup code.
