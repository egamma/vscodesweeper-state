# Issue #1893 — Identical, meaningless suffixes for same-name global interpreters in Environment Managers

[https://github.com/microsoft/vscode-python-environments/issues/1893](https://github.com/microsoft/vscode-python-environments/issues/1893)

## Summary

The current source still gives same-name global interpreters identical, unhelpful suffixes. Route this to area-environment; the report identifies a concrete presentation defect distinct from PET's duplicate-discovery work.

## Change summary

Make suffixes distinguish same-name global interpreters while preserving project-folder suffixes for virtual environments and leaving unique names unsuffixed.

## Best solution

Environment Managers should identify colliding global interpreters using meaningful differing path information, including executable names when their folders match. Preserve existing virtual-environment descriptions and address this in the view's disambiguation path, independently of PET discovery fixes.
