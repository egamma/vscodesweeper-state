## Summary

Current main still stores the global system-Python cache only in remote-scoped globalState, causing the traced cold-cache path. Keep this open while the targeted draft fix in PR 1611 is reviewed.

## Change summary

Persist the global system-Python fast-path cache per workspace so fresh remote sessions avoid unnecessary foreground PET refreshes.

## Best solution
