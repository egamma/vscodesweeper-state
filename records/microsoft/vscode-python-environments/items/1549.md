# Issue #1549 — "Create Python Terminal" button doesn't work as expected

[https://github.com/microsoft/vscode-python-environments/issues/1549](https://github.com/microsoft/vscode-python-environments/issues/1549)

## Summary

Still present on current main: command dispatch ignores the clicked environment whenever a project exists and does nothing when none exists. Route this source-reproducible bug to terminal and environment ownership.

## Change summary

The Environment Managers view's Create Python Terminal button should activate the clicked environment regardless of project state.

## Best solution

Handle `PythonEnvTreeItem` before the generic project branch in `src/features/envCommands.ts`, always passing the clicked `view.environment` to `TerminalManager.create`; use the selected project's directory only as the cwd, and allow an undefined cwd when no project exists.
