# Issue #1549 — "Create Python Terminal" button doesn't work as expected

[https://github.com/microsoft/vscode-python-environments/issues/1549](https://github.com/microsoft/vscode-python-environments/issues/1549)

## Summary

Still present on main: the command handler discards the clicked environment whenever any Python project exists and otherwise requires a project before creating its terminal. Routing this source-reproducible activation bug to the terminal and environment areas.

## Change summary

Create Python Terminal should activate the environment selected in the Environment Managers view, including when no project is open.

## Best solution

Update `createTerminalCommand` in `src/features/envCommands.ts` to preserve a `PythonEnvTreeItem`'s environment and choose only the terminal cwd from available projects; when none exists, create the terminal with an undefined cwd. Add coverage for zero projects, a project without an environment, and a project whose selected environment differs from the clicked environment.
