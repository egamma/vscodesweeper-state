# Issue #1549 — "Create Python Terminal" button doesn't work as expected

[https://github.com/microsoft/vscode-python-environments/issues/1549](https://github.com/microsoft/vscode-python-environments/issues/1549)

## Summary

Still present on current main: the command handles any workspace project before inspecting the clicked environment tree item, causing it to activate the project's environment instead. With no projects, the environment-item branch receives no cwd and exits without creating a terminal.

## Change summary

The Environment Managers view's Create Python Terminal button either does nothing or activates the project environment instead of the environment whose button was clicked.

## Best solution

Handle `PythonEnvTreeItem` before the project-default command path in `createTerminalCommand`, always passing the clicked environment to `TerminalManager.create`; retain project selection only to choose an optional cwd, and use an undefined cwd when no project is open.
