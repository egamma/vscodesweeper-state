# Issue #1549 — "Create Python Terminal" button doesn't work as expected

[https://github.com/microsoft/vscode-python-environments/issues/1549](https://github.com/microsoft/vscode-python-environments/issues/1549)

## Summary

The button still ignores the clicked environment when projects exist and creates no terminal when there are none. Route this confirmed defect to terminal activation; the attempted fix was closed without merging, and the maintainer's question about working-directory behavior remains unresolved.

## Change summary

Create Python Terminal should activate the environment whose button was clicked, including when no Python project exists.

## Best solution

Make environment-specific terminal creation honor the clicked environment through command and shell-startup activation without changing the project's selected environment. Settle whether this button retains project-based working-directory selection or delegates cwd entirely to VS Code, then revisit the closed implementation attempt.

Command activation and shell-startup fallback must both preserve the clicked environment.
- **Trace:**
