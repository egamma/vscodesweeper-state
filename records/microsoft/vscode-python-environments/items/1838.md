# Issue #1838 — Integrated terminals retain stale variables from workspace .env

[https://github.com/microsoft/vscode-python-environments/issues/1838](https://github.com/microsoft/vscode-python-environments/issues/1838)

## Summary

Keep open: the supplied settings and steps suffice to retest stale terminal variables. Main has since gained refresh-ordering and environment-file event fixes, but restored collection entries still lack corresponding in-memory ownership tracking, so those changes do not establish that this report is resolved.

## Change summary

New integrated terminals retain old workspace environment-file values after variables are changed, removed, or injection is disabled.

## Best solution

Ensure terminal environment-file contributions reconcile with current configuration both within a session and after persisted collections are restored, without disturbing shell-startup activation. Reproduce the reported flow first and distinguish refresh races, restored untracked entries, and inherited process values.
