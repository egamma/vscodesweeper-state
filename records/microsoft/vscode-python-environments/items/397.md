- **Behavior:**

  > Users should be able to create a new Flask project through the extension's project-creation workflow rather than assemble it manually. The project plan also calls for Quick Create support without additional input once the name and destination are supplied. Acceptance should establish that the agreed scaffold runs as a Flask application, appears as a Python project, and uses its associated environment. - **Trace:**

  > src/extension.ts registers four built-in creators and invokes them through python-envs.createNewProjectFromTemplate; there is no Flask registration, and Quick Create dispatch recognizes only package and script identifiers. src/api.ts exposes the creator interface and creation options, while docs/projects-api-reference.md explains registration and project ownership.
