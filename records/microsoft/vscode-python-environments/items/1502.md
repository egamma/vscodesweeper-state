# Issue #1502 — shellStartup not working on remote setup with vscode-server

[https://github.com/microsoft/vscode-python-environments/issues/1502](https://github.com/microsoft/vscode-python-environments/issues/1502)

## Summary

Remote SSH users have independently confirmed that shell-startup activation cannot be enabled in their remote window. This team-authored issue remains necessary because no referenced fix or broader open canonical owns the runtime/setup failure.

## Change summary

Make shell-startup environment activation work in VS Code remote windows backed by vscode-server.

## Best solution

Ensure `python-envs.terminal.autoActivationType` can be selected for the active remote machine and that profile detection and modification execute against the remote extension host's shell and home directory. Coordinate with https://github.com/microsoft/vscode-python-environments/issues/1640 for setting synchronization, while retaining this issue for remote activation correctness.
