# Issue #1502 — shellStartup not working on remote setup with vscode-server

[https://github.com/microsoft/vscode-python-environments/issues/1502](https://github.com/microsoft/vscode-python-environments/issues/1502)

## Summary

Confirmed remote-activation gap: multiple users report that shell-startup activation cannot be enabled in remote SSH/vscode-server windows. This team-authored issue must remain open for investigation.

## Change summary

Make shellStartup activation work in remote vscode-server sessions.

## Best solution

Ensure `python-envs.terminal.autoActivationType` can be configured for remote windows and that startup-script setup runs against the remote extension host and shell profile. The fix belongs in the terminal activation configuration and setup flow.
