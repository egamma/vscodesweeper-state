# Issue #1363 — Visual Studio Code failed to recognize default python interpreter path

[https://github.com/microsoft/vscode-python-environments/issues/1363](https://github.com/microsoft/vscode-python-environments/issues/1363)

## Summary

The original workspace-wide scan regression was fixed and confirmed resolved, but later evidence shows the same warning from a distinct PET resolve timeout, while the newest comment adds an unresolved wrapper-script capability request. Keep this open and route it to environment handling so maintainers can separate the remaining timeout defect from the wrapper-script feature request.

## Change summary

Configured default interpreter paths can be rejected when PET resolution times out, and executable Python wrapper scripts are not accepted as interpreter paths.

## Best solution

Track the current PET resolve-timeout failure as an environment-discovery bug and split wrapper-script support into a focused feature request. The resolver should continue validating ordinary Python binaries reliably, while wrapper support needs an explicit design decision about deriving environment metadata without replacing the configured executable.
