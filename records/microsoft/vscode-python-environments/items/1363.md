# Issue #1363 — Visual Studio Code failed to recognize default python interpreter path

[https://github.com/microsoft/vscode-python-environments/issues/1363](https://github.com/microsoft/vscode-python-environments/issues/1363)

## Summary

The original recursive workspace-scan problem was fixed and confirmed resolved, but the latest logs expose a distinct current failure: a default-interpreter resolve timeout kills the shared PET process and aborts discovery across all managers. Keep this open and route it to environment discovery.

## Change summary

Interpreter selection falls back or fails when resolving the configured default interpreter times out during concurrent environment discovery.

## Best solution

Make default-interpreter resolution resilient to a slow PET operation, particularly conda inspection, without terminating the shared discovery process and cascading failures through every manager. The environment discovery path should retry or use its JSON CLI fallback while preserving other in-flight discovery.
