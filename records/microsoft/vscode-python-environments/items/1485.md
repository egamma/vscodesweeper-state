# Issue #1485 — What is the global environment for?

[https://github.com/microsoft/vscode-python-environments/issues/1485](https://github.com/microsoft/vscode-python-environments/issues/1485)

## Summary

This is an API-integration question with a confirmed answer: manager extensions should set the project-scoped environment, while consuming extensions should subscribe to this extension's project-aware environment API rather than relying only on the legacy global event.

## Change summary

Clarify whether a manager extension should mirror project environment selections into the legacy global environment for tools such as Ruff and ty.

## Best solution

Keep Hatch selections project-scoped and have consumers use the flat `api.onDidChangeEnvironment` API, retaining the core Python extension's legacy event only as a compatibility fallback. Ruff and ty have since implemented this integration.
