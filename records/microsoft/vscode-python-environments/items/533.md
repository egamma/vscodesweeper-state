# Issue #533 — switch to dependency groups for new package flow

[https://github.com/microsoft/vscode-python-environments/issues/533](https://github.com/microsoft/vscode-python-environments/issues/533)

## Summary

Keep open: the package template still uses dev-requirements.txt and setuptools-backed development extras, so the requested dependency-group migration remains outstanding. This is team-authored work labeled needs spike, with an explicit decision to await community adoption.

## Change summary

Use PEP 735 dependency groups for development dependencies in newly scaffolded Python packages.

## Best solution

When the team considers ecosystem adoption sufficient, migrate the package template's development dependencies to dependency groups while retaining project metadata and build configuration in pyproject.toml. Ensure the generated project's dependency-installation workflow and documentation support the chosen tooling compatibility baseline.
