# Issue #533 — switch to dependency groups for new package flow

[https://github.com/microsoft/vscode-python-environments/issues/533](https://github.com/microsoft/vscode-python-environments/issues/533)

## Summary

This accepted, team-authored feature remains unimplemented on current main. The existing `needs spike` label requires keeping it open while the team evaluates community adoption of PEP 735 dependency groups.

## Change summary

Use PEP 735 dependency groups instead of a separate development-requirements file in newly scaffolded package projects.

## Best solution

After the adoption spike, update the package template and project documentation to declare development tools in a `[dependency-groups]` section, and ensure the package workflow recognizes and installs that group.
