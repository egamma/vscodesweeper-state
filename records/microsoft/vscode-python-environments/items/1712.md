# Issue #1712 — Kernel crashes when using a Pixi environment with Python Environments enabled

[https://github.com/microsoft/vscode-python-environments/issues/1712](https://github.com/microsoft/vscode-python-environments/issues/1712)

## Summary

Verified duplicate cluster: the open continuation issue already tracks the same Pixi activation timeout and resulting kernel disposal. This report adds a strong Windows reproduction where missing activated environment variables lead to a Matplotlib-triggered kernel crash with exit code 0xC06D007F.

## Change summary

Pixi activation uses an interactive `pixi shell` command that times out during environment-variable collection, after which a Windows Jupyter kernel crashes when plotting with Matplotlib.

## Best solution

Consolidate on https://github.com/microsoft/vscode-python-environments/issues/1672 and correct the Pixi activation integration so environment-variable collection does not chain commands after the non-returning interactive `pixi shell`; preserve this report's Windows, Matplotlib, and exit-code evidence in the canonical investigation.

## Evidence

- **canonical issue:** https://github.com/microsoft/vscode-python-environments/issues/1672 is open, predates this report, and explicitly continues the same Pixi activation defect: `pixi shell` starts an interactive shell, the chained environment-variable command never runs, and the operation times out after roughly 30 seconds.

- **provider source:** Pixi Code supplies `activation: [{ executable: pixi, args: ['shell', '--manifest-path', manifestPath, '-e', pixiEnv.name] }]` in https://github.com/renan-r-santos/pixi-code/blob/996c3687f8f3e4bf941b72ed5a44909941b6264a/src/pixi/utils.ts, matching the command shown timing out in this report.
- **API boundary:** `src/api.ts` defines third-party `PythonEnvironmentExecutionInfo.activation` and `activatedRun`, while `docs/design.md` identifies external environment managers as the providers of execution and terminal-activation information; this repository has no built-in Pixi activation implementation beyond recommending Pixi Code.
