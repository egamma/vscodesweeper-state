# Issue #924 — Support cancelling when searching for dependencies

[https://github.com/microsoft/vscode-python-environments/issues/924](https://github.com/microsoft/vscode-python-environments/issues/924)

## Summary

Keep open: dependency-search progress still has no Cancel button on the inspected main checkout, and the linked implementation PR was closed without merging. This remains accepted work, with a recent maintainer proposal describing cancellation through the creation flow.

## Change summary

Allow users to cancel long-running dependency searches during environment creation without exiting VS Code.

## Best solution

Make dependency searching cancellable end to end for direct Quick Create and the guided creation flow, with cancellation stopping before environment creation or package installation. Preserve successful empty searches, Back/Skip behavior, and genuine error reporting; the closed PR is prior work, not a delivered fix.
