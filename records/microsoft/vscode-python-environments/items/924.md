# Issue #924 — Support cancelling when searching for dependencies

[https://github.com/microsoft/vscode-python-environments/issues/924](https://github.com/microsoft/vscode-python-environments/issues/924)

## Summary

The cancellation gap remains on current main. A prior implementation PR was closed without merging, and this team-authored request should remain open.

## Change summary

Allow users to cancel the dependency-file search performed during Quick Create in large workspaces.

## Best solution

Make the notification in `getProjectInstallable` cancellable while continuing to pass its cancellation token to every file search, with unit coverage for both behaviors.

- **Fit:** aligned
- **Reason:** Cancellation improves the stability and usability of a core environment-creation workflow in unusually large workspaces.
- **Evidence:** The vision prioritizes environment lifecycle, discovery robustness, and the value that "Performance and stability trumps functionality."
