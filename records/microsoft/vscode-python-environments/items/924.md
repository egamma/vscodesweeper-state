# Issue #924 — Support cancelling when searching for dependencies

[https://github.com/microsoft/vscode-python-environments/issues/924](https://github.com/microsoft/vscode-python-environments/issues/924)

## Summary

Cancellation remains unavailable on current main: the dependency-search notification is not marked cancellable. The related implementation PR was closed without merging, so this team-authored request should remain open.

## Change summary

Allow users to cancel the dependency search performed during Quick Create in large workspaces.
