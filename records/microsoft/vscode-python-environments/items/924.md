# Issue #924 — Support cancelling when searching for dependencies

[https://github.com/microsoft/vscode-python-environments/issues/924](https://github.com/microsoft/vscode-python-environments/issues/924)

## Summary

The cancellation gap remains on current main: dependency discovery displays a notification without enabling cancellation, even though its file searches already receive the progress token. The only linked implementation PR was closed without merging, so this team-authored request should remain open.

## Change summary

Allow users to cancel the potentially long dependency-file search performed during Quick Create.

## Best solution

Make the dependency-search notification cancellable in `getProjectInstallable` and retain propagation of its cancellation token to every `findFiles` call, with unit coverage for both behaviors.
