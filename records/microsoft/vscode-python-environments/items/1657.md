[https://github.com/microsoft/vscode-python-environments/issues/1657](https://github.com/microsoft/vscode-python-environments/issues/1657)

## Summary

Verified duplicate: the workspace-relative value `.venv/bin/python` reaches the native finder without being resolved against the workspace, the same defect already tracked by the open canonical issue.

## Change summary

Enabling Python Environments fails to honor a workspace-level relative `python.defaultInterpreterPath` and reports that the valid interpreter cannot be resolved.

## Best solution

Consolidate on https://github.com/microsoft/vscode-python-environments/issues/1586 and land https://github.com/microsoft/vscode-python-environments/pull/1603, which resolves relative interpreter paths against their workspace before native resolution.
