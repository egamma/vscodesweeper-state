# Issue #1657 — Doesn't honor python.defaultInterpreterPath

[https://github.com/microsoft/vscode-python-environments/issues/1657](https://github.com/microsoft/vscode-python-environments/issues/1657)

## Summary

Still present on main: workspace-scoped relative defaultInterpreterPath values are passed to PET without resolving them against the workspace folder. Route this interpreter-selection bug to the environment area.

## Change summary

A workspace setting of python.defaultInterpreterPath using `.venv/bin/python` is rejected after enabling the Python Environments extension.

## Best solution

In `src/features/interpreterSelection.ts`, resolve non-absolute defaultInterpreterPath values against the scoped workspace folder before calling `nativeFinder.resolve`, preserving absolute and variable-expanded paths across platforms. Add coverage for POSIX and Windows-style relative paths.
