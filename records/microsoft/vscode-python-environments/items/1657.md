## Summary

Verified duplicate: current main passes the relative `.venv/bin/python` value to the native finder without resolving it against the workspace. The open canonical issue and its linked PR already cover this root cause.

## Change summary

A workspace-relative python.defaultInterpreterPath is ignored when the Python Environments extension is enabled.

Consolidate on https://github.com/microsoft/vscode-python-environments/issues/1586 and review or land https://github.com/microsoft/vscode-python-environments/pull/1603, which resolves relative interpreter paths against their workspace folder.
