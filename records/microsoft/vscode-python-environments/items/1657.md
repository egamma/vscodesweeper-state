# Issue #1657 — Doesn't honor python.defaultInterpreterPath

[https://github.com/microsoft/vscode-python-environments/issues/1657](https://github.com/microsoft/vscode-python-environments/issues/1657)

## Summary

Still present on current main: the workspace-scoped setting is read, but a relative value such as `.venv/bin/python` is passed to PET without first being resolved against the workspace folder. Routing this interpreter-selection bug to the environment area.

## Change summary

The extension should honor a workspace-relative `python.defaultInterpreterPath` instead of rejecting it and falling back to another environment.

## Best solution

In `src/features/interpreterSelection.ts`, resolve a relative `defaultInterpreterPath` against the scoped workspace folder before calling `NativePythonFinder.resolve`, while preserving absolute paths and existing variable expansion. Add coverage for bare POSIX and Windows-relative interpreter paths.
