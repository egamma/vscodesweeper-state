# Issue #1500 — python.terminal.executeInFileDir no longer uses "cd" to switch the working directory

[https://github.com/microsoft/vscode-python-environments/issues/1500](https://github.com/microsoft/vscode-python-environments/issues/1500)

## Summary

Still present on current main: the file directory is applied only when creating the dedicated terminal, so a reused terminal retains any directory selected manually. Route this source-reproducible regression to the terminal area.

## Change summary

Running a file again with python.terminal.executeInFileDir enabled no longer restores the file's directory in a reused terminal.

## Best solution

Honor python.terminal.executeInFileDir on every execution by applying a shell-appropriate directory change before launching Python, rather than only setting the terminal's initial cwd. The reused dedicated terminal should also be revealed consistently when execution starts.
