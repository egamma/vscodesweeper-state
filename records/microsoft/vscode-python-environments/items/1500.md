# Issue #1500 — python.terminal.executeInFileDir no longer uses "cd" to switch the working directory

[https://github.com/microsoft/vscode-python-environments/issues/1500](https://github.com/microsoft/vscode-python-environments/issues/1500)

## Summary

Still present on main: the configured file directory is used only when creating the dedicated terminal, so subsequent runs reuse that terminal without restoring its working directory.

## Change summary

Re-running a Python file no longer changes a reused dedicated terminal back to the file's directory when python.terminal.executeInFileDir is enabled.

## Best solution

Before each dedicated-terminal execution, restore the configured working directory using shell-appropriate syntax, then reveal and run in that terminal; terminal creation alone cannot enforce the directory after users run cd.
