# Issue #1613 — Allow workspace to opt-in/out of environment providers.

[https://github.com/microsoft/vscode-python-environments/issues/1613](https://github.com/microsoft/vscode-python-environments/issues/1613)

## Summary

A real configuration gap remains: workspaces can select a default manager but cannot prevent irrelevant managers from participating in discovery. This team-authored request is protected from judgment closes and should remain open for design and implementation.

## Change summary

Allow each workspace to opt environment providers such as Conda, Poetry, and venv in or out of discovery.

## Best solution

Add a resource-scoped provider allowlist or denylist and honor it wherever managers are queried or refreshed, including multi-root workspaces and third-party managers. Preserve registration of the extensibility API providers while avoiding discovery work for managers disabled in a particular workspace.
