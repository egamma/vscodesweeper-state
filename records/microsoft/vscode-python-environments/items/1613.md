# Issue #1613 — Allow workspace to opt-in/out of environment providers.

[https://github.com/microsoft/vscode-python-environments/issues/1613](https://github.com/microsoft/vscode-python-environments/issues/1613)

## Summary

This team-authored feature request addresses a real gap: workspaces can select default managers and search paths, but cannot prevent irrelevant providers from performing discovery. It should remain open for design and implementation.

## Change summary

Allow each workspace to enable or disable specific environment providers so irrelevant managers do not consume discovery resources.

## Best solution

Add a resource-scoped provider allow/deny setting keyed by stable manager IDs, and apply it to workspace discovery and refresh operations while preserving registration for built-in and third-party API providers.
