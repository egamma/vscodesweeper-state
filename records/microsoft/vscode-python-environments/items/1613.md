# Issue #1613 — Allow workspace to opt-in/out of environment providers.

[https://github.com/microsoft/vscode-python-environments/issues/1613](https://github.com/microsoft/vscode-python-environments/issues/1613)

## Summary

This is a valid, currently unmet workspace-scoped configuration request. Route it to the environment and API areas because provider filtering must cover built-in and externally registered managers.

## Change summary

Allow each workspace to enable or disable environment providers so irrelevant managers do not consume discovery resources.

## Best solution

Add a resource-scoped provider allow/deny setting and consistently apply it when querying, refreshing, and displaying registered environment managers, including managers contributed through the public API.

## Evidence

- **missing setting:** package.json defines python-envs.defaultEnvManager and resource-scoped workspace search paths, but no setting that enables or disables particular environment managers.
- **current behavior:** src/features/pythonApi.ts queries every registered manager for global/all environment requests, while src/extension.ts refreshes every entry in envManagers.managers.
