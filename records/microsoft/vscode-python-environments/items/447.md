# Issue #447 — Polish recommending Envs in Configure Python Env Tool

[https://github.com/microsoft/vscode-python-environments/issues/447](https://github.com/microsoft/vscode-python-environments/issues/447)

## Summary

Keep this team-authored, accepted proposal open: workspace-local venv selection already exists, but first-start recommendations across conda, Poetry, and pyenv are not covered by the same automatic-selection flow. The Configure Python Environment tool also crosses into the core Python extension, so the remaining behavior needs a coordinated maintainer proposal.

## Change summary

Prefer existing project-associated environments when configuring Python, including environments managed by conda, Poetry, and pyenv.

## Best solution

Define when an existing project-associated environment should be selected automatically versus recommended for confirmation, while preserving explicit user selections and settings. Coordinate this extension's environment-resolution policy with the Configure Python Environment tool in microsoft/vscode-python; a maintainer can transfer the tool-specific portion there if appropriate.
