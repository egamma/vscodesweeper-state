# Issue #447 — Polish recommending Envs in Configure Python Env Tool

[https://github.com/microsoft/vscode-python-environments/issues/447](https://github.com/microsoft/vscode-python-environments/issues/447)

## Summary

A real recommendation gap remains for project-local conda, Poetry, pyenv, and similar environments. This team-authored issue is accepted work under `needs proposal`, so it must remain open while the selection policy is designed.

## Change summary

Improve initial environment configuration so existing project-local environments are selected or recommended instead of considering only the default environment manager.

## Best solution

Define a proposal for ranking discovered project-local environments across supported managers, then apply it to initial selection and the environment picker while preserving explicit project, manager, and interpreter settings. Workspace `.venv` behavior already covers one case; the proposal should specify precedence and ambiguity handling for conda, Poetry, pyenv, and other registered managers.
