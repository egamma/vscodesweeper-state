# Issue #489 — Environment Manager -> Set as Project Environment should pre-select the environments it's already used in

[https://github.com/microsoft/vscode-python-environments/issues/489](https://github.com/microsoft/vscode-python-environments/issues/489)

## Summary

This accepted, team-authored feature request remains necessary: the multi-project picker supports initial selections internally, but the command does not identify or preselect projects already using the environment. The existing `needs PR` label requires keeping it open.

## Change summary

Preselect projects already using an environment when opening Set As Project Environment, and reset projects whose preselected entries are unchecked.

## Best solution

Resolve each project's current environment before opening the picker, pass matching projects as its initial selection, and compare the submitted selection with that initial set. Apply the environment to newly selected projects and restore the default environment for deselected projects.
