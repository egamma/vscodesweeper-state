# Issue #489 — Environment Manager -> Set as Project Environment should pre-select the environments it's already used in

[https://github.com/microsoft/vscode-python-environments/issues/489](https://github.com/microsoft/vscode-python-environments/issues/489)

## Summary

This accepted feature request remains necessary on current main: the project picker does not pre-select projects already using the environment or reset projects that are deselected. The `needs PR` label and team authorship independently require keeping it open.

## Change summary

When assigning an environment from the Environment Managers view, pre-select projects already using it and reset any that the user deselects.

## Best solution

Extend the multi-project picker to accept initial selections derived from each project's current environment, then reconcile the submitted selection by assigning the environment to newly selected projects and applying the existing reset-to-default behavior to deselected projects.
