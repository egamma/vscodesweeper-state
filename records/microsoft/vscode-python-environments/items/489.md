# Issue #489 — Environment Manager -> Set as Project Environment should pre-select the environments it's already used in

[https://github.com/microsoft/vscode-python-environments/issues/489](https://github.com/microsoft/vscode-python-environments/issues/489)

## Summary

This accepted feature request remains necessary on current main: the project picker does not preselect projects already using the chosen environment. The team-authored issue carries `needs PR`, so it should remain open for implementation.

## Change summary

Preselect projects already using an environment in the Set As Project Environment picker, and reset deselected projects to their default environment.

## Best solution

Extend the multi-project picker to accept the projects currently mapped to the selected environment as its initial selection, then treat deselection as an explicit reset to the default environment.
