[https://github.com/microsoft/vscode-python-environments/issues/367](https://github.com/microsoft/vscode-python-environments/issues/367)

## Summary

Keep open: this team-authored, milestone-assigned request is accepted with `needs PR`, and the package-installation recovery flow remains absent from current main. The prior fixing PR was closed without merging.

## Change summary

When Quick Create creates a venv but package installation fails, preserve and register the environment while offering a guided retry with selected dependencies.

## Best solution

Implement the agreed venv-specific recovery flow: distinguish creation from package-installation failure, report the partial success, and let the user select dependencies or packages to install into the created environment.
