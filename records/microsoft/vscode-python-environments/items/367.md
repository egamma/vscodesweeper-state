# Issue #367 — Quick Create fails to install packages

[https://github.com/microsoft/vscode-python-environments/issues/367](https://github.com/microsoft/vscode-python-environments/issues/367)

## Summary

Keep open: this team-authored, milestone-assigned request is accepted with `needs PR`, and the requested package-installation recovery flow remains absent on current main. The prior implementation attempt was closed without merging.

## Change summary

When Quick Create creates a venv but dependency installation fails, retain and resolve the environment while letting the user select a smaller dependency set and retry installation.

## Best solution

After successful venv creation and failed package installation, surface the partial success and offer a localized action that opens package selection for the newly created environment. Preserve the environment and install only the dependencies selected during that recovery flow.
