# Issue #367 — Quick Create fails to install packages

[https://github.com/microsoft/vscode-python-environments/issues/367](https://github.com/microsoft/vscode-python-environments/issues/367)

## Summary

Keep this accepted recovery-flow request open: current source preserves the created environment after package installation fails, but does not offer the requested dependency-selection retry. The assigned backlog milestone independently bars closing, and the linked implementation PR was closed without merging.

## Change summary

Provide manager-specific Quick Create recovery that retains a successfully created venv and lets the user select dependencies to retry installation, or restart creation when no environment was created.

## Best solution

Complete the venv manager's agreed recovery experience: distinguish creation failure from package-installation failure, retain and expose the created environment, and offer dependency selection targeting that same environment. Preserve each other manager's ownership of its recovery behavior.
