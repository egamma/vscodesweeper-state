# Issue #591 — New File hints

[https://github.com/microsoft/vscode-python-environments/issues/591](https://github.com/microsoft/vscode-python-environments/issues/591)

## Summary

Keep open: the existing project-template command does not make new-file hints language-relevant or provide an actionable Python snippet. The backlog milestone protects this item from closure, and needs spike marks accepted work rather than an abandoned request.

## Change summary

Make hints in newly created Python files less cluttered and more actionable, potentially by offering a Python script template as a snippet.

## Best solution

Separate generic empty-file hint filtering from a Python-specific template contribution: a maintainer can transfer the generic editor behavior to microsoft/vscode, while deciding whether this extension should expose its script template as a file-template snippet. Preserve ordinary Python-file creation without requiring project scaffolding.
