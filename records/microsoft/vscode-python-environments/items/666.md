## Summary

Keep open: this team-authored, accepted feature request still has `needs PR`. Current main detects broken virtual environments and permits removal, but provides no repair or recreation command.

## Change summary

Provide a repair workflow for virtual environments broken when their base Python installation is replaced or upgraded.

## Best solution

Add a safe repair action for broken venvs that recreates the environment against an available interpreter and restores its dependencies where possible. Build on the existing broken-environment detection and removal UI rather than requiring users to diagnose and rebuild manually.
