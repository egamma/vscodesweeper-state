This accepted feature request remains necessary: current main detects and displays broken virtual environments but only offers removal, not repair. Keep it open and route it to environment lifecycle ownership.

## Change summary

Provide a repair workflow for virtual environments broken when their base Microsoft Store Python installation is upgraded or removed.

## Best solution

Add a venv repair action that uses an available compatible Python installation to rebuild the environment in place while preserving the project association and, where feasible, restoring its package requirements. The implementation should drive Python's supported venv behavior rather than manually rewriting environment internals.
