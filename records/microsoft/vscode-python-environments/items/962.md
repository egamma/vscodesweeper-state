# Issue #962 — Experimental roll out shell startup as default

[https://github.com/microsoft/vscode-python-environments/issues/962](https://github.com/microsoft/vscode-python-environments/issues/962)

## Summary

This team-authored rollout initiative remains incomplete: current main supports shell-startup activation but still defaults to command activation. Its existing terminal and activation labels already route it appropriately.

## Change summary

Make shell-startup activation reliable and sufficiently tested before rolling it out as the default activation mode.

## Best solution

Complete the reliability refactoring and cross-shell coverage, retain command activation as a fallback for unsupported or unconfigured shells, then change the default activation type from `command` to `shellStartup` through a controlled rollout.
