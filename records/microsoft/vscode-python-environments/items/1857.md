## Summary

The directory-read defect remains present on main, and an open linked PR addresses it. Keep this issue open until that work lands; the separate expectation that python.envFile suppress project .env loading remains unresolved.

## Change summary

A virtual environment directory named .env is read as an environment-variable file, causing terminal injection and Pylance environment-variable reads to fail.

## Best solution

Review and land https://github.com/microsoft/vscode-python-environments/pull/1865 to skip directory paths while preserving valid environment-file loading. Separately settle whether an explicit python.envFile should suppress project .env loading, since the PR intentionally preserves the current loading order.
