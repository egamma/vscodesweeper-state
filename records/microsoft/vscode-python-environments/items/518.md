# Issue #518 — Select environment for project created with template if no new venv creation

[https://github.com/microsoft/vscode-python-environments/issues/518](https://github.com/microsoft/vscode-python-environments/issues/518)

## Summary

The gap remains on current main: declining venv creation does not open an environment picker for the new project. Route this aligned request to the environment area.

## Change summary

Allow users who decline venv creation during project-template setup to select an existing environment for the new project.

## Best solution

After creating the project without a new venv, reuse the existing environment-selection flow with the new project's URI and persist the choice through EnvironmentManagers.setEnvironment; apply this consistently across applicable template creators.
