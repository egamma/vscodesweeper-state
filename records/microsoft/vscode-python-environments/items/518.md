# Issue #518 — Select environment for project created with template if no new venv creation

[https://github.com/microsoft/vscode-python-environments/issues/518](https://github.com/microsoft/vscode-python-environments/issues/518)

## Summary

Keep open: declining virtual-environment creation still does not offer an existing-environment picker within the template flow. The separate environment-selection command is a workaround, not coverage of this team-authored request, and no verified canonical owns the same ask.

## Change summary

Offer selection of an existing environment during project creation from a template when the user declines creating a new virtual environment.

## Best solution

Let users associate the newly created project with an existing venv or global Python before completing the interactive template flow, while retaining the separate project environment-selection command.

- **Reason:** Selecting an existing environment during project creation supports the extension's per-project environment model without replacing community environment managers.
