# Issue #518 — Select environment for project created with template if no new venv creation

[https://github.com/microsoft/vscode-python-environments/issues/518](https://github.com/microsoft/vscode-python-environments/issues/518)

## Summary

Keep open: this is a team-authored feature request in the Python Projects/template flow, and the current code only auto-resolves or lets users set the environment after creation rather than offering an environment picker during the no-new-venv path.

## Change summary

When creating a project from a template without creating a new virtual environment, let the user choose which existing environment/global Python to associate with the new project.

## Best solution

Add an explicit environment-selection step to the template project creation flow when the user declines new venv creation and multiple candidate environments exist, reusing the existing project environment picker/set logic where possible.
