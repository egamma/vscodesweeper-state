# Issue #518 — Select environment for project created with template if no new venv creation

[https://github.com/microsoft/vscode-python-environments/issues/518](https://github.com/microsoft/vscode-python-environments/issues/518)

## Summary

A real workflow gap remains on current main: declining virtual-environment creation does not offer an existing-environment picker, and the protected team-authored request has no factual-close basis.

## Change summary

Allow users who decline creating a new virtual environment during project-template creation to select an existing environment for the project.

## Best solution

Extend the package-template flow so declining new-environment creation opens the existing project-environment picker and persists that selection through EnvironmentManagers.setEnvironment; retain the existing post-creation Set Project Environment command as a fallback.
