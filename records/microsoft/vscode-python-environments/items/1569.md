# Issue #1569 — Ignoring change watch events misses fast re-creation events and leaves environment state stale

[https://github.com/microsoft/vscode-python-environments/issues/1569](https://github.com/microsoft/vscode-python-environments/issues/1569)

## Summary

The defect remains on current main: activation and package watchers explicitly discard change events, so coalesced delete/create operations leave environment or package state stale. Route this actionable bug to the environment and package areas.

## Change summary

Refresh environment and package state when watched files are atomically replaced and reported as change events.

## Best solution

Subscribe the activation and package watchers to change events and trigger their existing debounced refresh paths, with tests covering create, delete, and change notifications.
