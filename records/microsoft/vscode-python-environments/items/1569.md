# Issue #1569 — Ignoring change watch events misses fast re-creation events and leaves environment state stale

[https://github.com/microsoft/vscode-python-environments/issues/1569](https://github.com/microsoft/vscode-python-environments/issues/1569)

## Summary

Still present on current main: both the environment and package watchers explicitly suppress change events, so a delete/create sequence coalesced into CHANGED leaves cached state stale. Route this confirmed defect to the environment and package areas.

## Change summary

Refresh environment and package state when watched files are rapidly replaced and the filesystem reports only a change event.

## Best solution

Subscribe both watcher paths to change events and pass them through their existing 500 ms debounce, preserving the current create/delete handling while covering coalesced atomic replacements.
