# Issue #194 — Simple requirements.txt check in package install flow

[https://github.com/microsoft/vscode-python-environments/issues/194](https://github.com/microsoft/vscode-python-environments/issues/194)

## Summary

Keep open: the package-install flow still does not offer to record newly installed packages in the root requirements.txt. This is accepted, team-authored work, and an open referencing PR independently bars a close.

## Change summary

After installing packages through the extension, offer to add them to an existing root requirements.txt.

## Best solution

Provide an opt-in post-install prompt that records the successfully installed packages without overwriting existing requirements. Coordinate this remaining behavior with the open dependency-file discovery PR; displaying dependency files alone does not fulfill the request.
