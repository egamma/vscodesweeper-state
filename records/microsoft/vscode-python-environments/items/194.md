## Summary

Keep open: this team-authored feature request is accepted into the proposal stage, and current package installation does not offer to record newly installed packages in a root requirements.txt.

## Change summary

After installing packages through the extension, offer to add those packages to the project's root requirements.txt.

## Best solution

Develop the requested proposal for the package-management flow, defining when an opt-in requirements.txt update should be offered and how versions, duplicates, multi-root projects, and manager-owned manifests are handled. The implementation should prompt only after a successful applicable install and preserve existing file contents and formatting.
