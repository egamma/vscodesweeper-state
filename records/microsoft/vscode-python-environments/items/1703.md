# Issue #1703 — [Python Environments] Conda environments discovered twice with different path casing on Windows (Miniconda3 vs miniconda3)

[https://github.com/microsoft/vscode-python-environments/issues/1703](https://github.com/microsoft/vscode-python-environments/issues/1703)

## Summary

The evidence isolates the duplicate discovery to PET itself: `pet find --list` emits eight entries for four physical environments. Keep this open for a maintainer to transfer to the PET tracker rather than closing it here.

## Change summary

PET reports Windows conda environments twice when the install path's on-disk casing differs from its lowercase well-known-location probe.

## Best solution

Fix path identity handling in microsoft/python-environment-tools so Windows paths are normalized to their on-disk casing before results from different conda discovery sources are merged. This extension could additionally de-duplicate PET results defensively, but PET should emit one environment per physical prefix.
