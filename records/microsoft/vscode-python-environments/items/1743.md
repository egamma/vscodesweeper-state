# Issue #1743 — Latest Python version is not being used by default

[https://github.com/microsoft/vscode-python-environments/issues/1743](https://github.com/microsoft/vscode-python-environments/issues/1743)

## Summary

Current main can select a previously persisted global interpreter for Quick Create instead of the latest discovered Python, contradicting the documented behavior. This team-authored issue should remain open and route to the environment area.

## Change summary

Quick Create defaults to macOS system Python 3.9 even when newer discovered Homebrew interpreters are available.

## Best solution

Make the venv Quick Create candidate the highest valid Python 3 version from the current global environments while preserving the persisted global interpreter for selection and activation flows. Ensure the displayed Quick Create version and the interpreter passed to venv creation use the same candidate.
