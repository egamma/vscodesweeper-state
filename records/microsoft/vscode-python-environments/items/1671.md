# Issue #1671 — VS Code discovers Conda environments but Python: Select Interpreter does not display them

[https://github.com/microsoft/vscode-python-environments/issues/1671](https://github.com/microsoft/vscode-python-environments/issues/1671)

## Summary

The confirmed compatibility-adapter defect has been fixed on the core Python extension's main branch. Conda environments without Python are now skipped without aborting delivery of the remaining environments to the interpreter and Jupyter pickers.

## Change summary

A Conda environment without Python caused all later valid Conda environments in the discovery batch to disappear from interpreter and kernel pickers.

## Best solution

Use the fix merged in https://github.com/microsoft/vscode-python/pull/26112, which preserves no-Python environments in Environment Manager while excluding them safely from Python interpreter lists and isolating malformed entries per item.
