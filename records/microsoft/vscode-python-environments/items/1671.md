# Issue #1671 — VS Code discovers Conda environments but Python: Select Interpreter does not display them

[https://github.com/microsoft/vscode-python-environments/issues/1671](https://github.com/microsoft/vscode-python-environments/issues/1671)

## Summary

Fixed on the core Python extension's current main: a no-Python Conda environment could abort compatibility-adapter conversion and prevent all later valid environments from reaching the interpreter picker.

## Change summary

Conda environments discovered by Python Environments were missing from Python and Jupyter pickers when the discovery batch contained an environment without Python.

## Best solution

Keep the per-item fault isolation and no-Python filtering merged in microsoft/vscode-python so non-interpreter Conda environments remain manageable without blocking valid interpreters from Python and Jupyter pickers.
