# Issue #272 — Hide Add Python Project context menu item if already selected as Python Project

[https://github.com/microsoft/vscode-python-environments/issues/272](https://github.com/microsoft/vscode-python-environments/issues/272)

## Summary

The menu-visibility defect remains on current main, and the attempted fix was explicitly found insufficient after the issue reopened. The assigned backlog milestone and `verification-found` status independently require keeping this team-authored issue open while the `needs proposal` UX decision is resolved.

## Change summary

Hide or replace the Add as Python Project action when the selected file or folder is already a project, without preventing users from adding a nested project.

## Best solution

Define a resource-specific project-management flow that distinguishes an exact project root from a file or folder merely contained by another project. The proposal should either expose the appropriate add/remove action for the selected resource or use a stable Manage as Python Project entry, while preserving the existing Add as Python Project wording for eligible resources.
