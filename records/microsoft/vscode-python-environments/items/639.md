# Issue #639 — Conda environment activation does not work for R terminals

[https://github.com/microsoft/vscode-python-environments/issues/639](https://github.com/microsoft/vscode-python-environments/issues/639)

## Summary

Still present on current main: command-mode activation targets every visible non-PTY terminal, so an R executable terminal receives `conda activate` as R input. Route this confirmed bug to Conda terminal activation.

## Change summary

Opening an R terminal injects the selected Conda environment's shell activation command into the R console instead of activating the environment before R starts.

## Best solution

Prevent command activation from being sent to terminals whose executable is not a supported shell, while preserving activation for ordinary shell terminals. Supporting silent Conda activation for R likely requires passing the selected environment into the terminal before the R process launches, coordinated with the R extension.
