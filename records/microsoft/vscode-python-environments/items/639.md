# Issue #639 — Conda environment activation does not work for R terminals

[https://github.com/microsoft/vscode-python-environments/issues/639](https://github.com/microsoft/vscode-python-environments/issues/639)

## Summary

Keep open: the existing activation modes do not establish support for launching R/radian terminals inside the selected conda environment. The linked core-extension issue explains the removal of environment-variable activation, but is not a concrete canonical for restoring this R workflow.

## Change summary

Restore launching R terminals inside the selected conda environment without sending shell activation commands to the R prompt.

## Best solution

Define how extension-created R/radian terminals can inherit the selected conda environment before their process starts, coordinating with the R extension and the core Python extension where necessary. Preserve ordinary shell activation and prevent shell commands from being submitted to an R interpreter.
