# Issue #639 — Conda environment activation does not work for R terminals

[https://github.com/microsoft/vscode-python-environments/issues/639](https://github.com/microsoft/vscode-python-environments/issues/639)

## Summary

Keep open: existing activation settings do not provide the requested silent conda activation before R starts. Related historical issues explain the integration boundary but neither establish a fix nor provide an open canonical covering the full request.

## Change summary

Restore launching R or radian terminals inside the selected conda environment without sending shell activation commands to the R prompt.

## Best solution

Decide a supported pre-launch environment-inheritance contract between Python Environments and the R terminal creator, coordinated with the core Python extension's retired environment-variable activation experiment. Preserve ordinary shell activation while ensuring shell commands are not injected into an R interpreter.

The August 6 follow-up reports persistence with this extension disabled, so ownership cannot be assigned solely to this repository.
- **Existing-capability check:** package.json contributes python-envs.terminal.autoActivationType with command, shellStartup, and off. package.nls.json restricts shellStartup to supported shells, not R. The registered python-envs.createTerminal command calls createTerminalCommand in src/features/envCommands.ts, which creates a Python terminal; it does not intercept R-console creation. Turning activation off avoids injection but does not deliver an activated R environment.
- **Current activation path:** src/features/terminal/terminalManager.ts handles terminal-open events and invokes autoActivateOnTerminalOpen. src/features/terminal/utils.ts:535-539 excludes hidden and PTY terminals, not ordinary R terminals. src/features/common/shellDetector.ts has no R/radian detection and can fall back to the platform shell; src/features/terminal/terminalActivationState.ts runCommand sends activation text when shell integration is absent. These paths do not establish silent activation before an R process starts.
