# Issue #1866 — Poetry package actions can misidentify their target environment

[https://github.com/microsoft/vscode-python-environments/issues/1866](https://github.com/microsoft/vscode-python-environments/issues/1866)

## Summary

The reported production-code probe confirms wrong-environment installation and package attribution; current remote main still leaves the project/UI route unchecked. Route this team-authored report to package management; the newer Poetry mismatch guard protects tool calls, not the reported route.

## Change summary

Project-scoped Poetry package actions can modify environment B while presenting package results and change events as belonging to selected environment A.

## Best solution

Ensure project-scoped Poetry installation and package queries honor their selected environment or clearly reject an incompatible pairing before modifying another environment. Preserve normal matched Poetry operations and intentional project manifest updates.
