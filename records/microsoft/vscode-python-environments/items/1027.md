# Issue #1027 — launching a local integrated terminal from wsl will look for linux location for venv

[https://github.com/microsoft/vscode-python-environments/issues/1027](https://github.com/microsoft/vscode-python-environments/issues/1027)

## Summary

Confirmed and still evident on main: a local PowerShell terminal opened from WSL can receive activation for the workspace's Linux environment. This team-authored issue must remain open until a referenced fix lands.

## Change summary

Opening a local integrated PowerShell terminal from a WSL workspace attempts to activate the WSL virtual environment using its Linux path.

## Best solution

Before auto-activation, distinguish local terminals from terminals belonging to the remote WSL workspace and avoid applying an environment whose location is incompatible with the terminal host. Add coverage for opening local PowerShell from WSL.
