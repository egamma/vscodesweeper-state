# Issue #1027 — launching a local integrated terminal from wsl will look for linux location for venv

[https://github.com/microsoft/vscode-python-environments/issues/1027](https://github.com/microsoft/vscode-python-environments/issues/1027)

## Summary

Still actionable: the reporter confirmed the WSL-to-local-PowerShell failure on a current release, and main still sends the WSL environment's activation command directly to the local terminal. Keep open and route to the WSL and PowerShell terminal areas.

## Change summary

Creating a local PowerShell terminal from a WSL workspace attempts to activate the environment using its Linux venv path.

## Best solution

Make terminal creation and activation account for whether the terminal and selected environment belong to compatible local or remote execution contexts. A local PowerShell terminal must not receive a Linux activation-script path from a WSL environment.
