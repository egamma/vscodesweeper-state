# Issue #1583 — CMD shell startup integration overwrites user's existing `HKCU\...\Command Processor\AutoRun` registry value

[https://github.com/microsoft/vscode-python-environments/issues/1583](https://github.com/microsoft/vscode-python-environments/issues/1583)

## Summary

The destructive overwrite remains on current main: CMD setup replaces the complete user AutoRun value, while teardown never restores it. This team-authored issue should remain open for implementation.

## Change summary

CMD shell startup integration destroys an existing user-configured AutoRun command and leaves its own registry entry behind during teardown.

## Best solution

Preserve existing AutoRun content by adding the extension-owned command as an idempotent segment, then remove only that segment during teardown. Cover empty, reordered, and mixed-content values with pure string-transformation unit tests.
