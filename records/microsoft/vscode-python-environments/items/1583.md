# Issue #1583 — CMD shell startup integration overwrites user's existing `HKCU\...\Command Processor\AutoRun` registry value

[https://github.com/microsoft/vscode-python-environments/issues/1583](https://github.com/microsoft/vscode-python-environments/issues/1583)

## Summary

Current main conclusively overwrites existing CMD AutoRun configuration and leaves the replacement behind during teardown. This team-authored, source-reproducible data-loss bug should remain open and be routed to CMD terminal activation.

## Change summary

CMD shell integration destroys an existing user AutoRun registry value instead of preserving and chaining it.

## Best solution

Change `cmdStartup.ts` to merge the extension-owned command with existing AutoRun content idempotently, then surgically remove only that command during teardown. Cover empty, reordered, and mixed-content values with pure transformation tests.
