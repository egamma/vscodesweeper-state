[https://github.com/microsoft/vscode-python-environments/issues/1583](https://github.com/microsoft/vscode-python-environments/issues/1583)

## Summary

Confirmed on current main: CMD activation replaces the complete user-level AutoRun value and teardown never restores it. Keep this team-authored issue open and route it to CMD terminal activation.

## Change summary

Preserve existing CMD AutoRun commands when installing shell activation and remove only the extension-owned command during teardown.

## Best solution

Introduce pure merge/remove transformations for the extension-owned AutoRun segment, use them when updating the registry, and cover ordering, idempotency, empty values, and teardown preservation with unit tests.
