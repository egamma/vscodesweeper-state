## Change summary

Enabling Python Environments prevents Python Envy from switching interpreters between nested Poetry projects in a monorepo.

## Best solution

Define and implement an interoperability path that lets Python Envy select environments for nested project scopes through the Python Environments API, coordinated with https://github.com/microsoft/vscode-python-environments/issues/970. Verify navigation-driven switching across nested Poetry projects without weakening this extension's per-project environment model.
