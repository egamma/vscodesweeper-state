## Change summary

Enabling the Python Environments extension prevents Python Envy from switching interpreters between nested monorepo projects.

## Best solution

Define and implement the compatibility path for extensions such as Python Envy that update interpreter selection through the core Python extension API, likely across `area-api` and the vscode-python integration seam. The proposal should determine whether the core API must bridge these updates into this extension or Python Envy should adopt the published Python Environments API, then validate editor-driven switching among nested `.venv` projects.
