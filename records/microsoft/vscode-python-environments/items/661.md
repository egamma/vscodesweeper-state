## Summary

Keep open: the issue is accepted under `needs proposal`, has an assigned milestone, and tracks a recognized compatibility regression with Python Envy. The report lacks enough detail to reproduce the conflict, but both hard keep-open rules override the normal needs-info path.

## Change summary

Enabling Python Environments prevents Python Envy from switching interpreters between nested Poetry projects in a monorepo.

## Best solution

Define and implement compatibility between scoped environment selection in this extension and Python Envy's interpreter-switching integration, ensuring the most specific project environment remains effective as users navigate files. Coordinate this with the broader extension-compatibility work in https://github.com/microsoft/vscode-python-environments/issues/970.
