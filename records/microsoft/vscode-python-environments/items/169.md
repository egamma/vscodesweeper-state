# Issue #169 — Leverage execution.exitCode for execution promise resolve

[https://github.com/microsoft/vscode-python-environments/issues/169](https://github.com/microsoft/vscode-python-environments/issues/169)

## Summary

Keep open: shell-execution completion already resolves before the timeout, but current main still ignores exitCode and treats failed or interrupted activation commands as successful. This team-authored, accepted debt item remains necessary; the related implementation attempt was closed without merging.

## Change summary

Use terminal shell-execution completion and exit codes to distinguish successful, failed, interrupted, and indeterminate activation or deactivation.

## Best solution

Complete outcome handling in TerminalActivationImpl so known command failures do not produce successful activation or deactivation state changes. Preserve the existing early-completion listener and timeout cleanup, and establish the intended treatment of undefined exit codes and timeouts.
