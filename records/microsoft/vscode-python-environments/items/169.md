# Issue #169 — Leverage execution.exitCode for execution promise resolve

[https://github.com/microsoft/vscode-python-environments/issues/169](https://github.com/microsoft/vscode-python-environments/issues/169)

## Summary

The accepted terminal-activation debt remains on current main: shell execution completion is observed, but its exit code is ignored and activation state is updated even after a failed command. The issue is team-authored and labeled `needs PR`, so it should remain open.

## Change summary

Use terminal shell execution exit codes to finish activation and deactivation promptly and distinguish successful commands from failures or interruptions.

## Best solution

Update the shell-integration execution path in `src/features/terminal/terminalActivationState.ts` to propagate `TerminalShellExecutionEndEvent.exitCode`, retain the timeout fallback for unavailable completion data, and change activation state only after confirmed success. Add focused tests covering zero, nonzero, undefined, interrupted, and timed-out executions.
