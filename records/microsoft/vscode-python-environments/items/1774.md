## Summary

Keep open: the discussion establishes a concrete folderless onboarding workflow where interpreter selection silently fails until a folder is opened and trusted. Current source does not establish that this is fixed; the supplied steps suffice to retest, and the trust-boundary concern requires maintainer handling.

Investigate the selection and extension-enablement boundary with the core Python extension and VS Code; a maintainer can transfer this to the owning tracker once that boundary is confirmed.
