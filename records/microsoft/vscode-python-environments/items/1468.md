# Issue #1468 — VS Code not selecting environment in .venv/ on open with Environments extension installed

[https://github.com/microsoft/vscode-python-environments/issues/1468](https://github.com/microsoft/vscode-python-environments/issues/1468)

## Summary

Fixed and shipped: the extension no longer writes manager defaults globally, and affected profiles received a one-time migration removing the stale system-manager setting.

## Change summary

A globally persisted system environment-manager setting prevented automatic selection of a workspace's .venv environment.

## Best solution

Keep the global-write prevention from commit 1eb7b677fea420125fece06462d7320dfcfb2774 and treat the cleanup migration in a4ca6282790a5d7fb1ffc7c0068c477a8e689ea1, shipped in 1.34.0, as completing the fix for affected users.
