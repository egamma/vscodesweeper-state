# Issue #186 — Built-in venv manager should detect `.py` files with inline metadata, add them as projects.

[https://github.com/microsoft/vscode-python-environments/issues/186](https://github.com/microsoft/vscode-python-environments/issues/186)

## Summary

A real gap remains: current main detects valid PEP 723 scripts only for telemetry and does not register them as Python projects. This team-authored, accepted `needs spike` item should remain open as the detection stage of the broader PEP 723 work.

## Change summary

Automatically detect Python files containing valid PEP 723 inline metadata and add each file as a Python project.

## Best solution

Connect PEP 723 metadata detection to the project manager so eligible workspace scripts are registered as file-based Python projects, while preserving explicit limits and deduplication. Coordinate this stage under the broader tracker at https://github.com/microsoft/vscode-python-environments/issues/185.
