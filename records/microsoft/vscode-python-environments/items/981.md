# Issue #981 — Configure environment via VSCode settings?

[https://github.com/microsoft/vscode-python-environments/issues/981](https://github.com/microsoft/vscode-python-environments/issues/981)

## Summary

A real configuration gap remains: project settings can declare managers but cannot persist the selected environment. The issue already has the correct type and area labels, so it should remain open.

## Change summary

Allow repositories to declaratively map Python projects to selected environments through VS Code settings.

## Best solution

Extend `python-envs.pythonProjects` with a portable environment identifier or path that registered managers can resolve at startup, including per-project mappings in monorepos and multi-root workspaces.

## Vision fit

- **Fit:** aligned
- **Reason:** Declarative per-project environment selection directly advances the Python Projects and environment-selection themes.
- **Evidence:** `docs/design.md` defines Python projects as files or folders connected to environments and explicitly supports workspace-to-environment relationships including monorepos and multi-root workspaces.

## Evidence

- **settings schema:** `package.json` defines `python-envs.pythonProjects` entries with only `path`, `envManager`, and `packageManager`; there is no selected-environment field.
- **current persistence:** `docs/startup-flow.md` states that selected environment paths are read from private workspace state and that startup caches selections without writing them to settings.
- **partial existing capability:** `src/features/interpreterSelection.ts` supports `python.defaultInterpreterPath` per workspace folder, but it is lower priority than `pythonProjects` manager configuration and does not provide a per-project environment mapping within one workspace folder.
- **related request:** https://github.com/microsoft/vscode-python-environments/issues/1480 requested the same settings-based mapping but was closed solely by the automated community-upvote policy, not because the capability exists or was declined on its merits.
