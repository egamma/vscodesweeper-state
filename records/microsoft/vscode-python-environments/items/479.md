# Issue #479 — "Auto find" could be in the same quickpick

[https://github.com/microsoft/vscode-python-environments/issues/479](https://github.com/microsoft/vscode-python-environments/issues/479)

## Summary

The accepted UX improvement remains unimplemented on current main. The `needs PR` label and team-authored requirement both require keeping it open.

## Change summary

Automatically discover projects and include them in the project-selection quick pick instead of presenting a separate Auto Find action that can fail.

## Best solution

Run project discovery before constructing the project-selection quick pick, merge discovered projects into its items, and omit Auto Find when discovery produces no new candidates.
