# Issue #479 — "Auto find" could be in the same quickpick

[https://github.com/microsoft/vscode-python-environments/issues/479](https://github.com/microsoft/vscode-python-environments/issues/479)

## Summary

This accepted project-picker improvement remains necessary on current main: Auto Find is always offered separately and still produces an error when its workspace scan finds nothing. The existing `needs PR` label protects the accepted work from cleanup closure.

## Change summary

Automatically surface discoverable Python projects in the project-selection flow and avoid offering Auto Find when it cannot find anything.

## Best solution

Implement the maintainer-agreed first step by determining whether eligible projects exist before composing the project-creator picker and omitting Auto Find when none are available; the broader one-picker experience can surface discovered projects directly without an error-producing intermediate choice.
