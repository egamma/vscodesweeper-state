# Issue #189 — Rebuild environment when metadata changes

[https://github.com/microsoft/vscode-python-environments/issues/189](https://github.com/microsoft/vscode-python-environments/issues/189)

## Summary

Keep open: this team-authored, accepted spike still represents an unresolved PEP 723 lifecycle decision. Current main can derive a new cache key from changed dependencies, but it does not yet connect saved metadata changes to invalidating and rebuilding or reselecting the script environment.

## Change summary

Rebuild or replace a script-specific environment when its PEP 723 inline metadata changes.

## Best solution

Complete the PEP 723 lifecycle tracked by https://github.com/microsoft/vscode-python-environments/issues/1602: detect saved metadata identity changes, invalidate the script association, and either rebuild automatically or deliberately return the setup CodeLens, then publish the per-file environment change. The spike should settle that UX before implementation is considered complete.
