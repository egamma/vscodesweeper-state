# Issue #1666 — Path-only pythonProjects entries crash manager initialization

[https://github.com/microsoft/vscode-python-environments/issues/1666](https://github.com/microsoft/vscode-python-environments/issues/1666)

## Summary

The defect remains directly traceable on main, but open PR https://github.com/microsoft/vscode-python-environments/pull/1667 references this issue and supplies a targeted fix and regression test, so the issue must remain open pending that PR.

## Change summary

Path-only pythonProjects entries cause manager-setting helpers to dereference omitted optional properties instead of falling back to configured defaults.

## Best solution

Review and land https://github.com/microsoft/vscode-python-environments/pull/1667, which makes the internal manager properties optional, safely falls back to default managers, and adds coverage for path-only nested projects.
