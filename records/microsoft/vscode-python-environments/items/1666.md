# Issue #1666 — Path-only pythonProjects entries crash manager initialization

[https://github.com/microsoft/vscode-python-environments/issues/1666](https://github.com/microsoft/vscode-python-environments/issues/1666)

## Summary

The defect remains directly reproducible from current source, but open PR https://github.com/microsoft/vscode-python-environments/pull/1667 references and fixes this issue. Keep the issue open while that implementation candidate is reviewed.

## Change summary

Path-only pythonProjects entries cause manager-setting helpers to dereference omitted envManager and packageManager properties instead of falling back to the configured defaults.

## Best solution

Review and land https://github.com/microsoft/vscode-python-environments/pull/1667, which makes the project-level manager properties optional, safely falls back to the default manager settings, and adds focused regression coverage.
