# Issue #1281 — Support `uv run` as an optional default run action.

[https://github.com/microsoft/vscode-python-environments/issues/1281](https://github.com/microsoft/vscode-python-environments/issues/1281)

## Summary

Keep open: current settings and inline-script work do not provide the requested optional uv run action for Run Python File and debugging. The request has exceeded the community-feedback threshold, and the execution/debugging boundary warrants coordinated planning with the core Python and Python Debugger extensions.

## Change summary

Allow an optional uv run-based default for running and debugging Python files, including scripts with or without inline dependencies.

## Best solution

Provide an opt-in execution mode that delegates script execution to uv while preserving interpreter-based execution by default and supporting debugger breakpoints. A maintainer can transfer this to microsoft/vscode-python for ownership of the Run action, coordinating environment execution metadata here and debugging support with microsoft/vscode-python-debugger.
