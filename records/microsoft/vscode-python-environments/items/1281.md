# Issue #1281 — Support `uv run` as an optional default run action.

[https://github.com/microsoft/vscode-python-environments/issues/1281](https://github.com/microsoft/vscode-python-environments/issues/1281)

## Summary

A real capability gap remains: current main has no setting that makes Run Python File or debugging invoke `uv run`, and the request has exceeded the community-feedback threshold with 47 upvotes. The newer inline-script environment work provides a related environment-based solution but does not implement the requested configurable run action.

## Change summary

Provide an opt-in default execution mode that runs Python files and debugger sessions through `uv run`, including PEP 723 scripts.

## Best solution

Coordinate the execution-setting portion with microsoft/vscode-python, which owns the green-triangle and debugger entry points, so one opt-in consistently affects running and debugging. Keep it distinct from https://github.com/microsoft/vscode-python-environments/issues/1602 unless the team explicitly decides that extension-managed per-script environments fully replace direct `uv run` support.
