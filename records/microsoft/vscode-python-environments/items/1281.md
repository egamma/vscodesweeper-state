# Issue #1281 — Support `uv run` as an optional default run action.

[https://github.com/microsoft/vscode-python-environments/issues/1281](https://github.com/microsoft/vscode-python-environments/issues/1281)

## Summary

This is a specific case of the open PEP 723 umbrella issue, whose design discussion already considers an optional uv-native backend and coordinated Run/F5 support. Proposing a duplicate close while preserving this report's strong community signal and debugging requirement.

## Change summary

Allow Python files, including debugger launches, to use `uv run` as a configurable default action for PEP 723 scripts.

## Best solution

Consolidate the request into https://github.com/microsoft/vscode-python-environments/issues/185 and coordinate with the core Python extension, which owns the Run button and Python debugger launch path. The design should retain the 46-upvote signal and evaluate an opt-in uv-native execution backend that works for scripts with or without inline dependencies.
