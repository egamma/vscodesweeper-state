# Issue #1281 — Support `uv run` as an optional default run action.

[https://github.com/microsoft/vscode-python-environments/issues/1281](https://github.com/microsoft/vscode-python-environments/issues/1281)

## Summary

A real capability gap remains: current main always launches the editor Run action through the selected environment's Python executable and offers no `uv run` setting. The request exceeded the community-feedback threshold with 46 upvotes, but delivering Run/F5 support requires coordination with the core Python extension, so it should remain open.

## Change summary

Allow Python files, particularly PEP 723 scripts, to use `uv run` as an optional default editor Run and debugging action.

## Best solution

Coordinate with microsoft/vscode-python so its Run/F5 paths can select a runner such as `uv run`, while this extension supplies the PEP 723 environment/project integration tracked by https://github.com/microsoft/vscode-python-environments/issues/185. The setting should remain optional and preserve normal selected-interpreter execution for other projects.
