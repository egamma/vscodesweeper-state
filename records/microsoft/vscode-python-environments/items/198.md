# Issue #198 — terminal.launchArgs not being used

[https://github.com/microsoft/vscode-python-environments/issues/198](https://github.com/microsoft/vscode-python-environments/issues/198)

## Summary

Still present on current main: the run-in-terminal commands pass only the script path and never read `python.terminal.launchArgs`. Routing this confirmed compatibility gap to the terminal area.

## Change summary

Running a Python file through the Environments extension ignores configured `python.terminal.launchArgs`.

## Best solution

Read `python.terminal.launchArgs` with the file or project URI as configuration scope in `src/features/envCommands.ts`, then prepend those arguments to the script path for both regular and dedicated terminal commands. Add coverage for user, workspace, and workspace-folder values.
