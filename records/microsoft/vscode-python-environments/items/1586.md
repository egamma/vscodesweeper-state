# Issue #1586 — python.defaultInterpreterPath fails to resolve ${workspaceFolder} correctly on Windows and may duplicate the workspace path

[https://github.com/microsoft/vscode-python-environments/issues/1586](https://github.com/microsoft/vscode-python-environments/issues/1586)

## Summary

The Windows path-resolution defect remains traceable on current main, but an open PR directly implements and tests fixes for both the unexpanded variable and duplicated relative-path symptoms. Keep the issue open while that implementation candidate is reviewed.

## Change summary

A workspace-scoped python.defaultInterpreterPath can retain ${workspaceFolder} or be resolved from the wrong working directory on Windows, producing an invalid duplicated path.

## Best solution

Review and land https://github.com/microsoft/vscode-python-environments/pull/1603, which adds a safe single-workspace fallback for variable expansion and resolves relative interpreter paths against the owning workspace before invoking the native finder.
