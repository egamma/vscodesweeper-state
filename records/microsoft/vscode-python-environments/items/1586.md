# Issue #1586 — python.defaultInterpreterPath fails to resolve ${workspaceFolder} correctly on Windows and may duplicate the workspace path

[https://github.com/microsoft/vscode-python-environments/issues/1586](https://github.com/microsoft/vscode-python-environments/issues/1586)

## Summary

The path-resolution defect remains visible in current source, but open PR https://github.com/microsoft/vscode-python-environments/pull/1603 directly addresses both reported symptoms. Keep the issue open while that implementation is reviewed.

## Change summary

Workspace-scoped default interpreter paths can retain `${workspaceFolder}` or resolve relative to the wrong directory on Windows, producing an invalid duplicated workspace path.

## Best solution

Review and land https://github.com/microsoft/vscode-python-environments/pull/1603, which adds a safe single-workspace fallback for variable expansion and resolves relative interpreter paths against the owning workspace folder.
