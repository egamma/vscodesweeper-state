# Issue #1043 — Add ability to exclude Python Environment from Python Extension

[https://github.com/microsoft/vscode-python-environments/issues/1043](https://github.com/microsoft/vscode-python-environments/issues/1043)

## Summary

A real capability gap remains: current settings and environment-selection paths provide no way to exclude known interpreter paths. This team-authored request is accepted for proposal work and must remain open.

## Change summary

Allow workspace or container configuration to exclude specified Python environments from discovery and selection across consuming extensions.

## Best solution

Design a workspace-scoped exclusion setting and apply it centrally to environment discovery/API results so Python, Jupyter, and other consumers consistently omit configured paths, ideally avoiding unnecessary discovery work as well.
