# Issue #1043 — Add ability to exclude Python Environment from Python Extension

[https://github.com/microsoft/vscode-python-environments/issues/1043](https://github.com/microsoft/vscode-python-environments/issues/1043)

## Summary

This remains an accepted design request: maintainers reconfirmed that environment exclusion should be handled by the Python Environments extension, and the current extension has no setting or shared filtering behavior that provides it. The team-authored issue is labeled `needs proposal`, so it should remain open while the filtering semantics are designed.

## Change summary

Allow configured Python executable paths to be excluded from environment discovery and selection surfaces, including consumers such as Jupyter.

## Best solution

Design a scoped exclusion setting in this extension and apply normalized path matching at the shared environment aggregation layer so the picker, Environments view, and API consumers receive a consistent filtered set. The proposal should define workspace versus machine scope, behavior for an already-selected or default interpreter, and compatibility with Jupyter's existing exclusion setting.
