# Issue #1043 — Add ability to exclude Python Environment from Python Extension

[https://github.com/microsoft/vscode-python-environments/issues/1043](https://github.com/microsoft/vscode-python-environments/issues/1043)

## Summary

This accepted, team-authored proposal remains necessary: current main exposes every discovered environment without a centralized exclusion setting. The `needs proposal` label also marks it as staged work that must remain open.

## Change summary

Allow configured Python executable paths to be excluded consistently from environment discovery consumers, pickers, and views.

## Best solution

Define a path-normalized exclusion setting and apply it at the shared Python Environments API boundary so this extension, the core Python extension, and Jupyter receive the same filtered environment set. The proposal should specify configuration scope, path matching, and how exclusions interact with selected or default interpreters.
