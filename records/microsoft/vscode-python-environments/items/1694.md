# Issue #1694 — Diagnose native Windows process exits (0xC0000142 / 0xC0000005 / 0xC0000409) seen in extension telemetry

[https://github.com/microsoft/vscode-python-environments/issues/1694](https://github.com/microsoft/vscode-python-environments/issues/1694)

## Summary

Keep open: this team-authored diagnostic tracker remains necessary because current telemetry identifies PET's native exit status but cannot attribute it to the in-flight operation or latest discovery phase. The issue is explicitly an investigation blocked on cohort data, and the maintainer discussion defines actionable pre-failure instrumentation.

## Change summary

Diagnose low-volume native Windows PET exits by correlating process termination with privacy-safe request and progress breadcrumbs.

## Best solution

Retain this as the diagnosis tracker while the extension records the active PET RPC, elapsed time, and latest refresh progress when the child exits; use the resulting cohort data to determine whether a separate PET or extension fix is warranted. Do not rely on panic hooks or crash-time JSON-RPC notifications for native structured exceptions and fail-fast termination.
