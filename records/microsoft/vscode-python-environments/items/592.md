# Issue #592 — Diagnose Issues with Copilot

[https://github.com/microsoft/vscode-python-environments/issues/592](https://github.com/microsoft/vscode-python-environments/issues/592)

## Summary

The requested one-click, context-rich Copilot diagnosis remains missing from current main. This accepted request carries needs proposal; route it to environment and package owners for a design that resolves the chat-session integration.

## Change summary

Add a Diagnose with Copilot action to relevant errors that opens contextual assistance with the failed command, logs, environment details, and useful tools.

## Best solution

Provide an error-to-chat handoff for environment and package failures without leaving diagnostic-mode files in the workspace. Coordinate any required chat capabilities with microsoft/vscode while retaining this extension's responsibility for collecting context and exposing the action.
