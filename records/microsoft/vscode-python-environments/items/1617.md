# Issue #1617 — No way to configure corporate pip index URL for environment creation / package install UI on Windows

[https://github.com/microsoft/vscode-python-environments/issues/1617](https://github.com/microsoft/vscode-python-environments/issues/1617)

## Summary

A real configuration gap remains on main: package installation supports neither configurable index arguments nor a documented unified private-index path for pip and uv. Route this to package management.

## Change summary

Allow environment creation and package-install UI operations to use corporate Python package indexes.

## Best solution

Honor manager-native index configuration consistently for pip and uv, preferably through their configuration files or environment variables, and document the supported Windows setup. If explicit extension configuration is needed, pass it through every package-install path while avoiding credential exposure in settings and logs.
