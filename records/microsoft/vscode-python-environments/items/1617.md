# Issue #1617 — No way to configure corporate pip index URL for environment creation / package install UI on Windows

[https://github.com/microsoft/vscode-python-environments/issues/1617](https://github.com/microsoft/vscode-python-environments/issues/1617)

## Summary

A real configuration gap remains: package installation supports pip and uv but exposes no setting for private-index arguments. Existing environment inheritance offers only a partial workaround, so this should be routed to package and environment management.

## Change summary

Allow environment creation and package-install UI operations to use a configured private Python package index.

## Best solution

Honor each manager's native index configuration consistently and document it; if that cannot cover both pip and uv, add a manager-aware package-install argument setting and apply it to package installs performed during environment creation and from the Packages view.
