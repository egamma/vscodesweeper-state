# Issue #1401 — Possible to pass environment variables to eslint server?

[https://github.com/microsoft/vscode-eslint/issues/1401](https://github.com/microsoft/vscode-eslint/issues/1401)

## Summary

A real capability gap remains: the extension can set NODE_ENV but cannot pass arbitrary per-workspace variables such as API_TOKEN to the ESLint server. The existing Backlog and help-wanted classification is appropriate, and no open canonical owns the request.

## Change summary

Allow a workspace to provide arbitrary environment variables to the ESLint server so plugins can authenticate against external services.

## Best solution

Add a general workspace-scoped server-environment mechanism in the client alongside eslint.nodeEnv and merge it into the language-server launch options. Because the motivating value is an API credential, the design should avoid encouraging raw secrets in checked-in workspace settings and document when the server must be restarted.
