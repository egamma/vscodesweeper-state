# Issue #2129 — ESLint plugin breaks when using `eslint-plugin-react-hooks`

[https://github.com/microsoft/vscode-eslint/issues/2129](https://github.com/microsoft/vscode-eslint/issues/2129)

## Summary

The follow-up isolates a task-only diagnostic parsing defect: normal per-file validation works, while the whole-folder task loses diagnostics because it feeds ESLint's multiline stylish output through VS Code's line-oriented `$eslint-stylish` problem matcher. This should remain open and be routed with `depends-on-vscode` while the task integration or core matcher is corrected.

## Change summary

The `lint whole folder` task reports only a small subset of diagnostics when eslint-plugin-react-hooks emits multiline messages, although the same CLI invocation prints all diagnostics.

## Best solution

Track an enhancement to VS Code's `$eslint-stylish` problem matcher in `microsoft/vscode`, or change the extension's task integration to consume an output format that preserves multiline ESLint diagnostics. Keep this extension issue open until the task provider adopts or verifies that solution, since normal language-server validation already works.
