# Issue #1355 — ESLint can't be used as a formatter until the ESLint server is fully initialized.

[https://github.com/microsoft/vscode-eslint/issues/1355](https://github.com/microsoft/vscode-eslint/issues/1355)

## Summary

The startup race remains visible in current source: ESLint registers as a formatter only after configuration, library resolution, validation probing, and ignored-file checks complete. The maintainer explicitly kept the issue open for an improvement, and no separate open canonical owns it.

## Change summary

Make ESLint available as a document formatter promptly at workspace startup instead of temporarily reporting that the configured formatter cannot format the file.

## Best solution

Improve the formatter-registration lifecycle in `server/src/eslint.ts` so a configured document does not appear to lack its formatter while ESLint capability probing is still in progress, without advertising formatting for unsupported or ignored files. Add lifecycle coverage for a format request issued immediately after opening a document.
