# Issue #1355 — ESLint can't be used as a formatter until the ESLint server is fully initialized.

[https://github.com/microsoft/vscode-eslint/issues/1355](https://github.com/microsoft/vscode-eslint/issues/1355)

## Summary

Keep open: current source still registers ESLint formatting only after asynchronous per-document configuration and library resolution, leaving a startup window in which Format Document cannot use it. The maintainer acknowledged this initialization problem; the later configuration workarounds do not resolve that distinct defect.

## Change summary

Make ESLint formatting usable when invoked immediately after opening a supported document, rather than requiring the user to wait and retry after initialization.

## Best solution

Coordinate formatter availability and initialization in client/ and server/ so an early formatting invocation can complete once the document's ESLint support is established. Preserve configuration-dependent eligibility, ignored-file handling, and lazy activation; verify the first invocation in a cold-start editor session.

- **Behavior:**

- **Trace:**
