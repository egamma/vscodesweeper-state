# Issue #1501 — Cannot use "Format Modified Lines" command or modifications formatOnSaveMode

[https://github.com/microsoft/vscode-eslint/issues/1501](https://github.com/microsoft/vscode-eslint/issues/1501)

## Summary

Modified-lines formatting remains unsupported: current main registers only whole-document formatting and computes fixes against the entire document. Keep this accepted request open with its existing upstream label; no verified older canonical owns the same behavior.

## Change summary

Support ESLint autofixes restricted to version-control-modified lines through Format Modified Lines and editor.formatOnSaveMode, with clearer feedback when unsupported.

## Best solution

Establish a safe range-restricted fixing contract with eslint/eslint, then integrate it into the extension's server-side formatting provider without changing whole-document fix-all behavior. Preserve the maintainer-requested improvement to unsupported-formatting feedback as part of the remaining work.
