# Issue #1501 — Cannot use "Format Modified Lines" command or modifications formatOnSaveMode

[https://github.com/microsoft/vscode-eslint/issues/1501](https://github.com/microsoft/vscode-eslint/issues/1501)

## Summary

The requested modified-lines formatting remains unsupported: the extension exposes whole-document formatting and depends on ESLint's whole-file fix output. The existing `upstream` label correctly records the required ESLint capability, while extension-side adoption would still be needed afterward.

## Change summary

Allow ESLint formatting and fix-on-save to operate only on version-control-modified lines through VS Code's range-formatting surfaces.

## Best solution

ESLint first needs a range-aware fixing API that can safely compute fixes within a requested region. Once available, `server/` should register LSP range formatting, pass the requested range through to ESLint, and return only fixes produced under those range semantics; the formatter-unavailable message should also accurately explain the current limitation.

## Evidence

- **maintainer assessment:** The maintainer confirmed in https://github.com/microsoft/vscode-eslint/issues/1501 that this is unsupported because ESLint's fix operation formats the whole file rather than a region, while also acknowledging that the resulting error message should improve.
- **whole-document registration:** Current `server/src/eslint.ts` registers only `DocumentFormattingRequest` with `DocumentFormattingRegistrationOptions`; there is no `DocumentRangeFormattingRequest` registration.
- **whole-file fixing path:** Current `server/src/eslintServer.ts` handles `onDocumentFormatting` by calling `computeAllFixes`, which invokes `eslintClass.lintText` over the complete document with `fix: true` and diffs the complete original and fixed contents. No requested range enters this path.
- **existing capability check:** `eslint.format.enable` enables ESLint as a formatter, and `eslint.codeActionsOnSave.mode` / `.rules` control fix-all behavior, but none of these settings provides version-control-modified-line or arbitrary-range fixing.
