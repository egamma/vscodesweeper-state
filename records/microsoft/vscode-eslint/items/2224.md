# Issue #2224 — Disable rule quick fixes insert JS-style comments into Markdown files

[https://github.com/microsoft/vscode-eslint/issues/2224](https://github.com/microsoft/vscode-eslint/issues/2224)

## Summary

The defect is directly visible on current main: Markdown has no language-default entry, so disable-rule actions generate JavaScript comments that Markdown treats as text. Keep the issue open because the linked fixing PR is still under review.

## Change summary

Generate valid HTML-style ESLint disable comments for Markdown documents instead of JavaScript line or block comments.

## Best solution

Review and land https://github.com/microsoft/vscode-eslint/pull/2225, which adds Markdown comment metadata and makes disable actions fall back to block syntax when a language has no line-comment form; add focused coverage for line-level and file-level Markdown disable actions.
