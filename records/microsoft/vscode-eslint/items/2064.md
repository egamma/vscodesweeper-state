# Issue #2064 — FEAT: Use ESLint extension without auto run

[https://github.com/microsoft/vscode-eslint/issues/2064](https://github.com/microsoft/vscode-eslint/issues/2064)

## Summary

This is a valid, accepted feature gap: the extension can format with ESLint, but it cannot keep formatting available while disabling automatic diagnostic runs. The existing feature-request label and Backlog milestone are appropriate.

## Change summary

Allow ESLint to remain available as a manually invoked formatter without automatically linting on type or save.

## Best solution

Decouple formatter registration from diagnostic validation and add an explicit off or manual-only value to `eslint.run`, while preserving the existing `onType` and `onSave` defaults. Formatting requests should still execute ESLint when `eslint.format.enable` is enabled, without publishing background diagnostics.
