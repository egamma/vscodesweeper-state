# Issue #2064 — FEAT: Use ESLint extension without auto run

[https://github.com/microsoft/vscode-eslint/issues/2064](https://github.com/microsoft/vscode-eslint/issues/2064)

## Summary

The requested formatter-only mode remains unavailable: current settings allow validation on type or save, while disabling validation also prevents ESLint formatting. The accepted Backlog feature request should remain open.

## Change summary

Allow ESLint to run only for manually requested formatting, without continuous validation or diagnostics on typing, saving, or focusing a document.

## Best solution

Add a validation mode that suppresses automatic diagnostic pulls while keeping document formatting enabled, wiring it through the setting schema, shared settings type, client configuration, and diagnostic-pull filter without changing normal onType/onSave behavior.
