# Issue #1517 — Feature: show rule docs if available in an ESLint config file

[https://github.com/microsoft/vscode-eslint/issues/1517](https://github.com/microsoft/vscode-eslint/issues/1517)

## Summary

This remains a valid, accepted Backlog feature request: the extension can open rule documentation from a diagnostic code action, but it does not provide links or hovers for rule names inside ESLint configuration files.

## Change summary

Provide Ctrl/Cmd-click links or hover documentation for rule names in JSON and reasonably analyzable JavaScript ESLint configuration files.

## Best solution

Add configuration-file language features that recognize rule keys, resolve their metadata through the workspace ESLint installation, and expose documentation URLs through LSP document links and/or hovers. JSON and statically analyzable flat or legacy JavaScript configs can be supported incrementally without attempting to evaluate every dynamic configuration shape.
