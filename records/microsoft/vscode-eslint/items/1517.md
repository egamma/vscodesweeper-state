# Issue #1517 — Feature: show rule docs if available in an ESLint config file

[https://github.com/microsoft/vscode-eslint/issues/1517](https://github.com/microsoft/vscode-eslint/issues/1517)

## Summary

This remains a valid, accepted feature request: the extension can open rule documentation from diagnostics, but it does not provide rule-documentation links or hovers inside ESLint configuration files.

## Change summary

Provide Ctrl/Cmd-click links and/or hover documentation for rule names declared in ESLint configuration files.

## Best solution

Keep the existing diagnostic code action and add a configuration-file language feature that resolves configured rule names through ESLint metadata, initially for structurally parseable JSON configurations and potentially for straightforward JavaScript configurations. The implementation should preserve support for plugin rules and both legacy and flat configuration styles.
