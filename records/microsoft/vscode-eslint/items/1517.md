## Summary

This remains a valid, unimplemented feature request: the extension can open rule documentation from a diagnostic quick fix, but it does not provide links or hovers for rule names inside ESLint configuration files. No open canonical issue found in the required search owns this work.

## Change summary

Add Ctrl/Cmd-click links and/or hover documentation for rule names in JSON and statically analyzable JavaScript ESLint configuration files.

## Best solution

Keep the existing diagnostic quick fix and add an editor-facing document-link or hover provider for rule entries in supported ESLint configuration files, resolving URLs from ESLint rule metadata. Start with JSON configurations and treat JavaScript or flat configurations conservatively when rule names cannot be determined statically.
