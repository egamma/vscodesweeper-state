# Issue #2108 — /* eslint-disable-next-line no-unused-vars */  will disappear when save

[https://github.com/microsoft/vscode-eslint/issues/2108](https://github.com/microsoft/vscode-eslint/issues/2108)

## Summary

The supplied Vue/TypeScript configuration enables `@typescript-eslint/no-unused-vars` while disabling the core `no-unused-vars` rule, so the reported directive disables no active rule and ESLint removes it as unused during fix-on-save. This is a configuration question rather than an extension defect.

## Change summary

An inline directive for `no-unused-vars` is removed when saving Vue or TypeScript files with ESLint fixes enabled.

## Best solution

Use `/* eslint-disable-next-line @typescript-eslint/no-unused-vars */` so the directive targets the rule enabled by the project's recommended TypeScript configuration. The extension should continue applying the fix output returned by the workspace's ESLint installation.
