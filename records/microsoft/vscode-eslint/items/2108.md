## Change summary

Saving a Vue or TypeScript file removes an `eslint-disable-next-line no-unused-vars` directive that the reporter expects to suppress an unused-variable diagnostic.

## Best solution

Determine whether the workspace is actually reporting `no-unused-vars` or `@typescript-eslint/no-unused-vars`, and whether save-specific settings disable the relevant rule while ESLint checks unused directives. If `eslint.codeActionsOnSave.rules` is involved, use negative rule patterns or `eslint.codeActionsOnSave.options` so the save configuration does not incorrectly make the directive appear unused; an extension change is warranted only if the same workspace does not remove it under `eslint --fix`.
