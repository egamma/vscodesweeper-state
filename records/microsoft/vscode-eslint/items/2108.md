# Issue #2108 — /* eslint-disable-next-line no-unused-vars */  will disappear when save

[https://github.com/microsoft/vscode-eslint/issues/2108](https://github.com/microsoft/vscode-eslint/issues/2108)

## Summary

The supplied project enables `@typescript-eslint/no-unused-vars`, while the comment disables the different, inactive core rule `no-unused-vars`. ESLint therefore treats the directive as unused and removes it during fix-on-save; this is a configuration question rather than an extension defect.

## Change summary

An ESLint disable-next-line comment for `no-unused-vars` disappears when a Vue or TypeScript file is saved with fix-all enabled.

## Best solution

Use `/* eslint-disable-next-line @typescript-eslint/no-unused-vars */` in this TypeScript configuration, preferably by selecting the extension's disable-rule quick fix so the active rule ID is inserted automatically.
