# Issue #2108 — /* eslint-disable-next-line no-unused-vars */  will disappear when save

[https://github.com/microsoft/vscode-eslint/issues/2108](https://github.com/microsoft/vscode-eslint/issues/2108)

## Summary

The attached project was retested outside VS Code: ESLint itself removes the directive because it names the disabled base rule rather than the active TypeScript rule. This is a configuration question with verified solutions, not an extension defect or a duplicate of the first-letter deletion report.

## Change summary

Preserve an eslint-disable-next-line comment when saving a Vue or TypeScript file.

## Best solution

Use eslint-disable-next-line @typescript-eslint/no-unused-vars to suppress the rule actually enabled in the project. If the project instead intends to preserve unused directives, set linterOptions.reportUnusedDisableDirectives to 'off' in its flat configuration; no extension change is needed.
