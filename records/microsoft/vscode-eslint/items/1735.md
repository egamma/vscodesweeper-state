# Issue #1735 — Feature Request: print *something* when this plug-in is involved in a VS Code "Format Document" command

[https://github.com/microsoft/vscode-eslint/issues/1735](https://github.com/microsoft/vscode-eslint/issues/1735)

## Summary

Keep open: current formatting still lacks the requested concise, default output message; opt-in protocol tracing is only a workaround. The maintainer's objection concerns enabling debugging by default, not an established rejection of lightweight formatting feedback.

## Change summary

Print a concise message identifying the formatted file whenever ESLint handles Format Document, without requiring debug mode or protocol tracing.

## Best solution

Decide whether lightweight formatting feedback should appear by default, separately from verbose debugging. If accepted, the extension's server formatting path should report its participation accurately, including when no edits are needed, without enabling general protocol tracing.
