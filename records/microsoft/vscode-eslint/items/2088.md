# Issue #2088 — Request: add quick-fix action for adding same-line disables, i.e. `// eslint-disable-line`

[https://github.com/microsoft/vscode-eslint/issues/2088](https://github.com/microsoft/vscode-eslint/issues/2088)

## Summary

The existing setting supports same-line disables, but it replaces the separate-line action rather than offering both choices at invocation time. The requested additional quick fix remains missing, and the maintainer already accepted that this is distinct from automatic JSX-context detection.

## Change summary

Offer a separate same-line rule-disable quick fix alongside the existing separate-line and whole-file actions, without requiring a settings change.

## Best solution

Retain this request for a maintainer decision on exposing both line-disable actions in server/src/eslintServer.ts while preserving the existing setting and defaults. Automatic JSX comment-context detection is separate work and does not satisfy the requested explicit choice.
