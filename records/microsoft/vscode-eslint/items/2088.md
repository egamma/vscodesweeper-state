# Issue #2088 — Request: add quick-fix action for adding same-line disables, i.e. `// eslint-disable-line`

[https://github.com/microsoft/vscode-eslint/issues/2088](https://github.com/microsoft/vscode-eslint/issues/2088)

## Summary

The existing setting provides a global choice between same-line and separate-line comments, but the request is for both quick fixes to be available simultaneously so the user can choose per occurrence. That capability remains missing on current main, and the previously suggested #1074 concerns automatic JSX-context detection rather than this explicit choice.

## Change summary

Offer an additional quick fix that inserts `eslint-disable-line` without replacing the existing `eslint-disable-next-line` action.

## Best solution

Extend the server's code-action construction to expose distinct same-line and separate-line disable actions concurrently, while preserving the existing setting's behavior or evolving it compatibly. Keep https://github.com/microsoft/vscode-eslint/issues/1074 separate because automatic context detection is not required for this request.

- **Reason:** A context-sensitive disable choice directly advances the extension's established investment in rich ESLint code actions and fix workflows.
