# Issue #1074 — doesn't apply right fix comment in jsx/tsx context

[https://github.com/microsoft/vscode-eslint/issues/1074](https://github.com/microsoft/vscode-eslint/issues/1074)

## Summary

The context-sensitive JSX/TSX disable-comment capability remains missing on current main. This issue is the established canonical for that work and should remain open in its accepted On Deck state.

## Change summary

Generate JSX-compatible ESLint disable comments such as `{/* eslint-disable-next-line rule */}` when a diagnostic occurs inside JSX, while retaining normal JavaScript comments outside JSX.

## Best solution

Enhance the server-side code-action path to determine whether the diagnostic position is inside a JSX ESTree node, preferably using the parser already selected by ESLint, and generate the appropriate contextual comment without depending on VS Code-specific language services.
