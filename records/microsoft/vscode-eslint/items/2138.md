# Issue #2138 — ESLint version 10.0.3 only supports flat configs. Setting is ignored

[https://github.com/microsoft/vscode-eslint/issues/2138](https://github.com/microsoft/vscode-eslint/issues/2138)

## Summary

The spurious ESLint 10 flat-config message was fixed by merged PR https://github.com/microsoft/vscode-eslint/pull/2172 and no longer appears with default settings on current main.

## Change summary

Avoid reporting that a flat-config setting was ignored under ESLint 10 when the user did not explicitly configure that setting.

## Best solution

Treat the issue as fixed: current main only sends the experimental flat-config option when explicitly enabled and only logs the ESLint 10 message when a flat-config option was explicitly supplied.
