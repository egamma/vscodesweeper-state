# Issue #2138 — ESLint version 10.0.3 only supports flat configs. Setting is ignored

[https://github.com/microsoft/vscode-eslint/issues/2138](https://github.com/microsoft/vscode-eslint/issues/2138)

## Summary

The warning was caused by the client sending the default false value of `eslint.experimental.useFlatConfig` even when the user had not configured it. PR 2172 fixed that path and explicitly closed this issue, so the issue can be closed as completed.

## Change summary

Avoid logging that the flat-config setting is ignored under ESLint 10 when neither flat-config setting was explicitly configured.

## Best solution

Use the shipped behavior from commit https://github.com/microsoft/vscode-eslint/commit/5a2809ce452e41c84747b86a0334734e87e9c87b, which omits the experimental setting unless explicitly enabled and only logs the ESLint 10 notice for an explicitly supplied flat-config setting.
