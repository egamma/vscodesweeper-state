# Issue #2138 — ESLint version 10.0.3 only supports flat configs. Setting is ignored

[https://github.com/microsoft/vscode-eslint/issues/2138](https://github.com/microsoft/vscode-eslint/issues/2138)

## Summary

The spurious ESLint 10 flat-config warning was caused by the client forwarding the deprecated setting's default value even when the user had not configured it. PR https://github.com/microsoft/vscode-eslint/pull/2172 fixed that path, explicitly references this issue, and shipped beginning with pre-release 3.0.25.

## Change summary

Avoid logging that the flat-config setting is ignored under ESLint 10 when the user did not explicitly configure either flat-config setting.

## Best solution

Treat the issue as completed by the merged fix, which now omits `experimental.useFlatConfig` from the server settings unless it was explicitly enabled and only logs the ESLint 10 notice for an explicitly supplied flat-config setting.
