# Issue #1597 — Show editor ruler for `max-len` value

[https://github.com/microsoft/vscode-eslint/issues/1597](https://github.com/microsoft/vscode-eslint/issues/1597)

## Summary

VS Code's open editor-API request already owns the broader capability needed here: allowing extensions to change rulers for a particular editor. The ESLint `max-len` integration is a concrete use case for that core API, so this issue can be consolidated there.

## Change summary

Display an editor ruler at the column configured by ESLint's `max-len` rule while ESLint is active.

## Best solution

VS Code core should provide the per-editor ruler contribution API tracked by https://github.com/microsoft/vscode/issues/111251. Once available, this extension could consider reading the effective `max-len` configuration and contributing the corresponding ruler without reimplementing editor rendering.
