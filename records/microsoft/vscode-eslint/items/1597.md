# Issue #1597 — Show editor ruler for `max-len` value

[https://github.com/microsoft/vscode-eslint/issues/1597](https://github.com/microsoft/vscode-eslint/issues/1597)

## Summary

This remains a valid extension-side feature request that is blocked on a VS Code editor API. The linked core issue is still open, but it only supplies the required capability; this repository would still need to read the effective `max-len` configuration and use that API.

## Change summary

Display a per-editor ruler at the column configured by ESLint's effective `max-len` rule.

## Best solution

Keep this issue as the extension-side tracker for adopting the editor-ruler API requested in https://github.com/microsoft/vscode/issues/111251. Once available, the server should expose the effective `max-len` value for each document and the client should update the corresponding editor ruler without overriding unrelated user-configured rulers.
