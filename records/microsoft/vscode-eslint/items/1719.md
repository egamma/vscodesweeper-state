# Issue #1719 — Support basic formatting in hint popup for `no-restricted-*`

[https://github.com/microsoft/vscode-eslint/issues/1719](https://github.com/microsoft/vscode-eslint/issues/1719)

## Summary

Keep this accepted request open and add depends-on-vscode: formatted diagnostic messages remain blocked on VS Code support. The core request enables the capability, but does not by itself implement the extension's handling of custom ESLint messages.

## Change summary

Render clickable links and backtick-delimited code in diagnostic tooltips for custom no-restricted-* rule messages.

## Best solution

Track https://github.com/microsoft/vscode/issues/54272 as the platform dependency, then adopt the supported formatted-message representation in the extension's diagnostic pipeline. Preserve ordinary plain-text messages and rule-documentation links; retain this issue for the extension-side integration rather than closing it against the enabling core request.
