# Issue #1719 — Support basic formatting in hint popup for `no-restricted-*`

[https://github.com/microsoft/vscode-eslint/issues/1719](https://github.com/microsoft/vscode-eslint/issues/1719)

## Summary

VS Code diagnostics currently accept only plain-string messages, and the broader platform request for Markdown or formatted diagnostic content is already tracked by microsoft/vscode#54272. This extension request is therefore a cross-repository duplicate of that open canonical issue.

## Change summary

Render links, inline code, and other basic formatting in custom messages emitted by ESLint's `no-restricted-*` rules.

## Best solution

Add formatted diagnostic-message support to VS Code through https://github.com/microsoft/vscode/issues/54272; once the platform and protocol surfaces support structured content, this extension can preserve formatting from ESLint diagnostics rather than attempting to implement a separate hover renderer.
