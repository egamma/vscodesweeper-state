# Issue #1719 — Support basic formatting in hint popup for `no-restricted-*`

[https://github.com/microsoft/vscode-eslint/issues/1719](https://github.com/microsoft/vscode-eslint/issues/1719)

## Summary

This is a valid diagnostic-presentation request that is currently blocked on VS Code and LSP support for formatted diagnostic messages. It should remain open and be routed with `depends-on-vscode`; the linked VS Code issue enables the extension work but does not eliminate the need to adopt that capability here.

## Change summary

Render Markdown-style links and inline code from custom `no-restricted-*` rule messages in diagnostic hover popups.

## Best solution

Keep this issue as the extension-side adoption item, dependent on https://github.com/microsoft/vscode/issues/54272 and corresponding LSP support. Once available, update `server/src/eslint.ts` so `Diagnostics.create` can preserve explicitly formatted rule messages as safe markup while retaining plain strings for ordinary ESLint diagnostics.
