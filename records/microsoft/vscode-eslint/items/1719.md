## Summary

This remains a valid extension feature request, but it is blocked on VS Code and LSP diagnostics supporting formatted message content. Route it with `depends-on-vscode` and keep it open because the linked core issue enables, rather than fully owns, the extension-side work.

## Change summary

Render links and inline code formatting in custom messages emitted by `no-restricted-*` ESLint rules.

## Best solution

Keep this issue as the extension-side adoption item for https://github.com/microsoft/vscode/issues/54272.
