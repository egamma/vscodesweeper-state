# Issue #1366 — Support for VS Code for Web

[https://github.com/microsoft/vscode-eslint/issues/1366](https://github.com/microsoft/vscode-eslint/issues/1366)

## Summary

The extension still lacks a browser entry point on current main, so VS Code for the Web support remains a real feature gap. An open PR explicitly fixes this issue with limited browser support, which requires keeping the issue open while that implementation is reviewed.

## Change summary

Provide a browser-compatible ESLint extension that can lint files in vscode.dev, potentially with a reduced feature set.

## Best solution

Review and refine https://github.com/microsoft/vscode-eslint/pull/2159, clearly document which languages, rules, configuration files, plugins, and `eslint.*` settings are supported on the web, and land it once that compatibility boundary is acceptable.
