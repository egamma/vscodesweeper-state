# Issue #1366 — Support for VS Code for Web

[https://github.com/microsoft/vscode-eslint/issues/1366](https://github.com/microsoft/vscode-eslint/issues/1366)

## Summary

Web support remains absent from current main, but an open PR explicitly fixes this issue with a limited browser implementation. The issue must remain open while that implementation is under review.

## Change summary

Make the ESLint extension available in VS Code for the Web, potentially with a reduced feature set for browser-hosted workspaces.

## Best solution

Review and refine https://github.com/microsoft/vscode-eslint/pull/2159, clearly documenting which languages, configuration sources, plugins, and `eslint.*` settings are supported in the browser, then close this issue only after the implementation merges.
