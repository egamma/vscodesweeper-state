## Summary

The extension still lacks a browser entry point on `main`, but an open PR explicitly fixes this issue with limited web support. Keep the issue open while that implementation is reviewed and its supported feature set is clarified.

## Change summary

Make the ESLint extension available in VS Code for the Web, potentially with a reduced browser-compatible feature set.

## Best solution

Review and land https://github.com/microsoft/vscode-eslint/pull/2159 after defining and documenting which languages, ESLint features, configurations, plugins, and `eslint.*` settings work on desktop, web, or both.
