## Summary

Browser-hosted ESLint support remains absent from current main, and an open PR explicitly references this request. Keep the issue open while that implementation is reviewed, including the maintainer's requirement to clearly distinguish web and desktop capabilities.

## Change summary

Make the ESLint extension available in browser-only VS Code environments such as vscode.dev.
