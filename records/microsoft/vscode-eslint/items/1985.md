[https://github.com/microsoft/vscode-eslint/issues/1985](https://github.com/microsoft/vscode-eslint/issues/1985)

## Summary

Keep this accepted feature request open: working-directory patterns still select ESLint's execution directory rather than restrict which files are validated. The reporter's request to exclude unmatched root files remains uncovered, and the canonical search found no older open issue owning that behavior.

## Change summary

Allow a monorepo to lint only its configured package directories without probing root files or requiring a root ESLint configuration.

## Best solution

Provide an explicit, backward-compatible way to restrict editor validation to selected directory trees while retaining normal linting within packages. Resolve whether this accepted request should cover exclusion of unmatched files, arbitrary working-directory mappings, or both, since the reporter and maintainer described different outcomes.
