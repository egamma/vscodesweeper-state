# Issue #1985 — Could not find config file. - at assertConfigurationExists

[https://github.com/microsoft/vscode-eslint/issues/1985](https://github.com/microsoft/vscode-eslint/issues/1985)

## Summary

Keep this open as the canonical feature request for limiting ESLint activation by working-directory scope. The maintainer confirmed that `eslint.workingDirectories` currently selects a working directory only when it is a prefix of the document path and explicitly retained the issue as a feature request.

## Change summary

Allow monorepos to prevent ESLint validation for root files that fall outside every configured `eslint.workingDirectories` entry.

## Best solution

Extend the client-side per-document configuration logic in `client/src/client.ts` so users can explicitly treat configured working directories as an activation scope, while preserving the current directory-selection behavior by default. The setting schema in `package.json` and shared configuration types would need to expose that opt-in behavior.
