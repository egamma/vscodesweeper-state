# Issue #2205 — Show output channel on manual restart

[https://github.com/microsoft/vscode-eslint/issues/2205](https://github.com/microsoft/vscode-eslint/issues/2205)

## Summary

Keep open while the linked implementation is reviewed. The maintainer has favored preserving an already-visible output channel through the shared LSP client rather than adding an automatic-opening setting; that narrower behavior does not fully deliver the original request.

## Change summary

Optionally open the ESLint output channel after a manual server restart so users can inspect configuration-related logs.

## Best solution

Resolve the linked implementation through https://github.com/microsoft/vscode-eslint/pull/2206 and its shared-client dependency, https://github.com/microsoft/vscode-languageserver-node/pull/1849. Explicitly distinguish the proposed visibility-preservation behavior from opening a previously hidden channel when deciding whether the original request is satisfied.
