# Issue #2205 — Show output channel on manual restart

[https://github.com/microsoft/vscode-eslint/issues/2205](https://github.com/microsoft/vscode-eslint/issues/2205)

## Summary

The restart command currently logs completion without revealing the existing ESLint output channel, so the requested convenience remains a real client-side gap. Keep the issue open because an open PR directly references it and implements a less intrusive visibility-preserving variant.

## Change summary

Make the ESLint output channel available automatically after a user manually restarts the ESLint server, optionally behind a disabled-by-default setting.

## Best solution

Review https://github.com/microsoft/vscode-eslint/pull/2206 and decide whether preserving an already-visible output channel is sufficient or whether the requested opt-in setting should always reveal it after restart; keep the issue open until that implementation decision is resolved and the PR lands or closes.
