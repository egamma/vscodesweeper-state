# Issue #2205 — Show output channel on manual restart

[https://github.com/microsoft/vscode-eslint/issues/2205](https://github.com/microsoft/vscode-eslint/issues/2205)

## Summary

This remains an active feature request with an open implementation PR. Maintainer feedback favors preserving an already-visible output channel during restart at the shared LSP client layer rather than adding an ESLint-specific setting.

## Change summary

Make the ESLint output channel available after a manual server restart so users can immediately inspect configuration and startup logs.

## Best solution
