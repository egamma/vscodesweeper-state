# Issue #1955 — fixTypes requires meta.docs.url?

[https://github.com/microsoft/vscode-eslint/issues/1955](https://github.com/microsoft/vscode-eslint/issues/1955)

## Summary

Current main still discards rule metadata unless `meta.docs.url` is present, which prevents `fixTypes` from recognizing otherwise valid rule types. The maintainer agreed that this restriction can be relaxed, and the assigned `Next` milestone requires the issue to remain open.

## Change summary

Allow autofixes selected through `eslint.options.fixTypes` for rules that declare `meta.type` but omit `meta.docs.url`.

## Best solution

Update `RuleMetaData.capture` in `server/src/eslint.ts` to retain usable rule metadata independently of the optional documentation URL, while leaving `getUrl` optional. Add coverage proving that a fixable rule with `meta.type` and no `meta.docs.url` still produces a code action when its type is selected.
