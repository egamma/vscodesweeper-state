# Issue #1666 — Use from CLI?

[https://github.com/microsoft/vscode-eslint/issues/1666](https://github.com/microsoft/vscode-eslint/issues/1666)

## Summary

This remains a valid, accepted feature request: the extension has no supported way for lint-staged or another CLI process to reuse its running ESLint language server, and no open canonical issue was found.

## Change summary

Provide a CLI-accessible mechanism that lets pre-commit tooling lint changed files through the already-running VS Code ESLint server.

## Best solution

Design a supported bridge in the client/server integration for submitting file-based lint requests and returning CLI-appropriate results, with explicit lifecycle and trust handling. The existing lint-task feature is not sufficient because it launches a separate ESLint CLI process and therefore repeats initialization.
