# Issue #1898 — Restarting an extension when that extension's output is selected in the "Output" pane should not change which extension is selected in the "Output" pane.

[https://github.com/microsoft/vscode-eslint/issues/1898](https://github.com/microsoft/vscode-eslint/issues/1898)

## Summary

The requested lifecycle behavior remains unimplemented on current main: restarting the ESLint language client still uses its internally managed output channel, allowing the selected channel to change when that channel is disposed and recreated. A targeted fix was attempted in a closed, unmerged PR, so this accepted Backlog request should remain open.

## Change summary

Preserve the selected ESLint output channel when restarting the language server and avoid revealing or focusing the Output panel unexpectedly.

## Best solution

Have `client/` create and retain a shared `LogOutputChannel`, pass it through `LanguageClientOptions.outputChannel`, and preserve focus when explicitly showing it, based on the approach in https://github.com/microsoft/vscode-eslint/pull/2124. The behavior should cover both parts of the report: retaining the selected channel and not unexpectedly revealing or focusing the Output panel.
