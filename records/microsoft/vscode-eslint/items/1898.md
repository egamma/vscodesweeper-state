# Issue #1898 — Restarting an extension when that extension's output is selected in the "Output" pane should not change which extension is selected in the "Output" pane.

[https://github.com/microsoft/vscode-eslint/issues/1898](https://github.com/microsoft/vscode-eslint/issues/1898)

## Summary

The requested output-channel persistence remains absent from current main: restarting the language client still uses its internally managed output channel, which can be disposed and recreated. A directly targeted fix was developed but its PR closed without merging, so this accepted Backlog request remains necessary.

## Change summary

Keep ESLint selected in the Output pane when the ESLint language server is restarted, without revealing or focusing the pane unexpectedly.

## Best solution

Have client/ retain an extension-owned LogOutputChannel across LanguageClient restart cycles and pass it through LanguageClientOptions, while preserving focus when showing it. The closed implementation in https://github.com/microsoft/vscode-eslint/pull/2124 is a concrete starting point, but should be reviewed and landed through a new or reopened change.
