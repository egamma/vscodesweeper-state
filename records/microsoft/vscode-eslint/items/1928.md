# Issue #1928 — Configuration to use a formatter

[https://github.com/microsoft/vscode-eslint/issues/1928](https://github.com/microsoft/vscode-eslint/issues/1928)

## Summary

The extension still does not run a configured ESLint output formatter when producing editor diagnostics, so the reporter's lint-todo baseline cannot suppress diagnostics in VS Code. This is an accepted Backlog feature request with no verified canonical issue.

## Change summary

Allow ESLint formatter behavior such as @lint-todo/eslint-formatter-todo to influence which lint violations appear as VS Code diagnostics.

## Best solution

Keep the request open and design an extension-side, structured suppression integration in `server/` that preserves diagnostic ranges and code actions; arbitrary formatter text cannot directly replace LSP diagnostics. The newer ESLint bulk-suppression support is relevant for upgraded workspaces, but it does not cover this ESLint 8.24 formatter's due-date workflow.

## Evidence

- **maintainer confirmation:** The maintainer states in the issue that this is currently not possible because the extension does not print detected problems through an ESLint formatter, and suggests a manually triggered ESLint task only as a workaround.
- **current diagnostic path:** `server/src/eslint.ts` `validate()` calls `eslintClass.lintText()` and converts `docReport.messages` directly into LSP diagnostics with `Diagnostics.create`; it does not load or execute an ESLint formatter.
- **task workaround:** `client/src/tasks.ts` passes `eslint.lintTask.options` to an ESLint shell task, so `--format @lint-todo/eslint-formatter-todo` can be used for a manually run workspace task, but that task does not control live editor diagnostics.
- **existing suppression capability:** `package.json` and `server/src/eslint.ts` now expose `eslint.bulkSuppression.*` using ESLint's structured Node API, but the setting requires ESLint >= 10.1; the report specifically uses ESLint 8.24 and https://github.com/lint-todo/eslint-formatter-todo with warning/error due dates.
