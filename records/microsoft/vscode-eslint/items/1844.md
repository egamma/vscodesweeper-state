# Issue #1844 — cache files (`.eslintcache`) on save

[https://github.com/microsoft/vscode-eslint/issues/1844](https://github.com/microsoft/vscode-eslint/issues/1844)

## Summary

The cache capability remains absent from current main, and an open PR explicitly implements and closes this issue. The issue must remain open while that implementation candidate is under review.

## Change summary

Allow on-save validation to use ESLint's file-based caching so editor linting can share `.eslintcache` state with command-line and pre-commit runs.

## Best solution

Review and either land or close https://github.com/microsoft/vscode-eslint/pull/2120 after resolving its requested changes and merge conflicts, with particular care that file-based validation is used only when the saved disk content matches the document. Keep ordinary on-type and unsaved-buffer validation on `lintText`.
