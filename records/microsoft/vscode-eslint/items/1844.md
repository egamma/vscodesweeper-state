# Issue #1844 — cache files (`.eslintcache`) on save

[https://github.com/microsoft/vscode-eslint/issues/1844](https://github.com/microsoft/vscode-eslint/issues/1844)

## Summary

The cache capability remains absent from current main, and an open PR explicitly fixes this issue by adding cache settings and using `lintFiles` for save-time validation. The issue must remain open while that implementation candidate is under review.

## Change summary

Add optional ESLint result-cache support on save so editor linting can update and reuse the same cache as command-line and pre-commit linting.

## Best solution

Update, review, and land https://github.com/microsoft/vscode-eslint/pull/2120, preserving `lintText` for unsaved/on-type content while using `lintFiles` on save only when caching is enabled through explicit settings.
