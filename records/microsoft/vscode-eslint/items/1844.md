## Summary

Keep this feature request open because PR https://github.com/microsoft/vscode-eslint/pull/2120 explicitly references and implements it but has not merged. Current main still validates saved documents through `lintText`, so the requested cache support is not yet shipped.

## Change summary

Allow on-save validation to use ESLint's file-based linting and cache options so `.eslintcache` is consulted and updated for subsequent CLI and pre-commit runs.
