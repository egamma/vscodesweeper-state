# Issue #1805 — Do not lint outside current project workspace directory

[https://github.com/microsoft/vscode-eslint/issues/1805](https://github.com/microsoft/vscode-eslint/issues/1805)

## Summary

Keep open: the requested workspace-boundary option is absent from current main, and an open implementation PR explicitly references this issue. The maintainer accepted an opt-in approach while requiring the existing default behavior to remain unchanged.

## Change summary

Add an option to skip linting opened files outside the current workspace folders.

## Best solution

Review and resolve https://github.com/microsoft/vscode-eslint/pull/2227, which proposes eslint.ignoreOutsideWorkspace with a false default. Preserve existing standalone-file behavior and verify workspace-folder changes before landing the option.
