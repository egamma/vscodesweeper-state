# Issue #1733 — Feature Request: enable the "eslint.format.enable" setting by default.

[https://github.com/microsoft/vscode-eslint/issues/1733](https://github.com/microsoft/vscode-eslint/issues/1733)

## Summary

The formatter is intentionally opt-in because enabling it by default would make ESLint participate when users have selected another formatter and would break existing configurations. The maintainer has explicitly confirmed this design boundary, so the request can be closed as designed without adding a label outside the supplied candidate set.

## Change summary

Enable ESLint's VS Code formatter integration by default, or remove the setting and make it permanently enabled.

## Best solution

Keep `eslint.format.enable` disabled by default so users explicitly choose ESLint as a formatter without disrupting TypeScript, Prettier, or other formatter configurations. Any remaining discoverability problem should be addressed through clearer setup guidance rather than changing the default.

## Vision fit

- **Fit:** rejected
- **Reason:** Automatically activating ESLint as a formatter would interfere with VS Code's shared formatter surface and remove the user's explicit choice of formatting provider.
- **Evidence:** The vision's guardrail says to build on core platform surfaces rather than overriding them, while the formatter theme treats formatting integration as an opt-in capability.

- **Proposed comment:**

  > Thanks for the context. “Formatting pipelines” here refers to VS Code's formatter infrastructure, not the Azure Pipelines extension. Multiple extensions can provide formatting, and users select the provider they want—often per language—with `editor.defaultFormatter`. Enabling ESLint's formatter unconditionally would make it participate for users who intentionally use TypeScript, Prettier, or another formatter, and changing the existing default would break those configurations. For that reason, `eslint.format.enable` is intentionally opt-in; users who want ESLint formatting can enable it and select `dbaeumer.vscode-eslint` as their default formatter for the relevant languages.
