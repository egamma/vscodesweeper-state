## Summary

The enable/disable commands were intentionally removed in favor of VS Code's standard extension-management UI, and VS Code can now disable an extension without requiring a restart. The reporter confirms that this resolves the motivating friction and is comfortable with closing the request.

## Change summary

Restore commands that temporarily enable or disable ESLint so diagnostics can be hidden while writing and restored before committing.
