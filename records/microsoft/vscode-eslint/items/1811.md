# Issue #1811 — Feature request: bring back enable/disable eslint command

[https://github.com/microsoft/vscode-eslint/issues/1811](https://github.com/microsoft/vscode-eslint/issues/1811)

## Summary

The extension panel now provides the underlying disablement without requiring a restart, but no ESLint command offers the requested quick or temporary toggle. The maintainer explicitly classified this later request as a Backlog feature request and help-wanted contribution, so it should remain open despite the reporter considering it less important.

## Change summary

Provide an ESLint command that quickly pauses and resumes diagnostics while writing code.

## Best solution

Add a supported pause/resume command in `client/` that immediately clears or restores ESLint diagnostics without relying on the deprecated `eslint.enable` workflow, and expose it through the command palette in `package.json`. The implementation should preserve VS Code's extension-panel disablement as the persistent workspace-level control.
