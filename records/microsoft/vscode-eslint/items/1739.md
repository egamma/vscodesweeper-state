# Issue #1739 — Improve error message / feedback when a file can't be linted with ESLint when in probing mode

[https://github.com/microsoft/vscode-eslint/issues/1739](https://github.com/microsoft/vscode-eslint/issues/1739)

## Summary

Keep open: current probing still suppresses useful feedback on some failure paths, and the maintainer explicitly accepted unobtrusive informational logging. Existing settings and the verified related issues do not deliver that improvement.

## Change summary

Explain why ESLint probing cannot enable linting or formatting for a file, with actionable information in the ESLint output channel.

## Best solution

Provide informational output for unsuccessful probing in server/src/eslint.ts, explaining the applicable installation or configuration requirement without intrusive notifications. Preserve ESLint's configuration resolution and the maintainer's explicit rejection of a fallback configuration.
