# Issue #1739 — Improve error message / feedback when a file can't be linted with ESLint when in probing mode

[https://github.com/microsoft/vscode-eslint/issues/1739](https://github.com/microsoft/vscode-eslint/issues/1739)

## Summary

The maintainer accepted a low-noise informational message for failed probing, and current main still handles a generic probe failure silently. The feature request remains valid and appropriately parked in Backlog with feature-request and help wanted.

## Change summary

Log useful, non-disruptive feedback when probing determines that ESLint cannot lint or format a file.

## Best solution

Preserve probing's quiet UI behavior but write an informational ESLint output-channel entry explaining why the file was rejected and suggesting relevant configuration or installation steps. Do not choose or synthesize a fallback ESLint configuration, which the maintainer explicitly rejected as confusing.
