# Issue #1753 — Localize this extension using the Localization pipeline

[https://github.com/microsoft/vscode-eslint/issues/1753](https://github.com/microsoft/vscode-eslint/issues/1753)

## Summary

Keep open: extension-owned settings descriptions, commands, notifications, and code-action titles remain hard-coded in English. The related VS Code tracker was closed because extension-specific issues were created, not because ESLint localization shipped.

## Change summary

Localize the extension's user-facing strings through the VS Code extension localization pipeline.

## Best solution

Onboard this extension's manifest and runtime UI strings to the localization pipeline, including server-generated action titles and packaged translation resources. Preserve ESLint-provided messages and executable identifiers; first recover the current onboarding guidance and establish translation extraction, delivery, and locale-fallback requirements.
