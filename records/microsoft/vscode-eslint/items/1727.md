# Issue #1727 — Prefer to use node from environment

[https://github.com/microsoft/vscode-eslint/issues/1727](https://github.com/microsoft/vscode-eslint/issues/1727)

## Summary

Keep open: selecting the environment's Node by default, with bundled-runtime fallback, is not implemented. The maintainer has accepted considering a trusted-workspace setting, and the security-sensitive runtime choice requires human review.

## Change summary

Prefer the project's environment-provided Node runtime without repeated workspace configuration, falling back to VS Code's bundled runtime when unavailable.

## Best solution

Resolve a trust-aware runtime-selection policy in the extension's client, preserving explicit eslint.runtime overrides and compatibility for existing users. Evaluate https://github.com/microsoft/vscode-eslint/pull/1977 separately: its working-directory change addresses project-context resolution, not the requested default or fallback.
