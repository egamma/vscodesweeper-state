## Summary

Keep open: environment-aware Node selection with bundled-runtime fallback remains distinct from the existing explicit runtime override. The linked open implementation PR and the workspace-trust concern both require maintainer review rather than closure.

## Change summary

Prefer the project's environment-selected Node runtime, falling back to VS Code's bundled runtime when unavailable.
