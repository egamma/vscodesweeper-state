The requested minimal repository and ESLint output are needed to distinguish an ESLint fix from an interaction among the several enabled save providers.

Fix-on-save reportedly removes the first character of source code after upgrading the ESLint extension from 3.0.10 to 3.0.16 or 3.0.20.
