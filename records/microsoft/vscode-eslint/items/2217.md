# Issue #2217 — Add a vsix to the releases assets?

[https://github.com/microsoft/vscode-eslint/issues/2217](https://github.com/microsoft/vscode-eslint/issues/2217)

## Summary

Keep this feature request open: current releases contain no downloadable VSIX, and the maintainer has explicitly started investigating whether the release pipeline can upload one. The existing Backlog placement is appropriate while pipeline feasibility is assessed.

## Change summary

Attach the packaged VSIX to each GitHub release so users in environments without Marketplace access can obtain it from the project's official repository.

## Best solution

Extend the stable and pre-release Azure Pipelines flow to attach the already-built VSIX to the corresponding GitHub release, avoiding a separate build or unofficial distribution source. The implementation should cover both `release/*` and `pre-release/*` tags and keep Marketplace publishing unchanged.
