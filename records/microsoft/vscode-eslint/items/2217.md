## Summary

Keep open: the latest stable GitHub release has no VSIX attachment, so the requested first-party download remains unavailable. The maintainer has explicitly raised pipeline support, and no open canonical or implementation PR was found.

## Change summary

Attach the official extension VSIX to GitHub releases so users without Marketplace access can obtain it without third-party distribution.
