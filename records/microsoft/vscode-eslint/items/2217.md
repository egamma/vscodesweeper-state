# Issue #2217 — Add a vsix to the releases assets?

[https://github.com/microsoft/vscode-eslint/issues/2217](https://github.com/microsoft/vscode-eslint/issues/2217)

## Summary

The current GitHub releases do not provide a usable VSIX, and no other open issue owns this request. The maintainer is actively investigating pipeline support and the issue is accepted in Backlog, so it should remain open as a release-infrastructure feature request.

## Change summary

Attach the packaged VSIX to each GitHub release so users in environments without Marketplace access can obtain the extension from an official source.

## Best solution

Have the release pipeline automatically attach its generated VSIX to the corresponding stable or pre-release GitHub release, avoiding a separately maintained manual publishing path. The likely implementation belongs in the shared vscode-engineering release template or its parameters rather than in client/ or server/.
