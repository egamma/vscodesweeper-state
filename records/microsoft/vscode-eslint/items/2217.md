# Issue #2217 — Add a vsix to the releases assets?

[https://github.com/microsoft/vscode-eslint/issues/2217](https://github.com/microsoft/vscode-eslint/issues/2217)

## Summary

This is a valid distribution feature request for locked-down environments, and the maintainer is already investigating pipeline support. Current GitHub releases have no downloadable assets, and no other open issue owns the request.

## Change summary

Attach the extension's packaged VSIX to each GitHub release so it can be installed without access to the VS Code Marketplace.

## Best solution

Extend the stable and pre-release publishing pipelines, or their shared microsoft/vscode-engineering templates, to upload the exact VSIX produced for Marketplace publication as a GitHub release asset. The artifact should be attached to the corresponding `release/*` or `pre-release/*` tag to preserve provenance.
