# Issue #795 — Support specifying the shell to use for Lint task to avoid problems with bash under Windows.

[https://github.com/microsoft/vscode-eslint/issues/795](https://github.com/microsoft/vscode-eslint/issues/795)

## Summary

Shell selection is already possible through VS Code task customization, and a commenter confirmed that it resolves this problem. Keep this accepted Backlog request open for the maintainer to decide whether that support is sufficient: there is no extension-specific shell option or verified fixing commit, and a question/as-designed close would contradict the recorded acceptance.

## Change summary

Allow the contributed ESLint lint task to use a Windows-compatible shell independently of the user's interactive Bash terminal.

## Best solution

Document the working task-scoped options.shell override so users can retain Git Bash for interactive terminals while running the ESLint task through cmd.exe. The maintainer can then determine whether this satisfies the accepted request or whether an extension-specific shell selector remains warranted; replacing ShellExecution with ProcessExecution is not an established solution in the discussion.
