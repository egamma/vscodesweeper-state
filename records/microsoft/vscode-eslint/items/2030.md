# Issue #2030 — Loading flat config from the node_modules fails

[https://github.com/microsoft/vscode-eslint/issues/2030](https://github.com/microsoft/vscode-eslint/issues/2030)

## Summary

The ESLint CLI flag is being supplied through the wrong setting: `eslint.execArgv` configures the Node runtime, while a custom flat-config path belongs in `eslint.options.overrideConfigFile`. This is a configuration question rather than an extension defect.

## Change summary

Configure the extension to load a flat ESLint configuration exported by a dependency under `node_modules`.

## Best solution

Keep the existing settings behavior and configure `eslint.options.overrideConfigFile` with the absolute path to the dependency's config. `eslint.execArgv` should remain reserved for Node runtime arguments such as memory limits.

  > Thanks for the detailed context. `eslint.execArgv` passes arguments to the Node runtime that hosts the ESLint server; it does not pass ESLint CLI flags such as `-c` to ESLint. Please provide the config through the ESLint class options instead:
  > 
  > ```json
  > {
  >   "eslint.useFlatConfig": true,
  >   "eslint.options": {
  >     "overrideConfigFile": "/Users/daniel/dev/helia/node_modules/aegir/eslint.config.js"
  >   }
  > }
  > ```
  > 
  > The `LegacyConfigLoader` name comes from ESLint's internal config-loader implementation and does not mean that `eslint.execArgv` selected the requested file. If this configuration still fails, the updated `ESLint` output-channel content would help distinguish config loading from a separate working-directory issue.

- **ESLint constructor:** `server/src/eslint.ts` lines 1220-1237 copy `settings.options` into the options used to construct the workspace's ESLint class, so `overrideConfigFile` reaches ESLint's Node API directly.
- **existing usage:** The discussion at https://github.com/microsoft/vscode-eslint/issues/1936 documents `eslint.options.overrideConfigFile` being used with a custom flat-config filename; that issue concerns watching imported config files, not selecting the config.
