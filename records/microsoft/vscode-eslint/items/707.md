# Issue #707 — Quick Fix for CRLF to LF does not work

[https://github.com/microsoft/vscode-eslint/issues/707](https://github.com/microsoft/vscode-eslint/issues/707)

## Summary

Keep open: ESLint's CLI corrects the line endings, but the extension offers fixes that do not change the document's EOL mode. The editor and extension have evolved since the reports, so a current-version retest is needed; the thread supplies concrete configurations and steps, and the maintainer acknowledged the unresolved integration problem.

## Change summary

Make ESLint line-ending quick fixes and fix-all actually convert the document's line endings rather than leave the diagnostic unresolved.

## Best solution

Support ESLint-requested EOL conversion in the extension's code-action integration while respecting VS Code's document-wide EOL model. Decide how a single diagnostic communicates that whole-document effect, then verify both conversion directions and fix-all; changing editor or Git defaults is only a workaround.
