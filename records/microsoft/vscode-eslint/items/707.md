# Issue #707 — Quick Fix for CRLF to LF does not work

[https://github.com/microsoft/vscode-eslint/issues/707](https://github.com/microsoft/vscode-eslint/issues/707)

## Summary

The quick fix remains ineffective because the server converts ESLint's line-ending fix into an ordinary LSP TextEdit, while VS Code normalizes document line delimiters and cannot apply a per-line EOL conversion that way. The maintainer confirmed this limitation in 2024 and left the issue On Deck for an all-or-nothing implementation.

## Change summary

Make ESLint quick fixes that change LF/CRLF convert the document's line-ending mode instead of applying a no-op text replacement.

## Best solution

Keep the issue open and implement a dedicated whole-document EOL path, likely coordinating the server's detected ESLint fix with client-side VS Code APIs rather than ordinary LSP TextEdits. Per-line line-ending fixes should not be offered when VS Code can only represent one EOL mode for the document.
