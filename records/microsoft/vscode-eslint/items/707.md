# Issue #707 — Quick Fix for CRLF to LF does not work

[https://github.com/microsoft/vscode-eslint/issues/707](https://github.com/microsoft/vscode-eslint/issues/707)

## Summary

The bug remains on current main: ESLint's line-ending fix is converted into ordinary LSP text edits, which cannot change VS Code's document-wide EOL mode. The existing `bug` label and On Deck milestone remain appropriate.

## Change summary

Quick Fix and fix-all actions for ESLint's `linebreak-style` rule fail to convert a document between CRLF and LF, even though `eslint --fix` succeeds.

## Best solution

Teach the client/server integration to recognize a whole-document line-ending fix and apply it through a VS Code API that changes the document EOL mode, treating the conversion as all-or-nothing. Single-line actions should either perform that document-wide conversion with clear wording or not be offered when they cannot work.
