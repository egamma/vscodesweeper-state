# Issue #1632 — [Feature Request] Add long paths support

[https://github.com/microsoft/vscode-eslint/issues/1632](https://github.com/microsoft/vscode-eslint/issues/1632)

## Summary

The long-path failure is already tracked by the older, open issue https://github.com/microsoft/vscode-eslint/issues/1229, where multiple reporters confirmed that files beyond Windows path limits are not linted even though the ESLint CLI handles them.

## Change summary

Support linting and fix-on-save for files whose Windows paths exceed the traditional path-length limit.

## Best solution

Consolidate investigation in https://github.com/microsoft/vscode-eslint/issues/1229 and determine whether the server's URI-to-path conversion or realpath handling needs to preserve a Windows long-path-compatible form before invoking ESLint.
