[https://github.com/microsoft/vscode-eslint/issues/1887](https://github.com/microsoft/vscode-eslint/issues/1887)

## Summary

This request depends on VS Code adding formatted or Markdown diagnostic messages and is fully covered by the open VS Code core issue https://github.com/microsoft/vscode/issues/54272, so it can be consolidated there as a cross-repository duplicate.

## Change summary

Render URLs and repository file paths embedded in custom ESLint diagnostic messages as clickable links in diagnostic tooltips.

## Best solution

VS Code core should provide Markdown or formatted diagnostic-message support through its diagnostics API; vscode-eslint can then preserve and expose links supplied by ESLint without implementing a separate tooltip surface.
