# Issue #1887 — Support custom clickable links in eslint error tooltips

[https://github.com/microsoft/vscode-eslint/issues/1887](https://github.com/microsoft/vscode-eslint/issues/1887)

## Summary

This is a valid diagnostic-presentation request that remains blocked on VS Code supporting formatted diagnostic content. The existing `depends-on-vscode` classification is correct, but the linked core issue is an enabler rather than a duplicate because this extension would still need to emit appropriate link metadata or markup.

## Change summary

Render URLs and repository file paths from custom ESLint rule messages as clickable links in diagnostic tooltips.

## Best solution

Keep the extension issue open to track adoption of the diagnostic-markdown capability requested in https://github.com/microsoft/vscode/issues/54272. Once that capability is available through VS Code and the LSP libraries, update diagnostic construction in `server/src/eslint.ts` to emit safe formatted content for supported links and add coverage for external URLs and workspace-relative file paths.
