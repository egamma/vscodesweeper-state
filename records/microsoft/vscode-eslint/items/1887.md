# Issue #1887 — Support custom clickable links in eslint error tooltips

[https://github.com/microsoft/vscode-eslint/issues/1887](https://github.com/microsoft/vscode-eslint/issues/1887)

## Summary

This is a valid diagnostic-presentation request that remains blocked on VS Code and LSP support for formatted diagnostic messages. The existing `depends-on-vscode` label correctly records that dependency, while this issue should remain open to track the extension-side adoption work.

## Change summary

Render URLs and repository file paths embedded in custom ESLint diagnostic messages as clickable links in diagnostic tooltips.

## Best solution

VS Code and the LSP diagnostic type should first support formatted or Markdown diagnostic content through https://github.com/microsoft/vscode/issues/54272. Once available, `server/src/eslint.ts` should emit supported markup for recognized links while preserving ordinary ESLint message text and the existing rule-documentation link.
