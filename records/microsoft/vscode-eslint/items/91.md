# Issue #91 — How to lint all files in project?

[https://github.com/microsoft/vscode-eslint/issues/91](https://github.com/microsoft/vscode-eslint/issues/91)

## Summary

The user-triggered lint task provides a documented workaround, but it does not implement the remaining feature request for extension-managed workspace-wide diagnostics. This is the oldest and best-supported canonical request for that capability, and its Backlog milestone and feature-request label indicate it should remain open.

## Change summary

Allow the extension to lint every file in a project and surface those diagnostics without requiring each file to be opened.

## Best solution

Keep this issue as the canonical product request and decide whether to add an opt-in workspace-scan mode spanning the client task/lifecycle integration and server diagnostics, with explicit performance limits. The existing `eslint.lintTask.enable` task should remain the manual alternative rather than being treated as full implementation of persistent workspace diagnostics.
