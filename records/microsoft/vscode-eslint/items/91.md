# Issue #91 — How to lint all files in project?

[https://github.com/microsoft/vscode-eslint/issues/91](https://github.com/microsoft/vscode-eslint/issues/91)

## Summary

The extension provides a user-triggered whole-workspace lint task, but it still validates only opened files during normal editor operation. This issue remains the established canonical request for project-wide editor diagnostics and is correctly retained in Backlog as a feature request.

## Change summary

Provide an opt-in way to lint every file in a workspace and expose those findings through VS Code rather than limiting live extension diagnostics to opened files.

## Best solution

Keep the existing task as the explicit full-workspace mechanism while deciding whether the client and server should support an opt-in workspace scan that publishes diagnostics for unopened files. Any implementation should define refresh and invalidation behavior carefully and avoid unconditional background work that would compromise editor responsiveness.
