# Issue #1997 — respect estlint-suppressions.json

[https://github.com/microsoft/vscode-eslint/issues/1997](https://github.com/microsoft/vscode-eslint/issues/1997)

## Summary

Bulk-suppression support is implemented on main and available in stable extension version 3.0.34, including configurable visibility, severity, and suppression-file location.

## Change summary

Make vscode-eslint honor ESLint's bulk-suppression API and eslint-suppressions.json when reporting editor diagnostics.

## Best solution

Use the shipped `eslint.bulkSuppression.*` settings with ESLint 10.1 or newer; users can enable suppression processing, choose how suppressed violations appear, and override the suppression-file location.
