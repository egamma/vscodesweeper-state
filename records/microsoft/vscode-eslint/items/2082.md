# Issue #2082 — Extension should report config file errors

[https://github.com/microsoft/vscode-eslint/issues/2082](https://github.com/microsoft/vscode-eslint/issues/2082)

## Summary

A real discoverability gap remains for flat-config failures: current main records unrecognized validation errors in the output channel and marks the ESLint language status as an error, but it does not notify the user explicitly or report the failure against the configuration file. The accepted On Deck feature request should remain open.

## Change summary

Surface invalid ESLint configuration errors prominently, preferably through a notification or a diagnostic located in the relevant eslint.config file.

## Best solution

Extend the server error-handling path to recognize flat-config errors such as InvalidConfigError and carry a reliable configuration-file location to the client. Show an actionable notification and, where ESLint supplies a trustworthy file and range, publish a diagnostic for that configuration document without replacing the existing output-channel logging and language-status indication.

- **Reason:** Making configuration failures visible directly advances the extension's durable configuration-resolution and diagnostic-presentation themes without changing ESLint semantics.

## Evidence

- **generic errors are only logged and reflected in status:** In server/src/eslint.ts, ErrorHandlers.showErrorMessage writes an unexpected validation error to the ESLint output channel and returns Status.error; server/src/eslintServer.ts sends that status to the client, and client/src/client.ts maps it to an error-severity ESLint language-status item.
- **flat-config error is not recognized:** ErrorHandlers.tryHandleConfigError in server/src/eslint.ts recognizes three legacy message shapes using regular expressions (Cannot read config file, invalid rule configuration, and Cannot find module). It has no InvalidConfigError or general flat-config error path, so the reported error falls through to generic handling.
- **existing notification support is partial:** For the recognized legacy message shapes, server/src/eslint.ts calls connection.window.showInformationMessage only when the parsed configuration file is not open. This does not cover the reporter's flat-config InvalidConfigError and does not create a diagnostic on eslint.config.mjs.
