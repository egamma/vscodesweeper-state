# Issue #1113 — jsonschema: source.fixAll.eslint does not seem to exist

[https://github.com/microsoft/vscode-eslint/issues/1113](https://github.com/microsoft/vscode-eslint/issues/1113)

## Summary

The completion gap remains on current main: ESLint provides `source.fixAll.eslint`, but its manifest does not augment the settings schema so VS Code can suggest that value. The linked general-purpose VS Code API proposal was declined, but the issue was deliberately reopened, classified as a feature request, and moved to On Deck after an extension-side schema-augmentation approach was suggested.

## Change summary

Offer `source.fixAll.eslint` in IntelliSense when users configure `editor.codeActionsOnSave` in settings JSON.

## Best solution

Add extension-side settings-schema metadata that documents and completes `source.fixAll.eslint`, following the schema-augmentation approach suggested in the thread if it remains supported. If current VS Code cannot safely accept that augmentation, retain this issue to track the extension-side adoption work for any replacement core capability rather than folding it into the declined general API proposal.
