# Issue #1113 — jsonschema: source.fixAll.eslint does not seem to exist

[https://github.com/microsoft/vscode-eslint/issues/1113](https://github.com/microsoft/vscode-eslint/issues/1113)

## Summary

VS Code now populates editor.codeActionsOnSave IntelliSense from registered code-action providers, including ESLint's source.fixAll.eslint kind. This addresses the reported missing completion once ESLint is running; completion before language activation remains a separate limitation.

## Change summary

Offer source.fixAll.eslint in settings.json IntelliSense when configuring editor.codeActionsOnSave.

## Best solution

Treat the requested completion as implemented by VS Code's dynamic schema updates, using the code-action metadata this extension already supplies. Preserve lazy activation rather than introducing a redundant static schema contribution.
