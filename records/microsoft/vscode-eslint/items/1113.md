## Summary

This remains a valid discoverability request: the extension supports `source.fixAll.eslint`, but VS Code's settings completion does not learn contributed code-action kinds dynamically. The underlying limitation is in VS Code core, with an extension-side schema augmentation identified as a possible workaround.
