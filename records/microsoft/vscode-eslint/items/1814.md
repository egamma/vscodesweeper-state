# Issue #1814 — Feature request: Provide a way to control files fixed during onCodeActionsSave (e.g., ignorePatterns)

[https://github.com/microsoft/vscode-eslint/issues/1814](https://github.com/microsoft/vscode-eslint/issues/1814)

## Summary

The requested save-specific file filtering is implemented by `eslint.codeActionsOnSave.options`, which passes a separate ESLint options object into fix-on-save computation and supports `ignorePatterns` without changing normal validation.

## Change summary

Allow workspaces to exclude selected file patterns from ESLint fixes on save independently of their normal lint configuration.

## Best solution

Use `eslint.codeActionsOnSave.options.ignorePatterns` to scope save-time fixes while retaining the workspace's normal ESLint configuration for validation. Keep the implemented generic options surface rather than adding dedicated `ignorePatterns` and `ignorePath` settings.

## Vision fit

- **Fit:** aligned
- **Reason:** Save-specific ESLint options strengthen the extension's established fix-on-save integration while preserving workspace ownership of ESLint configuration.
- **Evidence:** The durable themes explicitly include fix-on-save scope and configuration resolution, while the product promise is to integrate the workspace-installed ESLint into VS Code.
