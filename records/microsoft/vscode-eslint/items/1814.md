# Issue #1814 — Feature request: Provide a way to control files fixed during onCodeActionsSave (e.g., ignorePatterns)

[https://github.com/microsoft/vscode-eslint/issues/1814](https://github.com/microsoft/vscode-eslint/issues/1814)

## Summary

The requested per-save control is now implemented through `eslint.codeActionsOnSave.options`, which passes a separate ESLint options object when computing fixes on save. This supports a dedicated `overrideConfigFile` or other ESLint API options without changing normal validation.

## Change summary

Allow projects to exclude selected files or use a different ESLint configuration for fixes performed by code actions on save.

## Best solution

Use `eslint.codeActionsOnSave.options` to supply save-specific ESLint options, such as an `overrideConfigFile` containing the desired file selection or ignores. The shipped generic options surface covers this request without introducing separate `ignorePatterns` and `ignorePath` settings.
