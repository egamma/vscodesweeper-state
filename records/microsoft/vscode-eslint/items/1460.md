# Issue #1460 — Problems should not dissapear on file close

[https://github.com/microsoft/vscode-eslint/issues/1460](https://github.com/microsoft/vscode-eslint/issues/1460)

## Summary

This remains a valid, accepted feature request: current main provides diagnostics only for individual documents and explicitly disables workspace diagnostics. The existing lint task covers whole-workspace execution but does not preserve task diagnostics after an opened file's document diagnostics are cleared.

## Change summary

Add an opt-in mode that retains diagnostics for closed files and keeps workspace-wide ESLint problems current.

## Best solution

Implement an opt-in workspace diagnostic provider in the server, backed by a falsy-by-default `eslint.*` setting wired through the shared settings and client configuration. It should lint and refresh closed-file diagnostics without changing the default open-document behavior, with cancellation or time-budget controls to contain the performance cost.
