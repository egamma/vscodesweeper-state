# Issue #22128 — Adopt to using VS Code API to access terminal output

[https://github.com/microsoft/vscode-python/issues/22128](https://github.com/microsoft/vscode-python/issues/22128)

## Summary

The upstream shell-integration API is now finalized, but the accepted spike remains necessary: current main still uses terminal-data events, hidden terminals without strictEnv, and PATH prepending. The existing area-terminal and needs spike labels correctly represent the remaining work.

## Change summary

Adopt VS Code's terminal shell-integration API to inspect command output and replace legacy environment-activation workarounds.

## Best solution

Spike and migrate the legacy activation path in src/client/terminals/envCollectionActivation to TerminalShellIntegration execution/output APIs, using strictEnv with process.env for hidden terminals and replacing PATH where safe. Coordinate the result with the Python Environments extension rollout so superseded legacy behavior is removed rather than duplicated.
