# Issue #24753 — Unclear if the native REPL and terminal REPL shares the same session

[https://github.com/microsoft/vscode-python/issues/24753](https://github.com/microsoft/vscode-python/issues/24753)

## Summary

Keep open: launching the native REPL from the terminal still does not carry over the terminal session's variables or history. Existing settings only redirect future execution, and no verified older canonical owns this request.

## Change summary

Preserve variables and command history when moving from the terminal Python REPL to the native REPL.

## Best solution

The REPL owner should decide whether terminal-to-native launching should support session continuity; clearer launch wording can address the confusion but would not fulfill the requested state sharing.
