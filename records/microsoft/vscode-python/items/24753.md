# Issue #24753 — Unclear if the native REPL and terminal REPL shares the same session

[https://github.com/microsoft/vscode-python/issues/24753](https://github.com/microsoft/vscode-python/issues/24753)

## Summary

A real gap remains: the terminal link starts a separate native REPL process, so terminal history and variables are not carried over. The request is already correctly classified and routed to the REPL area.

## Change summary

Opening the native REPL from a terminal REPL should preserve the existing session's history, variables, and state.

## Best solution

Determine whether the terminal interpreter can be handed off or attached to the native REPL; otherwise make the link clearly state that it opens a new session. The implementation belongs in the REPL launch and terminal-link paths.
