# Issue #4586 — Perform test discovery per-file when a file is updated/added.

[https://github.com/microsoft/vscode-python/issues/4586](https://github.com/microsoft/vscode-python/issues/4586)

## Summary

The requested incremental per-file discovery remains unimplemented on main and is accepted work under `needs proposal`. The existing save-pattern setting reduces unnecessary triggers but still performs workspace-wide discovery.

## Change summary

Discover and update tests only for a created, modified, or deleted file instead of rediscovering the entire workspace.

## Best solution

Design a framework-neutral incremental discovery API that scopes collection and test-tree updates to the changed file, coordinating the implementation with the broader testing performance workstream at https://github.com/microsoft/vscode-python/issues/25978.
