# Issue #4586 — Perform test discovery per-file when a file is updated/added.

[https://github.com/microsoft/vscode-python/issues/4586](https://github.com/microsoft/vscode-python/issues/4586)

## Summary

A real gap remains: saving a matching file still triggers discovery for its entire workspace rather than collecting only that file. The accepted `needs proposal` request has 24 upvotes and recent maintainer support, so it should remain open in the testing backlog.

## Change summary

Incrementally discover tests for files that are created, changed, or deleted instead of rediscovering the entire project.

## Best solution

Define a framework-neutral incremental-discovery contract, pass the changed file through the pytest and unittest adapters, and update only the affected test-tree nodes while retaining full discovery for configuration changes and explicit refreshes. Coordinate this with the related incremental tree-update work without folding the request into a narrower regression report.
