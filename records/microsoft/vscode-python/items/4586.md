# Issue #4586 — Perform test discovery per-file when a file is updated/added.

[https://github.com/microsoft/vscode-python/issues/4586](https://github.com/microsoft/vscode-python/issues/4586)

## Summary

Per-file discovery remains missing: saving a matching file still triggers workspace-wide or all-project discovery. Keep this accepted, 24-upvote request open; the existing save-pattern setting reduces discovery triggers but not the scope of each discovery.

## Change summary

Discover tests incrementally after test files are created, modified, or deleted instead of rediscovering the whole project.

## Best solution

Deliver file-scoped discovery for pytest and unittest while preserving unaffected tests and retaining full discovery when configuration or shared discovery inputs require it. Develop the proposal here, coordinating with the newer test-tree update work rather than treating it as a replacement for this request.
