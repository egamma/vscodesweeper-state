# Issue #4586 — Perform test discovery per-file when a file is updated/added.

[https://github.com/microsoft/vscode-python/issues/4586](https://github.com/microsoft/vscode-python/issues/4586)

## Summary

Keep open as accepted testing work: it has 24 upvotes, carries `needs proposal`, and a maintainer reaffirmed that the team wants it. Current main can restrict which saved files trigger discovery, but discovery itself still collects the project rather than only the changed file.

## Change summary

Perform incremental test discovery for files that are added, modified, or deleted instead of rediscovering the entire project.

## Best solution

Design the uniform per-file discovery API requested here, pass changed paths to the pytest and unittest collectors, and merge only affected results into the existing test tree. Coordinate this with the incremental tree-update work tracked by https://github.com/microsoft/vscode-python/issues/25822 and the broader testing workstream at https://github.com/microsoft/vscode-python/issues/25978.
