# Issue #22797 — Add contribution points to extension API to add external support for Rye, pixi etc

[https://github.com/microsoft/vscode-python/issues/22797](https://github.com/microsoft/vscode-python/issues/22797)

## Summary

The general extensibility request is now implemented by the Python Environments extension, whose public API lets third-party extensions register environment and package managers.

## Change summary

Allow external extensions for tools such as Rye and pixi to provide environment discovery, creation, activation, and package-management workflows.

## Best solution

Keep this capability in the Python Environments extension: external tools can implement `EnvironmentManager` and `PackageManager` and register them through `registerEnvironmentManager` and `registerPackageManager`; linting and formatting remain with dedicated tool extensions.

## Vision fit

- **Fit:** aligned
- **Reason:** A public API for community environment managers advances the documented family-of-extensions architecture without adding every tool directly to the core extension.
- **Evidence:** The roadmap's durable themes explicitly include public environment discovery and selection APIs plus extensibility across the Python extension family.
