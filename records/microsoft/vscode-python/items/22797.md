# Issue #22797 — Add contribution points to extension API to add external support for Rye, pixi etc

[https://github.com/microsoft/vscode-python/issues/22797](https://github.com/microsoft/vscode-python/issues/22797)

## Summary

Route this accepted contribution-API request to area-api. Python Environments now provides environment and package-manager registration, but the core extension still has installation paths using its internal installer registry, so full coverage of the requested delegation is not established.

## Change summary

Allow external extensions to supply environment-manager and package-installation workflows for tools such as Rye and pixi without requiring pip or additional built-in integrations.

## Best solution

Use the Python Environments contribution APIs as the extensibility home and establish whether remaining core installation flows honor contributed package managers. Preserve tool-specific linting and formatting in their dedicated extensions rather than restoring built-in support.
