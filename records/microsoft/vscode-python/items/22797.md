# Issue #22797 — Add contribution points to extension API to add external support for Rye, pixi etc

[https://github.com/microsoft/vscode-python/issues/22797](https://github.com/microsoft/vscode-python/issues/22797)

## Summary

The requested extension contribution surface has shipped in the Python Environments extension, whose API supports registering external environment and package managers. This can be closed as completed.

## Change summary

Allow extensions for tools such as Rye and pixi to contribute environment discovery, lifecycle, activation, execution, and package-management behavior.

## Best solution

Keep environment-manager integration extensible through the Python Environments API; Rye, pixi, and similar extensions can implement EnvironmentManager and PackageManager and register them with the shipped APIs.

## Vision fit

- **Fit:** aligned
- **Reason:** An API through which ecosystem tools integrate without adding bespoke support to the core extension directly advances the family-of-extensions architecture.
- **Evidence:** The roadmap's extensibility theme favors APIs and access points for sibling and tool-specific extensions, while the community-tooling guardrail favors integration over rebuilding ecosystem tools.
