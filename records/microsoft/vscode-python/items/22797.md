# Issue #22797 — Add contribution points to extension API to add external support for Rye, pixi etc

[https://github.com/microsoft/vscode-python/issues/22797](https://github.com/microsoft/vscode-python/issues/22797)

## Summary

A real extensibility gap remains: current main lets extensions contribute environment creation, but not package-installation or tool-workflow behavior for environment managers such as Rye and pixi. The accepted proposal should remain open and be routed to the API and environments owners.

## Change summary

Add extension API contribution points through which external environment managers can provide package installation and related workflow operations.

## Best solution

Extend the environment API with provider-owned workflow operations, particularly package installation, so environment-manager extensions can override the pip-based default without adding each manager to vscode-python. Define the boundary jointly with the Python Environments extension while keeping the shared API surface in the Python extension family.
