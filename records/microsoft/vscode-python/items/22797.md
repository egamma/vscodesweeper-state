# Issue #22797 — Add contribution points to extension API to add external support for Rye, pixi etc

[https://github.com/microsoft/vscode-python/issues/22797](https://github.com/microsoft/vscode-python/issues/22797)

## Summary

Keep this accepted API proposal open while a maintainer reconciles it with the Python Environments extension, which now exposes environment-manager and package-manager registration APIs. The merged Pixi locator only addressed discovery, not the broader contribution-point request.

## Change summary

Expose extension APIs that let external environment tools such as Rye and Pixi provide discovery, creation, package installation, and tool-specific workflows.

## Best solution

A maintainer can transfer this to microsoft/vscode-python-environments and determine whether its current `registerEnvironmentManager` and `registerPackageManager` APIs fully cover Rye's workflows; any remaining API gap should be tracked there rather than adding another built-in manager to vscode-python.
