# Issue #21826 — Unit Tests with unittest do not show as failed if the setUpClass method raises an exception

[https://github.com/microsoft/vscode-python/issues/21826](https://github.com/microsoft/vscode-python/issues/21826)

## Summary

Still present on main: unittest reports a class-fixture error under a synthetic setUpClass ID that the execution resolver cannot correlate with discovered tests. The issue is already accepted and correctly routed with `needs PR` and `area-testing`.

## Change summary

Class-level unittest setup errors leave affected tests showing stale results instead of an error or not-run state with the traceback.

## Best solution

Teach unittest result handling to recognize class-fixture IDs such as `setUpClass (module.Class)`, locate the class's attempted test items, and mark them errored while attaching the fixture traceback. Cover both environment-extension and legacy execution paths with a regression test.
