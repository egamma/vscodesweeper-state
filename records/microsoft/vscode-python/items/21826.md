# Issue #21826 — Unit Tests with unittest do not show as failed if the setUpClass method raises an exception

[https://github.com/microsoft/vscode-python/issues/21826](https://github.com/microsoft/vscode-python/issues/21826)

## Summary

The bug remains source-reproducible on current main: unittest reports a synthetic `setUpClass (module.Class)` result ID, while the extension only updates UI items found through an exact test-method ID lookup. The issue is already accepted as `needs PR` in the correct testing area.

## Change summary

When unittest `setUpClass` raises, the Testing pane retains previous method results instead of showing the class-level execution error.

## Best solution

Recognize unittest class-fixture error IDs during execution-result handling and mark the affected discovered test methods as errored while preserving the fixture traceback. Limit the fallback to synthetic unittest fixture IDs so ordinary unittest and pytest result mapping remains unchanged.
