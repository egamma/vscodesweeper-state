[https://github.com/microsoft/vscode-python/issues/21826](https://github.com/microsoft/vscode-python/issues/21826)

## Summary

Keep open: current main still cannot associate unittest's setUpClass error identifier with discovered tests, so the error produces no corresponding Test Explorer result. The merged discovery-error PR was explicitly found insufficient after release; this accepted testing bug still needs an execution-result fix.

## Change summary

A unittest setUpClass exception leaves editor and Test Explorer results without an updated error state or associated traceback.

## Best solution

Surface class-setup errors in the unittest execution-result path and ensure affected tests do not retain misleading results from a previous run. Preserve unittest's distinction between a fixture error and an assertion failure, and leave unrelated classes' results unchanged.
