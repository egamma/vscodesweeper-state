# Issue #21826 — Unit Tests with unittest do not show as failed if the setUpClass method raises an exception

[https://github.com/microsoft/vscode-python/issues/21826](https://github.com/microsoft/vscode-python/issues/21826)

## Summary

The execution bug remains on current main: a setUpClass error is reported under a synthetic unittest ID that cannot be mapped to a VS Code test item, so the previous UI result remains visible. The issue is already correctly routed and accepted with area-testing and needs PR.

## Change summary

Show a visible error and update affected unittest results when setUpClass raises before individual tests run.

## Best solution

Teach the unittest execution result path to associate class-fixture errors such as `setUpClass (module.Class)` with the corresponding class or selected tests, mark them errored, and display the traceback.
