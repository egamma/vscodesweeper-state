# Issue #23305 — Integrated terminal profile using tmux creates additional session

[https://github.com/microsoft/vscode-python/issues/23305](https://github.com/microsoft/vscode-python/issues/23305)

## Summary

The issue remains relevant and is already routed correctly for investigation. Current source still creates a hidden terminal using the configured shell path without profile arguments, which can invoke plain tmux and create the additional session described in the report.

## Change summary

Activating the Python extension with a tmux-based integrated-terminal profile starts an unintended additional tmux session.

## Best solution

Update shell-integration detection in src/client/terminals/envCollectionActivation/shellIntegrationService.ts so it does not launch a dummy hidden terminal for unsupported shell executables such as tmux, while preserving detection for bash, zsh, fish, and PowerShell.
