# Issue #23305 — Integrated terminal profile using tmux creates additional session

[https://github.com/microsoft/vscode-python/issues/23305](https://github.com/microsoft/vscode-python/issues/23305)

## Summary

The extra session remains explainable on current main: Python creates a hidden terminal using the configured shell executable without its profile arguments. The accepted `needs spike` investigation should remain open in the terminal area.

## Change summary

A tmux-based integrated-terminal profile causes Python extension activation to create an additional unintended tmux session.

## Best solution

Change shell-integration detection in `src/client/terminals/envCollectionActivation/shellIntegrationService.ts` so it does not launch a profile shell without its configured arguments, preferably avoiding the dummy terminal entirely.
