# Issue #23305 — Integrated terminal profile using tmux creates additional session

[https://github.com/microsoft/vscode-python/issues/23305](https://github.com/microsoft/vscode-python/issues/23305)

## Summary

The causal path remains on current main: Python's shell-integration detection starts a hidden terminal using the resolved shell executable but omits profile arguments, which can launch a separate tmux session. The existing `needs spike` label marks this as accepted investigation, so it should remain open.

## Change summary

Using a tmux-based integrated-terminal profile causes the Python extension to create an unintended additional tmux session.

## Best solution

Change shell-integration detection in `src/client/terminals/envCollectionActivation/shellIntegrationService.ts` so it does not launch a profile wrapper such as tmux without its configured arguments; use the underlying supported shell or skip the probe for unsupported wrappers.
