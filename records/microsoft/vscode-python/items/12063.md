# Issue #12063 — allow usage of unittest's load_tests protocol in python unit tests

[https://github.com/microsoft/vscode-python/issues/12063](https://github.com/microsoft/vscode-python/issues/12063)

## Summary

A real implementation gap remains on current main: discovery invokes `load_tests`, but execution rebuilds the result as plain `unittest.TestSuite` instances, discarding custom suite behavior. The request is accepted with `needs PR` and should remain open as the specific work item.

## Change summary

Preserve unittest `load_tests` custom-suite behavior when discovering and running tests through VS Code.

## Best solution

Update the unittest execution adapter so filtering selected test IDs preserves custom suite semantics, or adopt the broader `unittest.main` and custom-runner design from https://github.com/microsoft/vscode-python/issues/22388 without discarding suites returned by `load_tests`.
