# Issue #26313 — Feature Request: Add setting to exclude specific Python interpreters from the environment list

[https://github.com/microsoft/vscode-python/issues/26313](https://github.com/microsoft/vscode-python/issues/26313)

## Summary

The open Python Environments request already asks for excluding specific interpreter paths from the Python extension. Consolidate this Windows/MSYS2 use case there rather than maintaining a separate request.

## Change summary

Allow users to hide selected Python interpreters without uninstalling them or removing their directories from PATH.

## Best solution

Follow https://github.com/microsoft/vscode-python-environments/issues/1043 for interpreter exclusion, preserving this report's MSYS2 paths and toolchain dependency constraints.
