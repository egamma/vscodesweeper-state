# Issue #25577 — Enable PyREPL for 3.13 and above

[https://github.com/microsoft/vscode-python/issues/25577](https://github.com/microsoft/vscode-python/issues/25577)

## Summary

The accepted REPL work remains necessary: current main still unconditionally disables PyREPL whenever Python terminal shell integration is enabled. This team-authored issue is already marked `needs PR` and should remain open for implementation.

## Change summary

Allow Python 3.13 and newer to use PyREPL while retaining VS Code terminal shell integration.

## Best solution
