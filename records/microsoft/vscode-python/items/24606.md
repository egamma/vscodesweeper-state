# Issue #24606 — terminal: smart send not working when returning dict

[https://github.com/microsoft/vscode-python/issues/24606](https://github.com/microsoft/vscode-python/issues/24606)

## Summary

Keep this open and route it to the terminal area: the dictionary case received a targeted fix, but current source still removes the terminating blank line for functions returning lists. The Python 3.13 behavior needs separate retesting against the supplied examples.

## Change summary

Smart Send should submit and execute complete function definitions returning dictionaries or lists without requiring parentheses or manual terminal input.

## Best solution

Complete compound-statement submission for list-returning functions while preserving standalone collection behavior. Retest the original Python 3.13 examples and coordinate any remaining bracketed-paste behavior with https://github.com/microsoft/vscode-python/issues/24565.
