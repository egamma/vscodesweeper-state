# Issue #22573 — Tests hang if subprocess spawned but not killed

[https://github.com/microsoft/vscode-python/issues/22573](https://github.com/microsoft/vscode-python/issues/22573)

## Summary

Keep open: current main still has a pytest execution path that waits indefinitely for inherited output streams to close after the runner exits. This leaves the run active and prevents another run; the existing area-testing label is appropriate.

## Change summary

Tests that leave a subprocess running can finish successfully while Test Explorer continues spinning and blocks subsequent runs.

## Best solution

Finalize pytest runs when the runner has completed even if a surviving descendant retains its output streams, without killing intentionally persistent daemons or losing buffered test results. Cover the exit-without-close case in the execution adapter tests.
