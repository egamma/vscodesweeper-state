# Issue #22573 — Tests hang if subprocess spawned but not killed

[https://github.com/microsoft/vscode-python/issues/22573](https://github.com/microsoft/vscode-python/issues/22573)

## Summary

The hang remains possible on current main: the legacy pytest execution path waits indefinitely for the child-process `close` event before ending the VS Code test run. A surviving subprocess that inherits pytest's output streams can prevent that event even after pytest exits.

## Change summary

Finish a pytest run when pytest itself completes, even if a test leaves a subprocess running.

## Best solution

In `src/client/testing/testController/pytest/pytestExecutionAdapter.ts`, decouple test-run completion from indefinite stdout/stderr closure after the pytest parent exits, while retaining a bounded output-drain period. Add coverage for a test subprocess that remains alive with inherited output streams.
