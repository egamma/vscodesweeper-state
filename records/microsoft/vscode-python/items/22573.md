# Issue #22573 — Tests hang if subprocess spawned but not killed

[https://github.com/microsoft/vscode-python/issues/22573](https://github.com/microsoft/vscode-python/issues/22573)

## Summary

The hang remains source-reproducible on main's legacy pytest execution path: completion waits for the process `close` event, which descendants retaining inherited stdio can prevent indefinitely. The existing testing-area routing is correct.

## Change summary

Finish a pytest run after pytest exits even when a test leaves a subprocess running with inherited output handles.

## Best solution

Align the legacy pytest execution path with the environments-extension path by completing on the primary pytest process exit while preserving bounded output and result-pipe draining, so descendant processes cannot keep the Test UI spinning.
