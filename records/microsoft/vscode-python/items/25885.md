# Issue #25885 — Unwanted execution of `KeyboardInterrupt` and `source activate`

[https://github.com/microsoft/vscode-python/issues/25885](https://github.com/microsoft/vscode-python/issues/25885)

## Summary

The delayed activation command is the command-mode behavior of the Python Environments extension. Maintainers have established shell-startup activation as the supported way to avoid injecting `source activate` and an interrupt into an active REPL or terminal.

## Change summary

Prevent delayed environment activation from inserting `KeyboardInterrupt` and `source activate` into the terminal REPL after Shift+Enter.

## Best solution

Use `python-envs.terminal.autoActivationType: "shellStartup"` with `python.useEnvironmentsExtension: true`; users who do not want automatic activation can set the activation type to `off`. Further activation-mode changes belong in microsoft/vscode-python-environments.
