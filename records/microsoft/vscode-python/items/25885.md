# Issue #25885 — Unwanted execution of `KeyboardInterrupt` and `source activate`

[https://github.com/microsoft/vscode-python/issues/25885](https://github.com/microsoft/vscode-python/issues/25885)

## Summary

Keep open for investigation of activation arriving after the terminal REPL starts. Current code queues REPL input and separates activation ownership between extensions, but the supplied WSL steps suffice to retest, and neither a covering fix nor a same-scope open duplicate was established.

## Change summary

Shift+Enter starts Python before delayed environment activation sends an interrupt and a shell activation command into the REPL.

## Best solution

Ensure terminal activation and REPL startup are coordinated so activation cannot interrupt Python or become Python input. Investigate the core terminal handoff and Python Environments activation together; a maintainer can transfer this to https://github.com/microsoft/vscode-python-environments if the delayed command originates there.
