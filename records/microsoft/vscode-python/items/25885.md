# Issue #25885 — Unwanted execution of `KeyboardInterrupt` and `source activate`

[https://github.com/microsoft/vscode-python/issues/25885](https://github.com/microsoft/vscode-python/issues/25885)

## Summary

The delayed interrupt and activation command come from terminal auto-activation owned by the Python Environments extension, whose maintainers subsequently documented this behavior and its configuration controls as designed. No vscode-python change is indicated, so this can be closed with that explanation.

## Change summary

Prevent delayed terminal environment activation from sending KeyboardInterrupt and a source command into a Python REPL launched with Shift+Enter.

## Best solution

Keep terminal activation behavior configurable in the Python Environments extension; users who do not want activation commands inserted into terminals can select its shell-startup activation mode or disable terminal auto-activation.

  > Thanks for the detailed report. Its maintainers documented this behavior as designed: set `python-envs.terminal.autoActivationType` to `shellStartup` to avoid inserting `source activate` into the terminal, or to `off` to disable terminal auto-activation.
