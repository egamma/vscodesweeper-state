# Issue #25885 — Unwanted execution of `KeyboardInterrupt` and `source activate`

[https://github.com/microsoft/vscode-python/issues/25885](https://github.com/microsoft/vscode-python/issues/25885)

## Summary

A later environments-extension report covers the same activation behavior and records the maintainer-supported configuration for avoiding command insertion and interrupts. This can be closed as designed with that guidance.

## Change summary

Prevent delayed environment activation from sending KeyboardInterrupt and source commands into an active Python REPL.

## Best solution

Use the Python Environments extension's shell-startup activation mode so activation does not inject commands into an active terminal, with activation disabled as the available fallback.

  > Thanks for the detailed report. This activation behavior is covered by https://github.com/microsoft/vscode-python-environments/issues/1570.
