# Issue #25940 — Environment tools block auto-approved agent calls on user input

[https://github.com/microsoft/vscode-python/issues/25940](https://github.com/microsoft/vscode-python/issues/25940)

## Summary

The blocking path remains on current main: without an explicit pythonPath, configure_python_environment can still invoke extension-owned selection UI and wait for user input. This team-authored issue was reopened after the earlier fixing PR proved insufficient, so it must remain open for a post-reopen fix.

## Change summary

Make default and auto-approved environment-tool calls deterministic and non-interactive, cancellable, and explicit about unsupported or ambiguous requests.

## Best solution

Add an explicit interaction policy to the compatibility tool and make non-interactive execution the default, covering deterministic reuse or creation, structured failures, cancellation, and both the Python Environments and fallback backends. Keep the broader ownership work in https://github.com/microsoft/vscode-python/issues/26078 separate from this concrete blocking bug.
