# Issue #25940 — Environment tools block auto-approved agent calls on user input

[https://github.com/microsoft/vscode-python/issues/25940](https://github.com/microsoft/vscode-python/issues/25940)

## Summary

The blocking default path remains on current main. The merged fix adds a non-interactive fast path only when the agent already supplies `pythonPath`; calls without it can still open environment-selection UI and wait indefinitely.

## Change summary

Make default or auto-approved Python environment tool calls terminate without requesting user input.

## Best solution

Add an explicit execution policy defaulting agent calls to no interaction, then deterministically reuse or create an environment or return a structured failure. Keep interactive selection available only when explicitly requested, across both environment backends.
