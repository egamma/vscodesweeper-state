# Issue #25940 — Environment tools block auto-approved agent calls on user input

[https://github.com/microsoft/vscode-python/issues/25940](https://github.com/microsoft/vscode-python/issues/25940)

## Summary

The blocking default path remains on current main. The merged mitigation supports non-interactive selection when an agent supplies `pythonPath`, but ordinary auto-approved calls can still open environment UI and wait indefinitely.

## Change summary

Ensure auto-approved environment-tool calls never block on extension-owned input UI and always terminate through deterministic setup or a structured failure.

## Best solution

Make non-interactive execution the default in `configurePythonEnvTool.ts` and thread that policy through both environment backends, with deterministic reuse or creation, structured failures, and cancellation. Preserve explicit interactive behavior and the existing `pythonPath` fast path.
