# Issue #25724 — Allow collecting coverage without `pytest-cov`

[https://github.com/microsoft/vscode-python/issues/25724](https://github.com/microsoft/vscode-python/issues/25724)

## Summary

The limitation remains on current main: coverage runs unconditionally add pytest-cov arguments and then fail when the plugin is unavailable. The accepted `needs PR` issue should remain open and be routed to the testing area.

## Change summary

Allow the pytest coverage profile to collect coverage through coverage.py when pytest-cov is not installed.

## Best solution

Add a coverage.py fallback to the pytest runner while retaining pytest-cov when it is installed or explicitly configured, and ensure the VS Code plugin stops/saves fallback coverage before constructing its coverage payload. Cover both paths with pytest adapter tests.
