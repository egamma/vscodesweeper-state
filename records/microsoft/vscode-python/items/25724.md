# Issue #25724 — Allow collecting coverage without `pytest-cov`

[https://github.com/microsoft/vscode-python/issues/25724](https://github.com/microsoft/vscode-python/issues/25724)

## Summary

The limitation remains on current main: pytest coverage unconditionally adds pytest-cov arguments and then rejects runs without that plugin. The existing `needs PR` label marks this as accepted work; route it to the testing area.

## Change summary

Support collecting pytest coverage through coverage.py when pytest-cov is not installed.

## Best solution

Add a native coverage.py execution path under `python_files/vscode_pytest/` while preserving pytest-cov when available, and derive branch-coverage handling independently of `--cov-branch`. Cover both execution paths in the pytest adapter coverage tests.
