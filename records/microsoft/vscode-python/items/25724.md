# Issue #25724 — Allow collecting coverage without `pytest-cov`

[https://github.com/microsoft/vscode-python/issues/25724](https://github.com/microsoft/vscode-python/issues/25724)

## Summary

The limitation remains on main: pytest coverage unconditionally adds pytest-cov arguments and then fails when that plugin is absent. This accepted bug should stay open and be routed to testing.

## Change summary

Allow pytest coverage collection through coverage.py when pytest-cov is unavailable.

## Best solution

Add a coverage.py fallback in python_files/vscode_pytest/run_pytest_script.py, following the unittest adapter's direct Coverage.start() approach, and explicitly communicate branch-coverage state to the pytest result plugin.
