# Issue #23949 — Output streaming for Django

[https://github.com/microsoft/vscode-python/issues/23949](https://github.com/microsoft/vscode-python/issues/23949)

## Summary

Keep open: Django discovery still buffers both stdout and stderr until the child process exits, although execution no longer uses that capture layer. This team-authored request is protected from a community-feedback close, and no verified canonical or issue-referencing implementation establishes full completion.

## Change summary

Stream Django testing stdout and stderr as they are produced instead of withholding them until completion.

## Best solution

Complete live output forwarding for Django discovery in python_files/unittestadapter/django_handler.py while preserving the existing execution output path and discovery-result protocol. This issue remains the concrete follow-up for the streaming work identified during Django integration.
