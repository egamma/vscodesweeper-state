## Change summary

Prevent transiently empty terminal environment contributions from producing unnecessary environment-change warnings after an editor reload.

## Best solution

Ensure the terminal activation collection is cleared and repopulated without an intervening asynchronous suspension, while preserving its activation values and scope.
