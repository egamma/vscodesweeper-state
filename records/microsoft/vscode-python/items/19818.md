# Issue #19818 — Ensure default global interpreter used is the default `python` in terminal

[https://github.com/microsoft/vscode-python/issues/19818](https://github.com/microsoft/vscode-python/issues/19818)

## Summary

The requested selection behavior remains absent on current main, and the existing `needs PR` and `partner ask` labels mark this as accepted work. The issue is already routed to the environments area.

## Change summary

Prefer the global Python executable resolved from `python` on `PATH` during automatic interpreter selection, falling back to the highest installed version, and document that order.

## Best solution

Update global auto-selection in `EnvironmentTypeComparer.getRecommended()` to prioritize the interpreter resolved from `python` on `PATH` before version sorting, while retaining workspace-environment precedence and the highest-version fallback; document the resulting selection order.
