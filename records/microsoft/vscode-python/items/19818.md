# Issue #19818 — Ensure default global interpreter used is the default `python` in terminal

[https://github.com/microsoft/vscode-python/issues/19818](https://github.com/microsoft/vscode-python/issues/19818)

## Summary

The requested PATH-first selection remains unimplemented on current main, and the existing `needs PR` and `partner ask` labels show that maintainers have accepted it for implementation. This issue is also the canonical tracker already used to consolidate the same Codespaces requirement.

## Change summary

Prefer the global interpreter resolved by the terminal's `python` command before falling back to the highest discovered Python version, and document that selection order.

## Best solution

Update global interpreter recommendation so the executable resolved from `python` on PATH wins, while retaining newest-version selection as the fallback and preserving local-environment precedence. Add documentation for the complete auto-selection order and account for the Python Environments extension integration boundary.
