# Issue #19818 — Ensure default global interpreter used is the default `python` in terminal

[https://github.com/microsoft/vscode-python/issues/19818](https://github.com/microsoft/vscode-python/issues/19818)

## Summary

The requested PATH-first selection remains unimplemented on current main. This is accepted work carrying `needs PR` and `partner ask`, so it should remain open.

## Change summary

Prefer the system-default `python` on PATH when automatically selecting a global interpreter, falling back to the highest discovered version, and document the selection order.

## Best solution

Update the global recommendation logic in `src/client/interpreter/configuration/environmentTypeComparer.ts` to resolve and prefer the interpreter invoked by `python` on PATH before version sorting, with appropriate Windows launcher behavior, tests, and user documentation.
