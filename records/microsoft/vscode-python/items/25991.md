# Issue #25991 — Infinite loop occurred in build_nested_folders.

[https://github.com/microsoft/vscode-python/issues/25991](https://github.com/microsoft/vscode-python/issues/25991)

## Summary

The failure remains possible on current main: the folder traversal can pass its containment check but ascend past the session path indefinitely. Route this regression to the testing area.

## Change summary

Pytest discovery fails for a nested testing cwd because build_nested_folders ascends to the filesystem root without reaching the session node.

## Best solution

Make build_nested_folders handle a file node equal to the session path and stop safely before ascending outside the session tree, with a regression test covering a nested python.testing.cwd and positional pytestArgs.
