## Summary

Keep open: this accepted API debt still carries `needs PR`, and the attempted implementation was closed without merging. The planned Python Environments extension migration may supersede it, but that transition is not yet complete.

## Change summary

Define useful environment-selection semantics when `getActiveEnvironmentPath()` receives no resource in a multiroot workspace.

## Best solution

Move API consumers to the Python Environments extension's resource-aware environment API, then formally deprecate the legacy Python extension API. Until that migration finishes, either implement the documented workspace-level fallback or clearly preserve and document the current behavior.
