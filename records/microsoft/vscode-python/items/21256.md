# Issue #21256 — Modify `getActiveEnvironmentPath()` API when `resource` is passed as `undefined` in a multiroot workspace

[https://github.com/microsoft/vscode-python/issues/21256](https://github.com/microsoft/vscode-python/issues/21256)

## Summary

Keep open: the accepted workspace-level API change is not implemented in the inspected checkout, and the attempted PR was closed without merging. The Python Environments migration is the team's preferred direction, but it does not establish that this API contract has been replaced successfully for affected consumers.

## Change summary

Make getActiveEnvironmentPath(undefined) in a multi-root workspace return the workspace-level selection or a preferred environment from global and workspace-file-directory discovery.

## Best solution

Validate that consumers can obtain the intended workspace-level environment through the Python Environments API while preserving per-folder interpreter choices. Resolve the legacy API's compatibility and retirement contract explicitly before treating this accepted work as completed.
