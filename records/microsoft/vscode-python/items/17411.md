# Issue #17411 — Syntax highlighting in the output of tests explorer

[https://github.com/microsoft/vscode-python/issues/17411](https://github.com/microsoft/vscode-python/issues/17411)

## Summary

A real gap remains in the failed-test peek view, and the existing `needs PR` label marks this as accepted work. The Test Results panel can display pytest-provided ANSI colors, but current main still sends plain-text `TestMessage` instances and does not provide syntax-highlighted failure details.

## Change summary

Render failed-test output with readable, selectable syntax highlighting in the Test Explorer result and peek interfaces.

## Best solution

Preserve this accepted testing request and implement a whitespace-preserving, selectable highlighted failure message through the VS Code Testing API, coordinating with VS Code core if the TestMessage Markdown renderer still prevents that behavior. Keep ANSI-colored pytest output in the Test Results panel as a partial capability rather than treating it as full coverage.
