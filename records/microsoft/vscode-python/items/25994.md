# Issue #25994 — [Feature request][Test explorer] List tests "by file", rather than "by tree"

[https://github.com/microsoft/vscode-python/issues/25994](https://github.com/microsoft/vscode-python/issues/25994)

## Summary

A real Test Explorer presentation gap remains: the Python extension always publishes every discovered directory level, with no by-file alternative. Route this feature request to the testing area.

## Change summary

Add a Test Explorer mode that groups Python tests directly by file without intermediate directory nodes.

## Best solution

Provide an optional by-file projection of discovered tests in `src/client/testing/testController/common/utils.ts`, preserving file, class, and test identities while omitting intermediate folder nodes. Expose the choice as a Python testing setting without changing the existing tree default.
