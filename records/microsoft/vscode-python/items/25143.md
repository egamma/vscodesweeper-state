# Issue #25143 — Hide progress messages when invoking tools

[https://github.com/microsoft/vscode-python/issues/25143](https://github.com/microsoft/vscode-python/issues/25143)

## Summary

Keep open: the merged implementation suppresses Python extension progress for environment creation and package installation, but does not conclusively cover the requested environment-selection notification or equivalent messages emitted by the Python Environments extension API. This team-authored item also carries `needs spike`, marking accepted work that should not be judgment-closed.

## Change summary

Suppress redundant progress and selection notifications when environment and package operations are invoked as chat tools.

## Best solution

Provide a tool-invocation option that consistently suppresses redundant progress and selection notifications across both legacy Python extension operations and the Python Environments extension API. The remaining environment-extension behavior likely belongs in microsoft/vscode-python-environments, coordinated through this repository's integration layer.
