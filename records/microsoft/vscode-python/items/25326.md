# Issue #25326 — Configure Python Env tool only creates and selects an env, but doesn't install required dependencies

[https://github.com/microsoft/vscode-python/issues/25326](https://github.com/microsoft/vscode-python/issues/25326)

## Summary

Keep this accepted, team-authored request open: existing dependency-installation capabilities do not establish that Configure Python Environment consistently prepares project dependencies. The older requirements-file tool request is related but does not own the same observable behavior.

## Change summary

Configure Python Environment should install the workspace's required dependencies when creating its environment.

## Best solution

Make project-dependency setup an explicit, supported outcome of the configure-tool workflow, reusing Python Environments capabilities while defining honest behavior for the legacy backend. Coordinate with the related requirements-file tool request and agent-tool design work without treating either as proof this request is complete.
