# Issue #25326 — Configure Python Env tool only creates and selects an env, but doesn't install required dependencies

[https://github.com/microsoft/vscode-python/issues/25326](https://github.com/microsoft/vscode-python/issues/25326)

## Summary

Keep open: this team-authored, accepted feature request still represents a gap in the environment-configuration tool and is explicitly marked `needs PR`. Current main can pass an explicit package list to the Python Environments extension, but it does not derive and install the dependencies declared by an existing workspace.

## Change summary

Configure Python Environment should install dependencies declared by files such as requirements.txt when it creates an environment for an existing repository.

## Best solution

Extend the environment-tool integration to detect supported workspace dependency metadata and carry the selected dependencies into environment creation, reusing the Python Environments extension's existing installation capability and preserving user confirmation. The likely integration boundary is ConfigurePythonEnvTool/CreateVirtualEnvTool in this repository calling `python-envs.createAny` with the appropriate packages.
