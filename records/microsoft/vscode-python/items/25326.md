# Issue #25326 — Configure Python Env tool only creates and selects an env, but doesn't install required dependencies

[https://github.com/microsoft/vscode-python/issues/25326](https://github.com/microsoft/vscode-python/issues/25326)

## Summary

The configure tool still exposes environment creation and selection without a project-dependency installation contract. This accepted request remains distinct from faster, separately invoked requirements installation and should reach the environments area owner.

## Change summary

Include installation of existing project dependencies when configuring a Python environment.

## Best solution

Make project dependency setup an explicit part of the configure-tool workflow, coordinated with the Python Environments implementation. Preserve isolated-environment installation restrictions and settle how dependency files are selected and authorized.
