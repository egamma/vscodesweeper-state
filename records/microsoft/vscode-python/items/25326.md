# Issue #25326 — Configure Python Env tool only creates and selects an env, but doesn't install required dependencies

[https://github.com/microsoft/vscode-python/issues/25326](https://github.com/microsoft/vscode-python/issues/25326)

## Summary

This accepted feature request remains necessary on current main: environment configuration creates and selects an environment without detecting or installing workspace dependency files. Route it to the environments area for implementation.

## Change summary

Have the Configure Python Environment tool install dependencies declared by an existing workspace when it creates the environment.

## Best solution

Coordinate the tool with the Python Environments extension so quick environment creation detects requirements.txt or pyproject.toml dependencies, obtains any necessary user selection, installs them, and then returns the configured environment.
