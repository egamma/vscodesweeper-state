# Issue #18315 — execSelectionInTerminal to run in now active terminal

[https://github.com/microsoft/vscode-python/issues/18315](https://github.com/microsoft/vscode-python/issues/18315)

## Summary

Keep open as the canonical, community-accepted request. Current main still sends selections to an extension-managed terminal, and a maintainer recently confirmed that reusing an active terminal remains valuable but requires a new proposal compatible with the queue-based execution architecture.

## Change summary

Allow python.execSelectionInTerminal to send selected code to the currently active Python terminal instead of always using the terminal tracked by the extension.

## Best solution

Define how to identify a suitable active Python REPL and fall back safely to the extension-managed terminal, then implement that behavior on the current queue-based terminal execution path. Consolidate the newer equivalent report at https://github.com/microsoft/vscode-python/issues/24960 into this older, accepted request.
