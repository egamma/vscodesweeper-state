# Issue #18315 — execSelectionInTerminal to run in now active terminal

[https://github.com/microsoft/vscode-python/issues/18315](https://github.com/microsoft/vscode-python/issues/18315)

## Summary

Keep open as the accepted canonical request: it exceeded the community-feedback threshold, and current main still routes selections through an extension-managed terminal rather than the active terminal.

## Change summary

Allow python.execSelectionInTerminal to send selected code to the currently active Python terminal instead of always using the extension-managed terminal.

## Best solution

Define the active-terminal and fallback semantics in a proposal, then adapt the current queue-based terminal execution path to reuse an active Python REPL safely. Consolidate the newer overlapping report at https://github.com/microsoft/vscode-python/issues/24960 into this older, community-supported request.
