# Issue #18315 — execSelectionInTerminal to run in now active terminal

[https://github.com/microsoft/vscode-python/issues/18315](https://github.com/microsoft/vscode-python/issues/18315)

## Summary

A real capability gap remains on current main: Run Selection/Line retains a workspace-scoped Python terminal rather than targeting the active terminal. The request has met the community threshold, carries accepted-work process labels, and is already routed to the terminal area.

## Change summary

Allow python.execSelectionInTerminal to send normalized selected code to the currently active eligible Python terminal so users can work across multiple REPL terminals.

## Best solution

Develop the existing proposal into an explicit terminal-selection policy in the terminal execution service, including how to determine whether the active terminal is a suitable Python REPL and when to fall back to the extension-managed terminal. Coordinate this concrete behavior with the broader run-in-terminal tracker at https://github.com/microsoft/vscode-python/issues/15770.
