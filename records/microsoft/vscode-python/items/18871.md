# Issue #18871 — Consider removing extensions to prototypes of base types in favor of custom functions

[https://github.com/microsoft/vscode-python/issues/18871](https://github.com/microsoft/vscode-python/issues/18871)

## Summary

Keep open: current main still installs four String prototype extensions and Promise.prototype.ignoreErrors. The merged changes addressed only part of this accepted cleanup, and maintainers have consolidated related reports into this issue.

## Change summary

Replace extensions of built-in prototypes with standalone functions to avoid collisions with other extensions.

## Best solution

Complete the behavior-preserving cleanup of the remaining prototype extensions, their consumers, and ambient declarations. Retain this issue as the canonical report until loading the extension no longer installs these global methods.
