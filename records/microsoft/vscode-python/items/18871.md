[https://github.com/microsoft/vscode-python/issues/18871](https://github.com/microsoft/vscode-python/issues/18871)

## Summary

The accepted cleanup remains incomplete on current main: five assignments still modify built-in String or Promise prototypes. The issue is already correctly classified and routed with `debt`, `area-internal`, and `needs PR`, so it should remain open for implementation.

## Change summary

Replace extensions of built-in JavaScript prototypes with explicitly imported utility functions to prevent collisions with other extensions.

## Best solution
