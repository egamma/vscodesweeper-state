# Issue #21538 — Stale nodes stay in test explorer

[https://github.com/microsoft/vscode-python/issues/21538](https://github.com/microsoft/vscode-python/issues/21538)

## Summary

Stale roots remain possible in current main's legacy discovery path when the start directory changes. Project-based discovery now cleans up workspace roots, but that does not cover the legacy path; the linked fix PR was closed without merging.

## Change summary

Changing the test discovery start directory leaves the previous test root visible alongside the new root until the window reloads.

## Best solution

Ensure successful legacy rediscovery reconciles the affected workspace's roots with the current discovery result, preserving other workspaces and existing project-based behavior. Keep this concrete report separate from broader testing redesign trackers.
