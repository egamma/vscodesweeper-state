Keep open: the linked fix corrected existing-environment detection but did not handle a `.venv` file blocking creation. The legacy path remains defective on main, while the newer Environments-extension flow still needs confirmation.

## Change summary

Creating a virtual environment fails when the workspace already contains a regular file named `.venv`.
