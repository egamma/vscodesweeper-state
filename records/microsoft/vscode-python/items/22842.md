## Change summary

Creating a virtual environment fails when the workspace already contains a regular file named `.venv`.

## Best solution

Confirm that `python-envs.createAny` handles a regular `.venv` file gracefully, then fix the collision in microsoft/vscode-python-environments if that active flow still fails.
