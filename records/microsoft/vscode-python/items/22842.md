# Issue #22842 — Create enviroment fails when there's a .venv file in the workspace

[https://github.com/microsoft/vscode-python/issues/22842](https://github.com/microsoft/vscode-python/issues/22842)

## Summary

The bug remains actionable: the merged fix distinguishes a `.venv` file from an environment but the legacy creation path still attempts to create a directory at that occupied path. The issue is team-authored, accepted with `needs PR`, and awaiting confirmation against the newer Environments extension flow.

## Change summary

Creating an environment should handle a workspace-level `.venv` file gracefully instead of attempting to create a directory at the same path and failing.

## Best solution

Detect a non-directory `.venv` collision before creation and offer a safe alternative or actionable error. Confirm and fix this behavior in `python-envs.createAny`; retain equivalent handling in the legacy provider while that path remains supported.
