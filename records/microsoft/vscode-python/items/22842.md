# Issue #22842 — Create enviroment fails when there's a .venv file in the workspace

[https://github.com/microsoft/vscode-python/issues/22842](https://github.com/microsoft/vscode-python/issues/22842)

## Summary

Keep open: current main's legacy creation flow still attempts to create a directory over an existing .venv file. The Python Environments flow has changed since the confirmed reproductions, but the supplied steps suffice to retest it; the earlier merged PR does not establish resolution.

## Change summary

Creating an environment fails when a workspace contains a regular file named .venv rather than an environment directory.

## Best solution

Handle the filename collision explicitly without deleting or overwriting the existing file, and give the user actionable guidance or a supported alternative environment location. Confirm the Python Environments quick-create behavior before deciding whether a maintainer should transfer the remaining work to https://github.com/microsoft/vscode-python-environments.
