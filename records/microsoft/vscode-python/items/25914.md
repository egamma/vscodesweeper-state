# Issue #25914 — Disable "just my code" by default, perhaps through user settings.json

[https://github.com/microsoft/vscode-python/issues/25914](https://github.com/microsoft/vscode-python/issues/25914)

## Summary

The requested user-wide override already exists as debugpy.debugJustMyCode. A maintainer addressed the identical request in this repository by pointing to that setting, so this can be closed with the existing configuration explained.

## Change summary

Allow users to disable Just My Code globally without creating a launch.json for each project.

## Best solution

Keep the configurable default provided by the Python Debugger extension: users can set debugpy.debugJustMyCode to false in user settings, while explicit launch-configuration values retain precedence.

## Vision fit

- **Fit:** rejected
- **Reason:** Debugger configuration belongs in the dedicated Python Debugger extension, which already provides the requested preference, rather than a new setting in the core Python extension.
- **Evidence:** The public vision's family-of-extensions guardrail places debugging in the Python Debugger sibling extension.

  > Thanks for the request. The Python Debugger extension already provides this preference: set "debugpy.debugJustMyCode": false in your user settings.json to allow stepping into library code by default, without creating a launch.json for each project. An explicit justMyCode value in a launch configuration takes precedence. This is also the existing-setting guidance given for https://github.com/microsoft/vscode-python/issues/25181, so we're closing this request as already supported.
