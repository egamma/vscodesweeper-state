# Issue #25914 — Disable "just my code" by default, perhaps through user settings.json

[https://github.com/microsoft/vscode-python/issues/25914](https://github.com/microsoft/vscode-python/issues/25914)

## Summary

The requested global override already exists as the `debugpy.debugJustMyCode` user setting, so a per-project `launch.json` is not required.

## Change summary

Allow users to disable Python debugger Just My Code globally rather than configuring every project.

## Best solution

Use the Python Debugger extension's `debugpy.debugJustMyCode` user setting and keep `justMyCode` in `launch.json` for per-project overrides.

## Vision fit

- **Fit:** aligned
- **Reason:** A configurable debugger default supports the durable REPL and run experience while preserving the family-of-extensions boundary.
- **Evidence:** The vision identifies a family of extensions rather than a monolith; the Python Debugger extension already owns and exposes this debugger preference.

## Evidence

- **maintainer precedent:** The identical request at https://github.com/microsoft/vscode-python/issues/25181 was closed after a maintainer pointed to the existing Debugpy: Debug Just My Code setting.
- **current launch behavior:** The launch configuration schema in package.json still exposes `justMyCode` with default true, allowing individual debug configurations to override the user-level debugger preference.
