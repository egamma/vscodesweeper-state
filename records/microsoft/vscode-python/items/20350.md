## Summary

This accepted, strongly supported feature request remains necessary: the implementation PR was closed without merging, and current main does not expose pytest marks as Test Explorer tags.

## Change summary

Expose pytest marks as filterable Test Explorer tags so users can select and run marked test groups from the Testing UI.

## Best solution

Complete the experience by addressing filtered-run exclusion behavior tracked in https://github.com/microsoft/vscode-python/issues/25742.
