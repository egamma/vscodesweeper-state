# Issue #25146 — Kernel picker wrongly displays `Python 2.7.undefined` for a valid `Python 3.12` kernel

[https://github.com/microsoft/vscode-python/issues/25146](https://github.com/microsoft/vscode-python/issues/25146)

## Summary

Route this confirmed version-metadata problem to the environment/API owners. The reporter later said the symptom had stopped appearing in the related container-image issue, but no concrete fixing commit establishes that this report can be closed as completed.

## Change summary

A working Python 3.12 notebook kernel initially displays as Python 2.7.undefined, then shows the correct version when browsing available environments.

## Best solution

Ensure the Python environment API and its Jupyter consumer do not present provisional filename-derived metadata as the interpreter's actual version. First retest the documented container startup sequence on current releases to determine whether any work remains; preserve the correctly selected executable and working kernel.
