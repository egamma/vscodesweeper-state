# Issue #25146 — Kernel picker wrongly displays `Python 2.7.undefined` for a valid `Python 3.12` kernel

[https://github.com/microsoft/vscode-python/issues/25146](https://github.com/microsoft/vscode-python/issues/25146)

## Summary

The incorrect transient version remains a confirmed Python environment API bug, with independent reproductions in containers, Codespaces, and Windows. Route it to environment discovery rather than closing or transferring it to Jupyter.

## Change summary

The environment API initially reports an incorrect or incomplete Python version, causing Jupyter's kernel picker to display labels such as `Python 2.7.undefined` before later correcting itself.

## Best solution

Make environment-version publication atomic in the discovery/API path, likely around `src/client/environmentApi.ts`, so consumers receive either the resolved Python 3 version or no version until resolution completes, never a mixed placeholder value.
