# Issue #24279 — Run test discovery by module/file instead of root project

[https://github.com/microsoft/vscode-python/issues/24279](https://github.com/microsoft/vscode-python/issues/24279)

## Summary

Keep this accepted, team-authored request open: current main isolates discovery by registered Python project, but does not generally collect individual modules/files independently within a project. The older discovery requests are related, but do not establish the same observable import-collision failure required for a duplicate close on re-review.

## Change summary

Support independent pytest discovery per module or file when combined project-wide collection fails because of overlapping import paths.

## Best solution

Extend core testing discovery to support isolated collection scopes within a Python project while retaining all discovered tests in Test Explorer. First establish which cases remain unsupported by current project-based discovery, using the linked overlapping-import example as the acceptance fixture.
