# Issue #23893 — Python writes `source .../.venv/bin/activate` to existing terminals

[https://github.com/microsoft/vscode-python/issues/23893](https://github.com/microsoft/vscode-python/issues/23893)

## Summary

Keep open: this team-authored report describes activation submitting pending terminal input, with reported destructive consequences. Activation ownership has since shifted toward Python Environments, but the supplied SSH reconnect steps suffice to retest; neither the disabling setting nor the related closures proves this behavior fixed.

## Change summary

Automatic Python environment activation must not submit pending input or disrupt user work in existing terminals after reconnecting.

## Best solution

Preserve pending input and running processes in restored, previously interacted-with terminals while retaining activation for genuinely new terminals. Establish which extension handles activation during SSH reconnect, and coordinate the corresponding safety behavior with Python Environments rather than treating opt-out settings as a fix.
