# Issue #23893 — Python writes `source .../.venv/bin/activate` to existing terminals

[https://github.com/microsoft/vscode-python/issues/23893](https://github.com/microsoft/vscode-python/issues/23893)

## Summary

Current main still sends an activation command into an existing terminal without checking whether the user has entered text. This team-authored issue must remain open because no issue-linked fix has landed, and the sibling tracker covers only the newer environments-extension path.

## Change summary

Prevent automatic environment activation from submitting commands already typed into existing terminals after reconnect or reload.

## Best solution

Guard the legacy activation path in src/client/providers/terminalProvider.ts so it never calls sendText on an existing interacted-with terminal. Keep the environments-extension variant consolidated in https://github.com/microsoft/vscode-python-environments/issues/1375 while shell-startup activation progresses under https://github.com/microsoft/vscode-python-environments/issues/962.
