# Issue #25621 — Run button missing until leaving and coming back to script

[https://github.com/microsoft/vscode-python/issues/25621](https://github.com/microsoft/vscode-python/issues/25621)

## Summary

The reporter supplied a concrete startup reproduction and then reopened the issue after confirming that it persists with larger scripts. The editor-title action is still declared on main, so this needs investigation of why its VS Code context conditions are stale until the active editor changes.

## Change summary

Restore the Run Python File editor-title button immediately when VS Code reopens with a large Python script already active.

## Best solution

Trace the initial values and refresh behavior of `resourceLangId` and `shellExecutionSupported` for the restored editor, since those context keys control the action in `package.json`. If VS Code core fails to initialize or reevaluate them when restoring a large file, a maintainer can transfer the report to https://github.com/microsoft/vscode; otherwise the contribution or activation handling should be corrected here.
