# Issue #25621 — Run button missing until leaving and coming back to script

[https://github.com/microsoft/vscode-python/issues/25621](https://github.com/microsoft/vscode-python/issues/25621)

## Summary

The detailed video and follow-up isolate a repeatable startup problem with large Python files, and no canonical issue or fix was found. Route it to the terminal area to determine which editor-title context is stale after session restore.

## Change summary

The Run Python File button remains absent after restoring a large Python script until the user switches editors and returns.

## Best solution

Ensure the editor-title Run command is shown once a restored Python document is recognized, without requiring an editor switch. Trace `resourceLangId` and `shellExecutionSupported` during restoration; if VS Code fails to refresh those context keys, a maintainer can transfer the issue to microsoft/vscode.
