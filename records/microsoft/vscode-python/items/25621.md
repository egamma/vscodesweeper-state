# Issue #25621 — Run button missing until leaving and coming back to script

[https://github.com/microsoft/vscode-python/issues/25621](https://github.com/microsoft/vscode-python/issues/25621)

## Summary

The attached recording and follow-up identify a repeatable Windows restore-time failure affecting larger Python files. The run-button contribution remains present on main, but its visibility depends on VS Code context keys, so this needs editor-area investigation rather than closure.

## Change summary

Restoring VS Code with a large Python script open can leave the Run Python File button hidden until the user switches editors.

## Best solution

Trace why the editor-title menu does not refresh its resource language and shell-execution context after restoring a large Python file. If those VS Code-owned context keys are stale rather than the Python contribution being at fault, a maintainer can transfer the issue to microsoft/vscode.
