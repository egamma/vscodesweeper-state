# Issue #22179 — Save before run after re-load does not save before executing

[https://github.com/microsoft/vscode-python/issues/22179](https://github.com/microsoft/vscode-python/issues/22179)

## Summary

The bug remains actionable: a maintainer reproduced it, and independent Windows and macOS reports confirm that reopened files can execute without saving current edits. It is already routed to the terminal area and marked for investigation.

## Change summary

Running a modified Python file after closing and reopening it through Recent Files can execute the previous on-disk contents without saving the edits first.

## Best solution

Investigate how the run command identifies reopened documents and ensure the exact document being executed is successfully saved before terminal execution. Add coverage for closing and reopening a dirty file before invoking Run Python File in Terminal.
