# Issue #22179 — Save before run after re-load does not save before executing

[https://github.com/microsoft/vscode-python/issues/22179](https://github.com/microsoft/vscode-python/issues/22179)

## Summary

The bug remains independently confirmed across Windows and macOS, including in 2026, and is accepted for investigation under `needs spike`. No fix or canonical issue was found, and the existing `area-terminal` routing is appropriate.

## Change summary

Running a modified Python file reopened through Recent Files can execute its previously saved contents instead of saving the latest edits first.

## Best solution

Investigate how the run command resolves reopened documents and ensure it awaits saving the active dirty document before invoking terminal execution, including after editor reloads.
