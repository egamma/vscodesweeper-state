# Issue #22179 — Save before run after re-load does not save before executing

[https://github.com/microsoft/vscode-python/issues/22179](https://github.com/microsoft/vscode-python/issues/22179)

## Summary

This remains a confirmed cross-platform bug with accepted investigation work. Current main attempts to save dirty documents, but its narrow URI lookup and failure handling can still allow stale contents to execute after reopening a file.

## Change summary

Running a modified Python file after reopening it through Recent Files can execute the previous on-disk contents without saving first.

## Best solution

Harden the save-before-execution path in `src/client/terminals/codeExecution/helper.ts` and `codeExecutionManager.ts`: reliably resolve the reopened document, await a successful save, and abort with an error rather than execute stale contents when saving fails. Add a regression test covering close, reopen through Recent Files, edit, and run.
