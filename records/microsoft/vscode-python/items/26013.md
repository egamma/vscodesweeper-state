# Issue #26013 — Fails to find environments after VScode updates

[https://github.com/microsoft/vscode-python/issues/26013](https://github.com/microsoft/vscode-python/issues/26013)

## Summary

Keep open: the report provides an update–launch–interactive-window sequence sufficient to retest, but the current discovery and Jupyter integration paths do not establish whether this environment-dependent failure persists. Later confirmations concern Python Environments being enabled, whereas the original failure occurs with it uninstalled; neither those workarounds nor the rollout establish a fix for this report.

## Change summary

Conda/mamba environments disappear from newly opened Jupyter interactive windows on the first launch after a VS Code update, then return after reloading.

## Best solution

Ensure that first-launch environment discovery reaches new Jupyter interactive windows without requiring a reload when Python Environments is absent. First distinguish missing environments in the Python discovery API from a stale Jupyter kernel list; if Jupyter owns the failure, a maintainer can transfer this to microsoft/vscode-jupyter.
