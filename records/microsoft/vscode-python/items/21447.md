# Issue #21447 — Unexpectedly overlapping import suggestions in multi-root workspace using Jedi

[https://github.com/microsoft/vscode-python/issues/21447](https://github.com/microsoft/vscode-python/issues/21447)

## Summary

The cross-workspace completion path remains present on current main: Jedi instances are created per workspace, but every client registers a global Python document selector. Keep the accepted spike open and route it to IntelliSense.

## Change summary

Jedi import completions in a multi-root workspace include packages from interpreters assigned to other workspace folders.

## Best solution

Scope each Jedi language client's document selector and completion requests to its associated workspace folder while preserving handling for untitled and notebook documents. Add a multi-root language-server test proving that each workspace receives completions only from its selected interpreter.
