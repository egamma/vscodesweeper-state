# Issue #21447 — Unexpectedly overlapping import suggestions in multi-root workspace using Jedi

[https://github.com/microsoft/vscode-python/issues/21447](https://github.com/microsoft/vscode-python/issues/21447)

## Summary

The bug remains visible in current main: separate Jedi clients are created per workspace folder, but every client registers an unscoped Python document selector, allowing completion results from both environments to overlap. Keep the accepted spike open and route it to IntelliSense.

## Change summary

Scope Jedi import completions to the workspace folder and interpreter associated with the current document in multi-root workspaces.

## Best solution

Scope each Jedi LanguageClient's document filters to its WorkspaceFolder in src/client/activation/jedi/analysisOptions.ts while preserving appropriate handling for untitled and notebook documents, then cover two workspace folders with distinct environments in a multi-root language-server test.
