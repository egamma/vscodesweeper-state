# Issue #21447 — Unexpectedly overlapping import suggestions in multi-root workspace using Jedi

[https://github.com/microsoft/vscode-python/issues/21447](https://github.com/microsoft/vscode-python/issues/21447)

## Summary

The workspace-scoping defect remains visible in current source: separate Jedi clients use identical, workspace-unrestricted document selectors and forward completion requests without checking document ownership. Keep the accepted investigation open and route it to IntelliSense.

## Change summary

Jedi import suggestions mix packages from different interpreters in a multi-root workspace and can include duplicate entries.

## Best solution

Ensure each folder's Jedi client provides completions only for documents belonging to that folder, using its selected interpreter. Preserve Pylance's single-client multi-root behavior and existing support for documents outside workspace folders.
