# Issue #21447 — Unexpectedly overlapping import suggestions in multi-root workspace using Jedi

[https://github.com/microsoft/vscode-python/issues/21447](https://github.com/microsoft/vscode-python/issues/21447)

## Summary

Still present on current main: separate Jedi clients are created per workspace folder, but each registers an unrestricted Python document selector, allowing overlapping completion responses. Route this accepted investigation to IntelliSense.

## Change summary

Jedi suggests imports from other projects' interpreters in multi-root workspaces.

## Best solution

Scope each Jedi language client's document selectors to its workspace folder in `src/client/activation/common/analysisOptions.ts`, with a multi-root regression test confirming that only the owning client handles each document.
