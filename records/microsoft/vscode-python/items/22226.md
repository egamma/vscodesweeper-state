# Issue #22226 — Consider providing more information when prompting about a new environment.

[https://github.com/microsoft/vscode-python/issues/22226](https://github.com/microsoft/vscode-python/issues/22226)

## Summary

The ambiguous legacy notification remains on main, while the accepted `needs spike` work and maintainer direction indicate that environment selection should move to the Python Environments extension. Keep this open and route it to the environments area for migration or transfer.

## Change summary

Make the new-environment notification identify the environment, workspace folder, current selection, and reversal path.

## Best solution

Remove this legacy selection prompt once environment-manager-driven selection fully replaces it. A maintainer should determine whether the remaining UX work should transfer to https://github.com/microsoft/vscode-python-environments; while the legacy path remains supported, its notification should identify the proposed environment and workspace folder.
