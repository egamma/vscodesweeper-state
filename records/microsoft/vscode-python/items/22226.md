# Issue #22226 — Consider providing more information when prompting about a new environment.

[https://github.com/microsoft/vscode-python/issues/22226](https://github.com/microsoft/vscode-python/issues/22226)

## Summary

The confusing legacy prompt remains in the current source, while the Environments extension suppresses this flow by selecting environments differently. Keep the accepted spike open and route it to the environments area to decide whether to remove the remaining legacy path or improve its context.

## Change summary

Make the new-environment selection prompt identify the environment, workspace folder, current selection, and reversal path.

## Best solution

Complete the Python Environments extension migration so environment managers select newly created environments without this ambiguous prompt; while the legacy path remains supported, either suppress it consistently or show the environment and workspace-folder names with a clear route to change the selection.
