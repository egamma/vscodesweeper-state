# Issue #22139 — Support fully integrated IPython terminal

[https://github.com/microsoft/vscode-python/issues/22139](https://github.com/microsoft/vscode-python/issues/22139)

## Summary

Keep open for proposal work: the request exceeded the community-feedback threshold and is accepted for design consideration, while neither the terminal REPL nor Native REPL currently provides the complete persistent IPython workflow requested.

## Change summary

Provide a persistent, fully integrated IPython terminal that runs files through `%run`, accepts editor selections, and preserves the resulting namespace for continued interactive use.

## Best solution

Develop the requested proposal around an explicit IPython terminal mode that launches IPython for the selected environment, sends files through `%run`, routes selections to the same session, and preserves its namespace. Coordinate this with the narrower Shift+Enter behavior tracked in https://github.com/microsoft/vscode-python/issues/17172 without treating that issue as canonical for the broader workflow.
