# Issue #22139 — Support fully integrated IPython terminal

[https://github.com/microsoft/vscode-python/issues/22139](https://github.com/microsoft/vscode-python/issues/22139)

## Summary

Keep open as accepted proposal work: the request has 25 upvotes, carries `community ask` and `needs proposal`, and maintainers explicitly support improving both terminal and Native REPL experiences. Current capabilities cover parts of the workflow but not persistent IPython `%run` integration.

## Change summary

Provide a persistent, integrated IPython terminal that runs scripts through `%run` and retains their namespace for subsequent interactive work.

## Best solution

Develop a proposal for an IPython terminal backend that starts with the selected environment, sends whole-file runs through `%run`, preserves session state, and supports selections reliably. Coordinate the narrower Shift+Enter behavior with https://github.com/microsoft/vscode-python/issues/17172 without collapsing this broader request into it.
