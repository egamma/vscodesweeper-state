# Issue #22139 — Support fully integrated IPython terminal

[https://github.com/microsoft/vscode-python/issues/22139](https://github.com/microsoft/vscode-python/issues/22139)

## Summary

Keep open for proposal work: the request exceeded the community-feedback threshold and carries accepted-work labels. Current main offers generic terminal and Native REPL paths, but not a fully integrated persistent IPython session.

## Change summary

Provide an integrated IPython terminal that starts with the IDE, runs files through `%run`, and preserves the session namespace for subsequent interactive work.

## Best solution

Design an opt-in IPython terminal backend that launches from the selected environment, reliably accepts selections, and executes whole files with `%run` in the persistent session. Coordinate the narrower Shift+Enter behavior tracked by https://github.com/microsoft/vscode-python/issues/17172 without folding this broader request into it.
