# Issue #24724 — Error while collecting test results (Socket communication)

[https://github.com/microsoft/vscode-python/issues/24724](https://github.com/microsoft/vscode-python/issues/24724)

## Summary

The corruption path remains on current main: parallel pytest-xdist workers can write chunked JSON-RPC messages concurrently to one named pipe, interleaving frames and dropping test results. The issue already has the correct testing-area classification and should remain open for a transport fix.

## Change summary

Parallel pytest-xdist runs intermittently corrupt named-pipe messages, leaving Test Explorer with incomplete result counts.

## Best solution

Make pytest result reporting xdist-aware by forwarding worker results through the xdist controller and using one named-pipe writer. Add a multi-worker regression case with messages exceeding one 4096-byte segment.
