# Issue #24724 — Error while collecting test results (Socket communication)

[https://github.com/microsoft/vscode-python/issues/24724](https://github.com/microsoft/vscode-python/issues/24724)

## Summary

The corruption remains plausible on current main: parallel pytest-xdist workers can write independently framed test-result messages to the same named pipe, allowing large messages to interleave and causing the reported JSON and Content-Length parsing failures. The issue already has the correct testing-area label and should remain open for a multi-worker transport fix.

## Change summary

Parallel pytest-xdist execution intermittently corrupts the test-result communication stream, leaving many completed tests without statuses in Test Explorer.

## Best solution

Ensure xdist workers cannot concurrently write framed JSON messages to one result stream, either by routing results through the xdist controller or by introducing process-safe serialization. Add a multi-worker pytest integration test with messages larger than the current 4096-byte write segment and verify every test result reaches the extension.
