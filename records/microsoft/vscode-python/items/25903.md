# Issue #25903 — Misleading Shift+Enter: python.REPL.enableREPLSmartSend

[https://github.com/microsoft/vscode-python/issues/25903](https://github.com/microsoft/vscode-python/issues/25903)

## Summary

Shift+Enter intentionally runs the current selection or smallest runnable Python block; the Smart Send setting controls block selection, not whether the shortcut executes code.

## Change summary

Change Shift+Enter so it inserts a newline rather than sending the enclosing Python block to the REPL.

## Best solution

Keep the established execution shortcut and let users remove or reassign it through Keyboard Shortcuts. Clarification of Smart Send's behavior and discoverability can continue in https://github.com/microsoft/vscode-python/issues/22558.

- **Proposed comment:**

  > Thanks for the feedback. Shift+Enter is intentionally the shortcut for “Python: Run Selection/Line”: `python.REPL.enableREPLSmartSend` only controls whether that command expands an empty selection to the smallest runnable block. Setting it to false sends only the selected text or current line; to make Shift+Enter insert a newline instead, remove or reassign the Shift+Enter bindings for `python.execSelectionInTerminal` and `python.execInREPL` in Keyboard Shortcuts. The related discoverability and explanation work is tracked in https://github.com/microsoft/vscode-python/issues/22558.
