# Issue #24000 — cwd of repl when in empty workspace is not / 

[https://github.com/microsoft/vscode-python/issues/24000](https://github.com/microsoft/vscode-python/issues/24000)

## Summary

The empty-workspace defect remains visible in current source: VS Code reports no workspace as undefined, but the fallback to process.cwd() is only reached for an empty array. This team-authored issue must remain open because no subsequent fix explicitly references it.

## Change summary

Starting the native REPL without an open workspace uses an unexpected working directory instead of the intended root directory.

## Best solution

Handle both undefined and empty workspace-folder collections in NativeRepl.setReplDirectory, then add a unit test confirming that the no-workspace path supplies the intended cwd to the Python server and REPL controller.
