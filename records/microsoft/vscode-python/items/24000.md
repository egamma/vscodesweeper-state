# Issue #24000 — cwd of repl when in empty workspace is not / 

[https://github.com/microsoft/vscode-python/issues/24000](https://github.com/microsoft/vscode-python/issues/24000)

## Summary

The empty-workspace cwd gap remains in current source, and this team-authored issue must stay open. The native REPL inherits the extension host directory because no cwd is assigned when VS Code reports no workspace folders.

## Change summary

Ensure a native REPL launched without an open workspace starts in the intended fallback directory rather than inheriting the extension host cwd.

## Best solution

Define the platform-appropriate empty-workspace fallback and handle an undefined workspace-folder list explicitly in `NativeRepl.setReplDirectory`, with coverage for the no-workspace case. `area-repl` is the most precise owner.
