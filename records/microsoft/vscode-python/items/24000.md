# Issue #24000 — cwd of repl when in empty workspace is not / 

[https://github.com/microsoft/vscode-python/issues/24000](https://github.com/microsoft/vscode-python/issues/24000)

## Summary

The empty-workspace REPL still inherits the extension host's working directory rather than reliably using the filesystem root. This team-authored issue must remain open for a fix or explicit design decision.

## Change summary

Make the native REPL use the intended root directory when VS Code has no workspace open.

## Best solution

Confirm the cross-platform empty-workspace default, then update `NativeRepl.setReplDirectory()` to select that directory explicitly instead of relying on `process.cwd()` or child-process inheritance.
