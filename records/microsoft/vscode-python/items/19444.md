# Issue #19444 — Add basic tests for end to end scenarios in language server

## Summary

The end-to-end coverage gap remains on current main, and the existing `needs PR` label marks this as accepted work. The smoke suite does not exercise language-server startup and completion across single-file mode, interpreter changes, and workspace-trust transitions.

## Change summary

Add end-to-end tests that verify language-server startup and completions in single-file mode and after interpreter or workspace-trust changes.

## Best solution

Extend the smoke-test harness under `src/test/smoke/` to open Python files without a workspace, trigger completion, change interpreters, and exercise trust transitions while asserting that the language server becomes responsive after each restart. The CI smoke-test action should run these scenarios against the intended language-server configuration rather than only the current Jedi workspace setup.
