# Issue #26094 — Auto-activating a venv in every new terminal should be opt-in, not opt-on-by-default

[https://github.com/microsoft/vscode-python/issues/26094](https://github.com/microsoft/vscode-python/issues/26094)

## Summary

This is a valid request to reconsider the default terminal-activation policy, not an implementation defect. The existing setting provides an opt-out but does not satisfy the requested opt-in default, so it should be routed to the terminal area for a product decision.

## Change summary

Make automatic Python environment activation in newly created terminals opt-in, or prompt before activating for the first time.

## Best solution

Decide and document a consistent activation default across the legacy Python-extension path and the Python Environments extension, preserving an explicit setting for users who want every terminal activated. The terminal integration owners should assess the compatibility cost of changing the existing default or introducing a first-use prompt.
