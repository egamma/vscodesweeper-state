# Issue #26094 — Auto-activating a venv in every new terminal should be opt-in, not opt-on-by-default

[https://github.com/microsoft/vscode-python/issues/26094](https://github.com/microsoft/vscode-python/issues/26094)

## Summary

The existing opt-out does not satisfy this request to change the default or obtain consent before first activation. Route to the terminal area for a product decision, accounting for activation now delegated to Python Environments when enabled.

## Change summary

Make automatic environment activation in new integrated terminals opt-in, or require an explicit, dismissible first-activation prompt.

## Best solution

The terminal owners should decide whether automatic activation should remain the default for mixed-language workspaces or require consent. Any accepted change should account for both the core extension's legacy activation and the Python Environments extension's activation policy; a maintainer can transfer the sibling-owned portion to https://github.com/microsoft/vscode-python-environments.
