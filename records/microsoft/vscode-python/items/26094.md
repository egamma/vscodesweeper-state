# Issue #26094 — Auto-activating a venv in every new terminal should be opt-in, not opt-on-by-default

[https://github.com/microsoft/vscode-python/issues/26094](https://github.com/microsoft/vscode-python/issues/26094)

## Summary

This is a valid, unimplemented request to change the terminal-activation default, not a defect in the current behavior. Route it to the terminal and environments areas for a coordinated decision with the Python Environments extension.

## Change summary

Make automatic Python environment activation in every new terminal opt-in, or prompt before activating for the first time.

## Best solution

Choose a consistent opt-in default across the legacy activation path and the Python Environments extension, while retaining an explicit Python command for creating an activated terminal. The related design in https://github.com/microsoft/vscode-python/issues/21864 can preserve convenient activation when automatic activation is disabled.
