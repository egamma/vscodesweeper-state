# Issue #26094 — Auto-activating a venv in every new terminal should be opt-in, not opt-on-by-default

[https://github.com/microsoft/vscode-python/issues/26094](https://github.com/microsoft/vscode-python/issues/26094)

## Summary

This is a valid request to reconsider the default terminal-activation policy, not an implementation defect or support question. The rollout now delegates activation to the Python Environments extension, so a maintainer should keep this open and transfer it to that tracker if the new extension owns the default.

## Change summary

Make automatic Python environment activation in every new integrated terminal opt-in, or prompt before enabling it for the first time.

## Best solution

Decide the default in microsoft/vscode-python-environments, where the replacement activation setting currently defaults to command injection; either default it to off or introduce an explicit first-use choice while preserving activation for users who opt in. A maintainer can transfer this issue to https://github.com/microsoft/vscode-python-environments.
