# Issue #25626 — executeCommand in Python REPL with shell integration

[https://github.com/microsoft/vscode-python/issues/25626](https://github.com/microsoft/vscode-python/issues/25626)

## Summary

Keep this team-authored, needs-spike request open: current main still deliberately uses sendText inside the Python REPL, so reconsidering executeCommand remains unfinished work. Neither the existing shell-integration setting nor the related issues establish implementation or a qualifying duplicate.

## Change summary

Investigate safely using the terminal shell-integration executeCommand API inside the Python REPL without introducing KeyboardInterrupt.

## Best solution

Retain the sendText safeguard while the REPL owner investigates execution-marker timing and the CPython pre-execution hook. Reintroduce executeCommand only when its benefits and interrupt-free behavior are established across the affected configurations.
