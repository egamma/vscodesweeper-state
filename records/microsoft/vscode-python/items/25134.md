# Issue #25134 — Vscode doesn't know which Python virtualenv to use if there there are multiple python projects opened

[https://github.com/microsoft/vscode-python/issues/25134](https://github.com/microsoft/vscode-python/issues/25134)

## Summary

The cross-workspace interpreter leak has independent confirmations and remains actionable, but no concrete fixing commit or open canonical exists. Route it to environment ownership, with likely transfer to the Python Environments tracker.

## Change summary

Separate VS Code windows can reuse another project's selected virtual environment instead of restoring the environment associated with each workspace.

## Best solution

Ensure environment selection and terminal activation resolve and persist the interpreter against the correct workspace folder in every window. A maintainer should transfer this to microsoft/vscode-python-environments if the latest environment-extension release still reproduces it.
