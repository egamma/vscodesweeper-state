[https://github.com/microsoft/vscode-python/issues/24259](https://github.com/microsoft/vscode-python/issues/24259)

Fixed and shipped: coverage result paths are now converted to absolute paths before being sent to VS Code, resolving the missing drive letter and inaccessible coverage files.

## Change summary

Coverage generated with coverage.py relative paths produced invalid Windows file URIs and no editor gutter coverage.
