# Issue #4963 — Status of tests marked with pytest.mark.xfail are showing as unknown 

[https://github.com/microsoft/vscode-python/issues/4963](https://github.com/microsoft/vscode-python/issues/4963)

## Summary

Expected pytest failures still appear as skipped on current main because the adapter ignores pytest's wasxfail metadata. Keep this accepted, team-authored testing issue open; neither a verified fix nor an older canonical reporting the same symptom was found.

## Change summary

Report pytest tests that fail as expected under pytest.mark.xfail as passed rather than unknown or skipped.

## Best solution

Honor expected-failure metadata in the pytest result translation so the reporter's failing xfail test receives the requested passed status, while ordinary skipped tests remain skipped. Preserve pytest's strictness semantics for unexpected passes rather than expanding this fix into a new Test Explorer status.
