# Issue #4963 — Status of tests marked with pytest.mark.xfail are showing as unknown 

[https://github.com/microsoft/vscode-python/issues/4963](https://github.com/microsoft/vscode-python/issues/4963)

## Summary

Still present on main: the pytest adapter ignores `report.wasxfail` and maps expected failures to skipped. This team-authored, accepted issue should remain open for implementation.

## Change summary

Represent pytest expected failures distinctly instead of reporting them as unknown or skipped.

## Best solution

Update `python_files/vscode_pytest/__init__.py` to recognize `report.wasxfail` and emit the intended expected-failure result; the TypeScript execution handler already treats `expected-failure` as successful.

## Evidence

- **current source:** `python_files/vscode_pytest/__init__.py:306-342` maps every skipped call report to `skipped` without inspecting pytest's `report.wasxfail`, so an expected failure remains indistinguishable from a skip.
- **existing result support:** `src/client/testing/testController/common/testExecutionHandler.ts:50-55` already maps `expected-failure` to a successful test result, while `skipped` follows the skipped path.
