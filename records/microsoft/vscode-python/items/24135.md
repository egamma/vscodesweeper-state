# Issue #24135 — Python shell integration should work on Windows

[https://github.com/microsoft/vscode-python/issues/24135](https://github.com/microsoft/vscode-python/issues/24135)

## Summary

Keep open: this is accepted spike work and remains the canonical tracker for Windows Python REPL shell integration. Current main still explicitly avoids installing the shell-integration prompt on Windows, while the required reliable command hook remains open upstream.

## Change summary

Enable Python REPL shell integration on Windows without emitting the unreliable 633 E command-line sequence.

## Best solution

Implement and validate a Windows-compatible path in python_files/pythonrc.py, initially omitting 633 E while preserving command boundaries and status decorations; incorporate a reliable command-line sequence when the upstream CPython pre-execution hook becomes available.
