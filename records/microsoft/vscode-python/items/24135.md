# Issue #24135 — Python shell integration should work on Windows

[https://github.com/microsoft/vscode-python/issues/24135](https://github.com/microsoft/vscode-python/issues/24135)

## Summary

Keep open: this accepted spike remains the canonical tracker for Windows Python REPL shell integration, and current main still explicitly excludes Windows.

## Change summary

Enable Python REPL shell integration on Windows without emitting the unreliable OSC 633 E command-line sequence.

## Best solution

Retain this as the canonical Windows tracker and spike a Windows implementation in python_files/pythonrc.py that provides reliable prompt and execution markers while omitting OSC 633 E until command capture is available through CPython's proposed pre-execution hook or another validated mechanism.
