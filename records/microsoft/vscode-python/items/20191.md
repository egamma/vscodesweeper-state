# Issue #20191 — Bring back logging on CI

[https://github.com/microsoft/vscode-python/issues/20191](https://github.com/microsoft/vscode-python/issues/20191)

## Summary

Keep this accepted CI-observability debt open: current workflows neither enable the existing file logger nor publish extension logs as artifacts. Console test output and coverage artifacts do not cover the requested extension diagnostics.

## Change summary

Make extension diagnostic logs accessible from CI through console output or downloadable artifacts.

## Best solution

Ensure maintainers can retrieve extension diagnostics from successful and failed CI test runs, without changing normal user-facing logging. The existing file logger and CI test workflows provide a bounded starting point.
