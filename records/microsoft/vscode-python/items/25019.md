# Issue #25019 — "install python" option from kernel picker doesn't lead to obvious next step

[https://github.com/microsoft/vscode-python/issues/25019](https://github.com/microsoft/vscode-python/issues/25019)

## Summary

Keep open: this team-authored, spike-staged bug has a concrete dev-container reproduction, and the prerequisite installation work remains open. Current source opens a platform-specific walkthrough rather than ensuring that the kernel picker's installation action produces an obvious installation result.

## Change summary

Selecting "Install Python" from the notebook kernel picker in a non-Python dev container neither installs Python nor clearly directs the user to the required installation step.

## Best solution

Complete or resolve the installation capability tracked by https://github.com/microsoft/vscode-python/issues/24963, then make `python.installPython` provide an unambiguous platform-appropriate installation path when invoked from the kernel picker and validate the complete flow in a Python-free dev container.
