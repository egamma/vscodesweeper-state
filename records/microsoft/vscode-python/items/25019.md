## Summary

Keep open: this team-authored issue is accepted for investigation with `needs spike` and depends on the open Python-installation work. Current source intends to open the platform-specific installation step, but the reported dev-container behavior cannot be verified through source inspection alone.

## Change summary

Make the kernel picker's Install Python action lead users without Python to an obvious, actionable installation step.

## Best solution

Complete the installation capability tracked by https://github.com/microsoft/vscode-python/issues/24963, then ensure `python.installPython` opens the correct platform-specific walkthrough step and clearly explains any manual installation required in a dev container.
