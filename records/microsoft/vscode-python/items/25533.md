# Issue #25533 — Reference already existing PYTHONSTARTUP

[https://github.com/microsoft/vscode-python/issues/25533](https://github.com/microsoft/vscode-python/issues/25533)

## Summary

Current main still replaces an existing PYTHONSTARTUP value when Python shell integration is enabled. This team-authored feature request identifies a real coexistence gap and should remain open.

## Change summary

Preserve and execute a user's existing PYTHONSTARTUP script alongside the extension's shell-integration startup script.

## Best solution

Design a startup-script chaining mechanism that runs both the user's script and pythonrc.py with documented ordering and failure behavior, then cover the coexistence case in the terminal shell-integration tests.
