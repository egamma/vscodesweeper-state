# Issue #25533 — Reference already existing PYTHONSTARTUP

[https://github.com/microsoft/vscode-python/issues/25533](https://github.com/microsoft/vscode-python/issues/25533)

## Summary

Keep open: shell integration still replaces an existing PYTHONSTARTUP without running the user's script. This team-authored request remains distinct from the original disabled-setting report, and no verified canonical or implementation was found.

## Change summary

Preserve user-defined Python startup behavior when injecting terminal REPL shell integration.

## Best solution

Support coexistence between user startup scripts and the extension's shell integration in src/client/terminals/pythonStartup.ts and python_files/pythonrc.py. The terminal/REPL owner should settle script execution order and handling of user-defined prompt and display hooks before implementation.
