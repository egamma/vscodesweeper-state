# Issue #25533 — Reference already existing PYTHONSTARTUP

[https://github.com/microsoft/vscode-python/issues/25533](https://github.com/microsoft/vscode-python/issues/25533)

## Summary

The gap remains on current main: enabling Python terminal shell integration unconditionally replaces PYTHONSTARTUP with the extension's pythonrc.py, preventing a user-configured startup script from running. This team-authored feature request already has the appropriate terminal and REPL routing labels and should remain open.

## Change summary

Preserve or invoke an existing user PYTHONSTARTUP script when injecting Python terminal shell integration.

## Best solution

Make the shell-integration startup path compose safely with an existing PYTHONSTARTUP script, so the user's script and the extension's pythonrc.py both run with documented ordering and error behavior. Cover enabled, disabled, and pre-existing-variable cases in the terminal shell-integration tests.
