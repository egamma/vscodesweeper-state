- **Current source defect:** src/client/terminals/codeExecution/terminalCodeExecution.ts: TerminalCodeExecutionProvider.initializeRepl caches a successful replActive promise and clears it only on terminal closure. Exiting Python while keeping the terminal open therefore bypasses relaunch on the next execute(). src/client/common/terminal/service.ts: onReplReady latches isReplReady and disposes its readiness listeners; executeCommand(..., true) subsequently sends code directly with terminal.sendText.
