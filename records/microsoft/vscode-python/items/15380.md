# Issue #15380 — Only activate components after registering all the classes

[https://github.com/microsoft/vscode-python/issues/15380](https://github.com/microsoft/vscode-python/issues/15380)

## Summary

The activation-ordering gap remains explicitly documented in current source, and the accepted `needs PR` issue should stay open until legacy registrations can precede parallel component activation.

## Change summary

Register all legacy services before activating components, then activate legacy and component paths in parallel.

## Best solution

Separate registration from activation in `src/client/extensionActivation.ts`, complete all service registrations first, and then run legacy and component activation concurrently without allowing components to resolve unregistered dependencies.
