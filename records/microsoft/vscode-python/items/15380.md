# Issue #15380 — Only activate components after registering all the classes

[https://github.com/microsoft/vscode-python/issues/15380](https://github.com/microsoft/vscode-python/issues/15380)

## Summary

The architectural gap remains on current main and is explicitly tracked by a source TODO referencing this issue. The linked PR addressed only the immediate discovery regression and opened this issue for the general activation-order cleanup.

## Change summary

Move legacy service registration ahead of component activation so legacy and component activation can run in parallel safely.

## Best solution

Separate DI registration from `activateLegacy()` in `src/client/extensionActivation.ts`, complete registration before activation begins, and then activate legacy code and Python environment components concurrently.
