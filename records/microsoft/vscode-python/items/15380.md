# Issue #15380 — Only activate components after registering all the classes

[https://github.com/microsoft/vscode-python/issues/15380](https://github.com/microsoft/vscode-python/issues/15380)

## Summary

The activation-ordering gap remains explicitly documented on current main, and the existing `needs PR` label marks it as accepted work. The related merged PR fixed one discovery-specific symptom but deliberately left this general restructuring for this issue.

## Change summary

Register all legacy dependency-injection classes before activating components, then activate legacy code and components in parallel.

## Best solution
