# Issue #10165 — Fix environment-dependent git pre-commit hooks

[https://github.com/microsoft/vscode-python/issues/10165](https://github.com/microsoft/vscode-python/issues/10165)

## Summary

Keep open: this accepted, highly requested feature still needs a cross-extension proposal for supplying the selected Python environment to VS Code's Git subprocesses. Current code activates environments for terminals but does not cover Source Control commits.

## Change summary

Run Git pre-commit hooks launched from Source Control with the workspace's selected Python environment.

## Best solution

Define a workspace-scoped integration between VS Code's Git extension and the Python environment provider so Git subprocesses can receive the selected environment's activated variables. The proposal should support multiple environment managers and update when interpreter selection changes.
