# Issue #10165 — Fix environment-dependent git pre-commit hooks

[https://github.com/microsoft/vscode-python/issues/10165](https://github.com/microsoft/vscode-python/issues/10165)

## Summary

Keep open: this is accepted work marked `needs proposal`, has substantial community demand, and remains the best-diagnosed Python-side tracker. Current code only applies selected-environment variables to terminals; SCM-launched Git still needs coordinated support from VS Code core.

## Change summary

Run Git commits initiated from Source Control with the environment variables of the workspace's selected Python interpreter so environment-dependent hooks work consistently.

## Best solution

Coordinate with https://github.com/microsoft/vscode/issues/265613 on an SCM mechanism for per-workspace environment injection, then have the Python extension supply the activated variables for the selected interpreter. Preserve this issue as the Python integration tracker and consolidate its cross-platform and environment-manager evidence into the proposal.
