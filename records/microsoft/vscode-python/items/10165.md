# Issue #10165 — Fix environment-dependent git pre-commit hooks

[https://github.com/microsoft/vscode-python/issues/10165](https://github.com/microsoft/vscode-python/issues/10165)

## Summary

Keep open for a technical proposal: maintainers have confirmed that supporting the selected Python environment in Source Control commits requires coordinated SCM environment-injection support in VS Code core. The request has substantial community demand and is explicitly staged with `needs proposal`.

## Change summary

Run Git operations initiated from VS Code's Source Control UI with the workspace's selected Python environment so environment-dependent pre-commit hooks behave like commits from an activated terminal.

## Best solution

Develop a proposal for a workspace-scoped VS Code Git/SCM API that lets an extension provide dynamic environment variables for Git subprocesses, then have the Python extension supply activation variables for the selected environment. The design should account for multi-root workspaces, interpreter changes, remote environments, and avoiding unintended modification of unrelated Git processes.
