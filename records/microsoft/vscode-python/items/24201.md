# Issue #24201 — Pytest does not show correct tests without `pytest.ini` file

[https://github.com/microsoft/vscode-python/issues/24201](https://github.com/microsoft/vscode-python/issues/24201)

## Summary

The logs show that pytest did load pyproject.toml; the missing Test Explorer entries were caused by pytest-ruff/pytest-mypy collection nodes colliding with normal test-file nodes. That collision was fixed and pytest-ruff coverage added, so this can close as completed.

## Change summary

Show normal pytest tests and editor run controls when pyproject.toml enables pytest-ruff or pytest-mypy through addopts.

## Best solution

Use Python extension 2025.0.0 or later, which merges plugin and normal collectors by file path and supports pytest-ruff items without requiring a pytest.ini workaround.
