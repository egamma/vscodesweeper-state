# Issue #24201 — Pytest does not show correct tests without `pytest.ini` file

[https://github.com/microsoft/vscode-python/issues/24201](https://github.com/microsoft/vscode-python/issues/24201)

## Summary

Keep open in area-testing: the configuration is loaded, but its pytest-ruff and pytest-mypy collectors disrupt the test tree. Ruff support shipped in 2025.0.0, while the report also uses pytest-mypy and no corresponding fix is evident.

## Change summary

Pytest discovery omits tests when pyproject.toml enables pytest-ruff and pytest-mypy, while adding pytest.ini masks the problem by overriding that configuration.

## Best solution

Retest the supplied minimal reproduction on the current release with --mypy isolated, then update python_files/vscode_pytest/__init__.py to represent pytest-mypy's custom items without hiding ordinary tests. The existing area-testing assignment is appropriate.
