# Issue #24201 — Pytest does not show correct tests without `pytest.ini` file

[https://github.com/microsoft/vscode-python/issues/24201](https://github.com/microsoft/vscode-python/issues/24201)

## Summary

The attached logs show that pytest did load `pyproject.toml`; the missing UI tests were caused by `pytest-ruff` and `pytest-mypy` adding collector nodes that collided with normal test-file nodes. That adapter defect was subsequently fixed and shipped in 2025.0.0.

## Change summary

Display and run normal pytest tests when `pyproject.toml` enables the `pytest-ruff` or `pytest-mypy` collection plugins.

## Best solution

Keep the adapter's path-keyed file-node merging and support for collector items without source ranges, implemented by commits 520f39659d84cdb6242ddecdf3c6aa1bfac3dacd and dcfcdc2c1fbe95ba08c6c2ceef5da250fe050fae.
