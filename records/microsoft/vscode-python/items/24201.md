[https://github.com/microsoft/vscode-python/issues/24201](https://github.com/microsoft/vscode-python/issues/24201)

## Summary

The attached logs show that pytest already loaded pyproject.toml and enabled asyncio auto mode; the missing tests instead match the adapter's handling of plugin-generated test items. Concrete fixes shipped in 2025.0.0 address the file-node collisions and missing source locations that interrupted the test tree.

## Change summary

Display and run pytest tests configured through pyproject.toml without requiring a pytest.ini workaround when pytest-mypy or pytest-ruff adds test items.

## Best solution

Retain the shipped plugin-item handling fixes and close this as completed rather than as a duplicate of a closed report. The project's pytest configuration can remain in pyproject.toml without an additional pytest.ini.
