# Issue #25993 — Use Smart Send with Jupyter Interactive Window

[https://github.com/microsoft/vscode-python/issues/25993](https://github.com/microsoft/vscode-python/issues/25993)

## Summary

A real capability gap remains, but it concerns the Jupyter Interactive Window and prior maintainer handling places the same request with the Jupyter extension. Keep this report open for a maintainer to transfer because no open canonical Jupyter issue was verified.

## Change summary

Allow Smart Send to normalize the current Python block and execute it in the Jupyter Interactive Window instead of the terminal or native Python REPL.

## Best solution

A maintainer should transfer this request to https://github.com/microsoft/vscode-jupyter, where the Interactive Window command and destination behavior are owned; any implementation should preserve Python Smart Send's block selection while handing execution to Jupyter.

- **Evidence:** The family-of-extensions guardrail assigns notebooks and the Interactive Window to the Jupyter extension, while vscode-python retains its native REPL and integration surfaces.
