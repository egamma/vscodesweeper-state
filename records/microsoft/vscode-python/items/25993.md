# Issue #25993 — Use Smart Send with Jupyter Interactive Window

[https://github.com/microsoft/vscode-python/issues/25993](https://github.com/microsoft/vscode-python/issues/25993)

## Summary

The requested Interactive Window destination is not covered by the current Smart Send settings. Route to the REPL area for a cross-extension integration decision; the related Jupyter request is closed and its native-REPL workaround does not deliver this request.

## Change summary

Allow Smart Send to execute its selected runnable block in the Jupyter Interactive Window instead of the native Python REPL.

## Best solution

Provide Smart Send block selection and cursor advancement when executing into the Jupyter Interactive Window, while preserving existing terminal and native-REPL behavior. Coordinate the destination setting and command contract with Jupyter; a maintainer can transfer this to https://github.com/microsoft/vscode-jupyter if that extension should own the user-facing option.
