# Issue #25795 — pytest.HIDDEN_PARAM Causes Discovery Failure

[https://github.com/microsoft/vscode-python/issues/25795](https://github.com/microsoft/vscode-python/issues/25795)

## Summary

Keep open: current main still assumes every parametrized test name contains brackets, so pytest.HIDDEN_PARAM causes discovery to fail. The related testing workstream explicitly tracks this report as unfinished child work, not a duplicate.

## Change summary

Parametrized tests using pytest.HIDDEN_PARAM fail discovery because the extension unconditionally splits their names at an absent opening bracket.

## Best solution

Make the pytest discovery tree support valid parametrized items without visible parameter IDs while preserving their executable node IDs and existing visible-parameter grouping.
