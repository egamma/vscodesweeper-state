# Issue #25795 — pytest.HIDDEN_PARAM Causes Discovery Failure

[https://github.com/microsoft/vscode-python/issues/25795](https://github.com/microsoft/vscode-python/issues/25795)

## Summary

The discovery failure remains source-reproducible on current main: parametrized items are identified by `callspec`, but the adapter unconditionally splits their display name at `[`, which fails for `pytest.HIDDEN_PARAM`. The issue already has the correct testing-area label and should remain open for a targeted fix.

## Change summary

Allow pytest discovery to process parametrized tests whose parameter ID is hidden with `pytest.HIDDEN_PARAM`.

## Best solution

Guard the parameter-name split in `python_files/vscode_pytest/__init__.py` and preserve the appropriate function/test-node structure when a parametrized item has no bracketed suffix, with a regression case in the pytest adapter discovery tests.
