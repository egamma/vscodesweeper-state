# Issue #25795 — pytest.HIDDEN_PARAM Causes Discovery Failure

[https://github.com/microsoft/vscode-python/issues/25795](https://github.com/microsoft/vscode-python/issues/25795)

## Summary

The discovery crash remains conclusively present on current main: parametrized items always have their names split at `[`, but pytest.HIDDEN_PARAM intentionally produces a name without that delimiter. The issue already has the correct testing-area label and should remain open for the localized fix.

## Change summary

Allow pytest discovery to process parametrized tests whose parameter ID is hidden with pytest.HIDDEN_PARAM.

## Best solution

Guard the parameter-name parsing in python_files/vscode_pytest/__init__.py so a callspec without a visible `[parameter]` suffix is represented without crashing, while preserving the existing grouped tree for ordinary parametrized tests. Add a pytest-adapter discovery fixture and expected-tree regression case for pytest.HIDDEN_PARAM.
