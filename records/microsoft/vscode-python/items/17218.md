# Issue #17218 — TOC for .py files with percent markup

[https://github.com/microsoft/vscode-python/issues/17218](https://github.com/microsoft/vscode-python/issues/17218)

## Summary

Keep open: the team accepted this highly supported request for future consideration, and it remains protected by its team authorship and the `needs proposal` and `community ask` labels. Current main still has no Python-extension implementation that adds percent-markup cells to the Outline.

## Change summary

Show `# %%` cells, markdown cells, and optionally hierarchical cell sections from Python files in the VS Code Outline so users can navigate script-based interactive workflows.

## Best solution

Develop the requested proposal across the Python, Jupyter, and language-symbol boundaries, then expose percent-markup cells as navigable document symbols without replacing the normal Python code outline. The proposal should define hierarchy, markdown-cell handling, configurable cell markers, and coexistence with symbols supplied by the language server.
