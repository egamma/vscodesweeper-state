# Issue #12075 — Enable multiple test suites and test configurations in the Test UI

[https://github.com/microsoft/vscode-python/issues/12075](https://github.com/microsoft/vscode-python/issues/12075)

## Summary

This remains an accepted, high-demand testing feature request: current main provides fixed Run, Debug, and Coverage profiles backed by one argument setting per framework, but not multiple named suites or selectable configurations. The existing area and needs-proposal labels already route it correctly.

## Change summary

Allow workspaces to define and select multiple test suites with distinct arguments, environments, interpreters, and test groupings in the Test UI.

## Best solution

Design a configuration model that lets the testing controller expose multiple named run profiles while preserving straightforward defaults, then use those profiles consistently for discovery, run, debug, and coverage. Coordinate this broader suite-selection requirement with https://github.com/microsoft/vscode-python/issues/21845 without folding it into that narrower per-action configuration proposal.
