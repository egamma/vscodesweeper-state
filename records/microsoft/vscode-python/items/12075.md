# Issue #12075 — Enable multiple test suites and test configurations in the Test UI

[https://github.com/microsoft/vscode-python/issues/12075](https://github.com/microsoft/vscode-python/issues/12075)

## Summary

This remains the accepted canonical request for multiple selectable test suites and run configurations. Current main adds multi-project test discovery but still exposes only one argument set per framework and fixed Run, Debug, and Coverage profiles.

## Change summary

Allow users to define, select, and run multiple named test suites with distinct arguments, environments, interpreters, and grouping rules from the Test UI.

## Best solution

Develop the existing proposal into named, selectable test profiles that support multiple run configurations as well as distinct discovery, run, debug, and coverage arguments. Coordinate the design with https://github.com/microsoft/vscode-python/issues/21845 while retaining this issue as the broader canonical request.
