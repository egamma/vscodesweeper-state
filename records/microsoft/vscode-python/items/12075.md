# Issue #12075 — Enable multiple test suites and test configurations in the Test UI

[https://github.com/microsoft/vscode-python/issues/12075](https://github.com/microsoft/vscode-python/issues/12075)

## Summary

Keep open as the canonical user-facing request. It has strong community support, is accepted for proposal work, and current main still exposes only global test arguments and fixed Run, Debug, and Coverage profiles.

## Change summary

Allow users to define, select, and run multiple test suites and configurations with distinct arguments, environments, interpreters, and test groupings.

## Best solution

Retain this issue as the umbrella for the user requirements while completing the profile design in https://github.com/microsoft/vscode-python/issues/21845 and the implementation work in https://github.com/microsoft/vscode-python/issues/23777. The resulting Test UI should expose selectable configurations without requiring users to rewrite the global test settings.
