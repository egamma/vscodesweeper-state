# Issue #24991 — Django test discovering

[https://github.com/microsoft/vscode-python/issues/24991](https://github.com/microsoft/vscode-python/issues/24991)

## Summary

Django discovery still receives incompatible unittest defaults on current main. Keep this accepted testing bug open: the empty-arguments workaround does not fix the default behavior, and the matching reports found are newer.

## Change summary

Refreshing Django tests fails because unittest's default bare -v and -s arguments are forwarded to manage.py test.

## Best solution

Make Django discovery work without a manual unittestArgs override while preserving ordinary unittest discovery and explicitly configured Django arguments. Use this older report to consolidate the matching newer reports rather than closing it against them.
