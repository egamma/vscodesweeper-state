# Issue #24991 — Django test discovering

[https://github.com/microsoft/vscode-python/issues/24991](https://github.com/microsoft/vscode-python/issues/24991)

## Summary

The accepted testing bug remains on current main: default unittest discovery arguments are forwarded unchanged to Django, where bare `-v` is invalid. Keep open because it is labeled `needs PR` and no fixing PR is linked.

## Change summary

Django test discovery fails under the default unittest configuration because incompatible unittest arguments are passed to `manage.py test`.

## Best solution

Normalize or filter unittest discovery arguments before invoking Django in `python_files/unittestadapter/django_handler.py`, including supplying a value for verbosity and excluding unittest-only options such as `-s`; add coverage for the default `python.testing.unittestArgs` path.
