## Summary

The bug remains source-reproducible on main: default unittest discovery arguments are forwarded unchanged to Django, where bare `-v` is invalid. The existing `needs PR` and `area-testing` labels already classify this as accepted testing work.

## Change summary

Django test discovery fails because the extension passes unittest's default bare `-v` and other incompatible discovery arguments to `manage.py test`.

## Best solution

Adapt or filter unittest discovery arguments before invoking Django in `python_files/unittestadapter/django_handler.py`, including supplying a value for verbosity and excluding flags unsupported by `manage.py test`; add coverage using the contributed default arguments.
