# Issue #20425 — Python unittest runner doesn't respect arguments to pass to unittest runner

[https://github.com/microsoft/vscode-python/issues/20425](https://github.com/microsoft/vscode-python/issues/20425)

## Summary

Verified duplicate: current main still silently discards unsupported unittest arguments, and the broader open unittest-runner proposal explicitly owns this issue and the work required to pass all arguments through.

## Change summary

Ensure arguments configured in python.testing.unittestArgs are respected rather than silently ignoring unrecognized options.

## Best solution

Consolidate on https://github.com/microsoft/vscode-python/issues/22388 and replace the adapter's limited argument parsing with the proposed unittest.main/custom-runner design so unittest handles configured arguments directly.
