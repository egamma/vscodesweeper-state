# Issue #20425 — Python unittest runner doesn't respect arguments to pass to unittest runner

[https://github.com/microsoft/vscode-python/issues/20425](https://github.com/microsoft/vscode-python/issues/20425)

## Summary

Verified duplicate: the open testing-configuration proposal explicitly tracks this issue and the broader work needed to stop filtering user-supplied test arguments.

## Change summary

Unittest execution silently ignores unsupported arguments from python.testing.unittestArgs instead of passing them to the runner and reporting an error.

## Best solution

Consolidate on https://github.com/microsoft/vscode-python/issues/21845 and implement its broader argument-configuration design so unittest execution receives user arguments without the extension silently discarding them.
