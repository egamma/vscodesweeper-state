# Issue #20425 — Python unittest runner doesn't respect arguments to pass to unittest runner

[https://github.com/microsoft/vscode-python/issues/20425](https://github.com/microsoft/vscode-python/issues/20425)

## Summary

The reported argument loss remains on main: the unittest parser silently discards --silly, allowing execution to continue. Keep this accepted testing bug open; the related design proposals do not replace this concrete report.

## Change summary

Configured unittest arguments are silently ignored instead of producing the runner's expected behavior or invalid-argument error.

## Best solution

Make ordinary unittest execution honor valid runner arguments and report invalid arguments without running tests. Preserve Django's separate argument handling and retain this report alongside the broader testing-design proposals.
