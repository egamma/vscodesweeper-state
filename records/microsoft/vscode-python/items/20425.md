# Issue #20425 — Python unittest runner doesn't respect arguments to pass to unittest runner

[https://github.com/microsoft/vscode-python/issues/20425](https://github.com/microsoft/vscode-python/issues/20425)

## Summary

The bug remains visible in current source, but the broader open unittest-runner issue explicitly owns support for all unittest arguments and identifies this report as covered work. Consolidating there preserves a single implementation path.

## Change summary

Unittest execution silently ignores unsupported values in python.testing.unittestArgs instead of passing them to unittest and reporting invalid arguments.

## Best solution

Follow https://github.com/microsoft/vscode-python/issues/22388 and replace the hand-built discovery and execution flow with unittest.main plus the custom result runner, allowing unittest itself to process and validate the configured arguments.
