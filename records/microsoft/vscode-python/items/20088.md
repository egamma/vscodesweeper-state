# Issue #20088 — Support terminal link provider to handle python error stacks

[https://github.com/microsoft/vscode-python/issues/20088](https://github.com/microsoft/vscode-python/issues/20088)

## Summary

A real capability gap remains on current main, and the request has already passed community review and is staged for a proposal. The existing terminal link provider handles only the Native REPL launch prompt, not Python traceback locations.

## Change summary

Make file locations in Python tracebacks emitted to the terminal open the referenced source file and position when clicked.

## Best solution

Extend the terminal link provider in src/client/terminals/pythonStartupLinkProvider.ts, or introduce a dedicated provider, to recognize Python traceback file/line/column locations and open them in the editor. Preserve this issue as the canonical proposal and use https://github.com/microsoft/vscode-python/issues/13938 for its broader design notes.
