Keep open for proposal work: the request passed the documented community-feedback threshold, is marked as accepted work, and current main still lacks an opt-in notification when pytest discovery fails.

## Change summary

Provide a prominent, preferably opt-in notification that explains or links to details when pytest test discovery fails.

## Best solution

Define a low-noise notification policy for discovery failures, then surface an actionable message that opens the Python output containing the error. Preserve the existing Test Explorer error node as the persistent failure indicator.
