# Issue #21874 — Show Notification when Pytest Discovery Fails

[https://github.com/microsoft/vscode-python/issues/21874](https://github.com/microsoft/vscode-python/issues/21874)

## Summary

Keep open: current discovery reporting provides an error node and output link, but not the requested opt-in notification. Community interest is established; the remaining decision is how to surface failures without excessive notifications.

## Change summary

Offer an opt-in notification when pytest discovery fails, including when some tests are successfully discovered.

## Best solution

Agree on a low-noise notification policy in the testing area, then deliver visible discovery-failure feedback without losing partially discovered tests. Coordinate with the related error-reporting work without replacing this accepted request with its younger umbrella issue.
