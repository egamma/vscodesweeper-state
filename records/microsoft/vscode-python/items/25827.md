# Issue #25827 — Long startup time when running a test from the suite

[https://github.com/microsoft/vscode-python/issues/25827](https://github.com/microsoft/vscode-python/issues/25827)

## Summary

Confirmed on current main: Pixi test execution resolves activated environment variables through an interactive `pixi shell` command, producing the reported 30-second timeouts. Keep this open and route the root cause to environments while retaining testing ownership.

## Change summary

Running or debugging tests in a Pixi-managed environment waits roughly 30–60 seconds for environment activation to time out.

## Best solution

Replace the interactive Pixi activation command in `src/client/pythonEnvironments/common/environmentManagers/pixi.ts` with a non-interactive activation path such as `shell-hook`, while preserving the environment variables required by pytest execution and debugging.
