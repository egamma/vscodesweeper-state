# Issue #25827 — Long startup time when running a test from the suite

[https://github.com/microsoft/vscode-python/issues/25827](https://github.com/microsoft/vscode-python/issues/25827)

## Summary

Verified cross-repository duplicate: the open Python Environments issue tracks the same Pixi activation-variable timeout on WSL2, caused by invoking interactive `pixi shell`. This report contributes a distinct Test Explorer debug symptom but requires the same underlying fix.

## Change summary

Running or debugging a test through Test Explorer waits roughly 30–60 seconds when using a Pixi-managed environment with the Python Environments extension.

## Best solution

Consolidate the Pixi activation defect in https://github.com/microsoft/vscode-python-environments/issues/1672 and replace the interactive `pixi shell` activation path with a non-interactive mechanism such as `pixi run` or `pixi shell-hook`; ensure the fix also covers Test Explorer's debug environment resolution.
