# Issue #24407 — Wrong path when running .py script in WSL

[https://github.com/microsoft/vscode-python/issues/24407](https://github.com/microsoft/vscode-python/issues/24407)

## Summary

The current execution paths still pass a local Windows file path unchanged to the WSL interpreter. The recent reporter confirmation and current source support routing this open bug to terminal execution.

## Change summary

Run Python File sends a c:/... script path to a WSL interpreter instead of a valid /mnt/c/... path.

## Best solution

Make terminal execution validate the document URI against the remote execution context and translate accessible Windows paths to WSL paths, or report that the local file must be opened through the WSL filesystem rather than issuing an invalid command.
