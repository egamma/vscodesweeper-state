# Issue #26136 — Setting to turn multi-project testing off

[https://github.com/microsoft/vscode-python/issues/26136](https://github.com/microsoft/vscode-python/issues/26136)

## Summary

Route to the testing area: current main lacks a testing-specific, container-local control that limits discovery to selected projects across this overlapping multi-root workspace. Existing framework settings and the environment-extension opt-out do not fully cover that request.

## Change summary

Allow a devcontainer to restrict test discovery to its own Python project while retaining the full multi-project workspace.

## Best solution

Provide a supported container-local way to select which projects participate in test discovery without disabling environment integration or changing the host workspace's testing behavior. The testing owner should first decide whether this is a project-selection control or a multi-project-mode opt-out.
