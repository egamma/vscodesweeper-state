- **worker override:** `python_files/vscode_pytest/__init__.py` registers `DeferPlugin.pytest_xdist_auto_num_workers`, which caps xdist's auto worker count at the number of selected pytest node IDs and disables xdist when that result is one. The logged VS Code invocation contains many IDs, so the source alone does not explain why no worker-count line appears.
