# Issue #25474 — Augist release breaks pytest testing

[https://github.com/microsoft/vscode-python/issues/25474](https://github.com/microsoft/vscode-python/issues/25474)

## Summary

The pytest regression was confirmed and apparently corrected in a pre-release, but execution from paths containing spaces remained broken and another user later confirmed the problem. Keep this open and route the remaining Windows execution failure beyond the testing area.

## Change summary

Python testing and execution commands fail when the workspace or interpreter path contains spaces on Windows.

## Best solution

Reproduce the remaining run-file flow on current stable with a Windows workspace and venv under a path containing spaces, testing with the Python Environments extension enabled and disabled. Isolate whether quoting fails in the core run-in-terminal integration or the environments-extension API boundary; debugging-only behavior should be handled by microsoft/vscode-python-debugger.
