# Issue #26091 — Test explorer disappears every time a test file is saved

[https://github.com/microsoft/vscode-python/issues/26091](https://github.com/microsoft/vscode-python/issues/26091)

## Summary

Confirmed current regression: saving a matching test file triggers project-based rediscovery, which deletes every workspace test item before pytest collection finishes. Route to the testing area.

## Change summary

Saving a test file temporarily empties Test Explorer and disrupts gutter test actions until pytest collection completes.

## Best solution

Preserve the existing test tree while project-based discovery runs in src/client/testing/testController/controller.ts, then reconcile stale and newly discovered items after collection completes instead of deleting everything beforehand.
