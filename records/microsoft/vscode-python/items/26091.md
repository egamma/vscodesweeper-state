# Issue #26091 — Test explorer disappears every time a test file is saved

[https://github.com/microsoft/vscode-python/issues/26091](https://github.com/microsoft/vscode-python/issues/26091)

## Summary

Still present on main: saving a matching test file triggers project-based rediscovery, which removes the workspace's existing test items before pytest collection begins. Route this regression to the testing area; two additional users independently confirm the visible disappearance and delay.

## Change summary

Saving a test file temporarily empties Test Explorer and disrupts gutter test actions until the full pytest collection finishes.

## Best solution

Preserve the existing test tree during project-based rediscovery and reconcile stale projects or tests only after fresh discovery results are available, so saving a file does not remove runnable test items while collection is in progress.
