# Issue #17171 — Support setting environmental variables for the test runner

[https://github.com/microsoft/vscode-python/issues/17171](https://github.com/microsoft/vscode-python/issues/17171)

## Summary

Keep open as the accepted canonical request for test-specific environment configuration. The existing python.envFile is shared across Python workflows, while the current testing implementation still lacks separate environment settings for discovery and execution.

## Change summary

Allow users to configure environment variables specifically for test discovery and execution, independently of normal run and debug configurations.

## Best solution

Add test-specific environment configuration for discovery, run, debug, and coverage as part of the design in https://github.com/microsoft/vscode-python/issues/21845, while retaining this issue as the canonical user request and preserving support for variables such as DYLD_LIBRARY_PATH.
