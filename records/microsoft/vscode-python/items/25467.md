# Issue #25467 — Shell Integration makes REPL prompt garbled

[https://github.com/microsoft/vscode-python/issues/25467](https://github.com/microsoft/vscode-python/issues/25467)

## Summary

This remains the canonical open bug for cross-platform REPL corruption caused by Python terminal shell integration. Current source still injects OSC 633 sequences into `sys.ps1`, and recent confirmed reproduction shows pasted code can also be corrupted.

## Change summary

Enabling Python terminal shell integration exposes control sequences, garbles the REPL prompt, and can corrupt code sent with Shift-Enter.

## Best solution

Keep this issue as the canonical cross-platform tracker and make the `PYTHONSTARTUP` shell-integration path robust when terminals do not consume OSC 633 sequences. The separate macOS Shift-Enter behavior can remain tracked at https://github.com/microsoft/vscode-python/issues/25937.
