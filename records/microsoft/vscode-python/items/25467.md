# Issue #25467 — Shell Integration makes REPL prompt garbled

[https://github.com/microsoft/vscode-python/issues/25467](https://github.com/microsoft/vscode-python/issues/25467)

## Summary

The shell-integration REPL defect remains actionable, with independent confirmations across local and remote Linux environments. A later macOS Shift-Enter problem was explicitly split into a separate issue, so it does not supersede this report.

## Change summary

Enabling Python terminal shell integration can expose OSC 633 sequences and garble the standard Python REPL prompt and input.

## Best solution

Make the PYTHONSTARTUP integration emit OSC 633 markers only when the active terminal can consume them, while preserving correct readline prompt-width accounting. Keep macOS Shift-Enter corruption tracked separately in https://github.com/microsoft/vscode-python/issues/25937.
