# Issue #22769 — Pre-launch Console Renaming in VSCode Using launch.json Configuration

[https://github.com/microsoft/vscode-python/issues/22769](https://github.com/microsoft/vscode-python/issues/22769)

## Summary

The central request is already supported through the documented `consoleTitle` launch configuration property. Automatic title derivation remains separate follow-up work tracked by an open, narrower issue.

## Change summary

Allow a Python debug console or terminal to be named before launch, optionally deriving its title from the module or launch configuration.

## Best solution

Keep `consoleTitle` as the explicit launch configuration mechanism and consolidate automatic title derivation work in https://github.com/microsoft/vscode-python/issues/25544.

- **Fit:** aligned
- **Reason:** A clearer multi-session debugging experience fits the extension family's durable focus on reliable, useful integration without introducing bespoke Python tooling.
- **Evidence:** The roadmap goal is for Python support to be "fast, stable, and useful to anyone writing Python code for whatever reason," while the family architecture assigns debugging capabilities to the Python debugging integration.

- **Proposed comment:**

  > Thanks for the request and community feedback. Python launch configurations already support setting the pre-launch console or terminal name with `"consoleTitle": "My Console Name"`; this was added in https://github.com/microsoft/vscode-python/commit/f98caf64bdcd79e0594526ae92db2151385dadc7 and is present in the current launch schema. The remaining request to derive that title automatically is tracked more specifically by https://github.com/microsoft/vscode-python/issues/25544, so I believe this issue can be closed with that follow-up retained.

## Evidence

- **existing capability:** Current `package.json` declares the Python launch configuration property `consoleTitle`, with the description "Display name of the debug console or terminal" and a default of "Python Debug Console".
- **implementation commit:** https://github.com/microsoft/vscode-python/commit/f98caf64bdcd79e0594526ae92db2151385dadc7 added `consoleTitle` to the launch.json schema on 2023-11-08, before this issue was filed, and states that the value names both integrated-terminal and internal-console sessions.
- **automatic-title follow-up:** https://github.com/microsoft/vscode-python/issues/25544 is open and specifically requests defaulting `consoleTitle` from the launch configuration name when it is omitted.
- **community decision:** The request reached 11 opening-post upvotes, and the maintainer comment at https://github.com/microsoft/vscode-python/issues/22769#issuecomment-2189945583 recorded that community interest; the proposed close is based on the existing capability rather than inactivity or insufficient traction.
