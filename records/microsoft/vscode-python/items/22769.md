# Issue #22769 — Pre-launch Console Renaming in VSCode Using launch.json Configuration

[https://github.com/microsoft/vscode-python/issues/22769](https://github.com/microsoft/vscode-python/issues/22769)

## Summary

The central request—setting a Python debug terminal's name before launch through consoleName—was implemented in the Python Debugger extension and shipped in 2024.6.0. Automatic naming remains a separate enhancement, rather than a reason to retain this report of missing configurable naming.

## Change summary

Allow launch.json to specify the Python debug terminal's display name before launching, with optional automatic naming from the module.

## Best solution

Close the configurable-naming request as implemented and direct users to consoleName with the current debugpy launch type. Keep automatic naming separate; https://github.com/microsoft/vscode-python/issues/25544 discusses a configuration-name default, though it does not implement the suggested module-name default.
