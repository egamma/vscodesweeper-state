# Issue #22769 — Pre-launch Console Renaming in VSCode Using launch.json Configuration

[https://github.com/microsoft/vscode-python/issues/22769](https://github.com/microsoft/vscode-python/issues/22769)

## Summary

The requested pre-launch naming capability already existed when this issue was filed: launch configurations accept `consoleTitle` to name the debug console or terminal.

## Change summary

Allow a Python launch configuration to specify the console or terminal name before launching.

## Best solution

Use `"consoleTitle": "My Console Name"` in the Python launch configuration; the existing schema and debugger behavior intentionally support this.
