# Issue #22769 — Pre-launch Console Renaming in VSCode Using launch.json Configuration

[https://github.com/microsoft/vscode-python/issues/22769](https://github.com/microsoft/vscode-python/issues/22769)

## Summary

The explicit-title portion is already available through `consoleTitle`, but its fixed default remains `Python Debug Console`, so automatic naming from the launch configuration is still a real gap. The request has passed community review and carries accepted-work labels, so it should remain open and route to the debugging area.

## Change summary

Allow Python debug terminals to receive a custom title from `launch.json` and automatically derive one from the launch configuration when no title is supplied.

## Best solution

Preserve the existing `consoleTitle` launch property and default it to the launch configuration name when omitted, with the Python Debugger extension owning the runtime behavior if that logic now resides there. Keep this older, community-supported issue as the canonical request and treat https://github.com/microsoft/vscode-python/issues/25544 as related narrower work.
