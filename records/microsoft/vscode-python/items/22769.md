# Issue #22769 — Pre-launch Console Renaming in VSCode Using launch.json Configuration

[https://github.com/microsoft/vscode-python/issues/22769](https://github.com/microsoft/vscode-python/issues/22769)

## Summary

Implemented and shipped by the Python Debugger extension: launch configurations can set `consoleName` before launch, which is translated to debugpy's `consoleTitle`.

## Change summary

Allow a Python launch configuration to choose the debug console or terminal title before launching.

## Best solution

Keep the shipped `consoleName` support in the Python Debugger extension. Automatic title selection remains separately tracked by https://github.com/microsoft/vscode-python/issues/25544.
