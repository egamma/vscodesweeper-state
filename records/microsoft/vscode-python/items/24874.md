## Summary

The request met the documented community-feedback threshold with 7 upvotes, and current main still provides variable exploration only for the Native REPL. It should remain open in the REPL area for implementation or design evaluation.

## Change summary

Expose the REPL Variables view for Python sessions running in the integrated terminal, not only for the notebook-backed Native REPL.

## Best solution

Design terminal-session variable inspection that preserves the existing terminal REPL workflow while populating the REPL Variables view after execution. The implementation may require coordination with VS Code's terminal APIs because the current provider is built around notebook documents.
