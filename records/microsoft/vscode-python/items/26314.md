# Issue #26314 — This release's booleans don't recognize the list class

[https://github.com/microsoft/vscode-python/issues/26314](https://github.com/microsoft/vscode-python/issues/26314)

## Summary

This is a Python usage question, not an extension defect: `a is list` compares object identity rather than checking whether `a` is a list instance.

## Change summary

The reporter expects `a is list` to recognize the type of a list instance.

## Best solution

Use `isinstance(a, list)` for the intended type check; no Python extension change is needed.
