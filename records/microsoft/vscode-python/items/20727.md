# Issue #20727 — Provide option to create multiple Python envs in a workspace folder with different (user defined) names

[https://github.com/microsoft/vscode-python/issues/20727](https://github.com/microsoft/vscode-python/issues/20727)

## Summary

Keep this accepted, team-authored request open: the legacy creation flow still uses fixed folder names, while Python Environments now documents custom naming. That is a strong capability lead, but no verified duplicate or issue-referencing implementation establishes a factual close.

## Change summary

Allow multiple user-named environments within one workspace, including environments using the same Python version with different packages.

## Best solution

Use the Python Environments custom-creation workflow rather than duplicate environment-management UI in the core extension. A maintainer should confirm that it supports multiple workspace-local environments with the same Python version and different package sets before considering this request fulfilled.
