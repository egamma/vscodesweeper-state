# Issue #20727 — Provide option to create multiple Python envs in a workspace folder with different (user defined) names

[https://github.com/microsoft/vscode-python/issues/20727](https://github.com/microsoft/vscode-python/issues/20727)

## Summary

A real capability gap remains: current environment creation uses fixed `.venv` and `.conda` paths and exposes no name or destination option. This team-authored request is already accepted for design work under `needs proposal`, so it should remain open.

## Change summary

Allow users to create multiple Python environments in one workspace folder with user-defined names.

## Best solution

Design the environment-creation UI and API to accept a validated name or destination and permit multiple workspace-local environments, including multiple environments based on the same Python version. The creation experience likely belongs in the Python Environments extension, with vscode-python API or integration changes only where required.
