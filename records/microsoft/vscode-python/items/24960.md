# Issue #24960 — Run Selection/Line in already active python interpreter terminal rather than opening a new terminal

[https://github.com/microsoft/vscode-python/issues/24960](https://github.com/microsoft/vscode-python/issues/24960)

## Summary

The requested capability remains absent on main. A maintainer confirmed that reusing an existing terminal is still valuable, but the earlier implementation must be rewritten for the current queue-based execution architecture.

## Change summary

Allow Run Selection/Line to send code to an already configured Python interpreter terminal instead of opening an extension-managed terminal.

## Best solution

Extend the current queue-based terminal execution path to safely target an existing active Python terminal, starting a REPL only when necessary, with coverage for preconfigured remote or SLURM sessions.
