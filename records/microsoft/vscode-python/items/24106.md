# Issue #24106 — ensureTerminal should return Promise<Terminal> 

[https://github.com/microsoft/vscode-python/issues/24106](https://github.com/microsoft/vscode-python/issues/24106)

## Summary

The debt remains on current main: `TerminalService.ensureTerminal` still returns `Promise<void>` and stores the terminal on the service. This team-authored, accepted `needs PR` item should remain open after its implementation PR was closed without merging.

## Change summary

Refactor `ensureTerminal` to return `Promise<Terminal>` so callers need not depend on terminal state retained by `TerminalService`.

## Best solution

Update `ITerminalService`, `TerminalService`, and `SynchronousTerminalService` so `ensureTerminal` returns the existing or newly created terminal, then migrate callers away from nullable retained state and assess whether `TerminalService` can be simplified further.
