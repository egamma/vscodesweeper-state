# Issue #25790 — printing huge str gets truncated with F5 or ctrl+F5

[https://github.com/microsoft/vscode-python/issues/25790](https://github.com/microsoft/vscode-python/issues/25790)

## Summary

Keep open as an upstream Windows/CPython I/O defect: debugger launches set Python to unbuffered mode, which has a confirmed partial-write failure matching this report.

## Change summary

Large single-line stdout writes are truncated on Windows when a Python file is launched with F5 or Ctrl+F5, while direct terminal execution prints the complete value.

## Best solution

The complete fix belongs in CPython's Windows console I/O path tracked by https://github.com/python/cpython/issues/86210. The Python/debugger integration can also assess whether integrated-terminal launches need to force PYTHONUNBUFFERED=1 while the upstream defect remains.

- **matching debugger investigation:** https://github.com/microsoft/debugpy/issues/299 reports the same F5-versus-direct-execution truncation on Windows; debugger maintainers traced it to CPython console writes and identified PYTHONUNBUFFERED=0 in an integrated terminal as a workaround.
