## Summary

The incomplete executable path was fixed and confirmed by the reporter, but Debug Test still starts the first integrated-terminal run before activating the selected conda environment. Keep this open for the remaining activation-ordering defect.

## Change summary

Ensure pytest debugging in an integrated terminal uses the selected conda interpreter and activates its environment before the first test run.
