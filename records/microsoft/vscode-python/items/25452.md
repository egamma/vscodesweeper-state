# Issue #25452 — Pytest: Debug test uses incomplete python executable path

[https://github.com/microsoft/vscode-python/issues/25452](https://github.com/microsoft/vscode-python/issues/25452)

## Summary

The incomplete executable path was fixed and confirmed by the reporter, but the same workflow still has a first-run conda activation race in an integrated terminal. Keep the issue open and route the remaining defect to testing, terminal, and environments.

## Change summary

Debugging a pytest test in an integrated terminal must use the selected conda interpreter and its activated environment from the first run.

## Best solution

Preserve the executable-path conversion from commit 6181f44c38c92ee25b2bfd6364233de9c015fddd, then ensure the test-debug launch waits for or receives the selected conda environment's activated variables, including PYTHONPATH, before starting the pytest script in a new integrated terminal.
