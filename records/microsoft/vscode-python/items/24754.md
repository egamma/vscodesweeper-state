# Issue #24754 — Embed Native REPL description link in the terminal 

[https://github.com/microsoft/vscode-python/issues/24754](https://github.com/microsoft/vscode-python/issues/24754)

## Summary

The documentation link remains absent on current main, and the team agreed that embedding it alongside the Native REPL launch prompt would address the discoverability gap. This team-authored request should remain open in the REPL area.

## Change summary

Add a learn-more link to the terminal prompt that invites users to launch the VS Code Native REPL.

## Best solution

Print a localized link to https://code.visualstudio.com/docs/python/run#_native-repl alongside the Native REPL launch prompt and extend the shell-integration tests to cover it.
