# Issue #23570 — Native REPL should allow for environment configuration

[https://github.com/microsoft/vscode-python/issues/23570](https://github.com/microsoft/vscode-python/issues/23570)

## Summary

A real Native REPL configuration gap remains on current main, and the request has substantially exceeded the community-feedback threshold. It is already correctly routed to area-repl and should remain open for design.

## Change summary

Allow projects to configure the Native REPL working directory, environment variables, startup code, and framework-specific initialization.

## Best solution

Add a resource-scoped Native REPL launch profile covering cwd, environment or env-file input, and startup scripts, then evaluate whether the same surface can support launchers such as Django's manage.py shell.
