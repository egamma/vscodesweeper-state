# Issue #23570 — Native REPL should allow for environment configuration

[https://github.com/microsoft/vscode-python/issues/23570](https://github.com/microsoft/vscode-python/issues/23570)

## Summary

A real Native REPL configuration gap remains on main, and the request exceeded the community-feedback threshold with 29 upvotes. It is already routed to the REPL area and should remain open for design and implementation.

## Change summary

Allow projects to configure the Native REPL working directory, environment variables, startup code, or framework-specific initialization such as Django shells.

## Best solution

Add resource-scoped Native REPL launch configuration for cwd, environment or env-file values, and startup commands in the REPL launch path, while evaluating whether framework launchers such as `manage.py shell` need a separate adapter.
