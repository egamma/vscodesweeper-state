# Issue #23570 — Native REPL should allow for environment configuration

[https://github.com/microsoft/vscode-python/issues/23570](https://github.com/microsoft/vscode-python/issues/23570)

## Summary

A meaningful Native REPL configuration gap remains on current main, and the request has passed the documented community-interest threshold with 29 upvotes. It is already correctly routed to the REPL area and should remain open for design and implementation.

## Change summary

Allow Native REPL sessions to configure their working directory, environment variables, startup code, and project-specific initialization such as Django shell setup.

## Best solution

Add resource-scoped Native REPL launch configuration for the working directory, environment, and startup code, while determining whether framework entry points such as `manage.py shell` can integrate with the Native REPL protocol. Preserve the existing selected-interpreter behavior and multi-root workspace selection.
