# Issue #24910 — Pytest inline error reporting

[https://github.com/microsoft/vscode-python/issues/24910](https://github.com/microsoft/vscode-python/issues/24910)

## Summary

A real testing UX gap remains on main, and a maintainer explicitly agreed to investigate the proposed JUnit XML approach. The issue is already routed to area-testing and marked confirmation pending.

## Change summary

Surface pytest collection failures inline at the source location instead of requiring users to inspect the Python output log.

## Best solution

Investigate extracting file and line information from pytest collection reports or JUnit XML, then attach the failure to the relevant source location through VS Code's testing or diagnostics APIs. The design must account for discovery currently filtering user-supplied --junit-xml arguments.
