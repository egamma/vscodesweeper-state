# Issue #24910 — Pytest inline error reporting

[https://github.com/microsoft/vscode-python/issues/24910](https://github.com/microsoft/vscode-python/issues/24910)

## Summary

Keep open: current discovery errors still point users to logs rather than the failing source line, and a maintainer explicitly welcomed investigating the proposed structured-output approach. Neither the closed original request nor the related open issues establish a valid duplicate or decline for this reconsideration.

## Change summary

Show pytest collection failures inline at their source locations instead of requiring users to search the Python output.

## Best solution

Investigate reliable source-location reporting for pytest collection failures through the existing discovery integration, including whether JUnit XML actually supplies the required information during collect-only discovery. Preserve log access as a fallback when a failure has no usable source location.
