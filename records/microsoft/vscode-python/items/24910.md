# Issue #24910 — Pytest inline error reporting

[https://github.com/microsoft/vscode-python/issues/24910](https://github.com/microsoft/vscode-python/issues/24910)

## Summary

The inline discovery-error capability remains absent, and a maintainer explicitly agreed to investigate the proposed JUnit XML approach. The request is already routed to testing and should remain open pending that investigation.

## Change summary

Show pytest discovery failures inline at the relevant source location, potentially using pytest's JUnit XML output instead of parsing console output.

## Best solution

Investigate generating and parsing structured pytest discovery results, then attach a VS Code TestMessage with the reported source location while retaining the full discovery log. Any implementation must account for the current discovery argument filtering and avoid conflicting with user-supplied JUnit XML settings.
