# Issue #22943 — Showing "quit()" in shell history for session

## Summary

The stale-history path remains present on current main: the initial customized prompt can publish the final entry from persisted readline history even though no command ran in the new session. This team-authored issue is already accepted for investigation with `needs spike` and should remain open.

## Change summary

A newly launched Python REPL can show `quit()` from a previous session in Terminal: Run Recent Command.

## Best solution

Update the Python shell-integration startup code so its initial prompt does not emit an OSC 633 command-line record from persisted readline history; only commands entered during the current REPL session should be added to terminal command history. The spike should confirm the correct session-boundary behavior across supported Unix-like platforms before implementing it.
