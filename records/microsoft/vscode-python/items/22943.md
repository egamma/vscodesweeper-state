# Issue #22943 — Showing "quit()" in shell history for session

[https://github.com/microsoft/vscode-python/issues/22943](https://github.com/microsoft/vscode-python/issues/22943)

## Summary

The current REPL startup path can publish a command loaded from persistent readline history before any command runs in the new session. This team-authored issue is accepted for investigation with `needs spike` and should remain open.

## Change summary

Prevent commands from earlier Python sessions, such as `quit()`, from appearing in the current terminal's recent-command history.

## Best solution

Update `python_files/pythonrc.py` to establish a session history baseline and emit OSC 633 command metadata only for commands entered during the current REPL session, with coverage for a pre-populated readline history.
