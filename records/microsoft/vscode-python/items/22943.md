# Issue #22943 — Showing "quit()" in shell history for session

[https://github.com/microsoft/vscode-python/issues/22943](https://github.com/microsoft/vscode-python/issues/22943)

## Summary

Keep this accepted REPL investigation open: the checkout's prompt hook can announce a command from pre-existing readline history as though it ran in the current session. This team-authored issue has neither a verified qualifying duplicate nor an explicitly linked fix.

## Change summary

Prevent a previously executed quit() from appearing as a command executed in a newly started Python REPL session.

## Best solution

Ensure terminal REPL shell integration distinguishes persisted command history from commands actually executed in the current session, while preserving access to historical commands and success/failure decorations.
