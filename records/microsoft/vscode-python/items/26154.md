# Issue #26154 — Remembered external interpreter is not activated when opening a new terminal

[https://github.com/microsoft/vscode-python/issues/26154](https://github.com/microsoft/vscode-python/issues/26154)

## Summary

The legacy terminal-activation path still depends on the Python extension having activated first; creating an ordinary terminal is not itself a declared activation trigger. Route this request to the terminal area for a decision on supporting remembered external interpreters before any Python-specific action.

## Change summary

Make creating an integrated terminal activate the legacy Python extension and honor the workspace's remembered external interpreter.

## Best solution

Decide whether the supported legacy configuration should activate on ordinary terminal creation, while preserving lazy activation for unrelated workspaces and avoiding duplicate activation when Python Environments handles terminals. Existing terminal commands and settings do not fully cover the requested automatic behavior.
