# Issue #25824 — failing `pytest` tests are marked as “success” when some of the subtests succeeded

[https://github.com/microsoft/vscode-python/issues/25824](https://github.com/microsoft/vscode-python/issues/25824)

## Summary

The bug remains source-reproducible on current main and is accepted work under `needs PR`. The pytest adapter publishes only the first report for a node ID, so a successful subtest can mask later failures.

## Change summary

Aggregate pytest subtest results so a parent test is marked failed whenever any subtest fails.

## Best solution

Aggregate all call-phase reports for each pytest node ID in `python_files/vscode_pytest/__init__.py` and publish the final outcome only after all subtest reports are known, preserving any failure.
