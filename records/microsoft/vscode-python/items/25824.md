# Issue #25824 — failing `pytest` tests are marked as “success” when some of the subtests succeeded

[https://github.com/microsoft/vscode-python/issues/25824](https://github.com/microsoft/vscode-python/issues/25824)

## Summary

The current pytest adapter still publishes the first subtest's result and drops subsequent failures for the same parent. Keep this issue open while the explicitly linked implementation PR is reviewed and merged.

## Change summary

A pytest test with any failed subtest must be marked failed in Test Explorer even when its first subtest passes.

## Best solution

Review and land https://github.com/microsoft/vscode-python/pull/26215 so parent results reflect failed subtests without changing pytest's reports or breaking JUnit output. Keep individual subtest display support separate in https://github.com/microsoft/vscode-python/issues/24455.
