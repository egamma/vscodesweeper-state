# Issue #21697 — Allow disabling the "Recommended" tag for python interpreter selection

[https://github.com/microsoft/vscode-python/issues/21697](https://github.com/microsoft/vscode-python/issues/21697)

## Summary

This is an accepted environment-picker feature request with demonstrated community interest, and current main still has no user-facing setting to suppress the Recommended marker. It should remain open for the proposal already requested.

## Change summary

Add a workspace-configurable option that hides the Recommended marker in the Python interpreter picker.

## Best solution

Define a workspace-scoped setting for suppressing the recommendation marker and ensure that both the legacy picker and the Python Environments extension's picker honor it during the environment-extension rollout.
