# Issue #21697 — Allow disabling the "Recommended" tag for python interpreter selection

[https://github.com/microsoft/vscode-python/issues/21697](https://github.com/microsoft/vscode-python/issues/21697)

## Summary

This remains an accepted environment-selection feature request with demonstrated community interest. Current main can suppress the Recommended entry for internal picker invocations, but exposes no workspace setting that lets repository owners disable it.

## Change summary

Allow repositories to disable the Recommended designation in the Python interpreter picker through workspace settings.

## Best solution

Add a workspace-scoped preference controlling whether the interpreter picker displays its Recommended group or tag, with the setting honored by whichever extension owns the active picker during the Python Environments rollout.
