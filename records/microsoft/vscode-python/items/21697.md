# Issue #21697 — Allow disabling the "Recommended" tag for python interpreter selection

[https://github.com/microsoft/vscode-python/issues/21697](https://github.com/microsoft/vscode-python/issues/21697)

## Summary

Keep open: the interpreter picker still exposes recommendation wording without a workspace setting to suppress it. The request has 18 upvotes, explicit maintainer support for retaining it, and accepted-work labels; no verified canonical covers the same request.

## Change summary

Allow repositories to disable the interpreter picker's “Recommended” tag through .vscode/settings.json so users do not mistake extension-generated guidance for repository policy.

## Best solution

Provide workspace-configurable control over recommendation wording while preserving interpreter availability and selection behavior. Agree on the public setting and its scope across the legacy picker and the Python Environments experience before implementation; a maintainer can transfer the UI work to https://github.com/microsoft/vscode-python-environments if appropriate.
