# Issue #25325 — Tool to install packages from requirements.txt

[https://github.com/microsoft/vscode-python/issues/25325](https://github.com/microsoft/vscode-python/issues/25325)

## Summary

Keep open: this team-authored request is accepted with `needs PR`, and current main still lacks a tool input for installing directly from requirements files.

## Change summary

Allow the environment tooling to install dependencies from requirements.txt using uv without returning the workflow to a terminal.

## Best solution

Extend `install_python_packages` or the configure/create-environment tool contract to accept requirements files and delegate their installation through the Python Environments API using uv.
