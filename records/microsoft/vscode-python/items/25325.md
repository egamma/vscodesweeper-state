# Issue #25325 — Tool to install packages from requirements.txt

[https://github.com/microsoft/vscode-python/issues/25325](https://github.com/microsoft/vscode-python/issues/25325)

## Summary

Keep open: this team-authored request is accepted with `needs PR`, and current main still lacks explicit support for installing dependency files through the package-install tool.

## Change summary

Allow the environment tools to install dependencies from requirements.txt using the environment's fast package-management path.

## Best solution

Extend `install_python_packages` to accept requirements files and pass them through the Python Environments package-management API, then let environment configuration invoke that capability when appropriate without leaving the chat workflow.
