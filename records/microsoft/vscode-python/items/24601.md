# Issue #24601 — DocTest unittest discovery adapter

[https://github.com/microsoft/vscode-python/issues/24601](https://github.com/microsoft/vscode-python/issues/24601)

## Summary

The requested doctest integration remains necessary: current main explicitly skips standard DocTestCase instances with short IDs, while other doctests are still interpreted through a unittest-specific tree shape. The issue is already correctly routed to testing and has maintainer support for a contribution.

## Change summary

Represent unittest-adapted doctests with their actual source file and line so Test Explorer hierarchy, navigation, and gutter locations work correctly.

## Best solution

Add dedicated DocTestCase handling in python_files/unittestadapter/pvsc_utils.py using the underlying doctest filename and line metadata, with defined behavior for sources outside the discovery root or with no filename. Extend the unittest adapter tests to cover module, class, function, src-layout, and unavailable-source cases without changing ordinary unittest tree construction.
