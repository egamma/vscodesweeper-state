# Issue #24601 — DocTest unittest discovery adapter

[https://github.com/microsoft/vscode-python/issues/24601](https://github.com/microsoft/vscode-python/issues/24601)

## Summary

A real doctest integration gap remains on main: unittest-discovered doctests still lack source-aware tree construction and navigation. The issue is already correctly classified and routed to testing.

## Change summary

Display unittest-adapted doctests under their actual source files and enable navigation to their source lines.

## Best solution

Special-case doctest.DocTestCase in python_files/unittestadapter/pvsc_utils.py, deriving the test path and line from its underlying DocTest while defining safe placement for sources outside the discovery root or without a filename.
