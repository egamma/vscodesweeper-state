# Issue #24601 — DocTest unittest discovery adapter

[https://github.com/microsoft/vscode-python/issues/24601](https://github.com/microsoft/vscode-python/issues/24601)

## Summary

The accepted request remains necessary: current main explicitly skips standard unittest doctests with short IDs and still derives other test locations from IDs rather than doctest metadata. It is already routed to area-testing, with no canonical issue or complete implementation found.

## Change summary

Add first-class unittest discovery support for doctests with accurate Test Explorer hierarchy and source locations.

## Best solution

Handle doctest.DocTestCase explicitly in python_files/unittestadapter/pvsc_utils.py using its underlying filename, line number, and qualified name, with defined behavior for sources outside the discovery root or lacking a filename. Add discovery coverage for module-, class-, and function-level doctests without requiring users to patch test IDs.
