# Issue #21443 — Support viewings `numpy` `.npy` and `.npz` and `pickle` `.pkl` files natively by double clicking on them

[https://github.com/microsoft/vscode-python/issues/21443](https://github.com/microsoft/vscode-python/issues/21443)

## Summary

Keep open for a concrete design proposal: the request exceeded the community-feedback threshold, and a maintainer explicitly accepted it for future consideration. Current main does not provide a native custom editor for these file types.

## Change summary

Open NumPy .npy/.npz and pickle .pkl files as inspectable, read-only data views when users double-click them.

## Best solution

Develop the requested proposal before implementation, defining the read-only viewing experience, handling of large or unsupported arrays, ownership within the Python extension family, and dependency behavior without automatically installing packages. Any pickle support must avoid unsafe deserialization of untrusted files; a JavaScript reader such as npyjs may cover part of the NumPy case without requiring NumPy in the selected environment.

## Vision fit
