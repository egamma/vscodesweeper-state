## Summary

Keep open because this team-authored request identifies a real unsupported capability: runTests only operates on discovered tests and cannot explicitly invoke a nonstandard pytest file. The tool is implemented by VS Code core, so a maintainer should transfer the request there.

## Change summary

Allow runTests to execute an explicitly supplied pytest file even when its name excludes it from normal discovery.
