## Summary

The confirmed gap remains: runTests cannot execute an explicitly requested pytest file unless that file was already discovered. This team-authored issue has no referenced fixing commit or verified duplicate, so it must remain open.

## Change summary

Allow runTests to execute an explicitly named pytest file that intentionally falls outside normal discovery patterns.

## Best solution
