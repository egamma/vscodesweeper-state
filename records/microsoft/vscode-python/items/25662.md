# Issue #25662 — runTests can't find tests in a file

[https://github.com/microsoft/vscode-python/issues/25662](https://github.com/microsoft/vscode-python/issues/25662)

## Summary

Explicitly running a pytest file excluded from normal discovery remains an unsupported capability, not something the existing discovery settings fully address. Keep this team-authored issue open for coordination between the Python testing integration and VS Code's runTests tool; no qualifying fix or canonical duplicate was found.

## Change summary

Allow runTests to collect and run an explicitly requested pytest file whose name intentionally excludes it from ordinary test discovery.

## Best solution

Support targeted collection and execution of explicitly requested files without permanently adding their tests to normal discovery or ordinary run-all operations. Coordinate the Python testing provider with VS Code's runTests tool; a maintainer can transfer this to https://github.com/microsoft/vscode if the required testing API or tool contract belongs there.
