# Issue #10645 — Add Profiling (code performance analysis) capability

[https://github.com/microsoft/vscode-python/issues/10645](https://github.com/microsoft/vscode-python/issues/10645)

## Summary

Keep open: this is highly requested, accepted proposal-stage work, and maintainers have explicitly said they would like to pursue it eventually. Current main offers limited PyTorch/TensorBoard integration but no general Python profiling UI covering the central request.

## Change summary

Add an integrated Python profiling experience with searchable and sortable performance statistics, potentially expanding to flame graphs and memory profiling.

## Best solution

Develop the requested proposal to define supported profiler backends, data interchange, and shared views before implementation. The design should integrate established Python profilers and determine whether the frontend belongs in this extension, a dedicated profiler extension, or ultimately a reusable VS Code profiling API.
