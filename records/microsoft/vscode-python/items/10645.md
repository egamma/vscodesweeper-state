# Issue #10645 — Add Profiling (code performance analysis) capability

[https://github.com/microsoft/vscode-python/issues/10645](https://github.com/microsoft/vscode-python/issues/10645)

## Summary

Keep open: this is accepted proposal-stage work with substantial community interest, and maintainers have explicitly said they would like to pursue it eventually. The extension still lacks the requested general profiling frontend.

## Change summary

Add a user-friendly Python profiling workflow with sortable and searchable performance results, potentially expanding to flame graphs and memory profiling.

## Best solution

Develop the requested proposal to define supported profiler backends, CPU-versus-memory scope, result views, and an adapter boundary that can integrate community profilers without coupling the core extension to one tool. The existing internal-backlog goal can inform prioritization, but it should not replace this concrete public request.
