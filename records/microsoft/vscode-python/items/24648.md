# Issue #24648 — Autoreload capability in native REPL

[https://github.com/microsoft/vscode-python/issues/24648](https://github.com/microsoft/vscode-python/issues/24648)

## Summary

A real capability gap remains in the native REPL, and the request exceeded the documented community-feedback threshold with 8 upvotes. It should remain open and be routed to the REPL area for design.

## Change summary

Add manual and optional automatic reloading of changed imported modules in native REPL sessions.

## Best solution

Provide an opt-in native REPL module-reloading mode, including a manual reload path that avoids the continuous performance cost noted by the reporter. The REPL area should coordinate its design with the broader IPython integration request at https://github.com/microsoft/vscode-python/issues/22139 without treating that broader terminal request as a duplicate.
