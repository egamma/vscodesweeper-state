A real native-REPL capability gap remains on current main, and the request exceeded the documented community-interest threshold. Route it to the REPL area for design and prioritization.

## Change summary

Add manual and opt-in automatic reloading of changed imported modules in the native Python REPL.

## Best solution

Add an opt-in reload mode to the native REPL execution path in python_files/python_server.py, including a manual trigger and an automatic mode that is disabled by default to avoid the reported performance cost.
