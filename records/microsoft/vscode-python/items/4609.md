## Change summary

Organize Python helper files into task-specific directories so adding python_files to sys.path cannot shadow unrelated user modules.

## Best solution

Move remaining top-level helpers into task-oriented subdirectories and update their TypeScript launch references, while narrowing each PYTHONPATH addition to the directory required by that task.
