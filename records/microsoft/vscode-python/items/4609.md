# Issue #4609 — Separate files in pythonFiles by task

[https://github.com/microsoft/vscode-python/issues/4609](https://github.com/microsoft/vscode-python/issues/4609)

## Summary

Keep open: this team-authored engineering-debt item is explicitly staged with `needs spike`, and the latest maintainer response confirms the restructuring is still wanted. Current main still contains numerous unrelated top-level scripts under `python_files` and passes that shared directory into testing subprocesses.

## Change summary

Separate Python helper files into task-specific directories to reduce module-name collisions when helper paths are exposed to user processes.

## Best solution

Spike a task-oriented `python_files` layout, move each helper into the narrowest functional directory, and update callers to expose only the directory required by that subprocess. Preserve the existing testing adapter subdirectories while removing reliance on the shared top-level path where practical.
