# Issue #24087 — Python Test uses incorrect python environment

[https://github.com/microsoft/vscode-python/issues/24087](https://github.com/microsoft/vscode-python/issues/24087)

## Summary

Keep open for the accepted investigation: multiple users confirmed that native-locator mode makes test discovery run with an interpreter other than the selected conda environment. The related fix merged before a maintainer deliberately reopened this team-authored issue and applied `needs spike`, so that commit cannot justify another completed close.

## Change summary

Pytest discovery uses a system or unrelated Python interpreter instead of the workspace's selected conda environment when the native locator is enabled.

## Best solution

Trace the selected-environment handoff from the native locator into the testing execution service and ensure discovery launches with the selected conda interpreter on Windows and macOS. Preserve the working JavaScript-locator behavior while covering conda environments that might also be considered by the Pixi handler.
