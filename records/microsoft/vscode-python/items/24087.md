# Issue #24087 — Python Test uses incorrect python environment

[https://github.com/microsoft/vscode-python/issues/24087](https://github.com/microsoft/vscode-python/issues/24087)

## Summary

Keep this accepted testing bug open: multiple reporters confirmed that discovery used another interpreter instead of the selected conda environment. Execution paths have changed since those confirmations, but the linked PR predates reopening and no qualifying subsequent fix or older same-symptom canonical was established.

## Change summary

Pytest discovery and execution should use the selected conda environment rather than falling back to a system or pyenv interpreter when the native locator is enabled.

## Best solution

Ensure native-locator environment metadata reaches test subprocess creation with the correct conda environment directory and selected interpreter. Retest the documented Windows and macOS cases against both the legacy execution factory and the Python Environments integration before deciding whether further changes belong in this repository or the locator.
