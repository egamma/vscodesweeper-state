# Issue #23703 — Python longstring tag vs block comment tag in Vscode 

[https://github.com/microsoft/vscode-python/issues/23703](https://github.com/microsoft/vscode-python/issues/23703)

## Summary

The incorrect block-comment declaration remains in VS Code's built-in Python language configuration. This accepted issue should stay open while a maintainer transfers it to microsoft/vscode or coordinates the change there.

## Change summary

Remove Python triple-quoted string delimiters from the LanguageConfiguration block-comment declaration.

## Best solution

Remove `comments.blockComment` from `extensions/python/language-configuration.json` in microsoft/vscode while retaining `#` as `lineComment`, so API consumers do not mistake string literals for Python comments.
