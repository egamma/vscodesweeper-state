## Summary

The requested removal remains unresolved: VS Code's built-in Python language configuration still declares triple-quoted strings as block-comment delimiters. Keep this accepted item open; a maintainer can transfer it to VS Code core, which owns that declaration.

Remove Python's block-comment delimiter declaration so extensions consuming LanguageConfiguration do not mistake triple-quoted strings for actual comments.
