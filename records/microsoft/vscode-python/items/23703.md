# Issue #23703 — Python longstring tag vs block comment tag in Vscode 

[https://github.com/microsoft/vscode-python/issues/23703](https://github.com/microsoft/vscode-python/issues/23703)

## Summary

The defect remains on current main: VS Code exposes a triple-quoted string delimiter as Python's block-comment token, while this extension's higher-priority language configuration leaves comments undefined and therefore does not override it. The accepted `needs PR` work should remain open and route to the editor area.

## Change summary

Remove the Python block-comment declaration so consumers of VS Code's language configuration do not treat triple-quoted strings as comments.

## Best solution

Update `getLanguageConfiguration()` in `src/client/language/languageConfiguration.ts` to provide Python's `#` line-comment configuration without a block-comment pair, overriding the built-in VS Code configuration, and update its unit test accordingly.
