# Issue #25915 — Run selection/line in terminal fails with IPython

[https://github.com/microsoft/vscode-python/issues/25915](https://github.com/microsoft/vscode-python/issues/25915)

## Summary

The detailed IPython/plain-Python comparison demonstrates a terminal REPL execution defect. Current main still routes custom launch arguments through the affected selection-execution path, so this should remain open with terminal and REPL ownership.

## Change summary

Run Selection/Line starts an IPython terminal configured through python.terminal.launchArgs but fails to send the selected code.

## Best solution

Make terminal selection delivery work with custom REPL prompts such as IPython, without depending on CPython's prompt shape, and add coverage for an IPython-style launchArgs configuration in the terminal execution tests.
