# Issue #11812 — Allow "Run Python File in Terminal" button to be configurable

[https://github.com/microsoft/vscode-python/issues/11812](https://github.com/microsoft/vscode-python/issues/11812)

## Summary

Keep open for proposal work: this team-authored request remains the canonical issue for making the Run Python File affordance configurable, and its `needs proposal` label records an accepted design decision that still needs resolution.

## Change summary

Make the Run Python File in Terminal button configurable for launch behavior, script or interpreter arguments, module execution, and stopping an active run.

## Best solution

Define a focused proposal for configuring the run-button command, including whether it delegates to a launch configuration and how arguments, module execution, and stopping are represented. Preserve the current lightweight terminal command as the default while allowing users to opt into the configurable behavior.
