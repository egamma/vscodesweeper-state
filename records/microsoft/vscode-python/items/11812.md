# Issue #11812 — Allow "Run Python File in Terminal" button to be configurable

[https://github.com/microsoft/vscode-python/issues/11812](https://github.com/microsoft/vscode-python/issues/11812)

## Summary

Keep this team-authored, accepted feature request open as the canonical proposal for configuring Run Python File behavior. Current main supports interpreter launch arguments and a dedicated terminal, but it does not provide the broader launch-configuration, script-argument, module, and stop behavior requested here.

## Change summary

Make the Run Python File button configurable, including launch.json-style execution, script or interpreter arguments, module execution, and stopping an existing run.

## Best solution

Retain this issue as the canonical design discussion and produce a scoped proposal for selecting configurable run behavior while preserving the simple current-file default. The implementation likely requires coordination between the editor-title commands in package.json, terminal execution under src/client/terminals/codeExecution/, and launch configuration handling owned by the Python Debugger extension.
