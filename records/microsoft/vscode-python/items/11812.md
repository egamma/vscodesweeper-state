# Issue #11812 — Allow "Run Python File in Terminal" button to be configurable

[https://github.com/microsoft/vscode-python/issues/11812](https://github.com/microsoft/vscode-python/issues/11812)

## Summary

A real configurability gap remains on main, and this team-authored request is accepted for proposal work with substantial community support. Existing options cover only parts of the request, so it should remain the canonical issue.

## Change summary

Make the editor's Run Python File button configurable for launch profiles, interpreter and script arguments, module execution, terminal reuse, and stopping execution.

## Best solution

Design a configurable run profile for the editor button that can invoke Run Without Debugging or direct terminal execution, including script/module arguments and stop behavior. Preserve this issue as the canonical design tracker and coordinate launch.json-backed behavior with the Python Debugger extension where necessary.
