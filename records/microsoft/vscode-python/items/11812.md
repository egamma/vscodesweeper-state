# Issue #11812 — Allow "Run Python File in Terminal" button to be configurable

[https://github.com/microsoft/vscode-python/issues/11812](https://github.com/microsoft/vscode-python/issues/11812)

## Summary

Keep open: this team-authored, accepted proposal remains the canonical request for configuring the Run Python File action, and current source still exposes only partial configuration.

## Change summary

Allow the editor Run Python File button to use configurable execution behavior, including launch configurations, script arguments, module execution, and stopping the running process.

## Best solution

Design the run action so users can select a launch.json-backed Run Without Debugging configuration or direct terminal execution, including script arguments, module execution, and stop behavior. Coordinate its narrower configuration scope with the broader terminal-experience tracker at https://github.com/microsoft/vscode-python/issues/15770.
