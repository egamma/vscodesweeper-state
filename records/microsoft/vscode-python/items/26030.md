# Issue #26030 — Python interpreter is attempting to run .venv as the python command

[https://github.com/microsoft/vscode-python/issues/26030](https://github.com/microsoft/vscode-python/issues/26030)

## Summary

Verified duplicate of the broader open activated-environment selection bug: the extension replaces the saved interpreter with the raw relative VIRTUAL_ENV value, causing `.venv` itself to be executed.

## Change summary

Preserve the selected workspace interpreter across reloads instead of attempting to execute a relative `.venv` directory as Python.

## Best solution

Consolidate on https://github.com/microsoft/vscode-python/issues/23833 and ensure activated-environment selection never overwrites the workspace interpreter with an unresolved relative VIRTUAL_ENV path.
