- **Confirmed remaining defect:** In src/client/activation/progress.ts, beginProgress() returns progressDeferred.promise to window.withProgress(). Starting progress and then disposing without an end notification therefore leaves the progress promise pending.
- **Current integration:** src/client/activation/node/languageServerProxy.ts and src/client/activation/jedi/languageServerProxy.ts register ProgressReporting in their disposables collections and dispose those collections in stop(). The Node proxy also has a delegated Pylance API path, so the source finding establishes the shared reporter's cleanup defect, not that every current Pylance session uses it.

Maintainer replies acknowledge the shared progress API and distinguish notification cleanup from fixing the server crash.
