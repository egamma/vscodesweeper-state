# Issue #20752 — Support discovering interpreters managed using `asdf-vm` which are run from workspace directory

[https://github.com/microsoft/vscode-python/issues/20752](https://github.com/microsoft/vscode-python/issues/20752)

## Summary

Keep this accepted, community-supported request open: workspace-dependent asdf interpreter resolution is not covered by the inspected settings or legacy resolver. The Python Environments integration provides a promising implementation boundary, but neither the discussion nor current source establishes that it delivers the requested behavior.

## Change summary

Support discovering and resolving asdf-managed Python interpreters in the relevant workspace directory, including different versions behind the same shim in multi-root workspaces.

## Best solution

Provide workspace-aware asdf interpreter resolution through the Python Environments manager/API boundary, preserving independent interpreter choices for each workspace folder. A maintainer can transfer this request to https://github.com/microsoft/vscode-python-environments if that extension should own the implementation, retaining the existing demand and reproduction details.
