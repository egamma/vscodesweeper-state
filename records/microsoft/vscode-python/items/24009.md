## Summary

Already fixed and shipped: closing a native REPL now clears its cached singleton, so opening another REPL recreates it and prompts for the working directory again in a multi-root workspace.

## Change summary

Opening a new native REPL in a multi-root workspace reused the working-directory choice from the previous closed session.
