## Summary

Fixed and shipped: closing a native REPL now clears its cached singleton, so reopening it creates a new session and prompts for the working directory again in multi-root workspaces.

## Change summary

Reopening the native REPL in a multi-root workspace should prompt for its working directory instead of reusing the previous selection.
