# Issue #21151 — "Run tests at cursor" takes exponentially longer with more pytest tests

[https://github.com/microsoft/vscode-python/issues/21151](https://github.com/microsoft/vscode-python/issues/21151)

## Summary

Fixed in VS Code core: gutter-triggered test runs now collapse fully selected parameterized children into their runnable parent, avoiding the process-per-variant slowdown.

## Change summary

Running a parameterized pytest test at the cursor becomes dramatically slower as the number of parameter variants increases.

## Best solution

Keep the VS Code core fix from commit 6ab3a15691ff9a1aa619a53d9dcd29c0b53d76a1, shipped in VS Code 1.92.0; no additional vscode-python change is needed.
