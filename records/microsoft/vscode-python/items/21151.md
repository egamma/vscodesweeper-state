# Issue #21151 — "Run tests at cursor" takes exponentially longer with more pytest tests

[https://github.com/microsoft/vscode-python/issues/21151](https://github.com/microsoft/vscode-python/issues/21151)

## Summary

Fixed and shipped in VS Code core: gutter-triggered test runs now collapse complete sets of parameterized children to their runnable parent, avoiding the reported process explosion.

## Change summary

Running parameterized pytest tests at the cursor became dramatically slower as the number of parameter cases increased.

## Best solution

Keep the generic test-run simplification shipped in VS Code 1.92.0; no additional vscode-python change is needed.
