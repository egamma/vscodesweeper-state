# Issue #25866 — `python.testing.autoTestDiscoverOnSaveEnabled` is running test discovery on change to any file (not just test files)

[https://github.com/microsoft/vscode-python/issues/25866](https://github.com/microsoft/vscode-python/issues/25866)

## Summary

The defect remains present on current main, but draft PR https://github.com/microsoft/vscode-python/pull/26083 already implements the targeted fix. Keep the issue open until that implementation is reviewed and merged.

## Change summary

The default discovery-on-save pattern matches every Python file, causing full test discovery after saving non-test source files and temporarily disrupting test rerun and debug workflows.

## Best solution

Review and land https://github.com/microsoft/vscode-python/pull/26083, narrowing the default save trigger to conventional pytest/unittest filenames and conftest.py while preserving user-configured patterns. The separate incremental test-tree rebuilding work should remain tracked by https://github.com/microsoft/vscode-python/issues/25822.
