# Issue #24011 — Include cwd in repl editor tooltip in multi root cases

[https://github.com/microsoft/vscode-python/issues/24011](https://github.com/microsoft/vscode-python/issues/24011)

## Summary

This accepted REPL improvement remains necessary on current main: multi-root users select a working directory, but the resulting REPL editor is still identified only as “Python REPL.” The existing `needs PR` and `area-repl` labels already route it appropriately.

## Change summary

Show the selected working directory in the native REPL editor UI so REPL sessions are unambiguous in multi-root workspaces.

## Best solution

Carry the cwd selected by `NativeRepl.setReplDirectory()` into the native REPL editor presentation, ideally its tab tooltip or another persistent location, while keeping the normal single-root presentation concise.
