# Issue #25507 — Allow selecting environment as kernel WITHOUT jupyter

[https://github.com/microsoft/vscode-python/issues/25507](https://github.com/microsoft/vscode-python/issues/25507)

## Summary

This requests extending the native Python REPL controller to regular notebooks, but notebook kernel selection belongs to the Jupyter extension. Keep it open for a maintainer to assess and transfer rather than closing from routing evidence alone.

## Change summary

Allow a selected Python environment to execute regular notebook cells without installing Jupyter in that environment.

## Best solution

A maintainer should transfer this request to https://github.com/microsoft/vscode-jupyter, where regular notebook kernel discovery and execution are owned, and clarify whether avoiding the Jupyter extension or only the Python jupyter package is required.

- **Evidence:** The public roadmap's family-of-extensions direction assigns per-concern capabilities to sibling extensions instead of rebuilding them in the core Python extension.
