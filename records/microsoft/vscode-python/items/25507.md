# Issue #25507 — Allow selecting environment as kernel WITHOUT jupyter

[https://github.com/microsoft/vscode-python/issues/25507](https://github.com/microsoft/vscode-python/issues/25507)

## Summary

This is a valid notebook-kernel feature request, but regular notebook execution is owned by the Jupyter extension rather than vscode-python. Keep it open for a maintainer to transfer, with data-science routing in the meantime.

## Change summary

Allow a selected Python environment to execute regular VS Code notebook cells without installing the Jupyter runtime.

## Best solution

The Jupyter extension should offer a lightweight plain-interpreter kernel option that does not depend on a Jupyter runtime, potentially reusing the Python extension's native execution support. A maintainer can transfer this request to https://github.com/microsoft/vscode-jupyter.
