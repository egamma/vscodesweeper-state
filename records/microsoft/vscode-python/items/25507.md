# Issue #25507 — Allow selecting environment as kernel WITHOUT jupyter

[https://github.com/microsoft/vscode-python/issues/25507](https://github.com/microsoft/vscode-python/issues/25507)

## Summary

Keep open: the native REPL controller is not evidence of a supported, standalone notebook workflow without Jupyter. No verified older duplicate or documented scope decision covers this request; notebook ownership warrants maintainer review.

## Change summary

Allow ordinary VS Code notebooks to execute using the selected Python environment and native REPL backend without installing Jupyter.

## Best solution

Decide whether ordinary notebooks should support the lightweight native REPL backend, distinguishing removal of the Jupyter extension requirement from removal of Python-side Jupyter dependencies. A maintainer can transfer this to https://github.com/microsoft/vscode-jupyter if notebook execution owns the requested integration.

## Evidence

- **Existing capability and limits:** package.json declares python.startNativeREPL and python.REPL.sendToNativeREPL, but neither declares a standalone notebook execution mode. src/client/repl/replCommands.ts registers the command to obtain the active interpreter and open the native REPL.
- **Controller is tied to the REPL lifecycle:** src/client/repl/replController.ts creates a 'pythonREPL' controller for 'jupyter-notebook' documents using the selected interpreter. However, src/client/repl/nativeRepl.ts creates that controller with the native REPL and disposes it when the REPL document closes; src/client/repl/replCommandHandler.ts opens documents with asRepl: 'Python REPL'. This offers a technical lead, not proof of an intentionally supported Jupyter-free ordinary-notebook workflow.
- **Documented notebook ownership:** README.md:60-74 documents notebook support through the Jupyter extension and instructs users to install it. .github/ISSUE_TEMPLATE/config.yml routes Jupyter-related issues to https://github.com/microsoft/vscode-jupyter/issues.

Neither reports the requested native-REPL-backed, Jupyter-free notebook capability, so neither satisfies the re-review duplicate bar.
