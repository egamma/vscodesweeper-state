# Issue #25744 — Venv activation command leaks into stdin when running tasks on Windows

[https://github.com/microsoft/vscode-python/issues/25744](https://github.com/microsoft/vscode-python/issues/25744)

## Summary

The legacy command-based activation path can contaminate task stdin, but the supported shell-startup activation avoids sending activation text through the terminal; the reporter confirmed that migration resolves the issue.

## Change summary

Prevent virtual-environment activation commands from appearing in stdin when VS Code tasks start.

## Best solution

Use the Python Environments extension with `python-envs.terminal.autoActivationType` set to `shellStartup`; this activates through shell initialization rather than the legacy `sendText` path.
