# Issue #25744 — Venv activation command leaks into stdin when running tasks on Windows

[https://github.com/microsoft/vscode-python/issues/25744](https://github.com/microsoft/vscode-python/issues/25744)

## Summary

The confirmed leak comes from legacy command-based activation; the supported shell-startup activation avoids stdin entirely, and the reporter confirmed that migration resolves the issue.

## Change summary

Prevent virtual-environment activation text from entering task stdin and breaking interactive programs.

## Best solution

Use the Python Environments extension with `python-envs.terminal.autoActivationType` set to `shellStartup`, keeping activation in the shell profile rather than sending commands through terminal stdin.
