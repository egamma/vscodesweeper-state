# Issue #22160 — VSCode slow with extension enabled

[https://github.com/microsoft/vscode-python/issues/22160](https://github.com/microsoft/vscode-python/issues/22160)

## Summary

Keep open: profiling confirmed that large test discovery can heavily block the extension host, and the issue remains accepted with `needs PR`. Later communication changes may have improved performance, but there is no current reproduction result or fixing commit that resolves this report.

## Change summary

Test discovery in a workspace with roughly 23,000 pytest tests makes the extension host and unrelated editor operations sluggish for up to two minutes.

## Best solution

Profile current test discovery on a Sentry-scale workspace and optimize result ingestion so large test trees do not block the extension host; retain automatic discovery while processing updates incrementally or yielding between batches.
