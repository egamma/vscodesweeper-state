# Issue #22160 — VSCode slow with extension enabled

[https://github.com/microsoft/vscode-python/issues/22160](https://github.com/microsoft/vscode-python/issues/22160)

## Summary

Keep open as accepted testing-performance work. The reporter isolated severe extension-host blocking to test discovery in a very large pytest workspace, and the issue already carries `needs PR`; later transport changes may have helped but do not establish that the remaining slowdown is resolved.

## Change summary

Large pytest discovery runs make the extension host and unrelated editor operations sluggish for tens of seconds.

## Best solution

Profile current discovery of 20,000–75,000 tests and reduce synchronous extension-host work while decoding results and updating the VS Code test tree, using batching or yielding where appropriate. Preserve the named-pipe architecture while benchmarking editor responsiveness as well as total discovery time.
