# Issue #22160 — VSCode slow with extension enabled

[https://github.com/microsoft/vscode-python/issues/22160](https://github.com/microsoft/vscode-python/issues/22160)

## Summary

Large pytest discoveries have demonstrably blocked the extension host and degraded editor responsiveness. This remains accepted work under `needs PR`, with a later large-suite performance report explicitly consolidated here.

## Change summary

Test discovery for workspaces containing tens of thousands of tests makes the extension host and unrelated editor operations sluggish.

## Best solution

Profile and optimize discovery payload processing and test-tree population in `src/client/testing/testController/common/testDiscoveryHandler.ts` and related utilities, benchmarking 20,000–75,000 tests to prevent long extension-host stalls.
