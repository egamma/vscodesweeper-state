# Issue #25718 — pytest discovery does not use specified environment

[https://github.com/microsoft/vscode-python/issues/25718](https://github.com/microsoft/vscode-python/issues/25718)

## Summary

The project-based testing implementation did not conclusively resolve this bug: a second user reproduced the same behavior on the latest release after the relevant PRs merged, and the active testing-reliability workstream explicitly retains this issue for investigation. Keep it open and route it to the testing area.

## Change summary

Pytest discovery in a monorepo uses the system interpreter instead of the Python Environments project-specific virtual environment.

## Best solution

Instrument and verify the environment-extension selection path during test discovery, then ensure each discovered Python project consistently runs pytest with its assigned environment even during startup and environment-change races. The existing workstream recommends recording the discovery environment source before correcting the remaining path.
