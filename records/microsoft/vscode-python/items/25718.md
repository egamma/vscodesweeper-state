# Issue #25718 — pytest discovery does not use specified environment

[https://github.com/microsoft/vscode-python/issues/25718](https://github.com/microsoft/vscode-python/issues/25718)

## Summary

This remains an accepted testing bug: project-based testing support merged, but a later user reproduced the wrong-environment behavior and the open testing workstream still tracks it. Route it to the testing area rather than closing it.

## Change summary

Pytest discovery in a monorepo can launch with the system interpreter instead of the environment assigned to the Python subproject.

## Best solution

Instrument whether project discovery enters the environment-extension path, then ensure each project adapter receives its resolved environment before pytest discovery starts or is rediscovered when that environment becomes available.
