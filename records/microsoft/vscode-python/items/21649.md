# Issue #21649 — Strings autocompleted as paths

[https://github.com/microsoft/vscode-python/issues/21649](https://github.com/microsoft/vscode-python/issues/21649)

## Summary

The requested suppression of Jedi's automatic path suggestions is implemented upstream and adopted on current main. Jedi now filters out path completions, removing the suggestions that interrupted ordinary strings and triple-quoted text.

## Change summary

Stop offering filesystem paths automatically when typing Python string literals, especially when Enter should start a new line in triple-quoted text.

## Best solution

Close as completed using the adopted upstream fix, which removes Jedi path completions without requiring editor.suggest.showFiles to be disabled. The first shipping Python extension version was not established.
