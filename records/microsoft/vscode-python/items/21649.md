# Issue #21649 — Strings autocompleted as paths

[https://github.com/microsoft/vscode-python/issues/21649](https://github.com/microsoft/vscode-python/issues/21649)

## Summary

The bundled Jedi language server no longer returns path completion items, resolving the unwanted string completions. The fixed dependency shipped in Python extension 2025.0.0.

## Change summary

Prevent Jedi from suggesting workspace paths whenever a Python string is opened.

## Best solution

Keep the bundled jedi-language-server at version 0.42.0 or newer, where path completion items are filtered before reaching VS Code.
