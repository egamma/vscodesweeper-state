# Issue #23833 — Python interpreter settings ignored if VS Code is launched from an activated environment

[https://github.com/microsoft/vscode-python/issues/23833](https://github.com/microsoft/vscode-python/issues/23833)

## Summary

The conflicting selection path remains on current main, and a maintainer confirmed that an explicit selection should win. The existing `needs spike` label marks this as accepted investigation, so it should remain open.

## Change summary

Launching VS Code from an activated environment overwrites the interpreter explicitly selected for the workspace.

## Best solution

Use the inherited `VIRTUAL_ENV` or `CONDA_PREFIX` only when the workspace has no explicit interpreter selection, consistently across the legacy path and Python Environments extension. Coordinate this with the active `defaultInterpreterPath` audit in https://github.com/microsoft/vscode-python/issues/25735.
