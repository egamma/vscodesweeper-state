# Issue #24103 — Don't monkey patch vscode ext API

[https://github.com/microsoft/vscode-python/issues/24103](https://github.com/microsoft/vscode-python/issues/24103)

## Summary

The reported monkey patch remains in the provided main checkout: TerminalManager replaces VS Code-owned Terminal.sendText methods and adds an isPatched property. Keep this accepted debt open and route it to the internal and terminal areas.

## Change summary

Stop mutating VS Code terminal API objects to intercept and log sendText calls.

## Best solution

TerminalManager should preserve VS Code-owned terminal objects and methods while retaining terminal creation, event delivery, and command execution behavior. Any retained command logging should be confined to Python-owned execution paths.

- **Reason:** Removing mutation of host-owned API objects supports stability and engineering health without adding product surface.
