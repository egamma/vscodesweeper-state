# Issue #14518 — vscode-variables only expanded in some environment vars from .env file 

[https://github.com/microsoft/vscode-python/issues/14518](https://github.com/microsoft/vscode-python/issues/14518)

## Summary

The requested substitution remains absent on current main, and maintainers have explicitly retained it as a proposal with a partner need. Route it to the environments area while the team decides whether implementation should move to the Python Environments extension.

## Change summary

Support documented, consistent expansion of VS Code variables such as `${workspaceFolder}` in every value read from `python.envFile`.

## Best solution

Define one documented `.env` substitution contract and implement `${workspaceFolder}` resolution in the environment-variable manager used by Python-family consumers, including Jupyter, debugging, and testing. Since broader parsing work is moving to `microsoft/vscode-python-environments`, a maintainer should either transfer this request there or keep the integration/API portion here.
