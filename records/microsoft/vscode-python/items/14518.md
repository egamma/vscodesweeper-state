# Issue #14518 — vscode-variables only expanded in some environment vars from .env file 

[https://github.com/microsoft/vscode-python/issues/14518](https://github.com/microsoft/vscode-python/issues/14518)

## Summary

The capability remains absent on current main, and this accepted partner request is already staged for design with `needs proposal`. It is the canonical issue for consistent `${workspaceFolder}` expansion in `.env` values.

## Change summary

Support VS Code variables such as `${workspaceFolder}` consistently in every value loaded from `python.envFile`.

## Best solution

Design and document workspace-aware `.env` parsing in the core Python extension, passing workspace context into the parser so `${workspaceFolder}` works uniformly for arbitrary variables and consumers such as Jupyter.
