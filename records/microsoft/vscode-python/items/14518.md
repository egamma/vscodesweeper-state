# Issue #14518 — vscode-variables only expanded in some environment vars from .env file 

[https://github.com/microsoft/vscode-python/issues/14518](https://github.com/microsoft/vscode-python/issues/14518)

## Summary

The requested VS Code-variable expansion remains absent on current main, while the accepted `needs proposal` and `partner ask` labels show that the work should remain open. Route it to the environments area for proposal and ownership.

## Change summary

Support VS Code variables such as `${workspaceFolder}` consistently in values loaded from `python.envFile`.

## Best solution

Define which VS Code variables are supported in environment files, then resolve them consistently before exposing the environment to debugging, testing, Jupyter, and other API consumers. The implementation should be coordinated with the environment-variable manager in microsoft/vscode-python-environments as that rollout assumes more environment handling.
