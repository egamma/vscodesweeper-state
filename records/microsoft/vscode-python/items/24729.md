# Issue #24729 — File paths placed without double quotes.

## Summary

Verified duplicate: the open shell-specific escaping issue covers PowerShell paths containing apostrophes, including this concrete Windows venv and script-path case.

## Change summary

Running a Python file from a Windows folder containing an apostrophe generates an invalid PowerShell command.

## Best solution

Consolidate on https://github.com/microsoft/vscode-python/issues/24126 and implement shell-aware argument escaping for interpreter, working-directory, and script paths rather than applying one quoting rule to every shell.
