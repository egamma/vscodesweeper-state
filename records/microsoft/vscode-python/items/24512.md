# Issue #24512 — Improve error popup for test failures- go to assertion and don't duplicate test code

[https://github.com/microsoft/vscode-python/issues/24512](https://github.com/microsoft/vscode-python/issues/24512)

## Summary

A real testing UX gap remains on current main: failure messages still navigate to the test item's function range and include pytest's complete traceback text. This team-authored feature request is already correctly routed to area-testing and should remain open.

## Change summary

Navigate failed tests directly to the failing assertion and omit duplicated source code from the inline failure widget.

## Best solution

Carry the assertion source location through the pytest execution payload and use it for the TestMessage location, while formatting the displayed failure text to remove the redundant source excerpt without losing assertion diagnostics.
