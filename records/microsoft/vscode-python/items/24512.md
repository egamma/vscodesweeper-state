# Issue #24512 — Improve error popup for test failures- go to assertion and don't duplicate test code

[https://github.com/microsoft/vscode-python/issues/24512](https://github.com/microsoft/vscode-python/issues/24512)

## Summary

Keep open in the testing area: current main still attaches pytest failure messages to the test item's function range and includes the full traceback, so the requested assertion-level navigation and deduplicated presentation remain unimplemented. This is also a team-authored request with explicit maintainer agreement.

## Change summary

Navigate from a pytest failure message directly to the failed assertion and omit duplicated test source from the error widget.

## Best solution

Extract the assertion file and line from pytest's structured failure or traceback data, use that location for the VS Code TestMessage, and format the displayed failure text without repeating source already visible at the destination.
