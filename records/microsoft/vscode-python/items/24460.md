# Issue #24460 — Support streaming output for native python REPL

[https://github.com/microsoft/vscode-python/issues/24460](https://github.com/microsoft/vscode-python/issues/24460)

## Summary

The streaming gap remains on current main: native REPL output is buffered until execution completes. This team-authored, source-reproducible issue should remain open in the REPL area.

## Change summary

Display native Python REPL output incrementally while code is running instead of only after completion.

## Best solution

Stream stdout and stderr chunks from python_files/python_server.py as JSON-RPC notifications, then append them to the active NotebookCellExecution in src/client/repl/replController.ts while execution remains in progress.
