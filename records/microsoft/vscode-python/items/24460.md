# Issue #24460 — Support streaming output for native python REPL

[https://github.com/microsoft/vscode-python/issues/24460](https://github.com/microsoft/vscode-python/issues/24460)

## Summary

The buffering defect remains directly visible on current main. This team-authored, help-wanted issue is the canonical tracker and should remain open.

## Change summary

Native Python REPL output is buffered until execution finishes instead of appearing incrementally.

## Best solution

Stream stdout and stderr from python_files/python_server.py as execution-time notifications, then append each chunk through the notebook execution in src/client/repl/replController.ts rather than waiting for one final response.
