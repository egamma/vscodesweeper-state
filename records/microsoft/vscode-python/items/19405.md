# Issue #19405 — Environment created with mamba missing prefix

[https://github.com/microsoft/vscode-python/issues/19405](https://github.com/microsoft/vscode-python/issues/19405)

## Summary

Keep this accepted environment-discovery request open: it exceeded the documented community threshold and carries both `community ask` and `needs proposal`. Current source has name fallbacks for Conda environments, but there is no issue-linked fix or confirmation that Mambaforge environments now receive the correct prefix name.

## Change summary

Display the correct environment prefix name and Python version for environments created through Mamba or Mambaforge.

## Best solution

Confirm the behavior with the current Python Environments extension and native locator, then ensure Mamba/Miniforge Conda records expose a stable environment name derived from their reported name or environment directory. A maintainer should decide whether the remaining implementation belongs in microsoft/vscode-python-environments or the native python-environment-tools locator while retaining this accepted request until ownership is resolved.
