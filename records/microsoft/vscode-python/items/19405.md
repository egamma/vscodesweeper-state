## Summary

The community-feedback process accepted this request with 17 upvotes, and its `needs proposal` and `community ask` labels protect it from cleanup closure. Environment discovery and naming now belong primarily to the Python Environments extension, so a maintainer should transfer this accepted request there rather than close it.

## Change summary

Display the correct environment prefix name for interpreters created through Mamba or Mambaforge, matching Conda-created environments.

## Best solution

Transfer the accepted request to https://github.com/microsoft/vscode-python-environments and ensure its Conda/Mamba discovery layer supplies consistent `name`, `displayName`, and `shortDisplayName` values for named environments. The vscode-python compatibility adapter should continue consuming those values without adding a separate Mamba-specific naming path.
