# Issue #20211 — `${env:<VARIABLE>}`  substitution is no longer working for `.env` files

[https://github.com/microsoft/vscode-python/issues/20211](https://github.com/microsoft/vscode-python/issues/20211)

## Summary

The reported substitution failure remains in the core extension's current parser: `${env:VARIABLE}` is classified as invalid and returned unchanged. Keep this accepted environments bug open; the related standardization request does not necessarily deliver the documented behavior this issue asks to restore.

## Change summary

Restore substitution of process environment variables referenced as `${env:VARIABLE}` inside `.env` files.

## Best solution

Make the core environment-file service resolve the reported process-variable references consistently for its synchronous and asynchronous consumers, preserving existing `${VARIABLE}` behavior. Coordinate with the broader standardization discussion without treating its unresolved syntax direction as completion of this bug.
