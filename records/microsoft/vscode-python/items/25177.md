## Summary

Verified duplicate: the open canonical issue tracks the same Django discovery failure caused by unittest arguments that are invalid for Django's test command.

## Change summary

Django test discovery fails after Configure Tests writes unittest arguments including a valueless `-v` flag.

## Best solution

Consolidate on https://github.com/microsoft/vscode-python/issues/24991 and update Django discovery so incompatible unittest defaults are not forwarded unchanged to `manage.py test`.
