# Issue #25177 — Unable to use test discovery for Django tests

[https://github.com/microsoft/vscode-python/issues/25177](https://github.com/microsoft/vscode-python/issues/25177)

## Summary

Verified duplicate of the older open Django discovery issue, which tracks the same incompatible unittest defaults and is already accepted with `needs PR`. Consolidating there preserves a single implementation target.

## Change summary

Configuring unittest writes `-v -s -p` discovery arguments that are forwarded unchanged to Django and can make Django test discovery fail.

## Best solution

Fix https://github.com/microsoft/vscode-python/issues/24991 by preventing the unittest configuration flow from passing incompatible generated defaults to Django, while preserving explicitly supported Django arguments.
