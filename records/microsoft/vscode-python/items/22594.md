# Issue #22594 — Enable per test output correlation for pytest

[https://github.com/microsoft/vscode-python/issues/22594](https://github.com/microsoft/vscode-python/issues/22594)

## Summary

Keep this accepted testing feature open: current main still does not associate captured output with successful tests. Related reports consolidate here, and the linked VS Code API request covers only an optional output-isolation capability, not this full feature.

## Change summary

Associate pytest stdout, stderr, and logging with individual test results, including successful tests, while respecting pytest capture configuration.

## Best solution

Complete per-test output correlation across the pytest plugin and TestRun result handling. Coordinate with the existing contributor work and settle whether successful-test output may also appear in the aggregate run output under the available VS Code API.
