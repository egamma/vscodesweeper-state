Keep open: this team-authored, accepted feature request still represents a source-confirmed gap on main and carries `needs PR`. Contributor investigation has established a viable pytest-side approach, although successful-test presentation remains constrained by the VS Code Testing API.

## Change summary

Correlate pytest-captured stdout, stderr, and logs with individual test results while respecting pytest capture options.

## Best solution

Implement capture and formatting in `python_files/vscode_pytest/__init__.py`, carry the structured output through the execution payload, and present it from the shared test execution handler. The implementation should preserve pytest's capture configuration and choose an acceptable successful-test presentation given the declined VS Code API request.
