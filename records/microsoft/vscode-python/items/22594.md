# Issue #22594 — Enable per test output correlation for pytest

[https://github.com/microsoft/vscode-python/issues/22594](https://github.com/microsoft/vscode-python/issues/22594)

## Summary

Keep open: this team-authored, accepted feature request still represents a concrete gap on main and already carries `needs PR`. Current pytest results correlate failure text but do not attach captured stdout, stderr, or logs to individual tests, and successful results receive no per-test output.

## Change summary

Correlate pytest-captured stdout, stderr, and logging with each test result while respecting pytest capture options and displaying available output for successful as well as failed tests.

## Best solution

Implement capture extraction and structured formatting in `python_files/vscode_pytest/__init__.py`, then attach it to the matching VS Code test result in `src/client/testing/testController/common/testExecutionHandler.ts`. The implementation should preserve pytest's `--capture` and `--show-capture` semantics and avoid duplicating per-test output into the main run stream where possible.
