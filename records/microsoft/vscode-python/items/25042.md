# Issue #25042 — Kernel is lost in the middle of working with a notebook

[https://github.com/microsoft/vscode-python/issues/25042](https://github.com/microsoft/vscode-python/issues/25042)

## Summary

Confirmed intermittent environment-discovery bug: a refresh reports existing virtual environments as removed, causing Jupyter to dispose the active controller. The issue was reopened and marked `needs PR`, so it should remain open and route to environments.

## Change summary

Prevent notebook kernels from being disconnected when environment discovery temporarily omits an existing virtual environment.

## Best solution

Make environment refreshes preserve an existing interpreter unless its deletion is confirmed, preventing transient locator results from emitting removal events that cause Jupyter to dispose an active kernel controller.
