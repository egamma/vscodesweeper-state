# Issue #26092 — "Copy test ID" includes `file://` gunk

[https://github.com/microsoft/vscode-python/issues/26092](https://github.com/microsoft/vscode-python/issues/26092)

## Summary

Still present on current main: project-based testing prefixes internal TestItem IDs with the project URI and `@@vsc@@`, while Copy Test ID writes that internal ID directly to the clipboard. Route this localized regression to the testing area.

## Change summary

Copy Test ID exposes the project-scoping URI and `@@vsc@@` separator instead of copying the runnable pytest ID.

## Best solution

Parse the project-scoped TestItem ID before formatting or copying it in `src/client/testing/utils.ts`, preserving legacy IDs and returning only the run ID to users.
