# Issue #26087 — Python extension fails to select Conda/Anaconda environment ("Invalid Python interpreter" & t.runInTerminal error)

[https://github.com/microsoft/vscode-python/issues/26087](https://github.com/microsoft/vscode-python/issues/26087)

## Summary

This remains an actionable environment-selection bug: detailed diagnostics and independent confirmations show that Conda selection fails specifically in no-folder Windows windows, while the same file works when its folder is opened. Route it to the environments area rather than closing; the failure crosses the core extension's terminal integration and the Python Environments extension's global-environment state.

## Change summary

Selecting a discovered Conda interpreter in a Windows no-folder window does not persist the global environment and prevents running the standalone Python file.

## Best solution

Make global interpreter selection persist for standalone files and ensure the core terminal integration can resolve that selected environment without requiring a workspace project. The environments-area owners should determine whether the state-resolution fix belongs in this repository's integration layer or in microsoft/vscode-python-environments.
