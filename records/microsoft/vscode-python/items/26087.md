# Issue #26087 — Python extension fails to select Conda/Anaconda environment ("Invalid Python interpreter" & t.runInTerminal error)

[https://github.com/microsoft/vscode-python/issues/26087](https://github.com/microsoft/vscode-python/issues/26087)

## Summary

The diagnostics establish a no-folder environment-selection failure: PET discovers both Conda interpreters, but the selected global environment immediately falls back to `python`, causing the core terminal bridge to reject execution. Keep this open and route it to environment ownership, with likely transfer to the Python Environments tracker.

## Change summary

Selecting a Conda interpreter for a standalone Python file fails, while opening the same file inside a folder works.

## Best solution

Make global or per-file environment selection work in no-folder windows and ensure the terminal execution bridge resolves that selection. Because the failure occurs with the Python Environments extension active, a maintainer should determine whether to transfer this to https://github.com/microsoft/vscode-python-environments or fix the integration boundary here.
