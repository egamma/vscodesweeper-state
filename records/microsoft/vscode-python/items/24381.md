# Issue #24381 — Run Python File button tries to run unsaved file

[https://github.com/microsoft/vscode-python/issues/24381](https://github.com/microsoft/vscode-python/issues/24381)

## Summary

Still present on current main: cancelling the save dialog returns no saved URI, but both run-file paths retain and execute the original untitled URI. Route this as a terminal/editor bug rather than a feature request.

## Change summary

Cancelling the save dialog for an untitled Python file causes the Run Python File button to execute the synthetic Untitled-N path.

## Best solution

Abort file execution when saving an untitled URI returns no saved URI, in both the standard and Python Environments extension execution paths in src/client/terminals/codeExecution/codeExecutionManager.ts.
