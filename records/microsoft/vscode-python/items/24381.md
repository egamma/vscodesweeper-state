# Issue #24381 — Run Python File button tries to run unsaved file

[https://github.com/microsoft/vscode-python/issues/24381](https://github.com/microsoft/vscode-python/issues/24381)

## Summary

The cancellation defect remains in current source: the Run Python File button can continue with the untitled URI when saving is cancelled. Classify this as a bug and route it to the terminal area.

## Change summary

Cancelling the Save dialog opened by Run Python File should abort execution instead of sending Python an Untitled-N filename.

## Best solution

Make cancelled saving of an untitled document stop file execution in both the legacy terminal path and the Python Environments integration path, while preserving execution of already-saved files and successful Save As operations.
