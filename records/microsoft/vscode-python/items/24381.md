# Issue #24381 — Run Python File button tries to run unsaved file

[https://github.com/microsoft/vscode-python/issues/24381](https://github.com/microsoft/vscode-python/issues/24381)

## Summary

Still present on current main: canceling the save dialog returns no saved URI, but both run-file paths continue with the original untitled URI. This is a bug rather than a feature request and should be routed to terminal/editor ownership.

## Change summary

Canceling Save As for an untitled Python file still runs its Untitled-N pseudo-path in the terminal.

## Best solution

Abort run-file execution when saving an untitled document is canceled, in both the standard and Python Environments extension paths, while retaining normal execution for clean and successfully saved files. Add regression coverage around the command handler and canceled save result.
