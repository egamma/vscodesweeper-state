# Issue #24381 — Run Python File button tries to run unsaved file

[https://github.com/microsoft/vscode-python/issues/24381](https://github.com/microsoft/vscode-python/issues/24381)

## Summary

Still present on main: cancelling the save leaves the original untitled URI in place, and execution proceeds with that invalid path. Reclassify this as a bug and route it to the terminal area.

## Change summary

Canceling the save dialog for an untitled Python file causes Run Python File to execute the Untitled-N path.

## Best solution

Represent a cancelled or failed save distinctly from “no save needed” and abort both execution paths in src/client/terminals/codeExecution/codeExecutionManager.ts when an untitled file was not saved. Add coverage for save cancellation so the original untitled URI is never passed to the terminal.
