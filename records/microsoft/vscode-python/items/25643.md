# Issue #25643 — Test coverage highlighting is missing for some folders in multi-root workspaces

[https://github.com/microsoft/vscode-python/issues/25643](https://github.com/microsoft/vscode-python/issues/25643)

## Summary

Still present on current main: multi-root coverage runs repeatedly overwrite the shared detailed-coverage callback, leaving it connected to only one workspace's coverage map. The existing area-testing classification is correct, so this should remain open for a fix.

## Change summary

Global coverage runs in multi-root workspaces omit line-level coverage details for files outside one workspace folder.

## Best solution

Configure one run-scoped loadDetailedCoverage callback that searches the coverage maps for every participating workspace and project, rather than replacing the callback during each concurrent workspace execution. Add a multi-root regression test that resolves details from files in at least two workspace folders.
