# Issue #25643 — Test coverage highlighting is missing for some folders in multi-root workspaces

[https://github.com/microsoft/vscode-python/issues/25643](https://github.com/microsoft/vscode-python/issues/25643)

## Summary

The multi-root coverage defect remains source-reproducible on current main. Each workspace overwrites the run profile's detailed-coverage callback, leaving coverage details available only from one workspace.

## Change summary

A global coverage run reports all files but omits line-level highlighting for files in some multi-root workspace folders.

## Best solution

Configure one run-level loadDetailedCoverage callback that searches the result resolvers for every participating workspace and project, rather than replacing the callback while each workspace executes. Add a multi-root test covering detailed coverage from both folders.
