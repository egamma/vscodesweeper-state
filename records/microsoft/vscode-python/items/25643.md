# Issue #25643 — Test coverage highlighting is missing for some folders in multi-root workspaces

[https://github.com/microsoft/vscode-python/issues/25643](https://github.com/microsoft/vscode-python/issues/25643)

## Summary

Keep open: current main overwrites the shared detailed-coverage callback separately for each workspace, leaving it able to retrieve coverage from only one folder. The newer project-based execution path still scopes that callback to one workspace, so the multi-root gap remains.

## Change summary

Global coverage runs report file totals for all workspace folders but omit line-level highlighting for files outside the final callback's workspace.

## Best solution

Ensure detailed coverage remains accessible for every participating workspace in a global coverage run, across both legacy and project-based testing. Preserve single-folder execution and existing coverage totals.
