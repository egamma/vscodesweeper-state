# Issue #25643 — Test coverage highlighting is missing for some folders in multi-root workspaces

[https://github.com/microsoft/vscode-python/issues/25643](https://github.com/microsoft/vscode-python/issues/25643)

## Summary

The multi-root coverage defect remains traceable on current main in the legacy workspace execution path: each workspace replaces the run profile's detailed-coverage callback, leaving it able to read coverage from only one workspace adapter. The issue is already correctly assigned to the testing area and should remain open.

## Change summary

Running all tests with coverage in a multi-root workspace reports aggregate coverage but omits line-level highlighting for files in some workspace folders.

## Best solution

Configure one detailed-coverage callback per test run that searches the result resolvers for every participating workspace, rather than replacing the callback once per workspace. Add a multi-root regression test proving that details from two workspace adapters remain available after a global coverage run.
