# Issue #25629 — User scoped python.defaultInterpreterPath is constantly overwritten

[https://github.com/microsoft/vscode-python/issues/25629](https://github.com/microsoft/vscode-python/issues/25629)

## Summary

The reporter confirmed that a corrupted selected interpreter triggers a silent fallback while the status bar continues showing the invalid environment. The issue is already correctly routed and should remain open to improve validation, logging, and status consistency.

## Change summary

Detect an unusable selected interpreter instead of silently falling back, overwriting the user-scoped default path, and displaying stale interpreter information.

## Best solution

Validate that the selected interpreter can execute before accepting or caching it; if validation fails, preserve the configured path, report the failure in the Python output channel, and surface an invalid-interpreter diagnostic rather than silently using a global interpreter.
