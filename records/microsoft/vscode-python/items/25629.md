# Issue #25629 — User scoped python.defaultInterpreterPath is constantly overwritten

[https://github.com/microsoft/vscode-python/issues/25629](https://github.com/microsoft/vscode-python/issues/25629)

## Summary

The reporter identified a corrupted uv-managed interpreter that caused a silent fallback to the system Python while the status bar retained the original selection. Current main still lacks a diagnostic for this selected-versus-active interpreter mismatch, so the environments bug remains actionable.

## Change summary

A failing selected interpreter silently falls back to the system Python, can replace the user-scoped default interpreter setting, and leaves the displayed interpreter inconsistent with the one actually used.

## Best solution

When the selected interpreter cannot execute, preserve the configured selection, log the failing path and error, and notify the user rather than silently adopting a global interpreter. The status bar and Python Environments integration should report the same effective interpreter.
