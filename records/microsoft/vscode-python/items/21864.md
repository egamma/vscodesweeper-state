# Issue #21864 — Modify `Python: Create Terminal` to create an activated terminal even when automatic terminal activation is turned off 

[https://github.com/microsoft/vscode-python/issues/21864](https://github.com/microsoft/vscode-python/issues/21864)

## Summary

This remains an accepted, well-supported feature request, but ownership has shifted to the Python Environments extension. The desired distinction between automatic activation and explicitly requesting an activated Python terminal still needs a proposal for the new command path.

## Change summary

Make `Python: Create Terminal` explicitly create an activated terminal even when automatic activation of ordinary terminals is disabled.

## Best solution

Define and implement the command semantics in `microsoft/vscode-python-environments`: its explicit create-terminal command should activate the selected environment independently of the global automatic-activation preference, while ordinary terminals continue respecting that preference. A maintainer can transfer this issue there once the desired behavior is confirmed.
