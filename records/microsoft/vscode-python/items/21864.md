## Summary

A real gap remains, but terminal creation and activation now belong to the Python Environments extension. Keep this accepted request open while a maintainer evaluates transferring it and updates the proposal for the current architecture.

## Change summary

Make the explicit Python terminal command create an activated terminal even when automatic activation is disabled.

## Best solution

Transfer the request to microsoft/vscode-python-environments and make explicit Python-terminal creation activate the selected environment independently of the global auto-activation preference.
