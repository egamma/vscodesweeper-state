# Issue #21864 — Modify `Python: Create Terminal` to create an activated terminal even when automatic terminal activation is turned off 

[https://github.com/microsoft/vscode-python/issues/21864](https://github.com/microsoft/vscode-python/issues/21864)

## Summary

A real gap remains: terminal creation now delegates to the Python Environments extension, but its explicit create command still respects the global auto-activation setting. The accepted `needs proposal` request should remain open and be transferred rather than closed.

## Change summary

Make `Python: Create Terminal` explicitly create an activated Python terminal even when automatic activation is disabled.

## Best solution

Implement an explicit force-activation path for `python-envs.createTerminal` in microsoft/vscode-python-environments, independent of automatic terminal activation, and have `python.createTerminal` delegate once to that path.
