# Issue #26056 — Support Relative Paths

[https://github.com/microsoft/vscode-python/issues/26056](https://github.com/microsoft/vscode-python/issues/26056)

## Summary

A real environment-selection gap remains: workspace-relative `python.defaultInterpreterPath` values fail while absolute paths work. This likely belongs to the Python Environments extension, but the related open report is Windows-specific and narrower, so it is not a safe duplicate target.

## Change summary

Allow `.venv/bin/python` and `${workspaceFolder}/.venv/bin/python` to resolve relative to the workspace on macOS.

## Best solution

Resolve relative `python.defaultInterpreterPath` values against the applicable workspace folder in the Python Environments extension and preserve the existing absolute-path behavior. A maintainer can transfer this report to microsoft/vscode-python-environments, carrying over the macOS and plain-relative-path evidence.
