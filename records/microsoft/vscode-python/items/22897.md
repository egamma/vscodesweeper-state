# Issue #22897 — No python formatter installed - Local new setup or Github codespace with python extension + formatter installed

[https://github.com/microsoft/vscode-python/issues/22897](https://github.com/microsoft/vscode-python/issues/22897)

## Summary

The reported behavior follows the deliberate migration of formatting into dedicated extensions: the Python extension does not bundle or register a default formatter. Automatically selecting or restoring a formatter here would reverse that architecture, so the documented out-of-scope close applies.

## Change summary

Automatically migrate deprecated formatting settings and provide a working default Python formatter in fresh local and Codespaces setups.

## Best solution

Keep formatter implementation and selection with dedicated formatter extensions and VS Code's `editor.defaultFormatter` configuration rather than restoring formatter ownership in the Python extension. Codespaces that require Black should recommend `ms-python.black-formatter` and set it as the Python default formatter in their repository configuration.
