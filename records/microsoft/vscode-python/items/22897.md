[https://github.com/microsoft/vscode-python/issues/22897](https://github.com/microsoft/vscode-python/issues/22897)

## Summary

Keep the settings-migration and formatter-onboarding request open and route it to the formatting area. A maintainer explicitly supported tracking that improvement here; manually selecting Black does not deliver the requested automatic migration.

## Change summary

Reduce formatter setup friction in fresh local installations and Codespaces by migrating obsolete configuration and helping users establish a working default formatter.

## Best solution

Provide a low-friction transition to dedicated formatter extensions while preserving explicit formatter preferences and keeping formatting outside the core Python extension. Separate the Python configuration-migration work from the VS Code Marketplace recommendation problem.
