# Issue #20275 — Place the recommended interpreter above the `+ Enter interpreter path` in `Select Interpreter` quick pick

[https://github.com/microsoft/vscode-python/issues/20275](https://github.com/microsoft/vscode-python/issues/20275)

## Summary

Keep this accepted, team-authored request open: the current interpreter picker still places manual path entry above the recommended interpreter. The existing area label is correct, and no verified canonical or issue-referencing implementation was found.

## Change summary

Show the recommended interpreter before the manual interpreter-path entry in the Select Interpreter picker.

## Best solution

Make the recommended interpreter more prominent than manual path entry while retaining access to undiscovered interpreters. The environment-area owner should settle the final placement of manual entry, including how that choice applies during the Python Environments rollout.
