# Issue #22558 — Smart send warning message feedback

[https://github.com/microsoft/vscode-python/issues/22558](https://github.com/microsoft/vscode-python/issues/22558)

## Summary

The warning remains difficult to understand and can still change the workspace setting through a single action. This accepted REPL proposal has 10 upvotes, and current main retains the original warning flow, so a real design gap remains.

## Change summary

Clarify the Smart Send parse-failure warning, explain what code was considered, and offer safer recovery choices before changing the setting.

## Best solution

Design a clearer parse-failure flow in the REPL code-execution path that explains what Smart Send attempted and why it failed, offers a non-persistent way to run the explicit selection or line, and makes any persistent change to `python.REPL.enableREPLSmartSend` unambiguous. Coordinate the interaction design with https://github.com/microsoft/vscode-python/issues/22542.
