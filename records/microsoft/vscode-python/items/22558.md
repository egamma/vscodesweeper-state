# Issue #22558 — Smart send warning message feedback

[https://github.com/microsoft/vscode-python/issues/22558](https://github.com/microsoft/vscode-python/issues/22558)

## Summary

Keep this accepted request open: current main still shows the ambiguous Smart Send warning and offers only a persistent disable action. The existing setting does not address the warning's clarity, and the related notification-flow issue does not cover this request's full scope.

## Change summary

Make Smart Send parse-failure warnings explain what could not run, why the current file could not be parsed, and how to recover without unintentionally changing future execution behavior.

## Best solution

Provide a clear Smart Send recovery experience in the core extension's REPL execution flow, distinguishing manual selection from permanently disabling the feature. Settle whether the warning should also offer a one-time execution action, coordinating with https://github.com/microsoft/vscode-python/issues/22542 without discarding this report's wording requirements.
