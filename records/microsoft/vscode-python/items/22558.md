[https://github.com/microsoft/vscode-python/issues/22558](https://github.com/microsoft/vscode-python/issues/22558)

## Summary

The Smart Send warning remains difficult to understand and can disable the setting without adequately explaining the scope or consequence. This accepted REPL request still needs its proposed warning and interaction design.

## Change summary

Clarify why Smart Send could not execute code, explain the available recovery choices, and guard changes to the Smart Send setting.

## Best solution

Redesign the invalid-code warning in the REPL execution flow to explain what failed and why, offer an explicit one-time non-Smart-Send action, and clearly describe the scope before disabling Smart Send. The proposal should also consider an editor affordance showing which code Smart Send executes.
