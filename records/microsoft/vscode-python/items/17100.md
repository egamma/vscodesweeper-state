# Issue #17100 — Error discovering pytest too aggressive

[https://github.com/microsoft/vscode-python/issues/17100](https://github.com/microsoft/vscode-python/issues/17100)

## Summary

Still present on current main: autosave triggers pytest discovery for incomplete Python files, and every discovery error is surfaced unconditionally in the Test view. The issue is already routed and marked as accepted design work with `needs proposal`, so it should remain open.

## Change summary

Avoid surfacing disruptive pytest discovery errors while users are still typing tests under autosave.

## Best solution

Define and implement trigger-aware discovery error handling in the testing controller: preserve previously discovered tests and suppress transient syntax-error nodes after automatic save-triggered discovery, while continuing to surface actionable errors after explicit refresh or run actions.
