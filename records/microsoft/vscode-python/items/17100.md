# Issue #17100 — Error discovering pytest too aggressive

[https://github.com/microsoft/vscode-python/issues/17100](https://github.com/microsoft/vscode-python/issues/17100)

## Summary

The transient pytest discovery error remains possible on current main, and this canonical report is explicitly staged for design with `needs proposal` and `partner ask`; it should remain open.

## Change summary

Avoid displaying disruptive pytest discovery errors while autosave runs against a partially written test.

## Best solution

Use the existing discovery-trigger context to preserve discovered tests and suppress transient error nodes for save-triggered discovery, while continuing to surface errors after explicit user-initiated discovery.
