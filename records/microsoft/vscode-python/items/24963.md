# Issue #24963 — Get python for users with no python installed

[https://github.com/microsoft/vscode-python/issues/24963](https://github.com/microsoft/vscode-python/issues/24963)

## Summary

Keep open: this team-authored request is accepted work marked `needs PR` and `help wanted`, and the current installation command provides platform-specific guidance rather than a complete Python acquisition flow.

## Change summary

Provide a reliable way to acquire Python for users who do not have an interpreter installed.

## Best solution

Extend the `python.installPython` flow to acquire or clearly complete Python installation across supported platforms, then refresh discovery so the new interpreter can be selected. Coordinate the user-facing environment-management experience with the Python Environments extension while retaining the core command integration here.
