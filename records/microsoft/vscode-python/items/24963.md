## Change summary

Provide an effective way for users without an installed Python interpreter to obtain one.

## Best solution

Complete the `python.installPython` flow under `src/client/interpreter/configuration/interpreterSelector/commands/installPython/` so supported platforms and remote environments receive an actionable installation path, then ensure the newly installed interpreter is discovered and selectable.
