# Issue #25298 — Pytest isn't killed when stopping test sessions

[https://github.com/microsoft/vscode-python/issues/25298](https://github.com/microsoft/vscode-python/issues/25298)

## Summary

Keep this report open and route it to testing: multiple users confirm that cancelling a pytest run leaves Python running and resources locked. This is already the consolidation target for two reports; no verified fix or open canonical supersedes it.

## Change summary

Cancelling a pytest run should terminate its execution process rather than only clear the running state in Test Explorer.

## Best solution

Ensure cancellation actually stops pytest and releases held resources across the legacy execution and Python Environments execution paths. Evaluate the existing cancellation PR against this report's infinite-loop example and the supplied devcontainer reproduction before treating it as a solution.
