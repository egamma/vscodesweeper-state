# Issue #25298 — Pytest isn't killed when stopping test sessions

[https://github.com/microsoft/vscode-python/issues/25298](https://github.com/microsoft/vscode-python/issues/25298)

## Summary

Keep this report open and route it to testing: independent reports confirm that cancellation clears the UI while pytest continues running, and maintainers already consolidated two reports here. No verified post-reopen fix establishes that the underlying process now terminates.

## Change summary

Cancelling a pytest run should terminate the executing process rather than leave it running and holding resources after the UI reports cancellation.

## Best solution

Make non-debug pytest cancellation reliably terminate the executing process in both the legacy execution and Python Environments integration paths. Evaluate https://github.com/microsoft/vscode-python/pull/25932 against this report's already-running infinite-loop reproduction; its startup-race change does not by itself establish coverage of this failure.
