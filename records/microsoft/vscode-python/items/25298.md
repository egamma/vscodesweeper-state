# Issue #25298 — Pytest isn't killed when stopping test sessions

[https://github.com/microsoft/vscode-python/issues/25298](https://github.com/microsoft/vscode-python/issues/25298)

## Summary

The cancellation defect remains actionable and has multiple confirmed reproductions, including on Windows and in a dev container. Route it to the testing area; no post-reopen fixing commit or open canonical supersedes this issue.

## Change summary

Cancelling a normal pytest run updates the Testing UI but can leave the underlying Python process running and holding resources.

## Best solution

Make non-debug pytest cancellation terminate the complete test process tree reliably across the legacy and Python Environments execution paths, preferably allowing a graceful interrupt before forced termination. Add platform-aware coverage that verifies the spawned test process actually exits rather than only checking that the cancellation callback resolves.
