# Issue #25298 — Pytest isn't killed when stopping test sessions

[https://github.com/microsoft/vscode-python/issues/25298](https://github.com/microsoft/vscode-python/issues/25298)

## Summary

The cancellation defect remains credible on current main and has independent Windows and dev-container confirmations. This issue is the established canonical report and should be routed to the testing area.

## Change summary

Cancelling a pytest run clears the Testing UI while leaving the underlying pytest process running and holding resources.

## Best solution

Make pytest cancellation terminate the complete process tree and wait for process exit before completing the test run, covering both legacy and Python Environments execution paths in src/client/testing/testController/pytest/pytestExecutionAdapter.ts.
