# Issue #25298 — Pytest isn't killed when stopping test sessions

[https://github.com/microsoft/vscode-python/issues/25298](https://github.com/microsoft/vscode-python/issues/25298)

## Summary

The cancellation defect remains actionable and has independent Windows and dev-container reproductions. Current main still marks the run canceled immediately after a direct process kill, so this should remain open and route to the testing area.

## Change summary

Canceling a pytest run updates the Testing UI but can leave the underlying Python process running and holding resources.

## Best solution

Update pytest cancellation in src/client/testing/testController/pytest/pytestExecutionAdapter.ts to interrupt pytest and, after a bounded grace period, terminate its full process tree; only complete cancellation after process exit. Apply equivalent behavior to both legacy execution and Python Environments extension paths.
