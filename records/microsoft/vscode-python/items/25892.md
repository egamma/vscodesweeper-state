# Issue #25892 — Python skip all Tests

[https://github.com/microsoft/vscode-python/issues/25892](https://github.com/microsoft/vscode-python/issues/25892)

## Summary

The open testing-reliability workstream explicitly tracks this failure and its source-level cause, so this report should be consolidated there as a duplicate.

## Change summary

Unittest runs through the Testing UI leave every test marked skipped when the result pipe is cancelled before producing results.

## Best solution

Follow https://github.com/microsoft/vscode-python/issues/25978 and make the environment-extension execution path publish an error result when its subprocess exits unsuccessfully, rather than leaving started tests to default to skipped.
