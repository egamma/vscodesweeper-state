# Issue #25892 — Python skip all Tests

[https://github.com/microsoft/vscode-python/issues/25892](https://github.com/microsoft/vscode-python/issues/25892)

## Summary

Still present on current main: the Python Environments execution path records a non-zero unittest subprocess exit but emits no error result, leaving every started test displayed as skipped. Route this regression to the testing area for the fix already identified in the testing reliability workstream.

## Change summary

Running unittest tests through the Testing UI can leave every test marked skipped when the result subprocess exits before sending results.

## Best solution

Make the Python Environments subprocess path in src/client/testing/testController/unittest/testExecutionAdapter.ts emit the same error execution payload as the legacy execution path when it exits non-zero, with a regression test covering missing results.
