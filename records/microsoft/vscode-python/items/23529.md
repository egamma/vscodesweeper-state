# Issue #23529 — Re-use terminal after re-starting VS Code

[https://github.com/microsoft/vscode-python/issues/23529](https://github.com/microsoft/vscode-python/issues/23529)

## Summary

The team confirmed the terminal-reuse gap and marked it for a spike. Current source still retains terminal identity only in memory, so restored terminals cannot be safely reused after VS Code restarts.

## Change summary

Reuse a restored Python terminal when running a file after restarting VS Code instead of repeatedly creating new terminals.

## Best solution

Use an appropriate VS Code terminal identity/state API to recognize restored terminals, verify their activation state, and reuse them safely. Keep the spike in the terminal area to establish the required VS Code API and integration design.
