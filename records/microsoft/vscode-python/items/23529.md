# Issue #23529 — Re-use terminal after re-starting VS Code

[https://github.com/microsoft/vscode-python/issues/23529](https://github.com/microsoft/vscode-python/issues/23529)

## Summary

The terminal-reuse gap remains on current main and is already accepted for investigation with `needs spike`. The Python extension cannot identify a restored terminal or verify its activation state after restart, so it creates another terminal.

## Change summary

Reuse a restored Python terminal when running a file after restarting VS Code instead of creating repeated new terminals.

## Best solution

Establish a durable terminal identity or activation-state API in VS Code, then update the terminal service to adopt and validate the restored terminal before creating a replacement.
