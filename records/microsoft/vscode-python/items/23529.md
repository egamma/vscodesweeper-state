# Issue #23529 — Re-use terminal after re-starting VS Code

[https://github.com/microsoft/vscode-python/issues/23529](https://github.com/microsoft/vscode-python/issues/23529)

## Summary

The behavior remains present on main: terminal ownership is retained only in memory, so the Python extension cannot recognize its restored terminal after an extension-host restart. Keep this accepted spike open while the required stable terminal identity API is pursued in VS Code.

## Change summary

Reuse the restored Python terminal when running a file after restarting VS Code instead of creating repeated new terminals.

## Best solution

VS Code should expose a stable terminal session identity across reloads through https://github.com/microsoft/vscode/issues/327326, after which the Python extension can persist its terminal association and reconnect each TerminalService to the restored terminal rather than creating a replacement.
