# Issue #21176 — pytest arg parsing bug

[https://github.com/microsoft/vscode-python/issues/21176](https://github.com/microsoft/vscode-python/issues/21176)

## Summary

The custom pytest argument bug remains visible in current main: the parser treats an unknown option as valueless and then removes its following value as a positional test path. The issue is already accepted for investigation with `needs spike` and correctly routed to testing, so it should remain open.

## Change summary

Preserve separately specified values for custom pytest options in `python.testing.pytestArgs` when running selected tests.

## Best solution

Replace or redesign the lossy pytest argument filtering so discovery, run, debug, and coverage configurations can pass custom plugin arguments without guessing their arity. Coordinate that work with the broader configuration proposal at https://github.com/microsoft/vscode-python/issues/21845 while retaining this concrete regression case.
