## Evidence

- **In-flight startup race:** src/client/activation/jedi/languageServerProxy.ts: JediLanguageServerProxy.start assigns this.languageClient only after awaiting factory.createLanguageClient and client.start. A concurrent stop checks only this.languageClient, so it cannot stop the pending client; overlapping starts can subsequently overwrite the tracked client.
