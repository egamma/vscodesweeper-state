# Issue #26057 — Native Environment Locator fails to register Miniforge/Conda interpreter, while JS Locator works

[https://github.com/microsoft/vscode-python/issues/26057](https://github.com/microsoft/vscode-python/issues/26057)

## Summary

The report isolates a current Native Locator integration failure: the Miniforge interpreter is detected, but it never becomes selectable, while the JS Locator works with the same installation. This remains actionable and should be routed to the native-locator area.

## Change summary

Make a Miniforge base interpreter installed under C:\ProgramData register correctly when using the Native Environment Locator.

## Best solution

Trace the discovered PET environment through the native adapter in src/client/pythonEnvironments/nativeAPI.ts and active-interpreter selection, ensuring the Conda executable is added and persisted before autoselection completes. Also determine whether malformed historical root-prefix candidates from .condarc files are affecting PET output.
