# Issue #21517 — Select environment type and python version should include titles

[https://github.com/microsoft/vscode-python/issues/21517](https://github.com/microsoft/vscode-python/issues/21517)

## Summary

The core environment-creation pickers still use placeholders without persistent titles, so typing a filter removes their orientation text. Keep this accepted UI improvement open; the existing area-environments and needs PR labels remain appropriate.

## Change summary

Keep the environment-type and Python-selection prompts identifiable while users filter their quick picks.

## Best solution

Provide persistent orientation in the core environment-creation type and Python-selection pickers while preserving filtering, selection, cancellation, and back navigation. Scope this work to the core creation flow and API; the Python Environments extension's delegated UI is a separate surface.
