# Issue #24491 — Make it possible to add coverage to the existing state

[https://github.com/microsoft/vscode-python/issues/24491](https://github.com/microsoft/vscode-python/issues/24491)

## Summary

Keep open as accepted testing work: it exceeded the community-feedback threshold and carries `needs PR`. Current main still replaces its detailed coverage map on each run and exposes no general accumulation/reset mode.

## Change summary

Allow coverage from targeted test runs to accumulate until the user explicitly resets it.

## Best solution

Add an opt-in cumulative coverage mode in the testing integration, merge new line and branch results into retained coverage state, and provide an explicit reset action. It should work consistently for pytest and unittest rather than relying on pytest's partial `--cov-append` workaround.
