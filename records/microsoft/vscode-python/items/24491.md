# Issue #24491 — Make it possible to add coverage to the existing state

[https://github.com/microsoft/vscode-python/issues/24491](https://github.com/microsoft/vscode-python/issues/24491)

## Summary

Keep this accepted testing request open: pytest has an argument-based accumulation workaround, but the extension does not provide a framework-independent additive coverage mode or reset control. The existing needs PR label and eight upvotes support retaining it while the coverage lifecycle is designed.

## Change summary

Allow selected-test coverage runs to add to previously collected coverage without rerunning the complete suite.

## Best solution

Provide an explicit, predictable accumulation lifecycle for Python coverage runs, including a fresh-start operation and consistent summary and line-detail results. Build on community coverage tooling and coordinate with the related VS Code coverage discussion rather than assuming that preserving separate controllers' reports also merges coverage within a Python project.
