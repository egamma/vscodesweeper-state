# Issue #24491 — Make it possible to add coverage to the existing state

[https://github.com/microsoft/vscode-python/issues/24491](https://github.com/microsoft/vscode-python/issues/24491)

## Summary

This accepted testing feature remains necessary on current main: each coverage result replaces the resolver's detailed coverage map, and no accumulation mode or reset command is exposed. The existing `needs PR` and `area-testing` labels correctly keep it open for implementation.

## Change summary

Allow coverage from a targeted test run to be added to previously collected coverage instead of replacing it, with a way to reset the accumulated state.

## Best solution

Add an explicit coverage-accumulation mode in the testing controller that safely merges covered and missed lines across runs, plus a command to clear the accumulated state. Preserve replacement as a clearly defined mode so users can choose between an independent coverage run and incremental feedback.
