# Issue #21845 — Proposal: Enable separate configs per run/discovery/debug/coverage with testing

[https://github.com/microsoft/vscode-python/issues/21845](https://github.com/microsoft/vscode-python/issues/21845)

## Summary

Keep open: this team-authored proposal is accepted design work with 42 upvotes and the `needs proposal` label, and current main still exposes one shared argument list per test framework rather than separate discovery, run, debug, and coverage configurations.

## Change summary

Allow users to configure testing arguments and environment variables separately for discovery, ordinary runs, debugging, and coverage, including multiple selectable run configurations.

## Best solution

Finalize the configuration model and implement named TestRunProfiles with per-purpose arguments and environment settings, while providing a clear migration path from `python.testing.pytestArgs` and `python.testing.unittestArgs`. Coordinate implementation through https://github.com/microsoft/vscode-python/issues/23777 and ensure the coverage-specific requirement in https://github.com/microsoft/vscode-python/issues/24865 is covered.
