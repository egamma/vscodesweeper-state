# Issue #21845 — Proposal: Enable separate configs per run/discovery/debug/coverage with testing

[https://github.com/microsoft/vscode-python/issues/21845](https://github.com/microsoft/vscode-python/issues/21845)

## Summary

Keep this accepted, team-authored proposal open: current main still shares framework arguments across testing actions rather than offering independently configurable profiles. The existing testing-area label is correct, and the related requests do not establish a canonical covering the full proposal.

## Change summary

Allow separately selectable testing configurations with action-specific arguments and environment settings for discovery, execution, debugging, and coverage.

## Best solution

Finish the core testing configuration design so named configurations can supply independent arguments and environments without requiring manual settings edits between actions. Coordinate that design with https://github.com/microsoft/vscode-python/issues/23777 and the coverage requirements in https://github.com/microsoft/vscode-python/issues/24865 while preserving automatic discovery and existing debug configurations.
