# Issue #25995 — Conversion to Scripts/python.exe not working

[https://github.com/microsoft/vscode-python/issues/25995](https://github.com/microsoft/vscode-python/issues/25995)

## Summary

The extension intentionally does not translate Unix executable paths into Windows paths. The existing cross-platform configuration is to provide the environment directory, which current code resolves to the platform-specific Python executable.

## Change summary

Automatically translate a configured `.venv/bin/python` path to `.venv/Scripts/python.exe` on Windows.

## Best solution

Keep executable paths platform-specific and use `python.defaultInterpreterPath: "${workspaceFolder}/.venv"` when a portable workspace default is needed; the extension already resolves that directory to `bin/python` or `Scripts/python.exe` as appropriate.

  > Thanks for the report. `python.defaultInterpreterPath` does not translate an executable path between platform layouts. For a portable workspace default, set it to the environment directory instead, for example `"python.defaultInterpreterPath": "${workspaceFolder}/.venv"`; the extension resolves that to the appropriate `Scripts/python.exe` or `bin/python` executable. Also note that this setting is only used until an interpreter has been selected for the workspace.
