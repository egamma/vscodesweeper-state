# Issue #25995 — Conversion to Scripts/python.exe not working

[https://github.com/microsoft/vscode-python/issues/25995](https://github.com/microsoft/vscode-python/issues/25995)

## Summary

The setting intentionally does not translate platform-specific executable paths. Current source already supports the portable form of this configuration by accepting the environment directory and resolving its Windows or POSIX executable.

## Change summary

Automatically translate a Unix-style workspace interpreter path into the corresponding Windows virtual-environment executable.

## Best solution

Keep executable paths machine-specific and use `${workspaceFolder}/.venv` when a portable conventional environment location is needed; the resolver selects `Scripts/python.exe` on Windows and `bin/python` elsewhere.
