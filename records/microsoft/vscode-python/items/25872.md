# Issue #25872 — PyTest exits when subprocess finishes execution when ran through Testing UI

[https://github.com/microsoft/vscode-python/issues/25872](https://github.com/microsoft/vscode-python/issues/25872)

## Summary

The debug launcher still allows a subprocess session to replace the tracked test session, so subprocess termination prematurely completes the test-debug lifecycle. Route this to the testing area; the result-pipe drainage change does not address that session-tracking defect.

## Change summary

Debugging a pytest test that launches a Python subprocess ends the test run when the child exits, before the parent test finishes.

## Best solution

Keep the parent test-debug lifecycle active across subprocess exits, allowing the parent to resume and publish its actual assertion result. Preserve independent concurrent project sessions and explicit cancellation.
