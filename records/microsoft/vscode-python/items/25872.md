# Issue #25872 — PyTest exits when subprocess finishes execution when ran through Testing UI

[https://github.com/microsoft/vscode-python/issues/25872](https://github.com/microsoft/vscode-python/issues/25872)

## Summary

The failure remains traceable on current main: an auto-attached subprocess can replace the tracked root test debug session, so its termination prematurely ends the pytest run. Route this to testing and debugging for a root-session lifecycle fix.

## Change summary

Debugging a pytest test that launches a subprocess terminates the entire test when that subprocess exits.

## Best solution

Keep the root pytest debug session identity stable in src/client/testing/common/debugLauncher.ts and ignore termination of auto-attached child sessions. Then verify result-pipe drainage from the merged cancellation change against this end-to-end subprocess scenario.
