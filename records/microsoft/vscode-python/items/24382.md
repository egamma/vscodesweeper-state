# Issue #24382 — Terminal shouldn't be focused if file cannot be run

[https://github.com/microsoft/vscode-python/issues/24382](https://github.com/microsoft/vscode-python/issues/24382)

## Summary

The invalid-file path still focuses the terminal on current main when the legacy execution path is active and python.terminal.focusAfterLaunch is enabled. Keep this already-routed bug open; the newer related issue does not qualify as a canonical duplicate under the re-review rules.

## Change summary

Running an unsaved Python file or a saved non-Python file should show the validation error without moving focus to the terminal.

## Best solution

Ensure rejected file-run commands preserve focus while retaining the configured focus behavior for valid runs. Keep this bounded correction separate from the broader setting-name and launch-timing discussion in https://github.com/microsoft/vscode-python/issues/24396.
