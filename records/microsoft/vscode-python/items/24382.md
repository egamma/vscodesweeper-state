# Issue #24382 — Terminal shouldn't be focused if file cannot be run

[https://github.com/microsoft/vscode-python/issues/24382](https://github.com/microsoft/vscode-python/issues/24382)

## Summary

The defect remains in the legacy execution path on current main: unsuccessful file validation resolves normally, after which the command handler focuses the terminal unconditionally. The issue is already accepted for investigation with `needs spike` and correctly routed to `area-terminal`.

## Change summary

Running an unsaved or non-Python file focuses the terminal even though validation rejects the file and nothing is launched.

## Best solution

Change the legacy run-file flow in `src/client/terminals/codeExecution/codeExecutionManager.ts` to focus the terminal only when execution actually starts, matching the newer environments-extension path, and cover rejected files with a unit test.
