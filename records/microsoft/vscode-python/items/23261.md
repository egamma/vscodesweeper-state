# Issue #23261 — Select interpreter via file dialog does not properly load virtual env

[https://github.com/microsoft/vscode-python/issues/23261](https://github.com/microsoft/vscode-python/issues/23261)

## Summary

The reporter reconfirmed this macOS bug on the July 2026 release, and current main still accepts the path returned by VS Code's symlink-resolving file dialog. Keep it open for the existing environment-area spike.

## Change summary

Preserve a virtual environment interpreter's symlink path when it is selected through the file dialog.

## Best solution
