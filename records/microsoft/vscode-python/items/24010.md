# Issue #24010 — `Start native repl` always opens repl to side even if there is nothing open

[https://github.com/microsoft/vscode-python/issues/24010](https://github.com/microsoft/vscode-python/issues/24010)

## Summary

The layout bug remains on current main: creating a native REPL unconditionally targets a new editor group beside the active group. The issue is already accepted and correctly routed with `needs PR` and `area-repl`, so it should remain open.

## Change summary

Starting the native Python REPL with no open editor tabs unnecessarily creates a second editor group and opens the REPL there.

## Best solution

Update `openInteractiveREPL` in `src/client/repl/replCommandHandler.ts` to use the active editor group when no tabs are open, while retaining `ViewColumn.Beside` when an existing editor should remain visible and preserving the group of an existing REPL.
