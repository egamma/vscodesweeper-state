# Issue #23228 — Explore how we can make test discovery more automatic

[https://github.com/microsoft/vscode-python/issues/23228](https://github.com/microsoft/vscode-python/issues/23228)

## Summary

Keep open as a team-authored exploration with an accepted `needs spike` stage. The existing configuration command and Testing-view welcome provide manual onboarding, but they do not resolve the requested automatic framework detection and discovery flow.

## Change summary

Explore automatically detecting Python test projects and prompting users to configure discovery without producing confusing failures or installing dependencies unexpectedly.

## Best solution

Spike a conservative, dismissible onboarding flow that detects likely test files or framework configuration and then offers `python.configureTests`, while explicitly handling missing pytest installations and interpreter mismatches. Coordinate the design with the configuration work in https://github.com/microsoft/vscode-python/issues/21845 and https://github.com/microsoft/vscode-python/issues/12075 rather than treating either narrower request as a duplicate.
