# Issue #23228 — Explore how we can make test discovery more automatic

[https://github.com/microsoft/vscode-python/issues/23228](https://github.com/microsoft/vscode-python/issues/23228)

## Summary

Keep open: this team-authored exploration is accepted for a spike and remains a real testing-onboarding gap. Current main provides manual configuration entry points but does not automatically detect likely test projects or proactively offer configuration from test files.

## Change summary

Explore automatically detecting unconfigured Python test projects and guiding users through framework selection, dependency installation, and environment selection.

## Best solution

Complete the testing spike around conservative framework detection and a dismissible configuration affordance, while preserving explicit user control over dependency installation and interpreter selection. Coordinate the design with the multiple-configuration work in https://github.com/microsoft/vscode-python/issues/21845 and https://github.com/microsoft/vscode-python/issues/12075.
