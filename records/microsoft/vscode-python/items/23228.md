[https://github.com/microsoft/vscode-python/issues/23228](https://github.com/microsoft/vscode-python/issues/23228)

## Summary

Keep this team-authored exploration open: current main still requires framework configuration before discovery, and the existing welcome experience does not deliver automatic onboarding. Its exploration scope is explicitly protected from closure, and area-testing already routes it correctly.

## Change summary

Explore automatic or proactively guided test discovery while accounting for framework choice, pytest installation, configuration arguments, and environment selection.

## Best solution

Retain this exploration as the testing team's design record for lower-friction onboarding, with explicit decisions about automatic detection versus dismissible configuration prompts and consent before package installation. Coordinate with the separate testing-configuration proposals without treating those dependencies as duplicates.
