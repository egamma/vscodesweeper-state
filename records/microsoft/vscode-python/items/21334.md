# Issue #21334 — Is "create environment" the right action on a missing dependency

[https://github.com/microsoft/vscode-python/issues/21334](https://github.com/microsoft/vscode-python/issues/21334)

## Summary

Keep open as an accepted, team-authored design proposal. Current main still presents Create Environment when dependency diagnostics are active, while the related Python Environments investigation treats updating dependencies as distinct planned workflow work rather than evidence that this issue is complete or duplicated.

## Change summary

Offer a safe update or synchronization action instead of defaulting to Create Environment when the selected workspace environment is missing declared dependencies.

## Best solution

Implement the workflow in the Python Environments extension: offer Update Environment only for a confidently identified workspace-owned virtual environment, otherwise offer selecting an existing workspace environment or creating one. Preserve this issue as the concrete UX requirement associated with the broader package-management investigation.
