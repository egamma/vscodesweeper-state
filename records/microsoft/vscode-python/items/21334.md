# Issue #21334 — Is "create environment" the right action on a missing dependency

[https://github.com/microsoft/vscode-python/issues/21334](https://github.com/microsoft/vscode-python/issues/21334)

## Summary

Keep this accepted, team-authored proposal open: the missing-dependency action still invokes environment creation rather than updating an existing workspace environment. The related package-management investigation does not establish a duplicate or completed implementation.

## Change summary

Offer an environment-aware dependency update action instead of always offering Create Environment when requirements change.

## Best solution

Provide an explicit dependency-update action for a confirmed workspace-owned virtual environment, select an existing workspace environment when appropriate, and retain creation when none exists without modifying global environments. Coordinate the package-management workflow with Python Environments while preserving this specific editor-action requirement; a maintainer can transfer this to https://github.com/microsoft/vscode-python-environments if that extension should own it.
