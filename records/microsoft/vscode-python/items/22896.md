# Issue #22896 — Confusing test screen when working with a monorepo

[https://github.com/microsoft/vscode-python/issues/22896](https://github.com/microsoft/vscode-python/issues/22896)

## Summary

The display-name gap remains on main, and maintainers explicitly accepted this community-supported request for future consideration. It is already correctly routed to testing and awaits a design proposal.

## Change summary

Show configured multi-root workspace folder names instead of identical filesystem basenames in the Test Explorer and discovery errors.

## Best solution

Use `WorkspaceFolder.name` for legacy multi-root Test Explorer roots and discovery-error labels while retaining URI paths for IDs and filesystem operations. The proposal should cover both pytest and unittest and test multiple workspace folders sharing the same basename.
