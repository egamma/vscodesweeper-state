# Issue #22896 — Confusing test screen when working with a monorepo

[https://github.com/microsoft/vscode-python/issues/22896](https://github.com/microsoft/vscode-python/issues/22896)

## Summary

This remains an accepted testing feature request with sufficient community support. Current main still derives legacy workspace labels from filesystem paths rather than the configured VS Code workspace-folder name.

## Change summary

Display configured workspace-folder names for test-tree roots and discovery errors in multi-root workspaces.

## Best solution

Use `WorkspaceFolder.name` for user-facing test roots and discovery-error labels in multi-root workspaces while retaining `uri.fsPath` for IDs and filesystem operations. A proposal should define behavior for legacy and project-based discovery before implementation.
