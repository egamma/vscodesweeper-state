# Issue #22896 — Confusing test screen when working with a monorepo

[https://github.com/microsoft/vscode-python/issues/22896](https://github.com/microsoft/vscode-python/issues/22896)

## Summary

Keep open: the accepted request still has a concrete gap—legacy test roots and discovery-error labels do not honor workspace folder display names. Project-based testing provides named roots, but does not establish coverage of the supplied multi-root workspace aliases.

## Change summary

Use configured workspace folder names to distinguish same-basename projects in Test Explorer roots and discovery errors.

## Best solution

Make workspace aliases visible consistently in testing roots and discovery errors, while preserving project identity and independent environments. Agree how workspace names should coexist with project names in the newer project-based experience.
