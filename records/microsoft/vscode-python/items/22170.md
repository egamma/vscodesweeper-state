# Issue #22170 — Expand testing on debugLauncher

[https://github.com/microsoft/vscode-python/issues/22170](https://github.com/microsoft/vscode-python/issues/22170)

## Summary

Keep this accepted, team-authored testing debt open: current launcher tests prepare expected IPC environment values but do not assert that the configuration passed to startDebugging contains them. The named-pipe migration changed the required variables, not the need for coverage.

## Change summary

Expand debug-launcher coverage to verify required subprocess environment variables for both unittest and pytest.

## Best solution

Ensure the debug-launcher unit suite checks the actual outgoing configuration for both providers, including TEST_RUN_PIPE and RUN_TEST_IDS_PIPE and preservation of unrelated environment values. These checks should fail when a required variable is omitted or receives the wrong launch-option value, without changing production debugging behavior.
