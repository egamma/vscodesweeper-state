# Issue #25809 — Failed to parse `pyproject.toml` error when pyproject.toml has comments and CRLF line endings

[https://github.com/microsoft/vscode-python/issues/25809](https://github.com/microsoft/vscode-python/issues/25809)

## Summary

The CRLF parsing defect remains in the current source, and an open PR already implements the targeted normalization and regression coverage. Keep the issue open while that implementation candidate is reviewed and landed.

## Change summary

Valid pyproject.toml files containing comments fail to parse when they use Windows CRLF line endings.

## Best solution

Land CRLF normalization and regression tests in the Python Environments implementation, then ensure the still-active legacy parser in src/client/pythonEnvironments/creation/provider/venvUtils.ts receives equivalent handling until that path is retired.
