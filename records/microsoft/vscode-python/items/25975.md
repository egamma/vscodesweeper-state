[https://github.com/microsoft/vscode-python/issues/25975](https://github.com/microsoft/vscode-python/issues/25975)

## Summary

The detailed report describes a likely regression in the Python Environments extension's terminal `.env` handling. Keep it open for a maintainer to transfer to the owning sibling tracker; there is no verified canonical issue supporting a duplicate close.

## Change summary

Changed or removed `.env` values remain injected into newly created terminals until the Python Environments workspace cache is explicitly cleared.

## Best solution

The Python Environments extension should invalidate its persisted terminal environment when the configured `.env` file changes and reload the current values when a workspace reopens. A maintainer can transfer this report to https://github.com/microsoft/vscode-python-environments, preserving the macOS reproduction and the link to the earlier removal-specific report.
