# Issue #23239 — unittest: `sys.path` is different when running from terminal vs test UI

[https://github.com/microsoft/vscode-python/issues/23239](https://github.com/microsoft/vscode-python/issues/23239)

## Summary

The path-ordering defect remains visible on current main and has recent reporter confirmation. This team-authored, accepted issue should remain open for its planned testing-area fix.

## Change summary

Unittest discovery and execution launched from the Test UI put workspace paths ahead of the standard library, unlike terminal unittest runs, allowing project modules such as logging.py to shadow standard-library modules.

## Best solution

Make Test UI unittest discovery and execution match normal Python/unittest import precedence without losing access to the bundled adapter, then add regression coverage using a workspace-level logging.py file. The fix should account for both the TypeScript launch environment and the Python adapter's explicit sys.path mutations.
