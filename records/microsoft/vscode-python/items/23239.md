# Issue #23239 — unittest: `sys.path` is different when running from terminal vs test UI

## Summary

The bug remains present on main and has repeated current-version confirmation. This team-authored issue is accepted work with `needs PR` and should remain open.

## Change summary

Make unittest discovery and execution use import-path ordering consistent with equivalent terminal invocation.

## Best solution

Stop prepending the nested unittest start-directory parent ahead of standard-library paths when an explicit top-level directory is provided, while preserving valid project imports. Cover discovery and execution with a regression fixture containing a project-local `logging.py`.
