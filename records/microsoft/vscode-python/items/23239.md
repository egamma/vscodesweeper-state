# Issue #23239 — unittest: `sys.path` is different when running from terminal vs test UI

[https://github.com/microsoft/vscode-python/issues/23239](https://github.com/microsoft/vscode-python/issues/23239)

## Summary

The path-ordering problem remains confirmed on current releases and the current unittest launch path still prepends the workspace to PYTHONPATH. Keep this accepted testing bug open for implementation.

## Change summary

Unittest discovery and execution use a different sys.path ordering than terminal runs, allowing project modules such as logging.py to shadow the standard library.

## Best solution

Adjust unittest discovery and execution path construction in the testing adapter so project imports continue to work without introducing workspace paths ahead of the standard library unexpectedly, with regression coverage for a project-local logging.py.
