# Issue #17777 — Jedi LS: Cannot disable language server linting

[https://github.com/microsoft/vscode-python/issues/17777](https://github.com/microsoft/vscode-python/issues/17777)

## Summary

Keep open: current main still enables Jedi diagnostics unconditionally, while the existing `needs proposal` and `community ask` labels record that the team accepted further design discussion.

## Change summary

Add a way to disable Jedi language-server diagnostics without disabling Jedi completions, navigation, or external linting tools.

## Best solution

Add a dedicated diagnostic-control setting and pass it to Jedi's `diagnostics.enable` initialization option in `src/client/activation/jedi/analysisOptions.ts`, keeping external linter configuration independent. Coordinate the setting boundary with Pylance while leaving Pylance-specific implementation in its sibling extension.
