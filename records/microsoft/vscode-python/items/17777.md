# Issue #17777 — Jedi LS: Cannot disable language server linting

[https://github.com/microsoft/vscode-python/issues/17777](https://github.com/microsoft/vscode-python/issues/17777)

## Summary

The requested control remains absent on current main: Jedi diagnostics are unconditionally enabled. Keep this accepted community request open because it carries `needs proposal` and `community ask`, and the maintainer explicitly identified a cross-language-server design decision.

## Change summary

Allow users to disable or filter Jedi language-server diagnostics independently of external linting tools and other Jedi features.

## Best solution

Settle a language-server-compatible configuration contract with Jedi and Pylance, then expose a dedicated analysis setting that can disable Jedi diagnostics without disabling completion, hover, or external tool extensions. Wire that setting into `JediLanguageServerAnalysisOptions.getInitializationOptions()` rather than coupling it to the removed built-in linting settings.
