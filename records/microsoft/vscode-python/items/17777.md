# Issue #17777 — Jedi LS: Cannot disable language server linting

[https://github.com/microsoft/vscode-python/issues/17777](https://github.com/microsoft/vscode-python/issues/17777)

## Summary

Keep open: current Jedi integration still enables diagnostics unconditionally, with no contributed setting to disable them independently of language features. This is an accepted configuration feature awaiting a proposal, not a request to restore removed built-in linting.

## Change summary

Allow users to disable or filter Jedi language-server diagnostics while retaining completion, hover, and external linting.

## Best solution

Expose an independent diagnostic control through the Python extension's Jedi integration, preserving existing defaults and external tool behavior. Settle the public configuration contract, including whether it is Jedi-specific or coordinated with Pylance.
