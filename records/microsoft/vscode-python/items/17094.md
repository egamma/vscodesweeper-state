# Issue #17094 — Test discovery flow is unusual/weird

[https://github.com/microsoft/vscode-python/issues/17094](https://github.com/microsoft/vscode-python/issues/17094)

## Summary

The confusing setup flow remains on current main, and this accepted proposal still captures distinct UX requirements for choosing test directories and understanding unittest patterns. The broader testing-configuration proposal references this issue as design input rather than replacing it.

## Change summary

Make test setup clearer by improving directory selection, explaining pattern choices, using reasonable defaults, and exposing the generated configuration for further editing.

## Best solution

Redesign the guided setup in the testing configuration managers so directory selection uses an appropriate workspace-relative picker, unittest pattern choices clearly explain that they are suggested globs, and users can inspect or edit the resulting settings. Reconcile that experience with the configuration model being designed in https://github.com/microsoft/vscode-python/issues/21845.
