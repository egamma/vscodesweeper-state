# Issue #17094 — Test discovery flow is unusual/weird

[https://github.com/microsoft/vscode-python/issues/17094](https://github.com/microsoft/vscode-python/issues/17094)

## Summary

A meaningful configuration-UX gap remains on current main, and the accepted `needs proposal` label protects this request from a quiet-backlog close. The broader testing-configuration proposal references this issue as separate UI-design input rather than superseding it.

## Change summary

Make test discovery configuration clearer by replacing or clarifying the directory and unittest file-pattern quick picks and exposing the generated settings.

## Best solution

Redesign `python.configureTests` so directory and pattern choices clearly communicate what will be written to `python.testing.pytestArgs` or `python.testing.unittestArgs`, then expose the resulting configuration for customization. Coordinate that UX with https://github.com/microsoft/vscode-python/issues/21845 while retaining this issue as the specific usability requirement.
