# Issue #25924 — Please turn off autodetect environment

[https://github.com/microsoft/vscode-python/issues/25924](https://github.com/microsoft/vscode-python/issues/25924)

## Summary

The requested automatic-activation opt-out already exists, but the report explicitly raises a malicious-script execution concern. Keep it open for human security/trust assessment rather than proposing an as-designed close.

## Change summary

Allow users to disable automatic virtual-environment activation commands in terminals, particularly PowerShell activation scripts.

## Best solution

Explain the existing activation opt-outs without disabling environment discovery. A maintainer should assess the reported trust concern and whether activation ownership across the Python and Python Environments extensions leaves any remaining gap.

- **Proposed comment:**

  > Thanks for the report. To disable this extension's automatic terminal activation, set `python.terminal.activateEnvironment` to `false` and leave `python.terminal.activateEnvInCurrentTerminal` set to `false`. If the Python Environments extension handles activation, set `python-envs.terminal.autoActivationType` to `"off"` as well. These settings control activation rather than environment discovery; the malicious-script concern still needs a maintainer's assessment.
