# Issue #25924 — Please turn off autodetect environment

## Summary

The requested opt-out already exists as `python.terminal.activateEnvironment`, but the report raises a security and trust concern that requires human review rather than closure.

## Change summary

Provide a way to prevent automatic PowerShell virtual-environment activation in newly created terminals.

## Best solution

Keep `python.terminal.activateEnvironment: false` as the supported opt-out, and have the terminal area assess whether automatic activation needs stronger Workspace Trust safeguards or clearer documentation.
