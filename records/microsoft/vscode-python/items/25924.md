# Issue #25924 — Please turn off autodetect environment

[https://github.com/microsoft/vscode-python/issues/25924](https://github.com/microsoft/vscode-python/issues/25924)

## Summary

The requested opt-out already exists as `python.terminal.activateEnvironment`, but the report raises a security concern about automatic PowerShell execution and therefore requires human review rather than closure.

## Change summary

Provide a way to prevent automatic virtual-environment activation commands from running in new terminals.

## Best solution

Retain and clearly surface `python.terminal.activateEnvironment: false` as the opt-out, while a maintainer assesses whether activation scripts require additional trust or consent safeguards.
