# Issue #24307 — "Run Test with Coverage" runs *all* tests when test execution fails

[https://github.com/microsoft/vscode-python/issues/24307](https://github.com/microsoft/vscode-python/issues/24307)

## Summary

Fixed and shipped in 2026.0.0: pytest execution exceptions no longer enter the fallback path that reruns all tests.

## Change summary

Prevent a failed targeted pytest coverage run from restarting pytest without test IDs and running the full suite.

## Best solution

Keep the try-except-else structure introduced by commit 05405197f2fb9b8d70c6db088edbcdad1b6dbc0a, which limits fallback execution to test-ID read failures.
