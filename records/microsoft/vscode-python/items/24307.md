# Issue #24307 — "Run Test with Coverage" runs *all* tests when test execution fails

[https://github.com/microsoft/vscode-python/issues/24307](https://github.com/microsoft/vscode-python/issues/24307)

## Summary

Keep open: current main prevents execution exceptions from restarting pytest, but still runs pytest without the selected test IDs when reading their file fails. This leaves the report's explicit fail-safe requirement unresolved; classify it as a testing bug.

## Change summary

Prevent failed test execution or unreadable test IDs from broadening a selected-test run into an all-tests run.

## Best solution

Preserve the existing separation of ID reading and test execution, and ensure an unreadable selection file reports failure without executing tests. Keep this issue as the owner of that remaining behavior.
