# Issue #24307 — "Run Test with Coverage" runs *all* tests when test execution fails

[https://github.com/microsoft/vscode-python/issues/24307](https://github.com/microsoft/vscode-python/issues/24307)

## Summary

Fixed and shipped in 2026.0.0: exceptions from a selected pytest run no longer enter the fallback that runs every test.

## Change summary

Prevent a failed targeted coverage run from restarting pytest without the selected test IDs.

## Best solution

Keep the shipped control-flow fix from commit 05405197f2fb9b8d70c6db088edbcdad1b6dbc0a, which limits the fallback to failures reading the test-ID file.
