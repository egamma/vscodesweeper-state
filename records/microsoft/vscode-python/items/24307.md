# Issue #24307 — "Run Test with Coverage" runs *all* tests when test execution fails

[https://github.com/microsoft/vscode-python/issues/24307](https://github.com/microsoft/vscode-python/issues/24307)

## Summary

The execution-exception restart has been fixed, but the explicit request not to run tests when selected IDs cannot be read remains unmet on main. Keep this issue open for that remaining failure path.

## Change summary

Prevent failed selected-test runs or unreadable test-ID files from triggering an unrestricted pytest run.

## Best solution

Finish the fail-closed behavior in the pytest runner: failure to obtain selected IDs must report the error without executing tests. Preserve the existing exception-handling fix and successful selected-test execution.
