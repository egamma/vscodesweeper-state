[https://github.com/microsoft/vscode-python/issues/25631](https://github.com/microsoft/vscode-python/issues/25631)

The false-pass defect remains in current main, but the open, accepted bug report at https://github.com/microsoft/vscode-python/issues/25824 tracks the same behavior. Consolidate there while preserving this report's ValueError reproduction.

## Change summary

A passing first pytest subtest causes Test Explorer to ignore a subsequent failing subtest and display the parent as passed.

## Best solution

Resolve parent-result reporting through https://github.com/microsoft/vscode-python/issues/25824 so later subtest failures cannot be discarded. Preserve this Windows, Python 3.12.6, pytest 9.0.1 example as an additional exception-case reproduction.
