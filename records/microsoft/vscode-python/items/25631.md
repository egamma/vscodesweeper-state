# Issue #25631 — Inconsistent Testing Reports

[https://github.com/microsoft/vscode-python/issues/25631](https://github.com/microsoft/vscode-python/issues/25631)

## Summary

This is the same pytest-subtests first-result-wins defect now tracked and accepted for implementation in the better-diagnosed canonical issue https://github.com/microsoft/vscode-python/issues/25824.

## Change summary

A pytest test is incorrectly reported as passed when an earlier subtest succeeds and a later subtest fails.

## Best solution

Consolidate on https://github.com/microsoft/vscode-python/issues/25824 and aggregate all call-phase subtest reports before publishing the parent test's final outcome.
