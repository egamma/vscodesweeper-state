- **Current source defect:** At checkout commit 918ddc05b64a5767ccc465834bc82c16d17fe1ae, python_files/vscode_pytest/__init__.py:320-349 publishes the first call-phase report for an absolute node ID and adds that ID to collected_tests_so_far. Subtests reuse the parent's ID, so the initial passing subtest suppresses subsequent failures and the final parent report. pytest_exception_interact at lines 205-227 uses the same deduplication set, preventing the later ValueError from correcting the result.

It addresses the same deduplication defect by retaining subtest failures and publishing the parent outcome; its description reports fail-before/pass-after checks.
