# Issue #25631 — Inconsistent Testing Reports

[https://github.com/microsoft/vscode-python/issues/25631](https://github.com/microsoft/vscode-python/issues/25631)

## Summary

This is the same confirmed pytest-subtests reporting defect tracked by the open, accepted issue https://github.com/microsoft/vscode-python/issues/25824. Current source still records only the first report for a test ID, allowing an initial successful subtest to hide later failures.

## Change summary

A pytest test is shown as passed when an earlier subtest succeeds and a later subtest fails.

## Best solution

Consolidate the fix in https://github.com/microsoft/vscode-python/issues/25824 and update the pytest result adapter to aggregate all reports for a test ID so any failed subtest marks its parent test failed.
