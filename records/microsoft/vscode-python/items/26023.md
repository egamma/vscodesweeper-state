# Issue #26023 — pytest discovery ignores per-subfolder pytest.ini / pyproject.toml [tool.pytest.ini_options] in monorepo (Windows)

[https://github.com/microsoft/vscode-python/issues/26023](https://github.com/microsoft/vscode-python/issues/26023)

## Summary

This is a specific case of the open monorepo pytest-discovery request, which already tracks isolating test discovery across multiple Python projects.

## Change summary

Allow each package in a monorepo to run pytest from its own directory and load its local pytest configuration.

## Best solution

Consolidate the remaining configuration and automatic project-detection work on https://github.com/microsoft/vscode-python/issues/25069. Ensure project-based testing gives each detected package its own cwd so local pyproject.toml settings apply.
