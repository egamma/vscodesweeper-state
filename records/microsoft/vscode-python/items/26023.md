# Issue #26023 — pytest discovery ignores per-subfolder pytest.ini / pyproject.toml [tool.pytest.ini_options] in monorepo (Windows)

[https://github.com/microsoft/vscode-python/issues/26023](https://github.com/microsoft/vscode-python/issues/26023)

## Summary

This is a specific case of the open monorepo pytest-discovery request, which already tracks independent discovery for multiple subprojects. Consolidating there preserves one design discussion while adding the per-package configuration evidence from this report.

## Change summary

Allow pytest discovery to run independently from each monorepo subproject so its local pytest.ini or pyproject.toml configuration applies.

## Best solution

Consolidate on https://github.com/microsoft/vscode-python/issues/25069 and design project-scoped discovery so each package uses its own working directory, pytest configuration, and environment. The existing Python Environments project mode is a useful foundation, but an explicit or reliably discovered project-root mechanism must cover these per-package configurations.
