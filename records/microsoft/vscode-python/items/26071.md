[https://github.com/microsoft/vscode-python/issues/26071](https://github.com/microsoft/vscode-python/issues/26071)

## Summary

The logs and current source confirm that POSIX result-pipe closure can fall through to the five-second timeout. Keep this open because https://github.com/microsoft/vscode-python/pull/26082 is an open fixing PR that explicitly closes this issue.

## Change summary

Test Explorer runs incur a five-second delay because the POSIX result-pipe reader does not signal EOF after pytest exits.

## Best solution

Review and land https://github.com/microsoft/vscode-python/pull/26082, which replaces the POSIX FIFO socket reader with explicit EOF detection while preserving buffered results and cleanup.
