# Issue #25735 — Audit and potentially deprecate `defaultInterpreterPath` updates when Python Environments extension is active

[https://github.com/microsoft/vscode-python/issues/25735](https://github.com/microsoft/vscode-python/issues/25735)

## Summary

Keep open: this team-authored spike remains necessary to define setting ownership during the Python Environments rollout, and it already carries the accepted `needs spike` classification.

## Change summary

Audit whether the Python extension should update `python.defaultInterpreterPath` while the Python Environments extension is active and deprecate conflicting paths.

## Best solution

Complete the spike and establish one ownership contract: when the Environments extension is active, selection changes should flow through its API rather than uncontrolled writes by the Python extension, while preserving explicitly requested user and extension-API behavior.
