# Issue #25735 — Audit and potentially deprecate `defaultInterpreterPath` updates when Python Environments extension is active

[https://github.com/microsoft/vscode-python/issues/25735](https://github.com/microsoft/vscode-python/issues/25735)

## Summary

Keep open: this team-authored, accepted spike tracks an unresolved ownership boundary between the core and Environments extensions. Current main still exposes unguarded interpreter-update APIs, while environment creation has only partially migrated.

## Change summary

Audit and potentially stop core Python extension code from updating interpreter state when the Python Environments extension is active.

## Best solution

Complete the spike by defining user-initiated versus automatic selection semantics, then route selection through the Environments extension when active and deprecate obsolete core APIs with a migration path.
