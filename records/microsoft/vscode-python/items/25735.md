# Issue #25735 — Audit and potentially deprecate `defaultInterpreterPath` updates when Python Environments extension is active

[https://github.com/microsoft/vscode-python/issues/25735](https://github.com/microsoft/vscode-python/issues/25735)

## Summary

Keep open for the accepted spike: current main still contains interpreter-selection update paths without a consistent Python Environments extension ownership guard, and maintainer discussion has not resolved whether explicit user selection should update the setting. This team-authored issue is protected from judgment closes and already carries `needs spike`.

## Change summary

Audit every interpreter-path update and define whether the Python extension may modify `python.defaultInterpreterPath` while the Python Environments extension is active.

## Best solution

Complete the spike across vscode-python and the Python Environments extension, separating explicit user-driven selection from implicit updates. When the environments extension is active, it should own selection state and the Python extension should avoid unsolicited `defaultInterpreterPath` changes while preserving documented fallback behavior.
