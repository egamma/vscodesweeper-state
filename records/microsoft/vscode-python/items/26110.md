# Issue #26110 — Running a single test imports the whole codebase

[https://github.com/microsoft/vscode-python/issues/26110](https://github.com/microsoft/vscode-python/issues/26110)

## Summary

The supplied main checkout still discovers the entire configured unittest suite before filtering to the selected test, importing unrelated test modules on every run. Route this to area-testing; the report provides sufficient reproduction details, and no verified open canonical owns this specific defect.

## Change summary

Running or rerunning one unittest imports unrelated test modules and their dependencies, adding avoidable startup delays.

## Best solution

Make selected unittest execution avoid importing unrelated test modules while preserving test identifiers, result reporting, and supported suite-loading behavior. Keep this concrete execution defect separate from the broader testing-performance workstream.
