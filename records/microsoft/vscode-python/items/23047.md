# Issue #23047 — Custom Test Discovery Option

[https://github.com/microsoft/vscode-python/issues/23047](https://github.com/microsoft/vscode-python/issues/23047)

## Summary

Verified duplicate: the open testing-config proposal already owns separate discovery configuration, including using a custom pytest plugin only during discovery. The related engineering tracker is accepted and remains open.

## Change summary

Allow large projects to replace or restrict full-workspace pytest collection through custom discovery configuration.

## Best solution

Consolidate discovery-specific arguments, environment variables, and pytest plugins under https://github.com/microsoft/vscode-python/issues/21845 and its engineering tracker https://github.com/microsoft/vscode-python/issues/23777; per-file discovery remains tracked separately at https://github.com/microsoft/vscode-python/issues/4586.
