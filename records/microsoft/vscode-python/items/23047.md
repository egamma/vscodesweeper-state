# Issue #23047 — Custom Test Discovery Option

[https://github.com/microsoft/vscode-python/issues/23047](https://github.com/microsoft/vscode-python/issues/23047)

## Summary

Keep open: configurable, lightweight discovery for very large suites remains a real capability gap. Existing settings and related proposals cover only parts of the request, and the needs spike label records ongoing investigation.

## Change summary

Allow custom or narrowly scoped pytest discovery so large projects can use Test Explorer without collecting their entire suite.

## Best solution

Agree on a pytest-compatible discovery customization contract that supports large-suite and CI-selected workflows while preserving normal execution and debugging. Coordinate with the separate-config and per-file discovery proposals without treating either as full coverage of this request.
