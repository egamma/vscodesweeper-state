# Issue #23047 — Custom Test Discovery Option

[https://github.com/microsoft/vscode-python/issues/23047](https://github.com/microsoft/vscode-python/issues/23047)

## Summary

A real capability gap remains on main: pytest discovery still uses a fixed command, while this accepted needs-spike request asks for customizable or scoped discovery for very large suites. Related issues offer partial mitigations but do not cover the full request.

## Change summary

Allow projects to customize or narrowly scope pytest discovery instead of always collecting the entire test suite.

## Best solution

Define a testing discovery profile or extension point that can customize the discovery command and scope, while preserving compatibility with the Test Explorer protocol. Coordinate this with the per-file discovery work in https://github.com/microsoft/vscode-python/issues/4586 and the testing-config proposal in https://github.com/microsoft/vscode-python/issues/21845.
