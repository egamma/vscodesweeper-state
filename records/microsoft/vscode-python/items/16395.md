# Issue #16395 — Refactor: Python process execution factory and service

[https://github.com/microsoft/vscode-python/issues/16395](https://github.com/microsoft/vscode-python/issues/16395)

## Summary

Keep open: this team-authored refactoring remains explicitly accepted with `needs PR`, and the current process factory still combines environment selection, activation, interpreter discovery, and execution-service construction.

## Change summary

Refactor the Python process execution factory and service into smaller, more testable interfaces and classes with narrower responsibilities.

## Best solution

Split environment resolution and specialized conda/Pixi handling from process-service construction in `src/client/common/process/pythonExecutionFactory.ts`, replace service-locator lookups with explicit dependencies, and narrow the interfaces in `src/client/common/process/types.ts` so each component can be tested independently.
