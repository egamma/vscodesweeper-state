[https://github.com/microsoft/vscode-python/issues/16395](https://github.com/microsoft/vscode-python/issues/16395)

## Summary

Keep this accepted refactor open: current main still combines interpreter selection, activation, environment-specific execution, and service lifecycle management in PythonExecutionFactory. The author reaffirmed the work, and neither a verified canonical nor an explicitly linked completing fix was found.

## Change summary

Simplify Python execution factory and service composition, narrow their interfaces, and reduce the dependencies required for isolated tests.

## Best solution

Retain the existing execution behavior while separating the factory's responsibilities and making its dependencies independently testable. The process-service layer already has some separation; the remaining scope should focus on factory orchestration and the combined execution-service contract.
