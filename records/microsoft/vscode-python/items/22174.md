# Issue #22174 — APIs required by Tensorboard ext (as well as Jupyter ext)

[https://github.com/microsoft/vscode-python/issues/22174](https://github.com/microsoft/vscode-python/issues/22174)

## Summary

Keep open: this is a team-authored partner proposal already marked `needs proposal`, and current main still lacks a stable public API covering activated environments, package management, and Python execution. The related TensorBoard migration tracker closed without completing this API task.

## Change summary

Provide stable extension APIs that let TensorBoard and Jupyter inspect and install packages, obtain activated environment details and tool paths, and execute Python code.

## Best solution

Finalize the API boundary with the Python Environments extension: package-manager operations should use its extensibility surface, while vscode-python should expose any remaining stable activation or execution integration needed by sibling extensions. Replace the current Jupyter-only private bridge once those public APIs are available.

- **Evidence:** The durable themes explicitly prioritize public environment discovery and selection APIs and access points for sibling extensions; the current priorities place environment-management workflows in the Python Environments extension while retaining integration plumbing in vscode-python.
