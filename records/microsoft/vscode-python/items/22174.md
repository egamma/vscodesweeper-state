## Summary

Keep this accepted, team-authored API request open: TensorBoard's temporary integration exists, and Python Environments now provides relevant APIs, but neither establishes completion of the full shared API contract. No verified canonical duplicate or issue-referencing fix was found.

## Change summary

Provide shared APIs for TensorBoard and Jupyter to install packages, inspect package availability and versions, and execute Python in the appropriate activated environment.

## Best solution

Reconcile these requirements with the Python Environments package-management and execution APIs, and establish whether TensorBoard and Jupyter can consume them without additional core Python API support. Preserve the existing private integrations until the shared contract and consumer migration are settled.
