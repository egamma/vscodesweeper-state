# Issue #26050 — "[warning] Working directory resolves to different path" due to case-sensitive comparison

[https://github.com/microsoft/vscode-python/issues/26050](https://github.com/microsoft/vscode-python/issues/26050)

## Summary

The false warning remains on current main: pytest discovery compares Windows paths case-sensitively, so a drive-letter case change from `realpath` unnecessarily triggers the symlink-parent check. Route this confirmed, localized bug to the testing area.

## Change summary

Avoid reporting an ordinary Windows drive-letter case difference as a potentially symlinked pytest working directory.

## Best solution

Use the repository's platform-aware path-equivalence helper in `handleSymlinkAndRootDir`, preserving the existing symlink handling while suppressing the warning and parent traversal when paths differ only by Windows casing.
