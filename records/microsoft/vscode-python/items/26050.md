# Issue #26050 — "[warning] Working directory resolves to different path" due to case-sensitive comparison

[https://github.com/microsoft/vscode-python/issues/26050](https://github.com/microsoft/vscode-python/issues/26050)

## Summary

The false warning remains directly traceable on main: pytest discovery compares Windows paths case-sensitively, so Node's uppercase drive letter is treated as a different path. Route this to testing for a focused comparison fix.

## Change summary

Suppress the misleading symlink warning when the pytest working directory and its resolved Windows path differ only in letter case.

## Best solution

Use the existing platform-aware `arePathsSame` helper in `handleSymlinkAndRootDir` and add coverage for drive-letter case differences while preserving genuine symlink detection. Treat the reported test-tree refresh as unconfirmed and separate unless evidence connects it to this path check.
