## Summary

Keep open for testing-area consideration: the request exceeded the community-feedback threshold, and current main still hard-codes pytest and unittest without an extension point for arbitrary frameworks.

Add built-in Behave support or an extensibility API through which arbitrary Python test frameworks can integrate.
