# Issue #25330 — Support for "behave" (or arbitrary) test framework

[https://github.com/microsoft/vscode-python/issues/25330](https://github.com/microsoft/vscode-python/issues/25330)

## Summary

A real extensibility gap remains: current main hard-codes pytest and unittest, while this request exceeded the community-feedback threshold with 13 upvotes. It should remain open for an area-testing design decision.

## Change summary

Support Behave tests directly or provide an extension API through which arbitrary Python test frameworks can integrate.

## Best solution

Define a public testing-adapter API that lets community-maintained framework extensions integrate discovery, execution, debugging, and results without adding every framework to vscode-python itself.
