# Issue #24923 — Keybinds for Enter key in REPL and Interactive Windows not restricted to Python contexts

[https://github.com/microsoft/vscode-python/issues/24923](https://github.com/microsoft/vscode-python/issues/24923)

## Summary

The Python Enter bindings still match non-Python composite REPL and Interactive Window inputs on current main, and their handlers require a Python interpreter. Keep this already-correctly-routed issue open; no verified canonical or pending fix was found.

## Change summary

Python-specific Enter handlers intercept non-Python REPL and Interactive Window inputs, preventing execution when the selected Python interpreter is unavailable.

## Best solution

Restrict Python Enter handling to Python input contexts while preserving existing Python completeness and multiline behavior. Non-Python inputs should retain their owning extension's Enter behavior without consulting a Python interpreter.
