# Issue #24923 — Keybinds for Enter key in REPL and Interactive Windows not restricted to Python contexts

[https://github.com/microsoft/vscode-python/issues/24923](https://github.com/microsoft/vscode-python/issues/24923)

## Summary

The bug remains on current main: the Python Enter keybindings match every composite REPL or Interactive editor, while their handlers unconditionally require a Python interpreter. The issue already has the correct REPL area label and should remain open.

## Change summary

Restrict Python's Enter keybindings to Python-owned REPL and Interactive Window contexts so they do not intercept input in other languages.

## Best solution

Narrow the `when` clauses for both Enter keybindings in `package.json` to a Python-specific REPL or kernel context, preserving the owning extension's normal Enter behavior in non-Python windows. The command handlers should also avoid Python interpreter resolution when invoked outside a Python context.
