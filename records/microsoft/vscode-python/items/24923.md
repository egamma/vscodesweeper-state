# Issue #24923 — Keybinds for Enter key in REPL and Interactive Windows not restricted to Python contexts

[https://github.com/microsoft/vscode-python/issues/24923](https://github.com/microsoft/vscode-python/issues/24923)

## Summary

The bug remains source-reproducible on current main: the Python Enter keybindings match composite REPL and Interactive editors without checking their language, then require an active Python interpreter. The existing area-repl routing is appropriate.

## Change summary

Python-specific Enter keybindings intercept input in non-Python REPL and Interactive Window sessions.

## Best solution

Constrain the Enter keybindings in package.json to Python-owned REPL and Interactive contexts, allowing each non-Python provider's normal Enter command to run without consulting the Python interpreter.
