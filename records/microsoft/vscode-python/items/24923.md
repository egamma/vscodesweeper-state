# Issue #24923 — Keybinds for Enter key in REPL and Interactive Windows not restricted to Python contexts

[https://github.com/microsoft/vscode-python/issues/24923](https://github.com/microsoft/vscode-python/issues/24923)

## Summary

Still present on current main: the Python extension contributes generic Enter bindings for every composite REPL and Interactive Window, then requires a Python interpreter before forwarding the command. The issue is correctly routed to the REPL area and should remain open.

## Change summary

Python's Enter keybindings intercept input in non-Python REPL and Interactive Window editors and can block execution when the selected Python interpreter is invalid.

## Best solution

Restrict the contributed keybindings in package.json to Python-owned REPL and Interactive Window contexts, using an appropriate language or kernel context key so other extensions retain their Enter behavior. If VS Code does not expose a sufficient context key, coordinate the necessary context surface with microsoft/vscode.
