# Issue #24126 — Extension should be aware of what shell type user is using to send shell specific escaped commands

[https://github.com/microsoft/vscode-python/issues/24126](https://github.com/microsoft/vscode-python/issues/24126)

## Summary

The shell-specific quoting defect remains on current main, while the VS Code API that previously blocked the work has shipped. Keep the accepted spike open and route it to the terminal area.

## Change summary

Generated terminal commands fail when Python or script paths contain shell-special characters such as `$` or `!`.

## Best solution

Use `Terminal.state.shell` in the terminal service and centralize shell-specific argument escaping in `src/client/common/terminal/helper.ts`, covering executable paths, script arguments, and working-directory changes.

- **execution path:** `src/client/terminals/codeExecution/terminalCodeExecution.ts` lines 40-46 formats the script path with the generic helper before passing it to `sendCommand`; `src/client/common/terminal/helper.ts` lines 68-75 then constructs the shell command with the same generic quoting.
