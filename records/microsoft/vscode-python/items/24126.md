# Issue #24126 — Extension should be aware of what shell type user is using to send shell specific escaped commands

[https://github.com/microsoft/vscode-python/issues/24126](https://github.com/microsoft/vscode-python/issues/24126)

## Summary

This accepted terminal-escaping bug should remain open and route to the terminal area. VS Code has since finalized the shell-identification API that the maintainer identified as the prerequisite.

## Change summary

Generate shell-specific escaping when sending Python commands so paths containing characters such as `$` or `!` are interpreted literally.

## Best solution

Use VS Code's finalized `Terminal.state.shell` information to select shell-specific command quoting in the terminal command builder, covering paths with spaces and shell metacharacters across bash-like shells, PowerShell, and cmd.
