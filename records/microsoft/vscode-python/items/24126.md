# Issue #24126 — Extension should be aware of what shell type user is using to send shell specific escaped commands

[https://github.com/microsoft/vscode-python/issues/24126](https://github.com/microsoft/vscode-python/issues/24126)

## Summary

The shell-escaping defect remains in the current source; route this accepted investigation to area-terminal. The referenced VS Code shell-detection API is now finalized, but that does not fix Python's command construction.

## Change summary

Preserve literal interpreter and script paths containing shell-special characters when running Python in a terminal.

## Best solution

Make terminal execution preserve literal paths using the actual terminal shell, covering both shell-integration execution and the sendText fallback. Coordinate the Python Environments delegation boundary so legacy and delegated execution provide the same behavior.
