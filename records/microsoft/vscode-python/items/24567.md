# Issue #24567 — Remove terminal env var experiment

[https://github.com/microsoft/vscode-python/issues/24567](https://github.com/microsoft/vscode-python/issues/24567)

## Summary

Keep open: the terminal environment-variable experiment remains declared, registered, and executable in the supplied main checkout. Python Environments integration bypasses it in some configurations but does not complete this accepted, team-authored cleanup.

## Change summary

Retire the terminal environment-variable activation experiment and its associated plumbing in favor of shell-aware activation.

## Best solution

Complete the retirement in the core extension while preserving Python Environments activation ownership and the supported fallback activation flow. Distinguish experiment-specific collection and notification code from PYTHONSTARTUP shell integration and microvenv support, which currently share the service.
