# Issue #24699 — Reactivating Terminal

[https://github.com/microsoft/vscode-python/issues/24699](https://github.com/microsoft/vscode-python/issues/24699)

## Summary

Keep this canonical investigation open: current main deliberately leaves the “Reactivating terminals...” progress indicator visible when terminal environment activation fails, and multiple reports confirm the resulting unusable state. The team-authored issue is already accepted for investigation with `needs spike` and `important`.

## Change summary

Terminal environment activation failures leave a permanent “Reactivating terminals...” indicator and can prevent the Python extension from becoming usable.

## Best solution

Make terminal environment activation failures bounded and recoverable: clear the progress indicator, preserve actionable diagnostics, and allow interpreter selection and extension activation to continue. The spike should account for invalid configured interpreters, locator failures, remote environments, and the Python Environments extension rollout.
