# Issue #23447 — Test Discovery Failing in all repos (for the Testing Panel)

[https://github.com/microsoft/vscode-python/issues/23447](https://github.com/microsoft/vscode-python/issues/23447)

## Summary

The confirmed Unix-domain-socket failure was fixed by switching test discovery and execution communication to FIFOs on Linux and macOS. The fix is present on current main and shipped in 2024.22.0, so this can be closed as completed.

## Change summary

Test discovery failed in WSL2 and macOS because the extension could not listen on its Unix-domain socket, while command-line unittest and pytest discovery continued to work.

## Best solution

Keep the FIFO-based communication introduced by commit d1d125a6cd7201883503da173bd774b1809b5a0e; it removes the Unix-domain-socket dependency responsible for this report.
