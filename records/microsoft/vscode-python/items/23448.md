# Issue #23448 — Multi-root workspace: Python resolves imports only from venv of first root-folder

[https://github.com/microsoft/vscode-python/issues/23448](https://github.com/microsoft/vscode-python/issues/23448)

## Summary

The multi-root environment-selection defect has multiple detailed confirmations and still needs investigation by the environments and terminal owners. A later activation exception seen by reporters was fixed in May 2026, but that cannot establish that the original wrong-interpreter behavior is resolved because the report predates that code path.

## Change summary

Each workspace folder should use its individually selected virtual environment for import resolution and terminal activation instead of inheriting the first folder's environment.

## Best solution

Verify the original two-environment reproduction on a build containing commit d48d1242833c3e579d9e08ea549ba7ac3a243357, then trace the resource passed through the per-folder environment API and terminal activation. If only Pylance import resolution remains incorrect after the Python extension reports the right environment for each resource, a maintainer can transfer that portion to microsoft/pylance-release.
