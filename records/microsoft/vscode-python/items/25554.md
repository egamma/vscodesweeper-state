# Issue #25554 — Conda/Miniforge environments not detected as Jupyter kernels in VSCode (2025.x extension versions)

[https://github.com/microsoft/vscode-python/issues/25554](https://github.com/microsoft/vscode-python/issues/25554)

## Summary

Keep this regression open and route it to environment discovery/API integration. Multiple users confirm missing conda kernels, including recent confirmations that disabling Python Environments restores them; that workaround does not establish a fix.

## Change summary

Conda environments with ipykernel disappear from notebook kernel selection when newer Python extension discovery is active.

## Best solution

Ensure discovered conda environments remain available through the Python extension API with Python Environments enabled, without requiring interpreter-path entry or extension rollback. Diagnose the core-to-environments discovery boundary; a maintainer can transfer this to https://github.com/microsoft/vscode-python-environments if the failing behavior is owned there.
