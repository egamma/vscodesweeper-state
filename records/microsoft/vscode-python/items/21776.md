# Issue #21776 — Run Selection/Line in Terminal again fails when running from an Untitled file

[https://github.com/microsoft/vscode-python/issues/21776](https://github.com/microsoft/vscode-python/issues/21776)

## Summary

The confirmed regression remains visible in current source, and the existing `needs PR` and `area-repl` labels already classify it as accepted REPL work. Keep it open for implementation.

## Change summary

Running a selection from an untitled or out-of-workspace Python file creates a different terminal service but incorrectly treats its shell as an initialized REPL.

## Best solution

Make the active terminal REPL identity independent of the source document's workspace folder, or track initialization per terminal service rather than globally. Add coverage for running first from a workspace file and then from an untitled or out-of-workspace editor.

- **source defect:** src/client/terminals/codeExecution/terminalCodeExecution.ts:49-69 uses one global replActive promise while requesting a terminal service for each document resource. After the first REPL starts, a different resource-specific terminal is shown without launching Python.
