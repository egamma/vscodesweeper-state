# Issue #21776 — Run Selection/Line in Terminal again fails when running from an Untitled file

[https://github.com/microsoft/vscode-python/issues/21776](https://github.com/microsoft/vscode-python/issues/21776)

## Summary

Keep open: current source still treats a workspace REPL as initialized while selecting a different terminal for untitled or out-of-workspace code. The newer command queue changes the failure symptom, but does not restore reuse of the existing Python session.

## Change summary

Running selection or line from an untitled or out-of-workspace Python editor should reuse the Python terminal previously started from a workspace file.

## Best solution

Make the terminal-selection and REPL-initialization lifecycle consistent so this editor transition preserves the existing Python session and executes the selection. Preserve independent workspace execution contexts and existing terminal-close behavior.
