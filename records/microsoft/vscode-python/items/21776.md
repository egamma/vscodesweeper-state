# Issue #21776 — Run Selection/Line in Terminal again fails when running from an Untitled file

[https://github.com/microsoft/vscode-python/issues/21776](https://github.com/microsoft/vscode-python/issues/21776)

## Summary

The confirmed regression remains visible in current main: selection execution resolves a new terminal service when the document moves from a workspace file to an untitled or outside-workspace resource, then sends code to that terminal without starting its Python REPL. The issue is already accepted with `needs PR` and correctly routed to `area-repl`, so it should remain open for implementation.

## Change summary

Running a selection from an untitled or outside-workspace Python document should reuse the Python REPL previously started from a workspace file instead of sending the code to a new shell.

## Best solution

Make `TerminalCodeExecutionProvider` retain and reuse the terminal service associated with its active REPL across workspace, untitled, and outside-workspace resources, while preserving resource-specific interpreter resolution when initially launching the REPL. Add a unit regression covering consecutive execution from a workspace URI and an untitled URI.
