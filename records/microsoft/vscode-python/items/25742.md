# Issue #25742 — Test runs ignore TestRunRequest.exclude (filtered tests still run)

[https://github.com/microsoft/vscode-python/issues/25742](https://github.com/microsoft/vscode-python/issues/25742)

## Summary

The defect remains directly visible on current main: both legacy and project-based execution expand included test items without consulting TestRunRequest.exclude. The abandoned fix PR also received maintainer feedback confirming the required behavior, so this should remain open and route to the testing area.

## Change summary

Honor TestRunRequest.exclude when converting requested test items into pytest and unittest test IDs, including exclusion of descendants.

## Best solution

Apply exclusion-aware traversal to both WorkspaceTestAdapter.executeTests and the project-based execution path, while preserving ID deduplication and returning without invoking the runner when exclusions leave no tests. Continue the implementation from the closed https://github.com/microsoft/vscode-python/pull/25743 with the maintainer-requested corrections.
