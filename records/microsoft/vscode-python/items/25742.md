## Summary

The exclusion defect remains in both legacy and project-based execution on current main. Route to the testing area; the proposed fix was closed without merging, and the older related issues do not provide a valid duplicate target.

## Change summary

Honor TestRunRequest.exclude so excluded tests and their descendants do not execute when running a filtered test selection.

## Best solution

Make legacy and project-based test execution honor the same include/exclude contract across pytest and unittest, preserving test-ID deduplication and avoiding runner invocation when exclusions leave no runnable tests.
