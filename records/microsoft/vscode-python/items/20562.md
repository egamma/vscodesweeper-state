# Issue #20562 — Support profile-specific `terminal.activateEnvInCurrentTerminal` settings

[https://github.com/microsoft/vscode-python/issues/20562](https://github.com/microsoft/vscode-python/issues/20562)

## Summary

The requested profile-specific activation control remains missing, while the existing `needs proposal` and `community ask` labels record that the request passed the community-feedback threshold and was accepted for future consideration. The environment-variable activation workaround avoids sending `source`, but does not let users disable activation for selected terminal profiles.

## Change summary

Allow users to enable or disable Python environment activation independently for each integrated-terminal profile.

## Best solution

Define a proposal for profile allow/exclude rules and implement it in the terminal-activation owner, coordinating with `microsoft/vscode-python-environments` because that extension now handles activation when enabled. Preserve compatibility with the existing global booleans while allowing specialized profiles to opt out entirely.
