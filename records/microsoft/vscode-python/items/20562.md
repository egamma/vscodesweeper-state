# Issue #20562 — Support profile-specific `terminal.activateEnvInCurrentTerminal` settings

[https://github.com/microsoft/vscode-python/issues/20562](https://github.com/microsoft/vscode-python/issues/20562)

## Summary

Keep this accepted terminal feature request open: current settings still do not provide profile-specific activation control, and the environment-variable workaround does not disable activation for selected profiles. The request has 10 upvotes and explicit maintainer support; the related closed requests are not canonical duplicates.

## Change summary

Allow users to disable automatic Python environment activation for selected terminal profiles while retaining it for other profiles.

## Best solution

Provide profile-specific activation exclusions without changing activation for ordinary terminals. Develop the proposal around the Python Environments activation handoff, deciding whether the contract also covers legacy core activation; a maintainer can transfer this to microsoft/vscode-python-environments if that extension should own the setting.
