[https://github.com/microsoft/vscode-python/issues/24750](https://github.com/microsoft/vscode-python/issues/24750)

## Summary

Keep open: the terminal's Native REPL launch hint still hardcodes Ctrl/Cmd and ignores editor.multiCursorModifier. The linked implementation PR was closed without merging, and this accepted, team-authored issue has no verified fix or canonical duplicate.

## Change summary

Make the Native REPL launch hint reflect Alt/Option-click when editor.multiCursorModifier is set to ctrlCmd.

## Best solution

Make the terminal's printed launch guidance agree with the effective link modifier while preserving recognition of the emitted banner and the python.startNativeREPL action. Coordinate the Python startup banner and TypeScript link provider; changing only the provider's expected text would stop recognizing the existing banner.
