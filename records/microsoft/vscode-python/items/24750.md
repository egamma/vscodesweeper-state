# Issue #24750 — Account for editor.multi-cursor setting for Native REPL link in Terminal

[https://github.com/microsoft/vscode-python/issues/24750](https://github.com/microsoft/vscode-python/issues/24750)

## Summary

The bug remains on current main: both the Native REPL startup message and its terminal-link provider hardcode Ctrl/Cmd without consulting editor.multiCursorModifier. This team-authored issue is accepted with needs PR, while the only linked implementation PR was closed without merging.

## Change summary

Make the Native REPL terminal link display and recognize Alt/Option instead of Ctrl/Cmd when editor.multiCursorModifier is set to ctrlCmd.

## Best solution

Resolve the effective link modifier from editor.multiCursorModifier in the TypeScript startup path, pass it consistently to pythonrc.py, and have the terminal-link provider recognize the same generated text while preserving Ctrl/Cmd as the default.
