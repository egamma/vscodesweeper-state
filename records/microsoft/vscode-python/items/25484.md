# Issue #25484 — Test runner with unittest seems to ignore updates to tests once decorated to skip

[https://github.com/microsoft/vscode-python/issues/25484](https://github.com/microsoft/vscode-python/issues/25484)

## Summary

The class-fixture skip gap remains on main: unittest reports a SkipTest raised by setUpClass against a synthetic class-level result, while the extension only updates selected method-level test items. The issue is already correctly routed and accepted for a spike.

## Change summary

Represent tests as skipped and refresh their decorator-derived outcomes when unittest setUpClass raises SkipTest.

## Best solution

Teach the unittest result translation to associate class-level fixture skips with the selected test methods in that class, then add execution coverage for adding and removing method skip decorators while setUpClass raises SkipTest.
