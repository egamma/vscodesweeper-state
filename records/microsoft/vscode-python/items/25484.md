# Issue #25484 — Test runner with unittest seems to ignore updates to tests once decorated to skip

[https://github.com/microsoft/vscode-python/issues/25484](https://github.com/microsoft/vscode-python/issues/25484)

## Summary

Keep open: current source drops the class-level skip result because its synthetic unittest identifier does not match any discovered test. This explains missing skip updates without establishing that test bodies actually execute or that decorators are cached.

## Change summary

Correctly report skipped unittest methods when setUpClass raises SkipTest, including subsequent changes to method-level skip decorators.

## Best solution

Ensure Test Explorer reflects class-level skips for the selected tests rather than retaining or omitting their results. Preserve unittest's execution semantics: setUpClass skipping prevents method execution, and removing that skip restores normal method-level decorator behavior.
