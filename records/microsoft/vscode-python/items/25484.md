# Issue #25484 — Test runner with unittest seems to ignore updates to tests once decorated to skip

[https://github.com/microsoft/vscode-python/issues/25484](https://github.com/microsoft/vscode-python/issues/25484)

## Summary

This is the skip variant of the open canonical setUpClass result-mapping bug: unittest reports a synthetic class-fixture ID that the extension cannot associate with individual test items, leaving their prior UI states intact.

## Change summary

Tests retain stale run or skip states when setUpClass raises unittest.SkipTest, including after skip decorators change.

## Best solution

Consolidate on https://github.com/microsoft/vscode-python/issues/21826 and update the unittest result adapter to map synthetic setUpClass outcomes to the affected class and its test items, preserving the skip outcome when the fixture raises unittest.SkipTest.
