# Issue #25484 — Test runner with unittest seems to ignore updates to tests once decorated to skip

[https://github.com/microsoft/vscode-python/issues/25484](https://github.com/microsoft/vscode-python/issues/25484)

## Summary

Keep open: current source drops the class-level skip outcome when mapping unittest results to Test Explorer items. This explains why tests can appear unchanged when setUpClass raises SkipTest, without establishing that their bodies actually execute.

## Change summary

Test Explorer fails to reflect skipped tests and decorator changes when their class raises unittest.SkipTest in setUpClass.

## Best solution

Make class-level unittest skips resolve the selected tests in that class to skipped in Test Explorer, while retaining unittest's execution semantics and ordinary method-level skip handling.
