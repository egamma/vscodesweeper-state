# Issue #25484 — Test runner with unittest seems to ignore updates to tests once decorated to skip

[https://github.com/microsoft/vscode-python/issues/25484](https://github.com/microsoft/vscode-python/issues/25484)

## Summary

The class-level skip path remains unsupported on current main: unittest reports a setUpClass skip under a synthetic result ID that the extension cannot map to the selected test items. The issue is already accepted for investigation and correctly routed to testing.

## Change summary

Make unittest execution correctly update test states when setUpClass raises SkipTest and when method skip decorators subsequently change.

## Best solution

Teach the unittest execution/result-resolution path to associate setUpClass skip results with the affected class and mark its selected descendants skipped, then cover transitions after adding or removing method-level skip decorators.
