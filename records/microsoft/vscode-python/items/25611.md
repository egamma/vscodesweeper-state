# Issue #25611 — `python.analysis.restartLanguageServer` not found

[https://github.com/microsoft/vscode-python/issues/25611](https://github.com/microsoft/vscode-python/issues/25611)

## Summary

Still present on main: Pyrefly intentionally selects the no-language-server manager, while the command palette continues exposing a restart command whose handler is only registered for Pylance or Jedi.

## Change summary

The Python extension exposes its Restart Language Server command when Pyrefly is active, but invoking it fails because no handler is registered.

## Best solution

Hide or disable `python.analysis.restartLanguageServer` when no Python-managed language server is active, while leaving Pyrefly restart behavior to its owning extension. The diagnostic value `None` is expected for this configuration because Pyrefly is external to the Python extension's language-server managers.
