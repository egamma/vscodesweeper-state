# Issue #25611 — `python.analysis.restartLanguageServer` not found

[https://github.com/microsoft/vscode-python/issues/25611](https://github.com/microsoft/vscode-python/issues/25611)

## Summary

The broken command remains source-reproducible on main when Pyrefly is active. The issue is already routed to the IntelliSense area and should remain open for a command-visibility fix.

## Change summary

The Python extension displays its restart-language-server command while Pyrefly is active, although no handler is registered for that command.

## Best solution

Hide the Python-owned restart command when an external language server such as Pyrefly is active, or delegate it to an exposed restart command from that extension. The diagnostic value `languageServer: "None"` is expected because current integration deliberately disables the Python extension's own language server when Pyrefly is active.
