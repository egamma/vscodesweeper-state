# Issue #24815 — Refresh integrated terminal with .env variables after changing .env file

[https://github.com/microsoft/vscode-python/issues/24815](https://github.com/microsoft/vscode-python/issues/24815)

## Summary

Keep open for the accepted terminal spike: multiple users confirm that the relaunch affordance does not reliably apply updated .env values, and one reports that relaunching loses virtual-environment activation.

## Change summary

Make terminal relaunch reliably apply changed .env variables while preserving Python environment activation.

## Best solution

Investigate the relaunch hyperlink and environment-collection lifecycle in the terminal activation service, ensuring a relaunched terminal receives the latest .env collection and restores interpreter activation. Running child processes cannot have their environment retroactively changed, so the supported boundary should remain terminal relaunch.
