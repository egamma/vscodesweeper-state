# Issue #24756 — Python-Lsp-Server as a replacement for Jedi-Language-Server

[https://github.com/microsoft/vscode-python/issues/24756](https://github.com/microsoft/vscode-python/issues/24756)

## Summary

A real capability gap remains: the extension supports only Pylance, Jedi, or no language server, while the requested PyLsp replacement or alternate-server API is still under investigation. Keep the accepted spike open and route it to the API area.

## Change summary

Replace Jedi Language Server with Python LSP Server, or allow users and extensions to provide another Python language server.

## Best solution

Design the alternate-language-server API tracked by https://github.com/microsoft/vscode-python/issues/24850, then evaluate PyLsp as a provider without restoring bundled linting and formatting responsibilities that belong to dedicated tool extensions.
