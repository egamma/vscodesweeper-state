[https://github.com/microsoft/vscode-python/issues/24756](https://github.com/microsoft/vscode-python/issues/24756)

## Summary

The discussion evolved into supporting user-selected language servers, which is now tracked by the broader alternate-language-server API issue. Consolidating there preserves PyLsp as a concrete use case without maintaining two design threads.

## Change summary

Allow Python-Lsp-Server to replace Jedi Language Server, particularly for improved hover formatting and integrated tooling.

## Best solution
