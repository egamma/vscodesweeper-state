# Issue #24756 — Python-Lsp-Server as a replacement for Jedi-Language-Server

[https://github.com/microsoft/vscode-python/issues/24756](https://github.com/microsoft/vscode-python/issues/24756)

## Summary

A real language-server extensibility gap remains on current main, and the existing `needs spike` label records that the team has accepted further investigation. Route this to the API area while coordinating with the broader alternate-language-server proposal.

## Change summary

Replace Jedi Language Server with Python LSP Server, or expose an API through which alternate Python language servers such as PyLsp can integrate.

## Best solution

Design the alternate-language-server API tracked by https://github.com/microsoft/vscode-python/issues/24850 so server extensions can integrate without changing user settings, while separately deciding whether PyLsp should replace Jedi as the fallback when Pylance is unavailable.
