# Issue #24756 — Python-Lsp-Server as a replacement for Jedi-Language-Server

[https://github.com/microsoft/vscode-python/issues/24756](https://github.com/microsoft/vscode-python/issues/24756)

## Summary

Keep this request open and route it to the language-server/API owners: current main does not support selecting PyLsp, and the team explicitly left the alternative-server decision open. The related API request is newer and cannot serve as a duplicate target under the re-review rules.

## Change summary

Support Python-Lsp-Server instead of Jedi-Language-Server, potentially through an API for user-selected language servers.

## Best solution

Decide whether PyLsp should be a built-in alternative or integrate through a general language-server API, coordinating with https://github.com/microsoft/vscode-python/issues/24850. Preserve the dedicated tools-extension architecture rather than treating bundled linting and formatting as a prerequisite.
