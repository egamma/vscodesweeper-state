# Issue #26065 — Activating environment takes a few seconds

[https://github.com/microsoft/vscode-python/issues/26065](https://github.com/microsoft/vscode-python/issues/26065)

## Summary

The current Python extension delegates terminal activation and terminal creation to the installed Python Environments extension, making that sibling tracker the likely owner. Keep this open until a maintainer transfers it; no verified open canonical currently owns the regression.

## Change summary

Venv activation takes 3–4 seconds, allowing terminal commands and Run Python File execution to start before activation completes.

## Best solution

A maintainer can transfer this to https://github.com/microsoft/vscode-python-environments, where terminal creation should wait for activation before accepting or launching commands while also avoiding the reported delay.
