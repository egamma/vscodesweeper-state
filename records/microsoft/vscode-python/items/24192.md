# Issue #24192 — Show "install Jupyter extension" only if users have rich output in REPL

[https://github.com/microsoft/vscode-python/issues/24192](https://github.com/microsoft/vscode-python/issues/24192)

## Summary

Keep open: this team-authored REPL feature is accepted for investigation under `needs spike`, and current main still exposes the Jupyter installation action through static menu conditions rather than detecting rich-output usage.

## Change summary

Offer installation of the Jupyter extension only when REPL input requests rich output that the native REPL cannot faithfully render.

## Best solution

Spike a rich-output signal in the native REPL execution path, then condition the Jupyter installation suggestion on that signal while retaining plain-text native REPL output for ordinary execution.
