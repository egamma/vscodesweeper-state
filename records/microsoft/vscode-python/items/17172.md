# Issue #17172 — Support IPython for Shift+Enter (execute line in terminal)

[https://github.com/microsoft/vscode-python/issues/17172](https://github.com/microsoft/vscode-python/issues/17172)

## Summary

Keep this accepted, team-authored feature request open: it exceeded the community-interest threshold, carries `community ask` and `needs proposal`, and current source still recognizes the standard Python prompt but not IPython's prompt when dispatching Shift+Enter input.

## Change summary

Support reliably launching IPython and executing lines or selections in it with Shift+Enter.

## Best solution

Define the supported IPython terminal workflow, then make REPL readiness detection handle IPython prompts so queued Shift+Enter input is sent only after IPython is ready. Keep this issue as the specific canonical request and consolidate the newer reproduction at https://github.com/microsoft/vscode-python/issues/25915 into its implementation work.
