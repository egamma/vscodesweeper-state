# Issue #17172 — Support IPython for Shift+Enter (execute line in terminal)

[https://github.com/microsoft/vscode-python/issues/17172](https://github.com/microsoft/vscode-python/issues/17172)

## Summary

Keep this accepted, team-authored feature request open as the focused tracker for reliable Shift+Enter execution in IPython. Current main still has no IPython-aware execution path, and a recent report confirms the central gap remains.

## Change summary

Make Shift+Enter reliably execute selected Python code in an IPython terminal.

## Best solution

Add an IPython-aware send and readiness strategy to the terminal code-execution path, potentially using the direct REPL integration explored in https://github.com/microsoft/vscode-python/issues/18177. Preserve this issue as the focused tracker rather than folding it into the broader fully integrated IPython experience.
