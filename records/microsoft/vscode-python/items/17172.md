# Issue #17172 — Support IPython for Shift+Enter (execute line in terminal)

[https://github.com/microsoft/vscode-python/issues/17172](https://github.com/microsoft/vscode-python/issues/17172)

## Summary

Keep open: this team-authored, community-backed request remains accepted under `needs proposal` and `community ask`, and current terminal execution still lacks explicit IPython readiness handling.

## Change summary

Make Shift+Enter reliably execute selected Python code in an IPython terminal.

## Best solution

Add IPython-aware REPL readiness and code-submission handling to the terminal execution path, coordinating the narrow Shift+Enter behavior here with the broader IPython integration tracked in https://github.com/microsoft/vscode-python/issues/22139.
