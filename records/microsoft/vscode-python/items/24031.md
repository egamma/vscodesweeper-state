# Issue #24031 — Insert into Python REPL from Copilot chat panel

[https://github.com/microsoft/vscode-python/issues/24031](https://github.com/microsoft/vscode-python/issues/24031)

## Summary

The existing editor-to-REPL commands do not provide the requested Copilot chat code-block action. Keep this team-authored request open; the remaining work is to define the chat interaction and establish the integration boundary.

## Change summary

Provide an action on Python code generated in Copilot chat to insert or run it directly in the Python REPL.

## Best solution

Provide a Python chat-code-block action connected to the native REPL, coordinated with VS Code's chat UI. Decide whether insertion leaves code editable before execution or whether insertion and execution are separate actions, while preserving existing editor and terminal workflows.
