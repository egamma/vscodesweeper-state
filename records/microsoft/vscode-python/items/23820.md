# Issue #23820 — Python extension creates too many zsh processes after update to v2024.10.0

[https://github.com/microsoft/vscode-python/issues/23820](https://github.com/microsoft/vscode-python/issues/23820)

## Summary

The recursive shell-spawning path remains in the legacy terminal activation implementation on current main. This issue is already the best canonical report and has the correct terminal-area label, so it should remain open.

## Change summary

Prevent terminal environment deactivation from recursively spawning thousands of zsh processes when shell startup hooks automatically activate or deactivate virtual environments.

## Best solution

Make the legacy deactivation helper unable to re-enter through zsh startup hooks, preferably by avoiding PATH-shadowing shell executables or adding a robust recursion guard. Cover automatic virtual-environment hooks on both local macOS and remote Linux terminals.
