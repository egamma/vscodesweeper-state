# Issue #21238 — Add support for refreshing tests in a single project/package/module.

[https://github.com/microsoft/vscode-python/issues/21238](https://github.com/microsoft/vscode-python/issues/21238)

## Summary

This remains an accepted testing feature request with demonstrated community interest. VS Code core added the context needed to contribute a per-item action, but the Python extension still only exposes whole-workspace refresh and does not implement project, package, or module-scoped discovery from the Test Explorer.

## Change summary

Add a Test Explorer action that refreshes discovery only for the selected Python test project, package, module, or subtree.

## Best solution

Add a Python-owned command to the `testing/item/context` menu, map the selected `TestItem` to its project or discovery path, and refresh that scope without clearing or rediscovering unrelated test-tree branches. The proposal should define behavior for both project-based and legacy discovery before implementation.
