# Issue #21238 — Add support for refreshing tests in a single project/package/module.

[https://github.com/microsoft/vscode-python/issues/21238](https://github.com/microsoft/vscode-python/issues/21238)

## Summary

A real capability gap remains on current main: Python contributes no per-item refresh action, and refreshing a workspace still discovers every project within it. The request has documented community support and is already accepted for proposal work in the testing area.

## Change summary

Allow users to refresh test discovery for one selected project, package, module, or Test Explorer subtree instead of the entire workspace.

## Best solution

Design and contribute a `testing/item/context` refresh command that maps the selected TestItem to its owning Python project or narrower discovery target, then refreshes that scope without clearing or rediscovering unrelated projects. The proposal should define behavior for discovery-error nodes and pytest collection failures.
