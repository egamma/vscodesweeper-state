# Issue #21238 — Add support for refreshing tests in a single project/package/module.

[https://github.com/microsoft/vscode-python/issues/21238](https://github.com/microsoft/vscode-python/issues/21238)

## Summary

Keep open: the community-feedback threshold was met, a maintainer explicitly retained the request, and current main still lacks a scoped refresh action.

## Change summary

Allow users to refresh test discovery for a selected project, package, module, or Test Explorer subtree instead of the entire workspace.

## Best solution

Add a `testing/item/context` refresh command that maps the selected test item to targeted discovery, coordinating with the module/file discovery work in https://github.com/microsoft/vscode-python/issues/24279 where appropriate.
