# Issue #24008 — Canceling cwd selector for repl in multi root workspaces results in no cwd

[https://github.com/microsoft/vscode-python/issues/24008](https://github.com/microsoft/vscode-python/issues/24008)

## Summary

Still present on current main: dismissing the workspace-folder picker leaves the REPL cwd undefined, but initialization continues and opens the REPL. The existing area-repl label already routes this confirmed bug correctly.

## Change summary

Canceling the native REPL cwd picker in a multi-root workspace opens a REPL without a workspace cwd instead of canceling the launch and prompting again next time.

## Best solution

Treat an dismissed cwd picker as cancellation of the current REPL launch: do not create or retain the NativeRepl singleton, Python server, controller, or notebook, so invoking the command again presents the picker again.
