# Issue #24008 — Canceling cwd selector for repl in multi root workspaces results in no cwd

[https://github.com/microsoft/vscode-python/issues/24008](https://github.com/microsoft/vscode-python/issues/24008)

## Summary

The bug remains on current main: canceling the multi-root directory picker leaves cwd undefined, but REPL creation continues. The existing area-repl label routes it correctly.

## Change summary

Canceling the native REPL working-directory picker should not open a REPL without a selected workspace directory.

## Best solution

Abort REPL creation when the directory picker is canceled and avoid retaining the singleton, so invoking the command again presents the picker again.
