# Issue #24008 — Canceling cwd selector for repl in multi root workspaces results in no cwd

[https://github.com/microsoft/vscode-python/issues/24008](https://github.com/microsoft/vscode-python/issues/24008)

## Summary

Still present on current main: cancelling the workspace picker leaves the REPL cwd undefined, but REPL creation continues. The issue is already correctly routed to area-repl.

## Change summary

Cancelling the native REPL cwd picker in a multi-root workspace opens a REPL without a workspace cwd.

## Best solution

Treat cancellation as cancellation of REPL creation, leaving the singleton unset so the workspace picker appears again on the next invocation.
