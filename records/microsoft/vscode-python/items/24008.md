# Issue #24008 — Canceling cwd selector for repl in multi root workspaces results in no cwd

[https://github.com/microsoft/vscode-python/issues/24008](https://github.com/microsoft/vscode-python/issues/24008)

## Summary

Canceling the multi-root directory picker still launches the native REPL with an undefined cwd on current main. Keep this open: reopening after closing now resets the session, but the initial cancellation behavior remains unresolved.

## Change summary

Pressing Escape in the native REPL's multi-root directory selector opens a session without a selected workspace working directory.

## Best solution

Define the native REPL's cancellation contract so declining a workspace selection does not silently produce an unscoped session. Preserve the maintainer's requested opportunity to select a directory on a subsequent opening, while keeping existing single-folder and no-folder behavior.
