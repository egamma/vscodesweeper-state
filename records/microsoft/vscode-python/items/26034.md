# Issue #26034 — Cannot select interpreters

[https://github.com/microsoft/vscode-python/issues/26034](https://github.com/microsoft/vscode-python/issues/26034)

## Summary

The interpreter-selection reversion is traced to inconsistent Python Environments extension gating on current main. Keep the issue open while the explicitly linked fixing PR is reviewed.

## Change summary

Selecting another interpreter in single-file mode immediately reverts to the default interpreter when the Python Environments extension manages the status bar.

## Best solution

Review and land https://github.com/microsoft/vscode-python/pull/26063, ensuring interpreter selection, reset, and active-interpreter resolution consistently delegate to the Python Environments extension when it owns activation.
