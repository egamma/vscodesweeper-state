# Issue #25069 — Support pytest test discovery in monorepo setup with multipe tests/conftest.py

[https://github.com/microsoft/vscode-python/issues/25069](https://github.com/microsoft/vscode-python/issues/25069)

## Summary

Project-based testing now supports separate pytest discovery processes for projects within one workspace, addressing the repeated tests/conftest.py collision without renaming directories. The implementation shipped in 2026.2.0 and requires projects registered with the enabled Python Environments extension.

## Change summary

Support pytest discovery across monorepo projects that each contain their own tests/conftest.py.

## Best solution

Use the shipped project-based testing integration with python.useEnvironmentsExtension enabled and each subproject registered separately. Preserve pytest's import semantics while isolating collection by project rather than renaming test directories.
