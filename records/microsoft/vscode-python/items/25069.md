# Issue #25069 — Support pytest test discovery in monorepo setup with multipe tests/conftest.py

[https://github.com/microsoft/vscode-python/issues/25069](https://github.com/microsoft/vscode-python/issues/25069)

## Summary

Project-based pytest discovery now runs each Python project independently, preventing sibling tests/conftest.py modules from colliding. The implementation shipped in Python extension 2026.2.0, so this can be closed as completed.

## Change summary

Support pytest discovery for monorepositories containing multiple projects with identically named tests/conftest.py modules.

## Best solution

Keep the project-based testing architecture shipped in 2026.2.0: discover Python projects through the Python Environments API and invoke pytest separately for each project root and environment.
