# Issue #25069 — Support pytest test discovery in monorepo setup with multipe tests/conftest.py

[https://github.com/microsoft/vscode-python/issues/25069](https://github.com/microsoft/vscode-python/issues/25069)

## Summary

Project-based pytest discovery now isolates each detected Python project, preventing one discovery process from importing duplicate tests/conftest.py modules across a monorepo. This shipped in 2026.2.0, so the broader request can close as completed.

## Change summary

Discover pytest tests separately for each project in a monorepo containing multiple tests/conftest.py files.

## Best solution

Keep the project-scoped discovery shipped in commit 502ad7021b59c98b40351863faf1d41a57d7e251; use https://github.com/microsoft/vscode-python/issues/26023 for the narrower remaining case where per-subfolder pytest configuration is not honored.
