# Issue #25069 — Support pytest test discovery in monorepo setup with multipe tests/conftest.py

[https://github.com/microsoft/vscode-python/issues/25069](https://github.com/microsoft/vscode-python/issues/25069)

## Summary

Project-based pytest discovery now runs each Python project separately and excludes nested projects from parent discovery, preventing multiple tests/conftest.py trees from colliding. The implementation shipped in 2026.2.0, so this can be closed as completed.

## Change summary

Support pytest discovery across monorepo projects that each contain a tests/conftest.py file.

## Best solution

Keep the project-based testing architecture shipped in 2026.2.0, where each Python project has an isolated discovery adapter, environment, root, and pytest process.
