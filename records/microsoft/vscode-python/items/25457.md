[https://github.com/microsoft/vscode-python/issues/25457](https://github.com/microsoft/vscode-python/issues/25457)

## Summary

Keep open: the team has accepted the work with `needs PR`, and multiple reports show that the current Python extension cannot be installed on vscode.dev after adding the Python Environments dependency. This team-authored issue is the older, better-diagnosed canonical report.

## Change summary

Make the latest Python extension install and load on vscode.dev despite its dependency on the Python Environments extension.

## Best solution

Add a browser-compatible entry point with a deliberately limited web implementation to the Python Environments extension, then ensure the Python extension's dependency and activation path allow the current release to install on vscode.dev.
