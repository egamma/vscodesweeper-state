# Issue #25457 — Python extension doesn't load in Web

## Summary

Keep this accepted, team-authored web-compatibility request open. Python already has a browser entry point, but its bundled Python Environments extension still lacks one; no issue-referencing fix or eligible older duplicate was established.

## Change summary

Allow the current Python extension to install and load on vscode.dev despite its bundled Python Environments extension.

## Best solution

Restore installation and partial IntelliSense on vscode.dev while preserving desktop environment functionality. Coordinate the browser-compatibility boundary with https://github.com/microsoft/vscode-python-environments rather than treating an older-version installation workaround as completion.
