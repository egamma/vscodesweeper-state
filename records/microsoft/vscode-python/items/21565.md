# Issue #21565 — Running npm run test:functional is different from running functional test via debugger

[https://github.com/microsoft/vscode-python/issues/21565](https://github.com/microsoft/vscode-python/issues/21565)

## Summary

The two functional-test entry points still use different Mocha configurations on current main. This team-authored, accepted debt item should remain open and be routed to the internal area.

## Change summary

Make command-line and debugger functional-test runs use equivalent arguments and behavior.
