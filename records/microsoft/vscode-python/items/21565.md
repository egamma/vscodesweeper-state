# Issue #21565 — Running npm run test:functional is different from running functional test via debugger

[https://github.com/microsoft/vscode-python/issues/21565](https://github.com/microsoft/vscode-python/issues/21565)

## Summary

Keep open: current `main` still defines the npm functional-test command and debugger launch with materially different Mocha options. This is a team-authored, accepted `needs PR` debt item, so it is protected from a judgment close.

## Change summary

Make functional tests behave consistently whether launched through `npm run test:functional` or the VS Code debugger configuration.

## Best solution

Have both entry points consume `build/.mocha.functional.json`, with the debugger configuration adding only debugger-specific behavior, so test selection, timeout, reporters, setup modules, and future changes remain synchronized.
