# Issue #21565 — Running npm run test:functional is different from running functional test via debugger

[https://github.com/microsoft/vscode-python/issues/21565](https://github.com/microsoft/vscode-python/issues/21565)

## Summary

The configuration mismatch remains on main, and this team-authored issue is already accepted with `needs PR`; it should stay open.

## Change summary

Make command-line and debugger launches of the repository's functional tests use equivalent Mocha configuration.

## Best solution

Have the functional-test launch configuration consume `build/.mocha.functional.json` through the same Mocha invocation used by `npm run test:functional`, eliminating duplicated arguments and preventing future drift.
