# Issue #17371 — Open correct position in `Pytest Test Log` with a single click on any test

[https://github.com/microsoft/vscode-python/issues/17371](https://github.com/microsoft/vscode-python/issues/17371)

## Summary

A real navigation gap remains: pytest output now appears in Test Results, but current main appends it only at run scope, so selecting a test cannot focus that test's raw output. This team-authored issue is accepted for proposal work and must remain open.

## Change summary

Selecting a test should open its pytest output and navigate directly to that test's section.

## Best solution

Define and implement a testing-area proposal that associates pytest output ranges with individual TestItems, allowing Test Results to focus the relevant raw output when a test is selected.
