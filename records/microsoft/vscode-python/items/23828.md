# Issue #23828 — Getting "pytest test discovery error for workspace" when having multiple projects in workspace

[https://github.com/microsoft/vscode-python/issues/23828](https://github.com/microsoft/vscode-python/issues/23828)

## Summary

The issue remains necessary: current main still initiates discovery for every workspace folder where pytest resolves as enabled, without excluding non-Python folders. It is already correctly routed to area-testing.

## Change summary

Mixed-language multi-root workspaces run pytest discovery in non-Python folders, producing errors that interfere with the usable Python test tree.

## Best solution

Restrict legacy discovery in src/client/testing/testController/controller.ts to applicable Python workspace folders while preserving explicit per-folder testing configuration, and isolate one folder's discovery failure from valid folders.
