# Issue #26224 — update precedence on exp

[https://github.com/microsoft/vscode-python/issues/26224](https://github.com/microsoft/vscode-python/issues/26224)

## Summary

The requested fallback and consistent experiment handling are still missing on main. Route to environment integration and coordinate with Python Environments; the related reports cover only portions of this request.

## Change summary

Resolve environment-extension enablement as explicit configuration, then experiment treatment, then true, consistently across activation and UI.

## Best solution

Establish one effective enablement contract across both extensions, preserving configuration precedence and standalone Python Environments usage. Coordinate activation, integration consumers, and contribution visibility so exactly one implementation manages environments.
