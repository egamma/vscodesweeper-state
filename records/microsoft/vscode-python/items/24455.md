## Summary

A real pytest-adapter capability gap remains on main: pytest subtests are not emitted as individual outcomes for the Testing view. The accepted `needs PR` request should remain open; the narrower false-pass defect is tracked separately.

## Change summary

Display pytest subtests individually in the Testing view and preserve each subtest's outcome.

## Best solution

Extend `python_files/vscode_pytest/__init__.py` to identify and emit individual pytest subtest reports using the existing subtest result shape consumed by `TestExecutionHandler`. Coordinate parent-result aggregation with https://github.com/microsoft/vscode-python/issues/25824 without folding this broader UI request into that narrower bug.
