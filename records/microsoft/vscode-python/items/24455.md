# Issue #24455 — Add support for unittest subtest with pytest as the adapter

[https://github.com/microsoft/vscode-python/issues/24455](https://github.com/microsoft/vscode-python/issues/24455)

## Summary

Keep open as accepted testing work: pytest-driven subtests still are not represented individually in the Test Explorer, the issue has exceeded the community threshold with 14 upvotes, carries `needs PR`, and has a recent contributor proposing an implementation.

## Change summary

Add pytest-adapter support for displaying and correctly reporting individual unittest-style subtests in the Test Explorer.

## Best solution

Extend `python_files/vscode_pytest/__init__.py` to recognize pytest 9 subtest reports and emit stable `subtest-success` and `subtest-failure` outcomes, with adapter fixtures covering passing, failing, repeated, unnamed, and parametrized subtests. Keep the narrower parent-result correctness fix coordinated with https://github.com/microsoft/vscode-python/issues/25824 rather than treating that issue as canonical for this broader UI capability.
