# Issue #23629 — Support for PDM's .pdm-python file

[https://github.com/microsoft/vscode-python/issues/23629](https://github.com/microsoft/vscode-python/issues/23629)

## Summary

Keep this request open: its 23 upvotes exceed the community-feedback threshold, and the inspected interpreter-selection surfaces do not read .pdm-python. The remaining work is project-specific interpreter discovery, with ownership to coordinate against the Python Environments extension rollout.

## Change summary

Suggest the interpreter recorded in a project's .pdm-python file, including externally stored environments, and optionally notify when that file changes.

## Best solution

Surface the interpreter identified by .pdm-python without requiring users to locate it among unrelated environments or manually copy its path into settings. Coordinate this capability with Python Environments; a maintainer can transfer the request to https://github.com/microsoft/vscode-python-environments if that extension should own the workflow.
