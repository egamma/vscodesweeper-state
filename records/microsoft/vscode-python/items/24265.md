# Issue #24265 — Unable to identify Python executable from path due to apostrophe

[https://github.com/microsoft/vscode-python/issues/24265](https://github.com/microsoft/vscode-python/issues/24265)

## Summary

The apostrophe-quoting defect remains in the core extension's terminal execution path: both executable and script paths can reach PowerShell unquoted. Keep this accepted investigation open; the older shell-escaping issue reports different observable symptoms and does not meet the stronger duplicate bar for this re-reviewed report.

## Change summary

Running a Python file fails when an apostrophe in the Windows username is interpreted as shell quoting instead of preserved in the executable and script paths.

## Best solution

Make the core terminal-run path preserve apostrophes in executable and script paths under PowerShell, including the sendText fallback, without changing interpreter discovery or requiring users to rename directories. Coordinate with the broader shell-escaping work at https://github.com/microsoft/vscode-python/issues/24126 while retaining this specific regression case.
