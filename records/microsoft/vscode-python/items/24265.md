[https://github.com/microsoft/vscode-python/issues/24265](https://github.com/microsoft/vscode-python/issues/24265)

## Change summary

Running a Python file fails on Windows when the interpreter path contains an apostrophe because the generated shell command does not escape it.

## Best solution

Implement shell-specific quoting in the terminal command builder under https://github.com/microsoft/vscode-python/issues/24126, including a PowerShell case for apostrophes in executable and script paths.
