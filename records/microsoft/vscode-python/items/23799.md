# Issue #23799 — autoloading `.env` file format does not ignore inline comments.

[https://github.com/microsoft/vscode-python/issues/23799](https://github.com/microsoft/vscode-python/issues/23799)

## Summary

The inline-comment parsing defect remains conclusively present on current main, and the existing `needs spike` label records that maintainers accepted it for investigation. The broader environment-parsing issue is a meta tracker rather than a valid duplicate canonical.

## Change summary

Parse `.env` inline comments as comments instead of including them in environment-variable values.

## Best solution

Update `parseEnvLine` in `src/client/common/variables/environment.ts` to strip inline comments outside quoted values while preserving literal `#` characters inside quotes, with matching parser tests. Keep the behavior consistent with the parser being developed in the Python Environments extension.
