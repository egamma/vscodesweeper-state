# Issue #23799 — autoloading `.env` file format does not ignore inline comments.

[https://github.com/microsoft/vscode-python/issues/23799](https://github.com/microsoft/vscode-python/issues/23799)

## Summary

Inline comments still become part of environment values on current main, and an existing test explicitly expects that behavior. Keep this accepted investigation open as a parsing-compatibility improvement; closing as fixed or requesting more information is not supported.

## Change summary

Support trailing inline comments in .env files without including them in loaded environment values.

## Best solution

Agree on a compatible inline-comment grammar across the Python extension family, then ensure environment loading follows it consistently. Coordinate with the broader standardization discussion while preserving this concrete terminal and debugger report.
