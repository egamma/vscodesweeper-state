# Issue #23799 — autoloading `.env` file format does not ignore inline comments.

[https://github.com/microsoft/vscode-python/issues/23799](https://github.com/microsoft/vscode-python/issues/23799)

## Summary

The defect remains directly reproducible in current source: inline comments are retained as part of unquoted values. The issue is already accepted for investigation with `needs spike` and correctly routed, so it should remain open.

## Change summary

The `.env` parser should exclude inline comments from unquoted environment-variable values while preserving hash characters inside quoted values.

## Best solution

Update `parseEnvLine` in `src/client/common/variables/environment.ts` to parse inline comments consistently with established dotenv behavior, including quote-aware handling, and revise the parser tests in `src/test/common/variables/envVarsService.unit.test.ts`.
