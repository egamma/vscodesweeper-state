# Issue #21998 — Try avoid putting run commands into shell history

[https://github.com/microsoft/vscode-python/issues/21998](https://github.com/microsoft/vscode-python/issues/21998)

## Summary

The gap remains on current main: activation and run commands can still be submitted without history suppression. This accepted proposal should stay open and also route to the terminal area.

## Change summary

Avoid adding Python environment activation and file-run commands to users' shell history.

## Best solution

Develop a cross-shell proposal in the terminal integration that suppresses history for commands owned by this extension without changing interactive commands; VS Code core should handle the separate DAP run-in-terminal case.
