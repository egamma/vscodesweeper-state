# Issue #21998 — Try avoid putting run commands into shell history

[https://github.com/microsoft/vscode-python/issues/21998](https://github.com/microsoft/vscode-python/issues/21998)

## Summary

A real gap remains: current main can still submit run and activation commands through terminal APIs that add them to shell history. The accepted `needs proposal` request has exceeded the community threshold, so it should remain open for a cross-shell design.

## Change summary

Prevent commands initiated by Python run, activation, and related flows from cluttering users' persistent shell history.

## Best solution

Design a shell-aware mechanism in the terminal and environment integration that suppresses history without changing command semantics, covering shell-integration and `sendText` fallbacks. Debug-adapter execution may require coordinated support in VS Code core, as noted by maintainers.
