The conflicting-scope activation defect remains in current source. Keep this open while maintainers review the two open fixing PRs; neither is a completed fix.

## Change summary

Conflicting user and workspace settings make Python consume an unavailable Python Environments API, aborting activation instead of using legacy discovery.
