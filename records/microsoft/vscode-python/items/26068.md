# Issue #26068 — Python activation fails when environment extension settings conflict across scopes

[https://github.com/microsoft/vscode-python/issues/26068](https://github.com/microsoft/vscode-python/issues/26068)

## Summary

The activation failure is confirmed on current main, and two open PRs explicitly reference this issue with targeted fixes and regression coverage. Keep the issue open until one implementation is reviewed and merged.

## Change summary

Conflicting user- and workspace-scoped python.useEnvironmentsExtension settings cause the Python extension to consume an API that the Python Environments extension declined to export.

## Best solution

Review and land one of the linked fixes so useEnvExtension() also respects shouldEnvExtHandleActivation(), then close the competing PR and verify that the legacy environment path is used when any scope explicitly disables the environments extension.
