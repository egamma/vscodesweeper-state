# Issue #8104 — Remove debugOptions when using python debug adapter

[https://github.com/microsoft/vscode-python/issues/8104](https://github.com/microsoft/vscode-python/issues/8104)

## Summary

The requested cleanup remains on current main: both launch and attach resolvers still synthesize and forward legacy `debugOptions`. This team-authored issue is accepted with `needs PR`, and no qualifying referenced fix or duplicate supports closing it.

## Change summary

Stop translating modern Python debug configuration properties into the legacy `debugOptions` array sent to the Python debug adapter.

## Best solution

Remove legacy `debugOptions` construction from the launch and attach configuration resolvers while preserving supported direct configuration properties such as `clientOS`, then update the resolver types and unit-test expectations.
