# Issue #23268 — Error occurs with "Python: Report Issue..." if certain extension is loaded

[https://github.com/microsoft/vscode-python/issues/23268](https://github.com/microsoft/vscode-python/issues/23268)

## Summary

Keep open for investigation in the internal area: the issue was deliberately reopened and marked `needs spike` after an earlier null-safe sorting fix had landed, so that pre-reopen commit cannot establish that the persistent problem is resolved.

## Change summary

The Python issue-reporting command crashes while sorting installed-extension metadata when certain third-party extensions are loaded.

## Best solution

Spike the current `getExtensions()` results from the identified extensions and make `ReportIssueCommandHandler.openReportIssue` tolerate all missing optional package metadata while still producing the installed-extensions table. Add a regression test using the malformed metadata shape found during that investigation.
