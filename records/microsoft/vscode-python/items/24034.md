## Change summary

Document how `.env` variables are loaded into terminals, including precedence, update timing, persistence, and how to disable the behavior.

## Best solution

Expand the Python environment documentation and setting descriptions to distinguish the legacy Python-extension behavior from the Python Environments extension, explaining when variables are injected, how existing environment variables win, when changes affect terminals, and which setting disables injection.
