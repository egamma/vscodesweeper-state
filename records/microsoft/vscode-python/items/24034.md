# Issue #24034 — Better documentation about .env file

[https://github.com/microsoft/vscode-python/issues/24034](https://github.com/microsoft/vscode-python/issues/24034)

## Summary

Keep open: this team-authored documentation debt is explicitly accepted with `needs PR`, and no linked pull request has completed it. The current setting description still does not explain that `.env` values can be injected into newly created terminals or how that affects variable precedence and updates.

## Change summary

Document how `python.envFile` variables are loaded into terminals, including persistence, refresh behavior, and precedence relative to application-level dotenv loaders.

## Best solution

Update the Python environment-variable documentation to state when `.env` values are applied to terminal processes, how existing and newly created terminals behave after file changes, and how injected variables interact with libraries such as python-dotenv. The documentation should also identify the currently supported way to disable this behavior, if one exists.
