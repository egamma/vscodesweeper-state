# Issue #24034 — Better documentation about .env file

[https://github.com/microsoft/vscode-python/issues/24034](https://github.com/microsoft/vscode-python/issues/24034)

## Summary

Keep open: this team-authored documentation debt is accepted with `needs PR`, and the discussion provides concrete evidence that the default `.env` behavior remains insufficiently discoverable.

## Change summary

Document when and how the extension loads `.env` variables, their precedence and affected surfaces, and the supported way to opt out.

## Best solution

Expand the environment-variables documentation and the `python.envFile` setting description to disclose the default `${workspaceFolder}/.env`, explain its effects on terminals, debugging, and testing, clarify variable precedence, and document the supported opt-out behavior.
