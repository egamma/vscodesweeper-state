# Issue #25670 — Remote (SSH) debugging/running not working on python files

[https://github.com/microsoft/vscode-python/issues/25670](https://github.com/microsoft/vscode-python/issues/25670)

## Summary

The reporter repeatedly confirmed a deterministic remote-debugging failure after terminating Python processes, with window reload as the only recovery. The issue remains actionable and should be routed to debugging.

## Change summary

Remote SSH debug and run commands stop responding after Python processes are killed on the remote host and do not recover until the window reloads.

## Best solution

Make debug launch recover when a previously managed remote Python process is externally terminated, without requiring an extension-host reload. The debugging owner should identify the killed process from Python and Python Debugger output logs and determine whether recovery belongs in this repository's adapter-launch integration or microsoft/vscode-python-debugger.
