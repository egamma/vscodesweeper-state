# Issue #25597 — Incorrect django test coverage report with parallel tests

[https://github.com/microsoft/vscode-python/issues/25597](https://github.com/microsoft/vscode-python/issues/25597)

## Summary

The current coverage path records only the parent unittest-adapter process and does not collect or combine data from Django's parallel workers. This remains a source-reproducible testing bug on main.

## Change summary

Django tests executed in parallel produce incomplete coverage because worker-process coverage is not combined.

## Best solution

Update the unittest coverage integration in python_files/unittestadapter/execution.py to collect coverage from Django's worker processes and combine it before constructing the coverage payload, while preserving existing non-parallel unittest coverage.
