# Issue #25597 — Incorrect django test coverage report with parallel tests

[https://github.com/microsoft/vscode-python/issues/25597](https://github.com/microsoft/vscode-python/issues/25597)

## Summary

The parallel Django coverage gap remains on current main: coverage is started only in the adapter process, while Django executes tests in worker processes whose coverage data is neither collected nor combined. The issue is already routed to the testing area and should remain open.

## Change summary

Django tests executed with --parallel report incomplete coverage because results from the worker processes are not combined.

## Best solution

Update the unittest coverage path to collect coverage from Django's parallel workers and combine their data before producing the VS Code coverage payload. Add a Django coverage regression test using --parallel so both parent- and worker-executed lines must appear.
