# Issue #25597 — Incorrect django test coverage report with parallel tests

[https://github.com/microsoft/vscode-python/issues/25597](https://github.com/microsoft/vscode-python/issues/25597)

## Summary

Keep open: current main supports in-process Django coverage, but its reporting path does not combine parallel-worker coverage. The supplied arguments, environment details, and logs suffice to retest; the existing serial coverage test does not establish that this parallel scenario works.

## Change summary

Running Django tests with --parallel produces coverage that does not include the combined execution of all test workers.

## Best solution

Ensure Django coverage runs report the union of coverage from every worker without changing serial execution or test-result reporting. First reproduce with multiple actual workers on the reported macOS/Python configuration and establish how coverage collection starts and finishes in those workers.
