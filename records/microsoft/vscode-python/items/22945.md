# Issue #22945 — Python line is sent before REPL is opened

[https://github.com/microsoft/vscode-python/issues/22945](https://github.com/microsoft/vscode-python/issues/22945)

## Summary

The race remains possible on current main: REPL initialization uses prompt-character detection with an unconditional three-second fallback, so slow startup can release queued code before Python is ready. Keep this correctly routed, team-authored bug open.

## Change summary

Prevent the first Shift+Enter line from being sent to the shell before the terminal Python REPL finishes starting after a cache clear and reload.

## Best solution

Gate code dispatch on confirmed readiness from the specific REPL terminal rather than a fixed timeout or unscoped prompt-character count, and cover the clear-cache/reload sequence with a regression test.
