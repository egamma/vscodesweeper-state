# Issue #22945 — Python line is sent before REPL is opened

[https://github.com/microsoft/vscode-python/issues/22945](https://github.com/microsoft/vscode-python/issues/22945)

## Summary

Keep open pending a targeted retest: current main queues Python commands until REPL readiness, which may address this startup race, but the change does not reference this team-authored issue. The linked test plan provides sufficient steps to retest clearing the cache, reloading, and sending the first line.

## Change summary

After clearing the extension cache and reloading, the first Python line is sent to the command shell before the Python REPL starts.

## Best solution

Confirm that the existing terminal command queue preserves the first Shift+Enter submission after cache clearing and reload, without sending it to the outer shell. If the race remains, address readiness handling in the terminal REPL execution path rather than increasing startup delays.
