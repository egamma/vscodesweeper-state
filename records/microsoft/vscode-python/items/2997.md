# Issue #2997 — Run Selection/Line and Run File produce error when used consecutively

[https://github.com/microsoft/vscode-python/issues/2997](https://github.com/microsoft/vscode-python/issues/2997)

## Summary

The conflicting command flow remains visible on main, and this accepted issue is the established canonical for several later reports. Both commands still use the same standard execution service, allowing a file command to be sent into an active Python REPL.

## Change summary

Run File and Run Selection/Line should not send shell and Python commands into the same terminal state when used consecutively.

## Best solution

Route selection execution through a distinct REPL terminal service, or reliably track the terminal's current shell/REPL state before dispatching either command. The existing `repl` service binding in `src/client/terminals/serviceRegistry.ts` provides a likely separation point.
