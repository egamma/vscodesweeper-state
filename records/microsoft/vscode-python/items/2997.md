# Issue #2997 — Run Selection/Line and Run File produce error when used consecutively

[https://github.com/microsoft/vscode-python/issues/2997](https://github.com/microsoft/vscode-python/issues/2997)

## Summary

The conflicting execution path remains on current main: Run File and Run Selection both use the same standard terminal service, while only selection initializes and tracks a REPL. Keep this canonical issue open for the existing proposal/design work.

## Change summary

Running a file and sending a selection consecutively reuses one terminal across incompatible shell and Python REPL states, causing the second command to be interpreted incorrectly.

## Best solution

Define the intended relationship between file execution and terminal REPL sessions, then make the standard execution provider distinguish shell and REPL state or use separate terminals so each command is sent to a compatible process. Add coverage for both command orderings in the terminal code-execution tests.
