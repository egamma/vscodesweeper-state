# Issue #11736 — Argument filtering for pytest fails to handle custom arguments

[https://github.com/microsoft/vscode-python/issues/11736](https://github.com/microsoft/vscode-python/issues/11736)

## Summary

The original discovery path has been rewritten, but the underlying custom-argument filtering defect remains in current execution code: a separated custom option value is mistaken for a positional test path and removed. The issue already has the accepted-work `needs PR` label and should remain open in the testing area.

## Change summary

Preserve custom pytest option/value pairs from python.testing.pytestArgs during test discovery and execution.

## Best solution

Replace or redesign the positional-argument filtering in src/client/testing/testController/pytest/arguments.ts so unknown pytest/plugin options can retain separate values without preserving configured test paths. Coordinate that work with the broader per-operation configuration proposal at https://github.com/microsoft/vscode-python/issues/21845.
