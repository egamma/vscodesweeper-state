# Issue #25922 — Run Selection/Line in Python Terminal fails unless ipykernel is installed

[https://github.com/microsoft/vscode-python/issues/25922](https://github.com/microsoft/vscode-python/issues/25922)

## Summary

The reported failure remains traceable on current main: terminal creation throws the exact reported error whenever the Environments extension resolves an interpreter but cannot associate the file with a Python project. Route this integration bug to the terminal and environments areas.

## Change summary

Run Selection/Line cannot create a Python terminal for a fresh or loose Python file unless installing ipykernel happens to initialize the missing project state.

## Best solution

Allow terminal creation when the selected Python environment is resolved even if `getPythonProject(resource)` returns undefined, while continuing to use the project URI as the default working directory when a project exists.
