# Issue #25922 — Run Selection/Line in Python Terminal fails unless ipykernel is installed

[https://github.com/microsoft/vscode-python/issues/25922](https://github.com/microsoft/vscode-python/issues/25922)

## Summary

Still present on main: selection execution rejects terminal creation when the Environments API returns an interpreter but no Python project, matching the reported fresh-file failure. Route this environment-integration defect to the terminal and environments areas.

## Change summary

Run Selection/Line fails with “Invalid arguments to create terminal” for a fresh Python file until environment state is incidentally initialized.

## Best solution

Allow `ensureTerminalLegacy` to create a terminal whenever an environment is available; treat the Python project as an optional source for `cwd`, consistent with the newer run-in-terminal path.
