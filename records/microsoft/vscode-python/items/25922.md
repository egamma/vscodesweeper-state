# Issue #25922 — Run Selection/Line in Python Terminal fails unless ipykernel is installed

[https://github.com/microsoft/vscode-python/issues/25922](https://github.com/microsoft/vscode-python/issues/25922)

## Summary

The reported error remains reachable on main: terminal creation rejects a resolved environment whenever the Environments extension has not also returned a Python project. This should stay open and route to the terminal/environment integration owners.

## Change summary

Run Selection/Line fails on a fresh Python 3.14 installation until installing ipykernel causes the environment integration to initialize successfully.

## Best solution

Update the Environments-extension terminal path in src/client/envExt/api.legacy.ts to create the terminal when an environment is available even if no Python project is resolved, using an appropriate fallback working directory. The area owner should also determine why package installation changes project resolution.
