# Issue #12997 — launch.json "args" don't get passed to pytest unittests

[https://github.com/microsoft/vscode-python/issues/12997](https://github.com/microsoft/vscode-python/issues/12997)

## Summary

Verified duplicate: the open testing-configuration proposal explicitly includes this issue and covers separate arguments for debug versus run, discovery, and coverage. Consolidating there preserves this accepted request without splitting implementation discussion.

## Change summary

Allow test-specific launch.json arguments to reach pytest when debugging tests instead of always using the global python.testing.pytestArgs.

## Best solution

Implement separate run, discovery, debug, and coverage argument configurations under https://github.com/microsoft/vscode-python/issues/21845, including support for passing debug-only pytest flags from the selected test launch configuration.
