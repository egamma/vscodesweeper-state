# Issue #12997 — launch.json "args" don't get passed to pytest unittests

[https://github.com/microsoft/vscode-python/issues/12997](https://github.com/microsoft/vscode-python/issues/12997)

## Summary

This request is explicitly covered by the broader open testing-configuration proposal, which tracks separate arguments for running, discovery, debugging, and coverage. Consolidating there preserves the confirmed launch.json behavior and user scenarios in one design discussion.

## Change summary

Allow a debug-test launch configuration to supply pytest arguments independently from the global python.testing.pytestArgs setting.

## Best solution

Implement the debug-specific argument behavior as part of https://github.com/microsoft/vscode-python/issues/21845, defining clear merge or override semantics between test profiles and launch.json debug configurations.
