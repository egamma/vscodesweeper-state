# Issue #12997 — launch.json "args" don't get passed to pytest unittests

[https://github.com/microsoft/vscode-python/issues/12997](https://github.com/microsoft/vscode-python/issues/12997)

## Summary

Keep this accepted testing request open: current main still replaces launch.json test-debug arguments with arguments derived from python.testing.pytestArgs. The existing settings and standalone pytest launch configurations do not provide debug-specific arguments while retaining Test Explorer integration.

## Change summary

Allow Test Explorer debugging to pass framework arguments from its debug-test configuration independently of normal test runs and discovery.

## Best solution

Support debug-specific pytest arguments without changing normal run/discovery settings or losing Test Explorer results. Settle the argument-precedence contract in coordination with https://github.com/microsoft/vscode-python/issues/21845, while retaining this concrete request until that behavior is delivered.
