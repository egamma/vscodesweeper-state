# Issue #12997 — launch.json "args" don't get passed to pytest unittests

[https://github.com/microsoft/vscode-python/issues/12997](https://github.com/microsoft/vscode-python/issues/12997)

## Summary

Verified duplicate: the open testing-configuration proposal explicitly includes this issue and owns the broader requirement for separate pytest arguments across debug, run, discovery, and coverage.

## Change summary

Allow a debug-test launch configuration to pass its own arguments to pytest instead of replacing them with the global testing arguments.

## Best solution

Consolidate the design and implementation in https://github.com/microsoft/vscode-python/issues/21845, ensuring that debug-test configurations can provide arguments independently from normal test runs and discovery.
