# Issue #17776 — Jedi LS: "python.autoComplete.showAdvancedMembers" setting ignored

[https://github.com/microsoft/vscode-python/issues/17776](https://github.com/microsoft/vscode-python/issues/17776)

## Summary

This accepted feature request remains necessary: Jedi Language Server supports completion filtering, but current main neither exposes `python.autoComplete.showAdvancedMembers` nor passes an equivalent ignore pattern to Jedi. The existing `needs PR` and `area-intellisense` labels already classify and route the remaining integration work.

## Change summary

Allow Jedi users to hide advanced double-underscore completion members through a Python extension setting.

## Best solution

Expose a supported completion-filter setting for Jedi and translate the disabled advanced-members behavior into Jedi Language Server's `completion.ignorePatterns` initialization option in `src/client/activation/jedi/analysisOptions.ts`, with coverage for the generated initialization options.
