# Issue #17776 — Jedi LS: "python.autoComplete.showAdvancedMembers" setting ignored

[https://github.com/microsoft/vscode-python/issues/17776](https://github.com/microsoft/vscode-python/issues/17776)

## Summary

The upstream Jedi language server now supports completion filtering, but vscode-python does not pass that option through. This remains accepted work under `needs PR` and already has the correct area label.

## Change summary

Honor the advanced-members preference for Jedi completions by filtering names that begin with double underscores.

## Best solution

Map the intended advanced-member behavior to Jedi Language Server's `completion.ignorePatterns` initialization option in `src/client/activation/jedi/analysisOptions.ts`, with an appropriate supported configuration surface and coverage for both enabled and disabled behavior.
