[https://github.com/microsoft/vscode-python/issues/17776](https://github.com/microsoft/vscode-python/issues/17776)

## Summary

Keep open: Jedi now supports completion filtering, but the Python extension still does not expose or enable it. This is accepted work marked needs PR, not a request awaiting community traction.

## Change summary

Allow Jedi users to hide completion names beginning with __ when python.autoComplete.showAdvancedMembers is false.
