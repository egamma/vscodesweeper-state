[https://github.com/microsoft/vscode-python/issues/17776](https://github.com/microsoft/vscode-python/issues/17776)

## Summary

The accepted Jedi integration work remains incomplete on main. Jedi Language Server supports completion filtering, but this extension does not configure it; the existing `needs PR` label requires keeping the issue open.

## Change summary

Allow Jedi completions beginning with double underscores to be hidden according to the extension's completion configuration.

## Best solution
