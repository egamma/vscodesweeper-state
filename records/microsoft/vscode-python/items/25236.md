# Issue #25236 — Visualise/highlight lines with missing branch coverage

[https://github.com/microsoft/vscode-python/issues/25236](https://github.com/microsoft/vscode-python/issues/25236)

## Summary

The request remains necessary and has exceeded the documented community-feedback threshold with 27 upvotes. Current main reports aggregate branch counts but deliberately omits per-line branch details, so routing this accepted testing request to the testing area is appropriate.

## Change summary

Show a distinct editor gutter highlight for covered lines whose branches are only partially covered.

## Best solution

Extend the pytest and unittest coverage payloads with per-line branch execution details, then attach those details to the corresponding VS Code StatementCoverage entries in src/client/testing/testController/common/testCoverageHandler.ts so VS Code can render partial branch coverage.
