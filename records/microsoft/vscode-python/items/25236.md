# Issue #25236 — Visualise/highlight lines with missing branch coverage

[https://github.com/microsoft/vscode-python/issues/25236](https://github.com/microsoft/vscode-python/issues/25236)

## Summary

The requested distinction remains missing: current coverage details expose covered and missed lines, but not partially covered branches. Route to the testing area; 27 upvotes exceed the community-feedback threshold.

## Change summary

Visually distinguish executed lines with incomplete branch coverage from fully covered and unexecuted lines.

## Best solution

Expose line-associated branch coverage through the Python testing integration and coordinate with VS Code core on its visual presentation. Preserve existing statement highlights and aggregate coverage statistics.

- **Behavior:**

  > Users running Python tests with branch coverage should be able to locate executed lines whose branches are not fully exercised without generating an external report. - **Trace:**

Preserve behavior when branch collection is disabled and avoid unrelated coverage changes.
