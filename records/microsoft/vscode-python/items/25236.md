# Issue #25236 — Visualise/highlight lines with missing branch coverage

[https://github.com/microsoft/vscode-python/issues/25236](https://github.com/microsoft/vscode-python/issues/25236)

## Summary

The requested distinction remains missing: current Python coverage details report statement execution but omit per-line branch information. Route to the testing area; 27 upvotes exceed the community-feedback threshold, and no verified canonical covers this request.

## Change summary

Visually distinguish executed lines with incomplete branch coverage from fully covered and wholly uncovered lines.

## Best solution

Expose sufficient line-level branch information through Python's testing coverage integration so incomplete branches are identifiable in the editor. Coordinate with VS Code core on gutter presentation; file-level branch totals alone cannot deliver this request.
