# Issue #24578 — Test discovery failure / regression for uniitest

[https://github.com/microsoft/vscode-python/issues/24578](https://github.com/microsoft/vscode-python/issues/24578)

## Summary

The regression remains in current main: unittest discovery prepends the start directory's parent to sys.path, allowing project modules such as logging.py to shadow the standard library. The issue is already accepted with needs PR and correctly routed to area-testing.

## Change summary

Unittest discovery fails when a project module shadows a standard-library module because the adapter changes sys.path ordering.

## Best solution

Change unittest discovery and execution path setup in python_files/unittestadapter/discovery.py and execution.py so project imports work without placing a collision-prone relative directory ahead of the standard library, while preserving the behavior required by the earlier path fix.
