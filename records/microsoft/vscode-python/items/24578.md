# Issue #24578 — Test discovery failure / regression for uniitest

[https://github.com/microsoft/vscode-python/issues/24578](https://github.com/microsoft/vscode-python/issues/24578)

## Summary

Verified duplicate: the older open issue tracks the same unittest adapter sys.path ordering defect and now contains the reporter's identical logging.py traceback. Consolidating there preserves one accepted, actionable issue for the shared root cause.

## Change summary

Unittest discovery prepends a project subdirectory to sys.path, allowing a local logging.py module to shadow Python's standard-library logging module and break test imports.

## Best solution

Consolidate on https://github.com/microsoft/vscode-python/issues/23239 and correct sys.path construction in both unittest discovery and execution without reintroducing the parent-import failure fixed by https://github.com/microsoft/vscode-python/pull/23712.
