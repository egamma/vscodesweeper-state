# Issue #24578 — Test discovery failure / regression for uniitest

[https://github.com/microsoft/vscode-python/issues/24578](https://github.com/microsoft/vscode-python/issues/24578)

## Summary

Verified duplicate of the older open unittest sys.path issue, which now contains the same logging.py collision and current-release confirmation. Consolidating there preserves one accepted testing fix.

## Change summary

Unittest discovery prepends the test start directory's parent to sys.path, allowing project modules such as logging.py to shadow standard-library modules.

## Best solution

Track and fix this in https://github.com/microsoft/vscode-python/issues/23239 by aligning unittest discovery and execution paths with command-line unittest without breaking nested-module discovery.
