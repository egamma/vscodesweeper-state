# Issue #19971 — Adopt changes to enable test discovery before "run at cursor"

[https://github.com/microsoft/vscode-python/issues/19971](https://github.com/microsoft/vscode-python/issues/19971)

## Summary

Keep open: this team-authored, accepted work item still has `needs PR`, and current main does not establish the busy state early enough for VS Code's run-at-cursor synchronization.

## Change summary

Adapt Python test discovery so run-at-cursor waits for discovery triggered by saving the document.

## Best solution

In the testing controller, establish the relevant test item's busy state during `onWillSaveTextDocument`, then clear it only after save-triggered discovery completes, allowing VS Code core to wait before resolving the test at the cursor.
