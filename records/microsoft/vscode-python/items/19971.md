# Issue #19971 — Adopt changes to enable test discovery before "run at cursor"

[https://github.com/microsoft/vscode-python/issues/19971](https://github.com/microsoft/vscode-python/issues/19971)

## Summary

Keep this accepted, team-authored request open: current discovery-on-save does not establish the pre-save busy state required by VS Code's run-at-cursor synchronization. The existing testing-area label is appropriate; no qualifying fix or older canonical duplicate was found.

## Change summary

Coordinate Python test discovery with saving so Run Test at Cursor selects tests using refreshed locations rather than stale discovery data.

## Best solution

Complete the Python TestController lifecycle integration so VS Code can wait for save-triggered discovery before resolving the test at the cursor. Preserve automatic-discovery settings and cover both legacy workspace and project-based discovery lifecycles.
