# Issue #19971 — Adopt changes to enable test discovery before "run at cursor"

[https://github.com/microsoft/vscode-python/issues/19971](https://github.com/microsoft/vscode-python/issues/19971)

## Summary

This accepted testing work remains necessary on current main: discovery starts from an after-save listener, while VS Code's run-at-cursor flow requires the relevant test item to become busy during the before-save event. The team-authored issue also carries `needs PR`, so it must remain open.

## Change summary

Coordinate save-triggered Python test discovery with VS Code's Run Test at Cursor command by marking the affected test tree busy before the document is saved.

## Best solution

Update the testing controller's save-discovery lifecycle so `onWillSaveTextDocument` synchronously marks the relevant file or ancestor test item busy, then retain that state until the ensuing discovery completes or fails. This belongs in the testing controller around `watchForTestContentChangeOnSave` and the discovery completion path.
