# Issue #19971 — Adopt changes to enable test discovery before "run at cursor"

[https://github.com/microsoft/vscode-python/issues/19971](https://github.com/microsoft/vscode-python/issues/19971)

## Summary

Keep open as accepted testing work: current main still starts rediscovery after the document-save event, too late for VS Code's Run Test at Cursor command to wait on the test item's busy state. The team-authored issue also carries `needs PR`, which marks it as accepted work.

## Change summary

Adopt VS Code's test-controller save lifecycle so Run Test at Cursor waits for Python test rediscovery after saving an edited test file.

## Best solution

Update the testing controller's save lifecycle to mark the relevant test item busy before saving, trigger rediscovery, and clear the state only after refreshed test data is available, allowing VS Code's Run Test at Cursor command to wait correctly.
