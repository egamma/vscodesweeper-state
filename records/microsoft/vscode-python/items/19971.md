# Issue #19971 — Adopt changes to enable test discovery before "run at cursor"

[https://github.com/microsoft/vscode-python/issues/19971](https://github.com/microsoft/vscode-python/issues/19971)

## Summary

The accepted testing-lifecycle work remains necessary on current main: discovery begins after save, too late for VS Code's Run Test at Cursor busy-state handshake. The team-authored issue also carries `needs PR`, so it must remain open.

## Change summary

Mark affected tests busy before saving so Run Test at Cursor waits for Python test rediscovery before selecting and executing the test.

## Best solution

Update the testing controller's save lifecycle to mark the relevant test item busy during `onWillSaveTextDocument`, then clear it when post-save discovery completes, preserving the existing discovery setting and file pattern.
