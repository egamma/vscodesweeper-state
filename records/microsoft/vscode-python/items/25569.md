# Issue #25569 — .env file content isn't autoloaded into a terminal, despite coresponding settings being set.

[https://github.com/microsoft/vscode-python/issues/25569](https://github.com/microsoft/vscode-python/issues/25569)

## Summary

Terminal injection from .env files is intentionally opt-in through `python.terminal.useEnvFile`; the reported configuration omits that setting, and the reporter agrees the issue can be closed.

## Change summary

Automatically inject variables from `python.envFile` into new terminals when environment activation is enabled.

## Best solution

Keep terminal .env injection opt-in through `python.terminal.useEnvFile` in the Python Environments extension, avoiding unexpected workspace-variable injection.
