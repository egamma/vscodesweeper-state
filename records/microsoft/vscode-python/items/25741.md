# Issue #25741 — Run selection/line in python terminal seems to fail if selected too many characters

[https://github.com/microsoft/vscode-python/issues/25741](https://github.com/microsoft/vscode-python/issues/25741)

## Summary

Keep open: an independent reporter confirmed corruption of long selections on VS Code 1.108 and 1.109, with 1.107 working, and supplied the requested trace logs. Source inspection establishes the execution path but not a current-main fix or an eligible older canonical.

## Change summary

Running a long, indented Python selection through Shift+Enter corrupts the submitted code and causes syntax errors.

## Best solution

Make long selections execute without corruption in the classic terminal REPL, first isolating whether the failure occurs during normalization or downstream terminal input handling. If the regression belongs to VS Code's terminal implementation, a maintainer can transfer this to https://github.com/microsoft/vscode.
