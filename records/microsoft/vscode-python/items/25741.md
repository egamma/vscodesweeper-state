## Summary

This remains a confirmed macOS terminal-execution bug: multiple reporters reproduce large selections becoming malformed starting with VS Code 1.108, and current main still sends normalized selections through the terminal API. The existing terminal-area routing is appropriate while the shell-integration boundary is investigated.

## Change summary

Running a sufficiently large, indented Python selection with Shift+Enter on macOS corrupts the transmitted code and produces syntax or indentation errors.
