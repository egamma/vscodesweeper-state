# Issue #25741 — Run selection/line in python terminal seems to fail if selected too many characters

[https://github.com/microsoft/vscode-python/issues/25741](https://github.com/microsoft/vscode-python/issues/25741)

## Summary

The report matches a confirmed macOS terminal-input limitation around 1024-byte multiline writes, not a Python parser failure. Keep it open while a maintainer determines whether to transfer it to VS Code core; the existing core fix covered the terminal agent tool, not the extension API used here.

## Change summary

Large multiline Python selections become corrupted when sent to the integrated terminal on macOS.

## Best solution

VS Code's terminal API should safely transport multiline extension input beyond macOS's approximately 1024-byte boundary, or expose bracketed-paste semantics that this extension can use. A maintainer can transfer this to https://github.com/microsoft/vscode because the failure occurs below the Python extension's selection normalization.
