# Issue #25603 — Use env extension for execute selection

[https://github.com/microsoft/vscode-python/issues/25603](https://github.com/microsoft/vscode-python/issues/25603)

## Summary

The env-extension migration remains incomplete for Run Selection/Line: current main routes file execution through the environment extension but leaves selection execution on the legacy path. This team-authored, accepted work item should remain open.

## Change summary

Make Run Selection/Line use the environment selected by the Python Environments extension.

## Best solution

Add an environment-extension execution path for selection execution in src/client/terminals/codeExecution/codeExecutionManager.ts, while preserving the legacy path when the environments extension is disabled. Extend the code-execution unit tests to cover both paths.
