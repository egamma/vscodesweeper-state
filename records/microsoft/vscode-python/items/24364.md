  > An OS upgrade can replace system Python while leaving its executable paths unchanged. The reporter confirmed that Python: Clear Cache and Reload corrected the system version in https://github.com/microsoft/vscode-python/issues/24364#issuecomment-2450529501; this establishes a workaround, not automatic upgrade detection.
- **Reporter did not retest the upgrade:** In https://github.com/microsoft/vscode-python/issues/24364#issuecomment-3643708777, the reporter says Python has not changed again and offers to consider the issue resolved if the area has been reworked. Smooth operation after manual configuration does not verify the original upgrade trigger.
- **Current discovery paths:** src/client/pythonEnvironments/index.ts initialize() selects createEnvExtApi() when useEnvExtension() is enabled, otherwise createNativeEnvironmentsApi() for the native locator. src/client/pythonEnvironments/nativeAPI.ts NativePythonEnvironments.triggerRefresh(), addEnv(), and hasChanged() replace same-path entries and recognize version changes when PET supplies fresh metadata. src/client/envExt/envExtApi.ts delegates refresh and resolution to the sibling extension.
