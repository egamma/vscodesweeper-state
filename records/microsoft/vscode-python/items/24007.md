# Issue #24007 — Repl cwd doesn't change when extending to multi root workspace

[https://github.com/microsoft/vscode-python/issues/24007](https://github.com/microsoft/vscode-python/issues/24007)

## Summary

Still present on current main: an active native REPL retains the working directory chosen when its singleton was created and does not react when workspace folders change.

## Change summary

Adding a folder to a single-folder workspace leaves the existing native REPL bound to its original working directory without indicating that association.

## Best solution

Define the REPL lifecycle for workspace-folder changes in `src/client/repl/nativeRepl.ts`: either restart or reselect the working directory when the workspace becomes multi-root, or deliberately preserve the running process while clearly displaying its bound folder. Coordinate the UI portion with https://github.com/microsoft/vscode-python/issues/24011.
