# Issue #24007 — Repl cwd doesn't change when extending to multi root workspace

[https://github.com/microsoft/vscode-python/issues/24007](https://github.com/microsoft/vscode-python/issues/24007)

## Summary

Keep open: the native REPL still retains its launch directory when another workspace folder is added, without exposing that directory in its UI. The launch-time directory selection is deliberate, but the expected behavior for an existing session during workspace changes remains unsettled.

## Change summary

Clarify the native REPL's working-directory association when a single-folder workspace becomes multi-root.

## Best solution

Define the existing-session behavior in the core native REPL and make its directory association discoverable without unexpectedly resetting Python state. The maintainer decision is whether adding a workspace folder should preserve the directory with a visible indication or offer an explicit directory change.
