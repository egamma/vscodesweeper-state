# Issue #24007 — Repl cwd doesn't change when extending to multi root workspace

[https://github.com/microsoft/vscode-python/issues/24007](https://github.com/microsoft/vscode-python/issues/24007)

## Summary

Still present on current main: the native REPL captures its working directory only when its singleton is created and does not react when a single-folder workspace becomes multi-root.

## Change summary

Adding a second workspace folder leaves the existing native REPL silently tied to the original folder.

## Best solution

Handle workspace-folder changes in `src/client/repl/nativeRepl.ts`: when the workspace becomes multi-root, expose the REPL's current directory and let the user select a folder without silently retaining an ambiguous association.
