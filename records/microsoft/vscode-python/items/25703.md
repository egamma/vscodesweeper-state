# Issue #25703 — Add `ignoreFocusOut` setting for "Select Interpreter" Quick Pick

[https://github.com/microsoft/vscode-python/issues/25703](https://github.com/microsoft/vscode-python/issues/25703)

## Summary

The interpreter picker still unconditionally ignores focus loss, and no existing setting provides the requested mouse-only dismissal. Route to the environments area to decide the cancellation behavior while preserving the documented reason for keeping manual path entry open.

## Change summary

Allow users to dismiss Select Interpreter by clicking outside it, either by default or through a configurable focus-loss policy.

## Best solution

Provide mouse-only cancellation without changing the selected interpreter, while retaining a usable copy-and-paste workflow for manual interpreter paths. Decide whether this should be the default behavior or an opt-in setting; the earlier decision about manual path entry does not settle this request's accessibility and configurability scope.
