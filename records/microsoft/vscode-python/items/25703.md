# Issue #25703 — Add `ignoreFocusOut` setting for "Select Interpreter" Quick Pick

[https://github.com/microsoft/vscode-python/issues/25703](https://github.com/microsoft/vscode-python/issues/25703)

## Summary

The inconsistent focus behavior remains on main and lacks a user setting. Route this accessibility and interaction improvement to the editor area for design and implementation.

## Change summary

Allow the Select Interpreter Quick Pick to dismiss on focus loss while preserving focus where interpreter-path entry requires it.

## Best solution

Make `MultiStepInput.showQuickPick` accept per-step focus behavior, use the native `ignoreFocusOut: false` default for the initial interpreter picker, and retain `true` for the Enter Interpreter Path step if needed.
