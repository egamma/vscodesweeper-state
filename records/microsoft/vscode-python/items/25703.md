# Issue #25703 — Add `ignoreFocusOut` setting for "Select Interpreter" Quick Pick

[https://github.com/microsoft/vscode-python/issues/25703](https://github.com/microsoft/vscode-python/issues/25703)

## Summary

The unexpected behavior remains in current main: the shared multi-step input helper unconditionally prevents focus-out dismissal, and the interpreter picker cannot override it. Route this as an environment-selection bug rather than closing the reopened report.

## Change summary

Allow users to dismiss the Select Interpreter quick pick by clicking outside it, consistent with native VS Code quick picks.

## Best solution

Make the interpreter picker use native focus-out dismissal by default, while preserving the existing behavior for multi-step flows that require it; parameterize the shared helper if necessary rather than adding a user setting for behavior that the maintainer already identified as unexpected.
