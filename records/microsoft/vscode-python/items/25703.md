# Issue #25703 — Add `ignoreFocusOut` setting for "Select Interpreter" Quick Pick

[https://github.com/microsoft/vscode-python/issues/25703](https://github.com/microsoft/vscode-python/issues/25703)

## Summary

A real accessibility and consistency gap remains: the interpreter picker unconditionally stays open on focus loss, and no setting or per-picker option exists. Route this to the environment and user-facing UI owners.

## Change summary

Allow the Select Interpreter picker to be dismissed by clicking elsewhere, while preserving focus where multi-step text entry requires it.

## Best solution

Make `MultiStepInput.showQuickPick` accept a per-step `ignoreFocusOut` option and use `false` for the initial interpreter picker, while retaining `true` for the Enter Interpreter Path flow that requires focus persistence.
