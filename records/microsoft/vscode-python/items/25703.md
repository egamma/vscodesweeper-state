# Issue #25703 — Add `ignoreFocusOut` setting for "Select Interpreter" Quick Pick

[https://github.com/microsoft/vscode-python/issues/25703](https://github.com/microsoft/vscode-python/issues/25703)

## Summary

The interpreter picker still forces focus persistence on current main, and no contributed setting provides mouse-only cancellation. Route this accessibility request to area-environments for a decision on default behavior versus configurability.

## Change summary

Allow users to dismiss Select Interpreter by clicking outside it without changing the selected interpreter.

## Best solution

Provide mouse-only cancellation in the Python interpreter picker while preserving the selected environment. Decide whether focus-out dismissal should become the default or be configurable, without inadvertently changing unrelated multi-step prompts.
