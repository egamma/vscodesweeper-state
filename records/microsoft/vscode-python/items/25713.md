# Issue #25713 — Shift+enter to run Python: Run Selection/Line in Python Terminal not showing results immediately

[https://github.com/microsoft/vscode-python/issues/25713](https://github.com/microsoft/vscode-python/issues/25713)

## Summary

Keep open: the reporter confirmed the problem persists over Remote SSH, and another user reported the same command failing on Linux. The existing steps suffice to retest; the inspected source now includes REPL-readiness queuing, but neither a fix for delayed visibility nor a same-symptom canonical is established.

## Change summary

Shift+Enter sends Python code to the terminal, but the submitted line and its result become visible only after interacting with the interpreter.

## Best solution

Restore immediate visibility of submitted code and results without requiring terminal interaction, including over Remote SSH. First distinguish delayed rendering after execution from code waiting for submission, then establish whether the remaining defect belongs in core terminal integration, the Python Environments extension, or VS Code's terminal.
