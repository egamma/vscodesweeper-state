# Issue #25822 — After latest update: Testing tree of python tests reloads completely rather than just update

[https://github.com/microsoft/vscode-python/issues/25822](https://github.com/microsoft/vscode-python/issues/25822)

## Summary

The regression remains confirmed across Linux and Windows, and current main still rebuilds test items after save-triggered discovery. This issue is the designated implementation item for incremental tree updates in the open testing reliability workstream.

## Change summary

Saving a Python file triggers full discovery and replaces the Python test tree, temporarily preventing test reruns and debugging.

## Best solution

Update the testing controller to diff each discovery result against the existing tree and insert, update, or remove only changed items while preserving stable TestItem instances. The narrower save-pattern work can reduce unnecessary discovery but does not replace this incremental-update fix.
