# Issue #25822 — After latest update: Testing tree of python tests reloads completely rather than just update

[https://github.com/microsoft/vscode-python/issues/25822](https://github.com/microsoft/vscode-python/issues/25822)

## Summary

Still present on current main: save-triggered discovery removes the existing project test items before asynchronous discovery rebuilds the tree, temporarily preventing rerun and debug operations. The issue already has the correct testing-area label and should remain open as distinct implementation work.

## Change summary

Saving a Python file clears and reconstructs the entire Python test tree instead of applying incremental changes.

## Best solution

Preserve the existing test tree while discovery runs, then diff the discovery payload against indexed test items and insert, update, or remove only changed nodes. Narrowing the save pattern in https://github.com/microsoft/vscode-python/issues/25866 is a useful mitigation for non-test files but does not replace incremental updates when discovery is legitimately triggered.
