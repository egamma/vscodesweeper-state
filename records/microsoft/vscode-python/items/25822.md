[https://github.com/microsoft/vscode-python/issues/25822](https://github.com/microsoft/vscode-python/issues/25822)

## Summary

Keep open: current source deletes project test roots before rediscovery and recreates test items when results arrive, matching the reported disappearance and temporary inability to rerun tests. The related workstream explicitly tracks this issue as unfinished child work, not a duplicate.

## Change summary

Saving a Python file clears and rebuilds the test tree instead of preserving existing tests while discovery updates it.

## Best solution

Preserve unchanged test items and their execution mappings throughout automatic rediscovery, applying additions, removals and metadata changes when discovery completes. Address project-adapter lifecycle and shared tree population together; narrowing discovery triggers alone does not fix the disappearing tree.
