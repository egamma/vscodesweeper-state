# Issue #25822 — After latest update: Testing tree of python tests reloads completely rather than just update

[https://github.com/microsoft/vscode-python/issues/25822](https://github.com/microsoft/vscode-python/issues/25822)

## Summary

Still present on current main: save-triggered project discovery removes the existing test items before rebuilding them, temporarily preventing test reruns and debugging. The testing workstream explicitly retains this issue for incremental tree updates.

## Change summary

Saving a Python file causes the entire Python test tree to disappear and rebuild instead of updating incrementally.

## Best solution

Preserve the current test tree while discovery runs, then diff the discovered tree against existing TestItems and apply only additions, removals, and updates in the testing controller. The separate trigger-scope problem should remain tracked by https://github.com/microsoft/vscode-python/issues/25866.
