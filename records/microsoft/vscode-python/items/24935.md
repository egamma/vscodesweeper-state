# Issue #24935 — Test Explorer is not reporting test status if a test is annotated with xdist_group

[https://github.com/microsoft/vscode-python/issues/24935](https://github.com/microsoft/vscode-python/issues/24935)

## Summary

The bug remains actionable and correctly triaged with `area-testing` and `needs PR`. Maintainer investigation confirmed the issue, another user independently reproduced it, and current `main` still maps execution results using the xdist-modified node ID.

## Change summary

Tests assigned an `xdist_group` under `--dist=loadgroup` execute but do not receive passed, failed, or skipped status in Test Explorer.

## Best solution

Normalize the execution node ID emitted by pytest-xdist's `loadgroup` mode back to the discovery ID before sending the result, while preserving legitimate `@` characters in test parameters. Add an adapter test covering an `xdist_group` test executed with `-n1 --dist=loadgroup` and assert that its result resolves to the discovered Test Explorer item.
