# Issue #24935 — Test Explorer is not reporting test status if a test is annotated with xdist_group

[https://github.com/microsoft/vscode-python/issues/24935](https://github.com/microsoft/vscode-python/issues/24935)

## Summary

The bug remains source-reproducible on current main and has already been accepted with `needs PR`; xdist's group suffix prevents the execution result from matching the discovered TestItem.

## Change summary

Tests marked with `xdist_group` do not receive pass, fail, or skipped status in Test Explorer when run with `--dist=loadgroup`.

## Best solution

Normalize xdist load-group execution IDs to their discovery IDs in `python_files/vscode_pytest/__init__.py` before emitting results, with coverage proving grouped tests map to the correct TestItems without altering legitimate parameterized IDs.
