# Issue #24935 — Test Explorer is not reporting test status if a test is annotated with xdist_group

[https://github.com/microsoft/vscode-python/issues/24935](https://github.com/microsoft/vscode-python/issues/24935)

## Summary

Confirmed testing bug that remains accepted for implementation: maintainers identified the issue, another user independently confirmed it, and the current `needs PR` label requires keeping it open.

## Change summary

Report pytest results in Test Explorer when tests use `xdist_group` with the `loadgroup` distribution mode.

## Best solution

Update the pytest adapter's xdist result handling so reports from grouped worker processes reach the Test Explorer result pipe and the listener remains active until all worker results are consumed.
