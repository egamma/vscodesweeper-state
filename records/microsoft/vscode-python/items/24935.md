# Issue #24935 — Test Explorer is not reporting test status if a test is annotated with xdist_group

[https://github.com/microsoft/vscode-python/issues/24935](https://github.com/microsoft/vscode-python/issues/24935)

## Summary

Keep open: the current result-mapping path cannot match loadgroup-suffixed execution IDs to discovered tests with released pytest-xdist 3.8.0. The team acknowledged the defect and marked it needs PR; older matching reports are closed, and a recent upstream change does not establish that this report is resolved.

## Change summary

Tests marked with xdist_group execute with -n1 --dist=loadgroup but do not receive pass, fail, or skipped status in Test Explorer.

## Best solution

Ensure grouped pytest execution results update the originally discovered TestItems without changing xdist scheduling or test identity. Account for the recent upstream node-ID change while retaining compatibility with released pytest-xdist versions.
