[https://github.com/microsoft/vscode-python/issues/25710](https://github.com/microsoft/vscode-python/issues/25710)

## Summary

The failure is confirmed, but the evidence identifies invalid position-encoding serialization in the bundled pygls/lsprotocol stack rather than a vscode-python client defect. Dependency-owned issues remain open while the upstream fix is pursued.

## Change summary

Jedi fails to initialize because its server reports the enum name instead of the LSP-required "utf-16" position-encoding value.

## Best solution
