# Issue #25710 — Jedi LSP error: Unsupported position encoding (PositionEncodingKind.Utf16) in VSCodium

[https://github.com/microsoft/vscode-python/issues/25710](https://github.com/microsoft/vscode-python/issues/25710)

## Summary

The confirmed failure originates in the bundled Jedi/pygls/lsprotocol dependency stack serializing an invalid LSP position-encoding value. Keep this open to track consuming the upstream fix rather than weakening the client’s protocol validation.

## Change summary

Jedi language features repeatedly fail to start because the server reports PositionEncodingKind.Utf16 instead of the LSP value utf-16.

## Best solution

Fix the capability serialization in the Jedi language-server dependency stack, then update vscode-python’s bundled Jedi requirements to a corrected release. Track the upstream work at https://github.com/pappasam/jedi-language-server/issues/351.
