# Issue #25710 — Jedi LSP error: Unsupported position encoding (PositionEncodingKind.Utf16) in VSCodium

[https://github.com/microsoft/vscode-python/issues/25710](https://github.com/microsoft/vscode-python/issues/25710)

## Summary

Keep open as an upstream serialization defect, not a request to support another encoding. The investigation confirms that the server sends an enum name instead of "utf-16"; no adopted upstream fix has been established.

## Change summary

Jedi initialization fails because server capabilities serialize UTF-16 as "PositionEncodingKind.Utf16" instead of the required "utf-16".

## Best solution

Resolve enum serialization in the Jedi server's pygls/lsprotocol/cattrs stack, then adopt the verified upstream fix in the bundled Jedi dependencies. Preserve the client's protocol validation rather than accepting malformed encoding names.
