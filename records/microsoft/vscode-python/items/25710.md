# Issue #25710 — Jedi LSP error: Unsupported position encoding (PositionEncodingKind.Utf16) in VSCodium

[https://github.com/microsoft/vscode-python/issues/25710](https://github.com/microsoft/vscode-python/issues/25710)

## Summary

The discussion traces this to the bundled pygls/lsprotocol serialization path rather than the Python extension's LSP client: the server sends an enum representation instead of the required "utf-16" value. The upstream report remains open and current main still bundles the implicated dependency versions, so this should remain open and route to the IntelliSense area for dependency coordination.

## Change summary

Prevent the bundled Jedi language server from advertising PositionEncodingKind.Utf16 as an invalid wire value that causes the language client to reject initialization.

## Best solution

Fix the enum serialization in the Jedi language server's pygls/lsprotocol dependency stack, then update the bundled Jedi requirements in python_files/jedilsp_requirements so the server emits the LSP-compliant "utf-16" value.
