# Issue #17112 — pytest assertions should generate rich diffs

[https://github.com/microsoft/vscode-python/issues/17112](https://github.com/microsoft/vscode-python/issues/17112)

## Summary

This remains accepted, team-authored testing work with substantial community interest. Current main still sends pytest failures as plain text rather than supplying the structured expected and actual values required for VS Code's native diff view.

## Change summary

Represent pytest assertion failures with VS Code's native rich diff UI instead of only displaying pytest's textual failure output.

## Best solution

Extend the pytest execution payload to preserve structured expected and actual assertion values, then create `TestMessage.diff` messages in the testing result handler while retaining the traceback and useful pytest diagnostics. The existing `needs proposal` state appropriately reflects the required design work around extracting structured values reliably from pytest reports.
