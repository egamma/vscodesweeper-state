# Issue #17112 — pytest assertions should generate rich diffs

[https://github.com/microsoft/vscode-python/issues/17112](https://github.com/microsoft/vscode-python/issues/17112)

## Summary

The accepted testing feature remains unimplemented on current main: pytest failures are still passed to VS Code as plain text rather than native expected/actual diffs. The team-authored issue also carries `needs proposal`, which protects it from a judgment or staleness close.

## Change summary

Render pytest assertion failures with VS Code's native rich diff experience instead of only showing plain or truncated traceback text.

## Best solution

Extend the pytest execution payload to preserve expected and actual assertion values, then construct a native diff-capable `TestMessage` in `src/client/testing/testController/common/testExecutionHandler.ts`, while retaining the complete pytest output for assertions that cannot be parsed safely.
