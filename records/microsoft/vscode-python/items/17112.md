# Issue #17112 — pytest assertions should generate rich diffs

[https://github.com/microsoft/vscode-python/issues/17112](https://github.com/microsoft/vscode-python/issues/17112)

## Summary

A real rich-diff gap remains on main. This team-authored, accepted feature request should stay open in the testing area.

## Change summary

Render pytest assertion failures with VS Code's native structured diff experience instead of plain traceback text.

## Best solution

Extend the pytest result payload in python_files/vscode_pytest/__init__.py with structured expected and actual values, then create a native diff-capable TestMessage in src/client/testing/testController/common/testExecutionHandler.ts while preserving complete pytest output.
