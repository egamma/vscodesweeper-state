# Issue #17112 — pytest assertions should generate rich diffs

[https://github.com/microsoft/vscode-python/issues/17112](https://github.com/microsoft/vscode-python/issues/17112)

## Summary

This accepted, team-authored testing request remains necessary: current main still presents pytest failures as plain text rather than native rich diffs. It should remain open for the proposal already requested.

## Change summary

Represent pytest assertion failures with VS Code's native expected-versus-actual rich diff experience.

## Best solution

Extend the pytest execution payload to carry structured expected and actual assertion values, then construct a native diff TestMessage in the testing controller while retaining the traceback as supporting output. The proposal should define parsing behavior and graceful handling for assertion forms that pytest cannot represent as a two-sided diff.
