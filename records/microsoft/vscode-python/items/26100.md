# Issue #26100 — Conda environments disappear when ms-python.vscode-python-envs is enabled

[https://github.com/microsoft/vscode-python/issues/26100](https://github.com/microsoft/vscode-python/issues/26100)

## Summary

The reported invalid version no-python failure is fixed on current main and in Python extension 2026.6.0. The compatibility adapter now skips non-Python Conda entries without losing subsequent valid environments, so this can be closed as completed.

## Change summary

Enabling Python Environments causes valid Conda environments to disappear from interpreter and notebook kernel selection when environment conversion encounters no-python.

## Best solution

Keep the adapter fix in e0f1d3c80da21e0246b007990f6513fed9017080, shipped in 2026.6.0, so valid Conda interpreters remain available without requiring Python installation in unrelated Conda environments.
