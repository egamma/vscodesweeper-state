# Issue #26100 — Conda environments disappear when ms-python.vscode-python-envs is enabled

[https://github.com/microsoft/vscode-python/issues/26100](https://github.com/microsoft/vscode-python/issues/26100)

## Summary

Still present on main: the Python Environments extension represents Conda environments without Python using version `no-python`, but vscode-python parses every environment version as numeric and throws. Route this confirmed integration defect to environments.

## Change summary

Enabling the Python Environments extension causes valid Conda environments to disappear from interpreter and notebook kernel pickers when a no-Python Conda environment is discovered.

## Best solution

Handle the `no-python` sentinel explicitly in `src/client/envExt/envExtApi.ts` and isolate conversion failures per environment, so one non-Python Conda environment cannot abort delivery of the remaining discovered interpreters.
