# Issue #26100 — Conda environments disappear when ms-python.vscode-python-envs is enabled

[https://github.com/microsoft/vscode-python/issues/26100](https://github.com/microsoft/vscode-python/issues/26100)

## Summary

Verified cross-repo duplicate: the Python Environments tracker already has an open report for environments containing the `no-python` sentinel disappearing from interpreter consumers.

## Change summary

Enabling Python Environments causes non-base Conda environments to disappear from interpreter and notebook-kernel selectors.

## Best solution

Consolidate on https://github.com/microsoft/vscode-python-environments/issues/1681 and make the environment handoff tolerate the `no-python` sentinel rather than aborting conversion, restoring environments to both selectors.
