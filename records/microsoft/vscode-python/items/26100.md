# Issue #26100 — Conda environments disappear when ms-python.vscode-python-envs is enabled

[https://github.com/microsoft/vscode-python/issues/26100](https://github.com/microsoft/vscode-python/issues/26100)

## Summary

Fixed on main: the compatibility adapter now skips Conda environments without Python and isolates conversion failures, preventing an `invalid version no-python` entry from hiding the remaining valid environments.

## Change summary

Enabling the Python Environments extension causes valid Conda environments to disappear from interpreter and notebook kernel selectors when discovery includes a no-Python Conda environment.

## Best solution

Keep the fix merged in https://github.com/microsoft/vscode-python/pull/26112 and ship it in the next Python extension release; no additional code change is currently needed.
