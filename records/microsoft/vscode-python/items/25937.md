# Issue #25937 — Run Selection in Terminal is broken on macOS

[https://github.com/microsoft/vscode-python/issues/25937](https://github.com/microsoft/vscode-python/issues/25937)

## Summary

The detailed macOS reproduction shows large Shift-Enter selections becoming interleaved and syntactically corrupted when Python terminal shell integration is enabled. The current execution path still sends the complete normalized selection through the terminal REPL, so this remains actionable terminal/REPL work.

## Change summary

Large multiline selections sent to the terminal REPL on macOS are corrupted and produce indentation errors when python.terminal.shellIntegration.enabled is enabled.

## Best solution

Make multiline terminal-REPL submission atomic and reliable on macOS when Python shell integration is active, without regressing short selections or other platforms. The terminal and REPL owners should determine whether the fix belongs in input framing, bracketed-paste handling, or the Python startup integration.
