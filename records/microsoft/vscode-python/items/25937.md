# Issue #25937 — Run Selection in Terminal is broken on macOS

Verified duplicate: the open canonical issue already tracks large selections becoming corrupted and producing syntax errors when sent to the Python terminal on macOS.

## Change summary

Large Python selections sent with Shift+Enter are corrupted on macOS when Python terminal shell integration is enabled.

## Best solution

Consolidate the fix in https://github.com/microsoft/vscode-python/issues/25741, carrying over this report's finding that disabling `python.terminal.shellIntegration.enabled` prevents the corruption.
