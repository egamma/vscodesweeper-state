# Issue #23523 — Support interrupt for Python REPL-Windows

[https://github.com/microsoft/vscode-python/issues/23523](https://github.com/microsoft/vscode-python/issues/23523)

## Summary

The Windows interrupt gap remains explicit in current main, and this team-authored REPL work item must stay open. The existing handler still relies solely on SIGINT and documents that it works only on macOS and Linux.

## Change summary

Allow users on Windows, and potentially Windows-hosted WSL sessions, to interrupt code executing in the native Python REPL.

## Best solution

Add a Windows-compatible interruption mechanism in `src/client/repl/pythonServer.ts` while preserving the existing POSIX SIGINT path, then determine whether the reported WSL behavior needs separate handling.
