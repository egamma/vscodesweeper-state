# Issue #23523 — Support interrupt for Python REPL-Windows

[https://github.com/microsoft/vscode-python/issues/23523](https://github.com/microsoft/vscode-python/issues/23523)

## Summary

Windows interrupt support remains missing from the native REPL's current implementation. Keep this team-authored request open: the existing interrupt path explicitly supports only macOS and Linux, and no verified canonical or referencing fix was found.

## Change summary

Support interrupting running code in the native Python REPL on Windows.

## Best solution

Provide Windows-native interruption in the core extension's REPL execution path so users can stop running code and continue using the same session without losing its variables. Assess the WSL comment separately, since a Linux-hosted interpreter may follow a different signal path.
