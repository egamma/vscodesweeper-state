# Issue #24850 — API for Alternate Python Language Servers

[https://github.com/microsoft/vscode-python/issues/24850](https://github.com/microsoft/vscode-python/issues/24850)

## Summary

The generic API remains unimplemented: current main special-cases Pyrefly rather than exposing a registration surface for alternate language servers. The accepted `needs proposal` and `needs spike` labels require keeping this open; route it to the API area.

## Change summary

Expose an API through which alternate Python language-server extensions can integrate without modifying user settings.

## Best solution

Define a public registration API that lets a language-server extension suppress the built-in service and integrate with the selected Python environment without hard-coded extension IDs. The proposal should generalize the existing Pyrefly-specific behavior.
