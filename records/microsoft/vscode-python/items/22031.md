# Issue #22031 — Fix assumption that macOS filesystem is case sensitive

[https://github.com/microsoft/vscode-python/issues/22031](https://github.com/microsoft/vscode-python/issues/22031)

## Summary

The accepted bug remains present on current main: shared and legacy environment path normalization still folds case only on Windows, so differently-cased paths on default macOS filesystems can remain distinct.

## Change summary

Correct filesystem path comparisons and environment IDs that incorrectly treat all macOS paths as case-sensitive.

## Best solution

Centralize filesystem-aware path comparison so default case-insensitive macOS volumes deduplicate equivalent paths without breaking case-sensitive volumes, then migrate affected environment IDs and invalidate the legacy cache.
