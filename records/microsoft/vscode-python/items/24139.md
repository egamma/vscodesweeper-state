## Summary

The requested command-palette cleanup remains necessary on current main. This is a team-authored debt item with appropriate terminal and REPL routing, and both attempted implementation PRs were closed without merging.

## Change summary

Hide the terminal and Django-shell Run Selection/Line commands from the command palette while preserving the intended editor context-menu workflow.
