# Issue #24461 — Use error mime type for error that cause cell execution failure in native repl

[https://github.com/microsoft/vscode-python/issues/24461](https://github.com/microsoft/vscode-python/issues/24461)

## Summary

The requested structured error output remains missing on current main, and the REPL controller explicitly records it as future work. This team-authored feature request should remain open in the REPL area.

## Change summary

Emit failed native REPL cell executions using VS Code's structured notebook error output instead of plain-text output.

## Best solution

Preserve structured exception details across the Python server protocol and have src/client/repl/replController.ts emit NotebookCellOutputItem.error for unsuccessful executions, while retaining text output for successful results.
