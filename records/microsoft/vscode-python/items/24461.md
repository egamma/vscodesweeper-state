# Issue #24461 — Use error mime type for error that cause cell execution failure in native repl

[https://github.com/microsoft/vscode-python/issues/24461](https://github.com/microsoft/vscode-python/issues/24461)

## Summary

The structured-error capability remains missing on current main: failed native REPL executions are still rendered as text/plain. This team-authored, correctly routed request should remain open.

## Change summary

Render native REPL execution failures with VS Code's structured notebook error MIME type.

## Best solution

Extend the native REPL execution result to preserve structured exception details, then emit NotebookCellOutputItem.error for failed executions in src/client/repl/replController.ts while retaining text output for successful results.
