# Issue #24461 — Use error mime type for error that cause cell execution failure in native repl

[https://github.com/microsoft/vscode-python/issues/24461](https://github.com/microsoft/vscode-python/issues/24461)

## Summary

Keep open: native REPL execution failures still produce plain-text output rather than structured error output. This team-authored request already has the correct area label, and neither implementation nor a qualifying duplicate was established.

## Change summary

Represent native REPL cell execution failures with the notebook error MIME type so accessibility, rendering, and assistance features can recognize structured errors.

## Best solution

Native REPL failures should expose structured exception information through notebook error output while preserving ordinary printed output and existing execution-status behavior. The relevant boundary is the Python execution server, its TypeScript response contract, and the REPL notebook controller.
