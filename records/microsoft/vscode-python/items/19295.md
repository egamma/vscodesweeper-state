# Issue #19295 — Add telemetry for which language server is being used on Python notebooks

[https://github.com/microsoft/vscode-python/issues/19295](https://github.com/microsoft/vscode-python/issues/19295)

## Summary

This accepted, team-authored telemetry debt remains necessary: current main distinguishes Pylance and Jedi startup telemetry but does not associate the actual server with notebook usage. The existing `needs PR` state and hard keep-open rule both apply.

## Change summary

Record which language server actually handles Python notebooks so telemetry analysis does not require unreliable session joins.

## Best solution

Emit notebook-associated telemetry from the Python extension after actual language-server selection and fallback, identifying Pylance, Jedi, or none without relying solely on the configured setting.
