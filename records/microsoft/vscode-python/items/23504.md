# Issue #23504 — Broken/Removed virtual environment can not be cleared

[https://github.com/microsoft/vscode-python/issues/23504](https://github.com/microsoft/vscode-python/issues/23504)

## Summary

The stale active interpreter can survive cache clearing and repeatedly trigger resolution errors after its executable is deleted. This accepted investigation already has the correct native-locator routing and should remain open.

## Change summary

Remove or safely invalidate a selected virtual environment after its directory has been deleted.

## Best solution

When the active interpreter executable disappears, clear or replace its persisted selection and cached metadata rather than repeatedly attempting resolution. The investigation should cover both the legacy locator and current environment-extension integration.
