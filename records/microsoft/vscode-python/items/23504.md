# Issue #23504 — Broken/Removed virtual environment can not be cleared

[https://github.com/microsoft/vscode-python/issues/23504](https://github.com/microsoft/vscode-python/issues/23504)

## Summary

The stale active-environment path remains possible on current main: environment removal updates discovery state without resetting the selected interpreter, while clearing caches does not clear that configured path. Maintainers already accepted this for a spike, so it should remain open.

## Change summary

Removing the selected virtual environment leaves its nonexistent interpreter active and repeatedly logged, with no effective way to clear it.

## Best solution

When the selected environment disappears or becomes unresolvable, reset or prompt for the active interpreter rather than continuing to execute its stale path. The spike should cover both legacy/native discovery and the Python Environments extension integration boundary.
