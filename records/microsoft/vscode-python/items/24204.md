This is a request to broaden default sync exclusions, not an established defect in the existing machine-scoped settings.

## Change summary

Exclude Python path-valued settings from Settings Sync by declaring ignoreSync metadata.

## Best solution

Retain existing machine-scope exclusions and close this broader default-exclusion proposal under the expired community-feedback criteria. Users can exclude additional machine-specific values through settingsSync.ignoredSettings without changing defaults for portable relative paths.
