# Issue #24565 — Python >= 3.13 Attempt to execute all the commands sent, without requiring manual 'Enter' keypress

[https://github.com/microsoft/vscode-python/issues/24565](https://github.com/microsoft/vscode-python/issues/24565)

## Summary

The Python 3.13+ terminal path still removes normalized trailing newlines on current main, leaving multiline submissions waiting for manual Enter. This team-authored, accepted issue should remain open for a replacement implementation because its fixing PR was closed without merging.

## Change summary

Make Run Selection/Line fully execute multiline code in Python 3.13+ terminal REPLs without manual Enter keypresses.

## Best solution

Preserve the trailing newlines produced by normalizeSelection.py when wrapping Python 3.13+ terminal input in bracketed-paste markers, with regression coverage for multiline blocks. Rework or supersede the unmerged implementation from https://github.com/microsoft/vscode-python/pull/25157.
