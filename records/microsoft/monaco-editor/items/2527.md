# Issue #2527 — Syntax Highlighting isn't working for the first item inside a Media Query

[https://github.com/microsoft/monaco-editor/issues/2527](https://github.com/microsoft/monaco-editor/issues/2527)

## Summary

The CSS Monarch grammar still mishandles media-query blocks on current main: `@media` has no dedicated tokenizer rule, so its block enters `selectorbody` and the first nested selector is not tokenized as a selector. The issue is already correctly routed to `grammars` and remains suitable for a community contribution.

## Change summary

Correct CSS syntax highlighting for media-query preludes and the first selector inside each media-query block.

## Best solution

Add a dedicated `@media` tokenizer state in `src/languages/definitions/css/css.ts` that tokenizes the at-rule and condition before returning to selector parsing inside the block, with regression coverage in `src/languages/definitions/css/css.test.ts`. This remains appropriate `open for PR` work.
