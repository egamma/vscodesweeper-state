# Issue #2742 — Font Icons not loading after upgrading css-loader version to 6.0.0

[https://github.com/microsoft/monaco-editor/issues/2742](https://github.com/microsoft/monaco-editor/issues/2742)

## Summary

Keep open: the plugin README now documents Webpack 5 asset modules, but the integration guide and samples still use file-loader, with samples avoiding the failure by retaining css-loader 5. The reported upgrade and corrupted-font output provide sufficient steps to retest; current behavior was not executed.

## Change summary

Upgrading to css-loader 6 causes the icon font URL to resolve to emitted JavaScript instead of valid font bytes.

## Best solution

Make the Webpack 5 samples and integration documentation consistently support css-loader 6 font loading, while preserving the plugin's advertised Webpack 4 compatibility. The merged downgrade restores older samples but does not satisfy the reporter's upgrade scenario.
