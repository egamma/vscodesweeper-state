The reporter's exclusive-provider pattern is now present in the published API, and current VS Code source shows it suppresses the default detector for matching languages. Keep open because no independent qualifying implementation commit was established after the prior fix claim was refuted.

## Change summary

Allow an embedder to disable built-in URL detection for a language while retaining its own link provider.
