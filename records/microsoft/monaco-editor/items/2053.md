# Issue #2053 — Disable built-in link provided

[https://github.com/microsoft/monaco-editor/issues/2053](https://github.com/microsoft/monaco-editor/issues/2053)

## Summary

The requested per-language replacement is now supported, including TypeScript declarations: register the custom link provider with an exclusive language selector. This addresses the reporter's workaround without disabling their own provider.

## Change summary

Allow disabling built-in link detection for a language while retaining a custom link provider.

## Best solution

Use monaco.languages.registerLinkProvider({ language: config.id, exclusive: true }, data.providers.links). Preserve links-enabled rendering; links: false disables custom providers too.
