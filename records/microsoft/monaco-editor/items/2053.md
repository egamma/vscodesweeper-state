# Issue #2053 — Disable built-in link provided

[https://github.com/microsoft/monaco-editor/issues/2053](https://github.com/microsoft/monaco-editor/issues/2053)

## Summary

The current public API already covers both requested cases: `links: false` disables all link detection, while an exclusive language-specific provider replaces the built-in provider for matching models.

## Change summary

Allow embedders to disable Monaco's built-in link provider globally or for a particular language.

## Best solution

Keep the existing APIs: use the `links` editor option for global disabling, or register the custom provider with `{ language: id, exclusive: true }` to suppress other providers only for that language.
