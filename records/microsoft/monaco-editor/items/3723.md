# Issue #3723 — [Bug] Code actions tooltip "Ctrl + Enter" to preview is not functional

[https://github.com/microsoft/monaco-editor/issues/3723](https://github.com/microsoft/monaco-editor/issues/3723)

## Summary

Fixed upstream and shipped in Monaco v0.44.0: code actions without edits no longer advertise the unavailable preview command.

## Change summary

The code-action tooltip incorrectly offered Ctrl+Enter preview for an action with nothing to preview.

## Best solution

Keep the shipped preview-capability check from the VS Code editor core; no additional Monaco change is needed.
