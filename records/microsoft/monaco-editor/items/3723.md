# Issue #3723 — [Bug] Code actions tooltip "Ctrl + Enter" to preview is not functional

[https://github.com/microsoft/monaco-editor/issues/3723](https://github.com/microsoft/monaco-editor/issues/3723)

## Summary

The misleading preview tooltip remains supported by the current source: code actions advertise preview even though Monaco's standalone bulk-edit service ignores the preview request and applies the edit. Keep this accepted bug open; the correction belongs in the VS Code sources Monaco bundles.

## Change summary

Code-action tooltips advertise Ctrl+Enter to preview, but the shortcut applies the action instead.

## Best solution

Make the code-action tooltip respect the standalone service's lack of preview support, preserving ordinary Enter-to-apply behavior. The change belongs in microsoft/vscode's shared code-action UI and should flow into Monaco through a subsequent editor-core update.
