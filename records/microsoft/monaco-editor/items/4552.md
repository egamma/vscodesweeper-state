# Issue #4552 — [Bug]-Did the monaco editor suggestWidget support fixed positioning, where the position was set dynamically following the cursor move

[https://github.com/microsoft/monaco-editor/issues/4552](https://github.com/microsoft/monaco-editor/issues/4552)

## Summary

Fixed positioning for suggestions is already supported through fixedOverflowWidgets: true. This report asks how to enable that behavior and does not describe a failure with the option enabled.

## Change summary

Display cursor-anchored suggestions using fixed positioning so an overflow:hidden ancestor does not clip them.

## Best solution

Enable fixedOverflowWidgets: true when creating the editor and retain the existing cursor-anchored suggestion layout; no new positioning API is needed for the stated scenario.

  > Thanks for the report. Monaco already supports this: pass `fixedOverflowWidgets: true` in the options to `monaco.editor.create(...)`. This renders the suggestion content widget with fixed positioning while retaining its cursor-based placement; the default is false. The described request is therefore an existing configuration capability rather than a missing feature.
