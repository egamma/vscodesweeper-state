# Issue #4552 — [Bug]-Did the monaco editor suggestWidget support fixed positioning, where the position was set dynamically following the cursor move

[https://github.com/microsoft/monaco-editor/issues/4552](https://github.com/microsoft/monaco-editor/issues/4552)

## Summary

The requested behavior already exists through the `fixedOverflowWidgets` editor option, which renders overflowing content widgets such as the suggestion widget using fixed positioning.

## Change summary

Allow the suggestion widget to escape an overflow-hidden editor container by positioning it relative to the viewport.

## Best solution

Configure the editor with `{ fixedOverflowWidgets: true }`; no Monaco change is needed for the requested fixed-position behavior.
