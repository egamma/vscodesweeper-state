# Issue #2521 — Can't override default autocomplete suggestions

[https://github.com/microsoft/monaco-editor/issues/2521](https://github.com/microsoft/monaco-editor/issues/2521)

## Summary

Implemented and shipped: JavaScript and TypeScript defaults can now disable the built-in completion provider, allowing a custom provider to replace it without duplicate suggestions.

## Change summary

Allow embedders to replace the built-in JavaScript or TypeScript autocomplete provider with custom suggestions.

## Best solution

Use `javascriptDefaults.setModeConfiguration({ ...javascriptDefaults.modeConfiguration, completionItems: false })` before registering the custom provider. Alternatively, rely solely on `addExtraLib` when the TypeScript language service already supplies the desired library completions.
