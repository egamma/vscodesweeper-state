# Issue #2357 — [Monarch Julia grammar] interpolation breaks inside multiline strings

[https://github.com/microsoft/monaco-editor/issues/2357](https://github.com/microsoft/monaco-editor/issues/2357)

## Summary

The Julia grammar still exits string interpolation at the first closing parenthesis, including one belonging to a nested expression. Keep this correctly labeled issue open; the defect is localized in Monaco-owned grammar code.

## Change summary

Nested parentheses inside Julia multiline-string interpolation prematurely switch syntax highlighting back to string content.

## Best solution

Make the Julia Monarch grammar retain expression highlighting until the interpolation's matching closing parenthesis, preserving surrounding string highlighting. Add focused tokenization cases to the existing Julia grammar tests.
