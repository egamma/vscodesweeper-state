# Issue #4599 — [Feature Request] Align `alwaysConsumeMouseWheel` Behavior with Native textarea Scrolling

[https://github.com/microsoft/monaco-editor/issues/4599](https://github.com/microsoft/monaco-editor/issues/4599)

## Summary

A real API gap remains: `alwaysConsumeMouseWheel: false` releases each wheel event immediately when Monaco cannot scroll, but cannot provide textarea-style scroll ownership until pointer movement. Route this editor-core request to the scrollbar/scroll owners.

## Change summary

Provide textarea-like wheel handling that retains editor scroll ownership at a boundary until the pointer moves.

## Best solution

Implement the wheel-ownership behavior in the VS Code editor core's scrollable element, expose it through `IEditorScrollbarOptions`, and let it flow into Monaco with a subsequent release. The existing boolean should retain its documented behavior, so this likely needs a separate option or carefully compatible mode.
