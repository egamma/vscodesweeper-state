# Issue #2269 — Diff - Merge values

[https://github.com/microsoft/monaco-editor/issues/2269](https://github.com/microsoft/monaco-editor/issues/2269)

## Summary

Implemented and shipped: side-by-side diff editors now display margin arrows that copy an original changed block into the modified model.

## Change summary

Add a convenient control for merging an entire changed block in the side-by-side diff editor.

## Best solution

Use the shipped `renderMarginRevertIcon` option, which defaults to `true`; clicking a change's arrow reverts the corresponding modified block to the original content.
