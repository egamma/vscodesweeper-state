The requested built-in block-copy control now exists in the side-by-side diff editor. Close as implemented and explain the options needed to display the revert arrows.

## Change summary

Provide a built-in button to copy a differing block between the compared documents, including in side-by-side mode.

## Best solution

Use the shipped side-by-side revert arrows to copy original blocks into the modified document without custom diff-processing code. Explain the configuration rather than treating the closed related reports as duplicate targets.

  > Thanks for the report. Built-in side-by-side block-copy arrows were added in https://github.com/microsoft/vscode/commit/778e6228a36232d9d78e0b920811f82ccb09c34e and are included in current Monaco; I haven't established the first release containing that change.
  > 
  > To show the arrows, configure the diff editor with `renderSideBySide: true`, `renderMarginRevertIcon: true`, `renderGutterMenu: false`, `readOnly: false`, and `useInlineViewWhenSpaceIsLimited: false`. Clicking an arrow copies that block from the original (left) document into the modified (right) document. This provides the built-in control requested here without a custom merge command.
