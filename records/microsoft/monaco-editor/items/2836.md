# Issue #2836 — [Feature Request] Documentation around registering custom languages with custom lsps

[https://github.com/microsoft/monaco-editor/issues/2836](https://github.com/microsoft/monaco-editor/issues/2836)

## Summary

Keep open: the existing documentation explains built-in worker bundling, but does not provide the requested end-to-end custom-language worker and LSP example. Native LSP APIs now exist, making an updated ESM guide more useful than preserving the thread's AMD workaround.

## Change summary

Document registering a custom language with worker-backed language features or an LSP server while retaining ordinary TypeScript support.

## Best solution

Provide a runnable ESM example and guide distinguishing Monaco worker proxies from LSP transports, covering language registration, worker startup, model synchronization and formatting. This is suitable community documentation work, with maintainer agreement on the supported integration contract.
