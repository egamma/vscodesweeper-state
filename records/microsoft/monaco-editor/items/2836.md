# Issue #2836 — [Feature Request] Documentation around registering custom languages with custom lsps

[https://github.com/microsoft/monaco-editor/issues/2836](https://github.com/microsoft/monaco-editor/issues/2836)

## Summary

The documentation gap remains: Monaco now ships a native LSP client and supports custom workers, but there is still no end-to-end guide or sample connecting a custom language, worker transport, providers, and bundler configuration.

## Change summary

Document how to register a custom language backed by a web-worker-hosted language server, including ESM and webpack integration.

## Best solution

Add a runnable playground or samples example using `languages.register`, `MonacoLspClient`, and a worker transport, plus document ESM `MonacoEnvironment.getWorker` and webpack-plugin `customLanguages` configuration. This is suitable for a community documentation PR.
