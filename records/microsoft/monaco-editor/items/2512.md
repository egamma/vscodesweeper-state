# Issue #2512 — TS regex missed by Monarch grammar

[https://github.com/microsoft/monaco-editor/issues/2512](https://github.com/microsoft/monaco-editor/issues/2512)

## Summary

Still present on main: the TypeScript Monarch grammar cannot recognize the first regex because its closing slash is followed by the ternary colon. This team-authored issue should remain open with its existing TypeScript and grammar routing.

## Change summary

The TypeScript tokenizer misclassifies a regular-expression literal before a ternary colon, causing incorrect bracket matching.

## Best solution

Extend the regular-expression termination rule in src/languages/definitions/typescript/typescript.ts to handle a following colon without confusing division operators, and add the reported ternary expression as a tokenizer regression test. This remains suitable for a community PR under the existing help-wanted designation.
