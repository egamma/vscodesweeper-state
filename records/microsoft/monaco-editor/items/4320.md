# Issue #4320 — [Feature Request] Make `setExtraLibs` and `addExtraLib` async

[https://github.com/microsoft/monaco-editor/issues/4320](https://github.com/microsoft/monaco-editor/issues/4320)

## Summary

The current API still provides no completion signal guaranteeing extra libraries have reached an existing TypeScript worker before declaration emission. Route this request to typescript; the verified related reports concern different observable failures.

## Change summary

Provide an awaitable way to ensure extra-library registration completes before compiling a model to declarations.

## Best solution

Define a supported worker-synchronization contract in Monaco's TypeScript integration so declaration emission can reliably follow extra-library registration without arbitrary delays. Preserve addExtraLib's disposable lifecycle when considering an async API or a separate readiness operation.
