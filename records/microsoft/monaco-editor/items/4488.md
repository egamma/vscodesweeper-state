# Issue #4488 — [Bug] Sticky scroll toggle does not work

[https://github.com/microsoft/monaco-editor/issues/4488](https://github.com/microsoft/monaco-editor/issues/4488)

## Summary

The sticky-scroll toggle still has a source-confirmed configuration mismatch in the standalone editor. Route to editor-sticky-scroll; the related applications closed their reports through workarounds, not a Monaco fix.

## Change summary

Right-clicking a sticky line exposes an ineffective Sticky Scroll toggle alongside the browser menu and an improperly styled editor menu.

## Best solution

Correct the standalone sticky-scroll command and context-menu behavior in the microsoft/vscode sources that Monaco bundles. Preserve this report until the fix reaches Monaco; disabling sticky scroll through updateOptions is a workaround, not coverage of the broken menu.

- **Proposed comment:**

  > Thanks for the report and the playground example. The standalone toggle changes the configuration service, but sticky scrolling reads the editor's own options, so the menu action does not update the visible editor. Calling myEditor.updateOptions({ stickyScroll: { enabled: false } }) is an application-side workaround. The command and context-menu correction belongs in the editor sources at https://github.com/microsoft/vscode/issues; this report should remain open until the fix reaches Monaco.
