# Issue #4488 — [Bug] Sticky scroll toggle does not work

[https://github.com/microsoft/monaco-editor/issues/4488](https://github.com/microsoft/monaco-editor/issues/4488)

## Summary

Still present in the current vscode-derived editor source: the sticky-scroll action changes the configuration service, but the standalone editor does not apply service-originated changes back to its editor options. Routing this confirmed Monaco-specific behavior to editor-sticky-scroll.

## Change summary

The sticky-scroll context menu is improperly rendered and its toggle does not disable sticky scrolling in standalone Monaco.

## Best solution

Fix the standalone editor integration in the vscode editor core so the sticky-scroll action updates the active editor's options while preserving VS Code's persistent configuration behavior; the context-menu event handling and styling should be corrected in the same area.
