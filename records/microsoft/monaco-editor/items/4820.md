[https://github.com/microsoft/monaco-editor/issues/4820](https://github.com/microsoft/monaco-editor/issues/4820)

## Summary

This asks how to handle navigation from Peek References rather than reporting broken behavior. The public editor-opener API provides the destination URI for cross-model navigation; propose closing as a support question.

## Change summary

Obtain a selected reference's URI and navigate to its destination from Peek References.

## Best solution

Use monaco.editor.registerEditorOpener with an openCodeEditor callback for cross-model navigation, receiving the resource URI and optional selection or position. This handles navigation requests, not every selection event inside the peek widget.
