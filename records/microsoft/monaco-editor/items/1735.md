# Issue #1735 — Feature request: Syntax highlighting support for Mustache

[https://github.com/microsoft/monaco-editor/issues/1735](https://github.com/microsoft/monaco-editor/issues/1735)

## Summary

A real capability gap remains: Monaco has a Handlebars grammar, but no dedicated Mustache language registration or support for Mustache expressions embedded in JSON. The existing grammars routing and Backlog milestone remain appropriate.

## Change summary

Add syntax highlighting for Mustache templates, including Mustache expressions embedded in content such as JSON.

## Best solution

Add an opt-in Mustache Monarch definition and registration under src/languages/definitions, or extend the language-composition surface so embedders can combine Mustache expressions with a host grammar such as JSON. This looks suitable for a community PR.

## Vision fit

- **Fit:** aligned

- **Evidence:** The vision identifies bundled language experiences as a durable theme and supported, tree-shakeable per-language entry points as the current ESM direction.

## Evidence
