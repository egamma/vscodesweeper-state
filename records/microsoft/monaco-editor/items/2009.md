# Issue #2009 — Single line mode

[https://github.com/microsoft/monaco-editor/issues/2009](https://github.com/microsoft/monaco-editor/issues/2009)

## Summary

A real API gap remains: existing options can produce the desired appearance, but Monaco still lacks a supported mode that consistently prevents multiline content. The issue is already correctly classified and routed.

## Change summary

Add a configuration option that makes Monaco behave as a single-line editor across typing, paste, and editor commands.

## Best solution

Add a supported editor-core option in microsoft/vscode that enforces a one-line model across all edit paths while preserving suggestion acceptance, then inherit it in Monaco. This looks suitable for an open community contribution after the API semantics are agreed.

## Vision fit

- **Fit:** rejected
- **Reason:** A Monaco-only editor behavior conflicts with the generated-from-VS-Code model, so the capability should first be implemented in the shared vscode editor core.
- **Evidence:** The README describes Monaco as "generated straight from VS Code's sources with some shims around services the code needs to make it run in a web browser."
