# Issue #1997 — Razor syntax highlighting does not recognize @code or @functions

[https://github.com/microsoft/monaco-editor/issues/1997](https://github.com/microsoft/monaco-editor/issues/1997)

## Summary

Still present on main: the Razor tokenizer recognizes direct `@{` blocks but treats `@code` and `@functions` as simple identifiers, leaving their following braces and C# bodies unhighlighted. The existing `bug`, `help wanted`, and `grammars` labels route it appropriately.

## Change summary

Recognize Razor `@code` and `@functions` directives as C# blocks for syntax highlighting.

## Best solution

Extend the Monarch tokenizer in `src/languages/definitions/razor/razor.ts` to enter the existing Razor C# block state for `@code { ... }` and `@functions { ... }`, with tokenization cases in `razor.test.ts`. This remains suitable for a community PR.
