# Issue #4707 — [Feature Request] Diff Editor Treats All Modified Lines as only "Added" or "Deleted", not "Modified"

[https://github.com/microsoft/monaco-editor/issues/4707](https://github.com/microsoft/monaco-editor/issues/4707)

## Summary

A real diff-editor theming gap remains: current tokens distinguish line-level from character-level changes, but not paired modified lines from wholly inserted or deleted lines. Route to the diff-editor area while the editor-core API request is raised in microsoft/vscode.

## Change summary

Provide distinct styling for wholly added or deleted lines versus modified-line pairs in the side-by-side diff editor.

## Best solution

Add separate theme tokens or equivalent diff-decoration semantics in the VS Code diff-editor core for pure insertions/deletions and modified-line pairs, then inherit them in a subsequent Monaco release. The existing Monaco issue should remain available until a VS Code issue owns the editor-core work.
