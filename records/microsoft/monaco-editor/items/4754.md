# Issue #4754 — [Feature Request] Allow using SharedWorker instead of Worker (for TypeScript)

[https://github.com/microsoft/monaco-editor/issues/4754](https://github.com/microsoft/monaco-editor/issues/4754)

## Summary

A real capability gap remains: Monaco's worker hook and RPC setup require a dedicated Worker-compatible endpoint, so a SharedWorker cannot currently be supplied directly. Keep the feature request open and route it to TypeScript and integration owners.

## Change summary

Allow embedders to share one TypeScript language-service worker across same-origin browser tabs using SharedWorker.

## Best solution

Define and support a worker endpoint abstraction that can use a SharedWorker MessagePort, including cross-tab model identity, configuration, and lifecycle handling. This looks like open-for-PR material after maintainers agree on the protocol and compatibility requirements.
