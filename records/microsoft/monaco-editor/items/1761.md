# Issue #1761 — Make monaco-editor-samples have independent folders

[https://github.com/microsoft/monaco-editor/issues/1761](https://github.com/microsoft/monaco-editor/issues/1761)

## Summary

The accepted request remains incomplete: individual sample `.gitignore` files still omit `node_modules`, and several samples continue to depend on the parent `samples` installation. The Backlog milestone and `help wanted` label appropriately keep this available for a community contribution.

## Change summary

Make copied sample folders self-contained and prevent their locally installed dependencies from being committed.

## Best solution

Add `node_modules` exclusions to each applicable sample `.gitignore` and make each sample independently installable, or clearly document the few that intentionally require the parent installation. This is suitable `open for PR` work in `samples/`.
