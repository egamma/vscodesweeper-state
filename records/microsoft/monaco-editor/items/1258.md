# Issue #1258 — Fold label

[https://github.com/microsoft/monaco-editor/issues/1258](https://github.com/microsoft/monaco-editor/issues/1258)

## Summary

The requested capability remains absent: folding providers cannot specify replacement text for a collapsed range. The request is already correctly classified and parked in Backlog, with no verified canonical issue owning it.

## Change summary

Allow a folding-range provider to define the text displayed for a collapsed range, such as `import ...`.

## Best solution

Add per-range collapsed display text to the vscode editor-core `FoldingRange` contract and rendering pipeline, then expose it through Monaco's generated API. This requires an editor-core API decision and looks suitable for a focused community contribution once that shape is agreed.
