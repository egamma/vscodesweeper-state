# Issue #3602 — [Bug] [0.35~0.52] The context menu in Apple device displays abnormally (no background) 

[https://github.com/microsoft/monaco-editor/issues/3602](https://github.com/microsoft/monaco-editor/issues/3602)

## Summary

The iOS context-menu theming defect remains traceable in the current vscode editor core: iOS deliberately renders the menu outside the editor's shadow DOM, where Monaco's scoped menu color variables are unavailable. Keep it open and route it to context-menu and shadow-DOM ownership.

## Change summary

Ensure Monaco context menus retain their theme background and foreground colors on iOS devices.

## Best solution

Fix the vscode editor core so an iOS context menu rendered outside the shadow DOM receives the standalone editor's menu theme variables, without requiring embedders to hoist CSS variables or disable shadow DOM.
