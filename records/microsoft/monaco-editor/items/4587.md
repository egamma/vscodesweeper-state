# Issue #4587 — Decorations are improper on undo

[https://github.com/microsoft/monaco-editor/issues/4587](https://github.com/microsoft/monaco-editor/issues/4587)

## Summary

The requested preservation of decoration targets across undo falls under an established maintainer decision: decoration positions are not recorded in undo history, and automatic restoration was declined. Embedders must update decorations when content changes.

## Change summary

Keep a decoration attached to the same age identifier when undo reverses a whole-document replacement.

## Best solution

Retain the existing text-only undo contract and have the embedding application recompute decoration ranges after content changes. Reconsidering automatic restoration would require revisiting the editor-core decision documented in https://github.com/microsoft/monaco-editor/issues/2933.
