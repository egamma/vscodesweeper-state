# Issue #608 — Provider APIs and addCommand don't work well together

[https://github.com/microsoft/monaco-editor/issues/608](https://github.com/microsoft/monaco-editor/issues/608)

## Summary

Completed in Monaco 0.22.0: `monaco.editor.registerCommand(id, handler)` now registers a global command that provider results can reference across editor instances.

## Change summary

Provide a stable global command ID that language-provider results can use with multiple editor instances.

## Best solution

Use the shipped `monaco.editor.registerCommand` API and place its caller-supplied ID in the provider's `Command`; no further API change is needed.
