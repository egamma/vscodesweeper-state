# Issue #5314 — [Bug] Why versions of marked and dompurify are fixed?

[https://github.com/microsoft/monaco-editor/issues/5314](https://github.com/microsoft/monaco-editor/issues/5314)

## Summary

Keep open for human review because the request concerns a vulnerable bundled sanitizer. Exact dependency versions intentionally describe the bundled code; allowing ranges alone would not make Monaco use the updated dependency.

## Change summary

Allow marked and DOMPurify dependency ranges so embedders can receive dependency updates without a new Monaco release.

## Best solution

Provide a supported distribution that actually consumes external npm dependencies before permitting independently updateable ranges, while keeping bundled dependency metadata accurate. Coordinate this packaging decision with https://github.com/microsoft/monaco-editor/issues/5067.
