# Issue #4437 — [Feature Request] Keep ThirdPartyNotices.txt up to date

[https://github.com/microsoft/monaco-editor/issues/4437](https://github.com/microsoft/monaco-editor/issues/4437)

## Summary

Keep open: the package build combines core notices with the repository's static supplement, but that supplement still identifies TypeScript 4.4.4 while current dependencies specify 5.9.3. Existing packaging answers where notices are delivered, not whether they remain current.

## Change summary

Keep third-party notices synchronized with bundled dependencies, or document a reliable way to obtain their inventory.

## Best solution

Maintain accurate notices for the dependencies actually bundled into each release and document where embedders can obtain that inventory. Review the static supplement and its maintenance workflow alongside the notice assembly in build/build-monaco-editor.ts.
