# Issue #5065 — Use LSP for TypeScript language features

[https://github.com/microsoft/monaco-editor/issues/5065](https://github.com/microsoft/monaco-editor/issues/5065)

## Summary

This team-authored Backlog request remains necessary: native LSP client APIs have shipped, but the TypeScript worker still exposes a custom interface and bespoke Monaco adapters.

## Change summary

Replace the TypeScript worker's custom language-feature protocol with LSP while reducing its minified bundle below 5 MB.

## Best solution

Implement an LSP server façade for the bundled TypeScript language service under src/languages/features/typescript and connect it through Monaco's native LSP client APIs, while modularizing the worker payload enough to approach the requested size target.
