# Issue #4806 — [Bug]  Color not applied in registerHoverProvider

[https://github.com/microsoft/monaco-editor/issues/4806](https://github.com/microsoft/monaco-editor/issues/4806)

## Summary

This is a resolved usage question rather than a Monaco defect: hover Markdown must identify the custom language in a fenced code block for syntax highlighting, and the reporter confirmed that approach works.

## Change summary

Apply the custom language's token colors to code displayed by a hover provider.

## Best solution

Use an `IMarkdownString` containing a fenced code block such as ` ```ppl ` so Monaco can tokenize and theme the hover content with the registered custom language.

Hover contents are Markdown, so Monaco needs the language identifier on a fenced code block to tokenize and theme the snippet—for example, `{ value: '```ppl\nFOR variable := 1 TO max DO\n```' }`.
