# Issue #4193 — [Bug] `monaco-editor-webpack-plugin` resolves `customLanguages` from `path.join(monacoEditorPath, "esm")` when `monacoEditorPath` is supplied

[https://github.com/microsoft/monaco-editor/issues/4193](https://github.com/microsoft/monaco-editor/issues/4193)

## Summary

The bug remains in current main: custom-language entries and workers are still passed through Monaco-specific path resolution whenever `monacoEditorPath` is set. Route this to the webpack plugin area.

## Change summary

Custom language entries and workers are incorrectly resolved beneath `<monacoEditorPath>/esm` when a custom Monaco installation path is configured.

## Best solution

Update `webpack-plugin/src/index.ts` to distinguish built-in Monaco entries from user-supplied custom-language entries, resolving only the former relative to `monacoEditorPath`; cover both custom language imports and custom workers.

## Evidence
