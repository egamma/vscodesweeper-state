# Issue #3005 — Decorations are not hidden within folded regions 

[https://github.com/microsoft/monaco-editor/issues/3005](https://github.com/microsoft/monaco-editor/issues/3005)

## Summary

Verified cross-repository duplicate: the open VS Code issue tracks the same word-wrap/folding decoration defect and identifies its still-present editor-core root cause.

## Change summary

Decorations inside folded regions remain visible when word wrapping creates enough additional view lines.

## Best solution

Fix the hidden-line fast path in VS Code's viewModelLines.ts so wrapped view lines cannot mask folded model lines; Monaco should receive that correction through a subsequent editor-core release cut.
