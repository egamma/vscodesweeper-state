# Issue #1784 — EncodedTokenizationSupport2Adapter does not implement tokenize method

[https://github.com/microsoft/monaco-editor/issues/1784](https://github.com/microsoft/monaco-editor/issues/1784)

## Summary

Implemented upstream and shipped in Monaco v0.22.0: encoded token providers can optionally implement `tokenize`, and the adapter delegates to it for classic token inspection.

## Change summary

Allow an encoded token provider to supply non-encoded tokens so tools such as the TextMate token inspector work.

## Best solution

Keep the optional `EncodedTokensProvider.tokenize` API and adapter delegation introduced by the cited vscode commit; no further implementation is needed.
