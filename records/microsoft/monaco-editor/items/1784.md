# Issue #1784 — EncodedTokenizationSupport2Adapter does not implement tokenize method

[https://github.com/microsoft/monaco-editor/issues/1784](https://github.com/microsoft/monaco-editor/issues/1784)

## Summary

The requested optional tokenize method and adapter wiring are implemented in the editor core used by current Monaco main. Propose closing as completed.

## Change summary

Allow encoded token providers to return non-encoded tokens for inspection, including TextMate integrations.

## Best solution

Use EncodedTokensProvider.tokenize alongside tokenizeEncoded; the adapter now delegates non-encoded tokenization to that method. No additional editor change is needed for the maintainer-defined request.
