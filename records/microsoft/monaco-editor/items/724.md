# Issue #724 — cut and copy visibility to false in context menu

[https://github.com/microsoft/monaco-editor/issues/724](https://github.com/microsoft/monaco-editor/issues/724)

## Summary

Verified duplicate of the broader open context-menu customization request. The current API can conditionally hide added actions, but it provides no supported way to remove built-in Cut and Copy entries.

## Change summary

Allow embedders to hide Cut and Copy from the context menu without disabling their commands or shortcuts.

## Best solution

Consolidate on https://github.com/microsoft/monaco-editor/issues/1280 and expose a supported per-editor API for filtering or removing built-in context-menu entries in the vscode editor core, which will then flow into Monaco.

## Vision fit

- **Fit:** aligned
- **Reason:** A supported context-menu customization API fits Monaco's role as an embeddable browser editor configured through its API.
- **Evidence:** The vision states that embedders integrate Monaco through its API and favors general integration points over embedder-specific workarounds.
