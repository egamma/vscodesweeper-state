## Summary

The request to hide built-in Cut and Copy menu entries is covered by the open context-menu customization issue. The thread's context-key example controls newly added actions, not the existing clipboard entries.

## Change summary

Allow embedders to hide Cut and Copy from the context menu without disabling their commands elsewhere.

## Best solution

Consolidate built-in menu-item visibility customization in https://github.com/microsoft/monaco-editor/issues/1280, preserving this report's requirement that clipboard commands remain available outside the menu.
