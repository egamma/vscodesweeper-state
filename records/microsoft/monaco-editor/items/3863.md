# Issue #3863 — [Feature Request] colorize styles target

[https://github.com/microsoft/monaco-editor/issues/3863](https://github.com/microsoft/monaco-editor/issues/3863)

## Summary

The requested capability remains missing: `colorize` installs token styles in the main document, with no public way to target an iframe document or obtain the generated CSS. The existing feature-request and tokenization routing remain appropriate.

## Change summary

Allow colorized HTML token styles to be installed in a caller-selected document, or return those styles to the caller.

## Best solution

Extend the standalone colorizer API in the vscode editor core to accept a target document or element and register `monaco-colors` in that document while preserving the current default. This appears suitable for a community PR, but should be implemented in `microsoft/vscode/src/vs/editor/standalone/browser` and flow into Monaco.
