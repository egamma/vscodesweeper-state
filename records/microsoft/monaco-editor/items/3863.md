# Issue #3863 — [Feature Request] colorize styles target

[https://github.com/microsoft/monaco-editor/issues/3863](https://github.com/microsoft/monaco-editor/issues/3863)

## Summary

The public colorization API still lacks a stylesheet destination or returned CSS, so the iframe use case remains uncovered. The related worker request describes a different observable limitation and is not a verified duplicate.

## Change summary

Allow colorized HTML and its required token styles to be used in a destination document such as an iframe.

## Best solution

Consider an explicit stylesheet destination or portable CSS output in the VS Code standalone editor API, then expose it through Monaco's generated API. Preserve existing default-document behavior; copying the generated style element remains a workaround rather than coverage of the requested capability.
