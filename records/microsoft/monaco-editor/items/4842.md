# Issue #4842 — [Bug] Tooltip does not appear in Find widget from v0.48.0 onwards

[https://github.com/microsoft/monaco-editor/issues/4842](https://github.com/microsoft/monaco-editor/issues/4842)

## Summary

Find-widget tooltips were restored in v0.55.0 by replacing the unavailable hover-delegate path with the standalone hover service. The thread confirms restoration; subsequent positioning and flickering reports concern different behavior.

## Change summary

Hovering the Find widget's collapse arrow stopped displaying its tooltip starting in v0.48.0.

## Best solution

Treat the missing-tooltip regression as fixed in v0.55.0. Keep remaining positioning and flickering work separate in https://github.com/microsoft/monaco-editor/issues/5177 and https://github.com/microsoft/monaco-editor/issues/5208.
