# Issue #5154 — Monaco-editor 0.55 generated bundle file larger than 6MB

[https://github.com/microsoft/monaco-editor/issues/5154](https://github.com/microsoft/monaco-editor/issues/5154)

## Summary

Keep open because this team-authored issue reports a concrete webpack bundle-size regression. Monaco 0.56 added tree-shakeable entry points that may address the extra TypeScript chunk, but the implementing commit does not reference this issue and no current-version build confirms resolution.

## Change summary

Upgrading the official webpack-plugin sample from Monaco 0.54 to 0.55.1 introduces an additional 6.41 MiB bundle containing TypeScript services.

## Best solution

Compare the sample's production output on 0.56 with 0.55.1 and determine why TypeScript services enter a UI-thread chunk despite already being present in the worker. If the full entry point is responsible, update the sample to demonstrate the 0.56 tree-shakeable editor and language registration entry points; otherwise correct the webpack-plugin split.
