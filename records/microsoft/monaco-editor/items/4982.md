# Issue #4982 — [Bug] Color highlight in xml closing tag

[https://github.com/microsoft/monaco-editor/issues/4982](https://github.com/microsoft/monaco-editor/issues/4982)

## Summary

The XML tokenizer on current main still requires a closing tag and its final bracket on the same line. Keep the issue open because the linked fixing PR remains open and is an implementation candidate awaiting resolution.

## Change summary

XML closing tags lose syntax highlighting when a newline appears before the closing bracket.

## Best solution

Update and review https://github.com/microsoft/monaco-editor/pull/5020, resolving its current conflicts and preserving its multiline closing-tag tokenization test, then merge it into the XML basic-language definition.
