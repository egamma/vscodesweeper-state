# Issue #1632 — Suggestions Width small and Not returning values with large characters

[https://github.com/microsoft/monaco-editor/issues/1632](https://github.com/microsoft/monaco-editor/issues/1632)

## Summary

Implemented and shipped: the suggestion widget is resizable, remembers custom dimensions, and supports fitting its width to its items. The reported long-label filtering example was already confirmed working in the playground.

## Change summary

Allow long completion labels to be displayed in a wider suggestion widget and matched by an internal word.

## Best solution

Use the shipped resize handles or double-click a handle for the ideal content width; providers can use CompletionItem.filterText when labels need custom matching. Further automatic or min/max width configuration is tracked by https://github.com/microsoft/monaco-editor/issues/4337.
