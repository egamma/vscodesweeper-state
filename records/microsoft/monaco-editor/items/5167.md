# Issue #5167 — [Bug] `@example` tag immediately followed by code block breaks markdown rendering on the jsDoc preview window

[https://github.com/microsoft/monaco-editor/issues/5167](https://github.com/microsoft/monaco-editor/issues/5167)

## Summary

The TypeScript hover formatter still places an em dash before an opening code fence, preventing block rendering. Keep open because an open PR explicitly targets this issue; the older matching report is a consolidation candidate once that implementation is resolved.

## Change summary

Render fenced code blocks immediately following a JSDoc @example tag as separate, syntax-highlighted blocks.
