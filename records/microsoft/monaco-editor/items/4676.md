# Issue #4676 — [Feature Request] Event listener for when findController is opened/closed

[https://github.com/microsoft/monaco-editor/issues/4676](https://github.com/microsoft/monaco-editor/issues/4676)

## Summary

A real public-API gap remains: find-widget visibility is observable only through internal contribution state, not a supported Monaco event. Route this to the editor-find area.

## Change summary

Expose a supported event that embedders can use to track when the editor find widget opens or closes.

## Best solution

Add a typed public visibility-change event in the vscode editor core and expose it through Monaco's editor API. This appears suitable for an API-reviewed community contribution.
