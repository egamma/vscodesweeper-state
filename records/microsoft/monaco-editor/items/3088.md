# Issue #3088 — [Feature Request] Expose tabFocusMode option so a default can be set

[https://github.com/microsoft/monaco-editor/issues/3088](https://github.com/microsoft/monaco-editor/issues/3088)

## Summary

Partially implemented but still necessary: `tabFocusMode` is now an editor option, while current editor-core code continues to synchronize it through a global singleton, leaving the requested per-editor behavior unresolved.

## Change summary

Allow embedders to initialize tab-focus mode and configure it independently for each editor instance.

## Best solution

Complete this in the vscode editor core by making tab-focus state effective per editor rather than writing each editor's option into the shared `TabFocus` singleton. The initialization and configuration-event failures reported in related Monaco issues should be resolved by the same design.

- **Fit:** aligned
- **Reason:** Per-instance tab-navigation configuration supports Monaco's browser-embedding API and its durable accessibility theme.
- **Evidence:** The vision describes Monaco as a browser library whose embedders integrate through its API and names accessibility as a durable area of investment.

## Evidence

- **partial implementation:** https://github.com/microsoft/vscode/commit/773668e936311f7945240aad84072dc6f60c5d6c added `IEditorOptions.tabFocusMode`, but `EditorConfiguration` initializes it by calling the shared `TabFocus.setTabFocusMode(...)`.
- **global state remains:** Current vscode source at https://github.com/microsoft/vscode/blob/main/src/vs/editor/browser/config/tabFocus.ts exports one `TabFocusImpl` singleton, and the toggle action reads and writes that global state.
- **initialization gap:** https://github.com/microsoft/monaco-editor/issues/4424 remains open with a playground reproduction showing that `tabFocusMode: true` does not reliably establish the requested initial behavior; its discussion also reports interference between multiple editor instances.
- **configuration gap:** https://github.com/microsoft/monaco-editor/issues/4740 remains open for configuration-change events not firing when tab-focus mode changes.
