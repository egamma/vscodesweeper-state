# Issue #3088 — [Feature Request] Expose tabFocusMode option so a default can be set

[https://github.com/microsoft/monaco-editor/issues/3088](https://github.com/microsoft/monaco-editor/issues/3088)

## Summary

The bundled editor core now honors tabFocusMode: true at creation, but fully independent per-editor configuration remains missing: the global toggle still overrides editors configured false. Keep this request open for that remaining capability.

## Change summary

Allow embedders to initialize tab-focus behavior and configure it independently for each editor.

## Best solution

Retain the supported tabFocusMode construction option and resolve independent per-editor behavior in the microsoft/vscode editor core, including how explicit false interacts with the global toggle.

  > Thanks for the request. The current editor core supports passing tabFocusMode: true when creating an editor. However, its effective value still combines that option with the shared global mode, so an editor configured false cannot remain independent when the global toggle is enabled. Keeping this open for the per-editor independence part; that change belongs in the editor core at https://github.com/microsoft/vscode/issues.

This addresses construction with true but does not remove global coupling.

An explicit false cannot override global true. Current upstream src/vs/editor/contrib/toggleTabFocusMode/browser/toggleTabFocusMode.ts still toggles the shared TabFocus singleton.
