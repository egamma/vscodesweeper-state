# Issue #4746 — [Bug] Font size changes after I destroy and create editor instance

[https://github.com/microsoft/monaco-editor/issues/4746](https://github.com/microsoft/monaco-editor/issues/4746)

## Summary

The supplied persistence flow still compounds font scaling in current editor-core source: it saves the zoom-adjusted size and recreates the editor while the global zoom remains active. Keep this accepted bug open; no verified canonical or fixing commit was found.

## Change summary

Persisting the computed font size and recreating an editor applies the existing zoom multiplier a second time.

## Best solution

Resolve the persistence contract between configured font size and global editor zoom in the VS Code editor core, with Monaco guidance showing how to restore both without double scaling. Preserve existing zoom behavior rather than resetting shared zoom when an editor is disposed.
