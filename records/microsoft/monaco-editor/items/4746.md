# Issue #4746 — [Bug] Font size changes after I destroy and create editor instance

[https://github.com/microsoft/monaco-editor/issues/4746](https://github.com/microsoft/monaco-editor/issues/4746)

## Summary

The additional increase comes from persisting the computed font size and then recreating the editor while its global zoom level remains active. Monaco provides the raw configured options needed to avoid applying that multiplier twice.

## Change summary

Preserve the displayed font size when an editor is disposed and recreated after using the font-zoom action.

## Best solution

Persist the configured value from `editor.getRawOptions().fontSize`, or manage font size directly with `updateOptions`, rather than passing the zoom-adjusted value returned by `getOption(EditorOption.fontSize)` into the next editor instance.

- **Proposed comment:**

  > Thanks for the report and playground example. The font-zoom action changes Monaco's global editor zoom level, while `getOption(EditorOption.fontSize)` returns the computed size after that zoom is applied. Saving that computed value and passing it to the next editor therefore applies the still-active zoom multiplier a second time.
  > 
  > For this lifecycle, persist `editor.getRawOptions().fontSize` instead, or manage the desired size directly with `editor.updateOptions({ fontSize })` rather than the font-zoom actions. With the example's raw value of `12`, the recreated editor retains the existing zoom and renders at `13.2px` without increasing again. This is the intended distinction between raw configuration and computed options, so no editor lifecycle fix is needed.

## Evidence

- **computed versus raw options:** The current editor API documents `getRawOptions()` as returning configuration without validation or defaults, while `getOption()` returns computed values: https://github.com/microsoft/vscode/blob/18ebe6515d696f52fa3172fa3d5d878ac8424e78/src/vs/editor/browser/editorBrowser.ts#L906-L914
- **global zoom behavior:** The font-zoom actions update the module-level `EditorZoom` singleton rather than the individual editor's raw `fontSize`: https://github.com/microsoft/vscode/blob/18ebe6515d696f52fa3172fa3d5d878ac8424e78/src/vs/editor/contrib/fontZoom/browser/fontZoom.ts
