# Issue #5023 — [Bug] Last editable line is not at the end of the editor

[https://github.com/microsoft/monaco-editor/issues/5023](https://github.com/microsoft/monaco-editor/issues/5023)

## Summary

The versioned playground comparison demonstrates a regression beginning between v0.51.0 and v0.52.0-rc2: with scrollBeyondLastLine enabled, keyboard navigation no longer lets the cursor remain on the bottom visible line. No canonical issue or concrete fixing commit was found, so this should remain open and be routed to editor scrolling.

## Change summary

Restore the ability to navigate and edit on the bottom visible line while scrollBeyondLastLine is enabled.

## Best solution

Confirm the behavior on v0.56.0, then fix the cursor-reveal and vertical-scroll interaction in the vscode editor core; the correction should flow into Monaco with the next core update.
