# Issue #4347 — [Bug] Can't use '$' and '.' as triggerCharacters in JSON Language

[https://github.com/microsoft/monaco-editor/issues/4347](https://github.com/microsoft/monaco-editor/issues/4347)

## Summary

The reported behavior remains traceable in current source: JSON treats `.` and `$` as words, causing the editor core to suppress their registered trigger-character path in favor of quick suggestions. Route to `suggest` and `json`; the behavioral fix belongs in the vscode editor core.

## Change summary

Registered JSON completion providers are not invoked automatically when `.` or `$` is typed as a trigger character.

## Best solution

Update the vscode suggest model so a registered trigger character is not discarded merely because the character also satisfies the language's word pattern, especially when quick suggestions are disabled for the current token. Add coverage using the JSON word pattern, then consume that editor-core fix in a Monaco release.
