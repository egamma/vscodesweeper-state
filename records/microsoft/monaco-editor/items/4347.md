# Issue #4347 — [Bug] Can't use '$' and '.' as triggerCharacters in JSON Language

Keep open: the supplied v0.45.0 playground sample provides enough information to retest, but its behavior has not been confirmed on current Monaco. Current source suggests an interaction between JSON word boundaries and automatic suggestions, not an outright prohibition on these trigger characters.

## Change summary

Custom JSON completions appear for '1' and ':' but not for '.' and '$'.
