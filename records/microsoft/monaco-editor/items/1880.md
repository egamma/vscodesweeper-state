# Issue #1880 — Not honoring 8-bit hex colors

[https://github.com/microsoft/monaco-editor/issues/1880](https://github.com/microsoft/monaco-editor/issues/1880)

## Summary

The current editor core intentionally discards token-color alpha, and maintainers declined the identical request because alpha cannot be represented correctly in the minimap. The documented workaround is to pre-composite the token color against the editor background.

## Change summary

Allow token theme foreground colors to preserve the alpha channel from eight-digit hexadecimal values.

## Best solution

Keep token colors opaque and pre-composite translucent theme colors against the configured editor background before calling `defineTheme`, preserving consistent editor and minimap rendering.
