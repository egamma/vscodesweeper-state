# Issue #1880 — Not honoring 8-bit hex colors

[https://github.com/microsoft/monaco-editor/issues/1880](https://github.com/microsoft/monaco-editor/issues/1880)

## Summary

Propose closing against an explicit maintainer precedent declining the same token-color alpha support. The limitation remains in current source; this is not an implemented fix or a duplicate of an open issue.

## Change summary

Honor the alpha channel in eight-digit hexadecimal token foreground colors supplied to defineTheme.

## Best solution

Keep opaque token colors consistent with minimap rendering and have embedders preblend translucent colors against their intended background, following the maintainer decision in https://github.com/microsoft/monaco-editor/issues/2061.
