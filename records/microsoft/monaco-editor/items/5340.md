# Issue #5340 — [Bug] [LSP] MonacoLspClient never disposes its language-feature registrations

[https://github.com/microsoft/monaco-editor/issues/5340](https://github.com/microsoft/monaco-editor/issues/5340)

## Summary

The provider-registration leak is present on main, and open PR https://github.com/microsoft/monaco-editor/pull/5339 directly fixes it. Keep the issue open while that implementation candidate is reviewed.

## Change summary

Make MonacoLspClient disposable so embedders can unregister all language-feature providers when tearing down an LSP session.

## Best solution

Review and land https://github.com/microsoft/monaco-editor/pull/5339, which retains the feature DisposableStore and exposes disposal through MonacoLspClient; close the issue only after the fix merges.
