# Issue #5328 — [Bug] Accessibility Bug: Broken Focus Management After Closing Search Pop-up Modal

[https://github.com/microsoft/monaco-editor/issues/5328](https://github.com/microsoft/monaco-editor/issues/5328)

## Summary

The current find controller intentionally focuses the editor when its widget closes; preserving an external embedder-owned trigger would be new editor-core behavior rather than a Monaco regression. Route this accessibility request to editor-find and accessibility.

## Change summary

Preserve and restore focus to an external Search button after it opens and closes Monaco's find widget.

## Best solution

Decide in the VS Code editor core whether the find controller should remember a non-editor invoking element or expose a supported dismissal hook for embedders; that change would then flow into Monaco. A playground example containing the external trigger would help define the required lifecycle.
