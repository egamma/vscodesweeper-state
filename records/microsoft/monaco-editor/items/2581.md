# Issue #2581 — Microsoft adopting/transferring all the Textmate repos officially

[https://github.com/microsoft/monaco-editor/issues/2581](https://github.com/microsoft/monaco-editor/issues/2581)

## Summary

The requested transfer of community TextMate integration projects is outside Monaco's repository boundary. Monaco officially provides the underlying APIs and Microsoft-maintained TextMate components while directing embedders to a community integration example.

## Change summary

Transfer three community TextMate integration and theme-conversion repositories into Microsoft ownership.

## Best solution

Keep the reusable TextMate primitives in microsoft/vscode-textmate and microsoft/vscode-oniguruma while leaving Monaco-specific integration projects community-owned, as documented in Monaco's README.
