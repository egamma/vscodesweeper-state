# Issue #4535 — [Bug] `delimiter.parenthesis` and `delimiter.bracket` values not applied

[https://github.com/microsoft/monaco-editor/issues/4535](https://github.com/microsoft/monaco-editor/issues/4535)

## Summary

Bracket-pair colorization intentionally overrides delimiter token foregrounds. The desired appearance is already supported by disabling bracket-pair colorization or configuring the dedicated bracket-highlight theme colors.

## Change summary

Allow delimiter token theme rules to control bracket colors while bracket-pair colorization is enabled.

## Best solution

Keep the VS Code editor-core behavior: embedders should either set `bracketPairColorization.enabled` to `false` or define `editorBracketHighlight.foreground1` through `foreground6` in the theme's `colors` section.

- **Proposed comment:**

  > Thanks for the report and the playground example. This is the intended interaction with bracket-pair colorization: its bracket decorations override the delimiter token foreground. To use the token colors, set `bracketPairColorization: { enabled: false }`; to retain pair colorization, configure `editorBracketHighlight.foreground1` through `editorBracketHighlight.foreground6` in the theme's `colors` section. Since the existing options cover both behaviors and Monaco follows the VS Code editor core here, I believe this can be closed as designed.
