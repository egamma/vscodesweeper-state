# Issue #2793 — Suggestion box incorrectly offset with translate animated container

[https://github.com/microsoft/monaco-editor/issues/2793](https://github.com/microsoft/monaco-editor/issues/2793)

## Summary

This remains the canonical report for overflow-widget mispositioning inside transformed containers, with repeated playground reproductions and confirmation through Monaco 0.52.2. Route it to the suggest and editor-rendering areas.

## Change summary

Suggestion and other overflow widgets are offset when the editor is hosted inside a CSS-transformed drawer or panel.

## Best solution

Fix widget positioning in the VS Code editor core so fixed overflow widgets account for transformed containing blocks, while preserving clipping behavior. `overflowWidgetsDomNode` is a useful workaround but does not cover the central behavior transparently.
