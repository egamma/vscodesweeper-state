# Issue #5400 — [Bug] Markdown Syntax: Nested Html tags inside of Markdown that span multiple lines render incorrectly

[https://github.com/microsoft/monaco-editor/issues/5400](https://github.com/microsoft/monaco-editor/issues/5400)

## Summary

Still present on current main: the Markdown tokenizer classifies four-space-indented HTML tag lines as code before HTML tokenization can begin. Route this Monaco-owned grammar defect to basic-language tokenization.

## Change summary

Markdown syntax highlighting loses HTML tag and attribute coloring when nested tags span multiple indented lines.

## Best solution

Update the Markdown Monarch grammar in src/languages/definitions/markdown/markdown.ts to preserve HTML tokenization across multiline HTML blocks while retaining indented-code behavior outside them, with regression coverage in markdown.test.ts. The closed PR https://github.com/microsoft/monaco-editor/pull/5422 contains a concrete attempted implementation and tests that can inform a revised fix.
