# Issue #2732 — how to disabled find widget completely?

[https://github.com/microsoft/monaco-editor/issues/2732](https://github.com/microsoft/monaco-editor/issues/2732)

## Summary

Keep open: retaining multicursor while completely excluding the find widget remains a meaningful modularity gap. Current source still couples these contributions, and no verified canonical was found.

## Change summary

Allow embedders to disable the find widget completely while retaining multicursor functionality.

## Best solution

Provide supported separation between multicursor's shared search functionality and the find UI in the microsoft/vscode editor core, then expose that separation through Monaco's feature entry points and webpack packaging.
