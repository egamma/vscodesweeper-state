# Issue #2732 — how to disabled find widget completely?

[https://github.com/microsoft/monaco-editor/issues/2732](https://github.com/microsoft/monaco-editor/issues/2732)

## Summary

A real capability gap remains: multicursor transitively includes the find controller, so embedders cannot retain multicursor while completely excluding the find widget. Route this existing feature request to the find and multicursor owners.

## Change summary

Allow embedders to disable or exclude the find widget while retaining multicursor support.

## Best solution

Decouple the multicursor find-state dependency from the find widget in the VS Code editor core, or expose an editor option that disables the widget without removing multicursor behavior. This would let Monaco's feature selection produce the requested smaller, restricted editor.
