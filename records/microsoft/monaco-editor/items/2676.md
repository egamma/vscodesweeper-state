# Issue #2676 — JavaScript syntax highlighting misidentifies `get` as a reserved keyword

[https://github.com/microsoft/monaco-editor/issues/2676](https://github.com/microsoft/monaco-editor/issues/2676)

## Summary

The bug remains on current main: JavaScript classifies every `get` identifier as a keyword. The existing `bug` and `grammars` labels already route this correctly.

## Change summary

JavaScript syntax highlighting incorrectly styles `get` as a keyword when it is used as an ordinary identifier.

## Best solution

Make the JavaScript Monarch grammar treat `get` contextually, preserving getter highlighting without classifying imports, variables, and calls named `get` as keywords. The relevant implementation is in `src/languages/definitions/javascript/javascript.ts` and its shared TypeScript tokenizer.
