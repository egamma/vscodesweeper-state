# Issue #3395 — [Bug] Wrong syntax highlighting in c++'s attribute specifiers

[https://github.com/microsoft/monaco-editor/issues/3395](https://github.com/microsoft/monaco-editor/issues/3395)

## Summary

The bug remains in current source: the C++ annotation tokenizer does not recognize string literals, so `using` and `alignas` inside attribute strings are incorrectly tokenized as keywords. The issue already has the appropriate grammar and basic-language routing labels.

## Change summary

C++ keywords inside string literals in attribute specifiers receive incorrect syntax highlighting.

## Best solution

Update the annotation tokenizer in `src/languages/definitions/cpp/cpp.ts` to enter the existing string-tokenization state for quoted attribute arguments, and add regression cases to `cpp.test.ts` covering `using`, `alignas`, and escaped quotes.
