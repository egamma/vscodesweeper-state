# Issue #3395 — [Bug] Wrong syntax highlighting in c++'s attribute specifiers

[https://github.com/microsoft/monaco-editor/issues/3395](https://github.com/microsoft/monaco-editor/issues/3395)

## Summary

The defect remains in the current C++ grammar: attribute arguments never enter string tokenization, so using and alignas inside quoted text become keywords. The linked PR was closed without merging, and this issue already has the correct routing labels.

## Change summary

C++ attribute string literals incorrectly highlight using and alignas as keywords.

## Best solution

Correct string-literal tokenization within attributes in src/languages/definitions/cpp/cpp.ts while preserving attribute syntax outside strings. This is bounded community-PR material with an existing tokenization test harness.
