# Issue #4497 — [Feature Request] Can we have a predicate to decide if a completion popup should be displayed?

[https://github.com/microsoft/monaco-editor/issues/4497](https://github.com/microsoft/monaco-editor/issues/4497)

## Summary

The current completion API has no provider-defined predicate controlling popup activation. Route to suggest for consideration in the VS Code editor core; existing filtering and manual triggering do not fully cover the requested hook.

## Change summary

Add a context-aware predicate that permits completion popups for identifier usage but suppresses them during declarations.

## Best solution

Evaluate a context-aware automatic-trigger hook in the VS Code editor core, preserving explicit completion requests and existing providers. Provider-side filtering and application-managed triggering remain alternatives, but neither supplies the requested integrated predicate.
