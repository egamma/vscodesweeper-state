[https://github.com/microsoft/monaco-editor/issues/264](https://github.com/microsoft/monaco-editor/issues/264)

## Summary

Keep open: JSX parsing is supported, but the bundled JavaScript/TypeScript tokenizer still lacks JSX-aware highlighting. This issue is the maintainer-designated tracking item, and the linked highlighting PR closed without merging.

## Change summary

Provide built-in JSX/TSX highlighting and clarify JSX-aware commenting support.

## Plan brief

- **Likely files:** `src/languages/definitions/typescript/typescript.ts`, `src/languages/definitions/javascript/javascript.ts`, `src/languages/definitions/typescript/typescript.test.ts`, `src/languages/definitions/javascript/javascript.test.ts`
- **Validation:** Add tokenization cases for nested JSX, fragments, attributes, expressions and keyword-like child text to the existing JavaScript/TypeScript suites; run npm run test:grammars. If commenting is included, also verify comment toggling inside JSX children and ordinary JavaScript in the playground.
- **Behavior:**

  > JSX and TSX receive built-in highlighting without an external tokenizer. Tags, attributes, child text and embedded expressions retain their distinct contexts across nested and multiline constructs; words such as 'for' in child text are not JavaScript keywords. Ordinary JavaScript operators and TypeScript generic syntax continue to highlight correctly. Whether this delivery also includes JSX-aware comment toggling remains to be decided.
- **Trace:**

  > src/languages/definitions/typescript/typescript.ts exports the shared Monarch tokenizer and ordinary // and /* */ comment configuration; javascript/javascript.ts reuses both. The tokenizer has no JSX state, so child text follows ordinary identifier and keyword rules. The separate TypeScriptWorker.getScriptKind path already recognizes .jsx/.tsx, and CompilerOptions.jsx controls parsing rather than this tokenizer. Existing testTokenization tests call editor.tokenize and assert token boundaries and types. Preserve ordinary JavaScript/TypeScript behavior and do not treat a TypeScript dependency update as a highlighting fix. https://github.com/microsoft/monaco-editor/pull/4650 is a closed, unmerged design reference; https://github.com/microsoft/monaco-editor/issues/1609#issuecomment-564444174 establishes this issue's ownership.
- **Open decisions:**
  - Should the initial built-in JSX delivery cover highlighting only, with JSX-aware comment toggling tracked separately, or include both behaviors?

## Evidence
