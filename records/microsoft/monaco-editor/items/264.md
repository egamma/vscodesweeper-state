# Issue #264 — Add support for JSX

[https://github.com/microsoft/monaco-editor/issues/264](https://github.com/microsoft/monaco-editor/issues/264)

## Summary

Keep open as the canonical JSX-support request. The TypeScript worker recognizes JSX/TSX models, but Monaco's built-in TypeScript tokenizer still lacks JSX syntax highlighting.

## Change summary

Provide native JSX and TSX support, particularly syntax highlighting, without requiring a custom tokenizer.

## Best solution

Extend the Monarch tokenizer in src/languages/definitions/typescript/typescript.ts to understand JSX while preserving existing TypeScript syntax. This is suitable community-PR work, consistent with the current help wanted label.
