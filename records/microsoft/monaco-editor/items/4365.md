# Issue #4365 — [Bug] DiffEditor updateOptions theme is not recognized by typescript

[https://github.com/microsoft/monaco-editor/issues/4365](https://github.com/microsoft/monaco-editor/issues/4365)

## Summary

The TypeScript error remains reproducible from current source: the standalone diff editor handles `theme` at runtime, but its public interface inherits the narrower `IDiffEditorOptions` signature. Route this API typing defect to `diff-editor` and `editor-api`.

## Change summary

Allow `theme` and other global editor options in the TypeScript signature for `IStandaloneDiffEditor.updateOptions`.

## Best solution

Update `IStandaloneDiffEditor` in the vscode editor core to expose `updateOptions(newOptions: IDiffEditorOptions & IGlobalEditorOptions)`, matching `StandaloneDiffEditor2`'s existing implementation; Monaco will receive the corrected declaration in a subsequent release cut.
