# Issue #2309 — Control markers rendering in minimap

[https://github.com/microsoft/monaco-editor/issues/2309](https://github.com/microsoft/monaco-editor/issues/2309)

## Summary

The requested disabling is already supported through minimap theme colors: transparent diagnostic colors suppress the minimap highlights without removing editor squiggles. A separate minimap setting is not necessary for the stated use case.

## Change summary

Allow embedders to disable noisy minimap highlights from spelling-error markers while retaining their editor annotations.

## Best solution

Use monaco.editor.defineTheme() to set minimap.errorHighlight and minimap.warningHighlight to #00000000, adding minimap.infoHighlight where supported. This is theme-wide control rather than filtering individual marker owners.

- **Proposed comment:**

  > Thanks for the context. You can hide these highlights while keeping the spelling squiggles by setting "minimap.errorHighlight": "#00000000" and "minimap.warningHighlight": "#00000000" in the colors passed to monaco.editor.defineTheme(), then selecting that theme. Versions supporting "minimap.infoHighlight" can make that transparent too. The minimap skips transparent decorations, independently of editor squiggles. These overrides affect all diagnostics of the corresponding severity in that theme, so the requested disabling is already available through the theme API.
