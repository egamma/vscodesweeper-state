# Issue #4509 — [Bug] Minimap sections visible only after text edit

[https://github.com/microsoft/monaco-editor/issues/4509](https://github.com/microsoft/monaco-editor/issues/4509)

## Summary

Already fixed in the VS Code editor core: section headers are now recomputed when tokenization completes, addressing headers that appeared only after an edit. The fix first shipped in Monaco v0.49.0.

## Change summary

MARK section headers should appear in the minimap immediately after editor creation rather than only after editing the model.

## Best solution

Keep the editor-core fix from https://github.com/microsoft/vscode/commit/622b60ba8fd32e1e2227f854fa17c53ad07f0150 and use Monaco v0.49.0 or newer.
