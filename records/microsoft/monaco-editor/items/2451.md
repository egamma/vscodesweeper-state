# Issue #2451 — Make monaco-editor use monaco-editor-core and friends

[https://github.com/microsoft/monaco-editor/issues/2451](https://github.com/microsoft/monaco-editor/issues/2451)

## Summary

A meaningful packaging gap remains. Monaco now builds from monaco-editor-core and offers modular entry points, but the published package still bundles core and language implementations rather than declaring them as regular dependencies.

## Change summary

Compose monaco-editor from separately consumable core and language packages so third-party plugins can target one compatible module identity.

## Best solution

Decide on a stable package-identity contract for plugins, then either publish monaco-editor as a dependency-based aggregate or document and enforce another compatible import target. This belongs in the packaging and integration architecture and should remain open for maintainer discussion.
