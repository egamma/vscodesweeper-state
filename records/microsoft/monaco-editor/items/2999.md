# Issue #2999 — [Feature Request] enable retention of size of docs popup 

[https://github.com/microsoft/monaco-editor/issues/2999](https://github.com/microsoft/monaco-editor/issues/2999)

## Summary

This is intentional editor-core behavior: documentation-popup dimensions persist only during the current suggestion session. VS Code maintainers previously declined the same request as designed.

## Change summary

Persist the resized completion-documentation popup dimensions across suggestion sessions.

## Best solution

Keep the current session-scoped sizing behavior inherited from VS Code; users can toggle the documentation widget when it obscures content.
