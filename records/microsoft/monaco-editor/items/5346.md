# Issue #5346 — [Bug] Imported `editor.api.js` doesn't expose the language namespaces anymore (moved in 0.55.0)

[https://github.com/microsoft/monaco-editor/issues/5346](https://github.com/microsoft/monaco-editor/issues/5346)

## Summary

The namespace-access problem has a supported solution in v0.56.0, but the issue remains useful as ESM documentation debt: current samples still use the deprecated editor.api entry point and integrate-esm.md does not explain the new tree-shakeable imports.

## Change summary

Document and demonstrate how custom ESM bundles import the editor, selected language definitions, and typed language-feature namespaces.

## Best solution

Update docs/integrate-esm.md and the ESM Vite/React samples to use monaco-editor/editor plus the supported feature, language-definition, and language-feature register entry points, including individual language-feature imports where appropriate.
