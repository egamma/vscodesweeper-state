# Issue #5346 — [Bug] Imported `editor.api.js` doesn't expose the language namespaces anymore (moved in 0.55.0)

[https://github.com/microsoft/monaco-editor/issues/5346](https://github.com/microsoft/monaco-editor/issues/5346)

## Summary

The central problem is resolved by the typed, per-language entry points shipped in v0.56.0. TypeScript can be imported independently without registering every language; the documentation concerns remain useful follow-up work.

## Change summary

Expose typed language configuration APIs when importing a minimal editor bundle without loading every language.

## Best solution

Use monaco-editor/editor together with a namespace import from monaco-editor/languages/features/typescript/register. Retain the modular exports introduced by the cited commit and update the older integration examples separately.

  > import * as monaco from 'monaco-editor/editor';
