# Issue #953 — Provide ability to block editing specific lines

[https://github.com/microsoft/monaco-editor/issues/953](https://github.com/microsoft/monaco-editor/issues/953)

## Summary

This request is now tracked by the open VS Code editor-core issue for read-only ranges and lines. Consolidating there matches Monaco's generated-from-VS-Code architecture while preserving the educational and template-editing use cases documented here.

## Change summary

Add an editor API that restricts modifications to designated lines or character ranges.

## Best solution

Implement read-only ranges in the VS Code editor core through https://github.com/microsoft/vscode/issues/88885, then deliver the API to Monaco through its normal source-generation and release pipeline.
