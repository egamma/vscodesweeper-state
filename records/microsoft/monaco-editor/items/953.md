## Evidence

- **Verified cross-repository canonical:** https://github.com/microsoft/vscode/issues/88885 is currently open and assigned to Backlog. Its body requests read-only ranges within an otherwise editable document, preserving protected content for reference and copying; it also identifies search-editor use cases. This encompasses the requested line and function-boundary protection.
- **Re-review ownership requirement:** The upstream issue was created in 2020, later than this 2018 report, but its assigned Backlog milestone satisfies the project-tracked exception for re-reviewed items. Both request the same observable capability: preventing edits within selected portions of an editable document.
- **Explicit connection:** https://github.com/microsoft/vscode/issues/88885#issuecomment-1521660898 explicitly links this Monaco discussion as related work.
- **Existing capability does not cover the request:** Current https://github.com/microsoft/vscode/blob/main/src/vs/editor/common/config/editorOptions.ts declares readOnly as an editor-wide boolean and readOnlyMessage as its message; neither provides protected ranges. The model interface in https://github.com/microsoft/vscode/blob/main/src/vs/editor/common/model.ts exposes onDidChangeContent, but no matching setEditableRange or onWillChangeContent API was found.
- **Workaround limitations and unique evidence:** https://github.com/microsoft/monaco-editor/issues/953#issuecomment-3164712473 tracks editable ranges with decorations and toggles editor-wide readOnly on selection changes. https://github.com/microsoft/monaco-editor/issues/953#issuecomment-3416440909 reports that editor.action.moveLinesUpAction defeats selection-based restrictions while protecting a function signature and closing brace. Earlier comments also describe redo and formatting limitations of undo-based enforcement.
- **Implementation boundary:** README.md confirms the editor core is generated from VS Code. This checkout consumes monaco-editor-core rather than owning the editor's edit-enforcement implementation, so native range protection belongs in the shared upstream core.
