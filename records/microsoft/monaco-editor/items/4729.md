# Issue #4729 — [Bug] Sticky scroll widget is rendered incorrectly after font size update

[https://github.com/microsoft/monaco-editor/issues/4729](https://github.com/microsoft/monaco-editor/issues/4729)

## Summary

The reported font-size mismatch is fixed in the editor core bundled with Monaco v0.57.0. Font configuration changes now explicitly rebuild visible sticky lines rather than retaining their previous font styling.

## Change summary

Changing fontSize through updateOptions leaves visible sticky-scroll lines rendered with the previous font size.

## Best solution

Treat this as resolved by https://github.com/microsoft/vscode/commit/70a1d06d93f6a90d3cae4bf84754b096d818ef40, shipped in Monaco v0.57.0; no Monaco-specific change is needed.
