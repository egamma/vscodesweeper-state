# Issue #4892 — [Bug] Some text keystrokes do not work in Firefox when accessibilitySupport = on

[https://github.com/microsoft/monaco-editor/issues/4892](https://github.com/microsoft/monaco-editor/issues/4892)

## Summary

Confirmed Firefox/Windows editor-core bug: forcing accessibility support breaks keyboard word navigation and selection. The related VS Code issue tracks a narrower symptom and does not absorb this broader report, so this should remain open and be routed to accessibility/input owners.

## Change summary

On Firefox for Windows, accessibilitySupport set to on prevents Ctrl+Arrow word navigation and Ctrl+Shift+Arrow selection.

## Best solution

Fix the accessibility-mode keyboard handling in the VS Code editor core so Firefox preserves standard Windows word-navigation and selection commands, then consume that fix in the next Monaco release. Coordinate with the related VS Code report without folding this broader issue into its narrower replacement-text symptom.
