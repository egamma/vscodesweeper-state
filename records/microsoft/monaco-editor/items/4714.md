# Issue #4714 — [Bug] DiffEditor does not emit dispose event

[https://github.com/microsoft/monaco-editor/issues/4714](https://github.com/microsoft/monaco-editor/issues/4714)

## Summary

Still present in the current VS Code editor core: DiffEditorWidget inherits an onDidDispose emitter that is disposed without ever being fired. Route this valid API-contract bug to the diff-editor area.

## Change summary

Disposing a diff editor does not emit its documented onDidDispose event.

## Best solution

Fix DelegatingEditor in the VS Code editor core to fire its disposal event exactly once before disposing the emitter, with a diff-editor lifecycle test; the change will flow into Monaco with a subsequent release.

  > Thanks for the report and playground reproduction. This remains visible in the current editor-core source: `IEditor` documents `onDidDispose`, but `DelegatingEditor` disposes the registered emitter without firing it. The related leak fix in https://github.com/microsoft/vscode/commit/70c82b00a938a82ec62ff80c7f72f4b94b898ca2 only removes the diff editor from the editor service and does not address this event. ## Evidence

- **API contract:** Current VS Code source at https://github.com/microsoft/vscode/blob/main/src/vs/editor/common/editorCommon.ts documents IEditor.onDidDispose as an event emitted when the editor is disposed; IDiffEditor extends that interface.
- **current implementation:** https://github.com/microsoft/vscode/blob/main/src/vs/editor/browser/widget/diffEditor/delegatingEditorImpl.ts registers _onDidDispose with the Disposable store but contains no dispose override or _onDidDispose.fire() call, so disposing the diff editor only disposes the emitter.
- **related issue is distinct:** https://github.com/microsoft/monaco-editor/issues/4659 tracks retained diff-editor references and memory leakage. Its merged fix https://github.com/microsoft/vscode/commit/70c82b00a938a82ec62ff80c7f72f4b94b898ca2 removes the editor from ICodeEditorService but does not fire onDidDispose, so it does not subsume this report.
