# Issue #3105 — [Bug] monaco.editor.colorize does not work as expected with json language

[https://github.com/microsoft/monaco-editor/issues/3105](https://github.com/microsoft/monaco-editor/issues/3105)

## Summary

The bug remains traceable on current main: JSON tokenization is installed only after language activation, while `colorize` requests an existing tokenizer or factory without activating the language. The existing json and grammars routing is appropriate, so this should remain open.

## Change summary

`monaco.editor.colorize` and `colorizeElement` return unhighlighted output for JSON until another operation activates the JSON language.

## Best solution

Register a lazy JSON tokenization factory in `src/languages/features/json/register.ts`, allowing `Colorizer.getOrCreate` to initialize syntax tokenization without creating a model or starting the full JSON worker. The existing model-activation path can continue installing the remaining language-service providers.

## Evidence
