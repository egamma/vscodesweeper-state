# Issue #3105 — [Bug] monaco.editor.colorize does not work as expected with json language

[https://github.com/microsoft/monaco-editor/issues/3105](https://github.com/microsoft/monaco-editor/issues/3105)

## Summary

Keep open: the current JSON registration and pinned editor-core source still explain why standalone colorization returns unhighlighted text before JSON mode initializes. The semantic-token request is not a duplicate, and the linked downstream PR remains open.

## Change summary

JSON colorize and colorizeElement calls should produce syntax-highlighted HTML without first creating an editor or manually initializing JSON mode.

## Best solution

Make standalone JSON tokenization available and awaitable without requiring editor-model initialization. Resolve the boundary between Monaco's JSON provider registration and the VS Code standalone colorizer; explicit setupMode calls are a workaround, not coverage of the reported behavior.
