# Issue #4614 — [Feature Request] monaco-esbuild-plugin

[https://github.com/microsoft/monaco-editor/issues/4614](https://github.com/microsoft/monaco-editor/issues/4614)

## Summary

The team explicitly does not want a Monaco-specific esbuild plugin because maintaining separate plugins for each bundler is unsustainable. The intended direction is tree-shakeable Monaco entry points plus a generic worker-URL plugin shared across bundlers.

## Change summary

Provide an official esbuild plugin with Monaco language, feature, and worker configuration comparable to the webpack plugin.

## Best solution

Keep Monaco bundler-neutral: use the supported tree-shakeable entry points for feature selection and the generic `@vscode/esbuild-plugin-esm-url` for workers. Continue the broader plugin-removal work in https://github.com/microsoft/monaco-editor/issues/5152 rather than adding another Monaco-specific plugin.

## Vision fit
