# Issue #4653 — [Bug] Placeholder doesn't display whitespaces

[https://github.com/microsoft/monaco-editor/issues/4653](https://github.com/microsoft/monaco-editor/issues/4653)

## Summary

The confirmed rendering bug remains in the current vscode editor core: placeholder text is rendered with collapsing whitespace, so indentation after a newline is lost. The issue is already routed correctly and should remain open.

## Change summary

Multiline editor placeholder text collapses leading whitespace, leaving indented lines aligned to the left.

## Best solution

Preserve whitespace in the vscode editor core's placeholder overlay CSS, likely in `src/vs/editor/contrib/placeholderText/browser/placeholderText.css`, while retaining the intended no-wrap and overflow behavior; the fix will then flow into Monaco.
