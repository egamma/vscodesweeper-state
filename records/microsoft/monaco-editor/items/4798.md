# Issue #4798 — [Bug] Monarch: Markdown syntax highlighting: continuation lines of list items rendered as code blocks

[https://github.com/microsoft/monaco-editor/issues/4798](https://github.com/microsoft/monaco-editor/issues/4798)

## Summary

The bug remains in current main: Markdown list continuations indented by four spaces still match the top-level indented-code rule. This is the requested successor to the closed earlier report and should be routed to the grammar owners.

## Change summary

Markdown list continuation lines are incorrectly highlighted as indented code blocks.

## Best solution

Update the Markdown Monarch grammar in src/languages/definitions/markdown/markdown.ts to track list context and distinguish continuation content from genuine indented code blocks. This remains suitable for a community PR, as noted in the earlier maintainer response.
