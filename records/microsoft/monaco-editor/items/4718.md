# Issue #4718 — [Feature Request] Parcel builds monaco-editor with all languages supported out of the box - limiting feature

[https://github.com/microsoft/monaco-editor/issues/4718](https://github.com/microsoft/monaco-editor/issues/4718)

## Summary

Implemented in v0.56.0: Monaco now provides supported, tree-shakeable ESM entry points for selecting individual language definitions and features, covering Parcel bundles that should not include every language.

## Change summary

Allow Parcel-based applications to bundle only the Monaco languages they use.

## Best solution

Use `monaco-editor/editor` with the required `monaco-editor/languages/definitions/<language>/register` and language-feature registration entry points introduced by PR https://github.com/microsoft/monaco-editor/pull/5155 and released in v0.56.0.
