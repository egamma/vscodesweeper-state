# Issue #4718 — [Feature Request] Parcel builds monaco-editor with all languages supported out of the box - limiting feature

[https://github.com/microsoft/monaco-editor/issues/4718](https://github.com/microsoft/monaco-editor/issues/4718)

## Summary

The requested language-selection capability shipped in v0.56.0: supported ESM entry points let Parcel applications import the editor and only their chosen languages. The default import intentionally remains all-inclusive.

## Change summary

Allow Parcel builds to include only selected Monaco languages rather than bundling every language.

## Best solution

Use monaco-editor/editor with explicitly selected language registration imports and the required worker configuration; no Parcel-specific plugin is needed for language selection.

  > Thanks for the request. This capability shipped in v0.56.0 through the ESM entry-point reorganization: https://github.com/microsoft/monaco-editor/commit/558bbbcc1619da88d466bd64856f337a5604e43c. Import the editor from `monaco-editor/editor`, optionally add `monaco-editor/features/register.all`, and register only the languages you need—for example, `monaco-editor/languages/definitions/javascript/register`. Language services can also be selected individually, such as `monaco-editor/languages/features/typescript/register`, with the corresponding worker configuration. The default `monaco-editor` import still includes all languages, so replace that import to create a selective bundle. This addresses the requested language-selection capability without a Parcel-specific plugin.
