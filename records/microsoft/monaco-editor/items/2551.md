# Issue #2551 — Support Pure Javascript/Typescript Expression

[https://github.com/microsoft/monaco-editor/issues/2551](https://github.com/microsoft/monaco-editor/issues/2551)

## Summary

A genuine TypeScript language-service capability remains missing: current main registers only JavaScript and TypeScript document modes, without an expression-only parsing context. The previously linked issue is closed and therefore cannot serve as a duplicate canonical.

## Change summary

Provide JavaScript and TypeScript language modes that accept only expressions rather than complete programs or statements.

## Best solution

Add an expression-document context in the TypeScript language integration under src/languages/features/typescript, preserving correct diagnostics and position mapping. This should remain open as a feature request routed to the TypeScript area.
