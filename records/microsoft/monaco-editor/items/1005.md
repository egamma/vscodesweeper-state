# Issue #1005 — Possible to only show scrollbar upon scroll?

[https://github.com/microsoft/monaco-editor/issues/1005](https://github.com/microsoft/monaco-editor/issues/1005)

## Summary

The requested scroll-only visibility mode remains absent: auto reveals scrollbars on hover and prevents idle hiding while the pointer remains over the editor. Keep this accepted Backlog request open; the capability belongs in the VS Code-derived scrollbar implementation.

## Change summary

Add an optional scrollbar mode that reveals on scrolling and hides after inactivity, including while the pointer remains over the editor.

## Best solution

Introduce an opt-in scroll-only visibility policy in the VS Code editor core while preserving existing modes and scrollbar dragging. The maintainer's question about VS Code applicability should be resolved there, with the resulting capability exposed through Monaco's scrollbar options.
