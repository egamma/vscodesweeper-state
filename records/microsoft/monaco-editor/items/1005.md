# Issue #1005 — Possible to only show scrollbar upon scroll?

[https://github.com/microsoft/monaco-editor/issues/1005](https://github.com/microsoft/monaco-editor/issues/1005)

## Summary

A distinct capability gap remains: the current `auto` mode reveals scrollbars both while scrolling and while hovering, so it cannot provide scroll-only visibility. The issue is already correctly classified and parked in Backlog.

## Change summary

Add a scrollbar visibility mode that reveals the scrollbar during scrolling and hides it after scrolling stops, without revealing it merely on hover.

## Best solution

Add a distinct visibility policy in the VS Code scrollbar core that reveals on scroll but not hover, then let the change flow into Monaco with the next release cut. This looks suitable for an editor-core contribution after the team confirms the desired interaction and timeout.

## Evidence

- **distinct request:** The open candidate issues https://github.com/microsoft/monaco-editor/issues/4374 and https://github.com/microsoft/monaco-editor/issues/4599 concern scrollbar styling and wheel propagation respectively, not visibility triggered exclusively by scrolling.
