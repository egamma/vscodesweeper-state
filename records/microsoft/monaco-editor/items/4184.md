# Issue #4184 — [Bug] Many duplicates in minified tsWorker.js leading to large file

[https://github.com/microsoft/monaco-editor/issues/4184](https://github.com/microsoft/monaco-editor/issues/4184)

## Summary

The size debt remains on current main: the TypeScript import generator embeds every declaration library verbatim, including declarations shared by multiple environments. Route to the TypeScript area; no broader canonical issue was found.

## Change summary

Reduce duplicated TypeScript declaration text in the generated worker bundle so it can satisfy constrained extension-package size limits.

## Best solution

Optimize build/importTypescript.ts and the TypeScript worker's library representation to share repeated declaration content without changing the individual lib files exposed to the language service. This remains suitable for a community PR, while any solution should target the current shared worker pipeline rather than the deprecated AMD surface alone.
