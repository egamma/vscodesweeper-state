# Issue #5192 — [Bug] Option `editor.selectionForeground` does not work

[https://github.com/microsoft/monaco-editor/issues/5192](https://github.com/microsoft/monaco-editor/issues/5192)

## Summary

Verified cross-repository duplicate: selection foreground colors are intentionally limited to high-contrast themes in the shared editor core, and support for ordinary themes is already tracked by the open vscode issue.

## Change summary

Allow `editor.selectionForeground` to override selected text colors in non-high-contrast Monaco themes.

## Best solution

Consolidate this request on https://github.com/microsoft/vscode/issues/36490. The editor core likely needs an explicit opt-in setting that permits the additional text-layer rendering cost; that implementation will flow into Monaco through its regular VS Code source update.
