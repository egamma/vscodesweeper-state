# Issue #4418 — [Bug] No alternate for getDiffLineInformationForOriginal or getDiffLineInformationForModified in diff editor

[https://github.com/microsoft/monaco-editor/issues/4418](https://github.com/microsoft/monaco-editor/issues/4418)

## Summary

This is an API migration question rather than a defect: `getLineChanges()` remains available and exposes the original-to-modified line ranges needed to derive line mappings.

## Change summary

Identify a replacement for two diff-editor line-mapping methods removed in Monaco 0.40.0.

## Best solution

Use `IDiffEditor.onDidUpdateDiff` followed by `getLineChanges()` and derive the required mapping from each change's original and modified start/end line numbers.
