# Issue #4418 — [Bug] No alternate for getDiffLineInformationForOriginal or getDiffLineInformationForModified in diff editor

[https://github.com/microsoft/monaco-editor/issues/4418](https://github.com/microsoft/monaco-editor/issues/4418)

## Summary

This asks how to migrate from two explicitly removed APIs, rather than reporting broken supported behavior. The supported getLineChanges() API exposes diff ranges, although it is not a drop-in equivalent-line lookup.

## Change summary

Find an alternative for mapping original and modified line positions after the v0.40.0 API removal.

## Best solution

Explain how getLineChanges() and onDidUpdateDiff expose the information needed for application-side line mapping, without promising a direct replacement or planned API.

- **Proposed comment:**

  > Thanks for the report. Those two methods were explicitly removed in v0.40.0. The supported alternative for obtaining diff information is getLineChanges(), read after onDidUpdateDiff; it returns the original and modified line ranges for each change. It is not a drop-in equivalent-line lookup, so mapping individual lines requires application-side logic, including handling inserted and deleted ranges.
  > 
  > Closing this as a migration/support question rather than a defect in a supported API. Further usage questions belong on StackOverflow under the monaco-editor tag: https://stackoverflow.com/questions/tagged/monaco-editor.
