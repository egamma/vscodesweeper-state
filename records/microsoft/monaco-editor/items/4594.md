The screenshot shows a worker-response cloning failure in Monaco 0.45.0, not merely a question about diagnostics. The matching getEmitOutput serialization fix is present on main and documented in v0.50.0.

## Change summary

Calling TypeScriptWorker.getEmitOutput fails to return errors because its response contains non-cloneable diagnostic data.
