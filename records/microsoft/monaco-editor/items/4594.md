# Issue #4594 — How to listen for TypeScriptWorker errors when executing getEmitOutput

[https://github.com/microsoft/monaco-editor/issues/4594](https://github.com/microsoft/monaco-editor/issues/4594)

## Summary

The screenshot uses monaco v0.45.0 and shows a DataCloneError caused by unserializable TypeScript emit diagnostics. The worker now sanitizes those diagnostics, with the fix shipped in v0.50.0.

## Change summary

Calling TypeScriptWorker.getEmitOutput can reject with a DataCloneError when emit diagnostics contain unserializable file data.

## Best solution

Use monaco v0.50.0 or newer, where getEmitOutput returns sanitized diagnostics instead of failing worker message serialization.
