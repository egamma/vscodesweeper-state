# Issue #4887 — using linesDecorationsClassName we able to show vertical bar with some color, is posible to show on right side of the editor?

[https://github.com/microsoft/monaco-editor/issues/4887](https://github.com/microsoft/monaco-editor/issues/4887)

## Summary

This is a usage question already covered by the decoration API: an overview-ruler decoration can render a colored marker in the editor's right-side ruler.

## Change summary

Show a colored vertical decoration on the right side of the editor.

## Best solution

Set the decoration's `overviewRuler` option with a color and `monaco.editor.OverviewRulerLane.Right`; no new editor capability is needed.

- **Proposed comment:**

  > Thanks for the playground example. This is supported through the decoration's overview-ruler options rather than `linesDecorationsClassName`:
  > 
  > ```js
  > options: {
  >   isWholeLine: true,
  >   overviewRuler: {
  >     color: "green",
  >     position: monaco.editor.OverviewRulerLane.Right
  >   }
  > }
  > ```
  > 
  > That renders the colored marker in the ruler on the editor's right side. For future Monaco usage questions, please use the StackOverflow `monaco-editor` tag: https://stackoverflow.com/questions/tagged/monaco-editor.
