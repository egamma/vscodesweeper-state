# Issue #4887 — using linesDecorationsClassName we able to show vertical bar with some color, is posible to show on right side of the editor?

[https://github.com/microsoft/monaco-editor/issues/4887](https://github.com/microsoft/monaco-editor/issues/4887)

## Summary

This is an API usage question: colored range markers on the editor's right side are supported through the overviewRuler decoration option.

## Change summary

Show a colored vertical range marker on the right side instead of the left line-decoration gutter.

## Best solution

Use overviewRuler with a color and monaco.editor.OverviewRulerLane.Right in the existing decoration collection. Explain that these are document-scaled overview markers, not a relocated line-height gutter.

- **Proposed comment:**

  > Thanks for the example. For a colored marker on the editor's right side, use `overviewRuler: { color: '#ff0000', position: monaco.editor.OverviewRulerLane.Right }` in your decoration's `options`. Unlike `linesDecorationsClassName`, this draws a document-scaled marker in the overview ruler, rather than a line-height bar beside the text. This is supported API usage, so closing as a question. Further usage questions belong on https://stackoverflow.com/questions/tagged/monaco-editor.
