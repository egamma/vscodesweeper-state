# Issue #3829 — bracketPairColorization: { enabled: false } does not work

[https://github.com/microsoft/monaco-editor/issues/3829](https://github.com/microsoft/monaco-editor/issues/3829)

## Summary

Still present in the current vscode editor core: Monaco's typed nested option is not converted into the flattened configuration key, while the dotted workaround is. This team-authored issue remains the best canonical report and should stay open.

## Change summary

Passing bracketPairColorization as a typed object fails to disable colorization, although the equivalent dotted configuration key works.

## Best solution

Fix updateConfigurationService in the vscode standalone editor core to map recognized nested editor options such as bracketPairColorization.enabled to their flattened configuration keys; the correction will then flow into Monaco with a release cut.
