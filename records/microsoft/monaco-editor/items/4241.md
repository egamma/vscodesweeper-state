# Issue #4241 — [Feature Request] Need to listen to the suggestion selected event

[https://github.com/microsoft/monaco-editor/issues/4241](https://github.com/microsoft/monaco-editor/issues/4241)

## Summary

This is a support question about an existing API: a completion item can specify a command that Monaco runs when the item is accepted.

## Change summary

Provide a way to observe when a user accepts a suggestion.

## Best solution

Register a command with `monaco.editor.addCommand` and assign its ID to each provided `CompletionItem.command`; the command handler receives notification after that item is accepted. This hook covers completion items controlled by the provider, rather than exposing a global suggestion-selection event.

  > Thanks for the question. This is supported through `CompletionItem.command`: register a handler with `monaco.editor.addCommand`, then set that command's ID on each completion item returned by your provider. Monaco runs the command after the item is accepted, and `arguments` can identify the selected item. This is a per-item acceptance hook rather than a global event for every suggestion shown by Monaco. For further usage help, please use StackOverflow's `monaco-editor` tag: https://stackoverflow.com/questions/tagged/monaco-editor.
