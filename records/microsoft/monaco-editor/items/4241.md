# Issue #4241 — [Feature Request] Need to listen to the suggestion selected event

[https://github.com/microsoft/monaco-editor/issues/4241](https://github.com/microsoft/monaco-editor/issues/4241)

## Summary

This asks how to observe completion acceptance, which the existing CompletionItem.command API supports. Propose answering with the supported pattern and closing as a usage question.

## Change summary

Explain how an embedder can receive notification when a user accepts a completion item.

## Best solution

Register a handler with monaco.editor.registerCommand and attach its command ID and item-identifying arguments to each supplied CompletionItem.command. Distinguish acceptance from highlighting a suggestion or globally observing other providers' items.

- **Proposed comment:**

  > Thanks for the question. For notification when a user accepts a completion item you provide, register a handler with `monaco.editor.registerCommand('completionAccepted', (_accessor, itemId) => { /* handle acceptance */ })`, then set that item's `command` to `{ id: 'completionAccepted', title: 'Completion accepted', arguments: [itemId] }`. The handler runs when that item is accepted, not when it is highlighted in the suggestion list; this is not a global subscription to other providers' suggestions.
  > 
  > This is supported through the existing API, so we're closing this as a usage question. Further usage questions belong at https://stackoverflow.com/questions/tagged/monaco-editor.
