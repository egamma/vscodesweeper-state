# Issue #1885 — API to talk with the language server of a language

[https://github.com/microsoft/monaco-editor/issues/1885](https://github.com/microsoft/monaco-editor/issues/1885)

## Summary

A real API gap remains: Monaco registers HTML outline and hover providers internally but exposes no supported API for embedders to invoke them or access the HTML worker. The issue is already appropriately classified and routed.

## Change summary

Expose supported APIs for custom UI to query outline, hover documentation, and other language features from Monaco's bundled language services.

## Best solution

Provide a supported, typed way to invoke registered language features across bundled languages, preferably through the native LSP direction rather than exposing each private worker implementation. Coordinate this with the CSS/JSON/HTML LSP migration tracked at https://github.com/microsoft/monaco-editor/issues/5066.
