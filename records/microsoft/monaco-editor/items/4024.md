# Issue #4024 — API for collapsing ranges

[https://github.com/microsoft/monaco-editor/issues/4024](https://github.com/microsoft/monaco-editor/issues/4024)

## Summary

A real public-API gap remains: commands can collapse known lines, but current editor-core APIs still do not expose the collapsed folding ranges. The issue already has the appropriate feature-request and folding labels and is accepted in Backlog.

## Change summary

Expose supported APIs to read collapsed ranges and restore or programmatically apply folding after editor content refreshes.

## Best solution

Add a public folding-state API in the vscode editor core that returns collapsed ranges and supports restoring them, then inherit it through Monaco's generated API. This looks suitable for a contributor PR after the editor API shape is agreed.

## Vision fit

- **Fit:** aligned
- **Reason:** A supported editor API for folding state advances Monaco's role as the browser-consumable form of the VS Code editor core.
- **Evidence:** The README describes Monaco as “generated straight from VS Code's sources with some shims around services the code needs to make it run in a web browser,” and tracking the vscode editor core is a durable theme.

## Evidence

- **current folding implementation:** Current vscode folding source keeps collapsed regions in the internal FoldingStateMemento and accesses them through FoldingModel.getMemento/applyMemento rather than a public editor API: https://github.com/microsoft/vscode/blob/a7faf30ddfa92f45fd0162984f287fc8fee0294c/src/vs/editor/contrib/folding/browser/folding.ts
- **public API gap:** The current public editor interface exposes onDidChangeHiddenAreas as Event<void> and whole-editor saveViewState/restoreViewState, but no method returning collapsed or hidden ranges: https://github.com/microsoft/vscode/blob/0c018c2a75be2027c8a3146af5e565f04c9a6f6e/src/vs/editor/browser/editorBrowser.ts
- **partial command support:** https://github.com/microsoft/vscode/pull/201315 merged support for forwarding arguments to editor actions, enabling editor.trigger(null, 'editor.fold', ...), but it does not provide the requested read API.
- **maintainer confirmation:** A maintainer confirmed in https://github.com/microsoft/monaco-editor/issues/4024#issuecomment-1864861801 that there was no way to retrieve currently collapsed regions.
