# Issue #2115 — Ability to turn off Screen Reader Mode via shortcut

[https://github.com/microsoft/monaco-editor/issues/2115](https://github.com/microsoft/monaco-editor/issues/2115)

## Summary

Keep the request open and route it to accessibility and keybindings. Embedders can implement a disabling shortcut, but that does not establish an existing built-in shortcut satisfying the end-user request.

## Change summary

Provide an end-user keyboard shortcut to disable screen-reader mode after enabling it.

## Best solution

Evaluate a discoverable, reversible screen-reader-mode command in the VS Code standalone editor sources that Monaco inherits. Preserve embedder control through accessibilitySupport; a custom action is a workaround, not coverage of the requested built-in behavior.
