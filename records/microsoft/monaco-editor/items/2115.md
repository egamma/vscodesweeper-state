# Issue #2115 — Ability to turn off Screen Reader Mode via shortcut

[https://github.com/microsoft/monaco-editor/issues/2115](https://github.com/microsoft/monaco-editor/issues/2115)

## Summary

A real accessibility gap remains: current standalone-editor messaging offers Command/Ctrl+E to enable screen-reader optimization but no equivalent built-in action to disable it. Route this to accessibility; the editor option provides an embedder workaround but does not satisfy the end-user shortcut request.

## Change summary

Provide a keyboard-accessible way to disable screen-reader optimized mode after enabling it from Accessibility Help.

## Best solution

Add a genuine toggle action in the vscode standalone editor core and expose it from Accessibility Help, while retaining `accessibilitySupport: 'auto' | 'off' | 'on'` for programmatic control. This should land in microsoft/vscode and flow into Monaco with a release cut.
