# Issue #5128 — [Feature Request] Add documentSelector to MonacoLspClient

[https://github.com/microsoft/monaco-editor/issues/5128](https://github.com/microsoft/monaco-editor/issues/5128)

## Summary

The requested filtering remains absent on current main: MonacoLspClient synchronizes every existing and newly created model. This is a valid native-LSP API gap with no verified canonical issue or existing option covering it.

## Change summary

Allow MonacoLspClient consumers to select which Monaco models are synchronized with a language server.

## Best solution

Add a client-level DocumentSelector option in monaco-lsp-client/src/adapters/LspClient.ts and apply it in TextDocumentSynchronizer before sending didOpen, didChange, and didClose notifications. The existing selector-matching machinery should be reused or completed so language, scheme, and pattern filters behave consistently.
