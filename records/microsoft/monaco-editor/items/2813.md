# Issue #2813 — [Bug] Sometimes Monaco loads extraLibs into models which causes IntelliSense to blow up

[https://github.com/microsoft/monaco-editor/issues/2813](https://github.com/microsoft/monaco-editor/issues/2813)

## Summary

The duplicate extra-lib/model path remains in current source and can corrupt TypeScript results or exhaust memory. This is the oldest, broadest report of the root cause and should remain the canonical issue.

## Change summary

Extra libraries materialized as editor models are submitted twice to the TypeScript language service, breaking IntelliSense and potentially exhausting memory.

## Best solution

Update src/languages/features/typescript/tsWorker.ts to exclude mirror models already represented by extra libs, while preserving peek-definition models. Review and land the approach in https://github.com/microsoft/monaco-editor/pull/4544 with regression coverage for this issue.
