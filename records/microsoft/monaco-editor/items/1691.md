# Issue #1691 — Expose undo stops in API?

[https://github.com/microsoft/monaco-editor/issues/1691](https://github.com/microsoft/monaco-editor/issues/1691)

## Summary

Keep open: the public API still lacks notifications identifying automatically created undo boundaries. Existing stack-control methods do not satisfy this accepted Backlog request, and no matching open canonical was found.

## Change summary

Expose undo-boundary notifications so embedders can coordinate undo across multiple Monaco models and their surrounding document.

## Best solution

Design a supported undo-boundary observation API in the VS Code editor core and expose it through Monaco's generated API, preserving existing undo grouping. It should distinguish meaningful stack boundaries from no-op calls without requiring private-state inspection.
