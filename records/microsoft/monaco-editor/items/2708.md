# Issue #2708 — ondidicreacteEditor callBack Can't addcommand

[https://github.com/microsoft/monaco-editor/issues/2708](https://github.com/microsoft/monaco-editor/issues/2708)

## Summary

Still present in the current editor core: `onDidCreateEditor` fires before `StandaloneCodeEditor` initializes the keybinding service, so calling `addCommand` synchronously returns `null`. Route this confirmed lifecycle bug to the editor API and commands areas.

## Change summary

Allow commands to be registered synchronously from an `onDidCreateEditor` callback.

## Best solution

Adjust the vscode standalone-editor lifecycle so the public creation event fires only after `StandaloneCodeEditor` has completed initialization, while preserving internal editor registration semantics.
