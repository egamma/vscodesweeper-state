# Issue #2708 — ondidicreacteEditor callBack Can't addcommand

[https://github.com/microsoft/monaco-editor/issues/2708](https://github.com/microsoft/monaco-editor/issues/2708)

## Summary

The initialization-order defect remains in current VS Code source: onDidCreateEditor fires before the standalone keybinding service is assigned, so synchronous addCommand returns null. Route to editor-api; the fix belongs in the VS Code editor sources.

## Change summary

Calling editor.addCommand synchronously inside onDidCreateEditor returns null instead of registering the command.

## Best solution

Make command registration work during onDidCreateEditor in microsoft/vscode's standalone editor implementation, then deliver the fix through a Monaco release. Preserve this focused bug separately from the broader request for a readiness event.
