# Issue #1899 — Code actions / quick fixes from VS Code

[https://github.com/microsoft/monaco-editor/issues/1899](https://github.com/microsoft/monaco-editor/issues/1899)

## Summary

A real capability gap remains: Monaco exposes TypeScript diagnostic quick fixes but not TypeScript refactors such as “Convert to template string.” The issue is already correctly classified and routed to the TypeScript area.

## Change summary

Expose TypeScript code actions and refactors available in VS Code through Monaco's built-in TypeScript integration.

## Best solution

Extend the TypeScript worker and CodeActionAdaptor to expose applicable TypeScript language-service refactors and apply their edits, while limiting the scope to browser-compatible TypeScript actions rather than every VS Code-specific provider. This looks suitable for a community PR.
