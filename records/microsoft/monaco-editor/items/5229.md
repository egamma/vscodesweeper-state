# Issue #5229 — [Bug] In Code Editor Monaco, pressing Insert on keyboard does not stop following characters from being moved to the right

[https://github.com/microsoft/monaco-editor/issues/5229](https://github.com/microsoft/monaco-editor/issues/5229)

## Summary

Standalone Monaco lacks VS Code's Insert-key action for toggling overtype mode. This is a missing parity capability rather than incorrect insertion behavior; keep it open and route to keybindings.

## Change summary

Allow pressing Insert to toggle between inserting characters and overwriting following characters.

## Best solution

Provide a supported standalone overtype toggle in the VS Code-derived editor, including its keyboard binding. Existing cursor and paste options do not enable the mode, and the related state-exposure request does not own this keyboard behavior.
