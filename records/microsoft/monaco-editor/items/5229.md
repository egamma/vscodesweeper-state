# Issue #5229 — [Bug] In Code Editor Monaco, pressing Insert on keyboard does not stop following characters from being moved to the right

[https://github.com/microsoft/monaco-editor/issues/5229](https://github.com/microsoft/monaco-editor/issues/5229)

## Summary

Overtype editing exists in the shared editor core, but the Insert-key toggle is currently a VS Code workbench action rather than a Monaco standalone action. This is a valid standalone-editor feature gap, not broken existing Monaco behavior.

## Change summary

Allow the Insert key to toggle Monaco between insert and overtype modes as it does in VS Code.

## Best solution

Expose the input mode and its change event through the standalone editor API, then register an appropriate standalone Insert-key action in the vscode editor layer so it flows into Monaco. Coordinate this with the broader API request at https://github.com/microsoft/vscode/issues/236218.
