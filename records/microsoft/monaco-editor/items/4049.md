# Issue #4049 — Monaco-editor-core cannot be compiled: Cannot redeclare block-scoped variable 'MonacoEnvironment'.

[https://github.com/microsoft/monaco-editor/issues/4049](https://github.com/microsoft/monaco-editor/issues/4049)

## Summary

The reported compiler error comes from combining Monaco's global and ESM declaration surfaces, not from compiling the documented ESM sample. The remaining request is integration guidance for a mixed loader setup, so it is best handled as a support question.

## Change summary

Provide type-safe access to the global Monaco API without conflicting with the ESM declarations.

## Best solution

Use one integration model consistently: reference monaco.d.ts for the global loader, or import the ESM API without referencing monaco.d.ts. Applications requiring guidance for a mixed dependency setup should use the StackOverflow monaco-editor channel.

## Vision fit

- **Fit:** rejected
- **Reason:** Mixing the deprecated global AMD surface with the ESM declarations runs against Monaco's ESM-first integration direction.
- **Evidence:** README.md distinguishes the /esm build from monaco.d.ts and states that AMD support is deprecated and will be removed.
