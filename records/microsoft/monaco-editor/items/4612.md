# Issue #4612 — [Bug] Error: InstantiationService has been disposed

[https://github.com/microsoft/monaco-editor/issues/4612](https://github.com/microsoft/monaco-editor/issues/4612)

## Summary

Confirmed editor-core defect with a current v0.55.1 playground reproduction and a directly linked open VS Code fix PR. Keep the issue open until that PR is reviewed and merged.

## Change summary

Disposing a diff editor leaves the global hover delegate factory holding a disposed instantiation service, breaking context menus in other editors.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/284577 in the VS Code editor core, then carry the fix into the next Monaco release. React activity reconnects can also expose a separate wrapper lifecycle bug tracked at https://github.com/suren-atoyan/monaco-react/issues/794.
