# Issue #5003 — [Bug] Duplicate underlines in model makers with `code` that has a `target`

[https://github.com/microsoft/monaco-editor/issues/5003](https://github.com/microsoft/monaco-editor/issues/5003)

## Summary

The duplicate decoration remains actionable: a maintainer confirmed the playground reproduction, and current editor-core hover styling still relies on VS Code's workbench-wide link reset. Route this to editor hover while keeping it open.

## Change summary

Diagnostic codes with a target receive duplicate underlines in Monaco marker hovers.

## Best solution

Adjust the vscode editor-core marker-hover CSS to define the code link's decoration explicitly instead of depending on `.monaco-workbench a`, preserving one underline in both standalone Monaco and VS Code. The fix should land under `src/vs/editor/contrib/hover/browser/` and flow into Monaco with a subsequent release.
