# Issue #5195 — [Bug] Unable to measure code action items size in shadow DOM

[https://github.com/microsoft/monaco-editor/issues/5195](https://github.com/microsoft/monaco-editor/issues/5195)

## Summary

The shadow-DOM sizing defect remains in the current vscode editor core: action-list rows are looked up through `ownerDocument`, which cannot find elements inside a shadow root. Route this confirmed bug to the shadow-DOM area.

## Change summary

Code-action items are measured incorrectly when Monaco is hosted inside a shadow DOM, producing an undersized action widget.

## Best solution

Change the action-list row lookup in the vscode editor core to query `this.domNode.getRootNode()` and add a shadow-root width-measurement test; the correction will flow into Monaco with a subsequent source update.
