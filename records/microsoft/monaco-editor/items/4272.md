# Issue #4272 — [Bug] maxTokenizationLineLength message does not make sense for JSON tokenizer

[https://github.com/microsoft/monaco-editor/issues/4272](https://github.com/microsoft/monaco-editor/issues/4272)

## Summary

Still present on main: JSON uses a custom tokenizer that ignores `maxTokenizationLineLength`, while the hover infers skipped tokenization solely from the configured limit. Route to JSON and tokenization.

## Change summary

JSON lines remain tokenized even though the hover reports that tokenization was skipped due to `maxTokenizationLineLength`.

## Best solution

Make the custom JSON token provider in `src/languages/features/json/tokenization.ts` honor `editor.maxTokenizationLineLength`, bringing its behavior and the hover message into agreement.
