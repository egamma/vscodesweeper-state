## Summary

The accepted GLSL grammar contribution remains unimplemented on current main. The issue is already correctly classified as a grammar feature request open to community contribution.

## Change summary

Add built-in GLSL syntax highlighting while clarifying that semantic completion requires a separate completion provider or language service.

## Best solution

Accept a community PR adding a GLSL language definition, registration, and tokenizer tests under src/languages/definitions. Function-aware suggestions should remain separate and use CompletionItemProvider or a GLSL language service rather than Monarch tokenization.
