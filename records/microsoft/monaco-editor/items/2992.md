[https://github.com/microsoft/monaco-editor/issues/2992](https://github.com/microsoft/monaco-editor/issues/2992)

## Summary

GLSL support remains missing from current main, and a maintainer explicitly welcomed a grammar contribution with tests. Keep this request open; syntax highlighting and symbol-aware completion are separate capabilities.

## Change summary

Add GLSL syntax highlighting and clarify support for completing user-defined functions.

## Best solution

Accept a tested GLSL grammar under src/languages/definitions, following the existing language-registration pattern. Separately settle whether symbol-aware GLSL completion is part of the bundled experience or left to an embedder-provided completion provider or language server.
