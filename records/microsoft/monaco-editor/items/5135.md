# Issue #5135 — [Bug] Calling setModel in command action or immediately after performing a command action causes "Uncaught (in promise) Canceled: Canceled" exception

[https://github.com/microsoft/monaco-editor/issues/5135](https://github.com/microsoft/monaco-editor/issues/5135)

## Summary

Fixed in the vscode editor core and shipped with Monaco v0.56.0: disposing the previous diff view model during setModel now handles the expected cancellation instead of leaking an unhandled rejection.

## Change summary

Swapping a diff editor's models from a command action emits an uncaught Canceled promise rejection.

## Best solution

Keep the cancellation handling added in vscode commit 817db05a56463c0369815b0b374218bfa9438896; embedders should update to Monaco v0.56.0 or newer.
