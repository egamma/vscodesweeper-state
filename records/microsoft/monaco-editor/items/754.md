# Issue #754 — monaco-typescript not picking up configured modules from addExtraLib

[https://github.com/microsoft/monaco-editor/issues/754](https://github.com/microsoft/monaco-editor/issues/754)

## Summary

A real TypeScript-worker integration gap remains: addExtraLib registers virtual files but does not map arbitrary filenames to bare module specifiers. The existing TypeScript routing labels and Backlog milestone remain appropriate.

## Change summary

Allow declaration files registered through addExtraLib to resolve reliably as imported modules.

## Best solution

Define and document predictable virtual-filesystem semantics for module-shaped extra libraries in src/languages/features/typescript, including supported URI and node_modules layouts; improve resolution if valid layouts still fail. This looks suitable for a community contribution.
