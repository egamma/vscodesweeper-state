# Issue #4865 — [Bug] False positive "potential listener LEAK detected"

[https://github.com/microsoft/monaco-editor/issues/4865](https://github.com/microsoft/monaco-editor/issues/4865)

## Summary

Fixed in the VS Code editor core: the language-configuration listener threshold was raised to 500 specifically to prevent false-positive leak errors when hundreds of text models exist. The fix landed after Monaco v0.56.0 and has not shipped in a Monaco release yet.

## Change summary

Creating approximately 200 models throws a false-positive listener-leak error, preventing large multi-file projects from loading.

## Best solution

Keep the upstream threshold increase and incorporate it with the next Monaco editor-core update; no Monaco-specific API is needed for the reported 200-model case.
