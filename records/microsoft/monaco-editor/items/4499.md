# Issue #4499 — [Bug] loadForeignModule error after I use editor with language json

[https://github.com/microsoft/monaco-editor/issues/4499](https://github.com/microsoft/monaco-editor/issues/4499)

## Summary

This is a bundler-configuration support question rather than a Monaco defect: the reproduction explicitly excludes every language worker and then activates JSON.

## Change summary

Loading JSON in a Next.js integration produces a loadForeignModule error that persists after switching languages.

## Best solution

Configure MonacoWebpackPlugin through the webpack plugins array and either omit its languages option or include every required worker-backed language, including json. Next.js-specific integration questions belong on StackOverflow's monaco-editor tag.

- **Proposed comment:**

  > Thanks for the reproduction. Its `next.config.js` passes `languages: []` to `MonacoWebpackPlugin`, which excludes all language workers, but the application later activates JSON and therefore has no JSON worker to load. Configure the plugin in webpack's `plugins` array and either remove the `languages` option to include all shipped languages or explicitly include `json` and every other worker-backed language you use. Since the remaining Next.js setup is an integration-support question rather than a Monaco defect, please use https://stackoverflow.com/questions/tagged/monaco-editor for further help.
