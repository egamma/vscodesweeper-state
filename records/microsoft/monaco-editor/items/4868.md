# Issue #4868 — ScrollBar Colour

[https://github.com/microsoft/monaco-editor/issues/4868](https://github.com/microsoft/monaco-editor/issues/4868)

## Summary

Scrollbar-track coloring is now implemented in the editor core bundled by current Monaco main. The new scrollbar.background theme color addresses the request independently of the existing slider colors.

## Change summary

Allow an opaque, independently configurable background color for overflow scrollbar tracks.

## Best solution

Use scrollbar.background in the colors section of monaco.editor.defineTheme(), rather than token rules or scrollbarSlider.*. Treat the requested capability as implemented; the first shipping Monaco release remains unverified.
