# Issue #2925 — [Feature Request] Triggering Snippets with Keybindings

[https://github.com/microsoft/monaco-editor/issues/2925](https://github.com/microsoft/monaco-editor/issues/2925)

## Summary

A real API gap remains: custom keybindings are supported, and snippets can be inserted through an internal contribution, but Monaco does not expose a supported, typed command or API combining them.

## Change summary

Expose a supported way to bind a shortcut that inserts a predefined completion snippet.

## Best solution

Add a typed standalone-editor API or command for inserting snippet text in the vscode editor core, then allow embedders to bind it through `addAction` or `addKeybindingRules` without importing or casting internal contributions.

## Vision fit

- **Fit:** aligned
- **Reason:** A supported snippet API fits Monaco's browser-library boundary by enabling embedders through the public API rather than requiring workbench services or internal modules.
- **Evidence:** The vision states that embedders integrate via the API and identifies Monaco as the VS Code editor adapted to run as a browser library.

## Evidence

- **existing keybinding API:** website/src/website/data/playground-samples/interacting-with-the-editor/adding-a-keybinding-to-an-existing-command/sample.js demonstrates `monaco.editor.addKeybindingRules`, but it requires an available command ID.
- **missing Monaco command:** The contributor confirmed that VS Code's `editor.action.insertSnippet` action is unavailable in Monaco: https://github.com/microsoft/monaco-editor/issues/2925#issuecomment-1027880561.
- **internal workaround:** The current workaround imports `snippetController2`, obtains it through `getContribution`, and casts its untyped `insert` method; the reporter notes that its declaration is empty: https://github.com/microsoft/monaco-editor/issues/2925#issuecomment-3341130312.
- **current source:** src/features/snippet/register.js only side-effect imports the snippet contribution; it does not expose a typed insertion API. The underlying controller is implemented in https://github.com/microsoft/vscode/blob/18ebe6515d696f52fa3172fa3d5d878ac8424e78/src/vs/editor/contrib/snippet/browser/snippetController2.ts.
- **prior decision:** https://github.com/microsoft/monaco-editor/issues/342 was closed because the internal controller workaround functioned, but the maintainer explicitly invited a new issue for limitations; the missing public typing and command documented here are such limitations.
