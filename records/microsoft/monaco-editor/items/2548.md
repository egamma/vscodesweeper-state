# Issue #2548 — PHP mode doesn't support HTML completions

[https://github.com/microsoft/monaco-editor/issues/2548](https://github.com/microsoft/monaco-editor/issues/2548)

## Summary

PHP still lacks default HTML completion-provider registration. The existing HTML-service registration API offers partial coverage, but does not establish automatic HTML/JavaScript completions in PHP mode; retain the request and route it to language support.

## Change summary

Provide HTML attribute and embedded JavaScript completions when editing PHP documents.

## Best solution

Decide the supported mixed-language completion experience for PHP in Monaco's language registrations and workers. Reuse the existing HTML-service registration capability where suitable, while treating embedded JavaScript completion as a separate integration requirement.
