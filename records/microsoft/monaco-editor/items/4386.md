# Issue #4386 — [Bug] Since 0.46.0, dropped text append "$0"

[https://github.com/microsoft/monaco-editor/issues/4386](https://github.com/microsoft/monaco-editor/issues/4386)

## Summary

The defect remains in Monaco's pinned editor source: dropped text is converted to snippet syntax, but the standalone bulk-edit service inserts that syntax literally. Route to editor-core and retain this older, confirmed report as the canonical.

## Change summary

Dragging external text into Monaco appends literal $0 and introduces snippet-escaping backslashes.

## Best solution

Correct snippet-aware edit handling in the standalone editor services in microsoft/vscode, then incorporate the fix into Monaco's generated core. Preserve literal dollar signs and braces in dropped text without removing valid snippet handling shared with VS Code.
