# Issue #4386 — [Bug] Since 0.46.0, dropped text append "$0"

[https://github.com/microsoft/monaco-editor/issues/4386](https://github.com/microsoft/monaco-editor/issues/4386)

## Summary

Still present in the current editor core: drop edits deliberately append a snippet `$0`, but Monaco's standalone bulk-edit service ignores the `insertAsSnippet` flag and inserts the snippet source as literal text. Keep the canonical report open and route it to editor contributions.

## Change summary

Dragging external text into Monaco inserts escaped characters and a literal `$0` suffix.

## Best solution

Fix `StandaloneBulkEditService.apply` in the vscode editor core to honor `insertAsSnippet`, matching the workbench implementation, and add a standalone drag-and-drop regression test; the correction will flow into Monaco with a subsequent release.

## Evidence

- **current source root cause:** Current `src/vs/editor/contrib/dropOrPasteInto/browser/edit.ts` constructs plain-text drop edits as `SnippetParser.escape(edit.insertText) + '$0'` with `insertAsSnippet: true`: https://github.com/microsoft/vscode/blob/18ebe6515d696f52fa3172fa3d5d878ac8424e78/src/vs/editor/contrib/dropOrPasteInto/browser/edit.ts
