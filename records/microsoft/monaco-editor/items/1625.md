# Issue #1625 — setCompilerOptions({target: scriptTarget}) has undesirable results

[https://github.com/microsoft/monaco-editor/issues/1625](https://github.com/microsoft/monaco-editor/issues/1625)

## Summary

Implemented and shipped in v0.21.0: Monaco now bundles the TypeScript standard libraries and selects the appropriate default library for the configured target. Modern syntax remaining valid under an older target is TypeScript's intended behavior because `target` controls emitted JavaScript rather than accepted syntax.

## Change summary

Make `setCompilerOptions({ target })` select matching TypeScript standard-library declarations without requiring embedders to add them manually.

## Best solution

Keep the target-aware library resolution introduced by the cited commit. Embedders can use `compilerOptions.lib` for an explicit library set; no manual `addExtraLib` setup is needed for bundled standard libraries.
