# Issue #4332 — [Bug] Electron nodeIntegrationInWorker enabled breaks monaco-editor loading

[https://github.com/microsoft/monaco-editor/issues/4332](https://github.com/microsoft/monaco-editor/issues/4332)

## Summary

The issue remains relevant: current Monaco still bundles TypeScript's Node-environment detection, which misclassifies Electron workers with Node integration and enters the Node system path. The root behavior belongs upstream in TypeScript, so this should remain open while an upstream fix is identified and imported.

## Change summary

Enabling Electron's nodeIntegrationInWorker causes Monaco's TypeScript worker to fail, disabling hover and other language features.

## Best solution

Correct TypeScript's environment detection so a bundled browser worker with Electron-provided Node globals does not initialize the Node system, then update Monaco's bundled TypeScript services. The Monaco issue should track that upstream resolution and its eventual import.
