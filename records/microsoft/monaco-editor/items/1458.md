# Issue #1458 — Support selection clipboard in linux via mouse wheel

[https://github.com/microsoft/monaco-editor/issues/1458](https://github.com/microsoft/monaco-editor/issues/1458)

## Summary

Browser APIs do not expose Linux's primary-selection clipboard, and VS Code deliberately restricts its implementation to the desktop client. Monaco cannot reliably provide this behavior, so the request is outside the browser library's scope.

## Change summary

Populate Linux's primary-selection clipboard with the complete Monaco selection for middle-click pasting.

## Best solution

Retain selection-clipboard support in desktop hosts that can access the platform clipboard; Monaco should not emulate an unavailable browser capability through its hidden textarea.

## Vision fit

- **Fit:** rejected
- **Reason:** Linux primary-selection integration requires platform capabilities outside Monaco's browser-library boundary.
- **Evidence:** The README defines Monaco as VS Code's editor generated for use in a web browser, while the verified VS Code implementation confines selection-clipboard access to its Electron desktop layer.

- **Proposed comment:**

  > Thanks for the report. Linux's primary-selection clipboard is not exposed by the web clipboard APIs available to Monaco. VS Code investigated this in https://github.com/microsoft/vscode/issues/82603 and removed the selection-clipboard controller from the web client in https://github.com/microsoft/vscode/commit/620a5e80a0d5d97061f1e678f7182e7bcf09c5e8; the implementation remains desktop/Electron-only. Monaco therefore cannot reliably populate the complete primary selection for middle-click paste, so this is outside the browser library's scope.

## Evidence

- **maintainer decision:** In https://github.com/microsoft/vscode/issues/82603#issuecomment-543093404, the maintainer states that the W3C clipboard specification does not cover the selection clipboard and that the contribution was therefore removed from the web client.
- **architecture commit:** https://github.com/microsoft/vscode/commit/620a5e80a0d5d97061f1e678f7182e7bcf09c5e8 moved SelectionClipboardController out of the browser contribution and into electron-browser, explicitly removing it from web.
- **current implementation:** Current VS Code source still implements Linux selection-clipboard writes only in src/vs/workbench/contrib/codeEditor/electron-browser/selectionClipboard.ts; there is no corresponding browser contribution available to Monaco.
