## Summary

This is an integration-support question rather than an actionable Monaco issue. TextMate grammars are not accepted by the Monarch API, and the README documents the supported alternatives.

## Change summary

Use an existing Luau TextMate grammar for syntax highlighting in a browser-hosted Monaco editor.

## Best solution

Use the documented monaco-tm integration for the TextMate grammar, or author a separate Monarch tokenizer and register it with `setMonarchTokensProvider`.
