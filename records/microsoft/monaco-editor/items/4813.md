# Issue #4813 — [Feature Request]: Support `exactOptionalPropertyTypes` TypeScript compiler options

[https://github.com/microsoft/monaco-editor/issues/4813](https://github.com/microsoft/monaco-editor/issues/4813)

## Summary

The requested compiler option is already supported through setCompilerOptions, including in v0.52.2. This is configuration guidance rather than a missing capability.

## Change summary

Enable exactOptionalPropertyTypes in Valibot's Monaco-based playground.

## Best solution

Configure typescriptDefaults with exactOptionalPropertyTypes: true and strictNullChecks: true, preserving the playground's other compiler options; no library change is needed.

- **Proposed comment:**

  > Thanks for the request. You can already enable this through the TypeScript defaults; the compiler-options index signature accepts the flag even though it is not listed as a named property:
  > 
  > ```ts
  > const defaults = monaco.languages.typescript.typescriptDefaults;
  > defaults.setCompilerOptions({
  >   ...defaults.getCompilerOptions(),
  >   strictNullChecks: true,
  >   exactOptionalPropertyTypes: true
  > });
  > ```
  > 
  > The bundled TypeScript language service receives and honors this option, so no new Monaco capability is needed. Configuration questions can go to https://stackoverflow.com/questions/tagged/monaco-editor.
