# Issue #4813 — [Feature Request]: Support `exactOptionalPropertyTypes` TypeScript compiler options

[https://github.com/microsoft/monaco-editor/issues/4813](https://github.com/microsoft/monaco-editor/issues/4813)

## Summary

The requested compiler option is already supported through `typescriptDefaults.setCompilerOptions`; Monaco forwards arbitrary compiler options directly to its bundled TypeScript language service.

## Change summary

Allow embedders to enable TypeScript's `exactOptionalPropertyTypes` checking in Monaco.

## Best solution

Use `monaco.languages.typescript.typescriptDefaults.setCompilerOptions` with `strictNullChecks: true` and `exactOptionalPropertyTypes: true`; no Monaco change is needed.

## Vision fit

- **Fit:** aligned
- **Reason:** Exposing TypeScript compiler behavior through the bundled language worker fits Monaco's durable language-experience theme.
- **Evidence:** The vision identifies the bundled TypeScript worker as a long-standing area of investment.

- **Proposed comment:**

  > Thanks for the request. This is already supported through the TypeScript defaults API:
  > 
  > ```ts
  > const defaults = monaco.languages.typescript.typescriptDefaults;
  > defaults.setCompilerOptions({
  >   ...defaults.getCompilerOptions(),
  >   strictNullChecks: true,
  >   exactOptionalPropertyTypes: true
  > });
  > ```
  > 
  > Monaco forwards these options directly to its bundled TypeScript language service, so no additional editor option is required.
