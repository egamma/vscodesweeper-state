# Issue #2681 — Wrong YAML syntax highlighting

[https://github.com/microsoft/monaco-editor/issues/2681](https://github.com/microsoft/monaco-editor/issues/2681)

## Summary

The quoted-value highlighting defect was fixed by the YAML key-detection change shipped in v0.37.0. Tracing the supplied example through current source shows that "{bar: 7}" remains a string rather than being highlighted as a mapping key.

## Change summary

YAML highlighting incorrectly treats text inside a quoted value containing a colon as a mapping key.
