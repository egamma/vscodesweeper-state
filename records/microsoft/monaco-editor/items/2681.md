# Issue #2681 — Wrong YAML syntax highlighting

[https://github.com/microsoft/monaco-editor/issues/2681](https://github.com/microsoft/monaco-editor/issues/2681)

## Summary

Fixed and shipped in v0.37.0: the YAML tokenizer now preserves `: ` inside quoted values as string content instead of interpreting it as another key-value delimiter.

## Change summary

A colon inside a double-quoted YAML value is incorrectly highlighted as part of a mapping key.

## Best solution

Keep the YAML tokenizer correction shipped in v0.37.0; the current grammar enters its quoted-string state after the outer mapping delimiter and tokenizes the complete quoted value as a string.
