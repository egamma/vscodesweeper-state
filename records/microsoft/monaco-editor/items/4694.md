# Issue #4694 — [Bug] globalDefine is not a function

[https://github.com/microsoft/monaco-editor/issues/4694](https://github.com/microsoft/monaco-editor/issues/4694)

## Summary

The reported Node/Electron failure is in Monaco's legacy AMD loader path, which is now deprecated and explicitly unsupported. Restoring compatibility there is out of scope; Electron integrations should migrate to the ESM build.

## Change summary

Restore Monaco's legacy AMD build compatibility with Electron environments that load it through Node require.

## Best solution

Use Monaco's supported ESM distribution with a bundler in the Electron renderer rather than extending the deprecated AMD loader's Node integration.
