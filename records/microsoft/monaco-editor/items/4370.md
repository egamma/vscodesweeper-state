# Issue #4370 — [Bug] Keyevents fired twice on new editor after disposing diff editor on same domElement (parent)

[https://github.com/microsoft/monaco-editor/issues/4370](https://github.com/microsoft/monaco-editor/issues/4370)

## Summary

Confirmed editor-core lifecycle bug: disposing a diff editor and reusing its container can leave stale registrations that process keyboard commands multiple times. The canonical issue remains necessary and should be routed to the diff-editor owner.

## Change summary

Fully dispose a standalone diff editor so a new editor on the same DOM container receives each keyboard command only once.

## Best solution

Fix the lifecycle in the vscode editor core, likely around diff-editor disposal and code-editor-service registration, and add a regression test that disposes a diff editor, reuses its container, verifies it disappears from `getDiffEditors()`, and checks that cursor and edit commands run once.
