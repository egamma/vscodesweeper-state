# Issue #4370 — [Bug] Keyevents fired twice on new editor after disposing diff editor on same domElement (parent)

[https://github.com/microsoft/monaco-editor/issues/4370](https://github.com/microsoft/monaco-editor/issues/4370)

## Summary

The current bundled editor core removes the disposed diff editor's container listeners before reuse, addressing the doubled keyboard commands. A concrete upstream fix and the adopted disposal path support closing as implemented on main.

## Change summary

Reusing a disposed diff editor's container causes arrow keys, backspace, and undo/redo to execute twice.

## Best solution

Retain the upstream disposal fix already adopted on main so container reuse executes each keyboard command once without remounting the DOM node or debouncing commands.
