# Issue #5047 — [Bug]  mousedown event does not support for mobile

[https://github.com/microsoft/monaco-editor/issues/5047](https://github.com/microsoft/monaco-editor/issues/5047)

## Summary

Current editor-core code intentionally excludes touch pointer-down events from the mouse-down path, so this is a feature request rather than a broken mouse-event implementation. Keep it open and route it to mobile editor input.

## Change summary

Expose touch interaction through `onMouseDown`, or provide an equivalent public pointer/touch event for mobile embedders.

## Best solution

Define the desired public touch/pointer API in the VS Code editor core and implement it without disrupting touch scrolling and selection; Monaco will inherit that change on its next source update.
