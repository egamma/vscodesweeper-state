# Issue #5390 — First keystroke typed over a backward selection is dropped (Safari/WebKit, textarea input path)

[https://github.com/microsoft/monaco-editor/issues/5390](https://github.com/microsoft/monaco-editor/issues/5390)

## Summary

Verified duplicate of the open cross-browser backward-selection defect in https://github.com/microsoft/monaco-editor/issues/5228. Current VS Code source confirms the same reversed textarea-selection path, while the canonical already includes Safari confirmation.

## Change summary

Typing over a backward selection through the textarea input path drops the first keystroke in Safari and WKWebView.

## Best solution

Consolidate the WebKit reproduction and reversed-offset diagnosis into https://github.com/microsoft/monaco-editor/issues/5228, then fix the textarea selection representation in the VS Code editor core so ordered offsets and backward direction are preserved across browsers.
