# Issue #4784 — IModelDecorationOptions IsWholeLine extends range in unexpected ways

[https://github.com/microsoft/monaco-editor/issues/4784](https://github.com/microsoft/monaco-editor/issues/4784)

## Summary

A real public-API gap remains: whole-line decorations intentionally track edits, but Monaco exposes no option for collapsing or removing a decoration when an edit replaces its entire range. Route this to the editor API and text-buffer owners.

## Change summary

Allow a whole-line decoration to disappear rather than move and regrow when its complete range is deleted and subsequently restored through undo.

## Best solution

In the vscode editor core, expose and document a stable decoration option for collapsing or removing a range after an encompassing edit, potentially building on the internal `collapseOnReplaceEdit` behavior, and cover whole-line deletion plus undo in model-decoration tests.
