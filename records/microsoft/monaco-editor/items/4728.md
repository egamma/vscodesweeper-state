# Issue #4728 — [Feature Request] Access to `registerDocumentPasteEditProvider`

[https://github.com/microsoft/monaco-editor/issues/4728](https://github.com/microsoft/monaco-editor/issues/4728)

## Summary

A real API gap remains: the editor core has document paste and drop provider registries, but Monaco's standalone language API does not expose registration functions. Route this feature request to the editor API and clipboard owners.

## Change summary

Expose document paste and drop edit provider registration so embedders can handle files and custom clipboard formats.

## Best solution

Add public registrar functions and associated types to the vscode standalone language API, backed by the existing document paste and drop registries; Monaco can then receive them through its generated editor API. This looks suitable for an `open for PR` decision.
