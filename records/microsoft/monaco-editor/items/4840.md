# Issue #4840 — [Bug] How to remove the previous decorations permanently ?

[https://github.com/microsoft/monaco-editor/issues/4840](https://github.com/microsoft/monaco-editor/issues/4840)

## Summary

This is an API usage question rather than a Monaco defect. The decorations API already replaces or clears a collection; the sample instead creates a new collection for every invocation and then calls `set` after assigning the collection to null.

## Change summary

Remove an earlier navigation highlight before applying a new decoration.

## Best solution

Retain one `IEditorDecorationsCollection` for this feature and call `set(newDecorations)` on each invocation, since `set` replaces that collection's previous decorations; call `clear()` when no highlight should remain.

  > Thanks for the question. Keep a single `IEditorDecorationsCollection` for this feature instead of creating one on every call, then call `collection.set(decorations)` whenever the target changes—`set` replaces all previous decorations in that collection. Use `collection.clear()` when the highlight should disappear, and remove the assignment to `null` plus the subsequent `set([])` call, which attempts to use the collection after clearing the reference.
