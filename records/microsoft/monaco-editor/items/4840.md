# Issue #4840 — [Bug] How to remove the previous decorations permanently ?

[https://github.com/microsoft/monaco-editor/issues/4840](https://github.com/microsoft/monaco-editor/issues/4840)

## Summary

This is a decoration-lifecycle usage question: each invocation creates an independent collection, and the timeout calls set() after assigning that collection to null. The existing collection API supports replacing and removing decorations.

## Change summary

Replace the previous navigation highlight with a new one and remove it after five seconds.

## Best solution

Retain one decorations collection per editor and use set() to replace its contents, with clear() to remove them. Cancel the previous timeout when updating the highlight so it cannot clear a newer selection.

- **Proposed comment:**

  > Thanks for the report. Each call creates a separate decorations collection, so setting the new collection does not replace decorations belonging to an earlier one. Keep one collection per editor and call collection.set(decorations) for each new highlight; collection.clear() removes its decorations without needing set([]) afterward. Cancel the previous timeout when setting a new highlight so an older timeout cannot clear it early.
  > 
  > Also remove the call to decorationsCollection.set([]) after assigning null, since that throws. For further API usage questions, please use https://stackoverflow.com/questions/tagged/monaco-editor.
