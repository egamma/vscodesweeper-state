# Issue #778 — monaco editor navigate to symbol from outside editor

[https://github.com/microsoft/monaco-editor/issues/778](https://github.com/microsoft/monaco-editor/issues/778)

## Summary

Keep open: current navigation APIs accept positions, but the quick-outline action still opens a picker rather than navigating directly to a named symbol. The related symbol-enumeration request does not fully cover this navigation contract.

## Change summary

Expose supported programmatic navigation to a named document symbol without opening the symbol picker.

## Best solution

Define supported symbol lookup and navigation semantics in the VS Code-derived standalone editor API, including handling ambiguous CSS symbol names. Existing position-based navigation can handle the final jump once a symbol location is known.
