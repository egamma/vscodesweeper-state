# Issue #4377 — [Feature Request] Get the value at position with specific delimiters

[https://github.com/microsoft/monaco-editor/issues/4377](https://github.com/microsoft/monaco-editor/issues/4377)

## Summary

A real API gap remains, but arbitrary delimiter extraction has unresolved semantics around escaping, nesting, and language syntax. Route the request to editor-api rather than closing it; the current model exposes only lower-level text and range operations.

## Change summary

Add a text-model API that returns the value enclosing a position between caller-specified delimiter pairs.

## Best solution

Determine in the VS Code editor core whether a language-neutral delimiter API can define escaping and nesting correctly. Otherwise, document a provider-specific pattern using getLineContent/getValueInRange, while language-aware embedders use parsing or selection ranges.
