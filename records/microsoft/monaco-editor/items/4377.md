# Issue #4377 — [Feature Request] Get the value at position with specific delimiters

[https://github.com/microsoft/monaco-editor/issues/4377](https://github.com/microsoft/monaco-editor/issues/4377)

## Summary

The requested delimiter-aware lookup is not covered directly by the current public model API. Route to editor-api for consideration; existing search and range APIs provide building blocks, but no verified canonical owns this request.

## Change summary

Add a position-based API that returns enclosing delimited text, including spaces and punctuation, without matching text between separate quoted strings.

## Best solution

Evaluate a reusable enclosing-delimiter API in the VS Code editor core, including its pairing, escaping, and nesting contract. Scoped findMatches plus position containment and getValueInRange can support application-defined quote rules today, but callers still implement delimiter interpretation themselves.
