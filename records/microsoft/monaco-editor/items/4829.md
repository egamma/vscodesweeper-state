# Issue #4829 — [Bug] StorageService override doesn't see the onDidChangeValue function

[https://github.com/microsoft/monaco-editor/issues/4829](https://github.com/microsoft/monaco-editor/issues/4829)

## Summary

The override does not satisfy the storage-service contract: `onDidChangeValue` must return an event function, while the supplied implementation returns `undefined`. This is an override-implementation question rather than a Monaco defect.

## Change summary

A custom storage-service override throws while opening suggestions after upgrading from Monaco 0.41.0.

## Best solution

Update the custom storage service so `onDidChangeValue(scope, key, disposable)` returns an event registration function and ensure the remaining storage-service members satisfy the current contract.
