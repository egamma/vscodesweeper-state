# Issue #1564 — Monarch indented block end

[https://github.com/microsoft/monaco-editor/issues/1564](https://github.com/microsoft/monaco-editor/issues/1564)

## Summary

Existing state parameters and regex guards support indentation-dependent termination, but the reporter explicitly retained the request for dedicated support. Keep this accepted Backlog request open and route it to tokenization; the downstream YAML workaround is not a Monaco fix or a canonical duplicate.

## Change summary

Provide convenient Monarch support for indentation-delimited blocks without duplicating rules for individual indentation widths.

## Best solution

Decide whether Monarch's existing parameterized-state mechanism is the intended long-term interface or whether dedicated indentation support should be added in the VS Code Monarch engine. Separately, address the bundled YAML grammar's premature termination on more-indented scalar lines.
