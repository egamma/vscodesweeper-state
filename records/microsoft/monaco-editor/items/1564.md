# Issue #1564 — Monarch indented block end

[https://github.com/microsoft/monaco-editor/issues/1564](https://github.com/microsoft/monaco-editor/issues/1564)

## Summary

A real Monarch capability gap remains: state captures and guards provide an awkward partial workaround, but there is no first-class indentation-aware block termination. Keep the Backlog request open and route it to tokenization.

## Change summary

Add native Monarch support for ending indentation-delimited tokenizer states when indentation decreases.

## Best solution

Add an indentation-aware guard or block-state primitive to the Monarch tokenizer in the vscode editor core, then consume it in indentation-sensitive grammars such as YAML. The API should distinguish equal or deeper indentation from dedentation without enumerating indentation widths.
