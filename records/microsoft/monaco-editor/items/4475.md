# Issue #4475 — [Bug] Glyph margin decorations/widgets for deleted lines not rendering in the inline view

[https://github.com/microsoft/monaco-editor/issues/4475](https://github.com/microsoft/monaco-editor/issues/4475)

## Summary

Verified duplicate of the open glyph-margin option issue: both symptoms come from the same current diff-editor logic, which forces the original editor's glyph margin to match side-by-side mode rather than the configured option.

## Change summary

Glyph-margin decorations and widgets on deleted lines disappear when the diff editor uses its inline view.

## Best solution

Consolidate on https://github.com/microsoft/monaco-editor/issues/4448 and fix the vscode diff-editor core so the original editor honors the configured glyph-margin behavior in both inline and side-by-side modes.
