# Issue #3893 — [Bug] `ITextModel.pushEditOperations()` ignores the `cursorStateComputer`

[https://github.com/microsoft/monaco-editor/issues/3893](https://github.com/microsoft/monaco-editor/issues/3893)

## Summary

Keep open for an explicit API-contract clarification: current source invokes the callback and stores and returns its selections, but does not apply them to an attached editor. The accepted bug was reopened, and no later maintainer decision establishes grounds for a decline close.

## Change summary

The reporter expects selections returned by ITextModel.pushEditOperations() to reposition the attached editor's cursor.

## Best solution

Clarify the model-versus-editor selection contract in the VS Code-derived API documentation: editor.executeEdits() applies computed selections, whereas model.pushEditOperations() returns them and records them for undo/redo. Preserve the shared-model boundary unless maintainers explicitly choose a different public contract.
