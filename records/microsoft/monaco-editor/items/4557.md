# Issue #4557 — [Bug] The RegExp d Modifier was not support on Safari 14 const markRegex = /\bMARK:\s*(.*)$/d;

[https://github.com/microsoft/monaco-editor/issues/4557](https://github.com/microsoft/monaco-editor/issues/4557)

## Summary

The compatibility gap remains in the current VS Code editor core: section-header detection still constructs a RegExp with the unsupported `d` flag. This issue is the older, better-documented canonical report and should remain open for the Safari and editor-core owners.

## Change summary

Monaco fails on Safari 14 when section-header code constructs a regular expression using the unsupported ES2022 `d` flag.

## Best solution

Handle the missing RegExp indices flag in `microsoft/vscode/src/vs/editor/common/services/findSectionHeaders.ts`, either with a capability-gated fallback or an explicit browser-support decision; the change will flow into Monaco with a subsequent release. Consolidate the newer https://github.com/microsoft/monaco-editor/issues/5216 into this issue rather than closing this older canonical.
