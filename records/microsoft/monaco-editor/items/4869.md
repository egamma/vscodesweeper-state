# Issue #4869 — [Bug] The editor isn't visible when the page direction is RTL

[https://github.com/microsoft/monaco-editor/issues/4869](https://github.com/microsoft/monaco-editor/issues/4869)

## Summary

The playground reproduction shows Monaco inheriting the host page's RTL direction and rendering outside the viewport. This remains a valid editor-core isolation bug and should be routed to RTL and rendering owners.

## Change summary

Keep the editor visible and LTR when embedded in a page whose inherited CSS direction is RTL.

## Best solution

Fix the vscode editor core so Monaco's root container establishes LTR direction independently of its host page, while preserving Monaco's existing RTL text behavior. The change likely belongs under microsoft/vscode's src/vs/editor browser/rendering code and should flow into Monaco with a subsequent release.
