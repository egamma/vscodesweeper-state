# Issue #4410 — [Feature Request] How to set the maximum editable line for the Monaco editor

[https://github.com/microsoft/monaco-editor/issues/4410](https://github.com/microsoft/monaco-editor/issues/4410)

## Summary

The public API has no built-in editable-line limit. Route this request to editor-api: the suggested event-and-undo workaround does not provide equivalent preventive enforcement.

## Change summary

Allow embedders to configure a maximum document line count that edits cannot exceed.

## Best solution

Decide whether an optional line-count editing constraint belongs in the VS Code editor core and its exported Monaco API. Existing content-change hooks support application-level enforcement, but do not themselves provide the requested built-in cap.
