# Issue #3593 — [Bug] Down arrow is not working if suggestion dropdown inside snippet only have one item

[https://github.com/microsoft/monaco-editor/issues/3593](https://github.com/microsoft/monaco-editor/issues/3593)

## Summary

The single-item keyboard-navigation defect was fixed in the VS Code editor core after this report. The changed command condition covers both the original snippet case and the commenter's selectionMode: "never" case, and is present in Monaco's published editor code.

## Change summary

Down Arrow fails to focus the only available completion, moving the cursor instead, inside snippets and with suggestion selection disabled.

## Best solution

Treat this as resolved by the upstream navigation fix: an unfocused single suggestion can now receive keyboard focus. Preserve the existing cursor-navigation behavior when the sole suggestion is already focused.
