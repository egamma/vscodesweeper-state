# Issue #4398 — [Bug] ESM Code contains require code

[https://github.com/microsoft/monaco-editor/issues/4398](https://github.com/microsoft/monaco-editor/issues/4398)

## Summary

The AMD compatibility branch remains in the current ESM package and vscode editor source. This valid packaging issue is already correctly routed with the ESM label and should remain open.

## Change summary

Remove AMD-specific global require and define compatibility code from the ESM editor entry point.

## Best solution

Move AMD interoperability into Monaco's AMD-specific bootstrap and keep it out of generated ESM output, coordinating the shared editor API change in microsoft/vscode where necessary. The released ESM tree should contain neither `require.config` nor `define.amd` compatibility branches.
