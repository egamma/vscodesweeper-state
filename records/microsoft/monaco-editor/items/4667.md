# Issue #4667 — [Bug] Expressions using Python's matrix multiplication operator highlighted as decorator

[https://github.com/microsoft/monaco-editor/issues/4667](https://github.com/microsoft/monaco-editor/issues/4667)

## Summary

The defect remains in current main: Python tokenization classifies any `@` followed immediately by an identifier as a decorator tag, including the valid matrix expression `x@y`. The issue is confirmed and already routed appropriately, so it should remain open.

## Change summary

Python matrix multiplication without surrounding whitespace is incorrectly highlighted as a decorator.

## Best solution

Update the Python Monarch grammar in `src/languages/definitions/python/python.ts` to recognize decorators only in decorator positions while tokenizing infix `@` as an operator, with regression tests covering `x@y`, `x @ y`, and decorators.
