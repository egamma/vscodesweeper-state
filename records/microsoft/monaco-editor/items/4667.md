- **Current grammar:** src/languages/definitions/python/python.ts, tokenizer.root, contains the unanchored rule /@[a-zA-Z_]\w*/ mapped to 'tag'. After consuming the identifier in a@b, this rule consumes @b as tag.python; whitespace after @ prevents that match. This directly explains the reported highlighting discrepancy.
- **Open implementation candidate:** https://github.com/microsoft/monaco-editor/pull/5579 was verified OPEN and explicitly states Fixes #4667.
