# Issue #3993 — [Bug] json code block in markdown has no highlight

[https://github.com/microsoft/monaco-editor/issues/3993](https://github.com/microsoft/monaco-editor/issues/3993)

## Summary

The playground content contains bare JSON rather than a Markdown code block. Monaco already supports JSON highlighting inside a fenced block marked `json`, so the demonstrated behavior is as designed.

## Change summary

Highlight JSON appearing as unfenced content in a Markdown model.

## Best solution

Use a fenced Markdown block beginning with three backticks followed by `json`; the existing Markdown tokenizer then delegates its contents to JSON tokenization.
