# Issue #2636 — Detect/Select keyboard layout to display shortcuts in

[https://github.com/microsoft/monaco-editor/issues/2636](https://github.com/microsoft/monaco-editor/issues/2636)

## Summary

Verified duplicate: the older open issue tracks Monaco's lack of non-US keyboard-layout support, while this report proposes layout detection and selection as the solution. Consolidating there preserves a single owner for the underlying capability.

## Change summary

Make standalone-editor shortcuts layout-aware and display the correct bindings by detecting or allowing selection of the keyboard layout.

## Best solution

Consolidate the request on https://github.com/microsoft/monaco-editor/issues/1233. The eventual implementation should replace the standalone editor's US-only resolver with a reusable layout-aware service from the vscode editor/platform layers, balancing browser detection, an embedder-facing selection API, and lazy loading of layout data.
