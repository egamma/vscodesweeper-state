# Issue #5260 — [Bug] Tooltips do not work with webcomponents

[https://github.com/microsoft/monaco-editor/issues/5260](https://github.com/microsoft/monaco-editor/issues/5260)

## Summary

This is an exact duplicate of the open Shadow DOM hover issue https://github.com/microsoft/monaco-editor/issues/3409, which has the same reporter, failing source check, proposed composedPath fix, and playground reproduction.

## Change summary

Hover tooltips fail when Monaco is hosted inside a web component's Shadow DOM because mouse events are checked through their retargeted target.

## Best solution

Consolidate the report on https://github.com/microsoft/monaco-editor/issues/3409 and fix the mouse-leave handling in the VS Code editor core, preserving support for open and closed shadow roots. Carry over that the reporter's fork already uses the proposed composedPath-based workaround.
