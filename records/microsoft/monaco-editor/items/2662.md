# Issue #2662 — How to change existing monaco editor contruction options( fixedOverflowWidgets ) at run time?

[https://github.com/microsoft/monaco-editor/issues/2662](https://github.com/microsoft/monaco-editor/issues/2662)

## Summary

The requested runtime configurability remains absent on current main. The issue is already correctly classified and routed to editor-core.

## Change summary

Allow `editor.updateOptions` to change `fixedOverflowWidgets` without recreating the editor.

## Best solution

Update the vscode editor core's content-widget implementation to react to `fixedOverflowWidgets` configuration changes and switch existing widgets between fixed and absolute positioning. This looks suitable for an `open for PR` decision in microsoft/vscode.
