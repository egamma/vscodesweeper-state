# Issue #2662 — How to change existing monaco editor contruction options( fixedOverflowWidgets ) at run time?

[https://github.com/microsoft/monaco-editor/issues/2662](https://github.com/microsoft/monaco-editor/issues/2662)

## Summary

Keep open: changing fixedOverflowWidgets on an existing editor still lacks support in the content-widget implementation. The maintainer acknowledged this limitation, and the existing editor-core label correctly identifies where the enhancement belongs.

## Change summary

Allow fixedOverflowWidgets to change dynamically when the same editor switches between single-line and full-view modes.

## Best solution

Support runtime changes to overflow-widget positioning in the microsoft/vscode editor core, then deliver that behavior through Monaco's generated editor. Existing widgets should follow the updated option without requiring a replacement editor instance.
