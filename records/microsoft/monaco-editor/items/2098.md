# Issue #2098 — addExtraLib() method is adding the library to all editor available in a page

[https://github.com/microsoft/monaco-editor/issues/2098](https://github.com/microsoft/monaco-editor/issues/2098)

## Summary

The requested per-editor TypeScript library isolation remains absent on current main. The existing feature-request and typescript labels already route this valid, repeatedly requested capability appropriately.

## Change summary

Allow separate Monaco editor instances on one page to use different TypeScript or JavaScript extra libraries.

## Best solution

Add project- or model-scoped TypeScript language-service contexts so each editor can select its own extra libraries without changing diagnostics in other editors. This likely requires coordinated changes to the TypeScript defaults, worker management, and worker host under src/languages/features/typescript/.

## Evidence

- **shared worker state:** src/languages/features/typescript/workerManager.ts creates one WorkerManager per language mode and passes the defaults object's complete extra-lib map to its worker; src/languages/features/typescript/tsWorker.ts then includes every entry from that map in getScriptFileNames().
