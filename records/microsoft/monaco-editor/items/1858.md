# Issue #1858 — View Zones move to wrong position

[https://github.com/microsoft/monaco-editor/issues/1858](https://github.com/microsoft/monaco-editor/issues/1858)

## Summary

The supplied view-zone displacement remains supported by the VS Code source pinned on Monaco main: text edits move the whitespace, but subsequent remapping recomputes its position from the unchanged zone anchor. Keep open; no verified canonical owns this symptom.

## Change summary

View zones snap back to their original line after edits above them followed by wrapping or folding changes.

## Best solution

Resolve the inconsistent edit-tracking and remapping behavior in the microsoft/vscode editor core so zones remain attached to the intended text through both operations. Carry the fix into Monaco through its normal editor-core update.
