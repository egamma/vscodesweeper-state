# Issue #5221 — [Bug] onEnterRules fails with 'Javascript'

[https://github.com/microsoft/monaco-editor/issues/5221](https://github.com/microsoft/monaco-editor/issues/5221)

## Summary

The custom JavaScript Enter rule is overwritten by Monaco's asynchronously loaded built-in language configuration. The behavior remains traceable on current main and should be routed to the basic-languages/API owners.

## Change summary

Custom `onEnterRules` registered for JavaScript stop working after the built-in language configuration loads.

## Best solution

Adjust the lazy language-loading path in `src/languages/definitions/_.contribution.ts` so built-in configuration initialization cannot supersede a configuration registered by the embedder, while retaining JavaScript's default rules.
