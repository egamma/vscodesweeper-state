# Issue #4627 — [Bug] Cannot find JS module imported from TS file (2307)

[https://github.com/microsoft/monaco-editor/issues/4627](https://github.com/microsoft/monaco-editor/issues/4627)

## Summary

The supplied example exposes a remaining model-synchronization gap: the TypeScript worker does not receive the JavaScript model, so allowJs cannot make its import resolve. Route this to TypeScript multifile support; the current source still contains the exclusion.

## Change summary

A TypeScript model importing an existing JavaScript model reports diagnostic 2307 despite allowJs being enabled.

## Best solution

Make JavaScript dependencies available to the TypeScript language worker when allowJs is enabled, preserving separate language-service settings and live model contents. This belongs in Monaco's worker synchronization, not the upstream TypeScript resolver or VS Code editor core.
