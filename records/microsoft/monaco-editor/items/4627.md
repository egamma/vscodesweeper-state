# Issue #4627 — [Bug] Cannot find JS module imported from TS file (2307)

[https://github.com/microsoft/monaco-editor/issues/4627](https://github.com/microsoft/monaco-editor/issues/4627)

## Summary

The mixed JavaScript/TypeScript project gap remains on main: the TypeScript worker synchronizes only TypeScript models, so its language service cannot resolve the JavaScript model imported by this reproduction. Route this to the TypeScript multifile area.

## Change summary

Allow a TypeScript model to resolve and type-check an imported JavaScript model when allowJs is enabled.

## Best solution

Update the TypeScript worker synchronization in src/languages/features/typescript/workerManager.ts so JavaScript dependencies can participate in a TypeScript language-service project when compiler options permit them, without merging the independently configured JavaScript and TypeScript projects indiscriminately.
