# Issue #4760 — [Bug] CTRL+F / Find does not work for offscreen content

[https://github.com/microsoft/monaco-editor/issues/4760](https://github.com/microsoft/monaco-editor/issues/4760)

## Summary

Still present in the current editor core: Monaco renders only viewport lines into the DOM, so native browser search cannot discover offscreen model content. The confirmed report should remain open and be routed to editor find/rendering.

## Change summary

Make browser find-in-page discover text in offscreen Monaco content, including pages containing multiple editor instances.

## Best solution

Address this in the vscode editor core's virtualized view-line rendering or an equivalent browser-find integration, preserving rendering performance while exposing complete model text to native page search.
