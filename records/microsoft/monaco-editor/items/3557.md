# Issue #3557 — [Bug] "No suggestions" persists while typing if the completion helper is set to return an empty list for empty content

[https://github.com/microsoft/monaco-editor/issues/3557](https://github.com/microsoft/monaco-editor/issues/3557)

## Summary

Keep open: the supplied playground code and steps suffice to retest, and the current pinned editor core retains the relevant manual-suggestion guards despite changes since v0.35.0. This team-authored report has neither a verified fixing commit nor an eligible duplicate canonical.

## Change summary

Typing after manually requesting completions on empty input leaves “No suggestions” visible instead of requesting the now-available completions.

## Best solution

Resolve the empty-result manual-suggestion behavior in the VS Code editor core, preserving providers that intentionally return nothing for empty input. The team should settle whether typing should retrigger completions or dismiss the empty widget; any fix would reach Monaco through a core update.
