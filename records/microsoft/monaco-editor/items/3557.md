# Issue #3557 — [Bug] "No suggestions" persists while typing if the completion helper is set to return an empty list for empty content

[https://github.com/microsoft/monaco-editor/issues/3557](https://github.com/microsoft/monaco-editor/issues/3557)

## Summary

The exact failure remains documented by a skipped regression test on current vscode main. This team-authored issue should remain open until the editor-core behavior is fixed and that test is enabled.

## Change summary

Typing after an explicitly triggered completion request returns no results does not retrigger the provider or clear the “No suggestions” state.

## Best solution

Fix manual suggestion retriggering in the vscode editor core, then enable the regression test in src/vs/editor/contrib/suggest/test/browser/suggestController.test.ts; Monaco will inherit the correction in a subsequent release.
