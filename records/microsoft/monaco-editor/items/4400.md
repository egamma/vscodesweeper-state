## Summary

The duplication remains in the current ESM distribution: v0.56.0 contains 205 module-level `__decorate` helpers. This is a valid bundle-size request that should remain open and route to the ESM packaging area.

## Change summary

Deduplicate TypeScript's emitted `__decorate` helper across ESM modules to reduce package and bundle size.

## Best solution

Adjust the vscode-to-monaco compilation or ESM packaging pipeline to share the decorator helper without compromising tree-shaking or imposing an unsuitable runtime dependency. Measure the resulting package and consumer-bundle sizes before adopting the approach.
