# Issue #771 — ESM modules in monaco-editor-core don't have source maps

[https://github.com/microsoft/monaco-editor/issues/771](https://github.com/microsoft/monaco-editor/issues/771)

## Summary

The debugging gap remains on current main: the ESM build neither enables Rollup source maps nor copies source maps from monaco-editor-core. Keep the request open and route it to the ESM packaging area.

## Change summary

Publish source maps for ESM modules so browser developer tools can map generated Monaco JavaScript back to TypeScript sources.

## Best solution

Extend the ESM packaging pipeline to preserve source provenance from monaco-editor-core and emit source maps for the published modules. This belongs in the Monaco ESM build and, if the core package lacks the necessary input maps, its VS Code-derived generation pipeline.
