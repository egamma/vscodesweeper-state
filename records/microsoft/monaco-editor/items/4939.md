# Issue #4939 — [Bug] Highlight exception in multi line string text of python code

[https://github.com/microsoft/monaco-editor/issues/4939](https://github.com/microsoft/monaco-editor/issues/4939)

## Summary

The bug remains on current main: Python triple-quoted f-strings use the single-line f-string tokenizer state, which exits after the first content line. Route this confirmed grammar defect to the grammars area.

## Change summary

Python triple-quoted f-strings lose string highlighting after their first content line.

## Best solution

Add dedicated multiline f-string tokenizer states for both quote styles in src/languages/definitions/python/python.ts, preserving interpolation handling until the matching triple quote, with multiline tokenization tests in python.test.ts.
