# Issue #5024 — [Feature Request] Make styles of linesDecorationsTooltip as glyphMarginHoverMessage tooltip

[https://github.com/microsoft/monaco-editor/issues/5024](https://github.com/microsoft/monaco-editor/issues/5024)

## Summary

This requires new hover infrastructure in the VS Code editor core, not Monaco-owned code. The VS Code team investigated the same native line-decoration tooltip limitation and closed it as not planned.

## Change summary

Add a Markdown-capable editor hover for line decorations instead of the browser-native title tooltip.

## Best solution

Retain the current native tooltip behavior unless the VS Code editor core revisits https://github.com/microsoft/vscode/issues/254049; any generic `linesDecorationsHoverMessage` API and rendering support must be implemented there before flowing into Monaco.

  > Thanks for the feature request. Line decorations are rendered by the VS Code editor core, where `linesDecorationsTooltip` currently becomes a native HTML `title` attribute. The same custom-hover limitation was investigated in https://github.com/microsoft/vscode/issues/254049; maintainers found that supporting this lane requires broader margin-hover infrastructure changes and closed that work as not planned. Since Monaco cannot add this editor-core API independently, I suggest closing this as out of scope for this repository.
