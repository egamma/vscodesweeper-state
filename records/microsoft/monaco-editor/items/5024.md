## Summary

The requested capability remains missing: line-decoration tooltips still use native browser titles, while Markdown hovers target glyph margins and line numbers. Route for editor API and hover consideration; no verified open duplicate was found.

## Change summary

Provide editor-themed Markdown hovers for line decorations, comparable to glyphMarginHoverMessage.

Consider an opt-in line-decoration Markdown hover in the VS Code editor core, preserving existing linesDecorationsTooltip behavior. Monaco would inherit the capability through its generated editor and API.
