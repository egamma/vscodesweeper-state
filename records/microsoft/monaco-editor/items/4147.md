# Issue #4147 — [Bug] Decorations cannot appear after inline completions

[https://github.com/microsoft/monaco-editor/issues/4147](https://github.com/microsoft/monaco-editor/issues/4147)

## Summary

Keep open as an editor-core feature request: existing decoration APIs do not expose explicit ordering relative to inline-completion ghost text. The supplied example is sufficient to investigate; no matching canonical or concrete fix was verified.

## Change summary

Allow injected decoration text to appear after an inline completion at the same document position.

## Best solution

Establish supported ordering between embedder-injected text and ghost text in the microsoft/vscode editor core, then expose that behavior through Monaco. Preserve document-coordinate range semantics rather than treating oversized columns as positions inside unaccepted suggestions.
