# Issue #2614 — Option suggest insertMode as replace always inserts

[https://github.com/microsoft/monaco-editor/issues/2614](https://github.com/microsoft/monaco-editor/issues/2614)

## Summary

Verified duplicate of the older open TypeScript completion-range issue. Current main still supplies one range, so the editor cannot distinguish insert and replace behavior.

## Change summary

TypeScript suggestions insert text instead of replacing the remainder of the current word when suggest.insertMode is set to replace.

## Best solution

Consolidate on https://github.com/microsoft/monaco-editor/issues/1979 and update the TypeScript SuggestAdapter to provide distinct insert and replace ranges for completion items.
