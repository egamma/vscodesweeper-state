# Issue #2131 — Add possibility to add view zone inside deleted text zone in inline diff editor

[https://github.com/microsoft/monaco-editor/issues/2131](https://github.com/microsoft/monaco-editor/issues/2131)

## Summary

A real API gap remains: custom view zones can only be anchored to model lines, while inline deleted text is rendered as one synthetic view zone. The issue is already correctly classified and should remain open.

## Change summary

Allow custom content to be inserted between individual deleted lines rendered by the inline diff editor.

## Best solution

Design the capability in the VS Code editor core, likely around `diffEditorViewZones.ts`, by exposing a supported way to place custom content within an inline deleted block; it can then flow into Monaco with a release cut.

## Evidence

- **confirmed limitation:** The maintainer explicitly confirmed that inserting a view zone inside deleted text in inline mode is not currently possible: https://github.com/microsoft/monaco-editor/issues/2131#issuecomment-696647689
- **current API:** The current `IViewZone` API in https://github.com/microsoft/vscode/blob/main/src/vs/editor/browser/editorBrowser.ts only anchors zones with `afterLineNumber` and optional `afterColumn`; it has no coordinate for a line within synthetic deleted content.
- **current implementation:** Current editor-core code in https://github.com/microsoft/vscode/blob/main/src/vs/editor/browser/widget/diffEditor/components/diffEditorViewZones/diffEditorViewZones.ts renders an entire deleted range into one `deletedCodeDomNode` and adds that node as a single modified-editor view zone, leaving no public insertion point between its rendered lines.
- **canonical search:** Searches for inserting custom view zones within inline deleted text found no distinct open Monaco or VS Code issue owning this exact capability.
