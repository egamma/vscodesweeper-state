# Issue #2131 — Add possibility to add view zone inside deleted text zone in inline diff editor

[https://github.com/microsoft/monaco-editor/issues/2131](https://github.com/microsoft/monaco-editor/issues/2131)

## Summary

Keep open: inserting custom content between deleted lines in an inline diff remains an unsupported capability, not a support question. The existing modified-editor workaround does not cover the clarified request, and no matching canonical was verified.

## Change summary

Allow custom view zones between individual deleted lines in the inline diff editor without covering subsequent lines.

## Best solution

Design deleted-line anchoring and layout support in the microsoft/vscode diff-editor core, then expose the capability through Monaco's generated API. Preserve this issue's concrete placement requirement rather than treating zones above or below the deleted block as equivalent.
