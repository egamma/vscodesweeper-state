# Issue #5163 — [Bug] widgets shifted when some parent container has `transform: translateZ(0px)`

[https://github.com/microsoft/monaco-editor/issues/5163](https://github.com/microsoft/monaco-editor/issues/5163)

## Summary

Verified duplicate: the shifted hover is another manifestation of the transformed-ancestor overflow-widget positioning defect tracked by the older open canonical issue.

## Change summary

Hover widgets are offset when fixed overflow widgets are enabled and an editor ancestor establishes a transformed containing block.

## Best solution

Consolidate the transformed-ancestor positioning work in https://github.com/microsoft/monaco-editor/issues/2793; its fix should cover both suggestion and hover content widgets, while preserving this report's `translateZ(0px)` reproduction detail.
