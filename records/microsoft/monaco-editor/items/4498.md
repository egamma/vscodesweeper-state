# Issue #4498 — [Bug] editor.EditorZoom.setZoomLevel doesn't set the scale for lightBulb icon

[https://github.com/microsoft/monaco-editor/issues/4498](https://github.com/microsoft/monaco-editor/issues/4498)

## Summary

The confirmed scaling defect remains traceable in the current vscode editor core: EditorZoom scales editor fonts and line height, while the lightbulb remains a fixed 16px codicon. Route this to the editor contribution/rendering owners.

## Change summary

Make the code-action lightbulb scale consistently with editor content when EditorZoom.setZoomLevel changes the editor zoom.

## Best solution

Update the vscode editor-core LightBulbWidget styling to derive both content-widget and gutter icon dimensions from the computed editor zoom, then let the change flow into the next monaco release.
