# Issue #5205 — [Bug] Rename popup for JS/TS private members does not include the `#` character

[https://github.com/microsoft/monaco-editor/issues/5205](https://github.com/microsoft/monaco-editor/issues/5205)

## Summary

Still present on main: Monaco's TypeScript rename adapter does not resolve the TypeScript language service's rename span, so the editor falls back to the word under the cursor and excludes `#`. Route this confirmed Monaco-specific gap to the TypeScript area.

## Change summary

Preserve the `#` prefix in the rename input for JavaScript and TypeScript private members.

## Best solution

Implement `resolveRenameLocation` in `src/languages/features/typescript/languageFeatures.ts`, using `getRenameInfo` and returning its `triggerSpan` and `displayName`, matching VS Code's TypeScript rename preparation.
