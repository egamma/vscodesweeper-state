# Issue #5148 — Remove worker namespace from monaco-editor-core

[https://github.com/microsoft/monaco-editor/issues/5148](https://github.com/microsoft/monaco-editor/issues/5148)

## Summary

Keep open: this team-authored exploration has an active implementation candidate in PR 5156. Current language workers still depend on the worker namespace and synchronized mirror models, so removal requires a supported replacement first.

## Change summary

Explore replacing Monaco's worker namespace and mirror-model synchronization API with a transport-neutral library or worker-based LSP approach.

## Best solution

Develop and review https://github.com/microsoft/monaco-editor/pull/5156, ensuring the replacement supports model synchronization and non-language RPC use cases before deprecating the existing editor API. The editor-core API changes likely need coordination with the generated VS Code editor sources.
