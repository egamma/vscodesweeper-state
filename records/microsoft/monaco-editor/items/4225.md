# Issue #4225 — [Bug] Custom link scheme is not detected as link in markdown

[https://github.com/microsoft/monaco-editor/issues/4225](https://github.com/microsoft/monaco-editor/issues/4225)

## Summary

The filtering is intentional for security, but the follow-up request for an embedder-controlled scheme allowlist remains valid and is not exposed through hover providers. Keep it open and route it to editor hover.

## Change summary

Allow embedders to opt trusted custom URI schemes into Markdown links rendered in editor hovers.

## Best solution

Expose a narrowly scoped editor-core API for augmenting allowed hover Markdown link schemes while retaining the secure default allowlist. This likely belongs in the vscode editor core and can then flow into Monaco.
