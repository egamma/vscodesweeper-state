# Issue #4491 — [Bug] Inline Completions doesn't respect word wrapping when rendering (ghost text) parts of an inline suggestion as additional lines (using view line)

[https://github.com/microsoft/monaco-editor/issues/4491](https://github.com/microsoft/monaco-editor/issues/4491)

## Summary

The wrapping gap remains visible in the current vscode editor-core source: multiline ghost-text additions are rendered as fixed-width view lines with one view-zone row per logical line. Keep this open and route it to inline completions and editor wrapping.

## Change summary

Wrap additional lines of multiline inline-completion ghost text according to the editor's word-wrapping configuration.

## Best solution

Implement wrapping for additional ghost-text lines in the vscode editor core at src/vs/editor/contrib/inlineCompletions/browser/view/ghostText/ghostTextView.ts, including correct view-zone height calculation, then consume that fix in a subsequent Monaco release.
