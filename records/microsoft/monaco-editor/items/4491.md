# Issue #4491 — [Bug] Inline Completions doesn't respect word wrapping when rendering (ghost text) parts of an inline suggestion as additional lines (using view line)

[https://github.com/microsoft/monaco-editor/issues/4491](https://github.com/microsoft/monaco-editor/issues/4491)

## Summary

Keep open: the supplied provider and steps suffice to retest the clipped multiline preview. Although the editor core has evolved since the pinned development version, current upstream source still renders additional ghost-text lines without wrapping; current Monaco rendering was not executed.

## Change summary

Additional lines of multiline inline suggestions overflow instead of respecting word wrapping, while accepting the suggestion wraps the inserted text correctly.

## Best solution

Make additional ghost-text lines honor the editor's wrapping configuration in the VS Code editor core, including allocating sufficient view-zone height. The defect should be tracked at https://github.com/microsoft/vscode/issues and reach Monaco through a subsequent editor-core release cut.
