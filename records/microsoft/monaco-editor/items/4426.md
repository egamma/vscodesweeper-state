# Issue #4426 — How do I display the full suggestion detail directly

[https://github.com/microsoft/monaco-editor/issues/4426](https://github.com/microsoft/monaco-editor/issues/4426)

## Summary

A supported way to open suggestion documentation by default remains a real API gap. Route to suggest; the matching open requests are newer and do not meet this re-reviewed item's canonical bar.

## Change summary

Allow embedders to display the full suggestion-details popup automatically without an arrow click or additional Ctrl+Space.

## Best solution

Consider a supported editor option for initially expanded suggestion documentation in the VS Code editor core, then expose it through Monaco's generated API. Preserve user-controlled toggling rather than requiring private widget access or a replacement storage service.
