# Issue #4426 — How do I display the full suggestion detail directly

[https://github.com/microsoft/monaco-editor/issues/4426](https://github.com/microsoft/monaco-editor/issues/4426)

## Summary

This is a valid feature request for a public option that opens suggestion documentation by default. Current editor-core code persists visibility internally but exposes no corresponding editor option, so this older report should remain the canonical tracker.

## Change summary

Allow embedders to display the full suggestion documentation pane immediately without requiring a user command.

## Best solution

Add a public suggest option in the vscode editor core for the initial documentation-pane visibility, then inherit it in Monaco. Consolidate the newer matching reports at https://github.com/microsoft/monaco-editor/issues/5210 and https://github.com/microsoft/monaco-editor/issues/5285 into this issue.
