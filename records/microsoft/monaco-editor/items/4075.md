# Issue #4075 — [Bug] monaco monarch embedded language examples not behaving correctly

[https://github.com/microsoft/monaco-editor/issues/4075](https://github.com/microsoft/monaco-editor/issues/4075)

## Summary

Still present on main: the Monarch workbench initializes only the editor core, so the HTML and Markdown examples reference embedded languages whose tokenizers were never loaded. Route this website-owned defect while retaining the existing languages-basic classification.

## Change summary

Monarch's HTML and Markdown examples fail to syntax-highlight embedded JavaScript and other languages.

## Best solution

Load `vs/basic-languages/monaco.contribution` before constructing the Monarch examples in `website/static/monarch/monarch.js`, matching the website's normal Monaco loader, so `nextEmbedded` can resolve the referenced language IDs.

## Evidence

- **language registration:** `src/languages/definitions/javascript/register.ts` registers `javascript`, alias `js`, and MIME type `text/javascript`; these mappings become available once the basic-language contribution is loaded.
