# Issue #5254 — [Bug] Minmap  background inherits its value from ui.line instead of common.bg

[https://github.com/microsoft/monaco-editor/issues/5254](https://github.com/microsoft/monaco-editor/issues/5254)

## Summary

This behavior comes from Bitburner's application-specific theme mapping, not Monaco Editor. Bitburner explicitly assigns `ui.line` to the default token background, which Monaco uses as the minimap fallback.

## Change summary

Make the embedded editor's minimap use `common.bg` rather than `ui.line`.

## Best solution

Update Bitburner's theme construction to set `minimap.background` from `common.bg`, while retaining `ui.line` for `editor.lineHighlightBackground`.

  > Thanks for the report. `ui.line` and `common.bg` are Bitburner theme properties rather than Monaco theme color IDs. Bitburner's theme adapter explicitly uses `ui.line` as the default token background and does not set Monaco's dedicated `minimap.background` color, so Monaco falls back to that value.
