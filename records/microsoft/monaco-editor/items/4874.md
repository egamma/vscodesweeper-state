# Issue #4874 — [Bug] inlineEdit.trigger action not working as expected

[https://github.com/microsoft/monaco-editor/issues/4874](https://github.com/microsoft/monaco-editor/issues/4874)

## Summary

The playground invokes two nonexistent action IDs. Monaco 0.52.2 already provided `editor.action.inlineSuggest.trigger`, which explicitly refreshes inline suggestions and edits.

## Change summary

Trigger the registered inline-edit provider whenever the cursor position changes.

## Best solution

Use `myEditor.trigger("", "editor.action.inlineSuggest.trigger", {})`; the existing action calls the inline-completions model's explicit trigger path, so no editor change is needed.
