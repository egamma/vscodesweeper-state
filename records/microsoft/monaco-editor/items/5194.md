# Issue #5194 — [Bug] Unable to show the lightbulb icon on hover

[https://github.com/microsoft/monaco-editor/issues/5194](https://github.com/microsoft/monaco-editor/issues/5194)

## Summary

The lightbulb is absent because the provider returns a malformed workspace edit, not because Monaco fails to display available code actions. This is an API-usage question rather than an editor defect.

## Change summary

Show the lightbulb for a custom quick fix returned by a code-action provider.

## Best solution

Return each workspace text edit with `resource`, `versionId`, and `textEdit`; once the provider returns a valid action, Monaco's existing lightbulb behavior covers the request.
