# Issue #4374 — [Feature Request] Rounded scroll bar

[https://github.com/microsoft/monaco-editor/issues/4374](https://github.com/microsoft/monaco-editor/issues/4374)

## Summary

Keep open: CSS can round the scrollbar thumbs, but the requested supported appearance option remains absent from Monaco's pinned editor core. The existing editor-scrollbar label correctly routes this request.

## Change summary

Provide an option for thin, rounded scrollbar thumbs that match an embedding website's styling.

## Best solution

Decide whether to expose rounded scrollbar styling through the VS Code editor core's scrollbar options, then inherit that capability in Monaco. Existing sizing options and CSS customization are useful workarounds, not the requested supported switch.
