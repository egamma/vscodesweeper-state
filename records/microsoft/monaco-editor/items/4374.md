# Issue #4374 — [Feature Request] Rounded scroll bar

[https://github.com/microsoft/monaco-editor/issues/4374](https://github.com/microsoft/monaco-editor/issues/4374)

## Summary

The requested appearance is already supported through Monaco's documented CSS-customization pattern, while scrollbar dimensions and colors have dedicated options and theme colors. A separate rounded-scrollbar switch is unnecessary.

## Change summary

Add an editor option that switches Monaco's scrollbar thumb to a thin, rounded style.

## Best solution

Keep scrollbar shape as embedder-controlled CSS: apply `border-radius` to `.monaco-scrollable-element > .scrollbar > .slider`, use `verticalSliderSize` and `horizontalSliderSize` for thickness, and use the existing `scrollbarSlider.*` theme colors for opacity and states.

- **Proposed comment:**

  > Thanks for the suggestion. Monaco's scrollbars are custom DOM elements, and their shape can already be styled with CSS; for example:
  > 
  > ```css
  > .monaco-editor .monaco-scrollable-element > .scrollbar > .slider {
  >   border-radius: 10px;
  > }
  > ```
  > 
  > The `scrollbar` editor options also expose `verticalSliderSize` and `horizontalSliderSize` for thickness, while the `scrollbarSlider.background`, `scrollbarSlider.hoverBackground`, and `scrollbarSlider.activeBackground` theme colors control the thumb appearance. The playground's scrollbar sample demonstrates this CSS-customization pattern, so a separate rounded-style switch is not needed.
