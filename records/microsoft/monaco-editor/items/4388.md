# Issue #4388 — [Feature Request] Standalone Monarch build

[https://github.com/microsoft/monaco-editor/issues/4388](https://github.com/microsoft/monaco-editor/issues/4388)

## Summary

The standalone-package request remains distinct from Monaco's existing tokenization APIs and modular editor build. Route it to packaging and tokenization owners for a scope decision; the related documentation issue does not clearly own the standalone deliverable.

## Change summary

Publish Monarch as a standalone package with documented APIs, without requiring the Monaco editor.

## Best solution

Decide whether to support a lightweight Monarch package derived from the existing VS Code implementation, rather than maintain a separate tokenizer fork. Coordinate its API documentation with https://github.com/microsoft/monaco-editor/issues/3514.
