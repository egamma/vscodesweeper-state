# Issue #4388 — [Feature Request] Standalone Monarch build

[https://github.com/microsoft/monaco-editor/issues/4388](https://github.com/microsoft/monaco-editor/issues/4388)

## Summary

A real packaging gap remains: Monaco 0.56 provides modular ESM entry points, but not a supported standalone Monarch tokenizer package or entry point. Route this to tokenization and ESM for a scope and API-design decision.

## Change summary

Publish Monarch as a documented standalone build that can be consumed without the full Monaco editor.

## Best solution

Provide a supported, tree-shakeable Monarch entry point or separate package with documented tokenizer APIs and minimal dependencies. Because the implementation originates in the vscode editor core, extraction may require coordinated upstream changes plus Monaco packaging work.
