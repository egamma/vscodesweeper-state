# Issue #1143 — Readonly view with mobile

[https://github.com/microsoft/monaco-editor/issues/1143](https://github.com/microsoft/monaco-editor/issues/1143)

## Summary

Implemented: `domReadOnly` prevents Monaco's input textarea from invoking the mobile keyboard, and a maintainer confirmed that `{ readOnly: true, domReadOnly: true }` addresses this request.

## Change summary

Allow a read-only editor on mobile to support selection without opening the virtual keyboard.

## Best solution

Use `{ readOnly: true, domReadOnly: true }`; the dedicated option shipped in Monaco v0.24.0 and remains part of the current editor API.
