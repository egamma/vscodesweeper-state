# Issue #1143 — Readonly view with mobile

[https://github.com/microsoft/monaco-editor/issues/1143](https://github.com/microsoft/monaco-editor/issues/1143)

## Summary

The original request is covered by the shipped domReadOnly option, which makes the editor's input textarea readonly when paired with readOnly. A maintainer recommends that exact configuration; this does not establish general mobile support or resolve every touch-scrolling issue.

## Change summary

Allow selecting content in a readonly Monaco editor on mobile without opening the virtual keyboard.

## Best solution

Use { readOnly: true, domReadOnly: true } and close the original keyboard-suppression request as implemented. Treat any remaining touch-scrolling defect as a separate, reproducible editor-core report.
