# Issue #390 — Mouse selection displaced in Firefox when editor embedded in dom nodes using `translateX`

[https://github.com/microsoft/monaco-editor/issues/390](https://github.com/microsoft/monaco-editor/issues/390)

## Summary

Keep open as an upstream Firefox issue. The linked Gecko bug remains open, and maintainer analysis attributes the displaced selection to incorrect Firefox `getClientRects()` results for content inside transformed ancestors.

## Change summary

Firefox offsets mouse selection when an ancestor of the editor uses `translateX`.

## Best solution

Gecko should correct text hit-testing and client-rectangle calculations under transformed ancestors; Monaco should retain this upstream tracking issue until the browser defect is resolved or a viable workaround emerges.
