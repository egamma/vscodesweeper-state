# Issue #5311 — [Bug] High renderer memory retention with `wrappingStrategy: "advanced"` on large text in Electron (memory does not drop after closing file)

[https://github.com/microsoft/monaco-editor/issues/5311](https://github.com/microsoft/monaco-editor/issues/5311)

## Summary

Keep open: the report provides sufficient steps to retest advanced wrapping's post-close renderer memory retention. Monaco has advanced beyond the reported 0.55.1, but neither current resolution nor a canonical covering the retained-memory symptom is verified.

## Change summary

Advanced wrapping of large text reportedly leaves several gigabytes of renderer memory retained after the file is cleared.

## Best solution

Isolate post-close retention from temporary layout allocations and application model ownership using the supplied Electron reproduction. Any editor wrapping fix belongs in microsoft/vscode; browser-native retention requires separate attribution before upstream routing.

This establishes browser-layout involvement, not whether native memory is released after file closure.
