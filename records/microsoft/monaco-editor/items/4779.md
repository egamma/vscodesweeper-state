# Issue #4779 — [Bug] Unmounting component in react throws error

[https://github.com/microsoft/monaco-editor/issues/4779](https://github.com/microsoft/monaco-editor/issues/4779)

## Summary

The React unmount error is already tracked by an older, open issue in the wrapper repository. Current wrapper source and the linked application fix identify the same model-before-widget disposal order.

## Change summary

Unmounting a React DiffEditor reports that its text models were disposed before the diff widget was reset.

## Best solution

Consolidate this wrapper lifecycle defect on https://github.com/suren-atoyan/monaco-react/issues/647. Teardown should release the diff widget before its owned models, without retaining models indefinitely.
