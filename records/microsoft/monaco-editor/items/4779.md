# Issue #4779 — [Bug] Unmounting component in react throws error

[https://github.com/microsoft/monaco-editor/issues/4779](https://github.com/microsoft/monaco-editor/issues/4779)

## Summary

The failure is caused by @monaco-editor/react disposing the diff models before disposing the widget that still references them. This lifecycle-ordering defect belongs to the wrapper and is already tracked there.

## Change summary

Unmounting an @monaco-editor/react DiffEditor throws because its text models are disposed while the diff widget still references them.

## Best solution

Fix https://github.com/suren-atoyan/monaco-react/issues/647 by disposing the DiffEditor widget before its original and modified models; embedders can use the wrapper's keepCurrentOriginalModel and keepCurrentModifiedModel options while managing disposal in that order.
