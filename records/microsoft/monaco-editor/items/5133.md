# Issue #5133 — [Bug] cannot access top level languages via `monaco-editor/esm/vs/editor/editor.api.js`

[https://github.com/microsoft/monaco-editor/issues/5133](https://github.com/microsoft/monaco-editor/issues/5133)

## Summary

The central problem is resolved by the typed, modular language entry points shipped in v0.56.0. Minimal bundles can configure TypeScript without importing the all-inclusive editor entry.

## Change summary

TypeScript defaults are inaccessible through the minimal editor entry, and the suggested language contribution import lacks usable declarations in v0.55.1.

## Best solution

Use monaco-editor/editor for the minimal editor and import typescriptDefaults separately from monaco-editor/languages/features/typescript/register. Keep language support separate rather than adding it to the editor-only entry.

  > 
  > ```ts
  > import * as monaco from 'monaco-editor/editor';
  > import { typescriptDefaults } from 'monaco-editor/languages/features/typescript/register';

  > typescriptDefaults.setDiagnosticsOptions(diagnosticsOptions);
  > ```
