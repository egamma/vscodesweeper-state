# Issue #45 — API to hide parts of the code

[https://github.com/microsoft/monaco-editor/issues/45](https://github.com/microsoft/monaco-editor/issues/45)

## Summary

A real API gap remains: hidden areas exist only as an internal editor-core facility, while protected editable ranges have no supported replacement. This broad, oldest report should remain open rather than be folded into the narrower read-only-ranges request.

## Change summary

Provide supported APIs for hiding generated code and restricting edits to selected ranges while retaining the complete model for language features.

## Best solution

Add supported hidden-area ownership and protected-range APIs in the vscode editor core, then expose them through Monaco. Hidden regions should coexist with folding, searching, formatting, and secondary editors without allowing generated code to be modified.
