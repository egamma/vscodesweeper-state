# Issue #45 — API to hide parts of the code

[https://github.com/microsoft/monaco-editor/issues/45](https://github.com/microsoft/monaco-editor/issues/45)

## Summary

Keep open: supported hiding and edit protection for generated wrappers remain unmet. Existing APIs and community workarounds cover portions of the request, but not the complete class-context editing experience.

## Change summary

Provide a supported way to hide and protect generated headers and footers while retaining their context for code completion.

## Best solution

Resolve the supported hidden-area and editable-region contract in the microsoft/vscode editor core, then expose it through Monaco's generated API. Preserve the complete model for language services without allowing ordinary editing operations to modify the generated wrapper.
