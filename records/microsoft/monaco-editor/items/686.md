## Summary

Consolidate this request into the older, open editor-serialization issue, which explicitly covers persisting and restoring undo history. Retaining a live model addresses editor recreation but not the requested serialization.

## Change summary

Provide a supported API to serialize and restore a model's undo/redo history without retaining the original model in memory.
