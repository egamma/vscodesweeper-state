# Issue #2762 — Incorrectly bolding markdown

[https://github.com/microsoft/monaco-editor/issues/2762](https://github.com/microsoft/monaco-editor/issues/2762)

## Summary

The whitespace-sensitive bolding defect remains in the current Markdown grammar. Keep this correctly routed issue open; the existing tokenization harness supports a bounded community fix.

## Change summary

Markdown incorrectly highlights double-asterisk spans as bold when their content starts or ends with whitespace.

## Best solution

Make Monaco's bundled Markdown grammar distinguish valid strong emphasis from the three whitespace-padded examples, preserving valid bold text and unrelated Markdown highlighting. This is suitable for a community PR in the Monaco-owned language definition, consistent with the maintainer's invitation.
