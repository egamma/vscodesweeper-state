# Issue #2762 — Incorrectly bolding markdown

[https://github.com/microsoft/monaco-editor/issues/2762](https://github.com/microsoft/monaco-editor/issues/2762)

## Summary

The bug remains in current source: Monaco's Markdown tokenizer recognizes strong emphasis even when whitespace follows the opening delimiter or precedes the closing delimiter. The issue already has the correct languages-basic routing and is suitable for a community PR.

## Change summary

Make Markdown strong-emphasis highlighting reject delimiter-adjacent whitespace, matching GFM and VS Code behavior.

## Best solution

Refine the strong-emphasis rules in src/languages/definitions/markdown/markdown.ts and add coverage in markdown.test.ts for valid and whitespace-invalid asterisk and underscore forms.
