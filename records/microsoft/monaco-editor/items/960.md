# Issue #960 — Expose background color override for editorOverview

[https://github.com/microsoft/monaco-editor/issues/960](https://github.com/microsoft/monaco-editor/issues/960)

## Summary

Implemented in the VS Code editor core and shipped with Monaco v0.21.0: themes can override the overview ruler background using `editorOverviewRuler.background`.

## Change summary

Expose a theme color for overriding the editor overview ruler background.

## Best solution

Use the shipped `editorOverviewRuler.background` theme color; its null default preserves the editor-derived background behavior when no override is defined.
