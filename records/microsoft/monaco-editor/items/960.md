# Issue #960 — Expose background color override for editorOverview

[https://github.com/microsoft/monaco-editor/issues/960](https://github.com/microsoft/monaco-editor/issues/960)

## Summary

The requested override is implemented as editorOverviewRuler.background and is consumed by Monaco's pinned editor core. A completed close is appropriate; the first shipping Monaco release was not established.

## Change summary

Expose a custom overview ruler background color independently of the base theme.

## Best solution

Use editorOverviewRuler.background in the colors supplied to monaco.editor.defineTheme(), then activate that theme with monaco.editor.setTheme(). Preserve the existing background fallback when the override is omitted.
