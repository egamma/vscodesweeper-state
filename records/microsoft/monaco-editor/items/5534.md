# Issue #5534 — [Feature Request] Close error report when underlying problem is fixed

[https://github.com/microsoft/monaco-editor/issues/5534](https://github.com/microsoft/monaco-editor/issues/5534)

## Summary

The request remains unmet: the current editor core deliberately retains the problem widget when its diagnostic disappears. Route this accessibility improvement to editor contributions; the behavioral change belongs in microsoft/vscode.

## Change summary

Automatically dismiss the F8 problem widget when its underlying diagnostic is resolved, avoiding obsolete messages for keyboard and screen-reader users.

## Best solution

Consider automatic dismissal of resolved diagnostics in the VS Code editor core, preserving keyboard focus and navigation to remaining problems. Monaco would inherit the accepted behavior through its generated editor sources.
