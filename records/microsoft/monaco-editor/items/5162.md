# Issue #5162 — [Bug] Import any language now also includes all the features

[https://github.com/microsoft/monaco-editor/issues/5162](https://github.com/microsoft/monaco-editor/issues/5162)

## Summary

Fixed and released in v0.56.0: language definitions and editor features now have separate tree-shakeable entry points, eliminating the v0.55 behavior where importing a language pulled in every editor feature.

## Change summary

Importing any language in v0.55 unintentionally includes all editor feature contributions and significantly increases bundle size.

## Best solution

Use Monaco v0.56.0 or later and import `monaco-editor/editor` plus the required `monaco-editor/languages/definitions/<language>/register` and feature entry points.
