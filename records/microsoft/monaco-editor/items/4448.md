# Issue #4448 — [Bug] DiffEditor with glyphMargin: false, still renders glyphMargin when rendered side by side.

[https://github.com/microsoft/monaco-editor/issues/4448](https://github.com/microsoft/monaco-editor/issues/4448)

## Summary

Verified cross-repository duplicate: the open VS Code issue tracks the same side-by-side diff behavior, where the original editor forces its glyph margin on despite `glyphMargin: false`.

## Change summary

The side-by-side diff editor ignores `glyphMargin: false` for its original editor.

## Best solution

Consolidate this editor-core defect on https://github.com/microsoft/vscode/issues/234728. The VS Code implementation should preserve the configured `glyphMargin` value instead of overriding it from `renderSideBySide`; that fix will flow into Monaco with a subsequent release.
