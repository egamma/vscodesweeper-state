# Issue #4348 — [Bug] alwaysConsumeMouseWheel property does not seem to work on mobile

[https://github.com/microsoft/monaco-editor/issues/4348](https://github.com/microsoft/monaco-editor/issues/4348)

## Summary

This is a request for touch-scroll chaining rather than a bug in `alwaysConsumeMouseWheel`, which is explicitly limited to wheel events. The same request was previously declined in https://github.com/microsoft/monaco-editor/issues/4108 after a workaround was documented.

## Change summary

Allow page scrolling to continue when a mobile touch gesture reaches the editor's scroll boundary.

## Best solution

Keep the existing mouse-wheel-only option contract and direct embedders needing nested mobile scrolling to the workaround in https://github.com/microsoft/monaco-editor/issues/4108. Any future native implementation would need to change the vscode editor-core touch gesture path.
