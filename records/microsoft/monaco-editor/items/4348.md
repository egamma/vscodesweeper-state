# Issue #4348 — [Bug] alwaysConsumeMouseWheel property does not seem to work on mobile

[https://github.com/microsoft/monaco-editor/issues/4348](https://github.com/microsoft/monaco-editor/issues/4348)

## Summary

The requested mobile touch-scroll handoff extends a mouse-wheel option beyond its documented contract. The repository explicitly excludes mobile-browser support, so an out-of-scope close is supported by published policy.

## Change summary

Allow mobile touch scrolling to continue into the surrounding page when the editor reaches its scroll boundary.

## Best solution

Keep the documented mouse-wheel contract and mobile-support boundary rather than treating touch scrolling as a failure of alwaysConsumeMouseWheel. Supporting touch-scroll handoff would require an explicit scope decision and work in the VS Code editor core.
