# Issue #4423 — [Bug] The setMonarchTokensProvider rule matches incorrectly

[https://github.com/microsoft/monaco-editor/issues/4423](https://github.com/microsoft/monaco-editor/issues/4423)

## Summary

This is a Monarch tokenizer configuration question rather than an editor defect. Keywords should be classified after matching the complete identifier instead of using lookbehind around an isolated keyword rule.

## Change summary

Highlight `Stop` as a keyword only when it is the complete token, not when it appears within a longer word.

## Best solution

Match complete words or identifiers and use a Monarch `cases` action with `@keywords`, following the built-in C++ tokenizer pattern.
