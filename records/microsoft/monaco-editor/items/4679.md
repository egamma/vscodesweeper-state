[https://github.com/microsoft/monaco-editor/issues/4679](https://github.com/microsoft/monaco-editor/issues/4679)

## Summary

Confirmed Firefox selection defect in shadow-DOM embeddings. Keep open because an active VS Code PR explicitly addresses this issue's root cause and must be reviewed and merged before the fix can flow into Monaco.

## Change summary

Mouse selection fails or throws during Firefox hit testing when Monaco is embedded in a shadow root.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/313960 in the VS Code editor core, then carry that change into the next Monaco release and verify the supplied shadow-DOM playground reproduction.
