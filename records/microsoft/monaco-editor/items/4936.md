# Issue #4936 — [Feature Request] Minimap background color improvements

[https://github.com/microsoft/monaco-editor/issues/4936](https://github.com/microsoft/monaco-editor/issues/4936)

## Summary

Function-specific background bands remain distinct from existing minimap decorations and section headers. Route to the minimap area; related VS Code requests do not establish an exact duplicate of this re-reviewed item.

## Change summary

Visually segment function bodies with distinct minimap background colors so their boundaries, sizes, and the viewport's position are apparent.

## Best solution

Consider optional function-range background segmentation in the VS Code editor core, inherited by Monaco. Existing minimap decorations offer an embedder-controlled building block, but do not automatically identify and color function bodies.

  > Thanks for the suggestion. Minimap decorations can already color supplied ranges, and section headers can mark regions or MARK comments, but neither automatically segments function bodies into differently colored bands. Built-in support would belong in the VS Code editor core: https://github.com/microsoft/vscode/issues. ## Evidence

- **Requested capability:** https://github.com/microsoft/monaco-editor/issues/4936 requests colored function-sized segments that reveal function count, relative sizes, boundaries, and viewport position; it is not merely a request for a global minimap background color.
- **Existing decoration capability:** https://github.com/microsoft/vscode/blob/main/src/vs/editor/common/model.ts exposes IModelDecorationOptions.minimap and IModelDecorationMinimapOptions.color/position. https://github.com/microsoft/vscode/blob/main/src/vs/editor/browser/viewParts/minimap/minimap.ts implements range-based line highlights in _renderDecorationsLineHighlights. These require supplied ranges and colors rather than automatically discovering functions.
- **Existing section headers are partial coverage:** https://github.com/microsoft/vscode/blob/main/src/vs/editor/common/config/editorOptions.ts defines region/MARK section-header options but no function-background segmentation option. SectionHeaderDetector in https://github.com/microsoft/vscode/blob/main/src/vs/editor/contrib/sectionHeaders/browser/sectionHeaders.ts constructs text-header decorations with color undefined, not colored function-body bands.
- **Related issues verified, not exact canonicals:** https://github.com/microsoft/vscode/issues/74891 is open in Backlog and discusses function-name labels and highlighting, but does not establish coverage of distinct background bands spanning complete function bodies. https://github.com/microsoft/vscode/issues/50047 is open and requests an outline view in the minimap location, a different observable capability. Neither clears the same-symptom duplicate bar for this re-reviewed item.
