# Issue #5532 — [Bug] Duplicate or incorrect Japanese localization for Monaco Editor cursor actions

[https://github.com/microsoft/monaco-editor/issues/5532](https://github.com/microsoft/monaco-editor/issues/5532)

## Summary

The duplicate Japanese labels are confirmed in monaco-editor-core@0.56.0 and remain identical in the current upstream Japanese translation source. Keep this open pending an upstream translation correction; no matching canonical issue was verified.

## Change summary

Distinguish Japanese labels for adding one cursor above or below from adding cursors through the top or bottom of the document.

## Best solution

Correct the Japanese multicursor translations in microsoft/vscode-loc, preserving the distinction between adjacent-line and document-wide cursor actions, then consume the corrected translations in a Monaco release.

- **Current upstream source:** https://github.com/microsoft/vscode-loc/blob/main/i18n/vscode-language-pack-ja/translations/main.i18n.json still assigns those identical pairs to mutlicursor.insertAbove/mutlicursor.addCursorsToTop and mutlicursor.insertBelow/mutlicursor.addCursorsToBottom in vs/editor/contrib/multicursor/browser/multicursor.
- **Distinct command behavior:** https://github.com/microsoft/vscode/blob/main/src/vs/editor/contrib/multicursor/browser/multicursor.ts uses separate localization keys for all four actions. InsertCursorAbove/Below call addCursorUp/Down, whereas addCursorsToBottom/Top construct selections through the last/first document line.
