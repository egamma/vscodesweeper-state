# Issue #4515 — [Feature Request] Does monao-editor support the jupyter-notebook?

[https://github.com/microsoft/monaco-editor/issues/4515](https://github.com/microsoft/monaco-editor/issues/4515)

## Summary

This asks how to build a notebook with Monaco rather than identifying a concrete missing editor capability. Answer the library-boundary question and redirect integration guidance to StackOverflow.

## Change summary

Explain whether LSP 3.17 notebook support enables creating a Jupyter-style notebook with Monaco.

## Best solution

Use Monaco as the text-editing component within an embedding application's notebook interface; LSP notebook protocol support does not provide notebook UI or kernel execution. Treat this report as an integration question rather than a notebook implementation request.

- **Proposed comment:**

  > Thanks for the question. Monaco can provide the text editors inside a notebook application, but LSP 3.17 notebook support describes communication with language servers; it does not supply a notebook interface or Jupyter kernel execution. Those parts belong to the embedding application. Bundling notebook functionality was previously declined in https://github.com/microsoft/monaco-editor/issues/2526.
