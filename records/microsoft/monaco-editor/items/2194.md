# Issue #2194 — Copying non-syntax-highlighted plain text removes formatting

[https://github.com/microsoft/monaco-editor/issues/2194](https://github.com/microsoft/monaco-editor/issues/2194)

## Summary

Keep open: the bundled editor core explicitly skips rich-text generation for plaintext models, and the existing copy-with-highlighting controls do not cover preserving their font and formatting. No qualifying open canonical was found.

## Change summary

Preserve editor formatting when copying non-syntax-highlighted text into a rich-text application.

## Best solution

Have the VS Code editor core support formatted clipboard output for plaintext models while preserving plain-text clipboard content. Carry the resulting behavior into Monaco through its normal core update.
