# Issue #2194 — Copying non-syntax-highlighted plain text removes formatting

[https://github.com/microsoft/monaco-editor/issues/2194](https://github.com/microsoft/monaco-editor/issues/2194)

## Summary

The requested capability remains absent: current editor-core code deliberately omits rich-text clipboard data for plain-text models. The issue is already correctly classified and should remain open pending a VS Code editor-core decision.

## Change summary

Include the editor's font and layout formatting in rich-text clipboard output even when the model uses the plain-text language.

## Best solution

Change `getRichTextToCopy` in the VS Code editor core to generate HTML for plain-text models, while retaining `copyWithSyntaxHighlighting` as the controlling option; Monaco would receive the behavior in a subsequent source update.
