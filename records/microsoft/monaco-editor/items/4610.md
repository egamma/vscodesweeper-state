# Issue #4610 — [Feature Request] Remove vertical scrollbar and corresponding space

[https://github.com/microsoft/monaco-editor/issues/4610](https://github.com/microsoft/monaco-editor/issues/4610)

## Summary

The requested configuration already exists: verticalScrollbarSize: 0 removes the scrollbar's reserved width, while vertical: 'hidden' controls visibility. Treat this as a configuration question rather than missing functionality.

## Change summary

Hide the vertical scrollbar without retaining the space allocated to it.

## Best solution

Use scrollbar: { vertical: 'hidden', verticalScrollbarSize: 0 }; no new editor capability is needed.
