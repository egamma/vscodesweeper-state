# Issue #4610 — [Feature Request] Remove vertical scrollbar and corresponding space

[https://github.com/microsoft/monaco-editor/issues/4610](https://github.com/microsoft/monaco-editor/issues/4610)

## Summary

The existing `scrollbar.verticalScrollbarSize` option already removes the reserved width when set to `0`, so no new editor capability is needed.

## Change summary

Allow embedders to hide the vertical scrollbar without reserving space for it.

## Best solution

Use `scrollbar: { vertical: 'hidden', verticalScrollbarSize: 0 }`; the editor layout already derives the reserved space from this size.

## Vision fit

- **Fit:** aligned
- **Reason:** The existing configurable editor API supports embedder-specific layout without introducing Monaco-only editor behavior.
- **Evidence:** The vision describes Monaco as a browser library whose embedders integrate through its API.
