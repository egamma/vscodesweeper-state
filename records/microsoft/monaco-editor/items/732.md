# Issue #732 — Support JavaScript intellisense inside HTML

[https://github.com/microsoft/monaco-editor/issues/732](https://github.com/microsoft/monaco-editor/issues/732)

## Summary

This remains the oldest and broadest Monaco issue for JavaScript IntelliSense in HTML. Current main provides JavaScript tokenization inside script tags but routes completion requests only through the HTML language service, so the requested semantic support is still absent.

## Change summary

Provide JavaScript IntelliSense within HTML script blocks, including symbols imported from other models or modules.

## Best solution

Add embedded-document delegation between the HTML and JavaScript/TypeScript language workers, with source-position mapping and module resolution across Monaco models. The ongoing VS Code implementation at https://github.com/microsoft/vscode/pull/171547 is useful design precedent, but Monaco still needs corresponding browser-library integration.

## Evidence

- **current source gap:** src/languages/features/html/htmlMode.ts registers completion for HTML models through HTMLCompletionAdapter only, while src/languages/features/html/htmlWorker.ts delegates doComplete exclusively to vscode-html-languageservice; there is no JavaScript/TypeScript worker delegation for script regions.
- **tokenization is partial coverage:** src/languages/definitions/html/html.ts marks script contents with nextEmbedded: 'text/javascript', providing embedded syntax tokenization but not semantic IntelliSense or cross-model module resolution.
- **VS Code implementation remains open:** https://github.com/microsoft/vscode/pull/171547 is still open and proposes Volar-based embedded-document and cross-file semantic support for https://github.com/microsoft/vscode/issues/26338 and https://github.com/microsoft/vscode/issues/114115.
- **canonical assessment:** https://github.com/microsoft/monaco-editor/issues/2962 covers the narrower script-type recognition case, while this older issue owns the broader missing IntelliSense capability and should remain the Monaco canonical.
