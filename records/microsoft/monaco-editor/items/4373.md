# Issue #4373 — [Feature Request] 

[https://github.com/microsoft/monaco-editor/issues/4373](https://github.com/microsoft/monaco-editor/issues/4373)

## Summary

The requested always-below placement remains unsupported: the current editor core prioritizes side placement, and the suggestion options do not expose a details-placement preference. Keep this request open; the capability requires a decision and implementation in the VS Code editor core.

## Change summary

Allow embedders to keep suggestion documentation below the suggestion list regardless of available horizontal space.

## Best solution

Consider a supported details-placement preference in the VS Code editor core while preserving automatic placement by default. Monaco would inherit that capability through its core update rather than relying on CSS overrides.
