# Issue #2984 — [Feature Request]  Provide API to leave snippet mode

[https://github.com/microsoft/monaco-editor/issues/2984](https://github.com/microsoft/monaco-editor/issues/2984)

## Summary

The public editor command API already covers this request: embedders can trigger the registered `leaveSnippet` command without accessing the private snippet contribution.

## Change summary

Expose a supported API for programmatically leaving snippet mode.

## Best solution

Use `editor.trigger('api', 'leaveSnippet', null)`; this invokes the existing snippet-exit command through Monaco's public editor API and avoids the private `snippetController2` contribution.

## Vision fit

- **Fit:** aligned
- **Reason:** Using Monaco's public editor API rather than an internal contribution matches its browser-library integration boundary.
- **Evidence:** The vision states that embedders integrate Monaco through its API.
