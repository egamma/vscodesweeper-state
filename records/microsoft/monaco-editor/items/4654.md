# Issue #4654 — [Bug] v0.51.0 breaks for browser based imports

[https://github.com/microsoft/monaco-editor/issues/4654](https://github.com/microsoft/monaco-editor/issues/4654)

## Summary

Fixed since v0.53.0: Monaco now creates ESM workers as module workers, and the webpack plugin emits an ESM import instead of importScripts in module contexts.

## Change summary

Upgrading from v0.50.0 caused browser-based ESM integrations to load workers through importScripts, which cannot run in a module worker.

## Best solution

Keep the module-worker implementation shipped in v0.53.0 and use Monaco's ESM build with a supported bundler; the deprecated unbundled browser-script/AMD integration is no longer supported.
