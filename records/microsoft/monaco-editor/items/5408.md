# Issue #5408 — [Bug] 0.56.0 The border radius theme variable is missing.

[https://github.com/microsoft/monaco-editor/issues/5408](https://github.com/microsoft/monaco-editor/issues/5408)

## Summary

Confirmed in current editor-core source: Monaco's standalone theme service emits registered color variables but omits the size registry, so the registered corner-radius variables are absent. This remains open and belongs in the vscode standalone theming implementation.

## Change summary

Expose VS Code's registered corner-radius size variables in Monaco's standalone theme CSS.

## Best solution

Update `src/vs/editor/standalone/browser/standaloneThemeService.ts` in microsoft/vscode to emit size-registry variables as the workbench theme service does, then bring that editor-core fix into the next Monaco release. The separately listed `widget.border` and `shadow.xl` names should be evaluated independently because they are not size tokens.
