# Issue #1770 — Improve Go syntax highlighting

[https://github.com/microsoft/monaco-editor/issues/1770](https://github.com/microsoft/monaco-editor/issues/1770)

## Summary

A real highlighting gap remains: the current Go Monarch grammar still classifies both `fmt` and `Println` as generic identifiers. The issue is already correctly routed as an open-for-PR grammar improvement in the Backlog.

## Change summary

Improve Go tokenization so qualified functions and methods such as `fmt.Println` receive more informative syntax highlighting.

## Best solution

Enhance `src/languages/definitions/go/go.ts` to classify qualified members or function calls more precisely, with corresponding tokenizer cases in `go.test.ts`. This remains suitable for a community PR, provided the behavior can be expressed reliably by the lexical Monarch grammar.
