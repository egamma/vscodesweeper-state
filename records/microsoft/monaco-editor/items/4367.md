# Issue #4367 — [Bug] `Toggle Tab Key Moves Focus` missing from Command Palette

[https://github.com/microsoft/monaco-editor/issues/4367](https://github.com/microsoft/monaco-editor/issues/4367)

## Summary

The standalone command palette still excludes the tab-focus toggle: it lists editor actions, while this command is registered through Action2. Keep this confirmed accessibility bug open and route it to the editor command owners.

## Change summary

Restore discovery of Toggle Tab Key Moves Focus in Monaco's command palette while preserving its working keyboard shortcut.

## Best solution

Restore the toggle's visibility in the standalone command palette through the vscode-derived editor core, preserving its keyboard behavior. The editor-core change belongs in https://github.com/microsoft/vscode/issues and should flow into Monaco through a subsequent release.
