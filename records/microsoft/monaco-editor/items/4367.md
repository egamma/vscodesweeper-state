# Issue #4367 — [Bug] `Toggle Tab Key Moves Focus` missing from Command Palette

[https://github.com/microsoft/monaco-editor/issues/4367](https://github.com/microsoft/monaco-editor/issues/4367)

## Summary

The regression remains traceable in current source: the toggle became a global Action2, while Monaco's standalone command palette only enumerates editor-supported actions. Route this confirmed accessibility discoverability bug to editor commands and accessibility.

## Change summary

Restore “Toggle Tab Key Moves Focus” to Monaco's standalone Command Palette while retaining its Ctrl+M keybinding.

## Best solution

Fix the vscode editor core so Monaco's standalone command provider includes this F1-enabled Action2, or expose the toggle as an editor-supported action again without losing its global behavior. The correction should land in microsoft/vscode and flow into the next Monaco release.

## Evidence

- **current registration:** Current Monaco src/features/toggleTabFocusMode/register.js imports the vscode toggle contribution, while https://github.com/microsoft/vscode/blob/main/src/vs/editor/contrib/toggleTabFocusMode/browser/toggleTabFocusMode.ts still registers it through registerAction2.
- **reproduction:** The report provides https://microsoft.github.io/monaco-editor/playground.html?source=v0.36.0#example-creating-the-editor-hello-world and confirms Ctrl+M still invokes the command, isolating the defect to command-palette discoverability.
