# Issue #5216 — [Bug] RegExp d Modifier

[https://github.com/microsoft/monaco-editor/issues/5216](https://github.com/microsoft/monaco-editor/issues/5216)

## Summary

Verified duplicate: the open canonical issue tracks the same editor-core dependency on the RegExp `d` flag in browsers that do not support it. This report adds Chrome 79 as another affected environment.

## Change summary

Loading Monaco's generated worker fails in Chrome 79 because `findSectionHeaders` constructs a regular expression with the unsupported `d` flag.

## Best solution

Consolidate browser-compatibility work on https://github.com/microsoft/monaco-editor/issues/4557; any fallback must be implemented in the vscode editor core and then flow into Monaco.
