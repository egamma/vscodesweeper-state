# Issue #4546 — [Bug] Cannot run monaco with lit and webpack

[https://github.com/microsoft/monaco-editor/issues/4546](https://github.com/microsoft/monaco-editor/issues/4546)

## Summary

The attached project conclusively identifies duplicate custom-element registration in the embedding application, not Monaco. Its shadow-root styling also omits Monaco's CSS; this is an integration-support question rather than a demonstrated editor defect.

## Change summary

Embedding Monaco with Lit and webpack throws a duplicate custom-element registration error, with additional autocomplete and cursor concerns.

## Best solution

Register the Lit component once, load the generated bundle once, and include Monaco's styles inside its shadow root. Any remaining autocomplete or cursor defect needs an isolated reproduction after those integration problems are corrected.
