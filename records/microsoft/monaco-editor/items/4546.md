# Issue #4546 — [Bug] Cannot run monaco with lit and webpack

[https://github.com/microsoft/monaco-editor/issues/4546](https://github.com/microsoft/monaco-editor/issues/4546)

## Summary

This is an embedding-code issue rather than a Monaco defect: Lit is attempting to register `my-component` more than once before `monaco.editor.create` runs.

## Change summary

A Lit custom element embedding Monaco fails because its custom-element name is registered twice.

## Best solution

Ensure the embedding application registers `my-component` exactly once; the `@customElement` decorator already performs registration, so any additional registration or duplicate module execution must be removed.
