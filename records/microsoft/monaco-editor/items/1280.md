# Issue #1280 — How can I customize context menu? I want to delete 'Go to definition' and others,and add my own meun.

[https://github.com/microsoft/monaco-editor/issues/1280](https://github.com/microsoft/monaco-editor/issues/1280)

## Summary

This remains the canonical feature request for publicly customizing the editor context menu. Current APIs can add actions or disable the entire menu, but removing built-in entries still requires unsupported private internals.

## Change summary

Expose supported APIs for removing built-in context-menu entries and adding a fully customized set of actions.

## Best solution

Add a public standalone-editor API in the vscode editor core for filtering or removing default context-menu entries without accessing MenuRegistry or contribution internals. Submenu support remains separately tracked by https://github.com/microsoft/monaco-editor/issues/1947.
