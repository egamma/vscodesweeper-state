# Issue #5014 — [Bug] Uncaught (in promise) Error: [invokeFunction] unknown service 'productService'

[https://github.com/microsoft/monaco-editor/issues/5014](https://github.com/microsoft/monaco-editor/issues/5014)

## Summary

Fixed in the vscode editor core and shipped with Monaco v0.56.0: paste actions no longer request the unavailable IProductService in standalone editors.

## Change summary

Paste as Text throws an unknown productService error and fails to paste in standalone Monaco.

## Best solution

Keep the editor-core fix that removes the unnecessary product and telemetry service dependencies from PasteAction; embedders should update to Monaco v0.56.0 or later.
