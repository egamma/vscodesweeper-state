# Issue #4474 — [Bug] paste by ctrl+v not working inside editor after update to 0.46.0

[https://github.com/microsoft/monaco-editor/issues/4474](https://github.com/microsoft/monaco-editor/issues/4474)

## Summary

Fixed upstream: this matches the Monaco 0.46.0 platform-detection regression that disabled clipboard shortcuts when a browser build exposed a process polyfill. The VS Code editor-core fix shipped in Monaco v0.48.0, where a reporter confirmed clipboard behavior was restored.

## Change summary

Ctrl+V stopped pasting after upgrading Monaco Editor from v0.44.0 to v0.46.0, while Ctrl+Shift+V continued working.

## Best solution

Keep the stricter Node.js environment detection shipped in Monaco v0.48.0 and close this report as resolved; embedders should upgrade from v0.46.0.
