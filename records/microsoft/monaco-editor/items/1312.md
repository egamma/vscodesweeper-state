# Issue #1312 — Go to line for Custom Line Numbers Problem

[https://github.com/microsoft/monaco-editor/issues/1312](https://github.com/microsoft/monaco-editor/issues/1312)

## Summary

A genuine API gap remains: custom line-number formatting changes only gutter rendering, while Go to Line still interprets input as model line numbers. The request is already appropriately classified and parked in Backlog.

## Change summary

Allow Go to Line to resolve custom displayed line numbers to their corresponding model lines.

## Best solution

Add a generalized display-to-model line mapping hook in the vscode editor core's Go to Line provider, paired with the existing model-to-display formatter, so it flows into Monaco on a subsequent release. This looks suitable for an accepted design discussion or community PR once the API shape is agreed.
