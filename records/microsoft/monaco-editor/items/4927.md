# Issue #4927 — [Bug] Monaco editor used inline styling that violates Content Security Policy for a web application

## Summary

Keep open while https://github.com/microsoft/vscode/pull/288813 remains an active implementation candidate that explicitly references this issue. The broader CSP capability is tracked by https://github.com/microsoft/monaco-editor/issues/271.

## Change summary

Support Monaco under a strict Content Security Policy without permitting inline styles or unsafe worker and font sources.
