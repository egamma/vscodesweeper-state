# Issue #5517 — Update bundled DOMPurify to 3.4.16+ in Monaco Editor 0.57.0 (XSS advisories)

[https://github.com/microsoft/monaco-editor/issues/5517](https://github.com/microsoft/monaco-editor/issues/5517)

## Summary

Thanks to everyone tracking this. Main is prepared for 0.58.0 and its CHANGELOG records 'Updates bundled DOMPurify from 3.4.15 to 3.4.17', which covers all three advisories raised in the thread (GHSA-p98j-92pf-mc4p, GHSA-6688-9rhm-gjv2, GHSA-cg2g-xh64-v4q7). This is a security-sensitive report, so it stays open under the hard keep-open rule; a maintainer should close it manually once 0.58.0 is published and the bundled copy is confirmed.

## Change summary

Monaco 0.57.0 bundles DOMPurify 3.4.15, which is affected by publicly disclosed XSS advisories, and npm overrides cannot replace the bundled copy.

## Best solution

Publish monaco-editor 0.58.0, which bundles DOMPurify 3.4.17. A maintainer should then confirm that esm/vs/base/browser/dompurify/dompurify.js in the published package reports 3.4.17 and close this issue manually, pointing to the release.
