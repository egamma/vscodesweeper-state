# Issue #2254 — getVisibleRanges: allow for partial visibility

[https://github.com/microsoft/monaco-editor/issues/2254](https://github.com/microsoft/monaco-editor/issues/2254)

## Summary

A real API gap remains: the current editor core still returns only completely visible lines, and no public option exposes partial visibility. The existing editor-api classification is appropriate.

## Change summary

Allow getVisibleRanges to include partially visible lines so scroll synchronization remains continuous.

## Best solution

Add a backward-compatible option or separate API in the VS Code editor core for ranges intersecting the viewport, preserving getVisibleRanges()'s current default. This looks suitable for an open community PR in microsoft/vscode.
