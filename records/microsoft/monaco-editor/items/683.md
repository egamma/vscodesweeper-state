# Issue #683 — Expose quick-open functionality

[https://github.com/microsoft/monaco-editor/issues/683](https://github.com/microsoft/monaco-editor/issues/683)

## Summary

Keep open: custom searchable selection lists remain unsupported by Monaco's public API. The internal-service workaround does not satisfy the request, and the related reports do not provide an open canonical covering its full scope.

## Change summary

Expose supported quick-input functionality so custom editor actions can present searchable choices and execute the selected operation.

## Best solution

Expose a supported standalone quick-pick API through the vscode-derived editor API, reusing the existing quick-input implementation. The API work belongs in microsoft/vscode; this accepted Monaco request should remain the tracking item until that capability is available.
