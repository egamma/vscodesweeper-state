# Issue #5126 — [Bug] Missing type declarations for basic-languages/typescript/typescript

[https://github.com/microsoft/monaco-editor/issues/5126](https://github.com/microsoft/monaco-editor/issues/5126)

## Summary

The declaration-generation gap remains on current main: language definitions are loaded dynamically but are not declaration entry points. Keep this correctly labeled issue open; migrating the import path alone does not supply the missing types.

## Change summary

Importing TypeScript's language configuration and tokenizer for a custom language fails during TypeScript compilation because the package omits their declarations.

## Best solution

Ship usable declarations for the exported language definitions at the current package subpaths through Monaco's declaration build. Preserve runtime registration behavior and handle legacy-path compatibility separately.
