# Issue #5126 — [Bug] Missing type declarations for basic-languages/typescript/typescript

[https://github.com/microsoft/monaco-editor/issues/5126](https://github.com/microsoft/monaco-editor/issues/5126)

## Summary

Resolved by the supported, typed ESM entry points shipped in v0.56.0. The old `esm/vs/basic-languages/...` deep import should be migrated to `monaco-editor/languages/definitions/typescript/typescript`.

## Change summary

Restore TypeScript declarations when importing the TypeScript Monarch configuration in an ESM application.

## Best solution

Use the supported v0.56.0 module `monaco-editor/languages/definitions/typescript/typescript`, which exports the typed `conf` and `language` values; the former internal deep-import path should not be restored.
