# Issue #4764 — [Bug]  customized Diff-Algorithm, needed for diff-editor

[https://github.com/microsoft/monaco-editor/issues/4764](https://github.com/microsoft/monaco-editor/issues/4764)

## Summary

This is a valid request for a stable custom diff-provider API, not a bug. The demonstrated service override uses private modules that may break between releases, while the current public API only supports built-in algorithms.

## Change summary

Provide a supported way to supply a custom diff algorithm to the diff editor across Monaco upgrades.

## Best solution

Design a public custom document-diff provider API in the VS Code editor core and expose it through Monaco's versioned declarations, avoiding private service and module imports.
