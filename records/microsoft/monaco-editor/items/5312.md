[https://github.com/microsoft/monaco-editor/issues/5312](https://github.com/microsoft/monaco-editor/issues/5312)

## Summary

The reported behavior is intentional: Monaco disables forced-color adjustment to match VS Code and relies on its built-in high-contrast themes. Because this is a team-authored request, the protected-item rule bars an as-designed judgment close; it should remain open as a feature request for explicit system-color theme support.

## Change summary

Allow Monaco Editor to adopt Windows system and forced-color themes instead of retaining its selected built-in theme.

## Best solution

Keep the existing VS Code-parity behavior unless the team decides to add and maintain a distinct system-color theme in the vscode editor core. Such a theme would need deliberate mapping, testing, and ongoing maintenance rather than relying implicitly on browser forced-color substitutions.
