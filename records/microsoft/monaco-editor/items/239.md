## Summary

Verified cross-repository duplicate: Monaco already exposes the model text and view state, while the remaining request—serializing the undo/redo stack—is tracked by the open VS Code editor-core issue https://github.com/microsoft/vscode/issues/7536.

## Change summary

Provide a public API for serializing and restoring an editor session, including its undo/redo history.
