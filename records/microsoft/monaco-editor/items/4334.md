# Issue #4334 — Issue in StandaloneThemeService

[https://github.com/microsoft/monaco-editor/issues/4334](https://github.com/microsoft/monaco-editor/issues/4334)

## Summary

The theme API intentionally requires a `colors` map; only the `editor.foreground` and `editor.background` entries are optional. An empty `colors: {}` satisfies the contract and avoids the reported exception.

## Change summary

Allow custom theme definitions to omit the entire `colors` map.

## Best solution

Keep the required `IStandaloneThemeData.colors` contract and define themes without color overrides using `colors: {}`.
