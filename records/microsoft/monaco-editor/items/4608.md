# Issue #4608 — Diff editor - highlight same lines

[https://github.com/microsoft/monaco-editor/issues/4608](https://github.com/microsoft/monaco-editor/issues/4608)

## Summary

A real diff-editor capability gap remains: there is no built-in option to highlight unchanged lines instead of changed lines. The request is terse, but it is distinct from existing open diff-highlighting requests and should be routed to the diff-editor area.

## Change summary

Add an inverse diff-highlighting mode that emphasizes lines shared by the original and modified models.

## Best solution

Define the desired rendering and add an option in the VS Code diff-editor core, from which Monaco inherits editor behavior. Embedders can currently approximate it by computing unchanged ranges after `onDidUpdateDiff` and decorating both child editors, but that is not equivalent to a supported rendering mode.
