The playground and screenshot demonstrate the word-wrap regression, and an open VS Code PR directly references this issue with a source-level root cause and fix. Keep the issue open until that PR is resolved.

## Change summary

Switching a diff editor from inline to side-by-side mode leaves word wrapping disabled in the original editor.

## Best solution

Review and land https://github.com/microsoft/vscode/pull/320761 in the VS Code editor core, then include that change in a subsequent Monaco release.
