# Issue #5153 — Remove AMD build

[https://github.com/microsoft/monaco-editor/issues/5153](https://github.com/microsoft/monaco-editor/issues/5153)

## Summary

The AMD build remains in the current build and package pipeline, while the playground still loads it directly. Keep this team-authored cleanup open and route it to the ESM area.

## Change summary

Remove the deprecated AMD distribution from the npm package and migrate the Monaco playground to ESM.

## Best solution

Remove the AMD build step and `min`/CommonJS package entry points, migrate the playground loader to supported ESM entry points, and update the README and changelog as one coordinated breaking change.
