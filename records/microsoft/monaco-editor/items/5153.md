# Issue #5153 — Remove AMD build

[https://github.com/microsoft/monaco-editor/issues/5153](https://github.com/microsoft/monaco-editor/issues/5153)

## Summary

The removal remains necessary: current main still builds and packages AMD, and the playground defaults still depend on it. This team-authored cleanup has neither a verified replacement canonical nor an issue-linked completed fix.

## Change summary

Remove the deprecated AMD build from the npm package and migrate the playground away from it.

## Best solution

Complete the playground's ESM migration and retire AMD packaging together, preserving supported ESM loading and declaration output. Account for the package's legacy main/require entry points and document the breaking change.
