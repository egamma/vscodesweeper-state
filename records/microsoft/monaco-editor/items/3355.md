# Issue #3355 — [Bug] Loading bulk models is causing major delay in intellisense

[https://github.com/microsoft/monaco-editor/issues/3355](https://github.com/microsoft/monaco-editor/issues/3355)

## Summary

The requested performance improvement remains necessary: current main still performs a linear scan of every mirror model for each TypeScript model lookup. The existing feature-request and typescript labels already route it appropriately.

## Change summary

Improve repeated TypeScript IntelliSense performance when an embedder loads thousands of models.

## Best solution

Provide an efficient URI-keyed mirror-model lookup through the worker context and use it in src/languages/features/typescript/tsWorker.ts, avoiding repeated full-model scans during TypeScript language-service requests.
