# Issue #1240 — F# highlighting issues with block comments tokenized by strings

[https://github.com/microsoft/monaco-editor/issues/1240](https://github.com/microsoft/monaco-editor/issues/1240)

## Summary

The supplied examples still expose incorrect comment boundaries in the current F# grammar. Keep this correctly routed issue open; the defect is in Monaco's own language definition, not the generated editor core.

## Change summary

F# block comments incorrectly terminate at comment delimiters inside strings and ignore triple-quoted string boundaries.

## Best solution

Make the Monaco F# grammar respect F# string boundaries within block comments while preserving comment styling. This is bounded community-PR work with an existing tokenization test harness.
