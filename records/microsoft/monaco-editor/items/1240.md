# Issue #1240 — F# highlighting issues with block comments tokenized by strings

[https://github.com/microsoft/monaco-editor/issues/1240](https://github.com/microsoft/monaco-editor/issues/1240)

## Summary

The F# block-comment tokenizer still treats the first `*)` inside a quoted string as the end of the comment. The issue remains valid and is already correctly routed to `grammars` as an open community contribution.

## Change summary

F# syntax highlighting prematurely ends block comments when a quoted string inside the comment contains `*)`.

## Best solution

Update the F# Monarch comment state in `src/languages/definitions/fsharp/fsharp.ts` to recognize F# string forms within comments and ignore comment delimiters until those strings close. Add both reported examples to `fsharp.test.ts`; this remains suitable for an `open for PR` contribution.
