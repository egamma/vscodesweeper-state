# Issue #5462 — [Bug] 0.56.0 browser CSP violation

[https://github.com/microsoft/monaco-editor/issues/5462](https://github.com/microsoft/monaco-editor/issues/5462)

## Summary

Keep open: the sample, extension-origin CSP error, and worker bootstrap text provide enough information to retest this regression. Main has advanced to the 0.58.0 release merge, but current upstream worker creation still uses blob bootstrapping; resolution in the reported environment remains unverified.

## Change summary

Monaco 0.56.0 attempts to load an editor worker through a blob URL that Firefox extension CSP blocks, unlike 0.55.1.

## Best solution

Support externally packaged editor workers without requiring embedders to permit blob workers. Retest the esbuild sample under the reported extension CSP and investigate the VS Code-derived editor worker loader separately from the sample's import-path build failure.
