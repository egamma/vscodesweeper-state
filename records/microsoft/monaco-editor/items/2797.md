# Issue #2797 — Support inspecting semantic tokens with [F1->Developer: Inspect Token]

[https://github.com/microsoft/monaco-editor/issues/2797](https://github.com/microsoft/monaco-editor/issues/2797)

## Summary

Semantic-token inspection remains a distinct missing capability in the standalone token inspector. Route to semantic-tokens; the implementation belongs in the VS Code source Monaco imports.

## Change summary

Extend Developer: Inspect Tokens to display semantic-token information.

## Best solution

Extend the standalone inspector in microsoft/vscode to expose semantic token types and modifiers at the cursor, then bring that capability into Monaco through a core release. Existing semantic-token provider APIs do not satisfy the inspection request.
