# Issue #4850 — [Bug] TypeScript string autocomplete works in VS Code but not Monaco

[https://github.com/microsoft/monaco-editor/issues/4850](https://github.com/microsoft/monaco-editor/issues/4850)

## Summary

The VS Code parity gap remains on current main: Monaco's TypeScript completion provider triggers automatically only for `.`, not quotes. Route this confirmed bug to the TypeScript area.

## Change summary

Automatically offer TypeScript string-literal completions after an opening quote, matching VS Code.

## Best solution

Update `SuggestAdapter.triggerCharacters` in `src/languages/features/typescript/languageFeatures.ts` to include the applicable VS Code TypeScript completion triggers, particularly single, double, and template-string quotes. This appears suitable for a focused community PR with coverage for string-union parameters.
