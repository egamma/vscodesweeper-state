# Issue #4850 — [Bug] TypeScript string autocomplete works in VS Code but not Monaco

[https://github.com/microsoft/monaco-editor/issues/4850](https://github.com/microsoft/monaco-editor/issues/4850)

## Summary

The automatic-completion gap remains in current source: Monaco's TypeScript provider registers only the period as a trigger, whereas VS Code also registers quotes. Route this to typescript; the supplied minimal example is sufficient and the defect is localized to Monaco's language adapter.

## Change summary

Typing an opening quote in a string-literal parameter should automatically suggest the allowed strings in JavaScript and TypeScript.

## Best solution

Restore automatic string-parameter completions through Monaco's bundled TypeScript/JavaScript completion adapter, preserving existing editor-wide suggestion settings. Cover the reported literal union and DOM event-name cases in the browser smoke suite.
