# Issue #949 — ES Modules (vs Webpack)

[https://github.com/microsoft/monaco-editor/issues/949](https://github.com/microsoft/monaco-editor/issues/949)

## Summary

Consolidate this request into the open browser-ready ESM distribution proposal. Native browser loading remains unsupported by the current packaging; this is a duplicate, not a completed implementation.

## Change summary

Allow Monaco and its language workers to load directly through native browser ES modules without a bundler or AMD loader.

## Best solution

Track a browser-consumable ESM distribution in https://github.com/microsoft/monaco-editor/issues/5067, preserving this report's requirements for direct HTTP-served imports, stylesheet loading, and native language workers.

- **Fit:** aligned
- **Reason:** Standards-compatible browser packaging advances Monaco's ESM integration direction without adding an application platform.
- **Evidence:** The durable packaging and bundler integration theme and the ESM-first modularization priority support modern, interoperable distribution entry points.
