# Issue #4576 — [Bug] `JSONDocument.getNodeFromOffset` is not a function at runtime

[https://github.com/microsoft/monaco-editor/issues/4576](https://github.com/microsoft/monaco-editor/issues/4576)

## Summary

The public JSON worker API still promises a callable getNodeFromOffset, but returns a language-service class instance across a worker boundary without restoring its prototype. Route this to the JSON area; the defect belongs to Monaco's worker API, not Vite.

## Change summary

Calling getNodeFromOffset on the JSON document returned by a real web worker fails despite the public TypeScript declaration.

## Best solution

Make the public JSON worker's returned document honor its declared offset-lookup contract when using a real Worker. Preserve AST data and existing JSON language features, and cover the reporter's flow in the Vite browser smoke harness.
