# Issue #4576 — [Bug] `JSONDocument.getNodeFromOffset` is not a function at runtime

[https://github.com/microsoft/monaco-editor/issues/4576](https://github.com/microsoft/monaco-editor/issues/4576)

## Summary

Still present on main: the JSON worker API promises `getNodeFromOffset`, but returns a class instance across a dedicated-worker boundary where its prototype method is not preserved. Route this confirmed API/runtime mismatch to the JSON area.

## Change summary

Calling the declared `JSONDocument.getNodeFromOffset` API fails in normal worker-based integrations because the returned runtime object lacks that method.

## Best solution

Expose offset lookup as a worker method such as `getNodeFromOffset(uri, offset, includeRightBound)` or return an explicitly serializable document API, rather than declaring a prototype method on an object transferred from the JSON worker.
