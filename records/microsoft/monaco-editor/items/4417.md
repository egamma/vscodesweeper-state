# Issue #4417 — [Bug] 0.47.0 TypeError: Cannot read properties of undefined (reading 'CI')

[https://github.com/microsoft/monaco-editor/issues/4417](https://github.com/microsoft/monaco-editor/issues/4417)

## Summary

Fixed in the VS Code editor core and shipped with Monaco v0.48.0: platform detection now rejects browser-side process polyfills instead of entering the native path and reading undefined platform data.

## Change summary

Monaco 0.47.0 crashes during ESM initialization in a Vue 3/Vite application because platform detection mistakes the browser environment for Node.js.

## Best solution

Keep the stricter Node.js detection from the VS Code fix and close this as shipped in Monaco v0.48.0.
