# Issue #4452 — [Bug] Tab only accept the empty space 

[https://github.com/microsoft/monaco-editor/issues/4452](https://github.com/microsoft/monaco-editor/issues/4452)

## Summary

The reported behavior follows the editor core's intentional Tab guard: Tab accepts an inline suggestion only when its leading indentation is less than the model's detected tab size. Changing that tradeoff is an editor-core feature decision rather than a Monaco-specific defect.

## Change summary

Allow Tab to accept an entire inline completion even when its leading whitespace reaches the model's tab size.

## Best solution

The inline-completions owner should decide in microsoft/vscode whether Tab can safely override indentation in this case or whether an explicit option is warranted; any editor-core change will flow into Monaco with a later release.
