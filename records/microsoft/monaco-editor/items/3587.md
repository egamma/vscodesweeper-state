# Issue #3587 — [Bug] Problem using Monaco 'wordWrapColumn', editor scrolls outside of view

[https://github.com/microsoft/monaco-editor/issues/3587](https://github.com/microsoft/monaco-editor/issues/3587)

## Summary

The defect remains structurally present in the current VS Code editor core: focusing the wrapped textarea can change an ancestor's horizontal scroll position, while the existing preservation helper restores only vertical scrolling. Route this confirmed editor-core bug to input and wrapping.

## Change summary

Using wordWrapColumn with a long line can horizontally scroll the editor's overflow container and move the editor outside its visible area when the hidden textarea receives focus.

## Best solution

Fix the textarea input path in microsoft/vscode to prevent focus-induced horizontal scrolling or preserve and restore both scroll axes, with a regression test covering wordWrapColumn in a scrollable embedder. The correction will flow into Monaco through a subsequent release.
