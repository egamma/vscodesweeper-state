# Issue #1233 — Some keybindings don't work with non US-Layouts

[https://github.com/microsoft/monaco-editor/issues/1233](https://github.com/microsoft/monaco-editor/issues/1233)

## Summary

Layout-aware default shortcuts remain a real capability gap; custom keybindings provide a workaround, not automatic translation. Route to keyboard-layout and keybindings while preserving this accepted Backlog request.

## Change summary

Translate default shortcuts into usable combinations on non-US keyboard layouts, including German Ctrl/Cmd+Shift+7 for line comments.

## Best solution

Design layout-aware shortcut resolution in the VS Code standalone editor services that Monaco consumes, with consistent shortcut labels and activation. Coordinate with the related layout-selection request without replacing this older report with it.
