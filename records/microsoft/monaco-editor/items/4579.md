# Issue #4579 — [Bug] fixedOverflowWidgets=true makes suggestion widget shows at a wrong location when monaco-editor is hosted inside fluent Callout control #2503

[https://github.com/microsoft/monaco-editor/issues/4579](https://github.com/microsoft/monaco-editor/issues/4579)

## Summary

Verified duplicate of the older open issue tracking incorrectly offset overflow widgets inside transformed containers. This report contributes a minimal playground reproduction using a translated parent.

## Change summary

Using fixedOverflowWidgets inside a transformed parent places the suggestion widget at the wrong vertical position.

## Best solution

Consolidate the transformed-container positioning defect on https://github.com/microsoft/monaco-editor/issues/2793 and fix the overflow-widget coordinate handling in the VS Code editor core. Embedders can meanwhile place overflow widgets in an untransformed root through overflowWidgetsDomNode.
