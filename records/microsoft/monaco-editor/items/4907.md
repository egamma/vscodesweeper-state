# Issue #4907 — [Bug] editor.foldLevel1 does not fold first region if it's the first line

[https://github.com/microsoft/monaco-editor/issues/4907](https://github.com/microsoft/monaco-editor/issues/4907)

## Summary

The first region remains expanded because Fold Level 1 intentionally excludes regions containing the cursor, including their starting line. This is documented behavior, not a first-line folding defect.

## Change summary

Programmatic Fold Level 1 leaves the first function expanded when folding immediately after editor creation.

## Best solution

Preserve the documented cursor exclusion and explain how to move the cursor outside the target regions before invoking editor.foldLevel1. Use editor.foldAll instead when collapsing every nesting level is acceptable.

- **Proposed comment:**

  > Thanks for the report and examples. `editor.foldLevel1` intentionally leaves regions containing the cursor expanded, including when the cursor is on the region's first line. This matches the documented behavior: https://code.visualstudio.com/docs/editing/codebasics#_folding.
  > 
  > Immediately after creation, the cursor is on line 1, inside your first function. Adding a leading newline places it outside that function. Move the cursor outside the regions you want to collapse before running `editor.foldLevel1`; alternatively, use `editor.foldAll` if folding all nesting levels is acceptable. The Command Palette action follows the same cursor-exclusion rule. Closing as expected behavior.
