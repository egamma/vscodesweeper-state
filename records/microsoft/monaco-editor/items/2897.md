# Issue #2897 — Rust syntax highlighting broken for raw strings

[https://github.com/microsoft/monaco-editor/issues/2897](https://github.com/microsoft/monaco-editor/issues/2897)

## Summary

The original hashed `r#"..."#` case is covered by the current grammar and tests. The remaining `br`/`cr` defect is conclusively present in source and is tracked with a playground reproduction by open issue https://github.com/microsoft/monaco-editor/issues/4856.

## Change summary

Rust raw strings using hashes or byte/C-string prefixes receive incorrect syntax highlighting.

## Best solution

Consolidate the remaining work on https://github.com/microsoft/monaco-editor/issues/4856 and extend the Rust tokenizer and tests there to recognize `br` and `cr` raw-string prefixes while preserving matching hash delimiters.
