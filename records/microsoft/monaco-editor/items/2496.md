# Issue #2496 — Type Checking in JS File allows invalid JavaScript

[https://github.com/microsoft/monaco-editor/issues/2496](https://github.com/microsoft/monaco-editor/issues/2496)

## Summary

The configuration workaround works, but the requested default experience remains unresolved: current JavaScript defaults enable allowJs but not checkJs, while the playground sample replaces those defaults without either option. The existing feature-request and typescript labels correctly route this Backlog item.

## Change summary

Make JavaScript semantic validation reject TypeScript-only syntax without requiring embedders to discover additional allowJs and checkJs settings.

## Best solution

Decide whether JavaScript defaults should enable checkJs, and update the configuring-JavaScript-defaults playground sample to preserve allowJs and demonstrate the supported semantic-checking configuration.
