# Issue #5001 — [Bug] monaco.editor.addEditorAction() doesn't add actions to the command palette

[https://github.com/microsoft/monaco-editor/issues/5001](https://github.com/microsoft/monaco-editor/issues/5001)

## Summary

A real API consistency gap remains: global actions register commands, keybindings, and optional context-menu entries, but unlike per-editor actions they never enter the action collection consumed by the command palette. Since this behavior never existed and its contract is under discussion, this is best tracked as an editor API feature request.

## Change summary

Make actions registered through monaco.editor.addEditorAction() discoverable in each editor's command palette.

## Best solution

Define addEditorAction() as the global analogue of StandaloneCodeEditor.addAction() and implement the lifecycle in the vscode editor core so registered descriptors contribute to getSupportedActions() for existing and future standalone editors, including correct disposal.
