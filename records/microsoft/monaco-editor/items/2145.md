# Issue #2145 — Links inside escaped strings consider ending `\` as part of the link 

[https://github.com/microsoft/monaco-editor/issues/2145](https://github.com/microsoft/monaco-editor/issues/2145)

## Summary

The escaped-delimiter case remains unsupported in the current vscode link detector, and no broader open canonical was found. Keep this canonical report open and route it to editor contributions.

## Change summary

Teach textual link detection to exclude the backslash preceding an escaped closing quote without breaking valid quoted URLs.

## Best solution

Implement and test escaped two-character delimiters in the vscode editor core at src/vs/editor/common/languages/linkComputer.ts, then let the change flow into Monaco with a release cut.
