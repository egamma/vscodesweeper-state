# Issue #4789 — [Feature Request] A way to propagate ctrl + wheel events

[https://github.com/microsoft/monaco-editor/issues/4789](https://github.com/microsoft/monaco-editor/issues/4789)

## Summary

Keep open: existing wheel options do not selectively preserve browser Ctrl+wheel zoom while retaining normal editor scrolling. This team-authored request has no verified fix or qualifying duplicate.

## Change summary

Allow Ctrl+wheel events to retain native browser zoom behavior instead of scrolling or zooming only the editor.

## Best solution

Provide supported modifier-specific wheel handling in the VS Code-derived editor core, preserving ordinary editor scrolling while allowing native browser zoom. Validate that behavior in the Monaco playground before adopting it in a release.
