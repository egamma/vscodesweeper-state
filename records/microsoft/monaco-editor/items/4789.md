# Issue #4789 — [Feature Request] A way to propagate ctrl + wheel events

[https://github.com/microsoft/monaco-editor/issues/4789](https://github.com/microsoft/monaco-editor/issues/4789)

## Summary

A real API gap remains: Monaco can disable all wheel handling or zoom the editor, but cannot selectively leave Ctrl+wheel to the browser while retaining ordinary editor scrolling. This team-authored request has no verified duplicate or implementation, so it should remain open.

## Change summary

Allow embedders to propagate Ctrl+wheel so the browser can zoom the whole page without disabling ordinary editor scrolling.

## Best solution

Add a modifier-aware wheel-handling option or cancellation hook in the vscode editor core, then expose it through Monaco's editor options. The API should preserve normal wheel scrolling while allowing Ctrl+wheel to retain the browser's default behavior.
