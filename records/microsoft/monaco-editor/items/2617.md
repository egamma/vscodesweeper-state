# Issue #2617 — TypeScript: imports are not foldable

[https://github.com/microsoft/monaco-editor/issues/2617](https://github.com/microsoft/monaco-editor/issues/2617)

## Summary

The capability remains missing on current main: Monaco's TypeScript mode does not register a folding-range provider, so `foldingImportsByDefault` receives no import ranges to collapse. Route this established feature request to TypeScript folding.

## Change summary

Add TypeScript and JavaScript folding ranges, including import ranges that `foldingImportsByDefault` can initially collapse.

## Best solution

Expose TypeScript's `getOutliningSpans` through the worker, convert its `imports`, `comment`, and `region` kinds in a folding adapter, and register that provider from `src/languages/features/typescript/tsMode.ts`. This is reasonable open-for-PR work in Monaco's bundled TypeScript support.
