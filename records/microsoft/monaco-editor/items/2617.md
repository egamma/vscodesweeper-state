# Issue #2617 — TypeScript: imports are not foldable

[https://github.com/microsoft/monaco-editor/issues/2617](https://github.com/microsoft/monaco-editor/issues/2617)

## Summary

Built-in TypeScript import folding remains missing: the current language integration registers no folding provider. The older semantic-folding request is related, but reports a different observable symptom and does not satisfy the re-review duplicate bar.

## Change summary

Provide TypeScript import folding ranges so foldingImportsByDefault can collapse consecutive imports automatically.

## Best solution

Add import-aware folding support to Monaco's bundled TypeScript language integration, producing Imports-kind ranges that the existing editor option can consume. Coordinate with the broader semantic-folding work at https://github.com/microsoft/monaco-editor/issues/1847 without treating its unindented-function symptom as an exact duplicate.
