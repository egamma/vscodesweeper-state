# Issue #4555 — editor Suggest whether the Widget can be inserted into the body or under the specified element

[https://github.com/microsoft/monaco-editor/issues/4555](https://github.com/microsoft/monaco-editor/issues/4555)

## Summary

The requested placement is already supported by the editor constructor's `overflowWidgetsDomNode` option, which accepts an external element such as `document.body` and receives overflowing content widgets including the suggest widget.

## Change summary

Allow the suggest widget to render under `document.body` or another specified element so ancestor `overflow: hidden` does not crop it.

## Best solution

Configure `overflowWidgetsDomNode` when creating the editor, using `document.body` or another suitable container; enable `fixedOverflowWidgets` as well when viewport-relative positioning is required.
