# Issue #3600 — Standalone editor theme available options

[https://github.com/microsoft/monaco-editor/issues/3600](https://github.com/microsoft/monaco-editor/issues/3600)

## Summary

A real documentation gap remains: Monaco's playground lists theme colors manually, but it does not reliably distinguish colors actually consumed by the standalone editor. The existing help-wanted classification makes this suitable to remain open for a community contribution.

## Change summary

Provide an authoritative, current list of theme colors supported by the standalone editor.

## Best solution

Generate or otherwise maintain a standalone-specific color reference in the playground or API documentation, identifying which components consume each color. This is appropriate open-for-PR material, likely involving the Monaco website sample and the vscode editor-core color registry.
