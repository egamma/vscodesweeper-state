# Issue #4908 — [Bug] Accessibility Help missing

[https://github.com/microsoft/monaco-editor/issues/4908](https://github.com/microsoft/monaco-editor/issues/4908)

## Summary

The standalone accessibility-help command remains missing while its public configuration option is still exposed. This is an editor-core regression that should remain open and route to accessibility.

## Change summary

Restore discoverable accessibility help in standalone Monaco and make accessibilityHelpUrl functional again.

## Best solution

Restore a standalone accessibility-help action/provider in the vscode editor core that does not depend on workbench services, then ship it through the next Monaco release. The implementation should expose the command in quick access, support Alt+F1, and consume accessibilityHelpUrl.
