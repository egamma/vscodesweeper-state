# Issue #4902 — [Bug] Autoprefixer warns about end value in CSS when building with Next.js.

[https://github.com/microsoft/monaco-editor/issues/4902](https://github.com/microsoft/monaco-editor/issues/4902)

## Summary

Already fixed upstream and shipped in monaco v0.53.0: the hover stylesheet now uses `flex-end`, eliminating the Autoprefixer warning.

## Change summary

Building Monaco with Next.js emits an Autoprefixer warning for `justify-content: end` in the hover stylesheet.

## Best solution

Use monaco-editor v0.53.0 or newer, which includes the corrected hover CSS from the vscode editor core.
