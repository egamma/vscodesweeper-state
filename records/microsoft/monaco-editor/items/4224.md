# Issue #4224 — [Bug] language:markdown italic error

[https://github.com/microsoft/monaco-editor/issues/4224](https://github.com/microsoft/monaco-editor/issues/4224)

## Summary

The Markdown tokenizer on current main can still interpret the two subscript underscores as one emphasis span. The issue is already routed to the grammars area and remains a valid help-wanted bug.

## Change summary

Markdown highlighting incorrectly italicizes text between underscores used in separate math-like subscripts.

## Best solution

Tighten the underscore-emphasis rule in src/languages/definitions/markdown/markdown.ts so intraword subscript underscores cannot delimit emphasis, and add this input to markdown.test.ts as a regression case. This is suitable for the existing help-wanted lane.
