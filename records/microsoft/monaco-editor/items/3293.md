# Issue #3293 — [Bug] Passing only `autoIndent` to `updateOptions` is not applied

[https://github.com/microsoft/monaco-editor/issues/3293](https://github.com/microsoft/monaco-editor/issues/3293)

## Summary

The bug remains traceable in the current VS Code editor core: `CursorConfiguration` caches `autoIndent`, but changing that option does not trigger configuration recreation. The existing `bug` and `editor-core` labels route it correctly, so it should remain open.

## Change summary

Calling `updateOptions` with a changed `autoIndent` value updates the reported option but not the editor's indentation behavior.

## Best solution

Update `CursorConfiguration.shouldRecreate` in the VS Code editor core to react to `EditorOption.autoIndent`, add coverage for runtime option updates, and let the fix flow into Monaco through the next source update.
