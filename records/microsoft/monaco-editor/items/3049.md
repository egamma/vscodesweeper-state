# Issue #3049 — [Bug] DiffEditor shows overloads because of duplicated definitions

[https://github.com/microsoft/monaco-editor/issues/3049](https://github.com/microsoft/monaco-editor/issues/3049)

## Summary

The defect remains traceable on current main: both diff models enter one TypeScript language-service project, so identical global declarations are interpreted as overloads. The existing typescript-multifile label routes it appropriately.

## Change summary

Diff-editor models representing two versions of one JavaScript file incorrectly contribute duplicate definitions to each other's language-service results.

## Best solution

Isolate the original and modified model sets in separate TypeScript worker projects while preserving language features on both sides, so each diff pane resolves declarations against its own file version.
