## Summary

The reported difficulty is choosing the token name for YAML keys, not an established editor defect. The bundled tokenizer emits type.yaml, which none of the listed theme rules targets.

## Change summary

Customize YAML key colors through defineTheme without changing string or number colors.

## Best solution

Use a theme rule targeting type.yaml and apply the custom theme. No tokenizer change is needed for the described customization.
