# Issue #4519 — [Bug] format test color for YAML is incredibly difficult

[https://github.com/microsoft/monaco-editor/issues/4519](https://github.com/microsoft/monaco-editor/issues/4519)

## Summary

This is a theming usage question rather than a Monaco defect: YAML mapping keys are emitted as `type.yaml` and can already be styled through `defineTheme`.

## Change summary

Provide a way to assign a custom theme color to YAML mapping keys.

## Best solution

Use a theme rule targeting `type.yaml` (or the prefix `type`) for YAML keys, and use Developer: Inspect Tokens to identify token names for other YAML elements.
