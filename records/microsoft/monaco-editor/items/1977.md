# Issue #1977 — Spell checking using browser spell checker

[https://github.com/microsoft/monaco-editor/issues/1977](https://github.com/microsoft/monaco-editor/issues/1977)

## Summary

This remains the canonical feature request for native browser spell-checking in plain-text and Markdown editors. Monaco has no corresponding option, the current rendering/input architecture prevents straightforward browser integration, and the existing editor-core label already routes it appropriately.

## Change summary

Allow Monaco editors to use browser-native spell checking and third-party spelling tools such as Grammarly.

## Best solution

Design support in the VS Code editor core so Monaco can expose text to browser spell-checking without breaking virtualized rendering, cursor behavior, or replacements. The request should remain open here as the canonical demand signal until that editor-core design is accepted or declined.

## Vision fit

- **Fit:** rejected
- **Reason:** A Monaco-only editor behavior conflicts with the generated-from-VS-Code model; the capability would need to originate in the shared VS Code editor core.
- **Evidence:** The README states that Monaco is "generated straight from VS Code's sources," and the vision consequently directs new editor behavior through the shared editor core.
