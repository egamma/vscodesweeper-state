# Issue #1977 — Spell checking using browser spell checker

[https://github.com/microsoft/monaco-editor/issues/1977](https://github.com/microsoft/monaco-editor/issues/1977)

## Summary

Keep open as the older, more-supported request for browser-native spell checking. Existing marker APIs enable custom dictionary-based checking, but do not satisfy native browser spell checking or Grammarly compatibility.

## Change summary

Allow browser-native spelling checks and corrections when editing Markdown or plain text in Monaco.

## Best solution

Retain this issue as the canonical Monaco request and seek an editor-core feasibility decision in microsoft/vscode covering native spelling annotations and safe correction handling. Treat the custom spell-checker library as a workaround, not completion of the browser-integration request.
