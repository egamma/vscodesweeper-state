# Issue #3359 — Make `onDropIntoEditor` api public

[https://github.com/microsoft/monaco-editor/issues/3359](https://github.com/microsoft/monaco-editor/issues/3359)

## Summary

The requested public drop event remains missing from the API at main's pinned VS Code revision. Keep this accepted Backlog request open: the team expressed willingness to consider exposing it, and the related dropped-text bug does not cover this capability.

## Change summary

Expose a supported drop API so embedders can obtain the drop position and customize file or text insertion.

## Best solution

Define a supported drop event and its default-handling contract in the VS Code editor core, then expose it through Monaco's generated API. The team's invitation to consider a community PR remains relevant; exposing the existing event should also address the reporter's need to override insertion.
