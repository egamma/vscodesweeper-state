# Issue #743 — Expose diff editor options to access and update them

[https://github.com/microsoft/monaco-editor/issues/743](https://github.com/microsoft/monaco-editor/issues/743)

## Summary

Keep open: updating diff options is supported, but reading diff-specific configuration and subscribing to its changes remain missing from the public API. The issue already has the appropriate area labels and an accepted Backlog placement.

## Change summary

Expose diff-editor configuration for reading and updating, together with an onDidChangeConfiguration event.

## Best solution

Extend the public diff-editor configuration API in the VS Code editor core to support reading diff-specific options and observing their changes, preserving the existing updateOptions API. Carry that API into Monaco through the generated core release.
