# Issue #743 — Expose diff editor options to access and update them

[https://github.com/microsoft/monaco-editor/issues/743](https://github.com/microsoft/monaco-editor/issues/743)

## Summary

A meaningful API gap remains: diff editor options can now be updated, but callers still cannot read the complete effective options or subscribe to diff-option changes. The existing editor-api and diff-editor labels route it correctly.

## Change summary

Expose APIs for reading diff editor options, updating them, and observing configuration changes.

## Best solution

Add public option access and a configuration-change event to IDiffEditor in the VS Code editor core, alongside the existing updateOptions method; the change will then flow into Monaco. Given the existing help wanted label and contained API scope, this remains suitable for a community contribution.

## Evidence
