# Issue #4404 — [Bug] Regex without anchor `^` in the tokenizer rule matches only the beginning of the string

[https://github.com/microsoft/monaco-editor/issues/4404](https://github.com/microsoft/monaco-editor/issues/4404)

## Summary

This is intended Monarch behavior: unanchored expressions may match later in the current input, while a leading `^` restricts matching to the start of the source line.

## Change summary

Restrict a custom Monarch token rule to markdown-like links appearing at the beginning of a line.

## Best solution

Use `/^\{(.*?)\}\(.*?\)/` for the custom rule. No tokenizer change is needed because Monarch already provides the requested line-start constraint.
