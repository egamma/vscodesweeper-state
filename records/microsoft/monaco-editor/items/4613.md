# Issue #4613 — [Bug] Error: The parameters in nameBuiltin  from elixir.js are globally replaced, causing compilation errors.

[https://github.com/microsoft/monaco-editor/issues/4613](https://github.com/microsoft/monaco-editor/issues/4613)

## Summary

The compilation failure is caused by the embedding application's Vite configuration globally replacing the valid Elixir token `__ENV__` inside Monaco's dependency code. Monaco's source is correct, so this should be resolved by using a non-colliding Vite constant name.

## Change summary

Prevent a Vite `define` entry named `__ENV__` from corrupting Monaco's generated Elixir language definition.

## Best solution

Rename the application's Vite constant to a sufficiently specific identifier such as `__APP_ENV__`, or use Vite's mode/environment facilities. The Monaco Elixir definition should continue representing `__ENV__` as a string and should not be patched in `node_modules`.
