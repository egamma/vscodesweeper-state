# Issue #1127 — Monarch embedded @pop rule requires two carets

[https://github.com/microsoft/monaco-editor/issues/1127](https://github.com/microsoft/monaco-editor/issues/1127)

## Summary

Already fixed in the VS Code editor core: embedded-language exit rules now honor `matchOnlyAtLineStart`, eliminating the two-caret workaround.

## Change summary

A line-start-anchored Monarch `@pop` rule incorrectly matched within a line unless written with two carets.

## Best solution

Keep the editor-core fix from https://github.com/microsoft/vscode/commit/7207e8aeff5e042848d86b24fc0b641b80a9c31d; a single leading caret now provides the documented behavior.
