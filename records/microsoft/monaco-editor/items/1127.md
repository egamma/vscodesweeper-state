# Issue #1127 — Monarch embedded @pop rule requires two carets

[https://github.com/microsoft/monaco-editor/issues/1127](https://github.com/microsoft/monaco-editor/issues/1127)

## Summary

The embedded-language exit scan now respects single-caret line anchors, fixing the reported defect. The concrete upstream fix is present in the editor core pinned by current Monaco main.

## Change summary

Monarch embedded-language exit rules incorrectly match mid-line unless their leading caret is doubled.

## Best solution

Close as implemented and retain the upstream anchor check; the supplied grammar can use /^\s*@/ instead of /^^\s*@/.
