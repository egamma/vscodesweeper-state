# Issue #4396 — [Feature Request] Option to keep glyphs position without changes

[https://github.com/microsoft/monaco-editor/issues/4396](https://github.com/microsoft/monaco-editor/issues/4396)

## Summary

The public decoration API does not expose fixed-line anchoring independent of text edits. Keep this request open and route it to editor-api; no qualifying canonical was found.

## Change summary

Provide an option that keeps a glyph on its assigned line number when edits move the original text to another line.

## Best solution

Evaluate an explicit fixed-line anchoring contract in the VS Code editor core while preserving existing text-tracking defaults. Embedders can currently reset decoration ranges after content changes, but that requires application logic rather than the requested option.
