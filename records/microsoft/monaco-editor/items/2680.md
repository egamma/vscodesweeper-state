# Issue #2680 — suggestWidget doesn't clean suggestion in case for triggerCharacters if this._completionModel.items.length === 0

[https://github.com/microsoft/monaco-editor/issues/2680](https://github.com/microsoft/monaco-editor/issues/2680)

## Summary

Fixed upstream: suggestion refiltering now runs synchronously before a trigger-character request, preventing Enter from accepting the stale pre-trigger selection. The fix shipped in monaco v0.35.0.

## Change summary

Prevent a stale completion from replacing a newly typed trigger character while the replacement completion request is pending.

## Best solution

Keep the synchronous refiltering introduced by https://github.com/microsoft/vscode/commit/b64e2d11cc24293e60b2240bfa57e1199154bf2c; its regression coverage verifies both immediate trigger-character filtering and acceptance of the visible suggestion.
