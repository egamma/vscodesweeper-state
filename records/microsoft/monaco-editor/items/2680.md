# Issue #2680 — suggestWidget doesn't clean suggestion in case for triggerCharacters if this._completionModel.items.length === 0

[https://github.com/microsoft/monaco-editor/issues/2680](https://github.com/microsoft/monaco-editor/issues/2680)

## Summary

Keep open: the editor core has evolved since Monaco 0.22.3, but current source still preserves the suggestion widget during trigger-character retriggers. The reported sequence is sufficient to retest; neither resolution nor a matching canonical issue was verified.

## Change summary

Accepting a stale suggestion while a trigger-character completion request is pending can overwrite the newly typed parenthesis.

## Best solution

Retest with a deliberately delayed completion provider and ensure invalid suggestions cannot be accepted while replacement results are pending. Any editor-core correction belongs in microsoft/vscode and should flow into Monaco through a subsequent release.
