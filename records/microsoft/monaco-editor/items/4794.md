# Issue #4794 — [Bug]  applyEdits nonsupport undoed

[https://github.com/microsoft/monaco-editor/issues/4794](https://github.com/microsoft/monaco-editor/issues/4794)

## Summary

The sample uses an API explicitly documented to bypass the undo stack. This is an API-usage question: executeEdits supports the requested undoable replacement.

## Change summary

Make the programmatic replacement triggered by Ctrl+S undoable.

## Best solution

Use myEditor.executeEdits for the replacement, with pushUndoStop before and after when it should be a separate undo step. Preserve applyEdits as the documented non-undo-stack API.
