# Issue #4750 — [Bug] The color contrast for the red and green lines that indicate code changes in the Monaco diff editor is low

[https://github.com/microsoft/monaco-editor/issues/4750](https://github.com/microsoft/monaco-editor/issues/4750)

## Summary

The accessibility gap remains in the current editor core: overlapping translucent diff backgrounds produce low-contrast red and green highlights on the default light background. The existing theme API provides an embedder workaround but does not correct the inaccessible defaults.

## Change summary

Increase the default light-theme contrast of inserted and removed diff highlights while preserving customization and underlying text visibility.

## Best solution

Adjust the transparent diff color defaults in the vscode editor core's `src/vs/platform/theme/common/colors/editorColors.ts` to provide accessible visual differentiation, then bring that change into Monaco through the normal source update. Embedders can meanwhile override the `diffEditor.*Background` colors with `monaco.editor.defineTheme`.
