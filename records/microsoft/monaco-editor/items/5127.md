# Issue #5127 — [Bug] pt-BR translation is just a file full of nulls

[https://github.com/microsoft/monaco-editor/issues/5127](https://github.com/microsoft/monaco-editor/issues/5127)

## Summary

Confirmed in the current v0.56.0 artifacts: the Brazilian Portuguese locale contains 2,120 null entries and no translations. The issue is already correctly routed to i18n and remains necessary.

## Change summary

The distributed Brazilian Portuguese localization file contains null entries instead of translated editor messages.

Fix the pt-BR localization generation feeding monaco-editor-core, add validation that rejects an all-null locale, and publish the corrected artifact in the next Monaco release.
