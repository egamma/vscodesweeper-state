# Issue #1514 — How to localize in esm?

[https://github.com/microsoft/monaco-editor/issues/1514](https://github.com/microsoft/monaco-editor/issues/1514)

## Summary

ESM localization is now implemented and documented. The upstream fix generates localized ESM message bundles, and Monaco's current build includes them; the latest comment also confirms the approach works with Vite.

## Change summary

Provide a supported way and example to localize Monaco's editor UI when loading it through ESM.

## Best solution

Close as implemented and direct embedders to load their locale bundle before importing the editor. Use the locale path appropriate to their Monaco version; current main exposes monaco-editor/nls/lang/zh-cn.js.
