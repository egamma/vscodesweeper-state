# Issue #4378 — [Bug] Platform is not always well detected

[https://github.com/microsoft/monaco-editor/issues/4378](https://github.com/microsoft/monaco-editor/issues/4378)

## Summary

Fixed in the vscode editor core and shipped with Monaco v0.48.0: platform detection now treats `process` as native only when `process.versions.node` exists. Multiple reporters confirmed the affected webpack configuration works after upgrading.

## Change summary

Browser bundles that polyfill `process` are incorrectly detected as native environments, breaking platform-dependent behavior such as keybindings and clipboard handling.

## Best solution

Keep the platform-detection guard introduced by the vscode fix and shipped in Monaco v0.48.0; no further change is needed for this report.
