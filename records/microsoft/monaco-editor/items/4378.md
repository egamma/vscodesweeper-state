# Issue #4378 — [Bug] Platform is not always well detected

[https://github.com/microsoft/monaco-editor/issues/4378](https://github.com/microsoft/monaco-editor/issues/4378)

## Summary

The browser process-polyfill regression was fixed in the VS Code editor core and first shipped in Monaco v0.48.0. The current adopted source retains the fix, and a commenter confirmed that upgrading to 0.48.0 resolved their problem.

## Change summary

A browser process polyfill incorrectly selects native platform detection, breaking macOS shortcuts and other platform-dependent behavior.

## Best solution

Treat the reported regression as resolved by the shipped platform-detection guard, which leaves ordinary browser process polyfills on the navigator-based path.
