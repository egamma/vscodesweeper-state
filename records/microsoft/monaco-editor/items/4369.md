# Issue #4369 — [Bug] No syntax highlighting for JSDoc any longer

[https://github.com/microsoft/monaco-editor/issues/4369](https://github.com/microsoft/monaco-editor/issues/4369)

## Summary

The missing JSDoc token distinctions remain in current source: JavaScript and TypeScript classify the entire comment uniformly. Route to tokenization; the related hover-formatting issue does not own this editor-text defect.

## Change summary

JSDoc tags and type expressions lose their distinct syntax colors inside JavaScript and TypeScript comments.

## Best solution

Restore distinguishable JSDoc syntax tokens in Monaco's shared JavaScript/TypeScript Monarch grammar while preserving ordinary comment behavior. This is Monaco-owned language tokenization, not a required change to the generated VS Code editor core.
