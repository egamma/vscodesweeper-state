# Issue #4369 — [Bug] No syntax highlighting for JSDoc any longer

[https://github.com/microsoft/monaco-editor/issues/4369](https://github.com/microsoft/monaco-editor/issues/4369)

## Summary

The confirmed JSDoc highlighting gap remains on main: the JavaScript/TypeScript tokenizer assigns one comment token to all JSDoc content, preventing distinct styling of tags and types. Route this to tokenization and TypeScript.

## Change summary

Restore distinct syntax highlighting for JSDoc tags, type expressions, and identifiers in JavaScript and TypeScript.

## Best solution

Extend the JSDoc tokenizer in src/languages/definitions/typescript/typescript.ts to emit distinct tokens for supported JSDoc constructs, with corresponding JavaScript and TypeScript tokenization tests.
