# Issue #4384 — [Bug] Duplicate module load issue: 'error-stack-parser' when Monaco is combined with Pyodide under AMD loading

[https://github.com/microsoft/monaco-editor/issues/4384](https://github.com/microsoft/monaco-editor/issues/4384)

## Summary

The failure was owned by Pyodide's dependency loading rather than Monaco: Pyodide's merged fix vendors error-stack-parser and stackframe to prevent the ambient AMD loader conflict.

## Change summary

Loading Pyodide alongside Monaco's AMD loader causes stackframe to resolve through Monaco's loader and prevents editor initialization.

## Best solution

Use a Pyodide release containing pyodide/pyodide commit b46e4a572d16dd96eb29b49f87fd8d34c2bc9c2e and prefer Monaco's modern ESM integration for new applications. No Monaco editor-core change is indicated.
