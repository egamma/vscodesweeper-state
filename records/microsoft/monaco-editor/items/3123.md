# Issue #3123 — [Bug] `int` in Rust highlighted as a type

[https://github.com/microsoft/monaco-editor/issues/3123](https://github.com/microsoft/monaco-editor/issues/3123)

## Summary

The incorrect highlighting remains in the current Rust grammar: `int` explicitly receives a type-keyword token. The attempted fix was closed without merging, and the related Rust playground issue delegates the fix to Monaco.

## Change summary

Rust highlights the valid function identifier `int` as a built-in type.

## Best solution
