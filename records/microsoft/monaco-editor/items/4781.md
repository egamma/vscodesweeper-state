# Issue #4781 — [Bug] Code validation (syntax error) does not work for php language

[https://github.com/microsoft/monaco-editor/issues/4781](https://github.com/microsoft/monaco-editor/issues/4781)

## Summary

PHP validation is not a broken Monaco feature: PHP is bundled only for syntax colorization, while diagnostics require an external language service. The homepage sample's wording is misleading, but adding a built-in PHP validator is outside Monaco's bundled language-worker scope.

## Change summary

Provide built-in PHP syntax diagnostics and highlight errors such as an empty if condition.

## Best solution

Keep PHP as a basic colorization language and obtain diagnostics from a PHP language server through Monaco's LSP integration. Separately, remove or clarify the misleading syntax-error comment in the homepage PHP sample.

## Vision fit

- **Fit:** rejected
- **Reason:** Bundling a PHP validation engine conflicts with Monaco's browser-library boundary; language intelligence beyond its bundled workers is intended to integrate through LSP.
- **Evidence:** The vision identifies the bundled JSON, CSS, HTML, and TypeScript workers as the maintained language experiences and native LSP support as the path for additional languages.
