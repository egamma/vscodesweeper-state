# Issue #2598 — Bug: some actions are missing, including cut/copy/paste/undo/redo/etc.

[https://github.com/microsoft/monaco-editor/issues/2598](https://github.com/microsoft/monaco-editor/issues/2598)

## Summary

Command execution was restored, but the broader discoverability gap remains: clipboard and undo/redo commands are not editor actions returned by `getAction`. The existing `feature-request` and `editor-core` routing remains appropriate.

## Change summary

Expose core editing commands such as cut, copy, paste, undo, and redo consistently through Monaco's action discovery, command palette, and keybinding metadata.

## Best solution

Preserve the editor core's command architecture while providing a supported standalone API for discovering registered commands and their keybindings, with consistent command-palette exposure. This belongs in the vscode editor core and can flow into Monaco with a release cut.
