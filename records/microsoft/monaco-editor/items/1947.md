# Issue #1947 — Allow Submenus in Context Menu

[https://github.com/microsoft/monaco-editor/issues/1947](https://github.com/microsoft/monaco-editor/issues/1947)

## Summary

Keep open: the supported action API still lacks custom submenu registration. The discussion's internal-API workarounds do not satisfy that request, and no qualifying canonical duplicate was found.

## Change summary

Allow embedders to organize custom actions into submenus within the default editor context menu through a supported public API.

## Best solution

Provide supported submenu registration in the VS Code standalone editor API that Monaco generates, preserving existing flat actions and editor-scoped disposal. This issue should continue tracking that capability rather than requiring embedders to mutate private menu registries.

- **Reason:** Exposing existing editor menu capabilities through a supported embedder API fits Monaco's browser-library and VS Code parity goals.

## Evidence

- **Public API gap:** The published https://github.com/microsoft/monaco-editor/blob/gh-pages/node_modules/monaco-editor/monaco.d.ts declares IActionDescriptor with contextMenuGroupId and contextMenuOrder, but no submenu or child-action field. Grouping and ordering flat entries do not supply nested menus.
- **Pinned and current upstream source:** package.json pins vscodeRef c132f72ae9f5ff80093e7d722c36f03755865b20. In https://github.com/microsoft/vscode/blob/c132f72ae9f5ff80093e7d722c36f03755865b20/src/vs/editor/standalone/browser/standaloneCodeEditor.ts, StandaloneCodeEditor.addAction constructs an IMenuItem containing command, when, group and order, then appends it to MenuId.EditorContext. The same descriptor and flat registration remain in the inspected upstream main source.
- **Workarounds use private internals:** https://github.com/microsoft/monaco-editor/issues/1947#issuecomment-1555908308 imports internal MenuRegistry and LinkedList modules, mutates _menuItems and linked-list internals, and removes existing menus. https://github.com/microsoft/monaco-editor/issues/1947#issuecomment-3245201455 uses SubmenuAction with a private _contextMenuService and explicitly reports not integrating it into the default menu. README.md identifies monaco.d.ts as the versioned API and everything else as private.
