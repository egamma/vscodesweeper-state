# Issue #2043 — Expose Language Features

[https://github.com/microsoft/monaco-editor/issues/2043](https://github.com/microsoft/monaco-editor/issues/2043)

## Summary

The adapters are reachable through mode modules on current main, but they are not exposed by the documented language-feature entry points. This team-authored request remains protected because the likely-covering commit references a different issue, not this one.

## Change summary

Expose reusable language-feature adapters such as DiagnosticsAdapter and CodeActionAdaptor through a supported public API.

## Best solution

Decide whether these adapters should become supported API, then export them from the relevant `languages/features/*/register` entry points and document their use; otherwise, the team should explicitly clarify that direct mode-module imports remain unsupported.
