# Issue #1513 — Change severity of Typescript error

[https://github.com/microsoft/monaco-editor/issues/1513](https://github.com/microsoft/monaco-editor/issues/1513)

## Summary

Keep open: the bundled TypeScript integration still lacks a diagnostic-severity override. Disabling diagnostics or supplying a custom worker is not equivalent to convenient severity configuration, and no matching canonical was found.

## Change summary

Allow embedders to display TypeScript errors as warnings, optionally selected by diagnostic code.

## Best solution

Provide an opt-in severity policy in Monaco's TypeScript integration while preserving existing defaults and diagnostic details. The maintainer should settle the public configuration scope before implementation.

- **Reason:** Configurable diagnostics improve the bundled language experience through an embedder-facing API without requiring a separate editor-core behavior.
- **Evidence:** The durable themes include bundled TypeScript language experiences, and the library guardrails favor integration through APIs and language workers.
