# Issue #1513 — Change severity of Typescript error

[https://github.com/microsoft/monaco-editor/issues/1513](https://github.com/microsoft/monaco-editor/issues/1513)

## Summary

A real API gap remains: TypeScript diagnostics can be suppressed by code, but their severity cannot be overridden. The existing feature-request and typescript labels already route this appropriately.

## Change summary

Allow embedders to display all or selected TypeScript errors as warnings instead of errors.

## Best solution

Extend DiagnosticsOptions with a per-diagnostic-code severity override, then apply it while converting TypeScript diagnostics to Monaco markers in src/languages/features/typescript/languageFeatures.ts. This looks suitable for an open community PR.
