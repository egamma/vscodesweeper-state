[https://github.com/microsoft/monaco-editor/issues/3142](https://github.com/microsoft/monaco-editor/issues/3142)

## Summary

Verified duplicate of the broader, open plan to replace the webpack plugin's worker-entry mechanism with bundler-native URL handling. That work owns this chunk-sharing limitation and should retain this custom-language case as an acceptance criterion.

## Change summary

Allow Monaco workers and application code to reuse shared webpack chunks instead of duplicating dependencies in independently compiled worker bundles.

## Best solution

Consolidate on https://github.com/microsoft/monaco-editor/issues/5152 and ensure its bundler-independent worker-entry replacement permits webpack to optimize shared dependencies. The custom-language dependency duplication described here should be preserved as a concrete test case.
