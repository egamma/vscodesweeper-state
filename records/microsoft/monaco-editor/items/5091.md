# Issue #5091 — [Bug] Accessibility: NVDA reads HTML tags in the custom suggestion details pane in the Monaco editor

[https://github.com/microsoft/monaco-editor/issues/5091](https://github.com/microsoft/monaco-editor/issues/5091)

## Summary

The defect remains in the current VS Code editor core: the suggestion ARIA label uses the raw MarkdownString value, including supported HTML tags. Keep this open and route it to accessibility and suggest while the fix is made upstream and carried into Monaco.

## Change summary

NVDA announces literal HTML tags when reading suggestion documentation that enables MarkdownString.supportHtml.

## Best solution

Update the VS Code suggest widget's accessible-label construction to derive plain accessible text from rich documentation rather than exposing documentation.value verbatim; the fix will then flow into Monaco with a release cut.
