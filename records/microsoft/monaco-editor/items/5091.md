# Issue #5091 — [Bug] Accessibility: NVDA reads HTML tags in the custom suggestion details pane in the Monaco editor

[https://github.com/microsoft/monaco-editor/issues/5091](https://github.com/microsoft/monaco-editor/issues/5091)

## Summary

Keep open: current VS Code suggestion accessibility code still inserts raw documentation markup into the announcement. The v0.54.0 playground sample and exact NVDA/browser/OS steps suffice to retest, but current-version speech output was not verified.

## Change summary

NVDA announces HTML tags when navigating suggestions whose expanded documentation enables HTML, although focusing the rendered details announces only their content.

## Best solution

Make suggestion announcements reflect the readable documentation content in the microsoft/vscode editor core, preserving rendered HTML details and plain-text documentation behavior. Retest the supplied NVDA scenario and bring the upstream fix into a subsequent Monaco release.
