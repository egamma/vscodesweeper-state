# Issue #4069 — [Bug] : Editor allows ctrl+v to paste but disables when using context menu paste option.

[https://github.com/microsoft/monaco-editor/issues/4069](https://github.com/microsoft/monaco-editor/issues/4069)

## Summary

The reported behavior is intentional: `pasteAs.enabled` controls alternate paste transformations, while ordinary text paste continues through the default handler. Disabling every paste path is a separate capability request that should be routed to the clipboard area.

## Change summary

Add an editor policy that prevents ordinary paste from keyboard shortcuts, context menus, and other clipboard paths.

## Best solution

Decide in the vscode editor core whether embedders should have a dedicated paste-prevention option covering all clipboard entry points; `pasteAs` should retain its current, narrower meaning.
