# Issue #4715 — [Bug] if I give autosurround: 'never' then also Auto closing is working for single/double quotes and brackets.

[https://github.com/microsoft/monaco-editor/issues/4715](https://github.com/microsoft/monaco-editor/issues/4715)

## Summary

This is expected configuration behavior: `autoSurround` controls wrapping selected text, while automatic insertion of closing quotes and brackets is controlled by separate options.

## Change summary

Setting `autoSurround: 'never'` is expected to also disable automatic closing of quotes and brackets.

## Best solution

Keep the options independent. Embedders that want neither behavior should set `autoSurround`, `autoClosingQuotes`, and `autoClosingBrackets` to `'never'`.
