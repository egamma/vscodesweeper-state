# Issue #4715 — [Bug] if I give autosurround: 'never' then also Auto closing is working for single/double quotes and brackets.

[https://github.com/microsoft/monaco-editor/issues/4715](https://github.com/microsoft/monaco-editor/issues/4715)

## Summary

The report conflates surrounding selected text with automatically inserting closing characters. These behaviors have separate options; the supplied configuration disables surrounding but leaves auto-closing enabled.

## Change summary

Disable automatic insertion of matching quotes and brackets when typing.

## Best solution

Use autoClosingQuotes: 'never' and autoClosingBrackets: 'never' to disable automatic closing, retaining autoSurround: 'never' to disable wrapping selected text. No editor change is needed for the reported auto-closing behavior.

- **Proposed comment:**

  > Thanks for the report. `autoSurround: 'never'` disables wrapping selected text with quotes or brackets; it does not disable inserting a matching closing character while typing. To disable both behaviors, use:
  > 
  > ```js
  > myEditor.updateOptions({
  >   autoSurround: 'never',
  >   autoClosingQuotes: 'never',
  >   autoClosingBrackets: 'never'
  > });
  > ```
  > 
  > This is a configuration question rather than an editor defect. For further usage questions, please use https://stackoverflow.com/questions/tagged/monaco-editor.
