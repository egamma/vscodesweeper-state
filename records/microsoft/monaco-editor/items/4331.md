# Issue #4331 — [Bug] GlyphMarginWidget seems not working correctly in modifiedEditor

[https://github.com/microsoft/monaco-editor/issues/4331](https://github.com/microsoft/monaco-editor/issues/4331)

## Summary

The sample omits glyphMargin: true. The original diff pane explicitly enables its margin, while the modified pane retains Monaco's disabled default; this is a configuration question rather than a widget defect.

## Change summary

Display hover-created glyph-margin widgets on the modified side of a diff editor.

## Best solution

Set glyphMargin: true in the createDiffEditor options so the modified pane renders its glyph widgets; no editor change is needed.

  > Thanks for the report and the sample. Add `glyphMargin: true` to your `monaco.editor.createDiffEditor(...)` options.
