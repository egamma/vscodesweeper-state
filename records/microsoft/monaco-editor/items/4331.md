# Issue #4331 — [Bug] GlyphMarginWidget seems not working correctly in modifiedEditor

[https://github.com/microsoft/monaco-editor/issues/4331](https://github.com/microsoft/monaco-editor/issues/4331)

## Summary

This is a configuration issue rather than a modified-editor defect: Monaco disables the glyph margin by default, while the diff editor enables it specially on the original side in side-by-side mode.

## Change summary

Show a custom glyph-margin widget when hovering over lines in the modified side of a diff editor.

## Best solution

Enable `glyphMargin: true` in the `createDiffEditor` options so both embedded editors allocate and render their glyph margins.

- **Proposed comment:**

  > Thanks for the report and playground example. Monaco disables the glyph margin by default. In a side-by-side diff editor the original side enables that margin for diff controls, which explains the apparent asymmetry, while the modified side retains the default setting. Adding `glyphMargin: true` to the `createDiffEditor` options enables the widget on both sides.
