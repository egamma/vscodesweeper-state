# Issue #5233 — [Bug] Java syntax highlighting does not handle unicode escape sequences

[https://github.com/microsoft/monaco-editor/issues/5233](https://github.com/microsoft/monaco-editor/issues/5233)

## Summary

Keep open: the Java tokenizer treats escaped line breaks as comment text, potentially concealing executable Java code. The security-sensitive report and its open implementation PR independently prohibit closing it.

## Change summary

Java Unicode escapes are highlighted as ordinary comment text even when Java preprocessing makes the following text executable code.

## Best solution

Review https://github.com/microsoft/monaco-editor/pull/5578 against the supplied example and Java escape eligibility rules, ensuring executable text following escaped line terminators is visibly distinguished from comments.
