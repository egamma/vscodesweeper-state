# Issue #3426 — [Bug] Freemarker

[https://github.com/microsoft/monaco-editor/issues/3426](https://github.com/microsoft/monaco-editor/issues/3426)

## Summary

HTML-aware FreeMarker highlighting remains missing from the bundled grammar. Keep this accepted enhancement open: the existing syntax variants do not cover it, and no open canonical or implementation PR was found.

## Change summary

Provide detailed highlighting for HTML mixed with FreeMarker directives and interpolations.

## Best solution

Design an HTML-aware FreeMarker experience in the bundled language definitions while preserving support for templates producing arbitrary text. This looks suitable for a community contribution once the public language-mode contract is settled.

- **Behavior:**

  > HTML-aware FreeMarker editing should distinguish HTML tags and attributes while continuing to highlight FreeMarker directives and interpolations, including interpolations inside HTML attributes. Use the issue's official FreeMarker sample as an acceptance case. Existing non-HTML template workflows and tag/interpolation syntax variants must remain supported.
- **Trace:**

  > The freemarker2 registration loads TagAutoInterpolationDollar; the explicitly selected angle/dollar registration loads TagAngleInterpolationDollar. Both use createMonarchLanguage, whose interpolation_and_text_token rules assign surrounding text the source token; no HTML embedding is present. Existing tokenization tests explicitly encode this plain-text behavior. https://github.com/microsoft/monaco-editor/issues/2383#issuecomment-1041567081 documents why the initial grammar avoided interpreting generated content. The gap lives in this repository's bundled grammar, not the generated vscode editor core. The unresolved boundary is how HTML-aware highlighting is selected without changing arbitrary-text templates unexpectedly.
- **Open decisions:**
  - Should HTML-aware FreeMarker highlighting be exposed through a separate opt-in language mode, or should existing FreeMarker language IDs infer the document language?
