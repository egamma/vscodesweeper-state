# Issue #3426 — [Bug] Freemarker

[https://github.com/microsoft/monaco-editor/issues/3426](https://github.com/microsoft/monaco-editor/issues/3426)

## Summary

A real grammar gap remains: Monaco intentionally tokenizes non-FreeMarker template content as plain source, so embedded HTML receives no highlighting. The existing feature-request, help-wanted, and grammars labels correctly keep this open for a contribution.

## Change summary

Extend FreeMarker syntax highlighting to recognize HTML surrounding FreeMarker directives and interpolations.

## Best solution

Add an HTML-aware FreeMarker language mode in src/languages/definitions/freemarker2 while retaining the current generic mode for templates producing arbitrary text. This is suitable for a community contribution, with tests covering mixed HTML, directives, and interpolations.
