# Issue #1300 — FR: Detect when addExtraLib is done processing / Permit bulk add/delete extra lib operations

[https://github.com/microsoft/monaco-editor/issues/1300](https://github.com/microsoft/monaco-editor/issues/1300)

## Summary

Bulk library replacement and worker reuse are supported, but the requested signal that all queued libraries have finished processing remains absent. Keep this accepted Backlog request open; the newer async-library request does not qualify as its canonical.

## Change summary

Provide bulk extra-library updates and a programmatic readiness signal so embedders can show progress until JavaScript/TypeScript language features are ready.

## Best solution

Retain setExtraLibs for bulk replacement and define a readiness contract in the Monaco TypeScript defaults/worker integration that covers successive updates. Coordinate with https://github.com/microsoft/monaco-editor/issues/4320 while distinguishing worker receipt from completed language-service processing.
