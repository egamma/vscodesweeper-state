# Issue #1300 — FR: Detect when addExtraLib is done processing / Permit bulk add/delete extra lib operations

[https://github.com/microsoft/monaco-editor/issues/1300](https://github.com/microsoft/monaco-editor/issues/1300)

## Summary

The bulk-operation half is implemented through `setExtraLibs`, but the current API still provides no signal that the latest coalesced update has reached the TypeScript worker. This remains the oldest and broader canonical request for that completion contract.

## Change summary

Provide bulk extra-library updates and a reliable notification when all pending libraries have been processed by the TypeScript worker.

## Best solution

Keep `setExtraLibs` for bulk replacement and add an awaitable completion contract that resolves after the latest coalesced `updateExtraLibs` worker call completes. Consolidate the newer https://github.com/microsoft/monaco-editor/issues/4320 request into this issue rather than closing this broader, older report.
