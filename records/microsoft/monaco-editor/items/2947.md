# Issue #2947 — [Bug] Multiple editor instances only latest created instance is working properly

[https://github.com/microsoft/monaco-editor/issues/2947](https://github.com/microsoft/monaco-editor/issues/2947)

## Summary

The regression remains in the current editor core: all standalone editors share one keybinding service, and instance-level addCommand calls register into that shared service. This issue is the established canonical and should remain open.

## Change summary

Commands registered on one editor instance override or execute from other editor instances on the same page.

## Best solution

Fix this in the VS Code standalone editor core by scoping instance-level commands to their owning editor or providing independent keybinding state per editor. Until then, addAction with editor-specific preconditions remains the safer workaround.
