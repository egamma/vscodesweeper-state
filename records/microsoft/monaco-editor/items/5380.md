# Issue #5380 — [Bug] After switching the model, the placeholder does not disappear

[https://github.com/microsoft/monaco-editor/issues/5380](https://github.com/microsoft/monaco-editor/issues/5380)

## Summary

The supplied model-switching example exposes a stale placeholder state that remains explainable in current VS Code source. Keep open and route to editor-core; no matching canonical or concrete fix was found.

## Change summary

Switching between empty and non-empty models leaves placeholder visibility reflecting the previous model.

## Best solution

Make placeholder visibility track the attached model's emptiness, including switches between models with identical version IDs. The change belongs in microsoft/vscode's ObservableCodeEditor and should reach Monaco through a subsequent editor-core release cut.
