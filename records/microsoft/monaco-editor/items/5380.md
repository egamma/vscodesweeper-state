# Issue #5380 — [Bug] After switching the model, the placeholder does not disappear

[https://github.com/microsoft/monaco-editor/issues/5380](https://github.com/microsoft/monaco-editor/issues/5380)

## Summary

The model-switching defect remains traceable in the current editor core: placeholder visibility observes the model version ID but not the model itself, so switching between models with equal version IDs does not recompute visibility. Route this to the editor contribution area.

## Change summary

Placeholder visibility is not refreshed when switching between an empty and non-empty model.

## Best solution

Fix `observableCodeEditor.valueIsEmpty` in the VS Code editor core to depend on the model observable as well as its version, and add a regression test that switches empty and non-empty models sharing the same version ID. The correction will then flow into Monaco through a subsequent release.

## Evidence
