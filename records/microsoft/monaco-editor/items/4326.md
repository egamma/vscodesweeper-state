# Issue #4326 — [Bug] wordBasedSuggestions set to "off" but still seeing content-based suggestions in json

[https://github.com/microsoft/monaco-editor/issues/4326](https://github.com/microsoft/monaco-editor/issues/4326)

## Summary

This is intended JSON language-service completion, not the editor's word-based suggestion provider. Monaco already exposes a separate configuration for disabling built-in JSON completions.

## Change summary

Prevent previously used values from appearing as JSON suggestions when word-based suggestions are disabled.

## Best solution

Keep the providers independently configurable: use `jsonDefaults.setModeConfiguration` with `completionItems: false` when built-in JSON completions should be disabled, while preserving the remaining mode configuration.

  > Thanks for the playground reproduction. The `"test"` entry is intentionally produced by the JSON language service, which suggests values previously used for the same property name; it is separate from the editor's generic word-based suggestion provider, so `wordBasedSuggestions: 'off'` does not suppress it.
  > 
  > To disable the built-in JSON completion provider while preserving the other JSON features, configure it before creating the editor:
  > 
  > ```ts
  > const mode = monaco.languages.json.jsonDefaults.modeConfiguration;
  > monaco.languages.json.jsonDefaults.setModeConfiguration({
  >   ...mode,
  >   completionItems: false
  > });
  > ```
  > 
  > Closing as designed because the existing provider-specific configuration covers disabling these suggestions.
