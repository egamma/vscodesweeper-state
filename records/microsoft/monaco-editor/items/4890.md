# Issue #4890 — [Bug] setModelMarkers() with MarkerSeverity.Hint only underlines the first letter, regardless of the endColumn value

[https://github.com/microsoft/monaco-editor/issues/4890](https://github.com/microsoft/monaco-editor/issues/4890)

## Summary

The short Hint indicator is intentional VS Code editor behavior, not a failure to honor marker ranges. Propose a manual as-designed close explaining the distinction and acknowledging the documentation gap.

## Change summary

Render Hint markers across their entire supplied range, like Info, Warning, and Error markers.

## Best solution

Preserve the inherited compact hint indicator and clarify its rendering semantics in the API documentation. Embedders needing a full-range diagnostic underline can use MarkerSeverity.Info.
