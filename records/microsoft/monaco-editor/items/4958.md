# Issue #4958 — [Feature Request] How to implement a peek window in Monaco Editor and customize its content, for example, to display a diff editor?

[https://github.com/microsoft/monaco-editor/issues/4958](https://github.com/microsoft/monaco-editor/issues/4958)

## Summary

The requested customizable peek-window API is outside Monaco's supported public surface, as confirmed by the maintainer-applied out-of-scope label. Embedders can instead compose equivalent UI from public editor primitives.

## Change summary

Expose an API for creating a customizable peek window whose body can contain components such as a diff editor.

## Best solution

Keep VS Code's PeekViewWidget internal and build this embedder-specific interface using a view zone or content widget together with a separately created diff editor.

## Vision fit

- **Fit:** rejected
- **Reason:** A customizable wrapper around an internal VS Code widget conflicts with Monaco's generated-library boundary; embedder-specific interfaces should use supported public APIs.
- **Evidence:** The README states that Monaco is "generated straight from VS Code's sources with some shims around services the code needs to make it run in a web browser," while the vision favors integration through public API surfaces rather than Monaco-specific forks of editor internals.
