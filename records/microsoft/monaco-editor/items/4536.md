## Summary

Verified duplicate of the open shell command-substitution tokenization issue: the tokenizer stops at the first closing parenthesis inside the quoted text, leaving the command substitution's final parenthesis unmatched.

## Change summary

Shell highlighting reports an unexpected closing bracket when command substitution contains parentheses inside a quoted string.

## Best solution

Consolidate on https://github.com/microsoft/monaco-editor/issues/1984 and update the shell Monarch grammar to handle quoted and nested parentheses within command substitutions.
