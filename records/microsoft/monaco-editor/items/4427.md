# Issue #4427 — [Feature Request] Add support for X position of a line decoration

[https://github.com/microsoft/monaco-editor/issues/4427](https://github.com/microsoft/monaco-editor/issues/4427)

## Summary

A real API gap remains: line decorations receive a fixed gutter position and width, with no option for horizontal lanes or offsets. Route this editor-core request to the rendering and API owners.

## Change summary

Allow overlapping line decorations to occupy distinct horizontal positions in the editor gutter.

## Best solution

Add an editor-core decoration option for horizontal placement within the lines-decoration gutter, likely using a lane model rather than arbitrary CSS offsets; this belongs in microsoft/vscode and would flow into Monaco with a later release. Existing glyph-margin lanes are a possible workaround for three positions, but do not provide placement of `linesDecorationsClassName` elements.

## Evidence

- **API gap:** `IModelDecorationOptions.linesDecorationsClassName` and `firstLineDecorationClassName` accept only CSS class names; there is no line-decoration position or lane property: https://github.com/microsoft/vscode/blob/main/src/vs/editor/common/model.ts
- **partial existing capability:** `IModelDecorationOptions.glyphMargin` supports `GlyphMarginLane.Left`, `Center`, and `Right`, but that positions `glyphMarginClassName` decorations in the separate glyph margin and does not horizontally position line decorations: https://github.com/microsoft/vscode/blob/main/src/vs/editor/common/model.ts
