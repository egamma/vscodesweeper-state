# Issue #463 — Reducing size of monaco-editor dependency

[https://github.com/microsoft/monaco-editor/issues/463](https://github.com/microsoft/monaco-editor/issues/463)

## Summary

Keep open: current packaging still includes development and minified builds alongside ESM. Tree-shakeable imports reduce application bundles, but do not satisfy the original request for a smaller installed npm dependency.

## Change summary

Offer a smaller npm distribution that avoids installing unused build variants and debugging artifacts.

## Best solution

Decide the supported distribution contract for reducing installed package size, coordinated with AMD retirement. Preserve this request separately from browser-bundle optimization: neither selective imports nor compression removes unused files from the installed dependency.
