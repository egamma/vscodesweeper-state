# Issue #463 — Reducing size of monaco-editor dependency

[https://github.com/microsoft/monaco-editor/issues/463](https://github.com/microsoft/monaco-editor/issues/463)

## Summary

The open team-authored issue https://github.com/microsoft/monaco-editor/issues/5153 now owns the broader solution: removing the deprecated AMD builds from the npm package. Consolidating there preserves this report's package-footprint evidence.

## Change summary

Provide a smaller Monaco npm distribution that omits development builds and source maps unnecessary for production consumers.

## Best solution

Remove the deprecated AMD `dev` and `min` artifacts through https://github.com/microsoft/monaco-editor/issues/5153 and use the supported tree-shakeable ESM entry points introduced in v0.56.0 for custom production bundles.

- **Fit:** aligned
- **Reason:** Reducing redundant package artifacts supports Monaco's ESM-first, lean-package direction.
- **Evidence:** The README says AMD is deprecated, while the v0.56.0 changelog introduces supported, tree-shakeable ESM entry points.
