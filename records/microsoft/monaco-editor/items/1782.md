# Issue #1782 — Monaco's underlying textarea, and content, can get out of sync when native undo is used

[https://github.com/microsoft/monaco-editor/issues/1782](https://github.com/microsoft/monaco-editor/issues/1782)

## Summary

Keep open: the report and contributor follow-up provide concrete steps sufficient to retest native menu undo/redo. Monaco has changed since v0.19.3, and a related Electron report stopped reproducing in 2023, but neither establishes that the standalone browser defect is fixed.

## Change summary

Native menu undo/redo can change Monaco's backing textarea without updating editor content after window focus changes.

## Best solution

Retest both the window-refocus sequence and the delete-character/Edit → Undo sequence on current Monaco. If either remains broken, address native undo synchronization in the VS Code-derived standalone editor input implementation, with the fix delivered through Monaco's release pipeline.
