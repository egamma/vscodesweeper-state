# Issue #4638 — [Bug] `CompletionItem.range` has a default but is marked as required in the typings

[https://github.com/microsoft/monaco-editor/issues/4638](https://github.com/microsoft/monaco-editor/issues/4638)

## Summary

The mismatch remains on current main: the public typing requires `CompletionItem.range`, while the editor core explicitly supplies a default when providers omit it. This is an editor-core API issue that should remain open and be routed to the suggest/API owners.

## Change summary

Allow completion providers to omit `CompletionItem.range` when relying on the editor's documented runtime default.

## Best solution

Update the provider-facing completion type in the VS Code editor core so `range` may be omitted, while preserving a normalized internal type after the default range is assigned; the generated Monaco declaration will inherit that correction.
