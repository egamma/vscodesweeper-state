# Issue #5073 — [Bug] monaco-editor-webpack-plugin 7.1.1 breaks CDN deployments with "Cannot use import statement outside a module"

[https://github.com/microsoft/monaco-editor/issues/5073](https://github.com/microsoft/monaco-editor/issues/5073)

## Summary

Keep open: current main retains the reported worker-bootstrap heuristic, and the downstream upgrade explicitly preserved the workaround rather than fixing it. Monaco versions have advanced, but the supplied cross-origin configuration and error suffice to retest; current browser reproduction remains unverified.

## Change summary

Webpack plugin 7.1.1 generates module-import blob code for classic workers, breaking cross-origin CDN deployments.

## Best solution

Make the webpack plugin's cross-origin bootstrap compatible with the worker actually constructed across supported Monaco versions, preserving both classic and module workers. First reproduce the reported configuration; reverting unconditionally to importScripts would risk restoring the opposite module-worker failure.
