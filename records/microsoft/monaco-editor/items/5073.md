# Issue #5073 — [Bug] monaco-editor-webpack-plugin 7.1.1 breaks CDN deployments with "Cannot use import statement outside a module"

[https://github.com/microsoft/monaco-editor/issues/5073](https://github.com/microsoft/monaco-editor/issues/5073)

## Summary

Still present on main: webpack plugin 7.1.1 selects the blob script syntax from the host bundle's `import.meta`, which does not establish whether Monaco creates a classic or module worker. This breaks cross-origin deployments using older Monaco versions that remain within the plugin's declared peer range.

## Change summary

Cross-origin workers fail because webpack plugin 7.1.1 emits an ES module import inside a blob that older Monaco versions start as a classic worker.

## Best solution

Make the cross-origin bootstrap explicitly match Monaco's worker type, supporting both classic and module workers across the declared compatibility range. If that compatibility cannot be preserved, narrow the `monaco-editor` peer dependency rather than selecting worker syntax from the host bundle.
