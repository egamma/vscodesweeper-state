# Issue #1847 — JavaScript folding ranges are not semantic

[https://github.com/microsoft/monaco-editor/issues/1847](https://github.com/microsoft/monaco-editor/issues/1847)

## Summary

The semantic-folding gap remains on main: Monaco's bundled JavaScript/TypeScript mode still registers no folding provider, although the included TypeScript language service supports outlining spans. The existing typescript and open-for-PR routing remains appropriate.

## Change summary

Provide syntax-aware folding for JavaScript and TypeScript instead of relying solely on indentation.

## Best solution

Expose TypeScript's `getOutliningSpans` through the worker, adapt those spans to Monaco folding ranges, and register the provider for JavaScript and TypeScript in `src/languages/features/typescript/tsMode.ts`. This remains suitable for a community PR.
