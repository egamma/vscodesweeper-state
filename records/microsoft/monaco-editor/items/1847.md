# Issue #1847 — JavaScript folding ranges are not semantic

[https://github.com/microsoft/monaco-editor/issues/1847](https://github.com/microsoft/monaco-editor/issues/1847)

## Summary

The bundled JavaScript/TypeScript support still lacks a language-aware folding provider. Keep this accepted feature request open: custom providers are possible, but they do not supply the requested built-in capability.

## Change summary

Provide JavaScript/TypeScript folding ranges based on language structure rather than indentation.

## Best solution

Provide language-aware folding through Monaco's bundled JavaScript/TypeScript worker integration, using the TypeScript language service's outlining capability. This remains suitable for a community PR, as the existing maintainer labels indicate.

- **Behavior:**

  > Built-in JavaScript/TypeScript folding should recognize multiline function structure without requiring indentation. In the issue's sample, both double and double2 should offer usable fold controls. Acceptance should cover both language modes and updates after editing, while preserving explicit indentation-only folding.
- **Trace:**

  > Both language modes use setupMode in src/languages/features/typescript/tsMode.ts, whose registerProviders has no folding registration. src/languages/features/typescript/register.ts likewise exposes no folding mode configuration, and tsWorker.ts has no getOutliningSpans bridge. The bundled TypeScript declarations already expose LanguageService.getOutliningSpans with text spans and outlining kinds, but availability is not adoption. The playground's custom folding-provider example proves an extension point exists, not that built-in JavaScript folding is implemented. This is a Monaco language-integration feature, not a required change to the generated editor core or TypeScript's outlining engine. Related import-folding work is at https://github.com/microsoft/monaco-editor/issues/2617; runtime range conversion and acceptance behavior remain unverified in this read-only review.
- **Open decisions:**
