# Issue #2264 — Paste menu item doesn't work in sandboxed item

[https://github.com/microsoft/monaco-editor/issues/2264](https://github.com/microsoft/monaco-editor/issues/2264)

## Summary

Keep open as the canonical request for context-menu paste handling in clipboard-restricted iframes. A maintainer reproduced and diagnosed the browser-policy limitation, and the team-authored issue is already correctly routed as an integration feature request.

## Change summary

Make context-menu paste usable, or hide it when unusable, inside sandboxed iframes that deny Clipboard API access.

## Best solution

In the vscode editor core, detect when programmatic clipboard reads are unavailable and suppress or appropriately disable the Paste action while retaining native Ctrl+V behavior. Preserve this issue as the canonical report; any implementation must remain safe for cross-origin frames rather than accessing `window.top` directly.
