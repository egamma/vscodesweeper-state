# Issue #2199 — Chinese IME does not work correctly with CompletionItemProvider

[https://github.com/microsoft/monaco-editor/issues/2199](https://github.com/microsoft/monaco-editor/issues/2199)

## Summary

Fixed in the VS Code editor core: suggestions no longer trigger during IME composition and are reevaluated when composition ends. The fix was verified with Chinese input and shipped in Monaco v0.31.0.

## Change summary

Completion items with Chinese labels fail to appear after entering text through a Chinese or Japanese IME.

## Best solution

Keep the editor-core IME suggestion fix from https://github.com/microsoft/vscode/commit/22f7085a3245848a770bd8fdd68b6be2f4ef66d8, shipped in Monaco v0.31.0; no Monaco-specific change remains.
