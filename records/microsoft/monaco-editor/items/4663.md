# Issue #4663 — [Feature Request] Support ES2023

[https://github.com/microsoft/monaco-editor/issues/4663](https://github.com/microsoft/monaco-editor/issues/4663)

## Summary

The central API gap remains on main: Monaco's public ScriptTarget enum still stops at ES2020, despite the bundled TypeScript service and library index supporting ES2023. Route this valid request to the TypeScript area.

## Change summary

Expose ES2021 through ES2023 ScriptTarget values and reliably load their standard-library declarations.

## Best solution

Update src/languages/features/typescript/register.ts so the public ScriptTarget enum tracks the vendored TypeScript targets, with coverage for selecting ES2023 and its libraries. This looks suitable for an open-for-PR contribution.
