# Issue #4067 — [Feature Request] Expose TypeScript formatting options

[https://github.com/microsoft/monaco-editor/issues/4067](https://github.com/microsoft/monaco-editor/issues/4067)

## Summary

The requested TypeScript/JavaScript formatting API remains absent on main, while formatting preferences are still hardcoded. The issue is already correctly routed and marked for community contribution.

## Change summary

Expose TypeScript-specific formatter settings instead of limiting embedders to generic tab and indentation options.

## Best solution

Add a backward-compatible formatting configuration to `LanguageServiceDefaults` and feed it into `FormatHelper._convertOptions`; this is suitable for a community PR without requiring the broader API deprecations proposed in the issue.
