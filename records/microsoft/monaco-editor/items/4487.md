# Issue #4487 — [Bug] Can't automatic init webworker

[https://github.com/microsoft/monaco-editor/issues/4487](https://github.com/microsoft/monaco-editor/issues/4487)

## Summary

This is a Vite integration question rather than an editor defect: Monaco requires the embedder to provide `MonacoEnvironment.getWorker`, and the warning confirms that configuration is absent.

## Change summary

Automatically initialize Monaco web workers in a Vue application bundled with Vite.

## Best solution

Configure `MonacoEnvironment.getWorker` using Vite worker imports, following the repository's Vite integration documentation and sample.
