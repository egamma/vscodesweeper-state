# Issue #4487 — [Bug] Can't automatic init webworker

[https://github.com/microsoft/monaco-editor/issues/4487](https://github.com/microsoft/monaco-editor/issues/4487)

## Summary

The reported Monaco 0.48.0 error identifies missing worker configuration in the Vite application, rather than a theme or browser defect. Treat this as an integration-support question.

## Change summary

Initialize Monaco's web workers successfully in a Vue application bundled with Vite.

## Best solution

Configure MonacoEnvironment.getWorker before creating the editor, using Vite-bundled worker constructors appropriate to the installed Monaco version. Track documentation defects separately from this application's missing configuration.
