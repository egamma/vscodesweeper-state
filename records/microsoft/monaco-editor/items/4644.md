# Issue #4644 — [Bug] Cursor becomes misaligned when using custom font

[https://github.com/microsoft/monaco-editor/issues/4644](https://github.com/microsoft/monaco-editor/issues/4644)

## Summary

The supported custom-font workflow already covers this case: wait for the asynchronous font load and call `monaco.editor.remeasureFonts()`. The reporter confirmed that this resolves the misalignment and said the issue should be closed.

## Change summary

Keep the cursor aligned when a custom web font finishes loading after the editor has measured its text.

## Best solution

Retain the existing `remeasureFonts()` API and have embedders invoke it after `document.fonts.ready` when loading custom fonts asynchronously.
