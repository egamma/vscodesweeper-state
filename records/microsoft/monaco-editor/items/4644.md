# Issue #4644 — [Bug] Cursor becomes misaligned when using custom font

[https://github.com/microsoft/monaco-editor/issues/4644](https://github.com/microsoft/monaco-editor/issues/4644)

## Summary

The reporter explicitly confirmed resolution using the existing font-remeasurement API. This is a resolved custom-font integration question, with no remaining editor change requested.

## Change summary

Keep the cursor aligned when an asynchronously loaded custom font replaces the font initially measured by the editor.

## Best solution

Use document.fonts.ready followed by monaco.editor.remeasureFonts() as the reporter demonstrated, and close the resolved integration question.
