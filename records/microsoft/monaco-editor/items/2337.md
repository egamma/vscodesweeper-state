# Issue #2337 — Windows High Contrast mode with Firefox makes scrollbars not visible using all built-in themes

[https://github.com/microsoft/monaco-editor/issues/2337](https://github.com/microsoft/monaco-editor/issues/2337)

## Summary

Keep open as an upstream Firefox accessibility issue. A maintainer traced the failure to Firefox not exposing Windows high-contrast state through the media query Monaco uses, and no current retest establishes that the browser limitation has been resolved.

## Change summary

Make Monaco scrollbars visible when Windows High Contrast mode is active in Firefox.

## Best solution

Track whether current Firefox exposes Windows forced-colors state reliably; once supported upstream, confirm Monaco selects its high-contrast styling automatically and that both scrollbars remain visible in the current playground.
