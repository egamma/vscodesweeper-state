# Issue #4858 — [Bug] Code suggestions not work in javascript language

[https://github.com/microsoft/monaco-editor/issues/4858](https://github.com/microsoft/monaco-editor/issues/4858)

## Summary

The requested literal-value suggestions are already supported, but Monaco intentionally disables automatic quick suggestions inside strings by default. Enabling `quickSuggestions: { strings: true }` provides the expected behavior.

## Change summary

Show JavaScript string-literal argument suggestions derived from union types supplied through `setExtraLibs`.

## Best solution

Keep the current configurable default and enable `quickSuggestions: { strings: true }` in embeddings that want automatic suggestions inside string literals.
