# Issue #4876 — [Bug] stickyScroll ignores maxLineCount? Only sticks 1 line (for language less)

[https://github.com/microsoft/monaco-editor/issues/4876](https://github.com/microsoft/monaco-editor/issues/4876)

## Summary

Still present on main: the CSS/LESS worker returns a flat symbol list, so sticky scroll cannot reconstruct nested LESS selectors. Routing this Monaco-owned language-worker bug to CSS and sticky scroll.

## Change summary

Sticky scroll shows only one scope instead of the configured number for nested LESS selectors.

## Best solution

Change `CSSWorker.findDocumentSymbols` in `src/languages/features/css/cssWorker.ts` to use the language service's hierarchical `findDocumentSymbols2` API, preserving nested selectors for sticky scroll, with coverage for nested LESS symbols.
