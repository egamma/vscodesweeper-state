## Summary

Keep open: the supplied playground code and steps suffice to retest the scroll-offset defect. ContextView positioning has changed since v0.57.0, but the currently bundled source still passes viewport-relative hover anchors into page-coordinate layout; browser behavior was not executed.

## Change summary

Find-widget tooltips appear too high or disappear above the viewport when the embedding page is scrolled.
