# Issue #2796 — provide typescript.preferences.importModuleSpecifierEnding setting from vscode for monaco editor

[https://github.com/microsoft/monaco-editor/issues/2796](https://github.com/microsoft/monaco-editor/issues/2796)

## Summary

The capability remains absent on current main: Monaco exposes inlay-hint preferences but not TypeScript completion preferences, so automatic imports cannot honor importModuleSpecifierEnding. The issue is already correctly routed to the TypeScript area.

## Change summary

Expose the TypeScript importModuleSpecifierEnding preference so embedders can control extensions in automatically generated imports.

## Best solution

Add a TypeScript UserPreferences API to LanguageServiceDefaults, pass it into the worker, and supply it to completion and completion-detail requests in src/languages/features/typescript. This looks suitable for a focused community PR.
