# Issue #4956 — Can CompletionItem support parameter control for showing or hiding details, without requiring selection to display？

[https://github.com/microsoft/monaco-editor/issues/4956](https://github.com/microsoft/monaco-editor/issues/4956)

## Summary

The requested always-visible type information is already supported through structured completion labels. Answer this as an API usage question rather than adding a new CompletionItem parameter.

## Change summary

Show custom completion items' data types before individual suggestions are selected.

## Best solution

Supply each item's type in CompletionItem.label.description using a structured label, and enable suggest.showInlineDetails. Keep detail for the focused item's additional information; no editor-core change is necessary.

- **Proposed comment:**

  > Thanks for the context. You can already show the data type on each suggestion without selecting it: use a structured completion label, for example `label: { label: 'myVariable', description: 'string' }`, and set the editor option `suggest: { showInlineDetails: true }`. Return that description from `provideCompletionItems` so it is available before selection. The separate `CompletionItem.detail` field has focus-dependent display; `label.description` is the always-visible row information.
  > 
  > This is supported by the existing API rather than requiring a new parameter. For further usage questions, please use https://stackoverflow.com/questions/tagged/monaco-editor.
