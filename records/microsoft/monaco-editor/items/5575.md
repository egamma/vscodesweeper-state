# Issue #5575 — [Bug] JavaScript/TypeScript tokenizer: regex literals with `/` inside `[...]` or with the `v` flag are not recognized

[https://github.com/microsoft/monaco-editor/issues/5575](https://github.com/microsoft/monaco-editor/issues/5575)

## Summary

The shared JavaScript/TypeScript grammar still mishandles slashes inside regex character classes and excludes the v flag on current main. Keep this open while the explicitly linked implementation PR is reviewed.

## Change summary

Recognize regex literals containing slashes inside character classes and literals using the v flag without corrupting subsequent highlighting.

## Best solution

Review and land https://github.com/microsoft/monaco-editor/pull/5576 with its JavaScript and TypeScript regression cases, preserving division tokenization. Coordinate its overlapping look-ahead change with https://github.com/microsoft/monaco-editor/pull/5552, which addresses a separate ternary-colon case.
