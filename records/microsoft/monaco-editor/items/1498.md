# Issue #1498 — Allow changing the wordBasedSuggestions via configuration service

[https://github.com/microsoft/monaco-editor/issues/1498](https://github.com/microsoft/monaco-editor/issues/1498)

## Summary

The underlying API gap remains: `wordBasedSuggestions` is still a global standalone-editor option backed by the shared configuration service, rather than an independently resolved per-editor option. The accepted On Deck request should remain open.

## Change summary

Make `wordBasedSuggestions` honor editor-specific configuration instead of relying on Monaco's shared configuration service.

## Best solution

Move word-based completion configuration to an editor- or model-specific resolution path in the vscode editor core, then inherit that change in Monaco. The implementation should also resolve the multi-editor behavior tracked at https://github.com/microsoft/monaco-editor/issues/3378.
