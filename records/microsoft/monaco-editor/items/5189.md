# Issue #5189 — [Bug] How to stop auto adding space after colon on css properties?

[https://github.com/microsoft/monaco-editor/issues/5189](https://github.com/microsoft/monaco-editor/issues/5189)

## Summary

This is a valid configurability request rather than a bug: CSS property completions intentionally insert `": "`, and no setting currently controls that space. Route it to the CSS language area.

## Change summary

Allow embedders to omit the space after the colon inserted by CSS property completion.

## Best solution

Add a CSS completion setting in vscode-css-languageservice for the property separator text and expose it through Monaco's CSS language-service options. Disabling Monaco's built-in completion provider and supplying a custom provider is possible but does not adequately cover the request.
