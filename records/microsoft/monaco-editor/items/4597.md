# Issue #4597 — [Question][Feature Request] Add ability to go from standalone editor into a diff editor

[https://github.com/microsoft/monaco-editor/issues/4597](https://github.com/microsoft/monaco-editor/issues/4597)

## Summary

Keep open: this team-authored request identifies a real API gap—diff editors still create their own editor instances rather than adopting an existing standalone editor—and no open canonical owns the work.

## Change summary

Provide an easier, capability-preserving transition from an existing standalone code editor to a diff editor.

## Best solution

Evaluate an editor-core API in microsoft/vscode that lets a diff editor adopt or reuse an existing modified editor; if that is not feasible, document the supported model-reuse transition and the behavioral differences between standalone code and diff editors.
