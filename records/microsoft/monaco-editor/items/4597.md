# Issue #4597 — [Question][Feature Request] Add ability to go from standalone editor into a diff editor

[https://github.com/microsoft/monaco-editor/issues/4597](https://github.com/microsoft/monaco-editor/issues/4597)

## Summary

Keep this team-authored request open and route it to diff-editor/editor-api. Existing APIs expose the diff editor's constituent code editors, but do not support adopting an already-created standalone editor.

## Change summary

Allow an existing standalone code editor to transition into a diff editor without recreating its editor instance, and clarify feature compatibility.

## Best solution

Clarify which standalone features are available through getModifiedEditor(), then decide whether editor-instance adoption should become a supported API. Any editor construction change belongs in the VS Code editor core and would flow into Monaco through its generation pipeline.

  > Thanks for the context. The diff editor already contains standalone code editors: getModifiedEditor() and getOriginalEditor() expose their APIs, and diff-editor commands and actions delegate to the modified editor. That does not guarantee identical behavior for every feature in a diff layout.
