# Issue #4310 — [Bug] Loading monaco via require doesn't always respect urlArgs parameter

[https://github.com/microsoft/monaco-editor/issues/4310](https://github.com/microsoft/monaco-editor/issues/4310)

## Summary

The AMD loader mishandles `urlArgs`, including worker URLs, but AMD support is now explicitly deprecated and unsupported. Further AMD-loader fixes are therefore out of scope.

## Change summary

Make the bundled AMD loader consistently apply RequireJS `urlArgs` without duplicating arguments or corrupting language-worker URLs.

## Best solution

Use the supported ESM build, or place each Monaco release under a versioned asset path for cache invalidation. Do not extend the deprecated AMD loader.

## Vision fit

- **Fit:** rejected
- **Reason:** Investing further in AMD-loader behavior conflicts with Monaco's ESM-first direction and the explicit withdrawal of AMD support.
- **Evidence:** README.md states that AMD support is deprecated and will be removed; CHANGELOG.md for v0.53.0 says the team no longer offers support for the AMD build and recommends migrating to ESM.
