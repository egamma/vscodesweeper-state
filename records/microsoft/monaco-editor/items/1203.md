# Issue #1203 — Add a setting like fixedOverflowWidgets for the context menu

[https://github.com/microsoft/monaco-editor/issues/1203](https://github.com/microsoft/monaco-editor/issues/1203)

## Summary

A real capability gap remains: current editor-core code does not use `fixedOverflowWidgets` or the configured overflow widget node for ordinary context-menu placement. The issue is already correctly classified and should remain open in Backlog.

## Change summary

Allow the editor context menu to escape an embedding container with `overflow: hidden`, similarly to fixed overflow widgets.

## Best solution

Extend the VS Code editor-core context-menu integration to render into `overflowWidgetsDomNode`, or introduce a dedicated context-menu container option while preserving current defaults; Monaco will inherit the change on its next source update. This looks suitable for a community PR.

## Evidence

- **existing API limitation:** https://github.com/microsoft/vscode/blob/main/src/vs/editor/browser/editorBrowser.ts defines `overflowWidgetsDomNode` specifically as the parent for overflow widgets, while `fixedOverflowWidgets` is not consulted by the context-menu path.
- **partial existing capability:** CHANGELOG.md documents `overflowWidgetsDomNode` in Monaco v0.21.0, but current source shows that it still does not cover the issue's ordinary non-shadow-DOM context-menu case.
