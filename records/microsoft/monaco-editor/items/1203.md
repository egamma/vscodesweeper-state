# Issue #1203 — Add a setting like fixedOverflowWidgets for the context menu

[https://github.com/microsoft/monaco-editor/issues/1203](https://github.com/microsoft/monaco-editor/issues/1203)

## Summary

The requested context-menu integration now exists: fixedOverflowWidgets participates in context-menu placement, and the shadow host uses fixed positioning. The implementing upstream change is included in Monaco v0.57.0 and current main.

## Change summary

Allow the editor context menu to escape an overflow-hidden ancestor, like suggestion widgets configured with fixedOverflowWidgets.

## Best solution

Treat the requested capability as implemented and retain fixedOverflowWidgets: true with the default useShadowDOM: true. CSS zoom and transformed containing blocks are separate cases, not demonstrated by this report's plain overflow-hidden example.
