[https://github.com/microsoft/monaco-editor/issues/4932](https://github.com/microsoft/monaco-editor/issues/4932)

## Summary

The missing right-to-left diff action is tracked by an open VS Code editor-core feature request. Consolidate there, preserving this report's read-only-right/editable-left configuration.

## Change summary

Allow built-in diff arrows to copy changes from the read-only right pane into the editable left pane.

## Best solution

Implement right-to-left diff actions in the VS Code editor core under https://github.com/microsoft/vscode/issues/269082, including support when only the original pane is editable, then inherit the capability in Monaco.
