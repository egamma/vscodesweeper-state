[https://github.com/microsoft/monaco-editor/issues/4932](https://github.com/microsoft/monaco-editor/issues/4932)

## Summary

The requested right-to-left merge action is a narrower form of the reversed diff-editor workflow previously declined by maintainers in issue 368. That precedent covers the editable-side and directionality requirements here.

## Change summary

Add a diff-editor option that reverses merge arrows so changes can be copied from the read-only right side into the editable left side.
