# Issue #627 — Access to `showInputBox`

[https://github.com/microsoft/monaco-editor/issues/627](https://github.com/microsoft/monaco-editor/issues/627)

## Summary

A supported API for collecting quick text input from custom actions remains absent on current main. The accepted Backlog placement and existing feature-request/quick-pick labels remain appropriate.

## Change summary

Expose an input-box or quick-input API that custom editor actions can invoke to collect user input.

## Best solution

Expose a supported standalone quick-input API, backed by the vscode editor core, rather than requiring embedders to import internal services or manipulate command-palette DOM. This looks suitable for a community PR after the public API shape is agreed.
