# Issue #627 — Access to `showInputBox`

[https://github.com/microsoft/monaco-editor/issues/627](https://github.com/microsoft/monaco-editor/issues/627)

## Summary

Keep open: custom actions still lack a supported public input-box API, although an internal quick-input service exists. The request remains accepted in Backlog, and the related reports do not provide a valid duplicate canonical.

## Change summary

Expose a supported input-box API so custom editor actions can collect user-entered arguments.

## Best solution

Define a supported standalone input-box contract backed by the existing VS Code quick-input implementation, with the API work landing in microsoft/vscode and flowing into Monaco. Preserve this report's free-text input scope rather than treating private service access or command filtering as equivalent coverage.
