# Issue #4893 — [Bug] Getting wrong range data on paste event

[https://github.com/microsoft/monaco-editor/issues/4893](https://github.com/microsoft/monaco-editor/issues/4893)

## Summary

The range mismatch remains in the current VS Code editor source: line paste inserts at column 1, but onDidPaste reports the cursor positions before and after insertion. Keep the report open and route it to the clipboard/API areas; whole-line insertion itself is intentional.

## Change summary

onDidPaste reports a cursor-derived range that does not match the text inserted by copying and pasting an unselected line.

## Best solution

Correct paste-event range reporting in the microsoft/vscode editor core while preserving intentional whole-line paste behavior. The supplied example provides sufficient steps to verify the correction when Monaco adopts the upstream fix.
