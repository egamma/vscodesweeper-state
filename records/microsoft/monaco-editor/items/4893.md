# Issue #4893 — [Bug] Getting wrong range data on paste event

[https://github.com/microsoft/monaco-editor/issues/4893](https://github.com/microsoft/monaco-editor/issues/4893)

## Summary

Still present in the current editor core: whole-line paste relocates the insertion to the line start, but `onDidPaste.range` is constructed from the original cursor and final selection rather than the actual edit range. Route this to the clipboard/API owners.

## Change summary

Make `onDidPaste.range` report the actual inserted range when pasting a whole line copied from an empty selection.

## Best solution

Fix the paste-event range calculation in the VS Code editor core so line-mode paste reports the actual insertion range, then bring that fix into Monaco through the normal source update.
