# Issue #2885 — [Feature Request] Get notified when a language features are ready

[https://github.com/microsoft/monaco-editor/issues/2885](https://github.com/microsoft/monaco-editor/issues/2885)

## Summary

Verified duplicate: the open, broader readiness-event issue already covers notification when language providers are attached. This report adds a useful tokenization-testing scenario that should be preserved there.

## Change summary

Expose an awaitable hook indicating that a language's features, particularly tokenization, are ready.

## Best solution

Consolidate on https://github.com/microsoft/monaco-editor/issues/115 and expose a supported per-language/provider readiness API so callers of `editor.tokenize` do not need timing workarounds.
