# Issue #3914 — [Feature Request] Support word wrapping only selected ranges, or not wrapping selected ranges

[https://github.com/microsoft/monaco-editor/issues/3914](https://github.com/microsoft/monaco-editor/issues/3914)

## Summary

A real selective-wrapping capability remains missing, and the Backlog milestone plus maintainer interest support keeping it open. Because wrapping is inherited editor-core behavior, implementation should first be proposed in microsoft/vscode.

## Change summary

Allow embedders to enable or suppress visual word wrapping for selected ranges, such as Markdown tables.

## Best solution

Design a range- or decoration-based wrapping override in the VS Code editor core, then inherit it in Monaco through the normal source-generation pipeline. The API should preserve global wrapping as the default while allowing embedders to mark exceptional ranges.
