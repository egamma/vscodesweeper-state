# Issue #3914 — [Feature Request] Support word wrapping only selected ranges, or not wrapping selected ranges

[https://github.com/microsoft/monaco-editor/issues/3914](https://github.com/microsoft/monaco-editor/issues/3914)

## Summary

Keep open: the public wrapping options do not cover excluding Markdown tables or other selected ranges. A maintainer expressed interest and recommended a VS Code feature request; the remaining work belongs in the shared editor core.

## Change summary

Allow embedders to enable or disable soft wrapping for selected ranges without changing model text.

## Best solution

Design a range-aware wrapping contract in the VS Code editor core that preserves existing whole-editor wrapping defaults and permits table exceptions. Retain this accepted Backlog request until that capability is implemented or a verified upstream canonical owns its full scope.
