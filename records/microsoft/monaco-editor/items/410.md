# Issue #410 — Line numbers are not keyboard/screen reader accessible

[https://github.com/microsoft/monaco-editor/issues/410](https://github.com/microsoft/monaco-editor/issues/410)

## Summary

Keep open: accessible line-position reporting remains an unresolved design question, with maintainer interest and a recent request for optional announcements. Existing navigation workarounds do not establish that the requested behavior is implemented.

## Change summary

Provide a screen-reader-accessible way to learn the current line number, optionally during navigation or through an on-demand command.

## Best solution

Resolve the announcement contract in the VS Code editor core: make current-position information available without interrupting code speech, while preserving quiet navigation by default. Monaco should inherit that behavior; VS Code status-bar workarounds are not standalone Monaco capabilities.
