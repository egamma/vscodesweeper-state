# Issue #410 — Line numbers are not keyboard/screen reader accessible

[https://github.com/microsoft/monaco-editor/issues/410](https://github.com/microsoft/monaco-editor/issues/410)

## Summary

Keep this canonical accessibility request open. Current behavior is intentional but incomplete: maintainers acknowledge the need, existing workarounds are imperfect, and no shipped implementation provides optional line-number announcements.

## Change summary

Provide a non-disruptive, keyboard-accessible way for screen-reader users to hear the current line number.

## Best solution

Design the capability in the VS Code editor core, preferably as an opt-in announcement command or setting that does not interrupt line content. Preserve this issue as the Monaco-facing canonical while the editor-core accessibility approach remains under discussion.
