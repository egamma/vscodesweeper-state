# Issue #5185 — [Bug] Changing content of a hidden editor and showing it again leaves the editor in a broken state

[https://github.com/microsoft/monaco-editor/issues/5185](https://github.com/microsoft/monaco-editor/issues/5185)

## Summary

The v0.55.1 playgrounds provide strong historical evidence, but they do not establish whether the problem remains in current v0.56.0. The editor API requires `layout()` after its container is resized; the report calls only `render(true)`, which does not remeasure the container.

## Change summary

Updating an editor while it is hidden leaves mouse-based cursor placement broken after the editor becomes visible again.

## Best solution

Retest on v0.56.0 using `editor.layout()` after showing the editor. If the problem remains, the vscode editor core should invalidate the affected layout or font-measurement state when content changes while hidden.
