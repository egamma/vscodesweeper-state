# Issue #4800 — [Bug] symbols from JS extra libs can be renamed

[https://github.com/microsoft/monaco-editor/issues/4800](https://github.com/microsoft/monaco-editor/issues/4800)

## Summary

Still present in current source: rename treats extra-lib declarations as editable project files, but Monaco applies those edits only to editor models rather than the registered extra-lib content. Routing to the TypeScript area.

## Change summary

Renaming a JavaScript symbol declared by addExtraLib produces a partial, non-persistent rename instead of rejecting the operation.

## Best solution

Update the TypeScript RenameAdapter in src/languages/features/typescript/languageFeatures.ts to reject renames whose locations include registered extra libs, since their configured content cannot be persistently edited through a workspace edit.
