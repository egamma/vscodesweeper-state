# Issue #4252 — [Bug] Go to Definition context menu item displays an incorrect hotkey (it shows Ctrl+F12, but is actually F12)

[https://github.com/microsoft/monaco-editor/issues/4252](https://github.com/microsoft/monaco-editor/issues/4252)

## Summary

Still present in the current VS Code editor core: web builds register F12 and Ctrl/Cmd+F12 for Go to Definition, while the context menu selects the later, more-specific binding and displays Ctrl/Cmd+F12. Route this to keybindings and context-menu handling.

## Change summary

The Monaco context menu displays Ctrl/Cmd+F12 for Go to Definition instead of its primary F12 shortcut.

## Best solution

Fix the vscode editor-core registration or menu keybinding selection so standalone Monaco displays F12 as the primary Go to Definition shortcut while any web fallback remains available without conflicting with Go to Implementations.
