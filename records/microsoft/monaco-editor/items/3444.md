# Issue #3444 — Lua syntax colorization not working properly [Bug] 

[https://github.com/microsoft/monaco-editor/issues/3444](https://github.com/microsoft/monaco-editor/issues/3444)

## Summary

The Lua long-string highlighting gap remains on current main and is already correctly routed to languages-basic. The Monarch grammar handles long-bracket comments but not equivalent Lua string literals.

## Change summary

Lua long strings using [[...]] or matching equals delimiters are not colorized as strings.

## Best solution

Extend the Lua Monarch tokenizer in src/languages/definitions/lua/lua.ts with a long-string state that matches the opener's equals count at the closing delimiter, and add tokenization coverage in lua.test.ts. This remains suitable for a community contribution.
