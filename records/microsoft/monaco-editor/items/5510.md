## Summary

Built-in todo.txt highlighting remains a genuine language-support request; existing customization APIs do not provide the requested format support automatically. Route to languages-basic for a scope decision, separating highlighting from the optional task-management behaviors.

## Change summary

Add todo.txt highlighting and optionally task-aware sorting, filtering, completion dates, reordering, and strikethrough.

## Best solution

Consider an opt-in todo.txt grammar in src/languages/definitions, while treating task-aware editing commands as a separate scope decision rather than assuming a tokenizer supplies them. Embedders can already implement custom highlighting and decorations, but that does not fulfill the built-in support request.
