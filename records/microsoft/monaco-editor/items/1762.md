# Issue #1762 — Improve Python syntax highlighting

[https://github.com/microsoft/monaco-editor/issues/1762](https://github.com/microsoft/monaco-editor/issues/1762)

## Summary

The broad Python-highlighting request remains valid: later contributions added Python 3 keywords and f-strings, but the current Monarch grammar still tokenizes identifiers generically and does not provide VS Code-like contextual highlighting for import clauses.

## Change summary

Improve the bundled Python Monarch grammar so import statements and other Python constructs receive more accurate syntax highlighting.

## Best solution

Keep this as the umbrella for incremental Python Monarch grammar improvements, with focused rules and tokenization tests under src/languages/definitions/python/. This remains suitable for a community PR, while TextMate integration is an available alternative for embedders requiring exact VS Code grammar behavior.
