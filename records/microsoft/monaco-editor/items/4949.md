# Issue #4949 — [Bug] Undo / Redo does not account for decorations

[https://github.com/microsoft/monaco-editor/issues/4949](https://github.com/microsoft/monaco-editor/issues/4949)

## Summary

The requested decoration-aware undo behavior is an editor-core feature that maintainers have explicitly declined in two directly matching issues. The related request for public undo-stack hooks was also declined in the vscode tracker.

## Change summary

Include decoration changes in undo/redo history and expose APIs that allow embedders to inspect or synchronize with the undo stack.

## Best solution

Keep decorations outside the editor's undo history and have embedders track and reapply them when their application requires that behavior. Changing the shared undo service or exposing its internals would belong in the vscode editor core, where the corresponding hook request was declined.
