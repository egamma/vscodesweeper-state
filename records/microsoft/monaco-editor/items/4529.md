# Issue #4529 — A function should be added that can get the variables and variable types of a certain line of code[Feature Request] 

[https://github.com/microsoft/monaco-editor/issues/4529](https://github.com/microsoft/monaco-editor/issues/4529)

## Summary

This requests language-specific semantic and debugger functionality rather than an editor capability. Monaco exposes language-service integration points, but a generic API cannot determine variables and types across arbitrary languages.

## Change summary

Add an API that returns every variable and its type for a specified source line to support breakpoint evaluation.

## Best solution

Implement variable discovery through the embedding application's language service or LSP and obtain runtime values through its debugger backend. For TypeScript and JavaScript, the existing worker API can provide symbol-level quick information, but Monaco should not add a language-independent debugger API.

- **Proposed comment:**

  > Thanks for the request. Determining all variables and their types is language-specific semantic analysis, while resolving their values at a breakpoint belongs to the embedding application's debugger backend. Monaco exposes language-service integration points rather than a generic debugger API; for TypeScript and JavaScript, `monaco.languages.typescript.getTypeScriptWorker()` and `getQuickInfoAtPosition` can provide type information for individual symbols. A line-wide implementation should therefore live in the application's language service or LSP/debugger integration, so this is outside Monaco's core scope.
