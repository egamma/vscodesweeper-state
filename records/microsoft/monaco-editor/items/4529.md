# Issue #4529 — A function should be added that can get the variables and variable types of a certain line of code[Feature Request] 

[https://github.com/microsoft/monaco-editor/issues/4529](https://github.com/microsoft/monaco-editor/issues/4529)

## Summary

Keep open: existing language-worker APIs provide individual symbol information, but do not establish coverage of the requested line-level variable-and-type enumeration. The supported languages and meaning of variables at a line need clarification before a public API decision.

## Change summary

Add an API returning variables and their types at a specified source line for integration with backend breakpoint handling.

## Best solution

Define whether the result includes variables referenced on the line or all variables visible in scope, and which languages are supported. Keep static analysis in language services and runtime values and breakpoint execution in the embedding application's backend.
