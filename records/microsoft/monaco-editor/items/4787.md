# Issue #4787 — [Feature Request] Print monaco editor whole content

[https://github.com/microsoft/monaco-editor/issues/4787](https://github.com/microsoft/monaco-editor/issues/4787)

## Summary

Keep open: the existing APIs support building a separate printable representation, but do not provide the requested full-document window.print() behavior. The older VS Code printing request is related, not a verified duplicate of this browser-specific symptom.

## Change summary

Support printing the entire embedded editor document rather than only its visible portion, preferably through library-provided print support.

## Best solution

Decide whether full-document browser printing should be supported by the shared editor renderer or documented as an embedder-managed printable view. Renderer changes belong in microsoft/vscode; the existing text and colorization APIs provide a workaround, not automatic print support.
