# Issue #2940 — [Bug] Disable highlighting of unicode characters option doesn't work.

[https://github.com/microsoft/monaco-editor/issues/2940](https://github.com/microsoft/monaco-editor/issues/2940)

## Summary

The no-op action remains in the current editor core: standalone Monaco still exposes “Adjust settings” and updates the standalone configuration service rather than the editor's local option. The existing `unicodeHighlight.ambiguousCharacters` API is a workaround, not a fix for the misleading hover action.

## Change summary

Remove or adapt the standalone Unicode-highlight hover action whose setting change does not affect the editor.

## Best solution

Fix this in the vscode editor core by hiding settings-backed Unicode-highlight actions in standalone editors, as the maintainer proposed, or by making them update the active editor option reliably. Preserve `unicodeHighlight.ambiguousCharacters` as the embedder-facing API.
