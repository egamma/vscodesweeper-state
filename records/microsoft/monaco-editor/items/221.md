# Issue #221 — Auto complete for HTML -- add the close tag

[https://github.com/microsoft/monaco-editor/issues/221](https://github.com/microsoft/monaco-editor/issues/221)

## Summary

The requested VS Code-style HTML closing-tag insertion remains absent from Monaco's current HTML integration. The issue is correctly classified and routed, and remains suitable for a community contribution.

## Change summary

Automatically insert the matching HTML closing tag after the user finishes typing an opening tag.

## Best solution

Expose the HTML language service's `doTagComplete` operation through the worker and invoke it after typing `>`, following VS Code's behavior. This remains `open for PR` material as confirmed by the maintainer.
