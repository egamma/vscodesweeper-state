# Issue #338 — Changing theme in one editor should change all editors

[https://github.com/microsoft/monaco-editor/issues/338](https://github.com/microsoft/monaco-editor/issues/338)

## Summary

Keep this as the canonical feature request for independent per-editor themes. Current vscode standalone-editor source still applies one global theme and token color map, while newer reports duplicate this same architectural limitation.

## Change summary

Allow multiple editors on one page to use independent themes without theme changes leaking across instances.

## Best solution

Implement editor-scoped theme state, CSS, and token color maps in the vscode standalone editor core, then inherit that support in Monaco. Keep https://github.com/microsoft/monaco-editor/issues/338 as the canonical tracker and consolidate narrower reports such as https://github.com/microsoft/monaco-editor/issues/4425 into it.
