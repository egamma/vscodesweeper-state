# Issue #338 — Changing theme in one editor should change all editors

[https://github.com/microsoft/monaco-editor/issues/338](https://github.com/microsoft/monaco-editor/issues/338)

## Summary

Keep open: independently themed editors remain unsupported, and the CSS workarounds do not cover token highlighting. This accepted Backlog request remains the established reference; the related reports do not establish a replacement canonical.

## Change summary

Allow multiple editors on one page to retain independent themes without one editor's theme selection changing the others.

## Best solution

Retain this issue as the reference for independent editor theming, with any architectural change evaluated in the VS Code standalone editor and tokenization services. Distinguish that capability from the historical partial-update defect and wrapper-specific theme flashes.

## Evidence

- **Existing capability and remaining gap:** CHANGELOG.md records that v0.9.0 replaced theme changes through editor.updateOptions() with monaco.editor.setTheme(). website/src/website/data/playground-samples/customizing-the-appearence/exposed-colors/sample.js uses defineTheme() and setTheme(); these configure a shared theme, not independent editor themes.
- **Current upstream architecture:** Read https://github.com/microsoft/vscode/blob/main/src/vs/editor/standalone/browser/standaloneThemeService.ts: StandaloneThemeService holds one _theme; _updateThemeOrColorMap() generates shared editor CSS and token colors, calls TokenizationRegistry.setColorMap(), and updates every registered stylesheet. https://github.com/microsoft/vscode/blob/main/src/vs/editor/standalone/browser/standaloneCodeEditor.ts passes each editor's options.theme to that theme service.
- **Maintainer position:** https://github.com/microsoft/monaco-editor/issues/338#issuecomment-417653270 states that independent themes were not planned because resolved token colors are stored in a text buffer that multiple editors can share. This explains the feature boundary but does not establish implementation or supersession.
