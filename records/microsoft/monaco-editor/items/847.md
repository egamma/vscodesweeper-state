# Issue #847 — How could I make an context menu disabled not hide

[https://github.com/microsoft/monaco-editor/issues/847](https://github.com/microsoft/monaco-editor/issues/847)

## Summary

Keep open: custom actions still use their precondition to control context-menu visibility, without a public option to retain disabled entries. The existing contextmenu label is appropriate, and no matching canonical was found.

## Change summary

Allow custom context-menu actions such as Redo to remain visible but disabled when their precondition is false.

## Best solution

Support independent visibility and enablement for standalone editor actions in the VS Code-derived API, preserving existing hiding behavior by default. The implementation belongs in microsoft/vscode's standalone editor sources and would reach Monaco through a subsequent release.
