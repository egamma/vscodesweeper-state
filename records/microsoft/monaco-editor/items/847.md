# Issue #847 — How could I make an context menu disabled not hide

[https://github.com/microsoft/monaco-editor/issues/847](https://github.com/microsoft/monaco-editor/issues/847)

## Summary

The requested capability remains absent: standalone actions expose one precondition that controls both command availability and context-menu visibility. This is a valid editor-core API feature request already routed to the context-menu area.

## Change summary

Allow context-menu actions to remain visible but disabled when their execution condition is false.

## Best solution

Add separate visibility and enablement conditions to the standalone IActionDescriptor API in the vscode editor core, then let the change flow into Monaco. The menu item should remain visible while its action reflects the enablement expression.
