# Issue #4603 — [Feature Request] Make close icon for the details suggestions view button

[https://github.com/microsoft/monaco-editor/issues/4603](https://github.com/microsoft/monaco-editor/issues/4603)

## Summary

The current editor core gives the close icon button semantics and an accessible name, but it remains outside the tab order and has only mouse activation handlers. The remaining keyboard-accessibility request is valid and belongs in the VS Code suggest widget implementation.

## Change summary

Make the suggestion-details close control directly operable by keyboard users.

## Best solution

Decide in the VS Code editor core whether the close control should enter the keyboard focus order or gain an equivalent activation path compatible with editor key handling; Monaco will inherit that implementation in a subsequent release.

- **Fit:** aligned
- **Reason:** Improving keyboard access to an inherited editor control supports Monaco's durable accessibility and VS Code editor-parity themes.
- **Evidence:** The vision identifies accessibility as a durable theme and states that Monaco is generated from the VS Code editor core.
