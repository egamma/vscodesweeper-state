# Issue #4603 — [Feature Request] Make close icon for the details suggestions view button

[https://github.com/microsoft/monaco-editor/issues/4603](https://github.com/microsoft/monaco-editor/issues/4603)

## Summary

The accessibility request remains only partially covered: the close icon has button semantics, but is excluded from sequential keyboard focus and lacks Enter/Space activation. Route to suggestion and accessibility owners; the implementation belongs in the VS Code editor core.

## Change summary

Make the suggestion-details close icon a keyboard-operable, accessible button.

## Best solution

Provide accessible keyboard activation of the close control in microsoft/vscode's SuggestDetailsWidget while preserving completion navigation and focus behavior, then inherit the change in Monaco. Existing details-toggle commands do not fully cover accessibility of the control itself.
