# Issue #2230 — Option for receiving cursor position when existing hover range is active

[https://github.com/microsoft/monaco-editor/issues/2230](https://github.com/microsoft/monaco-editor/issues/2230)

## Summary

Implemented in the VS Code editor core and shipped in Monaco v0.35.0: moving to a new hover anchor now recomputes provider results while retaining compatible visible hover content.

## Change summary

Allow hover providers to receive updated positions inside an existing hover range so nested hovers can replace the outer hover.

## Best solution

Keep the current editor-core behavior introduced by https://github.com/microsoft/vscode/commit/a02a660b1a286ee2f997a3e25e4b7c5551e3b99d; it preserves the existing hover while starting a provider computation for each changed anchor.
