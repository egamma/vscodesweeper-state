# Issue #2230 — Option for receiving cursor position when existing hover range is active

[https://github.com/microsoft/monaco-editor/issues/2230](https://github.com/microsoft/monaco-editor/issues/2230)

## Summary

The request remains distinct from the intended hover-range caching behavior: the reporter wants position-sensitive updates while preserving explicit range highlighting. Route to editor-hover for a decision on an opt-in capability in the VS Code editor core.

## Change summary

Allow hover providers to receive position updates inside an already-active hover range without losing that range's highlighting.

## Best solution

Consider an opt-in editor-core contract that decouples hover range highlighting from result reuse while retaining the current default optimization. Any implementation belongs in microsoft/vscode and would reach Monaco through its generated editor sources.
