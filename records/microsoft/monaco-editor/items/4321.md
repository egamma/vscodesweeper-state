# Issue #4321 — How to use it with highlight.js

[https://github.com/microsoft/monaco-editor/issues/4321](https://github.com/microsoft/monaco-editor/issues/4321)

## Summary

This is an integration-support question rather than an actionable Monaco defect. highlight.js produces HTML markup, while Monaco expects source text and performs highlighting through its tokenizer.

## Change summary

Determine how to display Modelica code highlighted with highlight.js inside Monaco Editor.

## Best solution

Pass the unmodified Modelica source as the editor value and use the registered Monarch tokens provider for syntax highlighting. Further integration questions belong on StackOverflow's monaco-editor tag.
