# Issue #4321 — How to use it with highlight.js

[https://github.com/microsoft/monaco-editor/issues/4321](https://github.com/microsoft/monaco-editor/issues/4321)

## Summary

This is an integration question: highlight.js returns highlighted HTML, whereas Monaco expects source text and applies highlighting through token providers. The documented custom-language pattern addresses the usage mismatch without an editor change.

## Change summary

The reporter wants highlight.js-generated Modelica highlighting to appear inside Monaco.

## Best solution

Pass the original Modelica source as the editor value and use the registered Monarch tokenizer with matching theme rules, rather than passing highlight.js HTML. Close as a support question.
