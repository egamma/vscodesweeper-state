# Issue #4328 — [Bug] Unable to access redirected JSON Schema URL

[https://github.com/microsoft/monaco-editor/issues/4328](https://github.com/microsoft/monaco-editor/issues/4328)

## Summary

Keep open as an upstream schema-hosting problem: the WordPress redirect response lacks cross-origin permission, while its GitHub destination allows it. Current source delegates loading to browser fetch; no Monaco redirect-handling defect or verified duplicate was established.

## Change summary

Loading the WordPress theme JSON schema through its redirecting URL fails in browser editors, although the destination URL works.

## Best solution

The schema host should make its redirect response CORS-accessible so browser editors can load the advertised URL. Until then, use the direct destination URL or supply schema content through JSON diagnostics options; no Monaco redirect change is justified by the evidence.
