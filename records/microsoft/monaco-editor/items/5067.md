# Issue #5067 — Ship two esm variants

[https://github.com/microsoft/monaco-editor/issues/5067](https://github.com/microsoft/monaco-editor/issues/5067)

## Summary

This remains the team-authored canonical proposal for reconciling bundler-optimized and direct-browser ESM distributions. Current main still exposes a single ESM family, and no open implementation PR was found.

## Change summary

Ship separate ESM variants for bundlers and direct browser loading, with different CSS-import and dependency-bundling behavior.

## Best solution

Resolve the packaging design under this issue, then implement distinct supported entry points in the ESM build and package exports: a tree-shakeable bundler variant with external dependencies and a browser-ready self-contained variant without bundler-only CSS imports.
