# Issue #4165 — [Bug] Incorrect syntax highlighting of Perl regex string

[https://github.com/microsoft/monaco-editor/issues/4165](https://github.com/microsoft/monaco-editor/issues/4165)

## Summary

The Perl tokenizer still closes a brace-delimited regular expression at the quantifier's `}`, but an open PR directly fixes this issue. Keep it open until that implementation candidate is reviewed and merged.

## Change summary

Perl regex quantifiers such as `{1,10}` prematurely terminate brace-delimited `qr{...}` expressions and produce incorrect highlighting.

## Best solution

Review and land https://github.com/microsoft/monaco-editor/pull/5351, which updates the Perl Monarch grammar and adds regression coverage for `qr{\\W{1,10}}`.
