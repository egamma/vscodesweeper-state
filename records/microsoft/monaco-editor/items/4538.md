[https://github.com/microsoft/monaco-editor/issues/4538](https://github.com/microsoft/monaco-editor/issues/4538)

## Summary

Optional first-party TextMate grammar support remains a product decision: the current README recommends an external integration rather than documenting built-in support. Route this request to tokenization; neither the closed historical discussion nor the related repository-adoption request establishes a duplicate.

## Change summary

Reconsider optional built-in tmLanguage support now that WebAssembly is widely available.

## Best solution

The tokenization maintainers should decide whether Monaco should offer optional first-party TextMate integration while preserving lean default bundles. Until then, retain the README's external integration guidance without treating it as fulfillment of the native-support request.
