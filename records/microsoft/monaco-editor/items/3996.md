# Issue #3996 — [Feature Request] Support for getting colorization ranges

[https://github.com/microsoft/monaco-editor/issues/3996](https://github.com/microsoft/monaco-editor/issues/3996)

## Summary

This remains a valid feature request: current APIs expose token metadata or rendered HTML, but not resolved CSS properties mapped to source ranges. The existing feature-request and tokenization labels already route it correctly.

## Change summary

Expose colorization ranges and their resolved CSS properties for rendering through APIs such as CSS Custom Highlight.

## Best solution

Add a lower-level colorization API in the vscode standalone editor core that returns ranges with theme-resolved styles, then expose it through Monaco. The maintainer has explicitly marked this as suitable for a community PR.
