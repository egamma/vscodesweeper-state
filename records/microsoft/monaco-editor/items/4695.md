# Issue #4695 — [Bug] Guidelines not rendering in correct positions

[https://github.com/microsoft/monaco-editor/issues/4695](https://github.com/microsoft/monaco-editor/issues/4695)

## Summary

The defect remains traceable in current editor-core source: character widths are measured from spans that can override inherited font settings through global CSS, misplacing indentation guides. Route to font rendering and indentation guides; the fix belongs in the VS Code editor core and will flow into Monaco.

## Change summary

Global universal font rules override the measurement spans' inherited editor font, causing indentation guides to render at incorrect horizontal positions.

## Best solution

Update `src/vs/editor/browser/config/charWidthReader.ts` in microsoft/vscode so measurement spans explicitly use the configured font or inherit it despite global selectors, then bring that editor-core fix into Monaco through a subsequent release.
