# Issue #4584 — [Bug] MultiDiff not work

[https://github.com/microsoft/monaco-editor/issues/4584](https://github.com/microsoft/monaco-editor/issues/4584)

## Summary

The multi-file diff API remains unusable in the current package: its factory returns a widget whose public model methods are removed from the emitted JavaScript. Route this accepted On Deck bug to the diff-editor area.

## Change summary

Preserve and expose the APIs needed to create and assign a view model to a standalone multi-file diff editor.

## Best solution

Update the Monaco generation/export pipeline so `createMultiFileDiffEditor` returns a typed public interface and the package retains `createViewModel` and `setViewModel`. The resulting API should be covered by a playground sample that constructs a multi-file diff.
