# Issue #4802 — [Bug] Infinite recursion in TS worker

[https://github.com/microsoft/monaco-editor/issues/4802](https://github.com/microsoft/monaco-editor/issues/4802)

## Summary

The recursion remains traceable in Monaco main's bundled TypeScript 5.9.3 service, but the faulty cycle is in the upstream TypeScript checker. Keep this open as an upstream dependency issue until TypeScript fixes it and Monaco imports that version.

## Change summary

The JavaScript diagnostics worker overflows its call stack when a for-of variable shadows the iterable expression.

## Best solution

Fix the recursive for-of symbol lookup in microsoft/TypeScript's checker and then update Monaco's bundled TypeScript service to the corrected release.

  > Thanks for the report and the minimal playground example. This is still traceable in the TypeScript 5.9.3 service bundled on Monaco main: the for-of handling in `getExplicitTypeOfSymbol` asks `getTypeOfDottedName` for the same-name iterable, which resolves the same symbol and recurses. The underlying checker code is owned by microsoft/TypeScript (https://github.com/microsoft/TypeScript/blob/main/src/compiler/checker.ts), so the fix needs to land there and then flow into Monaco through a TypeScript dependency update. This issue should remain open to track that upstream fix.
