# Issue #3441 — [Feature Request] Positive lookbehind not working

[https://github.com/microsoft/monaco-editor/issues/3441](https://github.com/microsoft/monaco-editor/issues/3441)

## Summary

A real Monarch capability gap remains: tokenizer rules only receive the unconsumed suffix of the line, so positive lookbehind cannot inspect previously consumed text. This issue is the best current canonical and is already routed to tokenization.

## Change summary

Allow Monarch tokenizer regular expressions to use positive lookbehind against text preceding the current token position.

## Best solution

Implement support in the VS Code editor core's Monarch lexer so a rule remains anchored at the current tokenizer position while its regular expression can inspect the original line prefix, with coverage for ordinary tokenization and embedded-language transitions. This looks suitable for a community PR in microsoft/vscode.
