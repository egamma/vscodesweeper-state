# Issue #3441 — [Feature Request] Positive lookbehind not working

[https://github.com/microsoft/monaco-editor/issues/3441](https://github.com/microsoft/monaco-editor/issues/3441)

## Summary

Positive lookbehind still cannot inspect previously consumed input in Monarch's current matching path. Keep this request open: existing grouping techniques do not provide general lookbehind support, and no verified open canonical owns the same request.

## Change summary

Support positive lookbehind in Monarch tokenizer rules so matches can depend on preceding input without consuming it.

## Best solution

Evaluate lookbehind support in the VS Code-owned Monarch compiler and lexer while preserving existing tokenizer semantics. Any implementation belongs in microsoft/vscode and would reach Monaco through a subsequent editor-core release cut.
