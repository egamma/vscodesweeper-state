# Issue #4022 — [Bug] editor.action.selectToBracket - selectBrackets argument is not considered

[https://github.com/microsoft/monaco-editor/issues/4022](https://github.com/microsoft/monaco-editor/issues/4022)

## Summary

The sample passes a JSON string where the action expects an object; the cited smoke helper serializes arguments into executable JavaScript, not into the trigger payload. Keep open because the existing maintainer-applied bug label bars a question/as-designed close without a later maintainer decision.

## Change summary

Exclude surrounding brackets when invoking editor.action.selectToBracket with selectBrackets set to false.

## Best solution

Use myEditor.trigger(null, 'editor.action.selectToBracket', { selectBrackets: false }); the existing action supports the requested selection. A maintainer should resolve the existing bug classification after reviewing this argument-handling explanation; no editor change is established.

- **Proposed comment:**

  > Thanks for the report. The third argument to trigger should be the object itself: `myEditor.trigger(null, 'editor.action.selectToBracket', { selectBrackets: false });`. With `JSON.stringify(args)`, the action receives a string, so it cannot read the selectBrackets property and uses the default of including brackets. The smoke-test helper you linked uses JSON.stringify to insert an object literal into the JavaScript evaluated by the browser; it does not pass a JSON string to trigger.
