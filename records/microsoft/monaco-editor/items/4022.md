# Issue #4022 — [Bug] editor.action.selectToBracket - selectBrackets argument is not considered

[https://github.com/microsoft/monaco-editor/issues/4022](https://github.com/microsoft/monaco-editor/issues/4022)

## Summary

The command behaves as designed; the example passes a JSON string instead of the argument object, so `selectBrackets` cannot be read and defaults to true.

## Change summary

Invoke Select to Bracket without including the surrounding brackets.

## Best solution

Pass the object directly as the trigger payload: `myEditor.trigger(null, actionId, { selectBrackets: false })`. No editor change is needed.
