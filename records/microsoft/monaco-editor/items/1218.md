## Summary

The requested public notification is implemented: ICodeEditor.onDidChangeHiddenAreas fires when folding or unfolding changes hidden lines and shipped in Monaco v0.30.0.

## Change summary

Expose a typed public event for folding changes so embedders can resize the editor without private contribution APIs or mouse-event heuristics.

## Best solution

Close as completed and use editor.onDidChangeHiddenAreas(() => ...) for the resizing callback; exposing private folding implementation types is unnecessary.
