# Issue #1218 — FR: Code folding changed event 

[https://github.com/microsoft/monaco-editor/issues/1218](https://github.com/microsoft/monaco-editor/issues/1218)

## Summary

Implemented and shipped: `ICodeEditor.onDidChangeHiddenAreas` now fires when folding or unfolding changes hidden regions.

## Change summary

Expose a public editor event that notifies embedders when code folding changes visible lines.

## Best solution

Use `editor.onDidChangeHiddenAreas(...)` to update layout when folding changes visible content; the API has been available since Monaco v0.30.0.
