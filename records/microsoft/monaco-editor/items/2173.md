# Issue #2173 — Allow HTML in documentation of CompletionItem

[https://github.com/microsoft/monaco-editor/issues/2173](https://github.com/microsoft/monaco-editor/issues/2173)

## Summary

Partially implemented: custom completion providers can enable sanitized HTML through `IMarkdownString.supportHtml`, but TypeScript completion documentation generated from `addExtraLib` still cannot opt into it. Keep the remaining request open and route it to the TypeScript worker.

## Change summary

Allow sanitized HTML in custom completion documentation and documentation extracted from TypeScript extra libraries.

## Best solution

Add an explicit TypeScript language-service option that makes completion documentation generated from extra libraries set `supportHtml: true`, while retaining the existing sanitizer and secure default. Generic completion providers should continue using the existing `IMarkdownString.supportHtml` property.
