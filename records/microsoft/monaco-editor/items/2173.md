# Issue #2173 — Allow HTML in documentation of CompletionItem

[https://github.com/microsoft/monaco-editor/issues/2173](https://github.com/microsoft/monaco-editor/issues/2173)

## Summary

Custom completion documentation already supports sanitized HTML through IMarkdownString.supportHtml, but the bundled TypeScript completion adapter does not enable it for documentation from addExtraLib. Keep this request open for that remaining capability; neither unrestricted HTML nor the full request is covered by the existing API.

## Change summary

Allow HTML formatting in completion documentation, including TypeScript documentation supplied through addExtraLib.

## Best solution

Document supportHtml for custom completion providers and decide whether TypeScript declaration documentation should support the same sanitized formatting through an explicit opt-in. Preserve the editor's sanitization boundary rather than adopting the thread's private-widget DOM workaround.
