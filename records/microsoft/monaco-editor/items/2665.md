# Issue #2665 — Language set as HTML not formating correctly when contains CSS/JS

[https://github.com/microsoft/monaco-editor/issues/2665](https://github.com/microsoft/monaco-editor/issues/2665)

## Summary

Current Monaco already supports formatting and syntax highlighting for CSS and JavaScript embedded in HTML. Custom ESM bundles must register the corresponding language definitions; the full `monaco-editor` entry point registers them automatically.

## Change summary

Format and syntax-highlight CSS and JavaScript inside HTML `<style>` and `<script>` elements.

## Best solution

Keep the existing embedded-language implementation and use the supported language registration entry points when building a custom bundle; no additional Monaco capability is required.

## Vision fit

- **Fit:** aligned
- **Reason:** Embedded HTML, CSS, and JavaScript support is part of Monaco's durable bundled-language experience.
- **Evidence:** The vision identifies “the bundled language experiences” as a durable theme and favors supported, tree-shakeable language entry points.

- **Proposed comment:**

  > Thanks for the report and follow-up context. Current Monaco supports both parts of this scenario: the HTML tokenizer embeds `text/css` and `text/javascript` inside `<style>` and `<script>`, and the HTML language service invokes CSS and JavaScript beautifiers for those elements. The full `monaco-editor` entry point loads all languages; custom ESM bundles need to register the HTML, CSS, and JavaScript definitions plus the HTML language feature. With those supported registrations in place, no additional feature is needed here.

## Evidence

- **embedded highlighting:** src/languages/definitions/html/html.ts routes `<script>` content to `text/javascript` and `<style>` content to `text/css` through Monarch's `nextEmbedded`; src/languages/definitions/css/register.ts maps `text/css` to the CSS tokenizer.
- **embedded formatting:** src/languages/features/html/htmlWorker.ts delegates formatting to vscode-html-languageservice 5.2.0. Its HTML beautifier selects and invokes dedicated CSS and JavaScript beautifiers for `<style>` and `<script>` content: https://github.com/microsoft/vscode-html-languageservice/blob/v5.2.0/src/beautify/beautify-html.js
- **supported registration:** CHANGELOG.md documents that `monaco-editor` loads all languages, while custom bundles can use `monaco-editor/languages/definitions/register.all` or individual language registration entry points.
