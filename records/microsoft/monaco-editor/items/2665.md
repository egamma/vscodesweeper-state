# Issue #2665 — Language set as HTML not formating correctly when contains CSS/JS

[https://github.com/microsoft/monaco-editor/issues/2665](https://github.com/microsoft/monaco-editor/issues/2665)

## Summary

Keep open: embedded JavaScript formatting remains unsupported in the bundled HTML formatter. Current source has embedded CSS formatting and CSS/JavaScript tokenization support, but those capabilities do not satisfy the full request.

## Change summary

Format CSS and JavaScript inside HTML style and script elements, with appropriate syntax highlighting.

## Best solution

Provide embedded JavaScript formatting through Monaco's HTML language integration while preserving HTML and CSS formatting. Retest the supplied CSS example and highlighting separately, since current source already supports those capabilities.
