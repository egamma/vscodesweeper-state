## Change summary

Pressing Enter after a function header with a trailing comment fails to indent the function body.

## Best solution

Preserve automatic body indentation when a header ends with a comment, without treating brackets inside comments as code. Establish whether Monaco's bundled language configurations need adjustment or the shared VS Code Enter handling needs a fix; the reported difference from VS Code makes that boundary important.
