## Summary

The recent playground reproduction demonstrates a real auto-indentation gap, and current language configurations remain susceptible to trailing comments. The issue is already correctly routed to editor-indent-detection and should remain open.

## Change summary

Trailing comments on block-opening lines prevent automatic indentation across several bundled languages.

## Best solution

Update the bundled language configurations and, where necessary, the vscode editor-core indentation handling so trailing comments do not suppress indentation after a valid block opener. Cover the reported TypeScript, Python, C-family, Java, Go, PHP, and Rust cases consistently.
