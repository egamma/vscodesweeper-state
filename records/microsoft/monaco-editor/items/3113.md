# Issue #3113 — [Bug] Wrong syntax highlighting for reStructuredText

[https://github.com/microsoft/monaco-editor/issues/3113](https://github.com/microsoft/monaco-editor/issues/3113)

## Summary

The standalone reStructuredText grammar still rejects directives without trailing whitespace and some valid hyphenated names, falling through to comment highlighting. Keep this issue as the canonical report; the maintainer explicitly welcomed a Monaco tokenizer fix.

## Change summary

Recognize valid reStructuredText directives consistently, including hyphenated names, optional arguments, and valid indentation.

## Best solution

Correct directive recognition in Monaco's own reStructuredText Monarch grammar and cover the supplied examples with tokenization tests. Preserve ordinary comments, reference syntax, and literal-block behavior.

## Evidence

- **Current source confirms the failure:** src/languages/definitions/restructuredtext/restructuredtext.ts: explicitMarkupBlocks uses /^(\.\.\s)(@simpleRefName)(::\s)(.*)$/, requiring whitespace after :: and anchoring the marker at column zero.
