# Issue #1289 — All editors on a page share the same theme

[https://github.com/microsoft/monaco-editor/issues/1289](https://github.com/microsoft/monaco-editor/issues/1289)

## Summary

Verified duplicate: the older open issue tracks the same request for independent themes across multiple editors and documents the shared token-color architecture causing the limitation.

## Change summary

Allow multiple Monaco editor instances on one page to use independent themes and token styling.

## Best solution

Consolidate the request on https://github.com/microsoft/monaco-editor/issues/338. Supporting per-editor themes requires an editor-core architectural change because token colors are currently shared through the text buffer.
