# Issue #4897 — [Bug] Avoiding bubbling up "copy" events happening within the code section

[https://github.com/microsoft/monaco-editor/issues/4897](https://github.com/microsoft/monaco-editor/issues/4897)

## Summary

The request changes clipboard-event propagation rather than demonstrating broken copying. Route it to editor-clipboard: current upstream handlers still allow ordinary copy events to bubble, and no verified canonical owns this requested change.

## Change summary

Prevent copy events handled inside the editor's code surface from bubbling to enclosing applications and being handled again.

## Best solution

Establish the propagation contract in the VS Code editor core, distinguishing editor-content copying from auxiliary inputs and preserving legitimate host observation. If suppression is accepted, implement it upstream so Monaco inherits the behavior rather than adding a Monaco-only fork.
