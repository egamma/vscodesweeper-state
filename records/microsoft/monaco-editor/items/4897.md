# Issue #4897 — [Bug] Avoiding bubbling up "copy" events happening within the code section

[https://github.com/microsoft/monaco-editor/issues/4897](https://github.com/microsoft/monaco-editor/issues/4897)

## Summary

The event propagation is current editor-core behavior, and suppressing it would be a behavior change rather than a fix for a broken Monaco contract. The request remains valid for evaluation by the clipboard area.

## Change summary

Prevent copy events handled by the editor from bubbling to the embedding page.

## Best solution

Decide in the vscode editor core whether copy events should remain observable to embedders; any propagation change belongs in src/vs/editor/browser/controller/editContext and would flow into Monaco. Until then, hosts can scope their copy listener by event target or stop propagation at the editor container.
