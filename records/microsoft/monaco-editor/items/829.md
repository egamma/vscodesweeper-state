# Issue #829 — Lisp base dialect syntax highlighter

[https://github.com/microsoft/monaco-editor/issues/829](https://github.com/microsoft/monaco-editor/issues/829)

## Summary

A dedicated Lisp/Common Lisp grammar remains absent. Monaco ships Scheme and Clojure highlighters, but neither registers a generic Lisp language ID or Common Lisp file extensions.

## Change summary

Add syntax highlighting for a base Lisp dialect such as Common Lisp.

## Best solution

Clarify the target Lisp dialect, then add a tested Monarch grammar and language registration under src/languages/definitions; this remains suitable for a community contribution.
