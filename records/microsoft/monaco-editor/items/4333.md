# Issue #4333 — [Bug] ResizeObserver loop completed with undelivered notifications.

[https://github.com/microsoft/monaco-editor/issues/4333](https://github.com/microsoft/monaco-editor/issues/4333)

## Summary

The automatic-layout resize loop remains actionable in the current VS Code editor core: the attempted fix still performs the first layout synchronously inside the ResizeObserver callback, and multiple reporters confirmed errors after that fix shipped. Route this issue to editor-core as the only open Monaco report owning the remaining work.

## Change summary

Shrinking an automatically laid-out editor can repeatedly emit “ResizeObserver loop completed with undelivered notifications” errors.

## Best solution

Update the VS Code editor core's ElementSizeObserver so layout cannot synchronously trigger another observation during the ResizeObserver delivery cycle, then flow that fix into Monaco. Verify it with the existing playground scenario plus WebView2 and webpack embeddings.
