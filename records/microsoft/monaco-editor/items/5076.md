# Issue #5076 — [Bug] LanguageConfiguration autoClosingPairs' notIn field doesn't work for variable/variable.source classes

[https://github.com/microsoft/monaco-editor/issues/5076](https://github.com/microsoft/monaco-editor/issues/5076)

## Summary

This is a feature request for context-dependent auto-closing, not a defect: `notIn` currently supports only standard string, comment, and regex token categories. The open VS Code issue https://github.com/microsoft/vscode/issues/171030 already owns the broader request.

## Change summary

Allow `autoClosingPairs.notIn` to suppress closing pairs for arbitrary Monarch token classes such as `variable` and `variable.source`.

## Best solution

Consolidate the request on https://github.com/microsoft/vscode/issues/171030 and implement any generalized token-context support in the VS Code editor core, from which Monaco is generated.
