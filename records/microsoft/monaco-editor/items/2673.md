# Issue #2673 — Manage multiple locales

[https://github.com/microsoft/monaco-editor/issues/2673](https://github.com/microsoft/monaco-editor/issues/2673)

## Summary

A real capability gap remains: Monaco supports selecting a locale before loading, but exposes no supported way to change it at runtime. This older, broader report should remain the canonical request.

## Change summary

Allow embedders to change the editor UI locale dynamically after initialization.

## Best solution

Design a supported runtime locale-switching API across the vscode-derived localization service and Monaco's loading integration, updating existing editor UI without losing model state. Consolidate the narrower https://github.com/microsoft/monaco-editor/issues/4669 into this issue.

## Evidence
