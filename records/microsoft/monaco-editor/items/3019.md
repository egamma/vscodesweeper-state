# Issue #3019 — [Bug] `json.worker.js` doesn't export anything, so I can't create a custom JSON language worker

[https://github.com/microsoft/monaco-editor/issues/3019](https://github.com/microsoft/monaco-editor/issues/3019)

## Summary

The requested JSON worker export remains absent on current main. The issue is already correctly classified and routed to the JSON area.

## Change summary

Expose the JSON worker factory so embedders can construct custom JSON language workers such as SharedWorkers.

## Best solution

Export `JSONWorker`, `create`, and the relevant initialization API from `src/languages/features/json/json.worker.ts`, matching the TypeScript worker pattern, and include them in the generated ESM entry point.
