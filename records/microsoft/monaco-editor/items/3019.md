# Issue #3019 — [Bug] `json.worker.js` doesn't export anything, so I can't create a custom JSON language worker

[https://github.com/microsoft/monaco-editor/issues/3019](https://github.com/microsoft/monaco-editor/issues/3019)

## Summary

The requested reusable JSON worker entry point remains missing from the current source. Keep this feature request open: the existing worker factory is internal to a separate module, and no verified canonical owns this export requirement.

## Change summary

Expose a reusable JSON worker factory so embedders can construct custom workers, including SharedWorker adapters.

## Best solution

Decide on a supported reusable JSON worker entry point in Monaco's language-worker packaging, separate from automatic worker initialization. Preserve the standard worker behavior while allowing custom transports to instantiate the JSON language service.
