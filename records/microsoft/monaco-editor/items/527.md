# Issue #527 — feature-request: Support Matching Tag Editing for HTML/XML

[https://github.com/microsoft/monaco-editor/issues/527](https://github.com/microsoft/monaco-editor/issues/527)

## Summary

A real gap remains: Monaco ships linked-editing infrastructure, but its bundled HTML language mode does not provide matching tag ranges. The Backlog milestone and existing html label remain appropriate.

## Change summary

Automatically synchronize matching HTML/XML start and end tag names while either tag is edited.

## Best solution

Add a LinkedEditingRangeProvider adapter to the bundled HTML language mode under src/languages/features/html, backed by matching-tag ranges from the HTML language service. This appears suitable for a community PR.
