# Issue #4577 — [Bug] Repeated Quick Fixes

[https://github.com/microsoft/monaco-editor/issues/4577](https://github.com/microsoft/monaco-editor/issues/4577)

## Summary

Still present on main: Monaco forwards multiple diagnostic codes to TypeScript, which returns the same generic suppression actions for each code, and the adapter does not deduplicate them. Route this Monaco-owned adapter defect to the TypeScript area.

## Change summary

Quick Fix lists duplicate TypeScript suppression actions when multiple diagnostics overlap the selected location.

## Best solution

Deduplicate equivalent TypeScript code fixes in `CodeActionAdaptor` before converting them to Monaco actions, using the action description and edits as a stable identity, and cover overlapping diagnostics with a regression test.
