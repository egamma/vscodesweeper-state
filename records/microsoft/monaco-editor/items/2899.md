## Evidence

- **Verified canonical:** https://github.com/microsoft/monaco-editor/issues/1984 is currently OPEN, was created in May 2020, and tracks shell command substitutions prematurely ending at an inner closing parenthesis, causing trailing quotes and subsequent code to be highlighted incorrectly.
- **Shared root cause in current source:** src/languages/definitions/shell/shell.ts enters parameterBodyParen on $(. That state consumes quotes and nested opening parentheses as variable text, then pops on the first ). In this report's $(realpath "$(dirname "$0")/../../"), it exits at dirname's closing parenthesis; the later quote starts dblStringBody instead of closing the argument, leaving subsequent code in a string state.
- **Canonical diagnosis:** https://github.com/microsoft/monaco-editor/issues/1984#issuecomment-635446396 identifies the same parameterBodyParen limitation: command-substitution contents are treated as variable text until the first closing parenthesis, ignoring nested syntax.
- **Distinct evidence preserved:** https://github.com/microsoft/monaco-editor/issues/2899 supplies a nested realpath/dirname example from the homepage shell demo.
