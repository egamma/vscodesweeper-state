# Issue #3245 — [Bug] C++ Raw strings aren't properly handled when the delimiter contains a quote

[https://github.com/microsoft/monaco-editor/issues/3245](https://github.com/microsoft/monaco-editor/issues/3245)

## Summary

Fixed on main: the C++ tokenizer now preserves the opening raw-string delimiter, including quotes, and dynamically matches it at the closing sequence. The fix shipped in v0.48.0.

## Change summary

C++ raw strings with a quote in their delimiter remain highlighted through the end of the file.

## Best solution

Keep the raw-string state matcher introduced by https://github.com/microsoft/monaco-editor/commit/92f21bfb5beb4af84f0196f3c5224e0d57b61c33; it directly handles the reported quoted delimiter.
