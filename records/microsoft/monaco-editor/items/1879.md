[https://github.com/microsoft/monaco-editor/issues/1879](https://github.com/microsoft/monaco-editor/issues/1879)

## Summary

The standalone monaco-languages repository has been archived and its languages moved into monaco-editor, where v0.56.0 introduced supported tree-shakeable ESM language entry points. The Python module still exports both `conf` and `language`, satisfying the central request through the current package.

## Change summary

Allow Node ESM consumers to import an individual language configuration and tokenizer without a custom loader.

## Best solution

Use the consolidated `monaco-editor` package and import the Python definition through `monaco-editor/languages/definitions/python/python`; no separate ESM package is needed.
