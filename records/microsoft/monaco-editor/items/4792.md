# Issue #4792 — [Bug] CodeLens. range.startColumn not take effect

[https://github.com/microsoft/monaco-editor/issues/4792](https://github.com/microsoft/monaco-editor/issues/4792)

## Summary

The example reflects CodeLens's intended above-line layout, not a positioning defect. Inline command labels are supported through the inlay-hints API.

## Change summary

Display a clickable command inline at a specified column instead of above the source line.

## Best solution

Use monaco.languages.registerInlayHintsProvider with an InlayHint.position and an InlayHintLabelPart.command for inline command labels; preserve CodeLens's existing above-line behavior.
