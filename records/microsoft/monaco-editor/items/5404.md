# Issue #5404 — [Bug] Unable to import "monaco-editor/min/vs/editor/editor.main.css"

[https://github.com/microsoft/monaco-editor/issues/5404](https://github.com/microsoft/monaco-editor/issues/5404)

## Summary

The bundled stylesheet remains generated, but current main's package exports redirect both reported CSS imports to nonexistent JavaScript paths. Keep the report open and route it to packaging; the linked fix PR was closed without merging.

## Change summary

Since v0.56.0, package imports cannot resolve the bundled editor stylesheet used for Shadow DOM style injection.

## Best solution

Provide a supported, resolvable bundled stylesheet for embedders that inject styles into Shadow DOM. Decide whether to preserve the existing CSS import path or expose a modern CSS entry point, without requiring the deprecated AMD loader.
