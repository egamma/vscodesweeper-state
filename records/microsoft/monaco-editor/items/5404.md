# Issue #5404 — [Bug] Unable to import "monaco-editor/min/vs/editor/editor.main.css"

[https://github.com/microsoft/monaco-editor/issues/5404](https://github.com/microsoft/monaco-editor/issues/5404)

## Summary

The CSS import regression remains in current main: the stylesheet is generated, but package exports redirect its import to a nonexistent JavaScript path. The referenced fix PR was closed without merging; route this to packaging/integration.

## Change summary

Since v0.56.0, package exports prevent importing the bundled editor stylesheet for uses such as Shadow DOM styling.

## Best solution

Restore package-level access to the generated bundled stylesheet without undoing the supported ESM entry points. Preserve explicit stylesheet consumption for Shadow DOM embedders and cover it with a generated-package bundling regression.
