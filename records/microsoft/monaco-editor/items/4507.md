# Issue #4507 — [Bug] Cannot redeclare block-scoped variable 'Map'.

[https://github.com/microsoft/monaco-editor/issues/4507](https://github.com/microsoft/monaco-editor/issues/4507)

## Summary

The sample triggers TypeScript's expected global-name collision, not a Monaco defect. Explain script versus module scope and close as a configuration question.

## Change summary

The reporter expects `let Map = new Set();` to pass TypeScript validation with an ES2019 target.

## Best solution

Preserve TypeScript's diagnostics. Add `export {};` to the edited code if it should be a module, or rename the variable if it should remain a global script.
