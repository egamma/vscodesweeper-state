# Issue #4507 — [Bug] Cannot redeclare block-scoped variable 'Map'.

[https://github.com/microsoft/monaco-editor/issues/4507](https://github.com/microsoft/monaco-editor/issues/4507)

## Summary

This is expected TypeScript global-script behavior rather than a Monaco defect: selecting an ES module output format does not make source text a module, so the declaration conflicts with the global `Map` constructor.

## Change summary

Allow a TypeScript model to declare a block-scoped variable named `Map` without diagnostic TS2451.

## Best solution

Treat the model as a module by adding `export {}` or configuring `moduleDetection: 3` (`Force`); Monaco already passes that compiler option through to the TypeScript language service.
