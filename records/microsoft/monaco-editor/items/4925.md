# Issue #4925 — [Bug] Requests to language workers (tsWorker/cssWorker..) result in 404 errors due to incorrect URLs. Happens even in a simple application. But only when urlArgs(for cache busting) are specified in require.config call.

[https://github.com/microsoft/monaco-editor/issues/4925](https://github.com/microsoft/monaco-editor/issues/4925)

## Summary

Verified duplicate: the open canonical issue tracks Monaco's inconsistent handling of RequireJS `urlArgs`, and its discussion already includes this exact malformed TypeScript worker URL and resulting 404.

## Change summary

Using `urlArgs` with the AMD loader corrupts language-worker URLs, causing requests such as `tsWorker.js` to return 404.

## Best solution

Consolidate the AMD loader's `urlArgs` handling under https://github.com/microsoft/monaco-editor/issues/4310, preserving this report's JSBin reproduction and malformed `/vs/bas/` worker-path evidence there.
