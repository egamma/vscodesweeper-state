# Issue #380 — Add flag to Disable Worker

[https://github.com/microsoft/monaco-editor/issues/380](https://github.com/microsoft/monaco-editor/issues/380)

## Summary

Implemented in the editor core: setting `links: false` prevents link computation, satisfying the accepted read-only plaintext-viewer scope without spawning the editor worker for link detection.

## Change summary

Allow read-only plaintext viewers to avoid spawning a web worker for unused editor features.

## Best solution

Use the existing `links: false` editor option for read-only plaintext viewers. Rich language and diff features may still require their respective workers; a global worker-disable switch is not needed for the scenario accepted in this issue.
