# Issue #4095 — [Feature Request] expose API for modifying configurations in standalone mode

[https://github.com/microsoft/monaco-editor/issues/4095](https://github.com/microsoft/monaco-editor/issues/4095)

## Summary

The requested capability already has a public API: `editor.updateOptions({ maxTokenizationLineLength: 40000 })` updates the standalone configuration service and notifies the tokenizer.

## Change summary

Expose a supported way to change `editor.maxTokenizationLineLength` at runtime in standalone Monaco.

## Best solution

Use the existing typed `IStandaloneCodeEditor.updateOptions` API rather than importing internal configuration services; no additional configuration API is needed for this setting.

## Vision fit

- **Fit:** aligned
- **Reason:** A supported editor API for embedders fits Monaco's browser-library boundary, and the existing API already provides it.
- **Evidence:** The vision states that embedders integrate through Monaco's API rather than internal VS Code services.

- **Proposed comment:**

  > Thanks for the context. You do not need to keep using the non-public `IConfigurationService` and `StandaloneServices` imports. `maxTokenizationLineLength` is a public global editor option, and it can be changed at runtime with:
  > 
  > ```ts
  > editor.updateOptions({ maxTokenizationLineLength: 40000 });
  > ```
  > 
  > The standalone editor forwards that call to its configuration service, and the tokenizer observes the change. Closing this as already supported by the public API.

## Evidence
