# Issue #4095 — [Feature Request] expose API for modifying configurations in standalone mode

[https://github.com/microsoft/monaco-editor/issues/4095](https://github.com/microsoft/monaco-editor/issues/4095)

## Summary

The supplied tokenization example already has a supported API, but that does not fully cover the broader request for editor-independent configuration updates. Keep the request open pending clarification of which additional configuration access is needed.

## Change summary

Expose a supported standalone configuration API instead of requiring private configuration-service imports.

## Best solution

Use editor.updateOptions({ maxTokenizationLineLength: 40000 }) for the demonstrated case. Any remaining editor-independent or general configuration API needs a public-contract decision in the VS Code standalone editor sources, rather than exposing private services indiscriminately.
