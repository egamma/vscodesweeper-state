# Issue #5066 — Use LSP for CSS/JSON/HTML language features

[https://github.com/microsoft/monaco-editor/issues/5066](https://github.com/microsoft/monaco-editor/issues/5066)

## Summary

The migration remains necessary: CSS, JSON, and HTML still use the legacy shared LSP adapters rather than the native Monaco LSP client. This team-authored Backlog item should remain open until that migration is implemented.

## Change summary

Migrate the bundled CSS, JSON, and HTML language features to the Monaco LSP client and remove their legacy adapter layer.

## Best solution

Connect the CSS, JSON, and HTML workers through `monaco-lsp-client`, preserve their existing configurable providers, and then remove `src/languages/features/common/lspLanguageFeatures.ts`. The separate TypeScript migration remains tracked by https://github.com/microsoft/monaco-editor/issues/5065.
