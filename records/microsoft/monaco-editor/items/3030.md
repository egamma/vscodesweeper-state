# Issue #3030 — [Bug] YAML keyword values affected by comments

[https://github.com/microsoft/monaco-editor/issues/3030](https://github.com/microsoft/monaco-editor/issues/3030)

## Summary

Fixed in v0.37.0: the YAML tokenizer now separates whitespace-delimited comments from scalar values, preserving keyword highlighting.

## Change summary

YAML keywords followed by an inline comment were incorrectly highlighted as strings.

## Best solution

Keep the tokenizer correction from https://github.com/microsoft/monaco-editor/commit/c7ce77ba1843a0509db546b035babf43ac0b73ac, shipped in v0.37.0; no further change is needed.
