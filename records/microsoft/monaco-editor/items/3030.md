# Issue #3030 — [Bug] YAML keyword values affected by comments

[https://github.com/microsoft/monaco-editor/issues/3030](https://github.com/microsoft/monaco-editor/issues/3030)

## Summary

The reported keyword/comment highlighting mismatch was fixed in v0.37.0. Tracing the supplied examples through current source shows that spaced comments preserve keyword highlighting, while an attached hash remains part of a string.

## Change summary

YAML keyword highlighting incorrectly changes when a trailing comment is separated by whitespace.

## Best solution

Treat the highlighting defect as fixed in v0.37.0; retain the distinction between `null #comment` and the string scalar `null#comment`, rather than changing YAML parsing semantics.
