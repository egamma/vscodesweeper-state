# Issue #4360 — [Bug] DiffEditor Trailing Line Is Marked As Difference When A Difference Text Is At The End Of Line

[https://github.com/microsoft/monaco-editor/issues/4360](https://github.com/microsoft/monaco-editor/issues/4360)

## Summary

The reported highlighting is an intentional diff heuristic rather than a Monaco-specific defect. The same case was reviewed in the VS Code editor core and closed as designed.

## Change summary

Show unchanged trailing characters as unchanged when most of an aligned line differs.

## Best solution

Keep the existing heuristic, which avoids misleading character alignments during larger edits. Any improvement to its threshold or alignment behavior belongs in the VS Code editor core rather than as a Monaco-only change.

  > Thanks for the report and playground example.
