[https://github.com/microsoft/monaco-editor/issues/1184](https://github.com/microsoft/monaco-editor/issues/1184)

## Summary

The accepted broader request remains necessary: current main supports continuation inside `//` comments, but not C/C++ line splicing everywhere. The issue is already correctly routed and marked open for community contribution.

## Change summary

Make the C/C++ Monarch tokenizer treat backslash-newline sequences as line splicing in every lexical context.

## Best solution
