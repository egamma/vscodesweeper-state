# Issue #1431 — PHP: does not work highlight for interpolated variable;

[https://github.com/microsoft/monaco-editor/issues/1431](https://github.com/microsoft/monaco-editor/issues/1431)

## Summary

Keep open: the current PHP grammar still treats interpolated variables as ordinary string text. This remains an accepted, correctly routed grammar enhancement; no matching canonical or open implementation PR was found.

## Change summary

Highlight interpolated PHP variables separately from the surrounding double-quoted string.

## Best solution

Extend the Monaco-owned PHP grammar in src/languages/definitions/php/php.ts to distinguish interpolated variables, with tokenization cases in php.test.ts. This remains suitable for the community contribution already invited by the maintainer.
