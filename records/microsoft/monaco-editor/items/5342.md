# Issue #5342 — [Bug] [LSP] `textDocument/codeAction` request omits diagnostic fields the server needs to produce quickfixes (`data`, `code`, `source`, …)

[https://github.com/microsoft/monaco-editor/issues/5342](https://github.com/microsoft/monaco-editor/issues/5342)

## Summary

The diagnostic round-trip defect is concretely reproduced, and open PR https://github.com/microsoft/monaco-editor/pull/5341 directly references and fixes this issue. Keep the issue open until that implementation candidate is reviewed and merged or closed.

## Change summary

Preserve complete LSP diagnostics, especially opaque `data`, when constructing `textDocument/codeAction` requests so servers can return diagnostic-specific quick fixes.

## Best solution

Review and land https://github.com/microsoft/monaco-editor/pull/5341, which caches received diagnostics and forwards the original matching diagnostic in code-action requests while retaining a synthesized fallback for unrelated markers.
