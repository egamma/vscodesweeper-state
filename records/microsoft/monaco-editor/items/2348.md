# Issue #2348 — Importing JSON in Typescript file results in error

[https://github.com/microsoft/monaco-editor/issues/2348](https://github.com/microsoft/monaco-editor/issues/2348)

## Summary

A real TypeScript multifile gap remains on current main: JSON editor models are not automatically synchronized into the TypeScript worker, and its script-kind mapping does not recognize JSON. The team-authored issue already has the correct routing labels and should remain open.

## Change summary

Allow TypeScript models to import JSON models with resolveJsonModule and receive inferred JSON types.

## Best solution

Extend the TypeScript worker integration in src/languages/features/typescript/workerManager.ts and src/languages/features/typescript/tsWorker.ts to synchronize referenced JSON models and expose them to TypeScript as ScriptKind.JSON. This looks suitable for a focused community contribution.
