## Summary

This is a usage question already answered by the existing `renderOverviewRuler: false` diff-editor option, with a working playground example.

## Change summary

Hide the remaining minimap-like overview ruler in a diff editor.

## Best solution

Set `renderOverviewRuler: false` when creating or updating the diff editor; no Monaco change is needed.
