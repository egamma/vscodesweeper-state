# Issue #4521 — How to close minimap in monaco-diff-editior

[https://github.com/microsoft/monaco-editor/issues/4521](https://github.com/microsoft/monaco-editor/issues/4521)

## Summary

This is an answered configuration question: minimap.enabled disables the minimap, while renderOverviewRuler: false hides the separate diff overview ruler.

## Change summary

Hide the overview visualization in an inline diff editor.

## Best solution

Use renderOverviewRuler: false in createDiffEditor alongside the existing minimap.enabled: false configuration; no new editor capability is needed.
