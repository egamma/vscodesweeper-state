# Issue #2960 — [Bug] workerMain and tsWorker are fetched each time setCompilerOptions is called

[https://github.com/microsoft/monaco-editor/issues/2960](https://github.com/microsoft/monaco-editor/issues/2960)

## Summary

The accepted feature request remains necessary: current `main` still disposes and recreates the TypeScript worker whenever compiler options change. No broader open canonical was found, and the existing labels already route it correctly.

## Change summary

Update TypeScript compiler options without recreating and refetching the entire web worker.

## Best solution

Add a worker-side configuration method that updates compiler options and recreates only the TypeScript language service, preserving the existing web worker and synchronized models.
