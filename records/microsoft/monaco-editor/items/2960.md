# Issue #2960 — [Bug] workerMain and tsWorker are fetched each time setCompilerOptions is called

[https://github.com/microsoft/monaco-editor/issues/2960](https://github.com/microsoft/monaco-editor/issues/2960)

## Summary

Keep open: current main still restarts the TypeScript worker when compiler options change, and the maintainer explicitly accepted updating options without replacing the worker as a feature request. Caching mitigates script downloads but does not provide that capability.

## Change summary

Update TypeScript and JavaScript compiler options without terminating and recreating their web worker.

## Best solution

Support compiler-option changes within the existing worker in Monaco's TypeScript integration, following the maintainer's direction to recreate only the language service. Preserve model synchronization and ensure subsequent language-service results reflect the new options.
