# Issue #4749 — [Bug] In the diffEditor, how can I fold the code? I set folding, but it is not working.

[https://github.com/microsoft/monaco-editor/issues/4749](https://github.com/microsoft/monaco-editor/issues/4749)

## Summary

Code-block folding in the diff editor is already tracked by the open VS Code issue linked below. Current core source explicitly disables folding, so this is a missing capability rather than a Monaco-specific regression.

## Change summary

Allow folding the JSON 'bb' object in a diff editor configured with folding: true.

Consolidate this example into https://github.com/microsoft/vscode/issues/116483, which owns enabling code folding in the shared diff editor while preserving alignment between panes.
