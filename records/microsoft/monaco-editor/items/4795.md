## Summary

This is a duplicate of the open feature request tracking an API for disabling workers. Returning undefined from getWorker is not a supported way to disable them.

## Change summary

Provide a way to disable Monaco workers or load their scripts from a CDN.

Consolidate the disable-worker request on https://github.com/microsoft/monaco-editor/issues/380. For CDN hosting, retain the documented MonacoEnvironment worker-factory configuration.
