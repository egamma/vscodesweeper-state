# Issue #3346 — [Bug] DiffEditor: Toggling `renderSideBySide` breaks `wordWrap` unrecoverably

[https://github.com/microsoft/monaco-editor/issues/3346](https://github.com/microsoft/monaco-editor/issues/3346)

## Summary

This remains the best canonical issue for a confirmed diff-editor regression: multiple users report it, and a newer v0.55.1 playground reproduces the same failure. The existing bug and diff-editor labels route it correctly.

## Change summary

Switching a diff editor between inline and side-by-side modes disables word wrapping on the original editor.

## Best solution

Fix the diff editor's option synchronization in the VS Code editor core so both embedded editors retain word wrapping across layout-mode changes, then let the fix flow into Monaco. Consolidate the newer reproduction from https://github.com/microsoft/monaco-editor/issues/5353 here.
