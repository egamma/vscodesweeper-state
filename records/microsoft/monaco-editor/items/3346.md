# Issue #3346 — [Bug] DiffEditor: Toggling `renderSideBySide` breaks `wordWrap` unrecoverably

[https://github.com/microsoft/monaco-editor/issues/3346](https://github.com/microsoft/monaco-editor/issues/3346)

## Summary

Keep open: current VS Code editor-core source still leaves the original pane's wrapping override disabled after an inline-to-side-by-side transition. Matching newer reports exist, but neither meets the stronger canonical-ownership bar for this re-reviewed issue.

## Change summary

Switching the diff editor through inline mode permanently disables word wrapping on the original pane despite wordWrap remaining enabled.

## Best solution

Restore the original pane's configured wrapping when returning to side-by-side mode in the microsoft/vscode editor core, while preserving the hidden pane's no-wrap behavior in inline mode. Coordinate with https://github.com/microsoft/vscode/issues/314898 and deliver the correction through a subsequent Monaco release.
