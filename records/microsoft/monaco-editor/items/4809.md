# Issue #4809 — Request for Enabling RTL Support in Monaco Editor

[https://github.com/microsoft/monaco-editor/issues/4809](https://github.com/microsoft/monaco-editor/issues/4809)

## Summary

This is a cross-repository duplicate of the open VS Code editor-core request for right-to-left editing. Monaco inherits this behavior from VS Code, where implementation work is already under review.

## Change summary

Add native right-to-left and bidirectional editing support for languages such as Persian and Arabic.

## Best solution

Consolidate the request on https://github.com/microsoft/vscode/issues/4994 and land the editor-core implementation there; Monaco will inherit it through a subsequent source update.
