# Issue #4329 — Provide configuration for deleting trigger characters after providing pop-up lists

[https://github.com/microsoft/monaco-editor/issues/4329](https://github.com/microsoft/monaco-editor/issues/4329)

## Summary

The requested outcome is already supported per completion item: its `range` determines which text is replaced when accepted, so it can include the preceding `@`. A provider-level `replaceTriggerChar` option is unnecessary.

## Change summary

Allow a completion provider to remove its trigger character when a suggestion is accepted.

## Best solution

Keep replacement scoped to each completion item by returning a single-line `range` from the `@` through the cursor; use an appropriate `filterText` if including the trigger in the range affects suggestion filtering.

- **Proposed comment:**

  > Thanks for the request. This is already supported on each completion item through its `range`, which specifies the text replaced when the item is accepted. Return a range beginning at the `@` and ending at the current position, for example `range: new monaco.Range(position.lineNumber, position.column - 1, position.lineNumber, position.column)`. You may also need a matching `filterText` so the suggestion remains visible while that range contains `@`. This keeps replacement behavior item-specific rather than adding a provider-level `replaceTriggerChar` option.
