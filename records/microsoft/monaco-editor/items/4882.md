## Summary

The linked Ace report clarifies that this requests built-in Python syntax checking. Monaco currently provides Python tokenization, not a bundled Python diagnostics worker; retain the request for a language-support scope decision.

## Change summary

Provide a built-in Python syntax-checking worker comparable to the JavaScript/TypeScript worker.

## Best solution

Decide whether Monaco should bundle an optional Python diagnostics service or leave Python checking to embedder-supplied language services through LSP. Existing highlighting and LSP integration do not themselves supply the requested built-in checker.
