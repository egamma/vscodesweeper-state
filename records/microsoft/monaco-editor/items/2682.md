# Issue #2682 — Import suggestions are not displayed when the caret is positioned after the last character

[https://github.com/microsoft/monaco-editor/issues/2682](https://github.com/microsoft/monaco-editor/issues/2682)

## Summary

Implemented upstream: Ctrl/Cmd+. now searches for the nearest quick fix on the current line, covering the reported caret position, and the behavior shipped in Monaco v0.44.0.

## Change summary

Show TypeScript import quick fixes when the caret is immediately after the unresolved identifier.

## Best solution

Keep the current vscode-derived nearby-quick-fix behavior, which finds the closest diagnostic on the caret's line without requiring the caret to be inside its range.
