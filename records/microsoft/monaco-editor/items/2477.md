# Issue #2477 — Install actions does not work (Bulb widget)

[https://github.com/microsoft/monaco-editor/issues/2477](https://github.com/microsoft/monaco-editor/issues/2477)

## Summary

Still present on current main: Monaco exposes TypeScript's command-only “Install '@types/node'” fix but discards its install command, leaving a visible action that does nothing. The existing typescript label already routes this confirmed bug correctly.

## Change summary

Suppress TypeScript install-package quick fixes that Monaco cannot execute.

## Best solution

Filter unsupported install-package fixes in `src/languages/features/typescript/languageFeatures.ts` before converting them to Monaco code actions. Disabling the entire built-in code-action provider is available but does not adequately address the misleading default behavior.
