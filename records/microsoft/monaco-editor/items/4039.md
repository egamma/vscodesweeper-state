# Issue #4039 — [Bug] Language C highlights "class" as token

The defect remains in current source: C loads the C++ tokenizer, which classifies class as a keyword. Keep this issue open while the existing implementation candidate is reviewed.

## Change summary

C syntax highlighting incorrectly treats C++-only keywords such as class as reserved words.
