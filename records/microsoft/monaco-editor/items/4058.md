# Issue #4058 — [Bug] monaco.editor.colorize ignores DocumentSemanticTokensProvider

[https://github.com/microsoft/monaco-editor/issues/4058](https://github.com/microsoft/monaco-editor/issues/4058)

## Summary

Semantic-token support remains absent from colorize's plain-text path. Keep this accepted Backlog feature request open: the matching earlier request was declined, not fixed, and that earlier decision does not override this item's subsequent triage.

## Change summary

Allow monaco.editor.colorize to include colors supplied by a registered DocumentSemanticTokensProvider.

## Best solution

Decide whether plain-text HTML colorization should invoke semantic providers, then implement any accepted enhancement in the VS Code standalone colorizer that Monaco imports. Preserve this issue as the outstanding request; the older closed request is precedent, not an open canonical.
