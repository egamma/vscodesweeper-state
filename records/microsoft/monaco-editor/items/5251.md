# Issue #5251 — [Bug] Monaco Codicon Font should be in an extra CSS for webcomponent setup

[https://github.com/microsoft/monaco-editor/issues/5251](https://github.com/microsoft/monaco-editor/issues/5251)

## Summary

This is a valid packaging request for Shadow DOM embedders: the Codicon font-face must be installed in the document while Monaco's remaining styles stay scoped to the component. The current Codicon feature entry point may provide the necessary separation, but the report does not establish whether that bundler-driven approach is sufficient.

## Change summary

Expose the Codicon font CSS separately so web components can load the font face outside their shadow root.

## Best solution

Confirm and document loading `monaco-editor/features/codicon/register` in the document-level bundle while injecting other editor styles into the shadow root; if bundlers cannot reliably separate that CSS, export a dedicated Codicon stylesheet from the ESM package.
