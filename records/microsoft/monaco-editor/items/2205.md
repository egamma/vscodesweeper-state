# Issue #2205 — Scroll/copy/paste/select all not working on WKWebview in Mac "Catalyst" app.

[https://github.com/microsoft/monaco-editor/issues/2205](https://github.com/microsoft/monaco-editor/issues/2205)

## Summary

This is an upstream WKWebView event-delivery problem rather than Monaco behavior: the host does not emit the wheel and keyboard/clipboard DOM events Monaco requires. The issue already has the appropriate upstream and safari-ios routing.

## Change summary

Scrolling and standard selection and clipboard shortcuts fail when Monaco is embedded in a Mac Catalyst WKWebView.

## Best solution

WKWebView should deliver the standard wheel, keyboard, and clipboard events to embedded web content. The resolved WebKit wheel-event fix should be retested on current Catalyst releases, while any remaining clipboard or selection failures likely require a separate WebKit report.
