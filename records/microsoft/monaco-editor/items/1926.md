# Issue #1926 — How to set alias path for files in monaco editor?

[https://github.com/microsoft/monaco-editor/issues/1926](https://github.com/microsoft/monaco-editor/issues/1926)

## Summary

This is a configuration question rather than a missing Monaco capability. The mapping omits the wildcard in its substitution and uses a base URL outside the models' `file:///` URI namespace.

## Change summary

Configure TypeScript path aliases so IntelliSense and definition navigation resolve across Monaco models.

## Best solution

Use model URIs and compiler paths in the same virtual URI namespace, for example `baseUrl: "file:///"` with `paths: { "@/*": ["*"] }`, while retaining models such as `file:///foo.js`.

- **Proposed comment:**

  > Thanks for the report. This configuration needs to preserve the matched wildcard and use the same URI namespace as the models. With models such as `file:///foo.js`, use `baseUrl: "file:///"` and `paths: { "@/*": ["*"] }` (or `"./*"`). The reported `"@/*": ["./"]` drops the matched `foo` segment, while `baseUrl: "./"` resolves outside the models' `file:///` namespace.
