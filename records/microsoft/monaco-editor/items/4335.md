# Issue #4335 — [Bug] CodeActionProvider text edits doesn't work correctly with flag insertAsSnippet

[https://github.com/microsoft/monaco-editor/issues/4335](https://github.com/microsoft/monaco-editor/issues/4335)

## Summary

The supplied code-action example still exposes a source-confirmed defect: Monaco's standalone bulk-edit service ignores insertAsSnippet and inserts placeholder syntax literally. Route to editor-contrib; the fix belongs in the VS Code sources Monaco bundles.

## Change summary

Code-action workspace edits marked insertAsSnippet should expand snippet placeholders instead of inserting their syntax literally.

## Best solution

Honor snippet-marked workspace edits in the VS Code standalone editor's bulk-edit service while preserving ordinary text-edit behavior. Bring that fix into Monaco through its generated editor-core package.
