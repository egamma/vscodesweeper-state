# Issue #4335 — [Bug] CodeActionProvider text edits doesn't work correctly with flag insertAsSnippet

[https://github.com/microsoft/monaco-editor/issues/4335](https://github.com/microsoft/monaco-editor/issues/4335)

## Summary

Still present in current source: Monaco's standalone bulk-edit service applies code-action text edits as plain replacements and never checks `insertAsSnippet`, leaving snippet placeholders unexpanded.

## Change summary

Code-action workspace edits marked `insertAsSnippet` are inserted as literal text instead of entering snippet mode.

## Best solution

Update `StandaloneBulkEditService` in the vscode editor core to preserve and execute snippet text edits against the active editor, with plain-text fallback where snippet mode is unavailable. The fix belongs in `microsoft/vscode` and should flow into Monaco with a subsequent release.
