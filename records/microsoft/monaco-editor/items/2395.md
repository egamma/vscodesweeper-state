# Issue #2395 — Right click in view zone or content/overlay widget has inconsistent behavior

[https://github.com/microsoft/monaco-editor/issues/2395](https://github.com/microsoft/monaco-editor/issues/2395)

## Summary

The inconsistency remains in the current VS Code editor core: overlay-widget context menus are allowed through, while content-widget events are suppressed without showing either menu. Route this confirmed bug to the context-menu/editor-contribution owners.

## Change summary

Selecting text and right-clicking inside content, overlay, or view-zone widgets produces inconsistent selection and context-menu behavior across Chrome and Safari.

## Best solution

Update the VS Code editor core context-menu contribution to handle content widgets consistently with overlay widgets, preserving widget text selection and allowing the intended native or editor context menu. The fix belongs in `src/vs/editor/contrib/contextmenu/browser/contextmenu.ts` and will flow into Monaco with a release cut.
