# Issue #2874 — [Bug] When using monaco-editor with webpack-plugin, webpack bundles all features and languages

[https://github.com/microsoft/monaco-editor/issues/2874](https://github.com/microsoft/monaco-editor/issues/2874)

## Summary

The root entry point still registers all features and languages, so plugin selections do not produce the expected minimal bundle. Keep this open because an open PR explicitly implements the request and must be reviewed or updated before closure.

## Change summary

Make monaco-editor-webpack-plugin honor configured feature and language subsets when applications import the main monaco-editor entry point.

## Best solution

Update and land https://github.com/microsoft/monaco-editor/pull/2865 against the current v0.56 entry-point structure, ensuring the plugin substitutes the API-only entry point before adding configured features and languages. The documented editor.api import remains a workaround, but does not satisfy the central request.
