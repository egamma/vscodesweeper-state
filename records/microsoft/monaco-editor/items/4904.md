Fixed in the VS Code editor core and shipped in Monaco v0.56.0. The fix handles the canceled WordHighlighter promise that produced this exact unhandled rejection.

Restoring editor view state after remounting can produce an unhandled canceled-promise rejection from the word highlighter.
