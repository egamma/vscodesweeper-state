The reported word-highlighter cancellation rejection is fixed in the VS Code editor core and included in Monaco v0.56.0. Current adopted source handles cancellations on every delayed word-highlighter operation, including view-state restoration.

## Change summary

## Best solution

Treat this as completed by the upstream cancellation-handling fix shipped in Monaco v0.56.0; retain word-highlighter state rather than deleting it as a workaround.
