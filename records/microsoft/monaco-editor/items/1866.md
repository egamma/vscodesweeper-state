Keep open as a request for selective completion suppression: the current TypeScript integration exposes an all-or-nothing completion switch, not a receiver-type filter. No verified canonical or implementation covers the full request.

## Change summary

Allow explicit completion requests after a dot to suppress speculative suggestions for any and unknown receivers while preserving useful typed completions.
