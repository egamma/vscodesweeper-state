Verified duplicate: the open canonical issue tracks the same TypeScript-language-service completions for values without useful type information and the missing preference needed to suppress them.

## Change summary

Allow embedders to suppress misleading explicit completions for TypeScript values typed as `any` or `unknown`.

## Best solution

Consolidate on https://github.com/microsoft/monaco-editor/issues/2136. The end state requires a TypeScript `UserPreferences` option for suppressing these completions, followed by exposing that option through Monaco's TypeScript worker.
