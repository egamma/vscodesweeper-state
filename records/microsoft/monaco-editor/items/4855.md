# Issue #4855 — [Bug] Paste does not work with Electron 34

[https://github.com/microsoft/monaco-editor/issues/4855](https://github.com/microsoft/monaco-editor/issues/4855)

## Summary

The Electron paste failure remains traceable in the current VS Code editor core: standalone Monaco receives the browser clipboard service, but Electron is classified as native, preventing the only fallback after `triggerPaste()` returns undefined. The issue is already correctly routed and should remain the canonical open report.

## Change summary

Pasting into Monaco fails under Electron 34 and later because the paste action does not fall back to reading clipboard text.

## Best solution

Fix the VS Code editor-core clipboard path so standalone Monaco can use `BrowserClipboardService.readText()` when `triggerPaste()` is unavailable, including when Electron process detection makes `platform.isWeb` false. Preserve this issue as the canonical Electron report and let the fix flow into the next Monaco release.
