# Issue #2953 — Latest 0.32.1 no longer expose tsWorker

[https://github.com/microsoft/monaco-editor/issues/2953](https://github.com/microsoft/monaco-editor/issues/2953)

## Summary

Custom TypeScript worker exports were added after this report and shipped in v0.41.0. Current main still exports TypeScriptWorker and the bundled TypeScript API from the worker entry point.

## Change summary

Expose the TypeScript worker class and compiler services so embedders can build custom workers.

## Best solution

Use the exported TypeScriptWorker, ts, initialize, and libFileMap to construct a custom ESM worker rather than depending on the former standalone internal files.

- **Reason:** Exposing language-worker building blocks supports customization through Monaco's embedder API and modern ESM integration.
