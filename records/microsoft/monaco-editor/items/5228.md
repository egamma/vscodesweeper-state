# Issue #5228 — [Bug] Typing any character doesn't replace backward-selected char at once in Firefox

[https://github.com/microsoft/monaco-editor/issues/5228](https://github.com/microsoft/monaco-editor/issues/5228)

## Summary

This remains a confirmed editor-input bug: multiple reporters reproduced the dropped first keystroke in Firefox on later 0.56 development builds, and the related reports point back here as the canonical issue.

## Change summary

Typing after making a backward selection in Firefox drops the first character instead of replacing the selected text.

## Best solution

Fix the textarea selection synchronization in the VS Code editor core, preserving Firefox screen-reader support rather than requiring embedders to disable accessibility. The correction should flow into Monaco through a subsequent source update.
