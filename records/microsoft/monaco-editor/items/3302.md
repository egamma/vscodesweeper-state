# Issue #3302 — [Feature Request] Colorizing with a specific theme

[https://github.com/microsoft/monaco-editor/issues/3302](https://github.com/microsoft/monaco-editor/issues/3302)

## Summary

The requested per-call theme and inline-styled HTML output remain missing. Related reports concern independently themed editors or stylesheet access, not the same complete capability, so none establishes a duplicate close.

## Change summary

Allow colorize to produce inline-styled HTML using a specified theme without changing the editor's active theme.

## Best solution

Decide whether to expose independent, theme-specific HTML serialization through the VS Code standalone colorizer that Monaco consumes. Preserve this request's distinction from independently themed live editors: exported code blocks should retain their colors without shared theme CSS.
