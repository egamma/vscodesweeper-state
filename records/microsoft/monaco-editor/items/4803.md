# Issue #4803 — [Feature Request] SetCurosorToEnd property for editor.SetValue()

[https://github.com/microsoft/monaco-editor/issues/4803](https://github.com/microsoft/monaco-editor/issues/4803)

## Summary

This is a valid editor API convenience request, but the workflow is already possible by composing the existing model, cursor, and reveal APIs. Any new `setValue` parameter would need an editor-core API decision in microsoft/vscode rather than a Monaco-only implementation.

## Change summary

Allow `editor.setValue()` to optionally move the cursor to the end of the new content and reveal that position.

## Best solution

The editor API owner should decide in microsoft/vscode whether this composition warrants a first-class option; if accepted there, it will flow into Monaco. Until then, embedders can obtain the model's final position, call `setPosition`, and then `revealPositionInCenterIfOutsideViewport`.
