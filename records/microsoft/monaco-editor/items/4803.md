# Issue #4803 — [Feature Request] SetCurosorToEnd property for editor.SetValue()

[https://github.com/microsoft/monaco-editor/issues/4803](https://github.com/microsoft/monaco-editor/issues/4803)

## Summary

The requested optional parameter is absent, although existing APIs support the cursor-and-scroll workflow. Route to editor-api for a decision on the convenience API; no verified canonical owns this request.

## Change summary

Add an optional setValue parameter that moves the cursor to the end of the replacement text and reveals that position.

## Best solution

Document the existing setValue → setPosition → revealPosition pattern and let the editor-api owner decide whether a combined convenience parameter is warranted. Any public editor API change belongs in the VS Code editor core.

  > Thanks for the suggestion. The current API supports this workflow through separate calls: after editor.setValue(text), get the model's final line with getLineCount(), its final column with getLineMaxColumn(lineNumber), then call editor.setPosition(position) and editor.revealPosition(position). That does not provide the combined optional parameter requested here, so the remaining question is whether to add that convenience API in the shared VS Code editor core.
