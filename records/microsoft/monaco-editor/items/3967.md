# Issue #3967 — [Feature Request] add highlighting for .diff/.patch

[https://github.com/microsoft/monaco-editor/issues/3967](https://github.com/microsoft/monaco-editor/issues/3967)

## Summary

Keep open: the current bundled language registry still lacks diff/patch highlighting. The existing grammars routing and Backlog milestone remain appropriate; the earlier related request is closed and cannot serve as a duplicate canonical.

## Change summary

Provide standalone .diff/.patch highlighting for metadata, hunk headers, additions, and deletions, including green/red backgrounds.

## Best solution

Provide a bundled diff/patch language definition and discoverable playground example, suitable for a community contribution. Agree first whether automatic addition/deletion backgrounds belong in the language experience or require a documented decoration pattern.

Verify that +++/--- file headers are not styled as changed content and that the agreed background behavior works in light and dark themes.
- **Behavior:**

  > A single ordinary editor should highlight a .diff/.patch document without requiring two source models or embedder-authored tokenization rules. File metadata, hunk headers, context, added lines, removed lines, and no-newline hints should be distinguishable. The reporter also requests green/red addition/deletion backgrounds; whether those are automatic or supplied through a documented pattern remains unsettled. A playground example should demonstrate the agreed behavior.
- **Trace:**

  > The current src/languages/definitions/register.all.ts has no diff/patch registration. src/languages/definitions/_.contribution.ts registerLanguage supplies extension metadata, lazy Monarch tokenization, and language configuration; src/languages/definitions/ini/register.ts demonstrates this path. The custom-languages playground sample confirms that custom tokenization is available, but it does not supply this bundled capability. The line-and-inline-decorations sample exposes separate styling building blocks, not an automatic patch background experience. https://github.com/microsoft/monaco-editor/issues/2471 contains earlier maintainer support for a community grammar contribution but is closed. Keep ordinary diff-editor behavior and unrelated grammars unchanged; any required editor-rendering change belongs upstream in microsoft/vscode.
- **Open decisions:**
