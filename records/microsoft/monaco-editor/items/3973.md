# Issue #3973 — [Feature Request] Basic theme manipulation functions

[https://github.com/microsoft/monaco-editor/issues/3973](https://github.com/microsoft/monaco-editor/issues/3973)

## Summary

The requested theme lifecycle and query APIs remain absent from the current public API, while the internal standalone theme service already maintains the necessary theme registry and active-theme state. The existing feature-request and themes labels route this valid API gap correctly.

## Change summary

Expose APIs to remove defined themes, list available themes, and retrieve the active theme name.

## Best solution

Add narrowly typed theme query and removal methods to the vscode standalone editor API and theme service, including safe behavior when removing the active or built-in theme; the changes will then flow into Monaco. This appears suitable for a community PR.
