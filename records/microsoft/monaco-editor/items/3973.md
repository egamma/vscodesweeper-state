[https://github.com/microsoft/monaco-editor/issues/3973](https://github.com/microsoft/monaco-editor/issues/3973)

## Summary

Keep open: the supported API still does not expose theme enumeration, removal, or the current theme name. The related theme-styles request covers different functionality, and no matching canonical was found.

## Change summary

Expose APIs to list registered themes, remove unused themes, and retrieve the active theme name.

## Best solution

Decide the supported theme-management contract in the VS Code standalone editor API and theme service, including removal of active or built-in themes. An accepted implementation would then flow into Monaco through its generated editor core.
