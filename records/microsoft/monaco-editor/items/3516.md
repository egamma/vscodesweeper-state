# Issue #3516 — [Bug] Scroll speed is now way faster on macOS & Chromium

[https://github.com/microsoft/monaco-editor/issues/3516](https://github.com/microsoft/monaco-editor/issues/3516)

## Summary

Fixed in the VS Code editor core: wheel deltas now account for Chromium's device scale factor, and affected users verified the corrected scrolling behavior. The fix predates Monaco v0.46.0.

## Change summary

Scrolling with Chromium on macOS is excessively fast compared with native browser scrolling.

## Best solution

Keep the device-scale-factor normalization shipped from the VS Code editor core; no further Monaco-specific change is needed for the reported speed regression.
