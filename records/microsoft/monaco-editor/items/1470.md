# Issue #1470 — Feature request: support JSONSchema with YAML

[https://github.com/microsoft/monaco-editor/issues/1470](https://github.com/microsoft/monaco-editor/issues/1470)

## Summary

A real capability gap remains: Monaco provides YAML tokenization but no official YAML language service or JSON Schema validation. The Backlog milestone, sustained demand, and lack of a broader canonical issue support keeping this request open.

## Change summary

Provide official JSON Schema validation and rich language support for YAML documents.

## Best solution

Add optional, tree-shakeable YAML language support backed by a browser-compatible YAML language server and Monaco's native LSP client, including schema association configuration comparable to `jsonDefaults`. Keep it outside the default bundle to preserve the lean ESM surface.

- **current capability:** `src/languages/definitions/yaml/register.ts` registers YAML extensions and loads a tokenizer only; it does not register diagnostics, completion, hover, or schema validation.
- **language-service boundary:** `src/index.ts` exports rich built-in language services only for CSS, HTML, JSON, and TypeScript, while separately exposing the native `lsp` namespace.
- **schema API:** `src/languages/features/json/register.ts` defines schema associations under JSON-specific `DiagnosticsOptions`; no equivalent YAML feature exists on current main.
- **maintainer confirmation:** A maintainer confirmed in https://github.com/microsoft/monaco-editor/issues/1470#issuecomment-2114590113 that Monaco does not provide rich YAML support.
