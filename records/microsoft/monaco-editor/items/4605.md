## Summary

This is an integration-support question rather than an actionable Monaco defect. The referenced CDN file is from the AMD build, while the repository documents an ESM-based Vite integration.

## Change summary

Provide instructions for loading Monaco from a CDN in a Vite 4 application without triggering `define is not defined`.

## Best solution

Use Monaco's documented ESM Vite integration and configure `MonacoEnvironment.getWorker` rather than loading the AMD `editor.main.js` as a standalone script. Further integration support belongs on StackOverflow.
