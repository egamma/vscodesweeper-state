- **Proposed comment:**

  > Thanks for the report. The 0.49.0 CDN URL points to an AMD module, which requires an AMD loader providing `define`; it cannot be imported directly as an ES module. The loading sequence is to load `min/vs/loader.js`, configure the `vs` path to the same CDN version, and then call `require(['vs/editor/editor.main'], ...)`, as shown in https://github.com/microsoft/monaco-editor/blob/main/samples/legacy/browser-amd-editor/index.html. This is an integration question rather than an editor defect, so we're closing it as a question. Please use https://stackoverflow.com/questions/tagged/monaco-editor for further usage questions.
