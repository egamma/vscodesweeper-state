# Issue #4710 — [Bug] `lightbulb` for `CodeAction` Not Showing When Text Has Only One Line

[https://github.com/microsoft/monaco-editor/issues/4710](https://github.com/microsoft/monaco-editor/issues/4710)

## Summary

Still present in the current editor core: a non-indented single-line model always routes the lightbulb to the glyph margin, even when `glyphMargin` is disabled, leaving no visible affordance. The accepted Backlog issue should remain open and route to editor contributions.

## Change summary

Show the code-action lightbulb for a single-line model when the editor's glyph margin is disabled.

## Best solution

Update `src/vs/editor/contrib/codeAction/browser/lightBulbWidget.ts` in microsoft/vscode to consider `EditorOption.glyphMargin` before selecting the gutter placement, falling back to a visible inline position when the gutter is unavailable; the fix will then flow into Monaco.
