# Issue #271 — Do not use inline styles!

[https://github.com/microsoft/monaco-editor/issues/271](https://github.com/microsoft/monaco-editor/issues/271)

## Summary

Keep open: strict CSP compatibility remains unimplemented, and an open VS Code editor-core PR explicitly references this issue. Recent testing confirms the proposed approach is viable but still has correctness and performance defects requiring review.

## Change summary

Allow Monaco Editor to render correctly without permitting inline styles in Content Security Policy.

## Best solution

Complete the editor-core work in https://github.com/microsoft/vscode/pull/288813 by covering all style-element creation paths and replacing CSP-blocked style attributes without introducing per-element stylesheet overhead or rendering regressions; the result can then flow into Monaco through a release cut.
