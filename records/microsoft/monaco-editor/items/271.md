[https://github.com/microsoft/monaco-editor/issues/271](https://github.com/microsoft/monaco-editor/issues/271)

Keep open: strict style CSP compatibility remains an unmet capability, and an open VS Code PR explicitly references this issue. The existing editor-core routing is appropriate; neither the newer related report nor the consumer workaround supersedes this request.

## Change summary

Allow Monaco to render correctly under a strict style Content Security Policy without requiring unsafe-inline.

## Best solution

Review https://github.com/microsoft/vscode/pull/288813 against both generated style elements and inline style attributes, including shadow-root paths. Deliver the complete editor-core capability through a Monaco release with a supported integration contract rather than requiring consumers to intercept document.createElement.
