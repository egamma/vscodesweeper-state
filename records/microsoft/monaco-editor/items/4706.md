# Issue #4706 — [Bug] Why is there no JavaScript ?

[https://github.com/microsoft/monaco-editor/issues/4706](https://github.com/microsoft/monaco-editor/issues/4706)

## Summary

This asks about generated worker configuration without reporting a failing editor operation. JavaScript support exists and shares the TypeScript worker; the plugin documents how to include it.

## Change summary

Explain why JavaScript is absent from the generated webpack worker URL map.

## Best solution

Use the existing shared TypeScript worker for JavaScript. If selecting a subset of languages in MonacoWebpackPlugin, include both javascript and typescript.
