# Issue #4706 — [Bug] Why is there no JavaScript ?

[https://github.com/microsoft/monaco-editor/issues/4706](https://github.com/microsoft/monaco-editor/issues/4706)

## Summary

This is a configuration question rather than a Monaco defect: JavaScript intentionally shares the TypeScript worker, which is absent because the selected languages did not include its TypeScript instantiator.

## Change summary

Explain why the generated webpack worker mapping contains no JavaScript worker.

## Best solution

Include `typescript` in `MonacoWebpackPlugin`'s `languages` option when including `javascript`; the plugin will then map both labels to the generated TypeScript worker.
