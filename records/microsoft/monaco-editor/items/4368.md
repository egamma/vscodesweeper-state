# Issue #4368 — [Bug] wordWrap: "off" not working for lines containing >~10k characters

[https://github.com/microsoft/monaco-editor/issues/4368](https://github.com/microsoft/monaco-editor/issues/4368)

## Summary

Fixed in the VS Code editor core and shipped with Monaco v0.53.0: long-line detection no longer overrides `wordWrap: "off"` unless screen-reader mode is enabled.

## Change summary

Prevent lines longer than approximately 10,000 characters from wrapping when `wordWrap` is explicitly set to `off`.

## Best solution
