# Issue #4368 — [Bug] wordWrap: "off" not working for lines containing >~10k characters

[https://github.com/microsoft/monaco-editor/issues/4368](https://github.com/microsoft/monaco-editor/issues/4368)

## Summary

The unconditional long-line wrapping was fixed upstream and the fix is included in current Monaco main. Source tracing shows the supplied configuration no longer forces wrapping merely because a line reaches 10,000 characters; screen-reader mode retains an explicit exception.

## Change summary

Lines around 10,000 characters wrap despite the editor being configured with wordWrap: "off".

## Best solution

Treat the default-mode defect as fixed by the adopted VS Code change. Preserve screen-reader behavior, with wordWrapOverride1: "off" available when an embedder needs to disable that wrapping too.
