# Issue #3877 — [Bug] Folding button is not active enough

[https://github.com/microsoft/monaco-editor/issues/3877](https://github.com/microsoft/monaco-editor/issues/3877)

## Summary

The folding control still advertises a pointer cursor over pixels that the current mouse handler deliberately rejects. This confirmed, team-authored Backlog issue should remain open and be fixed in the VS Code editor core.

## Change summary

Make every pointer-active part of the folding control respond to clicks.

## Best solution

Align the folding icon's CSS hit area with the gutter checks in `src/vs/editor/contrib/folding/browser/folding.ts` in microsoft/vscode, then let the fix flow into Monaco with the next release cut.
