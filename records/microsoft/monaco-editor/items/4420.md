# Issue #4420 — Adjust suggest filter in monaco editor

[https://github.com/microsoft/monaco-editor/issues/4420](https://github.com/microsoft/monaco-editor/issues/4420)

## Summary

The existing CompletionItem.filterText API supports filtering suggestions by alternate subword text, making this an integration question rather than a missing editor capability.

## Change summary

Configure completion suggestions so they match supplied subwords instead of only their displayed labels.

## Best solution

Set CompletionItem.filterText for each provided suggestion to the text against which Monaco should match; no editor-core change is needed.
