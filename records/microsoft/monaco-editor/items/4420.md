# Issue #4420 — Adjust suggest filter in monaco editor

[https://github.com/microsoft/monaco-editor/issues/4420](https://github.com/microsoft/monaco-editor/issues/4420)

## Summary

The screenshots request contiguous matching rather than scattered-character matches. Existing suggestion controls do not directly provide that filtering mode; route to suggest for an editor-core decision.

## Change summary

Allow completion filtering to exclude candidates that match only noncontiguous characters of the typed text.

## Best solution

Consider an opt-in contiguous-match mode in the VS Code editor core, preserving default fuzzy matching. A small completion-provider playground example would clarify whether the desired contract is prefix-only or substring matching.
