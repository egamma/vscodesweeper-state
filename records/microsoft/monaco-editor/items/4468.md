# Issue #4468 — [Bug] Wrong cursor position if editor has `transform: scale(0.4);`

[https://github.com/microsoft/monaco-editor/issues/4468](https://github.com/microsoft/monaco-editor/issues/4468)

## Summary

The playground demonstrates incorrect mouse hit-testing when an ancestor scales the editor, with four independent confirmations. The earlier scaling fix covered related rendering and hit-testing defects but did not resolve this between-line cursor placement case.

## Change summary

Clicking between lines in an editor scaled with CSS places the cursor roughly two lines away.

## Best solution

Fix scale-aware vertical mouse hit-testing in the VS Code editor core, likely alongside the mouse-coordinate handling previously changed by microsoft/vscode#139282, then pull that fix into Monaco through the normal source update.
