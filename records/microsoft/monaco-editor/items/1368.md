# Issue #1368 — Customizable padding

[https://github.com/microsoft/monaco-editor/issues/1368](https://github.com/microsoft/monaco-editor/issues/1368)

## Summary

A genuine horizontal-padding API gap remains: current editor padding supports only top and bottom. Keep this older, well-supported request open and route it to editor API/rendering.

## Change summary

Allow embedders to configure horizontal editor padding without CSS, gutter, scrollbar, or view-zone workarounds.

## Best solution

Extend `IEditorPaddingOptions` in the VS Code editor core with left/right padding and incorporate it consistently into content layout, wrapping, scrolling, minimap, and scrollbar calculations. Coordinate the left-padding portion with https://github.com/microsoft/vscode/issues/135114 while retaining this broader request as the Monaco tracker.

## Evidence
