# Issue #1368 — Customizable padding

[https://github.com/microsoft/monaco-editor/issues/1368](https://github.com/microsoft/monaco-editor/issues/1368)

## Summary

Custom horizontal padding remains unsupported; the existing padding option covers only top and bottom. Route to editor-core and retain this report because the verified related requests do not own its full scope.

## Change summary

Allow configurable editor padding without gutter, scrollbar, or view-zone workarounds, including when horizontal scrolling is enabled.

## Best solution

Design horizontal padding in the VS Code editor core and expose it through Monaco's generated options, preserving wrapping, scrolling, and gutter layout. Coordinate with the related upstream requests without losing this report's independently configurable left/right spacing requirements.
