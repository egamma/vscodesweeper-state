# Issue #4821 — [Bug] JSDoc @link tags not processed at all

[https://github.com/microsoft/monaco-editor/issues/4821](https://github.com/microsoft/monaco-editor/issues/4821)

## Summary

The current TypeScript hover adapter still preserves JSDoc link delimiters verbatim. Keep this report open and route it to typescript; the newer formatting report explicitly leaves link rendering to this issue.

## Change summary

Render JSDoc {@link foo} as readable reference text instead of exposing the raw tag syntax in JavaScript and TypeScript hovers.

## Best solution

Make Monaco's TypeScript documentation adapter display JSDoc references as readable text, with symbol navigation optional as the reporter requested. This belongs in src/languages/features/typescript/languageFeatures.ts, not the generated editor core or the upstream TypeScript service.
