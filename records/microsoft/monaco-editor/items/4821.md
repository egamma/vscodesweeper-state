# Issue #4821 — [Bug] JSDoc @link tags not processed at all

[https://github.com/microsoft/monaco-editor/issues/4821](https://github.com/microsoft/monaco-editor/issues/4821)

## Summary

Still present on main: Monaco flattens TypeScript's structured JSDoc link display parts into their raw text, reconstructing `{@link foo}` verbatim. Route this confirmed hover-rendering bug to the TypeScript area.

## Change summary

Process JSDoc `@link` tags in JavaScript and TypeScript hover documentation instead of displaying their source syntax.

## Best solution

Update the TypeScript hover documentation conversion in `src/languages/features/typescript/languageFeatures.ts` to interpret `link`, `linkName`, and `linkText` display parts, rendering readable text and resolved symbol links where supported.
