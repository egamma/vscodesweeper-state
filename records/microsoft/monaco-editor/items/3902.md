# Issue #3902 — [Bug] glyphMargin: true and box-sizing: border-box makes line number gap

[https://github.com/microsoft/monaco-editor/issues/3902](https://github.com/microsoft/monaco-editor/issues/3902)

## Summary

The box-model conflict remains visible in the current vscode editor-core source. The issue is already correctly classified and routed, so it should remain open for an editor-core fix.

## Change summary

Sticky-scroll line numbers develop a gap when glyph margins and a host-page border-box reset are enabled together.

## Best solution

Make sticky-scroll gutter sizing independent of host-page box-sizing rules in the vscode editor core, then carry that fix into the next Monaco release.
