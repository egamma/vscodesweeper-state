# Issue #4783 — [Bug] Incorrect Syntax Highlighting for 'End Sub' and 'Sub' in VB.NET Code

[https://github.com/microsoft/monaco-editor/issues/4783](https://github.com/microsoft/monaco-editor/issues/4783)

## Summary

The green rendering is intentional theme styling for VB block-pair keywords, not comment tokenization. Both `Sub` and `End Sub` are explicitly classified as `keyword.tag-sub.vb` on current main.

## Change summary

Render the VB.NET `Sub` and `End Sub` block keywords using a different color.

## Best solution

Keep the existing block-pair token classification; embedders wanting conventional keyword coloring can override `keyword.tag-sub.vb` in their Monaco theme.
