# Issue #3202 — [Bug] Programmatic update of a model doesn't remove error markers

[https://github.com/microsoft/monaco-editor/issues/3202](https://github.com/microsoft/monaco-editor/issues/3202)

## Summary

The cross-model marker invalidation gap remains in current source: changing B schedules validation only for B, leaving A's existing markers untouched. Keep this correctly labeled TypeScript multifile bug open.

## Change summary

Updating an imported TypeScript model should refresh error markers in models that depend on it without requiring an edit to those models.

## Best solution

Make the bundled TypeScript diagnostics adapter refresh affected models when an imported model changes, while preserving diagnostic filtering, visibility settings, and debouncing. This is bounded community-contribution work in Monaco's language integration, not the generated editor core.
