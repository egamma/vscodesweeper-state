# Issue #5207 — [Bug] Typing with backward (RTL) selection fails when editContext: false

[https://github.com/microsoft/monaco-editor/issues/5207](https://github.com/microsoft/monaco-editor/issues/5207)

## Summary

The cited VS Code fix shipped in Monaco v0.56.0 and resolved the reporter's application, but current Safari and Firefox reports demonstrate that the first keystroke can still be dropped through browser-specific textarea fallback paths. Keep this broader issue open and route it to editor input.

## Change summary

Typing over a backward selection with the textarea input path should replace the selection on the first keystroke.

## Best solution

Fix backward-selection direction handling in the VS Code editor core's textarea input path across Firefox and WebKit, then pull that fix into Monaco. This older, broader report should remain open while the browser-specific evidence in https://github.com/microsoft/monaco-editor/issues/5228 and https://github.com/microsoft/monaco-editor/issues/5390 is evaluated and consolidated.
