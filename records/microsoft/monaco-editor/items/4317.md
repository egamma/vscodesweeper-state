# Issue #4317 — [Feature Request] Customise the keys to trigger inlineCompletion

[https://github.com/microsoft/monaco-editor/issues/4317](https://github.com/microsoft/monaco-editor/issues/4317)

## Summary

Selective control over automatic inline-completion triggers remains missing: the current controller explicitly triggers on DeleteLeft, and the public options do not expose command exclusions. Route to inline-completions; the underlying change belongs in the VS Code editor core.

## Change summary

Allow embedders to exclude Backspace and other selected commands from automatically triggering inline completions.

## Best solution

Support selective automatic-trigger configuration in the VS Code editor core and expose it through Monaco's generated API. Disabling automatic suggestions and invoking the explicit trigger provides manual control, but does not preserve automatic typing suggestions while excluding Backspace.
