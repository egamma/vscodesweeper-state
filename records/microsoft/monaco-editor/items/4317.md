# Issue #4317 — [Feature Request] Customise the keys to trigger inlineCompletion

[https://github.com/microsoft/monaco-editor/issues/4317](https://github.com/microsoft/monaco-editor/issues/4317)

## Summary

This is an editor-core trigger-policy request already covered by the open VS Code issue tracking when inline completions should appear, including the exact request to suppress them while backspacing.

## Change summary

Allow embedders to prevent selected editing commands, such as DeleteLeft, from automatically triggering inline completions.

## Best solution

Consolidate the request into https://github.com/microsoft/vscode/issues/272812 and implement any trigger filtering in the VS Code editor core; Monaco will inherit it in a subsequent source update.
