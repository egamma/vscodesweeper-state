# Issue #5240 — [Bug] Links in hover tooltips show wrong link target on account of empty href attribute

[https://github.com/microsoft/monaco-editor/issues/5240](https://github.com/microsoft/monaco-editor/issues/5240)

## Summary

The empty-href defect is fixed in the VS Code renderer and included in Monaco v0.57.0 and current main. Source tracing confirms the reported HTTPS hover link now retains its real href while click handling remains intact.

## Change summary

Hover links should expose their actual destination to browser link previews and native link actions instead of the current page URL.

## Best solution

Treat the reported empty-href behavior as fixed and recommend Monaco v0.57.0 or later. The playground's separate suppression of right-click menus is not changed by this fix.
