# Issue #5240 — [Bug] Links in hover tooltips show wrong link target on account of empty href attribute

[https://github.com/microsoft/monaco-editor/issues/5240](https://github.com/microsoft/monaco-editor/issues/5240)

## Summary

The empty `href` is intentional editor-core behavior, but Monaco’s browser embedding exposes a real gap in native URL preview and context-menu actions. Route this as an editor-core hover improvement rather than a broken-link bug.

## Change summary

Allow ordinary web links in hover Markdown to expose their real target through native browser link interactions.

## Best solution

Evaluate in the VS Code editor core whether sanitized HTTP(S) links can retain a usable `href` while preserving `data-href`, controlled activation, and link-trust protections; Monaco will inherit that change with a subsequent release.
