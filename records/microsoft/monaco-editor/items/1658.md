# Issue #1658 — PHP: support for code snippets without the starting `<?php` token

[https://github.com/microsoft/monaco-editor/issues/1658](https://github.com/microsoft/monaco-editor/issues/1658)

## Summary

The bundled PHP grammar still requires an opening tag; snippet highlighting remains a valid accepted enhancement. Keep this request open while preserving the existing mixed HTML/PHP behavior.

## Change summary

Provide PHP syntax highlighting for snippets that omit the opening <?php token.

## Best solution

Offer an opt-in PHP snippet experience in the Monaco-owned grammar without changing ordinary PHP files. This looks suitable for a community PR once the public way to select snippet mode is agreed.
