# Issue #1658 — PHP: support for code snippets without the starting `<?php` token

[https://github.com/microsoft/monaco-editor/issues/1658](https://github.com/microsoft/monaco-editor/issues/1658)

## Summary

The requested snippet mode remains absent on current main. The existing Backlog, feature-request, help wanted, and grammars routing is appropriate.

## Change summary

Provide built-in PHP syntax highlighting for snippets that omit the opening `<?php` token.

## Best solution

Add a separate `php-snippet` language registration that starts directly in the existing PHP tokenizer rules without changing normal PHP/HTML behavior. This remains suitable for a community contribution.

## Evidence

- **current source:** src/languages/definitions/php/php.ts still starts the root tokenizer in HTML mode and enters PHP only after matching `<?`, while its reusable `phpRoot` state contains the desired PHP token rules.
- **registration gap:** src/languages/definitions/php/register.ts registers only the `php` language; no `php-snippet` or equivalent language exists on current main.
- **maintainer direction:** A maintainer explained that changing the existing root would break PHP files containing HTML and identified a separate snippet language as the appropriate approach: https://github.com/microsoft/monaco-editor/issues/1658#issuecomment-564592680.
- **workaround limitation:** The community workaround copies the PHP rules into a custom language, demonstrating feasibility but not providing the requested built-in capability: https://github.com/microsoft/monaco-editor/issues/1658#issuecomment-808868882.
