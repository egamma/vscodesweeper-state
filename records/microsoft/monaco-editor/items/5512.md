# Issue #5512 — [Bug] Hover and suggest widgets are placed off-screen when the host page is scrolled

[https://github.com/microsoft/monaco-editor/issues/5512](https://github.com/microsoft/monaco-editor/issues/5512)

## Summary

The coordinate mismatch remains in both the bundled VS Code revision and current upstream source. Route to editor-hover and suggest; the supplied playground steps are sufficient, and no verified canonical owns both affected widgets.

## Change summary

Hover and suggestion widgets choose off-screen placement when the host document is vertically scrolled.

## Best solution

Correct viewport-space availability calculations for both widgets in microsoft/vscode, then bring the fix into Monaco through its editor-source update. Preserve existing placement preferences when the host page is not scrolled.
