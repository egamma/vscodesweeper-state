# Issue #4558 — [Bug] incorrect hightlight of markdown code when an image is a link

[https://github.com/microsoft/monaco-editor/issues/4558](https://github.com/microsoft/monaco-editor/issues/4558)

## Summary

Still present on main: Monaco's Markdown tokenizer treats the inner image terminator as the end of the outer link, producing incorrect highlighting for linked images. Route this to the basic-language grammar and tokenization owners.

## Change summary

Markdown linked-image syntax such as `[![](./x.png)](./x.html)` receives mismatched highlighting.

## Best solution

Update the linked-image handling in `src/languages/definitions/markdown/markdown.ts` so nested image syntax is tokenized without terminating the outer link at the inner `]`, and add a regression case to `markdown.test.ts`.
