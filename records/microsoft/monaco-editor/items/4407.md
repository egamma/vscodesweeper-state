# Issue #4407 — [Feature Request] Close peek problem/definition window programmatically

[https://github.com/microsoft/monaco-editor/issues/4407](https://github.com/microsoft/monaco-editor/issues/4407)

## Summary

The requested programmatic close is already supported through the editor's `trigger` API and the registered `closeMarkersNavigation` command. Marker navigation also closes automatically when the editor model changes.

## Change summary

Provide an API for embedders to close the problem-marker peek widget programmatically.

## Best solution

Use `editor.trigger('', 'closeMarkersNavigation', {})` for the supported programmatic-close path. Focus-preserving closure currently requires the internal marker-controller contribution and would merit a narrower API request if needed.
