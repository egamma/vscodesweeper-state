## Change summary

## Best solution

For the supplied provider, use a quote-aware CompletionItem.range and matching filterText so the completion replaces the typed quote and word together. Clarify whether automatic handling beyond provider-controlled ranges is desired; that behavior belongs in the microsoft/vscode editor core.
