# Issue #2136 — Invalid completion items when using dots in completion item label

[https://github.com/microsoft/monaco-editor/issues/2136](https://github.com/microsoft/monaco-editor/issues/2136)

## Summary

The gap remains on current main: TypeScript still generates identifier completions for unchecked JavaScript files, and Monaco forwards them without a preference capable of honoring `wordBasedSuggestions`. Keep this canonical report open pending an upstream TypeScript option and Monaco integration.

## Change summary

Prevent TypeScript-generated document identifier completions from appearing when JavaScript word-based suggestions are disabled.

## Best solution

Add a TypeScript `UserPreferences` option that suppresses unchecked-file identifier completions, then pass it through `src/languages/features/typescript/tsWorker.ts` according to Monaco's `wordBasedSuggestions` setting.

## Evidence

- **current TypeScript behavior:** In `src/languages/features/typescript/lib/typescriptServices.js`, unchecked JavaScript completions call `getJSCompletionEntries`, which adds every identifier from the source file as a `warning` completion (`isFromUncheckedFile: true`).
- **missing upstream preference:** The bundled TypeScript `UserPreferences` declaration in `src/languages/features/typescript/lib/typescriptServices.d.ts` has no option for suppressing unchecked-file identifier completions.
- **Monaco forwarding:** `src/languages/features/typescript/tsWorker.ts` calls `getCompletionsAtPosition(fileName, position, undefined)`, and `languageFeatures.ts` maps every returned entry into Monaco suggestions without filtering these identifiers.
- **confirmed ownership:** A contributor captured the TypeScript completion response and described the required upstream preference plus Monaco integration at https://github.com/microsoft/monaco-editor/issues/2136#issuecomment-886025174.
- **canonical status:** https://github.com/microsoft/monaco-editor/issues/1980 was closed explicitly as a duplicate of this issue, so this report remains the canonical Monaco tracking item.
