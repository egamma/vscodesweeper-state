# Issue #3221 — [Bug] Wrong syntax highlighting for yaml

[https://github.com/microsoft/monaco-editor/issues/3221](https://github.com/microsoft/monaco-editor/issues/3221)

## Summary

Both reported YAML highlighting defects were fixed by merged grammar changes shipped in v0.37.0. Tracing the supplied examples through the current grammar confirms that embedded hashes remain scalar text and colons inside comments no longer disrupt highlighting.

## Change summary

YAML highlighting incorrectly treats an embedded hash as a comment and misclassifies comments containing a colon.

## Best solution

Treat this as resolved by the YAML changes in https://github.com/microsoft/monaco-editor/pull/3864, shipped in v0.37.0; retain the current grammar behavior.
