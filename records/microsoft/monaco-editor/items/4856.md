# Issue #4856 — [Bug] Rust raw strings with `br` or `cr` prefix are not treated as raw strings

[https://github.com/microsoft/monaco-editor/issues/4856](https://github.com/microsoft/monaco-editor/issues/4856)

## Summary

Verified duplicate of the open Rust raw-string highlighting issue, which explicitly includes the same `br` and `cr` prefix defect.

## Change summary

Rust raw byte and C-string literals using `br` or `cr` prefixes are tokenized as escaped strings rather than raw strings.

## Best solution

Consolidate this case into https://github.com/microsoft/monaco-editor/issues/2897 and extend the Rust Monarch tokenizer in `src/languages/definitions/rust/rust.ts` to recognize all supported raw-string prefixes.
