# Issue #4864 — [Bug] Suggestions not listing after entering "_"

[https://github.com/microsoft/monaco-editor/issues/4864](https://github.com/microsoft/monaco-editor/issues/4864)

## Summary

This is expected completion filtering rather than a Monaco defect: `_` filters out items whose matching text does not contain that prefix. The existing `CompletionItem.filterText` API addresses the use case, and the reporter confirmed the workaround solved it.

## Change summary

Show completion suggestions after typing `_` even when the displayed item labels do not begin with that character.

## Best solution

Keep the current filtering behavior and set each completion item's `filterText` to include `_` when suggestions should match that prefix.
