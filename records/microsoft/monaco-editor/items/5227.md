# Issue #5227 — [Bug] Cannot hide inline edit menu by setting `showInlineEditMenu` to false

[https://github.com/microsoft/monaco-editor/issues/5227](https://github.com/microsoft/monaco-editor/issues/5227)

## Summary

The current editor-core source still creates the gutter menu unconditionally for inline edits; `showInlineEditMenu` only gates the menu for ghost-text suggestions. Keep this team-authored report open and route it to inline completions.

## Change summary

Setting `showInlineEditMenu: false` does not hide the inline-edit gutter menu in standalone Monaco.

## Best solution

Update the vscode editor core's inline-suggestions view so providers can suppress the gutter menu for an inline edit, while preserving the existing opt-in behavior for ghost-text suggestions; Monaco will receive the fix in a subsequent source cut.
