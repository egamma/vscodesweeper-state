# Issue #4744 — [Feature Request] Ability to remove the limit on marker lines and hovers

[https://github.com/microsoft/monaco-editor/issues/4744](https://github.com/microsoft/monaco-editor/issues/4744)

## Summary

The 500-marker cap remains hardcoded in the current VS Code editor core, and this issue documents intentional high-volume informational markers not addressed by the earlier diagnostics-focused rationale. Keep this older, better-discussed report open as the canonical request and route it to editor-core.

## Change summary

Allow embedders to configure or remove the 500-marker decoration limit so all markers remain decorated and hoverable.

## Best solution

Add a configurable marker-decoration limit with a conservative default in the VS Code editor core at src/vs/editor/common/services/markerDecorationsService.ts, expose it through the editor options API, and let it flow into Monaco. The newer https://github.com/microsoft/monaco-editor/issues/5176 should consolidate into this issue.
