# Issue #4744 — [Feature Request] Ability to remove the limit on marker lines and hovers

[https://github.com/microsoft/monaco-editor/issues/4744](https://github.com/microsoft/monaco-editor/issues/4744)

## Summary

Keep the request open and route it to the editor API/core area: increasing a hardcoded limit does not provide the requested opt-out, and the discussion identifies an informational-marker use case beyond ordinary diagnostics.

## Change summary

Allow embedders to remove or configure marker-decoration limits while retaining underlines and copyable informational hovers in read-only diff editors.

## Best solution

Decide whether informational annotations should use a configurable marker budget or a documented decoration-based alternative that preserves the requested hover and copying behavior. Any marker-limit API change belongs in the microsoft/vscode editor core and should flow into Monaco through its release pipeline.
