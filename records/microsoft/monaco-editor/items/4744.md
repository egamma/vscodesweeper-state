# Issue #4744 — [Feature Request] Ability to remove the limit on marker lines and hovers

[https://github.com/microsoft/monaco-editor/issues/4744](https://github.com/microsoft/monaco-editor/issues/4744)

## Summary

Consolidate with the older, open VS Code issue tracking silently omitted marker decorations and requesting a configurable limit. The current core raises the ceiling to 5,000, but does not remove the underlying restriction.

## Change summary

Allow embedders to remove the marker-decoration limit so large read-only diff models retain annotation underlines and hovers.

## Best solution

Resolve configurability in the shared editor core through https://github.com/microsoft/vscode/issues/186604, preserving this report's informational-annotation and read-only diff use cases. Monaco should inherit the resulting behavior rather than maintain a separate core implementation.
