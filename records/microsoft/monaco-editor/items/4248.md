# Issue #4248 — [Feature Request] Request for Editor.focus method optional params support

[https://github.com/microsoft/monaco-editor/issues/4248](https://github.com/microsoft/monaco-editor/issues/4248)

## Summary

The public focus API still cannot accept browser focus options, and subsequent commenters report needing internal-DOM workarounds. The older Safari report is related but does not own the broader API request, including focusVisible.

## Change summary

Allow editor.focus() to accept browser focus options such as preventScroll and focusVisible.

## Best solution

Consider an optional focus-options contract in the microsoft/vscode editor core that works across textarea and native EditContext input paths while preserving existing no-argument behavior. Monaco would inherit the API through its generated editor sources.
