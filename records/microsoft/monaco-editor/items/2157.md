# Issue #2157 — Add possibility to remove keybindings

[https://github.com/microsoft/monaco-editor/issues/2157](https://github.com/microsoft/monaco-editor/issues/2157)

## Summary

Implemented and shipped in v0.34.1: the public `monaco.editor.addKeybindingRule(s)` API supports removing default keybindings without accessing the private keybinding service.

## Change summary

Expose a supported API for removing or overriding Monaco's default keybindings.

## Best solution

Use `monaco.editor.addKeybindingRule({ keybinding: 0, command: "-<commandId>" })` to remove a default binding, and dispose the returned registration when it is no longer needed.
