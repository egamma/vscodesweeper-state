# Issue #2157 — Add possibility to remove keybindings

[https://github.com/microsoft/monaco-editor/issues/2157](https://github.com/microsoft/monaco-editor/issues/2157)

## Summary

Public keybinding removal is available through monaco.editor.addKeybindingRule(s), shipped in v0.34.1. The additional command-palette filtering request remains separately tracked by an open issue.

## Change summary

Provide a supported way to remove default keybindings without accessing private editor services.

## Best solution

Use the shipped public keybinding API instead of _standaloneKeybindingService. Preserve the separate request to hide command-palette actions in https://github.com/microsoft/monaco-editor/issues/660.

- **Proposed comment:**

  > Thanks for the report and discussion. Since v0.34.1, default keybindings can be removed using the public API: `monaco.editor.addKeybindingRule({ keybinding: 0, command: '-editor.action.inspectTokens' })`. This replaces the private-service call and requires no dummy handler. The API was added in https://github.com/microsoft/vscode/commit/f195c00f1e471b14778012b020472ce88484c8af, so the keybinding-removal request is implemented.
  > 
  > This does not hide the action from the command palette; that separate request remains tracked in https://github.com/microsoft/monaco-editor/issues/660.
