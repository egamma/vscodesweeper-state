# Issue #2157 — Add possibility to remove keybindings

[https://github.com/microsoft/monaco-editor/issues/2157](https://github.com/microsoft/monaco-editor/issues/2157)

## Summary

Public keybinding-removal rules now cover the shortcut portion, but the discussion also requests removing built-in actions from the command palette. That separate capability is not covered by keybinding rules, so the whole issue cannot be treated as implemented.

## Change summary

Provide supported customization for disabling built-in keybindings and removing unwanted command-palette actions without accessing private services.

## Best solution

Use monaco.editor.addKeybindingRule for shortcut removal, and clarify the remaining supported action-filtering contract in the VS Code standalone editor sources. The command-palette portion is related to https://github.com/microsoft/monaco-editor/issues/135, but that report's disabled-feature filtering does not demonstrably own this issue's full scope.

- **Existing public shortcut capability:** https://github.com/microsoft/monaco-editor/blob/gh-pages/node_modules/monaco-editor/monaco.d.ts lines 1024–1039 declare IKeybindingRule and addKeybindingRule(s). https://github.com/microsoft/vscode/blob/main/src/vs/editor/standalone/browser/standaloneEditor.ts forwards these rules to StandaloneKeybindingService.addDynamicKeybindings; https://github.com/microsoft/vscode/blob/main/src/vs/platform/keybinding/common/keybindingResolver.ts lines 122–168 process negative command IDs as default-keybinding removals.
- **Palette visibility remains separate:** https://github.com/microsoft/vscode/blob/main/src/vs/editor/standalone/browser/quickAccess/standaloneCommandsQuickAccess.ts delegates to getCodeEditorCommandPicks. https://github.com/microsoft/vscode/blob/main/src/vs/editor/contrib/quickAccess/browser/commandsQuickAccess.ts lines 35–57 builds those picks from getSupportedActions(), independently of keybinding-removal rules. The shipped declarations contain no removeAction or removeCommand API.
- **Canonical search:** Public GitHub searches found https://github.com/microsoft/monaco-editor/issues/135 open and older, but it requests filtering commands according to disabled editor features rather than arbitrary action removal. https://github.com/microsoft/monaco-editor/issues/3623 is younger and requests per-editor keybinding rules, a different remaining capability; neither establishes a full-scope duplicate under the re-review bar.
