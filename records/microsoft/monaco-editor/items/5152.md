# Issue #5152 — Deprecate Monaco Editor Webpack Plugin

[https://github.com/microsoft/monaco-editor/issues/5152](https://github.com/microsoft/monaco-editor/issues/5152)

## Summary

Keep this maintainer-authored transition request open and route it to webpack-plugin. Feature-selection entry points have shipped, but the checkout still documents and uses the Monaco-specific plugin; replacement worker tooling alone does not complete its deprecation.

## Change summary

Deprecate the Monaco-specific webpack plugin in favor of explicit feature imports and bundler-independent worker entry discovery.

## Best solution

Complete the migration to supported feature-registration imports and generic ESM worker-entry plugins across webpack, Rollup/Vite, and esbuild, then document the webpack plugin's deprecation. Preserve this issue for the remaining transition rather than treating the completed feature-selection prerequisite as the whole request.
