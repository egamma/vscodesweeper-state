# Issue #2647 — Monarch: assigning multiple tokens to a capturing group

[https://github.com/microsoft/monaco-editor/issues/2647](https://github.com/microsoft/monaco-editor/issues/2647)

## Summary

The requested multiple independent scopes per token remain unsupported, but the team explicitly declined that capability in the broader related issue. Propose an out-of-scope close based on that precedent, not age or an equivalent workaround.

## Change summary

Allow one Monarch capturing group to receive multiple independently themed scopes for nested Markdown formatting.

## Best solution

Apply the existing decision against multiple independent classes per token to this Monarch-specific request. Any reconsideration should explicitly address synchronous grammar-based highlighting and colorizer output, which semantic tokens do not satisfy for the reporter.
