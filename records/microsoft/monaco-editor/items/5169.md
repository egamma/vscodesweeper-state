## Summary

The recovery trigger is not concrete enough to reproduce, although current theme-service code supports a detached-stylesheet hypothesis. Request a minimal recovery example; the merged Insomnia workaround does not establish a Monaco fix.

## Change summary

DiffEditor reportedly loses theme variables after renderer recovery or prolonged uptime, and reapplying the theme does not restore styling.

## Best solution

Establish exactly which recovery operation removes or invalidates the theme stylesheet and whether variables disappear on the editor itself. If standalone theme-service recovery is defective, fix it in microsoft/vscode's editor core rather than relying on application-level color fallbacks.
