# Issue #4457 — [Bug] Support CSS :has() pseudo-class

[https://github.com/microsoft/monaco-editor/issues/4457](https://github.com/microsoft/monaco-editor/issues/4457)

## Summary

The false syntax error for h1:has(~ span) is resolved by the upstream parser fix adopted in Monaco v0.50.0 and retained on main. The suggested duplicate is closed, so this should be closed as completed rather than duplicate.

## Change summary

Valid CSS :has() arguments beginning with a combinator incorrectly produce a ') expected' diagnostic.

## Best solution

Keep the adopted CSS language-service fix; embedders using v0.47.0 should upgrade to Monaco v0.50.0 or later.
