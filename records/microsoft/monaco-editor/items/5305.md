# Issue #5305 — [Feature Request] Support workspace configuration in MonacoLspClient

[https://github.com/microsoft/monaco-editor/issues/5305](https://github.com/microsoft/monaco-editor/issues/5305)

## Summary

This remains a valid gap in the native LSP client: the protocol types exist, but MonacoLspClient neither advertises workspace configuration capabilities nor exposes configuration request and change handling.

## Change summary

Add workspace configuration capabilities and an API for responding to workspace/configuration requests and sending workspace/didChangeConfiguration notifications.

## Best solution

Add a first-class configuration feature under monaco-lsp-client/src/adapters that accepts a settings provider, advertises workspace.configuration and didChangeConfiguration.dynamicRegistration, handles workspace/configuration, and exposes a supported way to notify the server after settings change. This looks suitable for a community PR.
