# Issue #4662 — [Bug] Handlebars syntax highlighting broken since version 0.35.0

[https://github.com/microsoft/monaco-editor/issues/4662](https://github.com/microsoft/monaco-editor/issues/4662)

## Summary

Still present on main: Handlebars declares overlapping `{{`/`}}` and `{`/`}` bracket pairs, so bracket-pair colorization can interpret valid triple braces as mismatched. The tokenizer handles triple braces correctly, localizing the regression to bracket highlighting rather than syntax tokenization.

## Change summary

Valid Handlebars expressions using triple curly braces receive incorrect bracket colors, including an unmatched-bracket error color.

## Best solution

Adjust the Handlebars language configuration or bracket-pair parser behavior so `{{{ value }}}` is recognized without mismatched-bracket decoration, while preserving ordinary Handlebars and JavaScript-style brace handling. Add bracket-colorization coverage alongside the existing triple-brace tokenization case.
