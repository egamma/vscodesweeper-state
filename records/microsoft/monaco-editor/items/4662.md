# Issue #4662 — [Bug] Handlebars syntax highlighting broken since version 0.35.0

[https://github.com/microsoft/monaco-editor/issues/4662](https://github.com/microsoft/monaco-editor/issues/4662)

## Summary

Keep open: the supplied sample and version comparison suffice to retest, but current rendering has not been verified since the reported 0.35.0 regression. Current Handlebars configuration still omits triple-brace pairs despite the tokenizer recognizing them, providing a concrete investigation lead rather than proof of resolution.

## Change summary

Valid Handlebars triple-brace expressions acquire unexpected red bracket highlighting, while other delimiters change from black to blue.

## Best solution

Investigate the interaction between Monaco's Handlebars language configuration and bracket-pair colorization so valid triple-brace expressions are not marked unmatched. Distinguish that defect from ordinary bracket colorization before changing general delimiter colors.
