# Issue #3378 — [Bug] Cannot disable suggestions for only one editor on page

[https://github.com/microsoft/monaco-editor/issues/3378](https://github.com/microsoft/monaco-editor/issues/3378)

## Summary

Keep open for independent word-suggestion configuration: the current API explicitly makes wordBasedSuggestions global, so one editor changing it affects the others. The accepted Backlog item should not be declined, and the linked keybinding reports do not cover the same observable problem.

## Change summary

Allow an editable XML editor to suggest only its own words without another editor's suggestion settings disabling those completions.

## Best solution

Support independent word-suggestion configuration in the VS Code standalone editor sources that Monaco bundles. The existing currentDocument value limits the source of words, but does not isolate enablement between editor instances.
