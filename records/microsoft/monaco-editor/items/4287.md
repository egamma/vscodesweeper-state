# Issue #4287 — [Feature Request] Support non-global `MonacoEnvironment`

[https://github.com/microsoft/monaco-editor/issues/4287](https://github.com/microsoft/monaco-editor/issues/4287)

## Summary

Keep open: worker initialization still prioritizes the shared MonacoEnvironment global, so independently embedded Monaco versions cannot isolate their worker configuration. This team-authored request remains necessary; no verified fix or same-symptom canonical was found.

## Change summary

Allow independently loaded Monaco versions to configure their workers without sharing the page-global MonacoEnvironment.

## Best solution

Provide library-scoped worker configuration that takes precedence over the global while preserving the global fallback for existing embedders. Coordinate Monaco's language-worker helper with the VS Code-derived editor worker API so isolation covers both worker paths.

## Evidence

- **Remaining configuration collision:** src/internal/common/workers.ts:getWorker reads globalThis.MonacoEnvironment and returns its getWorker or getWorkerUrl result before considering descriptor.createWorker. A host's global therefore overrides another bundled copy's worker factory.
- **Existing capability is only partial:** src/languages/features/typescript/workerManager.ts:WorkerManager._getClient supplies a module-relative createWorker callback, but src/internal/common/workers.ts treats it as a fallback after the global. This does not satisfy the requested scoped configuration precedence.
- **Public integration boundary:** docs/integrate-esm.md documents global self.MonacoEnvironment configuration, while src/editor.ts re-exports monaco-editor-core/esm/vs/editor/editor.api. No setMonacoEnvironment implementation was found in the checkout; the full editor-core API is imported rather than maintained here.
- **Related request is not a canonical:** https://github.com/microsoft/monaco-editor/issues/2605 is open and requests native worker loading to reduce bundler setup. Its body and discussion do not establish ownership of the same observable problem: incompatible worker selection when separate Monaco versions share one page global.
