# Issue #4287 — [Feature Request] Support non-global `MonacoEnvironment`

[https://github.com/microsoft/monaco-editor/issues/4287](https://github.com/microsoft/monaco-editor/issues/4287)

## Summary

The integration gap remains on current main: worker creation still reads only the process-wide `globalThis.MonacoEnvironment`, so independently bundled Monaco versions cannot provide isolated worker configurations. The existing `integration` label already routes this team-authored request appropriately.

## Change summary

Allow each Monaco instance or module copy to configure its worker environment without sharing the global `MonacoEnvironment` object.

## Best solution

Add a module-scoped environment registration API used by `src/internal/common/workers.ts`, while retaining `globalThis.MonacoEnvironment` as a compatibility fallback. This looks suitable for a focused community contribution after the API shape and lifecycle semantics are agreed.
