# Issue #3873 — [Bug] lightbulb in diff editor with one window is always showing

[https://github.com/microsoft/monaco-editor/issues/3873](https://github.com/microsoft/monaco-editor/issues/3873)

## Summary

Still present in the current vscode editor core: the inline diff deleted-code margin creates and reveals its lightbulb without consulting the editor's lightbulb setting. The issue already has the correct bug and diff-editor routing labels.

## Change summary

The inline diff editor displays a deleted-code action lightbulb even when lightbulbs are disabled.

## Best solution

Update `InlineDiffDeletedCodeMargin` in the vscode editor core to honor `EditorOption.lightbulb` when creating or revealing the deleted-code action glyph, then pull that fix into the next Monaco release.
