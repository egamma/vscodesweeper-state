## Summary

Keep open: current VS Code source still creates the inline deleted-line lightbulb and shows it on hover without checking the lightbulb configuration. The existing diff-editor label is appropriate, and no verified canonical or fixing commit was found.

## Change summary

Inline diff deleted lines show a lightbulb on hover despite the embedder disabling lightbulbs.

## Best solution

Resolve the inline deleted-code action control's configuration in the microsoft/vscode editor core, preserving access to copy/revert actions while providing a supported way to suppress the icon. Monaco should inherit that change through its generated editor sources.
