## Summary

Verified duplicate of the older open issue tracking the same uncaught cancellation during continuous pasting. Current vscode editor-core source still contains the cancellation path, so the downstream Compiler Explorer evidence should be consolidated into the canonical issue.

## Change summary

Rapid repeated pasting emits an unhandled `Canceled: Canceled` promise rejection.

## Best solution

Consolidate on https://github.com/microsoft/monaco-editor/issues/4389 and fix the vscode editor core so cancellation of an in-flight paste operation is consumed instead of reaching the global unhandled-rejection handler.
