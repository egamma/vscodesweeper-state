# Issue #2720 — Example of how to load monaco editor with different language

[https://github.com/microsoft/monaco-editor/issues/2720](https://github.com/microsoft/monaco-editor/issues/2720)

## Summary

The editor UI can now be localized in ESM builds, but the central request remains valid: the JSON worker does not configure or expose localization for its diagnostic messages. Route this canonical older request to the JSON and i18n areas.

## Change summary

Provide supported localization and an example for Monaco's language-worker messages, including JSON diagnostics such as "Trailing comma."

## Best solution

Pass locale data into the JSON worker and configure its `@vscode/l10n` dependency before creating the language service, then add a documented ESM example covering both editor UI and JSON diagnostics. This likely belongs in `src/languages/features/json/jsonWorker.ts` and the localization packaging pipeline.
