# Issue #4495 — [Bug] simpleWorker.nls.js fails to load if vs path does not end in 'vs'

[https://github.com/microsoft/monaco-editor/issues/4495](https://github.com/microsoft/monaco-editor/issues/4495)

## Summary

Keep open: the contrasting configurations and independent confirmation provide sufficient steps to retest the incorrect worker URL. AMD localization and worker packaging have changed since the report, but neither a current reproduction nor a concrete fixing commit was verified.

## Change summary

AMD worker localization loading replaces a configured directory not ending in 'vs' with an incorrect 'vs' path.

## Best solution

Determine whether relocated AMD distributions still resolve worker assets against the configured mapping, separating Monaco's packaging from the VS Code-derived worker loader. The documented modern integration is ESM; AMD deprecation alone does not establish that this reported defect was fixed.
