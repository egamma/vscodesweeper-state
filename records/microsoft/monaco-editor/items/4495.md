# Issue #4495 — [Bug] simpleWorker.nls.js fails to load if vs path does not end in 'vs'

[https://github.com/microsoft/monaco-editor/issues/4495](https://github.com/microsoft/monaco-editor/issues/4495)

## Summary

Supporting arbitrary AMD `vs` path layouts is now outside the maintained surface: AMD support was deprecated without support in v0.53.0 and is scheduled for removal.

## Change summary

Allow the AMD worker loader to resolve `simpleWorker.nls.js` when the configured `vs` path does not end in `/vs`.

## Best solution

Migrate the integration to the supported ESM build rather than extending the deprecated AMD loader; retaining `/vs` as the directory suffix remains the workaround for legacy deployments.

## Vision fit

- **Fit:** rejected
- **Reason:** Extending AMD loader compatibility conflicts with Monaco's ESM-first packaging direction and planned removal of the AMD build.
- **Evidence:** The v0.53.0 changelog states that the AMD build is deprecated, unsupported, and that consumers should migrate to ESM; https://github.com/microsoft/monaco-editor/issues/5153 tracks removing it.
