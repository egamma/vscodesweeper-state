# Issue #4709 — [Bug] update automaticLayout by updateOptions does not work

[https://github.com/microsoft/monaco-editor/issues/4709](https://github.com/microsoft/monaco-editor/issues/4709)

## Summary

The underlying bug remains in the current VS Code editor core: changing `automaticLayout` through `updateOptions` updates the option value but does not start or stop the container ResizeObserver. Keep this open and route it to the editor API area.

## Change summary

Changing `automaticLayout` from false to true after editor creation does not enable automatic container resizing.

## Best solution

Update the VS Code editor configuration so changes to `automaticLayout` synchronize the container observer, including both false-to-true and true-to-false transitions; Monaco will receive the fix with a subsequent editor-core update.
