# Issue #4708 — [Feature Request] Monaco's onDidPaste can only obtain text and cannot obtain clipboard objects

[https://github.com/microsoft/monaco-editor/issues/4708](https://github.com/microsoft/monaco-editor/issues/4708)

## Summary

Verified duplicate: the open follow-up issue explicitly covers exposing paste providers so embedders can process clipboard files and MIME types, including this image-upload scenario.

## Change summary

Expose non-text clipboard items when handling paste events so embedders can process pasted images and files.

## Best solution

Consolidate on https://github.com/microsoft/monaco-editor/issues/4728 and expose the document paste-edit provider API there; its data-transfer abstraction provides the file and MIME access needed by this report without expanding the post-paste event.
