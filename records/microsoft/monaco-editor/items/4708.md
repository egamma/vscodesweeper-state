# Issue #4708 — [Feature Request] Monaco's onDidPaste can only obtain text and cannot obtain clipboard objects

[https://github.com/microsoft/monaco-editor/issues/4708](https://github.com/microsoft/monaco-editor/issues/4708)

## Summary

Keep this request open and route it to clipboard/API ownership: the existing paste notification does not establish supported access to pasted image files. The related provider request is newer and does not meet the stronger duplicate bar for this re-reviewed item.

## Change summary

Provide supported access to clipboard image/file objects during paste so embedders can upload them.

## Best solution

Define a supported clipboard-data or paste-provider contract in the VS Code standalone editor core that lets Monaco embedders handle image/file pastes without intercepting internal DOM listeners. Coordinate with the related provider request while preserving this older report's clipboard-access requirement.
