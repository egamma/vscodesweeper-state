# Issue #5226 — [Bug] Typing input loses characters

[https://github.com/microsoft/monaco-editor/issues/5226](https://github.com/microsoft/monaco-editor/issues/5226)

## Summary

The character loss is caused by Striver's popup taking focus from the embedded editor, not by Monaco input handling. It does not reproduce in the Monaco playground or VS Code.

## Change summary

Prevent a host application's timer or popup from interrupting typing in its embedded Monaco editor.

## Best solution

The embedding platform should ensure its popup does not take keyboard focus from the editor, or explicitly restore focus afterward.
