# Issue #2844 — [Feature Request] Document z-index usage and add some logic to it

[https://github.com/microsoft/monaco-editor/issues/2844](https://github.com/microsoft/monaco-editor/issues/2844)

## Summary

Keep open: a documented, predictable stacking contract for embedders remains unaddressed, and a maintainer welcomed a contribution. Related upstream issues address internal layering but do not establish coverage of this report's external-overlay and customization requirements.

## Change summary

Document and rationalize Monaco's stacking layers so embedders can reliably interleave editor widgets, application overlays, and modal dialogs.

## Best solution

Agree on an embedder-facing stacking contract, implement any shared editor-layer changes in microsoft/vscode, and document the supported integration in Monaco. Preserve the distinction between the base editor and overflowing widgets rather than treating an internal-selector workaround as a supported API.
