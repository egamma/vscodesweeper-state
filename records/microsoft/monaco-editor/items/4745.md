# Issue #4745 — [Bug] Python syntax highlighting does not support underscores in numeric literals

[https://github.com/microsoft/monaco-editor/issues/4745](https://github.com/microsoft/monaco-editor/issues/4745)

## Summary

The Python tokenizer on current main still splits numeric literals at underscores. Keep the issue open because the directly linked fixing PR is still open.

## Change summary

Highlight Python numeric literals containing digit separators, such as `100_000`, as single numeric tokens.

## Best solution

Review and land https://github.com/microsoft/monaco-editor/pull/5084, which updates the Python Monarch tokenizer and adds coverage for underscored decimal, hexadecimal, octal, binary, floating-point, and exponent literals.
