# Issue #4601 — [Bug] new support for Python f-strings breaks with multi-line f-strings

[https://github.com/microsoft/monaco-editor/issues/4601](https://github.com/microsoft/monaco-editor/issues/4601)

## Summary

The multiline f-string tokenization defect remains on main, but an open PR directly fixes it and adds regression coverage. Keep the issue open while that implementation is reviewed.

## Change summary

Python multiline f-strings incorrectly terminate tokenization after an embedded expression, corrupting subsequent syntax highlighting.

## Best solution

Review and land https://github.com/microsoft/monaco-editor/pull/5272, which introduces dedicated triple-quoted f-string tokenizer states and tests both quote styles while preserving correct highlighting after the string.
