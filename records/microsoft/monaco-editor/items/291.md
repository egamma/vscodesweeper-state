# Issue #291 — go to definition - different model: loading via http

[https://github.com/microsoft/monaco-editor/issues/291](https://github.com/microsoft/monaco-editor/issues/291)

## Summary

The requested cross-model navigation hook is now public API: `monaco.editor.registerEditorOpener` lets embedders load or select the destination model and handle navigation. It shipped in v0.38.0, while asynchronous content loading remains the definition provider's responsibility.

## Change summary

Allow embedders to load a definition target from another URI and open or replace the active model when navigating to it.

## Best solution

Use `monaco.editor.registerEditorOpener` to implement application-specific tabs or in-place model switching, and materialize lazily fetched files as models before returning their locations from the asynchronous definition provider.

- **Fit:** aligned

- **Evidence:** The vision describes Monaco as a browser library whose embedders integrate through its API; the implemented opener API provides that integration point.
