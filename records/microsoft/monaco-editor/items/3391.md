## Summary

This URI-encoding mismatch was fixed immediately after the report and shipped in v0.35.0. Current main consistently passes encoded model URIs to the TypeScript language service.

## Change summary

TypeScript diagnostics fail for models whose URI query contains characters such as an equals sign.
