# Issue #4808 — Kusto keywords are not getting highlighted when updated to latest @kusto/monaco-kusto 12.0.14 version and monaco editor 0.49.0 version

## Summary

The identical report in the Kusto provider repository received a concrete configuration answer: enable semantic highlighting. This is integration guidance rather than an established Monaco defect.

## Change summary
