[https://github.com/microsoft/monaco-editor/issues/4808](https://github.com/microsoft/monaco-editor/issues/4808)

## Summary

This is a resolved Kusto integration configuration question rather than a Monaco Editor defect: the matching upstream report confirms that semantic highlighting must be enabled explicitly.

## Change summary

Kusto keywords lose syntax coloring after upgrading @kusto/monaco-kusto in a manually loaded React integration.

## Best solution

Enable `'semanticHighlighting.enabled': true` when creating the editor, as documented in the resolved @kusto/monaco-kusto report; any corresponding documentation improvement belongs in Azure/monaco-kusto.
