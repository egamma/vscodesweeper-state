# Issue #1714 — Present Sign-in option even when the folder is not a git repository

[https://github.com/microsoft/vscode-pull-request-github/issues/1714](https://github.com/microsoft/vscode-pull-request-github/issues/1714)

## Summary

The onboarding gap remains on current main: without an open Git repository, the extension shows the no-repository message while withholding its sign-in UI and command. Keep this team-authored On Deck request open and route it to authentication/UX.

## Change summary

Allow users to sign in to the extension when no folder or no Git repository is open.

## Best solution

Update the welcome contributions in package.json to offer GitHub sign-in alongside the no-folder and no-repository guidance, and make the sign-in command available without a repository while retaining the repository requirement for loading repository-scoped pull requests.

## Vision fit

- **Fit:** aligned
- **Reason:** Removing an authentication dead end directly supports the extension's role as the bridge between VS Code and GitHub and improves first-run access to its native workflow.
- **Evidence:** The public product promise is to "Review and manage your GitHub pull requests and issues directly in VS Code," and authentication breadth is a durable theme.
