## Summary

Keep open: current source supports the linked investigation's diagnosis that VS Code's Agent Host drops explicitly attached issue content. The open investigation PR references this issue, so it should remain open while maintainers coordinate the upstream fix.

## Change summary

Copilot should receive an attached GitHub issue's title, description, and comments without requiring its editor tab to be open.

## Best solution

Fix generic text-attachment forwarding in microsoft/vscode's Agent Host, preserving the extension's existing issue-content provider. Review the findings in https://github.com/microsoft/vscode-pull-request-github/pull/9146 and coordinate upstream tracking; opening the issue editor tab is the reported workaround.
