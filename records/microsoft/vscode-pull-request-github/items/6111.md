# Issue #6111 — Option to view Files Changed as tree (not just as list)

[https://github.com/microsoft/vscode-pull-request-github/issues/6111](https://github.com/microsoft/vscode-pull-request-github/issues/6111)

## Summary

This remains a valid request for the multi-diff editor's Files Changed pane, but that pane is rendered by VS Code core rather than this extension. Keep the team-authored, On Deck item open and route it through the upstream/vscode lane.

## Change summary

Allow the Files Changed pane in the pull-request multi-diff editor to switch from a flat list to a folder tree.

## Best solution

Add a list/tree layout option to VS Code's multi-diff editor used by the `vscode.changes` command, then let this extension inherit that capability. A maintainer should transfer or establish the corresponding microsoft/vscode issue; the extension should not implement a parallel file navigator.
