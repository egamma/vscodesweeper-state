# Issue #9113 — Option to hide githubPullRequests.queries categories with 0 results

[https://github.com/microsoft/vscode-pull-request-github/issues/9113](https://github.com/microsoft/vscode-pull-request-github/issues/9113)

## Summary

The requested option is not available on current main: custom PR categories remain visible when their queries return no results. Route to tree-views for a product decision; the linked Issues-view change and grouping PR do not cover this capability.

## Change summary

Allow custom Pull Requests query categories to disappear when empty and reappear after a refresh finds matching pull requests.

## Best solution

Provide opt-in empty-category hiding in the PR tree while preserving the current default. Refresh must reconsider hidden queries, and authentication or fetch failures must not be mistaken for successful empty results.
