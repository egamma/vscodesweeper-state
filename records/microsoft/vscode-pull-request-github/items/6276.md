# Issue #6276 — Option to not steal focus when switching PRs

[https://github.com/microsoft/vscode-pull-request-github/issues/6276](https://github.com/microsoft/vscode-pull-request-github/issues/6276)

## Summary

Verified duplicate: the active-PR sidebar takes focus during checkout through the same webview-focus behavior already tracked by the open canonical issue.

## Change summary

Allow switching to a pull request without taking focus from the terminal while still showing its details in the sidebar.

## Best solution

Consolidate on https://github.com/microsoft/vscode-pull-request-github/issues/5332 and preserve the user's current focus when showing the active-PR view, while retaining the accessibility-required focus behavior when appropriate.
