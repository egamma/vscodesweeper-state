# Issue #6276 — Option to not steal focus when switching PRs

[https://github.com/microsoft/vscode-pull-request-github/issues/6276](https://github.com/microsoft/vscode-pull-request-github/issues/6276)

## Summary

The focused-mode sidebar still explicitly takes focus, and no existing setting preserves terminal focus while retaining that layout. Keep this accepted improvement open and route it to focused mode.

## Change summary

Allow automatic PR checkout layout updates without taking keyboard focus away from the terminal.

## Best solution

Let users retain terminal focus when checkout automatically reveals the active PR sidebar and overview. Preserve intentional focus changes from explicit navigation commands; the team should decide whether automatic focus preservation is the default or configurable.
