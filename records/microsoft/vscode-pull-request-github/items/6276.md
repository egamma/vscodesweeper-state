# Issue #6276 — Option to not steal focus when switching PRs

[https://github.com/microsoft/vscode-pull-request-github/issues/6276](https://github.com/microsoft/vscode-pull-request-github/issues/6276)

## Summary

A real focused-mode UX gap remains on current main: checking out a PR unconditionally shows and focuses the active-PR sidebar, independently of the configured overview layout. Route this to focused-mode and UX for an explicit preserve-focus behavior.

## Change summary

Allow PR checkout to update the active-PR sidebar and overview without taking focus from the terminal.

## Best solution

Update the active-PR view during checkout without calling its focus-taking show path, while retaining explicit focus for user-invoked navigation. The focused-mode layout can still open the selected overview or diff when configured, but sidebar refresh should not independently steal focus.

## Vision fit

- **Fit:** aligned
- **Reason:** Preserving the user's active terminal while updating PR context improves the native in-editor review workflow and the focused-mode experience.
- **Evidence:** The durable themes explicitly include "Trees, queries, and views" and focused mode, while the product promise is to review and manage pull requests directly in VS Code.
