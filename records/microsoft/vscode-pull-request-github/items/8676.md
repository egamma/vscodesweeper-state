# Issue #8676 — `checkGitHubForPrBranch` associates branches with stale closed PRs via their tracked upstream (e.g. branches tracking `origin/dev`)

[https://github.com/microsoft/vscode-pull-request-github/issues/8676](https://github.com/microsoft/vscode-pull-request-github/issues/8676)

## Summary

The remaining defect is source-reproducible on main and is the same branch-association gap already tracked by the broader open issue https://github.com/microsoft/vscode-pull-request-github/issues/7944.

## Change summary

Branches tracking a differently named upstream are associated with stale closed PRs for that upstream branch.

## Best solution

Consolidate on https://github.com/microsoft/vscode-pull-request-github/issues/7944 and update branch-to-PR detection to distinguish a branch's merge upstream from its own push ref, preserving this report's closed-PR fallback case as concrete test coverage.
