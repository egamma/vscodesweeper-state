# Issue #3956 — Dismissing pull requests from the UI's tree

[https://github.com/microsoft/vscode-pull-request-github/issues/3956](https://github.com/microsoft/vscode-pull-request-github/issues/3956)

## Summary

A real capability gap remains: configurable queries can filter PRs by GitHub search criteria, but users cannot dismiss individual uninteresting PRs from the tree. Route this review-queue workflow to the tree-view and UX owners.

## Change summary

Allow users to dismiss individual open pull requests from the tree so they can progressively prune a large review queue.

## Best solution

Add a PR-tree context action that persistently hides a selected PR for the relevant repository and query, together with a clear way to view or reset dismissed items. Keep query editing for server-side filtering while treating dismissal as local workflow state.
