# Issue #3956 — Dismissing pull requests from the UI's tree

[https://github.com/microsoft/vscode-pull-request-github/issues/3956](https://github.com/microsoft/vscode-pull-request-github/issues/3956)

## Summary

The requested per-PR pruning workflow remains missing: custom queries filter lists, while notification dismissal does not remove PRs. Route to explorer for a product decision; no verified canonical owns this request.

## Change summary

Allow users to dismiss uninteresting PRs from a newest-first open-PR tree without closing them on GitHub.

## Best solution

Provide a reversible, personal dismissal workflow in the PR tree that leaves GitHub PR state unchanged. The team should decide dismissal persistence and how users restore hidden entries before implementation.

- **Reason:** Reducing large PR lists to relevant work supports managing pull requests directly in the editor.
