# Issue #3956 — Dismissing pull requests from the UI's tree

[https://github.com/microsoft/vscode-pull-request-github/issues/3956](https://github.com/microsoft/vscode-pull-request-github/issues/3956)

## Summary

The central capability remains missing: users can customize PR query categories, but cannot dismiss an individual uninteresting pull request from the tree. Route this valid feature request to the tree-view owners.

## Change summary

Allow users to prune individual pull requests from the open-PR tree without changing their state on GitHub.

## Best solution

Add a PR-node context action that records a repository-scoped dismissal and filters dismissed PRs from subsequent tree refreshes, together with an accessible way to restore or clear dismissed entries.

## Evidence

- **existing query surface:** package.json and package.nls.json expose `githubPullRequests.queries`, which customizes query-backed categories using GitHub search syntax; it does not provide per-PR dismissal state.

- **context actions:** The pull-request context menu in package.json includes `pr.dismissNotification` only for nodes carrying notification state; no action dismisses the PR itself from query results.
