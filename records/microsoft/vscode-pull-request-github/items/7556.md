# Issue #7556 — In progress comments are lost when updating after PR is merged

[https://github.com/microsoft/vscode-pull-request-github/issues/7556](https://github.com/microsoft/vscode-pull-request-github/issues/7556)

## Summary

Still present on current main: when a PR becomes merged under the default desktop configuration, review mode is cleared and its comment controller is disposed, which removes the file comment widget and its unsaved draft.

## Change summary

Unsaved text in a file review-comment widget is lost when the pull request becomes merged and its state refreshes.

## Best solution

Preserve or recover the active comment-widget draft before the merged-state path clears review mode in src/view/reviewManager.ts; alternatively, defer teardown or warn the user while unsaved input exists.
