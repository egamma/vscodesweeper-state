# Issue #7556 — In progress comments are lost when updating after PR is merged

[https://github.com/microsoft/vscode-pull-request-github/issues/7556](https://github.com/microsoft/vscode-pull-request-github/issues/7556)

## Summary

Still present on main: when a merged-state refresh tears down review mode, the extension disposes every file-comment thread, including a widget containing unsaved text. Route this to the review and comments areas to preserve or guard the draft before teardown.

## Change summary

Unsaved text in a file comment widget is discarded when the reviewed pull request is merged and its state refreshes.

## Best solution

Before clearing review mode for a merged PR, preserve any in-progress file-comment text or warn the user and defer teardown until they explicitly discard it. The change belongs in the review-mode cleanup and comment-controller lifecycle in src/view/reviewManager.ts and src/view/pullRequestCommentController.ts.
