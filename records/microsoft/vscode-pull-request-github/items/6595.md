# Issue #6595 — Make pr.goToNextDiffInPr work for Pull Requests in PULL REQUESTS tree list?

[https://github.com/microsoft/vscode-pull-request-github/issues/6595](https://github.com/microsoft/vscode-pull-request-github/issues/6595)

## Summary

A real navigation gap remains on main: the command can traverse files only for checked-out pull requests. Keep this team-authored request open and route it to the review and tree-view areas.

## Change summary

Allow the next/previous PR-diff commands to navigate across files opened from the Pull Requests tree without checking out the pull request.

## Best solution

Extend the navigation path in src/commands.ts to resolve the pull request represented by a `Schemes.Pr` diff and open the next or previous file from that PR's change model, without requiring an active checked-out review.
