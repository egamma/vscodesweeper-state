# Issue #9104 — Merge entire stack action is very hidden and should likely be a top level button or even the primary

[https://github.com/microsoft/vscode-pull-request-github/issues/9104](https://github.com/microsoft/vscode-pull-request-github/issues/9104)

## Summary

The whole-stack action now has a tooltip, but remains an icon-only secondary action beside the primary partial-stack button. Keep this accepted, team-authored request open and route the unresolved prominence and default-action decision to the description-page UX area.

## Change summary

Make merging an entire pull-request stack discoverable, potentially making it the primary action instead of merging through the current PR.

## Best solution

Choose a clear presentation for partial-stack versus whole-stack merging, accounting separately for merge-method selection. Coordinate with the ongoing merge-section presentation work without treating a tooltip or cosmetic changes as completion of this request.
