# Issue #6712 — Files in pull request opened by absolute path; not considered the same file as the file within the workspace

[https://github.com/microsoft/vscode-pull-request-github/issues/6712](https://github.com/microsoft/vscode-pull-request-github/issues/6712)

## Summary

The reported failure plausibly follows from the extension not recognizing the checked-out PR, but the reproduction is from extension 0.106.0 and lacks logs showing which current branch-resolution operation fails. Current-version confirmation and logs are needed before deciding whether an extension defect remains.

## Change summary

When SSH authentication is unavailable, the extension sometimes fails to recognize the checked-out PR and opens its files as separate read-only PR resources instead of workspace files.

## Best solution

Confirm the scenario on current versions and identify the failing operation from the GitHub Pull Request output. If it remains, active-PR detection in src/view/reviewManager.ts should rely on local branch metadata and GitHub API data without requiring a credentialed Git fetch, so src/view/fileChangeModel.ts selects the workspace file URI.
