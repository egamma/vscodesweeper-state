# Issue #4765 — Allow copying a github link to the default branch

[https://github.com/microsoft/vscode-pull-request-github/issues/4765](https://github.com/microsoft/vscode-pull-request-github/issues/4765)

## Summary

A real capability gap remains: current commands generate commit or checked-out-branch links, but none explicitly targets the repository's default branch. The On Deck request should remain open and be routed to the git/GitHub integration areas.

## Change summary

Add a command for copying a GitHub file link that targets the repository's default branch and preferably supports selecting the source remote.

## Best solution

Add a default-branch link command alongside `issue.copyGithubHeadLink`, resolving the chosen GitHub repository's default branch and constructing the link for that branch. The design should account for fork and multi-remote repositories, either by selecting the upstream repository automatically or offering a configurable remote.
