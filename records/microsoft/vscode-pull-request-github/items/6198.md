# Issue #6198 — Show files w/ updates in sidebar

[https://github.com/microsoft/vscode-pull-request-github/issues/6198](https://github.com/microsoft/vscode-pull-request-github/issues/6198)

## Summary

Per-file incoming-update indicators remain a distinct capability gap: existing pull prompts and file decorations do not identify which PR files are behind the remote. Route to explorer and git for consideration; no verified canonical owns this request.

## Change summary

Show which files in the PR sidebar have remote updates that have not yet been pulled locally.

## Best solution

Expose per-file local-versus-remote freshness in the PR changes tree, distinct from modification status and viewed state, and clear the indicators when the local branch catches up. Preserve the existing pull policy rather than requiring automatic pulls.

- **Fit:** aligned
- **Reason:** Making stale review content visible supports accurate in-editor review and real-world Git workflows.
- **Evidence:** Layer 1 promises reviewing and managing pull requests directly in VS Code; layer 2 identifies the review flow, trees and views, and Git plumbing as durable themes.
