# Issue #6198 — Show files w/ updates in sidebar

[https://github.com/microsoft/vscode-pull-request-github/issues/6198](https://github.com/microsoft/vscode-pull-request-github/issues/6198)

## Summary

A real feature gap remains: the PR changes tree shows each file's overall Git status and review state, but does not identify files changed by commits that have not been pulled locally. Routing this review-safety improvement to the tree and git areas.

## Change summary

Decorate files in the PR sidebar when newer remote PR commits contain changes that are not present in the reviewer's local checkout.

## Best solution

Track the checked-out PR branch's local head against the current remote PR head, determine which files changed between those commits, and decorate the corresponding file nodes in the Changes in Pull Request tree. Refresh those indicators when the PR timeline or local repository state changes, clearing them after the commits are pulled.

## Evidence
