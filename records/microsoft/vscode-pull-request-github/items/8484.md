# Issue #8484 — Selecting `Approved` from the dropdown should not auto submit

[https://github.com/microsoft/vscode-pull-request-github/issues/8484](https://github.com/microsoft/vscode-pull-request-github/issues/8484)

## Summary

Keep open for UX reconsideration. The immediate-submit behavior is intentional, but the request also identifies an unresolved visual ambiguity between an action menu and a selection control.

## Change summary

Make choosing Approve from the review dropdown select the review type without submitting, or visually clarify that dropdown entries execute immediately.

## Best solution

Have the review and UX owners decide whether to separate review-type selection from submission; if immediate submission remains, distinguish the action menu from the non-submitting merge-method selector to prevent accidental duplicate reviews.

- **Fit:** aligned
- **Reason:** Preventing accidental review submissions improves the extension's central in-editor review workflow.
- **Evidence:** The durable themes explicitly include “The review flow” and in-editor review submission.
