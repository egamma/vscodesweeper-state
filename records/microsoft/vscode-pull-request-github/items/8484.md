# Issue #8484 — Selecting `Approved` from the dropdown should not auto submit

[https://github.com/microsoft/vscode-pull-request-github/issues/8484](https://github.com/microsoft/vscode-pull-request-github/issues/8484)

## Summary

The dropdown still submits the selected review immediately on current main, while its split-button presentation can reasonably imply that it only changes the primary action. The earlier as-designed decision does not cover this report's full fallback request to make the immediate-action styling clearer, so this should remain open for review/UX consideration.

## Change summary

Make selecting Approve or Request Changes from the compact review dropdown choose the pending review type without submitting, or visually distinguish the menu as a set of immediate actions.

## Best solution

Have the review and UX owners decide whether the compact control should become a true selector matching GitHub's review form; if preserving one-click submission, use action-menu styling that does not imply selection of a new primary button state.
