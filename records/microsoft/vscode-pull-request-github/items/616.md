# Issue #616 — Warn when you need to use administrator privileges to merge

[https://github.com/microsoft/vscode-pull-request-github/issues/616](https://github.com/microsoft/vscode-pull-request-github/issues/616)

## Summary

Keep this request open and route it to the description-page area: current merge confirmations do not explicitly identify an administrator override. Existing protection-status messages partially address visibility, but do not establish that the requested warning is implemented.

## Change summary

Warn before merging when the operation relies on administrator privileges to bypass branch protection.

## Best solution

Make reliance on administrator bypass explicit before a merge is submitted, consistently across the description page and merge command. Preserve the distinction between warning about an override and adding the ability to perform one.
