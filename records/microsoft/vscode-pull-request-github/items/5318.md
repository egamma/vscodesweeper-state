# Issue #5318 — Comment Thread Filter "Most Recent Comment"

[https://github.com/microsoft/vscode-pull-request-github/issues/5318](https://github.com/microsoft/vscode-pull-request-github/issues/5318)

## Summary

A real gap remains: the extension collapses threads whose latest reply is from the current user, but it cannot hide them from VS Code's Comments panel. This team-authored feature request should remain open in the existing upstream/vscode lane.

## Change summary

Hide Comments panel threads when the signed-in user wrote the latest reply, until another participant responds.

## Best solution

Add Comments view filtering or extension-provided filter metadata in microsoft/vscode, then have this extension expose whether the current user authored each thread's latest comment. The existing upstream/vscode classification correctly identifies the likely implementation boundary.
