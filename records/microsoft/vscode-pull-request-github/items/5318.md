# Issue #5318 — Comment Thread Filter "Most Recent Comment"

[https://github.com/microsoft/vscode-pull-request-github/issues/5318](https://github.com/microsoft/vscode-pull-request-github/issues/5318)

## Summary

Keep open as the canonical request for an author-aware Comments view filter. The extension contributes comment threads through VS Code's Comments API, while VS Code core owns the panel and its filtering UI.

## Change summary

Add a filter that hides comment threads when the current user authored the most recent reply.

## Best solution

Add an author-aware filter to the VS Code Comments view, extending the comments API if providers must identify the current user or classify threads. Extension-contributed review threads should then inherit the filter without a separate GHPRI panel implementation.
