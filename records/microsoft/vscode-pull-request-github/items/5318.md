# Issue #5318 — Comment Thread Filter "Most Recent Comment"

[https://github.com/microsoft/vscode-pull-request-github/issues/5318](https://github.com/microsoft/vscode-pull-request-github/issues/5318)

## Summary

The requested last-comment-author filter remains missing from the Comments panel. Keep this team-authored request open in the existing upstream/vscode lane; no qualifying canonical or implementing fix was found.

## Change summary

Hide comment threads whose latest comment is mine until another participant replies, without resolving them.

## Best solution

Add an optional last-comment-author filter to the Comments view in microsoft/vscode, preserving thread resolution state and restoring visibility when another participant replies. This extension should continue supplying complete comment threads rather than removing them to simulate panel filtering.
