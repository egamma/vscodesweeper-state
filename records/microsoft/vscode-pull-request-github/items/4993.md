## Summary

Keep open: checkout still awaits Git operations through non-cancellable progress, although the SSH-induced hang has not been confirmed on current versions. The supplied prompt, checkout steps, and WSL environment suffice to retest despite changes since version 0.66.2.

## Change summary

PR checkout can remain pending indefinitely when an underlying Git command requires interactive input, with no cancellation or recovery short of reloading.

## Best solution

Provide recoverable checkout behavior when Git awaits interactive input, without leaving persistent progress or allowing abandoned operations to change branches later. First reproduce through the built-in Git provider to distinguish extension-side recovery work from prompt or process-control changes needed in microsoft/vscode.
