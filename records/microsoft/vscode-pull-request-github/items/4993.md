# Issue #4993 — checkout pull request hangs forever if the commands request interactive input

[https://github.com/microsoft/vscode-pull-request-github/issues/4993](https://github.com/microsoft/vscode-pull-request-github/issues/4993)

## Summary

The gap remains on current main: PR checkout awaits VS Code's Git API indefinitely, with neither a cancellable progress notification nor a cancellation token accepted by fetch. Route this through the git and upstream/vscode areas rather than closing it.

## Change summary

PR checkout hangs without a cancellation path when an underlying Git command waits for interactive SSH input.

## Best solution

VS Code's built-in Git extension should expose cancellation or reliably surface interactive SSH prompts for API-initiated fetches; this extension should then pass that cancellation through, make checkout progress cancellable, and prevent overlapping checkout attempts.
