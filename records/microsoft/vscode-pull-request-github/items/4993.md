# Issue #4993 — checkout pull request hangs forever if the commands request interactive input

[https://github.com/microsoft/vscode-pull-request-github/issues/4993](https://github.com/microsoft/vscode-pull-request-github/issues/4993)

## Summary

The cancellation gap remains on current main, but terminating the blocked Git process requires support from VS Code's built-in Git API. Keep this open in the upstream/vscode lane while the extension-side concurrency and cleanup behavior is also addressed.

## Change summary

Checking out a pull request can remain pending indefinitely and allow duplicate checkout attempts when an underlying Git command waits for interactive SSH input.

## Best solution

Add cancellable Git operations to the Repository API in microsoft/vscode, then pass that cancellation through the checkout flow in src/view/reviewsManager.ts, src/view/reviewManager.ts, and src/github/pullRequestGitHelper.ts. The extension should also prevent concurrent checkout attempts and reliably restore its progress and review-mode state after cancellation.
