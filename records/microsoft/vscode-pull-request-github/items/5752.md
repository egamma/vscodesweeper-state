# Issue #5752 — Allow search-ing on only the content of the PR

[https://github.com/microsoft/vscode-pull-request-github/issues/5752](https://github.com/microsoft/vscode-pull-request-github/issues/5752)

## Summary

The requested PR-scoped text search remains a real gap on current main. This issue is the established canonical and should remain open, routed to the review and UX areas.

## Change summary

Add search scopes covering files modified by a pull request and lines contained in its diff.

## Best solution

Add a review command that derives search targets from the current pull request's change models and supports both whole-file and diff-line scopes, coordinating with VS Code search APIs where file-scheme resources are currently limiting.
