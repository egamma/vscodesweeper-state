# Issue #5752 — Allow search-ing on only the content of the PR

[https://github.com/microsoft/vscode-pull-request-github/issues/5752](https://github.com/microsoft/vscode-pull-request-github/issues/5752)

## Summary

This remains a distinct feature gap: current main exposes PR file-list display controls but no command or setting for searching only a pull request's changed files or diff lines. Route it to review, with the VS Code scoped-search API limitation tracked as an upstream dependency.

## Change summary

Add search scopes covering all files changed by the active pull request and, separately, only lines included in its diff.

## Best solution

Provide an extension command that derives its file and line scope from the active PR's changes and presents scoped text-search results. Arbitrary file-set search support in https://github.com/microsoft/vscode/issues/20530 may enable the changed-files portion, while diff-line filtering still needs an extension-side design.
