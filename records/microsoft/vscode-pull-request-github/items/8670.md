# Issue #8670 — 'Complete Merge' button hidden behind notification toast

[https://github.com/microsoft/vscode-pull-request-github/issues/8670](https://github.com/microsoft/vscode-pull-request-github/issues/8670)

## Summary

Keep open in the existing upstream/vscode lane: the extension intentionally keeps a cancellable progress notification visible during local conflict resolution, while VS Code core positions that notification over the merge editor's Complete Merge action at some window sizes.

## Change summary

Keep the merge editor's Complete Merge button accessible while the conflict-resolution progress notification is visible.

## Best solution

VS Code core should prevent notifications from obscuring merge-editor actions, or provide an accessible equivalent for Complete Merge while an overlay is present. A maintainer should transfer or file this against microsoft/vscode and preserve the extension-specific detail that cancelling the progress notification aborts the merge.
