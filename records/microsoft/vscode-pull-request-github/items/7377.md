# Issue #7377 — Can't tell if user has been tagged in comment

[https://github.com/microsoft/vscode-pull-request-github/issues/7377](https://github.com/microsoft/vscode-pull-request-github/issues/7377)

## Summary

A real comment-composer UX gap remains: mention completion inserts plain text without visual confirmation until the comment is posted. Keep the Backlog request open and route it to comments/UX rather than closing based on parity with github.com.

## Change summary

Provide highlighting, navigation, or a preview affordance so users can verify an @mention while composing a review comment.

## Best solution

Add lightweight mention feedback to comment documents, such as token decoration and a hover/link after a completion is accepted; if the required comment-editor hook is unavailable to extensions, pursue the corresponding API or preview affordance in microsoft/vscode.
