# Issue #5864 — Network error: Unexpected token '<', "<!DOCTYPE "... is not valid JSON

[https://github.com/microsoft/vscode-pull-request-github/issues/5864](https://github.com/microsoft/vscode-pull-request-github/issues/5864)

## Summary

Still present on current main: an HTML response from an outage or enterprise proxy is surfaced as a raw JSON parse error, and an ambiguous create response can be reported as failure even when GitHub created the PR. The reopened report should remain open and route to the GitHub/GraphQL integration owners.

## Change summary

PR creation surfaces an unhelpful JSON parsing error when GitHub or a proxy returns HTML and can incorrectly report that creation failed after the mutation was processed.

## Best solution

Handle non-JSON GraphQL responses with diagnostics that identify the endpoint, HTTP status, and likely outage or proxy interception without exposing response contents. For a failed create response, reconcile against the requested head/base before declaring failure so a successfully created PR is not reported as failed or duplicated on retry.
