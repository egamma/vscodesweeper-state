## Summary

The raw JSON parser error remains possible on main when GitHub or a proxy returns HTML, and it can obscure whether PR creation succeeded. Keep this open and route it to the GitHub API area for better failure handling.

## Change summary

PR creation surfaces an opaque JSON parsing error when the GraphQL endpoint returns HTML, sometimes after the PR was successfully created.

## Best solution

Handle non-JSON GraphQL responses in the GitHub integration layer, reporting an actionable outage or proxy error with safe status and endpoint details. The creation flow should also distinguish a failed mutation from a post-creation failure and reconcile whether the PR exists before reporting failure.
