# Issue #2895 — [feature request]: Allow specific repositories to create issue branch on fork even when you have push access

[https://github.com/microsoft/vscode-pull-request-github/issues/2895](https://github.com/microsoft/vscode-pull-request-github/issues/2895)

## Summary

The requested fork-selection capability remains absent on main. Route this valid but uncommon workflow to the issues and git areas rather than closing it based on the unexplained wont-fix disposition of a broader request.

## Change summary

Allow selected repositories to create issue-working branches on a personal fork even when the user can push upstream.

## Best solution

Add a workspace- or repository-scoped setting, or an explicit prompt, that lets the issue start-work flow select a writable fork instead of upstream. The selection belongs in the remote-resolution path in `src/github/folderRepositoryManager.ts` and its caller in `src/issues/issueFeatureRegistrar.ts`.
