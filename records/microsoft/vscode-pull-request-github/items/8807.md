[https://github.com/microsoft/vscode-pull-request-github/issues/8807](https://github.com/microsoft/vscode-pull-request-github/issues/8807)

The extension already assists with PR descriptions, but issue creation still has the requested gap. Keep the feature request open and route it to the issues and chat areas, scoped to VS Code rather than github.com.
