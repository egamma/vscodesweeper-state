# Issue #8807 — Assisted issue and pull request descriptions

[https://github.com/microsoft/vscode-pull-request-github/issues/8807](https://github.com/microsoft/vscode-pull-request-github/issues/8807)

## Summary

Existing PR description generation covers part of this request, but optional assistance identifying missing information during issue creation remains absent. Route that remaining extension-side capability to issues and chat; no verified canonical owns the same request.

## Change summary

Provide optional pre-submission assistance that identifies missing details, ambiguous descriptions, and absent reproduction steps in issue and PR drafts.

## Best solution

Evaluate optional completeness feedback in the extension's issue-creation workflow, retaining contributor control and existing templates. Reuse the existing PR generation capability rather than duplicating it; github.com authoring assistance belongs to GitHub rather than this extension.
