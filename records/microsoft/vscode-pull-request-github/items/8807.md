# Issue #8807 — Assisted issue and pull request descriptions

[https://github.com/microsoft/vscode-pull-request-github/issues/8807](https://github.com/microsoft/vscode-pull-request-github/issues/8807)

## Summary

The PR portion is already supported, but assisted issue descriptions remain a real extension-side capability gap. Keep the request open and route the remaining work to the issues and chat areas, while excluding the original github.com scenario from this repository's scope.

## Change summary

Provide optional real-time assistance that identifies missing or ambiguous information while contributors compose issue and pull-request descriptions.

## Best solution

Scope the remaining work to issue creation inside the extension: add an optional assistance provider to the issue editor flow in src/issues/issueFeatureRegistrar.ts that can suggest missing reproduction details and expected behavior. Retain the existing PR title-and-description generation path, and leave assistance on github.com to GitHub's product surfaces.
