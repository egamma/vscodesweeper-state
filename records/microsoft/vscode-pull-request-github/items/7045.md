# Issue #7045 — Question: Is it possible to separate comments from the code when viewing a pull request?

[https://github.com/microsoft/vscode-pull-request-github/issues/7045](https://github.com/microsoft/vscode-pull-request-github/issues/7045)

## Summary

A real review-workflow gap remains: the Comments view offers navigation, but neither it nor the current settings provide a readable side-by-side comment view while keeping code free of inline widgets. Keep the request open and route it to the comments and UX areas.

## Change summary

Provide a view that displays pull-request comments beside unobstructed editable code rather than rendering comment threads inline.

## Best solution

Support a synchronized, readable Comments view alongside the editor and allow inline comment widgets to remain hidden while that view is active. Because the extension contributes threads through VS Code's comments API, implementation may require corresponding comment-layout support in microsoft/vscode rather than a parallel extension-specific commenting UI.
