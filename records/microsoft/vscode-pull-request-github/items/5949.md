# Issue #5949 — Show files with conflicts next to resolve conflicts

[https://github.com/microsoft/vscode-pull-request-github/issues/5949](https://github.com/microsoft/vscode-pull-request-github/issues/5949)

## Summary

The requested conflict-file preview remains missing on current main, and the issue is accepted in the On Deck milestone. GitHub's API does not currently expose the required data through the extension's standard query, while calculating it locally is expensive, so this should remain open as an upstream-dependent capability.

## Change summary

Show the names of conflicting files beside the Resolve conflicts action so users can assess the work before entering conflict resolution.

## Best solution

When GitHub provides a supported conflict-files API, fetch the paths with mergeability and surface them in the description page beside the Resolve conflicts action. Until then, retain this as the canonical request and evaluate any extension-side calculation only if it can avoid the existing file-count and API-cost limitations.

## Evidence

- **maintainer assessment:** The maintainer comment at https://github.com/microsoft/vscode-pull-request-github/issues/5949#issuecomment-2074101564 agrees with the request but states that GitHub has no API for the data and that calculating the files is very expensive.
- **current UI gap:** webviews/components/merge.tsx renders only the generic conflict summary and Resolve conflicts button in MergeStatus; it neither receives nor displays conflicting file paths.
- **upstream API dependency:** src/github/queriesShared.gql queries only mergeable and mergeStateStatus. A mergeRequirements query containing conflict paths exists in src/github/queries.gql and src/github/queriesExtra.gql as a private-field experiment, but its use is commented out in src/github/pullRequestModel.ts.
- **local calculation limitation:** src/github/folderRepositoryManager.ts derives potential conflicts only after conflict resolution starts by comparing changed files, and aborts when the comparison reaches GitHub's 300-file API limit.
- **canonical search:** Open issue https://github.com/microsoft/vscode-pull-request-github/issues/1466 concerns pulling a force-pushed branch and does not own this preview request; https://github.com/microsoft/vscode-pull-request-github/issues/5940 concerns truncation after entering the conflict view and is narrower.
