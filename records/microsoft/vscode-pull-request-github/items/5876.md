# Issue #5876 — Issues, go to linked code functionality is wonky.

[https://github.com/microsoft/vscode-pull-request-github/issues/5876](https://github.com/microsoft/vscode-pull-request-github/issues/5876)

## Summary

A real gap remains: current main preserves the TODO text when a file is dirty but still appends a permalink to committed code that may no longer match. Route this focused enhancement to the issues area.

## Change summary

Avoid misleading source links when creating an issue from a TODO in a locally modified file.

## Best solution

In `src/issues/issueFeatureRegistrar.ts`, retain the quoted TODO and file path for dirty files but omit the commit-based permalink; continue adding permalinks for clean files.
