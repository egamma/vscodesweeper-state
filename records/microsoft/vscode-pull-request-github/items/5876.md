# Issue #5876 — Issues, go to linked code functionality is wonky.

[https://github.com/microsoft/vscode-pull-request-github/issues/5876](https://github.com/microsoft/vscode-pull-request-github/issues/5876)

## Summary

A real gap remains in the TODO-to-issue flow: current main preserves the dirty line and file path but still appends a commit-based permalink that cannot represent uncommitted or subsequently moved code. Keep the feature request open and route it to the issues and git areas.

## Change summary

Avoid adding a misleading source permalink when creating an issue from a TODO in a locally modified file.

## Best solution

In the TODO issue-body path in src/issues/issueFeatureRegistrar.ts, detect working-tree or index changes affecting the document and omit the immutable GitHub permalink in that case, retaining the quoted TODO and repository-relative file path as useful context.
