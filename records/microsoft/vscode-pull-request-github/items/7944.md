# Issue #7944 — Support using `pushRemote` and `merge` to detect the PR of a branch

[https://github.com/microsoft/vscode-pull-request-github/issues/7944](https://github.com/microsoft/vscode-pull-request-github/issues/7944)

## Summary

The requested triangular-workflow support remains missing: current discovery matches the pull-tracking branch rather than the same-named branch on pushRemote. Route to git and review to settle the discovery behavior without changing the user's pull configuration.

## Change summary

Associate local branches with PRs using their push remote and local branch name while retaining a different merge-tracking branch.

## Best solution

Support distinguishing the PR's published head from the branch's pull upstream in both active-PR discovery and local-branch association. Decide whether explicit pushRemote configuration enables this automatically or requires an opt-in setting.
