# Issue #7944 — Support using `pushRemote` and `merge` to detect the PR of a branch

[https://github.com/microsoft/vscode-pull-request-github/issues/7944](https://github.com/microsoft/vscode-pull-request-github/issues/7944)

## Summary

The requested triangle-workflow support remains missing on current main. PR association still treats the configured merge/upstream branch as the PR head, so this should remain open and route to the git and review areas.

## Change summary

Detect a local branch's pull request from its push remote and local branch name when its merge configuration tracks a different base branch.

## Best solution

Update PR discovery in src/view/reviewManager.ts and src/github/folderRepositoryManager.ts to distinguish the push destination from the merge/upstream ref, using `branch.<name>.pushRemote` and the local branch name when appropriate. Preserve merge/upstream information for determining the PR base rather than treating it unconditionally as the head.
