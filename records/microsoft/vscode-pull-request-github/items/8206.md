## Summary

Keep open and route through upstream/vscode: a maintainer identified VS Code's diff editor as the correct owner for preserving scroll position, and the attempted extension-side fix was closed without merging. The MEMBER-authored issue is also protected from a judgment close.

## Change summary

Re-selecting an already-open pull-request diff should retain its previous scroll position.

## Best solution

VS Code's diff editor should preserve the visible range when the same diff resources are reopened, allowing this extension and other diff providers to retain navigation state without extension-specific caching. A maintainer should transfer or establish an upstream microsoft/vscode issue; no matching open canonical was found.
