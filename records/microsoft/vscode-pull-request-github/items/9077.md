[https://github.com/microsoft/vscode-pull-request-github/issues/9077](https://github.com/microsoft/vscode-pull-request-github/issues/9077)

## Summary

The inspected source has no setting to disable ReviewManager polling; existing controls do not cover this request. Route to review for a maintainer decision, without treating the reported editor jump as conclusively reproduced.

## Change summary

Provide an opt-out from automatic PR-state polling while preserving manual refresh and review functionality.

## Best solution

Decide whether to expose a ReviewManager polling opt-out that preserves normal initialization, explicit refresh, and repository-change handling. Independently retest the focus-regain scroll disturbance, since suppressing polling would mitigate rather than establish its root cause.
