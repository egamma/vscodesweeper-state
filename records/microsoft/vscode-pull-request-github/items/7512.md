# Issue #7512 — Open PR Editing Form in New Tab Instead of In Sidebar By Default

[https://github.com/microsoft/vscode-pull-request-github/issues/7512](https://github.com/microsoft/vscode-pull-request-github/issues/7512)

## Summary

A real creation-flow gap remains: current main always contributes the creation form as a sidebar webview, while the existing post-create setting only controls what happens after submission. Route this broader request to UX and the description-page area.

## Change summary

Allow the pull-request creation form to open in a full editor tab instead of the sidebar by default.

## Best solution

Add a creation-surface setting or companion command that presents the existing creation model in an editor webview panel while retaining the sidebar option. The implementation should share state and submission behavior with the provider in src/github/createPRViewProvider.ts.
