# Issue #7512 — Open PR Editing Form in New Tab Instead of In Sidebar By Default

[https://github.com/microsoft/vscode-pull-request-github/issues/7512](https://github.com/microsoft/vscode-pull-request-github/issues/7512)

## Summary

A real creation-flow usability gap remains: the Create Pull Request command always presents the form as a sidebar webview, and no setting offers an editor-tab alternative. Keep the request open and route it to the UX and panel areas.

## Change summary

Add a setting that opens the pull-request creation form in an editor tab instead of the sidebar.

## Best solution

Add an explicit creation-form placement setting and support presenting the existing creation webview as an editor-area webview panel while preserving the sidebar as the current behavior or selectable default. The implementation should continue sharing the existing creation model and commands rather than introducing a separate form.
