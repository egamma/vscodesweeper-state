# Issue #8575 — Support filesFirst in file tree

[https://github.com/microsoft/vscode-pull-request-github/issues/8575](https://github.com/microsoft/vscode-pull-request-github/issues/8575)

## Summary

A real capability gap remains: PR file trees always place directories before files, with no setting for files-first ordering. Route this valid feature request to the tree and review areas.

## Change summary

Allow PR file trees to display files before directories, potentially supporting the full `explorer.sortOrder` vocabulary.

## Best solution

Add a PR file-tree sort-order setting, or deliberately inherit `explorer.sortOrder`, and apply it recursively in `src/view/treeNodes/directoryTreeNode.ts`. Refresh every PR file-tree surface when the setting changes.
