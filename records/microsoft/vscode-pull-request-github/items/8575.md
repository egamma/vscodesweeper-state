# Issue #8575 — Support filesFirst in file tree

[https://github.com/microsoft/vscode-pull-request-github/issues/8575](https://github.com/microsoft/vscode-pull-request-github/issues/8575)

## Summary

The requested sort order remains unsupported on current main: pull-request file trees always place directories before files. This is a valid review-tree enhancement and should be routed to the tree-views and review areas.

## Change summary

Allow pull-request file trees to show files before subdirectories, ideally supporting the same ordering choices as `explorer.sortOrder`.

## Best solution

Add a configurable changed-files sort order and apply it recursively in `DirectoryTreeNode.sort()`, including a files-first option while preserving the current folders-first behavior as the default. Cover mixed file/directory ordering in the directory-tree tests.
