# Issue #8575 — Support filesFirst in file tree

[https://github.com/microsoft/vscode-pull-request-github/issues/8575](https://github.com/microsoft/vscode-pull-request-github/issues/8575)

## Summary

Files-first sorting remains unsupported in the extension's PR file trees. Route to tree-views; the older natural-sorting request concerns a different observable behavior and does not justify a duplicate close.

## Change summary

Allow files to appear before folders in PR tree mode, with possible support for additional explorer.sortOrder options.

## Best solution

Provide configurable files-first ordering while retaining the folder hierarchy. The team should decide whether to follow explorer.sortOrder or expose an extension-specific preference, and whether additional sorting modes belong in the same work.
