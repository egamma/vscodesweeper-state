# Issue #7847 — `Create pull requests` should tell me about uncommitted changes and make it easy to commit them

[https://github.com/microsoft/vscode-pull-request-github/issues/7847](https://github.com/microsoft/vscode-pull-request-github/issues/7847)

## Summary

The requested creation-flow guidance remains missing on current main: the view reports no commits even when the working tree is dirty, and the existing commit offer appears only after pull-request submission fails. Keep the accepted On Deck request open and route it to the Git/UX owners.

## Change summary

Show uncommitted changes in the Create Pull Request flow and provide an easy path to commit them or open Source Control.

## Best solution

When the selected compare branch is checked out and has working-tree or index changes, replace or augment the empty commits/files message with an explicit dirty-tree notice and a trusted action to open Source Control or commit. Preserve the existing branch-diff behavior and post-submission recovery prompt.
