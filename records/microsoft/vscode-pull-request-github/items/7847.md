# Issue #7847 — `Create pull requests` should tell me about uncommitted changes and make it easy to commit them

[https://github.com/microsoft/vscode-pull-request-github/issues/7847](https://github.com/microsoft/vscode-pull-request-github/issues/7847)

## Summary

A real creation-flow gap remains on main: the preview intentionally shows committed differences but gives no indication that staged or working-tree changes are excluded. Keep it open and route it to the git and UX areas.

## Change summary

Show uncommitted changes during pull-request creation and provide an easy path to commit them.

## Best solution

Have the create-PR flow observe staged and working-tree changes, display a clear notice that they are not part of the pull request, and offer an action to open the SCM view or commit them. The existing prompt pattern in `src/issues/util.ts` can inform the implementation.
