# Issue #6950 — Lost, overridden or misplaced pending comments

[https://github.com/microsoft/vscode-pull-request-github/issues/6950](https://github.com/microsoft/vscode-pull-request-github/issues/6950)

## Summary

Pending review comments are reportedly lost or attached to incorrect locations, with three independent confirmations, but no reliable reproduction or current-version logs identify the failing sequence.

## Change summary

Pending review comments can be lost, duplicated, or associated with the wrong line or file during asynchronous creation and concurrent pull-request updates.

## Best solution

Make pending-comment creation resilient to latency and branch updates by correlating each optimistic local thread with its specific server response rather than matching only its derived path and line, while preserving recoverable draft text when synchronization fails. Investigation should focus on the review comment controllers and GitHub Enterprise behavior.
