# Issue #9004 — Walk: Use multiple GitHub Enterprise instances concurrently

[https://github.com/microsoft/vscode-pull-request-github/issues/9004](https://github.com/microsoft/vscode-pull-request-github/issues/9004)

## Summary

Keep open: the merged Crawl implementation explicitly excludes simultaneous Enterprise connections, and Run addresses a separate account-selection phase. This team-authored request also involves credential and permission-scope isolation, requiring human oversight.

## Change summary

Support repositories on multiple GitHub Enterprise deployments concurrently, with one selected account per host and independently isolated connections.

## Best solution

Develop host-aware connections within the existing credential owner, preserving session-derived destinations and isolating repository actions, caches, and authentication failures by deployment. Settle ambiguous SSH deployment selection, per-host account preferences, and hostless-view behavior before implementation; leave same-host multiple accounts to Run.
