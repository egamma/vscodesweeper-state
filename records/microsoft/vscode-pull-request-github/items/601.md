# Issue #601 — Reply to comments on Description page

[https://github.com/microsoft/vscode-pull-request-github/issues/601](https://github.com/microsoft/vscode-pull-request-github/issues/601)

## Summary

The requested threaded-reply capability remains missing on current main: the Description page displays review threads and can resolve them, but its reply-like action creates a PR-level quoted comment rather than replying within the selected thread. This issue is the established canonical and should remain open, routed to the description-page review UI.

## Change summary

Allow users to reply directly to inline review-comment threads from the pull request Description page.

## Best solution

Add a reply composer to each review thread in the Description page and wire it through the webview context and pull-request model so the submitted comment is attached to that specific GitHub review thread. Preserve the existing file-opening, quote-reply, and resolve/unresolve actions.
