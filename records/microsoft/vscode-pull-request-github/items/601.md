# Issue #601 — Reply to comments on Description page

[https://github.com/microsoft/vscode-pull-request-github/issues/601](https://github.com/microsoft/vscode-pull-request-github/issues/601)

## Summary

Direct replies to review threads remain missing from the Description page. Route this established request to the description-page and comments areas; quote replies and editor navigation do not satisfy it.

## Change summary

Allow replying to existing review-comment threads directly from the PR Description page without opening the associated file.

## Best solution

Provide thread-targeted replies within the Description timeline, preserving GitHub thread identity and the existing review-submission conventions. Retain this issue as the canonical request rather than consolidating it into reports already closed as its duplicates.
