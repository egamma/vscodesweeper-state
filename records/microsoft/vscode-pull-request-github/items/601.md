# Issue #601 — Reply to comments on Description page

[https://github.com/microsoft/vscode-pull-request-github/issues/601](https://github.com/microsoft/vscode-pull-request-github/issues/601)

## Summary

The request remains open and is the established canonical for replying to review threads from the Description page. Current main displays and resolves threads there but still lacks a thread-specific reply action.

## Change summary

Allow users to reply directly to review-comment threads from the pull request Description page.

## Best solution

Add a reply composer to each review thread in `webviews/components/timeline.tsx` and connect it through the webview context and overview message handler to `PullRequestModel.createCommentReply`, preserving the thread relationship.

- **Fit:** aligned
- **Reason:** Direct thread replies strengthen the native in-editor review workflow and reduce the need to navigate away from the PR description.
- **Evidence:** The vision identifies the review flow, in-editor commenting, resolved-thread handling, and the description page as durable investment themes.
