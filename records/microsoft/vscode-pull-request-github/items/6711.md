# Issue #6711 — Closed PRs get associated with new branches of the same name

[https://github.com/microsoft/vscode-pull-request-github/issues/6711](https://github.com/microsoft/vscode-pull-request-github/issues/6711)

## Summary

The stale closed-PR association remains possible on current main, but the broader root cause is now tracked with a current reproduction in the open issue https://github.com/microsoft/vscode-pull-request-github/issues/8676. Consolidating there preserves this report's same-name reuse and erroneous branch-deletion evidence.

## Change summary

Reusing a closed PR's branch name can associate the new branch with stale PR metadata and make branch cleanup select it for deletion.

## Best solution

Consolidate the fix in https://github.com/microsoft/vscode-pull-request-github/issues/8676: PR discovery should not persist a closed PR as the match for a newly created branch, and stale duplicate `github-pr-owner-number` entries should be cleaned up safely.
