# Issue #8374 — Comments attached to wrong lines

[https://github.com/microsoft/vscode-pull-request-github/issues/8374](https://github.com/microsoft/vscode-pull-request-github/issues/8374)

## Summary

Keep open for GitHub API investigation: multiple users report misplaced review threads, while the extension currently renders the side and line coordinates returned by GitHub's GraphQL API.

## Change summary

Review comments are displayed against different lines in VS Code than on the GitHub pull-request diff.

## Best solution

Compare GitHub's reviewThreads payload with the browser placement while the divergence is visible. If the public API coordinates are inconsistent, track the GitHub service defect and consider an extension-side mapping workaround in src/github/utils.ts and the review comment controllers.
