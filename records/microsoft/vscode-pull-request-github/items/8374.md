# Issue #8374 — Comments attached to wrong lines

[https://github.com/microsoft/vscode-pull-request-github/issues/8374](https://github.com/microsoft/vscode-pull-request-github/issues/8374)

## Summary

The report now has a concrete public example and multiple independent confirmations, so it should remain open as a comment-positioning correctness bug rather than awaiting more reporter information. Routing it to the review and comments areas for investigation.

## Change summary

Review comments can be displayed against the new side or unrelated lines instead of the lines to which GitHub attached them.

## Best solution

Make thread placement preserve GitHub's side and original/current range semantics in the review comment controller, including comments spanning changed lines and threads whose position changes after additional commits or resolution. Add regression coverage using a thread with distinct startLine/originalStartLine values.
