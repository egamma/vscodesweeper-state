# Issue #7467 — PR view table of contents alternates between entries when clicking through them

[https://github.com/microsoft/vscode-pull-request-github/issues/7467](https://github.com/microsoft/vscode-pull-request-github/issues/7467)

## Summary

The stale PR-tree highlight remains possible on current main because overlapping asynchronous selection-sync operations can complete out of order. Keep this team-authored issue open and route it to the tree and description-page owners.

## Change summary

Rapidly opening pull requests can leave the Pull Requests tree highlighting an earlier entry instead of the active PR.

## Best solution

Make the active-PR synchronization in src/view/prsTreeDataProvider.ts latest-request-wins, preventing an older asynchronous lookup from revealing its PR after a newer overview has become active.
