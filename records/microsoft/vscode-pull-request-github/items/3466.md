[https://github.com/microsoft/vscode-pull-request-github/issues/3466](https://github.com/microsoft/vscode-pull-request-github/issues/3466)

## Summary

Thanks for the context. This remains a valid, team-authored feature request: current main renders GitHub review threads but does not retrieve or display code-scanning findings, and no broader canonical issue was found.

## Change summary

Display GitHub code-scanning findings inline with review comments while inspecting pull-request diffs.

## Best solution

Extend the GitHub integration to retrieve code-scanning alerts or check-run annotations for the active pull request, map findings to changed files and lines, and expose them as read-only editor threads alongside review comments.
