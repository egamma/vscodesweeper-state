# Issue #4315 — Commit wise reviews

[https://github.com/microsoft/vscode-pull-request-github/issues/4315](https://github.com/microsoft/vscode-pull-request-github/issues/4315)

## Summary

This remains the canonical request for full commit-wise review support. Current main can display each commit's changed files, but historical files use read-only review URIs, commit-specific commenting remains incomplete, and the requested local-checkout workflow is not implemented; an open partial-fix PR also requires the issue to remain open.

## Change summary

Provide a complete commit-wise review workflow with per-commit file viewing, inline comments, and editable language-enabled source at the selected commit.

## Best solution

Complete commit-specific comment anchoring without mapping comments incorrectly onto the PR head, and design a safe checkout or worktree-based flow that enables language tooling at the selected commit without overwriting local changes. Review https://github.com/microsoft/vscode-pull-request-github/pull/8866 as a narrow improvement, then track the remaining commenting and checkout work here.
