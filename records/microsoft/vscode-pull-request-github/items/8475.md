# Issue #8475 — Manage ISSUES / PROJECTS

[https://github.com/microsoft/vscode-pull-request-github/issues/8475](https://github.com/microsoft/vscode-pull-request-github/issues/8475)

## Summary

A meaningful Projects and issue-management gap remains: the extension can associate a new issue with projects, but cannot select issue types or manage Projects fields such as status. Keep open and route to the issues and GitHub integration areas.

## Change summary

Manage organization Projects, issue types, and project-field values such as status directly from VS Code.

## Best solution

Extend issue creation and the issue description UI to select issue types and read or mutate Projects v2 fields through the GitHub integration layer. The narrower issue-type creation work can be coordinated with https://github.com/microsoft/vscode-pull-request-github/issues/8817.
