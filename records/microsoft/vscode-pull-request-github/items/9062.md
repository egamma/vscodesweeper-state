# Issue #9062 — Configurable issue completion trigger

[https://github.com/microsoft/vscode-pull-request-github/issues/9062](https://github.com/microsoft/vscode-pull-request-github/issues/9062)

## Summary

A configurable completion prefix remains unsupported. Existing comment filtering and per-language trigger suppression only partially address unwanted suggestions when '#' starts a comment; route to issues for a product decision.

## Change summary

Allow issue suggestions to use a configurable prefix or avoid triggering on the comment delimiter itself.

## Best solution

Decide whether issue completion should support a configurable prefix or distinguish a comment-opening '#' from an issue reference inside the comment. Preserve the existing per-language suppression option as a workaround, not a replacement for that capability.

- **Evidence:** The durable Issues integration theme explicitly includes completions, hovers, and todo-comment code actions.

## Evidence

- **Existing settings:** package.json:669–703 declares githubIssues.issueCompletions.enabled and githubIssues.ignoreCompletionTrigger. The latter suppresses automatic '#' suggestions for configured language IDs and defaults to including python and shellscript; neither setting provides an alternative prefix.
- **Fixed trigger:** src/issues/issueFeatureRegistrar.ts:674–733 registers IssueCompletionProvider with the literal trigger '#'. src/issues/issueCompletionProvider.ts also recognizes '#' directly when determining completion context and replacement ranges.
- **Partial comment filtering:** src/issues/issueCompletionProvider.ts calls isComment before returning suggestions for ordinary source documents; src/issues/util.ts:549–555 checks the token type at the current position. This tests whether the cursor is in a comment, not whether '#' introduced that comment, so it does not implement the requested distinction.
- **Referenced precedent:** https://github.com/microsoft/vscode-pull-request-github/issues/1521 is closed, with a maintainer completion statement at https://github.com/microsoft/vscode-pull-request-github/issues/1521#issuecomment-972726505.
