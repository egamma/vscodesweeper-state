# Issue #6397 — Add button to open the issue or PR or thread from a summary in panel-chat or quick-chat

[https://github.com/microsoft/vscode-pull-request-github/issues/6397](https://github.com/microsoft/vscode-pull-request-github/issues/6397)

## Summary

The requested Open action remains a valid gap in chat-generated summaries. The only directly linked implementation PR was closed without merging, and this team-authored feature request is protected from judgment-based closure.

## Change summary

Add an Open action to issue, pull-request, and notification summaries shown in panel chat or quick chat.

## Best solution

Implement the action against the current skill-based summary flow, using the existing issue and pull-request webview URI handlers so users can open the summarized item inside VS Code. Preserve the existing Mark as Read and Mark as Done notification actions.
