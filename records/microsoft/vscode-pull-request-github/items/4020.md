# Issue #4020 — user icons are not loaded for Github Enterprise in PR Detail page

[https://github.com/microsoft/vscode-pull-request-github/issues/4020](https://github.com/microsoft/vscode-pull-request-github/issues/4020)

## Summary

Still present on current main: the shared PR-detail avatar component deliberately renders an avatar image only for `githubusercontent.com` URLs, so valid GitHub Enterprise avatar URLs always become the generic GitHub icon. The earlier fix predates the reopen and does not resolve the reported Enterprise case.

## Change summary

GitHub Enterprise users' configured avatars are replaced with generic GitHub icons throughout the pull-request detail page.

## Best solution

Handle authenticated GitHub Enterprise avatar URLs in the extension host and provide the PR-detail webview with a safe displayable resource, while retaining the generic icon only when an avatar cannot be retrieved. The implementation should cover every PR-detail surface using the shared `Avatar` component.
