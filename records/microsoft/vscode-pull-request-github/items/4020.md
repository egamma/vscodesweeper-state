# Issue #4020 — user icons are not loaded for Github Enterprise in PR Detail page

[https://github.com/microsoft/vscode-pull-request-github/issues/4020](https://github.com/microsoft/vscode-pull-request-github/issues/4020)

## Summary

Enterprise avatar URLs are intentionally not loaded; current releases show a GitHub placeholder because those URLs may be inaccessible. Alternative avatar support is tracked separately.

## Change summary

Display users' actual GitHub Enterprise avatars on the pull-request detail page instead of a placeholder.

## Best solution

Keep the deliberate placeholder behavior for inaccessible Enterprise avatar URLs and consolidate alternative avatar support on https://github.com/microsoft/vscode-pull-request-github/issues/4517.

- **Reason:** Improving identity display for GitHub Enterprise supports the extension's durable authentication-breadth and PR-view themes, although direct avatar loading is constrained.
