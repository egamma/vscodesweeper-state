# Issue #3859 — Dismiss notification without opening PR Overview

[https://github.com/microsoft/vscode-pull-request-github/issues/3859](https://github.com/microsoft/vscode-pull-request-github/issues/3859)

## Summary

The dismiss action can remain stale until the PR tree refreshes, and an open PR explicitly fixes this issue. Keep the issue open until that implementation candidate is resolved.

## Change summary

Refresh affected PR tree nodes when notification state changes so the dismiss-notification action appears without opening the overview or manually refreshing.

## Best solution

Review and land https://github.com/microsoft/vscode-pull-request-github/pull/8241, which adds notification-change listeners to PRNode and refreshes only the affected node.
