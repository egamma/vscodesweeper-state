# Issue #3859 — Dismiss notification without opening PR Overview

[https://github.com/microsoft/vscode-pull-request-github/issues/3859](https://github.com/microsoft/vscode-pull-request-github/issues/3859)

## Summary

Keep open: dismissing notifications is implemented, but notification changes still do not invalidate the PR tree item's context, leaving the dismiss action unavailable until a refresh. The original implementation predates the reopen, and the subsequent targeted PR was closed without merging.

## Change summary

Keep the PR notification indicator and dismiss context-menu action synchronized without opening the PR overview or manually refreshing.

## Best solution

Ensure notification changes refresh the affected PR tree item's context as well as its decoration. Separately retest the documented refresh-while-focused scenario to determine whether notification fetching also needs attention.
