# Issue #5332 — Clicking PR title looses focus

[https://github.com/microsoft/vscode-pull-request-github/issues/5332](https://github.com/microsoft/vscode-pull-request-github/issues/5332)

## Summary

The focus inconsistency remains on current main and is blocked by missing VS Code API support. Keep the accepted backlog item open and route it through the upstream/vscode lane.

## Change summary

Make PR-title activation follow normal tree semantics: single-click retains tree focus, while explicit open gestures move focus to the description.

## Best solution

VS Code core should expose the activation modifiers or accessibility state needed by extension-provided tree commands. Once available, the PR description path should retain tree focus for an ordinary click while preserving the intentional focus transfer for screen-reader users and explicit open gestures.
