# Issue #5332 — Clicking PR title looses focus

[https://github.com/microsoft/vscode-pull-request-github/issues/5332](https://github.com/microsoft/vscode-pull-request-github/issues/5332)

## Summary

The focus inconsistency remains in the current source: opening a new PR description takes focus, while revealing an existing panel can preserve it. Keep this accepted improvement open and route the accessibility and VS Code API dependency for investigation.

## Change summary

Make PR-title activation follow normal tree focus conventions without compromising screen-reader announcements.

## Best solution

Support single-click preview without moving tree focus, while double-click and keyboard activation move focus and screen-reader behavior remains accessible. Resolve the required activation/accessibility API support in microsoft/vscode and adopt it in the extension's description-opening path.
