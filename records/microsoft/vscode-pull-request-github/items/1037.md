# Issue #1037 — Description webview loads slowly

[https://github.com/microsoft/vscode-pull-request-github/issues/1037](https://github.com/microsoft/vscode-pull-request-github/issues/1037)

## Summary

The original bottleneck remains visible on current main: opening a PR waits for a large batch of GitHub requests before sending the single initialization payload, while the webview can render only a generic loading indicator. The issue already has the appropriate description-page and performance routing.

## Change summary

Render useful pull-request description content progressively instead of withholding the entire page for one to two seconds while all GitHub data loads.

## Best solution

Send enough cached or resolved PR data to render the description header and body immediately, then populate timeline, checks, reviewers, mergeability, and other secondary sections as their requests complete. This belongs in the description-page host initialization and editor webview state flow.
