# Issue #1037 — Description webview loads slowly

[https://github.com/microsoft/vscode-pull-request-github/issues/1037](https://github.com/microsoft/vscode-pull-request-github/issues/1037)

## Summary

Still present on current main: the description webview displays only a generic loading indicator until a large batch of GitHub requests completes and one initialization message arrives. This issue remains the canonical report and already has the appropriate area labels.

## Change summary

Render the pull-request description page progressively instead of withholding its work-in-progress layout while all GitHub data loads.

## Best solution

Initialize the description webview with basic pull-request data as soon as it is available, then hydrate status checks, timeline events, reviewers, permissions, mergeability, and other secondary fields through incremental updates in `src/github/pullRequestOverview.ts` and `webviews/editorWebview/`.
