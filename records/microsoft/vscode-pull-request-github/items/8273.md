# Issue #8273 — Show Deployments in pull request details page

[https://github.com/microsoft/vscode-pull-request-github/issues/8273](https://github.com/microsoft/vscode-pull-request-github/issues/8273)

## Summary

A real capability gap remains: the description page displays status checks but does not retrieve or render deployment environments and their destination URLs. Keep the request open and route it to the description-page and GitHub integration owners.

## Change summary

Add a deployments section to the pull-request details page with deployment status, environment name, and an Open link.

## Best solution

Retrieve deployments associated with the pull request's head revision through the GitHub integration layer, including their latest status and environment URL, then render them as a distinct section alongside status checks in the PR description webview. Preserve checks as their own concept because they only partially cover deployment-oriented workflows.
