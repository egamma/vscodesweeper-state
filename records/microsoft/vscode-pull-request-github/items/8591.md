# Issue #8591 — Auto-refresh PR comments when they are visible

[https://github.com/microsoft/vscode-pull-request-github/issues/8591](https://github.com/microsoft/vscode-pull-request-github/issues/8591)

## Summary

A real capability gap remains: automatic refresh covers an active description webview, but not visible inline threads or the Comments view. Route this feature request to the comments and review areas.

## Change summary

Automatically refresh PR comments at a configurable interval while inline comments or the Comments view are visible.

## Best solution

Extend comment refresh scheduling in the review/comment-controller path to poll while contributed comment threads are actively visible, reusing or generalizing `githubPullRequests.webviewRefreshInterval` where appropriate and avoiding polling in inactive windows.
