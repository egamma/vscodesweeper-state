# Issue #8591 — Auto-refresh PR comments when they are visible

[https://github.com/microsoft/vscode-pull-request-github/issues/8591](https://github.com/microsoft/vscode-pull-request-github/issues/8591)

## Summary

Visible inline comments and the Comments panel still lack the requested configurable refresh trigger. Route to comments; existing webview polling and manual refresh do not cover this workflow.

## Change summary

Automatically refresh PR comments at a configurable interval while inline comments or the Comments panel are visible, independently of extension sidebars.

## Best solution

Consider visibility-scoped comment polling that retrieves browser-posted replies without requiring a sidebar or PR description to remain open, while bounding GitHub API traffic. Preserve manual refresh and avoid polling every cached PR.

## Vision fit

- **Fit:** aligned
- **Reason:** Keeping visible review conversations current supports the native in-editor review workflow.
- **Evidence:** The review flow is a durable theme, and the product promises to review and manage GitHub pull requests directly in VS Code.
