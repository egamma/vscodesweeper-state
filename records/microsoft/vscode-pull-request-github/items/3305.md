# Issue #3305 — Allow commenting on lines not changed in a PR

[https://github.com/microsoft/vscode-pull-request-github/issues/3305](https://github.com/microsoft/vscode-pull-request-github/issues/3305)

Keep open: GitHub's API rollout remains the blocker, and an open implementation PR explicitly references this issue. Closing before that PR can merge would violate the linked-PR rule.

## Change summary

Allow reviewers to add line-level review comments on unchanged lines in files included in a pull request.
