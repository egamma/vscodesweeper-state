# Issue #3345 — Comment widget disappears after adding comment

[https://github.com/microsoft/vscode-pull-request-github/issues/3345](https://github.com/microsoft/vscode-pull-request-github/issues/3345)

## Summary

Keep open: current source still collapses newly submitted threads asynchronously under collapseAll, leaving the delay the maintainer agreed to remove. The newer collapsePreexisting option addresses a different preference, not this team-authored timing defect.

## Change summary

With collapseAll enabled, a submitted comment remains expanded briefly before collapsing, potentially interrupting a second reply.

## Best solution

Make collapseAll submission behavior match the maintainer's stated immediate-collapse expectation without a later interruption. Retain collapsePreexisting for users who want newly added threads expanded, and reassess whether the remaining timing constraint still requires VS Code core API work.
