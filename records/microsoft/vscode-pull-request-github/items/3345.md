# Issue #3345 — Comment widget disappears after adding comment

[https://github.com/microsoft/vscode-pull-request-github/issues/3345](https://github.com/microsoft/vscode-pull-request-github/issues/3345)

## Summary

Keep open: `collapseAll` is intended to collapse a submitted thread immediately, but the required VS Code commenting API remains unavailable. The newer `collapsePreexisting` option addresses a different preference rather than fixing this transient delay.

## Change summary

Collapse newly submitted comment threads immediately under `githubPullRequests.commentExpandState: collapseAll` instead of leaving them briefly editable before they disappear.

## Best solution

Add the necessary initial collapsed-state capability to VS Code's commenting API, then use it when creating threads under `collapseAll`; until then, preserve `collapsePreexisting` as the option for keeping new comments expanded.
