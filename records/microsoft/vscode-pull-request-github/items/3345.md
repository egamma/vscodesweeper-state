# Issue #3345 — Comment widget disappears after adding comment

[https://github.com/microsoft/vscode-pull-request-github/issues/3345](https://github.com/microsoft/vscode-pull-request-github/issues/3345)

## Summary

This should stay open: the team-authored issue is still tracking the remaining upstream/VS Code API limitation that prevents creating a comment directly in the collapsed state, and the latest maintainer comment says the desired behavior is immediate collapse rather than the delayed disappearance. The On Deck milestone does not block review, but the team-author hard keep-open rule does for this judgment close.

## Change summary

With `githubPullRequests.commentExpandState` set to `collapseAll`, a newly added review comment remains visible briefly and then collapses while the user may still be typing another reply.

## Best solution

Keep this as the upstream/vscode-tracked behavior until VS Code exposes an API to create comments in a collapsed state, then update the extension so comments collapse immediately on Add Comment when `collapseAll` is configured. Related later reports about missing comments on large PRs were addressed separately and should not close this original API/timing issue.
