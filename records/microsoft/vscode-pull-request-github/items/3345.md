# Issue #3345 — Comment widget disappears after adding comment

[https://github.com/microsoft/vscode-pull-request-github/issues/3345](https://github.com/microsoft/vscode-pull-request-github/issues/3345)

## Summary

Keep open in the existing upstream/vscode lane: `collapseAll` intentionally collapses a submitted thread, but the remaining defect is that VS Code creates it expanded and the extension can collapse it only after a delayed update. The newer `collapsePreexisting` option provides a different workflow but does not correct `collapseAll` timing.

## Change summary

Newly submitted comment threads remain visible briefly and then disappear while `githubPullRequests.commentExpandState` is set to `collapseAll`.

## Best solution

VS Code's commenting API should allow a newly created comment thread to start in the collapsed state; the extension can then apply `collapseAll` immediately rather than changing the state after submission. Keep `collapsePreexisting` as the separate option for users who want newly added comments to remain expanded.
