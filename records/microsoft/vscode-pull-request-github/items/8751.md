# Issue #8751 — Finding how to submit pending review comments is VERY hard

[https://github.com/microsoft/vscode-pull-request-github/issues/8751](https://github.com/microsoft/vscode-pull-request-github/issues/8751)

## Summary

The focus-stealing regressions received fixes, but the original discoverability gap remains on main: disabling focused mode also hides the sidebar's Review Pull Request view and its submission controls. Keep this open as review UX polish while the latest focus fix is confirmed.

## Change summary

Provide an easily discoverable way to submit pending reviews without requiring the focused-mode sidebar view or PR description webview.

## Best solution

Expose a Submit Review or Go to Review action from the Changes in Pull Request or Comments view regardless of `githubPullRequests.focusedMode`, while keeping layout automation independently configurable. Track any remaining unintended focus changes separately in https://github.com/microsoft/vscode-pull-request-github/issues/6276.
