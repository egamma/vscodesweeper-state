# Issue #8751 — Finding how to submit pending review comments is VERY hard

[https://github.com/microsoft/vscode-pull-request-github/issues/8751](https://github.com/microsoft/vscode-pull-request-github/issues/8751)

## Summary

The submission UI becomes unavailable because disabling focused mode also hides the active-PR review view, even though the setting promises only to prevent layout changes. The older open issue https://github.com/microsoft/vscode-pull-request-github/issues/6276 owns this same coupling between retaining the sidebar and avoiding focus/layout changes.

## Change summary

Make pending-review submission discoverable without requiring users to accept automatic editor layout and focus changes.

## Best solution

Consolidate on https://github.com/microsoft/vscode-pull-request-github/issues/6276 and decouple active-PR sidebar visibility from automatic layout changes, preserving this report's evidence that the coupling also hides the only readily discoverable pending-review submission UI.
