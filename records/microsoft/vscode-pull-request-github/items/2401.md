[https://github.com/microsoft/vscode-pull-request-github/issues/2401](https://github.com/microsoft/vscode-pull-request-github/issues/2401)

## Summary

The requested suggestions remain absent from both the PR creation description and the overview comment box. Route to the description-page area for a maintainer-led design; the thread supports improving this experience rather than declining it.

## Change summary

Offer searchable issue-number and username suggestions while composing PR descriptions and general PR comments.
