# Issue #6600 — Feature Request: Autofill Title & Description according to the branches differences

[https://github.com/microsoft/vscode-pull-request-github/issues/6600](https://github.com/microsoft/vscode-pull-request-github/issues/6600)

## Summary

A real creation-flow gap remains: the extension can derive the title from the branch or use the latest commit body, but it cannot populate the description with every commit message between the base and compare branches. Route this feature request to UX for a setting and formatting decision.

## Change summary

Populate a new pull request's title from its branch name and its description from all commits unique to that branch.

## Best solution

Add an explicit all-commits option to `githubPullRequests.pullRequestDescription`, then assemble the branch-derived title and ordered commit descriptions in `src/github/createPRViewProvider.ts` using the selected base and compare branches.
