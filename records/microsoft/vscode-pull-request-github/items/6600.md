# Issue #6600 — Feature Request: Autofill Title & Description according to the branches differences

[https://github.com/microsoft/vscode-pull-request-github/issues/6600](https://github.com/microsoft/vscode-pull-request-github/issues/6600)

## Summary

A meaningful gap remains: current main can derive the title from the branch name, but intentionally leaves the description without the full set of commit messages on multi-commit branches. Keep the request open and route it to UX for a decision on an opt-in description mode.

## Change summary

Populate a new pull request's title from its branch name and its description from every commit between the base and compare branches.

## Best solution

Add an explicit `githubPullRequests.pullRequestDescription` option that formats the non-merge commits between the selected base and compare branches into the initial description, while preserving the current GitHub-compatible default behavior. The existing `branchName` option already covers the requested title behavior.
