# Issue #6038 — Show issue status inline for issue links

[https://github.com/microsoft/vscode-pull-request-github/issues/6038](https://github.com/microsoft/vscode-pull-request-github/issues/6038)

## Summary

Inline open/closed indicators for issue links remain missing: current code supplies status through hover, while existing settings affect other surfaces. Route to issues for a product decision; no verified canonical or fixing commit was found.

## Change summary

Show issue status beside links in source comments so users can spot closed issues associated with workarounds without hovering.

## Best solution

Provide an unobtrusive editor-level status indicator for referenced issues, including third-party repositories, while preserving source text and existing hover behavior. The team should decide presentation and refresh expectations before implementation.

- **Fit:** aligned
