# Issue #6038 — Show issue status inline for issue links

[https://github.com/microsoft/vscode-pull-request-github/issues/6038](https://github.com/microsoft/vscode-pull-request-github/issues/6038)

## Summary

A real capability gap remains: issue references expose their state on hover, but current main has no inline status decoration or setting that provides the requested at-a-glance indication. Keep the request open and route it to the issues and UX areas.

## Change summary

Display an issue's open or closed state inline beside issue references in editor text.

## Best solution

Add an opt-in editor-decoration provider for recognized issue references, reusing the existing issue resolution and state data while avoiding unnecessary API requests. The presentation should remain compact and accessible, with hover behavior unchanged.

- **Evidence:** The durable Issues integration theme includes completions and hovers, and the README promise is to "Review and manage your GitHub pull requests and issues directly in VS Code."
