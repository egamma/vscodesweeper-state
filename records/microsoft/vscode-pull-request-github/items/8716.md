# Issue #8716 — Use same UI for checkout in worktree as built-in VS Code worktree feature

[https://github.com/microsoft/vscode-pull-request-github/issues/8716](https://github.com/microsoft/vscode-pull-request-github/issues/8716)

## Summary

A real UI consistency gap remains: PR worktree checkout uses the system save dialog instead of VS Code Git's editable path input. Route this polish request to the git and UX areas.

## Change summary

Use the built-in Git worktree-style path input when selecting where to create a PR worktree.

## Best solution

Replace the `showSaveDialog` path step in `src/github/worktree.ts` with an editable VS Code input matching the built-in Git worktree experience, including path validation and a folder-picker button, while retaining the selected PR branch.
