# Issue #2201 — Allow to see commits of a PR without checking out to it

[https://github.com/microsoft/vscode-pull-request-github/issues/2201](https://github.com/microsoft/vscode-pull-request-github/issues/2201)

## Summary

Keep open: the description timeline now supports viewing commit diffs without checkout, but the requested expandable commit nodes in the PR list remain absent. The linked implementation PR was closed without merging.

## Change summary

Expose a PR's commits and their individual file changes directly beneath its PR-list node without checking out the branch.

## Best solution

Provide commit-by-commit browsing in the remote PR tree without depending on locally fetched commits or changing the checked-out branch. Preserve existing aggregate-file browsing and use the shipped description-timeline viewer as an alternative, not evidence that the requested tree presentation is implemented.
