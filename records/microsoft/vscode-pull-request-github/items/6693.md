# Issue #6693 — Option to Archive Conversation on PR Comments

[https://github.com/microsoft/vscode-pull-request-github/issues/6693](https://github.com/microsoft/vscode-pull-request-github/issues/6693)

## Summary

A real review-workflow gap remains: conversations can be resolved or collapsed, but not archived until a new reply arrives. The maintainer prefers adopting a GitHub-supported conversation state, so this should remain open and route to the comments/review owners for dependency and UX scoping.

## Change summary

Allow users to archive an unresolved PR conversation, hide it from the Comments panel, and automatically reveal it when another reply arrives.

## Best solution

Adopt a first-class GitHub archive or snooze state if the service exposes one, then represent it in the extension's review-thread model and VS Code Comments panel. The area owners should decide whether a local-only state is acceptable in the meantime, including persistence, manual reveal, and reliable reply detection.
