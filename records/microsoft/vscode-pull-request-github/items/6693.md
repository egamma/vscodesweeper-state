# Issue #6693 — Option to Archive Conversation on PR Comments

[https://github.com/microsoft/vscode-pull-request-github/issues/6693](https://github.com/microsoft/vscode-pull-request-github/issues/6693)

## Summary

A real review-workflow gap remains, but the requested archive state is not currently represented by GitHub review threads. Routing the request to the comments and GitHub integration areas while retaining its distinct manual-archive scope.

## Change summary

Allow users to hide individual unresolved PR conversations and automatically reveal them when new replies arrive.

## Best solution

GitHub should expose a per-user archived or waiting state for review threads, after which the extension can surface archive and reveal controls in the Comments panel without maintaining machine-local state that diverges from GitHub.
