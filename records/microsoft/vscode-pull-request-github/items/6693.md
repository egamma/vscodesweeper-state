# Issue #6693 — Option to Archive Conversation on PR Comments

[https://github.com/microsoft/vscode-pull-request-github/issues/6693](https://github.com/microsoft/vscode-pull-request-github/issues/6693)

## Summary

The requested per-conversation archive remains distinct from existing collapse and resolve actions. Route to comments for a product decision, respecting the maintainer's preference for GitHub support before extension adoption.

## Change summary

Allow users to locally hide unresolved PR conversations until a new reply arrives, with an option to reveal archived conversations.

## Best solution

Establish whether conversation archiving should be GitHub-backed before adding extension behavior. Any eventual implementation should preserve unresolved status, restore visibility on new replies, and allow archived conversations to be inspected.
