# Issue #5931 — Mark files as reviewed from Multi File Diff Editor (Open Changes)

[https://github.com/microsoft/vscode-pull-request-github/issues/5931](https://github.com/microsoft/vscode-pull-request-github/issues/5931)

## Summary

Keep open: the multi-diff editor still lacks the requested reviewed-file controls on current main, and an open draft PR already implements the core mark-viewed/unviewed portion. The request is accepted in the On Deck milestone but remains dependent on VS Code's multi-diff extension APIs.

## Change summary

Allow reviewers to mark individual files viewed or unviewed directly from the multi-file diff editor and collapse reviewed files.

## Best solution

Review and complete https://github.com/microsoft/vscode-pull-request-github/pull/5986 once the required VS Code multi-diff menu API is available, exposing the existing viewed/unviewed commands on each multi-diff resource. Programmatic collapsing may require an additional VS Code API before the full GitHub-like workflow can be delivered.
