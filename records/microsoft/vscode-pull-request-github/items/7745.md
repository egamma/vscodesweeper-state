## Summary

Keep open: the account-selection discoverability gap is accepted in the Backlog, and an open draft PR explicitly references this issue with an implementation that prompts users when repository access suggests the wrong account.

## Change summary

Detect likely wrong-account repository access and guide users with multiple GitHub accounts to VS Code's account-preferences command.

## Best solution

Review and land https://github.com/microsoft/vscode-pull-request-github/pull/8413 after validating its 403/404 detection does not misidentify ordinary repository-access failures; keep this issue open until that implementation merges or is replaced.
