# Issue #1466 — "Your branch is old, Would you like to pull" causing merge conflict

[https://github.com/microsoft/vscode-pull-request-github/issues/1466](https://github.com/microsoft/vscode-pull-request-github/issues/1466)

## Summary

The force-push conflict path remains present on main, but an open PR explicitly references this issue and attempts to add force-push detection and a reset flow. Keep the issue open while that implementation is reviewed.

## Change summary

Pulling an outdated local PR branch after its remote history was rebased and force-pushed attempts a normal merge and produces conflicts instead of offering to reset to the new remote head.

## Best solution

Review and revise https://github.com/microsoft/vscode-pull-request-github/pull/8228, then land a safe divergence check in `FolderRepositoryManager.pullBranch` that distinguishes rewritten remote history from ordinary local divergence and requires explicit confirmation before discarding local commits.
