## Summary

The force-push conflict remains present on main, but an open PR explicitly fixes this issue. Keep the issue open until that implementation is resolved and merged.

## Change summary

Pulling an outdated local PR branch after its remote branch was rebased and force-pushed can produce merge conflicts instead of offering to reset to the new remote head.

## Best solution

Review and either land or revise https://github.com/microsoft/vscode-pull-request-github/pull/8228 so the update flow detects rewritten remote history and offers a safe reset rather than invoking a normal pull.
