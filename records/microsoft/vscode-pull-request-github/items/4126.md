# Issue #4126 — Ability to customise the repositories shown in the 'Pull Requests' and 'Issues' sections

[https://github.com/microsoft/vscode-pull-request-github/issues/4126](https://github.com/microsoft/vscode-pull-request-github/issues/4126)

## Summary

A meaningful gap remains: users cannot selectively hide or reorder repository roots in both trees while retaining those repositories for browsing. Route to the tree and issues areas; existing query filters and workspace ordering only partially address the request.

## Change summary

Allow users to hide and rearrange repositories in the Pull Requests and Issues trees independently of their availability in the workspace.

## Best solution

Provide explicit repository visibility and ordering controls shared by the Pull Requests and Issues views, without removing repositories from the workspace or changing their Git configuration. The team should first decide the scope and persistence of those preferences.
