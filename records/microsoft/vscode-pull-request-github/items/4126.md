# Issue #4126 — Ability to customise the repositories shown in the 'Pull Requests' and 'Issues' sections

[https://github.com/microsoft/vscode-pull-request-github/issues/4126](https://github.com/microsoft/vscode-pull-request-github/issues/4126)

## Summary

A meaningful gap remains for large multi-repository workspaces: current main can suppress repositories with no matching issues and follows workspace-folder order, but it provides no way to select or independently arrange the repositories displayed in both trees. Route this feature request to the tree-view and UX owners.

## Change summary

Allow users to hide and rearrange workspace repositories in the Pull Requests and Issues tree views.

## Best solution

Add a workspace-scoped repository visibility and ordering configuration shared by the Pull Requests and Issues tree providers, while retaining workspace-folder order as the default. Repository selection for actions such as creating an issue should remain independent so hidden tree entries are still available when needed.
