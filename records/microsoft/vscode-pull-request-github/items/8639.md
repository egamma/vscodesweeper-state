# Issue #8639 — Request for `>GitHub Pull Requests: Forget Pull Request`

[https://github.com/microsoft/vscode-pull-request-github/issues/8639](https://github.com/microsoft/vscode-pull-request-github/issues/8639)

## Summary

An opt-in command for finishing an author's PR remains missing in the inspected checkout. Existing deletion actions provide workarounds, but do not deliver the requested command-palette workflow after merging on GitHub.

## Change summary

Provide an explicit action that checks out the configured completion branch, optionally pulls it, and deletes the author's previous local PR branch.

## Best solution

Expose an opt-in completion action for PRs merged on GitHub, honoring githubPullRequests.postDone while preserving the existing non-destructive Checkout Default Branch behavior. Reuse the established checkout and local-deletion capabilities without making remote deletion implicit.
