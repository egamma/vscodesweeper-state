# Issue #3147 — Authenticate gh cli automatically in integrated terminal

[https://github.com/microsoft/vscode-pull-request-github/issues/3147](https://github.com/microsoft/vscode-pull-request-github/issues/3147)

## Summary

Keep open for an explicit security and product decision: current main still has no way to expose the extension's GitHub session to integrated terminals, while the discussion identifies unresolved token-scope and credential-exposure risks.

## Change summary

Add an opt-in mechanism that makes the extension's GitHub authentication token available to GitHub CLI and other tools in integrated terminals, especially inside dev containers.

## Best solution

Design a least-privilege, explicitly enabled terminal authentication mechanism around `CredentialStore` and VS Code's `ExtensionContext.environmentVariableCollection`, including clear handling for session changes, revocation, Enterprise hosts, and insufficient scopes. The team should threat-model exposing the raw token before choosing whether `GITHUB_TOKEN` is an acceptable interface.
