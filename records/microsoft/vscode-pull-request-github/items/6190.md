# Issue #6190 — Allow to easily open a PR or reveal it in the PR viewlet

[https://github.com/microsoft/vscode-pull-request-github/issues/6190](https://github.com/microsoft/vscode-pull-request-github/issues/6190)

## Summary

A discoverable, non-checkout entry point for an arbitrary PR remains missing in the inspected main snapshot. Keep this team-authored request open and route it to explorer; existing deep links and tree synchronization only partially cover the ask.

## Change summary

Allow users to open or reveal a browser-visible PR in VS Code by number or URL without changing their working branch.

## Best solution

Provide discoverable non-checkout navigation to a specified PR, with the transient PR subtree/view suggested in the discussion considered alongside direct overview opening. Coordinate URL entry with VS Code's newer link-navigation work without treating that broader story as a duplicate.
