# Issue #6190 — Allow to easily open a PR or reveal it in the PR viewlet

[https://github.com/microsoft/vscode-pull-request-github/issues/6190](https://github.com/microsoft/vscode-pull-request-github/issues/6190)

## Summary

A real capability gap remains: current commands can check out a PR by number or URL, and existing tree reveal logic only works for PRs already represented in the view. Route this team-authored Backlog request to the PR tree owners.

## Change summary

Provide a non-mutating way to open a pull request by number or reveal it in the Pull Requests view from a PR already open on GitHub.

## Best solution

Add a “Show Pull Request by Number or URL” flow that fetches the PR without checking it out, opens its description, and exposes or reveals it through a transient node in the Pull Requests view. The implementation likely belongs across the command registration and PR tree model/provider, reusing the existing identity-resolution and overview-opening paths.

## Evidence

- **current command behavior:** package.json registers `pr.checkoutByNumber` as “Checkout Pull Request by Number”; src/commands.ts resolves the entered number or URL and calls `ReviewManager.switch(...)`, which changes the active checkout rather than providing a non-mutating open/reveal operation.
- **partial existing infrastructure:** src/common/uri.ts and src/uriHandler.ts support resolving an `open-pull-request-webview` URI and opening PullRequestOverviewPanel, but package.json exposes no corresponding user command that accepts a browser PR URL or number without checkout.
- **tree limitation:** src/view/prsTreeDataProvider.ts can reveal a PR only after `findPRNode` locates an existing tree node; no transient search/result subtree is present for a PR outside the configured queries.
- **maintainer direction:** The maintainer comment at https://github.com/microsoft/vscode-pull-request-github/issues/6190#issuecomment-2321197936 proposes a transient subtree or view for “show pull request by number,” confirming the intended feature direction.
