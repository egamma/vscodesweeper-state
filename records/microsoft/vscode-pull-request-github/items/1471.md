# Issue #1471 — Create predefined text for Description page comment field

[https://github.com/microsoft/vscode-pull-request-github/issues/1471](https://github.com/microsoft/vscode-pull-request-github/issues/1471)

## Summary

The requested capability remains absent on current main: the Description page accepts free-form review text but provides no saved-reply, template, or macro action. Keep this older request open as the canonical item and route it to the Description page and review areas.

## Change summary

Allow reviewers to insert predefined approval wording into the Description page comment field through a keybinding, macro, or saved-reply picker.

## Best solution

Add a saved-reply or configurable comment-template action to the Description page's review form in `webviews/components/comment.tsx`, with command/keybinding integration through the extension host where appropriate. Consolidate the newer saved-replies request at https://github.com/microsoft/vscode-pull-request-github/issues/6820 into this older issue.
