# Issue #5857 — All issues queries are empty on GitHub Codespaces

[https://github.com/microsoft/vscode-pull-request-github/issues/5857](https://github.com/microsoft/vscode-pull-request-github/issues/5857)

## Summary

A maintainer reproduced this in a private organization repository and traced it to the authentication token supplied by GitHub Codespaces. Keep it open as an upstream Codespaces issue and route it to the Codespaces and authentication areas.

## Change summary

Issue queries return no results for private repositories in GitHub Codespaces, preventing issue-based branch and pull-request workflows.

## Best solution

GitHub Codespaces should supply a token capable of reading the private repository's issues. The extension can additionally surface the token-permission failure instead of presenting empty query results if an extension-side mitigation is possible.
