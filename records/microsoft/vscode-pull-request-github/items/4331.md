# Issue #4331 — [feature] mark/deprioritize generated files by default in Tree View

[https://github.com/microsoft/vscode-pull-request-github/issues/4331](https://github.com/microsoft/vscode-pull-request-github/issues/4331)

## Summary

A real gap remains: current main can hide manually reviewed files but does not recognize or visually deprioritize files marked `linguist-generated`. The extension-owned PR changes tree should be evaluated separately from the VS Code core-owned Source Control and editor-title surfaces.

## Change summary

Recognize generated files from `.gitattributes` and visually deprioritize or collapse them across pull-request review surfaces.

## Best solution

Add generated-file classification to the PR change model and expose it through decorations and optional tree filtering or collapsing in the review view. Determine whether the Source Control and editor-title portions can consume the same file decorations; any required platform changes belong in `microsoft/vscode` through the `upstream/vscode` lane.
