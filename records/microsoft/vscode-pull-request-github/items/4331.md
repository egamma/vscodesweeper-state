# Issue #4331 — [feature] mark/deprioritize generated files by default in Tree View

[https://github.com/microsoft/vscode-pull-request-github/issues/4331](https://github.com/microsoft/vscode-pull-request-github/issues/4331)

## Summary

A real capability gap remains: the extension's PR file tree supports tree layout and viewed-file filtering, but it neither identifies nor deprioritizes files marked `linguist-generated`. Route the extension-owned portion to the tree and review areas.

## Change summary

Recognize generated files from `.gitattributes` and visually deprioritize or initially collapse them across pull-request review surfaces.

## Best solution

Add generated-file metadata to the PR change model and use it to decorate or group generated entries in the Files tree, with a setting controlling automatic collapsing. The Source Control and editor-title portions should use an appropriate shared VS Code capability rather than duplicating core UI behavior in this extension.
