# Issue #4331 — [feature] mark/deprioritize generated files by default in Tree View

[https://github.com/microsoft/vscode-pull-request-github/issues/4331](https://github.com/microsoft/vscode-pull-request-github/issues/4331)

## Summary

Automatic generated-file de-emphasis remains missing from the PR tree. Route to explorer/UX for a scope decision; the earlier declined hiding request does not settle this broader request for decorations across multiple surfaces.

## Change summary

Recognize linguist-generated attributes and de-emphasize generated files in PR/local-change trees and editor titles, optionally collapsing generated directories.

## Best solution

Decide whether the extension should expose generated-file decorations in its native PR experience while preserving access to those files. Assess SCM and editor-title coverage separately against VS Code's shared decoration surfaces; hiding alone does not satisfy the request.
