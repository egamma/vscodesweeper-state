# Issue #2030 — Don't fetch every branch in contributor's remote when checking out a pull request

[https://github.com/microsoft/vscode-pull-request-github/issues/2030](https://github.com/microsoft/vscode-pull-request-github/issues/2030)

## Summary

Implemented and shipped: fork checkout now fetches only the pull request's source branch, without the background unshallow operation that fetched additional remote data.

## Change summary

Fetch only the contributor's pull request branch during checkout instead of fetching every branch from the contributor's remote.

## Best solution

Keep the targeted refspec fetch in `PullRequestGitHelper.checkoutFromFork`; the requested behavior shipped in v0.80.0 and no configuration option is necessary for the central ask.
