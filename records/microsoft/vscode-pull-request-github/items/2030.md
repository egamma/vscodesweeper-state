# Issue #2030 — Don't fetch every branch in contributor's remote when checking out a pull request

[https://github.com/microsoft/vscode-pull-request-github/issues/2030](https://github.com/microsoft/vscode-pull-request-github/issues/2030)

## Summary

Implemented and shipped: fork PR checkout now fetches only the selected head branch, without the repository-wide unshallow pull that fetched the contributor's other branches.

## Change summary

Limit pull-request checkout to fetching the contributor's selected PR branch instead of fetching every branch from that remote.

## Best solution

Keep the single-branch checkout behavior shipped in commit f6cbe407f3cd63a3313fd725399f5d5b51020c59 and v0.80.0; the central request no longer requires a configuration setting.
