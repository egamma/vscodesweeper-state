# Issue #8588 — Refreshing Pull Request doesn't load new comments

[https://github.com/microsoft/vscode-pull-request-github/issues/8588](https://github.com/microsoft/vscode-pull-request-github/issues/8588)

## Summary

Still actionable on current main: the refresh command reloads the review-thread cache but not the model's flat comment collection, and two users confirmed that GitHub-side comments remain stale until the window reloads.

## Change summary

Refreshing pull-request comments should load new GitHub comments and replies without reloading VS Code.

## Best solution

Update `pr.refreshComments` in `src/commands.ts` to await the complete comment-refresh path, including both review threads and the flat comment collection, and surface refresh failures through the existing logging path.
