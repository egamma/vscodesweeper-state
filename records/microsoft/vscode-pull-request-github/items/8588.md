# Issue #8588 — Refreshing Pull Request doesn't load new comments

[https://github.com/microsoft/vscode-pull-request-github/issues/8588](https://github.com/microsoft/vscode-pull-request-github/issues/8588)

## Summary

The manual refresh remains a valid bug: two users confirmed that new GitHub comments do not appear until the window reloads, and the current command path has no subsequent fix addressing this report. Route it to the comments and review areas.

## Change summary

Running “Refresh Pull Request Comments” fails to show comments or replies added on GitHub.com until VS Code is reloaded.

## Best solution

Make `pr.refreshComments` refresh the active pull request model and propagate both new threads and changed replies to every comments surface, including inline threads and the Comments panel. Add a regression test covering a remotely added reply followed by manual refresh.

## Evidence
