# Issue #8588 — Refreshing Pull Request doesn't load new comments

[https://github.com/microsoft/vscode-pull-request-github/issues/8588](https://github.com/microsoft/vscode-pull-request-github/issues/8588)

## Summary

Keep open: the report provides concrete steps and another user corroborates the failure. Current source includes a refresh-to-query-to-thread-update path, but its runtime failure remains unconfirmed; the supplied steps suffice to retest against main.

## Change summary

Manually refreshing PR comments fails to display new GitHub.com comments and replies until the VS Code window is reloaded.

## Best solution

Make explicit comment refresh reliably update both inline threads and the Comments panel without reloading the window. Investigate model selection in pr.refreshComments and follow the selected model through fetching and comment-controller updates.
