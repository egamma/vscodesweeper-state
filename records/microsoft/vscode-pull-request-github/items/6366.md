# Issue #6366 — Chat Participant: Syntax tool is not aware of what is supported

[https://github.com/microsoft/vscode-pull-request-github/issues/6366](https://github.com/microsoft/vscode-pull-request-github/issues/6366)

## Summary

Still present on main: the search-query skill does not describe unsupported repeated-assignee semantics, and the search tool forwards the generated query unchanged. This team-authored Backlog issue should remain open.

## Change summary

The chat search flow generates a multiple-assignee query that GitHub interprets differently from the requested intersection, producing incorrect results.

## Best solution

Teach `src/lm/skills/form-github-search-query/SKILL.md` which qualifier combinations GitHub supports and instruct it to explain when a requested intersection cannot be represented. The search tool could additionally reject known-invalid combinations before calling GitHub.
