# Issue #6366 — Chat Participant: Syntax tool is not aware of what is supported

[https://github.com/microsoft/vscode-pull-request-github/issues/6366](https://github.com/microsoft/vscode-pull-request-github/issues/6366)

## Summary

Still present on current main: the chat query-forming instructions do not describe GitHub's single-assignee limitation, and the search tool submits the generated query unchanged. The resulting answer can therefore silently represent only one assignee rather than the requested intersection.

## Change summary

The GitHub PR chat participant generates an unsupported multiple-assignee search instead of explaining that GitHub search cannot express the requested intersection.

## Best solution

Teach the chat query-forming path that multiple positive `assignee:` qualifiers cannot represent an intersection, and prevent `SearchTool` from silently executing such a query; the participant should explain the limitation rather than return misleading results.
