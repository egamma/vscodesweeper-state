# Issue #1460 — plugin should switch to least privelege permissions

[https://github.com/microsoft/vscode-pull-request-github/issues/1460](https://github.com/microsoft/vscode-pull-request-github/issues/1460)

## Summary

Keep open: current main still requires the broad `repo` and `workflow` OAuth scopes by default, and this security-sensitive permission-scope request remains unresolved.

## Change summary

Use least-privilege GitHub authorization and gracefully disable features requiring permissions the user has not granted.

## Best solution

Coordinate with VS Code's built-in GitHub Authentication provider and GitHub's authorization platform on a finer-grained token model, then make the extension's baseline session read-oriented and request additional capabilities only when needed. Preserve the existing progressive-scope architecture while removing `repo` and `workflow` from the unavoidable baseline.
