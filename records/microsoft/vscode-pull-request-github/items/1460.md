# Issue #1460 — plugin should switch to least privelege permissions

[https://github.com/microsoft/vscode-pull-request-github/issues/1460](https://github.com/microsoft/vscode-pull-request-github/issues/1460)

## Summary

Keep open: ordinary authorization still requests broad repository permissions, and existing permission-aware behavior does not satisfy the least-privilege default requested here. This security-sensitive permission-scope concern requires human review.

## Change summary

Request only necessary permissions by default and gracefully disable features when their permissions are unavailable.

## Best solution

Establish a supported least-privilege authorization model in the extension's CredentialStore, coordinating provider capabilities with microsoft/vscode's built-in GitHub Authentication. Reassess current GitHub App API compatibility rather than treating the 2020 limitations as permanent.
