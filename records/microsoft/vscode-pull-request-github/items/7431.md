# Issue #7431 — Feature request: hidden comments

[https://github.com/microsoft/vscode-pull-request-github/issues/7431](https://github.com/microsoft/vscode-pull-request-github/issues/7431)

## Summary

A real gap remains on current main: outdated review threads are identified in the PR timeline but remain expanded by default. The issue is accepted in Backlog and should stay open, routed to the description-page review UI.

## Change summary

Collapse review comments that GitHub marks as outdated while retaining the reason and a way to reveal their contents.

## Best solution

Update `CommentThread` in `webviews/components/timeline.tsx` so outdated threads start collapsed, retain the existing Outdated indicator, and remain expandable with the Show button. Add focused component coverage for initial state and state updates; the closed implementation attempt in https://github.com/microsoft/vscode-pull-request-github/pull/8296 can inform the change but should not be treated as shipped.
