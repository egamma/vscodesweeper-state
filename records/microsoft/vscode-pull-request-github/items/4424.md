# Issue #4424 — support for easily jump to next/previous file

[https://github.com/microsoft/vscode-pull-request-github/issues/4424](https://github.com/microsoft/vscode-pull-request-github/issues/4424)

## Summary

Keep this canonical keyboard-navigation request open and route it to review. Existing commands cover text-diff navigation and marking files viewed separately, but image and multi-diff navigation plus the combined mark-and-advance workflow remain unsupported.

## Change summary

Provide next/previous file navigation across all PR diff types and an efficient keyboard workflow for marking the current file viewed and advancing.

## Best solution

Extend the review navigation commands to support text, image, and multi-diff editors, then provide a command that marks the current file viewed and advances to the next unviewed file. Coordinate the multi-diff portion with https://github.com/microsoft/vscode-pull-request-github/issues/7608.
