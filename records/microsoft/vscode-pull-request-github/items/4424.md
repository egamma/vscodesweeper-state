# Issue #4424 — support for easily jump to next/previous file

[https://github.com/microsoft/vscode-pull-request-github/issues/4424](https://github.com/microsoft/vscode-pull-request-github/issues/4424)

## Summary

A meaningful navigation gap remains despite the existing next/previous commands: they are limited to text diff editors and do not cover image diffs, the multi-diff editor, toolbar navigation, or a combined mark-viewed-and-advance workflow. This issue is the broad canonical for that workflow and should remain open in the review and UX areas.

## Change summary

Provide keyboard and toolbar actions for moving between pull-request files, including non-text and multi-diff views, with an efficient mark-as-viewed-and-advance workflow.

## Best solution

Extend pull-request navigation so next/previous works consistently across text diffs, image diffs, and the multi-diff editor, with editor-toolbar actions that do not implicitly mark files viewed. Provide a deliberate combined command or option for users who want to mark the current file viewed and advance to the next unviewed file.

- **Reason:** Efficient keyboard navigation across changed files directly advances the extension's native in-editor review workflow.
- **Evidence:** The vision identifies "The review flow" as a durable theme and promises users can "Review and manage your GitHub pull requests and issues directly in VS Code."
