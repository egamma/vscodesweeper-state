# Issue #9005 — Run: Use multiple accounts per host, including GitHub.com

[https://github.com/microsoft/vscode-pull-request-github/issues/9005](https://github.com/microsoft/vscode-pull-request-github/issues/9005)

## Summary

Keep open: simultaneous accounts on one host remain a distinct capability gap, explicitly excluded from Crawl and Walk. This team-authored request also concerns credential and permission isolation, requiring human-led design.

## Change summary

Support explicit repository-to-account bindings so multiple accounts on the same GitHub host operate concurrently without shared-account switching or state crossover.

## Best solution

Build on Walk's host-aware connections and establish repository/account bindings using supported VS Code authentication APIs. Settle persistence, account-removal behavior, and hostless selection semantics before implementing and verifying account-isolated operations and caches.
