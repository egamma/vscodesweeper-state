# Issue #8187 — Error updating active pull request view: Cannot read properties of undefined (reading 'login')

[https://github.com/microsoft/vscode-pull-request-github/issues/8187](https://github.com/microsoft/vscode-pull-request-github/issues/8187)

## Summary

Still present on current main: an authentication-session change can temporarily leave the GitHub client without a current user, while the active pull-request view unconditionally reads `currentUser.login`. Route this account-switch race to authentication and review.

## Change summary

Switching from a corporate GitHub account to a free account can make the active pull-request view fail while reading an unavailable user's login.

## Best solution

Make the active pull-request view tolerate the transient absence of an authenticated user during session replacement, then refresh normally when authentication initialization completes. Add a regression test covering `updatePullRequest` when current-user resolution returns no account.

## Evidence
