# Issue #8187 — Error updating active pull request view: Cannot read properties of undefined (reading 'login')

[https://github.com/microsoft/vscode-pull-request-github/issues/8187](https://github.com/microsoft/vscode-pull-request-github/issues/8187)

## Summary

Still present on main: account switching can leave the credential store temporarily without a current user, while the active pull-request view dereferences `currentUser.login` unconditionally. Route this to authentication and the description page.

## Change summary

Switching from a corporate account to a free account can produce an undefined-login error while updating the active pull-request view.

## Best solution

Make the active pull-request view tolerate authentication transitions by deferring or safely cancelling its update until the new session has a current user, rather than dereferencing an absent account or displaying a misleading error.
