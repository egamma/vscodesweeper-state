# Issue #6866 — Support comment reactions in webviews

[https://github.com/microsoft/vscode-pull-request-github/issues/6866](https://github.com/microsoft/vscode-pull-request-github/issues/6866)

## Summary

The gap remains on main: issue and PR webviews display existing reactions but provide no way to add or remove them. Route this accepted Backlog request to the comments and description-page areas.

## Change summary

Allow users to add and remove emoji reactions on comments in the issue and pull-request webviews.

## Best solution

Make the webview reaction elements interactive and wire add/remove requests through the issue and pull-request overview handlers to the existing GraphQL reaction mutations, updating the displayed reaction state after each mutation.

- **Fit:** aligned
- **Reason:** Interactive reactions improve fidelity with GitHub and keep issue and pull-request discussion workflows inside VS Code.
- **Evidence:** The vision promises to "Review and manage your GitHub pull requests and issues directly in VS Code" and identifies the review flow and issue views as durable investment themes.
