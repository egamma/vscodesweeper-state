# Issue #6866 — Support comment reactions in webviews

[https://github.com/microsoft/vscode-pull-request-github/issues/6866](https://github.com/microsoft/vscode-pull-request-github/issues/6866)

## Summary

The requested interaction remains missing on current main: issue and PR webviews display existing comment reactions but provide no way to add or remove them. This accepted Backlog feature should remain open and be routed to the shared comments and description-page surfaces.

## Change summary

Allow users to add and remove emoji reactions on comments from the issue and pull-request editor webviews.

## Best solution

Make the shared webview reaction component interactive for both issue and PR comments, then connect it through the webview context and overview-panel message handlers to GitHub's add/remove reaction mutations while updating the displayed reaction state.

## Vision fit

- **Fit:** aligned
- **Reason:** Supporting reactions directly in the issue and PR editors advances the native in-editor review and issue-management experience.
- **Evidence:** The product promise is to "Review and manage your GitHub pull requests and issues directly in VS Code," and the durable themes explicitly include the review flow and issues integration.
