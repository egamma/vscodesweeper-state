# Issue #8021 — Cannot create comment on pull request based on fork

[https://github.com/microsoft/vscode-pull-request-github/issues/8021](https://github.com/microsoft/vscode-pull-request-github/issues/8021)

## Summary

Keep open as the canonical public tracker for a confirmed GitHub API defect. A maintainer reproduced the failure, GitHub is investigating internally, and multiple users report it across fork, upstream, and private-repository scenarios.

## Change summary

Creating a new pull-request review thread sometimes fails with a misleading "File has been deleted" error, preventing inline review comments.

## Best solution

GitHub should correct the review-thread mutation so it returns a thread for valid files; this issue should remain the public tracker until that upstream fix is confirmed. Extension-side work may improve the error message, but maintainers report that no alternative commenting API is available.
