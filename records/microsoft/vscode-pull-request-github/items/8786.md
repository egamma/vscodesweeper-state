# Issue #8786 — Repeatedly asked to sign in again using GitHub

[https://github.com/microsoft/vscode-pull-request-github/issues/8786](https://github.com/microsoft/vscode-pull-request-github/issues/8786)

## Summary

Still present on main: transient GitHub 401 responses are treated as proof that credentials are invalid, triggering a blocking reauthentication prompt in every extension host. The issue should remain open and be routed to authentication and GitHub integration owners.

## Change summary

Prevent repeated modal GitHub sign-in prompts when API requests temporarily return authentication errors.

## Best solution

Distinguish genuinely revoked credentials from transient service, connectivity, and rate-limit failures before forcing a new session. Add durable backoff or a non-modal recovery path so one failing provider cannot repeatedly block every VS Code window.
