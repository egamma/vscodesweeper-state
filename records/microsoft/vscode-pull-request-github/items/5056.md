# Issue #5056 — New 'create pr' view could suggest reviewers in the view

[https://github.com/microsoft/vscode-pull-request-github/issues/5056](https://github.com/microsoft/vscode-pull-request-github/issues/5056)

## Summary

Reviewer suggestions before PR creation remain missing; the existing picker supports manual selection, not recommendations. Keep this team-authored, accepted request open and route it to the creation-view area.

## Change summary

Show suggested reviewers directly in the create-PR view before submitting the PR.

## Best solution

Define a pre-creation recommendation policy and expose its suggestions in the creation view without requiring the PR to exist first. The extension would need its own recommendation source unless GitHub adds an appropriate API.

- **Fit:** aligned
- **Reason:** Pre-creation reviewer suggestions improve the native PR workflow within VS Code.
- **Evidence:** The product promise is to 'Review and manage your GitHub pull requests and issues directly in VS Code'; durable themes include the review flow and description-page views.
