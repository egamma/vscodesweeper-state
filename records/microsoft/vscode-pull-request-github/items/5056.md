# Issue #5056 — New 'create pr' view could suggest reviewers in the view

[https://github.com/microsoft/vscode-pull-request-github/issues/5056](https://github.com/microsoft/vscode-pull-request-github/issues/5056)

## Summary

Keep open and route to the create-PR UX owners. The existing picker lets users select reviewers, but current main deliberately supplies no suggested reviewers before creation, and the team confirms that an extension-side suggestion mechanism is still needed.

## Change summary

Show suggested reviewers directly in the create-pull-request view before the pull request exists.

## Best solution

Add an extension-owned reviewer-ranking mechanism for the pre-creation flow, then surface those candidates in the create-PR view while retaining the existing full reviewer picker. The implementation should avoid depending on GitHub's post-creation-only suggested-reviewers field.
