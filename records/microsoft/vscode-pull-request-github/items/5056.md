# Issue #5056 — New 'create pr' view could suggest reviewers in the view

[https://github.com/microsoft/vscode-pull-request-github/issues/5056](https://github.com/microsoft/vscode-pull-request-github/issues/5056)

## Summary

A real capability gap remains: reviewers can be selected manually during PR creation, but the extension provides no suggestions. This team-authored feature request is accepted in the On Deck milestone and must remain open.

## Change summary

Show suggested reviewers in the create-pull-request view before the pull request exists.

## Best solution

Implement an extension-side reviewer-ranking strategy for changed files and pass its results into the existing reviewer picker in src/github/createPRViewProvider.ts, while retaining manual search and selection.
