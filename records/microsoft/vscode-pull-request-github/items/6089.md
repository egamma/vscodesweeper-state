# Issue #6089 — Adding a comment is always associated with a review

[https://github.com/microsoft/vscode-pull-request-github/issues/6089](https://github.com/microsoft/vscode-pull-request-github/issues/6089)

## Summary

The requested distinction remains meaningful on current main: the extension supports immediate versus pending review comments, but not an ordinary PR discussion comment. Keep the feature request open and route it to the comments and review areas.

## Change summary

Allow users to post a normal pull-request discussion comment instead of creating or submitting a pull-request review comment.

## Best solution

Add a distinct discussion-comment action to the PR description UI that creates an issue-style comment on the pull request, while retaining the existing single-comment and pending-review paths for code review comments. The action should remain available when a review is already in progress.
