# Issue #6089 — Adding a comment is always associated with a review

[https://github.com/microsoft/vscode-pull-request-github/issues/6089](https://github.com/microsoft/vscode-pull-request-github/issues/6089)

## Summary

The requested distinction remains absent on current main: the description-page “Comment” action still submits a COMMENT review rather than a normal PR discussion comment. Keep this open and route it to the comments and description-page owners.

## Change summary

Provide an explicit way to post a normal pull-request discussion comment instead of creating or submitting a review.

## Best solution

Add a distinct discussion-comment action to the PR description page that uses the issue-comment mutation, while retaining separate actions for starting or submitting reviews. The UI should clearly identify which GitHub comment type will be created.

- **Reason:** Accurately representing GitHub's distinction between discussion comments and reviews advances the extension's native PR-management workflow.
