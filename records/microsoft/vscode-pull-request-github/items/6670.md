# Issue #6670 — This PR shows a different diff than what was merged

[https://github.com/microsoft/vscode-pull-request-github/issues/6670](https://github.com/microsoft/vscode-pull-request-github/issues/6670)

## Summary

Still present on current main: merged PR file metadata comes from GitHub, but an active PR's diff still compares against the mutable workspace file. Route this correctness bug to the review and git areas.

## Change summary

A merged PR can display a different overall diff after its source branch advances because the right side reflects the current workspace rather than the merge-time snapshot.

## Best solution

For merged PRs, construct both sides of the Changes diff from immutable merge-time revisions in `src/view/fileChangeModel.ts`, while retaining workspace-backed right sides for open PRs so the existing development flow remains unchanged.
