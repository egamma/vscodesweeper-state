# Issue #6670 — This PR shows a different diff than what was merged

[https://github.com/microsoft/vscode-pull-request-github/issues/6670](https://github.com/microsoft/vscode-pull-request-github/issues/6670)

## Summary

The defect remains source-reproducible on current main: for an active merged PR, the Changes view compares the PR base against the current workspace file, which may contain commits pushed after the merge. Route this confirmed diff-correctness bug to the review area.

## Change summary

Show the historical merged-PR file snapshot rather than newer workspace content when a merged PR's branch has advanced.

## Best solution

For merged pull requests, resolve the right side of Changes-view diffs to a readonly snapshot representing the PR at merge time; retain the current writable workspace behavior for open pull requests. The implementation should also distinguish this historical snapshot from later commits on the reused head branch.
