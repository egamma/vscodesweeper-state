# Issue #6670 — This PR shows a different diff than what was merged

[https://github.com/microsoft/vscode-pull-request-github/issues/6670](https://github.com/microsoft/vscode-pull-request-github/issues/6670)

## Summary

The merged-PR diff still uses workspace content on its right side when the PR is active, allowing later branch changes to appear as merged changes. Keep this open and route to review; the maintainer-approved historical snapshot behavior remains missing.

## Change summary

Show the merged PR's historical file changes rather than subsequent workspace changes, while preserving editable diffs for open PRs.

## Best solution

Merged PR diffs should match GitHub's historical changes and use read-only content, without changing the live-workspace review flow for open PRs.
