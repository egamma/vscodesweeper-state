# Issue #4023 — `Create an Issue` UI

[https://github.com/microsoft/vscode-pull-request-github/issues/4023](https://github.com/microsoft/vscode-pull-request-github/issues/4023)

## Summary

The requested form remains a real product gap on current main: issue creation still opens a synthetic Markdown editor rather than a structured title-and-description UI. This issue is the established canonical for that request and should remain open, routed to the issues and UX areas.

## Change summary

Replace the Markdown-based new-issue editor with a structured creation form containing separate title and description fields.

## Best solution

Add a structured issue-creation surface, likely reusing appropriate components and interaction patterns from the existing pull-request creation webview while preserving issue templates, repository selection, labels, assignees, milestones, projects, and code-action entry points.
