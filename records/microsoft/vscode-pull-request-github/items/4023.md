[https://github.com/microsoft/vscode-pull-request-github/issues/4023](https://github.com/microsoft/vscode-pull-request-github/issues/4023)

## Summary

The requested title-and-description form remains missing: issue creation still uses a text editor. Keep this as the canonical request and route it to issues and UX; a maintainer explicitly consolidated the matching interface request here.

## Change summary

Provide separate Title and Description fields when creating an issue inside VS Code.

Offer an in-editor issue creation form with distinct title and description inputs, preserving repository selection and existing creation capabilities. Use this issue to track the interface work already consolidated here.

  > Creating an issue inside VS Code should offer separate Title and Description fields rather than requiring users to encode them in a plain text document. Acceptance should cover successful submission, cancellation without creating an issue, and preservation of existing selection/TODO workflows.
- **Trace:**

  > IssueFeatureRegistrar.createIssue() in src/issues/issueFeatureRegistrar.ts selects a repository, template, and remote, then calls makeNewIssueFile(). That method serializes the title, metadata, and body into a newIssue document and opens a text editor; createIssueFromFile() extracts that document's metadata and delegates submission to doCreateIssue(). createTodoIssue() supplies a title quick input but also opens the same document for description editing. package.json exposes the creation commands without a form-mode setting.
