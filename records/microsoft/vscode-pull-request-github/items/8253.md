# Issue #8253 — Github project selection not available for github entreprise

[https://github.com/microsoft/vscode-pull-request-github/issues/8253](https://github.com/microsoft/vscode-pull-request-github/issues/8253)

## Summary

Keep open: Enterprise project association remains intentionally disabled, and the team has committed to reconsidering it using server-version telemetry. The assigned 1.147.0 milestone also bars a cleanup close.

## Change summary

Enable viewing and assigning projects on issues and pull requests hosted on sufficiently recent GitHub Enterprise Server versions.

## Best solution

Enable Enterprise project association once the team establishes an acceptable compatibility baseline from telemetry, preserving support for older servers according to that decision. Cover issue and PR viewing and creation rather than only exposing the project picker.
