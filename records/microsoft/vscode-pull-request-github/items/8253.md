# Issue #8253 — Github project selection not available for github entreprise

[https://github.com/microsoft/vscode-pull-request-github/issues/8253](https://github.com/microsoft/vscode-pull-request-github/issues/8253)

## Summary

Keep open: the project selector is still deliberately hidden for every GitHub Enterprise Server instance, and the team is monitoring installed server versions before enabling it. The assigned 1.138.0 milestone is an active scheduling decision that independently bars closure.

## Change summary

Make GitHub Projects associations available for issues and pull requests on GitHub Enterprise Server versions that support the required GraphQL fields.

## Best solution

Once telemetry confirms that the supported Enterprise population has the required `projectItems` API, remove the blanket Enterprise exclusion in the description sidebar and enable the existing project-management flow for those servers. If older installations must remain supported, gate the capability using the detected Enterprise version rather than hiding it for all Enterprise users.
