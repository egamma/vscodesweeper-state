# Issue #5786 — Allow multiple comments on a single line

[https://github.com/microsoft/vscode-pull-request-github/issues/5786](https://github.com/microsoft/vscode-pull-request-github/issues/5786)

## Summary

Keep open: replying to an existing thread does not satisfy the request for independently resolvable discussions on the same line. This issue already serves as the maintainer-selected extension canonical and is appropriately routed upstream/vscode.

## Change summary

Allow reviewers to start additional, independently resolvable threads on a line that already has a review thread.

## Best solution

Enable starting a separate thread on an already-commented line through VS Code's core commenting UI, with extension integration where needed. Preserve replies to existing threads and independent GitHub thread resolution; a maintainer should coordinate any upstream issue rather than asking reporters to re-file.
