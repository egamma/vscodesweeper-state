# Issue #5786 — Allow multiple comments on a single line

[https://github.com/microsoft/vscode-pull-request-github/issues/5786](https://github.com/microsoft/vscode-pull-request-github/issues/5786)

## Summary

This remains the canonical request for starting multiple independent review threads on one line. It is correctly classified as an upstream VS Code commenting-UI limitation, and no open core canonical was found.

## Change summary

Allow reviewers to create multiple independently resolvable comment threads on the same line.

## Best solution

VS Code's commenting UI should retain a create-new-thread affordance on lines that already contain a thread; the extension can then submit the resulting empty thread through its existing GitHub review-thread creation path. Keep this issue as the extension-side canonical until the upstream behavior is tracked or implemented.
