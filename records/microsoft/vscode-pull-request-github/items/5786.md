# Issue #5786 — Allow multiple comments on a single line

[https://github.com/microsoft/vscode-pull-request-github/issues/5786](https://github.com/microsoft/vscode-pull-request-github/issues/5786)

## Summary

Keep open as the canonical request for creating multiple independently resolvable comment threads on one line. Maintainer classification and the current implementation indicate that the missing creation affordance belongs to VS Code's commenting UI, and no open microsoft/vscode canonical was verified.

## Change summary

Allow reviewers to start more than one independent, separately resolvable comment thread on the same line.

## Best solution

Add support to VS Code's commenting UI for starting another thread where a thread already exists, then let this extension use that platform affordance through its existing CommentController integration. A maintainer should transfer or establish the corresponding microsoft/vscode issue through the upstream/vscode lane while preserving this issue's user evidence.
