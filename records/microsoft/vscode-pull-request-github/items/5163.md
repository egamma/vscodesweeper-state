# Issue #5163 — Allow "Files Changed" in new PR to diff against file on disk

[https://github.com/microsoft/vscode-pull-request-github/issues/5163](https://github.com/microsoft/vscode-pull-request-github/issues/5163)

## Summary

The requested editable pre-PR diff remains intentionally disabled on current main. This issue is the canonical request and should stay open, routed to the git and tree-view areas.

## Change summary

Allow the modified side of the pre-PR Files Changed diff to edit the checked-out working-tree file directly.

## Best solution

Update the create-PR comparison flow in `src/view/compareChangesTreeDataProvider.ts` and its content providers so the modified side resolves to the checked-out workspace file when safe, with edits immediately reflected on disk while preserving read-only behavior for remote or non-checked-out branches.

## Evidence

- **current source gap:** `src/view/gitHubContentProvider.ts` returns `vscode.FilePermission.Readonly` from `ChangesContentProvider.stat`, with an explicit comment that editability is deferred to https://github.com/microsoft/vscode-pull-request-github/issues/5163; `GitContentProvider.stat` also marks local comparison documents read-only.
- **current comparison flow:** `src/view/createPullRequestDataModel.ts` uses `GitContentProvider` for a local branch without a matching upstream and `src/view/compareChangesTreeDataProvider.ts` opens those changes through the virtual `gitpr` filesystem, so the modified diff document is not the editable workspace file.
- **reopened after attempted fix:** https://github.com/microsoft/vscode-pull-request-github/pull/5804 merged on 2024-03-04 and the issue was closed through its merge commit, but https://github.com/microsoft/vscode-pull-request-github/issues/5163 was reopened on 2024-03-22 because the requested behavior remained unresolved.
- **canonical status:** The older related request https://github.com/microsoft/vscode-pull-request-github/issues/3215 was closed explicitly as a duplicate of this issue. The open https://github.com/microsoft/vscode-pull-request-github/issues/4618 instead requests choosing a diff base for an existing PR and does not own editable pre-PR working-tree diffs.
- **existing capability check:** The existing Create Pull Request command and Compare Changes views expose the branch-to-base diff, but no setting or command in `package.json` makes its modified side editable; the current providers explicitly enforce read-only documents.
