# Issue #5163 — Allow "Files Changed" in new PR to diff against file on disk

[https://github.com/microsoft/vscode-pull-request-github/issues/5163](https://github.com/microsoft/vscode-pull-request-github/issues/5163)

## Summary

The requested capability remains absent on current main: files in the create-PR comparison are explicitly read-only. The existing implementation scaffolding makes this a concrete feature gap in the git-backed comparison tree.

## Change summary

Allow the create-PR Files Changed view to compare against and edit the working-tree file before the branch is pushed.

## Best solution

Make only the active compare-branch side writable in `src/view/gitHubContentProvider.ts`, preserving the base side as read-only, then apply edits through the existing changed-file and working-tree paths. Route this work to the git and tree-view owners.
