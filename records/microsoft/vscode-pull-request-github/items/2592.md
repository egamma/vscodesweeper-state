# Issue #2592 — Warn me if I'm editing a file that is changed in an open pull request to prevent merge conflicts

[https://github.com/microsoft/vscode-pull-request-github/issues/2592](https://github.com/microsoft/vscode-pull-request-github/issues/2592)

## Summary

This remains a valid, unimplemented feature request. Current main can fetch changed files for a selected pull request but does not warn when an actively edited workspace file overlaps an open PR.

## Change summary

Show an editor warning when the current file has also changed on the default branch or in an open pull request.

## Best solution

Add an opt-in, API-conscious workspace indicator that compares edited files with the default branch and cached changed-file lists from relevant open PRs, with clear links to the conflicting PRs.
