# Issue #2592 — Warn me if I'm editing a file that is changed in an open pull request to prevent merge conflicts

[https://github.com/microsoft/vscode-pull-request-github/issues/2592](https://github.com/microsoft/vscode-pull-request-github/issues/2592)

## Summary

A real capability gap remains: the extension can retrieve changed files for an individual pull request, but it does not warn when the active local file overlaps an open pull request or newer base-branch changes. The request should remain open and be routed to the GitHub integration and UX owners.

## Change summary

Warn developers when the file they are editing is also changed by an open pull request or by newer changes on the base branch.

## Best solution

Add an opt-in editor decoration or notification backed by a cached comparison between the active file and changed-file lists from relevant open pull requests, with links to the overlapping PRs. Base-branch divergence should use the repository's git state without changing existing review or conflict-resolution behavior.
