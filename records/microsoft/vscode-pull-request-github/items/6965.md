# Issue #6965 — Revisit using REST API for Copilot timeline events

[https://github.com/microsoft/vscode-pull-request-github/issues/6965](https://github.com/microsoft/vscode-pull-request-github/issues/6965)

## Summary

Still necessary on current main: Copilot-authored PRs continue to fetch Copilot timeline events separately through the REST API, and the source explicitly retains this issue as the cleanup TODO. Route the existing debt to the GitHub/GraphQL integration areas.

## Change summary

Replace the Copilot-specific REST timeline request with GraphQL once GitHub exposes the required Copilot work events there.

## Best solution

When GitHub's GraphQL timeline schema exposes the Copilot work event types, add them to the timeline query and parsing path, then remove `IssueModel.getCopilotTimelineEvents`, its REST pagination/cache, and the separate timeline merge. The relevant implementation is in `src/github/issueModel.ts`, `src/github/graphql.ts`, and `src/github/utils.ts`.
