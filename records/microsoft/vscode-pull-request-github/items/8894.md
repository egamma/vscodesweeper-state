## Summary

Verified cross-repository duplicate: the open VS Code issue tracks the same request for Chat to consume and act on PR review comments through VS Code's extension-provided tools. Consolidating there preserves the broader Chat integration discussion while carrying over the extension-specific failures reported here.

## Change summary

Expose PR review comments and related actions reliably to Chat, including reading, replying to, resolving, and refreshing review threads.

## Best solution
