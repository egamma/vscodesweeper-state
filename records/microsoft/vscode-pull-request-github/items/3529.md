# Issue #3529 — "Start working on issue" should appear in command palette

[https://github.com/microsoft/vscode-pull-request-github/issues/3529](https://github.com/microsoft/vscode-pull-request-github/issues/3529)

## Summary

The requested command-palette workflow remains missing on current main. Keep this team-authored Backlog item open as the canonical request and route it to the issues area.

## Change summary

Add a command-palette action that accepts an issue number or URL and starts work without locating the issue in a configured query.

## Best solution

Add a no-argument command that prompts for an issue number or URL, resolves it against the workspace repository, and passes the resulting IssueModel into the existing start-working flow in src/issues/issueFeatureRegistrar.ts. Keep this older issue as the canonical for the equivalent request in https://github.com/microsoft/vscode-pull-request-github/issues/4636.
