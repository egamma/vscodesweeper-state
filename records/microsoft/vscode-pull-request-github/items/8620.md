# Issue #8620 — Support line-level review progress within a PR diff

[https://github.com/microsoft/vscode-pull-request-github/issues/8620](https://github.com/microsoft/vscode-pull-request-github/issues/8620)

## Summary

A real review-workflow gap remains: current main tracks progress only at file granularity, while no existing setting, command, or canonical issue covers reviewed line ranges. Route this to the review and UX areas for product and interaction design.

## Change summary

Allow reviewers to mark selected lines or ranges as reviewed, visually distinguish them, and retain that progress for a PR revision.

## Best solution

Add extension-managed line-range progress to the PR diff workflow, keyed by repository, PR, file, and head SHA so stale ranges do not carry across revisions. The review area should define commands and editor decorations for marking, clearing, and displaying locally persisted ranges without changing GitHub's file-level viewed state.
