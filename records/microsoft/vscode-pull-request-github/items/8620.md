# Issue #8620 — Support line-level review progress within a PR diff

[https://github.com/microsoft/vscode-pull-request-github/issues/8620](https://github.com/microsoft/vscode-pull-request-github/issues/8620)

## Summary

A real review-workflow gap remains: current functionality tracks progress only for whole files. Route this feature request to the review and UX areas.

## Change summary

Allow reviewers to mark line ranges as reviewed, visually de-emphasize them, and retain that progress per pull-request head.

## Best solution

Add local range-level progress to the diff review flow, keyed by repository, PR, file, and head SHA, with editor decorations and commands for marking or clearing selected ranges. Preserve the existing GitHub-backed file-level viewed state separately.

- **Fit:** aligned

- **Evidence:** The durable themes explicitly include “The review flow,” including in-editor review behavior, while the product promise is to review and manage GitHub pull requests directly in VS Code.
