# Issue #5989 — Stash files when stop working

[https://github.com/microsoft/vscode-pull-request-github/issues/5989](https://github.com/microsoft/vscode-pull-request-github/issues/5989)

## Summary

This remains an unimplemented feature request. Current main checks out the default branch directly and only reports dirty-worktree failures, so routing the opt-in stash workflow to the issues and git areas.

## Change summary

Optionally stash uncommitted changes before Stop Working checks out the default branch.

## Best solution

Add an opt-in `githubIssues` setting and handle stashing in `src/issues/currentIssue.ts` before its default-branch checkout, with explicit error handling that preserves both the working tree and current-issue state when stashing fails.
