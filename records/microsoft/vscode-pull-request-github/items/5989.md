# Issue #5989 — Stash files when stop working

[https://github.com/microsoft/vscode-pull-request-github/issues/5989](https://github.com/microsoft/vscode-pull-request-github/issues/5989)

## Summary

The requested optional stash behavior is still missing on current main. Route this existing feature request to the issues and git areas for a product decision and implementation.

## Change summary

Optionally stash uncommitted issue-branch changes before Stop Working checks out the repository's default branch.

## Best solution

Add an opt-in `githubIssues` setting and handle the stash before the default-branch checkout in `CurrentIssue.stopWorking`, preserving the current behavior by default and surfacing stash failures without ending the working session. Reuse or extract the established uncommitted-change handling used by pull-request checkout where practical.
