# Issue #8346 — Changing templates flow could be smoother

[https://github.com/microsoft/vscode-pull-request-github/issues/8346](https://github.com/microsoft/vscode-pull-request-github/issues/8346)

## Summary

The interaction remains unchanged on current main: selecting the template icon waits for templates to load before opening a VS Code quick pick. This accepted Backlog request should remain open and be routed to the description-page and UX owners.

## Change summary

Make switching among multiple pull-request templates faster and more direct, such as through an inline dropdown or cycling control.

## Best solution

Expose the available templates and current selection directly in the create-PR description UI, preferably through a compact dropdown whose data is prefetched or cached when the view initializes, avoiding the network-dependent pause before showing the choices.
