# Issue #8346 — Changing templates flow could be smoother

[https://github.com/microsoft/vscode-pull-request-github/issues/8346](https://github.com/microsoft/vscode-pull-request-github/issues/8346)

## Summary

Template switching still fetches templates before opening a Quick Pick; the requested smoother interaction remains missing. Route this accepted Backlog request to the description-page and UX areas.

## Change summary

Make switching PR description templates faster and more direct, potentially through a dropdown or cycling control.

## Best solution

Provide responsive template selection in the PR creation description toolbar while preserving template contents and repository selection. The maintainer should choose whether users select a named template directly or cycle through templates.

- **Reason:** Smoother template selection improves the native pull-request creation workflow inside VS Code.
