# Issue #8346 — Changing templates flow could be smoother

[https://github.com/microsoft/vscode-pull-request-github/issues/8346](https://github.com/microsoft/vscode-pull-request-github/issues/8346)

## Summary

The UX gap remains on current main: changing a PR template still requires an asynchronous extension-host request followed by a Quick Pick. Keep this Backlog request open and route it to the creation-view UX owners.

## Change summary

Make switching among multiple pull-request templates faster and more direct, such as through an inline dropdown or cycling control.

## Best solution

Expose available templates directly in the create-PR webview and use an inline selector that updates the description without opening a separate Quick Pick. Preserve explicit template names and avoid repeated loading where practical.
