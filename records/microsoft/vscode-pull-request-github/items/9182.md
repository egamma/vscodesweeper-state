# Issue #9182 — Add URI handler path to open a PR file diff at a line

[https://github.com/microsoft/vscode-pull-request-github/issues/9182](https://github.com/microsoft/vscode-pull-request-github/issues/9182)

## Summary

The external single-file, line-targeted PR diff link remains a real capability gap. Route to review: existing multi-diff links and overview permalinks cover related workflows, but neither satisfies navigation from an external HTML report.

## Change summary

Add an external URI endpoint that opens a checked-out PR's specified file diff and selects a line in the head pane.

## Best solution

Provide a supported single-file deep-link contract using the extension's existing PR diff resolution, preserving the checked-out PR review experience. Define the endpoint's file and line semantics before implementation.
