# Issue #8741 — Implement automated Pull Request prioritization system

[https://github.com/microsoft/vscode-pull-request-github/issues/8741](https://github.com/microsoft/vscode-pull-request-github/issues/8741)

## Summary

Existing notification scoring and custom PR queries only partially address this request: neither assesses changed-code complexity and regression risk across incoming PRs. Keep it open for a product decision in the review and explorer areas.

## Change summary

Prioritize incoming pull requests using change size, review complexity, affected areas, regression risk, and impact.

## Best solution

Define an explainable, optional review-prioritization experience that accounts for changed-code metadata, distinguishing it from existing notification importance scoring. Settle the scoring contract and presentation before implementation.
