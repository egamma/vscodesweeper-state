# Issue #2998 — Auto-fork when when you don't have permissions to commit

[https://github.com/microsoft/vscode-pull-request-github/issues/2998](https://github.com/microsoft/vscode-pull-request-github/issues/2998)

## Summary

Implemented and shipped: the create-PR flow now detects insufficient push permission, offers to create a fork, configures the remotes, and publishes the branch to that fork.

## Change summary

Automatically create and configure a fork when a contributor cannot push the branch needed for a pull request.

## Best solution

Keep the shared branch-publishing flow introduced by commit b058a0eb76145446f8bfb5051d8490bab233d558, which gives regular VS Code and Codespaces PR creation the same permission-aware fork handling.
