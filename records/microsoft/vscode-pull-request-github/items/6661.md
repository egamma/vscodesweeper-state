## Change summary

Starting work on an issue fails when the current branch tracks a non-GitHub remote even though a valid GitHub remote is explicitly configured.

## Best solution

Review and land https://github.com/microsoft/vscode-pull-request-github/pull/8274 so `FolderRepositoryManager.getOrigin()` falls back to the configured GitHub remotes when the branch upstream is not hosted on GitHub, while preserving upstream selection when it is a GitHub remote.
