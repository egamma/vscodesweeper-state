# Issue #8696 — allow {un,}checking PR description checkboxes by clicking

[https://github.com/microsoft/vscode-pull-request-github/issues/8696](https://github.com/microsoft/vscode-pull-request-github/issues/8696)

## Summary

A real interaction gap remains on current main: task-list checkboxes are rendered as non-interactive HTML even though the description can be edited through a separate action. Route this feature request to the description-page and UX owners.

## Change summary

Allow users with edit permission to toggle task-list checkboxes directly in a pull request description.

## Best solution

Add an accessible checkbox interaction to the PR description renderer that updates the corresponding Markdown task-list marker through the existing description-edit API, while leaving comment checkboxes and descriptions without edit permission read-only.
