# Issue #8696 — allow {un,}checking PR description checkboxes by clicking

[https://github.com/microsoft/vscode-pull-request-github/issues/8696](https://github.com/microsoft/vscode-pull-request-github/issues/8696)

## Summary

A real capability gap remains: task-list checkboxes render with pointer styling but cannot update an editable PR description. Route this feature request to the description-page area.

## Change summary

Allow users to check or uncheck task-list items directly in rendered PR descriptions.

## Best solution

Make task-list inputs interactive when the user can edit the PR description, map the selected item back to its Markdown task marker, and persist the updated body through the existing description-edit pipeline in `webviews/components/comment.tsx`.

- **Evidence:** The product promise is to “Review and manage your GitHub pull requests and issues directly in VS Code,” and the durable themes explicitly include the description-page webview.
