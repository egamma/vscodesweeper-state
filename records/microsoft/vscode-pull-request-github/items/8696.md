[https://github.com/microsoft/vscode-pull-request-github/issues/8696](https://github.com/microsoft/vscode-pull-request-github/issues/8696)

## Summary

Directly toggling PR-description task checkboxes remains unsupported on main. Route to the description-page area; editing the Markdown is a workaround, not coverage of the requested interaction.

## Change summary

Allow clicking rendered PR-description checkboxes to persist their checked or unchecked state to GitHub.

## Best solution

Support persistent task-checkbox toggling in the description webview for users allowed to edit the description, preserving unrelated Markdown and surfacing save failures.
