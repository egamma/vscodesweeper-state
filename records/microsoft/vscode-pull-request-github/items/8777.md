# Issue #8777 — Issue fields are not supported in issue queries

[https://github.com/microsoft/vscode-pull-request-github/issues/8777](https://github.com/microsoft/vscode-pull-request-github/issues/8777)

## Summary

The behavior remains reproducible as a GitHub Search API limitation rather than an extension defect. The existing `upstream` classification is appropriate, and the issue should remain open while API support or a viable extension-side fallback is evaluated.

## Change summary

Allow configured issue queries to filter organization issues by custom issue fields such as `field.priority:high`.

## Best solution

GitHub's issue-search API should support the same issue-field qualifiers as the GitHub web interface. If that does not become available, assess whether a Projects v2 field-query fallback can preserve the existing cross-repository `githubIssues.queries` behavior without excessive requests or reduced compatibility.
