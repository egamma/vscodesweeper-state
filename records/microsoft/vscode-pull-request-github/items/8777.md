# Issue #8777 — Issue fields are not supported in issue queries

[https://github.com/microsoft/vscode-pull-request-github/issues/8777](https://github.com/microsoft/vscode-pull-request-github/issues/8777)

## Summary

GitHub's API search currently returns no results for the field qualifier, while the extension forwards the configured query unchanged. This is correctly classified as an upstream service limitation and should remain open for tracking.

## Change summary

Issue queries using qualifiers such as `field.priority:high` return an empty result.

## Best solution

GitHub's issue-search API should support issue-field qualifiers consistently with GitHub's web search; the extension will then inherit that behavior through its existing GraphQL search path. An extension-side workaround would require a separate project-field query and should be considered only if the API limitation persists.
