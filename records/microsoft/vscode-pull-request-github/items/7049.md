# Issue #7049 — Support filtering the files view to only show files with comments

[https://github.com/microsoft/vscode-pull-request-github/issues/7049](https://github.com/microsoft/vscode-pull-request-github/issues/7049)

## Summary

The requested commented-files filter remains missing from the PR file tree. Route to explorer and review; existing settings and related issues do not cover this capability.

## Change summary

Add an option to show only files with review comments in the Pull Requests pane while preserving their directory hierarchy.

## Best solution

Provide an optional comment-presence filter in the extension-owned PR file tree, retaining hierarchical navigation and leaving the unfiltered view available.
