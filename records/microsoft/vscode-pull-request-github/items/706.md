# Issue #706 — Don't show errors when offline

[https://github.com/microsoft/vscode-pull-request-github/issues/706](https://github.com/microsoft/vscode-pull-request-github/issues/706)

## Summary

Still present on current main: automatic PR-tree loading surfaces every non-authentication network failure as an error notification. This team-authored canonical issue must remain open and should be routed to the tree-view owners.

## Change summary

Suppress unsolicited pull-request loading errors while offline, while retaining useful feedback for an explicit user refresh.

## Best solution

Distinguish automatic tree loading from user-initiated refresh in the PR category path, logging offline failures without notifying during background loads while preserving actionable errors after an explicit refresh.
