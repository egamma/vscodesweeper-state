# Issue #706 — Don't show errors when offline

[https://github.com/microsoft/vscode-pull-request-github/issues/706](https://github.com/microsoft/vscode-pull-request-github/issues/706)

## Summary

Keep open: automatic PR-tree loading still displays error notifications for offline request failures. This team-authored issue remains the canonical report; the later matching report was explicitly closed as its duplicate.

## Change summary

Avoid unsolicited error notifications when background GitHub requests fail because the user is offline.

## Best solution

Make background offline failures non-intrusive in the PR-loading flow while retaining diagnostic logs and useful feedback for explicit user actions. Preserve authentication-error handling and distinguish connectivity failures from other actionable errors.
