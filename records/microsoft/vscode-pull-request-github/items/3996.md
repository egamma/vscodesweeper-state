# Issue #3996 — Allow bypass branch protection in the extension

[https://github.com/microsoft/vscode-pull-request-github/issues/3996](https://github.com/microsoft/vscode-pull-request-github/issues/3996)

## Summary

The capability remains absent on current main, and this issue is the established canonical for adding an authorized branch-protection bypass to the extension's merge flow. Keep it open and route it to the review and GitHub integration areas.

## Change summary

Allow authorized users to bypass branch-protection rules when merging a pull request from the extension.

## Best solution

Extend the PR merge UI and merge request path to expose an explicit bypass option only when GitHub reports that the viewer is authorized, while preserving the normal protected merge behavior by default. The implementation should cover both the description webview and other extension merge entry points.
