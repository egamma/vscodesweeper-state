# Issue #2243 — Enhancement request: Detect already-linked PR branches when selecting an issue

[https://github.com/microsoft/vscode-pull-request-github/issues/2243](https://github.com/microsoft/vscode-pull-request-github/issues/2243)

## Summary

Keep open while the linked implementation PR is reviewed. Current main still presents a new-branch input rather than discovering and clearly offering an existing branch associated with the issue.

## Change summary

When starting work on an issue with a linked pull request, offer to check out that pull request's existing branch instead of presenting it as a new branch.

## Best solution

Review and land https://github.com/microsoft/vscode-pull-request-github/pull/6278 after ensuring the branch picker prioritizes the actual linked pull-request branch rather than relying only on an issue-number naming heuristic, while retaining explicit new-branch creation as an option.
