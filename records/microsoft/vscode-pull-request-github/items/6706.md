# Issue #6706 — Show checkbox for checking out `main` after PR creation

[https://github.com/microsoft/vscode-pull-request-github/issues/6706](https://github.com/microsoft/vscode-pull-request-github/issues/6706)

## Summary

The checkout behavior exists as a global setting, but the requested per-creation checkbox is still absent from the current PR creation UI. Keep the accepted Backlog request open and route it to UX.

## Change summary

Add a checkbox to the pull-request creation form that checks out the repository's default branch after creating the PR.

## Best solution

Add a per-creation checkout-default-branch control to the creation webview, while retaining `githubPullRequests.postCreate` as the persistent default. Pass that selection through the creation state and use it when `ReviewManager.createPullRequest` performs the post-create action.

- **Fit:** aligned

- **Evidence:** The product promise is to "Review and manage your GitHub pull requests and issues directly in VS Code," and the current-priorities layer identifies creation-flow polish as an active workstream.
