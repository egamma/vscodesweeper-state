# Issue #6706 — Show checkbox for checking out `main` after PR creation

[https://github.com/microsoft/vscode-pull-request-github/issues/6706](https://github.com/microsoft/vscode-pull-request-github/issues/6706)

## Summary

The requested per-creation checkbox remains absent on main. The existing global post-create setting provides the behavior but does not cover the requested one-off choice, so this should remain open and route to UX and git.

## Change summary

Add a checkbox to the pull-request creation form for checking out the repository's default branch after creation.

## Best solution

Add a per-creation checkout-default-branch control in `webviews/createPullRequestViewNew/app.tsx`, carry it through the creation state, and honor it in the post-create callback while preserving `githubPullRequests.postCreate` as the global default.
