[https://github.com/microsoft/vscode-pull-request-github/issues/6333](https://github.com/microsoft/vscode-pull-request-github/issues/6333)

## Summary

Keep this canonical feature request open. Current main still fetches unread notifications only, and maintainers have consolidated broader notification-filtering requests here.

## Change summary

Allow the Notifications view to show and distinguish read and unread notifications and support additional filtering.
