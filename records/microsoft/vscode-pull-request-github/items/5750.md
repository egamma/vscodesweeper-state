# Issue #5750 — Button/Input outlines have disappeared in the Dark HC theme

[https://github.com/microsoft/vscode-pull-request-github/issues/5750](https://github.com/microsoft/vscode-pull-request-github/issues/5750)

## Summary

Confirmed accessibility bug remains on main: branch, Cancel, and Create controls lack persistent borders in high-contrast themes. Existing theme and accessibility labels route it correctly.

## Change summary

Buttons and input-like branch controls lose their outlines in the Dark High Contrast theme.

## Best solution

Update webviews/common/common.css so branch, secondary, and split Create buttons use the high-contrast border token at rest while retaining the active-border treatment for focus and hover.
