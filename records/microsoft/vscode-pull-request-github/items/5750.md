[https://github.com/microsoft/vscode-pull-request-github/issues/5750](https://github.com/microsoft/vscode-pull-request-github/issues/5750)

## Summary

The high-contrast border gap remains in current source: unfocused branch-selection buttons still inherit transparent borders. Later styling changes cover some action buttons, but do not satisfy the maintainer's full requirement.

## Change summary

Restore visible high-contrast borders around branch selectors, Cancel, and Create in the pull-request creation view.

## Best solution
