# Issue #5750 — Button/Input outlines have disappeared in the Dark HC theme

[https://github.com/microsoft/vscode-pull-request-github/issues/5750](https://github.com/microsoft/vscode-pull-request-github/issues/5750)

## Summary

Still present on current main: high-contrast inputs have a resting contrast border, but the branch, Cancel, and Create buttons only receive one while focused or hovered. The issue is already routed to the appropriate theme and accessibility areas.

## Change summary

Controls in the pull-request creation view lack visible resting-state outlines in the Dark High Contrast theme.

## Best solution

Update the high-contrast rules in webviews/common/common.css so the branch selector, Cancel button, and both parts of the Create split button use the contrast border in their resting state while preserving the distinct focus and hover treatments.

## Evidence

- **current source:** webviews/common/common.css defines a resting `var(--vscode-contrastBorder)` border for `.vscode-high-contrast input`, but button borders are defined only for `.vscode-high-contrast button:focus` and `button:hover`; ordinary high-contrast buttons retain the base transparent border.
- **affected controls:** webviews/createPullRequestViewNew/app.tsx renders the branch selector as `button.input-box`, Cancel as `button.secondary`, and Create through `ContextDropdown`; webviews/components/contextDropdown.tsx renders Create as `button.split-left` and `button.split-right`, so all follow the incomplete shared button styling.
- **maintainer confirmation:** The maintainer confirmed that the branch, Cancel, and Create buttons all require a border in high-contrast themes: https://github.com/microsoft/vscode-pull-request-github/issues/5750#issuecomment-3636264904
