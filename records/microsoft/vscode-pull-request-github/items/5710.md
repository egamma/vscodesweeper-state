# Issue #5710 — Resolve Conversation with Commit

[https://github.com/microsoft/vscode-pull-request-github/issues/5710](https://github.com/microsoft/vscode-pull-request-github/issues/5710)

## Summary

A real gap remains in the review workflow: current main can reply while resolving a thread, but it cannot select or capture a commit and associate that commit with one or more conversations. The team outlined an acceptable flow, so this should remain open and be routed to the comments, review, and git areas.

## Change summary

Add a workflow that associates review conversations with a commit, posts the commit SHA, and resolves the selected conversations.

## Best solution

Implement the team-proposed "Resolve with Existing Commit" action by selecting a commit, replying with its SHA, and resolving the thread; before implementation, decide whether to extend it with the later request to mark multiple threads for resolution after the next SCM commit. Keep normal commit creation in VS Code's Source Control UI rather than duplicating it in the extension.
