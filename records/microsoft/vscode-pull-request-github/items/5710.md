# Issue #5710 — Resolve Conversation with Commit

[https://github.com/microsoft/vscode-pull-request-github/issues/5710](https://github.com/microsoft/vscode-pull-request-github/issues/5710)

## Summary

The maintainer-endorsed workflow remains unimplemented: conversations can be resolved, but no action associates them with a selected or newly created commit. Route this valid feature request to the review, comments, and git areas.

## Change summary

Associate one or more review conversations with a commit, post its SHA to each conversation, and resolve them automatically.

## Best solution

Implement the approved “Resolve with Existing Commit” flow, with a commit picker and shared logic that posts “Resolved with <commit SHA>” before resolving the selected threads. Consider the later mark-for-next-commit bulk workflow as an extension of that design.
