# Issue #8083 — Would be cool if the GitHub Pull Requests: Delete local branches and remotes action would be available on the branches node

[https://github.com/microsoft/vscode-pull-request-github/issues/8083](https://github.com/microsoft/vscode-pull-request-github/issues/8083)

## Summary

The cleanup command exists, but its requested placement on the SCM Branches node is still missing. Keep this accepted, team-authored request open; the maintainer tied investigation to the repositories explorer graduating from experimental.

## Change summary

Expose Delete local branches and remotes on the SCM repositories explorer's Branches node.

## Best solution

Once the repositories explorer provides a supported contribution surface, expose the existing cleanup flow on its Branches node while preserving Command Palette access. Confirm repository targeting for node invocation, since the current command visits every folder manager.
