# Issue #5940 — Conflict view only shows the first conflicted file

[https://github.com/microsoft/vscode-pull-request-github/issues/5940](https://github.com/microsoft/vscode-pull-request-github/issues/5940)

## Summary

Keep open: GitHub's compare API truncates large comparisons, preventing the extension from discovering every conflicted file in pull requests with at least 300 changed files. The current source explicitly retains this limitation, and the team placed the issue On Deck while waiting for a more suitable API.

## Change summary

Show every conflicted file in the conflict-resolution view for pull requests containing more than 300 changed files.

## Best solution

Use a paginated GitHub API for merge-comparison files when one becomes available, or evaluate parsing the complete `.diff` response as a bounded extension-side workaround. The conflict discovery path in `src/github/folderRepositoryManager.ts` and `PullRequestModel.compareBaseBranchForMerge` must receive the complete changed-file set before constructing the resolution model.
