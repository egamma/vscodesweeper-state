# Issue #5940 — Conflict view only shows the first conflicted file

[https://github.com/microsoft/vscode-pull-request-github/issues/5940](https://github.com/microsoft/vscode-pull-request-github/issues/5940)

## Summary

The limitation remains on main: GitHub's comparison API caps results at 300 files, so large pull requests cannot produce a complete conflict view. Keep this team-authored issue open pending a complete API source.

## Change summary

Show every conflicted file when resolving conflicts for pull requests with more than 300 changed files.

## Best solution

Use a GitHub API that returns the complete conflict or changed-file set, then remove the 300-file guard in src/github/folderRepositoryManager.ts and populate the conflict-resolution model from the complete results.
