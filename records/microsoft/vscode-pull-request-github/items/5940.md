# Issue #5940 — Conflict view only shows the first conflicted file

[https://github.com/microsoft/vscode-pull-request-github/issues/5940](https://github.com/microsoft/vscode-pull-request-github/issues/5940)

## Summary

Keep open: the maintainer identified GitHub's 300-file comparison limit and explicitly deferred resolution pending API support. Current source prevents entering resolution with a capped response, but does not provide complete conflict resolution for large comparisons.

## Change summary

Show all conflicted files when resolving a PR whose base-to-head comparison exceeds GitHub's 300-file limit.

## Best solution

Provide complete conflict discovery and safe branch updates for large comparisons once GitHub supports the necessary data, or reconsider an extension-side diff fallback. The current guard avoids a partial conflict list but leaves the requested workflow unavailable.
