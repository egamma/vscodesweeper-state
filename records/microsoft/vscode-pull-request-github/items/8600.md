# Issue #8600 — Open Github Action checks in Github Actions extension

[https://github.com/microsoft/vscode-pull-request-github/issues/8600](https://github.com/microsoft/vscode-pull-request-github/issues/8600)

## Summary

The requested Actions-extension handoff remains missing: Details still links to the browser, while the newer in-editor log viewer only partially addresses the motivation. Route to the description-page area for an integration decision.

## Change summary

Allow PR check Details to open the corresponding run in the GitHub Actions extension, with browser fallback.

## Best solution

Decide whether to support an Actions-extension handoff from PR checks, using a supported integration contract and preserving browser access when unavailable. Existing failed-check log viewing should remain available independently.
