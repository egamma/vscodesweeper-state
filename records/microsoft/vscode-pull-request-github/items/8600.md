# Issue #8600 — Open Github Action checks in Github Actions extension

[https://github.com/microsoft/vscode-pull-request-github/issues/8600](https://github.com/microsoft/vscode-pull-request-github/issues/8600)

## Summary

A real integration gap remains: check details still use the GitHub URL directly, and no existing setting or suitable GitHub Actions extension API covers the requested handoff. Keep the request open and route it to the description-page UX owners.

## Change summary

Allow PR check details to open workflow runs in the GitHub Actions extension instead of a browser, with browser fallback.

## Best solution

Coordinate a public URL- or run-ID-based opening API with the GitHub Actions extension, then add an opt-in destination setting and browser fallback in the PR overview check-details path.

- **Reason:** Opening workflow information inside VS Code advances the extension's native, in-editor pull-request workflow.
- **Evidence:** The stated product promise is to "Review and manage your GitHub pull requests and issues directly in VS Code," with in-editor workflow preferred over browser replication.
