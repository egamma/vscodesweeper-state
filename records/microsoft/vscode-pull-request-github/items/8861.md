# Issue #8861 — Unable to add comments on diff files in workspaces with more than one PR in review

[https://github.com/microsoft/vscode-pull-request-github/issues/8861](https://github.com/microsoft/vscode-pull-request-github/issues/8861)

## Summary

The controller-ID collision is present on main, and an open PR explicitly fixes this issue. Keep it open while that implementation is reviewed and merged; the assigned 1.134.0 milestone independently bars closure.

## Change summary

Checking out PRs in multiple workspace repositories disables review-comment controls for all but the most recently checked-out PR.

## Best solution

Review and land https://github.com/microsoft/vscode-pull-request-github/pull/8863, which qualifies each review comment controller by repository as well as owner and PR number and adds regression coverage.
