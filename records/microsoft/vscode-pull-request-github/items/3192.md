[https://github.com/microsoft/vscode-pull-request-github/issues/3192](https://github.com/microsoft/vscode-pull-request-github/issues/3192)

## Summary

A real feature gap remains, but the attempted implementation was closed because VS Code cannot right-align tree-item details without making the file list visually busy. Keep this open and route it to the tree-view and upstream/vscode areas pending the required core API.

## Change summary

Show total and per-file added/deleted line counts in the pull-request changes view.

## Best solution

Track the right-aligned TreeItem API in https://github.com/microsoft/vscode/issues/107183, then display per-file additions and deletions in the PR changes tree without displacing path information; the total can be surfaced in the containing changes category.
