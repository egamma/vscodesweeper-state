[https://github.com/microsoft/vscode-pull-request-github/issues/3192](https://github.com/microsoft/vscode-pull-request-github/issues/3192)

## Summary

The per-file change-count display remains missing on main, and the attempted implementation was closed without merging. Retain the request and route it to explorer; the maintainer explicitly deferred revisiting it until right-aligned tree details are available.

## Change summary
