[https://github.com/microsoft/vscode-pull-request-github/issues/4552](https://github.com/microsoft/vscode-pull-request-github/issues/4552)

## Summary

The colorization gap remains on current main: permalink blocks are rendered and themed as code containers, but no syntax-token styling is applied. Keep the accepted Backlog request open and route it to comments and the description page.

## Change summary

Add syntax colorization to source lines rendered from GitHub permalinks in comments and PR descriptions.

## Best solution

Apply theme-aware syntax highlighting to permalink code using the linked file's language or extension, consistently across comment and description-page rendering.
