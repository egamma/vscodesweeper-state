# Issue #4552 — No colorization for code from permalink

[https://github.com/microsoft/vscode-pull-request-github/issues/4552](https://github.com/microsoft/vscode-pull-request-github/issues/4552)

## Summary

The permalink preview exists, but current main still emits its source as an untyped Markdown code fence in review comments, so syntax colorization is not consistently available. Keep the request open and route it to the comments area.

## Change summary

Add syntax colorization to source-code snippets rendered from GitHub permalinks.

## Best solution

Determine the permalinked file's language and attach that language to the generated code block in `GHPRComment.replacePermalink` in `src/github/prComment.ts`, using VS Code theme-compatible highlighting and preserving the existing local-file and GitHub links.
