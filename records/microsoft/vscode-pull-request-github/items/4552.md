## Summary

The colorization gap remains in the extension-generated permalink snippets: current source emits code fences without a language identifier. Route this accepted Backlog request to comments; the related completed work does not establish that permalink colorization was implemented.

## Change summary

Provide basic syntax colorization for code snippets expanded from GitHub permalinks.
