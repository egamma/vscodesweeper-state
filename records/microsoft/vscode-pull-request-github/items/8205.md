# Issue #8205 — Filter comments by reactions

[https://github.com/microsoft/vscode-pull-request-github/issues/8205](https://github.com/microsoft/vscode-pull-request-github/issues/8205)

## Summary

A real review-workflow gap remains: comments expose reactions, but current main has no setting, command, or list predicate for filtering threads by those reactions. Keep this team-authored feature request open and route it to the comments and review areas.

## Change summary

Allow reviewers to filter comment threads according to the reactions present or absent on their comments.

## Best solution

Add reaction-aware predicates to the comment-list filtering surface, supporting both presence and absence checks so teams can use reactions as intermediate review states. Coordinate with VS Code core if the filtering UI cannot consume reaction metadata through the existing comments API.
