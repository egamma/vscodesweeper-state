# Issue #8161 — Hover over on the Pull request view over a user id shows in a popup an URL instead of the user name.

[https://github.com/microsoft/vscode-pull-request-github/issues/8161](https://github.com/microsoft/vscode-pull-request-github/issues/8161)

## Summary

The requested identity information remains missing from both PR surfaces. Route to description page and explorer; the maintainer proposed enhancing the hovers, so the earlier by-design explanation does not justify declining the request.

## Change summary

Expose users' readable names in PR-tree details and PR-page user hovers without requiring navigation to GitHub.

## Best solution
