# Issue #8161 — Hover over on the Pull request view over a user id shows in a popup an URL instead of the user name.

[https://github.com/microsoft/vscode-pull-request-github/issues/8161](https://github.com/microsoft/vscode-pull-request-github/issues/8161)

## Summary

A real usability gap remains on main: PR-tree details expose only the login, while user links on the description page show only their URL on hover. The maintainer endorsed displaying the user's name while retaining the URL.

## Change summary

Show a user's readable display name in PR-tree and description-page hovers instead of exposing only an opaque login or profile URL.

## Best solution

Include the account name in the PR tree's full-details tooltip and render description-page user-link titles as `Name (URL)` when a name is available, retaining the URL-only fallback.

- **Fit:** aligned

- **Evidence:** The product promise is to "Review and manage your GitHub pull requests and issues directly in VS Code," and trees and the description page are durable investment themes.
