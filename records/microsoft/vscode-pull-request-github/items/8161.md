# Issue #8161 — Hover over on the Pull request view over a user id shows in a popup an URL instead of the user name.

[https://github.com/microsoft/vscode-pull-request-github/issues/8161](https://github.com/microsoft/vscode-pull-request-github/issues/8161)

## Summary

Thanks for the context. This remains a valid feature request: current main still exposes only the profile URL in description-page hovers and lacks an author-specific tree tooltip, while a maintainer has endorsed showing the user's name alongside the required URL.

## Change summary

Show a pull-request author's human-readable name when hovering their identity in the PR tree and description page, while retaining the GitHub profile URL.

## Best solution

Use the author name already supplied to the description webview to render a hover such as `Alex Ross (https://github.com/alexr00)`, falling back to the login when no name is available. Add the same identity information to the PR tree tooltip so Enterprise users do not need to leave VS Code to identify authors.
