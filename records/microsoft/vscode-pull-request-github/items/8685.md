# Issue #8685 — Session Card Parity with GitHub web

[https://github.com/microsoft/vscode-pull-request-github/issues/8685](https://github.com/microsoft/vscode-pull-request-github/issues/8685)

## Summary

Existing agent-status icons and session links provide partial coverage, but the PR description still lacks the requested inline activity card. Keep the request open and route it to the description-page and chat areas for a product decision.

## Change summary

Show agent-session activity directly in the PR description so users can follow ongoing work without repeatedly checking comments or opening the session separately.

## Best solution

Decide on a native session-activity summary in the PR description that makes ongoing work visible and links to the full session. Reuse the existing session integration rather than replicate GitHub's web interface wholesale.
