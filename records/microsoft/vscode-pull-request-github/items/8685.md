# Issue #8685 — Session Card Parity with GitHub web

[https://github.com/microsoft/vscode-pull-request-github/issues/8685](https://github.com/microsoft/vscode-pull-request-github/issues/8685)

## Summary

A real presentation gap remains: the PR description shows coarse Coding Agent lifecycle events and a session-log link, but not GitHub's inline activity card. Route this feature request to the description-page and chat owners.

## Change summary

Show an updating Coding Agent session card in the VS Code pull-request description so users can monitor agent activity without repeatedly refreshing the PR.

## Best solution

Extend the PR description data model and webview to render the active session's progress and recent activity, updating while the session is running. Preserve the existing View Session action for accessing the complete session log.
