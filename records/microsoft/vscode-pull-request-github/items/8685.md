# Issue #8685 — Session Card Parity with GitHub web

[https://github.com/microsoft/vscode-pull-request-github/issues/8685](https://github.com/microsoft/vscode-pull-request-github/issues/8685)

## Summary

A real feature gap remains: the PR description currently exposes coding-agent status and a session-log link, but not GitHub's richer live session activity card. Keep the request open and route it to the description-page and chat owners.

## Change summary

Show a live coding-agent session card in the VS Code pull-request UI so users can monitor agent activity without repeatedly checking comments or refreshing the PR.

## Best solution

Add a session activity component to the PR description page that presents the coding agent's current state and recent activity, reusing the existing session-link and coding-agent event infrastructure rather than duplicating the GitHub web UI wholesale.
