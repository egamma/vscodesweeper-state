# Issue #4517 — Support gravatars

[https://github.com/microsoft/vscode-pull-request-github/issues/4517](https://github.com/microsoft/vscode-pull-request-github/issues/4517)

## Summary

The requested Enterprise Gravatar support remains incomplete on current main. The issue is team-authored and accepted into the On Deck milestone, while the referenced implementation PR was closed without merging.

## Change summary

Provide avatars for GitHub Enterprise users who lack directly usable Enterprise avatar images, with optional Gravatar fallback.

## Best solution

Add an explicitly configurable Gravatar fallback or authenticated Enterprise-avatar proxy in the GitHub integration layer, covering the tree and webview avatar surfaces. The implementation should pass available user email data into the fallback path and include focused Enterprise avatar tests.
