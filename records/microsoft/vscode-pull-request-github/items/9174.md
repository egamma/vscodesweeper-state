# Issue #9174 — There is no button to add comment on binary file (or text file)

[https://github.com/microsoft/vscode-pull-request-github/issues/9174](https://github.com/microsoft/vscode-pull-request-github/issues/9174)

## Summary

Text-file commenting already has an editor action, but that does not establish a usable commenting entry point for binary files. Keep the binary-file capability request open and route it to the review/comments areas.

## Change summary

Provide a discoverable way to create file-level PR comments on binary files, not only display comments created on GitHub.

## Best solution

Provide a file-level commenting entry point that works without a text editor, preserving the existing text-file action and GitHub review semantics. Determine whether any necessary platform support belongs in VS Code core before choosing the UI.
