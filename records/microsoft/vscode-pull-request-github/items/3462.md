# Issue #3462 — Support PR comments in notebooks

[https://github.com/microsoft/vscode-pull-request-github/issues/3462](https://github.com/microsoft/vscode-pull-request-github/issues/3462)

## Summary

Verified cross-repository duplicate: VS Code core's open notebook-commenting issue owns the APIs and source mapping required to display and create pull-request comments on notebook cells.

## Change summary

Allow reviewers to create pull-request comments on individual notebook cells or code lines.

## Best solution

Consolidate the platform work on https://github.com/microsoft/vscode/issues/214017, where VS Code core can provide notebook comment locations and map serialized file ranges to cells; once that API exists, this extension can integrate its existing PR comment provider with it.
