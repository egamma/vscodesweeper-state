# Issue #3462 — Support PR comments in notebooks

[https://github.com/microsoft/vscode-pull-request-github/issues/3462](https://github.com/microsoft/vscode-pull-request-github/issues/3462)

## Summary

The required notebook comment mapping is owned by VS Code core and is now tracked in a detailed open canonical issue. Consolidating there preserves the design discussion and avoids parallel tracking.

## Change summary

Allow pull-request reviewers to create line- or cell-level comments in notebook diffs.

## Best solution

Complete the notebook file-range to cell-range API design in https://github.com/microsoft/vscode/issues/214017, then integrate that API into this extension's comment controllers.
