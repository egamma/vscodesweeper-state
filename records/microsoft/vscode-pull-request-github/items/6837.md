# Issue #6837 — Notifications: show a badge on the view for new notifications

[https://github.com/microsoft/vscode-pull-request-github/issues/6837](https://github.com/microsoft/vscode-pull-request-github/issues/6837)

## Summary

The Notifications view still has no badge; the existing Pull Requests badge covers only a filtered subset of notifications. Keep this accepted Backlog request open and route it to the notifications area, including the maintainer-requested reconciliation of the two notification surfaces.

## Change summary

Show a badge on the Notifications view so users can notice newly arrived notifications.

## Best solution

Provide a notification indicator for the Notifications view, with clear count and clearing semantics consistent with the existing Pull Requests indicator. Resolve the intended relationship between the two indicators before implementation.

## Vision fit

- **Fit:** aligned
- **Reason:** Making incoming notifications discoverable supports managing GitHub activity without leaving the editor.
- **Evidence:** The product promise is to review and manage GitHub pull requests and issues directly in VS Code; the durable trees, queries, and views theme explicitly includes the notifications view.
