[https://github.com/microsoft/vscode-pull-request-github/issues/6837](https://github.com/microsoft/vscode-pull-request-github/issues/6837)

## Summary

The notification view still lacks its own unread badge, and a maintainer explicitly identified this issue as the canonical place for reconciling notification presentation. Keep it open and route it to the notifications view area.

## Change summary
