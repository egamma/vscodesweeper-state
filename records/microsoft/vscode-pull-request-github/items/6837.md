# Issue #6837 — Notifications: show a badge on the view for new notifications

[https://github.com/microsoft/vscode-pull-request-github/issues/6837](https://github.com/microsoft/vscode-pull-request-github/issues/6837)

## Summary

The notification view still has no badge for unread notifications, while the separate Pull Requests view can show a notification count. This remains the canonical request for reconciling those notification surfaces and should stay open under the notifications-view area.

## Change summary

Show a badge on the Notifications view when new GitHub notifications arrive.

## Best solution

Retain the Notifications TreeView created in src/notifications/notificationsFeatureRegistar.ts and update its badge from the unread count maintained by NotificationsManager, including after polling and mark-as-read or mark-as-done operations. Reconcile this with the older Pull Requests notification badge and its configuration so users receive one consistent notification signal.
