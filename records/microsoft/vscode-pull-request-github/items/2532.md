## Summary

This reusable-branch workflow is a source-confirmed instance of the stale closed-PR association now tracked by the broader open canonical issue.

## Change summary

A long-lived development branch reused for successive pull requests remains associated with an already-merged PR, repeatedly entering review mode and showing an update notification.

## Best solution

Consolidate on https://github.com/microsoft/vscode-pull-request-github/issues/8676 and prevent closed PRs found through a branch's tracked upstream from being persisted as its current association; existing stale metadata should also be cleared.
