[https://github.com/microsoft/vscode-pull-request-github/issues/8824](https://github.com/microsoft/vscode-pull-request-github/issues/8824)

## Summary

The blank view follows failed GitHub API requests, but the thread contains two different failures—network timeouts tied to a Windows Ethernet connection and repository-metadata 404s. More environment and authentication diagnostics are needed to isolate any remaining extension defect.

## Change summary

The extension initializes to an empty pull-request view when GitHub API requests time out or return repository-metadata errors.

## Best solution

Separate the network-timeout scenario from inaccessible-repository 404s, then determine whether the extension should surface a recoverable connection error instead of an empty view. Investigating the timeout requires GitHub Authentication output and connectivity results from the WSL extension host while the affected Ethernet interface is connected.
