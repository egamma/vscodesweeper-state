# Issue #1964 — Clean up TODO comment after issue closed

[https://github.com/microsoft/vscode-pull-request-github/issues/1964](https://github.com/microsoft/vscode-pull-request-github/issues/1964)

## Summary

The requested closed-issue diagnostic remains a real gap on current main. A directly linked implementation PR was closed without merging, and no open canonical issue owns this cleanup behavior.

## Change summary

Warn users when a TODO comment still references an issue that has since been closed.

## Best solution

Add a diagnostic provider alongside IssueTodoProvider that resolves issue references in open documents and warns when the referenced issue is closed, following the maintainer's proposed behavior while avoiding excessive API requests.
