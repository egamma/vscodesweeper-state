# Issue #2353 — View Pull Request in the Context Menu

[https://github.com/microsoft/vscode-pull-request-github/issues/2353](https://github.com/microsoft/vscode-pull-request-github/issues/2353)

## Summary

This remains a distinct feature gap: current editor context menus can copy GitHub links but cannot locate the pull request that last changed the selected line. Route it to the git and UX areas for consideration.

## Change summary

Add an editor context-menu action that opens the latest pull request responsible for changing the selected line.

## Best solution

Add a line-level command that uses git blame to identify the introducing commit, resolves its associated pull request through the GitHub integration, and opens that PR, with a clear result when no associated PR exists.
