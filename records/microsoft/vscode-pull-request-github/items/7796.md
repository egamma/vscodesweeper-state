# Issue #7796 — See More has no action when PR card is already open

[https://github.com/microsoft/vscode-pull-request-github/issues/7796](https://github.com/microsoft/vscode-pull-request-github/issues/7796)

## Summary

The current source confirms the UX gap: the chat card's action opens the PR description while preserving focus, so clicking it can produce no perceptible response when that panel is already visible. This team-authored, assigned papercut should remain open for a deliberate interaction fix.

## Change summary

Make the PR chat card's See More action provide visible feedback or expanded content when the PR description panel is already open.

## Best solution

Make the action meaningful in both states: either expand the full description in chat if the VS Code chat-context API supports it, or focus/reveal the existing PR description panel when invoked from a PR chat card. The latter can likely be handled in the `PRChatContextItem` branch of `openDescriptionCommand` without changing other description-opening behavior.
