# Issue #3263 — Same markdown writing experience as GH

[https://github.com/microsoft/vscode-pull-request-github/issues/3263](https://github.com/microsoft/vscode-pull-request-github/issues/3263)

## Summary

The Markdown-writing gap remains on current main: the new-PR description is still a plain textarea with no GitHub-style inline-formatting shortcuts. Keep the feature request open and route it to UX.

## Change summary

Add GitHub-like Markdown editing behavior to new pull-request descriptions, particularly wrapping selected text in backticks via Cmd/Ctrl+E or the backtick key.

## Best solution

Add reusable Markdown selection-editing behavior to the pull-request creation textarea, including backtick wrapping and Cmd/Ctrl+E, while preserving the existing submit and undo handling. A full-editor workflow tracked by https://github.com/microsoft/vscode-pull-request-github/issues/6606 could provide a broader alternative, but it should not obscure this smaller shortcut request.
