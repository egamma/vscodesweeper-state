# Issue #3263 — Same markdown writing experience as GH

[https://github.com/microsoft/vscode-pull-request-github/issues/3263](https://github.com/microsoft/vscode-pull-request-github/issues/3263)

## Summary

The creation form still lacks the requested selection-wrapping shortcuts. Keep this request open and route it to the description-page and UX areas; the related suggestions issue does not cover the same observable behavior.

## Change summary

Support GitHub-style Markdown shortcuts in the new-PR description field, especially wrapping selected text in backticks.

## Best solution

Provide selection-preserving inline-code formatting in the PR creation form without requiring an external editor. Scope the initial improvement to the reported shortcuts rather than embedding a full editor or reproducing every GitHub editing feature.
