# Issue #514 — Stash changes before entering review mode

[https://github.com/microsoft/vscode-pull-request-github/issues/514](https://github.com/microsoft/vscode-pull-request-github/issues/514)

## Summary

Keep open while the linked implementation PR is under review. Current main can prompt users to stash before checking out a PR, but it does not automatically restore that stash when returning to the default branch.

## Change summary

Automatically stash local changes when entering PR review mode and restore them after returning to the previous or default branch.

## Best solution

Review and land https://github.com/microsoft/vscode-pull-request-github/pull/7926 after reconciling it with the existing checkout warning flow, ensuring that only extension-created stashes are restored after a successful return checkout.
