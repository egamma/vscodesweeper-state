# Issue #8554 — Feature Request: Fold files with all comments marked as resolved.

[https://github.com/microsoft/vscode-pull-request-github/issues/8554](https://github.com/microsoft/vscode-pull-request-github/issues/8554)

## Summary

The existing Comments view status filter covers the explicitly requested filtering alternative: hiding resolved threads also hides file groups with no remaining unresolved threads. A maintainer already pointed out this capability in the discussion.

## Change summary

Reduce clutter in large reviews by folding or filtering files whose comment threads are all resolved.

## Best solution

Use the Comments view filter with Show Resolved disabled and Show Unresolved enabled. This covers the requested status-filtering alternative without introducing automatic file-folding behavior.
