# Issue #8554 — Feature Request: Fold files with all comments marked as resolved.

[https://github.com/microsoft/vscode-pull-request-github/issues/8554](https://github.com/microsoft/vscode-pull-request-github/issues/8554)

## Summary

The existing Comments-view filter already covers the requested workflow by hiding resolved threads, including file groups with no remaining unresolved comments.

## Change summary

Hide or collapse files whose pull-request comment threads are all resolved.
