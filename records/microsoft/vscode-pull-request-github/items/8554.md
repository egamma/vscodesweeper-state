# Issue #8554 — Feature Request: Fold files with all comments marked as resolved.

[https://github.com/microsoft/vscode-pull-request-github/issues/8554](https://github.com/microsoft/vscode-pull-request-github/issues/8554)

## Summary

A filter already lets users hide resolved threads, but the requested automatic folding of file groups remains a distinct Comments view capability. Because file grouping and folding are owned by VS Code's Comments view, this should remain open and route through the upstream/vscode lane.

## Change summary

Automatically collapse file groups whose review threads are all resolved, particularly for pull requests with hundreds of files and comments.

## Best solution

Add resolved-state-aware file-group collapsing to the VS Code Comments view in microsoft/vscode while continuing to consume the resolved thread state supplied by this extension. The existing unresolved-comments filter should remain available as the current workaround.
