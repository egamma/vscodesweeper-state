# Issue #4636 — Add a command to "start working on" by issue number

[https://github.com/microsoft/vscode-pull-request-github/issues/4636](https://github.com/microsoft/vscode-pull-request-github/issues/4636)

## Summary

Thanks for the context. This is a direct duplicate of the older open issue https://github.com/microsoft/vscode-pull-request-github/issues/3529, which requests the same command-palette flow for entering an issue number instead of locating the issue in a query.

## Change summary

Add a command that starts work on an issue selected by number or from a quick pick.

## Best solution

Consolidate on https://github.com/microsoft/vscode-pull-request-github/issues/3529 and implement a command-palette entry that resolves an entered issue number before invoking the existing start-working flow; retain this report's quick-pick suggestion as a possible fallback.
