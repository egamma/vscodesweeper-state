# Issue #8406 — Max-width on Comment widget contents

[https://github.com/microsoft/vscode-pull-request-github/issues/8406](https://github.com/microsoft/vscode-pull-request-github/issues/8406)

## Summary

This remains a valid UI request, but the width and placement of editor comment threads are controlled by VS Code core rather than this extension. Keep it open and route it through the upstream/vscode lane for a core design decision.

## Change summary

Constrain editor comment content and its reply input to a centered maximum width so controls remain easier to reach on wide editors.

## Best solution

Add fixed- or maximum-width support to VS Code core's comment-thread or peek-view presentation, preserving the commenting API used by extensions. A maintainer should transfer or consolidate this into microsoft/vscode if a suitable core issue is established.
