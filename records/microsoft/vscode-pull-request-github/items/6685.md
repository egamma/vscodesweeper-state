# Issue #6685 — Create Pull Request widget doesn't respect keybinding "when" clause

[https://github.com/microsoft/vscode-pull-request-github/issues/6685](https://github.com/microsoft/vscode-pull-request-github/issues/6685)

## Summary

A real context-key gap remains for inputs inside the Create Pull Request webview. The standard focus contexts are owned by VS Code's webview platform, so this should remain open in the upstream/vscode lane.

## Change summary

Expose appropriate input-focus context to keybindings while editing a pull request title or description in the Create view.

## Best solution

Have the VS Code webview host propagate an input-focus context for editable elements and make it visible through context-key inspection. Track the platform work in microsoft/vscode rather than implementing a Create-view-specific substitute.
