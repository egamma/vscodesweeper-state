[https://github.com/microsoft/vscode-pull-request-github/issues/6685](https://github.com/microsoft/vscode-pull-request-github/issues/6685)

## Summary

The Create view still uses webview inputs without native editor focus contexts. Keep the request open and route the focus-context integration to the upstream/vscode lane; no verified canonical covers this exact symptom.

## Change summary

Make PR creation inputs compatible with input-sensitive keybindings, with native Vim editing requested additionally.

## Best solution

Establish supported input-focus context behavior in microsoft/vscode's webview platform so typing in PR creation fields does not activate shortcuts intended for non-input surfaces. Treat full Vim editing support as a separate capability rather than assuming focus-context integration provides it.
