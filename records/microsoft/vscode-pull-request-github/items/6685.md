# Issue #6685 — Create Pull Request widget doesn't respect keybinding "when" clause

[https://github.com/microsoft/vscode-pull-request-github/issues/6685](https://github.com/microsoft/vscode-pull-request-github/issues/6685)

## Summary

A real platform-integration gap remains: the Create Pull Request webview uses HTML inputs that do not expose VS Code's standard input context keys or support editor extensions such as Vim. No existing setting, command, or open canonical issue was found that covers the request.

## Change summary

Make keybinding when-clauses and Vim-style input bindings recognize the title and description fields in the Create Pull Request webview.

## Best solution

Keep this open through the upstream/vscode lane and determine whether VS Code webviews should expose an input-focus context and extension keyboard handling for embedded text controls. An extension-side custom focus context could mitigate command conflicts, but it would not make existing inputFocus clauses or Vim input behavior work generally.
