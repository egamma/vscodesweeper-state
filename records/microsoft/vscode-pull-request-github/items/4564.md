# Issue #4564 — Behavior of "reply comment" and "collapse all" are odd if there are more than one comment in the same line.

[https://github.com/microsoft/vscode-pull-request-github/issues/4564](https://github.com/microsoft/vscode-pull-request-github/issues/4564)

## Summary

The extension preserves distinct GitHub thread identities and delegates collapsing and widget interaction to VS Code's commenting UI. The incorrect selection of overlapping threads therefore belongs in the upstream/vscode lane and remains unresolved.

## Change summary

Multiple review threads anchored to the same line collapse inconsistently, and replying to or editing one can target another thread in github.dev.

## Best solution

VS Code's commenting UI should reliably associate collapse, reply, and edit actions with the selected thread when several comment threads share an identical range. Route this through upstream/vscode for a core fix rather than changing the extension's GitHub thread model.
