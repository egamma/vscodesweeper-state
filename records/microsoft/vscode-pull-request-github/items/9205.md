# Issue #9205 — Filter Comments since last review

[https://github.com/microsoft/vscode-pull-request-github/issues/9205](https://github.com/microsoft/vscode-pull-request-github/issues/9205)

## Summary

A distinct re-review capability remains missing: show threads with comment activity since the viewer's last review, including resolved threads but excluding reactions. Route to comments and review for product consideration.

## Change summary

Add a filter for comments or threads updated since the viewer's most recent review, regardless of resolution state and excluding reactions.

## Best solution

Provide a last-review-relative comment activity filter that preserves updated resolved threads. Decide the presentation surface and activity semantics before implementation; existing diff and collapse controls do not cover this request.

- **Existing last-review command has a different scope:** src/commands.ts:1228 registers pr.showDiffSinceLastReview, which sets showChangesSinceReview. src/github/pullRequestModel.ts:getRawFileChangesInfo uses the last reviewed commit to select file changes; this is not a comment-activity filter.

That authorship-based filter does not encompass activity since a submitted review, including subsequent comments by the viewer or updates to resolved threads.
