# Issue #2696 — Create PR should be smarter

[https://github.com/microsoft/vscode-pull-request-github/issues/2696](https://github.com/microsoft/vscode-pull-request-github/issues/2696)

## Summary

Keep open: current main prevents submitting an identical base/head pair and performs automatic base detection, but it still does not define a smarter branch-creation experience for uncommitted changes. Because this is a team-authored feature request without an issue-referencing fix or verified duplicate, the existing improvements do not meet the factual-close bar.

## Change summary

Make Create PR choose or create a sensible head branch and base instead of presenting the same branch on both sides.

## Best solution

When invoked with uncommitted changes on the default branch, offer to create and check out a feature branch before opening the PR form; otherwise initialize the current branch as head and its detected or repository-default branch as base. Preserve the existing guard that disables creation when base and head are identical.
