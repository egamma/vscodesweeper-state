# Issue #2696 — Create PR should be smarter

[https://github.com/microsoft/vscode-pull-request-github/issues/2696](https://github.com/microsoft/vscode-pull-request-github/issues/2696)

## Summary

The creation flow still lacks guidance for uncommitted changes on the default branch. Current code prevents submitting a same-repository, same-branch PR, but that does not satisfy this team-authored request for smarter preparation.

## Change summary

Make SCM-triggered PR creation guide users toward a meaningful branch comparison when their changes are still uncommitted.

## Best solution

Provide actionable preparation guidance in the PR creation flow when local changes cannot appear in the selected comparison, including the default-branch case. Coordinate the uncommitted-change guidance with the related request without losing this issue's branch-selection concern.
