# Issue #2696 — Create PR should be smarter

[https://github.com/microsoft/vscode-pull-request-github/issues/2696](https://github.com/microsoft/vscode-pull-request-github/issues/2696)

## Summary

A meaningful UX gap remains in the direct Create Pull Request flow: it starts from the current branch even when that produces a same-repository, same-branch proposal, then merely disables creation. This team-authored request has no explicitly referencing fix or open canonical, so it should remain open and route to the git and UX areas.

## Change summary

Make Create Pull Request recognize uncommitted changes and avoid presenting an unusable same-branch pull request.

## Best solution

When `pr.create` is invoked with a dirty working tree and the selected head equals the base, guide the user into the existing Commit & Create Pull Request/new-branch flow rather than opening an unusable form. The extension and VS Code Git integration owners should decide whether that means offering branch creation, redirecting to the SCM commit action, or displaying targeted guidance.

- **Evidence:** The product promise is to "Review and manage your GitHub pull requests and issues directly in VS Code," and creation-flow polish is identified as a current workstream.

## Evidence

- **current direct-create behavior:** src/view/createPullRequestHelper.ts initializes the compare side from the requested branch or repository HEAD and constructs the creation model with that branch; it does not special-case a dirty default branch or create a new branch.
- **same-branch guard:** webviews/common/createContextNew.ts rejects creation when base and compare repository/branch are equal, preventing submission but providing no smarter transition for the scenario reported here.
- **partial existing capability:** src/extension.ts registers a Git post-commit action titled "Commit & Create Pull Request," and src/commands.ts implements `pr.pushAndCreate`; this covers the commit-first workflow but not invoking the direct Create Pull Request button before committing.
