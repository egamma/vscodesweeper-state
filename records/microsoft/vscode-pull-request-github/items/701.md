# Issue #701 — Add support for reading http.proxy setting

[https://github.com/microsoft/vscode-pull-request-github/issues/701](https://github.com/microsoft/vscode-pull-request-github/issues/701)

## Summary

The gap remains on current main: GitHub requests support the HTTPS_PROXY environment variable but do not read VS Code's http.proxy setting. Keep this canonical feature request open and route it to the GitHub integration area.

## Change summary

Honor VS Code's http.proxy configuration when connecting to GitHub through a corporate proxy.

## Best solution

Resolve proxy configuration through the VS Code networking surface in src/env/node/net.ts and use the resulting agent consistently for Octokit, GraphQL, authentication, and GitHub Enterprise discovery requests.
