# Issue #6799 — Deleting a branch auto-closes any PRs targeting the deleted branch

[https://github.com/microsoft/vscode-pull-request-github/issues/6799](https://github.com/microsoft/vscode-pull-request-github/issues/6799)

## Summary

A real gap remains on current main: remote deletion directly removes the Git ref without preserving stacked pull requests that target it. The accepted On Deck request should remain open and route to the GitHub integration and description-page areas.

## Change summary

Retarget open pull requests to the default branch before deleting their base branch from the pull request description view.

## Best solution

Before remote deletion in src/github/pullRequestReviewCommon.ts, find open pull requests whose base is the branch being removed and retarget them to the default branch using the existing PullRequestModel.updateBaseBranch path. Delete the ref only after every retarget succeeds, preserving comments and reviews.
