# Issue #8836 — `Close` and `Comment` buttons should be the same as GitHub

[https://github.com/microsoft/vscode-pull-request-github/issues/8836](https://github.com/microsoft/vscode-pull-request-github/issues/8836)

## Summary

A real issue-management UX gap remains: closing with a typed comment works, but the description page lacks GitHub's button ordering and close-reason choices. Route this feature request to the issue-description UX owners.

## Change summary

Match GitHub's issue comment and close controls, including button placement, close reasons, and a clear close-with-comment action.

## Best solution

Update the issue-mode action bar in `webviews/components/comment.tsx` to expose GitHub-style comment and close actions, then pass the selected completed/not-planned/duplicate reason through `src/github/issueOverview.ts` to `src/github/issueModel.ts` as the API `state_reason`.
