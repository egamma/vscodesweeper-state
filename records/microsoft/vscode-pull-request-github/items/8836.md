# Issue #8836 — `Close` and `Comment` buttons should be the same as GitHub

[https://github.com/microsoft/vscode-pull-request-github/issues/8836](https://github.com/microsoft/vscode-pull-request-github/issues/8836)

## Summary

The requested issue-closing UI parity remains missing on main: close-reason selection, button grouping, and the contextual “Close with comment” label are absent. Route to the issues and description-page areas; existing comment-and-close functionality covers only part of the request.

## Change summary

Match GitHub’s issue-closing controls, including placement, close reasons, and labeling when a comment is entered.

## Best solution

Provide GitHub-style issue-closing controls in the description webview, retaining the existing ability to post a comment before closing and preserving separate pull-request review behavior.

- **Fit:** aligned
- **Reason:** Clear issue-closing semantics support managing GitHub issues directly in VS Code without requiring wholesale website replication.
- **Evidence:** The product promise is “Review and manage your GitHub pull requests and issues directly in VS Code”; issues integration and description-page ergonomics are durable themes.
