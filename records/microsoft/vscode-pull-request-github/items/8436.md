# Issue #8436 — Support "Branch auto delete" without having to press "merge" in the webview

[https://github.com/microsoft/vscode-pull-request-github/issues/8436](https://github.com/microsoft/vscode-pull-request-github/issues/8436)

## Summary

A real post-creation workflow gap remains: the extension can check out the default branch after creating a PR but cannot delete the now-pushed local topic branch. This team-authored Backlog request should remain open.

## Change summary

Add an opt-in post-create action that pushes the PR branch, checks out the default branch, and deletes the local topic branch.

## Best solution

Extend `githubPullRequests.postCreate` with a clearly named option that checks out the default branch and safely deletes only the local PR branch after confirming its remote branch exists. Keep this separate from `githubPullRequests.deleteBranchAfterMerge`, whose lifecycle begins after merging.
