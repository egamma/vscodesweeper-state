# Issue #8436 — Support "Branch auto delete" without having to press "merge" in the webview

[https://github.com/microsoft/vscode-pull-request-github/issues/8436](https://github.com/microsoft/vscode-pull-request-github/issues/8436)

## Summary

The requested post-creation cleanup remains missing: existing settings can switch to the default branch but do not automatically delete the author's local branch after creating a PR. Keep this team-authored Backlog request open and route it to git.

## Change summary

Offer an opt-in PR-creation workflow that preserves the published remote branch, switches to the default branch, and deletes the local source branch without merging.

## Best solution

Provide an opt-in post-creation cleanup action in the PR creation flow, preserving the remote PR branch and local-only work. The owner should decide its settings contract without changing existing post-create or post-merge defaults.
