# Issue #8607 — Ability to add comments in Markdown Preview Mode

[https://github.com/microsoft/vscode-pull-request-github/issues/8607](https://github.com/microsoft/vscode-pull-request-github/issues/8607)

## Summary

This is a valid review-workflow request, but commenting currently targets VS Code text documents rather than the Markdown preview webview. Keep it open and route it through the upstream/vscode lane because core preview/commenting support is needed.

## Change summary

Allow reviewers to place line-level pull-request comments directly on rendered Markdown previews.

## Best solution

VS Code core should expose a supported way for comment controllers to attach rendered preview locations to source-document ranges. The extension can then reuse its review comment controller for Markdown previews without implementing a separate preview surface.

## Vision fit

- **Fit:** aligned
- **Reason:** Reviewing rendered Markdown without leaving the editor advances the extension's native in-editor review experience, although the required preview integration belongs in VS Code core.
- **Evidence:** The durable review-flow theme explicitly includes in-editor commenting, and the product promise is to "Review and manage your GitHub pull requests and issues directly in VS Code."
