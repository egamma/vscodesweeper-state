# Issue #8607 — Ability to add comments in Markdown Preview Mode

[https://github.com/microsoft/vscode-pull-request-github/issues/8607](https://github.com/microsoft/vscode-pull-request-github/issues/8607)

## Summary

This is a valid, still-unimplemented review-flow request. The extension currently supplies comments through text-document commenting ranges, while Markdown Preview is a VS Code webview surface without an equivalent integration here, so the feature should remain open and be routed to the review and upstream/vscode areas.

## Change summary

Allow reviewers to create line-level pull-request comments directly from a rendered Markdown preview.

## Best solution

Establish a VS Code Markdown Preview commenting or source-position API in microsoft/vscode, then integrate it with the extension's review comment controller so rendered elements map reliably to changed Markdown lines. Avoid implementing a separate Markdown renderer solely for this extension.
