[https://github.com/microsoft/vscode-pull-request-github/issues/7186](https://github.com/microsoft/vscode-pull-request-github/issues/7186)

## Summary

The requested GitHub-style [AI] marker remains absent on main, while the extension already identifies Copilot-authored comments and displays an AI disclaimer. Keep the accepted On Deck request open and route it to comments/review UX.

## Change summary

Display an [AI] marker beside Copilot-authored review comments, matching github.com.

## Best solution

Use the existing Copilot account classification in `src/common/comment.ts` and `src/github/utils.ts` to expose a consistent [AI] author marker in both native editor comments and the description-page webview, without changing ordinary bot attribution.
