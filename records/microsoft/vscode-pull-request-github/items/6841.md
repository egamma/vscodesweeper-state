# Issue #6841 — Issues - create an issue does not use the new web view

[https://github.com/microsoft/vscode-pull-request-github/issues/6841](https://github.com/microsoft/vscode-pull-request-github/issues/6841)

## Summary

The gap remains on current main: the Issues view title action still creates a markdown-backed editor rather than using the issue webview. Keep this team-authored Backlog request open and route it to the issues area.

## Change summary

Use the issue webview instead of a markdown document when creating an issue from the Issues view title action.

## Best solution

Extend the issue webview to support an unsaved new-issue model, including repository, template, assignee, label, milestone, and project selection, then route `issue.createIssue` through it while preserving the existing creation capabilities.
