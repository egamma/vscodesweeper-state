# Issue #5325 — Cannot edit PR review: resource not accessible by integration

[https://github.com/microsoft/vscode-pull-request-github/issues/5325](https://github.com/microsoft/vscode-pull-request-github/issues/5325)

## Summary

Keep open as a confirmed GitHub Codespaces token limitation affecting fork-originated Codespaces. The extension now reports the limitation more clearly, but current main still cannot complete the affected mutations and recent feedback indicates the underlying token restriction persists.

## Change summary

Editing or deleting pending review comments fails with “Resource not accessible by integration” in a Codespace created from a fork PR.

## Best solution

GitHub Codespaces should provide a token or safe authorization path that permits review-comment mutations in fork-originated Codespaces. Until that is available, retain the extension's explicit error and documented workaround, and use this issue as the canonical report for the review-comment impact.
