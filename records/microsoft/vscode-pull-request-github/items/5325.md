# Issue #5325 — Cannot edit PR review: resource not accessible by integration

[https://github.com/microsoft/vscode-pull-request-github/issues/5325](https://github.com/microsoft/vscode-pull-request-github/issues/5325)

## Summary

Keep open as a confirmed GitHub Codespaces upstream limitation. Codespaces supplies a restricted token for spaces created from fork PRs, and current extension code detects the failure but cannot complete the operation.

## Change summary

Editing or deleting review comments fails with “Resource not accessible by integration” in Codespaces created from fork pull requests.

## Best solution

GitHub Codespaces should provide an authentication path that permits eligible review-comment mutations without weakening fork protections. Until then, the extension should retain its explicit diagnostic and documented workaround of creating the Codespace from the base repository before checking out the PR.
