# Issue #5325 — Cannot edit PR review: resource not accessible by integration

[https://github.com/microsoft/vscode-pull-request-github/issues/5325](https://github.com/microsoft/vscode-pull-request-github/issues/5325)

## Summary

Keep open: maintainers confirmed that Codespaces-provided tokens prevent editing and deleting draft review comments on fork PRs. The merged extension change improves error reporting, not authorization; this issue already serves as the canonical for related token failures.

## Change summary

Editing or deleting an unsubmitted review comment fails when the Codespace was created directly from a fork pull request.

## Best solution

Confirm with GitHub Codespaces whether its token-provider fix supports these review operations while preserving fork isolation. Retain this canonical until the original workflow works; meanwhile, preserve the documented workaround of creating the Codespace from the base repository's main branch and then checking out the PR.
