# Issue #8483 — Open existing issue as raw markdown file

[https://github.com/microsoft/vscode-pull-request-github/issues/8483](https://github.com/microsoft/vscode-pull-request-github/issues/8483)

## Summary

A real capability gap remains: existing issue descriptions can only be edited in the description-page webview, while the native Markdown editor is available only when creating issues. Route this feature to the issues and description-page owners.

## Change summary

Allow an existing issue to be opened and updated as a Markdown document so editor features such as Copilot completions are available.

## Best solution

Add an action on the issue description page that opens the issue title and body as an editable virtual Markdown document, reusing the new-issue editor conventions where practical and persisting saves through IssueModel.edit.

## Vision fit

- **Fit:** aligned
- **Reason:** Native Markdown editing would strengthen the extension's in-editor issue-management workflow rather than replicate an unrelated GitHub website surface.
- **Evidence:** The README promise is to "Review and manage your GitHub pull requests and issues directly in VS Code," and issues integration is a durable investment theme.
