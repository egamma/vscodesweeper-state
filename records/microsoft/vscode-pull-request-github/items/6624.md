# Issue #6624 — [Feature Request] Add the "only files owned by you" filter.

[https://github.com/microsoft/vscode-pull-request-github/issues/6624](https://github.com/microsoft/vscode-pull-request-github/issues/6624)

## Summary

A valid review-workflow gap remains on main: the changes tree can hide viewed files but cannot filter files by CODEOWNERS. The only implementation attempt was closed unmerged, so this should remain open and route to the review/tree-view owners.

## Change summary

Add a pull-request file filter that shows only files owned by the authenticated user according to CODEOWNERS.

## Best solution

Add a composable toggle to the PR changes tree that resolves the applicable CODEOWNERS rules, including team ownership, and filters the displayed files without interfering with the existing viewed-files filter.
