# Issue #6624 — [Feature Request] Add the "only files owned by you" filter.

[https://github.com/microsoft/vscode-pull-request-github/issues/6624](https://github.com/microsoft/vscode-pull-request-github/issues/6624)

## Summary

The requested CODEOWNERS filter remains a valid, unimplemented review feature on current main. A prior implementation attempt was closed without merging, so the issue should remain open and route to the review and tree-view areas.

## Change summary

Add a filter to the pull-request changes tree that shows only files owned by the authenticated user according to CODEOWNERS.

## Best solution

Add a composable filter to the Changes in Pull Request tree, backed by GitHub-compatible CODEOWNERS resolution for individual and team ownership, with focused parser and filtering tests. The implementation should account for CODEOWNERS lookup locations, rule precedence, team membership permissions, and interaction with the existing viewed-files filter.
