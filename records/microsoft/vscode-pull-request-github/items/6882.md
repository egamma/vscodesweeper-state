# Issue #6882 — Swapping between pull requests in webview does not clear text box

[https://github.com/microsoft/vscode-pull-request-github/issues/6882](https://github.com/microsoft/vscode-pull-request-github/issues/6882)

## Summary

Current main clears the displayed PR before switching, so the reported cross-PR text leak no longer follows the source path. This team-authored Backlog issue must remain open because the related fix does not reference this issue and per-PR draft restoration remains unimplemented.

## Change summary

Keep each unfinished PR comment associated with its own pull request when a webview switches between pull requests.

## Best solution

Store pending comment text by repository and PR number in the webview state, restoring the corresponding draft after each switch. The existing `pendingCommentDrafts` field can support this in `webviews/common/cache.ts` and `webviews/common/context.tsx`.
