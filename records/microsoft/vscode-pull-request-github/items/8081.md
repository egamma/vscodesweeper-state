[https://github.com/microsoft/vscode-pull-request-github/issues/8081](https://github.com/microsoft/vscode-pull-request-github/issues/8081)

## Summary

Emoji completions still explicitly use the Text kind, leaving the redundant kind icon beside the emoji. Keep the request open and route it through upstream/vscode: selective icon suppression needs support from the core suggestion platform.

## Change summary

Hide the completion-kind icon beside emoji suggestions in inline review comments.
