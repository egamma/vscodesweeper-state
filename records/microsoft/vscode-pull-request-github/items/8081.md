# Issue #8081 — Don't show completion kinds with emoji picker

[https://github.com/microsoft/vscode-pull-request-github/issues/8081](https://github.com/microsoft/vscode-pull-request-github/issues/8081)

## Summary

The unwanted completion-kind icon remains on current main because every emoji completion is explicitly classified as Text. Keep this open as review-comment UX polish.

## Change summary

Hide the generic Text completion-kind icon beside emoji suggestions in review comments.

## Best solution

Adjust src/view/emojiCompletionProvider.ts so emoji completion items omit the generic Text kind while retaining their emoji label, shortcode description, filtering, and ordering.
