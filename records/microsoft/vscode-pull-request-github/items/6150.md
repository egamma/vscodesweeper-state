# Issue #6150 — Transition into GH PR from github.dev is not very smooth

[https://github.com/microsoft/vscode-pull-request-github/issues/6150](https://github.com/microsoft/vscode-pull-request-github/issues/6150)

## Summary

A real cross-extension polish gap remains: entering a pull request from github.dev passes through unrelated and unstable intermediate views before reaching the PR UI. The maintainer identified github.dev and Remote Hub work as necessary, so this should remain open and be routed through the web and upstream/vscode areas.

## Change summary

Open the stable GitHub Pull Requests view directly when transitioning into a pull request from github.dev, without showing the Explorer or intermediate view states.

## Best solution

Coordinate the github.dev and Remote Hub entry path in microsoft/vscode with this extension's existing PR URI handler so repository initialization happens without activating visible intermediate views, then reveal the PR overview only when its stable state is ready.
