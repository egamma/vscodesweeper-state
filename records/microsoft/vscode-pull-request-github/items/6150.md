# Issue #6150 — Transition into GH PR from github.dev is not very smooth

[https://github.com/microsoft/vscode-pull-request-github/issues/6150](https://github.com/microsoft/vscode-pull-request-github/issues/6150)

## Summary

Keep open and route to web/UX: the requested stable github.dev-to-PR transition is not covered by the existing layout controls. The maintainer identified coordination with github.dev and Remote Hub; no verified fix or same-symptom open canonical was found.

## Change summary

Enter the PR review UI directly from github.dev without first showing Explorer or cycling through intermediate views.

## Best solution

Coordinate github.dev/Remote Hub startup with the extension's preload and review initialization so the intended PR surface is selected early and remains visually stable while data loads. Establish the current transition sequence before deciding which product owns each change.
