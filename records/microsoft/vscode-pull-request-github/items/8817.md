# Issue #8817 — Set issue type when creating new issue

[https://github.com/microsoft/vscode-pull-request-github/issues/8817](https://github.com/microsoft/vscode-pull-request-github/issues/8817)

## Summary

Verified duplicate: the older open issue-management request explicitly includes selecting an issue type during creation and owns this request as part of its broader scope.

## Change summary

Allow users to set a GitHub issue type while creating an issue so `${issueType}` can be resolved immediately in generated branch names.

## Best solution

Consolidate this request into https://github.com/microsoft/vscode-pull-request-github/issues/8475, preserving the branch-name substitution scenario as concrete motivation. The creation flow should collect the issue type and apply it through the GitHub integration after creating the issue if the creation API cannot accept it directly.
