# Issue #3567 — Selecting Revert Selected Ranges in Github pull request plane seems weird

[https://github.com/microsoft/vscode-pull-request-github/issues/3567](https://github.com/microsoft/vscode-pull-request-github/issues/3567)

## Summary

A real capability gap remains: the built-in Git command uses the branch HEAD as its baseline, while PR diffs use the target branch. Route this feature request to the review and git areas.

## Change summary

Add a PR-aware command that reverts selected ranges in a PR diff to their state on the target branch.

## Best solution

Implement a "Revert Selected Pull Request Ranges" command for PR diff editors that patches the working tree against the PR's target branch, without exposing the incompatible built-in Git action there.
