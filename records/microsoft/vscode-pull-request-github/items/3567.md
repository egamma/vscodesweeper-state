# Issue #3567 — Selecting Revert Selected Ranges in Github pull request plane seems weird

[https://github.com/microsoft/vscode-pull-request-github/issues/3567](https://github.com/microsoft/vscode-pull-request-github/issues/3567)

## Summary

The requested PR-relative revert capability is now available through the diff editor's Revert Selection action. This addresses the maintainer's proposed improvement without relying on the built-in Git command's different baseline.

## Change summary

Allow selected PR changes to be reverted to the displayed original content without leaving the PR diff.

## Best solution

Use the native diff editor's Revert Selection action (diffEditor.revert) in a checked-out PR's writable diff; no separate extension command is necessary.
