# Issue #7303 — Expect `Expand All` or `Reexpand All` option

[https://github.com/microsoft/vscode-pull-request-github/issues/7303](https://github.com/microsoft/vscode-pull-request-github/issues/7303)

## Summary

The missing expand/re-expand operation is a VS Code tree-widget capability already tracked by the broader open vscode issue. This extension uses that core tree surface for both PR and issue views.

## Change summary

Provide an Expand All or state-restoring Reexpand action after collapsing the pull-request or issue tree, or disable Collapse All when everything is collapsed.

## Best solution

Consolidate on https://github.com/microsoft/vscode/issues/174770 and implement resolved-node expansion or restoration in VS Code's tree widget, allowing this extension's PR and issue views to inherit the behavior without reimplementing the core control.
