# Issue #7303 — Expect `Expand All` or `Reexpand All` option

[https://github.com/microsoft/vscode-pull-request-github/issues/7303](https://github.com/microsoft/vscode-pull-request-github/issues/7303)

## Summary

The PR and Issues trees still lack a bulk re-expansion action; existing expansion persistence does not restore the state preceding Collapse All. Route this accepted, team-authored request to the tree-view and UX areas; no verified fix or duplicate supports closing it.

## Change summary

Provide Expand All or restoration of previously expanded PR/issue nodes after Collapse All, or disable the collapse action when nothing remains expanded.

## Best solution

Agree on consistent post-collapse behavior for both trees, balancing restoration of the previous expansion state against the API-fetch cost of expanding everything. Coordinate with VS Code core if changing the built-in Collapse All button is the preferred outcome.
