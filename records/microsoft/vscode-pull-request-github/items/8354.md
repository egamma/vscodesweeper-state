# Issue #8354 — "Switch Templates" should work with local templates

[https://github.com/microsoft/vscode-pull-request-github/issues/8354](https://github.com/microsoft/vscode-pull-request-github/issues/8354)

## Summary

Local template support remains missing: switching templates reads GitHub-hosted content, not locally added or edited files. Keep this team-authored Backlog request open and route it to the description-page area.

## Change summary

Allow switching PR templates to use locally added templates and locally edited template contents.

## Best solution

The PR creation template picker should offer current local template content. The team should establish how local templates interact with base-repository and owner-wide templates, especially when creating PRs from forks.

- **Fit:** aligned
- **Reason:** Using local templates supports the extension's native, in-editor PR creation workflow.
- **Evidence:** The README product promise is to "Review and manage your GitHub pull requests and issues directly in VS Code."
