# Issue #8354 — "Switch Templates" should work with local templates

[https://github.com/microsoft/vscode-pull-request-github/issues/8354](https://github.com/microsoft/vscode-pull-request-github/issues/8354)

## Summary

A real gap remains in the PR creation flow: switching templates reads GitHub-hosted template bodies and does not consider locally added or modified files. Keep the accepted Backlog request open and route it to the description-page area.

## Change summary

Allow the Create Pull Request view's Switch Templates action to use locally added or modified pull-request templates.

## Best solution

Update the template-selection path in src/github/folderRepositoryManager.ts and src/github/createPRViewProvider.ts to discover supported template paths in the workspace and prefer their current local contents over the corresponding remote versions, while preserving owner-wide template fallback behavior.
