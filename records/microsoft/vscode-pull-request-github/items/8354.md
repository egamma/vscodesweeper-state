# Issue #8354 — "Switch Templates" should work with local templates

[https://github.com/microsoft/vscode-pull-request-github/issues/8354](https://github.com/microsoft/vscode-pull-request-github/issues/8354)

## Summary

The local-template gap remains on current main: switching templates reads GitHub-hosted template bodies rather than workspace files. Keep this team-authored backlog request open and route it to UX.

## Change summary

Allow the create-PR view's template switcher to use locally added or modified pull request templates.

## Best solution

Update the template discovery used by `CreatePullRequestViewProvider.changeTemplate` to read supported template locations from the repository workspace before falling back to GitHub-hosted templates, so saved local additions and edits appear immediately.
