# Issue #6171 — Generated code suggestion can't be applied to the file correctly

[https://github.com/microsoft/vscode-pull-request-github/issues/6171](https://github.com/microsoft/vscode-pull-request-github/issues/6171)

## Summary

The underlying defect remains on current main: applying a suggestion uses the extension-host comment thread's potentially stale range after earlier edits shift the displayed thread. The merged extension and VS Code changes improved replacement bounds and active-editor rendering, but neither implemented the extension-owned revision-to-document mapping identified by the maintainers.

## Change summary

Applying a generated review suggestion after preceding lines change can replace the wrong range and leave the file in a broken state.

## Best solution

Track or recompute each review thread's position against the current working document before applying its suggestion in the review comment controller. Add coverage that applies sequential suggestions where the first insertion or deletion shifts the second thread.
