# Issue #6171 — Generated code suggestion can't be applied to the file correctly

[https://github.com/microsoft/vscode-pull-request-github/issues/6171](https://github.com/microsoft/vscode-pull-request-github/issues/6171)

## Summary

Suggestion application still uses an extension-host comment range that is not adjusted after local edits. The merged fixes address newline handling and visual positioning, not this remaining defect; route to comments and review.

## Change summary

Applying a generated suggestion after edits shift its target replaces the wrong lines and leaves broken code.

## Best solution

Ensure suggestion application targets the current document location after insertions or deletions, while preserving GitHub revision-based comment positions. This belongs in the extension's review-comment handling, consistent with the maintainer's stated ownership.
