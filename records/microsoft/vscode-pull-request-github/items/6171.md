# Issue #6171 — Generated code suggestion can't be applied to the file correctly

[https://github.com/microsoft/vscode-pull-request-github/issues/6171](https://github.com/microsoft/vscode-pull-request-github/issues/6171)

## Summary

Still present on main: applying a suggestion uses the extension-host comment range, which remains stale after earlier document edits. The partial extension and VS Code fixes did not synchronize that range back to this application path.

## Change summary

Applying a generated review suggestion after preceding lines change can replace the wrong source range and leave the file broken.

## Best solution

Maintain a current-document range for each review thread as edits shift its position, then use that mapped range in `ReviewCommentController.applySuggestion` rather than the stale `CommentThread.range`.
