# Issue #6606 — Feature Request: Pull request description in full editor

[https://github.com/microsoft/vscode-pull-request-github/issues/6606](https://github.com/microsoft/vscode-pull-request-github/issues/6606)

## Summary

A real accessibility gap remains: current main only supports editing the new PR description in the create-view textarea. Route this feature request to accessibility and UX rather than closing it.

## Change summary

Allow authors to compose a new pull request description in a full VS Code editor instead of only the sidebar.

## Best solution

Add an accessible “Open in Editor” action to the PR creation view that synchronizes an editor document with the pending description without losing draft state. Coordinate this with the related description-completion work in https://github.com/microsoft/vscode-pull-request-github/issues/2401.
