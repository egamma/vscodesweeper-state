# Issue #6606 — Feature Request: Pull request description in full editor

[https://github.com/microsoft/vscode-pull-request-github/issues/6606](https://github.com/microsoft/vscode-pull-request-github/issues/6606)

## Summary

A real accessibility and creation-flow gap remains: PR descriptions can only be edited in the create-view textarea, with no command or setting for using a full VS Code editor. Route this to accessibility and UX rather than closing it.

## Change summary

Allow users creating a pull request to compose its description in a full VS Code text editor instead of only the sidebar webview.

## Best solution

Add an accessible “Open Description in Editor” action to the PR creation view, backed by an editable document whose contents remain synchronized with the pending description until creation or cancellation. Preserve the existing webview flow as the default while allowing keyboard and assistive-technology users to opt into the standard editor surface.
