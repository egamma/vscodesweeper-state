# Issue #6606 — Feature Request: Pull request description in full editor

[https://github.com/microsoft/vscode-pull-request-github/issues/6606](https://github.com/microsoft/vscode-pull-request-github/issues/6606)

## Summary

Native-editor composition remains missing: PR creation still uses a sidebar textarea, and existing description settings do not address the accessibility need. Route to accessibility and UX; the related suggestions request does not establish a same-symptom duplicate.

## Change summary

Allow composing a new pull request's description in a full VS Code text editor, similar to git.commit.

## Best solution

Provide an accessible native-editor composition path integrated with the existing PR draft and creation flow. Decide how completing or cancelling composition interacts with submission, without requiring an embedded Monaco editor.

- **Behavior:**

  > A user creating a pull request can compose its description in a native VS Code text editor rather than being confined to the sidebar textarea. Existing template content and multiline Markdown must remain intact, and the submitted PR body must match the completed draft. The path must be keyboard-accessible. Completing, cancelling, and retrying composition must have explicit draft-preservation and submission behavior.
