[https://github.com/microsoft/vscode-pull-request-github/issues/3863](https://github.com/microsoft/vscode-pull-request-github/issues/3863)

## Summary

The dedicated Notifications view implements the reporter's accepted alternative: listing unread items directly rather than hunting through paginated PR categories. It shipped in v0.100.0 and is now shown by default, collapsed.

## Change summary

Make unread PR notifications discoverable when their pull requests are not visible in the loaded tree.

## Best solution

Treat the central discoverability request as completed by the Notifications view. A highlighted PR 'Load more' node remains unimplemented, but is no longer necessary to provide the notification-only experience explicitly requested in the discussion.
