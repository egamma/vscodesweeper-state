# Issue #3205 — Use package.json repository property as a remote fallback

[https://github.com/microsoft/vscode-pull-request-github/issues/3205](https://github.com/microsoft/vscode-pull-request-github/issues/3205)

## Summary

The accepted fallback remains unimplemented on main. Route it to the git and explorer areas; the existing remotes setting is only a manual workaround.

## Change summary

Use package.json's repository URL to identify the upstream GitHub remote when configured remote names do not select it, and improve discovery logging.

## Best solution

Extend remote discovery in src/common/remote.ts and src/github/folderRepositoryManager.ts to match package.json's repository URL to an existing Git remote when normal configured-name selection fails, while logging the selected remote names.
