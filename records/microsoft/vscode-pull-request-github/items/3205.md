# Issue #3205 — Use package.json repository property as a remote fallback

[https://github.com/microsoft/vscode-pull-request-github/issues/3205](https://github.com/microsoft/vscode-pull-request-github/issues/3205)

## Summary

The requested package.json repository fallback remains absent from current source. Keep the accepted feature open and route it to remote discovery; configuring remote names resolves the original problem but does not provide automatic upstream inference.

## Change summary

Use package.json's repository property as a hint or fallback when selecting the upstream GitHub repository.

## Best solution

Support repository-metadata-assisted discovery in FolderRepositoryManager, with explicit rules for when the fallback activates and how it respects configured remotes. Preserve existing git-based behavior for projects without applicable metadata.
