# Issue #3205 — Use package.json repository property as a remote fallback

[https://github.com/microsoft/vscode-pull-request-github/issues/3205](https://github.com/microsoft/vscode-pull-request-github/issues/3205)

## Summary

The accepted fallback remains unimplemented: current main selects GitHub repositories solely by remote names from `githubPullRequests.remotes`. Keep the feature open and route it to the git and GitHub integration areas.

## Change summary

Use a workspace package.json repository URL to identify the likely upstream GitHub remote when configured remote names do not select it.

## Best solution

Extend remote selection in `src/github/folderRepositoryManager.ts` to consult a valid package.json `repository` URL when the default remote-name selection misses the project upstream, while preserving explicit user configuration. Include the selected remote names in diagnostic logging so configuration mismatches are discoverable.
