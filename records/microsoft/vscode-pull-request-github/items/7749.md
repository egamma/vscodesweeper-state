# Issue #7749 — Edit Query flow is inconvenient

[https://github.com/microsoft/vscode-pull-request-github/issues/7749](https://github.com/microsoft/vscode-pull-request-github/issues/7749)

## Summary

The workflow gap remains on current main: Edit with AI opens Chat with a prompt but provides no path to apply the result automatically. The only linked implementation PR was closed unmerged, so this team-authored item should remain open and be routed to the query, UX, and chat owners.

## Change summary

Let users describe a PR-query change in natural language and apply the generated query without manually copying it from Chat.

## Best solution

Replace the one-way Chat handoff in `src/common/settingsUtils.ts` with a tool-backed or inline flow that writes the generated query to the correct configuration target. The approach from the closed PR https://github.com/microsoft/vscode-pull-request-github/pull/7792 can inform a new implementation.
