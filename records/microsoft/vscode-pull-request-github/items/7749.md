# Issue #7749 — Edit Query flow is inconvenient

[https://github.com/microsoft/vscode-pull-request-github/issues/7749](https://github.com/microsoft/vscode-pull-request-github/issues/7749)

## Summary

Keep open: AI-assisted query editing still requires manually copying the result back, and the linked implementation PR closed without merging. This team-authored Backlog item requests an acknowledged workflow improvement, not a decline close.

## Change summary

Allow AI-generated query changes to be applied without manually copying them from chat into the query editor.

## Best solution

Provide an integrated apply step for AI-assisted editing of the selected query in src/common/settingsUtils.ts, preserving the intended configuration scope. The team should settle whether that interaction stays in the quick pick, applies through chat, or uses inline editing in settings.json.
