[https://github.com/microsoft/vscode-pull-request-github/issues/5092](https://github.com/microsoft/vscode-pull-request-github/issues/5092)

## Summary

Keep open while the explicitly linked implementation PR is under review. Current main still closes the active editor when `pr.markFileAsViewed` is invoked from a keybinding or editor action.

## Change summary

Allow `pr.markFileAsViewed` to mark the active file as viewed without closing its editor.

## Best solution
