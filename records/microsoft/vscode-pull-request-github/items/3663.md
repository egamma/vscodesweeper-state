# Issue #3663 — Show counter of issues/PRs

[https://github.com/microsoft/vscode-pull-request-github/issues/3663](https://github.com/microsoft/vscode-pull-request-github/issues/3663)

## Summary

A real gap remains on current main: issue and pull-request query nodes do not display result counts, and the existing activity-bar badge represents notifications rather than configurable query totals. Route this feature request to the tree-view and UX owners.

## Change summary

Show configurable issue and pull-request counts on the corresponding views and query groups.

## Best solution

Display counts beside issue query/group nodes using the already-loaded issue collections, and obtain lightweight totals for paginated pull-request queries without eagerly loading every PR. Any configurable activity-bar count should remain distinguishable from the existing notification badge.

- **Fit:** aligned

- **Evidence:** The durable themes explicitly include “Trees, queries, and views — the PR/issue viewlets, customizable queries,” while the product promise is to review and manage GitHub pull requests and issues directly in VS Code.
