# Issue #3663 — Show counter of issues/PRs

[https://github.com/microsoft/vscode-pull-request-github/issues/3663](https://github.com/microsoft/vscode-pull-request-github/issues/3663)

## Summary

A real capability gap remains: current query and group nodes do not display result counts. The maintainer reopened the request after its use case was clarified, so it should remain open and be routed to the tree-view owners.

## Change summary

Display configurable issue and pull-request counts on the corresponding views and query groups.

## Best solution

Add result-count descriptions to issue query/group nodes in `src/issues/issuesView.ts`; for PR categories, obtain an inexpensive total count without forcing all paginated results to load in `src/view/treeNodes/categoryNode.ts` and the query-fetching layer. Keep the activity-bar badge configurable or reserved for actionable notifications so raw totals do not obscure notification state.

- **Evidence:** The durable themes explicitly include “Trees, queries, and views” and the PR/issue viewlets with customizable queries.
