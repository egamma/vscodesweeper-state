## Summary

This remains a valid, unimplemented feature request. Current PR title and description generation delegates static repository context to a registered provider without exposing tool selection or interpreting prompt-file tool metadata, so it should remain open and route to the chat area.

## Change summary

Allow PR title and description generation to invoke explicitly assigned Copilot tools or MCP tools, such as Jira lookup tools declared in a prompt file.
