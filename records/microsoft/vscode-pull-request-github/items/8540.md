# Issue #8540 — Add context menu item for copying links in comments

[https://github.com/microsoft/vscode-pull-request-github/issues/8540](https://github.com/microsoft/vscode-pull-request-github/issues/8540)

## Summary

Still present on main: the existing Copy Comment Link command works for any persisted PR comment, but its context-menu contribution is restricted to comments the current user can edit. Routing this visibility bug to the comments area.

## Change summary

Copy Comment Link is absent from the context menu for PR comments authored by other users.

## Best solution

Expose `pr.copyCommentLink` for every persisted `GHPRComment` by removing the `canEdit` restriction from its `comments/comment/title` menu condition in package.json, while continuing to exclude temporary comments.
