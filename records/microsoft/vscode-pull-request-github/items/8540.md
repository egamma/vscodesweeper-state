# Issue #8540 — Add context menu item for copying links in comments

[https://github.com/microsoft/vscode-pull-request-github/issues/8540](https://github.com/microsoft/vscode-pull-request-github/issues/8540)

## Summary

A real gap remains: the existing Copy Comment Link context-menu action is restricted to comments marked `canEdit`, so links cannot be copied from other participants' comments. Route this focused request to the comments area.

## Change summary

Make the Copy Comment Link context-menu action available on all published PR comments, including comments the current user cannot edit.

## Best solution

Change the `comments/comment/context` contribution in package.json so `pr.copyCommentLink` is offered for every published `GHPRComment`, without requiring `canEdit`; retain the existing exclusion for temporary comments.
