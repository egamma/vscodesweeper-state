[https://github.com/microsoft/vscode-pull-request-github/issues/8540](https://github.com/microsoft/vscode-pull-request-github/issues/8540)

## Summary

The screenshot requests copying a hyperlink inside an in-editor review comment, not copying the comment's GitHub permalink. Keep this open and route through upstream/vscode: core owns the rendered links and their context menu, and no matching open canonical was found.

## Change summary

Add a context-menu action to copy the destination of a hyperlink inside a PR review comment.

## Best solution

Support link-target copying in microsoft/vscode's comment renderer and context menu while retaining existing review actions. A maintainer should coordinate the upstream request; the extension's existing permalink command does not cover it.
