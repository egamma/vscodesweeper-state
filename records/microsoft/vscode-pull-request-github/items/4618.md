# Issue #4618 —  Option to Choose Base for Diff

[https://github.com/microsoft/vscode-pull-request-github/issues/4618](https://github.com/microsoft/vscode-pull-request-github/issues/4618)

## Summary

A distinct review-flow gap remains on current main: users can compare against the PR base or their latest review commit, but cannot select an arbitrary commit as the diff base. Route this feature request to the review area.

## Change summary

Allow reviewers to choose a specific commit or revision as the base for a pull-request diff.

## Best solution

Add a review command that presents suitable PR commits and stores the selected comparison base in PullRequestModel, while retaining the existing all-changes and changes-since-last-review shortcuts.

## Vision fit

- **Fit:** aligned
- **Reason:** Selecting a precise comparison base strengthens the extension's native iterative-review workflow.
- **Evidence:** The durable themes explicitly include the review flow and comment anchoring across force-pushes and merges.
