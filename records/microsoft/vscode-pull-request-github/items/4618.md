[https://github.com/microsoft/vscode-pull-request-github/issues/4618](https://github.com/microsoft/vscode-pull-request-github/issues/4618)

## Summary

Choosing a custom comparison base remains unavailable on main, but the older, open commit-range request already owns this capability. Consolidate there, preserving the force-push comparison use case.

## Change summary

Allow reviewers to select a specific base commit for pull-request diffs.

## Best solution

Track selectable comparison endpoints in https://github.com/microsoft/vscode-pull-request-github/issues/505, including this report's custom-base and pre/post-force-push comparison requirements; the closed implementation stack remains useful design evidence, not a shipped fix.
