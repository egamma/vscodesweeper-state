# Issue #4618 —  Option to Choose Base for Diff

[https://github.com/microsoft/vscode-pull-request-github/issues/4618](https://github.com/microsoft/vscode-pull-request-github/issues/4618)

## Summary

A real review-flow gap remains on current main: reviewers can compare against the PR base or their latest review commit, but cannot select an arbitrary commit as the diff base. The narrower merge-commit problem is tracked separately, so this broader request should remain open and route to the review area.

## Change summary

Allow reviewers to select a specific commit or revision as the base for a pull-request diff.

## Best solution

Add a review-flow command that presents suitable PR commits or revisions and refreshes the PR file tree and multi-diff view using the selected SHA as the comparison base, while retaining the existing all-changes and changes-since-last-review shortcuts.

- **Reason:** Choosing a comparison base directly improves iterative in-editor pull-request review, a durable focus of the extension.

## Evidence

- **current implementation:** src/github/pullRequestModel.ts#getRawFileChangesInfo selects only between this.base.sha and getViewerLatestReviewCommit().sha before calling compareCommits; there is no state or input for an arbitrary selected base.
- **command surface:** package.json and src/commands.ts expose pr.showDiffSinceLastReview and pr.showDiffAll, which only toggle PullRequestModel.showChangesSinceReview; no command or setting allows choosing a commit as the PR diff base.
- **maintainer confirmation:** The maintainer explicitly confirmed in https://github.com/microsoft/vscode-pull-request-github/issues/4618#issuecomment-1466109154 that there was no way to choose a specific base, while recognizing the individual-file/base-selection idea.
