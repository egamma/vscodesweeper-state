VS Code Sweeper has moved

The sweeper's dashboard and reports now live inside vscode-tools, the VS Code team's internal tooling site, under Sweeper. This page is no longer generated.

The data behind it stays here: every review record is on the state branch (one Markdown file per reviewed issue), and the JSON data contracts the tools views render are on the main branch.

The sweeper only ever proposes. Every verdict is a suggestion a human maintainer may act on, under their own identity; nothing is applied automatically. The review policy is public under policy/, and corpus-level accuracy statistics are planned for the open-source repository.

Send feedback about the sweeper (opens a prefilled issue on the state repository).
