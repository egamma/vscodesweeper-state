The fix-issue skill

Let an agent implement a sweeper-reviewed fix for one of your microsoft/vscode issues — from your own checkout, under your own identity, as a draft PR you own.

What the sweeper did for you

The sweeper reviewed the open microsoft/vscode backlog with a source checkout and marked the issues an agent can fix — each with a fix spec written while tracing the defect: the observable problem, the fix boundary (what must not change), the likely files, and a validation that becomes the regression test. Your ranked list is on your top-issues page (filter: agent-fixable), and every spec is inspectable there before you run anything.

Using it

One-time setup (interim): the skill is headed for the vscode repo's .github/skills/ (once that PR lands, your checkout has it with no install at all). Until then, copy the generated SKILL.md into your agent's personal skills dir — ~/.copilot/skills/fix-issue/SKILL.md (Copilot CLI) or ~/.claude/skills/fix-issue/SKILL.md (Claude Code).

Then, in your agent, from your vscode checkout, just ask:

Fix microsoft/vscode issue #262104 using the vscodesweeper fix-issue skill.

The Copy fix prompt button on the dashboard and top pages copies exactly this line for the row's issue — an optional shortcut, nothing more.

What to expect

  • Live gates first. The skill refuses if the issue is closed, security-labeled, not reviewed as agent-fixable, or already has an open PR — and warns if the issue changed since its review.
  • The fix + a test. It implements the review's fix spec narrowly and adds the validation as a test that fails before the change and passes after.
  • You approve the diff. Nothing is pushed until you've seen the full diff and said go.
  • A draft PR you own. Branch <you>/fix-<n>, base main, body carries Fixes #n and a "seeded by" link to the review record. You review, flip to ready, and merge — or close it. The sweeper never touches the PR again.
The PR is a draft on purpose: the diff derives from a spec written over issue text. Flipping it to ready is your "I've read this diff" signal.

Troubleshooting

  • Skill doesn't trigger? Say "fix-issue skill" explicitly (agents match on the skill description). Copilot CLI loads skills at session start — restart it after pulling a checkout that just gained the skill.
  • "Not agent-fixable" refusal? The review found no safe fix spec for that issue — the skill only implements reviewed specs. Check the record linked from the dashboard for what the review concluded instead.
  • Skill still not found? Check the SKILL.md landed at exactly ~/.copilot/skills/fix-issue/SKILL.md (or the Claude equivalent) — the folder name must match the skill name.
